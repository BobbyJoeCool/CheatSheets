# CheatSheets

Programming Languages Cheat Sheets

## Purpose

There are three purposes of these sheets:

1. To serve as a quick reference guide for myself for languages and concepts that I have learned through school or on my own.
1. To practice agentic coding.  Most of these sheets are created by Claude AI.  This is to practice using prompts to complete coding tasks, and to verify information is accurate after AI generated it.
1. To practice HTML/CSS and some basic scripting for a web site, with a Mobile Friendly version (using @media) and a printer friendly version.
