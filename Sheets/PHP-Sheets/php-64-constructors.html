Constructors & Destructors

__construct · constructor promotion · new in initializers · static factories · __destruct

Setting Up Objects

__construct() runs when new creates an object; use it to require and validate the data an object needs. Constructor promotion (8.0) declares and assigns a property in one step by adding a visibility keyword to a parameter. new in initializers (8.1) allows default objects as parameter defaults. Static factory methods give alternative, named ways to build an object. __destruct() runs when the object is destroyed.

Notes

  • A child class must call parent::__construct() itself
  • Promoted params can be readonly and have defaults
  • Constructors may be private (factories, singletons)
  • Destructors run at end of request or when refcount drops to 0
  • Don't throw from destructors

Promotion, Factories & Destructors

<?php
class Point
{
    public function __construct(
        public readonly float $x = 0.0,
        public readonly float $y = 0.0,
    ) {}

    public static function fromArray(array $a): static
    {
        return new static($a['x'], $a['y']);
    }

    public static function origin(): static
    {
        return new static();
    }
}

$p = new Point(3, 4);
$q = Point::fromArray(['x' => 1, 'y' => 2]);
$r = new Point(y: 5);              // named arg

class Logger
{
    public function __construct(
        private Clock $clock = new SystemClock(),  // 8.1
    ) {}
}

class TempFile
{
    public function __construct(public string $path) {}
    public function __destruct() { @unlink($this->path); }
}

Code Explained

Visibility on a parameter promotes it to a property
Defaults work like normal parameters
new static respects subclasses
new in a default creates the object when omitted
Destructor cleans up when the object goes away

⚠ Common Mistakes

  • Forgetting parent::__construct() in a child
  • Doing heavy work (DB, HTTP) in constructors
  • Relying on destructor timing for important logic

✓ Tips & Best Practices

  • Promote properties to cut boilerplate
  • Validate arguments in the constructor
  • Add named static factories for alternative inputs
