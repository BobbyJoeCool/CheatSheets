Property Hooks

get hook · set hook · virtual properties · backed properties · hooks in interfaces · PHP 8.4

Logic on Property Access (8.4)

Property hooks attach code to reading (get) or writing (set) a property, so you can validate or compute values while keeping plain $obj->prop syntax. A backed property stores a value and its hooks can refer to it with $this->prop. A virtual property has hooks that never touch its own storage — it's computed from other data. Interfaces can declare properties with required hooks.

Notes

  • set receives the new value as $value (or a named param)
  • Short form: get => expression; and set => expression;
  • A virtual property with only get is read-only
  • Hooks are incompatible with readonly
  • Child classes can override individual hooks

get and set Hooks

<?php
class User
{
    public string $email {
        set(string $value) {
            if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                throw new InvalidArgumentException("Bad email");
            }
            $this->email = strtolower($value);   // backing store
        }
    }

    public function __construct(
        public string $first,
        public string $last,
    ) {}

    public string $fullName {                  // virtual
        get => "$this->first $this->last";
    }
}

$u = new User('Ana', 'Lee');
$u->email = 'ANA@Example.com';
echo $u->email;        // ana@example.com
echo $u->fullName;     // Ana Lee
// $u->fullName = 'x'; // Error: no set hook

interface HasArea { public float $area { get; } }

Code Explained

set validates then writes the backing value
Inside the hook, $this->email is the raw storage
Promoted properties work alongside hooked ones
Virtual: computed on each read, no storage
Interfaces can require a readable property

⚠ Common Mistakes

  • Calling the hook recursively via another accessor
  • Combining hooks with readonly
  • Using hooks for heavy work — reads look cheap

✓ Tips & Best Practices

  • Use set hooks for validation and normalisation
  • Use virtual get hooks for derived values
  • Keep hook bodies short

Quick Summary

  • get / set on properties (8.4)
