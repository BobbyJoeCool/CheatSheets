if, elseif & else

if · elseif vs else if · else · alternative syntax endif · guard clauses

Conditional Branches

if runs a block when its condition is truthy; elseif tests further conditions in order and else catches everything left. Only the first matching branch runs. Braces are optional for one statement but always recommended. In templates, the alternative syntax (if (...): … endif;) reads better between chunks of HTML. Guard clauses return early and keep the main path unindented.

Notes

  • elseif (one word) and else if behave the same with braces
  • With the colon syntax only elseif works
  • Conditions use truthiness rules (Sheet 12)
  • Assignments in conditions need extra parentheses for clarity
  • Long elseif chains on one value → consider match

Branches, Guards & Templates

<?php
function shipping(float $total, string $country): float
{
    if ($total <= 0) {
        throw new InvalidArgumentException('Empty cart');
    }                                 // guard clause

    if ($total >= 100) {
        return 0.0;
    } elseif ($country === 'US') {
        return 5.0;
    } else {
        return 15.0;
    }
}

if (($user = findUser($id)) !== null) {
    echo $user->name;
}
?>
<?php if ($loggedIn): ?>
    <a href="/logout">Log out</a>
<?php else: ?>
    <a href="/login">Log in</a>
<?php endif; ?>

Code Explained

Guard clause handles the bad case and leaves
Branches are tested top to bottom; first match wins
else has no condition
Parenthesise an assignment used as a condition
Colon syntax pairs with endif; in HTML templates

⚠ Common Mistakes

  • if ($a = 5) — assigns instead of comparing
  • Mixing { braces and : syntax in one if
  • Deep nesting instead of returning early

✓ Tips & Best Practices

  • Always use braces in PHP-only code
  • Return early on invalid input
  • Use alternative syntax only in templates

Quick Summary
