match Expressions

match · strict === · comma conditions · no fall-through · UnhandledMatchError · match(true)

match (PHP 8.0)

match maps a value to a result. It is an expression — it returns a value — and it compares with **strict ===**. Each arm is a single expression; there's no fall-through and no break. Several values can share an arm separated by commas. If nothing matches and there's no default, PHP throws UnhandledMatchError, so missing cases show up immediately instead of silently doing nothing.

Notes

  • Arm results can be any expression, including throw
  • match (true) lets each arm be a condition
  • Only the matching arm's expression is evaluated
  • Trailing comma after the last arm is allowed
  • Combine with enums for exhaustive mapping

Mapping Values with match

<?php
$status = 404;

$message = match ($status) {
    200, 201 => 'OK',
    301, 302 => 'Redirect',
    404      => 'Not Found',
    500      => 'Server Error',
    default  => 'Unknown',
};                                  // 'Not Found'

$price = match ($plan) {
    'free'  => 0,
    'pro'   => 12,
    default => throw new DomainException("Bad plan: $plan"),
};

$grade = match (true) {
    $score >= 90 => 'A',
    $score >= 80 => 'B',
    $score >= 70 => 'C',
    default      => 'F',
};

echo match ('1') { 1 => 'int', '1' => 'string' }; // string

Code Explained

Comma list: any of these values selects the arm
Result is assigned directly — no temp variable
throw works as an arm expression
match (true) picks the first true condition
Strict comparison: '1' doesn't match 1

⚠ Common Mistakes

  • Expecting loose comparison like switch
  • Trying to put several statements in an arm
  • Adding default to enum matches — it hides new cases

✓ Tips & Best Practices

  • Use match for value-to-value mapping
  • Let UnhandledMatchError flag impossible states
  • Move complex arm logic into small functions

Quick Summary

  • Expression that returns a value
  • Strict ===
  • No fall-through or break
