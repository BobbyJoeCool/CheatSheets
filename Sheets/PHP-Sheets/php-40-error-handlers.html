Sheet 40

Global Error Handlers

set_error_handler() · set_exception_handler() · ErrorException · register_shutdown_function() · error_get_last() · trigger_error()

Catching What Slips Through

set_error_handler() intercepts warnings, notices and deprecations; the common pattern converts them to ErrorException so they behave like exceptions. set_exception_handler() receives any uncaught throwable — your last chance to log and show a friendly error page. True fatal errors (like running out of memory) can only be observed from a shutdown function using error_get_last().

Notes

  • The error handler must return true to stop PHP's default handling
  • Respect error_reporting() and the @ operator inside your handler
  • The exception handler ends the script after it runs
  • trigger_error() raises E_USER_* diagnostics from your code
  • Frameworks install these handlers for you

Installing Handlers

<?php
set_error_handler(function (
    int $no, string $msg, string $file, int $line,
): bool {
    if (!(error_reporting() & $no)) {
        return false;                 // silenced with @ or level off
    }
    throw new ErrorException($msg, 0, $no, $file, $line);
});

set_exception_handler(function (Throwable $e): void {
    error_log((string) $e);
    http_response_code(500);
    echo 'Something went wrong. Please try again.';
});

register_shutdown_function(function (): void {
    $err = error_get_last();
    $fatal = [E_ERROR, E_PARSE, E_CORE_ERROR];
    if ($err && in_array($err['type'], $fatal, true)) {
        error_log("Fatal: {$err['message']}");
    }
});

trigger_error('Use newApi() instead', E_USER_DEPRECATED);
echo $undefined;                      // now throws ErrorException

Code Explained

Bitmask check honours @ and error_reporting
ErrorException keeps the severity and location
Exception handler: log, send 500, show safe text
Shutdown function sees fatal errors after the fact
With the handler, warnings become exceptions

⚠ Common Mistakes

  • Ignoring error_reporting() — @ stops working
  • Echoing stack traces to users in production
  • Using E_USER_ERROR (deprecated in 8.4)

✓ Tips & Best Practices

  • Install handlers first thing in your front controller
  • Turn warnings into exceptions during development
  • Log with full context; show users a generic message

Quick Summary

  • set_error_handler → ErrorException
  • set_exception_handler = last resort
  • Shutdown function for fatals
  • trigger_error for deprecations
