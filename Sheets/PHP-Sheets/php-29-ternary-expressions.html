Ternary & Conditional Expressions

?: · short ternary ?: · nested ternary needs parens · ?? as default · ternary in templates

Choosing a Value Inline

The ternary operator cond ? a : b is an expression, so it produces a value you can assign, return or echo. The short ternary a ?: b returns a if it's truthy, otherwise b. Nesting ternaries without parentheses is a fatal error since PHP 8 because the old left-to-right grouping was confusing. For null-only defaults, ?? is safer than ?:.

Notes

  • Only one branch is evaluated
  • Keep ternaries to one line and one decision
  • ?: evaluates the left side once
  • Use match when there are three or more outcomes
  • Ternaries work well inside <?= ?> in templates

Ternary Patterns

<?php
$age = 17;
$label = $age >= 18 ? 'adult' : 'minor';   // 'minor'

echo $count === 1 ? 'item' : 'items';

$title = $post['title'] ?: 'Untitled';     // '' -> Untitled
$limit = $_GET['limit'] ?? 10;             // null-only

// Nested: parentheses are required
$size = $n < 10 ? 'small' : ($n < 100 ? 'medium' : 'large');
// $n < 10 ? 'a' : $n < 100 ? 'b' : 'c';  // Fatal error

// Better for 3+ outcomes
$size = match (true) {
    $n < 10  => 'small',
    $n < 100 => 'medium',
    default  => 'large',
};

return $user?->isAdmin() ? redirect('/admin') : view('home');
?>
<li class="<?= $active ? 'active' : '' ?>">Home</li>

Code Explained

Condition, then value if true, then value if false
?: falls back on any falsy value
?? falls back only on null or missing
Unparenthesised nesting is rejected at compile time
match(true) reads better than nested ternaries

⚠ Common Mistakes

  • Nesting ternaries without parentheses
  • Using ?: for a value where 0 is valid
  • Cramming side effects into ternary branches

✓ Tips & Best Practices

  • One ternary per expression
  • Use ?? for missing keys, ?: for empty strings
  • Switch to match for three or more outcomes

Quick Summary

  • c ? a : b is an expression
  • a ?: b short form
  • Nested needs parens
  • match for many outcomes
