Arithmetic Operators

+ - * / % ** · ++ -- · intdiv() · fmod() · DivisionByZeroError · numeric-string math

Doing Math

PHP has the usual arithmetic operators plus ** for powers. / returns an int only when both operands are ints and the result is exact; otherwise a float. % is the integer remainder and takes the sign of the left operand. Dividing or taking % by zero throws **DivisionByZeroError**. Numeric strings are converted automatically; non-numeric strings throw TypeError.

Notes

  • ** is right-associative: 2 ** 3 ** 2 is 2 ** 9
  • -2 ** 2 is -4 (power binds tighter than unary minus)
  • % truncates floats to int (7.9 % 2 is 1, deprecated 8.1+)
  • PHP_INT_MAX + 1 overflows to float
  • fdiv() returns INF/NAN instead of throwing

Operators in Action

<?php
echo 7 + 2, ' ', 7 - 2, ' ', 7 * 2;   // 9 5 14
var_dump(7 / 2);                      // float(3.5)
var_dump(6 / 2);                      // int(3)
var_dump(7 % 3);                      // int(1)
var_dump(-7 % 3);                     // int(-1)
var_dump(2 ** 10);                    // int(1024)
var_dump(2 ** -1);                    // float(0.5)
var_dump(fmod(7.5, 2));               // float(1.5)

$i = 5;
echo $i++;   // 5 (then $i = 6)
echo ++$i;   // 7

try {
    echo 1 % 0;
} catch (DivisionByZeroError $e) {
    echo $e->getMessage();            // Modulo by zero
}
var_dump(fdiv(1, 0));                 // float(INF)

Code Explained

/ gives int only for exact int division
% result has the sign of the dividend
Negative exponent produces a float
Postfix $i++ returns the old value; prefix returns the new
1 / 0 and 1 % 0 both throw in PHP 8

⚠ Common Mistakes

  • Using % with floats — operands are truncated to int
  • Expecting -2 ** 2 to be 4
  • Using ++ on strings — prefer str_increment() (8.3+)

✓ Tips & Best Practices

  • Use intdiv() when you want an int result
  • Parenthesise mixed operators for readability
  • Catch DivisionByZeroError where a divisor comes from input

Quick Summary
