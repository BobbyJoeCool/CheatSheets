try, catch & finally

try · catch · multi-catch A|B · catch without variable · finally · rethrow · getMessage()

Handling Exceptions

Wrap code that may throw in try. Each catch names one or more types; the first matching catch runs, so order them from most specific to most general. catch (A | B $e) handles several types in one block, and since PHP 8 the variable is optional. finally runs whether the try succeeded, threw, or returned — use it for cleanup like closing files or releasing locks.

Notes

  • A catch matches subclasses of the named type
  • Rethrow with throw $e; or wrap: throw new X('…', 0, $e)
  • A return in finally overrides earlier returns — avoid it
  • Uncaught exceptions bubble up through calling functions
  • getMessage(), getCode(), getFile(), getLine(), getTrace()

try / catch / finally

<?php
function loadConfig(string $path): array
{
    $fh = fopen($path, 'r')
        ?: throw new RuntimeException("Can't open $path");
    try {
        $json = stream_get_contents($fh);
        return json_decode($json, true,
            flags: JSON_THROW_ON_ERROR);
    } catch (JsonException $e) {
        throw new RuntimeException("Bad JSON in $path", 0, $e);
    } finally {
        fclose($fh);                  // always runs
    }
}

try {
    $cfg = loadConfig('app.json');
} catch (InvalidArgumentException | DomainException $e) {
    echo 'Input problem: ', $e->getMessage();
} catch (RuntimeException $e) {
    error_log($e);                    // __toString has trace
    $cfg = [];
} catch (Throwable) {                 // no variable (8.0)
    exit(1);
}

Code Explained

?: throw — throw as an expression when fopen fails
JSON_THROW_ON_ERROR turns JSON errors into exceptions
Wrapping keeps the original as getPrevious()
finally closes the file even after return
Multi-catch with |; broadest type last

⚠ Common Mistakes

  • Empty catch blocks that swallow errors
  • Catching Exception before a more specific type
  • Returning from finally

✓ Tips & Best Practices

  • Catch only what you can handle; let the rest bubble
  • Wrap low-level exceptions with context
  • Log the exception object — __toString() includes the trace

Quick Summary

  • First matching catch wins
  • A | B multi-catch
  • finally always cleans up
  • Wrap with $previous
