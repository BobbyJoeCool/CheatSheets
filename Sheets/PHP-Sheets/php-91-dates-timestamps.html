Dates — date() & Timestamps

time() · date() · format codes · mktime() · strtotime() · checkdate() · date_default_timezone_set()

Procedural Date Functions

A Unix timestamp is the number of seconds since 1970-01-01 00:00:00 UTC; time() returns the current one. date($format, $ts) formats a timestamp in the default timezone using format letters such as Y-m-d H:i:s. strtotime() parses English text ('next monday', '+1 week') into a timestamp and mktime() builds one from parts. For anything beyond simple formatting, prefer DateTimeImmutable (Sheet 92).

Notes

  • Set the default timezone in php.ini (date.timezone) or at startup
  • Store times in UTC; convert for display
  • strtotime() returns false on unparseable input
  • microtime(true) gives a float with microseconds
  • hrtime(true) gives nanoseconds for timing code

Timestamps and Formatting

<?php
date_default_timezone_set('UTC');

$now = time();                         // e.g. 1791468309
echo date('Y-m-d H:i:s');              // 2026-10-08 14:05:09
echo date('D, d M Y', $now);           // Thu, 08 Oct 2026
echo date('l jS \of F Y');             // Thursday 8th of October 2026
echo date(DATE_ATOM);                  // 2026-10-08T14:05:09+00:00
echo date('N');                        // 4 (ISO: Thu)

$ts = mktime(9, 30, 0, 12, 25, 2026);  // h, i, s, month, day, year
$ts = strtotime('2026-12-25 09:30');
$ts = strtotime('+1 week 2 days');
$ts = strtotime('last day of next month');
if (strtotime('not a date') === false) { /* invalid */ }

checkdate(2, 29, 2027);                // false (not leap)

$start = hrtime(true);
usleep(1000);
$ms = (hrtime(true) - $start) / 1e6;   // elapsed milliseconds

Code Explained

Always set a timezone
Format letters; escape literal letters with \
DATE_ATOM is ISO 8601
mktime argument order is hour, minute, second, month, day, year
hrtime() is monotonic — good for measuring durations

⚠ Common Mistakes

  • Leaving the timezone unset — results depend on server config
  • Adding 86400 to go to tomorrow — wrong across DST
  • Confusing m (month) and i (minutes)

✓ Tips & Best Practices

  • Store UTC; format in the user's timezone
  • Use DateTimeImmutable for arithmetic
  • Use hrtime() for benchmarks
