Sheet 44

Parameter & Return Types

int|string · ?int · void · never · mixed · static · A&B · DNF types

Type Declarations

Types on parameters, return values and properties are checked at runtime: a wrong type throws TypeError. In the default coercive mode, scalar arguments are converted when safe ('5' → 5). With declare(strict_types=1) at the top of the calling file, no conversion happens (except int → float). Unions (int|string), intersections (A&B) and DNF types ((A&B)|null) describe richer contracts.

Notes

  • strict_types affects calls made from the file that declares it
  • Return types are always checked against the function's own file mode
  • mixed = any value including null; it can't be nullable
  • iterable = array|Traversable (8.2 alias)
  • false, true and null exist as standalone types (8.2)

Type Forms

<?php
declare(strict_types=1);

function area(float $w, float $h): float { return $w * $h; }
area(2, 3);              // int → float allowed: 6.0
// area('2', 3);         // TypeError in strict mode

function idOf(int|string $id): string { return (string) $id; }
function find(int $id): ?User { return null; }
function note(string $m): void { echo $m; }
function fail(string $m): never { throw new Exception($m); }

function save(Countable&Traversable $items): void {}
function load((Countable&Traversable)|null $x): void {}

class Builder {
    public function where(string $c): static { return $this; }
}

Code Explained

Strict mode still widens int to float
int|string — union accepts either
?User — nullable shorthand
A&B — value must implement both
static return — the called class (fluent APIs)

⚠ Common Mistakes

  • Putting declare(strict_types=1) anywhere but the first statement
  • Using ?mixed — mixed already includes null
  • Typing callable on a property — not allowed

✓ Tips & Best Practices

  • Enable strict types in every file
  • Type every parameter, return and property
  • Use PHPDoc generics for array contents (Sheet 98)
