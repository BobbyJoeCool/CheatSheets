Sheet 112

Input Validation & Filtering

filter_var() · FILTER_VALIDATE_EMAIL · FILTER_VALIDATE_INT · options & flags · filter_input() · ctype_*

Trust Nothing

Validate every external value before using it. The filter extension handles common cases: filter_var($value, FILTER_VALIDATE_*) returns the converted value or false, with options such as ranges and defaults. filter_input() reads directly from the request. ctype_* functions check character classes, and regex covers custom formats. Validation decides accept or reject; escaping for output is a separate step.

Notes

  • FILTER_VALIDATE_INT returns 0 for "0" — compare with === false
  • FILTER_NULL_ON_FAILURE returns null instead of false
  • FILTER_SANITIZE_STRING is deprecated (8.1) — escape on output
  • Use allow-lists for enums and sort columns
  • Libraries: Symfony Validator, Respect\Validation

filter_var and Friends

<?php
filter_var('42', FILTER_VALIDATE_INT);               // 42
filter_var('4.2', FILTER_VALIDATE_INT);              // false
filter_var('0', FILTER_VALIDATE_INT);                // 0 (valid!)
filter_var('15', FILTER_VALIDATE_INT,
    ['options' => ['min_range' => 1, 'max_range' => 10]]);  // false

filter_var('ana@example.com', FILTER_VALIDATE_EMAIL);
filter_var('https://x.io/a', FILTER_VALIDATE_URL);
filter_var('192.168.1.1', FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE); // false
filter_var('yes', FILTER_VALIDATE_BOOL, FILTER_NULL_ON_FAILURE);  // true
filter_var('3,5', FILTER_VALIDATE_FLOAT,
    ['options' => ['decimal' => ',']]);              // 3.5

$age = filter_input(INPUT_POST, 'age', FILTER_VALIDATE_INT);
if ($age === false || $age === null) { /* invalid or missing */ }

ctype_digit('123');            // true ('-1' false)
ctype_alnum('abc123');         // true

$sort = in_array($_GET['sort'] ?? '', ['name', 'date'], true)
    ? $_GET['sort'] : 'name';   // allow-list

Code Explained

Returns the typed value on success
0 is valid — test with === false
Range options reject out-of-bounds values
Flags refine rules (no private IPs)
Allow-list user choices like sort columns

⚠ Common Mistakes

  • if (!filter_var($n, FILTER_VALIDATE_INT)) — rejects 0
  • Sanitising input instead of escaping output
  • Trusting client-side validation

✓ Tips & Best Practices

  • Validate at the boundary, then work with typed values
  • Use allow-lists over block-lists
  • Return all field errors at once

Quick Summary

  • filter_var validates + converts
  • === false check
  • filter_input for requests
  • Allow-lists for choices
