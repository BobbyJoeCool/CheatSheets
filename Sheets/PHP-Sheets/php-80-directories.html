Directories & File Management

mkdir() · scandir() · glob() · RecursiveDirectoryIterator · rename() · copy() · unlink() · rmdir()

Folders and Their Contents

Create directories with mkdir() (pass recursive: true for nested paths) and remove empty ones with rmdir(). List contents with scandir() (includes . and ..) or match patterns with glob(). To walk a whole tree, combine RecursiveDirectoryIterator with RecursiveIteratorIterator. Deleting a non-empty directory means removing its files first.

Notes

  • mkdir permissions are reduced by the process umask
  • glob() returns [] when nothing matches
  • GLOB_BRACE (*.{jpg,png}) isn't available on every platform
  • FilesystemIterator::SKIP_DOTS hides . and ..
  • rename() can move across directories on the same disk

List, Walk, Delete

<?php
mkdir(__DIR__ . '/storage/cache', 0775, recursive: true);

$entries = array_diff(scandir('.'), ['.', '..']);
$images  = glob(__DIR__ . '/img/*.{jpg,png}', GLOB_BRACE);
$dirs    = glob('*', GLOB_ONLYDIR);

$skip = FilesystemIterator::SKIP_DOTS;
$it = new RecursiveIteratorIterator(
    new RecursiveDirectoryIterator('src', $skip)
);
foreach ($it as $file) {               // SplFileInfo
    if ($file->getExtension() === 'php') {
        echo $file->getPathname(), ' ', $file->getSize(), "\n";
    }
}

function rrmdir(string $dir): void
{
    $skip = FilesystemIterator::SKIP_DOTS;
    $it = new RecursiveIteratorIterator(
        new RecursiveDirectoryIterator($dir, $skip),
        RecursiveIteratorIterator::CHILD_FIRST
    );
    foreach ($it as $f) {
        $p = $f->getPathname();
        $f->isDir() ? rmdir($p) : unlink($p);
    }
    rmdir($dir);
}

Code Explained

Named recursive: argument creates parents
Remove . and .. from scandir() output
glob brace pattern matches several extensions
Recursive iterator yields SplFileInfo objects
CHILD_FIRST deletes contents before folders

⚠ Common Mistakes

  • Forgetting . and .. in scandir() results
  • rmdir() on a non-empty directory — fails
  • Recursive delete on a path built from user input

✓ Tips & Best Practices

  • Use iterators for large trees (lazy)
  • Guard destructive operations with realpath() checks
  • Use Symfony Filesystem for robust cross-platform helpers

Quick Summary

  • mkdir(…, recursive: true)
  • scandir / glob
  • Recursive iterators walk trees
  • Empty before rmdir
