Sheet 110

Superglobals

$_GET · $_POST · $_REQUEST · $_SERVER · $_FILES · $_COOKIE · $_SESSION

Request Data Arrays

PHP fills several superglobal arrays at the start of each request; they're readable in any scope. $_GET holds query-string parameters, $_POST form fields from urlencoded or multipart bodies, $_COOKIE cookies, $_FILES uploads, and $_SERVER request metadata such as method, URI and headers. Treat every value as untrusted user input: validate on the way in, escape on the way out.

Notes

  • Values are strings or arrays — never ints or bools
  • $_POST is empty for JSON bodies; read php://input
  • Avoid $_REQUEST — it merges sources in config-dependent order
  • HTTP headers appear as $_SERVER['HTTP_*']
  • filter_input() reads the original request values

Reading Request Data

<?php
// GET /search.php?q=php&tags[]=web&tags[]=api&page=2
$q     = $_GET['q'] ?? '';                       // 'php'
$tags  = $_GET['tags'] ?? [];                    // ['web', 'api']
$page  = filter_input(INPUT_GET, 'page', FILTER_VALIDATE_INT,
         ['options' => ['default' => 1, 'min_range' => 1]]);

$method = $_SERVER['REQUEST_METHOD'];            // 'GET'
$path   = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
$agent  = $_SERVER['HTTP_USER_AGENT'] ?? '';
$ip     = $_SERVER['REMOTE_ADDR'];
$https  = ($_SERVER['HTTPS'] ?? '') === 'on';

if ($method === 'POST') {
    $email = trim($_POST['email'] ?? '');
}

$json = json_decode(file_get_contents('php://input') ?: 'null', true);
$theme = $_COOKIE['theme'] ?? 'light';

Code Explained

?? avoids undefined-index warnings
name[] in the query string becomes an array
filter_input validates and applies a default
REQUEST_URI includes the query string — parse the path
JSON APIs read the raw body, not $_POST

⚠ Common Mistakes

  • Using values without validation
  • Trusting X-Forwarded-For from the internet
  • Reading JSON bodies from $_POST

✓ Tips & Best Practices

  • Wrap globals in a Request object (PSR-7, Symfony HttpFoundation)
  • Validate with filter_input() / filter_var()
  • Escape output with htmlspecialchars()

Quick Summary

  • $_GET $_POST $_COOKIE $_FILES
  • $_SERVER metadata
  • Strings only, untrusted
  • JSON via php://input
