Sheet 50

Generators & yield

yield · yield $k => $v · yield from · send() · getReturn() · iterator_to_array() · memory savings

Lazy Sequences

A function containing yield is a generator: calling it returns a Generator object without running the body. Each foreach step resumes the body until the next yield, which hands out one value. Only the current value lives in memory, so generators can process huge files or infinite sequences. yield from delegates to another generator or array; return provides a final value via getReturn().

Notes

  • A generator can only be iterated once (no rewind after start)
  • yield $key => $value controls the keys
  • $gen->send($x) resumes and makes yield evaluate to $x
  • iterator_to_array($g, false) ignores keys (avoids overwrites)
  • Return type: Generator, iterable or Iterator

Generators in Action

<?php
function readLines(string $path): Generator
{
    $fh = fopen($path, 'r');
    try {
        while (($line = fgets($fh)) !== false) {
            yield rtrim($line, "\n");     // one line at a time
        }
    } finally {
        fclose($fh);
    }
}
foreach (readLines('huge.log') as $n => $line) {
    if (str_contains($line, 'ERROR')) echo "$n: $line\n";
}

function naturals(): Generator {
    for ($i = 1; ; $i++) yield $i;      // infinite
}

function all(): Generator {
    yield 0;
    yield from [1, 2];                  // delegate
    yield from naturals();
}

function job(): Generator { yield 1; return 'done'; }
$g = job();
foreach ($g as $v) {}
echo $g->getReturn();                   // done

Code Explained

Body pauses at each yield
finally closes the file even if the loop breaks early
Keys default to 0, 1, 2, …
An infinite generator is fine when the consumer stops
getReturn() reads the return value after completion

⚠ Common Mistakes

  • Iterating a generator twice — Exception: already closed
  • iterator_to_array() on yield from output — duplicate keys overwrite
  • Calling count() on a generator

✓ Tips & Best Practices

  • Stream big files and query results with generators
  • Pass false to iterator_to_array() for lists
  • Use try/finally inside generators for cleanup

Quick Summary

  • yield makes a lazy iterator
  • One value in memory at a time
  • yield from delegates
  • Iterate once only
