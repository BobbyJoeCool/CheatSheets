Integers

int literals · 0x · 0o · 0b · 1_000_000 · overflow to float · intdiv() · intval()

Whole Numbers

int is a signed whole number, 64 bits on all modern platforms (PHP_INT_MIN to PHP_INT_MAX). Write literals in decimal, hex (0x), octal (0o or a leading 0) or binary (0b), with _ separators for readability. When an arithmetic result goes past PHP_INT_MAX PHP silently switches to float, losing precision. / always returns a float if the result isn't whole; use intdiv() for integer division.

Notes

  • _ separators can't start, end or double up: 1__000 is invalid
  • 0o17 (8.1+) is clearer than legacy 017
  • % works on ints; fmod() for floats
  • Use the bcmath or gmp extension for arbitrary precision
  • is_int() checks type; ctype_digit() checks a digit string

Literals, Limits & Conversion

<?php
$dec = 1_000_000;           // 1000000
$hex = 0xFF;                // 255
$oct = 0o17;                // 15
$bin = 0b1010;              // 10

var_dump(PHP_INT_MAX + 1);  // float(9.2233720368548E+18)

var_dump(7 / 2);            // float(3.5)
var_dump(8 / 2);            // int(4)
var_dump(intdiv(7, 2));     // int(3)
var_dump(7 % 3, -7 % 3);    // int(1), int(-1)

(int) '42abc';              // 42 (no error)
intval('0x1A', 16);         // 26
intval('101', 2);           // 5
(int) 3.99;                 // 3 (truncates)

Code Explained

Literal prefixes pick the base; the value is the same int
Overflow turns the result into a float
/ gives int only when the division is exact
% takes the sign of the left operand
(int) truncates toward zero and ignores trailing junk

⚠ Common Mistakes

  • Validating input with (int) — '12abc' becomes 12 silently
  • Assuming integer math can't overflow — it becomes a float
  • Legacy octal 0755 read as decimal by humans

✓ Tips & Best Practices

  • Validate with filter_var(..., FILTER_VALIDATE_INT)
  • Use intdiv() when you need whole-number division
  • Use 0o for octal literals in new code

Quick Summary
