Headers, Redirects & Status Codes

header() · http_response_code() · Location redirects · headers_sent() · Content-Type · JSON responses

Controlling the Response

header() adds or replaces an HTTP response header; http_response_code() sets the status. Headers must be sent before any body output — even a space before <?php sends output and locks them. A redirect is a Location header plus a 3xx status, followed by exit. For JSON APIs set Content-Type: application/json and echo the encoded body.

Notes

  • header('X: 1', false) adds instead of replacing
  • headers_sent($file, $line) tells you who sent output
  • Output buffering can delay sending headers
  • header_remove('X-Powered-By') removes a header
  • Default content type is text/html; charset=UTF-8

Status, Headers, Redirects, JSON

<?php
function json(mixed $data, int $status = 200): never
{
    http_response_code($status);
    header('Content-Type: application/json; charset=utf-8');
    header('Cache-Control: no-store');
    echo json_encode($data, JSON_THROW_ON_ERROR | JSON_UNESCAPED_SLASHES);
    exit;
}

function redirect(string $url, int $status = 302): never
{
    header('Location: ' . $url, true, $status);
    exit;
}

if (headers_sent($file, $line)) {
    throw new LogicException("Output started at $file:$line");
}

header_remove('X-Powered-By');
header('X-Frame-Options: DENY');
header('Content-Security-Policy: default-src \'self\'');

$user ?? json(['error' => 'Not found'], 404);
header('Content-Disposition: attachment; filename="report.csv"');

Code Explained

never return type: these functions always exit
Status first, then headers, then body
Location + 302/303/301/307/308 = redirect
Check headers_sent() to debug output leaks
Security headers reduce attack surface

⚠ Common Mistakes

  • Output (even whitespace or a BOM) before header()
  • Missing exit after a redirect — code keeps running
  • Redirecting to a URL taken from user input (open redirect)

✓ Tips & Best Practices

  • Centralise responses in helper functions or a Response object
  • Use 303 after POST, 301/308 for moved pages
  • Remove X-Powered-By and add security headers

Quick Summary

  • header() before output
  • http_response_code()
  • Redirect + exit
  • JSON: content type + encode
