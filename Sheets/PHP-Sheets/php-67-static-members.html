Static Members & Class Constants

static · self:: · static:: late static binding · parent:: · class constants · typed constants (8.3)

Class-Level Members

static properties and methods belong to the class, not to an instance; access them with ::. Class constants are fixed values on the class; PHP 8.3 lets you type them. self:: refers to the class where the code is written, while static:: refers to the class that was actually called — this is late static binding, essential for inheritance-friendly factories.

Notes

  • Static methods have no $this
  • Static properties are shared across all instances (per request)
  • final constants can't be overridden (8.1)
  • Foo::{$name} dynamic constant fetch (8.3)
  • Prefer dependency injection over static state

self::, static:: and Constants

<?php
class Model
{
    public const string TABLE = 'models';      // typed (8.3)
    final public const int VERSION = 2;
    protected static int $count = 0;

    public static function create(): static
    {
        static::$count++;
        return new static();                   // called class
    }

    public static function table(): string
    {
        return static::TABLE;                  // late binding
    }

    public static function selfTable(): string
    {
        return self::TABLE;                    // always Model
    }
}

class User extends Model
{
    public const string TABLE = 'users';
}

echo User::table();       // users
echo User::selfTable();   // models
$u = User::create();      // a User, not a Model
echo Model::VERSION;      // 2

Code Explained

Constants are read with Class::NAME
final constants can't be redefined in children
new static() creates the subclass that was called
static::TABLE resolves in the child
self::TABLE is fixed to the defining class

⚠ Common Mistakes

  • Using self:: in factories, so subclasses get the parent type
  • Global state hidden in static properties
  • Calling instance methods statically — Error

✓ Tips & Best Practices

  • Use static:: and new static in base-class factories
  • Type your class constants (8.3)
  • Keep static methods pure (no shared state)

Quick Summary

  • :: for class members
  • self = here, static = called
  • Typed constants (8.3)
  • Avoid static state
