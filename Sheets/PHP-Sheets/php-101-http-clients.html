HTTP Clients — cURL & Guzzle

curl_init() · CURLOPT_ options · curl_exec() · Guzzle Client · request options · PSR-18

Making HTTP Requests

The cURL extension is PHP's low-level HTTP client: create a handle, set options, execute, close. It's powerful but verbose. Guzzle wraps it in a clean object API with JSON helpers, timeouts, retries via middleware and async requests. PSR-18 (ClientInterface) and PSR-7 messages let you swap clients — Symfony HttpClient is another popular choice.

Notes

  • Always set connect and total timeouts
  • Check both transport errors and HTTP status codes
  • Guzzle throws on 4xx/5xx by default (http_errors)
  • Keep TLS verification on (CURLOPT_SSL_VERIFYPEER)
  • curl_close() is a no-op since 8.0 — handles are objects

cURL vs Guzzle

<?php
// cURL
$ch = curl_init('https://api.example.com/users?page=1');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => ['Accept: application/json'],
    CURLOPT_CONNECTTIMEOUT => 3,
    CURLOPT_TIMEOUT        => 10,
]);
$body = curl_exec($ch);
if ($body === false) throw new RuntimeException(curl_error($ch));
$status = curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
$users = json_decode($body, true, flags: JSON_THROW_ON_ERROR);

// Guzzle
use GuzzleHttp\Client;
use GuzzleHttp\Exception\RequestException;

$http = new Client([
    'base_uri' => 'https://api.example.com/',
    'timeout'  => 10,
]);
try {
    $res = $http->post('users', ['json' => ['name' => 'Ana']]);
    $created = json_decode((string) $res->getBody(), true);
    echo $res->getStatusCode();                 // 201
} catch (RequestException $e) {
    $code = $e->getResponse()?->getStatusCode();
}

Code Explained

RETURNTRANSFER returns the body instead of printing it
Separate connect and total timeouts
false from curl_exec = network error; read curl_error
Guzzle json option encodes the body and sets headers
RequestException covers 4xx/5xx and transport failures

⚠ Common Mistakes

  • No timeouts — requests hang workers
  • Disabling TLS verification to "fix" certificate errors
  • Ignoring non-200 statuses with raw cURL

✓ Tips & Best Practices

  • Inject a PSR-18 client for testability
  • Add retry middleware for flaky upstreams
  • Use Guzzle's MockHandler in tests

Quick Summary

  • cURL: init, setopt, exec
  • Guzzle: object API + JSON
  • Always set timeouts
  • PSR-18 for swappable clients
