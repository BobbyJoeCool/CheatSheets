Variadic Parameters & Spread

...$args · spread in calls · string-key spread · func_get_args() · named + variadic

Any Number of Arguments

A variadic parameter ...$items collects all remaining arguments into an array. It must be the last parameter and can be typed (int ...$nums) so every element is checked. The same ... operator spreads an array or Traversable into separate arguments at the call site. With string keys, spread values become named arguments, and a variadic collects unknown named arguments with their names as keys.

Notes

  • Only one variadic parameter, and it must be last
  • A variadic can be by reference: &...$refs
  • func_get_args() is the old way — prefer ...
  • Spreading an empty array passes no arguments
  • array_merge(...$arrays) merges a list of arrays

Collecting and Spreading

<?php
function sum(int ...$nums): int
{
    return array_sum($nums);
}
sum();                         // 0
sum(1, 2, 3);                  // 6
$list = [4, 5, 6];
sum(...$list);                 // 15
sum(1, ...$list, ...[7]);      // 23

function tag(string $name, string ...$classes): string
{
    return "<$name class=\"" . implode(' ', $classes) . '">';
}
tag('div', 'card', 'shadow');  // <div class="card shadow">

function opts(...$o) { return $o; }
opts(1, debug: true);          // [0 => 1, 'debug' => true]

$args = ['tag' => 'p', 'text' => 'Hi'];
makeTag(...$args);             // spread as named args

$all = array_merge(...$chunks);   // flatten one level

Code Explained

int ...$nums — zero or more ints in an array
...$list at the call spreads elements as arguments
Mix fixed args with several spreads
Named extras land in the variadic with string keys
Spread a list of arrays into array_merge()

⚠ Common Mistakes

  • Putting a parameter after the variadic
  • Spreading an array with string keys into a function without those parameter names
  • Using func_get_args() and losing type checks

✓ Tips & Best Practices

  • Type variadic parameters
  • Use spread instead of call_user_func_array()
  • Prefer an explicit array parameter when callers already have an array

Quick Summary

  • ...$x in params collects
  • ...$x in calls spreads
  • Must be last
  • String keys → named args
