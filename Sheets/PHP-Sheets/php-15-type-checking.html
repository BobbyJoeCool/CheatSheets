Sheet 15

Type Checking

gettype() · get_debug_type() · is_int() · is_string() · is_numeric() · instanceof · TypeError

Finding Out What You Have

Use the is_*() family to test a value's type at runtime, instanceof for classes and interfaces, and get_debug_type() (PHP 8) for a readable name in error messages. Type declarations on parameters, returns and properties make the engine check for you and throw TypeError on a mismatch — prefer them over manual checks wherever you can.

Notes

  • gettype() returns legacy names like "double" and "NULL"
  • get_debug_type() returns "float", "null" and class names
  • is_numeric() accepts numeric strings like "1e3"
  • is_callable() and is_iterable() test capabilities
  • instanceof accepts a class name string on the right

Runtime Type Tests

<?php
$values = [42, 4.2, '42', true, null, [1], new DateTime()];

foreach ($values as $v) {
    echo str_pad(get_debug_type($v), 10), gettype($v), "\n";
}
// int       integer
// float     double
// string    string
// bool      boolean
// null      NULL
// array     array
// DateTime  object

is_numeric('1e3');               // true
is_numeric('0x1A');              // false
$d = new DateTime();
$d instanceof DateTimeInterface; // true

function area(float $r): float { return M_PI * $r ** 2; }
// area('big');  // TypeError: must be of type float

Code Explained

get_debug_type() gives the name you'd write in a type
gettype() uses old names — avoid for new code
is_numeric() is true for int/float and numeric strings
instanceof works with parent classes and interfaces
Typed parameters throw TypeError automatically

⚠ Common Mistakes

  • Checking gettype($x) == 'float' — it returns "double"
  • Using is_numeric() to validate an integer ID — it accepts "1.5"
  • Hand-written type checks where a type declaration would do

✓ Tips & Best Practices

  • Declare types; check manually only at system boundaries
  • Use get_debug_type() in exception messages
  • Check interfaces with instanceof, not class names

Quick Summary

  • is_*() for scalars
  • instanceof for objects
  • get_debug_type() for messages
  • Type declarations throw TypeError
