PHP History & Versions

Rasmus Lerdorf · Zend Engine · PHP 7 vs 8 · release cycle · RFCs · PHP-FIG

What PHP Is

PHP is a general-purpose scripting language built for the web. Rasmus Lerdorf released Personal Home Page Tools in 1995; today the name is the recursive PHP: Hypertext Preprocessor. The reference implementation runs on the Zend Engine, which compiles source to opcodes and executes them. PHP 7 roughly doubled performance over PHP 5; PHP 8 added a JIT, union types, match, attributes, enums and much more. New features arrive through public RFCs that core developers vote on.

Notes

  • One minor release every year, around late November
  • Each release gets 2 years of active support + 2 years of security fixes
  • There was no PHP 6 — the Unicode rewrite was abandoned
  • PHP-FIG publishes PSRs: shared standards for autoloading, logging, HTTP
  • Docs and changelogs live at php.net

Checking Your Version

<?php
echo PHP_VERSION;          // "8.5.0"
echo PHP_MAJOR_VERSION;    // 8
echo PHP_MINOR_VERSION;    // 5
echo PHP_OS_FAMILY;        // "Linux", "Darwin", "Windows"

if (version_compare(PHP_VERSION, '8.4.0', '<')) {
    exit('This script needs PHP 8.4 or newer');
}

// Feature check without a version number
if (function_exists('array_find')) {
    $first = array_find([1, 4, 9], fn($n) => $n > 3);
}

phpinfo();                 // full config page (dev only)

Code Explained

PHP_VERSION — full version string of the running engine
version_compare() — compares versions correctly (8.10 > 8.9)
function_exists() — test for a feature instead of a version
phpinfo() — prints build, extensions and ini values
Never leave phpinfo() reachable on a public server

⚠ Common Mistakes

  • Following tutorials written for PHP 5 — mysql_* functions and old idioms are gone
  • Running an end-of-life version in production — no security fixes
  • Checking PHP_VERSION with string comparison instead of version_compare()

✓ Tips & Best Practices

  • Target a supported version (8.3+) for new projects
  • Read the Migration appendix in the manual before upgrading
  • Pin the version in composer.json ("php": "^8.3")

Quick Summary

  • Zend Engine compiles to opcodes
  • Yearly releases, ~4 years of support
  • PHP 8 = modern typed language
  • Standards come from RFCs and PSRs
