Sheet 53

Searching Arrays

in_array() · array_search() · array_key_exists() · isset vs array_key_exists · array_find() · array_any() · array_all()

Finding Values and Keys

in_array() tells you whether a value exists; array_search() returns its key (or false). Both use loose comparison unless you pass true as the third argument — always do. For keys, isset() is fastest but treats null values as missing; array_key_exists() doesn't. PHP 8.4 added array_find(), array_find_key(), array_any() and array_all() for callback-based searches.

Notes

  • array_search() can return 0 — compare with !== false
  • Searching values is O(n); key lookups are O(1)
  • For many lookups, flip the list once: isset(array_flip($list)[$v])
  • array_keys($a, $v) returns every key holding $v
  • array_find() returns null when nothing matches

Search Functions

<?php
$ids = [10, 20, 30];
in_array('20', $ids);           // true  (loose)
in_array('20', $ids, true);     // false (strict)
array_search(30, $ids, true);   // 2
array_search(99, $ids, true);   // false

$cfg = ['debug' => null, 'env' => 'prod'];
isset($cfg['debug']);            // false (value is null)
array_key_exists('debug', $cfg); // true

$users = [
    ['id' => 1, 'name' => 'Ana', 'admin' => true],
    ['id' => 2, 'name' => 'Bo',  'admin' => false],
];
// PHP 8.4
$bo  = array_find($users, fn($u) => $u['name'] === 'Bo');
$key = array_find_key($users, fn($u) => $u['id'] === 2); // 1
array_any($users, fn($u) => $u['admin']);    // true
array_all($users, fn($u) => $u['admin']);    // false

$col = array_column($users, 'name', 'id');   // [1=>'Ana', 2=>'Bo']

Code Explained

Third argument true = strict comparison
array_search gives the key, not the value
isset ignores keys whose value is null
array_find returns the first matching element
array_column builds a lookup table for O(1) access

⚠ Common Mistakes

  • Loose in_array() — in_array('abc', [0]) was true in PHP 7
  • if (array_search(...)) when the match is at key 0
  • Using isset() on keys that may hold null

✓ Tips & Best Practices

  • Always pass true for strict search
  • Index data by key for repeated lookups
  • Use the 8.4 helpers instead of foreach + break

Quick Summary

  • in_array / array_search (strict!)

  • 8.4: array_find, array_any, array_all
  • Lookups by key are fastest
