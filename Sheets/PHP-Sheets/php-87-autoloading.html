Autoloading & PSR-4

spl_autoload_register() · PSR-4 mapping · classmap · vendor/autoload.php · composer dump-autoload

Loading Classes On Demand

Autoloading loads a class file the first time the class is used, so you never write require for classes. You register loaders with spl_autoload_register(); in practice Composer generates one for you. The PSR-4 standard maps a namespace prefix to a base directory: App\Models\User → src/Models/User.php. Run composer dump-autoload after changing the mapping.

Notes

  • Autoloaders run only for classes, interfaces, traits and enums — not functions
  • Load helper functions via Composer's files autoload
  • -o builds an optimised classmap for production
  • --classmap-authoritative skips filesystem checks entirely
  • class_exists($c, false) checks without autoloading

Composer PSR-4 and a Hand-Written Loader

// composer.json
{
    "autoload": {
        "psr-4": { "App\\": "src/" },
        "files": ["src/helpers.php"]
    },
    "autoload-dev": {
        "psr-4": { "Tests\\": "tests/" }
    }
}

<?php
// public/index.php
require __DIR__ . '/../vendor/autoload.php';
$user = new App\Models\User();   // loads src/Models/User.php

// What Composer does, simplified
spl_autoload_register(function (string $class): void {
    $prefix = 'App\\';
    if (!str_starts_with($class, $prefix)) return;
    $rel  = str_replace('\\', '/', substr($class, strlen($prefix)));
    $file = __DIR__ . "/src/$rel.php";
    if (is_file($file)) require $file;
});

Code Explained

Namespace prefix (escaped \\ in JSON) → folder
files always loads function helpers
autoload-dev maps test namespaces
One require of vendor/autoload.php is enough
A loader turns the class name into a file path

⚠ Common Mistakes

  • File name case differs from class name — works on macOS, fails on Linux
  • Forgetting dump-autoload after editing composer.json
  • Expecting functions to autoload

✓ Tips & Best Practices

  • Use Composer's autoloader everywhere
  • Optimise the classmap in production builds
  • Keep one class per file, named exactly like the class

Quick Summary
