Composer Basics

composer init · require · require --dev · composer.json · composer.lock · install vs update · ^ and ~ constraints

PHP's Package Manager

Composer installs libraries from Packagist into vendor/ and generates the autoloader. composer.json lists what you need with version constraints; composer.lock records the exact versions installed. composer install installs exactly what the lock file says (use it in CI and production); composer update resolves new versions within your constraints and rewrites the lock.

Notes

  • Commit composer.json and composer.lock for applications
  • Never commit vendor/
  • require-dev packages are skipped with --no-dev
  • Packages follow semantic versioning: MAJOR.MINOR.PATCH
  • composer outdated shows available upgrades

Everyday Commands

composer init                       # create composer.json
composer require guzzlehttp/guzzle  # add + install latest stable
composer require monolog/monolog:^3.5
composer require --dev phpunit/phpunit pestphp/pest
composer install                    # from composer.lock
composer install --no-dev -o        # production
composer update                     # newest allowed versions
composer update monolog/monolog     # just one package
composer remove guzzlehttp/guzzle
composer outdated --direct          # what's behind
composer show -t                    # dependency tree
composer validate                   # check composer.json

# composer.json (excerpt)
#  "require": {

Code Explained

require edits composer.json and installs
:^3.5 pins a constraint at install time
--dev for test and tooling packages
install follows the lock file exactly
php and ext-* declare platform requirements

⚠ Common Mistakes

  • Running composer update on production servers
  • Not committing composer.lock for an app
  • Using * constraints

✓ Tips & Best Practices

  • Use ^ constraints for libraries you depend on
  • Run composer audit in CI (Sheet 89)
  • Call tools via vendor/bin/…

Quick Summary

  • require adds packages
  • install = lock, update = resolve
  • Commit the lock file
  • ^ = compatible versions
