Sheet 73

Magic Methods — Property & Call Overloading

__get · __set · __isset · __unset · __call · __callStatic · __toString · __invoke

Intercepting Access

Magic methods start with __ and are called by PHP automatically. __get, __set, __isset and __unset fire when code touches inaccessible or undefined properties; __call and __callStatic fire for inaccessible or undefined methods. __toString() controls string conversion and __invoke() makes the object callable. They power proxies, fluent query builders and ORMs — but they hide behaviour from IDEs and static analysis.

Notes

  • Magic property methods don't fire for accessible properties
  • __toString() must return a string
  • Document magic members with @property / @method tags
  • Property hooks (8.4) replace most __get/__set uses
  • Magic calls are slower than real methods

Overloading Properties and Calls

<?php
/** @property string $title  @method string getTitle() */
class Record
{
    private array $data = [];

    public function __get(string $n): mixed
    { return $this->data[$n] ?? null; }

    public function __set(string $n, mixed $v): void
    { $this->data[$n] = $v; }

    public function __isset(string $n): bool
    { return isset($this->data[$n]); }

    public function __call(string $m, array $args): mixed
    {
        if (str_starts_with($m, 'get')) {
            return $this->{lcfirst(substr($m, 3))};
        }
        throw new BadMethodCallException("No method $m");
    }

    public function __toString(): string
    { return json_encode($this->data); }
}

$r = new Record();
$r->title = 'Hi';           // __set
echo $r->title;             // __get -> Hi
echo $r->getTitle();        // __call -> Hi
echo $r;                    // __toString -> {"title":"Hi"}

Code Explained

Docblock tags tell tools about magic members
Property methods route to an internal array
__isset keeps isset() and ?? working
__call receives the method name and arguments
echo $obj triggers __toString()

⚠ Common Mistakes

  • Forgetting __isset — isset() and ?? return false
  • Silently returning null for typos in __get
  • Expecting magic methods to fire for public properties

✓ Tips & Best Practices

  • Throw on unknown names instead of returning null
  • Add @property / @method docs for tooling
  • Use hooks or real methods when possible

Quick Summary

  • __get / __set / __isset / __unset
  • __call / __callStatic
  • __toString, __invoke
  • Use sparingly
