Classes and Instances

A class defines properties (data) and methods (behaviour); new creates an object from it. Use -> to reach an object's members and $this inside methods to refer to the current object. A variable holds a handle to the object, so assigning or passing it shares the same object — use clone for a copy. PHP 8.4 lets you call a method directly on new Foo() without wrapping it in parentheses.

Notes

  • One class per file, file named after the class (PSR-4)
  • Class names are case-insensitive but write them consistently
  • ClassName::class gives the fully qualified name as a string
  • Objects are destroyed when the last reference goes away
  • stdClass is the generic empty object (from (object) or json_decode)

Define, Create, Use

<?php
class Product
{
    public string $name;
    public float $price = 0.0;

    public function priceWithTax(float $rate = 0.2): float
    {
        return round($this->price * (1 + $rate), 2);
    }
}

$p = new Product();
$p->name = 'Mug';
$p->price = 8.5;
echo $p->priceWithTax();           // 10.2

$q = $p;                           // same object
$q->price = 10;
echo $p->price;                    // 10

$copy = clone $p;                  // independent copy
var_dump($p instanceof Product);   // true
echo Product::class;               // 'Product'

echo new Product()->priceWithTax(); // PHP 8.4: no extra ()

Code Explained

Typed properties with optional defaults
$this->price reads the current object's property
Assignment copies the handle, not the object
clone makes a shallow copy
PHP 8.4 allows member access right after new

⚠ Common Mistakes

  • Expecting $b = $a to copy an object
  • Using $this in a static method — Error
  • Accessing a typed property before it's set

✓ Tips & Best Practices

  • Initialise required data in the constructor (Sheet 64)
  • Keep properties private and expose methods
  • Prefer immutable objects where practical
