Array Destructuring

[$a, $b] = · list() · ['x' => $x] = · nested · swap · foreach destructuring

Unpacking Arrays into Variables

Destructuring assigns array elements to several variables at once. Use [$a, $b] = $arr for lists (or the older list($a, $b)), and ['key' => $var] = $arr for maps. You can skip positions, nest patterns, assign by reference and destructure directly in foreach. It's the natural way to receive multiple return values from a function.

Notes

  • Missing keys produce a Warning and null
  • You can't mix keyed and positional entries in one pattern
  • Skip elements with empty slots: [, $second] = $a
  • References: [&$a, $b] = $arr (7.3+)
  • Works with any array, not just lists

Destructuring Patterns

<?php
[$first, $second] = ['a', 'b'];
[, , $third] = [1, 2, 3];            // skip two

['name' => $name, 'age' => $age] = ['name' => 'Ana', 'age' => 30];

[$a, $b] = [1, 2];
[$a, $b] = [$b, $a];                 // swap: a=2, b=1

[[$x1, $y1], [$x2, $y2]] = [[0, 0], [3, 4]];    // nested

function stats(array $n): array {
    return ['min' => min($n), 'max' => max($n)];
}
['min' => $lo, 'max' => $hi] = stats([3, 9, 1]);

$points = [['x' => 1, 'y' => 2], ['x' => 3, 'y' => 4]];
foreach ($points as ['x' => $x, 'y' => $y]) {
    echo "($x, $y) ";
}

[$k, $v] = explode('=', 'color=red', 2);   // 'color', 'red'

Code Explained

Positional pattern matches keys 0, 1, …
Empty slots skip values
Keyed pattern can list keys in any order
Swap without a temp variable
explode + destructuring parses key=value pairs

⚠ Common Mistakes

  • Destructuring a map positionally — keys 0, 1 don't exist
  • Not passing a limit to explode before destructuring
  • Mixing [$a, 'k' => $b] in one pattern

✓ Tips & Best Practices

  • Return keyed arrays and destructure by name
  • Use destructuring in foreach over DB rows
  • Prefer small value objects for widely shared shapes

Quick Summary

  • [$a, $b] = $list
  • ['k' => $v] = $map
  • Skip, nest, swap
