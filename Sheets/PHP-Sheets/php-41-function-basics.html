Sheet 41

Defining & Calling Functions

function · return · case-insensitive names · function_exists() · conditional definitions · early return

Functions

function name(params): type { … } defines a named function. Top-level functions are hoisted: you can call them before the line that defines them in the same file. return sends a value back and ends the call; a function without return (or with a bare return;) gives null. Function names are global (within a namespace), case-insensitive, and can't be redeclared.

Notes

  • Functions defined inside if or another function exist only after that code runs
  • Return several values as an array and destructure them
  • void return type means "returns nothing"
  • never return type means "always throws or exits"
  • Built-in functions can't be redefined

Define, Call, Return

<?php
echo greet('Ana');                 // works: hoisted

function greet(string $name): string
{
    return "Hello, $name!";
}

function logLine(string $msg): void
{
    echo date('H:i'), " $msg\n";  // no return value
}

function minMax(array $nums): array
{
    if ($nums === []) {
        return [null, null];        // early return
    }
    return [min($nums), max($nums)];
}

[$lo, $hi] = minMax([4, 1, 9]);    // 1, 9

if (!function_exists('str_slug')) {
    function str_slug(string $s): string { return strtolower($s); }
}

Code Explained

Calling before the definition works for top-level functions
Return type after the colon
void functions can use bare return;
Return an array and destructure it at the call site
function_exists() guards optional helper definitions

⚠ Common Mistakes

  • Defining the same function twice (e.g. a file included twice) — fatal error
  • Echoing inside a function instead of returning the value
  • Relying on hoisting for functions declared inside if

✓ Tips & Best Practices

  • Give functions one job and a verb name
  • Declare parameter and return types
  • Use require_once or autoloaded classes to avoid redeclaration

Quick Summary

  • function f(): T { }
  • Top-level functions are hoisted
  • No return → null
  • Return arrays for several values
