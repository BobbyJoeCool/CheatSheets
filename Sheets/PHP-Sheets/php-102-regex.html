Pattern Matching with preg_*

PHP uses the PCRE2 engine through the preg_* functions. A pattern is a string wrapped in delimiters (usually /, or # / ~ when the pattern contains slashes), followed by modifier flags like i (case-insensitive) or u (UTF-8). preg_match() finds the first match and fills a $matches array; preg_match_all() finds every match; preg_replace() and preg_split() transform text. See the RegEx sheet set for syntax details.

Notes

  • Use single quotes so backslashes reach PCRE untouched
  • Always add u when working with UTF-8 text
  • preg_match returns 1, 0, or false on error
  • preg_quote($s, '/') escapes user input for a pattern
  • preg_last_error_msg() explains failures (8.0)

preg_* in Action

<?php
$log = '2026-10-08 ERROR [db] Timeout after 30s';

if (preg_match('/^(?<date>\d{4}-\d{2}-\d{2}) (?<lvl>\w+)/', $log, $m)) {
    echo $m['date'], ' ', $m['lvl'];          // 2026-10-08 ERROR
}

preg_match_all('/\d+/', 'a1 b22 c333', $all);
// $all[0] = ['1', '22', '333']

echo preg_replace('/\s+/', ' ', "too   many \n spaces");
echo preg_replace('#/+#', '/', 'a//b///c');   // a/b/c

echo preg_replace_callback('/\d+/',
    fn($m) => $m[0] * 2, 'x5 y10');           // x10 y20

preg_split('/[\s,]+/', 'a, b  c,d', -1, PREG_SPLIT_NO_EMPTY);
// ['a', 'b', 'c', 'd']

preg_match('/^\p{Lu}/u', 'Élan');             // 1 (Unicode upper)
$safe = '/' . preg_quote($userInput, '/') . '/i';
preg_grep('/^img_/', ['img_1', 'doc', 'img_2']);  // keeps img_*

Code Explained

Named groups (?<name>…) appear as keys in $m
preg_match_all fills arrays of all matches
# delimiter avoids escaping /
Callback receives the match array
u flag enables Unicode properties like \p{Lu}

⚠ Common Mistakes

  • Double-quoted patterns where PHP interprets \1 or $x first
  • Forgetting the u flag with accented text
  • Putting user input into a pattern without preg_quote()

✓ Tips & Best Practices

  • Prefer str_* functions for fixed strings
  • Use the x flag to comment complex patterns
  • Check for false and call preg_last_error_msg()
