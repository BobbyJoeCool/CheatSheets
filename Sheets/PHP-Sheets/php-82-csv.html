CSV

fgetcsv() · fputcsv() · str_getcsv() · escape parameter · SplFileObject::READ_CSV · UTF-8 BOM

Comma-Separated Values

fgetcsv() reads one CSV record from a stream and returns an array of fields, handling quotes and embedded commas and newlines. fputcsv() writes an array as a properly quoted line. str_getcsv() parses a single CSV string. For large files, read row by row. Since PHP 8.4, not passing the escape parameter is deprecated: pass escape: '' for RFC 4180 behaviour.

Notes

  • Default separator ,, enclosure "
  • A blank line returns [null]
  • Excel expects a UTF-8 BOM to detect encoding
  • Use ; as separator for many European Excel locales
  • Combine header row + array_combine() for keyed rows

Reading and Writing CSV

<?php
// Read with header row → associative arrays
$fh = fopen('users.csv', 'r');
$header = fgetcsv($fh, escape: '');
$rows = [];
while (($fields = fgetcsv($fh, escape: '')) !== false) {
    if ($fields === [null]) continue;        // blank line
    $rows[] = array_combine($header, $fields);
}
fclose($fh);

// Write
$out = fopen('export.csv', 'w');
fwrite($out, "\xEF\xBB\xBF");               // BOM for Excel
fputcsv($out, ['id', 'name', 'note'], escape: '');
fputcsv($out, [1, 'Ana', 'Says "hi", then leaves'], escape: '');
fclose($out);
// 1,Ana,"Says ""hi"", then leaves"

$fields = str_getcsv('a,"b,c",d', escape: '');   // ['a', 'b,c', 'd']

$file = new SplFileObject('users.csv');
$file->setFlags(SplFileObject::READ_CSV | SplFileObject::SKIP_EMPTY);
foreach ($file as $row) { /* … */ }

Code Explained

First row becomes the keys
escape: '' avoids the non-standard backslash escape
Blank lines come back as [null]
Quotes inside fields are doubled automatically
SplFileObject can iterate CSV directly

⚠ Common Mistakes

  • Splitting lines with explode(',') — breaks on quoted commas
  • Omitting escape (deprecated 8.4)
  • Exporting user data that starts with =, +, -, @ unescaped

✓ Tips & Best Practices

  • Always use the CSV functions, never explode
  • Stream large imports
  • Sanitise cells against spreadsheet formula injection

Quick Summary
