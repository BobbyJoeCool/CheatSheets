Iterators & Iterables

Iterator · IteratorAggregate · Traversable · ArrayIterator · iterable type · Countable

Making Objects Loopable

foreach works on arrays and on objects that implement **Traversable** — through either Iterator (you write current, key, next, rewind, valid) or IteratorAggregate (you return an iterator, often a generator, from getIterator()). IteratorAggregate + yield is almost always simpler. Add Countable for count() and ArrayAccess for $obj[...] syntax.

Notes

  • Traversable can't be implemented directly — use one of the two
  • The iterable type accepts arrays and Traversables
  • iterator_to_array() converts any Traversable to an array
  • iterator_count() counts by walking the iterator
  • SPL provides many ready iterators (filter, limit, caching)

IteratorAggregate with yield

<?php
class Playlist implements IteratorAggregate, Countable
{
    /** @var list<string> */
    private array $songs = [];

    public function add(string $song): static
    {
        $this->songs[] = $song;
        return $this;
    }

    public function getIterator(): Generator
    {
        foreach ($this->songs as $i => $song) {
            yield $i + 1 => $song;          // 1-based keys
        }
    }

    public function count(): int { return count($this->songs); }
}

$p = (new Playlist())->add('Intro')->add('Outro');
foreach ($p as $n => $song) echo "$n. $song\n";
echo count($p);                              // 2

$long = new CallbackFilterIterator(
    new ArrayIterator(['a', 'bbb', 'cc']),
    fn($s) => strlen($s) > 1,
);
iterator_to_array($long, false);             // ['bbb', 'cc']

Code Explained

IteratorAggregate needs only getIterator()
Returning a generator keeps the code short
Generators can set custom keys
Countable makes count($p) work
SPL iterators decorate other iterators lazily

⚠ Common Mistakes

  • Implementing Iterator by hand when a generator would do
  • Returning an array from getIterator() — must be Traversable
  • Iterating a generator-backed object twice when it's a one-shot generator

✓ Tips & Best Practices

  • Prefer IteratorAggregate + yield
  • Type parameters as iterable to accept both arrays and iterators
  • Use SPL iterators for lazy pipelines
