Sheet 18

String Functions — Search

strpos() · stripos() · str_contains() · str_starts_with() · str_ends_with() · strstr() · substr_count()

Finding Text

PHP 8 added three readable helpers — str_contains(), str_starts_with() and str_ends_with() — that return a plain bool. Use strpos() when you need the position: it returns the 0-based index or false, so always compare with !== false. The i variants (stripos, stristr) ignore ASCII case. strstr() returns the rest of the string from the match.

Notes

  • All of these are byte-based and case-sensitive unless noted
  • str_contains($s, '') is always true
  • Negative offsets search from the end (strpos($s, 'x', -5))
  • Use mb_strpos() when positions must be in characters
  • Use preg_match() for patterns (Sheet 102)

Search Functions

<?php
$s = 'The quick brown fox';

str_contains($s, 'quick');      // true
str_starts_with($s, 'The');     // true
str_ends_with($s, 'Fox');       // false (case)

strpos($s, 'quick');            // 4
strpos($s, 'The');              // 0  <- falsy!
strpos($s, 'cat');              // false
stripos($s, 'FOX');             // 16
strrpos('a-b-c', '-');          // 3 (last)

if (strpos($s, 'The') !== false) { /* found */ }

strstr('ana@example.com', '@');        // '@example.com'
strstr('ana@example.com', '@', true);  // 'ana'
strrchr('a/b/c.txt', '/');             // '/c.txt'
substr_count('banana', 'an');          // 2

Code Explained

str_* helpers return bool — no !== false dance
Position 0 is a real match but falsy
stripos() — case-insensitive strpos()
strstr(..., true) returns the part before the match
substr_count() doesn't count overlaps

⚠ Common Mistakes

  • if (strpos($s, 'x')) — fails when the match is at index 0
  • Using strpos + !== false when str_contains says it clearly
  • Expecting stripos to fold non-ASCII case — use mb_stripos

✓ Tips & Best Practices

  • Reach for str_contains / str_starts_with first
  • Always compare strpos() with !== false
  • Normalise case once with strtolower() for repeated checks

Quick Summary

  • str_contains / _starts_with / _ends_with
  • strpos() → index or false
  • i = case-insensitive
  • strstr() returns the tail
