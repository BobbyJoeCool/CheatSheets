Interfaces

interface · implements · multiple interfaces · interface constants · Stringable · ArrayAccess · Countable

Contracts

An interface lists public methods (and, since 8.4, hooked properties) that implementing classes must provide, without saying how. A class can implement many interfaces, and interfaces can extend several others. Type your parameters against interfaces rather than concrete classes so you can swap implementations in tests or later — this is the heart of dependency injection.

Notes

  • All interface methods are public
  • Interfaces may define constants (overridable since 8.1 unless final)
  • Any class with __toString() automatically implements Stringable
  • Built-ins: Countable, ArrayAccess, IteratorAggregate, JsonSerializable
  • Name by capability (Cache, Clock) or with an -able suffix

Defining and Implementing Interfaces

<?php
interface Cache
{
    public function get(string $key): mixed;
    public function set(string $key, mixed $v, int $ttl = 0): void;
}

final class ArrayCache implements Cache, Countable
{
    private array $items = [];

    public function get(string $key): mixed
    {
        return $this->items[$key] ?? null;
    }

    public function set(string $key, mixed $v, int $ttl = 0): void
    {
        $this->items[$key] = $v;
    }

    public function count(): int { return count($this->items); }
}

function warm(Cache $cache): void       // depends on the contract
{
    $cache->set('config', ['debug' => false]);
}

$c = new ArrayCache();
warm($c);
var_dump($c instanceof Cache, count($c));   // true, 1

⚠ Common Mistakes

  • Giant interfaces that force empty methods
  • Type-hinting concrete classes everywhere
  • Changing an interface signature without updating implementers

✓ Tips & Best Practices

  • Depend on interfaces, construct concretes at the edge
  • Keep interfaces focused on one role
  • Use PSR interfaces (logging, cache, HTTP) where they exist

Quick Summary

  • Public method contracts
  • Implement many
