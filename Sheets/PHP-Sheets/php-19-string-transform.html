Sheet 19

String Functions — Transform

strtoupper() · ucfirst() · ucwords() · trim() · str_replace() · str_repeat() · wordwrap()

Changing Strings

String functions never modify their argument — they return a new string, so assign the result. Case functions (strtoupper, ucfirst, …) are byte-based and ASCII-only since PHP 8.2; use mb_* for other alphabets. trim() removes whitespace (or chosen characters) from the ends. str_replace() replaces every occurrence and accepts arrays for many replacements at once.

Notes

  • str_replace() has a 4th by-reference $count argument
  • str_ireplace() ignores case
  • strtr($s, ['a' => 'b']) replaces longest keys first, in one pass
  • trim($s, '/') strips custom characters
  • nl2br() and strip_tags() are for HTML text

Transform Functions

<?php
$s = '  hello world  ';

trim($s);                    // 'hello world'
rtrim('path/', '/');         // 'path'
strtoupper('abc');           // 'ABC'
ucfirst('hello');            // 'Hello'
ucwords('hello big world');  // 'Hello Big World'
lcfirst('Hello');            // 'hello'

str_replace('world', 'PHP', 'hello world');   // 'hello PHP'
str_replace(['a', 'b'], ['1', '2'], 'abc');   // '12c'
str_replace('o', '0', 'foo boo', $n);         // $n = 4

strtr('Hi all', ['Hi' => 'Hello', 'all' => 'you']);
str_repeat('=-', 3);         // '=-=-=-'
strrev('abc');               // 'cba'
wordwrap('The quick brown fox', 10, "\n", true);

Code Explained

trim() default set: space, \t \n \r \0 \x0B
ucwords() uppercases the first letter of each word
Array search + array replace pair up by position
$n receives the replacement count
wordwrap(..., true) also breaks long words

⚠ Common Mistakes

  • Calling trim($s); without using the result
  • Chained str_replace calls that re-replace earlier output — use strtr
  • strtoupper('é') — unchanged; use mb_strtoupper

✓ Tips & Best Practices

  • Assign the result: $s = trim($s);
  • Use strtr() with an array for template-style swaps
  • Use mb_* functions for user-facing text

Quick Summary

  • Functions return new strings
  • trim / case functions
  • str_replace / strtr
  • mb_* for non-ASCII
