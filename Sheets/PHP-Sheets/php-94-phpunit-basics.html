Unit Testing with PHPUnit

PHPUnit is the standard PHP test framework. A test class extends PHPUnit\Framework\TestCase; each public method whose name starts with test (or has the #[Test] attribute) is a test. Assertions such as assertSame() compare expected and actual values. setUp() runs before every test for shared fixtures. Configure suites and coverage in phpunit.xml and run vendor/bin/phpunit.

Notes

  • Install per project: composer require --dev phpunit/phpunit
  • Test class names end in Test; files mirror src/
  • Each test runs on a fresh instance of the test class
  • PHPUnit 10+ uses attributes instead of docblock annotations
  • Arrange · Act · Assert keeps tests readable

A Test Class

<?php
namespace Tests\Unit;

use App\Cart;
use PHPUnit\Framework\TestCase;
use PHPUnit\Framework\Attributes\Test;

final class CartTest extends TestCase
{
    private Cart $cart;

    protected function setUp(): void
    { $this->cart = new Cart(); }

    public function testStartsEmpty(): void
    { $this->assertSame(0, $this->cart->count()); }

    #[Test]
    public function it_totals_items(): void
    {
        $this->cart->add('mug', 2, 8.50);
        $this->assertSame(17.0, $this->cart->total());
    }

    public function testRejectsNegativeQty(): void
    {
        $this->expectException(\InvalidArgumentException::class);
        $this->cart->add('mug', -1, 8.50);
    }
}

Code Explained

Extend TestCase; one class per unit under test
setUp() creates a fresh cart before each test
assertSame checks type and value (===)
#[Test] marks methods not named test…
expectException must come before the failing call

⚠ Common Mistakes

  • assertEquals where assertSame is needed — '1' == 1 passes
  • Tests depending on each other's state or order
  • Calling expectException after the code that throws

✓ Tips & Best Practices

  • Prefer assertSame by default
  • One behaviour per test, named after the behaviour
  • Run tests in CI on every push

Quick Summary

  • Extend TestCase
  • test* methods or #[Test]
  • assertSame & friends
  • setUp() for fixtures
