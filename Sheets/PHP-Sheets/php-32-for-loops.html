Counting Loops

for (init; condition; step) runs the init once, checks the condition before each pass, and runs the step after each pass. Use it when you need an index or counter; for walking arrays, foreach (Sheet 33) is simpler and works with any keys. Each section can hold several comma-separated expressions, and any section may be empty.

Notes

  • for (;;) is an infinite loop — exit with break
  • The condition is re-evaluated every iteration
  • Store count($arr) in a variable before looping
  • Loop variables stay defined after the loop ends
  • Alternative syntax: for (...): … endfor;

for Loop Patterns

<?php
for ($i = 1; $i <= 5; $i++) {
    echo $i, ' ';                    // 1 2 3 4 5
}

for ($i = 10; $i > 0; $i -= 3) {
    echo $i, ' ';                    // 10 7 4 1
}

$items = ['a', 'b', 'c'];
for ($i = 0, $n = count($items); $i < $n; $i++) {
    echo "$i: {$items[$i]}\n";
}

for ($i = 0, $j = 9; $i < $j; $i++, $j--) {
    // two counters moving toward each other
}

for ($row = 1; $row <= 3; $row++) {
    for ($col = 1; $col <= 3; $col++) {
        echo $row * $col, "\t";
    }
    echo "\n";                       // multiplication grid
}
echo $i;                             // still defined

Code Explained

Init $i = 1, test $i <= 5, step $i++
Steps can be any expression, like $i -= 3
$n = count(...) runs once, not every pass
Comma-separated expressions in init and step
Nested loops: inner runs fully per outer pass

⚠ Common Mistakes

  • $i <= count($a) — off by one, reads past the end
  • Calling count() in the condition of a huge loop
  • Using for with index access on arrays that aren't 0-indexed lists

✓ Tips & Best Practices

  • Prefer foreach for arrays
  • Hoist expensive calls out of the condition
  • Give nested loop counters meaningful names

Quick Summary

  • for (init; cond; step)
  • Use for counters and steps
  • Hoist count()
  • foreach for arrays
