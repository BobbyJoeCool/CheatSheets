What Arrived When

PHP 8 transformed the language with a steady stream of features. Use this sheet to check whether a feature is available on the version you deploy to, and to spot modern replacements for older idioms. Each release also deprecates older behaviour — read the migration guide on php.net before upgrading, and let tools like Rector and PHPStan do the mechanical work.

Notes

  • Releases land each year around late November
  • Check your floor with "php": "^8.3" in composer.json
  • Rector withPhpSets() upgrades syntax automatically
  • PHP_VERSION_ID (e.g. 80400) for numeric checks
  • Sheet numbers in parentheses point to the details

Modern PHP in One Snippet

<?php
// 8.1 enum
enum Status: string { case Active = 'a'; case Banned = 'b'; }

// 8.2 readonly class + 8.0 constructor promotion
final readonly class User
{
    public function __construct(
        public int $id,
        public string $email,
        public Status $status = Status::Active,
    ) {}
}

// 8.0 match (exhaustive with enums)
function label(User $u): string
{
    return match ($u->status) {
        Status::Active => 'ok',
        Status::Banned => 'blocked',
    };
}

$u = new User(id: 1, email: 'ana@x.io');     // 8.0 named args
echo $u?->email ?? 'none';                   // 8.0 nullsafe
$len = strlen(...);                          // 8.1 callable
json_validate('{"a":1}');                    // 8.3
$big = array_find([3, 8], fn($n) => $n > 5); // 8.4
$s = ' Hi ' |> trim(...) |> strtolower(...); // 8.5 pipe

Code Explained

Enums and readonly replace constant classes and getters
Constructor promotion + named args cut boilerplate
match + enums give exhaustive branching
First-class callables and the pipe compose functions
Array helpers in 8.4 replace common loops
