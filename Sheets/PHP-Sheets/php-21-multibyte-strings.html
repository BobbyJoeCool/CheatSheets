Multibyte Strings & UTF-8

mbstring · mb_strlen() · mb_substr() · mb_strtoupper() · mb_str_pad() · bytes vs characters · iconv()

UTF-8 Text

Core string functions count bytes. In UTF-8 a character takes 1–4 bytes, so strlen('café') is 5. The mbstring extension provides character-aware versions: mb_strlen, mb_substr, mb_strtoupper and friends. Set the internal encoding to UTF-8 (the default since PHP 5.6) and use mb_* for anything a human reads. The intl extension adds normalisation, transliteration and grapheme functions.

Notes

  • mb_str_pad() arrived in PHP 8.3
  • mb_trim(), mb_ucfirst(), mb_lcfirst() arrived in PHP 8.4
  • mb_check_encoding($s, 'UTF-8') validates input
  • Emoji with modifiers are several code points — use grapheme_strlen()
  • Save source files as UTF-8 without BOM

Bytes vs Characters

<?php
$s = 'Café über';

strlen($s);                  // 11 (bytes)
mb_strlen($s);               // 9  (characters)
substr($s, 0, 4);            // 'Caf' + half of é (broken)
mb_substr($s, 0, 4);         // 'Café'
strtoupper($s);              // 'CAFé üBER' (ASCII only)
mb_strtoupper($s);           // 'CAFÉ ÜBER'
mb_str_pad('né', 5, '*');    // 'né***' (8.3+)
mb_str_split('añb');         // ['a', 'ñ', 'b']

mb_check_encoding($input, 'UTF-8');   // validate
mb_convert_encoding($latin1, 'UTF-8', 'ISO-8859-1');

$e = "👍🏽";
mb_strlen($e);               // 2 (code points)
grapheme_strlen($e);         // 1 (what users see)

Code Explained

é and ü are 2 bytes each in UTF-8
substr() can cut a character in half
strtoupper() ignores non-ASCII letters (PHP 8.2+)
mb_convert_encoding() converts legacy text
grapheme_* (intl) counts user-visible characters

⚠ Common Mistakes

  • Truncating names with substr() — produces invalid UTF-8
  • Assuming strlen() is a character count for validation rules
  • Mixing encodings in one database

✓ Tips & Best Practices

  • Use mb_* for all user-visible text
  • Validate incoming text with mb_check_encoding()
  • Use UTF-8 (utf8mb4) end to end: files, DB, HTTP headers

Quick Summary

  • Core functions count bytes
  • mb_* counts characters
  • intl grapheme_* for emoji
  • UTF-8 everywhere
