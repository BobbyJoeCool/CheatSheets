Sheet 03

Running PHP

php script.php · php -a · php -r · php -S · php-fpm · mod_php · shebang

Ways to Run Code

PHP runs through a SAPI (Server API). The CLI runs scripts from a terminal and is used for tools, cron jobs and tests. For the web, PHP-FPM runs a pool of worker processes behind nginx or Apache; mod_php embeds PHP inside Apache. During development the built-in server (php -S) serves a folder with no web server at all. Every request starts with a fresh state.

Notes

  • CLI has no execution time limit by default
  • php -S is single-process — never use it in production
  • A router script handles every request (php -S host:port router.php)
  • PHP_SAPI tells you which SAPI is running
  • php -l file.php checks syntax without running

CLI, REPL & Built-in Server

php hello.php              # run a script
php hello.php Ana 42       # args land in $argv
php -r 'echo 2 ** 10;'     # inline code -> 1024
php -a                     # interactive shell
php -l src/User.php        # lint (syntax check)

php -S localhost:8000          # serve current folder
php -S localhost:8000 -t public  # docroot = public/
php -S 0.0.0.0:8000 router.php   # every request -> router

# Executable script (chmod +x tool.php)
#!/usr/bin/env php
<?php
echo "Running under " . PHP_SAPI . PHP_EOL;  // cli

Code Explained

$argv[0] is the script name; arguments follow
-a — REPL; end statements with ;
-t public — expose only the public folder
router.php returns false to serve static files as-is
Shebang line lets you run ./tool.php directly

⚠ Common Mistakes

  • Deploying with php -S — it handles one request at a time
  • Writing <?php in php -r code — it's a syntax error there
  • Expecting variables to persist between web requests

✓ Tips & Best Practices

  • Use php -l in a pre-commit hook
  • Pass -t public so config files are never served
  • Check PHP_SAPI === 'cli' before running CLI-only code

Quick Summary

  • CLI for scripts, FPM for the web
  • php -S for quick local serving
  • -r inline, -a REPL, -l lint
  • Each request starts fresh
