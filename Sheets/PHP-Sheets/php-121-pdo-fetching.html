PDO — Fetching Results

fetch() · fetchAll() · fetchColumn() · FETCH_ASSOC · FETCH_OBJ · FETCH_CLASS · FETCH_KEY_PAIR · lastInsertId()

Getting Rows Back

After execute(), read results with fetch() (one row at a time, false when done), fetchAll() (every row in an array) or fetchColumn() (one value). The fetch mode decides the shape: associative arrays, objects, instances of your own class, key-value pairs or grouped arrays. A statement is also iterable with foreach, which streams rows without loading them all.

Notes

  • fetch() returns false when no row matches
  • fetchAll() loads everything into memory
  • FETCH_CLASS sets properties before the constructor runs
  • Numbers may come back as strings depending on driver/settings
  • query() is fine for SQL with no variables

Fetch Modes in Practice

<?php
$stmt = $pdo->prepare(
    'SELECT id, name, email FROM users WHERE active = ?');
$stmt->execute([1]);

$row  = $stmt->fetch();                        // first row (assoc)
$rows = $stmt->fetchAll();                     // remaining rows

$count = $pdo->query('SELECT COUNT(*) FROM users')->fetchColumn();

foreach ($pdo->query('SELECT id, name FROM users') as $r) {
    echo $r['name'];                           // streams rows
}

$names = $pdo->query('SELECT id, name FROM users')
             ->fetchAll(PDO::FETCH_KEY_PAIR);  // [1 => 'Ana', …]
$emails = $pdo->query('SELECT email FROM users')
              ->fetchAll(PDO::FETCH_COLUMN);   // ['a@x', …]
$byRole = $pdo->query('SELECT role, name FROM users')
              ->fetchAll(PDO::FETCH_GROUP | PDO::FETCH_COLUMN);
// ['admin' => ['Ana'], 'user' => ['Bo', 'Cy']]

final class UserRow { public int $id; public string $name; }
$stmt = $pdo->query('SELECT id, name FROM users');
$users = $stmt->fetchAll(PDO::FETCH_CLASS, UserRow::class);

$one = $pdo->prepare('SELECT * FROM users WHERE id = ?');
$one->execute([$id]);
$user = $one->fetch() ?: throw new RuntimeException('Not found');

Code Explained

Default mode from the connection: FETCH_ASSOC
fetchColumn() → single scalar
Iterating the statement streams rows
KEY_PAIR builds id → name maps
fetch() ?: throw handles missing rows

⚠ Common Mistakes

  • fetchAll() on millions of rows
  • Treating false from fetch() as an empty array
  • Expecting FETCH_CLASS to call the constructor first

✓ Tips & Best Practices

  • Stream big results with foreach
  • Use KEY_PAIR / COLUMN to skip manual loops
  • Map rows to DTOs for type safety

Quick Summary

  • fetch / fetchAll / fetchColumn
  • Modes shape each row
  • foreach streams
  • false = no row
