Errors vs Exceptions

E_WARNING · E_NOTICE · E_DEPRECATED · error_reporting() · display_errors · Throwable · Error vs Exception

Two Error Systems

PHP reports problems in two ways. Diagnostics (warnings, notices, deprecations) are messages with a level such as E_WARNING; by default execution continues. Throwables interrupt execution until caught. Throwable has two branches: Exception for conditions your code expects to handle, and Error for engine failures such as TypeError, ValueError and calling an undefined function.

Notes

  • Uncaught throwables become a "Fatal error: Uncaught …"
  • Many PHP 7 fatal errors became catchable Errors in PHP 8
  • display_errors controls output; log_errors writes to the log
  • Development: E_ALL + display on; production: log only
  • Catch Throwable only at the top level of an app

Levels and Hierarchy

<?php
error_reporting(E_ALL);               // report everything
ini_set('display_errors', '1');       // dev only

echo $undefined;        // Warning: Undefined variable
$arr = [];
echo $arr['x'];         // Warning: Undefined array key
strlen();               // ArgumentCountError (an Error)

try {
    intdiv(1, 0);
} catch (DivisionByZeroError $e) {
    echo get_class($e), ': ', $e->getMessage(), "\n";
}

try {
    new DateTime('not a date');
} catch (Exception $e) {
    echo 'Exception: ', $e->getMessage(), "\n";
}

try {
    undefined_function();
} catch (Error $e) {
    echo 'Engine error: ', $e->getMessage();
}

Code Explained

E_ALL includes notices and deprecations
Undefined variables/keys are Warnings in PHP 8
Wrong argument count throws, it doesn't warn
DivisionByZeroError extends ArithmeticError → Error
Calling an unknown function throws Error

⚠ Common Mistakes

  • Hiding warnings instead of fixing them
  • Showing errors to visitors in production
  • Catching Exception and missing TypeError (it's an Error)

✓ Tips & Best Practices

  • Develop with E_ALL and display on
  • Convert warnings to exceptions with an error handler (Sheet 40)
  • Log everything in production
