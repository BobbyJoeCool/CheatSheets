File Paths & File Info

__DIR__ · realpath() · basename() · dirname() · pathinfo() · DIRECTORY_SEPARATOR · file_exists()

Working with Paths

Relative paths in PHP resolve against the current working directory, which differs between the CLI and web servers — so build paths from __DIR__. pathinfo(), basename() and dirname() split paths into parts; realpath() resolves .. and symlinks and returns false if the path doesn't exist. Status functions like file_exists(), is_file() and filesize() answer questions about a path.

Notes

  • / works as a separator on Windows too
  • dirname($p, 2) goes up two levels
  • Stat results are cached — call clearstatcache() after changes
  • realpath() is the basis of path-traversal checks
  • sys_get_temp_dir() gives the temp folder

Path Functions

<?php
$path = '/var/www/app/public/img/logo.final.png';

basename($path);                 // logo.final.png
basename($path, '.png');         // logo.final
dirname($path);                  // /var/www/app/public/img
dirname($path, 2);               // /var/www/app/public
pathinfo($path, PATHINFO_EXTENSION);  // png
pathinfo($path);
// ['dirname' => …, 'basename' => 'logo.final.png',
//  'extension' => 'png', 'filename' => 'logo.final']

$config = __DIR__ . '/../config/app.php';   // stable
realpath($config);               // /var/www/app/config/app.php

// Path traversal guard
$base = realpath(__DIR__ . '/uploads');
$full = realpath($base . '/' . $_GET['file']);
$inBase = $full !== false
    && str_starts_with($full, $base . DIRECTORY_SEPARATOR);
if (!$inBase) {
    http_response_code(403); exit;
}

is_file($full) && filesize($full);   // bytes
date('Y-m-d', filemtime($full));     // last modified

Code Explained

basename with a suffix strips it
dirname($p, n) climbs n levels
filename excludes only the last extension
__DIR__ keeps paths independent of the working directory
Compare resolved path against the allowed base

⚠ Common Mistakes

  • Relative includes that break when run from another directory
  • Trusting pathinfo() extension for security
  • Concatenating user input into paths without realpath() checks

✓ Tips & Best Practices

  • Build every path from __DIR__
  • Validate uploads by content, not extension
  • Use a filesystem library (Flysystem) for cloud storage

Quick Summary

  • __DIR__ for stable paths
  • basename / dirname / pathinfo
  • realpath for safety
  • is_file, filesize, filemtime
