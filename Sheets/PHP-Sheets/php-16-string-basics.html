Strings

A PHP string is a sequence of bytes, not characters — strlen() counts bytes (Sheet 21 covers UTF-8). Single quotes are literal: only \' and \\ are escapes. Double quotes expand variables and escape sequences like \n. Heredoc (<<<EOT) behaves like double quotes over many lines; nowdoc (<<<'EOT') behaves like single quotes. Join strings with the . operator.

Notes

  • Strings are mutable values but copied on assignment
  • Wrap complex expressions in braces: "{$user->name}"
  • Array keys in strings: "$row[id]" or "{$row['id']}"
  • Closing heredoc marker may be indented (7.3+); that indentation is stripped
  • "${var}" interpolation is deprecated in 8.2 — use {$var}

Quotes, Interpolation & Heredoc

<?php
$name = 'Ana';
$user = ['id' => 7];
$cart = new stdClass();
$cart->total = 9.5;

echo 'Hi $name\n';          // Hi $name\n (literal)
echo "Hi $name\n";          // Hi Ana + newline
echo "ID: {$user['id']}";   // ID: 7
echo "Total: {$cart->total}";
echo 'Hi ' . $name . '!';   // concatenation

$html = <<<HTML
    <p>Hello, {$name}</p>
    <p>Items: {$user['id']}</p>
    HTML;                    // indent removed

$raw = <<<'SQL'
    SELECT * FROM t WHERE x = '$notVar'
    SQL;

Code Explained

Single quotes print $name and \n as typed
Braces make array/property access unambiguous
. joins; .= appends ($s .= 'x')
Heredoc interpolates; closing marker sets the indent
Nowdoc never interpolates — good for SQL and templates

Interpolation Forms

SyntaxUse
"$var"Simple variable
"$arr[key]"Unquoted key, simple
"{$arr['key']}"Quoted key
"{$obj->a->b}"Chained props
"{$obj->m()}"Method call
"${var}"Deprecated (8.2)

⚠ Common Mistakes

  • '\n' in single quotes — prints backslash-n
  • Using + to join strings — that's numeric addition
  • Backticks as quotes — they execute a shell command

✓ Tips & Best Practices

  • Use single quotes when nothing needs interpolating
  • Always use {$...} braces for anything beyond a plain variable
  • Use nowdoc for SQL or code snippets

Quick Summary

  • '…' literal, "…" interpolates
  • . concatenates
  • Heredoc / nowdoc for blocks
  • Strings are bytes
