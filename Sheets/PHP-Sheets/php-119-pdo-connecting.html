PDO — Connecting

new PDO() · DSN strings · ERRMODE_EXCEPTION · DEFAULT_FETCH_MODE · utf8mb4 · driver-specific subclasses (8.4)

One API, Many Databases

PDO (PHP Data Objects) is the standard database layer: the same methods work with MySQL/MariaDB, PostgreSQL, SQLite, SQL Server and more, chosen by the DSN string. Create one connection per request with sensible attributes: throw exceptions on errors, fetch associative arrays by default, and use real prepared statements. Keep credentials in environment variables. PHP 8.4 adds driver subclasses such as Pdo\Mysql and the PDO::connect() factory.

Notes

  • Since PHP 8.0, ERRMODE_EXCEPTION is the default
  • Use charset=utf8mb4 in MySQL DSNs for full Unicode
  • ATTR_EMULATE_PREPARES => false uses native prepares
  • Connection closes when the PDO object is destroyed
  • Install drivers: pdo_mysql, pdo_pgsql, pdo_sqlite

Creating a Connection

<?php
$dsn = sprintf('mysql:host=%s;port=%d;dbname=%s;charset=utf8mb4',
    getenv('DB_HOST'), getenv('DB_PORT') ?: 3306, getenv('DB_NAME'));

try {
    $pdo = new PDO($dsn, getenv('DB_USER'), getenv('DB_PASS'), [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES   => false,
    ]);
} catch (PDOException $e) {
    error_log($e->getMessage());               // never echo it
    throw new RuntimeException('Database unavailable');
}

$pg   = new PDO('pgsql:host=db;dbname=shop', 'app', $pw);
$lite = new PDO('sqlite:' . __DIR__ . '/data.db');
$mem  = new PDO('sqlite::memory:');            // tests

// PHP 8.4: driver-specific class
$db = PDO::connect('sqlite::memory:');         // Pdo\Sqlite

Code Explained

DSN = driver prefix + parameters
Exceptions on any SQL error
Rows come back as associative arrays
Native prepares send parameters separately
Messages can contain credentials — log, don't display

⚠ Common Mistakes

  • Echoing PDOException messages to users
  • Missing charset — mojibake and encoding bugs
  • Opening a new connection per query

✓ Tips & Best Practices

  • Create the PDO in one factory or container service
  • Use SQLite in-memory for fast tests
  • Keep credentials in env vars or a secrets manager

Quick Summary

  • new PDO($dsn, $user, $pass, $opts)
  • Exceptions + FETCH_ASSOC
  • utf8mb4 for MySQL
  • Never show connection errors
