foreach Loops

foreach as $v · $k => $v · by reference &$v · unset after reference · destructuring · endforeach

Walking Arrays and Iterables

foreach visits every element of an array or Traversable object (iterators, generators) in order. as $v gives values; as $k => $v gives keys too. It works on a copy of the array, so changing $v doesn't change the array — iterate by reference (&$v) for in-place edits, then unset($v). You can destructure each element directly in the loop header.

Notes

  • Order is insertion order, not key order
  • Iterating a non-iterable gives a Warning
  • Adding elements during a by-value loop doesn't affect it
  • foreach over an object without Iterator walks public properties
  • Alternative syntax: foreach (...): … endforeach;

foreach Patterns

<?php
$prices = ['tea' => 3, 'cake' => 5];

foreach ($prices as $price) {
    echo $price, ' ';                    // 3 5
}

foreach ($prices as $item => $price) {
    echo "$item costs $price\n";
}

foreach ($prices as &$price) {           // by reference
    $price *= 2;
}
unset($price);                           // break the reference!
// $prices = ['tea' => 6, 'cake' => 10]

$users = [['id' => 1, 'name' => 'Ana'], ['id' => 2, 'name' => 'Bo']];
foreach ($users as ['id' => $id, 'name' => $name]) {
    echo "$id: $name\n";                 // destructuring
}

foreach ([[1, 2], [3, 4]] as [$x, $y]) {
    echo $x + $y, ' ';                   // 3 7
}

Code Explained

Value-only form when keys don't matter
$k => $v exposes the key
&$price writes back into the array
unset($price) prevents the classic dangling-reference bug
Keyed and list destructuring work in the header

⚠ Common Mistakes

  • Skipping unset($v) after a reference loop
  • Modifying $v and expecting the array to change
  • Looping over null from a failed lookup

✓ Tips & Best Practices

  • Prefer array_map / array_filter for pure transforms
  • Use destructuring for rows from a database
  • Guard with ?? [] when the array may be missing

Quick Summary

  • as $v / as $k => $v
  • By-value copy by default
  • &$v + unset($v)
