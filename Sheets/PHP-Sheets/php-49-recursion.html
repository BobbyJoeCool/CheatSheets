Functions That Call Themselves

A recursive function solves a problem by calling itself on a smaller part of it. Every recursive function needs a base case that returns without recursing. Recursion fits naturally on trees: nested arrays, directories, menus, JSON. PHP has no tail-call optimisation and no fixed recursion limit — very deep recursion exhausts memory — so convert deep or unbounded recursion into a loop with an explicit stack.

Notes

  • Xdebug limits nesting with xdebug.max_nesting_level
  • Recursive closures need use (&$fn) or static fn via a variable
  • Memoise repeated sub-results with a static array
  • SPL RecursiveIteratorIterator walks trees without recursion in your code
  • Generators with yield from make lazy recursive walks

Recursive Patterns

<?php
function factorial(int $n): int
{
    return $n <= 1 ? 1 : $n * factorial($n - 1);  // base case
}

function fib(int $n): int
{
    static $memo = [];
    if ($n < 2) return $n;
    return $memo[$n] ??= fib($n - 1) + fib($n - 2);
}
fib(90);                          // fast thanks to $memo

function flatten(array $a): array
{
    $out = [];
    foreach ($a as $v) {
        if (is_array($v)) array_push($out, ...flatten($v));
        else $out[] = $v;
    }
    return $out;
}
flatten([1, [2, [3, [4]]]]);      // [1, 2, 3, 4]

$walk = function (array $tree, int $d = 0) use (&$walk) {
    foreach ($tree as $k => $sub) {
        echo str_repeat('  ', $d), $k, "\n";
        $walk($sub, $d + 1);
    }
};

Code Explained

Base case $n <= 1 stops the recursion
static $memo caches results across calls
??= computes each value once
Spread the recursive result into the output
A closure refers to itself through use (&$walk)

⚠ Common Mistakes

  • Missing or unreachable base case — runs out of memory
  • Exponential recursion like naive fib() without memoisation
  • Recursing over user-supplied deep data without a depth limit

✓ Tips & Best Practices

  • Write the base case first
  • Use SPL recursive iterators for trees
  • Add a $maxDepth parameter for untrusted input

Quick Summary

  • Base case + smaller step
  • No tail-call optimisation
  • Memoise with static
  • Use iterators/loops for deep data
