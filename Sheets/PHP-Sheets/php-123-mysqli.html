MySQLi

new mysqli() · prepare() · bind_param() · get_result() · procedural vs OO · mysqli_report()

The MySQL-Specific Extension

MySQLi (MySQL improved) is an alternative to PDO that works only with MySQL and MariaDB. It offers both an object-oriented and a procedural API, supports prepared statements with bind_param(), and exposes MySQL-specific features such as multi-queries and async queries. Since PHP 8.1, errors throw mysqli_sql_exception by default. New projects usually prefer PDO for its portability and named placeholders.

Notes

  • bind_param type string: i int, d double, s string, b blob
  • get_result() needs the mysqlnd driver (standard today)
  • 8.2 added execute_query() — prepare + bind + execute in one
  • The old mysql_* functions were removed in PHP 7
  • Set the charset with set_charset('utf8mb4')

MySQLi Object-Oriented Style

<?php
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);   // throw

$db = new mysqli('localhost', 'app', $password, 'shop');
$db->set_charset('utf8mb4');

$stmt = $db->prepare(
    'SELECT id, name FROM products WHERE price < ? AND cat = ?');
$stmt->bind_param('ds', $maxPrice, $category);   // double, string
$stmt->execute();
$result = $stmt->get_result();
while ($row = $result->fetch_assoc()) {
    echo $row['name'], "\n";
}

// PHP 8.2+: one call
$rows = $db->execute_query(
    'SELECT * FROM orders WHERE user_id = ?', [$userId]
)->fetch_all(MYSQLI_ASSOC);

$db->query("INSERT INTO log (msg) VALUES ('started')");
echo $db->insert_id, ' ', $db->affected_rows;

// Procedural equivalent
$link = mysqli_connect('localhost', 'app', $password, 'shop');
$res  = mysqli_query($link, 'SELECT COUNT(*) AS n FROM products');
echo mysqli_fetch_assoc($res)['n'];

Code Explained

Make MySQLi throw exceptions (default since 8.1)
Always set utf8mb4
'ds' — one type letter per placeholder
execute_query() shortens the common case
Procedural functions take the link as first argument

⚠ Common Mistakes

✓ Tips & Best Practices

  • Enable strict error reporting
