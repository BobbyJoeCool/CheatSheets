Sheet 05

echo, print & Output

echo · print · multiple args · short echo tag · PHP_EOL · output buffering ob_start()

Sending Output

echo and print are language constructs, not functions, so parentheses are optional. echo takes one or more comma-separated arguments and returns nothing; print takes exactly one and returns 1. In a web request the output becomes the response body; on the CLI it goes to STDOUT. Output buffering (ob_start()) captures output into a string instead of sending it.

Notes

  • echo is slightly faster and far more common
  • Comma-separated echo a, b avoids building a joined string
  • PHP_EOL = newline for the current OS
  • Use "\n" for web output; HTML ignores newlines anyway
  • printf() / sprintf() format output (see Sheet 17)

Printing Values

<?php
$name = 'Ana';
$n = 3;

echo 'Hello';                    // Hello
echo 'Hi ', $name, PHP_EOL;      // Hi Ana + newline
echo "You have $n messages\n";   // interpolation
print "Done\n";                  // print returns 1

echo 'Sum: ' . (2 + 3) . "\n";   // parens around math

// Capture output into a string
ob_start();
echo '<p>Buffered</p>';
$html = ob_get_clean();          // '<p>Buffered</p>'

fwrite(STDERR, "warning\n");     // CLI error stream

Code Explained

Commas pass several arguments to echo
Double quotes interpolate $n; single quotes don't
(2 + 3) — parens make the order obvious; PHP 8 ranks + above .
ob_get_clean() returns the buffer and stops buffering
STDERR — constant stream, CLI only

⚠ Common Mistakes

  • echo '\n' — single quotes print backslash-n literally
  • Echoing before header() or session_start() — headers already sent
  • Echoing user input without htmlspecialchars() — XSS

✓ Tips & Best Practices

  • Prefer echo with commas for several values
  • Use output buffering to render templates into strings
  • Escape everything you echo into HTML

Quick Summary

  • echo a, b — many args
  • print x — one arg, returns 1
  • ob_start() / ob_get_clean() capture
  • Escape HTML output
