Sheet 48

Callables & First-Class Callables

callable type · 'strlen' · [$obj, 'method'] · strlen(...) · is_callable() · call_user_func() · __invoke

Things You Can Call

A callable is any value PHP can call: a function name string, a closure, an [object, 'method'] or [Class::class, 'staticMethod'] array, a 'Class::method' string, or an object with __invoke(). PHP 8.1's first-class callable syntax strlen(...) or $obj->method(...) creates a Closure directly, with IDE and static-analysis support — prefer it over strings and arrays.

Notes

  • callable can be used as a parameter type, not a property type
  • String and array callables break silently when renamed — (...) doesn't
  • (...) keeps the original scope, so private methods work
  • is_callable() checks before calling
  • Call any callable directly: $f(…)

Callable Forms

<?php
class Str {
    public static function up(string $s): string
    { return strtoupper($s); }
    public function wrap(string $s): string
    { return "[$s]"; }
}
$str = new Str();

array_map('trim', [' a ', ' b ']);             // string
array_map([$str, 'wrap'], ['a']);              // [obj, method]
array_map([Str::class, 'up'], ['a']);          // static
array_map('Str::up', ['a']);                   // 'Class::method'

$len  = strlen(...);                           // Closure (8.1)
$wrap = $str->wrap(...);
$up   = Str::up(...);
echo $len('hello'), $wrap('x'), $up('y');      // 5[x]Y

class Doubler {
    public function __invoke(int $n) { return $n * 2; }
}
$d = new Doubler();
echo $d(21);                                   // 42

is_callable([$str, 'missing']);                // false
call_user_func($wrap, 'z');                    // '[z]'

Code Explained

Strings name global functions
Arrays pair an object or class with a method name
f(...) turns any call target into a Closure
An invokable object is called like a function
call_user_func() is rarely needed now — call $f()

⚠ Common Mistakes

  • Typing a property as callable — use Closure
  • String callables that break after a rename
  • Passing [$this, 'privateMethod'] to outside code — not callable there

✓ Tips & Best Practices

  • Use name(...) syntax for callbacks
  • Type properties as Closure and parameters as callable
  • Use __invoke for single-action classes

Quick Summary

  • Strings, arrays, closures, invokables

  • Call with $f()
