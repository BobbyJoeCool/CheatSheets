Expressive Tests on PHPUnit

Pest is a testing framework built on top of PHPUnit with a function-based syntax. Tests are closures passed to test() or it(), and assertions use a chainable expect($value)->toBe(...) API. Pest supports datasets, hooks, higher-order tests, parallel runs and architecture tests that enforce rules like "controllers don't use the database". It runs existing PHPUnit tests unchanged.

Notes

  • Install: composer require pestphp/pest --dev, then ./vendor/bin/pest --init
  • $this in a Pest closure is the underlying TestCase
  • uses(TestCase::class)->in('Feature') sets the base class
  • ->only() and ->skip() focus or skip tests
  • Laravel ships with Pest by default

Pest Tests

<?php
beforeEach(function () {
    $this->cart = new Cart();
});

test('a new cart is empty', function () {
    expect($this->cart->count())->toBe(0);
});

it('totals items', function () {
    $this->cart->add('mug', 2, 8.50);
    expect($this->cart->total())->toEqualWithDelta(17.0, 0.001)
        ->and($this->cart->count())->toBe(1);
});

it('slugifies', function (string $in, string $out) {
    expect(slugify($in))->toBe($out);
})->with([
    ['Hello World', 'hello-world'],
    ['PHP & You!', 'php-you'],
]);

it('rejects negative quantities', fn () =>
    $this->cart->add('mug', -1, 1.0)
)->throws(InvalidArgumentException::class);

arch('controllers do not use the DB directly')
    ->expect('App\Http\Controllers')
    ->not->toUse('Illuminate\Support\Facades\DB');

Code Explained

beforeEach sets up $this->cart
expect()->toBe() is a strict === check
->and() chains a second expectation
->with() supplies a dataset
arch() enforces dependency rules
