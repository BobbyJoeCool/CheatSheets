Substrings, Indexing & Splitting

substr() · $str[0] · $str[-1] · explode() · implode() · str_split() · strtok()

Pieces of Strings

substr($s, $start, $length) extracts part of a string; negative values count from the end. You can read a single byte with $s[0] or $s[-1]. explode() splits on a delimiter into an array and implode() joins an array back into a string. str_split() cuts into fixed-size chunks and strtok() walks tokens one at a time.

Notes

  • substr() returns '' (not false) when out of range in PHP 8
  • Reading $s[99] past the end gives a Warning
  • explode() with a limit keeps the rest in the last element
  • implode() argument order: glue first, then array
  • Use mb_substr() / mb_str_split() for UTF-8 text

Slicing & Splitting

<?php
$s = 'Hello, World';

substr($s, 0, 5);        // 'Hello'
substr($s, 7);           // 'World'
substr($s, -5, 3);       // 'Wor'
$s[0];                   // 'H'
$s[-1];                  // 'd'

$parts = explode(',', 'a,b,,c');      // ['a','b','','c']
explode(',', 'a,b,c', 2);             // ['a', 'b,c']
explode(',', 'a,b,c', -1);            // ['a', 'b']
implode(' | ', ['x', 'y', 'z']);      // 'x | y | z'

str_split('abcdef', 2);               // ['ab','cd','ef']

$tok = strtok('one two  three', ' ');
while ($tok !== false) {
    echo $tok, "\n";                  // one, two, three
    $tok = strtok(' ');
}

Code Explained

substr($s, start, length) — length is optional
Negative start counts back from the end
explode keeps empty pieces ('' between ,,)
Negative limit drops that many pieces from the end
strtok() skips repeated delimiters

⚠ Common Mistakes

  • Using $s[0] on UTF-8 text — returns one byte of a multibyte char
  • Forgetting that explode on '' returns [''], not []
  • Passing implode($arr, ',') (old order) — TypeError in PHP 8

✓ Tips & Best Practices

  • Use array_filter(explode(...)) to drop empty parts
  • Use explode with a limit for key=value pairs
  • Use mb_substr() for anything a user typed
