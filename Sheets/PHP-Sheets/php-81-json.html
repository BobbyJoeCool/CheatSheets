Encoding and Decoding JSON

json_encode() turns PHP values into JSON text; json_decode() turns JSON into PHP values — objects (stdClass) by default, or associative arrays when the second argument is true. Without flags, errors return null/false silently, so always pass **JSON_THROW_ON_ERROR**. Classes control their JSON form by implementing JsonSerializable. PHP 8.3 adds json_validate() to check syntax cheaply.

Notes

  • Lists encode as […], other arrays as {…}
  • Strings must be valid UTF-8 or encoding fails
  • 1.0 encodes as 1 unless you pass JSON_PRESERVE_ZERO_FRACTION
  • Big integers in JSON may lose precision as floats
  • Public properties are encoded for plain objects

Encode, Decode, Customise

<?php
$data = ['name' => 'Ana', 'tags' => ['php', 'web'], 'url' => 'https://x.io/a'];

echo json_encode($data);
// {"name":"Ana","tags":["php","web"],"url":"https:\/\/x.io\/a"}
echo json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES
                        | JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR);

$obj = json_decode('{"a":1,"b":[2,3]}');            // stdClass
echo $obj->b[0];                                     // 2
$arr = json_decode('{"a":1}', true, 512, JSON_THROW_ON_ERROR);
echo $arr['a'];                                      // 1

try {
    json_decode('{bad json}', flags: JSON_THROW_ON_ERROR);
} catch (JsonException $e) {
    echo $e->getMessage();                           // Syntax error
}
json_validate('{"ok":true}');                        // true (8.3)

final class User implements JsonSerializable {
    public function __construct(private int $id, private string $pw) {}
    public function jsonSerialize(): array { return ['id' => $this->id]; }
}
echo json_encode(new User(7, 'secret'));             // {"id":7}

Code Explained

Default output escapes / and non-ASCII
Combine flags with | for readable output
true as 2nd arg → associative arrays
JSON_THROW_ON_ERROR turns failures into JsonException
jsonSerialize() hides private data like passwords

⚠ Common Mistakes

  • Not checking errors — json_decode returns null silently
  • Encoding non-UTF-8 strings
  • Expecting an empty array to encode as {}

✓ Tips & Best Practices

  • Always use JSON_THROW_ON_ERROR
  • Decode to arrays (true) for simple data
  • Implement JsonSerializable for API output
