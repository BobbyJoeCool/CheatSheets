Quick Reference — Core Functions

string · array · math · date · file · JSON · type checks

Most-Used Built-in Functions

PHP's standard library is large; these are the functions you'll reach for daily. Remember the two classic gotchas: argument order isn't consistent (array_map($fn, $arr) vs array_filter($arr, $fn)), and many functions return false on failure — compare strictly. Use mb_* versions for user-visible text. Detailed sheets are referenced in each table title.

Notes

  • Array functions return new arrays except sort/push/pop/shift
  • String functions never modify the original string
  • Pass true for strict in_array / array_search
  • Use JSON_THROW_ON_ERROR with JSON functions
  • Check php.net/function-name for full signatures

⚠ Common Mistakes

  • Ignoring false returns
  • Swapping needle/haystack order
  • Byte functions on UTF-8 text

✓ Tips & Best Practices

  • Let IDE parameter hints guide argument order
  • Wrap false-returning calls in small helpers that throw
  • Prefer the newer, clearer functions (str_contains, array_find)

Quick Summary

  • Strings: str_*, mb_*
  • Arrays: array_* + sort
  • Check for false
  • Mind argument order
