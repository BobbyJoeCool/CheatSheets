Syntax at a Glance

A one-page reminder of PHP's core syntax, from tags and variables to classes and namespaces. Each line shows the shape of a construct; the detailed sheets cover rules and edge cases. Start every file with <?php and declare(strict_types=1);, type everything, and prefer strict comparisons.

Notes

  • Statements end with ;
  • Variables start with $; constants don't
  • Blocks use braces; templates can use : … end*;
  • Strings: 'literal', "interpolated $x"
  • Comments: //, #, /* */, /** */

Core Syntax

<?php
declare(strict_types=1);
namespace App;
use App\Models\User;

const MAX = 10;
$name = 'Ana';              $list = [1, 2, 3];
$map  = ['k' => 'v'];       [$a, $b] = [1, 2];

if ($x > 0) { /* … */ } elseif ($x < 0) { /* … */ } else { /* … */ }
$r = match ($code) { 200, 201 => 'ok', default => 'err' };
foreach ($map as $k => $v) { /* … */ }
for ($i = 0; $i < MAX; $i++) { /* … */ }
try { /* … */ } catch (A|B $e) { /* … */ } finally { /* … */ }

function add(int $a, int $b = 0): int { return $a + $b; }
$double = fn(int $n): int => $n * 2;
$greet  = function (string $n) use ($name) { return "$n & $name"; };

interface Shape { public function area(): float; }
final class Circle implements Shape
{
    public function __construct(private float $r) {}
    public function area(): float
    { return M_PI * $this->r ** 2; }
    public static function unit(): static
    { return new static(1); }
}
echo (new Circle(2))->area();
