Handling Forms

method="post" · $_POST · isset checks · sticky forms · Post/Redirect/Get · arrays in names[]

Form Round Trips

An HTML form sends its fields to the action URL using GET (query string) or POST (request body). PHP exposes them in $_GET or $_POST keyed by each input's name. A typical handler checks the method, validates fields, re-displays the form with errors and the user's values (sticky form), and on success redirects (Post/Redirect/Get) so a browser refresh doesn't resubmit.

Notes

  • Unchecked checkboxes send nothing — use isset()
  • name="tags[]" sends an array
  • Use POST for anything that changes data
  • Escape values you echo back into inputs
  • Add a CSRF token to every POST form (Sheet 127)

Validate, Redisplay, Redirect

<?php
$errors = [];
$name = $email = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $name  = trim($_POST['name'] ?? '');
    $email = trim($_POST['email'] ?? '');
    $agree = isset($_POST['agree']);

    if ($name === '') $errors['name'] = 'Name is required';
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors['email'] = 'Invalid email';
    }
    if (!$agree) $errors['agree'] = 'Please accept the terms';

    if (!$errors) {
        saveSignup($name, $email);
        header('Location: /thanks', true, 303);   // PRG
        exit;
    }
}
$e = fn($v) => htmlspecialchars($v, ENT_QUOTES);
?>
<form method="post" action="">
  <input name="name" value="<?= $e($name) ?>">
  <?php if (isset($errors['name'])): ?>
    <p class="err"><?= $e($errors['name']) ?></p>
  <?php endif ?>
  <input name="email" type="email" value="<?= $e($email) ?>">
  <label><input type="checkbox" name="agree"> I agree</label>
  <button>Sign up</button>
</form>

Code Explained

Only process on POST
trim + ?? give clean defaults
Collect errors by field name
303 redirect after success (Post/Redirect/Get)
Escape every value echoed back (sticky form)

⚠ Common Mistakes

  • Missing exit after header('Location: …')
  • Echoing user input back without escaping
  • Validating only in JavaScript

✓ Tips & Best Practices

  • Always validate server-side
  • Use Post/Redirect/Get with status 303
  • Use a form library or framework validator for larger apps

Quick Summary

  • Fields arrive by name
  • Checkboxes: isset()
  • Sticky forms + escaping
