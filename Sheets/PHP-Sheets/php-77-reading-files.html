Sheet 77

Reading Files

file_get_contents() · file() · fopen() · fgets() · fread() · feof() · SplFileObject

Getting Data Out of Files

For small files, file_get_contents() reads everything into a string and file() reads lines into an array. For large files, open a stream with fopen() and read a line (fgets) or a chunk (fread) at a time so memory stays flat. Every read function returns false on failure and emits a Warning — check the result. SplFileObject wraps the same operations in an iterable object.

Notes

  • file() flags: FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES
  • Always fclose() handles you open (or let them go out of scope)
  • file_get_contents() also reads URLs if allow_url_fopen is on
  • Check is_readable() first for nicer error messages
  • Read binary files with mode 'rb'

Whole File, Lines, Streams

<?php
$text = file_get_contents(__DIR__ . '/notes.txt');
if ($text === false) {
    throw new RuntimeException('Cannot read notes.txt');
}

$lines = file('list.txt', FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);

$fh = fopen('big.log', 'r');
while (($line = fgets($fh)) !== false) {
    // one line at a time, constant memory
}
fclose($fh);

$fh = fopen('photo.jpg', 'rb');
$header = fread($fh, 8);               // first 8 bytes
fclose($fh);

$file = new SplFileObject('data.txt');
foreach ($file as $n => $line) {
    echo $n + 1, ': ', rtrim($line), "\n";
}

Code Explained

=== false distinguishes failure from an empty file
file() with flags gives clean lines
fgets() loop streams very large files
fread($fh, n) reads up to n bytes
SplFileObject is iterable line by line

⚠ Common Mistakes

  • Loading a multi-GB log with file_get_contents()
  • while (!feof($fh)) that processes a final false
  • Building paths from user input without validation (path traversal)

✓ Tips & Best Practices

  • Use __DIR__ to build paths
  • Stream with fgets() or a generator for big files
  • Throw on false instead of continuing

Quick Summary

  • file_get_contents / file for small
  • fopen + fgets for big
  • Check for false
  • SplFileObject iterates lines
