Extending Classes

class Child extends ParentClass inherits all public and protected members. A child can override a method by redefining it, and call the original with parent::method(). PHP supports single inheritance only — use interfaces and traits to share more. final stops a class from being extended or a method from being overridden. The #[\Override] attribute (8.3) makes PHP check that a method really overrides something.

Notes

  • Overrides may widen visibility (protected → public), never narrow it
  • Return types may be narrower (covariant)
  • Parameter types may be wider (contravariant)
  • Constructors are exempt from signature compatibility rules
  • Favour composition when the relationship isn't "is-a"

extends, parent:: and #[\Override]

<?php
class Animal
{
    public function __construct(protected string $name) {}

    public function speak(): string
    {
        return "{$this->name} makes a sound";
    }
}

class Dog extends Animal
{
    public function __construct(string $name, private string $breed)
    {
        parent::__construct($name);
    }

    #[\Override]
    public function speak(): string
    {
        return parent::speak() . ' — Woof!';
    }
}

final class Puppy extends Dog {}
// class X extends Puppy {}   // Fatal: cannot extend final

$d = new Dog('Rex', 'Lab');
echo $d->speak();     // Rex makes a sound — Woof!
var_dump($d instanceof Animal);   // true

Code Explained

Child constructor must call parent::__construct()
parent::speak() reuses the original logic
#[\Override] errors if no parent method exists
final class can't be extended
A Dog is also an Animal

⚠ Common Mistakes

  • Forgetting parent::__construct()
  • Deep inheritance trees that are hard to follow
  • Changing parameter types in incompatible ways

✓ Tips & Best Practices

  • Mark classes final unless designed for extension
  • Add #[\Override] to every overriding method
  • Prefer interfaces + composition for shared behaviour
