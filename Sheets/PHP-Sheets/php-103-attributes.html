Sheet 103

Attributes

#[Attribute] · targets · IS_REPEATABLE · ReflectionAttribute · #[\SensitiveParameter] · #[\Deprecated] · #[\NoDiscard]

Structured Metadata (8.0)

Attributes attach machine-readable metadata to classes, methods, properties, parameters, functions and constants using #[Name(args)]. They replace docblock annotations with real, autoloaded classes. Your code (or a framework) reads them with Reflection's getAttributes() and newInstance(). PHP also ships built-in attributes that change engine behaviour, such as #[\Override], #[\Deprecated] and #[\NoDiscard].

Notes

  • An attribute class itself is marked #[Attribute]
  • Targets restrict where it can be used (Attribute::TARGET_METHOD)
  • Attribute arguments must be constant expressions
  • Unknown attributes are ignored until you call newInstance()
  • Frameworks use them for routes, validation, ORM mapping

Defining and Reading Attributes

<?php
#[Attribute(Attribute::TARGET_METHOD | Attribute::IS_REPEATABLE)]
final class Route
{
    public function __construct(
        public string $path,
        public string $method = 'GET',
    ) {}
}

final class UserController
{
    #[Route('/users')]
    #[Route('/people')]
    public function index(): array { return []; }

    #[Route('/users', method: 'POST')]
    public function store(#[\SensitiveParameter] string $password): void {}
}

$rc = new ReflectionClass(UserController::class);
foreach ($rc->getMethods() as $m) {
    foreach ($m->getAttributes(Route::class) as $attr) {
        $route = $attr->newInstance();
        echo "$route->method $route->path → {$m->name}\n";
    }
}
// GET /users → index, GET /people → index, POST /users → store

Code Explained

#[Attribute] with flags declares a repeatable method attribute
Attribute arguments map to constructor parameters
Named arguments work in attributes
#[\SensitiveParameter] hides the value in stack traces
Reflection reads and instantiates attributes

⚠ Common Mistakes

  • Forgetting #[Attribute] on your attribute class — newInstance() fails
  • Using non-constant expressions as arguments
  • Expecting attributes to do anything without code that reads them

✓ Tips & Best Practices

  • Use attributes instead of docblock annotations
  • Restrict targets to catch misuse
  • Cache reflection results in production
