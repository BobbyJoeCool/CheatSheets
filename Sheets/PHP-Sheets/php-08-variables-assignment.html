Variables & Assignment

$name · by value · by reference =& · variable variables $$ · isset() · unset()

Variables

Every variable starts with $ and is created the first time you assign to it; there is no declaration keyword. Variables are dynamically typed: the value has a type, the variable doesn't. Assignment copies the value — arrays included (copy-on-write keeps this cheap). Objects are handles, so copying a variable that holds an object still points at the same object. =& makes two names share one value.

Notes

  • Names: letter or underscore first, then letters, digits, underscores
  • Names are case-sensitive: $user ≠ $User
  • Reading an undefined variable gives a Warning and null
  • $this is reserved inside classes
  • Convention: $camelCase (PSR) or $snake_case — be consistent

Assign, Copy, Reference

<?php
$name = 'Ana';
$count = 3;
$a = $b = 0;                 // chained assignment

$list = [1, 2];
$copy = $list;               // independent copy
$copy[] = 3;                 // $list is still [1, 2]

$ref = &$list;               // alias, not a copy
$ref[] = 99;                 // $list is now [1, 2, 99]

isset($name);                // true (exists, not null)
unset($name);                // remove the variable
isset($name);                // false

$field = 'count';
echo $$field;                // 3 (variable variable)

Code Explained

Chained $a = $b = 0 assigns right to left
Arrays copy on assignment; changes don't leak back
&$list — both names now refer to the same value
isset() is false for undefined and for null
$$field reads the variable named by $field — avoid in real code

⚠ Common Mistakes

  • Expecting $b = $arr to share changes — arrays are copied
  • Expecting $b = $obj to copy an object — use clone
  • Using isset() to test a key whose value may be null

✓ Tips & Best Practices

  • Initialise variables before use; enable E_ALL to catch typos
  • Avoid references unless you need in-place edits
  • Prefer clear names over variable variables

Quick Summary

  • $name = value creates it
  • Arrays copy, objects share
  • =& aliases
  • isset / unset / ??
