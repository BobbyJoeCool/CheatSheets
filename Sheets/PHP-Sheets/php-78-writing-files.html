Sheet 78

Writing & Appending Files

file_put_contents() · FILE_APPEND · LOCK_EX · fwrite() · modes w a x c · tempnam()

Putting Data Into Files

file_put_contents() writes a string (or array of strings) in one call, creating the file if needed and replacing it unless you pass FILE_APPEND. Add LOCK_EX so concurrent writers don't interleave. For incremental writes, open a handle with a write mode and call fwrite(). The mode decides whether the file is truncated, appended to, or must not already exist.

Notes

  • Return value: bytes written, or false on failure
  • The directory must exist — create it with mkdir(..., recursive: true)
  • Write to a temp file and rename() for atomic replacement
  • PHP_EOL vs "\n": pick one line ending per file format
  • Check permissions with is_writable()

Write, Append, Atomic Replace

<?php
file_put_contents('out.txt', "Hello\n");          // overwrite
file_put_contents('app.log', date('c') . " start\n",
                  FILE_APPEND | LOCK_EX);            // append safely
file_put_contents('list.txt', ["a\n", "b\n"]);    // array OK

$fh = fopen('report.csv', 'w');                     // truncate
fwrite($fh, "id,name\n");
fwrite($fh, "1,Ana\n");
fclose($fh);

$fh = fopen('new.lock', 'x');     // fails if file exists
if ($fh === false) { exit("Already running\n"); }

// Atomic write: readers never see a half-written file
$tmp = tempnam(dirname($path), 'tmp');
file_put_contents($tmp, json_encode($data));
rename($tmp, $path);

$dir = __DIR__ . '/cache/2026';
is_dir($dir) || mkdir($dir, 0775, recursive: true);

Code Explained

Default mode replaces the file
FILE_APPEND | LOCK_EX — append with an exclusive lock
'w' truncates before writing
'x' creates only if missing — a simple lock
rename() within one filesystem is atomic

⚠ Common Mistakes

  • Concurrent appends without LOCK_EX
  • Writing into a directory that doesn't exist
  • Ignoring a false return — disk full or permissions

✓ Tips & Best Practices

  • Use temp file + rename() for config or cache writes
  • Prefer a logging library over hand-rolled log files
  • Keep writable dirs outside the web root

Quick Summary

  • file_put_contents() one-shot
  • FILE_APPEND | LOCK_EX
  • Modes w a x c
  • Temp + rename() = atomic
