Comparing Values

== compares after type juggling; === requires the same type and value. Prefer the strict forms === and !== unless you specifically want conversion. The spaceship operator <=> returns -1, 0 or 1 and is ideal for sort callbacks. Arrays compare element by element; objects compare property by property with == and by identity with ===.

Notes

  • <> is an alias of !=
  • Strings compare byte by byte ('Z' < 'a')
  • Two numeric strings compare numerically: '10' == '1e1'
  • === on arrays also checks key order and types
  • match uses strict === comparison (Sheet 31)

Loose, Strict & Spaceship

<?php
var_dump(1 == '1');           // true
var_dump(1 === '1');          // false
var_dump(null == false);      // true
var_dump('abc' == 0);         // false (PHP 8)
var_dump('1e3' == '1000');    // true (numeric strings)

echo 1 <=> 2;                 // -1
echo 'b' <=> 'a';             // 1
echo [1, 2] <=> [1, 2];       // 0

var_dump([1, 2] == [2 => 1]);           // false
var_dump(['a' => 1, 'b' => 2]
      == ['b' => 2, 'a' => 1]);         // true
var_dump(['a' => 1, 'b' => 2]
     === ['b' => 2, 'a' => 1]);         // false (order)

usort($people, fn($a, $b) => $a->age <=> $b->age);

Code Explained

== converts; === doesn't
PHP 8 compares a number and non-numeric string as strings
<=> compares arrays element by element
Loose array equality ignores key order
<=> in usort sorts ascending; swap sides for descending

⚠ Common Mistakes

  • Using == to compare tokens or hashes — use hash_equals()
  • Writing = instead of == in a condition
  • Sorting with a callback that returns bool instead of <=>

✓ Tips & Best Practices

  • Default to === / !==
  • Use <=> in every sort comparator
  • Use hash_equals() for secrets (timing-safe)

Quick Summary

  • === strict, == loose
  • <=> → -1 / 0 / 1
  • Arrays: == ignores order
  • Objects: === = same instance
