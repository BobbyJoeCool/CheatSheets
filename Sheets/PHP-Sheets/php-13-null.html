Null

null · is_null() · nullable ?int · unset vs null · null in comparisons · uninitialized typed properties

The Absence of a Value

null is the only value of type null. A variable is null when assigned null, after unset(), or when read without being defined (with a Warning). Functions without a return value return null. Type declarations reject null unless you allow it with ?Type or Type|null. The ?? and ?-> operators exist to make null handling short and safe (Sheet 27).

Notes

  • null, NULL and Null are the same
  • isset($x) is false when $x is null
  • A typed property without a default is uninitialized, not null
  • null == false, null == 0, null == '' are all true; use ===
  • In arrays, a key can exist with a null value

Working with null

<?php
function findUser(int $id): ?User      // may return null
{
    return $id === 1 ? new User('Ana') : null;
}

$user = findUser(2);
if ($user === null) {
    echo "not found\n";
}

$name = $user?->name ?? 'guest';       // 'guest'

class Order {
    public ?string $note = null;       // nullable, default null
    public int $total;                 // uninitialized!
}
$o = new Order();
var_dump($o->note);                    // NULL
// echo $o->total;   // Error: must not be accessed
                     //        before initialization

Code Explained

?User return type — User or null
Compare with === null (or is_null())
?-> stops at null; ?? supplies a default
?string $note = null — explicitly nullable
Typed property with no default throws on read until set

⚠ Common Mistakes

  • int $x = null without ? — implicit nullable is deprecated in 8.4
  • Using == null and matching 0 or ''
  • Reading an uninitialized typed property

✓ Tips & Best Practices

  • Return null for "not found", throw for real errors
  • Give nullable properties an explicit = null
  • Reach for ?? and ?-> before nested if checks

Quick Summary

  • null = no value
  • ?Type allows null
  • Compare with === null
  • Uninitialized ≠ null
