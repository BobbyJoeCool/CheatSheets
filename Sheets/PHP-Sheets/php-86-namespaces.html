Namespaces

namespace · use · as aliases · use function · use const · group use · global \ prefix

Organising Names

Namespaces group classes, functions and constants under a prefix such as App\Models, so names from different libraries don't collide. Declare one at the top of a file with namespace. Refer to names in other namespaces by their fully qualified name (\App\Models\User) or import them with use. Namespaces map directly to folders under PSR-4 autoloading.

Notes

  • One namespace per file is the norm
  • Unqualified class names resolve relative to the current namespace
  • Unqualified function and constant names fall back to global
  • use is per file and resolved at compile time
  • ::class gives the fully qualified string

Declaring and Importing

<?php
declare(strict_types=1);

namespace App\Http\Controllers;

use App\Models\User;
use App\Models\{Order, Product};          // group use
use App\Services\Mailer as Mail;          // alias
use function App\Support\slugify;
use const App\Support\VERSION;

final class ShopController
{
    public function show(int $id): string
    {
        $user = new User($id);             // App\Models\User
        $now  = new \DateTimeImmutable();  // global class
        $len  = strlen('x');               // falls back to \strlen
        Mail::send($user);
        return slugify("product $id") . VERSION;
    }
}

echo ShopController::class;    // App\Http\Controllers\ShopController
echo __NAMESPACE__;            // App\Http\Controllers

Code Explained

namespace comes right after declare
Group use imports several classes from one prefix
as renames an import
Leading \ reaches the global namespace
Built-in functions resolve without importing

⚠ Common Mistakes

  • Forgetting the \ before global classes inside a namespace (DateTime not found)
  • Namespace not matching the folder — autoloading fails
  • Importing the same short name twice

✓ Tips & Best Practices

  • Let your IDE manage use statements
  • Import global classes explicitly or prefix with \
  • Match namespaces to directories

Quick Summary

  • namespace prefixes names
  • use imports / aliases
  • \ = global
  • Maps to folders (PSR-4)
