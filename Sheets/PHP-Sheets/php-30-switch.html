Sheet 30

switch

switch · case · break · fall-through · default · loose comparison · endswitch

Multi-Way Branch on One Value

switch compares one expression against several case values using **loose == comparison and runs code from the first match until a break**. Leaving out break makes execution fall through into the next case — useful for grouping cases, dangerous by accident. default runs when nothing matches. For most new code, match (Sheet 31) is shorter and stricter.

Notes

  • continue inside switch acts like break (and warns)
  • Cases can be expressions, not just literals
  • switch is a statement — it doesn't produce a value
  • Alternative syntax: switch (...): … endswitch;
  • default can appear anywhere but put it last

switch with Grouping & Fall-Through

<?php
$day = 'sat';

switch ($day) {
    case 'sat':
    case 'sun':                     // grouped cases
        $type = 'weekend';
        break;
    case 'fri':
        echo "Almost there\n";      // falls through ...
    case 'mon':
    case 'tue':
        $type = 'weekday';          // ... into here
        break;
    default:
        $type = 'unknown';
}

switch ('1') {
    case 1:                         // '1' == 1 -> matches
        echo "loose match\n";
        break;
}

switch (true) {                     // range checks
    case $score >= 90: $grade = 'A'; break;
    case $score >= 80: $grade = 'B'; break;
    default:           $grade = 'C';
}

Code Explained

Empty cases stack to share one body
No break after fri → runs the next body too
default handles unmatched values
Comparison is ==, so '1' matches 1
switch (true) turns cases into conditions

⚠ Common Mistakes

  • Forgetting break — silent fall-through
  • Relying on loose comparison with mixed types
  • Using switch just to assign one value — use match

✓ Tips & Best Practices

  • Comment intentional fall-through: // fall through
  • Use return instead of break inside small functions
  • Prefer match for value mapping

Quick Summary

  • Loose == comparison
  • break ends a case
  • Fall-through without it
  • default catches the rest
