SPL Data Structures

SplStack · SplQueue · SplPriorityQueue · SplMinHeap · SplFixedArray · SplObjectStorage · ArrayObject

Specialised Containers

The Standard PHP Library (SPL) ships classic data structures as classes. SplStack and SplQueue are doubly linked lists with stack and queue methods; SplMinHeap, SplMaxHeap and SplPriorityQueue keep items ordered by priority; SplFixedArray is a fixed-size integer-indexed array; SplObjectStorage maps objects to data. Use them when plain arrays get slow or unclear for the job.

Notes

  • SPL structures are objects — passed by handle, not copied
  • SplPriorityQueue with equal priorities has no guaranteed order
  • Iterating a heap or priority queue removes items
  • WeakMap (8.0) is an object-keyed map that doesn't keep keys alive
  • ArrayObject wraps an array in an object with array syntax

Using SPL Containers

<?php
$stack = new SplStack();
$stack->push('a'); $stack->push('b');
echo $stack->pop();                 // b (LIFO)

$queue = new SplQueue();
$queue->enqueue('job1'); $queue->enqueue('job2');
echo $queue->dequeue();             // job1 (FIFO)

$pq = new SplPriorityQueue();
$pq->insert('low', 1);
$pq->insert('urgent', 10);
echo $pq->extract();                // urgent

$heap = new SplMinHeap();
foreach ([5, 1, 3] as $n) $heap->insert($n);
echo $heap->extract();              // 1

$fixed = new SplFixedArray(3);
$fixed[0] = 'x';                    // index 3 → RuntimeException

$seen = new SplObjectStorage();
$seen[$user] = ['visits' => 3];     // object as key
count($seen);                       // 1

Code Explained

push / pop work from the top
enqueue / dequeue work first-in, first-out
Highest priority number comes out first
Min-heap always yields the smallest value
SplObjectStorage keys by object identity

⚠ Common Mistakes

  • Iterating an SplPriorityQueue and expecting it to stay full
  • Using array_shift on huge arrays instead of SplQueue
  • Assuming FIFO order for equal priorities

✓ Tips & Best Practices

  • Reach for SPL when a plain array obscures intent
  • Use WeakMap for per-object caches
  • Add a sequence number to priorities for stable ordering

Quick Summary

  • Stack, queue, heap, priority queue
  • Fixed arrays and object maps
  • Objects, not values
  • Iteration may consume items
