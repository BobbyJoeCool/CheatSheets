Passing Data In

Parameters are passed by value: the function gets a copy (objects pass their handle, so methods can still change the object). Give a parameter a default to make it optional. Prefix with & to pass by reference so the function can modify the caller's variable. PHP 8 named arguments let you pass values by parameter name, skip optional ones, and make calls self-documenting.

Notes

  • Defaults must be constant expressions (or new objects, 8.1+)
  • Optional parameters should come after required ones
  • Too few arguments → ArgumentCountError; extras are ignored by user functions
  • Named and positional args can mix; positional must come first
  • Renaming a parameter is a breaking change once callers use names

Defaults, References & Named Args

<?php
function makeTag(string $tag, string $text = '',
                 array $attrs = [], bool $close = true): string
{
    $a = '';
    foreach ($attrs as $k => $v) $a .= " $k=\"$v\"";
    return "<$tag$a>$text" . ($close ? "</$tag>" : '');
}

makeTag('p', 'Hi');                       // <p>Hi</p>
makeTag('br', close: false);              // <br>
makeTag(tag: 'a', text: 'Go', attrs: ['href' => '/']);

function addTax(float &$price, float $rate = 0.2): void
{
    $price *= 1 + $rate;                  // changes caller's var
}
$p = 10.0;
addTax($p);
echo $p;                                  // 12

htmlspecialchars($s, double_encode: false); // skip middle args

Code Explained

Defaults make $text, $attrs, $close optional
Named argument skips all the defaults in between
Names can be given in any order
&$price writes back to $p
Named args work with built-in functions too

⚠ Common Mistakes

  • Required parameter after an optional one — deprecated
  • Passing a literal to a by-reference parameter
  • Long boolean parameter lists called positionally (f(true, false, true))

✓ Tips & Best Practices

  • Use named arguments for booleans and option flags
  • Return new values instead of using references
  • Keep parameter lists short; group options into an object

Quick Summary

  • By value by default
  • Defaults → optional
  • & → by reference
  • Named args: f(name: value)
