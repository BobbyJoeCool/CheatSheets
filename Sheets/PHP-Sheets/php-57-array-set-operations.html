Set Operations & Keys

array_unique() · array_diff() · array_intersect() · _key variants · array_flip() · array_keys() · array_first() / array_last() (8.5)

Arrays as Sets

PHP has no built-in set type, but arrays work well. array_unique() removes duplicate values; array_diff() returns values of the first array not found in the others; array_intersect() returns values found in all. _key variants compare keys and _assoc variants compare both. For fast membership tests, store items as keys ($set[$item] = true). PHP 8.5 adds array_first() and array_last().

Notes

  • These functions compare as strings ((string) $a === (string) $b) by default
  • Results keep the keys of the first array
  • array_unique() keeps the first occurrence
  • u variants (array_udiff) take a comparison callback
  • array_key_first() / array_key_last() exist since 7.3

Set Operations

<?php
$a = ['red', 'green', 'blue', 'green'];
$b = ['green', 'yellow'];

array_unique($a);           // [0=>'red', 1=>'green', 2=>'blue']
array_diff($a, $b);         // [0=>'red', 2=>'blue']
array_intersect($a, $b);    // [1=>'green', 3=>'green']
array_values(array_unique(array_merge($a, $b)));  // union

$x = ['id' => 1, 'name' => 'Ana', 'pw' => 'secret'];
array_diff_key($x, ['pw' => 0]);           // drop 'pw'
array_intersect_key($x, array_flip(['id', 'name']));  // whitelist

$set = [];
foreach (['a', 'b', 'a'] as $tag) {
    $set[$tag] = true;      // keys = unique members
}
isset($set['a']);           // O(1) membership
array_keys($set);           // ['a', 'b']

array_first(['x' => 10, 'y' => 20]);   // 10 (8.5)
array_last(['x' => 10, 'y' => 20]);    // 20 (8.5)

Code Explained

Duplicates removed; first keys kept
diff = in first, not in others
intersect = in first and all others
array_intersect_key + array_flip = pick allowed fields
Keys-as-set gives constant-time lookups

⚠ Common Mistakes

  • Expecting array_diff results to be reindexed
  • Running array_unique on arrays of arrays — string conversion fails
  • Using in_array in a loop instead of a keyed set

✓ Tips & Best Practices

  • Model sets as [$member => true]
  • Whitelist input fields with array_intersect_key
  • Wrap results in array_values() when you need a list
