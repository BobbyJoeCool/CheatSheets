Logging — Monolog & PSR-3

Monolog Logger · handlers · formatters · log levels · context arrays · PSR-3 LoggerInterface

Structured Logging

PSR-3 defines Psr\Log\LoggerInterface with methods for eight severity levels; type-hint against it so any logger can be plugged in. Monolog is the standard implementation. A Logger has a channel name and a stack of handlers (where logs go: files, stderr, Slack…) and processors (add data such as request IDs). Pass variable data in the context array instead of building strings.

Notes

  • Handlers have a minimum level; lower messages are ignored
  • Placeholders {key} in messages are filled from context (with a processor)
  • Log to php://stderr in containers
  • Never log passwords, tokens or full card numbers
  • Frameworks wire Monolog for you

Monolog Setup and Use

<?php
use Monolog\Level;
use Monolog\Logger;
use Monolog\Handler\StreamHandler;
use Monolog\Handler\RotatingFileHandler;
use Monolog\Formatter\JsonFormatter;
use Monolog\Processor\PsrLogMessageProcessor;
use Psr\Log\LoggerInterface;

$log = new Logger('shop');
$log->pushHandler(new StreamHandler('php://stderr', Level::Warning));
$file = new RotatingFileHandler(
    __DIR__ . '/var/app.log', maxFiles: 14, level: Level::Debug);
$file->setFormatter(new JsonFormatter());
$log->pushHandler($file);
$log->pushProcessor(new PsrLogMessageProcessor());

$log->info('Order {id} placed', ['id' => 42, 'total' => 19.5]);
$log->error('Payment failed', ['exception' => $e]);

final class Checkout
{
    public function __construct(private LoggerInterface $logger) {}
    public function run(): void { $this->logger->debug('checkout start'); }
}

Code Explained

Channel name tags every record
stderr gets warnings and above
Rotating JSON file keeps 14 days of everything
Processor fills {id} from context
Depend on LoggerInterface, not Monolog

⚠ Common Mistakes

  • Interpolating values into messages — breaks grouping
  • Logging secrets or personal data
  • Using echo/var_dump for production diagnostics

✓ Tips & Best Practices

  • Type-hint LoggerInterface
  • Use FingersCrossedHandler to get debug context only on errors
  • Log JSON for aggregators
