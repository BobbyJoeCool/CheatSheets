Floats

float literals · 1.5e3 · precision · INF · NAN · is_nan() · round() · BCMath

Floating-Point Numbers

float is an IEEE-754 double: about 15–17 significant digits. Many decimal fractions (like 0.1) have no exact binary form, so **never compare floats with ==** — compare the difference against a tolerance. Division by zero throws DivisionByZeroError; other invalid results produce INF or NAN. For money, store integer cents or use BCMath (string-based decimals).

Notes

  • precision ini controls echo output; serialize_precision=-1 gives shortest round-trip
  • NAN is not equal to anything, including itself
  • round() rounds half away from zero by default
  • PHP 8.4 added RoundingMode enum for round()
  • number_format() formats for display (Sheet 17)

Precision & Special Values

<?php
$a = 1.5;  $b = 1.5e3;  $c = 7E-10;   // 1500.0, 0.0000000007

var_dump(0.1 + 0.2 == 0.3);           // bool(false)
var_dump(abs(0.1 + 0.2 - 0.3) < PHP_FLOAT_EPSILON); // true

echo round(2.5);          // 3
echo round(-2.5);         // -3
echo round(3.14159, 2);   // 3.14
echo floor(3.7), ' ', ceil(3.2);  // 3 4

var_dump(log(0));         // float(-INF)
var_dump(sqrt(-1));       // float(NAN)
is_nan(sqrt(-1));         // true
is_finite(1e308 * 10);    // false

echo bcadd('0.1', '0.2', 2);  // "0.30"

Code Explained

e notation works for large and small values
0.1 + 0.2 is 0.30000000000000004
PHP_FLOAT_EPSILON is a tolerance for values near 1
floor() / ceil() return floats
bcadd() adds decimal strings exactly (scale 2)

⚠ Common Mistakes

  • Comparing floats with == or ===
  • Storing money as floats — rounding drift adds up
  • Testing $x == NAN — always false; use is_nan()

✓ Tips & Best Practices

  • Store currency as integer cents or BCMath strings
  • Compare with a tolerance suited to your data
  • Round only for display, not mid-calculation

Quick Summary

  • IEEE-754 double
  • Never == floats
  • INF / NAN checks
  • BCMath for exact decimals
