Variable Scope

local scope · global · $GLOBALS · static variables · no block scope · superglobals

Where Variables Live

Each function has its own local scope: it can't see variables from the file or from its caller, and its variables disappear when it returns. Unlike many languages, PHP has no block scope — a variable created inside if or a loop is visible for the rest of the function. static variables keep their value between calls. Superglobals such as $_GET are visible everywhere.

Notes

  • The top level of a script is the global scope
  • global $x; imports a global into a function (avoid)
  • $GLOBALS is read-only as a whole array since PHP 8.1
  • Closures capture outer variables only with use (Sheet 46)
  • Arrow functions capture automatically (Sheet 47)

Local, Global & Static

<?php
$rate = 0.2;

function price(float $net): float
{
    // echo $rate;             // Warning: undefined
    global $rate;              // import (not recommended)
    return $net * (1 + $rate);
}

function priceBetter(float $net, float $rate): float
{
    return $net * (1 + $rate); // pass it in instead
}

function counter(): int
{
    static $n = 0;             // initialised once
    return ++$n;
}
counter(); counter();
echo counter();                // 3

if (true) { $inside = 'visible'; }
echo $inside;                  // 'visible' — no block scope

Code Explained

Functions can't see $rate without help
global links the local name to the global variable
Passing values in keeps functions testable
static $n survives across calls
Variables set inside if remain afterwards

⚠ Common Mistakes

  • Expecting a function to see a variable from the calling code
  • Relying on global — hidden dependencies
  • Using static variables as a cache that never clears in long-running workers

✓ Tips & Best Practices

  • Pass dependencies as parameters
  • Return results instead of writing to globals
  • Keep top-level script code small

Quick Summary

  • Functions have local scope
  • No block scope
  • static persists between calls
  • Avoid global
