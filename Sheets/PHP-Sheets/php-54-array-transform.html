Sheet 54

Transforming Arrays

array_map() · array_filter() · array_reduce() · array_walk() · array_column() · array_combine()

Map, Filter, Reduce

array_map() builds a new array by applying a callback to each element; array_filter() keeps elements whose callback returns truthy (or non-falsy values with no callback); array_reduce() folds everything into one value. These return new arrays and leave the input alone. array_walk() instead modifies elements in place via a by-reference parameter. Note the inconsistent argument order between them.

Notes

  • array_map($fn, $a) — callback first; array_filter($a, $fn) — array first
  • array_map keeps keys with one array; reindexes with several
  • array_filter preserves keys — wrap in array_values() for a list
  • ARRAY_FILTER_USE_KEY / _USE_BOTH pass keys to the callback
  • array_map(null, $a, $b) zips arrays together

Pipelines on Arrays

<?php
$nums = [1, 2, 3, 4, 5, 6];

$squares = array_map(fn($n) => $n ** 2, $nums);
$evens   = array_filter($nums, fn($n) => $n % 2 === 0);
// [1 => 2, 3 => 4, 5 => 6]  keys kept!
$evens   = array_values($evens);          // [2, 4, 6]
$sum     = array_reduce($nums, fn($c, $n) => $c + $n, 0);

$clean = array_filter(['a', '', null, 0, 'b']);  // ['a', 4 => 'b']

$prices = ['tea' => 3, 'cake' => 5];
array_walk($prices, function (&$p, $item) { $p *= 1.2; });

$rows = [['id' => 7, 'name' => 'Ana'], ['id' => 9, 'name' => 'Bo']];
array_column($rows, 'name');              // ['Ana', 'Bo']
array_column($rows, 'name', 'id');        // [7 => 'Ana', 9 => 'Bo']
array_combine(['a', 'b'], [1, 2]);        // ['a' => 1, 'b' => 2]
array_map(null, [1, 2], ['x', 'y']);      // [[1,'x'], [2,'y']]

Code Explained

array_map returns the transformed copy
array_filter keeps original keys
array_reduce($a, $fn, $initial) — carry, then item
No callback: array_filter removes falsy values
array_column picks one field, optionally keyed

Core Functions

FunctionReturns

array_filter($a, $fn)Subset (keys kept)
array_reduce($a, $fn, $init)Single value
array_walk($a, $fn)true; edits in place

Useful Variants

⚠ Common Mistakes

  • Swapping argument order between array_map and array_filter
  • Assuming array_filter output is a list
  • Forgetting & in array_walk callbacks — nothing changes

✓ Tips & Best Practices

  • Chain with variables or the |> pipe (8.5)
  • Use array_column for lookup maps
  • Use a plain foreach when the logic gets long

Quick Summary

  • map → transform
  • filter → subset (keys kept)
  • reduce → one value
  • array_column for fields
