Sheet 75

Cloning & Comparing Objects

clone · shallow vs deep copy · clone with (8.5) · == vs === on objects · spl_object_id() · WeakMap

Copies and Identity

clone $obj makes a shallow copy: scalar and array properties are copied, but properties holding objects still point to the same objects unless __clone() copies them. PHP 8.5's clone with syntax copies and changes properties in one step — even readonly ones — ideal for immutable "withers". Compare objects with == (same class, equal properties) or === (same instance).

Notes

  • clone doesn't call the constructor
  • Arrays inside objects are copied (copy-on-write)
  • spl_object_id() is unique only among live objects
  • WeakMap lets you attach data to objects without leaking memory
  • Immutable objects remove most cloning worries

Clone, Withers & Comparison

<?php
final class Money
{
    public function __construct(
        public readonly int $amount,
        public readonly string $currency,
    ) {}

    public function withAmount(int $amount): static
    {
        return clone($this, ['amount' => $amount]);   // PHP 8.5
    }
}

$a = new Money(100, 'EUR');
$b = $a->withAmount(250);         // new object, EUR kept
$c = new Money(100, 'EUR');

var_dump($a == $c);               // true  (equal props)
var_dump($a === $c);              // false (different objects)
var_dump($a === $a);              // true

$cfg = new stdClass();
$cfg->db = new stdClass();
$copy = clone $cfg;
$copy->db->host = 'x';            // also changes $cfg->db!

$meta = new WeakMap();
$meta[$a] = ['cached' => true];   // freed when $a is freed
echo spl_object_id($a);           // e.g. 12

Code Explained

clone($obj, [...]) sets new values on the copy
Works on readonly properties (8.5)
== compares class and property values
=== checks identity
Shallow clone shares nested objects

⚠ Common Mistakes

  • Assuming clone is deep
  • Using == when identity matters (e.g. entity tracking)
  • Keying a plain array by spl_object_id and leaking memory

✓ Tips & Best Practices

  • Make value objects readonly and add withers
  • Use clone with on PHP 8.5+
  • Use WeakMap for per-object caches

Quick Summary

  • clone = shallow copy
  • clone($o, [...]) (8.5)
  • == values, === identity
  • WeakMap for metadata
