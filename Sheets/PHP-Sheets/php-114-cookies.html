Sheet 114

Cookies

setcookie() · options array · SameSite · HttpOnly · Secure · expiry · deleting cookies

Small Data in the Browser

A cookie is a name/value pair the browser stores and sends back with every matching request. Set one with setcookie() before output — it's a Set-Cookie header — and read incoming ones from $_COOKIE (a newly set cookie appears there only on the next request). Protect cookies with the Secure, HttpOnly and SameSite attributes, and never store secrets or trusted data in them unsigned.

Notes

  • Cookie size limit is about 4 KB
  • Delete by setting an expiry in the past with the same path/domain
  • SameSite=Lax is a sensible default; None requires Secure
  • Values are URL-encoded; setrawcookie() skips that
  • Users can read and edit cookies — treat them as input

Setting, Reading, Deleting

<?php
setcookie('theme', 'dark', [
    'expires'  => time() + 60 * 60 * 24 * 365,   // 1 year
    'path'     => '/',
    'secure'   => true,       // HTTPS only
    'httponly' => true,       // hidden from JavaScript
    'samesite' => 'Lax',      // CSRF protection
]);

$theme = $_COOKIE['theme'] ?? 'light';     // next request

// Delete: same name/path, expiry in the past
setcookie('theme', '', ['expires' => time() - 3600, 'path' => '/']);

// Tamper-evident value
$value = 'user:42';
$sig = hash_hmac('sha256', $value, $key);
setcookie('remember', "$value|$sig", ['httponly' => true,
    'secure' => true, 'samesite' => 'Strict', 'path' => '/']);

[$v, $s] = explode('|', $_COOKIE['remember'] ?? '|', 2);
$valid = hash_equals(hash_hmac('sha256', $v, $key), $s);

Code Explained

Options array form (7.3+) sets every attribute
httponly blocks document.cookie access
Read on later requests via $_COOKIE
Deleting needs matching path/domain
HMAC signature detects tampering

⚠ Common Mistakes

  • Calling setcookie() after output
  • Expecting $_COOKIE to update in the same request
  • Storing user IDs or roles in plain cookies

✓ Tips & Best Practices

  • Always set HttpOnly, Secure, SameSite
  • Sign or encrypt values you rely on
  • Keep auth state in sessions instead

Quick Summary

  • setcookie() before output
  • Read via $_COOKIE next request
  • Secure + HttpOnly + SameSite
  • Never trust cookie contents
