Sheet 35

Loop Controls

break · continue · break 2 · continue 2 · goto · exit / die

Changing Loop Flow

break leaves the loop immediately; continue skips to the next iteration. Both take an optional level number to affect outer loops: break 2 leaves two nested loops. switch counts as a loop level for this purpose. exit (alias die) ends the whole script, optionally printing a message or returning an exit code. goto exists but is almost never the right tool.

Notes

  • The level must be a literal integer (no variables)
  • continue inside switch behaves like break and warns
  • exit(1) sets the CLI exit status; exit('msg') prints
  • exit still runs shutdown functions and destructors
  • goto can't jump into a loop or switch

break, continue & Levels

<?php
foreach ([1, 2, 3, 4, 5, 6] as $n) {
    if ($n % 2 === 0) continue;     // skip evens
    if ($n > 4) break;              // stop at 5
    echo $n, ' ';                   // 1 3
}

$grid = [[1, 2], [3, 99], [5, 6]];
foreach ($grid as $r => $row) {
    foreach ($row as $c => $v) {
        if ($v === 99) {
            echo "found at $r,$c\n";
            break 2;                // leave both loops
        }
    }
}

foreach ($files as $f) {
    switch (pathinfo($f, PATHINFO_EXTENSION)) {
        case 'tmp':
            continue 2;             // next file, not next case
    }
    process($f);
}

if (!$config) exit("No config\n");  // stop script

Code Explained

continue jumps to the next element
break ends the loop at the first $n > 4
break 2 exits the inner and outer loop
continue 2 skips past the switch to the next file
exit with a string prints it and stops

⚠ Common Mistakes

  • Using continue inside switch meaning "next loop pass" — use continue 2
  • Calling exit deep inside reusable code
  • break $n with a variable — not allowed

✓ Tips & Best Practices

  • Extract nested loops into a function and return
  • Use exit codes in CLI scripts so callers can react
  • Throw exceptions instead of die() in apps

Quick Summary

  • break leaves, continue skips
  • Level numbers for nesting
  • switch is a level
  • exit stops everything
