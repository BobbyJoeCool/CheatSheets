Arrow Functions

fn () => · auto capture by value · single expression · nesting · arrow vs closure

Short Closures (PHP 7.4)

fn(params) => expression is a compact closure whose body is one expression that is returned automatically. Arrow functions capture outer variables by value automatically — no use list. They can't modify outer variables and can't contain statements, so for multi-line logic use a regular closure. Types, defaults, by-reference parameters and variadics all work.

Notes

  • Captured values are copied when the arrow function is created
  • Assigning to an outer variable inside has no outside effect
  • Arrow functions can be nested; each captures from its parent
  • $this is captured automatically inside methods
  • throw is allowed as the expression (PHP 8)

Arrow Functions in Practice

<?php
$nums = [1, 2, 3, 4, 5];
$factor = 10;

$scaled = array_map(fn($n) => $n * $factor, $nums);
// [10, 20, 30, 40, 50] — $factor captured automatically

$evens = array_filter($nums, fn(int $n): bool => $n % 2 === 0);

usort($users, fn($a, $b) => $a->age <=> $b->age);

$adder = fn($x) => fn($y) => $x + $y;   // nested
echo $adder(2)(3);                      // 5

$total = 0;
$add = fn($n) => $total += $n;          // modifies a copy
$add(5);
echo $total;                            // 0

$get = fn(array $a, string $k) => $a[$k]
    ?? throw new OutOfBoundsException($k);

Code Explained

No use needed — $factor is captured
Typed params and return type work like normal functions
Ideal inline comparator for usort()
Inner arrow fn captures $x from the outer one
Outer $total is untouched — capture is by value

⚠ Common Mistakes

  • Expecting fn to change outer variables
  • Trying to write return inside an arrow function
  • Cramming complex logic onto one line

✓ Tips & Best Practices

  • Default to fn for short callbacks
  • Switch to a named function once logic grows
  • Add types to arrow parameters for clarity

Quick Summary

  • fn($x) => expr
  • Auto-captures by value
  • One expression only
  • Great for map/filter/sort
