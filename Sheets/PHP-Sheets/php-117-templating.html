Separating Logic from HTML

PHP itself is a template language: plain PHP files with <?= ?> echo tags and alternative control syntax (foreach … endforeach) make readable views. Pass data in, render with output buffering to capture the result, and wrap pages in a layout. Escape every value you output. Template engines like Twig (Symfony) and Blade (Laravel) add auto-escaping, inheritance and a cleaner syntax.

Notes

  • Keep business logic out of templates
  • extract() turns an array into local variables — use only with trusted keys
  • Auto-escaping engines escape by default; mark trusted HTML explicitly
  • Compiled templates are cached PHP — fast
  • Short helper e() keeps escaping concise

A Tiny View Renderer

<?php
function e(?string $v): string {
    return htmlspecialchars($v ?? '', ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}

function render(string $view, array $data = []): string {
    extract($data, EXTR_SKIP);
    ob_start();
    require __DIR__ . "/views/$view.php";
    return ob_get_clean();
}

$content = render('products', ['products' => $list]);
echo render('layout', ['title' => 'Shop', 'content' => $content]);
?>
<!-- views/products.php -->
<ul>
<?php foreach ($products as $p): ?>
    <li class="<?= $p->onSale ? 'sale' : '' ?>">
        <?= e($p->name) ?> — <?= number_format($p->price, 2) ?>
    </li>
<?php endforeach; ?>
</ul>
<!-- views/layout.php -->
<title><?= e($title) ?></title>
<main><?= $content /* already-rendered HTML */ ?></main>

Code Explained

e() escapes for HTML attributes and text
extract + require exposes data as variables
Output buffering captures the view as a string
Alternative syntax reads cleanly inside HTML
Layout receives pre-rendered content

⚠ Common Mistakes

  • Echoing variables without escaping
  • Database queries inside templates
  • extract() on user input — can overwrite variables

✓ Tips & Best Practices

  • Escape by default, opt out deliberately
  • Use an engine with auto-escaping for teams
  • Keep templates dumb: data in, HTML out

Quick Summary

  • PHP is a template language
  • <?= e($x) ?> everywhere
  • Buffer + layout
