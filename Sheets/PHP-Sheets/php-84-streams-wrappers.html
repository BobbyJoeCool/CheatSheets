Streams & Wrappers

php://input · php://stdin · php://memory · php://temp · stream_context_create() · data:// · compress.zlib://

One API for Many Sources

PHP's file functions work on streams, and a wrapper prefix decides what a stream points to: file:// (default), http://, php://, data://, compress.zlib:// and more. php://input reads a raw request body, php://stdin / stdout / stderr are the CLI channels, and php://memory / php://temp give in-memory buffers. Stream contexts pass options such as HTTP headers or timeouts.

Notes

  • php://temp spills to disk after 2 MB (configurable)
  • php://input isn't available for multipart/form-data
  • allow_url_fopen controls remote wrappers
  • stream_get_wrappers() lists what's registered
  • Register your own with stream_wrapper_register()

Wrappers and Contexts

<?php
// JSON request body (POST/PUT)
$payload = json_decode(file_get_contents('php://input'), true);

// CLI streams
$name = trim(fgets(STDIN));
fwrite(STDERR, "warn\n");

// In-memory buffer, then read back
$buf = fopen('php://temp', 'w+');
fputcsv($buf, ['a', 'b'], escape: '');
rewind($buf);
$csv = stream_get_contents($buf);     // "a,b\n"

// HTTP with a context
$ctx = stream_context_create(['http' => [
    'method'  => 'POST',
    'header'  => "Content-Type: application/json\r\n",
    'content' => json_encode(['q' => 'php']),
    'timeout' => 5,
]]);
$res = file_get_contents('https://api.example.com/search', false, $ctx);

$gz   = file_get_contents('compress.zlib://archive.log.gz');
$data = file_get_contents('data://text/plain;base64,SGVsbG8=');  // Hello

Code Explained

php://input holds the raw body
STDIN / STDERR constants in the CLI
php://temp buffers CSV in memory
Context options configure HTTP method, headers, timeout
Wrappers decompress or decode on the fly

⚠ Common Mistakes

  • Reading php://input on multipart uploads — use $_FILES
  • Remote file_get_contents without a timeout
  • Using http:// wrappers where a proper HTTP client is needed

✓ Tips & Best Practices

  • Use php://temp for building files in memory
  • Use Guzzle or Symfony HttpClient for real HTTP work (Sheet 101)
  • Disable allow_url_include always
