true, false and Truthiness

bool has two values, true and false (case-insensitive). Any value can be used in a condition; PHP converts it to bool. A short list of values is falsy — everything else is truthy. The surprise is that the string "0" is falsy while "0.0", " " and "false" are truthy. empty($x) is !isset($x) || !$x and never warns about undefined variables.

Notes

  • Empty arrays are falsy; all objects are truthy
  • (bool) / boolval() convert explicitly
  • true echoes as 1; false echoes as an empty string
  • filter_var($s, FILTER_VALIDATE_BOOL) parses "yes", "on", "1"
  • Comparison operators always return a bool

Truthiness in Practice

<?php
$vals = [0, 0.0, '', '0', [], null, '0.0', ' ', 'false', [0]];
foreach ($vals as $v) {
    echo json_encode($v), ' => ', $v ? 'truthy' : 'falsy', "\n";
}
// 0 falsy, 0.0 falsy, "" falsy, "0" falsy, [] falsy,
// null falsy, "0.0" truthy, " " truthy, "false" truthy,
// [0] truthy

echo true;     // 1
echo false;    // (nothing)

var_dump(empty($missing));                    // true, no warning
var_dump(filter_var('off', FILTER_VALIDATE_BOOL)); // false
var_dump((bool) 'false');                     // true

Code Explained

Eight falsy values: false 0 0.0 -0.0 "" "0" [] null
A non-empty array is truthy even if it holds only 0
echo false prints nothing — use var_dump to see it
empty() is safe on undefined variables
Casting the string 'false' gives true

⚠ Common Mistakes

  • if ($count) where 0 is a valid result — test !== null instead
  • if (strpos($s, 'a')) — position 0 is falsy (use str_contains)
  • Parsing "false" from config with (bool)

✓ Tips & Best Practices

  • Use strict comparisons when 0 or "" is meaningful
  • Use FILTER_VALIDATE_BOOL for user/config input
  • Use var_dump when debugging booleans

Quick Summary
