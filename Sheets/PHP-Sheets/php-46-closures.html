Anonymous Functions & Closures

function () use ($x) · use (&$x) · Closure::bind() · bindTo() · static function · $this binding

Functions as Values

An anonymous function (function () { … }) is an expression that creates a Closure object. You can store it, pass it to other functions, and return it. A closure doesn't see outer variables automatically: list them in use (…). use ($x) copies the value at creation time; use (&$x) binds by reference. Closures created inside a class method automatically get $this.

Notes

  • The use value is captured when the closure is created, not when it runs
  • static function () { … } doesn't bind $this (slightly cheaper)
  • Closure::bind() / bindTo() change $this and scope
  • $closure->call($obj, …) binds and calls in one step
  • Closures can be type-hinted as Closure or callable

use, References & Binding

<?php
$tax = 0.2;
$withTax = function (float $p) use ($tax): float {
    return $p * (1 + $tax);
};
$tax = 0.5;                       // closure still uses 0.2
echo $withTax(10);                // 12

$count = 0;
$inc = function () use (&$count) { $count++; };
$inc(); $inc();
echo $count;                      // 2

function multiplier(int $n): Closure
{
    return function (int $x) use ($n) { return $x * $n; };
}
$triple = multiplier(3);
echo $triple(5);                  // 15

class Counter { private int $n = 41; }
$peek = function () { return ++$this->n; };
echo Closure::bind($peek, new Counter, Counter::class)(); // 42

Code Explained

use ($tax) snapshots the value
use (&$count) shares the variable
Returning a closure creates a function factory
Each call to multiplier() captures its own $n
bind() gives access to private members of another class

⚠ Common Mistakes

  • Expecting changes after creation to show up with use ($x)
  • Forgetting use and getting "Undefined variable"
  • Capturing large objects in long-lived closures — memory stays alive

✓ Tips & Best Practices

  • Prefer arrow functions for one-line callbacks
  • Use static closures in classes when you don't need $this
  • Capture by value unless you truly need shared state
