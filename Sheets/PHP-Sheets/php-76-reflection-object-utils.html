Inspecting Code at Runtime

Simple questions — what class is this, does it have that method — are answered by functions such as get_class(), method_exists() and property_exists(). The Reflection API goes much further: ReflectionClass, ReflectionMethod, ReflectionProperty and friends expose names, types, attributes, doc comments and parameters, and can even create objects without constructors. Frameworks use it for dependency injection, routing and serialisation.

Notes

  • Reflection ignores visibility for reading metadata
  • setAccessible() is no longer needed (8.1+)
  • getAttributes() reads #[...] attributes (Sheet 103)
  • Reflection is slower — cache results in hot paths
  • class_exists() triggers autoloading by default

Introspection and Reflection

<?php
class User
{
    public function __construct(
        public int $id,
        private string $email = '',
    ) {}
    public function greet(string $g = 'Hi'): string
    { return $g; }
}
$u = new User(1);

echo $u::class;                       // User
method_exists($u, 'greet');           // true
property_exists(User::class, 'email');// true (even private)
get_object_vars($u);                  // ['id' => 1] from outside
class_exists('User');                 // true

$rc = new ReflectionClass(User::class);
foreach ($rc->getConstructor()->getParameters() as $p) {
    echo $p->getName(), ': ', $p->getType(),
         $p->isOptional() ? ' (optional)' : '', "\n";
}
// id: int
// email: string (optional)

$rp = new ReflectionProperty(User::class, 'email');
echo $rp->getValue($u);               // '' — private read
$rm = new ReflectionMethod(User::class, 'greet');
echo $rm->invoke($u, 'Hello');        // Hello
$blank = $rc->newInstanceWithoutConstructor();

Code Explained

::class on an object gives its class name
property_exists sees private properties too
get_object_vars respects the caller's scope
Reflection lists constructor parameters and types — the basis of autowiring
Reflection can read private values and call methods

⚠ Common Mistakes

  • Using reflection in tight loops without caching
  • Calling private methods via reflection in production code to work around design
  • class_exists($name, false) when you need autoloading

✓ Tips & Best Practices

  • Use simple functions for simple checks
  • Cache reflection results (frameworks do this)
  • Use attributes + reflection for metadata-driven code
