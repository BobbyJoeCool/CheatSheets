Arrays of Arrays

Arrays can contain other arrays to any depth: tables of rows, trees of categories, matrices of numbers. Access nested values by chaining brackets, and use ?? to avoid warnings on missing levels. Because arrays are values, copying a nested array copies everything (lazily) — but arrays of objects copy only the handles. Common jobs are extracting a column, grouping rows by a field, and walking all leaves.

Notes

  • Writing to a missing nested key auto-creates the levels
  • $a['x']['y'] ?? null is safe even if 'x' is missing
  • count($a, COUNT_RECURSIVE) counts all elements at all levels
  • Use json_encode with JSON_PRETTY_PRINT to inspect deep data
  • Large row sets: prefer generators over loading everything

Working with Nested Data

<?php
$orders = [
    ['id' => 1, 'user' => 'ana', 'total' => 30],
    ['id' => 2, 'user' => 'bo',  'total' => 15],
    ['id' => 3, 'user' => 'ana', 'total' => 20],
];

echo $orders[1]['user'];                 // bo
$byId   = array_column($orders, null, 'id');  // index rows by id
$totals = array_column($orders, 'total');      // [30, 15, 20]

$byUser = [];
foreach ($orders as $o) {
    $byUser[$o['user']][] = $o;          // group (auto-creates)
}
// ['ana' => [..2 rows..], 'bo' => [..1 row..]]

$sum  = fn($rows) => array_sum(array_column($rows, 'total'));
$sums = array_map($sum, $byUser);        // ['ana' => 50, 'bo' => 15]

$grid = [[1, 2, 3], [4, 5, 6]];
foreach ($grid as $r => $row) {
    foreach ($row as $c => $val) { /* $grid[$r][$c] */ }
}
$city = $data['user']['address']['city'] ?? 'unknown';

Code Explained

Chain brackets for nested access
array_column($rows, null, 'id') keys whole rows by id
$g[$key][] = builds groups in one pass
Combine array_map + array_column for per-group sums
?? guards every missing level

⚠ Common Mistakes

  • Deep nesting where a class would be clearer
  • Reading deep keys without ??
  • Expecting array copies to deep-copy objects inside them

✓ Tips & Best Practices

  • Index rows by id with array_column(…, null, 'id')
  • Group in one foreach pass
  • Convert stable shapes to DTO classes

Quick Summary

  • Arrays nest to any depth
  • ?? for safe deep reads
  • array_column for rows
  • Group with $g[$k][] = $row
