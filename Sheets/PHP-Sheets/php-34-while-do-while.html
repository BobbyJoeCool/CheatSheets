Sheet 34

while & do-while

while · do…while · endwhile · while ($row = …) · infinite loops

Condition-Driven Loops

while checks its condition before each pass, so the body may run zero times. do … while checks after, so the body always runs at least once. Use them when you don't know the number of iterations in advance: reading lines until end of file, fetching rows until none are left, retrying until success. Make sure something in the body moves toward the exit.

Notes

  • do … while needs a semicolon after while (...)
  • while (true) + break is fine for event loops
  • Assignment in the condition is idiomatic for readers and cursors
  • Compare with !== false when 0 or '' are valid values
  • Alternative syntax: while (...): … endwhile;

while and do-while

<?php
$n = 3;
while ($n > 0) {
    echo $n--, ' ';                 // 3 2 1
}

$fh = fopen('log.txt', 'r');
while (($line = fgets($fh)) !== false) {
    echo trim($line), "\n";
}
fclose($fh);

while ($row = $stmt->fetch(PDO::FETCH_ASSOC)) {
    process($row);                  // until fetch returns false
}

$attempt = 0;
do {
    $ok = tryConnect();
    $attempt++;
} while (!$ok && $attempt < 3);     // runs at least once

while (true) {
    $job = $queue->pop();
    if ($job === null) break;
    $job->run();
}

Code Explained

The counter changes inside the body, so the loop ends
Wrap the assignment in parentheses before !==
fetch() returns false when rows run out
do … while retries at least once
Infinite loop with an explicit break

⚠ Common Mistakes

  • Forgetting to change the loop variable — infinite loop
  • while (!feof($f)) that processes a final false line
  • Missing the ; after do { } while (...)

✓ Tips & Best Practices

  • Use a generator + foreach for unbounded streams
  • Add a max-iterations guard to retry loops
  • Use !== false with readers that can return '0'

Quick Summary

  • while checks first
  • do … while runs once minimum
  • Assign-in-condition for readers
  • Always progress toward exit
