Enumerations (8.1)

An enum defines a type with a fixed set of possible values called cases. A pure enum has cases only; a backed enum gives each case a scalar value (int or string) for storing in databases and JSON. Enums are objects: each case is a singleton, comparisons use ===, and enums can have methods, constants, static methods and implement interfaces. They pair perfectly with match.

Notes

  • Suit::Hearts is an instance of Suit
  • Backed enums: ->value; all enums: ->name
  • from() throws ValueError; tryFrom() returns null
  • Enums can't have state (no properties besides name/value)
  • Enum constants in const expressions work (Status::Active->value since 8.2)

Pure and Backed Enums

<?php
enum Status: string
{
    case Draft = 'draft';
    case Published = 'published';
    case Archived = 'archived';

    public function label(): string
    {
        return match ($this) {
            self::Draft     => 'Draft',
            self::Published => 'Live',
            self::Archived  => 'Archived',
        };
    }

    public static function visible(): array
    {
        return [self::Published];
    }
}

$s = Status::from('published');     // Status::Published
$t = Status::tryFrom('nope');       // null
echo $s->value, ' ', $s->name;      // published Published
echo $s->label();                   // Live
var_dump($s === Status::Published); // true
Status::cases();                    // all three cases

enum Suit { case Hearts; case Spades; }   // pure enum
function paint(Suit $s): void {}          // type-safe param

Code Explained

: string makes it a backed enum
match ($this) is exhaustive — no default needed
from() converts stored values back to cases
->value for storage, ->name for the identifier
Pure enums are perfect as parameter types

⚠ Common Mistakes

  • Comparing $case == 'draft' — compare $case->value or the case itself
  • Using from() on untrusted input without catching ValueError
  • Adding default to enum match and hiding missing cases

✓ Tips & Best Practices

  • Store ->value, rebuild with from()
  • Put labels and rules as enum methods
  • Prefer enums over string/int constants
