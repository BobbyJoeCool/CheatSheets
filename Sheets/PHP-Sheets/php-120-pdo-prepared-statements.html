PDO — Prepared Statements

prepare() · execute() · :named · ? positional · bindValue() · bindParam() · PDO::PARAM_INT

Queries Without SQL Injection

A prepared statement sends the SQL with placeholders first and the values separately, so user input can never change the query's structure. Use named (:email) or positional (?) placeholders, then call execute() with an array of values. bindValue() binds a value with an explicit type; bindParam() binds a variable by reference. Prepare once and execute many times for bulk work.

Notes

  • Placeholders work for values only — not table or column names
  • Don't mix named and positional placeholders in one query
  • execute() array values are bound as strings unless you bindValue types
  • rowCount() gives affected rows for INSERT/UPDATE/DELETE
  • lastInsertId() returns the new auto-increment key

Prepare, Bind, Execute

<?php
// Named placeholders
$stmt = $pdo->prepare('SELECT id, name FROM users WHERE email = :email');
$stmt->execute(['email' => $_POST['email']]);
$user = $stmt->fetch();                     // array or false

// Positional placeholders
$stmt = $pdo->prepare('UPDATE users SET name = ? WHERE id = ?');
$stmt->execute([$name, $id]);
echo $stmt->rowCount(), ' row(s) updated';

// Typed binding (LIMIT needs an int)
$stmt = $pdo->prepare('SELECT * FROM posts ORDER BY id DESC LIMIT :n');
$stmt->bindValue(':n', $limit, PDO::PARAM_INT);
$stmt->execute();

// Prepare once, run many
$ins = $pdo->prepare('INSERT INTO tags (name) VALUES (?)');
foreach (['php', 'sql', 'web'] as $tag) {
    $ins->execute([$tag]);
}
$newId = $pdo->lastInsertId();

// IN (...) with a dynamic list
$ids = [3, 5, 8];
$in  = implode(',', array_fill(0, count($ids), '?'));
$stmt = $pdo->prepare("SELECT * FROM users WHERE id IN ($in)");
$stmt->execute($ids);

Code Explained

:email is filled from the array key
? placeholders are filled in order
bindValue with PARAM_INT for LIMIT/OFFSET
Reuse one statement in a loop
Build one ? per item for IN lists

⚠ Common Mistakes

  • Concatenating input into SQL: "... WHERE id = $id"
  • Trying to bind a column name as a placeholder
  • Passing LIMIT values as strings — breaks with emulated prepares

✓ Tips & Best Practices

  • Prepare every query that has variables
  • Allow-list identifiers you can't bind
  • Wrap repeated inserts in a transaction (Sheet 122)

Quick Summary

  • prepare + execute([...])
  • :named or ?
  • Values only, never identifiers
  • bindValue for types
