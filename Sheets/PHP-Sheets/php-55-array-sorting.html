Sheet 55

Sorting Arrays

sort() · asort() · ksort() · usort() · uasort() · uksort() · SORT_ flags · stable sort

Ordering Arrays

Sort functions modify the array in place and return true. The name tells you what they do: plain sort sorts values and reindexes; a-prefixed functions keep key ⇄ value association; k functions sort by key; r means reverse; u means you supply a comparison callback, usually written with <=>. Since PHP 8.0 all sorts are stable: equal elements keep their original order.

Notes

  • sort() throws away string keys
  • Callbacks return negative, zero or positive — <=> does this
  • Sort by several fields: [$a->x, $a->y] <=> [$b->x, $b->y]
  • SORT_NATURAL orders img2 before img10
  • array_multisort() sorts parallel arrays together

Sorting Examples

<?php
$n = [3, 1, 2];
sort($n);                       // [1, 2, 3]
rsort($n);                      // [3, 2, 1]

$ages = ['Bo' => 30, 'Ana' => 25, 'Cy' => 35];
asort($ages);                   // by value, keep keys
// ['Ana' => 25, 'Bo' => 30, 'Cy' => 35]
ksort($ages);                   // by key
arsort($ages);                  // by value, descending

$users = [
    ['name' => 'Bo',  'age' => 30],
    ['name' => 'Ana', 'age' => 30],
    ['name' => 'Cy',  'age' => 25],
];
usort($users, fn($a, $b) =>
    [$a['age'], $a['name']] <=> [$b['age'], $b['name']]);
// Cy 25, Ana 30, Bo 30

$files = ['img12', 'img10', 'IMG2'];
sort($files, SORT_NATURAL | SORT_FLAG_CASE);
// ['IMG2', 'img10', 'img12']

Code Explained

sort / rsort reindex 0…n-1
asort sorts values but keeps keys
ksort orders by key
Array <=> compares element by element — multi-field sort
Flags combine natural order with case-insensitivity

⚠ Common Mistakes

  • $sorted = sort($a); — $sorted is true
  • Using sort() on a map and losing keys
  • Returning a bool from a usort callback

✓ Tips & Best Practices

  • Pick the a/k variant whenever keys matter
  • Write comparators with <=>
  • Sort a copy if the original order matters later

Quick Summary

  • Sorts modify in place
  • a keeps keys, k by key
  • u + <=> callback
  • Stable since 8.0
