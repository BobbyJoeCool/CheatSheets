XML & HTML Parsing

SimpleXMLElement · simplexml_load_string() · DOMDocument · DOMXPath · XMLReader · Dom\HTMLDocument (8.4)

Reading Markup

SimpleXML turns XML into objects you navigate with -> and [] — the easiest option for simple documents. DOM (DOMDocument, DOMXPath) gives full read/write control and XPath queries. XMLReader streams huge files node by node. For HTML, PHP 8.4's Dom\HTMLDocument parses real-world HTML5 correctly and supports CSS selectors via querySelector().

Notes

  • SimpleXML values are objects — cast with (string) or (int)
  • Attributes: $node['id']
  • Old DOMDocument::loadHTML() is HTML4-based and noisy
  • External entity loading is disabled by default (XXE safe since 8.0)
  • XMLWriter builds large XML efficiently

SimpleXML, XPath, HTML5

<?php
$xml = <<<XML
<catalog>
  <book id="1"><title>PHP</title><price>29.50</price></book>
  <book id="2"><title>SQL</title><price>19.00</price></book>
</catalog>
XML;

$cat = simplexml_load_string($xml);
foreach ($cat->book as $book) {
    echo $book['id'], ': ', $book->title, "\n";
    $total = ($total ?? 0) + (float) $book->price;
}
$cheap = $cat->xpath('//book[price < 20]/title');   // [SQL]

$dom = new DOMDocument();
$dom->loadXML($xml);
$xp = new DOMXPath($dom);
echo $xp->query('//book[@id="2"]/title')->item(0)->textContent;

$html = '<main><a class="nav" href="/a">A</a><a href="/b">B</a></main>';
$doc = Dom\HTMLDocument::createFromString($html, LIBXML_NOERROR);
foreach ($doc->querySelectorAll('a.nav') as $a) {
    echo $a->getAttribute('href');                    // /a
}

⚠ Common Mistakes

  • Comparing SimpleXML nodes without casting
  • Parsing HTML with regex
  • Loading huge XML into DOM — memory explodes

✓ Tips & Best Practices

  • Use XMLReader for large feeds
  • Use Dom\HTMLDocument for scraping on 8.4+
  • Use libxml_use_internal_errors(true) to collect parse errors

Quick Summary

  • SimpleXML for easy reading
  • DOM + XPath for control
  • XMLReader for size
  • Dom\HTMLDocument for HTML5
