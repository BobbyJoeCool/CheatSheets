System & Environment

getenv() · $_ENV · PHP_OS_FAMILY · ini_get() · ini_set() · exec() · proc_open() · escapeshellarg()

Talking to the System

Read environment variables with getenv() (or $_ENV / $_SERVER, depending on variables_order). Runtime settings can be read with ini_get() and some changed with ini_set(). To run external commands, use exec(), shell_exec(), system() or proc_open() for full control. Every value passed to a shell must be escaped with escapeshellarg() to prevent command injection.

Notes

  • $_ENV is often empty — variables_order lacks E by default in production ini
  • Libraries like vlucas/phpdotenv load .env files
  • PHP_OS_FAMILY: Linux, Darwin, Windows, BSD
  • Shell functions may be disabled via disable_functions
  • Symfony Process is a robust proc_open wrapper

Environment and Commands

<?php
$dbHost = getenv('DB_HOST') ?: 'localhost';
$debug  = filter_var(getenv('APP_DEBUG'), FILTER_VALIDATE_BOOL);
putenv('TZ=UTC');                       // for this process

echo PHP_OS_FAMILY, ' ', php_uname('m');  // Linux x86_64
echo ini_get('memory_limit');           // 128M
ini_set('memory_limit', '512M');        // where allowed
echo memory_get_peak_usage(true);       // bytes

$file = $_GET['file'] ?? 'report.txt';
exec('wc -l ' . escapeshellarg($file), $out, $code);
echo $out[0], ' (exit ', $code, ')';

$proc = proc_open(['git', 'log', '-1', '--format=%h'],   // array: no shell
    [1 => ['pipe', 'w'], 2 => ['pipe', 'w']], $pipes);
$hash = trim(stream_get_contents($pipes[1]));
proc_close($proc);

echo gethostname(), ' pid ', getmypid();

Code Explained

?: supplies a default when the variable is unset/empty
FILTER_VALIDATE_BOOL parses "true"/"1"/"on"
ini_set only works for settings changeable at runtime
escapeshellarg() quotes user input for the shell
proc_open with an array bypasses the shell (7.4+)

⚠ Common Mistakes

  • Concatenating user input into shell commands
  • Hard-coding secrets instead of reading environment variables
  • Relying on $_ENV without checking variables_order

✓ Tips & Best Practices

  • Pass commands as arrays to proc_open
  • Use Symfony Process for timeouts and streaming
  • Read config from the environment, with defaults

Quick Summary

  • getenv() for config
  • ini_get / ini_set
  • escapeshellarg() always
  • proc_open([...]) avoids the shell
