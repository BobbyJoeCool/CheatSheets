Sheet 38

Throwing & SPL Exceptions

throw · throw as expression · InvalidArgumentException · RuntimeException · LogicException · ValueError

Signalling Failure

throw raises any object that implements Throwable (in practice, an Exception subclass). Since PHP 8 throw is an expression, so it can appear after ??, ?:, in arrow functions and in match arms. The SPL exceptions give you ready-made types with clear meanings: LogicException branches for bugs in the calling code, RuntimeException branches for problems only detectable at runtime.

Notes

  • Throw specific types so callers can catch selectively
  • Messages should say what was wrong and with which value
  • Built-in functions throw ValueError / TypeError for bad arguments
  • Don't throw Error subclasses yourself — they're for the engine
  • Document thrown types with @throws

Throwing the Right Type

<?php
function setAge(int $age): void
{
    if ($age < 0 || $age > 150) {
        throw new InvalidArgumentException(
            "Age must be 0-150, got $age"
        );
    }
}

function withdraw(float $amt, float $balance): float
{
    if ($amt > $balance) {
        throw new UnderflowException('Insufficient funds');
    }
    return $balance - $amt;
}

$id = $_GET['id'] ?? throw new OutOfBoundsException('No id');
$fn = fn($x) => $x ?: throw new LengthException('Empty');

try {
    str_repeat('x', -1);
} catch (ValueError $e) {
    echo $e->getMessage();
    // str_repeat(): Argument #2 ($times) must be
    //   greater than or equal to 0
}

Code Explained

InvalidArgumentException — caller passed a bad value
UnderflowException — a runtime condition, not a bug
?? throw — fail fast on a missing input
throw inside an arrow function body
Engine argument checks throw ValueError

⚠ Common Mistakes

  • Throwing plain Exception for everything
  • Messages with no context ("Error occurred")
  • Using exceptions for normal control flow (e.g. "not found" in a loop)

✓ Tips & Best Practices

  • Pick the most specific SPL class, or subclass it (Sheet 39)
  • Include the bad value in the message
  • Use ?? throw for required inputs

Quick Summary

  • throw new X('msg')
  • throw is an expression (8.0)
  • Logic = caller bug, Runtime = environment
  • Engine throws TypeError / ValueError
