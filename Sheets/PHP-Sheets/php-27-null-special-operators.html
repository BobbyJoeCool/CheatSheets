Sheet 27

Null-Safe & Special Operators

?? · ??= · ?: · ?-> · @ suppression · ... spread · |> pipe (8.5)

Shortcuts for Common Patterns

?? (null coalescing) returns the left side unless it is null or undefined — without warnings. ?: (short ternary) returns the left side if it is truthy. ?-> (nullsafe) stops a property or method chain and returns null when it hits null. ... spreads arrays into calls and array literals. PHP 8.5 adds the pipe operator |>, which passes a value into a callable.

Notes

  • ?? checks for null only; ?: treats 0, '', '0' as missing too
  • ?? and ?-> don't raise undefined-index/variable warnings
  • ?-> can't be used for writing ($a?->b = 1 is an error)
  • @ hides warnings but slows code and hides bugs
  • |> right side must be a callable taking one argument

Null Handling, Spread & Pipe

<?php
$page = $_GET['page'] ?? 1;            // no warning if missing
$name = $input['name'] ?: 'Anonymous'; // '' -> Anonymous
$opts['limit'] ??= 20;                 // default if unset

$city = $user?->getAddress()?->city;   // null if any is null
$len  = $user?->name ? strlen($user->name) : 0;

function sum(int ...$n): int { return array_sum($n); }
$nums = [1, 2, 3];
echo sum(...$nums);                    // 6
$all = [...$nums, 4, ...[5, 6]];       // [1..6]

$ok = @file_get_contents('missing.txt');  // false, silent

// PHP 8.5 pipe operator
$slug = '  Hello World  '
    |> trim(...)
    |> strtolower(...)
    |> (fn($s) => str_replace(' ', '-', $s));
// 'hello-world'

Code Explained

?? — default for missing keys and nulls
?: — default for any falsy value
?-> — short-circuits the whole rest of the chain
...$nums unpacks into arguments or array elements
Each |> step receives the previous result

⚠ Common Mistakes

  • Using ?: when 0 is a valid value — use ??
  • Silencing errors with @ instead of checking return values
  • Expecting ?-> to also guard array access — use ?? for keys

✓ Tips & Best Practices

  • Use ?? for all request/array defaults
  • Replace nested null checks with ?->
  • Use |> for readable transformation chains (8.5+)

Quick Summary

  • ?? = null default
  • ?: = falsy default
  • ?-> = null-safe chain
  • ... spread, |> pipe
