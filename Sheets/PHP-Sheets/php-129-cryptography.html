Sheet 129

Hashing, HMAC & Encryption

hash() · hash_hmac() · sodium_crypto_secretbox() · sodium_crypto_box() · openssl_encrypt() · random_bytes()

Choosing the Right Primitive

A hash (hash('sha256', $data)) fingerprints data — fine for checksums, never for passwords. An HMAC (hash_hmac()) adds a secret key so only key holders can create a valid signature — use it to verify tokens and webhooks. Encryption hides data and is reversible with the key: use libsodium (sodium_crypto_secretbox() for one shared key, sodium_crypto_box() for public-key) — it's built in and hard to misuse.

Notes

  • Never invent your own crypto schemes
  • Keys come from random_bytes() or sodium_crypto_*_keygen()
  • A nonce must never repeat with the same key
  • Prefer authenticated encryption (secretbox, AES-GCM)
  • Wipe secrets with sodium_memzero() when done

Hash, HMAC, Encrypt

<?php
// Integrity / fingerprint
hash('sha256', 'hello');               // 2cf24dba5fb0a30e…
hash_file('sha256', 'release.zip');    // checksum

// Authenticity: HMAC-signed webhook
$expected = hash_hmac('sha256', $rawBody, $webhookSecret);
if (!hash_equals($expected, $_SERVER['HTTP_X_SIGNATURE'] ?? '')) {
    http_response_code(401); exit;
}

// Secret-key authenticated encryption (libsodium)
$key   = sodium_crypto_secretbox_keygen();          // store safely
$nonce = random_bytes(SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
$box   = sodium_crypto_secretbox('card ****4242', $nonce, $key);
$stored = base64_encode($nonce . $box);

$raw   = base64_decode($stored);
$n     = substr($raw, 0, SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
$c     = substr($raw, SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
$plain = sodium_crypto_secretbox_open($c, $n, $key);  // false if tampered

// OpenSSL AES-256-GCM (when interoperability requires it)
$iv  = random_bytes(12);
$enc = openssl_encrypt('data', 'aes-256-gcm', $aesKey, 0, $iv, $tag);

Code Explained

Plain hash: anyone can recompute it
HMAC: only holders of the secret can sign
hash_equals prevents timing attacks
Store nonce + ciphertext together; never reuse a nonce
Decryption returns false if data was modified

⚠ Common Mistakes

  • Using md5/sha1 for security
  • Reusing a nonce/IV with the same key
  • Comparing signatures with ==

✓ Tips & Best Practices

  • Prefer libsodium over OpenSSL for new code
  • Use HMAC for webhooks and signed URLs
  • Keep keys out of the codebase

Quick Summary

  • Hash ≠ HMAC ≠ encryption
  • hash_hmac + hash_equals
  • libsodium secretbox
  • Unique nonces, safe keys
