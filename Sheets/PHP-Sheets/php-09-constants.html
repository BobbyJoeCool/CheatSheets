Sheet 09

Constants & Magic Constants

const · define() · defined() · __LINE__ · __FILE__ · __DIR__ · PHP_INT_MAX · PHP_VERSION

Values That Don't Change

A constant holds a value that can't be reassigned. Use const at the top level or inside a class; use define() when the name or value is computed at runtime or the code is inside a function or if. Constants have no $ and are global (or class-scoped). PHP also has magic constants such as __DIR__ and __LINE__ whose value depends on where they appear.

Notes

  • Constant values: scalars, arrays, enums, and objects (via new in const expressions, 8.1+)
  • Convention: UPPER_SNAKE_CASE
  • const names are resolved at compile time and respect namespaces
  • Undefined constant → Error in PHP 8 (no more string fallback)
  • Class constants: self::MAX, Order::STATUS_NEW (Sheet 67)

Defining & Using Constants

<?php
const APP_NAME = 'Shop';
const RATES = ['std' => 0.2, 'low' => 0.05];

if (!defined('DEBUG')) {
    define('DEBUG', getenv('APP_DEBUG') === '1');
}

echo APP_NAME;                // Shop
echo RATES['low'];            // 0.05
echo constant('APP_NAME');    // dynamic lookup

echo __FILE__;   // /app/src/config.php
echo __DIR__;    // /app/src
echo __LINE__;   // 15
echo PHP_INT_MAX;             // 9223372036854775807

Code Explained

const at file level — simple, compile-time
define() inside if — runtime, conditional
defined('NAME') — avoids redefinition errors
constant() reads a constant by string name
__DIR__ is the directory of this file

⚠ Common Mistakes

  • Writing $APP_NAME — constants have no $
  • Calling define() twice for one name — Warning, value unchanged
  • Using const inside an if block — syntax error

✓ Tips & Best Practices

  • Prefer class constants or enums over global constants
  • Use __DIR__ for all include paths
  • Keep secrets in environment variables, not constants in code

Quick Summary

  • const X = 1; at top level
  • define() at runtime
  • No $, can't reassign
  • Magic constants: __DIR__, __LINE__
