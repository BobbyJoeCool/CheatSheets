Assignment and Evaluation Order

= stores the right-hand value and the whole expression evaluates to that value, so $a = $b = 5 works. Compound operators combine an operation with assignment: $total += $price, $html .= '<li>'. When an expression mixes operators, precedence decides what binds first and associativity decides the direction for equal precedence. When in doubt, add parentheses.

Notes

  • Assignment is right-associative: $a = ($b = 5)
  • .= is the idiomatic way to build strings
  • ??= assigns only if the left side is null or unset
  • In PHP 8, + and - bind tighter than .
  • Non-associative operators (==, <) can't be chained: 1 < $x < 5 is an error

Compound Assignment

<?php
$total = 0;
$total += 10;      // 10
$total -= 3;       // 7
$total *= 2;       // 14
$total /= 4;       // 3.5
$total **= 2;      // 12.25
$n = 17; $n %= 5;  // 2

$html = '<ul>';
foreach (['a', 'b'] as $item) {
    $html .= "<li>$item</li>";
}
$html .= '</ul>';

$opts['debug'] ??= false;   // set if missing

echo 'Sum: ' . 1 + 2;       // 'Sum: 3' in PHP 8
echo 2 + 3 * 4;             // 14
echo (2 + 3) * 4;           // 20
echo 2 ** 3 ** 2;           // 512 (right-assoc)

Code Explained

Each compound operator reads, computes, writes back
.= appends to the string in place
??= won't overwrite an existing non-null value
PHP 8: + evaluates before .
** groups from the right

⚠ Common Mistakes

  • 1 < $x < 5 — write 1 < $x && $x < 5
  • Relying on precedence across . and + without parentheses
  • Using = where == was meant inside if

✓ Tips & Best Practices

  • Parenthesise anything a reader might misread
  • Use .= in loops instead of building arrays when output is small
  • Use ??= to fill defaults in option arrays

Quick Summary

  • = returns the value
  • Compound: += .= ??=
  • Precedence then associativity
  • Parentheses beat memorising
