Command-Line PHP

PHP is a capable scripting language for the terminal. Arguments arrive in $argv (with $argv[0] the script name) and their count in $argc. getopt() parses short (-v) and long (--limit=5) options. Read input from STDIN, write results to STDOUT and diagnostics to STDERR, and finish with exit codes (0 = success) so other tools can react. For larger tools, use Symfony Console.

Notes

  • CLI has no max_execution_time by default
  • Guard CLI-only scripts with PHP_SAPI === 'cli'
  • $_SERVER['argv'] is also available
  • readline() prompts interactively (readline ext)
  • pcntl_signal() handles Ctrl-C (SIGINT) gracefully

A Small CLI Tool

#!/usr/bin/env php
<?php
declare(strict_types=1);

if (PHP_SAPI !== 'cli') { exit("CLI only\n"); }

$opts = getopt('vn:', ['limit:', 'dry-run', 'help'], $rest);
if (isset($opts['help'])) {
    echo "Usage: tool.php [-v] [--limit=N] FILE\n";
    exit(0);
}
$verbose = isset($opts['v']);
$limit   = (int) ($opts['limit'] ?? $opts['n'] ?? 10);
$file    = $argv[$rest] ?? null;

if ($file === null || !is_readable($file)) {
    fwrite(STDERR, "error: missing or unreadable FILE\n");
    exit(2);                               // usage error
}

$count = 0;
while (($line = fgets(STDIN)) !== false && $count < $limit) {
    $count++;
    if ($verbose) fwrite(STDERR, "line $count\n");
    echo strtoupper($line);
}
exit(0);

Code Explained

Shebang + chmod +x makes it executable
v = flag, n: = required value; long opts in an array
$rest = index of the first non-option argument
Errors go to STDERR with a non-zero exit code
Reads piped input: cat x | ./tool.php -v FILE

⚠ Common Mistakes

  • Printing errors to STDOUT, breaking pipelines
  • Always exiting 0, even on failure
  • Loading huge input with file_get_contents('php://stdin')

✓ Tips & Best Practices

  • Use Symfony Console for subcommands and help text
  • Stream input line by line
  • Return meaningful exit codes
