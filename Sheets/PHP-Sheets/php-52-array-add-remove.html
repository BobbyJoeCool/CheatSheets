Adding & Removing Elements

$a[] = · array_push() · array_pop() · array_shift() · array_unshift() · unset() · array_splice()

Changing Array Contents

Append with $a[] = $v (fastest) or array_push() for several values. array_pop() removes from the end and array_shift() from the front; array_unshift() adds to the front. These functions take the array by reference and modify it in place. unset($a[$k]) removes one key but leaves a gap in list indexes; array_splice() removes or inserts in the middle and reindexes numeric keys.

Notes

  • array_shift() / array_unshift() reindex numeric keys — O(n)
  • array_pop() and array_shift() return null on an empty array
  • Return value of array_push() is the new count
  • Use SplQueue for heavy queue workloads (Sheet 60)
  • array_values() renumbers keys 0…n-1

Push, Pop, Shift, Splice

<?php
$stack = [1, 2];
$stack[] = 3;                    // [1, 2, 3]
array_push($stack, 4, 5);        // [1, 2, 3, 4, 5]
$top = array_pop($stack);        // 5; [1, 2, 3, 4]

$queue = ['a', 'b', 'c'];
$first = array_shift($queue);    // 'a'; ['b', 'c']
array_unshift($queue, 'z');      // ['z', 'b', 'c']

$list = ['a', 'b', 'c', 'd'];
unset($list[1]);                 // [0 => 'a', 2 => 'c', 3 => 'd']
$list = array_values($list);     // ['a', 'c', 'd']

$n = [1, 2, 3, 4, 5];
$removed = array_splice($n, 1, 2);        // [2, 3]
// $n = [1, 4, 5]
array_splice($n, 1, 0, ['x', 'y']);       // insert
// $n = [1, 'x', 'y', 4, 5]
array_splice($n, -1, 1, 'last');          // replace end

Code Explained

$a[] = and array_push() add to the end
array_pop() returns the removed value
array_shift() takes the first element
unset() leaves a hole; array_values() fixes it
array_splice($a, offset, length, replacement)

⚠ Common Mistakes

  • array_push($a, $b) where $b is an array — nests it
  • Looping with for over a list after unset() — missing indexes
  • Using array_shift() in a loop over a huge array — slow

✓ Tips & Best Practices

  • Prefer $a[] = $v for single appends
  • Reindex with array_values() after removals
  • Use array_splice() for in-place middle edits

Quick Summary

  • Append $a[], array_push
  • array_pop / array_shift
  • unset leaves gaps
  • array_splice edits the middle
