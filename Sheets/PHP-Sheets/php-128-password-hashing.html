Sheet 128

Password Hashing

password_hash() · password_verify() · PASSWORD_ARGON2ID · PASSWORD_BCRYPT · password_needs_rehash() · why not md5/sha1

Storing Passwords Safely

Never store passwords in plain text or with fast hashes like MD5 or SHA-1 — they're cracked at billions of guesses per second. password_hash() uses a slow, salted algorithm (bcrypt by default, Argon2id if available) and returns a self-describing string that includes the algorithm, cost and salt. password_verify() checks a login; password_needs_rehash() upgrades hashes when you change settings.

Notes

  • Store the hash in a VARCHAR(255) column
  • Bcrypt only uses the first 72 bytes of the password
  • PHP 8.4 raised the default bcrypt cost from 10 to 12
  • Salt is generated automatically — don't supply one
  • Rate-limit login attempts as well

Hash, Verify, Rehash

<?php
// Registration
$hash = password_hash($plain, PASSWORD_DEFAULT);
// $2y$12$9bL1y0kq… (algorithm, cost, salt, hash)
$hash = password_hash($plain, PASSWORD_ARGON2ID, [
    'memory_cost' => 65536,     // KiB
    'time_cost'   => 4,
    'threads'     => 1,
]);

// Login
$row = findUserByEmail($email);
if (!$row || !password_verify($plain, $row['password_hash'])) {
    throw new RuntimeException('Invalid email or password');
}

// Upgrade old hashes transparently
if (password_needs_rehash($row['password_hash'], PASSWORD_DEFAULT)) {
    saveHash($row['id'], password_hash($plain, PASSWORD_DEFAULT));
}

password_get_info($hash);
// ['algo' => 'argon2id', 'algoName' => 'argon2id', 'options' => [...]]

Code Explained

PASSWORD_DEFAULT follows PHP's recommendation
Argon2id is memory-hard (better against GPUs)
Same error message for unknown user and wrong password
Rehash at login when settings change
password_get_info decodes a hash's settings

⚠ Common Mistakes

  • md5($password) or unsalted SHA hashes
  • Comparing hashes with == instead of password_verify()
  • Truncating the hash column to 60 chars (Argon2 is longer)

✓ Tips & Best Practices

  • Use PASSWORD_DEFAULT or PASSWORD_ARGON2ID
  • Rehash on login to migrate old hashes
  • Tune cost so hashing takes ~100–300 ms

Quick Summary

  • password_hash / password_verify
  • Bcrypt or Argon2id
  • Rehash when settings change
  • Never fast hashes
