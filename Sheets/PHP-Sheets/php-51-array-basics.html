Array Basics

[] · array() · indexed vs associative · key casting · count() · ordered hash map

One Type, Many Roles

A PHP array is an ordered map: every element has a key and a value, and elements keep insertion order. With automatic integer keys it acts as a list; with string keys it acts as a dictionary. Keys can only be int or string — other key types are cast. Arrays are values: assigning or passing one gives a copy (cheaply, using copy-on-write).

Notes

  • [] short syntax replaces array() (5.4+)
  • Appending with $a[] = x uses the next integer key (max int key + 1)
  • array_is_list($a) (8.1) checks for keys 0…n-1 in order
  • Reading a missing key gives a Warning and null
  • Trailing commas are allowed in array literals

Creating and Reading Arrays

<?php
$fruits = ['apple', 'banana', 'cherry'];   // list
$user = [                                  // map
    'name'  => 'Ana',
    'age'   => 30,
    'roles' => ['admin', 'editor'],        // nested
];

echo $fruits[0];             // apple
echo $user['name'];          // Ana
echo $user['roles'][1];      // editor
echo count($fruits);         // 3

$fruits[] = 'date';          // append, key 3
$user['email'] = 'a@x.io';   // add key

$mixed = [5 => 'a', 'b', '7' => 'c', true => 'd', 1.9 => 'e'];
// [5 => 'a', 6 => 'b', 7 => 'c', 1 => 'e']

var_dump(array_is_list($fruits));   // true
var_dump(array_is_list($mixed));    // false

Code Explained

Without keys, PHP assigns 0, 1, 2, …
=> sets a key explicitly
Chain brackets for nested access
$a[] = appends with the next integer key
'7' → 7, true → 1, 1.9 → 1 (overwrites 'd')

⚠ Common Mistakes

  • Using float or bool keys and losing data to collisions
  • Expecting unset() to reindex a list — use array_values()
  • Reading $a['missing'] without ??

✓ Tips & Best Practices

  • Use short [] syntax and trailing commas
  • Use ?? when a key may be missing
  • Use objects/DTOs for fixed structures instead of big maps

Quick Summary
