Sheet 17

String Formatting

printf() · sprintf() · %s %d %05.2f · number_format() · str_pad() · vsprintf()

Formatted Output

sprintf() builds a string from a format with placeholders; printf() prints it directly. A placeholder is % + optional flags, width and precision + a type letter: %05.2f means float, 2 decimals, padded with zeros to width 5. number_format() adds thousands separators for display, str_pad() pads to a fixed width, and vsprintf() takes the values as an array.

Notes

  • %% prints a literal percent sign
  • Argument numbering: %1$s reuses the first argument
  • %'*10s pads with * instead of spaces
  • - flag left-aligns; + forces a sign
  • For locales and currencies use NumberFormatter (intl)

sprintf, printf & Friends

<?php
$item = 'Coffee'; $qty = 3; $price = 4.5;

printf("%s x%d = %.2f\n", $item, $qty, $qty * $price);
// Coffee x3 = 13.50

echo sprintf('%05.1f', 3.14159);     // 003.1
echo sprintf('%-8s|', 'ab');         // 'ab      |'
echo sprintf('%08.3f', -1.5);        // -001.500
echo sprintf('%x %o %b', 255, 8, 5); // ff 10 101
echo sprintf('%1$s-%1$s', 'go');     // go-go
echo sprintf('%u%%', 50);            // 50%

echo number_format(1234567.891);         // 1,234,568
echo number_format(1234567.891, 2);      // 1,234,567.89
echo number_format(1234.5, 2, ',', '.'); // 1.234,50

echo str_pad('7', 3, '0', STR_PAD_LEFT); // 007
echo vsprintf('%s is %d', ['Bo', 30]);    // Bo is 30

Code Explained

%.2f — two decimal places, rounded
Width counts the whole output including sign and dot
%-8s — left-aligned in 8 columns
%1$s — positional argument, reusable
number_format() returns a string for display only

⚠ Common Mistakes

  • Formatting money with %f and floats — round to cents first
  • Passing fewer arguments than placeholders — ArgumentCountError
  • Doing math on number_format() output — it's a string with commas

✓ Tips & Best Practices

  • Keep numbers numeric until the moment you display them
  • Use positional %1$s in translatable strings
  • Use NumberFormatter for locale-aware output
