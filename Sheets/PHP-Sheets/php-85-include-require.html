include & require

include · require · include_once · require_once · return values · include_path · __DIR__ paths

Loading Other Files

require and include insert and run another PHP file at that point; the included code shares the current variable scope. The difference is failure: require stops with a fatal error, include emits a Warning and continues. The _once variants skip files already loaded. An included file can return a value — the standard way to load config arrays. Modern code loads classes through autoloading instead.

Notes

  • They're language constructs: parentheses are optional
  • Relative paths are resolved via include_path, then the working directory
  • Always build paths with __DIR__
  • require_once has a small cost — fine for bootstrapping
  • Never include paths built from user input

Including Files

<?php
// bootstrap.php
require __DIR__ . '/vendor/autoload.php';    // must exist
require_once __DIR__ . '/src/helpers.php';   // load once

$config = require __DIR__ . '/config/app.php';
echo $config['name'];                        // 'Shop'

if (is_file(__DIR__ . '/config/local.php')) {
    $config = array_replace($config, require __DIR__ . '/config/local.php');
}

include __DIR__ . '/views/header.php';       // Warning if missing

// config/app.php
return [
    'name'  => 'Shop',
    'debug' => (bool) getenv('APP_DEBUG'),
];

// views/header.php sees $config (same scope)
?>
<h1><?= htmlspecialchars($config['name']) ?></h1>

Code Explained

require the Composer autoloader first
require_once prevents double function definitions
Included file's return becomes the expression value
Optional overrides merged only if the file exists
Templates included this way can read local variables

⚠ Common Mistakes

  • include 'config.php' relative to the working directory
  • Including a file built from $_GET — remote/local file inclusion
  • Using include where missing files should stop execution

✓ Tips & Best Practices

  • Use require for anything essential
  • Return arrays from config files
  • Let Composer autoload classes (Sheet 87)

Quick Summary

  • require fatal, include warns
  • _once loads once
  • Files can return values
  • Paths from __DIR__
