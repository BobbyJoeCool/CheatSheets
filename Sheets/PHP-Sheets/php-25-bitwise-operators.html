Bitwise Operators

& · | · ^ · ~ · << · >> · E_ALL & ~E_NOTICE · flag constants

Working with Bits

Bitwise operators act on the binary digits of integers. & keeps bits set in both, | in either, ^ in exactly one, ~ flips every bit, and << / >> shift left or right. PHP uses them most for flags: many built-in functions take options combined with |, such as JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES, and error levels like E_ALL & ~E_DEPRECATED.

Notes

  • Operands are converted to int; on two strings they work byte-wise
  • >> is an arithmetic shift (keeps the sign)
  • Shifting by a negative amount throws ArithmeticError
  • & binds tighter than | but looser than == — use parentheses
  • See the Bitwise sheet set for deeper tricks

Flags & Masks

<?php
const READ  = 0b001;   // 1
const WRITE = 0b010;   // 2
const EXEC  = 0b100;   // 4

$perm = READ | WRITE;            // 3  (0b011)
$canWrite = ($perm & WRITE) !== 0;  // true
$perm |= EXEC;                   // add a flag  -> 7
$perm &= ~WRITE;                 // remove flag -> 5
$perm ^= READ;                   // toggle      -> 4

echo 1 << 3;      // 8
echo 64 >> 2;     // 16
echo ~0;          // -1
printf('%08b', 0b1010 ^ 0b0110);  // 00001100

echo json_encode(['a/b' => 'é'],
    JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE);
error_reporting(E_ALL & ~E_DEPRECATED);

Code Explained

Each flag is a different power of two
& with a flag tests it; wrap in parentheses before comparing
|= sets, &= ~ clears, ^= toggles
<< n multiplies by 2ⁿ; >> n divides
Built-in option constants combine the same way

⚠ Common Mistakes

  • $f & FLAG === FLAG — compares first; add parentheses
  • Using && when you meant & (or vice versa)
  • Defining flags that aren't powers of two

✓ Tips & Best Practices

  • Use 0b literals so flag bits are visible
  • Prefer enums or arrays of options for new APIs
  • Use printf('%b') to debug masks

Quick Summary

  • & | ^ ~ << >>
  • Combine options with |
  • Test with ($f & X) !== 0
  • Clear with & ~X
