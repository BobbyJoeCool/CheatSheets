Sessions

session_start() · $_SESSION · session_regenerate_id() · session_destroy() · session_set_cookie_params() · save handlers

Server-Side State

Sessions keep data on the server between requests. session_start() sends a session ID cookie (PHPSESSID) and loads stored data into $_SESSION; changes are saved at the end of the request. Call session_regenerate_id(true) whenever privileges change (login, logout) to prevent session fixation. By default sessions are files; Redis or a database scale across servers.

Notes

  • Call session_start() before any output
  • Session files lock: one request per session at a time
  • session_write_close() releases the lock early
  • Set cookie params before session_start()
  • session.use_strict_mode=1 rejects unknown IDs

Login, Use, Logout

<?php
session_set_cookie_params([
    'lifetime' => 0,
    'path'     => '/',
    'secure'   => true,
    'httponly' => true,
    'samesite' => 'Lax',
]);
session_start();

// Login
if (password_verify($password, $user->hash)) {
    session_regenerate_id(true);           // new ID, delete old
    $_SESSION['user_id'] = $user->id;
    $_SESSION['login_at'] = time();
}

// Use
$userId = $_SESSION['user_id'] ?? null;
$_SESSION['cart'][] = $productId;
session_write_close();                     // done writing → unlock

// Logout
session_start();
$_SESSION = [];
session_destroy();
setcookie(session_name(), '',
    ['expires' => time() - 3600, 'path' => '/']);

Code Explained

Harden the session cookie before starting
Regenerate the ID at login
$_SESSION behaves like a normal array
Release the lock when you're done writing
Full logout: clear data, destroy, expire cookie

⚠ Common Mistakes

  • Not regenerating the ID after login — session fixation
  • Long requests holding the session lock
  • Storing large objects in the session

✓ Tips & Best Practices

  • Store IDs, not whole objects
  • Use Redis for multi-server setups
  • Close the session early in slow requests

Quick Summary

  • session_start() + $_SESSION
  • Regenerate on login
  • Harden cookie params
  • Destroy fully on logout
