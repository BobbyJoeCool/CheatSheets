Numbers and Randomness

PHP's math functions cover rounding, extremes, powers, roots, logarithms and trigonometry, plus constants like M_PI. For random numbers, use random_int() and random_bytes() — they are cryptographically secure. PHP 8.2's Random\Randomizer class adds seedable, object-based random generation with methods for shuffling, picking keys and generating strings. Avoid rand() and mt_rand() for anything security-related.

Notes

  • max() / min() accept several values or one array
  • round() accepts negative precision: round(1234, -2) = 1200
  • intdiv() and % for integer math (Sheet 22)
  • Randomizer with a seeded engine gives repeatable results in tests
  • random_int() throws if no secure source is available

Math and Random Functions

<?php
abs(-4.2);              // 4.2
max(3, 9, 1);           // 9
max([3, 9, 1]);         // 9
min([]);                // ValueError
round(1234.567, 1);     // 1234.6
round(1234.567, -2);    // 1200.0
sqrt(16);               // 4.0
pow(2, 8);              // 256
log(M_E);               // 1.0
log10(1000);            // 3.0
hypot(3, 4);            // 5.0
array_sum([1.5, 2.5]);  // 4.0

$dice  = random_int(1, 6);              // secure
$token = bin2hex(random_bytes(16));     // 32 hex chars

$r = new Random\Randomizer();
$r->getInt(1, 100);
$r->shuffleArray(['a', 'b', 'c']);
$r->pickArrayKeys(['x' => 1, 'y' => 2, 'z' => 3], 2);
$r->getBytesFromString('abcdef0123456789', 8);   // 8.3

$seeded = new Random\Randomizer(new Random\Engine\Mt19937(42));
$seeded->getInt(1, 10);                 // same every run

Code Explained

max/min take values or an array; empty array throws
Negative precision rounds to tens, hundreds…
random_int for games, codes, anything that matters
random_bytes + bin2hex = random token
Seeded engine → reproducible sequences

⚠ Common Mistakes

  • rand() or mt_rand() for tokens or passwords
  • max([]) on possibly empty data — ValueError
  • Trig functions with degrees instead of radians

✓ Tips & Best Practices

  • Use random_int / random_bytes by default
  • Use a seeded Randomizer in tests
  • Use Randomizer::getBytesFromString() for codes from an alphabet
