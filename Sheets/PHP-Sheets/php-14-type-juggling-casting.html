Type Juggling & Casting

(int) · (string) · (array) · settype() · numeric strings · PHP 8 string-number comparison

Automatic and Explicit Conversion

PHP converts types automatically when an operator or function expects a different type — this is type juggling. '5' + 3 is 8; '5' . 3 is '53'. Casting with (int), (float), (string), (bool), (array) or (object) converts explicitly. PHP 8 made comparisons between numbers and non-numeric strings compare as strings, so 0 == 'abc' is finally false.

Notes

  • Arithmetic on a non-numeric string throws TypeError in PHP 8
  • Leading-numeric '12abc' + 1 works with a Warning
  • declare(strict_types=1) stops juggling for scalar parameters
  • (array) on an object exposes its properties
  • settype($x, 'int') converts the variable in place

Juggling and Casts

<?php
var_dump('5' + 3);        // int(8)
var_dump('5' . 3);        // string(2) "53"
var_dump('1.5' * 2);      // float(3)
var_dump('12abc' + 1);    // int(13) + Warning
// 'abc' + 1;             // TypeError (PHP 8)

var_dump(0 == 'abc');     // false in PHP 8 (true in 7)
var_dump('1' == '01');    // true  (numeric strings)
var_dump('10' == '1e1');  // true
var_dump(100 == '1e2');   // true

var_dump((int) '0x1A');   // int(0)
var_dump((string) 1.0);   // string(1) "1"
var_dump((array) 'hi');   // array(1) { [0]=> "hi" }
var_dump((bool) '0');     // bool(false)

Code Explained

+ converts strings to numbers; . converts numbers to strings
PHP 8 throws instead of treating 'abc' as 0
Two numeric strings compare as numbers
Casts don't parse hex strings
Casting a scalar to array wraps it

⚠ Common Mistakes

  • Relying on PHP 7 comparison rules after upgrading
  • Casting user input with (int) and calling it validation
  • Concatenating with + (JavaScript habit)

✓ Tips & Best Practices

  • Use === and !== by default
  • Turn on strict_types in every file
  • Validate input with filter_var() before casting

Quick Summary

  • Juggling = automatic conversion
  • Casts: (int) (string) …
  • PHP 8 fixed number/string ==
  • Prefer strict comparison
