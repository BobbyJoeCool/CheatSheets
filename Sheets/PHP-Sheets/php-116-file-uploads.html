Sheet 116

File Uploads

$_FILES · move_uploaded_file() · UPLOAD_ERR_* · upload_max_filesize · post_max_size · finfo MIME checks

Receiving Files

Upload forms need method="post" and enctype="multipart/form-data". PHP saves each file to a temporary path and describes it in $_FILES. Check the error code, verify size and real content type (with finfo, not the client's claim), generate your own filename, and move the file with move_uploaded_file() to a directory outside the web root or one that never executes PHP.

Notes

  • Temp files are deleted at the end of the request
  • upload_max_filesize limits one file; post_max_size the whole body
  • If the body exceeds post_max_size, $_POST and $_FILES are empty
  • name and type come from the client — don't trust them
  • Multiple files: name="docs[]" + multiple

A Safe Upload Handler

<?php
$f = $_FILES['avatar'] ?? null;
if (!$f || $f['error'] !== UPLOAD_ERR_OK) {
    $code = $f['error'] ?? 'none';
    throw new RuntimeException("Upload failed: code $code");
}
if ($f['size'] > 2 * 1024 * 1024) {
    throw new RuntimeException('Max 2 MB');
}

$mime = (new finfo(FILEINFO_MIME_TYPE))->file($f['tmp_name']);
$ext = match ($mime) {
    'image/jpeg' => 'jpg',
    'image/png'  => 'png',
    'image/webp' => 'webp',
    default      => throw new RuntimeException('Images only'),
};

$name = bin2hex(random_bytes(16)) . ".$ext";  // own name
$dest = __DIR__ . '/../storage/avatars/' . $name;
if (!move_uploaded_file($f['tmp_name'], $dest)) {
    throw new RuntimeException('Could not save file');
}
?>
<form method="post" enctype="multipart/form-data">
  <input type="file" name="avatar" accept="image/*">
  <button>Upload</button>
</form>

Code Explained

Check error first
Enforce your own size limit
finfo inspects the actual bytes
Random filename avoids overwrites and traversal
move_uploaded_file only moves genuine uploads

⚠ Common Mistakes

  • Trusting $_FILES['x']['type'] or the extension
  • Saving uploads in a public, PHP-executing folder
  • Using the original filename on disk

✓ Tips & Best Practices

  • Verify content with finfo and re-encode images
  • Store outside the web root; serve through a controller
  • Use object storage (S3) for scale

Quick Summary

  • multipart/form-data + POST
  • Check error and size
  • finfo for real MIME
  • Random name + move_uploaded_file
