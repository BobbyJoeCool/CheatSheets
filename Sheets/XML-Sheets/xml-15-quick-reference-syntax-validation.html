⚠ Common Mistakes

  • A bare & or < in text — escape as &amp; / &lt; or use CDATA
  • Assuming a prefix matters — the namespace URI is what identifies elements
  • Expecting a default namespace to apply to attributes

✓ Tips & Best Practices

  • Check well-formedness first (xmllint --noout f.xml), then validate
  • Prefer XSD over DTD for typed data and namespaces
  • Use attributes for metadata, elements for content

Quick Summary

  • One root, close every tag, quote every attribute
  • Five built-in entities: &lt; &gt; &amp; &quot; &apos;
  • Namespaces = URI + optional prefix
  • DTD = structure; XSD = structure + types
