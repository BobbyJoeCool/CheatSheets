XPath — XML Path Language

XPath is the query language for selecting nodes from an XML document. An XPath expression describes a path through the document tree, similar to a filesystem path. Expressions are evaluated relative to a context node. A path starting with / is absolute (from the document root); one without is relative (from the current node). XPath is used natively inside XSLT, XML Schema, and XQuery, and is exposed in most programming languages through DOM APIs and dedicated libraries.

Node Types

  • Element — a tagged element (<book>)
  • Attribute — an attribute of an element (@id)
  • Text — text content inside an element
  • Comment — <!-- … -->
  • Processing instruction — <?target data?>
  • Document root — the virtual top node above the root element
  • Namespace — namespace node on an element

Common Mistakes

  • Forgetting XPath positions are 1-based: [1] is the first node, not [0]
  • Using // at the start of every expression — it scans the entire tree each time and is very slow on large documents; prefer a more specific path
  • XPath on namespaced XML without registering prefixes — the engine needs prefix-URI bindings to match namespaced elements

Tips

  • Test XPath expressions interactively in browser DevTools: $x("//book[@id='bk101']") in the console
  • Use normalize-space() around text comparisons to ignore leading/trailing whitespace differences
  • Combine predicates: //book[@lang='en'][price > 10] — multiple predicates are ANDed together

Summary

  • / — absolute path from root; no / = relative from context node
  • // — anywhere in document (descendant-or-self)
  • @attr — select attribute; [predicate] — filter a node-set
  • Positions are 1-based; last() returns final position in context
