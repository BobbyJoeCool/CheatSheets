XSLT

templates · apply-templates · for-each · if · choose · output methods

What is XSLT?

XSLT (XSL Transformations) is an XML-based language for transforming XML documents into other formats — HTML, plain text, another XML vocabulary, or any text output. An XSLT stylesheet is itself a well-formed XML document using the xsl: namespace. Processing works by matching nodes in the source tree with templates and outputting their transformed result. XSLT uses XPath expressions to select and test nodes. The XSLT processor applies templates recursively until the entire source tree has been processed.

Core XSLT Elements

  • xsl:stylesheet — root element of every XSLT stylesheet
  • xsl:template — defines a rule matching a set of nodes
  • xsl:apply-templates — processes child nodes with matching templates
  • xsl:value-of — outputs the string value of an XPath expression
  • xsl:for-each — iterates over a node-set
  • xsl:if — conditional output
  • xsl:choose / xsl:when / xsl:otherwise — switch-style conditionals
  • xsl:output — declares output method and encoding

XSLT Stylesheet — XML to HTML

<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet
  version="1.0"
  xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

  <!-- ── Output format ────────────────────────────────────── -->
  <xsl:output method="html" encoding="UTF-8" indent="yes"/>

  <!-- ── Root template — matches document root ────────────── -->
  <xsl:template match="/">
    <html><body>
      <h1>Book Catalog</h1>
      <xsl:apply-templates select="catalog/book"/>
    </body></html>
  </xsl:template>

  <!-- ── Template for each book ───────────────────────────── -->
  <xsl:template match="book">
    <div>
      <h2><xsl:value-of select="title"/></h2>
      <p>Author: <xsl:value-of select="author"/></p>

      <!-- xsl:if — single condition -->
      <xsl:if test="price &gt; 10">
        <p>Price: <xsl:value-of select="price"/></p>
      </xsl:if>

      <!-- xsl:choose — multiple conditions -->
      <xsl:choose>
        <xsl:when test="@lang = 'en'"><span>English</span></xsl:when>
        <xsl:when test="@lang = 'fr'"><span>French</span></xsl:when>
        <xsl:otherwise><span>Other</span></xsl:otherwise>
      </xsl:choose>
    </div>
  </xsl:template>

  <!-- ── for-each with sort ────────────────────────────────── -->
  <xsl:template match="catalog">
    <xsl:for-each select="book">
      <xsl:sort select="title" order="ascending"/>
      <p><xsl:value-of select="title"/></p>
    </xsl:for-each>
  </xsl:template>

</xsl:stylesheet>

Notes

match="/" — matches the document root node (virtual node above the root element); this template fires first
xsl:apply-templates select="..." — hands off processing to whichever template matches each selected node; without select, processes all children
xsl:value-of select="title" — outputs the string value of <title>; equivalent to XPath string(title)
test="price &gt; 10" — XPath expression in test; use &gt; because > would break XML parsing
xsl:choose — like a switch statement; xsl:when clauses are tested top-to-bottom; xsl:otherwise is the default
xsl:sort — sorts the node-set before iteration; order="descending" also available; data-type="number" for numeric sort
xsl:output method="html" — also accepts "xml" and "text"; controls serialization of the result

"html"HTML; void elements like <br> not closed

Common Mistakes

  • Using > or < raw inside test="..." — XPath operators inside XML attributes must be escaped as &gt; / &lt;
  • Forgetting that xsl:variable is immutable — you cannot update a variable inside a loop; use recursion or xsl:for-each accumulation patterns instead
  • Omitting xsl:apply-templates in a template — without it, child nodes are silently dropped from the output

Tips

  • Prefer template matching (xsl:apply-templates) over xsl:for-each — it produces more modular, reusable stylesheets
  • Use xsl:copy-of instead of xsl:value-of when you need to copy a subtree with its markup intact
  • Test stylesheets with xsltproc input.xml transform.xsl on the command line for fast iteration

Summary

  • xsl:template match="..." — rule triggered when a node matches the XPath pattern
  • xsl:apply-templates — recurse into child nodes; drives the transformation engine
  • xsl:value-of — output text; xsl:copy-of — output node tree
  • xsl:if (no else) · xsl:choose/when/otherwise (multi-branch)
