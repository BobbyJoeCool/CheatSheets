Sheet 09

Parsing XML

DOM · SAX · StAX · Python · Java · JS · tree navigation · error handling

Parsing Models

Three major models exist for parsing XML programmatically. DOM (Document Object Model) loads the entire document into a tree in memory — easy to navigate and modify, but memory-intensive for large files. SAX (Simple API for XML) streams the document and fires events (startElement, endElement, characters) as it reads — low memory, but read-only and forward-only. StAX (Streaming API for XML) is a pull-based streaming model where your code drives parsing iteration — a middle ground that is easier to use than SAX while remaining memory-efficient.

Model Comparison

  • DOM — full tree in RAM; random access; read/write; slow on large files
  • SAX — event-driven; push model; very low memory; read-only; forward-only
  • StAX — pull streaming; low memory; more control than SAX; Java-native
  • Browser JS uses DOM API natively via DOMParser
  • Python: xml.etree.ElementTree = lightweight DOM; xml.sax = SAX
  • Always check for parse errors — malformed XML throws, not silently fails

Parsing in Python, JS & Java

# ── Python: xml.etree.ElementTree (DOM-like) ─────────────────
import xml.etree.ElementTree as ET

tree = ET.parse('catalog.xml')
root = tree.getroot()                # <catalog> element

for book in root.findall('book'):
    title = book.find('title').text  # text content
    bid   = book.get('id')           # attribute value
    price = float(book.find('price').text)
    print(bid, title, price)

# XPath-like selection (limited subset)
books = root.findall('.//book[@lang="en"]')

# Build and write XML
new_book = ET.SubElement(root, 'book', id='bk103')
ET.SubElement(new_book, 'title').text = 'New Title'
tree.write('out.xml', encoding='UTF-8', xml_declaration=True)

Notes

ET.parse() — loads file into memory; use ET.fromstring(xml_str) to parse a string directly
.findall('book') — finds direct children named book; './/book' finds at any depth
.find('title').text — the text content of an element; returns None if element is missing — guard against this
.get('id') — attribute value; returns None if attribute absent (use .get('id', 'default') for a fallback)
ET.SubElement(parent, tag) — creates and appends a new child element in one call
xml_declaration=True — writes <?xml version='1.0' encoding='UTF-8'?> at the top of the output file

Common Mistakes

  • Not checking for None after .find() — if the element is missing, accessing .text on None throws an AttributeError
  • Using browser DOMParser without checking for <parsererror> — a malformed document still returns a document object, not an exception
  • Loading huge XML files with DOM parsers — use SAX or StAX for files over ~50 MB to avoid memory exhaustion

Tips

  • Use Python's lxml library for full XPath 1.0 support and much faster parsing than the standard library's xml.etree
  • In the browser, doc.querySelector() with CSS selectors is often simpler than XPath for basic navigation
  • For namespaced XML in Python ElementTree, element names appear as {uri}localname — prefix with the URI in braces in your selectors

Summary

  • DOM — full tree in memory; best for small/medium files with random access
  • SAX — event push; best for huge files; read-only forward-only
  • Python: ET.parse() / ET.fromstring() · JS: new DOMParser().parseFromString()
  • Always guard against missing elements (None) and parse errors
