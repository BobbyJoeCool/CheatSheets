⚠ Common Mistakes

  • Forgetting namespaces in XPath — //item won't match x:item without a prefix mapping
  • XPath positions start at 1, not 0
  • Parsing untrusted XML with external entities enabled (XXE)

✓ Tips & Best Practices

  • Register namespace prefixes with your XPath engine before querying
  • Stream big files with SAX, StAX or iterparse
  • Keep XSLT templates small and let apply-templates drive recursion

Quick Summary

  • XPath: paths, axes, predicates, functions
  • XSLT: template + apply-templates + value-of
  • DOM for small, streaming for large
  • Disable DTDs / external entities on untrusted input
