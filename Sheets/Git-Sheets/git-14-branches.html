Creating & Managing Branches

git branch -a / -vv · switch / switch -c / switch - · checkout -b (legacy) · branch -m · -d / -D · --merged / --contains · --sort=-committerdate · detached HEAD

Branches Are Pointers

A branch is just a movable pointer to a commit; committing moves the current branch forward. git switch (Git 2.23+) changes branches, while git branch lists, renames, and deletes them. Checking out a commit or tag directly puts you in detached HEAD: fine for looking around, but create a branch before you commit.

Notes

  • switch refuses to discard uncommitted changes that conflict
  • origin/main is a remote-tracking branch; you don't commit to it
  • -d only deletes merged branches; -D forces
  • Naming: feature/login, fix/123-crash, lowercase, hyphens

Branch Commands

git branch                          # local branches (* = current)
git branch -a                       # local + remote-tracking
git branch -vv                      # last commit + upstream + ahead/behind
git switch -c feature/login         # create and switch
git switch -c hotfix v1.4.0         # new branch from a tag/commit
git switch main                     # switch to an existing branch
git switch -                        # back to the previous branch
git switch feature/x                # auto-tracks origin/feature/x if it exists
git checkout -b feature/login       # legacy equivalent of switch -c

git branch -m old-name new-name     # rename (-m alone renames current)
git branch -d feature/login         # delete if merged
git branch -D spike/test            # force delete
git branch --merged main            # safe to delete
git branch --contains a1b2c3d       # which branches have this commit
git branch --sort=-committerdate    # most recently active first
git switch --detach v1.4.0          # explore a tag (detached HEAD)

Code Explained

-vv — shows [origin/main: ahead 2] style tracking info
switch -c <name> <start> — branch from any revision
switch - — toggle between two branches
-m — rename; -M forces over an existing name
--merged / --no-merged — cleanup helpers
--detach — look around without moving a branch

⚠ Common Mistakes

  • Committing in detached HEAD and switching away. The commits are only reachable from the reflog
  • Deleting with -D to silence a warning. -d failing means the work isn't merged anywhere
  • Renaming a pushed branch locally only. Push the new name and delete the old one on the remote

✓ Tips & Best Practices

  • Set git config --global branch.sort -committerdate
  • Clean up merged branches: git branch --merged main | grep -v main
  • Use git switch -c from the branch you want as the base

Quick Summary

  • switch -c — create + switch
  • branch -vv — tracking status
  • branch -d / -D — delete
  • --detach — inspect without a branch
