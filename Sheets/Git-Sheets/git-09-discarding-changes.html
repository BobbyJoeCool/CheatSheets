Sheet 09

Discarding Working Changes

git restore <file> · restore --source=<sha> · restore -p · checkout -- <file> (legacy) · git clean -n · clean -fd / -x

Throwing Away Local Edits

git restore replaces files in your working tree (or staging area) with a known version, and git clean deletes untracked files. Both are destructive: uncommitted work they remove is not in the reflog and generally can't be recovered. Preview first, and stash if you're unsure (Sheet 27).

Notes

  • restore arrived in Git 2.23 to replace file-mode checkout
  • restore with no flags = --worktree from the index
  • clean refuses to run without -f (or -n / -i)
  • Ignored files are only removed with -x or -X

Restore and Clean

git restore app.js                      # discard unstaged edits to a file
git restore .                           # discard all unstaged edits
git restore -p app.js                   # discard hunk by hunk
git restore --staged app.js             # unstage only (edits kept)
git restore --staged --worktree app.js  # unstage AND discard edits
git restore --source=HEAD~2 app.js      # bring back an older version
git restore --source=main -- docs/      # take a folder from another branch

git checkout -- app.js                  # legacy form of: git restore app.js

git clean -n                            # dry run: what would be deleted
git clean -f                            # delete untracked files
git clean -fd                           # ...and untracked folders
git clean -fdx                          # ...and ignored files (build output)
git clean -i                            # interactive menu

Code Explained

restore <file> — copy the staged version over your edits
--staged — reset the index entry to HEAD
--source=<rev> — restore from any commit, branch, or tag
-p — choose which hunks to throw away
clean -n — always run first; it only lists
-x — also removes ignored files like node_modules/

Which Command?

GoalCommand
Discard edits in a filegit restore <file>
Unstage a filegit restore --staged <file>
File from an old commitgit restore --source=<sha> <file>
Delete untracked filesgit clean -fd
Reset everything to HEADgit reset --hard (Sheet 25)
Keep changes for latergit stash -u (Sheet 27)

git clean Flags

FlagEffect
-ndry run
-fforce (required)
-dinclude untracked folders
-xinclude ignored files too
-Xonly ignored files
-e <pattern>exclude a pattern

⚠ Common Mistakes

  • Running git clean -fdx without -n first. It deletes .env files and local config too
  • Expecting git restore to undo a commit. It only touches files; use revert or reset
  • Restoring and losing work you wanted. Uncommitted content isn't in the reflog; stash when unsure

✓ Tips & Best Practices

  • Use git stash -u as a reversible alternative to restore + clean
  • Add -p to restore to keep the good hunks
  • Use git clean -fdX to wipe only build artifacts

Quick Summary

  • restore <file> — discard edits
  • restore --staged — unstage
  • --source=<rev> — older version
  • clean -n then -fd — remove untracked
