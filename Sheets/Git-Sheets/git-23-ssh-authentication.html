SSH, Credentials & Signing

ssh-keygen -t ed25519 · ssh -T git@github.com · ~/.ssh/config · HTTPS + tokens · credential.helper · Git Credential Manager · gpg.format ssh / commit -S

Proving Who You Are

Hosts no longer accept account passwords for Git. Use either SSH keys (add your public key to your account) or HTTPS with a token, stored by a credential helper so you aren't prompted every time. Separately, commit signing proves a commit really came from you; Git 2.34+ can sign with the same SSH key.

Notes

  • Never share or commit the private key (id_ed25519)
  • Personal access tokens replace passwords for HTTPS
  • Git Credential Manager handles HTTPS + 2FA on all platforms
  • Signed commits show as "Verified" on GitHub/GitLab

SSH Keys, Credentials, Signing

ssh-keygen -t ed25519 -C "ada@example.com"   # creates ~/.ssh/id_ed25519(.pub)
ssh-add --apple-use-keychain ~/.ssh/id_ed25519   # macOS keychain
cat ~/.ssh/id_ed25519.pub                     # paste into GitHub > SSH keys
ssh -T git@github.com                         # "Hi ada! You've successfully…"

# ~/.ssh/config: pick a key per host
Host github.com
  IdentityFile ~/.ssh/id_ed25519
  AddKeysToAgent yes

git config --global credential.helper osxkeychain   # macOS (Windows: manager)

git config --global gpg.format ssh
git config --global user.signingkey ~/.ssh/id_ed25519.pub
git config --global commit.gpgsign true       # sign every commit
git commit -S -m "Signed commit"              # sign one commit
git log --show-signature -1                   # verify

Code Explained

-t ed25519 — modern, short, fast key type
ssh -T — tests auth without opening a shell
IdentityFile — choose a key per host or alias
credential.helper — stores HTTPS tokens securely
gpg.format ssh — sign with an SSH key instead of GPG
--show-signature — checks signatures in the log

⚠ Common Mistakes

  • Pasting the private key into GitHub. Only the .pub file goes there
  • Using an HTTPS remote after setting up SSH. Switch with git remote set-url origin git@…
  • Enabling commit.gpgsign without uploading the key as a *signing* key. Commits show "Unverified"

✓ Tips & Best Practices

  • Use a passphrase on keys and let the agent remember it
  • Use gh auth login to set up GitHub HTTPS credentials quickly
  • Two accounts on one host: add Host github-work aliases in ~/.ssh/config

Quick Summary

  • ssh-keygen -t ed25519 — new key
  • ssh -T — test the connection
  • credential.helper — store tokens
  • gpg.format ssh + -S — sign commits
