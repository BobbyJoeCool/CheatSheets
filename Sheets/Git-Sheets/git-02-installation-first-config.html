Installation & First-Time Config

git --version · brew / apt / winget · user.name / user.email · init.defaultBranch main · core.editor · core.autocrlf

Getting Set Up

Install Git from your platform's package manager, then set your name and email once. Git writes them into every commit you make, and hosts like GitHub use the email to link commits to your account. A few more global settings (default branch, editor, line endings) save headaches later. All of these live in ~/.gitconfig.

Notes

  • macOS ships Apple Git via Xcode tools; Homebrew gives a newer release
  • Ubuntu's default package can lag; the git-core PPA tracks the latest
  • Git for Windows includes Git Bash and Git Credential Manager
  • Use your host's no-reply email if you don't want your address public

Install, Verify, Configure

brew install git                       # macOS (Homebrew)
sudo apt install git                   # Debian / Ubuntu
sudo dnf install git                   # Fedora / RHEL
winget install --id Git.Git -e         # Windows
git --version                          # git version 2.5x.x

git config --global user.name  "Ada Lovelace"
git config --global user.email "ada@example.com"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"
git config --global core.autocrlf input   # macOS/Linux (Windows: true)
git config --global --list                # review everything you set

Code Explained

--global — writes to ~/.gitconfig for every repo on this account
user.name / user.email — stamped on each commit you create
init.defaultBranch — branch name for new git init repos
core.editor — opens for commit messages; --wait blocks until closed
core.autocrlf — converts line endings on commit/checkout
--list — prints all effective settings

⚠ Common Mistakes

  • Setting user.email per repo by accident (no --global). Other repos still use the old value
  • Leaving the editor as Vim when you don't know Vim. git commit with no -m then feels stuck (:wq exits)
  • core.autocrlf true on macOS/Linux. It rewrites line endings you didn't ask for

✓ Tips & Best Practices

  • Run git config --global --edit to edit the whole file at once
  • Check one value with git config user.email inside a repo
  • Keep work and personal identities apart with includeIf (Sheet 03)

Quick Summary

  • git --version — confirm the install
  • user.name / user.email — required identity
  • init.defaultBranch main — modern default
  • core.editor — editor for messages
