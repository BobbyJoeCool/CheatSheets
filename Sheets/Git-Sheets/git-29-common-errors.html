Common Errors & Fixes

detached HEAD · non-fast-forward rejected · unrelated histories · local changes would be overwritten · CRLF warnings · GIT_TRACE=1 · git gc / fsck

Reading Git's Messages

Most Git errors mean one of three things: your local state and the remote diverged, an operation would overwrite uncommitted work, or authentication failed. Git's message usually names the fix. When it doesn't, the trace variables below show exactly what Git is doing.

Notes

  • git status explains the current state and suggests commands
  • Mid-operation? Look for --continue / --abort hints
  • "warning" lines are informational; "fatal" stopped the command
  • Search the exact message text; it's usually well documented

Diagnostics

git status                         # what state am I in?
GIT_TRACE=1 git pull               # trace commands Git runs internally
GIT_CURL_VERBOSE=1 git fetch       # HTTPS request/response details
GIT_SSH_COMMAND="ssh -v" git fetch # SSH handshake details
git config --list --show-origin    # which config is in effect
git remote -v                      # are the URLs what you expect?
git fsck                           # check repository integrity
git gc                             # pack and clean up objects

Code Explained

GIT_TRACE=1 — prints each internal command and timing
GIT_CURL_VERBOSE — debugs HTTPS auth and proxies
GIT_SSH_COMMAND — runs SSH with verbose output
--show-origin — finds a surprising setting
fsck / gc — integrity check and housekeeping

⚠ Common Mistakes

  • Fixing a rejected push with --force. You overwrite others' work; integrate first
  • Using --allow-unrelated-histories to silence an error. It's for intentionally joining two repos
  • Ignoring "detached HEAD". Commits made there are easy to lose

✓ Tips & Best Practices

  • Read the full message: Git usually prints the exact command to run
  • Run git status after every error before trying anything else
  • Keep Git updated: newer versions give clearer errors and hints

Quick Summary

  • git status — first diagnostic
  • GIT_TRACE=1 — see what Git does
  • diverged → pull --rebase
  • dirty tree → commit or stash
