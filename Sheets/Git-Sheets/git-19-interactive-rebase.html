Sheet 19

Interactive Rebase

rebase -i HEAD~5 · pick reword edit · squash fixup drop · exec · reordering · commit --fixup + --autosquash

Editing Your Own History

Interactive rebase opens a todo list of commits that you edit to reorder, combine, reword, split, or drop them before sharing. It's how messy local work ("wip", "fix typo") becomes a clean series of reviewable commits. Save and close the editor to start; Git pauses where you asked it to.

Notes

  • The list is oldest at the top (opposite of git log)
  • Deleting a line drops that commit
  • HEAD~5 edits the last 5 commits; -i main edits everything since main
  • Same golden rule: only for commits not yet shared

A Todo List

git rebase -i HEAD~5      # or: git rebase -i main

pick   a1b2c3d Add login form
reword b2c3d4e Add validaton        # fix the typo in this message
fixup  c3d4e5f fix lint             # fold into the commit above, drop msg
squash d4e5f6a Add error messages   # fold in, combine messages
edit   e5f6a7b Add API client       # stop here to amend or split
exec   npm test                     # run a command; stop if it fails
drop   f6a7b8c debug logging        # remove this commit

# fixup workflow: mark fixes as you go, squash automatically later
git commit --fixup=a1b2c3d
git rebase -i --autosquash main
git config --global rebase.autoSquash true

Code Explained

reword — stops only to edit the message
fixup — melds into the previous commit, discards this message
squash — melds in and lets you merge both messages
edit — pauses; commit --amend or split, then --continue
exec — runs a shell command between commits
--autosquash — moves fixup! commits under their targets

Split a Commit (at edit)

1git reset HEAD~

⚠ Common Mistakes

  • Reading the list top-down as newest first. The top line is the oldest commit
  • Squashing the first line. squash/fixup need a commit above them to meld into
  • Interactive-rebasing past a merge without -r. Merge commits get flattened away

✓ Tips & Best Practices

  • Use git rebase -i --exec "npm test" main to test every commit
  • Set sequence.editor if you prefer a different editor for todo lists
  • Escape hatch: git rebase --abort, or git reset --hard ORIG_HEAD after finishing

Quick Summary

  • rebase -i — edit a commit list
  • fixup / squash — combine
  • reword / edit — change
  • --fixup + --autosquash — automate
