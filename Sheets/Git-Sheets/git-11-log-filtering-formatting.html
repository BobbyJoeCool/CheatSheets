Sheet 11

Log Filtering & Formatting

--author · --since / --until · --grep · -S pickaxe · -G regex · -- <path> · --pretty=format: · --no-merges

Finding the Right Commit

Filters narrow the log by author, date, message, path, or by the content a commit added or removed. The pickaxe options -S and -G are the fastest way to find when a function or string appeared or disappeared. --pretty=format: builds custom output for reports, changelogs, and scripts.

Notes

  • Multiple --author or --grep filters are OR'd by default
  • Add --all-match to require every --grep to match
  • Dates accept 2026-01-31, "2 weeks ago", yesterday
  • -i makes --grep and --author case-insensitive

Filters and Formats

git log --author="Ada"                    # commits by an author (regex)
git log --since="2 weeks ago" --until=yesterday
git log --grep="JIRA-142"                 # search commit messages
git log -S "parseToken" --oneline         # added/removed this string
git log -G "timeout\s*=" --oneline        # diff lines matching a regex
git log --no-merges main..feature         # skip merge commits
git log --merges --first-parent main      # only merge commits on main
git log --diff-filter=D --name-only       # commits that deleted files

git log --pretty=format:"%h %ad %an %s" --date=short
# a1b2c3d 2026-10-02 Ada Lovelace Fix login redirect
git log --pretty=format:"- %s (%h)" v1.2..v1.3   # changelog lines
git log --format="%H" -1                  # full hash of HEAD (scripts)

Code Explained

--author — matches name or email, regex allowed
-S <string> — commits where the string's count changed
-G <regex> — commits whose diff has a matching line
--diff-filter=D — A added, M modified, D deleted, R renamed
--pretty=format: — custom output using placeholders
--date=short — YYYY-MM-DD; also relative, iso

⚠ Common Mistakes

  • Using --grep to find code. It searches messages only; use -S or -G for content
  • Quoting regex characters in --author. --author="J. Smith" treats . as any character
  • Forgetting --date= in a format. %ad then prints the long default date

✓ Tips & Best Practices

  • Add -p to -S searches to see the exact change
  • Use %C(auto)%d in formats to get colored branch names
  • Combine --since and shortlog -sn for team activity reports

Quick Summary

  • --author / --grep — who / message
  • -S / -G — content search
  • --since — date range
  • --pretty=format: — custom output
