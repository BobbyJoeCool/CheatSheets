Sheet 10

Log Basics

git log · --oneline · --graph --all --decorate · -n 5 · -p · --stat · --follow · git shortlog -sn

Browsing History

git log lists commits reachable from HEAD, newest first. On its own it is verbose, so most people use a compact alias built from --oneline --graph --all. Add -p to see each commit's patch or --stat for a per-file summary. Give it a path to see only commits that touched that file.

Notes

  • Press q to leave the pager, / to search inside it
  • --all includes every branch and tag, not just HEAD
  • --decorate shows branch/tag names (on by default in a terminal)
  • --follow tracks a single file across renames

Everyday Log Commands

git log                              # full log: hash, author, date, message
git log --oneline                    # a1b2c3d Fix login redirect
git log -n 5                         # last 5 commits (also: -5)
git log --oneline --graph --all      # ASCII branch graph of everything
git log -p                           # each commit with its diff
git log --stat                       # files changed per commit
git log main..feature                # commits on feature not on main
git log -- src/auth.js               # commits that touched a file
git log --follow -- src/login.js     # ...including before a rename
git log -L 40,60:src/app.js          # history of lines 40-60

git shortlog -sn                     # commit count per author
git shortlog -sn --since="1 month ago"
git log --oneline | wc -l            # number of commits on HEAD

Code Explained

--oneline — short hash + subject, one line per commit
--graph — draws branch and merge lines
main..feature — reachable from feature, not from main
-- <path> — only commits that changed that path
-L start,end:file — line-range history with diffs
shortlog -sn — summary, numbered, sorted by count

⚠ Common Mistakes

  • Forgetting --all and thinking a branch's commits are gone. Plain git log only follows HEAD
  • Using --follow with multiple paths. It only works for a single file
  • Reading a busy graph without --oneline. Combine them or the graph is unreadable

✓ Tips & Best Practices

  • Set git config --global alias.lg "log --oneline --graph --all"
  • Use git log --first-parent main to see just merged PRs
  • Pipe to --no-pager when scripting: git --no-pager log -5

Quick Summary

  • log --oneline — compact history
  • --graph --all — visual branch map
  • -p / --stat — details per commit
  • -- <file> / --follow — file history
