Oops! — Not Pushed Yet

SituationFix
Typo in last commit messagegit commit --amend
Forgot a file in last commitgit add f && git commit --amend --no-edit
Committed to the wrong branchgit branch new && git reset --hard HEAD~1 && git switch new
Want to redo the last commitgit reset --soft HEAD~1
Messy commits before a PRgit rebase -i main
Reset/rebase went wronggit reflog → git reset --hard HEAD@{n}
Deleted a branchgit branch <name> <sha-from-message>

Oops! — Already Pushed / Other

SituationFix
Bad commit on maingit revert <sha> + push
Bad merge on maingit revert -m 1 <merge>
Pushed a secretrotate it, then filter-repo (34)
Push rejectedgit pull --rebase → push
Need to update my PR after rebasegit push --force-with-lease
Committed in detached HEADgit switch -c <branch>
Lost uncommitted workonly if stashed/staged: git fsck --lost-found

⚠ Common Mistakes

  • reset on pushed commits; use revert
  • --force instead of --force-with-lease
  • --ours/--theirs swap meaning in a rebase

✓ Tips & Best Practices

  • Make a backup branch before risky operations
  • Enable rerere and zdiff3 for easier conflicts
  • When stuck, git status names the next command

Quick Summary

  • pushed → revert · local → reset
  • lost commits live in the reflog
  • every operation has --abort
