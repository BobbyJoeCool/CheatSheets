⚠ Common Mistakes

  • Tabs for indentation — YAML only allows spaces
  • Unquoted NO, on, 3.10 or 012 changing type in YAML 1.1 parsers
  • Missing space after : or -, so the line parses as one plain string

✓ Tips & Best Practices

  • Quote any value that only looks like a number, boolean or date
  • Use | for scripts and >- for long one-line text
  • Keep anchors in a top-level x- or .base key and merge with <<:

Quick Summary

  • key: value maps, - item lists, indentation nests
  • Quotes: single = literal, double = escapes
  • &anchor / *alias / <<: — reuse
  • !!type forces a type; --- splits documents
