⚠ Common Mistakes

  • yaml.load without a safe loader — can build arbitrary objects
  • Unquoted port mappings like 22:22 (sexagesimal in YAML 1.1)
  • Assuming merge keys <<: work everywhere — they are not in YAML 1.2 core

✓ Tips & Best Practices

  • Add a $schema modeline so editors autocomplete and validate
  • Run yamllint and the tool's own validator in CI
  • Convert with yq -o=json to see exactly what a parser reads

Quick Summary

  • Compose, Actions and Kubernetes are plain YAML maps
  • yq reads and edits; yamllint checks style
  • Always use the safe loader in code
  • Validate with JSON Schema or the tool's checker
