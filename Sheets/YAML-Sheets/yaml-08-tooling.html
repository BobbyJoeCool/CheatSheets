Parsing & Validation

Every language has at least one YAML library, but they differ in YAML version support, security defaults, and round-trip fidelity. PyYAML is the most common Python library but defaults to YAML 1.1 and has unsafe loaders. ruamel.yaml provides true YAML 1.2 and preserves comments on round-trip. In JavaScript, js-yaml is the de facto standard. Always use the safe loader/parser variant when loading untrusted input — unsafe loaders can execute arbitrary code via custom tags.

Safety & Best Practices

  • Never use yaml.load() in Python — always use yaml.safe_load()
  • yaml.safe_load() only resolves standard YAML types; no custom Python objects
  • In Node.js, js-yaml uses safe schema by default
  • Run yamllint in CI to catch syntax and style issues before merge
  • yamllint -d relaxed file.yml — relaxed profile allows more flexible formatting
  • VS Code: install YAML extension by Red Hat for schema validation and autocompletion
  • JSON Schema can validate YAML — many tools support $schema in YAML files

Reading & Writing YAML in Code

# ── Python: PyYAML ───────────────────────────────────────────
import yaml

# Read YAML file safely
with open("config.yml") as f:
    config = yaml.safe_load(f)     # returns dict
    # config["app"]["port"] → 8080

# Read YAML string
data = yaml.safe_load("name: Alice\nage: 30")
# → {"name": "Alice", "age": 30}

# Write YAML
output = yaml.dump({"key": "value", "num": 42})
# → "key: value\nnum: 42\n"

# Pretty-print with options
yaml.dump(data, default_flow_style=False, indent=2)

# Multiple documents
docs = list(yaml.safe_load_all(open("multi.yml")))


# ── Python: ruamel.yaml (YAML 1.2 + comment-preserving) ─────
from ruamel.yaml import YAML
yml = YAML()
yml.preserve_quotes = True

with open("config.yml") as f:
    data = yml.load(f)             # preserves comments!

data["version"] = "2.0"
with open("config.yml", "w") as f:
    yml.dump(data, f)              # comments stay intact

Notes

yaml.safe_load() — only use yaml.load() with Loader=yaml.SafeLoader; bare load() can execute code
yaml.safe_load_all() — returns a generator of documents from a multi-document file
default_flow_style=False — forces block style output; True produces compact inline YAML
ruamel.yaml — preserves comments, quote styles, and key ordering on round-trip writes
yml.load(f) — ruamel's load is safe by default when using the YAML() constructor with no type argument
For JavaScript: const yaml = require('js-yaml'); yaml.load(str) — same pattern, safe by default
For Go: annotate structs with yaml:"field_name" tags then call yaml.Unmarshal(data, &cfg)

Common Mistakes

  • Using bare yaml.load() in Python — always use yaml.safe_load() or pass Loader=yaml.SafeLoader
  • Expecting PyYAML to honor %YAML 1.2 — it doesn't; use ruamel.yaml for 1.2 compliance
  • Using yaml.load_all() without iterating — it returns a lazy generator, not a list
  • Round-tripping with PyYAML loses comments, custom tags, and formatting — use ruamel.yaml when preserving these matters

Tips

  • Use yq on the command line to query and transform YAML files — yq '.services.web.image' docker-compose.yml
  • Add yamllint to your pre-commit hooks — catches indentation errors before they reach CI
  • Install the VS Code Red Hat YAML extension and point it at JSON Schema files for inline validation and autocomplete

Summary

  • yaml.safe_load() — always use safe loader in Python
  • ruamel.yaml — YAML 1.2 + round-trip comment preservation
  • js-yaml — standard JavaScript YAML parser
  • yamllint — lint YAML files in CI pipelines
  • yq — jq-style CLI tool for querying YAML files
