Requests, Limits & Quotas

requests vs limits · millicores / Mi · QoS classes · OOMKilled · CPU throttling · LimitRange · ResourceQuota

Sizing Containers

Requests are what the scheduler reserves: a pod only lands on a node with that much unrequested CPU and memory. Limits are hard caps enforced at runtime: going over the CPU limit gets the container throttled; going over the memory limit gets it OOMKilled. LimitRange sets per-container defaults in a namespace; ResourceQuota caps the namespace's totals.

Notes

  • Requests drive scheduling and autoscaling; set them on every container
  • Many teams set a memory limit but no CPU limit, to avoid throttling
  • With a quota on CPU/memory, pods without requests are rejected

Resources & Quota

containers:
  - name: api
    image: ghcr.io/acme/api:1.4.2
    resources:
      requests: { cpu: 250m, memory: 256Mi }   # reserved for scheduling
      limits:   { memory: 512Mi }              # hard cap (no CPU limit)
---
apiVersion: v1
kind: ResourceQuota                 # totals for the whole namespace
metadata: { name: shop-quota, namespace: shop }
spec:
  hard:
    requests.cpu: "8"
    requests.memory: 16Gi
    limits.memory: 32Gi
    pods: "50"
    persistentvolumeclaims: "10"

Code Explained

250m — 250 millicores = a quarter of one CPU
256Mi — mebibytes (220); M is 106
Limit only → request defaults to the limit
hard — new pods that would exceed it are rejected
kubectl describe quota -n shop — used vs hard

⚠ Common Mistakes

  • No requests — scheduler overpacks nodes and the HPA can't compute utilization
  • Memory limit below real peak usage — random OOMKilled restarts
  • Tight CPU limits on latency-sensitive apps — throttling spikes p99

✓ Tips & Best Practices

  • Measure with kubectl top pods before picking numbers
  • Set memory request = limit for predictable memory
  • Add LimitRange defaults so forgotten specs still get sane values

Quick Summary

  • requests — reserved, used to schedule
  • limits — CPU throttles, memory kills
  • LimitRange / ResourceQuota — defaults / totals
