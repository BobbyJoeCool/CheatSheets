Volumes & Persistent Storage

emptyDir · hostPath · PersistentVolume · PersistentVolumeClaim · StorageClass · RWO / RWX / RWOP · CSI

Data That Outlives Containers

A volume is a directory mounted into containers. emptyDir lives as long as the pod. For data that must survive the pod, a PersistentVolumeClaim (PVC) requests storage; a StorageClass tells a CSI driver to provision a matching PersistentVolume (PV) on demand, such as an EBS, Persistent Disk or Azure Disk volume.

Notes

  • PVCs are namespaced; PVs and StorageClasses are cluster-scoped
  • One class can be the default (annotation is-default-class)
  • Block disks are usually ReadWriteOnce: one node at a time
  • Shared RWX needs a file system: EFS, Filestore, Azure Files, NFS

PVC + Pod

apiVersion: v1
kind: PersistentVolumeClaim
metadata: { name: pg-data }
spec:
  accessModes: [ReadWriteOnce]       # one node at a time
  storageClassName: fast-ssd         # omit → default class
  resources: { requests: { storage: 20Gi } }
---
# inside a Pod / pod template spec:
volumes:
  - { name: data, persistentVolumeClaim: { claimName: pg-data } }
  - { name: scratch, emptyDir: { sizeLimit: 1Gi } }   # dies with pod
containers:
  - name: db
    image: postgres:17
    volumeMounts:
      - { name: data, mountPath: /var/lib/postgresql/data }
      - { name: scratch, mountPath: /tmp }

Code Explained

accessModes — must be supported by the driver
storageClassName: "" — bind only to a pre-made PV
requests.storage — grow later if the class allows expansion
claimName — PVC must be in the pod's namespace
emptyDir.medium: Memory — tmpfs, counts toward memory

⚠ Common Mistakes

  • PVC stuck Pending — no default class, or the class can't satisfy the access mode
  • reclaimPolicy: Delete on precious data — deleting the PVC deletes the disk
  • Two pods on different nodes sharing an RWO volume — second one won't start

✓ Tips & Best Practices

  • Use WaitForFirstConsumer so disks are created in the pod's zone
  • Resize: edit spec.resources.requests.storage on the PVC
  • Back up volumes with VolumeSnapshots or Velero

Quick Summary

  • emptyDir — scratch, pod lifetime
  • PVC — request; PV — actual disk
  • StorageClass — dynamic provisioning via CSI
  • RWO / RWX / RWOP — who can mount
