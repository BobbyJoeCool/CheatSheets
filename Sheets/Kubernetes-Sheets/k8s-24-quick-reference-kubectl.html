⚠ Common Mistakes

  • Running against the wrong context — check before you delete
  • delete ns deletes everything inside
  • kubectl edit changes are lost on the next apply

✓ Tips & Best Practices

  • alias k=kubectl + completion
  • -o name | xargs for bulk work
  • kubectl explain beats searching docs for field names
