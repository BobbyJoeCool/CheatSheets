Controlling Where Pods Land

The scheduler filters nodes that fit a pod's requests, then scores them. You steer it with nodeSelector and node affinity (pod wants certain nodes), pod affinity / anti-affinity (near or away from other pods), topology spread (even out across zones or nodes) and taints, which repel pods unless they carry a matching toleration.

Notes

  • required… rules are hard; preferred… rules are weighted hints
  • …IgnoredDuringExecution: running pods aren't evicted if labels change
  • A toleration allows a tainted node; it doesn't attract pods there

Placement Rules

spec:
  nodeSelector: { kubernetes.io/arch: arm64 }   # simple must-match
  affinity:
    podAntiAffinity:                    # keep replicas apart
      preferredDuringSchedulingIgnoredDuringExecution:
        - weight: 100
          podAffinityTerm:
            labelSelector: { matchLabels: { app: web } }
            topologyKey: kubernetes.io/hostname
  topologySpreadConstraints:            # even across zones
    - maxSkew: 1
      topologyKey: topology.kubernetes.io/zone
      whenUnsatisfiable: ScheduleAnyway
      labelSelector: { matchLabels: { app: web } }
  tolerations:                          # may use GPU nodes
    - { key: gpu, operator: Exists, effect: NoSchedule }

Code Explained

nodeSelector — node must have every label
topologyKey: hostname — "apart" means different nodes
maxSkew: 1 — zone pod counts differ by at most 1
ScheduleAnyway — soft; DoNotSchedule — hard
operator: Exists — any value of the key

⚠ Common Mistakes

  • Hard anti-affinity with more replicas than nodes — extra pods stay Pending
  • Expecting a toleration to pin pods to tainted nodes — add affinity too
  • drain without a PDB — every replica may be evicted at once

✓ Tips & Best Practices

  • Prefer topology spread over pod anti-affinity for spreading
  • Dedicated nodes = taint + toleration + node affinity together
  • describe pod Events show which filter failed

Quick Summary

  • nodeSelector / nodeAffinity — pick nodes
  • taints + tolerations — keep pods off
  • cordon / drain / uncordon — maintenance
