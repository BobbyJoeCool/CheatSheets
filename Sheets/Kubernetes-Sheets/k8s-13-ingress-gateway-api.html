Ingress & Gateway API

Ingress rules · ingressClassName · TLS · GatewayClass · Gateway · HTTPRoute · path / header matching

HTTP Routing Into the Cluster

Ingress routes HTTP(S) by host and path to Services, through an ingress controller you install. It's stable but frozen. Gateway API is its successor: roles are split into GatewayClass (provider), Gateway (listeners, ports, TLS; owned by ops) and HTTPRoute (owned by app teams), with header matching, traffic weights and more built in.

Notes

  • Both need a controller: Envoy Gateway, Istio, Cilium, Traefik, cloud LBs…
  • Community ingress-nginx is retired; plan a migration
  • Gateway API CRDs may need installing

Ingress

apiVersion: networking.k8s.io/v1
kind: Ingress
metadata: { name: shop }
spec:
  ingressClassName: traefik          # which controller handles it
  tls: [{ hosts: [shop.acme.io], secretName: shop-tls }]
  rules:
    - host: shop.acme.io
      http:
        paths:
          - path: /api
            pathType: Prefix
            backend: { service: { name: api, port: { number: 80 } } }

Gateway API: HTTPRoute

apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata: { name: shop }
spec:
  parentRefs: [{ name: public-gw }]  # attach to a Gateway
  rules:
    - matches: [{ path: { type: PathPrefix, value: /api } }]
      backendRefs:
        - { name: api, port: 80, weight: 90 }
        - { name: api-v2, port: 80, weight: 10 }   # 10% canary

Code Explained

ingressClassName — picks the controller; list with get ingressclass
tls.secretName — a kubernetes.io/tls Secret
pathType: Prefix — /api matches /api/x, not /apix
parentRefs — the Gateway must allow routes from this namespace
weight — split traffic without a service mesh

⚠ Common Mistakes

  • No controller installed — Ingress objects are accepted and do nothing
  • Missing ingressClassName with no default class — ignored
  • Controller-specific annotations don't port between controllers

✓ Tips & Best Practices

  • New setups: start with Gateway API
  • kubectl describe httproute shop → status shows Accepted / ResolvedRefs
  • Automate TLS with cert-manager

Quick Summary

  • Ingress — host/path → Service, frozen API
  • Gateway — listeners, owned by ops
  • HTTPRoute — routing rules, owned by apps
  • controller required for both
