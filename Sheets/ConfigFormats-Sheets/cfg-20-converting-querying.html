Converting & Querying Config

jq · yq · dasel · taplo · format conversion · reading a key in scripts · round-tripping and comment loss

Read and Change Config From the Command Line

Shell scripts and CI often need one value from a config file or a quick format change. jq queries JSON; yq (mikefarah) uses the same style of expressions on YAML, JSON, TOML, XML and .properties, and converts between them; dasel and taplo do similar jobs. Converting is easy, but most tools drop comments and reformat, so convert copies, not the files people edit.

Notes

  • yq in this sheet is mikefarah/yq v4 (Go); a different Python yq wraps jq
  • -r (jq) / plain output (yq) prints strings without quotes
  • -i edits a file in place (yq)
  • ruamel.yaml and tomlkit edit files and keep comments, from code

One-Liners

jq -r '.version' package.json                 # 1.4.0
jq '.scripts | keys' package.json               # ["build","dev","lint","test"]
yq '.services.db.image' compose.yaml            # postgres:17
yq -p toml '.project.version' pyproject.toml    # 1.4.0
yq -p toml -o json '.' pyproject.toml           # TOML → JSON
yq -o yaml '.' tsconfig.json                    # JSON → YAML
yq -p props -o yaml '.' app.properties          # .properties → YAML
yq -i '.services.api.ports[0] = "9090:3000"' compose.yaml
taplo get -f pyproject.toml project.version     # 1.4.0
VERSION=$(jq -r .version package.json)          # use in a script
git diff --exit-code package.json               # fail CI if a step changed it

Code Explained

-p sets the input format and -o the output format for yq
yq -i keeps most comments in YAML, but conversions between formats lose them
jq -r matters in scripts; without it you get "1.4.0" with quotes
Both tools return non-zero on parse errors, so they double as quick validators

Same Data In…

  • JSON query jq '.compilerOptions.strict' tsconfig.json (fails on comments; strip them or use yq)
  • Python python -c "import tomllib;print(tomllib.load(open('pyproject.toml','rb'))['project']['version'])"

Gotcha

  • jq fails on JSONC files like tsconfig.json; yq -p json is more forgiving
  • Round-tripping TOML through JSON loses date types and inline-table style

⚠ Common Mistakes

  • Converting a hand-edited YAML file to JSON and back, losing every comment
  • Installing the Python yq and getting different flags from the examples
  • Parsing config with grep / sed and breaking on the first reformat

✓ Tips & Best Practices

  • Read values with jq / yq in CI instead of hard-coding versions twice
  • Use yq -i for small automated edits to YAML; review the diff
  • Pipe through yq -P to pretty-print any supported format

Quick Summary

  • jq — query JSON
  • yq -p X -o Y — convert formats
  • yq -i — edit in place
  • conversions drop comments — edit originals by hand
