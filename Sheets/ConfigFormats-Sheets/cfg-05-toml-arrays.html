TOML Arrays & Arrays of Tables

arrays · mixed-type arrays · trailing commas · [[array.of.tables]] · nested arrays of tables · when to use which

Lists of Values and Lists of Records

An array is [ … ] of values, and can span lines with a trailing comma. A list of records uses an array of tables: each [[name]] header adds a new table to the list name. This is how Cargo.toml lists binaries, how pyproject.toml lists tool overrides, and how you'd list servers or users.

Notes

  • Arrays may mix types since TOML 1.0 ([1, "a"])
  • Trailing commas are allowed in arrays
  • Each [[x]] appends; the order is kept
  • Sub-tables of the last element use [x.sub] right after it

Arrays and [[Arrays of Tables]]

ports = [8080, 8443]
hosts = [
  "alpha",
  "beta",          # trailing comma OK
]
matrix = [[1, 2], [3, 4]]

[[servers]]
name = "web-1"
ip = "10.0.0.1"
roles = ["web"]

[[servers]]
name = "db-1"
ip = "10.0.0.2"

[servers.backup]            # belongs to db-1 (last element)
schedule = "daily"

# short records can be inline instead
users = [ { name = "ann", admin = true }, { name = "bo" } ]

Code Explained

Two [[servers]] headers make an array with two tables
[servers.backup] attaches to the most recent [[servers]] entry
The inline form fits short records; headers read better for long ones
Arrays of arrays (matrix) are fine

Same Data In…

  • JSON {"servers": [{"name": "web-1", "ip": "10.0.0.1"}, {"name": "db-1", "backup": {"schedule": "daily"}}]}
  • YAML servers: / - name: web-1 / - name: db-1 / backup: {schedule: daily}

Gotcha

  • Writing [servers] (single brackets) for the second server is an error: a table can't be redefined
  • Once users is an inline array, [[users]] later in the file is an error

Which to Use

DataWrite it as
List of plain valuesports = [80, 443]
Few short recordsInline array of inline tables
Records with many keys[[records]] headers
Records with sub-tables[[records]] + [records.sub]

⚠ Common Mistakes

  • Using [x] instead of [[x]] for a list item
  • Putting a sub-table header after a different array's entries, so it attaches to the wrong element
  • Very long inline arrays of tables that should have been [[…]] blocks

✓ Tips & Best Practices

  • One array element per [[ ]] block, with a blank line between, reads like a list of cards
  • Break long arrays across lines with a trailing comma; diffs stay clean
  • Convert to JSON (yq -p toml -o json) when unsure how a file nests

Quick Summary

  • [a, b] — array
  • [[x]] — append a table to array x
  • [x.sub] — sub-table of the last element
  • trailing commas — allowed in arrays
