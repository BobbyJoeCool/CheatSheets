Sheet 07

INI Files

[section] · key = value / key: value · ; and # comments · no standard spec · interpolation · setup.cfg · .gitconfig

Sections and Strings, No Standard

An INI file is [section] headers followed by key = value lines. It is old, simple and unstandardized: each parser decides whether : works as a separator, which comment characters count, whether keys are case-sensitive and whether values can span lines. Everything is a string. You'll meet it in setup.cfg, tox.ini, .gitconfig, php.ini, .editorconfig, my.cnf and Windows apps.

Notes

  • Python's configparser lowercases keys by default
  • Values are strings; getint(), getboolean() convert them
  • [DEFAULT] (configparser) provides fallbacks for every section
  • No nesting; [a.b] is just a section named "a.b" to most parsers

Parse It

  • Python configparser.ConfigParser().read("app.ini")
  • JavaScript import ini from "ini"; ini.parse(text)
  • Java Apache Commons INIConfiguration (or ini4j)

app.ini

; comment (also # in most parsers)
[DEFAULT]
log_level = info

[server]
host = 0.0.0.0
port = 8080
debug: false              ; ":" works in configparser

[database]
url = postgres://db:5432/orders
pool = 10
dsn = %(url)s?pool=%(pool)s   ; configparser interpolation

[paths]
data = /var/lib/orders
cache = ${paths:data}/cache   ; ExtendedInterpolation syntax

Code Explained

[DEFAULT] keys appear in every section unless overridden
%(name)s is configparser's basic interpolation; ${section:key} needs ExtendedInterpolation
debug: false reads as the string "false"; getboolean turns it into False
Inline ; comments only work in some parsers (configparser needs inline_comment_prefixes)

Same Data In…

  • TOML [server] / port = 8080 / debug = false (typed)
  • .properties server.port=8080
  • .env SERVER_PORT=8080

Gotcha

  • A literal % in a configparser value must be %%, or interpolation raises an error
  • .gitconfig is INI-like but has its own rules (subsections like [remote "origin"])

⚠ Common Mistakes

  • Assuming INI syntax is the same everywhere and moving a file between tools
  • Reading port and comparing it to an integer without converting it
  • Writing a % in a password inside a configparser file

✓ Tips & Best Practices

  • Use configparser.RawConfigParser or interpolation=None when values contain %
  • Set optionxform = str on configparser to keep key case
  • For new Python projects, put tool config in pyproject.toml instead of setup.cfg

Quick Summary

  • [section] + key = value
  • no spec — parser decides the details
  • everything is a string
  • [DEFAULT] + interpolation — configparser extras
