Sheet 07

Inline Tables

{ key = value } · nesting · dotted keys inside · closed tables · multi-line + trailing comma (1.1)

A Whole Table as One Value

An inline table writes a small table as a value: point = { x = 1, y = 2 }. It is complete the moment it closes, so no later key or header can add to it. TOML 1.0 allows no newlines between entries and no trailing comma; TOML 1.1 allows both.

Notes

  • Inline tables can nest: a = { b = { c = 1 } }
  • Dotted keys work inside: { type.name = "pug" }
  • Commas separate pairs; {} is an empty table
  • Best for small, fixed shapes: points, versions, name/email pairs
  • Inside arrays they make compact lists of records

Inline Table Forms

point   = { x = 1, y = 2 }
version = { major = 2, minor = 4, patch = 0 }
animal  = { type.name = "pug" }
empty   = {}

# Cargo.toml-style dependency
serde = { version = "1.0", features = ["derive"] }

# TOML 1.1: multi-line with a trailing comma
author = {
  name  = "Bob",
  email = "bob@example.com",
}

# point.z = 3      # ERROR: point is closed
# [point]          # ERROR: point already defined

Code Explained

{ type.name = "pug" } is the table { type = { name = "pug" } }
serde = { … } gives a dependency a version and options in one line
The author form is TOML 1.1 only; keep inline tables on one line for 1.0 tools
After point = { … }, nothing can add keys to point

Same Data In…

  • JSON {"serde": {"version": "1.0", "features": ["derive"]}}
  • YAML serde: {version: "1.0", features: [derive]}

Gotcha

  • A TOML 1.0 parser rejects multi-line inline tables; check before using them in pyproject.toml
  • An inline table can't be extended later by a [header] or a dotted key

⚠ Common Mistakes

  • Adding keys to an inline table further down the file
  • Packing a dozen keys into one inline table instead of using a header
  • Using trailing commas in a file a TOML 1.0 parser reads

✓ Tips & Best Practices

  • Use inline tables for dependency specs and small coordinate-like values
  • Let taplo fmt align = across a group of inline tables
  • Switch to a [table] header as soon as a line wraps

Quick Summary

  • { k = v } — inline table
  • closed — no keys added later
  • TOML 1.1 — newlines and trailing comma
  • keep them short
