Format, Lint and Query TOML

Taplo is the main TOML toolkit: a formatter, linter and language server that validates files against JSON Schema. The Even Better TOML extension brings it to VS Code. For scripts, yq and dasel read TOML, and the check-toml pre-commit hook catches syntax errors before they are committed.

Notes

  • Taplo reads its settings from .taplo.toml or taplo.toml
  • #:schema <url or path> at the top of a file points Taplo at a schema
  • Without it, Even Better TOML matches files like Cargo.toml to SchemaStore; the CLI needs --default-schema-catalogs
  • toml-sort sorts keys and tables for stable diffs
  • The toml-test suite checks parsers against the spec

Command Line

# Taplo: format, check, lint
taplo fmt                       # format all .toml files
taplo fmt --check               # CI: fail if unformatted
taplo lint pyproject.toml       # syntax; schema if one is set

# query and convert
yq -p toml -o json config.toml            # TOML → JSON
yq -p toml '.database.port' config.toml   # 5432
dasel -i toml 'database.port' < config.toml  # v3

# sort keys in place
toml-sort -i pyproject.toml

Code Explained

taplo fmt --check exits non-zero when a file would change, so it fits CI
taplo lint checks syntax, plus the #:schema schema; add --default-schema-catalogs for SchemaStore
-p toml sets the input format and -o the output; recent yq echoes TOML unless you pick -o yaml or -o json
toml-sort -i rewrites the file; commit first so the diff is easy to review

Same Data In…

  • YAML yamllint + # yaml-language-server: $schema=… does the job of taplo lint + #:schema
  • JSON a "$schema" key + check-jsonschema

Gotcha

  • taplo fmt rewrites alignment and array layout; format the whole repo once before turning on --check
  • Taplo targets TOML 1.0; check 1.1 files with a 1.1 parser such as Python 3.15+ tomllib

⚠ Common Mistakes

  • Turning on taplo fmt --check in CI before formatting the repo once
  • Expecting Taplo to know your app's keys without a schema
  • Editing TOML values with sed in scripts instead of a TOML-aware tool

✓ Tips & Best Practices

  • Write a small JSON Schema for your app's config and point #:schema at it
  • Add check-toml to pre-commit for a fast syntax gate
  • Use yq -p toml -o json to feed TOML into jq-based scripts
