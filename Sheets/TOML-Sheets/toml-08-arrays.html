Arrays & Arrays of Tables

[ ] arrays · mixed types · trailing commas · [[array]] · nested [[a.b]] · sub-tables per element

Lists of Values and Lists of Records

An array is a list in square brackets: ports = [80, 443]. Arrays can mix types, span lines and end with a trailing comma. An array of tables uses double brackets, [[name]]: each header appends a new table to the array, which is how TOML writes lists of records.

Notes

  • Mixed types are allowed: [1, "two", 3.0]
  • Newlines, comments and a trailing comma are fine inside [ ]
  • Each [[products]] starts a new element; the keys below belong to it
  • [[a.b]] nests an array inside the most recent [[a]] element
  • [a.x] after [[a]] adds a sub-table to the last element only

Arrays and [[ ]]

ports  = [80, 443]
mixed  = [1, "two", 3.0]
matrix = [[1, 2], [3, 4]]
hosts  = [
  "alpha",
  "beta",   # trailing comma OK
]

[[products]]
name = "Hammer"
sku  = 738594937

[[products]]               # second element
name = "Nail"
sku  = 284758393

[[fruits]]
name = "apple"
[fruits.physical]          # sub-table of this apple
color = "red"
[[fruits.varieties]]       # array inside this apple
name = "honeycrisp"

Code Explained

matrix is an array of arrays; nesting needs no special syntax
Each [[products]] header appends one table to products
[fruits.physical] attaches to the latest [[fruits]] element, not to all of them
[[fruits.varieties]] builds an array inside that same element

Same Data In…

  • JSON {"products": [{"name": "Hammer", "sku": 738594937}, {"name": "Nail", "sku": 284758393}]}
  • YAML products: / - name: Hammer / - name: Nail

Gotcha

  • A static array can't be extended: fruits = [] followed by [[fruits]] is an error
  • [fruits] after [[fruits]] is also an error; it tries to turn the array into a table

⚠ Common Mistakes

  • Writing [products] when you meant [[products]], which makes one table instead of a list
  • Expecting [fruits.physical] to apply to every fruit; it applies only to the last one
  • Writing long records as arrays of inline tables that wrap past 100 columns

✓ Tips & Best Practices

  • Use [[ ]] for records with more than 3–4 keys
  • Put one item per line in long arrays and keep the trailing comma for clean diffs
  • Indent keys under each [[ ]] element when the file has nested arrays

Quick Summary

  • [a, b] — array, mixed types allowed
  • [[name]] — append a table
  • [name.sub] — sub-table of the last element
  • [[a.b]] — nested array of tables
