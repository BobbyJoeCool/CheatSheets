Minimal, Obvious Config

TOML (Tom's Obvious, Minimal Language) maps straight onto a hash table: a file holds key = value pairs, [table] headers, comments and blank lines. Tom Preston-Werner created it in 2013; it reached 1.0 in 2021 and 1.1.0 in December 2025. Every value has a type, so there is no YAML-style guessing.

Notes

  • Files must be valid UTF-8; extension .toml, media type application/toml
  • Keys are case-sensitive: Name and name are different keys
  • Whitespace is spaces or tabs; indentation never changes meaning
  • One key = value per line; a value spans lines only where its syntax allows
  • # outside a string starts a comment that runs to the end of the line

config.toml

# This is a TOML document
title = "Inventory Service"
debug = false
max-workers = 8

[database]
host = "db.internal"
port = 5432
timeout = 2.5        # seconds

[owner]
name = "Bob"
since = 2026-11-19

Code Explained

title = "…" — keys before the first header live in the root table
[database] — starts a table; the keys under it belong to it
5432 is an integer, 2.5 a float, false a boolean
since = 2026-11-19 is a real date value, not a string

Same Data In…

  • JSON {"title": "Inventory Service", "database": {"host": "db.internal", "port": 5432}}
  • YAML title: Inventory Service / database: {host: db.internal, port: 5432}
  • INI [database] / host = db.internal / port = 5432 (all strings)

Gotcha

  • Root keys must come first; a key written after a header belongs to that table
  • Strings need quotes: host = db.internal is a syntax error, not a string

⚠ Common Mistakes

  • Indenting keys and expecting that to nest them; only headers and dotted keys nest
  • Leaving strings unquoted the way INI allows
  • Putting root-level keys after a [table] header, which files them under that table

✓ Tips & Best Practices

  • Keep root keys at the top, then tables from general to specific
  • Run taplo fmt to normalize spacing and alignment (it targets TOML 1.0)
  • Check which TOML version your parser targets before using 1.1 syntax

Quick Summary

  • key = value — one typed pair per line
  • [table] — groups the keys below it
  • # — comment to end of line
  • UTF-8 — required encoding
