Values & Data Types

string · integer 0x 0o 0b · float inf nan · boolean · date-time · no null

Every Value Has a Type

Each value is a string, integer, float, boolean, date-time, array or inline table. Integers should cover signed 64-bit, floats should be IEEE 754 doubles, and there is no null: leave the key out to mean "not set".

Notes

  • true / false only, lowercase; yes, on and True are errors
  • Underscores go between digits: 1_000_000 (never doubled or at the ends)
  • No leading zeros in decimals: 007 is an error, 0x00FF is fine
  • Hex, octal and binary take no sign: 0xFF is fine, -0xFF is an error
  • Floats need digits on both sides of the point: .5 and 5. are errors

All the Scalar Types

port     = 8080
offset   = -17
big      = 9_223_372_036_854_775_807  # int64 max
mask     = 0xFF        # 255
mode     = 0o755       # 493
flags    = 0b1010      # 10

ratio    = 0.75
avogadro = 6.022e23
tiny     = 1e-6
limit    = inf         # also +inf, -inf
missing  = nan         # also +nan, -nan

enabled  = true
released = 2026-11-19T08:30:00Z
tags     = ["api", "v2"]
point    = { x = 1, y = 2 }

Code Explained

0x, 0o, 0b prefixes are lowercase and only for non-negative integers
6.022e23 uses an exponent; e or E, sign optional
inf and nan are lowercase keywords, not strings
Past int64, a parser keeps the exact value (Python does) or raises an error; it never wraps around

Same Data In…

  • JSON {"port": 8080, "mask": 255, "enabled": true, "released": "2026-11-19T08:30:00Z"} (dates become strings)
  • YAML port: 8080 / mask: 0xFF / enabled: true

Gotcha

  • JSON has no inf or nan; converters may reject them, map them to null or emit nonstandard Infinity
  • JavaScript numbers lose precision above 2^53; check whether your parser offers BigInt

⚠ Common Mistakes

  • Writing timeout = null; omit the key and let the app use its default
  • Using True or yes for booleans
  • Zero-padding numbers like 007 or 0800

✓ Tips & Best Practices

  • Group long numbers with _: max-bytes = 10_485_760
  • Write file modes in octal: mode = 0o644
  • Put units in the key name for durations: timeout-ms = 1500

Quick Summary

  • int64 — integers, with 0x 0o 0b
  • binary64 — floats, plus inf and nan
  • true / false — booleans
  • no null — omit the key
