Sheet 05

Dates & Times

offset date-time · local date-time · local date · local time · T or space · optional seconds (1.1)

Four Native Date and Time Types

TOML has four first-class date and time types based on RFC 3339: offset date-time, local date-time, local date and local time. Only the offset form marks an exact instant; the local forms carry no time zone, so the app decides what they mean.

Notes

  • Date and time may be separated by T or a single space
  • Fractional seconds are allowed; parsers keep at least milliseconds
  • Z means UTC; offsets look like -06:00
  • TOML 1.1 makes seconds optional: 07:32 and 2026-11-19 07:32
  • Dates are never quoted; a quoted date is just a string

All Four Types

# offset date-time: an exact instant
deploy   = 2026-11-19T14:30:00Z
standup  = 2026-11-19T09:15:00-06:00
precise  = 2026-11-19T09:15:00.250-06:00

# local date-time: no zone attached
backup   = 2026-11-19 02:00:00

# local date and local time
birthday = 2014-06-21
opens    = 08:00:00

# TOML 1.1: seconds optional
closes   = 17:30
meeting  = 2026-11-20 10:00

Code Explained

Z and -06:00 make deploy and standup comparable instants
backup means "2 AM wherever this runs"; the app picks the zone
birthday is a calendar day with no time; opens is a clock time with no date
closes = 17:30 fails in a TOML 1.0 parser; write 17:30:00 for older tools

Same Data In…

  • JSON {"deploy": "2026-11-19T14:30:00Z", "birthday": "2014-06-21"} (strings only)
  • YAML deploy: 2026-11-19T14:30:00Z (a timestamp in YAML 1.1 loaders, a string in strict 1.2 ones)

Gotcha

  • A local date-time loads in Python as a naive datetime; ordering it against an aware one raises TypeError (== just returns False)
  • Extra fractional digits are truncated, not rounded

⚠ Common Mistakes

  • Quoting dates, which turns them into plain strings
  • Using a local date-time for an event that must happen at one exact moment
  • Writing offsets without the colon: -0600

✓ Tips & Best Practices

  • Use offset date-times (Z) for timestamps that cross time zones
  • Use local dates for birthdays, holidays and other calendar days
  • Keep seconds in times if any TOML 1.0 parser reads the file

Quick Summary

  • offset date-time — exact instant
  • local date-time — wall clock, no zone
  • local date / local time — day / clock time
  • seconds optional — TOML 1.1
