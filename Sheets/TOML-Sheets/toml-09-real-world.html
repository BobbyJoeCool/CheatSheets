Real-World TOML Files

pyproject.toml · Cargo.toml · ruff.toml · hugo.toml · netlify.toml · wrangler.toml · starship.toml

Where You Meet TOML

TOML is the config format for Python packaging (pyproject.toml), Rust (Cargo.toml) and a long list of tools: Ruff, uv, Hugo, Netlify, Cloudflare Wrangler, Starship and Alacritty. The patterns repeat: a main table, per-feature tables, inline tables for options and [[ ]] for lists of rules.

Notes

  • pyproject.toml keeps each tool's settings under [tool.<name>]
  • Standalone files like ruff.toml drop the [tool.ruff] prefix
  • Cargo.toml uses inline tables for dependencies with features
  • Netlify and Wrangler use [[ ]] for redirects and bindings
  • The Config Formats set has a full pyproject.toml sheet (cfg 15)

Cargo.toml

[package]
name    = "inventory"
version = "0.3.1"
edition = "2024"

[dependencies]
serde = { version = "1", features = ["derive"] }
tokio = { version = "1", features = ["full"] }

[dev-dependencies]
assert_cmd = "2"

[[bin]]
name = "inv"
path = "src/main.rs"

[profile.release]
lto = true

Code Explained

edition = "2024" picks the Rust language edition
Inline tables add features to a dependency without a separate header
[[bin]] lists binaries; repeat the header for each one
[profile.release] tunes the optimized build

Same Data In…

  • package.json "dependencies": {"express": "^5.1.0"}, "bin": {"inv": "cli.js"}
  • pom.xml <dependency><artifactId>jackson-databind</artifactId><version>2.18.0</version></dependency>
  • pyproject dependencies = ["httpx>=0.27"] and [project.scripts] inv = "inv.cli:main"

Gotcha

  • Tools on Python 3.14 or older parse pyproject.toml as TOML 1.0; avoid 1.1-only syntax there
  • If ruff.toml exists, Ruff uses it and ignores [tool.ruff] in pyproject.toml; the two aren't merged

⚠ Common Mistakes

  • Putting Ruff settings under [ruff] in pyproject.toml instead of [tool.ruff]
  • Writing [bin] instead of [[bin]] in Cargo.toml
  • Giving a dependency features with a second line instead of an inline table

✓ Tips & Best Practices

  • Rely on SchemaStore or a #:schema line so the editor checks these files (sheet 12)
  • After editing, run the tool once (cargo check, hugo config) to catch keys it rejects
  • Keep one tool's settings in one place: pyproject.toml or its own file, not both

Quick Summary

  • pyproject.toml — [project] + [tool.*]
  • Cargo.toml — [package] + [dependencies]
  • [[redirects]], [[bin]] — lists of records
  • ruff.toml — same keys, no [tool.ruff] prefix
