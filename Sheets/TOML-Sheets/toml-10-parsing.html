Parsing & Writing TOML in Code

tomllib · tomli-w · tomlkit · smol-toml · Rust toml / toml_edit · Go BurntSushi/toml · tomlj

Loading TOML in Your Language

Python ships tomllib for reading only (3.11+ reads TOML 1.0, 3.15+ adds 1.1); writing needs tomli-w, and tomlkit keeps comments and formatting. JavaScript has smol-toml, and Rust, Go and Java libraries decode straight into structs or objects.

Notes

  • tomllib.load() needs a file opened in binary mode: open(p, "rb")
  • A plain parse-and-dump round trip drops comments and layout
  • Edit a user's file with a style-preserving library: tomlkit, toml_edit
  • Check which TOML version a library supports before using 1.1 syntax
  • Dates come back as native date and time types, not strings

Python

import tomllib, tomli_w, tomlkit

with open("config.toml", "rb") as f:
    cfg = tomllib.load(f)           # dict
cfg["database"]["port"]             # 5432

tomllib.loads('a = 1')              # {'a': 1}
tomli_w.dumps({"a": 1})             # 'a = 1\n'

doc = tomlkit.parse(open("config.toml").read())
doc["database"]["port"] = 6543      # keeps comments
open("config.toml", "w").write(tomlkit.dumps(doc))

JavaScript

import { parse, stringify } from "smol-toml";
import { readFileSync } from "node:fs";

const cfg = parse(readFileSync("config.toml", "utf8"));
cfg.database.port;                  // 5432
stringify({ a: 1 });                // 'a = 1'

Code Explained

tomllib raises tomllib.TOMLDecodeError with the line and column of bad input
tomli_w writes plain dicts; tomlkit returns a document that remembers formatting
smol-toml returns plain objects and arrays, with dates as Date-based objects
Decode into typed structs in Rust and Go so wrong types fail at load time

Same Data In…

  • Python {'port': 5432, 'since': datetime.date(2026, 11, 19)}
  • Go cfg.Port == 5432, with cfg.Since decoded into a time.Time
  • Rust Config { port: 5432, .. } through serde::Deserialize

Gotcha

  • tomllib.load(open(p)) in text mode raises TypeError; open the file with "rb"
  • tomllib has no dump; writing needs tomli-w or tomlkit

⚠ Common Mistakes

  • Opening the file in text mode for tomllib
  • Rewriting a user's file with tomli_w and wiping their comments
  • Assuming every library accepts TOML 1.1 syntax

✓ Tips & Best Practices

  • Pass parse_float=decimal.Decimal to tomllib.load for exact money values
  • Decode into typed structs to catch mistyped values; in Go, check required keys with MetaData.IsDefined
  • Use tomlkit or toml_edit for tools that update config files

Quick Summary

  • tomllib — read-only, Python 3.11+
  • tomli-w / tomlkit — write / edit with comments
  • smol-toml — JavaScript parse + stringify
  • toml, BurntSushi/toml, tomlj — Rust, Go, Java
