List<T> — Basics

new List<T> · Add · Insert · indexer · Count · Capacity · Remove · RemoveAt

The Go-To Growable List

List<T> is a resizable array: it keeps elements in order, allows duplicates, and gives O(1) access by index. It grows automatically (doubling its internal capacity) as you add items. It's the default collection for most code; inserting or removing near the start is O(n) because elements shift.

Key Facts

  • Count = items stored; Capacity = room before resize
  • Index past Count - 1 → ArgumentOutOfRangeException
  • Remove(x) removes the first match only
  • In System.Collections.Generic

List<T> Basics

List<string> fruits = ["apple", "banana"];   // or new List<string>()
fruits.Add("cherry");                         // [apple, banana, cherry]
fruits.Insert(0, "kiwi");                     // [kiwi, apple, banana, cherry]
fruits.AddRange(["fig", "date"]);             // append many

Console.WriteLine(fruits[1]);                 // apple
Console.WriteLine(fruits.Count);              // 6
fruits[0] = "lime";                           // replace

bool removed = fruits.Remove("banana");       // True
fruits.RemoveAt(0);                           // remove by index
fruits.RemoveRange(0, 2);                     // remove 2 starting at 0
Console.WriteLine(fruits.Contains("fig"));    // True
Console.WriteLine(fruits.IndexOf("date"));    // 1

var big = new List<int>(capacity: 10_000);    // pre-size
fruits.Clear();                               // Count = 0

Code Explained

Add — append to the end (amortized O(1))
Insert(i, x) — shift later items right
AddRange — append a collection
list[i] — get or set by index
Remove / RemoveAt / RemoveRange — delete
capacity: — avoid repeated growth

⚠ Common Mistakes

  • Removing items in a forward for loop — elements shift and get skipped; use RemoveAll or loop backwards
  • Using Contains on large lists in a loop — O(n²); use a HashSet<T> for lookups
  • Exposing List<T> from public APIs — callers can mutate it; return IReadOnlyList<T>

✓ Tips & Best Practices

  • Pre-size with capacity: when you know the count
  • Use Queue<T> / LinkedList<T> for frequent front inserts
  • Return IReadOnlyList<T> and accept IEnumerable<T>
