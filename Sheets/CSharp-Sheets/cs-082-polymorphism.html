Sheet 082

Polymorphism & Casting

virtual dispatch · upcasting · downcasting · is / as · override vs new · covariant return types

One Interface, Many Forms

Polymorphism lets code work with a base type or interface while each object supplies its own behavior. A call to a virtual member is dispatched at run time to the object's actual type. Upcasting (derived → base) is implicit; downcasting (base → derived) needs a check with is / as or an explicit cast.

Key Facts

  • Overridden members dispatch on the runtime type
  • Hidden (new) members dispatch on the compile-time type
  • Failed explicit cast → InvalidCastException
  • Covariant return types allowed since C# 9

Polymorphism in Action

abstract class Shape
{
    public abstract double Area();
    public virtual Shape Clone() => (Shape)MemberwiseClone();
}
class Circle(double r) : Shape
{
    public override double Area() => Math.PI * r * r;
    public override Circle Clone() => new(r);         // covariant return (C# 9)
}
class Square(double s) : Shape { public override double Area() => s * s; }

List<Shape> shapes = [new Circle(1), new Square(2)];   // upcast: implicit
foreach (var s in shapes)
    Console.WriteLine($"{s.GetType().Name}: {s.Area():F2}");

Shape sh = shapes[0];
if (sh is Circle c) Console.WriteLine("circle!");      // safe downcast
Square? sq = sh as Square;                             // null — not a square
// var bad = (Square)sh;                               // InvalidCastException

double total = shapes.Sum(s => s.Area());             // works for any Shape

Code Explained

abstract Area() — each shape must implement
Covariant return — override returns a more specific type
List<Shape> — holds any subclass
Virtual dispatch — the right Area() runs
is Circle c — test + downcast
as — null on failure; cast — exception

⚠ Common Mistakes

  • Long if (x is A) … else if (x is B) chains — move the behavior into a virtual method
  • Blind downcasts (Derived)b — use is patterns
  • Expecting new members to be polymorphic — only override participates in dispatch

✓ Tips & Best Practices

  • Program against base types or interfaces in method signatures
  • Use switch expressions on types for closed sets you don't control
  • Combine abstract base classes with sealed leaf classes

Quick Summary

  • Virtual dispatch — runtime type decides
  • Upcast implicit; downcast checked
  • is / as — safe casts
  • Covariant returns — C# 9
