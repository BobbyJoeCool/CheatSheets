Nullable Value Types

int? · Nullable<T> · HasValue · Value · GetValueOrDefault · lifted operators

Value Types That Can Be Null

Adding ? to a value type (int?, DateTime?) creates Nullable<T>, which can hold a value or no value. It's ideal for optional database columns or missing input. Operators are lifted: if either operand is null, arithmetic gives null and comparisons give false.

Key Facts

  • int? is shorthand for Nullable<int>
  • Accessing .Value when empty throws
  • ?? supplies a fallback value
  • x is int n unwraps and tests in one step

Working with int?

int? score = null;
Console.WriteLine(score.HasValue);          // False
Console.WriteLine(score ?? -1);             // -1
Console.WriteLine(score.GetValueOrDefault()); // 0
// int bad = score.Value;                   // InvalidOperationException

score = 85;
if (score is int s) Console.WriteLine(s + 1);  // 86
int sure = score.Value;                     // 85 (safe now)

int? a = null, b = 5;
Console.WriteLine(a + b);         // (empty) — null
Console.WriteLine(a > b);         // False
Console.WriteLine(a < b);         // False (!)
Console.WriteLine(a == null);     // True

DateTime? shipped = order.ShippedAt;
string label = shipped?.ToString("d") ?? "Not shipped";

Code Explained

HasValue — true when a value is present
?? — use right side when left is null
GetValueOrDefault() — value or default(T)
is int s — pattern match and unwrap
Lifted ops — null + 5 is null
?. — call a member only when not null

⚠ Common Mistakes

  • Reading .Value without checking — throws InvalidOperationException when empty
  • Assuming !(a > b) means a <= b — with nulls both are false
  • Using int? where 0 is a fine default — nullability adds checks everywhere

✓ Tips & Best Practices

  • Prefer x is int v or x ?? fallback over .HasValue + .Value
  • Map nullable DB columns to T? properties
  • Use ??= to set a default only once

Quick Summary

  • T? — value type that can be null
  • HasValue / Value — test and read
  • ?? — fallback when null
  • Lifted operators — null propagates
