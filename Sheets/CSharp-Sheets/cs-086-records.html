Records

record · positional records · with expressions · value equality · record struct · generated ToString · record inheritance

Data-Centric Types

A record (C# 9) is a class (or record struct, C# 10) designed for data. The compiler generates value equality, a readable ToString(), deconstruction and support for with expressions that copy an object with some properties changed. Positional syntax declares the whole type in one line.

Key Facts

  • record = record class — reference type
  • Positional record properties are init-only
  • with creates a shallow copy
  • Records can inherit from other records only

Records

public record Person(string Name, int Age);            // positional record

var a = new Person("Ada", 36);
var b = new Person("Ada", 36);
Console.WriteLine(a == b);                 // True  (value equality)
Console.WriteLine(ReferenceEquals(a, b));  // False
Console.WriteLine(a);                      // Person { Name = Ada, Age = 36 }

var older = a with { Age = 37 };           // non-destructive copy
var (name, age) = older;                   // deconstruct → "Ada", 37

public record Product(string Sku, decimal Price)
{
    public decimal PriceWithTax => Price * 1.2m;      // extra members
    public string Sku { get; } = Sku.ToUpperInvariant(); // customize a property
}

public abstract record Shape;
public record Circle(double R) : Shape;               // record inheritance

public readonly record struct Money(decimal Amount, string Currency);

Code Explained

Positional — properties, ctor and Deconstruct in one line

ToString() — prints members
with { … } — copy with changes
Body — add computed or customized members

⚠ Common Mistakes

  • Records holding List<T> — equality compares the list reference, not its contents
  • Using records as EF Core entities that change identity-wise — entities need reference identity
  • Expecting with to deep-copy — nested objects are shared

✓ Tips & Best Practices

  • Use records for DTOs, messages, events and value objects
  • Use readonly record struct for small values like coordinates
  • Use ImmutableArray<T> or override Equals when records hold collections

Quick Summary

  • record R(…) — data type with value equality
  • with — non-destructive mutation
  • Generated ToString, Deconstruct
  • record struct — value-type variant
