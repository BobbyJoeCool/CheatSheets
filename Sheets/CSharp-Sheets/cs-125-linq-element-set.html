LINQ — Elements, Quantifiers & Sets

First / FirstOrDefault · Single · ElementAt · Any · All · Contains · Union / Intersect / Except

Picking Elements and Comparing Sets

Element operators pick a single item: First, Last, Single, ElementAt and their OrDefault versions. Quantifiers answer yes/no questions: Any, All, Contains. Set operators combine sequences: Union, Intersect, Except, with …By versions (.NET 6) that compare by key.

Key Facts

  • First() on empty throws; FirstOrDefault() returns default
  • Single() throws if there are 0 or 2+ matches
  • FirstOrDefault(fallback) (.NET 6) sets your own default
  • Set operators remove duplicates

Elements, Quantifiers, Sets

int[] n = [3, 8, 5, 8, 1];

Console.WriteLine(n.First());                    // 3
Console.WriteLine(n.First(x => x > 4));          // 8
Console.WriteLine(n.FirstOrDefault(x => x > 9)); // 0 (default)
Console.WriteLine(n.FirstOrDefault(x => x > 9, -1)); // -1 (custom)
Console.WriteLine(n.Last());                     // 1
Console.WriteLine(n.ElementAt(2));               // 5
Console.WriteLine(n.Single(x => x == 5));        // 5
// n.Single(x => x == 8);                        // ✗ more than one match

Console.WriteLine(n.Any(x => x > 7));            // True
Console.WriteLine(n.All(x => x > 0));            // True
Console.WriteLine(n.Contains(4));                // False

int[] a = [1, 2, 3], b = [2, 3, 4];
Console.WriteLine(string.Join(",", a.Union(b)));     // 1,2,3,4
Console.WriteLine(string.Join(",", a.Intersect(b))); // 2,3
Console.WriteLine(string.Join(",", a.Except(b)));    // 1
var newUsers = incoming.ExceptBy(existing.Select(u => u.Email), u => u.Email);

⚠ Common Mistakes

  • Using First() when the sequence may be empty — throws; use FirstOrDefault and check
  • Using Single() as a fast First() — it scans everything to prove uniqueness
  • Using Concat when you wanted Union — duplicates remain

✓ Tips & Best Practices

  • Use Single when duplicates indicate a bug you want surfaced
  • Use Any() instead of Count() > 0
  • Use a HashSet<T> for repeated Contains checks

Quick Summary

  • First / Single / Last (+ OrDefault)
  • Any / All / Contains
  • Union / Intersect / Except (+ By)
  • Concat keeps duplicates
