JSON — Serialization

JsonSerializer.Serialize · Deserialize · JsonSerializerOptions · [JsonPropertyName] · [JsonIgnore] · JsonSerializerContext

System.Text.Json Serialization

JsonSerializer converts objects to JSON strings (Serialize) and back (Deserialize<T>). Behavior is set with JsonSerializerOptions — naming policy, indentation, null handling — and with attributes on properties. For speed and trimming/AOT support, a source-generated JsonSerializerContext does the work at compile time.

Key Facts

  • Default naming is as declared (PascalCase)
  • JsonSerializerDefaults.Web = camelCase + case-insensitive
  • Records and init properties are supported
  • Reuse one options instance — creating them is costly

Round Trip

public record Person(string Name, int Age, string? Email = null);

var opts = new JsonSerializerOptions(JsonSerializerDefaults.Web)
{
    WriteIndented = true,
    DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull
};

string json = JsonSerializer.Serialize(new Person("Ada", 36), opts);
// { "name": "Ada", "age": 36 }

Person? p = JsonSerializer.Deserialize<Person>(json, opts);

await using var fs = File.OpenRead("people.json");          // from a file
var people = await JsonSerializer.DeserializeAsync<List<Person>>(fs, opts);

[JsonSerializable(typeof(Person))]                          // source gen
internal partial class AppJson : JsonSerializerContext { }
string fast = JsonSerializer.Serialize(p!, AppJson.Default.Person);

Code Explained

JsonSerializerDefaults.Web — camelCase, case-insensitive
WriteIndented — pretty-print
WhenWritingNull — skip null properties
Deserialize<T> — JSON → object (may be null)
DeserializeAsync — stream from a file or HTTP body
JsonSerializerContext — compile-time, AOT-friendly

Attributes

AttributeEffect
[JsonPropertyName("id")]Rename in JSON
[JsonIgnore]Skip property
[JsonRequired]Fail if missing
[JsonConverter(typeof(JsonStringEnumConverter))]Enum as text

⚠ Common Mistakes

  • Deserializing camelCase JSON with default options — properties stay empty; use Web defaults
  • Creating new JsonSerializerOptions per call — slow; cache a static instance
  • Serializing EF entities with cycles — throws; project to DTOs or ignore cycles

✓ Tips & Best Practices

  • Use source generation for Native AOT and trimmed apps
  • Use records as DTOs for clean JSON contracts
  • Use JsonSerializer.Serialize(obj, opts) with JsonNamingPolicy.SnakeCaseLower for snake_case APIs
