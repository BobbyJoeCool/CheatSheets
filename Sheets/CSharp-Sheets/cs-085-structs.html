Structs

struct · readonly struct · ref struct · parameterless constructors · defensive copies · when to choose a struct

Lightweight Value Types

A struct is a value type: it's copied on assignment and usually lives inline (on the stack or inside another object), avoiding heap allocations. Structs suit small, immutable data like points, money or IDs. readonly struct guarantees immutability, and ref struct (like Span<T>) must stay on the stack.

Key Facts

  • Guideline: ≤ 16 bytes, immutable, value-like
  • Structs can't inherit (but can implement interfaces)
  • default(MyStruct) zeroes every field
  • Parameterless constructors allowed since C# 10

Struct Kinds

public readonly struct Point(double x, double y)       // immutable
{
    public double X { get; } = x;
    public double Y { get; } = y;
    public double Length => Math.Sqrt(X * X + Y * Y);
    public Point With(double x) => new(x, Y);
}

var p1 = new Point(3, 4);
var p2 = p1;                       // full copy
Console.WriteLine(p1.Length);      // 5
Point zero = default;              // (0, 0)

public record struct Temp(double C);   // value equality + ToString
Console.WriteLine(new Temp(20) == new Temp(20));   // True

public ref struct Parser(ReadOnlySpan<char> input)   // stack-only
{
    private ReadOnlySpan<char> _rest = input;        // can hold a span
    public char Next() { var c = _rest[0]; _rest = _rest[1..]; return c; }
}

Code Explained

readonly struct — all fields immutable
Assignment — copies every field
default — all zeros, no constructor runs
record struct — generated equality and printing
ref struct — can hold spans; never boxed or captured

⚠ Common Mistakes

  • Large mutable structs — copies are expensive and edits apply to copies
  • Mutating a struct through a property getter (list[0].X = 1) — CS1612; you'd change a copy
  • Casting structs to interfaces in hot loops — boxing allocates every time

✓ Tips & Best Practices

  • Default to readonly struct or readonly record struct
  • Pass large structs with in to avoid copying
  • Measure before converting classes to structs for performance

Quick Summary

  • struct — value type, copied
  • readonly struct — immutable
  • record struct — value equality
  • ref struct — stack-only
