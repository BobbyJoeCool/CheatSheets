Arrays — Basics

T[] · new int[5] · initializers · Length · multidimensional [,] · jagged [][] · Array.Resize

Fixed-Size Sequences

An array T[] stores a fixed number of elements of one type in contiguous memory, accessed by zero-based index. Its length is set at creation and can't change. C# supports multidimensional arrays T[,] (one rectangular block) and jagged arrays T[][] (arrays of arrays with different lengths).

Key Facts

  • Arrays are reference types; elements start at default(T)
  • Out-of-range index → IndexOutOfRangeException
  • Length = total elements; GetLength(d) per dimension
  • Use List<T> when the size changes

Creating & Using Arrays

int[] a = new int[3];                  // [0, 0, 0]
int[] b = { 1, 2, 3 };                 // initializer
int[] c = [4, 5, 6];                   // collection expression (C# 12)
string[] names = new string[2];        // [null, null]

a[0] = 10;
Console.WriteLine(b[^1]);              // 3 (last)
Console.WriteLine(c.Length);           // 3

int[,] grid = new int[2, 3];           // 2 rows × 3 cols
grid[1, 2] = 7;
Console.WriteLine(grid.GetLength(1));  // 3

int[][] jagged = [[1], [2, 3], [4, 5, 6]];
Console.WriteLine(jagged[2][1]);       // 5

Array.Resize(ref a, 5);                // new array: [10, 0, 0, 0, 0]
int[] empty = [];                      // Array.Empty<int>()

Code Explained

new int[3] — fixed size, zeroed
{ … } / [ … ] — initialize with values
b[^1] — index from the end
int[,] — rectangular, indexed [r, c]
int[][] — jagged, indexed [r][c]
Array.Resize — allocates a new array and copies

⚠ Common Mistakes

  • Using <= arr.Length in a loop — the last valid index is Length - 1
  • Expecting Array.Resize to keep references — other variables still point to the old array
  • Comparing arrays with == — compares references; use SequenceEqual

✓ Tips & Best Practices

  • Prefer jagged arrays over [,] for performance and flexibility
  • Return [] (or Array.Empty<T>()) instead of null
  • Use ReadOnlySpan<T> parameters to accept arrays without copying

Quick Summary

  • T[] — fixed-size, zero-based
  • T[,] — rectangular; T[][] — jagged
  • Length / GetLength(d) — sizes
  • […] — collection expression initializer
