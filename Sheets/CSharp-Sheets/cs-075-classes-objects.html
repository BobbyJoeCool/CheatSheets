Classes & Objects

class · new · fields · methods · this · object initializers · target-typed new()

Blueprints and Instances

A class is a reference type that bundles data (fields, properties) and behavior (methods). Creating an object with new allocates it on the heap and runs a constructor. Each object has its own copy of instance fields; this refers to the current object. Object initializers set properties right after construction.

Key Facts

  • Default class accessibility is internal; members default to private
  • Variables hold references; two variables can share one object
  • new() (target-typed) infers the class from the declaration
  • Unreferenced objects are garbage-collected

A Complete Small Class

public class BankAccount
{
    private decimal _balance;                       // field (state)
    public string Owner { get; }                    // read-only property
    public string Id { get; init; } = Guid.NewGuid().ToString("N")[..8];

    public BankAccount(string owner) => Owner = owner;   // constructor

    public decimal Balance => _balance;             // computed property

    public void Deposit(decimal amount)             // method (behavior)
    {
        ArgumentOutOfRangeException.ThrowIfNegativeOrZero(amount);
        this._balance += amount;                    // this = current object
    }
}

var acct = new BankAccount("Ada");                  // create
acct.Deposit(100m);
BankAccount other = new("Bob") { Id = "custom" };   // target-typed new
Console.WriteLine(acct.Balance);                    // 100

Code Explained

private decimal _balance — hidden state
{ get; } — set only in the constructor
init — settable in an object initializer
Constructor — runs on new
this — optional qualifier for members
new("Bob") { Id = … } — constructor + initializer

⚠ Common Mistakes

  • Making fields public — exposes internals; use properties
  • Assuming var b = a; copies an object — both variables point to the same instance
  • Doing heavy work or I/O in constructors — use a factory or an async init method

✓ Tips & Best Practices

  • Keep classes small and focused on one responsibility
  • Override ToString() for easier debugging and logging
  • Prefer record for data-only types with value equality

Quick Summary

  • class — reference type blueprint
  • new — create an instance
  • Fields hold state, methods hold behavior
