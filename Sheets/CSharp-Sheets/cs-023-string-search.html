Sheet 023

String Methods — Search

Contains · IndexOf · LastIndexOf · StartsWith · EndsWith · IndexOfAny · StringComparison

Finding Text

Search methods return a bool (Contains, StartsWith, EndsWith) or a position (IndexOf, LastIndexOf) that is -1 when nothing is found. Most have overloads that take a char or a StringComparison, which decides between ordinal (byte-exact) and culture-aware comparison and whether case matters.

Key Facts

  • Contains(string) is ordinal by default
  • IndexOf(string) and StartsWith(string) are culture-aware by default
  • char overloads are always ordinal and fastest
  • Positions are zero-based

Searching

string s = "Hello, World";

Console.WriteLine(s.Contains("World"));            // True
Console.WriteLine(s.Contains("world"));            // False
var ic = StringComparison.OrdinalIgnoreCase;
Console.WriteLine(s.Contains("world", ic));        // True
Console.WriteLine(s.StartsWith("Hell"));           // True
Console.WriteLine(s.EndsWith('d'));                // True

Console.WriteLine(s.IndexOf('o'));                 // 4
Console.WriteLine(s.IndexOf('o', 5));              // 8 (start at 5)
Console.WriteLine(s.LastIndexOf('o'));             // 8
Console.WriteLine(s.IndexOf("xyz"));               // -1
Console.WriteLine(s.IndexOfAny(['W', ',']));       // 5

int count = s.Count(c => c == 'l');                // 3 (LINQ)
bool any = s.AsSpan().ContainsAny('x', 'W');       // True

Code Explained

Contains — substring present?
StringComparison.OrdinalIgnoreCase — fast case-insensitive
IndexOf(c, start) — begin the search at start
-1 — not found
IndexOfAny — first of several chars
AsSpan().ContainsAny — allocation-free span search

⚠ Common Mistakes

  • Lower-casing both strings to compare — allocates and fails for some cultures; pass OrdinalIgnoreCase
  • Testing IndexOf(x) > 0 — misses a match at position 0; use >= 0 or Contains
  • Relying on culture-aware IndexOf(string) for protocol text — results vary by machine

✓ Tips & Best Practices

  • Always pass a StringComparison when searching with a string
  • Use SearchValues<char> for repeated multi-char searches (.NET 8+)
  • Use Regex once patterns get complex

Quick Summary

  • Contains / StartsWith / EndsWith — bool tests
  • IndexOf — position or -1
  • StringComparison — ordinal vs culture, case
  • char overloads — always ordinal
