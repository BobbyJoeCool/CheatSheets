Iterators & yield

yield return · yield break · IEnumerable<T> · deferred execution · infinite sequences · IAsyncEnumerable<T>

Lazy Sequences with yield

A method returning IEnumerable<T> can use yield return to produce items one at a time. The compiler turns it into a state machine: nothing runs until someone enumerates, and each MoveNext resumes where the last yield left off. yield break ends the sequence. This is how LINQ operators are built.

Key Facts

  • Return type must be IEnumerable<T>, IEnumerator<T> or IAsyncEnumerable<T>
  • Execution is deferred until enumeration
  • Re-enumerating runs the method again
  • yield can't appear in a catch block

Iterators

static IEnumerable<int> CountTo(int max)
{
    for (int i = 1; i <= max; i++)
    { Console.Write($"[{i}]"); yield return i; }   // runs when pulled
}

var seq = CountTo(3);                     // nothing printed yet
foreach (var n in seq) Console.Write(n);  // [1]1[2]2[3]3

static IEnumerable<long> Fibonacci()      // infinite sequence
{
    long a = 0, b = 1;
    while (true) { yield return a; (a, b) = (b, a + b); }
}
Console.WriteLine(string.Join(",", Fibonacci().Take(8)));   // 0,1,1,2,3,5,8,13

static IEnumerable<string> NonEmpty(IEnumerable<string> lines)
{
    foreach (var l in lines)
    {
        if (l == "END") yield break;      // stop early
        if (l.Length > 0) yield return l;
    }
}

Code Explained

yield return — hand out one item, pause
Deferred — calling CountTo runs nothing
Interleaving — prints happen as each item is pulled
Infinite iterator — safe with Take
yield break — end the sequence

⚠ Common Mistakes

  • Expecting argument validation to run at call time — it runs on first MoveNext; validate in a wrapper
  • Enumerating an expensive iterator several times — cache with ToList()
  • Disposing a resource before enumeration finishes — keep using inside the iterator

✓ Tips & Best Practices

  • Use the wrapper + local iterator pattern for eager checks
  • Stream large files with yield return per line
  • Use IAsyncEnumerable<T> for paged API results

Quick Summary

  • yield return — produce lazily
  • yield break — end sequence
  • Deferred execution — runs on enumeration
  • IAsyncEnumerable<T> — async streams
