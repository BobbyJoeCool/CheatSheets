Math and Random Numbers

System.Math provides rounding, powers, roots, trigonometry and clamping for double (with decimal overloads for rounding). Rounding defaults to banker's rounding (to even). Random.Shared is a thread-safe generator for everyday use; RandomNumberGenerator produces cryptographically secure values for tokens and passwords.

Key Facts

  • Math.Round(2.5) → 2 (to even)
  • Random.Next(min, max) excludes max
  • new Random(seed) gives repeatable sequences
  • MathF has float versions

Math & Random

Console.WriteLine(Math.Round(2.5));                         // 2
Console.WriteLine(Math.Round(2.5, MidpointRounding.AwayFromZero)); // 3
Console.WriteLine(Math.Round(2.345m, 2));                   // 2.34
Console.WriteLine(Math.Floor(-2.5));                        // -3
Console.WriteLine(Math.Ceiling(2.1));                       // 3
Console.WriteLine(Math.Truncate(-2.7));                     // -2
Console.WriteLine(Math.Clamp(150, 0, 100));                 // 100
Console.WriteLine(Math.Pow(2, 8));                          // 256
Console.WriteLine(Math.Sqrt(81));                           // 9

int die = Random.Shared.Next(1, 7);                         // 1–6
double r = Random.Shared.NextDouble();                      // [0, 1)
string[] colors = ["red", "green", "blue"];
string[] picks = Random.Shared.GetItems(colors, 5);         // with repeats
Random.Shared.Shuffle(colors);                              // in place

var seeded = new Random(42);                                // reproducible
int token = RandomNumberGenerator.GetInt32(100_000, 1_000_000); // secure
string hex = RandomNumberGenerator.GetHexString(16);        // .NET 8

Code Explained

Round — banker's rounding by default
AwayFromZero — school-style rounding
Floor / Ceiling / Truncate — directional rounding
Clamp — limit to a range
Random.Shared — thread-safe shared instance
RandomNumberGenerator — cryptographic randomness

⚠ Common Mistakes

  • Expecting Math.Round(2.5) to be 3 — default is to-even; pass AwayFromZero
  • Creating new Random() in a tight loop — use Random.Shared instead
  • Using Random for passwords or tokens — predictable; use RandomNumberGenerator

✓ Tips & Best Practices

  • Round decimal for money: Math.Round(x, 2, MidpointRounding.AwayFromZero)
  • Seed Random in tests for repeatable results
  • Use int.Clamp / double.Clamp generic math helpers too
