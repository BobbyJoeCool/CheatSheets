Local Functions and Scope

A local function is a method declared inside another method; it's visible only there and keeps helper logic close to where it's used. Scope in C# is the block { } where a name is declared: locals disappear at the end of their block. A static local function can't capture the outer method's variables, which prevents accidental dependencies.

Key Facts

  • Local functions can be called before their declaration
  • Non-static local functions can capture outer locals
  • A local can't shadow another local in an enclosing scope
  • Fields can be shadowed by locals; use this.x to reach the field

Local Functions

int SumOfSquares(int[] nums)
{
    int total = 0;
    foreach (var n in nums) total += Square(n);
    return total;

    static int Square(int x) => x * x;     // static: no captures
}

IEnumerable<int> Evens(int max)
{
    ArgumentOutOfRangeException.ThrowIfNegative(max); // runs eagerly
    return Iterate();

    IEnumerable<int> Iterate()             // captures max
    {
        for (int i = 0; i <= max; i += 2) yield return i;
    }
}

if (true) { int inner = 1; }
// Console.WriteLine(inner);               // ✗ CS0103: out of scope

Code Explained

Local function — declared after return, still callable
static — compiler error if it touches outer variables
Iterator helper — validates eagerly, yields lazily
Captures — Iterate reads max from the outer method
Block scope — inner exists only inside its braces

⚠ Common Mistakes

  • Declaring the same name in a nested block — CS0136: name conflicts with an outer local
  • Using a local function where a private method would be reused elsewhere — move it out
  • Letting local functions capture lots of state — make them static and pass parameters

✓ Tips & Best Practices

  • Use the eager-validation + local iterator pattern for yield methods
  • Prefer static local functions by default
  • Keep variables in the narrowest block that needs them

Quick Summary

  • Local function — helper inside a method
  • static local — no captures
  • Block scope — names end at }
  • No shadowing of enclosing locals
