⚠ Common Mistakes

  • catch (Exception ex) { throw ex; } resets the stack trace — use throw;
  • Ignoring nullable warnings instead of fixing them
  • async void methods except event handlers

✓ Tips & Best Practices

  • Turn on <Nullable>enable</Nullable> and <TreatWarningsAsErrors>
  • Prefer switch expressions and patterns over long if chains
  • Use records for DTOs and value objects

Quick Summary

  • dotnet new / run / test / add package
  • Nullable types + ?. + ?? keep nulls explicit
  • Switch expressions and patterns
  • Classes for behaviour, records for data
