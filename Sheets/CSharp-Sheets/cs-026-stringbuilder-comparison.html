Building and Comparing Strings

StringBuilder is a mutable buffer for building text in many steps without creating a new string each time. For comparison, choose ordinal (StringComparison.Ordinal) for identifiers and culture-aware for sorting user-visible text. Encoding converts between strings and bytes.

Key Facts

  • StringBuilder is in System.Text
  • string.Compare returns <0, 0 or >0
  • StringComparer.OrdinalIgnoreCase plugs into collections
  • UTF-8: ASCII = 1 byte; é = 2; 😀 = 4

StringBuilder & Comparison

var sb = new StringBuilder();
sb.Append("Items: ");
for (int i = 1; i <= 3; i++) sb.Append(i).Append(',');
sb.Length--;                       // drop last comma
sb.AppendLine().AppendLine("Done");
sb.Insert(0, ">> ").Replace("Items", "IDs");
Console.WriteLine(sb.ToString());  // >> IDs: 1,2,3⏎Done⏎

bool same = string.Equals("ABC", "abc",
    StringComparison.OrdinalIgnoreCase);       // True
int ord = string.Compare("apple", "Banana",
    StringComparison.Ordinal);                 // > 0 ('a' > 'B')
int ui  = string.Compare("apple", "Banana",
    StringComparison.CurrentCulture);          // < 0

var names = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { "Ada" };
Console.WriteLine(names.Contains("ADA"));     // True

byte[] bytes = Encoding.UTF8.GetBytes("héllo"); // 6 bytes
string back = Encoding.UTF8.GetString(bytes);   // "héllo"

Code Explained

Append — returns the builder, so calls chain
Length-- — trim the last char cheaply
Insert / Replace — edit in place
Ordinal — compares char codes (uppercase sorts first)
Culture — dictionary order for people
Encoding.UTF8 — string ↔ bytes

⚠ Common Mistakes

  • Using += inside a large loop — O(n²) copying; switch to StringBuilder
  • Sorting identifiers with culture rules — results change between machines; use Ordinal
  • Assuming string.Length equals UTF-8 byte count — use Encoding.UTF8.GetByteCount

✓ Tips & Best Practices

  • Pre-size: new StringBuilder(capacity: 1024) when you know the size
  • Create dictionaries with StringComparer.OrdinalIgnoreCase for case-insensitive keys
  • Use Encoding.UTF8 unless a protocol demands another encoding

Quick Summary

  • StringBuilder — efficient repeated appends
  • StringComparison.Ordinal — exact, fast
  • StringComparer — rules for collections
  • Encoding.UTF8 — text ↔ bytes
