Dictionary — Basics

Dictionary<K,V> · Add · indexer · TryGetValue · ContainsKey · Remove · KeyValuePair iteration

Key-Value Lookups

Dictionary<TKey, TValue> maps unique keys to values using a hash table, giving near O(1) lookups, inserts and removals. Keys must be unique and non-null and should have stable GetHashCode/Equals. Use TryGetValue to read safely — the indexer throws when a key is missing.

Key Facts

  • dict[key] = v adds or overwrites
  • Add(key, v) throws if the key exists
  • dict[missing] throws KeyNotFoundException
  • Enumeration order isn't guaranteed

Dictionary Basics

var ages = new Dictionary<string, int>
{
    ["Ada"] = 36,                              // index initializer
    ["Bob"] = 25,
};
ages.Add("Cy", 41);                            // throws if "Cy" exists
ages["Bob"] = 26;                              // overwrite

Console.WriteLine(ages["Ada"]);                // 36
// Console.WriteLine(ages["Zed"]);             // KeyNotFoundException

if (ages.TryGetValue("Cy", out int cy))        // safe read
    Console.WriteLine(cy);                     // 41
Console.WriteLine(ages.ContainsKey("Bob"));    // True
Console.WriteLine(ages.Count);                 // 3

ages.Remove("Bob");                            // True
ages.Remove("Cy", out int old);                // removed value → 41

foreach (var (name, age) in ages)              // KeyValuePair deconstruct
    Console.WriteLine($"{name}: {age}");

Code Explained

["Ada"] = 36 — index initializer
Add — strict insert
dict[k] = v — upsert
TryGetValue — one lookup, no exception
Remove(k, out v) — remove and return the value
var (k, v) — deconstruct during iteration

⚠ Common Mistakes

  • if (d.ContainsKey(k)) x = d[k]; — two lookups; use TryGetValue
  • Using a mutable object as a key and then changing it — the entry becomes unreachable
  • Relying on insertion order — use OrderedDictionary<K,V> (.NET 9) or SortedDictionary

✓ Tips & Best Practices

  • Pass StringComparer.OrdinalIgnoreCase for case-insensitive keys
  • Pre-size: new Dictionary<K,V>(capacity) for large loads
  • Use IReadOnlyDictionary<K,V> in public APIs

Quick Summary

  • Dictionary<K,V> — O(1) key lookup
  • TryGetValue — safe read
  • dict[k] = v — upsert
  • Keys unique, non-null, stable hash
