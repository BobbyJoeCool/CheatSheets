⚠ Common Mistakes

  • .Result / .Wait() on tasks — deadlocks and thread starvation; await instead
  • Enumerating a LINQ query twice — call ToList() once
  • Creating new HttpClient() per request — use IHttpClientFactory

✓ Tips & Best Practices

  • Pass CancellationToken through every async call chain
  • Use AsNoTracking() for read-only EF Core queries
  • Register services by interface and inject via constructors
