Sheet 007

Compilation & the Runtime

Roslyn · IL · JIT · tiered compilation · assemblies · ReadyToRun · Native AOT

From Source to Machine Code

The Roslyn compiler turns C# into IL stored in an assembly (.dll/.exe). At run time the CLR's JIT compiles IL to native code method by method, using tiered compilation to start fast and re-optimize hot code. ReadyToRun and Native AOT compile ahead of time for faster startup.

Key Facts

  • Assembly = IL + metadata + manifest
  • Tier 0: quick JIT; Tier 1: optimized after ~30 calls
  • Dynamic PGO tunes hot paths using real usage
  • Native AOT: no JIT, small single binary, some limits

Publishing Options

# Framework-dependent (needs .NET runtime installed)
dotnet publish -c Release

# Self-contained (bundles the runtime)
dotnet publish -c Release -r linux-x64 --self-contained

# Single file
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true

# ReadyToRun (precompiled IL, JIT still available)
dotnet publish -c Release -r osx-arm64 -p:PublishReadyToRun=true

# Native AOT (set in .csproj: <PublishAot>true</PublishAot>)
dotnet publish -c Release -r linux-x64

Code Explained

-r — runtime identifier (RID): win-x64, linux-arm64, osx-arm64
--self-contained — no runtime needed on target
PublishSingleFile — one executable
PublishReadyToRun — faster startup, larger files
PublishAot — native code; reflection is limited

Pipeline

StageTool / Output
CompileRoslyn → IL in .dll
LoadCLR loads assembly
JITIL → native, per method
Tier upHot methods re-JIT optimized
GCFrees unreachable objects

⚠ Common Mistakes

  • Expecting Native AOT to support everything — reflection-heavy code and dynamic may fail
  • Benchmarking only the first call — Tier 0 code is slower until the JIT tiers up
  • Forgetting -r for self-contained or AOT builds — a RID is required

✓ Tips & Best Practices

  • Use Native AOT for CLIs and serverless where startup matters
  • Inspect IL with ILSpy or sharplab.io
  • Use BenchmarkDotNet for timing — it handles warm-up for you

Quick Summary

  • Roslyn — C# → IL
  • JIT — IL → native at run time
  • ReadyToRun — precompiled for startup
  • Native AOT — no JIT, single native binary
