Paths and Directories

Path builds and takes apart path strings without touching the disk, handling the right separator for each OS. Directory and File perform actions (create, list, move, delete), while FileInfo / DirectoryInfo are object versions that cache metadata like size and timestamps.

Key Facts

  • / works on Windows too; Path handles separators
  • Path.Combine drops earlier parts if a later one is rooted
  • EnumerateFiles streams; GetFiles builds an array
  • Directory.CreateDirectory is a no-op if it exists

Path & Directory

string dir  = Path.Combine("data", "2026", "reports");   // data/2026/reports
string file = Path.Join(dir, "q3.csv");

Console.WriteLine(Path.GetFileName(file));               // q3.csv
Console.WriteLine(Path.GetFileNameWithoutExtension(file)); // q3
Console.WriteLine(Path.GetExtension(file));              // .csv
Console.WriteLine(Path.GetDirectoryName(file));          // data/2026/reports
Console.WriteLine(Path.ChangeExtension(file, ".bak"));   // …/q3.bak
string full = Path.GetFullPath(file);                    // absolute path

Directory.CreateDirectory(dir);                          // creates all levels
var all = SearchOption.AllDirectories;
foreach (var f in Directory.EnumerateFiles("src", "*.cs", all))
    Console.WriteLine(f);

var info = new FileInfo(file);
if (info.Exists) Console.WriteLine($"{info.Length} bytes");

string home = Environment.GetFolderPath(Environment.SpecialFolder.UserProfile);
string temp = Path.GetTempPath();

Code Explained

Path.Combine / Join — build paths safely
GetFileName / GetExtension — split a path
GetFullPath — resolve relative to the current directory
CreateDirectory — makes parent folders too
EnumerateFiles(dir, pattern, AllDirectories) — recursive search
FileInfo — size, dates, attributes

⚠ Common Mistakes

  • Concatenating paths with + "\\" + — breaks on Linux/macOS; use Path.Combine
  • Path.Combine("a", "/b") returns /b — a rooted part resets the path
  • Using GetFiles on huge trees — loads everything; use EnumerateFiles

✓ Tips & Best Practices

  • Use Path.Join when parts may start with separators
  • Use EnumerationOptions { IgnoreInaccessible = true } for robust scans
  • Watch folders with FileSystemWatcher

Quick Summary

  • Path — string-only path helpers
  • Directory / File — disk actions
  • FileInfo / DirectoryInfo — metadata
