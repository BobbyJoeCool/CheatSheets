LINQ — Filtering & Projection

Where · Select · SelectMany · OfType · Cast · Distinct · DistinctBy

Filtering and Shaping Data

Where keeps elements that match a predicate. Select transforms each element into a new shape — a value, a tuple, a record or an anonymous type. SelectMany flattens nested collections. OfType<T> filters by type, and Distinct / DistinctBy remove duplicates.

Key Facts

  • Where/Select overloads also give the index
  • Anonymous types (new { … }) are great for projections
  • Cast<T> throws on a wrong type; OfType<T> skips it
  • DistinctBy (.NET 6) keeps the first per key

Where, Select, SelectMany

var orders = new[]
{
    new Order(1, "Ada", ["pen", "ink"], 30m),
    new Order(2, "Bob", ["pad"],        8m),
    new Order(3, "Ada", ["pen"],        12m),
};

var big = orders.Where(o => o.Total >= 10);                 // ids 1, 3
var names = orders.Select(o => o.Customer);                 // Ada, Bob, Ada
var shaped = orders.Select(o => new { o.Id, Items = o.Items.Length });
var withIdx = orders.Select((o, i) => $"{i}:{o.Id}");      // 0:1, 1:2, 2:3

var allItems = orders.SelectMany(o => o.Items);            // pen, ink, pad, pen
var unique = allItems.Distinct();                           // pen, ink, pad
var perCust = orders.DistinctBy(o => o.Customer);           // first Ada, Bob

object[] mixed = [1, "two", 3.0, "four"];
var strings = mixed.OfType<string>();                       // two, four

Code Explained

Where(pred) — filter
Select(f) — map to a new value
new { o.Id, … } — anonymous projection
Select((x, i) => …) — with index
SelectMany — flatten nested lists
OfType<T> — keep only matching types

Operators

OperatorResult
Where(pred)Matching elements
Select(f)One output per input
SelectMany(f)Flattened outputs
Distinct() / DistinctBy(key)Unique elements
OfType<T>() / Cast<T>()Type filter / conversion
Where(…).Select(…)Filter then project

Query Syntax

var q = from o in orders
        where o.Total >= 10
        from item in o.Items      // SelectMany
        select new { o.Id, item };

⚠ Common Mistakes

  • Projecting before filtering on large data — filter first so less work follows
  • Using Cast<T>() on mixed collections — throws InvalidCastException; use OfType<T>()
  • Returning anonymous types from methods — they can't be named; use a record

✓ Tips & Best Practices

  • Project to small DTOs in database queries to fetch fewer columns
  • Use tuples (o.Id, o.Total) for quick internal projections
  • Combine Where conditions in one lambda when they're related

Quick Summary

  • Where — filter
  • Select — transform
  • SelectMany — flatten
  • Distinct(By) / OfType<T>
