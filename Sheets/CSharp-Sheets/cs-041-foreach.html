foreach Loops

foreach · IEnumerable · var · ref foreach · deconstruction in foreach · collection modified exception

Iterating Collections

foreach walks every item of anything that is enumerable (IEnumerable<T>, arrays, List<T>, Dictionary, spans, strings). It's simpler and safer than for because there's no index to get wrong. The loop variable is read-only, and changing the collection during the loop throws.

Key Facts

  • Works with any type that has GetEnumerator()
  • Dictionaries yield KeyValuePair<K,V>
  • .Index() (.NET 9) adds the position
  • await foreach iterates IAsyncEnumerable<T>

foreach Forms

List<string> fruits = ["apple", "banana", "cherry"];
foreach (string f in fruits) Console.Write(f[0]);     // abc
foreach (var c in "hey") Console.Write(c);            // hey

var ages = new Dictionary<string, int> { ["Ada"] = 36, ["Bob"] = 25 };
foreach (var (name, age) in ages)                     // deconstruct pair
    Console.WriteLine($"{name}: {age}");

foreach (var (i, f) in fruits.Index())                // .NET 9
    Console.WriteLine($"{i}. {f}");                   // 0. apple …

int[] nums = [1, 2, 3];
foreach (ref int n in nums.AsSpan()) n *= 10;         // in-place → 10,20,30

foreach (var f in fruits)
    if (f == "banana") fruits.Remove(f);   // ✗ InvalidOperationException

fruits.RemoveAll(f => f == "banana");                 // ✓ safe alternative

Code Explained

foreach (T x in xs) — every element in order
var (k, v) — deconstruct KeyValuePair
.Index() — (int Index, T Item) tuples
ref foreach over a span — modify elements
Modifying the list mid-loop — throws
await foreach — consume async streams

⚠ Common Mistakes

  • Adding or removing items inside foreach — throws "Collection was modified"
  • Assigning to the loop variable — it's read-only (CS1656)
  • Enumerating a LINQ query twice in two foreach loops — runs the query twice; call ToList() once

✓ Tips & Best Practices

  • Prefer foreach unless you need the index or reverse order
  • Use .Index() instead of a separate counter
  • Iterate dict.Keys.ToList() when you must remove dictionary entries

Quick Summary

  • foreach (var x in xs) — every item
  • var (k, v) — deconstruct pairs
  • .Index() — item with position
  • await foreach — async streams
