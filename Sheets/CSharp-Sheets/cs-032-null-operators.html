Null Operators

?. · ?[] · ?? · ??= · null-conditional assignment (C# 14) · is null · is not null

Handling null Concisely

C# has a family of operators for null: ?. and ?[] access a member only when the target is not null (otherwise the result is null), ?? supplies a fallback, and ??= assigns only when the variable is null. C# 14 adds null-conditional assignment: a?.B = value assigns only when a isn't null.

Key Facts

  • ?. short-circuits the whole rest of the chain
  • ?. on a value-type member returns T?
  • x ?? throw new … validates in one line
  • is null ignores overloaded ==

Null Operators

Customer? c = GetCustomer();

string? city = c?.Address?.City;     // null if c or Address is null
int? len = c?.Name.Length;           // int? (null-propagating)
char? first = c?.Name?[0];           // ?[] for indexers
c?.Orders.Clear();                   // call only if not null
OnChanged?.Invoke(this, EventArgs.Empty); // safe event raise

string name = c?.Name ?? "Guest";    // fallback
int count = c?.Orders.Count ?? 0;
_cache ??= LoadCache();              // assign once

string id = input ?? throw new ArgumentNullException(nameof(input));

// C# 14: null-conditional assignment
c?.LastSeen = DateTime.UtcNow;       // skipped if c is null
c?.Points += 10;                     // compound OK; ++ / -- not allowed

if (c is null) return;               // pattern null check
if (c is not null) Console.WriteLine(c.Name);

Code Explained

?. — member access if not null
?[] — index if not null
?.Invoke — thread-safe event raising
?? — value when left is null
??= — assign only if null
c?.X = v — right side not evaluated when c is null

⚠ Common Mistakes

  • Expecting c?.Orders.Count == 0 to be true when c is null — it compares null == 0, which is false
  • Using ?. everywhere — it hides bugs where a value should never be null
  • Mixing ?? with other operators without parentheses — ?? has very low precedence

✓ Tips & Best Practices

  • Validate at the boundary with ?? throw, then trust non-null inside
  • Use ??= for lazy initialization
  • Prefer is null / is not null over == null

Quick Summary

  • ?. / ?[] — skip when null
  • ?? — fallback value
  • ??= — assign if null
  • a?.b = x — conditional assignment (C# 14)
