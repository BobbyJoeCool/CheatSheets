Interpolation and Format Strings

String interpolation $"...{expr}..." inserts values directly. Inside a hole you can add alignment ({x,10}) and a format specifier ({x:N2}). Numeric and date formats follow the current culture unless you pass one, which matters for decimal separators and currency symbols.

Key Facts

  • Format: {value,alignment:format}
  • Escape braces by doubling: {{ }}
  • $$""" raw strings use {{x}} for holes
  • Results shown are for en-US

Format Specifiers

double price = 1234.5; int n = 42; double p = 0.256;
var today = new DateTime(2026, 10, 11, 14, 5, 0);

Console.WriteLine($"{price:C}");       // $1,234.50
Console.WriteLine($"{price:N2}");      // 1,234.50
Console.WriteLine($"{price:F1}");      // 1234.5
Console.WriteLine($"{n:D5}");          // 00042
Console.WriteLine($"{n:X}  {n:x4}");   // 2A  002a
Console.WriteLine($"{p:P1}");          // 25.6%
Console.WriteLine($"{price:E2}");      // 1.23E+003
Console.WriteLine($"{today:yyyy-MM-dd HH:mm}"); // 2026-10-11 14:05
Console.WriteLine($"[{n,6}] [{n,-6}]");// [    42] [42    ]
Console.WriteLine($"{{literal}} {n}"); // {literal} 42

string s = string.Format("{0:N0} items", 1500);    // 1,500 items
string inv = string.Create(CultureInfo.InvariantCulture, $"{1.5}");
string j = $$"""{"id": {{n}}}""";      // {"id": 42}

Code Explained

C — currency; N2 — thousands + 2 decimals
F1 — fixed decimals, no grouping
D5 — zero-pad integers
X / x4 — hex, upper / lower, padded
P1 — multiply by 100, add %
string.Create(Invariant…) — culture-independent output

⚠ Common Mistakes

  • Using mm for months — mm is minutes; months are MM
  • Writing machine-readable text with the current culture — 1,5 vs 1.5; use InvariantCulture
  • Forgetting the $ prefix — "{x}" prints the braces literally

✓ Tips & Best Practices

  • Use the o format for round-trip dates in logs and JSON
  • Use ToString("F2", CultureInfo.InvariantCulture) for files
  • Put complex expressions in a variable before interpolating

Quick Summary

  • {x:N2} — format specifier
