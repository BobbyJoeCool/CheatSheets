Sheet 012

Integer Types

byte · short · int · long · unsigned types · nint / nuint · Int128 · 0x / 0b / _ literals

Whole-Number Types

C# has signed and unsigned integers from 8 to 128 bits. int (32-bit) is the default for literals and the usual choice; use long for larger values. Arithmetic overflow wraps around silently unless you use a checked context. Every keyword is an alias for a System struct, e.g. int = System.Int32.

Key Facts

  • Integer literals are int unless too big or suffixed
  • _ digit separators: 1_000_000
  • nint / nuint are 32 or 64 bits depending on the platform
  • Int128 / UInt128 exist since .NET 7

Integer Literals & Overflow

int  dec = 1_000_000;          // 1000000
int  hex = 0xFF;               // 255
int  bin = 0b_1010_1010;       // 170
long big = 9_000_000_000L;     // L suffix → long
uint u   = 42U;                // U → uint
ulong ul = 42UL;               // UL → ulong

int max = int.MaxValue;        // 2147483647
int wrap = max + 1;            // -2147483648 (silent wrap)
int safe = checked(max + 1);   // OverflowException

Console.WriteLine(7 / 2);      // 3 (integer division)
Console.WriteLine(-7 / 2);     // -3 (truncates toward zero)
Console.WriteLine(-7 % 3);     // -1 (sign of dividend)
Console.WriteLine(int.Parse("42") + 1); // 43

Code Explained

0x / 0b — hex / binary literals
L, U, UL — choose the literal's type
int.MaxValue + 1 — wraps to int.MinValue
checked(...) — throw on overflow instead
/ on integers — discards the remainder
% — remainder takes the sign of the left operand

⚠ Common Mistakes

  • Expecting 5 / 2 to be 2.5 — both operands are int; write 5 / 2.0 or cast first
  • Silent overflow in sums of large values — use long or checked
  • Using uint for counts that can go negative — 0u - 1 wraps to 4,294,967,295

✓ Tips & Best Practices

  • Set the CheckForOverflowUnderflow project property in Debug builds
  • Use long for IDs, file sizes and timestamps
  • Use byte only for raw binary data, not for small numbers

Quick Summary

  • int — default 32-bit integer
  • long — 64-bit, suffix L
  • checked — throw on overflow
  • / — integer division truncates
