JSON — DOM & Readers

JsonDocument · JsonElement · JsonNode · JsonObject · Utf8JsonReader · Newtonsoft.Json differences

Working with Raw JSON

When you don't have (or want) a class for the data, read JSON as a tree. JsonDocument is a fast, read-only DOM over pooled memory (dispose it). JsonNode / JsonObject / JsonArray form a mutable DOM you can edit and write back. Utf8JsonReader is a forward-only reader for maximum performance.

Key Facts

  • JsonDocument must be disposed
  • GetProperty throws if missing; TryGetProperty doesn't
  • JsonNode indexers return null when missing
  • All live in System.Text.Json(.Nodes)

JsonDocument & JsonNode

string json = """{ "name": "Ada", "tags": ["c#", "math"], "age": 36 }""";

using JsonDocument doc = JsonDocument.Parse(json);          // read-only
JsonElement root = doc.RootElement;
string name = root.GetProperty("name").GetString()!;        // Ada
int age = root.GetProperty("age").GetInt32();               // 36
foreach (var t in root.GetProperty("tags").EnumerateArray())
    Console.Write(t.GetString() + " ");                     // c# math
bool hasEmail = root.TryGetProperty("email", out _);        // False

JsonNode node = JsonNode.Parse(json)!;                      // mutable
node["age"] = 37;                                           // edit
node["tags"]!.AsArray().Add("ai");                          // append
node["address"] = new JsonObject { ["city"] = "London" };   // add object
Console.WriteLine(node["address"]?["city"]);                // London
string updated = node.ToJsonString();

Code Explained

"""…""" — raw literal, no escaping needed
JsonDocument.Parse — fast immutable tree
GetProperty().GetInt32() — typed accessors
EnumerateArray() — iterate JSON arrays
JsonNode.Parse — editable tree
ToJsonString() — serialize back

⚠ Common Mistakes

  • Forgetting to dispose JsonDocument — pooled buffers leak
  • Using a JsonElement after its document is disposed — ObjectDisposedException
  • Calling GetString() on a number — throws InvalidOperationException; check ValueKind

✓ Tips & Best Practices

  • Use root.Clone() to keep a JsonElement beyond the document's life
  • Use JsonNode for small config edits; typed classes for real data
  • Check element.ValueKind before reading unknown data

Quick Summary

  • JsonDocument — read-only DOM
  • JsonNode — mutable DOM
  • Utf8JsonReader — streaming reader
  • TryGetProperty — safe lookup
