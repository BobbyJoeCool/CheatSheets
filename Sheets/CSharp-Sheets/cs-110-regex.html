Regular Expressions

Regex.IsMatch · Match · Groups · named groups · Regex.Replace · RegexOptions · [GeneratedRegex]

Pattern Matching on Text

System.Text.RegularExpressions.Regex finds, validates, extracts and replaces text with regular expressions. Use verbatim or raw string literals so backslashes stay readable. For patterns known at compile time, [GeneratedRegex] (.NET 7) generates optimized code — faster startup and AOT-friendly.

Key Facts

  • Static Regex.IsMatch caches recent patterns
  • Named groups: (?<year>\d{4})
  • Replacement tokens: $1, ${name}
  • Set a timeout for untrusted input

Regex in Practice

string log = "2026-10-11 ERROR [db] timeout; 2026-10-12 WARN [api] slow";

bool hasError = Regex.IsMatch(log, @"\bERROR\b");            // True

Match m = Regex.Match(log, @"(?<date>\d{4}-\d{2}-\d{2}) (?<lvl>\w+)");
Console.WriteLine(m.Groups["date"].Value);                   // 2026-10-11
Console.WriteLine(m.Groups["lvl"].Value);                    // ERROR

foreach (Match x in Regex.Matches(log, @"\[(\w+)\]"))
    Console.Write(x.Groups[1].Value + " ");                  // db api

string iso = Regex.Replace("11/10/2026", @"(\d+)/(\d+)/(\d+)", "$3-$2-$1");
                                                             // 2026-10-11
string[] parts = Regex.Split("a1b22c", @"\d+");              // [a, b, c]

public static partial class Patterns
{
    [GeneratedRegex(@"^[\w.+-]+@[\w-]+\.[\w.]+$", RegexOptions.IgnoreCase)]
    public static partial Regex Email();
}
bool ok = Patterns.Email().IsMatch("ada@example.com");      // True

Code Explained

@"…" — no double-escaping of \
IsMatch — yes/no test
(?<name>…) + Groups["name"] — named capture
Matches — all occurrences
$3-$2-$1 — reorder captured groups
[GeneratedRegex] — source-generated, cached instance

Pattern Syntax

TokenMatches
\d \w \sDigit, word char, whitespace
\D \W \SNegations
. ^ $Any char, start, end
* + ? {2,4}Quantifiers
[abc] [^abc]Set / negated set
(…) (?:…) (?<n>…)Group, non-capturing, named

RegexOptions

OptionEffect
IgnoreCaseCase-insensitive
Multiline^ $ match each line

⚠ Common Mistakes

  • Writing "\d+" in a normal string — the C# escape eats the backslash; use @"\d+"
  • Running user-supplied patterns without a timeout — catastrophic backtracking can hang (ReDoS)
  • Creating new Regex(...) in a loop — cache it or use [GeneratedRegex]

✓ Tips & Best Practices

  • Pass TimeSpan.FromSeconds(1) as matchTimeout for untrusted input
  • Prefer string methods (Contains, Split) for simple cases
  • Test patterns with regex101.com (.NET flavor)
