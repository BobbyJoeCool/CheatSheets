Reading and Writing XML

LINQ to XML (System.Xml.Linq) is the modern XML API: XDocument and XElement load, query and build XML with LINQ. Explicit casts read element/attribute values safely, and functional construction builds trees in one expression. XmlSerializer maps whole classes to XML when you need a typed round trip.

Key Facts

  • Element("x") returns null if missing
  • (int?)el.Attribute("y") casts safely
  • Descendants searches all levels; Elements only children
  • Namespaces use XNamespace ns = "…"; ns + "name"

LINQ to XML

var doc = XDocument.Parse("""
<books>
  <book id="1" year="2008"><title>C# in Depth</title></book>
  <book id="2"><title>CLR via C#</title></book>
</books>
""");

foreach (var b in doc.Descendants("book"))
{
    string title = (string?)b.Element("title") ?? "";
    int? year = (int?)b.Attribute("year");           // null if missing
    Console.WriteLine($"{b.Attribute("id")?.Value}: {title} {year}");
}

var recent = doc.Descendants("book")
    .Where(b => (int?)b.Attribute("year") > 2000)
    .Select(b => (string)b.Element("title")!);

var xml = new XElement("order", new XAttribute("id", 42),
    new XElement("item", "Pen"), new XElement("qty", 3));
xml.Save("order.xml");   // <order id="42"><item>Pen</item><qty>3</qty></order>

Code Explained

XDocument.Parse / Load — from string / file
Descendants("book") — every <book> at any depth
(string?)Element(…) — value or null
(int?)Attribute(…) — typed attribute value
LINQ — filter and project XML
new XElement(…) — build XML declaratively

XmlSerializer

var ser = new XmlSerializer(typeof(Order));
using var w = File.Create("o.xml");
ser.Serialize(w, order);
using var r = File.OpenRead("o.xml");
var back = (Order)ser.Deserialize(r)!;

⚠ Common Mistakes

  • Using .Value on a possibly missing element — NullReferenceException; use casts
  • Forgetting namespaces — Descendants("book") finds nothing in namespaced XML
  • Using the old XmlDocument API for new code — LINQ to XML is simpler

✓ Tips & Best Practices

  • Use XDocument.Load(path, LoadOptions.PreserveWhitespace) to keep formatting
  • Use XmlReader for very large files
  • Prefer JSON for new APIs; use XML when a format requires it
