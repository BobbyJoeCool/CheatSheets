Sheet 017

Nullable Reference Types

#nullable enable · string? · ! null-forgiving · CS8600 warnings · [NotNullWhen] · [MaybeNull]

Null Safety for References

With <Nullable>enable</Nullable>, reference types are non-nullable by default: string means "never null" and string? means "may be null". The compiler tracks null-state through your code and warns on possible null dereferences. It's a compile-time analysis only — nothing changes at run time.

Key Facts

  • On by default in new projects since .NET 6
  • ! (null-forgiving) silences a warning — no runtime check
  • #nullable enable|disable|restore toggles per file/region
  • Attributes live in System.Diagnostics.CodeAnalysis

Nullable Annotations

#nullable enable
string name = "Ada";       // never null
string? nick = null;       // may be null

int a = name.Length;       // fine
int b = nick.Length;       // ⚠ CS8602: possible null dereference
int c = nick?.Length ?? 0; // safe
if (nick is not null)
    Console.WriteLine(nick.Length);  // flow analysis: not null here

string forced = nick!;     // "trust me" — no runtime check

public class User
{
    public required string Email { get; init; } // must be set
    public string? Phone { get; set; }
}

static bool TryFind(int id, [NotNullWhen(true)] out User? user)
{ user = id == 1 ? new User { Email = "a@b.c" } : null; return user != null; }

Code Explained

string? — opt in to nulls
CS8602 — dereference of a maybe-null value
is not null — narrows to non-null in that branch
! — suppresses the warning only
required — caller must set it, avoids CS8618
[NotNullWhen(true)] — non-null when method returns true

Attributes

⚠ Common Mistakes

  • Sprinkling ! to silence warnings — it hides real bugs; fix the flow instead
  • Thinking annotations prevent nulls at run time — callers with nullable off can still pass null
  • Leaving constructors that don't set non-nullable fields — use required or initialize them

✓ Tips & Best Practices

  • Set WarningsAsErrors to nullable in new projects
  • Still validate public API arguments with ArgumentNullException.ThrowIfNull
  • Migrate old projects file by file with #nullable enable

Quick Summary

  • string vs string? — non-null vs maybe-null
  • Compiler warnings, not runtime checks
  • ! — null-forgiving operator
  • [NotNullWhen] — teach the flow analysis
