Type Conversion & Casting

implicit · explicit (cast) · Convert.ToInt32 · Parse · TryParse · checked · unchecked

Changing a Value's Type

Implicit conversions happen automatically when no data can be lost (int → long, int → double). Explicit casts (T)x are required when data may be lost, and they truncate or wrap silently. Text is converted with Parse/TryParse, and Convert.ToX handles many types and rounds instead of truncating.

Key Facts

  • (int)3.9 → 3 (truncates)
  • Convert.ToInt32(3.5) → 4 (banker's rounding)
  • checked turns silent overflow into an exception
  • Every type has ToString()

Conversions

int i = 42;
long l = i;                    // implicit widening
double d = i;                  // 42
int back = (int)9.99;          // 9  (truncate)
byte wrap = unchecked((byte)300); // 44 (300 - 256)
// byte boom = checked((byte)300); // OverflowException

Console.WriteLine(Convert.ToInt32(3.5));  // 4
Console.WriteLine(Convert.ToInt32(2.5));  // 2 (to even)
Console.WriteLine(Convert.ToInt32("12")); // 12
Console.WriteLine(Convert.ToBoolean(1));  // True

int p = int.Parse("123");                 // 123
bool ok = double.TryParse("1e3", out var x); // True, 1000
string s = 3.75.ToString("F1");           // "3.8"

decimal price = (decimal)19.99;           // double → decimal
int code = (int)DayOfWeek.Friday;         // 5 (enum → int)

⚠ Common Mistakes

  • Expecting (int)2.7 to round — it truncates to 2; use Math.Round first
  • Casting large long to int without checked — the value silently wraps
  • Parsing locale-formatted numbers with the wrong culture — pass CultureInfo.InvariantCulture

✓ Tips & Best Practices

  • Use TryParse for anything a user typed
  • Use checked around casts that must not overflow
  • int.CreateChecked(x) / CreateSaturating(x) convert between number types generically

Quick Summary

  • Implicit — widening, no data loss
  • (T)x — explicit cast, may lose data
  • Convert.ToX — rounding conversions
  • TryParse — safe text conversion
