Comparison & Equality Operators

== · != · < > <= >= · Equals · ReferenceEquals · string vs object equality

Comparing Values

Relational operators (<, >, <=, >=) work on numbers, chars and enums. Equality depends on the type: value types and string compare contents, most classes compare references, and records compare their properties. Equals() and ReferenceEquals() make the intent explicit.

Key Facts

  • Comparison results are always bool
  • < / > aren't defined for string — use string.Compare
  • NaN compares false with everything
  • Types can overload == (string and records do)

Equality Rules

Console.WriteLine(5 == 5.0);           // True (int promoted)
Console.WriteLine('a' < 'b');          // True
Console.WriteLine("abc" == "ab" + "c"); // True (string contents)

class Pt { public int X; }
var p1 = new Pt { X = 1 }; var p2 = new Pt { X = 1 };
Console.WriteLine(p1 == p2);           // False (different objects)
Console.WriteLine(p1.Equals(p2));      // False (default = reference)

record RPt(int X);
Console.WriteLine(new RPt(1) == new RPt(1)); // True (value equality)

object o1 = 42, o2 = 42;
Console.WriteLine(o1 == o2);           // False (two boxes)
Console.WriteLine(o1.Equals(o2));      // True  (Int32.Equals)
Console.WriteLine(ReferenceEquals(p1, p1)); // True

Console.WriteLine(string.Compare("a", "b")); // -1
Console.WriteLine(3.CompareTo(7));           // -1

Code Explained

5 == 5.0 — int converted to double first
string == — overloaded to compare text
Class == — same object?
record — compiler-generated value equality
object == — reference compare even for boxed ints
CompareTo — <0, 0, >0 for ordering

⚠ Common Mistakes

  • Comparing objects with == expecting field equality — override Equals or use a record
  • Comparing boxed values via object == — always false for separate boxes; use Equals
  • Writing if (x = 5) — compile error in C#; use ==

✓ Tips & Best Practices

  • Implement IEquatable<T> for custom value equality
  • Use is null instead of == null to bypass overloaded ==
  • Use x is >= 1 and <= 10 for clean range checks

Quick Summary

  • == / != — equality (type-dependent)
  • < > <= >= — ordering
  • Equals — value equality when overridden
  • ReferenceEquals — identity
