HttpClient

HttpClient · IHttpClientFactory · GetFromJsonAsync · PostAsJsonAsync · EnsureSuccessStatusCode · Microsoft.Extensions.Http.Resilience

Calling HTTP APIs

HttpClient sends HTTP requests and receives responses asynchronously. Create clients through IHttpClientFactory (AddHttpClient) so connections are pooled and DNS changes are respected. System.Net.Http.Json extensions like GetFromJsonAsync and PostAsJsonAsync handle serialization, and Microsoft.Extensions.Http.Resilience adds retries and timeouts.

Key Facts

  • Don't create new HttpClient() per request
  • Non-2xx responses don't throw unless you ask
  • Default timeout is 100 seconds
  • Typed clients wrap an API in a class

Typed Client with Resilience

builder.Services.AddHttpClient<GitHubClient>(c =>
{
    c.BaseAddress = new Uri("https://api.github.com/");
    c.DefaultRequestHeaders.UserAgent.ParseAdd("my-app/1.0");
})
.AddStandardResilienceHandler();                     // retry, timeout, breaker

public class GitHubClient(HttpClient http)
{
    public Task<Repo?> GetRepo(string owner, string name) =>
        http.GetFromJsonAsync<Repo>($"repos/{owner}/{name}");

    public async Task<int> CreateIssue(string repo, NewIssue issue)
    {
        var url = $"repos/{repo}/issues";
        using var resp = await http.PostAsJsonAsync(url, issue);
        if (resp.StatusCode == HttpStatusCode.NotFound) return -1;
        resp.EnsureSuccessStatusCode();              // throw on other errors
        var created = await resp.Content.ReadFromJsonAsync<Issue>();
        return created!.Number;
    }
}

Code Explained

AddHttpClient<T> — typed client via the factory
BaseAddress — relative URLs after this
AddStandardResilienceHandler — retries + timeouts
GetFromJsonAsync<T> — GET + deserialize
PostAsJsonAsync — serialize + POST
EnsureSuccessStatusCode — throw for non-2xx

⚠ Common Mistakes

  • using var client = new HttpClient() per call — exhausts sockets under load
  • A static HttpClient without PooledConnectionLifetime — misses DNS changes
  • Ignoring status codes — GetFromJsonAsync throws on non-2xx, but PostAsJsonAsync doesn't

✓ Tips & Best Practices

  • Pass CancellationToken to every HTTP call
  • Use typed clients to keep API details in one class
  • Stream large downloads with ResponseHeadersRead
