Floating-Point & Decimal

float · double · decimal · f / d / m suffixes · NaN · Infinity · precision · Half

Fractional Numbers

double (64-bit) is the default for fractional literals and is fast but binary, so values like 0.1 are approximate. float (32-bit) saves memory. decimal (128-bit) stores base-10 digits exactly and is the right choice for money. Floating-point math never throws: it produces Infinity or NaN instead.

Key Facts

  • 3.14 is double; use f for float and m for decimal
  • NaN is never equal to anything, even itself
  • decimal ÷ 0 throws; double ÷ 0 gives Infinity
  • Half (16-bit) exists for ML and graphics

Floating-Point Behavior

double d = 3.14;            // default
float  f = 3.14f;           // f suffix required
decimal m = 3.14m;          // m suffix required

Console.WriteLine(0.1 + 0.2);          // 0.30000000000000004
Console.WriteLine(0.1 + 0.2 == 0.3);   // False
Console.WriteLine(0.1m + 0.2m == 0.3m);// True

Console.WriteLine(1.0 / 0);            // ∞ (PositiveInfinity)
Console.WriteLine(0.0 / 0);            // NaN
Console.WriteLine(double.NaN == double.NaN); // False
Console.WriteLine(double.IsNaN(0.0 / 0));    // True
// Console.WriteLine(1m / 0);          // DivideByZeroException

bool close = Math.Abs(a - b) < 1e-9;   // compare with tolerance
Console.WriteLine(1.5e3);              // 1500 (scientific)

Code Explained

f / m — float and decimal literals need suffixes
0.1 + 0.2 — binary rounding error
decimal — exact base-10 arithmetic
1.0 / 0 — Infinity, no exception
double.IsNaN — the only reliable NaN test
Tolerance compare — never == on computed doubles

⚠ Common Mistakes

  • Using double for currency — rounding errors add up; use decimal
  • Testing x == double.NaN — always false; use double.IsNaN(x)
  • Writing float f = 3.14; — error CS0664; add the f suffix

✓ Tips & Best Practices

  • Compare doubles with a tolerance or Math.Abs(a - b) < eps
  • Format output with ToString("F2") instead of rounding stored values
  • Mixing decimal and double needs an explicit cast — on purpose

Quick Summary

  • double — default, fast, approximate
  • decimal — exact base-10, use for money
  • NaN / Infinity — no exceptions in float math
  • f / m — literal suffixes
