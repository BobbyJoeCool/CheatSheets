Defining & Calling Methods

return types · void · expression-bodied => · static vs instance · access modifiers · calling

Methods

A method is a named block of code inside a class, struct or record. It declares an access modifier, a return type (void when it returns nothing), a name in PascalCase and a parameter list. Static methods belong to the type; instance methods act on an object and can use its fields.

Key Facts

  • Every code path of a non-void method must return
  • => creates an expression-bodied member
  • Local functions can live inside other methods
  • Methods can return tuples for multiple values

Declaring & Calling

public class Calculator
{
    private int _calls;                                // instance state

    public int Add(int a, int b)                       // instance method
    {
        _calls++;
        return a + b;
    }

    public int Square(int x) => x * x;                 // expression-bodied
    public void Reset() => _calls = 0;                 // void
    public static double Average(int a, int b) => (a + b) / 2.0; // static

    public (int Min, int Max) Range(int[] xs) => (xs.Min(), xs.Max());
}

var calc = new Calculator();
Console.WriteLine(calc.Add(2, 3));                 // 5
Console.WriteLine(calc.Square(4));                 // 16
Console.WriteLine(Calculator.Average(3, 4));       // 3.5
var (min, max) = calc.Range([4, 1, 9]);            // 1, 9

Code Explained

public int Add(int a, int b) — modifier, return type, name, parameters
return — hands back a value and exits
=> expr — one-expression body
void — no return value
static — call on the type: Calculator.Average
Tuple return — several named values

⚠ Common Mistakes

  • Missing return on some path — error CS0161: not all code paths return a value
  • Calling an instance method without an object — CS0120; make it static or create an instance
  • Overlong methods doing many things — split into smaller, well-named methods

✓ Tips & Best Practices

  • Name methods with verbs: CalculateTax, TryParse, LoadAsync
  • Mark helpers that don't use instance state as static
  • Use expression bodies for one-liners

Quick Summary

  • ReturnType Name(params) { } — method
  • void — no result
  • => — expression-bodied
  • static — no instance needed
