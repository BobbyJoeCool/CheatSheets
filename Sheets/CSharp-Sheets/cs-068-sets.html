Sets

HashSet<T> · SortedSet<T> · UnionWith · IntersectWith · ExceptWith · IsSubsetOf · comparers

Unique Items

HashSet<T> stores unique values with O(1) Add, Remove and Contains, making it ideal for de-duplication and membership tests. It also supports mathematical set operations — union, intersection, difference — either in place or as tests. SortedSet<T> keeps items ordered and supports ranges.

Key Facts

  • Add returns false for duplicates (no exception)
  • No index access; order is unspecified
  • Set operations like UnionWith modify the set in place
  • Pass a comparer for case-insensitive strings

HashSet in Action

var tags = new HashSet<string>(StringComparer.OrdinalIgnoreCase)
    { "c#", "dotnet" };
Console.WriteLine(tags.Add("C#"));          // False (duplicate, ignoring case)
Console.WriteLine(tags.Contains("DOTNET")); // True

int[] nums = [3, 1, 3, 2, 1];
var unique = new HashSet<int>(nums);        // {3, 1, 2}

var a = new HashSet<int> { 1, 2, 3, 4 };
var b = new HashSet<int> { 3, 4, 5 };
a.IntersectWith(b);                         // a = {3, 4}
a.UnionWith([9]);                           // a = {3, 4, 9}
a.ExceptWith(b);                            // a = {9}
a.SymmetricExceptWith([9, 10]);             // a = {10}

var small = new HashSet<int> { 3 };
Console.WriteLine(small.IsSubsetOf(b));     // True
Console.WriteLine(b.Overlaps([5, 6]));      // True

var ranks = new SortedSet<int> { 50, 10, 30 };   // {10, 30, 50}
Console.WriteLine(ranks.Min);               // 10
var mid = ranks.GetViewBetween(20, 40);     // {30}

Code Explained

Comparer — defines what counts as equal
Add — false if already present
new HashSet<T>(source) — de-duplicate
IntersectWith / UnionWith / ExceptWith — in place
IsSubsetOf / Overlaps — tests
SortedSet — ordered, Min/Max, ranges

⚠ Common Mistakes

  • Using List.Contains for repeated membership checks — O(n) each; a HashSet is O(1)
  • Expecting UnionWith to return a new set — it mutates; use LINQ Union for a new sequence
  • Storing mutable objects whose hash changes after insertion — they become unfindable

✓ Tips & Best Practices

  • Use seen.Add(x) as a combined "check and insert" in loops
  • Use LINQ Distinct/DistinctBy for one-off de-duplication
  • Use FrozenSet<T> for large, read-only lookup sets

Quick Summary

  • HashSet<T> — unique, O(1) membership
  • UnionWith / IntersectWith / ExceptWith
  • IsSubsetOf / Overlaps — tests
  • SortedSet<T> — ordered set
