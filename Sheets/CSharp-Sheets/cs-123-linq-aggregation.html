Summarizing Sequences

Aggregation operators reduce a sequence to a single value: Count, Sum, Average, Min, Max. MinBy/MaxBy (.NET 6) return the element with the smallest/largest key. Aggregate folds with any function, and .NET 9 adds CountBy and AggregateBy for per-key totals without GroupBy.

Key Facts

  • All aggregates execute immediately
  • Sum of empty = 0; Average/Min/Max of empty throw
  • Use nullable selectors (x => (int?)x) to get null instead
  • Count(pred) counts matching items

Aggregates

var sales = new[]
{
    new Sale("North", "pen", 12m), new Sale("South", "pad", 30m),
    new Sale("North", "ink", 8m),  new Sale("East", "pen", 20m),
};

Console.WriteLine(sales.Count());                      // 4
Console.WriteLine(sales.Count(s => s.Amount > 10));    // 3
Console.WriteLine(sales.Sum(s => s.Amount));           // 70
Console.WriteLine(sales.Average(s => s.Amount));       // 17.5
Console.WriteLine(sales.Max(s => s.Amount));           // 30
Console.WriteLine(sales.MaxBy(s => s.Amount)!.Region); // South (the element)

foreach (var (region, n) in sales.CountBy(s => s.Region))      // .NET 9
    Console.Write($"{region}:{n} ");                   // North:2 South:1 East:1

var totals = sales.AggregateBy(s => s.Region, 0m, (sum, s) => sum + s.Amount);
// North:20 South:30 East:20

string csv = sales.Select(s => s.Item).Aggregate((a, b) => $"{a},{b}");
// pen,pad,ink,pen

Code Explained

Count(pred) — matches only
Sum / Average / Max with a selector
MaxBy — returns the whole element
CountBy — key → count pairs
AggregateBy — key → folded value
Aggregate — general fold

⚠ Common Mistakes

  • Calling Average() or Max() on a possibly empty sequence — throws; check Any() or use DefaultIfEmpty()
  • Using Count() > 0 to test for items — Any() stops at the first element
  • Summing double money values — rounding errors; use decimal

✓ Tips & Best Practices

  • Use MaxBy instead of OrderByDescending(...).First()
  • Use CountBy / AggregateBy for quick dashboards
  • Use TryGetNonEnumeratedCount to get counts without enumerating

Quick Summary

  • Count / Sum / Average / Min / Max
  • MinBy / MaxBy — element with extreme key
  • CountBy / AggregateBy — per-key (.NET 9)
  • Aggregate — custom fold
