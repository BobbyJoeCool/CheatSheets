Interfaces

interface · multiple implementation · explicit implementation · default interface methods · static abstract members · I- naming

Contracts Between Types

An interface declares members that implementing types promise to provide. A class or struct can implement many interfaces, which is how C# models capabilities like IDisposable, IComparable<T> or IEnumerable<T>. Modern interfaces can also contain default implementations (C# 8) and static abstract members (C# 11) for generic math.

Key Facts

  • Names start with I by convention
  • Members are public by default
  • Explicit implementation hides a member unless cast to the interface
  • Interfaces can't hold instance fields

Interfaces in Practice

public interface IShape
{
    double Area();                                     // contract
    string Describe() => $"{GetType().Name}: {Area():F1}";  // default (C# 8)
}
public interface INamed { string Name { get; } }

public class Circle(double r) : IShape, INamed         // implement two
{
    public string Name => "circle";
    public double Area() => Math.PI * r * r;
}

IShape s = new Circle(2);
Console.WriteLine(s.Describe());                      // Circle: 12.6

public class Log : IDisposable
{
    void IDisposable.Dispose() => Console.WriteLine("closed"); // explicit
}
((IDisposable)new Log()).Dispose();                   // closed

Code Explained

Member without body — implementer must supply it
Default method — available through the interface
: IShape, INamed — multiple interfaces
Explicit implementation — IDisposable.Dispose()
Cast to the interface to call explicit members

⚠ Common Mistakes

  • Fat interfaces with dozens of members — split them (Interface Segregation)
  • Relying on default methods through a class reference — they're only visible via the interface type
  • Creating an interface for every class "just in case" — add one when you need a second implementation or a test seam

✓ Tips & Best Practices

  • Depend on interfaces in constructors to enable DI and mocking
  • Use explicit implementation to avoid name clashes between interfaces
  • Keep interfaces small: IReader, IWriter rather than IFileManager
