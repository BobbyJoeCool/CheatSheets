Pattern Matching — Advanced

property pattern { } · extended property a.b.c · positional (Deconstruct) · list patterns [1, .., var x] · slice pattern · recursive patterns

Matching Structure

Advanced patterns look inside values. Property patterns { Prop: pattern } test members, positional patterns (a, b) use Deconstruct, and list patterns [first, .., last] (C# 11) match arrays and lists by element. Patterns nest, so one expression can check an entire object graph.

Key Facts

  • Property patterns also check for non-null
  • { A.B: x } — extended property pattern (C# 10)
  • .. is the slice pattern; only one per list pattern
  • List patterns need Length/Count + an indexer

Property, Positional & List Patterns

if (order is { Status: OrderStatus.Paid, Total: > 100 }) Ship(order);
if (person is { Address.City: "Paris" }) Greet(person); // C# 10

record Point(int X, int Y);
string Quadrant(Point p) => p switch
{
    (0, 0)         => "origin",
    ( > 0, > 0)    => "Q1",
    ( < 0, > 0)    => "Q2",
    _              => "Q3/Q4"
};

int[] nums = [1, 2, 3, 4];
Console.WriteLine(nums is [1, ..]);              // True (starts with 1)
if (nums is [var first, .., var last])
    Console.WriteLine($"{first}..{last}");       // 1..4
if (nums is [_, .. var middle, _])
    Console.WriteLine(middle.Length);            // 2 (slice)

Code Explained

{ Status: X, Total: > 100 } — test several properties
{ Address.City: … } — dot into nested members
(0, 0) — positional via Deconstruct
[1, ..] — starts with 1, any length
[var f, .., var l] — capture first and last
.. var middle — capture the slice

List Pattern Examples

[]Empty
[_]Exactly one element

Nesting Patterns

bool IsVipUs(Customer c) => c is
{
    Tier: Tier.Gold or Tier.Platinum,
    Address: { Country: "US" },
    Orders: [_, _, ..]          // 2+ orders
};

⚠ Common Mistakes

  • Forgetting that { } rejects null — x is { } is a non-null test, which may surprise readers
  • Using two .. in one list pattern — only one slice is allowed
  • Using list patterns on a plain IEnumerable<T> — they need Length/Count and an indexer; materialize with ToList() first

✓ Tips & Best Practices

  • Use x is { } y as a compact "not null, bind it"
  • Use list patterns to parse command-line args
  • Add Deconstruct to classes to enable positional patterns

Quick Summary

  • { P: pat } — property pattern
  • (a, b) — positional pattern
  • [a, .., z] — list pattern
  • .. var rest — slice capture
