Grouping and Joining

GroupBy collects elements that share a key into IGrouping<TKey, T> groups; ToLookup does the same but executes immediately and allows key lookups. Join performs an inner join between two sequences, GroupJoin a one-to-many join, and .NET 10 adds LeftJoin and RightJoin. Zip pairs elements by position.

Key Facts

  • Each group has a Key and is itself enumerable
  • Join drops unmatched elements
  • LeftJoin keeps all left items; the right side may be null
  • ToDictionary throws on duplicate keys

GroupBy, Join, LeftJoin, Zip

var byRegion = sales.GroupBy(s => s.Region);
foreach (var g in byRegion)
    Console.WriteLine($"{g.Key}: {g.Count()} sales, {g.Sum(s => s.Amount):C}");

var lookup = sales.ToLookup(s => s.Region);            // immediate
Console.WriteLine(lookup["North"].Count());           // 2

var rows = customers.Join(orders,                     // inner join
    c => c.Id, o => o.CustomerId,
    (c, o) => new { c.Name, o.Total });

var all = customers.LeftJoin(orders,                  // .NET 10
    c => c.Id, o => o.CustomerId,
    (c, o) => new { c.Name, Total = o?.Total ?? 0 }); // o may be null

var perCustomer = customers.GroupJoin(orders,         // one-to-many
    c => c.Id, o => o.CustomerId,
    (c, os) => new { c.Name, Count = os.Count() });

var pairs = new[] { "a", "b" }.Zip([1, 2]);            // (a,1) (b,2)
var byId = customers.ToDictionary(c => c.Id);

Code Explained

GroupBy — groups with .Key
Aggregate inside each group
ToLookup — indexable multi-map
Join(inner, outerKey, innerKey, result)
LeftJoin — keep customers without orders
Zip — combine two sequences pairwise

Operators

OperatorShape
GroupBy(k)IEnumerable<IGrouping<K,T>>
ToLookup(k)ILookup<K,T>
JoinInner join
GroupJoinOuter item + matching inners
LeftJoin / RightJoinOuter joins (.NET 10)
Zip(a, b)(T1, T2) tuples

Query Syntax Join

var q = from c in customers
        join o in orders on c.Id equals o.CustomerId
        group o by c.Name into g
        select new { Name = g.Key,
                     Total = g.Sum(o => o.Total) };

⚠ Common Mistakes

  • Using ToDictionary when keys repeat — throws ArgumentException; use ToLookup
  • Emulating left joins with GroupJoin + SelectMany + DefaultIfEmpty on .NET 10 — use LeftJoin
  • Joining large in-memory lists with nested loops — Join uses hashing and is much faster

✓ Tips & Best Practices

  • Use CountBy/AggregateBy when you only need per-key totals
  • Use query syntax for multi-source joins — it reads better
  • Use Zip with three sequences: a.Zip(b, c)

Quick Summary

  • GroupBy / ToLookup — group by key
  • Join — inner join
  • LeftJoin / RightJoin — .NET 10
  • Zip — pair by position
