Math Operators

C# provides the usual arithmetic operators. The result type depends on the operands: two ints give an int (so division truncates), while mixing in a double promotes the result to double. Small types like byte and short are promoted to int before any arithmetic.

Key Facts

  • No ** power operator — use Math.Pow
  • % works on floating-point too: 5.5 % 2 = 1.5
  • Integer ÷ 0 throws; double ÷ 0 gives ∞
  • byte + byte is int

Arithmetic in Action

int a = 17, b = 5;
Console.WriteLine(a + b);        // 22
Console.WriteLine(a - b);        // 12
Console.WriteLine(a * b);        // 85
Console.WriteLine(a / b);        // 3
Console.WriteLine(a % b);        // 2
Console.WriteLine(a / (double)b); // 3.4
Console.WriteLine(Math.Pow(2, 10)); // 1024 (double)

int i = 5;
Console.WriteLine(i++);          // 5 (then i = 6)
Console.WriteLine(++i);          // 7
Console.WriteLine(-i);           // -7

var (q, r) = Math.DivRem(17, 5); // q = 3, r = 2
Console.WriteLine(2 + 3 * 4);    // 14 (* before +)
Console.WriteLine((2 + 3) * 4);  // 20
byte x = 10, y = 20;
int sum = x + y;                 // 30 — result is int

Code Explained

/ on ints — quotient only
(double)b — cast one operand to get a fraction
i++ — returns old value, then increments
++i — increments, then returns new value
Math.DivRem — quotient and remainder at once
Precedence — * / % before + -

⚠ Common Mistakes

  • Computing a percentage as count / total * 100 with ints — gives 0; use count * 100.0 / total
  • Using i++ inside complex expressions — hard to read and easy to get wrong
  • Assuming % is always positive — -7 % 3 is -1; use ((x % n) + n) % n for modulo

✓ Tips & Best Practices

  • Add parentheses whenever precedence isn't obvious
  • Use Math.Pow only for real exponents; x * x is faster for squares
  • Use checked for arithmetic that must not overflow

Quick Summary

  • / — integer division when both are ints
  • % — remainder (sign of left side)
  • ++x vs x++ — pre vs post increment
  • Math.Pow — exponentiation
