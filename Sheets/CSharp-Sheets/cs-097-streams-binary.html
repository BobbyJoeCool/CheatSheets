Streams & Binary Files

Stream · MemoryStream · BinaryReader · BinaryWriter · CopyToAsync · BufferedStream

Byte Streams

Stream is the abstract base for reading and writing sequences of bytes: files (FileStream), memory (MemoryStream), network (NetworkStream) and wrappers like GZipStream or BufferedStream. Streams can be chained, and BinaryReader/BinaryWriter read and write primitive types in binary form.

Key Facts

  • Check CanRead, CanWrite, CanSeek before use
  • Position / Seek work only on seekable streams
  • Read may return fewer bytes than requested
  • Always dispose streams (using)

Streams in Practice

using var ms = new MemoryStream();
using (var bw = new BinaryWriter(ms, Encoding.UTF8, leaveOpen: true))
{
    bw.Write(42);              // 4 bytes
    bw.Write(3.14);            // 8 bytes
    bw.Write("hi");            // length-prefixed string
}
ms.Position = 0;               // rewind
using var br = new BinaryReader(ms);
int i = br.ReadInt32(); double d = br.ReadDouble();   // same order as written
Console.WriteLine($"{i} {d} {br.ReadString()}");      // 42 3.14 hi

await using var src = File.OpenRead("big.log");
await using var dst = File.Create("big.log.gz");
await using var gz = new GZipStream(dst, CompressionLevel.Optimal);
await src.CopyToAsync(gz);                       // compress while copying

byte[] buffer = new byte[4096];
int n = await src.ReadAsync(buffer);             // may be < 4096
await src.ReadExactlyAsync(buffer.AsMemory(0, 16)); // exactly 16 or throw

Code Explained

MemoryStream — bytes in memory
BinaryWriter — write primitives as bytes
leaveOpen: true — don't close the inner stream
Position = 0 — rewind before reading
Chaining — file → gzip → file
ReadExactlyAsync — loop until the buffer is full (.NET 7)

⚠ Common Mistakes

  • Assuming Read fills the buffer — it returns how many bytes it read; loop or use ReadExactly
  • Reading a MemoryStream right after writing — Position is at the end; rewind first
  • Disposing a wrapper that closes the stream you still need — pass leaveOpen: true

✓ Tips & Best Practices

  • Use CopyToAsync to move data between streams
  • Use ms.ToArray() to get the written bytes
  • Use System.IO.Pipelines for high-throughput network parsing

Quick Summary

  • Stream — byte I/O abstraction
  • MemoryStream / FileStream — common backings
  • BinaryReader / Writer — primitives
  • Chain wrappers like GZipStream
