Adding Members to Existing Types

Extension methods let you add methods to types you don't own: a static method in a static class whose first parameter has the this modifier. C# 14 introduces extension blocks (extension(T receiver) { … }) that also allow extension properties and static extension members. C# 15 (preview) adds extension indexers.

Key Facts

  • Extensions need their namespace imported with using
  • Instance members always win over extensions
  • They can't access private members of the type
  • LINQ is built entirely from extension methods

Classic & C# 14 Extension Blocks

public static class Ext
{
    public static bool IsBlank(this string? s) =>   // classic (C# 3+)
        string.IsNullOrWhiteSpace(s);

    extension<T>(IEnumerable<T> src)                // C# 14 block
    {
        public bool IsEmpty => !src.Any();          // extension property
        public IEnumerable<T> SkipFirst() => src.Skip(1);
    }

    extension(string)                               // static extension
    {
        public static string Twice(string s) => s + s;
    }
}

Console.WriteLine("  ".IsBlank());              // True
int[] nums = [1, 2, 3];
Console.WriteLine(nums.IsEmpty);                // False
Console.WriteLine(string.Twice("ab"));          // abab

Code Explained

this string? s — the type being extended
extension<T>(IEnumerable<T> src) — block for a receiver
Extension property — nums.IsEmpty, no parentheses
extension(string) — static members appear on the type
string.Twice(…) — called like a built-in static

C# 15 Preview: Extension Indexer

extension(IEnumerable<int> seq)
{
    public int this[int i] => seq.ElementAt(i);
}
var third = Enumerable.Range(1, 10)[2];   // 3

⚠ Common Mistakes

  • Forgetting the using for the extension's namespace — the method seems to vanish
  • Defining an extension with the same signature as an instance method — it's never called
  • Putting heavy logic or hidden I/O in extension properties — they look like cheap fields

✓ Tips & Best Practices

  • Group extensions by receiver type: StringExtensions, EnumerableExtensions
  • Extend interfaces (IEnumerable<T>) to reach many types at once
  • Classic this methods and extension blocks can coexist; migration isn't required

Quick Summary

  • static M(this T x) — classic extension method
  • extension(T x) { … } — C# 14 block
  • Extension properties & static members — C# 14
  • Extension indexers — C# 15 preview
