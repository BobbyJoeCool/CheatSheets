Tuples & Deconstruction

(int, string) · named elements · ValueTuple · Deconstruct method · discards _ · tuple equality

Lightweight Groups of Values

Tuples (int, string) bundle a few values without declaring a type; they're System.ValueTuple structs with optional element names. Deconstruction unpacks tuples — and any type with a Deconstruct method, including records — into separate variables. Tuples compare with == element by element.

Key Facts

  • Unnamed elements are Item1, Item2, …
  • Names are compile-time only (not in reflection)
  • Tuples are mutable value types
  • Use _ to discard parts you don't need

Tuples & Deconstruction

(int, string) t = (1, "one");
Console.WriteLine(t.Item2);                   // one

var p = (Name: "Ada", Age: 36);               // named elements
Console.WriteLine(p.Name);                    // Ada

(int Min, int Max) Bounds(int[] xs) => (xs.Min(), xs.Max());
var (lo, hi) = Bounds([4, 9, 2]);             // lo = 2, hi = 9
var (_, max) = Bounds([1, 5]);                // discard min

int a = 1, b = 2;
(a, b) = (b, a);                              // swap

Console.WriteLine((1, "x") == (1, "x"));      // True

public class Point(int x, int y)
{
    public void Deconstruct(out int x0, out int y0) => (x0, y0) = (x, y);
}
var (x, y) = new Point(3, 4);                 // x = 3, y = 4

foreach (var (key, value) in dict) { }        // KeyValuePair deconstructs

Code Explained

(int, string) — tuple type

(a, b) = (b, a) — swap without a temp
Deconstruct — make your types deconstructible

⚠ Common Mistakes

  • Returning big unnamed tuples from public APIs — Item3 means nothing; use a record
  • Expecting tuple names to survive serialization — JSON shows Item1, Item2
  • Mixing up System.Tuple<T> (class, read-only) with value tuples (T1, T2)

✓ Tips & Best Practices

  • Name tuple elements in return types: (int Count, decimal Total)
  • Use tuples as composite dictionary keys
  • Add Deconstruct to small types for pattern matching

Quick Summary

  • (T1, T2) — value tuple
  • var (a, b) = x — deconstruction
  • _ — discard
  • Deconstruct — custom deconstruction
