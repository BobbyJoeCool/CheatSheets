List<T> Methods with Predicates

Beyond basic add/remove, List<T> has built-in methods that take predicates and converters: find items, remove all matches, sort with custom rules, and convert to another type. They run in place or return a new list without needing LINQ, and some (RemoveAll, Sort) are faster than LINQ equivalents.

Key Facts

  • Find returns default(T) when nothing matches
  • FindIndex returns -1 when nothing matches
  • Sort() uses IComparable<T>; overloads accept rules
  • CollectionsMarshal.AsSpan exposes the backing array

Predicate Methods

List<int> n = [7, 2, 9, 4, 6, 1];

int firstBig = n.Find(x => x > 5);            // 7
List<int> evens = n.FindAll(x => x % 2 == 0);  // [2, 4, 6]
int idx = n.FindIndex(x => x > 8);            // 2
int last = n.FindLast(x => x < 5);            // 1
bool any = n.Exists(x => x > 8);              // True
bool all = n.TrueForAll(x => x > 0);          // True

int removed = n.RemoveAll(x => x < 3);        // 2 → [7, 9, 4, 6]
n.Sort();                                     // [4, 6, 7, 9]
n.Sort((a, b) => b.CompareTo(a));             // [9, 7, 6, 4] descending
n.Reverse();                                  // [4, 6, 7, 9]

List<string> s = n.ConvertAll(x => $"#{x}");  // ["#4", "#6", …]
IReadOnlyList<int> ro = n.AsReadOnly();       // read-only wrapper
n.ForEach(x => Console.Write(x));             // 4679

Span<int> span = CollectionsMarshal.AsSpan(n); // fast, no copy
span[0] = 100;                                // n[0] = 100

Code Explained

Find / FindLast — first / last match
FindAll — new list of matches
RemoveAll — returns number removed
Sort(Comparison) — custom order
ConvertAll — map to a new List<TOut>
AsSpan — don't add/remove while using it

List Method vs LINQ

List<T>LINQ

FindAll(p)Where(p).ToList()

⚠ Common Mistakes

  • Treating Find returning 0 as "not found" for List<int> — 0 may be a real value; use FindIndex
  • Adding to the list while holding a span from AsSpan — the span may point to a stale array
  • Using ForEach with async lambdas — it doesn't await them

✓ Tips & Best Practices

  • Prefer RemoveAll over manual removal loops
  • Sort by key with list.Sort((a, b) => a.Age.CompareTo(b.Age))
  • Use LINQ when chaining several steps; list methods for single in-place ops

Quick Summary

  • Find / FindAll / FindIndex — search
  • RemoveAll — bulk delete
  • Sort(cmp) — custom ordering
  • ConvertAll — map to new list
