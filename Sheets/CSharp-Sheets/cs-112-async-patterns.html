async / await — Patterns

Task.WhenAll · Task.WhenAny · Task.WhenEach · CancellationToken · Task.Run · WaitAsync timeouts

Coordinating Tasks

Real programs run several async operations at once and need to combine, race, cancel and time out them. Task.WhenAll waits for everything, Task.WhenAny for the first, and Task.WhenEach (.NET 9) yields tasks as they complete. CancellationToken is the cooperative way to stop work, and WaitAsync adds a timeout to any task.

Key Facts

  • WhenAll throws the first exception at await
  • Cancellation is cooperative — code must check the token
  • Task.Run offloads CPU work to the thread pool
  • CancellationTokenSource must be disposed

Combining & Cancelling

using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(10));
CancellationToken ct = cts.Token;

string[] urls = ["https://a.com", "https://b.com", "https://c.com"];
var downloads = urls.Select(u => http.GetStringAsync(u, ct)).ToArray();

string[] pages = await Task.WhenAll(downloads);          // all, in parallel

Task<string> first = await Task.WhenAny(downloads);      // fastest one

await foreach (Task<string> done in Task.WhenEach(downloads))   // .NET 9
    Console.WriteLine($"finished: {(await done).Length}");

int hash = await Task.Run(() => ExpensiveHash(data), ct); // CPU work off-thread

try { await SlowOpAsync().WaitAsync(TimeSpan.FromSeconds(2)); }  // timeout
catch (TimeoutException) { Console.WriteLine("too slow"); }

var opts = new ParallelOptions { MaxDegreeOfParallelism = 2 };   // throttled
await Parallel.ForEachAsync(urls, opts,
    async (u, tok) => await http.GetStringAsync(u, tok));

Code Explained

CancellationTokenSource(timeout) — auto-cancel
Start all tasks first, then WhenAll
WhenAny — returns the completed task
WhenEach — process results in completion order
Task.Run — CPU-bound work
WaitAsync — timeout without cancelling the work itself

Combinators

APICompletes When
Task.WhenAll(ts)All done (or one faults)
Task.WhenAny(ts)First done
Task.WhenEach(ts)Yields each as done

⚠ Common Mistakes

  • Awaiting tasks one by one in a loop when they're independent — serial instead of parallel
  • Firing thousands of requests with WhenAll — throttle with Parallel.ForEachAsync or SemaphoreSlim
  • Accepting a CancellationToken but never passing it down

✓ Tips & Best Practices

  • Make CancellationToken ct = default the last parameter
  • Use WhenEach to show progress as results arrive
  • Inspect task.Exception after WhenAll to see every failure
