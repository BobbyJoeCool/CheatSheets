Sheet 078

Properties

get / set · auto-properties · init · required · field keyword (C# 14) · computed properties · expression-bodied

Encapsulated Data

Properties look like fields to callers but run code through get and set accessors. Auto-properties generate a hidden backing field. init allows setting only during initialization, required forces callers to set it, and C# 14's field keyword lets you add logic to one accessor without declaring the backing field yourself.

Key Facts

  • Accessors can have different access: { get; private set; }
  • init + required = immutable, must-set properties
  • Computed properties have only a getter
  • Use @field if you have a member literally named field

Property Forms

public class Product
{
    public string Name { get; set; } = "";             // auto-property
    public int Id { get; init; }                        // initializer only
    public required string Sku { get; init; }          // caller must set
    public decimal Price { get; private set; }         // read-only to callers

    public string Code                                  // C# 14 field keyword
    {
        get;
        set => field = value?.Trim().ToUpperInvariant() ?? "";
    }

    private int _qty;                                   // classic backing field
    public int Quantity { get => _qty; set => _qty = Math.Max(0, value); }

    public decimal Total => Price * Quantity;          // computed
}

var p = new Product { Sku = "A1", Id = 7, Code = " ab " };   // Code = "AB"
// p.Id = 8;                                        // ✗ init-only

Code Explained

{ get; set; } — compiler-generated field
init — only during construction/initializer
required — enforced at compile time
private set — only the class changes it
field — the auto-generated backing field (C# 14)
=> expr — computed, read-only

⚠ Common Mistakes

  • Expensive work in getters — callers expect properties to be cheap; use a method
  • Recursive property: set => Name = value; inside Name — stack overflow; use field
  • Public setters on collection properties — callers can replace the whole list

✓ Tips & Best Practices

  • Default to { get; init; } for data classes
  • Use field to add validation without a separate backing field
  • Expose collections as IReadOnlyList<T> with no setter

Quick Summary

  • Auto-property — { get; set; }
  • init / required — controlled initialization
  • field — C# 14 backing-field keyword
  • Computed — => expression
