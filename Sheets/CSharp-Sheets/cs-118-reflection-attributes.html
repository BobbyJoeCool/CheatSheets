Inspecting Types at Run Time

Reflection (System.Reflection) reads type metadata at run time — properties, methods, attributes — and can create objects or invoke members dynamically. Attributes attach declarative metadata to code ([Obsolete], [Required], [JsonIgnore]) that frameworks read via reflection. Reflection is powerful but slow and limited under Native AOT.

Key Facts

  • Start from typeof(T) or obj.GetType()
  • Attribute classes end with Attribute; the suffix is optional in use
  • [AttributeUsage] controls where an attribute can go
  • Source generators often replace reflection today

Reflection & Custom Attributes

[AttributeUsage(AttributeTargets.Property)]
public sealed class ColumnAttribute(string name) : Attribute
{
    public string Name { get; } = name;
}
public class Customer
{
    [Column("cust_name")] public string Name { get; set; } = "";
    public int Age { get; set; }
}
Type t = typeof(Customer);
foreach (PropertyInfo p in t.GetProperties())
{
    var col = p.GetCustomAttribute<ColumnAttribute>();
    Console.WriteLine($"{p.Name} → {col?.Name ?? p.Name}");
}   // Name → cust_name   Age → Age

var c = (Customer)Activator.CreateInstance(t)!;        // create dynamically
t.GetProperty("Age")!.SetValue(c, 42);                 // set by name
MethodInfo m = t.GetMethod(nameof(ToString))!;
Console.WriteLine(m.Invoke(c, null));                   // invoke by reflection

Code Explained

: Attribute — define a custom attribute
[AttributeUsage] — restrict targets
[Column("…")] — apply it
GetProperties() — list public properties
GetCustomAttribute<T>() — read the attribute
Activator / SetValue / Invoke — dynamic access

⚠ Common Mistakes

  • Reflection in hot loops — orders of magnitude slower; cache PropertyInfo or use delegates
  • Reflecting over private members of other libraries — breaks on updates
  • Relying on reflection in Native AOT/trimmed apps — members may be trimmed away

✓ Tips & Best Practices

  • Prefer source generators for serialization, mapping and DI
  • Use [DynamicallyAccessedMembers] to keep members when trimming
  • Use nameof with reflection lookups to stay rename-safe

Quick Summary

  • typeof(T) / GetType() — entry points
  • GetProperties / GetMethods — metadata
  • Custom attributes — : Attribute
  • Slow; limited under AOT
