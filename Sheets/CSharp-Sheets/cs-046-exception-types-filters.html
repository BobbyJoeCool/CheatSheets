Exception Types and Filters

The BCL defines exception types for common failures; knowing which ones you'll meet tells you what to catch. Exception filters — catch (T ex) when (condition) — let you catch only when a condition holds. A filter runs before the stack unwinds, so a filter that returns false can log without catching.

Key Facts

  • Filters don't change the stack trace
  • AggregateException wraps several errors (Tasks)
  • OperationCanceledException signals cancellation, not failure
  • StackOverflowException can't be caught

Filters in Practice

try
{
    await client.GetStringAsync(url, token);
}
catch (HttpRequestException ex) when (ex.StatusCode == NotFound)
{
    return null;                               // only 404s
}
catch (HttpRequestException ex) when (IsTransient(ex))
{
    await RetryAsync();
}
catch (OperationCanceledException) when (token.IsCancellationRequested)
{
    Console.WriteLine("Cancelled by caller");
}
catch (Exception ex) when (LogAndContinue(ex)) { }  // never catches

static bool LogAndContinue(Exception ex) { Log(ex); return false; }

Code Explained

when (…) — catch only if the condition is true
Same type, different filters — separate handling
Cancellation filter — distinguish caller cancel from timeout
Filter returning false — log without handling
IsTransient(ex) — any bool method works as a filter

⚠ Common Mistakes

  • Catching NullReferenceException — fix the null bug instead
  • Using .Result / .Wait() and then catching the inner type — you get AggregateException; prefer await
  • Side effects in filters that throw — an exception inside a filter is swallowed and treated as false

✓ Tips & Best Practices

  • Filter on HttpRequestException.StatusCode instead of parsing messages
  • Treat OperationCanceledException separately from real failures
  • Use a when (Log(ex)) filter returning false for diagnostics

Quick Summary

  • catch (T e) when (cond) — exception filter
  • Filters run before unwinding
  • AggregateException — many errors in one
  • Know the common BCL exception types
