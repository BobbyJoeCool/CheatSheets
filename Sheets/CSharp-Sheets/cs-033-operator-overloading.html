Operator Overloading

operator + · operator == · implicit / explicit operator · checked operators · user-defined compound assignment (C# 14) · true / false

Custom Operators

Classes and structs can define operators as public static methods with the operator keyword, so a Money or Vector type can be added with +. You can also define conversion operators (implicit / explicit). C# 14 adds user-defined compound assignment (+=) and ++/-- as instance methods that mutate in place.

Key Facts

  • == and != must be defined in pairs (also < / >)
  • Overload == → also override Equals and GetHashCode
  • implicit conversions must never throw or lose data
  • && / || can't be overloaded directly

A Money Type

public readonly record struct Money(decimal Amount, string Currency)
{
    public static Money operator +(Money a, Money b)
    {
        if (a.Currency != b.Currency) 
            throw new InvalidOperationException("Mixed");
        return new(a.Amount + b.Amount, a.Currency);
    }
    public static Money operator *(Money m, decimal f) =>
        m with { Amount = m.Amount * f };
    public static bool operator >(Money a, Money b) => a.Amount > b.Amount;
    public static bool operator <(Money a, Money b) => a.Amount < b.Amount;

    public static implicit operator decimal(Money m) => m.Amount;   // safe
    public static explicit operator Money(decimal d) => new(d, "USD");
}

var total = new Money(10, "USD") + new Money(5, "USD"); // 15 USD
decimal raw = total;            // implicit → 15
var m = (Money)3.5m;            // explicit; == comes from record

Code Explained

operator + — static, takes both operands
> requires a matching <
implicit — no cast needed at the call site
explicit — caller must write (Money)
Records generate == / != for you

C# 14 Compound Assignment

public class Counter
{
    public int Value { get; private set; }
    // instance, void, mutates in place
    public void operator +=(int n) => Value += n;
    public void operator ++() => Value++;
}
var c = new Counter(); c += 5; c++;  // Value = 6

⚠ Common Mistakes

  • Overloading == but not Equals/GetHashCode — collections and LINQ behave inconsistently
  • Implicit conversions that lose precision or throw — make those explicit
  • Overloading operators with surprising meanings (+ that removes) — keep math-like semantics

✓ Tips & Best Practices

  • Use record struct to get equality for free
  • Implement generic math interfaces (IAdditionOperators<,,>) for reusable math
  • Add operator checked variants for types that can overflow

Quick Summary

  • public static T operator +(T a, T b) — binary operator
  • implicit / explicit operator — conversions
  • == with !=, < with > — pairs
  • void operator += — C# 14 in-place
