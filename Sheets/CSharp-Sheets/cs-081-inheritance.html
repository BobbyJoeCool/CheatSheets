Sheet 081

Inheritance

: Base · base. · virtual · override · sealed · new (hiding) · protected members

Reusing and Extending Classes

A class can inherit from one base class with : Base, gaining its members. Methods marked virtual can be overridden in derived classes with override; base.Method() calls the parent's version. sealed stops further inheritance. C# supports single class inheritance plus any number of interfaces.

Key Facts

  • All classes ultimately derive from object
  • Constructors aren't inherited; chain with : base(...)
  • new on a member hides rather than overrides
  • Structs and records structs can't inherit classes

Inheritance Chain

public class Animal(string name)
{
    public string Name { get; } = name;
    public virtual string Speak() => "...";              // overridable
    public override string ToString() => $"{Name} says {Speak()}";
}

public class Dog(string name) : Animal(name)
{
    public override string Speak() => "Woof";
}

public sealed class Puppy(string name) : Dog(name)       // can't be inherited
{
    public override string Speak() => base.Speak() + "!"; // call parent
}

Animal a = new Puppy("Rex");
Console.WriteLine(a);              // Rex says Woof!
public class Cat(string n) : Animal(n)
{ public new string Speak() => "Meow"; }   // hides, doesn't override
Animal c = new Cat("Tom");
Console.WriteLine(c.Speak());      // ... (Animal's version)

Code Explained

virtual — permits overriding
: Animal(name) — inherit and pass ctor args
override — replace the behavior
base.Speak() — call the parent implementation
sealed — end of the chain
new — hiding; called by static type

⚠ Common Mistakes

  • Forgetting virtual on the base method — override fails with CS0506
  • Using new when you meant override — behavior depends on the variable's type
  • Deep inheritance hierarchies — fragile; prefer composition and interfaces

✓ Tips & Best Practices

  • Seal classes that aren't designed for inheritance
  • Favor composition ("has-a") over inheritance ("is-a") for reuse
  • Call base in overrides when extending, not replacing, behavior

Quick Summary

  • : Base — single inheritance
  • virtual / override — polymorphic methods
  • base. — parent access
  • sealed — stop inheritance
