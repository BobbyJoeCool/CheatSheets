if / else if / else

if · else if · else · braces · nested ifs · guard clauses · is checks in conditions

Branching with if

if runs a block when its condition is true; else if adds more conditions checked in order; else handles everything left. The condition must be a bool expression in parentheses. Braces are optional for single statements but recommended. Guard clauses — early returns — keep nesting shallow.

Key Facts

  • Only the first matching branch runs
  • No implicit truthiness: if (count) is an error
  • is patterns can test and declare in the condition
  • A variable declared in a pattern is in scope after a guard

if / else if / else

int score = 82;

if (score >= 90)
{
    Console.WriteLine("A");
}
else if (score >= 80)
{
    Console.WriteLine("B");              // ← runs
}
else Console.WriteLine("Below B");       // braces optional

// Guard clauses instead of deep nesting
static decimal Price(Order? order)
{
    if (order is null) return 0;              // early exit
    if (order.Items.Count == 0) return 0;
    return order.Items.Sum(i => i.Price);
}

if (input is string { Length: > 0 } text)     // test + bind
    Console.WriteLine(text.ToUpper());

Code Explained

else if — checked only when earlier tests fail
else — fallback, no condition
Guard clause — reject bad input first, then the happy path
is string { Length: > 0 } text — type + property test + variable
Braces — safer when adding lines later

⚠ Common Mistakes

  • Adding a second line under a brace-less if — only the first line is conditional
  • Ordering else if from loosest to strictest — >= 80 before >= 90 makes the A branch unreachable
  • Writing if (x = 5) — compile error in C#; use ==

✓ Tips & Best Practices

  • Always use braces except for one-line guard returns
  • Return early to keep the main logic at the left margin
  • Switch to a switch expression when every branch picks a value

Quick Summary

  • if / else if / else — ordered branches
  • Condition must be bool
  • Guard clauses — early returns
  • is patterns — test and bind in one step
