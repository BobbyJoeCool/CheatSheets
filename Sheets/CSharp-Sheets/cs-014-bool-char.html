bool & char

bool · char · 'A' · escape sequences · \e · char.IsDigit · char.IsLetter · Rune

Booleans and Characters

bool holds only true or false and does not convert to or from numbers. char is a single UTF-16 code unit written in single quotes. Most characters fit in one char, but emoji and some scripts need two (a surrogate pair), which is what System.Text.Rune represents.

Key Facts

  • if (1) is an error — conditions must be bool
  • bool.ToString() gives "True" / "False"
  • char arithmetic produces int
  • "😀".Length is 2 — two chars, one Rune

bool and char

bool done = false;
bool ok = bool.Parse("true");       // True
bool isAdult = age >= 18;           // comparison → bool

char c = 'A';
char tab = '\t';
char e = 'é';                  // é
Console.WriteLine(c + 1);           // 66 (int)
Console.WriteLine((char)(c + 1));   // B
Console.WriteLine(char.IsDigit('7'));       // True
Console.WriteLine(char.IsLetter('_'));      // False
Console.WriteLine(char.ToUpper('q'));       // Q
Console.WriteLine((int)'a');                // 97
Console.WriteLine("7"[0] - '0');            // 7 (digit value)

foreach (Rune r in "hi😀".EnumerateRunes())
    Console.Write(r.Value + " ");   // 104 105 128512

Code Explained

bool.Parse — case-insensitive "true" / "false"
'A' + 1 — char promotes to int
(char) — cast back to a character
char.IsDigit, IsLetter, IsWhiteSpace — classify
ch - '0' — digit character to its value
EnumerateRunes() — iterate real code points

⚠ Common Mistakes

  • Writing "A" when you mean 'A' — double quotes make a string, not a char
  • Assuming string.Length counts characters users see — emoji and accents can use several chars
  • Comparing letters with == across cultures — use char.ToUpperInvariant for case-insensitive checks

✓ Tips & Best Practices

  • Name bools as questions: isValid, hasItems, canRetry
  • Use Rune or StringInfo when handling user-visible characters
  • Use char.IsAscii* helpers for fast, culture-free checks

Quick Summary

  • bool — true/false only, no numeric conversion
  • char — one UTF-16 code unit in ' '
  • char.IsDigit & friends — classify chars
  • Rune — a full Unicode code point
