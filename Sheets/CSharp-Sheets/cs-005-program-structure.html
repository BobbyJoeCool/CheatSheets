Program Structure

top-level statements · static void Main · string[] args · namespace · file-scoped namespace · global using

Where a Program Starts

Every C# program has one entry point. Since C# 9, a single file can use top-level statements and the compiler generates the Main method for you. Larger apps still split code into namespaces and classes across files; braces { } mark blocks and every statement ends with ;.

Key Facts

  • Only one file may contain top-level statements
  • args is available automatically in top-level code
  • Main may return int and/or be async Task
  • File-scoped namespace X; saves one indentation level

Classic vs Top-Level

// ── Classic (explicit Main) ─────────────────
using System;                       // import a namespace

namespace Demo;                     // file-scoped namespace (C# 10)

internal static class Program
{
    static int Main(string[] args)  // entry point
    {
        Console.WriteLine($"{args.Length} args");
        return 0;                   // exit code
    }
}

// ── Top-level (same program, C# 9+) ─────────
Console.WriteLine($"{args.Length} args");
return 0;

Code Explained

using — lets you write Console instead of System.Console
namespace Demo; — applies to the whole file
static int Main(string[] args) — classic entry point
return 0 — process exit code (0 = success)
Top-level — compiler wraps it in a generated Main

Valid Main Signatures

SignatureUse
static void Main()No args, no exit code
static int Main(string[] args)Args + exit code
static async Task Main()Await inside Main
static async Task<int> Main(string[] a)Async + exit code

⚠ Common Mistakes

  • Putting top-level statements in two files — error CS8802; only one file may have them
  • Declaring types above top-level statements — statements must come first in the file
  • Writing main in lower case — C# is case-sensitive, so no entry point is found

✓ Tips & Best Practices

  • Use top-level statements for small tools and samples
  • Use file-scoped namespaces in every new file
  • Return a non-zero exit code on failure so scripts can detect it

Quick Summary

  • Main — the single entry point
  • Top-level statements — generated Main
  • namespace X; — file-scoped namespace
  • using — import namespaces
