Unions and Closed Hierarchies (C# 15 preview)

C# 15 (preview, shipping with .NET 11 in November 2026) adds union types — union Pet(Cat, Dog, Bird); — whose values are exactly one of several case types, and the closed modifier, which fixes a class hierarchy to the types declared in the same assembly. In both cases the compiler knows every possibility, so switch expressions are exhaustive without a default arm.

Key Facts

  • Needs the .NET 11 SDK and LangVersion preview
  • Unions convert implicitly from each case type
  • closed classes are implicitly abstract
  • Syntax may still change before release

Unions & closed (preview)

public record Cat(string Name); public record Dog(string Name);
public record Bird(string Name);
public union Pet(Cat, Dog, Bird);                 // union type

Pet pet = new Dog("Rex");                         // implicit conversion
string sound = pet switch
{
    Dog d  => $"{d.Name}: woof",
    Cat c  => $"{c.Name}: meow",
    Bird b => $"{b.Name}: tweet",                  // exhaustive, no _ arm
};

public closed record class GateState;             // closed hierarchy
public record class Closed : GateState;
public record class Open(float Percent) : GateState;

string Describe(GateState s) => s switch
{
    Closed => "closed",
    Open(var pct) => $"{pct}% open",            // no warning: all cases handled
};

Code Explained

union Pet(Cat, Dog, Bird) — exactly one of three
Assign any case type directly
Switch covers every case — no default needed
closed — subclasses only in this assembly
Positional pattern on Open — extract fields

C# 14 Workaround Today

public abstract record Shape
{
    private Shape() { }            // no outside subclasses
    public sealed record Circle(double R) : Shape;
    public sealed record Square(double S) : Shape;
}
// Switches over Shape still need:
//   _ => throw new UnreachableException()

⚠ Common Mistakes

  • Shipping preview language features in production code — syntax and behavior can change
  • Assuming closed is transitive — mark intermediate classes closed too for deep exhaustiveness
  • Combining closed with sealed, static or explicit abstract — not allowed

✓ Tips & Best Practices

  • Try previews in a side project with <LangVersion>preview</LangVersion>
  • Use the private-constructor nested-record pattern on C# 14
  • Libraries like OneOf offer union-like types today

Quick Summary

  • union U(A, B) — one of several types
  • closed — fixed hierarchy
  • Exhaustive switches without _
  • C# 15 preview — verify before relying on it
