What C# Is

C# is a statically typed, object-oriented language from Microsoft, designed by Anders Hejlsberg and released in 2002 with .NET Framework 1.0. Code compiles to IL (intermediate language) that the CLR runs as managed code with garbage collection. Today it runs cross-platform on modern .NET (Windows, macOS, Linux) for web APIs, desktop apps, games (Unity), cloud services and tools.

Key Facts

  • File extension: .cs; project file: .csproj
  • Current: C# 14 / .NET 10 (LTS, Nov 2025)
  • Next: C# 15 / .NET 11 ships Nov 2026 (in preview now)
  • A new major .NET ships every November
  • Open source: Roslyn compiler and runtime on GitHub

Hello, World (C# 9+ top-level statements)

// Program.cs — the whole program
Console.WriteLine("Hello, World!");   // Hello, World!

// Run it:
//   dotnet new console -o Hello
//   cd Hello
//   dotnet run                       // Hello, World!

// Or as a single file (.NET 10):
//   dotnet run hello.cs

Code Explained

Console.WriteLine — writes a line to standard output
Top-level statements — no class or Main needed in one file
dotnet new console — creates a project from a template
dotnet run — builds, then runs the project
dotnet run hello.cs — file-based app, no .csproj needed

⚠ Common Mistakes

  • Confusing .NET Framework with modern .NET — new projects target .NET 8/10, not 4.8
  • Assuming C# is Windows-only — it runs on macOS and Linux with the same SDK
  • Mixing up C# version and .NET version — each .NET release sets the default C# version

✓ Tips & Best Practices

  • Start new work on the current LTS (.NET 10) unless you need a preview feature
  • Check your version with dotnet --version
  • Use dotnet new list to see every project template

Quick Summary

  • C# — typed, OOP language that compiles to IL
  • CLR — runtime that JITs IL and manages memory
  • .NET 10 — current LTS, ships C# 14
  • dotnet run — the fastest way to run code
