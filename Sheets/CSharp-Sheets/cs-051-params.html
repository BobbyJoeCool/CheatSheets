params & Variadic Methods

params T[] · params Span<T> · params IEnumerable<T> · zero arguments · passing an array

Variable Numbers of Arguments

A params parameter lets callers pass zero or more arguments as a comma-separated list, or a collection directly. Before C# 13 it had to be an array; C# 13 params collections also allow Span<T>, ReadOnlySpan<T>, IEnumerable<T>, List<T> and other collection types, and span versions avoid allocating.

Key Facts

  • Only one params parameter, and it must be last
  • Zero arguments → an empty collection, never null
  • Passing null explicitly gives null (for arrays)
  • ReadOnlySpan<T> overloads win when both exist

params in Action

static int Sum(params int[] nums) => nums.Sum();

Console.WriteLine(Sum());              // 0  (empty array)
Console.WriteLine(Sum(1, 2, 3));       // 6
Console.WriteLine(Sum([4, 5]));        // 9  (pass a collection)

// C# 13: params collections
static int Max(params ReadOnlySpan<int> xs)   // no heap allocation
{
    int m = int.MinValue;
    foreach (var x in xs) m = Math.Max(m, x);
    return m;
}
static void LogAll(string prefix, params IEnumerable<string> items)
    => Console.WriteLine($"{prefix}: {string.Join(", ", items)}");

LogAll("Tags", "c#", "dotnet");          // Tags: c#, dotnet

Code Explained

params int[] — classic variadic array
Sum() — empty array, safe to loop
Sum([4, 5]) — pass an existing collection
params ReadOnlySpan<int> — stack-allocated args
params IEnumerable<string> — accept LINQ results
Regular parameters come before params

⚠ Common Mistakes

  • Putting params before other parameters — CS0231; it must be last
  • Calling M(null) on a params string[] and expecting an array with one null — you get a null array
  • Mutating the params array and expecting the caller to see changes — callers usually pass literals

✓ Tips & Best Practices

  • Use params ReadOnlySpan<T> for hot utility methods
  • Add a non-params overload for the common 1–2 argument case if allocation matters
  • Accept params IEnumerable<T> when callers often pass queries

Quick Summary

  • params T[] xs — zero or more args
  • Must be the last parameter
  • C# 13 — spans and collections allowed
  • Callers can pass a collection directly
