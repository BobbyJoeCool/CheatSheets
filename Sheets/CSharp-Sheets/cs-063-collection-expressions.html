Collection Expressions

[1, 2, 3] · .. spread · [] empty · target typing · with(...) arguments (C# 15 preview) · CollectionBuilder

One Syntax for Every Collection

Collection expressions (C# 12) create arrays, lists, spans, sets and immutable collections with the same [a, b, c] syntax; the target type decides what gets built. The spread element ..xs inlines another collection. C# 15 (preview) adds a leading with(...) element that passes constructor arguments such as capacity or a comparer.

Key Facts

  • No natural type: var x = [1, 2]; is an error
  • [] is the empty collection of the target type
  • Spans may be stack-allocated — no heap use
  • Custom types opt in with [CollectionBuilder]

Collection Expressions

int[] arr = [1, 2, 3];
List<string> names = ["Ada", "Bob"];
Span<int> span = [10, 20, 30];               // can live on the stack
HashSet<char> vowels = ['a', 'e', 'i'];
ImmutableArray<int> imm = [1, 2];
IEnumerable<int> seq = [1, 2, 3];             // compiler picks a type

int[] more = [0, .. arr, 4];                  // [0, 1, 2, 3, 4]
List<string> all = [.. names, .. GetOthers()];// combine sources
int[] none = [];                              // empty

static int Sum(ReadOnlySpan<int> xs)
    { int s = 0; foreach (var x in xs) s += x; return s; }
Console.WriteLine(Sum([1, 2, 3]));            // 6 — no array allocated

// C# 15 preview: constructor arguments
List<string> big = [with(capacity: 1000), .. names];
HashSet<string> set = [with(StringComparer.OrdinalIgnoreCase), "A", "a"];
Console.WriteLine(set.Count);                 // 1

Code Explained

Target type — array, list, span, set, immutable…
IEnumerable<int> target — compiler chooses an efficient type
..arr — spread the elements of another collection
[] — empty collection
Span argument — elements stay on the stack
with(...) — must be the first element (C# 15 preview)

Before vs After

OldCollection expression
new int[] { 1, 2 }[1, 2]
new List<int> { 1, 2 }[1, 2]
Array.Empty<int>()[]
a.Concat(b).ToArray()[.. a, .. b]
new List<T>(cap)[with(capacity: cap)]

Custom Type Support

[CollectionBuilder(typeof(Bag), nameof(Bag.Create))]
public class Bag<T> : IEnumerable<T> { … }
public static class Bag
{
    public static Bag<T> Create<T>(ReadOnlySpan<T> xs)
        => new(xs);
}
Bag<int> b = [1, 2, 3];

⚠ Common Mistakes

  • var list = [1, 2, 3]; — CS9176; declare the target type
  • Assuming IEnumerable<int> x = [...] gives a List you can cast and mutate — the type is unspecified
  • Using with(...) anywhere but first, or without LangVersion preview

✓ Tips & Best Practices

  • Use [] to return empty collections — clearer than new()
  • Prefer ReadOnlySpan<T> parameters so callers' [...] avoid allocation
  • Use spreads to combine lists without LINQ Concat

Quick Summary

  • [a, b] — build any collection type
  • ..xs — spread
  • [] — empty
  • with(...) — ctor args (C# 15 preview)
