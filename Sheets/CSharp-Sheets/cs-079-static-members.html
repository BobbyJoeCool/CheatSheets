Static Members & Classes

static fields · static methods · static classes · const vs static readonly · static constructor · singleton pattern

Type-Level Members

Static members belong to the type, not to any object: one copy shared by all instances, accessed as TypeName.Member. A static class can contain only static members and can't be instantiated — perfect for helpers like Math. A static constructor initializes static state once, before first use.

Key Facts

  • Static methods can't use this or instance members
  • const is implicitly static
  • Static state lives for the whole app lifetime
  • Static fields are shared across threads

Static in Practice

public class Order
{
    private static int _nextId = 1;                     // shared counter
    public static readonly TimeSpan Timeout = TimeSpan.FromSeconds(30);
    public const int MaxItems = 100;

    public int Id { get; } = Interlocked.Increment(ref _nextId); // per instance

    static Order() => Console.WriteLine("Order type initialized");  // once

    public static Order Create() => new();              // factory
}

var a = Order.Create();   // "Order type initialized" printed first
var b = Order.Create();
Console.WriteLine($"{a.Id} {b.Id} {Order.MaxItems}");  // 2 3 100

public static class Temperature                         // static class
{
    public static double ToFahrenheit(double c) => c * 9 / 5 + 32;
}
Console.WriteLine(Temperature.ToFahrenheit(100));      // 212

Code Explained

static int _nextId — one value for the whole type
static readonly — runtime constant
Interlocked.Increment — thread-safe counter
Static constructor — runs before first access
static class — helpers only, no instances

⚠ Common Mistakes

  • Storing per-user or per-request data in static fields — every request shares it
  • Unsynchronized writes to static fields from multiple threads — race conditions
  • Hiding dependencies behind static calls — hard to test; inject interfaces instead

✓ Tips & Best Practices

  • Mark helper methods static when they don't use instance state
  • Prefer DI singletons over hand-written static singletons in apps
  • Use using static System.Math; to call Sqrt without the prefix
