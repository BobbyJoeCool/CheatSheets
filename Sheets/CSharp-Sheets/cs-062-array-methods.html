Arrays — Methods

Array.Sort · Array.BinarySearch · Array.IndexOf · Array.Reverse · Array.Fill · Array.Copy · Array.Clear

Static Array Helpers

The System.Array class provides static methods to sort, search, fill, copy and reverse arrays in place. Most mirror LINQ operations but work directly on the array without allocating. BinarySearch is fast (O(log n)) but requires the array to be sorted first.

Key Facts

  • Sort, Reverse, Fill, Clear modify in place
  • IndexOf returns -1 when missing
  • BinarySearch returns a negative number when missing
  • Array.Sort is unstable (introsort)

Array Methods

int[] n = [5, 3, 8, 1, 9];

Array.Sort(n);                          // [1, 3, 5, 8, 9]
Console.WriteLine(Array.BinarySearch(n, 8));   // 3
Console.WriteLine(Array.BinarySearch(n, 4));   // -3 (~index to insert)
Console.WriteLine(Array.IndexOf(n, 9));        // 4
Array.Reverse(n);                       // [9, 8, 5, 3, 1]

int[] z = new int[4];
Array.Fill(z, 7);                       // [7, 7, 7, 7]
Array.Clear(z, 1, 2);                   // [7, 0, 0, 7]
Array.Copy(n, z, 2);                    // z = [9, 8, 0, 7]

string[] w = ["pear", "fig", "apple"];
Array.Sort(w, (x, y) => x.Length.CompareTo(y.Length)); // [fig, pear, apple]
int idx = Array.FindIndex(w, s => s.StartsWith('a'));  // 2
bool any = Array.Exists(w, s => s.Length > 4);         // True
int[] lens = Array.ConvertAll(w, s => s.Length);       // [3, 4, 5]

Code Explained

Sort — ascending in place
BinarySearch — needs sorted input; ~result = insert point
Reverse / Fill / Clear — in-place edits
Copy(src, dest, count) — copy elements
Comparison lambda — custom sort order
FindIndex / Exists / ConvertAll — predicate helpers

Array vs LINQ

In place (Array)New sequence (LINQ)
Array.Sort(a)a.Order()
Array.Reverse(a)a.Reverse()
Array.Find(a, p)a.FirstOrDefault(p)
Array.ConvertAll(a, f)a.Select(f).ToArray()
Array.Exists(a, p)a.Any(p)

⚠ Common Mistakes

  • Calling BinarySearch on unsorted data — returns wrong answers without any error
  • Expecting Array.Sort to keep equal items in order — it's unstable; use LINQ OrderBy for stability
  • Confusing Array.Copy with assignment — b = a copies the reference, not the elements

✓ Tips & Best Practices

  • Use ~Array.BinarySearch(...) to find the insertion point
  • Use a.AsSpan().Sort() / .Reverse() for span-based work
  • Sort parallel arrays together with Array.Sort(keys, items)

Quick Summary

  • Array.Sort / Reverse — in place
  • BinarySearch — sorted only
  • Fill / Clear / Copy — bulk edits
  • Find / Exists / ConvertAll — predicates
