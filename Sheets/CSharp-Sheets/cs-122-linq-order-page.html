LINQ — Ordering & Paging

OrderBy · ThenBy · OrderDescending · Reverse · Skip · Take · Chunk · Index()

Sorting and Paging

OrderBy / OrderByDescending sort by a key and ThenBy adds tie-breakers; LINQ sorting is stable. Order() (.NET 7) sorts by natural order. Skip and Take implement paging, TakeWhile/SkipWhile stop on a condition, Chunk splits into batches, and Index() (.NET 9) pairs each item with its position.

Key Facts

  • Sorting needs the whole sequence before yielding
  • Take(2..5) accepts a range (.NET 6)
  • C# 14: array.Reverse() binds to the in-place span version
  • Page formula: Skip((page - 1) * size).Take(size)

Ordering, Paging, Batching

var people = new[] { ("Ada", 36), ("Bob", 25), ("Cy", 36), ("Di", 19) };

var sorted = people.OrderByDescending(p => p.Item2)   // age desc
                   .ThenBy(p => p.Item1);             // then name
// (Ada,36) (Cy,36) (Bob,25) (Di,19)

int[] nums = [4, 1, 3];
var asc = nums.Order();                               // 1, 3, 4

int page = 2, size = 2;
var paged = sorted.Skip((page - 1) * size).Take(size);  // (Bob,25) (Di,19)
var middle = Enumerable.Range(0, 10).Take(3..6);        // 3, 4, 5

var leading = new[] { 2, 4, 5, 6 }.TakeWhile(n => n % 2 == 0); // 2, 4

foreach (int[] batch in Enumerable.Range(1, 7).Chunk(3))
    Console.Write($"[{string.Join(",", batch)}] ");   // [1,2,3] [4,5,6] [7]

foreach (var (i, p) in sorted.Index())                // .NET 9
    Console.WriteLine($"{i + 1}. {p.Item1}");

Code Explained

OrderByDescending + ThenBy — multi-key sort
Order() — natural ascending order
Skip + Take — pages
Take(range) — slice by indices
TakeWhile — stop at the first non-match
Chunk(n) — arrays of up to n items

Operators

OperatorReturns
OrderBy / OrderByDescendingSorted by key
ThenBy / ThenByDescendingSecondary keys
Order / OrderDescendingNatural order
Skip(n) / Take(n)Paging
SkipLast(n) / TakeLast(n)From the end
Chunk(n) / Index()Batches / (index, item)

Watch Out

CodeProblem
xs.OrderBy(a).OrderBy(b)Second sort replaces the first
Skip/Take without OrderByUnstable pages in databases
TakeWhile vs WhereTakeWhile stops at first miss
Deep Skip on big tablesSlow — use keyset paging

⚠ Common Mistakes

  • Chaining OrderBy(...).OrderBy(...) — use ThenBy for the second key
  • Paging without a deterministic order — items repeat or vanish between pages
  • Using Take when you mean "while" — TakeWhile stops at the first failing element

✓ Tips & Best Practices

  • Add a unique key (e.g. Id) as the last ThenBy for stable paging
  • Use Chunk to batch API calls or database inserts
  • Use Index() instead of Select((x, i) => …) for readability

Quick Summary

  • OrderBy / ThenBy — stable sort
  • Skip / Take — paging
  • Chunk — batching
  • Index() — positions (.NET 9)
