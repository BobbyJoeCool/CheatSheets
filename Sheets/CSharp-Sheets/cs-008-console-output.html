Sheet 008

Console Output

Console.WriteLine · Console.Write · Console.Error · Debug.WriteLine · ForegroundColor · Console.Clear

Writing to the Console

System.Console writes text to standard output (Console.Out) and standard error (Console.Error). WriteLine adds a newline, Write does not. Both accept any value (calling ToString()) and support composite formatting with {0} placeholders, though string interpolation $"..." is usually clearer.

Key Facts

  • using System; is implicit with ImplicitUsings
  • Console.WriteLine() with no args prints a blank line
  • null prints as an empty string
  • Debug.WriteLine goes to the debugger, not the console

Output Variants

Console.WriteLine("Hello");            // Hello⏎
Console.Write("A"); Console.Write("B"); // AB (no newline)
Console.WriteLine(42);                 // 42
Console.WriteLine(3.5 * 2);            // 7
Console.WriteLine(true);               // True

string name = "Ada"; int age = 36;
Console.WriteLine($"{name} is {age}");      // Ada is 36
Console.WriteLine("{0} is {1}", name, age); // Ada is 36
Console.WriteLine($"[{name,-6}][{age,4}]"); // [Ada   ][  36]
Console.WriteLine("Tab:\tNew:\nX");         // Tab:    New:⏎X

Console.Error.WriteLine("Something failed"); // to stderr
System.Diagnostics.Debug.WriteLine("dbg");   // debugger only

Code Explained

WriteLine — value + newline
Write — value only; build a line in pieces
$"{x}" — interpolation (preferred)
{0}, {1} — composite format placeholders
{x,-6} / {x,4} — left / right align in 6 / 4 chars
Console.Error — stderr; survives > out.txt redirects

⚠ Common Mistakes

  • Writing errors to Console.WriteLine — they disappear into redirected output; use Console.Error
  • Forgetting ResetColor() after changing colors — the terminal stays colored
  • Expecting Debug.WriteLine in Release builds — calls are removed by [Conditional("DEBUG")]

✓ Tips & Best Practices

  • Prefer $"..." over {0} placeholders for readability
  • Use alignment {x,-10} to print simple tables
  • For logs in real apps use ILogger, not Console

Quick Summary

  • Console.WriteLine — print with newline
  • Console.Write — print without newline
  • Console.Error — write to stderr
  • {x,10} — alignment inside interpolation
