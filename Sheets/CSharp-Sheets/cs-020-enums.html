Named Constants

An enum defines a set of named integral constants, making code like status == OrderStatus.Shipped readable and type-safe. The underlying type is int by default. Mark an enum [Flags] and use powers of two to combine values with bitwise operators.

Key Facts

  • First member is 0 unless you set values
  • Any int can be cast to an enum, even undefined ones
  • default(MyEnum) is 0 — define a None = 0 member
  • Generic helpers: Enum.GetValues<T>(), Enum.Parse<T>()

Enums and Flags

enum OrderStatus { Pending, Paid, Shipped = 10, Delivered }  // 0,1,10,11
enum Level : byte { Low = 1, High = 2 }                      // byte-backed

var s = OrderStatus.Paid;
Console.WriteLine(s);                  // Paid
Console.WriteLine((int)s);             // 1
Console.WriteLine((OrderStatus)11);    // Delivered
Console.WriteLine((OrderStatus)99);    // 99 (no error!)

var p = Enum.Parse<OrderStatus>("Shipped");          // Shipped
Enum.TryParse("paid", ignoreCase: true, out OrderStatus q); // Paid
foreach (var v in Enum.GetValues<OrderStatus>()) Console.Write($"{v} ");

[Flags] enum Perm { None = 0, Read = 1, Write = 2, Exec = 4 }
var rw = Perm.Read | Perm.Write;
Console.WriteLine(rw);                 // Read, Write
Console.WriteLine(rw.HasFlag(Perm.Write)); // True
rw &= ~Perm.Write;                     // remove a flag → Read

Code Explained

Shipped = 10 — later members continue from 10
: byte — choose the underlying integer type
Casting undefined values — allowed; validate with Enum.IsDefined
Enum.Parse<T> — string → enum (throws if unknown)
[Flags] + | — combine; ToString lists names
&= ~flag — clear a flag

Switch on an Enum

string Label(OrderStatus s) => s switch
{
    OrderStatus.Pending   => "Waiting",
    OrderStatus.Paid      => "Paid",
    OrderStatus.Shipped   => "On the way",
    OrderStatus.Delivered => "Done",
    _ => throw new ArgumentOutOfRangeException(nameof(s))
};

⚠ Common Mistakes

  • Trusting casts from external ints — (OrderStatus)99 is legal; check Enum.IsDefined
  • Flags values that aren't powers of two — Read = 1, Write = 2, Exec = 3 overlaps
  • Reordering members after persisting numbers — stored values now mean something else

✓ Tips & Best Practices

  • Give explicit values to enums stored in databases or JSON
  • Always include None = 0 in [Flags] enums
  • Add a _ => arm in switches to catch undefined values

Quick Summary

  • enum — named integer constants
  • [Flags] — combinable bit values
  • Enum.Parse<T> / TryParse — from text
  • HasFlag — test a flag
