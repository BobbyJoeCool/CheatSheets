Loop Control & Jumps

break · continue · labeled break / continue (C# 15 preview) · goto · return · yield break

Controlling Loop Flow

break exits the innermost loop or switch, continue skips to the next iteration, and return leaves the whole method. To exit nested loops you previously needed a flag, goto or a helper method; C# 15 (preview) adds labeled break and continue that name the target loop.

Key Facts

  • break / continue affect the innermost loop only
  • Labeled jumps need .NET 11 SDK + LangVersion preview
  • yield break ends an iterator method
  • C# has no pass; use an empty block { }

break, continue & labels

foreach (int n in Enumerable.Range(1, 10))
{
    if (n % 2 == 0) continue;           // skip evens
    if (n > 7) break;                   // stop the loop
    Console.Write(n);                   // 1357
}

// C# 15 preview: labeled break / continue
outer: for (int r = 0; r < rows; r++)
{
    for (int c = 0; c < cols; c++)
    {
        if (blocked[r, c]) continue outer;   // next row
        if (goal[r, c]) break outer;         // leave both loops
    }
}

Code Explained

continue — jump to the next iteration
break — leave the innermost loop
outer: — label placed directly on the loop
continue outer — next iteration of the outer loop
break outer — exit both loops at once

⚠ Common Mistakes

  • Expecting break inside a switch inside a loop to exit the loop — it only exits the switch
  • Using labeled jumps on C# 14 — they don't exist yet; use a method + return
  • Long chains of continue — invert the conditions or filter the input first

✓ Tips & Best Practices

  • Use continue for early "skip this one" checks
  • Turn nested search loops into a method that returns the result
  • Replace search loops with LINQ (Any, First) when it reads better

Quick Summary

  • break — exit innermost loop
  • continue — next iteration
  • break outer / continue outer — C# 15 preview
  • return — exit everything
