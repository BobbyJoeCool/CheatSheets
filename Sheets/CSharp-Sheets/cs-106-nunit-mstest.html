NUnit and MSTest

NUnit and MSTest are the other two mainstream .NET test frameworks. Concepts map closely to xUnit — test attributes, data-driven cases, setup/teardown — but the attribute names and assertion styles differ. NUnit is known for its fluent constraint model (Assert.That(x, Is.EqualTo(5))); MSTest is Microsoft's own, built into Visual Studio.

Key Facts

  • Templates: dotnet new nunit / dotnet new mstest
  • Both run with dotnet test
  • Both support the Microsoft.Testing.Platform runner
  • NUnit reuses one fixture instance for all tests in a class

Same Test, Two Frameworks

[TestFixture]                                              // NUnit
public class CartTests
{
    private Cart _cart = null!;
    [SetUp] public void Init() => _cart = new Cart();      // before each
    [TestCase(1, 10.0, 10.0)]
    [TestCase(3, 2.5, 7.5)]
    public void Total_IsQtyTimesPrice(int qty, double price, double total)
    {
        _cart.Add("pen", qty, price);
        Assert.That(_cart.Total, Is.EqualTo(total).Within(0.001));
    }
}
[TestClass]                                                // MSTest
public class CartTestsMs
{
    [TestMethod, DataRow(1, 10.0, 10.0)]
    public void Total(int qty, double price, double total) =>
        Assert.AreEqual(total, Cart.Of("pen", qty, price).Total, 0.001);
}

Code Explained

[TestFixture] / [TestClass] — test class
[SetUp] / [TestInitialize] — before each test
[TestCase] / [DataRow] — inline data
Assert.That(x, Is.EqualTo(y)) — NUnit constraints
.Within(0.001) — tolerance for doubles
Assert.AreEqual(expected, actual, delta) — MSTest

⚠ Common Mistakes

  • Keeping state in NUnit fixture fields without [SetUp] — the instance is shared across tests
  • Using MSTest's ExpectedException attribute — passes if any line throws; use Assert.ThrowsExactly<T>
  • Mixing frameworks in one test project — pick one per project

✓ Tips & Best Practices

  • Choose by team familiarity; capabilities are similar
  • Use MSTest.Sdk for the simplest MSTest project setup
  • Use [Parallelizable] (NUnit) to speed up suites

Quick Summary

  • NUnit — [Test], Assert.That constraints
  • MSTest — [TestMethod], Assert.AreEqual
  • Both — data rows, setup/teardown, dotnet test
