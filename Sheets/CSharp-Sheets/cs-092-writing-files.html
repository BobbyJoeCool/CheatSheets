Sheet 092

Writing & Appending Files

File.WriteAllText · File.AppendAllText · StreamWriter · FileStream · FileMode · async variants

Writing Files

File.WriteAllText / WriteAllLines create or overwrite a file in one call, and AppendAllText adds to the end. For many writes use a StreamWriter, which buffers output; dispose it (or Flush) so data reaches disk. FileStream with a FileMode gives precise control over create/append/overwrite behavior.

Key Facts

  • Write methods overwrite existing files
  • The target directory must already exist
  • Data may sit in a buffer until Dispose/Flush
  • Default encoding is UTF-8 without BOM

Writing Text

File.WriteAllText("out.txt", "Hello\n");               // create/overwrite
File.AppendAllText("out.txt", "More\n");               // append
File.WriteAllLines("list.txt", ["a", "b", "c"]);       // one per line
File.WriteAllBytes("data.bin", [0x01, 0x02]);

using (var w = new StreamWriter("log.txt", append: true))
{
    w.WriteLine($"{DateTime.Now:o} started");
    w.WriteLine("…");
}                                                      // flushed + closed

await File.WriteAllTextAsync("out.txt", json);         // async

// Safe replace: write temp, then move over the original
string tmp = path + ".tmp";
await File.WriteAllTextAsync(tmp, newContent);
File.Move(tmp, path, overwrite: true);

Code Explained

WriteAllText — replaces the whole file
AppendAllText — creates if missing, else appends
WriteAllLines — any IEnumerable<string>
StreamWriter(path, append: true) — buffered writes
using — guarantees flush and close
Temp + File.Move — avoid half-written files

⚠ Common Mistakes

  • Writing to a folder that doesn't exist — DirectoryNotFoundException; call Directory.CreateDirectory first
  • Forgetting to dispose a StreamWriter — the end of the file is missing
  • Overwriting important files in place — a crash leaves them corrupt; write to a temp file and move

✓ Tips & Best Practices

  • Use File.AppendAllText for quick logs; ILogger for real logging
  • Pass new UTF8Encoding(true) if a tool needs a BOM
  • Use FileOptions.Asynchronous for heavy async file I/O

Quick Summary

  • WriteAllText — overwrite
  • AppendAllText — append
  • StreamWriter — buffered, dispose it
  • Temp file + File.Move — atomic replace
