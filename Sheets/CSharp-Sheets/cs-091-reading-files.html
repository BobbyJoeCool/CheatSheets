Reading Files

The static File class reads a whole file in one call — as a string, an array of lines or bytes. For large files use File.ReadLines, which streams lines lazily, or a StreamReader for full control. Every method has an Async version for apps that must stay responsive. Text defaults to UTF-8.

Key Facts

  • Missing file → FileNotFoundException
  • ReadAllLines loads everything; ReadLines streams
  • Relative paths resolve from the current directory
  • Pass an Encoding for non-UTF-8 files

Reading Text

string path = "notes.txt";
if (!File.Exists(path)) return;

string all = File.ReadAllText(path);              // whole file
string[] lines = File.ReadAllLines(path);         // array of lines
byte[] raw = File.ReadAllBytes("logo.png");       // binary

foreach (string line in File.ReadLines("big.log")) // lazy, low memory
    if (line.Contains("ERROR")) Console.WriteLine(line);

int errors = File.ReadLines("big.log").Count(l => l.StartsWith("ERR"));

using var reader = new StreamReader(path);        // manual control
while (reader.ReadLine() is { } line)
    Console.WriteLine(line);

string text = await File.ReadAllTextAsync(path);  // async
await foreach (var l in File.ReadLinesAsync(path)) { }  // .NET 7+

Code Explained

File.Exists — check before reading (still handle errors)
ReadAllText / ReadAllLines / ReadAllBytes — load fully
ReadLines — IEnumerable<string>, one line at a time
LINQ on ReadLines — streams without loading the file
ReadLine() is { } line — loop until null
ReadAllTextAsync / ReadLinesAsync — non-blocking

⚠ Common Mistakes

  • Using ReadAllLines on multi-GB logs — runs out of memory; use ReadLines
  • Relying only on File.Exists — the file can disappear before you read it; still catch IOException
  • Assuming the working directory is the exe folder — use AppContext.BaseDirectory

✓ Tips & Best Practices

  • Use Path.Combine(AppContext.BaseDirectory, "data.json") for app files
  • Use async APIs in web and UI apps
  • Pass Encoding.Latin1 etc. when reading legacy files

Quick Summary

  • File.ReadAllText — whole file
  • File.ReadLines — streaming lines
  • StreamReader — fine-grained reads
  • …Async — non-blocking versions
