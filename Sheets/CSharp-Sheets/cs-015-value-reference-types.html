Value vs Reference Types

stack vs heap · struct vs class · copy semantics · boxing · unboxing · ValueType

Two Kinds of Types

Value types (struct, enum, all numeric types, bool, char) hold their data directly, and assignment copies the value. Reference types (class, string, arrays, delegates, record) hold a reference to an object on the heap, and assignment copies the reference, so both variables see the same object.

Key Facts

  • Value types can't be null (unless T?)
  • Locals of value type usually live on the stack
  • Boxing wraps a value in an object on the heap
  • string is a reference type but behaves like a value (immutable)

Copy vs Share

struct PointS { public int X; }
class  PointC { public int X; }

var s1 = new PointS { X = 1 };
var s2 = s1;          // copies the data
s2.X = 99;
Console.WriteLine(s1.X);   // 1  (unchanged)

var c1 = new PointC { X = 1 };
var c2 = c1;          // copies the reference
c2.X = 99;
Console.WriteLine(c1.X);   // 99 (same object)

object boxed = 42;          // boxing: int → object (heap)
int unboxed = (int)boxed;   // unboxing
// long bad = (long)boxed;  // InvalidCastException

Console.WriteLine(ReferenceEquals(c1, c2)); // True

Code Explained

struct assignment — independent copy
class assignment — two names, one object
Boxing — allocation each time a value becomes object
Unboxing — must cast to the exact boxed type
ReferenceEquals — same object?

⚠ Common Mistakes

  • Mutating a struct inside a List<T> — list[0].X = 5 won't compile because the indexer returns a copy
  • Unboxing to a different numeric type — (long)(object)42 throws; unbox then convert
  • Assuming class parameters are passed "by reference" — the reference is copied; reassigning it doesn't affect the caller

✓ Tips & Best Practices

  • Make structs small and immutable (readonly struct)
  • Avoid boxing in hot loops — use generics instead of object
  • Use record when you want reference types with value equality

Quick Summary

  • Value types — copy the data
  • Reference types — copy the reference
  • Boxing — value → object, costs an allocation
  • ReferenceEquals — identity check
