Ternary & Conditional Expressions

?: · nested ternary · target-typed conditional · ref conditional · ?? as fallback

Expressions That Choose

The conditional operator condition ? a : b evaluates to a when true and b when false. Unlike if, it is an expression, so it can initialize variables, be returned, or be passed as an argument. Both branches must convert to a common type, which C# 9 can take from the target.

Key Facts

  • Only the chosen branch is evaluated
  • Right-associative: a ? b : c ? d : e
  • ?? is a shorter choice for null fallbacks
  • ref ternaries choose between variables

Ternary Forms

int age = 20;
string group = age >= 18 ? "adult" : "minor";         // "adult"
Console.WriteLine($"{n} item{(n == 1 ? "" : "s")}");  // pluralize

// Nested — keep it short or use a switch expression
string size = n < 10 ? "small" : n < 100 ? "medium" : "large";

// Target-typed (C# 9): the declared type unifies both sides
int? maybe = age > 0 ? age : null;
IShape s = useCircle ? new Circle() : new Square();

decimal Total(bool vip, decimal amt) => vip ? amt * 0.9m : amt;

string name = user?.Name ?? "Guest";     // null fallback

int a = 1, b = 2;
ref int bigger = ref (a > b ? ref a : ref b);
bigger = 99;                             // b is now 99

⚠ Common Mistakes

  • Nesting ternaries three deep — unreadable; use a switch expression
  • Forgetting parentheses in interpolation — $"{a ? b : c}" treats : as a format specifier
  • Using ?: only for side effects (ok ? Save() : Log()) — use if

✓ Tips & Best Practices

  • Keep each branch short and side-effect free
  • Put each part on its own line for longer ternaries
  • Use ?? instead of x != null ? x : y

Quick Summary

  • c ? a : b — conditional expression
  • Only one branch is evaluated
  • Target typing (C# 9) — resolves mixed types
  • ref (c ? ref a : ref b) — conditional alias
