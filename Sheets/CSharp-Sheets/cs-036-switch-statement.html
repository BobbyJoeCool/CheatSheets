switch Statement

switch · case · break · default · goto case · case guards (when) · no implicit fall-through

The switch Statement

A switch statement compares one value against case labels and runs the matching section. C# has no implicit fall-through: each non-empty section must end with break, return, throw, continue or goto case. Cases can use patterns and when guards, not just constants.

Key Facts

  • Works on any type with patterns (C# 7+)
  • Stack empty labels to share one section
  • default can appear anywhere; runs last
  • Use a switch expression when you just need a value

switch Statement

switch (command)
{
    case "start":
    case "run":                          // stacked labels
        Start();
        break;
    case "stop":
        Stop(); break;
    case "restart":
        Stop();
        goto case "start";               // explicit jump
    default:
        Console.WriteLine($"Unknown: {command}"); break;
}

switch (shape)
{
    case Circle c when c.Radius > 10:    // type pattern + guard
        Console.WriteLine("Big circle"); break;
    case Circle c:
        Console.WriteLine($"Circle r={c.Radius}"); break;
}

Code Explained

Stacked case labels — share one block
break — required at the end of each section
goto case — deliberate fall-through
default — no other case matched
case Circle c when … — pattern + extra condition
Order matters — specific cases before general ones

Case Label Kinds

LabelMatches
case 3:Constant
case "a" or "b":Either constant
case > 100:Relational
case int n:Type, binds n
case Point { X: 0 }:Property pattern
case var x when x.Ok:Any value + guard

Section Exits

StatementEffect
breakLeave the switch
returnLeave the method
throwRaise an exception
goto case XJump to another case
goto defaultJump to default
continueNext loop iteration (in a loop)

⚠ Common Mistakes

  • Leaving out break — error CS0163: control cannot fall through to another case
  • Putting a general pattern before a specific one — the compiler flags the later case as unreachable
  • Using break inside a switch to exit a surrounding loop — it only exits the switch

✓ Tips & Best Practices

  • Prefer switch expressions when each case produces a value
  • Combine constants with or instead of stacking many labels
  • Throw in default for enums so new members don't slip through

Quick Summary

  • switch — multi-way branch on one value
  • No fall-through — end each section
  • case T x when … — patterns with guards
  • goto case — explicit jump
