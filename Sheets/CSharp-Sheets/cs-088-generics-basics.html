Generics — Basics

generic classes · generic methods · type inference · default(T) · generic interfaces · nameof(List<>) (C# 14)

Type Parameters

Generics let you write classes, interfaces and methods with type parameters (T) that callers fill in, giving type safety and reuse without casting or boxing. List<T>, Dictionary<TKey, TValue> and Func<T, TResult> are generic. The compiler usually infers type arguments for generic methods.

Key Facts

  • Name type params T or TSomething
  • default(T) / default gives null or zero
  • Value-type instantiations get specialized code — no boxing
  • C# 14: nameof(List<>) with an unbound generic

Generic Types & Methods

public class Box<T>(T value)
{
    public T Value { get; } = value;
    public Box<TOut> Map<TOut>(Func<T, TOut> f) => new(f(Value));
}

var b = new Box<int>(21);
Box<string> s = b.Map(x => $"#{x * 2}");     // TOut inferred as string
Console.WriteLine(s.Value);                  // #42

static T FirstOrFallback<T>(IEnumerable<T> xs, T fallback)
{
    foreach (var x in xs) return x;
    return fallback;
}
Console.WriteLine(FirstOrFallback([3, 4], 0));          // 3 (T = int)
Console.WriteLine(FirstOrFallback<string>([], "none")); // none

static void Swap<T>(ref T a, ref T b) => (a, b) = (b, a);

Console.WriteLine(nameof(Dictionary<,>));    // Dictionary (C# 14)

Code Explained

Box<T> — generic class
Map<TOut> — generic method on a generic type
Inference — TOut comes from the lambda's return
<string> — explicit when inference can't decide
Swap<T>(ref T, ref T) — works for any type
nameof(Dictionary<,>) — unbound generic name (C# 14)

⚠ Common Mistakes

  • Using object parameters instead of generics — loses type safety and boxes value types
  • Comparing T values with == without a constraint — not allowed; use EqualityComparer<T>.Default
  • Creating new T() without the new() constraint — compile error

✓ Tips & Best Practices

  • Let inference work; only write type arguments when needed
  • Prefer generic methods over generic classes when only one method needs T
  • Use EqualityComparer<T>.Default.Equals(a, b) for generic equality

Quick Summary

  • class C<T> — generic type
  • M<T>(…) — generic method
  • Type inference — usually automatic
  • default(T) — zero or null
