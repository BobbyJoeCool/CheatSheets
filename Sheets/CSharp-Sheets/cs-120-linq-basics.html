LINQ — Basics

method syntax · query syntax · deferred execution · ToList / ToArray · IEnumerable vs IQueryable · multiple enumeration

Language-Integrated Query

LINQ queries any data source — arrays, lists, XML, databases — with the same operators. You can write method syntax (xs.Where(…).Select(…)) or query syntax (from x in xs where … select …); they compile to the same calls. Most operators use deferred execution: nothing runs until you enumerate the result.

Key Facts

  • Operators are extension methods in System.Linq
  • ToList(), Count(), First() execute immediately
  • IEnumerable<T> runs in memory; IQueryable<T> is translated (e.g. to SQL)
  • Re-enumerating a query re-runs it

Two Syntaxes, Deferred Execution

int[] nums = [5, 3, 8, 1, 9, 2];

var big = nums.Where(n => n > 4).OrderBy(n => n).Select(n => n * 10);

var big2 = from n in nums                 // query syntax — same result
           where n > 4
           orderby n
           select n * 10;

Console.WriteLine(string.Join(",", big)); // 50,80,90

var list = new List<int> { 1, 2 };
var query = list.Where(x => x > 1);       // nothing runs yet
list.Add(3);
Console.WriteLine(query.Count());         // 2 — sees the new item

var snapshot = list.Where(x => x > 1).ToList();   // runs now, fixed copy
var slow = GetOrders().Where(o => o.Total > 100);
int c = slow.Count(); var f = slow.First();       // ✗ query runs twice

Code Explained

Method syntax — chain extension methods with lambdas
Query syntax — SQL-like keywords, same IL
string.Join — enumerates the query
Deferred — the query sees later changes to list
ToList() — execute once and keep results
Multiple enumeration — cache with ToList()

⚠ Common Mistakes

  • Enumerating an expensive query several times — call ToList() once
  • Assuming a query captured the data when defined — it reads the source when enumerated
  • Calling ToList() on an IQueryable too early — pulls the whole table into memory

✓ Tips & Best Practices

  • Prefer method syntax; use query syntax for joins and let
  • Keep IQueryable until the last step so filters run in the database
  • Use Enumerable.Range, Repeat, Empty to generate sequences

Quick Summary

  • LINQ — one query model for all data
  • Method vs query syntax — same result
  • Deferred execution — runs on enumeration
  • ToList() — materialize once
