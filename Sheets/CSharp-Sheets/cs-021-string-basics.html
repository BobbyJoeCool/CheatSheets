String Basics

string vs String · immutability · Length · indexer · @"" verbatim · """ raw literals · string.IsNullOrWhiteSpace

Text in C#

string (alias for System.String) is an immutable sequence of UTF-16 chars. Every method that seems to change a string returns a new one. Strings are reference types, but == compares their contents. C# offers regular, verbatim @"...", and raw """...""" literals.

Key Facts

  • string.Empty == ""; default of string is null
  • Index with s[0]; read-only, no s[0] = 'x'
  • Raw literals (C# 11) need no escaping
  • "abc"u8 is a UTF-8 ReadOnlySpan<byte>

Literals & Basics

string a = "Hello";
string path = @"C:\temp\new";      // verbatim: \ is literal
string q = "She said \"hi\"";      // escaped quotes
string json = """
    { "name": "Ada", "tags": ["c#"] }
    """;                            // raw: no escapes, indent trimmed

Console.WriteLine(a.Length);        // 5
Console.WriteLine(a[1]);            // e
Console.WriteLine(a + " World");    // Hello World
Console.WriteLine(a == "Hello");    // True (content)
Console.WriteLine(new string('-', 5)); // -----
string up = a.ToUpper();            // "HELLO"; a unchanged

Console.WriteLine(string.IsNullOrEmpty(""));       // True
Console.WriteLine(string.IsNullOrWhiteSpace("  ")); // True

Code Explained

@"..." — backslashes are literal; "" for a quote
"""...""" — raw literal; closing quotes set indentation
Length — number of UTF-16 chars
== — ordinal content comparison
new string(c, n) — repeat a char
Immutability — ToUpper returns a new string

⚠ Common Mistakes

  • Calling s.Trim(); and ignoring the result — strings are immutable; write s = s.Trim();
  • Building strings with += in a loop — each step copies; use StringBuilder or string.Join
  • Checking only s == "" — misses null; use string.IsNullOrEmpty

✓ Tips & Best Practices

  • Use raw literals for JSON, SQL and regex patterns
  • Prefer string.IsNullOrWhiteSpace for user input checks
  • Use string (keyword) in code, String only in docs if you like

Quick Summary

  • string — immutable UTF-16 text
  • @"" / """ — verbatim / raw literals
  • == — compares contents
  • IsNullOrWhiteSpace — robust empty check
