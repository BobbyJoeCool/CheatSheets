Environment & Processes

Environment.GetEnvironmentVariable · Environment.Exit · Process.Start · ProcessStartInfo · Stopwatch · RuntimeInformation

The Process and Its Environment

Environment exposes information about the running process and machine: environment variables, processor count, OS, exit codes. Process starts and controls other programs, optionally capturing their output. Stopwatch measures elapsed time precisely, and OperatingSystem / RuntimeInformation detect the platform.

Key Facts

  • Env var lookup returns null if not set
  • Environment.Exit(code) ends the process immediately
  • Redirected output must be read or the child can hang
  • Stopwatch uses a high-resolution timer

Environment, Process, Stopwatch

string? env = Environment.GetEnvironmentVariable("ASPNETCORE_ENVIRONMENT");
string home = Environment.GetEnvironmentVariable("HOME") ?? "/";
Console.WriteLine(Environment.ProcessorCount);       // e.g. 10
Console.WriteLine(Environment.MachineName);
Console.WriteLine(OperatingSystem.IsMacOS());        // True on a Mac
Console.WriteLine(RuntimeInformation.FrameworkDescription); // .NET 10.0.x

var psi = new ProcessStartInfo("git")
{
    ArgumentList = { "status", "--short" },
    RedirectStandardOutput = true,
    WorkingDirectory = "/repo"
};
using var proc = Process.Start(psi)!;
string output = await proc.StandardOutput.ReadToEndAsync();
await proc.WaitForExitAsync();
Console.WriteLine($"exit {proc.ExitCode}: {output}");

var sw = Stopwatch.StartNew();
DoWork();
Console.WriteLine($"{sw.ElapsedMilliseconds} ms");
long t0 = Stopwatch.GetTimestamp();                  // allocation-free
Console.WriteLine(Stopwatch.GetElapsedTime(t0));     // TimeSpan (.NET 7)

Code Explained

GetEnvironmentVariable — null when unset
OperatingSystem.IsX() — platform checks
ArgumentList — one entry per arg, no quoting issues
RedirectStandardOutput — capture output
WaitForExitAsync — await the child process
Stopwatch — timing; GetElapsedTime avoids allocation

⚠ Common Mistakes

  • Building one argument string with manual quotes — use the ArgumentList overload
  • Redirecting output but not reading it — the child blocks when its buffer fills
  • Timing code with DateTime.Now — low resolution; use Stopwatch

✓ Tips & Best Practices

  • Read configuration through IConfiguration, not raw env vars, in apps
  • Use CliWrap for complex process piping
  • Use BenchmarkDotNet for serious performance measurement

Quick Summary

  • Environment — env vars, machine info
  • Process.Start — run other programs
  • Stopwatch — precise timing
  • OperatingSystem.IsX() — platform checks
