for Loops

for · counter variables · multiple variables · reverse loops · nested loops · for (;;)

Counted Loops

A for loop has three parts: an initializer that runs once, a condition checked before each iteration, and an iterator that runs after each iteration. It's the right choice when you need the index, want to step by something other than 1, loop backwards, or modify the collection by position.

Key Facts

  • The loop variable is scoped to the loop
  • All three parts are optional: for (;;) loops forever
  • Multiple variables are comma-separated
  • Use foreach when you don't need the index

for Loop Patterns

for (int i = 0; i < 5; i++)
    Console.Write(i);                   // 01234

for (int i = 10; i > 0; i -= 3)
    Console.Write($"{i} ");             // 10 7 4 1

string[] names = ["Ada", "Bob", "Cy"];
for (int i = names.Length - 1; i >= 0; i--)
    Console.Write(names[i]);            // CyBobAda (reverse)

for (int i = 0, j = 9; i < j; i++, j--)
    Console.Write($"({i},{j})");        // (0,9)(1,8)…(4,5)

for (int r = 1; r <= 3; r++)            // nested: multiplication table
{
    for (int c = 1; c <= 3; c++)
        Console.Write($"{r * c,4}");
    Console.WriteLine();
}

for (int i = list.Count - 1; i >= 0; i--)   // safe removal
    if (list[i] < 0) list.RemoveAt(i);

for (;;) { if (Done()) break; }         // infinite with exit

Code Explained

int i = 0 — initializer, runs once
i < 5 — checked before every pass
i++ / i -= 3 — step after every pass
i, j — two variables moving toward each other
Nested — inner loop runs fully for each outer pass
Backwards removal — indexes stay valid

⚠ Common Mistakes

  • Off-by-one with <= — for (i = 0; i <= arr.Length; i++) reads past the end
  • Removing items while counting up — elements shift and get skipped; iterate backwards
  • Modifying the loop variable in the body — makes the loop hard to reason about

✓ Tips & Best Practices

  • Cache Count only if it's expensive; .Length on arrays is free
  • Use Enumerable.Range(0, n) with LINQ for functional style
  • Use Parallel.For only for CPU-heavy, independent iterations

Quick Summary

  • for (init; cond; step) — counted loop
  • Reverse loops — i-- from Length - 1
  • Multiple variables — i++, j--
  • for (;;) — infinite loop
