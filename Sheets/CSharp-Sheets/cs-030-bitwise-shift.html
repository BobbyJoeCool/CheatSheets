Bitwise & Shift Operators

& · | · ^ · ~ · << · >> · >>> · BitOperations

Working with Bits

Bitwise operators act on each bit of an integer: & keeps bits set in both, | in either, ^ in exactly one, and ~ flips all bits. Shifts move bits left (<<, multiply by 2ⁿ) or right (>>, divide by 2ⁿ keeping the sign). C# 11 added >>> for an unsigned right shift that fills with zeros.

Key Facts

  • Work on int, uint, long, ulong (smaller types promote)
  • ~x equals -x - 1 for signed ints
  • Shift counts are masked: 1 << 33 == 1 << 1 for int
  • Convert.ToString(x, 2) prints binary

Worked Example: 12 and 10

int a = 0b1100;   // 12
int b = 0b1010;   // 10

Console.WriteLine(a & b);    //  8  → 1000
Console.WriteLine(a | b);    // 14  → 1110
Console.WriteLine(a ^ b);    //  6  → 0110
Console.WriteLine(~a);       // -13
Console.WriteLine(a << 2);   // 48  → 110000
Console.WriteLine(a >> 2);   //  3  → 11
Console.WriteLine(-16 >> 2); // -4  (sign kept)
Console.WriteLine(-16 >>> 2);// 1073741820 (zero-filled)

Console.WriteLine(Convert.ToString(a, 2));      // 1100
Console.WriteLine(int.PopCount(a));             // 2 (set bits)
Console.WriteLine(BitOperations.IsPow2(64));    // True

int flags = 0;
flags |= 1 << 3;                   // set bit 3
bool on = (flags & (1 << 3)) != 0; // test bit 3 → True
flags &= ~(1 << 3);                // clear bit 3

Code Explained

& — AND: mask bits
| — OR: set bits
^ — XOR: toggle bits
~ — NOT: invert all bits
>> vs >>> — sign-fill vs zero-fill
1 << n — a mask with only bit n set

⚠ Common Mistakes

  • Forgetting parentheses: x & 1 == 0 parses as x & (1 == 0) — a compile error; write (x & 1) == 0
  • Expecting >> to zero-fill negative numbers — use >>> or an unsigned type
  • Shifting by 32+ on an int — the count wraps; use long for wider masks

✓ Tips & Best Practices

  • Prefer [Flags] enums over raw bit masks for readability
  • Use BitOperations / int.PopCount instead of hand-written bit loops
  • Write masks in binary literals: 0b_0000_1000

Quick Summary

  • & | ^ ~ — AND, OR, XOR, NOT
  • << >> — shift (×2ⁿ, ÷2ⁿ)
  • >>> — unsigned right shift (C# 11)
  • int.PopCount — count set bits
