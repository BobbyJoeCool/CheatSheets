Variables & Constants

var · explicit types · const · readonly · definite assignment · default · naming conventions

Declaring Variables

C# is statically typed: every variable has a type fixed at compile time. You can write the type explicitly or let the compiler infer it with var — the variable is still strongly typed. const declares a compile-time constant; readonly fields can be set once, in a declaration or constructor.

Key Facts

  • Locals must be definitely assigned before use
  • var needs an initializer and can't be null alone
  • const works only with primitives, string, enums, null
  • Use @ to name a variable after a keyword: @class

Variables in Practice

int count = 10;                 // explicit type
var total = 19.99m;             // inferred: decimal
string? note = null;            // nullable reference
int a = 1, b = 2;               // several at once
int x = default;                // 0
DateTime start = new(2026, 1, 1); // target-typed new

const double Pi = 3.14159;      // compile-time constant
const string Greeting = "Hi";

class Config
{
    public readonly string Path;       // set once
    public static readonly DateTime Loaded = DateTime.Now;
    public Config(string path) => Path = path;
}

int y;
// Console.WriteLine(y);        // CS0165: unassigned local

Code Explained

var — type inferred from the right side; still static
default — zero value for the target type
new(…) — type taken from the declaration
const — baked into callers at compile time
readonly — assigned in field initializer or constructor only
static readonly — runtime value, set once per type

⚠ Common Mistakes

  • var x = null; — error CS0815; the compiler can't infer a type from null
  • Using public const for values that may change — other assemblies keep the old value until rebuilt
  • Thinking readonly makes an object immutable — readonly List<T> can still be modified

✓ Tips & Best Practices

  • Use var when the type is obvious from the right-hand side
  • Prefer static readonly over public const for shared values
  • Declare variables in the smallest scope that needs them

Quick Summary

  • var — inferred, still strongly typed
  • const — compile-time constant
  • readonly — assign once at run time
  • default — zero value of a type
