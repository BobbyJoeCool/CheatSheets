Dictionary Patterns

Real code uses dictionaries for counting, grouping and caching. Helpers like GetValueOrDefault and TryAdd remove boilerplate, and CollectionsMarshal.GetValueRefOrAddDefault updates a value with a single hash lookup. Choose SortedDictionary for key order and OrderedDictionary<K,V> (.NET 9) for insertion order with index access.

Key Facts

  • GetValueOrDefault is an extension on IReadOnlyDictionary
  • TryAdd returns false instead of throwing
  • ToDictionary throws on duplicate keys
  • Read-heavy, never-changing maps → FrozenDictionary

Counting, Grouping, Fast Updates

string[] words = ["a", "b", "a", "c", "a"];

var counts = new Dictionary<string, int>();               // counting
foreach (var w in words)
    counts[w] = counts.GetValueOrDefault(w) + 1;           // a:3 b:1 c:1

foreach (var w in words)                                   // one lookup
    CollectionsMarshal.GetValueRefOrAddDefault(counts, w, out _)++;

var byLen = new Dictionary<int, List<string>>();           // grouping
foreach (var w in new[] { "hi", "yo", "hey" })
{
    if (!byLen.TryGetValue(w.Length, out var list))
        byLen[w.Length] = list = [];
    list.Add(w);                                           // 2:[hi, yo] 3:[hey]
}

bool added = counts.TryAdd("a", 99);                       // False
var ordered = new OrderedDictionary<string, int> { ["x"] = 1, ["y"] = 2 };
Console.WriteLine(ordered.GetAt(1));                       // [y, 2]

Code Explained

GetValueOrDefault(k) + 1 — simple counter
GetValueRefOrAddDefault(...)++ — update by ref, single lookup
TryGetValue + add — classic grouping
TryAdd — insert only if absent
OrderedDictionary.GetAt(i) — index access (.NET 9)

⚠ Common Mistakes

  • Using ToDictionary when keys may repeat — throws; use GroupBy or ToLookup
  • Modifying a dictionary while enumerating it — throws; iterate Keys.ToList()
  • Sharing a plain Dictionary across threads with writes — corrupts state; use ConcurrentDictionary

✓ Tips & Best Practices

  • Use CountBy / AggregateBy (.NET 9) instead of manual counting loops
  • Use FrozenDictionary for lookup tables built once at startup
  • Use TryAdd for "first one wins" semantics
