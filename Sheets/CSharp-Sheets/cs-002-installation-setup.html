Installing the .NET SDK

SDK vs runtime · dotnet --info · global.json · Visual Studio · VS Code C# Dev Kit · Rider

SDK vs Runtime

To write C# you install the .NET SDK, which includes the compiler, the dotnet CLI, templates and every runtime. To only run apps, a machine needs just the runtime (or nothing at all for self-contained apps). Several SDKs can sit side by side; global.json pins which one a folder uses.

Key Facts

  • Download: dotnet.microsoft.com/download
  • SDK version ≠ runtime version (SDK 10.0.1xx → runtime 10.0)
  • SDKs install side by side; newest is used by default
  • Editors: Visual Studio, VS Code + C# Dev Kit, JetBrains Rider

Install & Verify

# macOS (Homebrew)
brew install --cask dotnet-sdk

# Windows
winget install Microsoft.DotNet.SDK.10

# Linux (Ubuntu)
sudo apt-get install -y dotnet-sdk-10.0

# Any OS: official install script
./dotnet-install.sh --channel 10.0

dotnet --version          # 10.0.100
dotnet --list-sdks        # every installed SDK
dotnet --list-runtimes    # every installed runtime
dotnet --info             # full environment report

Code Explained

--version — SDK that this folder will use
--list-sdks — all SDKs with install paths
--list-runtimes — ASP.NET Core / .NET / Desktop runtimes
--info — OS, RID, SDKs and runtimes in one report
dotnet-install.sh — no admin rights; good for CI

Pin an SDK — global.json

{
  "sdk": {
    "version": "10.0.100",
    "rollForward": "latestFeature"
  }
}

⚠ Common Mistakes

  • Installing only the runtime, then wondering why dotnet new is missing — you need the SDK
  • Forgetting a global.json pins an old SDK — dotnet --version shows what's active
  • Installing VS Code's old C# extension only — add C# Dev Kit for project and test support

✓ Tips & Best Practices

  • Commit global.json so the team and CI use the same SDK
  • Use rollForward: latestFeature to accept SDK patch updates
  • Run dotnet --info first when reporting build problems

Quick Summary

  • .NET SDK — compiler, CLI, templates, runtimes
  • dotnet --list-sdks — see what's installed
  • global.json — pin the SDK per folder
  • C# Dev Kit — VS Code support for projects and tests
