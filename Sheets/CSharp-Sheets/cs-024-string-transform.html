String Methods — Transform

ToUpper · ToLower · Trim · Replace · Split · string.Join · PadLeft · Substring

Changing Text

Transform methods build and return a new string: case changes, trimming, replacing, splitting into arrays, joining collections, and padding. Combine them in chains, and remember to assign the result. Split and Join are the workhorses for parsing and producing delimited data.

Key Facts

  • Trim() removes whitespace; Trim('/') removes chars
  • Split options: RemoveEmptyEntries, TrimEntries
  • Substring(start, length) — length, not end index
  • Use ToUpperInvariant for culture-free case changes

Transformations

string s = "  Hello, World  ";

Console.WriteLine(s.Trim());                 // "Hello, World"
Console.WriteLine(s.TrimStart());            // "Hello, World  "
Console.WriteLine("//a//".Trim('/'));        // "a"
Console.WriteLine("abc".ToUpper());          // "ABC"
Console.WriteLine("cat".Replace('c', 'b'));  // "bat"
Console.WriteLine("a-b-c".Replace("-", "")); // "abc"

string[] parts = "a, b,,c".Split(',',
    StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);
// ["a", "b", "c"]
Console.WriteLine(string.Join(" | ", parts));   // a | b | c

Console.WriteLine("7".PadLeft(3, '0'));      // "007"
Console.WriteLine("ab".PadRight(4) + "|");   // "ab  |"
Console.WriteLine("Hello".Substring(1, 3));  // "ell"
Console.WriteLine("Hello".Insert(5, "!"));   // "Hello!"
Console.WriteLine("Hello".Remove(1, 3));     // "Ho"

Code Explained

Trim / TrimStart / TrimEnd — strip edges
Replace — all occurrences, char or string
Split(sep, options) — parse delimited text
string.Join(sep, items) — the reverse of Split
PadLeft(width, ch) — fixed-width output
Insert / Remove — edit by position

Chaining

string slug = "  My First Post!  "
    .Trim()
    .ToLowerInvariant()
    .Replace(" ", "-")
    .Replace("!", "");      // "my-first-post"

⚠ Common Mistakes

  • s.Replace("a", "b"); without assignment — the original is unchanged
  • Substring(2, 5) read as "from 2 to 5" — the second argument is a length
  • Splitting CSV with Split(',') — quoted fields with commas break; use a CSV library

✓ Tips & Best Practices

  • Use s[start..end] ranges as a clearer alternative to Substring
  • Pass TrimEntries to Split instead of trimming each item
  • Use ToUpperInvariant for keys; ToUpper for UI text

Quick Summary

  • Trim — strip whitespace or chars
  • Replace — swap text
  • Split / Join — parse and build lists
  • PadLeft / PadRight — fixed width
