Delegates

delegate · Func<> · Action<> · Predicate<T> · method groups · multicast · Invoke

Methods as Values

A delegate is a type-safe reference to a method: a variable you can store, pass and invoke. The BCL provides generic delegates for almost every need — Func<…, TResult> returns a value, Action<…> returns void, Predicate<T> returns bool. Delegates can point to static methods, instance methods or lambdas.

Key Facts

  • Func<int, string> = takes int, returns string (last type is the result)
  • Method group: list.ForEach(Console.WriteLine)
  • Delegates are multicast: += adds targets
  • Invoking a null delegate throws — use ?.Invoke

Delegates

delegate int MathOp(int a, int b);         // custom delegate type

static int Add(int a, int b) => a + b;
MathOp op = Add;                           // method group
Console.WriteLine(op(2, 3));               // 5

Func<int, int, int> mul = (a, b) => a * b;
Func<string, int> len = s => s.Length;
Action<string> log = msg => Console.WriteLine($"[log] {msg}");
Predicate<int> isEven = n => n % 2 == 0;

Console.WriteLine(mul(4, 5));              // 20
log("started");                            // [log] started
Console.WriteLine(isEven(7));              // False

Action notify = () => Console.Write("A");
notify += () => Console.Write("B");        // multicast
notify();                                  // AB
Func<int>? maybe = null;
int? r = maybe?.Invoke();                  // null, no exception

Code Explained

delegate — declare your own signature (rarely needed)
Method group — assign a method by name
Func<T1, T2, TResult> — last type parameter is the return
Action<T> — returns void
+= — chain several methods
?.Invoke() — safe call when possibly null

Built-in Delegates

TypeSignature
Action() → void
Action<T1, T2>(T1, T2) → void
Func<TResult>() → TResult
Func<T, TResult>(T) → TResult
Predicate<T>(T) → bool
Comparison<T>(T, T) → int

⚠ Common Mistakes

  • Declaring custom delegate types when Func/Action already fit
  • Calling a delegate field without a null check — NullReferenceException
  • Expecting a multicast Func to return all results — you only get the last target's value

✓ Tips & Best Practices

  • Accept Func<…> parameters to make methods configurable
  • Pass method groups (Select(int.Parse)) when signatures already match
  • Use Comparison<T> lambdas for one-off sorts

Quick Summary

  • Delegate — reference to a method
  • Func — returns a value; Action — void
  • Predicate<T> — bool test
  • += — multicast
