Logs, Queries and Traces

CloudWatch Logs stores events in log groups (one per app / function) and streams. Set retention on every group: the default is to keep logs forever. Logs Insights queries logs with a pipe-based language; metric filters turn patterns into metrics. Traces flow through X-Ray or the AWS Distro for OpenTelemetry (ADOT) into CloudWatch Application Signals.

Key Points

  • Lambda, ECS (awslogs) and API Gateway write to log groups automatically
  • Structured JSON logs make fields queryable
  • Subscription filters stream logs to Lambda, Firehose or OpenSearch
  • Infrequent Access log class cuts ingestion cost for rarely queried logs

Retention, Tail, Query, Metric Filter

aws logs put-retention-policy --log-group-name /aws/lambda/orders \
    --retention-in-days 30
aws logs tail /aws/lambda/orders --follow --since 10m --format short
aws logs put-metric-filter --log-group-name /ecs/shop-api \
    --filter-name errors --filter-pattern '{ $.level = "error" }' \
    --metric-transformations \
    metricName=ApiErrors,metricNamespace=Shop,metricValue=1
aws logs start-query --log-group-names /ecs/shop-api \
    --start-time $(date -d '-1 hour' +%s) --end-time $(date +%s) \
    --query-string file://errors.query

Logs Insights Query

fields @timestamp, level, path, duration_ms
| filter level = "error" or duration_ms > 1000
| stats count() as n, pct(duration_ms, 95) as p95 by path
| sort p95 desc
| limit 20

Tracing With OpenTelemetry (Python)

from opentelemetry import trace
tracer = trace.get_tracer("shop")
with tracer.start_as_current_span("checkout") as span:
    span.set_attribute("cart.items", 3)     # exported via ADOT / CW agent

Code Explained

30-day retention stops logs from accumulating forever
tail --follow streams new events like tail -f
The JSON metric filter counts error-level log lines
The query finds slow or failing paths with p95 latency

Cost Check

  • Ingestion per GB is the main cost; Infrequent Access class is cheaper
  • Storage per GB-month after ingestion
  • Logs Insights bills per GB scanned: narrow time ranges and groups

Limits & Quotas

  • Default retention: never expire (set it)
  • Logs Insights queries time out after 60 minutes
  • PutLogEvents batches up to 1 MB / 10,000 events

Do & Don't

  • Do Set retention on every log group (enforce with Config / IaC)
  • Do Log JSON with request and trace IDs
  • Don’t Log secrets or full request bodies with PII
  • Don’t Query 30 days of all log groups for a one-hour incident

Local Testing

  • OpenTelemetry Collector + Jaeger in Docker for local traces
  • sam local prints Lambda logs to the terminal
  • Test Insights queries on a small time window first

Production Checklist

  • Retention, log class and encryption set per group
  • Metric filters / alarms for error patterns
  • Tracing across services with ADOT
