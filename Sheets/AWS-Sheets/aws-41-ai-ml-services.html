Prebuilt AI and Custom ML

AWS offers task-specific AI APIs: Rekognition (images and video), Textract (forms, tables, documents), Transcribe (speech-to-text), Polly (text-to-speech), Comprehend (entities, sentiment, PII) and Translate. SageMaker AI trains, tunes and hosts custom models. Amazon Q Developer is the coding assistant.

Key Points

  • Prebuilt APIs need no training data
  • Async APIs (Textract, Transcribe) work on files in S3
  • SageMaker endpoints bill while running: delete idle ones
  • Comprehend detects and redacts PII

Textract, Comprehend, Transcribe

import boto3
tx = boto3.client("textract")
doc = tx.analyze_expense(Document={"S3Object": {"Bucket": "acme-docs",
                                                "Name": "invoice.pdf"}})
for f in doc["ExpenseDocuments"][0]["SummaryFields"]:
    print(f["Type"]["Text"], "=", f.get("ValueDetection", {}).get("Text"))

cp = boto3.client("comprehend")
pii = cp.detect_pii_entities(Text="Call Ada at 555-0100 about order 42.",
                             LanguageCode="en")
print([e["Type"] for e in pii["Entities"]])   # ['NAME', 'PHONE']

ts = boto3.client("transcribe")
ts.start_transcription_job(TranscriptionJobName="call-42",
    Media={"MediaFileUri": "s3://acme-audio/call-42.mp3"},
    LanguageCode="en-US", OutputBucketName="acme-transcripts")

Rekognition and SageMaker

aws rekognition detect-labels \
    --image 'S3Object={Bucket=acme-media,Name=cat.jpg}' \
    --max-labels 5 --query "Labels[].[Name,Confidence]"
aws sagemaker list-endpoints --query "Endpoints[].[EndpointName,EndpointStatus]"

Code Explained

analyze_expense extracts invoice totals and vendor fields
Comprehend returns PII entity types and offsets
Transcribe runs as a job and writes results to S3
Rekognition labels images straight from S3

Cost Check

  • Per image / page / minute / character, most with free tiers for the first year
  • SageMaker: instance hours for training, endpoints and notebooks
  • Serverless and async inference avoid paying for idle endpoints

Do & Don't

  • Do Try prebuilt APIs before training custom models
  • Do Use async / batch APIs for large volumes
  • Don’t Leave SageMaker endpoints and notebooks running idle
  • Don’t Process personal data without checking retention and opt-out settings

Local Testing

  • Mock clients with botocore Stubber in tests
  • Test with small sample files in a dev account
  • SageMaker local mode runs training containers on your machine

Production Checklist

  • IAM scoped per service and bucket
  • Retries for throttling; quotas monitored
  • Idle SageMaker resources cleaned up automatically
