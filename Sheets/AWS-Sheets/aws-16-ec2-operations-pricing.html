Running and Paying for EC2

Instances can be stopped (EBS kept, compute not billed) or terminated (gone; root volume deleted by default). EBS volumes and snapshots hold data. Pricing options: On-Demand; Savings Plans (1 or 3 year spend commitment, flexible); Reserved Instances (specific type); and Spot (spare capacity at a deep discount with a 2-minute interruption notice).

Key Points

  • Snapshots are incremental and stored in S3 (managed by AWS)
  • Termination protection guards important instances
  • Spot works best for stateless, fault-tolerant work
  • Compute Savings Plans also cover Fargate and Lambda

Operate and Save

aws ec2 stop-instances --instance-ids i-0abc1234       # compute billing stops
aws ec2 start-instances --instance-ids i-0abc1234
aws ec2 modify-instance-attribute --instance-id i-0abc1234 \
    --disable-api-termination

aws ec2 create-volume --availability-zone us-east-1a --size 100 \
    --volume-type gp3 --iops 6000 --throughput 250 --encrypted
aws ec2 attach-volume --volume-id vol-0abc --instance-id i-0abc1234 \
    --device /dev/sdf
aws ec2 create-snapshot --volume-id vol-0abc --description nightly
aws dlm create-lifecycle-policy --execution-role-arn <role-arn> \
    --description daily --state ENABLED --policy-details file://dlm.json

# Spot instance
aws ec2 run-instances --image-id $AMI --instance-type c7g.large \
    --instance-market-options MarketType=spot

aws ec2 describe-volumes --filters Name=status,Values=available \
    --query "Volumes[].[VolumeId,Size]" --output table     # unattached
aws ce get-savings-plans-purchase-recommendation \
    --savings-plans-type COMPUTE_SP --term-in-years ONE_YEAR \
    --payment-option NO_UPFRONT --lookback-period-in-days THIRTY_DAYS

Code Explained

Stopping keeps EBS volumes; terminating usually deletes the root volume
gp3 sets IOPS and throughput independently of size
Data Lifecycle Manager automates snapshot schedules
Cost Explorer suggests a Savings Plan from recent usage

Azure / GCP Equivalent

  • Azure deallocate, managed disks, Spot VMs, Reservations / savings plan (az-16)
  • GCP Persistent Disk / Hyperdisk, Spot VMs, committed use discounts (gcp-16)

Cost Check

  • Savings Plans: up to ~72% off vs On-Demand
  • Spot: up to ~90% off, interruptible
  • Unattached EBS volumes and idle Elastic IPs keep billing

Do & Don't

  • Do Use gp3 instead of gp2
  • Do Automate snapshots with DLM or AWS Backup
  • Don’t Leave detached volumes and old snapshots around
  • Don’t Buy commitments before rightsizing with Compute Optimizer

Local Testing

  • Price options in the AWS Pricing Calculator
  • Test Spot interruption handling with Fault Injection Service
  • Restore a snapshot into a scratch instance to verify backups

Production Checklist

  • Backups / snapshot policies on all data volumes
  • Savings Plans cover the steady baseline
  • Alerts on idle and unattached resources
