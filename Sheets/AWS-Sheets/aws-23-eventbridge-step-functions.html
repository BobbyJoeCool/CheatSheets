EventBridge & Step Functions

event buses · rules & event patterns · EventBridge Scheduler · Step Functions state machines · Amazon States Language · Standard vs Express

Events and Workflows

EventBridge routes events from AWS services, SaaS partners and your apps to targets by matching event patterns on rules; Scheduler runs one-time or recurring invocations. Step Functions orchestrates multi-step workflows defined in the Amazon States Language (ASL): tasks, choices, retries, parallel branches, maps and waits, with direct integrations to 200+ services.

Key Points

  • The default bus receives AWS service events
  • Archive and replay events for recovery or testing
  • Standard workflows: durable, up to a year; Express: high-volume, up to 5 minutes
  • Retries and catches are declared per state

Rule, Schedule, State Machine

aws events put-rule --name order-created --event-bus-name shop \
    --event-pattern '{"source":["acme.orders"],"detail-type":["OrderCreated"],
      "detail":{"total":[{"numeric":[">",100]}]}}'
aws events put-targets --rule order-created --event-bus-name shop \
    --targets Id=sfn,Arn=$SFN_ARN,RoleArn=$EVENTS_ROLE
aws events put-events --entries file://order-created.json

aws scheduler create-schedule --name nightly-report \
    --schedule-expression "cron(0 2 * * ? *)" --flexible-time-window Mode=OFF \
    --target "{\"Arn\":\"$FN_ARN\",\"RoleArn\":\"$SCHED_ROLE\"}"

Amazon States Language (excerpt)

{ "StartAt": "Charge",
  "States": {
    "Charge": { "Type": "Task", "Resource": "arn:aws:states:::lambda:invoke",
      "Parameters": { "FunctionName": "charge", "Payload.$": "$" },
      "Retry": [{ "ErrorEquals": ["States.TaskFailed"], "MaxAttempts": 3,
                  "BackoffRate": 2 }],
      "Next": "Ship" },
    "Ship": { "Type": "Task", "End": true,
      "Resource": "arn:aws:states:::sqs:sendMessage",
      "Parameters": { "QueueUrl": "${ShipQueueUrl}", "MessageBody.$": "$" } }
  } }

Code Explained

The pattern matches large orders only (numeric filter)
EventBridge needs a role to start the state machine
Scheduler cron has six fields including year
Step Functions retries the charge step with backoff, then queues shipping

Cost Check

  • EventBridge: per million events published (AWS service events on the default bus are free)
  • Step Functions Standard: per state transition; Express: per request + duration
  • Scheduler has a large monthly free tier

Do & Don't

  • Do Use a custom bus per domain with schemas
  • Do Put retries and catches in the state machine, not the code
  • Don’t Build long synchronous Lambda chains instead of a workflow
  • Don’t Match events too broadly and trigger targets by accident

Local Testing

  • Step Functions Local (Docker) runs ASL locally
  • EventBridge test-event-pattern checks patterns offline
  • Workflow Studio designs state machines visually

Production Checklist

  • DLQs on rule targets; archives for replay
  • Alarms on failed executions and throttled targets
  • State machines defined in IaC with versions / aliases
