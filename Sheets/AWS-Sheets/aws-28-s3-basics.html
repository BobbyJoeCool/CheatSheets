Object Storage on AWS

Amazon S3 stores objects under keys in buckets. Bucket names are globally unique; a bucket lives in one Region. The high-level aws s3 commands copy and sync files (with automatic multipart upload); aws s3api exposes every API. Storage classes trade storage price for retrieval price and speed, and Intelligent-Tiering moves objects automatically.

Key Points

  • "Folders" are key prefixes (2026/11/photo.jpg)
  • Strong read-after-write consistency for all operations
  • New buckets block public access and use bucket-owner-enforced ownership by default
  • S3 Express One Zone offers single-digit millisecond access in one AZ

Security Check

  • Keep Block Public Access on at account and bucket level
  • Require TLS with a bucket policy (aws:SecureTransport)
  • Use SSE-KMS with a customer managed key for sensitive data

Limits & Quotas

  • Objects up to 5 TB; single PUT up to 5 GB (use multipart beyond)
  • Buckets per account: 10,000 by default (adjustable)
  • At least 3,500 writes / 5,500 reads per second per prefix

Everyday S3

aws s3 mb s3://acme-media-prod --region us-east-1
aws s3 cp photo.jpg s3://acme-media-prod/2026/11/photo.jpg
aws s3 cp ./images s3://acme-media-prod/images/ --recursive \
    --exclude "*" --include "*.jpg"
aws s3 sync ./site s3://acme-site --delete
aws s3 ls s3://acme-media-prod/2026/ --recursive --human-readable --summarize
aws s3 rm s3://acme-media-prod/tmp/ --recursive

aws s3 cp backup.tar s3://acme-backup/ --storage-class GLACIER_IR
aws s3api head-object --bucket acme-media-prod --key 2026/11/photo.jpg
aws s3api put-object-tagging --bucket acme-media-prod \
    --key 2026/11/photo.jpg --tagging 'TagSet=[{Key=team,Value=web}]'
aws s3api list-objects-v2 --bucket acme-media-prod --prefix 2026/ \
    --query "Contents[?Size>\`1000000\`].Key"

Python

import boto3
s3 = boto3.client("s3")
s3.upload_file("big.zip", "acme-backup", "2026/big.zip")   # multipart if large
obj = s3.get_object(Bucket="acme-media-prod", Key="2026/11/photo.jpg")
data = obj["Body"].read()

Code Explained

cp --recursive with include / exclude filters copies by pattern
sync --delete mirrors a folder exactly
GLACIER_IR keeps millisecond access at archive-like storage prices
JMESPath filters objects larger than 1 MB

Azure / GCP Equivalent

  • Azure Blob Storage: storage accounts, containers, tiers (az-28)
  • GCP Cloud Storage: buckets, classes, Autoclass (gcp-28)

Cost Check

  • Storage per GB-month by class, plus requests, retrieval and egress
  • Minimum storage durations and retrieval fees on IA / Glacier classes
  • Incomplete multipart uploads bill until aborted (add a lifecycle rule)

Do & Don't

  • Do Use prefixes that group data by lifecycle (logs/, tmp/)
  • Do Add a lifecycle rule to abort incomplete multipart uploads
  • Don’t Make buckets public to serve websites (use CloudFront + OAC)
  • Don’t List huge buckets repeatedly (use S3 Inventory)

Local Testing

  • LocalStack and MinIO emulate S3 APIs
  • moto mocks S3 in Python tests
  • S3 Mountpoint mounts a bucket as a file system for experiments

Production Checklist

  • Block Public Access, TLS-only policy, SSE-KMS where needed
  • Versioning and lifecycle rules (sheet 29)
  • Server access logs or CloudTrail data events for audit
