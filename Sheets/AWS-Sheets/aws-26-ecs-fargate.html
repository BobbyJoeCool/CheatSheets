ECS & Fargate

clusters · task definitions · services · Fargate vs EC2 launch type · awsvpc networking · task roles · ECS Exec

Containers the AWS Way

Amazon ECS runs containers from task definitions (image, CPU, memory, ports, env, logging, roles). A service keeps a desired number of tasks running behind a load balancer with rolling or blue/green deploys. Fargate runs tasks without servers; the EC2 launch type uses your instances. Each task gets its own ENI (awsvpc), a task role for app permissions and an execution role for pulling images and logs.

Key Points

  • Task role = what the app can do; execution role = what ECS needs to start it
  • Secrets come from Secrets Manager / Parameter Store via secrets
  • Capacity providers mix Fargate and Fargate Spot
  • ECS Exec opens a shell in a running container

Cluster, Service, Exec

aws ecs create-cluster --cluster-name shop \
    --capacity-providers FARGATE FARGATE_SPOT
aws ecs register-task-definition --cli-input-json file://taskdef.json
aws ecs create-service --cluster shop --service-name api \
    --task-definition shop-api --desired-count 2 --launch-type FARGATE \
    --network-configuration file://awsvpc.json \
    --load-balancers targetGroupArn=$TG,containerName=api,containerPort=8080 \
    --enable-execute-command
aws ecs execute-command --cluster shop --task <task-id> --container api \
    --interactive --command "/bin/sh"

Code Explained

Fargate tasks declare CPU and memory at the task level
ARM64 runs on Graviton for lower cost
The secrets block injects the value at start using the execution role
ECS Exec needs --enable-execute-command and SSM permissions

Cost Check

  • Fargate: per vCPU-second and GB-second while tasks run
  • Fargate Spot: up to ~70% off, interruptible
  • ECS control plane is free; EC2 launch type pays for instances

Security Check

  • Separate task and execution roles with least privilege
  • Run tasks in private subnets without public IPs
  • Read-only root file system and non-root user in task definitions

Limits & Quotas

  • Fargate On-Demand vCPU quota per Region (adjustable)
  • Fargate task size up to 16 vCPU / 120 GB
  • 10 containers per task definition

Do & Don't

  • Do Enable the deployment circuit breaker with rollback
  • Do Use Fargate Spot for workers and dev
  • Don’t Put secrets in plain environment variables
  • Don’t Give the task role the execution role's permissions (or vice versa) without need

Local Testing

  • docker run the same image with the same env
  • Docker Compose mimics multi-container tasks
  • AWS Copilot CLI and ecs-cli alternatives scaffold services

Production Checklist

  • Private subnets, circuit breaker, health checks
  • Container Insights and log retention set
  • Autoscaling on CPU / requests per target
