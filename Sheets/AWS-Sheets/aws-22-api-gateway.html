API Gateway

HTTP API vs REST API · routes & integrations · stages · Lambda / JWT authorizers · CORS · throttling

Managed APIs in Front of Your Code

API Gateway exposes HTTPS APIs backed by Lambda, HTTP endpoints or AWS services. HTTP APIs are cheaper, faster and simpler, with built-in JWT authorizers and CORS. REST APIs add request validation, usage plans with API keys, caching, WAF and private endpoints. Stages deploy versions; throttling protects back ends.

Key Points

  • WebSocket APIs handle two-way connections
  • Custom domains map to stages with ACM certificates
  • Usage plans + API keys meter clients (keys are not authentication)
  • Default endpoint can be disabled when using a custom domain

Security Check

  • Authenticate with JWT (Cognito / OIDC) or IAM authorizers
  • Attach AWS WAF to REST APIs (or front HTTP APIs with CloudFront + WAF)
  • Disable the default execute-api endpoint when a custom domain is used

HTTP API With Lambda and JWT Auth

API=$(aws apigatewayv2 create-api --name shop --protocol-type HTTP \
  --cors-configuration AllowOrigins=https://shop.acme.com,AllowMethods=POST \
  --query ApiId --output text)
INT=$(aws apigatewayv2 create-integration --api-id $API \
  --integration-type AWS_PROXY --integration-uri $FN_ARN \
  --payload-format-version 2.0 --query IntegrationId --output text)
AUTH=$(aws apigatewayv2 create-authorizer --api-id $API --name jwt \
  --authorizer-type JWT --identity-source '$request.header.Authorization' \
  --jwt-configuration Audience=shop-api,Issuer=$COGNITO_ISSUER_URL \
  --query AuthorizerId --output text)
aws apigatewayv2 create-route --api-id $API --route-key "POST /orders" \
    --target integrations/$INT --authorization-type JWT --authorizer-id $AUTH
aws apigatewayv2 create-stage --api-id $API --stage-name '$default' \
    --auto-deploy \
    --default-route-settings ThrottlingBurstLimit=100,ThrottlingRateLimit=50
aws lambda add-permission --function-name orders --statement-id apigw \
    --action lambda:InvokeFunction --principal apigateway.amazonaws.com \
    --source-arn "arn:aws:execute-api:us-east-1:111122223333:$API/*"

Code Explained

HTTP APIs set CORS in one flag
Payload format 2.0 is the simpler event shape for Lambda
The JWT authorizer validates Cognito tokens before Lambda runs
Lambda needs a resource policy allowing API Gateway to invoke it

Cost Check

  • HTTP APIs cost much less per million requests than REST APIs
  • REST API caching bills hourly by cache size
  • Throttle to stop runaway clients from running up Lambda costs

Do & Don't

  • Do Start with HTTP APIs unless you need REST features
  • Do Set throttling on every stage
  • Don’t Rely on API keys as authentication
  • Don’t Return stack traces from integrations

Local Testing

  • sam local start-api runs routes against local Lambdas
  • Test JWTs with a local OIDC provider or Cognito test users
  • Validate OpenAPI definitions with Spectral

Production Checklist

  • Authorizer on every non-public route
  • Access logging and throttling configured
  • Custom domain with ACM; default endpoint disabled
