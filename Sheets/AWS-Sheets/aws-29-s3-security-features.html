S3 Security & Features

Block Public Access · bucket policies · presigned URLs · versioning · lifecycle rules · SSE-S3 / SSE-KMS · static website hosting

Protecting and Managing S3 Data

Control access with IAM and bucket policies, keep Block Public Access on, and share single objects with time-limited presigned URLs. Versioning keeps every version of an object; Object Lock adds write-once retention. Lifecycle rules transition and expire objects. Encryption at rest is automatic (SSE-S3); SSE-KMS adds key control and audit.

Key Points

  • ACLs are disabled by default (bucket owner enforced); use policies
  • Presigned URLs carry the signer's permissions until they expire
  • MFA delete and Object Lock protect against destructive deletes
  • Replication (same or cross Region) needs versioning

Security Check

  • Block Public Access at the account level
  • Bucket policy denying non-TLS and wrong-key uploads
  • Versioning + Object Lock or AWS Backup for critical data

Policies, Presigning, Versioning, Lifecycle

aws s3api put-public-access-block --bucket acme-media-prod \
    --public-access-block-configuration BlockPublicAcls=true,\
IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
aws s3api put-bucket-policy --bucket acme-media-prod --policy file://tls.json
aws s3api put-bucket-encryption --bucket acme-media-prod \
    --server-side-encryption-configuration file://sse-kms.json
aws s3api put-bucket-versioning --bucket acme-media-prod \
    --versioning-configuration Status=Enabled
aws s3 presign s3://acme-media-prod/2026/11/photo.jpg --expires-in 900
aws s3api put-bucket-lifecycle-configuration --bucket acme-logs \
    --lifecycle-configuration file://lifecycle.json

lifecycle.json

{ "Rules": [{ "ID": "logs", "Status": "Enabled",
    "Filter": { "Prefix": "logs/" },
    "Transitions": [{ "Days": 30, "StorageClass": "STANDARD_IA" },
                    { "Days": 180, "StorageClass": "GLACIER" }],
    "Expiration": { "Days": 730 },
    "NoncurrentVersionExpiration": { "NoncurrentDays": 30 },
    "AbortIncompleteMultipartUpload": { "DaysAfterInitiation": 7 } }] }

Code Explained

All four Block Public Access switches on
Default SSE-KMS with an S3 Bucket Key cuts KMS request costs
The presigned URL works for 15 minutes
Lifecycle tiers logs, expires old ones, and cleans versions and uploads

Azure / GCP Equivalent

  • Azure Blob data roles, user delegation SAS, versioning, lifecycle (az-29)
  • GCP Uniform access, signed URLs, versioning, lifecycle (gcp-29)

Cost Check

  • Old versions bill as normal storage: expire noncurrent versions
  • S3 Bucket Keys reduce SSE-KMS request charges
  • Lifecycle transitions bill per request; tiny objects may not be worth moving

Do & Don't

  • Do Serve sites through CloudFront with OAC
  • Do Expire noncurrent versions
  • Don’t Hand out long-lived presigned URLs
  • Don’t Disable Block Public Access to fix an access problem

Local Testing

  • LocalStack supports bucket policies and presigning
  • IAM Access Analyzer for S3 flags public or shared buckets
  • Validate lifecycle JSON in a sandbox bucket

Production Checklist

  • Account-level Block Public Access
  • Versioning + replication or Backup for critical buckets
  • Macie or Access Analyzer reviews for sensitive / shared data
