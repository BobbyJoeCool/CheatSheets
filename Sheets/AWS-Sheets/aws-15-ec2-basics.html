Virtual Servers on AWS

An EC2 instance combines an instance type (family, generation, size), an AMI (machine image), EBS volumes, a subnet and security groups. Type names encode the details: m7g.large is general purpose (m), generation 7, Graviton Arm (g), large. User data runs a script at first boot. IMDSv2 protects the metadata service that hands out role credentials.

Key Points

  • Graviton (Arm) types usually give the best price-performance for Linux
  • Get current Amazon Linux AMIs from public SSM parameters
  • Use Session Manager instead of SSH keys where possible
  • Burstable T types earn and spend CPU credits

Security Check

  • Require IMDSv2 (HttpTokens=required) on every instance
  • No public IP and no port 22: use Session Manager
  • Encrypt EBS volumes by default (account setting)

Limits & Quotas

  • On-Demand vCPU quotas per instance family group and Region
  • New accounts start low: check aws service-quotas list-service-quotas --service-code ec2
  • 5 Elastic IPs per Region by default

Launch a Private Graviton Instance

P=/aws/service/ami-amazon-linux-latest
AMI=resolve:ssm:$P/al2023-ami-kernel-default-arm64
aws ec2 run-instances --image-id $AMI --instance-type t4g.small \
    --subnet-id $APP_A --security-group-ids $APP_SG \
    --iam-instance-profile Name=app-instance-profile \
    --metadata-options HttpTokens=required,HttpEndpoint=enabled \
    --user-data file://init.sh --no-associate-public-ip-address \
    --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=web-1}]'

aws ec2 describe-instances --filters Name=tag:Name,Values=web-1 \
    --query "Reservations[].Instances[].[InstanceId,State.Name]"
aws ssm start-session --target i-0abc1234                # shell, no SSH
aws ec2 enable-ebs-encryption-by-default
aws service-quotas get-service-quota --service-code ec2 \
    --quota-code L-1216C47A    # Running On-Demand Standard instances (vCPUs)

init.sh (user data)

#!/bin/bash
dnf install -y nginx && systemctl enable --now nginx

Code Explained

The resolve:ssm: prefix looks up the latest Amazon Linux 2023 Arm AMI
The instance profile gives the instance its IAM role (and Session Manager access)
IMDSv2 required blocks token-less metadata requests
L-1216C47A is the vCPU quota for standard families

Azure / GCP Equivalent

  • Azure Virtual Machines, cloud-init, Bastion (az-15)
  • GCP Compute Engine, startup scripts, OS Login / IAP (gcp-15)

Cost Check

  • Billed per second (Linux) while running, plus EBS and public IPv4
  • Graviton types cost less per hour than comparable x86
  • Stopped instances still pay for EBS volumes and Elastic IPs

Do & Don't

  • Do Bake AMIs with EC2 Image Builder or Packer
  • Do Use launch templates for every instance
  • Don’t Assign public IPs to app servers
  • Don’t Hand-patch long-lived pets

Local Testing

  • Test user data in a local VM or container first
  • LocalStack EC2 emulation for IaC flows (no real VMs)
  • Packer builds and tests AMIs from your laptop

Production Checklist

  • IMDSv2, EBS encryption, no public IPs
  • SSM Agent + Patch Manager baselines
  • Instances in Auto Scaling groups across AZs
