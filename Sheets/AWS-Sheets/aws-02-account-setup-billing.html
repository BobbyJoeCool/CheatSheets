Account Setup & Billing

root user & MFA · IAM Identity Center · AWS Organizations · AWS Budgets & billing alarms · Cost Explorer · tags for cost allocation

Setting Up an Account Safely

A new account starts with a root user that can do anything: lock it with MFA and stop using it. Create an Organization to group accounts into organizational units (OUs) with consolidated billing and service control policies (SCPs). People sign in through IAM Identity Center (SSO). Budgets alert on spend and Cost Explorer shows where it goes.

Key Points

  • Root user only for tasks that require it (account closure, some billing settings)
  • Landing zones: Control Tower sets up accounts, logging and guardrails
  • Cost allocation tags must be activated in Billing to appear in reports
  • Budgets can trigger actions (apply an SCP or IAM policy)

Limits & Quotas

  • New organizations start with a small default account quota (raise in Service Quotas)
  • SCP document size up to 5,120 characters; 5 SCPs per OU / account
  • 50 user tags per resource

Organization, SSO, Budgets

aws organizations create-organization --feature-set ALL
aws organizations create-organizational-unit --parent-id r-ab12 --name Prod
aws organizations create-account --email shop-prod@example.com \
    --account-name shop-prod
aws organizations list-accounts --output table

aws budgets create-budget --account-id 111122223333 \
    --budget file://budget.json \
    --notifications-with-subscribers file://notify.json
# budget.json: {"BudgetName": "monthly", "BudgetType": "COST",
#   "TimeUnit": "MONTHLY", "BudgetLimit": {"Amount": "300", "Unit": "USD"}}
# notify.json: [{"Notification": {"NotificationType": "ACTUAL",
#   "ComparisonOperator": "GREATER_THAN", "Threshold": 80},
#   "Subscribers": [{"SubscriptionType": "EMAIL", "Address": "ops@acme.com"}]}]

aws ce get-cost-and-usage --time-period Start=2026-10-01,End=2026-11-01 \
    --granularity MONTHLY --metrics UnblendedCost \
    --group-by Type=TAG,Key=team

aws service-quotas list-service-quotas --service-code organizations

Code Explained

feature-set ALL enables SCPs and other policy types
New accounts are created inside the organization with their own root
The budget emails at 80% of actual monthly spend
Cost Explorer groups spend by the activated team tag

Azure / GCP Equivalent

  • Azure management groups, subscriptions, Cost Management budgets (az-02)
  • GCP organization, folders, projects, billing budgets (gcp-02)

Cost Check

  • Organizations, SCPs and Identity Center are free
  • The first two budgets are free; more cost a little per day
  • Cost Explorer UI is free; its API bills per request

Do & Don't

  • Do Enable MFA on root and store its credentials offline
  • Do Use Identity Center for all human access
  • Don’t Run workloads in the management account
  • Don’t Create IAM users with long-lived keys for people

Local Testing

  • Practice in a sandbox account inside your organization
  • Price designs with the AWS Pricing Calculator
  • Infracost estimates CloudFormation / Terraform changes

Production Checklist

  • Root MFA, alternate contacts and billing alerts set
  • SCP guardrails on OUs (deny leaving org, disabling CloudTrail)
  • Cost allocation tags activated and enforced
