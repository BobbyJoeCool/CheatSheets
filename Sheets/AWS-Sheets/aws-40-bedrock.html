Generative AI on AWS

Amazon Bedrock offers foundation models from Anthropic, Amazon (Nova), Meta, Mistral, Cohere and others behind one API. The Converse API gives a uniform chat interface with tools and streaming across models; InvokeModel sends model-specific payloads. Cross-Region inference profiles spread load. Knowledge Bases add managed RAG, Agents add tool use, and Guardrails filter content and PII.

Key Points

  • Serverless models are enabled automatically on first use (some providers need a one-time use-case form)
  • Model IDs or inference profile IDs select the model
  • Data is not used to train the models
  • Batch inference costs less for offline jobs

Converse API (Python)

import boto3
brt = boto3.client("bedrock-runtime", region_name="us-east-1")
MODEL = "us.amazon.nova-lite-v1:0"        # inference profile ID (example)

resp = brt.converse(
    modelId=MODEL,
    system=[{"text": "You are a concise support assistant."}],
    messages=[{"role": "user", "content": [
        {"text": "Summarize our return policy in 3 bullets."}]}],
    inferenceConfig={"maxTokens": 300, "temperature": 0.2})
print(resp["output"]["message"]["content"][0]["text"])
print(resp["usage"])                      # input / output tokens

stream = brt.converse_stream(modelId=MODEL, messages=[{"role": "user",
    "content": [{"text": "Write a haiku about queues."}]}])
for ev in stream["stream"]:
    if "contentBlockDelta" in ev:
        print(ev["contentBlockDelta"]["delta"]["text"], end="")

CLI

aws bedrock list-foundation-models --by-output-modality TEXT \
    --query "modelSummaries[].modelId" --output text
aws bedrock list-inference-profiles \
    --query "inferenceProfileSummaries[].inferenceProfileId"
aws bedrock create-guardrail --name support --blocked-input-messaging "Sorry." \
    --blocked-outputs-messaging "Sorry." --cli-input-json file://guardrail.json

Code Explained

Converse works the same across model providers
Inference profile IDs (us. prefix) route across US Regions
usage reports tokens for cost tracking
Streaming prints text as it arrives

  • Azure Microsoft Foundry / Azure OpenAI (az-40)
  • GCP Agent Platform (Vertex AI) + Gemini (gcp-40)

Cost Check

  • On-demand: per input / output token, varies by model
  • Batch inference is about half the on-demand price for supported models
  • Smaller models (Nova Micro / Lite, Haiku-class) cost far less for simple tasks

Security Check

  • IAM policies scoped to specific model / inference profile ARNs
  • VPC interface endpoint (bedrock-runtime) for private access
  • Guardrails for PII and harmful content on user-facing apps

Limits & Quotas

  • Quotas per model per Region: tokens per minute and requests per minute
  • Throttling returns ThrottlingException: retry with backoff
  • Provisioned Throughput reserves capacity for steady high volume

Do & Don't

  • Do Use the Converse API to keep model switching cheap
  • Do Log token usage per feature for cost tracking
  • Don’t Send sensitive data without Guardrails / redaction where required
  • Don’t Retry throttles instantly in a tight loop

Local Testing

  • Prototype prompts in the Bedrock console playground
  • Mock bedrock-runtime responses in unit tests (botocore Stubber)
  • Run evaluation sets locally against a dev account

Production Checklist

  • Least-privilege model access and VPC endpoints
  • Guardrails and logging (model invocation logging) on
  • Quota monitoring and backoff for throttling
