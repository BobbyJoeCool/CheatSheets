Running Lambda in Production

Versions freeze code and config; aliases (e.g. live) point at versions and can split traffic for canaries. Reserved concurrency caps (and guarantees) a function's share; provisioned concurrency keeps environments warm to remove cold starts. SnapStart snapshots initialized environments for Java, Python and .NET. Layers share libraries; event source mappings poll SQS, Kinesis and streams.

Key Points

  • Account concurrency is shared by all functions in a Region
  • Alias routing configuration enables weighted canary releases
  • Partial batch responses avoid retrying a whole SQS batch
  • Lambda Powertools adds logging, tracing, idempotency helpers

Limits & Quotas

  • Default 1,000 concurrent executions per Region (adjustable)
  • Up to 5 layers per function; 250 MB unzipped total
  • Each function scales by up to 1,000 environments every 10 seconds

Versions, Aliases, Concurrency, Queues

V=$(aws lambda publish-version --function-name orders \
  --query Version --output text)
aws lambda create-alias --function-name orders --name live --function-version $V
# Canary: 10% of traffic to the new version
aws lambda update-alias --function-name orders --name live \
    --function-version $OLD \
    --routing-config "AdditionalVersionWeights={\"$V\"=0.1}"

aws lambda put-function-concurrency --function-name orders \
    --reserved-concurrent-executions 50
aws lambda put-provisioned-concurrency-config --function-name orders \
    --qualifier live --provisioned-concurrent-executions 5

aws lambda create-event-source-mapping --function-name orders \
    --event-source-arn arn:aws:sqs:us-east-1:111122223333:orders \
    --batch-size 10 --function-response-types ReportBatchItemFailures
aws lambda publish-layer-version --layer-name common \
    --zip-file fileb://layer.zip --compatible-runtimes python3.13
aws lambda update-function-configuration --function-name orders \
    --snap-start ApplyOn=PublishedVersions

Code Explained

Callers invoke the live alias, not $LATEST
Weights shift 10% of invocations to the new version
Reserved concurrency 50 protects the database from overload
ReportBatchItemFailures retries only the failed messages

Azure / GCP Equivalent

  • Azure App Service slots, Durable Functions, Functions plans (az-21)
  • GCP Cloud Run revisions and jobs, Cloud Run functions (gcp-21)

Cost Check

  • Provisioned concurrency bills per hour even when idle
  • SnapStart for Python / .NET bills for caching and restores; Java is free
  • Reserved concurrency is free

Do & Don't

  • Do Deploy through aliases with canaries (CodeDeploy can automate)
  • Do Use partial batch responses for SQS
  • Don’t Let one function consume the whole account concurrency
  • Don’t Pay for provisioned concurrency on low-traffic internal jobs

Local Testing

  • SAM accelerate (sam sync --watch) for fast dev loops
  • Lambda Powertools has test helpers
  • Replay sample SQS events locally with sam local invoke -e

Production Checklist

  • Aliases + gradual deployments with automatic rollback alarms
  • Reserved concurrency on critical / dangerous functions
  • Powertools logging, tracing and idempotency
