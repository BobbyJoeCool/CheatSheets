Sheet 03

AWS CLI v2

install · aws configure · aws configure sso / aws sso login · --profile · --region / --output · --query (JMESPath) · CloudShell

Scripting AWS

The AWS CLI v2 calls every AWS API from the shell: aws <service> <operation>. Sign in with IAM Identity Center via aws configure sso, which stores a profile that refreshes short-lived credentials. --query filters output with JMESPath, --output picks json, table, text or yaml, and many services add high-level commands like aws s3.

Key Points

  • Config lives in ~/.aws/config (profiles) and ~/.aws/credentials (keys, avoid)
  • AWS_PROFILE and AWS_REGION environment variables override defaults
  • Pagination is automatic; --max-items limits it
  • --dry-run checks EC2 permissions without acting

Security Check

  • Prefer SSO profiles over aws configure access keys
  • Never commit ~/.aws/credentials or paste keys into scripts
  • Use --profile explicitly in scripts that touch production

Everyday aws

aws configure sso                         # one-time: creates a profile
aws sso login --profile shop-dev
export AWS_PROFILE=shop-dev AWS_REGION=us-east-1

aws sts get-caller-identity
aws ec2 describe-instances \
    --filters Name=instance-state-name,Values=running \
    --query "Reservations[].Instances[].[InstanceId,InstanceType]" \
    --output table

aws s3 ls
aws lambda list-functions --query "Functions[].FunctionName" --output text
aws ec2 run-instances --dry-run --image-id ami-0abc --instance-type t4g.micro

ID=$(aws ec2 describe-vpcs --filters Name=isDefault,Values=true \
     --query "Vpcs[0].VpcId" --output text)
aws cloudformation deploy help            # built-in docs
aws --cli-auto-prompt                     # interactive completion

Code Explained

configure sso asks for the SSO start URL, account and role
JMESPath flattens reservations into instance ID and type
--output text makes values easy to capture in variables
--dry-run answers "would I be allowed?"

Azure / GCP Equivalent

  • Azure Azure CLI, --query, az account set (az-03)
  • GCP gcloud, configurations, --format / --filter (gcp-03)

Cost Check

  • The CLI is free; every call to a billable API costs the same as from the console
  • CloudShell is free (1 GB persistent storage per Region)
  • Watch loops that call paid APIs (e.g. Cost Explorer) repeatedly

Do & Don't

  • Do Use one named SSO profile per account / role
  • Do Set --no-cli-pager or AWS_PAGER="" in scripts
  • Don’t Create access keys for your own laptop use
  • Don’t Parse table output in scripts

Local Testing

  • aws --endpoint-url http://localhost:4566 s3 ls talks to LocalStack
  • awslocal wraps the CLI for LocalStack
  • Docker image amazon/aws-cli runs the CLI without installing

Production Checklist

  • Automation uses roles (OIDC / instance profiles), not user keys
  • Scripts pin profile and Region explicitly
  • CloudTrail records every CLI call for audit
