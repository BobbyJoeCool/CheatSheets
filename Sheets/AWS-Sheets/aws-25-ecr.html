Elastic Container Registry

Private Container Images on AWS

Amazon ECR stores container images and OCI artifacts in private repositories (and offers a public gallery). Docker logs in with a short-lived token from get-login-password. Immutable tags prevent overwrites, lifecycle policies expire old images, and scanning (basic or enhanced with Inspector) reports vulnerabilities. Pull-through cache rules mirror public registries.

Key Points

  • Registry URL: <account>.dkr.ecr.<region>.amazonaws.com
  • ECS, EKS, Lambda and App Runner pull with IAM roles
  • Replication copies images across Regions and accounts
  • Pull-through cache avoids Docker Hub rate limits

Security Check

  • Enable tag immutability on release repositories
  • Enhanced scanning (Inspector) with alerts on critical findings
  • Repository policies limiting who can push

Limits & Quotas

  • Repositories and images per repository have adjustable quotas (Service Quotas)
  • Lifecycle policies: up to 50 rules each
  • API rate limits per account and Region apply to large fleets

Create, Push, Expire

aws ecr create-repository --repository-name shop-api \
    --image-tag-mutability IMMUTABLE \
    --image-scanning-configuration scanOnPush=true \
    --encryption-configuration encryptionType=KMS
REG=111122223333.dkr.ecr.us-east-1.amazonaws.com
aws ecr get-login-password | docker login --username AWS --password-stdin $REG

docker build -t $REG/shop-api:1.4.0 .
docker push $REG/shop-api:1.4.0
aws ecr describe-images --repository-name shop-api \
    --query "imageDetails[].[imageTags[0],imagePushedAt]" --output table
aws ecr describe-image-scan-findings --repository-name shop-api \
    --image-id imageTag=1.4.0 --query "imageScanFindings.findingSeverityCounts"

aws ecr put-lifecycle-policy --repository-name shop-api \
    --lifecycle-policy-text '{"rules":[{"rulePriority":1,
      "selection":{"tagStatus":"untagged","countType":"sinceImagePushed",
        "countUnit":"days","countNumber":14},"action":{"type":"expire"}}]}'
aws ecr create-pull-through-cache-rule --ecr-repository-prefix dockerhub \
    --upstream-registry-url registry-1.docker.io --credential-arn <secret-arn>

Code Explained

Immutable tags stop a release tag from being overwritten
The login token lasts 12 hours
Scan findings summarize vulnerabilities by severity
The lifecycle rule expires untagged images after 14 days

Azure / GCP Equivalent

Cost Check

  • Storage per GB-month plus data transfer out
  • Pulls inside the same Region are free (other than NAT / endpoint charges)
  • Lifecycle policies keep storage from growing forever

Do & Don't

  • Do Tag images with version + commit SHA
  • Do Add VPC endpoints (ecr.api, ecr.dkr, S3) for private pulls
  • Don’t Deploy latest
  • Don’t Keep every CI build forever

Local Testing

  • docker run -d -p 5000:5000 registry:2 for a local registry
  • Trivy scans images before push
  • LocalStack Pro emulates ECR

Production Checklist

  • Immutable tags + enhanced scanning on release repos
  • VPC endpoints for private pulls
  • Replication for DR Regions where needed
