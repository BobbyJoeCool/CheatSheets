Route 53

hosted zones · A / AAAA / CNAME / MX / TXT records · alias records · routing policies (weighted, latency, failover) · health checks · domain registration

DNS on AWS

Route 53 hosts public and private hosted zones, registers domains, and routes with policies: simple, weighted, latency, failover, geolocation and more, often combined with health checks. Alias records point names (even the zone apex) at AWS resources like CloudFront, load balancers and S3 websites, and follow their IP changes for free.

Key Points

  • Private hosted zones resolve only inside associated VPCs
  • Alias queries to AWS resources are free
  • Route 53 Resolver handles hybrid DNS (inbound / outbound endpoints)
  • Route 53 has a 100% availability SLA

Zone, Alias Record, Failover

aws route53 create-hosted-zone --name acme-shop.com \
    --caller-reference $(date +%s)
aws route53 list-hosted-zones --query "HostedZones[].[Name,Id]" --output table

Change Batch: Alias to an ALB (alias.json)

{ "Changes": [{ "Action": "UPSERT",
  "ResourceRecordSet": { "Name": "shop.acme-shop.com", "Type": "A",
    "SetIdentifier": "primary", "Failover": "PRIMARY",
    "HealthCheckId": "11111111-2222-3333-4444-555555555555",
    "AliasTarget": { "HostedZoneId": "Z35SXDOTRQ7X7K",
      "DNSName": "web-alb-123.us-east-1.elb.amazonaws.com",
      "EvaluateTargetHealth": true } } }] }

Apply and Check

aws route53 create-health-check --caller-reference hc-$(date +%s) \
    --health-check-config file://health-check.json
aws route53 change-resource-record-sets --hosted-zone-id Z0123 \
    --change-batch file://alias.json
dig +short shop.acme-shop.com

Code Explained

caller-reference must be unique per request
The alias target uses the load balancer's own hosted zone ID
A matching SECONDARY record completes failover routing
Health checks decide when to fail over

Do & Don't

  • Do Use alias records for AWS targets
  • Do Keep TTLs short on failover records
  • Don’t Point a CNAME at the zone apex
  • Don’t Delete a hosted zone still delegated at the registrar

Local Testing

  • dig @ns-123.awsdns-45.com shop.acme-shop.com tests before delegation
  • Route 53 "test record" in the console simulates answers
  • CoreDNS locally for split-horizon experiments

Production Checklist

  • Records managed in IaC
  • Health-checked failover for critical names
  • DNSSEC signing considered; registrar lock on
