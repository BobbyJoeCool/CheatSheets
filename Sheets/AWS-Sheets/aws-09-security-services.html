Sheet 09

Security & Audit Services

CloudTrail · GuardDuty · Security Hub · AWS Config rules · IAM Access Analyzer · WAF & Shield

Detect, Audit and Protect

CloudTrail records API calls; an organization trail sends every account's events to one bucket. GuardDuty detects threats from logs and runtime signals. AWS Config records resource configuration and evaluates rules. Security Hub aggregates findings and scores against standards. IAM Access Analyzer finds external and unused access, and WAF / Shield protect web apps.

Key Points

  • CloudTrail event history keeps 90 days of management events for free
  • Delegate admin for GuardDuty / Security Hub to a security account
  • Config conformance packs bundle rules for standards
  • Shield Standard is automatic; Shield Advanced is paid

Turn On the Basics

aws cloudtrail create-trail --name org-trail --s3-bucket-name acme-ct-logs \
    --is-organization-trail --is-multi-region-trail
aws cloudtrail start-logging --name org-trail
aws cloudtrail lookup-events --lookup-attributes \
    AttributeKey=EventName,AttributeValue=DeleteBucket --max-results 5

aws guardduty create-detector --enable
aws securityhub enable-security-hub --enable-default-standards
aws configservice put-configuration-recorder --configuration-recorder \
    name=default,roleARN=arn:aws:iam::111122223333:role/config-role
aws accessanalyzer create-analyzer --analyzer-name org --type ORGANIZATION

aws securityhub get-findings --filters \
    '{"SeverityLabel":[{"Value":"CRITICAL","Comparison":"EQUALS"}]}' \
    --query "Findings[].Title" --max-items 10

Code Explained

The organization trail covers every account and Region
lookup-events searches the last 90 days of management events
Security Hub default standards include AWS Foundational Security Best Practices
An organization analyzer reports access shared outside the org

Azure / GCP Equivalent

  • Azure Activity Log, Defender for Cloud, Azure Policy, Sentinel (az-09)
  • GCP Cloud Audit Logs, Security Command Center, Cloud Armor (gcp-09)

Cost Check

  • One CloudTrail copy of management events per Region is free to deliver; S3 storage is billed
  • GuardDuty and Security Hub bill by volume analyzed / checks
  • Config bills per configuration item recorded and rule evaluation

Do & Don't

  • Do Use an organization trail to a locked-down log archive account
  • Do Route high-severity findings to on-call
  • Don’t Disable GuardDuty to save money in production
  • Don’t Let findings pile up without owners

Local Testing

  • Prowler and ScoutSuite audit a live account from your laptop
  • Checkov / cfn-nag scan templates before deploy
  • Test Config rules in a sandbox account

Production Checklist

  • Org-wide CloudTrail, GuardDuty, Security Hub and Config
  • SCP denying CloudTrail / GuardDuty disablement
  • Findings triaged with SLAs
