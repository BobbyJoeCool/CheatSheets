HTTP Server Basics

http.createServer() · req / res · writeHead() · setHeader() · end() · listen() · keep-alive

The http Module

node:http is the server every Node framework is built on. createServer takes one function that runs for every request, receiving req (an IncomingMessage, a Readable) and res (a ServerResponse, a Writable). You set the status and headers, write the body, and must call res.end(). Routing, parsing, and middleware are up to you, which is why frameworks exist.

Notes

  • Header names in req.headers are lowercase
  • Headers must be set before the first body write
  • Default requestTimeout is 300 s; headersTimeout 60 s

A Minimal Server

import { createServer } from 'node:http';

const server = createServer((req, res) => {
  if (req.method === 'GET' && req.url === '/') {
    res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
    return res.end('<h1>Home</h1>');
  }
  if (req.url === '/api/health') {
    res.setHeader('Content-Type', 'application/json');
    return res.end(JSON.stringify({ ok: true }));   // 200 by default
  }
  res.statusCode = 404;
  res.end('Not found');
});

server.listen(3000, () => console.log('http://localhost:3000'));
server.keepAliveTimeout = 65_000;   // above the load balancer's idle timeout
server.on('error', (err) => {
  if (err.code === 'EADDRINUSE') console.error('Port 3000 is taken');
});

Code Explained

req.url — path + query string, e.g. /a?b=1
writeHead — status and headers in one call
return res.end() — prevents writing twice
statusCode — set before end()
keepAliveTimeout — avoids 502s behind AWS ALB / nginx

Common Mistakes

  • Forgetting res.end(); the client waits until it times out
  • Writing after end() → ERR_STREAM_WRITE_AFTER_END
  • Comparing req.url === '/search' when a query string is attached; parse it (Sheet 38)

Tips

  • Bind to 0.0.0.0 in containers; localhost isn't reachable from outside
  • Read the port from process.env.PORT
  • Use a framework (Express, Fastify) for anything beyond a few routes

Summary

  • createServer(fn) — one handler per request
  • req — method, url, headers, body stream
  • res.writeHead / end — send the reply
  • listen(port) — start accepting
