Sheet 13

Timers

setTimeout · setInterval · setImmediate · timers/promises · ref() / unref() · AbortSignal.timeout()

Scheduling Code Later

Node has the browser's setTimeout and setInterval, plus setImmediate (run after the current I/O phase). In Node they return a Timeout object, not a number. The node:timers/promises module offers promise versions you can await, cancel with an AbortSignal, and loop over with for await.

Notes

  • Delays are clamped to at least 1 ms and max ~24.8 days
  • An active timer keeps the process alive unless you unref() it
  • Extra arguments after the delay are passed to the callback

Callback & Promise Timers

import { setTimeout as sleep, setInterval as every }
  from 'node:timers/promises';

const t = setTimeout((name) => console.log(`hi ${name}`), 1000, 'Ada'); // hi Ada
clearTimeout(t);                          // cancel before it fires

const id = setInterval(() => console.log('tick'), 500);
setTimeout(() => clearInterval(id), 2100); // tick ×4, then stops

setTimeout(flushLogs, 60_000).unref();    // won't keep the process alive

await sleep(250);                         // pause 250 ms
const v = await sleep(100, 'done');       // resolves with 'done'

const ac = new AbortController();
sleep(5000, null, { signal: ac.signal })
  .catch(e => console.log(e.name));      // AbortError
ac.abort();

for await (const _ of every(1000)) {      // async interval
  if (await poll()) break;                // break clears the interval
}

Code Explained

as sleep — rename to avoid shadowing the global
'Ada' — extra arg forwarded to the callback
unref() — background timer, exit allowed
sleep(ms, value) — resolves with value
signal — abort rejects with AbortError
for await — interval that can't overlap itself

Common Mistakes

  • setInterval with async work: runs overlap if one takes longer than the delay
  • Storing the timer in a number type (TS); use ReturnType<typeof setTimeout>
  • A forgotten interval keeps the process from ever exiting

Tips

  • Debounce with t.refresh() instead of clearing and recreating
  • Use AbortSignal.timeout() rather than racing promises against a timer
  • Mock timers in tests with mock.timers (Sheet 49)

Summary

  • setTimeout — run once after a delay
  • setInterval — run repeatedly
  • timers/promises — awaitable timers
  • unref() — let the process exit
