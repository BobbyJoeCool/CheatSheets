The Most Common Node Framework

Express wraps node:http with routing, request helpers, and middleware. Routes match a method and path; path segments like :id land in req.params, query strings in req.query, and parsed bodies in req.body. Express 5 (current) forwards errors from async handlers automatically, so a rejected promise reaches your error handler instead of hanging the request.

Notes

  • req.body is undefined unless body-parsing middleware runs
  • res.json sets Content-Type and stringifies
  • Routes are checked top to bottom; first match wins

Routes & Responses

import express from 'express';                    // npm i express

const app = express();
app.use(express.json());                          // parse JSON bodies

app.get('/', (req, res) => res.send('Hello'));
app.get('/notes/:id', async (req, res) => {
  const note = await db.find(req.params.id);      // '42' (a string)
  if (!note) return res.status(404).json({ error: 'Not found' });
  res.json(note);
});
app.get('/search', (req, res) => res.json({ q: req.query.q }));   // ?q=node
app.post('/notes', async (req, res) => {
  const note = await db.create(req.body);
  res.status(201).location(`/notes/${note.id}`).json(note);
});
app.delete('/notes/:id', async (req, res) => {
  await db.remove(req.params.id);
  res.sendStatus(204);
});

app.listen(3000, () => console.log('http://localhost:3000'));

Code Explained

express.json() — fills req.body for JSON requests
:id — path parameter, always a string
return res… — stop after responding
location() — sets the Location header for 201s
sendStatus(204) — status with no body

Common Mistakes

  • Forgetting express.json(); req.body is undefined
  • Sending a response twice (no return); throws ERR_HTTP_HEADERS_SENT
  • Express 4 habits on v5: '*' route paths throw at startup

Tips

  • Validate req.params / req.body with a schema before use
  • Set app.set('trust proxy', 1) behind one proxy so req.ip is correct
  • Split routes into Routers by resource (Sheet 62)

Summary

  • app.get / post / … — define routes
  • req.params / query / body — inputs
  • res.status().json() — responses
  • Express 5 — async errors handled
