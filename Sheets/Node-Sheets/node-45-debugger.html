Debugging

--inspect · --inspect-brk · chrome://inspect · VS Code launch.json · debugger statement · --watch + inspect

Stepping Through Code

--inspect starts the V8 inspector, the same debugging protocol Chrome DevTools uses. Attach from Chrome (chrome://inspect), VS Code, or any JetBrains IDE to set breakpoints, step through code, inspect variables, and profile. A debugger; statement pauses execution when a debugger is attached and does nothing otherwise.

Notes

  • Default address is 127.0.0.1:9229
  • Anyone who can reach the port can run code in your process
  • VS Code's JavaScript Debug Terminal auto-attaches to any node you run

Starting the Debugger

node --inspect app.js            # run with debugger on 127.0.0.1:9229
node --inspect-brk app.js        # pause before the first line
node --inspect-wait app.js       # wait for a debugger, then run
node --inspect=9230 app.js       # different port (two processes)
node --watch --inspect app.js    # restart on change, reattach
node --inspect-brk --test        # debug tests
node inspect app.js              # built-in terminal debugger
kill -USR1 48213                 # enable the inspector in a running process

# then open chrome://inspect → "Open dedicated DevTools for Node"

Code Explained

--inspect-brk — set breakpoints before any code runs
--inspect-wait — like brk, but doesn't pause on line 1
=9230 — needed when debugging two processes
node inspect — no GUI required (SSH sessions)
SIGUSR1 — attach to a process started without flags

Common Mistakes

  • --inspect=0.0.0.0 on a server; anyone on the network gets remote code execution
  • Forgetting --enable-source-maps when debugging compiled code
  • Leaving debugger; statements in committed code

Tips

  • Use conditional breakpoints instead of adding if + debugger
  • Use logpoints to print without editing code
  • Tunnel to a remote debugger over SSH: ssh -L 9229:localhost:9229 host

Summary

  • --inspect — enable the debugger
  • --inspect-brk — pause at start
  • chrome://inspect — attach from Chrome
  • debugger; — code breakpoint
