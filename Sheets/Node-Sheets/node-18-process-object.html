Sheet 18

The process Object

process.argv · env · exit() · exitCode · cwd() · pid · platform · memoryUsage()

Your Program's Runtime Handle

The global process object connects your code to the running Node process and the OS around it. It holds the command-line arguments, environment variables, working directory, platform info, and memory stats, and it controls how and when the process exits. It's also an EventEmitter for signals and lifecycle events (Sheet 19).

Notes

  • Always available; no import needed (or import process from 'node:process')
  • Every process.env value is a string or undefined
  • cwd() is where node was launched, not where the file lives

Reading Process State

// node app.js serve --port 8080
process.argv;               // ['/usr/bin/node', '/app/app.js', 'serve', …]
process.argv.slice(2);      // ['serve', '--port', '8080']
process.env.HOME;           // '/home/ada'
process.env.PORT ?? '3000'; // env values are strings
process.cwd();              // '/app'
process.chdir('/tmp');      // change the working directory
process.pid;                // 48213
process.platform;           // 'linux' | 'darwin' | 'win32'
process.arch;               // 'x64' | 'arm64'
process.version;            // 'v26.1.0'
process.versions.v8;        // '14.6.…'
process.uptime();           // 12.03 (seconds)
process.memoryUsage().heapUsed;  // 5832144 (bytes)
process.exitCode = 1;       // exit with 1 when the loop empties
process.exit(2);            // exit now; pending async work is dropped

Code Explained

argv[0] — node binary; argv[1] — script path
slice(2) — just the user's arguments
?? — fallback when the variable is unset
exitCode — graceful: lets writes and logs finish
exit() — immediate; use only when you must stop now

Common Mistakes

  • Treating process.env.DEBUG === true as boolean; it's the string 'true'
  • Calling process.exit() right after stdout.write(); output can be cut off when piped
  • Reading files relative to cwd(); it changes depending on where the user runs the command

Tips

  • Parse and validate env vars once at startup (Sheet 20)
  • Use process.hrtime.bigint() or performance.now() for timing, not Date.now()
  • Prefer setting exitCode and letting the process end on its own

Summary

  • process.argv — command-line arguments
  • process.env — string environment variables
  • process.cwd() — launch directory
  • process.exitCode — graceful exit status
