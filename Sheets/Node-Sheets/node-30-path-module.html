The path Module

path.join() · resolve() · basename() · extname() · dirname() · parse() · sep · fileURLToPath()

Building Paths Correctly

node:path builds and takes apart file paths without string concatenation. It knows the separator for the current OS, removes .. and duplicate slashes, and splits a path into folder, name, and extension. Use path.join to combine pieces and path.resolve to get an absolute path.

Notes

  • path only manipulates strings; it never touches the disk
  • path.posix / path.win32 force a specific style
  • ES modules: base paths on import.meta.dirname

Joining & Splitting Paths

import path from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';

path.join('/app', 'src', '../lib', 'a.js');      // '/app/lib/a.js'
path.resolve('src', 'a.js');                     // '/cwd/src/a.js'
path.resolve(import.meta.dirname, 'data.json');  // next to this module
path.basename('/a/b/photo.jpg');                 // 'photo.jpg'
path.basename('/a/b/photo.jpg', '.jpg');         // 'photo'
path.extname('archive.tar.gz');                  // '.gz'
path.dirname('/a/b/photo.jpg');                  // '/a/b'
path.parse('/a/b/photo.jpg').name;               // 'photo'
path.relative('/a/b', '/a/c/d');                 // '../c/d'
path.normalize('a//b/../c/');                    // 'a/c/'
path.isAbsolute('./x');                          // false
path.sep;                                        // '/' (or '\\' on Windows)
fileURLToPath(import.meta.url);                  // '/app/src/index.js'
pathToFileURL('/tmp/a b.txt').href;              // 'file:///tmp/a%20b.txt'

Code Explained

join — combines and normalizes; result can be relative
resolve — right to left until absolute, else prepends cwd
basename(p, ext) — strip a known extension
parse — { root, dir, base, ext, name }
fileURLToPath — file: URL → OS path

Block Path Traversal

const root = path.resolve('uploads');
const p = path.resolve(root, userInput);
if (!p.startsWith(root + path.sep))
  throw new Error('outside uploads');

Common Mistakes

  • Building paths with + '/' +; breaks on Windows and doubles slashes
  • Passing user input to join without checking; ../../etc/passwd escapes your folder
  • Using new URL(import.meta.url).pathname as a path; it keeps %20 and breaks on Windows

Tips

  • Use path.resolve for anything passed to child processes or stored in config
  • Use path.posix.join for URL paths and archive entries
  • Compare paths after path.resolve so ./a and a match

Summary

  • join — combine segments
  • resolve — absolute path
  • basename / extname / dirname — split a path
  • fileURLToPath — module URL → path
