pipeline() & Transforms

stream/promises pipeline() · Transform · zlib gzip / brotli · error propagation · finished()

Connecting Streams Safely

pipeline() from node:stream/promises connects any number of streams, propagates backpressure, and if any stage fails, destroys every stream and rejects. Middle stages can be Transform streams, zlib compressors, or plain async generator functions, which are the simplest way to write a transform.

Notes

  • .pipe() doesn't forward errors; pipeline does
  • A generator stage receives the previous stage as source
  • Pass { signal } as the last argument to make it cancellable

pipeline, Transforms & Compression

import { pipeline } from 'node:stream/promises';
import { Transform } from 'node:stream';
import { createReadStream, createWriteStream } from 'node:fs';
import { createGzip, createGunzip } from 'node:zlib';

const upper = new Transform({
  transform(chunk, enc, cb) { cb(null, chunk.toString().toUpperCase()); },
});
await pipeline(createReadStream('in.txt'), upper, createGzip(),
  createWriteStream('out.txt.gz'));           // any error rejects

await pipeline(
  createReadStream('data.csv.gz'),
  createGunzip(),
  async function* (source) {                  // generator as a transform
    for await (const chunk of source)
      yield chunk.toString().replaceAll(';', ',');
  },
  createWriteStream('data.csv'),
  { signal: AbortSignal.timeout(60_000) },    // cancel after 60 s
);

Code Explained

cb(null, data) — push transformed data downstream
createGzip — a Transform stream from zlib
source — async iterable of the previous stage's chunks
yield — sends a chunk to the next stage
signal — aborting destroys all stages

Common Mistakes

  • a.pipe(b).pipe(c) in production; an error in b leaves a and c open
  • Using replaceAll on chunks for multi-character patterns; a match can be split between chunks
  • Gzipping already-compressed files (JPEG, MP4); it wastes CPU for no gain

Tips

  • Serve precompressed .br / .gz files instead of compressing per request
  • Split text into lines first (readline) before line-based transforms
  • Use objectMode transforms to parse records, not raw bytes

Summary

  • pipeline — connect, propagate errors
  • Transform — change chunks in flight
  • async generator — easiest transform
  • zlib — gzip / brotli streams
