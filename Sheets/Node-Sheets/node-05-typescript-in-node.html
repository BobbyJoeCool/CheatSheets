Running .ts Files Directly

Node runs .ts files with no build step by stripping types: it replaces type annotations with whitespace and runs what's left. That only works for erasable syntax, TypeScript that disappears completely once types are removed. Node does not type-check; run tsc --noEmit (in your editor or CI) to catch type errors.

Notes

  • On by default since Node 23.6 and 22.18; no flag needed
  • Imports must include the .ts extension
  • Type-only imports need import type
  • .ts files inside node_modules are not stripped

Erasable TypeScript

// greet.ts — run with: node greet.ts
import type { User } from './types.ts';   // type-only, with .ts extension

interface Options { loud?: boolean }

export function greet(user: User, opts: Options = {}): string {
  const msg = `Hello, ${user.name}`;
  return opts.loud ? msg.toUpperCase() : msg;
}

console.log(greet({ name: 'Ada' }));                 // Hello, Ada
console.log(greet({ name: 'Ada' }, { loud: true })); // HELLO, ADA

// ✖ Not erasable: these emit runtime code → SyntaxError
enum Color { Red, Green }
class Point { constructor(public x: number) {} }   // parameter property

Code Explained

import type — removed entirely at runtime
interface — pure type, erased
: string — annotations become whitespace
enum — generates an object, so it can't be erased
public x — generates an assignment; same problem
Use a union or as const object instead of enum

tsconfig.json for Node

{
  "compilerOptions": {
    "module": "nodenext",
    "target": "esnext",
    "noEmit": true,
    "erasableSyntaxOnly": true,
    "verbatimModuleSyntax": true,
    "allowImportingTsExtensions": true
  }
}

Common Mistakes

  • Assuming Node checks types; a wrong type runs fine until it crashes
  • Importing ./types without .ts; Node won't guess the extension
  • Importing a type without import type; the import stays and fails at runtime

Tips

  • Turn on erasableSyntaxOnly so tsc flags unsupported syntax
  • Add "check": "tsc --noEmit" and run it in CI
  • Libraries you publish should still ship compiled .js + .d.ts

Summary

  • node app.ts — strips types and runs
  • erasable — syntax that leaves no runtime code
  • tsc --noEmit — the actual type check
  • tsx — fallback for full TypeScript
