HTTPS & TLS

https.createServer() · key / cert · tls options · self-signed certs · NODE_EXTRA_CA_CERTS · http2

Encrypted Servers & Clients

node:https is node:http plus TLS: pass a private key and certificate and everything else works the same. node:http2 adds HTTP/2 (multiplexed streams over one connection). In production, TLS is often handled by a reverse proxy or load balancer instead, with Node serving plain HTTP behind it.

Notes

  • cert should contain the full chain (leaf + intermediates)
  • Browsers require TLS for HTTP/2
  • Clients reject untrusted certs by default

HTTPS & HTTP/2 Servers

import https from 'node:https';
import http2 from 'node:http2';
import { readFileSync } from 'node:fs';

const tls = {
  key:  readFileSync('certs/key.pem'),
  cert: readFileSync('certs/fullchain.pem'),   // cert + intermediates
  minVersion: 'TLSv1.2',
};
https.createServer(tls, (req, res) => res.end('secure\n')).listen(8443);

const h2 = http2.createSecureServer({ ...tls, allowHTTP1: true });
h2.on('request', (req, res) => res.end(`HTTP/${req.httpVersion}`));
h2.listen(8444);

const agent = new https.Agent({ ca: readFileSync('company-ca.pem') });
https.get('https://intranet.local', { agent }, (res) => {
  console.log(res.statusCode);                 // 200
});

Code Explained

key / cert — PEM files as Buffers or strings
minVersion — refuse old TLS versions
allowHTTP1 — same server answers HTTP/1.1 clients
Agent({ ca }) — trust a private CA for these requests

Self-Signed Dev Cert

openssl req -x509 -newkey rsa:2048 \
  -nodes -days 365 \
  -keyout key.pem -out cert.pem \
  -subj "/CN=localhost"

Common Mistakes

  • NODE_TLS_REJECT_UNAUTHORIZED=0 to "fix" a cert error; it disables TLS checks for every request
  • Serving only the leaf cert; some clients fail with "unable to verify the first certificate"
  • Reading cert files once and never reloading them after renewal

Tips

  • Use mkcert to create locally trusted dev certificates
  • Terminate TLS at a proxy (nginx, Caddy, cloud LB) unless you need it in Node
  • Use --use-system-ca on corporate networks with inspection proxies

Summary

  • https.createServer(tls) — TLS server
  • http2.createSecureServer — HTTP/2
  • Agent({ ca }) — trust private CAs
  • fullchain.pem — serve the whole chain
