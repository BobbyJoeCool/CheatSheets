The util Module

util.promisify() · inspect() · format() · types · deprecate() · isDeepStrictEqual() · aborted()

Small Helpers You Already Have

node:util is a grab bag of helpers used throughout Node itself. Several have their own sheets (promisify 14, parseArgs 22, styleText 24, inspect / debuglog 46); this sheet collects the rest. Check here before installing a utility package.

Notes

  • util.types checks work across realms (workers, vm)
  • util.deprecate warns once per process
  • Many old util.is* helpers are removed; use typeof / Array.isArray

Everyday util Functions

import util from 'node:util';

util.format('%s is %d', 'Ada', 36);              // 'Ada is 36'
util.isDeepStrictEqual({ a: [1] }, { a: [1] });  // true
util.types.isPromise(Promise.resolve());         // true
util.types.isDate(new Date());                   // true
util.types.isNativeError(new TypeError());       // true
util.getSystemErrorName(-2);                     // 'ENOENT'
util.stripVTControlCharacters('\x1b[31mred\x1b[0m');   // 'red'
util.toUSVString('bad \ud800 surrogate');        // replaces lone surrogates

export const oldApi = util.deprecate(
  newApi, 'oldApi() is deprecated; use newApi()', 'DEP_APP_001');

await util.aborted(signal, resource);   // resolves when signal aborts
const mime = new util.MIMEType('text/html; charset=utf-8');
mime.essence;                           // 'text/html'
mime.params.get('charset');             // 'utf-8'

Code Explained

format — same placeholders as console.log
isDeepStrictEqual — the comparison assert uses
getSystemErrorName — errno number → code
stripVTControlCharacters — remove ANSI colors
deprecate — wrap old functions to warn callers

Common Mistakes

  • Using removed helpers like util.isString; they throw on current versions
  • Comparing objects with JSON.stringify; key order differs, use isDeepStrictEqual
  • Formatting user strings with util.format as a template; % in input gets interpreted

Tips

  • Wrap legacy exports with deprecate before removing them
  • Use util.types checks for values that come from other realms
  • Run node -p "Object.keys(require('node:util'))" to see everything

Summary

  • format — printf-style strings
  • isDeepStrictEqual — deep compare
  • types — reliable type checks
  • deprecate — warn on old APIs
