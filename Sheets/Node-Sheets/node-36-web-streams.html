The Web-Standard Streams

Node also implements the WHATWG streams used by browsers, fetch, and edge runtimes: ReadableStream, WritableStream, and TransformStream. They have a different API from Node streams but the same ideas. Use them for code that must run everywhere, and convert with Readable.toWeb() / fromWeb() when mixing with Node APIs.

Notes

  • fetch request and response bodies are Web streams
  • Web streams are globals; no import needed
  • pipeTo / pipeThrough replace pipeline

ReadableStream, TransformStream & Bridges

import fs from 'node:fs';
import { Readable, Writable } from 'node:stream';

const rs = new ReadableStream({
  start(controller) {
    controller.enqueue('a'); controller.enqueue('b'); controller.close();
  },
});
for await (const chunk of rs) console.log(chunk);   // a, b

const upper = new TransformStream({
  transform(chunk, controller) { controller.enqueue(chunk.toUpperCase()); },
});

const res = await fetch('https://example.com/readme.txt');
await res.body
  .pipeThrough(new TextDecoderStream())             // bytes → strings
  .pipeThrough(upper)
  .pipeTo(Writable.toWeb(process.stdout));          // Node → Web writable

const web = Readable.toWeb(fs.createReadStream('a.txt'));   // Node → Web
const gz = web.pipeThrough(new CompressionStream('gzip'));

Code Explained

controller.enqueue — push a chunk
controller.close() — end of data
pipeThrough — attach a TransformStream, returns the readable side
pipeTo — sends to a WritableStream, returns a promise
CompressionStream — built-in gzip / deflate

Common Mistakes

  • Reading res.body twice; a stream can only be consumed once (use res.clone())
  • Passing a Node stream where a Web stream is expected, e.g. to new Response()
  • Forgetting await on pipeTo; errors become unhandled rejections

Tips

  • Write portable libraries against Web streams; convert at the Node edge
  • Use new Response(stream).text() to collect a Web stream
  • Stick with Node streams for fs and sockets; they're faster there

Summary

  • ReadableStream — web-standard source
  • pipeThrough / pipeTo — connect stages
  • TextDecoderStream — decode safely
  • toWeb / fromWeb — convert between worlds
