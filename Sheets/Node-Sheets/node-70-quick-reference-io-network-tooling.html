⚠ Common Mistakes

  • exec with user input in the command string (shell injection) — use execFile / spawn
  • pipe() without error handling — use stream.pipeline
  • Reading huge files with readFile instead of streaming them

✓ Tips & Best Practices

  • Build paths with path.join, never string concatenation
  • Use the built-in fetch, node:test and --watch before adding dependencies
  • Handle SIGTERM: stop accepting requests, finish in-flight ones, then exit

Quick Summary

  • fs/promises + path for files
  • Streams + pipeline() for big data
  • http.createServer serves, fetch requests
  • node:test + assert for tests
