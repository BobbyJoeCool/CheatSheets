Making HTTP Requests

fetch is built into Node and works like the browser version. It's powered by Undici, Node's HTTP client, which you can import directly for connection pools, proxies, and lower-level control. fetch only rejects on network errors; a 404 or 500 still resolves, so check res.ok yourself.

Notes

  • Undici 8 ships with Node 26
  • No timeout by default; pass a signal
  • The body can be read once: json(), text(), arrayBuffer(), or blob()

GET, POST & Uploads

const res = await fetch('https://api.example.com/notes?limit=10', {
  headers: { Authorization: `Bearer ${token}` },
  signal: AbortSignal.timeout(5000),            // give up after 5 s
});
res.ok;                                         // true for 200–299
res.status;                                     // 200
res.headers.get('content-type');                // 'application/json'
const notes = await res.json();

const created = await fetch('https://api.example.com/notes', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: 'Buy milk' }),
});
if (!created.ok) throw new Error(`HTTP ${created.status}`);

const form = new FormData();
form.append('file', new Blob([bytes], { type: 'image/jpeg' }), 'photo.jpg');
await fetch(uploadUrl, { method: 'POST', body: form });   // multipart

Code Explained

AbortSignal.timeout — rejects with TimeoutError
res.ok — the check fetch won't do for you
JSON.stringify + header — fetch doesn't encode objects
FormData — sets the multipart boundary itself
Don't set Content-Type for FormData manually

Common Mistakes

  • Assuming fetch throws on 4xx/5xx; it resolves, so check res.ok
  • Calling res.json() then res.text(); the body is already used
  • No timeout on outbound calls; one slow API stalls your requests

Tips

  • Wrap fetch in a small helper that adds timeout, ok check, and JSON parsing
  • Stream big downloads: Readable.fromWeb(res.body) into a file
  • Retry only idempotent requests (GET, PUT), with backoff

Summary

  • fetch — built-in HTTP client
  • res.ok — check status yourself
  • AbortSignal.timeout — set a deadline
  • undici — pools, proxies, speed
