⚠ Common Mistakes

  • Mixing ESM and CJS without knowing which one a file is — check "type" and the extension
  • Blocking the event loop with sync I/O or heavy CPU work on a server
  • Unhandled "error" events or rejections crashing the process

✓ Tips & Best Practices

  • Use node --watch and --env-file instead of extra tools in dev
  • Pass an AbortSignal through long operations so they can be cancelled
  • Set process.exitCode instead of calling process.exit() mid-write

Quick Summary

  • ESM with "type": "module" and node: imports
  • fs/promises + async/await everywhere
  • nextTick → microtasks → timers → I/O → setImmediate
  • process.env, process.argv, signals for lifecycle
