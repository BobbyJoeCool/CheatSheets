The os Module

os.cpus() · availableParallelism() · totalmem() · freemem() · homedir() · tmpdir() · EOL · platform()

Operating System Information

The node:os module reports facts about the machine: CPU cores, memory, the OS name and version, network interfaces, and standard folders like the home and temp directories. Use it to size worker pools, write cross-platform paths and line endings, and include host details in logs and diagnostics.

Notes

  • os.platform() equals process.platform
  • cpus() counts logical cores (hyperthreads included)
  • loadavg() always returns zeros on Windows

Querying the Machine

import os from 'node:os';

os.type();                    // 'Linux' | 'Darwin' | 'Windows_NT'
os.release();                 // '6.8.0-45-generic'
os.arch();                    // 'arm64'
os.cpus().length;             // 8
os.availableParallelism();    // 8 (respects CPU limits; prefer this)
os.totalmem() / 1024 ** 3;    // 16 (GB)
os.freemem();                 // free bytes
os.loadavg();                 // [0.52, 0.61, 0.70] (1, 5, 15 min)
os.uptime();                  // seconds since boot
os.homedir();                 // '/home/ada'
os.tmpdir();                  // '/tmp'
os.hostname();                // 'web-01'
os.userInfo().username;       // 'ada'
os.networkInterfaces().eth0;  // [{ address, family, mac, internal }]
os.EOL;                       // '\n' (or '\r\n' on Windows)

Code Explained

availableParallelism — the right number for pool sizes
totalmem — in bytes; divide by 1024³ for GB
tmpdir — honors TMPDIR / TEMP
networkInterfaces — find the machine's IP addresses
EOL — line ending when writing text for this OS

Common Mistakes

  • Sizing a pool with os.cpus().length inside a container; it can report the host's cores
  • Checking for 'windows'; the value is 'win32' even on 64-bit
  • Hardcoding /tmp or ~; use os.tmpdir() and os.homedir()

Tips

  • Use os.availableParallelism() - 1 workers to leave the main thread a core
  • Use fs.mkdtemp(path.join(os.tmpdir(), 'app-')) for temp folders
  • Log os.hostname() to tell instances apart

Summary

  • availableParallelism() — usable cores
  • totalmem / freemem — memory in bytes
  • homedir / tmpdir — standard folders
  • EOL — OS line ending
