Reading Files

readFile loads a whole file into memory: give it an encoding to get a string, or none to get a Buffer of raw bytes. That's right for configs and small data. For large files, stream them: createReadStream hands you chunks, and wrapping it in readline gives you one line at a time with constant memory.

Notes

  • No encoding → Buffer; 'utf8' → string
  • Relative paths resolve from process.cwd()
  • Paths can be strings, Buffers, or file: URL objects

Whole File, Lines & Chunks

import { readFile } from 'node:fs/promises';
import { createReadStream } from 'node:fs';
import { createInterface } from 'node:readline';

const text = await readFile('notes.txt', 'utf8');   // string
const img  = await readFile('logo.png');            // Buffer
const cfg  = JSON.parse(await readFile('config.json', 'utf8'));
const lines = text.split(/\r?\n/);                 // all lines in memory

const here = new URL('./data.json', import.meta.url);   // next to this file
const data = JSON.parse(await readFile(here, 'utf8'));

const rl = createInterface({                        // huge file, line by line
  input: createReadStream('big.log'), crlfDelay: Infinity,
});
for await (const line of rl) if (line.includes('ERROR')) console.log(line);

const opts = { highWaterMark: 1024 * 1024 };        // 1 MB chunks
for await (const chunk of createReadStream('big.bin', opts)) handle(chunk);

Code Explained

'utf8' — decode bytes to text
/\r?\n/ — split Windows and Unix line endings
new URL(…, import.meta.url) — path relative to the module
readline — memory stays flat on multi-GB files
highWaterMark — chunk size (default 64 KB)

Common Mistakes

  • readFile on a 4 GB log; it can exceed memory or the max string length
  • Forgetting the encoding and printing a <Buffer 68 65 …>
  • Paths relative to cwd when you meant relative to the file; use import.meta.dirname

Tips

  • Strip a UTF-8 BOM before parsing: text.replace(/^\uFEFF/, '')
  • Use import data from './x.json' with { type: 'json' } for static JSON
  • Pass { signal } to cancel slow reads

Summary

  • readFile(p, 'utf8') — whole file as text
  • readFile(p) — whole file as Buffer
  • readline — line by line
  • createReadStream — chunks, any size
