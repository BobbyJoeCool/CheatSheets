The assert Module

assert.strictEqual() · deepStrictEqual() · throws() · rejects() · match() · assert/strict · partialDeepStrictEqual()

Making Assertions

node:assert checks values and throws an AssertionError with a readable diff when they don't match. Always import node:assert/strict: it uses === and strict deep comparison, so 1 never equals '1'. It works in any code, not just tests, which makes it handy for invariants.

Notes

  • Legacy (non-strict) mode uses ==; avoid it
  • Deep equality compares structure, not identity
  • throws / rejects can match a class, regex, object, or function

Common Assertions

import assert from 'node:assert/strict';

assert.equal(1 + 1, 2);                          // ===
assert.notEqual('a', 'b');
assert.deepEqual({ a: [1, 2] }, { a: [1, 2] });  // structure
assert.notDeepEqual([1, 2], [2, 1]);
assert.ok(user.active);                          // truthy
assert.match('2026-10-02', /^\d{4}-\d{2}-\d{2}$/);

assert.throws(() => JSON.parse('{'), SyntaxError);
assert.throws(() => pay(-1), { name: 'RangeError', message: /negative/ });
await assert.rejects(getUser(999), { code: 'E_NOT_FOUND' });
await assert.doesNotReject(save());

assert.partialDeepStrictEqual(               // only the listed keys
  { id: 1, name: 'Ada', tags: [] },
  { name: 'Ada' },
);
assert.fail('should never get here');

Code Explained

deepEqual (strict) — also compares prototypes
ok — fails on 0, '', null, undefined
Object matcher — each listed property must match
rejects — takes a promise or async function; await it
partialDeepStrictEqual — subset match (newer API)

Common Mistakes

  • Importing node:assert (legacy) and getting loose == comparisons
  • assert.rejects(...) without await; the test ends before the check runs
  • assert.throws(fn()) instead of assert.throws(() => fn()); the error is thrown before assert sees it

Tips

  • Add a message as the last argument for clearer failures
  • Use t.assert inside tests so assertions are tracked per test
  • Use assert.ok(cond, 'invariant') in app code for impossible states

Summary

  • assert/strict — always import this
  • equal / deepEqual — values and structures
  • throws / rejects — expected errors
  • match — regex checks
