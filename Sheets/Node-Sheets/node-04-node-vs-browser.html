Sheet 04

Node vs the Browser

globalThis · process · no window / DOM · import.meta.dirname · import.meta.filename · Web APIs in Node · node: prefix

Same Language, Different Host

Node runs the same JavaScript as the browser but provides a different set of globals. There is no DOM, no window, and no document. Instead you get process, Buffer, and the core modules for files, networking, and the OS. Node also implements most standard Web APIs (fetch, URL, AbortController, Web Crypto), so a lot of browser code runs unchanged.

Notes

  • Use globalThis for code that runs in both
  • __dirname exists in CommonJS only
  • The node: prefix is required for some modules (node:test, node:sqlite)
  • Node has full disk and network access; there is no sandbox by default

Globals & Web APIs in Node

import { readFile } from 'node:fs/promises';   // core module, node: prefix

typeof window;                       // 'undefined'
globalThis === global;               // true
process.version;                     // 'v26.x.x'
import.meta.filename;                // '/app/src/index.js'  (ESM)
import.meta.dirname;                 // '/app/src'           (ESM)
import.meta.url;                     // 'file:///app/src/index.js'

const res = await fetch('https://api.github.com/zen');   // Response
await res.text();                    // 'Keep it logically awesome.'
new URL('/a?b=1', 'https://x.dev').searchParams.get('b'); // '1'
structuredClone({ list: [1, 2] });   // deep copy
crypto.randomUUID();                 // '3b241101-e2bb-4255-8caf-…'
new TextEncoder().encode('hi');      // Uint8Array(2) [ 104, 105 ]

Code Explained

global — Node's old name for globalThis
import.meta.dirname — ESM replacement for __dirname
import.meta.url — a file:// URL, not a path
await at top level — allowed in ES modules
crypto — global Web Crypto, no import needed

Common Mistakes

  • Using __dirname in an ES module throws ReferenceError; use import.meta.dirname
  • Passing import.meta.url to fs as a path string; it's a URL
  • Installing node-fetch or uuid for things Node now has built in

Tips

  • Check for Node at runtime: typeof process !== 'undefined'
  • Convert URLs with fileURLToPath(import.meta.url) from node:url
  • Prefer Web APIs when code may also run in browsers or edge runtimes

Summary

  • globalThis — the global object everywhere
  • process — Node's runtime interface
  • import.meta — current module's location
  • Web APIs — fetch, URL, crypto built in
