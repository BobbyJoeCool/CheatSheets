Running Other Programs

node:child_process starts other programs. execFile runs a command and buffers its output; spawn streams output for long-running or chatty commands; exec runs a string through a shell (pipes, globs, and also injection risk); fork starts another Node script with a message channel. Prefer the versions that don't use a shell.

Notes

  • Arguments as an array are never shell-interpreted
  • exec / execFile buffer up to 1 MB of output by default
  • On Windows, .cmd / .bat files need shell: true

execFile, spawn, exec & fork

import { spawn, execFile, exec, fork } from 'node:child_process';
import { promisify } from 'node:util';
const execFileP = promisify(execFile);

const { stdout } = await execFileP('git', ['rev-parse', 'HEAD']);
stdout.trim();                                   // 'a1b2c3d…'

const ff = spawn('ffmpeg', ['-i', 'in.mp4', 'out.webm'], { stdio: 'inherit' });
ff.on('close', (code) => console.log('exit', code));   // live output

const g = spawn('grep', ['ERROR']);
g.stdout.on('data', (d) => process.stdout.write(d));
g.stdin.end('ok\nERROR disk full\n');            // feed input, close stdin

await promisify(exec)('ls *.log | wc -l');       // shell: never with user input

const child = fork('./job.js');                   // Node + IPC channel
child.send({ jobId: 42 });
child.on('message', (m) => console.log('result', m));

Code Explained

execFile + array — safe from shell injection
stdio: 'inherit' — child writes straight to your terminal
stdin.end — send input and signal EOF
exec — only for fixed strings you wrote yourself
fork — child calls process.send() to reply

Common Mistakes

  • exec('convert ' + filename) with user input; a filename like x; rm -rf ~ runs
  • Not handling 'error' on spawn; a missing binary emits ENOENT and crashes
  • Ignoring the exit code; a failed command still "succeeds" if you don't check

Tips

  • Use execa for nicer promises, errors, and cross-platform behavior
  • Pass env: { ...process.env, LANG: 'C' } for predictable command output
  • Kill child processes on shutdown so they don't outlive the parent

Summary

  • execFile — run a command, get output
  • spawn — stream long-running output
  • exec — shell strings (careful)
  • fork — Node child with messages
