TCP, UDP & DNS

net.createServer() · net.connect() · socket events · dgram · dns.lookup() vs dns.resolve() · dns/promises

Lower-Level Networking

node:net provides raw TCP servers and sockets: a byte stream with no HTTP on top. node:dgram provides UDP: individual datagrams, no connection, no delivery guarantee. node:dns resolves names; lookup uses the OS resolver (and /etc/hosts), while the resolve* functions query DNS servers directly.

Notes

  • A TCP socket is a Duplex stream
  • TCP has no message boundaries; you define framing
  • UDP messages can be lost, duplicated, or reordered

TCP, UDP & DNS

import net from 'node:net';
import dgram from 'node:dgram';
import dns from 'node:dns/promises';

net.createServer((socket) => {                 // TCP echo server
  socket.write('hi\n');
  socket.on('data', (buf) => socket.write(buf));
  socket.on('end', () => console.log('client left'));
}).listen(7000);

const client = net.connect({ host: 'localhost', port: 7000 });
client.on('data', (d) => console.log(d.toString()));   // 'hi'

const udp = dgram.createSocket('udp4');
udp.on('message', (msg, rinfo) => console.log(msg.toString(), rinfo.port));
udp.bind(9000, () => udp.send('ping', 9000, '127.0.0.1'));

await dns.lookup('nodejs.org');      // { address: '104.20.…', family: 4 }
await dns.resolve4('nodejs.org');             // ['104.20.…', …]
await dns.resolveMx('gmail.com');             // [{ exchange, priority }, …]

Code Explained

createServer(fn) — runs per client connection
'end' — the other side finished sending
rinfo — sender's address and port
bind callback — send once the socket is ready
lookup — same answer the OS gives other programs

Common Mistakes

  • Treating each 'data' event as one message; TCP can split or merge writes
  • No 'error' handler on sockets; a reset connection (ECONNRESET) crashes the app
  • Using resolve4 and expecting /etc/hosts entries; only lookup reads them

Tips

  • Frame TCP messages with a length prefix or newline delimiter
  • Use socket.setKeepAlive(true) for long-lived connections
  • Use net.isIP(str) to validate IP addresses

Summary

  • net — raw TCP servers and clients
  • dgram — UDP datagrams
  • dns.lookup — OS name resolution
  • framing — your job on TCP
