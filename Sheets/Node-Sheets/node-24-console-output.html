Writing to the Terminal

console writes to stdout (log, info, table) or stderr (error, warn, trace). Keep that split: data on stdout stays pipeable while messages go to stderr. util.styleText adds colors without a dependency, and process.stdout.write gives you output without the automatic newline, for progress lines.

Notes

  • console.log is synchronous to files and TTYs, async to pipes
  • styleText respects NO_COLOR and skips colors when output isn't a terminal
  • Exit code 0 means success to every shell and CI system

Console & Styled Output

import { styleText } from 'node:util';

console.log('info');                        // stdout
console.error('oops');                      // stderr
console.table([{ id: 1, ok: true }, { id: 2, ok: false }]);   // grid
console.dir(obj, { depth: null });          // full nested object
console.log('%s has %d items', 'cart', 3);  // cart has 3 items
console.time('load'); await load(); console.timeEnd('load');  // load: 41.2ms
console.count('hit');                       // hit: 1 … hit: 2
console.group('Build'); console.log('step'); console.groupEnd();  // indented
console.assert(n > 0, 'n must be positive');   // prints only when false

console.log(styleText('green', '✔ done'));
console.log(styleText(['bold', 'red'], 'FAILED'));
process.stdout.write('Progress 40%\r');     // no newline; \r rewrites line
process.stdout.columns;                     // terminal width, e.g. 120

Code Explained

table — arrays of objects become a grid
depth: null — log stops at 2 levels by default
%s %d — printf-style placeholders
time / timeEnd — labels must match exactly
styleText — accepts one style or an array
\r — returns the cursor to the line start

Common Mistakes

  • Printing errors with console.log; they get mixed into piped data
  • Hardcoding ANSI escape codes; they garble logs and CI output
  • Using console.log as a production logger; it has no levels or structure (Sheet 65)

Tips

  • Print machine-readable output with a --json flag
  • Check process.stdout.isTTY before drawing progress bars
  • Use console.table for quick debugging of arrays

Summary

  • log / error — stdout vs stderr
  • table / dir — inspect data
  • styleText — built-in colors
  • stdout.write — output without newline
