The Built-In Test Runner

node:test is a full test framework that ships with Node: test definitions, describe / it suites, hooks, subtests, skipping, mocking, snapshots, coverage, watch mode, and several reporters. Run every test file with node --test. For many projects it replaces Jest or Mocha, with no dependencies to install.

Notes

  • Each test file runs in its own process by default
  • A test fails if it throws or its promise rejects
  • Default files: *.test.js, *-test.js, *_test.js, test/**

Writing Tests

// math.test.js — run: node --test
import { test, describe, it, beforeEach } from 'node:test';
import assert from 'node:assert/strict';
import { add, divide, load } from './math.js';

test('adds numbers', () => {
  assert.equal(add(2, 3), 5);
});

describe('divide', () => {
  beforeEach(() => { /* fresh state before each test */ });
  it('divides', () => assert.equal(divide(6, 3), 2));
  it('throws on zero', () => assert.throws(() => divide(1, 0), /zero/));
  it('loads async data', async () => {
    assert.deepEqual(await load(), { ok: true });
  });
  it.skip('not ready yet', () => {});
});

Code Explained

test / it — the same function under two names
describe — groups tests and scopes hooks
assert/strict — strict equality everywhere
async test — awaited; rejection = failure
it.skip — reported but not run; also it.todo

Running Tests

node --testRun default patterns
node --test 'src/**/*.test.js'Specific files
node --test --watchRe-run on change
--test-name-pattern=divideFilter by name
--test-reporter=dotspec, tap, dot, junit

Hooks

beforeOnce before the suite
beforeEachBefore every test
afterEachAfter every test

Common Mistakes

  • Forgetting await on t.test() or an async assertion; the test passes before checking
  • Shared state between tests without beforeEach; order-dependent failures
  • Leaving it.only in code; with --test-only everything else is skipped

Tips

  • Add "test": "node --test" to package.json scripts
  • Use --test-reporter=junit --test-reporter-destination=junit.xml in CI
  • Keep test files next to the code: user.js and user.test.js

Summary

  • node --test — run all tests
  • test / describe / it — define tests
  • beforeEach — reset state
  • --watch — re-run on change
