Promise Versions of Core Modules

Most core modules expose a promise API under a /promises subpath, so you can write plain async/await code with try/catch. Combine them with the standard Promise combinators to run work in parallel. Since Node 15, an unhandled rejection crashes the process, the same as an uncaught exception.

Notes

  • Import named functions: import { readFile } from 'node:fs/promises'
  • Rejections carry the same err.code values as callbacks
  • events.once() turns an event into a promise

Async / Await with Core APIs

import { readFile, writeFile } from 'node:fs/promises';
import { pipeline } from 'node:stream/promises';
import { once } from 'node:events';

try {
  const cfg = JSON.parse(await readFile('config.json', 'utf8'));
  await writeFile('out.txt', `port=${cfg.port}\n`);
} catch (err) {
  if (err.code === 'ENOENT') console.log('no config yet');  // expected
  else throw err;                                           // unexpected
}

const [a, b] = await Promise.all([readFile('a.txt'), readFile('b.txt')]);
const results = await Promise.allSettled(urls.map(u => fetch(u)));
results.filter(r => r.status === 'rejected').length;       // failure count

await pipeline(src, gzip, dest);          // resolves when the stream finishes
const [req] = await once(server, 'request');   // wait for one event

Code Explained

try/catch — catches rejected awaits
err.code — branch on the error type, rethrow the rest
Promise.all — parallel, fails fast on the first rejection
allSettled — waits for all, never rejects
once() — resolves with the event's args as an array

Common Mistakes

  • Calling an async function without await or .catch(); its error becomes an unhandled rejection
  • Awaiting in a loop when the calls are independent; use Promise.all
  • Swallowing every error in catch; rethrow what you didn't expect

Tips

  • Use allSettled for batch jobs where partial success is fine
  • Mark intentional background promises: void task().catch(log)
  • Lint with no-floating-promises (typescript-eslint)

Summary

  • Promise.all — parallel, fail fast
