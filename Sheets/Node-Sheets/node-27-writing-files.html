Writing & Appending

writeFile() · appendFile() · flags 'w' / 'a' / 'wx' · createWriteStream() · atomic write via rename · mode

Writing Files Safely

writeFile creates or overwrites a file; appendFile adds to the end. The flag option changes that behavior (for example 'wx' fails if the file exists), and mode sets permissions on new files. For files other processes read, write to a temp file and rename it: the rename is atomic, so readers never see half a file.

Notes

  • Parent folders must exist; mkdir({ recursive: true }) first
  • Strings are written as UTF-8 by default
  • rename is atomic only within the same filesystem

Write, Append & Atomic Replace

import { writeFile, appendFile, rename } from 'node:fs/promises';
import { createWriteStream } from 'node:fs';
import { once } from 'node:events';

await writeFile('out.txt', 'hello\n');                // create or overwrite
await writeFile('data.json', JSON.stringify(obj, null, 2));
await appendFile('app.log', `${new Date().toISOString()} start\n`);
await writeFile('new.txt', 'x', { flag: 'wx' });      // EEXIST if present
await writeFile('secret.key', key, { mode: 0o600 });  // owner-only access

await writeFile('config.json.tmp', json);             // atomic replace:
await rename('config.json.tmp', 'config.json');      // all or nothing

const out = createWriteStream('report.csv');          // many small writes
for (const r of rows) {
  if (!out.write(`${r.id},${r.total}\n`)) await once(out, 'drain');
}
out.end();
await once(out, 'finish');                            // all data flushed

Code Explained

null, 2 — pretty-print JSON with 2-space indent
'wx' — create-only; safe for lock files
0o600 — octal permissions (read/write for owner)
write() returns false — buffer full, wait for 'drain'
'finish' — fired after end() flushes everything

Flags

FlagMeaning
wWrite, create/truncate (default)
wxWrite, fail if exists
aAppend, create if missing
axAppend, fail if exists
r+Read/write, must exist

Modes

ModePermissions
0o644Owner rw, others r
0o600Owner rw only
0o755Executable script
0o700Private folder

Common Mistakes

  • Overwriting a config in place; a crash mid-write leaves it corrupted
  • Calling appendFile thousands of times in a loop; each call opens and closes the file
  • Ignoring write()'s return value; memory grows without limit

Tips

  • Use a stream for logs and CSV exports
  • Add a trailing newline to text files so tools like cat and diff behave
  • Write JSON with JSON.stringify(data, null, 2) + '\n'

Summary

  • writeFile — create or replace
  • appendFile — add to the end
  • flag: 'wx' — create only
  • tmp + rename — atomic update
