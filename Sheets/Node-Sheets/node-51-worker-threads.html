Worker Threads

Parallel JavaScript

worker_threads runs JavaScript on additional threads inside the same process, each with its own event loop and V8 isolate. Use them for CPU-heavy work (image processing, parsing, hashing, compression) so the main thread keeps answering requests. They don't help with I/O, which is already non-blocking.

Notes

  • Workers don't share variables; they exchange messages
  • Messages are copied via structured clone
  • Starting a worker costs tens of milliseconds; reuse them

Offloading CPU Work

// main.js
import { Worker } from 'node:worker_threads';

function hashInWorker(text) {
  return new Promise((resolve, reject) => {
    const url = new URL('./hash-worker.js', import.meta.url);
    const w = new Worker(url, { workerData: text });
    w.once('message', resolve);
    w.once('error', reject);
    w.once('exit', (code) => code && reject(new Error(`exit ${code}`)));
  });
}
console.log(await hashInWorker('big input'));   // main thread stayed free

// hash-worker.js
import { parentPort, workerData } from 'node:worker_threads';
import { createHash } from 'node:crypto';
const digest = createHash('sha256').update(workerData).digest('hex');
parentPort.postMessage(digest);

Code Explained

new URL(…, import.meta.url) — worker path relative to this file
workerData — initial input, cloned into the worker
once('message') — first reply resolves the promise
'exit' with non-zero code — worker crashed
parentPort — the worker's line back to the main thread

Common Mistakes

  • Creating a new worker per request; startup cost exceeds the work, so use a pool
  • Moving I/O into workers; it was never blocking the main thread
  • Sending huge objects back and forth; cloning costs more than the computation

Tips

  • Use piscina for a ready-made worker pool
  • Size pools with os.availableParallelism()
  • Transfer ArrayBuffers with transferList instead of copying

Summary

  • Worker — run JS on another thread
  • postMessage — the only way to talk
  • SharedArrayBuffer — opt-in shared memory
  • pool — reuse workers
