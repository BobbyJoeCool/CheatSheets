CommonJS

CommonJS (CJS) is Node's original module system. A file exports by assigning to module.exports and imports with require(), which loads synchronously and returns whatever the other file exported. Each module runs once; later require() calls return the cached result. Most older packages and many configs still use CJS, so you need to read it even if you write ES modules.

Notes

  • A file is CJS if it ends in .cjs, or is .js without "type": "module"
  • require can be called anywhere, even inside if
  • Extension is optional: .js, .json, .node are tried
  • Code is wrapped in a function, so top-level return works

Exporting & Requiring

// math.js
const PI = 3.14159;
function area(r) { return PI * r * r; }
module.exports = { area, PI };            // export an object

// app.js
const { area } = require('./math');       // relative file, extension optional
const fs = require('node:fs');            // core module
const _ = require('lodash');              // package from node_modules
console.log(area(2));                     // 12.56636

exports.hello = () => 'hi';               // ✔ adds to module.exports
exports = { hello: () => 'hi' };          // ✖ rebinds local var only

require.resolve('lodash');                // '/app/node_modules/lodash/lodash.js'
delete require.cache[require.resolve('./math')];  // force reload
if (require.main === module) main();      // true only when run directly

Code Explained

module.exports — the value require returns
exports — a shortcut that points at module.exports
require.resolve — path only, does not load
require.cache — keyed by absolute path
require.main — the entry module

Common Mistakes

  • Assigning exports = …; only module.exports = … replaces the export
  • Circular requires: one side gets a half-filled object; move shared code to a third module
  • Mutating an object from require; every importer shares the same cached instance

Tips

  • Write new code as ESM; use CJS when a tool or config file requires it
  • Use .cjs for a CJS file inside a "type": "module" package
  • Lazy-require heavy modules inside the function that needs them

Summary

  • module.exports — what a file exports
  • require() — synchronous, cached import
  • require.resolve — find a module's path
  • require.main — detect direct execution
