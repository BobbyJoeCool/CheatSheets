WebSockets

global WebSocket client · open / message / close · ws library server · upgrade event · heartbeats

Real-Time Connections

A WebSocket is a long-lived, two-way connection over one TCP socket, upgraded from an HTTP request. Node has a built-in WebSocket client with the browser API. For a server, use the ws package (or a framework plugin built on it). Plan for dropped connections: send periodic pings and terminate sockets that stop answering.

Notes

  • wss:// is WebSocket over TLS
  • Messages are strings or binary; JSON is common
  • Load balancers must allow the HTTP Upgrade

Client (Built In) & Server (ws)

import { WebSocketServer } from 'ws';               // npm i ws

const ws = new WebSocket('wss://echo.example.com');  // client, global
ws.addEventListener('open', () => ws.send(JSON.stringify({ type: 'hi' })));
ws.addEventListener('message', (e) => console.log(JSON.parse(e.data)));
ws.addEventListener('close', (e) => console.log('closed', e.code));

const wss = new WebSocketServer({ port: 8080 });    // server
wss.on('connection', (socket, req) => {
  socket.isAlive = true;
  socket.on('pong', () => { socket.isAlive = true; });
  socket.on('message', (data) => {                   // broadcast
    for (const c of wss.clients)
      if (c.readyState === WebSocket.OPEN) c.send(data);
  });
});

setInterval(() => {                                  // heartbeat
  for (const s of wss.clients) {
    if (!s.isAlive) { s.terminate(); continue; }
    s.isAlive = false; s.ping();
  }
}, 30_000);

Code Explained

addEventListener — same API as browsers
req — the upgrade request: read cookies, auth here
wss.clients — Set of open sockets
ping / pong — detects dead peers
terminate — hard close, no handshake

Common Mistakes

  • Skipping heartbeats; half-open connections pile up until memory runs out
  • Authenticating after connect; check the token during the upgrade request
  • Broadcasting without checking readyState; sends to closing sockets throw

Tips

  • Reconnect clients with exponential backoff
  • Use Redis pub/sub or similar to broadcast across multiple server instances
  • Consider Server-Sent Events for one-way server → client updates

Summary

  • WebSocket — built-in client
  • ws — the standard server package
  • ping / pong — keep connections honest
  • wss:// — always in production
