Directories & Globbing

mkdir({ recursive }) · readdir({ withFileTypes }) · rm({ recursive, force }) · cp() · fs.glob() · opendir()

Working with Directories

fs/promises covers every directory task: create (with recursive for whole paths), list (with withFileTypes to tell files from folders, or recursive for the whole tree), copy, move, and delete. fs.glob matches files by pattern (like src/**/*.test.js), replacing the glob package for most uses.

Notes

  • readdir order is not guaranteed; sort it if order matters
  • rm with recursive deletes without a recycle bin
  • Glob results are relative to cwd unless you pass { cwd }

Create, List, Glob, Delete

import { mkdir, readdir, cp, rename, rm, glob } from 'node:fs/promises';

await mkdir('out/img/thumbs', { recursive: true });   // like mkdir -p
await readdir('src');                                 // ['app.js', 'lib']

const entries = await readdir('src', { withFileTypes: true });
entries.filter((e) => e.isDirectory()).map((e) => e.name);   // ['lib']
await readdir('src', { recursive: true });   // [… 'lib', 'lib/db.js']

for await (const file of glob('src/**/*.test.js')) console.log(file);
const docs = await Array.fromAsync(glob('docs/*.md'));   // array of paths

await cp('template', 'site', { recursive: true });    // copy a folder
await rename('drafts', 'archive/drafts');             // move or rename
await rm('dist', { recursive: true, force: true });   // like rm -rf

Code Explained

recursive on mkdir — creates parents, no error if it exists
withFileTypes — Dirent objects with isFile() / isDirectory()
recursive on readdir — paths relative to the start folder
Array.fromAsync — collects an async iterator
force — no error if the path is missing

Common Mistakes

  • rm({ recursive: true }) on a path built from user input; one bad value deletes the wrong tree
  • mkdir without recursive when parents don't exist → ENOENT
  • Walking huge trees with readdir recursive into one array; use opendir to iterate

Tips

  • Resolve and check paths before deleting (Sheet 30)
  • Use mkdtemp(path.join(os.tmpdir(), 'job-')) for scratch folders
  • Sort listings with names.sort((a, b) => a.localeCompare(b))

Summary

  • mkdir recursive — create whole paths
  • readdir withFileTypes — list with types
  • glob — find files by pattern
  • rm recursive force — delete a tree
