Installing Node

You can install Node from the official installer, a system package manager, or a version manager. A version manager is the best choice for development: it installs Node per user (no sudo), switches versions per project, and reads a pinned version from .nvmrc or .node-version. Every install includes npm and npx.

Notes

  • nvm is macOS / Linux only; nvm-windows is a separate project
  • fnm works on all three OSes and is faster
  • Global npm packages belong to one Node version each
  • Get nvm's install command from github.com/nvm-sh/nvm

Version Manager Workflow

nvm install --lts            # newest LTS release
nvm install 26               # newest 26.x
nvm use 24                   # switch this shell to 24.x
nvm alias default 26         # version for new shells
nvm ls                       # list installed versions
echo "26" > .nvmrc && nvm use   # pin, then use the project version

fnm install 26 && fnm use 26  # same idea with fnm
eval "$(fnm env --use-on-cd)"  # auto-switch when you cd into a project

node -v                      # v26.x.x
npm -v                       # bundled npm version
which node                   # path of the active binary (where on Windows)

Code Explained

--lts — tracks the newest LTS line
use — affects the current shell only
alias default — persists across terminals
.nvmrc — commit it so the team matches
--use-on-cd — put in your shell profile
which node — confirms which install wins on PATH

Common Mistakes

  • Installing with sudo apt install nodejs: distro packages are often several majors behind
  • Mixing a system Node and nvm; whichever is first on PATH wins silently
  • Using sudo npm i -g; fix permissions with a version manager instead

Tips

  • Commit .nvmrc and use the same file in CI setup
  • Add engine-strict=true to .npmrc to make engines an error
  • Reinstall globals on upgrade: nvm install 26 --reinstall-packages-from=24

Summary

  • nvm / fnm — install and switch versions
  • .nvmrc — pins the project's version
  • node -v — verify what's active
  • engines — declares supported versions
