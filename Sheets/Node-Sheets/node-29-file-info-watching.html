File Info & Watching

stat() · lstat() · access() · existence checks · fs.watch() · chmod() · utimes()

Metadata, Permissions & Watching

stat returns a file's metadata: size, type, timestamps, and permissions. Node has no promise-based "exists" function on purpose: checking first and then acting is a race. Instead, just try the operation and handle ENOENT. fs.watch reports changes to files and folders as they happen, as an async iterator in the promise API.

Notes

  • stat follows symlinks; lstat describes the link itself
  • birthtime isn't reliable on every filesystem
  • watch events can arrive twice or with a missing filename

Stat, Access & Watch

import { stat, access, chmod, utimes, watch, constants }
  from 'node:fs/promises';

const s = await stat('photo.jpg');
s.size;              // 482113 (bytes)
s.isFile();          // true
s.isDirectory();     // false
s.mtime;             // 2026-09-30T14:02:11.000Z (last modified)
s.mode.toString(8);  // '100644'

const exists = await stat('x.txt').then(() => true, () => false);
await access('deploy.sh', constants.X_OK);      // throws if not executable
await chmod('deploy.sh', 0o755);
await utimes('a.txt', new Date(), new Date());  // like touch

const ac = new AbortController();
const opts = { recursive: true, signal: ac.signal };
for await (const { eventType, filename } of watch('src', opts)) {
  console.log(eventType, filename);             // 'change' 'app.js'
}

Code Explained

mtime — use for "changed since" checks
mode.toString(8) — permission bits in octal
.then(() => true, () => false) — existence as a boolean
X_OK — check execute permission
signal — stop watching with ac.abort()

Common Mistakes

  • if (exists) await readFile(); the file can vanish in between, so handle ENOENT instead
  • Reacting to every watch event; editors fire several per save, so debounce
  • Comparing mtime with ===; compare mtimeMs numbers

Tips

  • Use stat(p, { throwIfNoEntry: false }) on the sync API to get undefined
  • Use chokidar for cross-platform watching with globbing
  • Use node --watch instead of your own watcher for dev restarts

Summary

  • stat — size, type, times
  • try + ENOENT — the right existence check
  • chmod / access — permissions
  • watch — react to changes
