Buffer Basics

Buffer.from() · alloc() · toString(encoding) · concat() · subarray() · byteLength · utf8 / base64 / hex

Raw Bytes in Node

A Buffer is a fixed-length sequence of bytes, Node's type for binary data: file contents, network packets, images, hashes. It's a subclass of Uint8Array, so every typed-array method works too. Convert between text and bytes with an encoding; the byte length of a string often differs from its character length.

Notes

  • Buffers can't grow; build a list and Buffer.concat it
  • alloc zero-fills; allocUnsafe is faster but may contain old memory
  • subarray shares memory with the original

Creating & Converting Buffers

const a = Buffer.from('héllo', 'utf8');    // <Buffer 68 c3 a9 6c 6c 6f>
a.length;                                  // 6 (bytes, not characters)
'héllo'.length;                            // 5
a.toString();                              // 'héllo'
a.toString('base64');                      // 'aMOpbGxv'
a.toString('hex');                         // '68c3a96c6c6f'
Buffer.from('aGk=', 'base64').toString();  // 'hi'
Buffer.byteLength('héllo');                // 6, without creating a Buffer

Buffer.alloc(4);                           // <Buffer 00 00 00 00>
Buffer.from([1, 2, 255]);                  // <Buffer 01 02 ff>
Buffer.concat([a, Buffer.from('!')]);      // joined copy
const head = a.subarray(0, 2);             // bytes 0–1, same memory
a[0];                                      // 104
a.equals(Buffer.from('héllo'));            // true
a.includes('ll');                          // true
Buffer.isBuffer(a);                        // true

Code Explained

é — two bytes in UTF-8, so length is 6
toString(enc) — decode bytes; default 'utf8'
byteLength — size a string will take on disk or wire
subarray — changing head[0] changes a[0]
equals — compare contents, not identity

Common Mistakes

  • Using string length to size binary data; use Buffer.byteLength
  • Decoding chunks one by one with toString(); a multi-byte character split across chunks becomes �
  • Using slice() and expecting a copy; on Buffers it's a view like subarray

Tips

  • Decode streams with setEncoding('utf8') or TextDecoderStream, which handle split characters
  • Use crypto.timingSafeEqual to compare secrets, not equals
  • Log buffers as hex when debugging protocols

Summary

  • Buffer — fixed bytes, Uint8Array subclass
  • from / toString — text ↔ bytes
  • byteLength — bytes in a string
  • concat / subarray — join and slice
