Sheet 03

Running Node

node file.js · REPL · -e / -p · --watch · --env-file · shebang · node --run

Ways to Run Code

The node command runs a file, evaluates a string, or opens the interactive REPL (Read-Eval-Print Loop). Built-in flags now cover jobs that used to need extra packages: --watch replaces nodemon, --env-file replaces dotenv, and --run runs package.json scripts faster than npm run.

Notes

  • Flags go before the file name; args after it go to process.argv
  • node --run skips pre/post hooks
  • Set default flags for every run with NODE_OPTIONS
  • node --help lists every flag

Common Invocations

node app.js                    # run a script
node app.js --port 8080        # extra args land in process.argv
node                           # open the REPL (Ctrl+D to quit)
node -e "console.log(1 + 1)"   # evaluate: prints 2
node -p "2 ** 10"              # evaluate and print: 1024
node --watch app.js            # restart when imported files change
node --watch-path=src app.js   # watch a specific folder
node --env-file=.env app.js    # load KEY=value pairs into process.env
node --env-file-if-exists=.env.local app.js   # no error if missing
node --run dev                 # run the "dev" script from package.json
node --check app.js            # syntax check only, no execution

#!/usr/bin/env node           # shebang: first line of an executable script
chmod +x cli.js && ./cli.js    # run it directly (macOS / Linux)

Code Explained

-e — runs code, prints nothing by itself
-p — runs code and prints the result
--watch — watches the entry file and its imports
--env-file — repeatable; later files win
--run — adds node_modules/.bin to PATH
shebang — lets the OS find node on PATH

Common Mistakes

  • Putting flags after the file: node app.js --watch passes --watch to your app instead
  • Using -e and expecting output; use -p to print
  • Expecting --watch to see files you read with fs; it tracks imports only

Tips

  • Dev script: "dev": "node --watch --env-file=.env app.js"
  • Use node -p for quick math and JSON checks in the shell
  • Check scripts in CI with node --check before deploying

Summary

  • node file — run a script
  • node — interactive REPL
  • --watch — restart on change
  • --env-file — load env vars
  • --run — run a package script
