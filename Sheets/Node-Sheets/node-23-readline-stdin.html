Reading User Input

node:readline reads text line by line from any readable stream. Its promise API, readline/promises, makes interactive prompts simple: await rl.question(). The same module processes piped input (cat file | node app.js) with for await. Check process.stdin.isTTY to tell whether a person or a pipe is on the other end.

Notes

  • Always rl.close(), or the open stdin keeps the process alive
  • isTTY is undefined (not false) when input is piped
  • crlfDelay: Infinity treats \r\n as one line break

Prompts & Piped Input

import * as readline from 'node:readline/promises';
import { stdin as input, stdout as output } from 'node:process';
import { text } from 'node:stream/consumers';

if (input.isTTY) {                                  // a person is typing
  const rl = readline.createInterface({ input, output });
  const name = await rl.question('Name? ');         // waits for Enter
  const yes = (await rl.question('Continue? (y/N) ')).trim() === 'y';
  rl.close();
} else {                                            // cat data.txt | node app.js
  const rl = readline.createInterface({ input, crlfDelay: Infinity });
  let count = 0;
  for await (const line of rl) if (line.trim()) count++;
  console.log(count);                               // 42
}

const all = await text(process.stdin);              // whole stdin as one string

Code Explained

question() — prints the prompt, resolves with the answer
output — needed for prompts; omit when only reading
for await — one iteration per line, constant memory
text() — collects a whole stream; also json(), buffer()

Common Mistakes

  • Prompting when input is piped; question() reads from the pipe instead of a person
  • Forgetting rl.close(); the program hangs after the last prompt
  • Asking for passwords with question(); it echoes the input to the screen

Tips

  • Support both modes: read stdin when piped, prompt when interactive
  • For rich prompts (select lists, hidden input) use @inquirer/prompts
  • Handle Ctrl+C: rl.on('SIGINT', () => process.exit(130))

Summary

  • readline/promises — awaitable prompts
  • for await — lines from any stream
  • isTTY — interactive or piped
  • stream/consumers — read a whole stream
