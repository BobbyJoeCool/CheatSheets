Sheet 53

Measuring Performance

perf_hooks · performance.now() · mark() / measure() · monitorEventLoopDelay() · --cpu-prof · flame graphs

Finding What's Slow

Measure before optimizing. performance.now() and marks/measures time specific code. Event loop delay tells you whether the main thread is blocked, the most common cause of a slow Node server. For "where does the time go?", record a CPU profile and read it as a flame graph in Chrome DevTools.

Notes

  • performance.now() is monotonic; Date.now() can jump
  • Event loop delay above ~100 ms means users notice
  • Profile production-like builds; dev mode skews results

Timing & Loop Health

import { performance, monitorEventLoopDelay } from 'node:perf_hooks';

const t0 = performance.now();
await work();
console.log(`${(performance.now() - t0).toFixed(1)} ms`);   // 41.7 ms

performance.mark('start'); await work(); performance.mark('end');
performance.measure('work', 'start', 'end').duration;      // 41.7

const h = monitorEventLoopDelay({ resolution: 20 });
h.enable();
setInterval(() => {
  console.log('p99 delay', (h.percentile(99) / 1e6).toFixed(1), 'ms');
  h.reset();
}, 10_000).unref();

performance.eventLoopUtilization().utilization;   // 0.37 (37% busy)
const timed = performance.timerify(slowFn);       // records each call

Code Explained

mark / measure — named spans, visible in profilers
monitorEventLoopDelay — histogram in nanoseconds
/ 1e6 — nanoseconds → milliseconds
eventLoopUtilization — near 1 means CPU-bound
timerify — wraps a function to time every call

Common Mistakes

  • Optimizing on a hunch; most time is usually in one or two functions
  • Benchmarking a single run; JIT warm-up dominates, so run many iterations
  • Measuring with Date.now(); millisecond resolution and clock jumps

Tips

  • Export loop delay and ELU as metrics (Sheet 58)
  • Use autocannon to load-test an HTTP endpoint
  • Profile under realistic load, not with one request

Summary

  • performance.now — precise timing
  • monitorEventLoopDelay — blocked-loop detector
  • ELU — how busy the main thread is
  • --cpu-prof — flame-graph profiles
