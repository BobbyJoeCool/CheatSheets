Transforming and Updating Maps

Maps have functional operations that return new maps: mapValues, mapKeys, filterKeys, filterValues, and +/- for adding or removing entries. On mutable maps, getOrPut returns the existing value or inserts a computed one, which makes caches and groupings short.

Key Points

  • mapValues { (k, v) -> } gets each entry
  • getOrPut computes the value only when missing
  • + (k to v) returns a new map with the entry
  • withDefault changes only getValue, not []

Map Transformations

val prices = mapOf("tea" to 3.5, "cake" to 4.0, "pie" to 5.25)

println(prices.mapValues { (_, p) -> p * 1.06 })   // taxed prices
println(prices.mapKeys { it.key.uppercase() })     // {TEA=…, CAKE=…, PIE=…}
println(prices.filterValues { it > 4.0 })          // {pie=5.25}
println(prices.filterKeys { it.startsWith("c") })  // {cake=4.0}
println(prices + ("coffee" to 2.0))                // new map with coffee
println(prices - "tea")                            // new map without tea
println(prices.maxBy { it.value }.key)             // pie
println(prices.entries.sortedBy { it.value }.map { it.key })
// [tea, cake, pie]

val cache = mutableMapOf<Int, String>()
fun lookup(id: Int) = cache.getOrPut(id) { loadName(id) }   // load once

val wordsByLetter = mutableMapOf<Char, MutableList<String>>()
for (w in listOf("apple", "avocado", "banana")) {
    wordsByLetter.getOrPut(w.first()) { mutableListOf() }.add(w)
}
println(wordsByLetter)              // {a=[apple, avocado], b=[banana]}

val config = buildMap {
    put("env", "prod")
    if (debug) put("log", "verbose")
}

val counts = mutableMapOf<String, Int>()
counts.merge("x", 1, Int::plus); counts.merge("x", 1, Int::plus)
println(counts)                     // {x=2}

Code Explained

mapValues keeps keys and transforms values
getOrPut avoids "check, then put" boilerplate
buildMap creates a read-only map with conditional entries
merge is Java's map API, usable directly

Java Equivalent

  • map.computeIfAbsent(k, key -> new ArrayList<>()).add(w)
  • map.entrySet().stream().collect(toMap(…)) for transforms
  • map.merge("x", 1, Integer::sum)

Idiomatic Kotlin

  • if (!m.containsKey(k)) m[k] = …; m[k]!! → m.getOrPut(k) { … }
  • stream collectors on maps → mapValues / filterValues

⚠ Common Mistakes

  • Using mapKeys where keys collide (later ones overwrite)
  • Expecting withDefault to affect map[key]
  • Mutating a map while iterating its entries

✓ Tips & Best Practices

  • Use getOrPut for memoization and grouping
  • Use groupBy (sheet 53) when building lists per key
  • Convert with toSortedMap() for ordered output
