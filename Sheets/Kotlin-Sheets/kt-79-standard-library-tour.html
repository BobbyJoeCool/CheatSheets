Standard Library Tour

kotlin.math · kotlin.random.Random · kotlin.time.Duration · measureTime { } · kotlinx-datetime · java.time interop

Everyday Utilities

The Kotlin standard library covers math (kotlin.math), randomness (Random), durations and timing (kotlin.time), plus text, collections and I/O helpers. Dates on the JVM use java.time directly; multiplatform code uses kotlinx-datetime.

Key Points

  • Duration literals: 5.seconds, 250.milliseconds
  • measureTime { } returns a Duration; measureTimedValue adds the result
  • Random(seed) gives repeatable sequences
  • kotlinx-datetime is a separate dependency

Math, Random, Time

import kotlin.math.*
import kotlin.random.Random
import kotlin.time.*
import kotlin.time.Duration.Companion.minutes
import kotlin.time.Duration.Companion.seconds
import java.time.*

println(hypot(3.0, 4.0))                  // 5.0
println(log2(1024.0))                     // 10.0
println(round(2.5))                       // 2.0 (half to even)
println(abs(-7))                          // 7

println(Random.nextInt(1, 7))             // 1..6
println(listOf("a", "b", "c").random())   // random element
val seeded = Random(42)                   // repeatable sequence

val timeout = 2.minutes + 30.seconds
println(timeout)                          // 2m 30s
println(timeout.inWholeSeconds)           // 150

val elapsed = measureTime { Thread.sleep(100) }
println(elapsed)                          // ~100ms
val (sum, took) = measureTimedValue { (1..1_000_000).sum() }

val due = LocalDate.of(2026, 11, 12).plusDays(30)
println(due)                              // 2026-12-12
println(Duration.between(LocalTime.of(9, 0), LocalTime.of(17, 30)))   // PT8H30M
val zoned = ZonedDateTime.now(ZoneId.of("America/Chicago"))
println(timeout.toJavaDuration())         // PT2M30S

Code Explained

kotlin.math functions are top-level, no Math. prefix
Duration arithmetic reads like English
measureTimedValue returns the result and the time
toJavaDuration() bridges to java.time.Duration

Java Equivalent

  • Math.hypot, ThreadLocalRandom.current().nextInt(1, 7)
  • Duration.ofMinutes(2).plusSeconds(30)
  • System.nanoTime() before and after for timing

Idiomatic Kotlin

  • Long milliseconds everywhere → kotlin.time.Duration
  • System.currentTimeMillis() timing → measureTime { }

⚠ Common Mistakes

  • Using java.util.Date in new code
  • Expecting round(2.5) to be 3.0
  • Raw Long timeouts with unclear units

✓ Tips & Best Practices

  • Use Duration for timeouts and delays (coroutines accept it)
  • Seed Random in tests for repeatable results
  • Use java.time on the JVM; it is excellent
