Sheet 09

Integers

Int / Long / Short / Byte · literals 1_000 0xFF 0b1010 10L · UInt / ULong unsigned · Int.MAX_VALUE · overflow wraps

Whole-Number Types

Kotlin has Byte, Short, Int and Long, plus unsigned versions (UByte, UShort, UInt, ULong). Integer literals default to Int, or Long if they are too big or end in L. All numbers are objects in the type system, but compile to Java primitives where possible.

Key Points

  • Underscores improve readability: 1_000_000
  • Hex 0xFF and binary 0b1010; no octal literals
  • Overflow wraps silently, like Java
  • Use Math.addExact or BigInteger when overflow matters

Under the JVM

  • val x: Int = 5 compiles to a primitive int
  • Int? and List<Int> use boxed java.lang.Integer
  • UInt is an inline value class over Int (sheet 65)

Integer Types and Literals

val a = 42                    // Int
val big = 3_000_000_000       // Long (too big for Int)
val l = 42L                   // Long
val b: Byte = 127
val s: Short = 30_000
val hex = 0xFF                // 255
val bin = 0b1010              // 10
val u = 42u                   // UInt
val ul = 18_000_000_000uL     // ULong

println(Int.MAX_VALUE)        // 2147483647
println(Int.MAX_VALUE + 1)    // -2147483648 (wraps)
println(Math.addExact(Int.MAX_VALUE, 1))  // ArithmeticException
println(7 / 2)                // 3 (integer division)
println(7 % 2)                // 1
println(255.toString(16))     // ff
println("ff".toInt(16))       // 255
val boxed: Int? = 42          // java.lang.Integer

Code Explained

A literal larger than Int.MAX_VALUE becomes Long automatically
u and uL suffixes make unsigned literals
Integer division drops the remainder
toString(radix) and toInt(radix) convert bases

Java Equivalent

  • int, long, short, byte primitives; Integer wrappers
  • 42L, 0xFF, 0b1010, and octal 017 (no octal in Kotlin)
  • No unsigned types; use Integer.toUnsignedString helpers

Idiomatic Kotlin

  • Integer.parseInt(s) → s.toInt() / s.toIntOrNull()
  • magic big numbers → underscores 1_000_000

⚠ Common Mistakes

  • Expecting 017 to be octal (Kotlin has no octal literals)
  • Silent overflow in totals that should use Long
  • Comparing boxed Int? values with === (identity, not value)

✓ Tips & Best Practices

  • Use Long for IDs, counts of records and millisecond times
  • Use Math.*Exact when overflow must be an error
  • Use unsigned types only for bit-level or protocol work

Quick Summary

  • Int default, Long with L
  • 1_000 — readable literals
  • u / uL — unsigned
  • overflow wraps silently
