Objects & Companion Objects

object singletons · companion object · @JvmStatic · factory methods · object expressions (anonymous) · data object

Singletons and Class-Level Members

An object declaration creates a singleton: one instance, created lazily on first use. A companion object inside a class holds members called on the class itself, replacing Java static. Object expressions create anonymous objects, such as one-off listener implementations.

Key Points

  • Objects can extend classes and implement interfaces
  • Companion members: Config.load() — no instance needed
  • A companion can be named and can implement interfaces
  • Object expressions can capture local variables

Under the JVM

  • object Registry compiles to a class with a static INSTANCE field
  • A companion becomes a static nested Companion class; members are called through it
  • @JvmStatic adds a real static method so Java can call Config.load()

object, companion, anonymous

object Registry {                             // singleton
    private val items = mutableMapOf<String, Int>()
    fun register(name: String, value: Int) { items[name] = value }
    fun count() = items.size
}
Registry.register("a", 1)
println(Registry.count())                     // 1

class User private constructor(val name: String) {
    companion object {
        const val MAX_NAME = 50
        @JvmStatic fun create(name: String): User {   // factory
            require(name.length <= MAX_NAME)
            return User(name.trim())
        }
    }
}
val u = User.create(" Ada ")                  // called on the class
println(User.MAX_NAME)                        // 50

interface Listener { fun onEvent(e: String) }
var events = 0
val listener = object : Listener {            // object expression
    override fun onEvent(e: String) { events++; println("got $e") }
}
listener.onEvent("click")

val point = object { val x = 1; val y = 2 }   // ad-hoc object (local use)
println(point.x + point.y)                    // 3

sealed interface Cmd { data object Quit : Cmd }   // data object: nice toString
println(Cmd.Quit)                             // Quit

Code Explained

Registry exists once and is created on first access
User.create acts like a static factory
@JvmStatic lets Java call User.create(…) directly
The anonymous listener can update the captured events var

Java Equivalent

  • Singleton: enum Registry { INSTANCE; } or a static holder class
  • static fields and methods on the class
  • Anonymous classes: new Listener() { … }

Idiomatic Kotlin

  • static utility classes → object or top-level functions
  • Java-style getInstance() singletons → object

⚠ Common Mistakes

  • Putting mutable global state in objects without thread safety
  • Calling companion members from Java without @JvmStatic (needs User.Companion.create)
  • Using objects where dependency injection would be easier to test

✓ Tips & Best Practices

  • Use companion objects for factories and constants
  • Add @JvmStatic / @JvmField for Java callers
  • Prefer top-level functions over objects for stateless helpers
