Sheet 84

async & Structured Concurrency

async / await · awaitAll · coroutineScope · Job · parent-child cancellation · CoroutineScope

Results and Lifetimes

async starts a coroutine that returns a value through a Deferred; await() gets it. Structured concurrency means every coroutine runs inside a scope: a parent waits for its children, and if one child fails, the others are cancelled. coroutineScope { } creates such a scope inside a suspend function.

Key Points

  • Start several asyncs, then await them to run in parallel
  • coroutineScope returns only when all children finish
  • A failed child cancels its siblings and the parent
  • Never use GlobalScope in application code

Parallel Calls in a Scope

import kotlinx.coroutines.*

suspend fun loadDashboard(userId: Int): Dashboard = coroutineScope {
    val profile = async { api.profile(userId) }     // starts now
    val orders  = async { api.orders(userId) }      // runs in parallel
    val alerts  = async { api.alerts(userId) }
    Dashboard(profile.await(), orders.await(), alerts.await())
}   // returns after all three, or fails fast if any fails

suspend fun prices(skus: List<String>): List<Double> = coroutineScope {
    skus.map { sku -> async { api.price(sku) } }.awaitAll()
}

class ReportService {
    private val scope = CoroutineScope(SupervisorJob() + Dispatchers.Default)

    fun start(): Job = scope.launch {
        while (isActive) { refresh(); delay(60_000) }
    }
    fun shutdown() = scope.cancel()              // cancels every child
}

fun main() = runBlocking {
    val time = kotlin.time.measureTime { println(loadDashboard(7)) }
    println("took $time")                        // ≈ slowest call, not the sum
}

Code Explained

Three asyncs run at once; total time is the slowest call
If orders throws, profile and alerts are cancelled
awaitAll waits for a list of Deferreds
A class-owned scope lets you cancel all its work on shutdown

Java Equivalent

  • CompletableFuture.allOf(a, b, c).join() then a.join()…
  • Structured concurrency preview: StructuredTaskScope (Java 21+ preview)
  • ExecutorService futures do not cancel siblings automatically

Idiomatic Kotlin

  • GlobalScope.launch → a scope tied to a lifecycle (or coroutineScope)
  • sequential awaits right after each async → start all, then await

⚠ Common Mistakes

  • async { }.await() immediately (no parallelism)
  • Launching from GlobalScope and leaking work
  • Forgetting to cancel class-level scopes

✓ Tips & Best Practices

  • Use coroutineScope inside suspend functions that fan out
  • Use framework scopes: viewModelScope, Ktor call scope, Spring coroutines
  • Use supervisorScope when one failure should not stop the rest (sheet 87)

Quick Summary

  • async / await — results
  • coroutineScope — structured
  • child failure cancels siblings
  • no GlobalScope
