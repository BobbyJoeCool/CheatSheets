Extension Functions & Properties

fun String.shout() · this receiver · extension properties · nullable receivers · resolved statically · extensions on companions

Adding Functions to Existing Types

An extension function adds a function to a type you do not own, such as String or a Java class, without inheritance. Inside, this is the receiver object. Extensions are resolved statically by the declared type, and they cannot reach private members.

Key Points

  • Most of the Kotlin standard library is extensions
  • Extensions on nullable types can be called on null
  • Members win over extensions with the same signature
  • Extension properties need a getter; they have no backing field

Under the JVM

  • fun String.shout() compiles to static String shout(String $this) in FileNameKt
  • No method is added to the real class
  • Static dispatch: the declared type picks the extension, not the runtime type

Extensions in Action

fun String.shout(): String = uppercase() + "!"          // this = the String
println("hello".shout())                                 // HELLO!

fun Int.isEven() = this % 2 == 0
println(4.isEven())                                      // true

val String.wordCount: Int                                // extension property
    get() = trim().split(Regex("\\s+")).size
println("one two three".wordCount)                       // 3

fun String?.orDash(): String = if (isNullOrBlank()) "-" else this
val missing: String? = null
println(missing.orDash())                                // -

fun <T> List<T>.second(): T = this[1]
println(listOf(1, 2, 3).second())                        // 2

open class Shape; class Circle : Shape()
fun Shape.name() = "shape"
fun Circle.name() = "circle"
val s: Shape = Circle()
println(s.name())                                        // shape (static type)

class Temp { companion object }
fun Temp.Companion.fromF(f: Double) = (f - 32) * 5 / 9
println(Temp.fromF(212.0))                               // 100.0

Code Explained

Call extensions like members: "hello".shout()
A nullable receiver lets missing.orDash() work on null
Generic extensions work on any List<T>
s.name() uses the declared type Shape, not the runtime Circle

Java Equivalent

  • Static helpers: StringUtils.shout(s)
  • Utility classes like Collections.sort(list)
  • Java has no extension methods

Idiomatic Kotlin

  • Utils.format(date) static helpers → date.format() extensions
  • extensions that need private state → member functions

⚠ Common Mistakes

  • Expecting virtual dispatch on extensions
  • Defining an extension that a member already provides (member wins)
  • Scattering extensions across many files with no structure

✓ Tips & Best Practices

  • Group extensions by receiver type in files like StringExt.kt
  • Use nullable receivers for safe helpers like orEmpty
  • Keep extensions small and obvious
