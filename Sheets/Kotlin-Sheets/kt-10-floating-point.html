Floating-Point Numbers

Double / Float · 1.5f · NaN / POSITIVE_INFINITY · roundToInt() · kotlin.math · BigDecimal for money

Decimals and Their Limits

Double (64-bit) is the default for decimal literals; Float (32-bit) needs an f suffix. Both are binary floating point, so values like 0.1 are approximate. Use kotlin.math for math functions and BigDecimal for money and other exact decimal work.

Key Points

  • 1.5 is Double; 1.5f is Float
  • No implicit widening: val d: Double = 1 is an error
  • 0.1 + 0.2 == 0.3 is false
  • Division by zero gives Infinity or NaN, not an exception

Doubles, Rounding and BigDecimal

import kotlin.math.*
import java.math.BigDecimal
import java.math.RoundingMode

val d = 3.14                     // Double
val f = 2.5f                     // Float
val e = 1.2e3                    // 1200.0

println(0.1 + 0.2)               // 0.30000000000000004
println(abs(0.1 + 0.2 - 0.3) < 1e-9)   // true
println(1.0 / 0)                 // Infinity
println(0.0 / 0)                 // NaN
println(Double.NaN == Double.NaN)       // false
println(2.567.roundToInt())      // 3
println(floor(2.7))              // 2.0
println(sqrt(16.0))              // 4.0
println(2.0.pow(10))             // 1024.0
println("%.2f".format(2.567))    // 2.57

val price = BigDecimal("19.99")
val tax = (price * BigDecimal("0.06")).setScale(2, RoundingMode.HALF_UP)
println(tax)                     // 1.20

Code Explained

Compare doubles with a tolerance, not ==
roundToInt() rounds halves up: 2.5 → 3, -2.5 → -2
BigDecimal("19.99") from a String keeps the exact value
Kotlin overloads * for BigDecimal

Java Equivalent

  • double / float; Math.round, Math.sqrt, Math.pow
  • new BigDecimal("19.99").multiply(rate).setScale(2, HALF_UP)
  • Double.isNaN(x) to test for NaN

Idiomatic Kotlin

  • Math.sqrt(x) → sqrt(x) from kotlin.math
  • BigDecimal(19.99) (from a double) → BigDecimal("19.99")

⚠ Common Mistakes

  • Money in Double, producing rounding errors
  • Expecting round(2.5) (kotlin.math) to give 3.0 (it rounds half to even)
  • Assigning an Int literal to a Double variable without .0

✓ Tips & Best Practices

  • Use BigDecimal with string constructors for currency
  • Use roundToInt() / roundToLong() for display rounding
  • Use compareTo for BigDecimal equality when scale differs
