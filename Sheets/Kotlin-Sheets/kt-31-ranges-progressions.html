Ranges & Progressions

IntRange · CharRange · in checks · reversed() · step · first / last · coerceIn

Ranges as Values

A range like 1..10 is an object (IntRange) with a start and end, not just loop syntax. Ranges support in checks, step and reversed() (which produce progressions), and collection-style functions such as map, sum and filter. They exist for Int, Long, Char and any Comparable.

Key Points

  • a..b is closed; a..<b is open-ended
  • Empty if start > end: 5..1 has no elements
  • step must be positive; use downTo to go backward
  • Comparable ranges ("a".."m") support in but not iteration

Working with Ranges

val r = 1..10
println(r.first)                  // 1
println(r.last)                   // 10
println(5 in r)                   // true
println(11 !in r)                 // true
println(r.count())                // 10
println(r.sum())                  // 55
println(r.filter { it % 3 == 0 }) // [3, 6, 9]

val odd = 1..10 step 2
println(odd.toList())             // [1, 3, 5, 7, 9]
println((1..5).reversed().toList())   // [5, 4, 3, 2, 1]
println((5..1).isEmpty())         // true

val letters = 'a'..'e'
println(letters.joinToString(""))  // abcde
println('c' in letters)           // true

val versions = "1.0".."2.5"       // ClosedRange<String>
println("1.8" in versions)        // true (string compare)

val age = 130
println(age.coerceIn(0..120))     // 120
println((1..6).random())          // random die roll

Code Explained

Ranges have properties like first, last and count()
step 2 turns a range into a progression
5..1 is empty; use 5 downTo 1 to count down
random() picks a random element of the range

Java Equivalent

  • IntStream.rangeClosed(1, 10) for a stream of numbers
  • x >= 1 && x <= 10 for range checks
  • ThreadLocalRandom.current().nextInt(1, 7) for dice

Idiomatic Kotlin

  • x >= lo && x <= hi → x in lo..hi
  • 5..1 expecting a countdown → 5 downTo 1

⚠ Common Mistakes

  • Writing 5..1 and getting zero iterations
  • Negative step (throws)
  • Iterating a String range (not iterable)

✓ Tips & Best Practices

  • Use ranges in when branches
  • Use coerceIn(range) for limits
  • Use ..< for sizes and indexes

Quick Summary

  • a..b — closed range
  • ..< — exclusive end
  • step / downTo
  • in — membership
