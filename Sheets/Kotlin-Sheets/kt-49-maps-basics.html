Maps — Basics

mapOf("a" to 1) · mutableMapOf · map[key] · getValue · getOrDefault · entries / keys / values · for ((k, v) in map)

Key-Value Pairs

Maps store values by key. Build them with mapOf(key to value) (read-only) or mutableMapOf(). map[key] returns the value or null, so lookups are null-safe by type. getValue(key) throws if the key is missing, and getOrDefault supplies a fallback.

Key Points

  • mapOf / mutableMapOf keep insertion order (LinkedHashMap)
  • map[key] = value adds or replaces in a MutableMap
  • Iterate with destructuring: for ((k, v) in map)
  • Keys rely on equals/hashCode

Creating and Reading Maps

val prices = mapOf("tea" to 3.5, "cake" to 4.0, "pie" to 5.25)

println(prices["tea"])                   // 3.5
println(prices["coffee"])                // null
println(prices["coffee"] ?: 0.0)         // 0.0
println(prices.getOrDefault("coffee", 1.0))   // 1.0
println(prices.getValue("cake"))         // 4.0
// prices.getValue("coffee")             // NoSuchElementException
println("pie" in prices)                 // true (containsKey)
println(prices.containsValue(4.0))       // true
println(prices.keys)                     // [tea, cake, pie]
println(prices.values)                   // [3.5, 4.0, 5.25]
println(prices.size)                     // 3

for ((item, price) in prices) println("$item: $price")

val stock = mutableMapOf<String, Int>()
stock["apple"] = 10                      // add
stock["apple"] = 12                      // replace
stock["pear"] = 4
stock.remove("pear")
println(stock)                           // {apple=12}

val byLength = listOf("a", "bb", "cc").associateBy { it.length }  // {1=a, 2=cc}

Code Explained

"tea" to 3.5 builds a Pair used as an entry
map[key] returns a nullable type, forcing a decision on missing keys
in checks keys, not values
associateBy builds a map from a list (later duplicates win)

Java Equivalent

  • Map.of("tea", 3.5, "cake", 4.0) (immutable)
  • map.get(key) returns null silently; Kotlin's type shows it
  • for (var e : map.entrySet()) with getKey() / getValue()

Idiomatic Kotlin

  • if (map.containsKey(k)) map[k]!! → map[k] ?: default
  • map.put(k, v) → map[k] = v

⚠ Common Mistakes

  • Using !! on map[key] instead of handling missing keys
  • Expecting in to search values
  • Duplicate keys in mapOf (the last one wins silently)

✓ Tips & Best Practices

  • Use getValue when a missing key is a bug
  • Use associate/associateBy/groupBy to build maps from lists
  • Expose Map, not MutableMap, from classes

Quick Summary

  • mapOf(k to v) — build
  • map[k] — nullable lookup
  • getValue — must exist
  • for ((k, v) in map) — iterate
