Writing Files and Working with Paths

writeText replaces a file's contents and appendText adds to it. For many lines, write through printWriter().use { } or bufferedWriter().use { }. The kotlin.io.path package adds Kotlin-style helpers to NIO Path, including the / operator for joining paths.

Key Points

  • writeText creates the file if needed (parent folders must exist)
  • Path / "child" joins segments
  • walk() lists a directory tree (marked experimental in older versions)
  • Use createDirectories() before writing to new folders

Writing and Paths

import java.io.File
import kotlin.io.path.*

File("out.txt").writeText("Hello\n")              // overwrite
File("out.txt").appendText("More\n")              // append

File("report.txt").printWriter().use { out ->
    out.println("Report")
    listOf("a", "b").forEach { out.println(" - $it") }
}

val base = Path("build") / "reports" / "2026"      // build/reports/2026
base.createDirectories()
val file = base / "summary.csv"
file.writeLines(listOf("id,total", "1,12.50"))
println(file.fileName)                             // summary.csv
println(file.extension)                            // csv
println(file.nameWithoutExtension)                 // summary
println(file.parent)                               // build/reports/2026
println(file.exists() && file.isRegularFile())     // true
println(file.fileSize())                           // bytes

Path("src").walk()
    .filter { it.extension == "kt" }
    .forEach { println(it) }

Path("build/tmp/x.txt").deleteIfExists()
File("old").deleteRecursively()                    // careful
file.copyTo(base / "backup.csv", overwrite = true)

Code Explained

use closes the writer even if writing fails
/ on Path joins folders and files
extension and nameWithoutExtension parse the name
deleteRecursively() removes a whole folder tree

Java Equivalent

  • Files.writeString(path, text) / StandardOpenOption.APPEND
  • Path.of("build", "reports", "2026") / resolve("x")
  • Files.walk(path) stream; Files.createDirectories(path)

Idiomatic Kotlin

  • string concatenation for paths → Path("a") / "b"
  • File APIs in new code → Path + kotlin.io.path

⚠ Common Mistakes

  • Writing to a folder that does not exist yet
  • Using writeText in a loop (rewrites the file each time)
  • Running deleteRecursively on the wrong path

✓ Tips & Best Practices

  • Create parent folders with parent?.createDirectories()
  • Write to a temp file then move it for safe replacement
  • Use Files.newBufferedWriter options for append/create flags
