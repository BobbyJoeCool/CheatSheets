Sheet 03

Building with Gradle

kotlin("jvm") plugin · jvmToolchain(21) · application plugin · ./gradlew run / build · src/main/kotlin · Maven plugin note

A Standard Kotlin Project

Kotlin projects are built with Gradle, usually with the Kotlin DSL (build.gradle.kts). The kotlin("jvm") plugin compiles Kotlin, jvmToolchain pins the JDK, and the application plugin adds a run task. Source goes in src/main/kotlin and tests in src/test/kotlin.

Key Points

  • gradle init can generate a Kotlin application
  • The wrapper (./gradlew) pins the Gradle version
  • Java and Kotlin can live in the same module
  • Maven works too with kotlin-maven-plugin

build.gradle.kts

plugins {
    kotlin("jvm") version "2.2.0"
    application
}

repositories {
    mavenCentral()
}

dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.10.2")
    testImplementation(kotlin("test"))
}

kotlin {
    jvmToolchain(21)
}

application {
    mainClass.set("com.example.AppKt")   // file App.kt
}

tasks.test {
    useJUnitPlatform()
}

// ./gradlew run      ./gradlew build      ./gradlew test

Code Explained

kotlin("jvm") applies the Kotlin JVM plugin at that version
mainClass is AppKt because top-level functions in App.kt compile to class AppKt
kotlin("test") adds kotlin.test wired to JUnit
Version numbers are examples; use current releases

Java Equivalent

  • plugins { id("java"); application } in Gradle
  • Maven: pom.xml with maven-compiler-plugin
  • java { toolchain { languageVersion = JavaLanguageVersion.of(21) } }

Idiomatic Kotlin

  • Groovy build.gradle → Kotlin DSL build.gradle.kts
  • hard-coded versions in many files → a version catalog (sheet 76)

⚠ Common Mistakes

  • mainClass set to App instead of AppKt for a top-level main
  • Kotlin plugin and kotlinx library versions that do not match
  • Forgetting useJUnitPlatform(), so tests never run

✓ Tips & Best Practices

  • Start with gradle init --type kotlin-application
  • Pin the JDK with jvmToolchain rather than relying on your machine
  • See the Gradle set for multi-module builds

Quick Summary

  • kotlin("jvm") — plugin
  • jvmToolchain — JDK version
  • AppKt — main class name
  • ./gradlew run — run it
