Higher-Order Functions & Function Types

(Int) -> Int · nullable function types · ::functionRef · returning functions · T.() -> Unit receivers · typealias for function types

Functions That Take or Return Functions

A higher-order function takes another function as a parameter or returns one. Function types are written (A, B) -> R. A function type with a receiver, T.() -> R, lets the lambda use this as a T, which is how builders like apply and DSLs work.

Key Points

  • () -> Unit takes nothing and returns nothing useful
  • ((Int) -> Int)? is a nullable function; call with f?.invoke(x)
  • Function references (::name) can be passed where a function type is expected
  • Name long function types with typealias

Taking and Returning Functions

fun applyTwice(x: Int, f: (Int) -> Int): Int = f(f(x))
println(applyTwice(3) { it * 2 })           // 12

fun makeMultiplier(factor: Int): (Int) -> Int = { it * factor }
val triple = makeMultiplier(3)
println(triple(5))                          // 15

fun measure(label: String, block: () -> Unit) {
    val start = System.nanoTime()
    block()
    println("$label took ${(System.nanoTime() - start) / 1_000_000} ms")
}
measure("sort") { (1..100_000).shuffled().sorted() }

fun retry(
    times: Int,
    onError: ((Exception) -> Unit)? = null,
    action: () -> Unit
) {
    repeat(times) {
        try { action(); return } catch (e: Exception) { onError?.invoke(e) }
    }
}

fun html(build: StringBuilder.() -> Unit): String =
    StringBuilder().apply(build).toString()
println(html { append("<b>"); append("hi"); append("</b>") })  // <b>hi</b>

typealias Validator = (String) -> Boolean
val notBlank: Validator = { it.isNotBlank() }
fun isEven(n: Int) = n % 2 == 0
println(listOf(1, 2, 3).filter(::isEven))   // [2]

Code Explained

applyTwice receives a function and calls it twice
makeMultiplier returns a lambda that remembers factor
Inside html { … }, this is the StringBuilder
::isEven passes an existing function

Java Equivalent

  • Function<Integer,Integer>, Supplier<T>, Runnable, BiFunction
  • Returning lambdas: IntUnaryOperator mult(int f) { return x -> x * f; }
  • list.stream().filter(Main::isEven)

Idiomatic Kotlin

  • (String) -> Boolean repeated everywhere → typealias Validator
  • interfaces with one method for callbacks → function types

⚠ Common Mistakes

  • Calling a nullable function type directly (needs ?.invoke)
  • Overly long function type signatures with no alias
  • Returning lambdas that capture large objects by accident

✓ Tips & Best Practices

  • Put the function parameter last so callers can use trailing lambdas
  • Mark small higher-order functions inline (sheet 43)
  • Use receivers for builder-style APIs
