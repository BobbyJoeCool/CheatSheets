Printing and Reading Lines

println writes a value and a newline; print skips the newline. String templates put values straight into strings with $name or ${expression}. readln() reads a line from standard input and throws at end of input, while readlnOrNull() returns null instead.

Key Points

  • println accepts any type and calls toString()
  • Use ${} for anything more than a simple name
  • Write errors with System.err.println
  • readln() was added in Kotlin 1.6, replacing readLine()!!

Output and Input

val name = "Ada"
val items = listOf(3, 5, 8)

println("Hello")                       // Hello
print("No newline ")
println("then newline")                // No newline then newline
println("Hi, $name")                   // Hi, Ada
println("Total: ${items.sum()}")       // Total: 16
println("Name has ${name.length} chars")
println("Price: %.2f".format(19.5))    // Price: 19.50
println(items)                         // [3, 5, 8]
System.err.println("Warning: low stock")

print("Your age? ")
val age = readln().toInt()             // throws if not a number
val line = readlnOrNull()              // null at end of input
val safe = readln().toIntOrNull() ?: 0 // 0 if not a number

Code Explained

$name inserts a variable; ${…} inserts any expression
"%.2f".format(x) uses Java's String.format rules
Collections print in readable form
toIntOrNull() avoids a crash on bad input

Java Equivalent

  • System.out.println("Hi, " + name);
  • String.format("Price: %.2f", 19.5) or "…".formatted(19.5)
  • new Scanner(System.in).nextLine() / BufferedReader.readLine()

Idiomatic Kotlin

  • "Hi, " + name → "Hi, $name"
  • readLine()!! → readln()

⚠ Common Mistakes

  • "$user.name" prints the user object followed by ".name" (use ${user.name})
  • readln().toInt() crashing on empty or bad input
  • Using templates to build SQL (injection risk)

✓ Tips & Best Practices

  • Use a logger (SLF4J, kotlin-logging) instead of println in apps
  • Use raw strings """…""" for multi-line output
  • Prefer toIntOrNull() for any user input

Quick Summary
