Aggregation & Grouping

sum / sumOf · count · fold / reduce · groupBy · partition · maxByOrNull / minOf · groupingBy().eachCount()

Summarizing Collections

Aggregations reduce a collection to one value: sumOf, count, average, maxOf, or a custom fold. groupBy turns a list into a map of lists by key, and groupingBy with eachCount() or fold aggregates each group without building the lists.

Key Points

  • reduce throws on empty collections; fold takes a start value
  • maxByOrNull returns the element; maxOf returns the selector value
  • sumOf works with Int, Long, Double, BigDecimal
  • groupBy keeps insertion order of keys

Totals and Groups

data class Sale(val region: String, val rep: String, val amount: Double)
val sales = listOf(
    Sale("East", "Ada", 120.0), Sale("West", "Bob", 80.0),
    Sale("East", "Cy", 200.0), Sale("West", "Bob", 50.0)
)

println(sales.sumOf { it.amount })                    // 450.0
println(sales.count { it.amount > 100 })              // 2
println(sales.map { it.amount }.average())            // 112.5
println(sales.maxByOrNull { it.amount }?.rep)         // Cy
println(sales.minOf { it.amount })                    // 50.0
println(sales.fold(0.0) { acc, s -> acc + s.amount }) // 450.0
println(listOf(1, 2, 3, 4).reduce { a, b -> a * b })  // 24

val byRegion = sales.groupBy { it.region }
println(byRegion.keys)                                // [East, West]
println(byRegion.mapValues { (_, list) -> list.sumOf { it.amount } })
// {East=320.0, West=130.0}
println(sales.groupBy({ it.rep }, { it.amount }))
// {Ada=[120.0], Bob=[80.0, 50.0], Cy=[200.0]}
println(sales.groupingBy { it.rep }.eachCount())      // {Ada=1, Bob=2, Cy=1}

val (big, small) = sales.partition { it.amount >= 100 }
println(big.size to small.size)                       // (2, 2)
println(listOf("a", "b", "a").groupingBy { it }.eachCount())   // {a=2, b=1}

Code Explained

sumOf { } sums a selected property
maxByOrNull returns the whole Sale; ?.rep reads its rep
groupBy with two lambdas picks keys and values
groupingBy { }.eachCount() counts per key without lists

Java Equivalent

  • sales.stream().mapToDouble(Sale::amount).sum()
  • Collectors.groupingBy(Sale::region, summingDouble(Sale::amount))
  • Collectors.partitioningBy(s -> s.amount() >= 100)

Idiomatic Kotlin

  • map { }.sum() → sumOf { }
  • counting with a mutable map loop → groupingBy { }.eachCount()

⚠ Common Mistakes

  • reduce on an empty list (exception)
  • maxBy (throws on empty) instead of maxByOrNull
  • Floating-point sums for money (use BigDecimal sumOf)

✓ Tips & Best Practices

  • Use groupingBy for large data to avoid building lists
  • Use sumOf { it.price } with BigDecimal for currency
  • Use partition when you need both sides of a filter

Quick Summary

  • sumOf / count / average
  • fold / reduce — custom
  • groupBy — map of lists
  • eachCount() — counts per key
