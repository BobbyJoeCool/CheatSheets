Sheet 18

String Methods — Search

contains · startsWith / endsWith · indexOf / lastIndexOf · isBlank() / isEmpty() / isNullOrBlank() · equals(ignoreCase = true) · count { }

Finding Things in Text

Kotlin strings have search functions for substrings, prefixes, positions and predicates. Most take an ignoreCase parameter. isBlank() checks for whitespace-only text, and isNullOrBlank() / isNullOrEmpty() work on nullable strings so you can skip a separate null check.

Key Points

  • indexOf returns -1 when not found
  • in is shorthand for contains
  • isBlank() is true for "" and " "
  • Predicates: any, all, none, count work on characters

Search Functions

val s = "Kotlin Coroutines Guide"

println("Coroutines" in s)                   // true
println(s.contains("guide", ignoreCase = true))   // true
println(s.startsWith("Kot"))                 // true
println(s.endsWith(".pdf"))                  // false
println(s.indexOf('o'))                      // 1
println(s.lastIndexOf('o'))                  // 10
println(s.indexOf("Java"))                   // -1
println(s.count { it.isUpperCase() })        // 3
println(s.any { it.isDigit() })              // false
println(s.equals("kotlin coroutines guide", ignoreCase = true))   // true
println(s.indexOfFirst { it == ' ' })        // 6

val blank = "   "
val missing: String? = null
println(blank.isEmpty())                     // false
println(blank.isBlank())                     // true
println(missing.isNullOrBlank())             // true
println(s.commonPrefixWith("Kotlin Flow"))   // "Kotlin "

Code Explained

in reads naturally in conditions
ignoreCase = true avoids lowercasing both sides
isNullOrBlank() can be called on a null String safely
indexOfFirst takes a predicate instead of a value

Java Equivalent

  • s.contains("x"), s.startsWith("x"), s.indexOf("x")
  • s.isBlank() (Java 11+); null checks are separate
  • s.equalsIgnoreCase(t); s.chars().filter(…).count()

Idiomatic Kotlin

  • s == null || s.trim().isEmpty() → s.isNullOrBlank()
  • s.toLowerCase().contains(t.toLowerCase()) → contains(t, ignoreCase = true)

⚠ Common Mistakes

  • Checking isEmpty() when whitespace-only input should also be rejected
  • Using indexOf(...) > 0 to test presence (misses index 0)
  • Lowercasing with the default locale for comparisons

✓ Tips & Best Practices

  • Use in for readability in if conditions
  • Use isNullOrBlank() on form fields
  • Use Regex (sheet 20) for patterns, not chains of contains

Quick Summary

  • in / contains — substring
  • startsWith / endsWith
  • indexOf — position or -1
  • isNullOrBlank() — null-safe check
