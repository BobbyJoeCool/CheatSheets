Data Classes

data class · generated equals / hashCode / toString · copy() · componentN & destructuring · rules & limits

Classes for Holding Data

A data class generates equals, hashCode, toString, copy and componentN functions from the properties in its primary constructor. Use them for DTOs, values and results. copy() creates a changed copy, which pairs well with read-only val properties.

Key Points

  • Only primary-constructor properties are used in generated methods
  • Must have at least one constructor parameter
  • Cannot be abstract, open, sealed or inner
  • Properties in the body are ignored by equals/toString

Under the JVM

  • The compiler emits equals, hashCode, toString, copy, component1..N as normal methods
  • copy has default arguments for every property (via a synthetic copy$default)
  • Data classes are not Java records unless annotated @JvmRecord

Data Class Features

data class User(val id: Int, val name: String, val email: String = "") {
    var lastLogin: Long = 0            // not part of equals/toString
}

val a = User(1, "Ada", "ada@x.com")
val b = User(1, "Ada", "ada@x.com")

println(a)                             // User(id=1, name=Ada, email=ada@x.com)
println(a == b)                        // true (generated equals)
println(a.hashCode() == b.hashCode())  // true
println(setOf(a, b).size)              // 1

val renamed = a.copy(name = "Ada L.")  // change one property
println(renamed)  // User(id=1, name=Ada L., email=ada@x.com)

val (id, name) = a                     // destructuring via component1/2
println("$id: $name")                  // 1: Ada

val users = listOf(a, User(2, "Bob"))
for ((uid, uname) in users) println("$uid $uname")

@JvmRecord
data class Point(val x: Int, val y: Int)   // also a Java record

data class Page<T>(val items: List<T>, val total: Int)   // generic

Code Explained

Two Users with the same constructor values are equal
copy(name = …) keeps all other properties
Destructuring uses component1(), component2(), in order
@JvmRecord makes Java see a real record

Java Equivalent

  • record User(int id, String name, String email) {} (Java 16+)
  • Records have no copy; use a "wither" or a new instance
  • Before records: Lombok @Data / @Value

Idiomatic Kotlin

  • hand-written equals/hashCode → data class
  • mutable var properties in data classes → val + copy()

⚠ Common Mistakes

  • Mutable var properties used as map/set keys, then changed
  • Destructuring by position after reordering properties
  • Expecting body properties in toString/equals

✓ Tips & Best Practices

  • Prefer val properties and copy() for updates
  • Use data classes for API DTOs and JSON models
  • Use data object for singletons in sealed hierarchies

Quick Summary

  • data class — value holder
  • equals/hashCode/toString — free
  • copy() — modified copy
  • destructuring — val (a, b) = x
