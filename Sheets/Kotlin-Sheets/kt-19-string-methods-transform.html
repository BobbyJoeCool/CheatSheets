String Methods — Transform

uppercase() / lowercase() · trim() · replace · split / lines() · substring / substringBefore / substringAfter · take / drop · reversed()

Changing Text

Because strings are immutable, transform functions return new strings. Kotlin adds handy ones beyond Java: substringBefore/substringAfter split at a delimiter, take/drop keep or skip characters, and removePrefix/removeSuffix strip known ends.

Key Points

  • uppercase() uses a locale-independent rule (replaced toUpperCase())
  • split returns a List, not an array
  • take(n) never throws if the string is shorter
  • replace replaces all occurrences

Transform Functions

val path = "  /home/ada/report.final.pdf  "
val p = path.trim()                          // "/home/ada/report.final.pdf"

println(p.uppercase())                       // /HOME/ADA/REPORT.FINAL.PDF
println(p.substringAfterLast('/'))           // report.final.pdf
println(p.substringBeforeLast('.'))          // /home/ada/report.final
println(p.substringAfterLast('.'))           // pdf
println(p.removePrefix("/home/"))            // ada/report.final.pdf
println(p.replace("ada", "bob"))             // /home/bob/report.final.pdf
println(p.split('/'))                        // [, home, ada, report.final.pdf]
println(p.split('/').filter { it.isNotEmpty() })
// [home, ada, report.final.pdf]

val code = "ABC-123"
println(code.take(3))                        // ABC
println(code.drop(4))                        // 123
println(code.takeLast(2))                    // 23
println(code.substring(1, 3))                // BC
println(code.reversed())                     // 321-CBA
println("a,b;c".split(',', ';'))             // [a, b, c]
println("line1\nline2".lines())              // [line1, line2]
println("kotlin".replaceFirstChar { it.uppercase() })   // Kotlin

Code Explained

substringAfterLast('/') gets a file name without index math
split keeps empty strings between delimiters
take/drop are safe on short strings; substring can throw
replaceFirstChar replaces the deprecated capitalize()

Java Equivalent

  • s.toUpperCase(), s.strip(), s.replace(a, b)
  • s.split("/") returns String[] and takes a regex
  • s.substring(s.lastIndexOf('/') + 1) for the file name

Idiomatic Kotlin

  • s.substring(s.lastIndexOf('/') + 1) → s.substringAfterLast('/')
  • capitalize() (deprecated) → replaceFirstChar { it.uppercase() }

⚠ Common Mistakes

  • Expecting split to take a regex (it takes literal delimiters; pass Regex to use one)
  • Calling substring with an index past the end
  • Using deprecated toUpperCase() / capitalize()

✓ Tips & Best Practices

  • Use substringBefore/After instead of index arithmetic
  • Use split(...).map { it.trim() } for CSV-ish input
  • Use take(n) for safe previews
