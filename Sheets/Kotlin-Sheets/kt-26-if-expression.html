if as an Expression

if / else if / else · val x = if (…) a else b · no ternary · last expression is the value · block bodies

if Returns a Value

In Kotlin, if is an expression: it produces a value you can assign or return. That replaces Java's ternary operator. In a block, the last expression is the block's value. When if is used as an expression, an else branch is required.

Key Points

  • There is no ?: ternary; ?: is the Elvis operator
  • Branches can be blocks { }
  • Conditions must be Boolean
  • Long chains often read better as when

if Statements and Expressions

val temp = 72

if (temp > 85) {
    println("Hot")
} else if (temp < 50) {
    println("Cold")
} else {
    println("Nice")                         // Nice
}

val label = if (temp > 85) "Hot" else "OK"  // replaces ternary

val fee = if (temp > 90) {
    println("Heat surcharge")
    5.0                                     // value of this branch
} else {
    0.0
}

fun max(a: Int, b: Int) = if (a > b) a else b

val message = if (temp in 60..80) "Ideal" else if (temp < 60) "Cool" else "Warm"
println(message)                            // Ideal

Code Explained

if used as a statement needs no else
As an expression, every path must produce a value
The last line of a block is its result (5.0 or 0.0)
max is a one-line function built on an if expression

Java Equivalent

  • String label = temp > 85 ? "Hot" : "OK";
  • if in Java is only a statement
  • Switch expressions (Java 14+) are the nearest equivalent for multi-way

Idiomatic Kotlin

  • var x; if (c) x = a else x = b → val x = if (c) a else b
  • long else if ladders → when

⚠ Common Mistakes

  • Writing c ? a : b (not Kotlin)
  • Missing else on an if expression (compile error)
  • Putting a return in one branch and a value in another by accident

✓ Tips & Best Practices

  • Assign from if to keep variables as val
  • Switch to when after two else ifs
  • Keep expression branches short

Quick Summary

  • if — expression
  • no ternary
  • else required as expression
  • block value — last line
