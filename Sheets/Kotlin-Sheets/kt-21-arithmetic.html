Math Operators

Kotlin's arithmetic operators map to functions (plus, minus, times, div, rem), which is how operator overloading works. Integer division truncates, % is the remainder, and mod() gives a result with the divisor's sign. coerceIn clamps a value to a range.

Key Points

  • % is rem: sign follows the dividend
  • a.mod(b): sign follows the divisor
  • Mixed types widen: Int * Double is Double
  • No ** operator: use pow

Operators and Helpers

val a = 17
val b = 5
println(a + b)             // 22
println(a - b)             // 12
println(a * b)             // 85
println(a / b)             // 3   (truncated)
println(a % b)             // 2
println(a / b.toDouble())  // 3.4
println(-17 % 5)           // -2
println((-17).mod(5))      // 3

var count = 10
count++                    // 11
count += 5                 // 16
count *= 2                 // 32
println(count--)           // 32, then count is 31

println(150.coerceIn(0, 100))      // 100
println((-5).coerceAtLeast(0))     // 0
println(maxOf(3, 9, 4))            // 9
println(2.0.pow(8))                // 256.0 (kotlin.math.pow)
println(7.toDouble() / 2)          // 3.5

Code Explained

Convert one side to Double to get a decimal result
-17 % 5 is -2 but (-17).mod(5) is 3
Postfix count-- returns the old value
coerceIn replaces min(max(x, lo), hi)

Java Equivalent

  • Same operators; % is remainder
  • Math.floorMod(-17, 5) → 3
  • Math.max(0, Math.min(150, 100)) for clamping

Idiomatic Kotlin

  • Math.max(lo, Math.min(x, hi)) → x.coerceIn(lo, hi)
  • (a % n + n) % n → a.mod(n)

⚠ Common Mistakes

  • 7 / 2 expecting 3.5
  • Negative remainders breaking wrap-around index math
  • Looking for a ** operator

✓ Tips & Best Practices

  • Use mod for circular indexes
  • Use coerceIn for user-provided limits
  • Use BigDecimal operators (they overload too) for money
