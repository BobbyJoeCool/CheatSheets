while & do-while

while · do { } while · repeat(n) { } · loop variables · forEach vs loops

Condition-Based Loops

while repeats while a condition is true and checks it first. do { } while runs the body once before checking, and variables declared inside the body are visible in its condition. repeat(n) runs a block a fixed number of times.

Key Points

  • Same semantics as Java
  • Variables in do are in scope in the while condition
  • repeat(n) { } passes the zero-based index as it
  • Use while (true) with break for read loops

while, do-while, repeat

var balance = 1000.0
var years = 0
while (balance < 2000) {
    balance *= 1.07
    years++
}
println("$years years")              // 11 years

do {
    print("Enter a number (0 to quit): ")
    val n = readln().toIntOrNull() ?: -1
    if (n > 0) println("Square: ${n * n}")
} while (n != 0)                     // n is visible here

repeat(3) { i -> println("Attempt ${i + 1}") }

val queue = ArrayDeque(listOf("a", "b", "c"))
while (queue.isNotEmpty()) {
    println(queue.removeFirst())
}

val reader = File("data.txt").bufferedReader()
while (true) {
    val line = reader.readLine() ?: break   // exit at end of file
    println(line)
}

Code Explained

The condition is checked before each pass
n declared inside do can be used in the while
repeat replaces counting loops
readLine() ?: break exits at end of file

Java Equivalent

  • while (…) { } and do { } while (…); are the same
  • In Java, do body variables are not visible in the condition
  • for (int i = 0; i < 3; i++) for repeat

Idiomatic Kotlin

  • counter while loops → repeat(n) or for (i in 0..<n)
  • manual read loops → useLines { } (sheet 71)

⚠ Common Mistakes

  • Forgetting to change the loop variable (infinite loop)
  • Using while with an index where for is clearer
  • Not handling null from readLine()

✓ Tips & Best Practices

  • Use ArrayDeque for queue-style loops
  • Use ?: break for end-of-input
  • Keep loop bodies short; extract functions

Quick Summary

  • while — check first
  • do-while — run once first
  • repeat(n) — fixed count
  • ?: break — exit on null
