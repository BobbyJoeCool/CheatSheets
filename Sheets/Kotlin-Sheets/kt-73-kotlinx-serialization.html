JSON with kotlinx.serialization

@Serializable · Json.encodeToString · decodeFromString · Json { ignoreUnknownKeys = true } · @SerialName · plugin setup

Kotlin-First JSON

kotlinx.serialization turns @Serializable classes into JSON and back with code generated at compile time, so no reflection is needed. It understands Kotlin nullability and default values. A configured Json instance controls leniency, unknown keys and pretty printing.

Key Points

  • Needs the kotlin("plugin.serialization") Gradle plugin
  • Default values are used for missing fields
  • Non-null fields without defaults must be present
  • Jackson (with jackson-module-kotlin) and Moshi are alternatives

Encode and Decode

// build.gradle.kts
// plugins { kotlin("plugin.serialization") version "2.2.0" }
// implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.8.1")

import kotlinx.serialization.*
import kotlinx.serialization.json.*

@Serializable
data class User(
    val id: Int,
    val name: String,
    @SerialName("email_address") val email: String? = null,
    val roles: List<String> = emptyList()
)

val user = User(1, "Ada", "ada@x.com", listOf("admin"))
val json = Json.encodeToString(user)
println(json)
// {"id":1,"name":"Ada","email_address":"ada@x.com","roles":["admin"]}

val parser = Json {
    ignoreUnknownKeys = true
    prettyPrint = true
}
val input = """{"id":2,"name":"Bob","extra":true}"""
val back = parser.decodeFromString<User>(input)
println(back)                    // User(id=2, name=Bob, email=null, roles=[])

val list = Json.decodeFromString<List<User>>("""[{"id":3,"name":"Cy"}]""")
val tree = Json.parseToJsonElement("""{"a":{"b":42}}""")
println(tree.jsonObject["a"]?.jsonObject?.get("b"))   // 42

Code Explained

@SerialName maps a Kotlin property to a different JSON key
Missing email and roles fall back to their defaults
ignoreUnknownKeys skips "extra" instead of failing
parseToJsonElement gives a tree for ad-hoc JSON

Java Equivalent

  • Jackson: new ObjectMapper().writeValueAsString(user)
  • mapper.readValue(json, User.class)
  • @JsonProperty("email_address") instead of @SerialName

Idiomatic Kotlin

  • reflection-based Gson with Kotlin classes → kotlinx.serialization or Jackson Kotlin module
  • failing on new server fields → ignoreUnknownKeys = true

⚠ Common Mistakes

  • Forgetting the serialization Gradle plugin ("Serializer not found")
  • Non-null fields with no default when the JSON may omit them
  • Creating a new Json { } instance for every call

✓ Tips & Best Practices

  • Create one configured Json and reuse it
  • Give optional fields defaults or make them nullable
  • Write custom serializers for LocalDate and BigDecimal
