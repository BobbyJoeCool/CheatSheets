Spring Boot with Kotlin

kotlin("plugin.spring") (all-open) · constructor injection · data classes as DTOs · kotlin("plugin.jpa") · coroutines in controllers · runApplication<App>()

Kotlin as a First-Class Spring Language

Spring Boot officially supports Kotlin. The spring compiler plugin opens classes Spring needs to proxy (Kotlin classes are final), the jpa plugin adds no-arg constructors for entities, and constructor injection works through primary constructors with no @Autowired. Controllers can be suspend functions or return Flow.

Key Points

  • Start at start.spring.io with "Kotlin" selected
  • jackson-module-kotlin handles data classes and defaults
  • Spring's Kotlin extensions add runApplication, bean DSL and more
  • See the Spring set for the full framework

Kotlin Spring Boot App

// build.gradle.kts plugins:
//   kotlin("jvm"), kotlin("plugin.spring"), kotlin("plugin.jpa"),
//   id("org.springframework.boot"), id("io.spring.dependency-management")

@SpringBootApplication
class ShopApplication

fun main(args: Array<String>) {
    runApplication<ShopApplication>(*args)
}

@Entity
class Product(
    @Id @GeneratedValue var id: Long? = null,
    var name: String,
    var price: BigDecimal
)

interface ProductRepository : JpaRepository<Product, Long>

data class ProductDto(val id: Long, val name: String, val price: BigDecimal)

@Service
class ProductService(private val repo: ProductRepository) {  // injected
    fun all() = repo.findAll().map { ProductDto(it.id!!, it.name, it.price) }
}

@RestController
@RequestMapping("/products")
class ProductController(private val service: ProductService) {
    @GetMapping fun list() = service.all()

    @GetMapping("/{id}")
    suspend fun one(@PathVariable id: Long): ProductDto =   // coroutine handler
        withContext(Dispatchers.IO) { service.all().first { it.id == id } }
}

Code Explained

runApplication<…> is Spring's Kotlin entry point
The jpa plugin gives Product the no-arg constructor JPA needs
Constructor parameters are injected with no annotations
A suspend handler is supported with Spring WebFlux or MVC coroutine support

Java Equivalent

  • SpringApplication.run(ShopApplication.class, args)
  • Lombok @RequiredArgsConstructor for constructor injection
  • Records as DTOs: record ProductDto(long id, String name, BigDecimal price)

Idiomatic Kotlin

  • lateinit var + @Autowired field injection → constructor injection
  • data classes as JPA entities → regular classes (entities need mutability and identity)

⚠ Common Mistakes

  • Missing the spring plugin, so @Transactional classes cannot be proxied
  • Data classes as JPA entities (equals/hashCode on mutable IDs)
  • Using !! on generated IDs before they are saved

✓ Tips & Best Practices

  • Let start.spring.io generate the Kotlin build
  • Use data classes for DTOs, plain classes for entities
  • Use @ConfigurationProperties with constructor-bound data classes
