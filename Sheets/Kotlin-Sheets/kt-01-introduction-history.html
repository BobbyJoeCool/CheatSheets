A Modern Language for the JVM

Kotlin was created by JetBrains (makers of IntelliJ) and reached 1.0 in 2016. It compiles to JVM bytecode and calls Java libraries directly, while adding null safety, concise syntax and coroutines. Google made it the preferred language for Android in 2019, and Kotlin 2.0 (2024) shipped the new K2 compiler.

Key Points

  • Source files: .kt; scripts: .kts
  • Runs anywhere Java runs; also targets JS, Wasm and native
  • Statically typed, with strong type inference
  • The Kotlin Foundation (JetBrains + Google) guides the language

Hello, World

// Hello.kt
fun main() {
    println("Hello, World")          // Hello, World
}

// With arguments
fun main(args: Array<String>) {
    val name = args.firstOrNull() ?: "World"
    println("Hello, $name")          // Hello, Bob
}

// Build and run with the command-line compiler:
// kotlinc Hello.kt -include-runtime -d hello.jar
// java -jar hello.jar Bob

Code Explained

main is a top-level function: no class needed
Semicolons are optional and almost never written
$name is a string template
?: supplies a default when firstOrNull() returns null

Java Equivalent

  • public class Hello { public static void main(String[] args) { … } }
  • Java 25 also allows a bare void main() { … } (instance main)
  • String name = args.length > 0 ? args[0] : "World";

Idiomatic Kotlin

  • wrapping main in a class → top-level fun main()
  • args[0] with a length check → args.firstOrNull() ?: default

⚠ Common Mistakes

  • Assuming Kotlin needs its own runtime environment (it runs on the normal JVM)
  • Writing Java-style Kotlin full of !! and getters
  • Forgetting -include-runtime when building a runnable jar by hand

✓ Tips & Best Practices

  • Use IntelliJ's Java-to-Kotlin converter to compare styles
  • Try snippets in the Kotlin Playground (play.kotlinlang.org)
  • Learn null safety first: it shapes everything else
