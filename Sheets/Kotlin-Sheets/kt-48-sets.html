Sheet 48

Sets

setOf / mutableSetOf · union / intersect / subtract · contains · LinkedHashSet order · sortedSetOf · toSet() dedup

Unique Elements

A set holds each element once. setOf() and mutableSetOf() create sets that keep insertion order (LinkedHashSet); hashSetOf() gives no order guarantee and sortedSetOf() keeps elements sorted. Set operations union, intersect and subtract are infix functions.

Key Points

  • Uniqueness uses equals and hashCode
  • add returns false if the element was already there
  • toSet() is a quick way to remove duplicates
  • in checks are fast (hash-based)

Set Basics and Operations

val tags = mutableSetOf("kotlin", "jvm")
println(tags.add("kotlin"))          // false (already there)
println(tags.add("android"))         // true
println(tags)                        // [kotlin, jvm, android] (insertion order)
println("jvm" in tags)               // true
tags.remove("jvm")

val a = setOf(1, 2, 3, 4)
val b = setOf(3, 4, 5)
println(a union b)                   // [1, 2, 3, 4, 5]
println(a intersect b)               // [3, 4]
println(a subtract b)                // [1, 2]
println(a + 9)                       // [1, 2, 3, 4, 9]
println(a.containsAll(listOf(1, 2))) // true

val emails = listOf("a@x.com", "b@x.com", "a@x.com")
println(emails.toSet())              // [a@x.com, b@x.com]
println(emails.distinct())           // same, but stays a List

val sorted = sortedSetOf(5, 1, 3)    // TreeSet
println(sorted)                      // [1, 3, 5]
println(sorted.first())              // 1

data class Point(val x: Int, val y: Int)
println(setOf(Point(1, 2), Point(1, 2)).size)   // 1 (data class equals)

Code Explained

add reports whether the set changed
union, intersect, subtract read naturally as infix calls
distinct() dedups but keeps a List
Data classes work in sets because equals/hashCode are generated

Java Equivalent

  • Set.of(…) (immutable), new HashSet<>(), new LinkedHashSet<>()
  • set.addAll(b) / retainAll(b) / removeAll(b) mutate in place
  • new TreeSet<>(List.of(5, 1, 3))

Idiomatic Kotlin

  • list.contains in a loop on big lists → convert to a Set first
  • mutating retainAll for intersection → a intersect b

⚠ Common Mistakes

  • Mutable objects as set elements whose hash changes after insertion
  • Expecting hashSetOf to keep order
  • Using a List for frequent membership tests

✓ Tips & Best Practices

  • Use toSet() or distinct() for deduplication
  • Use sets for "seen" tracking in loops
  • Use sortedSetOf or toSortedSet() when order matters

Quick Summary

  • setOf — unique, ordered
  • union / intersect / subtract
  • toSet() — dedupe
  • sortedSetOf — sorted
