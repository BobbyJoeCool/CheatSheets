Installation & Tooling

IntelliJ IDEA · kotlinc · SDKMAN! / Homebrew · Kotlin Playground · .kt vs .kts · REPL

Getting a Kotlin Toolchain

Most developers use IntelliJ IDEA, which bundles the Kotlin plugin, plus Gradle to build. You can also install the command-line compiler kotlinc with Homebrew or SDKMAN!. A JDK (17 or newer recommended) is required either way, because Kotlin/JVM compiles to Java bytecode.

Key Points

  • IntelliJ Community is free and fully supports Kotlin
  • Android Studio is IntelliJ with Android tools
  • kotlinc alone is fine for scripts and learning
  • Project builds should use Gradle, not raw kotlinc

Install and Try It

# JDK first
brew install openjdk@21
java -version                      # openjdk 21

# Kotlin compiler
brew install kotlin                # or: sdk install kotlin
kotlinc -version                   # info: kotlinc-jvm 2.x

# Compile and run
kotlinc Hello.kt -include-runtime -d hello.jar
java -jar hello.jar

# Scripts: .main.kts files run directly
kotlin hello.main.kts

# Interactive shell
kotlinc                            # REPL (or Kotlin Notebook in IntelliJ)
>>> listOf(1, 2, 3).sum()
res0: kotlin.Int = 6

Code Explained

Install the JDK before Kotlin
-include-runtime bundles the Kotlin standard library into the jar
.main.kts scripts can declare dependencies with annotations
IntelliJ users rarely call kotlinc directly

Java Equivalent

  • brew install openjdk gives javac and java
  • java Hello.java runs a single file without compiling first
  • jshell is Java's REPL

Idiomatic Kotlin

  • raw kotlinc for real projects → Gradle with the Kotlin plugin
  • old JDK 8 → JDK 17+ (matches modern Spring and Android)

⚠ Common Mistakes

  • No JDK installed, so kotlinc and Gradle fail
  • Mixing Kotlin compiler versions between IDE and build
  • Building production jars with kotlinc instead of Gradle

✓ Tips & Best Practices

  • Let the Gradle wrapper pin the build's Kotlin version
  • Use the Kotlin Playground to share small examples
  • Turn on "Kotlin code style" in IntelliJ for consistent formatting

Quick Summary

  • IntelliJ — main IDE
  • kotlinc — CLI compiler
  • JDK 17+ — required
  • .kts — scripts
