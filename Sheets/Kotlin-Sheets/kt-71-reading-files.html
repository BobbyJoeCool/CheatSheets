Reading Text Files

Kotlin adds extension functions to java.io.File and java.nio.file.Path that make reading short: readText() for the whole file, readLines() for a list of lines, and useLines { } to process a large file lazily and close it automatically. UTF-8 is the default charset.

Key Points

  • readText / readLines load the whole file into memory
  • useLines streams lines as a Sequence and closes the file
  • kotlin.io.path adds the same helpers for Path
  • Pass a Charset for non-UTF-8 files

Reading Files

import java.io.File
import kotlin.io.path.*

val text = File("notes.txt").readText()             // whole file
val lines = File("notes.txt").readLines()           // List<String>
println(lines.size)

val errors = File("app.log").useLines { seq ->      // large file, lazy
    seq.filter { "ERROR" in it }.take(10).toList()
}

File("data.csv").bufferedReader().use { reader ->
    val header = reader.readLine()
    reader.lineSequence().forEach { println(it.split(",")) }
}

val p = Path("config/settings.properties")          // kotlin.io.path
if (p.exists()) println(p.readText())
val words = p.readLines().flatMap { it.split(" ") }

val latin = File("old.txt").readText(Charsets.ISO_8859_1)
val bytes = File("image.png").readBytes()           // ByteArray

val fromResources = object {}.javaClass.getResource("/data.json")?.readText()

Code Explained

readText() is simplest for small files
useLines keeps memory flat for big logs
bufferedReader().use { } closes the reader automatically
Path(...) with readText() uses NIO underneath

Java Equivalent

  • Files.readString(Path.of("notes.txt")) (Java 11+)
  • Files.readAllLines(path) / Files.lines(path) stream
  • try-with-resources around Files.newBufferedReader(path)

Idiomatic Kotlin

  • readLines() on huge files → useLines { }
  • manual reader close in finally → .use { }

⚠ Common Mistakes

  • Loading multi-gigabyte files with readText()
  • Forgetting to close readers (use use)
  • Relative paths resolved from an unexpected working directory

✓ Tips & Best Practices

  • Prefer Path / kotlin.io.path in new code
  • Use useLines for anything that could be large
  • Read classpath resources with getResource(...)?.readText()

Quick Summary

  • readText() — whole file
  • readLines() — list of lines
  • useLines { } — lazy + closes
  • Path.readText() — NIO
