Lambdas

{ x -> x * 2 } · implicit it · trailing lambda syntax · _ unused params · return value of a lambda · destructuring params

Function Literals

A lambda is a function written as a value in braces: parameters, an arrow, then the body. A single parameter can be called it. When a lambda is the last argument, it goes outside the parentheses (trailing lambda), which is why Kotlin code reads like list.filter { it > 0 }.

Key Points

  • The last expression is the lambda's return value
  • Omit () entirely if the lambda is the only argument
  • Use _ for parameters you do not need
  • Lambdas can read and change outer vars

Under the JVM

  • Lambdas compile via invokedynamic (LambdaMetafactory) by default since Kotlin 2.0
  • Captured vars are wrapped in Ref objects so they can change
  • Passing a lambda to an inline function creates no object at all (sheet 43)

Lambda Syntax

val double: (Int) -> Int = { x -> x * 2 }
val add = { a: Int, b: Int -> a + b }
val greet: () -> String = { "Hi" }
println(double(4))                       // 8
println(add(2, 3))                       // 5

val nums = listOf(3, -1, 4, -5)
println(nums.filter { it > 0 })          // [3, 4] (it = the element)
println(nums.map { n -> n * n })         // [9, 1, 16, 25]

println(nums.fold(0) { acc, n -> acc + n })   // 1 (trailing lambda)

val map = mapOf("a" to 1, "b" to 2)
map.forEach { (key, value) -> println("$key=$value") }  // destructuring
map.forEach { (_, value) -> println(value) }            // ignore key

val grade = { score: Int ->
    val bonus = 5
    if (score + bonus >= 90) "A" else "B"   // last expression returned
}
println(grade(87))                       // A

var clicks = 0
val onClick = { clicks++ }               // captures and changes clicks
onClick(); onClick()
println(clicks)                          // 2

Code Explained

Function types are written (Int) -> Int
it is the default name for a single parameter
fold(0) { … }: initial value in parentheses, lambda outside
Lambdas can capture and modify local vars, unlike Java

Java Equivalent

  • Function<Integer, Integer> d = x -> x * 2;
  • list.stream().filter(n -> n > 0).toList()
  • Java lambdas can only capture effectively final variables

Idiomatic Kotlin

  • list.filter({ it > 0 }) → list.filter { it > 0 }
  • nested lambdas all using it → name the parameters

Syntax

FormMeaning
{ x -> x * 2 }One parameter
{ it * 2 }Implicit it
{ a, b -> a + b }Two parameters
{ (k, v) -> … }Destructure a Pair/entry
{ _, v -> v }Ignore a parameter
{ }No parameters
f(1) { … }Trailing lambda

⚠ Common Mistakes

  • Using it in nested lambdas so it is unclear which it
  • Writing return in a lambda and leaving the enclosing function
  • Confusing { (a, b) -> } (destructure one arg) with { a, b -> } (two args)

✓ Tips & Best Practices

  • Name lambda parameters when the body is longer than one line
  • Use function references (sheet 45) when a function already exists
  • Keep lambdas short; extract named functions

Quick Summary

  • { x -> body } — lambda
  • it — single param
  • trailing lambda — outside ()
  • last expression — result
