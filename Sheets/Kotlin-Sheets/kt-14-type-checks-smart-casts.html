is / !is · smart casts · as / as? · Any · smart casts with when · stable vals only

Checking and Casting Types

is checks a value's type, and after a successful check Kotlin smart casts the value, so you can use it as that type with no explicit cast. as casts explicitly and throws on failure; as? returns null instead. Any is the root of all non-null types.

Key Points

  • Smart casts work in if, when, && and || branches
  • They need a value the compiler knows cannot change
  • Generic types are erased: is List<String> is not allowed
  • Any? holds anything, including null

is, Smart Casts and as?

fun describe(x: Any): String = when (x) {
    is Int    -> "Int doubled: ${x * 2}"         // x is Int here
    is String -> "String of length ${x.length}"  // x is String
    is List<*> -> "List with ${x.size} items"
    else      -> "Unknown: $x"
}

println(describe(21))             // Int doubled: 42
println(describe("hi"))           // String of length 2

val obj: Any = "Kotlin"
if (obj is String && obj.length > 3) {   // smart cast after &&
    println(obj.uppercase())      // KOTLIN
}
if (obj !is Int) println("not an Int")

val s = obj as String             // explicit cast, OK
val n = obj as? Int               // null, no exception
// val bad = obj as Int           // ClassCastException

class Box(var item: Any)
val box = Box("x")
// if (box.item is String) box.item.length  // error: var property may change

Code Explained

Inside each when branch, x already has the checked type
Smart casts also flow through &&
as? is the safe cast; combine it with ?:
Mutable properties do not smart cast: copy to a local val first

Java Equivalent

  • if (x instanceof String s) { s.length(); } (pattern matching, Java 16+)
  • switch (x) { case Integer i -> … } (Java 21)
  • (String) obj throws ClassCastException like as

Idiomatic Kotlin

  • (x as String).length after an is check → rely on the smart cast
  • obj as Int that may fail → obj as? Int ?: default

⚠ Common Mistakes

  • Expecting smart casts on var properties
  • Checking is List<String> (erased; use List<*>)
  • Using as where failure is possible

✓ Tips & Best Practices

  • Use when with is branches instead of if-else chains
  • Copy a property to a local val to enable smart casts
  • Prefer sealed types (sheet 63) over open-ended Any checks

Quick Summary

  • is — check + smart cast
  • as — cast or throw
  • as? — cast or null
  • local vals — smart cast safely
