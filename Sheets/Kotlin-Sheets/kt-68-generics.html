Generics

class Box<T> · fun <T> f() · upper bounds T : Comparable<T> · where clauses · type inference · reified (pointer to 43)

Type Parameters

Generics let classes and functions work with any type while staying type-safe. Declare type parameters in angle brackets, add upper bounds with : to require capabilities, and use where for several bounds. Type arguments are usually inferred, and they are erased at runtime unless reified.

Key Points

  • The default upper bound is Any? (nullable)
  • Use T : Any to forbid nulls
  • where lists multiple constraints
  • Raw types do not exist: always give type arguments

Generic Classes and Functions

class Box<T>(val item: T) {
    fun <R> map(f: (T) -> R): Box<R> = Box(f(item))
}
val intBox = Box(42)                       // Box<Int> inferred
val strBox = intBox.map { "#$it" }         // Box<String>
println(strBox.item)                       // #42

fun <T> firstOrDefault(list: List<T>, default: T): T =
    list.firstOrNull() ?: default
println(firstOrDefault(emptyList(), "none"))   // none

fun <T : Comparable<T>> maxOf3(a: T, b: T, c: T): T = maxOf(a, maxOf(b, c))
println(maxOf3(3, 9, 4))                   // 9
println(maxOf3("pear", "apple", "fig"))    // pear

fun <T> copyNonNull(src: List<T>): List<T & Any> = src.filterNotNull()

fun <T> describe(x: T) where T : CharSequence, T : Comparable<T> =
    "${x.length} chars, compares to 'm': ${x.compareTo(x)}"

class Cache<K : Any, V : Any> {
    private val map = mutableMapOf<K, V>()
    operator fun get(k: K): V? = map[k]
    operator fun set(k: K, v: V) { map[k] = v }
}
val cache = Cache<String, Int>()
cache["a"] = 1

Code Explained

map introduces its own type parameter R
T : Comparable<T> allows maxOf on T
T & Any is a definitely non-null version of T
where adds several bounds to one parameter

Java Equivalent

  • class Box<T>, <T extends Comparable<T>> T max(...)
  • <T extends CharSequence & Comparable<T>> for multiple bounds
  • Raw types like List still compile in Java

Idiomatic Kotlin

  • Any parameters with casts → type parameters
  • unbounded T that must not be null → T : Any

⚠ Common Mistakes

  • Assuming T is non-null by default (it is Any?)
  • Checking is T without reified (erased)
  • Over-generalizing simple code

✓ Tips & Best Practices

  • Let inference fill type arguments when obvious
  • Add bounds only for what you call on T
  • See variance (sheet 69) for producer/consumer types
