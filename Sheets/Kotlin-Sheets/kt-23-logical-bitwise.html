Boolean Logic and Bits

Boolean logic uses &&, || and !, which short-circuit. For bits, Kotlin uses named infix functions instead of symbols: and, or, xor, inv(), shl, shr and ushr. On Booleans, and/or also exist but do not short-circuit.

Key Points

  • && / || short-circuit; infix and / or do not
  • No &, |, ^, <<, >> symbols
  • ushr is the unsigned right shift (Java >>>)
  • Bit functions work on Int and Long

Logic and Bit Operations

val loggedIn = true
val isAdmin = false
println(loggedIn && isAdmin)       // false
println(loggedIn || isAdmin)       // true
println(!isAdmin)                  // true

val a = 0b1100                     // 12
val b = 0b1010                     // 10
println(a and b)                   // 8   (0b1000)
println(a or b)                    // 14  (0b1110)
println(a xor b)                   // 6   (0b0110)
println(a.inv())                   // -13
println(1 shl 4)                   // 16
println(-16 shr 2)                 // -4
println(-16 ushr 28)               // 15
println(a.countOneBits())          // 2
println(Integer.toBinaryString(a)) // 1100

const val READ = 1; const val WRITE = 2; const val EXEC = 4
var perms = READ or WRITE          // 3
println(perms and WRITE != 0)      // true
perms = perms and WRITE.inv()      // remove WRITE → 1

Code Explained

Infix calls read as words: a and b
shr keeps the sign; ushr fills with zeros
Combine flags with or, test with and
Infix calls bind tighter than !=, so this reads as (perms and WRITE) != 0

Java Equivalent

  • &&, ||, ! are the same
  • a & b, a | b, a ^ b, ~a
  • <<, >>, >>>; Integer.bitCount(a)

Idiomatic Kotlin

  • raw bit flags for options → EnumSet or Set<Flag>
  • magic masks 0x4 → named const val flags

⚠ Common Mistakes

  • Typing & or << (not Kotlin operators)
  • Using infix and on Booleans and losing short-circuit
  • Assuming Java precedence: in Kotlin a and b == c means (a and b) == c

✓ Tips & Best Practices

  • Add parentheses around infix bit expressions
  • Prefer enums and sets for permissions in new code
  • See the Bitwise set for patterns
