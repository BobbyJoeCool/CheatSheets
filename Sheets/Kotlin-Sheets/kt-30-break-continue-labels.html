break, continue & Labels

break / continue · labels outer@ · break@outer · return@forEach · non-local returns from inline lambdas

Jumping Out of Loops

break leaves the nearest loop and continue skips to its next pass. Labels (outer@) let you target an outer loop. Inside lambdas such as forEach, a plain return leaves the enclosing function; use return@forEach to skip to the next element instead.

Key Points

  • Label syntax: name@ before the loop, @name after the jump
  • Lambdas get implicit labels named after the function
  • break/continue inside forEach work only since Kotlin 2.2 (non-local break/continue)
  • Prefer any, first, takeWhile over complex jumps

Labels and Lambda Returns

for (i in 1..10) {
    if (i % 2 == 0) continue      // skip evens
    if (i > 7) break              // stop at 9
    print("$i ")                  // 1 3 5 7
}
println()

outer@ for (row in 1..3) {
    for (col in 1..3) {
        if (col == 2) continue@outer
        if (row == 3) break@outer
        println("$row,$col")      // 1,1  2,1
    }
}

fun firstNegative(nums: List<Int>): Int? {
    nums.forEach {
        if (it < 0) return it     // returns from firstNegative
    }
    return null
}

listOf(1, -2, 3).forEach {
    if (it < 0) return@forEach    // like continue
    print("$it ")                 // 1 3
}

val found = listOf(4, 9, 16).first { it > 5 }   // 9, no loop needed

Code Explained

continue@outer jumps to the next row
A plain return in an inline lambda leaves the whole function
return@forEach ends only the current element's block
first { } often replaces a loop with break

Java Equivalent

  • outer: for (…) { … continue outer; } labeled loops
  • In stream().forEach, return acts like continue
  • No non-local returns from lambdas in Java

Idiomatic Kotlin

  • forEach + return@forEach to stop early → a for loop or first { }
  • nested loops with labels → extract a function and return

Jumps

StatementEffect
breakLeave loop
continueNext iteration
break@labelLeave labeled loop
continue@labelNext of labeled loop
returnLeave function (also from inline lambda)
return@forEachLeave this lambda call

⚠ Common Mistakes

  • Using return in forEach and leaving the whole function by surprise
  • Expecting break inside forEach to work on older Kotlin
  • Deep label jumps that are hard to follow

✓ Tips & Best Practices

  • Use for loops when you need break/continue
  • Use firstOrNull, any, takeWhile instead of manual searching
  • Name labels for what they loop over (rows@)

Quick Summary

  • break / continue
  • label@ + break@label
  • return@forEach — skip one
  • plain return — leaves function
