Sheet 05

Kotlin Targets

Kotlin/JVM · Android · Kotlin/JS · Kotlin/Wasm · Kotlin/Native · Kotlin Multiplatform

One Language, Many Platforms

Kotlin compiles to several targets: JVM bytecode (servers, desktop, Android), JavaScript and WebAssembly for browsers, and native binaries through LLVM for iOS, macOS, Linux and Windows. Kotlin Multiplatform (KMP) shares common code across targets while each platform keeps its own UI and APIs.

Key Points

  • This set focuses on Kotlin/JVM
  • Android uses Kotlin/JVM with the Android SDK
  • KMP shares business logic; Compose Multiplatform shares UI
  • The standard library works on every target; java.* only on JVM

Multiplatform Build Sketch

// build.gradle.kts of a shared module
plugins {
    kotlin("multiplatform") version "2.2.0"
}

kotlin {
    jvm()                       // servers / desktop
    js { browser() }            // web
    iosArm64()                  // iPhone (native)
    linuxX64()                  // native binary

    sourceSets {
        commonMain.dependencies {
            implementation("org.jetbrains.kotlinx:kotlinx-datetime:0.6.2")
        }
        jvmMain.dependencies {
            implementation("org.postgresql:postgresql:42.7.4")
        }
    }
}

Code Explained

Each target block adds a platform to compile for
commonMain code compiles for every target
jvmMain can use Java libraries; common code cannot
Platform-specific APIs are bridged with expect/actual (sheet 94)

Java Equivalent

  • Java targets the JVM only (plus GraalVM native images)
  • GraalVM native-image builds native executables from Java
  • Android also runs Java, but new Android APIs are Kotlin-first

Idiomatic Kotlin

  • java.* imports in shared code → kotlinx libraries (datetime, serialization)
  • sharing UI too early → share logic first, UI later

⚠ Common Mistakes

  • Using Java classes in commonMain (they do not exist on other targets)
  • Assuming every library supports every target
  • Expecting Kotlin/JS to accept any npm package without typed wrappers

✓ Tips & Best Practices

  • Start on Kotlin/JVM; add targets once the basics are solid
  • Check a library's supported platforms on klibs.io
  • See sheet 94 for expect/actual

Quick Summary

  • JVM — main target
  • JS / Wasm — browser
  • Native — iOS, CLI
  • KMP — shared common code
