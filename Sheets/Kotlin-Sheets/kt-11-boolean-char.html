Boolean & Char

Boolean · Char literals · isDigit() / isLetter() · digitToInt() · code · Char isn't a number

True/False and Single Characters

Boolean holds true or false and works with &&, || and !. Char holds one UTF-16 character in single quotes. Unlike Java, a Char is not a number: use code to get its numeric value and digitToInt() to turn '7' into 7.

Key Points

  • Char literals: 'A', '\n', '\u00E9'
  • No char + int arithmetic that gives an Int silently
  • Char has many tests: isWhitespace(), isUpperCase()
  • Emoji often need two Chars (surrogate pair)

Booleans and Chars

val isActive = true
val hasStock = false
println(isActive && !hasStock)   // true
println(isActive.and(hasStock))  // false (eager, no short-circuit)

val c = 'A'
val tab = '\t'
val e = '\u00E9'                 // é
println(c.code)                  // 65
println(Char(66))                // B
println(c + 1)                   // B (Char + Int = Char)
println('7'.digitToInt())        // 7
println('7'.isDigit())           // true
println('x'.isLetter())          // true
println('a'.uppercaseChar())     // A
println(c in 'A'..'Z')           // true
println("Kotlin"[0])             // K
println("Kotlin".count { it.isUpperCase() })   // 1

Code Explained

c.code replaces Java's cast (int) c
Char + Int moves along the alphabet and stays a Char
digitToInt() is the safe way to read a digit character
'A'..'Z' is a CharRange

Java Equivalent

  • boolean, char primitives
  • (int) c gets the code; (char) 66 gets B
  • Character.isDigit(c), Character.getNumericValue('7')

Idiomatic Kotlin

  • c.toInt() (deprecated) → c.code
  • c - '0' to read a digit → c.digitToInt()

⚠ Common Mistakes

  • Using c.toInt() and getting a deprecation warning
  • Comparing a Char with an Int (c == 65 does not compile)
  • Assuming one Char = one visible character for emoji

✓ Tips & Best Practices

  • Use code / Char(n) for conversions
  • Use '0'..'9' ranges in when for character classes
  • Use codePoints() for full Unicode text processing

Quick Summary
