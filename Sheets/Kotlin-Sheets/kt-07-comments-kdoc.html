Comments & KDoc

// · /* */ (nestable) · /** */ KDoc · @param / @return / @throws · [Name] links · Dokka

Comments and API Docs

Kotlin uses // for line comments and /* */ for block comments, which can nest (unlike Java). Documentation comments /** */ use KDoc, a Markdown-based format with block tags like @param. Dokka turns KDoc into HTML documentation, and IntelliJ shows it on hover.

Key Points

  • Block comments nest: /* outer /* inner */ still comment */
  • KDoc uses Markdown, not HTML
  • Link to symbols with [ClassName] or [function]
  • The first paragraph is the summary

KDoc in Practice

/**
 * Calculates the monthly payment on a loan.
 *
 * Uses the standard amortization formula. See [Loan] for inputs.
 *
 * @param principal amount borrowed, must be positive
 * @param annualRate yearly rate as a decimal, e.g. `0.05`
 * @param months number of monthly payments
 * @return the payment amount, rounded to cents
 * @throws IllegalArgumentException if [principal] is not positive
 * @sample com.example.LoanSamples.basic
 */
fun monthlyPayment(principal: Double, annualRate: Double, months: Int): Double {
    require(principal > 0) { "principal must be positive" }
    val r = annualRate / 12            // monthly rate
    /* Formula:
       P * r / (1 - (1 + r)^-n)  /* nested comment is fine */ */
    return principal * r / (1 - Math.pow(1 + r, -months.toDouble()))
}

Code Explained

[Loan] and [principal] become links in generated docs
@sample embeds a function's code as an example
The nested /* */ inside the block comment is legal Kotlin
require throws IllegalArgumentException with the message

Java Equivalent

  • Javadoc /** … */ with HTML and {@link Loan}
  • @param, @return, @throws work the same
  • Java block comments do not nest

Idiomatic Kotlin

  • HTML tags in KDoc → Markdown (**bold**, backticks)
  • comments that repeat the code → explain the why

KDoc Tags

⚠ Common Mistakes

  • Javadoc {@link X} syntax in KDoc (use [X])
  • Documenting every private helper and nothing public
  • Leaving commented-out code instead of deleting it

✓ Tips & Best Practices

  • Run Dokka (./gradlew dokkaHtml or dokkaGenerate) to publish docs
  • Use @property on data class docs for constructor properties
  • Write the first sentence as a one-line summary

Quick Summary

  • // /* */ — comments (nestable)
  • /** */ — KDoc
  • [Name] — link
  • Dokka — HTML docs
