Building Strings

buildString { } · StringBuilder · joinToString() · padStart / padEnd · "%.2f".format(x) · repeat()

Assembling Text Efficiently

For text built in loops, buildString { } gives you a StringBuilder and returns the final string. joinToString() turns any collection into a delimited string with optional prefix, suffix and transform. padStart, padEnd, repeat and format handle alignment and number formatting.

Key Points

  • buildString is the idiomatic StringBuilder
  • joinToString defaults to ", " as separator
  • format uses Java Formatter rules
  • repeat(n) repeats a string n times

buildString, joinToString, padding

val items = listOf("apple", "pear", "fig")

val report = buildString {
    appendLine("Fruit report")
    items.forEachIndexed { i, f -> appendLine("${i + 1}. $f") }
    append("Total: ${items.size}")
}
println(report)

println(items.joinToString())                    // apple, pear, fig
println(items.joinToString(" | "))               // apple | pear | fig
println(items.joinToString(prefix = "[", postfix = "]") { it.uppercase() })
                                                 // [APPLE, PEAR, FIG]
println("7".padStart(3, '0'))                    // 007
println("ID".padEnd(6, '.') + "|")               // ID....|
println("=".repeat(10))                          // ==========
println("%-8s%6.2f".format("Tea", 3.5))          // Tea       3.50
println("%,d".format(1234567))                   // 1,234,567

Code Explained

Inside buildString, this is the StringBuilder
appendLine adds text plus a newline
joinToString takes a transform lambda as the last argument
%-8s left-aligns in 8 columns; %6.2f right-aligns a number

Java Equivalent

  • var sb = new StringBuilder(); sb.append(…); sb.toString();
  • String.join(", ", items) or Collectors.joining(", ", "[", "]")
  • "x".repeat(10) (Java 11+) and String.format

Idiomatic Kotlin

  • var s = "" + s += … in a loop → buildString { }
  • manual comma logic → joinToString()

⚠ Common Mistakes

  • String += in large loops (creates many strings)
  • Locale surprises: format may use a comma decimal separator
  • Forgetting that joinToString already adds ", "

✓ Tips & Best Practices

  • Pass Locale.US with String.format(Locale.US, …) for fixed output
  • Use joinToString(limit = n) for long previews
  • Use appendLine instead of append("\n")
