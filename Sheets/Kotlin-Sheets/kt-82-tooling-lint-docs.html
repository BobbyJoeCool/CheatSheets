Lint, Docs & Scripting

ktlint · detekt · Dokka · Kotlin scripts .main.kts · @file:DependsOn · IntelliJ Java-to-Kotlin converter

Keeping Kotlin Code Healthy

ktlint enforces the official Kotlin style and can auto-format, detekt finds code smells and complexity problems, and Dokka generates documentation from KDoc. Kotlin scripts (.main.kts) run directly and can pull Maven dependencies, which makes Kotlin usable for automation.

Key Points

  • Official style guide: kotlinlang.org coding conventions
  • Both ktlint and detekt have Gradle plugins and IntelliJ integration
  • IntelliJ: Code → Convert Java File to Kotlin File
  • Scripts need kotlin on the PATH

Build Plugins and a Script

// build.gradle.kts
plugins {
    kotlin("jvm") version "2.2.0"
    id("org.jlleitschuh.gradle.ktlint") version "12.1.2"
    id("io.gitlab.arturbosch.detekt") version "1.23.8"
    id("org.jetbrains.dokka") version "2.0.0"
}
detekt {
    buildUponDefaultConfig = true
    config.setFrom("config/detekt.yml")
}
// ./gradlew ktlintCheck   ./gradlew ktlintFormat
// ./gradlew detekt        ./gradlew dokkaGenerate

// cleanup.main.kts  — run with:  kotlin cleanup.main.kts logs
@file:DependsOn("com.github.ajalt.clikt:clikt-jvm:5.0.3")

import java.io.File

val dir = File(args.firstOrNull() ?: ".")
val old = dir.walk()
    .filter { it.isFile && it.extension == "log" }
    .filter { System.currentTimeMillis() - it.lastModified() > 7 * 86_400_000L }
    .toList()
old.forEach { println("deleting ${it.name}"); it.delete() }
println("Removed ${old.size} files")

Code Explained

ktlint checks and fixes formatting
detekt reports long methods, magic numbers and other smells
Dokka turns KDoc into an HTML site
The script reads args and can declare dependencies inline

Java Equivalent

⚠ Common Mistakes

  • Adding detekt with the default config and drowning in warnings (baseline first)
  • Converting Java to Kotlin and keeping Java style (!!, getters)
  • Mixing formatter versions between IDE and CI

✓ Tips & Best Practices

  • Create a detekt baseline for existing code
  • Run ktlint in a pre-commit hook
  • Clean up converted code: remove !!, use properties and data classes
