Enum Classes

enum class · properties & methods on enums · entries · valueOf · exhaustive when · interfaces on enums

Fixed Sets of Values

An enum class defines a fixed set of constants. Enums can have constructor properties, methods, abstract members per constant, and can implement interfaces. entries lists all values (preferred over values()), and when over an enum is checked for exhaustiveness.

Key Points

  • name and ordinal are built in
  • entries (Kotlin 1.9+) returns an immutable list
  • valueOf("RED") throws on unknown names
  • Use enumValueOf<T>() / enumEntries<T>() generically

Enums with Data and Behavior

enum class Planet(val massKg: Double, val radiusM: Double) {
    MERCURY(3.303e23, 2.4397e6),
    EARTH(5.976e24, 6.37814e6);

    val gravity get() = 6.67e-11 * massKg / (radiusM * radiusM)
}

enum class Op(val symbol: String) {
    ADD("+") { override fun apply(a: Int, b: Int) = a + b },
    MUL("*") { override fun apply(a: Int, b: Int) = a * b };

    abstract fun apply(a: Int, b: Int): Int
}

enum class Status { ACTIVE, SUSPENDED, CLOSED }

println(Planet.EARTH.gravity)                 // ~9.8
println(Op.MUL.apply(3, 4))                   // 12
println(Status.entries)                       // [ACTIVE, SUSPENDED, CLOSED]
println(Status.CLOSED.ordinal)                // 2
println(Status.valueOf("ACTIVE"))             // ACTIVE
println(Status.entries.find { it.name == "PAUSED" })   // null (safe lookup)

fun label(s: Status) = when (s) {             // exhaustive, no else
    Status.ACTIVE    -> "Open"
    Status.SUSPENDED -> "On hold"
    Status.CLOSED    -> "Closed"
}

Code Explained

Each Planet constant passes values to the constructor
A semicolon ends the constants when members follow
Each Op constant overrides the abstract apply
entries.find is a safe alternative to valueOf

Java Equivalent

  • enum Planet { EARTH(5.976e24, 6.37814e6); … } (very similar)
  • Status.values() returns a new array each call
  • switch over enums without exhaustiveness checks (before Java 21)

Idiomatic Kotlin

  • Status.values() → Status.entries
  • String constants for states → enum (or sealed class for data per state)

⚠ Common Mistakes

  • Persisting ordinal (reordering constants breaks data)
  • valueOf on user input without handling the exception
  • Forgetting the semicolon before enum members

✓ Tips & Best Practices

  • Store name (or an explicit code property) in databases
  • Use entries.associateBy { it.code } for fast lookups
  • Let when exhaustiveness catch new constants

Quick Summary

  • enum class — fixed set

  • entries — all values
