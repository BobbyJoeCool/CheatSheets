Iterating with for

Kotlin's for loop iterates over anything with an iterator(): ranges, collections, strings and maps. There is no C-style for (i = 0; …); use ranges like 0..<n, downTo and step instead. withIndex() and indices give positions when you need them.

Key Points

  • 1..5 includes 5; 1..<5 and 1 until 5 exclude it
  • downTo counts backward
  • Destructure map entries: for ((k, v) in map)
  • Prefer forEach / collection functions for transforms

Loop Forms

for (i in 1..5) print(i)               // 12345
for (i in 0..<5) print(i)              // 01234
for (i in 10 downTo 0 step 3) print(" $i")  //  10 7 4 1
println()

val fruits = listOf("apple", "pear", "fig")
for (f in fruits) println(f)
for (i in fruits.indices) println("$i: ${fruits[i]}")
for ((i, f) in fruits.withIndex()) println("$i -> $f")

val prices = mapOf("tea" to 3.5, "cake" to 4.0)
for ((item, price) in prices) println("$item costs $price")

for (c in "hey") print(c.uppercaseChar())   // HEY
println()

for (row in 1..3) {
    for (col in 1..3) print("${row * col}\t")
    println()
}

fruits.forEachIndexed { i, f -> println("${i + 1}. $f") }

Code Explained

0..<5 is the clearest way to loop over sizes
step 3 skips by three
withIndex() gives index and value together
Map entries destructure into key and value

Java Equivalent

  • for (int i = 0; i < 5; i++)
  • for (String f : fruits)
  • for (var e : prices.entrySet()) { e.getKey(); e.getValue(); }

Idiomatic Kotlin

  • for (i in 0..list.size - 1) → for (i in list.indices)
  • index loops to build lists → map, filter (sheet 52)

Ranges

ExpressionValues
1..51, 2, 3, 4, 5
1..<5 / 1 until 51, 2, 3, 4
5 downTo 15, 4, 3, 2, 1

⚠ Common Mistakes

  • 0..list.size (one past the end)
  • Expecting for (i = 0; …) syntax
  • Modifying a list while iterating it (ConcurrentModificationException)

✓ Tips & Best Practices

  • Use indices or withIndex instead of manual counters
  • Use repeat(n) { } for "do this n times"
  • Prefer collection functions over loops that build results

Quick Summary

  • for (x in xs) — iterate
  • .. / ..< — ranges
  • downTo / step
  • withIndex() — index + value
