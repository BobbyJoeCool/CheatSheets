Sheet 40

Infix, Local & tailrec Functions

infix fun · to pairs · local functions · tailrec · recursion · Nothing-returning helpers

Special Function Forms

infix functions are called without dots or parentheses: a to b. Local functions are declared inside another function and can read its variables. tailrec tells the compiler to turn a tail-recursive function into a loop, so deep recursion does not overflow the stack.

Key Points

  • Infix functions: one parameter, member or extension
  • to creates a Pair: "a" to 1
  • Local functions keep helpers private to one function
  • tailrec requires the recursive call to be the very last operation

Under the JVM

  • tailrec compiles to a while loop with no extra stack frames
  • Local functions capturing variables compile to helper methods or closure objects
  • Infix calls compile to ordinary method calls

Infix, Local and tailrec

infix fun Int.percentOf(total: Int) = this * 100.0 / total
println(25 percentOf 200)              // 12.5

val pair = "Ada" to 36                 // Pair("Ada", 36)
val map = mapOf("a" to 1, "b" to 2)

data class Money(val cents: Long) {
    infix fun split(ways: Int) = Money(cents / ways)
}
println(Money(1000) split 4)           // Money(cents=250)

fun validate(user: User): List<String> {
    val errors = mutableListOf<String>()
    fun check(ok: Boolean, msg: String) { if (!ok) errors += msg }  // local
    check(user.name.isNotBlank(), "name required")
    check(user.age >= 0, "age must be >= 0")
    return errors
}

tailrec fun gcd(a: Int, b: Int): Int = if (b == 0) a else gcd(b, a % b)
println(gcd(48, 18))                   // 6

tailrec fun countDown(n: Long): Long = if (n == 0L) 0 else countDown(n - 1)
println(countDown(1_000_000))          // 0, no StackOverflowError

// not tail recursive: multiplies after the call
fun factorial(n: Int): Long = if (n <= 1) 1 else n * factorial(n - 1)

Code Explained

25 percentOf 200 reads like English
The local check can add to errors from the outer function
gcd calls itself as the last step, so tailrec applies
factorial multiplies after the call, so it is not tail recursive

Java Equivalent

  • No infix calls: Pair.of("Ada", 36) or Map.entry("a", 1)
  • No local functions; use a private method or a lambda
  • No tail-call optimization in Java; write a loop

Idiomatic Kotlin

  • private helpers used by one function → local functions
  • deep recursion → tailrec or a loop

Rules

FeatureRequirement
infixMember/extension, one param, no default/vararg
local funInside another function
tailrecRecursive call is the last operation

toBuilt-in infix for Pair

⚠ Common Mistakes

  • Adding tailrec to a non-tail function (warning, no optimization)
  • Overusing infix for things that read worse without dots
  • Recursing deeply without tailrec (StackOverflowError)

✓ Tips & Best Practices

  • Use infix for DSL-like code (shouldBe, to, until)
  • Use local functions to avoid passing many parameters
  • Watch for the compiler warning on invalid tailrec

Quick Summary

  • infix — a op b calls
  • to — make a Pair
  • local functions — private helpers
  • tailrec — recursion as a loop
