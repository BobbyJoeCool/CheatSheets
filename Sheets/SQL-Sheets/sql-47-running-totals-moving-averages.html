Sheet 47

Running Totals & Moving Averages

SUM() OVER · running total · moving average · cumulative count · percent of total

Cumulative and Sliding Calculations

Add ORDER BY to an aggregate's window and it becomes cumulative: sum(x) OVER (ORDER BY d) is a running total. Add a frame like ROWS BETWEEN 6 PRECEDING AND CURRENT ROW and it becomes a moving (sliding) calculation such as a 7-day average. Combined with GROUP BY, you can window over aggregates: sum(sum(total)) OVER (…) is a running total of daily totals. sum(x) OVER () gives the grand total for percent of total.

Running Facts

  • Default frame with ORDER BY includes ties (peers)
  • Use ROWS for exact row-count windows
  • Moving windows need one row per period: fill gaps first
  • Aggregates inside windows: sum(count(*)) OVER (…)

NoSQL Comparison

  • MongoDB: window: { documents: ['unbounded', 'current'] } → running total
  • window: { range: [-6, 0], unit: 'day' } → 7-day window
  • Inside $setWindowFields with sortBy

Running & Moving

-- Running total of revenue by day
SELECT order_date, sum(total) AS day_total,
       sum(sum(total)) OVER (ORDER BY order_date)
         AS running
FROM   orders
GROUP  BY order_date;

-- 7-row moving average of daily totals
SELECT order_date, day_total,
       avg(day_total) OVER (ORDER BY order_date
         ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS ma7
FROM  (SELECT order_date, sum(total) AS day_total
       FROM orders GROUP BY order_date) d;

-- Cumulative count and percent of total
SELECT category, count(*) AS n,
       sum(count(*)) OVER (ORDER BY count(*) DESC) AS cum,
       round(100.0 * count(*) / sum(count(*)) OVER (), 1)
         AS pct
FROM   products
GROUP  BY category;

Code Explained

sum(sum(total)) — window over the grouped daily sums
One row per day, so no ties share a running value
6 PRECEDING + current row = 7 rows
OVER () — grand total for the percentage

In an ORM

let run = 0;
const days = await prisma.order.groupBy({
  by: ['orderDate'], _sum: { total: true },
  orderBy: { orderDate: 'asc' },
});
const withRunning = days.map(d =>
  ({ ...d, running: (run += Number(d._sum.total)) }));

⚠ Common Mistakes

  • Ties on the sort key making several rows share a running total
  • Moving averages over data with missing days
  • Integer percent math: 100 * a / b truncating

✓ Tips & Best Practices

  • Fill missing days with a date spine first (sheet 34)
  • Use ROWS unless you want ties grouped
  • Round only the displayed result

Quick Summary

  • sum() OVER (ORDER BY …) — running
  • ROWS n PRECEDING — moving
  • OVER () — percent of total
