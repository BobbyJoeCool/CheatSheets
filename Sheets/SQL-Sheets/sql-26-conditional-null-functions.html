Conditional & NULL Functions

COALESCE · NULLIF · GREATEST · LEAST · IFNULL · ISNULL · NVL

Defaults and Guards

coalesce(a, b, …) returns its first non-NULL argument, so it's the standard way to supply a default. nullif(a, b) does the reverse: it returns NULL when a = b, which turns zeros into NULLs to prevent division errors, or empty strings into real NULLs. greatest and least pick the largest or smallest of their arguments. IFNULL, ISNULL and NVL are two-argument, engine-specific versions of coalesce.

Function Facts

  • coalesce stops at the first non-NULL argument
  • x / nullif(y, 0) → NULL instead of an error
  • sum() of no rows is NULL; wrap it in coalesce
  • PG greatest ignores NULLs; MySQL's returns NULL

NoSQL Comparison

  • MongoDB: $ifNull: ['$city', 'Unknown'] (several args from 5.0)
  • $max / $min over an array act as greatest / least
  • $cond with $eq mimics nullif

COALESCE, NULLIF & Friends

SELECT name, coalesce(category, 'Uncategorized') AS cat
FROM   products;
SELECT coalesce(city, country, 'n/a') FROM customers;

-- Avoid divide-by-zero
SELECT order_id,
       sum(unit_price * quantity)
         / nullif(sum(quantity), 0) AS avg_unit_price
FROM   order_items
GROUP  BY order_id;

-- Treat '' as missing, then default
SELECT coalesce(nullif(trim(city), ''), 'Unknown')
FROM   customers;

-- Aggregate over zero rows
SELECT coalesce(sum(total), 0) AS refunded
FROM   orders
WHERE  status = 'refunded';

SELECT greatest(10, 20, 5), least(10, 20, 5);  -- 20 | 5
SELECT name, greatest(price * 0.9, 5.00) AS sale
FROM   products;                   -- never below 5.00
SELECT greatest(1, NULL, 3);       -- 3 in PG

Code Explained

coalesce(city, country, …) tries each in turn
nullif(…, 0) makes the division return NULL, not fail
nullif(trim(city), '') turns blanks into NULL first
greatest(…, 5.00) puts a floor under a price

⚠ Common Mistakes

  • SQL Server ISNULL(code, 'unknown') cut to code's length
  • Showing a NULL sum as blank instead of 0
  • Using coalesce to hide bad joins instead of fixing them

✓ Tips & Best Practices

  • Prefer coalesce everywhere: it's standard and multi-arg
  • Turn sentinel values ('', 0, -1) into NULL with nullif
  • Default at display time; keep NULL in storage when it's true

Quick Summary

  • coalesce — first non-NULL
  • nullif — NULL when equal
  • greatest / least — max / min of args
