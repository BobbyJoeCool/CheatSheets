Aggregate Functions

COUNT(*) · COUNT(col) · SUM · AVG · MIN · MAX · NULL handling

Many Rows → One Value

An aggregate reduces a set of rows to one value. With no GROUP BY, the whole (filtered) table is one group and you get one row back. count(*) counts rows; count(col) counts non-NULL values. sum, avg, min and max ignore NULLs. Over zero rows, count returns 0 and the others return NULL. min and max work on text and dates as well as numbers.

Aggregate Facts

  • avg divides by the non-NULL count only
  • Plain columns + aggregates need GROUP BY (sheet 28)
  • Aggregates can't go in WHERE; use HAVING (sheet 29)
  • count(DISTINCT col) counts unique values

NoSQL Comparison

  • MongoDB: { $group: { _id: null, n: { $sum: 1 }, avg: { $avg: '$total' } } }
  • countDocuments(filter) for a plain count
  • $sum / $avg also skip missing and null values

Aggregates

SELECT count(*)        AS orders,
       count(total)    AS with_total,   -- skips NULL
       sum(total)      AS revenue,
       avg(total)      AS avg_order,
       min(order_date) AS first_order,
       max(order_date) AS last_order
FROM   orders
WHERE  status <> 'cancelled';

SELECT count(DISTINCT customer_id) AS buyers
FROM   orders;

-- NULLs and empty input
SELECT avg(x), sum(x), count(x), count(*)
FROM   (VALUES (10), (NULL), (20)) AS t(x);
-- 15 | 30 | 2 | 3
SELECT sum(total), count(*) FROM orders WHERE false;
-- NULL | 0

SELECT avg(coalesce(total, 0)) FROM orders; -- NULL = 0
SELECT min(name), max(name) FROM products;  -- text
SELECT customer_id, count(*) FROM orders;
-- ERROR: must appear in GROUP BY

Code Explained

avg of 10, NULL, 20 is 15, not 10
sum over no rows is NULL; wrap in coalesce(…, 0)
coalesce inside avg counts NULLs as zero
Adding a plain column requires GROUP BY

⚠ Common Mistakes

  • Using count(col) when you meant rows, or the reverse
  • Letting avg ignore NULLs that really mean 0
  • SQL Server AVG(qty) on an int column returning a whole number

✓ Tips & Best Practices

  • Filter with WHERE before aggregating; it's cheaper
  • Use FILTER for several conditional counts (sheet 29)
  • Cast before averaging ints: avg(qty * 1.0)

Quick Summary

  • count · sum · avg · min · max
  • NULLs skipped (except count(*))
  • No rows → count 0, others NULL
