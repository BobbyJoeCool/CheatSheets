What SQL Is

SQL (Structured Query Language) is the language of relational databases. It is declarative: you describe the result you want and the database's query planner decides how to get it. It grew out of E. F. Codd's 1970 relational model and IBM's SEQUEL prototype, became an ANSI standard in 1986 and an ISO standard in 1987, and the current edition is SQL:2023 (ISO/IEC 9075). Every RDBMS speaks a dialect: the core is portable, the edges are not.

SQL Facts

  • Say "S-Q-L" or "sequel"; both are common
  • A table is an unordered set of rows; without ORDER BY row order is not guaranteed
  • This set uses PostgreSQL 17+ and notes MySQL 8.4, SQL Server 2022+ and SQLite 3.45+

NoSQL Comparison

  • MongoDB stores JSON-like documents in collections; no fixed columns
  • Queries are method calls and pipelines, not one declarative statement
  • SELECT name FROM customers WHERE city = 'Oslo' ≈ db.customers.find({ city: "Oslo" }, { name: 1 })

A First Query

-- Which customers spent the most?
SELECT   c.name,
         SUM(o.total) AS spent
FROM     customers AS c
JOIN     orders    AS o ON o.customer_id = c.customer_id
WHERE    o.status <> 'cancelled'
GROUP BY c.name
HAVING   SUM(o.total) > 500
ORDER BY spent DESC
LIMIT    5;

-- The five sublanguages
SELECT name FROM products;               -- DQL
DELETE FROM orders WHERE order_id = 9;   -- DML
CREATE TABLE tags (tag_id INT);          -- DDL
GRANT SELECT ON products TO analyst;     -- DCL
COMMIT;                                  -- TCL

Code Explained

JOIN … ON — pairs each order with its customer (sheet 32)
WHERE filters rows, HAVING filters groups (sheet 29)
SUM(…) AS spent — aggregate with an alias
ORDER BY … LIMIT 5 — sort, then keep the top five

⚠ Common Mistakes

  • Expecting rows back in insert order without ORDER BY
  • Assuming a feature works everywhere because one engine has it
  • Writing loops over rows when one set-based statement would do

✓ Tips & Best Practices

  • Learn standard SQL first, then your engine's extras
  • Read a query in logical order: FROM first, SELECT near the end (sheet 03)
  • Develop against the same engine and version you run in production

Quick Summary

  • Standard — ISO/IEC 9075, latest SQL:2023
  • Dialects — PostgreSQL, MySQL, SQL Server, SQLite
  • Statements — DQL, DML, DDL, DCL, TCL
