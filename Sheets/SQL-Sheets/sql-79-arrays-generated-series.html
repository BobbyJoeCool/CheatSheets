Arrays & Generated Series

ARRAY[] · ANY(array) · unnest · array_agg · @> · generate_series

Lists in a Column, Rows from Nothing

PostgreSQL columns can hold arrays (text[], int[]). Test membership with = ANY (arr), containment with @> and overlap with &&. unnest turns an array into rows, and array_agg turns rows back into an array (sheet 31). Arrays are perfect for passing a list as one parameter. generate_series produces rows from nothing: number ranges, or one row per day for reports.

Array Facts

  • Arrays are 1-based: tags[1] is the first
  • Out-of-range index → NULL, not an error
  • Arrays suit small tag-like lists, not relations (sheet 62)
  • Other engines use JSON arrays instead

NoSQL Comparison

  • MongoDB arrays are native: find({ tags: 'led' }) matches an element
  • $all, $elemMatch, $push, $addToSet
  • $unwind = unnest; $push in $group = array_agg

Arrays & Series

ALTER TABLE products ADD COLUMN tags TEXT[] DEFAULT '{}';
UPDATE products SET tags = ARRAY['desk', 'led']
WHERE  product_id = 7;

SELECT name, tags[1] AS first_tag,
       cardinality(tags) AS n_tags
FROM   products;

SELECT name FROM products WHERE 'led' = ANY (tags);
SELECT name FROM products WHERE tags @> ARRAY['desk'];
SELECT name FROM products
WHERE  tags && ARRAY['sale', 'new'];    -- any overlap

-- Array → rows
SELECT p.name, t.tag
FROM   products p, unnest(p.tags) AS t(tag);

-- A list as one parameter
SELECT * FROM orders WHERE order_id = ANY ($1::int[]);

-- Rows from nothing
SELECT generate_series(1, 5);              -- 1 … 5
SELECT d::date
FROM   generate_series(DATE '2026-10-01',
                       DATE '2026-10-07',
                       INTERVAL '1 day') AS d;

Code Explained

'{}' is an empty array literal
= ANY (tags) — true if any element equals 'led'
@> all listed present · && at least one shared
$1::int[] — the driver sends one array value

⚠ Common Mistakes

  • Using arrays where a junction table belongs
  • Off-by-one: arrays start at 1
  • NOT ('x' = ANY (arr)) with NULL elements → UNKNOWN

✓ Tips & Best Practices

  • GIN-index array columns queried with @> or &&
  • Pass id lists as one array parameter, not many ?s
  • Left-join a series to fill reporting gaps (sheet 34)

Quick Summary

  • text[] · = ANY · @> · &&
  • unnest ↔ array_agg
  • generate_series for numbers and dates
