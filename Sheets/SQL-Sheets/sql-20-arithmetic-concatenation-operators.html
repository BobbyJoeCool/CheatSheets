Arithmetic & Concatenation Operators

+ - * / · % · integer division · || · CONCAT · operator precedence

Math and Joining Strings

SQL has the usual **+ - * / plus % for the remainder. Dividing two integers gives an integer** in PostgreSQL, SQL Server and SQLite (the fraction is dropped), but a decimal in MySQL. *, / and % bind before + and -. To join strings, the standard operator is ||; MySQL uses CONCAT() and SQL Server +. Any NULL operand makes the result NULL, except in CONCAT, which treats NULL as an empty string.

Operator Facts

  • Integer division truncates toward zero: -7 / 2 = -3
  • Dividing by zero is an error (MySQL: NULL)
  • x / NULLIF(y, 0) returns NULL instead (sheet 26)
  • || turns numbers into text automatically (PG)

NoSQL Comparison

  • MongoDB updates: $inc and $mul do arithmetic in place
  • Pipelines: $add, $multiply, $divide, $mod
  • $concat returns null if any input is null, like ||

Arithmetic & Concatenation

SELECT order_id,
       unit_price * quantity AS line_total,
       round(unit_price * quantity * 1.08, 2) AS with_tax
FROM   order_items;

SELECT 7 / 2, 7 / 2.0, 7 % 3;      -- 3 | 3.5000… | 1
SELECT -7 / 2, -7 % 3;             -- -3 | -1
SELECT 2 + 3 * 4, (2 + 3) * 4;     -- 14 | 20
SELECT 7 / 0;      -- ERROR: division by zero
SELECT 7 / NULLIF(0, 0);           -- NULL
SELECT 2 ^ 10;                     -- 1024 (PG: power)

SELECT first_name || ' ' || last_name AS full_name
FROM   employees;
SELECT 'Order #' || order_id FROM orders;
SELECT 'a' || NULL;                -- NULL
SELECT concat('a', NULL, 'b');     -- ab
SELECT concat_ws(', ', city, country) FROM customers;

Code Explained

round(…, 2) keeps money at two decimals
7 / 2.0 — one decimal operand makes it decimal division
% takes the sign of the left operand
concat_ws skips NULLs and puts the separator between

⚠ Common Mistakes

  • avg_qty = sum(qty) / count(*) silently truncating
  • MySQL 'a' || 'b' returning 0 (it's logical OR)
  • A NULL middle name blanking the whole || result

✓ Tips & Best Practices

  • Multiply by 1.0 or cast to get decimal division
  • Use concat_ws for optional parts of names and addresses
  • Round only at the end of a calculation

Quick Summary

  • + - * / % · * before +
  • int / int → int (not MySQL)
  • || · CONCAT · + (SQL Server)
