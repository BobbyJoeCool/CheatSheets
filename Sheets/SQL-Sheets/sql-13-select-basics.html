SELECT Basics

SELECT · FROM · * · column list · AS alias · computed columns · SELECT without FROM

Choosing Columns

SELECT lists what to return and FROM names the table it comes from. * returns every column; a column list returns only the ones you name, in that order. Each item can be an expression evaluated once per row (price * 0.9), and AS gives it an output name (an alias). With no FROM, SELECT just evaluates its expressions once, which is handy for testing functions.

SELECT Facts

  • Output column order = the order you list them
  • AS is optional: price * 2 doubled works
  • A missing comma makes an alias: SELECT name price
  • Table aliases shorten joins: FROM products p

NoSQL Comparison

  • MongoDB projection picks fields: find({}, { name: 1, price: 1, _id: 0 })
  • Computed fields need the aggregation pipeline: $project
  • { sale: { $multiply: ['$price', 0.9] } }

SELECT

SELECT * FROM products;                -- every column

SELECT name, price
FROM   products;                       -- chosen columns

SELECT name            AS product,
       price * 0.9     AS sale_price,  -- computed
       price * stock   AS stock_value,
       upper(category) AS category,
       'USD'           AS currency     -- constant
FROM   products;

SELECT p.name, p.price                 -- table alias
FROM   products AS p;

SELECT first_name || ' ' || last_name AS "Full Name"
FROM   employees;

SELECT 2 + 3 AS five, now() AS at;     -- no FROM
SELECT current_user, version();

Code Explained

* is fine for exploring; list columns in application code
Each expression runs once per row of products
"Full Name" — quoted alias keeps the space and capitals
No FROM → exactly one row of computed values

⚠ Common Mistakes

  • SELECT * in app code: breaks or slows down when columns change
  • A missing comma silently renaming a column
  • Using an alias in WHERE

✓ Tips & Best Practices

  • Alias every computed column so callers get a clear name
  • Qualify columns (p.name) as soon as there's a join
  • Use SELECT without FROM to try out a function

Quick Summary

  • SELECT cols FROM table
