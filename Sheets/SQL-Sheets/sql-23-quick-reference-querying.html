⚠ Common Mistakes

  • Filtering an aggregate in WHERE — use HAVING
  • Using a SELECT alias in WHERE (it doesn't exist yet in execution order)
  • NOT IN (subquery) when the subquery can return NULL — use NOT EXISTS

✓ Tips & Best Practices

  • Write CTEs to break a big query into named steps
  • Prefer UNION ALL unless you need duplicates removed
  • Use window functions instead of self-joins for rankings and running totals

Quick Summary

  • Runs: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
  • LEFT JOIN keeps every left row
  • COALESCE / IS NULL for nulls
  • OVER (PARTITION BY … ORDER BY …) for windows
