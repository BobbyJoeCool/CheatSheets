String & Array Aggregation

STRING_AGG · GROUP_CONCAT · ARRAY_AGG · LISTAGG · JSON_AGG · WITHIN GROUP

Collapsing Rows into Lists

These aggregates join a group's values into one list instead of one number. string_agg(x, ', ') builds delimited text; array_agg builds a PostgreSQL array; json_agg builds a JSON array, often of objects from json_build_object, so one query can return API-ready nested data. Add ORDER BY inside the call to control list order, and DISTINCT to drop repeats.

List Facts

  • Without ORDER BY inside, list order is arbitrary
  • NULL inputs are skipped by string_agg
  • MySQL GROUP_CONCAT cuts at 1,024 bytes by default
  • json_agg keeps NULLs as null

NoSQL Comparison

  • MongoDB: $push collects values into an array inside $group
  • $addToSet collects distinct values
  • With embedded documents the list is often already stored

String & Array Aggregation

-- Comma-separated product names per category
SELECT category,
       string_agg(name, ', ' ORDER BY name) AS products
FROM   products
GROUP  BY category;

SELECT string_agg(DISTINCT city, ' / ') FROM customers;

-- Arrays (PostgreSQL)
SELECT customer_id,
       array_agg(order_id ORDER BY order_date) AS orders
FROM   orders
GROUP  BY customer_id;

-- Nested JSON: one row per order with its items
SELECT o.order_id,
       json_agg(json_build_object(
         'product', p.name,
         'qty',     i.quantity)) AS items
FROM   orders o
JOIN   order_items i USING (order_id)
JOIN   products p    USING (product_id)
GROUP  BY o.order_id;

Code Explained

ORDER BY name inside the call sorts each list
DISTINCT inside drops repeated cities
json_build_object makes one JSON object per row
json_agg wraps them into an array per order

⚠ Common Mistakes

  • Forgetting ORDER BY inside and getting shuffled lists
  • MySQL lists silently cut at group_concat_max_len
  • Splitting the string back apart later: keep arrays or JSON

✓ Tips & Best Practices

  • Raise group_concat_max_len for long MySQL lists
  • Use jsonb_agg when you'll query the result further
  • array_agg(DISTINCT x ORDER BY x) for tidy, unique lists

Quick Summary

  • string_agg / GROUP_CONCAT → text
  • array_agg → array · json_agg → JSON
  • ORDER BY inside controls order
