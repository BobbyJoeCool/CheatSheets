ROLLUP, CUBE & GROUPING SETS

ROLLUP · CUBE · GROUPING SETS · GROUPING() · subtotals · WITH ROLLUP

Subtotals in One Query

These extensions run several groupings at once and stack the results. GROUPING SETS lists exactly which groupings you want; ROLLUP (a, b) is the hierarchy (a, b), (a), () — detail, subtotal, grand total; CUBE (a, b) is every combination. In subtotal rows the rolled-up columns are NULL, and GROUPING(col) returns 1 there, so you can tell a subtotal from a real NULL.

Facts

  • () is the empty grouping: the grand total
  • ROLLUP (a, b, c) → 4 levels; order matters
  • CUBE with n columns → 2ⁿ groupings
  • Sort with GROUPING() to put totals last

NoSQL Comparison

  • MongoDB has no ROLLUP
  • $facet runs several $group pipelines over the same input in one query
  • Or compute the total in the app from the detail rows

ROLLUP, CUBE & GROUPING SETS

-- Revenue by country and city, with subtotals
SELECT c.country,
       CASE WHEN GROUPING(c.city) = 1
            THEN '(subtotal)' ELSE c.city END AS city,
       sum(o.total) AS revenue
FROM   orders o
JOIN   customers c USING (customer_id)
GROUP  BY ROLLUP (c.country, c.city)
ORDER  BY c.country, GROUPING(c.city), city;

-- Every combination of department and hire year
SELECT dept_id,
       extract(YEAR FROM hire_date) AS yr,
       count(*)                     AS hires
FROM   employees
GROUP  BY CUBE (dept_id, extract(YEAR FROM hire_date));

-- Just the groupings you name
SELECT status, customer_id, count(*)
FROM   orders
GROUP  BY GROUPING SETS ((status), (customer_id), ());

Code Explained

ROLLUP adds a subtotal per country and one grand total
GROUPING(c.city) = 1 marks rows where city was rolled up
The grand-total row has NULL country and NULL city
GROUPING SETS here = 3 separate GROUP BYs, one scan

⚠ Common Mistakes

  • Treating subtotal NULLs as missing data
  • Getting ROLLUP column order backwards (city before country)
  • CUBE on many columns: rows explode

✓ Tips & Best Practices

  • Label totals with GROUPING(), not coalesce
  • Keep ROLLUP to 2–3 levels for readable reports
  • Format totals in the report tool, not in SQL

Quick Summary

  • ROLLUP — hierarchy + total
  • CUBE — all combinations
  • GROUPING SETS — exactly what you list
