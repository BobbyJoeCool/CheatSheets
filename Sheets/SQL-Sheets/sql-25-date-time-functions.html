Date & Time Functions

NOW() · CURRENT_DATE · EXTRACT · DATE_TRUNC · INTERVAL · DATEADD / DATEDIFF · TO_CHAR · AT TIME ZONE

Working with Dates

now() and current_date give the current moment and day (fixed for the whole transaction). extract(part FROM d) pulls out a year, month, weekday or hour. date_trunc('month', d) rounds down to the start of a unit, which is how you group by month. Add or subtract INTERVALs for date math, format with to_char, and convert zones with AT TIME ZONE. This is the area where dialects differ most.

Date Facts

  • now() is the transaction start; clock_timestamp() is live
  • date - date → whole days (PG)
  • DOW: 0 = Sunday; ISODOW: 1 = Monday
  • Group by date_trunc, not by to_char text

NoSQL Comparison

  • MongoDB: $dateTrunc, $dateAdd, $dateDiff, $dateToString
  • Each takes a timezone option, e.g. 'America/Chicago'
  • $year, $month, $dayOfWeek extract parts

Date & Time Functions

SELECT now(), current_date, current_timestamp;

SELECT extract(YEAR FROM order_date) AS yr,
       extract(DOW  FROM order_date) AS dow
FROM   orders;

-- Revenue per month
SELECT date_trunc('month', order_date) AS month,
       sum(total)                      AS revenue
FROM   orders
GROUP  BY month
ORDER  BY month;

SELECT order_date + INTERVAL '30 days' AS due FROM orders;
SELECT DATE '2026-12-25' - CURRENT_DATE AS days_left;
SELECT to_char(DATE '2026-10-18', 'Dy DD Mon YYYY');
-- Sun 18 Oct 2026
SELECT now() AT TIME ZONE 'Asia/Tokyo';

-- The last 7 full days
SELECT * FROM orders
WHERE  order_date >= CURRENT_DATE - 7
  AND  order_date <  CURRENT_DATE;

Code Explained

date_trunc('month', …) → the 1st of the month at 00:00
GROUP BY month — PG allows the output alias here
date - date returns an integer number of days
AT TIME ZONE on TIMESTAMPTZ → local wall-clock time

⚠ Common Mistakes

  • Grouping on to_char(d, 'Mon'): every year's October merges
  • WHERE date(created_at) = … blocking the index
  • Mixing up DATEDIFF argument order between engines

✓ Tips & Best Practices

  • Filter with half-open ranges on the raw column
  • Keep zone conversion at the edges (display, reports)
  • Generate missing days with generate_series (sheet 79)
