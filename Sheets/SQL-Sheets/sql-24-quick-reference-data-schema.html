⚠ Common Mistakes

  • UPDATE or DELETE without WHERE — run the SELECT version first
  • Money in FLOAT instead of DECIMAL
  • An index on every column — each one slows down writes

✓ Tips & Best Practices

  • Wrap related writes in one transaction
  • Name constraints (CONSTRAINT fk_order_user …) so errors are readable
  • Check EXPLAIN before and after adding an index

Quick Summary

  • INSERT / UPDATE / DELETE change rows; DDL changes tables
  • Upsert syntax differs per database
  • Keys and CHECKs keep data valid
  • Transactions: BEGIN → COMMIT or ROLLBACK
