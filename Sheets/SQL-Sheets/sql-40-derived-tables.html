Derived Tables

FROM (subquery) · required alias · inline view · nested aggregation · aggregate of aggregate

A Query as a Table

A derived table is a subquery in FROM; the outer query treats its result like a table (it's also called an inline view). It's the classic way to aggregate twice (average of per-customer counts), to filter on a column you computed, or to pre-aggregate a child table before joining it. Most engines require an alias after the parentheses, and every column needs a name.

Facts

  • Alias required in MySQL and SQL Server
  • Name computed columns, or alias them AS t(a, b)
  • The planner usually merges it into the outer query
  • Same idea, named up front: a CTE (sheet 41)

NoSQL Comparison

  • MongoDB pipelines nest naturally: $group, then $group again
  • [{ $group: { _id: '$customerId', n: { $sum: 1 } } }, { $group: { _id: null, avg: { $avg: '$n' } } }]

Derived Tables

-- Average number of orders per customer
SELECT avg(n) AS avg_orders
FROM  (SELECT customer_id, count(*) AS n
       FROM   orders
       GROUP  BY customer_id) AS per_customer;

-- Filter on a computed column
SELECT *
FROM  (SELECT name, price * stock AS stock_value
       FROM   products) AS t
WHERE  stock_value > 1000;

-- Largest order per customer, with its date
SELECT o.customer_id, o.order_id, o.total, o.order_date
FROM   orders o
JOIN  (SELECT customer_id, max(total) AS top
       FROM   orders
       GROUP  BY customer_id) m
  ON   m.customer_id = o.customer_id
 AND   m.top = o.total;

-- Name the columns on the alias
SELECT t.status, t.n
FROM  (SELECT status, count(*) FROM orders GROUP BY status)
       AS t(status, n);

Code Explained

avg(count(*)) isn't allowed; the derived table splits it in two
stock_value exists for the outer WHERE
Joining back on max(total) returns ties too
AS t(status, n) names unnamed columns

⚠ Common Mistakes

  • Forgetting the alias (MySQL, SQL Server error)
  • Unnamed expression columns in the derived table
  • Nesting three levels deep instead of using a CTE

✓ Tips & Best Practices

  • Switch to a CTE once nesting passes two levels
  • Pre-aggregate children to avoid join fan-out (sheet 35)
  • Push filters into the inner query when you can

Quick Summary

  • FROM (SELECT …) AS t
  • Aggregate twice, filter on aliases
  • Alias it (required in many engines)
