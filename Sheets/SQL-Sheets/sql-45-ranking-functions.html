Ranking Functions

ROW_NUMBER · RANK · DENSE_RANK · NTILE · PERCENT_RANK · CUME_DIST

Numbering and Ranking Rows

Ranking functions number rows by the window's ORDER BY. They differ only in how they treat ties. row_number gives every row a unique number (ties broken arbitrarily); rank gives ties the same number and then skips (1, 2, 2, 4); dense_rank doesn't skip (1, 2, 2, 3). ntile(n) splits rows into n nearly equal buckets; percent_rank and cume_dist express position as a fraction from 0 to 1.

Ranking Facts

  • Ranking needs ORDER BY inside OVER
  • row_number with ties is non-deterministic
  • Add a unique tie-breaker for stable numbering
  • ntile puts extra rows in the first buckets

NoSQL Comparison

  • MongoDB $setWindowFields outputs: $documentNumber, $rank, $denseRank
  • Same tie behavior as SQL's three functions

Ranking

SELECT name, price,
       row_number()   OVER w AS rn,
       rank()         OVER w AS rnk,
       dense_rank()   OVER w AS drnk,
       ntile(4)       OVER w AS quartile,
       percent_rank() OVER w AS pct,
       cume_dist()    OVER w AS cume
FROM   products
WINDOW w AS (ORDER BY price DESC);

-- Rank salaries within each department
SELECT dept_id, first_name, salary,
       dense_rank() OVER (PARTITION BY dept_id
                          ORDER BY salary DESC) AS pos
FROM   employees;

-- Stable numbering: break ties on the key
SELECT order_id, order_date,
       row_number() OVER (ORDER BY order_date, order_id)
         AS seq
FROM   orders;

Code Explained

All six share one named window w
PARTITION BY dept_id restarts the ranking per department
dense_rank — "2nd highest salary" stays 2 with ties at 1st
order_id makes seq the same on every run

Dialect Notes

Same in all four (MySQL 8.0+, SQLite 3.25+). QUALIFY for filtering on a rank exists only in DuckDB, Snowflake and BigQuery (sheet 49).

⚠ Common Mistakes

  • Expecting row_number ties to come out the same each run
  • Using rank for "Nth highest" and skipping N after ties
  • Forgetting ORDER BY inside OVER (error or meaningless)

✓ Tips & Best Practices

  • Always end the window's ORDER BY with a unique column
  • Filter on rank in an outer query or CTE (sheet 49)
  • percent_rank = (rank − 1) / (rows − 1)

Quick Summary

  • row_number — unique
  • rank — ties, gaps · dense_rank — ties, no gaps
  • ntile · percent_rank · cume_dist
