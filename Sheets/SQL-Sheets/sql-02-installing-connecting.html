Installing & Connecting

psql · mysql · sqlite3 · sqlcmd · connection string · GUI clients · Docker

Getting a Database

The quickest way to get a server engine is a Docker container: one command, nothing installed on your machine, and you can throw it away. You then connect with the engine's command-line client (psql, mysql, sqlcmd) or a GUI, using a host, port, user, password and database name, often packed into one connection string (URL). SQLite has no server at all: the client opens a file and the file is the database.

Clients

  • Cross-engine GUIs: DBeaver, DataGrip, TablePlus, Beekeeper Studio
  • Engine GUIs: pgAdmin, MySQL Workbench, SSMS, DB Browser for SQLite
  • Keep passwords in env vars (PGPASSWORD, .env), not in scripts

NoSQL Comparison

  • MongoDB: docker run -d -p 27017:27017 mongo:8
  • Client: mongosh "mongodb://localhost:27017/shop"
  • Redis: docker run -d -p 6379:6379 redis then redis-cli

Start & Connect

# PostgreSQL 17
docker run -d --name pg -p 5432:5432 \
  -e POSTGRES_PASSWORD=secret postgres:17
psql "postgresql://postgres:secret@localhost:5432/postgres"

# MySQL 8.4 LTS
docker run -d --name my -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=secret mysql:8.4
mysql -h 127.0.0.1 -P 3306 -u root -p

# SQL Server 2022
docker run -d --name ms -p 1433:1433 -e ACCEPT_EULA=Y \
  -e MSSQL_SA_PASSWORD='Str0ng!Passw0rd' \
  mcr.microsoft.com/mssql/server:2022-latest
sqlcmd -S localhost -U sa -P 'Str0ng!Passw0rd' -C

# SQLite: no server; creates the file if missing
sqlite3 shop.db < schema.sql

Code Explained

-p 5432:5432 — publish the container port to localhost
-p with no value — mysql prompts for the password
-C — sqlcmd trusts the self-signed certificate
< schema.sql — run a file of statements

⚠ Common Mistakes

  • Connecting to localhost from inside another container; use the service name
  • Forgetting GO in sqlcmd, so nothing runs
  • Committing a connection string with a real password to git

✓ Tips & Best Practices

  • Name containers and add a volume (-v pgdata:/var/lib/postgresql/data) to keep data
  • Pin the image tag (postgres:17) so upgrades are deliberate
  • Use a read-only user for GUI browsing of production

Quick Summary

  • Docker — fastest way to run a server engine
  • CLI — psql, mysql, sqlcmd, sqlite3
  • URL — engine://user:pass@host:port/db
  • SQLite — the file is the database
