Sheet 07

Inheritance & Global Keywords

inherited vs non-inherited · inherit · initial · unset · revert · revert-layer · all

What Children Get

If no declaration in the cascade sets a property on an element, inherited properties (mostly text: color, font-*, line-height, visibility, cursor) take the parent's computed value, while non-inherited properties (box and layout: margin, border, background, display) fall back to their initial value. Five global keywords work on every property to override that default, and all applies one of them to (almost) every property at once.

Notes

  • Custom properties (--x) inherit by default
  • Form controls don't inherit font in most UA stylesheets; set font: inherit
  • inherit copies the parent's computed value: em sizes are already resolved
  • all skips direction, unicode-bidi and custom properties

♿ Accessibility

  • all: unset on a button also removes its focus outline; add :focus-visible styles back
  • Inherited color keeps text and icons (currentColor) in sync in high-contrast themes

Browser Support

  • inherit, initial, unset: universal
  • revert: Baseline 2020; revert-layer: Baseline 2022

Code Explained

color and font flow down; border stops at body
font: inherit fixes controls that use the system font
unset acts as inherit or initial depending on the property
revert rolls back to the user-agent (or user) style
revert-layer rolls back to the value from earlier layers

Inheritance in Action

body {
  color: #222;            /* inherited by all text */
  font: 16px/1.5 system-ui;
  border: 1px solid red;  /* NOT inherited */
}

/* form controls ignore body font by default */
button, input, select, textarea {
  font: inherit;
  color: inherit;
}

a       { color: inherit; }   /* match parent */
.panel  { margin: initial; }  /* margin: 0 */
.reset  { color: unset; }     /* inherited → inherit */
.reset  { border: unset; }    /* non-inh. → initial */

/* back to browser default (UA style) */
h2.plain { font-size: revert; }

/* undo this layer, use the previous layer */
@layer theme {
  .card { color: revert-layer; }
}

/* blank slate component */
.widget { all: revert; }

Global Keywords

KeywordResult
inheritParent's computed value
initialSpec's initial value (display: initial is inline)
unsetinherit if inherited, else initial
revertValue from the previous origin (usually UA)
revert-layerValue from the previous cascade layer

Inherited?

PropertyInherits
color, font-*, line-heightYes
text-align, letter-spacingYes
visibility, cursorYes
list-style, quotesYes
margin, padding, borderNo
background, display, widthNo
opacity, transformNo (but affects children visually)

⚠ Common Mistakes

  • display: initial expecting the element's default: it gives inline; use revert
  • Expecting opacity to be inherited: children aren't set, they're painted with the parent
  • all: unset wiping focus outlines and button cursor

✓ Tips & Best Practices

  • Set type on body once and let it inherit
  • Use color: inherit on links inside colored components
  • Prefer revert over initial to get browser defaults back

Quick Summary

  • Text props inherit; box props don't
  • inherit / initial / unset
  • revert → browser default
  • all: … → every property at once
