Grid: Line-Based Placement

grid-column · grid-row · span · negative line numbers · named lines · grid-area shorthand

Placing Items on Lines

Grid lines are numbered from 1 at the start edge; negative numbers count from the end, so -1 is always the last explicit line. Place an item with grid-column: start / end and grid-row, or with span n to cover n tracks. Lines can also be named in the template ([content-start]) and used instead of numbers. Items you don't place are auto-placed into the next free cells.

Notes

  • A grid with 3 columns has 4 column lines
  • grid-column: 1 / -1 spans the full width of the explicit grid
  • Items placed in the same cells overlap; later ones paint on top (use z-index)
  • Lines named x-start and x-end create an implicit area called x

♿ Accessibility

  • Overlapping or reordered items still read in DOM order; check that order makes sense

Browser Support

  • All placement properties: Baseline Widely available

Code Explained

1 / -1: first line to last line
span 2: cover two tracks from wherever it's placed
content-start/content-end define an area named content
grid-area: 1 / 1 stacks every child in the same cell
grid-area with four values: row start, column start, row end, column end

Lines, Spans, Names

.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 8rem;
  gap: 1rem;
}

.hero    { grid-column: 1 / -1; }     /* full width */
.feature { grid-column: span 2; grid-row: span 2; }
.side    { grid-column: 4; grid-row: 2 / 4; }
.last    { grid-column: -2 / -1; }    /* last column */

/* named lines: full-bleed article layout */
.article {
  display: grid;
  grid-template-columns:
    [full-start] 1fr
    [content-start] min(65ch, 100% - 2rem) [content-end]
    1fr [full-end];
}
.article > *       { grid-column: content; }
.article > .bleed  { grid-column: full; }

/* overlap: text on image, same cell */
.banner > * { grid-area: 1 / 1; }

/* grid-area: row-start / col-start / row-end / col-end */
.box { grid-area: 2 / 1 / 4 / 3; }

⚠ Common Mistakes

  • Counting tracks instead of lines (3 columns = 4 lines)
  • Expecting -1 to mean the last implicit row: it's the last explicit line
  • Placing many items manually when auto-placement would work

✓ Tips & Best Practices

  • Use named lines for full-bleed article layouts
  • Stack layers with grid-area: 1 / 1 instead of absolute positioning
  • Show line numbers with the DevTools grid overlay

Quick Summary

  • Lines start at 1; -1 = last
  • start / end or span n
  • Named lines → areas
  • Same cell = overlap
