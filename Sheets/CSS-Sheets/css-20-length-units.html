Sheet 20

Length Units

px · em · rem · % · ch · lh · rlh · print units

Absolute and Relative

Absolute units are fixed: px is the CSS pixel (1/96 inch on screen, scaled by device), and cm, mm, in, pt, pc are tied to it (1in = 96px), so they mainly matter for print. Relative units scale with something: em with the element's font size, rem with the root's, ch with the width of 0, and lh with the line height. Use rem for most sizes so text and spacing follow the user's preferred font size.

Notes

  • em on font-size is relative to the parent's font size; elsewhere to the element's own
  • Nested em font sizes compound: 1.2em inside 1.2em = 1.44×
  • ch ≈ one character width; 65ch is a comfortable line length
  • rlh = root line height; useful for vertical rhythm

♿ Accessibility

  • px font sizes still zoom, but ignore the browser's default font-size setting; rem respects it
  • Size media queries in em/rem so layouts adapt when users enlarge text

Browser Support

  • px, em, rem, %, ch, ex, cm/mm/in/pt/pc: universal
  • lh, rlh: Baseline 2023
  • cap, ic, rex, rch: Baseline 2023–2024; check before use

Code Explained

font-size: 100% keeps the user's choice instead of forcing 16px
padding: .5em 1em scales with each button's own font size
1px borders stay crisp; text sizes use rem
1lh sizes an icon to exactly one line of text
pt and cm make sense for print styles

Choosing Units

html { font-size: 100%; }    /* user default, ~16px */

body {
  font-size: 1rem;               /* 16px */
  line-height: 1.5;
}

h1 {
  font-size: 2.5rem;             /* 40px */
  margin-block: 0 .5em;          /* .5 × 40 = 20px */
}

.btn {
  font-size: .875rem;            /* 14px */
  padding: .5em 1em;           /* scales with text */
  border: 1px solid;             /* hairlines in px */
}

.prose  { max-width: 65ch; }     /* line length */
.icon   { width: 1lh; height: 1lh; } /* match line */
.stack > * + * { margin-top: 1rlh; } /* rhythm */

/* compounding em */
.parent { font-size: 1.25em; }   /* 20px */
.parent .child { font-size: 1.25em; } /* 25px! */

@media print {
  body { font-size: 11pt; }
  .page { margin: 2cm; }
}

⚠ Common Mistakes

  • Setting html { font-size: 62.5% } then forgetting to restore body text to 1.6rem
  • Nesting em font sizes and getting compounding growth
  • Using px for all text, which ignores the user's default font size

✓ Tips & Best Practices

  • Default to rem for type and spacing, em for component-internal padding
  • Use ch for readable measure, px only for hairlines and shadows
  • Write breakpoints in em or rem, not px

Quick Summary

  • rem = root font size
  • em = current font size
  • ch = character width; lh = line height
  • 1in = 96px; print units for print
