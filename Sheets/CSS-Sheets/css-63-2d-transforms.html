Sheet 63

2D Transforms

transform · translate() · rotate() · scale() · skew() · transform-origin · individual transform properties · order of functions

Moving Without Reflow

transform moves, rotates, scales or skews an element visually, without affecting the layout around it. Functions apply in order, and each one moves the coordinate system for the ones after it, so rotate(45deg) translateX(100px) differs from the reverse. The individual properties translate, rotate and scale can be set and animated separately and always apply in that fixed order. Transforms are GPU-friendly, which makes them the go-to for animation.

Notes

  • transform-origin (default center) is the pivot for rotate, scale and skew
  • Percentages in translate refer to the element's own size
  • Individual properties apply before the transform property: translate → rotate → scale → transform
  • A transform creates a stacking context and a containing block for fixed children

♿ Accessibility

  • Large or spinning transform animations can trigger vestibular disorders; respect prefers-reduced-motion
  • Transforms don't change focus order or hit-testing order for keyboard users

Browser Support

  • transform 2D functions: universal
  • Individual translate, rotate, scale: Baseline 2022

Code Explained

translateX(-50%) moves by half the element's own width
scaleX(-1) mirrors horizontally
In .b, rotation turns the axes first, so the move is diagonal
transform-origin: bottom pivots a needle from its base
Separate translate and scale can have different transition timings

Transform Functions

.move    { transform: translate(20px, -10px); }
.center-x { transform: translateX(-50%); }   /* own width */
.spin    { transform: rotate(45deg); }
.grow    { transform: scale(1.1); }
.flip    { transform: scaleX(-1); }          /* mirror */
.slant   { transform: skew(-10deg); }

/* order matters */
.a { transform: translateX(100px) rotate(45deg); }
.b { transform: rotate(45deg) translateX(100px); }
/* .b moves along the rotated (diagonal) axis */

/* pivot point */
.door { transform-origin: left center;
        transform: rotateY(30deg); }
.needle { transform-origin: bottom; rotate: -30deg; }

/* individual properties: animate independently */
.card {
  translate: 0 0;
  scale: 1;
  transition: translate .2s, scale .3s;
}
.card:hover { translate: 0 -4px; scale: 1.02; }

/* absolute centering with transform */
.modal {
  position: fixed; top: 50%; left: 50%;
  translate: -50% -50%;
}

⚠ Common Mistakes

  • Overwriting a transform on hover and losing the first one (transform replaces all functions)
  • Animating left/top instead of translate, which forces layout every frame
  • Expecting a transform to push neighboring elements

✓ Tips & Best Practices

  • Use individual translate/rotate/scale properties to avoid overwriting
  • Animate only transform and opacity for smooth 60fps motion
  • Center with translate: -50% -50% when you can't use grid

Quick Summary

  • transform is visual only
  • Order of functions matters
  • transform-origin = pivot
  • translate / rotate / scale properties
