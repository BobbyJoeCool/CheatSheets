Sheet 68

View Transitions

@view-transition · view-transition-name · ::view-transition-old · ::view-transition-new · ::view-transition-group · startViewTransition()

Animating Between States

The View Transition API animates between two states of a page: the browser snapshots the old state, you update the DOM, and it crossfades to the new state. Elements given a view-transition-name morph individually (a thumbnail growing into a hero image). Same-document transitions start with document.startViewTransition(update) in JS; cross-document transitions between pages of one site only need @view-transition { navigation: auto; } in CSS on both pages.

Notes

  • Each view-transition-name must be unique on the page at that moment
  • The default is a crossfade; customize it through the ::view-transition-* pseudo-elements
  • view-transition-class styles several named transitions at once
  • The update still happens instantly where unsupported, so it's safe progressive enhancement

♿ Accessibility

  • Turn off or simplify view transitions under prefers-reduced-motion: reduce
  • Move focus to the new content after a same-document transition

Browser Support

  • Same-document view transitions: Chromium and Safari 18+, newer elsewhere; check before relying on them
  • Cross-document (@view-transition): Chromium and Safari, newer; ignored elsewhere

Code Explained

navigation: auto enables transitions for same-origin page loads
Matching names on both pages make the image morph
root is the whole page's snapshot
::view-transition-group() controls size and position animation
Feature-check startViewTransition and fall back to a plain update

Same- and Cross-Document

/* both pages: opt in to cross-page transitions */
@view-transition { navigation: auto; }

/* morph the product image between pages */
.product-thumb, .product-hero {
  view-transition-name: product-photo;
}

/* customize the default crossfade */
::view-transition-old(root) {
  animation: .25s ease-in both fade-out;
}
::view-transition-new(root) {
  animation: .35s ease-out both slide-in;
}

/* shape morph timing */
::view-transition-group(product-photo) {
  animation-duration: .4s;
}

@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*),
  ::view-transition-old(*),
  ::view-transition-new(*) { animation: none !important; }
}

/* same-document (JS):
   if (!document.startViewTransition) update();
   else document.startViewTransition(() => update()); */

⚠ Common Mistakes

  • Two visible elements with the same view-transition-name: the transition is skipped
  • Forgetting the opt-in on the destination page for cross-document transitions
  • Long or bouncy page transitions that slow navigation down

✓ Tips & Best Practices

  • Start with the default crossfade, then name one or two hero elements
  • Keep transitions under ~400ms
  • Assign names dynamically (inline style) for list items so they stay unique

Quick Summary

  • view-transition-name morphs elements
