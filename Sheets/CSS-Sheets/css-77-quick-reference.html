Quick Reference

selectors · at-rules · units · layout properties · functions · global keywords

CSS at a Glance

A one-page summary of the syntax covered in this set: the selectors you'll use most, the at-rules, units, layout properties, functions and the global keywords that work on every property. Each line points back to the sheet with the full explanation. When something on this page surprises you, open DevTools and check the cascade (sheet 05) and specificity (sheet 06) first.

Notes

  • Specificity: (IDs, classes/attributes/pseudo-classes, types/pseudo-elements)
  • Cascade: origin & importance → inline → layer → specificity → order
  • Inherited: text properties; not inherited: box and layout properties
  • Prefer rem, gap, logical properties and @layer in new code

♿ Accessibility

  • Focus: :focus-visible ring · Contrast: 4.5:1 / 3:1 · Motion: prefers-reduced-motion · Hide visually: .visually-hidden

Browser Support

  • Widely available: grid, flex gap, clamp(), aspect-ratio, :has(), nesting, container queries
  • Newly available: @property, light-dark(), relative colors, @starting-style, text-wrap: balance
  • Check first: anchor positioning, scroll-driven animations, @scope, view transitions

Code Explained

Combinators: space, >, +, ~
Conditional at-rules: @media, @container, @supports
Definition at-rules: @property, @font-face, @keyframes
repeat(auto-fit, minmax()) = responsive grid in one line
clamp() + var() cover most dynamic values

⚠ Common Mistakes

  • Fixing a cascade problem with !important instead of layers or lower specificity
  • Fixed px sizes everywhere instead of rem and intrinsic sizing
  • Removing focus outlines

✓ Tips & Best Practices

  • Start every project with a reset, tokens and a layer order
  • Reach for grid and flex gap before margins
  • Check Baseline status before shipping new features without fallbacks
