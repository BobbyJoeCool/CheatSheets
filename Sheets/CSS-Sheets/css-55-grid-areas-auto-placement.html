Grid: Areas & Auto-Placement

grid-template-areas · grid-auto-flow · dense · grid-auto-rows · grid-auto-columns · implicit grid

Named Areas and the Implicit Grid

grid-template-areas draws a layout as ASCII art: each string is a row, each word a cell, and repeating a name spans it. Items join an area with grid-area: name. Items without a position are auto-placed, filling rows by default. When they run past the defined tracks, the grid adds implicit rows (or columns) sized by grid-auto-rows / grid-auto-columns, and grid-auto-flow: dense backfills gaps left by large items.

Notes

  • Each area must be a rectangle; L-shapes are invalid
  • A . marks an empty cell
  • All rows in the template must have the same number of cells
  • Redefining the template in a media query rearranges the whole page

♿ Accessibility

  • dense packing can move items out of reading order visually; avoid it for content where sequence matters

Browser Support

  • Template areas, auto-flow, implicit tracks: Baseline Widely available

Template Areas

.page {
  display: grid;
  grid-template-columns: 14rem 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "nav    main"
    "footer footer";
  min-height: 100dvh;
}
.page > header { grid-area: header; }
.page > nav    { grid-area: nav; }
.page > main   { grid-area: main; }
.page > footer { grid-area: footer; }

/* rearrange on small screens */
@media (width < 48rem) {
  .page {
    grid-template-columns: 1fr;
    grid-template-areas: "header" "main" "nav" "footer";
  }
}

/* implicit rows and dense packing */
.gallery {
  display: grid;
  grid-template-columns:
    repeat(auto-fill, minmax(10rem, 1fr));
  grid-auto-rows: 10rem;
  grid-auto-flow: dense;
}
.gallery .wide { grid-column: span 2; }

⚠ Common Mistakes

  • Uneven row lengths or L-shaped areas: the whole template is invalid
  • Forgetting grid-area on children, so they auto-place instead
  • Using grid-auto-flow: dense on content lists and scrambling reading order

✓ Tips & Best Practices

  • Use template areas for page layouts; they're readable and easy to rearrange
  • Set grid-auto-rows for galleries so rows stay even
  • Use minmax(auto, …) implicit rows for content of varying height
