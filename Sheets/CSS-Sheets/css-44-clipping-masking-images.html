Clipping, Masking & Images

clip-path · circle()/polygon()/inset() · mask-image · mask-size · object-fit · object-position · image-rendering

Shaping What Shows

clip-path cuts an element to a shape: everything outside is invisible and doesn't receive clicks. Shapes include inset(), circle(), ellipse(), polygon() and path(). Masks are softer: mask-image uses an image's alpha (often a gradient) so parts fade rather than cut. For replaced elements like <img> and <video>, object-fit controls how content fills its box and object-position where it's anchored.

Notes

  • Clip-path shapes with the same number of points can be animated
  • mask is a shorthand like background, with size, position and repeat
  • object-fit: cover is the <img> version of background-size: cover
  • image-rendering: pixelated keeps pixel art crisp when scaled

♿ Accessibility

  • Clipped content is still read by screen readers; don't use clip-path to hide information
  • Make sure clipped buttons keep a large enough click area

Browser Support

  • clip-path basic shapes, object-fit, object-position: universal
  • Unprefixed mask-*: Baseline 2023; clip-path: shape(): newer

Code Explained

circle(50%): radius half the box
polygon() takes x y pairs, clockwise
Animating inset() from full to zero reveals left to right
Mask: black (opaque) shows, transparent hides
currentColor background + SVG mask = a single-color icon you can recolor

Clip, Mask, Fit

.avatar { clip-path: circle(50%); }
.diag   { clip-path: polygon(0 0, 100% 0,
                            100% 85%, 0 100%); }
.inset  { clip-path: inset(10px round 12px); }
.tri    { clip-path: polygon(50% 0, 100% 100%, 0 100%); }

/* reveal animation */
.reveal {
  clip-path: inset(0 100% 0 0);
  transition: clip-path .6s ease;
}
.reveal.is-visible { clip-path: inset(0 0 0 0); }

/* fade edges with a mask */
.scroller {
  mask-image: linear-gradient(90deg,
    transparent, #000 10%, #000 90%, transparent);
}

/* icon colored by CSS */
.icon {
  background: currentColor;
  mask: url("icon.svg") center / contain no-repeat;
}

/* images that fill a fixed box */
.thumb {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
  object-position: 50% 25%;   /* keep faces */
}
.pixel-art { image-rendering: pixelated; }

⚠ Common Mistakes

  • Hiding text with clip-path and assuming it's hidden from screen readers
  • Forgetting a fixed size or aspect-ratio on object-fit images
  • Animating between polygons with different point counts (it jumps)

✓ Tips & Best Practices

  • Use object-fit: cover for thumbnails and hero images
  • Fade scroll edges with a gradient mask-image
  • Use mask icons to recolor SVGs with currentColor

Quick Summary

  • clip-path hard cut
  • mask-image soft fade
  • object-fit: cover for <img>
  • object-position sets the crop anchor
