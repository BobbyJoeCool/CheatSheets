Sheet 14

Pseudo-Classes: User Action & Links

:hover · :active · :focus · :focus-visible · :focus-within · :link · :visited · :target

Reacting to the User

User-action pseudo-classes match elements in a temporary interaction state: :hover under the pointer, :active while pressed, :focus when focused. :focus-visible matches only when the browser decides a focus ring should show (keyboard use), so you can style keyboard focus without boxing every mouse click. Link pseudo-classes split links into :link (unvisited) and :visited, and :target matches the element named by the URL fragment.

Notes

  • Order link states LVHA: :link, :visited, :hover, :active (equal specificity)
  • :visited can only change colors, for privacy
  • :focus-within matches a parent when anything inside it has focus
  • :any-link matches both :link and :visited

♿ Accessibility

  • Never remove focus styles without a replacement; use :focus-visible with at least a 2px, 3:1-contrast outline
  • Touch screens have no hover; don't hide essential content behind :hover

Browser Support

  • All on this sheet: Baseline Widely available
  • :focus-visible: Baseline 2022

Code Explained

LVHA order stops :visited from overriding :hover
:focus-visible shows the ring for keyboard, not mouse clicks
:focus:not(:focus-visible): an older pattern; usually unneeded now
:focus-within styles a container while a child is focused
@media (hover: hover) keeps hover effects off touch devices

States in Order

/* LVHA order */
a:link    { color: #5b4bc4; }
a:visited { color: #7b1fa2; }
a:hover   { text-decoration-thickness: 3px; }
a:active  { color: #311b92; }

/* keyboard focus only */
:focus-visible {
  outline: 3px solid #ff9800;
  outline-offset: 2px;
}

/* mouse focus: no ring (keyboard ring kept) */
button:focus:not(:focus-visible) {
  outline: none;
}

/* highlight a whole form row */
.field:focus-within { background: #f3f0ff; }

/* jump-to section */
:target {
  scroll-margin-top: 4rem;
  animation: flash 1s;
}

/* hover only on devices that can hover */
@media (hover: hover) {
  .card:hover { translate: 0 -2px; }
}

⚠ Common Mistakes

  • :focus { outline: none; } with no replacement: keyboard users get lost
  • Writing a:hover before a:visited: visited links never show hover
  • Showing menus on :hover only: touch and keyboard users can't open them

✓ Tips & Best Practices

  • Style :focus-visible globally once, then tweak per component
  • Pair :hover with :focus-visible so keyboard users get the same feedback
  • Use :target with scroll-margin-top under a sticky header
