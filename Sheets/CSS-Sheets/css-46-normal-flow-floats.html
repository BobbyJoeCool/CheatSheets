Normal Flow & Floats

block vs inline flow · float · clear · clearfix · block formatting context · shape-outside

The Default Layout

Without flex, grid or positioning, elements lay out in normal flow: block boxes stack vertically and fill the width, inline boxes run along lines and wrap like text. A float is pulled to the left or right edge and inline content wraps around it. Floats were once used for whole page layouts; today they're for what they were designed for: wrapping text around images and pull quotes, optionally along a shape with shape-outside.

Notes

  • Floats are removed from block flow but still push inline content aside
  • A parent containing only floats collapses to zero height unless it's a BFC
  • clear: both moves an element below earlier floats
  • float: inline-start follows text direction

♿ Accessibility

  • Floated content still reads in source order; place the float in the HTML near the text it relates to

Browser Support

  • float, clear: universal; shape-outside: Baseline Widely available
  • float: inline-start / inline-end: Baseline 2023

Code Explained

Text and inline content flow around the floated image
shape-outside lets text follow the circle, not the box
flow-root makes the parent wrap its floats
The clearfix pseudo-element clears floats inside old layouts
clear: both pushes the footer under every float

Floating and Clearing

/* wrap text around an image */
.article img.left {
  float: left;
  width: 40%;
  margin: 0 1rem 1rem 0;
}

/* wrap along a circle */
.portrait {
  float: right;
  width: 12rem;
  aspect-ratio: 1;
  border-radius: 50%;
  shape-outside: circle(50%);
  shape-margin: 1rem;
}

/* contain floats in the parent */
.media { display: flow-root; }

/* legacy clearfix (old codebases) */
.clearfix::after {
  content: "";
  display: table;
  clear: both;
}

/* start below any floats */
.article footer { clear: both; }

/* drop cap */
.drop::first-letter {
  float: left;
  font-size: 3.2em;
  line-height: .8;
  margin: .1em .1em 0 0;
}

⚠ Common Mistakes

  • Building columns with floats instead of flex or grid
  • Forgetting to contain floats, so the parent's background disappears
  • Floating flex or grid items: float has no effect on them

✓ Tips & Best Practices

  • Use floats only for text wrap; use flex/grid for layout
  • Add shape-margin so text doesn't touch the shape
  • Use display: flow-root instead of clearfix

Quick Summary

  • Normal flow: blocks stack, inlines wrap
  • float for text wrap only
  • clear: both drops below floats
  • flow-root contains floats
