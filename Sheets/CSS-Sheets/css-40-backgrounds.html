Sheet 40

Backgrounds

background-image · background-size · cover/contain · background-position · background-repeat · background-clip · multiple backgrounds

Painting Behind Content

An element's background is a color plus any number of image layers (images or gradients). Each layer has its own size, position, repeat, origin and clip, listed comma-separated with the first layer on top. background-size: cover fills the box and crops; contain fits the whole image and may leave gaps. background-clip decides where painting stops (border, padding, content or text).

Notes

  • background-color always paints under every image layer
  • In the shorthand, size follows position after a slash: center / cover
  • background-attachment: fixed is ignored on most mobile browsers
  • background-clip: text + transparent text fills letters with the background

♿ Accessibility

  • Background images can't have alt text; put meaningful images in <img>
  • Set a background-color close to the image's average so text stays readable while it loads or if it fails

Browser Support

  • Multiple backgrounds, size, origin, clip: universal
  • background-clip: text: works everywhere, but keep the -webkit- version too for older Chrome/Safari

Code Explained

Background color first so text is readable before the image loads
center 30%: horizontal then vertical position
/ cover after the position sets the size in the shorthand
The scrim gradient sits on top of the photo
background-clip: text shows the background only through the glyphs

Layers and Sizing

.hero {
  background-color: #1d1b26;                /* fallback */
  background-image: url("mountains.webp");
  background-size: cover;
  background-position: center 30%;
  background-repeat: no-repeat;
}

/* same thing as a shorthand */
.hero {
  background: #1d1b26 url("mountains.webp")
              center 30% / cover no-repeat;
}

/* multiple layers: first is on top */
.banner {
  background:
    linear-gradient(#0000, #000a),           /* scrim */
    url("photo.jpg") center / cover;
}

/* pattern tile */
.dots {
  background: radial-gradient(#ccc 1px, transparent 1px)
              0 0 / 16px 16px;
}

/* gradient text */
.gradient-text {
  background: linear-gradient(90deg, #5b4bc4, #00bcd4);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

⚠ Common Mistakes

  • Putting content images (products, people) in CSS backgrounds: no alt text, no lazy-loading control
  • Setting background shorthand after background-size and resetting it
  • Forgetting color: transparent with background-clip: text

✓ Tips & Best Practices

  • Add a gradient scrim layer under text on photos
  • Use image-set() for resolution-aware background images
  • Prefer <img> + object-fit for important or LCP images

Quick Summary

  • Layers: first = top
  • center / cover no-repeat
  • cover crops, contain fits
  • background-clip: text for gradient text
