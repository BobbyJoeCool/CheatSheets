Sheet 47

Positioning

static · relative · absolute · fixed · sticky · inset · containing block · sticky gotchas

Taking Boxes Out of Place

position changes how a box is placed. relative shifts it visually without moving its space. absolute removes it from flow and places it relative to its containing block, the nearest positioned ancestor. fixed is relative to the viewport. sticky acts like relative until scrolling reaches its offset, then sticks within its parent. Offsets use top, right, bottom, left or the inset shorthand.

Notes

  • "Positioned" means any value except static
  • transform, filter or contain on an ancestor become the containing block for fixed children
  • Absolute boxes shrink-wrap; give inset: 0 or a width to fill
  • Sticky needs an offset (top: 0) and fails inside an ancestor with overflow: hidden

♿ Accessibility

  • Fixed headers can cover focused elements; add scroll-padding-top to the scroller (WCAG 2.4.11)
  • Positioning changes visual order only; tab and reading order follow the HTML

Browser Support

  • All position values: universal; inset: Baseline 2021

Code Explained

position: relative on the card makes it the containing block
inset: 0 stretches an absolute box to all four edges
inset: 0 + fixed size + margin: auto centers it
inset: auto 1rem 1rem auto = bottom-right corner
Sticky headers need a background or content shows through

Position Values

.card { position: relative; }      /* anchor for children */

.card .badge {
  position: absolute;
  top: .5rem;
  right: .5rem;
}

/* fill the parent */
.overlay {
  position: absolute;
  inset: 0;                        /* all four edges 0 */
}

/* center absolutely */
.center {
  position: absolute;
  inset: 0;
  margin: auto;
  width: 10rem; height: 4rem;
}

/* stays on screen */
.toast { position: fixed; inset: auto 1rem 1rem auto; }

/* sticks while its section scrolls */
.section-head {
  position: sticky;
  top: 0;
  background: var(--surface);      /* hide content below */
}

/* account for a fixed header */
html { scroll-padding-top: 4rem; }

⚠ Common Mistakes

  • Forgetting position: relative on the parent, so the absolute child aligns to the page
  • A transform on an ancestor breaking position: fixed
  • Sticky inside an overflow: hidden wrapper

✓ Tips & Best Practices

  • Use inset instead of four offsets
  • Use overflow: clip when you need clipping without breaking sticky
  • Prefer grid or flex for layout; position for overlays and badges

Quick Summary

  • relative = shift, keep space
  • absolute = out of flow, nearest positioned ancestor
  • fixed = viewport; sticky = scroll-dependent
  • inset: 0 fills
