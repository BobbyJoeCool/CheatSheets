Variable Fonts & Features

font-variation-settings · wght/wdth axes · font-optical-sizing · font-feature-settings · tabular-nums · ligatures

One File, Many Styles

A variable font packs a continuous range of styles into one file along axes: weight (wght), width (wdth), slant (slnt), italic (ital), optical size (opsz) and custom ones. Use the normal properties (font-weight: 650) for registered axes, and font-variation-settings only for custom ones. OpenType features (tabular numbers, small caps, ligatures) are switched on with high-level font-variant-* properties, or font-feature-settings as a last resort.

Notes

  • Declare the range in @font-face: font-weight: 100 900
  • Registered axes are lowercase (wght); custom axes are uppercase (GRAD)
  • font-variation-settings and font-feature-settings reset all unlisted values when redeclared
  • font-optical-sizing: auto adjusts detail for small and large sizes

♿ Accessibility

  • Tabular figures keep numbers aligned in tables, which helps scanning
  • Grade (GRAD) changes weight without changing width, useful for dark mode or hover without reflow

Browser Support

  • Variable fonts and font-variation-settings: Baseline Widely available
  • font-variant-numeric, font-optical-sizing: universal

Code Explained

font-weight: 300 1000 tells the browser the file covers that range
Use font-stretch for wdth and font-weight for wght
Uppercase tags are font-specific custom axes
tabular-nums: every digit has the same width
font-feature-settings for stylistic sets the high-level props don't cover

Axes and Features

@font-face {
  font-family: "Recursive";
  src: url("recursive.woff2") format("woff2");
  font-weight: 300 1000;           /* range */
  font-display: swap;
}

h1 { font-weight: 850; }           /* any value in range */
.condensed { font-stretch: 75%; }  /* wdth axis */
.mono { font-variation-settings: "MONO" 1; } /* custom */

/* animate weight smoothly */
.link { transition: font-weight .2s; }
.link:hover { font-weight: 700; }

/* numbers */
.price, td.num {
  font-variant-numeric: tabular-nums lining-nums;
}
.fraction { font-variant-numeric: diagonal-fractions; }
.zero     { font-variant-numeric: slashed-zero; }

/* ligatures and caps */
code      { font-variant-ligatures: none; }
.label    { font-variant-caps: all-small-caps; }

/* low-level fallback */
.ss01 { font-feature-settings: "ss01" 1, "cv11" 1; }

⚠ Common Mistakes

  • Using font-variation-settings: "wght" 700 instead of font-weight, which breaks inheritance and bolder/lighter
  • Redeclaring font-feature-settings and silently dropping earlier features
  • Forgetting the range in @font-face, so the browser synthesizes weights

✓ Tips & Best Practices

  • Prefer high-level properties; use the low-level settings only for custom axes and stylistic sets
  • Use tabular-nums in tables, prices and timers
  • One variable file often beats four static weights in total size
