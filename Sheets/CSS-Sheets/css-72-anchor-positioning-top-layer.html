Sheet 72

Anchor Positioning & Top Layer

anchor-name · position-anchor · anchor() · position-area · position-try · dialog & popover styling · ::backdrop

Tooltips and Menus Without JS Math

Anchor positioning places an absolutely positioned element relative to another element anywhere in the page. Name the anchor with anchor-name, point at it with position-anchor, then place with position-area (a 3×3 grid around the anchor) or the anchor() function in inset properties. position-try-fallbacks flips the element when it would overflow. Combined with popovers and dialogs, which live in the top layer, it covers tooltips, menus and modals.

Notes

  • Anchor names are dashed idents: anchor-name: --menu-btn
  • position-area: bottom span-right places below, aligned to the anchor's left edge
  • Top-layer elements ignore z-index and ancestors' overflow and transforms
  • ::backdrop styles the layer behind a modal dialog or popover

♿ Accessibility

  • Use <button popovertarget> and <dialog>: they wire up focus, Escape and ARIA for you
  • Tooltips must show on focus as well as hover, and be dismissible (WCAG 1.4.13)

Browser Support

  • <dialog>, ::backdrop: Baseline 2022; Popover API: Baseline 2024
  • Anchor positioning: newer, Chromium and Safari 26+; check support and provide a fallback position

Code Explained

popovertarget toggles the popover; no JS needed
anchor-name on the button, position-anchor on the menu
position-area positions in the grid around the anchor
flip-block moves the menu above if there's no room below
anchor(top) = the anchor's top edge, usable in any inset

Anchored Popover Menu

/* HTML:
   <button popovertarget="menu" class="menu-btn">
     Options</button>
   <div id="menu" popover>…</div> */

.menu-btn { anchor-name: --menu-btn; }

#menu {
  position-anchor: --menu-btn;
  position-area: bottom span-right; /* below, left edge */
  margin: 0;
  margin-top: .25rem;
  position-try-fallbacks: flip-block, flip-inline;
}

/* with anchor() for exact edges */
.tooltip {
  position: absolute;
  position-anchor: --target;
  bottom: anchor(top);
  left: anchor(center);
  translate: -50% -.5rem;
}

/* fallback for browsers without anchors */
@supports not (anchor-name: --a) {
  #menu { inset: auto; top: 3rem; left: 1rem; }
}

/* modal dialog */
dialog { border: 0; border-radius: 12px; padding: 1.5rem;
         max-width: min(32rem, 100% - 2rem); }
dialog::backdrop { background: rgb(0 0 0 / .5);
                   backdrop-filter: blur(2px); }

⚠ Common Mistakes

  • Building tooltips that only appear on hover
  • Fighting z-index for modals instead of using <dialog> + showModal()
  • No fallback position where anchor positioning isn't supported

✓ Tips & Best Practices

  • Pair popover + anchor positioning for menus and tooltips
  • Add position-try-fallbacks so menus stay on screen
  • Use the Floating UI library where you need anchoring everywhere today

Quick Summary

  • anchor-name + position-anchor
  • position-area or anchor()
  • position-try-fallbacks flips
  • Top layer: dialog, popover
