Sheet 65

Transitions

transition-property · duration · timing functions · delay · cubic-bezier() · steps() · transition-behavior · @starting-style

Smooth State Changes

A transition animates a property between its old and new value whenever it changes, for example on hover or when a class is added. Specify which property, how long, the timing function (easing) and an optional delay. Only interpolable values transition (lengths, colors, numbers, transforms). Newer features let discrete properties like display take part (transition-behavior: allow-discrete) and define entry styles with @starting-style.

Notes

  • Put the transition on the base state so it runs both ways
  • List several: transition: opacity .2s, translate .3s ease-out
  • transition: all is easy but animates things you didn't mean to
  • height: auto can't transition without interpolate-size or grid tricks

♿ Accessibility

  • Keep UI transitions short (100–300ms) and wrap larger motion in prefers-reduced-motion: no-preference

Browser Support

  • Transitions, cubic-bezier(), steps(): universal; linear() easing: Baseline 2023
  • @starting-style, transition-behavior: Baseline 2024

Code Explained

Transition defined on .btn, so it plays on hover and un-hover
Shorter duration on :active feels snappier
cubic-bezier() defines a custom ease curve
allow-discrete lets display flip at the right moment
@starting-style sets the "from" values for an element's first render

Transition Recipes

.btn {
  background: #5b4bc4;
  transition: background-color .2s ease,
              translate .2s ease-out;
}
.btn:hover  { background: #4a3bb0; translate: 0 -2px; }
.btn:active { translate: 0; transition-duration: .05s; }

/* custom easing */
.drawer {
  translate: -100% 0;
  transition: translate .35s cubic-bezier(.2, .8, .2, 1);
}
.drawer.open { translate: 0 0; }

/* fade in a popover, including display */
[popover] {
  opacity: 0;
  transition: opacity .2s, display .2s allow-discrete,
              overlay .2s allow-discrete;
}
[popover]:popover-open { opacity: 1; }
@starting-style {
  [popover]:popover-open { opacity: 0; }
}

/* stepped */
.typing { transition: width 1s steps(20); }

@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 0.01ms !important; }
}

⚠ Common Mistakes

  • Putting transition only on :hover: it animates in but snaps back
  • Transitioning width, top or margin, causing layout on every frame
  • Expecting display: none → block to fade without allow-discrete and @starting-style

✓ Tips & Best Practices

  • Transition transform and opacity for the smoothest results
  • Use ease-out for things entering and ease-in for things leaving
  • Use DevTools' Animations panel to slow down and inspect transitions
