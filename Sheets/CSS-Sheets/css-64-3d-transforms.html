3D Transforms

perspective · perspective-origin · rotateX/Y · translateZ · transform-style: preserve-3d · backface-visibility · card flip

Adding Depth

3D transforms add a Z axis pointing toward the viewer. Without perspective, 3D rotation looks flat. Set perspective on a parent (shared vanishing point for all children) or the perspective() function in a transform (per element); smaller values mean stronger distortion. transform-style: preserve-3d lets children live in the same 3D space, and backface-visibility: hidden hides the back of a flipped element, which is how card flips work.

Notes

  • Typical perspective: 600px–1200px
  • rotateX tilts forward/back, rotateY turns left/right, rotateZ = 2D rotate
  • overflow other than visible on a preserve-3d element flattens it
  • perspective-origin moves the vanishing point

♿ Accessibility

  • 3D flips and parallax are common motion triggers; disable them under prefers-reduced-motion: reduce
  • Back-face content is still in the DOM; hide it from screen readers when not shown

Browser Support

  • 3D transforms, perspective, preserve-3d, backface-visibility: Baseline Widely available

Code Explained

perspective on the scene gives depth to its children
preserve-3d keeps both faces in one 3D space
rotate: y 180deg is the individual-property form of rotateY
backface-visibility: hidden shows only the face toward the viewer
perspective() as a function affects only that element

Card Flip

.scene {
  perspective: 800px;              /* depth for children */
}

.card {
  position: relative;
  aspect-ratio: 3 / 4;
  transform-style: preserve-3d;
  transition: rotate .6s;
}

.scene:hover .card,
.card.is-flipped {
  rotate: y 180deg;                /* = rotateY(180deg) */
}

.face {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
}

.face.back {
  rotate: y 180deg;                /* starts facing away */
}

/* tilt toward the viewer */
.tilt {
  transform: perspective(600px) rotateX(10deg)
             translateZ(20px);
}

@media (prefers-reduced-motion: reduce) {
  .card { transition: none; }
}

⚠ Common Mistakes

  • No perspective: rotations look like squashing, not turning
  • Putting perspective on the element being rotated instead of its parent
  • Adding overflow: hidden to a preserve-3d container and flattening it

✓ Tips & Best Practices

  • Use one perspective on the parent for consistent scenes
  • Keep 3D for small flourishes; it's heavy for large areas
  • Hide the hidden face with aria-hidden or inert when it isn't visible

Quick Summary

  • Z axis points at the viewer
  • perspective on the parent
  • preserve-3d for nested 3D
  • backface-visibility: hidden for flips
