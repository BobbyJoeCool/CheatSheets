Sheet 37

Text Styling

text-align · text-decoration · text-underline-offset · text-transform · text-indent · text-overflow · line-clamp

Decorating and Aligning Text

text-align positions inline content in its line box (use start/end for direction-aware alignment). text-decoration is a shorthand for line, style, color and thickness, with text-underline-offset to move underlines clear of descenders. text-transform changes case visually without changing the text. To cut long text, text-overflow: ellipsis handles one line and line-clamp handles several.

Notes

  • text-overflow needs overflow: hidden and white-space: nowrap to work
  • Multi-line clamp still uses the -webkit- prefixed trio for broad support
  • text-align: justify + hyphens: auto avoids rivers of space
  • text-decoration-skip-ink: auto (default) breaks underlines around descenders

♿ Accessibility

  • Avoid justify for body text; uneven spacing slows dyslexic readers
  • Capitals typed into the HTML can be read letter by letter; keep source text in normal case and use text-transform
  • Truncated text should be available in full somewhere (title, tooltip, detail view)

Browser Support

  • All decoration and alignment properties: universal
  • -webkit-line-clamp: universal (prefixed); unprefixed line-clamp: limited

Code Explained

text-indent indents the first line only
text-decoration shorthand: line, thickness, color (and style)
Underline offset moves the line below descenders
Ellipsis needs all three: hidden overflow, no wrapping, ellipsis
The prefixed -webkit-box trio is the cross-browser multi-line clamp

Decoration, Case, Truncation

.prose     { text-align: start; text-indent: 2em; }
.centered  { text-align: center; }

/* nicer underlines */
a {
  text-decoration: underline 2px #5b4bc4;
  text-underline-offset: 3px;
  text-decoration-skip-ink: auto;
}
a:hover { text-decoration-thickness: 3px; }
.strike { text-decoration: line-through wavy red; }

/* case (display only) */
.label { text-transform: uppercase; letter-spacing: .06em; }
.name  { text-transform: capitalize; }

/* one line with ellipsis */
.truncate {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

/* clamp to 3 lines */
.excerpt {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}

⚠ Common Mistakes

  • Setting text-overflow: ellipsis without overflow: hidden and nowrap
  • Writing headings in uppercase in the HTML instead of using text-transform
  • Removing link underlines in body text; color alone fails WCAG 1.4.1

✓ Tips & Best Practices

  • Use text-underline-offset and thickness instead of border-bottom for links
  • Add letter-spacing to uppercase labels for legibility
  • Use text-align: start so RTL works automatically

Quick Summary

  • text-align: start | center | end
  • text-decoration + text-underline-offset
  • text-transform is visual only
  • Ellipsis trio; line-clamp trio
