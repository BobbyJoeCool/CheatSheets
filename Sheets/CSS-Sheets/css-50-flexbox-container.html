Flexbox: Container

display: flex · flex-direction · flex-wrap · flex-flow · justify-content · align-items · align-content · gap

One-Dimensional Layout

Flexbox lays out items along one main axis (a row or a column), with the cross axis perpendicular to it. display: flex makes the container; its direct children become flex items. justify-content distributes items along the main axis, align-items aligns them on the cross axis, and gap adds space between them. With flex-wrap: wrap, items flow onto new lines and align-content spaces those lines.

Notes

  • Default: flex-direction: row, flex-wrap: nowrap, align-items: stretch
  • row-reverse and column-reverse flip visual order only
  • Text nodes directly inside the container become anonymous flex items
  • align-content only matters when there are multiple lines

♿ Accessibility

  • *-reverse makes visual order differ from tab and reading order (WCAG 1.3.2, 2.4.3); reorder the HTML instead

Browser Support

  • Flexbox: universal; gap in flexbox: Baseline 2021

Code Explained

justify-content works on the main axis, align-items on the cross axis
Two-value gap: row gap, then column gap
In a column, justify-content becomes vertical
justify-content + align-items: center = centered both ways
inline-flex is a flex container that flows like text

Container Properties

.row {
  display: flex;
  flex-direction: row;          /* main axis → */
  flex-wrap: wrap;
  justify-content: space-between; /* main axis */
  align-items: center;          /* cross axis */
  gap: 1rem 2rem;               /* row-gap column-gap */
}

/* shorthand for direction + wrap */
.col { display: flex; flex-flow: column nowrap; }

/* perfect centering */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100dvh;
}

/* spread a toolbar */
.toolbar {
  display: flex;
  align-items: center;
  gap: .5rem;
}

/* wrapping tags with even line spacing */
.tags {
  display: flex;
  flex-wrap: wrap;
  align-content: flex-start;
  gap: .5rem;
}

/* inline flex: sits in text */
.icon-label {
  display: inline-flex; align-items: center; gap: .25em;
}

⚠ Common Mistakes

  • Expecting justify-content to center vertically in a row (that's align-items)
  • Using margins between items instead of gap
  • Using row-reverse to reorder content and breaking keyboard order

✓ Tips & Best Practices

  • Think "main axis" and "cross axis", not horizontal and vertical
  • Use gap for spacing; it never adds space at the edges
  • Use flex for one-dimensional rows and columns; grid for two

Quick Summary

  • display: flex → children are items
  • justify-content = main axis
  • align-items = cross axis
  • gap between items
