Filters & Blend Modes

filter · blur() · brightness() · grayscale() · backdrop-filter · mix-blend-mode · background-blend-mode · isolation

Image Effects in CSS

filter applies image effects to an element and its children: blur(), brightness(), contrast(), grayscale(), saturate(), hue-rotate(), drop-shadow(), applied left to right. backdrop-filter applies them to what's behind the element, the basis of frosted-glass panels. Blend modes mix colors like layers in an image editor: mix-blend-mode blends an element with what's behind it, background-blend-mode blends an element's own background layers.

Notes

  • Any filter other than none creates a stacking context and a containing block for fixed children
  • backdrop-filter needs a partly transparent background to show the effect
  • isolation: isolate limits blending to a group
  • Filters are GPU-friendly but large blurs on scroll can still be expensive

♿ Accessibility

  • Check text contrast on frosted panels with busy content behind them
  • Avoid filter: invert() dark modes; they invert images and break brand colors

Browser Support

  • filter, blend modes, isolation: universal
  • backdrop-filter unprefixed: Baseline 2024 (keep -webkit- for older Safari)

Code Explained

Filters chain left to right
opacity() in a filter can be GPU-accelerated with other effects
Backdrop blur only works if the panel background is see-through
difference with white text inverts whatever is behind it
background-blend-mode: multiply tints the photo with the color layer

Filters and Blending

img.muted   { filter: grayscale(1) contrast(1.1); }
img.muted:hover { filter: none; }

.disabled   { filter: saturate(0) opacity(.6); }
.night      { filter: brightness(.8) sepia(.2); }
.blur-bg    { filter: blur(8px); }

/* frosted glass */
.glass {
  background: rgb(255 255 255 / .2);
  -webkit-backdrop-filter: blur(12px) saturate(1.5);
  backdrop-filter: blur(12px) saturate(1.5);
}

/* text that inverts over any background */
.cursor-label { mix-blend-mode: difference; color: white; }

/* tint a photo with a color */
.duotone {
  background: url("photo.jpg") center / cover, #5b4bc4;
  background-blend-mode: multiply;
}

/* keep blending inside the card */
.card { isolation: isolate; }
.card .overlay { mix-blend-mode: screen; }

⚠ Common Mistakes

  • Applying filter: blur() to a container and blurring its text too
  • Using backdrop-filter on an opaque background and seeing nothing
  • Not isolating, so a blend mode mixes with the whole page

✓ Tips & Best Practices

  • Use filter on hover for image galleries (grayscale → color)
  • Pair backdrop-filter with a semi-transparent background and a border
  • Keep -webkit-backdrop-filter alongside the standard property

Quick Summary

  • filter: fn() fn() left to right
  • backdrop-filter = behind
  • mix-blend-mode with what's below
  • isolation: isolate contains blending
