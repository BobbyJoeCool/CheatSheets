Accessible CSS

focus indicators · .visually-hidden · contrast ratios · prefers-reduced-motion · forced-colors · visual vs DOM order

CSS That Includes Everyone

CSS can make an accessible page unusable or a rough one much better. The essentials: visible focus on every interactive element, sufficient contrast, no information by color alone, respect for user preferences (reduced motion, contrast, forced colors), content that reflows at 320px and 400% zoom, and a visual order that matches the DOM. The visually-hidden pattern hides text visually while keeping it for screen readers.

Notes

  • WCAG contrast: 4.5:1 normal text, 3:1 large text (≥24px or ≥18.66px bold) and UI parts
  • Focus indicators should be at least 2px and contrast 3:1 (WCAG 2.4.13)
  • CSS-generated content may or may not be announced; keep meaning in HTML
  • display: none and visibility: hidden remove content from the accessibility tree

Code Explained

:focus-visible gives keyboard users a strong ring

System colors keep borders visible in forced-colors mode

Accessibility Toolkit

/* 1. visible focus everywhere */
:focus-visible {
  outline: 3px solid var(--focus, #ff9800);
  outline-offset: 2px;
}

/* 2. hide visually, keep for screen readers */
.visually-hidden:not(:focus):not(:active) {
  position: absolute;
  width: 1px; height: 1px;
  margin: -1px; padding: 0; border: 0;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
}

/* 3. skip link appears on focus */
.skip-link { position: absolute; translate: 0 -200%; }
.skip-link:focus { translate: 0 0; }

/* 4. motion opt-in */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* 5. forced colors: keep boundaries */
@media (forced-colors: active) {
  .btn, .card { border: 1px solid CanvasText; }
}

/* 6. links distinguishable without color */
p a { text-decoration: underline; }

⚠ Common Mistakes

  • outline: none without a replacement
  • Reordering with order, grid-area or flex-direction: *-reverse so tab order jumps around
  • Light gray placeholder or body text that fails contrast

✓ Tips & Best Practices

  • Tab through every page after styling it
  • Use DevTools: contrast in the color picker, Rendering → emulate vision deficiencies
  • Keep the visually-hidden utility in your base layer

Quick Summary

  • Visible :focus-visible always
  • 4.5:1 text, 3:1 UI
  • Respect reduced motion + forced colors
  • Visual order = DOM order
