Sheet 41

Linear & Radial Gradients

linear-gradient() · angles · color stops · hard stops · radial-gradient() · shape & position · fades

Generated Images

Gradients are images generated by CSS, so they go anywhere url() does: background-image, border-image, mask-image, list-style-image. linear-gradient() blends along a line set by an angle or to <side>; radial-gradient() blends outward from a center as a circle or ellipse. Color stops place colors along the line; two stops at the same position make a hard edge instead of a blend.

Notes

  • 0deg points up and angles go clockwise; the default is to bottom (180deg)
  • A stop with two positions (red 20% 40%) holds a solid band
  • A lone percentage between colors is a hint that moves the midpoint
  • Radial sizes: closest-side, farthest-corner (default) and others

♿ Accessibility

  • Text over a gradient needs contrast at every point it covers; test the lightest spot

Browser Support

  • Linear and radial gradients: universal
  • Interpolation in other spaces (in oklch): Baseline 2024

Linear and Radial

.a { background: linear-gradient(#5b4bc4, #00bcd4); }
.b { background: linear-gradient(to right, #5b4bc4, #0bd); }
.c { background: linear-gradient(135deg, #f093fb, #f55); }

/* multiple stops and a hint */
.d {
  background: linear-gradient(90deg,
    red, orange 25%, yellow 50%, 70%, green);
}

/* hard stops: flag stripes */
.flag {
  background: linear-gradient(
    #002395 0 33.3%, #fff 0 66.6%, #ed2939 0);
}

/* fade text out at the bottom */
.fade::after {
  content: "";
  position: absolute; inset: auto 0 0;
  height: 4rem;
  background: linear-gradient(transparent, var(--surface));
}

/* radial */
.e { background: radial-gradient(#fff, #5b4bc4); }
.f { background: radial-gradient(circle at top left,
       #ffe082, transparent 60%); }
.spot {
  background: radial-gradient(circle closest-side,
    #5b4bc4 0 98%, transparent);
}

⚠ Common Mistakes

  • Writing linear-gradient(right, …): needs to right
  • Gradient to transparent going gray in old browsers; use the color at zero alpha
  • Expecting gradients on background-color: they're images

✓ Tips & Best Practices

  • Use hard stops for stripes, flags and progress fills
  • Layer gradients for complex effects instead of images
  • Add in oklch to keep mid-colors vivid: linear-gradient(in oklch, blue, yellow)

Quick Summary

  • linear-gradient(angle, stops)
  • radial-gradient(shape at pos, stops)
  • Same position twice = hard edge
  • Gradients are images
