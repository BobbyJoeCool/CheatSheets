Sheet 10

User-Agent Styles & Resets

UA stylesheet · normalize.css · modern reset · box-sizing reset · margin defaults · all: unset

Starting From Defaults

Every browser ships a user-agent stylesheet: margins on body and headings, bullets on lists, blue underlined links, bold th. They differ slightly between engines. A reset clears or evens out these defaults so your styles start from a known base. Old "hard" resets removed everything; modern resets keep useful defaults and fix the annoying ones, like content-box sizing and images overflowing.

Notes

  • normalize.css makes browsers consistent but keeps defaults
  • A modern reset (Josh Comeau, Andy Bell) is ~30 lines of opinionated fixes
  • Put the reset in the lowest cascade layer so everything overrides it
  • Wrapping reset selectors in :where() keeps their specificity at zero

♿ Accessibility

  • Removing list styles with list-style: none drops list semantics in Safari/VoiceOver; add role="list" if the count matters
  • Never reset outline: none globally; it hides keyboard focus

Browser Support

  • Every rule in a modern reset is Baseline Widely available
  • text-wrap: balance (often added to headings): Baseline 2024

Code Explained

box-sizing: border-box: width includes padding and border
* { margin: 0 }: remove UA margins, add spacing back on purpose
text-size-adjust: stop iOS inflating text in landscape
max-width: 100% keeps media inside its container
Reduced-motion rule lives in the reset so nothing forgets it

A Modern Reset

@layer reset {
  *, *::before, *::after {
    box-sizing: border-box;
  }

  * { margin: 0; }

  html {
    -webkit-text-size-adjust: none;
    text-size-adjust: none;
  }

  body {
    min-height: 100dvh;
    line-height: 1.5;
  }

  img, picture, video, canvas, svg {
    display: block;
    max-width: 100%;
  }

  input, button, textarea, select {
    font: inherit;
  }

  p, h1, h2, h3 { overflow-wrap: break-word; }

  @media (prefers-reduced-motion: reduce) {
    * { animation-duration: 0.01ms !important; }
  }
}

Reset Approaches

ApproachIdea

Modern resetA few targeted fixes
all: revertUndo author styles in one subtree

⚠ Common Mistakes

  • outline: none in a reset: removes keyboard focus indicators site-wide
  • Leaving the reset unlayered: it then beats component styles in layers
  • Inline images leaving a gap under them; set display: block

✓ Tips & Best Practices

  • Keep the reset tiny and read every line of it
  • Pair * { margin: 0 } with a spacing system (gap, margin-block utilities)
  • Test forms and lists after adding a reset

Quick Summary

  • UA styles differ by browser
  • Reset in @layer reset
  • box-sizing: border-box everywhere
  • Keep focus outlines
