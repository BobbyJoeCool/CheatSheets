Perceptual and Wide-Gamut Color

oklch(L C H) describes color by lightness (0–100%), chroma (colorfulness, about 0–0.4) and hue (degrees). It's perceptually uniform: the same L looks equally light across hues, so palettes and hover shades come out even. It also reaches wide-gamut colors (Display P3) that rgb() can't. color() names a space explicitly, like color(display-p3 1 0 0).

Notes

  • oklch hue numbers differ from hsl: oklch 0 is pinkish red, 145 green, 265 blue
  • Colors outside a screen's gamut are mapped to the nearest displayable color
  • lab()/lch() (CIE) are older perceptual spaces; oklab/oklch fix their blue hue shift
  • none can stand in for a missing channel: oklch(70% 0 none)

♿ Accessibility

  • Equal oklch lightness gives similar contrast across hues, which makes accessible palettes easier
  • Wide-gamut colors still need contrast checked in sRGB fallback too

Browser Support

  • oklch(), oklab(), lab(), lch(), color(): Baseline 2023
  • Add an sRGB hex fallback for very old browsers

Code Explained

Only L changes in the brand scale, so steps look even
Success and danger share L 60%, so they look equally strong
The hex line is the fallback for browsers that skip oklch
color(display-p3 …): channels 0–1 in the P3 space
@media (color-gamut: p3) targets wide-gamut displays

Using oklch

:root {
  /* one hue, even steps of lightness */
  --brand-300: oklch(80% 0.10 285);
  --brand-500: oklch(60% 0.18 285);
  --brand-700: oklch(42% 0.16 285);

  /* same lightness, different hue */
  --success:   oklch(60% 0.15 145);
  --danger:    oklch(60% 0.19 25);
}

.btn       { background: var(--brand-500); }
.btn:hover { background: oklch(52% 0.18 285); }

/* fallback first, then wide gamut */
.hot {
  background: #ff2e00;
  background: oklch(65% 0.30 35);
}

/* explicit color spaces */
.p3   { color: color(display-p3 1 0.2 0.1); }
.srgb { color: color(srgb 0.36 0.29 0.77); }

/* only on wide-gamut screens */
@media (color-gamut: p3) {
  .hero { background: oklch(70% 0.28 330); }
}

⚠ Common Mistakes

  • Copying hsl hue numbers into oklch: the hue scales differ
  • Very high chroma at low or high lightness: falls outside the gamut and gets clipped
  • No fallback in projects that support old browsers

✓ Tips & Best Practices

  • Build palettes by stepping L in oklch with fixed C and H
  • Use oklch.com to pick values and see gamut limits
  • Keep chroma under ~0.2 for UI colors that must work in sRGB

Quick Summary

  • oklch(L C H) perceptual
  • Even lightness across hues
  • color(display-p3 …) wide gamut
  • Fallback hex first
