Sheet 30

Sizing

width · height · min-/max- · min-content · max-content · fit-content · aspect-ratio

How Big Is a Box?

Block boxes take the full available width and are as tall as their content. width and height set sizes explicitly; min-* and max-* set limits that always win (min beats max if they conflict). Intrinsic keywords size from content: min-content is the narrowest a box can get without overflow, max-content is its widest unwrapped size, and fit-content is max-content capped at the available space. aspect-ratio sets one dimension from the other.

Notes

  • Percentage heights only work if the parent's height is definite
  • max-width: 100% keeps images and media from overflowing
  • aspect-ratio is ignored if both width and height are set
  • height: auto means "fit content"; it can't be transitioned without newer interpolate-size

♿ Accessibility

  • Avoid fixed height on text containers; zoomed or translated text overflows (WCAG 1.4.10 reflow)
  • Use min-height instead so boxes grow with content

Browser Support

  • width/height/min/max and intrinsic keywords: universal
  • aspect-ratio: Baseline 2021

Code Explained

max-width + margin-inline: auto = centered, shrinking column
height: auto with max-width: 100% keeps image ratios
aspect-ratio: 1: square from width alone
fit-content shrink-wraps a block like inline-block would
min-width wins when it conflicts with max-width

Explicit and Intrinsic Sizes

.container {
  width: 100%;
  max-width: 70rem;          /* cap */
  margin-inline: auto;
}

.panel {
  min-height: 12rem;         /* grows with content */
}

img, video {
  max-width: 100%;
  height: auto;              /* keep proportions */
}

.video  { aspect-ratio: 16 / 9; width: 100%; }
.avatar { aspect-ratio: 1; width: 3rem; object-fit: cover; }

/* intrinsic sizes */
.tag      { width: fit-content; }   /* shrink-wrap */
.caption  { width: min-content; }   /* widest word */
.no-wrap  { width: max-content; }   /* one line */

/* min wins over max */
.box { max-width: 200px; min-width: 300px; }  /* 300px */

/* full height app */
html, body { height: 100%; }
.app { min-height: 100dvh; }

⚠ Common Mistakes

  • Setting height on text boxes and clipping content when text grows
  • height: 100% inside a parent with no set height: does nothing
  • Forgetting height: auto on images with HTML width/height attributes

✓ Tips & Best Practices

  • Prefer min-height and max-width over fixed sizes
  • Keep HTML width/height on images (for layout shift) and add height: auto in CSS
  • Reach for fit-content before display: inline-block

Quick Summary

  • min-* / max-* limits win
  • min-content · max-content · fit-content
  • aspect-ratio: 16 / 9
  • % height needs a definite parent
