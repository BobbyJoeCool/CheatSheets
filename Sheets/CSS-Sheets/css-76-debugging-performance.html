Sheet 76

Debugging & Performance

DevTools Styles/Computed · layout shift · will-change · contain · content-visibility · expensive properties · Stylelint

Finding and Fixing Problems

DevTools is the main debugging tool: the Styles pane shows every matching rule (losers struck through), Computed shows final values and where they came from, and overlays visualize grid, flex and the box model. For performance, the rendering pipeline is style → layout → paint → composite. Animating properties that only need compositing (transform, opacity) is cheap; properties that trigger layout are expensive. Containment tells the browser a subtree is independent.

Notes

  • Struck-through declaration: overridden; yellow warning icon: invalid or ignored
  • Layout shift (CLS) comes from late-loading images, fonts and injected content
  • will-change reserves resources; add it just before animating, not everywhere
  • Selector matching is rarely the bottleneck; layout and paint usually are

♿ Accessibility

  • Use DevTools' accessibility pane and contrast checker while debugging styles
  • Emulate prefers-reduced-motion and forced colors in the Rendering tab

Browser Support

  • contain: Baseline 2022; content-visibility: Baseline 2024; will-change: universal

Code Explained

A translucent outline on everything shows which box overflows
translate and opacity skip layout and paint
Animating top/height re-runs layout each frame
contain: layout paint limits how far changes ripple
HTML width/height plus height: auto reserves image space; min-height reserves ad space

Debug and Speed Up

/* outline every box to find overflow */
* { outline: 1px solid rgb(255 0 0 / .3); }

/* find the element causing horizontal scroll */
/* DevTools console:
   [...document.querySelectorAll('*')]
     .filter(e => e.scrollWidth > innerWidth) */

/* cheap animation: compositor only */
.toast { transition: translate .3s, opacity .3s; }

/* expensive: layout every frame */
.toast-bad { transition: top .3s, height .3s; }

/* hint right before animating, then remove */
.drawer.is-opening { will-change: translate; }

/* isolate a widget's layout and paint */
.widget { contain: layout paint; }

/* skip rendering off-screen sections */
.feed-item {
  content-visibility: auto;
  contain-intrinsic-size: auto 400px;
}

/* stop layout shift: <img width="800" height="450"> */
img { max-width: 100%; height: auto; }  /* keeps ratio */
.ad-slot { min-height: 250px; }   /* reserve space */

⚠ Common Mistakes

  • will-change: transform on hundreds of elements, wasting memory
  • Animating height or box-shadow on large elements
  • Guessing at overrides instead of reading the Styles pane

✓ Tips & Best Practices

  • Turn on paint flashing to see what repaints
  • Lint with Stylelint to catch invalid values before they ship
  • Use the Coverage panel to find unused CSS

Quick Summary

  • Styles + Computed panes first
  • Animate transform and opacity
  • contain / content-visibility
  • Reserve space to prevent CLS
