Sheet 45

Display & Formatting Contexts

display · block · inline · inline-block · none · contents · flow-root · two-value syntax

How a Box Participates

display sets two things: the outer type (how the box sits among siblings: block or inline) and the inner type (how its children are laid out: flow, flex, grid, table). The two-value syntax makes this explicit: display: inline flex is the same as inline-flex. Some values start a new block formatting context (BFC), an isolated layout region that contains floats and stops margin collapse.

Notes

  • display: none removes the box and its children from layout and the accessibility tree
  • display: contents removes the box but keeps its children, which become children of the grandparent
  • flow-root is the clean way to make a BFC (clearfix replacement)
  • Every element has a UA default: div is block, span inline, li list-item

♿ Accessibility

  • display: contents has historically stripped semantics from buttons, tables and lists in some browsers; test with a screen reader
  • display: none hides from everyone; use a visually-hidden class to hide only visually

Browser Support

  • Single-keyword values: universal
  • Two-value syntax (block flex): Baseline 2023; flow-root, contents: Baseline

Code Explained

inline-block: sits in a line but accepts width, height and vertical margin
inline-flex: flex container that flows inline with text
flow-root contains floats inside without hacks
contents: the wrapper disappears and its children become grid items
list-item generates a marker box

Outer and Inner Display

.block   { display: block; }          /* block flow */
.inline  { display: inline; }         /* inline flow */
.ib      { display: inline-block; }   /* inline flow-root */
.hidden  { display: none; }

/* inner layout types */
.row     { display: flex; }           /* block flex */
.chip    { display: inline-flex; }    /* inline flex */
.layout  { display: grid; }           /* block grid */
.badge   { display: inline grid; }    /* two-value */

/* contain floats, stop margin collapse */
.media   { display: flow-root; }

/* make children join the parent grid */
.grid > .wrapper { display: contents; }

/* list-item gets a ::marker */
.faux-li { display: list-item; }

/* table layout without table markup */
.t   { display: table; width: 100%; }
.tr  { display: table-row; }
.td  { display: table-cell; vertical-align: middle; }

⚠ Common Mistakes

  • Using display: none to hide skip links or labels screen readers need
  • Applying width to inline elements and wondering why nothing changes
  • Using overflow: hidden as a clearfix and clipping focus rings or shadows

✓ Tips & Best Practices

  • Use flow-root instead of clearfix hacks
  • Use contents sparingly; test semantics
  • Read display as outer + inner to predict behavior

Quick Summary

  • outer (block/inline) + inner (flow/flex/grid)
  • none removes from layout and a11y tree
  • flow-root = new BFC
  • contents = drop the wrapper box
