Sheet 02

Adding CSS to a Page

link rel="stylesheet" · style element · style attribute · @import · media attribute · load order · render-blocking

Three Ways In

CSS reaches a page three ways: an external stylesheet linked with <link rel="stylesheet">, an embedded <style> element, or an inline style attribute. External files are the default: they are cached, shared across pages and keep markup clean. Stylesheets in the <head> are render-blocking: the browser waits for them before painting, which prevents a flash of unstyled content.

Notes

  • Later sources win ties: a <style> after a <link> overrides it for equal specificity
  • Inline style beats any selector unless the other declaration uses !important
  • @import must come before all other rules except @charset and @layer statements
  • A media attribute on <link> still downloads the file but stops it blocking render

♿ Accessibility

  • Inline styles can't respond to user preferences like prefers-reduced-motion; keep them out of the critical path
  • Never put content in CSS alone; screen readers may skip or misread generated text

Browser Support

  • <link>, <style>, inline styles and @import: universal
  • @import … layer(): Baseline 2022; supports() conditions on @import are newer, so check support
  • blocking="render" on <link>/<style>: Chromium only

Code Explained

rel="stylesheet": the only rel that applies CSS
media="print": file loads but only applies when printing
<style>: rules for this page only; not cached separately
@import … layer(theme): puts the file in a cascade layer
@import … (width >= 60rem): a conditional import

Linking Stylesheets

<!-- in <head> -->
<link rel="stylesheet" href="/css/main.css">
<link rel="stylesheet" href="/css/print.css"
      media="print">
<link rel="preload" href="/css/late.css" as="style">

<style>
  /* embedded: page-specific rules */
  .hero { min-height: 60vh; }
</style>

<!-- inline: one element, avoid -->
<p style="color: tomato;">Warning</p>

<style>
  /* @import must open the stylesheet */
  @import url("reset.css");
  @import url("theme.css") layer(theme);
  @import url("wide.css") (width >= 60rem);
</style>

⚠ Common Mistakes

  • Placing @import after other rules: the browser ignores it
  • Chaining @imports: each waits for the last, slowing first paint
  • Linking stylesheets at the end of <body>: content flashes unstyled first

✓ Tips & Best Practices

  • One or two linked files per page; let a bundler combine partials
  • Inline only the small critical CSS for above-the-fold content
  • Prefer <link> + @layer order over @import for performance

Quick Summary

  • <link rel="stylesheet">: external, cached, default
  • <style>: per-page rules
  • style="…": inline, highest normal priority
  • @import: top of file only; slower
