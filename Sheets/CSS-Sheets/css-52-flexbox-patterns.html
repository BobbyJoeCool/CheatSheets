Sheet 52

Flexbox Patterns

centering · nav bar · media object · sticky footer · equal-height cards · margin-left: auto · wrapping toolbars

Recipes

Most everyday components are a handful of flex declarations. These patterns cover the common ones: a navigation bar with a pushed-right item, the media object (image beside text), a sticky footer that stays at the bottom of short pages, equal-height cards with buttons aligned to the bottom, and a wrapping toolbar. Each relies on gap, auto margins and the flex shorthand from the last two sheets.

Notes

  • Auto margins in flex absorb free space in that direction
  • Flex items stretch to the tallest item in a line by default
  • Nested flex containers are normal; each solves one axis
  • If a pattern needs rows and columns to line up, use grid

♿ Accessibility

  • Keep nav links in a <ul> inside <nav>; flex on the ul doesn't change semantics
  • Make sure wrapped toolbars keep a logical tab order left to right

Browser Support

  • Every pattern here: Baseline Widely available

Code Explained

margin-inline-start: auto pushes login to the far end
flex: none stops the image shrinking
main { flex: 1 } fills leftover height, pushing the footer down
margin-top: auto sends the button to the bottom of each card
The search box grows but wraps below 12rem

Five Patterns

/* 1. nav: logo left, links, login right */
.nav { display: flex; align-items: center; gap: 1rem; }
.nav .login { margin-inline-start: auto; }

/* 2. media object */
.media { display: flex; gap: 1rem; align-items: start; }
.media img { flex: none; width: 4rem; }
.media .body { flex: 1; min-width: 0; }

/* 3. sticky footer */
body { display: flex; flex-direction: column;
       min-height: 100dvh; }
main { flex: 1; }

/* 4. equal-height cards, buttons at bottom */
.cards { display: flex; gap: 1rem; flex-wrap: wrap; }
.card  { flex: 1 1 16rem; display: flex;
         flex-direction: column; }
.card .btn { margin-top: auto; }

/* 5. toolbar that wraps */
.toolbar {
  display: flex; flex-wrap: wrap;
  gap: .5rem; align-items: center;
}
.toolbar .search { flex: 1 1 12rem; }

⚠ Common Mistakes

  • Building a full page grid from nested flex rows; columns won't line up
  • Forgetting min-width: 0 on the text side of a media object
  • Last row of wrapped cards stretching wider than the rest (use grid for even columns)

✓ Tips & Best Practices

  • Reach for auto margins before extra wrapper divs
  • Use grid when the last row must match earlier columns
  • Name patterns as utility classes (.cluster, .stack, .sidebar)

Quick Summary

  • Auto margin = push
  • Column flex + margin-top: auto = bottom
  • main { flex: 1 } = sticky footer
  • Wrap + basis = responsive row
