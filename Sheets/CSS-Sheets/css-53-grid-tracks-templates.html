Sheet 53

Grid: Tracks & Templates

display: grid · grid-template-columns · grid-template-rows · fr · repeat() · minmax() · auto-fill vs auto-fit · gap

Two-Dimensional Layout

CSS Grid lays items out in rows and columns at once. Define tracks with grid-template-columns and grid-template-rows; children are placed into the cells automatically. The fr unit shares leftover space, repeat() avoids repetition, and minmax(min, max) gives a track a flexible range. repeat(auto-fit, minmax(15rem, 1fr)) makes a fully responsive grid with no media queries.

Notes

  • fr divides space after fixed tracks and gaps are subtracted
  • 1fr is really minmax(auto, 1fr); use minmax(0, 1fr) to let it shrink below content
  • Rows you don't define are created automatically (implicit tracks)
  • gap replaces the old grid-gap

♿ Accessibility

  • Grid placement can make visual order differ from source order; keep the HTML in a sensible reading order

Browser Support

  • CSS Grid: Baseline since 2017; gap: universal
  • Subgrid: Baseline 2023 (sheet 56)

Code Explained

200px 1fr 2fr: fixed column, then the rest split 1:2
auto 1fr auto: header, stretching body, footer
auto-fit + minmax(): as many 15rem+ columns as fit
min(15rem, 100%) stops overflow on very narrow screens
minmax(0, 1fr) lets columns shrink below their content

Defining Tracks

.grid {
  display: grid;
  grid-template-columns: 200px 1fr 2fr;  /* fixed + flex */
  grid-template-rows: auto 1fr auto;
  gap: 1rem;
  min-height: 100dvh;
}

/* 12-column system */
.twelve { display: grid;
          grid-template-columns: repeat(12, 1fr); }

/* responsive cards, no media queries */
.cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(min(15rem, 100%), 1fr));
  gap: 1.5rem;
}

/* allow columns to shrink below long content */
.code-cols {
  grid-template-columns: repeat(2, minmax(0, 1fr));
}

/* sidebar clamps between 12rem and 20rem */
.layout { grid-template-columns: minmax(12rem, 20rem) 1fr; }

/* track fits content up to a max */
.form { grid-template-columns: fit-content(14rem) 1fr; }

Track Sizes

ValueSize
200px / 10remFixed
1frShare of free space
autoContent-based (stretches)
min-content / max-contentIntrinsic
minmax(a, b)Between a and b
fit-content(x)Content, capped at x
repeat(n, …)Repeat a pattern

auto-fill vs auto-fit

KeywordSpare room
auto-fillKeeps empty tracks; items stay min size
auto-fitCollapses empty tracks; items stretch
Few items, wide screenDifference is visible
Many itemsSame result

⚠ Common Mistakes

  • Long words or <pre> blowing out 1fr columns: use minmax(0, 1fr)
  • Applying grid properties to grandchildren: only direct children are items
  • Using auto-fill when you wanted items to stretch (auto-fit)

✓ Tips & Best Practices

  • Learn repeat(auto-fit, minmax(min(X, 100%), 1fr)) by heart
  • Turn on the DevTools grid overlay to see lines and tracks
  • Use fr instead of percentages; gaps are subtracted automatically

Quick Summary

  • grid-template-columns / -rows
  • fr = free-space share
  • repeat(), minmax()
  • auto-fit + minmax = responsive
