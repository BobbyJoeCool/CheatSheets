Overflow & Visibility

overflow · overflow-x/y · hidden vs clip · scrollbar-gutter · visibility · display:none vs opacity: 0 · content-visibility

Too Much Content, or None Shown

When content is bigger than its box, overflow decides what happens: visible (spill out, the default), hidden (clip, but still scrollable by script), clip (clip with no scrolling at all), scroll (always show scrollbars) or auto (scrollbars when needed). Separately, there are several ways to hide an element, and they differ in whether it keeps its space, gets focus, and is announced by screen readers.

Notes

  • Setting one axis to non-visible forces the other off visible too (except with clip)
  • overflow: hidden creates a scroll container; this is what breaks position: sticky
  • scrollbar-gutter: stable reserves space so layout doesn't jump when a scrollbar appears
  • content-visibility: auto skips rendering off-screen sections until needed

♿ Accessibility

  • visibility: hidden and display: none hide from screen readers; opacity: 0 does not
  • A visually-hidden utility keeps text for screen readers only (sheet 75)
  • Scrollable regions need to be keyboard reachable; add tabindex="0" and a label

Browser Support

  • overflow, visibility: universal; overflow: clip: Baseline 2022
  • scrollbar-gutter, content-visibility: Baseline 2024

Code Explained

overflow: auto scrolls only when content overflows
scrollbar-gutter: stable keeps width constant
overflow: clip doesn't create a scroll container
opacity: 0 alone still takes clicks; add pointer-events: none
contain-intrinsic-size gives skipped sections a placeholder height

Overflow and Hiding

.scroll-box {
  max-height: 20rem;
  overflow: auto;               /* bars only when needed */
  scrollbar-gutter: stable;     /* no layout jump */
}

.table-wrap { overflow-x: auto; }  /* wide tables */

.rounded-media {
  border-radius: 12px;
  overflow: clip;               /* sticky still works */
}

/* hide entirely: no space, no a11y */
.is-hidden    { display: none; }

/* invisible but keeps space; not focusable */
.placeholder  { visibility: hidden; }

/* invisible but still there for a11y and clicks */
.fade-out     { opacity: 0; pointer-events: none; }

/* lazy-render long pages */
.article-section {
  content-visibility: auto;
  contain-intrinsic-size: auto 600px;
}

/* tables collapse rows */
tr.collapsed  { visibility: collapse; }

⚠ Common Mistakes

  • overflow-x: hidden on body to fix horizontal scroll instead of finding the wide element
  • Using opacity: 0 to hide menus that can still be tabbed into
  • overflow: hidden on a sticky element's ancestor

✓ Tips & Best Practices

  • Find overflow culprits with * { outline: 1px solid red }
  • Use overflow: clip for rounded corners on media
  • Wrap wide tables in a focusable overflow-x: auto container

Quick Summary

  • auto scrolls when needed
  • clip = clip without scrolling
  • display:none vs visibility vs opacity
  • scrollbar-gutter: stable
