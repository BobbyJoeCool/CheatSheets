Loading Custom Fonts

@font-face declares a font: a family name, where to load it (src), and which weight and style the file covers. WOFF2 is the only format you need today. font-display controls what shows while the file downloads: swap shows fallback text immediately and swaps when ready. Fallback metric overrides (size-adjust, ascent-override) make the fallback occupy the same space, so the swap doesn't shift layout.

Notes

  • Fonts download only when text actually uses them
  • One @font-face per file; group them with the same font-family name
  • unicode-range lets the browser skip files for scripts the page doesn't use
  • local() in src tries an installed font first

♿ Accessibility

  • font-display: swap keeps text readable during slow loads (no invisible text)
  • Icon fonts read as random characters to screen readers; use SVG icons

Browser Support

  • @font-face, WOFF2, font-display, unicode-range: universal
  • size-adjust, ascent-override, descent-override: Baseline 2023 (Safari 17)

Code Explained

Two faces share one family name; font-weight picks between them
format("woff2") lets old browsers skip files they can't use
local("Arial") + size-adjust: a metric-matched fallback
unicode-range: only download when matching characters appear
Preload needs crossorigin, even for same-origin fonts

@font-face and Fallback Tuning

@font-face {
  font-family: "Inter";
  src: url("/fonts/inter-400.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: "Inter";
  src: url("/fonts/inter-700.woff2") format("woff2");
  font-weight: 700;
  font-display: swap;
}

/* fallback sized to match Inter */
@font-face {
  font-family: "Inter Fallback";
  src: local("Arial");
  size-adjust: 107%;
  ascent-override: 90%;
}

body { font-family: "Inter", "Inter Fallback", sans-serif; }

/* only Latin glyphs in this file */
@font-face {
  font-family: "Inter";
  src: url("/fonts/inter-latin.woff2") format("woff2");
  unicode-range: U+0000-00FF;
}

/* in <head>: start the download early
<link rel="preload" href="/fonts/inter-400.woff2"
      as="font" type="font/woff2" crossorigin> */

⚠ Common Mistakes

  • Missing crossorigin on font preloads: the font downloads twice
  • Shipping TTF/OTF or several formats; WOFF2 alone covers current browsers
  • Declaring weights you never use, or using weights you never declared (faux bold)

✓ Tips & Best Practices

  • Self-host WOFF2 with font-display: swap and preload the one or two critical files
  • Subset fonts to the characters you need
  • Generate fallback overrides with a tool like Fontaine or Capsize

Quick Summary

  • @font-face { font-family; src; }
  • WOFF2 only
  • font-display: swap
  • size-adjust stops layout shift
