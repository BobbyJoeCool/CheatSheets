Sheet 60

Container Queries

container-type · container-name · container shorthand · @container · size queries · style() queries

Components That Respond to Their Space

Container queries style an element based on the size of an ancestor container instead of the viewport. Mark a wrapper with container-type: inline-size, then write @container (width > 30rem) { … } for its descendants. The same card can then be compact in a sidebar and spacious in the main column. Style queries (@container style(--theme: dark)) test a container's custom property values.

Notes

  • A query applies to descendants; an element can't query itself
  • inline-size containment means the container's width can't depend on its children
  • Without a name, @container uses the nearest container ancestor
  • Container units (cqi, cqb) size things relative to the container

♿ Accessibility

  • Container queries make components reflow inside narrow slots, which also helps at high zoom

Browser Support

  • Size container queries and cq* units: Baseline 2023
  • Style queries for custom properties: not yet in all engines
  • Scroll-state queries: newer, Chromium only

Code Explained

container-type: inline-size makes each column a size container
container: name / type shorthand
Base styles are for the narrowest slot
@container (width > 30rem) checks the nearest container's width
4cqi = 4% of the container's inline size

Responsive Component

/* 1. declare containers */
.sidebar, .main {
  container-type: inline-size;
}
.product-list {
  container: products / inline-size;   /* name / type */
}

/* 2. component base: stacked */
.card {
  display: grid;
  gap: 1rem;
}

/* 3. side-by-side when its container is wide */
@container (width > 30rem) {
  .card {
    grid-template-columns: 10rem 1fr;
  }
}

/* named container */
@container products (width > 50rem) {
  .card h2 { font-size: 1.5rem; }
}

/* fluid inside the container */
.card h2 { font-size: clamp(1rem, 4cqi, 1.75rem); }

/* style query (newer) */
@container style(--variant: featured) {
  .card { border: 2px solid gold; }
}

⚠ Common Mistakes

  • Querying an element that is itself the container (queries apply to descendants)
  • Using container-type: size without a set height, so the container collapses
  • Making the page body a container and then wondering why viewport-sized children shrink

✓ Tips & Best Practices

  • Mark layout slots (columns, sidebars) as containers, not the components
  • Write component styles mobile-first with @container (width > …) upgrades
  • Use cqi units for fluid component typography

Quick Summary

  • container-type: inline-size
  • @container (width > X)
  • Name with container: name / type
  • cqi = container-relative units
