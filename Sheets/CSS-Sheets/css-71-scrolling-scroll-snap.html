Sheet 71

Scrolling & Scroll Snap

scroll-behavior · scroll-margin · scroll-padding · scroll-snap-type · scroll-snap-align · overscroll-behavior · scrollbar-color

Controlling Scroll

CSS can shape scrolling without JS. scroll-behavior: smooth animates jumps to anchors. scroll-padding (on the scroller) and scroll-margin (on targets) offset where things land, for example below a sticky header. Scroll snap makes a scroller stop at defined points: scroll-snap-type on the container, scroll-snap-align on children; it's the basis of CSS-only carousels. overscroll-behavior stops scroll chaining into the page behind a modal or sidebar.

Notes

  • mandatory always snaps; proximity snaps only near a snap point
  • scroll-snap-stop: always prevents fast swipes skipping items
  • scrollbar-width: thin and scrollbar-color: thumb track style scrollbars
  • overscroll-behavior: contain also disables pull-to-refresh inside that element

♿ Accessibility

  • Only enable smooth scrolling under prefers-reduced-motion: no-preference
  • Carousels need visible controls and keyboard access; snap alone isn't enough
  • Don't hide scrollbars on content that needs scrolling to be discovered

Browser Support

  • scroll-behavior, scroll-margin/padding, scroll snap: Baseline Widely available
  • overscroll-behavior: Baseline 2022; scrollbar-width: Baseline 2024; scrollbar-color: not in Safari

Code Explained

Smooth scrolling only when motion is welcome
scroll-padding-top on the scroller offsets every anchor target
x mandatory + align: start snaps each slide to the left edge
scroll-snap-stop: always stops one slide at a time
overscroll-behavior: contain stops scroll chaining to the page

Scroll Recipes

/* smooth anchor jumps, opt-in */
@media (prefers-reduced-motion: no-preference) {
  html { scroll-behavior: smooth; }
}

/* anchors land below a 4rem sticky header */
html { scroll-padding-top: 4rem; }
h2   { scroll-margin-top: 1rem; }      /* extra space */

/* horizontal carousel */
.carousel {
  display: flex;
  gap: 1rem;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  scroll-padding-inline: 1rem;
  overscroll-behavior-x: contain;
}
.carousel > * {
  flex: 0 0 80%;
  scroll-snap-align: start;
  scroll-snap-stop: always;
}

/* vertical full-screen sections */
.slides { height: 100dvh; overflow-y: auto;
          scroll-snap-type: y proximity; }
.slides > section { height: 100dvh;
                    scroll-snap-align: start; }

/* modal panel doesn't scroll the page */
.drawer { overflow-y: auto; overscroll-behavior: contain; }

/* thin themed scrollbars */
.panel { scrollbar-width: thin;
         scrollbar-color: #5b4bc4 transparent; }

⚠ Common Mistakes

  • Setting scroll-padding on the target instead of the scroll container (use scroll-margin there)
  • mandatory snapping on content taller than the viewport, which traps users
  • Hiding scrollbars with scrollbar-width: none on scrollers without other affordances

✓ Tips & Best Practices

  • Use scroll-padding-top for sticky headers instead of JS offsets
  • Use proximity for long content, mandatory for slides
  • Add overscroll-behavior: contain to modals and drawers

Quick Summary

  • scroll-behavior: smooth (opt-in)
  • scroll-padding on scroller, scroll-margin on target
  • scroll-snap-type + scroll-snap-align
  • overscroll-behavior: contain
