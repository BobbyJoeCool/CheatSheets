Flexbox: Items

flex-grow · flex-shrink · flex-basis · flex shorthand · align-self · order · min-width: 0

How Items Share Space

Each flex item starts at its flex-basis (its ideal size). If there's space left, items grow in proportion to flex-grow; if there's too little, they shrink in proportion to flex-shrink (weighted by basis). The flex shorthand sets all three; use it rather than the longhands. Items can't shrink below their min-content size by default, which is why long words and code blocks overflow until you add min-width: 0.

Notes

  • flex: 1 = 1 1 0%: share all space equally regardless of content
  • flex: auto = 1 1 auto: grow from content size
  • flex: none = 0 0 auto: rigid
  • order changes visual position only (default 0)

♿ Accessibility

  • order does not change tab or reading order; reorder the HTML when the sequence matters

Browser Support

  • All flex item properties: universal

Code Explained

flex: 1 → 1 1 0%: equal widths
flex: 0 0 16rem keeps the sidebar exactly 16rem
min-width: 0 lets .main shrink below long content
flex: 1 1 15rem: wrap when items would be narrower than 15rem
margin-inline-start: auto absorbs the free space

Grow, Shrink, Basis

/* equal columns */
.cols > * { flex: 1; }

/* sidebar fixed, main fills */
.layout { display: flex; gap: 2rem; }
.sidebar { flex: 0 0 16rem; }   /* no grow, no shrink */
.main    { flex: 1; min-width: 0; } /* allow shrinking */

/* 2:1 split */
.a { flex: 2; }
.b { flex: 1; }

/* wrap items at a minimum width */
.cards { display: flex; flex-wrap: wrap; gap: 1rem; }
.cards > * { flex: 1 1 15rem; }  /* basis 15rem */

/* one item aligned differently */
.row { display: flex; align-items: flex-start; }
.row .tall { align-self: stretch; }

/* push the last item to the end */
.nav .spacer { margin-inline-start: auto; }

/* visual reorder (use rarely) */
.featured { order: -1; }

⚠ Common Mistakes

  • Text or <pre> overflowing a flex item: add min-width: 0 (or overflow: hidden)
  • Using flex-grow: 1 and expecting equal widths (needs basis 0: flex: 1)
  • Setting width on items and having flex-basis: auto silently use it

✓ Tips & Best Practices

  • Always use the flex shorthand
  • flex: 1 1 <min> + flex-wrap: wrap makes responsive card rows
  • Use align-self for one-off cross-axis alignment

Quick Summary

  • basis → grow or shrink
  • flex: 1 equal share
  • flex: none rigid
  • min-width: 0 fixes overflow
