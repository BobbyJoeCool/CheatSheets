Sheet 18

Pseudo-Elements

::before · ::after · content · ::first-line · ::first-letter · ::marker · ::selection · ::backdrop

Styling Parts and Extras

Pseudo-elements style a part of an element (::first-line, ::marker, ::placeholder) or create a box that isn't in the HTML. ::before and ::after insert a child at the start or end of the element's content and only render when content is set (even to ""). They're used for icons, decorative shapes, quotes, counters and overlays. Use two colons; the single-colon form works only for the four CSS 2 pseudo-elements.

Notes

  • ::before/::after don't work on replaced elements like <img> or <input>
  • Generated boxes are display: inline by default
  • Only one of each pseudo-element per element; nest wrappers for more
  • content accepts strings, attr(), counter(), url() and open-quote

♿ Accessibility

  • Screen readers often announce content text; keep meaning in the HTML and use content: "→" / "" to give decorative text an empty alt
  • ::selection colors still need enough contrast

Browser Support

  • ::before, ::after, ::first-line, ::first-letter, ::selection, ::placeholder: universal
  • ::marker: Baseline 2020 (Safari supports only some properties); alt text in content: Baseline 2024

Code Explained

content: "↗" / "": text after / is the alternative text (empty = decorative)
attr(href) prints an attribute value
content: "" + absolute positioning = a free extra layer
::marker: bullets and numbers of list items
::backdrop: the layer behind a modal dialog or popover

Generated and Part Styles

/* decorative icon, hidden from screen readers */
.external::after {
  content: "↗" / "";
  margin-inline-start: .25em;
}

/* show the URL when printing */
@media print {
  a[href^="http"]::after { content: " (" attr(href) ")"; }
}

/* overlay layer */
.hero { position: relative; }
.hero::before {
  content: "";
  position: absolute;
  inset: 0;
  background: linear-gradient(#0000, #0009);
}

p::first-line        { font-variant: small-caps; }
.drop::first-letter  { float: left; font-size: 3em; }
li::marker           { color: #5b4bc4; content: "▸ "; }
::selection          { background: #ffe082; }
input::placeholder   { color: #767676; }
dialog::backdrop     { background: #000a; }
input[type=file]::file-selector-button {
  border-radius: 4px;
}

⚠ Common Mistakes

  • Forgetting content: the pseudo-element doesn't render at all
  • Adding ::after to <img> or <input>: replaced elements have no content box
  • Putting meaningful text in content that copy, search and some screen readers miss

✓ Tips & Best Practices

  • Use ::before with inset: 0 for overlays instead of extra divs
  • Give decorative generated text empty alt: content: "★" / ""
  • Style placeholders with enough contrast (4.5:1) or don't rely on them

Quick Summary

  • ::before / ::after need content
  • Two colons for pseudo-elements
  • ::marker · ::placeholder · ::selection
  • No pseudo-elements on <img>/<input>
