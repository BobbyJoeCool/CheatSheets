Custom Properties: Advanced

@property · syntax · inherits · initial-value · animating variables · theming · setProperty()

Typed Custom Properties

@property registers a custom property with a type (syntax), an initial-value and whether it inherits. Registered properties are validated, so an invalid value falls back to the initial value instead of breaking the property, and because the browser knows the type it can interpolate them. That makes gradients, angles and counters animatable, which raw --vars (treated as strings) can't do.

Notes

  • syntax uses type names: '<length>', '<color>', '<number>', '<angle>', '*'
  • Combine: '<length> | <percentage>'; lists: '<length>+'
  • inherits: false keeps a value local to the element that sets it
  • JS equivalent: CSS.registerProperty({ name, syntax, inherits, initialValue })

♿ Accessibility

  • Wrap property-driven animations in prefers-reduced-motion: no-preference

Browser Support

  • @property: Baseline 2024
  • Unregistered variables still work everywhere; animations just jump instead of easing

Code Explained

syntax: '<angle>' lets the browser interpolate 0deg → 360deg
Keyframes animate the variable; the gradient re-renders each frame
transition: --stop works only because --stop is registered
An invalid value (red for a length) uses initial-value
inherits: false stops the value leaking into children

Register, Then Animate

@property --angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}

/* spinning conic border */
.ring {
  background: conic-gradient(
    from var(--angle), #5b4bc4, #00bcd4, #5b4bc4);
  animation: spin 3s linear infinite;
}
@keyframes spin { to { --angle: 360deg; } }

@property --stop {
  syntax: '<percentage>';
  inherits: false;
  initial-value: 0%;
}

/* animated gradient fill on hover */
.bar {
  background: linear-gradient(90deg,
    #5b4bc4 var(--stop), #ddd var(--stop));
  transition: --stop .4s;
}
.bar:hover { --stop: 100%; }

/* type safety */
@property --gap {
  syntax: '<length>';
  inherits: true;
  initial-value: 1rem;
}
.grid { --gap: red; gap: var(--gap); } /* → 1rem */

⚠ Common Mistakes

  • Forgetting inherits or initial-value: the whole @property rule is ignored
  • Transitioning an unregistered variable: it switches instantly at the midpoint
  • Registering a property with syntax: '*' and expecting animation

✓ Tips & Best Practices

  • Register any variable you plan to animate or transition
  • Use inherits: false for per-element animation state
  • Put @property rules at the top level, near your tokens

Quick Summary

  • @property --x { syntax; inherits; initial-value }
  • Registered → typed, validated
  • Typed → animatable
  • JS: CSS.registerProperty()
