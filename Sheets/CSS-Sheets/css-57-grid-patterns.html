Grid Patterns

auto-fit card grid · holy grail · full-bleed layout · overlapping items · grid vs flexbox

Recipes

A few grid patterns cover most page and component layouts: the auto-fit card grid (the "RAM" pattern: Repeat, Auto, Minmax), the holy grail page with header, footer and two sidebars, a full-bleed article where some elements break out of the text column, overlapping layers without absolute positioning, and a sidebar layout that stacks on narrow screens. Grid shines whenever rows and columns must line up.

Notes

  • Use min() inside minmax() to prevent overflow on tiny screens
  • Layering with grid-area: 1 / 1 keeps items in flow, so the container sizes to the tallest
  • Nested grids are fine; use subgrid when they need the parent's lines
  • Grid and flex combine: grid for the page, flex inside components

♿ Accessibility

  • The holy grail areas should map to landmarks (header, nav, main, aside, footer)

Browser Support

  • Every pattern here: Baseline Widely available

Code Explained

RAM: as many 16rem+ columns as fit, stretched evenly
grid-template: rows / columns shorthand
The middle column is the text measure; .bleed spans all three
Everything in one cell, aligned with align-self
fit-content(18rem) sizes the sidebar to content up to 18rem

Five Grid Patterns

/* 1. RAM card grid */
.cards {
  display: grid; gap: 1rem;
  grid-template-columns:
    repeat(auto-fit, minmax(min(16rem, 100%), 1fr));
}

/* 2. holy grail */
.page {
  display: grid; min-height: 100dvh;
  grid-template: auto 1fr auto / 12rem 1fr 12rem;
}
.page > header, .page > footer { grid-column: 1 / -1; }

/* 3. full bleed */
.post {
  display: grid;
  grid-template-columns: 1fr min(65ch, 100% - 2rem) 1fr;
}
.post > *      { grid-column: 2; }
.post > .bleed { grid-column: 1 / -1; }

/* 4. overlap text on image */
.hero { display: grid; }
.hero > * { grid-area: 1 / 1; }
.hero h1 { align-self: end; z-index: 1; }

/* 5. sidebar that stacks when narrow */
.with-sidebar {
  display: grid; gap: 2rem;
  grid-template-columns: fit-content(18rem) minmax(0, 1fr);
}
@media (width < 40rem) {
  .with-sidebar { grid-template-columns: 1fr; }
}

Grid vs Flexbox

SituationPick
Columns must align across rowsGrid
Items size from content in one lineFlex
Page-level layoutGrid
Nav bars, button groupsFlex
Overlap without positioningGrid
Unknown items, even last rowGrid

⚠ Common Mistakes

  • Using a fixed minmax(16rem, 1fr) that overflows on 320px screens
  • Absolute-positioning overlays that could be grid layers
  • Choosing flex for card grids and getting a stretched last row

✓ Tips & Best Practices

  • Keep these as utility classes (.grid-auto, .bleed, .stack)
  • Combine grid layout with container queries for truly modular components
  • Inspect with the DevTools grid badge

Quick Summary

  • RAM = Repeat, Auto, Minmax
  • grid-template shorthand
  • Full bleed via named/side columns
  • Grid for 2D, flex for 1D
