Sheet 09

Nesting & @scope

native nesting · & · nested at-rules · @scope · scope root · scope limit · proximity

Grouping Related Rules

Native nesting lets you write child rules inside a parent rule, like Sass. The & stands for the parent selector and is required when attaching to it (&:hover, &.active). Nested rules compile to :is() behavior, so they take the parent's highest specificity. @scope limits rules to a subtree, with an optional lower boundary (to), and when two scoped rules tie, the one with the closer scope root wins.

Notes

  • & can go anywhere: .theme-dark & matches the parent inside .theme-dark
  • You can nest @media, @supports, @container and @layer directly in a rule
  • Unlike Sass, &__title concatenation doesn't work; nesting is selector-based
  • Inside @scope (.card), :scope refers to the scope root

♿ Accessibility

  • Deep nesting makes it easy to lose :focus-visible states; nest them next to :hover

Browser Support

  • Native nesting: Baseline 2023 (bare type selectors like p {} nested since late 2023)
  • @scope: newer; check support and keep a plain-selector fallback

Code Explained

& h2: descendant of the parent; & is optional before a combinator
&:hover: no space, so it attaches to .card itself
.theme-dark &: parent inside an ancestor
Nested @media wraps declarations for the parent selector
to (.content): the scope stops at this boundary

Nesting and Scope

.card {
  padding: 1rem;

  & h2 { margin-top: 0; }       /* .card h2 */
  > p  { color: #444; }         /* .card > p */

  &:hover,
  &:focus-within { outline: 2px solid; }
  &.is-featured  { border-color: gold; }

  .theme-dark & { background: #222; }

  @media (width >= 40rem) {
    padding: 2rem;              /* applies to .card */
  }
}

/* @scope: only inside .card, not .card .content */
@scope (.card) to (.content) {
  img     { border-radius: 8px; }
  :scope  { container-type: inline-size; }
}

/* proximity: nearer root wins on a tie */
@scope (.light) { p { color: black; } }
@scope (.dark)  { p { color: white; } }

⚠ Common Mistakes

  • Writing &-title or &__el expecting Sass concatenation
  • Nesting more than three levels: selectors get long and specific
  • Forgetting nested rules take the parent's specificity (#id parents make everything heavy)

✓ Tips & Best Practices

  • Nest pseudo-classes, states and media queries; avoid deep descendant chains
  • Use @scope … to (…) for components that contain other components
  • Keep a plain-selector fallback where @scope support matters

Quick Summary

  • &: the parent selector
  • Nested @media works inside rules
  • @scope (root) to (limit)
  • Proximity breaks scope ties
