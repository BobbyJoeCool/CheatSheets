Lists & Counters

list-style-type · list-style-position · ::marker · @counter-style · counter-reset · counter-increment · counters()

Bullets and Numbering

list-style-type picks the bullet or numbering system (disc, decimal, lower-roman, or any string). ::marker styles the bullet itself: color, size and content. CSS counters number anything: counter-reset creates a counter, counter-increment steps it, and counter() or counters() prints it in generated content, which is how numbered headings and nested "1.2.3" outlines work. @counter-style defines custom numbering systems.

Notes

  • list-style-position: inside puts the marker inside the content box
  • list-style: none removes markers but Safari also drops list semantics
  • <ol> items use the built-in list-item counter
  • counters(name, ".") joins nested counter values

♿ Accessibility

  • Add role="list" to unstyled lists if the item count matters to screen-reader users
  • Numbers created with counters in ::before may not be read as list numbers; keep real <ol> where order matters

Browser Support

  • list-style-*, counters: universal
  • ::marker: Baseline (Safari supports a subset of properties)
  • @counter-style: Baseline 2023

Code Explained

A string value becomes the literal marker
::marker colors bullets without extra spans
counter-reset on the parent, counter-increment on each item
counters(item, ".") prints the full nested path
@counter-style with system: cyclic repeats its symbols

Markers and Counters

ul.checks { list-style-type: "✓ "; }
ol.roman  { list-style-type: upper-roman; }
ul.inside { list-style-position: inside; }

li::marker {
  color: #5b4bc4;
  font-weight: 700;
}

/* unstyled list for navigation */
.nav-list { list-style: none; padding: 0; }

/* numbered headings */
article        { counter-reset: section; }
article h2     { counter-increment: section; }
article h2::before {
  content: counter(section) ". ";
}

/* nested outline numbering: 1, 1.1, 1.1.1 */
ol.outline      { counter-reset: item; list-style: none; }
ol.outline > li    { counter-increment: item; }
ol.outline > li::before {
  content: counters(item, ".") " ";
}

/* custom system */
@counter-style thumbs {
  system: cyclic;
  symbols: "👍";
  suffix: " ";
}
ul.fun { list-style: thumbs; }

⚠ Common Mistakes

  • Incrementing the counter on the parent instead of each item
  • Resetting the counter on every item, so all show 1
  • Styling ::marker with padding or display (only a few properties apply)

✓ Tips & Best Practices

  • Use string list-style-type for simple custom bullets
  • Use counters for numbered headings, figures and steps
  • Keep <ol> for real sequences; the browser and screen readers count for you
