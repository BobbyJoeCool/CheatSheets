font-family · font stacks · system-ui · font-size · font-weight · font-style · font shorthand

Choosing and Sizing Type

font-family takes a stack: a list of fonts tried in order, ending with a generic family (serif, sans-serif, monospace, system-ui) as the guaranteed fallback. font-size sets the em box, font-weight the thickness (100–900), and font-style italic or oblique. The font shorthand sets them all at once but resets every font longhand it doesn't mention, including line-height.

Notes

  • font shorthand order: style, variant, weight, size/line-height, family (size and family required)
  • Weights without a matching font file are synthesized (faux bold); font-synthesis controls this
  • bolder/lighter are relative to the parent's weight
  • Keyword sizes: xx-small … xxx-large; smaller/larger are relative

♿ Accessibility

  • Body text of at least 16px (1rem) and sizes in rem respect user settings
  • Avoid thin weights (100–300) for body text; low stroke contrast hurts readability

Browser Support

  • All font properties: universal
  • system-ui: Baseline; ui-monospace, ui-serif, ui-rounded: Safari only, so add fallbacks

Code Explained

Each family is tried in order until one is available
Family names with spaces need quotes; generics never do
font: … 2rem/1.1 …: size, slash, line-height
A later font shorthand resets line-height to normal
font: inherit gives controls the page's type

Stacks, Sizes, Shorthand

body {
  font-family: system-ui, -apple-system, "Segoe UI",
               Roboto, sans-serif;
  font-size: 1rem;
  font-weight: 400;
  line-height: 1.5;
}

code, pre {
  font-family: ui-monospace, "Cascadia Code",
               Menlo, Consolas, monospace;
  font-size: .9em;            /* relative to parent */
}

h1 { font-weight: 800; }
em { font-style: italic; }
.small-caps { font-variant-caps: small-caps; }

/* shorthand: style weight size/line-height family */
.title { font: italic 700 2rem/1.1 Georgia, serif; }

/* shorthand resets line-height! */
.oops { line-height: 2; font: 1rem sans-serif; }
/* line-height is now normal */

/* don't fake bold or italic */
.brand { font-synthesis: none; }

/* inherit fonts into form controls */
button, input, select, textarea { font: inherit; }

⚠ Common Mistakes

  • No generic family at the end of a stack: the browser default may be a serif
  • Using the font shorthand after line-height and losing it
  • Requesting weight 600 when only 400 and 700 are loaded (it rounds to the nearest)

✓ Tips & Best Practices

  • End every stack with a generic family
  • Use system-ui for fast, native-looking UI text
  • Load only the weights you use

Quick Summary

  • Stack fonts; end with a generic
  • font-weight 100–900
  • font shorthand resets longhands
  • Size text in rem
