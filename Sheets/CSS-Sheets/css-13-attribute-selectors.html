Sheet 13

Attribute Selectors

[attr] · [attr=v] · ~= · |= · ^= · $= · *= · i/s flags

Matching on Attributes

Attribute selectors match elements by the presence or value of an attribute. [attr] checks that it exists; the operator forms compare the value exactly (=), by word (~=), by prefix (^=), suffix ($=), substring (*=) or language-style prefix (|=). Add i before the bracket closes to compare case-insensitively. They're ideal for styling by state, link type or data-* attributes.

Notes

  • Values with spaces or special characters need quotes: [title="Hi there"]
  • Each attribute selector adds (0,1,0) specificity, like a class
  • [class~="btn"] equals .btn; [class*="btn"] also matches btn-group
  • data-* attributes make clean state hooks: [data-state="open"]

♿ Accessibility

  • Style from ARIA state so visuals can't drift from what assistive tech hears: [aria-current="page"], [aria-expanded="true"]
  • [aria-disabled="true"] elements stay focusable; style them as disabled anyway

Browser Support

  • All operators: universal
  • i flag: universal in current browsers; s flag: Firefox only

Code Explained

^= starts with, $= ends with, *= contains
~= matches one whole word in a space-separated list
|= matches en exactly or en- followed by anything
i makes the value comparison case-insensitive
ARIA and data-* attributes double as styling state

Attribute Operators

[disabled]                { opacity: .5; }
[type="checkbox"]         { accent-color: #5b4bc4; }

/* link types */
a[href^="https://"]       { padding-right: 1em; }
a[href^="mailto:"]::before { content: "✉ "; }
a[href$=".pdf"]::after    { content: " (PDF)"; }
a[href*="example.com"]    { font-weight: 600; }

/* word in a space-separated list */
[rel~="nofollow"]         { color: gray; }

/* lang prefix: en, en-US, en-GB */
[lang|="en"]              { quotes: "“" "”"; }

/* case-insensitive */
a[href$=".PDF" i]         { color: crimson; }

/* state hooks */
[data-state="open"]       { display: block; }
[aria-current="page"]     { font-weight: 700; }
[aria-expanded="true"] .icon { rotate: 180deg; }

/* combine with type */
input[type="email"]:invalid { border-color: red; }

Operators

⚠ Common Mistakes

  • Using [class*="col"] and accidentally matching .collapse
  • Forgetting quotes around values containing spaces, dots or colons
  • Setting display on [hidden] elements in your CSS and making them visible

✓ Tips & Best Practices

  • Prefer ~= over *= for class-like lists
  • Drive component state with data-state or ARIA attributes instead of extra classes
  • Add [hidden] { display: none !important; } to your reset

Quick Summary

  • [a] exists · [a=v] exact
  • ^= start · $= end · *= contains
  • ~= word · |= lang prefix
  • i flag ignores case
