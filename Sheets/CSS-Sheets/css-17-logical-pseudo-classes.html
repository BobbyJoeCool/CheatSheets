Sheet 17

Logical Pseudo-Classes

:is() · :where() · :not() · :has() · forgiving selector lists · parent-selector patterns

Selector Logic

Four functional pseudo-classes take selector lists. :is() matches any of them (OR) and takes the highest argument's specificity; :where() does the same with zero specificity. :not() excludes matches. :has() is the long-wanted parent selector: it matches an element that contains (or is followed by) something matching a relative selector, so a card can react to having an image or a form to holding an invalid field.

Notes

  • :is() and :where() use forgiving lists: one invalid selector doesn't kill the rule
  • :not(.a, .b) excludes both; it accepts complex selectors
  • :has() arguments are relative: :has(> img), :has(+ p)
  • :has() can't be nested inside another :has()

♿ Accessibility

  • :has(:focus-visible) lets a whole card show focus when its link is focused
  • body:has(dialog[open]) can lock scroll while a modal is open

Browser Support

  • :is(), :where(), complex :not(): Baseline 2021
  • :has(): Baseline 2023; use @supports selector(:has(a)) for a fallback

Code Explained

:is() turns 3 × 2 combinations into one selector
:where() resets lists without raising specificity
:not(a, b) excludes internal and fragment links
h2:has(+ p): style a heading based on what follows it
:has(> :nth-child(5)): a container that has at least five children

Is, Where, Not, Has

/* :is() shortens long lists */
:is(article, section, aside) :is(h1, h2) {
  margin-top: 0;
}

/* :where() = zero specificity defaults */
:where(ul, ol)[class] { list-style: none; }

/* :not() */
a:not([href^="/"], [href^="#"]) {
  text-decoration-style: dotted;   /* external */
}
.btn:not(:disabled):hover { filter: brightness(1.1); }

/* :has(): parent and previous-sibling selector */
.card:has(img)           { grid-template-rows: auto 1fr; }
.card:has(> h2 + p)      { padding-top: 0; }
label:has(+ input:required)::after { content: " *"; }
h2:has(+ p)              { margin-bottom: .25rem; }

/* page-level state */
body:has(dialog[open])   { overflow: hidden; }
form:has(:user-invalid) button[type="submit"] {
  opacity: .6;
}

/* quantity: grid with 5+ items */
.grid:has(> :nth-child(5)) { --cols: 3; }

⚠ Common Mistakes

  • Using :is(#id, .class) and getting ID weight for every match
  • Writing :has(img) when you mean direct children (:has(> img))
  • Very broad :has() on body or * that the browser must re-check constantly

✓ Tips & Best Practices

  • Use :where() in resets and libraries
  • Anchor :has() to a specific element or class to keep it fast
  • Feature-test with @supports selector(:has(*))

Quick Summary

  • :is() OR, heaviest weight
  • :where() OR, zero weight
  • :not() exclude
  • :has() parent / previous sibling
