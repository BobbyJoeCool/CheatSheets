Sheet 33

Shadows

box-shadow · inset · spread · layered shadows · text-shadow · drop-shadow() · elevation scales

Depth Without Images

box-shadow draws one or more shadows around an element's border box: x y blur spread color. inset draws it inside. Shadows follow border-radius and take no layout space. text-shadow applies to glyphs (no spread or inset). The filter: drop-shadow() function follows the alpha shape of an element, so it shadows transparent PNGs and SVG outlines, not just rectangles.

Notes

  • Comma-separate several shadows; the first one is drawn on top
  • Positive spread grows the shadow; negative shrinks it
  • A shadow with 0 blur and spread acts like a solid offset copy
  • Animating box-shadow repaints each frame; animate the opacity of a pseudo-element instead

♿ Accessibility

  • Don't rely on a subtle shadow alone to separate a control from its background; borders survive forced-colors mode
  • text-shadow can help contrast on images but doesn't replace sufficient contrast

Browser Support

  • box-shadow, text-shadow, filter: drop-shadow(): universal

Code Explained

Low alpha black gives natural shadows
Three stacked shadows mimic soft real-world light
inset flips the shadow inside the box
0 0 0 3px = a crisp ring using only spread
drop-shadow() traces transparent areas of images and SVG

Shadow Recipes

/* soft card */
.card { box-shadow: 0 1px 3px rgb(0 0 0 / .12); }

/* layered = more realistic */
.raised {
  box-shadow:
    0 1px 2px rgb(0 0 0 / .08),
    0 4px 8px rgb(0 0 0 / .08),
    0 12px 24px rgb(0 0 0 / .08);
}

/* inset: pressed or input field */
.pressed { box-shadow: inset 0 2px 4px rgb(0 0 0 / .2); }

/* spread-only ring (focus) */
.ring { box-shadow: 0 0 0 3px #5b4bc4; }

/* glow */
.glow { box-shadow: 0 0 16px 4px rgb(91 75 196 / .5); }

/* readable text on images */
.hero h1 { text-shadow: 0 2px 6px rgb(0 0 0 / .6); }

/* shape-aware shadow */
.logo { filter: drop-shadow(0 4px 6px rgb(0 0 0 / .3)); }

/* elevation tokens */
:root {
  --shadow-1: 0 1px 2px rgb(0 0 0 / .1);
  --shadow-2: 0 4px 12px rgb(0 0 0 / .12);
}

⚠ Common Mistakes

  • Using pure black at high opacity: looks harsh and dirty
  • Animating large box-shadows, which causes paint jank
  • Expecting box-shadow on a transparent PNG to follow the image shape

✓ Tips & Best Practices

  • Define 3–5 elevation tokens and use only those
  • Fade a pre-rendered shadow on a ::after for smooth hover effects
  • Tint shadows with the brand hue instead of pure black for warmth

Quick Summary

  • box-shadow: x y blur spread color
  • Comma-separate to layer
  • inset for inner shadows
  • drop-shadow() follows shape
