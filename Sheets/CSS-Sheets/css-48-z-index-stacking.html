Sheet 48

Z-Index & Stacking Contexts

z-index · stacking context triggers · isolation: isolate · opacity & transform contexts · top layer

What Sits on Top

z-index orders positioned elements (and flex/grid items) along the z-axis, but only within their stacking context. A stacking context is a self-contained group: its children can never rise above or sink below things outside it, no matter how big their z-index. Many properties create one: opacity below 1, transform, filter, isolation: isolate, and positioned elements with a z-index. The top layer (dialogs, popovers, fullscreen) sits above everything.

Notes

  • z-index has no effect on position: static elements (except flex/grid items)
  • Within one context, later siblings paint over earlier ones at equal z-index
  • Negative z-index puts a child behind its parent's content but not behind the context's background
  • isolation: isolate makes a context with no other side effects

♿ Accessibility

  • Modals in the top layer (<dialog> via showModal()) also make the rest of the page inert for keyboard and screen readers

Browser Support

  • z-index, stacking contexts: universal; isolation: Baseline
  • Top layer via <dialog> and popover: Baseline 2022 / 2024

Code Explained

.header forms a context at level 2
.main's transform makes its own context at level 0
The dropdown's 9999 is compared only inside .main
isolation: isolate lets z-index: -1 stay inside the card
Dialogs opened with showModal() are above all z-indexes

Why 9999 Doesn't Win

/* context A */
.header {
  position: relative;
  z-index: 2;
}

/* context B: transform creates a context */
.main {
  transform: translateZ(0);       /* context, z = auto→0 */
}
.main .dropdown {
  position: absolute;
  z-index: 9999;                  /* only inside .main */
}                                 /* still under .header */

/* fix: isolate components, keep z small */
.card { isolation: isolate; }
.card .bg   { position: absolute; inset: 0; z-index: -1; }
.card .text { position: relative; }

/* layering tokens */
:root {
  --z-dropdown: 10;
  --z-sticky: 20;
  --z-overlay: 30;
  --z-toast: 40;
}

/* top layer: no z-index needed */
dialog::backdrop { background: #0008; }

⚠ Common Mistakes

  • Escalating z-index to 9999 when the real issue is the parent's context
  • Adding opacity: .99 or a transform and unexpectedly trapping a dropdown
  • Setting z-index on a static element and seeing no effect

✓ Tips & Best Practices

  • Use small z-index scales stored as tokens
  • Inspect contexts with the DevTools Layers panel or 3D view
  • Use <dialog> and popover so overlays live in the top layer

Quick Summary

  • z-index works within a stacking context
  • Many properties create contexts
  • isolation: isolate = clean context
  • Top layer beats everything
