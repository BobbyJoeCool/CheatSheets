Color Syntax

named colors · hex · rgb() · hsl() · alpha · opacity · currentColor · transparent

Writing Colors

CSS colors can be named (tomato), hex (#ff6347), rgb() or hsl(), plus the modern spaces on the next sheet. Modern syntax separates channels with spaces and alpha with a slash: rgb(255 99 71 / 50%). currentColor reuses the element's color value, which keeps borders, icons and SVG fills in sync. Color alpha only affects that one color; opacity fades the whole element and its children.

Notes

  • Hex shorthands: #f60 = #ff6600; with alpha: #ff660080 or #f608
  • rgba()/hsla() are legacy aliases; rgb() takes alpha now
  • hsl(h s l): hue in degrees, saturation and lightness in %
  • transparent = rgb(0 0 0 / 0)

♿ Accessibility

  • Text needs 4.5:1 contrast (3:1 for large text and UI parts) against its background (WCAG 1.4.3, 1.4.11)
  • Don't use color alone to convey meaning (WCAG 1.4.1)

Browser Support

  • Named, hex, rgb(), hsl(), currentColor: universal
  • Space-separated syntax and 8-digit hex: Baseline Widely available

Code Explained

Modern rgb(): spaces between channels, / before alpha
Alpha can be 0–1 or a percentage
currentColor makes the border match the text automatically
opacity fades everything, including child text
Changing HSL lightness is a quick hover shade (but see oklch)

Color Formats

.a { color: rebeccapurple; }          /* named */
.b { color: #5b4bc4; }                /* hex */
.c { color: #5b4bc480; }              /* hex + alpha */
.d { color: rgb(91 75 196); }         /* modern rgb */
.e { color: rgb(91 75 196 / 50%); }   /* + alpha */
.f { color: hsl(248 51% 53%); }       /* hue sat light */
.g { color: hsl(248 51% 53% / .5); }

/* legacy comma syntax still valid */
.h { color: rgba(91, 75, 196, 0.5); }

/* currentColor: follow the text color */
.icon-btn {
  color: #5b4bc4;
  border: 2px solid currentColor;
}
.icon-btn svg { fill: currentColor; }

/* alpha color vs opacity */
.overlay-a { background: rgb(0 0 0 / 60%); } /* text ok */
.overlay-b { background: black; opacity: .6; } /* fades */

/* tint via hsl lightness */
.btn       { background: hsl(248 51% 53%); }
.btn:hover { background: hsl(248 51% 45%); }

⚠ Common Mistakes

  • Using opacity to fade a background and fading the text with it
  • Mixing comma and space syntax in one function (rgb(0, 0 0))
  • Assuming equal HSL lightness looks equally light: yellow and blue at 50% differ a lot

✓ Tips & Best Practices

  • Use currentColor for borders, icons and SVG fills
  • Check contrast in DevTools' color picker
  • Prefer oklch for palettes; HSL lightness isn't perceptual

Quick Summary

  • rgb(r g b / a) · hsl(h s l / a)
  • #rrggbbaa hex with alpha
  • currentColor = text color
  • Alpha color ≠ opacity
