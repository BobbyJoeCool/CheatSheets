The Box Model

content · padding · border · margin · box-sizing · content-box vs border-box · DevTools box view

Four Nested Boxes

Every element renders as a rectangle made of four areas: content, padding (inside the border, takes the background), border, and margin (outside, always transparent). By default (box-sizing: content-box) width sets only the content, so padding and border are added on top. border-box makes width include padding and border, which is what almost everyone wants, and is why resets set it globally.

Notes

  • Margins are transparent and can be negative; padding can't
  • Backgrounds paint under padding and border by default (background-clip: border-box)
  • Inline elements ignore width, height and vertical margins
  • outline and box-shadow don't take up space in the layout

♿ Accessibility

  • Padding enlarges the clickable area of links and buttons; aim for at least 24×24px targets (WCAG 2.5.8)

Browser Support

  • Box model and box-sizing: universal

Code Explained

content-box: rendered width = width + padding + border
border-box: rendered width = width
Margins never count toward width
inherit version lets a component switch back to content-box
inline-block gives inline elements full box behavior

content-box vs border-box

/* width: 200 + 2×20 padding + 2×5 border = 250px */
.content-box {
  box-sizing: content-box;     /* default */
  width: 200px;
  padding: 20px;
  border: 5px solid;
  margin: 10px;                /* outside, not in width */
}

/* width stays 200px; content shrinks to 150px */
.border-box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid;
}

/* global reset (inheritable version) */
html { box-sizing: border-box; }
*, *::before, *::after { box-sizing: inherit; }

/* inline elements: vertical margins ignored */
span.tag {
  margin-block: 20px;          /* no effect */
  padding-block: 4px;          /* paints, no layout push */
  display: inline-block;       /* now both apply */
}

⚠ Common Mistakes

  • Setting width: 100% plus padding with content-box: the box overflows its parent
  • Trying to size <span>s without changing display
  • Using margin for the inner space of a clickable element (margin isn't clickable)

✓ Tips & Best Practices

  • Set border-box globally in your reset
  • Use the DevTools box-model diagram to see every area
  • Use padding for internal spacing, gap or margin for spacing between boxes

Quick Summary

  • content → padding → border → margin
  • border-box: width includes padding + border
  • Margins are outside and transparent
  • Inline boxes ignore width/height
