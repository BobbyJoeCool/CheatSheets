What CSS Is

Cascading Style Sheets describe how HTML is presented: layout, color, type, spacing and motion. HTML says what content is; CSS says how it looks. The language is developed by the W3C CSS Working Group as separate modules (Selectors, Color, Grid…) that each move through their own levels. There is no CSS4: "CSS3" just meant everything after CSS 2.1, and the yearly CSS Snapshot lists which modules are stable.

Notes

  • A browser applies three style sources: its own UA stylesheet, the user's, and yours (the author)
  • Three engines matter: Blink (Chrome, Edge, Opera), WebKit (Safari, every iOS browser) and Gecko (Firefox)
  • Unknown properties and values are ignored, not errors, so new CSS degrades gracefully
  • File extension is .css; MIME type text/css

♿ Accessibility

  • Users can override author CSS with zoom, forced colors, custom fonts and user stylesheets
  • Good CSS keeps content readable when styles fail; the HTML order is the reading order

Browser Support

  • Baseline labels a feature Newly available once it works in all major engines, and Widely available 30 months later
  • Check caniuse.com or the Baseline badge on MDN before relying on a feature
  • Use @supports to ship new features as progressive enhancement

Code Explained

:root: the <html> element; a home for site-wide variables
body { … }: a rule = selector + declaration block
font-size: 2rem: relative to the root font size
a:hover: pseudo-class, matches while the pointer is over a link
@media: an at-rule that applies its rules only when the condition is true

A First Stylesheet

/* styles.css */
:root {
  --brand: #5b4bc4;              /* custom property */
}

body {
  font-family: system-ui, sans-serif;
  line-height: 1.5;
  margin: 0;
}

h1 {
  color: var(--brand);
  font-size: 2rem;             /* 32px at default size */
}

a:hover {
  text-decoration-thickness: 2px;
}

.card {
  padding: 1rem;
  border: 1px solid #ddd;
  border-radius: 8px;
}

@media (min-width: 40rem) {    /* wider screens only */
  .card { padding: 2rem; }
}

⚠ Common Mistakes

  • Searching for "CSS3 feature" lists: modules version independently, so check each feature's support
  • Treating an unsupported property as broken CSS: the browser skips just that declaration
  • Testing only in Chrome: Safari is the only engine on iOS

✓ Tips & Best Practices

  • Keep MDN and DevTools open while you write; edit in DevTools, then copy the result back
  • Check a feature's Baseline status before you use it without a fallback
  • Write the plain version first, then layer newer features on top

Quick Summary

  • selector { property: value; }: the basic rule
  • Cascade: UA, user and author styles combine by priority
  • Modules + levels replace version numbers
  • Baseline: Newly → Widely available after 30 months
