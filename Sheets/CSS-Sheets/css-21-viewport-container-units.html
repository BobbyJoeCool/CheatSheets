Sheet 21

Viewport & Container Units

vw · vh · vmin · vmax · svh · lvh · dvh · cqi

Sizing to the Screen or Container

Viewport units are percentages of the viewport: 1vw is 1% of its width and 1vh 1% of its height. On mobile, browser toolbars grow and shrink, so vh was ambiguous. The small (svh), large (lvh) and dynamic (dvh) variants fix that. Container query units (cqi, cqb, cqw, cqh) are the same idea relative to the nearest size container, which makes components scale with their slot instead of the window.

Notes

  • 100vw includes the vertical scrollbar, so it can cause horizontal scroll
  • svh = toolbars shown (smallest); lvh = toolbars hidden (largest); dvh follows them live
  • vi/vb follow the writing mode's inline/block axes
  • Without a container ancestor, cq* units fall back to small viewport units

♿ Accessibility

  • Pure vw font sizes don't grow with zoom; always mix with rem in clamp()
  • 100vh layouts can hide content behind mobile toolbars; use 100dvh or min-height

Browser Support

  • vw, vh, vmin, vmax: universal
  • svh/lvh/dvh and friends: Baseline 2022
  • Container query units: Baseline 2023

Code Explained

Declare vh first as a fallback, then the newer unit
100svh fits even when the mobile toolbar is visible
clamp() with rem + vw scales but still zooms
container-type: inline-size makes the slot a size container
5cqi = 5% of the container's inline size

Viewport and Container Sizing

/* full-screen hero that respects mobile toolbars */
.hero {
  min-height: 100vh;        /* fallback */
  min-height: 100svh;       /* never hidden by toolbars */
}

/* app shell that tracks toolbars as they move */
.app { height: 100dvh; }

/* fluid type: never pure vw */
h1 { font-size: clamp(2rem, 1rem + 4vw, 4rem); }

/* square based on the smaller side */
.square { width: 50vmin; aspect-ratio: 1; }

/* container query units */
.card-slot { container-type: inline-size; }

.card h2 {
  font-size: clamp(1rem, 5cqi, 2rem); /* 5% of slot */
}
.card {
  padding: 4cqi;
  gap: 2cqi;
}

/* avoid: horizontal scroll from scrollbar */
.full-bleed { width: 100vw; }   /* use 100% */

Viewport Units

Unit1 unit =
vw / vh1% of viewport width / height
vmin / vmax1% of smaller / larger side
vi / vb1% of inline / block axis
svh / svwSmall viewport (toolbars shown)
lvh / lvwLarge viewport (toolbars hidden)
dvh / dvwDynamic: current size

Container Units

Unit1 unit =
cqw / cqh1% of container width / height
cqi / cqb1% of container inline / block size
cqmin / cqmax1% of smaller / larger

⚠ Common Mistakes

  • width: 100vw on a page with a scrollbar: adds horizontal scroll
  • height: 100vh on mobile: bottom content sits under the toolbar
  • font-size: 5vw: text no longer responds to zoom (fails WCAG 1.4.4)

✓ Tips & Best Practices

  • Use svh for heroes and dvh for app shells
  • Prefer cqi over vw inside components
  • Combine viewport units with rem inside clamp()

Quick Summary

  • vw/vh = viewport %
  • svh · lvh · dvh for mobile
  • cqi = container inline %
  • Never size text in vw alone
