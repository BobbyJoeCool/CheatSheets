Sheet 29

Margin & Padding

1–4 value shorthand · auto margins · negative margins · margin collapsing · percentage padding

Space Around and Inside

margin and padding take 1 to 4 values going clockwise from the top. margin: auto absorbs free space, which centers block elements horizontally and pushes flex items apart. Vertical margins between blocks in normal flow collapse: adjacent margins merge into the larger one instead of adding up. Collapsing never happens in flex or grid containers, and is blocked by padding, borders or a new formatting context.

Notes

  • Clockwise order: Top, Right, Bottom, Left ("TRouBLe")
  • Percentages for margin and padding use the containing block's width, even vertically
  • Negative margins pull elements over neighbors or reduce space
  • A parent's top margin collapses with its first child's when nothing separates them

♿ Accessibility

  • Don't use large negative margins that push text off-screen or under other content

Browser Support

  • Margin, padding, auto margins: universal
  • Logical versions (margin-inline, padding-block): Baseline 2021; see sheet 31

Code Explained

Missing values copy their opposite side
margin-inline: auto centers a block with a set width
margin-left: auto in flex eats all free space before .login
Adjacent vertical margins collapse to the larger one
flow-root creates a formatting context and stops collapse

Shorthands and Collapsing

.a { margin: 1rem; }                 /* all four */
.b { margin: 1rem 2rem; }            /* T/B  L/R */
.c { margin: 1rem 2rem 3rem; }       /* T  L/R  B */
.d { margin: 1rem 2rem 3rem 4rem; }  /* T R B L */

/* center a block */
.page { max-width: 60rem; margin-inline: auto; }

/* push the last flex item right */
.nav { display: flex; }
.nav .login { margin-left: auto; }

/* collapsing: gap is 32px, not 52px */
h2 { margin-bottom: 32px; }
p  { margin-top: 20px; }

/* stop parent-child collapse */
.card { padding-top: 1px; }          /* or */
.card { display: flow-root; }

/* negative margin: overlap an avatar */
.avatar { margin-top: -2rem; }

/* intrinsic ratio via % padding (old trick) */
.ratio { padding-top: 56.25%; }      /* 16:9 */
/* modern: aspect-ratio: 16 / 9; */

Shorthand Values

CountApplies to
1All sides
2Vertical, horizontal
3Top, horizontal, bottom
4Top, right, bottom, left

Margin Collapse

SituationCollapses?
Adjacent siblings (vertical)Yes
Parent and first/last childYes, without padding/border
Empty block's own top/bottomYes
Horizontal marginsNever
Flex or grid itemsNever
Floats, absolute, inline-blockNever

⚠ Common Mistakes

  • Expecting margin-top: 10% to use the parent's height
  • Being surprised a child's top margin moves the parent down (collapse through the parent)
  • Using margin: auto vertically in normal flow (only works in flex/grid or absolute positioning)

✓ Tips & Best Practices

  • Space siblings with gap in flex/grid instead of margins
  • Pick one direction for flow margins (e.g. only margin-block-start) to avoid collapse puzzles
  • Use aspect-ratio instead of the padding-percentage trick

Quick Summary

  • 1–4 values, clockwise from top
  • auto absorbs free space
  • Vertical margins collapse in normal flow
  • % padding/margin = parent width
