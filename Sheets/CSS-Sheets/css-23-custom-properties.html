Sheet 23

Custom Properties

--name · var() · fallback · :root · inheritance & scope · invalid at computed-value time

CSS Variables

Custom properties are author-defined properties whose names start with --. Read them with var(--name, fallback). Unlike preprocessor variables they're live: they cascade and inherit, can change per element, in media queries or from JavaScript, and every var() updates. Define global design tokens on :root, then override them in a narrower scope to theme a component.

Notes

  • Names are case-sensitive: --Brand ≠ --brand
  • Values are stored as raw tokens and only checked when used
  • A var() that resolves to an invalid value makes the property invalid at computed-value time: it becomes unset, not the earlier declaration
  • var() can't build property names or selectors; only values

♿ Accessibility

  • Keep color tokens paired (--text / --surface) so every theme keeps contrast
  • Expose --focus-ring as a token so components can't forget focus styles

Browser Support

  • Custom properties and var(): Baseline Widely available (since 2017)
  • Typed, animatable custom properties via @property: see sheet 24

Code Explained

:root makes tokens available everywhere by inheritance
var(--btn-text, white): fallback when the variable isn't set
.btn--danger changes the variable, not the rule
Changing a token in a media query updates every use
An invalid var() result doesn't fall back to the earlier width

Tokens and Themes

:root {
  --brand: #5b4bc4;
  --text: #1d1b26;
  --surface: #ffffff;
  --space: 1rem;
  --radius: 8px;
}

.btn {
  background: var(--brand);
  padding: calc(var(--space) / 2) var(--space);
  border-radius: var(--radius);
  color: var(--btn-text, white);       /* fallback */
}

/* component-level override */
.btn--danger { --brand: #c62828; }

/* theme switch */
[data-theme="dark"] {
  --text: #ece9f6;
  --surface: #17151f;
}

/* responsive token */
@media (width >= 60rem) {
  :root { --space: 1.5rem; }
}

/* invalid at computed-value time */
.box { --size: red; width: 100px; width: var(--size); }
/* width → auto, NOT 100px */

⚠ Common Mistakes

  • Writing var(--space)px: produces 16 px tokens, not 16px; use calc(var(--n) * 1px)
  • Expecting an invalid var() to fall back to the previous declaration
  • Defining tokens on body and using them in html-level rules

✓ Tips & Best Practices

  • Keep raw tokens (--purple-600) and semantic tokens (--brand) separate
  • Override tokens per component instead of rewriting rules
  • Store unitless numbers and multiply in calc() when JS updates them

Quick Summary

  • --name: value / var(--name)
  • Cascades and inherits
  • Fallback: var(--x, default)
  • Invalid result → unset
