Sheet 67

Scroll-Driven Animations

animation-timeline · scroll() · view() · animation-range · scroll-timeline · view-timeline · reduced-motion fallback

Animation Tied to Scrolling

Scroll-driven animations replace time with scroll position. Set animation-timeline: scroll() to drive a normal @keyframes animation by how far a scroller has scrolled (reading-progress bars), or view() to drive it by an element's visibility as it moves through the scrollport (reveal on scroll). animation-range narrows when it plays, like entry 0% cover 40%. No JavaScript, and they run off the main thread.

Notes

  • Time-based duration doesn't apply on a scroll timeline; the scroll range sets progress
  • Declare animation-timeline after the animation shorthand, which resets it
  • scroll(root block): the document scroller on the block axis
  • Named timelines (scroll-timeline, view-timeline) let other elements follow a scroller

♿ Accessibility

  • Parallax and scroll-linked motion can cause nausea; disable under prefers-reduced-motion: reduce
  • Never hide content until it scrolls into view without a fallback; unsupported browsers must still show it

Browser Support

  • Scroll-driven animations: not yet in every engine (Chromium first, then Safari); Firefox status: check
  • Wrap in @supports (animation-timeline: view()) so other browsers get static content

Code Explained

scroll(root block): progress of the page's vertical scroll
scale: 0 1 → 1 1 grows the bar horizontally from the left
view(): progress of the card crossing the viewport
entry 0% cover 30%: run from first appearance until 30% through
scroll-timeline: --gallery inline names a horizontal scroller's timeline

Progress Bar and Reveal

/* reading progress bar */
@keyframes grow { from { scale: 0 1; } to { scale: 1 1; } }

.progress {
  position: fixed; inset: 0 0 auto;
  height: 4px; background: #5b4bc4;
  transform-origin: left;
  animation: grow linear both;
  animation-timeline: scroll(root block);
}

/* reveal as each card enters the viewport */
@keyframes reveal {
  from { opacity: 0; translate: 0 2rem; }
  to   { opacity: 1; translate: 0 0; }
}

@supports (animation-timeline: view()) {
  @media (prefers-reduced-motion: no-preference) {
    .card {
      animation: reveal linear both;
      animation-timeline: view();
      animation-range: entry 0% cover 30%;
    }
  }
}

/* named timeline used by another element */
.gallery { scroll-timeline: --gallery inline; }
.gallery-dots { animation: grow linear both;
                animation-timeline: --gallery; }

⚠ Common Mistakes

  • Setting animation-timeline before the animation shorthand, which resets it to auto
  • Starting content at opacity: 0 without @supports, so it stays invisible in other browsers
  • Giving the animation an easing other than linear and getting odd scroll feel

✓ Tips & Best Practices

  • Use linear timing so motion tracks the scroll directly
  • Keep keyframes to transform and opacity for smoothness
  • Use the Scroll-Driven Animations DevTools extension to debug ranges

Quick Summary

  • animation-timeline: scroll() / view()
  • animation-range limits the phase
  • Declare timeline after the shorthand
  • @supports + reduced-motion guard
