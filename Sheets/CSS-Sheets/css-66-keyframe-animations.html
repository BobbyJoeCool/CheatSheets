Keyframe Animations

@keyframes · animation-name · iteration-count · direction · fill-mode · play-state · animation shorthand · multiple animations

Multi-Step Motion

Where transitions go from A to B on a change, animations run a sequence defined by @keyframes: any number of steps at percentages (from = 0%, to = 100%). Attach with animation-name and a duration; control repetition (iteration-count), direction (alternate back and forth), and fill-mode, which decides whether the first or last keyframe applies before and after the animation runs. They start automatically when the style applies.

Notes

  • Omit a property in a keyframe and it interpolates from the element's own value
  • animation-fill-mode: both holds the start state during the delay and the end state after
  • Several animations: comma-separate them in animation
  • animation-play-state: paused freezes an animation in place

♿ Accessibility

  • Nothing should flash more than 3 times per second (WCAG 2.3.1)
  • Infinite animations need a way to stop; wrap them in prefers-reduced-motion: no-preference (WCAG 2.2.2)

Browser Support

  • @keyframes and animation-*: universal
  • animation-composition: Baseline 2023

Code Explained

from/to are 0% and 100%
Shorthand: name, duration, easing, fill-mode
Grouped selectors 0%, 100% share one keyframe
--i set inline (style="--i: 2") staggers the delay
In the shorthand the first time is duration, the second is delay

Keyframes and Shorthand

@keyframes fade-up {
  from { opacity: 0; translate: 0 1rem; }
  to   { opacity: 1; translate: 0 0; }
}

.toast {
  animation: fade-up .4s ease-out both;
}

@keyframes pulse {
  0%, 100% { scale: 1; }
  50%      { scale: 1.08; }
}
.badge { animation: pulse 1.5s ease-in-out infinite; }

/* spinner */
@keyframes spin { to { rotate: 1turn; } }
.spinner { animation: spin 1s linear infinite; }

/* staggered list */
.list > li {
  animation: fade-up .4s ease-out both;
  animation-delay: calc(var(--i) * 60ms);
}

/* pause on hover */
.marquee:hover { animation-play-state: paused; }

/* opt in to motion */
@media (prefers-reduced-motion: no-preference) {
  .hero h1 { animation: fade-up .8s .2s ease-out both; }
}

⚠ Common Mistakes

  • Element jumps back after the animation ends: add forwards or both
  • Flash of final state before a delayed entrance: use backwards or both
  • Animating layout properties like height or left instead of transforms

✓ Tips & Best Practices

  • Name keyframes by effect (fade-up), not by element
  • Use negative delays to start loaders mid-cycle
  • Prefer transitions for simple A→B changes

Quick Summary

  • @keyframes name { from {} to {} }
  • animation: name dur ease delay count dir fill
  • fill-mode: both keeps start/end
  • Opt in under no-preference
