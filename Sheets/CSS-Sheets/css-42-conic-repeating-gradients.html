Conic & Repeating Gradients

conic-gradient() · from · at · pie charts · repeating-linear-gradient() · stripes · in oklch interpolation

Around a Point, Over and Over

conic-gradient() sweeps colors around a center point instead of outward, which makes pie charts, color wheels and spinners. from sets the starting angle and at the center. The repeating variants (repeating-linear-gradient(), repeating-radial-gradient(), repeating-conic-gradient()) tile their stop pattern endlessly, which is ideal for stripes and checkerboards. A color-interpolation space (in oklch) changes how the middle colors blend.

Notes

  • Conic stops use angles or percentages of the full turn
  • Hard stops in a conic gradient make pie slices
  • Repeating gradients repeat the distance between the first and last stop
  • longer hue in in oklch longer hue goes the long way around the wheel

♿ Accessibility

  • A CSS pie chart is decorative to screen readers; provide the numbers as text or a table

Browser Support

  • Conic and repeating gradients: Baseline Widely available
  • Interpolation color spaces (in oklch, longer hue): Baseline 2024

Code Explained

Each slice starts where the last ended (0 = same as previous stop)
A radial mask turns the pie into a donut
longer hue from red to red sweeps the whole hue wheel
repeating-conic tiled at 20px makes a checkerboard
Stripes repeat every 20px along the 45° line

Conic, Repeating, Interpolation

/* pie chart: 40 / 35 / 25 */
.pie {
  border-radius: 50%;
  background: conic-gradient(
    #5b4bc4 0 40%,
    #00bcd4 0 75%,
    #ffb74d 0);
}

/* donut: mask out the middle */
.donut {
  mask: radial-gradient(circle, transparent 55%, #000 56%);
}

/* color wheel */
.wheel {
  border-radius: 50%;
  background: conic-gradient(in oklch longer hue,
    red, red);
}

/* checkerboard */
.checker {
  background: repeating-conic-gradient(
    #ddd 0 25%, #fff 0 50%) 0 0 / 20px 20px;
}

/* diagonal stripes */
.stripes {
  background: repeating-linear-gradient(45deg,
    #5b4bc4 0 10px, #7e6fd6 10px 20px);
}

/* rings */
.rings {
  background: repeating-radial-gradient(circle,
    #5b4bc4 0 4px, transparent 4px 12px);
}

⚠ Common Mistakes

  • Building data charts in CSS only: values aren't readable or accessible
  • Forgetting background-size with repeating patterns made from conic tiles
  • Using hsl interpolation and getting uneven brightness across the wheel

✓ Tips & Best Practices

  • Feed pie values from custom properties: var(--a) stops
  • Use in oklch for gradients between saturated colors
  • Patterns from gradients cost no requests and scale perfectly
