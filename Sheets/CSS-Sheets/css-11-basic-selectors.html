Basic Selectors

Picking Elements

A simple selector matches elements by one trait: type (p), class (.note), ID (#intro), attribute ([href]) or the universal *. Chain them with no spaces into a compound selector (button.primary[disabled]) to require all conditions on the same element. Separate selectors with commas to make a selector list that shares one declaration block.

Notes

  • An element can have many classes: class="btn btn-primary"
  • IDs must be unique per page; #id also has very high specificity
  • Class and ID names are case-sensitive; HTML type selectors are not
  • Names can't start with a digit unless escaped: .\31 0col

♿ Accessibility

  • Select by semantic element or ARIA state ([aria-expanded="true"]) so styles follow real meaning
  • Avoid styling divs to look like buttons; style the button

Browser Support

  • All basic selectors: universal

Code Explained

.note: any element with class note
button.primary: a <button> that also has class primary
.btn.btn--large: both classes on one element
Commas make a list; each item is matched independently
A space between .primary and button means descendant, not compound

Simple and Compound

/* type */
p        { line-height: 1.6; }

/* class */
.note    { background: #fff8e1; }

/* id: unique, heavy */
#site-header { position: sticky; }

/* universal */
* { box-sizing: border-box; }

/* compound: all on the same element */
button.primary        { background: navy; }
a.external[target]    { padding-right: 1em; }
.btn.btn--large       { font-size: 1.25rem; }

/* selector list: shared block */
h1, h2, h3 {
  font-family: Georgia, serif;
  line-height: 1.2;
}

/* type must come first in a compound */
.primary button  { }   /* descendant! not same */

Naming Rules

RuleExample
Case-sensitive.Card ≠ .card
Hyphens, underscores OK.card__title--big
No leading digit.3col invalid; escape it
Escape specials.md\:flex for md:flex
Unicode allowed.café

⚠ Common Mistakes

  • Adding a space in button .primary: that selects .primary inside a button
  • Reusing an ID on several elements: CSS still matches all, but JS and anchors break
  • Styling by ID and then needing another ID to override

✓ Tips & Best Practices

  • Use classes for styling, element selectors for base typography
  • Keep compound selectors short; two parts is usually enough
  • Group shared styles with selector lists instead of repeating blocks

Quick Summary

  • p · .class · #id · *
  • No space = same element
  • Comma = list
  • Classes are case-sensitive
