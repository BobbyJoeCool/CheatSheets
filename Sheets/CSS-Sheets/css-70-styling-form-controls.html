Sheet 70

Styling Form Controls

appearance: none · accent-color · ::placeholder · ::file-selector-button · field-sizing · custom checkboxes · :user-invalid styling

Making Native Controls Fit

Form controls are rendered partly by the OS, so styling them takes a few specific tools. accent-color recolors checkboxes, radios, range sliders and progress bars in one line. For full control, appearance: none removes native styling from the real input, which you then rebuild with borders, backgrounds and :checked states, keeping it accessible. field-sizing: content lets inputs and textareas grow with what's typed.

Notes

  • Always style the native element; hidden inputs + fake divs lose keyboard and screen-reader support
  • Set font: inherit on controls (they don't inherit by default)
  • ::file-selector-button styles the button inside <input type="file">
  • Customizable <select> (appearance: base-select) is arriving; plain select styling is limited

♿ Accessibility

  • Every control needs a visible label, a 3:1 border contrast against the background (WCAG 1.4.11) and a focus style
  • Show errors with text and an icon, not only a red border

Browser Support

  • accent-color, appearance, ::placeholder, ::file-selector-button: Baseline
  • field-sizing: Chromium only so far; appearance: base-select: newer, Chromium first

Code Explained

accent-color themes native checkboxes and radios
#767676 is the lightest gray with 4.5:1 on white
field-sizing: content grows the textarea as text is typed
appearance: none keeps the real checkbox, focusable and announced
::before draws the check mark; :checked reveals it

Controls Styled Accessibly

input, select, textarea, button { font: inherit; }

form { accent-color: #5b4bc4; }        /* quick theming */

.input {
  border: 1px solid #767676;           /* 4.5:1 on white */
  border-radius: 6px;
  padding: .5rem .75rem;
}
.input:focus-visible { outline: 3px solid #5b4bc4; }
.input:user-invalid  { border-color: #c62828; }
.input::placeholder  { color: #6b6b6b; }

textarea { field-sizing: content; min-block-size: 3lh; }

/* custom checkbox on the real input */
.check {
  appearance: none;
  width: 1.25rem; height: 1.25rem;
  border: 2px solid currentColor;
  border-radius: 4px;
  display: inline-grid; place-content: center;
}
.check::before {
  content: ""; width: .7rem; height: .7rem;
  clip-path: polygon(14% 44%, 0 65%, 50% 100%,
                     100% 16%, 80% 0, 43% 62%);
  background: currentColor; scale: 0;
}
.check:checked::before { scale: 1; }
.check:focus-visible   { outline: 2px solid #5b4bc4;
                         outline-offset: 2px; }

input[type=file]::file-selector-button {
  border: 0; padding: .5rem 1rem; border-radius: 6px;
}

⚠ Common Mistakes

  • Hiding the real checkbox and styling a <span>: not focusable or announced
  • Light-gray borders (#ddd) that fail 3:1 non-text contrast
  • Placeholders used as labels; they disappear on typing

✓ Tips & Best Practices

  • Start with accent-color; go custom only when needed
  • Keep custom controls as real inputs with appearance: none
  • Test controls in forced-colors mode

Quick Summary
