Borders & Outlines

border shorthand · border-style · border-radius · outline · outline-offset · border-image

Edges and Rings

A border sits between padding and margin and takes space. Its shorthand border: 2px solid red sets width, style and color; nothing shows unless the style is set. border-radius rounds corners and also clips backgrounds. An outline is drawn outside the border, takes no space, and is what browsers use for focus rings; outline-offset moves it away from the edge.

Notes

  • Default border color is currentColor; default width is medium (3px)
  • border-radius: 50% on a square makes a circle; 999px makes a pill
  • Elliptical corners: border-radius: 50% / 20%
  • Outlines now follow border-radius in all major browsers

♿ Accessibility

  • Never outline: none without a visible replacement on :focus-visible
  • If a focus style uses box-shadow, add outline: 2px solid transparent so forced-colors mode still shows a ring

Browser Support

  • Borders, radius, outline: universal
  • Outline following border-radius: Baseline 2023

Code Explained

Shorthand order doesn't matter, but style is required
Radius values go clockwise from top-left
999px radius = fully rounded ends at any height
outline-offset adds a gap without shifting layout
border-image … 1 slices the gradient as a border (no radius support)

Borders, Radius, Outlines

.card {
  border: 1px solid #ddd;          /* width style color */
  border-radius: 12px;
}

.alert {
  border-left: 4px solid #f57c00;  /* one side */
  border-radius: 0 8px 8px 0;      /* TL TR BR BL */
}

.pill   { border-radius: 999px; }
.circle { border-radius: 50%; aspect-ratio: 1; }
.blob   { border-radius: 40% 60% 70% 30% /
                         40% 50% 60% 50%; }

/* styles */
.dashed { border: 2px dashed currentColor; }
.double { border: 4px double #555; }

/* focus ring that takes no space */
:focus-visible {
  outline: 3px solid #ff9800;
  outline-offset: 3px;
}

/* gradient border */
.fancy {
  border: 4px solid;
  border-image: linear-gradient(90deg, #5b4bc4, #00bcd4) 1;
}

⚠ Common Mistakes

  • border: 2px red with no style: nothing renders
  • Adding a border on hover and shifting layout; use outline, box-shadow or a transparent border by default
  • Expecting border-image to respect border-radius

✓ Tips & Best Practices

  • Reserve space with border: 2px solid transparent, then color it on hover
  • Use outline for focus, never remove it without a replacement
  • Combine border-radius with overflow: clip to round child media

Quick Summary

  • border: width style color
  • border-radius clockwise from TL
  • outline takes no space
  • outline-offset for focus rings
