Sheet 22

Math Functions

calc() · min() · max() · clamp() · fluid type · round() · mod() · abs()

Computing Values

calc() does arithmetic with mixed units (100% - 2rem). min() and max() pick the smaller or larger of several values, and clamp(MIN, PREFERRED, MAX) keeps a fluid value between limits. That's the basis of fluid typography and spacing without media queries. Newer stepped functions (round(), mod(), rem()) and sign functions (abs(), sign()) round out the set.

Notes

  • + and - need spaces around them: calc(100% - 1rem)
  • Math functions nest and accept var(): calc(var(--gap) * 2)
  • min() acts as a maximum size limit, max() as a minimum, which trips everyone up
  • Trig functions (sin(), cos(), atan2()) also exist, for circular layouts

♿ Accessibility

  • Fluid type formulas must include a rem term so text still scales with zoom (WCAG 1.4.4)

Browser Support

  • calc(): universal; min(), max(), clamp(): Baseline 2020
  • round(), mod(), rem(), trig functions: Baseline 2023–2024
  • abs(), sign(): newer and less widely supported; check first

Code Explained

calc() mixes % and rem at layout time
min(100% - 2rem, 70rem): a centered column with side gutters
max(44px, …): never smaller than a touch target
clamp(): min, preferred (fluid), max
round(up, value, 8px) rounds to the next multiple of 8px

calc, min, max, clamp

.sidebar-layout {
  width: calc(100% - 2 * var(--gutter));
}

/* responsive width without media queries */
.container {
  width: min(100% - 2rem, 70rem);  /* ≤ 70rem */
}

/* at least 44px tall, more if needed */
.tap { min-height: max(44px, 2.75rem); }

/* fluid type: 1.25rem → 2rem between widths */
h2 {
  font-size: clamp(1.25rem, 0.9rem + 1.5vw, 2rem);
}

/* fluid spacing */
.section {
  padding-block: clamp(2rem, 6vw, 6rem);
}

/* snap to an 8px grid */
.box { height: round(up, 100% / 3, 8px); }

/* 0 or 1 from an index variable */
.item { --odd: mod(var(--i), 2); }

/* full-bleed inside a centered column */
.bleed {
  margin-inline: calc(50% - 50vw);
}

Fluid Type Recipe

StepValue
Min size1.25rem at 20rem viewport
Max size2rem at 80rem viewport
Slope(2 − 1.25) / (80 − 20) = 0.0125 → 1.25vw
Intercept1.25 − 20 × 0.0125 = 1rem
Resultclamp(1.25rem, 1rem + 1.25vw, 2rem)

⚠ Common Mistakes

  • calc(100%-1rem) without spaces: invalid, because -1rem parses as a negative number
  • Using min() to set a minimum: min() picks the smaller value, so it caps
  • Fluid type with only vw: no zoom scaling

✓ Tips & Best Practices

  • Generate fluid clamp() values with utopia.fyi
  • Use min(100% - gutter, max) instead of width + max-width + padding
  • Store results in custom properties to reuse them

Quick Summary

  • calc() mixes units
  • min() caps, max() floors
  • clamp(min, fluid, max)
  • Spaces around + and -
