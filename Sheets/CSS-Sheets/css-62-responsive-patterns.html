Responsive Patterns

intrinsic layouts · fluid type · responsive media · max-width: 100% · viewport meta · layout shifts

Responsive Without Breakpoints

Modern responsive CSS leans on intrinsic techniques that adapt continuously instead of jumping at breakpoints: clamp() for fluid type and spacing, min() for widths, auto-fit grids and wrapping flex rows, and container queries for components. Media need max-width: 100% and reserved dimensions so they never overflow or cause layout shift. Breakpoints remain for big structural changes.

Notes

  • The viewport meta tag is required for any of this to work on phones
  • Reserve space for images with width/height attributes or aspect-ratio
  • A fluid type scale: each step is a clamp() between a min and max size
  • Every-Layout primitives (stack, cluster, sidebar, switcher) solve layouts without queries

♿ Accessibility

  • Test at 200% and 400% zoom; content should reflow without loss (WCAG 1.4.4, 1.4.10)
  • Don't disable zoom with user-scalable=no or maximum-scale=1

Browser Support

  • Every technique on this sheet: Baseline Widely available (container queries: 2023)

Code Explained

Fluid steps scale smoothly between minimum and maximum
min(70rem, 100% - …) replaces width + max-width + padding
Switcher: basis flips from huge negative to huge positive at 40rem
Sidebar: content keeps at least 60%, sidebar wraps below otherwise
aspect-ratio sizes video embeds without padding hacks

Intrinsic Toolkit

/* <meta name="viewport"
         content="width=device-width, initial-scale=1"> */

/* fluid type scale */
:root {
  --step-0: clamp(1rem, .95rem + .25vw, 1.125rem);
  --step-2: clamp(1.5rem, 1.2rem + 1.5vw, 2.25rem);
  --space:  clamp(1rem, 3vw, 2rem);
}

/* media never overflow */
img, video, iframe { max-width: 100%; height: auto; }

/* centered column with gutters */
.wrap { width: min(70rem, 100% - 2 * var(--space));
        margin-inline: auto; }

/* switcher: row until too narrow, then column */
.switcher { display: flex; flex-wrap: wrap; gap: 1rem; }
.switcher > * {
  flex-grow: 1;
  flex-basis: calc((40rem - 100%) * 999);
}

/* sidebar: sidebar wraps under content when tight */
.sidebar-l { display: flex; flex-wrap: wrap; gap: 1rem; }
.sidebar-l > :first-child { flex: 1 1 16rem; }
.sidebar-l > :last-child  { flex-basis: 0; flex-grow: 999;
                            min-inline-size: 60%; }

/* responsive embeds */
.embed { aspect-ratio: 16 / 9; width: 100%; }

⚠ Common Mistakes

  • Hard-coding widths in px that overflow small screens
  • Images without dimensions causing content to jump on load (CLS)
  • Disabling pinch-zoom in the viewport meta tag

✓ Tips & Best Practices

  • Start with intrinsic layouts; add breakpoints only where needed
  • Generate type and space scales with utopia.fyi
  • Keep one fluid --space token for gutters

Quick Summary

  • clamp() fluid type and space
  • min() widths
  • Media: max-width: 100% + aspect
  • Breakpoints for structure only
