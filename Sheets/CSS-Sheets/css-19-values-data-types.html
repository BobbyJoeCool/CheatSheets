Sheet 19

Values & Data Types

<length> · <percentage> · <number> · <string> · url() · keywords · specified/computed/used values

What a Value Can Be

Every property accepts specific data types, written in specs as <length>, <color>, <percentage> and so on. A value is built from keywords (auto, none), numbers with or without units, strings, and functions like url(), calc() or rgb(). On its way to the screen each value passes through stages: specified (from the cascade), computed (relative units resolved where possible), used (layout done) and actual (rounded to device pixels).

Notes

  • 0 is the only length that may drop its unit
  • Percentages resolve against something different per property (width of parent, font-size, own size…)
  • Strings use single or double quotes; keywords never take quotes
  • getComputedStyle() returns the resolved value, usually the used value for sizes

♿ Accessibility

  • Prefer relative units (rem, em) for text so user font-size settings scale it

Browser Support

  • All core data types: universal
  • Typed attr() (attr(data-x type(<length>))): newer, Chromium first

Code Explained

line-height: 1.5 (unitless) inherits as a ratio, unlike 1.5em
rebeccapurple is one of 148 named colors
Font family names with spaces are quoted strings; generic families aren't
16 / 9 is a ratio; spaces around / are optional
Computed values are what children inherit

Value Types

.box {
  width: 50%;                     /* <percentage> */
  max-width: 40rem;               /* <length> */
  line-height: 1.5;               /* <number>, unitless */
  z-index: 10;                    /* <integer> */
  opacity: 0.8;                   /* <alpha-value> */
  color: rebeccapurple;           /* <color> keyword */
  font-family: "Inter", sans-serif; /* <string>, keyword */
  background: url("bg.webp");     /* <url> */
  rotate: 15deg;                  /* <angle> */
  transition: opacity 200ms;      /* <time> */
  aspect-ratio: 16 / 9;           /* <ratio> */
  grid-template-columns: 1fr 2fr; /* <flex> */
  margin: 0;                      /* unitless zero */
  display: none;                  /* keyword */
}

/* value stages for font-size: 1.5em
   specified: 1.5em
   computed:  24px  (parent 16px)
   used:      24px
   actual:    24px  (rounded on device) */

⚠ Common Mistakes

  • Writing margin-top: 10% expecting a share of the height: vertical margins use the width
  • Quoting keywords (display: "flex"): the declaration is invalid
  • Using line-height: 1.5em on a parent: children inherit a fixed length, not a ratio

✓ Tips & Best Practices

  • Use unitless line-height
  • Check the Computed tab in DevTools to see resolved values
  • Learn what each property's percentage refers to before using %

Quick Summary

  • Keywords, numbers, strings, functions
  • 0 needs no unit
  • specified → computed → used → actual
  • % basis varies by property
