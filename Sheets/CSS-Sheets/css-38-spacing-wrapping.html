Sheet 38

Spacing & Wrapping

line-height · letter-spacing · word-spacing · white-space · overflow-wrap · word-break · hyphens · text-wrap

Line Height and Line Breaks

line-height sets the height of each line box; use a unitless number (1.4–1.6 for body text) so it scales with font size and inherits as a ratio. letter-spacing and word-spacing adjust tracking. Wrapping is controlled by white-space (whether spaces collapse and lines wrap), overflow-wrap (break long words only when they'd overflow), word-break, hyphens, and text-wrap, which can balance headings or make paragraphs pretty.

Notes

  • hyphens: auto needs a lang attribute to pick the dictionary
  • white-space: pre-wrap keeps spaces and newlines but still wraps
  • text-wrap: balance is limited to short blocks (a few lines) for performance
  • overflow-wrap: anywhere also lets min-content shrink, break-word doesn't

♿ Accessibility

  • WCAG 1.4.12: layouts must survive line-height 1.5, letter-spacing .12em, word-spacing .16em and paragraph spacing 2em
  • Avoid tight line-height below 1.2 for body text

Browser Support

  • line-height, spacing, white-space, overflow-wrap, word-break: universal
  • hyphens: auto: Baseline 2023; text-wrap: balance: Baseline 2024
  • text-wrap: pretty: not yet in every engine; it's safe to add as enhancement

Code Explained

Unitless line-height inherits as a multiplier
balance evens out line lengths in short text
pretty avoids a single word on the last line
overflow-wrap: break-word breaks only words that would overflow
word-break: break-all breaks anywhere, even in normal words

Readable Lines

body {
  line-height: 1.55;          /* unitless */
}
h1, h2, h3 {
  line-height: 1.15;
  text-wrap: balance;         /* even heading lines */
}
p { text-wrap: pretty; }      /* avoid orphan words */

.caps    { letter-spacing: .08em; }
.tight   { letter-spacing: -.01em; } /* large headings */

/* long URLs and IDs */
.content { overflow-wrap: break-word; }
.hash    { word-break: break-all; }

/* hyphenation (needs lang="en" on html) */
article p {
  hyphens: auto;
  text-align: justify;
}

/* whitespace handling */
pre   { white-space: pre; }        /* keep all, no wrap */
.poem { white-space: pre-line; }   /* keep newlines */
.chip { white-space: nowrap; }     /* never wrap */
.log  { white-space: pre-wrap; }   /* keep + wrap */

⚠ Common Mistakes

  • line-height: 24px on the body: headings with bigger text overlap
  • Using word-break: break-all for URLs and breaking ordinary words mid-letter
  • hyphens: auto without a lang attribute: nothing happens

✓ Tips & Best Practices

  • Set line-height unitless on body; tighten it for large headings
  • Add overflow-wrap: break-word to user-generated content
  • Use text-wrap: balance on headings and pretty on paragraphs

Quick Summary

  • Unitless line-height ~1.5
  • white-space controls spaces + wrapping
  • overflow-wrap: break-word for long words
  • text-wrap: balance | pretty
