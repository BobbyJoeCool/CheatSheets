Sheet 15

Pseudo-Classes: Structural

:first-child · :last-child · :nth-child(An+B) · :nth-of-type · :only-child · :empty · :root · of S

Position in the Tree

Structural pseudo-classes match elements by where they sit among their siblings, with no extra classes. :nth-child(An+B) is the workhorse: it counts siblings from 1, so 2n is even, 2n+1 odd and -n+3 the first three. The -of-type variants count only siblings of the same element type, and :nth-child(An+B of S) counts only siblings that match a selector.

Notes

  • Counting is 1-based and includes all element siblings (not text nodes)
  • :nth-last-child() counts from the end
  • :empty matches elements with no children and no text, not even whitespace
  • :root is <html> in HTML documents but has class-level specificity (0,1,0)

♿ Accessibility

  • Zebra stripes with :nth-child(even) help scanning wide tables; keep contrast between stripes and text
  • Don't use position-based styling to convey meaning a screen reader won't announce

Browser Support

  • All structural pseudo-classes: universal
  • :nth-child(An+B of S): Baseline 2023

Code Explained

even = 2n, odd = 2n+1
-n + 3: n = 0, 1, 2 gives 3, 2, 1
p:first-of-type ignores earlier h2 or img siblings
of :not([hidden]) keeps stripes right when rows are filtered
Quantity query: the first item checks the total count from the end

Counting Siblings

li:first-child          { font-weight: bold; }
li:last-child           { border-bottom: none; }
li:only-child           { list-style: none; }

/* An+B */
tr:nth-child(even)      { background: #f6f6f6; }
tr:nth-child(2n + 1)    { }        /* odd */
li:nth-child(3n)        { }        /* 3, 6, 9… */
li:nth-child(-n + 3)    { }        /* first 3 */
li:nth-child(n + 4)     { }        /* 4 onward */
li:nth-last-child(2)    { }        /* 2nd from end */

/* of type: only <p> siblings counted */
article p:first-of-type { font-size: 1.2em; }
img:nth-of-type(2n)     { float: right; }

/* of S: count only visible rows */
tr:nth-child(even of :not([hidden])) {
  background: #f6f6f6;
}

/* quantity query: style when 4+ items */
li:first-child:nth-last-child(n + 4),
li:first-child:nth-last-child(n + 4) ~ li {
  flex-basis: 25%;
}

.alert:empty { display: none; }

An+B Cheats

ExpressionMatches
odd / 2n+11, 3, 5…
even / 2n2, 4, 6…
3Only the 3rd
3n3, 6, 9…
n+33rd onward
-n+3First three
3n+11, 4, 7…

Structural Selectors

SelectorMatches
:first-child / :last-childFirst / last sibling
:only-childHas no siblings
:nth-child(An+B)By position
:nth-last-child()By position from the end
:first-of-typeFirst of its element type
:only-of-typeOnly one of its type
:emptyNo children or text
:rootThe document root

⚠ Common Mistakes

  • p:first-child when an h2 comes first: nothing matches; use :first-of-type
  • Expecting :nth-of-type to count classes: it counts element types only
  • :empty failing because of a stray space or newline inside the element

✓ Tips & Best Practices

  • Use :nth-child(… of …) instead of re-indexing classes after filtering
  • Prefer li + li over li:not(:first-child) for in-between borders
  • Hide empty alert or badge containers with :empty

Quick Summary

  • :nth-child(An+B) 1-based
  • -of-type counts same tag only
  • of S counts matches only
  • :empty = nothing, not even spaces
