Grid: Alignment & Subgrid

justify-items · align-items · place-items · justify-self · place-content · subgrid

Aligning Items and Sharing Tracks

Grid alignment has two axes: justify-* works along the inline axis (row direction) and align-* along the block axis. *-items aligns every item inside its cell, *-self overrides one item, and *-content moves the whole grid within the container when the tracks are smaller than it. subgrid lets a nested grid reuse its parent's tracks, so headings, text and buttons line up across sibling cards.

Notes

  • place-items: center = align-items: center; justify-items: center
  • Default stretch fills the cell (unless the item has a fixed size or aspect-ratio)
  • A subgrid item must span the parent tracks it inherits (grid-row: span 3)
  • Subgrid inherits the parent's gaps unless it sets its own

♿ Accessibility

  • Subgrid aligns visually without changing DOM order, so card content stays readable in sequence

Browser Support

  • Grid alignment properties: Baseline Widely available
  • subgrid: Baseline 2023

Code Explained

justify-content centers the 30rem grid inside a wider container
align-items: start stops items stretching to the row height
place-items: center is the shortest centering
grid-row: span 3 + subgrid makes card sections align across siblings
Column subgrid aligns every label/input pair

Alignment and Subgrid

.grid {
  display: grid;
  grid-template-columns: repeat(3, 10rem);
  justify-content: center;   /* whole grid in container */
  align-items: start;        /* items at top of cells */
  justify-items: center;     /* items centered in cells */
}
.grid .special { align-self: end; justify-self: stretch; }

/* center one thing, the shortest way */
.center { display: grid; place-items: center; }

/* cards whose parts line up across a row */
.cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fill, minmax(16rem, 1fr));
  gap: 1rem;
}
.card {
  display: grid;
  grid-row: span 3;                /* title, body, button */
  grid-template-rows: subgrid;     /* share parent rows */
  gap: .5rem;
}

/* form: labels and inputs aligned across rows */
.form { display: grid; grid-template-columns: auto 1fr; }
.form .field {
  grid-column: span 2;
  display: grid;
  grid-template-columns: subgrid;
}

Which Property?

PropertyMoves
justify-itemsAll items, inline axis
align-itemsAll items, block axis
place-itemsBoth (align / justify)
justify-self / align-selfOne item
justify-contentWhole grid, inline axis
align-contentWhole grid, block axis
place-contentBoth

Alignment Values

ValueResult
stretchFill the cell (default)
start / endCell start / end
centerCentered in cell
baselineAlign text baselines
space-between / -around / -evenly*-content only

⚠ Common Mistakes

  • Using justify-content to center items in their cells (that's justify-items)
  • Forgetting the span on a subgrid item, so it inherits only one track
  • Expecting stretch on images with fixed width

✓ Tips & Best Practices

  • display: grid; place-items: center for any centering job
  • Use subgrid for card grids with aligned titles and buttons
  • Remember: *-items inside cells, *-content moves the tracks

Quick Summary

  • justify = inline, align = block
  • items / self / content
  • place-items: center
  • grid-template-rows: subgrid
