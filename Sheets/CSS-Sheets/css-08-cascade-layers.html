Sheet 08

Cascade Layers

@layer · layer order · anonymous layers · nested layers · @import layer() · unlayered styles · !important reversal

Priority by Intent

Cascade layers let you group styles and decide which group wins before specificity is compared. Declare the order once (@layer reset, base, components, utilities;) and later layers beat earlier ones no matter how specific their selectors are. Unlayered styles beat every layer. For !important declarations the order reverses, so an early layer like reset can protect critical rules.

Notes

  • Order is fixed the first time a layer name appears; put the order statement first
  • Adding rules to a layer later (@layer base { … }) keeps its original position
  • Nested layers: @layer framework.base, ordered within their parent
  • Anonymous @layer { … } blocks can't be added to later

♿ Accessibility

  • Put user-protective rules (focus rings, reduced motion) in a late layer or unlayered so components can't override them by accident

Browser Support

  • @layer, revert-layer, @import layer(): Baseline 2022
  • Older browsers ignore layered rules entirely; test any fallback path

Code Explained

The first @layer statement fixes priority: utilities > components > base > reset
.btn (0,1,0) beats #content a (1,0,1) because its layer is later
@import … layer(reset): library code can't beat your own layers
Unlayered .legacy-banner a wins over all layers
components.card: a sub-layer, ordered inside components

Layering a Site

/* 1. declare order: last wins */
@layer reset, base, components, utilities;

/* 2. third-party CSS into a low layer */
@import url("normalize.css") layer(reset);

@layer base {
  a { color: #5b4bc4; }
  #content a { color: navy; }   /* (1,0,1) */
}

@layer components {
  .btn { color: white; }        /* beats #content a */
}

@layer utilities {
  .text-red { color: red; }     /* beats .btn */
}

/* unlayered: beats every layer */
.legacy-banner a { color: black; }

/* nested layers */
@layer components {
  @layer card, modal;            /* components.card */
}
@layer components.card {
  .card { padding: 1rem; }
}

⚠ Common Mistakes

  • Forgetting the order statement: layers rank by first appearance, which can shift as files load
  • Leaving framework CSS unlayered: it beats all your layered code
  • Using !important in a late layer expecting it to win: important order is reversed

✓ Tips & Best Practices

  • Declare the full order in the first stylesheet that loads
  • Import third-party CSS into the lowest layer
  • Typical stack: reset, base, layout, components, utilities

Quick Summary

  • @layer a, b;: b beats a
  • Unlayered beats layered
  • !important reverses layer order
  • Layer check happens before specificity
