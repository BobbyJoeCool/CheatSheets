Sheet 31

Logical Properties

inline vs block axis · margin-inline · padding-block · inset-inline · inline-size · writing-mode · direction

Flow-Relative Directions

Logical properties describe sides by text flow instead of screen direction. The inline axis runs along a line of text (left→right in English, right→left in Arabic), and the block axis is the direction lines stack (top→bottom). margin-inline-start is the left margin in English and the right margin in Hebrew, with no extra CSS. They also adapt to vertical writing modes.

Notes

  • inline-size / block-size replace width / height
  • Shorthands: margin-inline: 1rem 2rem = start, end
  • inset-inline-start replaces left for positioning
  • Logical values exist too: text-align: start, float: inline-start

♿ Accessibility

  • Logical properties keep layouts correct for right-to-left readers without a separate stylesheet
  • Set dir in the HTML (<html dir="rtl">); CSS direction alone doesn't change semantics

Browser Support

  • Logical margin/padding/inset/size/border: Baseline 2021
  • Logical border-radius: Baseline 2021; float: inline-start: Baseline 2023

Code Explained

inline-start = left in LTR, right in RTL
text-align: start follows dir automatically
margin-block: a b = block-start, block-end
inline-size = width in horizontal writing modes
In vertical-rl, inline runs top to bottom and blocks stack right to left

Physical vs Logical

/* physical: breaks in RTL */
.card {
  margin-left: 1rem;
  padding-right: 2rem;
  border-left: 4px solid;
  text-align: left;
}

/* logical: works in any direction */
.card {
  margin-inline-start: 1rem;
  padding-inline-end: 2rem;
  border-inline-start: 4px solid;
  text-align: start;
}

/* shorthands */
.box {
  margin-block: 2rem 1rem;      /* top, bottom */
  padding-inline: 1.5rem;       /* left + right */
  inline-size: min(100%, 40rem);
  max-block-size: 80vh;
  inset-inline-end: 0;          /* right in LTR */
  border-start-end-radius: 8px; /* top-right in LTR */
}

/* vertical text */
.vertical {
  writing-mode: vertical-rl;    /* inline = top→bottom */
}

⚠ Common Mistakes

  • Mixing physical and logical for the same side: both apply and order decides
  • Using direction: rtl in CSS instead of the dir attribute
  • Assuming inline-size is always width (it's height in vertical modes)

✓ Tips & Best Practices

  • Write new CSS logically by default; it costs nothing in LTR-only sites
  • Use margin-inline: auto to center
  • Test RTL by setting dir="rtl" on <html> in DevTools

Quick Summary

  • inline = along text; block = across lines
  • *-inline-start / *-block-end
  • inline-size / block-size
  • Direction comes from dir
