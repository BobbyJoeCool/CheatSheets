Print Styles

@media print · @page · size · page margins · break-before · break-inside · orphans/widows · print-color-adjust

Designing for Paper

@media print rules apply when printing or saving as PDF. Typical print CSS hides navigation and buttons, switches to dark text on white, shows link URLs, and controls page breaks with break-before, break-after and break-inside. The @page rule sets the paper size and page margins. Browsers drop background colors and images by default to save ink; print-color-adjust: exact keeps them where they matter.

Notes

  • orphans / widows set the minimum lines left at the bottom / top of a page
  • break-inside: avoid keeps figures, tables rows and cards on one page
  • Absolute units (pt, cm, in) behave predictably on paper
  • Fixed and sticky elements may repeat on every page; set them to static

♿ Accessibility

  • Print styles help people who read on paper; keep headings and link text meaningful when printed
  • Show URLs after links so printed references are usable

Browser Support

  • @media print, break-*, @page { margin }: universal
  • @page { size }: Chromium and Firefox; Safari support is newer
  • print-color-adjust: write both prefixed and unprefixed; orphans/widows: not in Firefox

Code Explained

@page sets paper size and printable margins
Hide anything interactive or decorative
attr(href) prints the link destination
break-after: avoid keeps a heading with its next paragraph

A Print Stylesheet

@page {
  size: letter portrait;    /* or A4, 8.5in 11in */
  margin: 0.5in 0.6in;
}

@media print {
  nav, .ads, .btn, video { display: none !important; }

  body {
    font: 11pt/1.4 Georgia, serif;
    color: #000;
    background: #fff;
  }

  a[href^="http"]::after {
    content: " (" attr(href) ")";
    font-size: 9pt;
  }

  h1, h2, h3 { break-after: avoid; }   /* stay with text */
  figure, table, .card { break-inside: avoid; }
  .chapter { break-before: page; }
  p { orphans: 3; widows: 3; }

  .header { position: static; }       /* not on each page */

  .chart, .badge {
    -webkit-print-color-adjust: exact;
    print-color-adjust: exact;        /* keep colors */
  }
}

⚠ Common Mistakes

  • Leaving dark-mode backgrounds that the browser strips, leaving light text on white
  • Absolute layouts and fixed heights that cut content across pages
  • Using page-break-* only; prefer the modern break-* names (legacy ones still work)

✓ Tips & Best Practices

  • Preview with DevTools → Rendering → Emulate CSS media type: print
  • Set print colors explicitly; don't inherit screen themes
  • Test with Save as PDF in each browser you care about
