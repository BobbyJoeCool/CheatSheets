String Conversions

std::to_string · std::stoi / stod · std::from_chars · std::to_chars · std::stringstream · std::format

Numbers ↔ Text

C++ offers three generations of conversion. std::to_string / std::stoi are simple but allocate, and stoi throws on bad input. std::stringstream handles mixed parsing with stream syntax. std::from_chars / std::to_chars (C++17, <charconv>) are the fastest: no allocation, no locale, no exceptions; they report errors through a result struct. std::format is the easiest way to produce text.

Choosing

  • Quick script code: std::stoi, std::to_string
  • Hot paths / parsers: std::from_chars, std::to_chars
  • Formatting: std::format("{:.2f}", x)
  • to_string(double) always prints 6 decimals: "3.140000"

Conversion Examples

#include <charconv>
#include <sstream>
#include <string>

std::to_string(42);                // "42"
std::to_string(3.14);              // "3.140000"
std::format("{}", 3.14);           // "3.14"

std::stoi("123");                  // 123
std::stoi("12abc");                // 12 (stops at 'a')
std::stoi("abc");                  // throws std::invalid_argument

std::string_view in = "8080";
int port{};
auto [ptr, ec] = std::from_chars(in.data(), in.data() + in.size(), port);
if (ec == std::errc{}) {}          // success, port == 8080
std::istringstream iss("7 2.5 abc");
int i; double d; std::string w;
iss >> i >> d >> w;                // 7, 2.5, "abc"

Code Explained

stoi — parses a prefix; throws on no digits or overflow
stoi(s, nullptr, 16) — optional base argument
from_chars — returns {ptr, errc}; check ec == std::errc{}
std::format("{}", x) — shortest round-trip text for numbers
istringstream — tokenize mixed-type text with >>

⚠ Common Mistakes

  • Assuming std::stoi("12abc") fails; it returns 12. Use the pos out-param or from_chars and check ptr == end
  • Calling stoi on user input without try/catch
  • Using std::atoi; it can't report errors and has UB on overflow

✓ Tips & Best Practices

  • Wrap from_chars in a helper returning std::optional<int>
  • Prefer std::format over to_string for floats to avoid trailing zeros
  • Reuse one std::ostringstream with .str("") instead of creating one per value

Quick Summary

  • std::to_string / std::stoi — simple, allocating, throwing
  • std::from_chars / to_chars — fast, no-throw
  • std::istringstream — parse mixed tokens
  • std::format — best way to produce text
