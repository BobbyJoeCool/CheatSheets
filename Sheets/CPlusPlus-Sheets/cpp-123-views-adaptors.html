Range Views & Adaptors

views::filter · views::transform · views::take / drop · | pipes · std::ranges::to · views::zip · views::chunk

Lazy Pipelines

Range adaptors in std::views build lazy views that transform, filter, slice, or combine ranges without copying. Compose them with the pipe operator | to form readable pipelines; nothing runs until you iterate. C++23 added views::zip, enumerate, chunk, slide, join_with, and std::ranges::to, which materializes a view into a real container.

Notes

  • Views evaluate on demand, element by element
  • views::iota(a) is infinite; bound it with take
  • Views reference the source: keep it alive while iterating
  • std::ranges::to<std::vector>() builds a container (C++23)

Pipelines

#include <ranges>
namespace vw = std::views;

std::vector<int> nums{1, 2, 3, 4, 5, 6, 7, 8};
auto evensSquared = nums
    | vw::filter([](int x) { return x % 2 == 0; })
    | vw::transform([](int x) { return x * x; });    // lazy: 4 16 36 64
for (int x : evensSquared) std::print("{} ", x);

auto firstFive = vw::iota(1) | vw::take(5);          // 1 2 3 4 5
auto v = nums | vw::drop(2) | vw::reverse
              | std::ranges::to<std::vector>();      // 8 7 6 5 4 3
std::vector<std::string> names{"Ada", "Bo"};
for (auto [n, a] : vw::zip(names, std::vector{36, 31}))   // C++23
    std::println("{} {}", n, a);
for (auto ch : nums | vw::chunk(3)) {}               // [1 2 3] [4 5 6] [7 8]
auto csv = names | vw::join_with(',')
                 | std::ranges::to<std::string>();   // "Ada,Bo"

Code Explained

| — feeds a range into an adaptor
filter then transform — nothing computed until the loop
iota(1) | take(5) — bounded infinite sequence
ranges::to<std::vector>() — materialize into a container
zip — iterate two ranges in lockstep
chunk(3) / join_with(',') — group and flatten

⚠ Common Mistakes

  • Returning a view over a local container from a function; it dangles
  • Modifying the underlying container while a view (especially filter) is in use
  • Expecting a view to store results; it recomputes them each pass. Materialize with ranges::to when needed

✓ Tips & Best Practices

  • Alias the namespace (namespace vw = std::views;) to keep pipelines short
  • Put each adaptor on its own line for readability
  • Check library support for C++23 views (zip, chunk, to): GCC 13–14+, Clang/libc++ 17+, MSVC 17.4+
