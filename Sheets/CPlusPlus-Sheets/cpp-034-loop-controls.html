Loop Controls & goto

break · continue · goto · labels · breaking nested loops · early return

Changing Loop Flow

break exits the innermost loop (or switch) immediately. continue skips the rest of the current iteration and goes to the next one; in a for loop, the increment still runs. C++ has no labeled break, so leaving nested loops takes a flag, a return from a helper function or lambda, or a goto. goto is legal but rarely the clearest choice.

Notes

  • break / continue affect only the innermost loop
  • break inside a switch inside a loop leaves the switch, not the loop
  • return exits the whole function, ending all loops
  • goto can't jump forward past variable initializations

break, continue, goto

for (int x : data) {
    if (x < 0) continue;              // skip negatives
    if (x == 0) break;                // stop at first zero
    sum += x;
}

// Find in a 2D grid: return from a lambda to exit both loops
auto find = [&](int target) -> std::optional<std::pair<int,int>> {
    for (int r = 0; r < rows; ++r)
        for (int c = 0; c < cols; ++c)
            if (grid[r][c] == target) return std::pair{r, c};
    return std::nullopt;
};

for (int i = 0; i < n; ++i) {         // goto version
    for (int j = 0; j < m; ++j)
        if (bad(i, j)) goto done;
}
done:
    cleanup();

Code Explained

continue — jump to the next iteration
break — leave the innermost loop
returning from a lambda — clean exit from nested loops
std::optional — signals "not found" without sentinels
goto done; — jumps to a label in the same function

Statements

StatementEffect

⚠ Common Mistakes

  • Expecting break inside a switch to exit the enclosing loop; it only leaves the switch
  • Using continue in a while loop before the counter update, causing an infinite loop
  • Using exceptions to leave loops for normal control flow; they're slow and obscure intent

✓ Tips & Best Practices

  • Turn the nested loop into a function that returns the result, then return early
  • Use algorithms like std::ranges::find_if to remove many manual break loops
  • Keep continue guard clauses at the top of the loop body for readability

Quick Summary

  • break — exit innermost loop
  • continue — skip to next iteration
  • nested exit — return from a function or lambda
  • goto — allowed, rarely the best option
