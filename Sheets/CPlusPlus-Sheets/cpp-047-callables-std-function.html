Callables & std::function

function pointers · std::function · std::move_only_function · std::invoke · std::bind_front · member function pointers

Things You Can Call

A callable is anything you can invoke with (): free functions, function pointers, lambdas, objects with operator(), and member function pointers. std::function<R(Args...)> is a type-erased wrapper that can hold any copyable callable with a matching signature, at the cost of a possible heap allocation and an indirect call. std::invoke calls any callable uniformly, including member pointers.

Choosing a Type

  • Template parameter (auto f / F&&) — fastest, inlinable
  • std::function — store heterogeneous callbacks
  • std::move_only_function (C++23) — for move-only lambdas
  • std::function_ref (C++26) — non-owning, no allocation

Callables

int add(int a, int b) { return a + b; }

int (*fp)(int, int) = &add;           // function pointer
fp(2, 3);                             // 5

std::function<int(int, int)> op = add;
op = [](int a, int b) { return a * b; };
op(2, 3);                             // 6

struct Account { double balance() const { return 42; } };
double (Account::*mp)() const = &Account::balance;  // member fn pointer
Account acct;
(acct.*mp)();                         // 42
std::invoke(&Account::balance, acct); // 42, uniform syntax

auto addTen = std::bind_front(add, 10);
addTen(5);                            // 15

Code Explained

int (*fp)(int, int) — pointer to a function taking two ints
std::function — holds any matching callable; check emptiness with if
.* — call a member function through a member pointer
std::invoke — works for functions, lambdas, and member pointers
std::bind_front — fix leading arguments (C++20)

⚠ Common Mistakes

  • Calling an empty std::function; it throws std::bad_function_call
  • Using std::function parameters in hot loops when a template parameter would allow inlining
  • Forgetting the parentheses in (obj.*mp)(); obj.*mp() parses differently

✓ Tips & Best Practices

  • Accept callables as auto&& f or a constrained template (std::invocable<int> auto f) in library code
  • Use std::bind_front or a lambda instead of the older std::bind
  • Store callbacks as std::move_only_function when they capture move-only state

Quick Summary

  • callable — anything invocable with ()
  • std::function<R(A...)> — type-erased callback holder
  • std::invoke — call any callable uniformly
  • std::bind_front — partial application
