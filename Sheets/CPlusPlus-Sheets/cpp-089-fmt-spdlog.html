{fmt} & spdlog

fmt::format · fmt::print · spdlog::info · log levels · sinks · patterns

Formatting & Logging Libraries

{fmt} is the library std::format and std::print were based on. It's still useful on older toolchains and has extras like colored output and compile-time format strings. spdlog is a fast, header-friendly logging library built on {fmt}: you log with format strings, choose sinks (console, rotating files), set levels, and customize the output pattern.

Setup

  • vcpkg: fmt, spdlog; link fmt::fmt, spdlog::spdlog
  • spdlog can use std::format instead (SPDLOG_USE_STD_FORMAT)
  • Levels: trace, debug, info, warn, error, critical, off
  • Default level is info

fmt & spdlog

#include <fmt/format.h>
#include <fmt/color.h>
#include <spdlog/spdlog.h>
#include <spdlog/sinks/rotating_file_sink.h>

fmt::print("{:>8.2f}\n", 3.14159);                      //     3.14
auto s = fmt::format("{} items", 3);                    // "3 items"
fmt::print(fg(fmt::color::red), "error: {}\n", msg);    // colored

spdlog::info("server listening on port {}", 8080);
spdlog::warn("disk {}% full", 91);
spdlog::set_level(spdlog::level::debug);
spdlog::debug("cache hit ratio {:.2f}", 0.93);
spdlog::set_pattern("[%Y-%m-%d %H:%M:%S.%e] [%^%l%$] %v");

auto file = spdlog::rotating_logger_mt("app", "logs/app.log",
                                       5 * 1024 * 1024, 3);  // 5 MB × 3
file->error("payment failed for order {}", orderId);

Code Explained

fmt::print — same mini-language as std::print
fg(fmt::color::red) — terminal colors
spdlog::info(...) — default console logger
set_level — hide messages below this level
set_pattern — timestamp, level (%l), message (%v)
rotating_logger_mt — thread-safe file sink with rotation

⚠ Common Mistakes

  • Building log messages with string concatenation before calling spdlog; pass format arguments so disabled levels cost nothing
  • Using _st (single-threaded) loggers from multiple threads; use _mt
  • Forgetting spdlog::shutdown() / flushing before exit with async loggers

✓ Tips & Best Practices

  • Use SPDLOG_DEBUG(...) macros with SPDLOG_ACTIVE_LEVEL to compile out debug logs in release
  • Call spdlog::flush_on(spdlog::level::err) so errors hit disk immediately
  • Prefer std::print in new code on C++23 toolchains; keep {fmt} for colors or older compilers

Quick Summary

  • fmt::format / fmt::print — the original {fmt}
  • spdlog::info(...) — format-string logging
  • levels + set_level — filter output
  • sinks + patterns — where and how logs appear
