Sheet 012

Floating-Point Types

float · double · long double · 1e-3 / f suffix · std::numeric_limits · NaN & inf · epsilon comparisons · <stdfloat>

Real Numbers

Floating-point types follow IEEE 754 on all mainstream platforms: float is 32-bit (~7 decimal digits), double is 64-bit (~15–16 digits), and long double is 80- or 128-bit on some platforms but just double on MSVC. Floating-point values are binary approximations, so 0.1 + 0.2 != 0.3. Special values NaN and infinity come from operations like 0.0/0.0 and 1.0/0.0.

Defaults

  • Unsuffixed literals like 3.14 are double
  • 3.14f is float; 3.14L is long double
  • C++23 <stdfloat>: std::float16_t, float32_t, float64_t, bfloat16_t (if supported)
  • NaN != NaN is always true

Literals, Limits & Special Values

#include <cmath>
#include <limits>

double d = 3.14;            // double
float  f = 2.5f;            // float
double e = 6.02e23;         // scientific
double h = 0x1.8p1;         // hex float: 3.0

0.1 + 0.2 == 0.3;                         // false
std::abs((0.1 + 0.2) - 0.3) < 1e-9;       // true
double inf = 1.0 / 0.0;                   // inf
double nan = std::sqrt(-1.0);             // nan
std::isnan(nan);                          // true
std::isinf(inf);                          // true
using lim = std::numeric_limits<double>;
lim::max();        // 1.79769e+308
lim::epsilon();    // 2.22045e-16
lim::infinity();   // inf
lim::quiet_NaN();  // nan

Code Explained

2.5f — without f it's a double narrowed to float
0x1.8p1 — hex mantissa × 2^exponent; exact binary value
std::abs(a - b) < eps — compare with a tolerance, never ==
std::isnan / std::isinf — test special values
epsilon() — gap between 1.0 and the next representable double

⚠ Common Mistakes

  • Testing x == 0.3 after arithmetic; use a relative tolerance like std::abs(a-b) <= 1e-9 * std::max(std::abs(a), std::abs(b))
  • Storing money in double; rounding errors accumulate. Use integer cents or a decimal library
  • Integer division before conversion: double r = 1 / 2; gives 0.0. Write 1.0 / 2

✓ Tips & Best Practices

  • Default to double; use float only for large arrays, GPUs, or memory-bound code
  • Print round-trippable values with std::println("{}", x); it prints the shortest exact representation
  • Use std::numbers::pi (C++20) instead of hand-typed constants

Quick Summary

  • double — default floating type (~15 digits)
  • 3.0f — float literal suffix
  • NaN / inf — check with std::isnan / std::isinf
  • never == — compare floats with a tolerance
