Reading Files

std::ifstream · is_open() · std::getline loop · >> extraction · good / fail / eof · the while (!eof()) pitfall

Input File Streams

std::ifstream (<fstream>) reads files with the same >> and std::getline interface as std::cin. Opening happens in the constructor and closing in the destructor (RAII), so you rarely call close(). Always check that the stream opened, and loop on the read operation itself: the stream converts to false once a read fails or hits end of file.

Notes

  • if (!in) or !in.is_open() — file missing or unreadable
  • while (std::getline(in, line)) — the idiomatic line loop
  • in >> x skips whitespace; getline keeps it
  • Read a whole file in one go with std::istreambuf_iterator

Reading Patterns

#include <fstream>

std::ifstream in{"scores.txt"};
if (!in) throw std::runtime_error("cannot open scores.txt");

std::string line;
while (std::getline(in, line)) {          // line by line
    if (line.empty() || line.starts_with('#')) continue;
    process(line);
}

std::ifstream nums{"data.txt"};
int x, sum = 0;
while (nums >> x) sum += x;               // whitespace-separated ints

std::ifstream all{"config.json"};
std::string text{std::istreambuf_iterator<char>{all}, {}};  // whole file

Code Explained

constructor opens; destructor closes automatically
if (!in) — check before reading anything
getline returns the stream, which is false at EOF
nums >> x — stops at EOF or the first non-number
istreambuf_iterator — slurp the entire file into a string

⚠ Common Mistakes

  • while (!in.eof()) { getline(in, line); … } processes a bogus last iteration; loop on getline itself
  • Not checking whether the file opened, then silently processing nothing
  • Using relative paths and being surprised by the working directory; print std::filesystem::current_path()

✓ Tips & Best Practices

  • Use std::filesystem::path for file names; streams accept it directly
  • Enable exceptions for strict code: in.exceptions(std::ios::badbit);
  • Speed up big reads by slurping the file, then parsing the string

Quick Summary

  • std::ifstream in{path} — open for reading
  • if (!in) — check it opened
  • while (getline(in, line)) — read lines
  • RAII — closes automatically
