std::span & std::mdspan

std::span · static vs dynamic extent · subspan · first / last · std::mdspan · passing arrays safely

Views over Contiguous Data

std::span<T> (C++20, <span>) is a non-owning pointer + size view over any contiguous sequence: a C array, std::array, std::vector, or part of one. It replaces the classic (T* ptr, size_t n) parameter pair. std::mdspan (C++23, <mdspan>) extends the idea to multidimensional views over flat storage, such as matrices and images.

Notes

  • span<const T> for read-only access, span<T> to modify
  • Dynamic extent span<T> stores size; static span<T, N> fixes it at compile time
  • Pass by value; it's two words
  • Like string_view, it must not outlive the data

span & mdspan

#include <span>
#include <mdspan>

double average(std::span<const double> xs) {
    return std::accumulate(xs.begin(), xs.end(), 0.0) / xs.size();
}
double raw[] = {1, 2, 3};
std::vector<double> vec{4, 5, 6, 7};
average(raw);                       // 2
average(vec);                       // 5.5
average({vec.data() + 1, 2});       // 5.5  (5, 6)

std::span<int> s{ints};             // writable view
s.first(2);  s.last(2);             // first / last 2 elements
s.subspan(1, 3);                    // 3 elements from index 1
s[0] = 42;                          // modifies ints[0]
std::span<int, 4> fixed{arr4};      // static extent
std::vector<float> pixels(3 * 4);
std::mdspan img{pixels.data(), 3, 4};   // 3 rows × 4 cols
img[1, 2] = 0.5f;                   // C++23 multi-index operator[]
img.extent(0); img.extent(1);       // 3, 4

Code Explained

span<const double> — accepts arrays, vectors, std::array

first / last / subspan — O(1) slicing
writes through span<int> modify the original data

⚠ Common Mistakes

  • Returning a span over a local vector; it dangles
  • Keeping a span to a vector, then calling push_back; reallocation invalidates it
  • Passing a std::list to a span parameter; spans need contiguous storage

✓ Tips & Best Practices

  • Make span the default parameter type for "a bunch of T" when you don't need ownership
  • Use std::as_bytes(span) for serialization and checksums
  • Library support for std::mdspan is newer (libstdc++ 14+, libc++ 17+, MSVC 17.9+); check before relying on it

Quick Summary

  • std::span<T> — non-owning contiguous view
  • span<const T> — read-only parameter type
  • first / last / subspan — slicing
  • std::mdspan — multidimensional view (C++23)
