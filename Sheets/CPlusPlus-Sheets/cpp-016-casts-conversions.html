Conversions & Casts

implicit conversions · integral promotion · static_cast · const_cast · reinterpret_cast · C-style casts · std::bit_cast

Changing Types

C++ performs many implicit conversions: small integers promote to int in arithmetic, mixed int/double expressions convert to double, and signed/unsigned mixes convert to unsigned. For explicit conversions, use the four named casts. Each says what it does, can be searched for, and refuses conversions outside its job. C-style casts (int)x try all of them silently and should be avoided.

Promotion Rules

  • char, short, bool → int before arithmetic
  • int op double → double
  • int op unsigned → unsigned (danger!)
  • Narrowing (double → int) truncates toward zero

Named Casts

double price = 9.99;
int dollars = static_cast<int>(price);          // 9
int avg     = static_cast<double>(7) / 2;       // 3.5 → 3

char c = 'A';
int code = static_cast<int>(c);                 // 65
enum class Color { Red, Green };
int g = static_cast<int>(Color::Green);         // 1

const std::string& ref = name;
auto& mut = const_cast<std::string&>(ref);      // removes const

Base* b = getShape();
if (auto* d = dynamic_cast<Circle*>(b)) {}      // null if not a Circle
std::uint32_t bits = 0x3F800000;
float f = std::bit_cast<float>(bits);           // 1.0f (C++20)
auto* raw = reinterpret_cast<std::byte*>(&bits);// view as bytes
int bad = (int)price;                           // C-style: avoid

Code Explained

static_cast — ordinary, compile-time-checked conversions
const_cast — add/remove const; only legal to write if the object isn't really const
dynamic_cast — run-time-checked downcast in polymorphic hierarchies
std::bit_cast — reinterpret bits between same-size types safely
reinterpret_cast — low-level pointer reinterpretation; easy to make UB

⚠ Common Mistakes

  • Integer division before casting: static_cast<double>(a / b) truncates first. Cast an operand: static_cast<double>(a) / b
  • Using reinterpret_cast to read a float as an int; this breaks aliasing rules. Use std::bit_cast
  • dynamic_cast on a class with no virtual functions; it doesn't compile because there's no RTTI

✓ Tips & Best Practices

  • Enable -Wconversion -Wsign-conversion to surface hidden implicit conversions
  • Use std::in_range<T>(x) (C++20) before narrowing to check the value fits
  • Grep for _cast< in reviews; every cast should have a reason

Quick Summary

  • static_cast — everyday explicit conversion
  • dynamic_cast — checked downcast
  • const_cast / reinterpret_cast — rare, low-level
  • std::bit_cast — safe bit reinterpretation
