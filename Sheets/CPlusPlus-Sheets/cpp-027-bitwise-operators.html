Bitwise Operators

Working with Bits

Bitwise operators work on the individual bits of integer values. They're used for flags, masks, hashing, compression, and hardware registers. Use unsigned types: shifting a negative value or shifting into the sign bit has historically been a trap. <bit> (C++20) provides portable helpers such as std::popcount and std::has_single_bit that compile to single CPU instructions. (For depth, see the Bitwise set.)

Shift Rules

  • Shifting by ≥ the type's width is UB
  • x << n multiplies by 2ⁿ (unsigned)
  • Right shift of negative signed values is arithmetic since C++20
  • Operands smaller than int promote first: ~uint8_t{0} is an int

Bit Manipulation

#include <bit>
#include <bitset>

unsigned a = 0b1100, b = 0b1010;
a & b;            // 0b1000 = 8    AND
a | b;            // 0b1110 = 14   OR
a ^ b;            // 0b0110 = 6    XOR
~a;               // 0xFFFFFFF3    NOT (all 32 bits)
1u << 4;          // 16

unsigned flags = 0;
flags |=  (1u << 2);           // set bit 2
flags &= ~(1u << 2);           // clear bit 2
flags ^=  (1u << 3);           // toggle bit 3
bool on = flags & (1u << 3);   // test bit 3 → true
std::popcount(0b1011u);        // 3   set bits
std::countr_zero(8u);          // 3   trailing zeros
std::bit_width(255u);          // 8   bits needed
std::has_single_bit(64u);      // true (power of 2)
std::bitset<8>(37).to_string();// "00100101"

Code Explained

& / | / ^ / ~ — and, or, xor, not on each bit

std::popcount — count 1 bits

std::bitset<N> — fixed-size bit array with printing

⚠ Common Mistakes

  • Writing x & 1 == 0; == binds tighter, so it's x & (1 == 0). Parenthesize: (x & 1) == 0
  • Shifting 1 << 31 with signed int; use 1u << 31
  • Applying ~ to small unsigned types and comparing; the result is a promoted int with high bits set

✓ Tips & Best Practices

  • Use enum class flags with overloaded | and & for type-safe bit sets
  • Use std::bitset::test, set, reset, count for readable flag code
  • Check endianness with std::endian::native == std::endian::little

Quick Summary

  • & | ^ ~ — bitwise and, or, xor, not
  • << >> — shifts; use unsigned types
  • set/clear/toggle — |=, &= ~, ^= with masks
  • <bit> — popcount, bit_width, rotl
