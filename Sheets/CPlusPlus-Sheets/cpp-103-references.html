References

Aliases for Objects

A reference is another name for an existing object. It must be initialized when declared, can't be reseated to refer to something else, and can't be null. Reading or writing through a reference affects the original. const T& binds to anything, including temporaries (and extends their lifetime). References make function parameters and range-for loops efficient without pointer syntax.

Notes

  • No "null reference" and no reference reassignment
  • T& binds to lvalues only; const T& also binds to temporaries
  • A reference member makes a class non-assignable
  • std::reference_wrapper<T> is a copyable, reseatable reference

References

int score = 70;
int& ref = score;          // alias
ref += 5;                  // score == 75
int other = 10;
ref = other;               // assigns 10 to score — does NOT reseat

const std::string& name = std::string{"temp"};  // lifetime extended
// int& bad = 5;           // ERROR: non-const ref to temporary

void bump(int& x) { ++x; }
bump(score);               // score == 11

std::string& first(std::vector<std::string>& v) { return v.front(); }
first(names) = "Zed";      // modifies the vector element

std::vector<std::reference_wrapper<int>> refs{score, other};
refs[0].get() = 1;         // score == 1
int& dangling() { int local = 5; return local; }   // UB on use

Code Explained

int& ref = score — ref and score are the same object
ref = other — copies the value; references never reseat
const& to a temporary — temporary lives as long as the reference
returning T& — lets callers modify the original
reference_wrapper — store references in containers

⚠ Common Mistakes

  • Returning a reference to a local variable or temporary; it dangles immediately
  • Expecting ref = other; to make ref refer to other; it assigns through it
  • Storing references to vector elements and then growing the vector; they dangle after reallocation

✓ Tips & Best Practices

  • Use const T& for read-only parameters of non-trivial types
  • Prefer pointers for optional or reseatable relationships, references for required ones
  • Use std::ref(x) to pass references through std::thread, std::bind, or std::invoke

Quick Summary

  • T& r = x; — alias for x
  • no null, no reseating
  • const T& — binds to temporaries
  • std::reference_wrapper — reference in containers
