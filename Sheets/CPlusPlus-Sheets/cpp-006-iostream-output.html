Sheet 006

Output with iostream

std::cout · << chaining · '\n' vs std::endl · std::cerr · <iomanip> · std::setw · std::setprecision · std::fixed

Stream Output

std::cout is the standard output stream from <iostream>. The insertion operator << sends values to it and returns the stream, so calls chain left to right. Formatting is controlled by manipulators from <iomanip>. Most of them are sticky: they stay in effect until changed. std::cerr writes to standard error and is unbuffered.

Streams

  • std::cout — buffered stdout
  • std::cerr — unbuffered stderr, for errors
  • std::clog — buffered stderr, for logging
  • '\n' ends a line; std::endl ends a line and flushes (slower in loops)

cout & Manipulators

#include <iostream>
#include <iomanip>

int qty = 42; double price = 3.14159;
std::cout << "Qty: " << qty << '\n';              // Qty: 42
std::cout << std::fixed << std::setprecision(2)
          << price << '\n';                       // 3.14
std::cout << std::setw(6) << qty << "|\n";        //     42|
std::cout << std::left << std::setw(6) << qty
          << "|\n";                               // 42    |
std::cout << std::setfill('0') << std::right
          << std::setw(5) << 7 << '\n';           // 00007
std::cout << std::hex << 255 << std::dec << '\n'; // ff
std::cout << std::boolalpha << true << '\n';      // true
std::cerr << "error: file not found\n";           // → stderr

Code Explained

<< — insertion; returns the stream so it can chain
std::fixed + setprecision(2) — 2 digits after the decimal point
std::setw(6) — width for the next item only (not sticky)
std::left / std::right — alignment within the width
std::setfill('0') — pad character (sticky)
std::hex — sticky; switch back with std::dec

⚠ Common Mistakes

  • Using std::endl in tight loops; each flush is a system call. Use '\n'
  • Forgetting std::hex is sticky, so every later integer also prints in hex
  • Expecting setw to persist; it resets after the next insertion

✓ Tips & Best Practices

  • Prefer std::print / std::format (next sheet) for new code: clearer and type-safe
  • Call std::ios::sync_with_stdio(false); for faster iostream I/O when you don't mix in printf
  • Save and restore format state with std::ios state(nullptr); state.copyfmt(std::cout);

Quick Summary

  • std::cout << — chained output to stdout
  • '\n' — newline without flushing
  • <iomanip> — setw, setprecision, fixed, setfill
  • std::cerr — unbuffered error output
