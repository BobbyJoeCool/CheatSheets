Sheet 115

Type Traits & SFINAE

<type_traits> · std::is_integral_v · std::is_same_v · std::conditional_t · std::decay_t · std::enable_if · std::declval

Compile-Time Type Logic

<type_traits> provides compile-time queries and transformations on types. Predicates like std::is_integral_v<T> yield a bool; transformations like std::remove_cvref_t<T> yield a new type. Before concepts, templates were constrained with SFINAE ("substitution failure is not an error"): an overload whose signature fails to substitute is silently dropped. You'll still see std::enable_if in older code.

Naming

  • _v suffix — value shortcut: is_same_v<A, B> = is_same<A, B>::value
  • _t suffix — type shortcut: decay_t<T> = typename decay<T>::type
  • std::declval<T>() — pretend to have a T in unevaluated contexts
  • Prefer if constexpr and concepts over SFINAE in new code

Traits & SFINAE

#include <type_traits>

static_assert(std::is_integral_v<long>);
static_assert(std::is_same_v<std::remove_cvref_t<const int&>, int>);
std::is_trivially_copyable_v<std::string>;     // false

template <typename T>
using Storage = std::conditional_t<(sizeof(T) <= 8), T, const T&>;
template <typename T>
std::string describe(const T& v) {
    if constexpr (std::is_arithmetic_v<T>) return std::to_string(v);
    else if constexpr (std::is_convertible_v<T, std::string>) return v;
    else return "?";
}
// SFINAE (pre-C++20 style):
template <typename T, std::enable_if_t<std::is_integral_v<T>, int> = 0>
T twice(T x) { return x * 2; }
using R = decltype(std::declval<Widget&>().size());   // member's return type

Code Explained

static_assert + traits — compile-time checks
remove_cvref_t — strip const, volatile, and references
conditional_t<cond, A, B> — pick a type at compile time
if constexpr + traits — modern replacement for SFINAE overloads
enable_if_t — removes the overload when the condition is false
declval — get an expression's type without constructing a Widget

⚠ Common Mistakes

  • Forgetting typename with the long form: typename std::decay<T>::type; use the _t alias
  • Writing complex SFINAE when a concept or if constexpr would be clearer
  • Using std::is_same_v<T, std::string> in generic code that receives const std::string& without removing cvref first

✓ Tips & Best Practices

  • Reach for std::remove_cvref_t<T> before comparing deduced types
  • Replace enable_if with requires clauses when upgrading code to C++20
  • Use static_assert(trait, "message") to give users clear errors

Quick Summary

  • is_*_v — compile-time type predicates
  • *_t — type transformations
  • SFINAE / enable_if — legacy constraint technique
  • std::declval — types of expressions in unevaluated contexts
