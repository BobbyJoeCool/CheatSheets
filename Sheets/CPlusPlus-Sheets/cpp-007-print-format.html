Sheet 007

std::print & std::format

std::print · std::println · std::format · {} placeholders · format spec {:>10.2f} · std::format_to · formatter<T>

Python-Style Formatting

C++20 added std::format, which builds a std::string from a format string with {} placeholders, checked at compile time. C++23 added std::print and std::println in <print>, which write formatted text straight to stdout (or a FILE*). The format-spec mini-language after a colon controls fill, alignment, width, precision, and type.

Spec Grammar

  • {[index]:[fill][align][sign][#][0][width][.precision][type]}
  • Align: < left, > right, ^ center
  • Mismatched argument types fail to compile, not at run time
  • Use {{ and }} for literal braces

format / print / println

#include <format>
#include <print>

std::string s = std::format("{} + {} = {}", 2, 3, 5); // "2 + 3 = 5"
std::println("{:>8}|", "right");     //    right|
std::println("{:<8}|", "left");      // left    |
std::println("{:*^9}", "mid");       // ***mid***
std::println("{:.2f}", 3.14159);     // 3.14
std::println("{:08.3f}", -3.5);      // -003.500
std::println("{:+d} {:x} {:#b}", 7, 255, 5); // +7 ff 0b101
std::println("{1} before {0}", "a", "b");    // b before a
std::println("{:%Y-%m-%d}",
    std::chrono::system_clock::now());       // 2026-10-11
std::print(stderr, "warn: {}\n", 42);        // → stderr
std::vector v{1, 2, 3};
std::println("{}", v);               // [1, 2, 3]  (C++23)

Code Explained

std::format — returns a std::string
std::println — prints and appends a newline
{:>8} — right-align in a field of 8
{:.2f} — fixed notation, 2 decimals
{1} / {0} — explicit argument indexes
Ranges and containers format directly in C++23

⚠ Common Mistakes

  • Passing a runtime string as the format: std::format(userStr) fails to compile; use std::vformat with std::make_format_args
  • Mixing automatic {} and manual {0} indexing in one string, which is an error
  • Assuming std::print exists on older standard libraries; it needs GCC 14+, Clang/libc++ 18+, or MSVC 19.37+

✓ Tips & Best Practices

  • Use {fmt} (fmt::print) as a drop-in on older toolchains; std::format is based on it
  • Specialize std::formatter<Point> once so std::println("{}", p) works everywhere
  • Prefer println over print("...\n"); it reads better

Quick Summary

  • std::format — type-safe string building with {}
  • std::println — formatted print plus newline (C++23)
  • {:>10.2f} — fill/align, width, precision, type
  • std::formatter<T> — make your own types formattable
