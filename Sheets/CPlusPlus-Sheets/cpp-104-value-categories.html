lvalues, rvalues & Forwarding

Every expression has a value category. An lvalue has identity and can be addressed (a named variable). A prvalue is a pure temporary value (42, f() returning by value). An xvalue is an expiring object, such as the result of std::move(x). In templates, T&& with a deduced T is a forwarding reference that binds to anything, and std::forward<T> passes the argument on with its original category preserved.

Rules of Thumb

  • Has a name → lvalue (even if its type is T&&!)
  • std::move(x) → xvalue (rvalue)
  • T&& in a template parameter with deduction → forwarding ref
  • auto&& is a forwarding reference too

Categories & Perfect Forwarding

int x = 5;
int& lr = x;                 // lvalue ref binds to lvalue
int&& rr = 5;                // rvalue ref binds to prvalue
// int&& bad = x;            // ERROR: x is an lvalue
int&& moved = std::move(x);  // OK: std::move makes an xvalue

void take(std::string& s)  { std::println("lvalue"); }
void take(std::string&& s) { std::println("rvalue"); }

template <class T>
void relay(T&& arg) {                  // forwarding reference
    take(std::forward<T>(arg));        // preserves category
}
std::string s = "hi";
relay(s);                    // lvalue  (T = std::string&)
relay(std::string{"tmp"});   // rvalue  (T = std::string)
relay(std::move(s));         // rvalue

Code Explained

int&& — binds only to rvalues
std::move — a cast to rvalue reference; moves nothing itself
forwarding reference — T deduced as X& for lvalues, X for rvalues
std::forward<T> — casts back to rvalue only if the argument was one
inside relay, arg is a named lvalue, hence the need to forward

⚠ Common Mistakes

  • Using std::move on a forwarding reference; it turns lvalues into rvalues and steals from the caller. Use std::forward
  • Assuming a parameter declared T&& x is an rvalue inside the function; it's a named lvalue
  • Calling std::forward twice on the same argument; the second use may see a moved-from object

✓ Tips & Best Practices

  • Remember: std::move for rvalue references you own, std::forward for forwarding references
  • auto&& in range-for works for every element type, including proxies
  • Use decltype(auto) to return a forwarded expression without decaying it

Quick Summary

  • lvalue / prvalue / xvalue — value categories
  • T&& (deduced) — forwarding reference
  • std::forward<T> — preserve category
