Static Members

static data members · static member functions · inline static · static constexpr · per-class counters · singleton

Class-Level Members

A static data member belongs to the class, not to any object: there's exactly one copy shared by all instances. A static member function has no this pointer and can only touch static members directly; call it as ClassName::f(). Since C++17, inline static lets you define a static data member inside the class, so no separate .cpp definition is needed.

Notes

  • static constexpr members are implicitly inline (C++17)
  • Access via Class::member (preferred) or through an object
  • Static members exist even if no object is ever created
  • A function-local static initializes once, thread-safely

Static Members

class Connection {
public:
    Connection()  { ++open_; }
    ~Connection() { --open_; }
    static int openCount() { return open_; }     // no `this`
    static constexpr int kMaxOpen = 64;          // compile-time constant
    static Connection& primary() {               // singleton accessor
        static Connection instance;              // built on first call
        return instance;
    }
private:
    inline static int open_ = 0;                 // one shared counter
};
Connection a, b;
Connection::openCount();                         // 2
Connection::kMaxOpen;                            // 64
Connection::primary();                           // same object every call

Code Explained

++open_ — every instance updates the shared counter
static int openCount() — called without an object
static constexpr — class-wide constant
function-local static — Meyers singleton, thread-safe init
inline static — in-class definition (C++17)

⚠ Common Mistakes

  • Declaring static int count; without a definition (pre-C++17 style), causing an "undefined reference" link error
  • Accessing instance members inside a static function; there's no object, so it won't compile
  • Overusing singletons; global state makes testing and concurrency harder

✓ Tips & Best Practices

  • Use inline static for in-class definitions
  • Prefer a free function or namespace for utilities that don't need class access
  • If a singleton is truly needed, use a function-local static, not a global pointer

Quick Summary

  • static data — one copy shared by all objects
  • static function — no this, call Class::f()
  • inline static — define in class (C++17)
  • local static — lazy, thread-safe singleton
