Headers & Include Guards

#include <> vs "" · #pragma once · include guards · forward declarations · what goes in a header

Header Files

A header declares the interface that other .cpp files need: classes, function prototypes, templates, inline functions, and constants. #include pastes the header's text into each translation unit, so a header can end up included several times in one TU. Include guards or #pragma once stop the second inclusion. Forward declarations (class Widget;) cut compile times by avoiding includes when only a pointer or reference is needed.

Notes

  • <header> — searched in system/include paths
  • "header.h" — searched next to the including file first
  • #pragma once is non-standard but supported everywhere
  • Each header should compile on its own (include what you use)

Header + Source Pair

// inventory.h
#pragma once                      // or classic include guards below
#include <string>                 // needed: used by value
#include <vector>
class Supplier;                   // forward declaration: only a pointer

class Inventory {
public:
    void add(std::string name, int qty);
    int  total() const;
    void setSupplier(Supplier* s) { supplier_ = s; }
private:
    std::vector<std::pair<std::string, int>> items_;
    Supplier* supplier_ = nullptr;
};
// inventory.cpp
#include "inventory.h"            // own header first
#include "supplier.h"             // full definition needed here

Code Explained

#pragma once — the compiler skips the file if already included
#include <string> — the header needs the full type
class Supplier; — enough for pointers and references
definitions go in inventory.cpp
own header first — proves it's self-contained

⚠ Common Mistakes

  • using namespace std; in a header, which forces it on every file that includes it
  • Defining non-inline functions or globals in a header, causing "multiple definition" link errors
  • Circular includes between two headers; break the cycle with forward declarations

✓ Tips & Best Practices

  • Include what you use; don't rely on another header pulling it in transitively
  • Forward-declare in headers, include in .cpp files, to speed up builds
  • Use .hpp for C++-only headers if your project mixes C and C++

Quick Summary

  • header — declarations and inline definitions
  • #pragma once / guards — prevent double inclusion
  • forward declaration — class X; for pointers/refs
  • .cpp — definitions
