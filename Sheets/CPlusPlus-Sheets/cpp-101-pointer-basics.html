Pointer Basics

* and & · dereferencing · nullptr · pointer to pointer · const T* vs T* const · void*

Addresses & Indirection

A pointer stores the memory address of an object. &x takes an address, and *p dereferences a pointer to reach the object it points to. A pointer can be reassigned to point elsewhere and can be null (nullptr), meaning it points to nothing. Dereferencing a null, dangling, or uninitialized pointer is undefined behavior. In modern C++, raw pointers are for non-owning access; ownership belongs to smart pointers.

Reading Declarations

  • int* p — pointer to int
  • const int* p — pointer to const int (can't modify *p)
  • int* const p — const pointer (can't reseat p)
  • int** pp — pointer to pointer to int

Pointer Basics

int x = 10;
int* p = &x;            // p holds x's address
*p = 20;                // x == 20
std::println("{}", static_cast<void*>(p));   // e.g. 0x7ffd5c3a

int* q = nullptr;       // points to nothing
if (q) *q = 1;          // guard before dereferencing

int** pp = &p;          // pointer to pointer
**pp = 30;              // x == 30

const int* ro = &x;     // *ro = 1;  ERROR   ro = &y;  OK
int* const fixed = &x;  // *fixed = 1; OK    fixed = &y; ERROR

void* any = &x;                      // untyped address
int* back = static_cast<int*>(any);  // must cast back to use

Code Explained

&x — address-of operator
*p — dereference: the object p points to
nullptr — typed null pointer constant (not NULL or 0)
**pp — two levels of indirection
void* — generic address; cast back before use

⚠ Common Mistakes

  • Declaring int* a, b; — only a is a pointer; b is an int. Declare one per line
  • Using an uninitialized pointer: int* p; *p = 5; is UB. Initialize to nullptr or a valid address
  • Keeping a pointer to a local after its function returns; it dangles

✓ Tips & Best Practices

  • Use references when null isn't a valid value; use pointers when "no object" is meaningful
  • Use std::unique_ptr / std::shared_ptr for ownership; raw T* means "I'm just looking"
  • Enable -Wnull-dereference and run ASan to catch pointer bugs early

Quick Summary

  • T* p = &x; — pointer to x
  • *p — dereference
  • nullptr — null pointer
  • const T* vs T* const — pointee vs pointer constness
