std::string — Modify & Substring

substr · insert · erase · replace · append · resize · std::transform + toupper · trimming

Editing Strings

std::string is mutable, and its editing members change the string in place. Most take a position and a count, and many return *this so calls can chain. substr(pos, len) returns a new string. There's no built-in trim, split, or case conversion, but each is a one- or two-liner with find_first_not_of, std::views::split, or std::ranges::transform.

Notes

  • Positions past size() throw std::out_of_range
  • A count past the end is clamped (substr(2, 100) is fine)
  • erase / insert shift every following char: O(n)
  • resize(n, c) grows with c or truncates

Modify, Substring, Transform

std::string s = "Hello World";

s.substr(6);                     // "World"
s.substr(0, 5);                  // "Hello"
s.insert(5, ",");                // "Hello, World"
s.erase(5, 1);                   // "Hello World"
s.replace(6, 5, "C++");          // "Hello C++"
s.append(" 23");                 // "Hello C++ 23"
s.resize(5);                     // "Hello"
s.resize(8, '.');                // "Hello..."

std::ranges::transform(s, s.begin(),
    [](unsigned char c) { return std::toupper(c); }); // "HELLO..."

// trim whitespace
std::string t = "  padded \n";
t.erase(0, t.find_first_not_of(" \t\n"));
t.erase(t.find_last_not_of(" \t\n") + 1);            // "padded"

Code Explained

substr(pos, n) — copy of up to n chars from pos
insert / erase / replace — edit in place
resize — truncate or pad
ranges::transform with toupper — in-place uppercase
trim — erase leading and trailing runs of whitespace

⚠ Common Mistakes

  • Calling s.substr(pos) with pos = npos from a failed find; it throws. Check find first
  • Passing plain char to std::toupper; negative values are UB. Take unsigned char in the lambda
  • Erasing inside an index loop and skipping the char that shifted into the current position

✓ Tips & Best Practices

  • Use std::erase / std::erase_if (C++20) to remove characters in one call
  • For many edits, build a new string with reserve + append instead of repeated insert
  • Return std::string_view slices instead of substr copies when the source outlives the view

Quick Summary

  • substr(pos, n) — new string slice
  • insert / erase / replace — in-place edits
  • ranges::transform — case conversion
  • find_first_not_of — trimming building block
