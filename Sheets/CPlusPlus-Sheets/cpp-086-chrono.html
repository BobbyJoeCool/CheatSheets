Time in C++

<chrono> models time with three ideas: a duration (an amount of time with a unit), a clock (a source of time), and a time_point (a duration since a clock's epoch). Units convert automatically when lossless; lossy conversions need duration_cast. C++20 added calendar types (year_month_day) and time zones (zoned_time), so most date work no longer needs a third-party library.

Clocks

  • steady_clock — monotonic; use for measuring elapsed time
  • system_clock — wall-clock time; can jump (NTP, DST)
  • high_resolution_clock — often an alias; prefer steady_clock
  • Literals: using namespace std::chrono_literals; → 5s, 250ms, 2h

Durations, Timing, Dates

#include <chrono>
using namespace std::chrono;
using namespace std::chrono_literals;

auto timeout = 1500ms;
duration_cast<seconds>(timeout).count();   // 1  (truncated)
auto total = 2min + 30s;                   // 150s
std::this_thread::sleep_for(100ms);

auto start = steady_clock::now();
doWork();
auto ms = duration_cast<milliseconds>(steady_clock::now() - start);
std::println("took {}", ms);               // took 42ms

year_month_day today = floor<days>(system_clock::now());
auto due = today + months{1};              // same day next month
auto wd = weekday{sys_days{today}};        // e.g. Sun
zoned_time ny{"America/New_York", system_clock::now()};
std::println("{:%Y-%m-%d %H:%M %Z}", ny);  // 2026-10-11 09:30 EDT

Code Explained

1500ms — chrono literal
duration_cast<seconds> — explicit lossy conversion
steady_clock for timing — immune to wall-clock changes
floor<days> — time_point → calendar date
zoned_time — time in a named IANA zone
chrono types format directly with std::format

⚠ Common Mistakes

  • Measuring elapsed time with system_clock; a clock adjustment can make it negative. Use steady_clock
  • Calling .count() and losing the unit; keep values as durations until printing
  • Mixing local time and UTC without a time zone; use zoned_time

✓ Tips & Best Practices

  • Write a small Timer RAII class that prints elapsed steady_clock time in its destructor
  • Accept durations in APIs (void wait(std::chrono::milliseconds)) instead of raw ints
  • Parse dates with std::chrono::parse and an istringstream

Quick Summary

  • duration — amount of time with units
  • steady_clock — measure elapsed time
  • year_month_day — calendar dates (C++20)
  • zoned_time — time zones (C++20)
