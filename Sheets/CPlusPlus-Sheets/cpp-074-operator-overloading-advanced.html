Operator Overloading — Advanced

operator() · conversion operators · explicit operator bool · ++ prefix / postfix · copy-and-swap · user-defined literals

Special-Purpose Operators

Some operators unlock idioms beyond arithmetic. operator() makes an object callable (a functor), the basis of comparators and lambdas. Conversion operators let a type convert to another; mark them explicit to avoid surprises, especially explicit operator bool. Increment comes in prefix and postfix forms, and user-defined literals (operator"") let you write values like 10_km.

Notes

  • Postfix ++ takes a dummy int parameter
  • explicit operator bool still works in if and ! (contextual conversion)
  • User-defined literal suffixes must start with _
  • operator[] can take multiple indexes since C++23

Functors, Conversions, ++, Literals

struct ByLength {                                        // functor
    bool operator()(const std::string& a, const std::string& b) const {
        return a.size() < b.size();
    }
};
std::ranges::sort(words, ByLength{});
class Handle {
    int fd_ = -1;                                        // private
public:
    explicit operator bool() const { return fd_ >= 0; }  // if (h) OK
};
struct Counter {
    int n = 0;
    Counter& operator++() { ++n; return *this; }         // prefix
    Counter operator++(int) { auto old = *this; ++n; return old; } // postfix
};
struct Distance { double meters; };
constexpr Distance operator""_km(long double v) {
    return {static_cast<double>(v * 1000)};
}
auto d = 2.5_km;                                         // Distance{2500}

Code Explained

operator() — instances can be called like functions
explicit operator bool — allows if (h), blocks int x = h;
prefix returns a reference; postfix returns the old value by copy
operator""_km — user-defined literal suffix
long double — required parameter type for floating literals

⚠ Common Mistakes

  • Non-explicit operator bool, which allows nonsense like h1 + h2 or int x = handle;
  • Writing postfix ++ without the int parameter, or returning a reference to the old value
  • Implicit conversion operators that create ambiguous overloads

✓ Tips & Best Practices

  • Prefer ++it over it++ for iterators; postfix creates a copy
  • Put user-defined literals in a namespace (namespace units::literals) and import them where needed
  • Use copy-and-swap in assignment operators for the strong exception guarantee

Quick Summary

  • operator() — callable objects
  • explicit operator bool — safe truthiness
  • ++x vs x++ — operator++() vs operator++(int)
  • operator""_suffix — user-defined literals
