Range-Based for

for (auto x : c) · auto& · const auto& · auto&& · structured bindings · views::enumerate · views::reverse

Iterating a Range

The range-based for loop visits every element of anything with begin() and end(): containers, arrays, strings, initializer lists, and views. The loop variable's declaration decides whether you copy each element, modify it in place, or read it through a const reference. Combine it with structured bindings for maps and pairs, and with views for indexes, reversal, or filtering.

Picking the Variable

  • auto x — copy (cheap types only)
  • auto& x — modify elements in place
  • const auto& x — read-only, no copies (default choice)
  • auto&& x — works with proxies and views (generic code)

Range-for Variants

std::vector<std::string> names{"Ada", "Bo", "Cy"};

for (const auto& n : names) std::print("{} ", n);   // Ada Bo Cy
for (auto& n : names) n += "!";                     // modify in place
for (int x : {1, 2, 3}) {}                          // initializer list
for (char c : std::string{"hey"}) {}                // characters

std::map<std::string, int> ages{{"Ada", 36}, {"Bo", 25}};
for (const auto& [name, age] : ages)                // structured binding
    std::println("{} is {}", name, age);

for (auto [i, n] : std::views::enumerate(names))    // C++23
    std::println("{}: {}", i, n);                   // 0: Ada! …
for (const auto& n : names | std::views::reverse) {}
for (auto x : nums | std::views::filter([](int v) { return v > 0; })) {}

for (auto v = makeVec(); auto x : v) {}             // init (C++20)

Code Explained

const auto& — no copy, can't modify
auto& — writes go to the container
[name, age] — unpacks each std::pair in the map
views::enumerate — yields (index, element) tuples
views::reverse / filter — lazy adaptors, no copies
for (init; x : range) — keeps a temporary alive (C++20)

⚠ Common Mistakes

  • for (auto s : names) copies every string; use const auto&
  • Calling push_back or erase on the container inside its own range-for; iterators are invalidated (UB)
  • for (auto x : getObj().items()) before C++23 could dangle if getObj() returns a temporary; use the init form

✓ Tips & Best Practices

  • Default to const auto&; drop to auto only for small types like int or char
  • Use std::views::keys(m) when you only need map keys
  • Can't get an index? Use views::enumerate instead of a separate counter

Quick Summary

  • for (decl : range) — visit every element
  • const auto& — default, no copies
  • [k, v] — structured bindings for pairs/maps
  • views::enumerate / reverse — index and order helpers
