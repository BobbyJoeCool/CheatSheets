std::pair & std::tuple

std::pair · std::make_pair · std::tuple · std::get · std::tie · structured bindings · std::apply

Grouping Values

std::pair<A, B> holds exactly two values in .first and .second; maps use it for key/value entries. std::tuple<Ts...> (<tuple>) holds any fixed number of values, accessed by index or type with std::get. Structured bindings (C++17) unpack both into named variables. For anything with meaning, a small named struct is usually clearer than a tuple.

Notes

  • Both compare lexicographically with ==, <, <=>
  • CTAD: std::pair p{1, 2.5}; deduces pair<int, double>
  • std::tie(a, b) = f(); assigns into existing variables
  • std::apply(f, tup) calls f with the tuple's elements as arguments

pair, tuple, structured bindings

#include <tuple>
#include <utility>

std::pair<std::string, int> p{"Ada", 36};
p.first;  p.second;                    // "Ada", 36
auto q = std::make_pair(1, 2.5);       // pair<int, double>

std::tuple<int, std::string, double> t{7, "seven", 7.0};
std::get<0>(t);                        // 7
std::get<std::string>(t);              // "seven" (by type)

auto [name, age] = p;                  // structured bindings
auto& [id, label, val] = t;            // references into t

std::tuple<int, int> minmax(std::span<const int> v);
auto [lo, hi] = minmax(data);
int a, b;
std::tie(a, std::ignore) = minmax(data);   // skip one value
std::apply([](int x, auto& s, double d) { /* ... */ }, t);

Code Explained

.first / .second — pair members
std::get<0> — compile-time index; std::get<T> works if T is unique
auto [name, age] — copies; auto& binds references
std::tie + std::ignore — assign into existing variables
std::apply — unpack a tuple into a function call

⚠ Common Mistakes

  • Returning std::tuple<int, int, int> from public APIs; callers can't tell which int is which. Return a named struct
  • std::get<int>(t) when the tuple has two int elements; it doesn't compile
  • Expecting auto [x, y] = p; to alias p; it's a copy unless you write auto&

✓ Tips & Best Practices

  • Use structured bindings with maps: for (const auto& [k, v] : m)
  • Use std::tie(a.x, a.y) < std::tie(b.x, b.y) for quick lexicographic comparisons
  • Aggregates (plain structs) also support structured bindings with no extra code

Quick Summary

  • std::pair — two values, .first / .second
  • std::tuple — N values, std::get<I>
  • auto [a, b] = … — structured bindings
  • std::tie / std::apply — assign / unpack
