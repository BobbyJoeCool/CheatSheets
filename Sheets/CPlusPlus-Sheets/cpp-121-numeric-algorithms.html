Numeric Algorithms

<numeric> holds algorithms for summing and combining values. std::accumulate folds left to right; std::reduce (C++17) does the same but may reorder operations, which allows parallel execution policies from <execution>. std::transform_reduce maps then reduces in one pass. std::iota fills a range with increasing values, and std::partial_sum produces running totals.

Notes

  • The type of the initial value decides the result type
  • reduce requires an associative, commutative operation
  • Policies: std::execution::seq, par, par_unseq, unseq
  • C++23 adds std::ranges::fold_left / fold_right

accumulate, reduce, iota

#include <numeric>
#include <execution>

std::vector<int> v{1, 2, 3, 4, 5};
std::accumulate(v.begin(), v.end(), 0);           // 15
std::accumulate(v.begin(), v.end(), 1, std::multiplies<>{}); // 120
std::accumulate(prices.begin(), prices.end(), 0.0);  // use 0.0 for doubles!

std::reduce(std::execution::par, big.begin(), big.end(), 0LL);
std::transform_reduce(a.begin(), a.end(), b.begin(), 0.0);   // dot product

std::vector<int> ids(5);
std::iota(ids.begin(), ids.end(), 100);           // 100 101 102 103 104
std::vector<int> run(v.size());
std::partial_sum(v.begin(), v.end(), run.begin()); // 1 3 6 10 15
std::gcd(12, 18);  std::lcm(4, 6);                // 6, 12
std::midpoint(1, 4);                              // 2 (no overflow)
std::ranges::fold_left(v, 0, std::plus<>{});      // 15 (C++23)

Code Explained

accumulate(b, e, init) — sum starting from init
std::multiplies<>{} — product instead of sum
0.0 initial value — otherwise doubles are summed as int
reduce with par — may run on multiple threads
transform_reduce(a, b, init) — sum of pairwise products
iota / partial_sum — sequences and running totals

⚠ Common Mistakes

  • std::accumulate(d.begin(), d.end(), 0) on doubles truncates every partial sum to int
  • Using reduce with a non-associative operation like subtraction; results vary between runs
  • Expecting parallel policies to speed up small ranges; thread overhead dominates

✓ Tips & Best Practices

  • Write the initial value with the type you want: 0LL, 0.0, std::string{}
  • On GCC, parallel policies need TBB (-ltbb); MSVC has them built in
  • Use std::iota + std::ranges::shuffle to build random permutations

Quick Summary

  • accumulate — sequential fold with init
  • reduce — parallelizable fold
  • transform_reduce — map + reduce, e.g. dot product
  • iota / partial_sum — sequences and running totals
