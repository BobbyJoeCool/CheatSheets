Arithmetic Operators

+ - * / % · integer division & truncation · ++ / -- prefix vs postfix · mixed-type arithmetic · overflow

Math Operators

Arithmetic operators work on all numeric types after the usual arithmetic conversions: operands smaller than int promote to int, and mixed types convert to the wider one. Integer division truncates toward zero, and % takes the sign of the dividend. Dividing an integer by zero is undefined behavior, and so is signed overflow.

Precedence

  • * / % bind tighter than + -
  • Unary - and ++/-- bind tighter still
  • Same precedence groups left-to-right: 8 / 4 / 2 = 1
  • Parenthesize when in doubt

Arithmetic in Action

int a = 17, b = 5;
a + b;            // 22
a - b;            // 12
a * b;            // 85
a / b;            // 3     (truncated)
a % b;            // 2
-17 / 5;          // -3    (toward zero)
-17 % 5;          // -2    (sign of dividend)
17.0 / 5;         // 3.4   (double wins)
static_cast<double>(a) / b;   // 3.4

int i = 5;
int x = i++;      // x = 5, i = 6   (postfix: old value)
int y = ++i;      // y = 7, i = 7   (prefix: new value)
char c = 'a';
auto z = c + 1;   // int 98 (char promoted)
unsigned u = 3;
u - 5;            // 4294967294 (wraps)
1 / 0;            // UB: integer divide by zero
1.0 / 0.0;        // inf

Code Explained

/ on ints — fractional part discarded
% — remainder; only for integer types (use std::fmod for floats)
i++ vs ++i — postfix yields old value, prefix yields new
c + 1 — promotion makes the result int
unsigned subtraction below zero wraps around

⚠ Common Mistakes

  • double avg = sum / count; with two ints gives a truncated result; cast one operand first
  • i = i++ + ++i; — modifying a variable twice without sequencing is UB (or unspecified); split the statement
  • Using % to test oddness with negative numbers: -3 % 2 == -1, so test x % 2 != 0

✓ Tips & Best Practices

  • Prefer ++i in loops and with iterators; it never needs a temporary copy
  • Use std::midpoint(a, b) (C++20) to avoid overflow in (a + b) / 2
  • Check for overflow with __builtin_add_overflow (GCC/Clang) or C++26 std::add_sat

Quick Summary

  • + - * / — standard arithmetic after promotion
  • int / int — truncates toward zero
  • % — remainder, sign follows dividend
  • i++ / ++i — old value vs new value
