Parsing Text Formats

The standard library has no CSV or JSON parser, but simple formats are easy with std::getline using a delimiter, std::istringstream for typed fields, and C++20/23 ranges (views::split). Use std::from_chars to convert fields to numbers quickly and with error reporting. Real CSV (quoted fields with embedded commas) needs a small state machine or a library.

Notes

  • getline(ss, field, ',') — split one line on commas
  • std::quoted reads/writes "quoted strings" with escapes
  • Trim whitespace before converting numbers
  • Libraries: rapidcsv, csv-parser; JSON → nlohmann/json

CSV Round Trip

struct Row { std::string name; int qty; double price; };
std::vector<Row> readCsv(const fs::path& file) {
    std::ifstream in{file};
    std::vector<Row> rows;
    std::string line;
    std::getline(in, line);                      // skip header
    while (std::getline(in, line)) {
        std::istringstream ss{line};
        Row r; std::string qty, price;
        std::getline(ss, r.name, ','); std::getline(ss, qty, ',');
        std::getline(ss, price);
        std::from_chars(qty.data(), qty.data() + qty.size(), r.qty);
        r.price = std::stod(price);
        rows.push_back(std::move(r));
    }
    return rows;
}
for (auto f : std::string_view{"a,b,c"} | std::views::split(',')) {}

Code Explained

first getline — consume the header row
istringstream ss{line} — treat one line as a stream
getline(ss, field, ',') — read up to the next comma
from_chars / stod — convert the text fields
views::split(',') — lazy split of a string_view (C++20)

⚠ Common Mistakes

  • Splitting quoted fields like "Smith, Jr." on commas; handle quotes or use a library
  • Forgetting Windows line endings: lines keep a trailing '\r'; strip it
  • Converting with std::stoi on untrusted data without catching exceptions

✓ Tips & Best Practices

  • Read a whole line first, then parse it; error messages can include the line number
  • Wrap field conversion in a helper returning std::optional or std::expected
  • Collect split pieces with std::ranges::to<std::vector>() (C++23)

Quick Summary

  • getline(ss, field, ',') — classic CSV split
  • std::istringstream — parse one line
  • views::split — lazy splitting
  • std::from_chars — fast numeric conversion
