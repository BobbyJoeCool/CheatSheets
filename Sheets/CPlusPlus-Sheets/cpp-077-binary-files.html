Binary Files

std::ios::binary · read() · write() · seekg / tellg · reinterpret_cast<char*> · endianness · std::byteswap

Raw Bytes

Open with std::ios::binary to read and write raw bytes with no newline translation (which matters on Windows). Use write(ptr, n) and read(ptr, n), which take a char*, so you reinterpret_cast your object's address. That's only safe for trivially copyable types, and the bytes depend on the platform's endianness, padding, and type sizes. seekg/tellg move around the file.

Notes

  • gcount() — bytes actually read by the last read
  • std::endian::native (C++20) — check byte order
  • std::byteswap (C++23) — reverse bytes of an integer
  • Use fixed-width types (std::uint32_t) for file formats

Binary Read & Write

#include <fstream>
#include <bit>

struct Header {
    std::uint32_t magic; std::uint16_t version; std::uint16_t count;
};
static_assert(std::is_trivially_copyable_v<Header>);

Header h{0xCAFEBABE, 2, 10};
std::ofstream out{"data.bin", std::ios::binary};
out.write(reinterpret_cast<const char*>(&h), sizeof h);
std::ifstream in{"data.bin", std::ios::binary};
Header r{};
in.read(reinterpret_cast<char*>(&r), sizeof r);
if (in.gcount() != sizeof r) throw std::runtime_error("truncated");
in.seekg(0, std::ios::end);
auto size = in.tellg();                          // file size in bytes
in.seekg(0);                                     // back to start
std::vector<char> bytes(size);
in.read(bytes.data(), size);
std::uint32_t be = std::byteswap(h.magic);       // little ↔ big endian

Code Explained

std::ios::binary — bytes in, bytes out
reinterpret_cast<const char*>(&h) — view the struct as bytes
static_assert(is_trivially_copyable_v) — guard against unsafe types
seekg(0, end) + tellg() — find the file size
std::byteswap — convert endianness (C++23)

Safe vs Unsafe to write()

TypeSafe?
int, double, uint32_t✔ (watch endianness)
struct of those✔ (watch padding)
std::string✖ (holds a pointer)
std::vector✖ (write data() + size)
class with virtuals✖ (vptr)

⚠ Common Mistakes

  • Writing a std::string or std::vector object with write; you save pointers, not data
  • Forgetting std::ios::binary on Windows, which corrupts bytes 0x0A/0x0D
  • Assuming struct layout matches another compiler or CPU; padding and endianness differ

✓ Tips & Best Practices

  • Serialize field by field in a defined byte order for portable formats
  • Use std::filesystem::file_size(path) instead of seek/tell to get the size
  • Prefer a format library (Protocol Buffers, FlatBuffers, Cap'n Proto) for anything shared

Quick Summary

  • std::ios::binary — raw byte I/O
  • write / read — with reinterpret_cast<char*>
  • trivially copyable — only types safe to dump
  • seekg / tellg — positioning
