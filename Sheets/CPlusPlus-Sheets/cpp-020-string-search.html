Sheet 020

std::string — Search

find · rfind · find_first_of · find_last_not_of · npos · contains · starts_with · ends_with

Finding Text

The find family returns the index of the first match, or the special value std::string::npos when nothing is found. Each takes an optional starting position. C++20 added starts_with / ends_with, and C++23 added contains, which cover most yes/no checks without index juggling. The same members exist on std::string_view.

npos

  • npos is size_t(-1), the largest possible size
  • Always compare: if (pos != std::string::npos)
  • find_first_of("aeiou") matches any char in the set
  • All searches are case-sensitive

Search Members

std::string s = "banana split";

s.find("an");                   // 1
s.find("an", 2);                // 3   (search from index 2)
s.rfind("an");                  // 3   (last occurrence)
s.find('z');                    // npos
s.find_first_of("aeiou");       // 1   (first vowel)
s.find_last_of("aeiou");        // 10  ('i')
s.find_first_not_of("ban");     // 6   (' ')
s.find_last_not_of(" \t\n");    // 11  (trim helper)

s.starts_with("ban");           // true   (C++20)
s.ends_with("split");           // true   (C++20)
s.contains("nan");              // true   (C++23)

// Count every occurrence
std::size_t count = 0;
for (auto pos = s.find('a'); pos != std::string::npos;
     pos = s.find('a', pos + 1)) ++count;   // count == 3

Code Explained

find(str, pos) — first match at or after pos
rfind — searches backward from the end
find_first_of(set) — any character from the set
find_first_not_of — first char outside the set (good for trimming)
loop pattern — restart at pos + 1 to find all matches

⚠ Common Mistakes

  • Testing if (s.find(x)); a match at index 0 is false and npos is true. Compare against npos
  • Storing the result in int; npos won't fit. Use std::size_t or auto
  • Expecting find_first_of("abc") to find the substring "abc"; it finds any single char a, b, or c

✓ Tips & Best Practices

  • Use contains / starts_with for readability when you don't need the index
  • For case-insensitive search, lowercase copies first or use std::ranges::search with a custom predicate
  • Use std::regex or std::boyer_moore_searcher for complex or repeated searches

Quick Summary

  • find / rfind — first / last index or npos
  • find_first_of(set) — any char from a set
  • starts_with / ends_with — prefix/suffix test (C++20)
  • contains — substring test (C++23)
