Sheet 014

auto, decltype & Type Aliases

auto · const auto& · auto&& · decltype · decltype(auto) · using aliases · typedef · sizeof / alignof

Let the Compiler Infer

auto deduces a variable's type from its initializer using template deduction rules: top-level const and references are dropped unless you write them (const auto&, auto&). decltype(expr) gives the declared type of an expression without evaluating it. Type aliases (using) give a long type a readable name, and sizeof / alignof report size and alignment in bytes.

Deduction Rules

  • auto → copies, drops const and &
  • auto& / const auto& → binds a reference
  • auto&& → forwarding reference; binds to anything
  • decltype(auto) → keeps references exactly as written

auto, decltype, using

auto i  = 42;              // int
auto d  = 3.0;             // double
auto s  = "hi";            // const char*  (not std::string!)
auto s2 = std::string{"hi"};
using namespace std::literals;
auto s3 = "hi"s;           // std::string

const int& cr = i;
auto a = cr;               // int        (const & dropped)
const auto& b = cr;        // const int&
for (const auto& [k, v] : myMap) {}   // no copies

decltype(i)  x = 0;        // int
decltype((i)) y = i;       // int&  (parenthesized → ref)

using Grid = std::vector<std::vector<int>>;
typedef unsigned long ulong;          // old style
template <class T> using Vec = std::vector<T>;

sizeof(int);               // 4
alignof(double);           // 8

Code Explained

"hi" — string literals deduce to const char*; use "hi"s for std::string
auto a = cr; — makes a copy; const and reference vanish
const auto& — standard choice for read-only loop variables
decltype((i)) — extra parentheses yield a reference
using — preferred over typedef; supports templates

auto Forms

When to Use auto

SituationRecommendation
iterators, lambdasalways auto
make_unique<T>() resultauto (type is visible)

range-for over big objectsconst auto&

⚠ Common Mistakes

  • for (auto x : bigVector) copies every element; use const auto&
  • auto flag = bits[3]; with std::vector<bool> stores a proxy that dangles if the vector changes
  • Expecting auto s = "text"; to be a std::string

✓ Tips & Best Practices

  • Use auto when the type is obvious from the right-hand side or irrelevant to the reader
  • Hover in your IDE (or use decltype in a static_assert) to confirm what auto deduced
  • Prefer using Alias = Type; over typedef everywhere

Quick Summary

  • auto — deduce type; drops const/ref
  • const auto& — read-only reference, no copy
  • decltype(expr) — declared type of an expression
  • using X = T; — type alias (template-capable)
