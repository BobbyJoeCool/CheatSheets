User-Defined Types

A class bundles data (data members) with the functions that operate on it (member functions). An object is an instance of a class. class and struct are identical except for default access: struct members are public by default, class members private. Inside a member function, this points to the current object. Large classes usually declare members in a header and define them in a .cpp using ClassName::.

Conventions

  • struct for plain data bundles; class when there are invariants to protect
  • End the class definition with };
  • Member functions defined inside the class are implicitly inline
  • Common member naming: name_, m_name, or mName

A Complete Minimal Class

// counter.h
class Counter {
public:
    void increment() { ++count_; }      // defined inline
    int  value() const;                 // declared only
    void reset(int start = 0);
private:
    int count_ = 0;                     // default member initializer
};
// counter.cpp
int  Counter::value() const { return count_; }
void Counter::reset(int start) { this->count_ = start; }
// main.cpp
Counter c;                              // object on the stack
c.increment(); c.increment();
c.value();                              // 2
auto* p = &c;  p->reset(10);            // via pointer: 10

Code Explained

public: / private: — access sections
int count_ = 0; — every object starts at 0
Counter::value() — out-of-class definition
this->count_ — explicit access; usually just count_
. on objects, -> on pointers

⚠ Common Mistakes

  • Forgetting the semicolon after the closing brace: class X { … } followed by an error on the next line
  • Writing int value() const in the header but int Counter::value() (no const) in the .cpp; they're different functions
  • Making all data public in a class with invariants; anyone can break them

✓ Tips & Best Practices

  • Give every data member a default initializer so objects are never half-initialized
  • Keep the public interface small; add private helpers freely
  • Order members: public interface first, then private details

Quick Summary

  • class / struct — same thing, different default access
  • data + member functions — bundled behavior
  • this — pointer to the current object
  • Class::member — out-of-class definition
