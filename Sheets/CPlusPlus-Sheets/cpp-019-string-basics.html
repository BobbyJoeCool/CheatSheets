The Standard String

std::string from <string> is a growable, owning sequence of char that manages its own memory. It supports value semantics: copies are independent, == compares contents, and + concatenates. Most implementations use small string optimization (SSO), which stores short strings (about 15–22 chars) inside the object with no heap allocation. std::string doesn't know about encodings; it's bytes.

Notes

  • s[i] is unchecked; s.at(i) throws std::out_of_range
  • size() and length() are identical
  • "abc"s (with using namespace std::literals) is a std::string literal
  • Always null-terminated internally, so c_str() is O(1)

Creating & Using Strings

#include <string>
using namespace std::literals;

std::string a;                    // ""
std::string b = "hello";
std::string c(3, 'x');            // "xxx"
std::string d = b + ", world";    // "hello, world"

b.size();                         // 5
b.empty();                        // false
b[0];                             // 'h'
b.at(10);                         // throws std::out_of_range
b += '!';                         // "hello!"
b.push_back('?');                 // "hello!?"
b.pop_back();                     // "hello!"
b == "hello!";                    // true (content compare)
b < "help";                       // true (lexicographic)
std::string copy = b;             // independent copy

Code Explained

std::string c(3, 'x') — count + char constructor (parentheses, not braces)
+ / += — concatenation; at least one side must be std::string
at() — bounds-checked access
==, < — compare contents lexicographically
copies are deep; use std::move or references to avoid them

⚠ Common Mistakes

  • "a" + "b" doesn't compile (two pointers); make one side a std::string: "a"s + "b"
  • Using s[i] with an index from user input; use at() or check i < s.size()
  • Passing std::string by value to read-only functions; use const std::string& or std::string_view

✓ Tips & Best Practices

  • Call reserve() before building a long string in a loop
  • Use std::string_view parameters so callers can pass literals, std::string, or slices without copies
  • std::getline(std::cin, s) reads a whole line into a string

Quick Summary

  • std::string — owning, growable byte string
  • + / += — concatenate
  • at() — checked access; [] unchecked
  • size() / empty() — length checks
