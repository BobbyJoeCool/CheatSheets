Sheet 053

std::map & std::multimap

operator[] · insert · try_emplace · insert_or_assign · find · contains · erase · ordered iteration

Ordered Key/Value Store

std::map<K, V> stores unique keys in sorted order, usually as a red-black tree, so lookup, insert, and erase are O(log n) and iteration visits keys in order. std::multimap allows duplicate keys. Keys are compared with std::less<K> (<) by default; pass a custom comparator for other orderings. Elements are std::pair<const K, V>.

Lookup Caveat

  • m[key] inserts a default value if the key is missing
  • m.at(key) throws std::out_of_range if missing
  • m.contains(key) (C++20) checks without inserting
  • m.find(key) returns an iterator or m.end()

map Operations

#include <map>

std::map<std::string, int> stock{{"apple", 5}, {"pear", 2}};

stock["kiwi"] = 7;                     // insert or overwrite
stock["plum"];                         // inserts plum → 0 (!)
stock.at("apple");                     // 5
stock.contains("fig");                 // false

auto [it, inserted] = stock.insert({"apple", 9});    // no overwrite
inserted;                              // false; apple still 5
stock.try_emplace("fig", 3);           // inserts only if absent
stock.insert_or_assign("pear", 4);     // overwrite
if (auto f = stock.find("kiwi"); f != stock.end())
    std::println("{} → {}", f->first, f->second);    // kiwi → 7
stock.erase("plum");                   // by key
for (const auto& [fruit, n] : stock)   // sorted: apple fig kiwi pear
    std::print("{}:{} ", fruit, n);
auto lo = stock.lower_bound("b");      // first key >= "b" → fig

Code Explained

operator[] — creates a default value when the key is absent
insert — returns {iterator, bool}; never overwrites
try_emplace — constructs the value only if the key is new
insert_or_assign — always ends with your value stored
lower_bound — ordered search, handy for ranges of keys

⚠ Common Mistakes

  • Using m[key] to check whether a key exists; it inserts it. Use contains or find
  • Calling m[key] on a const std::map; there's no const operator[]. Use at or find
  • Modifying a key through an iterator; keys are const because changing them would break ordering

✓ Tips & Best Practices

  • Use std::less<> so find("literal") doesn't build a temporary std::string
  • Prefer try_emplace for "insert if missing" with expensive values
  • Reach for std::unordered_map when you don't need ordering and want O(1) average lookup

Quick Summary

  • std::map — sorted, unique keys, O(log n)
  • m[k] — inserts default if missing
  • contains / find / at — non-inserting lookup
  • try_emplace / insert_or_assign — explicit insert intent
