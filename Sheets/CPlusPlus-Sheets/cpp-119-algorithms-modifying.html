Transforming Ranges

Modifying algorithms write to a range: copying, transforming, filling, replacing, removing, and reordering. Output usually goes to a destination iterator that must have enough room, or to an inserter like std::back_inserter. std::remove / remove_if don't change the container's size; they shift kept elements forward and return the new logical end, which is why C++20's std::erase_if exists.

Notes

  • Destination ranges must be large enough (or use an inserter)
  • transform can write in place (out = in.begin())
  • unique removes consecutive duplicates only; sort first
  • Many algorithms have _copy variants that write elsewhere

copy, transform, replace, unique

std::vector<int> v{1, 2, 3, 4, 5, 6};
std::vector<int> out;

std::ranges::copy(v, std::back_inserter(out));                 // copy all
std::ranges::copy_if(v, std::back_inserter(out),
                     [](int x) { return x % 2 == 0; });        // 2 4 6
std::ranges::transform(v, v.begin(), [](int x) { return x * x; }); // in place
std::ranges::fill(out, 0);                                     // all 0
std::ranges::replace_if(v, [](int x) { return x > 20; }, -1);  // 1 4 9 16 -1 -1

std::erase_if(v, [](int x) { return x < 0; });                 // 1 4 9 16
std::ranges::reverse(v);                                       // 16 9 4 1
std::ranges::rotate(v, v.begin() + 1);                         // 9 4 1 16

std::vector<int> d{3, 1, 3, 2, 1};
std::ranges::sort(d);                                          // 1 1 2 3 3
auto dup = std::ranges::unique(d);         // leftover subrange
d.erase(dup.begin(), dup.end());                               // 1 2 3

Code Explained

back_inserter — grows the output as needed
transform(src, dst, f) — apply f to each element
replace_if(r, pred, value) — overwrite matches
erase_if — real removal in one call
rotate — v.begin() + 1 becomes the new first element
unique + erase — dedupe a sorted vector

⚠ Common Mistakes

  • Copying into an empty vector with v.begin() as the destination; that's UB. Use back_inserter or resize first
  • Calling std::remove and expecting the size to shrink
  • Using unique on unsorted data and expecting all duplicates gone

✓ Tips & Best Practices

  • Prefer std::erase_if over the remove-erase idiom
  • Reserve the destination when you know the output size: out.reserve(v.size());
  • Use std::ranges::to (C++23) with views to build new containers lazily instead of copying

Quick Summary

  • copy / transform — write to an output range
  • fill / replace — assign values
  • remove + erase / erase_if — actually delete
  • unique — consecutive duplicates; sort first
