Sheet 113

Variadic Templates & Fold Expressions

typename... Args · sizeof... · fold expressions (... + args) · perfect forwarding · pack indexing (C++26)

Any Number of Arguments

A variadic template takes a parameter pack of zero or more types: template <typename... Ts>. The pack is expanded with ... wherever a comma-separated list is valid. Fold expressions (C++17) reduce a pack with a binary operator in one expression. Combined with forwarding references and std::forward, packs enable perfect forwarding, which powers emplace_back and make_unique. C++26 adds direct pack indexing (Ts...[0]).

Notes

  • sizeof...(Ts) — number of elements in the pack
  • f(args...) — expand arguments; f(g(args)...) — apply g to each
  • Unary folds: (... op pack) / (pack op ...)
  • An empty pack is fine for &&, ||, and , folds

Packs, Folds, Forwarding

template <typename... Ts>
auto sum(Ts... xs) { return (xs + ... + 0); }       // binary fold
sum(1, 2, 3, 4);                                    // 10
sum();                                              // 0

template <typename... Ts>
void printAll(const Ts&... xs) {
    ((std::cout << xs << ' '), ...);                // comma fold
}
printAll("id", 7, 2.5);                             // id 7 2.5

template <typename... Ts>
constexpr std::size_t count = sizeof...(Ts);
count<int, char, double>;                           // 3

template <typename T, typename... Args>
std::unique_ptr<T> make(Args&&... args) {           // perfect forwarding
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}
template <typename... Ts> using First = Ts...[0];   // C++26 pack indexing

Code Explained

Ts... xs — function parameter pack
(xs + ... + 0) — ((x1 + x2) + x3) + 0; safe when empty
(expr, ...) — runs expr for each element in order
sizeof... — pack length at compile time
std::forward<Args>(args)... — forwards each argument with its category
Ts...[0] — first type in the pack (C++26)

⚠ Common Mistakes

  • Forgetting the parentheses around a fold; xs + ... alone doesn't compile
  • Using std::move instead of std::forward on Args&&..., which moves from lvalue arguments
  • Recursive variadic templates for simple reductions; a fold expression is shorter and compiles faster

✓ Tips & Best Practices

  • Use the comma fold (f(xs), ...) to call a function on each argument in order
  • Constrain packs: template <std::integral... Ts>
  • Use std::tuple and std::apply to store a pack and expand it later

Quick Summary

  • typename... Ts — parameter pack
  • sizeof...(Ts) — pack size
  • (xs op ...) — fold expressions (C++17)
  • std::forward<Args>(args)... — perfect forwarding
