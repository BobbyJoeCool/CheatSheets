⚠ Common Mistakes

  • Missing virtual destructor in a polymorphic base class
  • Iterator invalidation — push_back or erase while iterating a vector
  • Forgetting const on member functions that don't modify state

✓ Tips & Best Practices

  • Default to std::vector; reach for maps when you need lookup
  • Follow the rule of zero: let members manage resources
  • Use ranges algorithms and views instead of raw loops

Quick Summary

  • vector / map / unordered_map / set cover most needs
  • std::ranges algorithms + views pipelines
  • Classes: constructors, const, virtual, = default
  • Templates + concepts for generic code
