std::vector — Operations

insert · erase · std::erase_if · resize · clear · shrink_to_fit · iterator invalidation

Changing a Vector

Inserting or erasing anywhere except the end shifts every following element, so those operations are O(n). The erase-remove idiom, now wrapped by std::erase / std::erase_if (C++20), deletes all matching elements in one pass. Any operation that changes size can invalidate iterators: knowing which ones prevents the most common vector bug.

Invalidation

  • Reallocation (growth past capacity) → all iterators invalid
  • insert / erase → iterators at or after the point invalid
  • pop_back → only the last element's iterators
  • clear() keeps capacity; shrink_to_fit() may release it

Insert, Erase, Resize

std::vector<int> v{1, 2, 3, 4, 5, 6};

v.insert(v.begin() + 1, 99);          // 1 99 2 3 4 5 6
v.insert(v.end(), {7, 8});            // ... 6 7 8
v.erase(v.begin());                   // 99 2 3 4 5 6 7 8
v.erase(v.begin(), v.begin() + 2);    // 3 4 5 6 7 8
v.pop_back();                         // 3 4 5 6 7

std::erase(v, 5);                     // 3 4 6 7     (C++20)
std::erase_if(v, [](int x) { return x % 2; });   // 4 6
v.resize(4);                          // 4 6 0 0
v.resize(2);                          // 4 6
v.assign(3, 9);                       // 9 9 9
v.clear();                            // size 0, capacity kept
v.shrink_to_fit();                    // non-binding request
for (auto it = v.begin(); it != v.end(); )       // erase in a loop
    it = (*it < 0) ? v.erase(it) : it + 1;

Code Explained

insert(pos, val) — inserts before pos
erase(first, last) — removes the half-open range
std::erase_if — erase-remove in one call, returns count removed
resize(n) — grows with value-initialized elements or truncates
erase loop — use the iterator erase returns

⚠ Common Mistakes

  • for (auto it = v.begin(); it != v.end(); ++it) if (bad) v.erase(it); — it is invalid after erase. Use the returned iterator
  • Calling std::remove without erase; elements are only moved, the size doesn't change
  • Inserting at the front of a large vector in a loop, which is O(n²); use std::deque or build reversed

✓ Tips & Best Practices

  • Use std::erase_if for every "remove all matching" task
  • If order doesn't matter, erase by swapping with the last element then pop_back (O(1))
  • Use v.insert(v.end(), other.begin(), other.end()) or append_range (C++23) to concatenate

Quick Summary

  • insert / erase — O(n) middle edits
  • std::erase_if — remove matching elements (C++20)
  • resize / clear / shrink_to_fit — size control
  • invalidation — use the iterator erase returns
