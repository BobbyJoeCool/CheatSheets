Comparison & Three-Way (<=>)

== != < > <= >= · <=> · std::strong_ordering · std::partial_ordering · = default comparisons · std::cmp_less

Comparing Values

The six relational operators return bool. C++20 added the three-way comparison operator <=> ("spaceship"), which returns an ordering object that says whether the left side is less, equal, or greater. Writing auto operator<=>(const T&) const = default; gives a class all six comparisons, memberwise, in one line. A defaulted operator== is generated alongside it.

Ordering Types

  • std::strong_ordering — equal means interchangeable (ints)
  • std::weak_ordering — equivalent but distinguishable (case-insensitive strings)
  • std::partial_ordering — some values are unordered (NaN)
  • Compare the result to 0: (a <=> b) < 0

Relational & Spaceship

#include <compare>

3 == 3;              // true
3 != 4;              // true
2 < 5;  5 >= 5;      // true, true

auto r = 3 <=> 5;    // std::strong_ordering::less
r < 0;               // true

struct Version {
    int major, minor, patch;
    auto operator<=>(const Version&) const = default; // all 6 ops
};
Version a{1, 4, 0}, b{1, 10, 2};
a < b;               // true  (compares major, then minor, ...)
a == b;              // false
-1 < 0u;             // false!  -1 converts to unsigned
std::cmp_less(-1, 0u);         // true (C++20, <utility>)

Code Explained

<=> — one comparison yields less / equal / greater
= default — memberwise comparison in declaration order
partial_ordering::unordered — result when NaN is involved
-1 < 0u — mixed signedness converts -1 to a huge unsigned value
std::cmp_less — mathematically correct mixed-sign comparison

⚠ Common Mistakes

  • Writing if (x = 5); that assigns and is always true. Use ==, and enable -Wparentheses
  • Chaining comparisons like math: 0 < x < 10 means (0 < x) < 10, always true. Write 0 < x && x < 10
  • Comparing floats with == after computation; use a tolerance

✓ Tips & Best Practices

  • Default operator<=> on value types; reorder members to change comparison priority
  • Use std::tie(a.x, a.y) < std::tie(b.x, b.y) for ad-hoc lexicographic compares in older code
  • Turn on -Wsign-compare to catch signed/unsigned comparisons

Quick Summary

  • == != < > <= >= — return bool
  • <=> — three-way comparison (C++20)
  • = default — generate all comparisons
  • std::cmp_less — safe mixed-sign compare
