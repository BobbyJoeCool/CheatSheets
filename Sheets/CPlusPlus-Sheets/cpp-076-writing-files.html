Sheet 076

Writing & Appending Files

std::ofstream · std::ios::app · std::fstream · open modes · flush · std::print to a file

Output File Streams

std::ofstream writes files with <<, just like std::cout. By default it truncates an existing file; open with std::ios::app to append. std::fstream can read and write the same file. Output is buffered and flushed when the stream is destroyed, so data is safe on normal exit. C++23's std::print writes to a FILE*, and std::format_to works with a stream iterator.

Notes

  • Default mode for ofstream: out | trunc
  • std::ios::app — every write goes to the end
  • Check if (!out) after opening and after writing
  • flush() forces buffered data to the OS

Writing & Appending

#include <fstream>

std::ofstream out{"report.txt"};                  // create / truncate
if (!out) throw std::runtime_error("cannot write report.txt");
out << "Name,Score\n";
for (const auto& [name, score] : results)
    out << name << ',' << score << '\n';

std::ofstream log{"app.log", std::ios::app};      // append
log << std::format("[{}] started\n", timestamp());
log.flush();                                      // push to disk now

std::fstream db{"data.bin", std::ios::in | std::ios::out | std::ios::binary};

std::FILE* f = std::fopen("out.txt", "w");
std::println(f, "pi = {:.3f}", 3.14159);          // C++23 print to FILE*
std::fclose(f);

Code Explained

ofstream{"report.txt"} — truncates if the file exists
loop with structured bindings — one CSV row per entry
std::ios::app — preserves existing content
std::fstream with in | out — read and write one file
std::println(FILE*, …) — formatted output to C files

⚠ Common Mistakes

  • Opening a log with plain ofstream and wiping it every run; use std::ios::app
  • Using std::endl on every line of a large file; each one flushes. Use '\n'
  • Assuming data is on disk right after <<; it may still be buffered if the program crashes

✓ Tips & Best Practices

  • Write to a temporary file, then std::filesystem::rename it over the original for atomic saves
  • Check out after the last write to catch disk-full errors
  • Use std::format to build each line, then write it in one <<

Quick Summary

  • std::ofstream — write (truncates by default)
  • std::ios::app — append
  • std::fstream — read + write
  • flush() — force buffered data out
