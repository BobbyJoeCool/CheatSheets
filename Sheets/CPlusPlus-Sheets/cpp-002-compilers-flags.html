The Big Three Compilers

Three compilers dominate: GCC (g++), Clang (clang++, also the default on macOS via Xcode), and MSVC (cl.exe, part of Visual Studio). All three implement most of C++23, but library support lags the language, so check cppreference's compiler support page for newer features. Flags pick the standard, the warning level, the optimization level, and whether to emit debug info.

Install

  • Linux: sudo apt install g++ clang (or your distro's equivalent)
  • macOS: xcode-select --install (Clang) or brew install gcc llvm
  • Windows: Visual Studio "Desktop development with C++", or MSYS2 for GCC
  • Verify: g++ --version, clang++ --version, cl (from a Developer Prompt)

Typical Compile Commands

# Debug build: all warnings, debug symbols, no optimization
g++ -std=c++23 -Wall -Wextra -Wpedantic -g -O0 main.cpp -o app

# Release build: optimized, warnings are errors
clang++ -std=c++23 -Wall -Wextra -Werror -O2 -DNDEBUG main.cpp -o app

# Multiple files + include dir + link a library
g++ -std=c++23 -Iinclude src/*.cpp -Llib -lfmt -o app

# Runtime bug hunting with sanitizers
g++ -std=c++23 -g -fsanitize=address,undefined main.cpp -o app

# MSVC equivalent of a debug build
cl /std:c++latest /W4 /Zi /EHsc main.cpp

Code Explained

-std=c++23 — language standard (c++20, c++26 / c++2c also exist)
-Wall -Wextra — enable the common warning sets; -Wpedantic flags non-standard extensions
-O0 / -O2 — no optimization vs. full safe optimization
-g — embed debug info for gdb / lldb
-I / -L / -l — include path, library path, library name
/EHsc — MSVC's standard exception handling model

⚠ Common Mistakes

  • Forgetting -std=c++20/23 on older GCC, so new features fail with confusing errors
  • Shipping -O0 builds; unoptimized C++ can be 10× slower than -O2
  • Ignoring warnings; -Wall warnings like "unused variable" or "comparison of signed and unsigned" often point to real bugs

✓ Tips & Best Practices

  • Keep two build configs: debug (-g -O0 -fsanitize=…) and release (-O2 -DNDEBUG)
  • Add -Werror in CI so new warnings break the build instead of piling up
  • Paste code into Compiler Explorer to check a feature on GCC, Clang, and MSVC at once

Quick Summary

  • g++ / clang++ / cl — the three major compilers
  • -std=c++23 — choose the language standard
  • -Wall -Wextra -Werror — warnings on, and fatal in CI
  • -O2 -DNDEBUG — typical release flags
