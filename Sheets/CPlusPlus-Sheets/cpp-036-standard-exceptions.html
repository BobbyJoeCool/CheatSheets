Standard Exception Hierarchy

std::exception · what() · std::logic_error · std::runtime_error · std::out_of_range · std::bad_alloc · <stdexcept>

Built-In Exception Types

The standard library's exceptions all derive from std::exception, which has one virtual function, what(). Two main branches exist: std::logic_error for bugs that could have been prevented (bad arguments, out-of-range indexes) and std::runtime_error for conditions only detectable at run time (I/O failures, overflow). Most live in <stdexcept>; a few have their own headers.

Headers

  • <exception> — std::exception, std::terminate
  • <stdexcept> — logic_error, runtime_error families
  • <new> — std::bad_alloc
  • <system_error> — std::system_error with an error_code

Hierarchy in Practice

#include <stdexcept>
#include <vector>

std::vector<int> v{1, 2, 3};
try {
    v.at(10);                              // throws std::out_of_range
} catch (const std::out_of_range& e) {
    std::println("{}", e.what());          // vector::_M_range_check: ...
}

try { std::stoi("abc"); }
catch (const std::invalid_argument&) {}    // from stoi

std::size_t huge = 1ull << 62;
try { auto p = new int[huge]; }
catch (const std::bad_alloc&) {}           // bad_array_new_length
try { std::optional<int> o; o.value(); }
catch (const std::bad_optional_access&) {}
throw std::runtime_error(std::format("cannot open {}", path));

Code Explained

v.at(10) — checked access throws out_of_range
std::stoi — throws invalid_argument or out_of_range
new failure — throws bad_alloc (unless nothrow)
bad_optional_access / bad_any_cast — misuse of vocabulary types
std::format in the message — include the failing value

⚠ Common Mistakes

  • Expecting v[10] to throw; only .at() checks bounds. operator[] out of range is UB
  • Catching std::exception everywhere and swallowing errors silently; log or rethrow
  • Throwing raw strings or ints (throw "oops";); they don't derive from std::exception

✓ Tips & Best Practices

  • Throw std::invalid_argument for bad caller input and std::runtime_error for environment failures
  • std::filesystem throws filesystem_error; overloads taking std::error_code& don't throw
  • Put context in the message: what failed and with which value

Quick Summary

  • std::exception — root; what() returns the message
  • logic_error — preventable bugs
  • runtime_error — run-time failures
  • bad_alloc — memory exhaustion
