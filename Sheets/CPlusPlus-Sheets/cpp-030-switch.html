switch

switch · case · default · fallthrough · [[fallthrough]] · switch with initializer · -Wswitch with enums

Multi-Way Branch on a Value

switch jumps to the case label matching an integral or enum value. Execution falls through into the next case unless you break, so mark intentional fall-through with [[fallthrough]]. switch can't test strings or ranges directly. Since C++17 it accepts an initializer like if. Compilers warn (-Wswitch) when a switch over an enum misses a value and has no default.

Rules

  • case labels must be constant expressions
  • Duplicate case values don't compile
  • Declaring a variable in a case needs braces { }
  • Works on int, char, enum, bool — not std::string

switch Patterns

enum class Cmd { Start, Stop, Pause, Resume };
switch (cmd) {
    case Cmd::Start:
        launch();
        break;
    case Cmd::Pause:
        save();
        [[fallthrough]];               // intentional
    case Cmd::Stop:
        halt();                        // runs for Pause and Stop
        break;
    case Cmd::Resume: {                // braces: local variable
        resume(now());
        break;
    }
}                                      // no default → -Wswitch helps
switch (char c = next(); c) {          // initializer (C++17)
    case 'y': case 'Y': return true;   // multiple labels
    case 'n': case 'N': return false;
    default:            return ask();
}

Code Explained

break — leave the switch; omitting it falls through
[[fallthrough]] — silences the fall-through warning on purpose
{ } around a case — required when you declare variables
stacked labels — several values share one body
return inside a case — also ends the switch

⚠ Common Mistakes

  • Forgetting break, so one case runs into the next
  • Adding default: to enum switches; it hides the warning when someone adds a new enumerator
  • Jumping past an initialized variable: case 1: int x = 5; break; case 2: doesn't compile without braces

✓ Tips & Best Practices

  • Turn on -Wimplicit-fallthrough so missing breaks are reported
  • For enum switches, handle every value and put the "impossible" path after the switch
  • Return directly from cases in small mapping functions to avoid break noise

Quick Summary

  • switch (v) — jump to matching case
  • break — stop fall-through
  • [[fallthrough]] — intentional fall-through
  • enums + no default — compiler checks completeness
