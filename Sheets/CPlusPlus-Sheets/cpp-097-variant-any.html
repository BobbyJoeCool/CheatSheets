std::variant & std::any

std::variant · std::visit · overloaded lambdas pattern · std::holds_alternative · std::get_if · std::any / any_cast

Type-Safe Unions

std::variant<Ts...> (C++17) holds exactly one value from a fixed list of types and always knows which. Access it with std::visit (handles every alternative, checked at compile time), std::get_if (pointer or null), or std::get (throws bad_variant_access on the wrong type). std::any holds a value of any copyable type, discovered at run time with any_cast.

Notes

  • v.index() — which alternative is active (0-based)
  • Default-constructs the first alternative; use std::monostate for "empty"
  • std::visit with the overloaded lambda pattern is idiomatic
  • Prefer variant (closed set) over any (open set)

variant, visit, any

#include <variant>
#include <any>
using Value = std::variant<int, double, std::string>;
Value v = 3.5;
v.index();                                  // 1 (double)
std::holds_alternative<double>(v);          // true
std::get<double>(v);                        // 3.5
if (auto* s = std::get_if<std::string>(&v)) {}   // nullptr here
v = "text";                                 // now holds std::string
template <class... Fs> struct overloaded : Fs... { using Fs::operator()...; };
std::visit(overloaded{
    [](int i)                { std::println("int {}", i); },
    [](double d)             { std::println("double {}", d); },
    [](const std::string& s) { std::println("string {}", s); },
}, v);                                      // string text
std::any a = std::string{"hi"};             // any copyable type
std::any_cast<std::string>(a);              // "hi"

Code Explained

index() / holds_alternative — query the active type
std::get<T> — throws if T isn't active
std::get_if<T>(&v) — returns pointer or nullptr
overloaded — combines lambdas into one visitor (no deduction guide needed since C++20)
any_cast<T>(&a) — pointer form doesn't throw

⚠ Common Mistakes

  • std::get<int>(v) without checking; throws bad_variant_access when another type is active
  • Forgetting an alternative in visit; it won't compile, which is a feature, so don't paper over it with an auto catch-all too early
  • variant<std::string, bool> v = "x"; — before C++20 this picked bool; be explicit with std::string{"x"}

✓ Tips & Best Practices

  • Model state machines and AST nodes as std::variant instead of class hierarchies
  • Keep overloaded in a shared utility header
  • Avoid std::any in public APIs; it hides the type contract

Quick Summary

  • std::variant<Ts...> — one of a fixed set of types
  • std::visit + overloaded — exhaustive handling
  • get_if — safe checked access
  • std::any — any type, checked at run time
