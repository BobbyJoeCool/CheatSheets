What C++ Is

C++ is a compiled, statically typed, multi-paradigm language created by Bjarne Stroustrup at Bell Labs, starting in 1979 as "C with Classes". It adds classes, templates, exceptions, and a large standard library to C while keeping C's direct access to memory and hardware. The guiding rule is the zero-overhead principle: you don't pay for what you don't use, and what you do use is as fast as hand-written code. The language is standardized by ISO WG21, which ships a new standard every three years.

At a Glance

  • Files: .cpp / .cc / .cxx for source, .h / .hpp for headers, .cppm / .ixx for modules
  • Used for games, browsers, databases, trading systems, embedded, compilers, and HPC
  • Compiled ahead of time to native machine code; there is no VM or garbage collector
  • The C++ Core Guidelines (Stroustrup & Sutter) are the de facto style rulebook

Hello, World (C++23)

#include <print>                 // C++23: std::print / std::println

int main() {
    std::println("Hello, World!");   // Hello, World!
}

// Pre-C++23 equivalent you'll see everywhere:
#include <iostream>

int main() {
    std::cout << "Hello, World!\n";  // Hello, World!
    return 0;
}

// $ g++ -std=c++23 hello.cpp -o hello && ./hello

Code Explained

#include <print> — pulls in the standard header that declares std::println
int main() — program entry point; returning from it ends the program
std:: — every standard library name lives in the std namespace
return 0; — optional in main only; falling off the end returns 0
-std=c++23 — tells the compiler which standard to compile against

⚠ Common Mistakes

  • Treating C++ as "C with classes": modern C++ avoids raw new, C arrays, and macros in everyday code
  • Learning from pre-2011 tutorials; they teach manual memory management that smart pointers replaced
  • Assuming every compiler supports the newest standard fully; check the support tables first

✓ Tips & Best Practices

  • Bookmark cppreference.com; each page marks which standard added a feature (e.g. "since C++20")
  • Try snippets on Compiler Explorer (godbolt.org) to compare compilers and see the generated assembly
  • Turn on warnings from day one: -Wall -Wextra catches many beginner bugs

Quick Summary

  • C++ — compiled, multi-paradigm, zero-overhead systems language
  • WG21 — ISO committee; new standard every 3 years
  • C++23 — current baseline for this set; C++26 flagged where relevant
  • std::println — the modern Hello, World
