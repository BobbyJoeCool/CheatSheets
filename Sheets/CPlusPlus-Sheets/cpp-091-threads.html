Threads

std::thread · join / detach · std::jthread · std::stop_token · passing arguments · hardware_concurrency

Running Code in Parallel

std::thread (<thread>) starts a new OS thread running any callable. You must join() it (wait for it) or detach() it before the std::thread object is destroyed, or the program calls std::terminate. C++20's std::jthread joins automatically in its destructor and supports cooperative cancellation through a std::stop_token, so it's the better default.

Notes

  • Arguments are copied into the thread; use std::ref to pass references
  • std::thread::hardware_concurrency() — hint of available cores
  • Exceptions escaping a thread function call std::terminate
  • Threads share memory: unsynchronized writes are data races (UB)

thread & jthread

#include <thread>

void work(int id, std::string& out) { out = std::format("worker {}", id); }

std::string result;
std::thread t{work, 1, std::ref(result)};   // pass a reference with ref()
t.join();                                   // wait; result == "worker 1"

std::jthread j{[](std::stop_token st) {
    while (!st.stop_requested()) {
        poll();
        std::this_thread::sleep_for(100ms);
    }
}};
j.request_stop();                           // ask it to finish
                                            // destructor joins
unsigned cores = std::thread::hardware_concurrency();   // e.g. 8
std::this_thread::get_id();                 // current thread id

Code Explained

std::thread{f, args...} — starts immediately
std::ref(result) — otherwise the thread gets a copy
join() — blocks until the thread finishes
std::jthread — passes a stop_token if the callable accepts one
request_stop() — cooperative; the thread must check the token

⚠ Common Mistakes

  • Letting a joinable std::thread go out of scope; the program terminates. Use jthread or join
  • Passing a reference argument without std::ref, so the thread modifies a copy
  • Detaching threads that use local variables of the creating function; they dangle

✓ Tips & Best Practices

  • Default to std::jthread in new code
  • Prefer higher-level tools (std::async, thread pools, parallel algorithms) to raw threads
  • Catch exceptions inside the thread function and hand them back via std::promise or a queue

Quick Summary

  • std::thread — must join or detach
  • std::jthread — auto-join + stop token (C++20)
  • std::ref — pass references to threads
  • stop_token — cooperative cancellation
