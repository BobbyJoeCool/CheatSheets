Sheet 110

Function Templates

template<typename T> · argument deduction · explicit template args · instantiation · abbreviated templates (auto params)

Generic Functions

A function template is a blueprint for a family of functions: template <typename T> introduces a type parameter, and the compiler instantiates a concrete function for each set of types it's called with. Template arguments are usually deduced from the call's arguments. C++20 abbreviated templates let you write auto parameters directly, and concepts can constrain them.

Notes

  • typename and class are interchangeable in parameter lists
  • Templates must be visible where used: define them in headers
  • Deduction ignores implicit conversions: max(1, 2.0) fails
  • Specify explicitly when needed: max<double>(1, 2.0)

Function Templates

template <typename T>
T maxOf(T a, T b) { return a < b ? b : a; }

maxOf(3, 7);                 // T = int → 7
maxOf(2.5, 1.5);             // T = double → 2.5
maxOf<std::string>("a", "b");// explicit T → "b"
// maxOf(1, 2.0);            // ERROR: T deduced as int and double

template <typename T, typename U>
auto add(T a, U b) { return a + b; }   // return type deduced
add(1, 2.5);                 // 3.5 (double)

auto printAll(const auto& container) { // abbreviated (C++20)
    for (const auto& x : container) std::print("{} ", x);
}
printAll(std::vector{1, 2, 3});        // 1 2 3

void sink(std::integral auto n);       // constrained auto (C++20)

Code Explained

template <typename T> — T is a placeholder type
each distinct T creates a separate instantiation
mixed argument types — deduction conflict; use two parameters or explicit args
auto parameter — shorthand for a template parameter
std::integral auto — only integer types accepted

Syntax

⚠ Common Mistakes

  • Defining a template in a .cpp file and calling it from another; you get "undefined reference". Put it in the header
  • Expecting implicit conversions during deduction (maxOf(1, 2.0))
  • Huge error messages from unconstrained templates; add concepts to get clear errors

✓ Tips & Best Practices

  • Constrain templates with concepts (std::totally_ordered T) to document requirements
  • Use std::type_identity_t<T> on a parameter to exclude it from deduction
  • Look at instantiations with C++ Insights (cppinsights.io)

Quick Summary

  • template <typename T> — generic function
  • deduction — T inferred from arguments
  • f<T>(…) — explicit template arguments
  • auto params — abbreviated templates (C++20)
