std::filesystem

fs::path · operator/ · exists · create_directories · directory_iterator · file_size · copy / remove

Paths & Directories

<filesystem> (C++17) provides portable path manipulation and file system operations. std::filesystem::path handles separators and joins with /. Free functions query and change the file system: existence, size, directories, copy, rename, remove. Most functions have two overloads: one that throws filesystem_error and one that takes a std::error_code& and reports errors without throwing.

Notes

  • Alias it: namespace fs = std::filesystem;
  • path / "sub" / "file.txt" joins with the right separator
  • directory_iterator — one level; recursive_directory_iterator — all levels
  • Iteration order is unspecified

std::filesystem Basics

#include <filesystem>
namespace fs = std::filesystem;

fs::path p = fs::path{"logs"} / "2026" / "app.log";   // logs/2026/app.log
p.filename();        // "app.log"
p.stem();            // "app"
p.extension();       // ".log"
p.parent_path();     // "logs/2026"

fs::create_directories(p.parent_path());   // mkdir -p
fs::exists(p);                             // true / false
if (fs::is_regular_file(p)) fs::file_size(p);   // bytes
fs::copy_file(p, "backup.log", fs::copy_options::overwrite_existing);
fs::rename("backup.log", "old.log");
fs::remove("old.log");                     // true if removed

for (const auto& e : fs::directory_iterator{"logs"})
    std::println("{} {}", e.path().filename().string(), e.is_directory());
std::error_code ec;
fs::remove_all("tmp", ec);                 // no throw; check ec

Code Explained

/ — joins path components portably
filename / stem / extension — decompose a path
create_directories — creates every missing level
directory_iterator — entries in one folder
error_code overload — report errors without exceptions

⚠ Common Mistakes

  • Concatenating with + and hard-coded "/" or "\\"; use operator/
  • Calling fs::file_size on a directory, which throws
  • Checking exists(p) and then opening it; the file can change in between (race). Just open and handle failure

✓ Tips & Best Practices

  • Use p.string() / p.u8string() when printing or passing to APIs that need text
  • Filter by extension: if (e.path().extension() == ".cpp")
  • Use fs::weakly_canonical(p) to normalize paths that may not exist yet

Quick Summary

  • fs::path + / — portable paths
  • exists / file_size / create_directories — queries and setup
  • directory_iterator — list a folder
  • error_code overloads — no-throw variants
