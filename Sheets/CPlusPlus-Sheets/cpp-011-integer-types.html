Integer Types

Whole Numbers

C++ has several integer types whose sizes are implementation-defined, only guaranteed in minimum ranges. When exact width matters, use the fixed-width aliases from <cstdint>. Signed overflow is undefined behavior; unsigned arithmetic wraps around modulo 2ⁿ. std::size_t is the unsigned type returned by sizeof and container size().

Guarantees

  • char ≤ short ≤ int ≤ long ≤ long long
  • int ≥ 16 bits (32 in practice); long long ≥ 64 bits
  • long is 32 bits on Windows, 64 on Linux/macOS (LP64)
  • Since C++20, signed integers are defined as two's complement

Literals & Limits

#include <cstdint>
#include <limits>

int        dec  = 1'000'000;      // digit separators (C++14)
int        hex  = 0xFF;           // 255
int        oct  = 017;            // 15  (leading 0 = octal!)
int        bin  = 0b1010;         // 10
unsigned   u    = 42u;            // unsigned int
long long  big  = 9'000'000'000LL;
std::size_t n   = 10uz;           // size_t literal (C++23)

std::int32_t  i32 = -5;           // exactly 32 bits
std::uint8_t  byte = 255;
std::int64_t  ms  = 1'700'000'000'000;

std::numeric_limits<int>::max();  // 2147483647
std::numeric_limits<int>::min();  // -2147483648
unsigned w = 0u - 1;              // 4294967295 (wraps)
int ov = INT_MAX + 1;             // UB: signed overflow

Code Explained

1'000'000 — ' separators are ignored by the compiler
017 — leading zero means octal, a classic trap
LL / u / uz — literal suffixes choose the type
int32_t — exact width; int_fast32_t / int_least32_t also exist
unsigned wraps; signed overflow is UB (optimizer assumes it never happens)

⚠ Common Mistakes

  • Comparing signed and unsigned: -1 < 0u is false because -1 converts to a huge unsigned value
  • Looping for (unsigned i = n - 1; i >= 0; --i); the condition is always true, so it never ends
  • Assuming long is 64 bits; on Windows it's 32. Use std::int64_t

✓ Tips & Best Practices

  • Use std::ssize(container) (C++20) to get a signed size and avoid mixed comparisons
  • Check overflow-prone math with -fsanitize=undefined
  • Use std::cmp_less(a, b) (C++20) to compare mixed signed/unsigned values safely

Quick Summary

  • int — default integer, ≥ 32 bits in practice
  • <cstdint> — int32_t, uint64_t for exact widths
  • signed overflow — UB; unsigned — wraps
  • 0x / 0b / 1'000 — hex, binary, separators
