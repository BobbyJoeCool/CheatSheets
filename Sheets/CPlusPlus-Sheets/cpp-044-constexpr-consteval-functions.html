Sheet 044

constexpr & consteval Functions

constexpr functions · consteval · if constexpr · std::is_constant_evaluated · constexpr std::vector / std::string

Compile-Time Functions

A constexpr function can run at compile time when given constant arguments and is used where a constant is required; otherwise it runs normally at run time. A consteval function (C++20) must run at compile time, which makes it an "immediate function". Since C++20, constexpr code can use try, virtual, dynamic allocation that's freed before the end, and even std::vector and std::string.

Detecting Context

  • if consteval { … } (C++23) — branch taken during constant evaluation
  • std::is_constant_evaluated() (C++20) — older equivalent
  • if constexpr (cond) — compile-time branch on a constant
  • constexpr functions are implicitly inline

constexpr & consteval

constexpr int fib(int n) {
    return n < 2 ? n : fib(n - 1) + fib(n - 2);
}
constexpr int f10 = fib(10);          // 55, computed by compiler
static_assert(fib(10) == 55);

consteval int square(int x) { return x * x; }
constexpr int s = square(8);          // 64
// int bad = square(readInt());       // ERROR: not a constant
constexpr std::size_t countWords(std::string_view s) {
    std::vector<std::string_view> words;   // OK in C++20 constexpr
    for (auto w : s | std::views::split(' ')) words.emplace_back(w);
    return words.size();
}
static_assert(countWords("compile time strings") == 3);
template <class T> auto describe(T v) {
    if constexpr (std::is_integral_v<T>) return "integer";
    else return "other";
}

Code Explained

same fib at run time — constexpr functions are dual-use
consteval — calling it with a run-time value is an error
std::vector in constexpr — allowed if freed before evaluation ends
if constexpr — the discarded branch isn't instantiated

⚠ Common Mistakes

  • Assuming a constexpr call always happens at compile time; assign it to a constexpr variable to force it
  • Calling a non-constexpr function inside a constexpr function used in a constant expression
  • Returning a std::vector from a constexpr function into a constexpr variable; allocations can't survive constant evaluation

✓ Tips & Best Practices

  • Make pure helper functions constexpr by default; it costs nothing at run time
  • Use consteval for compile-time validation helpers such as format-string checking
  • Move lookup tables to compile time with constexpr std::array built by a constexpr function

Quick Summary

  • constexpr function — usable at compile or run time
  • consteval — compile time only (C++20)
  • if constexpr — discard branches in templates
  • static_assert(f(x) == y) — test at compile time
