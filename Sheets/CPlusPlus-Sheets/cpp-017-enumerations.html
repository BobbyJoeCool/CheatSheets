Enumerations

enum · enum class · underlying type : uint8_t · using enum · std::to_underlying · enum flags pattern

Named Constants

An enumeration defines a type with a fixed set of named values. Old-style enum names leak into the surrounding scope and convert silently to int. Scoped enums (enum class) keep names inside the type and require explicit conversion, so they're the default in modern code. You can choose the underlying type to control size.

Key Points

  • Values start at 0 and count up unless assigned
  • enum class requires Color::Red
  • using enum Color; (C++20) brings names into scope locally
  • std::to_underlying(e) (C++23) converts to the integer value

enum vs enum class

enum Fruit { Apple, Banana };              // unscoped: names leak
int f = Banana;                            // 1, implicit conversion

enum class Status : std::uint8_t {         // scoped, 1 byte
    Pending = 1, Active, Closed = 10       // 1, 2, 10
};
Status s = Status::Active;
// int bad = s;                            // ERROR: no implicit conv.
auto v = std::to_underlying(s);            // 2 (uint8_t)
Status t = static_cast<Status>(10);        // Status::Closed

switch (s) {
    using enum Status;                     // C++20
    case Pending: break;
    case Active:  break;
    case Closed:  break;                   // -Wswitch warns if missing
}
enum class Perm : unsigned { Read = 1, Write = 2, Exec = 4 };
constexpr Perm operator|(Perm a, Perm b) {
    return Perm(std::to_underlying(a) | std::to_underlying(b));
}
auto rw = Perm::Read | Perm::Write;        // flags pattern

Code Explained

enum Fruit — names are visible in the enclosing scope

std::to_underlying — cleaner than static_cast<std::underlying_type_t<E>>
using enum — avoids repeating Status:: inside a switch
operator| — opt-in bitwise ops for flag enums

⚠ Common Mistakes

  • Using unscoped enums in headers; Red from one enum can clash with Red in another
  • Casting an out-of-range integer to an enum without a fixed underlying type, which can be UB
  • Adding a default: to a switch over an enum; it hides the -Wswitch warning when new values are added

✓ Tips & Best Practices

  • Make every new enum an enum class with an explicit underlying type when size matters
  • Add a Count sentinel as the last value to size arrays indexed by the enum
  • Convert to strings with a constexpr lookup function or C++26 reflection when available
