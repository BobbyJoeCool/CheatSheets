while & do-while

while · do-while · while (std::cin >> x) · sentinel loops · infinite loops

Condition-Driven Loops

A while loop checks its condition before each iteration, so the body may run zero times. A do-while checks after each iteration, so the body runs at least once, which suits menus and "try then check" logic. Use these loops when the number of iterations isn't known up front: reading input until EOF, waiting for a state, or processing a queue until it's empty.

Notes

  • do { … } while (cond); needs the trailing semicolon
  • while (true) with break is a common "loop and a half"
  • The condition can declare a variable: while (auto x = next())
  • Streams in conditions are true while reads succeed

while & do-while

int n = 27, steps = 0;
while (n != 1) {                       // Collatz
    n = (n % 2 == 0) ? n / 2 : 3 * n + 1;
    ++steps;
}                                      // steps == 111

int value;
while (std::cin >> value) {            // read until EOF / bad input
    total += value;
}

std::string line;
while (std::getline(file, line)) {}    // line by line
while (auto job = queue.try_pop()) {   // optional-like condition
    process(*job);
}
int choice;
do {
    showMenu();
    std::cin >> choice;
} while (choice != 0);                 // runs at least once

Code Explained

while (n != 1) — may run zero times
while (cin >> value) — stops on EOF or a non-number
while (getline(…)) — the idiomatic line-reading loop
while (auto job = …) — condition variable, tested for truthiness
do … while — menu loop runs before checking

⚠ Common Mistakes

  • Forgetting to change the loop variable, causing an infinite loop
  • while (!file.eof()) processes the last line twice or reads garbage; loop on the read itself
  • Missing ; after while (cond) in a do-while, which is a compile error

✓ Tips & Best Practices

  • If you can express the loop as a for with a clear counter, do that instead
  • Add a maximum-iteration guard to loops that wait on external state
  • Put the exit condition in the loop header when possible; break in the middle is harder to read

Quick Summary

  • while (c) — test first, 0+ runs
  • do {} while (c); — test last, 1+ runs
  • while (cin >> x) — read until failure
  • while (auto v = f()) — declare in the condition
