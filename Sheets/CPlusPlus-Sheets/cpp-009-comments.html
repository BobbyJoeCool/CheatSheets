Sheet 009

Comments

// · /* */ · Doxygen /** */ · @param · @return · @brief · #if 0 blocks

Comment Forms

C++ has two comment styles inherited from C and C99: // runs to the end of the line, and /* … */ spans any number of lines. Comments are removed before compilation and never affect the program. Doxygen-style comments (/// or /** … */) placed before a declaration are picked up by IDEs for hover text and by Doxygen to generate HTML/PDF API docs.

Rules

  • /* … */ comments do not nest
  • #if 0 … #endif safely disables code that contains block comments
  • Comments explain why; the code shows what
  • IDE hover (VS Code, CLion, Visual Studio) reads /// and /** */

Comment Styles

// Single-line comment
int retries = 3;   // trailing comment

/* Block comment
   spanning several lines */

/**
 * @brief  Compute the average of a list of scores.
 * @param  scores  Values to average; must not be empty.
 * @return The arithmetic mean.
 * @throws std::invalid_argument if scores is empty.
 */
double average(std::span<const double> scores);
/// Short doc comment for a single declaration.
int clamp_percent(int v);
#if 0   // disabled block: may contain /* comments */
legacy_code();
#endif

Code Explained

// — everything to end of line is ignored
/** … */ — Doxygen block attached to the next declaration
@brief / @param / @return — common Doxygen tags
/// — one-line Doxygen comment
#if 0 — preprocessor removes the block entirely

⚠ Common Mistakes

  • Nesting /* … /* … */ … */; the first */ ends the comment and the rest becomes code
  • Commenting out code with // on every line and leaving it in; delete it, version control remembers
  • Writing comments that restate the code (i++; // increment i)

✓ Tips & Best Practices

  • Document the contract in the header: preconditions, units, ownership, thrown exceptions
  • Use [[deprecated("use foo2")]] instead of a comment so the compiler warns callers
  • Keep TODO(name): comments searchable with a consistent prefix

Quick Summary

  • // — single-line comment
  • /* */ — block comment (no nesting)
  • /** @brief */ — Doxygen API docs and IDE hover
  • #if 0 — disable a block of code
