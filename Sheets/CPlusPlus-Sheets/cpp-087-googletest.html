Google's Test Framework

GoogleTest (gtest) is the most widely used C++ unit-testing framework, and gMock (bundled with it) adds mock objects. Tests are written with macros: TEST(Suite, Name) for standalone tests and TEST_F(Fixture, Name) for tests sharing setup. EXPECT_* assertions record a failure and keep going; ASSERT_* stop the current test. CMake's gtest_discover_tests registers every test with CTest.

Setup

  • vcpkg: gtest; CMake: find_package(GTest CONFIG REQUIRED)
  • Link GTest::gtest_main to get a ready-made main()
  • Run: ctest --test-dir build or the test binary directly
  • Filter: ./tests --gtest_filter=Cart.*

Tests & a Fixture

#include <gtest/gtest.h>
#include "cart.h"

TEST(PriceTest, AppliesDiscount) {
    EXPECT_DOUBLE_EQ(applyDiscount(100.0, 0.2), 80.0);
    EXPECT_THROW(applyDiscount(100.0, 1.5), std::invalid_argument);
}
class CartTest : public ::testing::Test {
protected:
    void SetUp() override { cart.add("apple", 2); }   // before each test
    Cart cart;
};
TEST_F(CartTest, CountsItems) {
    ASSERT_EQ(cart.size(), 1u);                        // stop if wrong
    EXPECT_EQ(cart.quantity("apple"), 2) << "apples should be 2";
}

Code Explained

TEST(Suite, Name) — a standalone test case
EXPECT_DOUBLE_EQ — floating comparison with ULP tolerance
EXPECT_THROW(stmt, Type) — checks an exception type
fixture SetUp() — runs before every TEST_F
<< "msg" — extra context printed on failure

⚠ Common Mistakes

  • Using ASSERT_* in a helper that returns a value; ASSERT returns void from the function. Use EXPECT or return status
  • Comparing floats with EXPECT_EQ; use EXPECT_DOUBLE_EQ or EXPECT_NEAR
  • Tests that depend on run order or shared global state

✓ Tips & Best Practices

  • Use TEST_P with INSTANTIATE_TEST_SUITE_P for table-driven tests
  • Mock interfaces with gMock: MOCK_METHOD(int, get, (std::string_view), (override));
  • Run tests under -fsanitize=address,undefined in CI

Quick Summary

  • TEST / TEST_F — define tests
  • EXPECT_* — continue; ASSERT_* — stop
  • fixtures — shared setup via SetUp()
  • gtest_discover_tests — CTest integration
