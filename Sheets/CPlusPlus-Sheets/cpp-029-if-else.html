if / else & Conditional Operator

if · else if · else · ?: · if with initializer · [[likely]] / [[unlikely]] · if consteval

Branching

if runs a statement when its condition converts to true; else if chains further tests and else catches the rest. Since C++17, an if can declare a variable in an initializer that's scoped to the whole if/else chain. The conditional operator ?: picks between two expressions and yields a value, so it works where a statement can't, such as in initializers.

Variants

  • if (init; cond) — C++17 initializer
  • [[likely]] / [[unlikely]] — branch hints (C++20)
  • if constexpr — compile-time branch (templates)
  • if consteval — true during constant evaluation (C++23)

if / else / ?:

int score = 83;
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';                       // runs: 'B'
} else {
    grade = 'C';
}

if (auto it = users.find(id); it != users.end()) {
    std::println("found {}", it->second);   // it scoped to if/else
} else {
    std::println("no user {}", id);
}

if (err) [[unlikely]] { return handleError(err); }

const auto label = score >= 50 ? "pass" : "fail";  // "pass"
int clamped = v < 0 ? 0 : (v > 100 ? 100 : v);

Code Explained

else if — just an else whose body is another if
if (init; cond) — keeps it out of the surrounding scope
[[unlikely]] — hints the optimizer about the cold path
?: — an expression; both branches must have a common type
nested ternaries — fine for clamps, otherwise prefer if

⚠ Common Mistakes

  • Writing if (x = 0); that assigns 0 and is always false. Use ==
  • A stray semicolon: if (ok); makes the body empty and always runs the next line
  • Dangling else: without braces, else binds to the nearest if. Always use braces for nested ifs

✓ Tips & Best Practices

  • Return early for error cases to avoid deep nesting
  • Use std::clamp(v, 0, 100) instead of nested ternaries
  • Mark variables used only in a branch with the if-initializer form

Quick Summary

  • if / else if / else — multi-way branching
  • if (init; cond) — scoped initializer (C++17)
  • c ? a : b — conditional expression
  • [[likely]] / [[unlikely]] — branch hints
