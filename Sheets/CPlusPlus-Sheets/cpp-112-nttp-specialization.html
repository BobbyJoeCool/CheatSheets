Value Parameters & Specialization

Template parameters can be values as well as types: integers, enums, pointers, and since C++20 floating-point values and literal class types. These non-type template parameters (NTTPs) are compile-time constants, like N in std::array<T, N>. Specialization provides a custom implementation for particular arguments: a full specialization for one exact set, or a partial specialization (class templates only) for a pattern.

Notes

  • template <auto N> (C++17) deduces the NTTP's type
  • Function templates can't be partially specialized; overload instead
  • Specializations must be declared before first use
  • Class-type NTTPs need public members and structural types (C++20)

NTTPs & Specialization

template <typename T, std::size_t N>
constexpr std::size_t count(const T (&)[N]) { return N; }
int a[7]{};  count(a);                      // 7

template <auto V> constexpr auto constant = V;
constant<42>;  constant<'x'>;               // int, char

template <class T> struct TypeName    { static constexpr auto value = "?"; };
template <> struct TypeName<int>      { static constexpr auto value = "int"; };
template <class T> struct TypeName<T*> { static constexpr auto value = "ptr"; };
TypeName<int>::value;                       // "int"
TypeName<double*>::value;                   // "ptr"

struct Fixed {
    char s[8]; constexpr Fixed(const char* p) { std::copy_n(p, 8, s); }
};
template <Fixed Name> struct Tag {};        // class-type NTTP (C++20)
Tag<"metrics"> t;

Code Explained

T (&)[N] — deduces the array size as a template argument
template <auto V> — value and its type deduced together
template <> — full specialization for exactly int
TypeName<T*> — partial specialization for any pointer type
class-type NTTP — lets string literals be template arguments

⚠ Common Mistakes

  • Trying to partially specialize a function template; it's not allowed. Overload or use if constexpr
  • Specializing after the template was already used with those arguments (ill-formed, no diagnostic)
  • Declaring specializations in a different namespace from the primary template

✓ Tips & Best Practices

  • Prefer if constexpr inside one template over many tiny specializations
  • Specialize standard traits only where allowed (e.g. std::hash, std::formatter)
  • Use NTTPs for sizes and compile-time configuration, like Matrix<3, 3>

Quick Summary

  • NTTP — compile-time value parameter
  • template <auto V> — deduced NTTP type (C++17)
  • full specialization — template <> struct X<int>
  • partial specialization — patterns like X<T*>
