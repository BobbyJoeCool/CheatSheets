Program Structure

int main() · argc / argv · return 0 · #include · std:: · statements & blocks · semicolons & braces

Anatomy of a Program

Every C++ program needs exactly one main function, which the runtime calls after initializing globals. Code is organized into statements that end with semicolons, grouped into blocks with braces. Whitespace and indentation don't matter to the compiler. #include lines are processed by the preprocessor before compilation and paste in the declarations your code uses.

Rules

  • main returns int; 0 (or EXIT_SUCCESS) means success
  • Two legal forms: int main() and int main(int argc, char* argv[])
  • argv[0] is the program name; real arguments start at argv[1]
  • Names are case-sensitive: Count and count are different

Annotated Program

#include <print>        // std::println
#include <string>       // std::string
#include <cstdlib>      // EXIT_SUCCESS / EXIT_FAILURE
// A function must be declared before it is used
int square(int x) {
    return x * x;
}
int main(int argc, char* argv[]) {      // entry point
    if (argc < 2) {                      // no argument given
        std::println("usage: {} NAME", argv[0]);
        return EXIT_FAILURE;             // non-zero = error
    }
    std::string name = argv[1];          // first real argument
    std::println("Hi {}, 7^2 = {}", name, square(7));
    return EXIT_SUCCESS;                 // 0
}
// $ ./app Ada   →   Hi Ada, 7^2 = 49

Code Explained

#include <…> — standard headers use angle brackets; your own use quotes
int square(int x) — return type, name, typed parameter list
argc / argv — count and array of C-string arguments
{ … } — a block; also creates a new scope for variables
; — ends every statement (but not a function body's closing brace)

⚠ Common Mistakes

  • Writing void main(); it's not standard C++ and some compilers reject it
  • Calling a function above the point where it's declared; add a prototype or move the definition up
  • Reading argv[1] without checking argc first, which is undefined behavior when no argument was passed

✓ Tips & Best Practices

  • Use EXIT_SUCCESS / EXIT_FAILURE from <cstdlib> for readable, portable exit codes
  • Convert argv to std::vector<std::string_view> args(argv, argv + argc); to work with it safely
  • Keep main short: parse arguments, call into real functions, return a status

Quick Summary

  • int main() — single required entry point
  • argc / argv — command-line argument count and values
  • #include — preprocessor pastes in declarations
  • ; and {} — statements and blocks; whitespace is free-form
