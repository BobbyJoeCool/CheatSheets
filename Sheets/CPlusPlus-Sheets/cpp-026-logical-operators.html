Logical Operators

&& · || · ! · short-circuit evaluation · and / or / not tokens · pointer & stream truthiness

Boolean Logic

&& (and), || (or), and ! (not) operate on bool, converting other operands first: zero, nullptr, and false are false; everything else is true. && and || short-circuit: the right side is evaluated only if it can change the result. That makes guard patterns like ptr && ptr->ok() safe. C++ also accepts the alternative tokens and, or, not.

Precedence

  • ! binds tightest, then &&, then ||
  • a || b && c means a || (b && c)
  • Overloaded && / || lose short-circuiting, so avoid overloading them
  • && and || are sequence points: left is fully evaluated first

Logic & Short-Circuit

bool a = true, b = false;
a && b;            // false
a || b;            // true
!a;                // false
a and not b;       // true  (alternative tokens)

int* p = nullptr;
if (p && *p > 0) {}            // safe: *p never evaluated
if (!p || p->empty()) {}       // safe guard with ||

std::vector<int> v;
if (!v.empty() && v[0] == 42) {}   // check before index

if (std::ifstream f{"cfg.txt"}; f && f.peek() != EOF) {}

int n = 7;
bool inRange = n >= 1 && n <= 10;  // true
bool isEdge  = n == 0 || n == 10;  // false
bool odd     = n % 2;              // true (1 → true)
auto expensive = [] { return true; };
if (cached || expensive()) {}      // expensive() skipped if cached

Code Explained

p && *p > 0 — right side only runs when p is non-null
!p || … — the "null or empty" guard
streams convert to bool: true when no error
n % 2 — integer converted to bool
put cheap or guarding checks on the left

⚠ Common Mistakes

  • Using bitwise & or | instead of && / ||; there's no short-circuit and both sides always run
  • Writing if (x == 1 || 2); that's always true. Write x == 1 || x == 2
  • Putting the guard on the right: *p > 0 && p dereferences null first

✓ Tips & Best Practices

  • Name complex conditions: const bool canRetry = attempts < 3 && !fatal;
  • Use std::ranges::any_of / all_of / none_of instead of long || chains over a container
  • Apply De Morgan to simplify: !(a && b) == !a || !b

Quick Summary

  • && / || / ! — and, or, not
  • short-circuit — right side may not run
  • guard pattern — ptr && ptr->x
  • truthiness — zero/null are false
