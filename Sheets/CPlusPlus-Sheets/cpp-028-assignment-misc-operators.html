Assignment & the Rest

Assignment = stores a value and returns a reference to the left operand, so a = b = 0 works right to left. Every binary arithmetic and bitwise operator has a compound form that combines the operation with assignment. This sheet also collects the other everyday operators: scope resolution ::, member access . and ->, sizeof, the comma operator, and the full precedence table.

Notes

  • x += y evaluates x once; x = x + y evaluates it twice
  • Assignment is right-associative
  • ::name refers to the global name
  • -> is shorthand for (*ptr).member

Assignment & Misc Operators

int x = 10;
x += 5;        // 15
x -= 3;        // 12
x *= 2;        // 24
x /= 5;        // 4
x %= 3;        // 1
x <<= 4;       // 16
x |= 0b11;     // 19
int a, b, c;
a = b = c = 0; // all 0 (right to left)
std::string s = "hi";
std::string* ps = &s;
s.size();      // .  member of object
ps->size();    // -> member through pointer
std::string::npos;   // :: scope resolution
::globalCount; // global namespace
sizeof(int);   // 4    (bytes, compile-time)
sizeof x;      // 4    (parens optional for expressions)
int r = (a++, b++, a + b);   // comma: evaluates left, yields right

Code Explained

compound ops — op= exists for + - * / % & | ^ << >>
chained = — each assignment returns the left operand
. vs -> — object vs pointer to object
:: — names inside a namespace or class, or the global scope
comma operator — rarely useful outside for headers

⚠ Common Mistakes

  • Confusing = with == in conditions; enable warnings and consider if (5 == x) style only if your team uses it
  • Expecting a < b < c style chaining to work like math; it doesn't
  • Relying on the order of evaluation of function arguments: f(i++, i++) is unspecified

✓ Tips & Best Practices

  • When mixing &, |, <<, and comparisons, always parenthesize; their precedence surprises people
  • Use std::exchange(x, newVal) to assign and get the old value in one step
  • Prefer sizeof(var) over sizeof(Type) so it updates if the type changes

Quick Summary

  • . / -> — member access via object / pointer
