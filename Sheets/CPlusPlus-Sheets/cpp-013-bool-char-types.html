Booleans & Characters

bool holds true or false and converts to 1/0 in arithmetic. Any number or pointer converts to bool: zero and nullptr are false, everything else is true. char is one byte, and whether plain char is signed is implementation-defined. C++ adds explicit character types for each Unicode encoding (char8_t, char16_t, char32_t) and std::byte for raw memory that isn't text.

Facts

  • sizeof(char) is always 1
  • 'A' is a char literal; "A" is a string (array of 2 chars)
  • char8_t (C++20) is UTF-8; u8"…" literals now use it
  • std::byte supports bitwise ops but not arithmetic

bool, char & Friends

#include <cctype>
#include <cstddef>

bool ready = true;
int  n = ready + ready;        // 2
bool ok = 42;                  // true (non-zero)

char c = 'A';
int  code = c;                 // 65
char next = c + 1;             // 'B'
std::toupper('q');             // 'Q' (returns int)

char8_t  u8 = u8'a';           // UTF-8 code unit
char16_t u16 = u'é';           // UTF-16
char32_t u32 = U'😀';          // UTF-32 code point
wchar_t  w = L'Ω';             // 16-bit Win, 32-bit Linux
std::byte b{0b1010'0000};
b |= std::byte{0x0F};          // 0xAF
std::to_integer<int>(b);       // 175

Code Explained

ready + ready — bools promote to int in arithmetic
c + 1 — chars are small integers; arithmetic works on codes
std::toupper — pass unsigned char values to avoid UB on negative chars
u8'' / u'' / U'' / L'' — prefixes pick the character type
std::byte — raw memory; convert with std::to_integer

⚠ Common Mistakes

  • Calling std::toupper(c) with a negative char (e.g. UTF-8 bytes); cast first: std::toupper((unsigned char)c)
  • Using char for small numbers and printing it: std::cout << int8_t{65} prints A, not 65
  • Treating one char as one character in UTF-8 text; non-ASCII characters take 2–4 bytes

✓ Tips & Best Practices

  • Print a char as a number with +c or static_cast<int>(c)
  • Use std::byte for buffers of raw data so nobody accidentally does arithmetic on them
  • Write if (ptr) and if (!vec.empty()) instead of comparing to true

Quick Summary

  • bool — true/false; zero converts to false
  • char — 1 byte; signedness varies by platform
  • char8_t / char16_t / char32_t — Unicode code units
  • std::byte — raw memory, bitwise ops only
