Stacks, Queues & Priority Queues

std::stack · std::queue · std::priority_queue · push / pop / top · std::greater · min-heap

Container Adaptors

Container adaptors wrap another container and expose a restricted interface. std::stack is LIFO (last in, first out), std::queue is FIFO (first in, first out), and std::priority_queue always gives you the largest element first (a binary heap). None of them support iteration. Choose the underlying container with a template argument.

Defaults

  • stack / queue default to std::deque
  • priority_queue defaults to std::vector + std::less (max-heap)
  • pop() returns void; read with top() / front() first
  • Calling top()/pop() on an empty adaptor is UB

stack, queue, priority_queue

#include <stack>
#include <queue>

std::stack<int> st;
st.push(1); st.push(2); st.push(3);
st.top();                 // 3
st.pop();                 // removes 3

std::queue<std::string> q;
q.push("a"); q.push("b");
q.front(); q.back();      // "a", "b"
q.pop();                  // removes "a"

std::priority_queue<int> maxHeap;
for (int x : {4, 9, 1}) maxHeap.push(x);
maxHeap.top();            // 9

std::priority_queue<int, std::vector<int>, std::greater<>> minHeap{
    std::greater<>{}, {4, 9, 1}};
minHeap.top();            // 1
using Job = std::pair<int, std::string>;          // (priority, name)
std::priority_queue<Job> jobs;                    // highest priority first
jobs.emplace(2, "email"); jobs.emplace(5, "deploy");  // top: deploy

⚠ Common Mistakes

  • Writing int x = st.pop();; pop returns void. Read top() first, then pop()
  • Expecting a min-heap from the default priority_queue; it's a max-heap
  • Needing to iterate or update priorities; adaptors can't. Use a std::set or std::ranges::make_heap on a vector

✓ Tips & Best Practices

  • Use a min-heap of {distance, node} pairs for Dijkstra's algorithm
  • Store std::pair<int, T> with negated priorities as a quick min-heap alternative
  • Check empty() before every top() / front()

Quick Summary

  • std::queue — FIFO
  • std::priority_queue — max-heap by default
