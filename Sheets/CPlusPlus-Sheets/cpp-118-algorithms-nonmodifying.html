Querying Ranges

Non-modifying algorithms in <algorithm> inspect a range without changing it: finding elements, counting, checking predicates, and comparing ranges. Each classic form takes an iterator pair; the C++20 std::ranges:: versions accept a whole container and optional projections. Finding functions return an iterator, equal to end when nothing matched.

Notes

  • _if variants take a predicate instead of a value
  • find is O(n); use set / map / binary_search for repeated lookups
  • all_of on an empty range is true; any_of is false
  • std::ranges::contains (C++23) — direct yes/no

find, count, all_of & friends

std::vector<int> v{3, 8, 1, 8, 5};

auto it = std::ranges::find(v, 8);              // first 8 (index 1)
if (it != v.end()) {}
auto big = std::ranges::find_if(v, [](int x) { return x > 4; });   // 8
std::ranges::count(v, 8);                       // 2
std::ranges::count_if(v, [](int x) { return x % 2; });           // 3

std::ranges::all_of(v,  [](int x) { return x > 0; });   // true
std::ranges::any_of(v,  [](int x) { return x > 7; });   // true
std::ranges::none_of(v, [](int x) { return x < 0; });   // true
std::ranges::contains(v, 5);                    // true   (C++23)

auto [mn, mx] = std::ranges::minmax(v);         // 1, 8
std::ranges::equal(v, std::vector{3, 8, 1, 8, 5});   // true
auto adj = std::ranges::adjacent_find(v);       // first equal neighbors?
auto pos = std::ranges::search(v, std::vector{1, 8}); // subrange at index 2
auto oldest = std::ranges::max_element(people, {}, &Person::age);

Code Explained

find / find_if — iterator to first match or end()
count / count_if — number of matches
all_of / any_of / none_of — boolean checks
minmax — both extremes in one pass
search — find a sub-sequence
projection &Person::age — compare by a member without a lambda

⚠ Common Mistakes

  • Not checking find's result against end() before dereferencing
  • Calling std::max_element and treating the result as a value; it's an iterator
  • Using count(...) > 0 just to test membership; any_of / contains stop at the first match

✓ Tips & Best Practices

  • Use projections to search or compare by a member: ranges::find(users, id, &User::id)
  • Use std::ranges::contains for readable membership tests in C++23
  • Switch to a hash set if you call find on the same large vector many times

Quick Summary

  • find / find_if — locate an element
  • count / count_if — tally matches
  • all_of / any_of / none_of — predicate checks
  • projections — operate on members directly
