Aggregates & Designated Initializers

aggregate types · brace initialization · .x = 1 designated init · default member initializers · trivial / standard-layout

Plain Data Types

An aggregate is a class or array with no user-declared constructors, no private non-static data, no virtual functions, and no virtual or private bases. Aggregates can be initialized directly with braces, member by member. C++20's designated initializers (.x = 1) name the members being set, which makes calls readable, and default member initializers fill in anything omitted.

Rules

  • Designators must appear in declaration order
  • Omitted members use their default initializer, or are value-initialized
  • Designated init and positional init can't be mixed
  • Aggregates support structured bindings automatically

Aggregates & Designated Init

struct Options {
    std::string host = "localhost";
    int  port = 8080;
    bool tls  = false;
    int  timeoutMs = 5000;
};
Options a;                                  // all defaults
Options b{"example.com", 443, true};        // positional; timeout 5000
Options c{.host = "api.dev", .tls = true};  // port 8080, timeout 5000
// Options d{.port = 1, .host = "x"};       // ERROR: out of order
void connect(const Options& o);
connect({.port = 9000, .timeoutMs = 100});  // named-argument style
auto [h, p, t, ms] = c;                     // structured bindings
struct Point { double x, y; };
Point pts[] = {{0, 0}, {1, 2}};             // nested aggregates
static_assert(std::is_aggregate_v<Options>);

Code Explained

default member initializers — used when a member isn't mentioned
positional {…} — fills members in order
.tls = true — designated initializer (C++20)
connect({.port = …}) — emulates named arguments
std::is_aggregate_v — verify a type is an aggregate

⚠ Common Mistakes

  • Adding a constructor to an aggregate (even = default declared), which stops brace-init by member
  • Writing designators out of order; unlike C, C++ requires declaration order
  • Reordering struct members and silently changing the meaning of positional initializers

✓ Tips & Best Practices

  • Use designated initializers for option/config structs with many fields
  • Keep option structs as aggregates with sensible defaults instead of many-parameter constructors
  • Add auto operator<=>(const T&) const = default; to aggregates for free comparisons

Quick Summary

  • aggregate — public data, no ctors, no virtuals
  • T{a, b} — positional initialization
  • T{.x = 1} — designated initializers (C++20)
  • default member initializers — fill omitted fields
