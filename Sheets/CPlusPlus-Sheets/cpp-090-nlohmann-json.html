JSON for Modern C++

nlohmann/json is the most popular C++ JSON library. A nlohmann::json value behaves like a dynamic container: index it with strings and numbers, assign from C++ values, and iterate it. json::parse reads text and dump() writes it. Define to_json / from_json, or use the NLOHMANN_DEFINE_TYPE_* macros, to convert your own structs automatically.

Setup

  • vcpkg: nlohmann-json; link nlohmann_json::nlohmann_json
  • Header-only: #include <nlohmann/json.hpp>
  • using json = nlohmann::json; is the common alias
  • Parse errors throw json::parse_error (or use json::accept)

Parse, Access, Serialize

#include <nlohmann/json.hpp>
using json = nlohmann::json;
json cfg = json::parse(R"({"name":"api", "port":8080, "tags":["a","b"]})");
std::string name = cfg["name"];              // "api"
int port = cfg.at("port").get<int>();        // 8080
cfg.value("debug", false);                   // default if missing
cfg["tags"].push_back("c");
cfg.contains("port");                        // true
struct Server { std::string host; int port; };
NLOHMANN_DEFINE_TYPE_NON_INTRUSIVE(Server, host, port)
Server s = json{{"host", "db"}, {"port", 5432}}.get<Server>();
json out = s;                                // {"host":"db","port":5432}
std::println("{}", out.dump(2));             // pretty, 2-space indent
std::ifstream f{"config.json"};
json fromFile = json::parse(f);

Code Explained

json::parse — from string or stream
cfg["name"] — implicit conversion to std::string
.at() + .get<int>() — checked access, explicit type
value(key, default) — safe lookup with fallback
NLOHMANN_DEFINE_TYPE_NON_INTRUSIVE — generates to/from_json
dump(2) — serialize with indentation

⚠ Common Mistakes

  • Reading with j["missing"] on a non-const json; it silently inserts null
  • Implicit conversions from a value of the wrong type throw type_error at run time
  • Using dump() output as a map key or for comparisons; key order and spacing can vary

✓ Tips & Best Practices

  • Use the …_WITH_DEFAULT variant of the macro to tolerate missing fields
  • Use json::parse(text, nullptr, false) to get a discarded value instead of an exception
  • For very large or performance-critical JSON, look at simdjson or Glaze
