Sheet 048

Attributes & Specifiers

[[nodiscard]] · [[maybe_unused]] · [[deprecated]] · [[noreturn]] · [[assume]] · = delete on functions

Telling the Compiler More

Attributes ([[...]]) attach standard hints to declarations: they let the compiler warn about misuse, suppress false-positive warnings, or optimize. Deleted functions (= delete) make a call a compile error, which is useful to block dangerous conversions or forbid copying. Unknown attributes are ignored, so vendor-specific ones such as [[gnu::always_inline]] are safe to write.

Notes

  • Attributes go before the declaration or after the name for variables
  • [[nodiscard("reason")]] takes a message (C++20)
  • = delete works on any function, not just special members
  • [[assume(expr)]] (C++23) — UB if expr is false

Attributes & = delete

[[nodiscard]] std::expected<int, Err> parse(std::string_view);
parse("42");                        // warning: ignoring return value

[[deprecated("use connect2()")]] void connect();
connect();                          // warning: 'connect' is deprecated

[[noreturn]] void fatal(std::string_view msg);   // calls std::exit

void handler([[maybe_unused]] int signal) {}   // no unused warning

int scale(int x) { [[assume(x > 0)]]; return x / 4; }
void setPercent(int);
void setPercent(double) = delete;   // block implicit double → int
// setPercent(0.5);                 // ERROR: use of deleted function

Code Explained

[[nodiscard]] — warns when a result is ignored
[[deprecated("…")]] — warns at every call site with your message
[[noreturn]] — the function never returns normally
[[maybe_unused]] — silences unused-variable/parameter warnings
[[assume]] — optimization hint; wrong assumptions are UB
= delete — calling the overload is a compile error

⚠ Common Mistakes

  • Using [[assume]] as a check; it's not verified, and a false assumption is UB. Use assert for checks
  • Putting [[nodiscard]] on functions whose result is commonly ignored, training people to ignore warnings
  • Declaring copy operations private-and-unimplemented (C++98 style) instead of = delete

✓ Tips & Best Practices

  • Mark factory functions, error-returning functions, and empty()-style queries [[nodiscard]]
  • Use [[deprecated]] for a release before removing an API
  • Delete overloads to stop bool/double from sneaking into integer parameters

Quick Summary

  • [[nodiscard]] — don't ignore the result
  • [[deprecated]] — migration warning
  • [[maybe_unused]] / [[noreturn]] — silence / document
  • = delete — make specific calls ill-formed
