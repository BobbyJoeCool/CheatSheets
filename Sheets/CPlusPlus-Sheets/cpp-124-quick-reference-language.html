⚠ Common Mistakes

  • Returning a reference or pointer to a local variable (dangling)
  • Using new / delete by hand — use make_unique / containers
  • Reading uninitialized variables or going out of bounds (undefined behaviour)

✓ Tips & Best Practices

  • Compile with -Wall -Wextra -Werror and sanitizers in debug builds
  • Pass large objects by const&, small ones by value
  • Prefer std::println / std::format over iostream formatting

Quick Summary

  • Brace-init, auto, constexpr, enum class
  • std::string + string_view for text
  • optional / expected / exceptions for errors
  • RAII + smart pointers for ownership
