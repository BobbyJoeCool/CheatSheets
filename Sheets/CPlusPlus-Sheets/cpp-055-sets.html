Sets

std::set · std::unordered_set · std::multiset · insert · contains · erase · custom comparator

Unique Collections

A set stores unique keys with no associated value. std::set keeps them sorted (tree, O(log n)); std::unordered_set uses a hash table (O(1) average, no order). std::multiset / unordered_multiset allow duplicates. Sets are the right tool for membership tests, deduplication, and ordered unique collections. Elements are const once inserted.

Notes

  • insert returns {iterator, bool}; false means it was already there
  • contains(x) (C++20) is the clearest membership test
  • Change an element by extract-ing it, editing, and reinserting
  • Set operations need sorted ranges: std::set_union, etc.

set & unordered_set

#include <set>
#include <unordered_set>

std::set<int> s{5, 1, 3, 1};           // 1 3 5  (dup dropped)
auto [it, added] = s.insert(3);        // added == false
s.insert(4);                           // 1 3 4 5
s.erase(1);                            // 3 4 5
s.contains(4);                         // true
*s.begin(); *s.rbegin();               // 3, 5 (min, max)
s.lower_bound(4);                      // iterator to 4

std::unordered_set<std::string> seen;
for (const auto& w : words)
    if (!seen.insert(w).second) std::println("dup: {}", w);
std::set<std::string, std::greater<>> desc{"b", "a", "c"};  // c b a
auto byLen = [](const std::string& a, const std::string& b) {
    return a.size() < b.size(); };
std::set<std::string, decltype(byLen)> lens(byLen);  // custom compare
std::vector<int> v{3, 1, 3, 2};
std::set<int> uniq(v.begin(), v.end()); // dedupe + sort: 1 2 3
std::multiset<int> ms{1, 1, 2};  ms.count(1);   // 2

Code Explained

duplicates in the initializer are ignored
insert(...).second — tells you whether the value was new
*begin() / *rbegin() — smallest and largest in a sorted set
std::greater<> — reverse order
custom comparator — elements equal under it count as duplicates

⚠ Common Mistakes

  • A comparator that isn't a strict weak ordering (e.g. using <=) gives undefined behavior
  • Trying to modify *it in a set; elements are const. Erase and reinsert, or use extract
  • Running std::set_union on unsorted vectors; the output is wrong

✓ Tips & Best Practices

  • Use std::unordered_set for fast "have I seen this?" checks
  • To dedupe a vector in place, std::ranges::sort then v.erase(std::ranges::unique(v).begin(), v.end())
  • Use std::flat_set (C++23) for small, read-mostly sets for better cache behavior

Quick Summary

  • std::set — sorted unique keys
  • std::unordered_set — hashed unique keys
  • contains / insert().second — membership tests
  • std::multiset — duplicates allowed
