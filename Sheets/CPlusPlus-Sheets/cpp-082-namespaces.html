Namespaces

Organizing Names

A namespace groups related names and prevents collisions between libraries: std::vector and mylib::vector can coexist. Refer to names with ::, bring specific ones into scope with a using-declaration (using std::string;), or import a whole namespace with a using-directive (using namespace std;), which is best kept to small local scopes. Namespaces can be nested, aliased, reopened, and made inline for versioning.

Notes

  • namespace a::b { } — nested shorthand (C++17)
  • Namespaces are open: add to them in multiple files
  • ::name — the global namespace
  • ADL: functions are also looked up in their arguments' namespaces

Namespaces in Practice

namespace acme::geometry {                // nested (C++17)
    struct Point { double x, y; };
    double distance(Point a, Point b);
}
namespace acme::geometry {                // reopened in another file
    double distance(Point a, Point b) {
        return std::hypot(a.x - b.x, a.y - b.y);
    }
}
acme::geometry::Point p{0, 0}, q{3, 4};
distance(p, q);                           // 5 — found by ADL
namespace geo = acme::geometry;           // alias
void report() {
    using std::println;                   // using-declaration
    using namespace std::chrono_literals; // directive, local scope only
    println("{}", 5s);                    // 5s
}
namespace lib {
    inline namespace v2 { int api(); }    // lib::api → lib::v2::api
}

Code Explained

acme::geometry — avoids clashes with other Point types
reopening — split a namespace across headers and sources
ADL — distance(p, q) works without qualification
namespace geo = … — shorter alias
inline namespace v2 — default version for lib::api

⚠ Common Mistakes

  • using namespace std; at file scope in headers; it leaks everywhere and causes ambiguities
  • Adding your own declarations to namespace std (only specializations like std::hash are allowed)
  • Unqualified calls that unexpectedly pick an ADL overload from another namespace

✓ Tips & Best Practices

  • Put all your code in a project namespace
  • Use using namespace only inside functions, and only for literal namespaces or tight scopes
  • Name an internal sub-namespace detail to signal "not public API"

Quick Summary

  • namespace a::b {} — group names
  • a::b::name — qualified access
  • using X::name; — import one name
  • namespace x = a::b; — alias
