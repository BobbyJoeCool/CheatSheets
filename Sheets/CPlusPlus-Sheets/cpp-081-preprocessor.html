The Preprocessor

#define · function-like macros · #if / #ifdef · __FILE__ / __LINE__ · #error · std::source_location · #embed (C++26)

Text Substitution Before Compiling

The preprocessor runs before the compiler and works on text: #include pastes files, #define creates macros, and #if / #ifdef include or drop code. Macros ignore scope, namespaces, and types, so modern C++ replaces most uses with constexpr, inline functions, templates, and std::source_location. Conditional compilation for platforms and feature flags remains a legitimate use, and C++26 adds #embed for including binary files.

Notes

  • Macro names are conventionally ALL_CAPS
  • Parenthesize macro parameters and the whole body
  • -DNAME=value defines a macro from the command line
  • __has_include(<header>) tests whether a header exists

Macros & Conditional Compilation

#define BUFFER_SIZE 4096                 // object-like (prefer constexpr)
#define SQUARE(x) ((x) * (x))            // function-like
SQUARE(3 + 1);                           // 16 (parens matter)
SQUARE(i++);                             // UB: i incremented twice

#ifdef _WIN32
    #include <windows.h>
#elif defined(__linux__) || defined(__APPLE__)
    #include <unistd.h>
#else
    #error "unsupported platform"
#endif

#if __cpp_lib_print >= 202207L           // feature-test macro
    #include <print>
#endif
void trace(std::source_location loc = std::source_location::current()) {
    std::println("{}:{} {}", loc.file_name(), loc.line(), loc.function_name());
}

Code Explained

object-like macro — plain text substitution
SQUARE(i++) — argument evaluated twice: a classic macro bug
#ifdef _WIN32 — platform-specific code
#error — stops compilation with a message
__cpp_lib_print — check library support before using a feature
std::source_location — replaces __FILE__ / __LINE__ macros (C++20)

⚠ Common Mistakes

  • Unparenthesized macros: #define DOUBLE(x) x * 2 makes DOUBLE(1 + 2) equal 5
  • Macros with side-effect arguments evaluated twice
  • Macro names clashing with real identifiers (min/max from windows.h); define NOMINMAX

✓ Tips & Best Practices

  • Replace constant macros with constexpr and function macros with inline/template functions
  • Use feature-test macros (__cpp_lib_*) from <version> to support several compilers
  • Use std::source_location in logging helpers instead of __FILE__ / __LINE__

Quick Summary

  • #define — text substitution, no scope or types
  • #if / #ifdef — conditional compilation
  • feature-test macros — detect support
  • std::source_location — modern file/line info
