std::ranges::sort · std::ranges::find · projections · range concepts · views vs containers · dangling iterators

Ranges Library

C++20 ranges treat a whole container as one argument: std::ranges::sort(v) instead of std::sort(v.begin(), v.end()). Range algorithms are constrained with concepts, so misuse gives clear errors, and they accept projections to operate on a member. Algorithms that return iterators into a temporary return std::ranges::dangling instead, preventing use-after-free at compile time.

Notes

  • Headers: <algorithm> (range algorithms), <ranges> (views, concepts)
  • A range is anything with begin() and end()
  • Views are lazy, non-owning ranges; containers own their elements
  • Range algorithms are function objects (niebloids): no ADL surprises

Range Algorithms & Projections

#include <algorithm>
#include <ranges>

std::vector<int> v{4, 1, 3};
std::ranges::sort(v);                          // 1 3 4
std::ranges::reverse(v);                       // 4 3 1

struct User { std::string name; int age; };
std::vector<User> users{{"Bo", 31}, {"Ada", 36}};
std::ranges::sort(users, {}, &User::name);     // by name (projection)
auto it = std::ranges::find(users, 36, &User::age);   // Ada
auto top = std::ranges::max(users, {}, &User::age);   // Ada (copy)

auto bad = std::ranges::find(getUsers(), 36, &User::age);
// bad is std::ranges::dangling — can't be dereferenced (compile error)

static_assert(std::ranges::random_access_range<std::vector<int>>);
static_assert(!std::ranges::random_access_range<std::list<int>>);

Code Explained

ranges::sort(v) — whole container, no iterator pair
{} — default comparator (std::ranges::less)
&User::name — projection applied before comparing
getUsers() returns a temporary — result becomes dangling
range concepts — check capabilities at compile time

⚠ Common Mistakes

  • Mixing std::sort (needs iterators) and range syntax: std::sort(v) doesn't compile; use std::ranges::sort
  • Keeping a view after its underlying container is destroyed
  • Assuming every view is cheap to iterate twice; some (like filter) cache and some recompute

✓ Tips & Best Practices

  • Default to std::ranges:: algorithms in C++20+ code
  • Use projections instead of writing comparator lambdas for single-member keys
  • Check concept satisfaction with static_assert when writing generic code
