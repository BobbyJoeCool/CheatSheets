Sheet 008

Console Input

std::cin · >> extraction · std::getline · cin.fail() · cin.clear() · cin.ignore() · input validation loop

Reading stdin

std::cin reads from standard input. The extraction operator >> skips leading whitespace, parses one value of the target's type, and stops at the next whitespace. std::getline reads a whole line including spaces. When extraction fails, the stream enters a fail state and ignores every later read until you call clear() and discard the bad input.

Stream State

  • if (std::cin >> x) — true when the read succeeded
  • cin.fail() — wrong type or EOF
  • cin.clear() — reset the error flags
  • cin.ignore(n, '\n') — throw away the rest of the line

Safe Input Loop

#include <iostream>
#include <limits>
#include <string>

int age;
std::cout << "Age: ";
while (!(std::cin >> age) || age < 0) {             // typed "abc"?
    std::cin.clear();                               // reset fail flag
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
    std::cout << "Enter a non-negative number: ";
}
std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

std::string name;
std::cout << "Full name: ";
std::getline(std::cin, name);                       // "Ada Lovelace"

int a, b;
std::cin >> a >> b;                                 // "3 4" → a=3, b=4

Code Explained

!(std::cin >> age) — extraction failed (not a number)
clear() then ignore(...) — the standard recovery pair
second ignore — drops the '\n' left by >> before getline
std::getline — reads up to (and removes) the newline
>> a >> b — chained reads; any whitespace separates values

⚠ Common Mistakes

  • Calling getline right after cin >> n; it reads the leftover newline and returns an empty string
  • Not checking the result of >>, so a bad value leaves x at 0 (C++11+) and the loop spins forever
  • Using while (!cin.eof()); check the read itself: while (cin >> x)

✓ Tips & Best Practices

  • Read whole lines with getline, then parse with std::from_chars or std::stringstream for robust input
  • Add std::cin >> std::ws before getline to skip leftover whitespace in one step
  • while (std::cin >> x) processes all numbers until EOF (Ctrl+D / Ctrl+Z)

Quick Summary

  • std::cin >> x — read one typed token
  • std::getline — read a full line
  • clear() + ignore() — recover from bad input
  • if (cin >> x) — always test the read
