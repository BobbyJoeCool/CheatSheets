CMake Basics

CMakeLists.txt · project() · add_executable · add_library · target_link_libraries · target_compile_features · cmake -B build · cmake --build

Why CMake

CMake is the de facto build system generator for C++. You describe targets (executables and libraries) and their properties in CMakeLists.txt; CMake generates Ninja, Makefile, Visual Studio, or Xcode projects from it. Modern CMake is target-based: settings are attached to a target with target_* commands and flow to whatever links it, instead of global variables.

Workflow

  • Configure once: cmake -B build -G Ninja
  • Build: cmake --build build (works with any generator)
  • Out-of-source builds keep generated files in build/
  • PRIVATE / PUBLIC / INTERFACE control what propagates to dependents

CMakeLists.txt

cmake_minimum_required(VERSION 3.28)
project(Inventory VERSION 1.0 LANGUAGES CXX)

# A library target with its public headers
add_library(core src/item.cpp src/store.cpp)
target_include_directories(core PUBLIC include)
target_compile_features(core PUBLIC cxx_std_23)

# The executable links the library
add_executable(inventory src/main.cpp)
target_link_libraries(inventory PRIVATE core)

# Warnings, per compiler
if(MSVC)
  target_compile_options(core PRIVATE /W4)
else()
  target_compile_options(core PRIVATE -Wall -Wextra)
endif()

Code Explained

cmake_minimum_required — first line; pins policy behavior
project(... LANGUAGES CXX) — names the project, enables C++
add_library / add_executable — define targets from sources
target_compile_features(... cxx_std_23) — require C++23
PUBLIC include dir — also applied to anything linking core
target_link_libraries — link and inherit usage requirements

Keyword Scope

KeywordApplies to
PRIVATEthis target only
PUBLICthis target + dependents
INTERFACEdependents only (header-only libs)

⚠ Common Mistakes

  • Using global include_directories() / add_compile_options(); they leak into every target. Prefer target_*
  • Setting CMAKE_BUILD_TYPE with Visual Studio or Xcode; those generators use --config at build time
  • Building in the source folder, which mixes generated files with your code

✓ Tips & Best Practices

  • Set CMAKE_EXPORT_COMPILE_COMMANDS=ON so clangd and other tools understand your build
  • Use CMakePresets.json to share configure/build options with your team
  • Mark header-only libraries add_library(name INTERFACE)

Quick Summary

  • CMakeLists.txt — declares targets and their properties
  • cmake -B build — configure; cmake --build build — build
  • target_link_libraries — link and propagate usage requirements
  • cxx_std_23 — request the standard per target
