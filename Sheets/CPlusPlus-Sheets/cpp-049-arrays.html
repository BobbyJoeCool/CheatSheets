Fixed-Size Arrays

A C-style array T a[N] is a contiguous block of N elements whose size is fixed at compile time. It decays to a pointer to its first element in most expressions, losing its size, and can't be copied or returned by value. std::array<T, N> (<array>) wraps the same storage with zero overhead but behaves like a proper value: it copies, compares, knows its size(), and works with algorithms.

Notes

  • Indexes run 0 … N-1; out-of-bounds access is UB
  • std::size(a) works for both kinds (C++17)
  • std::array can be constexpr and returned from functions
  • Uninitialized local arrays hold indeterminate values; use {}

C Array vs std::array

int raw[5] = {1, 2, 3};          // 1 2 3 0 0
int zeros[100]{};                // all 0
std::size(raw);                  // 5
int* p = raw;                    // decays: size info lost
void takes(int a[]);             // really: void takes(int* a)

std::array<int, 4> arr{10, 20, 30, 40};
arr.size();                      // 4
arr[1];                          // 20 (unchecked)
arr.at(9);                       // throws std::out_of_range
arr.front(); arr.back();         // 10, 40
arr.fill(0);                     // 0 0 0 0
auto copy = arr;                 // real copy
auto [a, b, c, d] = arr;         // structured bindings
auto deduced = std::to_array({1, 2, 3});   // std::array<int, 3>
int grid[3][4]{};                // 3 rows × 4 cols
std::array<std::array<int, 4>, 3> grid2{};

Code Explained

{1, 2, 3} — remaining elements are zero-initialized
int* p = raw — array-to-pointer decay; sizeof(p) is pointer size
int a[] parameter — just a pointer; pass std::span instead
arr.at() — bounds-checked access
std::to_array — deduces element type and size (C++20)

⚠ Common Mistakes

  • Using sizeof(arr) / sizeof(arr[0]) on a parameter; it's a pointer there, so the result is wrong. Use std::size or std::span
  • Writing past the end of an array; the compiler won't stop you and it corrupts memory
  • Forgetting std::array needs its size as a template argument: std::array<int> a; doesn't compile

✓ Tips & Best Practices

  • Default to std::array for fixed-size data and std::vector for everything else
  • Pass arrays to functions as std::span<const T> to keep the size
  • Use std::array with constexpr for compile-time lookup tables

Quick Summary

  • T a[N] — C array; decays to pointer
  • std::array<T, N> — fixed size, value semantics
  • at() — checked access
  • std::to_array — deduce type and size
