Counted Loops

The classic for loop has three parts: an init statement, a condition checked before each iteration, and an increment run after each iteration. Any part may be empty. Variables declared in the init are scoped to the loop. C++20's std::views::iota offers a range-based alternative for counting that avoids off-by-one mistakes.

Notes

  • for (;;) is an infinite loop
  • The condition is re-evaluated every iteration
  • Use std::size_t (or std::ssize) when indexing containers
  • Prefer range-for when you don't need the index

for Loop Forms

for (int i = 0; i < 5; ++i) {          // 0 1 2 3 4
    std::print("{} ", i);
}
for (int i = 10; i > 0; i -= 3) {}     // 10 7 4 1

for (int i = 0, j = 9; i < j; ++i, --j) {
    std::swap(arr[i], arr[j]);         // reverse in place
}

std::vector<int> v{4, 8, 15};
for (std::size_t i = 0; i < v.size(); ++i) {}  // index loop

for (auto i = v.size(); i-- > 0;) {}   // safe unsigned countdown

for (int i : std::views::iota(1, 4)) {}        // 1 2 3
for (int i : std::views::iota(0) | std::views::take(3)) {}

for (int r = 0; r < 3; ++r)            // nested: 3×3 grid
    for (int c = 0; c < 3; ++c)
        grid[r][c] = r * 3 + c;

Code Explained

i -= 3 — increment can be any expression
i = 0, j = 9 — comma declares two variables of the same type
i-- > 0 — counts down an unsigned index without wrapping
views::iota(1, 4) — half-open range 1, 2, 3
nested loops — inner variable restarts each outer iteration

⚠ Common Mistakes

  • for (unsigned i = n - 1; i >= 0; --i) never ends: unsigned values are always ≥ 0
  • Comparing int i with v.size() gives sign-compare warnings and bugs for huge sizes; use std::size_t or std::ssize(v)
  • Modifying the container (push_back/erase) while index-looping without adjusting the index or bound

✓ Tips & Best Practices

  • Cache expensive conditions: for (auto i = 0uz, n = v.size(); i < n; ++i)
  • Prefer algorithms (std::ranges::fill, transform) over hand-written loops for common tasks
  • Use views::iota with views::reverse for clear countdowns: iota(0, n) | views::reverse

Quick Summary

  • for (init; cond; inc) — classic counted loop
  • std::size_t — index type for containers
  • i-- > 0 — safe unsigned countdown
  • views::iota(a, b) — counting range (C++20)
