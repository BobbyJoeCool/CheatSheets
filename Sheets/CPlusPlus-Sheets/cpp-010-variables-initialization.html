Variables & Initialization

declaration · copy init = · direct init () · brace init {} · narrowing errors · default init · uninitialized reads

Declaring Variables

A variable has a type, a name, and (ideally) an initial value. C++ offers several initialization syntaxes. Brace initialization {} is the most uniform: it works for every type and rejects narrowing conversions that would lose data. A local variable of built-in type that isn't initialized holds an indeterminate value, and reading it is undefined behavior.

Naming

  • Letters, digits, _; can't start with a digit
  • Names starting with _ + uppercase, or containing __, are reserved
  • Common styles: snake_case (std library) or camelCase
  • Declare variables close to first use, in the smallest scope

Initialization Forms

int a;               // default-init: indeterminate if local!
int b = 5;           // copy initialization
int c(5);            // direct initialization
int d{5};            // brace (list) initialization
int e{};             // value-init → 0
int f = {5};         // copy-list initialization

int g{3.7};          // ERROR: narrowing double → int
int h = 3.7;         // compiles, h == 3 (silent truncation)

double x = 1.5, y = 2.0;     // several on one line
auto  n = 10;                // int (type deduced)
const int max_users = 100;   // can't change after init

std::vector<int> v1(3, 7);   // 3 elements: 7 7 7
std::vector<int> v2{3, 7};   // 2 elements: 3 7

Code Explained

int a; — local built-ins are not zeroed; globals and statics are
{} — uniform syntax; blocks narrowing
int e{}; — value-initialization; zero for numbers, nullptr for pointers
int h = 3.7; — allowed but truncates; -Wconversion warns
v1(3, 7) vs v2{3, 7} — braces prefer the initializer_list constructor

⚠ Common Mistakes

  • Reading an uninitialized local: int total; total += x; is UB. Write int total = 0;
  • Widget w(); declares a function, not an object (most vexing parse). Use Widget w; or Widget w{};
  • Expecting std::vector<int> v{5}; to have five elements; it has one element, 5

✓ Tips & Best Practices

  • Default to {} for initialization; switch to () when you need a non-list constructor like vector(n, val)
  • Turn on -Wuninitialized / -Wmaybe-uninitialized; also MSVC's /W4
  • Give class members default values: int count = 0;

Quick Summary

  • T x{v}; — brace init, rejects narrowing
  • T x{}; — value-init to zero
  • int a; — local built-ins start indeterminate
  • const — value fixed after initialization
