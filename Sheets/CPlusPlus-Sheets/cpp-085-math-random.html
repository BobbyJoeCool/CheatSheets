Math & Random

<cmath> · std::numbers::pi · std::abs / pow / sqrt · <random> · std::mt19937 · uniform_int_distribution · std::random_device

Numbers & Randomness

<cmath> provides the usual math functions, overloaded for float, double, and long double, and <numbers> (C++20) provides exact constants like std::numbers::pi. <random> separates a random engine (the bit source) from a distribution (the shape of the output). Seed an engine once and reuse it; never use rand() % n, which is low quality and biased.

Notes

  • std::mt19937 — good general-purpose engine
  • std::random_device — non-deterministic seed source
  • Distributions: uniform_int, uniform_real, normal, bernoulli
  • Same seed → same sequence (great for tests)

<cmath>, <numbers>, <random>

#include <cmath>
#include <numbers>
#include <random>

std::sqrt(16.0);            // 4
std::pow(2.0, 10);          // 1024
std::hypot(3.0, 4.0);       // 5
std::abs(-7);               // 7
std::log(std::numbers::e);  // 1
std::sin(std::numbers::pi / 2);   // 1

std::mt19937 rng{std::random_device{}()};          // seed once
std::uniform_int_distribution<int> die{1, 6};
die(rng);                                          // 1..6 inclusive
std::uniform_real_distribution<double> unit{0.0, 1.0};
unit(rng);                                         // [0, 1)
std::normal_distribution<double> height{170.0, 8.0};
std::ranges::shuffle(deck, rng);                   // shuffle a vector
std::mt19937 test_rng{42};                         // reproducible

Code Explained

<cmath> functions — overloaded for each floating type
std::numbers::pi / e — exact constants (C++20)
random_device{}() — one call to seed the engine
uniform_int_distribution{1, 6} — inclusive both ends
std::ranges::shuffle — uniform shuffle with your engine

⚠ Common Mistakes

  • Creating a new engine (and seed) inside a loop or function on every call; seed once and reuse
  • Using rand() % 6 + 1; it's biased and rand() quality is poor
  • Passing degrees to std::sin; it expects radians. Multiply by std::numbers::pi / 180

✓ Tips & Best Practices

  • Make the engine a function-local static or a member so it's created once
  • Use a fixed seed in tests for reproducible runs
  • Use std::lerp(a, b, t) and std::clamp (C++20/17) instead of hand-written formulas

Quick Summary

  • <cmath> — sqrt, pow, trig, rounding
  • std::numbers::pi — exact constants
  • engine + distribution — the <random> model
  • std::mt19937 rng{seed} — seed once, reuse
