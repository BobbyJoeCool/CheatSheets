Class Templates

template class · out-of-class member definitions · CTAD · deduction guides · default template arguments

Generic Types

A class template defines a family of types: std::vector<int> and std::vector<std::string> are different classes instantiated from one template. Member functions are only instantiated when used, so unused members don't need to compile for every T. CTAD (class template argument deduction, C++17) deduces template arguments from constructor arguments, and deduction guides customize it.

Notes

  • Inside the class, the name alone (Stack) means Stack<T>
  • Out-of-class members repeat template <class T> and use Stack<T>::
  • std::pair p{1, 2.5}; — CTAD at work
  • Default template arguments work like default function arguments

A Class Template

template <typename T, std::size_t Cap = 16>
class Stack {
public:
    void push(T v) { data_.push_back(std::move(v)); }
    T pop();
private:
    std::vector<T> data_;
};
template <typename T, std::size_t Cap>          // out-of-class member
T Stack<T, Cap>::pop() {
    T v = std::move(data_.back()); data_.pop_back(); return v;
}
Stack<int> s; s.push(4); s.pop();   // 4   (Cap = 16 by default)
template <class T> struct Box { T value; };
template <class T> Box(T) -> Box<T>;           // deduction guide
Box b{3.5};                // Box<double> via CTAD

Code Explained

Cap = 16 — default template argument
members defined in the class are implicitly inline
out-of-class definition repeats the template header
deduction guide — Box(T) -> Box<T> (aggregates need it before C++20)
Box b{3.5} — CTAD deduces Box<double>

⚠ Common Mistakes

  • Splitting template member definitions into a .cpp; link errors follow. Keep them in the header
  • Forgetting typename before dependent nested types: typename T::value_type x;
  • Surprises from CTAD with braces: std::vector v{3, 4}; is two ints, not three fours

✓ Tips & Best Practices

  • Keep class templates small; move type-independent code into non-template helpers to reduce bloat
  • Add deduction guides when constructor parameters don't map directly to template parameters
  • Constrain parameters with requires clauses to get clear errors

Quick Summary

  • template <class T> class X — generic type
  • X<T>::member — out-of-class definitions
  • CTAD — deduce arguments from constructors (C++17)
