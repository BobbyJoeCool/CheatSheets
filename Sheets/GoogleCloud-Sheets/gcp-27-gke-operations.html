Running GKE Day to Day

Expose services with the Gateway API (GKE controller provisions Google load balancers) or Ingress. Scale Pods with HPA / VPA and nodes with the cluster autoscaler or node auto-provisioning (built in on Autopilot). Control upgrades with maintenance windows and exclusions. Config Sync applies Git-stored config and Policy Controller enforces policies across a fleet. Backup for GKE protects workloads and volumes.

Key Points

  • Gateway classes: gke-l7-global-external-managed, gke-l7-rilb…
  • PodDisruptionBudgets keep upgrades from taking everything down
  • Managed Service for Prometheus collects metrics without running Prometheus
  • Surge upgrades and blue-green node upgrades are configurable

Gateway, HTTPRoute, HPA

apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata: { name: shop, namespace: api }
spec:
  gatewayClassName: gke-l7-global-external-managed
  listeners:
    - { name: http, protocol: HTTP, port: 80 }
---
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata: { name: api, namespace: api }
spec:
  parentRefs: [{ name: shop }]
  rules:
    - matches: [{ path: { type: PathPrefix, value: /api } }]
      backendRefs: [{ name: api, port: 80 }]
---
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata: { name: api, namespace: api }
spec:
  scaleTargetRef: { apiVersion: apps/v1, kind: Deployment, name: api }
  minReplicas: 3
  maxReplicas: 20
  metrics:
    - type: Resource
      resource:
        name: cpu
        target: { type: Utilization, averageUtilization: 60 }

Backup for GKE

gcloud beta container backup-restore backup-plans create shop-daily \
    --location=us-central1 \
    --cluster=projects/shop-prod-4821/locations/us-central1/clusters/shop \
    --all-namespaces --include-volume-data --cron-schedule="0 3 * * *" \
    --backup-retain-days=14

Code Explained

The Gateway provisions a global external Application Load Balancer
The HTTPRoute sends /api traffic to the api Service
HPA keeps average CPU near 60% across 3–20 Pods
The backup plan protects every namespace nightly for 14 days

Cost Check

  • Each Gateway / Ingress creates billable load balancer pieces
  • Backup for GKE: per protected Pod + backup storage
  • Right-size requests (VPA recommendations) to cut Autopilot bills

Limits & Quotas

  • Maintenance exclusions are limited in length and number
  • HPA needs resource requests to compute utilization
  • Gateway / Ingress map to load balancer quotas (forwarding rules, backend services)

Do & Don't

  • Do Use PodDisruptionBudgets for critical Deployments
  • Do Set maintenance windows that match low traffic
  • Don’t Run without requests (HPA and Autopilot both rely on them)
  • Don’t Upgrade on the Rapid channel in production

Local Testing

  • kubectl apply --dry-run=server -f gateway.yaml
  • kind + Gateway API CRDs for local routing tests
  • Restore a Backup for GKE plan to a test cluster

Production Checklist

  • Gateway API with Cloud Armor via GCPBackendPolicy
  • Maintenance windows + PDBs
  • Backup for GKE tested by restore drills
