Prebuilt and Custom ML

Google Cloud offers prebuilt APIs for common tasks (Vision, Speech-to-Text, Text-to-Speech, Translation, Natural Language, Video Intelligence), Document AI for parsing forms, invoices and IDs, and the Agent Platform (Vertex AI) for custom training, endpoints, pipelines and model registry. Gemini Code Assist brings AI help into IDEs and the console.

Key Points

  • Try Gemini first: many vision, OCR and classification tasks no longer need a dedicated API
  • Document AI processors are created per type (OCR, Form, Invoice…)
  • Custom training runs your container on managed infrastructure (GPUs / TPUs)
  • BigQuery ML trains models with SQL

Prebuilt APIs (Python)

from google.cloud import vision, translate_v3, documentai

img = vision.Image(source=vision.ImageSource(
    image_uri="gs://acme-media-prod/2026/receipt.jpg"))
labels = vision.ImageAnnotatorClient().label_detection(image=img)
print([l.description for l in labels.label_annotations])

tr = translate_v3.TranslationServiceClient()
out = tr.translate_text(parent="projects/shop-prod-4821/locations/global",
    contents=["Your order has shipped"], target_language_code="es")
print(out.translations[0].translated_text)

doc_client = documentai.DocumentProcessorServiceClient()
name = doc_client.processor_path("shop-prod-4821", "us", "a1b2c3d4e5f6")
with open("invoice.pdf", "rb") as f:
    raw = documentai.RawDocument(content=f.read(),
                                 mime_type="application/pdf")
result = doc_client.process_document(
    request=documentai.ProcessRequest(name=name, raw_document=raw))
for e in result.document.entities:
    print(e.type_, e.mention_text)

Custom Training and Endpoint

TRAIN=us-central1-docker.pkg.dev/shop-prod-4821/ml/train:1.0
POOL=machine-type=n1-standard-8,replica-count=1
gcloud ai custom-jobs create --region=us-central1 --display-name=churn \
    --worker-pool-spec=$POOL,container-image-uri=$TRAIN
gcloud ai endpoints create --region=us-central1 --display-name=churn

Code Explained

Vision labels an image straight from Cloud Storage
Translation uses the global location
The invoice processor returns typed entities (totals, dates)
Custom jobs run your training container on managed VMs

Cost Check

  • Prebuilt APIs bill per unit (image, minute, character, page) with free monthly tiers
  • Endpoints bill per node-hour while deployed, even idle
  • Training bills per machine / accelerator hour

Do & Don't

  • Do Start with a prebuilt API or Gemini before custom training
  • Do Undeploy idle endpoints
  • Don’t Send sensitive documents without checking data residency
  • Don’t Train custom models for tasks a prebuilt API already does well

Local Testing

  • Client libraries work locally with ADC
  • Small sample files for quick API checks
  • Train locally in the same container before submitting jobs

Production Checklist

  • Processors and endpoints in IaC
  • Monitoring on prediction latency and errors
  • Cost alerts on per-unit API usage
