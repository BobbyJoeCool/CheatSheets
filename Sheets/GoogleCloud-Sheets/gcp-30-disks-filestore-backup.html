Disks, Filestore & Backup

Persistent Disk vs Hyperdisk · regional disks · snapshot schedules · Filestore (NFS) · Cloud Storage FUSE · Backup and DR Service

Block, File and Backups

VM block storage comes as Persistent Disk (balanced, SSD, standard) or Hyperdisk (Balanced, Throughput, Extreme, ML), where you tune IOPS and throughput separately. Regional disks replicate across two zones. Filestore provides managed NFS shares. Cloud Storage FUSE mounts buckets for read-heavy workloads. Backup and DR Service manages backup plans, vaults and app-consistent backups.

Key Points

  • Disks can grow online, never shrink
  • Hyperdisk Balanced High Availability replicates synchronously across zones
  • Local SSDs are fast but lose data when the VM stops
  • Backup vaults can be immutable and indelible for ransomware protection

Disks, Snapshots, Filestore, Backups

gcloud compute disks create data-1 --zone=us-central1-a \
    --type=hyperdisk-balanced --size=500GB \
    --provisioned-iops=6000 --provisioned-throughput=290
gcloud compute instances attach-disk web-1 --disk=data-1 \
    --zone=us-central1-a
gcloud compute disks resize data-1 --zone=us-central1-a --size=1TB

gcloud compute disks create db-ha --region=us-central1 --type=pd-ssd \
    --size=200GB --replica-zones=us-central1-a,us-central1-b

gcloud filestore instances create shared --zone=us-central1-a \
    --tier=BASIC_HDD --file-share=name=vol1,capacity=1TB \
    --network=name=vpc-shop
# On a VM: sudo mount 10.10.0.20:/vol1 /mnt/shared

gcloud backup-dr backup-vaults create vault-prod --location=us-central1 \
    --backup-min-enforced-retention=30d
VAULT=projects/shop-prod-4821/locations/us-central1/backupVaults/vault-prod
RULE=rule-id=daily,recurrence=DAILY,retention-days=30
gcloud backup-dr backup-plans create daily-vm --location=us-central1 \
    --backup-vault=$VAULT --resource-type=compute.googleapis.com/Instance \
    --backup-rule=$RULE,backup-window-start=2,backup-window-end=6

Code Explained

Hyperdisk sets IOPS and throughput independently of size
The regional disk survives the loss of one zone
Filestore exposes an NFS share on the VPC
The vault enforces at least 30 days of retention

Cost Check

  • Disks bill per GB provisioned (Hyperdisk adds IOPS / throughput)
  • Filestore bills per provisioned TiB even when empty
  • Snapshots and backup vaults bill per GB stored

Do & Don't

  • Do Use Hyperdisk when you need tuned IOPS
  • Do Store backups in a locked vault
  • Don’t Keep important data only on Local SSD
  • Don’t Overprovision Filestore capacity you never use

Local Testing

  • fio benchmarks disk IOPS on a test VM
  • Restore a snapshot to a new disk to test recovery
  • Mount a test bucket with gcsfuse to check access patterns

Production Checklist

  • Backup plans with locked vaults
  • Regional disks for stateful single VMs
  • Restore drills scheduled and documented
