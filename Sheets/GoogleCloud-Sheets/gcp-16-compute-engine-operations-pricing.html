Sheet 16

Compute Engine Operations & Pricing

Spot VMs · committed use discounts · sustained use discounts · snapshots & machine images · live migration · VM Manager (OS patching)

Running VMs Cheaply and Safely

Compute Engine pricing has three levers: sustained use discounts (automatic on some families), committed use discounts (1 or 3 years, resource- or spend-based) and Spot VMs (deep discount, preemptible). Snapshots back up disks; machine images capture a whole VM. Live migration moves VMs during host maintenance, and VM Manager patches and inventories OSes.

Key Points

  • Spot VMs get a 30-second shutdown notice
  • Snapshot schedules automate disk backups
  • Flexible CUDs apply across families and regions
  • Rightsizing recommendations come from the Recommender

Spot, Snapshots, Commitments, Patching

gcloud compute instances create batch-1 --zone=us-central1-a \
    --machine-type=c4-standard-8 --provisioning-model=SPOT \
    --instance-termination-action=DELETE \
    --image-family=debian-12 --image-project=debian-cloud --no-address

gcloud compute resource-policies create snapshot-schedule daily-7 \
    --region=us-central1 --daily-schedule --start-time=03:00 \
    --max-retention-days=7
gcloud compute disks add-resource-policies web-1 --zone=us-central1-a \
    --resource-policies=daily-7
gcloud compute snapshots create web-1-pre-upgrade \
    --source-disk=web-1 --source-disk-zone=us-central1-a
gcloud compute machine-images create web-1-img --source-instance=web-1 \
    --source-instance-zone=us-central1-a

gcloud compute commitments create cud-web --region=us-central1 \
    --plan=36-month --resources=vcpu=16,memory=64GB

gcloud compute os-config patch-jobs execute --instance-filter-all \
    --display-name=monthly --duration=3600s
gcloud recommender recommendations list --location=us-central1-a \
    --recommender=google.compute.instance.MachineTypeRecommender

Code Explained

The Spot VM is deleted when Google reclaims capacity
The resource policy snapshots the disk daily and keeps 7 days
Machine images capture all disks plus configuration
The recommender suggests smaller machine types for idle VMs

Cost Check

  • Spot VMs: up to 60–91% off on-demand
  • CUDs: up to 55% off (more for memory-optimized) for 1–3 years
  • Snapshots bill per GB stored (incremental)

Do & Don't

  • Do Run batch and CI on Spot VMs
  • Do Buy CUDs only for the steady baseline
  • Don’t Forget snapshot retention (they pile up)
  • Don’t Treat live migration as a substitute for multi-zone design

Local Testing

  • Simulate preemption: gcloud compute instances simulate-maintenance-event
  • Restore a snapshot to a scratch VM to test backups
  • Pricing calculator for CUD vs on-demand

Production Checklist

  • Snapshot schedules on every persistent disk
  • CUDs covering baseline; Spot for batch
  • VM Manager patch policies with reporting
