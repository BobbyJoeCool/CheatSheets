Logs and Traces

Cloud Logging ingests logs from services, agents and apps (structured JSON on stdout works on Cloud Run and GKE). The Log Router sends entries through sinks to log buckets, BigQuery, Cloud Storage or Pub/Sub. Query with the Logging query language or Log Analytics (SQL). Cloud Trace receives OpenTelemetry spans, and Error Reporting groups exceptions.

Key Points

  • _Required bucket keeps audit logs 400 days; _Default keeps 30 days by default
  • Exclusion filters drop noisy logs before ingestion charges
  • Write JSON with severity and message fields for structured logs
  • Trace context propagates via traceparent headers

Query, Route, Retain

gcloud logging read 'resource.type="cloud_run_revision"
  AND resource.labels.service_name="api" AND severity>=ERROR' \
  --freshness=1h --limit=20 --format="value(timestamp,jsonPayload.message)"

gcloud logging buckets update _Default --location=global --retention-days=90
gcloud logging sinks create audit-to-bq \
    bigquery.googleapis.com/projects/sec-logs-1111/datasets/audit \
    --log-filter='logName:"cloudaudit.googleapis.com"' \
    --organization=123456789012 --include-children
gcloud logging sinks update _Default \
    --add-exclusion=name=no-health,filter='httpRequest.requestUrl:"/healthz"'
gcloud logging metrics create checkout_errors \
    --log-filter='jsonPayload.event="checkout_failed"'

Structured Logs and Traces (Python)

import json, sys
def log(severity, message, **fields):
    print(json.dumps({"severity": severity, "message": message, **fields}),
          file=sys.stdout, flush=True)
log("ERROR", "checkout failed", event="checkout_failed", order="o-1001")

from opentelemetry import trace
tracer = trace.get_tracer("shop.api")
with tracer.start_as_current_span("charge-card") as span:
    span.set_attribute("order.id", "o-1001")
    charge()

Code Explained

The query finds recent errors from one Cloud Run service
The org-level sink copies all audit logs to BigQuery
The exclusion drops health-check request logs
JSON lines become structured entries with severity

Cost Check

  • Ingestion per GiB after 50 GiB per project per month free
  • Retention beyond 30 days bills per GiB-month
  • Exclusions and sampling cut the biggest costs

Limits & Quotas

  • Log entry size up to 256 KB
  • Default _Default retention 30 days (configurable up to 3,650)
  • Write quotas per project per minute (batch writes)

Do & Don't

  • Do Log structured JSON with severity
  • Do Centralize audit logs with an org-level sink
  • Don’t Log secrets, tokens or full request bodies
  • Don’t Keep debug logging on in production without exclusions

Local Testing

  • Print the same JSON locally; read with jq
  • Jaeger in Docker receives OTLP spans locally
  • gcloud logging tail streams live logs (beta)

Production Checklist

  • Retention set per bucket; audit logs centralized
  • Exclusions for noisy logs
  • Traces sampled and linked to logs
