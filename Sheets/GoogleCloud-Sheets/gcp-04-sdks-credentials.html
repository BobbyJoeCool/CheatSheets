Sheet 04

Client Libraries & Credentials

Application Default Credentials · lookup order · Python & Node.js client libraries · service account impersonation · metadata server · avoiding key files

Authenticating Code

Google Cloud client libraries use Application Default Credentials (ADC): the GOOGLE_APPLICATION_CREDENTIALS file if set, your gcloud auth application-default login credentials on a laptop, or the attached service account via the metadata server on Google Cloud compute. The same code works everywhere with no keys in the code.

Key Points

  • Python: pip install google-cloud-storage; Node: npm i @google-cloud/storage
  • ADC can impersonate a service account locally (--impersonate-service-account)
  • Quota project is set with gcloud auth application-default set-quota-project
  • Prefer WIF configs over key files outside Google Cloud

Security Check

  • Block service account key creation with org policy
  • Attach a dedicated service account to each workload
  • Never commit JSON key files; scan repos for them

Python and Node.js

from google.cloud import storage, secretmanager
gcs = storage.Client()                     # ADC: laptop login or attached SA
for b in gcs.list_buckets():
    print(b.name)

sm = secretmanager.SecretManagerServiceClient()
name = "projects/shop-prod-4821/secrets/db-password/versions/latest"
password = sm.access_secret_version(name=name).payload.data.decode()

Node.js

import { Storage } from "@google-cloud/storage";
const storage = new Storage();             // ADC
const bucket = storage.bucket("acme-media-prod");
const [files] = await bucket.getFiles({ prefix: "2026/" });
console.log(files.map(f => f.name));

Local ADC Options

gcloud auth application-default login
gcloud auth application-default login \
    --impersonate-service-account=api@shop-dev-1234.iam.gserviceaccount.com

Code Explained

No credentials appear in code: ADC finds them
Secret Manager returns bytes; decode to text
The Node client uses the same ADC chain
Impersonated ADC tests with the app's real permissions

Cost Check

  • Client libraries are free; you pay for API usage
  • Metadata server token requests are free
  • Reusing clients avoids extra connection and auth overhead

Do & Don't

  • Do Create one client per process and reuse it
  • Do Use impersonation locally to test least privilege
  • Don’t Download service account keys
  • Don’t Use your personal user credentials in production

Local Testing

  • ADC from gcloud auth application-default login
  • Emulators: set PUBSUB_EMULATOR_HOST, FIRESTORE_EMULATOR_HOST and the client libraries use them
  • Unit tests mock clients or use emulators

Production Checklist

  • Dedicated, least-privilege service account per workload
  • Key creation disabled by org policy
  • No GOOGLE_APPLICATION_CREDENTIALS key files on servers
