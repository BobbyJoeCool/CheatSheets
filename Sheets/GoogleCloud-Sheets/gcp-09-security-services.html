Security Services

Cloud Audit Logs · Security Command Center · Cloud Armor · VPC Service Controls · Identity-Aware Proxy · Binary Authorization

Audit, Detect and Protect

Cloud Audit Logs record admin activity (always on), data access (opt-in), system events and policy denials. Security Command Center (SCC) finds misconfigurations, vulnerabilities and threats. Cloud Armor is the WAF and DDoS layer for load balancers. VPC Service Controls put perimeters around services to stop data exfiltration, IAP gates apps and SSH by identity, and Binary Authorization only deploys trusted images.

Key Points

  • Admin Activity logs are free and kept 400 days
  • Data Access logs are off by default for most services (they can be large)
  • SCC Standard is free; Premium / Enterprise add threat detection and more
  • IAP TCP forwarding replaces bastion hosts

Audit, SCC, Armor, IAP

gcloud logging read 'logName:"cloudaudit.googleapis.com%2Factivity" AND
  protoPayload.methodName:"SetIamPolicy"' --freshness=1d --limit=10 \
  --format="table(timestamp,protoPayload.authenticationInfo.principalEmail)"

gcloud scc findings list organizations/123456789012 \
    --filter='state="ACTIVE" AND severity="HIGH"' --limit=10

gcloud compute security-policies create shop-waf
gcloud compute security-policies rules create 1000 \
    --security-policy=shop-waf \
    --expression="evaluatePreconfiguredWaf('sqli-v33-stable')" \
    --action=deny-403
gcloud compute backend-services update web-be --global \
    --security-policy=shop-waf

gcloud compute ssh web-1 --zone=us-central1-a --tunnel-through-iap
gcloud iap web enable --resource-type=backend-services --service=web-be

Code Explained

Admin activity audit logs show who changed IAM policies
SCC lists active high-severity findings for the organization
The Cloud Armor rule blocks SQL injection with a preconfigured WAF rule
IAP tunnels SSH without external IPs or open port 22 to the world

AWS / Azure Equivalent

  • AWS CloudTrail, GuardDuty, Security Hub, WAF (aws-09)
  • Azure Activity Log, Defender for Cloud, Azure Policy, Sentinel (az-09)

Cost Check

  • Admin Activity audit logs are free; Data Access logs bill as log ingestion
  • Cloud Armor: per policy + per rule + per million requests
  • SCC Premium / Enterprise are subscription priced

Do & Don't

  • Do Route audit logs to a central, locked logging project
  • Do Put Cloud Armor in front of public load balancers
  • Don’t Turn on every Data Access log everywhere without a cost plan
  • Don’t Leave SCC findings without owners

Local Testing

  • Prowler and other scanners audit projects from your laptop
  • Checkov / tfsec scan Terraform before apply
  • Test VPC SC perimeters in dry-run mode first

Production Checklist

  • Org-level log sink for audit logs
  • SCC enabled with findings routed to on-call
  • IAP for admin access; Cloud Armor on public endpoints
