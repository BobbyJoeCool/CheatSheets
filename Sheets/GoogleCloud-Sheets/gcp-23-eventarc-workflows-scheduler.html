Eventarc, Workflows & Scheduler

Eventarc triggers · CloudEvents · event sources (direct, audit logs, Pub/Sub) · Workflows (YAML orchestration) · Cloud Scheduler · Cloud Tasks

Events and Orchestration

Eventarc routes events from Google services (directly, via Cloud Audit Logs, or Pub/Sub) and third parties to Cloud Run, GKE, Workflows or functions as CloudEvents. Workflows orchestrates steps (HTTP calls, connectors, conditions, retries, parallel branches) in YAML. Cloud Scheduler runs cron jobs, and Cloud Tasks queues HTTP calls with rate limiting.

Key Points

  • Eventarc Advanced adds a message bus with routing and transformation
  • Workflows connectors call Google APIs with built-in auth and retries
  • Callbacks let Workflows wait for human approval or external events
  • Cloud Tasks gives explicit, rate-limited dispatch to one handler

Trigger and Schedule

gcloud eventarc triggers create on-upload --location=us-central1 \
    --destination-run-service=thumbnailer \
    --destination-run-region=us-central1 \
    --event-filters="type=google.cloud.storage.object.v1.finalized" \
    --event-filters="bucket=acme-uploads-prod" \
    --service-account=events@shop-prod-4821.iam.gserviceaccount.com

gcloud workflows deploy order-flow --location=us-central1 \
    --source=order-flow.yaml \
    --service-account=wf@shop-prod-4821.iam.gserviceaccount.com

gcloud scheduler jobs create pubsub nightly-report --location=us-central1 \
    --schedule="0 6 * * 1-5" --time-zone="America/Chicago" \
    --topic=reports --message-body='{"type":"daily"}'

order-flow.yaml

main:
  params: [input]
  steps:
    - charge:
        try:
          call: http.post
          args:
            url: https://payments-abc123-uc.a.run.app/charge
            auth: { type: OIDC }
            body: { orderId: ${input.orderId} }
          result: payment
        retry: ${http.default_retry}
    - ship:
        call: googleapis.pubsub.v1.projects.topics.publish
        args:
          topic: projects/shop-prod-4821/topics/ship
          body:
            messages: [{ data: ${base64.encode(json.encode(input))} }]

Code Explained

The trigger sends finalized-object events to the thumbnailer
Workflows calls Cloud Run with an OIDC token and retries
The Pub/Sub connector publishes the ship event
Scheduler publishes a weekday report message at 6 AM Chicago time

AWS / Azure Equivalent

Cost Check

  • Eventarc: Google-source events free; Pub/Sub delivery bills as Pub/Sub
  • Workflows: per 1,000 steps (internal vs external)
  • Cloud Tasks / Scheduler: free tiers, then per operation / job

Do & Don't

  • Do Give each trigger and workflow its own service account
  • Do Use connectors instead of raw HTTP to Google APIs
  • Don’t Chain functions with direct calls when a workflow fits
  • Don’t Forget that events can be delivered more than once

Local Testing

  • Send sample CloudEvents to a local service with curl
  • Workflows has no local emulator: test in a dev project
  • Pub/Sub emulator for message-driven flows

Production Checklist

  • Dead-letter and retry policies on triggers
  • Workflow execution failures alerted
  • Schedules in IaC with explicit time zones
