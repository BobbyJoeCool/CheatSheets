Projects & Billing

Projects, APIs and Paying

Each project links to one billing account. Projects are where APIs are enabled, quotas apply and IAM is granted. Budgets alert at thresholds (and can publish to Pub/Sub for automation). Labels attribute costs, and billing export to BigQuery gives detailed, queryable cost data. Shutting down a project stops its billing.

Key Points

  • Deleted projects can be restored for 30 days
  • Budgets alert but do not cap spending (automate shutdown via Pub/Sub if needed)
  • Quotas are per project (and often per region)
  • Use folders to group projects by team or environment

Limits & Quotas

  • Project creation is quota-limited per user / organization (request more)
  • Up to 64 labels per resource
  • Service quotas per project and region: check in Quotas & System Limits

Projects, Billing, Budgets, Quotas

gcloud projects create shop-prod-4821 --folder=987654321 \
    --labels=team=web,env=prod
gcloud billing projects link shop-prod-4821 \
    --billing-account=0X0X0X-0X0X0X-0X0X0X
gcloud services enable run.googleapis.com sqladmin.googleapis.com \
    secretmanager.googleapis.com --project=shop-prod-4821

gcloud billing budgets create --billing-account=0X0X0X-0X0X0X-0X0X0X \
    --display-name="shop-prod monthly" --budget-amount=300USD \
    --filter-projects=projects/shop-prod-4821 \
    --threshold-rule=percent=0.5 --threshold-rule=percent=0.9 \
    --threshold-rule=percent=1.0

gcloud projects update shop-prod-4821 --update-labels=costcenter=1234
gcloud compute project-info describe --flatten=quotas \
    --format="table(quotas.metric,quotas.limit,quotas.usage)"
gcloud projects delete shop-scratch-1    # stops billing; 30-day restore

Code Explained

Labels set at creation help cost reports
Billing must be linked before most APIs work
Thresholds at 50%, 90%, 100% of $300 email billing admins
project-info describe lists Compute Engine quotas and usage

Cost Check

  • Projects, budgets and billing export are free (BigQuery storage / queries bill normally)
  • Sustained use discounts apply automatically to many VM types
  • Leftover static IPs, disks and snapshots keep billing

Do & Don't

  • Do Create a budget per project before deploying
  • Do Turn on BigQuery billing export on day one
  • Don’t Share one project across teams and environments
  • Don’t Assume a budget alert will stop spending

Local Testing

  • Estimate with the Google Cloud Pricing Calculator
  • Infracost reads Terraform google plans
  • Practice in a scratch project you delete afterwards

Production Checklist

  • Budgets with Pub/Sub alerts per project
  • Billing export to BigQuery with dashboards
  • Label policy enforced via org policy / IaC
