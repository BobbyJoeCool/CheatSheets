Object Storage

Cloud Storage keeps objects in buckets with globally unique names. A bucket's location type (region, dual-region, multi-region) sets availability and latency. Storage classes (Standard, Nearline, Coldline, Archive) trade storage price for retrieval cost and minimum storage duration; Autoclass moves objects between classes automatically. All classes have millisecond access.

Key Points

  • Object names can contain /, but the namespace is flat (folders are simulated, unless hierarchical namespace is on)
  • gcloud storage does parallel composite uploads automatically
  • Strong read-after-write consistency for objects and listings
  • Hierarchical namespace buckets add real folders for analytics workloads

Security Check

  • Keep public access prevention enforced (org policy)
  • Use uniform bucket-level access, not object ACLs
  • Grant bucket-level IAM to service accounts, not project-wide storage roles

Limits & Quotas

  • Object size up to 5 TiB
  • About 1 write per second to the same object name
  • Bucket names are global and DNS-compatible (3–63 characters)

Buckets and Objects

gcloud storage buckets create gs://acme-media-prod --location=us-central1 \
    --default-storage-class=STANDARD --uniform-bucket-level-access \
    --public-access-prevention
gcloud storage buckets create gs://acme-logs-archive --location=US \
    --enable-autoclass

gcloud storage cp report.pdf gs://acme-media-prod/2026/
gcloud storage cp -r ./site gs://acme-site/
gcloud storage rsync ./build gs://acme-site --recursive \
    --delete-unmatched-destination-objects
gcloud storage ls -l gs://acme-media-prod/2026/
gcloud storage objects update gs://acme-media-prod/2026/report.pdf \
    --storage-class=NEARLINE
gcloud storage rm gs://acme-media-prod/tmp/**
gcloud storage du -s gs://acme-media-prod

Python Client

from google.cloud import storage
bucket = storage.Client().bucket("acme-media-prod")
bucket.blob("2026/report.pdf").upload_from_filename("report.pdf")
for blob in bucket.list_blobs(prefix="2026/"):
    print(blob.name, blob.size, blob.storage_class)
data = bucket.blob("2026/notes.txt").download_as_text()

Code Explained

UBLA + public access prevention lock the bucket down
Autoclass picks classes per object based on access
rsync with delete mirrors a build folder
The double-star wildcard matches every object under a prefix

Cost Check

  • Storage per GB-month by class + operations + retrieval (colder classes)
  • Minimum durations: Nearline 30, Coldline 90, Archive 365 days
  • Egress and cross-region replication bill per GB

Do & Don't

  • Do Use Autoclass when access patterns are unknown
  • Do Prefix object names to spread load and organize lifecycle
  • Don’t Use Archive for data you read often (retrieval fees)
  • Don’t Mount buckets as a POSIX file system for databases

Local Testing

  • gcloud storage against a dev bucket
  • fake-gcs-server in Docker emulates the JSON API
  • Unit tests mock the storage client

Production Checklist

  • UBLA, public access prevention, bucket IAM
  • Lifecycle / Autoclass for cost
  • Soft delete and versioning set for critical buckets
