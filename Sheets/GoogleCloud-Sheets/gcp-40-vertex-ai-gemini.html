Generative AI on Google Cloud

Gemini Enterprise Agent Platform (the April 2026 rename of Vertex AI) serves Gemini models and partner / open models from Model Garden. Call them with the Google Gen AI SDK (google-genai) using ADC and IAM, no API keys. Features include streaming, structured output, function calling, grounding with Google Search or your data (RAG Engine, Vertex AI Search) and Agent Builder with the Agent Development Kit (ADK).

Key Points

  • The global location routes to available capacity; regional locations keep data in a region
  • Model IDs change often: check the model versions page before pinning
  • Older Gemini 2.5 models are being retired; plan migrations
  • Provisioned Throughput reserves capacity for production

Gemini With the Gen AI SDK (Python)

from google import genai
from google.genai import types

client = genai.Client(vertexai=True, project="shop-prod-4821",
                      location="global")

resp = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="Summarize this support ticket in two sentences: ...",
    config=types.GenerateContentConfig(temperature=0.2,
                                       max_output_tokens=300))
print(resp.text, resp.usage_metadata.total_token_count)

for chunk in client.models.generate_content_stream(
        model="gemini-3.8-flash", contents="Write a product blurb"):
    print(chunk.text, end="")

grounded = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="What changed in the latest Cloud Run release notes?",
    config=types.GenerateContentConfig(
        tools=[types.Tool(google_search=types.GoogleSearch())]))
print(grounded.text)

Setup

gcloud services enable aiplatform.googleapis.com
gcloud projects add-iam-policy-binding shop-prod-4821 \
    --member="serviceAccount:api@shop-prod-4821.iam.gserviceaccount.com" \
    --role="roles/aiplatform.user"

Usage metadata reports tokens for cost tracking
Streaming prints text as it is generated
The Google Search tool grounds answers in fresh web results

Cost Check

  • Billed per input / output token (rates differ by model and context length)
  • Batch prediction and context caching cut costs
  • Grounding with Google Search bills per grounded request beyond free allowances

Security Check

  • Grant roles/aiplatform.user to the app's service account only
  • Use VPC Service Controls around AI APIs for sensitive data
  • Never send secrets or unneeded personal data in prompts

Limits & Quotas

  • Quotas are per model and region (or dynamic shared quota on global)
  • 429 errors mean quota / capacity: retry with backoff
  • Context window and output tokens are limited per model

Do & Don't

  • Do Use structured output (response_schema) for machine-read results
  • Do Log token usage per request for cost attribution
  • Don’t Hard-code a model ID without a plan to update it
  • Don’t Use API keys in server apps (use ADC / service accounts)

Local Testing

  • Same SDK with ADC from gcloud auth application-default login
  • Agent Studio (formerly Vertex AI Studio) to draft prompts
  • Mock the client in unit tests; run evals separately

Production Checklist

  • Dedicated SA with aiplatform.user
  • Retries with backoff for 429s; quota monitored
  • Prompt / response logging policy reviewed for privacy
