Fabric Native Components

codegenNativeComponent · props spec · native view managers · events · commands · interop layer

Wrapping Native Views

A Fabric Native Component exposes a native view (a map, a video player, a custom chart) as a React component. Like modules, you write a TypeScript spec of its props, events, and commands, run Codegen, and implement the view in Kotlin and Objective-C++/Swift. The interop layer lets many old (Paper) components work without rewriting, but new code should use Fabric directly.

Spec Types

  • ViewProps — base props (style, layout)
  • DirectEventHandler<T> — event to one component
  • BubblingEventHandler<T> — bubbles up the tree
  • WithDefault<T, v> — default prop values

Component Spec

// specs/WebViewNativeComponent.ts
import type { CodegenTypes, HostComponent, ViewProps } from 'react-native'
import { codegenNativeComponent, codegenNativeCommands } from 'react-native'

type LoadEvent = Readonly<{ result: 'success' | 'error' }>

export interface NativeProps extends ViewProps {
  sourceURL?: string
  zoomEnabled?: CodegenTypes.WithDefault<boolean, true>
  onScriptLoaded?: CodegenTypes.BubblingEventHandler<LoadEvent> | null
}

export interface NativeCommands {
  reload: (viewRef: React.ElementRef<HostComponent<NativeProps>>) => void
}
export const Commands = codegenNativeCommands<NativeCommands>({
  supportedCommands: ['reload'] })

export default codegenNativeComponent<NativeProps>('CustomWebView')

// Usage
<CustomWebView ref={ref} style={{ flex: 1 }}
  sourceURL="https://example.com"
  onScriptLoaded={e => log(e.nativeEvent)} />
Commands.reload(ref.current!)

Notes

ViewProps — gives style, accessibility, layout
WithDefault — native default if prop omitted
BubblingEventHandler — read data on e.nativeEvent
Commands — imperative calls like reload()
codegenConfig.type — "components" or "all"

⚠ Common Mistakes

  • Passing large data through props on every render; send it via a command or module instead
  • Expecting setNativeProps-style mutations; Fabric views update through props
  • Forgetting to mark optional event props | null, which breaks Codegen

✓ Tips & Best Practices

  • Read existing open-source Fabric components (e.g. react-native-screens) as references
  • Use Expo Modules' View when you'd rather write Swift and Kotlin only
  • Keep native views dumb; put logic in JS where it's testable

Quick Summary

  • codegenNativeComponent — declare view
  • Props / events / commands — the spec
  • ViewManager / ComponentView — native impl
  • Interop layer — legacy views still run
