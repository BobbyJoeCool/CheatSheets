Building and Running on iOS

iOS builds require macOS and Xcode. The CLI drives xcodebuild for you, but Xcode is where you set signing, inspect native crashes, and use Instruments. A scheme picks the target and build configuration (Debug loads JS from Metro; Release embeds an optimized bundle). Simulators are managed with xcrun simctl; physical devices need signing and Developer Mode.

Version Requirements

  • RN 0.87 minimum: Xcode 16.1
  • App Store uploads need Xcode 26 / iOS 26 SDK (since Apr 2026)
  • Expo SDK 56+: Xcode 26.4
  • iOS 27 SDK (Xcode 27) requires the UIKit scene lifecycle

Running and Simulator Control

# Run
npx expo run:ios                              # default simulator
npx expo run:ios --device "My iPhone"         # physical device
npx expo run:ios --configuration Release
npx react-native run-ios --simulator "iPhone 17 Pro"
npx react-native run-ios --udid <UDID>

# Simulators
xcrun simctl list devices available
xcrun simctl boot "iPhone 17"
open -a Simulator
xcrun simctl openurl booted myapp://post/42
xcrun simctl push booted com.acme.myapp payload.apns
xcrun simctl io booted screenshot shot.png
xcrun simctl privacy booted grant photos com.acme.myapp
xcrun simctl erase all                        # factory reset

# Build without running
xcodebuild -workspace ios/MyApp.xcworkspace -scheme MyApp \
  -configuration Release -sdk iphonesimulator build

Notes

--device — prompts if no name is given
--configuration Release — test real performance
simctl push — fake a push notification from a JSON file
simctl privacy grant — skip permission prompts in tests
xcodebuild — CI builds without Xcode UI

iOS

  • xcrun simctl list devices lists simulators
  • npx expo run:ios --device targets a connected iPhone
  • Turn on Developer Mode on iOS 16+ devices

Android

  • emulator -list-avds / adb devices
  • npx expo run:android --device picks a device
  • Turn on USB debugging in Developer options

⚠ Common Mistakes

  • Judging speed or animations in Debug; JS runs unoptimized with dev checks
  • Updating macOS/Xcode the week of a release; new Xcode versions often need pod or RN updates
  • Running on a device without enabling Developer Mode (Settings → Privacy & Security)

✓ Tips & Best Practices

  • Use xcrun simctl in scripts to reset state before E2E tests
  • Keep one older simulator runtime installed to test your minimum iOS version
  • Use Product → Profile (Instruments) on a Release build to find native hot spots
