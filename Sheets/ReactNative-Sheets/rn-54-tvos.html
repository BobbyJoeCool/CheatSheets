tvOS (Apple TV)

react-native-tvos · Platform.isTV · focus engine · TVFocusGuideView · useTVEventHandler · Siri Remote

Building for the Living Room

Apple TV support comes from react-native-tvos, a community fork that tracks core closely (0.87.1-1 as of Oct 2026) and also supports Android TV. You alias it as react-native in package.json. TV apps have no touch: users move a focus highlight with the Siri Remote, so every interactive element must be focusable and the layout must make focus movement predictable.

Setup

  • "react-native": "npm:react-native-tvos@latest"
  • Don't install core react-native alongside it
  • Expo: TV builds via CNG (Expo dev menu works on TV since SDK 54)
  • Platform.isTV is true on tvOS and Android TV

Focus and Remote Events

import { TVFocusGuideView, useTVEventHandler, Platform } from 'react-native'

function Row({ items }: { items: Movie[] }) {
  return (
    <TVFocusGuideView autoFocus trapFocusLeft trapFocusRight
      style={{ flexDirection: 'row', gap: 24 }}>
      {items.map((m, i) => (
        <Pressable key={m.id} hasTVPreferredFocus={i === 0}
          onFocus={() => setActive(m.id)}
          style={({ focused }) => [styles.poster,
            focused && { transform: [{ scale: 1.1 }] }]}>
          <Image source={{ uri: m.poster }} style={styles.img} />
        </Pressable>
      ))}
    </TVFocusGuideView>
  )
}

useTVEventHandler(evt => {
  if (evt.eventType === 'playPause') togglePlayback()
})

// Menu / back button on Apple TV
TVEventControl.enableTVMenuKey()
BackHandler.addEventListener('hardwareBackPress',
  () => { goBack(); return true })

Notes

TVFocusGuideView — groups focus and remembers last item
autoFocus — focus first child on first visit
trapFocus* — keep focus inside the row
hasTVPreferredFocus — initial focus target
focused style state — show the highlight

iOS

  • One react-native-tvos package builds iOS and tvOS
  • Expo: prebuild with EXPO_TV=1 for TV targets
  • tvOS has no WebKit — no WebView

Android

  • Needs the LEANBACK_LAUNCHER intent and a banner image
  • Mark touchscreen as not required in the manifest
  • Navigation is D-pad focus, not touch

⚠ Common Mistakes

  • Using touch-only components with no focus styles; users can't tell what's selected
  • Installing both react-native and react-native-tvos; native linking breaks
  • Small text and dense layouts; design for viewing from 3 meters away

✓ Tips & Best Practices

  • Keep a 90 pt safe margin on the edges for TV overscan
  • Test with the Apple TV simulator's remote window and arrow keys
  • Share code with the phone app, with Platform.isTV branches for layout

Quick Summary
