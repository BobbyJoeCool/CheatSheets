Sheet 07

State & Effect Hooks

useState · useEffect · cleanup · dependency arrays · useRef · useMemo · useCallback

React Refresher: Hooks

State (useState) is data that triggers a re-render when it changes. Effects (useEffect) sync your component with something outside React: subscriptions, timers, native listeners. Refs (useRef) hold mutable values or native handles without re-rendering. useMemo and useCallback cache values and functions between renders, though the React Compiler can do this for you.

Hook Rules

  • Call hooks at the top level, never in loops or conditions
  • Only call them from components or custom hooks
  • State updates are async and batched
  • Effects run after the frame is painted

Hooks in Practice

function Timer() {
  const [seconds, setSeconds] = useState(0)
  const [running, setRunning] = useState(false)
  const startedAt = useRef<number | null>(null)

  useEffect(() => {
    if (!running) return
    const id = setInterval(() => setSeconds(s => s + 1), 1000)
    return () => clearInterval(id)          // cleanup
  }, [running])                             // re-run when running changes

  useEffect(() => {
    const sub = AppState.addEventListener('change', st => {
      if (st === 'background') setRunning(false)
    })
    return () => sub.remove()
  }, [])                                    // mount / unmount only

  const label = useMemo(() => formatTime(seconds), [seconds])
  const toggle = useCallback(() => setRunning(r => !r), [])
  return <Pressable onPress={toggle}><Text>{label}</Text></Pressable>
}

Notes

setSeconds(s => s + 1) — updater form avoids stale state
return () => … — cleanup on re-run and unmount
[] — effect runs once on mount
AppState — RN API: active / background / inactive
useRef — persists without causing renders

iOS

  • AppState passes through 'inactive' (Control Center, app switcher)
  • JS timers pause soon after the app is backgrounded
  • useColorScheme updates live when Dark Mode toggles

Android

  • AppState has no 'inactive' — only active / background
  • Add BackHandler listeners in useEffect; return remove()
  • Test resize and multi-window: dimensions change at runtime

⚠ Common Mistakes

  • Forgetting to remove listeners (sub.remove()); leaks pile up across navigation
  • Reading state right after setState and expecting the new value; it updates on the next render
  • Using useEffect to derive data from props; compute it during render instead

✓ Tips & Best Practices

  • Turn on the React Compiler and drop most manual useMemo / useCallback
  • Use useFocusEffect (navigation) for work that should pause when a screen is hidden
  • Keep effects small, one concern per effect

Quick Summary

  • useState — re-render on change
  • useEffect — side effects + cleanup
  • useRef — mutable, no re-render
  • useMemo / useCallback — memoize
