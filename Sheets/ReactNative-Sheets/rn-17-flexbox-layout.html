Flexbox in React Native

column default · flex: 1 · justifyContent · alignItems · gap · position: absolute · Yoga differences from web

Layout Is Flexbox

Every View is a flex container, laid out by the Yoga engine. The defaults differ from the web: flexDirection is column, alignContent is flex-start, flexShrink is 0, and flex accepts a single number. Use flex: 1 to fill available space, justifyContent for the main axis, and alignItems for the cross axis.

Defaults vs Web

  • flexDirection: 'column' (web: row)
  • flexShrink: 0 (web: 1)
  • position: 'relative' by default; static supported (0.74+)
  • flex: N = grow N, shrink 1, basis 0 when positive

Layout Recipes

// Full screen, centered
<View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }} />

// Header / scrolling body / footer
<View style={{ flex: 1 }}>
  <Header />                           {/* fixed height */}
  <ScrollView style={{ flex: 1 }} />   {/* takes the rest */}
  <Footer />
</View>

// Row: avatar, text that truncates, badge pinned right
<View style={{ flexDirection: 'row', alignItems: 'center', gap: 8 }}>
  <Avatar />
  <Text style={{ flex: 1 }} numberOfLines={1}>{name}</Text>
  <Badge />
</View>

// Wrap chips
<View style={{ flexDirection: 'row', flexWrap: 'wrap', gap: 6 }} />

// Floating button
<Pressable style={{ position: 'absolute', right: 16, bottom: 24 }} />

Notes

flex: 1 on body — it fills between header and footer
flex: 1 on Text — lets it shrink and truncate
gap — spacing between children (0.71+)
flexWrap — chips / tags
absolute — positioned against the parent

iOS

  • Yoga lays out identically on both platforms
  • Text metrics differ — check vertical centering on both
  • StyleSheet.hairlineWidth = 1 physical pixel (≈ 0.33 pt @3x)

Android

  • includeFontPadding shifts text in centered rows — set false
  • elevation changes drawing order, overriding zIndex
  • Check RTL: I18nManager flips start / end

⚠ Common Mistakes

  • Parent without a height (no flex: 1) so flex: 1 children collapse to zero
  • Long Text in a row pushing siblings off screen; give it flex: 1 or flexShrink: 1
  • Copying web CSS assuming row default; RN stacks vertically

✓ Tips & Best Practices

  • Debug layout with a temporary borderWidth: 1 or the DevTools element inspector
  • Use aspectRatio for images and cards instead of computing heights
  • Use inset / start / end for RTL-friendly positioning

Quick Summary

  • Column by default
  • flex: 1 — fill remaining space
  • justifyContent / alignItems — main / cross axis
  • gap — spacing between children
