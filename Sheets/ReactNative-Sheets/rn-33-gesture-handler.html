Native Gestures

react-native-gesture-handler recognizes touches on the native side, so pans, pinches, and swipes stay responsive even when JS is busy. Version 3 replaces the Gesture.Pan() builder with hooks (usePanGesture, useTapGesture…) that take a config object. Attach a gesture with GestureDetector; with Reanimated installed, callbacks run on the UI thread and can update shared values directly.

Versions

  • v3 (latest, 3.3): hook API; Gesture.* builders deprecated
  • v2 (legacy tag, 2.33) still ships with Expo SDK 57
  • React Navigation 8 requires v3
  • Expo Router / React Navigation set up the root view

Draggable, Pinchable Card (v3)

import { GestureDetector, usePanGesture, usePinchGesture,
  useSimultaneousGestures } from 'react-native-gesture-handler'
import Animated, { useSharedValue, useAnimatedStyle, withSpring }
  from 'react-native-reanimated'

function DraggableCard() {
  const x = useSharedValue(0), y = useSharedValue(0)
  const scale = useSharedValue(1)

  const pan = usePanGesture({
    onUpdate: e => { x.value += e.changeX; y.value += e.changeY },
    onDeactivate: () => {
      x.value = withSpring(0); y.value = withSpring(0) },
  })
  const pinch = usePinchGesture({
    onUpdate: e => { scale.value = e.scale },
    onDeactivate: () => { scale.value = withSpring(1) },
  })
  const both = useSimultaneousGestures(pan, pinch)

  const style = useAnimatedStyle(() => ({ transform: [
    { translateX: x.value }, { translateY: y.value },
    { scale: scale.value }] }))

  return (
    <GestureDetector gesture={both}>
      <Animated.View style={[styles.card, style]} />
    </GestureDetector>
  )
}
// Root: wrap the app in <GestureHandlerRootView style={{ flex: 1 }}>
// v2 equivalent: Gesture.Pan().onChange(…).onEnd(…)

Notes

Config object — callbacks + options in one place
changeX — delta since the last event
onDeactivate — gesture ended or was cancelled
useSimultaneousGestures — both run together
runOnJS: true — run callbacks on the JS thread instead

iOS

  • Native-stack edge swipe can steal horizontal pans
  • Gestures map to native UIGestureRecognizers
  • Pair gesture ends with haptics for native feel

Android

  • Wrap Modal content in GestureHandlerRootView
  • System back gesture claims swipes near the screen edges
  • Keep draggable areas away from the edges

⚠ Common Mistakes

  • Missing GestureHandlerRootView; gestures silently never fire (especially inside RN Modal)
  • Mixing v2 tutorials (Gesture.Pan().onEnd) into a v3 codebase; the builder is deprecated
  • Setting React state on every pan event; update shared values and call scheduleOnRN only when done

✓ Tips & Best Practices

  • Use activeOffsetX / failOffsetY so horizontal swipes don't fight a vertical ScrollView
  • Use useExclusiveGestures(doubleTap, singleTap) for like-on-double-tap
  • Use ReanimatedSwipeable for swipe-to-delete rows and the v3 Touchable for buttons
