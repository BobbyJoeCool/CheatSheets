ScrollView

<ScrollView> · horizontal · contentContainerStyle · keyboardShouldPersistTaps · pagingEnabled · RefreshControl · scrollTo()

Scrolling Content

ScrollView renders all its children at once and lets the user scroll. That's fine for forms, settings, and screens with a bounded amount of content. For long or unknown-length data, use FlatList, which renders lazily. A ScrollView needs a bounded height (usually flex: 1 from its parent) to scroll at all.

Layout Rules

  • style sizes the scroll box; contentContainerStyle styles the content
  • Use contentContainerStyle={{ flexGrow: 1 }} to center short content
  • Nested vertical ScrollViews in the same direction fight each other
  • Don't nest a FlatList inside a vertical ScrollView

Common Configurations

const scrollRef = useRef<ScrollViewInstance>(null)
const [refreshing, setRefreshing] = useState(false)

<ScrollView
  ref={scrollRef}
  style={{ flex: 1 }}
  contentContainerStyle={{ padding: 16, gap: 12 }}
  keyboardShouldPersistTaps="handled"
  keyboardDismissMode="on-drag"
  showsVerticalScrollIndicator={false}
  refreshControl={
    <RefreshControl refreshing={refreshing} onRefresh={reload} />
  }
  onScroll={e => setY(e.nativeEvent.contentOffset.y)}
  scrollEventThrottle={16}>
  {sections}
</ScrollView>

scrollRef.current?.scrollTo({ y: 0, animated: true })
scrollRef.current?.scrollToEnd()

<ScrollView horizontal pagingEnabled
  showsHorizontalScrollIndicator={false}>{slides}</ScrollView>

Notes

keyboardDismissMode — none · on-drag · interactive (iOS)
RefreshControl — pull-to-refresh
scrollEventThrottle={16} — ~60 events/sec on iOS
pagingEnabled — snap by full width (carousels)
scrollTo / scrollToEnd — imperative scrolling

iOS

  • Bounces by default; bounces={false} turns it off
  • contentInsetAdjustmentBehavior="automatic" respects safe areas
  • automaticallyAdjustKeyboardInsets scrolls inputs into view

Android

  • Overscroll stretch / glow; overScrollMode="never" disables it
  • nestedScrollEnabled for scroll views inside scroll views
  • fadingEdgeLength fades content at the edges

⚠ Common Mistakes

  • Putting alignItems or justifyContent in style; content layout goes in contentContainerStyle
  • Rendering hundreds of items in a ScrollView; memory spikes and startup slows
  • Passing the boolean keyboardShouldPersistTaps; removed in 0.87, use "handled" / "always" / "never"

✓ Tips & Best Practices

  • Pair onScroll animations with Reanimated's useAnimatedScrollHandler for smooth 60/120fps
  • contentInsetAdjustmentBehavior="automatic" handles iOS large titles
  • Use maintainVisibleContentPosition for chat-style prepends

Quick Summary

  • ScrollView — renders everything
  • contentContainerStyle — inner layout
  • RefreshControl — pull to refresh
  • Long data — use FlatList
