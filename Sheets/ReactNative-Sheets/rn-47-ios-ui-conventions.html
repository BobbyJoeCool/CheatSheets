iOS UI Conventions & APIs

ActionSheetIOS · DynamicColorIOS · SF Symbols · haptics · large titles · Liquid Glass (expo-glass-effect) · Expo UI SwiftUI

Feeling at Home on iOS

iOS users expect swipe-back navigation, large titles, action sheets, haptics, SF Symbols, and system colors that adapt to dark mode. Native stacks and tabs give you most of this for free. Since iOS 26, Liquid Glass is the system material; expo-glass-effect exposes it. Expo UI (@expo/ui/swift-ui) lets you render real SwiftUI controls from React (stable since SDK 56).

Platform Expectations

  • Back = swipe from left edge, not a hardware button
  • Tab bar at bottom; no floating action buttons
  • 44 × 44 pt minimum touch targets
  • Respect Dynamic Type and Reduce Motion

iOS-Only APIs

// Action sheet
ActionSheetIOS.showActionSheetWithOptions(
  { options: ['Cancel', 'Save', 'Delete'], cancelButtonIndex: 0,
    destructiveButtonIndex: 2, title: 'Photo' },
  (i) => { if (i === 1) save(); if (i === 2) remove() })

// Share sheet (cross-platform)
await Share.share({ message: 'Check this out', url: link })

// Adaptive colors
const bg = DynamicColorIOS({ light: '#ffffff', dark: '#000000' })
const label = PlatformColor('label')

// Haptics
Haptics.selectionAsync()
Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium)

// SF Symbols (expo-symbols)
<SymbolView name="heart.fill" tintColor="red" size={24} />

// Liquid Glass (iOS 26+)
import { GlassView } from 'expo-glass-effect'
<GlassView glassEffectStyle="regular" style={styles.toolbar} />

// Native SwiftUI control via Expo UI
import { Host, Slider, Button } from '@expo/ui/swift-ui'
<Host matchContents>
  <Slider value={vol} min={0} max={1} onValueChange={setVol} />
</Host>
<Host matchContents>
  <Button label="Share" systemImage="square.and.arrow.up" onPress={share} />
</Host>

Notes

ActionSheetIOS — native bottom action sheet
DynamicColorIOS — light/dark pair, auto switch
PlatformColor('label') — iOS semantic text color
SymbolView — SF Symbols, scales with text
GlassView — falls back to a plain view on older iOS

iOS

  • ActionSheetIOS for native action sheets
  • DynamicColorIOS for light / dark pairs
  • Large titles and sheets match platform style

Android

  • Back button and gesture instead of edge swipe
  • Floating action buttons and snackbars are normal
  • 48 × 48 dp targets; ToastAndroid for short messages

⚠ Common Mistakes

  • Building a custom back button and disabling swipe-back; it feels broken on iOS
  • Using Android-style FABs and toasts on iOS; prefer toolbar buttons and inline banners
  • Hardcoding white/black colors that ignore dark mode

✓ Tips & Best Practices

  • Use native stack/tabs (or NativeTabs) to get system transitions and Liquid Glass bars automatically
  • Test with the largest Dynamic Type size in Settings → Accessibility
  • Try Expo UI pickers, menus, and sheets before building custom controls
