FlatList & SectionList

data / renderItem · keyExtractor · ListEmptyComponent · onEndReached · getItemLayout · SectionList · FlashList

Virtualized Lists

FlatList renders only what's near the viewport and recycles memory as you scroll, so it handles thousands of rows. Give it data, a renderItem function, and a keyExtractor. SectionList adds grouped data with headers. Shopify's FlashList is a drop-in alternative that recycles views and is usually faster for big feeds.

Performance Levers

  • Keep renderItem items light and memoized
  • getItemLayout skips measurement for fixed heights
  • initialNumToRender, windowSize tune the window
  • Avoid inline anonymous objects in item props

Infinite Feed + Sections

<FlatList
  data={posts}
  keyExtractor={item => item.id}
  renderItem={({ item }) => <PostRow post={item} />}
  ItemSeparatorComponent={Divider}
  ListHeaderComponent={<Header />}
  ListEmptyComponent={<Text>No posts yet</Text>}
  ListFooterComponent={loading ? <ActivityIndicator /> : null}
  onEndReached={loadMore}
  onEndReachedThreshold={0.5}
  refreshing={refreshing} onRefresh={refresh}
  getItemLayout={(_, i) => ({ length: 72, offset: 72 * i, index: i })}
/>

<SectionList
  sections={[{ title: 'Today', data: today },
             { title: 'Earlier', data: older }]}
  keyExtractor={item => item.id}
  renderItem={({ item }) => <Row item={item} />}
  renderSectionHeader={({ section }) => <H>{section.title}</H>}
  stickySectionHeadersEnabled
/>

Notes

keyExtractor — stable string key per item
onEndReachedThreshold={0.5} — load at half a screen from end
refreshing + onRefresh — built-in pull-to-refresh
getItemLayout — only for fixed-height rows
sections — each needs a data array

iOS

  • Status-bar tap scrolls to top (scrollsToTop, one list at a time)
  • RefreshControl: tintColor and title
  • ProMotion (120 Hz) makes dropped frames more visible

Android

  • removeClippedSubviews defaults to true on Android
  • RefreshControl: colors and progressBackgroundColor
  • Lower windowSize on low-end devices to save memory

⚠ Common Mistakes

  • Using array index as the key when items reorder or delete; rows show the wrong data
  • Forgetting extraData when renderItem reads external state; rows don't update
  • Wrapping a FlatList in a vertical ScrollView; virtualization is lost and RN warns

✓ Tips & Best Practices

  • Wrap row components in memo (or rely on the React Compiler) and pass primitive props
  • Guard onEndReached with a loading flag; it can fire several times
  • Use inverted for chat instead of reversing data and scrolling to end

Quick Summary

  • FlatList — virtualized list
  • keyExtractor / renderItem — required pair
  • onEndReached — infinite scroll
  • SectionList / FlashList — groups / speed
