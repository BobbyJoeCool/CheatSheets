Android TV, Large Screens & Other Devices

react-native-tvos for Android TV · leanback · foldables · tablets · ChromeOS · resizable activities

Android Beyond Phones

The same Android build can run on tablets, foldables, Chromebooks, and TVs. For Android TV, use react-native-tvos (same fork as Apple TV) for D-pad focus handling and declare the leanback launcher. For large screens, Android 16 ignores orientation and resizability restrictions on displays ≥ 600 dp for apps targeting API 36, so layouts must adapt.

Large-Screen Facts

  • Window size changes on fold/unfold and in multi-window
  • useWindowDimensions updates; design with breakpoints
  • ChromeOS adds mouse, keyboard, and free-form windows
  • Meta Quest (Horizon OS) runs Android apps, incl. RN

TV Manifest + Adaptive Layout

<!-- AndroidManifest.xml additions for Android TV -->
<uses-feature android:name="android.software.leanback"
  android:required="false" />
<uses-feature android:name="android.hardware.touchscreen"
  android:required="false" />

<application android:banner="@drawable/tv_banner">
  <activity android:name=".MainActivity"
    android:resizeableActivity="true"
    android:configChanges="...">  <!-- keep RN's default list -->
    <intent-filter>
      <action android:name="android.intent.action.MAIN" />
      <category android:name="android.intent.category.LAUNCHER" />
      <category android:name="android.intent.category.LEANBACK_LAUNCHER" />
    </intent-filter>
  </activity>
</application>

⚠ Common Mistakes

  • Locking orientation and expecting it to hold on tablets; Android 16 ignores the lock on large screens
  • Using core react-native for Android TV and fighting focus issues; react-native-tvos handles D-pad focus
  • Shipping a TV build without a banner; it won't appear properly on the TV launcher

✓ Tips & Best Practices

  • Use the Resizable emulator and Pixel Fold / Tablet AVDs to test window changes
  • Share breakpoints with your iPad layouts
  • Keep state in stores, not in components that remount on configuration changes

Quick Summary
