Networking & Data Fetching

fetch() · expo/fetch · AbortController · WebSocket · TanStack Query · NetInfo · cleartext / ATS rules

Talking to Servers

React Native provides the web-standard fetch, WebSocket, URL, and AbortController. In Expo SDK 56+, expo/fetch (with streaming support) is the default global fetch. For real apps, wrap requests in TanStack Query for caching, retries, background refetch, and offline awareness. Both OSes block plain http:// by default.

Platform Rules

  • iOS ATS blocks non-HTTPS unless exempted in Info.plist
  • Android 9+ blocks cleartext unless usesCleartextTraffic
  • localhost on an Android emulator is 10.0.2.2
  • No CORS on native; it only applies on web

fetch + TanStack Query

async function getPosts(signal?: AbortSignal): Promise<Post[]> {
  const res = await fetch('https://api.example.com/posts', {
    headers: { Authorization: `Bearer ${token}` }, signal })
  if (!res.ok) throw new Error(`HTTP ${res.status}`)
  return res.json()
}

const queryClient = new QueryClient()
// root: <QueryClientProvider client={queryClient}>…</QueryClientProvider>

function Feed() {
  const { data, isPending, error, refetch, isRefetching } = useQuery({
    queryKey: ['posts'],
    queryFn: ({ signal }) => getPosts(signal),
    staleTime: 60_000,
  })
  const mutation = useMutation({
    mutationFn: (p: NewPost) => api.create(p),
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ['posts'] }),
  })
  if (isPending) return <ActivityIndicator />
  if (error) return <Text>{error.message}</Text>
  return <FlatList data={data} refreshing={isRefetching} onRefresh={refetch}
    renderItem={({ item }) => <PostRow post={item} />} />
}

Notes

res.ok — fetch doesn't throw on 4xx/5xx
signal — cancels when the query is abandoned
staleTime — how long data counts as fresh
invalidateQueries — refetch after a mutation
Wire focusManager to AppState for refetch on resume

iOS

  • The Simulator shares the Mac's network — localhost works
  • A physical iPhone needs your Mac's LAN IP
  • Proxies (Charles, Proxyman) need their root cert trusted

Android

  • User-installed CAs aren't trusted unless the network config allows them
  • adb reverse tcp:3000 tcp:3000 lets a USB device hit localhost
  • fetch runs on OkHttp under the hood

⚠ Common Mistakes

  • Calling localhost from an Android emulator; that's the emulator itself, use 10.0.2.2
  • Assuming fetch rejects on 404 or 500; check res.ok
  • Fetching in useEffect without cancellation; responses land after the screen unmounts

✓ Tips & Best Practices

  • Configure TanStack Query's onlineManager with NetInfo for offline pause/resume
  • Keep API calls in one module so auth headers and base URLs live in one place
  • Inspect traffic in React Native DevTools' Network panel

Quick Summary

  • fetch — web-standard HTTP
  • TanStack Query — cache, retry, refetch
  • ATS / cleartext — HTTPS by default
  • 10.0.2.2 — emulator → host
