Animated API

Animated.Value · Animated.timing() · spring() · interpolate() · useNativeDriver · LayoutAnimation

Built-In Animations

The core Animated API drives values over time and binds them to Animated.View, Animated.Text, and friends. With useNativeDriver: true, the animation runs on the UI thread, so JS work can't make it stutter, but only transform and opacity can be animated that way. LayoutAnimation animates the next layout change automatically. For gestures and complex motion, use Reanimated.

Native Driver Limits

  • Supported: transform, opacity
  • Not supported: width, height, colors, top
  • Can't switch drivers on the same value
  • Gesture-linked animation → Reanimated

Fade, Spring, Interpolate

function FadeInCard({ children }: { children: React.ReactNode }) {
  const opacity = useRef(new Animated.Value(0)).current
  const scale = useRef(new Animated.Value(0.9)).current

  useEffect(() => {
    Animated.parallel([
      Animated.timing(opacity, { toValue: 1, duration: 300,
        easing: Easing.out(Easing.cubic), useNativeDriver: true }),
      Animated.spring(scale, { toValue: 1, friction: 6,
        useNativeDriver: true }),
    ]).start()
  }, [])

  const translateY = opacity.interpolate({
    inputRange: [0, 1], outputRange: [20, 0] })

  return (
    <Animated.View style={{ opacity,
      transform: [{ scale }, { translateY }] }}>
      {children}
    </Animated.View>
  )
}

// Animate the next layout change (expand / collapse)
LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut)
setExpanded(e => !e)

Notes

useRef(...).current — keep the same value across renders
parallel — run animations together
useNativeDriver: true — UI-thread playback
interpolate — map one range to another
LayoutAnimation — call right before the state change

iOS

  • shouldRasterizeIOS caches complex views while animating
  • Respect Reduce Motion: AccessibilityInfo.isReduceMotionEnabled()
  • ProMotion runs at 120 Hz — use durations, not frame counts

Android

  • renderToHardwareTextureAndroid during opacity / transform
  • Low-end devices drop frames first — test on one
  • Judge smoothness in release; debug is much slower

⚠ Common Mistakes

  • Creating new Animated.Value() in render without useRef; it resets every render
  • Animating height with the native driver; it throws, use Reanimated or scaleY
  • Forgetting useNativeDriver; animations stutter whenever JS is busy

✓ Tips & Best Practices

  • Use Animated.event with useNativeDriver: true for scroll-linked headers
  • Respect AccessibilityInfo.isReduceMotionEnabled() and shorten or skip motion
  • Move to Reanimated as soon as animations depend on gestures or layout

Quick Summary

  • Animated.Value — animated number
  • timing / spring — drivers
  • useNativeDriver — UI thread, transform/opacity
  • LayoutAnimation — auto layout transitions
