StyleSheet Basics

StyleSheet.create() · style arrays · unitless numbers · no cascade · Text style inheritance · boxShadow / filter

Styling Without CSS Files

Styles are JavaScript objects with camelCased properties and unitless numbers (density-independent pixels). There's no cascade or selectors: each component gets its own style prop. StyleSheet.create validates styles and lets you reference them by name. Combine styles with arrays; later entries win. Modern RN supports web-like boxShadow, filter, and mixBlendMode.

Differences From CSS

  • margin: 8 = 8 dp, no px; '50%' strings for percent
  • Flexbox only; display: 'none' hides
  • position: 'absolute' | 'relative' | 'static'
  • No rem / em; no media queries in StyleSheet

Styles in Practice

const styles = StyleSheet.create({
  card: {
    padding: 16,
    borderRadius: 12,
    backgroundColor: '#1e2130',
    boxShadow: '0 4px 12px rgba(0,0,0,0.3)',   // 0.76+
    borderWidth: StyleSheet.hairlineWidth,
    borderColor: '#2e3348',
  },
  title: { fontSize: 18, fontWeight: '600', color: '#e8eaf6' },
  muted: { color: '#9aa0b8' },
  selected: { borderColor: '#7e57c2' },
})

<View style={[styles.card, isSelected && styles.selected,
  { marginTop: index === 0 ? 0 : 12 }]}>
  <Text style={[styles.title, disabled && styles.muted]}>Title</Text>
</View>

const flat = StyleSheet.flatten([styles.card, override])
StyleSheet.absoluteFill          // { position:'absolute', inset 0 }

Notes

Arrays — falsy entries are ignored
boxShadow — CSS syntax, both platforms
hairlineWidth — thinnest line the screen can draw
flatten — merge into one object (for reading)
absoluteFill — overlay helper

iOS

  • Sizes are points (pt)
  • All nine fontWeights work with the system font
  • shadow* props draw shadows

Android

  • Sizes are density-independent pixels (dp)
  • Custom fonts need a file per weight
  • textAlignVertical and includeFontPadding are Android-only

⚠ Common Mistakes

  • Writing '16px' or '1rem'; RN wants numbers (or '%' strings)
  • Expecting a View's color or fontSize to reach child Text; only nested Text inherits
  • Building a new style object inline on every render in hot lists; hoist it or use StyleSheet.create

✓ Tips & Best Practices

  • Keep a theme.ts with spacing, colors, and radii constants
  • Use gap, rowGap, columnGap instead of margins between children
  • Try NativeWind or Unistyles if you want utility classes or breakpoints

Quick Summary

  • StyleSheet.create — named style objects
  • [a, cond && b] — compose styles
  • Unitless numbers — dp, not px
  • boxShadow / filter — web-like effects
