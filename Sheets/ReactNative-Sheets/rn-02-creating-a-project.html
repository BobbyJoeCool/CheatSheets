Creating a Project

Two Ways to Start

The React Native docs recommend a framework, and today that means Expo: it generates the native projects for you, adds routing, and handles builds. The Community CLI creates a bare app with ios/ and android/ folders you own and edit directly. Both run the same React Native; you can add native code to an Expo app at any time.

Prerequisites

  • Node.js 22.13+ (required since RN 0.87)
  • iOS builds need a Mac with Xcode; Android needs Android Studio + JDK 17
  • Watchman recommended on macOS (brew install watchman)
  • A physical device works with Expo Go or a development build

Create and Run

# Expo (recommended)
npx create-expo-app@latest MyApp      # default: Expo Router + TS
npx create-expo-app@latest MyApp --template blank-typescript
cd MyApp && npx expo start                # QR code, press i / a / w

# Bare React Native (Community CLI)
npx @react-native-community/cli@latest init MyApp
npx @react-native-community/cli@latest init MyApp --version 0.87.0
cd MyApp
npx react-native run-ios                  # needs pod install first time
npx react-native run-android

# Check your machine
npx react-native doctor                   # bare
npx expo-doctor                           # Expo

Notes

@latest — always pull the current template
--template — default, blank, blank-typescript, tabs
Both paths produce a TypeScript project by default
npx expo start — starts Metro and the dev server
init --version — pin an RN version for a bare app
doctor — checks Node, JDK, Xcode, SDK paths

iOS

  • Install Xcode, its command line tools and a simulator runtime
  • CocoaPods installs native deps (pod install)
  • The iOS Simulator only runs on macOS

Android

  • Android Studio provides the SDK, emulator and build tools
  • Set ANDROID_HOME; add platform-tools to PATH
  • JDK 17 — Android Studio's bundled JBR works

⚠ Common Mistakes

  • Running npx react-native init; the old global init was removed, use @react-native-community/cli init
  • Using Node 18 or 20; current RN requires Node 22.13 or newer
  • Spaces or special characters in the project path, which break native build scripts

✓ Tips & Best Practices

  • Use nvm or fnm and add .nvmrc so every machine uses the same Node
  • Expo Go only runs SDK modules; switch to a development build once you add custom native code
  • Commit package-lock.json (or your manager's lockfile) from day one

Quick Summary

  • create-expo-app — recommended start
  • cli init — bare project you own
  • expo start / run-ios — run it
  • doctor — diagnose setup
