Key-Value & Secure Storage

AsyncStorage · react-native-mmkv · expo-secure-store · Keychain / Keystore · expo-file-system · what not to store

Saving Data on the Device

There's no localStorage on native. AsyncStorage is the basic async key-value store. MMKV is a much faster synchronous store backed by memory-mapped files. Anything sensitive (tokens, passwords) belongs in expo-secure-store, which uses the iOS Keychain and Android Keystore-backed encryption. Files and blobs go through expo-file-system.

Limits and Behavior

  • AsyncStorage and MMKV store strings; JSON-encode objects
  • SecureStore values ~2 KB; meant for small secrets
  • Data is deleted when the app is uninstalled (Keychain may persist on iOS)
  • All of these are unencrypted except SecureStore (MMKV can encrypt)

Three Stores Side by Side

// AsyncStorage — async, simple
import AsyncStorage from '@react-native-async-storage/async-storage'
await AsyncStorage.setItem('settings', JSON.stringify({ units: 'metric' }))
const raw = await AsyncStorage.getItem('settings')   // string | null
const settings = raw ? JSON.parse(raw) : defaults
await AsyncStorage.removeItem('settings')

// MMKV — synchronous, fast
import { createMMKV } from 'react-native-mmkv'
const storage = createMMKV({ id: 'app' })
storage.set('onboarded', true)
storage.getBoolean('onboarded')                     // true
storage.set('user', JSON.stringify(user))
const [name, setName] = useMMKVString('name')       // reactive hook

// SecureStore — Keychain / Keystore
import * as SecureStore from 'expo-secure-store'
await SecureStore.setItemAsync('token', jwt, {
  keychainAccessible: SecureStore.AFTER_FIRST_UNLOCK })
const token = await SecureStore.getItemAsync('token')
await SecureStore.deleteItemAsync('token')

Notes

JSON.stringify / parse — store objects as strings
createMMKV — MMKV v4 API (new MMKV in v2/v3)
getBoolean / getNumber — typed MMKV getters
useMMKVString — re-renders when the key changes
keychainAccessible — when iOS can read the item

iOS

  • SecureStore uses the Keychain — items can survive uninstall
  • keychainAccessible controls access while locked
  • Documents files are backed up to iCloud by default

Android

  • SecureStore uses Keystore-encrypted storage
  • Auto Backup can restore app data after reinstall
  • Set allowBackup false or exclude secrets from backup

⚠ Common Mistakes

  • Storing tokens in AsyncStorage; a rooted or backed-up device exposes them in plain text
  • Forgetting await on AsyncStorage calls and reading before the write finishes
  • Putting large blobs in SecureStore; it has size limits and is slow

✓ Tips & Best Practices

  • Wrap storage access in a small typed module so keys aren't magic strings
  • Clear SecureStore on first launch after reinstall if you don't want iOS Keychain items to survive
  • Use expo-sqlite/kv-store as a drop-in AsyncStorage API backed by SQLite

Quick Summary

  • AsyncStorage — simple async KV
  • MMKV — fast sync KV
  • SecureStore — secrets only
  • JSON — serialize objects
