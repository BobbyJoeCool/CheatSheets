Android App Signing

upload keystore · keytool · signingConfigs · Play App Signing · SHA-1 / SHA-256 fingerprints · EAS credentials

Signing for Release

Every APK/AAB is signed. With Play App Signing (required for new apps), Google holds the final app signing key and you sign uploads with your own upload key. If you lose the upload key, Google can reset it; if you lost the old self-managed key, you couldn't update the app. Debug builds use a shared debug keystore. EAS can generate and store the upload keystore for you.

Two Keys

  • Upload key — yours, signs what you upload
  • App signing key — Google's, signs what users install
  • Fingerprints of both go into Firebase, Maps, App Links
  • Never commit keystores or passwords

Create and Configure an Upload Key

keytool -genkeypair -v -storetype PKCS12 \
  -keystore my-upload-key.keystore -alias my-key-alias \
  -keyalg RSA -keysize 2048 -validity 10000
mv my-upload-key.keystore android/app/

# ~/.gradle/gradle.properties (outside the repo)
MYAPP_UPLOAD_STORE_FILE=my-upload-key.keystore
MYAPP_UPLOAD_KEY_ALIAS=my-key-alias
MYAPP_UPLOAD_STORE_PASSWORD=*****
MYAPP_UPLOAD_KEY_PASSWORD=*****

# android/app/build.gradle
# signingConfigs { release {
#   storeFile file(MYAPP_UPLOAD_STORE_FILE)
#   storePassword MYAPP_UPLOAD_STORE_PASSWORD
#   keyAlias MYAPP_UPLOAD_KEY_ALIAS
#   keyPassword MYAPP_UPLOAD_KEY_PASSWORD } }

cd android && ./gradlew signingReport      # SHA-1 / SHA-256 of all keys
keytool -list -v -keystore android/app/my-upload-key.keystore

eas credentials -p android                 # EAS-managed keystore

Notes

PKCS12 — modern keystore format
-validity 10000 — ~27 years
Global gradle.properties — keeps secrets out of git
signingReport — fingerprints for debug and release
eas credentials — download a backup of the keystore

iOS

  • Certificate + provisioning profile per Apple team
  • No fingerprints — the Team ID goes in the AASA file
  • EAS can generate and store everything

Android

  • keytool -genkeypair -v -storetype PKCS12 -keystore upload.keystore -alias upload -keyalg RSA -keysize 2048 -validity 10000
  • Keep passwords in ~/.gradle/gradle.properties
  • ./gradlew signingReport prints SHA-1 / SHA-256

If Something Goes Wrong

SituationFix
Lost upload keyRequest upload key reset in Play Console
Leaked upload keyReset upload key
Wrong key on uploadPlay rejects; sign with registered upload key
Signature mismatch installingUninstall old build first

⚠ Common Mistakes

  • Committing the keystore and passwords to git; anyone with them can sign updates as you
  • Adding only the debug SHA-1 to Firebase; Google Sign-In fails in Play builds
  • Not backing up the upload keystore outside your laptop or CI

✓ Tips & Best Practices

  • Store keystores in a password manager or let EAS manage them
  • Use separate debug keystores per developer only if a service requires it; otherwise share the default
  • Copy fingerprints from Play Console → App integrity for the app signing key

Quick Summary

  • Upload key — you sign uploads
  • Play App Signing — Google signs installs
  • keytool / signingReport — create & inspect
  • Keep secrets out of git
