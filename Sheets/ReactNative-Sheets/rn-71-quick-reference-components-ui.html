⚠ Common Mistakes

  • Text outside a <Text> component — it crashes on native
  • ScrollView for long lists — use FlatList so rows are virtualized
  • Unstable or index keys in lists causing re-render bugs

✓ Tips & Best Practices

  • Use npx expo install so native packages match your SDK
  • Pass ({ pressed }) style functions for touch feedback
  • Test on a real device early — simulators hide performance issues

Quick Summary

  • View / Text / Image / Pressable / FlatList cover most screens
  • StyleSheet + flexbox (column by default) for layout
  • Platform.select and .ios / .android files for differences
  • Expo Router: files in app/ are screens
