Push on iOS

iOS pushes go through Apple Push Notification service (APNs). Your app asks permission, receives a device token, and your server sends payloads to APNs using a .p8 auth key from your Apple Developer account. expo-notifications handles permission, tokens, and listeners; with the Expo Push Service you send one API call and Expo forwards to APNs and FCM. Pushes need a real device or a simulator simctl push.

Requirements

  • Push Notifications capability + aps-environment entitlement
  • APNs key (.p8) uploaded to EAS or your push provider
  • Paid Apple Developer Program membership
  • Silent pushes need remote-notification background mode

Register and Listen

import * as Notifications from 'expo-notifications'
import Constants from 'expo-constants'

Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowBanner: true, shouldShowList: true,
    shouldPlaySound: true, shouldSetBadge: false }),
})

async function registerForPush() {
  const { status } = await Notifications.requestPermissionsAsync({
    ios: { allowAlert: true, allowBadge: true, allowSound: true,
           allowProvisional: false } })
  if (status !== 'granted') return null
  const projectId = Constants.expoConfig?.extra?.eas?.projectId
  const { data: expoToken } =
    await Notifications.getExpoPushTokenAsync({ projectId })
  const { data: apnsToken } = await Notifications.getDevicePushTokenAsync()
  return { expoToken, apnsToken }        // send to your server
}

useEffect(() => {
  const sub = Notifications.addNotificationResponseReceivedListener(r => {
    router.push(r.notification.request.content.data.url as string)
  })
  return () => sub.remove()
}, [])

Notes

setNotificationHandler — show banners while app is open
allowProvisional — quiet delivery without a prompt
Expo token — use with Expo Push Service
Device token — raw APNs token for your own server
Response listener — user tapped a notification

iOS

  • Test payloads: xcrun simctl push booted <bundleId> file.apns
  • Provisional authorization delivers quietly without a prompt
  • Foreground banners need setNotificationHandler

Android

  • FCM tokens instead of APNs
  • Android 13+: POST_NOTIFICATIONS runtime permission
  • Channels required; small icon must be white-on-transparent

⚠ Common Mistakes

  • Testing remote push on an old simulator setup and assuming it's broken; use a device or simctl push
  • Mixing sandbox and production APNs environments; dev builds use sandbox tokens
  • Asking for push permission on first launch before the user sees any value

✓ Tips & Best Practices

  • Use provisional authorization to deliver quietly and earn a later full opt-in
  • Store tokens server-side per device and refresh them on every launch
  • Upload your .p8 key once with eas credentials; it works for all your apps
