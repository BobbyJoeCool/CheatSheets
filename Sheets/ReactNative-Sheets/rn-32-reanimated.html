Reanimated

useSharedValue · useAnimatedStyle · withTiming / withSpring · worklets · entering / exiting layout animations · CSS animations

High-Performance Animation

Reanimated runs animation logic on the UI thread as worklets, small JS functions executed outside the main JS thread via react-native-worklets. You store animated state in shared values, derive styles with useAnimatedStyle, and animate with withTiming / withSpring. Reanimated 4 (New Architecture only) adds CSS-style transitions and keyframe animations and declarative layout animations.

Setup (v4)

  • Install react-native-reanimated + react-native-worklets
  • Babel plugin: react-native-worklets/plugin (Expo adds it)
  • Requires the New Architecture
  • Expo SDK 57 ships Reanimated 4.5

Shared Values, Layout, CSS

import Animated, { useSharedValue, useAnimatedStyle, withSpring,
  withTiming, FadeIn, FadeOut, LinearTransition }
  from 'react-native-reanimated'

function Toggle() {
  const x = useSharedValue(0)
  const style = useAnimatedStyle(() => ({
    transform: [{ translateX: x.value }],
    backgroundColor: x.value > 20 ? '#7e57c2' : '#444',
  }))
  return (
    <Pressable onPress={() => {
      x.value = withSpring(x.value === 0 ? 40 : 0, { damping: 15 }) }}>
      <Animated.View style={[styles.knob, style]} />
    </Pressable>
  )
}

// Layout animations: mount, unmount, reorder
<Animated.View entering={FadeIn.duration(250)} exiting={FadeOut}
  layout={LinearTransition.springify()} />

// CSS transitions (v4): animate when style changes
<Animated.View style={{ width: open ? 240 : 80,
  transitionProperty: 'width', transitionDuration: 300 }} />

Notes

x.value — read/write shared values via .value
useAnimatedStyle — worklet; re-runs on the UI thread
withSpring / withTiming — assign to animate
entering / exiting — mount/unmount animations
transitionProperty — CSS-like transitions in v4

iOS

  • ProMotion runs at 120 Hz — animate by time, not frames
  • reduceMotion: ReduceMotion.System honours Reduce Motion
  • Profile with Xcode Instruments in a release build

Android

  • Debug builds are much slower — test in release
  • ReduceMotion.System honours Remove animations
  • Profile with Android Studio Profiler or Perfetto

⚠ Common Mistakes

  • Reading x.value during render; it doesn't trigger re-renders, so use it in worklets only
  • Calling a normal JS function (setState, navigation) inside a worklet without scheduleOnRN
  • Forgetting the Babel plugin in a bare app; worklets crash at runtime

✓ Tips & Best Practices

  • Use CSS transitions for simple state-driven changes; keep shared values for gestures
  • Combine with Gesture Handler for drag, swipe, and pinch interactions
  • Profile memory on Android with Hermes V1; an SDK 56 regression was fixed in SDK 57
