Native Windows Apps

React Native for Windows (RNW) is Microsoft's out-of-tree platform for building native Windows desktop apps. It runs on the New Architecture (Fabric) only since 0.82, rendering through the Windows App SDK. RNW tracks core with a short lag (latest 0.84 as of Oct 2026); your RN version must match its minor. Build on a Windows machine with Visual Studio.

Requirements

  • Windows 10/11 dev machine; Visual Studio 2026 for RNW 0.84
  • VS workloads: Desktop development with C++, WinUI app development
  • Node and Yarn (Yarn recommended)
  • Developer Mode enabled in Windows settings

Add Windows to a Project

# Create a project at the matching RN version
npx --yes @react-native-community/cli@latest init MyApp --version 0.84.0
cd MyApp
yarn add react-native-windows@^0.84.0
npx react-native init-windows --overwrite     # creates windows/

npx react-native run-windows                  # build, deploy, launch
npx react-native run-windows --release --arch x64
npx react-native autolink-windows             # before opening VS

# Visual Studio: open windows/MyApp.sln,
# Debug | x64, run `yarn start`, press Run

# Check / install prerequisites
powershell -ExecutionPolicy Unrestricted -File `
  node_modules\react-native-windows\scripts\rnw-dependencies.ps1

Notes

RN and RNW must share the same minor version
init-windows --overwrite — also rewrites metro.config.js
run-windows — builds the .sln and deploys
autolink-windows — links native modules into the solution
rnw-dependencies.ps1 — installs/checks prerequisites

iOS

  • iOS builds need a Mac; Windows builds need Windows
  • UIKit-only libraries have no Windows port
  • .ios.tsx is ignored — add .windows.tsx

Android

  • One Windows PC can build Android and Windows
  • RN Windows also resolves .native.tsx
  • Android-only libraries need Windows fallbacks too

⚠ Common Mistakes

  • Installing RNW 0.84 into an RN 0.87 app; the minors must match
  • Running init-windows --overwrite without backing up a customized metro.config.js
  • Missing VS workloads; builds fail with cryptic MSBuild errors

✓ Tips & Best Practices

  • Run rnw-dependencies.ps1 on new machines to set up everything in one go
  • Keep Windows-specific UI in .windows.tsx files and share the rest
  • Pin RN to the newest version RNW supports when Windows is a target

Quick Summary

  • RNW — Microsoft's Windows platform
  • init-windows / run-windows — setup & run
  • Visual Studio + C++ workloads — required
  • Match RN minor versions
