edge-to-edge · BackHandler · ToastAndroid · android_ripple · Material You colors · Expo UI Jetpack Compose

Feeling at Home on Android

Android users expect the system back gesture to work everywhere, ripple feedback on touch, Material components, and apps that draw edge-to-edge under transparent system bars (enforced on Android 15+, no opt-out on 16). Handle back with BackHandler, show quick messages with ToastAndroid, and use Material You dynamic colors. Expo UI's @expo/ui/jetpack-compose renders real Compose components.

Platform Expectations

  • Back gesture / button must close modals, then go back
  • Predictive back animation default when targeting API 36
  • Status and nav bars transparent; pad with safe-area insets
  • 48 × 48 dp minimum touch targets

Android-Only APIs

// Back handling (also handles Android TV back)
useEffect(() => {
  const sub = BackHandler.addEventListener('hardwareBackPress', () => {
    if (menuOpen) { setMenuOpen(false); return true }   // handled
    return false                         // default: back / exit
  })
  return () => sub.remove()
}, [menuOpen])

ToastAndroid.show('Saved', ToastAndroid.SHORT)

<Pressable android_ripple={{ color: '#ffffff33', borderless: false }}>
  <Text>Ripple</Text>
</Pressable>

// Material You (Android 12+) dynamic colors
const primary = PlatformColor('@android:color/system_accent1_500')

// Navigation bar style (expo-navigation-bar, SDK 56 component)
<NavigationBar style="light" hidden={false} />

// Native Jetpack Compose control via Expo UI
import { Host, Switch } from '@expo/ui/jetpack-compose'
<Host matchContents><Switch value={on} onCheckedChange={setOn} /></Host>

⚠ Common Mistakes

  • Returning true from every back handler; users get trapped and can't exit the app
  • Setting a solid status bar color and assuming content starts below it; content now draws underneath
  • iOS-style navigation without a back affordance; Android users rely on the system gesture

✓ Tips & Best Practices

  • Register back handlers inside useFocusEffect so only the visible screen intercepts back
  • Test 3-button and gesture navigation modes
  • Use expo-system-ui / app theme background to avoid white flashes behind bars
