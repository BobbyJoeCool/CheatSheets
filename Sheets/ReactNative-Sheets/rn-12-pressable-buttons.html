Pressable & Buttons

<Pressable> · onPress / onLongPress · pressed state style · hitSlop · <Button> · Touchable* legacy · android_ripple

Handling Taps

Pressable is the modern, flexible way to make anything tappable. It exposes press states (pressed, hovered, focused) so you can style feedback, and fires onPressIn, onPress, onLongPress, onPressOut. The built-in Button is quick but barely styleable. The old TouchableOpacity family still works but Pressable is recommended.

Press Lifecycle

  • onPressIn → (hold 500ms → onLongPress) → onPressOut
  • onPress fires on release if not long-pressed
  • delayLongPress changes the 500ms default
  • disabled blocks all handlers

Pressable Patterns

<Pressable
  onPress={save}
  onLongPress={showMenu}
  disabled={saving}
  hitSlop={8}                                  // bigger touch area
  android_ripple={{ color: '#ffffff33' }}
  accessibilityRole="button"
  accessibilityState={{ disabled: saving }}
  style={({ pressed }) => [
    styles.btn,
    pressed && { opacity: 0.6 },
    saving && styles.btnDisabled,
  ]}>
  {({ pressed }) => (
    <Text style={styles.btnText}>{pressed ? 'Saving…' : 'Save'}</Text>
  )}
</Pressable>

<Button title="Quick action" onPress={doIt} color="#5c6bc0" />

Notes

style function — receives { pressed, hovered }
Children function — change content while pressed
hitSlop — number or { top, bottom, left, right }
android_ripple — native ripple; add borderless for icons
accessibilityRole="button" — screen readers announce it

iOS

  • No ripple — show feedback with pressed-state opacity
  • Pair presses with expo-haptics for native feel
  • Use hitSlop to reach 44 × 44 pt targets

Android

  • android_ripple={{ color, borderless, foreground }}
  • Core <Button> renders Material-style, uppercase
  • Use hitSlop to reach 48 × 48 dp targets

⚠ Common Mistakes

  • Touch targets under 44×44 pt; use hitSlop or padding to meet platform guidelines
  • Using TouchableWithoutFeedback with no visual cue; users think the tap failed
  • Putting onPress on a View; Views don't handle presses, wrap in Pressable

✓ Tips & Best Practices

  • Build one <AppButton> with variants instead of styling every Pressable
  • Add haptics on important presses (expo-haptics impactAsync)
  • Set accessibilityLabel on icon-only buttons

Quick Summary

  • Pressable — default tap handler
  • style={({pressed}) => …} — feedback
  • hitSlop — larger target
  • Button — quick, minimal styling
