React 19 Features

use() · <Suspense> · Actions · useActionState · useOptimistic · ref as prop · React Compiler

React Refresher: What's New

React Native 0.87 ships React 19.2. You get use() for reading promises and context, Actions for async transitions with built-in pending state, useOptimistic for instant UI, and ref as a normal prop (no more forwardRef). The React Compiler auto-memoizes components and is on by default in new Expo projects.

Good to Know in RN

  • No <form> element; call Actions from onPress
  • useFormStatus is web-only (needs <form>)
  • Concurrent features work because of Fabric
  • <Activity> (19.2) hides UI while keeping state

Actions + Optimistic UI

function LikeButton({ post }: { post: Post }) {
  const [optimisticLikes, addLike] = useOptimistic(
    post.likes, (current, delta: number) => current + delta)

  const [error, likeAction, isPending] = useActionState(
    async (_prev: string | null) => {
      addLike(1)                                  // instant UI
      try { await api.like(post.id); return null }
      catch { return 'Could not like post' }
    }, null)

  return (
    <Pressable disabled={isPending}
      onPress={() => startTransition(likeAction)}>
      <Text>♥ {optimisticLikes}</Text>
      {error && <Text style={{ color: 'red' }}>{error}</Text>}
    </Pressable>
  )
}

function Profile({ userPromise }: { userPromise: Promise<User> }) {
  const user = use(userPromise)        // suspends until resolved
  return <Text>{user.name}</Text>
}

Notes

useOptimistic — shows a value until the Action settles
useActionState — returns [state, action, isPending]
startTransition — needed when calling an action outside a form
use(promise) — wrap the caller in <Suspense>
Create promises outside render (cache them)

iOS

  • Same React 19 runtime as Android (Hermes)
  • Fire Actions from onSubmitEditing with returnKeyType="go"
  • Optimistic UI hides latency on slow cellular links

Android

  • returnKeyType sets the keyboard's IME action button
  • submitBehavior="blurAndSubmit" closes the keyboard on submit
  • Debug builds are slow — judge transitions in release

⚠ Common Mistakes

  • Creating a new promise in render and passing it to use(); it refetches forever
  • Calling an Action from onPress without startTransition; isPending never updates
  • Still wrapping components in forwardRef in new code; pass ref as a prop

✓ Tips & Best Practices

  • Pair use() with <Suspense fallback={<ActivityIndicator/>}> and an error boundary
  • Use <Activity> for tab screens you want to keep warm without rendering
  • Let the Compiler handle memoization before adding manual memo

Quick Summary

  • use() — read promises / context
  • Actions — async with isPending
  • useOptimistic — instant feedback
  • React Compiler — auto memo
