React Native for Web

react-native-web · Expo web · npx expo start --web · .web.tsx files · unsupported APIs · static / server output

The Same Components in a Browser

react-native-web implements RN components and APIs on top of React DOM, so View becomes a div and Text a span with styles turned into atomic CSS. Expo wires it up with Metro: npx expo start --web runs it, and Expo Router gives every screen a real URL with static, server, or single-page output. Use .web.tsx files where the browser needs something different.

Good to Know

  • Latest react-native-web: 0.21.x
  • Most core components work; some APIs are no-ops on web
  • Native-only libraries need web fallbacks
  • Accessibility props map to ARIA

Running and Exporting

npx expo install react-dom react-native-web @expo/metro-runtime
npx expo start --web                 # dev server
npx expo export --platform web       # → dist/
npx serve dist                       # preview locally

# app.json
# "web": { "output": "static", "favicon": "./assets/favicon.png" }
#   static → pre-rendered HTML per route (SEO)
#   server → server rendering, loaders, API routes
#   single → one index.html SPA

iOS

  • On iPhone the web build runs in Safari (WebKit)
  • Use env(safe-area-inset-*) for the notch
  • No native modules — check Platform.OS === 'web'

Android

  • On Android the web build runs in Chrome
  • PWAs can be installed to the home screen
  • Hardware back follows browser history

Platform-Aware Code

// Button.web.tsx overrides Button.tsx on web
import { Platform } from 'react-native'

const isWeb = Platform.OS === 'web'

<Pressable
  style={({ hovered, pressed }) => [styles.btn, hovered && styles.hover]}
  accessibilityRole="link"
  href="/pricing"                  // RNW renders an <a>
/>

<Text selectable style={{ userSelect: 'text' }}>Copy me</Text>

// Web-only APIs behind a guard
if (isWeb) document.title = 'Pricing · MyApp'

// Expo Router metadata
import Head from 'expo-router/head'
<Head><title>Pricing</title><meta name="description" content="…" /></Head>

⚠ Common Mistakes

  • Calling document or window at module scope in shared code; native crashes, and static rendering breaks
  • Assuming every npm RN library works on web; check for web support or add a .web.tsx fallback
  • Using Dimensions for responsive web layouts; use useWindowDimensions or media queries via a library

✓ Tips & Best Practices

  • Use Expo Router static output for public pages and +api.ts routes for backend endpoints
  • Test keyboard navigation and screen readers; RNW maps roles to ARIA
  • Consider separate web layouts (sidebars) instead of stretching phone UIs

Quick Summary
