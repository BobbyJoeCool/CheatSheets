Cross-Platform Device APIs

expo-camera · expo-location · expo-notifications · expo-haptics · expo-sensors · requestPermissionsAsync() · Linking.openSettings()

Hardware Through One API

The Expo SDK wraps device features in modules that work on iOS and Android (and often web), and you can install them in bare apps too. Most follow the same pattern: check or request permission, then call the API. Permission prompt text comes from your config so the stores accept it. The OS-specific sheets later cover the native details.

Permission Pattern

  • getPermissionsAsync() — current status, no prompt
  • requestPermissionsAsync() — prompt if allowed
  • status: granted · denied · undetermined
  • canAskAgain: false → send the user to Settings

Location + Camera + Haptics

import * as Location from 'expo-location'
import * as Haptics from 'expo-haptics'
import { CameraView, useCameraPermissions } from 'expo-camera'

async function getPosition() {
  const { status, canAskAgain } =
    await Location.requestForegroundPermissionsAsync()
  if (status !== 'granted') {
    if (!canAskAgain) Linking.openSettings()
    return null
  }
  const pos = await Location.getCurrentPositionAsync({
    accuracy: Location.Accuracy.Balanced })
  return pos.coords            // { latitude, longitude, … }
}

function Scanner() {
  const [permission, request] = useCameraPermissions()
  if (!permission?.granted)
    return <Button title="Allow camera" onPress={request} />
  return <CameraView style={{ flex: 1 }} facing="back"
    barcodeScannerSettings={{ barcodeTypes: ['qr'] }}
    onBarcodeScanned={({ data }) => {
      Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success)
      open(data)
    }} />
}

Notes

requestForegroundPermissionsAsync — while app is open
canAskAgain — false after a hard deny
Accuracy.Balanced — battery-friendly
useCameraPermissions — hook form of the pattern
Haptics — tactile confirmation on success

iOS

  • Every prompt needs an NS…UsageDescription string
  • Denied once → no re-prompt; use Linking.openSettings()
  • "Allow Once" location expires when the app closes

Android

  • Permissions must also be declared in the manifest
  • After two denials the prompt stops showing
  • Users choose approximate vs precise location (12+)

⚠ Common Mistakes

  • Requesting every permission at launch; users deny and stores may reject; ask in context
  • Ignoring canAskAgain; calling request again shows nothing after a permanent deny
  • Forgetting the usage-description text in config; iOS crashes the app when the API is called

✓ Tips & Best Practices

  • Show a short explainer screen before the OS prompt to raise acceptance
  • Use the hooks (useCameraPermissions) to re-check after returning from Settings
  • Check reactnative.directory for maintained community alternatives when Expo lacks a module
