What React Native Is

React Native lets you build native apps with React. Your components render real platform views (UIView on iOS, android.view.View on Android), not a WebView. JavaScript runs on the Hermes engine and talks to native code through JSI, a C++ interface that replaced the old asynchronous JSON bridge. Since 0.82 the New Architecture is the only option.

Version Snapshot (Oct 2026)

  • About one minor release every two months; latest 3 are supported
  • React 19.2, Hermes V1 default since 0.84
  • Expo SDK 57 ships RN 0.86; SDK 58 (beta) moves to 0.88

Hello, World

// App.tsx — the smallest complete app
import { StyleSheet, Text, View } from 'react-native'

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Hello, React Native!</Text>
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center' },
  title: { fontSize: 24, fontWeight: '600' },
})

Notes

View — becomes UIView / ViewGroup; the basic layout box
Text — all strings must live inside <Text>
StyleSheet.create — JS objects, not CSS files
flex: 1 — fill the screen; layout is Flexbox via Yoga
Default export is the root component the native app mounts
Same code runs on iOS and Android unchanged

iOS

  • <View> renders a native UIView; <Text> a native text view
  • Building for iOS needs a Mac with Xcode
  • Every native change goes through App Store review

Android

  • <View> renders a native ViewGroup; <Text> a TextView
  • Android builds on macOS, Windows or Linux
  • Play Store releases ship as .aab bundles

⚠ Common Mistakes

  • Expecting HTML tags like <div> or <p>; only RN components (or a web-only renderer) work
  • Following pre-2025 tutorials that toggle newArchEnabled; the flag is ignored since 0.82
  • Assuming one codebase means zero native work; signing, permissions, and store setup are per OS

✓ Tips & Best Practices

  • Start with Expo (create-expo-app) unless you have a reason to manage native folders by hand
  • Check a library on reactnative.directory for New Architecture and platform support before installing
  • Read the release blog before upgrading; each minor can contain breaking changes

Quick Summary

  • View / Text — native UI primitives
  • JSI — direct JS ↔ native calls
  • Fabric / TurboModules — renderer and modules
  • Hermes — default JS engine
