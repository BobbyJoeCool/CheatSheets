Expo Modules API

create-expo-module · Module definition DSL · Function / AsyncFunction · Events · View · Swift & Kotlin

Native Code in Swift and Kotlin

The Expo Modules API lets you write native modules and views in modern Swift and Kotlin with a small declarative DSL. It handles type conversion, threading, and registration, and works in any React Native app (Expo or bare). It's built on JSI and the New Architecture, and most expo-* packages are written with it.

Getting Started

  • npx create-expo-module@latest my-module (library)
  • npx create-expo-module@latest --local (inside an app)
  • Autolinked; rebuild the dev client after changes
  • Expo Modules 2.0 is in beta with SDK 58

One Module, Both Platforms

// ios/BatteryModule.swift
import ExpoModulesCore

public class BatteryModule: Module {
  public func definition() -> ModuleDefinition {
    Name("Battery")
    Function("getLevel") { () -> Float in
      UIDevice.current.isBatteryMonitoringEnabled = true
      return UIDevice.current.batteryLevel
    }
    AsyncFunction("fetchReport") {
      (days: Int) async throws -> [String: Any] in
      try await BatteryReport.load(days: days)
    }
    Events("onLowBattery")
  }
}

iOS

  • Swift Module with definition()
  • ExpoAppDelegateSubscriber hooks AppDelegate events
  • Run pod install (or prebuild) after adding

Android

  • Kotlin Module with the same DSL
  • ReactActivityLifecycleListener hooks Activity events
  • Rebuild with npx expo run:android

Kotlin + JS

// android/.../BatteryModule.kt
class BatteryModule : Module() {
  override fun definition() = ModuleDefinition {
    Name("Battery")
    Function("getLevel") {
      val bm = appContext.reactContext!!
        .getSystemService(Context.BATTERY_SERVICE) as BatteryManager
      bm.getIntProperty(BatteryManager.BATTERY_PROPERTY_CAPACITY) / 100f
    }
  }
}

// JS
import { requireNativeModule } from 'expo'
const Battery = requireNativeModule('Battery')
Battery.getLevel()                       // 0.82

⚠ Common Mistakes

  • Blocking the JS thread with heavy work in Function; use AsyncFunction
  • Forgetting to rebuild after editing Swift/Kotlin; Metro reloads only JS
  • Mismatched module names between platforms; requireNativeModule fails on one OS

✓ Tips & Best Practices

  • Use Record classes instead of loose dictionaries for typed arguments
  • Add a TypeScript wrapper exporting typed functions over requireNativeModule
  • Prefer Expo Modules over raw TurboModules unless you need C++ or sync JSI tricks
