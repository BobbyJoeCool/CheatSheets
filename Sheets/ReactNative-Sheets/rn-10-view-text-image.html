Sheet 10

View, Text & Image

<View> · <Text> · nesting rules · numberOfLines · <Image> · source / require() · resizeMode · expo-image

The Three Building Blocks

View is the layout container (like a div with Flexbox). Text is the only component that can display strings, and nested Text inherits styles from its parent. Image shows local assets (via require) or remote URLs (via { uri }); remote images need explicit width and height. Expo apps usually swap in expo-image for caching and better formats.

Rules That Bite

  • Strings outside <Text> throw a render error
  • View can't be inside Text on Android (inline views are limited)
  • Text styles inherit only within nested Text
  • Remote Image with no size renders at 0×0

Typical Usage

<View style={{ flexDirection: 'row', gap: 12, padding: 16 }}>
  <Image
    source={{ uri: user.avatarUrl }}           // remote: size required
    style={{ width: 48, height: 48, borderRadius: 24 }}
    accessibilityIgnoresInvertColors
  />
  <View style={{ flex: 1 }}>
    <Text style={{ fontWeight: '700' }} numberOfLines={1}>
      {user.name}{' '}
      <Text style={{ color: 'gray' }}>@{user.handle}</Text>
    </Text>
    <Text numberOfLines={2} ellipsizeMode="tail">{post.body}</Text>
  </View>
  <Image source={require('./assets/icon.png')} />  {/* local */}
</View>

// expo-image: caching, blurhash, transitions
<ExpoImage source={url} placeholder={{ blurhash }}
  contentFit="cover" transition={200} style={{ flex: 1 }} />

Notes

{ uri } — network or file URL; set width/height
require() — bundled asset; size inferred
Nested Text — inherits bold, color, font
numberOfLines + ellipsizeMode — truncate
expo-image — contentFit replaces resizeMode

iOS

  • shadowColor / shadowOffset / shadowOpacity / shadowRadius shadows
  • dynamicTypeRamp on Text scales with Dynamic Type
  • capInsets makes stretchable images

Android

  • elevation gives Material shadows
  • includeFontPadding: false fixes vertical text offset
  • resizeMethod controls how large bitmaps are downscaled

⚠ Common Mistakes

  • Rendering {0} or a string directly in a View; wrap text in <Text>
  • Remote images without width/height; they're invisible, not broken
  • Setting fontFamily on a parent View and expecting children to inherit; only nested Text inherits

✓ Tips & Best Practices

  • Make a shared <AppText> with your default font, color, and size
  • Use @2x / @3x suffixes for local images; RN picks the right density
  • Prefer expo-image (works in bare apps too) for lists of remote images

Quick Summary

  • View — layout container
  • Text — all strings, inherits when nested
  • Image — require() or { uri } + size
  • expo-image — caching & placeholders
