React Refresher: Components

A component is a function that returns JSX. Props are its read-only inputs; children is whatever you nest inside it. JSX compiles to function calls, so you embed any JS expression in {}. In React Native, the JSX uses RN components (View, Text) instead of HTML tags, but the rules are identical to React on the web.

JSX Rules

  • One root element per return (or a fragment <>…</>)
  • Components start with a capital letter
  • {} holds expressions, not statements
  • Lists need a stable key on each item

Props, Children, Conditions, Lists

type CardProps = {
  title: string; done?: boolean; children?: React.ReactNode }

function Card({ title, done = false, children }: CardProps) {
  return (
    <View style={{ padding: 12 }}>
      <Text>{title}{done && ' ✓'}</Text>
      {children}
    </View>
  )
}

function TodoList({ todos }: { todos: Todo[] }) {
  if (todos.length === 0) return <Text>Nothing to do</Text>
  return (
    <>
      {todos.map(t => (
        <Card key={t.id} title={t.title} done={t.done}>
          {t.note ? <Text>{t.note}</Text> : null}
        </Card>
      ))}
    </>
  )
}

Notes

done = false — default value via destructuring
children — nested JSX passed by the parent
&& — render only when true; ternary for either/or
Early return — simplest conditional render
key={t.id} — stable IDs, never array index if order changes

iOS

  • Default font is San Francisco (System)
  • iOS-only props sit beside shared ones, e.g. contentInsetAdjustmentBehavior
  • <Text selectable> shows the native copy menu

Android

  • Default font is Roboto
  • Android-only props use an android_ prefix or *Android suffix
  • <Button> titles render uppercase (Material style)

⚠ Common Mistakes

  • {count && <Text/>} with count = 0; RN tries to render 0 outside <Text> and crashes, use count > 0 &&
  • Mutating props or objects in props; treat them as read-only
  • Bare strings inside View (<View>Hi</View>); text must be in <Text>

✓ Tips & Best Practices

  • Keep components small; extract when a block has its own state or is reused
  • Use React.ReactNode for children and slot props
  • Destructure props in the signature so defaults and types sit together
