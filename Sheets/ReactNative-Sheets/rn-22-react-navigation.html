React Navigation

NavigationContainer · createNativeStackNavigator · bottom tabs · drawer · navigation.navigate() · route.params · static config

Navigation Without File Routing

React Navigation is the standard library for bare apps or teams that prefer configuring screens in code. Version 7 offers a static API (config objects with automatic types and linking) and the classic dynamic API (JSX navigators). Native stack uses platform navigation controllers via react-native-screens. Version 8 is in pre-release with deeper type inference.

Install

  • @react-navigation/native + react-native-screens + react-native-safe-area-context
  • Stack: @react-navigation/native-stack
  • Tabs: @react-navigation/bottom-tabs; drawer needs Gesture Handler + Reanimated
  • v8 (pre-release) needs Gesture Handler 3 and screens 4.25+

Static API (v7)

import { createStaticNavigation, useNavigation }
  from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'
import { createBottomTabNavigator } from '@react-navigation/bottom-tabs'

const HomeTabs = createBottomTabNavigator({
  screens: { Feed: FeedScreen, Profile: ProfileScreen },
})

const RootStack = createNativeStackNavigator({
  screens: {
    Home: { screen: HomeTabs, options: { headerShown: false } },
    Details: { screen: DetailsScreen, linking: 'details/:id' },
  },
})

const Navigation = createStaticNavigation(RootStack)
export default () => <Navigation linking={{ prefixes: ['myapp://'] }} />

function FeedScreen() {
  const navigation = useNavigation()
  return <Button title="Open"
    onPress={() => navigation.navigate('Details', { id: '42' })} />
}
function DetailsScreen({ route }) { return <Text>{route.params.id}</Text> }

Notes

createStaticNavigation — wraps the container for you
linking: 'details/:id' — deep link path per screen
Nested navigators — tabs inside a stack
navigation.navigate(name, params) — go to a screen
Declare RootParamList globally for typed useNavigation

iOS

  • headerBlurEffect, headerLargeTitle, headerTransparent
  • fullScreenGestureEnabled allows swipe-back from anywhere
  • Native stack headers are real UINavigationBars

Android

  • Navigators handle the system back button for you
  • animation: 'slide_from_right' for an iOS-like push
  • A drawer is the common Android top-level pattern

⚠ Common Mistakes

  • Forgetting react-native-screens or Gesture Handler peer deps; crashes or no native transitions
  • Passing functions or large objects in params; params should be serializable IDs
  • Using navigate when you want a second copy of the same screen; use push

✓ Tips & Best Practices

  • Pass an ID in params and fetch the object on the screen
  • Use useFocusEffect for refetching when returning to a screen
  • Prefer native stack over JS stack for performance and platform feel

Quick Summary

  • createNativeStackNavigator — native push/pop
  • Static API — config + automatic types
  • navigate / push / goBack — moves
  • route.params — screen input
