Modal & Feedback Components

<Modal> · presentationStyle · onRequestClose · ActivityIndicator · Switch · Alert.alert() · StatusBar

Overlays and Small Controls

Modal shows content above the current screen. Alert.alert opens a native dialog with buttons. ActivityIndicator is the native spinner, Switch the native toggle, and StatusBar controls the status bar style. With Expo Router you often use a modal route instead of <Modal>, so it gets a URL and native gestures.

0.87 Changes

  • Modal animated prop removed → use animationType
  • StatusBar backgroundColor / translucent removed (edge-to-edge)
  • Modal style now reaches the inner container (0.86)
  • Alert.prompt is iOS only

Modal, Alert, Spinner, Switch

<Modal
  visible={open}
  animationType="slide"                 // none | slide | fade
  presentationStyle="pageSheet"         // iOS card-style sheet
  onRequestClose={() => setOpen(false)} // Android back button
  transparent={false}>
  <SafeAreaView style={{ flex: 1 }}>
    <Button title="Close" onPress={() => setOpen(false)} />
  </SafeAreaView>
</Modal>

Alert.alert('Delete photo?', 'This cannot be undone.', [
  { text: 'Cancel', style: 'cancel' },
  { text: 'Delete', style: 'destructive', onPress: remove },
])

<ActivityIndicator size="large" color="#7e57c2" />
<Switch value={on} onValueChange={setOn}
  trackColor={{ true: '#5c6bc0' }} />
<StatusBar barStyle="light-content" />

Notes

presentationStyle — fullScreen · pageSheet · formSheet · overFullScreen
onRequestClose — required for Android back
transparent — draw your own dim backdrop
style: 'destructive' — red button on iOS
barStyle — default · light-content · dark-content

iOS

  • presentationStyle="pageSheet" gives a native card sheet
  • Alert.prompt and ActionSheetIOS are iOS-only
  • ActivityIndicator size is 'small' or 'large' only

Android

  • Modal needs onRequestClose for the back button
  • Alert supports up to 3 buttons; cancelable allows outside tap
  • ToastAndroid.show() for brief messages

⚠ Common Mistakes

  • Omitting onRequestClose; the Android back button won't close the modal
  • Using StatusBar backgroundColor for Android color; removed in 0.87 since apps draw edge-to-edge
  • Stacking two RN Modals at once; iOS can only present one at a time from the same parent

✓ Tips & Best Practices

  • In Expo Router, prefer presentation: 'modal' or 'formSheet' on a route for native sheets
  • Use formSheet with sheetAllowedDetents for half-height sheets
  • Keep alerts for confirmations; use toasts or inline errors for info

Quick Summary

  • Modal — overlay with animationType
  • Alert.alert — native dialog
  • ActivityIndicator / Switch — native controls
  • StatusBar — bar style only on Android now
