Expo Router Layouts

_layout.tsx · <Stack> · <Tabs> · (group) folders · modal presentation · Stack.Screen options · protected routes

Navigators Live in Layouts

A _layout.tsx file decides how its folder's routes are presented: a Stack (push/pop), Tabs, a drawer, or a plain <Slot />. Layouts nest, so a root Stack can contain a (tabs) group with its own Tabs layout. Groups in parentheses organize routes without changing URLs. Stack.Protected hides routes behind a condition such as being logged in.

Presentation Options

  • presentation: 'modal' — card from bottom (iOS)
  • presentation: 'formSheet' — native sheet with detents
  • presentation: 'transparentModal' — overlay
  • Native tabs (NativeTabs) stable in SDK 58

Root Stack, Tabs Group, Auth Guard

// app/_layout.tsx
export default function RootLayout() {
  const { user } = useAuth()
  return (
    <Stack screenOptions={{ headerShown: false }}>
      <Stack.Protected guard={!!user}>
        <Stack.Screen name="(tabs)" />
        <Stack.Screen name="compose" options={{
          presentation: 'formSheet', sheetAllowedDetents: [0.5, 1],
          headerShown: true, title: 'New post' }} />
      </Stack.Protected>
      <Stack.Protected guard={!user}>
        <Stack.Screen name="login" />
      </Stack.Protected>
    </Stack>
  )
}

// app/(tabs)/_layout.tsx
export default function TabLayout() {
  return (
    <Tabs screenOptions={{ tabBarActiveTintColor: '#7e57c2' }}>
      <Tabs.Screen name="index" options={{ title: 'Home',
        tabBarIcon: ({ color }) => <Icon name="home" color={color} /> }} />
      <Tabs.Screen name="profile" options={{ title: 'Me' }} />
    </Tabs>
  )
}

Notes

name — the file or folder name (no extension)
Stack.Protected guard — false hides & redirects
formSheet + detents — half-height sheet
(tabs) — URL is /, /profile, not /(tabs)/…
tabBarIcon — receives color, size, focused

iOS

  • formSheet uses the native sheet with detents
  • Swipe down dismisses modals; gestureEnabled: false stops it
  • NativeTabs render a native UITabBar

Android

  • formSheet renders as a Material bottom sheet
  • Modals have no swipe-down — back closes them
  • NativeTabs use Material bottom navigation

⚠ Common Mistakes

  • Naming a Stack.Screen that doesn't match a file; the options silently never apply
  • Doing auth redirects in useEffect before navigation mounts; use Stack.Protected or <Redirect>
  • Putting a Tabs layout inside a screen file instead of _layout.tsx

✓ Tips & Best Practices

  • Use groups like (auth) and (app) to split layouts without URL changes
  • Keep the root layout for providers (theme, query client, auth) and the root Stack
  • Prefer formSheet over a custom bottom-sheet library when native detents suffice
