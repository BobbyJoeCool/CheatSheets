Native Mac Apps

React Native macOS is Microsoft's fork that renders real AppKit views (NSView), giving you a true Mac app. It tracks core RN with a lag (latest 0.83 as of Oct 2026), so pin your RN minor to match. Alternatives: run your iPad app on Apple silicon Macs ("Designed for iPad"), or enable Mac Catalyst for a UIKit-based Mac build of your iOS target.

Setup Rules

  • RN and RN macOS must share the same minor version
  • Adds a macos/ folder with its own Podfile and workspace
  • Platform.OS === 'macos'
  • Desktop UX: menus, windows, keyboard, hover

Add macOS to a Project

# New project at a matching RN minor
npx @react-native-community/cli init MyApp --version 0.83.0
cd MyApp
npx react-native-macos-init         # adds react-native-macos + macos/

npx react-native run-macos           # build + launch
npx react-native build-macos         # build only
xed -b macos                         # open the workspace in Xcode

iOS

  • macOS uses AppKit, not UIKit — iOS-only libraries need a port
  • Mac Catalyst / "Designed for iPad" is the zero-effort route
  • Platform.OS is 'macos', not 'ios'

Android

  • No Android desktop target — ChromeOS runs Android builds
  • Keep Android-only code in .android.tsx
  • Hover props (onHoverIn / onHoverOut) work on ChromeOS

Desktop-Aware Components

<Pressable
  onHoverIn={() => setHover(true)}
  onHoverOut={() => setHover(false)}
  focusable                             // tab-key focus
  tooltip="Open a file"                 // macOS-only prop
  keyDownEvents={[{ key: 'Enter' }]}    // keys to receive
  onKeyDown={e => { if (e.nativeEvent.key === 'Enter') open() }}
  style={{ cursor: 'pointer' }}>
  <Text>Open file</Text>
</Pressable>

const title = Platform.select({
  macos: 'Preferences…', default: 'Settings' })

⚠ Common Mistakes

  • Mixing RN 0.87 with RN macOS 0.83; versions must match at the minor level
  • Porting a phone UI unchanged; Mac users expect sidebars, menus, and shortcuts
  • Assuming every native library supports macOS; many are iOS/Android only

✓ Tips & Best Practices

  • Share business logic and components; keep navigation and shell per platform
  • Use .macos.tsx files for desktop-specific screens
  • Try Mac Catalyst first if you only need "the iPad app, but on Mac"
