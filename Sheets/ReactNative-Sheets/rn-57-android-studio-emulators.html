Android Studio, Emulators & adb

SDK Manager · AVD emulators · adb devices · adb reverse · logcat · run:android --variant · Gradle sync errors

Building and Running on Android

Android builds work on macOS, Windows, and Linux. Android Studio installs the SDK, build tools, and emulators (AVDs). The RN CLI runs Gradle for you; adb (Android Debug Bridge) installs apps, forwards ports, and streams logs. You need JDK 17, ANDROID_HOME set, and the platform tools on your PATH.

Environment

  • ANDROID_HOME=$HOME/Library/Android/sdk (macOS)
  • Add $ANDROID_HOME/platform-tools and emulator to PATH
  • Install the SDK Platform for compileSdk (API 37)
  • Physical device: enable Developer options + USB debugging

Running, adb, Gradle

npx expo run:android                       # build + install + Metro
npx expo run:android --variant release
npx react-native run-android --mode debugOptimized
npx react-native run-android --deviceId emulator-5554

emulator -list-avds && emulator -avd Pixel_9_API_36
adb devices                                # list devices
adb reverse tcp:8081 tcp:8081              # Metro over USB
adb install app-release.apk
adb shell am start -n com.acme.myapp/.MainActivity
adb logcat *:S ReactNative:V ReactNativeJS:V
adb shell input keyevent 82                # open dev menu
adb shell pm clear com.acme.myapp          # wipe app data

cd android
./gradlew assembleDebug                    # APK
./gradlew bundleRelease                    # AAB for Play
./gradlew clean
./gradlew :app:dependencies

Notes

--variant / --mode — Gradle build type
adb reverse — device localhost:8081 → your Metro
logcat filter — only React Native logs
keyevent 82 — menu key = dev menu
bundleRelease — Play Store artifact

iOS

  • xcodebuild ↔ ./gradlew
  • simctl ↔ adb / emulator
  • Debug / Release configurations ↔ build types

Android

  • ./gradlew assembleRelease (APK) or bundleRelease (AAB)
  • adb install -r app-release.apk
  • Raise Gradle memory via org.gradle.jvmargs

⚠ Common Mistakes

  • Testing performance in debug; use debugOptimized or release
  • Forgetting adb reverse on USB devices, so the app can't reach Metro
  • Mixing JDK versions between Android Studio and the terminal

✓ Tips & Best Practices

  • Use Android Studio's Logcat and Layout Inspector for native crashes and view hierarchies
  • Create an emulator with the newest API and one with your minSdk
  • Turn on Gradle configuration cache and build cache for faster local builds

Quick Summary

  • Android Studio — SDK + emulators
  • adb — install, logs, port forwarding
  • ./gradlew bundleRelease — AAB
  • JDK 17 + ANDROID_HOME — required
