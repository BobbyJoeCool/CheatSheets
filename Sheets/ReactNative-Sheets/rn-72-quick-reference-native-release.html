⚠ Common Mistakes

  • Tokens in AsyncStorage — use expo-secure-store
  • Shipping an OTA update that needs new native code — bump runtimeVersion and rebuild
  • Animating layout on the JS thread — use the native driver or Reanimated

✓ Tips & Best Practices

  • Keep native config in app.config.ts + config plugins (Continuous Native Generation)
  • Use eas build --profile preview builds for testers
  • Profile release builds; dev mode is much slower

Quick Summary

  • app.json / app.config.ts configure the app
  • TanStack Query + Zustand for data and state
  • Reanimated + Gesture Handler for motion
  • EAS builds, submits and ships OTA updates
