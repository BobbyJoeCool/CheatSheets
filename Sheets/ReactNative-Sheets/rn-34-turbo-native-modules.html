Sheet 34

Turbo Native Modules

TypeScript spec · Codegen · TurboModuleRegistry · codegenConfig · Swift / Obj-C++ · Kotlin implementation

Calling Native Code

When no library exists, write a Turbo Native Module. You describe its API in a TypeScript spec; Codegen generates the C++/Objective-C++/Java glue at build time; then you implement the methods natively. TurboModules load lazily and are called through JSI, so synchronous methods are possible. Since 0.87 TurboModules are always enabled.

Workflow

Spec and Usage

// specs/NativeLocalStorage.ts
import type { TurboModule } from 'react-native'
import { TurboModuleRegistry } from 'react-native'

export interface Spec extends TurboModule {
  setItem(value: string, key: string): void
  getItem(key: string): string | null           // synchronous
  clear(): Promise<void>                         // async
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeLocalStorage')

// package.json
"codegenConfig": {
  "name": "AppSpecs", "type": "modules", "jsSrcsDir": "specs",
  "android": { "javaPackageName": "com.myapp.specs" }
}

// App code
import NativeLocalStorage from './specs/NativeLocalStorage'
NativeLocalStorage.setItem('hello', 'greeting')
NativeLocalStorage.getItem('greeting')          // 'hello'

Notes

File must be named Native*.ts
getEnforcing — throws if the module isn't linked
Return types define sync vs Promise
codegenConfig.name — prefix for generated classes
Kotlin class extends generated NativeLocalStorageSpec

iOS

  • Implement in Objective-C++ (.mm) against the generated protocol
  • Swift needs an Objective-C++ wrapper
  • Codegen runs during pod install

Android

  • Implement in Kotlin / Java extending the generated Native…Spec
  • Register it in a BaseReactPackage
  • Codegen runs during the Gradle build

⚠ Common Mistakes

  • Changing the spec without re-running Codegen; native signatures and JS no longer match
  • Doing slow work in a synchronous method; it blocks the JS thread
  • Naming the spec file without the Native prefix, so Codegen skips it

✓ Tips & Best Practices

  • Use the Expo Modules API (sheet 36) for Swift/Kotlin modules with less boilerplate
  • Scaffold libraries with npx create-react-native-library@latest
  • Keep the spec small and stable; it's your contract between JS and native
