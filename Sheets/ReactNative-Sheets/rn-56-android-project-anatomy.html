Android Project Anatomy

android/ folder · MainActivity.kt · MainApplication.kt · AndroidManifest.xml · build.gradle · gradle.properties

What's Inside android/

The android/ folder is a standard Gradle project. MainApplication.kt creates the ReactHost and loads React Native; MainActivity.kt hosts your root component. Native modules from node_modules are autolinked by the React Native Gradle Plugin. The 0.87 template targets minSdk 24 (Android 7.0), targetSdk 36, compileSdk 37, with AGP 9 and Kotlin 2.2.

Key Facts

  • Kotlin entry files since 0.73; Java still works
  • newArchEnabled is ignored (always on since 0.82)
  • edgeToEdgeEnabled=true in the template
  • Hermes V1 is the default engine (0.84+)

MainApplication.kt + MainActivity.kt

class MainApplication : Application(), ReactApplication {
  override val reactHost: ReactHost by lazy {
    getDefaultReactHost(
      context = applicationContext,
      packageList = PackageList(this).packages.apply {
        // add(MyReactNativePackage())   // manual (non-autolinked)
      },
    )
  }
  override fun onCreate() {
    super.onCreate()
    loadReactNative(this)
  }
}

class MainActivity : ReactActivity() {
  override fun getMainComponentName(): String = "MyApp"
  override fun createReactActivityDelegate(): ReactActivityDelegate =
    DefaultReactActivityDelegate(this, mainComponentName, fabricEnabled)
}

Notes

PackageList — autolinked native packages
loadReactNative — initializes RN and Hermes
getMainComponentName — must match AppRegistry
DefaultReactActivityDelegate — New Arch delegate
Expo generates equivalents with ReactActivityDelegateWrapper

iOS

  • Info.plist ↔ AndroidManifest.xml
  • AppDelegate.swift ↔ MainApplication.kt

Android

⚠ Common Mistakes

  • Changing applicationId after publishing; Play treats it as a different app
  • Editing android/ by hand in an Expo CNG project; prebuild regenerates it, so use config plugins
  • Building only arm64-v8a for local speed and shipping that; older and x86 devices break

✓ Tips & Best Practices

  • Build one ABI locally for speed: -PreactNativeArchitectures=arm64-v8a
  • Keep gradle.properties changes in config (expo-build-properties) for Expo apps
  • Use Android Studio's "Open" on android/ to get Gradle sync and Kotlin tooling
