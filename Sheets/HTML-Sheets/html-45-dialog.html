Modal and Non-Modal Dialogs

<dialog> is a native dialog box. Opened with **showModal(), it sits in the top layer above everything, makes the rest of the page inert**, keeps focus inside, closes with Esc and gets a ::backdrop. Opened with **show()**, it's non-modal and the page stays usable. A form with method="dialog" closes the dialog and sets its returnValue to the clicked button's value.

Notes

  • Don't show modals with the open attribute; that opens them non-modally
  • close(value) closes the dialog and sets returnValue
  • closedby="any" lets a backdrop click close it (newer; not in every browser)
  • commandfor + command="show-modal" opens it without JS (newer; check support)

♿ Accessibility

  • Name the dialog with aria-labelledby pointing at its heading
  • Focus moves into the dialog; put autofocus on the most sensible control
  • When it closes, focus returns to the element that opened it

Pairing with CSS

  • dialog::backdrop { background: rgb(0 0 0 / .5); }: dim the page
  • dialog:modal: styles only when opened with showModal()
  • dialog[open] + @starting-style: animate the opening

Code Explained

showModal(): top layer, inert page, Esc closes it
method="dialog": submitting closes the dialog; no request is sent
button value: becomes dlg.returnValue
close event: fires however it was closed (Esc, form, close())
commandfor: declarative invoker, no script needed

Modal Dialog

<button type="button" id="open-del">Delete trip</button>

<dialog id="confirm" aria-labelledby="dlg-title">
  <h2 id="dlg-title">Delete this trip?</h2>
  <p>This can't be undone.</p>
  <form method="dialog">
    <button value="cancel" autofocus>Cancel</button>
    <button value="delete">Delete</button>
  </form>
</dialog>

<script>
  const dlg = document.getElementById('confirm');
  document.getElementById('open-del')
    .addEventListener('click', () => dlg.showModal());

  dlg.addEventListener('close', () => {
    if (dlg.returnValue === 'delete') deleteTrip();
  });
</script>

<!-- no-JS version: invoker commands (newer) -->
<button commandfor="confirm" command="show-modal">
  Delete trip
</button>

<!-- non-modal: the page stays usable -->
<dialog id="tip" open>Tip: drag to reorder.</dialog>

⚠ Common Mistakes

  • Showing a modal with the open attribute or show(): no backdrop, no inert page, no Esc
  • Building modals from <div>s: you must rebuild focus trapping, Esc and inertness yourself
  • Handling only button clicks: Esc closes the dialog too; listen for close

✓ Tips & Best Practices

  • Use method="dialog" forms for confirm / cancel choices
  • Read the result in the close event via returnValue
  • Animate with @starting-style and transition-behavior: allow-discrete

Quick Summary

  • showModal(): modal, top layer
  • show(): non-modal
  • method="dialog": close via a form
  • ::backdrop: style the overlay
