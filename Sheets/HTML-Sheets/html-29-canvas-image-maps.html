Canvas & Image Maps

canvas · getContext · fallback content · map · area · shape · coords · usemap

Drawing Surfaces and Clickable Regions

<canvas> is a blank bitmap that JavaScript draws on: charts, games, image editors. HTML supplies only the element and its fallback content; the drawing is done with the Canvas API (getContext('2d')). Image maps (<map> + <area>) make regions of one image clickable. Both are niche today, so prefer SVG for interactive graphics and separate links for clickable areas when you can.

Notes

  • Set the bitmap size with width / height attributes (default 300×150)
  • CSS sizing only stretches the bitmap, which can look blurry
  • Content inside <canvas> shows when canvas or scripting is unavailable
  • usemap="#name" links an <img> to <map name="name">

♿ Accessibility

  • Canvas output is just a picture to screen readers; provide text or a data table
  • Canvas charts need role="img" + aria-label, or a nearby summary
  • Each <area> is a link, and its alt is the link text

Pairing with CSS

  • canvas { width: 100%; height: auto; }: scale the display size
  • image-rendering: pixelated: crisp pixel art when scaled up
  • Image-map coordinates use the image's original pixels; they don't follow CSS resizing

Code Explained

width / height: bitmap resolution in pixels
fallback <p>: used when the canvas can't be shown
getContext('2d'): 2D drawing API (webgl2 for 3D)
coords: rect x1,y1,x2,y2 · circle x,y,r · poly x,y pairs
usemap="#trails": matches <map name="trails">

Canvas and an Image Map

<!-- canvas with fallback text -->
<canvas id="chart" width="600" height="300"
        role="img" aria-label="Sales rose from 40 to 95">
  <p>Sales rose from 40 (Jan) to 95 (Jun).</p>
</canvas>

<script>
  const c = document.getElementById('chart');
  const ctx = c.getContext('2d');
  ctx.fillStyle = '#1b5e20';
  ctx.fillRect(20, 200, 60, 80);       // x, y, w, h
  ctx.beginPath();
  ctx.arc(300, 150, 40, 0, Math.PI * 2);
  ctx.fill();
</script>

<!-- image map -->
<img src="trail-map.png" alt="Park trail map"
     width="800" height="500" usemap="#trails">
<map name="trails">
  <area shape="rect" coords="40,60,220,140"
        href="/trails/ridge" alt="Ridge Loop">
  <area shape="circle" coords="500,250,60"
        href="/trails/lake" alt="Lake Trail">
  <area shape="poly" coords="600,50,760,90,700,200"
        href="/trails/summit" alt="Summit Path">
</map>

⚠ Common Mistakes

  • Sizing a canvas only with CSS: the 300×150 bitmap is stretched and blurry
  • Shipping a canvas chart with no text alternative: the data is invisible to screen readers
  • Expecting image maps to adapt to responsive images: coordinates stay in the original pixels

✓ Tips & Best Practices

  • Multiply the canvas size by devicePixelRatio and ctx.scale() for sharp drawing
  • Use SVG or HTML + CSS for interactive diagrams instead of image maps
  • Offer a data table alongside any canvas chart

Quick Summary

  • <canvas>: script-drawn bitmap
  • getContext('2d'): drawing API
  • <map> + <area>: clickable regions
  • fallback / alt: text alternatives
