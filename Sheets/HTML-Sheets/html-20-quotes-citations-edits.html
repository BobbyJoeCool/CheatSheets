Sheet 20

Quotes, Citations & Edits

blockquote · q · cite · abbr · dfn · time · ins · del

Quoting, Defining and Tracking Changes

<blockquote> holds a long quotation as its own block; <q> is a short inline quote, and the browser adds the quotation marks. <cite> is the title of a work, not a person. <abbr> marks an abbreviation and <dfn> the defining use of a term. <time> gives dates a machine-readable datetime, and <ins> / <del> record edits to a document.

Notes

  • The cite attribute (a source URL) isn't shown to users
  • Put the attribution outside <blockquote>, e.g. in a <figcaption>
  • datetime accepts dates, times and durations like PT2H30M
  • <ins> / <del> take cite and datetime attributes

♿ Accessibility

  • <abbr title> isn't reliably announced; spell the term out on first use
  • Quote marks from <q> come from CSS, and most screen readers skip them
  • <del> / <ins> usually aren't announced; add hidden "deleted:" text when edits matter

Pairing with CSS

  • q { quotes: "“" "”" "‘" "’"; }: set quote marks; :lang(fr) q for « guillemets »
  • blockquote { margin: 1em 40px; }: UA indent; restyle with a left border
  • abbr[title] { text-decoration: underline dotted; }: UA default hint

Code Explained

cite attribute: source URL for scripts, not displayed
<cite>: the title of the work (Camping Handbook)
<q>: browser inserts language-appropriate quote marks
<dfn id>: link to the definition from elsewhere
datetime: ISO format that machines can read

Quotes and Citations

<figure>
  <blockquote cite="https://example.com/handbook">
    <p>Leave every campsite better than you
       found it.</p>
  </blockquote>
  <figcaption>
    Rocky Trails Club, <cite>Camping Handbook</cite>
  </figcaption>
</figure>

<p>The ranger said <q>stay on the marked trail</q>.</p>

<p><dfn id="def-treeline">Treeline</dfn> is the
   elevation above which trees can't grow.</p>

<p>Check the
   <abbr title="National Park Service">NPS</abbr>
   website first.</p>

<p>Opens <time datetime="2026-06-01">June 1</time>
   at <time datetime="09:00">9 am</time>.</p>

<p>Permit fee: <del datetime="2026-01-10">$20</del>
   <ins datetime="2026-01-10">$25</ins></p>

⚠ Common Mistakes

  • Wrapping the author's name in <cite>: it's for titles of works
  • Using <blockquote> just to indent text; use CSS margin
  • Typing quote marks inside <q>: you get doubled quotes

✓ Tips & Best Practices

  • Use <figure> + <figcaption> to attach an attribution to a quote
  • Always add datetime when the visible text is relative ("yesterday")
  • Show price changes with <s>; document edits with <del> / <ins>

Quick Summary

  • <blockquote> / <q>: block / inline quote
  • <cite>: title of a work
  • <abbr> / <dfn>: abbreviation / definition
  • <time>, <ins>, <del>: dates and edits
