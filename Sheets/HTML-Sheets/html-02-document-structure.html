Sheet 02

Document Structure

<!doctype html> · html · head · body · lang · charset · boilerplate

The Page Skeleton

Every HTML document has the same skeleton: a doctype, one <html> root, a <head> for metadata and a <body> for content. The parser adds missing <html>, <head> and <body> tags automatically, but writing them out keeps the structure clear. The charset declaration must appear within the first 1024 bytes of the file.

Notes

  • Only one <head> and one <body> per document
  • <html lang> sets the default language for all content
  • <meta charset="utf-8"> should be the first child of <head>
  • Nothing in <head> renders; <title> shows in the tab

♿ Accessibility

  • <title> is announced first when the page loads; make each page's title unique
  • lang lets screen readers pick pronunciation and translators detect the language
  • Use dir="rtl" on <html> for right-to-left languages like Arabic or Hebrew

Pairing with CSS

  • html: the root element; rem units are relative to its font-size
  • :root: same element as html but higher specificity; home for custom properties
  • body: every browser gives it an 8px margin; most resets remove it

Code Explained

<!doctype html>: case-insensitive; no DTD needed in modern HTML
lang: BCP 47 codes such as en, en-US, fr, zh-Hans
order in <head>: charset first, then viewport and title
defer in <head>: downloads early, runs after parsing
<header> / <main> / <footer>: landmark regions (sheet 13)

Annotated Boilerplate

<!doctype html>                  <!-- standards mode -->
<html lang="en">                 <!-- root + language -->
<head>
  <meta charset="utf-8">         <!-- text encoding -->
  <meta name="viewport"          <!-- mobile scaling -->
        content="width=device-width, initial-scale=1">
  <title>Order History · Trailhead</title>
  <meta name="description"
        content="Your past orders and receipts.">
  <link rel="icon" href="/favicon.svg">
  <link rel="stylesheet" href="/css/site.css">
  <script src="/js/app.js" defer></script>
</head>
<body>
  <header>…site header…</header>
  <main>
    <h1>Order History</h1>
    …page content…
  </main>
  <footer>…site footer…</footer>
</body>
</html>

Document-Level Elements

ElementRole
<!doctype html>triggers standards mode
<html>root element; holds lang, dir
<head>metadata container
<body>rendered content
<title>required; tab and history name
<meta charset>character encoding

Optional Tags

TagParser behavior
<html>inserted if missing
<head>inferred from first metadata element
<body>inferred from first content element
</p>, </li>closed by the next block or item

Rendering Modes

DoctypeMode
<!doctype html>standards (no quirks)

⚠ Common Mistakes

  • Omitting the doctype: the page renders in quirks mode with old box-model bugs
  • Putting <meta charset> late in <head>: the browser may guess the encoding and garble text
  • Placing visible content in <head>: the parser closes <head> early and moves it into <body>

✓ Tips & Best Practices

  • Type ! then Tab in VS Code (Emmet) to insert this boilerplate
  • Give every page one <h1> and a unique <title>
  • Put <script defer> in <head> instead of at the end of <body>

Quick Summary

  • <!doctype html>: standards mode
  • <html lang>: root and language
  • <head>: metadata, not rendered
  • <body>: visible content
