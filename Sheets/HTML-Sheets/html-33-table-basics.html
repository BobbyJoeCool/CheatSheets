Table Basics

Structuring Tabular Data

Tables present data in rows and columns, like a schedule or price list. <table> holds rows (<tr>), and each row holds header cells (<th>) and data cells (<td>). Row groups <thead>, <tbody> and <tfoot> separate headers, data and totals, and <caption> titles the table. Never use tables for page layout; that's CSS Grid's job.

Notes

  • <caption> must be the first child of <table>
  • The parser adds <tbody> automatically if you leave it out
  • <tfoot> renders at the bottom wherever it appears in the source
  • Browsers usually repeat <thead> on each printed page

♿ Accessibility

  • <caption> is the table's accessible name, announced first
  • <th> cells are read as headers as users move between cells
  • Inherited layout tables need role="presentation" so they aren't read as data

Pairing with CSS

  • border-collapse: collapse: single borders instead of doubled ones
  • tbody tr:nth-child(even): zebra striping
  • caption-side: bottom moves the caption; th { text-align: left } overrides the centered default

Code Explained

<caption>: visible title and accessible name
scope="col": header for the column below it
<th scope="row">: the first cell names the row
<tfoot>: the totals row
empty <td>: keeps every row the same width

A Complete Table

<table>
  <caption>Trail difficulty and distance</caption>
  <thead>
    <tr>
      <th scope="col">Trail</th>
      <th scope="col">Distance</th>
      <th scope="col">Elevation</th>
      <th scope="col">Difficulty</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Lake Trail</th>
      <td>4 km</td>
      <td>120 m</td>
      <td>Easy</td>
    </tr>
    <tr>
      <th scope="row">Ridge Loop</th>
      <td>12 km</td>
      <td>600 m</td>
      <td>Hard</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Total</th>
      <td>16 km</td>
      <td>720 m</td>
      <td></td>
    </tr>
  </tfoot>
</table>

⚠ Common Mistakes

  • Using <td> with bold text as headers: screen readers don't treat them as headers
  • Missing <caption>: users hear "table, 4 columns" with no idea what it holds
  • Building page layouts with tables: hard to make responsive and confusing when read aloud

✓ Tips & Best Practices

  • Right-align numbers and use font-variant-numeric: tabular-nums
  • Wrap wide tables in a scroll container (sheet 35)
  • Use position: sticky on thead th for long tables

Quick Summary

  • <table> / <tr>: rows
  • <th> / <td>: header / data cells
  • <thead> / <tbody> / <tfoot>: groups
  • <caption>: accessible title
