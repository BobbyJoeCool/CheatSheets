Sheet 39

Date, Color, Range & File

date · time · datetime-local · color · range · file · accept · capture

Specialized Inputs

Some input types bring their own picker. date, time and datetime-local open native date and time pickers and always submit ISO values (2026-06-01), whatever format the user sees. color opens a color picker, range shows a slider and file opens the file chooser, with accept to filter file types and capture to open the camera on phones.

Notes

  • min, max and step work on date, time and range
  • month and week aren't supported in Firefox or desktop Safari
  • A color value is always lowercase hex: #1b5e20
  • file + multiple lets users pick several files

♿ Accessibility

  • A range slider hides the exact value; show it with <output> (sheet 40)
  • Native date pickers vary with screen readers; allow typing too
  • Label file inputs with what to upload and the size/format limits

Pairing with CSS

  • ::file-selector-button: style the "Choose file" button
  • accent-color: tints the range thumb and track in most browsers
  • ::-webkit-slider-thumb / ::-moz-range-thumb: full slider styling

Code Explained

date value: always YYYY-MM-DD; shown in the user's locale
step="900": seconds, so 15-minute steps
datetime-local: no time zone included
accept: MIME types or extensions (.pdf); not a security check
capture="environment": rear camera; user = front

⚠ Common Mistakes

  • Trusting accept for security: users can pick any file; validate on the server
  • Using range when the exact number matters: precise values are hard to hit
  • Formatting a date value in local style (06/01/2026): the input ignores it

✓ Tips & Best Practices

  • Show the slider's current value beside it with <output>
  • Check file.size in JS before uploading large files
  • Use min / max on dates to block impossible bookings

Quick Summary

  • date / time: ISO values, native pickers
  • color: hex picker
  • range: slider, imprecise
  • file + accept: uploads
