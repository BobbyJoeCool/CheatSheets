Link Schemes & rel

mailto: · tel: · sms: · rel="noopener" · noreferrer · nofollow · hreflang · ping

Special URLs and Link Relationships

href isn't limited to web pages. URL schemes like mailto:, tel: and sms: open the user's email, phone or messaging app. The rel attribute describes the relationship to the target: noopener and noreferrer protect security and privacy, while nofollow, sponsored and ugc tell search engines how to treat the link. hreflang and type describe what's on the other end.

Notes

  • rel takes a space-separated list: rel="noopener noreferrer"
  • noreferrer also implies noopener
  • mailto: parameters: subject, body, cc, bcc (URL-encoded)
  • Use full international numbers in tel:: tel:+13035550142

♿ Accessibility

  • Show the actual email address or number as link text; not everyone has a mail app set up
  • Phone links are announced as links, so say "Call" in the text
  • rel values aren't announced; the visible text must carry the meaning

Pairing with CSS

  • a[href^="mailto:"]::before { content: "✉ "; }: icons by scheme
  • a[href^="tel:"]: style phone links, e.g. larger tap targets
  • a[rel~="external"]: ~= matches one word in a space-separated list

Code Explained

%20: URL-encode spaces and punctuation in mailto:
tel:+1…: E.164 format dials correctly worldwide
noopener: the new page can't reach window.opener
noreferrer: no Referer header is sent
ping: tracking without redirects; off by default in Firefox

Schemes and Relationships

<!-- email with a subject -->
<a href="mailto:help@example.com?subject=Order%201042">
  help@example.com
</a>

<!-- phone and SMS -->
<a href="tel:+13035550142">Call (303) 555-0142</a>
<a href="sms:+13035550142">Text us</a>

<!-- security & privacy -->
<a href="https://partner.example" target="_blank"
   rel="noopener noreferrer">Partner site</a>

<!-- search engine hints -->
<a href="https://ads.example/x" rel="sponsored">Ad</a>
<a href="https://visitor.example" rel="ugc nofollow">
  Commenter's site</a>

<!-- describe the target -->
<a href="/es/" hreflang="es" lang="es">Español</a>
<a href="/report.pdf" type="application/pdf">Report</a>

<!-- relationships -->
<a href="/blog/page/3" rel="next">Next page</a>
<a href="https://me.example" rel="me">My website</a>

<!-- ping: POSTs to a URL when clicked -->
<a href="/shop" ping="/analytics/click">Shop</a>

⚠ Common Mistakes

  • Hiding the address behind "Contact us" with mailto:: users without a mail app can't copy it
  • Unencoded spaces or & in mailto: parameters: the subject or body gets cut off
  • Letters and spaces in tel: (tel:303-555-SHOE): dialers may fail; use digits and +

✓ Tips & Best Practices

  • Add rel="noopener noreferrer" to untrusted links that open new tabs
  • Use rel="ugc" on links in comments and forums
  • Pair hreflang with language names written in that language

Quick Summary

  • mailto: / tel: / sms:: app links
  • noopener / noreferrer: security, privacy
  • nofollow / sponsored / ugc: SEO hints
  • hreflang / type: describe the target
