Language and Direction

The lang attribute tells browsers, screen readers, translators and spell-checkers what language text is in. dir sets text direction: ltr, rtl or auto. <bdi> isolates text of unknown direction (like usernames) so it can't scramble the line, and <bdo> forces a direction. <ruby> adds pronunciation guides above East Asian characters, and translate="no" protects names from machine translation.

Notes

  • Set lang on <html>, then override per element: <span lang="fr">
  • dir="auto" picks the direction from the first strong character
  • <bdi> behaves as if dir="auto" were set
  • <rp> holds fallback parentheses for browsers without ruby support

♿ Accessibility

  • Screen readers switch voice and pronunciation on lang changes; tag foreign phrases
  • A wrong lang makes text unintelligible when read aloud
  • WCAG 3.1.2 (Language of Parts) requires marking language changes

Pairing with CSS

  • :lang(ar) styles by language; :dir(rtl) styles by direction
  • margin-inline-start: logical properties flip automatically for RTL
  • ruby-position: under: place annotations below the base text

Code Explained

lang="fr": French voice and hyphenation rules
dir="rtl": right-to-left base direction
<bdi>: keeps ": 3 posts" in the right place after Arabic names
dir="auto" on inputs: follows what the user types
<rt>: the annotation; <rp>: fallback parentheses

Language, Direction & Ruby

<html lang="en">
…
<!-- inline language change -->
<p>She said <span lang="fr">c'est la vie</span>.</p>

<!-- right-to-left block -->
<p dir="rtl" lang="ar">مرحبا بالعالم</p>

<!-- user content of unknown direction -->
<ul>
  <li><bdi>إيان</bdi>: 3 posts</li>
  <li><bdi>Maria</bdi>: 5 posts</li>
</ul>

<!-- direction from what the user types -->
<input type="text" name="comment" dir="auto">

<!-- force a direction (rare) -->
<bdo dir="rtl">This text is reversed</bdo>

<!-- ruby: pronunciation annotation -->
<ruby>漢<rp>(</rp><rt>kan</rt><rp>)</rp>
      字<rp>(</rp><rt>ji</rt><rp>)</rp></ruby>

<!-- don't translate brand names -->
<p><span translate="no">Trailhead</span> ships abroad.</p>

⚠ Common Mistakes

  • Setting lang only on <html> for mixed-language pages: foreign phrases get mispronounced
  • Using dir="rtl" just to right-align text; use CSS text-align
  • Inserting user names into text without <bdi>: punctuation and numbers jump around

✓ Tips & Best Practices

  • Use logical CSS properties (padding-inline-start) so layouts flip for RTL
  • Add translate="no" to product names, code and usernames
  • Test RTL by setting dir="rtl" on <html> in DevTools

Quick Summary

  • lang: language of the content
  • dir: text direction
  • <bdi> / <bdo>: isolate / override direction
  • <ruby>: pronunciation annotations
