SVG in HTML

inline svg · viewBox · path · use · symbol · title · role="img"

Inline and Referenced SVG

SVG is a vector image format written in XML. You can reference it like any image (<img src="logo.svg">) or paste it inline in HTML, where its shapes become DOM elements you can style with CSS and script with JS. viewBox defines the drawing's coordinate system so it scales cleanly, and <symbol> + <use> build an icon sprite you reuse across the page.

Notes

  • Inline SVG in HTML doesn't need the xmlns attribute
  • viewBox="0 0 24 24" = min-x, min-y, width, height
  • <img src=".svg"> is sandboxed: no page CSS, no scripts
  • fill="currentColor" makes icons follow the text color

♿ Accessibility

  • Informative inline SVG: role="img" plus <title> or aria-label
  • Decorative icons: aria-hidden="true" so they're skipped
  • Icon-only buttons need a name on the <button>, not just the SVG

Pairing with CSS

  • .icon { width: 1em; height: 1em; fill: currentColor; }: icons sized and colored like text
  • .map path { stroke: var(--brand); }: style shapes inside inline SVG
  • Transitions and animations work on inline SVG shapes

Code Explained

viewBox: the drawing is 24×24 units, scaled to 48×48 px
role="img" + <title>: announced as one image named Mountain
<symbol>: reusable, not drawn until a <use> points at it
<use href>: the old xlink:href is no longer needed
external sprites: must be same-origin

Inline SVG and Sprites

<!-- as an image (simplest) -->
<img src="/img/logo.svg" alt="Trailhead"
     width="120" height="40">

<!-- inline, informative -->
<svg viewBox="0 0 24 24" width="48" height="48"
     role="img" aria-labelledby="t1">
  <title id="t1">Mountain</title>
  <path d="M2 20 L9 7 L13 13 L16 9 L22 20 Z"
        fill="currentColor"/>
</svg>

<!-- sprite: define once, hidden -->
<svg width="0" height="0" style="position:absolute">
  <symbol id="i-cart" viewBox="0 0 24 24">
    <path d="M3 4h2l2 12h11l2-8H7"/>
  </symbol>
</svg>

<!-- reuse anywhere -->
<button type="button" aria-label="Cart">
  <svg class="icon" aria-hidden="true">
    <use href="#i-cart"/>
  </svg>
</button>

<!-- external sprite (same origin) -->
<svg class="icon" aria-hidden="true">
  <use href="/icons.svg#i-cart"/>
</svg>

⚠ Common Mistakes

  • Missing viewBox: the SVG won't scale; it crops or stays at a fixed size
  • Hard-coded fill="#000" in icons: CSS color can't change them; use currentColor
  • Unlabeled informative inline SVG: screen readers skip it

✓ Tips & Best Practices

  • Optimize exported SVGs with SVGO to strip editor metadata
  • Use a sprite for icon sets; inline only icons you animate or restyle
  • Keep width / height attributes as a fallback before CSS loads

Quick Summary

  • <img src=".svg">: simple and cached
  • inline <svg>: stylable and scriptable
  • viewBox: scalable coordinates
  • <symbol> + <use>: icon sprites
