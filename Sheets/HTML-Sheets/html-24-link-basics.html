Link Basics

a · href · absolute vs relative · fragment #id · target · download

Anchors and URLs

The <a> element with an href creates a hyperlink. URLs can be absolute (https://…), root-relative (/about) or relative to the current file (../img/a.png). A fragment (#id) jumps to an element on a page. target chooses where the link opens, and download saves the file instead of navigating to it.

Notes

  • <a> without href is a placeholder, not a link, and isn't focusable
  • href="#" jumps to the top and adds # to the URL; use a <button> for actions
  • target="_blank" implies rel="noopener" in modern browsers
  • download only works for same-origin, blob: and data: URLs

♿ Accessibility

  • Link text must make sense alone: "Download the 2026 catalog", not "click here"
  • Say when a link opens a new tab or downloads a file: "(PDF, 2 MB)"
  • Links navigate, buttons act; keyboard users press Enter on links, Enter or Space on buttons

Pairing with CSS

  • a:link, :visited, :hover, :active: write state rules in LVHA order
  • :any-link: matches every <a href>, visited or not
  • a[target="_blank"]::after { content: " ↗"; }: mark new-tab links

Code Explained

/shop/boots: starts at the site root, works from any folder
../: moves up one folder
#reviews: scrolls to id="reviews"
download="catalog.pdf": the suggested filename
#:~:text=: scrolls to and highlights matching text

Link Types

<!-- absolute URL -->
<a href="https://developer.mozilla.org/">MDN Web Docs</a>

<!-- root-relative: from the site root -->
<a href="/shop/boots">Boots</a>

<!-- document-relative -->
<a href="sizing.html">Sizes</a>        <!-- same folder -->
<a href="../index.html">Home</a>       <!-- up a level -->
<a href="docs/returns.html">Returns</a> <!-- down one -->

<!-- fragments -->
<a href="#reviews">Jump to reviews</a>
<a href="/faq#shipping">Shipping FAQ</a>
<h2 id="reviews">Reviews</h2>

<!-- new tab: tell the user -->
<a href="https://maps.example.com" target="_blank">
  Trail map (opens in a new tab)
</a>

<!-- download with a suggested filename -->
<a href="/files/catalog-2026.pdf" download="catalog.pdf">
  Download the catalog (PDF, 2 MB)
</a>

<!-- link to a text fragment -->
<a href="/guide#:~:text=bring%20water">Bring water</a>

⚠ Common Mistakes

  • Using <a href="#"> or href="javascript:void(0)" for actions; use <button type="button">
  • Repeating vague text like "read more": a screen reader's link list becomes useless
  • Relative URLs in shared headers that break in subfolders; use root-relative paths

✓ Tips & Best Practices

  • Use root-relative URLs in site-wide headers and footers
  • Include the file type and size in download links
  • Avoid target="_blank" for your own pages; let users choose
