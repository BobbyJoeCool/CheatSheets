Checkboxes, Radios and Selects

Use checkboxes for independent yes/no choices, radio buttons for exactly one choice from a small set, and **<select>** for one (or several) choices from a longer list. Radios that share a name form a group, so only one can be checked. A checkbox submits its value only when checked, and the default value is "on".

Notes

  • Radio groups: the same name, a different value for each
  • checked and selected set the initial state only
  • <select multiple> needs Ctrl/Cmd-click; checkboxes are often clearer
  • <optgroup label> groups options under a heading

♿ Accessibility

  • Wrap radio and checkbox groups in <fieldset> + <legend> so the question is read (sheet 42)
  • Arrow keys move within a radio group; Tab moves to the next group
  • Native controls are accessible by default; custom ones need roles and key handling

Pairing with CSS

  • accent-color: #1b5e20: recolor native checkboxes, radios, range and progress
  • :checked: input:checked + label or label:has(:checked) for selected states
  • appearance: none: fully custom controls (keep a visible focus style)

Code Explained

wrapping <label>: clicking the text toggles the box
name="ship": the shared name links the radios
value="" first option + required: forces a real choice
disabled option: visible but can't be chosen
<option> with no value: submits its text

Checkbox, Radio and Select

<!-- independent checkbox -->
<label>
  <input type="checkbox" name="news" value="yes" checked>
  Email me trail updates
</label>

<!-- radio group -->
<fieldset>
  <legend>Shipping speed</legend>
  <label><input type="radio" name="ship" value="std"
         checked> Standard (5–7 days)</label>
  <label><input type="radio" name="ship" value="exp">
    Express (2 days)</label>
</fieldset>

<!-- select with groups -->
<label for="size">Size</label>
<select id="size" name="size" required>
  <option value="">Choose a size</option>
  <optgroup label="Women's">
    <option value="w7">7</option>
    <option value="w8" selected>8</option>
  </optgroup>
  <optgroup label="Men's">
    <option value="m9">9</option>
    <option value="m10" disabled>10 (sold out)</option>
  </optgroup>
</select>

<!-- several choices -->
<label for="colors">Colors</label>
<select id="colors" name="colors" multiple size="3">
  <option>Moss</option><option>Slate</option>
  <option>Sand</option>
</select>

⚠ Common Mistakes

  • Radio buttons with different names: they stop acting as a group
  • Expecting an unchecked checkbox to submit false: it submits nothing; handle the missing key on the server
  • Placeholder options without value="": required can't tell nothing was chosen

✓ Tips & Best Practices

  • Make the whole <label> clickable for bigger touch targets
  • Prefer radios over a select for five or fewer options: every choice stays visible
  • Style checked states with :has(:checked) on the wrapping label

Quick Summary

  • checkbox: independent on/off
  • radios + shared name: one of many
  • <select> / <optgroup>: long lists
  • checked / selected: initial state
