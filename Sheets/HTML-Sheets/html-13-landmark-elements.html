Landmark Elements

header · nav · main · footer · aside · search · implicit landmark roles

Page Regions

Landmark elements divide a page into regions that assistive-tech users can jump between: <header> (banner), <nav>, <main>, <aside> (complementary), <footer> (contentinfo) and <search>, plus <form> and <section> when they have a name. They replace the old <div id="header"> pattern with structure that's easy to read in code and quick to navigate by ear.

Notes

  • Use exactly one visible <main> per page
  • <header> / <footer> are landmarks only when not inside <article>, <aside>, <main>, <nav> or <section>
  • <search> (2023) wraps search and filter forms
  • Several <nav> elements are fine; label each one

♿ Accessibility

  • Screen readers list landmarks (NVDA: D key, VoiceOver: rotor) to jump between regions
  • Label repeated landmarks: <nav aria-label="Breadcrumb">
  • Keep all content inside some landmark so landmark navigation skips nothing

Pairing with CSS

  • body > header: targets the site header only, not article headers
  • main { max-width: 70rem; margin-inline: auto; }: common page-width anchor
  • grid-template-areas: "header header" "nav main" "footer footer": lay out landmarks with Grid

Code Explained

<header> at body level: role banner
aria-label: tells the two <nav> landmarks apart
<search>: role search
<aside> at body level: role complementary
<footer> at body level: role contentinfo

A Page with Landmarks

<body>
  <header>                          <!-- banner -->
    <a href="/" class="logo">Trailhead</a>
    <nav aria-label="Main">         <!-- navigation -->
      <ul>
        <li><a href="/shop">Shop</a></li>
        <li><a href="/blog">Blog</a></li>
      </ul>
    </nav>
    <search>                        <!-- search -->
      <form action="/search">
        <label for="q">Search</label>
        <input id="q" name="q" type="search">
      </form>
    </search>
  </header>

  <main>                            <!-- main -->
    <h1>Hiking Boots</h1>
    …
  </main>

  <aside aria-label="Related">      <!-- complementary -->
    …
  </aside>

  <footer>                          <!-- contentinfo -->
    <nav aria-label="Footer">…</nav>
    <p>&copy; 2026 Trailhead</p>
  </footer>
</body>

⚠ Common Mistakes

  • More than one visible <main>: screen readers can't tell which is the real content
  • Wrapping every block in <section> or <nav>: too many landmarks help as little as none
  • Assuming <header> is only for the site banner: articles and cards can have headers (just not landmarks)

✓ Tips & Best Practices

  • Sketch the page as header / nav / main / aside / footer before writing markup
  • Check landmarks in DevTools' Accessibility tree or with a browser extension
  • Make the skip link the first element in <body>, pointing at <main id="main">

Quick Summary

  • <header> / <footer>: banner, contentinfo
  • <nav>: navigation blocks
  • <main>: one per page
  • <aside> / <search>: side and search regions
