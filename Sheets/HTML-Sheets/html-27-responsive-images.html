Responsive Images

srcset, sizes and picture

Responsive images let the browser download the right file for each screen. **srcset with w descriptors plus sizes lists the available widths and how wide the image will display; the browser picks a file for the screen's width and pixel density. x descriptors handle fixed-size images on high-DPI screens. <picture> handles art direction (different crops) and format fallbacks** (AVIF → WebP → JPEG).

Notes

  • sizes is required with w descriptors; it describes layout width, not file width
  • High-DPI screens may get a larger file than the layout width; that's intended
  • <source> elements are tested in order; the first match wins
  • The <img> inside <picture> is required and holds alt

♿ Accessibility

  • alt goes on the <img>, never on <picture> or <source>
  • Art-directed crops should keep the same meaning, or the alt won't match
  • Smaller files load faster on slow mobile connections

Pairing with CSS

  • picture img { width: 100%; height: auto; }: style the <img>; <picture> is only a wrapper
  • Keep sizes in step with your CSS breakpoints and column widths
  • background-image: image-set(…): the CSS version of srcset

Code Explained

2x: file for screens with a device pixel ratio of 2
400w: the file's real width in pixels
sizes: full width under 600px, half under 1200px, else 600px
type: skip formats the browser can't decode
media: swap the crop at a breakpoint

Resolution, Width and Art Direction

<!-- fixed display size, sharper on retina: x -->
<img src="avatar-80.jpg"
     srcset="avatar-80.jpg 1x, avatar-160.jpg 2x"
     alt="Jo Rivera" width="80" height="80">

<!-- fluid width: w + sizes -->
<img src="boot-800.jpg"
     srcset="boot-400.jpg 400w,
             boot-800.jpg 800w,
             boot-1600.jpg 1600w"
     sizes="(max-width: 600px) 100vw,
            (max-width: 1200px) 50vw,
            600px"
     alt="Trail Runner 3, side view"
     width="800" height="600">

<!-- format fallback -->
<picture>
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="Hikers at sunrise"
       width="1600" height="900">
</picture>

<!-- art direction: a different crop on phones -->
<picture>
  <source media="(max-width: 600px)"
          srcset="team-square.jpg">
  <img src="team-wide.jpg" alt="Our guide team"
       width="1200" height="500">
</picture>

⚠ Common Mistakes

  • Omitting sizes with w descriptors: the browser assumes 100vw and downloads oversized files
  • Putting alt on <source> or <picture>: only the <img> alt is used
  • Using <picture> only for resolution switching: srcset on <img> is simpler and lets the browser decide

✓ Tips & Best Practices

  • Generate 400/800/1200/1600 widths at build time or with an image CDN
  • Check which file loaded in DevTools → Network or with img.currentSrc
  • List AVIF first, then WebP, then the JPEG <img>

Quick Summary

  • srcset + x: density switching
  • srcset + w + sizes: width switching
  • <picture> + type: format fallback
  • <picture> + media: art direction
