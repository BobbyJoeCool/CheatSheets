Template & Slot

template · content · cloneNode · slot · named slots · slotchange

Inert Markup for Reuse

<template> holds HTML that is parsed but not rendered: no images load, no scripts run and it isn't part of the page. JavaScript clones its content (a DocumentFragment) to stamp out copies such as rows, cards or list items. Inside a shadow DOM, <slot> marks where a component's children appear, and named slots place specific children in specific spots.

Notes

  • template.content is a DocumentFragment; copy it with cloneNode(true)
  • Templates are allowed almost anywhere, even inside <table> or <select>
  • <slot> only does anything inside a shadow root
  • Children without slot="…" go into the default (unnamed) slot

♿ Accessibility

  • Cloned content still needs semantic elements and unique ids
  • After inserting new content, announce it (live region) or move focus if needed
  • Slotted content keeps its place in the accessibility tree under the host

Pairing with CSS

  • template { display: none; }: UA default; its content never renders
  • ::slotted(h2): style top-level slotted children from inside the shadow DOM
  • Slotted elements still get page styles; they live in the light DOM

Code Explained

.content.cloneNode(true): deep copy of the fragment
textContent: safe; no HTML injection
slot="title": goes into <slot name="title">
"Untitled": fallback shown when nothing is slotted
default <slot>: receives every other child

Templates and Slots

<ul id="trail-list"></ul>

<template id="trail-row">
  <li class="trail">
    <h3 class="name"></h3>
    <p class="meta"><span class="km"></span> km</p>
  </li>
</template>

<script>
  const tpl = document.getElementById('trail-row');
  const list = document.getElementById('trail-list');
  const trails = [{ name: 'Ridge', km: 12 },
                  { name: 'Lake', km: 4 }];
  for (const t of trails) {
    const li = tpl.content.cloneNode(true);
    li.querySelector('.name').textContent = t.name;
    li.querySelector('.km').textContent = t.km;
    list.append(li);
  }
</script>

<!-- slots in a component's shadow DOM -->
<trail-card>
  <h2 slot="title">Ridge Loop</h2>
  <p>12 km, hard.</p>            <!-- default slot -->
</trail-card>

<template id="trail-card-tpl">
  <article>
    <header><slot name="title">Untitled</slot></header>
    <slot></slot>
  </article>
</template>

⚠ Common Mistakes

  • Appending template.content itself: the fragment is emptied after the first insert; clone it
  • Building rows with innerHTML string concatenation: risks XSS; clone a template and set textContent
  • Using <slot> in normal page HTML: it does nothing outside a shadow root

✓ Tips & Best Practices

  • Keep repeated markup in a <template> near the code that uses it
  • Give slots fallback content for optional parts
  • Listen for slotchange to react when children change

Quick Summary

  • <template>: inert, reusable markup
  • content.cloneNode(true): stamp out copies
  • <slot>: insertion point in shadow DOM
  • slot="name": target a named slot
