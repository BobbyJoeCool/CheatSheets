Multi-Line Text, Suggestions and Results

<textarea> collects multi-line text: rows and cols set its default size, and the text between its tags is the initial value. <datalist> attaches suggestions to an input through the list attribute; users can pick one or type anything. <output> shows the result of a calculation, <progress> shows how far a task has got, and <meter> shows a measurement within a known range.

Notes

  • <textarea> has no value attribute; put default text between the tags
  • wrap="hard" inserts line breaks on submit (needs cols)
  • <output for="a b"> lists the ids of the inputs it depends on
  • <progress> without value shows an indeterminate (busy) state

♿ Accessibility

  • <output> has the status role, so screen readers announce its new value
  • <progress> and <meter> need a label like any control
  • Datalist suggestions are announced inconsistently; don't hide required options in them

Pairing with CSS

  • textarea { resize: vertical; }; field-sizing: content grows with the text (newer, Chromium)
  • ::-webkit-meter-optimum-value / :-moz-meter-optimum: meter colors
  • progress { accent-color: … }, or appearance: none for a custom bar

Code Explained

text between the tags: the initial value; whitespace is kept
list="parks": matches the datalist's id
oninput on the form: runs on any field change
<output>: shows a result but isn't submitted
low / high / optimum: meter color shifts as the value worsens

Textarea, Suggestions and Results

<label for="msg">Trip notes</label>
<textarea id="msg" name="msg" rows="4" cols="40"
          maxlength="500">Leave by 7 am.</textarea>

<!-- suggestions -->
<label for="park">Park</label>
<input id="park" name="park" list="parks">
<datalist id="parks">
  <option value="Yosemite"></option>
  <option value="Zion"></option>
  <option value="Acadia"></option>
</datalist>

<!-- live result -->
<form oninput="total.value = nights.valueAsNumber * 40">
  <label for="nights">Nights</label>
  <input id="nights" name="nights" type="number"
         min="1" value="1">
  Cost: $<output name="total" for="nights">40</output>
</form>

<!-- task progress -->
<label for="up">Uploading:</label>
<progress id="up" max="100" value="70">70%</progress>

<!-- measurement in a known range -->
<label for="pack">Pack weight</label>
<meter id="pack" min="0" max="20" low="8" high="14"
       optimum="5" value="11">11 kg</meter>

⚠ Common Mistakes

  • Putting default text in a value attribute on <textarea>: it's ignored
  • Using <meter> for loading progress; that's <progress>
  • Relying on a datalist to restrict input: users can type anything, so validate it

✓ Tips & Best Practices

  • Use field-sizing: content (where supported) for auto-growing textareas
  • Show the characters remaining for maxlength fields
  • Put the value as text inside <progress> and <meter>: 70%

Quick Summary

  • <textarea>: multi-line input
  • <datalist> + list: suggestions
  • <output>: live calculated result
  • <progress> / <meter>: completion / measurement
