Comments & Whitespace

<!-- --> · comment rules · -- pitfall · whitespace collapsing · inter-element whitespace · &nbsp; vs CSS spacing

The Invisible Parts of the Source

HTML comments <!-- … --> stay in the DOM but never render. Whitespace (spaces, tabs, newlines) is collapsed: any run becomes a single space, and spaces at the start and end of a line disappear. That's why extra spaces and line breaks in your source don't show up, and why inline-block elements get small gaps between them.

Notes

  • Comments can't be nested: the first --> ends the comment
  • -- inside a comment is allowed in HTML but invalid in XML; avoid it
  • Comments show in View Source and DevTools; never put secrets in them
  • <pre> and <textarea> keep whitespace exactly

♿ Accessibility

  • Screen readers ignore comments; they're for developers only
  • Don't build layout from runs of &nbsp;: some screen readers pause or announce them
  • Spaced-out text (S P A C E D) is read letter by letter; use CSS letter-spacing

Pairing with CSS

  • white-space: pre-wrap: keep spaces and newlines but still wrap
  • white-space: nowrap / pre: no wrapping / keep everything
  • display: flex + gap: removes inline-block whitespace gaps

Code Explained

-->: always closes the comment, nested or not
collapsing: any run of whitespace becomes one space
<pre>: preformatted, so whitespace and line breaks are kept
&nbsp;: a space that never breaks onto a new line
inline-block gap: the newline between tags renders as a space

⚠ Common Mistakes

  • Wrapping a block that already contains comments in another comment: the inner --> ends it early
  • Using spaces or &nbsp;&nbsp; for alignment; use CSS margin, padding or gap
  • Leaving notes or old code in comments: anyone can read View Source

✓ Tips & Best Practices

  • Toggle comments with Ctrl+/ (Cmd+/) in most editors
  • Mark the end of long blocks: <!-- /.card -->
  • Use white-space: pre-line for user text where newlines matter

Quick Summary

  • <!-- … -->: comment, not nestable
  • whitespace: runs collapse to one space
  • <pre>: keeps whitespace
  • &nbsp;: non-breaking space
