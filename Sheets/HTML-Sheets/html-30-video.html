Video

video · source · controls · autoplay · muted · loop · poster · playsinline

The video Element

<video> plays video natively, with no plugin. Add controls for the browser's player UI, list several <source> files so each browser can pick a format it supports, and set a poster image to show before playback. Browsers only allow autoplay when the video is muted, and iPhones need playsinline to play without going fullscreen.

Notes

  • preload: none, metadata, auto
  • MP4 (H.264) plays everywhere; WebM and AV1 save bandwidth
  • Text between the tags is a fallback for old browsers, not a caption
  • Set width / height (or CSS aspect-ratio) to avoid layout shift

♿ Accessibility

  • Provide captions with <track kind="captions"> (sheet 31; WCAG 1.2.2)
  • Never autoplay with sound; anything moving for over 5 seconds needs a pause control
  • Native controls work with the keyboard; custom players must too

Pairing with CSS

  • video { width: 100%; height: auto; }: responsive video
  • object-fit: cover: fill a hero box without letterboxing
  • @media (prefers-reduced-motion: reduce): hide or pause background video

Code Explained

<source> order: the first playable type wins
poster: shown until playback starts
preload="metadata": fetch only duration and size
muted + playsinline: required for autoplay on phones
codecs: lets browsers skip files they can't decode

Video Playback

<!-- standard player -->
<video controls width="960" height="540"
       poster="/media/trail-poster.jpg"
       preload="metadata">
  <source src="/media/trail.webm" type="video/webm">
  <source src="/media/trail.mp4" type="video/mp4">
  <track kind="captions" src="/media/trail.en.vtt"
         srclang="en" label="English" default>
  <p>Your browser can't play this video.
     <a href="/media/trail.mp4">Download it</a>.</p>
</video>

<!-- silent background loop (hero) -->
<video autoplay muted loop playsinline
       poster="/media/clouds.jpg" aria-hidden="true">
  <source src="/media/clouds.mp4" type="video/mp4">
</video>

<!-- codecs help the browser choose -->
<source src="trail-av1.mp4"
        type='video/mp4; codecs="av01.0.05M.08"'>

<script>
  const v = document.querySelector('video');
  v.play();          // returns a Promise
  v.pause();
  v.currentTime = 30;
</script>

⚠ Common Mistakes

  • Autoplay without muted: browsers block it and nothing plays
  • Background video with no way to pause: distracting, and fails WCAG 2.2.2
  • One huge MP4 for every device: offer smaller encodes or adaptive streaming (HLS/DASH)

✓ Tips & Best Practices

  • Always include a poster and preload="metadata"
  • Add aria-hidden="true" to purely decorative background video
  • Use a player library with HLS/DASH for long or high-bitrate video

Quick Summary

  • <video controls>: native player
  • <source type>: format fallbacks
  • muted autoplay playsinline: silent autoplay
  • poster / preload: performance
