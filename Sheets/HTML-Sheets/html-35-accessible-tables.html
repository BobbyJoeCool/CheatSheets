Headers, Associations and Responsive Tables

Screen readers announce the matching headers as users move through cells, but only if the table says which headers apply. For simple tables, <th> with scope="col" or "row" is enough. For irregular tables (multi-level headers, merged cells), give each <th> an id and list the relevant ids in each cell's headers attribute. Wide tables also need a scroll container to work on phones.

Notes

  • scope values: col, row, colgroup, rowgroup
  • headers takes a space-separated list of <th> ids
  • The summary attribute is obsolete; use <caption> or nearby text
  • A scroll wrapper needs tabindex="0", a role and a name

♿ Accessibility

  • Test with screen-reader table commands (NVDA/JAWS: Ctrl+Alt+Arrows)
  • display: block / grid on table elements can strip table semantics in some browsers
  • Keep header text short; it's repeated for every cell

Pairing with CSS

  • .table-wrap { overflow-x: auto; }: horizontal scroll for wide tables
  • thead th { position: sticky; top: 0; }: headers stay visible while scrolling
  • Stacked "card" tables at small widths need ARIA table roles restored

Code Explained

role="region" + name: announced as "Permit fees, region"
tabindex="0": keyboard users can focus and scroll it
headers="adult res day": read as Adults, Resident, Day pass, $10
scope="rowgroup": Adults heads the rows beneath it
corner <td>: an empty cell, not a header

headers, ids and a Scroll Wrapper

<div class="table-wrap" role="region"
     aria-labelledby="cap-fees" tabindex="0">
  <table>
    <caption id="cap-fees">Permit fees (USD)</caption>
    <thead>
      <tr>
        <td></td>
        <th id="day" scope="col">Day pass</th>
        <th id="year" scope="col">Annual</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th id="adult" colspan="3"
            scope="rowgroup">Adults</th>
      </tr>
      <tr>
        <th id="res" headers="adult">Resident</th>
        <td headers="adult res day">$10</td>
        <td headers="adult res year">$60</td>
      </tr>
      <tr>
        <th id="vis" headers="adult">Visitor</th>
        <td headers="adult vis day">$15</td>
        <td headers="adult vis year">$90</td>
      </tr>
    </tbody>
  </table>
</div>

⚠ Common Mistakes

  • Putting scope on <td>: it only works on <th>
  • Restyling tables with display: grid or block without testing a screen reader: semantics may vanish
  • Wide tables that overflow the viewport: phone users can't reach the right-hand columns

✓ Tips & Best Practices

  • Start with scope; add headers only for complex tables
  • Wrap every wide table in a focusable, labeled scroll region
  • Re-add table roles with ARIA when CSS changes display

Quick Summary

  • scope: simple header association
  • id + headers: complex tables
  • scroll wrapper: role="region" + tabindex="0"
  • <caption>: always
