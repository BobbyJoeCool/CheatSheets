Sheet 23

Description Lists & Menus

dl · dt · dd · div grouping in dl · menu · nav list pattern

Name–Value Groups

A description list <dl> holds name–value groups: each <dt> is a term or name, followed by one or more <dd> descriptions. It fits glossaries, metadata (Author: …, Published: …), FAQs and spec sheets. Each group may be wrapped in a <div> for styling. <menu> is a semantic alternative to <ul> for a toolbar of commands.

Notes

  • One <dt> can have several <dd>s; several <dt>s can share one <dd>
  • <div> is the only wrapper allowed directly inside <dl>
  • <menu> renders and behaves like <ul> (it holds <li> items)
  • HTML 4 called <dl> a "definition list"; it's now a "description list"

♿ Accessibility

  • Screen-reader support for <dl> varies; some announce "term" and "definition", others just a list
  • Keep each <dt> short so the pair reads naturally
  • Don't use <dl> just for indentation; its structure is announced

Pairing with CSS

  • dd { margin-left: 40px; }: the UA default indent
  • dl { display: grid; grid-template-columns: max-content 1fr; }: two-column key/value layout
  • dl > div: style each group, e.g. borders between rows

Code Explained

<dt> + <dd>: one name–value group
<div> wrapper: lets CSS grid treat a group as one row
two <dd>s: one name with several values
<menu>: a list of commands (implicit role list)

Description Lists

<!-- glossary -->
<dl>
  <dt>Switchback</dt>
  <dd>A trail that zig-zags up a steep slope.</dd>

  <dt>Cairn</dt>
  <dd>A pile of stones marking the route.</dd>
</dl>

<!-- product specs with div groups -->
<dl class="specs">
  <div>
    <dt>Weight</dt>
    <dd>340 g</dd>
  </div>
  <div>
    <dt>Drop</dt>
    <dd>6 mm</dd>
  </div>
  <div>
    <dt>Colors</dt>
    <dd>Moss</dd>
    <dd>Slate</dd>
  </div>
</dl>

<!-- toolbar of commands -->
<menu aria-label="Text formatting">
  <li><button type="button">Bold</button></li>
  <li><button type="button">Italic</button></li>
</menu>

⚠ Common Mistakes

  • Using <dl> just to indent text; use CSS margin
  • Putting <p> or <span> directly in <dl>: only <dt>, <dd>, <div>, <script> and <template> are allowed
  • Adding role="menu" to site navigation: screen readers expect app-style arrow-key behavior

✓ Tips & Best Practices

  • Lay out specs with display: grid on the <dl>
  • Use <details> for collapsible FAQs (sheet 44)
  • Use <menu> for toolbars; keep <nav><ul> for site navigation

Quick Summary

  • <dl>: description list
  • <dt> / <dd>: name / value
  • <div>: group wrapper inside <dl>
  • <menu>: toolbar list
