Sheet 17

Paragraphs & Breaks

p · br · hr · wbr · pre · line-break misuse

Blocks of Text

<p> marks a paragraph, the basic block of prose. <br> is a line break that belongs to the content itself (addresses, poems). <hr> is a thematic break between topics, drawn as a rule. <wbr> marks an optional break point in long words or URLs, and <pre> holds preformatted text where spacing matters.

Notes

  • Don't use empty <p>s or stacked <br>s for spacing; use CSS margins
  • <hr> means a topic shift; for decoration use a CSS border
  • <wbr> adds no hyphen; &shy; shows one if the word breaks
  • The parser ignores a newline right after <pre>

♿ Accessibility

  • <hr> is announced as a separator; use it only for real topic changes
  • Empty paragraphs and stacked <br>s can be announced as "blank"
  • Readable line length (max-width: 70ch) helps readers with dyslexia and low vision

Pairing with CSS

  • p + p { margin-top: 1em; }: space paragraphs instead of <br><br>
  • hr { border: 0; border-top: 1px solid #ccc; }: restyle the rule
  • text-wrap: pretty / balance: fewer orphans, neater headings

Code Explained

newlines inside <p>: collapse to one space
<br>: the address format needs the line breaks
<hr>: default is an inset 1px border; restyle with CSS
<wbr>: wraps only if needed, without a hyphen
<pre>: monospace; the first newline after it is dropped

Text Blocks

<p>Our store opens at 9 am. Orders placed before noon
   ship the same day.</p>

<p>Returns are free within 30 days.</p>

<!-- <br>: line breaks that are part of the content -->
<address>
  Trailhead Outfitters<br>
  120 Pine Street<br>
  Boulder, CO 80302
</address>

<!-- <hr>: change of topic -->
<p>That covers shipping.</p>
<hr>
<p>Now, sizing.</p>

<!-- <wbr>: allowed break points -->
<p>docs.example.com/<wbr>api/<wbr>v2/<wbr>orders</p>

<!-- <pre>: whitespace kept -->
<pre>
Size  US   EU
S     7    40
M     9    42
</pre>

⚠ Common Mistakes

  • Separating paragraphs with <br><br>: use two <p> elements
  • Using <hr> as decoration between every block: it's announced every time
  • Lining up a table with spaces in <pre>: use a real <table> for tabular data

✓ Tips & Best Practices

  • Limit line length to ~60–75 characters with max-width: 65ch
  • Add <wbr> after slashes in long URLs shown as text
  • Use text-wrap: balance on headings and pretty on paragraphs

Quick Summary

  • <p>: paragraph
  • <br>: meaningful line break
  • <hr>: thematic break
  • <wbr> / <pre>: break hint, preformatted
