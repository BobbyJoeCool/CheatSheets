Details & Summary

details · summary · open · name (exclusive accordion) · toggle event · ::marker

Native Disclosure Widgets

<details> creates a disclosure widget: content stays hidden until the user opens it by clicking the <summary>. It needs no JavaScript, works with the keyboard and is announced correctly by screen readers. The open attribute shows or sets the state, the toggle event fires on each change, and giving several <details> the same name makes an exclusive accordion where only one can be open.

Notes

  • <summary> must be the first child; without one the browser shows "Details"
  • open is a boolean attribute: present = expanded
  • Same name on several <details> = only one open at a time (2024+)
  • The toggle event fires after the state changes

♿ Accessibility

  • <summary> is announced as a button with its expanded/collapsed state
  • Don't put links or buttons inside <summary>
  • Keep summary text descriptive: "Shipping policy", not "More"

Pairing with CSS

  • details[open] > summary: style the open state
  • summary { list-style: none; } + summary::marker: change or hide the triangle
  • ::details-content: style or animate the hidden part (newer; check support)

Code Explained

<summary>: the clickable, focusable label
open: present when expanded; set from JS with d.open = true
name="faq": opening one closes the others
toggle: e.oldState / e.newState are "open" or "closed"

Disclosure and Accordion

<!-- single disclosure -->
<details>
  <summary>Shipping policy</summary>
  <p>Orders ship within 2 business days.</p>
</details>

<!-- open by default -->
<details open>
  <summary>What's included</summary>
  <ul>
    <li>Tent body and fly</li>
    <li>Stakes and guylines</li>
  </ul>
</details>

<!-- exclusive accordion -->
<details name="faq">
  <summary>Can I return worn boots?</summary>
  <p>Yes, within 30 days if unwashed.</p>
</details>
<details name="faq">
  <summary>Do you ship to Canada?</summary>
  <p>Yes, duties included.</p>
</details>

<script>
  for (const d of document.querySelectorAll('details')) {
    d.addEventListener('toggle', (e) => {
      console.log(d.open, e.newState);  // true "open"
    });
  }
</script>

⚠ Common Mistakes

  • Putting links or buttons inside <summary>: nested interactive content breaks clicks and keys
  • Hiding the marker with display: block alone: older Safari still shows ::-webkit-details-marker
  • Building accordions from <div>s and JS: more code and usually worse accessibility

✓ Tips & Best Practices

  • Use name for FAQ accordions instead of JavaScript
  • Add a custom icon with summary::after and rotate it on [open]
  • Open the right section from a URL hash with details.open = true

Quick Summary

  • <details> + <summary>: disclosure
  • open: expanded state
  • name: exclusive accordion
  • toggle: state-change event
