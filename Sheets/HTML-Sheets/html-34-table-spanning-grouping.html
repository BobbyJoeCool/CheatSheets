Spanning & Column Groups

colspan · rowspan · colgroup · col · span · irregular grids

Merged Cells and Columns

colspan makes a cell span several columns and rowspan several rows, which is useful for grouped headers and merged values. When a cell spans, remove the cells it covers, or the row gets too many columns. <colgroup> and <col> describe columns, so you can style a whole column (background, width, border) without a class on every cell.

Notes

  • rowspan="0" spans to the end of the row group
  • <colgroup span="2"> or <col span="2"> covers two columns
  • <colgroup> goes after <caption> and before <thead>
  • Only background, border, width and visibility apply to columns

♿ Accessibility

  • Headers over spanned groups need scope="colgroup" / "rowgroup" or headers (sheet 35)
  • Heavily merged tables are hard to navigate by ear; split them when you can
  • Don't merge cells just for visual layout

Pairing with CSS

  • colgroup.summer { background: #fff8e1; }: tint a whole column group
  • col { width: 30%; } with table-layout: fixed: reliable column widths
  • td:nth-child(3): for properties columns ignore, like text-align

Code Explained

<colgroup span="2">: one group per season, styled by class
rowspan="2": the empty corner cell covers both header rows
colspan="2" + scope="colgroup": Summer heads Jun and Jul
colspan="2" in the body: Closed replaces two cells
every row adds up to 5 columns

Grouped Headers

<table>
  <caption>Hut bookings by season</caption>
  <colgroup></colgroup>                  <!-- hut names -->
  <colgroup span="2" class="summer"></colgroup>
  <colgroup span="2" class="winter"></colgroup>
  <thead>
    <tr>
      <td rowspan="2"></td>
      <th colspan="2" scope="colgroup">Summer</th>
      <th colspan="2" scope="colgroup">Winter</th>
    </tr>
    <tr>
      <th scope="col">Jun</th>
      <th scope="col">Jul</th>
      <th scope="col">Dec</th>
      <th scope="col">Jan</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Alpine Hut</th>
      <td>42</td><td>58</td>
      <td colspan="2">Closed</td>
    </tr>
    <tr>
      <th scope="row">Lake Hut</th>
      <td>30</td><td>35</td><td>12</td><td>9</td>
    </tr>
  </tbody>
</table>

⚠ Common Mistakes

  • Forgetting to remove covered cells: the table grows an extra, jagged column
  • Centering a column with col { text-align: center }: ignored; target the cells with nth-child
  • Using colspan to fake layout, like full-width banner rows in data tables

✓ Tips & Best Practices

  • Count the columns in every row after adding a span
  • Use table-layout: fixed with <col> widths for predictable sizing
  • Prefer two simple tables over one heavily merged table

Quick Summary

  • colspan / rowspan: merge cells
  • <colgroup> / <col>: column styling
  • span: cover several columns
  • remove the covered cells
