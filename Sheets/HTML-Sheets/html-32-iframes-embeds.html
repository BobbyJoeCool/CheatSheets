Iframes & Embeds

iframe · sandbox · allow · srcdoc · loading · referrerpolicy · embed · object

Embedding Other Pages

<iframe> embeds another HTML page inside yours: maps, videos, payment forms, code demos. Because embedded content may be untrusted, iframes have security controls: **sandbox blocks scripts, forms and navigation unless you allow them, allow** grants features like fullscreen or the camera, and referrerpolicy limits what's sent. <embed> and <object> are older ways to embed plugins and PDFs.

Notes

  • Sites can refuse framing with X-Frame-Options or CSP frame-ancestors
  • sandbox with no value applies every restriction
  • srcdoc sets inline HTML instead of a URL
  • loading="lazy" defers off-screen iframes

♿ Accessibility

  • Every iframe needs a title describing its content; it's the frame's accessible name
  • Focus moves into iframes, so the embedded page must be accessible too
  • Avoid embeds that autoplay sound or trap keyboard focus

Pairing with CSS

  • iframe { border: 0; width: 100%; aspect-ratio: 16 / 9; }: responsive video embed
  • Your CSS doesn't reach inside the iframe; style the embedded page itself
  • Set color-scheme on both pages so light/dark themes match

Code Explained

title: announced when focus enters the frame
allow: Permissions Policy for the frame
sandbox="allow-scripts": scripts run, but in a unique origin
srcdoc: inline HTML; it wins over src
<object>: has fallback content; <embed> doesn't

Embedding Safely

<!-- video embed (privacy-enhanced domain) -->
<iframe src="https://www.youtube-nocookie.com/embed/ID"
        title="Trail safety basics (video)"
        width="560" height="315" loading="lazy"
        allow="fullscreen; picture-in-picture"
        referrerpolicy="strict-origin-when-cross-origin">
</iframe>

<!-- map -->
<iframe src="https://maps.example.com/embed?trail=ridge"
        title="Ridge Loop trailhead map"
        width="600" height="400" loading="lazy"></iframe>

<!-- untrusted user code: sandboxed -->
<iframe sandbox="allow-scripts"
        srcdoc="<p>Hello from the sandbox</p>"
        title="Code preview"></iframe>

<!-- PDF -->
<embed src="/docs/permit.pdf" type="application/pdf"
       width="600" height="800">

<object data="/docs/permit.pdf" type="application/pdf"
        width="600" height="800">
  <a href="/docs/permit.pdf">Download the permit (PDF)</a>
</object>

⚠ Common Mistakes

  • Combining allow-scripts and allow-same-origin for same-origin content: the frame can remove its own sandbox
  • Iframes without title: screen readers just say "frame"
  • Fixed width="560" with no responsive CSS: the embed overflows on phones

✓ Tips & Best Practices

  • Lazy-load embeds below the fold, or use click-to-load placeholders for heavy players
  • Grant only the allow features the embed needs
  • On mobile, a plain link to a PDF beats <embed>

Quick Summary

  • <iframe src title>: embed a page
  • sandbox: restrict untrusted content
  • allow: grant features
  • <object> / <embed>: legacy embeds, PDFs
