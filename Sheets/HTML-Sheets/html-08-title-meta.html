Sheet 08

Title & Meta Tags

title · meta charset · viewport · description · robots · theme-color · color-scheme · http-equiv

Describing the Page

<head> metadata never appears on the page, but it controls how the page is encoded, scaled, named and indexed. <title> is required. The charset and viewport meta tags belong on every page; description, robots and theme-color tune search results and browser UI. Each <meta> uses charset, name + content, or http-equiv + content.

Notes

  • Search engines show <title> and often description in results
  • Keep titles ~50–60 characters: page first, site name last
  • http-equiv imitates an HTTP header; real headers are better
  • Major search engines ignore the keywords meta tag

♿ Accessibility

  • Never set user-scalable=no or maximum-scale=1; it blocks zoom for low-vision users
  • Update document.title when a single-page app changes view
  • The title is announced first on page load, so make it describe the page

Pairing with CSS

  • <meta name="color-scheme">: themes form controls and scrollbars; pair with color-scheme: light dark
  • theme-color with media: match your @media (prefers-color-scheme: dark) palette
  • width=device-width: makes @media (max-width: …) use the real device width

Code Explained

initial-scale=1: 1 CSS px = 1 device-independent px on load
robots: noindex, nofollow, noarchive, nosnippet
theme-color: tints the address bar in mobile browsers
color-scheme: default form controls follow light or dark
refresh: redirects after 5 s; prefer a server 301

A Complete Meta Set

<head>
  <meta charset="utf-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1">
  <title>Hiking Boots · Trailhead Outfitters</title>

  <meta name="description"
        content="Waterproof hiking boots, sizes 5–15.">
  <meta name="robots" content="index, follow">
  <meta name="author" content="Trailhead Web Team">

  <!-- browser UI color per theme -->
  <meta name="theme-color" content="#1b5e20"
        media="(prefers-color-scheme: light)">
  <meta name="theme-color" content="#0d1f0e"
        media="(prefers-color-scheme: dark)">
  <meta name="color-scheme" content="light dark">

  <!-- pragma directives -->
  <meta http-equiv="Content-Security-Policy"
        content="default-src 'self'">
  <meta http-equiv="refresh"
        content="5; url=/new-page">
</head>

⚠ Common Mistakes

  • Disabling zoom with user-scalable=no: it fails WCAG 1.4.4 Resize Text
  • The same <title> on every page: tabs, bookmarks and search results look identical
  • Redirecting with <meta http-equiv="refresh">: slow, confusing for screen readers, weaker for SEO than a 301

✓ Tips & Best Practices

  • Order: charset, then viewport, then <title>
  • Write descriptions as a sentence people would click (~150 characters)
  • Use noindex on staging sites, internal search results and thank-you pages

Quick Summary

  • <meta charset="utf-8">: encoding
  • viewport: responsive scaling
  • <title>: tab and search title
  • description / robots: search control
