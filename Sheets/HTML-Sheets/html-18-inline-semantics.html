Sheet 18

Inline Text Semantics

strong · em · b · i · u · s · mark · small

Emphasis and Stylistic Offsets

These elements mark why text is different, not just how it looks. <strong> means importance and <em> means stress emphasis that changes a sentence's meaning. HTML5 gave <b>, <i>, <u> and <s> their own meanings: attention, alternate voice, annotation and no-longer-accurate. <mark> highlights relevance and <small> holds side comments and fine print.

Notes

  • Nest <strong> to raise importance further
  • <i> suits technical terms, foreign phrases, ship names, thoughts
  • <s> = no longer accurate; <del> = a document edit (sheet 20)
  • <u> looks like a link; style it differently or avoid it

♿ Accessibility

  • Most screen readers don't change voice for <em>/<strong> by default, so don't rely on them alone for warnings
  • <mark> usually isn't announced; add hidden text if the highlight matters
  • <s> usually isn't announced; say "was $149" in the text as well

Pairing with CSS

  • strong, b { font-weight: bold }; em, i { font-style: italic }: UA defaults
  • mark { background: yellow; }: override with your theme color
  • small { font-size: smaller; }: relative to the parent

Code Explained

<strong>: the content is serious or urgent
<em>: moving it changes what the sentence means
<i lang>: also sets pronunciation for the term
<b>: product names, lead words, keywords
<s>: the old price shown beside the new one

Choosing the Right Element

<!-- importance -->
<p><strong>Warning:</strong> the trail closes at dusk.</p>

<!-- stress emphasis changes the meaning -->
<p>I <em>said</em> bring water.</p>
<p>I said bring <em>water</em>.</p>

<!-- alternate voice: terms, foreign words -->
<p>The <i lang="la">Ursus arctos</i> is a brown bear.</p>

<!-- draws attention, no extra importance -->
<p><b>Trail Runner 3</b> is back in stock.</p>

<!-- relevance, e.g. a search match -->
<p>Results for <mark>waterproof</mark> boots</p>

<!-- no longer accurate -->
<p>Price: <s>$149</s> $129</p>

<!-- non-textual annotation: misspelling -->
<p>This word is <u class="spell">mispeled</u>.</p>

<!-- side comment / fine print -->
<p><small>Prices include sales tax.</small></p>

Pick One

If the text is…Use
a warning<strong>
spoken with stress<em>
a technical term<i> or <dfn>
a product name in a review<b>
a search hit<mark>
an outdated price<s>

⚠ Common Mistakes

  • Using <b>/<i> only for bold or italic looks: use CSS, or the element that matches the meaning
  • Underlining non-links with <u>: users try to click it
  • Using <small> to shrink headings or whole paragraphs: it means fine print

✓ Tips & Best Practices

  • Ask "is it more important, stressed or just different?" before choosing
  • Add lang to <i> around foreign phrases
  • Use <mark> to highlight search terms in results

Quick Summary

  • <strong> / <em>: importance / stress
  • <b> / <i>: attention / alternate voice
  • <mark>: relevance highlight
  • <s> / <small>: outdated / fine print
