Checking and Polishing Markup

Browsers forgive almost any markup, so errors hide until something breaks: a label that doesn't connect, a duplicate id, a table that reads wrong. Validators and linters catch these early. The W3C Nu HTML Checker tests against the spec, html-validate and editor extensions lint as you type, and axe and Lighthouse audit accessibility and performance. Pair the tools with a few habits.

Notes

  • Valid HTML isn't automatically accessible, but invalid HTML often isn't
  • Validators flag obsolete elements like <center>, <font> and <marquee>
  • Prettier formats HTML; it doesn't validate it
  • Emmet expands abbreviations: ul>li*3 → a list with three items

♿ Accessibility

  • Run axe DevTools or Lighthouse's accessibility audit on every page template
  • Duplicate ids and missing labels are the validator findings that hurt accessibility most
  • WebAIM's yearly Million report: low contrast, missing alt and missing labels top the list

Pairing with CSS

  • Check CSS separately with the W3C CSS Validator or Stylelint
  • Move inline style="" attributes into classes; they're easier to override and audit
  • Replace presentational attributes (align, bgcolor, border) with CSS

Code Explained

<center>, <font>: obsolete; use CSS
missing alt: a validator error
duplicate id: breaks labels and fragment links
placeholder-only field: no accessible name
href="#" + onclick: should be a button

⚠ Common Mistakes

  • Treating "it renders" as "it's correct": browsers silently repair broken markup
  • Validating once at launch: templates and CMS content drift over time
  • Fixing every validator message blindly: some, like trailing-slash notes, are style info, not bugs

✓ Tips & Best Practices

  • Add html-validate or axe-core to CI so regressions fail the build
  • Use the Nu checker's outline option to review headings
  • Format on save with Prettier to keep diffs clean

Quick Summary

  • linter / axe: rules and a11y in CI
  • obsolete tags: replace with CSS
  • habits: alt, labels, headings, lang
