Unordered & Ordered Lists

ul · ol · li · start · reversed · type · value · nested lists

ul, ol and li

Use <ul> when order doesn't matter (features, links) and <ol> when it does (steps, rankings). Both may contain only <li> items. <ol> has attributes that control numbering: start, reversed and type, plus value on an individual <li>. Lists nest by placing a whole new list inside an <li>.

Notes

  • Nested lists go inside an <li>, not directly in the <ul>
  • type on <ol>: 1, a, A, i, I
  • reversed counts down; start sets the first number
  • <li value="10"> renumbers from that item on

♿ Accessibility

  • Screen readers announce "list, 5 items", so users know the length up front
  • list-style: none removes list semantics in Safari/VoiceOver; add role="list"
  • Use real lists for navigation menus so item counts are announced

Pairing with CSS

  • list-style: square inside: marker type and position
  • li::marker { color: tomato; }: style bullets and numbers
  • counter-reset / counter(): custom numbering like "Step 1:"

Code Explained

<ul>: default bullets disc, then circle and square when nested
start="4": an HTML attribute, works without CSS
reversed: counts down from the number of items
value: resets numbering from that item onward
nested <ul>: belongs to the Footwear item

Lists and Numbering

<!-- unordered: order doesn't matter -->
<ul>
  <li>Waterproof leather</li>
  <li>Vibram sole</li>
  <li>Sizes 5–15</li>
</ul>

<!-- ordered: steps -->
<ol>
  <li>Loosen the laces</li>
  <li>Slide your foot in</li>
  <li>Tighten from the toe up</li>
</ol>

<!-- numbering control -->
<ol start="4">…</ol>        <!-- 4, 5, 6 -->
<ol reversed>…</ol>         <!-- 3, 2, 1 -->
<ol type="A">…</ol>         <!-- A, B, C -->
<ol type="i">…</ol>         <!-- i, ii, iii -->
<ol>
  <li>First</li>
  <li value="10">Tenth</li>  <!-- 10 -->
  <li>Eleventh</li>          <!-- 11 -->
</ol>

<!-- nesting: inside the <li> -->
<ul>
  <li>Footwear
    <ul>
      <li>Boots</li>
      <li>Trail runners</li>
    </ul>
  </li>
</ul>

⚠ Common Mistakes

  • Putting a nested <ul> directly inside another <ul>: invalid; nest it inside an <li>
  • Typing numbers into <li> text: they double up with the markers and go stale on reorder
  • Using a list for data with several attributes per item; that's a table

✓ Tips & Best Practices

  • Use <ol> for anything a user follows in order: steps, rankings, timelines
  • Restyle markers with ::marker instead of background images
  • Add role="list" when you remove bullets with CSS

Quick Summary

  • <ul>: unordered items
  • <ol>: ordered steps
  • start / reversed / type: numbering
  • nest inside <li>
