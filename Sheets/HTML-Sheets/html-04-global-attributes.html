Sheet 04

Global Attributes

title · hidden · tabindex · contenteditable · draggable · spellcheck · inert · autocapitalize

Attributes Every Element Accepts

Global attributes work on any element. id, class, data-* (sheet 05) and lang / dir (sheet 21) are the familiar ones. This sheet covers the rest: tooltips, visibility, focus, editing and dragging. Some of them, like hidden and inert, change behavior and accessibility, not just appearance.

Notes

  • hidden removes the element from rendering and from the accessibility tree
  • hidden="until-found" keeps content findable with Ctrl+F (newer; check support)
  • inert makes an element and its subtree unfocusable and unclickable
  • autofocus focuses an element on page load or when a <dialog> opens

♿ Accessibility

  • title tooltips are unreliable: no keyboard or touch access, uneven screen reader support
  • Use tabindex="0" only for custom widgets; never positive values (sheet 50)
  • inert suits content behind a modal: screen readers and Tab both skip it

Pairing with CSS

  • [hidden]: UA style is display: none; your display rule beats it, so add [hidden] { display: none !important }
  • [contenteditable]:focus / :read-write: style editable regions
  • [inert]: no visual change by default; add opacity to show it's unavailable

Code Explained

hidden: toggle from JS with el.hidden = true / false
tabindex="-1": lets el.focus() move focus to a heading after an update
contenteditable: true, false or plaintext-only (no pasted formatting)
draggable: still needs dragstart / drop handlers in JS
autocapitalize: off, sentences, words, characters

Global Attributes in Use

<!-- tooltip text (mouse hover only) -->
<abbr title="Cascading Style Sheets">CSS</abbr>

<!-- hidden: not rendered, not announced -->
<p id="error" hidden>Card number is invalid.</p>

<!-- inert: whole region unfocusable -->
<main inert>…page behind an open drawer…</main>

<!-- tabindex: 0 = in Tab order, -1 = script only -->
<div role="button" tabindex="0">Custom button</div>
<h2 id="results" tabindex="-1">Results</h2>

<!-- editable content -->
<div contenteditable="plaintext-only">Edit me</div>
<p contenteditable spellcheck="false">ID: X1-99</p>

<!-- drag and drop source -->
<li draggable="true">Pack the tent</li>

<!-- virtual keyboard capitalization -->
<input name="city" autocapitalize="words">

<!-- focus on page load -->
<input type="search" name="q" autofocus>

<script>
  document.getElementById('error').hidden = false;
</script>

⚠ Common Mistakes

  • Giving a hidden element display: flex in CSS: your rule wins and the element shows
  • Putting essential info only in title: keyboard and touch users never see it
  • Using tabindex="1" or higher: it reorders tabbing for the whole page

✓ Tips & Best Practices

  • Toggle hidden from JS instead of adding and removing a .hide class
  • Put inert on everything outside a custom modal or drawer
  • Use plaintext-only when pasted formatting would cause trouble

Quick Summary

  • hidden: removed from page and a11y tree
  • inert: visible but unusable
  • tabindex: 0 focusable, -1 script-only
  • contenteditable: user-editable content
