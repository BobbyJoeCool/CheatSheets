Popovers Without JavaScript

The popover attribute turns any element into a popover: hidden by default and shown in the top layer when triggered. A button with popovertarget="id" toggles it with no script. **auto popovers (the default) light-dismiss: they close on Esc or an outside click, and opening one closes the others. manual** popovers stay open until closed. Use them for menus, pickers and toasts.

Notes

  • popovertargetaction: toggle (default), show or hide
  • JS methods: showPopover(), hidePopover(), togglePopover()
  • Popovers aren't modal: the page stays usable (use <dialog> for modals)
  • popover="hint" is a newer type for hover hints (Chromium)

♿ Accessibility

  • Invoker buttons get aria-expanded and a link to the popover automatically
  • Focus doesn't move into the popover; add autofocus inside if it should
  • Light dismiss (Esc) is built in; keep it for auto popovers

Pairing with CSS

  • :popover-open: style the shown state
  • UA default is position: fixed; inset: 0; margin: auto; override it to place the popover
  • position-anchor / anchor(): pin it to its button (CSS anchor positioning, newer)

Code Explained

popovertarget: only works on <button> and button-type inputs
popover alone = popover="auto"
popover="manual": no light dismiss; several can stay open
role="status": the toast text is announced
beforetoggle / toggle: events before and after a change

Popover Menu and Toast

<!-- auto popover: light dismiss -->
<button popovertarget="acct-menu">Account ▾</button>
<div id="acct-menu" popover>
  <ul>
    <li><a href="/orders">Orders</a></li>
    <li><a href="/settings">Settings</a></li>
    <li><button type="button">Sign out</button></li>
  </ul>
</div>

<!-- manual popover: stays open -->
<div id="toast" popover="manual" role="status">
  Saved!
  <button popovertarget="toast"
          popovertargetaction="hide">Dismiss</button>
</div>

<!-- separate show button -->
<button popovertarget="help"
        popovertargetaction="show">Help</button>
<div id="help" popover>…</div>

<script>
  const toast = document.getElementById('toast');
  toast.showPopover();
  setTimeout(() => toast.hidePopover(), 4000);

  toast.addEventListener('toggle', (e) => {
    console.log(e.newState);    // "open" / "closed"
  });
</script>

⚠ Common Mistakes

  • Using popover for a confirmation that must be answered: nothing blocks the rest of the page
  • Positioning a popover with position: absolute from its button: it lives in the top layer; use anchor positioning
  • Pointing popovertarget from a <div> or <a>: only buttons work as invokers

✓ Tips & Best Practices

  • Use auto popovers for menus; they close themselves
  • Add CSS anchor positioning to keep popovers next to their buttons
  • Animate with @starting-style, just like dialogs

Quick Summary
