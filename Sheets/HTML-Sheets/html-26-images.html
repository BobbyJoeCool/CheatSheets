img, alt and figure

<img> embeds an image; treat src and alt as required. Alt text replaces the image for screen readers, search engines and broken images, so describe the image's purpose on this page. Always set width and height so the browser reserves space and the layout doesn't jump. loading="lazy" defers off-screen images, and <figure> + <figcaption> attach a caption.

Notes

  • Decorative images get alt="" (empty, not missing)
  • width / height are plain pixel numbers; CSS can still resize the image
  • AVIF and WebP are smaller than JPEG/PNG; use SVG for icons and logos
  • decoding="async" lets the image decode off the main thread

♿ Accessibility

  • Missing alt makes screen readers read the file name ("IMG_4021.jpg")
  • Images of text need the same text in alt; real text is better
  • <figcaption> is visible to everyone; it doesn't replace alt, and alt shouldn't repeat it

Pairing with CSS

  • img { max-width: 100%; height: auto; }: responsive images that keep their ratio
  • object-fit: cover + object-position: fill a box and choose the crop
  • figure { margin: 0; }: removes the UA's 40px side margins

Code Explained

informative alt: what the image shows that matters here
alt="": screen readers skip the image
link alt: describes the destination, not the picture
loading="lazy": never on the hero (LCP) image
chart alt: summarize the data, not just "chart"

Images and Figures

<!-- informative image -->
<img src="/img/boot-moss.jpg"
     alt="Trail Runner 3 in moss green, side view"
     width="800" height="600">

<!-- decorative image -->
<img src="/img/divider-leaves.svg" alt="">

<!-- functional image inside a link -->
<a href="/"><img src="/logo.svg" alt="Trailhead home"></a>

<!-- below the fold: lazy load -->
<img src="/img/review-1.jpg" alt="Customer on a ridge"
     width="400" height="300"
     loading="lazy" decoding="async">

<!-- hero image: load as early as possible -->
<img src="/img/hero.avif" alt="Hikers at sunrise"
     width="1600" height="900" fetchpriority="high">

<!-- figure with caption -->
<figure>
  <img src="/img/elevation.png"
       alt="Elevation: 1,800 m to 2,400 m over 6 km"
       width="600" height="300">
  <figcaption>Ridge Loop elevation profile</figcaption>
</figure>

⚠ Common Mistakes

  • Omitting alt entirely: screen readers fall back to the file name
  • Leaving out width / height: content jumps as images load (layout shift)
  • Lazy-loading the hero image: it delays Largest Contentful Paint

✓ Tips & Best Practices

  • Write alt text as if describing the image over the phone in one sentence
  • Serve AVIF/WebP with <picture> fallbacks (sheet 27)
  • Use <figure> for any image, chart or code that has a caption

Quick Summary

  • <img src alt>: always include alt
  • alt="": decorative images
  • width / height: reserve space
  • <figure> + <figcaption>: captions
