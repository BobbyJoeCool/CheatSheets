Link & Resource Hints

link rel · stylesheet · preload · preconnect · dns-prefetch · prefetch · modulepreload · media

Linking External Resources

<link> connects the document to other resources, and its rel attribute names the relationship: a stylesheet to apply, an icon to show, or a resource hint that tells the browser to connect, fetch or preload something early. Hints don't change what loads, only when. Used well, they cut hundreds of milliseconds from page loads.

Notes

  • rel="stylesheet" is render-blocking unless its media doesn't match
  • preload needs as (plus crossorigin for fonts) or the file may download twice
  • preconnect opens DNS + TCP + TLS early; limit it to 2–4 origins
  • prefetch is low priority, for files a future page will need

♿ Accessibility

  • rel="alternate" with hreflang helps users reach the page in their language
  • Fast-loading CSS avoids layout shifts that move content under the pointer
  • Preloading large files on slow connections delays the content users need

Pairing with CSS

  • media="print": print-only stylesheet that doesn't block screen rendering
  • media="(max-width: 600px)": still downloaded, but at low priority
  • preload as="font": avoids a flash of invisible text with @font-face

Code Explained

crossorigin: required for preloaded fonts, even same-origin ones
as: sets priority and request type; must match how the file is used
fetchpriority="high": boosts the hero (LCP) image
modulepreload: fetches and parses an ES module early
alternate stylesheet: user-selectable in Firefox

Stylesheets and Hints

<head>
  <!-- stylesheets -->
  <link rel="stylesheet" href="/css/main.css">
  <link rel="stylesheet" href="/css/print.css"
        media="print">
  <link rel="alternate stylesheet" title="High contrast"
        href="/css/contrast.css">

  <!-- connect early to third-party origins -->
  <link rel="preconnect"
        href="https://fonts.gstatic.com" crossorigin>
  <link rel="dns-prefetch" href="https://cdn.example.com">

  <!-- fetch now, used on this page -->
  <link rel="preload" href="/fonts/inter.woff2"
        as="font" type="font/woff2" crossorigin>
  <link rel="preload" href="/img/hero.avif"
        as="image" fetchpriority="high">
  <link rel="modulepreload" href="/js/app.js">

  <!-- fetch later, for the next page -->
  <link rel="prefetch" href="/js/checkout.js">

  <!-- alternate formats -->
  <link rel="alternate" type="application/rss+xml"
        title="Trail blog" href="/feed.xml">
</head>

⚠ Common Mistakes

  • Preloading without as: the browser can't match it and downloads the file twice
  • Preloading files the page doesn't use within a few seconds: Chrome warns about unused preloads
  • preconnect to a dozen domains: each connection costs CPU and closes if unused

✓ Tips & Best Practices

  • Preload only the LCP image and critical fonts
  • Use media="print" for print styles instead of @import in your main CSS
  • Check the Network panel's Priority column to confirm hints work

Quick Summary

  • rel="stylesheet": load CSS
  • preconnect: warm up an origin
  • preload + as: fetch now
  • prefetch: fetch for later
