Quick Reference — Attributes

global · link · media · form · validation · ARIA

Attribute Cheat Sheet

The attributes you'll use most, grouped by where they apply. Global attributes work on every element; the rest belong to links, media, forms or ARIA. Boolean attributes (hidden, required, disabled) are true whenever they're present, so remove them to turn them off.

Notes

  • Attribute values are strings; boolean attributes need no value
  • Unknown attributes are ignored but invalid; use data-* for custom data
  • Event-handler attributes (onclick) work, but addEventListener is preferred
  • Attribute names are case-insensitive in HTML documents

♿ Accessibility

  • Naming: alt, <label for>, aria-label, aria-labelledby
  • State: aria-expanded, aria-current, aria-invalid, disabled, checked
  • Focus: tabindex, autofocus, inert

Pairing with CSS

  • [attr], [attr="v"], ^=, $=, *=, ~=: attribute selectors
  • :disabled, :checked, :required, :read-only: prefer pseudo-classes for live state
  • content: attr(data-label): show an attribute's value from CSS

Code Explained

download / type: link behavior and hints
loading / decoding: image performance
min / max / step / required: validation
autocomplete / aria-describedby: autofill and hints
aria-* / popovertarget: state and invokers

Attributes in Context

<!-- links -->
<a href="/guide.pdf" download hreflang="en"
   type="application/pdf">Guide (PDF)</a>

<!-- images -->
<img src="hero.jpg" srcset="hero-2x.jpg 2x"
     alt="Ridge at sunrise" width="800" height="500"
     loading="lazy" decoding="async">

<!-- media -->
<video src="tour.mp4" controls muted playsinline
       poster="tour.jpg" preload="metadata"></video>

<!-- forms -->
<form action="/book" method="post">
  <label for="n">Nights</label>
  <input id="n" name="nights" type="number"
         min="1" max="14" step="1" value="2" required>
  <label for="e">Email</label>
  <input id="e" name="email" type="email"
         autocomplete="email" aria-describedby="e-h">
  <p id="e-h">For your confirmation.</p>
  <button type="submit" formaction="/hold">Hold</button>
</form>

<!-- global -->
<div id="panel" class="card is-open"
     data-state="open" lang="en" dir="ltr"
     tabindex="-1" hidden>…</div>

<!-- ARIA + invokers -->
<button aria-expanded="false" aria-controls="panel">
  Details</button>
<button popovertarget="menu">Menu</button>

⚠ Common Mistakes

  • Writing required="false" or disabled="false": still required, still disabled
  • Inventing attributes (<div tooltip="…">): use data-tooltip
  • Repeating an attribute on one element: the parser keeps the first and drops the rest

✓ Tips & Best Practices

  • Remove boolean attributes with removeAttribute() or toggleAttribute()
  • Use properties in JS for live state (input.value, box.checked)
  • Keep a consistent attribute order: id, class, name, type, then the rest

Quick Summary

  • global: any element
  • boolean: presence = true
  • data-*: custom attributes
  • aria-*: accessibility semantics
