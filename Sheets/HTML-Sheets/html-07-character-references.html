Character References

&lt; · &amp; · &quot; · named references · &#decimal; · &#xhex; · UTF-8 · escaping rules

Escaping Special Characters

Some characters mean something to HTML: < starts a tag and & starts a character reference. To show them as text, escape them as &lt; and &amp;. References come in three forms: named (&copy;), decimal (&#169;) and hex (&#xA9;). With <meta charset="utf-8"> you can type almost every other character (é, —, €, emoji) directly.

Notes

  • Named references are case-sensitive: &Eacute; ≠ &eacute;
  • Always end with ;; some names work without it, but not reliably
  • In attributes, escape the quote you used: title="Say &quot;hi&quot;"
  • &nbsp; (U+00A0) prevents a line break between two words

♿ Accessibility

  • Screen readers voice symbols differently; write "5 to 10" instead of relying on "5–10"
  • Emoji are read by name ("grinning face"), so decorative emoji add noise
  • Label meaningful symbols: <span role="img" aria-label="4 of 5 stars">★★★★☆</span>

Pairing with CSS

  • content: "\2014": CSS uses backslash hex escapes, not HTML references
  • ::before { content: "→ " }: add decorative symbols in CSS so they stay out of the text
  • hyphens: manual (default): breaks words only at &shy; soft hyphens

Code Explained

&lt;: needed wherever < could start a tag
&amp;: needed for a literal &, including inside URLs
&quot;: or switch to single quotes around the value
&shy;: shows a hyphen only if the word breaks there
<pre><code>: content still needs escaping

Escaping in Practice

<!-- must escape in text -->
<p>Use &lt;p&gt; for paragraphs.</p>  <!-- Use <p> for… -->
<p>Tom &amp; Jerry</p>                 <!-- Tom & Jerry -->

<!-- escape the quote character in attributes -->
<img alt="The &quot;Big&quot; Sale" src="sale.png">
<img alt='The "Big" Sale' src="sale.png">  <!-- also OK -->

<!-- three ways to write © -->
<p>&copy; 2026</p>
<p>&#169; 2026</p>
<p>&#xA9; 2026</p>
<p>© 2026</p>    <!-- UTF-8: just type it -->

<!-- spacing helpers -->
<p>Pay $10&nbsp;000 by 5&nbsp;pm.</p>
<p>super&shy;cali&shy;fragilistic</p> <!-- soft hyphens -->

<!-- show markup as code -->
<pre><code>&lt;a href="/"&gt;Home&lt;/a&gt;</code></pre>

<!-- & in URLs inside attributes -->
<a href="/search?q=boots&amp;size=9">Size 9 boots</a>

⚠ Common Mistakes

  • Pasting code samples without escaping <: the browser parses them as real tags
  • A raw & before letters in text (&copy, &lt): browsers may decode it as a character
  • Double-escaping user content (&amp;lt;): the reference text appears on screen

✓ Tips & Best Practices

  • Declare UTF-8 and type characters directly instead of memorizing references
  • Let your template engine or textContent escape user input
  • Put &nbsp; between numbers and units: 10&nbsp;km

Quick Summary

  • &lt; &amp;: always escape in text
  • &quot;: quotes inside attributes
  • &#169; / &#xA9;: numeric references
  • UTF-8: type characters directly
