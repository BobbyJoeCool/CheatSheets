Sections, Articles and Heading Levels

Headings <h1>–<h6> create the page outline, and they're how most screen-reader users skim. <article> is self-contained content that makes sense on its own (a post, a product card, a comment). <section> is a thematic group that should start with a heading. <hgroup> pairs a heading with a subtitle, and <address> holds contact details for the nearest article or the page.

Notes

  • Heading level comes only from the tag; browsers never shipped the "outline algorithm"
  • Don't skip levels going down (h2 → h4); jumping back up is fine
  • One <h1> per page is the common convention
  • <address> is for contact info, not every postal address

♿ Accessibility

  • Screen-reader users jump by heading (H key), so a clean heading tree is the fastest navigation
  • <section> becomes a region landmark only when it has an accessible name
  • Never pick a heading level for its size; fix the size in CSS

Pairing with CSS

  • Browsers are dropping the old smaller h1 styles inside <article>/<section>; set heading sizes yourself
  • :is(h1, h2, h3) { line-height: 1.2; }: style several levels at once
  • article + article { margin-top: 2rem; }: space between sibling articles

Code Explained

<hgroup>: heading plus a subtitle <p>; the subtitle isn't a heading
aria-labelledby: names the section, making it a region landmark
<h4> under <h3>: a sub-topic of Route Details
<footer> in <article>: the article's footer, not a landmark
<address>: contact for this article's authors

Article with Sections

<main>
  <h1>Trail Guides</h1>

  <article>
    <hgroup>
      <h2>Hiking the Ridge Loop</h2>
      <p>A 12 km day hike with lake views</p>
    </hgroup>
    <p>Posted <time datetime="2026-05-02">May 2</time></p>

    <section aria-labelledby="gear">
      <h3 id="gear">What to Bring</h3>
      <p>Water, layers and a map.</p>
    </section>

    <section>
      <h3>Route Details</h3>
      <h4>Trailhead parking</h4>
      <p>Lot B fills by 9 am.</p>
    </section>

    <footer>
      <address>
        Questions?
        <a href="mailto:guides@example.com">Email us</a>
      </address>
    </footer>
  </article>
</main>

⚠ Common Mistakes

  • Choosing <h4> because it's "the right size": the outline skips levels and confuses screen-reader users
  • Using <section> as a generic wrapper with no heading; use <div>
  • Marking a title and subtitle as <h1> + <h2>: the subtitle becomes a fake section

✓ Tips & Best Practices

  • Check the outline with a headings extension (e.g. HeadingsMap)
  • Ask "could this be shared on its own?" If yes, use <article>
  • Keep heading text short and specific; it works as a menu

Quick Summary

  • <h1>–<h6>: outline levels
  • <article>: self-contained content
  • <section>: themed group with a heading
  • <hgroup>: heading + subtitle
