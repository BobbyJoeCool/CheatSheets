Importing Assets

Importing an image, font or other file gives you its final URL: in dev it points at the source, in the build it's a hashed file in dist/assets/. Small files are inlined as base64 data URLs. Query suffixes change what the import returns, and public/ holds files you reference by a fixed absolute path instead.

Notes

  • assetsInlineLimit default is 4096 bytes
  • SVGs under the limit inline as URL-encoded text
  • new URL('./x.png', import.meta.url) works without an import
  • Add extra types with assetsInclude: ['**/*.gltf']

Asset Imports

import logoUrl from './logo.png'            // '/assets/logo-B2xF4k.png'
import iconUrl from './icon.svg?url'        // force URL, never inline
import shader from './glow.glsl?raw'        // file contents as string
import tinyPng from './dot.png?inline'      // always a data: URL
import bigSvg from './map.svg?no-inline'    // never inline

img.src = logoUrl

// Dynamic path without an import
const flag = new URL(`./flags/${code}.svg`, import.meta.url).href

// Public folder: absolute path, no import, no hash
favicon.href = '/favicon.ico'

// CSS url() is rewritten too:  background: url('./bg.jpg')

Code Explained

Default import — final public URL as a string
?url — URL even for files that would be inlined
?raw — contents as a string (shaders, SVG markup)
?inline / ?no-inline — force inlining on or off
new URL(..., import.meta.url) — static template literal only

⚠ Common Mistakes

  • Hard-coding '/src/assets/logo.png' strings — they work in dev but break after the build
  • Importing from public/ — reference public files by /name only; importing them warns and copies twice
  • Using fully dynamic new URL(variable, import.meta.url) — Vite can only see template literals with a static prefix
  • Expecting ?raw content to be transformed — it's the untouched file text

✓ Tips & Best Practices

  • Set build.assetsInlineLimit: 0 to never inline (e.g. strict CSP)
  • Use ?url for SVGs you set as <img src> to avoid huge inlined strings
  • Prefix public paths with import.meta.env.BASE_URL when base isn't /
  • Declare extra suffix types in vite-env.d.ts if you add custom ones

Quick Summary

  • import url from './x.png' — hashed URL
  • ?raw / ?url / ?inline — change the result
  • public/ — fixed paths, no processing
  • assetsInlineLimit — inline threshold (4 KiB)
