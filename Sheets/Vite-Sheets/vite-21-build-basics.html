Sheet 21

Build Basics

vite build · outDir · assetsDir · emptyOutDir · build.sourcemap · build.manifest · build.target

What a Build Produces

vite build bundles index.html and everything it imports into dist/: hashed JS and CSS chunks, processed assets, and copies of public/. The defaults target browsers in the Baseline Widely Available set. Most tuning happens under the build key; bundler-level control lives in build.rolldownOptions (sheet 22).

Notes

  • Mode is production, so import.meta.env.PROD is true
  • dist/ is emptied first when it's inside root
  • File names include a content hash for long-term caching
  • Vite 8 target: Chrome/Edge 111, Firefox 114, Safari 16.4

Build Config

export default defineConfig({
  build: {
    outDir: 'dist',
    assetsDir: 'assets',            // inside outDir
    emptyOutDir: true,              // needed if outDir is outside root
    sourcemap: 'hidden',            // maps without //# comment
    manifest: true,                 // dist/.vite/manifest.json
    target: 'baseline-widely-available',
    copyPublicDir: true,
    reportCompressedSize: false,    // faster on big projects
    chunkSizeWarningLimit: 800,     // kB
  },
})
// dist/
//   index.html
//   assets/index-BvX1kq3d.js   assets/index-Dk2m.css   favicon.svg

Code Explained

outDir / assetsDir — where files land
sourcemap — true, 'inline' or 'hidden'
manifest — map of source entries → built files (backends)
target — syntax level for output JS
reportCompressedSize — skip gzip size calc for speed

⚠ Common Mistakes

  • Serving dist/ from a subpath without setting base — every asset 404s
  • Building into a folder outside the project with no emptyOutDir: true — stale files pile up
  • Shipping sourcemap: true when you don't want source visible — use 'hidden'
  • Treating the chunk-size warning as an error — it's advice; split or raise the limit

✓ Tips & Best Practices

  • Run vite build && vite preview before every deploy
  • Use build.manifest when a server-side framework renders the HTML
  • Set reportCompressedSize: false in CI to save time
  • Pin a custom target only when you must support older browsers

Quick Summary

  • vite build — bundle into dist/
  • build.outDir / assetsDir — output layout
  • build.sourcemap: 'hidden' — private maps
  • build.manifest — entry → file mapping
