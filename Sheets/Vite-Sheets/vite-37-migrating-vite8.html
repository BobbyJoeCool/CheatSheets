Migrating to Vite 8

rollupOptions → rolldownOptions · esbuild → oxc · esbuildOptions → rolldownOptions · manualChunks → codeSplitting · minify defaults · target bump

What Changed

Vite 8 swaps esbuild and Rollup for Rolldown and Oxc. A compatibility layer converts most old options automatically, so many projects upgrade with no config changes, but you'll see deprecation warnings until you rename them. The breaking changes are a higher browser baseline, new default minifiers, stricter CommonJS interop and some removed Rollup-only options and hooks.

Notes

  • Node requirement unchanged: 20.19+ / 22.12+
  • Install grows by about 15 MB (Lightning CSS, Rolldown)
  • @vitejs/plugin-react v5 still works; v6 drops Babel
  • Try the upgrade on a branch and run a full build + preview

Before (Vite 7)

export default defineConfig({
  esbuild: {
    jsxImportSource: 'preact',
    drop: ['console', 'debugger'],
  },
  optimizeDeps: {
    esbuildOptions: { keepNames: true },
  },
  build: {
    rollupOptions: {
      output: {
        manualChunks: { vendor: ['react', 'react-dom'] },
      },
    },
  },
})

After (Vite 8)

export default defineConfig({
  oxc: { jsx: { importSource: 'preact' } },
  optimizeDeps: {
    rolldownOptions: { output: { keepNames: true } },
  },
  build: {
    rolldownOptions: {
      output: {
        minify: { compress: { dropConsole: true, dropDebugger: true } },
        codeSplitting: {
          groups: [{ name: 'vendor', test: /node_modules[\\/]react/ }],
        },
      },
    },
  },
})

⚠ Common Mistakes

  • Upgrading plugins and Vite in one step — upgrade Vite first, confirm it builds, then plugins
  • Ignoring deprecation warnings because the build passes — the auto-conversion will go away in a later major
  • Assuming esbuild is still installed — add it as a devDependency if you keep minify: 'esbuild'
  • Missing the CJS default-import change — test pages that use older CommonJS packages

✓ Tips & Best Practices

  • Run npx vite build and read every deprecation line; each one names the new option
  • Compare bundle sizes before and after (CSS may grow slightly with Lightning CSS)
  • Check plugins that use shouldTransformCachedModule, resolveImportMeta, renderDynamicImport or resolveFileUrl; they're unsupported
  • Read the official "Migration from v7" guide for the full list

Quick Summary

  • rollupOptions → rolldownOptions
  • esbuild → oxc
  • manualChunks → codeSplitting.groups
  • Oxc + Lightning CSS — new default minifiers
