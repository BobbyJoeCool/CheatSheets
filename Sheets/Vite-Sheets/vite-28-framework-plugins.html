Framework Plugins

@vitejs/plugin-react v6 · reactCompilerPreset · @vitejs/plugin-vue · @sveltejs/vite-plugin-svelte · vite-plugin-solid

One Plugin per Framework

Each UI framework needs one plugin that compiles its components and wires up HMR. @vitejs/plugin-react v6 uses Oxc for JSX and React Refresh and no longer depends on Babel; React Compiler is opt-in through @rolldown/plugin-babel. Vue, Svelte, Solid and Preact have their own official or framework-maintained plugins.

Notes

  • plugin-react v5 still works with Vite 8
  • @vitejs/plugin-react-swc is an SWC-based alternative
  • Vue JSX needs @vitejs/plugin-vue-jsx as well
  • SvelteKit / Nuxt add these plugins for you

Framework Setups

// React (+ optional React Compiler)
import react, { reactCompilerPreset } from '@vitejs/plugin-react'
import babel from '@rolldown/plugin-babel'
plugins: [react(), babel({ presets: [reactCompilerPreset()] })]

// Vue 3 (+ JSX)
import vue from '@vitejs/plugin-vue'
import vueJsx from '@vitejs/plugin-vue-jsx'
plugins: [
  vue({ template: { compilerOptions: {
    isCustomElement: (tag) => tag.startsWith('ion-'),
  } } }),
  vueJsx(),
]

// Svelte 5
import { svelte } from '@sveltejs/vite-plugin-svelte'
plugins: [svelte()]

// Solid / Preact
import solid from 'vite-plugin-solid'        // plugins: [solid()]
import preact from '@preact/preset-vite'     // plugins: [preact()]

Code Explained

react() — JSX, Fast Refresh, automatic runtime
reactCompilerPreset() — React Compiler via Babel
vue() — SFC compile; isCustomElement for web components
svelte() — reads svelte.config.js
preact() — aliases React imports to Preact

⚠ Common Mistakes

  • Passing babel: { plugins: [...] } to plugin-react v6 — Babel was removed; use @rolldown/plugin-babel
  • Using both plugin-react and plugin-react-swc — they conflict; pick one
  • Forgetting vueJsx() and getting JSX syntax errors in .tsx Vue files
  • Adding svelte() to a SvelteKit config — sveltekit() already includes it

✓ Tips & Best Practices

  • Start with plain react(); add React Compiler only after measuring
  • Use compilationMode: 'annotation' to try React Compiler on a few components
  • Set Emotion with react({ jsxImportSource: '@emotion/react' })
  • Stay on plugin-react v5 if you depend on Babel plugins and can't migrate yet

Quick Summary

  • react() — Oxc-based in v6, no Babel
  • reactCompilerPreset() — opt-in React Compiler
  • vue() / svelte() / solid() — per framework
  • One framework plugin per project
