Sheet 03

Project Structure & index.html

index.html as entry · <script type="module"> · public/ · src/ · root · vite-env.d.ts

The HTML Entry

In Vite, index.html is the entry point, not an afterthought in public/. It sits at the project root and loads your code with <script type="module" src="/src/main.ts">. Vite parses the HTML, follows that script and every import from it, and rewrites URLs at build time. Files in public/ are copied as-is and served from /.

Notes

  • root defaults to the folder with vite.config.* / process.cwd()
  • Absolute URLs in HTML (/src/...) resolve from root
  • Each extra .html file can be another entry (multi-page app)
  • %VITE_TITLE% placeholders in HTML are replaced from env vars

Typical Layout

my-app/
├── index.html          # entry, at root
├── public/             # copied as-is
│   └── favicon.svg     # → /favicon.svg
├── src/
│   ├── main.ts         # loaded by index.html
│   ├── App.tsx
│   ├── assets/logo.png # → hashed URL
│   ├── styles.css
│   └── vite-env.d.ts   # vite/client types
├── .env                # VITE_* variables
├── vite.config.ts
├── tsconfig.json
└── package.json

index.html

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" href="/favicon.svg" />
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0" />
    <title>%VITE_APP_TITLE%</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>

HTML Handling

In index.htmlWhat Vite does
<script type="module" src>Entry; bundled and hashed
<link rel="stylesheet" href>Processed CSS, hashed
<img src="./x.png">Asset URL rewritten
%VITE_X%Replaced with env value
Inline <script type="module">Bundled like a file

⚠ Common Mistakes

  • Putting index.html inside public/ — Vite won't treat it as the entry
  • Leaving off type="module" — the script isn't processed and imports fail
  • Importing from public/ (import x from '/public/x.png') — reference public files by URL only
  • Changing root without updating publicDir and envDir, which resolve relative to it

✓ Tips & Best Practices

  • Keep src/vite-env.d.ts so import.meta.env and asset imports are typed
  • Use public/ only for files that must keep their exact name
  • Set root: 'src' only if you want index.html inside src/
  • Add more .html entries via build.rolldownOptions.input (sheet 22)

Quick Summary

  • index.html — root-level entry, not in public/
  • <script type="module"> — where Vite starts
  • public/ — static, unhashed, served at /
  • src/assets — imported, hashed, optimized
