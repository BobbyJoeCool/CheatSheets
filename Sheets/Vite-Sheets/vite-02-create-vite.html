Sheet 02

Creating a Project

npm create vite@latest · --template react-ts · templates · package.json scripts · Node 20.19+ / 22.12+

Scaffolding

create-vite scaffolds a ready-to-run project: an index.html entry, a src/ folder, a config file and the three npm scripts. Run it without arguments for interactive prompts, or pass a project name and --template to skip them. The same command works through npm, pnpm, yarn, bun and deno.

Notes

  • Use . as the name to scaffold into the current folder
  • npm 7+ needs the extra -- before --template
  • Templates ending in -ts add TypeScript and tsconfig files
  • Community templates: npx degit user/repo my-app

Create Commands

npm create vite@latest                               # interactive prompts
npm create vite@latest my-app -- --template react-ts
pnpm create vite my-app --template vue-ts
yarn create vite my-app --template svelte-ts
bun create vite my-app --template solid-ts
deno init --npm vite my-app --template preact-ts
npm create vite@latest . -- --template vanilla       # current folder

# Add Vite to an existing project
npm install -D vite
npx vite                                             # serves ./index.html

Code Explained

@latest — avoids a stale cached version of create-vite
--template — skips the framework and variant prompts
pnpm / yarn / bun — no -- separator needed
npm install -D vite — Vite is always a dev dependency
Bare npx vite works with no config file at all

⚠ Common Mistakes

  • Running npm create vite my-app --template react without -- on npm 7+ — the flag is swallowed and you get prompts
  • Installing vite as a regular dependency — it's build tooling and belongs in devDependencies
  • Using an old Node version — Vite 8 refuses to start below 20.19 / 22.12
  • Scaffolding into a non-empty folder and letting it overwrite files

✓ Tips & Best Practices

  • Keep the TS template's tsc -b && vite build so CI fails on type errors
  • Pin Node with "engines" or .nvmrc so teammates match
  • Prefer framework starters (Nuxt, SvelteKit, React Router) when you need routing and SSR
  • Commit the lockfile right after scaffolding

Quick Summary

  • npm create vite@latest — interactive scaffold
  • --template x-ts — pick framework + TypeScript
  • npm i -D vite — add to an existing app
  • dev / build / preview — the three scripts
