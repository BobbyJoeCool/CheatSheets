What Vite Is

Vite (French for "quick", pronounced *veet*) is a front-end build tool created by Evan You in 2020. In development it serves your source over native ES modules and transforms each file only when the browser asks for it, so startup time doesn't grow with app size. For production, vite build bundles with Rolldown (Rust) and transforms and minifies with Oxc. Vite 8 (March 2026) replaced the old esbuild + Rollup pair with this single toolchain.

Notes

  • Requires Node.js 20.19+ or 22.12+; Vite 8 ships as ESM only
  • Framework-agnostic: React, Vue, Svelte, Solid, Preact, Lit, vanilla
  • Powers Vitest, Nuxt, SvelteKit, Astro, React Router, Analog
  • Default ports: dev 5173, preview 4173

From Zero to Running App

npm create vite@latest hello -- --template vanilla-ts
cd hello
npm install
npm run dev       # ➜ Local: http://localhost:5173/
npm run build     # → dist/index.html + dist/assets/*-[hash].js
npm run preview   # serves dist/ at http://localhost:4173/

Code Explained

create vite — scaffolds a project from a template
npm run dev — runs vite; no bundling, instant start
npm run build — runs vite build; output goes to dist/
npm run preview — serves the built output locally to check it
Edit a file while dev runs → HMR updates the page in place

Dev Server vs Build

Aspectvite (dev)vite build
ModulesNative ESM, one request per fileBundled, hashed chunks
TransformOxc, on demand per requestOxc + Rolldown, whole graph
DependenciesPre-bundled once to .vite/Bundled with your code
UpdatesHMR over WebSocketRebuild (--watch)
OutputServed from memoryFiles in dist/

⚠ Common Mistakes

  • Opening index.html straight from disk — it needs the dev server or a built dist/ served over HTTP
  • Expecting vite to type-check — it strips types only; run tsc --noEmit separately
  • Deploying the project root instead of dist/ — only the build output is production-ready
  • Following pre-2026 tutorials that configure esbuild or rollupOptions without knowing they're renamed

✓ Tips & Best Practices

  • Check your version with npx vite --version before copying config from docs
  • Use npm create vite@latest so you always get the current templates
  • Run vite preview before deploying to catch base-path and asset issues
  • Read sheet 37 when upgrading a Vite 7 project

Quick Summary

  • vite — fast dev server on native ESM + HMR
  • vite build — Rolldown bundle into dist/
  • vite preview — serve dist/ locally
  • Oxc — transforms TS/JSX and minifies JS
