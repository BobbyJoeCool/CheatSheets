Special Imports

Vite handles three special file types out of the box. JSON imports become ES modules, and named imports let unused fields be tree-shaken. WebAssembly loads with ?init, and Vite 8.1 adds direct ESM imports of .wasm files. Web Workers are bundled as their own entry whether you use the ?worker suffix or the standard new Worker(new URL(...)) pattern.

Notes

  • json.stringify emits JSON.parse("…") for large files
  • .wasm?init works in SSR since Vite 8
  • Workers default to worker.format: 'iife'
  • Use { type: 'module' } for ES module workers

All Three Patterns

// JSON — default or named (named = tree-shakeable)
import pkg from './package.json'
import { version } from './package.json'

// WebAssembly with ?init
import init from './math.wasm?init'
const instance = await init({ env: { log: console.log } })

// Web Worker — standard syntax (recommended)
const worker = new Worker(new URL('./heavy.ts', import.meta.url),
  { type: 'module' })
worker.postMessage({ n: 40 })

// Web Worker — Vite suffix
import HeavyWorker from './heavy.ts?worker'
import InlineWorker from './heavy.ts?worker&inline'   // base64 blob

Code Explained

Named JSON import — only that field ships
?init — returns init(imports?) → Promise<Instance>
new URL('./w.ts', import.meta.url) — must be inline in new Worker()
?worker — default export is a Worker constructor
?worker&inline — worker embedded as base64

⚠ Common Mistakes

  • Storing the URL in a variable first — new Worker(url) isn't detected; write new Worker(new URL(...)) inline
  • Using import inside an IIFE worker — set worker.format: 'es' and { type: 'module' }
  • Importing a .wasm file with no suffix before Vite 8.1 — it fails; add ?init or upgrade for ESM integration

✓ Tips & Best Practices

  • Prefer the new URL worker syntax — it's standard and works in other tools too
  • Use ?worker&inline only for small workers; it inflates the main bundle
  • Use Comlink to call worker functions like async methods
  • Name JSON imports to keep big config files out of the bundle

Quick Summary

  • import { version } from './package.json' — JSON
  • import init from './x.wasm?init' — Wasm
  • new Worker(new URL('./w.ts', import.meta.url)) — worker
  • worker.format: 'es' — module workers
