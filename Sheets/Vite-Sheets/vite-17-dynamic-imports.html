Dynamic Imports & Preloading

import() · variables in import() · /* @vite-ignore */ · modulepreload · build.modulePreload · vite:preloadError

Code Splitting by Import

A dynamic import() splits code into a separate chunk that loads on demand. Vite supports template-literal paths with variables, turning them into a glob of possible files, and automatically preloads a chunk's dependencies in parallel so lazy routes don't waterfall. If a chunk fails to load (often after a new deploy), Vite fires a vite:preloadError event you can handle.

Notes

  • Variable paths must start with ./ or ../
  • They must include the file extension
  • Variables can only fill a single folder level
  • /* @vite-ignore */ silences warnings for truly runtime paths

Dynamic Import Patterns

// Lazy route / component → own chunk
const Settings = () => import('./pages/Settings.tsx')

// Variable path → Vite globs ./locales/*.json
const messages = await import(`./locales/${lang}.json`)

// Runtime URL Vite shouldn't analyze
const plugin = await import(/* @vite-ignore */ remoteUrl)

// Reload once when chunks 404 after a deploy
window.addEventListener('vite:preloadError', (event) => {
  event.preventDefault()          // stop the error from throwing
  window.location.reload()
})

// vite.config.ts
// build: { modulePreload: { polyfill: false } }

Code Explained

Static string — one chunk per imported file
Template literal — all matching files become chunks
@vite-ignore — leave the import untouched
vite:preloadError — handle missing chunks
modulePreload.polyfill — off if you only target modern browsers

Variable Import Rules

⚠ Common Mistakes

  • Using a bare variable import(path) — Vite can't know the files, so nothing gets bundled
  • Lazy-loading tiny modules — each chunk is an extra request; split at routes and heavy libraries
  • Ignoring stale-chunk errors after deploys — users with an old tab get blank screens; handle vite:preloadError
  • Assuming @vite-ignore makes a local file work — it won't be in dist/

✓ Tips & Best Practices

  • Split at route boundaries with React.lazy / defineAsyncComponent
  • Keep old assets on the server for a while after deploys so open tabs still load
  • Use import.meta.glob when you need the list of files, not just one
  • Check chunk sizes with a bundle analyzer after adding lazy imports

Quick Summary

  • import('./x') — new chunk on demand
  • ` import(./dir/${v}.ext) ` — globbed variable import
  • vite:preloadError — recover from missing chunks
  • build.modulePreload — preload settings
