Writing Plugins: Server & HTML Hooks

configureServer · server.middlewares · transformIndexHtml · hotUpdate · this.environment · vite-plugin-inspect

Dev-Server Hooks

Some plugin hooks exist only in Vite. configureServer gives you the dev server to add middleware or watch files; transformIndexHtml edits or injects into HTML; hotUpdate customizes what happens when a file changes. Inside hooks, this.environment tells you whether you're working on the client, SSR or another environment.

Notes

  • configureServer can return a function to run after internal middleware
  • configurePreviewServer is the same hook for vite preview
  • hotUpdate replaces the older handleHotUpdate
  • Use apply: 'serve' for dev-only plugins

Middleware, HTML Injection, HMR

import type { Plugin } from 'vite'

export function devTools(): Plugin {
  return {
    name: 'dev-tools',
    apply: 'serve',
    configureServer(server) {
      server.middlewares.use('/__health', (req, res) => res.end('ok'))
      return () => server.middlewares.use(spaFallback)   // after internals
    },
    transformIndexHtml: () => [
      { tag: 'script', attrs: { src: '/banner.js' }, injectTo: 'body' },
    ],
    hotUpdate({ file, server }) {
      if (file.endsWith('.md') && this.environment.name === 'client') {
        server.ws.send({ type: 'custom', event: 'content-changed', data: { file } })
        return []                                         // skip default HMR
      }
    },
  }
}

Code Explained

server.middlewares — Connect app; add routes
Returned function — post-middleware
transformIndexHtml — return tags or new HTML
hotUpdate — [] = handled; server.ws.send notifies clients

Useful server Properties

⚠ Common Mistakes

  • Adding a catch-all middleware directly in configureServer — it runs before Vite's and swallows module requests; return a function instead
  • Forgetting apply: 'serve' on dev-only plugins — configureServer code may still be imported and run at build
  • Using handleHotUpdate in new plugins — prefer hotUpdate, which is environment-aware

✓ Tips & Best Practices

  • Debug your transforms with vite-plugin-inspect at /__inspect/
  • Use server.ws.send({ type: 'full-reload' }) to force a reload
  • Use injectTo: 'head-prepend' for scripts that must run first
  • Read this.environment.config instead of global config in environment-aware hooks

Quick Summary

  • configureServer — dev middleware + watcher
  • transformIndexHtml — edit / inject HTML
  • hotUpdate — custom HMR handling
  • this.environment — which environment is running
