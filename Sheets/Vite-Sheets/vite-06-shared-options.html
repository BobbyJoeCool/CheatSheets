Sheet 06

Shared Options

root · base · mode · define · publicDir · cacheDir · logLevel · clearScreen

Top-Level Options

Shared options sit at the top level of the config and apply to dev, build and preview alike. The ones you'll touch most are base (the public path the app is served from), define (compile-time constants) and publicDir. Server-, build- and preview-specific settings live under their own keys.

Notes

  • base must start and end with / (or be ./ for relative)
  • define values are replaced as raw code, so strings need JSON.stringify
  • publicDir: false turns the public folder off
  • appType: 'spa' (default), 'mpa' or 'custom'

Shared Options in Use

import { defineConfig } from 'vite'

export default defineConfig({
  root: 'src',                         // folder holding index.html
  base: '/my-app/',                    // served from /my-app/
  publicDir: '../static',              // relative to root
  cacheDir: '../node_modules/.vite',
  envDir: '..',                        // where .env files live
  appType: 'spa',                      // HTML fallback for routes
  define: {
    __APP_VERSION__: JSON.stringify('1.4.2'),
    __DEV_TOOLS__: false,
  },
  logLevel: 'info',
  clearScreen: false,
})

Code Explained

root — moves where index.html and relative paths start
base — prefix for every asset URL; also import.meta.env.BASE_URL
define — find-and-replace at transform time
appType: 'spa' — unknown routes return index.html in dev
clearScreen: false — keeps logs from other tools visible

⚠ Common Mistakes

  • define: { API: 'https://x' } — inserted unquoted and breaks the code; wrap with JSON.stringify
  • Setting base: 'my-app' without slashes — produces broken asset URLs
  • Using define for secrets — the value ends up in the shipped JS
  • Putting server-only options at the top level where they're ignored

✓ Tips & Best Practices

  • Declare define globals in a .d.ts: declare const __APP_VERSION__: string
  • Use base: './' for builds opened from arbitrary subfolders
  • Prefer import.meta.env.VITE_* over define for config that varies by environment
  • Set clearScreen: false when running Vite alongside other watchers

Quick Summary

  • base — public path prefix
  • define — compile-time constants (stringify!)
  • root / publicDir / envDir — where things live
  • appType — spa · mpa · custom
