Minification & Bundle Size

build.minify (Oxc) · minify.compress.drop · treeshake · chunkSizeWarningLimit · bundle analysis · build.chunkImportMap

Shrinking the Output

Vite 8 minifies JavaScript with the Oxc minifier and CSS with Lightning CSS. You can still choose Terser, or esbuild if you install it, but both are slower. Beyond minification, bundle size comes down to tree-shaking (ESM imports, side-effect-free packages), splitting heavy code into lazy chunks, and checking what actually ships.

Notes

  • build.minify: 'esbuild' is deprecated and needs esbuild installed
  • Property mangling isn't supported by Oxc
  • Tree-shaking needs ESM; CJS deps shake poorly
  • Vite 8.1 adds experimental build.chunkImportMap

Minify and Analyze

import { visualizer } from 'rollup-plugin-visualizer'

export default defineConfig({
  plugins: [visualizer({ filename: 'stats.html', gzipSize: true })],
  build: {
    minify: 'oxc',                       // default; or 'terser' / false
    cssMinify: 'lightningcss',           // default
    rolldownOptions: {
      output: {
        minify: {
          compress: { dropConsole: true, dropDebugger: true },
        },
      },
      treeshake: { moduleSideEffects: 'no-external' },
    },
    chunkSizeWarningLimit: 600,
  },
})

Code Explained

minify: 'oxc' — fast default JS minifier
output.minify.compress.dropConsole — strip console.* (was esbuild.drop)
dropDebugger — remove debugger statements
treeshake — Rolldown tree-shaking options
visualizer — treemap of what's in each chunk

⚠ Common Mistakes

  • Using dropConsole and losing console.error too — it drops every console.* call; use manualPureFunctions for selective removal
  • Importing import _ from 'lodash' — pulls the whole CJS library; import named functions from lodash-es
  • Relying on 'esbuild' minify after upgrading — it's no longer installed by default
  • Judging size by uncompressed numbers — compare gzip/brotli sizes

✓ Tips & Best Practices

  • Add "sideEffects": false to your own library packages
  • Check output with npx vite-bundle-visualizer for a one-off report
  • Keep debugger removal on even if you keep console logs
  • Try build.chunkImportMap (experimental) for better cache hits across deploys

Quick Summary

  • build.minify: 'oxc' — default JS minifier
  • compress.dropConsole — strip logs
  • rolldownOptions.treeshake — tree-shaking control
  • visualizer() — see what's in the bundle
