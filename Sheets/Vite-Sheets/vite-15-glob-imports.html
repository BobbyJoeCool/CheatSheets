import.meta.glob

import.meta.glob() imports many files at once using a glob pattern. Vite expands it at compile time into an object whose keys are file paths. By default each value is a lazy loader (a function returning a dynamic import()), which creates a separate chunk per file. With eager: true the files are imported up front instead.

Notes

  • Arguments must be string literals, not variables
  • Patterns are relative (./), absolute (/) or aliased
  • Prefix with ! to exclude files
  • Vite 8.1 adds caseSensitive: false

Lazy, Eager and Named

// Lazy: { './pages/About.tsx': () => import('./pages/About.tsx'), ... }
const pages = import.meta.glob('./pages/*.tsx')
const mod = await pages['./pages/About.tsx']()

// Eager: modules imported immediately
const locales = import.meta.glob('./locales/*.json', { eager: true })

// Only the default export, eager
const icons = import.meta.glob('./icons/*.svg', {
  eager: true, query: '?raw', import: 'default',
})                               // { './icons/x.svg': '<svg…>' }

// Several patterns, with exclusion and a typed result
const tests = import.meta.glob<{ run: () => void }>(
  ['./specs/**/*.ts', '!**/*.skip.ts'],
)

Code Explained

Default — values are () => Promise<Module>
eager: true — values are the modules themselves
import: 'default' — pick one export (tree-shakes the rest)
query: '?raw' — apply an import suffix to every match
Generic <T> — types the module values

Options

OptionEffect
eagerImport immediately, no chunks
importNamed export to take ('default', 'setup')
querySuffix like '?raw' or '?url'
baseBase folder for result keys
exhaustiveAlso search node_modules / dotfiles
caseSensitivefalse = ignore case (Vite 8.1)

⚠ Common Mistakes

  • Building the pattern from a variable — glob arguments must be literal strings or arrays of literals
  • Using eager: true for large route sets — everything lands in the main bundle; keep routes lazy
  • Expecting keys to be file names — keys are the relative paths you wrote, such as ./pages/Home.tsx
  • Matching the file that calls the glob — it can import itself; add a ! exclusion

✓ Tips & Best Practices

  • Build a route table from import.meta.glob('./pages/**/*.tsx') for file-based routing
  • Use import: 'default', eager: true for small registries like icons or translations
  • Use base to strip a common folder from the keys
  • For one dynamic file, prefer import(./locales/${lang}.json) (sheet 17)

Quick Summary

  • import.meta.glob('./x/*.ts') — lazy loaders
  • { eager: true } — modules up front
  • { import: 'default', query: '?raw' } — shape results
  • '!pattern' — exclude files
