Transpile Only

Vite compiles .ts and .tsx with Oxc, which strips types file by file and never type-checks. That keeps dev fast, but you need tsc (or vue-tsc) in a separate step to catch type errors. Because each file is compiled alone, your tsconfig must use settings that work without whole-program information.

Notes

  • Vite 8 replaced the esbuild option with oxc
  • emitDecoratorMetadata is supported natively in Vite 8
  • const enum across files and namespaces merging aren't supported
  • Use import type for type-only imports

tsconfig.json (app)

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "isolatedModules": true,
    "verbatimModuleSyntax": true,
    "useDefineForClassFields": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "strict": true,
    "types": ["vite/client"]
  },
  "include": ["src"]
}

Type Checking and oxc Options

// package.json scripts
// "build":     "tsc -b && vite build"
// "check": "tsc --noEmit --watch"

// vite.config.ts
import { defineConfig } from 'vite'
export default defineConfig({
  oxc: {
    jsx: { importSource: 'preact' },
    define: { __TEST__: 'false' },
  },
})

// src/vite-env.d.ts
/// <reference types="vite/client" />

⚠ Common Mistakes

  • Thinking vite build will fail on type errors — it won't; add tsc -b && to the build script
  • Exporting a type without export type — breaks under isolated compilation
  • Leaving out vite/client types — import.meta.env and .png imports show errors
  • Keeping old esbuild: { ... } options and assuming they're ignored — Vite 8 converts them, but move them to oxc

✓ Tips & Best Practices

  • Run tsc --noEmit --watch in a second terminal, or use vite-plugin-checker for overlay errors
  • Use vue-tsc for Vue and svelte-check for Svelte
  • Split configs: tsconfig.app.json and tsconfig.node.json (for vite.config)
  • Override a client type by adding your own declare module '*.svg' before the reference

Quick Summary

  • Oxc — strips types, no checking
  • tsc -b && vite build — check then build
  • isolatedModules + verbatimModuleSyntax — required style
  • oxc option — replaces esbuild in Vite 8
