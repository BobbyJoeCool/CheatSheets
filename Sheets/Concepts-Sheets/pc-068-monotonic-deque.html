Monotonic Deque

sliding window maximum · deque of indices · pop stale front · shortest subarray with sum ≥ K · jump game VI

Window Max or Min in O(1) per Step

A monotonic deque keeps indexes whose values are decreasing from front to back. The front is the current window's maximum. Before adding a new index, pop from the back every item it beats (they can never be the max again); pop from the front when an index slides out of the window. Every index enters and leaves once: O(n) total.

Recognize It When

  • "Maximum / minimum of every window of size k"
  • DP where dp[i] needs the max of the last k values
  • Shortest subarray with sum ≥ K with negatives
  • Front = answer; back = where you drop losers

Sliding Window Maximum

function maxSlidingWindow(nums, k)
    dq ← new Deque()                    // indexes; values decreasing
    out ← []
    for i ← 0 to length(nums) - 1
        if not dq.isEmpty() and dq.front() ≤ i - k
            dq.popFront()               // fell out of the window
        while not dq.isEmpty() and nums[dq.back()] ≤ nums[i]
            dq.popBack()                // can never be the max again
        dq.pushBack(i)
        if i ≥ k - 1
            out.append(nums[dq.front()])
    return out

Code Explained

front — index of the window max
pop front — expired index
pop back — dominated by the new item
window min — keep values increasing instead
O(n) time, O(k) space

Shortest Subarray with Sum ≥ K

function shortestSubarray(nums, K)
    P ← prefix sums, length n + 1
    dq ← new Deque()          // P increasing
    best ← ∞
    for j ← 0 to n
        while not dq.isEmpty()
                and P[j] - P[dq.front()] ≥ K
            best ← min(best, j - dq.popFront())
        while not dq.isEmpty()
                and P[dq.back()] ≥ P[j]
            dq.popBack()
        dq.pushBack(j)
    return if best = ∞ then -1 else best

Jump Game VI (Deque-Optimized DP)

function maxResult(nums, k)
    dp ← new Array(n)
    dp[0] ← nums[0]
    dq ← new Deque([0])       // dp decreasing
    for i ← 1 to n - 1
        if dq.front() < i - k
            dq.popFront()
        dp[i] ← nums[i] + dp[dq.front()]
        while not dq.isEmpty()
                and dp[dq.back()] ≤ dp[i]
            dq.popBack()
        dq.pushBack(i)
    return dp[n - 1]

⚠ Common Mistakes

  • Storing values in the deque: you can't tell when one has left the window
  • Checking expiry with < instead of ≤ i − k: the window becomes k + 1 wide
  • Using a heap: works, but O(n log n) and needs lazy deletion

✓ Tips & Best Practices

  • Practice: Sliding Window Maximum, Shortest Subarray with Sum ≥ K, Jump Game VI, Constrained Subsequence Sum
  • Longest subarray with |max − min| ≤ limit: two deques (max and min)
  • Deque here = Python collections.deque, Java ArrayDeque

Quick Summary

  • deque of indexes — values monotonic
  • front — window answer
  • pop back — dominated items
  • O(n) — each index in and out once
