Shortest Paths: Dijkstra

non-negative weights · min-heap · relaxation · dist array · stale-entry skip · O((V + E) log V) · network delay time

Cheapest Paths with Non-Negative Weights

Dijkstra's algorithm finds the lowest-cost path from one source to every node when no edge is negative. It always expands the closest unfinished node (via a min-heap); once popped, that node's distance is final. Relaxing an edge means improving dist[v] through u. Instead of decrease-key, push duplicates and skip stale heap entries.

Recognize It When

  • Weighted edges, all ≥ 0
  • "Minimum cost / time / effort" from a start
  • Network delay, flight prices without stop limits
  • Grid where moves have different costs

Dijkstra with a Min-Heap

function dijkstra(n, adj, src)        // adj[u] = [(v, w), …], w ≥ 0
    dist ← new Array(n, ∞)
    prev ← new Array(n, null)
    dist[src] ← 0
    heap ← new MinHeap([(0, src)])    // (distance, node)
    while not heap.isEmpty()
        (d, u) ← heap.pop()
        if d > dist[u] continue       // stale entry: skip
        for each (v, w) in adj[u]
            if d + w < dist[v]        // relax
                dist[v] ← d + w
                prev[v] ← u
                heap.push((dist[v], v))
    return (dist, prev)

function pathTo(prev, t)              // walk predecessors back
    path ← []
    while t ≠ null
        path.append(t)
        t ← prev[t]
    return reverse(path)

Code Explained

dist — best known cost; ∞ = unreached
heap — always pop the smallest tentative distance
stale check — node already finalized cheaper
relax — d + w < dist[v]
prev — rebuild the actual route
Network Delay Time: answer is max(dist) or -1

⚠ Common Mistakes

  • Running Dijkstra with negative edges: finalized nodes can later get cheaper
  • Skipping the stale check: correct but much slower on dense graphs
  • Marking visited on push instead of on pop: can lock in a worse distance

✓ Tips & Best Practices

  • Stop early when you pop the target if you only need one distance
  • For a grid, nodes are cells and w is the cell's cost
  • Equal weights everywhere? Plain BFS is enough

Quick Summary

  • min-heap — closest first
  • relax — dist[v] ← d + w
  • skip if d > dist[u] — stale
  • O((V + E) log V)
