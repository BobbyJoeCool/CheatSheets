Arrays & Dynamic Arrays

contiguous memory · O(1) index · insert / delete O(n) · resize doubling · 2D arrays · row-major order · in-place edits

Contiguous, Indexed Storage

An array stores items side by side in memory, so any index is reached in O(1) by arithmetic (base + i × size). Inserting or deleting in the middle shifts everything after it: O(n). A dynamic array (Python list, Java ArrayList, JS array, C++ vector) grows by doubling, making append O(1) amortized.

Costs

  • Read / write arr[i]: O(1)
  • Append / pop at end: O(1) amortized
  • Insert / delete at front or middle: O(n)
  • Search unsorted: O(n); sorted: O(log n)

Working with Arrays

arr ← new Array(5, 0)            // [0, 0, 0, 0, 0]
arr[2] ← 7                       // O(1) write
last ← arr[length(arr) - 1]      // O(1) read

list ← []                        // dynamic array
list.append(4)                   // O(1) amortized
list.insert(0, 9)                // O(n): shifts right
list.removeAt(0)                 // O(n): shifts left
list.pop()                       // O(1): remove last

grid ← new Array(rows)           // 2D grid, row-major
for r ← 0 to rows - 1
    grid[r] ← new Array(cols, 0)

function reverse(arr, l, r)      // in place, O(1) extra space
    while l < r
        (arr[l], arr[r]) ← (arr[r], arr[l])
        (l, r) ← (l + 1, r - 1)

Code Explained

new Array(n, v) — n slots, all v
insert(0, x) — every element moves
pop() — cheap; prefer working from the end
row-major — grid[r][c] rows stored one after another
reverse — building block for rotations

⚠ Common Mistakes

  • Inserting at index 0 inside a loop: O(n²) total; append and reverse once instead
  • Reading arr[n]: the last valid index is n - 1
  • Creating a 2D grid with one shared row ([[0] * c] * r in Python)

✓ Tips & Best Practices

  • Rotate by k: k ← k mod n first, then reverse all, first k, and the rest
  • Pre-allocate when the final size is known
  • Iterate backward when deleting by index

Quick Summary

  • arr[i] — O(1) access
  • append — O(1) amortized
  • insert(0, x) — O(n)
  • write pointer — in-place filtering
