Sheet 071

Cyclic Sort & In-Place Index Marking

values 1..n · swap to home index · find missing number · find duplicates · negate-to-mark · first missing positive

Use the Array as Its Own Hash Table

When values fall in a known range like 1…n, each value has a natural home index (value − 1). Cyclic sort swaps every value to its home in O(n); afterwards any index holding the wrong value reveals a missing or duplicate number. Alternatively, negate nums[v − 1] to mark that v was seen. Both use O(1) extra space.

Recognize It When

  • Values in 1…n or 0…n and "O(1) extra space"
  • "Find the missing / duplicate / first missing positive"
  • "All numbers disappeared", "set mismatch"
  • Input may be modified in place

Cyclic Sort

function cyclicSort(nums)      // values 1..n
    i ← 0
    while i < length(nums)
        j ← nums[i] - 1        // home index
        if nums[i] ≠ nums[j]
            swap(nums, i, j)   // recheck slot i
        else
            i ← i + 1
// each swap places one value for good:
// at most n swaps → O(n)

Negate to Mark: Find Duplicates

function findDuplicates(nums)  // values 1..n
    out ← []
    for each x in nums
        j ← abs(x) - 1
        if nums[j] < 0
            out.append(abs(x)) // seen before
        else
            nums[j] ← -nums[j] // mark seen
    return out
// Disappeared Numbers: mark, then report
// every index still positive (i + 1)

First Missing Positive

function firstMissingPositive(nums)
    n ← length(nums)
    for i ← 0 to n - 1
        while nums[i] ≥ 1 and nums[i] ≤ n
                and nums[nums[i] - 1] ≠ nums[i]
            swap(nums, i, nums[i] - 1)    // send home
    for i ← 0 to n - 1
        if nums[i] ≠ i + 1
            return i + 1                  // first gap
    return n + 1

⚠ Common Mistakes

  • Using nums[i] ≠ i + 1 as the swap test with duplicates: infinite loop
  • Reading nums[x − 1] after x was negated: always use abs(x)
  • Modifying input when the problem forbids it (Find the Duplicate Number)

✓ Tips & Best Practices

  • Shift the range first if values are 0…n−1 (home = value) or 0…n
  • Missing Number without modifying input: n(n+1)/2 − sum or XOR
  • Restore signs afterward if the caller needs the original array

Quick Summary

  • home index — value − 1
  • swap until home — cyclic sort
  • negative sign — seen flag
  • O(n) time, O(1) space
