Split, Solve, Combine

Divide and conquer breaks a problem into independent pieces (usually halves), solves each recursively, and combines the results. Unlike DP, the pieces don't overlap, so no caching is needed. Its cost follows the recurrence T(n) = a·T(n/b) + combine cost, which the Master Theorem (Sheet 024) solves.

Recognize It When

  • The answer for the whole follows from answers for halves
  • A cheap combine step exists (merge, compare, multiply)
  • Halving cuts work: O(n²) → O(n log n), O(n) → O(log n)
  • Tree problems: each subtree is an independent half

Template and Fast Power

function solve(problem)
    if problem is small
        return answer directly      // base case
    (A, B) ← split(problem)         // usually halves
    return combine(solve(A), solve(B))

function power(x, n)                // O(log n)
    if n = 0 return 1
    half ← power(x, n div 2)        // solve once, reuse
    if n mod 2 = 0
        return half * half
    return half * half * x
// negative n: 1 / power(x, -n)

Majority Element (D&C)

function majority(a, lo, hi)        // O(n log n)
    if lo = hi return a[lo]
    mid ← (lo + hi) div 2
    left ← majority(a, lo, mid)
    right ← majority(a, mid + 1, hi)
    if left = right return left
    cl ← count of left in a[lo..hi]
    cr ← count of right in a[lo..hi]
    return if cl > cr then left else right

// Boyer-Moore voting: O(n), O(1) space

⚠ Common Mistakes

  • Calling power(x, n div 2) twice: O(n) instead of O(log n)
  • Halves that overlap or share state: that's DP territory, not D&C
  • Unbalanced splits (always 1 and n − 1): degrades to O(n²)

✓ Tips & Best Practices

  • Draw the recursion tree: depth × work per level gives the total
  • Closest pair: only points within d of the middle line need checking, ~7 neighbors each
  • Practice: Pow(x, n), Sort an Array, Majority Element, Construct Tree from Traversals

Quick Summary

  • split — independent subproblems
  • combine — where the real work is
  • T(n) = aT(n/b) + f(n) — cost
  • reuse a half result — fast power
