Queues & Deques

FIFO · enqueue / dequeue · circular buffer · deque · queue from two stacks · BFS use

First In, First Out

A queue adds at the back and removes from the front, so items leave in arrival order: the backbone of BFS, task scheduling, and buffering. A deque (double-ended queue) adds and removes at both ends in O(1), which makes it a stack, a queue, and a sliding-window tool at once.

Quick Facts

  • enqueue / dequeue: O(1) with a proper queue
  • Removing from the front of an array is O(n)
  • A circular buffer is a fixed-size array queue
  • Python collections.deque, Java ArrayDeque

Queue, Deque, Circular Buffer

queue ← new Queue()
queue.enqueue("a")
queue.enqueue("b")
queue.dequeue()                    // "a"  first in, first out

dq ← new Deque()
dq.pushBack(1)
dq.pushFront(0)                    // [0, 1]; popBack / popFront

class CircularQueue                // fixed array that wraps
    function init(k)
        (this.data, this.head, this.size) ← (new Array(k), 0, 0)
    function enqueue(x)
        if this.size = length(this.data) return false   // full
        tail ← (this.head + this.size) mod length(this.data)
        this.data[tail] ← x
        this.size ← this.size + 1
        return true
    function dequeue()
        x ← this.data[this.head]
        this.head ← (this.head + 1) mod length(this.data)
        this.size ← this.size - 1
        return x

Queue from Two Stacks

class MyQueue
    function init()
        this.in ← []
        this.out ← []
    function push(x)
        this.in.push(x)
    function pop()
        if this.out.isEmpty()
            while not this.in.isEmpty()
                this.out.push(this.in.pop())
        return this.out.pop()

// each item moves in → out once:
// O(1) amortized per operation

⚠ Common Mistakes

  • Using an array's shift / pop(0) as a queue: O(n) per dequeue
  • Forgetting the mod wrap in a circular buffer: index runs off the end
  • Distinguishing full vs empty by head = tail alone: keep a size

✓ Tips & Best Practices

  • BFS always uses a queue; a stack there would make it DFS
  • Use a deque when you need both ends (sliding windows, 0-1 BFS)
  • A JS queue: keep an array plus a moving head index

Quick Summary

  • enqueue / dequeue — FIFO, O(1)
  • deque — O(1) at both ends
  • (head + size) mod k — ring buffer tail
  • two stacks — amortized O(1) queue
