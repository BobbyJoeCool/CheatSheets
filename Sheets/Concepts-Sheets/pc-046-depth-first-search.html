Depth-First Search

recursive DFS · iterative with stack · visited set · connected components · path exists · clone graph

Go Deep, Then Backtrack

Depth-first search follows one path as far as it can, then backs up and tries the next branch. A visited set prevents infinite loops on cycles. DFS answers reachability questions, counts connected components, detects cycles, and drives backtracking. Recursive or with an explicit stack, it runs in O(V + E) time and O(V) space.

Recognize It When

  • "Is there a path from A to B?"
  • "How many groups / islands / provinces?"
  • "Copy / explore the whole structure"
  • Order doesn't need to be nearest-first

Recursive DFS and Components

function dfs(u, adj, visited)
    visited.add(u)
    for each v in adj[u]
        if not visited.has(v)
            dfs(v, adj, visited)

function countComponents(n, adj)
    visited ← new Set()
    count ← 0
    for u ← 0 to n - 1
        if not visited.has(u)
            dfs(u, adj, visited)     // one component
            count ← count + 1
    return count

Iterative DFS (Explicit Stack)

function dfsIterative(start, adj)
    visited ← new Set([start])
    stack ← [start]
    while not stack.isEmpty()
        u ← stack.pop()
        visit(u)
        for each v in adj[u]
            if not visited.has(v)
                visited.add(v)
                stack.push(v)

// same as BFS, but a stack instead of a queue
// avoids recursion-depth limits

Clone Graph

function cloneGraph(node)
    copies ← new Map()               // original → clone
    function clone(n)
        if copies.has(n) return copies[n]
        c ← new GraphNode(n.val)
        copies[n] ← c                // register BEFORE recursing
        for each nb in n.neighbors
            c.neighbors.append(clone(nb))
        return c
    return if node = null then null else clone(node)

⚠ Common Mistakes

  • Marking visited after the recursive call: cycles recurse forever
  • Forgetting the outer loop over all nodes: disconnected parts are skipped
  • Recursing 10⁵ levels deep in Python: switch to the iterative version

✓ Tips & Best Practices

  • The map in Clone Graph doubles as the visited set
  • Track the path (push before, pop after) when you need the route itself
  • Reset visited between independent searches

Quick Summary

  • visited — prevents revisits and loops
  • outer loop — one DFS per component
  • stack — iterative DFS
  • O(V + E) — time
