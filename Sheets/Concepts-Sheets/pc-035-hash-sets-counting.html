Hash Sets & Counting Patterns

set membership · dedupe · frequency map · complement lookup (Two Sum) · group by key · longest consecutive sequence

The Most-Used Interview Tool

A hash set answers "have I seen this?" in O(1); a hash map answers "how many?" or "where?". Replacing an inner search loop with a lookup is the single most common way to turn O(n²) into O(n). The art is choosing the key: the value itself, its complement, or a canonical form.

Recognize It When

  • "Find a pair that sums to …" (complement lookup)
  • "Contains duplicate", "first unique", "seen before"
  • "Group items that are equivalent" (canonical key)
  • Counts or frequencies of anything

Two Sum: Complement Lookup

function twoSum(nums, target)            // O(n) time, O(n) space
    seen ← new Map()                     // value → index
    for i ← 0 to length(nums) - 1
        need ← target - nums[i]
        if seen.has(need)
            return (seen[need], i)
        seen[nums[i]] ← i                // add AFTER checking
    return null

Group Anagrams: Canonical Key

function groupAnagrams(words)
    groups ← new Map()
    for each w in words
        key ← sorted(w)              // or 26-count tuple
        if not groups.has(key)
            groups[key] ← []
        groups[key].append(w)
    return values(groups)

// "eat","tea","ate" → key "aet"
// O(n · k log k), k = word length

Longest Consecutive Sequence

function longestConsecutive(nums)    // O(n)
    set ← toSet(nums)
    best ← 0
    for each x in set
        if not set.has(x - 1)        // x starts a run
            len ← 1
            while set.has(x + len)
                len ← len + 1
            best ← max(best, len)
    return best

⚠ Common Mistakes

  • Adding to seen before checking: a number can pair with itself
  • Sorting each word as a key for very long words: count tuples are O(k)
  • Starting the consecutive scan from every number: O(n²); only start at run heads

✓ Tips & Best Practices

  • Ask "what would I need to have seen?" and store exactly that
  • Use getOrDefault / Counter to keep counting code short
  • Sets trade memory for speed: mention O(n) space

Quick Summary

  • set.has(x) — O(1) membership
  • complement — target - x
  • canonical key — group equivalents
  • run heads — not has(x - 1)
