Tabulation & Space Optimization

Fill a Table Bottom-Up

Tabulation computes DP answers iteratively, smallest subproblems first, storing them in an array. It has no recursion overhead or depth limit, and it makes space optimization easy: if each row depends only on the previous one or two, keep just those. To output the actual solution (not just its value), walk back through the table.

Memo vs Table

  • Memo: only visits needed states; easy to write
  • Table: no stack limit; often faster; fill order matters
  • Fill order = an order where dependencies come first
  • Space: n² table → two rows → one row

Table, Then Rolling Variables

function climbStairs(n)            // O(n) space
    dp ← new Array(n + 1, 0)
    (dp[0], dp[1]) ← (1, 1)
    for i ← 2 to n                 // dependencies first
        dp[i] ← dp[i - 1] + dp[i - 2]
    return dp[n]

function climbStairsO1(n)          // O(1) space
    (prev2, prev1) ← (1, 1)
    for i ← 2 to n
        (prev2, prev1) ← (prev1, prev1 + prev2)
    return prev1

Two-Row Trick (LCS Length)

function lcsLength(a, b)           // O(m) space
    prev ← new Array(m + 1, 0)
    for i ← 1 to n
        cur ← new Array(m + 1, 0)
        for j ← 1 to m
            if a[i-1] = b[j-1]
                cur[j] ← prev[j-1] + 1
            else
                cur[j] ← max(prev[j], cur[j-1])
        prev ← cur                 // slide down
    return prev[m]

Reconstructing the Answer (LCS String)

// needs the full dp table from Sheet 083
(i, j, out) ← (n, m, [])
while i > 0 and j > 0
    if a[i-1] = b[j-1]
        out.append(a[i-1])          // part of the LCS
        (i, j) ← (i - 1, j - 1)
    else if dp[i-1][j] ≥ dp[i][j-1]
        i ← i - 1                   // came from above
    else
        j ← j - 1                   // came from the left
return reverse(out)

⚠ Common Mistakes

  • Wrong fill order: reading a cell that hasn't been computed yet
  • Dropping to one row when cells need values from the same row's old version
  • Space-optimizing away the table you later need to reconstruct the answer

✓ Tips & Best Practices

  • Write the memo version first, then convert: each recursive call becomes a table read
  • Pad tables with an extra row/column of base values to avoid bounds checks
  • Keep the full table in interviews unless asked to optimize space

Quick Summary

  • tabulation — bottom-up loops
  • rolling variables — O(1) for 1D
  • two rows — O(m) for 2D
  • walk back — rebuild the solution
