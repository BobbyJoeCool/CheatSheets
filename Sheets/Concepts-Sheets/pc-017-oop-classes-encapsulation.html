Bundling Data with Behavior

A class is a blueprint; an object (instance) is one thing built from it. The constructor sets up each new object's fields, and methods act on them through this / self. Encapsulation hides the fields and exposes only safe operations, so objects can't be put into invalid states.

Vocabulary

  • Field / attribute: data stored in each object
  • Method: function that belongs to the class
  • Static: belongs to the class, shared by all instances
  • Getter / setter: controlled access to a field

A Complete Class

class BankAccount
    static count ← 0                       // shared by every instance
    private balance                        // hidden field

    function init(owner, opening ← 0)      // constructor
        this.owner ← owner
        this.balance ← opening
        BankAccount.count ← BankAccount.count + 1

    function deposit(amount)               // method guards the invariant
        if amount ≤ 0
            throw ValueError("amount must be positive")
        this.balance ← this.balance + amount

    function getBalance()                  // getter: read-only access
        return this.balance

acct ← new BankAccount("Ada", 100)         // create an instance
acct.deposit(50)
acct.getBalance()                          // 150
acct.balance ← -5                          // error: balance is private
BankAccount.count                          // 1

Code Explained

class — blueprint for objects
init — constructor runs on new
this — the current object (self in Python)
private — only the class's own methods can touch it
static — one copy for the whole class
methods validate input so state stays valid

⚠ Common Mistakes

  • Making every field public, then validating everywhere it's changed
  • Forgetting this. / self.: assigns a local variable instead of the field
  • Storing per-object data in a static field: every instance shares it

✓ Tips & Best Practices

  • Keep invariants (e.g. balance ≥ 0) inside the class's methods
  • Add getters freely; add setters only when outside code must change a field
  • In interviews, a small class per entity (Node, LRUCache) keeps code clear

Quick Summary

  • class / new — blueprint / instance
  • init — constructor sets fields
  • private — encapsulation
  • static — shared across instances
