Sheet 094

LRU & LFU Caches

hash map + doubly linked list · O(1) get / put · eviction · frequency buckets · min-frequency tracking

Fixed-Size Caches with O(1) Operations

An LRU cache evicts the least recently used key. Pair a hash map (key → node) with a doubly linked list ordered by recency: the map finds a node in O(1), the list moves or removes it in O(1). An LFU cache evicts the least frequently used key (ties: least recent), using frequency buckets and a running minimum frequency.

List Helpers

function remove(node)
    node.prev.next ← node.next
    node.next.prev ← node.prev
function addFront(node)       // after head
    (node.prev, node.next) ← (head, head.next)
    head.next.prev ← node
    head.next ← node

LRU Cache

class LRUCache
    function init(capacity)
        this.cap ← capacity
        this.map ← new Map()        // key → node
        (head, tail) ← (new Node(), new Node())
        link(head, tail)            // sentinels
    function get(key)
        if not this.map.has(key) return -1
        node ← this.map[key]
        remove(node)
        addFront(node)              // most recent
        return node.val
    function put(key, val)
        if this.map.has(key)
            remove(this.map[key])
        node ← new Node(key, val)
        addFront(node)
        this.map[key] ← node
        if length(this.map) > this.cap
            lru ← tail.prev         // oldest
            remove(lru)
            this.map.delete(lru.key)

LFU Cache

class LFUCache
    vals, freq ← new Map(), new Map()
    buckets ← freq → ordered set of keys
    minF ← 0
    function touch(key)
        f ← freq[key]
        buckets[f].remove(key)
        if f = minF and buckets[f] is empty
            minF ← f + 1
        freq[key] ← f + 1
        buckets[f + 1].add(key)   // newest last
    function get(key)
        if not vals.has(key) return -1
        touch(key)
        return vals[key]
    function put(key, v)
        if cap = 0 return
        if vals.has(key)
            vals[key] ← v
            touch(key)
            return
        if length(vals) = cap
            old ← first key in buckets[minF]
            buckets[minF].remove(old)
            delete vals[old] and freq[old]
        (vals[key], freq[key], minF) ← (v, 1, 1)
        buckets[1].add(key)

⚠ Common Mistakes

  • Evicting before inserting the new key when the key already existed
  • Storing only values in list nodes: eviction needs the key to delete from the map
  • LFU: forgetting to reset minF to 1 when inserting a new key

✓ Tips & Best Practices

  • Shortcuts: Python OrderedDict, Java LinkedHashMap with access order
  • Practice: LRU Cache, LFU Cache, Design Browser History
  • Mention thread safety (a lock) if asked about production use

Quick Summary

  • map + doubly linked list — LRU
  • front = newest, back = evict
  • freq buckets + minF — LFU
  • sentinels — no edge cases
