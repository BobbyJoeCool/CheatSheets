Sorting Without Comparisons

Comparison sorts can't beat O(n log n). When keys are small integers (or can be split into digits), you can place items directly by value instead. Counting sort tallies each value, radix sort runs a stable counting pass per digit, and bucket sort spreads items into ranges. They run in O(n + k), where k is the value range or bucket count.

Recognize It When

  • Values in a small range (0…100, letters, ages)
  • Frequencies are bounded by n → bucket by frequency
  • Fixed-width keys: digits, dates, IP addresses
  • "Linear time" is required and keys are integers

Counting Sort

function countingSort(a, k)     // values 0..k-1
    count ← new Array(k, 0)
    for each x in a
        count[x] ← count[x] + 1
    i ← 0
    for v ← 0 to k - 1
        repeat count[v] times
            a[i] ← v
            i ← i + 1

// stable version (for records):
// prefix-sum the counts, then place
// items from right to left

Radix Sort (LSD, Base 10)

function radixSort(a)           // non-negative ints
    exp ← 1
    while max(a) div exp > 0
        buckets ← 10 empty lists
        for each x in a
            d ← (x div exp) mod 10
            buckets[d].append(x)    // stable
        a ← concat(buckets)
        exp ← exp * 10
    return a
// O(d · (n + 10)), d = digit count

Bucket by Frequency: Top K Frequent

function topKFrequent(nums, k)
    count ← frequency map of nums
    buckets ← n + 1 empty lists          // index = frequency
    for each (x, c) in count
        buckets[c].append(x)
    result ← []
    for f ← length(nums) down to 1
        for each x in buckets[f]
            result.append(x)
            if length(result) = k return result

⚠ Common Mistakes

  • Counting sort on values up to 10⁹: the count array is far too big
  • Radix sort with an unstable per-digit pass: later digits scramble earlier work
  • Negative numbers in radix sort: offset them or sort negatives separately

✓ Tips & Best Practices

  • Sort Colors and H-Index are counting-sort problems in disguise
  • Maximum Gap: buckets by range give O(n) via the pigeonhole principle
  • Letters: a count[26] array is a counting sort

Quick Summary

  • counting — tally, then rewrite
  • radix — stable pass per digit
  • bucket — group by range or frequency
  • O(n + k) — beats n log n for small k
