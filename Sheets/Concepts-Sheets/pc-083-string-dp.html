Two Strings, One Table

Two-string DP uses dp[i][j] = the answer for the prefixes a[0..i−1] and b[0..j−1]. Each cell looks at three neighbors: diagonal (both characters used, usually when they match), up (drop a char of a), and left (drop a char of b). Row 0 and column 0 hold the empty-string base cases.

Recognize It When

  • Two sequences compared: subsequence, alignment, edits
  • "Minimum operations to convert a into b"
  • Pattern matching with ?, *, or .
  • One string vs its reverse → palindromic subsequence

Longest Common Subsequence

function lcs(a, b)
    dp ← (n+1) × (m+1) grid of 0
    for i ← 1 to n
        for j ← 1 to m
            if a[i-1] = b[j-1]
                dp[i][j] ← dp[i-1][j-1] + 1
            else
                dp[i][j] ← max(dp[i-1][j],
                               dp[i][j-1])
    return dp[n][m]
// LPS(s) = lcs(s, reverse(s))

Edit Distance

function minDistance(a, b)
    dp[i][0] ← i, dp[0][j] ← j     // base
    for i ← 1 to n
        for j ← 1 to m
            if a[i-1] = b[j-1]
                dp[i][j] ← dp[i-1][j-1]
            else
                dp[i][j] ← 1 + min(
                    dp[i-1][j],      // delete
                    dp[i][j-1],      // insert
                    dp[i-1][j-1])    // replace
    return dp[n][m]

Wildcard Matching (? and *)

function isMatch(s, p)
    dp ← (n+1) × (m+1) grid of false
    dp[0][0] ← true
    for j ← 1 to m                  // * can match empty
        dp[0][j] ← dp[0][j-1] and p[j-1] = '*'
    for i ← 1 to n
        for j ← 1 to m
            if p[j-1] = '*'
                dp[i][j] ← dp[i][j-1] or dp[i-1][j]
            else if p[j-1] = '?' or p[j-1] = s[i-1]
                dp[i][j] ← dp[i-1][j-1]
    return dp[n][m]

⚠ Common Mistakes

  • Off-by-one between dp indexes and string indexes: dp[i] refers to a[i − 1]
  • Forgetting base row/column: edit distance needs dp[i][0] = i
  • Regex x*: treating * alone instead of as a pair with the char before it

✓ Tips & Best Practices

  • Practice: LCS, Edit Distance, Longest Palindromic Subsequence, Distinct Subsequences, Wildcard / Regex Matching
  • Draw the table for two 3-letter strings before coding
  • Only the previous row is needed for the length: O(min(n, m)) space

Quick Summary

  • dp[i][j] — prefixes of a and b
  • diagonal — both chars used
  • up / left — skip a char
  • row 0 / col 0 — empty-string base
