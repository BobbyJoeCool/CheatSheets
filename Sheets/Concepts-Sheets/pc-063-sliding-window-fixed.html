Sliding Window — Fixed Size

add right / drop left · window sum / average · max sum of size k · permutation in string · find all anagrams

A Window That Slides One Step at a Time

For questions about every contiguous block of size k, don't recompute each block. Keep a running summary of the current window, and as it slides right, add the new item and remove the one that fell off the left. Each step is O(1) (or O(26) for letter counts), so the whole scan is O(n) instead of O(n·k).

Recognize It When

  • "Subarray / substring of length k"
  • "Average / sum / max of every window"
  • "Permutation / anagram of p inside s" (window = len(p))
  • Window size is fixed by the problem

Find All Anagrams (Fixed Window of Letter Counts)

function findAnagrams(s, p)
    k ← length(p)
    need ← letterCounts(p)                        // count[26]
    have ← new Array(26, 0)
    out ← []
    for r ← 0 to length(s) - 1
        have[idx(s[r])] ← have[idx(s[r])] + 1             // add right
        if r ≥ k
            have[idx(s[r - k])] ← have[idx(s[r - k])] - 1   // drop left
        if r ≥ k - 1 and have = need              // 26 compares: O(1)
            out.append(r - k + 1)                 // window start
    return out

Code Explained

idx(c) — code(c) - code('a')
window is s[r-k+1 .. r]
drop s[r - k] once the window is full
have = need — compare two count arrays
Permutation in String: return true on first match

Max Sum of k Consecutive Items

function maxSumK(arr, k)
    window ← 0
    for i ← 0 to k - 1
        window ← window + arr[i]
    best ← window
    for r ← k to length(arr) - 1
        window ← window + arr[r] - arr[r - k]
        best ← max(best, window)
    return best

⚠ Common Mistakes

  • Off-by-one on the drop index: the item leaving is arr[r - k]
  • Recording a result before the first window is full (r < k − 1)
  • Re-summing the window each step: back to O(n·k)

✓ Tips & Best Practices

  • Track a matches counter of letters with equal counts for O(1) per step
  • Window max/min needs a monotonic deque, not a running value
  • Average = window sum ÷ k; compare sums to avoid float error

Quick Summary

  • add right, drop left — O(1) per step
  • window [r − k + 1, r]
  • count arrays — anagram windows
  • O(n) — total time
