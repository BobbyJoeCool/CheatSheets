Hash Maps

hash function · buckets · chaining vs open addressing · load factor · O(1) average · hashable keys · iteration order

Key → Value in O(1) Average

A hash map runs each key through a hash function to pick a bucket in an array, so lookups skip searching. Different keys can land in the same bucket (collision); buckets hold a short list (chaining) or probe to the next free slot (open addressing). When the load factor (items ÷ buckets) gets high, the table doubles and rehashes.

Costs

  • get / put / delete: O(1) average
  • Worst case O(n): everything in one bucket
  • Resize: O(n), but O(1) amortized per insert
  • No ordering by key (use a tree map for that)

Inside put / get, and Everyday Use

function put(key, value)                  // separate chaining
    i ← hash(key) mod capacity            // choose a bucket
    for each entry in buckets[i]
        if entry.key = key
            entry.value ← value           // update existing key
            return
    buckets[i].append((key, value))
    size ← size + 1
    if size / capacity > 0.75             // load factor limit
        resize(capacity * 2)              // rehash all entries

function get(key)
    i ← hash(key) mod capacity
    for each entry in buckets[i]
        if entry.key = key return entry.value
    return null

ages ← new Map()
ages["ada"] ← 36
ages.has("bob")                           // false
ages.getOrDefault("bob", 0)               // 0

Code Explained

hash(key) — turns the key into an integer
mod capacity — maps it onto a bucket
update vs insert — keys are unique
0.75 — common default load factor
resize — new array, re-insert every entry
getOrDefault — avoids missing-key errors

⚠ Common Mistakes

  • Using a mutable list as a key: Python rejects it; elsewhere a changed key gets lost
  • Overriding equals without hashCode (Java): equal keys land in different buckets
  • Relying on HashMap iteration order: it can change between runs

✓ Tips & Best Practices

  • Use a tuple or string as a composite key: (row, col) or "r,c"
  • Use a counting helper (Counter, getOrDefault) instead of if has … else …
  • Need sorted keys or floor/ceiling lookups? Use a tree map (Sheet 040)

Quick Summary

  • hash(key) mod n — bucket index
  • collision — chaining or probing
  • load factor — triggers resize
  • O(1) avg · O(n) worst
