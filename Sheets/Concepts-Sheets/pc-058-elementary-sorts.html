Elementary Sorts

bubble · selection · insertion · stable vs unstable · in-place · nearly sorted input

The Simple O(n²) Sorts

Bubble, selection, and insertion sort are slow on big inputs but worth knowing: they're the base cases inside real library sorts, they introduce stability and in-place sorting, and their inner loops show up in interview problems. Insertion sort is the useful one: O(n) on nearly sorted data and fastest for tiny arrays.

Terms

  • Stable: equal items keep their original order
  • In-place: O(1) extra memory
  • Adaptive: faster when input is nearly sorted
  • Library sorts switch to insertion sort below ~16–32 items

Bubble Sort

function bubbleSort(a)        // swap adjacent pairs
    n ← length(a)
    for i ← 0 to n - 2
        swapped ← false
        for j ← 0 to n - 2 - i
            if a[j] > a[j + 1]
                swap(a, j, j + 1)
                swapped ← true
        if not swapped
            break             // sorted: O(n) best
// after pass i, the largest i+1 items are final

Selection Sort

function selectionSort(a)     // pick min of the rest
    n ← length(a)
    for i ← 0 to n - 2
        m ← i
        for j ← i + 1 to n - 1
            if a[j] < a[m]
                m ← j
        swap(a, i, m)         // only n - 1 swaps
// unstable: the long swap can jump
// over an equal item

Insertion Sort

function insertionSort(a)     // sorted prefix
    for i ← 1 to length(a) - 1
        x ← a[i]
        j ← i - 1
        while j ≥ 0 and a[j] > x
            a[j + 1] ← a[j]   // shift right
            j ← j - 1
        a[j + 1] ← x          // into the gap

⚠ Common Mistakes

  • Using a[j] ≥ x in insertion sort: moves equal items and breaks stability
  • Calling selection sort stable: its swaps reorder equal keys
  • Writing these in an interview when sort() is allowed: use the library

✓ Tips & Best Practices

  • Insertion sort is ideal for streams of items arriving in nearly sorted order
  • Selection sort minimizes writes: useful when writes are expensive
  • Practice: Sort Colors (Dutch flag), Insertion Sort List, Sort an Array

Quick Summary

  • bubble — adjacent swaps, early exit
  • selection — min of the rest, fewest swaps
  • insertion — shift into sorted prefix
  • O(n²) — fine only for small n
