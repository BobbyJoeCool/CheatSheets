Kadane's Algorithm & Subarrays

max subarray sum · reset rule · tracking indices · max product subarray · circular subarray · best time to buy / sell stock

Best Subarray in One Pass

Kadane's algorithm finds the maximum-sum contiguous subarray in O(n). At each index, the best subarray ending here either extends the previous one or restarts at this element, whichever is larger. The overall answer is the best of those. The same idea solves product subarrays (track min and max) and the classic stock-profit problem.

Recognize It When

  • "Maximum / minimum sum of a contiguous subarray"
  • "Maximum product subarray" (negatives flip signs)
  • Buy once, sell once for max profit
  • Circular arrays: max of normal vs total − min subarray

Kadane: Extend or Restart

function maxSubArray(nums)
    cur ← nums[0]                 // best ending here
    best ← nums[0]                // best seen anywhere
    for i ← 1 to length(nums) - 1
        cur ← max(nums[i], cur + nums[i])
        best ← max(best, cur)
    return best

// circular: max(best, total - minSubarray)
// unless every number is negative

Tracking the Indices

function maxSubArrayRange(nums)
    (cur, start) ← (0, 0)
    (best, bl, br) ← (-∞, 0, 0)
    for i ← 0 to length(nums) - 1
        if cur ≤ 0
            (cur, start) ← (nums[i], i)   // restart
        else
            cur ← cur + nums[i]
        if cur > best
            (best, bl, br) ← (cur, start, i)
    return (best, bl, br)

Maximum Product Subarray

function maxProduct(nums)
    (hi, lo, best) ← (nums[0], nums[0], nums[0])
    for i ← 1 to length(nums) - 1
        x ← nums[i]
        c ← (x, hi * x, lo * x)
        (hi, lo) ← (max(c), min(c))  // sign flips
        best ← max(best, hi)
    return best

Best Time to Buy and Sell Stock

function maxProfit(prices)
    (minPrice, profit) ← (∞, 0)
    for each p in prices
        minPrice ← min(minPrice, p)
        profit ← max(profit, p - minPrice)
    return profit
// = Kadane on daily price differences

⚠ Common Mistakes

  • Starting best at 0: wrong when every number is negative
  • Tracking only the max in product subarrays: a negative times the min becomes the new max
  • Updating hi before computing lo with the old value: compute both from a saved tuple

✓ Tips & Best Practices

  • Practice: Maximum Subarray, Max Product Subarray, Max Sum Circular Subarray, Best Time to Buy and Sell Stock
  • Kadane is 1D DP with O(1) state (Sheet 080)
  • Max sum rectangle in a matrix: fix two rows, run Kadane on column sums

Quick Summary

  • cur = max(x, cur + x) — extend or restart
  • best — max over all cur
  • track hi and lo — products
  • min so far — stock profit
