Reusable Greedy Moves

Most greedy interview problems use one of a handful of moves: sort by end time and keep what fits, schedule the most frequent item first, extend a segment until everything inside it is closed, sort by a difference (cost saved), or merge the two smallest repeatedly (Huffman). Recognizing the move is most of the work.

Quick Facts

  • Activity selection: sort by end, keep non-overlapping (Sheet 069)
  • Huffman coding: optimal prefix code via a min-heap
  • Scheduling with cooldown: the most frequent task sets the frame
  • Pairing problems: sort, then two pointers

Task Scheduler

function leastInterval(tasks, n)    // cooldown n
    freq ← counts of each task
    maxF ← max(freq)
    numMax ← tasks with frequency maxF
    // A _ _ A _ _ A   (maxF − 1) frames of n + 1
    frame ← (maxF - 1) * (n + 1) + numMax
    return max(frame, length(tasks))

// if tasks overflow the frame,
// no idle slots are needed

Partition Labels

function partitionLabels(s)
    last ← map char → last index in s
    (start, end, out) ← (0, 0, [])
    for i ← 0 to length(s) - 1
        end ← max(end, last[s[i]])
        if i = end              // all chars closed
            out.append(end - start + 1)
            start ← i + 1
    return out
// "ababcbacadefegdehijhklij" → [9, 7, 8]

Huffman Coding (Total Bits)

function huffmanCost(freqs)
    heap ← new MinHeap(freqs)
    total ← 0
    while heap.size() > 1
        a ← heap.pop()          // two rarest
        b ← heap.pop()
        total ← total + a + b   // merge cost
        heap.push(a + b)
    return total
// same shape: Min Cost to Connect Sticks

⚠ Common Mistakes

  • Task Scheduler: forgetting max(frame, length(tasks)) when there are many task types
  • Partition Labels: cutting at the first repeat instead of the furthest last index
  • Hand of Straights: starting runs from arbitrary cards instead of the smallest

✓ Tips & Best Practices

  • Write the greedy rule in one sentence before coding it
  • Ties matter: decide the tie-break order explicitly when sorting
  • Practice: Task Scheduler, Partition Labels, Two City Scheduling, Hand of Straights
