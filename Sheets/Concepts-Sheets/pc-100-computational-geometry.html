Points, Lines, and Shapes

Most geometry problems reduce to the cross product: its sign says whether three points turn left, turn right, or are collinear. Compare squared distances to avoid square roots, and store slopes as reduced integer fractions (via gcd) instead of floats. Sorting points plus cross products gives the convex hull in O(n log n).

Exactness Rules

  • Prefer integer math: no /, no sqrt, no float slopes
  • Normalize slope signs so (1, −2) and (−1, 2) match
  • Manhattan distance for grid moves; Euclidean for straight lines
  • Touching edges: decide if they count as overlap

Cross Product and Max Points on a Line

function cross(o, a, b)        // > 0 left · < 0 right · 0 collinear
    return (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x)

function maxPoints(pts)                         // O(n²)
    best ← 1
    for i ← 0 to n - 1
        slopes ← new Map()
        for j ← i + 1 to n - 1
            (dx, dy) ← (pts[j].x - pts[i].x, pts[j].y - pts[i].y)
            g ← gcd(abs(dx), abs(dy))
            (dx, dy) ← (dx div g, dy div g)     // reduced fraction
            if dx < 0 or (dx = 0 and dy < 0)
                (dx, dy) ← (-dx, -dy)           // one sign convention
            slopes[(dx, dy)] ← slopes.getOrDefault((dx, dy), 0) + 1
            best ← max(best, slopes[(dx, dy)] + 1)
    return best

Convex Hull (Monotone Chain)

function convexHull(pts)          // O(n log n)
    sort(pts) by (x, y)
    function half(seq)
        h ← []
        for each p in seq         // k = length(h)
            while k ≥ 2 and cross(h[k-2], h[k-1], p) ≤ 0
                h.pop()           // not a left turn
            h.append(p)
        h.pop()                   // shared endpoint
        return h
    return half(pts) + half(reverse(pts))

Rectangles and Polygons

function overlap(a, b)        // (x1, y1, x2, y2)
    w ← min(a.x2, b.x2) - max(a.x1, b.x1)
    h ← min(a.y2, b.y2) - max(a.y1, b.y1)
    return w > 0 and h > 0    // area = w * h

⚠ Common Mistakes

  • Storing slopes as floats: 1/3 and 2/6 may differ in the last bit
  • Computing sqrt to compare distances: compare squared values instead
  • Convex hull with < 0 instead of ≤ 0: keeps collinear points (decide which you want)

✓ Tips & Best Practices

  • Practice: Max Points on a Line, Rectangle Overlap, Rectangle Area, Erect the Fence, K Closest Points
  • Use 64-bit ints for cross products of coordinates up to 10⁹
  • Rotate 45° (u = x + y, v = x − y) to turn Manhattan into Chebyshev distance

Quick Summary

  • cross(o, a, b) — turn direction
  • squared distance — no sqrt
  • gcd-reduced slope — exact lines
  • monotone chain — hull in O(n log n)
