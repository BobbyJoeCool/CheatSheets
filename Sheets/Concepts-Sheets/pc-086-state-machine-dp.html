State Machine DP

A Few States per Step

Some problems are a walk through days or items where you're always in one of a few states (holding a stock or not, cooling down, which color was used last). Keep one value per state, and for each new item compute every state's best from the previous step's states using the allowed transitions. It's 1D DP with a small extra dimension.

Recognize It When

  • Stock problems with cooldown, fees, or k trades
  • "Adjacent items can't share a color / choice"
  • Rules like "after X you must Y"
  • Draw the state diagram first; code follows it

Stock with Cooldown

function maxProfit(prices)
    (hold, sold, rest) ← (-∞, 0, 0)
    for each p in prices
        (hold, sold, rest) ←
            (max(hold, rest - p),   // keep or buy
             hold + p,              // sell today
             max(rest, sold))       // idle / cool down
    return max(sold, rest)

State Diagram

  [rest] ---------> [hold]  (keep)
   ^  (idle)           |
   |                   | sell
   |    cooldown       v
   +-------------- [sold]

At Most k Transactions

function maxProfitK(k, prices)
    buy ← new Array(k + 1, -∞)
    sell ← new Array(k + 1, 0)
    for each p in prices
        for t ← 1 to k
            buy[t] ← max(buy[t], sell[t - 1] - p)
            sell[t] ← max(sell[t], buy[t] + p)
    return sell[k]
// k ≥ n/2 → unlimited: sum every rise

Fee · Paint House

function maxProfitFee(prices, fee)
    (hold, cash) ← (-prices[0], 0)
    for each p in prices[1..]
        (hold, cash) ← (max(hold, cash - p),
                        max(cash, hold + p - fee))
    return cash

function minCost(costs)    // 3 colors
    (r, g, b) ← (0, 0, 0)
    for each (cr, cg, cb) in costs
        (r, g, b) ← (cr + min(g, b),
                     cg + min(r, b),
                     cb + min(r, g))
    return min(r, g, b)

⚠ Common Mistakes

  • Updating states one at a time so a new value feeds another update in the same step
  • Allowing a buy straight from sold in the cooldown version
  • Starting hold at 0: you can't hold a stock you never paid for

✓ Tips & Best Practices

  • Practice: Best Time to Buy and Sell Stock II, III, IV, with Cooldown, with Fee; Paint House
