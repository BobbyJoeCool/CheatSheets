Heap Patterns: Top-K, Merge K & Two Heaps

k largest (min-heap of size k) · kth element · merge k sorted lists · two heaps median · task scheduling

Heaps in Interview Problems

Reach for a heap whenever you repeatedly need the current smallest or largest item while items keep arriving or changing. Three shapes cover most problems: a size-k heap for top-k, a heap of list heads to merge k sorted sources, and two heaps split at the median.

Recognize It When

  • "k largest / smallest / closest / most frequent"
  • "merge k sorted …"
  • "running median", "data stream"
  • Scheduling by earliest end time or highest count

Top-K: Min-Heap of Size k

function kthLargest(nums, k)       // O(n log k), O(k)
    heap ← new MinHeap()
    for each x in nums
        heap.push(x)
        if heap.size() > k
            heap.pop()             // drop the smallest
    return heap.peek()             // kth largest
// k smallest: use a max-heap of size k

Merge k Sorted Lists

function mergeK(lists)              // O(N log k)
    heap ← new MinHeap()            // (val, i, node)
    for i ← 0 to length(lists) - 1
        if lists[i] ≠ null
            heap.push((lists[i].val, i, lists[i]))
    dummy ← new Node(0)
    tail ← dummy
    while not heap.isEmpty()
        (v, i, node) ← heap.pop()
        tail.next ← node
        tail ← node
        if node.next ≠ null
            heap.push((node.next.val, i, node.next))
    return dummy.next

Two Heaps: Running Median

class MedianFinder
    low ← new MaxHeap()             // smaller half
    high ← new MinHeap()            // larger half
    function add(x)
        low.push(x)
        high.push(low.pop())        // pass max up
        if high.size() > low.size()
            low.push(high.pop())    // keep low ≥ high
    function median()
        if low.size() > high.size()
            return low.peek()
        return (low.peek() + high.peek()) / 2

⚠ Common Mistakes

  • Using a max-heap of all n items for top-k: O(n log n) instead of O(n log k)
  • Pushing nodes without a tiebreak index: equal values make the heap compare nodes
  • Letting the two median heaps drift more than one apart in size

✓ Tips & Best Practices

  • Top-k by frequency with small counts: bucket sort is O(n) (Sheet 060)
  • Quickselect finds the kth element in O(n) average (Sheet 061)
  • Lazy deletion: mark removed items and skip them when they reach the top

Quick Summary

  • size-k min-heap — k largest
  • heap of heads — merge k sorted
  • two heaps — median in O(log n)
  • heap of end times — room counting
