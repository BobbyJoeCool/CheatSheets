Stacks

LIFO · push / pop / peek · valid parentheses · min stack · evaluate RPN · undo history · array-backed stack

Last In, First Out

A stack only touches its top: push adds, pop removes the most recent item, peek looks without removing. All are O(1). Stacks model anything nested or most-recent-first: matching brackets, undo history, expression evaluation, and the call stack that makes recursion work.

Recognize It When

  • Matching pairs or nesting: ()[]{}, tags
  • "Most recent" item matters (undo, backspace)
  • Evaluate or parse expressions
  • Next greater / smaller element → monotonic stack (067)

Valid Parentheses

function isValid(s)
    pairs ← { ')': '(', ']': '[', '}': '{' }
    stack ← []
    for each c in s
        if c in "([{"
            stack.push(c)
        else if stack.isEmpty()
            return false             // no opener
        else if stack.pop() ≠ pairs[c]
            return false             // wrong opener
    return stack.isEmpty()       // unclosed = invalid

Evaluate Reverse Polish Notation

// ["2", "1", "+", "3", "*"]  →  (2 + 1) * 3 = 9
function evalRPN(tokens)
    stack ← []
    for each t in tokens
        if t in ["+", "-", "*", "/"]
            b ← stack.pop()          // right operand
            a ← stack.pop()
            stack.push(apply(t, a, b))
        else
            stack.push(toInt(t))
    return stack.pop()

Min Stack: O(1) getMin

class MinStack
    function init()
        this.items ← []
        this.mins ← []                 // top = current minimum
    function push(x)
        this.items.push(x)
        if this.mins.isEmpty() or x ≤ this.mins.peek()
            this.mins.push(x)
    function pop()
        x ← this.items.pop()
        if x = this.mins.peek()
            this.mins.pop()
        return x
    function getMin()
        return this.mins.peek()

⚠ Common Mistakes

  • Popping an empty stack: check isEmpty() first
  • Pushing ≤ vs < in MinStack: duplicates of the min must be pushed too
  • Operand order in RPN: a - b needs b popped first

✓ Tips & Best Practices

  • A dynamic array is a stack: append / pop from the end
  • Store indexes, not values, when you'll need positions later
  • Convert recursion to iteration with an explicit stack

Quick Summary

  • push / pop / peek — all O(1)
  • LIFO — most recent first
  • brackets — push opens, match on close
  • two stacks — O(1) min
