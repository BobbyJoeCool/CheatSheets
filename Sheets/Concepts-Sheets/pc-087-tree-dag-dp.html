DP on Trees and DAGs

On a tree, compute each node's DP values in post-order: children first, then combine. Return a small tuple of states (e.g. best if this node is used vs. not used). On a DAG, process nodes in topological order so every predecessor is final before you use it. Rerooting gets the answer for every possible root in two passes.

Recognize It When

  • Choose nodes with rules about parent/child ("no two adjacent")
  • Longest / heaviest path in a tree or DAG
  • Answer needed "for every node as root"
  • Covering nodes (cameras, guards) at minimum cost

House Robber III

function rob(root)
    function dfs(node)        // → (robThis, skipThis)
        if node = null return (0, 0)
        (lr, ls) ← dfs(node.left)
        (rr, rs) ← dfs(node.right)
        robThis ← node.val + ls + rs
        skipThis ← max(lr, ls) + max(rr, rs)
        return (robThis, skipThis)
    return max(dfs(root))

Longest Path in a DAG

function longestPath(n, adj)  // adj[u] = [(v, w)]
    order ← topoSort(n, adj)  // Sheet 049
    dist ← new Array(n, 0)
    for each u in order
        for each (v, w) in adj[u]
            dist[v] ← max(dist[v], dist[u] + w)
    return max(dist)

Rerooting: Sum of Distances in Tree

function sumOfDistances(n, adj)
    size ← new Array(n, 1)
    ans ← new Array(n, 0)
    function post(u, p)             // root 0 answer
        for each v in adj[u] where v ≠ p
            post(v, u)
            size[u] ← size[u] + size[v]
            ans[u] ← ans[u] + ans[v] + size[v]
    function pre(u, p)              // shift root u → v
        for each v in adj[u] where v ≠ p
            ans[v] ← ans[u] - size[v] + (n - size[v])
            pre(v, u)
    post(0, -1)
    pre(0, -1)
    return ans

Binary Tree Cameras

function minCameras(root)
    cams ← 0
    // 0 needs cover · 1 covered · 2 camera
    function dfs(node)
        if node = null return 1
        (l, r) ← (dfs(node.left), dfs(node.right))
        if l = 0 or r = 0
            cams ← cams + 1
            return 2
        if l = 2 or r = 2 return 1
        return 0
    if dfs(root) = 0
        cams ← cams + 1
    return cams

⚠ Common Mistakes

  • Using max(robThis, skipThis) of a child when the parent is robbed: the child must be skipped
  • Longest path in a general graph with cycles: NP-hard; DAG only
  • Rerooting with only one pass: the second (top-down) pass is what moves the root

✓ Tips & Best Practices

  • Practice: House Robber III, Binary Tree Max Path Sum, Diameter, Sum of Distances in Tree, Cameras
  • Return tuples instead of recomputing children for each state
  • Iterative post-order avoids recursion limits on 10⁵-node trees

Quick Summary

  • post-order — children before parent
  • tuple of states — used / not used
  • topological order — DAG DP
  • rerooting — every node as root, O(n)
