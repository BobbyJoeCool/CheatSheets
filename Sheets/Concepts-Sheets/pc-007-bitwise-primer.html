Working with Individual Bits

Integers are stored in binary, and bitwise operators work on each bit position independently. They power fast parity checks, subsets-as-integers (bitmasks), and tricks like XOR-cancellation. This is a one-page primer; the Bitwise set covers two's complement, masks, and bit-DP in depth.

Notation

  • Bitwise uses C-style symbols: & | ^ ~ << >>
  • and / or stay boolean; & / | are bitwise
  • Bit i is worth 2^i; bit 0 is the rightmost
  • Negative numbers use two's complement: -x = ~x + 1

Operators and Classic Tricks

// x = 12 = 1100₂   y = 10 = 1010₂
x & y            // 1000₂ = 8    AND: both bits set
x | y            // 1110₂ = 14   OR: either bit set
x ^ y            // 0110₂ = 6    XOR: bits differ
~x               // -13          NOT: flip every bit
x << 1           // 11000₂ = 24  shift left = × 2
x >> 2           // 11₂ = 3      shift right = div 4

(x >> i) & 1     // read bit i
x | (1 << i)     // set bit i
x & ~(1 << i)    // clear bit i
x ^ (1 << i)     // toggle bit i
x & 1 = 1        // x is odd
x & (x - 1)      // drop lowest set bit · = 0 → power of 2
x & -x           // keep only lowest set bit
a ^ a = 0        // XOR cancels pairs: XOR of all = the single one

Code Explained

& — mask: keep only selected bits
| — turn bits on
^ — toggle; a ^ b ^ b = a
<< / >> — fast × / ÷ by powers of 2
x & (x - 1) — used to count set bits
x & -x — lowbit (Fenwick trees, Sheet 093)

⚠ Common Mistakes

  • Precedence: x & 1 = 1 parses as x & (1 = 1) in C/Java/JS; add parentheses
  • Right-shifting negatives: arithmetic >> keeps the sign; use >>> (Java/JS) for logical shift
  • Shifting by ≥ word size (e.g. 1 << 32 on int32) is undefined or wraps

✓ Tips & Best Practices

  • Write binary in comments when debugging (1100₂)
  • Use 1L << i (Java) or 64-bit types for masks above bit 30
