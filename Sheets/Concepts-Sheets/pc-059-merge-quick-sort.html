Merge Sort & Quick Sort

divide & conquer · merge step · Lomuto / Hoare partition · pivot choice · worst case O(n²) · count inversions

The Divide-and-Conquer Sorts

Merge sort splits the array in half, sorts each half, then merges them: always O(n log n), stable, but needs O(n) extra space. Quick sort partitions around a pivot (smaller left, larger right) and recurses: O(n log n) on average, in place, but O(n²) if pivots are bad. A random pivot makes the worst case very unlikely.

Quick Facts

  • Merge sort: best for linked lists and external (disk) sorting
  • Quick sort: fastest in practice on arrays
  • Merge step counts inversions for free
  • Partition also powers quickselect (Sheet 061)

Merge Sort

function mergeSort(a, lo, hi)      // sorts a[lo..hi]
    if lo ≥ hi return
    mid ← (lo + hi) div 2
    mergeSort(a, lo, mid)
    mergeSort(a, mid + 1, hi)
    merge(a, lo, mid, hi)

function merge(a, lo, mid, hi)
    tmp ← []
    (i, j) ← (lo, mid + 1)
    while i ≤ mid and j ≤ hi
        if a[i] ≤ a[j]             // ≤ keeps it stable
            tmp.append(a[i])
            i ← i + 1
        else
            tmp.append(a[j])       // inv += mid - i + 1
            j ← j + 1
    append a[i..mid] and a[j..hi] to tmp
    copy tmp into a[lo..hi]

Quick Sort (Lomuto Partition)

function quickSort(a, lo, hi)
    if lo ≥ hi return
    p ← partition(a, lo, hi)
    quickSort(a, lo, p - 1)
    quickSort(a, p + 1, hi)

function partition(a, lo, hi)
    swap(a, randomInt(lo, hi), hi) // random pivot
    pivot ← a[hi]
    i ← lo                         // next small slot
    for j ← lo to hi - 1
        if a[j] < pivot
            swap(a, i, j)
            i ← i + 1
    swap(a, i, hi)                 // pivot to place
    return i

⚠ Common Mistakes

  • Always picking the last element as pivot: sorted input becomes O(n²)
  • Allocating a new array in every merge call: copy into one shared buffer
  • Using < in the merge comparison: breaks stability

✓ Tips & Best Practices

  • Count of Smaller Numbers After Self and Reverse Pairs: count during merge
  • Sort a linked list with merge sort: O(1) extra space, no random access needed
  • Many duplicates? Use 3-way partitioning

Quick Summary

  • merge sort — split, sort, merge; stable
  • quick sort — partition, recurse; in place
  • random pivot — avoids O(n²)
  • merge step — counts inversions
