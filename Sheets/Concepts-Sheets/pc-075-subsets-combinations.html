Choosing Subsets of Items

Subsets and combinations ignore order, so a start index stops you from reusing earlier items (which would create the same set in another order). Every node of the subset tree is an answer; for combinations, only nodes of the right size or sum are. With duplicate values, sort and skip a value equal to the previous one at the same depth.

Variants

  • Subsets: record at every node
  • k-combinations: record when length(path) = k
  • Combination Sum: reuse allowed → recurse with i
  • Combination Sum II: no reuse → i + 1 + skip duplicates

Subsets (and Subsets II)

function subsets(nums)          // 2ⁿ subsets
    sort(nums)                  // needed for II
    out ← []
    function bt(start, path)
        out.append(copy(path))  // every node
        for i ← start to length(nums) - 1
            if i > start and nums[i] = nums[i - 1]
                continue        // II: skip dup
            path.append(nums[i])
            bt(i + 1, path)
            path.pop()
    bt(0, [])
    return out

Combination Sum (Reuse Allowed)

function combinationSum(cands, target)
    sort(cands)
    out ← []
    function bt(start, path, remain)
        if remain = 0
            out.append(copy(path))
            return
        for i ← start to length(cands) - 1
            if cands[i] > remain
                break           // rest too big
            path.append(cands[i])
            bt(i, path, remain - cands[i])
            path.pop()
    bt(0, [], target)
    return out

k-Combinations

function combine(n, k)               // choose k of 1..n
    out ← []
    function bt(start, path)
        if length(path) = k
            out.append(copy(path))
            return
        need ← k - length(path)
        for i ← start to n - need + 1   // prune: room left
            path.append(i)
            bt(i + 1, path)
            path.pop()
    bt(1, [])
    return out

⚠ Common Mistakes

  • Skipping duplicates with i > 0 instead of i > start: drops valid sets like [1, 1]
  • Recursing with i + 1 when reuse is allowed (or i when it isn't)
  • Looping from 0 instead of start: generates the same set in different orders

✓ Tips & Best Practices

  • Bitmask subsets: for mask ← 0 to 2ⁿ − 1, take item i when (mask >> i) & 1 = 1
  • Sort once up front; it enables both break pruning and duplicate skipping
  • Need only the count? Use DP (knapsack, Sheet 082) instead

Quick Summary

  • start index — no reordering
  • i > start and equal — skip duplicates
  • bt(i, …) — reuse allowed
  • mask >> i & 1 — bitmask subsets
