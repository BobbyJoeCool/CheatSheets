Sheet 065

Prefix Sums & Difference Arrays

prefix[i] · range sum O(1) · subarray sum = k (prefix + map) · 2D prefix sums · difference array range updates · prefix XOR / product

Precompute Once, Answer in O(1)

A prefix sum array stores the running total up to each index, so any range sum is one subtraction. Combined with a hash map of prefix counts, it finds subarrays with a target sum even when numbers are negative (where sliding windows fail). A difference array is the reverse trick: apply many range updates in O(1) each, then rebuild with one prefix pass.

Recognize It When

  • Many range-sum queries on a fixed array
  • "Count subarrays with sum = k / divisible by k"
  • Many "add v to every item in [l, r]" updates
  • Matrix region sums (2D prefix)

Prefix Sums and Subarray Sum = k

prefix ← new Array(n + 1, 0)      // prefix[i] = sum arr[0..i-1]
for i ← 0 to n - 1
    prefix[i + 1] ← prefix[i] + arr[i]
// sum of arr[l..r] = prefix[r + 1] - prefix[l]

function subarraySum(nums, k)     // counts, negatives OK
    seen ← new Map()
    seen[0] ← 1                   // the empty prefix
    (sum, count) ← (0, 0)
    for each x in nums
        sum ← sum + x
        count ← count + seen.getOrDefault(sum - k, 0)
        seen[sum] ← seen.getOrDefault(sum, 0) + 1
    return count

diff ← new Array(n + 1, 0)
for each (l, r, v) in updates  // +v on [l..r]
    diff[l] ← diff[l] + v
    diff[r + 1] ← diff[r + 1] - v

⚠ Common Mistakes

  • Forgetting seen[0] ← 1: misses subarrays that start at index 0
  • Adding the current prefix to the map before looking up sum − k
  • Negative mod when grouping by remainder: normalize with ((s mod k) + k) mod k

✓ Tips & Best Practices

  • Use length n + 1 prefixes so prefix[0] = 0 and no index needs a special case
  • Difference arrays shine for "bookings", "car pooling", "flights"
  • If the array changes between queries, use a Fenwick tree (Sheet 093)

Quick Summary

  • prefix[r+1] − prefix[l] — range sum
  • map of prefix counts — subarray targets
  • difference array — O(1) range updates
  • 2D prefix — inclusion–exclusion
