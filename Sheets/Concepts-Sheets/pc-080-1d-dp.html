1D DP Patterns

climbing stairs · house robber · decode ways · coin change (min coins) · word break · jump game

One Index of State

In 1D DP, dp[i] answers the question for a prefix (first i items) or a suffix. Each problem differs only in its transition: which earlier states feed dp[i] and how they combine (add for counting ways, min / max for optimizing, or for feasibility). Most compress to O(1) space with rolling variables.

House Robber

function rob(nums)
    (prev2, prev1) ← (0, 0)
    for each x in nums
        cur ← max(prev1, prev2 + x)  // skip or take
        (prev2, prev1) ← (prev1, cur)
    return prev1
// circular street (Robber II):
// max(rob(nums[1..]), rob(nums[..n-2]))

Decode Ways

function numDecodings(s)
    prev2 ← 1                        // dp[i-2]
    prev1 ← if s[0] = '0' then 0 else 1
    for i ← 1 to length(s) - 1
        cur ← 0
        if s[i] ≠ '0'
            cur ← prev1              // one digit
        two ← toInt(s[i-1..i])
        if two ≥ 10 and two ≤ 26
            cur ← cur + prev2        // two digits
        (prev2, prev1) ← (prev1, cur)
    return prev1

Coin Change (Tabulated)

function coinChange(coins, amount)
    dp ← new Array(amount + 1, ∞)
    dp[0] ← 0
    for a ← 1 to amount
        for each c in coins
            if c ≤ a
                dp[a] ← min(dp[a], dp[a - c] + 1)
    if dp[amount] = ∞ return -1
    return dp[amount]

Word Break

function wordBreak(s, words)
    dict ← toSet(words)
    dp ← new Array(n + 1, false)  // prefix len i OK?
    dp[0] ← true
    for i ← 1 to n
        for j ← 0 to i - 1
            if dp[j] and dict.has(s[j..i-1])
                dp[i] ← true
                break
    return dp[n]

⚠ Common Mistakes

  • Decode Ways: treating "06" as valid; a leading zero makes a two-digit code invalid
  • Coin Change: initializing dp with 0 instead of ∞, so min never moves
  • Word Break: building substrings longer than the longest word (wasted O(n) slices)

✓ Tips & Best Practices

  • Practice: Climbing Stairs, Min Cost Climbing Stairs, House Robber I/II, Decode Ways, Coin Change, Word Break
  • Limit Word Break's inner loop to i − maxWordLen … i − 1
  • Jump Game is DP-shaped but a greedy reach pointer solves it in O(n)

Quick Summary

  • dp[i] — answer for the first i items
  • add — counting · min/max — optimizing
  • rolling variables — O(1) space
  • base case dp[0] — the empty prefix
