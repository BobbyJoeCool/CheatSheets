Functions That Call Themselves

A recursive function solves a problem by calling itself on a smaller version of the same problem until it reaches a base case it can answer directly. Each call waits on the call stack until its sub-call returns. The key skill is to trust the recursion: assume the call on the smaller input is correct, and only write how to combine its answer.

Every Recursion Needs

  • A base case that stops (empty, 0, leaf, null)
  • Progress: each call's input is strictly smaller
  • A clear statement of what f(x) returns
  • Depth that fits the stack (~10³–10⁴ frames)

Base Case, Recursive Case, Trace

function factorial(n)
    if n ≤ 1 return 1             // base case
    return n * factorial(n - 1)   // smaller input

// factorial(3)
//   = 3 * factorial(2)
//         = 2 * factorial(1)
//               = 1          ← base case returns first
//         = 2 * 1 = 2
//   = 3 * 2 = 6

function factTail(n, acc ← 1)     // tail call: last action
    if n ≤ 1 return acc
    return factTail(n - 1, acc * n)

Recursion → Iteration

function sumTree(root)            // recursive
    if root = null return 0
    return root.val + sumTree(root.left)
                    + sumTree(root.right)

function sumTreeIter(root)        // explicit stack
    (total, stack) ← (0, [root])
    while not stack.isEmpty()
        node ← stack.pop()
        if node = null continue
        total ← total + node.val
        stack.push(node.left)
        stack.push(node.right)
    return total

⚠ Common Mistakes

  • Missing or unreachable base case: infinite recursion → stack overflow
  • Recursing on an input that isn't smaller (f(n) calling f(n))
  • Re-solving the same subproblem many times: add memoization (Sheet 078)

✓ Tips & Best Practices

  • Trace the smallest two inputs by hand to check the base case
  • Python: sys.setrecursionlimit helps a little; iteration helps more
  • Practice: Fibonacci, Pow(x, n), Reverse Linked List (recursive), Max Depth of Tree

Quick Summary

  • base case — stop condition
  • recursive case — smaller input
  • trust the recursion — only combine
  • explicit stack — same logic, no depth limit
