Hierarchies of Nodes

A tree is a connected structure with no cycles: one root, and every other node has exactly one parent. In a binary tree each node has at most two children, left and right. Most tree algorithms are short recursive functions because every subtree is itself a tree.

Handy Facts

  • n nodes → exactly n − 1 edges
  • Level d holds at most 2ᵈ nodes
  • Perfect tree of height h: 2ʰ⁺¹ − 1 nodes
  • Complete tree height: ⌊log₂ n⌋

Node and Basic Measures

class TreeNode
    function init(val, left ← null, right ← null)
        (this.val, this.left, this.right) ← (val, left, right)

function height(node)           // edges; empty tree = -1
    if node = null return -1
    return 1 + max(height(node.left), height(node.right))

function countNodes(node)
    if node = null return 0
    return 1 + countNodes(node.left) + countNodes(node.right)

function depthOf(root, target, d ← 0)
    if root = null return -1
    if root = target return d
    l ← depthOf(root.left, target, d + 1)
    return if l ≠ -1 then l else depthOf(root.right, target, d + 1)

Binary Tree Shapes

ShapeDefinition
fullevery node has 0 or 2 children
completeall levels full except the last, filled left to right
perfectall internal nodes have 2 children, leaves at one depth
balancedsubtree heights differ by ≤ 1 everywhere
degenerateeach node has one child (a linked list)

⚠ Common Mistakes

  • Mixing height conventions: LeetCode's "max depth" counts nodes (empty = 0)
  • Calling any tree with two children per node "perfect" or "complete"
  • Forgetting the null base case: every recursion must handle an empty subtree

✓ Tips & Best Practices

  • Draw a 5–7 node example before coding any tree function
  • A heap is a complete tree, which is why it fits in an array
  • Balanced → height O(log n); skewed → O(n)

Quick Summary

  • root / leaf — top / no children
  • depth ↓ from root · height ↑ to leaves
  • n − 1 edges for n nodes
  • complete · full · perfect · balanced
