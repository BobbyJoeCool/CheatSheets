DP over Sub-Ranges

Interval DP stores dp[i][j], the answer for the slice i..j, built from smaller slices. Fill it by increasing length so every shorter range is ready. Many problems try every split point k inside the range; others (like Burst Balloons) pick the element handled last, which makes the two sides independent.

Recognize It When

  • Merging / bursting / cutting where neighbors change
  • "Optimal order to combine a sequence"
  • Palindromic substructure inside a string
  • n ≤ ~500 (O(n³) is fine)

The Shape

for len ← 1 to n             // short ranges first
    for i ← 0 to n - len
        j ← i + len - 1
        if len = 1
            dp[i][j] ← base(i)
        else
            dp[i][j] ← best over k in i..j-1 of
                combine(dp[i][k], dp[k+1][j], i, k, j)

// Matrix Chain: dims d[0..n]
// combine = left + right + d[i]·d[k+1]·d[j+1]

Burst Balloons (Last One Wins)

function maxCoins(nums)
    a ← [1] + nums + [1]
    m ← length(a)
    dp ← m × m grid of 0       // open range (l, r)
    for len ← 2 to m - 1
        for l ← 0 to m - 1 - len
            r ← l + len
            for k ← l + 1 to r - 1   // k burst LAST
                gain ← a[l] * a[k] * a[r]
                dp[l][r] ← max(dp[l][r],
                    dp[l][k] + gain + dp[k][r])
    return dp[0][m - 1]

Palindrome Partitioning II (Min Cuts)

function minCut(s)
    isPal ← n × n grid of false
    for len ← 1 to n                       // interval fill
        for i ← 0 to n - len
            j ← i + len - 1
            isPal[i][j] ← s[i] = s[j] and (len ≤ 2 or isPal[i+1][j-1])
    cuts ← new Array(n, 0)
    for j ← 0 to n - 1
        if isPal[0][j]
            cuts[j] ← 0
        else
            cuts[j] ← min over i in 1..j with isPal[i][j] of cuts[i-1] + 1
    return cuts[n - 1]

⚠ Common Mistakes

  • Filling by i then j instead of by length: reads ranges not yet computed
  • Burst Balloons by choosing the first balloon: the sides still depend on each other
  • Forgetting the padded 1s around Burst Balloons

✓ Tips & Best Practices

  • Practice: Burst Balloons, Minimum Cost Tree From Leaf Values, Palindrome Partitioning II, Strange Printer, Stone Game
  • Longest Palindromic Subsequence: dp[i+1][j−1] + 2 if ends match, else max of the two shrinks
  • Memoized solve(i, j) avoids thinking about fill order

Quick Summary

  • dp[i][j] — answer for the range
  • iterate by length
  • split point k — combine halves
  • last element — independent sides
