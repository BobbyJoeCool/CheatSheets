Binary Tree Traversals

preorder · inorder · postorder · iterative with stack · level order (BFS) · Morris traversal

Visiting Every Node

Depth-first traversals go down one branch before backtracking; the only difference is when the node is visited: before (preorder), between (inorder), or after (postorder) its children. Level order (breadth-first) visits the tree row by row with a queue. All are O(n) time.

Which Order?

  • Preorder: copy or serialize a tree
  • Inorder: BST values come out sorted
  • Postorder: children before parent (sizes, delete)
  • Level order: anything per level, nearest-first

Recursive DFS

function preorder(node)         // root, left, right
    if node = null return
    visit(node)
    preorder(node.left)
    preorder(node.right)
function inorder(node)          // left, root, right
    if node = null return
    inorder(node.left)
    visit(node)
    inorder(node.right)
function postorder(node)        // left, right, root
    if node = null return
    postorder(node.left)
    postorder(node.right)
    visit(node)

Iterative Inorder (Explicit Stack)

function inorderIterative(root)
    stack ← []
    node ← root
    while node ≠ null or not stack.isEmpty()
        while node ≠ null           // dive left
            stack.push(node)
            node ← node.left
        node ← stack.pop()
        visit(node)
        node ← node.right           // then go right

// preorder: pop, visit, push right, push left
// postorder: reverse of (root, right, left)

Level Order (BFS)

function levelOrder(root)
    if root = null return []
    result ← []
    queue ← new Queue([root])
    while not queue.isEmpty()
        level ← []
        count ← length(queue)          // nodes on this level
        repeat count times
            node ← queue.dequeue()
            level.append(node.val)
            if node.left ≠ null
                queue.enqueue(node.left)
            if node.right ≠ null
                queue.enqueue(node.right)
        result.append(level)
    return result

⚠ Common Mistakes

  • Reading length(queue) inside the inner loop: the level mixes with the next one
  • Recursive DFS on a 10⁵-deep skewed tree: stack overflow
  • Pushing left before right in iterative preorder: visits right subtree first

✓ Tips & Best Practices

  • Right Side View, Zigzag, Level Averages: all small tweaks of level order
  • Validate BST and Kth Smallest: inorder
  • Morris traversal threads predecessor.right ← node to get O(1) space

Quick Summary

  • pre — node first · in — middle · post — last
  • inorder of BST — sorted
  • BFS — queue + level size
  • all traversals — O(n) time
