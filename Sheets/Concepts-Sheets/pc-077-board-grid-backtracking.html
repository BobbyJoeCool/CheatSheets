Board & Grid Backtracking

N-Queens (column / diagonal sets) · Sudoku solver · word search · palindrome partitioning · restore visited cell

Constraint Puzzles on Boards

Board problems are backtracking with constraint checks: place something in a cell, verify rows, columns, diagonals, or boxes, recurse, then restore the cell. O(1) checks come from keeping sets of what each row, column, or diagonal already contains. For word paths on a grid, mark a cell visited before recursing and unmark it afterward.

Constraint Tricks

  • Diagonal id: r − c; anti-diagonal id: r + c
  • Sudoku box id: (r div 3) * 3 + c div 3
  • Mark visited with a sentinel like '#', then restore

N-Queens

function solveNQueens(n)
    (cols, diag, anti) ← (new Set(), new Set(), new Set())
    out ← []
    function place(r, queens)
        if r = n
            out.append(copy(queens))
            return
        for c ← 0 to n - 1
            if cols.has(c) or diag.has(r - c)
                    or anti.has(r + c)
                continue                // attacked
            add c, r - c, r + c to the sets
            queens.append(c)
            place(r + 1, queens)
            queens.pop()
            remove c, r - c, r + c from the sets
    place(0, [])
    return out                    // queens[r] = col

Sudoku Solver

function solve(board)
    cell ← next empty cell
    if cell = null return true      // full
    for each d in "123456789"
        if canPlace(cell, d)        // row/col/box sets
            board[cell] ← d
            mark d used in its row, col, box
            if solve(board)
                return true
            board[cell] ← '.'       // undo
            unmark d
    return false

Word Search

function exist(board, word)
    function dfs(r, c, i)
        if i = length(word) return true
        if not inBounds(r, c) or board[r][c] ≠ word[i]
            return false
        tmp ← board[r][c]
        board[r][c] ← '#'           // visited
        found ← dfs(r + 1, c, i + 1) or dfs(r - 1, c, i + 1)
             or dfs(r, c + 1, i + 1) or dfs(r, c - 1, i + 1)
        board[r][c] ← tmp           // restore
        return found
    for each cell (r, c)
        if dfs(r, c, 0) return true
    return false

Palindrome Partitioning

function partition(s)
    out ← []
    function bt(start, path)
        if start = length(s)
            out.append(copy(path))
            return
        for end ← start to length(s) - 1
            if isPalindrome(s, start, end)
                path.append(s[start..end])
                bt(end + 1, path)
                path.pop()
    bt(0, [])
    return out

⚠ Common Mistakes

  • Not restoring the cell after Word Search's DFS: later starts see '#'
  • Checking queen attacks by scanning the board: O(n) per check instead of O(1)
  • Word Search on many words: run one Trie-guided DFS instead (Word Search II, Sheet 091)

✓ Tips & Best Practices

  • Practice: N-Queens, N-Queens II, Sudoku Solver, Word Search, Palindrome Partitioning
  • Precompute isPal[i][j] with DP to speed up partitioning
  • Return early on the first solution when only one is needed

Quick Summary

  • sets per row / col / diagonal — O(1) checks
  • r − c, r + c — diagonal ids
  • mark → recurse → restore
  • fail fast — prune before recursing
