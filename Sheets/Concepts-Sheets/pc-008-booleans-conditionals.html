Booleans & Conditionals

truth tables · short-circuit · De Morgan's laws · if / else if / else · switch / match · ternary · guard clauses

Making Decisions

Conditionals choose which code runs based on boolean expressions. and / or short-circuit: the right side runs only if it can change the result, which makes guards like i < n and arr[i] > 0 safe. Prefer flat code with guard clauses over deeply nested if blocks.

Quick Facts

  • a and b stops at the first false
  • a or b stops at the first true
  • match / switch picks one branch by value
  • Some languages treat 0, "", [], null as falsy

Conditional Forms

if age ≥ 18 and hasId
    allow()
else if age ≥ 16
    allowWithGuardian()
else
    deny()

if i < length(arr) and arr[i] > 0   // index checked first: safe

label ← if score ≥ 50 then "pass" else "fail"   // ternary

match command                        // switch / match
    case "start": begin()
    case "stop", "halt": finish()
    default: unknown(command)

function ship(order)                 // guard clauses
    if order = null return "no order"
    if order.items is empty return "nothing to ship"
    return sendPackage(order)        // main path, not nested

Code Explained

else if — checked only if earlier tests failed
short-circuit — guards protect the right side
if … then … else — expression that returns a value
match — compare one value against many cases
guard clause — return early for bad cases

⚠ Common Mistakes

  • Writing if x = 5 in C/JS: that's assignment; use == (or === in JS)
  • Reversing guard order arr[i] > 0 and i < n: crashes before the bounds check
  • Forgetting break in C/Java/JS switch: execution falls through to the next case

✓ Tips & Best Practices

  • Negate a condition with De Morgan instead of wrapping it in not (…)
  • Order else if chains from most specific to most general
  • In JS, [] and {} are truthy; check .length explicitly

Quick Summary

  • and / or — short-circuit left to right
  • if … then … else — conditional expression
  • match — multi-way branch
  • Guard clause — exit early, keep the happy path flat
