DP Fundamentals & Memoization

overlapping subproblems · optimal substructure · state · transition · base case · top-down memo · brute force → memo

Solve Each Subproblem Once

Dynamic programming applies when a problem breaks into subproblems that overlap (the same ones come up again and again) and the best answer is built from best answers to subproblems (optimal substructure). Memoization is the easiest way in: write the brute-force recursion, then cache each result by its arguments so it's computed only once.

Recognize It When

  • "Count the number of ways …"
  • "Minimum / maximum cost, length, profit …"
  • "Is it possible to reach / form …"
  • Each choice changes what's possible later

Brute Force → Memoized

// Climbing Stairs: 1 or 2 steps at a time
function ways(n)                  // O(2ⁿ): repeats work
    if n ≤ 1 return 1
    return ways(n - 1) + ways(n - 2)

memo ← new Map()
function waysMemo(n)              // O(n): each n once
    if n ≤ 1 return 1
    if memo.has(n) return memo[n]
    memo[n] ← waysMemo(n - 1) + waysMemo(n - 2)
    return memo[n]

// ways(5) calls ways(3) twice and ways(2)
// three times; the memo answers repeats in O(1)

Memo with a Richer State: Coin Change

function coinChange(coins, amount)   // fewest coins
    memo ← new Map()
    function best(rem)               // state = rem
        if rem = 0 return 0
        if rem < 0 return ∞
        if memo.has(rem) return memo[rem]
        res ← ∞
        for each c in coins          // transition
            res ← min(res, 1 + best(rem - c))
        memo[rem] ← res
        return res
    ans ← best(amount)
    return if ans = ∞ then -1 else ans

⚠ Common Mistakes

  • Memoizing on something that isn't the full state: different situations share a cache entry
  • Mutable arguments (lists) as part of the state: use an index instead
  • Greedy instead of DP for Coin Change: coins [1, 3, 4], amount 6 → greedy 3 coins, best 2

✓ Tips & Best Practices

  • Get the brute-force recursion right first; caching is the easy part
  • Python: @functools.cache memoizes a function in one line
  • Deep memo recursion can overflow; convert to tabulation (Sheet 079)

Quick Summary

  • state · transition · base case · answer
