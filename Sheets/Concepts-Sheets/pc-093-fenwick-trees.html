Fenwick Trees (Binary Indexed Trees)

Prefix Sums That Can Change

A Fenwick tree (binary indexed tree) supports point update and prefix sum in O(log n) with a single array and about ten lines of code. Index i stores the sum of a block that ends at i and has length i & -i (its lowest set bit). Updates climb by adding the lowbit; queries descend by subtracting it.

Quick Facts

  • Arrays are 1-indexed (index 0 unused)
  • Range sum = prefix(r) − prefix(l − 1)
  • Range add + point query: build it over a difference array
  • Only for invertible operations like + (not min/max)

Fenwick Tree

class Fenwick
    function init(n)
        this.n ← n
        this.tree ← new Array(n + 1, 0)
    function add(i, delta)            // a[i] += delta
        while i ≤ this.n
            this.tree[i] ← this.tree[i] + delta
            i ← i + (i & -i)          // next covering block
    function prefix(i)                // a[1] + … + a[i]
        s ← 0
        while i > 0
            s ← s + this.tree[i]
            i ← i - (i & -i)          // drop lowest bit
        return s
    function rangeSum(l, r)
        return this.prefix(r) - this.prefix(l - 1)

Count of Smaller Numbers After Self

function countSmaller(nums)
    ranks ← compress(nums)            // values → 1..m
    bit ← new Fenwick(m)
    out ← new Array(n, 0)
    for i ← n - 1 down to 0           // right to left
        out[i] ← bit.prefix(ranks[i] - 1)   // smaller, already seen
        bit.add(ranks[i], 1)
    return out

⚠ Common Mistakes

  • Using index 0: i & -i is 0 there, so the loops never move
  • Forgetting to compress large values before using them as indexes
  • Expecting range min/max: Fenwick can't subtract a min

✓ Tips & Best Practices

  • Shift a 0-indexed array by one: add(i + 1, x)
  • Inversion count: same as Count Smaller, summed
  • Practice: Range Sum Query – Mutable, Count of Smaller Numbers After Self, Reverse Pairs

Quick Summary

  • i & -i — lowbit
  • add — climb with i += lowbit
  • prefix — descend with i −= lowbit
  • O(log n) — both operations
