Backtracking Template

choose / explore / unchoose · state & path · decision tree · pruning · copy on record · branches^depth cost

Try, Recurse, Undo

Backtracking builds a solution one choice at a time, exploring a decision tree with DFS. At each step it chooses an option, explores deeper, then unchooses it to try the next one. Pruning (skipping choices that can't lead to a valid answer) is what keeps it practical. Cost is roughly branches^depth.

Recognize It When

  • "Generate all …" combinations, permutations, subsets
  • "Find any arrangement satisfying constraints"
  • n is small (≤ 10–20)
  • Need the actual solutions, not just a count

The Template

function backtrack(path, choices)
    if path is complete
        results.append(copy(path))   // record a COPY
        return
    for each c in choices
        if not valid(c, path)
            continue                 // prune
        path.append(c)               // choose
        backtrack(path, choices')    // explore
        path.pop()                   // unchoose

Decision Tree: Subsets of [a, b, c]

                  []
         /        |        \
       [a]       [b]       [c]
      /   \       |
  [a,b]  [a,c]  [b,c]
    |
 [a,b,c]

each edge = one choice
each node = one partial path

Letter Combinations of a Phone Number

function letterCombinations(digits)
    if digits is empty return []
    keys ← { '2': "abc", '3': "def", …, '9': "wxyz" }
    out ← []
    function bt(i, path)
        if i = length(digits)
            out.append(join(path))
            return
        for each ch in keys[digits[i]]
            path.append(ch)
            bt(i + 1, path)
            path.pop()
    bt(0, [])
    return out

⚠ Common Mistakes

  • Appending path itself to results: every stored result is the same emptied list
  • Forgetting to undo (pop, unmark): later branches see stale choices
  • Pruning after recursing instead of before: no time saved

✓ Tips & Best Practices

  • Sort input first so you can break once values get too large
  • Pass indexes, not sliced copies, to avoid O(n) work per call
  • Practice: Letter Combinations, Generate Parentheses, Subsets, Permutations, Combination Sum

Quick Summary

  • choose → explore → unchoose
  • copy the path when recording
  • prune early — the real speedup
  • ≈ branches^depth — cost
