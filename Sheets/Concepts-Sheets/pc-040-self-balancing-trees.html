Self-Balancing Trees

AVL trees · rotations · red-black rules · B-trees · skip lists · ordered map / TreeMap · O(log n) guarantee

Keeping Height O(log n)

A plain BST degrades to O(n) when inputs arrive in order. Self-balancing trees restore balance after each insert or delete with rotations, guaranteeing O(log n) operations. You'll rarely implement one in an interview, but you'll use them constantly through ordered maps and sets such as Java TreeMap and C++ std::map.

Family Members

  • AVL: strict balance, faster lookups
  • Red-black: looser balance, faster inserts (most libraries)
  • B-tree: many keys per node; databases and file systems
  • Skip list: layered linked lists, expected O(log n)

Rotation (Right)

//        y                x
//       / \              / \
//      x   C    →       A   y
//     / \                  / \
//    A   B                B   C
function rotateRight(y)
    x ← y.left
    y.left ← x.right            // B moves
    x.right ← y
    updateHeight(y)             // child first
    updateHeight(x)
    return x                    // new root

AVL Rebalance

function rebalance(node)
    updateHeight(node)
    bf ← height(node.left) - height(node.right)
    if bf > 1                                  // left-heavy
        if balance(node.left) < 0
            node.left ← rotateLeft(node.left)  // LR case
        return rotateRight(node)               // LL case
    if bf < -1                                 // right-heavy
        if balance(node.right) > 0
            node.right ← rotateRight(node.right)   // RL
        return rotateLeft(node)                // RR case
    return node
// call on every node along the insert/delete path

Red-Black Rules

⚠ Common Mistakes

  • Assuming a hash map keeps keys ordered: only tree maps do
  • Updating the parent's height before the child's after a rotation
  • Reaching for a sorted array when there are many inserts: each insert is O(n)

✓ Tips & Best Practices

  • Need "next larger" or "range between" with updates? Use an ordered map
  • Calendar booking, sliding-window median, and stock price problems use ordered sets
  • Python lacks a built-in: SortedList is allowed on LeetCode

Quick Summary

  • rotation — O(1) local restructure
  • AVL — |balance| ≤ 1 at every node
  • red-black — the usual library tree
  • TreeMap / std::map — O(log n) ordered ops
