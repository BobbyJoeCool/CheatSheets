Topological Sort

DAG · Kahn's algorithm (in-degree) · DFS postorder · course schedule · cycle detection · alien dictionary

Ordering Dependencies

A topological order lists the nodes of a directed graph so every edge u → v has u before v: a valid order to take courses or build modules. It exists only for a DAG (no cycles), so the same algorithms also detect cycles. Kahn's algorithm repeatedly removes nodes with in-degree 0; the DFS version outputs nodes in reverse finishing order.

Recognize It When

  • Prerequisites, dependencies, build order
  • "Can all tasks be finished?" (cycle check)
  • Derive an order from pairwise rules (Alien Dictionary)
  • Both methods: O(V + E)

Kahn's Algorithm (BFS)

function topoSort(n, edges)        // (u, v): u before v
    adj ← n empty lists
    indeg ← new Array(n, 0)
    for each (u, v) in edges
        adj[u].append(v)
        indeg[v] ← indeg[v] + 1
    queue ← nodes with indeg = 0
    order ← []
    while not queue.isEmpty()
        u ← queue.dequeue()
        order.append(u)
        for each v in adj[u]
            indeg[v] ← indeg[v] - 1
            if indeg[v] = 0
                queue.enqueue(v)
    if length(order) < n
        return null                // cycle
    return order

DFS with Three States

function topoDFS(n, adj)
    state ← new Array(n, 0)  // 0 new · 1 active · 2 done
    order ← []
    function visit(u)
        if state[u] = 1 return false   // back edge: cycle
        if state[u] = 2 return true
        state[u] ← 1
        for each v in adj[u]
            if not visit(v) return false
        state[u] ← 2
        order.append(u)                // after descendants
        return true
    for u ← 0 to n - 1
        if not visit(u) return null
    return reverse(order)

⚠ Common Mistakes

  • Reversing edge direction: [course, prereq] means prereq → course
  • Using a plain visited set for directed cycle detection: needs the "active" state
  • Forgetting to return null / false when not every node was output

✓ Tips & Best Practices

  • Kahn's is easier to get right and handles "levels" naturally
  • Use a min-heap instead of a queue for the lexicographically smallest order
  • Alien Dictionary: a longer word before its own prefix is invalid

Quick Summary

  • in-degree 0 — ready to take
  • length(order) < n — cycle
  • 3 states — DFS cycle detection
  • reverse postorder — DFS topo order
