Monotonic Stack

next greater element · daily temperatures · stock span · largest rectangle in histogram · trapping rain water

Answer "Next Greater" for Everyone in O(n)

A monotonic stack keeps its items in increasing or decreasing order. When a new item breaks the order, everything it pops has just found its next greater (or smaller) element: the new item. Each index is pushed and popped once, so the whole pass is O(n), replacing an O(n²) "scan right for each element".

Which Stack?

  • Next greater: keep a decreasing stack
  • Next smaller: keep an increasing stack
  • Previous greater: the stack top after popping
  • Store indexes so you can compute distances

Next Greater Element / Daily Temperatures

function nextGreater(nums)
    res ← new Array(length(nums), -1)
    stack ← []                              // indexes; values decreasing
    for i ← 0 to length(nums) - 1
        while not stack.isEmpty() and nums[stack.peek()] < nums[i]
            j ← stack.pop()
            res[j] ← nums[i]                // Daily Temperatures: i - j
        stack.push(i)
    return res                              // still on stack → no answer

Code Explained

decreasing stack — waiting for something bigger
pop — the current item answers it
i - j — distance (days to wait)
circular array: loop 2n times using i mod n

Largest Rectangle in Histogram

function largestRectangle(h)
    h.append(0)                   // flush the stack
    stack ← []                    // increasing heights
    best ← 0
    for i ← 0 to length(h) - 1
        while not stack.isEmpty()
                and h[stack.peek()] ≥ h[i]
            height ← h[stack.pop()]
            left ← if stack.isEmpty() then -1 else stack.peek()
            best ← max(best, height * (i - left - 1))
        stack.push(i)
    return best

Trapping Rain Water (Stack)

function trap(h)
    (stack, water) ← ([], 0)
    for i ← 0 to length(h) - 1
        while not stack.isEmpty()
                and h[i] > h[stack.peek()]
            bottom ← stack.pop()
            if stack.isEmpty() break
            left ← stack.peek()
            width ← i - left - 1
            depth ← min(h[left], h[i]) - h[bottom]
            water ← water + width * depth
        stack.push(i)
    return water

⚠ Common Mistakes

  • Storing values instead of indexes: can't compute widths or distances
  • Wrong comparison (< vs ≤) with duplicates: double-counted or missed ranges
  • Forgetting the leftover stack items: they have no next greater (−1 / 0)

✓ Tips & Best Practices

  • Practice: Next Greater Element I/II, Daily Temperatures, Online Stock Span, Car Fleet
  • Histogram: popped bar's width runs from the new top + 1 to i − 1
  • Rain water also has an O(1)-space two-pointer solution

Quick Summary

  • decreasing stack — next greater
  • increasing stack — next smaller
  • push / pop once — O(n)
  • sentinel 0 — flush remaining bars
