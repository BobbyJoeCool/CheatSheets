Sheet 012

Memory: Stack, Heap & References

call stack · heap allocation · references / pointers · aliasing · shallow vs deep copy · garbage collection · stack overflow

Where Values Live

Each function call gets a stack frame for its locals; frames are freed automatically when the call returns. Objects created with new live on the heap and outlive the call that made them. Variables that hold objects actually hold references, so two names can point at the same object (aliasing).

Key Facts

  • The stack is small (often ~1–8 MB): deep recursion overflows it
  • Heap memory is reclaimed by GC, ownership rules, or manual free
  • Assignment copies the reference, not the object
  • Python's default recursion limit is 1000 frames

References, Aliases, Copies

function build(n)                 // one stack frame per call
    size ← n * 2                  // local value: lives in the frame
    node ← new Node(size)         // object on the heap; frame holds a reference
    return node                   // frame is freed; the heap object survives

a ← [1, 2, 3]
b ← a                             // alias: same array
b[0] ← 99                         // a[0] is 99 too

c ← copy(a)                       // shallow copy: new outer array
c[1] ← 7                          // a unchanged

grid ← [[0, 0], [0, 0]]
g2 ← copy(grid)                   // shallow: rows are still shared
g2[0][0] ← 5                      // grid[0][0] is 5 too!
g3 ← deepCopy(grid)               // fully independent

rows ← new Array(3, [])           // trap: 3 references to ONE list
for i ← 0 to 2
    rows[i] ← []                  // fix: a separate list per slot

Code Explained

stack frame — params + locals for one call
new — allocates on the heap
b ← a — aliasing, not copying
shallow copy — copies the outer container only
deep copy — copies nested objects too
new Array(3, []) — shares one inner list

⚠ Common Mistakes

  • Building a 2D grid as [[0] * m] * n (Python): every row is the same list
  • "Copying" with b ← a then mutating b: you changed a
  • Recursing 10⁵ deep in Python or Java: stack overflow; use an explicit stack

✓ Tips & Best Practices

  • Draw boxes (objects) and arrows (references) when debugging aliasing
  • Return new objects from helpers instead of mutating shared ones
  • Convert deep recursion to iteration with your own stack (Sheet 072)

Quick Summary

  • stack — per-call frames, auto-freed
  • heap — objects that outlive calls
  • b ← a — alias, same object
  • deepCopy — independent nested copy
