Longest Increasing Subsequence

The LIS is the longest set of items, in original order (not necessarily adjacent), that strictly increases. The O(n²) DP asks, for each i, which earlier smaller item gives the longest run ending at i. The O(n log n) version keeps tails[k], the smallest possible tail of an increasing run of length k + 1, and binary-searches where each new value fits.

Recognize It When

  • "Longest increasing / non-decreasing subsequence"
  • Nesting items: envelopes, boxes, stacking
  • "Longest chain of pairs"
  • Minimum deletions to make a sequence sorted = n − LIS

O(n²) DP

function lengthOfLIS(nums)
    dp ← new Array(n, 1)      // LIS ending at i
    for i ← 1 to n - 1
        for j ← 0 to i - 1
            if nums[j] < nums[i]
                dp[i] ← max(dp[i], dp[j] + 1)
    return max(dp)

O(n log n) with tails[]

function lisFast(nums)
    tails ← []
    for each x in nums
        i ← lowerBound(tails, x)   // first ≥ x
        if i = length(tails)
            tails.append(x)        // longer run
        else
            tails[i] ← x           // smaller tail
    return length(tails)
// non-decreasing: use upperBound

Number of LIS

function findNumberOfLIS(nums)
    len ← new Array(n, 1)
    cnt ← new Array(n, 1)
    for i ← 0 to n - 1
        for j ← 0 to i - 1
            if nums[j] < nums[i]
                if len[j] + 1 > len[i]
                    (len[i], cnt[i]) ← (len[j] + 1, cnt[j])
                else if len[j] + 1 = len[i]
                    cnt[i] ← cnt[i] + cnt[j]
    L ← max(len)
    return sum of cnt[i] where len[i] = L

⚠ Common Mistakes

  • Reading tails as the actual subsequence: it's only valid for its length
  • Russian Doll Envelopes sorted by height ascending on ties: equal widths nest wrongly
  • Using upperBound for strictly increasing runs (or lowerBound for non-decreasing)

✓ Tips & Best Practices

  • Russian Doll: sort width ↑, height ↓ on ties, then LIS on heights
  • Longest chain of pairs: sort by end and pick greedily (O(n log n))
  • Practice: LIS, Number of LIS, Russian Doll Envelopes, Max Length of Pair Chain

Quick Summary

  • dp[i] — LIS ending at i, O(n²)
  • tails + binary search — O(n log n)
  • sort + LIS — 2D nesting
  • n − LIS — deletions to sort
