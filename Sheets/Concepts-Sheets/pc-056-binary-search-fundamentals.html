Halve the Search Space

Binary search finds a target in a sorted array by comparing with the middle and discarding half each step: O(log n). Most bugs come from mixing interval styles, so pick one template and keep its rules. The most useful forms return the boundary: the first index where a condition becomes true (lower bound, upper bound).

Ground Rules

  • Data must be sorted, or the condition must be monotonic
  • Use mid ← lo + (hi - lo) div 2 (no overflow)
  • Every branch must shrink the range, or it loops forever
  • 10⁹ items → about 30 steps

Boundary Search (Half-Open [lo, hi))

function lowerBound(arr, x)     // first i: arr[i] ≥ x
    (lo, hi) ← (0, length(arr))
    while lo < hi
        mid ← lo + (hi - lo) div 2
        if arr[mid] < x
            lo ← mid + 1
        else
            hi ← mid
    return lo                     // length(arr) if none

function upperBound(arr, x)     // first i: arr[i] > x
    (lo, hi) ← (0, length(arr))
    while lo < hi
        mid ← lo + (hi - lo) div 2
        if arr[mid] ≤ x
            lo ← mid + 1
        else
            hi ← mid
    return lo

Exact Match (Closed [lo, hi])

function search(arr, x)
    (lo, hi) ← (0, length(arr) - 1)
    while lo ≤ hi
        mid ← lo + (hi - lo) div 2
        if arr[mid] = x
            return mid
        else if arr[mid] < x
            lo ← mid + 1
        else
            hi ← mid - 1
    return -1

// arr = [1, 2, 2, 2, 5]
// lowerBound(2) = 1   upperBound(2) = 4
// first 2 at 1, last 2 at 4 - 1 = 3
// count of 2s = 4 - 1 = 3

⚠ Common Mistakes

  • hi ← mid with while lo ≤ hi: infinite loop when lo = hi
  • (lo + hi) / 2 overflowing 32-bit ints, or using float division
  • Returning lo without checking lo < n and arr[lo] = x

✓ Tips & Best Practices

  • Search Insert Position = lowerBound
  • First / last occurrence = lowerBound(x) / upperBound(x) − 1
  • Practice: Binary Search, Search Insert Position, First and Last Position, Sqrt(x)
