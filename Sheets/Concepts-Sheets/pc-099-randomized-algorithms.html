Randomized Algorithms & Sampling

Fisher-Yates shuffle · reservoir sampling · weighted random pick (prefix + binary search) · rejection sampling · random pivot

Using Randomness Correctly

Randomized algorithms rely on a uniform randomInt(lo, hi). Fisher-Yates shuffles so every ordering is equally likely. Reservoir sampling picks uniformly from a stream of unknown length in O(1) memory. Weighted picks use prefix sums plus binary search. Rejection sampling builds one uniform range out of another by throwing away the leftovers.

Quick Facts

  • randomInt(lo, hi) here includes both ends
  • Random pivots make quicksort / quickselect O(n log n) / O(n) expected
  • Seed the generator in tests for reproducible runs
  • Correctness argument: show each outcome's probability is equal

Shuffle and Reservoir Sampling

function shuffle(a)            // Fisher-Yates
    for i ← length(a) - 1 down to 1
        j ← randomInt(0, i)    // includes i
        swap(a, i, j)

function reservoir(stream)     // one item, O(1) memory
    (chosen, count) ← (null, 0)
    for each x in stream
        count ← count + 1
        if randomInt(1, count) = 1
            chosen ← x         // prob. 1 / count
    return chosen
// k items: keep the first k, then replace a
// random slot with probability k / count

Weighted Pick and Rejection Sampling

class WeightedPicker           // Random Pick with Weight
    function init(w)
        this.prefix ← running sums of w
        // w = [1, 3] → prefix = [1, 4]
    function pick()
        total ← this.prefix[length(this.prefix) - 1]
        target ← randomInt(1, total)
        return lowerBound(this.prefix, target)

function rand10()              // from rand7()
    while true
        x ← (rand7() - 1) * 7 + rand7()   // 1..49
        if x ≤ 40              // reject 41..49
            return (x - 1) mod 10 + 1

⚠ Common Mistakes

  • Shuffling by swapping with any index 0..n−1: some orders become more likely
  • Reservoir sampling with randomInt(0, count): off by one, wrong probabilities
  • Using random() mod n for large n: low values come up slightly more often

✓ Tips & Best Practices

  • Prove a sampler by checking the final probability of one item
  • Expected loop count for rand10: 49/40 ≈ 1.2 iterations
  • Randomized hash seeds defend against crafted collision attacks

Quick Summary

  • Fisher-Yates — swap with randomInt(0, i)
  • reservoir — keep with prob. 1 / count
  • prefix + binary search — weighted pick
  • rejection — discard and retry
