Bellman-Ford, Floyd-Warshall & 0-1 BFS

negative edges · negative cycle check · k-stops limit · all-pairs DP · 0-1 BFS with deque

Beyond Dijkstra

Bellman-Ford relaxes every edge V − 1 times, so it handles negative weights, detects negative cycles, and can cap the number of edges used ("at most k stops"). Floyd-Warshall computes all-pairs shortest paths with a triple loop. 0-1 BFS solves graphs whose weights are only 0 or 1 in O(V + E) with a deque.

Bellman-Ford

function bellmanFord(n, edges, src)
    dist ← new Array(n, ∞)
    dist[src] ← 0
    repeat n - 1 times             // ≤ n−1 edges per path
        for each (u, v, w) in edges
            if dist[u] + w < dist[v]
                dist[v] ← dist[u] + w
    for each (u, v, w) in edges    // one extra round
        if dist[u] + w < dist[v]
            return null            // negative cycle
    return dist

Cheapest Flights Within k Stops

function cheapest(n, flights, src, dst, k)
    dist ← new Array(n, ∞)
    dist[src] ← 0
    repeat k + 1 times             // k stops = k+1 edges
        next ← copy(dist)          // read last round only
        for each (u, v, w) in flights
            if dist[u] + w < next[v]
                next[v] ← dist[u] + w
        dist ← next
    return if dist[dst] = ∞ then -1 else dist[dst]

Floyd-Warshall (All Pairs)

// d[i][j] = edge weight or ∞; d[i][i] = 0
for k ← 0 to n - 1                 // allow k as a stop
    for i ← 0 to n - 1
        for j ← 0 to n - 1
            if d[i][k] + d[k][j] < d[i][j]
                d[i][j] ← d[i][k] + d[k][j]
// any d[i][i] < 0 → negative cycle

0-1 BFS (Deque)

function zeroOneBFS(adj, src)
    dist ← new Array(n, ∞)
    dist[src] ← 0
    dq ← new Deque([src])
    while not dq.isEmpty()
        u ← dq.popFront()
        for each (v, w) in adj[u]  // w is 0 or 1
            if dist[u] + w < dist[v]
                dist[v] ← dist[u] + w
                if w = 0 dq.pushFront(v)
                else dq.pushBack(v)
    return dist

⚠ Common Mistakes

  • k-stops with in-place updates: one round can chain several edges
  • Putting k in an inner loop of Floyd-Warshall: it must be the outer loop
  • Treating ∞ + w as smaller than ∞ in languages using a big int sentinel

✓ Tips & Best Practices

  • Use a large finite sentinel (e.g. 10¹⁸) and check dist[u] ≠ ∞ before adding
  • Floyd-Warshall also answers reachability (transitive closure) with booleans
  • 0-1 BFS: "min walls to break", "min arrow changes" in grids

Quick Summary

  • Bellman-Ford — V − 1 rounds, negatives OK
  • copy per round — edge-count limit
  • Floyd — k outermost, O(V³)
  • 0-1 BFS — front for 0, back for 1
