Rebuilding and Encoding Trees

One traversal alone can't pin down a tree's shape, but preorder + inorder can: preorder gives each subtree's root, and that root's position in inorder splits left from right. To save a tree as text, serialize a traversal with explicit null markers, then rebuild it by reading tokens in the same order.

Key Facts

  • A hash map value → inorder index makes building O(n)
  • Postorder + inorder: take roots from the end, build right first
  • Null markers (#) make a single traversal enough
  • Sorted array → balanced BST: middle element is the root

Build from Preorder + Inorder

function buildTree(preorder, inorder)
    pos ← map of value → index in inorder
    p ← 0                                   // next root in preorder
    function build(lo, hi)                  // inorder range
        if lo > hi return null
        root ← new TreeNode(preorder[p])
        p ← p + 1
        mid ← pos[root.val]
        root.left ← build(lo, mid - 1)      // left first
        root.right ← build(mid + 1, hi)
        return root
    return build(0, length(inorder) - 1)

Serialize / Deserialize (Preorder)

function serialize(node)
    if node = null return "#"
    return toString(node.val) + ","
        + serialize(node.left) + ","
        + serialize(node.right)

function deserialize(data)
    tokens ← iterator(split(data, ","))
    function build()
        t ← tokens.next()
        if t = "#" return null
        node ← new TreeNode(toInt(t))
        node.left ← build()
        node.right ← build()
        return node
    return build()

Sorted Array → Balanced BST

function toBST(arr, lo, hi)
    if lo > hi return null
    mid ← (lo + hi) div 2
    node ← new TreeNode(arr[mid])
    node.left ← toBST(arr, lo, mid - 1)
    node.right ← toBST(arr, mid + 1, hi)
    return node

// [1,2,3,4,5] → root 3, left {1,2}, right {4,5}
// "1,2,#,#,3,4,#,#,5,#,#" encodes:
//     1
//    / \
//   2   3
//      / \
//     4   5

⚠ Common Mistakes

  • Searching inorder linearly for each root: O(n²); use the index map
  • Building right before left with preorder: the order must match the traversal
  • Serializing without null markers: different trees produce the same string

✓ Tips & Best Practices

  • Use an iterator or index pointer shared across recursive calls
  • BFS (level-order) serialization also works; it matches LeetCode's format
  • Practice: Construct from Pre+In, Serialize/Deserialize, Sorted Array to BST

Quick Summary

  • preorder root + inorder split — rebuild
  • # — null marker
  • index map — O(n) build
  • middle element — balanced BST
