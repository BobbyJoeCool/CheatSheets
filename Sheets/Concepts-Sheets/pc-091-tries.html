A Tree of Prefixes

A trie stores strings character by character along a path from the root; words that share a prefix share nodes. Insert, search, and prefix checks take O(L) for a word of length L, independent of how many words are stored. Mark nodes where a word ends with a flag (or store the word there).

Recognize It When

  • Many prefix queries: autocomplete, "starts with"
  • Searching many words at once (Word Search II)
  • Wildcards like . matching any letter

Trie

class Trie                    // node: children + isWord
    root ← new TrieNode()
    function insert(word)                 // O(L)
        node ← root
        for each ch in word
            if not node.children.has(ch)
                node.children[ch] ← new TrieNode()
            node ← node.children[ch]
        node.isWord ← true
    function walk(prefix)                 // node or null
        node ← root
        for each ch in prefix
            if not node.children.has(ch) return null
            node ← node.children[ch]
        return node
    function search(word)
        node ← walk(word)
        return node ≠ null and node.isWord
    function startsWith(prefix)
        return walk(prefix) ≠ null

Word Search II (Trie-Guided DFS)

function findWords(board, words)
    root ← trie of words; end node stores .word
    out ← []
    function dfs(r, c, node)
        ch ← board[r][c]
        if ch = '#' or not node.children.has(ch) return
        node ← node.children[ch]
        if node.word ≠ null
            out.append(node.word)
            node.word ← null              // report once
        board[r][c] ← '#'
        for each (nr, nc) in inBoundsNeighbors(r, c)
            dfs(nr, nc, node)
        board[r][c] ← ch
    for each cell (r, c)
        dfs(r, c, root)
    return out

Wildcard Search ('.')

function searchDot(node, word, i)
    if i = length(word)
        return node.isWord
    ch ← word[i]
    if ch = '.'
        for each child in node.children
            if searchDot(child, word, i + 1)
                return true
        return false
    if not node.children.has(ch)
        return false
    return searchDot(node.children[ch],
                     word, i + 1)

⚠ Common Mistakes

  • Treating any reached node as a word: check the end-of-word flag
  • Running Word Search I for each word: one shared trie DFS is far faster
  • Using array[26] when the alphabet is larger (Unicode, digits, symbols)

✓ Tips & Best Practices

  • Binary trie on bits: Maximum XOR of Two Numbers
  • Prune leaf nodes after finding a word to speed up Word Search II
  • Store counts at nodes to answer "how many words start with …"

Quick Summary

  • path = prefix
  • isWord — end-of-word flag
  • O(L) — insert / search / prefix
  • trie + DFS — many-word search
