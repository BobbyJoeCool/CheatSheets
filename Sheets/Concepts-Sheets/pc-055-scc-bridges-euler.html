Connectivity: SCCs, Bridges & Euler Paths

Kosaraju · Tarjan low-link · bridges · articulation points · Euler path · Hierholzer · reconstruct itinerary

Deeper Graph Structure

Tarjan's low-link DFS records each node's discovery time and the lowest time reachable through its subtree. An edge u–v is a bridge if v's subtree can't reach above u. Kosaraju finds strongly connected components (SCCs) with two DFS passes. Hierholzer builds an Euler path that uses every edge exactly once.

Quick Facts

  • Bridge: low[v] > disc[u]
  • Articulation point: low[v] ≥ disc[u] (root: ≥ 2 children)
  • SCC graph collapsed to nodes is a DAG
  • All three run in O(V + E)

Bridges (Tarjan Low-Link)

function bridges(n, adj)
    disc ← new Array(n, -1)
    low ← new Array(n, 0)
    (time, out) ← (0, [])
    function dfs(u, parent)
        disc[u] ← time
        low[u] ← time
        time ← time + 1
        for each v in adj[u]
            if v = parent continue
            if disc[v] = -1
                dfs(v, u)
                low[u] ← min(low[u], low[v])
                if low[v] > disc[u]
                    out.append((u, v))   // bridge
            else
                low[u] ← min(low[u], disc[v])
    for u ← 0 to n - 1
        if disc[u] = -1 dfs(u, -1)
    return out

SCCs (Kosaraju)

function kosaraju(n, adj)
    order ← []                  // 1) finish order
    seen ← new Set()
    function dfs1(u)
        seen.add(u)
        for each v in adj[u]
            if not seen.has(v) dfs1(v)
        order.append(u)
    for u ← 0 to n - 1
        if not seen.has(u) dfs1(u)
    radj ← reversed edges       // 2) transpose
    comp ← new Array(n, -1)
    c ← 0
    function dfs2(u)
        comp[u] ← c
        for each v in radj[u]
            if comp[v] = -1 dfs2(v)
    for each u in reverse(order)    // 3)
        if comp[u] = -1
            dfs2(u)
            c ← c + 1
    return comp

Euler Path (Hierholzer)

function findItinerary(tickets)   // Reconstruct Itinerary
    adj ← map airport → min-heap of destinations
    route ← []
    function visit(a)
        while adj[a] is not empty
            visit(adj[a].pop())   // smallest first
        route.append(a)           // add when stuck
    visit("JFK")
    return reverse(route)

⚠ Common Mistakes

  • Skipping the parent edge by node, not edge id: breaks with parallel edges
  • Using low[v] instead of disc[v] for back edges in the bridge DFS
  • Appending to the route before exploring in Hierholzer: wrong order

✓ Tips & Best Practices

  • Practice: Critical Connections (bridges), Reconstruct Itinerary, Valid Arrangement of Pairs
  • Tarjan's SCC does it in one pass with a stack; Kosaraju is easier to remember
  • Use iterative DFS for V ≈ 10⁵ to avoid stack overflow

Quick Summary

  • disc / low — Tarjan's low-link
  • low[v] > disc[u] — bridge
  • Kosaraju — finish order, transpose, DFS
  • Hierholzer — post-order, then reverse
