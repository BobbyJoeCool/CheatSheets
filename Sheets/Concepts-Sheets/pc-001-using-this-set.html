What This Set Covers

A language-agnostic reference for the ideas every programmer needs and the algorithm patterns behind coding-interview sites like LeetCode and NeetCode. Every code block is pseudocode (see Sheet 002), so the same page works whether you solve in Python, Java, JavaScript, C++, or anything else. Translate the pseudocode into your language as practice. Pattern sheets follow one layout: idea → pseudocode → complexity (time · space) → recognize-it-when signals → practice problems. Bitwise (007) and RegEx (029) are one-page primers with their own full sets.

⚠ Common Mistakes

  • Reading pseudocode without coding it: you only learn a pattern by typing it in your own language and running it
  • Jumping to DP before arrays, hashing, and recursion: most DP is recursion plus a cache
  • Memorizing problem answers instead of patterns: new problems reuse patterns, not answers

✓ Tips & Best Practices

  • Work one roadmap topic at a time; read the sheet, then solve 3–5 problems
  • Use Sheet 103 when you're stuck on which technique applies
  • Re-solve a problem a week later from a blank editor to test recall
