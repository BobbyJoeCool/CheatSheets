Minimum Spanning Trees

Kruskal · Prim · cut property · union-find use · min cost to connect points · dense vs sparse choice

Connect Everything for the Least Cost

A minimum spanning tree (MST) connects all V vertices of a weighted, undirected graph with V − 1 edges and the smallest total weight. Both classic algorithms are greedy and rest on the cut property: the cheapest edge crossing any split of the vertices is safe to include. Kruskal adds edges cheapest-first; Prim grows one tree outward.

Recognize It When

  • "Connect all points / cities / houses at minimum cost"
  • Undirected, weighted, every node must be reached
  • No start or end node (that would be shortest path)
  • MST is not unique when weights tie, but its cost is

Kruskal (Sort + Union-Find)

function kruskal(n, edges)        // edges: (w, u, v)
    sort(edges) by w
    uf ← new UnionFind(n)         // Sheet 050
    (total, used) ← (0, 0)
    for each (w, u, v) in edges
        if uf.union(u, v)         // joins 2 parts
            total ← total + w
            used ← used + 1
            if used = n - 1 break
    if used < n - 1
        return -1                 // disconnected
    return total

Prim (Min-Heap)

function prim(n, adj)             // adj[u] = [(v, w)]
    inTree ← new Array(n, false)
    heap ← new MinHeap([(0, 0)])  // (weight, node)
    (total, count) ← (0, 0)
    while not heap.isEmpty() and count < n
        (w, u) ← heap.pop()
        if inTree[u] continue     // stale
        inTree[u] ← true
        total ← total + w
        count ← count + 1
        for each (v, wv) in adj[u]
            if not inTree[v]
                heap.push((wv, v))
    return total

⚠ Common Mistakes

  • Using an MST to answer shortest-path questions: different problems
  • Running Prim from one node on a disconnected graph and not checking count
  • Building all n² edges for 10³ points and then sorting: works, but Prim's O(n²) array is faster

✓ Tips & Best Practices

  • "Pay to build at a node" costs: add a virtual node with edges of that cost
  • Maximum spanning tree: sort descending (or negate weights)
  • Stop Kruskal once n − 1 edges are used

Quick Summary

  • MST — V − 1 edges, minimum total
  • Kruskal — sort edges + union-find
  • Prim — heap of crossing edges
  • cut property — why greedy works
