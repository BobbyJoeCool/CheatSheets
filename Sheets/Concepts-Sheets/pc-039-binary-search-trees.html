Ordered Binary Trees

In a binary search tree, every value in a node's left subtree is smaller and every value in its right subtree is larger. That lets search, insert, and delete follow a single path: O(h), which is O(log n) when balanced and O(n) when skewed. An inorder traversal visits the values in sorted order.

Recognize It When

  • Ordered data with frequent inserts and lookups
  • "kth smallest", "successor", "closest value"
  • "validate BST", "range sum of BST"
  • Floor / ceiling: largest ≤ x, smallest ≥ x

Search, Insert, Validate

function search(node, x)                  // O(h)
    while node ≠ null and node.val ≠ x
        node ← if x < node.val then node.left else node.right
    return node

function insert(node, x)
    if node = null return new TreeNode(x)
    if x < node.val
        node.left ← insert(node.left, x)
    else
        node.right ← insert(node.right, x)
    return node

function isValidBST(node, lo ← -∞, hi ← ∞)
    if node = null return true
    if node.val ≤ lo or node.val ≥ hi return false
    return isValidBST(node.left, lo, node.val)
        and isValidBST(node.right, node.val, hi)

Delete

function delete(node, x)
    if node = null return null
    if x < node.val
        node.left ← delete(node.left, x)
    else if x > node.val
        node.right ← delete(node.right, x)
    else
        if node.left = null return node.right
        if node.right = null return node.left
        succ ← node.right             // 2 children:
        while succ.left ≠ null        // min of right
            succ ← succ.left
        node.val ← succ.val
        node.right ← delete(node.right, succ.val)
    return node

Floor (Largest ≤ x)

function floor(node, x)
    best ← null
    while node ≠ null
        if node.val = x return x
        if node.val < x
            best ← node.val       // candidate; try bigger
            node ← node.right
        else
            node ← node.left
    return best
// ceiling: mirror (val > x → candidate, go left)

⚠ Common Mistakes

  • Validating by comparing only parent and child: a deep left node can still exceed the root
  • Inserting sorted data into a plain BST: it becomes a linked list, O(n) per op
  • Forgetting to reassign node.left ← … after recursive insert/delete

✓ Tips & Best Practices

  • Use a library ordered map/set (Sheet 040) instead of writing a balanced BST
  • Kth smallest iteratively: inorder with a stack, stop at the kth pop
  • Duplicate values: decide on a side (e.g. ≥ goes right) and keep it consistent

Quick Summary

  • left < node < right — BST property
  • O(h) — search / insert / delete
  • inorder — sorted output
  • bounds (lo, hi) — validation
