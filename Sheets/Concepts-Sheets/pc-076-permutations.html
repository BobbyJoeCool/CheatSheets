Permutations

used[] array · swap-in-place method · duplicate handling · next permutation · kth permutation · n! cost

Every Ordering

A permutation uses every item once in some order, so each level of the tree may pick any unused item: track them with a used[] array (or by swapping into place). There are n! permutations, so this is only feasible for n ≤ ~10. For the next or kth ordering, skip enumeration and compute it directly.

Variants

  • All permutations: used[] or swap method
  • With duplicates: sort, skip nums[i] = nums[i−1] if not used[i−1]
  • Next permutation: O(n), in place
  • kth permutation: factorial number system, O(n²)

Permutations with used[]

function permute(nums)          // n! · n
    n ← length(nums)
    (out, used) ← ([], new Array(n, false))
    function bt(path)
        if length(path) = n
            out.append(copy(path))
            return
        for i ← 0 to n - 1
            if used[i] continue
            // with duplicates (sorted input):
            // if i > 0 and nums[i] = nums[i-1]
            //    and not used[i-1]: continue
            used[i] ← true
            path.append(nums[i])
            bt(path)
            path.pop()
            used[i] ← false
    bt([])
    return out

Swap-in-Place Method

function permuteSwap(a, k)
    if k = length(a)
        out.append(copy(a))
        return
    for i ← k to length(a) - 1
        swap(a, k, i)           // fix a[k]
        permuteSwap(a, k + 1)
        swap(a, k, i)           // undo

// no extra used[] array;
// output order differs from
// the lexicographic one

Next Permutation

function nextPermutation(a)
    i ← length(a) - 2
    while i ≥ 0 and a[i] ≥ a[i + 1]
        i ← i - 1              // rightmost "dip"
    if i ≥ 0
        j ← length(a) - 1
        while a[j] ≤ a[i]
            j ← j - 1          // rightmost bigger
        swap(a, i, j)
    reverse(a, i + 1, length(a) - 1)
// [1,2,3]→[1,3,2]→[2,1,3]→…→[3,2,1]→[1,2,3]

⚠ Common Mistakes

  • Duplicate-skip with used[i−1] instead of not used[i−1]: still produces duplicates
  • Forgetting to reset used[i] after the call
  • Generating all n! permutations to find the next one

✓ Tips & Best Practices

  • Practice: Permutations, Permutations II, Next Permutation, Permutation Sequence
  • Next permutation reversed (rightmost bump, smaller swap) gives the previous one
  • n ≤ 8 is the usual comfort limit (8! = 40,320)

Quick Summary

  • used[] — pick any unused item
  • swap / unswap — in-place method
  • dip, swap, reverse — next permutation
  • n! — always the cost of listing them
