Heaps & Priority Queues

Fast Access to the Smallest (or Largest)

A binary heap is a complete binary tree where each parent is ≤ its children (min-heap) or ≥ them (max-heap). Because it's complete, it lives in a plain array with no pointers. It gives O(1) peek and O(log n) push / pop, which makes it the standard priority queue.

Array Layout (0-indexed)

  • children of i: 2i + 1, 2i + 2
  • parent of i: (i − 1) div 2
  • root (min or max) at index 0
  • Heapify an array bottom-up: O(n)

Push and Pop (Min-Heap)

function push(heap, x)                // O(log n)
    heap.append(x)
    i ← length(heap) - 1
    while i > 0                       // sift up
        p ← (i - 1) div 2
        if heap[p] ≤ heap[i] break
        swap(heap, i, p)
        i ← p

function pop(heap)                    // O(log n)
    top ← heap[0]
    heap[0] ← heap[length(heap) - 1]  // move last to root
    heap.removeLast()
    siftDown(heap, 0)
    return top

Sift Down and Heapify

function siftDown(heap, i)
    n ← length(heap)
    while true
        small ← i
        for each c in [2 * i + 1, 2 * i + 2]
            if c < n and heap[c] < heap[small]
                small ← c
        if small = i return
        swap(heap, i, small)
        i ← small

function heapify(arr)                 // O(n) total
    for i ← length(arr) div 2 - 1 down to 0
        siftDown(arr, i)

⚠ Common Mistakes

  • Assuming a heap is sorted: only the root is guaranteed; siblings are unordered
  • Forgetting C++ priority_queue is a max-heap by default
  • Searching a heap for an arbitrary value: that's O(n)

✓ Tips & Best Practices

  • Store tuples (priority, tiebreak, item) so items never get compared directly
  • Heap sort: heapify, then pop n times; O(n log n), O(1) extra
  • Need decrease-key? Push a new entry and skip stale ones on pop (Sheet 051)

Quick Summary

  • parent ≤ children — min-heap
  • 2i+1, 2i+2, (i−1) div 2 — array links
  • push / pop — O(log n)
  • heapify — O(n)
