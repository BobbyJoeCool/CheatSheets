Knapsack Family

0/1 knapsack · unbounded knapsack · reverse capacity loop · partition equal subset sum · target sum · coin change II (ways)

Pick Items Under a Capacity

In the 0/1 knapsack, each item is taken at most once to maximize value within a weight limit. In 1D form, loop capacity backward so an item can't be reused in the same pass. Looping forward gives the unbounded version (unlimited copies). Many problems are knapsack in disguise: subset sums, target sums, and coin combinations.

Disguises

  • Partition into equal halves → subset sum = total / 2
  • Target Sum (±) → subset sum = (total + target) / 2
  • Coin Change II → unbounded, count ways
  • Ones and Zeroes → 2D capacity (zeros, ones)

0/1 vs Unbounded (1D Arrays)

function knapsack01(wt, val, W)          // each item at most once
    dp ← new Array(W + 1, 0)             // dp[w] = best value at capacity w
    for i ← 0 to n - 1
        for w ← W down to wt[i]          // BACKWARD: no reuse this pass
            dp[w] ← max(dp[w], dp[w - wt[i]] + val[i])
    return dp[W]

function knapsackUnbounded(wt, val, W)   // unlimited copies
    dp ← new Array(W + 1, 0)
    for i ← 0 to n - 1
        for w ← wt[i] to W               // FORWARD: item may repeat
            dp[w] ← max(dp[w], dp[w - wt[i]] + val[i])
    return dp[W]

Code Explained

2D form: dp[i][w] = max(skip, take)
backward loop — reads values from before item i
forward loop — reads values that may include item i
time O(n · W), space O(W)
W up to ~10⁵ is fine; 10⁹ is not

Partition Equal Subset Sum

function canPartition(nums)
    total ← sum(nums)
    if total mod 2 = 1 return false
    target ← total div 2
    dp ← new Array(target + 1, false)
    dp[0] ← true
    for each x in nums
        for s ← target down to x
            dp[s] ← dp[s] or dp[s - x]
    return dp[target]

Coin Change II (Count Combinations)

function change(amount, coins)
    dp ← new Array(amount + 1, 0)
    dp[0] ← 1
    for each c in coins           // coins OUTER
        for a ← c to amount
            dp[a] ← dp[a] + dp[a - c]
    return dp[amount]
// amount outer, coins inner counts
// ORDERED ways (Combination Sum IV)

⚠ Common Mistakes

  • Looping capacity forward in 0/1 knapsack: silently allows reusing an item
  • Swapping loop order in Coin Change II: counts [1,2] and [2,1] separately
  • Target Sum: skipping the check that total + target is even and non-negative

✓ Tips & Best Practices

  • Practice: Partition Equal Subset Sum, Target Sum, Coin Change II, Last Stone Weight II, Ones and Zeroes
  • Feasibility uses or, counting uses +, optimizing uses max / min
  • Big sums with small n? Meet-in-the-middle or bitset shifts instead

Quick Summary

  • 0/1 — capacity backward
  • unbounded — capacity forward
  • items outer — combinations
  • O(n · W) — pseudo-polynomial
