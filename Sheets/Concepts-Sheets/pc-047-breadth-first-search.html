Breadth-First Search

queue · level-by-level · shortest path (unweighted) · multi-source BFS · mark visited on enqueue · word ladder

Explore in Rings

Breadth-first search visits all nodes 1 step away, then 2 steps, and so on, using a queue. Because of that order, the first time BFS reaches a node is along a shortest path (fewest edges) in an unweighted graph. Start from several nodes at once (multi-source) to get the distance to the nearest source.

Recognize It When

  • "Minimum number of steps / moves / transformations"
  • "Nearest", "shortest" with equal-cost moves
  • "Level by level", "spreads each minute"
  • States can be words, boards, or (cell, keys) pairs

Shortest Path (Unweighted)

function shortestPath(adj, src, dst)
    dist ← new Map()
    dist[src] ← 0
    queue ← new Queue([src])
    while not queue.isEmpty()
        u ← queue.dequeue()
        if u = dst return dist[u]
        for each v in adj[u]
            if not dist.has(v)   // mark on enqueue
                dist[v] ← dist[u] + 1
                queue.enqueue(v)
    return -1                    // unreachable

// multi-source: put every source in the
// queue with dist 0 before the loop

Word Ladder (Implicit Graph)

function ladderLength(begin, end, words)
    wordSet ← toSet(words)
    queue ← new Queue([(begin, 1)])
    seen ← new Set([begin])
    while not queue.isEmpty()
        (w, steps) ← queue.dequeue()
        if w = end return steps
        for i ← 0 to length(w) - 1
            for each c in "abcdefghijklmnopqrstuvwxyz"
                nxt ← w[0..i-1] + c + w[i+1..]
                if wordSet.has(nxt) and not seen.has(nxt)
                    seen.add(nxt)
                    queue.enqueue((nxt, steps + 1))
    return 0

⚠ Common Mistakes

  • Marking visited on dequeue: the same node is enqueued many times
  • Using BFS distances on weighted graphs: fewest edges ≠ lowest cost
  • Rebuilding strings for each neighbor in Word Ladder without a set lookup

✓ Tips & Best Practices

  • Store (node, distance) in the queue or keep a dist map
  • Bidirectional BFS (from both ends) cuts the search on huge graphs
  • Process one level at a time with count ← length(queue)

Quick Summary

  • queue — nearest first
  • mark on enqueue — no duplicates
  • multi-source — all starts at level 0
  • O(V + E) — time
