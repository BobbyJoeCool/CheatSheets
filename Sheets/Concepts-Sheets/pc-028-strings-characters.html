Text as an Array of Characters

A string is a sequence of characters, and most string problems are array problems in disguise. Each character has a numeric code, so code(c) - code('a') maps 'a'…'z' to 0…25, the index into a count[26] array. In many languages strings are immutable, so build results with a list or builder, not repeated +.

Quick Facts

  • Immutable in Java, Python, JS, C#; mutable in C++
  • s + t creates a new string: O(len)
  • code('0')=48, code('A')=65, code('a')=97
  • Digit value: code(c) - code('0')

Core Techniques

function isAnagram(a, b)                  // same letters, same counts
    if length(a) ≠ length(b) return false
    count ← new Array(26, 0)
    for i ← 0 to length(a) - 1
        x ← code(a[i]) - code('a')
        y ← code(b[i]) - code('a')
        count[x] ← count[x] + 1
        count[y] ← count[y] - 1
    return all(count, lambda v: v = 0)
function isPalindrome(s)                  // two pointers, skip symbols
    (l, r) ← (0, length(s) - 1)
    while l < r
        if not isAlnum(s[l])
            l ← l + 1
        else if not isAlnum(s[r])
            r ← r - 1
        else if lower(s[l]) ≠ lower(s[r])
            return false
        else
            (l, r) ← (l + 1, r - 1)
    return true

Code Explained

+1 for a, −1 for b: all zeros means anagram
two pointers — compare ends, move inward
isAlnum / lower — normalize before comparing

⚠ Common Mistakes

  • Building output with s ← s + c in a loop: O(n²)
  • Assuming only lowercase letters: ask about case, digits, Unicode
  • Using count[26] for general Unicode text: use a hash map instead

✓ Tips & Best Practices

  • Convert to a char array when you need in-place edits
  • Lowercase once at the start rather than in every comparison
  • Sorting a word gives a canonical key for anagram grouping
