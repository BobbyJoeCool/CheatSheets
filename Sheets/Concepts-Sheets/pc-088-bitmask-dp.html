Bitmask DP

dp[mask] · visited-set as integer · traveling salesman · task assignment · partition to k equal subsets · n ≤ 20 signal

Subsets as Integers

When n is small (≤ 20), the set of items already used fits in an integer mask: bit i is 1 if item i is used. dp[mask] (optionally with the last item) stores the best answer for that subset, and transitions add one unused item. There are 2ⁿ masks, so expect O(2ⁿ · n) or O(2ⁿ · n²) time.

Bit Operations Used

  • Test: (mask >> i) & 1 = 1
  • Add: mask | (1 << i)
  • Full set: (1 << n) - 1
  • Submasks: sub ← (sub − 1) & mask until 0

Traveling Salesman (Held-Karp)

function tsp(dist)                          // n ≤ ~16–20
    FULL ← (1 << n) - 1
    dp ← 2ⁿ × n grid of ∞              // dp[mask][i]: visited, at i
    dp[1][0] ← 0                            // start at city 0
    for mask ← 1 to FULL
        for i ← 0 to n - 1
            if dp[mask][i] = ∞ continue
            for j ← 0 to n - 1
                if (mask >> j) & 1 = 1 continue    // already visited
                nm ← mask | (1 << j)
                dp[nm][j] ← min(dp[nm][j], dp[mask][i] + dist[i][j])
    return min over i of dp[FULL][i] + dist[i][0]

Code Explained

mask — set of visited cities
dp[mask][i] — cheapest way to visit mask ending at i
transition — go to an unvisited j
close the tour back to city 0
O(2ⁿ · n²) vs n! brute force

Assignment (Workers → Tasks)

function assign(cost)        // cost[worker][task]
    dp ← new Array(2^n, ∞)
    dp[0] ← 0
    for mask ← 0 to 2^n - 1
        w ← popcount(mask)   // next worker
        if w = n continue
        for t ← 0 to n - 1
            if (mask >> t) & 1 = 0
                nm ← mask | (1 << t)
                dp[nm] ← min(dp[nm],
                             dp[mask] + cost[w][t])
    return dp[2^n - 1]

Partition to K Equal Subsets

function canPartitionK(nums, k)
    if sum(nums) mod k ≠ 0 return false
    target ← sum(nums) div k
    dp ← new Array(2^n, -1)  // current bucket fill
    dp[0] ← 0
    for mask ← 0 to 2^n - 1
        if dp[mask] = -1 continue
        for i ← 0 to n - 1
            if (mask >> i) & 1 = 0
                    and dp[mask] + nums[i] ≤ target
                nm ← mask | (1 << i)
                dp[nm] ← (dp[mask] + nums[i]) mod target
    return dp[2^n - 1] = 0

⚠ Common Mistakes

  • Using bitmask DP with n = 40: 2⁴⁰ states won't fit; look for another approach
  • Operator precedence: mask >> i & 1 = 1 needs parentheses in most languages
  • Allocating 2ⁿ × n arrays of 64-bit values without checking memory (n = 20 → 160 MB)

✓ Tips & Best Practices

  • The small-n constraint (≤ 20) is the main signal for bitmasks
  • Process masks in increasing order: adding a bit always makes the mask larger
  • Practice: Shortest Path Visiting All Nodes, Partition to K Equal Sum Subsets, Can I Win

Quick Summary

  • mask — subset as an integer
  • dp[mask] / dp[mask][last] — state
  • mask | (1 << j) — add an item
  • O(2ⁿ · n) — only for small n
