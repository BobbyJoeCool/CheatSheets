Walking and Reshaping Grids

Matrix problems reuse a few index tricks: transpose swaps m[i][j] with m[j][i], reversing rows mirrors left-right, and together they rotate in place. Boundaries (top, bottom, left, right) that shrink inward drive spiral order. Cells on one diagonal share r − c; on an anti-diagonal they share r + c.

Quick Facts

  • R × C matrix: m[r][c], rows first
  • Rotate 90° clockwise = transpose, then reverse each row
  • Sorted rows + columns: start at the top-right corner
  • Flatten: index r * C + c ↔ (i div C, i mod C)

Rotate 90° Clockwise (In Place)

function rotate(m)                   // n × n
    n ← length(m)
    for i ← 0 to n - 1               // 1) transpose
        for j ← i + 1 to n - 1
            (m[i][j], m[j][i]) ← (m[j][i], m[i][j])
    for each row in m                // 2) mirror
        reverse(row)

// counter-clockwise: transpose,
// then reverse each column

Search a Sorted Matrix (Staircase)

function searchMatrix(m, t)    // rows & cols sorted
    (r, c) ← (0, C - 1)        // top-right corner
    while r < R and c ≥ 0
        if m[r][c] = t
            return true
        if m[r][c] > t
            c ← c - 1          // drop this column
        else
            r ← r + 1          // drop this row
    return false
// O(R + C)

Spiral Order

function spiral(m)
    (top, bottom, left, right) ← (0, R - 1, 0, C - 1)
    out ← []
    while top ≤ bottom and left ≤ right
        for c ← left to right
            out.append(m[top][c])
        top ← top + 1
        for r ← top to bottom
            out.append(m[r][right])
        right ← right - 1
        if top ≤ bottom
            for c ← right down to left
                out.append(m[bottom][c])
            bottom ← bottom - 1
        if left ≤ right
            for r ← bottom down to top
                out.append(m[r][left])
            left ← left + 1
    return out

⚠ Common Mistakes

  • Swapping every pair during transpose (j from 0): each swap is undone
  • Spiral without the top ≤ bottom / left ≤ right checks: duplicates single rows
  • Mixing R and C for non-square matrices

✓ Tips & Best Practices

  • Draw a 3×3 and a 3×4 example before coding any traversal
  • Use a direction array and turn on bounds for a simpler spiral
  • Copying the matrix is fine unless the problem says in place

Quick Summary

  • transpose + reverse rows — rotate right
  • shrinking bounds — spiral
  • r − c / r + c — diagonals
  • top-right start — sorted matrix search
