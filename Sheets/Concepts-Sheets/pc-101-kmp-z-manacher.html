Linear-Time String Algorithms: KMP, Z & Manacher

LPS / failure array · KMP search · Z-array · pattern search O(n + m) · expand around center · Manacher O(n)

Linear-Time String Preprocessing

Three algorithms build an array that captures repeated structure, so later steps never re-compare characters. KMP's lps array says how far to fall back after a mismatch. The Z-array gives, for each position, how long it matches the string's prefix. Manacher gives every center's palindrome radius. Each runs in O(n).

Pick One

  • Find pattern in text: KMP or Z on p + "$" + t
  • Repeated substring / shortest period: n − lps[n − 1]
  • Longest palindromic substring: Manacher (or O(n²) expand-around-center)
  • Shortest palindrome by adding a prefix: KMP on s + "#" + rev(s)

KMP: Failure (lps) Array

function buildLPS(p)
    lps ← new Array(m, 0)
    k ← 0          // current prefix length
    for i ← 1 to m - 1
        while k > 0 and p[i] ≠ p[k]
            k ← lps[k - 1]     // fall back
        if p[i] = p[k]
            k ← k + 1
        lps[i] ← k
    return lps
// "aabaaab" → [0,1,0,1,2,2,3]

KMP Search

function kmpSearch(t, p)      // O(n + m)
    lps ← buildLPS(p)
    (k, out) ← (0, [])
    for i ← 0 to n - 1
        while k > 0 and t[i] ≠ p[k]
            k ← lps[k - 1]
        if t[i] = p[k]
            k ← k + 1
        if k = m
            out.append(i - m + 1)
            k ← lps[k - 1]    // keep going
    return out

Z-Array

function zArray(s)
    z ← new Array(n, 0)
    (l, r) ← (0, 0)            // window [l, r)
    for i ← 1 to n - 1
        if i < r
            z[i] ← min(r - i, z[i - l])   // reuse
        while i + z[i] < n
                and s[z[i]] = s[i + z[i]]
            z[i] ← z[i] + 1
        if i + z[i] > r
            (l, r) ← (i, i + z[i])
    return z

Manacher

function manacher(s)
    t ← "^#" + join(s, "#") + "#$"   // odd only
    p ← new Array(length(t), 0)      // radii
    (c, r) ← (0, 0)
    for i ← 1 to length(t) - 2
        if i < r
            p[i] ← min(r - i, p[2 * c - i])
        while t[i + p[i] + 1] = t[i - p[i] - 1]
            p[i] ← p[i] + 1
        if i + p[i] > r
            (c, r) ← (i, i + p[i])
    k ← index of max(p)
    return s[(k - p[k]) div 2 ..
             (k - p[k]) div 2 + p[k] - 1]

⚠ Common Mistakes

  • Resetting k to 0 after a mismatch: that's the naive O(n·m) search
  • Z search without a separator: matches can run past the pattern into the text
  • Manacher without sentinels ^ and $: the expansion walks off the ends

✓ Tips & Best Practices

  • Expand-around-center (O(n²), 2n − 1 centers) is usually enough in interviews
  • Practice: Find the Index of First Occurrence, Repeated Substring Pattern, Longest Palindromic Substring, Shortest Palindrome
  • lps[i] = longest proper prefix of p[0..i] that's also its suffix

Quick Summary

  • lps — where to resume after a mismatch
  • Z — prefix-match length at each i
  • Manacher — palindrome radius per center
  • all O(n)
