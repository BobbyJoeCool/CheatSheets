OOP: Inheritance, Polymorphism & Interfaces

extends · override · super · abstract class · interface · dynamic dispatch · composition over inheritance

Reusing and Substituting Behavior

Inheritance lets a subclass reuse and override a parent's behavior (IS-A). Polymorphism means code written for the parent type works with any subclass: the right method is chosen at run time (dynamic dispatch). Interfaces define a contract with no implementation; abstract classes provide a partial one.

Key Ideas

  • extends — inherit from a class
  • implements — promise to provide an interface's methods
  • super — call the parent's version
  • Prefer composition (HAS-A) for code reuse

Interfaces, Overriding, Dispatch

interface Shape                          // contract: WHAT, not HOW
    function area()

abstract class BaseShape implements Shape
    function describe()                  // shared, uses abstract area()
        return "area = " + toString(this.area())

class Circle extends BaseShape
    function init(r)
        this.r ← r
    function area()                      // override
        return 3.14159 * this.r * this.r

class Square extends BaseShape
    function init(side)
        this.side ← side
    function area()
        return this.side * this.side

for each s in [new Circle(1), new Square(2)]
    print(s.describe())                  // area = 3.14159 · area = 4

Code Explained

interface — methods only, no state
abstract class — can't be instantiated; shares code
override — subclass replaces a method
dispatch — s.area() runs the real object's version
describe is written once and works for every shape

⚠ Common Mistakes

  • Inheriting just to reuse a helper: creates a false IS-A relation
  • Overriding with a different signature: you overloaded, not overrode
  • Hierarchies deeper than 2–3 levels: changes ripple unpredictably

✓ Tips & Best Practices

  • Mark intended overrides (@Override, override) so the compiler checks them
  • Program to interfaces: accept Shape, not Circle
  • Reach for composition first; inherit when the IS-A test truly holds

Quick Summary

  • extends — inherit and override
  • interface — pure contract
  • dynamic dispatch — run-time method choice
  • composition — build from parts
