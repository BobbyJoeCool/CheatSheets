Producing Values One at a Time

An iterator hands out a sequence one item at a time through hasNext() / next(), without exposing how it's stored. A generator is a function that yields values and pauses between them, so items are computed only when asked for (lazy evaluation). Laziness makes huge or even infinite sequences cheap.

Quick Facts

  • for each loops use an iterator under the hood
  • A generator keeps its local state between yields
  • Lazy = O(1) memory for a stream of any length
  • Most iterators can be consumed only once

Iterators and Generators

it ← iterator([10, 20, 30])          // the iterator protocol
while it.hasNext()
    print(it.next())                 // 10, 20, 30

function countUpTo(n)                // generator: pauses at each yield
    for i ← 1 to n
        yield i
for each x in countUpTo(3)           // 1, 2, 3, made on demand
    print(x)

function naturals()                  // infinite, safe because lazy
    n ← 0
    while true
        yield n
        n ← n + 1
take(naturals(), 5)                  // [0, 1, 2, 3, 4]

Code Explained

hasNext / next — the two-method contract
yield — return a value and pause
next call resumes right after the yield
take — stops pulling, so the loop ends

Peeking Iterator (LC 284)

class PeekingIterator
    function init(it)
        this.it ← it
        this.buf ← this.advance()      // look one item ahead
    function advance()
        return if this.it.hasNext() then this.it.next() else null
    function peek()
        return this.buf
    function next()
        val ← this.buf
        this.buf ← this.advance()
        return val
    function hasNext()
        return this.buf ≠ null

⚠ Common Mistakes

  • Iterating a generator twice: the second pass is empty
  • Calling next() without checking hasNext(): exception at the end
  • Turning an infinite generator into a list: never finishes

✓ Tips & Best Practices

  • Use a one-item buffer for peek/lookahead problems
  • Flatten Nested List Iterator: keep a stack of iterators
  • Stream large files line by line with a generator
