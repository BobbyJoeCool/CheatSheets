Two-Coloring and Finding Cycles

A graph is bipartite if its nodes split into two groups with every edge going between them; equivalently, it can be 2-colored, and it has no odd-length cycle. Cycle detection differs by edge type: in an undirected graph, any visited neighbor other than your parent closes a cycle; in a directed graph you need three states to find a back edge.

Recognize It When

  • "Split into two teams / groups with no conflicts"
  • "Is this graph a valid tree?" (connected + no cycle)
  • "Can all courses be finished?" (directed cycle)
  • "Which nodes are safe / never reach a cycle?"

Bipartite Check (BFS Coloring)

function isBipartite(n, adj)
    color ← new Array(n, -1)              // -1 = uncolored
    for s ← 0 to n - 1                    // every component
        if color[s] ≠ -1 continue
        color[s] ← 0
        queue ← new Queue([s])
        while not queue.isEmpty()
            u ← queue.dequeue()
            for each v in adj[u]
                if color[v] = -1
                    color[v] ← 1 - color[u]   // opposite color
                    queue.enqueue(v)
                else if color[v] = color[u]
                    return false              // edge inside one group
    return true

Code Explained

colors 0 / 1 — the two groups
outer loop — graphs may be disconnected
1 - color[u] — neighbors get the other color
same color on both ends — odd cycle, not bipartite
DFS coloring works the same way

Undirected Cycle (Parent Check)

function hasCycle(u, parent, adj, seen)
    seen.add(u)
    for each v in adj[u]
        if not seen.has(v)
            if hasCycle(v, u, adj, seen)
                return true
        else if v ≠ parent
            return true        // not the edge we came on
    return false

Directed Cycle (Three States)

// 0 = new, 1 = on current path, 2 = done
function hasCycleDir(u, adj, state)
    state[u] ← 1
    for each v in adj[u]
        if state[v] = 1
            return true        // back edge
        if state[v] = 0 and hasCycleDir(v, adj, state)
            return true
    state[u] ← 2
    return false

⚠ Common Mistakes

  • Using the undirected parent trick on a directed graph: misses or invents cycles
  • Using a plain visited set for directed graphs: a node reached twice isn't a cycle
  • Checking only from node 0: other components may hold the conflict

✓ Tips & Best Practices

  • Practice: Is Graph Bipartite, Possible Bipartition, Graph Valid Tree, Course Schedule
  • Find Eventual Safe States: nodes that end in state 2 without hitting a cycle
  • Undirected cycles are also easy with union-find (Sheet 050)

Quick Summary

  • bipartite ⇔ 2-colorable ⇔ no odd cycle
  • undirected — visited neighbor ≠ parent
  • directed — edge into state 1
  • loop over all nodes — disconnected graphs
