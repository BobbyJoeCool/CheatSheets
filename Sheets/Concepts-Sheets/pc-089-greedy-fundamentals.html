Greedy Fundamentals

Take the Best Choice Now

A greedy algorithm makes the locally best choice at each step and never revisits it. It's correct only when the problem has the greedy-choice property: some optimal solution starts with the greedy choice. Prove it with an exchange argument (swapping any optimal solution's first choice for the greedy one doesn't make it worse), or find a counterexample.

Recognize It When

  • A natural "best next" rule exists (earliest end, cheapest, farthest)
  • Sorting reveals the order to decide in
  • DP works but every state picks the same kind of option
  • Reach / coverage questions ("can you get to the end?")

Jump Game I and II

function canJump(nums)
    reach ← 0                   // farthest index so far
    for i ← 0 to length(nums) - 1
        if i > reach return false
        reach ← max(reach, i + nums[i])
    return true

function minJumps(nums)         // BFS by ranges
    (jumps, end, far) ← (0, 0, 0)
    for i ← 0 to length(nums) - 2
        far ← max(far, i + nums[i])
        if i = end              // current jump used up
            jumps ← jumps + 1
            end ← far
    return jumps

Gas Station

function canCompleteCircuit(gas, cost)
    if sum(gas) < sum(cost) return -1
    (start, tank) ← (0, 0)
    for i ← 0 to length(gas) - 1
        tank ← tank + gas[i] - cost[i]
        if tank < 0
            start ← i + 1       // no start in
            tank ← 0            // [start..i] works
    return start

// enough total gas guarantees the
// last reset point succeeds

Exchange Argument

StepDo
1take any optimal solution O
2find its first difference from greedy G
3swap in G's choice
4show the result is no worse
5repeat → G is optimal

⚠ Common Mistakes

  • Trusting a greedy rule without testing small counterexamples
  • Gas Station: restarting at start + 1 instead of i + 1 (O(n²) and still wrong)
  • Using greedy for 0/1 knapsack or general coin change: those need DP

✓ Tips & Best Practices

  • Brute-force small inputs and compare with the greedy answer before trusting it
  • Most greedy solutions start with a sort; ask "sorted by what?"
  • Practice: Jump Game I/II, Gas Station, Assign Cookies, Lemonade Change

Quick Summary

  • local best choice, never undone
  • exchange argument — proof
  • counterexample — disproof
  • often sort + one pass, O(n log n)
