Linked Lists — Basics

node · singly vs doubly · head / tail · insert · delete · traversal · dummy / sentinel node

Nodes Linked by Pointers

A linked list is a chain of nodes, each holding a value and a pointer to the next node (and, in a doubly linked list, the previous one). Inserting or removing is O(1) once you hold the right node, but reaching index i takes O(i). A dummy (sentinel) head removes special cases when the real head might change.

Costs

  • Access / search: O(n)
  • Insert / delete at a known node: O(1)
  • Insert at head: O(1); at tail: O(1) with a tail pointer
  • Extra memory per node for pointers

Nodes, Traversal, Insert, Delete

class Node
    function init(val, next ← null)
        this.val ← val
        this.next ← next

head ← new Node(1, new Node(2, new Node(3)))   // 1 → 2 → 3
node ← head                              // traverse: O(n)
while node ≠ null
    print(node.val)
    node ← node.next
head ← new Node(0, head)                 // insert at head: O(1)
prev.next ← new Node(5, prev.next)       // insert after prev: O(1)

function removeAll(head, target)         // dummy avoids head special-case
    dummy ← new Node(0, head)
    prev ← dummy
    while prev.next ≠ null
        if prev.next.val = target
            prev.next ← prev.next.next   // unlink
        else
            prev ← prev.next
    return dummy.next

Code Explained

next ← null — the last node points nowhere
traversal — follow next until null
insert — set the new node's next before relinking
dummy — a fake node before head
unlink — skip over the node; GC frees it
return dummy.next — the head may have changed

⚠ Common Mistakes

  • Losing the rest of the list: relinking before saving node.next
  • Accessing node.next.val without checking node.next ≠ null
  • Returning the old head after deleting the first node

✓ Tips & Best Practices

  • Practice: Design Linked List, Remove Linked List Elements, Remove Duplicates from Sorted List
  • Use a dummy node whenever the head can change
  • Draw boxes and arrows for 3 nodes before coding pointer updates

Quick Summary

  • node.next — follow the chain
  • dummy — sentinel before head
  • prev.next ← prev.next.next — unlink
  • O(1) insert / delete, O(n) access
