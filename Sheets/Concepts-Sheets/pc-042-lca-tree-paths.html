Common Ancestors and Path Sums

The lowest common ancestor (LCA) of p and q is the deepest node that has both in its subtree: where their paths from the root split. Path problems ask for the best sequence of connected nodes; when a path may bend through any node, compute the best downward arm from each child and combine them at the node.

Other LCA Methods

  • Parent pointers: put p's ancestors in a set, walk up from q
  • Binary lifting: up[k][v] = 2ᵏ-th ancestor; O(log n) per query
  • up[k][v] = up[k−1][ up[k−1][v] ]
  • Lift the deeper node to equal depth, then jump both

LCA in a Binary Tree

function lca(node, p, q)                 // O(n)
    if node = null or node = p or node = q
        return node
    left ← lca(node.left, p, q)
    right ← lca(node.right, p, q)
    if left ≠ null and right ≠ null
        return node                      // split here
    return if left ≠ null then left else right

LCA in a BST

function lcaBST(node, p, q)              // O(h)
    while node ≠ null
        if p.val < node.val and q.val < node.val
            node ← node.left             // both left
        else if p.val > node.val and q.val > node.val
            node ← node.right            // both right
        else
            return node                  // split

Binary Tree Maximum Path Sum

function maxPathSum(root)
    best ← -∞
    function gain(node)            // best downward arm
        if node = null return 0
        l ← max(gain(node.left), 0)     // drop negatives
        r ← max(gain(node.right), 0)
        best ← max(best, node.val + l + r)
        return node.val + max(l, r)
    gain(root)
    return best

All Root-to-Leaf Paths

function paths(node, path, out)
    if node = null return
    path.append(node.val)
    if node.left = null and node.right = null
        out.append(copy(path))     // record a copy
    paths(node.left, path, out)
    paths(node.right, path, out)
    path.pop()                     // backtrack

⚠ Common Mistakes

  • Returning node.val + l + r from gain: a parent can only extend one arm
  • Appending path itself instead of a copy: every saved path ends up empty
  • Using the BST shortcut on a plain binary tree: values aren't ordered

✓ Tips & Best Practices

  • Practice: LCA of BST, LCA of Binary Tree, Max Path Sum, Path Sum II, Binary Tree Paths
  • Initialize best to -∞, not 0: all values may be negative
  • Many queries on a static tree: precompute binary lifting

Quick Summary

  • LCA — where p and q split
  • BST LCA — walk until values straddle
  • gain — best arm; best — bend
  • append / recurse / pop — path backtracking
