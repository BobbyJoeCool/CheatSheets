Sliding Window — Variable Size

expand / shrink · longest without repeats · minimum window substring · at most K distinct · exactly K = atMost(K) − atMost(K−1)

Grow Right, Shrink Left

When the window size isn't fixed, expand the right edge one step at a time and shrink from the left whenever the window breaks the rule. Each index enters and leaves at most once, so the scan is O(n). For "longest" answers, record after shrinking; for "shortest", record while shrinking a valid window.

Recognize It When

  • "Longest / shortest substring or subarray such that …"
  • "At most k distinct", "no repeats", "sum ≥ target"
  • Validity is monotonic: shrinking never breaks a valid window
  • All numbers non-negative (for sum windows)

Template: Longest Valid Window

l ← 0
best ← 0
for r ← 0 to n - 1
    add(arr[r])               // expand
    while window invalid
        remove(arr[l])        // shrink
        l ← l + 1
    best ← max(best, r - l + 1)

// exactly K = atMost(K) − atMost(K − 1)

Longest Substring Without Repeats

function lengthOfLongestSubstring(s)
    last ← new Map()              // char → last index
    (l, best) ← (0, 0)
    for r ← 0 to length(s) - 1
        c ← s[r]
        if last.has(c) and last[c] ≥ l
            l ← last[c] + 1       // jump past repeat
        last[c] ← r
        best ← max(best, r - l + 1)
    return best

Minimum Window Substring

function minWindow(s, t)
    need ← counts of t (missing keys = 0)
    missing ← length(t)                  // chars still needed
    (l, bestL, bestLen) ← (0, 0, ∞)
    for r ← 0 to length(s) - 1
        if need[s[r]] > 0
            missing ← missing - 1
        need[s[r]] ← need[s[r]] - 1      // negative = surplus
        while missing = 0                // valid: shrink
            if r - l + 1 < bestLen
                (bestL, bestLen) ← (l, r - l + 1)
            need[s[l]] ← need[s[l]] + 1
            if need[s[l]] > 0
                missing ← missing + 1
            l ← l + 1
    if bestLen = ∞ return ""
    return s[bestL .. bestL + bestLen - 1]

⚠ Common Mistakes

  • Using a variable window on arrays with negatives: shrinking may not help (use prefix sums)
  • Moving l backward in the no-repeat trick: guard with last[c] ≥ l
  • Counting "exactly K" directly: windows aren't monotonic; subtract two atMost counts

✓ Tips & Best Practices

  • Write add, remove, and the validity test first; the loop is always the same
  • Character Replacement: maxFreq never needs to decrease
  • Store the best window's start and length, slice once at the end

Quick Summary

  • longest — record after shrinking
