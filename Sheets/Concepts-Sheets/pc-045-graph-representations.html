Nodes and Edges

A graph is a set of vertices (nodes) joined by edges. Edges can be directed (one-way) or undirected, and weighted or not. Trees, grids, maps, dependencies, and social networks are all graphs. Most problems hand you an edge list; your first step is usually to build an adjacency list.

Vocabulary

  • V = number of vertices, E = number of edges
  • Degree: edges at a node (in / out for directed)
  • DAG: directed graph with no cycles
  • Sparse: E ≈ V; dense: E ≈ V²

Example Graph

 0 --- 1
  \   /
   \ /
    2 --- 3

edges = [(0,1), (0,2), (1,2), (2,3)]

adjacency list:
 0: [1, 2]
 1: [0, 2]
 2: [0, 1, 3]
 3: [2]

degree(2) = 3

Building Representations

adj ← new Array(n)                    // adjacency list: O(V + E)
for i ← 0 to n - 1
    adj[i] ← []                       // separate list per node
for each (u, v) in edges
    adj[u].append(v)
    adj[v].append(u)                  // skip this line if directed

matrix ← grid(n, n, 0)                // adjacency matrix: O(V²)
for each (u, v) in edges
    matrix[u][v] ← 1
    matrix[v][u] ← 1

for each (u, v, w) in weightedEdges   // weighted: store pairs
    adj[u].append((v, w))

indeg ← new Array(n, 0)               // directed in-degree
for each (u, v) in edges
    indeg[v] ← indeg[v] + 1

⚠ Common Mistakes

  • Creating new Array(n, []): every node shares one neighbor list
  • Adding only u → v for an undirected graph: traversal misses half the edges
  • Using a V² matrix for V = 10⁵: 10¹⁰ cells

✓ Tips & Best Practices

  • Nodes labeled by strings? Map them to 0…n−1 or use a map of lists
  • Ask: directed? weighted? connected? self-loops or duplicate edges?
  • Grids are graphs with 4 implicit neighbors per cell (Sheet 048)

Quick Summary

  • adjacency list — default choice
  • matrix — O(1) edge check, O(V²) space
  • (v, w) pairs — weighted edges
  • in-degree — dependencies (Sheet 049)
