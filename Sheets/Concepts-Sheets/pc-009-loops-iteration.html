Sheet 009

Loops & Iteration

counted loop · for each · while · do-while · break / continue · nested loops · off-by-one · loop invariants

Repeating Work

Loops repeat a block while some condition holds. Pick the loop that matches the job: counted when you need the index, for-each for values, while when the end depends on what happens inside. A loop invariant (something true before and after every iteration) is the tool for proving a loop correct.

Quick Facts

  • for i ← 0 to n - 1 runs n times
  • Nested loops multiply: n × m iterations
  • break exits the loop; continue skips to the next pass
  • Don't add or remove items from a collection while iterating it

Loop Forms

for i ← 0 to n - 1               // counted: need the index
    print(i, arr[i])

for each x in arr                // for-each: just the values
    total ← total + x

while lo < hi                    // condition checked before each pass
    lo ← lo + 1

repeat                           // do-while: body runs at least once
    line ← readLine()
until line = "quit"

for i ← 0 to rows - 1            // nested: rows × cols passes
    for j ← 0 to cols - 1
        grid[i][j] ← 0

for each x in arr
    if x < 0 continue            // skip negatives
    if x = target break          // stop at target

Code Explained

to — inclusive end, so n - 1 for n items
for each — no index; use counted loop when you need one
while — may run zero times
repeat … until — runs at least once
continue / break — skip one pass / leave loop

⚠ Common Mistakes

  • Running to n instead of n - 1: index out of range on the last pass
  • while loop that never changes its condition variable: infinite loop
  • Removing items while iterating forward: skips the item after each removal

✓ Tips & Best Practices

  • Iterate backward when deleting by index
  • Name loop variables for meaning (row, col) in nested loops
  • Write the invariant as a comment for any tricky while loop

Quick Summary

  • for i ← 0 to n - 1 — n passes
  • for each — values only
  • while / repeat — condition-driven
  • break / continue — exit / skip
