Divisibility, Primes, and Digits

A few number-theory tools cover most interview math. Euclid's algorithm computes the GCD in O(log n). The Sieve of Eratosthenes lists every prime up to n in O(n log log n). Trial division up to √n factors a number or finds its divisors, because factors come in pairs (d, n / d). Digits come off one at a time with mod 10 and div 10.

Quick Facts

  • gcd(a, 0) = a; lcm(a, b) = a / gcd(a, b) · b
  • Divisors pair up: test d only while d · d ≤ n
  • A number's digit count is ⌊log₁₀ n⌋ + 1
  • Every integer > 1 has a unique prime factorization

GCD, LCM, Sieve

function gcd(a, b)             // O(log min(a, b))
    while b ≠ 0
        (a, b) ← (b, a mod b)
    return a

function lcm(a, b)
    return a div gcd(a, b) * b // divide first

function sieve(n)              // primes ≤ n
    isPrime ← new Array(n + 1, true)
    (isPrime[0], isPrime[1]) ← (false, false)
    p ← 2
    while p * p ≤ n
        if isPrime[p]
            for m ← p * p to n step p
                isPrime[m] ← false
        p ← p + 1
    return isPrime

Factorize, Reverse Integer

function factorize(n)          // O(√n)
    out ← []
    d ← 2
    while d * d ≤ n
        while n mod d = 0
            out.append(d)
            n ← n div d
        d ← d + 1
    if n > 1 out.append(n)     // leftover prime
    return out

function reverseInt(x)         // 0 if it overflows int32
    (sign, x, rev) ← (sign(x), abs(x), 0)
    while x > 0
        d ← x mod 10           // last digit
        if rev > (2147483647 - d) div 10
            return 0
        rev ← rev * 10 + d
        x ← x div 10           // drop last digit
    return sign * rev

⚠ Common Mistakes

  • lcm(a, b) = a * b div gcd: a * b can overflow before dividing
  • Sieve marking from 2p instead of p²: correct but slower
  • Testing primality up to n instead of √n: O(n) per number

✓ Tips & Best Practices

  • Precompute a sieve once when many primality queries arrive
  • Smallest-prime-factor sieve: factor any number ≤ n in O(log n)
  • Use abs and track the sign separately for negative digit math

Quick Summary

  • gcd — Euclid, O(log n)
  • sieve — all primes ≤ n
  • √n — trial division bound
  • mod 10 / div 10 — peel digits
