Counting Without Listing

Combinatorics counts arrangements with formulas instead of enumerating them. Permutations count orderings, combinations count selections, and nCr shows up in grid paths, binomial expansions, and probability. For many nCr mod p queries, precompute factorials and inverse factorials once in O(n), then answer each in O(1).

Recognize It When

  • "How many ways …" with no constraints between choices
  • Grid paths with only right/down moves
  • Answers like Catalan numbers (1, 1, 2, 5, 14, 42 …)
  • Answer required modulo 10⁹ + 7

Factorials and nCr mod p

fact[0] ← 1
for i ← 1 to N
    fact[i] ← fact[i - 1] * i mod MOD
invFact[N] ← power(fact[N], MOD - 2, MOD)
for i ← N down to 1
    invFact[i - 1] ← invFact[i] * i mod MOD

function nCr(n, r)                   // O(1)
    if r < 0 or r > n return 0
    return fact[n] * invFact[r] mod MOD
                   * invFact[n - r] mod MOD

Pascal's Triangle (No Modulus Needed)

C ← (n+1) × (n+1) grid of 0
for i ← 0 to n
    C[i][0] ← 1
    for j ← 1 to i
        C[i][j] ← C[i-1][j-1] + C[i-1][j]
// C[i][j] = choose j of i
// row 4: 1 4 6 4 1
// O(n²) time, good for n ≤ ~1000

⚠ Common Mistakes

  • Computing n! directly for n > 20: overflows 64 bits
  • Dividing factorials under a modulus instead of multiplying by inverse factorials
  • Using combinations when order matters (or the reverse)

✓ Tips & Best Practices

  • Pigeonhole: n + 1 items in n boxes → some box holds two (duplicate-finding proofs)
  • Stars and bars: distribute n identical items into k boxes = C(n + k − 1, k − 1)
  • Practice: Pascal's Triangle, Unique Paths, Unique BSTs, Count Sorted Vowel Strings

Quick Summary

  • n! — orderings
  • C(n, r) — selections
  • fact + invFact — O(1) nCr mod p
  • Catalan — nested / tree shapes
