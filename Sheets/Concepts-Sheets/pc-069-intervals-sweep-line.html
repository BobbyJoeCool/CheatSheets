Ranges on a Line

Interval problems almost always start by sorting (by start to merge, by end to schedule greedily). After sorting, one pass compares each interval with the last kept one. A sweep line turns intervals into +1 / −1 events at their start and end times; the running total at any moment is how many intervals overlap there.

Overlap Test

  • Closed: a.start ≤ b.end and b.start ≤ a.end
  • Half-open: a.start < b.end and b.start < a.end
  • Sorted by start: overlap iff cur.start ≤ last.end
  • Ask whether touching endpoints count as overlapping

Merge Intervals

function merge(intervals)
    sortBy(intervals, lambda iv: iv.start)
    out ← [intervals[0]]
    for each (s, e) in intervals[1..]
        last ← out[length(out) - 1]
        if s ≤ last.end
            last.end ← max(last.end, e)  // extend
        else
            out.append((s, e))
    return out

Insert Interval

function insert(ivs, ns, ne)      // sorted, disjoint
    (out, i) ← ([], 0)
    while i < n and ivs[i].end < ns       // before
        out.append(ivs[i])
        i ← i + 1
    while i < n and ivs[i].start ≤ ne     // overlap
        ns ← min(ns, ivs[i].start)
        ne ← max(ne, ivs[i].end)
        i ← i + 1
    out.append((ns, ne))
    append ivs[i..] to out                // after
    return out

Meeting Rooms II (Sweep Line)

function minRooms(meetings)
    events ← []
    for each (s, e) in meetings
        events.append((s, +1))
        events.append((e, -1))
    sort(events)          // ties: -1 before +1
    (cur, best) ← (0, 0)
    for each (t, d) in events
        cur ← cur + d
        best ← max(best, cur)
    return best

Non-Overlapping Intervals (Greedy by End)

function eraseOverlap(intervals)
    sortBy(intervals, lambda iv: iv.end)
    (keep, lastEnd) ← (0, -∞)
    for each (s, e) in intervals
        if s ≥ lastEnd              // fits after last
            keep ← keep + 1
            lastEnd ← e
    return length(intervals) - keep // removals

⚠ Common Mistakes

  • Sorting by end to merge, or by start to schedule: each task needs the other key
  • Merging into a new interval but forgetting to extend end with max
  • Sweep ties: processing a start before an end at the same time adds a false room

✓ Tips & Best Practices

  • Practice: Merge Intervals, Insert Interval, Non-overlapping Intervals, Meeting Rooms I/II, Minimum Arrows
  • Meeting Rooms II also works with a min-heap of end times (Sheet 044)
  • Interval List Intersections: two pointers, advance the one that ends first

Quick Summary

  • sort by start — merge
  • sort by end — keep the most intervals
  • +1 / −1 events — max overlap
  • overlap — a.start ≤ b.end and b.start ≤ a.end
