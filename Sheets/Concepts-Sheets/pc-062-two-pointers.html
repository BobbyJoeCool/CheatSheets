Two Pointers

opposite ends · same direction (read / write) · sorted Two Sum · 3Sum · container with most water · remove duplicates in place

Two Indexes Instead of Two Loops

Two pointers replace a nested O(n²) loop with two indexes that each move at most n times: O(n). Opposite ends pointers work on sorted data: move the side that can improve the answer. Same-direction pointers (read and write) filter or compact an array in place. Sorting first (O(n log n)) often unlocks the pattern.

Recognize It When

  • Sorted array + pair/triplet with a target sum
  • "In place", "O(1) extra space", remove / move items
  • Palindromes, reversing, comparing from both ends
  • Maximize area / width between two positions

Opposite Ends: Two Sum (Sorted)

function twoSumSorted(arr, target)
    (l, r) ← (0, length(arr) - 1)
    while l < r
        s ← arr[l] + arr[r]
        if s = target
            return (l, r)
        if s < target
            l ← l + 1             // need bigger
        else
            r ← r - 1             // need smaller
    return null

Same Direction: Remove Duplicates

function removeDuplicates(arr)    // sorted input
    if arr is empty return 0
    w ← 1                         // next write slot
    for r ← 1 to length(arr) - 1
        if arr[r] ≠ arr[w - 1]
            arr[w] ← arr[r]       // keep it
            w ← w + 1
    return w                      // new length

3Sum (Sort + Anchor + Two Pointers)

function threeSum(nums)                     // O(n²)
    sort(nums)
    out ← []
    for i ← 0 to length(nums) - 3
        if i > 0 and nums[i] = nums[i - 1]
            continue                        // skip duplicate anchor
        (l, r) ← (i + 1, length(nums) - 1)
        while l < r
            s ← nums[i] + nums[l] + nums[r]
            if s < 0
                l ← l + 1
            else if s > 0
                r ← r - 1
            else
                out.append((nums[i], nums[l], nums[r]))
                l ← l + 1
                while l < r and nums[l] = nums[l - 1]
                    l ← l + 1               // skip duplicate
                r ← r - 1
    return out

Container With Most Water

function maxArea(h)
    (l, r, best) ← (0, length(h) - 1, 0)
    while l < r
        area ← (r - l) * min(h[l], h[r])
        best ← max(best, area)
        if h[l] < h[r]
            l ← l + 1     // shorter side
        else              // limits area
            r ← r - 1
    return best

⚠ Common Mistakes

  • Using opposite-end pointers on unsorted data: the move logic has no basis
  • Forgetting to skip duplicates in 3Sum: repeated triplets in the output
  • Moving the taller wall in Container With Most Water: can never improve the area

✓ Tips & Best Practices

  • Practice: Valid Palindrome, Two Sum II, 3Sum, Container With Most Water, Move Zeroes
  • Ask "which pointer's move can improve things?" and move only that one
  • 4Sum = two nested anchors + two pointers: O(n³)

Quick Summary

  • opposite ends — sorted pairs, O(n)
  • read / write — in-place filtering
  • sort + anchor — kSum
  • each pointer moves ≤ n times
