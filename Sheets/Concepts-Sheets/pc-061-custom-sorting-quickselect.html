Sorting Your Way, and Selecting Without Sorting

Real problems sort records by custom rules: by a field, descending, or by several keys. A comparator returns negative, zero, or positive; a key function returns a value to sort by (tuples give multi-key order). When you need only the kth element, quickselect partitions like quick sort but recurses into one side: O(n) on average.

Recognize It When

  • "Sort by … then by …", custom ordering rules
  • Sorting first makes a greedy or two-pointer scan possible
  • "kth largest / smallest" with no other ordering needed
  • "Largest number formed by …" (concatenation order)

Comparators and Keys

// comparator: < 0 → a first, 0 → tie, > 0 → b first
sort(people, lambda a, b: compare(a.age, b.age))      // ascending
sort(people, lambda a, b: compare(b.score, a.score))  // descending
sortBy(people, lambda p: (p.last, p.first))           // multi-key tuple
sortBy(words, lambda w: (-count[w], w))     // freq desc, then A→Z

// Largest Number: put a before b if a+b > b+a
sort(strs, lambda a, b: compare(b + a, a + b))
// ["3","30","34","5","9"] → "9534330"

Quickselect

function kthLargest(a, k)     // O(n) avg
    target ← length(a) - k    // sorted index
    (lo, hi) ← (0, length(a) - 1)
    while true
        p ← partition(a, lo, hi)  // 059
        if p = target
            return a[p]
        if p < target
            lo ← p + 1
        else
            hi ← p - 1

Comparator Contract

RuleMeaning
consistentsame inputs → same answer
antisymmetriccmp(a,b) = −cmp(b,a)
transitivea<b and b<c → a<c
no subtractiona − b can overflow

⚠ Common Mistakes

  • Returning a boolean from a comparator (JS, Java): sorting silently breaks
  • a.x - b.x with large values: overflow flips the sign; use compare
  • Quickselect with a fixed pivot on sorted input: degrades to O(n²)

✓ Tips & Best Practices

  • Negate numeric keys for descending order inside a tuple key
  • Python 3 has no cmp=; wrap with functools.cmp_to_key
  • Practice: Largest Number, Sort Characters by Frequency, Kth Largest, K Closest Points
