Matrices as Graphs

In a grid, each cell is a node and its 4 neighbors (up, down, left, right) are its edges. A direction array keeps neighbor code short, a bounds check keeps it safe, and you can often mark visited cells in place instead of using a set. DFS flood fill counts regions; BFS spreads in rings for minimum steps.

Recognize It When

  • 2D board of '1'/'0', walls, water, oranges
  • "Islands", "regions", "flood fill" → DFS or BFS
  • "Minimum minutes / steps" → BFS
  • "Reach the border / ocean" → start from the edges

Number of Islands (DFS Flood Fill)

DIRS ← [(1, 0), (-1, 0), (0, 1), (0, -1)]

function numIslands(grid)
    (R, C) ← (rows(grid), cols(grid))
    function sink(r, c)
        if r < 0 or r ≥ R or c < 0 or c ≥ C
            return                  // off grid
        if grid[r][c] ≠ '1' return  // water/seen
        grid[r][c] ← '0'            // mark seen
        for each (dr, dc) in DIRS
            sink(r + dr, c + dc)
    count ← 0
    for r ← 0 to R - 1
        for c ← 0 to C - 1
            if grid[r][c] = '1'
                sink(r, c)
                count ← count + 1
    return count

Rotting Oranges (Multi-Source BFS)

function orangesRotting(grid)
    queue ← new Queue()
    fresh ← 0
    for each cell (r, c)
        if grid[r][c] = 2 queue.enqueue((r, c))
        if grid[r][c] = 1 fresh ← fresh + 1
    minutes ← 0
    while fresh > 0 and not queue.isEmpty()
        repeat length(queue) times     // one minute
            (r, c) ← queue.dequeue()
            for each (dr, dc) in DIRS
                (nr, nc) ← (r + dr, c + dc)
                if inBounds(nr, nc) and grid[nr][nc] = 1
                    grid[nr][nc] ← 2
                    fresh ← fresh - 1
                    queue.enqueue((nr, nc))
        minutes ← minutes + 1
    return if fresh = 0 then minutes else -1

⚠ Common Mistakes

  • Checking grid[r][c] before the bounds check: index error at the edges
  • Mixing up rows and columns: grid[r][c], R = rows, C = cols
  • Modifying the input when the problem says not to: copy it or use a visited set

✓ Tips & Best Practices

  • Reverse the search: start from borders or targets instead of every cell
  • Count fresh cells first so you can stop early and detect -1
  • Deep DFS on a 1000×1000 grid can overflow the stack; BFS avoids that

Quick Summary

  • DIRS — neighbor offsets
  • bounds check — first, always
  • in-place marking — O(1) visited
  • multi-source BFS — spreading over time
