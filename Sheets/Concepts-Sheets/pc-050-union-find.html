Union-Find (Disjoint Set)

parent array · find · path compression · union by rank / size · component count · redundant connection

Tracking Connected Groups

Union-Find (disjoint set union) keeps items in groups and answers "are a and b connected?" while edges are added. Each group is a tree; find returns its root, union links two roots. With path compression and union by size/rank, each operation is nearly O(1): O(α(n)), where α grows so slowly it's under 5 for any practical n.

Recognize It When

  • Edges arrive one at a time; ask about connectivity
  • "Number of connected components / provinces"
  • "Which edge creates a cycle?" (redundant connection)
  • Grouping equivalent items (accounts, synonyms)

Union-Find with Both Optimizations

class UnionFind
    function init(n)
        this.parent ← [0, 1, …, n - 1]     // each node is its own root
        this.size ← new Array(n, 1)
        this.count ← n                     // number of groups
    function find(x)
        while this.parent[x] ≠ x
            this.parent[x] ← this.parent[this.parent[x]]   // path halving
            x ← this.parent[x]
        return x
    function union(a, b)
        (ra, rb) ← (this.find(a), this.find(b))
        if ra = rb return false            // already connected
        if this.size[ra] < this.size[rb]
            (ra, rb) ← (rb, ra)            // smaller tree goes under
        this.parent[rb] ← ra
        this.size[ra] ← this.size[ra] + this.size[rb]
        this.count ← this.count - 1
        return true

Code Explained

parent[x] = x — x is a root
path halving — point to grandparent while climbing
union by size — keeps trees shallow
union returns false — the edge closes a cycle
count — components left

Redundant Connection

function findRedundant(edges)   // nodes 1..n
    uf ← new UnionFind(length(edges) + 1)
    for each (u, v) in edges
        if not uf.union(u, v)
            return (u, v)   // closes a cycle
    return null

Cost per Operation

Versionfind / union
naiveO(n)
union by size onlyO(log n)

bothO(α(n)) ≈ O(1)

⚠ Common Mistakes

  • Comparing parent[a] = parent[b] instead of find(a) = find(b)
  • Linking a under b instead of root under root: breaks the trees
  • Off-by-one with 1-indexed nodes: allocate n + 1 slots

✓ Tips & Best Practices

  • Graph Valid Tree: exactly n − 1 edges and no union returns false
  • Map strings or grid cells (r * C + c) to integer ids first
  • Union-Find can't split groups; for deletions process edges in reverse

Quick Summary

  • find — root with path compression
  • union — attach smaller root under larger
  • false from union — cycle
  • O(α(n)) — effectively constant
