One Layout Across Three Apps

All three apps share a layout: a toolbar across the top and a sidebar on the right with Format (style the selection), Document (page setup, Pages / Numbers) and Animate (Keynote). Shared shortcuts include Copy Style / Paste Style (copy formatting), Paste and Match Style (paste as plain text) and the standard Mac text shortcuts.

Notes

  • Customize the toolbar: right-click it › Customize Toolbar
  • Format sidebar tabs change with the selection: Text, Arrange, Style, Table, Cell…
  • ⌘T Show Fonts and ⇧⌘C Show Colors open the system panels
  • Add your own shortcut for any menu item: System Settings › Keyboard › Keyboard Shortcuts › App Shortcuts
  • View › Show Rulers (⌘R) for tabs and indents in Pages and Keynote

Shared Shortcuts

⌥⌘C  ⌥⌘V      # copy style / paste style
⌥⇧⌘V          # paste and match style (plain text)
⌘B ⌘I ⌘U      # bold, italic, underline
⌘+  ⌘-        # bigger / smaller font
⌘{  ⌘|  ⌘}    # align left / center / right
⌃⌘+  ⌃⌘-      # superscript / subscript
⌘T  ⇧⌘C       # Fonts / Colors panels
⌘F  ⌘G  ⌘E    # find / find next / use selection for find
⌘K            # add link
⇧⌘K           # add comment
⌘R            # show / hide rulers
⇧⌘/           # Help menu search

Code Explained

Copy Style copies character and paragraph formatting; it works across the three apps
Paste and Match Style takes on the formatting where you paste
⌘E loads the selected text into Find so ⌘G jumps to the next match
Custom App Shortcuts need the exact menu item name, including "…"

Other Suites

  • Microsoft 365 — Format Painter, Paste Special ⌃⌘V / Ctrl+Alt+V, ribbon
  • Google Workspace — paint format, ⌘⇧V paste plain, menu search ⌥/

Platform Differences

  • Mac — every shortcut, custom App Shortcuts
  • iPad / iPhone — hold ⌘ with a keyboard to see shortcuts; Format button (brush)
  • iCloud (web) — Format sidebar and most shortcuts in the browser

⚠ Common Mistakes

  • Pasting web text with its fonts; use ⌥⇧⌘V
  • Restyling text by hand when Paste Style would copy it in one step
  • Hunting menus for rare commands; type them into Help search

✓ Tips & Best Practices

  • Add toolbar buttons for commands you use daily
  • Assign your own shortcut to any menu item you use a lot
  • Learn the Format sidebar tabs; nearly every setting lives there

Quick Summary
