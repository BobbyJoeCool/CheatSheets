Rules, Signatures & Accounts

Mail rules & conditions · apply rules · signatures per account · Gmail / Exchange / iCloud · Mail Privacy Protection · Hide My Email · block & mute

Let Mail Do the Filing

Rules (Mail › Settings › Rules) act on incoming mail: move, flag, colour, forward, play a sound or run a Shortcut. Signatures are set per account. Mail handles iCloud, Gmail, Exchange and IMAP accounts side by side. Mail Privacy Protection hides your IP and blocks tracking pixels.

Notes

  • Rules run on the Mac when Mail is open; iCloud rules (iCloud.com) run on the server
  • Apply rules to existing mail: select messages › Message › Apply Rules (⌥⌘L)
  • Signatures: Settings › Signatures; drag to an account; choose a default
  • Block a sender: hover the name › Block Contact
  • Privacy: Settings › Privacy › Protect Mail Activity

Automate It

  • Rules that file newsletters and receipts as they arrive
  • Rule action Run Shortcut for custom automation (sheet 24)

Create a Rule

  1. Mail › Settings › Rules › Add Rule
  2. Name it (e.g. "Receipts")
  3. Condition: From contains store@… or Subject contains receipt
  4. Action: Move Message to mailbox Receipts; add Mark as Read
  5. Click OK; choose Apply to run it on existing mail
  6. For server-side rules on iCloud mail, use iCloud.com › Mail › Settings › Rules

Platform Differences

  • Mac — every rule action (scripts, Shortcuts)
  • iPad / iPhone — no rule editor; server rules from iCloud.com still apply
  • iCloud (web) — server-side rules for iCloud addresses

⚠ Common Mistakes

  • Relying on Mac rules while the Mac is asleep; use server rules for 24/7 filing
  • Rules in the wrong order; Mail stops at the first rule that moves a message
  • Using one signature for work and personal accounts

✓ Tips & Best Practices

  • Put specific rules first
  • Use iCloud.com rules for iCloud addresses so iPhone stays tidy
  • Add a plain-text signature for replies
