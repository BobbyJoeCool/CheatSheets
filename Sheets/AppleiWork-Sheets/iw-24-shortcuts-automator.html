Shortcuts, Quick Actions & Text Replacements

Shortcuts app iWork actions · Quick Actions in Finder · Mail rule › run a Shortcut · Text Replacements · Automator (legacy) · Folder Actions

Automate Without Code

The Shortcuts app strings actions together: convert files, make PDFs, add rows, send messages. Shortcuts can run from the menu bar, Finder Quick Actions, keyboard shortcuts, Siri, or a Mail rule. Text Replacements expand short codes everywhere. Automator still works but Shortcuts is the modern path.

Notes

  • Shortcut details (ⓘ) › Use as Quick Action / Pin in Menu Bar / Add Keyboard Shortcut
  • Run AppleScript and Run Shell Script actions bridge to scripts
  • Automations (iPhone / iPad, and Mac) run on time, arrival or other triggers
  • Text Replacements: System Settings › Keyboard › Text Replacements
  • Folder Actions (Automator) run when files land in a folder

Automate It

  • Quick Action "Make PDF" for any Pages / Keynote file in Finder
  • Text Replacements for addresses, sign-offs and email templates

Build a Finder Quick Action

  1. Open Shortcuts › New Shortcut
  2. Add Receive Files from Quick Actions (input: Files)
  3. Add Make PDF (or Convert Image, Rename Files…)
  4. Add Save File to the same folder or a chosen one
  5. Details (ⓘ) › tick Use as Quick Action › Finder
  6. Right-click files in Finder › Quick Actions › your shortcut

⚠ Common Mistakes

  • Text Replacement codes that are real words
  • Building in Automator when Shortcuts covers it (Automator gets few updates)
  • Shortcuts that overwrite originals; save output to a new file
