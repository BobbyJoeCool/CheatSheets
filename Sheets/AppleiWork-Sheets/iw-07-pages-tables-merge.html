Tables, Charts & Mail Merge

tables in Pages · charts · media placeholders · mail merge from Numbers / Contacts · merge fields · ePub & PDF export

Data in Documents

Pages tables work like small Numbers tables, formulas included. Charts update when you edit their data. Mail merge fills merge fields from a Numbers spreadsheet or a Contacts group to make one personalised document per row, ready to print, PDF or share.

Notes

  • Table formulas: click a cell, type = (same functions as Numbers)
  • Merge fields: Document sidebar › Document tab › Mail Merge › Add Merge Field
  • Run the merge: Document button › Mail Merge, pick the Numbers file or Contacts group
  • Preview with real data before merging
  • Charts: Insert › Chart; Edit Chart Data opens the data editor

Automate It

  • Mail merge from a Numbers list instead of copying names into letters
  • Drag a Contact card onto merge fields for a single quick letter

Run a Mail Merge

  1. Keep recipients in Numbers: one header row, one row per person
  2. In Pages, place the cursor; Document sidebar › Document › Mail Merge › Add Merge Field
  3. Pick the field (e.g. First Name); repeat for each field
  4. Click Document in the toolbar › Mail Merge
  5. Choose the Numbers file (or Contacts group) under Populate With
  6. Click Preview, then Merge to create the documents

⚠ Common Mistakes

  • Blank rows or merged cells in the Numbers list
  • Header names in Numbers that don't match the merge fields you picked
  • Merging without previewing a few records

✓ Tips & Best Practices

  • Keep one master contacts spreadsheet and reuse it for every merge
  • Use a Contacts group for holiday cards and labels
  • Export the merged result to PDF for printing or emailing
