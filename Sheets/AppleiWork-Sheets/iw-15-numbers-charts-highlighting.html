Charts & Conditional Highlighting

chart types · interactive charts · edit chart references · conditional highlighting rules · highlight rules · copy rules

Show It and Flag It

Select data and click Chart to add a chart that stays linked to the table. Interactive charts add a slider to step through data sets. Conditional highlighting (Format › Cell › Conditional Highlighting) colours cells that meet rules: values, text, dates, durations, blanks, or matching another cell.

Notes

  • Edit Data References: select the chart › Edit Data References, then drag the coloured ranges
  • Plot rows or columns as series: toggle in the chart's data editing bar
  • Rules can compare to a cell (e.g. greater than Target::B2)
  • Copy rules with Copy Style / Paste Style (⌥⌘C / ⌥⌘V)
  • Numbers highlighting has no custom formula rules; use a helper column for complex logic

Automate It

  • Highlight rules on a whole column apply to new rows automatically
  • Interactive chart for monthly dashboards instead of 12 separate charts

Add a Chart and a Rule

  1. Select the cells to chart (include header cells)
  2. Click Chart in the toolbar; pick 2D, 3D or Interactive
  3. Style with the Format sidebar (Chart, Axis, Series tabs)
  4. Select a column of cells › Format › Cell › Conditional Highlighting
  5. Add a Rule: e.g. Numbers › Greater than › 1000 › Red Fill
  6. For complex logic, add a helper column with a formula and highlight on TRUE

⚠ Common Mistakes

  • Charting totals rows along with data, doubling the bars
  • Expecting formula-based highlight rules; use a helper column
  • 3D charts that hide values; prefer 2D

✓ Tips & Best Practices

  • Include header cells so series get names
  • Use value labels instead of gridlines for small charts
  • Compare against a target cell so changing the target updates highlights
