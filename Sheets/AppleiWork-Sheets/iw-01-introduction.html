Introduction to iWork

Pages / Numbers / Keynote · Mac, iPad, iPhone & iCloud · Apple Creator Studio · .pages .numbers .key · Office files

Apple's Free Office Suite

Pages (documents), Numbers (spreadsheets) and Keynote (presentations) come free on every Mac, iPad and iPhone, and run in a browser at iCloud.com on any computer. Files sync through iCloud Drive. They open and export Word, Excel and PowerPoint files. Apple Creator Studio (announced January 2026) is a subscription that adds premium templates, content and some intelligent features on top of the free apps.

Notes

  • App Store updates keep the apps current; check App Store › Updates
  • iCloud.com versions need only an Apple Account, so PC users can collaborate
  • Open Office files directly; export via File › Export To
  • Each app has a template chooser on launch (turn it off in Settings)
  • Creator Studio features are marked in the template chooser and menus

Open Things Fast

⌘N            # new document (template chooser)
⌘O            # open
⌘S  ⇧⌘S       # save / duplicate (save as)
⌘P            # print / PDF
File › Export To › Word / Excel / PowerPoint / PDF / EPUB
⇧⌘/           # Help menu search (find any command)
⌘,            # Settings
⌘W  ⌘Q        # close / quit

open -a Numbers budget.xlsx        # Terminal: open an Excel file in Numbers

Code Explained

iWork autosaves; Save names a file the first time, after that it saves versions
Duplicate (⇧⌘S) replaces Save As; hold ⌥ in the File menu to see Save As
Shortcuts on this set are Mac shortcuts; iPad keyboard shortcuts mostly match
The Help menu search box finds and highlights any menu command

Other Suites

  • Microsoft 365 — Word / Excel / PowerPoint, desktop + web, subscription
  • Google Workspace — Docs / Sheets / Slides in the browser, free account

Platform Differences

  • Mac — full feature set, AppleScript, Shortcuts
  • iPad / iPhone — nearly full editing, Apple Pencil, touch layouts
  • iCloud (web) — any browser; fewer features, good for collaboration

⚠ Common Mistakes

  • Sending .pages files to Windows users; export to Word or PDF
  • Expecting Excel macros or VBA to survive import (they're dropped)
  • Editing an exported copy and the original separately, so versions drift

✓ Tips & Best Practices

  • Use the Help menu search (⇧⌘/) whenever you can't find a command
  • Keep work in iCloud Drive for versions and collaboration
  • Turn off the template chooser if you always start blank

Quick Summary

  • Pages · Numbers · Keynote — free on Apple devices
  • iCloud.com — web versions
  • File › Export To — Office / PDF
  • ⇧⌘/ — Help menu search
