sort rules · filters · categories & summary rows · pivot tables · refresh pivot data · smart categories by date

Organize Data Without Formulas

The Organize sidebar sorts and filters a table. Categories group rows by a column value with collapsible summary rows (sum, count, average), like subtotals that update as you edit. Pivot tables (Organize › Create Pivot Table) summarise a source table into rows, columns and values, and refresh when the data changes.

Notes

  • Organize button (toolbar) › Sort / Filter / Categories
  • Categories by date can group by year, quarter, month or week
  • Summary row: click the category header cell › pick Sum, Count, Average…
  • Pivot: select a table › Organize › Create Pivot Table › On New Sheet / Current Sheet
  • Pivot options: Rows, Columns, Values in the Organize sidebar; Refresh after source edits

Automate It

  • Categories with summary rows instead of hand-written subtotals
  • A pivot table that refreshes in one click instead of a rebuilt summary

Group and Summarise

  1. Select the table; click Organize in the toolbar
  2. Categories › Add a Category › pick the column (e.g. Region)
  3. Click a category row's cell under Amount › choose Sum
  4. For a cross-tab: Organize › Create Pivot Table
  5. Drag fields to Rows, Columns and Values
  6. After editing the source table, click Refresh on the pivot

⚠ Common Mistakes

  • Forgetting to refresh pivot tables after editing the source
  • Filtering a shared table and confusing collaborators (filters apply to everyone)
  • Typing subtotals by hand that go stale

✓ Tips & Best Practices

  • Use categories for quick grouping; pivots for cross-tabs
  • Turn off filters before sending a file
  • GETPIVOTDATA pulls a pivot value into a formula
