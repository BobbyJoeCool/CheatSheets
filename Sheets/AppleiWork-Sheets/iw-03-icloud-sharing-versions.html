Sheet 03

iCloud, Collaboration & Versions

iCloud Drive · Share › Collaborate · permissions & activity · Browse All Versions · password protection · export to Office / PDF

Work Together and Go Back in Time

Save to iCloud Drive and you can collaborate: invite people by link, Messages or Mail, and edit at the same time from Mac, iPad, iPhone or iCloud.com. The activity list shows who changed what. Revert To › Browse All Versions brings back any earlier version, and a password protects sensitive files.

Notes

  • Share button (toolbar) › Collaborate › choose people and permission
  • Permissions: Only invited people / Anyone with the link; Can make changes / View only
  • Collaborators' cursors show in colour; the Collaboration button lists who's in
  • File › Set Password to require a password to open
  • Versions are kept automatically for files on iCloud Drive and the Mac

Collaborate and Restore

  1. Move the file to iCloud Drive (File › Move To)
  2. Click Share › Collaborate; set Only invited people or Anyone with the link
  3. Choose Can make changes or View only; send via Messages, Mail or copy link
  4. Watch changes in the activity list (Collaborate button › Show All Activity)
  5. To go back: File › Revert To › Browse All Versions
  6. Pick a version and click Restore, or hold ⌥ and click Restore a Copy

Other Suites

  • Microsoft 365 — OneDrive Share, AutoSave, Version History
  • Google Workspace — Share button, Version history (⌘⌥⇧H)

Platform Differences

  • Mac — full sharing, Browse All Versions (Time Machine-style)
  • iPad / iPhone — share and collaborate; versions on iCloud.com
  • iCloud (web) — collaborate from any browser, Browse versions

⚠ Common Mistakes

  • Sharing "Anyone with the link" for private documents
  • Exporting a copy to share instead of collaborating, then merging edits by hand
  • Forgetting a password; Apple can't recover it

✓ Tips & Best Practices

  • Send iCloud links to PC users; they can edit in the browser
  • Use Restore a Copy to compare an old version side by side
  • Export PDFs for final copies so layout never shifts

Quick Summary

  • Share › Collaborate — real-time editing
  • Activity list — who changed what
  • Revert To › Browse All Versions — restore
  • File › Set Password — protect
