A Faster Inbox in Mail

Apple Mail handles iCloud, Gmail, Exchange and other accounts in one inbox. Keyboard shortcuts cover every action, search tokens narrow results, Smart Mailboxes save searches, and VIPs surface important people. Send Later, Remind Me and Follow Up keep things from slipping, and categories (macOS 15.4+) sort mail into Primary, Transactions, Updates and Promotions.

Notes

  • Smart Mailbox: Mailbox › New Smart Mailbox; rules like From is VIP and Unread
  • VIP: hover a sender name › Add to VIPs
  • Send Later: click and hold the Send button
  • Remind Me: right-click a message › Remind Me
  • Categories: View › Show Mail Categories (turn off for a single list)

Automate It

  • Smart Mailboxes instead of manual searches every morning
  • VIPs + notifications only for VIPs

Mail Shortcuts & Search

⌘N            # new message
⌘R  ⇧⌘R       # reply / reply all
⇧⌘F           # forward
⇧⌘D           # send
⇧⌘N           # get new mail
⇧⌘U           # mark read / unread
⇧⌘L           # flag
⌃⌘A           # archive
⌥⌘F           # search
⌘1  ⌘2        # go to Inbox / VIPs (favorites order)

from:dana subject:invoice date:last week
attachment:pdf  is:flagged  is:unread

Code Explained

Mail search turns typed words into tokens (From, Subject, Date) you can click to adjust
⌘1… jump to favorites in the Favorites bar order
Archive moves mail out of the inbox without deleting
Rules (sheet 21) can file mail automatically

Other Suites

  • Microsoft 365 — Outlook search operators, Focused Inbox, Quick Steps
  • Google Workspace — Gmail operators, labels, snooze, filters

Platform Differences

  • Mac — Smart Mailboxes, rules, categories
  • iPad / iPhone — categories, Remind Me, Send Later; no Smart Mailbox editing
  • iCloud (web) — iCloud Mail only; rules via settings

⚠ Common Mistakes

  • Leaving categories on and missing mail in Updates; check the setting
  • Deep folder trees instead of Smart Mailboxes and search
  • Using flags with no plan; pair flags with a Smart Mailbox

✓ Tips & Best Practices

  • Make a Smart Mailbox "Flagged and from VIPs"
  • Undo Send: Settings › Composing › Undo send delay
  • Use Hide My Email for sign-ups
