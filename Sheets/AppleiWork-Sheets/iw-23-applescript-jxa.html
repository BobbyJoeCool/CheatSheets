AppleScript & JXA for iWork

Script Editor · tell application "Numbers" · tables, rows & cell values · batch export · JXA · Script menu

Script the Apps

Pages, Numbers and Keynote are scriptable with AppleScript or JavaScript for Automation (JXA) in Script Editor. Scripts can read and write table cells, loop through rows, change text, and batch-export files to PDF or Office formats. Save scripts to the Script menu for one-click use.

Notes

  • Script Editor: Applications › Utilities › Script Editor
  • Dictionary: File › Open Dictionary › Numbers shows every command and object
  • Pick JavaScript in the language pop-up for JXA
  • Script menu: Script Editor › Settings › Show Script menu in menu bar
  • First run asks for Automation permission (System Settings › Privacy & Security)

AppleScript: Numbers and Pages

-- Flag rows over 1000 in the front Numbers table
tell application "Numbers"
  tell table 1 of sheet 1 of front document
    repeat with r from 2 to row count
      set amt to value of cell 4 of row r
      if amt > 1000 then set value of cell 5 of row r to "Review"
    end repeat
  end tell
end tell

-- Export every open Pages document to PDF on the Desktop
tell application "Pages"
  repeat with d in documents
    set outPath to (path to desktop as text) & (name of d) & ".pdf"
    export d to file outPath as PDF
  end repeat
end tell

Code Explained

Objects nest: document › sheet › table › row › cell
row count and column count give table size
export … as PDF also accepts Microsoft Word, Microsoft Excel, Microsoft PowerPoint formats
Run with ⌘R in Script Editor; compile (check syntax) with ⌘K

⚠ Common Mistakes

  • Running scripts on the wrong front document; name documents explicitly
  • Cell-by-cell loops over thousands of rows (slow); keep tables small or export CSV
  • Denying the Automation prompt and wondering why nothing happens

✓ Tips & Best Practices

  • iWork has no macro recorder, so start from the Dictionary and examples
  • Save scripts as apps or to the Script menu
  • Use Shortcuts' Run AppleScript action to mix both

Quick Summary
