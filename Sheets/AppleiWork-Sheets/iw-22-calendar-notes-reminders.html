Calendar, Notes & Reminders

Calendar quick event · shared calendars · Notes tags & smart folders · Quick Note · Reminders lists, sections & smart lists · reminders from Mail

The Rest of the Apple Toolkit

Calendar creates events from plain language ("Lunch with Sam Friday noon") and shares calendars through iCloud. Notes supports checklists, tables, tags and smart folders, and Quick Note captures from anywhere. Reminders organizes tasks into lists with sections, tags and smart lists, and can be created from Mail.

Notes

  • Calendar quick event: + button or ⌘N, then type naturally
  • Share an iCloud calendar: right-click it › Share Calendar
  • Notes tags: type #tag; smart folders filter by tag, date, checklist
  • Quick Note: hot corner or fn Q / Globe Q
  • Reminders: drag a Mail message into Reminders to link it

Shortcuts

# Calendar
⌘N            # new event (natural language)
⌘T            # go to today
⌘1 ⌘2 ⌘3 ⌘4   # day / week / month / year
⌘→  ⌘←        # next / previous period

# Notes
⌘N            # new note
⇧⌘L           # checklist
⇧⌘U           # mark checklist item done
⌥⌘T           # insert table
fn Q          # Quick Note (Globe + Q)

# Reminders
⌘N            # new reminder
⇧⌘N           # new list

Code Explained

Natural-language events understand dates, times and "every Monday"
Notes checklists can be sorted to move done items to the bottom
Quick Notes link to the app or web page you were in
Reminders smart lists filter by tag, date, location, priority

⚠ Common Mistakes

  • Keeping to-dos in Notes, Reminders and Mail flags at once
  • Sharing a calendar publicly when only family needed it
  • Forgetting locked notes need their password on every device

✓ Tips & Best Practices

  • Use Notes tags + smart folders instead of nested folders
  • Drag emails into Reminders for linked follow-ups
  • Type events in plain language and let Calendar parse them
