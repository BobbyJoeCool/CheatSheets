Interactive Cells

Numbers cells can be more than text: checkboxes, star ratings, sliders, steppers and pop-up menus are all cell formats (Format › Cell › Data Format). Autofill extends patterns by dragging the yellow handle. Duration is a real format, so time tracking adds up correctly.

Notes

  • Autofill: select cells, drag the yellow dot on the edge
  • Data Format pop-up: Automatic, Number, Currency, Percentage, Date & Time, Duration…
  • Pop-up Menu format: list choices once, then pick in each cell
  • Checkbox values are TRUE / FALSE in formulas
  • Form (iPad / iPhone): enter one row at a time like a form

Automate It

  • Pop-up menus instead of typed status values, so sorting and counting stay clean
  • Checkbox + COUNTIF(…, TRUE) for live progress counts

Entry Shortcuts

=                 # start a formula in the cell
⌥↩                # line break in a cell
⌥⌘C  ⌥⌘V          # copy / paste style only
⇧⌘V               # paste formula results (values)
⌥⇧⌘V              # paste and match style
Table › Autofill Cells › Down   # fill down
Table › Autofill Cells › Right
Format › Cell › Data Format › Pop-Up Menu
⌥ + drag cell     # copy a cell

Code Explained

Numbers has no "insert today" shortcut; use =TODAY() and paste results to freeze it
Paste Formula Results turns formulas into fixed values
Autofill continues series like Monday → Tuesday, Q1 → Q2, 1, 2 → 3
Pop-up menu options can include a blank first item for "not set"

⚠ Common Mistakes

  • Typing "Done" / "done" / "DONE"; use a pop-up menu
  • Storing times as text ("2:30") instead of a Duration format
  • Expecting Excel's Ctrl+; today shortcut

✓ Tips & Best Practices

  • Use sliders or steppers for model inputs people will tweak
  • Star ratings make quick scoring sheets
  • Paste Formula Results to freeze calculated values
