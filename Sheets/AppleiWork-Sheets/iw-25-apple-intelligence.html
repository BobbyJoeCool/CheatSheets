Writing Tools · Mail summaries & smart replies · Image Playground / Image Wand · ChatGPT extension · Creator Studio features · verify AI edits

AI in Apple's Apps

On supported Macs, iPads and iPhones, Apple Intelligence adds Writing Tools (proofread, rewrite, summarise) in Pages, Keynote, Mail and any text field, summaries and smart replies in Mail, and Image Playground for generated images. An optional ChatGPT extension can handle requests Apple's models can't. Apple Creator Studio adds more intelligent features to Pages, Numbers and Keynote by subscription.

Notes

  • Turn on: System Settings › Apple Intelligence & Siri
  • Writing Tools: select text › right-click › Writing Tools (or the ✦ icon)
  • Mail: summary at the top of long threads; Priority messages; Smart Reply
  • Image Playground and Image Wand create images from prompts or sketches
  • Feature availability varies by device, language, region and subscription

Prompts & Writing Tools

# Keynote / Pages with Creator Studio (check current features)

"Suggest a layout for this page"

Code Explained

Proofread marks each change so you can review them one by one
Writing Tools work in any app with text fields, not just iWork
ChatGPT requests ask before sending anything off-device
Creator Studio features change over time; check Apple's current list

Platform Differences
