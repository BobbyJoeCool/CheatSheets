Reports, Books and Manuals in Pages

Long documents in Pages run on paragraph styles: apply Heading styles and the table of contents builds itself, both in the document and in the TOC sidebar for navigation. Sections let headers, footers and page numbering change, footnotes and endnotes number automatically, and bookmarks create cross-links inside the document.

Notes

  • TOC: Insert › Table of Contents › Document / Section; it updates automatically
  • TOC sidebar: View › Table of Contents (click to jump)
  • Headers / footers: Document sidebar › Section tab; Hide on first page
  • Page numbers: click in header / footer › Insert › Page Number; Section tab › Start at
  • Footnote: Insert › Footnote; switch to endnotes in Document › Footnotes

Automate It

  • Paragraph styles drive the TOC, so no manual page lists
  • Bookmarks + links instead of typed "see page 12"

Long-Doc Shortcuts

F1 … F8         # your paragraph style shortcuts
Insert › Page Break  # page break
⇧⌘I            # show invisibles
⌘K             # add link (to a bookmark, URL, email)
⌘F             # find; options for match case / whole words
⇧⌘W            # show word count

Insert › Table of Contents › Document
Insert › Footnote
Format › Bookmark (Bookmarks list in Document sidebar)

Code Explained

Choose which styles appear in the TOC: select the TOC › Format sidebar › tick styles
The TOC updates as headings change; no refresh step
Sections start at section breaks; each has its own header / footer settings
Links to bookmarks keep working when text moves

⚠ Common Mistakes

  • Headings made with bold Normal text; they never reach the TOC
  • Changing a header and having every section change; turn off Match previous section
  • Typing page numbers into the footer instead of inserting a page number field

✓ Tips & Best Practices

  • Set style shortcuts F1–F8 for headings while writing
  • Use the TOC sidebar as your navigation pane
  • Export to PDF with "Include table of contents" for bookmarks in the PDF

Quick Summary

  • Paragraph styles — power the TOC
  • Insert › Table of Contents — auto-updating
  • Section tab — headers / numbering per section
  • Format › Bookmark — internal links
