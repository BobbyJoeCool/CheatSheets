Text Clean-Up and Date Math

Numbers has modern text functions (TEXTBEFORE, TEXTAFTER, TEXTBETWEEN, TEXTSPLIT, TEXTJOIN) and regular expressions through REGEX (as a condition inside other functions), REGEX.EXTRACT and COUNTMATCHES. Dates and durations are first-class: DATEDIF, EOMONTH, NETWORKDAYS, plus DUR2HOURS and friends to turn durations into numbers.

Notes

  • REGEX.EXTRACT(source, regex, occurrence, capture-group)
  • REGEX("pattern") can be used where a condition or search string is expected (SUBSTITUTE, COUNTIF, MATCH…)
  • Add (?i) to a pattern for case-insensitive matching
  • Durations: format a cell as Duration; DUR2HOURS(B2) gives a number
  • Date & Time format can show date, time or both

Text, Regex & Date Formulas

=TEXTBEFORE(Email, "@")                    # jane
=TEXTAFTER(Email, "@")                     # acme.com
=TEXTBETWEEN(A2, "(", ")")                 # text inside parentheses
=TEXTJOIN(", ", TRUE, B2:B10)
=PROPER(TRIM(A2))
=REGEX.EXTRACT(A2, "\d{3}-\d{4}")          # 555-1234
=REGEX.EXTRACT(A2, "(\w+)@(\w+)", 1, 2)     # 2nd capture group
=COUNTMATCHES(A2, REGEX("\b\w+\b"))        # word count
=SUBSTITUTE(A2, REGEX("\s+"), " ")          # collapse spaces
=EOMONTH(TODAY(), 0)
=DATEDIF(Birth, TODAY(), "Y")
=NETWORKDAYS(Start, End)
=DUR2HOURS(Worked)×Rate                    # duration × hourly rate

Code Explained

Numbers patterns use ICU regular expressions; \d, \w, \s, groups and (?i) all work
REGEX inside SUBSTITUTE replaces every match
COUNTMATCHES counts how many times a pattern appears
Duration × number needs DUR2HOURS (or similar) first

⚠ Common Mistakes

  • Multiplying a duration by a rate directly; convert with DUR2HOURS
  • Dates typed as text in an unusual format; set Date & Time format first
  • Forgetting regex is case-sensitive; add (?i)

✓ Tips & Best Practices

  • Use TEXTBETWEEN for codes in brackets or quotes
  • COUNTMATCHES + REGEX makes a quick word or tag counter
  • Track time as Duration so totals read "12h 30m"

Quick Summary

  • TEXTBEFORE / AFTER / BETWEEN — slice text
  • REGEX.EXTRACT — pull matches
  • REGEX("…") — pattern inside other functions
  • DUR2HOURS — duration to number
