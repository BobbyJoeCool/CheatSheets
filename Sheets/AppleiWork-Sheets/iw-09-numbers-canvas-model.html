Tables on a Blank Page

A Numbers sheet is a blank canvas, not an endless grid. On it you place tables, charts, text and images, each a separate object you can move and resize. Every table has its own header rows, header columns and footer rows, its own name, and only as many rows and columns as you give it. Formulas refer to tables by name.

Notes

  • Add a table: Table button in the toolbar; pick a style
  • Rename: click the table name (turn it on in Format › Table › Table Name)
  • Header rows stay visible when scrolling and can repeat on printed pages
  • Footer rows are good for totals; they stay at the bottom as rows are added
  • Resize a table by dragging the round handle at the bottom right

Table Navigation & Structure

Tab / ⇧Tab       # next / previous cell (Tab at end adds a column)
↩ / ⇧↩           # next / previous row (↩ at end of last row adds a row)
⌥↑  ⌥↓           # add row above / below
⌥←  ⌥→           # add column before / after
⌥⌘⌫              # delete selected rows or columns
⌘↑ ⌘↓ ⌘← ⌘→      # jump to table edge
⌥↩               # line break inside a cell
Esc              # stop editing, keep cell selected

Code Explained

A table only has the rows you add, so size it to the data
Header rows and columns are included in formulas by name, not by number
Click the table once to select it as an object; again to select a cell
Use multiple small tables (Inputs, Data, Summary) instead of one huge grid

Other Suites

  • Microsoft 365 — Excel: one huge grid per sheet; tables (Ctrl+T) are ranges inside it
  • Google Workspace — Sheets: grid per tab like Excel; tables via Convert to table

Platform Differences

  • Mac — full table tools
  • iPad / iPhone — tap and drag handles; Form view for data entry (iPad / iPhone)
  • iCloud (web) — tables and formulas; fewer table options

⚠ Common Mistakes

  • Building one giant table like an Excel sheet; split into named tables
  • Leaving default names like "Table 1" before writing cross-table formulas
  • Typing totals into a body row instead of a footer row, so sorting moves them

✓ Tips & Best Practices

  • Name every table before writing formulas
  • Put inputs, data and results on separate tables on one sheet
  • Use footer rows for totals so new data rows go above them
