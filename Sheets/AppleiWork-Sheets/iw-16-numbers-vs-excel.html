Living in a Mixed Office

Numbers opens .xlsx files and exports them, and recent versions share most of Excel's modern functions (XLOOKUP, FILTER, UNIQUE, LET, LAMBDA, TEXTSPLIT). The gaps are in features, not formulas: no VBA, no Power Query, no data model, and layout differences because Numbers puts tables on a canvas. Know what survives a round trip before you send a file.

Notes

  • Import: open the .xlsx; Numbers shows a warning list of what changed
  • Export: File › Export To › Excel; choose one sheet per table or one per sheet
  • Each Numbers table becomes its own Excel sheet unless you combine them
  • Macros (VBA) are removed on import
  • Check the Functions Browser before relying on a function a coworker uses in Excel

Round-Trip Checklist

# Before importing an Excel file
1. Save a copy of the original .xlsx
2. Open in Numbers → read the import warnings
3. Check: pivot tables, charts, conditional formats, data validation

# Before exporting to Excel
File › Export To › Excel › Advanced Options:
   ☑ Include a summary worksheet       ☐ one worksheet per table
4. Open the export in Excel (or Excel for the web) and test key formulas
5. Replace Numbers-only features (pop-up menus, sliders, durations)

# Functions to double-check in both directions
GROUPBY · PIVOTBY · REGEXTEST · REGEXREPLACE · COPILOT · PY
DUR2HOURS · REGEX · COUNTMATCHES · TEXTBETWEEN · STOCK

Code Explained

Excel-only functions (e.g. GROUPBY, PIVOTBY) become values or errors in Numbers
Numbers-only functions (DUR2HOURS, REGEX conditions, COUNTMATCHES) turn into values in Excel
Pop-up menus become data validation lists; sliders become plain numbers
Always reopen exports in the other app before sending them out

Other Suites

  • Microsoft 365 — Excel is the usual destination; check in Excel for the web
  • Google Workspace — Sheets opens .xlsx too; QUERY / IMPORTRANGE have no Numbers equivalent

Platform Differences

  • Mac — import / export options in full
  • iPad / iPhone — export to Excel from the Share menu
  • iCloud (web) — download as Excel

When to Hand Off

SituationUse

Data > ~100k rowsExcel / Sheets
Automation needed on a serverExcel + Office Scripts / Sheets + Apps Script
Design-heavy reportNumbers (export PDF)

⚠ Common Mistakes

  • Sending an exported file without opening it in Excel first
  • Assuming every Excel function exists in Numbers (or the reverse)
  • Editing both the .numbers and .xlsx copies so they drift apart

✓ Tips & Best Practices

  • Keep one master format; export only for sharing
  • Use PDF for read-only sharing; layout is guaranteed
  • For mixed teams, iCloud.com links let PC users edit in the browser

Quick Summary

  • Import warnings — read them
  • Export To › Excel — per sheet / table
  • No VBA / Power Query — features, not formulas, differ
  • Reopen exports — test before sending
