Sheet 18

Building Slides & Animations

Magic Move · build in / build out · Action builds · Animate sidebar & build order · alignment guides · Instant Alpha · object styles

Motion With Meaning

Magic Move is Keynote's signature transition: duplicate a slide, move or resize objects on the copy, and Keynote animates the change. Builds bring objects in (build in), out (build out) or animate them in place (Action). The Build Order window sets sequence and timing. Instant Alpha removes image backgrounds.

Notes

  • Animate button (toolbar) opens the Animate sidebar
  • Magic Move matches objects that appear on both slides
  • Build Order: Animate › Build Order; set On Click, After Previous or With Previous
  • Instant Alpha: select image › Format › Image › Instant Alpha, drag over the background
  • Alignment guides appear while dragging; hold ⌘ to turn them off temporarily

Automate It

  • Magic Move between duplicated slides instead of hand-built motion paths
  • Copy Animation / Paste Animation to repeat builds

Building Shortcuts

⇧⌘N             # new slide
⌘D              # duplicate slide or object
⇧⌘H             # skip / unskip slide
⌥⌘G  ⇧⌥⌘G       # group / ungroup
⇧⌘F  ⇧⌘B        # bring to front / send to back
⌥⇧⌘F ⌥⇧⌘B       # bring forward / send backward
⌘L   ⌥⌘L        # lock / unlock
⌥ + drag        # duplicate while dragging
⇧ + drag        # constrain movement / proportions
⌘ + drag        # turn off alignment guides
Format › Copy Animation / Paste Animation

Code Explained

Duplicate the slide (⌘D) before making the Magic Move version
Skipped slides stay in the deck but don't play
Locked background objects can't be moved by accident
Builds can run by paragraph, so bullets appear one at a time

⚠ Common Mistakes

  • Too many builds per slide; they slow the talk
  • Changing an object's text on the second slide, which breaks the Magic Move match
  • Long durations; 0.5 s reads well

✓ Tips & Best Practices

  • Use Magic Move to "zoom" into part of a chart
  • Lock background shapes before building animations
  • Rehearse with the Build Order window open

Quick Summary

  • Magic Move — duplicate, change, transition
  • Build In / Out / Action — object motion
  • Build Order — sequence and timing
  • ⌘L — lock objects
