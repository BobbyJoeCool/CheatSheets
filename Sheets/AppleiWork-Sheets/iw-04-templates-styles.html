Sheet 04

Templates & Styles

template chooser · Save as Template · My Templates · paragraph, character & list styles · object styles · Creator Studio templates

Set Up Once, Reuse Forever

Every new file starts in the template chooser. Save your own with File › Save as Template and it appears under My Templates. Inside a file, paragraph, character and list styles (Pages, Keynote text) and object styles (shapes, tables, charts, text boxes) let you restyle many items at once. Creator Studio subscribers get extra premium templates.

Notes

  • Paragraph styles: Format sidebar › Text › style name; Update when you change one
  • Style shortcuts: assign F1–F8 from the paragraph style menu (Pages)
  • Object styles: select an object › Format › Style › + to save its look
  • Templates sync to other devices through iCloud
  • Settings › General › For New Documents: choose a default template

Automate It

  • Save as Template + a default template = new files start correct
  • Style shortcuts F1–F8 for the styles you apply most

Make a Template

  1. Build the file: styles, colours, placeholders, logo
  2. Turn text into placeholders: select text › Format › Advanced › Define as Placeholder Text
  3. Turn images into media placeholders: Format › Image › Define as Media Placeholder
  4. File › Save as Template › Add to Template Chooser
  5. Name it; it shows under My Templates
  6. Settings › General › For New Documents › Use template

⚠ Common Mistakes

  • Changing one paragraph by hand and forgetting to click Update
  • Copying last year's file instead of starting from a template
  • Hard-coding colours instead of saving object styles

✓ Tips & Best Practices

  • Assign F1–F8 to your most-used paragraph styles
  • Save object styles for brand shapes and tables
  • Keep templates in iCloud so every device has them
