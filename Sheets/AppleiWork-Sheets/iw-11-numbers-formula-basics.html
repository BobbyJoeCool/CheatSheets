Formulas That Read Like Sentences

Type = in a cell to open the formula editor and the Functions Browser. Numbers can refer to cells by header names (Price Widget = Price column, Widget row) as well as by address. Other tables use Table::Cell, other sheets Sheet::Table::Cell. Click a reference's arrow to preserve row or column, the equivalent of $.

Notes

  • Header-name references need header rows / columns turned on
  • Click cells or drag ranges while editing a formula; Numbers writes the reference
  • Preserve: click the reference token's triangle › Preserve Row / Preserve Column
  • Quick calculations: select cells and read Sum, Average, Min, Max at the bottom
  • Errors show a red triangle; click it for the message

References & Operators

=B2×C2                         # Numbers shows × for *
=Price × Quantity              # header names (same row)
=SUM(Amount)                   # whole Amount column
=SUM(Sales::Amount)            # column in another table
=Inputs::B2                    # cell in table "Inputs"
=Summary::Totals::B2           # sheet::table::cell
=B2×$F$1                       # preserved row and column
="Total: "&D2                  # join text with &
=A2<>""                        # not empty
=(B2−C2)÷C2                    # growth

Code Explained

Numbers displays * as × and / as ÷; type either
A whole-column reference like SUM(Amount) excludes header and footer rows
Cross-table references update if you rename the table
The Functions Browser (right side) shows syntax and examples for every function

⚠ Common Mistakes

  • Copying formulas without preserving the input cell, so references drift
  • Header names with spaces or duplicates that make references ambiguous
  • Forgetting that renaming a table changes every formula's text (correctly, but surprisingly)

✓ Tips & Best Practices

  • Turn on header rows and use names; formulas explain themselves
  • Keep inputs in their own table and refer to them by Inputs::
  • Use quick calculations at the bottom instead of writing throwaway formulas
