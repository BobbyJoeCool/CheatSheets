Logic, Math & Lookup Functions

IF · IFS · SWITCH · IFERROR · SUMIFS · COUNTIFS · AVERAGEIFS · XLOOKUP · XMATCH · INDEX / MATCH · VLOOKUP

Decide, Summarise, Look Up

Numbers supports the same core functions as Excel and Sheets: IF, IFS, SWITCH, the conditional …IFS family, and modern lookups like XLOOKUP and XMATCH. Header names make them readable: =SUMIFS(Amount, Region, "West"). Recent versions add array functions such as FILTER, UNIQUE and SORT.

Notes

  • Criteria: ">100", "<>Closed", ">="&F1
  • Wildcards in criteria: "*north*"; Numbers also accepts REGEX("…") as a condition
  • SUMIFS: sum values first, then test values / condition pairs
  • XLOOKUP(search-for, search-where, result-values, if-not-found, match-type, search-type)
  • Check the Functions Browser for argument names in your version

Automate It

  • One SUMIFS table driven by input cells instead of filtered copies
  • XLOOKUP against a Prices table instead of retyping prices

Logic & Lookup Formulas

=IF(Score≥70, "Pass", "Fail")
=IFS(Score≥90,"A", Score≥80,"B", Score≥70,"C", TRUE,"F")
=SWITCH(Code, "N","North", "S","South", "Other")
=SUMIFS(Sales::Amount, Sales::Region, "West")
=COUNTIFS(Status, "Open", Due, "<"&TODAY())
=AVERAGEIFS(Amount, Product, "Widget")
=SUMIFS(Amount, Name, REGEX("^A"))                  # names starting with A
=XLOOKUP(SKU, Products::SKU, Products::Price, "Not found")
=XLOOKUP(Income, Rates::Min, Rates::Rate, , -1)     # bracket
=INDEX(Products::Price, MATCH(SKU, Products::SKU, 0))
=IFERROR(B2÷C2, 0)
=FILTER(Sales::A2:D100, Sales::Region="West")       # recent versions

Code Explained

≥ and >= both work; Numbers displays the symbol
REGEX("…") as a criteria value lets SUMIFS / COUNTIFS match patterns
XLOOKUP match-type -1 = exact or next smaller
Array functions spill results into the cells below in recent versions

⚠ Common Mistakes

  • Putting the sum values last in SUMIFS
  • Writing ">F1" instead of ">"&F1
  • VLOOKUP with approximate matching on unsorted data

✓ Tips & Best Practices

  • Use header names in formulas for readability
  • Use REGEX conditions instead of helper columns
  • Wrap lookups with an if-not-found value instead of IFERROR
