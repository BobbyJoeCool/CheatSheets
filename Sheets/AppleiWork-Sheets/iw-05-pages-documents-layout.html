Word Processing vs Page Layout

document types & converting · sections · text boxes & linked text boxes · inline vs floating objects · text wrap · facing pages

Two Kinds of Pages Documents

Pages has two modes. Word processing documents flow text from page to page (reports, letters). Page layout documents are canvases where you place text boxes and images freely (flyers, newsletters). Switch with File › Convert to Page Layout / Word Processing. Objects can sit inline with text, move with text, or stay on page.

Notes

  • Document sidebar › Document › Document Body checkbox = word processing
  • Linked text boxes (page layout): text flows from one box to the next
  • Object placement: Format › Arrange › Stay on Page / Move with Text
  • Text Wrap: Automatic, Around, Above and Below, Through, None
  • Facing pages: Document › Document › Facing Pages for book layouts

Layout Shortcuts

Insert › Page Break            # page break (word processing)
Insert › Section Break         # new section
Insert › Column Break          # next column
⇧⌘I            # show invisibles (¶, breaks)
⌘R             # show rulers
⌥⌘G  ⇧⌥⌘G      # group / ungroup objects
⇧⌘F  ⇧⌘B       # bring to front / send to back
⌥⇧⌘F ⌥⇧⌘B      # bring forward / send backward
⌘L  ⌥⌘L        # lock / unlock object
⌥ + drag       # duplicate object

Code Explained

Show invisibles (⇧⌘I) reveals breaks and spaces so you can delete stray ones
Locked objects can't be moved by accident; unlock with ⌥⌘L
Inline objects behave like big characters inside the text
Converting to Page Layout removes the main text body; content becomes text boxes

Other Suites

  • Microsoft 365 — Word for flowing docs; Publisher (retired) or PowerPoint for layouts
  • Google Workspace — Docs pageless / pages modes; no free page layout canvas

Platform Differences

  • Mac — both modes, linked text boxes
  • iPad / iPhone — both modes; touch arrange
  • iCloud (web) — both modes, fewer layout controls

⚠ Common Mistakes

  • Building a flyer in word processing mode and fighting the text flow
  • Spacing with blank lines and spaces instead of breaks and spacing
  • Leaving images on Stay on Page in flowing documents, so they drift from their text

✓ Tips & Best Practices

  • Decide the type before you start; converting later rearranges content
  • Turn on invisibles when layouts misbehave
  • Lock background shapes so they don't move while editing

Quick Summary

  • Word processing — text flows
  • Page layout — free canvas
  • ⇧⌘I — show invisibles
  • Move with text / Stay on page — object anchoring
