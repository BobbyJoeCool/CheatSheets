Sheet 17

Themes & Master Slides

Edit Master Slides · layouts & placeholders · custom themes · Save Theme · change theme · Creator Studio themes

Design the Deck Once

Every Keynote presentation uses a theme made of master slides (Title, Title & Bullets, Photo…). Edit the masters and every slide based on them updates. Save Theme adds your design to the theme chooser so new decks start on-brand. Creator Studio subscribers see additional premium themes.

Notes

  • Edit masters: View › Edit Master Slides (or right-click a slide › Edit Master Slide)
  • Placeholders: Format › Style › Define as Text / Media Placeholder
  • Change a slide's master: Format sidebar › Slide Layout › master thumbnail
  • File › Save Theme › Add to Theme Chooser
  • Change theme on an existing deck: Document sidebar › Change Theme

Automate It

  • Custom theme with master slides instead of copying old decks
  • Media placeholders so dropped photos crop and position themselves

Build a Custom Theme

  1. Start from a simple theme; open View › Edit Master Slides
  2. Set fonts and colours on the main text placeholders
  3. Add the logo to each master you'll use; delete masters you won't
  4. Add media placeholders where photos go
  5. Click Done, then File › Save Theme › Add to Theme Chooser
  6. Apply to old decks via Document sidebar › Change Theme

⚠ Common Mistakes

  • Restyling each slide instead of the master
  • Pasting logos per slide; put them on masters
  • Typing into free text boxes, which don't follow master changes

✓ Tips & Best Practices

  • Name custom masters clearly for others
  • Keep a "style guide" slide in the theme
  • Use Update in Slide Layout after pasting slides from another deck
