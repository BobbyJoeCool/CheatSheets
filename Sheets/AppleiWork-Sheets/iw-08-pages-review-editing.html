Review & Editing

Track Changes · comments & highlights · Find & Replace · word count · Text Replacements · dictation · Writing Tools

Edit, Review, Proofread

Track Changes marks every edit with the author's colour so changes can be accepted or rejected. Comments and highlights hold notes without changing text. Find & Replace has options for case and whole words. macOS Text Replacements, Dictation and the Apple Intelligence Writing Tools speed up writing and proofreading.

Notes

  • Track Changes: Edit › Track Changes; toolbar for Accept / Reject
  • Comment: ⇧⌘K; highlight: ⇧⌘H
  • Find & Replace: ⌘F, then the gear for Find & Replace and options
  • Text Replacements: System Settings › Keyboard › Text Replacements (all apps)
  • Writing Tools: select text, right-click › Writing Tools (Apple Intelligence Macs)

Review Shortcuts

⇧⌘E           # Track Changes on / off
⇧⌘K           # add comment
⇧⌘H           # highlight
⌘F            # find (gear › Find & Replace)
⌘G  ⇧⌘G       # next / previous match
⌘E            # use selection for find
⇧⌘W           # show word count
⌘;            # next misspelled word
⇧⌘;           # spelling and grammar panel
fn fn / Globe twice  # start dictation

Code Explained

Turn tracking on before editing; earlier edits aren't tracked
Comments and highlights can be replied to and resolved in the Comments pane
Text Replacements sync via iCloud to iPhone and iPad
Writing Tools can proofread, rewrite in a tone, or summarise selected text

Other Suites

  • Microsoft 365 — Word Track Changes ⇧⌘E / Ctrl+Shift+E, Compare, Editor
  • Google Workspace — Docs Suggesting mode, Compare documents, regex replace

Platform Differences

  • Mac — tracking, comments, Writing Tools (Apple Intelligence Macs)
  • iPad / iPhone — tracking, comments, dictation, Writing Tools on supported devices
  • iCloud (web) — comments; Track Changes viewing

⚠ Common Mistakes

  • Sending a file with tracked changes still visible; Accept All or export final
  • Relying only on spell check; Proofread or read aloud catches more
  • Creating Text Replacements that are real words

✓ Tips & Best Practices

  • Use highlights for "check this" notes that aren't full comments
  • Read aloud: Edit › Speech › Start Speaking for a final proof
  • Review Writing Tools changes before accepting them
