Java — Pattern & Matcher

Pattern.compile · flags · matches() vs find() vs lookingAt() · group(n) / group("name") · start() / end() · while (m.find()) · results()

java.util.regex

Java splits regex work between two classes. A Pattern is the compiled, immutable regex: build it once with Pattern.compile(regex, flags) and share it. A Matcher applies that pattern to one input and holds the search state (current position, last match), so you call find() in a loop and read group(), start() and end() after each success. Java's flavor is close to PCRE: possessive quantifiers, atomic groups, \p{…}, lookbehind with a bounded length, and class intersection &&.

Key Points

  • Pattern is thread-safe; a Matcher is not, so create one per use
  • Call find() / matches() before group(), or it throws IllegalStateException
  • CASE_INSENSITIVE is ASCII-only unless you add UNICODE_CASE
  • Backslashes are doubled in Java strings: \\d (sheet 19)

Pattern & Matcher

import java.util.regex.*;
Pattern p = Pattern.compile("(?<name>\\w+)=(?<val>\\d+)");
Matcher m = p.matcher("a=1, b=22, c=333");
while (m.find()) {
    System.out.println(m.group("name") + "->" + m.group(2) + " @" + m.start());
}                                         // a->1 @0   b->22 @5   c->333 @11
p.matcher("a=1").matches();               // true   (whole input)
p.matcher("a=1; x").matches();            // false
p.matcher("a=1; x").lookingAt();          // true   (prefix)
p.matcher("a=1 b=2").results()            // Java 9+
    .map(r -> r.group(2)).toList();       // [1, 2]

Code Explained

(?<name>…) — read with m.group("name") or by number
while (m.find()) — the standard loop over all matches
matches() — entire input; lookingAt() — from the start; find() — anywhere
results() — a Stream<MatchResult>

⚠ Common Mistakes

  • Reading m.group() without a successful find() first: IllegalStateException: No match found
  • Sharing one Matcher across threads; its state is mutable, so results interleave
  • Expecting matches() to search; it requires the whole input to match

✓ Tips & Best Practices

  • Store patterns as private static final Pattern fields
  • Use UNICODE_CHARACTER_CLASS to make \w, \d and \b Unicode-aware
  • p.asPredicate() plugs straight into stream.filter(…)

Quick Summary

  • Pattern.compile — immutable, shareable
  • Matcher — stateful search over one input
  • find / matches / lookingAt — anywhere / whole / prefix
  • group / start / end — read the last match
