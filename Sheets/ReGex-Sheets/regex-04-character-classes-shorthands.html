Sheet 04

Character Classes & Shorthands

[abc] · [^abc] · [a-z0-9] · special chars in classes · \d \w \s · \D \W \S · . and newlines · [\s\S]

One Character from a Set

A character class [...] matches exactly one character from the set inside the brackets. Use ranges like a-z, put ^ first to negate the set, and combine freely: [A-Za-z0-9_]. Shorthands such as \d, \w and \s are ready-made classes, and their uppercase forms are the negations. Inside a class most metacharacters lose their meaning: [.*+] matches a literal dot, star or plus.

Inside the Brackets

  • Only ], \, ^ (first) and - (between chars) are special
  • Literal -: put it first or last, [-a] / [a-], or escape \-
  • Literal ]: escape it [\]a]; []a] works in PCRE/Python but means an empty class in JS
  • [^...] also matches newlines, unlike .

Classes & Shorthands (Python)

import re
re.findall(r"[aeiou]", "regex")               # ['e', 'e']
re.findall(r"[^aeiou\s]", "a big cat")         # ['b', 'g', 'c', 't']
re.findall(r"gr[ae]y", "gray grey groy")       # ['gray', 'grey']
re.findall(r"[0-9A-Fa-f]+", "ff 1Z c0de")      # ['ff', '1', 'c0de']
re.findall(r"[\w.-]+@", "a.b-c@x.io")          # ['a.b-c@']
re.findall(r"[\]\\^-]", r"a]b\c^d-e")          # [']', '\\', '^', '-']
re.findall(r"\d+", "Order 66, gate 9")         # ['66', '9']
re.findall(r"\w+", "naïve café_2")             # ['naïve', 'café_2']
re.findall(r"\s", "a b\tc\n")                  # [' ', '\t', '\n']
re.findall(r".", "a\nb")                       # ['a', 'b']
re.findall(r"[\s\S]", "a\nb")                  # ['a', '\n', 'b']

Code Explained

[^aeiou\s] — negated set: not a vowel and not whitespace
[\w.-] — shorthands work inside classes; . is literal there
[\]\\^-] — escaping the four special class characters
\w matched ï and é: Python 3 shorthands are Unicode-aware
. skips \n; [\s\S] matches anything, newlines included

Class Syntax

SyntaxMatches
[abc]one of a, b, c
[^abc]any char except a, b, c (incl. \n)
[a-z]range by code point
[a-zA-Z0-9_]several ranges combined
[-.] [.-]literal hyphen at either edge
[a^]^ is literal unless first
[.*+?(){}|$]metacharacters are literal inside

⚠ Common Mistakes

  • [A-z] looks like “all letters” but the range also includes [ \ ] ^ _ and the backtick
  • [^…] matches newlines, so <[^>]*> can run across lines (often what you want, sometimes not)
  • Assuming \d means [0-9]: in Python 3 and .NET it also matches other scripts' digits, like ٣

✓ Tips & Best Practices

  • Prefer a negated class over .*? when you know the terminator: "[^"]*"
  • Use [0-9] (or the ASCII flag) when you need ASCII-only digits
  • [\s\S] or the s flag (sheet 12) lets . span lines

Quick Summary

  • [...] — one character from the set
  • [^...] — one character not in the set
  • \d \w \s — digit, word char, whitespace
  • \D \W \S — their negations
