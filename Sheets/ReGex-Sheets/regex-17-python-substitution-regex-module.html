Replacing, and When to Reach for regex

re.sub(pattern, repl, string, count=0, flags=0) returns a new string with matches replaced; re.subn also returns how many replacements it made. repl is either a template string (where \1, \g<name> and escapes like \n are processed) or a function that receives each Match and returns the replacement. When the built-in engine runs out of features (Unicode properties, variable-length lookbehind, recursion, fuzzy matching, timeouts), install the third-party regex module: it's largely a drop-in replacement.

Version Notes

  • 3.7: re.sub handles empty matches next to previous matches consistently
  • 3.11: atomic groups (?>…) and possessive *+ ++ ?+
  • 3.13: passing count, maxsplit or flags positionally is deprecated
  • pip install regex, then import regex as re for most code

Substitution & the regex Module

import re
re.sub(r"\s+", " ", "a   b \t c")                     # 'a b c'
re.sub(r"(\w+)@(\w+)", r"\2 at \1", "me@site")         # 'site at me'
re.sub(r"(?P<u>\w+)@", r"\g<u> at ", "me@site")        # 'me at site'
re.subn(r"o", "0", "foo boo")                         # ('f00 b00', 4)
re.sub(r"o", "0", "foo", count=1)                     # 'f0o'
re.sub(r"\d+", lambda m: str(int(m[0]) * 2), "3 cats, 10 dogs")  # '6 cats, 20 dogs'
prices = {"apple": "1.20", "pear": "0.90"}
re.sub(r"\{(\w+)\}", lambda m: prices.get(m[1], m[0]), "{apple}/{kiwi}")  # '1.20/{kiwi}'
import regex
regex.findall(r"\p{Lu}\p{Ll}+", "Élan Vital ölçü")     # ['Élan', 'Vital']
regex.search(r"(?<=\$\d+)\.\d\d", "$12.50")[0]        # '.50'
len(regex.findall(r"\X", "éa")), len(re.findall(r".", "éa"))  # (2, 3)
regex.search(r"(?:color){e<=1}", "colr")[0]           # 'colr'
regex.findall(r"\d\d", "1234", overlapped=True)       # ['12', '23', '34']

Code Explained

\2 at \1 — swap groups in a template
\g<u> — named group in a template
subn — returns (new_string, count)
lambda m: — compute each replacement; unknown keys fall back to m[0]
regex: \p{…}, any-length lookbehind, \X graphemes
{e<=1} — fuzzy: up to 1 edit; overlapped=True — overlapping matches

⚠ Common Mistakes

  • Inserting user text as a template: a \1 or \g in it is interpreted; pass lambda m: text instead
  • re.sub(p, r, s, 1) — positional count is deprecated; write count=1
  • Expecting re.sub to modify the string in place; strings are immutable, so assign the result

✓ Tips & Best Practices

  • Use a dict + function for multi-token templating: lambda m: table[m[1]]
  • For many literal replacements, one alternation \b(?:a|b|c)\b with a dict lookup beats repeated sub calls
  • regex is a near drop-in: try import regex as re when re lacks a feature

Quick Summary

  • re.sub(p, repl, s) — replace all
  • re.subn — replace and count
  • \g<name> / function — template / computed
  • regex — \p{}, lookbehind, fuzzy, timeout
