Java — String Methods, Replacement & Gotchas

"\\d+" escaping & text blocks · String.matches() · replaceAll / replaceFirst · split + limit · quoteReplacement · Pattern.quote · Kotlin Regex

Regex Through java.lang.String

String has four regex shortcuts: matches, replaceAll, replaceFirst and split. They're convenient but compile the pattern on every call, and each has a trap: matches needs the whole string, split treats its argument as a regex and drops trailing empty strings, and the replacement string treats $ and \ as special. Java has no raw string literals, so every regex backslash is written twice; text blocks (""") still process escapes and don't change that.

Escaping Layers

  • Regex \d → Java "\\d"
  • Regex \. → Java "\\."
  • Literal backslash: regex \\ → Java "\\\\"
  • Replacement $ → "\\$"; or wrap text in Matcher.quoteReplacement

String Methods (Java)

String s = "a1b22c333";
s.matches("[a-z0-9]+");                     // true   (whole string)
s.matches("\\d+");                          // false
s.replaceAll("\\d+", "#");                  // "a#b#c#"
s.replaceFirst("\\d+", "#");                // "a#b22c333"
"2026-03-14".replaceAll("(\\d+)-(\\d+)-(\\d+)", "$3/$2/$1");   // "14/03/2026"
"a,b,,c,,".split(",");                      // [a, b, , c]
"a,b,,c,,".split(",", -1);                  // [a, b, , c, , ]
"a.b.c".split(".");                         // []
"a.b.c".split(Pattern.quote("."));          // [a, b, c]
"cost".replaceAll("cost", "\\$5");          // "$5"
"x".replaceAll("x", Matcher.quoteReplacement("$1\\"));   // "$1\\"
Pattern.compile("\\d+").matcher("3 and 4")
    .replaceAll(r -> String.valueOf(Integer.parseInt(r.group()) * 10));  // "30 and 40"
// Kotlin: raw strings need no doubling
Regex("""(\d+)-(\d+)""").replace("10-20", "$2-$1")      // "20-10"
"\\d+".toRegex().findAll("a1b22").map { it.value }.toList()  // [1, 22]

Code Explained

matches — implicit ^…$
split(",") — trailing empty strings removed; -1 keeps them
split(".") — . matches everything, so every piece is empty
\\$5 — literal $ in a replacement
quoteReplacement — makes any text safe as a replacement
replaceAll(Function) — computed replacement (Java 9+)

⚠ Common Mistakes

  • s.split("|") or split("."): both are regex metacharacters; use "\\|" or Pattern.quote
  • Calling String.matches in a hot loop; it compiles each time, so hoist a Pattern
  • Using replaceAll for a literal swap; replace is literal and faster

✓ Tips & Best Practices

  • Use Pattern.quote for literal search text and Matcher.quoteReplacement for literal replacements
  • Check patterns in regex101's Java flavor, then double every backslash when pasting
  • In Kotlin, prefer raw strings """…""" for patterns

Quick Summary

  • "\\d" — Java needs doubled backslashes
  • matches — whole string only
  • split(re, -1) — keep trailing empties
  • quote / quoteReplacement — literal text
