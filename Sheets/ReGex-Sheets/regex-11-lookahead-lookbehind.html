Sheet 11

Lookahead & Lookbehind

(?=…) · (?!…) · (?<=…) · (?<!…) · zero-width · lookbehind length limits · \K · stacked lookaheads

Look Without Consuming

A lookaround checks whether a pattern matches next to the current position, then returns to that position without consuming anything. Lookahead (?=…) peeks to the right, lookbehind (?<=…) peeks to the left, and the ! forms assert that the pattern does not match. Because they're zero-width, lookarounds let you match text based on its surroundings while keeping those surroundings out of the result, and several lookaheads at one position act like an AND of conditions.

Limits

  • Lookbehind length is restricted in many flavors (table below)
  • Groups inside a lookaround still capture: (?=(\w+))
  • Go and Rust have no lookaround; restructure or post-filter in code
  • \K (PCRE, Perl, Ruby, regex) drops everything matched so far: a lookbehind without length limits

Lookarounds (Python)

import re, regex
re.findall(r"\d+(?=px)", "10px 20em 30px")        # ['10', '30']
re.findall(r"\d+(?!px|\d)", "10px 20em 30px")     # ['20']
re.findall(r"(?<=\$)\d+", "$5 and €7 and $12")    # ['5', '12']
re.findall(r"(?<!\$)\b\d+", "$5 and 7 and $12")   # ['7']
re.sub(r"\B(?=(\d{3})+(?!\d))", ",", "1234567")   # '1,234,567'
strong = r"(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,}"
bool(re.fullmatch(strong, "Passw0rd"))            # True
bool(re.fullmatch(strong, "password"))            # False
re.search(r"(?<=\w+)@", "me@x")                   # re.error: fixed width only
regex.search(r"(?<=\w+)@", "me@x").start()        # 2
regex.sub(r"foo\Kbar", "BAZ", "foobar")           # 'fooBAZ'

Code Explained

(?=px) — digits only if px follows; px isn't returned
(?!px|\d) — the \d stops \d+ backing off to "1" in 10px
(?<=\$) — digits preceded by a dollar sign
\B(?=(\d{3})+(?!\d)) — positions followed by groups of 3 digits
Stacked lookaheads at the start: digit AND lower AND upper
\K — keep foo out of the match, so only bar is replaced

Syntax

SyntaxSucceeds If
(?=X)X matches next (lookahead)
(?!X)X does not match next
(?<=X)X matches just before (lookbehind)
(?<!X)X does not match just before
\Kreset match start here

Common Uses

PatternFinds
\d+(?=%)number before a %
(?<=@)[\w.]+domain after @
^(?!.*admin).*$lines without “admin”
q(?!u)q not followed by u
(?<![\w.])\d+(?![\w.])standalone integers

⚠ Common Mistakes

  • Expecting lookaround text in the match: (?<=\$)\d+ returns 5, not $5
  • A negative lookahead without an anchor: (?!foo)\w+ still matches “oo” inside “foo”; use \b(?!foo\b)\w+
  • Porting a lookbehind-heavy pattern to Go or Rust; it won't compile there

✓ Tips & Best Practices

  • Use ^(?=…)(?=…) to require several independent conditions in any order
  • Replace a variable-length lookbehind with a capture group plus \1 in the replacement
  • Prefer \K over lookbehind in PCRE for speed and no length limits

Quick Summary

  • (?=X) / (?!X) — X does / doesn't follow
  • (?<=X) / (?<!X) — X does / doesn't precede
  • zero-width — nothing is consumed
  • \K — discard the match so far
