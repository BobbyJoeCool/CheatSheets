Substitution & Replacement Syntax

$1 vs \1 vs \g<1> · ${name} / \g<name> / $<name> · $& $0 \0 & · $` $' · $$ · \U \L \E · ${1}0

The Replacement String Is Its Own Mini-Language

In search-and-replace, the replacement is not a regex, but it has its own escape syntax for inserting captured text, and that syntax varies more between languages than the patterns do. Python uses backslashes (\1, \g<name>), most others use dollars ($1, ${name}), and sed uses \1 and &. When the text you insert comes from users, escape $ and \ in it, or pass a function that returns the replacement, which skips the mini-language entirely.

Good to Know

  • Python and sed: $ is literal. JS, Java, .NET: $ is special
  • Java treats \ as an escape in replacements: \\ for one backslash
  • Case conversion \U…\E exists in Perl, GNU sed, PCRE2 extended mode, VS Code and Notepad++
  • Function replacements are the escape hatch for anything conditional

Replacing (Python)

import re
d = "2026-03-14"
re.sub(r"(\d+)-(\d+)-(\d+)", r"\3/\2/\1", d)          # '14/03/2026'
re.sub(r"(?P<y>\d+)-(?P<m>\d+)-(?P<d>\d+)", r"\g<d>.\g<m>.\g<y>", d)  # '14.03.2026'
re.sub(r"(\d)", r"\g<1>0", "a1b2")                    # 'a10b20'
re.sub(r"\w+", r"[\g<0>]", "hi there")                # '[hi] [there]'
re.sub(r"\w+", lambda m: m[0].upper(), "hi there")    # 'HI THERE'
re.sub(r"(\w)(\w*)", lambda m: m[1].upper() + m[2], "hi there")  # 'Hi There'
re.sub(r"x", "$1", "x")                               # '$1'
# JavaScript  d.replace(/(\d+)-(\d+)-(\d+)/, "$3/$2/$1")
# Java        d.replaceAll("(\\d+)-(\\d+)-(\\d+)", "$3/$2/$1")
# C#          Regex.Replace(d, @"(\d+)-(\d+)-(\d+)", "$3/$2/$1")
# GNU sed     sed -E 's/([0-9]+)-([0-9]+)-([0-9]+)/\3\/\2\/\1/'
# Perl        s/(\w+)/\u$1/g   # capitalize each word

Code Explained

\3/\2/\1 — reorder captured groups
\g<name> — Python's named reference in a replacement
\g<1>0 — group 1 then a literal 0 (plain \10 would mean group 10)
\g<0> — the whole match ($& / $0 elsewhere)
lambda m: … — compute each replacement in code
$1 is literal in Python; it only means group 1 in $ flavors

⚠ Common Mistakes

  • Inserting user text into a $-style replacement: a $1 in their input becomes a group reference
  • Writing r"\10" in Python for group 1 + “0”; it's group 10 (or an error)
  • Using Python's \1 syntax in JS, or JS's $1 in Python; both are treated literally

✓ Tips & Best Practices

  • Escape literal replacement text: Matcher.quoteReplacement(t) (Java), t.Replace("$", "$$") (C#), or pass () => t (JS)
  • Use a replacement function whenever the output depends on the match
  • Prefer named groups in long replacements so a pattern edit doesn't scramble the numbers

Quick Summary

  • \1 / $1 — group 1 (Python, sed / most others)
  • \g<name> / ${name} / $<name> — named group
  • \g<0> / $& / $0 / & — whole match
  • function — compute the replacement
