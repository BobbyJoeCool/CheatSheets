RegExp in JavaScript

JavaScript has regex built into the language. A literal /\d+/g is compiled when the script loads; the constructor new RegExp(str, flags) builds one at runtime from a string, which means backslashes must be doubled ("\\d+") or written with String.raw. Patterns are used through RegExp methods (test, exec) and String methods (match, matchAll, search, replace, split). A regex with the g or y flag is stateful: it remembers where the last match ended in lastIndex.

Key Points

  • match without g returns groups; with g it returns only the matched strings
  • matchAll requires g and gives full match objects for every match
  • Escape / inside a literal: /https?:\/\//
  • Read re.source and re.flags to inspect a pattern

RegExp Basics

const re = /(\d{4})-(\d{2})/;
re.test("Due 2026-10")                       // true
"Due 2026-10".match(re)                      // ['2026-10', '2026', '10']
"a1 b22 c333".match(/\d+/g)                  // ['1', '22', '333']
"none".match(/\d+/g)                         // null
[..."a=1 b=2".matchAll(/(\w)=(\d)/g)].map(m => m[2])  // ['1', '2']
"hello world".search(/o/)                    // 4
"a, b ,c".split(/\s*,\s*/)                   // ['a', 'b', 'c']
"a1b2".split(/(\d)/)                         // ['a', '1', 'b', '2', '']
/(?<y>\d{4})/.exec("in 2026").groups.y       // '2026'
new RegExp("\\d+", "g").source               // '\d+'
new RegExp(String.raw`\d+\.\d+`).test("3.14")  // true
// Stateful g flag:
// const g = /a/g;  g.test("ab") → true;  g.test("ab") → false;  g.lastIndex → 0

Code Explained

test — boolean; the fastest check
match(re) without g — array with groups plus index
match(/…/g) — all matched strings, no groups; null if none
matchAll — iterator of full match objects
split with a capture group keeps the delimiters
Second g.test starts at lastIndex 1, fails, and resets to 0

⚠ Common Mistakes

  • Reusing a global regex with test() or exec(): lastIndex makes alternate calls fail; drop g or reset lastIndex = 0
  • new RegExp("\\d+") written as "\d+": the string becomes d+, matching letters
  • Calling matchAll with a non-global regex: it throws a TypeError

✓ Tips & Best Practices

  • Use String.raw with new RegExp to avoid double escaping
  • Hoist literals out of loops; they're compiled once anyway, but stateful g regexes shouldn't be shared
  • Use matchAll + destructuring: for (const [, k, v] of s.matchAll(re))
