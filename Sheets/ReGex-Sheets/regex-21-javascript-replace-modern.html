JavaScript — Replace & Modern Features

Replacing, and What's New

str.replace(pattern, replacement) replaces the first match unless the regex has the g flag; replaceAll replaces every match and requires g when given a regex. The replacement can be a string with $ tokens or a function called once per match. JavaScript's regex flavor has grown quickly: lookbehind, named groups and \p{…} (ES2018), match indices (ES2022), set operations (ES2024), and RegExp.escape plus inline modifiers (ES2025).

Good to Know

  • replace("-", "+") with a string pattern replaces only the first occurrence
  • In a replacement string, $$ is a literal dollar sign
  • A replacer function's return value is used literally: no $ processing
  • Check runtime support for ES2025 features (Node 24+, current browsers)

Replace & Modern Features

"2026-03-14".replace(/(\d+)-(\d+)-(\d+)/, "$3/$2/$1")    // '14/03/2026'
"a-b-c".replace("-", "+")                                // 'a+b-c'
"a-b-c".replaceAll("-", "+")                             // 'a+b+c'
"a-b-c".replace(/-/g, "+")                               // 'a+b+c'
"x".replaceAll(/x/, "y")                                 // TypeError: needs g flag
"John Smith".replace(/(?<f>\w+) (?<l>\w+)/, "$<l>, $<f>")  // 'Smith, John'
"hi there".replace(/\b\w/g, c => c.toUpperCase())        // 'Hi There'
"3 + 4".replace(/(\d+) \+ (\d+)/, (m, a, b) => +a + +b)  // '7'
"$5".replace(/\$(\d)/, "$$$1.00")                        // '$5.00'
/(?<=\$)\d+/.exec("cost $42")[0]                         // '42'
/a.c/s.test("a\nc")                                      // true
/(?<y>\d{4})/d.exec("in 2026").indices.groups.y          // [3, 7]
/[\p{L}--[a-z]]/v.test("é")                              // true
// ES2025: RegExp.escape("1+1")  → '\x31\+1' (safe in any position)
// ES2025: /(?i:hello) world/.test("HELLO world")  → true

Code Explained

$3/$2/$1 — reorder groups
String pattern → first only; replaceAll or /g → all
$<name> — named group in a replacement
(m, a, b) => … — replacer gets match, then groups
$$ — literal $
d flag — [start, end] for each group
v flag — set subtraction inside a class

⚠ Common Mistakes

  • Expecting str.replace("a", "b") to replace every a; use replaceAll or /a/g
  • Inserting user text as a replacement string: its $& or $1 gets expanded; use () => text
  • Forgetting the replacer's trailing offset and string arguments when using ...args

✓ Tips & Best Practices

  • Use named groups for readable replacements: $<year>
  • Prefer the function form for anything conditional or computed
  • Until RegExp.escape is available everywhere, use s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&")

Quick Summary

  • replace — first match (all with g)
  • replaceAll — every match; regex needs g
  • $1 $<name> $& $$ — replacement tokens
  • function — computed replacement
