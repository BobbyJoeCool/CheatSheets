Sheet 02

Literals, Metacharacters & Escaping

metacharacters · \. \\ · \t \n \r · \xhh / \uhhhh · \Q…\E · raw strings · re.escape / Pattern.quote

Literal vs Special

Most characters in a pattern match themselves: cat finds "cat". A small set of metacharacters have special meaning, and you put a backslash in front of one to match it literally: \. matches a real dot. The catch is that the backslash is usually processed twice: once by your language's string literal, then again by the regex engine. Raw strings (r"…", @"…", backticks) skip the first pass, which is why every example in this set uses them.

Rules of Thumb

  • Outside a class, the 12 metacharacters are \ ^ $ . | ? * + ( ) [ {
  • ], } and - are literal outside a class
  • Inside [...] only ] \ ^ - are special (sheet 04)
  • Escaping punctuation is safe in most flavors; JS u/v mode rejects needless ones like \- outside a class

Escaping in Practice (Python)

import re
re.findall(r"3.14", "3.14 3x14")          # ['3.14', '3x14']
re.findall(r"3\.14", "3.14 3x14")         # ['3.14']
re.findall(r"\$\d+", "Cost: $25")         # ['$25']
re.findall(r"a\+b", "a+b aab")            # ['a+b']
re.escape("1+1=2?")                       # '1\\+1=2\\?'
re.findall(re.escape("(c)"), "(c) 2026")  # ['(c)']
len("\n"), len(r"\n")                     # (1, 2)
re.findall("\\\\", r"C:\temp")            # ['\\']
re.findall(r"\\", r"C:\temp")             # ['\\']
re.findall(r"\x41\u00e9", "Aé")           # ['Aé']
re.findall("\bcat\b", "a cat")            # []
re.findall(r"\bcat\b", "a cat")           # ['cat']

Code Explained

3.14 — unescaped . matches any character, so 3x14 matches too
\$ \+ — escaped metacharacters are literal
re.escape — escapes every special character in a string
"\\\\" — non-raw: 4 backslashes in source = \\ to the engine = one literal \
\x41 \u00e9 — characters by hex code
"\bcat\b" — non-raw \b is a backspace, so nothing matches

⚠ Common Mistakes

  • Not escaping the dot in domains and versions: example.com also matches exampleXcom
  • Non-raw strings: "\b" is a backspace and "\d" may warn or break; use r"\b"
  • Building a pattern from user input without escaping: ( fails to compile and .* matches everything

✓ Tips & Best Practices

  • Escape any dynamic text with re.escape / Pattern.quote before inserting it
  • [.] or [$] matches one literal metacharacter with no backslash, handy inside shell or JSON strings
  • \Q…\E quotes a whole span in PCRE, Java and Perl

Quick Summary

  • \ + meta — match the metacharacter literally
  • \t \n \xhh \uhhhh — character escapes
  • raw strings — avoid double escaping
  • re.escape & friends — quote untrusted text
