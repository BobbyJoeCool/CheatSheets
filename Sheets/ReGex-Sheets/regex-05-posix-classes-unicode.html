Beyond ASCII

[a-z] and \w were designed for English text. For everything else you have two tools. POSIX bracket classes like [[:alpha:]] are named sets used inside brackets by grep, sed, PCRE and Ruby. Unicode properties like \p{L} (any letter) or \p{Script=Greek} describe characters by their Unicode category or script, and work in nearly every modern flavor. Most need a Unicode switch: JS requires the u or v flag, and Python needs the third-party regex module.

Unicode Gotchas

  • \w and \d are ASCII in JS and Java (by default), Unicode in Python 3 and .NET
  • One visible character can be several code points: é may be e + U+0301
  • \X matches one grapheme (what a user sees as one character): PCRE, Perl, Java 9+, Ruby
  • Normalize text first (NFC) so é has one form

Unicode Matching (JavaScript)

"Ünïcödé 123".match(/\p{L}+/gu)              // ['Ünïcödé']
"Привет, world".match(/\p{Script=Cyrillic}+/gu)  // ['Привет']
"ABc".match(/\p{Lu}/gu)                      // ['A', 'B']
"1٣5".match(/\d/gu)                          // ['1', '5']
"1٣5".match(/\p{Nd}/gu)                      // ['1', '٣', '5']
"😀".match(/^.$/)                            // null
"😀".match(/^.$/u)                           // ['😀']
"é".normalize("NFD").length                  // 2
"aeixyz".match(/[\p{L}--[aeiou]]/gv)         // ['x', 'y', 'z']

Code Explained

\p{L}+ — any run of letters in any script
\p{Script=Cyrillic} — characters from one writing system
\d stays ASCII in JS; \p{Nd} matches every decimal digit
Without u, . sees an emoji as two UTF-16 halves
v flag — set subtraction -- and intersection &&

⚠ Common Mistakes

  • Using [a-zA-Z] for names: it rejects “José” and “Zoë”; use \p{L}
  • Forgetting the u flag in JS: \p{L} is then a syntax error (or a literal p in old code)
  • Comparing text with different normalization: NFC é and NFD e+◌́ don't match each other

✓ Tips & Best Practices

  • Normalize input with NFC before matching user text
  • In Python, pip install regex for \p{…}, \X and set operations
  • Use [[:alpha:]] in grep/sed; it respects the locale, unlike [a-z]

Quick Summary

  • [[:alpha:]] — POSIX named class, inside brackets
  • \p{L} / \P{L} — Unicode property / negation
  • \p{Script=…} — match a writing system
  • \X — one user-visible character
