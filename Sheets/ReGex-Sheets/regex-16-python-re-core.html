The re Module

Python's built-in re module offers module-level functions (re.search(pattern, text)) and compiled Pattern objects (re.compile(pattern).search(text)) with the same methods. A successful match returns a Match object, which is truthy and holds the matched text, groups and positions; a failed one returns None. Always write patterns as raw strings so backslashes reach the engine untouched.

Key Points

  • search scans anywhere, match only at position 0, fullmatch needs the whole string
  • findall returns strings, or tuples of groups if the pattern has groups
  • Module functions cache recently used patterns; compile when you reuse one in a loop
  • Check for None before .group(): if m := re.search(…):

Core API

import re
s = "Ann 31, Bob 27, Cy 45"
re.search(r"\d+", s)                    # <re.Match object; span=(4, 6), match='31'>
re.match(r"\d+", s)                     # None
re.findall(r"\d+", s)                   # ['31', '27', '45']
re.findall(r"(\w+) (\d+)", s)           # [('Ann', '31'), ('Bob', '27'), ('Cy', '45')]
[m.start() for m in re.finditer(r"\d+", s)]   # [4, 12, 19]
re.split(r",\s*", s)                    # ['Ann 31', 'Bob 27', 'Cy 45']
age = re.compile(r"(?P<name>\w+) (?P<age>\d+)", re.I)
m = age.search(s)
m.group("name"), m["age"]               # ('Ann', '31')
m.groups(), m.span(), m.end(2)          # (('Ann', '31'), (0, 6), 6)

Code Explained

match — anchored at 0; "Ann…" doesn't start with a digit
findall with 2 groups → list of 2-tuples
finditer — Match objects, for positions and groups
split — break on the pattern; captured delimiters are kept
(?P<name>…) + m["age"] — groups by name

⚠ Common Mistakes

  • Calling .group() on a failed search: AttributeError: 'NoneType' object has no attribute 'group'
  • Adding a group to a findall pattern and suddenly getting tuples or partial text; use (?:…)
  • Using re.match to search mid-string; it only checks position 0

✓ Tips & Best Practices

  • Use the walrus: if m := pat.search(line): …
  • finditer over findall when you need positions or large inputs (lazy)
  • re.DEBUG (or regex101's Python flavor) shows exactly how Python parsed a pattern

Quick Summary

  • search / match / fullmatch — anywhere / start / whole
  • findall / finditer — all matches
  • split — break on a pattern
  • compile — reuse, plus pos / endpos
