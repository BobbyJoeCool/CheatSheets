Copy-Ready Text Patterns

Search-and-replace and extraction patterns for everyday text work, PCRE-style and unanchored. Flags column: m = multiline, i = case-insensitive; write \1 as $1 in JS, Java and .NET. Patterns that touch code or markup (comments, tags, quoted strings) are naive: they don't know about context like a // inside a string, so check results before bulk edits.

⚠ Common Mistakes

  • Naive comment/tag patterns break on strings and nesting
  • Forgetting m: ^ and $ then match only once

✓ Tips & Best Practices

  • Preview matches with rg before a bulk replace
  • Use a replacement function for computed output

Quick Summary
