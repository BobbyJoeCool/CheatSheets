Sheet 06

Quantifiers

* + ? · {n} · {n,} · {n,m} · {,m} · quantifying groups (ab)+ · last capture kept · literal {

How Many Times

A quantifier says how many times the item just before it may repeat. It applies to exactly one atom: a single character, an escape like \d, a class like [a-z], or a whole group ( … ). So ab+ means "a, then one or more b", while (ab)+ repeats the pair. By default quantifiers are greedy: they take as many repetitions as possible and give some back only if the rest of the pattern needs them (sheet 07).

Good to Know

  • * and ? can match zero times, so they always succeed
  • {n,m} has no spaces: {2, 5} is literal text in most flavors
  • A { that isn't a valid quantifier is literal in Python, JS (non-u), PCRE; an error in Java and JS u mode
  • A repeated capture group keeps only its last iteration

Quantifiers in Action (Python)

import re
re.findall(r"colou?r", "color colour")       # ['color', 'colour']
re.findall(r"\d+", "a1b22c333")              # ['1', '22', '333']
re.findall(r"\d*", "a1")                     # ['', '1', '']
re.findall(r"\b\d{3}\b", "12 123 1234")      # ['123']
re.findall(r"\d{2,3}", "1 12 123 1234")      # ['12', '123', '123']
re.findall(r"\d{2,}", "1 12 12345")          # ['12', '12345']
re.findall(r"x{,2}", "xxx")                  # ['xx', 'x', '']
re.findall(r"(?:ab)+", "ababab abba")        # ['ababab', 'ab']
re.search(r"(ab)+", "ababab").group(1)       # 'ab'
re.search(r"(\d)+", "123").group(1)          # '3'
re.findall(r"x{a}", "x{a}")                  # ['x{a}']

Code Explained

u? — the u is optional
\d* succeeds with zero digits, producing empty matches
\d{2,3} — 2 or 3 digits; "1234" yields "123" and leaves "4"
{,2} — 0 to 2 (Python, Ruby, newer PCRE2); literal or an error elsewhere
(\d)+ — the group matched 1, 2, then 3; only '3' is kept
x{a} — not a valid quantifier, so the braces are literal

⚠ Common Mistakes

  • ab* when you meant (ab)*: the quantifier only covers b
  • Expecting (\w)+ to capture the whole word; wrap the quantifier inside: (\w+)
  • .* at the start of a search pattern is redundant and slow; search already scans every position

✓ Tips & Best Practices

  • Use (?:…)+ to repeat a sequence without creating a capture
  • Bound open-ended counts on untrusted input: \d{1,10} rather than \d+
  • Write {0,m} instead of {,m} for portable patterns

Quick Summary

  • * + ? — 0+, 1+, 0 or 1
  • {n} {n,} {n,m} — counted repetition
  • (…)+ — repeat a group
  • repeated group — keeps the last capture only
