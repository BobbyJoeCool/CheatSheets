Named Groups & Backreferences

(?<name>…) · (?P<name>…) · \1 \2 · \k<name> / (?P=name) · \g{-1} · branch reset (?|…) · doubled words

Naming and Reusing Captures

A named group labels a capture so you can read it by name instead of counting parentheses: (?<year>\d{4}). A backreference matches the same text a group already captured, later in the same pattern: (\w+) \1 matches a doubled word. Note the difference: a backreference repeats the captured text, not the subpattern; (\d)\1 matches "77" but not "78". Named groups are still numbered, so \1 and \k<name> both work.

Flavor Notes

  • Python re uses (?P<name>…) and (?P=name) only
  • JS, Java, .NET, PCRE, Ruby and Go use (?<name>…)
  • Go and Rust (RE2-style) have no backreferences at all
  • Duplicate group names: .NET, PCRE (?J), JS ES2025 (in different branches)

Named Groups & Backreferences (Python)

import re, regex
m = re.search(r"(?P<year>\d{4})-(?P<mon>\d\d)", "on 2026-10")
m.group("year")                                   # '2026'
m.groupdict()                                     # {'year': '2026', 'mon': '10'}
re.findall(r"\b(\w+) \1\b", "the the cat sat sat")  # ['the', 'sat']
re.sub(r"\b(\w+) \1\b", r"\1", "the the cat")       # 'the cat'
re.search(r"(['\"]).*?\1", "say 'hi' now").group()  # "'hi'"
re.search(r"<(?P<t>\w+)>.*?</(?P=t)>", "<b>x</b>")[0]   # '<b>x</b>'
[bool(re.fullmatch(r"(\d)\1", t)) for t in ("77", "78")]  # [True, False]
regex.search(r"(?<y>\d+)", "42").group("y")       # '42'
regex.search(r"(?|(\d+)|([a-z]+))", "abc").group(1)   # 'abc'

Code Explained

(?P<year>…) + .group("year") — read by name
groupdict() — every named group as a dict
\b(\w+) \1\b — a word followed by the same word
(['"]).*?\1 — the closing quote must match the opening one
(?P=t) — Python's named backreference
(?|…) — branch reset: each branch reuses group 1 (PCRE, Perl, regex)

⚠ Common Mistakes

  • Expecting (\d)\1 to mean "two digits": it means the same digit twice; use \d{2}
  • Using (?<name>…) in Python re: it's a syntax error; write (?P<name>…)
  • Writing \10 and getting group 1 + "0" (or octal); use \g<10> / \g{10} for group 10+

✓ Tips & Best Practices

  • Name every group you read back in code; numbers break when the pattern changes
  • Pair backreferences with lazy or negated content: (['"])[^'"]*\1
  • In replacements, named groups are \g<name> (Python), ${name} (Java, .NET), $<name> (JS)

Quick Summary

  • (?<name>…) — named capture
  • \1 / \k<name> — repeat the captured text
  • (?P<name>…) / (?P=name) — Python forms
  • (?|…) — branch reset shares numbers
