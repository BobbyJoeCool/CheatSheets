Flags & Inline Modifiers

i · m · s · x verbose + # comments · u / v Unicode · g global · y sticky · (?i) / (?i:…) / (?-i)

Changing How a Pattern Behaves

Flags (also called modifiers or options) change how the whole pattern is interpreted: case sensitivity, what ^ $ and . mean, whether whitespace in the pattern is ignored, and how Unicode is handled. You set them outside the pattern (/x/gi in JS, re.I in Python, Pattern.CASE_INSENSITIVE in Java) or inline at the start of the pattern with (?i). Inline groups like (?i:…) limit a flag to part of the pattern.

Naming Traps

  • m changes ^ and $ only; it does not let . match newlines (that's s)
  • .NET calls the s flag Singleline: it's the same dot-all behavior
  • Ruby's /m means dot-all; Ruby ^ $ are always per line
  • Python 3.11+: global (?i) must be at the very start of the pattern

Flags in Python

import re
re.findall(r"hello", "Hello HELLO", re.I)      # ['Hello', 'HELLO']
re.findall(r"(?i)hello", "Hello HELLO")        # ['Hello', 'HELLO']
re.findall(r"^\w", "a\nb", re.M)               # ['a', 'b']
re.findall(r"a.b", "a\nb", re.S)               # ['a\nb']
re.findall(r"\d", "1٣", re.A)                  # ['1']
re.findall(r"(?i:A)b", "ab Ab AB")             # ['ab', 'Ab']
re.findall(r"x", "xX", re.I | re.M)            # ['x', 'X']
pat = re.compile(r"""
    (?P<area>\d{3})   # area code
    [-.\s]?           # optional separator
    (?P<num>\d{4})    # number
""", re.X)
pat.search("call 555 1234")["num"]            # '1234'

Inline Modifiers

SyntaxEffect
(?i)on for the whole pattern (not JS; Python: start only)
(?i:…)on inside this group only (JS: ES2025)
(?-i)off from here on (PCRE, Java, .NET, Ruby)
(?-i:…)off inside this group (Python 3.7+ too)
(?im-sx)several on and off at once
(?x)verbose mode from inside the pattern

⚠ Common Mistakes

  • Adding m to make . span lines; you needed s (or [\s\S])
  • Reusing a JS regex with g across test() calls; lastIndex makes alternate calls fail (sheet 20)
  • In verbose mode, forgetting that a literal space or # must be escaped

✓ Tips & Best Practices

  • Use verbose mode for any pattern longer than ~40 characters, with a comment per piece
  • Prefer scoped (?i:…) over a global flag when only one word is case-insensitive
  • Combine flags with | in Python and Java: re.I | re.M

Quick Summary

  • i m s x — case, lines, dot-all, verbose
  • g y — JS: all matches / sticky
  • (?i) — inline flag
  • (?i:…) — flag for one group only
