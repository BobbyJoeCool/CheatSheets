Sheet 10

Padding, Frames & Alignment

.padding · .frame(maxWidth: .infinity) · alignmentGuide · fixedSize · layoutPriority

Sizing & Positioning

SwiftUI layout is a negotiation: a parent proposes a size, the child chooses its size, and the parent places it. .padding adds space, .frame proposes a size (fixed or min/max) and aligns the content within it, and fixedSize and layoutPriority settle conflicts when space runs out.

Notes

  • .frame(maxWidth: .infinity) makes a view as wide as allowed
  • Text wraps by default; fixedSize() stops truncation
  • Higher layoutPriority gets space first
  • alignmentGuide shifts a view's alignment point

Padding & Frames

Text("Edge to edge")
    .padding(.horizontal, 16)
    .padding(.vertical, 8)
    .frame(maxWidth: .infinity, alignment: .leading)   // full width
    .background(.blue.opacity(0.1))

Image(systemName: "star")
    .frame(width: 44, height: 44)                      // tap target

Text("Fits")
    .frame(minWidth: 80, maxWidth: 200, minHeight: 32)

HStack {
    Text("A very long title that should win").layoutPriority(1)
    Text("Detail")                                     // shrinks first
}

Text("Never truncate me").fixedSize()

HStack(alignment: .top) {
    Text("•")
    Text("Shifted").alignmentGuide(.top) { d in d[.top] - 4 }
}

Frame Forms

FormEffect
.frame(width: 100)Fixed width
.frame(maxWidth: .infinity)Fill width
.frame(minHeight: 44)At least 44
.frame(…, alignment: .leading)Position inside
.fixedSize(horizontal: false, vertical: true)Grow vertically

Code Explained

.padding(.horizontal, 16) — edges + amount
maxWidth: .infinity — expand
frame(width:height:) — fixed size
layoutPriority(1) — gets space first
fixedSize() — ideal size, no truncation

Minimum OS

  • All APIs here: iOS 13
  • .padding(.vertical, 8) edge sets: iOS 13

UIKit / React Equivalent

  • UIKit Auto Layout constraints, content hugging / compression priority
  • React Native padding, width, flex: 1, alignSelf

⚠ Common Mistakes

  • Fixed widths everywhere: breaks on small phones and large text
  • .frame after .background: the background doesn't grow
  • Fighting truncation with fixed widths instead of layoutPriority

✓ Tips & Best Practices

  • Keep tap targets at least 44×44 points
  • Use .containerRelativeFrame for "half the screen" sizes (Sheet 13)
  • Debug sizes with .border(.red)

Quick Summary

  • parent proposes, child chooses
  • padding / frame / maxWidth: .infinity
  • layoutPriority / fixedSize for conflicts
