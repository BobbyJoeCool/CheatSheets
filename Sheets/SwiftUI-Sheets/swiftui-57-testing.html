Testing SwiftUI Apps

Test logic in models with fast unit tests (Swift Testing), using fake services. Test flows with XCUITest, which drives the real app through accessibility; give important elements an accessibilityIdentifier. Previews catch visual regressions during development, and snapshot testing libraries compare rendered images in CI.

Notes

  • Models with injected services are easy to unit test
  • Mark model tests @MainActor when the model is
  • Pass launch arguments to switch the app to mock data
  • Snapshot testing: e.g. pointfreeco/swift-snapshot-testing
  • Swift set: 087 · Swift Testing

Unit & UI Tests

import Testing
@testable import Recipes

@MainActor
@Test func loadsRecipes() async {
    let model = RecipeListModel(service: MockRecipeService())
    await model.load()
    #expect(model.recipes.count == Recipe.samples.count)
}

// UI test target (XCTest)
import XCTest
final class RecipeUITests: XCTestCase {
    func testAddRecipe() {
        let app = XCUIApplication()
        app.launchArguments = ["-useMockData"]
        app.launch()
        app.buttons["addRecipe"].tap()
        app.textFields["recipeName"].typeText("Soup")
        app.buttons["Save"].tap()
        XCTAssertTrue(app.staticTexts["Soup"].waitForExistence(timeout: 2))
    }
}

// In the app:
Button("Add", systemImage: "plus", action: add)
    .accessibilityIdentifier("addRecipe")

Code Explained

@MainActor @Test — unit test a model
mock service — no network in tests
XCUIApplication + launch arguments — UI test
accessibilityIdentifier — stable UI handle
waitForExistence — handle async UI

Minimum OS

  • Swift Testing: Xcode 16
  • XCUITest: all supported OS versions

UIKit / React Equivalent

  • UIKit Same: XCTest + XCUITest; view controllers harder to unit test
  • React Native Jest + React Native Testing Library; Detox / Maestro for E2E

⚠ Common Mistakes

  • Testing view internals: test models and user-visible behavior instead
  • UI tests depending on real network data: flaky
  • Locating elements by display text that gets localized

✓ Tips & Best Practices

  • Read ProcessInfo.processInfo.arguments at launch to inject mocks
  • Keep UI tests few and focused on critical flows
  • Run tests on CI with xcodebuild test -scheme App -destination …

Quick Summary
