Color, Gradients & Materials

Color values come from the system (.blue, .primary, .secondary), the asset catalog (with light and dark variants), or RGB. Apply them with .foregroundStyle, .background and .tint. Gradients and materials (translucent blurred backgrounds) are also ShapeStyles, so they work anywhere a color does.

Notes

  • .primary / .secondary adapt to light and dark mode
  • .tint sets the accent for controls in a subtree
  • Asset catalog colors: Color("Brand") or generated Color.brand
  • Materials blur what's behind them

Styles

Text("Primary").foregroundStyle(.primary)
Text("Muted").foregroundStyle(.secondary)
Text("Brand").foregroundStyle(Color.brand)       // asset symbol

Rectangle()
    .fill(.linearGradient(colors: [.purple, .blue],
                          startPoint: .top, endPoint: .bottom))
    .frame(height: 120)

Circle().fill(.radialGradient(colors: [.yellow, .orange],
                              center: .center, startRadius: 5, endRadius: 60))

Text("Overlay")
    .padding()
    .background(.ultraThinMaterial, in: .rect(cornerRadius: 12))

Form { Toggle("Alerts", isOn: $on) }
    .tint(.green)                                // control accent

Color(red: 0.2, green: 0.6, blue: 0.9).opacity(0.5)

Semantic Colors

ColorUse
.primaryMain text
.secondarySupporting text
.accentColorApp accent
Color(.systemBackground)Screen background
Color(.secondarySystemBackground)Grouped cards

Code Explained

.primary / .secondary — adaptive text colors
Color.brand — generated asset color symbol
.linearGradient / .radialGradient — gradient styles
.ultraThinMaterial — blurred background
.tint — accent color for controls

Minimum OS

  • Materials, foregroundStyle: iOS 15
  • Asset color symbols (Color.brand): Xcode 15

UIKit / React Equivalent

  • UIKit UIColor.systemBlue, UIVisualEffectView for blur
  • React Native Hex strings in styles; expo-blur for materials

Accessibility

  • Check contrast in both appearances; asset colors support high-contrast variants
  • Don't use color alone to convey state; add an icon or text

⚠ Common Mistakes

  • Hard-coding .black text: invisible in dark mode
  • Using foregroundColor: deprecated, use foregroundStyle
  • Stacking several materials: muddy and slow

✓ Tips & Best Practices

  • Define brand colors in the asset catalog with dark variants
  • Use .background(.regularMaterial, in: .capsule) for floating chips
  • ShapeStyle lets one property accept colors, gradients or materials

Quick Summary

  • semantic + asset colors
  • gradients and materials are styles
  • .tint for controls
