Touch Gestures

Attach gestures with .gesture(...) or shortcut modifiers like .onTapGesture. DragGesture, LongPressGesture, MagnifyGesture and RotateGesture report values as they change. @GestureState holds a value only during the gesture and resets automatically; combine gestures with simultaneously, sequenced and exclusively.

Notes

  • Prefer Button over onTapGesture for actions
  • .highPriorityGesture wins over children's gestures
  • .contentShape(.rect) makes empty areas tappable
  • Gesture values: translation, magnification, rotation

Drag & Magnify

struct DraggableCard: View {
    @State private var offset = CGSize.zero          // where it rests
    @GestureState private var drag = CGSize.zero     // during drag
    @State private var scale = 1.0

    var body: some View {
        RoundedRectangle(cornerRadius: 20).fill(.blue)
            .frame(width: 200, height: 120)
            .scaleEffect(scale)
            .offset(x: offset.width + drag.width, y: offset.height + drag.height)
            .gesture(
                DragGesture()
                    .updating($drag) { v, state, _ in state = v.translation }
                    .onEnded { v in
                        offset.width += v.translation.width
                        offset.height += v.translation.height
                    }
                    .simultaneously(with: MagnifyGesture()
                        .onChanged { scale = $0.magnification })
            )
            .onTapGesture(count: 2) { withAnimation { scale = 1 } }
    }
}

Code Explained

@GestureState — resets when the gesture ends
.updating($drag) — live value
.onEnded — commit final position
.simultaneously(with:) — combine gestures
onTapGesture(count: 2) — double tap

Minimum OS

  • Drag / LongPress / Tap gestures: iOS 13
  • MagnifyGesture, RotateGesture: iOS 17 (were MagnificationGesture)

UIKit / React Equivalent

  • UIKit UIPanGestureRecognizer, UIPinchGestureRecognizer
  • React Native react-native-gesture-handler + Reanimated

Accessibility

  • Provide an .accessibilityAction for anything only reachable by a gesture
  • Custom drag UIs need an alternative like buttons or a slider

⚠ Common Mistakes

  • A gesture on a ScrollView child blocking scrolling: use simultaneousGesture
  • Storing drag offsets in @State and forgetting to reset them
  • Gestures on views with transparent areas that don't receive touches

✓ Tips & Best Practices

  • Animate the snap-back in onEnded with a spring
  • Use minimumDistance: on drags inside scroll views
  • .sensoryFeedback adds haptics at gesture milestones

Quick Summary

  • .gesture(DragGesture()...)
  • @GestureState for transient values
  • compose with simultaneously etc.
