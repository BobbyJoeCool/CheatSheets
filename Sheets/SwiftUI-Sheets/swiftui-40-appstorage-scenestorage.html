@AppStorage & @SceneStorage

@AppStorage · @SceneStorage · UserDefaults · RawRepresentable values · state restoration

Small Persistent Values

@AppStorage is a property wrapper that reads and writes a UserDefaults key and redraws the view when it changes, which is perfect for settings. @SceneStorage saves small UI state per scene (selected tab, draft text) so it's restored when the system relaunches the app. Neither is for large data or secrets.

Notes

  • Supports Bool, Int, Double, String, URL, Data and String/Int RawRepresentable enums
  • Pass store: UserDefaults(suiteName:) to share with widgets
  • SceneStorage is per window and lost if the user force-quits
  • Secrets belong in the Keychain (see Swift set)
  • Swift set: 080 · UserDefaults & Keychain

@AppStorage & @SceneStorage

enum Theme: String, CaseIterable { case system, light, dark }

struct SettingsView: View {
    @AppStorage("theme") private var theme = Theme.system
    @AppStorage("fontScale") private var fontScale = 1.0
    @AppStorage("onboarded") private var onboarded = false

    var body: some View {
        Form {
            Picker("Theme", selection: $theme) {
                ForEach(Theme.allCases, id: \.self) { Text($0.rawValue) }
            }
            Slider(value: $fontScale, in: 0.8...1.4)
            Button("Replay Onboarding") { onboarded = false }
        }
    }
}

struct RootTabs: View {
    @SceneStorage("selectedTab") private var tab = "home"
    var body: some View { TabView(selection: $tab) { /* tabs */ } }
}

  • UIKit UserDefaults + state restoration APIs
  • React Native AsyncStorage / MMKV + a hook

⚠ Common Mistakes

  • Storing arrays of models in AppStorage via Data: use SwiftData or files
  • Typos in duplicated key strings: centralize keys
  • Expecting SceneStorage to survive a force-quit

✓ Tips & Best Practices

  • Define keys once: enum Keys { static let theme = "theme" }
  • Use .defaultAppStorage(_:) to set the store for a subtree
  • Apply the theme at the root with .preferredColorScheme

Quick Summary

  • @AppStorage — settings
  • @SceneStorage — UI restoration
  • neither for big data or secrets
