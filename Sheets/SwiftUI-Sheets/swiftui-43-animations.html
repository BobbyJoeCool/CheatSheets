Animating Changes

SwiftUI animates state changes. Wrap a change in withAnimation (explicit) to animate everything it affects, or attach .animation(_:value:) (implicit) to animate a view whenever one value changes. Springs are the default feel; contentTransition animates text and symbol changes in place.

Notes

  • Only animatable properties interpolate (opacity, frame, color, offset)
  • Always pass value: to .animation
  • .spring(duration:bounce:), .snappy, .bouncy presets
  • Respect Reduce Motion for large movement

Explicit & Implicit

@State private var expanded = false
@State private var count = 0

VStack {
    RoundedRectangle(cornerRadius: expanded ? 30 : 10)
        .fill(expanded ? .orange : .blue)
        .frame(width: expanded ? 240 : 120, height: 120)
        .animation(.spring(duration: 0.4, bounce: 0.3), value: expanded)

    Text("\(count)")
        .font(.largeTitle.monospacedDigit())
        .contentTransition(.numericText(value: Double(count)))

    Button("Toggle") { expanded.toggle() }
    Button("Add") {
        withAnimation(.snappy) { count += 1 }     // explicit
    }
}

withAnimation(.easeInOut(duration: 0.3)) { isOn = true } completion: {
    showNext = true
}

Animation Curves

AnimationFeel
.default / .springNatural spring
.snappyQuick, small bounce
.bouncyPlayful bounce
.smoothNo bounce
.easeInOut(duration:)Classic curve
.linearConstant speed

Code Explained

.animation(_:value:) — implicit, tied to a value
withAnimation { } — explicit, around a change
.spring(duration:bounce:) — spring parameters
contentTransition(.numericText()) — rolling numbers
completion: — run after the animation

Minimum OS

  • withAnimation: iOS 13; contentTransition: iOS 16
  • Spring presets, completion:: iOS 17

UIKit / React Equivalent

  • UIKit UIView.animate(withDuration:) / UIViewPropertyAnimator
  • React Native Animated API or Reanimated withSpring

Accessibility

  • Check @Environment(\.accessibilityReduceMotion) and swap big motion for fades
  • Don't animate essential info away before VoiceOver can read it

⚠ Common Mistakes

  • .animation(.default) without value:: deprecated, animates too much
  • Animating layout of huge lists: janky; animate smaller pieces
  • Expecting if insertions to animate without a transition (Sheet 44)

✓ Tips & Best Practices

  • Use .transaction { $0.animation = nil } to turn animation off for a change
  • Use .sensoryFeedback alongside motion for physical feel
  • Test with Slow Animations in the simulator's Debug menu
