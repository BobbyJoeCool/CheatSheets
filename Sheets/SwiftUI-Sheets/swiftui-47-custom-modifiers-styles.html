Custom Modifiers & Styles

ViewModifier · .modifier() · view extensions · ButtonStyle · LabelStyle · style configuration

Reusable Styling

Package repeated modifier chains into a ViewModifier and expose it as a view extension, so .cardStyle() reads like a built-in modifier. For controls, write styles: a ButtonStyle gets the label and pressed state, and applying it with .buttonStyle(...) restyles every button in that subtree while keeping button behavior and accessibility.

Notes

  • ViewModifier: func body(content: Content) -> some View
  • Styles exist for buttons, labels, toggles, pickers, progress, gauges
  • Static extensions give dot syntax: .buttonStyle(.primary)
  • Styles flow down the hierarchy like environment values
  • Swift set: 070 · Protocol Extensions & POP

Modifier & ButtonStyle

struct CardStyle: ViewModifier {
    func body(content: Content) -> some View {
        content
            .padding()
            .background(.background, in: .rect(cornerRadius: 16))
            .shadow(color: .black.opacity(0.1), radius: 8, y: 4)
    }
}
extension View { func cardStyle() -> some View { modifier(CardStyle()) } }

struct PrimaryButtonStyle: ButtonStyle {
    func makeBody(configuration: Configuration) -> some View {
        configuration.label
            .font(.headline)
            .padding(.horizontal, 24).padding(.vertical, 12)
            .background(.tint, in: .capsule)
            .foregroundStyle(.white)
            .scaleEffect(configuration.isPressed ? 0.96 : 1)
            .animation(.snappy, value: configuration.isPressed)
    }
}
extension ButtonStyle where Self == PrimaryButtonStyle {
    static var primary: Self { .init() }
}

VStack { Text("Hello").cardStyle(); Button("Go") {}.buttonStyle(.primary) }

Minimum OS

  • ViewModifier, ButtonStyle: iOS 13
  • .background(_, in: shape): iOS 15

UIKit / React Equivalent

  • UIKit UIView subclasses or UIButton.Configuration; UIAppearance
  • React Native Shared StyleSheet objects / styled components

⚠ Common Mistakes

  • Rebuilding a button from onTapGesture + modifiers instead of a ButtonStyle
  • Hard-coded colors inside styles: use .tint and semantic colors
  • Huge modifiers with many parameters: split them

✓ Tips & Best Practices

  • Read @Environment(\.isEnabled) in a style to draw disabled states
  • Put your design system in a Swift package of modifiers and styles
  • Use PrimitiveButtonStyle only when you need custom tap handling
