Overlays, Backgrounds & Safe Area

.overlay · .background · ignoresSafeArea · safeAreaInset · safeAreaPadding · zIndex

Layers & the Safe Area

.background and .overlay add views behind or in front of a view and take its size, which makes them better than ZStack for decorations like badges and cards. The safe area keeps content clear of the notch, home indicator and bars; ignoresSafeArea extends backgrounds into it, and safeAreaInset adds your own bars that content scrolls under.

Notes

  • Overlay content is sized and aligned to the base view
  • Backgrounds that are Colors fill the safe area automatically
  • safeAreaInset shrinks the safe area for siblings like scroll views
  • zIndex changes stacking order in a ZStack

Overlay, Background, Safe Area

Image(systemName: "bell")
    .font(.title)
    .overlay(alignment: .topTrailing) {
        Circle().fill(.red).frame(width: 10, height: 10)   // badge
    }

Text("Card")
    .padding()
    .frame(maxWidth: .infinity)
    .background(.background, in: .rect(cornerRadius: 16))
    .shadow(radius: 4)

ZStack {
    Color.indigo.ignoresSafeArea()            // full-bleed background
    Text("Content stays safe")
}

ScrollView { messages }
    .safeAreaInset(edge: .bottom) {
        ComposeBar().background(.bar)        // list scrolls under it
    }
    .safeAreaPadding(.horizontal, 20)

Code Explained

.overlay(alignment:) — decorate on top
.background(_, in: shape) — shaped background
.ignoresSafeArea() — extend into edges
.safeAreaInset(edge:) — custom bar
.safeAreaPadding — padding that respects scroll

Minimum OS

  • overlay(alignment:content:): iOS 15
  • safeAreaPadding: iOS 17

UIKit / React Equivalent

  • UIKit Subviews + safeAreaLayoutGuide, additionalSafeAreaInsets
  • React Native position: 'absolute' + SafeAreaView / safe-area-context

⚠ Common Mistakes

  • Calling ignoresSafeArea on content, not just its background: text under the notch
  • Using ZStack for a badge and fighting alignment
  • Adding a bottom bar with VStack over a ScrollView: content can't scroll under it

✓ Tips & Best Practices

  • .ignoresSafeArea(.keyboard) stops the keyboard pushing a view up
  • Use .background(.bar) for system-styled bars
  • Use .containerShape + ContainerRelativeShape for nested corner radii

Quick Summary

  • .overlay / .background take the base size
  • ignoresSafeArea for backgrounds
  • safeAreaInset for custom bars
