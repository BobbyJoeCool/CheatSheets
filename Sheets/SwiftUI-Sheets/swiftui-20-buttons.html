Buttons

Button · role: · buttonStyle · .bordered · .borderedProminent · .disabled · Button(action:label:)

Buttons

Button runs an action when tapped. Give it a title and a trailing closure, or a custom label view. Roles (.destructive, .cancel) tell the system how to style and place it, and button styles (.bordered, .borderedProminent, .plain) set its look for a whole subtree.

Notes

  • Style a group at once: .buttonStyle(.bordered) on a container
  • .controlSize(.large) scales built-in styles
  • .disabled(cond) dims and blocks taps
  • Async work: start a Task inside the action
  • Swift set: 045 · Closures — Basics

Button Forms

Button("Save") { save() }
    .buttonStyle(.borderedProminent)
    .controlSize(.large)

Button("Delete", role: .destructive) { delete() }
    .buttonStyle(.bordered)

Button {
    Task { await refresh() }                  // async action
} label: {
    Label("Refresh", systemImage: "arrow.clockwise")
}
.disabled(isLoading)

Button(action: share) {
    Image(systemName: "square.and.arrow.up")
}
.accessibilityLabel("Share")

HStack { Button("A") {}; Button("B") {} }
    .buttonStyle(.plain)                      // applies to both
    .sensoryFeedback(.success, trigger: savedCount)

Code Explained

Button("Title") { } — simplest form
role: .destructive — red, placed correctly
label: — any view as the label
.disabled — block taps
.sensoryFeedback — haptics on change

Minimum OS

  • role:, .bordered styles: iOS 15
  • .sensoryFeedback: iOS 17

UIKit / React Equivalent

  • UIKit UIButton with UIButton.Configuration + addAction
  • React Native <Pressable onPress> / <Button title onPress>

Accessibility

  • Icon-only buttons need .accessibilityLabel
  • Keep the tap area at least 44×44 pt; add .contentShape(.rect) for padded labels

Built-in Styles

StyleLook
.automaticPlatform default
.borderedTinted capsule
.borderedProminentFilled accent
.borderlessText only
.plainNo styling at all

⚠ Common Mistakes

  • Wrapping a view in .onTapGesture instead of Button: loses accessibility and highlight
  • Long-running work directly in the action without Task
  • Tapping only the text of a wide button: add .contentShape(.rect)

✓ Tips & Best Practices

  • Write custom ButtonStyles for brand buttons (Sheet 47)
  • Use .keyboardShortcut(.defaultAction) on Mac/iPad
  • Show progress by swapping the label while isLoading
