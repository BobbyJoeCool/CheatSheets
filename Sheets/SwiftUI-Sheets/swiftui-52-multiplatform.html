Multiplatform SwiftUI

#if os() · macOS · watchOS · visionOS · platform-only modifiers · Settings scene

One Codebase, Many Platforms

Most SwiftUI code runs everywhere, but each platform has its own conventions: menus and windows on Mac, the Digital Crown on Watch, volumes and ornaments on Vision Pro. Use #if os(...) for platform-only code, prefer semantic APIs (toolbar placements, Settings scenes) that adapt by themselves, and design for pointer and keyboard where they exist.

Notes

  • One multiplatform target can build for iOS, iPadOS, macOS, visionOS
  • Some modifiers are platform-only and fail to compile elsewhere
  • Mac windows need sensible minimum sizes
  • .keyboardShortcut helps Mac and iPad with keyboards

Platform Differences

@main struct NotesApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
                #if os(macOS)
                .frame(minWidth: 700, minHeight: 450)
                #endif
        }
        .commands {
            CommandMenu("Note") {
                Button("New Note") { newNote() }.keyboardShortcut("n")
            }
        }
        #if os(macOS)
        Settings { SettingsView() }
        MenuBarExtra("Quick Note", systemImage: "note") { QuickNote() }
        #endif
        #if os(visionOS)
        ImmersiveSpace(id: "focus") { FocusSpace() }
        #endif
    }
}

Platform-Specific APIs

PlatformExamples
macOSSettings, MenuBarExtra, .commands
iOS.navigationBarTitleDisplayMode, .keyboardType
watchOS.digitalCrownRotation, NavigationStack-only UI
visionOSImmersiveSpace, .ornament, .glassBackgroundEffect
tvOS.focusable, focus sections

Code Explained

#if os(macOS) — platform-only code
.commands / CommandMenu — Mac/iPad menus
Settings / MenuBarExtra — Mac scenes
ImmersiveSpace — visionOS

Minimum OS

  • macOS SwiftUI apps: macOS 11+; MenuBarExtra: macOS 13
  • visionOS: 1.0 (2024)

UIKit / React Equivalent

  • UIKit Mac Catalyst or separate AppKit code
  • React Native Platform.OS checks; react-native-macos / windows

⚠ Common Mistakes

  • Sprinkling #if os everywhere: wrap differences in small helpers
  • Shipping iPhone layouts stretched on Mac
  • Ignoring hover and pointer: add .hoverEffect / .onHover

✓ Tips & Best Practices

  • Share models and most views; specialize only top-level layout
  • Use #if canImport(UIKit) for UIKit-dependent helpers
  • Test keyboard navigation on iPad and Mac

Quick Summary

  • #if os() for platform code
  • semantic APIs adapt automatically
  • Mac: commands, Settings, windows
