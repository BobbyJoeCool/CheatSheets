Toggle, Slider & Stepper

Toggle · toggleStyle · Slider · in: step: · Stepper · onEditingChanged

Switches & Sliders

Toggle binds to a Bool, Slider to a floating-point value within a range, and Stepper increments or decrements a value. All take bindings and adapt their look to the platform. Use onEditingChanged to know when a drag begins and ends, for example to save only when the user lets go.

Notes

  • Labels are required for accessibility, even if hidden
  • .labelsHidden() hides the visual label but keeps it for VoiceOver
  • Slider(step:) snaps to increments
  • toggleStyle(.button) makes a toggle look like a button

Toggle, Slider, Stepper

@State private var wifi = true
@State private var brightness = 0.7
@State private var guests = 2

Form {
    Toggle("Wi-Fi", isOn: $wifi)

    Slider(value: $brightness, in: 0...1) {
        Text("Brightness")
    } minimumValueLabel: {
        Image(systemName: "sun.min")
    } maximumValueLabel: {
        Image(systemName: "sun.max")
    } onEditingChanged: { editing in
        if !editing { save(brightness) }       // on release
    }

    Stepper("Guests: \(guests)", value: $guests, in: 1...10)

    Toggle("Bold", systemImage: "bold", isOn: $isBold)
        .toggleStyle(.button)
}

Code Explained

Toggle(isOn:) — Bool binding
Slider(value:in:) — range binding
min/max labels — icons at each end
onEditingChanged — drag start/end
Stepper(value:in:) — +/- control

Minimum OS

  • Toggle, Slider, Stepper: iOS 13
  • Toggle(_:systemImage:isOn:): iOS 17

UIKit / React Equivalent

  • UIKit UISwitch, UISlider, UIStepper + value-changed actions
  • React Native <Switch>, community <Slider>, custom stepper

Accessibility

  • VoiceOver reads the label and value: always give one, then .labelsHidden() if needed
  • Sliders adjust with swipe up/down; give a step that makes sense

Toggle Styles

StyleLook
.automaticSwitch (iOS)
.switchSwitch
.buttonHighlighted button
.checkboxCheckbox (macOS)

⚠ Common Mistakes

  • Saving on every slider tick: use onEditingChanged or debounce
  • Using an empty label Toggle(""): VoiceOver says nothing
  • Ranges on Int with Slider: it needs a floating-point binding

✓ Tips & Best Practices

  • Show the live value next to a slider with .monospacedDigit()
  • Use Gauge for read-only progress values
  • Wrap controls in Form for platform-standard layout

Quick Summary

  • Toggle / Slider / Stepper
