App & Scene Lifecycle

@Environment(\.scenePhase) tells you when a scene is active, inactive or in the background, so you can save data or pause work. onOpenURL handles deep links and universal links. @UIApplicationDelegateAdaptor connects an AppDelegate for things SwiftUI doesn't cover yet, like push notification registration.

Notes

  • Read scenePhase in the App for app-wide reactions
  • .backgroundTask(.appRefresh("id")) handles BGTasks
  • openWindow(id:) opens extra windows on iPad/Mac
  • handlesExternalEvents routes URLs to scenes (Mac)

Lifecycle Hooks

final class AppDelegate: NSObject, UIApplicationDelegate {
    func application(_ app: UIApplication,
        didRegisterForRemoteNotificationsWithDeviceToken token: Data) {
        Push.register(token)
    }
}

@main
struct MyApp: App {
    @UIApplicationDelegateAdaptor(AppDelegate.self) var delegate
    @Environment(\.scenePhase) private var phase
    @State private var store = Store()

    var body: some Scene {
        WindowGroup {
            RootView()
                .environment(store)
                .onOpenURL { url in store.handle(url) }   // deep links
        }
        .onChange(of: phase) { _, new in
            if new == .background { store.save() }
        }
        .backgroundTask(.appRefresh("refresh")) { await store.refresh() }
    }
}

Scene Phases

PhaseMeaning
.activeForeground, receiving events
.inactiveVisible but not interactive
.backgroundNot visible; save now

Code Explained

@UIApplicationDelegateAdaptor — classic delegate hooks
scenePhase — active / inactive / background
onChange(of: phase) — save on background
onOpenURL — deep links
.backgroundTask — background refresh

Minimum OS

  • scenePhase, onOpenURL, delegate adaptor: iOS 14
  • .backgroundTask, openWindow: iOS 16

UIKit / React Equivalent

  • UIKit AppDelegate / SceneDelegate callbacks
  • React Native AppState.addEventListener('change'), Linking

⚠ Common Mistakes

  • Doing heavy work when entering background: you get little time
  • Reading scenePhase in a subview to mean the whole app (it's that scene)
  • Handling deep links before the UI and models are ready

✓ Tips & Best Practices

  • Register the BGTask identifier in Info.plist (BGTaskSchedulerPermittedIdentifiers)
  • Route URLs through your router (Sheet 31)
  • SwiftData autosaves, but explicit saves on background are cheap insurance

Quick Summary

  • scenePhase for foreground/background
  • onOpenURL for links
  • delegate adaptor for UIKit-only hooks
