Sheets & Full-Screen Covers

.sheet(isPresented:) · .sheet(item:) · fullScreenCover · presentationDetents · dismiss · interactiveDismissDisabled

Modal Sheets

.sheet presents a view modally, controlled by a Bool (isPresented:) or an optional Identifiable item (item:), which also passes the data to show. fullScreenCover covers the whole screen. Detents make half-height sheets, and the presented view closes itself with @Environment(\.dismiss).

Notes

  • Prefer item: when the sheet needs data: no stale values
  • Each sheet gets its own environment; re-inject models if needed
  • interactiveDismissDisabled blocks swipe-down
  • Sheets on iPad show as centered cards

Sheets & Detents

@State private var showNew = false
@State private var editing: Note?               // item drives sheet

List(notes) { note in
    Button(note.title) { editing = note }
}
.toolbar { Button("New", systemImage: "plus") { showNew = true } }
.sheet(isPresented: $showNew) {
    NewNoteView()
        .presentationDetents([.medium, .large])
        .presentationDragIndicator(.visible)
}
.sheet(item: $editing) { note in
    EditNoteView(note: note)
        .interactiveDismissDisabled(note.hasUnsavedChanges)
}
.fullScreenCover(isPresented: $showOnboarding) { OnboardingView() }

struct NewNoteView: View {
    @Environment(\.dismiss) private var dismiss
    var body: some View { Button("Cancel") { dismiss() } }
}

Presentation Modifiers

Code Explained

.sheet(isPresented:) — Bool-driven
.sheet(item:) — data-driven, auto-nil on close
presentationDetents — half/full heights
fullScreenCover — covers everything
dismiss() — close from inside

Minimum OS

  • .sheet, fullScreenCover: iOS 13–14
  • presentationDetents: iOS 16

UIKit / React Equivalent

  • UIKit present(_:animated:) + UISheetPresentationController
  • React Navigation presentation: 'modal' screen / RN <Modal>

⚠ Common Mistakes

  • Bool sheet reading a separately stored selected item: shows stale data; use item:
  • Several .sheet modifiers on the same view for different Bools: use an enum item
  • Forgetting environment models inside the sheet content

✓ Tips & Best Practices

  • Use an enum SheetKind: Identifiable with one .sheet(item:)
  • Wrap sheet content in a NavigationStack to get a toolbar
  • Use .presentationDetents([.height(200)]) for small pickers
