Editing & Selecting Rows

Lists support editing out of the box: .onDelete and .onMove on a ForEach enable swipe-to-delete and drag-to-reorder, and EditButton toggles edit mode. swipeActions add custom leading or trailing buttons. Pass a selection binding to make rows selectable, including multiple selection in edit mode.

Notes

  • .onDelete gives an IndexSet; .onMove gives IndexSet + destination
  • Custom swipe actions replace the default delete
  • Selection uses each row's ID type
  • contextMenu adds long-press menus

Delete, Move, Swipe, Select

@State private var todos: [Todo] = Todo.samples
@State private var selection = Set<Todo.ID>()

NavigationStack {
    List(selection: $selection) {
        ForEach(todos) { todo in
            Text(todo.title)
                .swipeActions(edge: .leading) {
                    Button("Done") { complete(todo) }.tint(.green)
                }
                .contextMenu { Button("Duplicate") { dup(todo) } }
        }
        .onDelete { todos.remove(atOffsets: $0) }
        .onMove { todos.move(fromOffsets: $0, toOffset: $1) }
    }
    .toolbar { EditButton() }
    .navigationTitle("\(selection.count) selected")
}

Code Explained

.onDelete — swipe to delete
.onMove — drag to reorder in edit mode
swipeActions(edge:) — custom swipe buttons
List(selection:) — selectable rows
EditButton() — toggles edit mode

Minimum OS

  • onDelete, onMove, EditButton: iOS 13
  • swipeActions: iOS 15

UIKit / React Equivalent

  • UIKit tableView(_:commit:forRowAt:), UISwipeActionsConfiguration
  • React Native react-native-swipe-list-view, draggable-flatlist

Accessibility

  • Swipe actions appear in VoiceOver's actions rotor automatically
  • Custom drag reordering needs .accessibilityAction alternatives

Editing APIs

APIGives you
.onDelete { offsets }IndexSet
.onMove { from, to }IndexSet, Int
remove(atOffsets:)Array helper
move(fromOffsets:toOffset:)Array helper
.deleteDisabled(cond)Block per row

⚠ Common Mistakes

  • Applying .onDelete to List instead of the ForEach
  • Filtering with .filter then using offsets on the original array: wrong rows deleted
  • Destructive swipe action without role: .destructive

✓ Tips & Best Practices

  • Delete by ID when the list is filtered: map offsets to items first
  • Use allowsFullSwipe: false for risky actions
  • SwiftData lists: delete via modelContext.delete (Sheet 42)
