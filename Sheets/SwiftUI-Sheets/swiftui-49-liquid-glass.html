Liquid Glass

glassEffect · GlassEffectContainer · glassEffectID · .buttonStyle(.glass) · backgroundExtensionEffect · iOS 26 design

Apple's 2025 Design Language

iOS 26 introduced Liquid Glass, a translucent material that reflects and refracts content behind it. Standard bars, tab bars, toolbars and sheets adopt it automatically when built with the iOS 26 SDK. For custom controls, .glassEffect() applies glass to any view, GlassEffectContainer blends nearby glass shapes, and glassEffectID morphs glass between states.

Notes

  • Rebuilding with the iOS 26 SDK updates standard controls for free
  • Use glass for controls floating above content, not for content itself
  • .interactive() makes glass react to touch
  • Gate custom glass with if #available(iOS 26, *)

Glass Effects

@Namespace private var glass

GlassEffectContainer(spacing: 16) {             // shapes blend when close
    HStack(spacing: 16) {
        Button("Edit", systemImage: "pencil") { }
            .buttonStyle(.glass)
        if showMore {
            Button("Share", systemImage: "square.and.arrow.up") { }
                .buttonStyle(.glass)
                .glassEffectID("share", in: glass)
        }
    }
}

Text("Now Playing")
    .padding()
    .glassEffect(.regular.tint(.purple).interactive(), in: .capsule)

Button("Buy") { }.buttonStyle(.glassProminent)

Image("hero").resizable().scaledToFill()
    .backgroundExtensionEffect()                // extends under sidebar

Code Explained

.glassEffect(_:in:) — glass behind a view
.regular.tint().interactive() — glass variants
GlassEffectContainer — merges nearby glass
glassEffectID — morph glass on change
.buttonStyle(.glass / .glassProminent) — glass buttons

Minimum OS

  • Liquid Glass APIs: iOS 26 / macOS 26
  • Older OS: fall back to .background(.ultraThinMaterial)

UIKit / React Equivalent

  • UIKit UIGlassEffect in UIVisualEffectView (iOS 26)
  • React Native No built-in equivalent; native modules or blur views

⚠ Common Mistakes

  • Putting glass on large content areas: reduces legibility
  • Stacking glass on glass
  • Custom opaque nav bars fighting the new system bars

✓ Tips & Best Practices

  • Remove custom bar backgrounds and let the system draw glass
  • Check legibility with Reduce Transparency turned on
  • Use ToolbarSpacer to group toolbar items on iOS 26

Quick Summary

  • .glassEffect() on floating controls
  • GlassEffectContainer + glassEffectID
  • iOS 26+, with material fallback
