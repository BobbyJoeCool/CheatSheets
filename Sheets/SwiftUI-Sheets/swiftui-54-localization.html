Translating Your App

String literals in Text, Button and other views are LocalizedStringKeys, looked up automatically. Xcode String Catalogs (.xcstrings) collect every string at build time, track translation state, and handle plural and device variations. Use String(localized:) for strings created in code, and format numbers and dates with FormatStyle so they localize too.

Notes

  • Interpolations become format arguments: "\(count) items"
  • Mark plural variants in the catalog ("Vary by Plural")
  • Add comments for translators with comment:
  • Right-to-left languages flip layouts automatically
  • Swift set: 017 · String Interpolation & Formatting

Localized Strings

Text("Welcome")                                    // looked up
Text("\(count) photos")                            // plural variants in catalog
Button("Delete All") { }

let title = String(localized: "Settings",
                   comment: "Navigation title for settings screen")
let msg = String(localized: "Saved \(count) items")

Text(verbatim: user.name)                          // never translated
Text(LocalizedStringResource("onboarding.title"))  // keyed resource

Text(price, format: .currency(code: currency))     // locale-aware
Text(date, format: .dateTime.month().day())

#Preview("German") {
    SettingsView().environment(\.locale, Locale(identifier: "de"))
}
#Preview("RTL") {
    SettingsView().environment(\.layoutDirection, .rightToLeft)
}

Code Explained

string literal in Text — localized key
interpolation — becomes a plural-capable format
String(localized:comment:) — strings in code
Text(verbatim:) — skip lookup
\.locale / \.layoutDirection — preview languages

Minimum OS

  • String Catalogs: Xcode 15
  • String(localized:), LocalizedStringResource: iOS 15–16

UIKit / React Equivalent

  • UIKit NSLocalizedString + .strings / .stringsdict files
  • React Native i18next / react-intl translation keys

Catalog States

StateMeaning
NewNeeds translation

⚠ Common Mistakes

  • Building sentences by concatenation: word order differs by language
  • Passing a String variable to Text and expecting translation: it's displayed verbatim
  • Hard-coded left/right padding: use leading/trailing

✓ Tips & Best Practices

  • Export with Product › Export Localizations for translators
  • Use pseudo-languages (double length, RTL) in scheme options
  • Keep keys natural-language; catalogs handle the rest
