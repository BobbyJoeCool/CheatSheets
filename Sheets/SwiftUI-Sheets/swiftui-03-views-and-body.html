Views & body

View protocol · var body · some View · composition · extracting subviews · @ViewBuilder

The View Protocol

A view is a struct that conforms to View and provides a computed body. body returns some View: one concrete type the compiler works out from your code. Build screens by composing small views; extracting a subview into its own struct is cheap and makes previews and reuse easy. body is implicitly a @ViewBuilder, so you can list views and use if and switch inside it.

Notes

  • Views should be small; SwiftUI handles the cost
  • Pass data into subviews through their properties (let)
  • Use @ViewBuilder on your own functions that return views
  • Group groups views without adding layout
  • Swift set: 050 · Result Builders, 074 · Opaque & Existential Types

Composing Views

struct ProfileView: View {
    let user: User
    var body: some View {
        VStack(alignment: .leading) {
            Avatar(url: user.photoURL)              // subview
            Text(user.name).font(.title2)
            if user.isPro { ProBadge() }            // conditional
            stats                                   // computed sub-view
        }
    }
    @ViewBuilder private var stats: some View {
        if user.posts > 0 { Text("\(user.posts) posts") }
        else { Text("No posts yet").foregroundStyle(.secondary) }
    }
}

struct ProBadge: View {
    var body: some View { Text("PRO").font(.caption.bold()) }
}

Minimum OS

  • View, @ViewBuilder: iOS 13
  • if/switch in builders: iOS 14+

UIKit / React Equivalent

  • UIKit Custom UIView subclasses + addSubview
  • React Native Small function components with props

⚠ Common Mistakes

  • One 300-line body: slow to type-check and hard to read
  • Returning different types from a non-@ViewBuilder function: "opaque return type" error
  • Using AnyView to mix types: hurts diffing; use @ViewBuilder

✓ Tips & Best Practices

  • Extract a subview when a block gets a comment heading
  • Prefer subview structs over computed properties for reuse
  • Give previews sample data with a static let sample

Quick Summary

  • struct X: View { var body }
  • compose small views
  • @ViewBuilder for multi-branch helpers
