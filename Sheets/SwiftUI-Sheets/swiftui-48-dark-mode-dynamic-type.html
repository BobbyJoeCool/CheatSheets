Sheet 48

Dark Mode, Dynamic Type & Theming

colorScheme · preferredColorScheme · dynamicTypeSize · @ScaledMetric · custom fonts · theme via environment

Appearance & Text Size

Apps must look right in light and dark mode and at every Dynamic Type size. Semantic colors and fonts handle most of it automatically. Read colorScheme and dynamicTypeSize from the environment for special cases, scale custom numbers with @ScaledMetric, and switch layouts at accessibility sizes.

Notes

  • Accessibility sizes go up to .accessibility5
  • Custom fonts: .custom(_:size:relativeTo:) scales them
  • .preferredColorScheme forces a scheme for a whole presentation
  • Theme values travel well through the environment

Adapting to Settings

struct ProfileHeader: View {
    @Environment(\.colorScheme) private var scheme
    @Environment(\.dynamicTypeSize) private var typeSize
    @ScaledMetric(relativeTo: .body) private var avatar = 48.0

    var body: some View {
        let layout = typeSize.isAccessibilitySize
            ? AnyLayout(VStackLayout(alignment: .leading))
            : AnyLayout(HStackLayout())
        layout {
            Image("me").resizable().frame(width: avatar, height: avatar)
            Text("Ada").font(.custom("Avenir Next", size: 20, relativeTo: .title3))
        }
        .shadow(color: scheme == .dark ? .clear : .black.opacity(0.1), radius: 6)
    }
}

RootView()
    .preferredColorScheme(theme == .dark ? .dark : theme == .light ? .light : nil)
    .dynamicTypeSize(...DynamicTypeSize.accessibility3)   // cap if needed

Preview Checks

Code Explained

colorScheme — light / dark
dynamicTypeSize.isAccessibilitySize — switch layout
@ScaledMetric — numbers that scale with text
.custom(_:size:relativeTo:) — scalable custom font
.preferredColorScheme(nil) — follow system

Minimum OS

  • colorScheme: iOS 13; @ScaledMetric: iOS 14
  • dynamicTypeSize: iOS 15

UIKit / React Equivalent

  • UIKit traitCollection.userInterfaceStyle, UIFontMetrics
  • React Native useColorScheme(), allowFontScaling

Accessibility

  • Test at the largest accessibility size; nothing should truncate important text
  • Never block Dynamic Type entirely; cap only where layout truly breaks

⚠ Common Mistakes

  • Fixed font sizes that ignore Dynamic Type
  • Images and icons that don't grow with text: use @ScaledMetric
  • Shadows designed for light mode that look muddy in dark mode

✓ Tips & Best Practices

  • Use the Environment Overrides button in Xcode's debug bar
  • Use Xcode Previews' variants mode to see all type sizes at once
  • Keep a theme struct in the environment for brand values

Quick Summary

  • semantic colors + fonts first
  • @ScaledMetric for custom sizes
  • switch layouts at accessibility sizes
