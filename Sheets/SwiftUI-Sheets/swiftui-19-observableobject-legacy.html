ObservableObject (Legacy)

ObservableObject · @Published · @StateObject · @ObservedObject · @EnvironmentObject · migration

The Pre-iOS 17 Model API

Before Observation, models conformed to ObservableObject and marked properties @Published. Views held them with @StateObject (owner), @ObservedObject (passed in) and @EnvironmentObject (injected). You'll meet this in older code and in apps supporting iOS 16. Unlike @Observable, any published change redraws every observing view.

Notes

  • Built on Combine's objectWillChange publisher
  • @StateObject keeps the object alive across redraws
  • @ObservedObject doesn't own: recreated if the parent recreates it
  • Migration to @Observable is mostly mechanical

ObservableObject

import Combine

final class TimerModel: ObservableObject {
    @Published var seconds = 0
    @Published var isRunning = false
}

struct TimerScreen: View {
    @StateObject private var timer = TimerModel()      // owner
    var body: some View {
        TimerFace(timer: timer)
            .environmentObject(timer)                  // inject
    }
}

struct TimerFace: View {
    @ObservedObject var timer: TimerModel              // passed in
    var body: some View { Text("\(timer.seconds)s") }
}

struct StopButton: View {
    @EnvironmentObject var timer: TimerModel           // injected
    var body: some View { Button("Stop") { timer.isRunning = false } }
}

Code Explained

ObservableObject + @Published — old model
@StateObject — owner
@ObservedObject — non-owning reference
.environmentObject / @EnvironmentObject — injection

Minimum OS

  • ObservableObject, @ObservedObject: iOS 13
  • @StateObject: iOS 14

UIKit / React Equivalent

  • UIKit Combine sink on @Published in view controllers
  • React Native Redux store + connect / useSelector

⚠ Common Mistakes

  • Using @ObservedObject to create an object: it gets recreated and loses state
  • Forgetting @Published: views don't update
  • Mixing old and new wrappers on one object

✓ Tips & Best Practices

  • Migrate one model at a time; both systems coexist
  • Use @Published + Combine only if you need publisher pipelines
  • Check deployment target: below iOS 17, stay with this API

Quick Summary

  • ObservableObject / @Published — legacy
  • @StateObject owns, @ObservedObject borrows
  • migrate to @Observable
