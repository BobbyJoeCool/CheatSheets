Search, Refresh & Empty States

.searchable adds a system search field bound to a String; filter your data from it, optionally with scopes and suggestions. .refreshable adds pull-to-refresh to Lists and ScrollViews and awaits your async function. ContentUnavailableView shows standard empty and no-results screens.

Notes

  • Attach .searchable inside a NavigationStack for the bar placement
  • .refreshable shows the spinner until your async work finishes
  • ContentUnavailableView.search adapts to the query text
  • Debounce server searches with .task(id: query)

Search & Refresh

@State private var query = ""
@State private var scope = Scope.all

var filtered: [Book] {
    books.filter { query.isEmpty || $0.title.localizedStandardContains(query) }
}

NavigationStack {
    List(filtered) { BookRow($0) }
        .overlay {
            if filtered.isEmpty { ContentUnavailableView.search(text: query) }
        }
        .searchable(text: $query, prompt: "Title or author")
        .searchScopes($scope) {
            ForEach(Scope.allCases) { Text($0.label).tag($0) }
        }
        .refreshable { await store.reload() }
        .task(id: query) {                          // debounced server search
            try? await Task.sleep(for: .milliseconds(300))
            await store.search(query)
        }
}

Code Explained

.searchable(text:) — search field
localizedStandardContains — user-friendly match
ContentUnavailableView.search — no results
.searchScopes — scope bar
.refreshable — pull to refresh

Minimum OS

  • searchable, refreshable: iOS 15
  • searchScopes: iOS 16.4; ContentUnavailableView: iOS 17

UIKit / React Equivalent

  • UIKit UISearchController + UIRefreshControl
  • React Native TextInput header + RefreshControl on FlatList

⚠ Common Mistakes

  • Calling the server on every keystroke: debounce with .task(id:)
  • Blank screen when nothing matches: show ContentUnavailableView
  • Refresh that returns before the work finishes (not awaited)

✓ Tips & Best Practices

  • Use ContentUnavailableView("No Notes", systemImage:, description:) for empty states
  • Keep filtering in a computed property or the model
  • Add .searchable(…, placement: .navigationBarDrawer(displayMode: .always)) to pin it

Quick Summary
