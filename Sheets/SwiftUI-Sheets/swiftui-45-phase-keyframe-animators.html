Phase & Keyframe Animators

PhaseAnimator · phaseAnimator · KeyframeAnimator · keyframes · symbolEffect

Multi-Step Animations

Phase animators cycle a view through a list of phases, animating between each, either continuously or each time a trigger changes. Keyframe animators give precise control: separate tracks for properties like scale and offset, each with timed keyframes. SF Symbols have their own built-in symbol effects.

Notes

  • Phase animator: simple sequences (pulse, shake)
  • Keyframe animator: choreographed, timed motion
  • Both re-run when trigger: changes
  • Keyframe types: Linear, Spring, Cubic, Move

Phase & Keyframe

Image(systemName: "heart.fill")
    .phaseAnimator([1.0, 1.3, 1.0], trigger: likes) { view, scale in
        view.scaleEffect(scale)
    } animation: { _ in .spring(duration: 0.2) }

struct Jump { var y = 0.0; var scale = 1.0 }

Text("🎉")
    .font(.system(size: 60))
    .keyframeAnimator(initialValue: Jump(), trigger: wins) { view, v in
        view.offset(y: v.y).scaleEffect(v.scale)
    } keyframes: { _ in
        KeyframeTrack(\.y) {
            SpringKeyframe(-60, duration: 0.25)
            SpringKeyframe(0, duration: 0.35)
        }
        KeyframeTrack(\.scale) {
            CubicKeyframe(1.4, duration: 0.2)
            CubicKeyframe(1.0, duration: 0.4)
        }
    }

Image(systemName: "wifi")
    .symbolEffect(.variableColor.iterative, isActive: searching)

Code Explained

.phaseAnimator(phases, trigger:) — step through values
animation: — curve per phase
.keyframeAnimator(initialValue:trigger:) — tracks
KeyframeTrack(\.y) — one property's timeline
.symbolEffect(isActive:) — symbol animation

Minimum OS

  • PhaseAnimator, KeyframeAnimator, symbol effects: iOS 17
  • More symbol effects (.wiggle, .breathe): iOS 18

UIKit / React Equivalent

  • UIKit CAKeyframeAnimation / UIView.animateKeyframes
  • React Native Reanimated withSequence / Lottie

Keyframe Types

TypeMotion
LinearKeyframeStraight interpolation
SpringKeyframeSpring into value
CubicKeyframeSmooth curve
MoveKeyframeJump instantly

⚠ Common Mistakes

  • Phase animator without a trigger runs forever: fine for loaders, bad for content
  • Keyframe tracks of different lengths: shorter ones hold their last value
  • Using these for simple state changes withAnimation handles

✓ Tips & Best Practices

  • Store animation values in a small struct
  • Pair celebratory animations with .sensoryFeedback(.success, trigger:)
  • Respect Reduce Motion by skipping the trigger

Quick Summary

  • phaseAnimator — sequences
  • keyframeAnimator — timed tracks
