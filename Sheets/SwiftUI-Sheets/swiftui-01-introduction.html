What SwiftUI Is

SwiftUI is Apple's declarative UI framework, introduced in 2019. Instead of creating views and then changing them step by step, you describe what the screen should look like for the current state, and SwiftUI updates the screen whenever that state changes. Views are lightweight Swift structs, and one codebase runs on iOS, iPadOS, macOS, watchOS, tvOS and visionOS.

Notes

  • Views are values: cheap structs recreated on every update
  • State lives in property wrappers (@State) and models (@Observable)
  • UIKit and AppKit still run underneath; you can mix them
  • Requires Swift; see the Swift set for language features

A Complete SwiftUI View

import SwiftUI

struct CounterView: View {
    @State private var count = 0              // source of truth

    var body: some View {                     // describes the UI
        VStack(spacing: 12) {
            Text("Count: \(count)")
                .font(.largeTitle)
            Button("Add One") { count += 1 }  // change state…
                .buttonStyle(.borderedProminent)
        }                                     // …SwiftUI redraws
        .padding()
    }
}

Code Explained

View — protocol every screen piece conforms to
@State — value SwiftUI stores and watches
body — computed again when state changes
modifiers — .font, .padding return new views

⚠ Common Mistakes

  • Trying to keep references to views and change them later: describe state instead
  • Putting heavy work in body: it runs often
  • Learning from 2019–2021 tutorials: navigation and state APIs have changed

✓ Tips & Best Practices

  • Think "UI = f(state)": change the data, not the view
  • Use the preview canvas constantly while building
  • Read Apple's SwiftUI tutorials alongside this set

Quick Summary
