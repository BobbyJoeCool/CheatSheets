TabView

TabView · Tab · selection · badge · tabViewStyle · .page · sidebarAdaptable

Tabs

TabView shows top-level sections with a tab bar (or sidebar). Since iOS 18 you declare tabs with the Tab type, which supports a selection value, badges, and the .sidebarAdaptable style that becomes a sidebar on iPad. With .tabViewStyle(.page) the same view becomes swipeable pages.

Notes

  • Each tab usually has its own NavigationStack
  • Bind selection to switch tabs from code
  • Tab(role: .search) gets the system search tab
  • On iOS 26 the tab bar adopts Liquid Glass and can minimize on scroll

TabView

enum AppTab: Hashable { case home, inbox, profile, search }
@State private var tab = AppTab.home

TabView(selection: $tab) {
    Tab("Home", systemImage: "house", value: .home) {
        NavigationStack { HomeView() }
    }
    Tab("Inbox", systemImage: "tray", value: .inbox) {
        NavigationStack { InboxView() }
    }
    .badge(unreadCount)
    Tab("Profile", systemImage: "person", value: .profile) {
        NavigationStack { ProfileView() }
    }
    Tab(value: .search, role: .search) {
        NavigationStack { SearchView() }
    }
}
.tabViewStyle(.sidebarAdaptable)                 // sidebar on iPad

TabView { ForEach(pages) { OnboardingPage($0) } }
    .tabViewStyle(.page)                         // swipe pages

Code Explained

Tab(_:systemImage:value:) — declarative tab
TabView(selection:) — switch from code
.badge — count on the tab
role: .search — system search tab
.page style — onboarding pager

Minimum OS

  • Tab type, .sidebarAdaptable, role: .search: iOS 18
  • Before iOS 18: .tabItem { Label(…) } + .tag

UIKit / React Equivalent

  • UIKit UITabBarController with view controllers
  • React Navigation createBottomTabNavigator

TabView Styles

StyleLook
.automaticTab bar
.sidebarAdaptableTabs ↔ sidebar (iPad)
.tabBarOnlyNever a sidebar
.pageSwipeable pages

⚠ Common Mistakes

  • One NavigationStack wrapping the whole TabView: tab bar disappears on push
  • More than 5 tabs on iPhone: extras go to a "More" tab
  • Mixing Tab and .tabItem styles in one TabView

✓ Tips & Best Practices

  • Keep the selected tab in @SceneStorage to restore it
  • Use .tabBarMinimizeBehavior(.onScrollDown) on iOS 26
  • Use TabSection to group tabs in the iPad sidebar
