Sheet 09

Stacks

VStack · HStack · ZStack · alignment · spacing · Spacer · Divider

Stacking Views

Stacks are the core layout tools: VStack arranges children vertically, HStack horizontally and ZStack on top of each other. Each takes an alignment and (for V/H) a spacing. Spacer expands to push views apart, and Divider draws a separator line in the stack's direction.

Notes

  • Stacks size to fit their children
  • Spacer() takes all free space; Spacer(minLength:) sets a floor
  • Default spacing is adaptive per platform
  • Use lazy stacks only inside scroll views (Sheet 28)

V, H & Z Stacks

HStack(alignment: .top, spacing: 12) {
    Image(systemName: "person.circle.fill")
        .font(.largeTitle)
    VStack(alignment: .leading, spacing: 4) {
        Text("Ada Lovelace").font(.headline)
        Text("Analyst").foregroundStyle(.secondary)
    }
    Spacer()                                   // push button right
    Button("Follow") { }
}

VStack {
    Text("Top")
    Divider()
    Text("Bottom")
}

ZStack(alignment: .bottomTrailing) {
    Image("photo").resizable().scaledToFit()
    Text("NEW").padding(6).background(.red)    // badge in corner
}

Code Explained

HStack(alignment:spacing:) — row
VStack(alignment: .leading) — left-aligned column
Spacer() — fill remaining space
Divider() — separator line
ZStack(alignment:) — layered views

Minimum OS

  • Stacks, Spacer, Divider: iOS 13
  • LazyVStack / LazyHStack: iOS 14

UIKit / React Equivalent

  • UIKit UIStackView (axis, alignment, spacing)
  • React Native <View> with flexDirection: 'row' | 'column'

Alignment Values

StackOptions
VStack.leading .center .trailing
HStack.top .center .bottom .firstTextBaseline
ZStack.topLeading … .bottomTrailing

⚠ Common Mistakes

  • Expecting VStack to fill the width: it hugs its content; add .frame(maxWidth: .infinity)
  • Using ZStack for side-by-side content
  • Deeply nesting stacks where a Grid would be clearer

✓ Tips & Best Practices

  • Use .firstTextBaseline alignment for text of different sizes in a row
  • Pass spacing: 0 and add padding yourself for precise designs
  • Prefer .overlay over ZStack when one view decorates another
