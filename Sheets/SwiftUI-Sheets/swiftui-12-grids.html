Grids

Grid · GridRow · LazyVGrid · LazyHGrid · GridItem · .adaptive · .flexible

Grid Layouts

Grid lays out a fixed set of rows and columns that align across rows, like a table. For large or dynamic collections, LazyVGrid and LazyHGrid create cells only as they scroll into view, with columns described by GridItem: fixed, flexible, or adaptive (fit as many as possible).

Notes

  • Grid is eager: fine for forms and dashboards
  • Lazy grids must sit inside a ScrollView
  • .adaptive(minimum:) gives a responsive photo grid
  • gridCellColumns(_:) spans a cell across columns

Grid & LazyVGrid

Grid(alignment: .leading, horizontalSpacing: 16) {
    GridRow {
        Text("Steps");  Text("8,204").bold()
    }
    GridRow {
        Text("Distance");  Text("6.1 km").bold()
    }
    Divider().gridCellColumns(2)
}

let columns = [GridItem(.adaptive(minimum: 100), spacing: 8)]

ScrollView {
    LazyVGrid(columns: columns, spacing: 8) {
        ForEach(photos) { photo in
            PhotoThumb(photo)
                .aspectRatio(1, contentMode: .fill)
        }
    }
    .padding(8)
}

Code Explained

Grid + GridRow — aligned table layout
gridCellColumns(2) — span columns
GridItem(.adaptive(minimum:)) — responsive columns
LazyVGrid in ScrollView — lazy cells

Minimum OS

  • LazyVGrid / LazyHGrid: iOS 14
  • Grid / GridRow: iOS 16

UIKit / React Equivalent

  • UIKit UICollectionView with a compositional layout
  • React Native FlatList numColumns={3}

GridItem Sizes

SizeBehavior
.fixed(80)Exactly 80 pt
.flexible()Share space evenly
.flexible(minimum: 50)Share, with a floor
.adaptive(minimum: 100)As many as fit

⚠ Common Mistakes

  • Using Grid for hundreds of items: everything is built at once
  • Lazy grid outside a ScrollView: content is clipped
  • Expecting .adaptive columns to be one GridItem per column: one item makes many columns

✓ Tips & Best Practices

  • Use GridRow(alignment:) and .gridColumnAlignment for per-column alignment
  • Add pinnedViews: [.sectionHeaders] for sticky headers
  • Give cells a fixed aspect ratio to avoid jumpy scrolling

Quick Summary

  • Grid — small aligned tables
  • LazyVGrid — big scrolling collections
  • GridItem — fixed / flexible / adaptive
