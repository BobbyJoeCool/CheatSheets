Adaptive Layout

GeometryReader · ViewThatFits · containerRelativeFrame · horizontalSizeClass · Layout protocol · AnyLayout

Layouts That Adapt

Screens range from Apple Watch to a Mac window, so layouts must adapt. ViewThatFits picks the first child that fits. horizontalSizeClass tells you compact vs regular width. containerRelativeFrame sizes a view as a fraction of its container. GeometryReader exposes exact sizes when nothing else works, and the Layout protocol builds custom layouts; AnyLayout switches between them with animation.

Notes

  • Prefer size classes and ViewThatFits over raw geometry
  • GeometryReader takes all offered space: wrap it carefully
  • AnyLayout keeps identity when switching H ↔ V stacks
  • Custom Layout needs sizeThatFits + placeSubviews

Adaptive Techniques

@Environment(\.horizontalSizeClass) private var sizeClass

var body: some View {
    let layout = sizeClass == .compact
        ? AnyLayout(VStackLayout()) : AnyLayout(HStackLayout())
    layout { ChartView(); DetailsView() }     // animates on change
}

ViewThatFits {                                // first that fits wins
    HStack { Label("Download", systemImage: "arrow.down"); Text("2.1 GB") }
    Label("Download", systemImage: "arrow.down")
    Image(systemName: "arrow.down")
}

ScrollView(.horizontal) {
    LazyHStack {
        ForEach(cards) { CardView($0) }
            .containerRelativeFrame(.horizontal, count: 3, spacing: 10)
    }
}

GeometryReader { geo in
    Ring(progress: p).frame(width: geo.size.width * 0.5)
}

Code Explained

horizontalSizeClass — compact vs regular
AnyLayout — switch layouts, keep identity
ViewThatFits — fallbacks by size
containerRelativeFrame(count:) — 3 per screen
GeometryReader — exact size as a last resort

Minimum OS

  • ViewThatFits, AnyLayout, Layout: iOS 16
  • containerRelativeFrame: iOS 17

UIKit / React Equivalent

  • UIKit Trait collections + viewWillTransition(to:with:)
  • React Native useWindowDimensions() + conditional styles

⚠ Common Mistakes

  • Wrapping whole screens in GeometryReader: it breaks normal sizing
  • Checking UIScreen.main.bounds: wrong in split view and on iPad windows
  • Using if compact { VStack } else { HStack }: loses state; use AnyLayout

✓ Tips & Best Practices

  • Test in iPad split view and Slide Over, not just full screen
  • Use onGeometryChange (iOS 18) to read a size without GeometryReader
  • Write a small FlowLayout with the Layout protocol for tag clouds

Quick Summary

  • size classes + ViewThatFits
  • containerRelativeFrame for fractions
  • GeometryReader / Layout when needed
