NavigationStack

NavigationStack · NavigationLink · navigationDestination · navigationTitle · navigationBarTitleDisplayMode

Stack Navigation

NavigationStack manages a push/pop stack of screens. NavigationLink(value:) pushes a value, and navigationDestination(for:) declares which view to show for values of that type, keeping links and destinations decoupled. Titles and bar display mode are set on the content inside the stack.

Notes

  • Put navigationDestination inside the stack, not on lazy rows
  • Link values must be Hashable
  • Older NavigationView and NavigationLink(destination:) are deprecated patterns
  • Back button and swipe-back come for free
  • Swift set: 071 · Common Standard Protocols

NavigationStack

struct LibraryView: View {
    let books: [Book]
    var body: some View {
        NavigationStack {
            List(books) { book in
                NavigationLink(value: book) {          // push a value
                    BookRow(book)
                }
            }
            .navigationTitle("Library")
            .navigationDestination(for: Book.self) { book in
                BookDetail(book: book)
            }
            .navigationDestination(for: Author.self) { AuthorView($0) }
        }
    }
}

struct BookDetail: View {
    let book: Book
    var body: some View {
        Form { NavigationLink(book.author.name, value: book.author) }
            .navigationTitle(book.title)
            .navigationBarTitleDisplayMode(.inline)
    }
}

Code Explained

NavigationStack — push/pop container
NavigationLink(value:) — push data, not a view
navigationDestination(for:) — map type → view
navigationTitle — set on content
.inline title mode — small title

Minimum OS

  • NavigationStack, navigationDestination: iOS 16
  • Before iOS 16: NavigationView + NavigationLink(destination:)

UIKit / React Equivalent

  • UIKit UINavigationController.pushViewController
  • React Navigation createNativeStackNavigator + navigation.navigate

⚠ Common Mistakes

  • Nesting a NavigationStack inside another: double bars, broken pushes
  • Putting navigationDestination on a row inside a lazy List: may not register
  • Using non-Hashable values in NavigationLink(value:)

✓ Tips & Best Practices

  • One NavigationStack per tab, at the root of each tab
  • Use an enum Route: Hashable for all destinations (Sheet 31)
  • .toolbarTitleMenu { } adds a menu under the title

Quick Summary

  • NavigationStack + value links
  • navigationDestination(for:)
  • titles on content
