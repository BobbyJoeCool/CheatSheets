Lists

List · ForEach · Identifiable · id: · listStyle · Section · row content

Lists of Data

List shows scrolling rows in the platform's standard style, with built-in separators, sections, swipe actions and selection. Feed it a collection of Identifiable items (or give an id: key path) so SwiftUI can track rows across changes. ForEach inside a List lets you mix static rows, sections and dynamic data.

Notes

  • List is lazy: rows are created as they scroll on screen
  • IDs must be stable and unique, never array indices
  • listStyle changes the whole look (.insetGrouped, .plain)
  • Row modifiers: listRowSeparator, listRowBackground, listRowInsets
  • Swift set: 071 · Common Standard Protocols

List & ForEach

struct Contact: Identifiable {
    let id: UUID
    var name: String
    var isFavorite: Bool
}

List {
    Section("Favorites") {
        ForEach(contacts.filter(\.isFavorite)) { c in
            Label(c.name, systemImage: "star.fill")
        }
    }
    Section("All") {
        ForEach(contacts) { c in
            NavigationLink(c.name, value: c.id)
        }
    }
}
.listStyle(.insetGrouped)

List(tags, id: \.self) { tag in Text(tag) }    // Strings, id by self

Code Explained

Identifiable — stable id per row
Section("…") — grouped headers
ForEach — rows from data inside List
id: \.self — for simple unique values
.listStyle — whole-list appearance

Minimum OS

  • List, ForEach: iOS 13
  • listRowSeparator, .insetGrouped on iPhone: iOS 15

UIKit / React Equivalent

  • UIKit UITableView / UICollectionView list + diffable data source
  • React Native <FlatList data keyExtractor> / <SectionList>

Accessibility

  • Rows combine their text for VoiceOver automatically
  • Add .accessibilityElement(children: .combine) to custom multi-part rows

⚠ Common Mistakes

  • id: \.self on items that can repeat or change: rows glitch
  • Using array indices as IDs: insert/delete animations break
  • Putting a List inside a ScrollView: it collapses to zero height

✓ Tips & Best Practices

  • Make model types Identifiable once and reuse everywhere
  • Use .listRowSeparator(.hidden) for custom row designs
  • Use ContentUnavailableView when the list is empty (Sheet 29)

Quick Summary
