Text & Labels

Text · .font · .fontWeight · Label · AttributedString · Markdown in Text · lineLimit

Displaying Text

Text displays read-only strings, styled with modifiers like .font, .fontWeight and .foregroundStyle. String literals in Text are localized automatically and support simple Markdown (bold, italic, links). Label pairs text with an icon and adapts to its context, for example showing only the icon in a toolbar.

Notes

  • Use semantic fonts (.headline, .body) so Dynamic Type works
  • Text concatenation with + mixes styles
  • Text(date, style: .relative) updates live
  • AttributedString for rich text from code

Text & Label

VStack(alignment: .leading, spacing: 8) {
    Text("Welcome back").font(.largeTitle.bold())
    Text("Last sync \(lastSync, style: .relative) ago")
        .font(.subheadline)
        .foregroundStyle(.secondary)
    Text("Read the **terms** and [privacy policy](https://ex.com)")
    Text(longText)
        .lineLimit(2)
        .truncationMode(.tail)
    Text(price, format: .currency(code: "USD"))
    Text("Total: ").bold() + Text("$42").foregroundStyle(.green)
    Label("Downloads", systemImage: "arrow.down.circle")
    Text(verbatim: "Not_localized_key")
}

Code Explained

.font(.largeTitle.bold()) — semantic font + weight
style: .relative — live-updating date
Markdown — bold, links in literals
lineLimit / truncationMode — overflow
format: — FormatStyle in Text

Minimum OS

  • Text Markdown, format:: iOS 15
  • Label: iOS 14

UIKit / React Equivalent

  • UIKit UILabel + NSAttributedString
  • React Native <Text style={…}>, nested <Text> for mixed styles

Accessibility

  • Semantic fonts scale with Dynamic Type automatically
  • Label reads its title to VoiceOver even when only the icon shows

Text Styles

⚠ Common Mistakes

  • Fixed sizes like .font(.system(size: 14)): ignores Dynamic Type
  • Markdown from a variable doesn't render: wrap it in AttributedString(markdown:)
  • Concatenating strings for display when Text(… format:) would localize

✓ Tips & Best Practices

  • Use .monospacedDigit() for counters that shouldn't jiggle
  • Use Text(verbatim:) for user content that shouldn't be localized
  • .textSelection(.enabled) lets users copy text

Quick Summary

  • Text + semantic fonts
  • Markdown and format: built in
  • Label = text + icon
