ScrollView & Lazy Stacks

ScrollView · LazyVStack · LazyHStack · scrollTargetBehavior · scrollPosition · ScrollViewReader

Custom Scrolling

When you need custom layouts instead of List rows, use ScrollView with a LazyVStack or LazyHStack, which create children only when needed. Scroll target behavior adds paging and snapping, scrollPosition reads and sets the visible item, and ScrollViewReader scrolls to an ID on older systems.

Notes

  • Plain VStack in a ScrollView builds everything up front
  • .scrollTargetLayout() marks which children are snap targets
  • .scrollIndicators(.hidden) hides scroll bars
  • .scrollClipDisabled() lets shadows overflow

ScrollView Patterns

ScrollView {
    LazyVStack(spacing: 12, pinnedViews: .sectionHeaders) {
        Section { ForEach(posts) { PostCard($0) } }
        header: { Text("Today").font(.headline) }
    }
    .padding()
}

@State private var current: Card.ID?

ScrollView(.horizontal) {
    LazyHStack(spacing: 16) {
        ForEach(cards) { CardView($0).containerRelativeFrame(.horizontal) }
    }
    .scrollTargetLayout()
}
.scrollTargetBehavior(.viewAligned)            // snap to cards
.scrollPosition(id: $current)                  // read/set visible card
.scrollIndicators(.hidden)

Button("Back to first") { withAnimation { current = cards.first?.id } }

Code Explained

LazyVStack — lazy rows in a ScrollView
pinnedViews: .sectionHeaders — sticky headers
scrollTargetBehavior(.viewAligned) — snapping
scrollPosition(id:) — two-way scroll binding
scrollTargetLayout() — snap targets

Minimum OS

  • ScrollViewReader, lazy stacks: iOS 14
  • scrollPosition(id:), scrollTargetBehavior: iOS 17

UIKit / React Equivalent

  • UIKit UIScrollView / compositional layout with orthogonalScrollingBehavior
  • React Native <ScrollView> / <FlatList horizontal pagingEnabled>

Scroll Modifiers

ModifierEffect
.scrollTargetBehavior(.paging)Full-page paging
.scrollDismissesKeyboard(.interactively)Drag hides keyboard
.defaultScrollAnchor(.bottom)Start at bottom (chat)
.contentMargins(16)Inset content
.scrollBounceBehavior(.basedOnSize)No bounce when it fits

⚠ Common Mistakes

  • VStack with 1,000 items in a ScrollView: slow first render
  • Forgetting .scrollTargetLayout(): snapping does nothing
  • Nesting a vertical List inside a vertical ScrollView

✓ Tips & Best Practices

  • Use .defaultScrollAnchor(.bottom) for chat screens
  • Use ScrollViewReader + proxy.scrollTo(id) if you support iOS 16
  • Use .onScrollGeometryChange (iOS 18) for scroll-driven effects
