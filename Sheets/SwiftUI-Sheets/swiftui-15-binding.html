@Binding

@Binding · $ projection · .constant · passing down · Binding(get:set:)

Two-Way Connections

A @Binding gives a child view read and write access to state owned elsewhere, without owning it. The parent passes $value (the projected binding of its @State), and when the child changes it, the parent's state changes. Controls like Toggle and TextField all take bindings.

Notes

  • Child declares @Binding var x; caller passes $x
  • .constant(value) makes a read-only binding for previews
  • Bindings to properties: $settings.isOn
  • Custom Binding(get:set:) adapts or validates values
  • Swift set: 095 · Property Wrappers

@Binding

struct SettingsView: View {
    @State private var wifiOn = true
    @State private var volume = 0.5

    var body: some View {
        Form {
            SettingRow(title: "Wi-Fi", isOn: $wifiOn)   // pass binding
            VolumeSlider(value: $volume)
            Text(wifiOn ? "Connected" : "Off")
        }
    }
}

struct SettingRow: View {
    let title: String
    @Binding var isOn: Bool                             // doesn't own it
    var body: some View { Toggle(title, isOn: $isOn) }
}

let percent = Binding(                                  // adapter
    get: { Int(volume * 100) },
    set: { volume = Double($0) / 100 })

#Preview { SettingRow(title: "Demo", isOn: .constant(true)) }

Where Bindings Come From

Code Explained

@Binding var isOn — borrowed read/write value
$wifiOn — projected binding from @State
Toggle(isOn: $isOn) — controls take bindings
Binding(get:set:) — computed binding
.constant(true) — fixed binding for previews

Minimum OS

  • @Binding: iOS 13
  • ForEach($items) { $item in } bindings: Xcode 13+

UIKit / React Equivalent

  • UIKit Delegate or closure callbacks to report changes back
  • React Native Passing value + onChange props (lifted state)

⚠ Common Mistakes

  • Declaring @State in the child instead of @Binding: changes don't reach the parent
  • Passing wifiOn instead of $wifiOn: type mismatch
  • Using .constant outside previews: controls appear frozen

✓ Tips & Best Practices

  • Use ForEach($items) { $item in TextField("", text: $item.name) } to edit lists
  • Prefer @Bindable models over many separate bindings
  • Bindings are cheap; pass exactly the piece a child needs

Quick Summary

  • @Binding — borrowed, writable
  • $x creates one from state
  • Binding(get:set:) for adapters
