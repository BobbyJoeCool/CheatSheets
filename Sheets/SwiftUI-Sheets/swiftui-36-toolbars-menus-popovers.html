Toolbars, Menus & Popovers

.toolbar places items in the navigation bar, bottom bar or keyboard accessory using placements. Menu shows a button that opens a list of actions, .contextMenu adds a long-press menu, .popover shows content attached to a view (a sheet on iPhone unless told otherwise), and .inspector adds a trailing side panel.

Notes

  • Placements are semantic: the system positions them per platform
  • ToolbarItemGroup places several items together
  • Menu can nest menus, pickers and dividers
  • .presentationCompactAdaptation(.popover) keeps popovers on iPhone

Toolbar, Menu, Popover

.toolbar {
    ToolbarItem(placement: .topBarLeading) { EditButton() }
    ToolbarItem(placement: .primaryAction) {
        Menu("Sort", systemImage: "arrow.up.arrow.down") {
            Picker("Sort", selection: $sort) {
                Text("Date").tag(Sort.date)
                Text("Title").tag(Sort.title)
            }
            Divider()
            Button("Export…", systemImage: "square.and.arrow.up", action: export)
        }
    }
    ToolbarItemGroup(placement: .bottomBar) {
        Spacer(); Text("\(count) notes").font(.caption); Spacer()
    }
}

Image(systemName: "info.circle")
    .onTapGesture { showTip = true }
    .popover(isPresented: $showTip) {
        Text("Tip text").padding()
            .presentationCompactAdaptation(.popover)
    }

Common Placements

PlacementWhere (iOS)
.topBarLeading / .topBarTrailingNav bar sides
.primaryActionMain action spot
.principalTitle area
.bottomBarBottom toolbar
.keyboardAbove the keyboard
.confirmationAction / .cancellationActionSheet buttons

Code Explained

ToolbarItem(placement:) — position by meaning
Menu — button that opens actions
Picker inside Menu — checkmarked choices
ToolbarItemGroup(.bottomBar) — bottom toolbar
.popover + compact adaptation — bubble on iPhone

Minimum OS

  • .toolbar, Menu: iOS 14
  • .inspector: iOS 17; presentationCompactAdaptation: iOS 16.4

UIKit / React Equivalent

  • UIKit navigationItem.rightBarButtonItems, UIMenu, UIPopoverPresentationController
  • React Navigation headerRight option; menu libraries

Accessibility

  • Icon-only toolbar items need labels: Button("Sort", systemImage:) provides one
  • Context menus must have a visible alternative; long press isn't discoverable

⚠ Common Mistakes

  • Hard-coding .topBarTrailing everywhere: macOS and iPad place things differently
  • Hiding important actions only in a context menu
  • Expecting .popover to show as a bubble on iPhone by default

✓ Tips & Best Practices

  • Use .confirmationAction / .cancellationAction in sheets
  • Use .toolbar(.hidden, for: .tabBar) to hide bars on a screen
  • ControlGroup groups related toolbar buttons
