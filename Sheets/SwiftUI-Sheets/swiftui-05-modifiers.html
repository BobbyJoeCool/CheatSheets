Sheet 05

Modifiers & Order

modifier chains · order matters · .padding · .background · .frame · conditional modifiers

How Modifiers Work

A modifier like .padding() doesn't change a view; it wraps it in a new view. That's why order matters: .padding().background(.blue) colors the padding, while .background(.blue).padding() doesn't. Read a modifier chain from top to bottom as layers added from the inside out.

Notes

  • Each modifier returns a new view type
  • Some modifiers flow down to children (.font, .foregroundStyle)
  • Layout modifiers (padding, frame) change size; others just draw
  • Avoid if around modifiers: it changes view identity

Order Matters

Text("A")
    .padding()                     // 1. add space
    .background(.yellow)           // 2. color includes padding
    .border(.red)                  // 3. border around both

Text("B")
    .background(.yellow)           // 1. color just the text
    .padding()                     // 2. space outside the color
    .border(.red)

VStack {                           // environment flows down
    Text("Title")
    Text("Subtitle")
}
.font(.headline)                   // both Texts get .headline
.foregroundStyle(.blue)

// conditional value, not conditional modifier
Text("Status")
    .opacity(isHidden ? 0 : 1)     // same identity either way

Code Explained

modifier = new wrapping view
padding then background — color fills padding
.font on a container — applies to children
ternary inside modifier — keeps identity stable

Minimum OS

  • Core modifiers: iOS 13
  • foregroundStyle replaces foregroundColor: iOS 15

UIKit / React Equivalent

  • UIKit Setting properties on a view (layer.borderColor, backgroundColor)
  • React Native style={{ padding, backgroundColor }}, but order-free

Common Modifiers

ModifierDoes
.padding(_:)Space around
.frame(width:height:)Propose size
.background(_:)Layer behind
.overlay(_:)Layer in front
.clipShape(.rect(cornerRadius: 8))Clip
.shadow(radius:)Drop shadow

⚠ Common Mistakes

  • .background(...) before .padding() and wondering why the color is tight
  • if flag { view.bold() } else { view }: two identities, broken animations
  • Applying .frame after .background and expecting the background to grow

✓ Tips & Best Practices

  • When layout looks wrong, add .border(.red) between modifiers to see each layer
  • Bundle repeated chains into a custom ViewModifier (Sheet 47)
  • Put modifiers that apply to many children on the container

Quick Summary

  • modifiers wrap views
  • order changes the result
  • some modifiers flow to children
