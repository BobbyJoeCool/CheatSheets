Pickers

Picker · pickerStyle · .segmented · .menu · DatePicker · ColorPicker · .tag

Choosing from Options

Picker selects one value from a list; each option is tagged with the value it represents. Its look comes from pickerStyle: menu, segmented, wheel, inline or navigation link. DatePicker picks dates and times within a range, and ColorPicker opens the system color panel.

Notes

  • Selection type must match the .tag types exactly
  • ForEach over an enum with CaseIterable fills a picker
  • Optional selections need optional tags: .tag(Optional(x))
  • Inside Form, the default style adapts to platform
  • Swift set: 063 · Enums — Basics

Picker, DatePicker, ColorPicker

enum Size: String, CaseIterable, Identifiable {
    case small, medium, large
    var id: Self { self }
}
@State private var size = Size.medium
@State private var due = Date.now
@State private var color = Color.blue

Form {
    Picker("Size", selection: $size) {
        ForEach(Size.allCases) { s in
            Text(s.rawValue.capitalized).tag(s)
        }
    }
    .pickerStyle(.segmented)

    DatePicker("Due", selection: $due,
               in: Date.now..., displayedComponents: [.date, .hourAndMinute])

    ColorPicker("Accent", selection: $color, supportsOpacity: false)
}

Code Explained

Picker(selection:) + .tag — options
CaseIterable enum — easy option list
.pickerStyle(.segmented) — style
DatePicker(in:) — limit the range
displayedComponents — date, time or both

Minimum OS

  • Picker, DatePicker: iOS 13; ColorPicker: iOS 14
  • .pickerStyle(.palette): iOS 17

UIKit / React Equivalent

  • UIKit UISegmentedControl, UIPickerView, UIDatePicker, UIColorWell
  • React Native @react-native-picker/picker, datetimepicker libraries

Accessibility

  • Each option's Text is what VoiceOver reads; use full words
  • Segmented pickers announce "1 of 3" automatically

⚠ Common Mistakes

  • Tag type differs from selection type (e.g. String vs enum): selection never changes
  • Segmented picker with long labels: truncated
  • DatePicker without in: when past dates aren't allowed

✓ Tips & Best Practices

  • Use .datePickerStyle(.graphical) for a calendar
  • Use MultiDatePicker for picking several dates (iOS 16)
  • .labelsHidden() for pickers that sit in custom rows
