Text Input & Focus

TextField · SecureField · TextEditor · @FocusState · onSubmit · keyboardType · textContentType

Typing & Keyboard Focus

TextField edits a String (or a formatted value), SecureField hides passwords, and TextEditor handles multi-line text. @FocusState tracks and moves keyboard focus between fields, and onSubmit reacts to the return key. Keyboard type and content type help the system offer the right keyboard and AutoFill.

Notes

  • TextField(axis: .vertical) grows as the user types
  • format: lets a TextField edit numbers directly
  • .textContentType(.emailAddress) enables AutoFill
  • .scrollDismissesKeyboard(.interactively) on scroll views

Fields & Focus

enum Field { case email, password }
@State private var email = ""
@State private var password = ""
@State private var age = 0
@FocusState private var focus: Field?

Form {
    TextField("Email", text: $email)
        .keyboardType(.emailAddress)
        .textContentType(.emailAddress)
        .textInputAutocapitalization(.never)
        .focused($focus, equals: .email)
        .onSubmit { focus = .password }          // return → next
    SecureField("Password", text: $password)
        .focused($focus, equals: .password)
        .submitLabel(.go)
        .onSubmit(signIn)
    TextField("Age", value: $age, format: .number)
    TextField("Notes", text: $notes, axis: .vertical).lineLimit(3...6)
}
.onAppear { focus = .email }

Code Explained

@FocusState — which field has focus
.focused($focus, equals:) — link a field
.onSubmit — return key action
value:format: — numeric field
axis: .vertical + lineLimit(3...6) — growing field

Minimum OS

  • @FocusState, onSubmit: iOS 15
  • TextField(axis:): iOS 16

UIKit / React Equivalent

  • UIKit UITextField delegates, becomeFirstResponder()
  • React Native <TextInput> with refs, ref.focus(), onSubmitEditing

Accessibility

  • The placeholder is not a label: add Text labels or LabeledContent in custom layouts
  • Use textContentType so password managers and VoiceOver identify fields

Keyboard Modifiers

ModifierEffect
.keyboardType(.decimalPad)Keyboard layout
.textContentType(.oneTimeCode)AutoFill hint
.submitLabel(.next)Return key text
.autocorrectionDisabled()No autocorrect
.textInputAutocapitalization(.never)No auto-caps

⚠ Common Mistakes

  • Using placeholder text as the only label
  • Forgetting .textInputAutocapitalization(.never) on emails and usernames
  • Dismissing the keyboard with UIKit hacks instead of focus = nil

✓ Tips & Best Practices

  • Set focus = nil to dismiss the keyboard
  • Add a toolbar Done button: .toolbar { ToolbarItemGroup(placement: .keyboard) { … } }
  • Validate in onChange(of:) and show errors under the field
