Transitions & Matched Geometry

.transition · .move · .opacity · .asymmetric · matchedGeometryEffect · @Namespace · zoom navigation transition

Insertion & Hero Animations

A transition describes how a view enters and leaves when it's added or removed by an if. Combine built-in transitions or use .asymmetric for different in and out effects. matchedGeometryEffect morphs one view into another across a layout change, and the zoom navigation transition expands a tapped cell into the next screen.

Notes

  • Transitions need an animation (withAnimation around the change)
  • @Namespace creates an ID space for matched geometry
  • Only one view per id should be visible in matched geometry
  • Zoom transition: mark source + destination with the same id

Transitions & Matched Geometry

@State private var showBanner = false
@Namespace private var ns

if showBanner {
    Banner()
        .transition(.move(edge: .top).combined(with: .opacity))
}
Button("Show") { withAnimation { showBanner.toggle() } }

// morph a small badge into a large card
if expanded {
    Card().matchedGeometryEffect(id: "card", in: ns)
} else {
    Badge().matchedGeometryEffect(id: "card", in: ns)
}

// zoom from a grid cell into a detail screen
NavigationLink(value: photo) {
    Thumb(photo).matchedTransitionSource(id: photo.id, in: ns)
}
.navigationDestination(for: Photo.self) { p in
    PhotoDetail(p).navigationTransition(.zoom(sourceID: p.id, in: ns))
}

Code Explained

.transition(.move(edge:)) — enter/exit effect
.combined(with:) — mix transitions
@Namespace + matchedGeometryEffect — morph
matchedTransitionSource — zoom source
.navigationTransition(.zoom) — zoom push

Minimum OS

  • Transitions: iOS 13; matchedGeometryEffect: iOS 14
  • Zoom navigation transition: iOS 18

UIKit / React Equivalent

  • UIKit Custom UIViewControllerAnimatedTransitioning
  • React Native Reanimated layout animations / shared element transitions

Built-in Transitions

TransitionEffect
.opacityFade
.scaleGrow / shrink
.slideSlide in leading, out trailing
.move(edge:)Slide from an edge
.push(from:)Push with fade
.asymmetric(insertion:removal:)Different in/out

⚠ Common Mistakes

  • Toggling the if without withAnimation: transition doesn't play
  • Two views with the same matched id visible at once: glitches
  • Using opacity to hide a view and expecting a transition

✓ Tips & Best Practices

  • Wrap changing content in a container so transitions have a stable parent
  • Use .id(value) + transition to animate content swaps
  • Write custom transitions with the Transition protocol (iOS 17)

Quick Summary
