UIKit in SwiftUI

UIViewRepresentable · UIViewControllerRepresentable · makeUIView · updateUIView · Coordinator

Wrapping UIKit Views

When SwiftUI lacks a control, wrap the UIKit one. UIViewRepresentable (or UIViewControllerRepresentable) creates the UIKit object in makeUIView, updates it from SwiftUI state in updateUIView, and uses a Coordinator object as its delegate to send changes back through bindings.

Notes

  • make… runs once; update… runs on every relevant state change
  • The Coordinator is created before make and lives as long as the view
  • AppKit equivalents: NSViewRepresentable
  • Check if a SwiftUI version exists first (Map, PhotosPicker, VideoPlayer)

UIViewRepresentable

struct RichTextView: UIViewRepresentable {
    @Binding var text: String

    func makeUIView(context: Context) -> UITextView {
        let tv = UITextView()
        tv.delegate = context.coordinator
        return tv
    }
    func updateUIView(_ tv: UITextView, context: Context) {
        if tv.text != text { tv.text = text }        // avoid loops
    }
    func makeCoordinator() -> Coordinator { Coordinator(text: $text) }

    final class Coordinator: NSObject, UITextViewDelegate {
        var text: Binding<String>
        init(text: Binding<String>) { self.text = text }
        func textViewDidChange(_ tv: UITextView) {
            text.wrappedValue = tv.text
        }
    }
}

struct SafariView: UIViewControllerRepresentable {
    let url: URL
    func makeUIViewController(context: Context) -> SFSafariViewController {
        SFSafariViewController(url: url)
    }
    func updateUIViewController(_ vc: SFSafariViewController,
                                context: Context) {}
}

Code Explained

makeUIView — create once
updateUIView — push SwiftUI state in
Coordinator — delegate, sends changes out
Binding in coordinator — write back

Minimum OS

  • Representables: iOS 13
  • sizeThatFits(_:uiView:context:) for sizing: iOS 16

UIKit / React Equivalent

  • UIKit This is the bridge into UIKit itself
  • React Native Native UI components via requireNativeComponent / Fabric

Accessibility

  • UIKit views keep their own accessibility; set it on the UIKit object
  • Make sure Dynamic Type works: use preferred fonts and adjustsFontForContentSizeCategory

Representable Methods

MethodWhen
makeCoordinator()First, once
makeUIView(context:)Once
updateUIView(_:context:)State changes
sizeThatFits(_:uiView:context:)Custom size

⚠ Common Mistakes

  • Setting values unconditionally in updateUIView: cursor jumps, loops
  • Creating the UIKit view inside updateUIView
  • Retaining the parent struct in the coordinator: copy the bindings you need

✓ Tips & Best Practices

  • Use context.transaction.animation to animate UIKit changes
  • Keep representables small; put logic in a model

Quick Summary

  • make once, update often
  • Coordinator = delegate
  • bindings carry changes back
