Images & SF Symbols

Image shows images from the asset catalog or SF Symbols, Apple's library of thousands of icons that scale with text. Images draw at their natural size until you add .resizable() and a content mode. AsyncImage loads remote images with a placeholder. Symbols support rendering modes, variable values and animated symbol effects.

Notes

  • Browse symbols in the free SF Symbols app
  • Symbols size with .font, not .frame
  • .resizable() must come first among image modifiers
  • Decorative images should be hidden from VoiceOver

Images & Symbols

Image("hero")                              // asset catalog
    .resizable()
    .scaledToFill()
    .frame(height: 200)
    .clipped()

Image(systemName: "heart.fill")
    .font(.title)                          // symbols scale with font
    .foregroundStyle(.red)

Image(systemName: "cloud.sun.rain.fill")
    .symbolRenderingMode(.multicolor)

Image(systemName: "bell")
    .symbolEffect(.bounce, value: unread)  // animate on change

AsyncImage(url: user.avatarURL) { image in
    image.resizable().scaledToFit()
} placeholder: { ProgressView() }
.frame(width: 64, height: 64)
.clipShape(.circle)

Code Explained

.resizable() + scaledToFill/Fit — sizing
systemName: — SF Symbol
symbolRenderingMode — mono, hierarchical, multicolor
symbolEffect — animated symbols
AsyncImage — remote image + placeholder

Minimum OS

  • SF Symbols: iOS 13; AsyncImage: iOS 15
  • symbolEffect: iOS 17

UIKit / React Equivalent

  • UIKit UIImageView + UIImage(systemName:)
  • React Native <Image source={{uri}} /> + an icon library

Accessibility

  • Hide decorative images: .accessibilityHidden(true)
  • Give meaningful images a label: Image("x", label: Text("…"))

Rendering Modes

ModeLook
.monochromeOne color
.hierarchicalOne color, layered opacity
.paletteYour own colors
.multicolorSymbol's built-in colors

⚠ Common Mistakes

  • Forgetting .resizable(): the image ignores your frame
  • Sizing symbols with .frame: blurry or misaligned; use .font
  • Using AsyncImage for large scrolling lists: no caching beyond URLCache

✓ Tips & Best Practices

  • Use .imageScale(.large) to nudge symbol size inside text
  • Use Nuke or Kingfisher when you need real image caching
  • Export custom icons as custom SF Symbols to match text weight

Quick Summary

  • Image("asset") / Image(systemName:)
  • .resizable() + content mode
  • AsyncImage for URLs
