Programmatic Navigation

NavigationPath · path binding · push / pop · router · deep links · Hashable routes

Navigating from Code

Bind a NavigationStack to a path and you control navigation with plain data: append to push, remove to pop, set to [] to go to the root. A typed array ([Route]) works when all destinations share one enum; NavigationPath holds mixed types. A small router model makes deep links and restoration easy.

Notes

  • The path is your navigation state: save and restore it
  • NavigationPath is type-erased and can be Codable
  • Deep links: parse a URL into routes, then set the path
  • Keep the router in the environment
  • Swift set: 064 · Enums — Associated Values

Router + Path

enum Route: Hashable {
    case book(Book.ID), author(Author.ID), settings
}

@MainActor @Observable final class Router {
    var path: [Route] = []
    func open(_ r: Route) { path.append(r) }
    func popToRoot() { path.removeAll() }
}

struct RootView: View {
    @State private var router = Router()
    var body: some View {
        NavigationStack(path: $router.path) {
            HomeView()
                .navigationDestination(for: Route.self) { route in
                    switch route {
                    case .book(let id):   BookDetail(id: id)
                    case .author(let id): AuthorView(id: id)
                    case .settings:       SettingsView()
                    }
                }
        }
        .environment(router)
        .onOpenURL { url in router.path = Route.parse(url) }
    }
}

Code Explained

NavigationStack(path:) — bound navigation state
enum Route: Hashable — every destination
path.append / removeAll — push / pop to root
.environment(router) — any view can navigate
.onOpenURL — deep link into the path

Minimum OS

  • NavigationStack(path:), NavigationPath: iOS 16
  • @Observable router: iOS 17

UIKit / React Equivalent

  • UIKit Coordinators pushing view controllers
  • React Navigation navigation.reset({ routes }) + linking config

Path Operations

CodeEffect
path.append(r)Push
path.removeLast()Pop
path.removeLast(path.count)Pop to root
path = [a, b]Jump to a deep stack

⚠ Common Mistakes

  • Using NavigationLink(destination:) and path state together: they don't sync
  • Storing whole model objects in routes: store IDs
  • Separate path state per tab forgotten: tabs share one stack

✓ Tips & Best Practices

  • Encode NavigationPath.codable to restore navigation on relaunch
  • Unit-test URL → [Route] parsing without UI
  • One router per tab, held by the tab's root view

Quick Summary

  • path binding = navigation state
