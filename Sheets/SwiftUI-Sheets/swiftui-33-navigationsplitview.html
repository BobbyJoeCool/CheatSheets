NavigationSplitView

NavigationSplitView · sidebar · content · detail · columnVisibility · iPad and Mac

Split Views

NavigationSplitView builds multi-column layouts for iPad, Mac and visionOS: a sidebar, an optional content column and a detail column. On iPhone it collapses into a single navigation stack automatically. Drive it with selection bindings so the detail column shows whatever is selected.

Notes

  • Two columns: sidebar + detail; three: sidebar + content + detail
  • columnVisibility controls which columns show
  • Selection in a List drives the next column
  • Put a NavigationStack inside detail for deeper pushes

NavigationSplitView

@State private var folder: Folder.ID?
@State private var note: Note.ID?
@State private var visibility = NavigationSplitViewVisibility.all

NavigationSplitView(columnVisibility: $visibility) {
    List(folders, selection: $folder) { f in
        Label(f.name, systemImage: "folder")
    }
    .navigationTitle("Folders")
} content: {
    if let folder {
        List(notes(in: folder), selection: $note) { Text($0.title) }
    } else { Text("Pick a folder") }
} detail: {
    if let note { NoteEditor(id: note) }
    else { ContentUnavailableView("No Note", systemImage: "note.text") }
}
.navigationSplitViewStyle(.balanced)

Code Explained

sidebar / content / detail — three columns
List(selection:) — selection drives next column
columnVisibility — show/hide columns
.balanced / .prominentDetail — column style
collapses to a stack on iPhone

Minimum OS

  • NavigationSplitView: iOS 16 / macOS 13
  • .inspector side panel: iOS 17

UIKit / React Equivalent

  • UIKit UISplitViewController (double/triple column)
  • React Navigation Drawer navigator + custom tablet layout

Visibility Values

ValueShows
.allEvery column
.doubleColumnContent + detail
.detailOnlyDetail only
.automaticSystem decides

⚠ Common Mistakes

  • Using split view for an iPhone-only app: TabView/Stack is simpler
  • Not handling nil selection in detail: blank column
  • Pushing in the sidebar instead of changing selection

✓ Tips & Best Practices

  • Test in iPad portrait, landscape and Slide Over
  • Set column widths with navigationSplitViewColumnWidth
  • Combine with TabView(.sidebarAdaptable) for top-level sections

Quick Summary

  • sidebar → content → detail
  • selection bindings drive columns
  • auto-collapses on iPhone
