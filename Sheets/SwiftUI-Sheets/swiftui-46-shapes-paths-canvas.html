Shapes, Paths & Canvas

Shape · Path · Circle · RoundedRectangle · stroke · fill · Canvas · TimelineView

Drawing

Built-in shapes (Rectangle, RoundedRectangle, Circle, Capsule) can be filled, stroked and trimmed. Write your own Shape by returning a Path for a given rect. Canvas draws many items efficiently in immediate mode, and TimelineView redraws on a schedule for clocks and animations.

Notes

  • Shapes fill their frame by default
  • .trim(from:to:) draws part of a stroke (progress rings)
  • Canvas content isn't individual views: no per-item accessibility
  • Path uses CGPoints in the given rect

Shapes, Paths, Canvas

Circle()
    .trim(from: 0, to: progress)
    .stroke(.green, style: StrokeStyle(lineWidth: 12, lineCap: .round))
    .rotationEffect(.degrees(-90))
    .frame(width: 100, height: 100)

struct Triangle: Shape {
    func path(in r: CGRect) -> Path {
        Path { p in
            p.move(to: CGPoint(x: r.midX, y: r.minY))
            p.addLine(to: CGPoint(x: r.maxX, y: r.maxY))
            p.addLine(to: CGPoint(x: r.minX, y: r.maxY))
            p.closeSubpath()
        }
    }
}
Triangle().fill(.orange.gradient).frame(width: 80, height: 70)

TimelineView(.animation) { tl in
    Canvas { ctx, size in
        let t = tl.date.timeIntervalSinceReferenceDate
        for i in 0..<40 {
            let x = size.width * (Double(i) / 40)
            let y = size.height / 2 + sin(t * 2 + Double(i) / 3) * 30
            ctx.fill(Path(ellipseIn: CGRect(x: x, y: y, width: 6, height: 6)),
                     with: .color(.blue))
        }
    }
}

Code Explained

.trim + .stroke(style:) — progress ring
Shape + path(in:) — custom shape
.fill(.orange.gradient) — quick gradient
Canvas { ctx, size in } — fast drawing
TimelineView(.animation) — per-frame redraw

Minimum OS

  • Shapes, Path: iOS 13
  • Canvas, TimelineView: iOS 15

UIKit / React Equivalent

  • UIKit draw(_:) / CAShapeLayer / Core Graphics
  • React Native react-native-svg / Skia

Accessibility

  • Describe charts and drawings with .accessibilityLabel or .accessibilityRepresentation
  • Canvas is one element: add an accessibilityChildren description if needed

⚠ Common Mistakes

  • Hundreds of individual shape views in a ZStack: use Canvas
  • Forgetting -90° rotation so the ring starts at the top
  • Using .stroke and .fill together on a Shape (iOS 17+ allows chaining; earlier needs overlay)

✓ Tips & Best Practices

  • Use Swift Charts for real data visualization
  • Make custom shapes Animatable via animatableData
  • Use .drawingGroup() to flatten complex vector art into one layer
