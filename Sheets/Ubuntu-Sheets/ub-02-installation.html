Sheet 02

Installing Ubuntu

ISO + bootable USB · desktop installer · Subiquity · LVM · encryption · OpenSSH · dual boot

Description

Download the ISO from ubuntu.com, write it to a USB stick, and boot from it. Desktop has a graphical installer with a live session to test hardware first. Server uses the text-based Subiquity installer, which offers LVM, disk encryption, an OpenSSH server and SSH key import from GitHub or Launchpad.

Notes

  • Verify the ISO checksum before writing it
  • Server installer: tick "Install OpenSSH server"
  • Default server layout: LVM using about half the disk
  • Dual boot: shrink Windows first, disable Fast Startup

⚠ Danger Check

  • Writing the ISO erases the whole USB stick
  • "Erase disk and install" wipes every partition on that drive
  • Check the target disk name (lsblk) before picking it

Make a Bootable USB (Linux/macOS)

# verify download
sha256sum ubuntu-26.04-live-server-amd64.iso
# compare with SHA256SUMS from releases.ubuntu.com

lsblk                                  # find the USB, e.g. /dev/sdb
sudo dd if=ubuntu-26.04-live-server-amd64.iso of=/dev/sdb \
        bs=4M status=progress conv=fsync

# macOS: diskutil list → /dev/disk4
sudo dd if=ubuntu.iso of=/dev/rdisk4 bs=4m
# or use balenaEtcher / Rufus (Windows) / Startup Disk Creator

Code Explained

sha256sum — confirm the ISO isn't corrupted
lsblk — identify the USB by size
of=/dev/sdb — the whole device, not sdb1
conv=fsync — flush before finishing
GUI tools do the same, with safety checks

Other Distros

  • Debian — netinst ISO, text or graphical installer
  • Fedora — Anaconda installer, Fedora Media Writer
  • macOS — Recovery mode reinstall

Prefer / Avoid

  • Avoid skipping LVM on servers · Prefer LVM for easy resizing
  • Avoid password-only SSH from day one · Prefer importing SSH keys in the installer

⚠ Common Mistakes

  • Writing the ISO to a partition (/dev/sdb1) instead of the device
  • Choosing the wrong disk in "erase disk" on multi-drive machines
  • Forgetting the LVM default leaves half the disk unallocated

✓ Tips & Best Practices

  • Grow the root LV later with lvextend -r (sheet 26)
  • Use autoinstall YAML for repeatable installs (sheet 41)
  • Test the live session on desktops before installing

Quick Summary

  • ISO + checksum + USB — install media
  • Subiquity — server installer
  • LVM + OpenSSH — sensible server defaults
  • double-check the target disk
