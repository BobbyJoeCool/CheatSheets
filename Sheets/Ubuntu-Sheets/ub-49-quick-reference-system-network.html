⚠ Common Mistakes

  • netplan apply over SSH without netplan try (29)
  • ufw enable before allowing SSH (33)
  • Untested fstab edits before reboot (25)

✓ Tips & Best Practices

  • systemctl status + journalctl -u first, always
  • Keep console access when touching network, SSH or firewall
  • Snapshot or back up before risky changes
