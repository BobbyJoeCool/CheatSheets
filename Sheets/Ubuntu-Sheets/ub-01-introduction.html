Sheet 01

Introduction & Release Cycle

Canonical · Debian roots · LTS vs interim · YY.MM versions · codenames · ESM · flavors

Description

Ubuntu is a Linux distribution built on Debian and published by Canonical. A new version ships every April and October, numbered YY.MM. April releases in even years are LTS (long-term support) and get years of security updates; the releases in between are interim releases with 9 months of support, used to try new features.

Notes

  • Current LTS: 26.04 "Resolute Raccoon"; previous: 24.04 "Noble Numbat"
  • LTS: 5 years standard, up to 10+ with Ubuntu Pro (ESM)
  • Same packages for desktop and server; the install differs
  • Uses apt/.deb like Debian, plus Snap

Which Ubuntu Am I On?

lsb_release -a
# Distributor ID: Ubuntu
# Description:    Ubuntu 26.04 LTS
# Release:        26.04
# Codename:       resolute

cat /etc/os-release          # same info, scriptable
. /etc/os-release && echo "$VERSION_CODENAME"   # resolute
uname -r                     # running kernel version
hostnamectl                  # OS, kernel, hardware summary
pro status                   # Ubuntu Pro / ESM coverage

Code Explained

lsb_release -a — distro, version, codename
/etc/os-release — KEY=value file for scripts
codename — used in apt sources and docs
uname -r — kernel, separate from Ubuntu version
pro status — support and Ubuntu Pro state

Other Distros

  • Debian — cat /etc/debian_version; stable every ~2 years
  • Fedora/RHEL — cat /etc/redhat-release; RHEL 10-year life
  • macOS — sw_vers

Prefer / Avoid

  • Avoid interim releases on servers · Prefer the current LTS
  • Avoid parsing lsb_release text · Prefer sourcing /etc/os-release

⚠ Common Mistakes

  • Calling 25.10 "the latest" for a server: interim support ends after 9 months
  • Confusing kernel version with Ubuntu version
  • Following old guides blindly: tools and defaults change between LTS releases

✓ Tips & Best Practices

  • Check a guide's Ubuntu version before copying commands
  • Plan LTS-to-LTS upgrades every 2–4 years (sheet 18)
  • Ubuntu Pro is free for personal use on a few machines

Quick Summary

  • YY.MM — April/October releases
  • LTS — even-year April, long support
  • /etc/os-release — version for scripts
  • flavors — same base, different desktops
