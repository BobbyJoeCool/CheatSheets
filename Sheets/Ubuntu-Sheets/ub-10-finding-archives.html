Sheet 10

Finding Files & Archives

find -name -mtime -exec · plocate · which / type · grep -r · tar -czf / -xzf · zip / unzip · zstd

Description

find searches the live filesystem by name, size, age, type or owner and can act on results. plocate answers "where is that file?" instantly from an index. grep -r searches inside files. tar bundles directories into one archive, compressed with gzip, xz or zstd.

Notes

  • plocate index updates daily; sudo updatedb to refresh
  • find options go after the path
  • tar flags: c create, x extract, t list, f file
  • .tar.zst is fast and small; Ubuntu packages use zstd

Search & Archive

find ~ -name "*.pdf" -mtime -7          # PDFs changed in 7 days
find /var/log -size +100M               # big files
find . -type f -name "*.tmp" -delete    # delete matches (careful)
find /srv -user www-data -type d        # dirs owned by www-data
plocate nginx.conf                      # instant, from index
which python3 && type -a python3        # what runs?
grep -rn "listen 443" /etc/nginx/       # search contents

tar -czf site-2026-11-13.tar.gz /srv/site   # create .tar.gz
tar -tzf site-2026-11-13.tar.gz | head      # list
tar -xzf site.tar.gz -C /tmp/restore        # extract to dir
tar --zstd -cf logs.tar.zst /var/log/app    # zstd archive
zip -r photos.zip Pictures/ && unzip -l photos.zip

Code Explained

-mtime -7 — modified less than 7 days ago
-size +100M — bigger than 100 MB
-delete — acts on matches; run without it first
tar -czf — create, gzip, to file
-C dir — extract somewhere else

Other Distros

  • Debian — plocate too; Fedora uses plocate/mlocate
  • macOS — mdfind (Spotlight); BSD find/tar mostly compatible

Prefer / Avoid

  • Avoid find ... -exec rm {} \; · Prefer -delete or -exec ... {} +
  • Avoid tar with absolute paths you'll extract over live files · Prefer -C to a temp dir

find Tests

TestMatches
-name / -inamename (case-insensitive)
-type f / d / lfile / dir / link
-mtime -N / +Nage in days
-size +10Msize
-user / -groupowner
-perm -o+wworld-writable

tar Cheats

CommandDoes
tar -czf a.tgz dircreate gzip
tar -cJf a.txz dircreate xz
tar --zstd -cf a.tar.zst dircreate zstd
tar -tf a.tgzlist
tar -xf a.tgzextract (auto-detects)
--exclude='*.log'skip files

⚠ Common Mistakes

  • Putting -delete before the tests: find . -delete -name x deletes everything
  • Forgetting -f in tar: it tries to use a tape device
  • plocate doesn't find new files until updatedb runs

✓ Tips & Best Practices

  • Install fd-find and ripgrep for faster, friendlier search
  • tar -xf detects compression automatically
  • Add dates to archive names for easy sorting

Quick Summary

  • find — live search + actions
  • plocate — instant indexed lookup
  • grep -r — search contents
  • tar -czf / -xf — archive and extract
