Sheet 13

umask, ACLs & Special Bits

umask · setfacl / getfacl · setuid · setgid on directories · sticky bit · chattr +i

Description

Beyond basic rwx: umask sets default permissions for new files; ACLs grant access to extra users or groups without changing ownership; setgid directories make new files inherit the folder's group (great for shared folders); the sticky bit stops users deleting each other's files; chattr +i makes a file immutable even to root.

Notes

  • Default umask 0002 (user) → files 664, dirs 775
  • ACLs show as + at the end of ls -l modes
  • /tmp uses the sticky bit (drwxrwxrwt)
  • passwd uses setuid to edit /etc/shadow

Shared Folder Done Right

umask                           # 0002
umask 027                       # new files 640, dirs 750 (this shell)

sudo mkdir /srv/shared
sudo chgrp devs /srv/shared
sudo chmod 2775 /srv/shared     # setgid: new files get group devs
ls -ld /srv/shared              # drwxrwsr-x ... devs

sudo setfacl -m u:alice:rwx /srv/reports     # extra user
sudo setfacl -d -m g:devs:rx /srv/reports    # default for new files
getfacl /srv/reports

sudo chmod 1777 /srv/dropbox    # sticky: delete only your own
sudo chattr +i /etc/resolv.conf # immutable
lsattr /etc/resolv.conf         # ----i---------
sudo chattr -i /etc/resolv.conf

Code Explained

umask 027 — remove w for group, all for others
2775 — leading 2 = setgid
setfacl -m u:alice:rwx — add a user ACL entry
-d — default ACL inherited by new files
1777 — leading 1 = sticky bit

Other Distros

  • Debian/Fedora — same tools; Fedora also has SELinux contexts
  • macOS — ACLs via chmod +a, chflags uchg for immutable

Prefer / Avoid

  • Avoid chmod 777 for shared dirs · Prefer setgid + group + umask
  • Avoid setuid scripts · Prefer a sudoers rule

⚠ Common Mistakes

  • Setting setgid but leaving umask 022: group members still can't write
  • Forgetting default ACLs: new files don't get the extra access
  • Leaving chattr +i on and wondering why updates fail

✓ Tips & Best Practices

  • Find setuid files when auditing: find / -perm -4000 -type f 2>/dev/null
  • Set umask for a service with UMask= in its unit file
  • Use ACLs sparingly; groups are easier to reason about

Quick Summary

  • umask — default permissions
  • setgid dir — shared group folders
  • ACLs — extra users/groups
  • sticky / immutable — protect files
