Sheet 44

Ubuntu on WSL

wsl --install -d Ubuntu · WSL 2 · /mnt/c · wsl.conf · systemd in WSL · VS Code Remote · paths

Description

WSL (Windows Subsystem for Linux) runs real Ubuntu inside Windows using a lightweight VM. You get the full Ubuntu userland, apt, and even systemd, with fast access to your Windows files and tools. Keep projects inside the Linux filesystem for speed, and use VS Code's WSL extension to edit them.

Notes

  • WSL 2 is the default (real Linux kernel)
  • Windows drives appear under /mnt/c
  • Linux files from Windows: \\wsl$\Ubuntu
  • systemd is on by default in new Ubuntu WSL installs

PowerShell (Windows) + Ubuntu

# PowerShell (admin)
wsl --install -d Ubuntu-26.04
wsl -l -v                         # distros + WSL version
wsl --update
wsl --shutdown                    # restart the VM

# inside Ubuntu
sudo apt update && sudo apt upgrade
cd ~ && git clone https://github.com/me/app.git   # Linux FS = fast
explorer.exe .                    # open this folder in Windows
code .                            # VS Code (WSL extension)
cat /etc/wsl.conf
# [boot]
# systemd=true
# [automount]
# options = "metadata"

Code Explained

wsl --install -d — install a distro
wsl -l -v — list with versions
wsl --shutdown — apply config changes
~/ projects — much faster than /mnt/c
wsl.conf — per-distro settings

Other Distros

  • Debian, openSUSE, Fedora, Arch — also available on WSL
  • macOS — no WSL; use Multipass, OrbStack, UTM

Prefer / Avoid

  • Avoid working in /mnt/c/... · Prefer the Linux home directory
  • Avoid Windows editors writing Linux files over \\wsl$ heavily · Prefer VS Code WSL mode

WSL Commands

CommandDoes
wsl -l -vlist distros
wsl -d Ubuntustart a distro
wsl --set-default Ubuntudefault distro
wsl --export Ubuntu u.tarbackup
wsl --importrestore/clone
wsl --unregister Ubuntudelete (data gone)

Config Files

FileScope
/etc/wsl.confone distro (systemd, automount, user)
%UserProfile%\.wslconfigall distros (RAM, CPUs, networking)
networkingMode=mirroredshare Windows network
memory=8GBVM memory cap

⚠ Common Mistakes

  • Slow builds because the repo lives on /mnt/c
  • wsl --unregister without an export: everything is deleted
  • Line-ending issues: set git config core.autocrlf input

✓ Tips & Best Practices

  • Use wsl --export before big changes
  • Cap memory in .wslconfig if WSL eats RAM
  • Docker Desktop integrates with WSL 2 distros

Quick Summary

  • wsl --install -d Ubuntu-26.04 — install
  • WSL 2 + systemd — real Ubuntu
  • keep code in ~ — speed
  • VS Code WSL — edit seamlessly
