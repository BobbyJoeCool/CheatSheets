Sheet 31

SSH

ssh user@host · ssh-keygen -t ed25519 · ssh-copy-id · ~/.ssh/config · sshd_config.d/ · password login off · port forwarding

Description

SSH gives you an encrypted shell on remote machines. Log in with keys instead of passwords: generate a key pair, copy the public key to the server, then turn off password logins. A ~/.ssh/config file turns long commands into short aliases. SSH can also forward ports, tunneling a remote service to your laptop.

Notes

  • Server package: openssh-server; service name ssh
  • Put server settings in /etc/ssh/sshd_config.d/*.conf
  • Ubuntu uses socket activation for ssh (ssh.socket)
  • Private key never leaves your machine

⚠ Danger Check

  • Disabling passwords before your key works locks you out
  • Test a second session before closing the first one
  • Run sudo sshd -t before restarting; a bad config stops the server

Keys, Config, Hardening

ssh-keygen -t ed25519 -C "bob@laptop"      # ~/.ssh/id_ed25519(.pub)
ssh-copy-id bob@192.168.1.20               # install public key
ssh bob@192.168.1.20                       # no password prompt now

# ~/.ssh/config
# Host home
#     HostName 192.168.1.20
#     User bob
#     IdentityFile ~/.ssh/id_ed25519
ssh home                                   # short alias

# server: /etc/ssh/sshd_config.d/10-hardening.conf
#   PasswordAuthentication no
#   PermitRootLogin no
#   AllowUsers bob
sudo sshd -t && sudo systemctl restart ssh

ssh -L 8080:localhost:80 home              # local :8080 → server :80
ssh -J jump.example.com bob@10.0.0.5       # via a jump host

Code Explained

ed25519 — modern, short, fast key type
ssh-copy-id — appends to ~/.ssh/authorized_keys
Host blocks — aliases and per-host settings
drop-in .conf — survives package updates
-L — forward a local port through SSH

Other Distros

  • Debian/Fedora — same OpenSSH; Fedora service is sshd
  • macOS — enable Remote Login; same ssh client and ~/.ssh/config

Prefer / Avoid

  • Avoid password SSH on internet-facing hosts · Prefer keys only
  • Avoid editing the main sshd_config · Prefer sshd_config.d/ drop-ins

⚠ Common Mistakes

  • Wrong permissions on ~/.ssh: server silently ignores your key
  • Copying the private key to the server instead of the .pub
  • Restarting ssh with a typo in the config and locking yourself out

✓ Tips & Best Practices

  • Use ssh-agent (or the macOS keychain) so you type the passphrase once
  • Debug logins with ssh -v and journalctl -u ssh
  • Add fail2ban for brute-force protection (sheet 34)

Quick Summary

  • ssh-keygen + ssh-copy-id — key login
  • ~/.ssh/config — aliases
  • PasswordAuthentication no — harden
  • -L / -J — tunnels and jump hosts
