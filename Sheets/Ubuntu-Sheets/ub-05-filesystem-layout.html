Sheet 05

Filesystem Layout

/ · /etc · /home · /var · /usr · /opt · /tmp · /dev · /proc · merged /usr

Description

Linux has a single directory tree starting at /; disks are attached (mounted) somewhere in it. Ubuntu follows the Filesystem Hierarchy Standard: configuration in /etc, user files in /home, changing data and logs in /var, installed software in /usr. Knowing where things live is half of system administration.

Notes

  • Everything is a file, including devices (/dev/sda)
  • /proc and /sys are virtual: kernel info, not disk files
  • Merged /usr: /bin → /usr/bin symlinks
  • Paths are case-sensitive: Docs ≠ docs

Look Around

ls /                         # top-level directories
ls /etc | head               # system-wide config files
ls -l /bin                   # /bin -> usr/bin (merged /usr)
du -sh /var/log              # how big are the logs?
cat /proc/cpuinfo | grep "model name" | head -1
cat /proc/meminfo | head -3
ls /dev/sd* /dev/nvme*       # disks
findmnt /                    # which device is mounted at /
echo $HOME                   # /home/bob
ls -a ~                      # dotfiles: .bashrc, .ssh/

Code Explained

/etc — text config files, edited with sudo
merged /usr — old paths still work via symlinks
/proc/* — live kernel data as files
findmnt — what's mounted where
~ — your home directory

Other Distros

  • Debian/Fedora — same FHS layout, merged /usr too
  • macOS — /Users not /home, /Applications, /Library

Prefer / Avoid

  • Avoid putting your own apps in /usr/bin · Prefer /usr/local or /opt
  • Avoid storing data in /tmp · Prefer /var/lib/<app> or /srv

⚠ Common Mistakes

  • Filling /var with logs or Docker images until services fail
  • Editing files under /usr/lib that get overwritten by updates
  • Assuming /tmp survives a reboot

✓ Tips & Best Practices

  • Override vendor configs in /etc, never in /usr/lib
  • Put a separate disk at /srv or /var/lib/docker for big data
  • Use ncdu / to find what's eating space (sheet 45)

Quick Summary

  • / — one tree; disks mount into it
  • /etc config, /var data, /usr programs
  • /proc, /sys — virtual kernel files
  • /opt, /usr/local — your installs
