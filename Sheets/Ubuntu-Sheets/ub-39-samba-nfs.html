Sheet 39

File Sharing: Samba & NFS

smb.conf shares · smbpasswd -a · access from macOS/Windows · nfs-kernel-server · /etc/exports · exportfs -ra

Description

Share folders on your network with Samba (SMB, the protocol Windows and macOS speak natively) or NFS (fast, simple, best between Linux machines). Samba users need a separate Samba password; NFS trusts client UIDs, so restrict exports to your LAN.

Notes

  • Samba ports: 445/tcp; NFS: 2049/tcp
  • Samba users must exist as Linux users
  • macOS: Finder → Go → Connect to Server → smb://host/share
  • NFS v4 needs only port 2049

/etc/samba/smb.conf (add at end)

[media]
   path = /srv/media
   browseable = yes
   read only = no
   valid users = bob @family
   create mask = 0664
   directory mask = 2775

Samba + NFS Setup

sudo apt install samba
sudo smbpasswd -a bob                     # Samba password for bob
testparm                                  # check smb.conf
sudo systemctl restart smbd
sudo ufw allow from 192.168.1.0/24 to any app Samba

sudo apt install nfs-kernel-server
echo "/srv/media 192.168.1.0/24(rw,sync,no_subtree_check)" \
  | sudo tee -a /etc/exports
sudo exportfs -ra && sudo exportfs -v
# client: sudo mount -t nfs server:/srv/media /mnt/media

Code Explained

[media] — share name clients see
valid users — users and @groups allowed
smbpasswd -a — add Samba credential
testparm — validate config
/etc/exports + exportfs -ra — NFS share

Other Distros

  • Debian — same packages; Fedora — samba, nfs-utils + firewalld + SELinux booleans
  • macOS — File Sharing in System Settings (SMB)

Prefer / Avoid

  • Avoid guest-writable shares · Prefer valid users
  • Avoid NFS exports to * · Prefer your LAN subnet

⚠ Common Mistakes

  • Forgetting smbpasswd -a: Linux password alone doesn't work
  • Linux perms block access even though Samba allows it
  • no_root_squash on NFS: remote root becomes local root

✓ Tips & Best Practices

  • Add vfs objects = catia fruit streams_xattr for Time Machine/macOS
  • Mount NFS in fstab with _netdev,nofail,x-systemd.automount
  • Use smbstatus to see connected clients

Quick Summary

  • Samba — SMB for Windows/macOS
  • smbpasswd -a — Samba users
  • NFS — /etc/exports + exportfs -ra
  • limit both to your LAN
