Sheet 36

Ubuntu Pro & Security Updates

pro attach · ESM · Livepatch · pro status · apt list --upgradable · USNs · CIS / USG

Description

Ubuntu Pro extends security coverage: ESM patches for universe packages and for older LTS releases, Livepatch kernel fixes without rebooting, and compliance tooling (CIS benchmarks, FIPS). It's free for personal use on a handful of machines. Canonical publishes Ubuntu Security Notices (USNs) for every fix.

Notes

  • Free Pro token: ubuntu.com/pro (personal account)
  • Without Pro, universe packages get community fixes only
  • Livepatch covers many, not all, kernel CVEs
  • pro fix CVE-... checks and applies a specific fix

Attach and Use Pro

pro status                              # services and entitlements
sudo pro attach C1aBcDeFgH...  # token from ubuntu.com/pro
pro status                     # esm-apps, esm-infra: enabled
sudo pro enable livepatch
canonical-livepatch status

apt list --upgradable                   # pending updates
pro security-status            # coverage of installed pkgs
sudo pro fix CVE-2024-6387     # check/fix one CVE

sudo pro enable usg                     # Ubuntu Security Guide
sudo apt install usg && sudo usg audit cis_level1_server
sudo pro detach                         # remove from Pro

Code Explained

pro attach — link machine to your subscription
esm-infra / esm-apps — main vs universe coverage
Livepatch — kernel fixes without reboot
pro fix CVE — targeted check and patch
USG — CIS audit and hardening

Other Distros

  • Debian — LTS/ELTS via Debian LTS and Freexian
  • RHEL — subscription + kpatch; Fedora — short life, no ESM
  • macOS — Rapid Security Responses

Prefer / Avoid

  • Avoid running old LTS releases without ESM · Prefer Pro or upgrading
  • Avoid ignoring USNs for internet-facing services · Prefer watching them

⚠ Common Mistakes

  • Assuming unattended-upgrades patches universe without ESM Apps
  • Treating Livepatch as a reason never to reboot
  • Sharing a Pro token publicly (scripts, repos)

✓ Tips & Best Practices

  • Attach your home server and laptop to the free personal Pro tier
  • Still reboot during maintenance windows to load new kernels fully
  • Use pro fix during incident response for named CVEs

Quick Summary

  • free for personal use
