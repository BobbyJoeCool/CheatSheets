Sheet 12

sudo & Root

sudo · sudo -i · sudo group · visudo · /etc/sudoers.d/ · sudo-rs · locked root

Description

Ubuntu locks the root account and gives admins sudo, which runs one command as root after you type *your* password, and logs it. Members of the sudo group get full access. Fine-grained rules go in drop-in files under /etc/sudoers.d/, always edited with visudo, which checks syntax before saving. Ubuntu 25.10+ uses sudo-rs, a Rust rewrite with the same commands.

Notes

  • Password is cached ~15 minutes per terminal
  • sudo -i = root login shell; sudo -s = root shell
  • Every sudo use is logged (journalctl -t sudo)
  • Classic sudo is still available as sudo.ws

⚠ Danger Check

  • A syntax error in sudoers can lock everyone out of sudo
  • Always use visudo; keep a second root shell open while editing
  • NOPASSWD: ALL turns any compromise of that user into root

Using and Configuring sudo

sudo apt update                       # one command as root
sudo -i                               # root shell (exit to leave)
sudo -u postgres psql                 # run as another user
sudo -l                               # what am I allowed to do?

sudo visudo -f /etc/sudoers.d/deploy  # create a drop-in safely
# deploy may restart one service without a password:
#   deploy ALL=(root) NOPASSWD: /usr/bin/systemctl restart myapp
sudo visudo -c                        # check all sudoers files
sudo chmod 440 /etc/sudoers.d/deploy

journalctl -t sudo --since today      # audit sudo use

Code Explained

sudo -u user — run as someone other than root
sudo -l — list your allowed commands
visudo -f — edit a drop-in with syntax check
rule format — who where=(as_whom) what
visudo -c — validate before logging out

Other Distros

  • Debian — sudo optional; root password may be set
  • Fedora/RHEL — wheel group instead of sudo
  • macOS — admin users can sudo; same sudoers syntax

Prefer / Avoid

  • Avoid sudo su - · Prefer sudo -i
  • Avoid editing /etc/sudoers directly · Prefer /etc/sudoers.d/ + visudo

⚠ Common Mistakes

  • sudo echo x > /etc/file fails: the redirect runs as you; use | sudo tee
  • Drop-in filenames with . or ~ are ignored by sudo
  • Granting NOPASSWD on editors or shells: instant root escape

✓ Tips & Best Practices

  • Keep a root shell open while changing sudoers or SSH
  • Use echo text | sudo tee -a /etc/file to append as root
  • Prefer narrow, full-path command rules for automation

Quick Summary

  • sudo — one command as root, logged
  • sudo -i — root shell when needed
  • /etc/sudoers.d/ + visudo — safe rules
  • sudo-rs — default from 25.10
