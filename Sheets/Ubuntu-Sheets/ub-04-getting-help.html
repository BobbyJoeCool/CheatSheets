Sheet 04

Getting Help

man · --help · apropos · tldr · info · /usr/share/doc · Ask Ubuntu

Description

Almost every command documents itself. man pages are the full reference, --help gives a quick summary, and tldr shows the handful of examples you usually need. When you don't know the command name, apropos searches man page descriptions. Ubuntu-specific questions are well covered on Ask Ubuntu and Ubuntu Discourse.

Notes

  • Minimized server images strip man pages: unminimize restores them
  • Man sections: 1 commands, 5 file formats, 8 admin commands
  • man 5 crontab ≠ man crontab
  • Package docs live in /usr/share/doc/<pkg>/

Finding Answers

man ls                          # full manual; / to search, q to quit
man 5 sshd_config               # section 5: config file format
ls --help | less                # quick option summary
apropos "disk usage"            # du (1), df (1), ...
whatis rsync                    # one-line description
type ll                         # alias? builtin? file?
help cd                         # bash builtins use `help`
sudo apt install tldr && tldr tar    # example-first cheat sheet
ls /usr/share/doc/nginx/        # package docs and changelogs

Code Explained

man <cmd> — the reference; /word searches
man 5 <file> — config file docs
apropos — search by keyword
type — what a name actually runs
help — docs for shell builtins

Other Distros

  • Debian/Fedora — identical man/apropos/tldr
  • macOS — BSD man pages; options differ from GNU

Prefer / Avoid

  • Avoid copying commands you don't understand · Prefer man / tldr first
  • Avoid googling flags for builtins · Prefer help <builtin>

⚠ Common Mistakes

  • man cd finds nothing: it's a shell builtin; use help cd
  • Trusting a 2014 forum answer for a 2026 release
  • Ignoring --help because the man page is long

✓ Tips & Best Practices

  • Run unminimize on minimized servers you log into
  • Use man -k regex (same as apropos) with patterns
  • Read /usr/share/doc/<pkg>/README.Debian for Ubuntu-specific notes

Quick Summary

  • man — full reference
  • --help / tldr — quick usage
  • apropos — find the command
  • help — shell builtins
