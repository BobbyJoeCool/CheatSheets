Sheet 11

Users & Groups

adduser · usermod -aG · deluser · passwd · groups / id · /etc/passwd · /etc/group

Description

Every process runs as a user, and access is granted through groups. Ubuntu's adduser is the friendly way to create users (it makes the home directory and asks for a password); usermod -aG adds a user to more groups. Service accounts like www-data have no login shell and exist only to run software.

Notes

  • Group changes apply at next login (or newgrp)
  • Human users start at UID 1000
  • /etc/shadow holds password hashes (root only)
  • useradd is the low-level tool; prefer adduser

Manage Users

sudo adduser alice                    # interactive: password, name
sudo usermod -aG sudo,docker alice    # append to groups
groups alice                          # alice : alice sudo docker
id alice                              # uid=1001(alice) gid=1001 ...
sudo passwd alice                     # set/reset password
sudo passwd -l alice                  # lock account
sudo chage -l alice                   # password aging info
sudo addgroup devs && sudo adduser alice devs
sudo adduser --system --group --no-create-home myapp   # service user
sudo deluser --remove-home bob        # delete user + home
who && last -n 5                      # logged in now / recent logins

Code Explained

adduser — creates user, group, home, prompts
usermod -aG — append; without -a replaces groups
passwd -l — lock without deleting
--system — no-login account for a service
last — login history

Other Distros

  • Debian — same adduser; Fedora — useradd + passwd, wheel group
  • macOS — sysadminctl -addUser, System Settings → Users

Prefer / Avoid

  • Avoid usermod -G without -a · Prefer usermod -aG
  • Avoid running services as your user · Prefer a --system user

⚠ Common Mistakes

  • usermod -G docker bob drops bob from sudo; always use -a
  • Expecting new group access in the same shell session
  • Adding users to docker without realizing it's root-equivalent

✓ Tips & Best Practices

  • getent passwd alice works with LDAP too
  • Use sudo -iu alice to test as another user
  • Remove ex-users promptly and lock shared accounts

Quick Summary

  • adduser — create users
  • usermod -aG — add to groups
  • id / groups — check membership
  • --system — service accounts
