Sheet 38

Docker on Ubuntu

Docker apt repo vs docker.io vs snap · docker group · Compose plugin · enable on boot · UFW caveat

Description

Install Docker from Docker's official apt repository for the newest Engine and the Compose plugin; Ubuntu's docker.io package and the snap also work but lag behind or behave differently. Add yourself to the docker group to skip sudo, and remember that published container ports bypass UFW by default.

Notes

  • Three options: Docker repo, docker.io (Ubuntu), snap
  • docker group membership = root-equivalent
  • Compose v2: docker compose (space, not hyphen)
  • See the Docker set for images, volumes, Compose files

Install from Docker's Repo

sudo apt remove docker.io docker-compose podman-docker 2>/dev/null
# add key + repo (see sheet 15 for the pattern)
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
     -o /etc/apt/keyrings/docker.asc
# ... add docker.list with signed-by, then:
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io \
     docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker $USER && newgrp docker
docker run --rm hello-world
docker compose version

# publish only on localhost; let Nginx/UFW face the internet
docker run -d -p 127.0.0.1:8080:80 nginx

Code Explained

remove old packages — avoid conflicts
Docker repo — current Engine + plugins
enable --now — start at boot
usermod -aG docker + newgrp — no sudo needed
-p 127.0.0.1:8080:80 — not exposed publicly

Other Distros

  • Debian — same Docker repo steps (debian path)
  • Fedora — Docker repo or Podman (default, daemonless)
  • macOS — Docker Desktop, OrbStack or Colima

Prefer / Avoid

  • Avoid -p 8080:80 on public servers · Prefer 127.0.0.1: + reverse proxy
  • Avoid mixing snap and apt Docker · Prefer one install method

⚠ Common Mistakes

  • Expecting UFW to block -p 0.0.0.0:5432:5432: it won't
  • Filling /var with images; prune with docker system prune
  • Unbounded container logs eating the disk

✓ Tips & Best Practices

  • Set default log rotation in /etc/docker/daemon.json
  • Move /var/lib/docker to a big disk with data-root
  • Use rootless Docker or Podman for shared machines

Quick Summary

  • Docker apt repo — recommended install
  • docker group — convenience, root-equivalent
  • docker compose — v2 plugin
  • bind ports to 127.0.0.1 — UFW won't save you
