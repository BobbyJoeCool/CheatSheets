Sheet 42

GNOME Desktop & Settings

GNOME Shell · gsettings · dconf · extensions · Wayland vs X11 · shortcuts · .desktop launchers

Description

Ubuntu Desktop runs GNOME with Ubuntu's own touches (dock, app indicators). Most settings live in dconf, which you can script with gsettings. Extensions add features like tiling or system monitors. Ubuntu uses Wayland by default; X11 sessions remain available for old apps and some remote-desktop tools.

Notes

  • Super key opens Activities
  • echo $XDG_SESSION_TYPE → wayland or x11
  • App launchers are .desktop files
  • Tweaks app: sudo apt install gnome-tweaks

Script Your Desktop

gsettings get org.gnome.desktop.interface color-scheme
gsettings set org.gnome.desktop.interface \
    color-scheme 'prefer-dark'
gsettings set org.gnome.shell.extensions.dash-to-dock \
    dock-position 'BOTTOM'
gsettings set org.gnome.desktop.peripherals.touchpad \
    tap-to-click true
gsettings list-recursively org.gnome.desktop.wm.keybindings | head

dconf dump /org/gnome/ > gnome-settings.ini     # back up
dconf load /org/gnome/ < gnome-settings.ini     # restore

sudo apt install gnome-shell-extension-manager
gnome-extensions list --enabled
echo $XDG_SESSION_TYPE                          # wayland

Code Explained

gsettings get/set schema key — read/write a setting
color-scheme 'prefer-dark' — dark mode
dconf dump / load — back up all GNOME settings
Extension Manager — browse and install extensions
XDG_SESSION_TYPE — Wayland or X11

Other Distros

  • Fedora — vanilla GNOME, same gsettings
  • Kubuntu — KDE Plasma, settings via kwriteconfig6
  • macOS — defaults write is the gsettings equivalent

Prefer / Avoid

  • Avoid editing dconf binary files · Prefer gsettings / dconf load
  • Avoid many extensions after upgrades · Prefer a few maintained ones

⚠ Common Mistakes

  • Extensions breaking after a GNOME version bump: disable and update
  • Screen sharing tools that only support X11 failing on Wayland
  • Hand-copying .config dirs between versions instead of dconf dump

✓ Tips & Best Practices

  • Keep dconf dump output in your dotfiles repo
  • Install gnome-tweaks for fonts and title-bar buttons
  • Pick "Ubuntu on Xorg" at the login gear icon if an app needs X11

Quick Summary

  • GNOME — Ubuntu's desktop
  • gsettings — script settings
  • dconf dump/load — back up / restore
  • Wayland default; X11 optional
