Sheet 16

dpkg & .deb Files

dpkg -i · apt install ./file.deb · dpkg -l / -L / -S · apt-mark hold · apt --fix-broken install

Description

dpkg is the low-level tool that actually installs .deb packages; apt sits on top and handles downloads and dependencies. Use dpkg to query what's installed and which package owns a file. To install a downloaded .deb, prefer apt install ./file.deb so dependencies are resolved.

Notes

  • dpkg -i doesn't fetch dependencies
  • ./ is required so apt treats it as a file
  • apt-mark hold freezes a package version
  • Interrupted installs: sudo dpkg --configure -a

⚠ Danger Check

  • Forcing installs (--force-all) can leave a broken package database
  • Holding security-critical packages leaves them unpatched
  • Removing packages marked essential (libc, apt) breaks the system

Install, Query, Repair

sudo apt install ./code_1.95_amd64.deb   # resolves deps
sudo dpkg -i some-tool.deb               # low-level, no deps
sudo apt --fix-broken install            # pull missing deps

dpkg -l | grep nginx                     # installed? (ii = yes)
dpkg -L nginx-common | head              # files from a package
dpkg -S /usr/sbin/nginx                  # which package owns it
dpkg-deb -c tool.deb                     # list a .deb's contents
dpkg -s nginx | grep Version

sudo apt-mark hold linux-image-generic   # freeze version
apt-mark showhold
sudo apt-mark unhold linux-image-generic

sudo dpkg --configure -a                 # finish interrupted setup

Code Explained

apt install ./x.deb — the right way to install files
--fix-broken install — repair after dpkg -i
dpkg -l — ii means installed fine
dpkg -S path — reverse lookup
apt-mark hold — skip in upgrades

Other Distros

  • Debian — identical
  • Fedora — rpm -qa, rpm -ql, rpm -qf, dnf versionlock
  • macOS — .pkg with installer -pkg; pkgutil --files

Prefer / Avoid

  • Avoid dpkg -i then guessing deps · Prefer apt install ./file.deb
  • Avoid permanent holds · Prefer documented, temporary holds

⚠ Common Mistakes

  • Leaving rc packages: clear with sudo apt purge ~c (apt patterns)
  • Killing apt mid-install, then ignoring dpkg --configure -a
  • Holding a package and forgetting it for years

✓ Tips & Best Practices

  • apt purge '~c' removes all leftover configs
  • Check .deb contents with dpkg-deb -c before installing
  • debsums verifies installed files against package checksums

Quick Summary

  • apt install ./file.deb — install with deps
  • dpkg -l / -L / -S — query
  • apt-mark hold — freeze versions
  • dpkg --configure -a — repair
