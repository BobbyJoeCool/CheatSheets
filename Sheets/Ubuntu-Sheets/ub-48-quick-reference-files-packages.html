⚠ Common Mistakes

  • usermod -G without -a removes other groups (11)
  • chmod -R 777 as a fix (09)
  • rm -rf with an unchecked variable (07)

✓ Tips & Best Practices

  • Read man / tldr before running unfamiliar flags
  • Use sudoedit and visudo for system files
  • Prefer apt repos over random .deb downloads
