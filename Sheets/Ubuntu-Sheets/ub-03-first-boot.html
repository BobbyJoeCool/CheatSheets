Sheet 03

First Boot Checklist

apt update && apt upgrade · hostnamectl · timedatectl · locale · create a user · enable SSH · os-release

Description

Right after installing, bring the system up to date, set its name, time zone and locale, make sure you have a non-root user with sudo, and confirm SSH works with a key. Doing this first avoids odd problems later, like wrong timestamps in logs or a server you can only reach from its console.

Notes

  • apt update refreshes lists; apt upgrade installs updates
  • Root is locked by default; your user uses sudo
  • Time sync is on by default; check it once
  • Reboot if /var/run/reboot-required exists

First 10 Minutes

sudo apt update && sudo apt full-upgrade -y
sudo hostnamectl set-hostname homeserver
sudo timedatectl set-timezone America/Chicago
timedatectl                              # NTP synchronized: yes
sudo localectl set-locale LANG=en_US.UTF-8
sudo adduser bob && sudo usermod -aG sudo bob
sudo apt install -y openssh-server
systemctl status ssh                     # active (running)
# from your laptop:
ssh-copy-id bob@homeserver.local
ls /var/run/reboot-required && sudo reboot

Code Explained

full-upgrade — also handles changed dependencies
hostnamectl set-hostname — permanent name
timedatectl set-timezone — local time for logs/cron
usermod -aG sudo — add to the sudo group
ssh-copy-id — install your public key

Other Distros

  • Debian — same commands; root may be enabled if you set a password
  • Fedora — sudo dnf upgrade, user in wheel group
  • macOS — softwareupdate -ia, scutil --set HostName

Prefer / Avoid

  • Avoid working as root · Prefer a sudo user
  • Avoid leaving updates for later · Prefer patching on day one

⚠ Common Mistakes

  • Changing the hostname without updating /etc/hosts (sudo warns "unable to resolve host")
  • Leaving the time zone as UTC and misreading cron schedules
  • Closing the console before confirming SSH key login works

✓ Tips & Best Practices

  • Use ip -br a for a one-line-per-interface view
  • Set up unattended-upgrades before you forget (sheet 18)
  • Write down what you changed; future you will thank you

Quick Summary

  • apt update && apt full-upgrade — patch
  • hostnamectl / timedatectl — identity and time
  • sudo user + SSH key — safe access
  • reboot if required
