Sheet 08

Viewing & Editing Text

cat · less · head / tail -f · nano · vim basics · sudoedit · diff

Description

Linux configuration is plain text, so reading and editing files is a core skill. less pages through big files, tail -f follows logs live, nano is the friendly editor installed everywhere, and vim is worth knowing at least well enough to save and quit. Use sudoedit to edit system files safely.

Notes

  • nano is the default EDITOR on Ubuntu
  • sudo update-alternatives --config editor changes it
  • sudoedit edits a temp copy as you, then installs it
  • less +F = follow mode like tail -f

Read, Follow, Edit

cat /etc/hostname                    # small files
less /var/log/syslog                 # page; /search, q quit
head -n 20 access.log                # first 20 lines
tail -n 50 access.log                # last 50 lines
tail -f /var/log/nginx/error.log     # follow live (Ctrl+C)
grep -n "error" app.log | less       # search with line numbers
nano ~/.bashrc                       # Ctrl+O save, Ctrl+X exit
sudoedit /etc/ssh/sshd_config        # safe root edit
vim notes.md                         # i insert, Esc, :wq save+quit
diff -u nginx.conf nginx.conf.bak    # what changed?

Code Explained

less — doesn't load the whole file
tail -f — watch new lines appear
nano — shortcuts shown at the bottom
sudoedit — your editor settings, root file
diff -u — unified diff, like git

Other Distros

  • Debian — same; vi may be vim-tiny
  • Fedora — vi default EDITOR; nano installed
  • macOS — nano is a pico alias in recent versions

Prefer / Avoid

  • Avoid sudo nano habitually · Prefer sudoedit
  • Avoid cat bigfile · Prefer less or head

⚠ Common Mistakes

  • Getting stuck in vim: press Esc then type :q!
  • Editing a config without a backup: sudo cp file file.bak first
  • tail -f on a rotated log stops showing lines; use tail -F

✓ Tips & Best Practices

  • Validate configs before restarting: nginx -t, sshd -t, visudo -c
  • Use journalctl -f for systemd services (sheet 22)
  • Set export EDITOR=nano (or vim) in ~/.bashrc

Quick Summary

  • less / head / tail — read
  • tail -F — follow logs
  • nano / vim — edit
  • sudoedit — safe system edits
