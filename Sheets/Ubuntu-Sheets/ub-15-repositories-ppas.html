Sheet 15

Repositories & PPAs

main / restricted / universe / multiverse · deb822 ubuntu.sources · add-apt-repository · signed-by · vendor repos

Description

apt downloads from repositories listed in source files. Ubuntu's archive has four components: main and restricted (supported by Canonical), universe and multiverse (community, non-free). Since 24.04, sources use the deb822 format in /etc/apt/sources.list.d/ubuntu.sources. Add third-party software with a PPA or a vendor repo pinned to its own signing key.

Notes

  • Old one-line sources.list format still works
  • Each repo should be tied to one key via Signed-By
  • apt-key is deprecated and removed in newer releases
  • PPAs are built by individuals; trust carefully

/etc/apt/sources.list.d/ubuntu.sources

Types: deb
URIs: http://archive.ubuntu.com/ubuntu/
Suites: resolute resolute-updates resolute-backports
Components: main restricted universe multiverse
Signed-By: /usr/share/keyrings/ubuntu-archive-keyring.gpg

Add a PPA and a Vendor Repo

sudo add-apt-repository ppa:deadsnakes/ppa     # extra Pythons
sudo add-apt-repository --remove ppa:deadsnakes/ppa

# vendor repo with its own key (example: Docker)
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
     -o /etc/apt/keyrings/docker.asc
. /etc/os-release
echo "deb [signed-by=/etc/apt/keyrings/docker.asc] \
https://download.docker.com/linux/ubuntu $VERSION_CODENAME stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt update

Code Explained

Suites — release + -updates / -backports
Components — which parts of the archive
Signed-By — only this key may sign this repo
add-apt-repository ppa: — adds source + key
$VERSION_CODENAME — matches your release

Other Distros

  • Debian — debian.sources, components main/contrib/non-free
  • Fedora — .repo files in /etc/yum.repos.d/, COPR ≈ PPA
  • macOS — brew tap user/repo

Prefer / Avoid

  • Avoid apt-key add · Prefer a keyring file + signed-by
  • Avoid piping install scripts to bash · Prefer a repo you can inspect

⚠ Common Mistakes

  • Adding a repo for another release codename: broken dependencies
  • Leaving dead PPAs that break apt update after upgrades
  • Enabling -proposed on a production machine

✓ Tips & Best Practices

  • Run ppa-purge ppa:x/y to downgrade back to Ubuntu's versions
  • Prefer official vendor repos for Docker, Node, PostgreSQL
  • List all sources: grep -r ^ /etc/apt/sources.list.d/

Quick Summary

  • components — main, restricted, universe, multiverse
  • deb822 .sources — 24.04+ format
  • PPA — add-apt-repository ppa:...
  • signed-by — one key per repo
