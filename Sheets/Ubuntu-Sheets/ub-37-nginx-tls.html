Sheet 37

Nginx & HTTPS

apt install nginx · sites-available / sites-enabled · server blocks · proxy_pass · nginx -t · Certbot · Apache

Description

Nginx is the usual web server and reverse proxy on Ubuntu: it serves static files and forwards requests to apps on local ports (FastAPI, Node, Docker containers). Each site is a server block in sites-available, enabled by a symlink. Certbot gets free Let's Encrypt certificates and renews them automatically.

Notes

  • Config test before reload: sudo nginx -t
  • reload applies config without dropping connections
  • Certbot renews via a systemd timer
  • Apache: a2ensite, a2enmod play the same roles

/etc/nginx/sites-available/todo

server {
    listen 80;
    server_name todo.example.com;

    location /static/ {
        alias /srv/todo/static/;
        expires 7d;
    }
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Enable + HTTPS

sudo ln -s /etc/nginx/sites-available/todo /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d todo.example.com      # cert + HTTPS redirect
sudo certbot renew --dry-run

Code Explained

server_name — which hostname this block serves
location /static/ + alias — files from disk
proxy_pass — forward to the app
X-Forwarded-* — tell the app the real client/scheme
certbot --nginx — edits the block for TLS

Other Distros

  • Debian — identical layout
  • Fedora/RHEL — single /etc/nginx/conf.d/*.conf, SELinux booleans for proxying
  • macOS — brew install nginx, /opt/homebrew/etc/nginx/

Prefer / Avoid

  • Avoid editing nginx.conf for each site · Prefer one file per site
  • Avoid exposing app ports publicly · Prefer apps on 127.0.0.1 behind Nginx

⚠ Common Mistakes

  • Forgetting the trailing slash rules in alias and proxy_pass
  • Leaving the default site enabled and catching all hostnames
  • Port 80 blocked by UFW: Certbot's HTTP challenge fails

✓ Tips & Best Practices

  • sudo ufw allow "Nginx Full" opens 80 and 443
  • Use Caddy if you want automatic HTTPS with less config
  • Read /var/log/nginx/error.log first when you see 502

Quick Summary

  • server block per site — sites-available + symlink
  • proxy_pass — reverse proxy to apps
  • nginx -t → reload — safe changes
  • Certbot — free HTTPS, auto-renew
