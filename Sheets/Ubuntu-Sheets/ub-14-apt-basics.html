Sheet 14

apt Basics

apt update · install · remove / purge · autoremove · search / show · list --installed · apt vs apt-get

Description

apt installs and updates software from Ubuntu's repositories, resolving dependencies for you. Always run apt update first to refresh the package lists. Ubuntu 25.04+ ships apt 3, with clearer colored output and a solver that explains conflicts; the commands are the same.

Notes

  • apt = interactive; apt-get = stable output for scripts
  • remove keeps config files; purge deletes them
  • Package lists live in /var/lib/apt/lists/
  • Downloaded .debs cache in /var/cache/apt/archives/

Everyday apt

sudo apt update                       # refresh lists
apt list --upgradable                 # what would change
sudo apt upgrade                      # install updates
sudo apt install nginx htop           # install (+ deps)
sudo apt install --no-install-recommends curl
apt search "image viewer"             # find packages
apt show nginx                        # version, deps, description
apt policy nginx                      # installed vs candidate, source
sudo apt remove nginx                 # keep /etc/nginx
sudo apt purge nginx                  # remove config too
sudo apt autoremove --purge           # unused dependencies
sudo apt clean                        # empty the download cache
apt list --installed | wc -l

Code Explained

update — refresh, doesn't install anything
upgrade — newer versions of installed packages
--no-install-recommends — skip optional extras
apt policy — which repo a version comes from
autoremove — drop orphaned dependencies

Other Distros

  • Debian — identical apt
  • Fedora/RHEL — dnf install/remove/search/info
  • macOS — brew install/uninstall/search/info

Prefer / Avoid

  • Avoid apt in shell scripts · Prefer apt-get -y (stable output)
  • Avoid downloading random .debs · Prefer repos and PPAs you trust

⚠ Common Mistakes

  • Installing without apt update on a new box: 404 errors for old package versions
  • Answering "Y" without reading what full-upgrade will remove
  • Running two apt commands at once: "Could not get lock"

✓ Tips & Best Practices

  • apt-mark showmanual lists what you installed on purpose
  • apt changelog <pkg> shows what changed
  • Wait for unattended-upgrades to finish instead of killing its lock

Quick Summary

  • apt update → apt upgrade — keep current
  • install / remove / purge — manage packages
  • search / show / policy — investigate
  • apt-get — for scripts
