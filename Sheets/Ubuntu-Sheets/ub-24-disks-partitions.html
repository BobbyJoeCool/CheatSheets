Sheet 24

Disks & Partitions

lsblk · fdisk -l · parted · GPT vs MBR · /dev/sda vs /dev/nvme0n1 · blkid · wipefs

Description

Before you can store data on a new disk you identify it, partition it, and create a filesystem on it (sheet 25). lsblk shows disks and partitions as a tree; parted or fdisk edits partition tables. Use GPT for modern systems. Device names depend on the bus: sda for SATA/USB, nvme0n1 for NVMe.

Notes

  • NVMe partitions add p: nvme0n1p1
  • Names can change between boots; mount by UUID
  • GPT: up to 128 partitions, > 2 TB disks
  • GUI option: GNOME Disks or GParted

⚠ Danger Check

  • Partitioning the wrong disk destroys its data instantly
  • wipefs -a and dd to a device have no confirmation
  • Confirm the disk by size and model with lsblk -o +MODEL,SERIAL first

Partition a New Disk

lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS,MODEL
# sdb   4T disk              WDC WD40EFRX
sudo fdisk -l /dev/sdb               # details + partition table
sudo parted /dev/sdb --script \
     mklabel gpt \
     mkpart data ext4 1MiB 100%      # one partition, whole disk
lsblk /dev/sdb                       # sdb1 now exists
sudo blkid /dev/sdb1                 # UUID (after mkfs)
sudo wipefs /dev/sdb                 # list signatures (no -a = safe)
sudo smartctl -H /dev/sdb            # disk health (smartmontools)

Code Explained

lsblk -o ... MODEL — match the physical disk
mklabel gpt — new GPT partition table
mkpart ... 1MiB 100% — aligned, full-size partition
blkid — UUIDs and filesystem types
smartctl -H — SMART health check

Other Distros

  • Debian/Fedora — same tools; Fedora defaults to Btrfs
  • macOS — diskutil list, diskutil partitionDisk

Prefer / Avoid

  • Avoid MBR on new disks · Prefer GPT
  • Avoid relying on /dev/sdX names · Prefer UUIDs or /dev/disk/by-id/

⚠ Common Mistakes

  • Formatting /dev/sdb (whole disk) when you meant /dev/sdb1
  • Unaligned partitions (start at 1MiB to be safe)
  • Assuming sdb is the same disk after adding hardware

✓ Tips & Best Practices

  • Use /dev/disk/by-id/ paths in scripts and ZFS
  • Run sudo partprobe if the kernel doesn't see new partitions
  • Label partitions so lsblk output is self-explanatory

Quick Summary

  • lsblk — see disks
  • parted mklabel gpt + mkpart — partition
  • blkid — UUIDs
  • triple-check the device name
