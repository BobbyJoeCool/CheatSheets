Sheet 40

VMs & System Containers

Multipass · LXD (lxc launch) · KVM/QEMU · virt-manager · kvm-ok · when to use which

Description

Ubuntu has several ways to run more Ubuntu. Multipass spins up Ubuntu VMs in one command, great for testing. LXD runs system containers (full OS, shared kernel, very light) and VMs, with snapshots and networking built in. KVM/QEMU with libvirt and virt-manager runs any OS, including Windows.

Notes

  • kvm-ok (cpu-checker) confirms hardware virtualization
  • Multipass and LXD install as snaps
  • LXD needs lxd init once
  • Docker = app containers; LXD = whole-OS containers

Three Ways to Get a Test Box

multipass launch 26.04 -n dev --cpus 2 --memory 4G --disk 20G
multipass shell dev
multipass list && multipass delete --purge dev

sudo snap install lxd && sudo lxd init --minimal
lxc launch ubuntu:26.04 web1                # system container
lxc exec web1 -- bash
lxc launch ubuntu:26.04 vm1 --vm            # full VM instead
lxc snapshot web1 before-upgrade
lxc restore web1 before-upgrade
lxc list

sudo apt install cpu-checker && kvm-ok   # "can be used"
sudo apt install qemu-kvm libvirt-daemon-system virt-manager
sudo usermod -aG libvirt $USER

Code Explained

multipass launch — VM with CPU/RAM/disk sizes
lxd init --minimal — default storage + bridge
lxc launch — container; --vm — VM
lxc snapshot / restore — instant rollback
libvirt + virt-manager — GUI for any OS

Other Distros

  • Debian — LXD/Incus, libvirt; Fedora — libvirt + GNOME Boxes
  • macOS — UTM, Parallels; Multipass also runs on macOS

Prefer / Avoid

  • Avoid testing upgrades on your real server · Prefer an LXD clone or snapshot
  • Avoid full VMs for Linux services · Prefer LXD containers (lighter)

⚠ Common Mistakes

  • Running VMs without KVM acceleration: painfully slow
  • LXD and Docker fighting over iptables/forwarding rules
  • Forgetting --purge: deleted Multipass instances keep disk space

✓ Tips & Best Practices

  • multipass mount ~/code dev:/code shares folders
  • Use cloud-init with Multipass/LXD for repeatable setups (sheet 41)
  • Incus is the community fork of LXD with the same incus CLI ideas

Quick Summary

  • Multipass — one-command Ubuntu VMs
  • LXD — system containers + VMs
  • KVM/libvirt — any OS
  • snapshots — safe experiments
