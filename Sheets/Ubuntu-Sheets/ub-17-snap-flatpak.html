Sheet 17

Snap, Flatpak & Other Formats

snap install / refresh / remove · channels · --classic · snap list · Flatpak + Flathub · AppImage

Description

Snaps are Canonical's self-contained packages: they bundle their dependencies, update automatically, and run confined. Ubuntu ships some apps (Firefox, LXD) as snaps by default. Flatpak is a similar format popular on other desktops, with apps from Flathub. AppImage is a single executable file with no install step.

Notes

  • Snaps auto-refresh several times a day by default
  • --classic snaps run unconfined (editors, SDKs)
  • Some apt packages are transitional wrappers that install the snap
  • Flatpak is not installed by default on Ubuntu

Snap & Flatpak Basics

snap find "markdown editor"
sudo snap install code --classic        # VS Code, unconfined
sudo snap install lxd --channel=6/stable
snap list                               # installed + versions
snap info lxd                           # channels, publisher
sudo snap refresh                       # update all now
sudo snap refresh --hold=72h            # pause auto-updates
sudo snap revert lxd                    # back to previous revision
sudo snap remove --purge lxd

sudo apt install flatpak
flatpak remote-add --if-not-exists flathub \
    https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install flathub org.gimp.GIMP
flatpak update

Code Explained

--classic — needs full system access
--channel=6/stable — track + risk level
snap revert — instant rollback
--hold — delay auto-refresh
Flathub — main Flatpak app store

Other Distros

  • Debian — apt first; Snap and Flatpak both optional
  • Fedora — Flatpak + Flathub built in, no snaps by default
  • macOS — Homebrew casks, Mac App Store

Prefer / Avoid

  • Avoid mixing apt and snap versions of the same app · Prefer one source
  • Avoid disabling snap refresh forever · Prefer --hold for a set time

⚠ Common Mistakes

  • Snap apps can't see files outside $HOME by default (confinement)
  • Old revisions eat disk: snap keeps 2–3 per app
  • Running AppImages that need libfuse2 without installing it

✓ Tips & Best Practices

  • Limit kept revisions: sudo snap set system refresh.retain=2
  • Schedule refreshes: sudo snap set system refresh.timer=sat,03:00
  • Check snap permissions with snap connections <app>

Quick Summary

  • snap install — confined, auto-updating apps
  • channels — track/risk
  • Flatpak + Flathub — alternative app store
  • apt for servers, snaps/flatpaks for desktop apps
