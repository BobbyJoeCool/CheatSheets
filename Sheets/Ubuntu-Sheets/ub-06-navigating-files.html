Sheet 06

Navigating & Managing Files

pwd · cd · ls -lah · cp -r · mv · mkdir -p · touch · globbing

Description

Daily file work is a small set of commands: cd to move, ls to look, cp, mv and mkdir to organize. Globs like *.log let the shell expand patterns into file lists before the command runs. Ubuntu 25.10+ uses the Rust uutils coreutils by default; everyday flags behave the same.

Notes

  • cd alone or cd ~ → home; cd - → previous dir
  • . = current dir, .. = parent
  • Hidden files start with .; ls -a shows them
  • Quote names with spaces: "My Files"

Everyday Commands

pwd                          # /home/bob
cd /var/log && cd -          # go and come back
ls -lah                      # long, all, human sizes
ls -lt | head                # newest first
mkdir -p projects/api/src    # create parents as needed
touch notes.txt              # create empty / update time
cp report.pdf backup/        # copy file into dir
cp -a site/ site.bak/        # copy dir, keep perms + times
mv draft.md final.md         # rename
mv *.jpg ~/Pictures/         # glob: all .jpg files
cp -i a.txt b.txt            # ask before overwrite
ls ~/projects/{api,web}      # brace expansion

Code Explained

ls -lah — permissions, owner, size, date
mkdir -p — no error if it exists
cp -a — archive mode for directories
mv — move and rename are the same thing
{a,b} — expands to two paths

Other Distros

  • Debian/Fedora — GNU coreutils, same flags
  • macOS — BSD ls/cp; cp -a OK, some GNU flags missing

Prefer / Avoid

  • Avoid cp -r for backups · Prefer cp -a (keeps metadata)
  • Avoid unquoted variables in paths · Prefer "$dir"

Globs

PatternMatches
*anything
?one character
[abc]one of a, b, c
**/*.pyrecursive (bash: shopt -s globstar)
{jpg,png}brace list

ls Flags

FlagEffect
-llong format
-ainclude hidden

-t / -Ssort by time / size
-rreverse
-Rrecursive

⚠ Common Mistakes

  • mv file dir when dir doesn't exist renames the file to dir
  • cp silently overwrites; use -i or -n for safety
  • Unmatched glob passed literally (*.log when none exist)

✓ Tips & Best Practices

  • Tab-complete paths; double Tab lists options
  • Use tree -L 2 (apt install tree) for a quick overview
  • Add alias ll='ls -lah' to ~/.bashrc

Quick Summary

  • cd, ls, pwd — move and look
  • cp -a, mv, mkdir -p — organize
  • globs — shell expands patterns
  • quote paths with spaces
