Sheet 45

System Info & Performance

uname -a · lscpu · free -h · df -h / du -sh / ncdu · uptime / load average · vmstat / iostat · btop

Description

When a machine feels slow, check the four resources: CPU, memory, disk space/IO and network. uptime shows load average, free -h memory, df -h space, iostat disk activity, and btop all of it at once. Linux uses spare RAM for cache, so low "free" memory is normal: look at available.

Notes

  • Load average ≈ runnable tasks; compare to CPU count
  • available in free -h is what apps can use
  • Swap use alone isn't bad; constant swapping is
  • iostat comes from the sysstat package

Quick Health Check

uptime                       # load average: 0.42, 0.55, 0.61
nproc                        # 4 CPUs → load 4 = fully busy
uname -a                     # kernel, arch
lscpu | grep "Model name"
free -h                      # look at "available"
df -h -x tmpfs -x squashfs   # real filesystems only
du -sh /var/* | sort -h      # biggest dirs in /var
sudo ncdu /                  # interactive disk usage
vmstat 2 5                   # CPU, memory, swap, IO every 2 s
iostat -xz 2                 # per-disk utilization (sysstat)
btop                         # all-in-one dashboard
systemd-cgtop                # resource use per service

Code Explained

load avg — 1, 5, 15 minute averages
nproc — compare load to core count
df -h -x ... — hide virtual filesystems
du | sort -h — find space hogs
iostat -xz — %util near 100 = disk bound

Other Distros

  • Debian/Fedora — same tools
  • macOS — top, vm_stat, df -h, Activity Monitor

Prefer / Avoid

  • Avoid reading "free" memory as a problem · Prefer "available"
  • Avoid guessing · Prefer measuring CPU, RAM, disk, network in turn

⚠ Common Mistakes

  • Deleting files that a running process holds: space isn't freed (lsof +L1)
  • Ignoring inode exhaustion: df -i can be full while df -h isn't
  • Treating squashfs snap mounts as full disks

✓ Tips & Best Practices

  • Find deleted-but-open files: sudo lsof +L1
  • Enable sysstat history: sudo systemctl enable --now sysstat
  • Add a swap file on small VMs: fallocate + mkswap + swapon

Quick Summary

  • uptime / nproc — CPU load
  • free -h available — memory
  • df / du / ncdu — space
  • iostat / btop — IO and overview
