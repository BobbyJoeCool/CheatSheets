Ordered, Mutable Sequences

A list is an ordered, mutable sequence that can hold items of any type, duplicates included. Create one with brackets or list(). Indexing and slicing work exactly as they do on strings, but unlike strings you can change items, replace slices, and grow or shrink the list in place.

Notes

  • Indexes start at 0; -1 is the last item
  • Slicing returns a new list
  • Assignment b = a shares the same list
  • Lists can nest: [[1, 2], [3]]
  • Methods are on Sheet 47; copying on Sheet 48

List Basics

nums = [10, 20, 30, 40]
mixed = [1, "two", 3.0, [4]]       # any types
empty = []; also_empty = list()
nums[0], nums[-1]                  # (10, 40)
nums[1:3]                          # [20, 30]  (new list)
nums[0] = 99                       # [99, 20, 30, 40]
nums[1:3] = [7, 8, 9]              # [99, 7, 8, 9, 40]
del nums[0]                        # [7, 8, 9, 40]
len(nums)                          # 4
30 in nums                         # False
[0] * 3                            # [0, 0, 0]
[1, 2] + [3]                       # [1, 2, 3]
list("abc"), list(range(3))        # (['a', 'b', 'c'], [0, 1, 2])

Code Explained

nums[0] = 99 — replace one item in place
nums[1:3] = [...] — slice assignment can change length
del nums[0] — remove by index
[0] * 3 — repeat; safe for immutable items
list(iterable) — build from any iterable

⚠ Common Mistakes

  • lst[len(lst)] — IndexError; the last item is lst[-1]
  • [[0] * 3] * 3 — three references to one row
  • b = a then changing b — a changes too
  • Removing items while looping over the same list

✓ Tips & Best Practices

  • Copy with lst[:] or lst.copy() before modifying
  • Use a tuple for a fixed record that shouldn't change
  • lst[-n:] gets the last n items safely
  • Check emptiness with if not lst:

Quick Summary

  • [...] — ordered, mutable
  • lst[i] = v — change in place
  • slices — new lists
  • b = a — alias, not copy
