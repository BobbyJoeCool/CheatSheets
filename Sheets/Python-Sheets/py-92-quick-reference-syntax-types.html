⚠ Common Mistakes

  • Mutable default arguments (def f(x=[])) — use None and create inside
  • == with None or True — use is None
  • Shadowing built-ins like list, dict, id with variable names

✓ Tips & Best Practices

  • Use f-strings for all formatting
  • Prefer enumerate and zip to index loops
  • Catch the narrowest exception you can handle

Quick Summary
