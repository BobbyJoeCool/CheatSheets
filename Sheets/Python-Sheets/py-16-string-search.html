String Methods — Search

find() · index() · startswith() · endswith() · in · count() · rfind()

Finding Substrings

Search methods locate substrings without regular expressions. in gives a yes/no answer, find() returns an index or -1, and index() raises ValueError when nothing matches. startswith() and endswith() accept a tuple of options. All of them are case-sensitive, and most accept optional start and end positions.

Notes

  • rfind() / rindex() search from the right
  • count() counts non-overlapping matches
  • For patterns, use the re module (Sheet 83)
  • Case-insensitive search: lower both sides first
  • Index results are 0-based

Search Methods

s = "banana split"
"nan" in s                     # True
s.find("an")                   # 1
s.find("an", 2)                # 3  (search from index 2)
s.rfind("an")                  # 3
s.find("xyz")                  # -1
s.index("xyz")                 # ValueError
s.count("a")                   # 3
s.count("ana")                 # 1  (non-overlapping)
s.startswith("ban")            # True
s.endswith((".txt", "split"))  # True  (tuple of options)
"Hello".lower().find("h")      # 0  (case-insensitive)
s.split().index("split")       # 1  (list.index)

Code Explained

in — best for a plain existence check
find() — safe position lookup, -1 if missing
index() — same, but raises on a miss
tuple argument — endswith() tries each option

⚠ Common Mistakes

  • if s.find(x): — 0 is falsy and -1 is truthy; use in
  • Calling index() without try — crashes on a miss
  • Forgetting case: "Py" in "python" is False
  • Expecting count() to find overlapping matches

✓ Tips & Best Practices

  • Use in for yes/no, find() when you need the position
  • Pass a tuple to endswith() to match several extensions
  • Normalize with casefold() before searching user text
  • Switch to re.search() once you need wildcards

Quick Summary

  • in — contains test
  • find() — index or -1
  • index() — index or ValueError
  • startswith() / endswith() — prefix/suffix tests
