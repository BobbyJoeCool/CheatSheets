Math Operators

Python has seven arithmetic operators. / is true division and always returns a float. // is floor division and rounds toward negative infinity. % returns a remainder with the sign of the divisor. ** raises to a power, groups right to left, and binds tighter than unary minus.

Notes

  • int op int → int, except /
  • Any float operand makes the result a float
  • a == (a // b) * b + a % b always holds
  • Division by zero raises ZeroDivisionError
  • @ is matrix multiplication (NumPy), unused by built-ins

Arithmetic in Action

7 + 2, 7 - 2, 7 * 2            # (9, 5, 14)
7 / 2, 6 / 3                   # (3.5, 2.0)  always float
7 // 2, -7 // 2                # (3, -4)  floors
7 % 3, -7 % 3, 7 % -3          # (1, 2, -2)  sign of divisor
2 ** 10, 2 ** -1               # (1024, 0.5)
2 ** 3 ** 2                    # 512  (2 ** 9, right to left)
-2 ** 2                        # -4   (** before unary -)
(-2) ** 2                      # 4
divmod(17, 5)                  # (3, 2)
7.5 // 2                       # 3.0  (float in, float out)
1 / 0                          # ZeroDivisionError
abs(-3), round(2.567, 1)       # (3, 2.6)

Code Explained

⚠ Common Mistakes

  • Expecting 7 / 2 to be 3 — use // for integer division
  • Assuming -7 // 2 is -3 — it floors to -4
  • -2 ** 2 is -4 — wrap the base: (-2) ** 2
  • -7 % 3 is 2, not -1 — use math.fmod() for C-style

✓ Tips & Best Practices

  • Even test: n % 2 == 0
  • Wrap an index: items[i % len(items)]
  • Split seconds: mins, secs = divmod(total, 60)
  • Add parentheses whenever precedence isn't obvious

Quick Summary

  • / — float division
  • // — floor division
  • % — remainder, divisor's sign
  • ** — power, right-associative
