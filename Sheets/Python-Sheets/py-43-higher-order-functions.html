Functions as Values

A higher-order function takes a function as an argument, returns a function, or both. Python functions are first-class values: you can store them in variables, lists, and dicts, and pass them around. Built-ins like map(), filter(), sorted(), min(), and max() accept functions, and functools.reduce() folds a sequence into one value.

Notes

  • map() and filter() return lazy iterators
  • filter(None, xs) keeps the truthy items
  • map() accepts several iterables in parallel
  • Comprehensions are often clearer than map/filter
  • Decorators (Sheet 44) return functions

Passing and Returning Functions

def apply(func, value):
    return func(value)
apply(str.upper, "hi")             # 'HI'
apply(len, [1, 2, 3])              # 3
list(map(int, ["1", "2"]))         # [1, 2]
list(map(pow, [2, 3], [3, 2]))     # [8, 9]  two iterables
list(filter(str.isdigit, ["1", "a", "2"]))  # ['1', '2']
list(filter(None, [0, 1, "", "x"]))         # [1, 'x']
from functools import reduce
reduce(lambda a, b: a * b, [1, 2, 3, 4])    # 24
ops = {"+": lambda a, b: a + b, "-": lambda a, b: a - b}
ops["-"](7, 2)                     # 5  dispatch table
def compose(f, g):
    return lambda x: f(g(x))
shout = compose(str.upper, str.strip)
shout("  hey ")                    # 'HEY'

Code Explained

apply(str.upper, ...) — pass the function, don't call it
map(f, xs) — f applied to each item
filter(pred, xs) — keep items where pred is truthy
reduce(f, xs) — combine items pairwise into one
compose — returns a brand-new function

⚠ Common Mistakes

  • Printing map(...) — shows an iterator; wrap with list()
  • Reusing a map or filter result — it's exhausted after one pass
  • Passing f() instead of f — you pass the result, not the function
  • reduce() on an empty list without initial — TypeError

✓ Tips & Best Practices

  • Use sum, max, any before reaching for reduce
  • Replace long if/elif chains with a dict of functions
  • Prefer comprehensions for simple map/filter work
  • Use operator functions instead of tiny lambdas

Quick Summary

  • reduce — fold to one value
