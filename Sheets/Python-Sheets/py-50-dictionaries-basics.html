Key–Value Mappings

A dict maps unique, hashable keys to values with fast average O(1) lookups and keeps insertion order (3.7+). Create one with {} or dict(). Reading d[key] raises KeyError when the key is missing, so use get() when absence is normal. Assigning to a key adds it or updates its value.

Notes

  • Keys must be hashable: str, int, tuple, frozenset
  • 1, 1.0, and True count as the same key
  • in checks keys, not values
  • Values can be anything, including other dicts
  • Methods: Sheet 51; patterns: Sheet 52

Dict Basics

user = {"name": "Ana", "age": 30}
also = dict(name="Ana", age=30)
user["name"]                       # 'Ana'
user["email"]                      # KeyError
user.get("email")                  # None
user.get("email", "n/a")           # 'n/a'
user["age"] = 31                   # update
user["city"] = "Lima"              # add
del user["city"]                   # remove
"age" in user                      # True  (keys)
len(user)                          # 2
for key, val in user.items():
    print(f"{key}={val}")          # name=Ana / age=31

Code Explained

d[key] — strict lookup
d.get(key, default) — forgiving lookup
d[key] = v — add or replace
del d[key] — remove; KeyError if missing
.items() — loop over key–value pairs

⚠ Common Mistakes

  • d[k] on a missing key — KeyError; use get() or in
  • s = {} expecting a set — it's an empty dict
  • Using a list as a key — TypeError: unhashable type
  • d[1] and d[True] — the same slot

✓ Tips & Best Practices

  • Use get() with a default for optional fields
  • Loop with .items() instead of d[k] lookups
  • Nested dicts mirror JSON naturally
  • Use collections.Counter for counting

Quick Summary

  • {k: v} — mapping
  • d[k] — strict; get() — safe
  • k in d — key check
  • keys — hashable only
