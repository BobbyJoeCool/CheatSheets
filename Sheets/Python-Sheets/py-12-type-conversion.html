Type Conversion & Casting

int() · float() · str() · bool() · ValueError · implicit coercion

Explicit Conversion

Python converts values by calling the target type: int(), float(), str(), bool(), list(), and so on. Implicit conversion only happens for numeric widening in arithmetic (int → float → complex). Python never joins str and int automatically. Invalid conversions raise ValueError (bad content) or TypeError (wrong type).

Notes

  • int(float) truncates toward zero
  • str(x) calls x.__str__()
  • bool(s) checks emptiness, not the text
  • list("abc") splits a string into characters
  • ord() / chr() convert characters ↔ code points

Conversions

int("42"), float("3.5")        # (42, 3.5)
int(3.9), float(7)             # (3, 7.0)
str(42) + "!"                  # '42!'
int("3.5")                     # ValueError
int(float("3.5"))              # 3
1 + 2.0                        # 3.0  (int widened)
"1" + 1                        # TypeError
list("abc")                    # ['a', 'b', 'c']
tuple([1, 2]), set([1, 1, 2])  # ((1, 2), {1, 2})
dict([("a", 1), ("b", 2)])     # {'a': 1, 'b': 2}
ord("A"), chr(66)              # (65, 'B')
"5" * 3, int("5") * 3          # ('555', 15)

Code Explained

int("3.5") — fails; the string must be an integer literal
1 + 2.0 — the only automatic conversion is numeric widening
set([...]) — conversion also removes duplicates
dict(pairs) — needs an iterable of 2-item pairs
"5" * 3 — string repetition, not math

⚠ Common Mistakes

  • "Total: " + 5 — TypeError; use str(5) or an f-string
  • int("3.5") — ValueError; go through float() first
  • bool("False") is True — compare s.lower() == "true"
  • int("1,000") fails — remove commas: s.replace(",", "")

✓ Tips & Best Practices

  • Wrap conversions of outside data in try/except ValueError
  • str.isdigit() rejects "-5" and "3.5"; prefer try/except
  • int(round(x)) rounds before converting
  • repr(x) shows the exact value, including quotes

Quick Summary

  • T(x) — convert by calling the type
  • ValueError — bad content
  • TypeError — wrong type
  • numeric widening — the only implicit conversion
