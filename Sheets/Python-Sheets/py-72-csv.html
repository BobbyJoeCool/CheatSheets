CSV Files

csv.reader · csv.writer · DictReader · DictWriter · newline='' · delimiter

Comma-Separated Values

The csv module reads and writes delimited text correctly, handling quotes, embedded commas, and line breaks inside fields. csv.reader yields each row as a list of strings and csv.writer writes lists. DictReader and DictWriter use the header row so you can work with column names. Always open CSV files with newline="".

Notes

  • Every value read is a str; convert it yourself
  • newline="" prevents blank lines on Windows
  • Excel files saved as CSV may need encoding="utf-8-sig"
  • delimiter=";" or "\t" for other separators
  • For analysis, pandas.read_csv() is often easier

Read & Write CSV

import csv
rows = [["name", "score"], ["Ana", 91], ["Bo", 78]]
with open("scores.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows(rows)          # handles quoting
with open("scores.csv", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)                  # ['name', 'score']
    for name, score in reader:
        print(name, int(score))            # values arrive as str
with open("scores.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["name"], row["score"])   # Ana 91
people = [{"name": "Cy", "score": 85}]
with open("more.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.DictWriter(f, fieldnames=["name", "score"])
    w.writeheader(); w.writerows(people)

Code Explained

writerows() — write many rows at once
next(reader) — pull off the header row
int(score) — convert numeric columns
DictReader — each row is a dict keyed by header
writeheader() — write the field names first

⚠ Common Mistakes

  • Leaving out newline="" — doubled line breaks on Windows
  • Splitting lines with .split(",") — breaks on quoted commas
  • Forgetting that every value is a string
  • DictWriter given dicts with unexpected keys — ValueError

✓ Tips & Best Practices

  • Use utf-8-sig when the file will be opened in Excel
  • Detect the format with csv.Sniffer().sniff(sample)
  • Stream big files row by row; don't load them all
  • Switch to pandas for filtering, grouping, and joins

Quick Summary

  • csv.reader / writer — lists
  • DictReader / DictWriter — dicts
  • newline="" — always
  • values — strings; convert yourself
