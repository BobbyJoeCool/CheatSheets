Tkinter Basics & Windows

tk.Tk() · mainloop() · title() · geometry() · resizable() · Toplevel

Your First Window

Tkinter is Python's built-in GUI toolkit, a wrapper around Tcl/Tk. Create exactly one root window with tk.Tk(), add widgets to it, then call mainloop(), which runs the event loop that draws the window and dispatches clicks and keystrokes until the window closes. Extra windows use tk.Toplevel.

Notes

  • Included with most Python installers
  • Linux may need the python3-tk system package
  • mainloop() blocks until the window closes
  • Long-running work in callbacks freezes the window
  • Use root.after() for timers instead of time.sleep()

Window Setup

import tkinter as tk
root = tk.Tk()                         # main window (create once)
root.title("My App")
root.geometry("400x300+100+50")        # W x H + X + Y
root.minsize(300, 200)
root.resizable(True, False)            # width yes, height no
root.configure(bg="#f4f4f4")
root.attributes("-topmost", True)      # stay above other windows
tk.Label(root, text="Hello, Tkinter!").pack(pady=20)
def open_settings():
    win = tk.Toplevel(root)            # second window
    win.title("Settings")
    win.transient(root); win.grab_set()   # modal-style
tk.Button(root, text="Settings", command=open_settings).pack()
root.protocol("WM_DELETE_WINDOW", root.destroy)  # close-button handler
root.after(1000, lambda: print("1 s later"))      # timer
root.mainloop()                        # start the event loop

Code Explained

geometry("WxH+X+Y") — size and screen position
resizable(w, h) — allow resizing per axis
Toplevel — additional window tied to root
grab_set() — route input to this window only
protocol("WM_DELETE_WINDOW", f) — run f on close

⚠ Common Mistakes

  • Creating a second tk.Tk() — confusing bugs; use Toplevel
  • Forgetting mainloop() — the window flashes and the script ends
  • time.sleep() in a callback — the window stops responding
  • Running heavy work in command= — move it to a thread or after() steps

✓ Tips & Best Practices

  • Subclass tk.Tk to keep state and widgets together
  • Use after() for polling and animations
  • Group widgets into Frames per screen area
  • Use ttk widgets for a native look (Sheet 96)
