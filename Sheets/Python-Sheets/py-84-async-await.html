Async/await & Coroutines

async def · await · asyncio.run() · gather() · create_task() · TaskGroup

Concurrent I/O with asyncio

async def defines a coroutine; calling it creates a coroutine object that does nothing until awaited. await pauses the coroutine until a result is ready, letting the event loop run other tasks meanwhile. That makes asyncio ideal for many simultaneous network or disk waits. asyncio.run() starts the loop, and gather(), create_task(), and TaskGroup run coroutines concurrently.

Notes

  • Only one coroutine runs at a time (single thread)
  • await only works inside async def
  • Blocking calls like time.sleep() freeze every task
  • asyncio.TimeoutError is TimeoutError (3.11+)
  • Use async libraries: httpx, aiohttp, aiofiles

Coroutines and Tasks

import asyncio
async def fetch(name, delay):
    await asyncio.sleep(delay)         # yields to the event loop
    return f"{name} done"
async def main():
    results = await asyncio.gather(    # concurrent: ~2 s total
        fetch("b", 2), fetch("c", 1))
    print(results)                     # ['b done', 'c done']
    task = asyncio.create_task(fetch("d", 1))  # starts now
    async with asyncio.TaskGroup() as tg:      # 3.11+
        t1 = tg.create_task(fetch("e", 1))
        t2 = tg.create_task(fetch("f", 1))
    print(t1.result(), await task)     # e done d done
    try:
        await asyncio.wait_for(fetch("g", 5), timeout=1)
    except TimeoutError:
        print("too slow")
asyncio.run(main())                    # start the event loop

Code Explained

await asyncio.sleep() — a non-blocking pause
gather() — run several and collect results in order
create_task() — schedule now, await later
TaskGroup — waits for all; cancels the rest if one fails
wait_for(..., timeout=) — give up after a limit

⚠ Common Mistakes

  • Calling fetch() without await — "coroutine was never awaited"
  • time.sleep() or requests.get() inside async code — blocks everything
  • asyncio.run() inside an already running loop (e.g. Jupyter) — use await
  • Expecting asyncio to speed up CPU-bound work

✓ Tips & Best Practices

  • Prefer TaskGroup over bare gather() for error handling
  • Wrap unavoidable blocking calls with asyncio.to_thread()
  • Limit concurrency with asyncio.Semaphore(10)
  • Keep asyncio.run() as the single entry point

Quick Summary

  • async def — coroutine
  • await — pause without blocking
  • gather / TaskGroup — concurrency
  • asyncio.run() — entry point
