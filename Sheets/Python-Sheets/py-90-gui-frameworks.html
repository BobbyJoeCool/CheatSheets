GUI Frameworks Overview

Tkinter · ttk · PySide6 / PyQt6 · wxPython · Kivy · event loop · callbacks

Desktop Apps in Python

A GUI framework draws windows and widgets and runs an event loop that waits for clicks and keystrokes, then calls your callbacks. Tkinter ships with Python and suits small tools and learning; Qt (PySide6 / PyQt6) is the usual choice for full desktop apps. Every framework shares the same shape: build widgets, arrange them with a layout, connect events, start the loop.

Notes

  • Full coverage: the Tkinter Reference set (62 sheets)
  • Tkinter needs no install; Linux may need python3-tk
  • The event loop blocks — keep callbacks short
  • GUI objects must only be touched from the main thread

Same App, Two Frameworks

# Tkinter — standard library, no install
import tkinter as tk
from tkinter import ttk

class App(tk.Tk):
    def __init__(self):
        super().__init__()
        self.title("Counter")
        self.count = tk.IntVar(value=0)
        ttk.Label(self, textvariable=self.count).pack(padx=20, pady=8)
        ttk.Button(self, text="Add", command=self.add).pack(pady=8)

    def add(self):
        self.count.set(self.count.get() + 1)

App().mainloop()                       # event loop; blocks until closed

# PySide6 (Qt) — pip install pyside6
from PySide6.QtWidgets import QApplication, QPushButton
app = QApplication([])
btn = QPushButton("Add")
btn.clicked.connect(lambda: print("clicked"))   # signal → slot
btn.show()
app.exec()

Code Explained

class App(tk.Tk) — window, state and widgets in one object
IntVar — control variable; the label updates itself
command= — Tkinter callback on click
clicked.connect() — Qt signal wired to a slot
mainloop() / exec() — run the event loop

The Pythonic Way

  • from tkinter import * → import tkinter as tk
  • Classic tk.Button → ttk.Button (native look)
  • time.sleep() in a callback → after() / QTimer

⚠ Common Mistakes

  • Forgetting mainloop() / exec() — the window flashes and the script ends
  • Slow work in a callback — the window freezes; use a thread
  • Updating widgets from a worker thread — crashes or glitches
  • Creating a second tk.Tk() — use Toplevel for more windows

✓ Tips & Best Practices

  • Start with Tkinter; move to Qt when you need richer widgets
  • Keep logic in plain functions so it is testable without the GUI
  • Hand results back to the main thread (after() / signals)
  • Ship apps with PyInstaller or Briefcase
