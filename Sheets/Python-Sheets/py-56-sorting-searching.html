Sorting & Searching

sorted() · list.sort() · key= · reverse= · bisect · stable sort

Ordering and Finding Data

sorted() returns a new sorted list from any iterable; list.sort() sorts a list in place and returns None. Both accept key= (a function that extracts the sort value) and reverse=True. Python's sort is stable, so items with equal keys keep their order. For fast searching in sorted data, use the bisect module.

Notes

  • Sorting uses Timsort: O(n log n)
  • Stability lets you sort by several keys in passes
  • Mixed types like [1, "a"] can't be sorted
  • in and index() are linear searches
  • heapq finds the n smallest/largest efficiently

Sorting & Searching

nums = [5, 2, 9, 1]
sorted(nums)                       # [1, 2, 5, 9]  new list
sorted(nums, reverse=True)         # [9, 5, 2, 1]
nums.sort()                        # in place; returns None
words = ["banana", "Apple", "cherry"]
sorted(words, key=str.lower)       # case-insensitive
sorted(words, key=len)             # ['Apple', 'banana', 'cherry']
people = [("Ana", 30), ("Bo", 25), ("Cy", 30)]
sorted(people, key=lambda p: (-p[1], p[0]))
# [('Ana', 30), ('Cy', 30), ('Bo', 25)]  age desc, name asc
import bisect
a = [1, 3, 5, 7]
bisect.bisect_left(a, 5)           # 2  (where 5 is)
bisect.insort(a, 4)                # [1, 3, 4, 5, 7]
nums.index(9)                      # 3  (linear search)

Code Explained

key=str.lower — compare by a derived value
key=len — ties (banana, cherry) keep original order
tuple key with - — mix descending and ascending
bisect — binary search on sorted lists

⚠ Common Mistakes

  • x = x.sort() — x becomes None
  • reverse=True with a tuple key when only one field should flip — negate that field instead
  • Sorting mixed types — TypeError
  • Using bisect on unsorted data — wrong answers, no error

✓ Tips & Best Practices

  • Use operator.itemgetter for record sorts
  • Get top items with heapq.nlargest(5, xs, key=...)
  • Keep a list sorted while inserting with bisect.insort
  • Sort dict items by value: sorted(d.items(), key=lambda kv: kv[1])

Quick Summary

  • sorted() — new list
  • .sort() — in place, None
  • key= / reverse= — control order
  • bisect — binary search
