Generators & yield

yield · generator function · next() · send() · yield from · StopIteration

Lazy Functions

A function that contains yield is a generator function. Calling it returns a generator object and runs none of the body. Each next() resumes the body until the next yield, hands back a value, and pauses with all local state preserved. When the function returns, iteration stops with StopIteration. Generators are ideal for lazy sequences, infinite streams, and pipelines.

Notes

  • for loops call next() and catch StopIteration for you
  • A generator runs once; create a new one to restart
  • yield from iterable delegates to another iterable
  • return x inside sets StopIteration.value
  • Generator expressions are the one-line version (Sheet 33)

yield in Practice

def countdown(n):
    while n > 0:
        yield n                    # pause here
        n -= 1
gen = countdown(3)                 # body hasn't run yet
next(gen), next(gen)               # (3, 2)
list(gen)                          # [1]
for x in countdown(2): print(x)    # 2 / 1
def fib():                         # infinite stream
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
from itertools import islice
list(islice(fib(), 7))             # [0, 1, 1, 2, 3, 5, 8]
def flatten(xss):
    for xs in xss:
        yield from xs              # delegate
list(flatten([[1, 2], [3]]))       # [1, 2, 3]

Code Explained

yield n — produce a value and pause
next(gen) — resume until the next yield
while True — fine; values are produced on demand
islice(gen, 7) — take the first 7 safely
yield from — yields every item of xs

⚠ Common Mistakes

  • Expecting the body to run on call — nothing happens until next()
  • Iterating an exhausted generator — silently empty
  • len() or indexing a generator — TypeError
  • list() on an infinite generator — hangs; use islice

✓ Tips & Best Practices

  • Turn "build a list and return it" functions into generators
  • Use yield from instead of a for + yield loop
  • Limit infinite generators with islice or takewhile
  • send() is rarely needed; prefer plain iteration

Quick Summary

  • yield — makes a generator function
  • next() — resume to next yield
  • yield from — delegate
  • lazy — memory-friendly streams
