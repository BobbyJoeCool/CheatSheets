Sheet 11

None & Type Checking

None · is None · type() · isinstance() · hasattr()

The Absence of a Value

None is the single instance of NoneType and means "no value". Functions without a return give None. Because there is exactly one None, test it with is None. For types, type() returns the exact class, isinstance() also accepts subclasses and is usually preferred, and hasattr() checks for a capability.

Notes

  • None is falsy but not equal to 0, "", or False
  • None < 1 raises TypeError
  • Hint optional values as int | None (3.10+)
  • type(None) is NoneType
  • Python favors duck typing over type checks

None & Type Checks

def find(items, target):
    for i, x in enumerate(items):
        if x == target:
            return i
    # falls off the end → returns None
result = find([5, 7], 9)
result is None                 # True
result == 0                    # False
type(3), type("a")             # (<class 'int'>, <class 'str'>)
type(True) is int              # False (it's bool)
isinstance(True, int)          # True  (bool subclasses int)
isinstance(3.0, (int, float))  # True  (tuple of types)
hasattr("abc", "upper")        # True
callable(len)                  # True

Code Explained

is None — identity test; fastest and lint-clean
implicit return — any function without return gives None
type(x) is T — exact class match only
isinstance(x, (A, B)) — any of several types
hasattr() / callable() — check capabilities

⚠ Common Mistakes

  • lst = lst.sort() — lst becomes None; use sorted()
  • if x == None: — use is None
  • if not x: when 0 or "" are valid values
  • type(x) == int — misses subclasses; use isinstance

✓ Tips & Best Practices

  • Use None as the default for mutable args: def f(items=None):
  • Pass a tuple to isinstance to accept several types
  • Prefer trying an operation (EAFP) over checking types first
  • Annotate optional returns as -> int | None

Quick Summary

  • None — single no-value object
  • is None — the correct test
  • isinstance() — type check with inheritance
  • hasattr() — capability check
