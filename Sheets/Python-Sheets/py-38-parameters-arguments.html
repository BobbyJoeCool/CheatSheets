Passing Values In

Parameters are the names in the def; arguments are the values passed in a call. Arguments match by position or by keyword. *args collects extra positional arguments into a tuple and **kwargs collects extra keyword arguments into a dict. At the call site, * and ** do the reverse: they unpack a sequence or dict into arguments.

Notes

  • Positional arguments must come before keyword ones
  • Keyword arguments can appear in any order
  • args / kwargs are conventional names only
  • Order in def: normal, *args, keyword-only, **kwargs
  • Defaults and keyword-only: Sheet 39

Positional, Keyword, *args, **kwargs

def describe(name, age, city="Unknown"):
    return f"{name}, {age}, {city}"

describe("Ana", 30)                    # 'Ana, 30, Unknown'
describe(age=30, name="Ana")           # keywords, any order
describe("Ana", city="Rome", age=30)   # mixed
def total(*args):
    return sum(args)                   # args is a tuple
total(1, 2, 3)                         # 6
def tag(**kwargs):
    return kwargs                      # kwargs is a dict
tag(id=1, cls="box")                   # {'id': 1, 'cls': 'box'}
def show(a, *args, **kwargs):
    print(a, args, kwargs)
show(1, 2, 3, x=4)                     # 1 (2, 3) {'x': 4}
nums = [30]; opts = {"city": "Oslo"}
describe("Bo", *nums, **opts)          # 'Bo, 30, Oslo'

Code Explained

positional — matched left to right
keyword — matched by name
*args — extra positionals → tuple
**kwargs — extra keywords → dict
*seq / **dict in a call — unpack into arguments

⚠ Common Mistakes

  • f(a=1, 2) — positional after keyword is a SyntaxError
  • Passing an argument both by position and by name
  • Using *args when a single list parameter is clearer
  • Forgetting ** when forwarding: f(kwargs) passes one dict

✓ Tips & Best Practices

  • Pass booleans by keyword: save(path, overwrite=True)
  • Forward everything with wrapped(*args, **kwargs)
  • Unpack config dicts into calls with **settings
  • Type *args: int and **kwargs: str for clarity

Quick Summary

  • positional — by order
  • keyword — by name
  • *args — tuple of extras
  • **kwargs — dict of extras
