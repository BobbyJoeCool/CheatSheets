What Is Python?

Python is a general-purpose, high-level language created by Guido van Rossum and first released in 1991. It puts readability first: indentation defines code blocks, and the language favors one obvious way to do things. The reference implementation, CPython, compiles source to bytecode and runs it on a virtual machine. Python 2 reached end of life on January 1, 2020, so all modern code targets Python 3.

Key Facts

  • Named after Monty Python, not the snake
  • Dynamically typed — types belong to values, not variables
  • Strongly typed — "2" + 2 raises TypeError
  • Memory is managed by reference counting plus a cycle-detecting garbage collector
  • Language changes are proposed and documented as PEPs

Hello, World & Version Check

# hello.py
print("Hello, World!")          # Hello, World!

# The Zen of Python (PEP 20)
import this                      # prints 19 aphorisms

# Inspect the running interpreter
import sys
print(sys.version_info)          # sys.version_info(major=3, minor=12, ...)
print(sys.version_info >= (3, 10))  # True on 3.10 and newer
print(sys.implementation.name)   # cpython

Code Explained

print() — built-in; writes text to standard output
import this — Easter egg that prints the Zen of Python
sys.version_info — named tuple; compare it to a tuple like (3, 10)
sys.implementation.name — cpython, pypy, etc.

⚠ Common Mistakes

  • Following Python 2 tutorials — print "x" is a SyntaxError in Python 3
  • Mixing tabs and spaces — raises TabError; use 4 spaces
  • Assuming python means Python 3 — some systems map it to 2 or nothing; use python3 or py
  • Thinking interpreted means no compile step — CPython compiles to .pyc bytecode first

✓ Tips & Best Practices

  • Run import this once and read it; idiomatic code follows it
  • Learn PEP 8 style, then let ruff format or black enforce it
  • Check sys.version_info before relying on newer syntax
  • Read the docs at docs.python.org for the exact version you run

Quick Summary

  • CPython — source → bytecode → virtual machine
  • Python 3 — the only supported line since 2020
  • PEP 20 — the Zen of Python; readability counts
  • .py — source; .pyc — cached bytecode
