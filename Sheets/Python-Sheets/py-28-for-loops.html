Iterating over Iterables

for walks through any iterable — lists, strings, dicts, files, ranges, generators — binding each item to the loop variable in turn. It is not a counter loop. Use range() for counts, enumerate() when you also need the index, and zip() to walk several sequences side by side. An optional else runs when the loop ends without break.

Notes

  • range(stop) starts at 0 and excludes stop
  • The loop variable stays defined after the loop
  • Iterating a dict yields keys
  • zip() stops at the shortest input
  • for-else is covered on Sheet 30

for Patterns

for fruit in ["apple", "fig"]:
    print(fruit)                   # apple / fig
for i in range(3): ...             # 0, 1, 2
for i in range(2, 10, 3): ...      # 2, 5, 8
for i in range(5, 0, -1): ...      # 5, 4, 3, 2, 1
for i, name in enumerate(["a", "b"], start=1):
    print(i, name)                 # 1 a / 2 b
for name, age in zip(["Ana", "Bo"], [30, 25]):
    print(name, age)               # Ana 30 / Bo 25
for key, val in {"x": 1}.items(): ...
for ch in "hi": ...                # 'h', 'i'
for row in [[1, 2], [3, 4]]:
    for cell in row:
        print(cell, end=" ")       # 1 2 3 4
for x in reversed([1, 2, 3]): ...  # 3, 2, 1

Code Explained

range(a, b, step) — negative step counts down
enumerate(xs, start=1) — index and item together
zip(a, b) — pairs items by position
.items() — unpack key and value
nested loops — inner runs fully for each outer item

⚠ Common Mistakes

  • Removing items from a list while looping over it — items get skipped
  • for i in range(len(xs)): just to read xs[i] — use enumerate()
  • Unequal lists in zip() — extras dropped silently
  • range(1, 10) expecting 10 — the stop is excluded

✓ Tips & Best Practices

  • Loop over a copy when removing: for x in xs[:]:
  • Use zip(..., strict=True) when lengths must match
  • Prefer for item in items over index math
  • See itertools (Sheet 55) for chaining and grouping

Quick Summary

  • for x in iterable — visit each item
  • range() — counting
  • enumerate() — index + item
  • zip() — parallel iteration
