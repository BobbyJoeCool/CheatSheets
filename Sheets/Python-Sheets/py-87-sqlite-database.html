SQLite Database

sqlite3.connect() · cursor · execute() · ? placeholders · commit() · fetchall()

Built-in SQL Database

sqlite3 gives you a full SQL database stored in a single file, with no server to install. Connect, get a cursor, run SQL with execute(), and save changes with commit(). Always pass values with ? placeholders rather than formatting them into the SQL string; this prevents SQL injection and handles quoting for you.

Notes

  • ":memory:" creates a temporary in-RAM database
  • Parameters must be a tuple or list: (x,)
  • with con: commits or rolls back, but doesn't close
  • sqlite3.Row allows access by column name
  • Explore files with the sqlite3 CLI or DB Browser

CRUD with sqlite3

import sqlite3
con = sqlite3.connect("shop.db")       # file, or ":memory:"
con.row_factory = sqlite3.Row          # rows act like dicts
cur = con.cursor()
cur.execute("""CREATE TABLE IF NOT EXISTS items (
    id INTEGER PRIMARY KEY, name TEXT NOT NULL, price REAL)""")
cur.execute("INSERT INTO items (name, price) VALUES (?, ?)", ("pen", 1.5))
cur.executemany("INSERT INTO items (name, price) VALUES (?, ?)",
                [("ink", 4.0), ("pad", 2.25)])
con.commit()                           # save changes
cur.execute("SELECT * FROM items WHERE price > ?", (2,))
[dict(r) for r in cur.fetchall()]      # [{'id': 2, 'name': 'ink', ...}, ...]
cur.execute("UPDATE items SET price = ? WHERE name = ?", (1.75, "pen"))
cur.execute("DELETE FROM items WHERE id = ?", (3,))
with con:                              # commit, or rollback on error
    con.execute("INSERT INTO items (name) VALUES (?)", ("cap",))
con.close()

Code Explained

INTEGER PRIMARY KEY — auto-assigned row id
? placeholders — values passed separately and safely
executemany() — one statement, many rows
(2,) — a one-item tuple, not (2)
with con: — transaction block

⚠ Common Mistakes

  • f"... WHERE name = '{name}'" — SQL injection; use ?
  • Forgetting commit() — inserts vanish when the program ends
  • Passing (5) instead of (5,) — not a tuple
  • Assuming with con: closes the connection — call close()

✓ Tips & Best Practices

  • Set row_factory = sqlite3.Row for readable rows
  • Use executemany() for bulk inserts
  • Iterate the cursor directly for big result sets
  • Move to SQLAlchemy or an ORM as the schema grows

Quick Summary

  • connect() — open database
  • execute(sql, params) — run SQL
  • ? — safe parameters
  • commit() — persist changes
