Importing & Modules

import · from import · as · relative imports · sys.path · __all__

Using Code from Other Files

Every .py file is a module. import loads a module once, caches it in sys.modules, and binds a name to it. from module import name pulls specific names in, and as sets an alias. Inside packages, relative imports with dots refer to sibling modules. The if __name__ == "__main__": guard runs code only when a file is executed directly.

Notes

  • A module runs top to bottom on first import only
  • Python searches sys.path in order
  • Relative imports work only inside packages
  • __all__ limits what from m import * exports
  • importlib.reload(m) re-runs a module (REPL only)

Import Forms

import math                        # bind the module
math.sqrt(16)                      # 4.0
import numpy as np                 # module alias
from math import pi, floor         # specific names
floor(pi)                          # 3
from os.path import join as pjoin  # alias one name
from math import *                 # every public name (avoid)
import importlib
json_mod = importlib.import_module("json")   # by string
# inside mypkg/reader.py:
from . import utils                # sibling module
from .utils import clean           # name from a sibling
from ..core import Engine          # parent package
if __name__ == "__main__":         # only when run directly
    main()
import sys
sys.path[:2]                       # first search locations

Code Explained

import x — use as x.name
from x import y — use y directly
. / .. — current / parent package
__name__ — "__main__" when run as a script, else module name

⚠ Common Mistakes

  • Naming your file random.py or json.py — shadows the real module
  • Running a package file directly with relative imports — ImportError; use python -m pkg.mod
  • Circular imports — two modules importing each other at top level
  • from x import * — unclear origins and name clashes

✓ Tips & Best Practices

  • Order imports: standard library, third-party, local
  • Run package code with python -m package.module
  • Import heavy modules inside the function that needs them
  • Let ruff or isort sort imports automatically

Quick Summary

  • import m — whole module
  • from m import x — one name
  • . imports — inside packages
  • __main__ guard — script-only code
