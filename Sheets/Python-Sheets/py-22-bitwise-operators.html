Bitwise Operators

& · | · ^ · ~ · << · >> · bin()

Working with Bits

Bitwise operators work on the binary digits of integers. &, |, and ^ combine bits pair by pair, ~ flips every bit, and << / >> shift bits left or right. They're used for flags, masks, permissions, and binary protocols. Because Python ints are unbounded, ~x equals -x - 1.

Notes

  • Integers only; floats raise TypeError
  • x << n = x * 2**n; x >> n = x // 2**n
  • Sets reuse & | ^ - for set operations
  • Precedence: looser than + and <<, tighter than ==
  • enum.IntFlag gives flags readable names

Bits & Flags

a, b = 12, 10                  # 0b1100, 0b1010
a & b                          # 8    0b1000  (both 1)
a | b                          # 14   0b1110  (either 1)
a ^ b                          # 6    0b0110  (differ)
~a                             # -13  (-(a + 1))
a << 2                         # 48   0b110000 (× 4)
a >> 2                         # 3    0b11    (÷ 4)
bin(a), f"{a:08b}"             # ('0b1100', '00001100')
READ, WRITE, EXEC = 4, 2, 1
perm = READ | WRITE            # 6   set flags
bool(perm & WRITE)             # True  test a flag
perm &= ~WRITE                 # 4   clear a flag
perm ^= EXEC                   # 5   toggle a flag

Code Explained

& — keeps bits set in both
| — keeps bits set in either
^ — keeps bits set in exactly one
~ — flips all bits (two's complement)
perm & WRITE — nonzero means the flag is on

⚠ Common Mistakes

  • & instead of and in conditions — works on bools but breaks on ints
  • 2 ^ 3 for powers — that's XOR (1); use 2 ** 3
  • Expecting ~5 to be 2 — it's -6
  • Shifting a float — TypeError

✓ Tips & Best Practices

  • Inspect values with f"{x:08b}"
  • Use enum.IntFlag instead of bare constants
  • Mask the low byte with x & 0xFF
  • Prefer sets when you just need membership flags

Quick Summary

  • & | ^ — AND, OR, XOR
  • ~x — equals -x - 1
  • << >> — multiply/divide by powers of 2
  • flags — set |=, clear &= ~, test &
