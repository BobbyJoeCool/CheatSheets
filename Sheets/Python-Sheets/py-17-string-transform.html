String Methods — Transform

replace() · split() · join() · strip() · upper() · lower() · title()

Changing Text

Transform methods return a new string and leave the original untouched. They cover case changes, trimming whitespace, replacing text, splitting a string into a list, and joining a list back into a string. split() and join() are opposites and appear in nearly every text-processing task.

Notes

  • Assign the result: s = s.strip()
  • split() with no argument splits on any whitespace run
  • strip(chars) removes characters, not a substring
  • removeprefix() / removesuffix() (3.9+) remove exact text
  • join() needs every item to be a str

Transform Methods

s = "  Hello, World  "
s.strip()                      # 'Hello, World'
"xxhixx".strip("x")            # 'hi'
"Hello".upper(), "Hello".lower()  # ('HELLO', 'hello')
"hello world".title()          # 'Hello World'
"a-b-c".replace("-", "+")      # 'a+b+c'
"a-b-c".replace("-", "", 1)    # 'ab-c'  (first only)
"a,b,,c".split(",")            # ['a', 'b', '', 'c']
"  a  b ".split()              # ['a', 'b']
"k=v=w".split("=", 1)          # ['k', 'v=w']
", ".join(["x", "y", "z"])     # 'x, y, z'
"one\ntwo".splitlines()        # ['one', 'two']
"report.pdf".removesuffix(".pdf")  # 'report'
"7".zfill(3), "ab".center(6, "*")  # ('007', '**ab**')

Code Explained

strip() — trims both ends; lstrip() / rstrip() one end
replace(old, new, count) — optional max replacements
split(sep, maxsplit) — limit the number of splits
sep.join(items) — the separator calls join

⚠ Common Mistakes

  • s.upper() without assigning — s is unchanged
  • "file.txt".strip(".txt") → 'file' by luck; it strips characters — use removesuffix()
  • ",".join([1, 2]) — TypeError; use map(str, items)
  • split(" ") keeps empty strings on double spaces; split() doesn't

✓ Tips & Best Practices

  • Chain calls: s.strip().lower().replace(" ", "_")
  • partition() is cleaner than split(sep, 1) for one cut
  • Use str.translate(str.maketrans(...)) for many single-char swaps
  • textwrap.fill(s, 60) wraps long text

Quick Summary

  • strip() — trim whitespace
  • replace() — swap substrings
  • split() / join() — str ↔ list
  • upper() lower() title() — change case
