ttk Themed Widgets

tkinter.ttk · ttk.Style · theme_use() · configure() · Treeview · Combobox · Progressbar

Modern-Looking Widgets

tkinter.ttk provides themed versions of the classic widgets plus extra ones such as Combobox, Progressbar, Treeview, and Notebook. Their appearance comes from a theme and styles, not per-widget color options. Pick a theme with Style.theme_use() and customize named styles with configure() and state-based map().

Notes

  • Available themes vary by OS: check theme_names()
  • ttk widgets ignore fg / bg; use styles
  • Some native themes (e.g. vista, aqua) ignore colors
  • Custom style names end with the base: Danger.TButton

Styles and ttk-Only Widgets

import tkinter as tk
from tkinter import ttk
root = tk.Tk()
style = ttk.Style()
style.theme_use("clam")
style.configure("TButton", padding=6, font=("Arial", 11))
style.configure("Danger.TButton", foreground="white", background="crimson")
ttk.Button(root, text="Delete", style="Danger.TButton").pack(pady=4)
combo = ttk.Combobox(root, values=["Small", "Medium", "Large"], state="readonly")
combo.current(1); combo.pack()          # combo.get() → 'Medium'
bar = ttk.Progressbar(root, length=200, maximum=100)
bar.pack(); bar["value"] = 40
tree = ttk.Treeview(root, columns=("qty",), show="headings", height=3)
tree.heading("qty", text="Quantity")
tree.insert("", "end", values=(5,))
tree.pack()
nb = ttk.Notebook(root)
nb.add(ttk.Frame(nb), text="General"); nb.pack(fill="both")
root.mainloop()

Code Explained

theme_use("clam") — a theme that honors colors
configure("TButton", ...) — every ttk Button
Danger.TButton — a derived style for some buttons
state="readonly" — Combobox without free typing
show="headings" — Treeview as a table

⚠ Common Mistakes

  • Passing bg="red" to a ttk widget — TclError: unknown option
  • Styling under a native theme that ignores colors — switch to clam
  • Naming a style without the base ("Danger") — not applied
  • Forgetting show="headings" — Treeview shows an empty tree column

✓ Tips & Best Practices

  • Start with style.theme_use("clam") for consistent styling
  • Use style.map() for hover and pressed colors
  • Bind <<ComboboxSelected>> to react to choices
  • Use Treeview with a scrollbar for tabular data
