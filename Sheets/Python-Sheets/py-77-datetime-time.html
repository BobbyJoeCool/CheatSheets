Dates, Times & Timezones

datetime · date · timedelta · strftime() · strptime() · zoneinfo

Working with Time

datetime provides date, time, datetime, and timedelta. A datetime is naive (no time zone) or aware (has tzinfo). Do arithmetic with timedelta, format with strftime(), and parse with strptime() or fromisoformat(). zoneinfo (3.9+) supplies real time zones with daylight-saving rules.

Notes

  • Naive and aware datetimes can't be compared
  • weekday(): Monday is 0; isoweekday(): Monday is 1
  • timedelta has days, seconds, microseconds — no months
  • datetime.utcnow() is deprecated (3.12); use now(timezone.utc)
  • Windows may need pip install tzdata for zoneinfo

datetime Essentials

from datetime import datetime, date, timedelta, timezone
from zoneinfo import ZoneInfo
today = date.today()                   # date(2026, 10, 1)
now = datetime.now()                   # naive local time
utc = datetime.now(timezone.utc)       # aware, UTC
d = datetime(2026, 10, 1, 14, 30)
d.year, d.month, d.weekday()           # (2026, 10, 3)  Mon=0
d + timedelta(days=7, hours=2)         # 2026-10-08 16:30
(date(2026, 12, 25) - date(2026, 10, 1)).days   # 85
d.strftime("%Y-%m-%d %H:%M")           # '2026-10-01 14:30'
d.strftime("%a %b %d")                 # 'Thu Oct 01'
datetime.strptime("01/10/2026", "%d/%m/%Y")  # parse text
datetime.fromisoformat("2026-10-01T14:30")   # ISO 8601
d.isoformat()                          # '2026-10-01T14:30:00'
ny = d.replace(tzinfo=ZoneInfo("America/New_York"))
ny.astimezone(ZoneInfo("Asia/Tokyo"))  # 2026-10-02 03:30+09:00

Code Explained

timedelta — add or subtract durations
date − date — a timedelta; .days gives the count
strftime — datetime → text; strptime — text → datetime
replace(tzinfo=...) — attach a zone to a naive time
astimezone() — convert between zones

⚠ Common Mistakes

  • Comparing naive and aware datetimes — TypeError
  • Adding months with timedelta(days=30) — wrong lengths
  • Format string not matching input in strptime — ValueError
  • Using wall-clock datetime.now() to time code — use perf_counter()

✓ Tips & Best Practices

  • Use dateutil.relativedelta for month/year arithmetic
  • Keep datetimes aware and in UTC internally
  • f-strings accept format codes: f"{d:%Y-%m-%d}"
  • Parse ISO strings with fromisoformat() — fast and strict
