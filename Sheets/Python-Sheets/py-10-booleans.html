True, False, and Truth Values

bool has exactly two values, True and False, and is a subclass of int (True == 1). Every object also has a truth value used by if, while, and, or, and not. Zero, None, and empty containers are falsy; almost everything else is truthy. bool(x) shows an object's truth value.

Notes

  • Capitalized: True, False (true is a NameError)
  • and / or return one of their operands, not always a bool
  • not always returns a real bool
  • Classes set truthiness with __bool__ or __len__
  • sum() over bools counts the True values

Truthiness in Practice

bool(0), bool(0.0), bool("")   # (False, False, False)
bool([]), bool({}), bool(None) # (False, False, False)
bool(42), bool("0"), bool([0]) # (True, True, True)
True + True                    # 2
sum([True, False, True])       # 2  (count Trues)
isinstance(True, int)          # True
items = []
if not items:                  # idiomatic empty check
    print("empty")             # empty
name = "" or "Guest"           # 'Guest'
5 > 3 and "yes"                # 'yes'
1 < 5 < 10                     # True  (chained)

Code Explained

bool(x) — the truth value Python uses in conditions
if not items: — true for any empty container
a or b — returns a if truthy, else b
a and b — returns a if falsy, else b
1 < 5 < 10 — means 1 < 5 and 5 < 10

⚠ Common Mistakes

  • if x == True: — just write if x:
  • bool("False") is True — compare the text instead
  • if not x: when 0 is valid — use if x is None:
  • Writing true or TRUE — NameError

✓ Tips & Best Practices

  • Test emptiness with if not seq:, not len(seq) == 0
  • Use any() / all() with a generator for checks over items
  • x or default works only when falsy values are invalid input
  • Give custom classes __bool__ for meaningful truthiness

Quick Summary

  • True / False — subclass of int
  • falsy — 0, None, empty containers
  • and / or — return an operand
  • any() / all() — test many values
