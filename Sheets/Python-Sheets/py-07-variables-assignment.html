Names Bound to Objects

A Python variable is a name bound to an object; assignment never copies data. = creates the name or rebinds it, with no declaration keyword and no type required. The same name can later refer to an object of any type. Constants exist only as a naming convention (ALL_CAPS); nothing stops reassignment.

Rules

  • Names are case-sensitive: total ≠ Total
  • Letters, digits, _; can't start with a digit
  • Keywords are reserved: see keyword.kwlist
  • del x removes the name, not necessarily the object
  • Two names can share one object; mutations show through both

Assignment Forms

count = 10                     # bind a name to an int
count = "ten"                  # rebind to a str (allowed)
name, age = "Ana", 30          # multiple assignment
x = y = 0                      # chained: both refer to 0
a, b = 1, 2
a, b = b, a                    # swap: a=2, b=1
first, *rest = [1, 2, 3, 4]    # first=1, rest=[2, 3, 4]
MAX_RETRIES = 3                # constant by convention
total: int = 0                 # annotation, not enforced
nums = [1, 2]
alias = nums                   # same list, two names
alias.append(3); print(nums)   # [1, 2, 3]
del count; print(count)        # NameError

Code Explained

a, b = 1, 2 — tuple packing on the right, unpacking on the left
*rest — collects leftover items into a list
x: int = 0 — type hint for tools; runtime ignores it
alias = nums — copies the reference, not the list
del — unbinds the name; later use raises NameError

⚠ Common Mistakes

  • a = b = [] then appending — both names share one list
  • Naming variables list, str, id — shadows the built-ins
  • Expecting b = a to copy a list — use a.copy() or list(a)
  • Reading a name before assigning it — NameError or UnboundLocalError

✓ Tips & Best Practices

  • Pick descriptive names instead of explaining them in comments
  • Swap with a, b = b, a — no temp variable needed
  • Use _ for throwaway values: for _ in range(3):
  • Check sharing with a is b or id(a) == id(b)

Quick Summary

  • = — binds a name, never copies
  • a, b = b, a — unpack and swap
  • UPPER_CASE — constant by convention only
  • del x — removes the name
