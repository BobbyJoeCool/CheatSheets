Immutable Unicode Text

A str is an immutable sequence of Unicode code points. Single and double quotes are interchangeable, triple quotes span lines, and prefixes change meaning: r for raw, f for formatted, b for bytes. Because strings are immutable, every method that seems to modify a string actually returns a new one.

Notes

  • No separate char type: "a" is a str of length 1
  • Adjacent literals join: "a" "b" → "ab"
  • Strings are hashable, so they work as dict keys
  • str holds text; bytes holds raw data — encode() / decode() convert
  • len() counts code points, not bytes

String Literals & Basics

s1 = 'single'; s2 = "double"       # same type
quote = "It's fine"                # mix quotes to skip escapes
path = r"C:\new\table"             # raw: backslashes kept
text = """Line one
Line two"""                        # newline is part of the string
len("héllo")                       # 5
"ab" + "cd", "ab" * 3              # ('abcd', 'ababab')
"py" "thon"                        # 'python'
s = "cat"
s[0] = "b"                         # TypeError: immutable
s = "b" + s[1:]                    # 'bat'  (new string)
"ell" in "hello"                   # True
"café".encode("utf-8")             # b'caf\xc3\xa9'
b"caf\xc3\xa9".decode()            # 'café'

Code Explained

r"..." — backslashes are not escapes (paths, regex)
"""...""" — multi-line literal; also used for docstrings
s[0] = ... — fails; build a new string instead
encode() — str → bytes; decode() — bytes → str

⚠ Common Mistakes

  • s[0] = "x" — strings are immutable; slice and rebuild
  • += in a loop to build big text — slow; collect parts and "".join()
  • r"C:\" — a raw string can't end in one backslash
  • Sorting mixed-case words — uppercase sorts before lowercase

✓ Tips & Best Practices

  • Use textwrap.dedent() to clean indented triple-quoted text
  • Compare case-insensitively with a.casefold() == b.casefold()
  • Prefer pathlib.Path over raw path strings
  • Always pass encoding="utf-8" when crossing to bytes or files

Quick Summary

  • str — immutable Unicode text
  • r"" / f"" / b"" — raw, formatted, bytes
  • "".join(parts) — efficient building
  • encode() / decode() — str ↔ bytes
