Canvas & Drawing

Canvas · create_line() · create_rectangle() · create_oval() · create_text() · tags · move()

2D Drawing Surface

A Canvas is a drawing area for lines, shapes, text, and images. Each create_* call returns an item id, and items can also share tags so you can change many at once. Move, recolor, resize, or delete items after drawing them, which makes the canvas suitable for charts, diagrams, and simple games when combined with after() for animation.

Notes

  • Origin (0, 0) is the top-left; y grows downward
  • Shapes are defined by bounding-box coordinates
  • Tag "all" refers to every item
  • Later items draw on top; use tag_raise() / tag_lower()
  • Keep a reference to PhotoImage objects or they vanish

Draw, Update, Animate

import tkinter as tk
root = tk.Tk()
c = tk.Canvas(root, width=300, height=200, bg="white")
c.pack()
c.create_line(10, 10, 290, 10, fill="gray", width=2)
box = c.create_rectangle(20, 30, 120, 90, fill="skyblue", outline="navy")
c.create_oval(150, 30, 210, 90, fill="tomato", tags="ball")
c.create_polygon(240, 90, 270, 30, 300, 90, fill="gold")
c.create_text(150, 150, text="Score: 0", font=("Arial", 14), tags="score")
c.itemconfig("score", text="Score: 10")    # update by tag
c.move("ball", 5, 0)                        # shift by dx, dy
c.coords(box, 20, 30, 140, 100)             # new bounding box
def tick():
    c.move("ball", 3, 0)
    if c.coords("ball")[2] < 300:           # right edge
        root.after(30, tick)                # ~33 frames per second
tick()
c.tag_bind("ball", "<Button-1>", lambda e: c.delete("ball"))
root.mainloop()

Code Explained

create_* — returns an int id
tags="ball" — name items for later
itemconfig — change color, text, width
coords() — read or set an item's points
after() loop — animation without blocking

⚠ Common Mistakes

  • PhotoImage created in a function and not stored — image disappears
  • Animating with while + sleep — window freezes; use after()
  • Expecting y to grow upward — it grows down
  • Deleting by tag when several items share it — all of them go

✓ Tips & Best Practices

  • Use tags to group and move composite objects together
  • c.delete("all") clears the canvas for redraws
  • Use find_overlapping() for simple collision checks
  • Add scrollbars with scrollregion= and xview / yview

Quick Summary

  • create_* — draw items
  • tags — address groups
  • move / coords / itemconfig — update
  • after() — animate
