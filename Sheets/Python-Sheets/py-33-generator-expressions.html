Generator Expressions

(x for x in it) · lazy evaluation · sum() · any() · all() · next()

Lazy Comprehensions

A generator expression (expr for item in iterable) looks like a list comprehension with parentheses, but it produces items lazily, one at a time, without building a list in memory. It's ideal for feeding sum(), any(), all(), max(), and join(), or for streaming large files. A generator can be consumed only once.

Notes

  • Parentheses can be dropped when it's the only argument
  • len() and indexing don't work on generators
  • next(gen, default) avoids StopIteration
  • Generator functions with yield: Sheet 45
  • Items are computed when requested, not upfront

Generator Expressions

nums = range(1_000_000)
sum(n * n for n in nums)           # no list is built
gen = (n * 2 for n in [1, 2, 3])
gen                                # <generator object <genexpr> ...>
next(gen), next(gen)               # (2, 4)
list(gen)                          # [6]  (what's left)
list(gen)                          # []   (exhausted)
any(w.startswith("x") for w in ["ax", "xy"])  # True
max(len(w) for w in ["a", "abc"])  # 3
",".join(str(n) for n in range(3)) # '0,1,2'
import sys
sys.getsizeof([n for n in range(10**6)])  # ~8 MB
sys.getsizeof((n for n in range(10**6)))  # ~200 bytes
lines = (l.strip() for l in open("app.log"))
errors = (l for l in lines if "ERROR" in l)  # pipeline

Code Explained

sum(... for ...) — single argument, so no extra parens
next(gen) — pulls one item
exhausted — a second pass yields nothing
any() — stops at the first True
pipeline — each stage pulls from the previous one

⚠ Common Mistakes

  • Looping over the same generator twice — the second loop is empty
  • len(gen) — TypeError; count with sum(1 for _ in gen)
  • Printing a generator to see values — wrap in list() first
  • Closing a file before the generator reading it is consumed

✓ Tips & Best Practices

  • Use generators with sum, any, all, max, join
  • Chain generator stages to process big files line by line
  • Take the first n items with itertools.islice(gen, n)
  • Use a list when you need the results more than once

Quick Summary

  • (x for x in xs) — lazy sequence
  • one pass — then exhausted
  • next(gen, default) — safe single item
  • low memory — ideal for streaming
