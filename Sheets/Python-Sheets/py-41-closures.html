Closures & Nested Functions

nested def · closure · nonlocal · __closure__ · factory functions

Functions That Remember

A nested function can read variables from the function that encloses it. When the inner function is returned and outlives the outer call, it keeps those variables alive; that pairing of function plus captured variables is a closure. Use nonlocal to rebind a captured variable. Closures give you lightweight state and function factories.

Notes

  • Closures capture variables, not values (late binding)
  • Reading a captured name needs no keyword
  • Rebinding it needs nonlocal
  • Mutating a captured list works without nonlocal

Factories, State, Late Binding

def make_multiplier(factor):
    def multiply(x):
        return x * factor          # factor is captured
    return multiply
double = make_multiplier(2)
triple = make_multiplier(3)
double(5), triple(5)               # (10, 15)

def counter():
    n = 0
    def inc():
        nonlocal n                 # rebind enclosing n
        n += 1
        return n
    return inc
c = counter(); c(); c()            # 2

fns = [lambda: i for i in range(3)]
[f() for f in fns]                 # [2, 2, 2]  late binding!

Code Explained

make_multiplier — a factory that returns configured functions
each call to the factory creates a new closure
nonlocal n — without it, n += 1 raises UnboundLocalError
late binding — every lambda sees the final i

⚠ Common Mistakes

  • Building lambdas in a loop — all share the last value; bind with i=i
  • Rebinding without nonlocal — UnboundLocalError
  • Assuming each closure copies values — it shares the variable
  • Hiding lots of state in nested functions — use a class

✓ Tips & Best Practices

  • Use functools.partial(f, x) for simple pre-filled arguments
  • Inspect captured values: f.__closure__[0].cell_contents
  • Prefer a class once you need more than one operation
  • Closures are the building block for decorators

Quick Summary

  • closure — function + captured variables
  • factory — returns configured functions
  • nonlocal — rebind captured name
  • late binding — captures variables, not values
