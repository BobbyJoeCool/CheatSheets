Built-in Dict Methods

Dict methods read, insert, merge, and remove entries. keys(), values(), and items() return live views that reflect later changes. setdefault() inserts only when a key is missing, update() merges another mapping, and pop() removes a key and returns its value, with an optional default to avoid KeyError.

Notes

  • Views update when the dict changes
  • keys() views support set operators
  • popitem() removes the last-inserted pair
  • Changing the dict's size while looping raises RuntimeError
  • copy() is shallow

Dict Methods

d = {"a": 1, "b": 2}
d.keys()                       # dict_keys(['a', 'b'])
d.values()                     # dict_values([1, 2])
d.items()                      # dict_items([('a', 1), ('b', 2)])
d.get("z", 0)                  # 0
d.setdefault("c", 3)           # 3  (inserted)
d.setdefault("a", 99)          # 1  (kept existing)
d.update({"b": 20, "d": 4})    # {'a': 1, 'b': 20, 'c': 3, 'd': 4}
d.pop("d")                     # 4
d.pop("zz", None)              # None  (no KeyError)
d.popitem()                    # ('c', 3)  last inserted
d.copy()                       # {'a': 1, 'b': 20}
d.clear()                      # {}

Code Explained

views — iterate, len(), in, but no indexing
setdefault(k, v) — get, inserting v if missing
update() — merges; incoming values win
pop(k, default) — remove safely

⚠ Common Mistakes

  • Deleting keys while iterating — loop over list(d) instead
  • d.pop(k) with no default on a missing key — KeyError
  • setdefault(k, expensive()) — the default is built every call
  • Holding a view and expecting a snapshot — views are live

✓ Tips & Best Practices

  • Use set operators on keys() to compare dicts
  • d.update(port=8080) accepts keyword arguments
  • Prefer defaultdict over repeated setdefault
  • Snapshot with list(d.items()) before mutating

Quick Summary

  • keys / values / items — live views
  • get / setdefault — safe access
  • update — merge
  • pop / popitem / clear — remove
