Django · Flask · FastAPI · routes · WSGI vs ASGI · Gunicorn · Uvicorn

Serving the Web from Python

A web framework maps a URL route to a Python function that takes a request and returns a response. Django is "batteries included" (ORM, admin, auth, templates); Flask is a small core you extend; FastAPI builds async JSON APIs from type hints. Apps run behind a WSGI (sync) or ASGI (async) server.

Notes

  • Full coverage: the Django Reference set (70 sheets)
  • Install into a virtual environment (Sheet 02)
  • Built-in dev servers are not for production
  • Never commit secret keys — read them from env vars

One Route, Three Frameworks

# Flask — pip install flask            (WSGI, small core)
from flask import Flask
app = Flask(__name__)

@app.get("/hello/<name>")
def hello(name):
    return {"msg": f"Hello, {name}"}        # dict → JSON
# run: flask --app app run --debug

# FastAPI — pip install "fastapi[standard]"   (ASGI, async)
from fastapi import FastAPI
api = FastAPI()

@api.get("/hello/{name}")
async def hello(name: str, times: int = 1):   # hints validate input
    return {"msg": f"Hello, {name} " * times}
# run: fastapi dev main.py              → docs at /docs

# Django — pip install django            (full stack)
# django-admin startproject mysite; python manage.py startapp blog
from django.http import JsonResponse
def hello(request, name):                   # blog/views.py
    return JsonResponse({"msg": f"Hello, {name}"})
# urls.py: path("hello/<str:name>/", views.hello)

Code Explained

@app.get(...) — register a route for GET
<name> / {name} — path parameter
times: int = 1 — FastAPI query param, converted and checked
JsonResponse — Django views return response objects
path() — Django routes live in urls.py

The Pythonic Way

  • Hand-built JSON strings → return a dict / JsonResponse
  • SQL built with f-strings → the ORM or ? placeholders
  • DEBUG = True in production → settings from env vars

⚠ Common Mistakes

  • Deploying with the dev server or DEBUG on
  • Blocking calls inside async def routes — stalls every request
  • Hard-coding secret keys and passwords in source
  • Rebuilding Django's admin and auth by hand in Flask

✓ Tips & Best Practices

  • Pick Django for full sites, FastAPI for APIs, Flask for small apps
  • Use plain def routes unless the code awaits I/O
  • Run behind Gunicorn / Uvicorn and a reverse proxy
  • Test with each framework's test client
