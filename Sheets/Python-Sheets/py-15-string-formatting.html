f-strings & Format Specs

f-strings (3.6+) embed expressions inside {} and are the standard way to format text. After a colon, a format spec controls fill, alignment, width, grouping, precision, and type: {value:fill align width , .precision type}. str.format() uses the same spec language; % formatting is legacy but still common in older code and logging.

Notes

  • {x!r} uses repr(), {x!s} uses str()
  • {x=} prints the expression and value (3.8+)
  • {{ and }} produce literal braces
  • Nested specs work: f"{x:{width}}"
  • 3.12+ allows the same quote type inside f-string braces

Formatting Examples

name, n, pi = "Ana", 1234.5, 3.14159
f"Hi {name}!"                  # 'Hi Ana!'
f"{pi:.2f}"                    # '3.14'
f"{n:,.2f}"                    # '1,234.50'
f"{0.256:.1%}"                 # '25.6%'
f"[{name:<6}]"                 # '[Ana   ]'
f"[{name:>6}]"                 # '[   Ana]'
f"[{name:*^7}]"                # '[**Ana**]'
f"{42:05d}"                    # '00042'
f"{255:#x}, {5:08b}"           # '0xff, 00000101'
f"{1e6:.2e}"                   # '1.00e+06'
f"{name!r}", f"{n = }"         # ("'Ana'", 'n = 1234.5')
"{} is {}".format("x", 3)      # 'x is 3'
"%s has %d" % ("Ana", 3)       # 'Ana has 3'

Code Explained

.2f — fixed point, 2 decimals
, — thousands separator (_ also works)
< > ^ — left, right, center within the width
*^7 — fill with *, center, width 7
#x — hex with 0x prefix; 08b — zero-padded binary

⚠ Common Mistakes

  • Forgetting the f prefix — braces print literally
  • f"{name:.2f}" on a str — ValueError
  • "%s" % (x) with a tuple x — wrap it: (x,)
  • Formatting to a string, then doing math with it

✓ Tips & Best Practices

  • Debug with f"{total=}"
  • Build tables with fixed widths: f"{item:<20}{price:>8.2f}"
  • Use string.Template for user-supplied templates
  • logging uses % style lazily: log.info("%s", x)

Quick Summary

  • f"{x}" — embed expressions
  • {x:.2f} — precision
  • {x:>10} — width and alignment
  • {x:,} — thousands separators
