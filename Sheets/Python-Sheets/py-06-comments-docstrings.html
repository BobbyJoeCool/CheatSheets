Comments & Docstrings

# comments · docstrings · __doc__ · help() · doctest · PEP 257

Comments vs Docstrings

Comments start with # and run to the end of the line; Python ignores them completely. Docstrings are string literals placed first in a module, class, or function. Unlike comments, they are kept at runtime in __doc__, where help(), IDE hover text, and documentation generators read them. Python has no block-comment syntax, so use consecutive # lines.

Notes

  • Comments explain why; the code already shows what
  • A triple-quoted string that isn't first in a body is a discarded expression, not a comment
  • PEP 257 defines docstring conventions
  • Common styles: Google, NumPy, reStructuredText (Sphinx)
  • # noqa and # type: ignore are tool directives

Comments & a Google-Style Docstring

# Full-line comment
x = 10  # inline comment: two spaces before #

def area(w: float, h: float) -> float:
    """Return the area of a rectangle.

    Args:
        w: Width in meters.
        h: Height in meters.

    Returns:
        Area in square meters.

    >>> area(2, 3)
    6
    """
    return w * h

print(area.__doc__.splitlines()[0])  # Return the area of a rectangle.
help(area)                           # shows the full docstring

Code Explained

# — ignored to the end of the line
"""...""" — first statement in the body, stored in __doc__
summary line — one sentence, then a blank line
Args: / Returns: — Google-style sections
>>> — doctest example; run python -m doctest file.py -v

⚠ Common Mistakes

  • Using ''' blocks as comments — they're string expressions and may be mistaken for docstrings
  • Comments that restate code: i += 1 # add 1 to i
  • Docstring placed after other code — it's no longer the docstring
  • Stale comments — a wrong comment is worse than none

✓ Tips & Best Practices

  • Document every public module, class, and function
  • Write the first line as a short imperative summary
  • Add doctest examples to small, pure functions
  • Toggle comments with Ctrl+/ (Cmd+/ on macOS) in most editors

Quick Summary

  • # — comment, discarded at runtime
  • """docstring""" — first statement, kept in __doc__
  • help(obj) — reads docstrings
  • python -m doctest — tests docstring examples
