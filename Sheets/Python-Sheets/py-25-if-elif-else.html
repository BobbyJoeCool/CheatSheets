if/elif/else Statements

if · elif · else · nested if · pass

Branching

if runs its block when the condition is truthy. elif checks further conditions in order, and only the first true branch runs. else catches everything left over. A condition can be any expression, judged by truthiness. Every block needs at least one statement, so use pass as a placeholder.

Notes

  • The keyword is elif, not else if
  • Each header ends with a colon
  • elif and else are optional; else must be last
  • Conditions short-circuit with and / or
  • For many fixed values, see match (Sheet 26) or a dict lookup

if / elif / else

score = 82
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"                # this branch runs
elif score >= 70:
    grade = "C"
else:
    grade = "F"
print(grade)                   # B

if not items: ...              # empty check
if 0 <= x < 10: ...            # range check
if role in {"admin", "root"}:
    pass                       # placeholder body
if user is not None and user.active:
    print("welcome")

Code Explained

order matters — >= 90 must come before >= 80
... — Ellipsis; a valid one-line body like pass
in {...} — compare against several values
is not None and ... — guard before using attributes

⚠ Common Mistakes

  • else if — SyntaxError; use elif
  • Ordering ranges wrong — >= 70 first catches every grade above it
  • if x == True: — just if x:
  • Deep nesting — flatten with and or early returns

✓ Tips & Best Practices

  • Use guard clauses: if not valid: return at the top
  • Put the most specific condition first
  • Replace value-to-value chains with a dict
  • Keep nesting to two levels where possible

Quick Summary

  • if — run when truthy
  • elif — next check; first true wins
  • else — fallback
  • pass — empty-block placeholder
