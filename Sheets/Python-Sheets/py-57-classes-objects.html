Blueprints and Instances

A class is a blueprint that bundles data (attributes) with behavior (methods). Calling the class creates an instance. Every method receives the instance as its first parameter, named self by convention, which is how methods read and change that object's data. Attributes set on self belong to one instance; attributes in the class body are shared.

Notes

  • Class names use PascalCase
  • Everything in Python is an object of some class
  • self is passed automatically: rex.sit() → Dog.sit(rex)
  • Add __repr__ for readable debugging output
  • Data-only classes: see @dataclass on Sheet 58

A Complete Small Class

class Dog:
    """A dog with a name and tricks."""
    species = "Canis familiaris"       # class attribute (shared)

    def __init__(self, name, age):
        self.name = name               # instance attributes
        self.age = age
        self.tricks = []

    def add_trick(self, trick):        # method
        self.tricks.append(trick)

    def __repr__(self):
        return f"Dog({self.name!r}, {self.age})"

rex = Dog("Rex", 3)                    # create an instance
rex.add_trick("sit")
rex.name, rex.tricks                   # ('Rex', ['sit'])
rex                                    # Dog('Rex', 3)

Code Explained

class Dog: — defines the blueprint
__init__ — sets up each new instance
self.tricks = [] — a separate list per dog
rex.add_trick("sit") — calls the method on rex
__repr__ — what the REPL shows for the object

⚠ Common Mistakes

  • Leaving out self in a method — TypeError about arguments
  • Writing name = name instead of self.name = name in __init__
  • Mutable class attribute tricks = [] — shared by every dog
  • rex = Dog without () — you get the class, not an instance

✓ Tips & Best Practices

  • Always give classes a __repr__
  • Keep each class focused on one responsibility
  • Use @dataclass when a class mainly holds data
  • Initialize every attribute in __init__, even to None

Quick Summary

  • class — define a type
  • Dog(...) — create an instance
  • self.attr — per-instance data
  • methods — functions that take self
