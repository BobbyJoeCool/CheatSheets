Integers

int literals · 0x · 0o · 0b · int() · arbitrary precision · _ separators

Arbitrary-Precision Integers

int stores whole numbers with arbitrary precision: there is no overflow, only memory limits. Literals can be decimal, hex, octal, or binary, and underscores improve readability. int() converts strings and floats. / always returns a float, while // and % keep integer results.

Notes

  • No MAX_INT; sys.maxsize is the largest container index
  • Leading zeros like 012 are a SyntaxError
  • bool is a subclass of int: True == 1
  • int → str conversion is capped at 4300 digits by default (3.11+)
  • // floors toward negative infinity, not toward zero

Integer Operations

n = 1_000_000                  # 1000000 (underscores ignored)
0xFF, 0o17, 0b1010             # (255, 15, 10)
2 ** 100                       # 1267650600228229401496703205376
int("42"), int("  -7 ")        # (42, -7)  whitespace ok
int("ff", 16)                  # 255
int("0b101", 0)                # 5  (base 0 reads the prefix)
int(3.99), int(-3.99)          # (3, -3)  truncates toward zero
hex(255), oct(8), bin(5)       # ('0xff', '0o10', '0b101')
(255).bit_length()             # 8
abs(-5), pow(2, 10, 1000)      # (5, 24)
7 // 2, -7 // 2, 7 % 3         # (3, -4, 1)
divmod(17, 5)                  # (3, 2)
f"{n:,}"                       # '1,000,000'

Code Explained

1_000_000 — underscores are visual only
int(s, base) — parse bases 2–36; base 0 uses the prefix
int(float) — truncates; use round() to round
pow(b, e, m) — fast modular exponent
(255).bit_length() — parentheses needed on a literal

⚠ Common Mistakes

  • int("3.5") — ValueError; use int(float(s))
  • Expecting int() to round — it truncates: int(2.9) is 2
  • -7 // 2 is -4, not -3 — floor division rounds down
  • Writing 010 for octal — SyntaxError; use 0o10

✓ Tips & Best Practices

  • Group digits in big literals: 10_000_000
  • Use math.isqrt() instead of int(math.sqrt()) for exact roots
  • f"{n:,}" adds thousands separators
  • int(s, 0) accepts 0x, 0o, 0b input automatically

Quick Summary

  • int — unbounded whole numbers
  • 0x 0o 0b — hex, octal, binary literals
  • int(s, base) — parse from text
  • // % divmod — integer division tools
