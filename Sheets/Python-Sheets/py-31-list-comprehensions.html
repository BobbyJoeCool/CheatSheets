List Comprehensions

[x for x in it] · if filter · if-else · nested comprehensions

Building Lists in One Expression

A list comprehension [expr for item in iterable if condition] builds a new list in one expression. It replaces a loop with append(), is usually faster, and reads left to right. A filtering if goes at the end; a value choice a if c else b goes at the front. Multiple for clauses nest in the same order as written loops.

Notes

  • Always produces a new list
  • The loop variable doesn't leak out (Python 3)
  • Use parentheses instead for a lazy generator (Sheet 33)
  • Dict and set versions: Sheet 32
  • Keep them short enough to read in one glance

Comprehension Examples

nums = [1, 2, 3, 4, 5]
[n * n for n in nums]                  # [1, 4, 9, 16, 25]
[n for n in nums if n % 2 == 0]        # [2, 4]
["even" if n % 2 == 0 else "odd" for n in nums[:3]]
# ['odd', 'even', 'odd']
[c.upper() for c in "abc"]             # ['A', 'B', 'C']
[w for w in "a bb ccc".split() if len(w) > 1]  # ['bb', 'ccc']
[(x, y) for x in [1, 2] for y in "ab"]
# [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]
matrix = [[1, 2], [3, 4]]
[v for row in matrix for v in row]     # [1, 2, 3, 4]
[[r[i] for r in matrix] for i in range(2)]  # [[1, 3], [2, 4]]
[int(s) for s in "1,2,3".split(",")]   # [1, 2, 3]

Code Explained

map — transform each item
filter — if at the end keeps matching items
choose — if/else at the front picks a value
two fors — outer loop first, like nested loops
nested comprehension — builds a list of lists

⚠ Common Mistakes

  • [print(x) for x in xs] — use a plain for loop for side effects
  • [x for x in xs if c else y] — SyntaxError; ternary goes before for
  • Reversing nested for order — outer loop comes first
  • [[0] * 3] * 2 for a grid — rows are shared; use a comprehension

✓ Tips & Best Practices

  • Feed sum() / any() a generator instead of a list
  • Name the loop variable for the item: user, not x
  • Split long comprehensions over lines inside the brackets
  • Use := to avoid calling a function twice

Quick Summary

  • [f(x) for x in xs] — map
  • if at end — filter
  • a if c else b at front — choose
  • multiple for — nested order
