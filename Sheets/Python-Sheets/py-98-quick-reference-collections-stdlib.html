⚠ Common Mistakes

  • Modifying a list while iterating over it
  • sort() returns None — use sorted() when you need the result
  • Opening files without encoding="utf-8" or without with

✓ Tips & Best Practices

  • Use pathlib for paths and dataclasses for plain records
  • Reach for Counter, defaultdict and itertools before writing loops
  • Add type hints and run a checker (mypy / pyright)
