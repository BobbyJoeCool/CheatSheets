Collections Module

namedtuple · Counter · defaultdict · deque · ChainMap · OrderedDict

Specialized Containers

The collections module adds containers for common jobs. Counter counts hashable items, defaultdict supplies missing values, deque gives fast appends and pops at both ends, namedtuple creates lightweight records, and ChainMap layers several dicts into one view without copying.

Notes

  • Counter returns 0 for missing keys, no KeyError
  • deque(maxlen=n) drops old items automatically
  • deque indexing in the middle is O(n)
  • OrderedDict still offers move_to_end()
  • All are in the standard library; no install needed

collections in Action

from collections import Counter, defaultdict, deque, namedtuple, ChainMap
c = Counter("mississippi")
c.most_common(2)                   # [('i', 4), ('s', 4)]
c["s"], c["z"]                     # (4, 0)  missing → 0
Counter(a=3) + Counter(a=1, b=2)   # Counter({'a': 4, 'b': 2})
dd = defaultdict(int)
for w in "a b a".split(): dd[w] += 1   # {'a': 2, 'b': 1}
q = deque([1, 2, 3], maxlen=3)
q.appendleft(0)                    # deque([0, 1, 2])  3 dropped
q.rotate(1)                        # deque([2, 0, 1])
Point = namedtuple("Point", ["x", "y"])
Point(1, 2).x                      # 1
defaults = {"theme": "light"}; user = {"theme": "dark"}
ChainMap(user, defaults)["theme"]  # 'dark'

⚠ Common Mistakes

  • Using a list as a queue — pop(0) is O(n); use deque.popleft()
  • Expecting Counter subtraction to keep negatives — - drops them
  • Indexing deep into a deque — slow in the middle
  • Mutating a namedtuple field — it's immutable; use _replace()

✓ Tips & Best Practices

  • Count words: Counter(text.split()).most_common(10)
  • Keep the last N log lines: deque(lines, maxlen=N)
  • Use typing.NamedTuple or a dataclass for richer records
  • ChainMap(cli, env, defaults) for layered settings

Quick Summary
