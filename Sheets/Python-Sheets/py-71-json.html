Sheet 71

JSON

json.load() · json.dump() · json.loads() · json.dumps() · indent · default=

JavaScript Object Notation

The json module converts between Python objects and JSON text. dumps() and loads() work with strings; dump() and load() work with open files. Dicts become JSON objects, lists become arrays, and None, True, False become null, true, false. Types JSON lacks, like datetime and set, need a default= function.

Notes

  • The s in dumps / loads means "string"
  • JSON object keys are always strings
  • Tuples are written as arrays and load back as lists
  • JSON requires double quotes
  • Invalid input raises json.JSONDecodeError

Round-Trip Example

import json
data = {"name": "Ana", "age": 30, "tags": ["admin"], "active": True}
s = json.dumps(data)               # '{"name": "Ana", "age": 30, ...}'
json.dumps(data, indent=2)         # pretty-printed
json.dumps({"b": 1, "a": 2}, sort_keys=True)  # '{"a": 2, "b": 1}'
json.loads('{"x": [1, 2], "ok": null}')  # {'x': [1, 2], 'ok': None}
with open("user.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2)   # write to a file
with open("user.json", encoding="utf-8") as f:
    loaded = json.load(f)          # read from a file
loaded == data                     # True
from datetime import date
json.dumps({"d": date(2026, 10, 1)}, default=str)  # '{"d": "2026-10-01"}'
json.dumps({"city": "Zürich"}, ensure_ascii=False) # keeps ü
json.loads("{'a': 1}")             # JSONDecodeError (single quotes)

Code Explained

indent=2 — readable output
sort_keys=True — stable output for diffs
dump / load — file versions
default=str — fallback for unknown types
ensure_ascii=False — write non-ASCII characters as-is

⚠ Common Mistakes

  • Mixing up dump and dumps — one needs a file, one returns a string
  • Expecting int keys back — {1: "a"} loads as {"1": "a"}
  • Writing Python-style text ('single quotes', True) — invalid JSON
  • Dumping datetime or set — TypeError: not JSON serializable

✓ Tips & Best Practices

  • Validate and pretty-print from the shell: python -m json.tool file.json
  • Catch json.JSONDecodeError when parsing outside input
  • Convert sets with default=list or sorted(s) first
  • Use dataclasses.asdict() to serialize dataclasses

Quick Summary

  • dumps / loads — strings
  • dump / load — files
  • indent= — pretty output
  • default= — custom types
