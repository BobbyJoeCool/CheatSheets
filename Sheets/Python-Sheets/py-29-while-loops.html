while Loops

while · while-else · while True · sentinel loops

Condition-Controlled Loops

while repeats its block as long as the condition is truthy, checking it before each pass. Use it when you don't know the number of iterations in advance: polling, reading until a sentinel, or retrying. Something in the body must eventually make the condition false or break, or the loop never ends. else runs when the condition turns false, not after break.

Notes

  • No do-while; use while True + break
  • Condition uses truthiness: while queue:
  • Ctrl+C stops a runaway loop (KeyboardInterrupt)
  • Prefer for when looping over a collection
  • Don't loop on float equality

while Patterns

n = 3
while n > 0:
    print(n)                   # 3 2 1
    n -= 1

while True:                    # loop-and-a-half
    cmd = input("> ")
    if cmd == "quit":
        break
    print(f"ran {cmd}")

attempts = 0
while attempts < 3:
    attempts += 1
    if connect():
        break
else:
    print("gave up")           # only if never broke

while (line := f.readline()):  # until ''
    handle(line)

Code Explained

counter — update the variable every pass
while True — emulates do-while; exit with break
while ... else — runs when retries run out
walrus — read and test in one step

⚠ Common Mistakes

  • Forgetting to update the loop variable — infinite loop
  • Index-based while i < len(xs) — use for instead
  • while x != 1.0: with floats — may never be exactly equal
  • Thinking else runs after break — it runs only when no break happened

✓ Tips & Best Practices

  • Make while True exits obvious and near the top
  • Always cap retries and add a delay between attempts
  • Use while stack: / while queue: for work lists
  • Use time.monotonic() for timeout loops

Quick Summary

  • while cond: — repeat while truthy
  • while True + break — do-while style
  • else — runs if loop wasn't broken
  • update state — or it never ends
