Built-in List Methods

List methods change the list in place and most return None. Add items with append(), extend(), and insert(); remove them with remove() (by value), pop() (by index), and clear(). sort() and reverse() reorder, while index() and count() answer questions without changing anything.

Notes

  • append(x) adds x as one item
  • extend(it) adds each item of an iterable
  • pop() is the only remover that returns the item
  • sort() is stable; equal items keep their order
  • For a new sorted list, use sorted()

Methods in Order

xs = [3, 1, 2]
xs.append(4)                   # [3, 1, 2, 4]
xs.extend([5, 6])              # [3, 1, 2, 4, 5, 6]
xs.insert(0, 0)                # [0, 3, 1, 2, 4, 5, 6]
xs.remove(3)                   # [0, 1, 2, 4, 5, 6]  first match
xs.pop()                       # 6  → [0, 1, 2, 4, 5]
xs.pop(0)                      # 0  → [1, 2, 4, 5]
xs.index(4), xs.count(2)       # (2, 1)
xs.sort(reverse=True)          # [5, 4, 2, 1]
xs.reverse()                   # [1, 2, 4, 5]
ys = xs.copy()                 # shallow copy
xs.clear()                     # []
result = [3, 1].sort()         # None! sorts in place

Code Explained

insert(i, x) — x lands at index i
remove(x) — first matching value; ValueError if absent
pop(i) — removes and returns; default is last
sort(key=..., reverse=...) — same options as sorted()

⚠ Common Mistakes

  • lst = lst.sort() — lst becomes None
  • a.append([1, 2]) — nests a list; use extend()
  • remove(x) on a missing value — ValueError
  • pop(0) in a loop — slow; use collections.deque

✓ Tips & Best Practices

  • sorted(xs) keeps the original; xs.sort() changes it
  • Use deque when you add/remove at the front
  • extend() accepts generators: xs.extend(n * 2 for n in ys)
  • Guard remove: if x in xs: xs.remove(x)

Quick Summary

  • append / extend / insert — add
  • remove / pop / clear — delete
  • sort / reverse — reorder in place
  • most methods — return None
