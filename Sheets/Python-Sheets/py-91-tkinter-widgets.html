Label · Button · Entry · Text · Listbox · Checkbutton · Radiobutton · config()

Core Widgets

Widgets are the controls in a window. Each widget is created with its parent as the first argument, configured with keyword options, and then placed with a layout manager (Sheet 92). Read user input with get(), or link widgets to control variables like StringVar and BooleanVar. Change options later with config() or dict-style access.

Notes

  • Creating a widget doesn't show it; you must pack/grid/place it
  • Entry is single-line; Text is multi-line
  • Text indexes look like "line.column", e.g. "1.0"
  • Options: widget.config(opt=v) or widget["opt"] = v

Common Widgets

import tkinter as tk
root = tk.Tk()
tk.Label(root, text="Name:", font=("Arial", 12)).pack()
name = tk.Entry(root, width=30)
name.pack(); name.insert(0, "Ana")       # name.get() → 'Ana'
notes = tk.Text(root, height=4, wrap="word")
notes.pack(); notes.insert("end", "Hi")  # notes.get("1.0", "end-1c")
agree = tk.BooleanVar()
tk.Checkbutton(root, text="I agree", variable=agree).pack()
size = tk.StringVar(value="M")
for s in "SML":
    tk.Radiobutton(root, text=s, value=s, variable=size).pack()
lb = tk.Listbox(root, height=3)
for item in ["red", "green", "blue"]: lb.insert("end", item)
lb.pack()                                # lb.curselection() → (1,)
btn = tk.Button(root, text="Save", command=lambda: print(name.get()))
btn.pack()
root.mainloop()

Code Explained

Entry.insert(0, s) — put text at the start
"end-1c" — the end, minus Text's trailing newline
shared StringVar — groups the radio buttons
curselection() — tuple of selected indexes
config(state="disabled") — grey out a control later

⚠ Common Mistakes

  • e = tk.Entry(root).pack() — e is None; pack on a separate line
  • command=save() — calls immediately; pass save or a lambda
  • Radiobuttons without a shared variable — all can be selected
  • Reading Text.get("1.0", "end") — includes an extra newline

✓ Tips & Best Practices

  • Keep widget references only when you need them later
  • Use control variables to sync widgets automatically
  • Wrap related widgets in a Frame
  • Prefer ttk versions for a modern look

Quick Summary

  • create with parent → then place
  • get() / control vars — read input
  • config() — change options
  • command= — button callbacks
