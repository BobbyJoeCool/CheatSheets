Extending Classes

Inheritance lets a subclass reuse and extend a base class: class Dog(Animal):. The subclass gets every attribute and method of the parent, can override methods by redefining them, and can call the parent's version with super(). Every class ultimately inherits from object. Use inheritance for true "is-a" relationships.

Notes

  • Method lookup checks the subclass first, then parents
  • super() reaches the next class in the MRO (Sheet 62)
  • typing.override (3.12+) marks intended overrides
  • For "has-a" relationships, use composition instead

Subclass, Override, super()

class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return "..."
    def describe(self):
        return f"{self.name} says {self.speak()}"
class Dog(Animal):                     # Dog inherits from Animal
    def __init__(self, name, breed):
        super().__init__(name)         # run parent setup
        self.breed = breed
    def speak(self):                   # override
        return "Woof"
d = Dog("Rex", "lab")
d.describe()                           # 'Rex says Woof'
isinstance(d, Animal)                  # True
issubclass(Dog, Animal)                # True

Code Explained

class Dog(Animal) — Animal is the base class
super().__init__(name) — reuse the parent's setup
speak() override — describe() now calls Dog's version
isinstance — a Dog is also an Animal

⚠ Common Mistakes

  • Skipping super().__init__() — parent attributes never get set
  • Changing an override's signature — breaks code that treats it like the parent
  • Deep hierarchies (4+ levels) — hard to follow; flatten
  • Inheriting just to reuse a helper — use composition

✓ Tips & Best Practices

  • Ask "is a Dog an Animal?" before inheriting
  • Keep hierarchies one or two levels deep
  • Mark overrides with @typing.override (3.12+)
  • Put shared behavior in the base; specifics in subclasses

Quick Summary

  • class B(A) — B inherits A
  • override — redefine a method
  • super() — call parent version
  • isinstance — respects inheritance
