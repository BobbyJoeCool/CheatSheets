Conditional Expressions

The conditional expression a if condition else b evaluates to a or b. Because it's an expression, it fits inside assignments, return statements, function arguments, f-strings, lambdas, and comprehensions. Only the chosen branch is evaluated, and the else part is always required.

Notes

  • Order: value-if-true, condition, value-if-false
  • No ?: operator in Python
  • Lowest precedence of all operators except lambda
  • Nesting chains to the right; keep it short
  • x or default is a shortcut for falsy fallbacks

Ternary Examples

age = 20
status = "adult" if age >= 18 else "minor"   # 'adult'
n = 3
f"{n} file{'s' if n != 1 else ''}"           # '3 files'
a, b = 4, 9
bigger = a if a > b else b                   # 9 (or max(a, b))
x = -5
sign = "pos" if x > 0 else "neg" if x < 0 else "zero"  # 'neg'
["even" if i % 2 == 0 else "odd" for i in range(3)]
# ['even', 'odd', 'even']
user_name = ""
name = user_name or "Guest"                  # 'Guest'
fee = lambda member: 0 if member else 5
1 if True else 1 / 0                         # 1 (other side skipped)

Code Explained

a if c else b — reads like English
inside an f-string — handy for plurals
nested — evaluated left to right; two levels max
in a comprehension — the ternary goes before for
skipped branch — never evaluated, so no error

Forms

SyntaxMeaning
x if c else yPick one value
a if c1 else b if c2 else dThree-way choice
[a if c else b for v in xs]Map each item
[v for v in xs if c]Filter (no else)
x or defaultFalsy fallback

⚠ Common Mistakes

  • Leaving out else — SyntaxError
  • Putting a ternary after for — that slot is for filter-if only
  • Nesting three or more levels — switch to if/elif
  • Side effects in branches — use a statement for actions

✓ Tips & Best Practices

  • Use max() / min() instead of comparing two values
  • Use x or default only when every falsy value is invalid
  • Wrap long ternaries in parentheses across lines
  • If you need to explain it, use an if statement

Quick Summary

  • a if c else b — expression form of if
  • else — always required
  • only one branch — runs
  • comprehension — ternary before for
