Assignment & Compound Assignment

= · += · -= · *= · /= · //= · := walrus

Assign and Update

Compound operators combine an operation with assignment: x += 1 means x = x + 1. For mutable objects such as lists, += updates the object in place, so other references see the change. For immutable objects it creates a new object and rebinds the name. The walrus := (3.8+) assigns inside an expression.

Notes

  • Python has no ++ or --
  • /= turns an int into a float
  • list += iterable behaves like extend()
  • := must be parenthesized as a statement
  • Every arithmetic and bitwise operator has a compound form

Compound Assignment & Walrus

x = 10
x += 5; x -= 3; x *= 2         # 24
x /= 4                         # 6.0  (now a float)
n = 17; n %= 5                 # 2
s = "ab"; s += "c"             # 'abc'  (new string)
a = [1, 2]; b = a
a += [3]                       # in place
b                              # [1, 2, 3]  (b sees it)
a = a + [4]                    # builds a new list
b                              # [1, 2, 3]  (b doesn't)
if (n := len("hello")) > 3:
    print(n)                   # 5
while (cmd := input("> ")) != "q":
    print(cmd)

Code Explained

x op= y — shorthand for x = x op y
a += [3] — mutates the shared list
a = a + [4] — new list; b keeps the old one
(n := ...) — assign and use in one step
walrus loop — read and test without repeating the call

⚠ Common Mistakes

  • x++ — SyntaxError; ++x is just +(+x)
  • items += "ab" adds 'a' and 'b' as separate items
  • x = x.append(1) — append returns None
  • Forgetting /= makes floats — use //= to stay integer

✓ Tips & Best Practices

  • Use += on lists when you want shared references updated
  • Use a = a + b when you need a fresh list
  • Reach for := only when it removes a duplicated call
  • Counter pattern: counts[k] = counts.get(k, 0) + 1

Quick Summary

  • x += 1 — increment
  • mutable += — in place
  • immutable += — new object
  • := — assign inside an expression
