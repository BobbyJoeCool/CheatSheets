File Paths & Operations

pathlib.Path · / operator · exists() · mkdir() · glob() · os.path

Working with Paths

pathlib.Path represents file-system paths as objects. Join parts with the / operator, read pieces like .name and .suffix, and call methods to test, create, list, rename, and delete. It works the same on Windows, macOS, and Linux. The older os.path functions still work but operate on plain strings.

Notes

  • Relative paths resolve against the current working directory
  • Path(__file__).parent is the script's own folder
  • glob() patterns: *, ?, ** for recursion
  • Use shutil for copying and deleting whole trees
  • Most functions that take paths accept Path objects

pathlib Essentials

from pathlib import Path
p = Path("data") / "2026" / "report.csv"   # join with /
p.name, p.stem, p.suffix           # ('report.csv', 'report', '.csv')
p.parent                           # Path('data/2026')
p.with_suffix(".json")             # Path('data/2026/report.json')
Path.cwd(), Path.home()            # current folder, home folder
p.exists(), p.is_file(), p.is_dir()
p.parent.mkdir(parents=True, exist_ok=True)  # create folders
p.resolve()                        # absolute path
list(Path(".").glob("*.py"))       # matches in this folder
list(Path(".").rglob("*.csv"))     # recursive search
p.stat().st_size                   # size in bytes
p.rename("old.csv")                # move / rename
Path("old.csv").unlink(missing_ok=True)  # delete file
import os
os.path.join("data", "x.txt")      # 'data/x.txt'  (string style)

Code Explained

/ — builds paths with the right separator
stem / suffix — name without / only the extension
mkdir(parents=True, exist_ok=True) — like mkdir -p
rglob() — searches subfolders too
unlink(missing_ok=True) — no error if already gone

⚠ Common Mistakes

  • Building paths with + "/" + — breaks on Windows
  • Assuming relative paths start at the script — they start at the cwd
  • mkdir() on an existing folder without exist_ok=True — FileExistsError
  • rmdir() on a non-empty folder — use shutil.rmtree()

✓ Tips & Best Practices

  • Anchor data files with Path(__file__).parent / "data"
  • Use shutil.copy2, move, and rmtree for bigger jobs
  • sorted(p.glob("*.txt")) for predictable order
  • Convert to a string with str(p) only when an API requires it
