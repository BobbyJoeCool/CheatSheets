Program Structure & Entry Point

if __name__ == "__main__" · main() · indentation · imports · line continuation

How a Python File Is Organized

A Python file is a module that runs top to bottom when executed or imported. Blocks are defined by indentation instead of braces, and every block header ends with a colon. The if __name__ == "__main__": guard lets one file work both as an importable module and a runnable script, because the code inside it runs only when the file is executed directly.

Rules

  • __name__ is "__main__" when run directly, the module name when imported
  • PEP 8: 4 spaces per indent level, no tabs
  • One statement per line; no semicolons needed
  • Lines inside (), [], {} continue automatically
  • A trailing \ continues a line but breaks easily

Annotated Script Template

#!/usr/bin/env python3
"""Greet a user by name."""          # 1. module docstring

import sys                           # 2. imports: stdlib, 3rd-party, local

DEFAULT_NAME = "World"               # 3. module-level constants

def greet(name: str) -> str:         # 4. functions and classes
    """Return a greeting."""
    return f"Hello, {name}!"

def main() -> int:                   # 5. entry-point function
    name = sys.argv[1] if len(sys.argv) > 1 else DEFAULT_NAME
    print(greet(name))               # Hello, World!
    return 0                         # exit status 0 = success

if __name__ == "__main__":           # 6. runs only when executed
    sys.exit(main())

Code Explained

docstring — first string in the file; shown by help()
imports — grouped stdlib → third-party → local, one blank line between
main() — keeps logic out of module scope and makes it testable
sys.exit(main()) — passes the return code to the shell
__name__ guard — importing the file doesn't call main()

⚠ Common Mistakes

  • Script logic at module level — it runs on every import; put it in main()
  • if __name__ == "main": — missing underscores, so it's never true
  • Mixing tabs and spaces — TabError or IndentationError
  • Space after a trailing \ — breaks the continuation; use parentheses

✓ Tips & Best Practices

  • Return an int from main() and hand it to sys.exit()
  • Wrap long expressions in parentheses instead of using \
  • Set your editor to insert 4 spaces on Tab
  • Let ruff or isort order your imports

Quick Summary

  • : + indent — defines a block
  • __name__ == "__main__" — true only when run directly
  • main() — single, testable entry point
  • ( ) — implicit line continuation
