Raising & Re-raising Exceptions

raise · raise from · re-raise · ValueError · TypeError · ExceptionGroup

Signaling Errors

raise signals an error by throwing an exception instance (or a class, which gets instantiated). Inside an except block, a bare raise re-raises the current exception with its original traceback. raise New(...) from err chains exceptions so the traceback shows the cause; from None hides the original. Python 3.11 added ExceptionGroup and except* for several errors at once.

Notes

  • Only BaseException subclasses can be raised
  • Messages should state what was wrong and the bad value
  • e.add_note("...") adds context (3.11+)
  • assert is for debugging; python -O removes it
  • Exceptions bubble up until something catches them

raise, re-raise, chain

def set_age(age):
    if not isinstance(age, int):
        raise TypeError(f"age must be int, got {type(age).__name__}")
    if age < 0:
        raise ValueError(f"age must be >= 0, got {age}")
    return age

try:
    set_age(-1)
except ValueError as e:
    print(e)                       # age must be >= 0, got -1

try:
    config = json.loads(text)
except json.JSONDecodeError as e:
    raise ConfigError("bad config") from e   # chained
except OSError:
    raise                          # re-raise as-is

Code Explained

validate early — raise before doing work
TypeError vs ValueError — wrong type vs bad value
from e — sets __cause__; traceback shows both
bare raise — let the same error propagate

⚠ Common Mistakes

  • raise "error" — TypeError; raise an exception object
  • Raising bare Exception — callers can't catch it precisely
  • Using assert for input validation — disabled with -O
  • raise NewError() inside except without from — muddled traceback

✓ Tips & Best Practices

  • Include the offending value in the message
  • Use from e whenever you translate one error into another
  • Prefer bare raise over raise e when re-raising
  • Raise NotImplementedError in abstract-style base methods

Quick Summary

  • raise E("msg") — signal an error
  • raise — re-raise in except
  • from e — chain the cause
  • pick the most specific built-in
