Dialogs & Message Boxes

messagebox · showinfo() · askyesno() · filedialog · askopenfilename() · simpledialog

Standard Dialogs

Tkinter includes ready-made dialogs for common interactions. messagebox shows alerts and asks yes/no questions, filedialog opens native file and folder pickers, simpledialog asks for a single value, and colorchooser picks a color. Each call blocks until the user responds and returns their answer, or an empty/None value if they cancel.

Notes

  • Import submodules explicitly: from tkinter import messagebox
  • A root window must exist (it can be hidden with withdraw())
  • File dialogs return "" on cancel, not None
  • Build custom dialogs with Toplevel + grab_set()

Dialog Calls

import tkinter as tk
from tkinter import messagebox, filedialog, simpledialog, colorchooser
root = tk.Tk()
messagebox.showinfo("Saved", "File saved.")          # OK only
messagebox.showwarning("Careful", "Disk almost full")
messagebox.showerror("Error", "Could not connect")
messagebox.askyesno("Quit", "Quit without saving?")  # True / False
messagebox.askokcancel("Delete", "Delete 3 files?")  # True / False
messagebox.askyesnocancel("Save", "Save changes?")   # True / False / None
path = filedialog.askopenfilename(
    title="Open", filetypes=[("Text", "*.txt"), ("All files", "*.*")])
path                                                 # '' if cancelled
filedialog.asksaveasfilename(defaultextension=".csv")
filedialog.askdirectory()                            # folder path
simpledialog.askstring("Name", "Your name?")         # str or None
simpledialog.askinteger("Age", "Age?", minvalue=0)   # int or None
colorchooser.askcolor()                              # ((r, g, b), '#rrggbb')

Code Explained

show* — information only; returns "ok"
ask* — returns the user's choice
filetypes= — filter shown in the picker
defaultextension= — added if the user omits it
cancel — "", None, or (None, None)

⚠ Common Mistakes

  • import tkinter as tk then tk.messagebox — may fail; import the submodule
  • Checking if path is None: after a file dialog — cancel returns ""
  • Showing dialogs before creating a root — an empty extra window appears
  • Using askquestion and comparing to True — it returns "yes"

✓ Tips & Best Practices

  • Test with if not path: to catch cancel
  • Use askyesno before destructive actions
  • Remember the last folder with initialdir=
  • Hide the root with root.withdraw() for dialog-only scripts

Quick Summary

  • messagebox — alerts and questions
  • filedialog — file/folder pickers
  • simpledialog — one value
  • cancel — empty or None
