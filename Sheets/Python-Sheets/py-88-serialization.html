Serialization & Pickling

pickle · shelve · json vs pickle · marshal · security risks

Saving Python Objects

Serialization turns objects into bytes or text you can store or send, and deserialization rebuilds them. pickle handles almost any Python object, including sets, tuples, and class instances, but the format is Python-only and unsafe to load from untrusted sources, because unpickling can execute code. shelve is a dict-like store built on pickle. Prefer JSON for data exchange.

Notes

  • Pickle files are binary: open with "wb" / "rb"
  • Unpickling needs the original class importable
  • marshal is for Python's own .pyc files, not your data
  • copy.deepcopy() uses the same machinery
  • pickle.HIGHEST_PROTOCOL selects the newest format

pickle and shelve

import pickle, shelve, json
data = {"user": "ana", "scores": {3, 5}, "when": (2026, 10, 1)}
blob = pickle.dumps(data)              # bytes; keeps set and tuple
pickle.loads(blob) == data             # True
with open("state.pkl", "wb") as f:
    pickle.dump(data, f)               # binary mode
with open("state.pkl", "rb") as f:
    restored = pickle.load(f)
json.dumps(data)                       # TypeError: set not serializable
with shelve.open("cache") as db:       # persistent dict
    db["config"] = {"theme": "dark"}
    db.get("config")                   # {'theme': 'dark'}
class Point:
    def __init__(self, x, y): self.x, self.y = x, y
p = pickle.loads(pickle.dumps(Point(1, 2)))
p.x                                    # 1
# NEVER pickle.load() data from an untrusted source

Code Explained

pickle keeps Python types that JSON can't represent
shelve — keys are strings, values are pickled

⚠ Common Mistakes

  • Loading pickles from users or the internet — arbitrary code execution
  • Opening pickle files in text mode — TypeError / corrupt data
  • Renaming or moving a class — old pickles fail to load
  • Using pickle for long-term storage across Python versions

✓ Tips & Best Practices

  • Use JSON whenever the data is plain dicts, lists, and strings
  • Treat pickle files like executable code
  • Pass protocol=pickle.HIGHEST_PROTOCOL for speed and size
  • Sign or checksum pickles if you must move them between machines

Quick Summary

  • pickle — any Python object
  • shelve — persistent dict
  • JSON — portable and safe
  • untrusted pickle — never load
