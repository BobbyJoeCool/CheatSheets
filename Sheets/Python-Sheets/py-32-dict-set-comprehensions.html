Dict and Set Comprehensions

{key: value for item in iterable} builds a dict; {expr for item in iterable} builds a set, removing duplicates automatically. Both follow the same filtering and nesting rules as list comprehensions. Remember that empty braces {} create an empty dict, not a set.

Notes

  • Duplicate keys: the last value wins
  • Sets are unordered; printed order may differ
  • Dicts keep insertion order (3.7+)
  • Inverting a dict needs unique values
  • set() is the only way to write an empty set

Dict & Set Comprehensions

words = ["apple", "fig", "kiwi"]
{w: len(w) for w in words}         # {'apple': 5, 'fig': 3, 'kiwi': 4}
{w: len(w) for w in words if len(w) > 3}  # {'apple': 5, 'kiwi': 4}
prices = {"tea": 3, "cake": 5}
{k: v * 2 for k, v in prices.items()}     # {'tea': 6, 'cake': 10}
{v: k for k, v in prices.items()}  # {3: 'tea', 5: 'cake'}  inverted
{k.upper(): v for k, v in prices.items()} # {'TEA': 3, 'CAKE': 5}
{x: x ** 2 for x in range(4)}      # {0: 0, 1: 1, 2: 4, 3: 9}
dict(zip(["a", "b"], [1, 2]))      # {'a': 1, 'b': 2}
{n % 3 for n in range(10)}         # {0, 1, 2}
{w[0] for w in words}              # {'a', 'f', 'k'}
{c.lower() for c in "AaBb"}        # {'a', 'b'}

Code Explained

{k: v for ...} — key and value expressions
.items() — loop over pairs to transform both
{v: k ...} — swap keys and values
{expr for ...} — set; duplicates collapse
dict(zip(keys, values)) — build without a comprehension

⚠ Common Mistakes

  • Inverting with repeated values — earlier keys are overwritten
  • s = {} expecting a set — it's a dict; use set()
  • Relying on set order — it's arbitrary
  • Counting with a comprehension — use collections.Counter

✓ Tips & Best Practices

  • list(dict.fromkeys(xs)) removes duplicates and keeps order
  • Use dict(zip()) when you already have two parallel lists
  • Filter dicts by value: {k: v for k, v in d.items() if v}
  • Build a set once for fast repeated in checks

Quick Summary

  • {k: v for ...} — dict comprehension
  • {x for ...} — set comprehension
  • {} — empty dict
  • duplicates — last key wins / set dedupes
