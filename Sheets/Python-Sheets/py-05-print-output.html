Sheet 05

Print & Output

print() · sep · end · file · flush · sys.stdout · sys.stderr

How print() Works

print() converts each argument with str(), joins them with sep (a space by default), appends end (a newline by default), and writes the result to sys.stdout. Its keyword arguments cover most formatting needs without string concatenation. Send errors and diagnostics to sys.stderr so they stay separate from normal output.

Notes

  • Signature: print(*objects, sep=' ', end='\n', file=None, flush=False)
  • Non-strings convert automatically: print(42) works
  • print() returns None
  • stdout is line-buffered in a terminal, block-buffered when piped
  • Use the logging module (Sheet 82) for applications

print() Variants

import sys
print("Hello")                       # Hello
print("a", "b", "c")                 # a b c
print("a", "b", "c", sep="-")        # a-b-c
print("a", "b", sep="")              # ab
print("Loading", end="...")          # Loading...  (no newline)
print()                              # blank line
print(3, 4.5, True, None)            # 3 4.5 True None
print(*[1, 2, 3])                    # 1 2 3
print(*[1, 2, 3], sep="\n")          # one per line
print(f"{2 + 3 = }")                 # 2 + 3 = 5
print(repr("hi"))                    # 'hi'
print("failed!", file=sys.stderr)    # goes to stderr
print("50%", end="\r", flush=True)   # overwrite same line

Code Explained

sep — string placed between arguments
end — string placed after the last argument
*list — unpacks items into separate arguments
f"{expr = }" — prints the expression and its value (3.8+)
file=sys.stderr — separate stream for errors
flush=True — write immediately (progress output)

⚠ Common Mistakes

  • print "x" — Python 2 syntax; SyntaxError in Python 3
  • print("Total: " + 5) — TypeError; use a comma or an f-string
  • x = print("hi") — x is None, not the text
  • Progress not appearing when piped — add flush=True

✓ Tips & Best Practices

  • print(f"{var=}") is the fastest debug print
  • pprint.pprint() makes nested dicts readable
  • Send errors to sys.stderr so > out.txt captures only results
  • print(*items, sep="\n") prints one item per line

Quick Summary

  • print(a, b) — space-separated, newline-terminated
  • sep= / end= — control separators
  • file= — redirect to stderr or a file
  • flush=True — force an immediate write
