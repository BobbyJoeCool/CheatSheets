pack, grid, and place

Tkinter has three geometry managers that decide where widgets go. pack() stacks widgets against a side, good for toolbars and simple columns. grid() arranges widgets in rows and columns, best for forms. place() positions widgets at exact or relative coordinates. Use one manager per container; combine them by nesting Frames.

Notes

  • Never mix pack and grid in the same parent
  • sticky stretches a grid cell's widget to its edges
  • Rows/columns only grow if they have weight
  • fill + expand make packed widgets resize
  • place() doesn't adapt well to window resizing

Three Managers, Nested Frames

import tkinter as tk
root = tk.Tk()
top = tk.Frame(root); top.pack(side="top", fill="x")
tk.Label(top, text="Toolbar").pack(side="left", padx=5)
tk.Button(top, text="Quit").pack(side="right", padx=5, pady=5)
form = tk.Frame(root, padx=10, pady=10)
form.pack(fill="both", expand=True)
tk.Label(form, text="Name").grid(row=0, column=0, sticky="w")
tk.Entry(form).grid(row=0, column=1, sticky="ew", padx=5)
tk.Label(form, text="Email").grid(row=1, column=0, sticky="w")
tk.Entry(form).grid(row=1, column=1, sticky="ew", padx=5)
tk.Button(form, text="Submit").grid(row=2, column=0, columnspan=2, pady=8)
form.columnconfigure(1, weight=1)       # column 1 stretches
badge = tk.Label(root, text="NEW", bg="gold")
badge.place(relx=1.0, rely=0, anchor="ne")   # pinned top-right
root.mainloop()

Code Explained

top uses pack; form uses grid — different parents
sticky="ew" — stretch east–west
columnspan=2 — span both columns
weight=1 — gives extra space to column 1
relx=1.0, anchor="ne" — right edge, top

⚠ Common Mistakes

  • pack and grid in one container — Tk raises a TclError
  • Forgetting weight — the form won't stretch with the window
  • w = tk.Button(...).grid() — w is None
  • Building whole layouts with place() — breaks on resize and DPI changes

✓ Tips & Best Practices

  • Sketch the layout as nested frames first
  • Use grid for forms, pack for bars and stacks
  • sticky="nsew" + weights for fully resizable panes
  • Set padding on frames instead of every widget

Quick Summary

  • pack — stack against sides
  • grid — rows and columns
  • place — exact positions
  • one manager per parent
