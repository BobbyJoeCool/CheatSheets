Sets

set() · add() · discard() · | · & · - · ^ · frozenset

Unique, Unordered Collections

A set is an unordered collection of unique, hashable items with O(1) average membership tests. Sets remove duplicates automatically and support math-style operations: union, intersection, difference, and symmetric difference. frozenset is the immutable, hashable version. Note that {} creates a dict; use set() for an empty set.

Notes

  • No indexing or slicing; order is arbitrary
  • Items must be hashable (no lists or dicts)
  • discard() ignores missing items; remove() raises
  • pop() removes an arbitrary item
  • Operators need sets; methods accept any iterable

Set Operations

a = {1, 2, 3}; b = {3, 4}
empty = set()                  # {} would be a dict
set([1, 1, 2])                 # {1, 2}
a.add(4)                       # {1, 2, 3, 4}
a.discard(9)                   # no error if missing
a.remove(9)                    # KeyError
a | b                          # {1, 2, 3, 4}  union
a & b                          # {3, 4}  intersection
a - b                          # {1, 2}  difference
a ^ b                          # {1, 2}  in one, not both
{1, 2} <= a                    # True  subset
a.isdisjoint({7, 8})           # True  nothing shared
fs = frozenset([1, 2])         # immutable, hashable

Code Explained

set(iterable) — dedupe anything iterable
| & - ^ — set algebra
<= / >= — subset / superset
frozenset — usable as a dict key or set member

⚠ Common Mistakes

  • s = {} for an empty set — it's a dict
  • Indexing s[0] — sets aren't ordered
  • Adding a list — TypeError: unhashable type
  • Relying on pop() returning a particular item

✓ Tips & Best Practices

  • Convert lists to sets for repeated in checks
  • Use sorted(s) when you need ordered output
  • Methods accept lists: a.union([5, 6])
  • Dedupe but keep order: list(dict.fromkeys(xs))
