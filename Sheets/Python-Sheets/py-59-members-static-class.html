Instance, Class & Static Members

instance attrs · class attrs · @staticmethod · @classmethod · cls

Three Kinds of Members

Instance attributes and methods belong to one object and use self. Class attributes live on the class and are shared by every instance; @classmethod methods receive the class as cls. @staticmethod methods receive neither; they're plain functions grouped inside the class because they relate to it.

Notes

  • Lookup order: instance → class → base classes
  • Assigning through an instance creates an instance attribute
  • Classmethods are inherited and receive the subclass
  • Static methods can't see self or cls

All Three on One Class

class Pizza:
    count = 0                          # class attribute (shared)
    def __init__(self, size):
        self.size = size               # instance attribute
        Pizza.count += 1
    def area(self):                    # instance method
        return 3.14159 * (self.size / 2) ** 2
    @classmethod
    def small(cls):                    # class method
        return cls(8)
    @staticmethod
    def is_valid(size):                # static method
        return 6 <= size <= 18
p = Pizza(12)
round(p.area(), 1)                     # 113.1
Pizza.small().size                     # 8
Pizza.is_valid(20)                     # False
Pizza.count                            # 2
p.count = 99                           # new instance attribute!
Pizza.count                            # still 2

Code Explained

Pizza.count += 1 — update shared data via the class
self.size — unique per pizza
cls(8) — builds an instance of whatever class called it
p.count = 99 — shadows, doesn't change, the class attribute

⚠ Common Mistakes

  • Mutable class attribute (items = []) — shared by all instances
  • self.count += 1 — creates an instance copy instead of updating the class
  • Static method that needs class data — make it a classmethod
  • Forgetting @classmethod — cls receives an instance or nothing

✓ Tips & Best Practices

  • Update shared counters through the class name or cls
  • Use classmethods for factories so subclasses work
  • Use class attributes for constants: MAX_SIZE = 18
  • If a static method doesn't relate to the class, move it out

Quick Summary

  • instance — self, per object
  • @classmethod — cls, per class
  • @staticmethod — no implicit arg
  • class attrs — shared
