Math & Random Modules

math.sqrt · math.floor · math.pi · random.randint · random.choice · random.shuffle · random.seed

Numbers and Randomness

math provides fast functions for real numbers: roots, rounding, logarithms, trigonometry, and combinatorics, plus constants like pi. random generates pseudo-random numbers and choices; call random.seed() to make results repeatable. For passwords and tokens, use the secrets module instead, because random is predictable.

Notes

  • math works on floats; use cmath for complex numbers
  • Trig functions use radians
  • randint(a, b) includes b; randrange(a, b) excludes b
  • shuffle() changes the list in place
  • statistics handles mean, median, stdev

math and random

import math, random
math.sqrt(16), math.isqrt(17)          # (4.0, 4)
math.floor(-2.5), math.ceil(2.1)       # (-3, 3)
math.pi, math.e, math.tau, math.inf    # constants
math.log(100, 10), math.log2(8)        # (2.0, 3.0)
math.sin(math.pi / 2)                  # 1.0
math.degrees(math.pi)                  # 180.0
math.gcd(12, 18), math.lcm(4, 6)       # (6, 12)
math.factorial(5), math.comb(5, 2)     # (120, 10)
math.hypot(3, 4)                       # 5.0
random.seed(42)                        # repeatable sequence
random.random()                        # float in [0.0, 1.0)
random.randint(1, 6)                   # 1..6 inclusive
random.choice(["red", "green"])        # one item
random.sample(range(100), 3)           # 3 unique items
deck = list(range(10)); random.shuffle(deck)  # in place

Code Explained

isqrt — exact integer square root
log(x, base) — any base; log2, log10 are faster
comb(n, k) — n choose k
seed(42) — same numbers every run
sample() — no repeats; choices() allows repeats

⚠ Common Mistakes

  • Using random for passwords or tokens — use secrets
  • math.sqrt(-1) — ValueError; use cmath.sqrt
  • deck = random.shuffle(deck) — deck becomes None
  • Passing degrees to math.sin() — convert with math.radians()

✓ Tips & Best Practices

  • Seed random in tests for reproducible results
  • random.Random(seed) gives an independent generator
  • Use math.isclose() instead of == for floats
  • Use math.prod() instead of reduce(mul, ...)

Quick Summary

  • seed() — repeatable runs
