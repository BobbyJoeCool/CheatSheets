Logging

logging · levels · basicConfig() · getLogger() · handlers · formatters

Recording What Happens

The logging module records messages with a level, a timestamp, and the module they came from, and sends them to handlers such as the console or a file. Unlike print(), you can turn detail up or down without editing code. Create one logger per module with getLogger(__name__) and configure output once at program start.

Notes

  • Default level is WARNING; DEBUG and INFO are hidden
  • basicConfig() only works the first time (unless force=True)
  • Pass values as arguments: log.info("x=%s", x)
  • Libraries should log but never call basicConfig()

Configure and Log

import logging
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)-8s %(name)s: %(message)s",
    datefmt="%H:%M:%S",
)
log = logging.getLogger(__name__)      # one logger per module
log.debug("hidden")                    # below INFO: not shown
log.info("server started on %s", 8080)
# 14:30:05 INFO     __main__: server started on 8080
log.warning("disk at %d%%", 91)
try:
    1 / 0
except ZeroDivisionError:
    log.exception("math failed")       # ERROR + traceback
fh = logging.FileHandler("app.log", encoding="utf-8")
fh.setLevel(logging.WARNING)
log.addHandler(fh)                     # warnings also go to a file

Code Explained

basicConfig — sets the root level and format
getLogger(__name__) — logger named after the module
%s args — formatted only if the message is emitted
log.exception() — call inside except
handler level — filters what reaches that destination

⚠ Common Mistakes

  • Using print() for diagnostics — can't be filtered or redirected
  • log.info(f"x={x}") — formats even when the level is off
  • Calling basicConfig() after something else configured logging — no effect
  • log.error(e) in except — loses the traceback; use log.exception()

✓ Tips & Best Practices

  • Configure once in main(); just call getLogger(__name__) elsewhere
  • Use RotatingFileHandler for long-running services
  • Use logging.config.dictConfig() for larger setups
  • Quiet chatty libraries by raising their logger level (e.g. urllib3)

Quick Summary

  • getLogger(__name__) — per-module logger
  • levels — DEBUG → CRITICAL
  • basicConfig() — quick setup
  • log.exception() — error + traceback
