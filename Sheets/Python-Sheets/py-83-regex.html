re.search() · re.match() · re.findall() · re.sub() · groups · flags

Pattern Matching on Text

The re module finds, extracts, splits, and replaces text using regular expression patterns. Write patterns as raw strings (r"...") so backslashes reach the regex engine untouched. search() finds the first match anywhere, match() only at the start, and fullmatch() requires the whole string. Parentheses create groups you can extract from the match object.

Notes

  • Failed searches return None; check before .group()
  • findall() returns groups if the pattern has them
  • Quantifiers are greedy; add ? to make them lazy
  • Flags: re.I ignore case, re.M multiline, re.S dot-all
  • re.compile() helps when reusing a pattern

re Functions

import re
text = "Order #123 shipped 2026-10-01; order #456 pending"
re.search(r"#(\d+)", text).group(1)        # '123'  first match
re.match(r"Order", text)                   # matches only at start
re.fullmatch(r"\d{4}", "2026")             # whole string must match
re.findall(r"#(\d+)", text)                # ['123', '456']
re.sub(r"\d", "X", "a1b22")                # 'aXbXX'
re.split(r"[;,]\s*", "a; b,c")             # ['a', 'b', 'c']
m = re.search(r"(?P<y>\d{4})-(?P<m>\d\d)-(?P<d>\d\d)", text)
m.group("y"), m.groups()                   # ('2026', ('2026', '10', '01'))
m.span()                                   # (19, 29)
re.findall(r"order", text, flags=re.I)     # ['Order', 'order']
pat = re.compile(r"\b[A-Z][a-z]+\b")
pat.findall("Ana met Bo in Lima")          # ['Ana', 'Bo', 'Lima']

Code Explained

(\d+) — capture one or more digits
(?P<y>...) — named group, read with group("y")
span() — start and end positions
sub() — replacement can use \1 or a function
\b — word boundary

⚠ Common Mistakes

  • Plain strings like "\d" — escapes get mangled; use r"\d"
  • Using match() to search the middle of a string — use search()
  • Greedy .* grabbing too much — use .*?
  • Parsing HTML or JSON with regex — use a real parser

✓ Tips & Best Practices

  • Test patterns interactively (e.g. regex101.com, Python flavor)
  • Use re.VERBOSE to comment complex patterns
  • Prefer string methods (in, startswith) for simple checks
  • Use re.escape(user_text) before inserting text into a pattern

Quick Summary

  • r"..." — raw-string patterns
  • search / match / fullmatch
  • findall / sub / split
  • groups — ( ) and (?P<name> )
