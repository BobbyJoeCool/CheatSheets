Wrapping Functions

A decorator is a function that takes a function and returns a replacement, usually a wrapper that adds behavior before or after the original runs. Writing @decorator above a def is shorthand for func = decorator(func). Use functools.wraps so the wrapper keeps the original name and docstring. A decorator that takes arguments needs one extra layer: a factory that returns the decorator.

Notes

  • Decorators run once, at definition time
  • The wrapper runs on every call
  • Forward arguments with *args, **kwargs
  • Stacked decorators apply bottom-up
  • Classes can be decorated too (@dataclass)

A Timer and a Decorator Factory

import functools, time
def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__}: {time.perf_counter() - start:.3f}s")
        return result
    return wrapper
@timer                              # same as: nap = timer(nap)
def nap(secs):
    time.sleep(secs)
nap(0.1)                            # nap: 0.100s
def repeat(times):                  # factory: returns a decorator
    def deco(func):
        return lambda *a, **kw: [func(*a, **kw) for _ in range(times)]
    return deco
@repeat(3)
def hi(): return "hi"
hi()                                # ['hi', 'hi', 'hi']

Code Explained

wrapper(*args, **kwargs) — accepts any signature
return result — pass the original return value back
@functools.wraps(func) — copies __name__, __doc__
@repeat(3) — call the factory, then decorate

⚠ Common Mistakes

  • Forgetting return result — decorated function returns None
  • Skipping @wraps — every function looks like wrapper in logs
  • @repeat without (3) — the factory receives the function instead
  • @timer() with parentheses on a plain decorator — TypeError

✓ Tips & Best Practices

  • Keep wrappers thin; put real logic in helpers
  • Test the undecorated function via f.__wrapped__
  • Use @functools.cache before writing your own memoizer
  • Name the factory parameter clearly: @retry(times=3)
