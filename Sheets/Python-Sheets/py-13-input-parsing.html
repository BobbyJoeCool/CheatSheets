User Input & Parsing

input() · int(input()) · strip() · try/except ValueError · validation loop

Reading from the Keyboard

input(prompt) shows the prompt, reads one line from standard input, and returns it as a str without the trailing newline. Always convert and validate, because users type unexpected things. Wrap conversion in try/except and loop until the value is valid. EOFError signals that input ended (Ctrl+D, or a piped file ran out).

Notes

  • input() always returns str
  • The prompt prints without a trailing newline
  • Ctrl+C raises KeyboardInterrupt
  • getpass.getpass() hides typed passwords
  • For script options use sys.argv or argparse

Validated Input

name = input("Name: ").strip()          # 'Ana'
age = int(input("Age: "))               # ValueError on "abc"

def ask_int(prompt, lo, hi):
    while True:
        raw = input(prompt).strip()
        try:
            n = int(raw)
        except ValueError:
            print(f"{raw!r} is not a number")
            continue
        if lo <= n <= hi:
            return n
        print(f"Enter {lo}-{hi}")

qty = ask_int("Qty (1-10): ", 1, 10)
x, y = map(int, input("x y: ").split())  # "3 4" → 3, 4

Code Explained

.strip() — removes stray spaces and tabs
while True + return — loop until valid
continue — re-prompt after a bad value
map(int, s.split()) — convert several numbers at once

⚠ Common Mistakes

  • input() + 1 — TypeError; convert first
  • Comparing age > 18 while age is still a str
  • Relying on isdigit() — rejects "-5" and "3.5"
  • a, b = input().split() with three words — ValueError

✓ Tips & Best Practices

  • Show the expected format in the prompt: "Date (YYYY-MM-DD): "
  • Put validation in a reusable function like ask_int()
  • Use getpass.getpass() for passwords
  • Catch EOFError when your script may read piped input

Quick Summary

  • input() — returns a str
  • int(input()) — convert immediately
  • try/except ValueError — handle bad input
  • while True — re-prompt until valid
