Sheet 03

Running Python

REPL · python script.py · -m · -c · -i · shebang

Three Ways to Run Code

Python runs code interactively in the REPL, from a script file, or as a module with -m. The REPL evaluates each line immediately and echoes expression results, which makes it ideal for testing ideas. A script runs top to bottom once. The -m flag runs a module by its import name, which is how you launch tools like pip, venv, and http.server.

REPL Basics

  • >>> is the main prompt, ... a continuation line
  • _ holds the last expression result
  • Exit with exit(), Ctrl+D (Unix), or Ctrl+Z Enter (Windows)
  • 3.13+ REPL adds color, multiline editing, and bare exit
  • IPython and Jupyter are richer third-party REPLs

Running Python

python3                         # start the REPL
>>> 2 + 3
5
>>> _ * 10                      # 50  (last result)

python3 hello.py                # run a script
python3 hello.py a b            # sys.argv == ['hello.py', 'a', 'b']
python3 -m http.server 8000     # run a module as a script
python3 -c "print(2**10)"       # 1024
python3 -i hello.py             # run, then stay in the REPL

# Unix: make a script executable
#!/usr/bin/env python3          # first line of hello.py
chmod +x hello.py && ./hello.py

Code Explained

-m module — finds the module on sys.path and runs it as __main__
-c "code" — executes a string of code
-i — keeps the REPL open so you can inspect variables
#!/usr/bin/env python3 — shebang; locates python3 on PATH
sys.argv[0] — script name; arguments follow

⚠ Common Mistakes

  • Typing python hello.py inside the REPL — it's a shell command; exit first
  • Naming a script random.py or json.py — it shadows the stdlib module
  • python -m mymodule.py — drop .py; -m takes an import name
  • Shebang file saved with CRLF — Unix reports python3\r not found; save with LF

✓ Tips & Best Practices

  • python -i script.py lets you inspect state after a crash
  • python -m http.server serves the current folder instantly
  • Keep a REPL open while coding to test snippets
  • breakpoint() drops into the pdb debugger mid-script

Quick Summary

  • python3 — interactive REPL
  • python3 file.py — run a script
  • python3 -m pkg — run a module by import name
  • #!/usr/bin/env python3 — executable Unix scripts
