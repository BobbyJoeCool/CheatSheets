Defining & Calling Functions

def · return · multiple return · None return · call syntax

Functions

def creates a function object and binds it to a name. The indented body runs each time the function is called. return sends a value back and ends the call immediately; a function with no return gives None. Return several values as a tuple and unpack them. Functions are ordinary objects, so you can assign, pass, and store them.

Notes

  • Define before calling (at runtime, top to bottom)
  • greet is the function; greet() calls it
  • Code after return never runs
  • Arguments are passed by object reference
  • Type hints: def f(x: int) -> str:

Define, Call, Return

def greet(name: str) -> str:
    """Return a greeting for name."""
    return f"Hello, {name}!"

greet("Ana")                       # 'Hello, Ana!'

def log(msg):
    print(msg)                     # no return statement

result = log("hi")                 # prints: hi
result is None                     # True

def min_max(nums):
    return min(nums), max(nums)    # returns a tuple

lo, hi = min_max([4, 1, 9])        # lo=1, hi=9
say = greet                        # functions are objects
say("Bo")                          # 'Hello, Bo!'

Code Explained

-> str — return type hint (not enforced)
docstring — first line of the body
no return — the call evaluates to None
return a, b — tuple; unpack at the call
say = greet — no parentheses, so no call

⚠ Common Mistakes

  • Calling before the def line runs — NameError
  • Writing greet instead of greet() — you get the function, not a result
  • Using print() where you meant return — caller gets None
  • Putting code after return — it's unreachable

✓ Tips & Best Practices

  • Give each function one job and a verb name
  • Return values; let the caller decide whether to print
  • Return early to avoid deep nesting
  • Write a one-line docstring for every public function

Quick Summary

  • def name(params): — define
  • name(args) — call
  • return — send back and exit
  • no return — None
