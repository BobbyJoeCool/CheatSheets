Loop Controls

break · continue · pass · loop else · flag variables

break, continue, pass

break exits the innermost loop immediately. continue skips the rest of the current iteration and moves to the next. pass does nothing; it's a placeholder where a statement is required. A loop's else clause runs only when the loop finishes without break, which makes searches clean. Python has no labeled break, so leave nested loops with return or a flag.

Notes

  • break and continue affect only the innermost loop
  • else works on both for and while
  • ... (Ellipsis) also works as an empty body
  • return inside a loop exits the loop and the function

Loop Control

for n in [3, 8, 11, 4]:
    if n > 10:
        print("found", n); break   # found 11
for n in range(6):
    if n % 2:
        continue               # skip odd
    print(n, end=" ")          # 0 2 4
for n in [4, 6, 8]:
    if n % 2:
        print("odd found"); break
else:
    print("all even")          # all even
def find(grid, target):        # leave nested loops
    for r, row in enumerate(grid):
        for c, val in enumerate(row):
            if val == target:
                return r, c
    return None

Code Explained

break — stop searching once found
continue — skip the current item
for … else — runs only if no break
return — the cleanest exit from nested loops

⚠ Common Mistakes

  • Expecting break to exit all loops — only the innermost one
  • continue before i += 1 in a while — infinite loop
  • Misaligned else — it belongs to the loop, not the inner if
  • Leaving pass in finished code where logic was intended

✓ Tips & Best Practices

  • Move nested search loops into a function and return
  • Use for … else instead of a found flag
  • Filter with a comprehension instead of continue when building lists
  • Loop over itertools.product(a, b) to avoid nesting

Quick Summary

  • break — exit loop
  • continue — next iteration
  • pass — placeholder
  • loop else — no-break case
