Unpacking, Nesting, Copying

Beyond basic methods, lists support unpacking with *, nesting into grids, and two kinds of copies. A shallow copy creates a new outer list that still shares inner objects; a deep copy duplicates everything. Knowing the difference prevents the most confusing list bugs, especially with nested data.

Notes

  • Only one starred target per unpacking
  • * in a list literal merges iterables
  • a.copy(), a[:], list(a) are all shallow
  • copy.deepcopy() handles any nesting depth
  • zip(*matrix) transposes rows and columns

Advanced List Patterns

first, second, *rest = [1, 2, 3, 4]   # 1, 2, [3, 4]
head, *_, tail = "abcde"              # 'a', 'e'
[*range(3), *"ab"]                    # [0, 1, 2, 'a', 'b']
grid = [[0] * 3 for _ in range(2)]    # independent rows
grid[0][1] = 5                        # [[0, 5, 0], [0, 0, 0]]
bad = [[0] * 3] * 2
bad[0][1] = 5                         # [[0, 5, 0], [0, 5, 0]]  shared!
a = [[1, 2], [3]]
b = a.copy()                          # shallow: inner lists shared
b[0].append(9); a                     # [[1, 2, 9], [3]]
import copy
c = copy.deepcopy(a)                  # fully independent
c[0].append(7); a                     # [[1, 2, 9], [3]]  unchanged
list(zip(*[[1, 2], [3, 4]]))          # [(1, 3), (2, 4)]

Code Explained

*rest — collects the remaining items
*_ — ignore the middle
comprehension grid — each row is a new list
[[0] * 3] * 2 — the same row twice
shallow vs deep — outer only vs everything

⚠ Common Mistakes

  • [[0] * n] * m for grids — every row is the same object
  • Expecting .copy() to copy nested lists — it's shallow
  • a, b = [1, 2, 3] — ValueError: too many values
  • Two starred targets — SyntaxError

✓ Tips & Best Practices

  • Use copy.deepcopy() for nested config or game state
  • Build grids with a comprehension
  • Transpose with [list(r) for r in zip(*m)]
  • Ignore unpacked values with _

Quick Summary

  • [*a, *b] — merge
  • shallow copy — shares inner objects
