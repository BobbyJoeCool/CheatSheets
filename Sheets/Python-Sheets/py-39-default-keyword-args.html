Defaults & Argument Rules

Default values make parameters optional. Defaults are evaluated once, when the def runs, so a mutable default such as [] or {} is shared across every call; use None and create the object inside. A bare * makes the parameters after it keyword-only, and / (3.8+) makes the parameters before it positional-only.

Notes

  • Parameters with defaults must follow those without
  • Immutable defaults (numbers, strings, None) are safe
  • f.__defaults__ shows stored defaults
  • Positional-only lets you rename parameters freely
  • Use an object() sentinel when None is a valid value

Defaults, *, /

def connect(host, port=5432, timeout=10): ...
connect("db")                          # port=5432, timeout=10
connect("db", timeout=3)               # skip port by name

def add_item(item, bucket=[]):         # BUG: one shared list
    bucket.append(item); return bucket
add_item(1); add_item(2)               # [1, 2]  surprise!

def add_item(item, bucket=None):       # fix
    if bucket is None:
        bucket = []
    bucket.append(item); return bucket

def resize(img, *, width, height): ...
resize(img, width=800, height=600)     # names required
resize(img, 800, 600)                  # TypeError

def dist(x, y, /, *, unit="m"): ...
dist(3, 4, unit="km")                  # x, y positional-only

Code Explained

defaults — fill in what the caller omits
bucket=[] — created once, reused forever
None sentinel — fresh list per call
* — everything after must be named
/ — everything before must be positional

⚠ Common Mistakes

  • Mutable default [] or {} — state leaks between calls
  • def f(a=1, b): — SyntaxError; defaults go last
  • def f(when=datetime.now()) — timestamp frozen at import
  • Bare positional flags f(x, True, False) — unreadable

✓ Tips & Best Practices

  • Make flags keyword-only: def save(path, *, overwrite=False)
  • Use _MISSING = object() when None is meaningful
  • Inspect signatures with inspect.signature(f)
  • Prefer / in public APIs whose parameter names may change

Quick Summary

  • p=val — optional parameter
  • None default — avoid shared mutables
  • * — keyword-only after
  • / — positional-only before
