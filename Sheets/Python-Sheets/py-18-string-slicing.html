String Slicing & Indexing

s[i] · negative index · s[start:stop] · step · s[::-1]

Indexes and Slices

Strings are sequences: s[i] returns one character, and negative indexes count from the end. A slice s[start:stop:step] returns a new string from start up to, but not including, stop. Omitted bounds default to the ends. Out-of-range slices are clamped silently, while an out-of-range index raises IndexError.

Notes

  • s[0] is first, s[-1] is last
  • len(s[a:b]) == b - a when both are in range
  • A negative step walks right to left
  • Slicing never raises an error
  • The same syntax works on lists and tuples

Index Map & Slices

s = "PYTHON"
#     P  Y  T  H  O  N
#     0  1  2  3  4  5
#    -6 -5 -4 -3 -2 -1
s[0], s[-1]                    # ('P', 'N')
s[1:4]                         # 'YTH'
s[:2], s[2:]                   # ('PY', 'THON')
s[-3:]                         # 'HON'
s[::2]                         # 'PTO'
s[::-1]                        # 'NOHTYP'
s[4:1:-1]                      # 'OHT'
s[10:]                         # ''  (clamped, no error)
s[10]                          # IndexError

Code Explained

s[1:4] — indexes 1, 2, 3; stop is excluded
s[-3:] — the last three characters
s[::2] — every second character
s[::-1] — reversed copy
s[4:1:-1] — 4, 3, 2 walking backward

⚠ Common Mistakes

  • Expecting stop to be included — s[0:3] has 3 chars, not 4
  • s[len(s)] — IndexError; the last index is len(s) - 1
  • s[1:4:-1] — empty; direction and bounds disagree
  • Assigning to a slice of a str — TypeError (immutable)

✓ Tips & Best Practices

  • Name slices for fixed-width records: DATE = slice(0, 10)
  • s[-1:] returns '' on empty strings instead of raising
  • Reverse with s[::-1]; check palindromes with s == s[::-1]
  • Practice slices on lists too — the rules are identical

Quick Summary

  • s[i] — one character
  • s[a:b] — a up to b (exclusive)
  • s[::-1] — reverse
  • negative indexes — count from the end
