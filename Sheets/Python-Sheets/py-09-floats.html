Sheet 09

Floats

float literals · e notation · inf · nan · round() · math.isclose · Decimal

IEEE 754 Doubles

float is a 64-bit IEEE 754 double with about 15–17 significant digits and a range near ±1.8e308. Many decimals such as 0.1 have no exact binary form, so arithmetic produces tiny rounding errors. Compare floats with math.isclose() and use decimal.Decimal when exact decimal results matter, as with money.

Notes

  • / always returns a float: 4 / 2 is 2.0
  • round() uses banker's rounding (half to even)
  • nan is never equal to anything, including itself
  • Limits live in sys.float_info
  • float("inf") and math.inf are equivalent

Float Behavior

3.14, 2., .5, 1e3, 2.5e-4      # (3.14, 2.0, 0.5, 1000.0, 0.00025)
0.1 + 0.2                      # 0.30000000000000004
0.1 + 0.2 == 0.3               # False
import math
math.isclose(0.1 + 0.2, 0.3)   # True
round(2.5), round(3.5)         # (2, 4)  banker's rounding
round(2.675, 2)                # 2.67  (stored as 2.67499...)
float("inf") > 1e308           # True
nan = float("nan")
nan == nan, math.isnan(nan)    # (False, True)
(7.0).is_integer()             # True
from decimal import Decimal
Decimal("0.1") + Decimal("0.2")  # Decimal('0.3')

Code Explained

⚠ Common Mistakes

  • Comparing floats with == — use math.isclose()
  • Decimal(0.1) — inherits the float error; pass "0.1"
  • Expecting round(2.5) to be 3 — it's 2
  • Storing currency as float — use Decimal or integer cents

✓ Tips & Best Practices

  • Format for display with f"{x:.2f}"; keep full precision internally
  • Pass abs_tol=1e-9 to isclose() when comparing to zero
  • math.fsum([0.1] * 10) gives 1.0; sum() gives 0.9999999999999999
  • Read big numbers with float("1e6") or 1e6
