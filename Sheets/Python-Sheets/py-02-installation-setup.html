Getting Python Running

Install Python 3 from python.org (Windows, macOS), your OS package manager (Linux), or a version manager. Give every project its own virtual environment so its packages never collide with other projects or the system Python. The venv module is built in, and pip installs packages into whichever environment is active.

Platform Notes

  • Windows installer: tick Add python.exe to PATH
  • Windows py launcher selects versions: py -3.12
  • macOS /usr/bin/python3 comes with Xcode tools; prefer python.org or Homebrew
  • Linux system Python runs OS tools; never pip install into it
  • uv is a fast newer tool that handles venvs and packages

Verify, Create a venv, Install

# Verify the install
python3 --version             # Python 3.12.x
python3 -m pip --version      # pip 24.x from ...

# Create and activate a virtual environment
python3 -m venv .venv         # creates ./.venv
source .venv/bin/activate     # macOS / Linux
.venv\Scripts\activate        # Windows

# Work inside the env
pip install requests          # installs into .venv only
pip freeze > requirements.txt # record exact versions
deactivate                    # leave the env

Code Explained

-m venv — runs the venv module as a script
.venv — conventional folder name; add it to .gitignore
activate — puts the env's bin/ or Scripts\ first on PATH
python -m pip — guarantees pip matches that interpreter
deactivate — restores the previous PATH

⚠ Common Mistakes

  • pip install with no active venv — pollutes the global site-packages
  • sudo pip install on Linux — can break OS tools; use a venv or pipx
  • Committing .venv/ to git — it's machine-specific; commit requirements.txt
  • pip and python pointing at different installs — use python -m pip

✓ Tips & Best Practices

  • One venv per project, stored in the project folder as .venv
  • VS Code and PyCharm detect .venv; select it as the interpreter
  • Restore an env with pip install -r requirements.txt
  • Use pipx for global tools like ruff or httpie

Quick Summary

  • python3 --version — confirm the install
  • python -m venv .venv — create an isolated env
  • activate / deactivate — enter and leave it
  • python -m pip install — install into the active env
