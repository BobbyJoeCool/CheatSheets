OS & System Modules

os.environ · os.getcwd() · sys.argv · sys.exit() · subprocess.run() · shutil

Talking to the Operating System

os reads and changes the environment your program runs in: the working directory, environment variables, and processes. sys exposes the interpreter itself: command-line arguments, version, platform, and exit codes. shutil performs high-level file operations, and subprocess.run() launches other programs and captures their output.

Notes

  • os.environ changes affect this process and its children only
  • sys.argv[0] is the script name
  • Exit status 0 means success
  • Pass commands to subprocess as a list, not a string
  • For real CLIs, use argparse instead of raw sys.argv

os, sys, shutil, subprocess

import os, sys, shutil, subprocess
os.getcwd()                            # current folder
os.environ.get("HOME")                 # env var or None
os.environ["APP_MODE"] = "dev"         # set for this process
os.listdir(".")                        # names in folder
os.cpu_count()                         # e.g. 8
sys.argv                               # ['script.py', 'arg1', ...]
sys.version_info >= (3, 10)            # True
sys.platform                           # 'linux', 'darwin', 'win32'
shutil.copy2("a.txt", "b.txt")         # copy with metadata
shutil.rmtree("build")                 # delete a folder tree
shutil.which("git")                    # '/usr/bin/git' or None
r = subprocess.run(["git", "status"], capture_output=True,
                   text=True, check=True)
r.returncode, r.stdout[:15]            # (0, 'On branch main\n')
sys.exit(1)                            # exit with status 1

Code Explained

environ.get() — safe; environ[k] raises KeyError
sys.platform — branch on OS
shutil.which() — find a program on PATH
capture_output + text — get stdout as a str
check=True — raise if the command fails

⚠ Common Mistakes

  • shell=True with user input — command injection risk
  • os.environ["KEY"] for optional settings — KeyError when unset
  • Calling sys.exit() inside library code — kills the caller's program
  • Relying on the working directory — scripts break when run elsewhere

✓ Tips & Best Practices

  • Use argparse for flags and help text
  • Use pathlib instead of os.path for paths
  • Set timeout= on subprocess calls that might hang
  • Read config from env vars with defaults: os.getenv("PORT", "8000")
