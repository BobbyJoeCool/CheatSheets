Sheet 20

Comparison Operators

== · != · < · > · <= · >= · chained comparisons

Comparing Values

Comparison operators return a bool. == compares values by calling __eq__, not identity. Ordering operators work between compatible types; comparing an int with a str raises TypeError. Comparisons can be chained: a < b < c means a < b and b < c, with b evaluated only once.

Notes

  • Strings compare by Unicode code point
  • Sequences compare item by item; the first difference decides
  • nan is unequal to everything, itself included
  • Sets use < / > for subset / superset
  • = assigns; == compares

Comparison Examples

3 == 3.0                       # True  (value, not type)
"a" == "A"                     # False (case-sensitive)
[1, 2] == [1, 2]               # True  (element-wise)
3 != 4                         # True
"apple" < "banana"             # True  (lexicographic)
"Z" < "a"                      # True  (90 < 97)
[1, 2, 3] < [1, 3]             # True  (2 < 3 decides)
(1, "b") > (1, "a")            # True
1 < 5 < 10                     # True  (chained)
1 < 5 > 3                      # True  (1 < 5 and 5 > 3)
1 < "2"                        # TypeError
float("nan") == float("nan")   # False
max("pear", "fig", key=len)    # 'pear'

Code Explained

3 == 3.0 — numbers compare by value across types
string order — uppercase letters sort before lowercase
[1, 2, 3] < [1, 3] — stops at the first unequal item
chained — reads like math: 0 <= x < 10
key= — compare by a derived value

⚠ Common Mistakes

  • if x = 5: — SyntaxError; use ==
  • x == 1 or 2 — always truthy; use x in (1, 2)
  • Comparing floats with == — use math.isclose()
  • Sorting numeric strings — "10" < "9"; convert to int first

✓ Tips & Best Practices

  • Range checks read naturally: 0 <= x < 10
  • Use key= with max, min, sorted for custom order
  • functools.total_ordering fills in missing comparison methods
  • Case-insensitive compare: a.casefold() == b.casefold()

Quick Summary

  • == / != — value equality
  • < > <= >= — ordering
  • chaining — a < b < c
  • mixed types — TypeError for ordering
