itertools Module

count() · cycle() · chain() · combinations() · permutations() · groupby() · islice()

Iterator Building Blocks

itertools provides fast, memory-efficient tools that build and combine iterators. There are three families: infinite iterators (count, cycle, repeat), combinatoric generators (product, permutations, combinations), and terminating tools that slice, chain, group, and accumulate. All return lazy iterators, so wrap them in list() to see the values.

Notes

  • Always limit infinite iterators with islice or break
  • groupby() groups consecutive keys; sort first
  • pairwise (3.10+) and batched (3.12+) are newer
  • Results are lazy and single-pass
  • more-itertools (PyPI) adds many more recipes

itertools Highlights

from itertools import (count, cycle, repeat, chain, islice, combinations,
                       permutations, product, accumulate, groupby, pairwise)
list(islice(count(10, 5), 3))          # [10, 15, 20]
list(islice(cycle("AB"), 5))           # ['A', 'B', 'A', 'B', 'A']
list(repeat("x", 3))                   # ['x', 'x', 'x']
list(chain([1, 2], (3,), "ab"))        # [1, 2, 3, 'a', 'b']
list(combinations("ABC", 2))           # [('A','B'), ('A','C'), ('B','C')]
len(list(permutations("ABC", 2)))      # 6
list(product([0, 1], repeat=2))        # [(0,0), (0,1), (1,0), (1,1)]
list(accumulate([1, 2, 3, 4]))         # [1, 3, 6, 10]
list(pairwise([1, 2, 3]))              # [(1, 2), (2, 3)]
words = sorted(["apple", "bean", "avocado"])
for k, grp in groupby(words, key=lambda w: w[0]):
    print(k, list(grp))                # a ['apple', 'avocado'] / b ['bean']

Code Explained

islice — take part of any iterator
chain — iterate several iterables as one
combinations — order doesn't matter; permutations — it does
groupby — needs input sorted by the same key

⚠ Common Mistakes

  • groupby() on unsorted data — the same key appears in several groups
  • list(count()) — never finishes
  • Reusing an itertools iterator — it's exhausted after one pass
  • Consuming grp after moving to the next group — it's gone

✓ Tips & Best Practices

  • Replace nested loops with product()
  • Flatten one level with chain.from_iterable(lists)
  • Running totals: accumulate(xs); running max: accumulate(xs, max)
  • Chunk large data with batched(rows, 500)

Quick Summary

  • infinite — count cycle repeat
  • combinatoric — product combinations
  • terminating — chain islice groupby
  • lazy — wrap in list() to view
