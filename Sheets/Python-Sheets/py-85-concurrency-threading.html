Threading & Concurrency

threading.Thread · start() · join() · Lock · ThreadPoolExecutor · GIL

Running Code in Threads

A thread runs a function concurrently inside the same process and shares its memory. In standard CPython, the Global Interpreter Lock (GIL) lets only one thread execute Python bytecode at a time, so threads help with I/O-bound waits (network, disk) but not CPU-heavy work. Protect shared data with a Lock, and prefer ThreadPoolExecutor for simple parallel jobs.

Notes

  • The GIL is released while threads wait on I/O
  • counter += 1 is not atomic across threads
  • join() waits for a thread to finish
  • Free-threaded builds (3.13+) can run without the GIL

Threads, Locks, Executors

import threading, time
from concurrent.futures import ThreadPoolExecutor
def download(url):
    time.sleep(1)                      # stands in for network I/O
    return f"got {url}"
counter, lock = 0, threading.Lock()
def bump():
    global counter
    for _ in range(100_000):
        with lock:                     # one thread at a time
            counter += 1
threads = [threading.Thread(target=bump) for _ in range(4)]
for th in threads: th.start()
for th in threads: th.join()
counter                                # 400000, exact
with ThreadPoolExecutor(max_workers=5) as pool:
    results = list(pool.map(download, ["a", "b", "c"]))  # ~1 s

Code Explained

Thread(target=bump) — function to run in the thread
with lock: — acquire and always release
pool.map() — parallel map that returns results in order

⚠ Common Mistakes

  • Updating shared data without a lock — lost updates
  • Forgetting join() — the program moves on before results exist
  • Expecting threads to speed up CPU-bound code under the GIL
  • Calling t.run() instead of t.start() — runs in the current thread

✓ Tips & Best Practices

  • Use ThreadPoolExecutor instead of managing threads by hand
  • Pass data with queue.Queue rather than shared variables
  • Keep locked sections short
  • Give threads names for clearer logs: Thread(name="worker-1")

Quick Summary
