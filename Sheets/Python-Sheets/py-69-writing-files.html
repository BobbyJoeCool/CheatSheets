Writing & Appending Files

'w' · 'a' · 'x' · write() · writelines() · print(file=)

Creating and Updating Files

Open a file with mode "w" to write (creating it or erasing existing content), "a" to append to the end, or "x" to create it only if it doesn't exist yet. write() takes a string and doesn't add newlines; writelines() writes many strings; print(..., file=f) formats and adds a newline for you. Use "b" modes for bytes.

Notes

  • "w" truncates the file immediately on open
  • write() returns the number of characters written
  • Data is buffered until the file is flushed or closed
  • "x" raises FileExistsError instead of overwriting
  • Write CSV files with newline="" (Sheet 72)

Writing Patterns

with open("out.txt", "w", encoding="utf-8") as f:
    f.write("Hello\n")                 # returns 6
    f.write(f"Total: {42}\n")          # write() needs a str
with open("out.txt", "a", encoding="utf-8") as f:
    f.write("appended line\n")         # added at the end
lines = ["a", "b", "c"]
with open("list.txt", "w", encoding="utf-8") as f:
    f.writelines(f"{x}\n" for x in lines)  # add \n yourself
with open("report.txt", "w", encoding="utf-8") as f:
    print("Name", "Score", sep="\t", file=f)  # print to a file
with open("new.txt", "x", encoding="utf-8") as f:
    f.write("fresh")                   # FileExistsError if present
with open("data.bin", "wb") as f:
    f.write(bytes([0, 255]))           # binary needs bytes
from pathlib import Path
Path("note.txt").write_text("hi\n", encoding="utf-8")

Code Explained

"w" — start fresh; old content is gone
"a" — keep content, add to the end
writelines() — no separators added
print(file=f) — handy for formatted rows
"wb" — write bytes objects

⚠ Common Mistakes

  • Opening an existing file with "w" — its content is erased instantly
  • f.write(42) — TypeError; convert with str() or an f-string
  • Expecting writelines() to add newlines — it doesn't
  • Not closing the file — buffered data can be lost

✓ Tips & Best Practices

  • Write to a temp file and os.replace() it for crash safety
  • Use print(..., file=f) for quick reports
  • Use "x" mode for files that must never be overwritten
  • tempfile.NamedTemporaryFile for scratch files

Quick Summary

  • "w" — overwrite; "a" — append
  • "x" — create only
  • write() — str only, no newline
  • print(file=f) — formatted output
