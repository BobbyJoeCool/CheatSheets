Lambda Functions

lambda · sorted(key=) · map() · filter() · limitations

Anonymous Functions

lambda params: expression creates a small anonymous function. The body is a single expression whose value is returned automatically: no statements, no return, no annotations. Lambdas shine as short key= and callback arguments. If you'd give it a name or reuse it, write a def instead.

Notes

  • lambda creates the same function type as def
  • Its __name__ is '<lambda>' (worse tracebacks)
  • Defaults, *args, **kwargs all work
  • Ternary expressions are allowed inside
  • PEP 8 discourages f = lambda ...

Lambdas in Context

square = lambda x: x * x           # works, but prefer def
square(4)                          # 16
(lambda a, b=2: a + b)(3)          # 5
names = ["bo", "Ana", "cy"]
sorted(names, key=str.lower)       # ['Ana', 'bo', 'cy']
sorted(names, key=lambda s: len(s))  # ['bo', 'cy', 'Ana']
pairs = [("a", 3), ("b", 1)]
sorted(pairs, key=lambda p: p[1])  # [('b', 1), ('a', 3)]
max(pairs, key=lambda p: p[1])     # ('a', 3)
list(map(lambda x: x * 2, [1, 2])) # [2, 4]
list(filter(lambda x: x > 1, [1, 2, 3]))  # [2, 3]
users = [{"n": "Bo", "age": 30}, {"n": "Ana", "age": 30}]
sorted(users, key=lambda u: (u["age"], u["n"]))  # Ana first
button.config(command=lambda: save(doc))  # Tkinter callback

Code Explained

key=str.lower — pass an existing function when one fits
key=lambda p: p[1] — sort by the second field
tuple key — sorts by age, then name
command=lambda: ... — delays the call until the click

⚠ Common Mistakes

  • f = lambda x: ... — use def f(x): for named functions
  • Trying statements in a lambda (=, if: blocks, return) — SyntaxError
  • Lambdas created in a loop capture the last loop value
  • Long, clever lambdas — turn them into a named def

✓ Tips & Best Practices

  • Sort by several fields with a tuple key
  • operator.itemgetter and attrgetter are faster and clearer
  • Pass key=len, key=str.lower directly — no lambda needed
  • In GUIs, use lambda to pass arguments to callbacks

Quick Summary

  • lambda x: expr — inline function
  • single expression — auto-returned
  • best for key= and callbacks
  • reuse it → def
