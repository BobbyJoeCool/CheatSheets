Reading Files

open() · read() · readline() · readlines() · for line in f · encoding

Opening and Reading

open(path) returns a file object; the default mode "r" reads text. Always open files in a with block so they close automatically. read() returns the whole file as one string, readline() one line, readlines() a list of lines, and iterating the file object streams one line at a time. Pass encoding="utf-8" explicitly, because the default depends on the operating system.

Notes

  • Lines keep their trailing \n
  • Iterating for line in f uses little memory
  • "rb" mode returns bytes, not str
  • A file object is consumed as you read; seek(0) rewinds
  • Path.read_text() reads a whole file in one call

Reading Patterns

with open("notes.txt", encoding="utf-8") as f:
    text = f.read()                    # whole file as one str
with open("notes.txt", encoding="utf-8") as f:
    first = f.readline()               # 'line 1\n' (keeps \n)
    rest = f.readlines()               # ['line 2\n', 'line 3\n']
with open("big.log", encoding="utf-8") as f:
    for line in f:                     # streams line by line
        if "ERROR" in line:
            print(line.rstrip("\n"))
with open("notes.txt", encoding="utf-8") as f:
    lines = f.read().splitlines()      # no trailing \n
with open("photo.jpg", "rb") as f:
    header = f.read(4)                 # b'\xff\xd8\xff\xe0'
from pathlib import Path
Path("notes.txt").read_text(encoding="utf-8")  # one-liner

Code Explained

with — closes the file even if an error occurs
readline() then readlines() — continues where it left off
for line in f — best for large files
splitlines() — lines without newline characters
"rb" — raw bytes for images and other binary data

⚠ Common Mistakes

  • Opening without with — the file may stay open after errors
  • Omitting encoding — works on your machine, fails on another
  • read() on a multi-GB file — loads it all into memory
  • Comparing lines without stripping \n — "yes\n" != "yes"

✓ Tips & Best Practices

  • Stream big files with for line in f
  • Use Path(...).read_text() for small files
  • Pass errors="replace" when reading messy text
  • Build paths relative to the script with Path(__file__).parent

Quick Summary

  • with — auto-close
  • read() / readline() / readlines()
