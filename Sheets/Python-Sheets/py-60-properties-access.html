Properties & Access Control

@property · setter · deleter · _private · __mangling · __slots__

Controlled Attribute Access

A property looks like a plain attribute to callers but runs methods behind the scenes, so you can validate values, compute results, or make attributes read-only without changing the public interface. Python has no private keyword: a single underscore marks something internal by convention, and a double underscore triggers name mangling to avoid clashes in subclasses.

Notes

  • Start with plain attributes; add a property later if needed
  • Store the real value under _name
  • A property without a setter is read-only
  • __slots__ blocks new attributes and saves memory
  • functools.cached_property computes once, then caches

Validated and Computed Properties

class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius         # runs the setter
    @property
    def celsius(self):
        return self._celsius
    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("below absolute zero")
        self._celsius = value
    @property
    def fahrenheit(self):              # computed, read-only
        return self._celsius * 9 / 5 + 32
t = Temperature(20)
t.fahrenheit                           # 68.0
t.celsius = -300                       # ValueError
t.fahrenheit = 50                      # AttributeError (no setter)

Code Explained

@property — getter; accessed without ()
@celsius.setter — runs on assignment
self._celsius — the stored value
__init__ uses the setter, so validation always applies

⚠ Common Mistakes

  • Setter assigns self.celsius — infinite recursion; use self._celsius
  • Setter name not matching the property — creates a separate property
  • Expensive work in a getter — callers assume attribute access is cheap
  • Treating _name as enforced privacy — it's only a convention

✓ Tips & Best Practices

  • Don't write getters/setters up front; Python lets you add them later
  • Use cached_property for costly values that never change
  • Add __slots__ when creating millions of small objects
  • Expose read-only data as a property without a setter

Quick Summary

  • @property — method as attribute
  • @x.setter — validate on assignment
  • _name — internal by convention
  • __name — name mangling
