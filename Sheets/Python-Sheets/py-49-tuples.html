Tuples

tuple literals · immutability · unpacking · namedtuple · hashable

Immutable Sequences

A tuple is an ordered, immutable sequence. Commas create tuples; parentheses are only needed for the empty tuple or to avoid ambiguity. Because tuples can't change, those holding only hashable items are hashable, so they work as dict keys and set members. Use them for fixed records, multiple return values, and unpacking. namedtuple adds field names.

Notes

  • A one-item tuple needs a trailing comma: (5,)
  • Only two methods: count() and index()
  • Immutable container, but inner lists can still change
  • Slightly smaller and faster than lists
  • typing.NamedTuple gives a class-style definition

Tuple Basics

point = (3, 4)
also = 3, 4                        # parentheses optional
single = (5,)                      # trailing comma required
not_tuple = (5)                    # just the int 5
x, y = point                       # unpacking
point[0]                           # 3
point[0] = 9                       # TypeError
(1, 2) + (3,)                      # (1, 2, 3)
locs = {(0, 0): "origin"}          # tuple as dict key
t = ([1], 2); t[0].append(5)       # ([1, 5], 2)
from collections import namedtuple
P = namedtuple("P", "x y")
p = P(3, 4)
p.x, p._asdict()                   # (3, {'x': 3, 'y': 4})

Code Explained

3, 4 — the comma makes the tuple
(5) — parentheses alone just group
point[0] = 9 — tuples can't be changed
t[0].append(5) — the list inside is still mutable
namedtuple — access by name or index

⚠ Common Mistakes

  • (5) is an int — write (5,)
  • Trying t.append() — tuples have no mutating methods
  • Using a tuple that contains a list as a dict key — TypeError
  • Long positional tuples — use namedtuple or a dataclass

✓ Tips & Best Practices

  • Use typing.NamedTuple for typed, named fields
  • Return tuples and unpack them at the call
  • Use tuples for constants: RGB = (255, 128, 0)
  • _replace() makes a modified copy of a namedtuple

Quick Summary

  • (a, b) / a, b — tuple
  • (x,) — single item
  • immutable — can be dict keys
  • namedtuple — named fields
