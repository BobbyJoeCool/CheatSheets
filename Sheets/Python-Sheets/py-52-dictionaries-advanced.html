Merging, Grouping, Nesting

Beyond basic methods, dicts support merging with | (3.9+), auto-initializing values with defaultdict, and nesting for JSON-like data. These patterns cover most real-world dict work: combining configs, grouping items, counting, and safely reading deep structures.

Notes

  • In a | b, b's values win on conflicts
  • defaultdict creates a missing key on first access
  • Sorting a dict gives a list; rebuild with dict()
  • OrderedDict adds move_to_end() for LRU logic
  • Nested dicts copy shallowly unless you deepcopy

Advanced Dict Patterns

from collections import defaultdict
base = {"host": "localhost", "port": 80}
extra = {"port": 8080}
base | extra                       # {'host': 'localhost', 'port': 8080}
{**base, **extra}                  # same result (any 3.x)
base |= extra                      # merge in place (3.9+)
groups = defaultdict(list)
for word in ["apple", "avocado", "kiwi"]:
    groups[word[0]].append(word)   # no KeyError
dict(groups)                       # {'a': ['apple', 'avocado'], 'k': ['kiwi']}
cfg = {"db": {"host": "x", "port": 5432}}
cfg["db"]["port"]                  # 5432
cfg.get("cache", {}).get("ttl", 60)  # 60  safe nested read
scores = {"ana": 9, "bo": 7}
sorted(scores, key=scores.get)     # ['bo', 'ana']
max(scores, key=scores.get)        # 'ana'

Code Explained

| — new merged dict; |= — in place
defaultdict(list) — missing keys start as []
chained .get(..., {}) — no KeyError on missing levels
key=scores.get — sort or pick keys by their values

⚠ Common Mistakes

  • Reading a defaultdict key to test it — the read creates the key
  • Assuming | keeps the left value on conflict — the right side wins
  • sorted(d) expecting a dict — you get a list of keys
  • Copying nested configs with .copy() — inner dicts are shared

✓ Tips & Best Practices

  • Test with k in dd on defaultdicts to avoid insertion
  • Layer settings: defaults | file_cfg | cli_args
  • Use TypedDict to document dict shapes for type checkers
  • Convert to a plain dict with dict(dd) before printing

Quick Summary

  • a | b — merge (right wins)
  • defaultdict — automatic defaults
  • nested .get() — safe deep reads
  • key=d.get — rank keys by value
