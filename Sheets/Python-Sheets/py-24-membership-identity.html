Membership & Identity Operators

in · not in · is · is not · id()

in, not in, is, is not

in and not in test membership in strings (substring), lists, tuples, sets, and dicts (keys). is and is not test identity: whether two names point to the same object, the same id(). Use == to compare values; use is only for singletons such as None, True, False, and sentinel objects.

Notes

  • in on a dict checks keys, not values
  • Set and dict lookups are O(1) on average
  • List, tuple, and str lookups scan: O(n)
  • is can't be overridden; == can (__eq__)
  • x is 5 triggers a SyntaxWarning (3.8+)

Membership & Identity

3 in [1, 2, 3]                 # True
"py" in "python"               # True  (substring)
"a" in {"a": 1}                # True  (dict keys)
1 in {"a": 1}.values()         # True
4 not in (1, 2, 3)             # True
a = [1, 2]; b = [1, 2]; c = a
a == b, a is b                 # (True, False)
a is c                         # True  (same object)
id(a) == id(c)                 # True
x = None
x is None                      # True  (preferred test)
5 in range(0, 10)              # True  (fast for ints)

Code Explained

in str — substring search
in dict — key lookup; use .values() for values
a == b — equal contents
a is b — literally the same object
in range — computed, not scanned

⚠ Common Mistakes

  • x is 1000 — identity of numbers is an implementation detail
  • "Ana" in users_dict.values() vs keys — know which you need
  • Checking in against a big list inside a loop — convert to a set
  • not x in y — works, but x not in y is clearer

✓ Tips & Best Practices

  • Build a set once for repeated lookups: seen = set(items)
  • Use is for None and sentinel objects only
  • Use d.get(key) instead of if key in d: d[key]
  • Test small option lists inline: if ext in {".jpg", ".png"}:

Quick Summary

  • in / not in — membership
  • is / is not — identity
  • == — value equality
  • sets & dicts — fast lookups
