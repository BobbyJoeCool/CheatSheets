Sheet 18

Loops

for x in … · for x ($list) short form · for ((i=0; i<n; i++)) · while / until · repeat N · break / continue N · for line in ${(f)"$(cmd)"}

Looping

for runs a block once per word in a list, a range, or C-style counter. while repeats while a command succeeds and until repeats while it fails. Zsh adds repeat N, short forms that skip do … done for one command, and the ability to take several variables per pass. Lists come from globs, arrays, brace ranges, or command output split into lines with ${(f)…}.

Notes

  • {1..$n} works with variables in zsh
  • {0..10..2} adds a step: 0 2 4 6 8 10
  • while read -r line is the safe way to read lines
  • break 2 / continue 2 affect the outer loop

Loop Forms

for f in *.txt; do
  echo "→ $f"
done
for f in *.txt; echo $f                 # short form, one command
for x ($fruits) print $x                # short form with ( )
for i in {1..5}; do echo $i; done
for (( i = 0; i < 3; i++ )); do echo $i; done       # 0 1 2
for k v in ${(kv)user}; do echo "$k=$v"; done      # two vars per pass
for host in ${(f)"$(< hosts.txt)"}; do ping -c1 $host; done
while read -r line; do
  echo "> $line"
done < input.txt
until curl -sf localhost:8080 >/dev/null; do sleep 2; done
repeat 3 print hi                       # hi hi hi (3 lines)
for i in {1..10}; do
  (( i % 2 )) && continue               # skip odd numbers
  (( i > 6 )) && break                  # stop after 6
  echo $i                               # 2 4 6
done

Code Explained

for f in *.txt — glob expands once, before the loop starts
for k v in — takes two words per pass
${(f)"$(< file)"} — one element per line, spaces kept
while read -r … done < file — reads in the current shell, so variables persist
repeat N — runs a command N times

⚠ Common Mistakes

  • Changing an array inside a loop over it: the list was expanded when the loop started
  • Writing for line in $(cat file): it splits on spaces as well as newlines. Use ${(f)"$(<file)"}
  • Forgetting -r on read: backslashes are eaten
  • Using for i in 1..5: you need braces, {1..5}

✓ Tips & Best Practices

  • Use the short form for f (*.log) gzip $f for quick one-liners
  • Add (N) to loop globs so an empty match skips the loop instead of erroring
  • Use while IFS=, read -r a b to split CSV-like lines into fields
  • Loop over lines safely with while read -r line; do …; done < <(cmd)

Quick Summary

  • for x in list; do …; done — iterate
  • for ((;;)) — counter loop
  • while / until — conditional loops
  • repeat N — fixed count
  • break / continue — loop control
