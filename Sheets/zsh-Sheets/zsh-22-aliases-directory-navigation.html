Aliases & Directory Navigation

alias · alias -g global · alias -s suffix · AUTO_CD · AUTO_PUSHD / dirs -v · cd -<Tab> · hash -d named dirs · cd old new

Shortcuts for Typing & Moving

An alias replaces a word with text before the command runs. Zsh has three kinds: regular aliases (only in command position), global aliases with -g (anywhere on the line), and suffix aliases with -s (open a file by typing its name). For navigation, zsh can cd when you type a bare directory name, keep a numbered directory stack, and give folders short named directory names like ~proj.

Notes

  • Aliases aren't expanded in scripts unless ALIASES is set and they're defined there
  • Escape an alias with \ls or command ls
  • Named dirs also shorten the prompt: %~ shows ~proj/src
  • cdpath=(~ ~/code) lets cd app find ~/code/app

Aliases & Navigation

alias ll='ls -lah'            # regular alias
alias -g G='| grep -i'        # global: works anywhere
ps aux G python               # → ps aux | grep -i python
alias -g NE='2>/dev/null'     # find / -name x NE
alias -s md=code              # suffix: typing notes.md opens it in code
unalias ll                    # remove an alias

setopt AUTO_CD AUTO_PUSHD PUSHD_IGNORE_DUPS
src                           # AUTO_CD: same as cd src
..                            # up one level
cd -                          # previous directory
dirs -v                       # numbered directory stack
cd -2                         # jump to stack entry 2 (try cd -<Tab>)
hash -d proj=~/code/myproject # create a named directory
cd ~proj                      # → ~/code/myproject
cd /usr/local/bin
cd local share                # → /usr/share/bin   (swap part of $PWD)

Code Explained

alias -g — expands anywhere, so pick names that won't clash (uppercase is common)
alias -s ext=cmd — file.ext alone runs cmd file.ext
AUTO_PUSHD — every cd pushes the old dir onto the stack
cd old new — replaces old with new in the current path

⚠ Common Mistakes

  • Defining a global alias with a common word: alias -g e=… rewrites every standalone e
  • Expecting aliases inside functions defined *before* the alias: aliases expand when code is read
  • Using aliases in scripts: write a function instead
  • Forgetting quotes: alias ll=ls -la fails. Use alias ll='ls -la'

✓ Tips & Best Practices

  • Use a function when you need arguments in the middle: mkcd() { mkdir -p $1 && cd $1 }
  • Press Tab after cd - to pick from the directory stack menu
  • Add hash -d names for folders you visit every day
  • List global aliases with alias -g and suffix aliases with alias -s
