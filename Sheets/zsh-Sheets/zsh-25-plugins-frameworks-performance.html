Extending Zsh

Frameworks like Oh My Zsh bundle settings, themes and plugins in one install. Plugin managers like antidote or zinit just download and load the plugins you list. You can also clone a plugin and source it yourself. Every plugin adds startup time, so measure with zprof and time zsh -i -c exit, and keep startup under roughly 100–200 ms.

Notes

  • Load zsh-syntax-highlighting last: it wraps widgets made by other plugins
  • Most plugins are plain .zsh files you can source
  • Prompts like Starship work in any shell; Powerlevel10k is zsh-only

Loading & Profiling

# Oh My Zsh (in ~/.zshrc)
ZSH=$HOME/.oh-my-zsh
plugins=(git z fzf)
source $ZSH/oh-my-zsh.sh

# antidote: repos listed in ~/.zsh_plugins.txt
source ~/.antidote/antidote.zsh
antidote load                 # clones, sources, caches a bundle

# No manager: clone once, then source
source ~/.zsh/zsh-autosuggestions/zsh-autosuggestions.zsh
eval "$(starship init zsh)"   # Starship prompt

zmodload zsh/zprof            # FIRST line of .zshrc
zprof                         # LAST line: time spent per function
time zsh -i -c exit           # total interactive startup time

Code Explained

plugins=(…) — Oh My Zsh loads each from $ZSH/plugins
antidote load — reads .zsh_plugins.txt and builds a static load file
eval "$(starship init zsh)" — prints the setup code, then runs it
zprof — the top rows show what to remove or lazy-load

⚠ Common Mistakes

  • Loading Oh My Zsh and a plugin manager that also runs compinit: double work at every start
  • Enabling dozens of Oh My Zsh plugins you never use: each one costs startup time
  • Sourcing syntax highlighting before other widget plugins: highlighting breaks

✓ Tips & Best Practices

  • Profile first: zprof usually points at nvm, compinit, or a heavy plugin
  • Accept an autosuggestion with → or End; bind Ctrl-Space to autosuggest-accept
  • Try a new plugin in zsh -f first, then source it, before adding it to .zshrc
