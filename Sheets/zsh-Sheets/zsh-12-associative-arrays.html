Associative Arrays

An associative array maps string keys to values, like a dictionary or hash map. It must be declared with typeset -A (or local -A) before use. Assign pairs with h=(k1 v1 k2 v2) or h[key]=value, and read with $h[key]. Expansion flags list the keys (k), values (v), or both (kv). Key order is not preserved, so sort with (ok) when order matters.

Notes

  • Without typeset -A, h[name]=x is treated as a numeric index and fails
  • Values are strings; there are no nested hashes
  • $h alone expands to all values
  • Quote keys with spaces or special chars: $h["my key"]

Using a Hash

typeset -A user               # declare first
user=(name Ada lang zsh)      # key value key value …
user[city]=London             # add or update a key
echo $user[name]              # Ada
echo ${(k)user}               # name lang city   (order not guaranteed)
echo ${(v)user}               # Ada zsh London
echo ${#user}                 # 3
(( ${+user[city]} )) && echo "has city"     # key exists?
unset 'user[city]'            # delete a key (quote it)
for k v in ${(kv)user}; do print "$k=$v"; done
for k in ${(ok)user}; do print "$k → $user[$k]"; done   # sorted keys
typeset -A codes=( [red]=31 [green]=32 )   # [key]=value form
echo ${codes[(r)3*]}          # 31 or 32   (first value matching)
echo ${codes[(I)g*]}          # green      (key matching pattern)

Code Explained

${+h[key]} — 1 if the key exists, even when its value is empty
unset 'h[key]' — quotes stop [key] being read as a glob
for k v in — zsh can take two loop variables at a time
(r) / (I) — search values / keys by pattern

⚠ Common Mistakes

  • Skipping typeset -A: assigning h[key]=v then fails with a subscript error
  • Expecting keys in insertion order: zsh hashes are unordered. Use (ok) or keep a separate key array
  • Testing [[ -n $h[k] ]] for existence: it's false for keys with empty values. Use ${+h[k]}
  • Writing local h inside a function and then h[k]=v: declare it as local -A h

✓ Tips & Best Practices

  • Use typeset -p h to inspect a hash quickly while debugging
  • Copy a hash with typeset -A b=("${(@kv)a}")
  • Use a hash as a set: seen[$x]=1, then check (( ${+seen[$x]} ))
  • Build a lookup table at the top of a script instead of a long case

Quick Summary

  • typeset -A h — declare
  • h[k]=v / $h[k] — set / get
  • ${(k)h} ${(v)h} — keys / values
  • ${+h[k]} — key exists?
  • for k v in ${(kv)h} — iterate pairs
