Arrays

Arrays hold an ordered list of strings. Create one with name=(a b c). Zsh arrays are 1-based: $arr[1] is the first element, and $arr alone expands to all elements (in bash it's only the first). Negative indexes count from the end, $arr[2,4] takes a slice, and subscript flags like (i) and (r) search the array without a loop.

Notes

  • $arr (unquoted) skips empty elements; "${arr[@]}" keeps them
  • $#arr and ${#arr} both give the length
  • setopt KSH_ARRAYS switches to bash-style 0-based indexing
  • Arrays can't be nested or exported

Working with Arrays

fruits=(apple banana cherry)
echo $fruits[1]               # apple       (1-based!)
echo $fruits[-1]              # cherry
echo $fruits[2,3]             # banana cherry
echo ${#fruits}               # 3
fruits+=(date)                # append
fruits[2]=blueberry           # replace one element
fruits[2,3]=()                # delete elements 2–3
echo $fruits                  # apple date
echo ${fruits[(i)date]}       # 2   (index of first match)
echo ${fruits[(r)a*]}         # apple   (first value matching a*)
echo ${fruits:#a*}            # date    (remove values matching a*)
echo ${(M)fruits:#a*}         # apple   (keep only matches)
(( $fruits[(Ie)kiwi] )) || echo "no kiwi"   # (I) gives 0 if missing
nums=({1..5})                 # 1 2 3 4 5
for f in $fruits; do echo "- $f"; done

Code Explained

arr[i,j]=() — removes a range; arr[i]=() removes one element
(i) — index of first match; returns length + 1 if not found
(I) — index of last match; returns 0 if not found, so it works as a test
(e) — exact match, so * in the search isn't a pattern
:#pat — filters elements; (M) flips it to keep matches

Search & Set Ops

SyntaxResult
${a[(i)x]}first index of x
${a[(Ie)x]}last index, 0 if none
${a[(r)pat]}first value matching
${a:#pat}remove matches
${a:|b}in a but not in b
${a:*b}in both a and b

⚠ Common Mistakes

  • Using $arr[0]: in zsh that's empty. The first element is $arr[1]
  • Writing arr=(a, b, c): commas become part of the values. Separate with spaces
  • Testing membership with (i) and != 0: it never returns 0. Use (Ie) or compare with ${#a}+1
  • Copying with b=$a: you get one joined string. Use b=("${a[@]}")

✓ Tips & Best Practices

  • Use "${arr[@]}" when elements may be empty or must stay separate
  • Set operations need no loops: ${a:|b} (difference) and ${a:*b} (intersection)
  • Remove duplicates with typeset -U arr or ${(u)arr}
  • Use print -l $arr to see each element on its own line

Quick Summary

  • a=(x y z) — create
  • $a[1] / $a[-1] — first / last (1-based)
  • $a[2,3] — slice
  • a+=(x) — append
  • ${a[(Ie)x]} — find (0 if missing)
