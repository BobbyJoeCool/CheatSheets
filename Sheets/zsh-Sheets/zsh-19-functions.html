Functions

A function is a named group of commands that runs in the current shell, so it can change variables and the working directory. Arguments arrive as $1, $@, $#. The return value is only an exit status (0–255): to give back data, print it and capture it with $( ). Zsh adds anonymous functions, which run immediately, and autoloading, which loads functions from files in $fpath on first use.

Notes

  • Variables are global unless declared local
  • $0 inside a function is the function's name
  • Functions take priority over commands of the same name
  • command ls / builtin cd skip a function wrapper

Defining & Calling

greet() {
  local name=${1:-world}      # first arg, default "world"
  print "Hello, $name"
}
greet Ada                     # Hello, Ada
function add { print $(( $1 + $2 )) }
sum=$(add 2 3); echo $sum     # 5   (capture printed output)
is_even() { (( $1 % 2 == 0 )) }   # last status is the result
is_even 4 && echo even        # even
fail() { return 3 }; fail; echo $?        # 3
show() { echo "$0 got $#: $@" }; show a b # show got 2: a b
() { echo "anon got $1" } hi              # anon got hi  (runs now)
mkcd() { mkdir -p -- "$1" && cd -- "$1" }   # changes caller's dir

fpath=(~/.zsh/functions $fpath)   # file ~/.zsh/functions/backup
autoload -Uz backup           # loaded on first call
functions greet               # print the definition
unfunction greet              # delete it

Code Explained

local — keeps the variable inside this call (and functions it calls)
$( … ) — runs in a subshell, so cd or variable changes inside are lost
return N — sets $?; without it, the last command's status is returned
() { … } args — anonymous function: good for a private scope in .zshrc
autoload -Uz — -U skips aliases, -z uses zsh-style loading

⚠ Common Mistakes

  • Using return "text": return only takes a number. Print the text and capture it
  • Calling cd inside $(fn): the subshell changes directory, not your shell
  • Forgetting local: helper variables leak and overwrite globals
  • Naming a function after a command (ls() { ls -G }): infinite recursion. Use command ls -G

✓ Tips & Best Practices

  • Return data through REPLY to avoid a subshell: fn; echo $REPLY
  • Keep big functions as files in ~/.zsh/functions and autoload them
  • Wrap .zshrc setup in () { local … } so temporary variables don't stay around
  • Start reusable functions with emulate -L zsh

Quick Summary

  • f() { … } — define
  • $1 "$@" — arguments
  • local — scope variables
  • print + $( ) — return data
  • autoload -Uz — lazy-load from $fpath
