Sheet 06

Line Editor (ZLE) & Key Bindings

bindkey -e / -v · bindkey '^R' · zle -N custom widgets · edit-command-line · $BUFFER / $CURSOR · KEYTIMEOUT

The Zsh Line Editor

ZLE is the editor behind the prompt. Every action it can take (moving the cursor, searching history, completing) is a named widget, and bindkey maps key sequences to widgets in a keymap. Zsh ships emacs (default) and vi keymaps. You can write your own widgets as shell functions that edit the special variables $BUFFER (the whole line) and $CURSOR (cursor position), then register them with zle -N.

Notes

  • Find a key's code: press Ctrl-V then the key, or run cat -v
  • ^X means Ctrl-X; \e or ^[ means Esc/Alt
  • bindkey '^R' shows what one key does
  • zle -al lists every widget

Bindings & Custom Widgets

bindkey -e                    # emacs keymap (default)
bindkey -v                    # vi keymap
bindkey '^R' history-incremental-search-backward
bindkey '^[[A' up-line-or-search    # Up arrow: search by prefix
bindkey -s '^G' 'git status\n'      # key types a string

# Ctrl-X Ctrl-E: edit the current line in $EDITOR
autoload -Uz edit-command-line
zle -N edit-command-line
bindkey '^X^E' edit-command-line

# Esc Esc: put "sudo " in front of the line
sudo-line() { BUFFER="sudo $BUFFER"; CURSOR=$#BUFFER }
zle -N sudo-line
bindkey '\e\e' sudo-line

KEYTIMEOUT=1                  # 10 ms Esc delay (snappier vi mode)

Code Explained

bindkey KEY WIDGET — binds in the current main keymap; add -M vicmd for another keymap
autoload -Uz — loads a function shipped with zsh on first use
zle -N name — turns a shell function into a widget
CURSOR=$#BUFFER — moves the cursor to the end of the line
KEYTIMEOUT — in hundredths of a second (default 40 = 0.4 s)

⚠ Common Mistakes

  • Binding arrow keys with codes from another terminal: check yours with Ctrl-V, or use $terminfo[kcuu1]
  • Defining a widget function but forgetting zle -N: bindkey reports No such widget
  • Turning on vi mode and losing Ctrl-R: bindkey -v replaces the emacs bindings, so rebind it in viins
  • Leaving KEYTIMEOUT at default in vi mode: Esc waits 0.4 s before switching modes

✓ Tips & Best Practices

  • Ctrl-X Ctrl-E (edit-command-line) is the easiest way to edit long one-liners
  • Alt-. repeats the last argument; press again for older ones
  • Use ^Q (push-line) to stash a half-typed command, run something else, and get it back
  • Use LBUFFER+= in widgets to insert text at the cursor

Quick Summary

  • bindkey -e / -v — emacs / vi mode
  • bindkey KEY widget — map a key
  • zle -N fn — make a widget
  • $BUFFER $CURSOR — edit the line
  • edit-command-line — open in $EDITOR
