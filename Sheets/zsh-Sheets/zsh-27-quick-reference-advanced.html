⚠ Common Mistakes

  • No match is an error: add (N) to globs that may be empty
  • EXTENDED_GLOB is needed for ^, ~, #
  • $(( 1 / 3 )) is 0; use 1.0 / 3

  • zsh -f isolates config problems
  • time zsh -i -c exit keeps startup honest
