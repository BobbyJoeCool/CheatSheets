Sheet 07

Variables & typeset

name=value · typeset / local · -i integer · -F float · -r readonly · -x export · -U unique · -l / -u case

Variables

Assign with name=value, with no spaces around =. Read with $name or ${name}. Variables are untyped strings by default, but typeset (alias declare) can give them attributes: integer, float, readonly, exported, upper or lower case, or unique (arrays). Variables are global even inside functions unless declared with local or typeset.

Notes

  • Use ${name} when text follows: ${name}s
  • Unset variables expand to an empty string
  • typeset -p name shows a variable's value and attributes
  • export is typeset -gx

Assigning & typeset

name="Ada"                    # no spaces around =
echo $name ${name}s           # Ada Adas
typeset -i count=5            # integer: assignments are math
count+=2; echo $count         # 7
count="3 * 4"; echo $count    # 12
typeset -F 2 price=3.14159    # float, 2 decimal places
echo $price                   # 3.14
typeset -r PI=3.14            # readonly (same as readonly PI=3.14)
PI=3                          # zsh: read-only variable: PI
export EDITOR=nvim            # visible to child processes
typeset -u up="shout"; echo $up   # SHOUT
typeset -l lo="QUIET"; echo $lo   # quiet
typeset -Z 3 n=7; echo $n     # 007   (zero-pad)
typeset -p name               # typeset name=Ada
f() { local x=1; y=2 }        # x is local, y leaks out as a global

Code Explained

typeset -i — the right side of = and += is evaluated as arithmetic
typeset -F N — float shown with N decimals; -E uses scientific notation
typeset -r — later assignments and unset fail
typeset -u / -l — case is converted on every assignment
local — same as typeset inside a function

⚠ Common Mistakes

  • Writing name = value: zsh runs a command called name with arguments = and value
  • Forgetting local in functions: loop variables like i silently overwrite globals
  • Expecting typeset -i n=3.9 to round: it truncates to 3
  • Using $name_suffix when you meant ${name}_suffix: zsh reads the whole name

✓ Tips & Best Practices

  • Use typeset -p var to debug: it shows type flags as well as the value
  • Use typeset -U path to remove duplicate PATH entries automatically
  • Use local for every function variable, and turn on WARN_CREATE_GLOBAL to catch slips
  • Test whether a variable is set with (( ${+var} )), which works even if the value is empty

Quick Summary

  • name=value — no spaces
  • typeset -i/-F — integer / float
  • typeset -r / readonly — constant
  • export — pass to child processes
  • local — function scope
