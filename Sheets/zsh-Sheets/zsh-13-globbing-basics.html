Globbing Basics

* ? [...] · **/ recursive · ***/ follows symlinks · <1-10> numeric ranges · {a,b} / {1..5} braces · ^ ~ # with EXTENDED_GLOB · NULL_GLOB

Filename Generation

Globbing turns patterns into lists of matching filenames before a command runs. Zsh supports the standard *, ? and [...], and adds recursive /, numeric ranges <1-10>, and alternatives (a|b). With setopt EXTENDED_GLOB you also get negation ^, exclusion ~, and repetition #. By default a pattern that matches nothing is an error** (no matches found), not a literal string.

Notes

  • Globs skip dotfiles unless the pattern starts with . or you use (D) / GLOB_DOTS
  • Brace expansion {a,b} isn't globbing: it builds strings whether files exist or not
  • Quote patterns meant for other programs: find . -name '*.py'
  • noglob cmd turns globbing off for one command

Patterns

ls *.txt                      # every .txt here
ls file?.log                  # file1.log, fileA.log
ls [a-c]*.md                  # starting with a, b or c
ls [^0-9]*                    # not starting with a digit
ls **/*.py                    # recursive: .py files at any depth
ls ***/*.py                   # recursive, following symlinked dirs
ls log<1-10>.txt              # log1.txt … log10.txt (that exist)
ls img<->.png                 # img + any number
ls (README|LICENSE)*          # alternatives
echo {a,b,c}.txt              # a.txt b.txt c.txt   (no files needed)
echo {1..5} {01..03}          # 1 2 3 4 5 01 02 03
setopt EXTENDED_GLOB
ls ^*.bak                     # everything except *.bak
ls *.log~error*               # .log files, excluding error*
ls *.(jpg|png)(N)             # (N): empty if no match, no error

Code Explained

/ — zero or more directories, so /*.py includes ./x.py
<1-10> — matches numbers by value, so log07.txt matches too
<-> — any non-negative integer
(N) — the NULL_GLOB qualifier for one pattern (Sheet 14)

⚠ Common Mistakes

  • curl https://x.com/?q=1 fails with no matches found: ? is a glob. Quote URLs
  • git add *.js stops the command when nothing matches. Add (N) or quote it
  • Using ls for recursion: you need /
  • Expecting ^ and ~ to work without setopt EXTENDED_GLOB

✓ Tips & Best Practices

  • Use **/*.ext(.) instead of find . -name for quick searches
  • Add alias curl='noglob curl' (and wget, git) to stop URL glob errors
  • Preview a destructive glob first: print -l **/*.tmp before rm
  • Use (#i) for one case-insensitive pattern without changing options

Quick Summary

  • * ? [..] — standard wildcards
  • **/ — recursive
  • <1-10> — numeric range
  • ^ ~ — not / except (EXTENDED_GLOB)
  • (N) — no error on no match
