Completion System

Zsh's completion system (compsys) is turned on by compinit. It ships completions for hundreds of commands and loads extras from files named _command in $fpath. Behavior is tuned with zstyle, which takes a context pattern like ':completion:*' and a setting. You can write your own completion with _arguments, or reuse an existing one with compdef.

Notes

  • Add to fpath before compinit runs
  • compinit caches results in ~/.zcompdump
  • Delete ~/.zcompdump* if new completions don't appear
  • compaudit lists insecure completion dirs

Setup & Custom Completion

fpath=(~/.zsh/completions $fpath)              # before compinit
autoload -Uz compinit && compinit
zstyle ':completion:*' menu select             # arrow-key menu
zstyle ':completion:*' matcher-list 'm:{a-z}={A-Z}'   # case-insensitive
zstyle ':completion:*' list-colors ${(s.:.)LS_COLORS}
zstyle ':completion:*:descriptions' format '%F{yellow}-- %d --%f'
zstyle ':completion:*' group-name ''           # group by type
zstyle ':completion:*' use-cache on            # cache slow results

compdef _gnu_generic mytool   # complete --flags from mytool --help
compdef mygit=git             # use git's completion for mygit

# ~/.zsh/completions/_deploy
#compdef deploy
_arguments \
  '-v[verbose output]' \
  '--env=[target environment]:env:(dev staging prod)' \
  '*:file:_files'

Code Explained

menu select — Tab opens a menu you can move through with arrows
m:{a-z}={A-Z} — lowercase typing matches uppercase names
#compdef deploy — first line of the file; ties it to the command
'-v[…]' — a flag with a description
:env:(dev staging prod) — a value chosen from a list

⚠ Common Mistakes

  • Running compinit before changing fpath: new completions are ignored
  • Calling compinit several times (framework + your own): it slows startup
  • Leaving a stale ~/.zcompdump: delete it after adding completion files
  • Using bash completion scripts directly: load them with bashcompinit first

✓ Tips & Best Practices

  • Many CLIs print their own: gh completion -s zsh > ~/.zsh/completions/_gh
  • Press Ctrl-X h to see the context name to use in a zstyle
  • Use compinit -C once your setup is stable to skip the audit
  • Bind Shift-Tab to go back: bindkey '^[[Z' reverse-menu-complete

Quick Summary

  • compinit — enable completion
  • zstyle ':completion:*' … — configure
  • compdef — assign completers
  • _arguments — write completions
  • $fpath — where _cmd files live
