Special Parameters

$0 $1 $# · $@ vs $* · $? · $$ / $! · $argv · $PWD / $OLDPWD · $path ↔ $PATH tied arrays

Parameters Zsh Sets for You

Zsh fills in many parameters automatically: script and function arguments, exit status, process IDs and session info. Two zsh extras matter most: $argv, a real array of the arguments, and tied pairs like $path / $PATH, where an array and a colon-separated string always stay in sync. Edit $path as an array and $PATH updates itself.

Notes

  • Inside a function, $1, $#, $@ refer to the function's arguments
  • "$@" keeps each argument separate; "$*" joins them into one word
  • $? and $status are the same
  • Use ${10} (braces) for arguments past 9

Arguments & Status

# ./greet.zsh Ada "Grace Hopper" Linus
echo $0                       # ./greet.zsh
echo $1 / $2                  # Ada / Grace Hopper
echo $#                       # 3
echo $argv[-1]                # Linus   (argv is an array)
for a in "$@"; do print -r -- "<$a>"; done   # <Ada> <Grace Hopper> <Linus>
print -r -- "$*"              # Ada Grace Hopper Linus  (one word)
shift; echo $1                # Grace Hopper
false; echo $?                # 1
sleep 30 &
echo $!                       # 4182   (PID of last background job)
echo $$                       # 4170   (PID of this shell)
print -l $path                # one PATH entry per line
path=(~/bin $path)            # prepend ~/bin to PATH
echo $RANDOM $SECONDS         # 18342 12  (random 0–32767, secs since start)

Code Explained

$argv[-1] — negative indexes count from the end
"$@" — the safe way to pass arguments on to another command
shift — drops $1; shift 2 drops two
path=(~/bin $path) — array edit; $PATH is rewritten to match

⚠ Common Mistakes

  • Writing $10: it means ${1}0. Use ${10}
  • Passing $* or unquoted $@ on: empty arguments are dropped. Use "$@"
  • Reading $? after an echo: it now holds echo's status. Save it first: rc=$?
  • Appending to PATH with PATH=$PATH:~/bin in quotes: ~ doesn't expand there. Use path+=(~/bin)

✓ Tips & Best Practices

  • Use typeset -U path so repeated .zshrc loads don't duplicate entries
  • Use $argv when you want array features like $argv[2,-1]
  • $SECONDS makes quick timers: start=$SECONDS; …; echo $((SECONDS-start))
  • zmodload zsh/datetime gives $EPOCHSECONDS and strftime

Quick Summary

  • $1 $# "$@" — arguments
  • $? — last exit code
  • $$ / $! — this shell / last job PID
  • $path ↔ $PATH — tied array and string
  • shift — drop the first argument
