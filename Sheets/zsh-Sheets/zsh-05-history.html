Sheet 05

History & History Expansion

HISTFILE / HISTSIZE / SAVEHIST · SHARE_HISTORY · HIST_IGNORE_DUPS · !! !$ !* · ^old^new · fc · history -i

Command History

Zsh keeps history in memory (HISTSIZE lines) and saves it to HISTFILE (SAVEHIST lines). Plain zsh has SAVEHIST=0, which means nothing is saved until you set it (macOS's /etc/zshrc sets it for you). History expansion with ! reuses earlier commands or arguments, and ^old^new reruns the last command with a fix. Search interactively with Ctrl-R.

Notes

  • history is fc -l, so it takes the same flags
  • fc with no args opens the last command in $EDITOR
  • HIST_VERIFY shows the expansion so you can edit it before running
  • EXTENDED_HISTORY saves timestamps and durations
  • Turn off ! expansion with setopt NO_BANG_HIST

Configure & Use History

HISTFILE=~/.zsh_history       # where history is saved
HISTSIZE=50000                # lines kept in memory
SAVEHIST=50000                # lines written to HISTFILE
setopt SHARE_HISTORY          # share live across open terminals
setopt HIST_IGNORE_ALL_DUPS   # remove older duplicates
setopt HIST_IGNORE_SPACE      # " cmd" (leading space) not saved
setopt EXTENDED_HISTORY       # save start time + duration
setopt HIST_VERIFY            # show !! expansion before running

sudo !!                       # rerun last command with sudo
mkdir projects && cd !$       # !$ = last word of previous command
^teh^the                      # rerun last command, first teh → the
history -10                   # list the last 10 entries
history -i -5                 # last 5 with ISO timestamps
fc                            # edit last command in $EDITOR, then run

Code Explained

SHARE_HISTORY — every shell reads and appends history as you go
HIST_IGNORE_SPACE — prefix a command with a space to keep secrets out of history
!$ — last argument of the previous command; !* is all of them
^a^b — quick substitution; !!:gs/a/b/ replaces every match
history -i — needs EXTENDED_HISTORY for real timestamps

Event Designators

Word Designators

!$last word
!^first argument
!*all arguments
!:2word 2
!:2-4words 2 to 4

Modifiers

SyntaxEffect
:h :tdirname, basename
:r :edrop / keep extension
:s/a/b/replace first a with b
:gs/a/b/replace all
:pprint, don't run

⚠ Common Mistakes

  • Setting HISTSIZE but not SAVEHIST: history vanishes when the shell closes
  • Making SAVEHIST larger than HISTSIZE: only HISTSIZE lines exist to save
  • Using ! inside double quotes, like echo "hi!": zsh tries history expansion. Use single quotes
  • Combining SHARE_HISTORY with INC_APPEND_HISTORY: they overlap, so pick one

✓ Tips & Best Practices

  • Press Ctrl-R and type a fragment to search history; press it again for older matches
  • Bind Up/Down to up-line-or-search to search by the typed prefix (Sheet 06)
  • Add :p to preview: !git:p prints the command without running it
  • Use fc -l 1 | grep docker to search the whole history

Quick Summary

  • HISTFILE HISTSIZE SAVEHIST — set all three
  • !! !$ !* — reuse commands and args
  • ^old^new — fix and rerun
  • history -10 — list recent entries
  • fc — edit and rerun
