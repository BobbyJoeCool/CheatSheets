Qualifiers & Modifiers

A glob qualifier is a parenthesized suffix that filters or sorts the matches: *(.) keeps only regular files, *(om[1]) picks the newest. Qualifiers can test type, size, age, permissions and owner, and they combine (*(.Lm+10om)). Modifiers like :h and :t edit a path; they work on variables ($f:t), history (!$:h), and inside qualifiers (*(:r)).

Notes

  • Combine qualifiers in one set: (.Lk+500om[1,5])
  • ^ negates the next qualifier: *(^/) = not directories
  • Time units: s m h d (default) w M; size units: k m
  • +n means more than n, -n less than n

Filter, Sort & Edit Paths

ls *(.)                       # regular files only
ls -d *(/)                    # directories only
ls *(@)                       # symlinks only
ls *(*)                       # executable files
ls -l *(.om[1])               # newest file
ls *(.om[1,3])                # 3 most recently modified
ls **/*(.Lm+100)              # files over 100 MB, any depth
ls *(.mh-1)                   # modified in the last hour
rm *.log(.md+30)              # .log files older than 30 days
ls *(D)                       # include dotfiles
print -l **/*(/^F)            # empty directories
rm *.tmp(N)                   # no error if nothing matches
f=~/src/app/main.test.js
echo $f:h                     # /home/ada/src/app
echo $f:t $f:e $f:t:r         # main.test.js js main.test
echo *.md(:r)                 # file names without .md

Code Explained

om — sort by modification time, newest first; [1] takes the first
Lm+100 — size (L) in megabytes greater than 100
mh-1 — modified less than 1 hour ago; md+30 — more than 30 days
^F — not "full", i.e. empty directories
:t:r — modifiers chain left to right

⚠ Common Mistakes

  • Writing ls *(/) and seeing contents: ls lists inside dirs. Use ls -d *(/) or print -l
  • Mixing up m (days) and mm (minutes): mm-5 is the last 5 minutes
  • Running rm on a qualifier glob without previewing: check with print -l first
  • Expecting qualifiers to work inside quotes: "*(.)" is literal

✓ Tips & Best Practices

  • Open the newest download: open ~/Downloads/*(.om[1])
  • Find big files fast: print -l **/*(.OL[1,10]) lists the 10 largest
  • Turn off BARE_GLOB_QUAL only if you need literal (...) in filenames
  • Use :A to resolve a script's real path: ${0:A:h}

Quick Summary

  • *(.) *(/) — files / dirs
  • (om[1]) — newest
  • (Lm+N) (md-N) — size / age
  • (N) (D) — null glob / dotfiles
  • :h :t :r :e — path parts
