⚠ Common Mistakes

  • $arr[0] is empty: arrays start at 1
  • name = value runs a command; no spaces around =
  • Unquoted URLs fail with no matches found

✓ Tips & Best Practices

  • print -l anything to see it one item per line
  • typeset -p shows a variable's type and value
  • emulate -L zsh at the top of every function
