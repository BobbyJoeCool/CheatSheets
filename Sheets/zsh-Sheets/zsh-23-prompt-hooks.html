Prompts & Hooks

The prompt is set with PROMPT (left, alias PS1) and RPROMPT (right side, hidden when the line gets long). It uses % escapes for user, host, directory, time and exit status, %F{color} for colors, and %(x.true.false) for conditionals. Hook functions run at set moments: precmd before each prompt, preexec before each command, chpwd after a directory change. Register them with add-zsh-hook.

Notes

  • Single-quote prompts so $vars expand each time (with PROMPT_SUBST)
  • print -P '…' previews escapes
  • Colors: names (red) or 0–255 numbers (%F{208})
  • vcs_info ships with zsh and shows git branch info

Building a Prompt

PROMPT='%n@%m %~ %# '         # ada@mac ~/src %
PROMPT='%B%1~%b %# '          # bold, current folder name only
RPROMPT='%*'                  # right side: 14:03:59
PROMPT='%F{cyan}%~%f %(?.%F{green}.%F{red})❯%f '   # red ❯ after a failure

autoload -Uz vcs_info add-zsh-hook
zstyle ':vcs_info:git:*' formats ' (%b)'           # (main)
add-zsh-hook precmd vcs_info  # refresh before every prompt
setopt PROMPT_SUBST           # expand $vars inside PROMPT
PROMPT='%~${vcs_info_msg_0_} %# '                  # ~/src/app (main) %

note_dir() { print "now in $PWD" }
add-zsh-hook chpwd note_dir   # runs after every cd
print -P '%F{208}orange%f %B bold%b'   # preview escapes

Code Explained

%~ — current dir with ~ for home; %1~ — last folder only
%(?.A.B) — A if the last command succeeded, else B
vcs_info — fills $vcs_info_msg_0_; %b in formats is the branch
add-zsh-hook — adds to a hook without replacing other plugins' hooks

⚠ Common Mistakes

  • Double-quoting a prompt with $vars: they expand once, when .zshrc loads
  • Forgetting PROMPT_SUBST: ${vcs_info_msg_0_} shows literally
  • Defining precmd() { … } directly: it overwrites hooks set by plugins. Use add-zsh-hook
  • Using raw ANSI codes without %{ %}: zsh miscounts the width and the cursor jumps

✓ Tips & Best Practices

  • Show the exit code only on failure: %(?..%F{red}[%?]%f )
  • Use %1~ or %3~ to keep long paths short
  • Put slow info (like git status) in RPROMPT or use an async prompt
  • Use preexec + precmd with $EPOCHREALTIME (zsh/datetime) to time commands

Quick Summary

  • PROMPT / RPROMPT — left / right
  • %~ %n %m %# — core escapes
  • %F{c}…%f — color
  • %(?.a.b) — conditional
  • add-zsh-hook precmd fn — hooks
