Parameter Expansion Flags

${(U)var} / (L) · (s:,:) split · (j:,:) join · (f) lines · (o) / (O) sort · (u) unique · (P) indirect · nested ${${var#x}%y}

Expansion Flags

Flags are letters in parentheses right after ${: ${(U)name}. They transform the value: change case, split a string into an array, join an array into a string, sort, remove duplicates, quote, or look up a variable by name. Flags combine (${(Ou)arr}) and expansions nest, so the inner result feeds the outer one: ${(U)${file%.*}}.

Notes

  • Flags taking an argument use any delimiter pair: (s:,:), (s/,/), (j|-|)
  • (f) = (ps:\n:) split on newlines; (F) joins with newlines
  • Sorting is lexical; add n for numeric: (on)
  • Full list: man zshexpn, section *Parameter Expansion Flags*

Flags in Action

s="hello world"
echo ${(U)s}                  # HELLO WORLD
echo ${(C)s}                  # Hello World
csv="b,a,c,a"
parts=(${(s:,:)csv})          # split on commas → (b a c a)
echo ${#parts}                # 4
echo ${(j:-:)parts}           # b-a-c-a
echo ${(o)parts}              # a a b c   (sort ascending)
echo ${(Ou)parts}             # c b a     (descending + unique)
nums=(10 9 100); echo ${(on)nums}    # 9 10 100  (numeric sort)
lines=(${(f)"$(git branch)"}) # one element per output line
var=HOME; echo ${(P)var}      # /home/ada   (indirect lookup)
n=42; echo ${(l:5::0:)n}      # 00042   (left-pad to 5 with 0)
echo ${(U)${s%% *}}           # HELLO   (nested)
cmd='git commit -m "fix bug"'
print -l ${(z)cmd}            # git / commit / -m / "fix bug"  (shell words)

Code Explained

(s:,:) — split; wrap in ( ) to store the pieces as an array
(j:-:) — join array elements with -
(f) — the standard way to read command output line by line
(P) — treats the value as a variable name and expands that
(z) — splits like the shell would, keeping quoted words together

Case & Format

FlagEffect
(U) (L)upper / lower case
(C)capitalize words
(q) (qq)backslash / single-quote
(Q)remove one level of quoting
(l:n::c:)left-pad to n with c
(r:n::c:)right-pad to n with c

Split & Join

FlagEffect
(s:x:)split on x
(j:x:)join with x
(f)split on newlines
(F)join with newlines
(z)split into shell words
(@)keep elements in quotes

Sort & Select

FlagEffect
(o) (O)sort ascending / descending
(on) (oi)numeric / case-insensitive
(u)unique, keep first
(k) (v) (kv)assoc keys / values / both
(P)indirect: value is a name
(M)keep matches of :#pat

⚠ Common Mistakes

  • Writing parts=${(s:,:)csv} without ( ): you get a string, not an array
  • Forgetting quotes with (f): ${(f)$(cmd)} splits on spaces first. Use ${(f)"$(cmd)"}
  • Sorting numbers with (o): 10 comes before 9. Use (on)
  • Putting the flag after the name, ${name(U)}: flags go right after ${

✓ Tips & Best Practices

  • Chain flags in one set of parentheses: ${(Lou)words}
  • Read a file into lines with lines=(${(f)"$(<file.txt)"}); $(<file) needs no cat
  • Use (P) instead of eval for indirect variables
  • Use (q) before building a command for eval to keep it safe

Quick Summary

  • (U) (L) (C) — case
  • (s:,:) / (j:,:) — split / join
  • (f) — lines of output
  • (o) (O) (u) — sort / unique
  • (P) — indirect lookup
