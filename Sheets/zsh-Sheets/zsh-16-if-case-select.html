if, case & select

if / elif / else / fi · short form if [[ ]] { } · case / esac · a|b) patterns · ;; ;& ;| · select / PS3 / $REPLY

Branching

if runs a command and branches on its exit status: 0 is true, anything else is false. The condition is often [[ ]] or (( )), but any command works (if grep -q …). case matches one value against glob patterns, top to bottom, and runs the first match. Zsh adds two extra terminators: ;& falls through to the next body and ;| keeps testing. select builds a numbered menu from a list.

Notes

  • Zsh also accepts brace forms: if [[ … ]] { … } else { … }
  • case patterns are globs, not regexes; *) is the default
  • select puts the choice in a variable and the typed number in $REPLY

if, case & select

if [[ $1 == -h ]]; then
  print "usage: deploy ENV"
elif (( $# == 0 )); then
  print -u2 "no environment"; exit 1
else
  deploy "$1"
fi

case $file in
  *.jpg|*.png) echo image ;;
  *.tar.gz)    echo tarball ;&    # ;& runs the next body too
  *.zip)       echo archive ;;
  *)           echo other ;;
esac

PS3="Pick a color: "
select c in red green blue; do
  [[ -n $c ]] && { echo "You chose $c (#$REPLY)"; break }
done

Code Explained

elif / else — optional; close with fi
a|b) — either pattern matches
;& — skips the next pattern test and runs its body
PS3 — the prompt select shows
$c is empty when the input isn't a valid number

⚠ Common Mistakes

  • Using a && b || c as if/else: if b fails, c runs too
  • Forgetting ;;: the next pattern line becomes part of the current body or a syntax error
  • Quoting case patterns: "*.txt") only matches a literal *.txt
  • Missing break in select: the menu repeats forever

✓ Tips & Best Practices

  • Order case patterns from most to least specific; the first match wins
  • Use ;| to tag a value with every matching category
  • Branch on commands directly: if command -v brew >/dev/null; then …
  • Use the brace form for short one-line conditionals

Quick Summary

  • if … elif … else … fi — branching
  • case $x in pat) … ;; esac — matching
  • ;& / ;| — fall through / keep testing
  • select x in … — numbered menu
