Math in Zsh

$(( expr )) evaluates arithmetic and substitutes the result; (( expr )) evaluates it as a command whose status is true when the result is non-zero. Unlike bash, zsh does floating point math natively: if any operand is a float, the result is a float. Inside (( )), variables need no $. Load zsh/mathfunc for sqrt, floor, sin and other functions.

Notes

  • Integer division truncates: 7 / 2 is 3
  • Write 2.0 (not 2) to force float math
  • 16#ff reads a number in base 16
  • [#16] prints the result in base 16

Arithmetic

echo $(( 7 + 3 * 2 ))         # 13
echo $(( 7 / 2 ))             # 3      (integer division)
echo $(( 7 / 2.0 ))           # 3.5    (float)
echo $(( 7 % 3 ))             # 1
echo $(( 2 ** 10 ))           # 1024
x=5
(( x++ )); echo $x            # 6      (no $ inside)
(( x += 10 )); echo $x        # 16
(( x > 10 )) && echo big      # big
echo $(( x > 10 ? 1 : 0 ))    # 1      (ternary)
echo $(( 16#ff ))             # 255
echo $(( [#16] 255 ))         # 16#FF
echo $(( [##2] 5 ))           # 101
echo $(( 10.0 / 3 ))          # 3.3333333333333335
zmodload zsh/mathfunc
echo $(( sqrt(16) ))          # 4.
printf "%.2f\n" $(( 10.0 / 3 ))   # 3.33

Code Explained

** — power; % — remainder
(( x++ )) — returns false when x was 0, which matters with ERR_EXIT
[#16] — output base with prefix; [##16] without
sqrt(16) — float result prints as 4.; wrap in int() for 4
printf "%.2f" — the easiest way to round for display

⚠ Common Mistakes

  • Expecting $(( 1 / 3 )) to be 0.33: both are integers, so it's 0. Use 1.0 / 3
  • Writing $(( $x++ )): that becomes 5++. Use (( x++ ))
  • Using (( count++ )) with ERR_EXIT when count is 0: the status is false and the script exits
  • Forgetting zmodload zsh/mathfunc: sqrt is an unknown function without it

✓ Tips & Best Practices

  • Use (( )) for all number comparisons instead of -gt
  • Format floats with printf '%.2f' or typeset -F 2
  • Use (( x++ )) || true, or (( ++x )), in scripts with ERR_EXIT
  • Leading zeros are decimal in zsh (010 is 10) unless OCTAL_ZEROES is set

Quick Summary

  • $(( )) — math result
  • (( )) — math test
  • 2.0 — any float makes float math
  • 16#ff / [#16] — bases
