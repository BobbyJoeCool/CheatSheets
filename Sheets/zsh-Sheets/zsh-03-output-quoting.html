Printing & Quoting

Zsh has three output commands: echo (portable, but zsh's version interprets escapes like \t by default), print (zsh's own, with options for lines, columns, prompts and stderr), and printf (C-style formatting). Quoting controls what the shell expands: single quotes keep everything literal, double quotes expand $vars and $(cmds) but stop word splitting and globbing, and $'...' turns escape sequences into real characters.

Notes

  • Unlike bash, zsh does not word-split $var unquoted, so echo $file is safe with spaces
  • print -r and echo -E print backslashes literally
  • -- ends options: print -r -- "$x" is safe when $x starts with -

Output Commands

echo "Hello"                  # Hello
echo "a\tb"                   # a	b   (zsh echo expands escapes)
echo -E "a\tb"                # a\tb  (-E: raw)
print -l one two three        # one / two / three on separate lines
print -n "prompt> "           # no newline
print -P "%F{green}ok%f"      # ok in green (prompt escapes)
print -r -- "$raw"            # raw, no escape processing
print -u2 "error!"            # to stderr, same as >&2
print -a -C 3 a b c d e f     # a b c / d e f  (3 columns)
printf "%-6s|%5.2f\n" id 3.14159   # id    | 3.14
printf "%s\n" a b c           # format repeats: a / b / c

name="Ada"
echo 'Hi $name'               # Hi $name   (literal)
echo "Hi $name"               # Hi Ada     (expanded)
echo $'tab:\there'            # tab:	here (ANSI-C quoting)
echo "cost: \$5"              # cost: $5
v='a b*'; echo ${(q)v}        # a\ b\*     (quoted for reuse)

Code Explained

print -l — one argument per line; great for arrays: print -l $path
print -P — expands prompt escapes like %F{red}, %B, %~ (Sheet 23)
print -u2 — writes to file descriptor 2 (stderr)
printf — reuses the format until all arguments are consumed
${(q)v} — backslash-quotes a value so it can be pasted back into a command

⚠ Common Mistakes

  • Using echo "$x" where $x may start with -n or -e: it's read as an option. Use print -r -- "$x"
  • Expecting '$HOME' to expand: single quotes are always literal
  • Writing echo "\n" and expecting the bash result \n: zsh's echo prints a real newline
  • Putting ' inside single quotes: end and reopen, 'it'\''s', or use $'it\'s'

✓ Tips & Best Practices

  • Prefer print or printf in zsh scripts; echo behavior varies across shells
  • Send errors to stderr with print -u2 so pipelines only carry data
  • Use ${(q)var} when building a command string to eval or show to a user
  • Color output portably with print -P '%F{red}...%f' instead of raw \e[31m codes

Quick Summary

  • print -l — one item per line
  • printf — formatted output
  • '…' — literal, "…" — expands vars
  • $'…' — real escape characters
  • ${(q)v} — safely quoted value
