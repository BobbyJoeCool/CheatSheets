Sheet 09

Parameter Expansion

${var:-default} · ${var:=val} · ${var:?msg} · ${var:+alt} · ${#var} · ${var#pat} / ${var%pat} · ${var/old/new} · ${var:off:len}

Parameter Expansion

${...} does much more than read a variable. It can supply defaults when a value is missing, trim prefixes and suffixes by pattern, replace text, and take substrings. Patterns use glob syntax (*, ?, [...]), not regex. One # or % removes the shortest match and doubling it removes the longest. None of these change the variable except :=.

Notes

  • # trims from the front, % from the back (# is left of % on the keyboard)
  • The colon in :- := :? :+ means "unset or empty"; without it, only unset
  • Offsets in ${v:o:l} start at 0; subscripts $v[1,3] start at 1
  • Modifiers like :t and :h work too (Sheet 14)

Trim, Replace & Default

file=/home/ada/report.final.pdf
echo ${#file}                 # 26
echo ${file##*/}              # report.final.pdf   (longest */ from front)
echo ${file%.*}               # /home/ada/report.final  (shortest .* from back)
echo ${file%%.*}              # /home/ada/report
echo ${file/ada/bob}          # /home/bob/report.final.pdf
echo ${file//a/A}             # /home/AdA/report.finAl.pdf  (all)
echo ${file:1:4}              # home   (offset 1, length 4)
echo ${file: -3}              # pdf    (space before -)

unset name
echo ${name:-guest}           # guest  (name still unset)
echo ${name:=guest}           # guest  (name is now "guest")
echo ${name:+"Hi $name"}      # Hi guest
: ${API_KEY:?must be set}     # zsh: API_KEY: must be set   (exits script)

Code Explained

##*/ — removes everything through the last /, like basename
%.* — removes the last extension; %%.* removes all of them
// — replaces every match; / only the first
: — the no-op command; with :? it validates required variables

Defaults

SyntaxResult
${v:-x}x if v unset/empty
${v-x}x only if v unset
${v:=x}also assigns x to v
${v:?msg}error + exit if unset/empty
${v:+x}x only if v is set
${+v}1 if set, else 0

Trim & Replace

SyntaxEffect
${v#pat}drop shortest prefix
${v##pat}drop longest prefix
${v%pat}drop shortest suffix
${v%%pat}drop longest suffix
${v/a/b} ${v//a/b}replace first / all
${v/#a/b} ${v/%a/b}replace at start / end

Length & Substrings

SyntaxResult
${#v}length
${v:2}from offset 2
${v:2:3}3 chars from offset 2
${v: -3}last 3 chars
$v[1,3]chars 1–3 (1-based)
$v[-1]last char

⚠ Common Mistakes

  • Writing ${v:-3} for the last 3 characters: that's the default operator. Use ${v: -3} or $v[-3,-1]
  • Using regex in patterns: ${v%[0-9]+} matches literally. Use glob syntax, or ## with EXTENDED_GLOB
  • Mixing up # and %: # trims the front, % the back

✓ Tips & Best Practices

  • Validate required inputs at the top of scripts with : ${VAR:?message}
  • Get basename/dirname without subprocesses: ${f##*/} and ${f%/*}, or $f:t and $f:h
  • Use ${v:-} with NO_UNSET to read an optional variable without an error
  • Expansions nest: ${${file##*/}%.*} gives the name without its folder or extension

Quick Summary

  • ${v:-x} — default value
  • ${v#p} / ${v%p} — trim front / back
  • ${v//a/b} — replace all
  • ${v:o:l} — substring
  • ${#v} — length
