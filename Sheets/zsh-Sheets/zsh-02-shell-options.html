Options

Shell options are named on/off switches that change how zsh behaves. setopt NAME turns one on and unsetopt NAME turns it off. Names are case-insensitive and ignore underscores, so AUTO_CD, autocd and AutoCd are the same option. A NO_ prefix inverts an option: setopt NO_BEEP is the same as unsetopt BEEP.

Notes

  • setopt with no args lists options that differ from the default
  • set -o lists every option with on/off
  • [[ -o name ]] tests whether an option is set
  • $options[name] reads on / off from an associative array

Setting & Scoping Options

setopt AUTO_CD                # type a directory name to cd into it
setopt EXTENDED_GLOB NO_BEEP  # several at once
unsetopt CORRECT              # turn off spelling correction
setopt NO_CLOBBER             # > refuses to overwrite existing files
[[ -o autocd ]] && echo on    # on   (case and _ ignored)
echo $options[autocd]         # on

tidy() {
  emulate -L zsh              # zsh defaults; LOCAL_OPTIONS turned on
  setopt EXTENDED_GLOB        # undone automatically on return
  print -l *.txt~draft*       # all .txt except draft*
}

emulate sh -c 'source old.sh' # run sh code with sh rules

Code Explained

emulate -L zsh — resets options to zsh defaults and sets LOCAL_OPTIONS so changes end with the function
LOCAL_OPTIONS — restores the caller's options when a function returns
emulate sh -c — runs one command (or file) under sh rules, then switches back
~ in *.txt~draft* — "except" pattern; needs EXTENDED_GLOB (Sheet 13)

⚠ Common Mistakes

  • Setting EXTENDED_GLOB globally, then being surprised ^ and # act as glob operators in filenames
  • Changing options inside a function without LOCAL_OPTIONS: the change leaks into the whole shell
  • Assuming a bash option name exists: zsh has no shopt, so use setopt instead

✓ Tips & Best Practices

  • Start every reusable function with emulate -L zsh so the user's options can't break it
  • Find an option with setopt | grep -i hist or man zshoptions
  • Turn on INTERACTIVE_COMMENTS so pasted snippets with # comments work at the prompt

Quick Summary

  • setopt X / unsetopt X — on / off
  • NO_X — inverted form
  • emulate -L zsh — safe defaults in functions
  • [[ -o X ]] — test an option
  • set -o — show all options
