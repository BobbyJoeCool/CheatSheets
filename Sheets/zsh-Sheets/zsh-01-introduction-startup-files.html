What Zsh Is

Zsh (the Z shell) is a Unix shell written by Paul Falstad in 1990. It runs almost all everyday sh/bash commands unchanged and adds recursive globbing, parameter expansion flags, a programmable completion system, and themeable prompts. It has been the default login shell on macOS since Catalina (10.15, 2019). Its behavior is configured by dotfiles in $HOME (or $ZDOTDIR), read in a fixed order that depends on the type of shell being started.

Good to Know

  • $ZSH_VERSION holds the running version, e.g. 5.9
  • $SHELL is your *login* shell, not the current one. Use echo $0 or ps -p $$
  • System-wide copies run first: /etc/zshenv, /etc/zprofile, /etc/zshrc
  • Zsh does not read .bashrc or .bash_profile
  • Check the shell type with [[ -o login ]] or [[ -o interactive ]]

Install, Switch & Run

brew install zsh              # newer zsh on macOS (system one is /bin/zsh)
sudo apt install zsh          # Debian / Ubuntu
zsh --version                 # zsh 5.9 (x86_64-apple-darwin23.0)
which zsh                     # /bin/zsh
chsh -s "$(which zsh)"        # make zsh your login shell, then log out/in
echo $ZSH_VERSION             # 5.9

# hello.zsh
#!/usr/bin/env zsh
print "Hello, World"          # Hello, World

zsh hello.zsh                 # run with zsh explicitly
chmod +x hello.zsh && ./hello.zsh
zsh -f                        # clean shell: skip all startup files
exec zsh                      # replace current shell, re-read rc files

Code Explained

chsh -s — changes the login shell; a non-system zsh must be listed in /etc/shells first
#!/usr/bin/env zsh — finds zsh on $PATH, so it works with Homebrew zsh too
print — zsh's builtin for output (see Sheet 03)
zsh -f — same as NO_RCS: the fastest way to tell if a problem comes from your config
exec zsh — cleaner than source ~/.zshrc, which keeps stale aliases

⚠ Common Mistakes

  • Printing output in .zshenv: it runs for every script and scp session, and stray output breaks them
  • Expecting scripts to see .zshrc aliases: non-interactive shells only read .zshenv
  • Editing .bash_profile after switching: zsh ignores it
  • chsh refusing Homebrew zsh: add its path to /etc/shells first

✓ Tips & Best Practices

  • On macOS, set PATH in .zprofile: /etc/zprofile runs path_helper, which reorders PATH set in .zshenv
  • Move your dotfiles with export ZDOTDIR=~/.config/zsh in ~/.zshenv
  • Debug slow or broken startup with zsh -f, then add files back one at a time

Quick Summary

  • $ZSH_VERSION — running version
  • chsh -s $(which zsh) — set login shell
  • .zshrc — interactive config
  • .zprofile — login-only setup like PATH
  • zsh -f — start with no config
