context

A context.Context carries a cancellation signal, an optional deadline, and request-scoped values across API boundaries and goroutines. Every function that does I/O or may block should accept ctx context.Context as its first parameter and stop when ctx.Done() closes. Derived contexts form a tree: canceling a parent cancels all its children.

Rules

  • Never store a context in a struct; pass it explicitly
  • Always call the cancel func (usually defer cancel())
  • Use WithValue only for request-scoped data (IDs), not optional params
  • ctx.Err() is context.Canceled or context.DeadlineExceeded

Cancellation & Deadlines

func fetch(ctx context.Context, url string) (*http.Response, error) {
    req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
    return http.DefaultClient.Do(req)        // aborts on cancel
}

ctx, cancel := context.WithTimeout(context.Background(), 3*time.Second)
defer cancel()
resp, err := fetch(ctx, url)
if errors.Is(err, context.DeadlineExceeded) { /* too slow */ }

for {                                        // worker loop
    select {
    case <-ctx.Done(): return ctx.Err()      // stop promptly
    case j := <-jobs: handle(ctx, j)
    }
}

ctx2, cancelC := context.WithCancelCause(parent)
cancelC(errShutdown); context.Cause(ctx2)    // errShutdown
stop := context.AfterFunc(ctx, cleanup)      // run on cancel
type ctxKey struct{}; ctx = context.WithValue(ctx, ctxKey{}, reqID)

⚠ Common Mistakes

  • Forgetting cancel(): timers and goroutines leak until the parent ends (go vet lostcancel)
  • Passing nil as a context; use context.TODO()
  • Using context.Background() deep inside handlers, losing the request's cancellation

✓ Tips & Best Practices

  • In HTTP handlers use r.Context(); it cancels when the client disconnects
  • Use context.WithoutCancel for work that must finish after the request (audit logs)
  • In tests, use t.Context() (1.24); it's canceled when the test ends

Quick Summary

  • ctx first param — cancellation + deadline
  • WithTimeout / WithCancel + defer cancel()
  • <-ctx.Done() / ctx.Err() — react
  • WithValue — request-scoped data only
