Reading Files

os.ReadFile loads a whole file into memory in one call, ideal for small files. For large files or line-by-line processing, os.Open returns an *os.File (an io.Reader), which you wrap in a bufio.Scanner or bufio.Reader. Always defer f.Close() after checking the open error.

Notes

  • bufio.Scanner strips the trailing \n (and \r\n)
  • Scanner's default max line is 64 KB; raise it with Buffer
  • Check scanner.Err() after the loop
  • errors.Is(err, fs.ErrNotExist) detects a missing file

Reading Patterns

data, err := os.ReadFile("config.json")   // whole file
if errors.Is(err, fs.ErrNotExist) { return defaults, nil }

f, err := os.Open("access.log")
if err != nil { return err }
defer f.Close()

sc := bufio.NewScanner(f)
sc.Buffer(make([]byte, 0, 64*1024), 1024*1024) // allow 1 MB lines
for sc.Scan() {
    line := sc.Text()                  // no trailing newline
    if strings.HasPrefix(line, "#") { continue }
    process(line)
}
if err := sc.Err(); err != nil { return err }

sc = bufio.NewScanner(strings.NewReader("a b  c"))
sc.Split(bufio.ScanWords)              // word by word

br := bufio.NewReader(os.Stdin)        // interactive input
name, _ := br.ReadString('\n')         // includes the '\n'
name = strings.TrimSpace(name)

Code Explained

os.ReadFile — returns []byte; convert with string(data)
defer f.Close() — only after the error check
sc.Scan() — false at EOF or on error
sc.Buffer — needed for lines over 64 KB
ReadString('\n') — keeps the delimiter; trim it

Coming From…

  • Python — open().read() → os.ReadFile
  • Python — for line in f → bufio.Scanner
  • Java — Files.readAllBytes → os.ReadFile

⚠ Common Mistakes

  • bufio.Scanner: token too long on big lines; call sc.Buffer with a larger max
  • Forgetting sc.Err(), so read errors look like a normal end of file
  • Reading multi-GB files with os.ReadFile; stream them instead

✓ Tips & Best Practices

  • Open with os.Open + defer Close in a small helper so the file closes per call
  • Pass io.Reader to parsing functions instead of file names
  • Use os.Root (1.24) to confine reads to a directory when paths come from users

Quick Summary

  • os.ReadFile — whole file
  • os.Open + defer f.Close() — streaming
  • bufio.Scanner — line by line
  • fs.ErrNotExist — missing file check
