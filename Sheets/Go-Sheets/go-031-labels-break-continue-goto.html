break, continue, labels & goto

break exits the innermost for, switch or select; continue skips to the next loop iteration. A label before a loop lets you break or continue an outer loop, which is the clean way out of nested loops or a select inside a for. goto exists but is rarely used.

Notes

  • Labels are identifiers followed by : on the statement
  • Unused labels are compile errors
  • goto can't jump over variable declarations or into blocks
  • Inside select, plain break exits only the select

Loop Control

for i := range 10 {
    if i%2 == 0 { continue }    // skip evens
    if i > 7 { break }          // stop at 9
    fmt.Print(i, " ")           // 1 3 5 7
}

outer:
for _, row := range grid {
    for _, cell := range row {
        if cell == target { break outer } // exits both
        if cell < 0 { continue outer } // next row
    }
}

loop:
for {
    select {
    case msg := <-msgs:
        handle(msg)
    case <-ctx.Done():
        break loop  // plain break only exits select
    }
}

Code Explained

continue — jumps to the post statement / next element
break outer — terminates the labeled loop
continue outer — next iteration of the outer loop
break loop — required to leave a for/select combo
return is often clearer than labels inside a helper func

Coming From…

  • Java — same labeled break outer / continue outer
  • Python — no labels; Go doesn't need flag variables
  • C — goto exists but is restricted

⚠ Common Mistakes

  • break inside switch or select within a loop, expecting to leave the loop
  • Declaring a label and never using it: "label L defined and not used"
  • Using goto for cleanup paths; defer handles that reliably

✓ Tips & Best Practices

  • Name labels after what they loop over: rows:, retry:, loop:
  • If you need two labels, the code probably wants a helper function
  • Use slices.ContainsFunc / IndexFunc to replace simple search loops

Quick Summary

  • break / continue — innermost loop
  • break L / continue L — labeled outer loop
  • for + select — needs a label to exit
  • goto — legal, rarely needed
