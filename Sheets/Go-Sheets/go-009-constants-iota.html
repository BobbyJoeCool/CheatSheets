Constants & iota

const · typed vs untyped constants · arbitrary-precision constant math · iota enums · skipping with _ · 1 << iota bit flags · stringer for String()

Constants

const declares values fixed at compile time: numbers, strings, booleans and runes only. Untyped constants have arbitrary precision and get a type only when used. iota is a counter that restarts at 0 in every const ( … ) block and increments per line, the standard way to build enums.

Constant Facts

  • Untyped constants convert implicitly: time.Sleep(2 * time.Second) works
  • Typed constants (const n int = 5) follow normal type rules
  • A line with no expression repeats the previous expression with the next iota

iota Enums & Flags

const big = 1 << 100       // OK: untyped, never stored
const MaxUsers int = 500   // typed constant

type Weekday int
const (
    Sunday Weekday = iota       // 0
    Monday                      // 1 (repeats the expr)
    Tuesday                     // 2
)

type Perm uint8
const (
    Read  Perm = 1 << iota      // 1
    Write                       // 2
    Exec                        // 4
)
p := Read | Write               // 3; p&Exec == 0

const (
    _  = iota                   // skip 0
    KB = 1 << (10 * iota)       // 1024, then MB = 1048576
)

Code Explained

Weekday = iota — defined type keeps enum values distinct from plain ints
Empty lines in the block repeat the last expression
1 << iota — powers of two for bit flags
_ = iota — skip a value (often to reserve 0 as "unset")
big overflows int64 but compiles because it stays untyped

Coming From…

  • Java / C# — no enum keyword; type + iota instead
  • JS — const is compile-time only, not a frozen variable
  • C — iota replaces manual enum numbering

⚠ Common Mistakes

  • Expecting iota to continue across const blocks; it restarts at 0 in each block
  • const t = time.Now(): function calls aren't constant (only builtins like len on constants)
  • Reordering enum lines renumbers them; stored values change meaning

✓ Tips & Best Practices

  • Generate String() methods with //go:generate stringer -type=Weekday
  • Reserve 0 as an "unknown" value so the zero value is detectable

Quick Summary

  • const — compile-time numbers, strings, bools, runes
  • untyped constants — arbitrary precision, adapt on use
  • iota — 0, 1, 2… per const block
  • type X int + iota — Go's enum idiom
