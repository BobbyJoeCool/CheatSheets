Web Routers

Since Go 1.22 the standard http.ServeMux supports methods and path wildcards (GET /items/{id}), so many services need no router library. Third-party routers still add conveniences: chi stays net/http-compatible with middleware groups; Gin and Echo use their own context type with binding, validation and rendering helpers.

Notes

  • chi handlers are plain http.HandlerFuncs
  • Gin/Echo handlers take *gin.Context / echo.Context
  • All support middleware chains and route groups
  • Stdlib first; add a router when you need groups or binding

Same Route, Three Routers

// chi (github.com/go-chi/chi/v5)
r := chi.NewRouter()
r.Use(middleware.Logger, middleware.Recoverer)
r.Route("/api", func(r chi.Router) {
    r.Get("/users/{id}", func(w http.ResponseWriter, q *http.Request) {
        fmt.Fprint(w, chi.URLParam(q, "id"))
    })
})
http.ListenAndServe(":8080", r)

// Gin (github.com/gin-gonic/gin)
g := gin.Default()
g.GET("/api/users/:id", func(c *gin.Context) {
    c.JSON(http.StatusOK, gin.H{"id": c.Param("id")})
})
g.POST("/api/users", func(c *gin.Context) {
    var u User
    if err := c.ShouldBindJSON(&u); err != nil { c.AbortWithStatus(400) }
})
g.Run(":8080")

// Echo: e.GET("/users/:id", func(c echo.Context) error {
//     return c.JSON(200, map[string]string{"id": c.Param("id")}) })

Code Explained

chi Route — nested route groups
chi.URLParam — like stdlib r.PathValue
Gin :id path params + c.Param
ShouldBindJSON — decode + validate tags
Echo handlers return error

Coming From…

  • Python — Gin ≈ Flask; chi ≈ minimal Flask
  • Node — Echo / Gin ≈ Express
  • Java — ≈ Spring MVC routing, without annotations

⚠ Common Mistakes

  • Picking Fiber and then finding net/http middleware and libraries don't plug in
  • Forgetting return after writing an error response in Gin handlers
  • Adding a router just for path params; Go 1.22's ServeMux already does it

✓ Tips & Best Practices

  • Start with stdlib ServeMux; move to chi for groups/middleware without lock-in
  • Keep business logic out of handlers so switching routers is cheap
  • Use Gin's binding:"required" tags for quick request validation

Quick Summary

  • stdlib ServeMux — methods + wildcards (1.22)
  • chi — net/http-compatible groups
  • Gin / Echo — rich context APIs
  • choose by ecosystem fit
