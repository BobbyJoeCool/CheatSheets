Hashing, Crypto & UUIDs

Go's standard library includes production-grade cryptography: hashes (crypto/sha256), MACs (crypto/hmac), secure randomness (crypto/rand), TLS and more. Passwords need a slow hash like bcrypt or argon2 from golang.org/x/crypto. Go 1.27 added a uuid package for generating and parsing UUIDs, replacing the most common third-party dependency.

Notes

  • Never use md5 / sha1 for security; fine for checksums
  • hash/fnv, hash/maphash are fast non-crypto hashes
  • Compare secrets with subtle.ConstantTimeCompare or hmac.Equal
  • Go 1.27 adds crypto/mldsa (post-quantum signatures)

Common Crypto Tasks

sum := sha256.Sum256([]byte("hello"))       // [32]byte
fmt.Println(hex.EncodeToString(sum[:]))     // 2cf24dba…

h := sha256.New()                           // streaming
io.Copy(h, file)
digest := h.Sum(nil)

mac := hmac.New(sha256.New, secretKey)      // sign a webhook
mac.Write(body)
valid := hmac.Equal(mac.Sum(nil), gotSig)   // constant time

key := make([]byte, 32)
crand.Read(key)                             // crypto/rand
tok := crand.Text()                         // base32 token (1.24)

hash, _ := bcrypt.GenerateFromPassword([]byte(pw), bcrypt.DefaultCost)
err := bcrypt.CompareHashAndPassword(hash, []byte(pw)) // nil = ok

f := fnv.New64a(); f.Write([]byte("key")); f.Sum64() // fast non-crypto
id := uuid.NewV7()                          // uuid pkg (1.27), time-ordered
u, err := uuid.Parse("0b7c…")               // UUID, error; id.String()

Code Explained

sha256.Sum256 — one-shot digest as an array
h.Sum(nil) — finish a streaming hash
hmac.Equal — avoids timing attacks
bcrypt — salted, slow password hashing (x/crypto)
fnv — fast hashing for sharding/buckets

Coming From…

  • Python — hashlib.sha256 → sha256.Sum256
  • Python — uuid.uuid4() → uuid.New() (1.27)
  • Node — crypto.randomBytes → crypto/rand.Read

⚠ Common Mistakes

  • Storing passwords as SHA-256 hashes; fast hashes are easy to brute-force
  • Comparing MACs with == / bytes.Equal; use hmac.Equal
  • Seeding math/rand with time for tokens; use crypto/rand

✓ Tips & Best Practices

  • Prefer high-level APIs (crypto/tls, x/crypto/nacl/secretbox) over raw primitives
  • Check the 1.27 uuid package before adding a third-party UUID library
  • Hash files with io.Copy(h, f) so large files stream

Quick Summary

  • sha256.Sum256 / New — hashing
  • hmac + hmac.Equal — message auth
  • crypto/rand — secure random bytes
  • bcrypt — passwords; uuid — IDs (1.27)
