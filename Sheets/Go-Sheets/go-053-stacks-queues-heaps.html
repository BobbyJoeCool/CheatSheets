Stacks, Queues & Heaps

Go has no built-in stack or queue types; slices cover both. container/heap turns any type implementing heap.Interface into a priority queue, and container/list provides a doubly linked list. A buffered channel is a ready-made concurrent FIFO queue with a fixed capacity.

Notes

  • Stack push/pop on a slice end is O(1) amortized
  • Queue s = s[1:] is O(1) but keeps the old array until reallocated
  • heap.Interface = sort.Interface + Push + Pop
  • container/list is rarely faster than a slice in practice

Stack, Queue, Heap

stack := []int{}
stack = append(stack, 1, 2, 3)            // push
top := stack[len(stack)-1]                // peek: 3
stack = stack[:len(stack)-1]              // pop

queue := []string{"a", "b"}
queue = append(queue, "c")                // enqueue
front := queue[0]; queue = queue[1:]      // dequeue "a"

type MinHeap []int
func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *MinHeap) Pop() any {
    old := *h; x := old[len(old)-1]; *h = old[:len(old)-1]; return x
}
h := &MinHeap{5, 2, 8}
heap.Init(h)
heap.Push(h, 1)
fmt.Println(heap.Pop(h), heap.Pop(h))     // 1 2

Code Explained

stack — append to push, reslice to pop
queue — queue[1:] drops the front
Less — < gives a min-heap; > a max-heap
Push / Pop — pointer receivers; called by heap
always use heap.Push/Pop, not h.Push directly

Coming From…

  • Java — PriorityQueue ≈ heap; ArrayDeque ≈ slice
  • Python — deque ≈ slice or ring buffer

⚠ Common Mistakes

  • Calling h.Pop() directly instead of heap.Pop(h); the heap order breaks
  • Popping from an empty slice: index out of range [-1]; check len first
  • Long-running queue = queue[1:] loops that never shrink memory; copy down periodically

✓ Tips & Best Practices

  • For a max-heap, flip Less to h[i] > h[j]
  • Store an index field in heap items to support heap.Fix updates
  • Use a buffered channel as a semaphore or bounded work queue between goroutines

Quick Summary

  • slice — stack and simple queue
  • container/heap — priority queue
  • container/list — linked list
