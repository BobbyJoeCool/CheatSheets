⚠ Common Mistakes

  • No cancel(), no Close(), no Flush(): leaks and lost data
  • http.Get without a timeout in production
  • Unbounded goroutines; use errgroup.SetLimit

✓ Tips & Best Practices

  • Pass ctx first; select on ctx.Done() in loops
  • Set go in go.mod to the oldest version you support
  • Check go.dev/doc/go1.N release notes when upgrading
