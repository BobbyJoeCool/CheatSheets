Arithmetic Operators

Go's arithmetic operators work on numbers of the same type; mixing int and float64 needs a conversion. Integer division truncates toward zero, and % takes the sign of the left operand. ++ and -- are statements, not expressions, so y := x++ doesn't compile.

Notes

  • No power operator: use math.Pow(x, y) or 1 << n for powers of 2
  • + also concatenates strings
  • Integer overflow wraps silently; there is no checked arithmetic
  • Int division by a zero variable panics; float division gives ±Inf

Arithmetic in Practice

a, b := 17, 5
fmt.Println(a+b, a-b, a*b)   // 22 12 85
fmt.Println(a / b)           // 3   (truncated)
fmt.Println(a % b)           // 2
fmt.Println(-17 / 5)         // -3  (toward zero)
fmt.Println(-17 % 5)         // -2  (sign of dividend)
fmt.Println(17.0 / 5)        // 3.4

x := 10
x++                          // statement only
// y := x++                  // syntax error
fmt.Println(-x, +x)          // -11 11

f := float64(a) / float64(b) // 3.4: convert first
avg := float64(a+b) / 2      // 11

zero := 0
// _ = a / zero              // panic: divide by zero
fmt.Println(math.Pow(2, 10)) // 1024

Code Explained

17 / 5 — both ints, so the result is an int (3)
-17 % 5 — -2, not 3 like Python
17.0 / 5 — untyped constants: float division
x++ — a statement; can't be used inside expressions
float64(a) / float64(b) — convert before dividing

Coming From…

  • Python — // floor vs Go truncation: -7/2 is -3
  • Python / JS — no **; use math.Pow
  • C / Java — i++ is a statement, not an expression

⚠ Common Mistakes

  • avg := sum / count with ints; the fraction is lost. Convert to float64 first
  • Using % to wrap negative indexes; -1 % 5 is -1, use ((i % n) + n) % n
  • Writing x**2; Go has no exponent operator (** is a pointer-deref syntax error)

✓ Tips & Best Practices

  • Use x*x instead of math.Pow(x, 2) for small integer powers (faster, exact)
  • Use min(a, b) / max(a, b) builtins (Go 1.21) instead of if-statements
  • Guard divisions on user input: if d == 0 { return errDivZero }

Quick Summary

  • / on ints — truncates toward zero
  • % — sign follows the dividend
  • ++ / -- — statements only
  • math.Pow — no ** operator
