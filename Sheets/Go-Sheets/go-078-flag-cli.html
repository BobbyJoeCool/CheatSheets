Command-Line Flags

The flag package parses -name value style options. Define flags (each returns a pointer, or binds to a variable with …Var), call flag.Parse(), then read the remaining positional arguments with flag.Args(). -h / -help prints auto-generated usage. For subcommands, create one flag.FlagSet per command.

Syntax Accepted

  • -port 8080, -port=8080, --port=8080 all work
  • Booleans: -v or -v=false (not -v false)
  • Parsing stops at the first non-flag argument or --
  • For GNU-style -abc short flags use spf13/pflag or Cobra

Defining Flags

var (
    port    = flag.Int("port", 8080, "listen port")
    verbose = flag.Bool("v", false, "verbose output")
    timeout = flag.Duration("timeout", 5*time.Second, "timeout")
    name    string; tags []string
)

func main() {
    flag.StringVar(&name, "name", "world", "who to greet")
    flag.Func("tag", "repeatable tag", func(s string) error {
        tags = append(tags, s); return nil
    })
    flag.Usage = usage          // custom -h; calls flag.PrintDefaults()
    flag.Parse()
    fmt.Println(*port, *verbose, *timeout, name, tags, flag.Args())
}
// $ greet -port=9000 -v -tag a -tag b -timeout 2s x.txt
// 9000 true 2s world [a b] [x.txt]

serve := flag.NewFlagSet("serve", flag.ExitOnError) // subcommand
addr := serve.String("addr", ":80", "address")
serve.Parse(os.Args[2:])

Code Explained

flag.Int(…) — returns *int; dereference after Parse
flag.Duration — parses 2s, 1h30m
flag.Func — custom parsing, repeatable flags
flag.Usage — customize -h output
NewFlagSet — separate flags per subcommand

Coming From…

⚠ Common Mistakes

  • Reading *port before flag.Parse(); you get the default
  • Putting flags after positional args (app file.txt -v); -v becomes a positional arg
  • -v false for booleans; it sets true and treats false as an argument

✓ Tips & Best Practices

  • Use flag.TextVar for types like net.IP or slog.Level
  • Combine flags with env fallbacks for 12-factor apps
  • Move to Cobra (sheet 082) when you have many nested subcommands

Quick Summary
