Testing Basics

Go has testing built in. Tests live in _test.go files next to the code, are functions named TestXxx(t *testing.T), and run with go test. There's no assertion library in the stdlib: compare values and call t.Errorf (continue) or t.Fatalf (stop). The idiomatic style is table-driven tests with subtests via t.Run.

Notes

  • package foo tests see unexported names; package foo_test tests only the public API
  • Test results are cached; -count=1 forces a re-run
  • -run 'TestAdd/neg' selects tests and subtests by regex
  • t.Errorf messages: got X, want Y

Table-Driven Test

package mathx                            // math_test.go

func TestAdd(t *testing.T) {
    tests := []struct {
        name       string
        a, b, want int
    }{
        {"positive", 2, 3, 5},
        {"negative", -2, -3, -5},
        {"zero", 0, 0, 0},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if got := Add(tt.a, tt.b); got != tt.want {
                t.Errorf("Add(%d,%d) = %d, want %d", tt.a, tt.b, got, tt.want)
            }
        })
    }
}

Code Explained

_test.go — compiled only by go test
[]struct{…} — one row per case
t.Run(name, …) — named subtest, filterable with -run
t.Errorf — record failure and keep going
got … want — the conventional message order

Coming From…

  • Python — no assert; use t.Errorf (or testify)
  • Java — no annotations; TestXxx names are found automatically
  • JS — table tests ≈ test.each

Failure Methods

MethodBehavior
t.Error / Errorffail, continue
t.Fatal / Fatalffail, stop this test
t.Log / Logfprint with -v or on fail
t.Skip / Skipfmark skipped
t.Fail / FailNowfail without message

⚠ Common Mistakes

  • Calling t.Fatal from a goroutine started by the test; it must run on the test goroutine
  • Tests that depend on execution order or shared global state
  • Vague messages like "wrong result"; include inputs, got and want

✓ Tips & Best Practices

  • Use go test -cover to see coverage per package
  • Put fixtures in testdata/; the go tool ignores that directory
  • Compare structs with reflect.DeepEqual or github.com/google/go-cmp/cmp.Diff

Quick Summary

  • func TestX(t *testing.T) in _test.go
  • t.Errorf / t.Fatalf — report failures
  • table-driven + t.Run — idiomatic style
  • go test ./... -run -v -count=1
