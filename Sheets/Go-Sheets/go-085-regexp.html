Regular Expressions

Go's regexp package uses the RE2 engine, which guarantees linear-time matching: no catastrophic backtracking, so it's safe on untrusted input. The trade-off is no backreferences and no lookaround. Compile once with regexp.MustCompile at package level and reuse the *Regexp; it's safe for concurrent use.

Notes

  • Use raw strings for patterns: `\d+`
  • Find… returns the leftmost match; FindAll… takes a limit n (-1 = all)
  • Submatch variants return capture groups; Index variants return positions
  • (?i) case-insensitive, (?m) multiline, (?s) dot matches newline

regexp in Practice

var reDate = regexp.MustCompile(`(?P<year>\d{4})-(?P<month>\d{2})-(\d{2})`)

reDate.MatchString("due 2026-10-16")             // true
reDate.FindString("a 2026-10-16 b 2027-01-01")   // "2026-10-16"
reDate.FindAllString("2026-10-16 2027-01-01", -1) // [both]

m := reDate.FindStringSubmatch("2026-10-16")
fmt.Println(m[0], m[1], m[3])                    // 2026-10-16 2026 16
i := reDate.SubexpIndex("month")
fmt.Println(m[i])                                // 10

reDate.ReplaceAllString("2026-10-16", "${month}/$3/${year}") // 10/16/2026
re := regexp.MustCompile(`\s+`)
re.ReplaceAllString("a   b \t c", " ")           // "a b c"
re.Split("a  b c", -1)                           // [a b c]

upper := regexp.MustCompile(`[a-z]+`).ReplaceAllStringFunc("go is fun",
    strings.ToUpper)                             // GO IS FUN

re2, err := regexp.Compile(userPattern)           // check user input

Code Explained

(?P<year>…) — named group
FindStringSubmatch — [full, g1, g2, …]
SubexpIndex("month") — group index by name
${month} / $3 — references in replacements
Compile — returns error for bad patterns (user input)

Coming From…

  • Python / JS — no lookahead or backreferences (RE2)
  • Python — re.compile → regexp.MustCompile
  • Java — named groups (?P<n>…) (Python syntax)

⚠ Common Mistakes

  • Compiling inside a loop or handler; compile once at package level
  • Porting patterns with lookahead (?=…) or backrefs \1; RE2 rejects them
  • Forgetting anchors: MatchString("\d+") is true for "abc1"; use ^\d+$

✓ Tips & Best Practices

  • Prefer strings functions for fixed substrings; they're much faster
  • Use the []byte methods (Find, ReplaceAll) to avoid conversions on byte data
  • Test patterns at regex101.com with the Golang flavor

Quick Summary

  • RE2 — linear time, no backrefs/lookaround
  • MustCompile once — reuse safely
  • Find…Submatch — capture groups
  • ReplaceAllString — $1 / ${name}
