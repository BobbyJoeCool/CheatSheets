Comparison & Logical Operators

== != < <= > >= · comparable types (struct, array, pointer, chan, interface) · slices/maps/funcs compare only to nil · && || ! short-circuit · no ternary · cmp.Compare · min / max builtins

Comparison & Logic

Comparison operators return an untyped bool. Both sides must be the same type (or one an untyped constant). Only comparable types work with ==: numbers, strings, booleans, pointers, channels, interfaces, and arrays or structs made of comparable fields. Slices, maps and funcs can only be compared to nil.

Notes

  • && and || short-circuit: the right side may not run
  • No ternary ? :; write an if / else
  • cmp.Compare(a, b) returns -1, 0 or +1 (Go 1.21)
  • Comparing interfaces holding uncomparable values panics at runtime

Comparisons

fmt.Println(3 < 5, "a" >= "b", 2 != 2) // true false false

type Point struct{ X, Y int }
p1, p2 := Point{1, 2}, Point{1, 2}
fmt.Println(p1 == p2)                  // true (field-wise)
fmt.Println([2]int{1, 2} == [2]int{1, 2}) // true

s1, s2 := []int{1}, []int{1}
// s1 == s2                            // compile error
fmt.Println(slices.Equal(s1, s2))      // true
fmt.Println(s1 != nil)                 // true

ok := len(s1) > 0 && s1[0] == 1  // short-circuit
fmt.Println(!ok)                       // false

fmt.Println(cmp.Compare(2, 5))         // -1
fmt.Println(min(3, 1, 2), max(4.5, 2)) // 1 4.5

label := "odd"                         // no ternary:
if n%2 == 0 { label = "even" }

Code Explained

Struct and array == compare every field/element
slices.Equal / maps.Equal / bytes.Equal for the rest
len(s) > 0 && s[0]… — right side skipped when empty
cmp.Compare — three-way compare for sort funcs
min / max — variadic builtins since Go 1.21

Coming From…

  • JS — no ===; == never coerces types
  • Python — == on structs compares fields; slices need slices.Equal
  • C / Java — no ?: ternary operator

⚠ Common Mistakes

  • Using a slice or map as a map key; keys must be comparable (use an array or string key)
  • reflect.DeepEqual in production hot paths; it's slow and treats nil vs empty slices as different
  • Comparing floats with == after arithmetic (see sheet 011)

✓ Tips & Best Practices

  • Order cheap checks first in && chains to skip expensive ones
  • Make structs comparable (no slice fields) if you want them as map keys
  • Use cmp.Or(a, b, c) to pick the first non-zero value

Quick Summary

  • == != < > — same-type comparisons
  • structs/arrays — comparable field-by-field
  • slices/maps/funcs — only == nil
  • && / || — short-circuit; no ternary
