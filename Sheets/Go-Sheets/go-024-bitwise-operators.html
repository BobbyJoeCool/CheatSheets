Bitwise Operators

Bitwise operators work on integers bit by bit. Go adds &^ (AND NOT, bit clear), and uses ^x as unary NOT instead of ~. Right shift is arithmetic for signed integers (sign bit copied) and logical for unsigned. Shifting by a negative count panics.

Notes

  • ^ is XOR when binary, NOT when unary
  • x &^ y clears in x every bit set in y
  • Shift counts may be any integer type (since Go 1.13)
  • math/bits has popcount, rotate, leading/trailing zeros

Bits in Action

a, b := 0b1100, 0b1010          // 12, 10
fmt.Printf("%04b\n", a&b)       // 1000  AND
fmt.Printf("%04b\n", a|b)       // 1110  OR
fmt.Printf("%04b\n", a^b)       // 0110  XOR
fmt.Printf("%04b\n", a&^b)      // 0100  AND NOT
fmt.Println(^0)                 // -1    NOT
fmt.Println(1<<4, 64>>2)        // 16 16
fmt.Println(-16 >> 2)           // -4 (sign kept)

const (
    FlagA uint8 = 1 << iota     // 0001
    FlagB                       // 0010
    FlagC                       // 0100
)
f := FlagA | FlagC              // set
f &^= FlagA                     // clear
on := f&FlagC != 0              // test → true
f ^= FlagB                      // toggle

bits.OnesCount(255)             // 8
bits.LeadingZeros64(1)          // 63
bits.RotateLeft8(0b1000_0001, 1) // 3

Code Explained

%04b — binary, padded to 4 digits
a &^ b — keep bits of a not in b
-16 >> 2 — arithmetic shift keeps the sign
set |=, clear &^=, test & != 0, toggle ^=
math/bits — fast intrinsics for bit tricks

Coming From…

  • C / Java — ^x is NOT (not ~x)
  • C — &^ (bit clear) is Go-only
  • Java — no >>>; use unsigned types instead

⚠ Common Mistakes

  • Writing ~x for NOT (C habit); Go uses ^x
  • Shifting past the type width: uint8(1) << 8 is 0 at runtime and a compile error for constants
  • Shifting a signed value expecting zeros on the left; convert to unsigned first

✓ Tips & Best Practices

  • Use typed constants (type Perm uint8) so flags don't mix with other ints
  • Give the flag type a String() method for readable logs
  • Use bits.Len(x) to find the number of bits needed to represent x

Quick Summary

  • & | ^ — AND, OR, XOR
  • &^ — bit clear (AND NOT)
  • ^x — bitwise NOT
  • << >> — shifts; signed >> keeps the sign
