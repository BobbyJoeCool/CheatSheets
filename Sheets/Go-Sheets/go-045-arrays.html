Arrays

An array has a fixed length that is part of its type: [3]int and [4]int are different types. Arrays are values: assigning or passing one copies every element. Because of that they're rarely used directly; slices (built on arrays) are the everyday collection. Arrays shine as fixed-size keys, buffers and lookup tables.

Notes

  • [...]T{…} lets the compiler count the elements
  • Arrays of comparable elements support ==, so they work as map keys
  • Out-of-range constant indexes are compile errors
  • len(arr) is a compile-time constant

Array Basics

var a [3]int                     // [0 0 0]
b := [3]string{"x", "y", "z"}
c := [...]int{10, 20, 30, 40}    // len 4, counted by compiler
d := [5]int{1: 7, 3: 9}          // [0 7 0 9 0] indexed literal

a[0] = 5
fmt.Println(len(c), c[len(c)-1]) // 4 40

e := c                           // full copy
e[0] = 99
fmt.Println(c[0], e[0])          // 10 99

fmt.Println(b == [3]string{"x", "y", "z"}) // true

var grid [3][3]int               // 2D array
grid[1][2] = 1

seen := map[[2]int]bool{}        // array as map key
seen[[2]int{0, 1}] = true

s := c[1:3]                      // slice of the array: [20 30]

Code Explained

[...]int{…} — length inferred (4)
{1: 7, 3: 9} — index: value literals; others zero
e := c — copies all elements (value semantics)
== — element-wise comparison
c[1:3] — a slice that shares the array's memory

Coming From…

  • Python / JS — arrays are fixed size; slices are the "list"
  • Java — arrays are values: assignment copies
  • C — arrays don't decay to pointers

⚠ Common Mistakes

  • Passing a large array to a function and wondering why changes don't stick (copy); pass *[N]T or a slice
  • Mixing [3]int and []int in a signature; they're unrelated types
  • Ranging for _, v := range bigArray copies the whole array first

✓ Tips & Best Practices

  • Use arrays when the size is part of the meaning (RGB, IPv4, digest)
  • Convert slice → array with [4]byte(s) (Go 1.20) after a length check
  • Use arr[:] to pass an array to slice-based APIs

Quick Summary

  • [N]T — fixed length in the type
  • value semantics — copies on assign
  • comparable — map keys
  • arr[:] — view as a slice
