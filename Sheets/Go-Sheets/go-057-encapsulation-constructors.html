Encapsulation & Constructors

Go's only access control is package-level: capitalized identifiers are exported, everything else is package-private. There are no language constructors; by convention NewThing(…) returns an initialized *Thing. Types with a useful zero value may need no constructor at all.

Conventions

  • New alone when the package has one main type: list.New()
  • Getters drop Get: u.Name(), setters keep Set: u.SetName()
  • internal/ packages can only be imported by their parent tree
  • Unexported fields + exported methods = invariants enforced

Controlled Construction

type Account struct {
    owner   string        // unexported: package-only
    balance int64
}

func New(owner string) (*Account, error) {   // constructor
    if owner == "" { return nil, errors.New("owner required") }
    return &Account{owner: owner}, nil
}

func (a *Account) Owner() string  { return a.owner }   // getter
func (a *Account) Deposit(n int64) error {
    if n < 0 { return ErrNegative }
    a.balance += n
    return nil
}

acct, err := account.New("ann")   // from another package
// acct.balance = 1e9   // compile error: unexported field

Code Explained

lowercase owner, balance — inaccessible outside the package
New — validates and returns (*T, error)
Owner() — getter without a Get prefix
Deposit — the only way to change the balance
acct.balance — rejected at compile time

⚠ Common Mistakes

  • Exporting struct fields "for convenience" and losing the ability to enforce invariants
  • Constructors that return a value T when methods have pointer receivers
  • Naming getters GetName(); Go style is Name()

✓ Tips & Best Practices

  • Make the zero value usable where possible (var b bytes.Buffer style)
  • Return concrete types from constructors; accept interfaces in parameters
  • Use internal/ for code shared inside your module but not public

Quick Summary

  • Capitalized — exported; lowercase — package-private
  • NewX(…) (*X, error) — constructor convention
  • getters — Name(), not GetName()
  • internal/ — module-private packages
