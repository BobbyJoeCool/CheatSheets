Transforming & Joining

Because strings are immutable, every strings transform returns a new string. The Trim family is the most confusing: Trim / TrimLeft / TrimRight remove any of a set of characters, while TrimPrefix / TrimSuffix remove an exact substring once.

Notes

  • Replace(s, old, new, n) — n = -1 means all (same as ReplaceAll)
  • NewReplacer does many replacements in one pass
  • strings.Title is deprecated; use golang.org/x/text/cases
  • ToUpper / ToLower are Unicode-aware

Transform Functions

strings.ToUpper("gopher")              // GOPHER
strings.ToLower("HeLLo")               // hello
strings.TrimSpace("  hi \n")           // "hi"
strings.Trim("--hi--", "-")            // "hi"
strings.TrimLeft("xxhixx", "x")        // "hixx"
strings.TrimPrefix("v1.2.3", "v")      // "1.2.3"
strings.TrimSuffix("file.go", ".go")   // "file"
strings.TrimFunc("123abc456", unicode.IsDigit) // "abc"

strings.Replace("aaaa", "a", "b", 2)   // "bbaa"
strings.ReplaceAll("a-b-c", "-", "/")  // "a/b/c"
r := strings.NewReplacer("<", "&lt;", ">", "&gt;")
r.Replace("<b>")                       // "&lt;b&gt;"

strings.Join([]string{"a", "b"}, ", ") // "a, b"
strings.Repeat("ab", 3)                // "ababab"
strings.Map(func(r rune) rune {        // drop vowels
    if strings.ContainsRune("aeiou", r) { return -1 }
    return r
}, "gopher")                           // "gphr"

Code Explained

Trim(s, "-") — strips any - chars from both ends
TrimPrefix — removes the exact prefix once, if present
Replace(…, 2) — replaces only the first 2 matches
NewReplacer — reusable, safe for concurrent use
Map — return -1 to delete a rune

Coming From…

  • Python — strip() → TrimSpace; lstrip(x) → TrimLeft
  • JS — replaceAll → strings.ReplaceAll
  • Java — String.join → strings.Join(slice, sep)

⚠ Common Mistakes

  • TrimLeft("version", "ver") → "sion"; it trims characters, use TrimPrefix for a word
  • TrimRight(name, ".go") turns "logo.go" into "l"; use TrimSuffix
  • Forgetting that strings.Replace returns a value: strings.ReplaceAll(s, …) alone does nothing

✓ Tips & Best Practices

  • Build reusable strings.NewReplacer values once at package level
  • For HTML escaping use html.EscapeString, not a hand-made replacer
  • Use strings.Join instead of concatenating with separators in a loop

Quick Summary

  • TrimSpace / TrimPrefix / TrimSuffix — trimming
