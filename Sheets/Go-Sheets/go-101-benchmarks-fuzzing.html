Benchmarks, Fuzzing & Examples

The testing package also runs benchmarks (BenchmarkXxx(b *testing.B)), fuzz tests (FuzzXxx(f *testing.F)) that feed random mutated input to find crashes, and examples (ExampleXxx) that double as documentation and are verified against // Output:. Go 1.24's b.Loop() is the preferred benchmark loop.

Notes

  • Benchmarks run only with -bench; -benchmem reports allocations
  • b.Loop() keeps setup out of timing and prevents dead-code elimination
  • Fuzz failures are saved to testdata/fuzz/ and become regression tests
  • Compare runs statistically with benchstat

Bench, Fuzz, Example

func BenchmarkJoin(b *testing.B) {
    parts := strings.Fields("a b c d e f")  // setup: not timed
    for b.Loop() { strings.Join(parts, ",") } // Go 1.24
}

func FuzzReverse(f *testing.F) {
    f.Add("hello")                          // seed corpus
    f.Fuzz(func(t *testing.T, s string) {
        if Reverse(Reverse(s)) != s && utf8.ValidString(s) {
            t.Errorf("round trip failed for %q", s)
        }
    })
}

func ExampleReverse() {
    fmt.Println(Reverse("abc"))
    // Output: cba
}

// $ go test -bench=. -benchmem -count=6 > new.txt
// $ benchstat old.txt new.txt
// $ go test -fuzz=FuzzReverse -fuzztime=30s

Code Explained

for b.Loop() — runs the body enough times to measure
f.Add — seed inputs; f.Fuzz — property to check
ExampleReverse — shown in docs, checked by go test
-count=6 + benchstat — compare with confidence
go tool cover -html — visual coverage report

⚠ Common Mistakes

  • Old-style for i := 0; i < b.N; i++ with setup inside the loop being timed
  • Comparing single benchmark runs; noise can exceed the difference
  • Examples without // Output:; they compile but are never checked

✓ Tips & Best Practices

  • Run go fix to migrate b.N loops to b.Loop()
  • Fuzz parsers and decoders: they find edge cases humans miss
  • Use testing.AllocsPerRun to assert a function doesn't allocate

Quick Summary

  • BenchmarkX + b.Loop() — performance
  • FuzzX + f.Fuzz — random inputs
  • ExampleX + // Output: — tested docs
  • -benchmem, benchstat, -cover
