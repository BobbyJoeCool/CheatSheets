Time & Durations

time.Time is an instant with a location; time.Duration is an int64 count of nanoseconds. Formatting uses a reference time instead of %Y-%m-%d: write how Mon Jan 2 15:04:05 MST 2006 would look in your format (01/02 03:04:05PM '06 −0700). time.Now() includes a monotonic clock reading, so time.Since is safe from wall-clock jumps.

Notes

  • Compare times with Before, After, Equal, not ==
  • Store and transmit times in UTC / RFC 3339
  • time.Time{} zero value is year 1; test with t.IsZero()
  • Import _ "time/tzdata" to embed time zones in the binary

Working with Time

now := time.Now()
fmt.Println(now.Format("2006-01-02 15:04:05")) // 2026-10-16 14:30:00
now.Format(time.RFC3339)                    // 2026-10-16T14:30:00-05:00
now.Format("Jan 2, 2006 3:04 PM")           // Oct 16, 2026 2:30 PM

t, err := time.Parse("2006-01-02", "2026-12-25")
loc, _ := time.LoadLocation("America/Chicago")
t2, _ := time.ParseInLocation("2006-01-02 15:04", "2026-12-25 09:00", loc)

d := 90 * time.Minute                  // Duration
fmt.Println(d, d.Hours())              // 1h30m0s 1.5
later := now.Add(d)
tomorrow := now.AddDate(0, 0, 1)
age := now.Sub(t)                      // Duration between
start := time.Now(); work(); fmt.Println(time.Since(start))

dd, _ := time.ParseDuration("1h15m30s")
now.Truncate(time.Hour); now.Weekday(); now.YearDay()

timer := time.NewTimer(2 * time.Second) // fires once: <-timer.C
ticker := time.NewTicker(time.Second)   // repeats; defer ticker.Stop()

Code Explained

layout strings — use the 2006-01-02 15:04:05 reference
time.Parse — UTC unless the layout has a zone
ParseInLocation — interpret in a named zone
Add / Sub / AddDate — arithmetic
Timer / Ticker — one-shot / repeating events

⚠ Common Mistakes

  • Using "YYYY-MM-DD" layouts; Go needs "2006-01-02"
  • time.Sleep(5) sleeps 5 nanoseconds; write 5 * time.Second
  • Comparing times with ==; locations and monotonic readings differ, use Equal

✓ Tips & Best Practices

  • Use the predefined layouts: time.RFC3339, time.DateOnly, time.TimeOnly, time.DateTime
  • Inject a clock (func() time.Time) for testable time-dependent code
  • Since Go 1.23, unstopped Timers/Tickers are garbage-collected, but still Stop them
