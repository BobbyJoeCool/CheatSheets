Handling Errors Well

Good Go error handling adds context at each layer, handles each error exactly once, and decides at API boundaries what callers may inspect. Concurrent work collects errors with errgroup or errors.Join, and errors from deferred Close calls on written files must not be lost.

Principles

  • Wrap: fmt.Errorf("verb object: %w", err) at each layer
  • Decide once: return it or log it
  • Opaque by default; expose sentinels/types deliberately
  • Treat io.EOF and context.Canceled as normal outcomes

Patterns

func (s *Store) Save(u User) (err error) {
    f, err := os.Create(s.path(u.ID))
    if err != nil {
        return fmt.Errorf("save user %d: %w", u.ID, err)
    }
    defer func() { err = errors.Join(err, f.Close()) }()
    return json.NewEncoder(f).Encode(u)
}

g, ctx := errgroup.WithContext(ctx)      // x/sync/errgroup
for _, url := range urls {
    g.Go(func() error { return fetch(ctx, url) })
}
if err := g.Wait(); err != nil {         // first error wins
    slog.Error("fetch failed", "err", err)
}

var errs []error                         // collect all
for _, r := range rows {
    if e := check(r); e != nil { errs = append(errs, e) }
}
return errors.Join(errs...)              // nil if none

Code Explained

errors.Join(err, f.Close()) — keep both write and close errors
errgroup.WithContext — cancels siblings on first error
g.Wait() — returns the first non-nil error
slog.Error(…, "err", err) — log once at the top
errors.Join(errs...) — validation reports every problem

Coming From…

  • Java — no stack traces by default; add context when wrapping
  • Python — except: log; raise is the "handle twice" anti-pattern
  • JS — Promise.allSettled ≈ errors.Join of results

⚠ Common Mistakes

  • Logging at every layer, producing five log lines for one failure
  • Swallowing errors in goroutines (go f() where f returns an error)
  • Returning raw driver errors from a public package, leaking implementation details

✓ Tips & Best Practices

  • Translate errors at boundaries: DB ErrNoRows → your ErrNotFound
  • Use errgroup.SetLimit(n) to bound concurrency while collecting errors
  • Attach errors to logs as attributes: slog.Any("err", err)

Quick Summary

  • wrap with context — each layer
  • handle once — log or return
  • errgroup — concurrent errors
  • errors.Join — keep close/validation errors
