Streams: Reader & Writer

io.Reader and io.Writer are the two most important interfaces in Go. Files, network connections, HTTP bodies, compressors, hashes and buffers all implement them, so one function written against io.Reader works with every source. The io package supplies helpers to copy, combine, limit and split streams.

The Read Contract

  • Read(p) fills up to len(p) bytes and returns n
  • Process n > 0 bytes before checking err
  • io.EOF signals the normal end of the stream
  • Write must return a non-nil error if n < len(p)

Composing Streams

r := strings.NewReader("hello, reader")
buf := make([]byte, 5)
for {
    n, err := r.Read(buf)
    fmt.Print(string(buf[:n]), "|")   // hello|, rea|der|
    if err == io.EOF { break }
    if err != nil { return err }
}

n, err := io.Copy(os.Stdout, resp.Body)    // stream, no full load
data, err := io.ReadAll(io.LimitReader(r, 1<<20)) // cap at 1 MB

h := sha256.New()
tee := io.TeeReader(file, h)                // hash while reading
io.Copy(io.Discard, tee)
fmt.Printf("%x\n", h.Sum(nil))

var log bytes.Buffer
w := io.MultiWriter(os.Stdout, &log)        // write to both
fmt.Fprintln(w, "saved")

pr, pw := io.Pipe()                         // sync in-memory pipe
go func() { json.NewEncoder(pw).Encode(v); pw.Close() }()
http.Post(url, "application/json", pr)

Code Explained

buf[:n] — use only the bytes actually read
io.Copy — streams with a 32 KB buffer
LimitReader — protect against huge inputs
TeeReader — copy everything read into a writer
io.Pipe — connect a writer goroutine to a reader

Coming From…

  • Java — io.Reader ≈ InputStream, Writer ≈ OutputStream
  • Python — ≈ file-like objects with read / write
  • Node — ≈ streams, but synchronous calls

⚠ Common Mistakes

  • Checking err before using n; the last chunk often arrives together with io.EOF
  • Treating io.EOF as a failure and reporting it to users
  • io.ReadAll on untrusted input without a limit (memory exhaustion)

✓ Tips & Best Practices

  • Accept io.Reader / io.Writer params so tests can pass strings.Reader / bytes.Buffer
  • Use io.ReadFull when you need an exact number of bytes (headers, frames)
  • Wrap with bufio for many small reads/writes

Quick Summary

  • io.Reader — Read(p) (n, err)
  • io.Writer — Write(p) (n, err)
  • io.EOF — normal end
  • io.Copy / TeeReader / MultiWriter — compose
