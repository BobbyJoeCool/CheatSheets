Logging: log & slog

The classic log package writes timestamped lines to stderr; log.Fatal also exits. log/slog (Go 1.21) is the standard structured logger: each record has a level, a message and key-value attributes, rendered by a handler as text or JSON. Use slog for anything that runs in production.

Notes

  • Levels: Debug (-4), Info (0), Warn (4), Error (8)
  • slog.SetDefault also routes the old log package through slog
  • Typed attrs (slog.Int, slog.String) avoid allocations
  • LogValuer controls how a type is logged (redact secrets)

log and slog

log.SetFlags(log.LstdFlags | log.Lshortfile)
log.SetPrefix("[api] ")
log.Println("starting")  // [api] 2026/10/16 14:30:00 main.go:12: …
// log.Fatalf("bad config: %v", err) // logs, then os.Exit(1)

slog.Info("user login", "user", "ann", "attempts", 3)
// time=… level=INFO msg="user login" user=ann attempts=3

h := slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
    Level:     slog.LevelDebug,
    AddSource: true,
})
logger := slog.New(h)
slog.SetDefault(logger)

reqLog := logger.With("request_id", rid)   // child logger
reqLog.Warn("slow query", slog.Duration("took", d),
    slog.Group("db", "table", "users", "rows", 120))
reqLog.ErrorContext(ctx, "save failed", "err", err)

type Token string
func (Token) LogValue() slog.Value { return slog.StringValue("REDACTED") }

Code Explained

log.Lshortfile — add file:line to each line
slog.Info(msg, k, v, …) — alternating key-value pairs
NewJSONHandler — machine-readable output
logger.With(…) — attach attrs to every later record
LogValue — custom/redacted rendering

⚠ Common Mistakes

  • Odd number of key-value args: you get !BADKEY in the output (go vet checks this)
  • log.Fatal inside libraries or goroutines; it kills the process and skips defers
  • Logging secrets (tokens, passwords) as attributes; implement LogValuer

✓ Tips & Best Practices

  • Create one logger in main and pass it (or ctx) down; avoid globals in libraries
  • Use JSON in production, Text in local dev
  • Use slog.LevelVar to change log level at runtime

Quick Summary

  • log — simple timestamped lines
  • slog — structured, leveled logging
  • slog.With — contextual child loggers
  • JSONHandler / TextHandler — output format
