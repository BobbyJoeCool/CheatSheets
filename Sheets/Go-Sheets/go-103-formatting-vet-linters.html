Formatting, Vet & Linters

Go's tooling removes style debates: gofmt defines the format, goimports also manages imports, and go vet reports suspicious code like bad printf verbs or copied locks. staticcheck and the golangci-lint aggregator add hundreds more checks. go fix applies modernizers that rewrite code to newer idioms after a Go upgrade.

Notes

  • go vet runs automatically (a subset) during go test
  • gopls shows vet/staticcheck diagnostics in the editor
  • Go 1.27 gofmt alignment changed slightly; reformat after upgrading
  • govulncheck reports only vulnerabilities your code actually reaches

Tooling Commands

gofmt -l .                       # list unformatted files
gofmt -w .                       # rewrite in place
gofmt -s -w .                    # also simplify code
go install golang.org/x/tools/cmd/goimports@latest
goimports -w .                   # format + fix imports

go vet ./...                     # standard analyzers
go vet -printf=false ./...       # disable one analyzer

go install honnef.co/go/tools/cmd/staticcheck@latest
staticcheck ./...

golangci-lint run ./...          # many linters, config in .golangci.yml
golangci-lint run --fix

go fix ./...                     # modernizers (min/max, any, b.Loop…)
govulncheck ./...                # known CVEs on reachable code
go mod tidy -diff                # fail CI if go.mod is untidy

Code Explained

gofmt -l — use in CI to fail on unformatted code
goimports — add/remove imports + format
go vet — fast, no false-positive-heavy checks
golangci-lint — runs staticcheck, errcheck, revive…
go fix — automated modernization

⚠ Common Mistakes

  • Disabling linters globally instead of one //nolint:name // reason on a line
  • Running gofmt in CI but not goimports, causing import-order churn
  • Treating every staticcheck suggestion as optional; many are real bugs

✓ Tips & Best Practices

  • Configure editor format-on-save with gopls (gofumpt option for stricter style)
  • Pin golangci-lint's version in CI for reproducible results
  • Run go fix ./... right after bumping the go line in go.mod

Quick Summary

  • go vet — built-in static checks
  • staticcheck / golangci-lint — deeper linting
