Build Tags & Cross-Compiling

Go cross-compiles by setting GOOS and GOARCH; no extra toolchain is needed for pure-Go code. Build constraints (//go:build lines and _os_arch.go filename suffixes) include or exclude files per platform or custom tag. -ldflags -X injects values like a version string at link time.

Notes

  • //go:build must be the first line(s), before package, followed by a blank line
  • Filename suffixes: _linux.go, _windows_amd64.go, _test.go
  • CGO_ENABLED=0 → fully static binary, easy to ship in scratch containers
  • go tool dist list prints every supported GOOS/GOARCH

Constraints

//go:build linux && amd64      ← must be line 1

package sys

var version = "dev"            // set via -ldflags -X

// other constraint expressions:
//   //go:build !windows       all but Windows
//   //go:build integration    only with -tags integration
//   //go:build go1.27         only on Go ≥ 1.27
//   //go:build (linux || darwin) && !cgo

//go:generate stringer -type=Color

Build Commands

GOOS=windows GOARCH=amd64 go build -o app.exe .
GOOS=darwin GOARCH=arm64 go build -o app-mac .
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build .

go build -tags integration ./...
go test -tags integration ./...

go build -trimpath \
  -ldflags "-s -w -X main.version=v1.4.0" .

go generate ./...              # run //go:generate
go version -m ./app            # embedded build info

⚠ Common Mistakes

  • Missing the blank line after //go:build and package; the line is treated as a doc comment
  • -X main.Version=… on a const or a non-string var; it silently does nothing
  • Cross-compiling with cgo enabled and getting "C compiler not found"

✓ Tips & Best Practices

  • Read build info at runtime with debug.ReadBuildInfo() (VCS revision, module versions)
  • Use GoReleaser to build, archive and publish multi-platform binaries
  • Gate slow tests behind //go:build integration

Quick Summary

  • GOOS / GOARCH — cross-compile
  • //go:build expr — file constraints
  • -ldflags -X — inject version strings
  • CGO_ENABLED=0 — static binaries
