Methods & Receivers

Methods

A method is a function with a receiver: func (u User) Name() string. A value receiver gets a copy; a pointer receiver (u *User) can modify the original and avoids copying. Go automatically takes the address or dereferences when you call a method, so u.SetName(…) works on an addressable value even with a pointer receiver.

Choosing a Receiver

  • Pointer receiver if the method mutates, or the struct is large
  • Pointer receiver if the type holds a sync.Mutex (never copy it)
  • Be consistent: if any method needs *T, use *T for all
  • Receiver names are short (u, s), never this or self

Value vs Pointer Receivers

type Counter struct{ n int }

func (c Counter) Value() int { return c.n }  // value receiver
func (c *Counter) Inc()      { c.n++ }       // pointer receiver

var c Counter
c.Inc()                  // Go rewrites to (&c).Inc()
c.Inc()
fmt.Println(c.Value())   // 2

p := &Counter{}
p.Inc()                  // pointer → pointer method
fmt.Println(p.Value())   // 1: (*p).Value() automatically

func (c Counter) Broken() { c.n = 100 } // modifies a copy only

type Celsius float64                      // any defined type
func (t Celsius) String() string { return fmt.Sprintf("%.1f°C", t) }
fmt.Println(Celsius(21.5))               // 21.5°C

// Counter{}.Inc()       // error: can't take address of literal

Code Explained

(c Counter) — receives a copy
(c *Counter) — operates on the original
c.Inc() — auto &c because c is addressable
Broken — changes vanish when it returns
methods work on any defined type, not just structs

Coming From…

  • Java / Python — no this / self; receiver is named
  • C++ — pointer receiver ≈ non-const method
  • Python — methods declared outside the struct

⚠ Common Mistakes

  • A setter with a value receiver; the change is applied to a copy and lost
  • Calling a pointer method on a map element: m[k].Inc() doesn't compile (not addressable)
  • Copying a struct that contains a sync.Mutex via a value receiver (go vet copylocks)

✓ Tips & Best Practices

  • Default to pointer receivers for structs with behavior; value receivers for small immutable types
  • Implement String() string for readable fmt output
  • Store *T in maps (map[K]*T) when you need to call mutating methods on entries

Quick Summary

  • func (r T) M() — value receiver
  • func (r *T) M() — pointer receiver, can mutate
  • auto & / * on calls
  • consistency — pick one receiver kind per type
