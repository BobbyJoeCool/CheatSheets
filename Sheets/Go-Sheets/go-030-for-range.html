for range

for range iterates over arrays, slices, strings, maps, channels, integers and iterator functions. It yields one or two values depending on the type. The value variable is a copy of the element, so assigning to it doesn't change the collection; use the index to modify in place.

Notes

  • Map iteration order is randomized on purpose
  • Strings range over runes, with byte indexes
  • The range expression is evaluated once before the loop
  • Ranging over a nil slice or map runs zero times

Ranging Over Everything

nums := []int{10, 20, 30}
for i, v := range nums { fmt.Print(i, ":", v, " ") }
for i := range nums { nums[i] *= 2 }   // modify in place
for _, v := range nums { v++ }  // no effect: v is a copy

ages := map[string]int{"ann": 30, "bo": 25}
for name, age := range ages {          // random order
    fmt.Println(name, age)
}

for i, r := range "hé!" { fmt.Print(i, string(r)) } //0h1é3!

ch := make(chan int)
go func() { ch <- 1; ch <- 2; close(ch) }()
for v := range ch { fmt.Print(v) }     // 12, ends on close

for i := range 3 { fmt.Print(i) }      // 012 (Go 1.22)

for i, v := range slices.Backward(nums) { // iterator (1.23)
    fmt.Print(i, v, " ")                // 2 60 1 40 0 20
}

Code Explained

i, v — index and copy of element
for i := range s — index only; write s[i] to modify
maps — key, value; order differs between runs
channels — one value; loop ends when channel is closed
functions — any iter.Seq / iter.Seq2 (sheet 054)

Coming From…

  • Python — for i, v := range s ≈ enumerate(s)
  • JS — like for…of, but yields index + value
  • Java — enhanced for; v is a copy, not a reference

⚠ Common Mistakes

  • Taking &v in the loop to store pointers; each points to a copy. Use &s[i]
  • Depending on map order in tests or output; sort the keys (sheet 050)
  • Ranging over a channel nobody closes; the loop blocks forever

✓ Tips & Best Practices

  • Use slices.Sorted(maps.Keys(m)) for deterministic map iteration
  • For large structs, range by index to avoid copying each element
  • Deleting map entries during range is safe; adding may or may not be visited

Quick Summary

  • for i, v := range s — index + copy
  • maps — random order
  • strings — runes; channels — until closed
  • range n, range iter — ints & iterators
