Functional Options & Function Patterns

type Option func(Server) · WithTimeout(d) Option · NewServer(addr, opts...) · config-struct alternative · decorator / middleware wrapping · recursion (no tail-call optimization) · callback hooks

Functional Options

Go has no default or named arguments, so configurable constructors use the functional options pattern: each option is a function that modifies a config struct, and the constructor takes them as a variadic list. Callers pass only what they need, and new options can be added without breaking anyone. A plain config struct is the simpler alternative.

Related Patterns

  • Decorator — wrap a func/handler to add behavior
  • Callback hooks — func fields called at lifecycle points
  • Recursion works normally; Go has no tail-call optimization
  • Deep recursion grows the goroutine stack (up to 1 GB)

Options & Decorators

type Server struct{ addr string; timeout time.Duration }
type Option func(*Server)

func WithTimeout(d time.Duration) Option {
    return func(s *Server) { s.timeout = d }
}

func NewServer(addr string, opts ...Option) *Server {
    s := &Server{addr: addr, timeout: 30 * time.Second}
    for _, opt := range opts { opt(s) }   // apply in order
    return s
}
srv := NewServer(":8080", WithTimeout(5*time.Second))

func timed(f func()) func() {             // decorator
    return func() { t := time.Now(); f(); log.Println(time.Since(t)) }
}

func fact(n int) int {                    // recursion
    if n <= 1 { return 1 }
    return n * fact(n-1)
}

Code Explained

type Option func(*Server) — each option mutates the config
defaults set first, then options override them
opts ...Option — zero or more options
timed(f) — returns a wrapped function
fact — base case first; each call adds a stack frame

⚠ Common Mistakes

  • Options that can't report errors; return func(*S) error if validation is needed
  • Deep recursion on untrusted input (e.g. nested JSON) without a depth limit
  • Exporting the config fields and also offering options; pick one style

✓ Tips & Best Practices

  • Start with a config struct; switch to options when defaults get complex
  • Name options WithXxx so they read well at the call site
  • Convert hot recursive functions to loops with an explicit stack

Quick Summary

  • type Option func(*T) — option type
  • New(req, opts ...Option) — constructor
  • decorators — funcs returning wrapped funcs
  • recursion — fine, but no TCO
