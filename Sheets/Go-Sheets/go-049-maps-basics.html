Maps — Basics

map[string]int{} · make(map[K]V, hint) · m[k] = v · comma-ok v, ok := m[k] · delete(m, k) · clear(m) · random iteration order · writing to a nil map panics

Maps

A map is a built-in hash table from keys to values: map[K]V. Keys must be comparable (no slices, maps or funcs). Reading a missing key returns the zero value, so use the comma-ok form to tell "missing" from "zero". Maps are reference-like: passing one to a function shares the same data.

Notes

  • Zero value nil map: reads OK, writes panic
  • Iteration order is randomized every run
  • clear(m) empties a map (Go 1.21)
  • Maps aren't safe for concurrent writes; you'll get a fatal error

Map Basics

ages := map[string]int{"ann": 31, "bo": 25}  // literal
scores := make(map[string]int, 100)          // size hint

ages["cy"] = 40                  // insert / update
fmt.Println(ages["ann"])         // 31
fmt.Println(ages["zed"])         // 0 (missing → zero value)

age, ok := ages["zed"]           // comma-ok: 0 false

delete(ages, "bo")               // no-op if missing
fmt.Println(len(ages))           // 2

for name, age := range ages {    // random order
    fmt.Println(name, age)
}

counts := map[string]int{}
for _, w := range words { counts[w]++ }  // zero value helps

clear(ages)                      // empty, keeps allocation
var m map[string]int             // nil
// m["x"] = 1                    // panic: assignment to nil map

Code Explained

make(map[K]V, n) — hint avoids rehashing
missing key — returns 0, "", nil…
v, ok := m[k] — ok is false if absent
counts[w]++ — works because missing reads as 0
clear(m) — remove all entries (1.21)

Coming From…

  • Python — map ≈ dict; missing key returns zero, no KeyError
  • JS — map ≈ Map/object; v, ok := m[k] ≈ has + get
  • Java — ≈ HashMap; iteration order is random

⚠ Common Mistakes

  • Declaring var m map[K]V and writing to it without make
  • Treating a zero value as "present"; use comma-ok when zero is a valid value
  • Writing from several goroutines without a mutex: fatal error: concurrent map writes

✓ Tips & Best Practices

  • Use struct keys for composite lookups: map[Point]bool
  • Use map[K][]V + append for grouping; missing keys start as nil slices
  • Protect shared maps with sync.Mutex / RWMutex (or sync.Map for special cases)

Quick Summary

  • map[K]V — hash table, comparable keys
  • v, ok := m[k] — presence check
  • delete / clear — remove
  • nil map — write panics; random order
