strconv

String ↔ Value Conversion

strconv converts between strings and numbers or booleans. Parse functions return (value, error): the error is a *strconv.NumError whose Err is strconv.ErrSyntax (not a number) or strconv.ErrRange (too big). Format functions never fail. Append* variants write into an existing []byte.

Arguments

  • base — 2-36, or 0 to detect 0x, 0o, 0b prefixes
  • bitSize — 8/16/32/64 range check; result is still int64
  • Float format byte: 'f' decimal, 'e' scientific, 'g' compact
  • Precision -1 means shortest that round-trips

Parse & Format

n, err := strconv.Atoi("42")             // 42 <nil>
_, err = strconv.Atoi("4x")
fmt.Println(err) // …parsing "4x": invalid syntax

i, _ := strconv.ParseInt("-ff", 16, 64)  // -255
h, _ := strconv.ParseInt("0x1F", 0, 64)  // 31 (prefix)
u, _ := strconv.ParseUint("255", 10, 8)  // 255
_, err = strconv.ParseInt("300", 10, 8)  // out of range
f, _ := strconv.ParseFloat("3.14", 64)   // 3.14
b, _ := strconv.ParseBool("t")           // true

strconv.Itoa(-7)                         // "-7"
strconv.FormatInt(255, 2)                // "11111111"
strconv.FormatFloat(3.14159, 'f', 2, 64) // "3.14"
strconv.FormatFloat(1e21, 'g', -1, 64)   // "1e+21"
strconv.Quote("hi\n")                    // "\"hi\\n\""
strconv.Unquote(`"a\tb"`)                // "a	b" <nil>
buf := strconv.AppendInt(nil, 42, 10)    // []byte("42")
if errors.Is(err, strconv.ErrRange) { /* too big */ }

Code Explained

Atoi — shorthand for ParseInt(s, 10, 0) → int
base 0 — honors 0x, 0o, 0b and _ separators
bitSize 8 — rejects values that don't fit int8
FormatFloat(x, 'f', 2, 64) — fixed 2 decimals
errors.Is(err, strconv.ErrRange) — classify failures

Coming From…

  • Python — int(s) → strconv.Atoi + error check
  • JS — parseInt never throws; Go returns an error
  • Java — Integer.parseInt throws; Go returns err

⚠ Common Mistakes

  • Ignoring the parse error: n, _ := strconv.Atoi(input) silently gives 0 on bad input
  • Using fmt.Sprint(n) in hot paths; strconv.Itoa is several times faster
  • Passing bitSize 32 and storing straight into int32 without converting the int64 result

✓ Tips & Best Practices

  • Trim input first: strconv.Atoi(strings.TrimSpace(s))
  • Use strconv.Append* with a reusable buffer to avoid allocations
  • Use strconv.Quote for safely printing untrusted strings in logs
