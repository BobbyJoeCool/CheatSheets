any & Type Assertions

any is an alias for interface{}, the interface with no methods, which every type satisfies. To get a concrete value back out you use a type assertion x.(T), which panics on mismatch unless you use the two-result comma-ok form. A type switch checks several types at once.

Notes

  • Asserting to an interface type checks for those methods
  • In a type switch with one type per case, v has that type
  • With several types in a case, v keeps the interface type
  • Prefer generics (sheet 062) over any when types are known

Assertions & Type Switches

var x any = "hello"

s := x.(string)              // "hello"
n, ok := x.(int)             // 0 false: no panic
// n := x.(int)              // panic: interface conversion

func describe(v any) string {
    switch t := v.(type) {
    case nil:
        return "nil"
    case int, int64:
        return fmt.Sprintf("integer %v", t) // t is any here
    case string:
        return "string of len " + strconv.Itoa(len(t))
    case error:
        return "error: " + t.Error()
    case fmt.Stringer:
        return t.String()
    default:
        return fmt.Sprintf("other %T", t)
    }
}

if w, ok := r.(io.WriterTo); ok { w.WriteTo(dst) } // optional capability

Code Explained

x.(string) — returns the string or panics
v, ok := x.(T) — safe form
switch t := v.(type) — t is typed per case
case int, int64 — t stays any
asserting to io.WriterTo — detect optional methods

⚠ Common Mistakes

  • Single-result assertion on untrusted input; one unexpected type crashes the program
  • Type-switching on many concrete types where an interface method would be cleaner
  • Using errors type switches instead of errors.As, which misses wrapped errors

✓ Tips & Best Practices

  • Use %T to discover a value's dynamic type while debugging
  • Check for optional interfaces (io.WriterTo, http.Flusher) with comma-ok
  • Keep any at the edges (decoding); convert to concrete types quickly

Quick Summary

  • any — interface{}, holds anything
  • x.(T) — assert, panics on mismatch
  • v, ok := x.(T) — safe assert
