bool and the Zero Value

bool holds true or false, and Go has no truthiness: an int, string or pointer can't stand in for a condition. Every type has a zero value that a variable gets when declared without an initializer. Good Go types are designed so their zero value is immediately useful, like sync.Mutex, bytes.Buffer and strings.Builder.

Notes

  • Conditions must be bool: write if n != 0, not if n
  • No bool ↔ int conversion; use if b { n = 1 }
  • nil is the zero value for pointers, slices, maps, channels, funcs, interfaces
  • Reading a nil map or ranging over a nil slice is fine; writing to a nil map panics

Zero Values in Action

var (
    i  int            // 0
    f  float64        // 0
    s  string         // "" (empty, not nil)
    b  bool           // false
    p  *int           // nil
    sl []int          // nil, len 0
    m  map[string]int // nil
    e  error          // nil
)
fmt.Println(len(sl), sl == nil)  // 0 true
sl = append(sl, 1)               // append to nil slice: OK
fmt.Println(m["x"])              // 0: reading nil map OK
// m["x"] = 1                    // panic: nil map write

var buf bytes.Buffer             // ready to use
buf.WriteString("hi")
var mu sync.Mutex                // unlocked, ready to use
mu.Lock(); mu.Unlock()

ok := len(s) == 0 && !b          // true

Code Explained

Every declared variable has a defined value, no garbage memory
string zero value is "", never nil
append on a nil slice allocates as needed
Nil map reads return the element zero value; writes panic
bytes.Buffer, sync.Mutex work without constructors

⚠ Common Mistakes

  • if count { … } from C/Python habits: "non-boolean condition in if statement"
  • Writing to a map declared with var m map[K]V; initialize with make or a literal first
  • Checking s == nil for a string; strings can't be nil, check s == ""

✓ Tips & Best Practices

  • Design structs so the zero value works (no required Init() call)
  • Return nil slices for "no results"; len() and range handle them
  • Name booleans as questions: isReady, hasNext, ok

Quick Summary

  • bool — true / false, no truthiness
  • zero values — 0, false, "", nil
  • nil map — read OK, write panics
  • useful zero value — bytes.Buffer, sync.Mutex
