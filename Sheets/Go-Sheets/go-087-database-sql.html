database/sql

database/sql is a driver-agnostic API over a connection pool. You import a driver for its side effect (_ "github.com/jackc/pgx/v5/stdlib"), open a *sql.DB once, and share it everywhere. Always use placeholders for parameters, always Close rows, and pass a context so queries can be canceled.

Notes

  • sql.Open doesn't connect; call db.PingContext to verify
  • *sql.DB is safe for concurrent use; don't open one per request
  • QueryRow returns sql.ErrNoRows from Scan if nothing matched

Query, Exec, Transactions

db, err := sql.Open("pgx", os.Getenv("DATABASE_URL")) // check err, then:
defer db.Close()
db.SetMaxOpenConns(20); db.SetConnMaxIdleTime(5 * time.Minute)

var name string
err = db.QueryRowContext(ctx, "SELECT name FROM users WHERE id=$1", 7).
    Scan(&name)
if errors.Is(err, sql.ErrNoRows) { return ErrNotFound }

rows, err := db.QueryContext(ctx, "SELECT id, email FROM users")
if err != nil { return err }
defer rows.Close()
for rows.Next() {
    var id int; var email sql.Null[string]   // nullable
    if err := rows.Scan(&id, &email); err != nil { return err }
}
if err := rows.Err(); err != nil { return err }

res, err := db.ExecContext(ctx, "DELETE FROM users WHERE id=$1", 7)
n, _ := res.RowsAffected()

tx, err := db.BeginTx(ctx, nil)
defer tx.Rollback()                       // no-op after Commit
tx.ExecContext(ctx, "INSERT INTO audit(msg) VALUES ($1)", "x")
err = tx.Commit()

Code Explained

sql.Open("pgx", dsn) — driver name + data source
QueryRowContext(…).Scan — single row
defer rows.Close() + rows.Err() — always both
ExecContext — INSERT/UPDATE/DELETE
defer tx.Rollback() — safe even after Commit

⚠ Common Mistakes

  • Forgetting rows.Close(); connections leak until the pool is exhausted
  • Skipping rows.Err(); network errors mid-iteration look like "fewer rows"
  • Scanning a NULL into a plain string: "converting NULL to string is unsupported"

✓ Tips & Best Practices

  • Wrap sql.ErrNoRows into your own ErrNotFound at the repository layer
  • Use Prepare for statements executed many times in a loop
  • Keep transactions short and always pass ctx

Quick Summary

  • sql.Open once — pooled *sql.DB
  • QueryRow / Query / Exec (+Context)
  • rows.Close + rows.Err — every time
  • BeginTx + defer Rollback + Commit
