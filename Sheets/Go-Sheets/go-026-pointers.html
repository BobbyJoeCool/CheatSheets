Pointers

A pointer holds the address of a value. &x takes an address, *p reads or writes through it, and *T is the pointer type. Go has no pointer arithmetic and is garbage collected, so returning a pointer to a local variable is safe: the compiler moves it to the heap if needed (escape analysis).

Notes

  • Zero value is nil; dereferencing nil panics
  • p.Field auto-dereferences struct pointers (no ->)
  • new(T) allocates a zeroed T; Go 1.26 also allows new(expr)
  • Use pointers to mutate a caller's value or avoid copying big structs

Pointer Basics

x := 10
p := &x              // p is *int
fmt.Println(*p)      // 10
*p = 20              // write through the pointer
fmt.Println(x)       // 20

func double(n *int) { *n *= 2 }
double(&x)           // x is now 40

type User struct{ Name string }
u := &User{Name: "Ann"}  // pointer to composite literal
u.Name = "Bo"            // same as (*u).Name

q := new(int)        // *int → 0
r := new(42)         // *int → 42 (Go 1.26)
s := new(time.Now()) // *time.Time (1.26)

var np *User
// fmt.Println(np.Name) // panic: nil pointer dereference
if np != nil { fmt.Println(np.Name) }

func newCounter() *int { c := 0; return &c } // safe

Code Explained

&x — address of x; *p — value at p
double(&x) — pass a pointer to let the callee modify x
u.Name — automatic dereference for struct fields
new(expr) — allocate and initialize in one step (1.26)
&c escaping — the GC keeps c alive

Coming From…

  • C — no pointer arithmetic; returning &local is safe
  • Java / Python — explicit pointers decide sharing vs copying
  • C++ — p.Field auto-derefs; no ->

⚠ Common Mistakes

  • Dereferencing a pointer that may be nil (e.g. a failed lookup result) without checking
  • Taking pointers to maps or slices to "pass by reference"; they already share data
  • Returning &s[i] and then appending to s; the pointer may refer to the old backing array

✓ Tips & Best Practices

  • Prefer values by default; reach for pointers for mutation or large structs
  • Use new(expr) (1.26) for optional fields: Port: new(8080)
  • Run go build -gcflags=-m to see which variables escape to the heap

Quick Summary

  • &x / *p — address-of / dereference
  • *T — pointer type; zero value nil
  • new(T) / new(expr) — allocate
  • no pointer arithmetic; escaping is safe
