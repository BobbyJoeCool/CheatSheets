for Loops

three-clause for i := 0; i < n; i++ · while-style for cond · infinite for { } · per-iteration loop variables (1.22) · multiple vars i, j := 0, n-1 · for range 10 (1.22)

for: Go's Only Loop

Go has a single loop keyword, for, used in three shapes: the classic three-clause loop, a condition-only loop (Go's while), and an infinite loop. Since Go 1.22 each iteration gets a fresh copy of the loop variable, which fixed the classic closure-capture bug. for range n counts from 0 to n-1.

Notes

  • No parentheses; braces required
  • Any clause may be omitted: for ; i < n; {
  • No while or do-while keywords
  • Loop variables are per-iteration from Go 1.22 (module go ≥ 1.22)

Loop Shapes

for i := 0; i < 3; i++ {          // classic
    fmt.Print(i, " ")             // 0 1 2
}

n := 1
for n < 100 {                     // while-style
    n *= 2
}                                 // n == 128

for {                             // infinite
    line, err := r.ReadString('\n')
    if err != nil { break }
    process(line)
}

for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
    s[i], s[j] = s[j], s[i]       // reverse in place
}

for i := range 5 { fmt.Print(i) } // 01234 (Go 1.22)
for range 3 { fmt.Print("hi ") }  // hi hi hi

Code Explained

for init; cond; post — the C-style form
for cond — runs while cond is true
for {} — exit with break or return
i, j := 0, n-1 — parallel assignment in the clauses
range 5 — integers 0-4, no variable needed with for range

Coming From…

  • C / Java — no while / do; for cond {} instead
  • Python — for i := range 5 ≈ for i in range(5)
  • JS — loop vars are per-iteration (since 1.22), like let

⚠ Common Mistakes

  • Modifying the slice length inside a three-clause loop over it; recompute bounds carefully
  • Relying on per-iteration variables in a module whose go.mod says go 1.21 or older
  • Busy-waiting with for !done {}; use channels, sync.WaitGroup or a Ticker

✓ Tips & Best Practices

  • Use for range n for simple repetition
  • Name nested loop labels (outer:) when you need to break out of both
  • Prefer for range over index loops unless you need the index arithmetic

Quick Summary

  • for init; cond; post — classic
  • for cond — while
  • for {} — forever
  • for range n — count (1.22)
