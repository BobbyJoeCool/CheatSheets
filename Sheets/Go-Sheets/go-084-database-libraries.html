Database Libraries

Go's database/sql (sheet 087) is low-level. Popular libraries sit on top or beside it: pgx is the native PostgreSQL driver with pooling and rich types; sqlx adds struct scanning to database/sql; sqlc generates type-safe Go from SQL queries; GORM is a full ORM. Migrations are usually handled by goose or golang-migrate.

Choosing

  • Like writing SQL? sqlc or sqlx
  • PostgreSQL only? use pgx directly (pgxpool)
  • Want an ORM with associations? GORM
  • Always use placeholders, never string-built SQL

Four Approaches

// pgx (github.com/jackc/pgx/v5)
pool, _ := pgxpool.New(ctx, os.Getenv("DATABASE_URL"))
rows, _ := pool.Query(ctx, "SELECT id, name FROM users WHERE age > $1", 18)
users, err := pgx.CollectRows(rows, pgx.RowToStructByName[User])

// sqlx (github.com/jmoiron/sqlx)
db := sqlx.MustConnect("postgres", dsn)
var u User                                   // `db:"name"` tags
err = db.Get(&u, "SELECT * FROM users WHERE id = $1", 7)
var all []User
err = db.Select(&all, "SELECT * FROM users ORDER BY id")

// sqlc: write SQL, generate Go
// -- name: GetUser :one
// SELECT * FROM users WHERE id = $1;
q := db.New(pool)
user, err := q.GetUser(ctx, 7)               // generated, typed

// GORM (gorm.io/gorm)
gdb, _ := gorm.Open(postgres.Open(dsn), &gorm.Config{})
gdb.Create(&User{Name: "Ann"})
gdb.Where("age > ?", 18).Order("name").Find(&all)

Code Explained

pgxpool — concurrent connection pool
RowToStructByName — map columns to fields
db.Get / db.Select — one row / many rows
sqlc — compile-time checked queries
GORM — chainable query builder + models

Coming From…

  • Python — GORM ≈ SQLAlchemy ORM
  • Python — sqlx ≈ raw SQL with row mapping
  • Java — sqlc ≈ jOOQ codegen; GORM ≈ Hibernate

⚠ Common Mistakes

  • Building SQL with fmt.Sprintf and user input: SQL injection
  • Relying on GORM AutoMigrate in production instead of versioned migrations
  • Mixing ? and $1 placeholders; Postgres needs $1, MySQL ?

✓ Tips & Best Practices

  • sqlc + pgx is a strong default for Postgres services
  • Pass ctx to every query so requests can cancel slow work
  • Embed migration files with //go:embed and run them at startup

Quick Summary

  • pgx — native Postgres, pooling
  • sqlx — struct scanning
  • sqlc — SQL → typed Go
  • GORM — ORM; goose/migrate — migrations
