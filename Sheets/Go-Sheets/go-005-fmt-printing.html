Printing with fmt

fmt.Println / Print / Printf · Sprintf / Sprint / Sprintln · Fprintf(os.Stderr, …) · fmt.Appendf · println builtin (debug only) · fmt vs log

The fmt Package

fmt handles formatted I/O. Functions come in families by destination: Print* writes to stdout, Sprint* returns a string, Fprint* writes to any io.Writer, and Append* appends to a byte slice. Within each family, the plain form joins operands, …ln adds spaces and a newline, and …f takes a format string.

Spacing Rules

  • Println — always a space between operands + trailing newline
  • Print — adds spaces only between operands when neither is a string
  • Printf — no newline unless you write \n
  • All return (n int, err error); usually ignored for stdout

Print Family

name, n := "Go", 3
fmt.Print("a", "b", 1, 2)           // ab1 2
fmt.Println("a", "b", 1, 2)         // a b 1 2
fmt.Printf("%s has %d\n", name, n)  // Go has 3

s := fmt.Sprintf("%05.1f", 3.14159) // "003.1"
msg := fmt.Sprint("x=", 42)         // "x=42"

fmt.Fprintln(os.Stderr, "warning!") // to stderr
fmt.Fprintf(w, "<h1>%s</h1>", name) // any io.Writer

buf := []byte("log: ")
buf = fmt.Appendf(buf, "%d items", n) // "log: 3 items"

err := fmt.Errorf("open %q: %w", "a.txt", os.ErrNotExist)
fmt.Println(err)  // open "a.txt": file does not exist

println("debug", n)                 // builtin → stderr

Code Explained

Sprintf — build a string; the workhorse for messages
Fprint* — any io.Writer: files, buffers, HTTP responses
Appendf — append to []byte for zero-extra-allocation logging
Errorf — formatted errors; %w wraps another error
println — builtin, unstable output format; never in real code

Coming From…

  • Python — print() ≈ fmt.Println; f-strings ≈ Sprintf
  • C — printf verbs, but %v prints anything
  • JS — console.log ≈ fmt.Println (no objects auto-expanded)

⚠ Common Mistakes

  • fmt.Println("x = %d", x) prints the verb literally; formatting needs Printf
  • Forgetting \n with Printf, so the next output lands on the same line
  • Building strings in a loop with Sprintf + +; use strings.Builder (sheet 020)

✓ Tips & Best Practices

  • Run go vet: it checks Printf verbs against argument types
  • Use %v when unsure and %+v on structs to see field names
  • Write to os.Stderr for errors so piping stdout stays clean

Quick Summary

  • Print / Println / Printf — stdout
  • Sprintf — format to a string
  • Fprintf(w, …) — format to any writer
  • Errorf("…: %w", err) — wrap an error
