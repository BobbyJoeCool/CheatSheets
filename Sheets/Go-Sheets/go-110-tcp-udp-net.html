TCP, UDP & the net Package

Below HTTP, the net package provides TCP and UDP sockets. A TCP server calls net.Listen, then Accepts connections in a loop and handles each in its own goroutine. Clients use net.Dial / DialTimeout. A net.Conn is an io.Reader + io.Writer, so bufio, io.Copy and encoders all work on it.

Notes

  • Set deadlines (SetDeadline) or a stalled peer blocks forever
  • net/netip (1.18) has small, comparable Addr / AddrPort types
  • net.Dialer{Timeout, KeepAlive} for fine-grained control
  • Network names: "tcp", "tcp4", "udp", "unix"

TCP Echo Server & Client

ln, err := net.Listen("tcp", ":9000")
if err != nil { log.Fatal(err) }
for {
    conn, err := ln.Accept()
    if err != nil { continue }
    go func(c net.Conn) {                      // one goroutine per conn
        defer c.Close()
        c.SetDeadline(time.Now().Add(time.Minute))
        sc := bufio.NewScanner(c)
        for sc.Scan() { fmt.Fprintf(c, "echo: %s
", sc.Text()) }
    }(conn)
}

conn, err := net.DialTimeout("tcp", "localhost:9000", 3*time.Second)
fmt.Fprintln(conn, "hello")
reply, _ := bufio.NewReader(conn).ReadString('
') // echo: hello

pc, _ := net.ListenPacket("udp", ":9001")       // UDP
n, addr, _ := pc.ReadFrom(buf); pc.WriteTo(buf[:n], addr)
ap := netip.MustParseAddrPort("10.0.0.1:443")  // ap.Addr(), ap.Port()

Code Explained

Accept loop — handle each connection concurrently
SetDeadline — absolute time limit for reads + writes
bufio.Scanner over conn — line-based protocol
ListenPacket / ReadFrom / WriteTo — UDP datagrams
netip — value-type IP addresses

⚠ Common Mistakes

  • Handling connections inline in the Accept loop; one slow client blocks all others
  • No deadlines on connections; idle or malicious peers leak goroutines
  • Assuming one Read returns one full message; TCP is a byte stream, frame your protocol

✓ Tips & Best Practices

  • Use net.JoinHostPort to build addresses (handles IPv6 brackets)
  • Prefix messages with a length (binary.BigEndian) to frame them
  • Prefer HTTP/gRPC unless you need a custom protocol

Quick Summary

  • net.Listen + Accept + go handle
  • net.Dial / DialTimeout — clients
  • SetDeadline — avoid hangs
  • ListenPacket — UDP; netip — addresses
