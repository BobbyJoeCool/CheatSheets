CSV, XML & Other Encodings

The encoding/* packages convert between Go values and common formats. encoding/csv reads and writes records as []string. encoding/xml works like json with struct tags. base64 and hex turn bytes into text, binary handles fixed-size binary layouts, and gob is Go-to-Go serialization.

Notes

  • CSV reader handles quoted fields and embedded commas
  • r.Comma = ';' or '\t' changes the delimiter
  • csv.Writer buffers: call Flush then check Error()
  • base64.URLEncoding is safe in URLs and filenames

Encoding Round-Trips

r := csv.NewReader(strings.NewReader("name,age\n\"Lee, Ann\",31\n"))
records, _ := r.ReadAll()          // [[name age] [Lee, Ann 31]]
for _, rec := range records[1:] { fmt.Println(rec[0]) } // Lee, Ann

w := csv.NewWriter(os.Stdout)
w.Write([]string{"id", "note"})
w.Write([]string{"1", `says "hi"`}) // 1,"says ""hi"""
w.Flush()
if err := w.Error(); err != nil { return err }

type Book struct {
    XMLName xml.Name `xml:"book"`
    ID      string   `xml:"id,attr"`
    Title   string   `xml:"title"`
}
out, _ := xml.Marshal(Book{ID: "7", Title: "Go"})
// <book id="7"><title>Go</title></book>

s := base64.StdEncoding.EncodeToString([]byte("hi?")) // aGk/
raw, _ := base64.StdEncoding.DecodeString(s)
hex.EncodeToString([]byte{0xde, 0xad})                // dead
buf := binary.BigEndian.AppendUint32(nil, 258)        // [0 0 1 2]

Code Explained

ReadAll — all records; use Read in a loop for big files
quoted fields — commas and quotes handled for you
w.Flush() + w.Error() — catch write failures
xml:"id,attr" — encode as an attribute
binary.BigEndian — fixed byte-order integers

Coming From…

  • Python — csv module ≈ encoding/csv
  • Python — base64.b64encode → base64.StdEncoding
  • Java — struct.pack ≈ encoding/binary

⚠ Common Mistakes

  • Splitting CSV lines with strings.Split(line, ","); quoted commas break it
  • Forgetting w.Flush() on csv.Writer, losing the last rows
  • Using gob for data other languages must read; it's Go-specific

✓ Tips & Best Practices

  • Stream big CSV files with r.Read() in a loop and r.ReuseRecord = true
  • Use base64.RawURLEncoding for tokens (no padding, URL-safe)
  • Third-party YAML/TOML: gopkg.in/yaml.v3, github.com/BurntSushi/toml

Quick Summary

  • csv — records as []string
  • xml — struct tags like JSON
  • base64 / hex — bytes ↔ text
  • binary / gob — binary formats
