os, exec & Signals

The os package exposes the process environment: arguments, environment variables, working directory, exit codes. os/exec runs external commands without a shell, and os/signal lets you react to Ctrl-C and SIGTERM, usually by canceling a context for a graceful shutdown.

Notes

  • os.Exit skips deferred functions
  • exec.Command does not use a shell: no globs, pipes or $VAR
  • exec.LookPath finds a binary on PATH
  • runtime.GOOS / GOARCH tell you the platform

Process & Environment

fmt.Println(os.Args[0], os.Args[1:])     // program, args
port := os.Getenv("PORT")                // "" if unset
if v, ok := os.LookupEnv("DEBUG"); ok { fmt.Println("debug:", v) }
os.Setenv("MODE", "test")
host, _ := os.Hostname()
wd, _ := os.Getwd()

out, err := exec.Command("git", "rev-parse", "HEAD").Output()
fmt.Println(strings.TrimSpace(string(out)))

cmd := exec.CommandContext(ctx, "ffmpeg", "-i", in, outFile)
cmd.Stdout, cmd.Stderr = os.Stdout, os.Stderr
cmd.Env = append(os.Environ(), "LANG=C")
if err := cmd.Run(); err != nil {
    var ee *exec.ExitError
    if errors.As(err, &ee) { fmt.Println("exit:", ee.ExitCode()) }
}

ctx, stop := signal.NotifyContext(context.Background(),
    os.Interrupt, syscall.SIGTERM)       // Ctrl-C / kill
defer stop()
<-ctx.Done()                             // wait, then clean up
fmt.Println(runtime.GOOS, runtime.NumCPU()) // darwin 10

Code Explained

os.LookupEnv — distinguishes unset from empty
Output() — run and capture stdout
CommandContext — kill the process when ctx is done
*exec.ExitError — non-zero exit details
signal.NotifyContext — ctx canceled on signal

Coming From…

  • Python — sys.argv → os.Args
  • Python — subprocess.run → exec.Command(...).Run
  • Node — process.on('SIGTERM') → signal.NotifyContext

⚠ Common Mistakes

  • exec.Command("ls *.go"): treats the whole string as the program name. Split args, glob in Go
  • Passing user input to exec.Command("sh", "-c", input): command injection
  • Calling os.Exit in library code; return an error instead

✓ Tips & Best Practices

  • Keep main as if err := run(); err != nil { fmt.Fprintln(os.Stderr, err); os.Exit(1) }
  • Use exec.CommandContext with a timeout for external tools
  • Read config from env with defaults: cmp.Or(os.Getenv("PORT"), "8080")

Quick Summary

  • os.Args / Getenv / LookupEnv — inputs
  • exec.Command(…).Output() — run programs
  • signal.NotifyContext — graceful shutdown
  • os.Exit(code) — skips defers
