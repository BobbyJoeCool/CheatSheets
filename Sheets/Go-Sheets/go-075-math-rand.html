math & math/rand/v2

math provides float functions and constants, while math/rand/v2 (Go 1.22) is the modern random package: it's auto-seeded, has clearer names (IntN), and offers a generic rand.N that works with any integer type, including time.Duration. For secrets (tokens, passwords) always use crypto/rand.

Notes

  • Top-level rand funcs are safe for concurrent use
  • Use rand.New(rand.NewPCG(s1, s2)) for reproducible sequences
  • crypto/rand.Text() (1.24) returns a secure random string
  • math/big handles arbitrary-precision ints, floats, rationals

Math & Randomness

math.Sqrt(16)          // 4
math.Pow(2, 8)         // 256
math.Abs(-3.2)         // 3.2
math.Mod(10, 3)        // 1
math.Max(3, 7)         // 7 (floats; use max() for ints)
math.Log(math.E)       // 1
math.Pi, math.MaxInt   // 3.14159… 9223372036854775807

rand.IntN(6) + 1                       // dice roll 1-6
rand.Float64()                         // [0.0, 1.0)
rand.N(5 * time.Second)                // random duration < 5s
rand.Shuffle(len(s), func(i, j int) { s[i], s[j] = s[j], s[i] })
rand.Perm(4)                           // e.g. [2 0 3 1]

r := rand.New(rand.NewPCG(1, 42))      // seeded: same each run
r.IntN(100)

token := cryptorand.Text()             // crypto/rand, 1.24
b := make([]byte, 32); cryptorand.Read(b)

f := new(big.Int).Exp(big.NewInt(2), big.NewInt(100), nil) // 2^100

Code Explained

math — float64 functions; ints need conversion
rand.IntN(n) — [0, n)
rand.N — generic over integer types
rand.NewPCG(…) — deterministic generator for tests/sims
cryptorand.Text() — secure token (import alias)

⚠ Common Mistakes

  • Generating session tokens or passwords with math/rand; it's predictable
  • rand.IntN(0) panics; guard against empty ranges
  • Using math.Max on ints with conversions; use the max builtin

✓ Tips & Best Practices

  • Seed a local generator in tests for reproducible randomized data
  • Add jitter to retries: base + rand.N(base/2)
  • Use big.Rat for exact fractions and big.Int for huge integers
