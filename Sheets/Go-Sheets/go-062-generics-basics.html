Generics

Since Go 1.18, functions and types can take type parameters in square brackets: func Map[T, U any](…). Each type parameter has a constraint (an interface) that limits which types are allowed. Callers rarely write type arguments because the compiler infers them from the arguments.

Notes

  • any allows every type; comparable allows == / map keys
  • var zero T gives a type parameter's zero value
  • Generic types must be instantiated: Stack[int]
  • Write generic code when the logic is identical across types

Generic Functions & Types

func Map[T, U any](xs []T, f func(T) U) []U {
    out := make([]U, 0, len(xs))
    for _, x := range xs { out = append(out, f(x)) }
    return out
}
lens := Map([]string{"go", "rust"}, strLen) // [2 4]; T, U inferred

func Index[T comparable](xs []T, v T) int {
    for i, x := range xs { if x == v { return i } }
    return -1
}

type Stack[T any] struct{ items []T }
func (s *Stack[T]) Push(v T) { s.items = append(s.items, v) }
func (s *Stack[T]) Pop() (T, bool) {
    var zero T
    if len(s.items) == 0 { return zero, false }
    v := s.items[len(s.items)-1]; s.items = s.items[:len(s.items)-1]
    return v, true
}
var st Stack[string]                     // instantiate
st.Push("a")

Code Explained

[T, U any] — two type parameters
type inference — no need to write Map[string, int]
comparable — required for x == v
Stack[T any] — generic struct type
var zero T — return a zero value of any T

Coming From…

  • Java — [T any] ≈ <T>; no type erasure
  • TS — generics look alike; constraints are interfaces
  • Python — ≈ TypeVar, but enforced

⚠ Common Mistakes

  • Making everything generic; if a plain interface works, it's simpler
  • func F[T any](a, b T) bool { return a == b } — any doesn't allow ==; use comparable
  • Expecting inference from return types alone; F[int]() must be explicit

✓ Tips & Best Practices

  • Check slices, maps, cmp first; they cover most generic helpers
  • Name type params T, K, V, E (element), S ~[]E (slice)
  • Benchmark hot paths; generic code is fast but not always identical to hand-written
