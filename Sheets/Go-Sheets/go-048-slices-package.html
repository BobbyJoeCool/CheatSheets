The slices Package

slices (Go 1.21) provides generic helpers for any slice type: searching, inserting, deleting, comparing and more. Functions that change length return the new slice, which you must assign. Since Go 1.22, Delete and Compact also zero the removed tail so the GC can free referenced objects.

Notes

  • …Func variants take a callback instead of ==
  • Insert, Delete, Compact, Grow return the updated slice
  • Sorting and binary search are on sheet 052
  • Iterator helpers: All, Values, Backward, Collect, Chunk (1.23)

Common Helpers

s := []int{3, 1, 4, 1, 5, 9}
slices.Contains(s, 4)                    // true
slices.Index(s, 1)                       // 1
slices.IndexFunc(s, func(n int) bool { return n > 4 }) // 4
slices.Max(s), slices.Min(s)             // 9 1

s = slices.Insert(s, 1, 7, 8)            // [3 7 8 1 4 1 5 9]
s = slices.Delete(s, 1, 3)               // [3 1 4 1 5 9]
s = slices.DeleteFunc(s, func(n int) bool { return n == 1 }) // [3 4 5 9]
s = slices.Replace(s, 0, 1, 30)          // [30 4 5 9]

slices.Reverse(s)                        // [9 5 4 30] in place
slices.Equal(s, []int{9, 5, 4, 30})      // true
d := slices.Compact([]int{1, 1, 2, 2, 1}) // [1 2 1]
all := slices.Concat([]int{1}, []int{2, 3}) // [1 2 3]
slices.Repeat([]string{"a"}, 3)          // [a a a]

for c := range slices.Chunk(all, 2) { fmt.Print(c) } // [1 2][3]
evens := slices.Collect(filterSeq(slices.Values(all))) // iter → slice

Code Explained

IndexFunc / ContainsFunc — predicate versions
Insert(s, i, v…) — shift and insert at index i
Delete(s, i, j) — remove s[i:j]
Compact — collapse consecutive duplicates
Chunk / Values / Collect — iterator bridges

Coming From…

  • JS — indexOf → slices.Index; reverse → Reverse
  • Java — ≈ Collections / List helpers

⚠ Common Mistakes

  • slices.Delete(s, i, i+1) without reassigning s; the length doesn't change
  • Using Compact to remove all duplicates; sort first (slices.Sort + Compact)
  • slices.Max on an empty slice panics; check len first

✓ Tips & Best Practices

  • Dedupe: slices.Sort(s); s = slices.Compact(s)
  • Use slices.ContainsFunc instead of hand-written found loops
  • Use slices.Grow(s, n) before a known number of appends
