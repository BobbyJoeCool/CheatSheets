Functions as Values

Functions are first-class values: you can assign them to variables, pass them as arguments, return them, and store them in maps or struct fields. A function type like func(int) bool describes a signature. Methods can be used as values too, either bound to a receiver (t.Method) or as an expression taking the receiver as its first argument (T.Method).

Notes

  • Zero value of a func type is nil; calling it panics
  • Funcs are only comparable to nil
  • Anonymous funcs (func(){}) can be called immediately
  • Defined func types can have methods (http.HandlerFunc)

First-Class Functions

type Predicate func(int) bool

func filter(xs []int, keep Predicate) []int {
    var out []int
    for _, x := range xs { if keep(x) { out = append(out, x) } }
    return out
}

isEven := func(n int) bool { return n%2 == 0 }
filter([]int{1, 2, 3, 4}, isEven)           // [2 4]

ops := map[string]func(a, b int) int{
    "+": func(a, b int) int { return a + b },
    "*": func(a, b int) int { return a * b },
}
ops["*"](3, 4)                              // 12

slices.SortFunc(users, func(a, b User) int {
    return cmp.Compare(a.Age, b.Age)
})
greet := user.Greet         // method value, bound to user
greet()
f := (*User).Greet          // method expression: f(&user)

Code Explained

type Predicate func(int) bool — named function type
keep(x) — call a function received as a value
map[string]func… — dispatch table
slices.SortFunc — callback returns -1/0/+1
user.Greet vs (*User).Greet — bound vs unbound

Coming From…

  • Java — no functional interfaces; func(int) bool is the type
  • C — function values, without pointer syntax

⚠ Common Mistakes

  • Calling an optional hook field without a nil check: if s.OnClose != nil { s.OnClose() }
  • Comparing two funcs with ==; only nil comparison compiles
  • Using func(…) params where a one-method interface would be clearer and mockable

✓ Tips & Best Practices

  • Give a function type a method to make it satisfy an interface (HandlerFunc pattern)
  • Pass strings.TrimSpace etc. directly; no wrapper lambda needed
  • Prefer slices / maps helpers that take funcs over hand-written loops

Quick Summary
