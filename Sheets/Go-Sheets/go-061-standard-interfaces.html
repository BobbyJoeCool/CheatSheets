Standard Library Interfaces

A handful of tiny interfaces glue the standard library together. Implement them on your types and they plug into fmt, io.Copy, json, sort, net/http and more for free. Recognizing them is one of the fastest ways to read idiomatic Go.

Notes

  • io.Reader / io.Writer connect files, sockets, buffers, hashes
  • String() is used by %v and %s; Error() wins over it
  • MarshalJSON / UnmarshalJSON customize JSON for a type

Implementing Stdlib Interfaces

type Level int
const (Debug Level = iota; Info; Warn)

var names = [...]string{"DEBUG", "INFO", "WARN"}
func (l Level) String() string { return names[l] } // fmt.Stringer
fmt.Println(Warn)                           // WARN

func (l Level) MarshalText() ([]byte, error) { // TextMarshaler
    return []byte(strings.ToLower(l.String())), nil
}
json.Marshal(map[string]Level{"lvl": Info}) // {"lvl":"info"}

type Upper struct{ w io.Writer }            // io.Writer wrapper
func (u Upper) Write(p []byte) (int, error) {
    return u.w.Write(bytes.ToUpper(p))
}
fmt.Fprintln(Upper{os.Stdout}, "shout")    // SHOUT

type Hello struct{}                         // http.Handler
func (Hello) ServeHTTP(w http.ResponseWriter, _ *http.Request) {
    io.WriteString(w, "hi")
}

Code Explained

String() — fmt prints WARN, not 2
MarshalText — JSON writes the text form
Upper — any io.Writer can be decorated
Fprintln(Upper{…}) — fmt accepts any writer
ServeHTTP — makes Hello an HTTP handler

⚠ Common Mistakes

  • String() that calls fmt.Sprintf("%v", t) on itself: infinite recursion. Convert to the underlying type first
  • Write returning n < len(p) without an error; callers treat that as a failure
  • Pointer-receiver String() used on values; fmt won't find it for T

✓ Tips & Best Practices

  • Use io.Copy, io.MultiWriter, io.TeeReader instead of manual loops
  • Prefer MarshalText over MarshalJSON for simple scalar types
  • Check var _ fmt.Stringer = Level(0) to lock in the implementation

Quick Summary

  • io.Reader / io.Writer — streaming glue
  • fmt.Stringer — custom printing
  • json.Marshaler / TextMarshaler — encoding
  • http.Handler — web servers
