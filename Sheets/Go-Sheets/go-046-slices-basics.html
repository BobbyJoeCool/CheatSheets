Slices

A slice is a dynamically sized view into an array and Go's main list type. It has a length (elements you can index) and a capacity (room before reallocating). append adds elements and returns the possibly new slice, so you must always assign its result. make([]T, len, cap) pre-allocates.

Notes

  • Zero value is nil: len 0, append and range work
  • Indexing beyond len panics even if cap is larger
  • s[low:high] excludes high; omitted bounds default to 0 and len
  • Slices aren't comparable; use slices.Equal

Slice Basics

s := []int{1, 2, 3}             // literal
var empty []string              // nil slice
buf := make([]byte, 0, 1024)    // len 0, cap 1024
grid := make([]int, 5)          // [0 0 0 0 0]

s = append(s, 4)                // [1 2 3 4]
s = append(s, 5, 6)             // variadic
s = append(s, []int{7, 8}...)   // append another slice

fmt.Println(len(s), cap(s))     // 8 8 (cap may vary)
fmt.Println(s[2:5])             // [3 4 5]
fmt.Println(s[:2], s[6:])       // [1 2] [7 8]
last := s[len(s)-1]             // 8

for i, v := range s { _ = i + v }

matrix := make([][]int, 3)      // 2D: slice of slices
for i := range matrix { matrix[i] = make([]int, 4) }

fmt.Println(empty == nil, len(empty)) // true 0

Code Explained

make([]T, len, cap) — pre-size to avoid growth copies
s = append(s, …) — always reassign
append(s, other...) — concatenate slices
s[2:5] — elements 2, 3, 4
2D — allocate each row separately

Coming From…

  • Python — slice ≈ list; append ≈ .append (reassign!)
  • JS — slice ≈ Array; s[a:b] ≈ .slice(a, b) but shared
  • Java — slice ≈ ArrayList

⚠ Common Mistakes

  • append(s, x) without assigning; the new element may be lost
  • make([]int, 10) then append, expecting 1 element; you get 11 (10 zeros + x)
  • Returning []T{} vs nil inconsistently; JSON encodes them as [] vs null

✓ Tips & Best Practices

  • When the final size is known, use make([]T, 0, n) + append
  • Prefer returning nil for "no results" unless JSON shape matters
  • Use the slices package for search, sort and modification (sheet 048)

Quick Summary

  • []T — dynamic view over an array
  • len / cap — size / room
  • s = append(s, x) — always reassign
  • make([]T, n, c) — pre-allocate
