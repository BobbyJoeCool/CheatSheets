panic & recover

panic stops normal execution, runs deferred calls up the stack, and crashes the program with a stack trace. It's for programmer errors and impossible states, not expected failures. recover() called inside a deferred function stops the panic and returns its value, letting a server keep running after one bad request.

Notes

  • recover() returns nil when not panicking or not called from a defer
  • A panic in another goroutine can't be recovered from main
  • Runtime panics: nil map write, index out of range, nil deref, bad assertion
  • Must… helpers (regexp.MustCompile) panic for init-time failures

Panic and Recovery

func mustPositive(n int) int {
    if n <= 0 { panic(fmt.Sprintf("bad n: %d", n)) }
    return n
}

func safeCall(f func()) (err error) {
    defer func() {
        if r := recover(); r != nil {      // stop the panic
            err = fmt.Errorf("recovered: %v", r)
        }
    }()
    f()
    return nil
}

err := safeCall(func() { var m map[string]int; m["x"] = 1 })
fmt.Println(err) // recovered: assignment to entry in nil map

var re = regexp.MustCompile(`^\d+$`) // panics at init if bad

Code Explained

panic(v) — any value; usually a string or error
recover() — only works directly inside a deferred func
named result err — the deferred func converts panic → error
Runtime errors are panics with a runtime.Error value
MustCompile — fail fast on a constant that must be valid

Coming From…

  • Java / Python — panic ≈ unchecked exception; rarely caught
  • Python — recover ≈ a top-level except in a deferred func
  • Rust — panic! ≈ Go panic

⚠ Common Mistakes

  • Using panic/recover as try/catch for normal control flow
  • Calling recover() in a helper called by the deferred func; it must be the deferred func itself
  • Starting goroutines without recovery in servers; one panic kills the whole process

✓ Tips & Best Practices

  • Recover at boundaries only: HTTP middleware, worker loops (net/http already recovers per request)
  • Log the stack with debug.Stack() when you recover
  • Re-panic (panic(r)) values you don't know how to handle

Quick Summary

  • panic(v) — unwinds, runs defers, crashes
  • recover() — only in a deferred func
  • errors for expected failures; panic for bugs
  • Must… — panic on invalid constants
