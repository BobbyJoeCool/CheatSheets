⚠ Common Mistakes

  • := in an inner block shadows outer vars (esp. err)
  • append without reassigning; writes to nil maps
  • Typed nil pointer returned as error is non-nil

✓ Tips & Best Practices

  • Run gofmt, go vet and -race on every change
  • Prefer slices / maps / cmp helpers to hand loops
  • Check the version tags: range n 1.22, iterators 1.23

Quick Summary

  • x := v / var x T — declare
  • for — the only loop; range everywhere
  • interfaces — implicit; generics — [T C]
  • errors — values, checked with if err != nil
