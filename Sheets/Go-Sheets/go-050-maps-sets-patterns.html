Map Patterns & Sets

The maps package adds cloning, comparison and iterators like maps.Keys. Go has no set type; the idiom is map[T]struct{} or map[T]bool. Iteration is random, so sort keys for stable output with slices.Sorted(maps.Keys(m)).

Notes

  • maps.Keys / maps.Values return iterators, not slices (1.23)
  • slices.Collect(maps.Keys(m)) builds a slice
  • struct{}{} uses no memory; bool reads more naturally
  • sync.Map suits write-once/read-many caches across goroutines

Patterns

m := map[string]int{"b": 2, "a": 1, "c": 3}
for _, k := range slices.Sorted(maps.Keys(m)) {
    fmt.Print(k, m[k], " ")              // a1 b2 c3
}
vals := slices.Collect(maps.Values(m))   // [2 1 3] any order

seen := map[string]struct{}{}            // set
seen["go"] = struct{}{}
_, has := seen["go"]                     // true

byLen := map[int][]string{}              // grouping
for _, w := range []string{"a", "bb", "cc"} {
    byLen[len(w)] = append(byLen[len(w)], w)
}                                        // {1:[a] 2:[bb cc]}

type key struct{ x, y int }              // composite key
grid := map[key]rune{{0, 0}: '#'}

c := maps.Clone(m)                       // shallow copy
maps.DeleteFunc(c, func(k string, v int) bool { return v > 1 })
maps.Copy(c, map[string]int{"z": 26})    // merge into c

Code Explained

slices.Sorted(maps.Keys(m)) — deterministic order
map[T]struct{} — set with zero-size values
append(byLen[n], w) — nil slice for new keys works
map[key]rune{{0, 0}: '#'} — struct key literal
Clone / Equal / DeleteFunc / Copy — helpers

Coming From…

  • Python — no set; use map[T]struct{}
  • Python — defaultdict(list) ≈ append(m[k], v)
  • Java — HashSet ≈ map[T]bool

⚠ Common Mistakes

  • Expecting maps.Keys to return []K; wrap it in slices.Collect or slices.Sorted
  • Assuming maps.Clone deep-copies; nested slices/maps are shared
  • Using sync.Map as a general concurrent map; a mutex + map is usually faster and typed

✓ Tips & Best Practices

  • Sort keys before printing or hashing maps to get stable output and tests
  • Use map[T]bool when if set[x] readability beats the tiny memory savings
  • Consider golang.org/x/exp/maps-free code: the stdlib now covers most needs

Quick Summary

  • maps.Keys/Values/All — iterators
  • slices.Sorted(maps.Keys(m)) — ordered keys
  • map[T]struct{} — set
  • map[K][]V — grouping
