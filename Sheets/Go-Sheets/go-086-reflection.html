Reflection

The reflect package inspects types and values at runtime: it's how encoding/json, fmt and ORMs work. reflect.TypeOf describes a type (name, fields, tags); reflect.ValueOf wraps a value you can read and, if it's addressable, set. Reflection is slow and loses compile-time safety, so use it only for generic infrastructure.

Laws of Reflection

  • Interface value → reflection object (ValueOf)
  • Reflection object → interface value (v.Interface())
  • To modify, the value must be settable: pass a pointer + Elem()
  • Kind is the category (Struct, Ptr…); Type is the exact type

Inspecting Structs

type User struct {
    Name  string `json:"name" validate:"required"`
    Age   int    `json:"age"`
    email string
}

u := User{Name: "Ann", Age: 31}
t := reflect.TypeOf(u)
fmt.Println(t.Name(), t.Kind(), t.NumField()) // User struct 3

for i := range t.NumField() {
    f := t.Field(i)
    fmt.Println(f.Name, f.Type, f.Tag.Get("json"), f.IsExported())
}   // Name string name true / Age int age true / email string  false

v := reflect.ValueOf(&u).Elem()               // settable
v.FieldByName("Age").SetInt(32)
fmt.Println(u.Age, v.CanSet())                // 32 true

rt := reflect.TypeFor[map[string]int]()       // 1.22, no value needed
fmt.Println(rt.Key(), rt.Elem())              // string int
reflect.DeepEqual([]int{1}, []int{1})         // true

Code Explained

TypeOf(u) — type metadata
f.Tag.Get("json") — read struct tags
ValueOf(&u).Elem() — addressable, so fields can be set
SetInt — panics if not settable or wrong kind
reflect.TypeFor[T]() — type without a value (1.22)

Coming From…

  • Java — reflect ≈ java.lang.reflect
  • Python — ≈ getattr / type(), but much stricter
  • C# — ≈ System.Reflection; struct tags ≈ attributes

⚠ Common Mistakes

  • Setting fields on reflect.ValueOf(u) (a copy): panic: using unaddressable value
  • Calling Field(i).Interface() on an unexported field: panics
  • Using reflection where generics or an interface would be type-safe and faster

✓ Tips & Best Practices

  • Cache reflect.Type field info per type when processing many values
  • Check Kind() before calling kind-specific methods
  • Prefer reflect.TypeFor[T]() over reflect.TypeOf((*T)(nil)).Elem()

Quick Summary

  • TypeOf / ValueOf — inspect
  • Tag.Get — struct tag metadata
  • pointer + Elem() — settable values
  • slow & unsafe — use sparingly
