UTF-8 and Runes

Go source and strings are UTF-8, where one character (rune) takes 1-4 bytes. for range over a string decodes runes and yields each rune's starting byte index. Converting to []rune gives random access by character at the cost of a copy.

Notes

  • range yields (byteIndex, rune), so indexes skip by 1-4
  • Invalid bytes decode as utf8.RuneError (U+FFFD, �)
  • []rune(s) allocates 4 bytes per character
  • Grapheme clusters (e.g. 👍🏽) can span several runes

Bytes vs Runes

s := "héllo"
fmt.Println(len(s))                    // 6 bytes
fmt.Println(utf8.RuneCountInString(s)) // 5 runes

for i, r := range s {
    fmt.Printf("%d:%c ", i, r) // 0:h 1:é 3:l 4:l 5:o
}

r := []rune(s)
fmt.Println(string(r[1]))              // é
fmt.Println(string(r[1:3]))            // él

ch, size := utf8.DecodeRuneInString(s[1:])
fmt.Println(string(ch), size)          // é 2

bad := "a\xffb"
fmt.Println(utf8.ValidString(bad))     // false
fmt.Println(strings.ToValidUTF8(bad, "?")) // a?b
for _, r := range bad { fmt.Print(r, " ") } // 97 65533 98

Code Explained

RuneCountInString — character count without allocating
range s — index 3 follows 1 because é is 2 bytes
[]rune(s) — index by character position
DecodeRuneInString — decode one rune + its byte size
65533 — U+FFFD, the replacement for invalid bytes

Coming From…

  • Python — for ch in s ≈ for _, r := range s
  • JS — [...s] ≈ []rune(s)
  • Java — no surrogate pairs; runes are whole code points

⚠ Common Mistakes

  • Reversing a string byte-by-byte; multi-byte characters get scrambled. Reverse a []rune
  • Truncating with s[:10] for display; it can cut a character in half
  • Assuming the range index counts characters; it's a byte offset

✓ Tips & Best Practices

  • Truncate safely: string([]rune(s)[:n]) (after checking length)
  • Validate external input with utf8.ValidString before storing it
  • Use golang.org/x/text/unicode/norm to compare accented text reliably

Quick Summary

  • range s — decodes runes, index is bytes
  • utf8.RuneCountInString — character count
  • []rune(s) — character-indexed copy
  • U+FFFD — marker for invalid UTF-8
