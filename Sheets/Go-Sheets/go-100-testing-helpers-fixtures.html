Test Helpers & Fixtures

The testing.T type has helpers that make tests clean and isolated: t.Helper fixes failure line numbers, t.Cleanup registers teardown, t.TempDir / t.Setenv / t.Chdir provide auto-reverted fixtures, and t.Context (1.24) gives a context canceled at test end. httptest tests HTTP handlers and clients without a real network.

Notes

  • t.Parallel() runs a test alongside other parallel tests
  • t.Setenv can't be used with t.Parallel
  • TestMain(m *testing.M) runs package-wide setup/teardown
  • Golden files: compare output with testdata/*.golden, update with a flag

Helpers in Action

func newTestDB(t *testing.T) *DB {
    t.Helper()                          // errors point at the caller
    db, err := Open(filepath.Join(t.TempDir(), "test.db"))
    if err != nil { t.Fatalf("open: %v", err) }
    t.Cleanup(func() { db.Close() })    // runs after the test
    return db
}

func TestHandler(t *testing.T) {
    t.Setenv("MODE", "test")            // restored; not with Parallel
    req := httptest.NewRequest("GET", "/users/7", nil)
    rec := httptest.NewRecorder()
    NewServer(newTestDB(t)).ServeHTTP(rec, req)
    if rec.Code != http.StatusOK { t.Fatalf("status %d", rec.Code) }
}

func TestClient(t *testing.T) {
    srv := httptest.NewServer(okHandler)  // any http.Handler
    defer srv.Close()
    got, err := Fetch(t.Context(), srv.URL)  // t.Context: 1.24
}

Code Explained

t.Helper() — report failures at the caller's line
t.TempDir() — unique dir, removed automatically
t.Cleanup — LIFO teardown, even on failure
NewRecorder — capture a handler's response
NewServer — real local HTTP server for client tests

⚠ Common Mistakes

  • Forgetting t.Helper() in helpers, so every failure points inside the helper
  • Using defer in a helper for cleanup; it runs when the helper returns. Use t.Cleanup
  • Hitting real external services in unit tests; use httptest.NewServer

✓ Tips & Best Practices

  • Return cleanup-free fixtures from helpers by registering t.Cleanup inside them
  • Add -update flag handling for golden files: var update = flag.Bool("update", false, "")
  • Use TestMain sparingly (e.g. starting one container for the whole package)

Quick Summary

  • t.Helper / t.Cleanup — clean helpers
  • t.TempDir / Setenv / Chdir — fixtures
  • t.Context — test-scoped ctx (1.24)
