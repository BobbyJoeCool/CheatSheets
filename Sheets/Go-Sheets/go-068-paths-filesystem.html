Paths & Directories

Use path/filepath for operating-system paths (it uses \ on Windows) and path only for slash-separated paths like URLs. The os package handles directory creation, listing, stat and removal. Go 1.24's os.Root opens a directory and blocks any access that escapes it, which prevents path-traversal bugs.

Notes

  • filepath.Join cleans .. and duplicate separators
  • os.ReadDir returns entries sorted by name
  • WalkDir is faster than the older Walk (no extra Stat)
  • os.UserHomeDir(), os.UserConfigDir() for per-user paths

Filesystem Operations

p := filepath.Join("data", "2026", "report.csv")  // data/2026/report.csv
filepath.Base(p)               // report.csv
filepath.Dir(p)                // data/2026
filepath.Ext(p)                // .csv
abs, _ := filepath.Abs(p)      // /home/me/app/data/2026/report.csv
rel, _ := filepath.Rel("data", p) // 2026/report.csv

info, err := os.Stat(p)
if errors.Is(err, fs.ErrNotExist) { /* missing */ }
fmt.Println(info.Size(), info.IsDir(), info.ModTime())

os.MkdirAll("out/logs", 0o755)
entries, _ := os.ReadDir(".")
for _, e := range entries { fmt.Println(e.Name(), e.IsDir()) }

filepath.WalkDir(".", func(path string, d fs.DirEntry, err error) error {
    if err != nil { return err }
    if d.IsDir() && d.Name() == ".git" { return filepath.SkipDir }
    if filepath.Ext(path) == ".go" { fmt.Println(path) }
    return nil
})
matches, _ := filepath.Glob("*.json")
root, _ := os.OpenRoot("uploads")  // 1.24: can't escape dir
f, err := root.Open("../etc/passwd") // error: escapes root

Code Explained

filepath.Join — OS separator, cleaned result
os.Stat + fs.ErrNotExist — existence check
os.MkdirAll — like mkdir -p
filepath.SkipDir — prune a directory in WalkDir
os.OpenRoot — safe access to user-supplied paths

⚠ Common Mistakes

  • Building paths with + "/" +; breaks on Windows and doesn't clean ..
  • Joining user input to a base dir and trusting it; ../ escapes. Use os.Root or check with filepath.IsLocal
  • Using path.Join for file paths (always /)

✓ Tips & Best Practices

  • Use filepath.IsLocal(p) (1.20) to validate relative paths from users
  • Prefer os.ReadDir / WalkDir over the older ioutil / Walk APIs
  • Use t.TempDir() in tests; it's cleaned up automatically

Quick Summary

  • path/filepath — OS paths
  • os.Stat / ReadDir / MkdirAll — fs ops
  • filepath.WalkDir — recursive walk
  • os.Root — confined access (1.24)
