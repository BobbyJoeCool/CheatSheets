Atomic Operations

sync/atomic performs lock-free reads and writes on single values. The typed wrappers (atomic.Int64, atomic.Bool, atomic.Pointer[T]) added in Go 1.19 are the preferred API: they can't be accessed non-atomically by accident and are correctly aligned. Use atomics for counters, flags and swapping immutable snapshots; use a mutex when several values must change together.

Notes

  • Every access to an atomic must be atomic (no mixing with plain reads)
  • CompareAndSwap is the building block of lock-free updates
  • atomic.Pointer[T] swaps whole immutable structs (config reload)
  • go fix modernizer atomictypes (1.27) migrates old calls

Typed Atomics

var requests atomic.Int64
requests.Add(1)                       // safe from many goroutines
fmt.Println(requests.Load())          // 1

var ready atomic.Bool; ready.Store(true)
old := hits.Swap(0)                   // read + reset (atomic.Uint32)

var state atomic.Int32
if state.CompareAndSwap(0, 1) {       // only one winner
    start()
}

type Config struct{ Limit int }
var cfg atomic.Pointer[Config]
cfg.Store(&Config{Limit: 10})
go func() { cfg.Store(&Config{Limit: 20}) }() // hot reload
limit := cfg.Load().Limit             // readers never block

var n int64
atomic.AddInt64(&n, 1)                // old func style; prefer types

Code Explained

atomic.Int64 — methods Add, Load, Store, Swap, CAS
atomic.Bool — lock-free flag
Swap — set and return the previous value
CompareAndSwap(old, new) — succeed only if unchanged
atomic.Pointer[T] — publish new immutable snapshots

⚠ Common Mistakes

  • Mixing atomic.AddInt64(&n, 1) with plain n++ elsewhere: data race
  • Check-then-act with Load then Store instead of CompareAndSwap
  • Mutating the struct behind an atomic.Pointer instead of storing a new one

✓ Tips & Best Practices

  • Prefer typed atomics over the function API
  • Expose metrics counters as atomic.Int64 fields
  • Benchmark: under low contention a mutex is often just as fast and clearer

Quick Summary

  • atomic.Int64 etc. — lock-free values
  • Add / Load / Store / Swap
  • CompareAndSwap — conditional update
  • atomic.Pointer[T] — swap snapshots
