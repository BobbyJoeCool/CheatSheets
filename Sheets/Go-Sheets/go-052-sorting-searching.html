Sorting & Searching

slices.Sort sorts any ordered type in place, and slices.SortFunc takes a comparison function returning negative, zero or positive, usually built with cmp.Compare. Neither is stable; use SortStableFunc to keep equal elements in order. slices.BinarySearch finds items in sorted slices in O(log n).

Notes

  • cmp.Compare(a, b) → -1 / 0 / +1 for ordered types
  • cmp.Or chains comparisons for multi-key sorts
  • Reverse order: swap arguments, cmp.Compare(b, a)
  • The older sort package (sort.Slice) still works but is slower

Sort & Search

nums := []int{5, 2, 8, 1}
slices.Sort(nums)                       // [1 2 5 8]
i, found := slices.BinarySearch(nums, 5) // 2 true
i, found = slices.BinarySearch(nums, 4)  // 2 false (insert pos)

type P struct{ Name string; Age int }
people := []P{{"Bo", 30}, {"Ann", 25}, {"Cy", 30}}

slices.SortFunc(people, func(a, b P) int {
    return cmp.Compare(a.Age, b.Age)      // by age asc
})
slices.SortStableFunc(people, func(a, b P) int {
    return cmp.Or(
        cmp.Compare(b.Age, a.Age),        // age desc, then
        strings.Compare(a.Name, b.Name),  // name asc
    )
})
j, ok := slices.BinarySearchFunc(people, 25, func(p P, t int) int {
    return cmp.Compare(p.Age, t)
})
slices.IsSorted(nums)                   // true

Code Explained

BinarySearch — index + found; index is the insert point
cmp.Compare(a.Age, b.Age) — ascending
cmp.Or(…) — first non-zero comparison wins
SortStableFunc — equal keys keep their order
sort.Slice — legacy, less func on indexes

Coming From…

  • Python — key= → cmp.Compare func returning -1/0/1
  • Java — Comparator ≈ slices.SortFunc callback
  • JS — sort((a,b)=>a-b) ≈ SortFunc, but typed

⚠ Common Mistakes

  • Returning a.Age < b.Age (bool) from a SortFunc comparator; it must return an int
  • Binary-searching an unsorted slice; results are meaningless
  • Subtracting for comparisons (a - b) on large ints; overflow flips the sign. Use cmp.Compare

✓ Tips & Best Practices

  • Sort a copy when the caller's order matters: slices.Sorted(slices.Values(s))
  • Use strings.Compare / cmp.Compare + cmp.Or for readable multi-key sorts
  • Keep data sorted on insert with BinarySearch + slices.Insert for small sets

Quick Summary

  • slices.Sort / SortFunc — sort in place
  • cmp.Compare + cmp.Or — comparators
  • SortStableFunc — stable order
  • BinarySearch — sorted lookup
