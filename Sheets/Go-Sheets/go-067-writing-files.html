Writing Files

os.WriteFile(name, data, 0o644) · os.Create · os.OpenFile with O_APPEND|O_CREATE|O_WRONLY · bufio.Writer + Flush · fmt.Fprintf(f, …) · f.Sync · check the Close error · atomic write via temp + os.Rename

Writing Files

os.WriteFile writes a whole byte slice in one call, creating or truncating the file. For streaming output, os.Create or os.OpenFile returns an *os.File; wrap it in bufio.Writer for many small writes and remember to Flush. The error from Close matters for writes, since buffered data can fail to land on disk.

Permissions & Flags

  • 0o644 — owner rw, others r (typical files)
  • 0o755 — dirs and executables; 0o600 — secrets
  • Permissions are filtered by the process umask
  • Combine flags with |: os.O_APPEND|os.O_CREATE|os.O_WRONLY

Writing Patterns

err := os.WriteFile("out.txt", []byte("hello\n"), 0o644)

f, err := os.OpenFile("app.log",
    os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)   // append
if err != nil { return err }
defer f.Close()
fmt.Fprintf(f, "%s started\n", time.Now().Format(time.RFC3339))

func writeReport(path string, rows []Row) (err error) {
    f, err := os.Create(path)                      // truncate
    if err != nil { return err }
    defer func() { err = errors.Join(err, f.Close()) }()
    w := bufio.NewWriter(f)
    for _, r := range rows { fmt.Fprintln(w, r) }
    return w.Flush()                               // don't forget
}

tmp, _ := os.CreateTemp(dir, "cfg-*.tmp")          // atomic write
tmp.Write(data); tmp.Sync(); tmp.Close()
os.Rename(tmp.Name(), filepath.Join(dir, "cfg.json"))

Code Explained

os.WriteFile — create/truncate + write + close
O_APPEND|O_CREATE|O_WRONLY — append, creating if needed
errors.Join(err, f.Close()) — keep the close error
w.Flush() — push buffered data to the file
temp + Sync + Rename — readers never see half a file

Coming From…

  • Python — open(p, 'a') → O_APPEND|O_CREATE|O_WRONLY
  • Java — BufferedWriter → bufio.Writer + Flush
  • Node — fs.writeFileSync → os.WriteFile

⚠ Common Mistakes

  • Forgetting bufio.Writer.Flush(): the end of the file is silently missing
  • Ignoring Close() errors on written files (full disk, NFS errors)
  • Using 0644 permissions for files containing secrets; use 0o600

✓ Tips & Best Practices

  • Write atomically with temp file + os.Rename (same directory/filesystem)
  • Use os.MkdirAll(dir, 0o755) before writing into nested paths
  • Return w.Flush() as the last statement so its error isn't lost

Quick Summary

  • os.WriteFile — one-shot write
  • os.Create / os.OpenFile — streaming
  • bufio.Writer + Flush — fast small writes
  • check Close — write errors surface there
