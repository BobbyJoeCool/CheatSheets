Variadic Functions

Variadic Functions

A final parameter written ...T accepts zero or more arguments of type T, which arrive in the function as a []T. Callers can pass individual values or spread an existing slice with s.... When you spread, the function receives the caller's slice itself, not a copy.

Notes

  • Only the last parameter can be variadic
  • With no arguments the parameter is a nil slice
  • ...any accepts mixed types (like fmt.Println)
  • You can't mix loose args and a spread: f(1, s...) is invalid

Variadic Examples

func sum(nums ...int) int {
    total := 0
    for _, n := range nums { total += n }
    return total
}

sum()                       // 0 (nums is nil)
sum(1, 2, 3)                // 6
xs := []int{4, 5}
sum(xs...)                  // 9: spread a slice

func logf(level string, format string, args ...any) {
    fmt.Printf("["+level+"] "+format+"\n", args...) // forward
}
logf("INFO", "%s has %d items", "cart", 3)

all := append([]int{1}, xs...)   // append is variadic too

func zero(s ...int) { s[0] = 0 }
zero(xs...)                 // xs is now [0 5]: same array!

Code Explained

nums ...int — nums is []int inside the function
sum() — valid; loop over a nil slice does nothing
xs... — pass the slice as the variadic param
args... — forward variadic args to another variadic func
zero(xs...) — spread slices are shared, not copied

Coming From…

  • Python — ...int ≈ *args; f(s...) ≈ f(*s)
  • JS — ...rest and spread, same idea
  • Java — int... nums is nearly identical

⚠ Common Mistakes

  • Forgetting ... when forwarding: fmt.Printf(format, args) prints [a b] as one value
  • Mutating a variadic slice and surprising a caller who spread their slice
  • Using ...any where a typed ...T would catch mistakes at compile time

✓ Tips & Best Practices

  • Require at least one value with func max(first int, rest ...int)
  • Copy with slices.Clone(s) before mutating a variadic argument
  • go vet checks ...any printf-style wrappers if the name ends in f

Quick Summary

  • ...T — last param, arrives as []T
  • f(s...) — spread a slice
  • spread — shares the caller's array
  • args... — forward to another variadic
