Integers

int / uint (platform size) · int8…int64 · uint8…uint64 · uintptr · literals 0x 0b 0o 1_000_000 · wraparound overflow · math.MaxInt64 / MinInt64

Integer Types

Go has sized signed (int8…int64) and unsigned (uint8…uint64) integers plus int and uint, which are 64 bits on 64-bit platforms. Integer overflow is well defined: values wrap around silently. Different integer types never mix in one expression without an explicit conversion, even int and int64.

Integer Notes

  • int is the default for counts, indexes and len() results
  • byte = uint8, rune = int32 (aliases, see sheet 015)
  • uintptr holds a pointer as an integer (unsafe code only)
  • Integer division by a constant zero is a compile error; by a variable, a runtime panic

Literals, Limits & Overflow

dec := 1_000_000          // underscores for readability
hex := 0xFF               // 255
oct := 0o755              // 493 (0755 also works)
bin := 0b1010             // 10

var small int8 = 127
small++                   // -128: wraps around
var u uint8 = 0
u--                       // 255

fmt.Println(math.MaxInt64)  // 9223372036854775807
fmt.Println(math.MinInt64)  // -9223372036854775808
fmt.Println(math.MaxUint32) // 4294967295
fmt.Println(strconv.IntSize) // 64 (bits in int)

var a int32 = 5
var b int64 = 10
// c := a + b             // error: mismatched types
c := int64(a) + b         // 15

Code Explained

1_000_000 — digit separators, also in hex/binary
0o755 — explicit octal prefix (clearer than 0755)
small++ past 127 — wraps to -128, no panic
math.MaxInt64 etc. — limits as untyped constants
Mixed types need conversion: int64(a) + b

Coming From…

  • Python — ints are fixed-size and wrap; no bigints by default
  • Java — unsigned types exist; int is 64-bit on 64-bit
  • JS — real integers, not floats

⚠ Common Mistakes

  • Using uint for sizes to "prevent negatives"; len(s) - 1 on an empty slice then wraps to a huge number
  • Assuming overflow panics; it silently wraps, so validate before arithmetic on untrusted input
  • Writing 0755 and reading it as decimal 755; prefer 0o755

✓ Tips & Best Practices

  • Default to int; pick sized types only for binary formats, protocols or memory layout
  • Use math/bits.Add64 / Mul64 when you need to detect overflow (carry out)
  • Use math/big for arbitrary-precision integers (crypto, factorials)

Quick Summary

  • int — 64-bit default integer
  • int8…int64, uint8…uint64 — sized types
  • overflow — wraps, no error
  • mixed types — convert explicitly
