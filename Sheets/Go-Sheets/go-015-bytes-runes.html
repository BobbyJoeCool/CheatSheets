Sheet 015

Bytes & Runes

byte = uint8 · rune = int32 · rune literals 'a' '\n' 'é' · unicode.IsLetter / IsDigit / ToUpper · utf8.RuneLen · utf8.RuneError · Unicode 17 (1.27)

byte and rune

A byte is an alias for uint8 and represents one byte of raw data. A rune is an alias for int32 and represents one Unicode code point. Go strings are UTF-8, so one character can be 1-4 bytes. Rune literals use single quotes, 'a', and are just integers. The unicode and unicode/utf8 packages classify and encode runes.

Notes

  • 'a' is a rune (int32 97); "a" is a string
  • utf8.RuneError (U+FFFD) marks invalid UTF-8
  • unicode tables track Unicode 17 as of Go 1.27
  • Arithmetic works: 'a' + 1 == 'b'

Working with Runes

var b byte = 'A'               // 65
r := 'é'                       // rune 233 (U+00E9)
fmt.Printf("%c %d %U\n", r, r, r) // é 233 U+00E9
fmt.Println(string(r + 1))     // ê

fmt.Println(utf8.RuneLen('a'))  // 1
fmt.Println(utf8.RuneLen('é'))  // 2
fmt.Println(utf8.RuneLen('世')) // 3
fmt.Println(utf8.RuneLen('🚀')) // 4

unicode.IsLetter('x')          // true
unicode.IsDigit('7')           // true
unicode.IsSpace('\t')          // true
unicode.IsUpper('Q')           // true
unicode.ToUpper('ß')           // 7838 'ẞ'

digit := '7' - '0'             // 7 (int32)
esc := []rune{'\n', '\'', '\x41', '\u00e9'}

Code Explained

%c / %U — print a rune as a character / code point
utf8.RuneLen — bytes needed to encode a rune
unicode.Is… — Unicode-aware classification
'7' - '0' — classic digit-to-number trick
'\x41', '\u00e9' — hex and Unicode escapes

Coming From…

  • Java / C# — char is 16-bit; Go rune is a full code point
  • Python — no char type; 'a' here is an int
  • C — byte ≈ unsigned char

⚠ Common Mistakes

  • Treating len("é") as 1; it's 2 bytes. Count runes with utf8.RuneCountInString
  • Using byte to hold characters from user input; non-ASCII text breaks
  • string(b) on a single byte above 127 gives a Unicode char, not the raw byte

✓ Tips & Best Practices

  • Iterate with for _, r := range s to get runes, not bytes
  • Use unicode.SimpleFold or strings.EqualFold for case-insensitive comparisons
  • Use golang.org/x/text for normalization (é vs e + ◌́)

Quick Summary

  • byte — uint8, raw data
  • rune — int32, one code point
  • 'x' — rune literal; "x" — string
  • unicode / utf8 — classify and encode
