Format Verbs

Format strings use % verbs like C's printf, but Go adds generic verbs: %v prints any value in a default format, %+v adds struct field names, and %#v prints Go syntax. Width, precision and flags go between % and the verb. A wrong verb never crashes; it prints %!d(string=hi) instead, and go vet catches it.

Flags

  • - left-align · 0 zero-pad · + always sign · (space) pad for sign
  • # alternate form: 0x for hex, Go syntax for %#v
  • * width/precision from an argument: %*d
  • %[2]d explicit argument index

Verbs in Action

type P struct{ X, Y int }
p := P{1, 2}
fmt.Printf("%v", p)        // {1 2}
fmt.Printf("%+v", p)       // {X:1 Y:2}
fmt.Printf("%#v", p)       // main.P{X:1, Y:2}
fmt.Printf("%T", p)        // main.P
fmt.Printf("%d %b %o", 255, 5, 8)   // 255 101 10
fmt.Printf("%x %X %#x", 255, 255, 255) // ff FF 0xff
fmt.Printf("%.2f %e", 3.14159, 1234.5) // 3.14 1.234500e+03
fmt.Printf("%g %g", 0.000012, 100.0)   // 1.2e-05 100
fmt.Printf("%s %q %c", "go", "go", 'G') // go "go" G
fmt.Printf("[%6d][%-6d]", 42, 42)   // [    42][42    ]
fmt.Printf("[%06d][%+d]", 42, 42)   // [000042][+42]
fmt.Printf("[%8.3f]", 3.14159)      // [   3.142]
fmt.Printf("[%*d]", 5, 7)           // [    7]
fmt.Printf("%t %p", true, &p)       // true 0xc000012345
fmt.Printf("%d%%", 50)              // 50%
fmt.Printf("%d", "hi")              // %!d(string=hi)

Code Explained

%v — default format for any type; maps print sorted by key
%T — the dynamic type, great for debugging any values
%q — quoted, escaped string; also works on runes
%8.3f — width 8, 3 decimals; %-8s left-aligns
%!d(…) — bad verb/arg pair reported inline, not a panic

Coming From…

  • C — same %d %s %x, plus %v, %T, %q
  • Python — {:>8.2f} ≈ %8.2f
  • Java — String.format ≈ fmt.Sprintf

⚠ Common Mistakes

  • Using %s on an int; you get %!s(int=5), use %d or %v
  • %.3s truncates bytes, which can split a multi-byte UTF-8 character
  • Passing a pointer to %v and expecting the value; structs print as &{…}, other pointers as an address

✓ Tips & Best Practices

  • Implement String() string on a type and %v / %s will use it
  • Use %q in error messages so empty strings and spaces are visible: ""
  • %#v is a quick way to dump a value as copy-pasteable Go code

Quick Summary

  • %v / %+v / %#v — default / fields / Go syntax
  • %d %x %f %s %q — the everyday verbs
  • %-8s %08d %.2f — width, padding, precision
  • go vet — catches verb/argument mismatches
