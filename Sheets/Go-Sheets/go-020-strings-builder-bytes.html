Building Strings Efficiently

strings.Builder accumulates text in a growing byte buffer and produces the final string without an extra copy. bytes.Buffer is the read/write cousin for []byte data. The bytes package mirrors nearly every strings function for []byte, so you can process raw data without converting.

Notes

  • Zero values are ready: var b strings.Builder
  • Never copy a non-empty Builder (it panics); pass *strings.Builder
  • Both implement io.Writer, so fmt.Fprintf(&b, …) works
  • strings.NewReader(s) turns a string into an io.Reader

Builder & Buffer

var b strings.Builder
b.Grow(64)                         // optional: pre-size
for i := 1; i <= 3; i++ {
    fmt.Fprintf(&b, "item%d,", i)  // io.Writer
}
b.WriteString("done")
b.WriteByte('!')
b.WriteRune('✓')
fmt.Println(b.String())  // item1,item2,item3,done!✓

var buf bytes.Buffer
buf.WriteString("hello ")
buf.Write([]byte("world"))
line, _ := buf.ReadString(' ')     // "hello " (consumes it)
fmt.Println(line, buf.String())    // hello  world

data := []byte("  Go,Rust  ")
bytes.TrimSpace(data)              // []byte("Go,Rust")
bytes.Equal([]byte("a"), []byte("a")) // true
r := strings.NewReader("streamed text") // io.Reader

Code Explained

Grow(n) — reserve capacity to avoid re-allocations
Fprintf(&b, …) — formatted writes into the builder
b.String() — no copy: returns the internal bytes
bytes.Buffer — supports both writing and reading
bytes.* — strings equivalents for []byte

Coming From…

  • Java — StringBuilder ≈ strings.Builder
  • Python — ''.join(parts) ≈ strings.Join
  • C# — MemoryStream ≈ bytes.Buffer

⚠ Common Mistakes

  • Copying a strings.Builder by value after writing: "illegal use of non-zero Builder copied by value"
  • Calling buf.String() on bytes.Buffer repeatedly in a loop; each call copies
  • Converting []byte → string → []byte just to call a strings func; use the bytes version

✓ Tips & Best Practices

  • Call Grow when you can estimate the final size
  • Use bytes.Buffer as an in-memory io.Reader/io.Writer in tests
  • strings.Builder is not goroutine-safe; build per goroutine and join
