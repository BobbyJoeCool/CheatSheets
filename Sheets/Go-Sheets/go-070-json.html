JSON

encoding/json maps JSON to Go values using struct tags to rename fields and control omission. Only exported fields are encoded. Go 1.24 added omitzero, and Go 1.27 ships encoding/json/v2 and jsontext: the v1 package now runs on the v2 engine, v2 rejects invalid UTF-8 and duplicate keys by default, and unmarshaling is much faster.

Notes

  • omitempty skips 0, "", false, nil, empty slices/maps
  • omitzero (1.24) skips zero values, incl. time.Time{} structs
  • Unknown JSON fields are ignored unless you call DisallowUnknownFields
  • Numbers decode into float64 when the target is any

Encode & Decode

type User struct {
    ID      int       `json:"id"`
    Name    string    `json:"name"`
    Email   string    `json:"email,omitempty"`
    Created time.Time `json:"created,omitzero"`
    Secret  string    `json:"-"`                 // never encoded
}

b, err := json.Marshal(User{ID: 1, Name: "Ann"})
fmt.Println(string(b))            // {"id":1,"name":"Ann"}

var u User
err = json.Unmarshal([]byte(`{"id":2,"name":"Bo"}`), &u)

dec := json.NewDecoder(r.Body)    // streams from a Reader
dec.DisallowUnknownFields()
if err := dec.Decode(&u); err != nil { /* 400 */ }
json.NewEncoder(w).Encode(u)      // to a Writer (+ newline)

var anyv map[string]any           // unknown shape
json.Unmarshal(data, &anyv)       // numbers → float64
type Env struct{ Type string; Data json.RawMessage } // defer decoding

Code Explained

json:"name" — key name in JSON
omitempty / omitzero — drop empty values
json:"-" — exclude a field
Unmarshal(data, &u) — needs a pointer
RawMessage — keep raw bytes, decode later by type

Coming From…

  • Python — json.dumps → json.Marshal (struct tags rename)
  • JS — JSON.parse → Unmarshal into a typed struct
  • Java — Jackson annotations ≈ struct tags

⚠ Common Mistakes

  • Lowercase struct fields: they're silently left out of the JSON
  • json.Unmarshal(data, u) without &: returns an InvalidUnmarshalError
  • Decoding large numbers into any; IDs lose precision as float64. Use dec.UseNumber() or typed fields

✓ Tips & Best Practices

  • Use Decoder for HTTP bodies and files; Unmarshal for in-memory bytes
  • Implement MarshalJSON/UnmarshalJSON or TextMarshaler for custom formats
  • Test against GOEXPERIMENT=nojsonv2 when upgrading to 1.27 if output must stay byte-identical

Quick Summary

  • Marshal / Unmarshal — bytes ↔ values
  • NewEncoder / NewDecoder — streams
  • tags — name, omitempty, omitzero, -
  • encoding/json/v2 — new engine (1.27)
