HTTP Server — Basics

http.HandleFunc · http.ListenAndServe · http.ResponseWriter / http.Request · http.NewServeMux · method & wildcard patterns "GET /items/{id}" (1.22) · r.PathValue("id") · {path...} / {$} · http.Error

net/http Server

Go's standard library ships a production-ready HTTP server. A handler writes to an http.ResponseWriter and reads the *http.Request. Since Go 1.22, http.ServeMux patterns can include a method and wildcards like GET /items/{id}, read with r.PathValue. Each request runs in its own goroutine.

Pattern Rules

  • /path/ (trailing slash) matches the whole subtree
  • {$} matches the exact path only: GET /{$}
  • {rest...} captures the remaining path segments
  • The most specific pattern wins; conflicts panic at registration

A Minimal Server

func main() {
    mux := http.NewServeMux()
    mux.HandleFunc("GET /{$}", home)                  // exact "/"
    mux.HandleFunc("GET /items/{id}", getItem)        // method + wildcard
    mux.HandleFunc("POST /items", createItem)
    mux.HandleFunc("/files/{path...}", serveFile)     // any method
    log.Fatal(http.ListenAndServe(":8080", mux))
}

func home(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "hello")
}

func getItem(w http.ResponseWriter, r *http.Request) {
    id := r.PathValue("id")
    item, ok := store[id]
    if !ok {
        http.Error(w, "not found", http.StatusNotFound)
        return
    }
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(item)
}

⚠ Common Mistakes

  • Forgetting return after http.Error; the handler keeps writing
  • Setting headers after Write/WriteHeader; they're already sent and ignored
  • Using http.ListenAndServe with no timeouts in production (sheet 109)

✓ Tips & Best Practices

  • Register routes in one function (routes(mux)) so they're easy to review
  • Use http.StatusText(code) / named constants instead of bare numbers
  • Test handlers with httptest.NewRecorder (sheet 100)

Quick Summary

  • HandleFunc("GET /x/{id}", h) — routing (1.22)
  • r.PathValue / Query / FormValue — input
  • w.Header → WriteHeader → Write — output order
  • http.Error + return — errors
