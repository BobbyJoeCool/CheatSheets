if / else

Go's if needs no parentheses but always requires braces. It can start with a short init statement whose variables are scoped to the if and its else branches, the idiom behind if err := f(); err != nil. Go code favors early returns (guard clauses) over deep else nesting.

Notes

  • Condition must be a bool; no truthy values
  • else must be on the same line as the closing }
  • Init-statement variables are visible in every branch, not after
  • There is no ternary operator

if Forms

if n > 0 {
    fmt.Println("positive")
} else if n < 0 {
    fmt.Println("negative")
} else {
    fmt.Println("zero")
}

if v, ok := cache[key]; ok {      // comma-ok + init stmt
    return v
}

if err := save(doc); err != nil { // err scoped to this if
    return fmt.Errorf("save: %w", err)
}

func process(u *User) error {     // guard clauses
    if u == nil { return errNoUser }
    if !u.Active { return errInactive }
    return send(u)                // happy path unindented
}

Code Explained

else if — chain as many as needed
if v, ok := m[k]; ok — lookup and test in one line
if err := …; err != nil — keeps err out of the outer scope
Guard clauses — handle failures first, then the main logic
gofmt keeps } else { on one line

Coming From…

  • Python — braces required; no parentheses around conditions
  • JS / Java — if x := f(); x > 0 scopes x to the if
  • All — no ternary; use if/else

⚠ Common Mistakes

  • Putting else on a new line after }: syntax error (automatic semicolon)
  • Using a variable from the init statement after the if ends; it's out of scope
  • Nesting the happy path inside if err == nil { … } instead of returning early

✓ Tips & Best Practices

  • Keep the success path at the left margin; return early on errors
  • Use the init statement to limit the scope of temporary variables
  • Drop the else after a branch that ends in return (golint indent-error-flow)

Quick Summary

  • if cond { } — braces required, no parens
  • if x := f(); x > 0 — init statement
  • else if / else — on the } line
  • guard clauses — return early
