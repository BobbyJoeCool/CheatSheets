Import & Live Data

IMPORTRANGE · IMPORTHTML · IMPORTXML · IMPORTDATA · GOOGLEFINANCE · GOOGLETRANSLATE · IMAGE · recalculation

Pull Data From Other Files and the Web

Sheets can fetch live data. IMPORTRANGE pulls a range from another spreadsheet you can access. IMPORTHTML grabs tables and lists from web pages, IMPORTXML uses XPath, and IMPORTDATA loads CSV files. GOOGLEFINANCE returns stock prices and history, GOOGLETRANSLATE translates text, and IMAGE puts a picture in a cell.

Notes

  • IMPORTRANGE asks once per source file: click Allow access
  • Import functions refresh on a schedule (roughly hourly) and when the sheet opens
  • File › Settings › Calculation controls recalculation for NOW / RAND / GOOGLEFINANCE
  • Pages that build content with JavaScript can't be read by IMPORTHTML / IMPORTXML
  • Insert › Image › Image in cell, or =IMAGE(url)

Automate It

  • Use IMPORTRANGE to keep one summary file in sync with each team's sheet
  • Import once to a hidden tab, then reference that tab, to limit fetches

Import Functions

=IMPORTRANGE("https://docs.google.com/spreadsheets/d/ID", "Data!A1:E500")
=IMPORTRANGE(B1, "Data!A:E")                     # URL or ID in a cell
=IMPORTHTML("https://example.com/stats", "table", 2)   # 2nd table on page
=IMPORTXML("https://example.com", "//h2")        # all h2 headings (XPath)
=IMPORTDATA("https://example.com/data.csv")
=GOOGLEFINANCE("NASDAQ:GOOG")                    # current price
=GOOGLEFINANCE("MSFT", "close", DATE(2026,1,1), TODAY(), "WEEKLY")
=GOOGLEFINANCE("CURRENCY:USDEUR")                # exchange rate
=GOOGLETRANSLATE(A2, "en", "es")
=IMAGE("https://example.com/logo.png", 1)        # fit to cell
=DETECTLANGUAGE(A2)

Code Explained

IMPORTRANGE accepts the full URL or just the spreadsheet ID
IMPORTHTML's index counts tables (or lists) from 1
GOOGLEFINANCE history returns a Date / Close table that spills
IMAGE modes: 1 fit, 2 stretch, 3 original size, 4 custom size

Other Suites

  • Microsoft 365 — Power Query (Get Data › From Web / Workbook), STOCKHISTORY, linked data types
  • Apple iWork — no web imports in Numbers; STOCK / STOCKH for market data

Platform Differences

  • Browser — all functions
  • Offline — last fetched values show; no refresh
  • Mobile — values display and refresh online

⚠ Common Mistakes

  • Hundreds of IMPORTRANGE calls slowing the file; import once and reference locally
  • Expecting IMPORTXML to read sites that render with JavaScript
  • Using GOOGLEFINANCE for trading decisions; data can be delayed up to 20 minutes

✓ Tips & Best Practices

  • Keep source URLs in cells so swaps are one edit
  • Wrap imports in IFERROR to show a friendly message while loading
  • Combine IMPORTRANGE with QUERY to fetch only the rows you need

Quick Summary
