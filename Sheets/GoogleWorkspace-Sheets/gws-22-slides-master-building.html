Themes, Master & Building Slides

Edit theme · import theme · Import slides · duplicate ⌘D · align & distribute · group ⌘⌥G · linked charts · animations

Consistent Decks Without the Fuss

Every Slides deck has a theme with a master slide and layouts. Slide › Edit theme opens the theme builder: set fonts, colours and logo once and every slide follows. Import slides pulls slides from another deck, and linked charts from Sheets update with one click. The Motion pane holds transitions and animations.

Notes

  • Edit theme: Slide › Edit theme (or View › Theme builder)
  • Import theme: Slide › Change theme › Import theme
  • Import slides: File › Import slides, pick a deck and slides
  • Linked chart: copy a chart in Sheets, paste in Slides › Link to spreadsheet
  • Animations: select object › Insert › Animation (Motion pane)

Automate It

  • Master slides and Import slides instead of rebuilding standard slides each time
  • Linked charts update from Sheets with one click (Update button)

Building Shortcuts

⌘M            / Ctrl+M            # new slide
⌘D            / Ctrl+D            # duplicate slide or object
⌘⌥G           / Ctrl+Alt+G        # group
⌘⌥⇧G          / Ctrl+Alt+Shift+G  # ungroup
⌘↑ / ⌘↓       / Ctrl+↑ / Ctrl+↓   # bring forward / send backward
⌘⇧↑ / ⌘⇧↓     / Ctrl+Shift+↑ / ↓  # bring to front / send to back
⇧ + arrow     / Shift + arrow     # nudge by one pixel
⌥ + drag      / Alt + drag        # duplicate while dragging
⌘⌥⇧B          / Ctrl+Alt+Shift+B  # Motion (animations) pane

Code Explained

⌘D on an object duplicates it in place; move it, then ⌘D again to repeat the offset
Arrange › Align and Arrange › Distribute work on two or more objects
Linked charts show an Update button when the Sheet changes
Hold ⇧ while resizing to keep proportions

⚠ Common Mistakes

  • Formatting text on each slide instead of in the theme builder
  • Pasting charts as images; they go stale when the data changes
  • Leaving unused layouts that clutter the Layout menu

✓ Tips & Best Practices

  • Import slides from a "library" deck of approved slides
  • Turn on View › Guides for consistent margins
  • Use the theme's colour palette so recolouring later is one change

Quick Summary

  • File › Import slides — reuse slides
  • ⌘D / Ctrl+D — duplicate
