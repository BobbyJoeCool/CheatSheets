Headings Make Everything Else Work

Docs has paragraph styles: Normal text, Title, Subtitle and Heading 1–6. Use them instead of bold and big fonts and you get a document outline, a clickable table of contents and consistent formatting. Change a style once with Update heading to match and every heading follows; Save as my default styles applies it to new documents.

Notes

  • Styles dropdown is on the toolbar; shortcuts ⌘⌥0 (Normal) to ⌘⌥6
  • Format › Paragraph styles › Heading 1 › Update ‘Heading 1’ to match
  • Options › Save as my default styles makes your look the default
  • Pageless (File › Page setup) removes page breaks for on-screen docs
  • Line & paragraph spacing: Format › Line & paragraph spacing › Custom

Formatting Shortcuts

⌘⌥0          / Ctrl+Alt+0       # Normal text
⌘⌥1 … ⌘⌥6    / Ctrl+Alt+1 … 6   # Heading 1–6
⌘\           / Ctrl+\           # clear formatting
⌘B ⌘I ⌘U     / Ctrl+B I U       # bold, italic, underline
⌘⇧X          / Alt+Shift+5      # strikethrough
⌘. ⌘,        / Ctrl+. Ctrl+,    # superscript / subscript
⌘⇧> ⌘⇧<      / Ctrl+Shift+> <   # bigger / smaller font
⌘⇧L E R J    / Ctrl+Shift+L E R J  # left, center, right, justify
⌘⇧7 ⌘⇧8      / Ctrl+Shift+7 8   # numbered / bulleted list
⌘] ⌘[        / Ctrl+] Ctrl+[    # indent / outdent

Code Explained

Heading shortcuts both style the text and add it to the outline
Clear formatting resets to the paragraph style, so a messy paste becomes clean Normal text
Custom fonts: font menu › More fonts (any Google Font)
Docs has no character styles; paint format fills that gap

Other Suites

  • Microsoft 365 — Word Styles gallery, Update to Match Selection, ⌥⌘1 / Ctrl+Alt+1 headings
  • Apple iWork — Pages paragraph styles, Update button in the Format sidebar

Platform Differences

  • Browser — every option
  • Offline — same
  • Mobile — apply styles; can't update style definitions

⚠ Common Mistakes

  • Bold Normal text as headings; nothing appears in the outline or TOC
  • Fixing every heading by hand after changing your mind; update the style once
  • Using Enter for spacing instead of paragraph spacing

✓ Tips & Best Practices

  • Paste messy text, select it, press ⌘\ / Ctrl+\, then apply styles
  • Set your fonts once and Save as my default styles
  • Use pageless for wide tables and on-screen documents
