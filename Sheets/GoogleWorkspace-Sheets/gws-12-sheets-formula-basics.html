How Sheets Formulas Work

Formulas start with = and work like Excel: relative references shift when copied, $ locks them, and F4 cycles the $ while editing. Sheets adds open-ended ranges like A2:A (to the bottom) and offers formula suggestions and autocomplete with argument help. Hover an error to see what went wrong.

Notes

  • Cross-sheet: =Data!B2; with spaces: ='Q1 Data'!B2
  • Open-ended ranges: A2:A (to the last row), A2:2 (to the last column)
  • Named ranges: Data › Named ranges; use the name in formulas
  • Show formulas: View › Show › Formulas, or ⌃~ / Ctrl+~
  • Formula help popup: ⇧F1 / Shift+F1 while typing, or click the ?

References & Operators

=B2*C2                     # relative: becomes =B3*C3 below
=B2*$F$1                   # locked tax rate
=SUM(Data!B2:B)            # open-ended column on another tab
=SUM('Q1 Data'!B:B)        # tab name with spaces
=Price*(1+TaxRate)         # named ranges
="Total: "&TEXT(D2,"$#,##0")  # → Total: $1,250
=A2<>""                    # TRUE if not blank
=(B2-C2)/C2                # growth
=IF(ISBLANK(A2), "", A2*2) # blank-safe

Code Explained

F4 cycles A1 → $A$1 → A$1 → $A1 while the cursor is on a reference
Open-ended ranges are handy, but whole-column math on huge sheets can slow recalculation
& joins text; wrap numbers in TEXT() to control their format
Sheets is case-insensitive for function names and text comparisons

Other Suites

  • Microsoft 365 — same syntax; no A2:A open ranges (use tables or A2:.A1000)
  • Apple iWork — Numbers uses header names and Table 1::B2

Platform Differences

  • Browser — formula suggestions, help popups
  • Offline — formulas calculate; IMPORT functions wait for a connection
  • Mobile — edit formulas with a function list

⚠ Common Mistakes

  • Forgetting $ before copying across, so references drift
  • Numbers stored as text (left-aligned); use Format › Number or VALUE()
  • Using A:A in a formula placed in column A (circular reference)

✓ Tips & Best Practices

  • Click a cell while typing a formula instead of typing references by hand
  • Name inputs so formulas read as sentences
  • Turn off formula suggestions (Tools › Autocomplete) if they get in the way

Quick Summary

  • A2:A — open-ended range
  • 'Tab name'!A1 — cross-sheet
