Sheet 04

Templates & Smart Chips

Template gallery · custom templates · /copy · /template/preview · @ smart chips · dropdown chips · building blocks

Start From Structure

Docs, Sheets and Slides each have a template gallery; Workspace domains can add their own templates. Inside documents, type @ to insert smart chips: people, files, dates, places, dropdowns and building blocks like meeting notes, project trackers and email drafts. Chips are live: hover a person for their contact card, a file for a preview.

Notes

  • Gallery: Docs home › Template gallery (or File › New › From template)
  • Custom templates (Workspace): Template gallery › Submit template
  • Free accounts: share a master with a /copy link (sheet 03)
  • @ menu: people, files, calendar events, dates, dropdowns, building blocks
  • Dropdown chips (status, priority) can be customised and reused

Automate It

  • A /copy link to your master file means people always start from the template
  • Building blocks (@meeting notes, @project roadmap) instead of rebuilding layouts

Make and Use a Template

  1. Build the file with styles, headings, placeholders and dropdown chips
  2. Free account: Share › Copy link, change /edit… to /copy and send that
  3. Workspace: Template gallery › your org tab › Submit template
  4. Inside docs, type @ and pick a building block (e.g. Meeting notes)
  5. Type @date or @today for date chips; @ + name for people chips
  6. Insert › Dropdown to create a status chip, then copy-paste it down

Other Suites

  • Microsoft 365 — File › New templates; Loop components for live tables and checklists
  • Apple iWork — template chooser, Save as Template; no live chips

Platform Differences

  • Browser — all chips and building blocks
  • Offline — chips show, previews need a connection
  • Mobile — insert people and date chips; fewer building blocks

⚠ Common Mistakes

  • Editing the shared master because people opened it instead of copying
  • Typing dates as text so they don't sort or remind; use date chips
  • Creating a new dropdown per row instead of copying one chip

✓ Tips & Best Practices

  • Use the /template/preview link for a friendlier "Use template" page
  • Put status dropdowns in tables to make lightweight trackers in Docs
  • Email draft blocks let a team write an email together before sending
