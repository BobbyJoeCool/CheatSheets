Record, Then Read the Code

Sheets can record macros: Extensions › Macros › Record macro, do the steps, save. The recording is saved as Apps Script (JavaScript) in the file, and you can give it a shortcut. Open Extensions › Apps Script to edit macros, write custom functions you can call from cells, and automate Docs, Gmail, Drive and Calendar.

Notes

  • Absolute vs relative references are chosen when you start recording
  • Shortcut keys: ⌘⌥⇧1…0 / Ctrl+Alt+Shift+1…0 (10 slots)
  • Macros live in the file's bound script project (macros.gs)
  • First run asks for authorization; review what the script can access
  • Custom functions use a JSDoc @customfunction tag for autocomplete

A Macro and a Custom Function

/** Recorded macro, tidied: bold header, freeze, resize */
function formatReport() {
  const sheet = SpreadsheetApp.getActiveSheet();
  sheet.getRange('1:1').setFontWeight('bold');
  sheet.setFrozenRows(1);
  sheet.autoResizeColumns(1, sheet.getLastColumn());
  sheet.getRange('D2:D').setNumberFormat('$#,##0.00');
}

/**
 * Adds sales tax and rounds to cents.
 * @param {number} amount  The pre-tax amount.
 * @param {number} rate    Tax rate, e.g. 0.0825.
 * @customfunction
 */
function TAXED(amount, rate) {
  return Math.round(amount * (1 + rate) * 100) / 100;
}

Code Explained

Run functions from the editor's Run button or Extensions › Macros
In a cell: =TAXED(B2, 0.0825); custom functions can't change other cells
getRange('D2:D') uses A1 notation, including open ranges
The JSDoc comment becomes the help text shown in the cell

Other Suites

  • Microsoft 365 — Excel macro recorder writes VBA; Office Scripts write TypeScript
  • Apple iWork — no recorder; AppleScript and Shortcuts automate the Mac apps

Platform Differences

  • Browser — record, edit, run
  • Offline — scripts don't run offline
  • Mobile — custom functions calculate; menus and macros don't run

⚠ Common Mistakes

  • Recording with absolute references and running the macro from a different cell
  • Calling a custom function on thousands of rows one cell at a time; pass a range and return an array
  • Clicking through authorization for scripts you didn't write or read

✓ Tips & Best Practices

  • Record first, then rename the function and delete extra lines
  • Use named functions (sheet 20) when a formula is enough
  • Read the Execution log (View › Logs) to debug
