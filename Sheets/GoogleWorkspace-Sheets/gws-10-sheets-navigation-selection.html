Sheets Navigation & Selection

⌘↓ / Ctrl+↓ jump · ⇧ extend · select row / column · Name Box · freeze · switch sheets ⌥↓ / Ctrl+Shift+PgDn · hide / group

Move Around Big Sheets

Sheets uses the same jump logic as Excel: ⌘+Arrow / Ctrl+Arrow goes to the edge of the data block, and adding Shift selects along the way. Type a range or named range in the Name Box to jump there. Freeze rows and columns so headers stay visible, and group rows to collapse detail.

Notes

  • ⌘A / Ctrl+A selects the data region, press again for the whole sheet
  • Name Box (left of the formula bar): type D200 or Sales and press Enter
  • View › Freeze › 1 row / up to current row; or drag the thick grey bar
  • Group rows: select rows › ⌥⇧→ / Alt+Shift+→; collapse with the − button
  • Search the menus (⌥/) for "go to range" if the Name Box is hidden

Moving & Selecting

⌘↑ ↓ ← →       / Ctrl+↑ ↓ ← →      # jump to data edge
⇧⌘↓            / Ctrl+Shift+↓      # select to data edge
fn⌘←           / Ctrl+Home         # go to A1
fn⌘→           / Ctrl+End          # last cell with data
⌃Space         / Ctrl+Space        # select column
⇧Space         / Shift+Space       # select row
⌘A             / Ctrl+A            # select data / all
⌥↓  ⌥↑         / Ctrl+Shift+PgDn PgUp  # next / previous sheet
⌥⇧K            / Alt+Shift+K       # list of sheets
⌥⇧→  ⌥⇧←       / Alt+Shift+→ ←     # group / ungroup rows or columns
⌘⌥=  ⌘⌥-       / Ctrl+Alt+= -      # insert / delete (rows, columns)

Code Explained

Like Excel, jumps stop at blank cells; gaps in data break them
Group collapse / expand buttons appear above columns or left of rows
Alt+Shift+K lists all tabs; handy in files with dozens of sheets
Turn on compatible spreadsheet shortcuts (in ⌘/) for more Excel-style keys

Other Suites

  • Microsoft 365 — Excel uses the same jumps; Go To Special for blanks / visible cells
  • Apple iWork — Numbers tables are objects on a canvas; ⌥↑↓ adds rows

Platform Differences

  • Browser — every shortcut
  • Offline — same
  • Mobile — tap / drag only; freeze and group work from menus

⚠ Common Mistakes

  • Freezing the wrong rows by selecting a cell lower than intended; use "1 row"
  • Gaps in the data so ⌘↓ stops early; fill or delete blank rows
  • Hiding rows others need; group them so the collapse is visible

✓ Tips & Best Practices

  • Colour-code tabs by type (input, calc, output)
  • Name key ranges (Data › Named ranges) and jump via the Name Box
  • Use ⌥⇧K / Alt+Shift+K instead of scrolling the tab bar

Quick Summary

  • ⌘↓ / Ctrl+↓ — jump to edge
  • ⇧ + jump — select
  • View › Freeze — sticky headers
  • ⌥⇧→ — group rows / columns
