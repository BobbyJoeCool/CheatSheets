Forms, Keep & Tasks

Forms question types · quizzes · responses to Sheets · Keep notes, labels & reminders · Tasks from Gmail / Docs · action items

Collect, Capture and Track

Forms builds surveys, sign-ups and quizzes and sends responses straight into a Sheet. Keep holds quick notes, checklists and reminders that sync everywhere and can be dropped into Docs. Tasks collects to-dos from Gmail, Docs action items and Calendar in one list.

Notes

  • Forms: Responses tab › Link to Sheets for live response data
  • Quiz mode: Settings › Make this a quiz; set answer keys and points
  • Response validation (number, regex, length) per question
  • Keep: label notes, add reminders, share; Keep side panel in Docs / Gmail
  • Tasks: Gmail ⋯ › Add to Tasks; assigned Docs comments appear too

Automate It

  • Form → Sheet → Apps Script onFormSubmit trigger for confirmations or routing
  • Pre-filled form links (⋯ › Get pre-filled link) for repeat submissions

Build a Form That Feeds a Sheet

  1. Go to forms.new; add a title and questions
  2. Pick types (short answer, dropdown, date, file upload…)
  3. Turn on Required and response validation where needed
  4. Settings: collect emails, limit to 1 response, quiz mode
  5. Responses › Link to Sheets (new or existing sheet)
  6. Send › copy link or embed; watch rows arrive in the Sheet

Other Suites

Platform Differences

  • Browser — full Forms editor
  • Offline — Keep and Tasks work offline; Forms needs a connection
  • Mobile — Keep and Tasks apps; Forms fill-in works, editing is basic

⚠ Common Mistakes

  • Editing the response Sheet's structure (deleting columns) and breaking the link
  • File upload questions on forms for people outside your domain (they must sign in)
  • Keeping to-dos in Keep, Tasks and email flags all at once

✓ Tips & Best Practices

  • Add formulas on a separate tab, not in the response columns
  • Use sections and branching to keep forms short
  • Pick one task system and route everything into it
