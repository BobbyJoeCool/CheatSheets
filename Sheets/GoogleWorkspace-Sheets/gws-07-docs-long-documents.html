Long Documents & Document Tabs

document outline · document tabs · table of contents · headers / footers · different first page · section breaks · footnotes · bookmarks

Navigate and Structure Big Docs

The document outline (left panel) lists every heading for quick jumps. Document tabs split one file into named tabs and sub-tabs, like chapters, each with its own outline. Insert a table of contents that links to headings, use section breaks for different headers or orientation, and add footnotes and bookmarks for references.

Notes

  • Show outline / tabs: View › Show tabs & outlines, or the icon at top left
  • Add a tab: the + next to Document tabs; drag to nest as sub-tabs
  • TOC: Insert › Table of contents (with page numbers or with links); refresh with the ↻ button
  • Headers: Insert › Headers & footers; Different first page in Options
  • Footnote: ⌘⌥F / Ctrl+Alt+F

Automate It

  • A template with tabs already set up (Overview, Requirements, Decisions…) for every project
  • Link to headings (Insert › Link › Headings) instead of writing "see page 12"

Long-Doc Keys

⌘↩            / Ctrl+Enter        # page break
⌘⌥F           / Ctrl+Alt+F        # footnote
⌃⌘ N then H   / Ctrl+Alt N then H     # next heading
⌃⌘ P then H   / Ctrl+Alt P then H     # previous heading
⌃⌘ N then F   / Ctrl+Alt N then F     # next footnote
⌘⌥A ⌘⌥H       / Ctrl+Alt+A Ctrl+Alt+H # show document outline
Insert › Bookmark · Insert › Link › Bookmarks / Headings
Insert › Break › Section break (next page / continuous)

Code Explained

Heading-to-heading jumps are two-key sequences: hold the modifiers, then press N (or P) then H
Each document tab has its own outline and can be linked to directly
The TOC is not live; click its refresh icon after adding headings
Section breaks let headers, margins and orientation change mid-document

Other Suites

  • Microsoft 365 — Word Navigation pane, TOC, captions & cross-references, section breaks
  • Apple iWork — Pages TOC sidebar, section breaks, footnotes; no tabs

Platform Differences

  • Browser — tabs, outline, TOC, bookmarks
  • Offline — same
  • Mobile — view tabs and outline; limited header / section editing

⚠ Common Mistakes

  • Forgetting to refresh the TOC before sharing or exporting
  • Splitting one project into five docs when tabs would keep one link
  • Typing page references; link to headings or bookmarks instead

✓ Tips & Best Practices

  • Use emoji in tab names for quick visual scanning
  • Copy a link to a heading (right-click in outline) to send people to the right spot
  • Use sub-tabs for appendices so the main tab stays short

Quick Summary
