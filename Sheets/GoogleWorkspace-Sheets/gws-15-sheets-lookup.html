XLOOKUP · INDEX / MATCH · VLOOKUP / HLOOKUP · XMATCH · FILTER as a lookup · approximate & wildcard · two-way

Pull Values From Another Table

Sheets supports XLOOKUP with the same arguments as Excel: value, search column, return column, plus optional not-found value and match modes. INDEX / MATCH and VLOOKUP still work. When you need every matching row, use FILTER instead of a lookup, and combine with IMPORTRANGE to look up in another file.

Notes

  • XLOOKUP(key, lookup_range, result_range, [missing], [match_mode], [search_mode])
  • match_mode 0 exact, -1 next smaller, 1 next larger, 2 wildcard
  • search_mode -1 searches from the bottom (latest entry)
  • VLOOKUP needs FALSE (or 0) for exact matches
  • Cross-file lookups: wrap the other file's range in IMPORTRANGE (sheet 19)

Lookup Patterns

=XLOOKUP(A2, Products!A:A, Products!C:C)                # exact
=XLOOKUP(A2, Products!A:A, Products!C:C, "Not found")
=XLOOKUP(A2, Products!A:A, Products!B:D)                # returns 3 columns
=XLOOKUP(D2, Rates!A:A, Rates!B:B, , -1)                # bracket lookup
=XLOOKUP(A2, Log!A:A, Log!C:C, , 0, -1)                 # last match
=INDEX(Products!C:C, MATCH(A2, Products!A:A, 0))        # classic
=VLOOKUP(A2, Products!A:C, 3, FALSE)                    # legacy
=FILTER(Orders!A:D, Orders!B:B = A2)                    # all matches
=XLOOKUP(A2, IMPORTRANGE(url, "P!A:A"), IMPORTRANGE(url, "P!C:C"))

Code Explained

XLOOKUP can return several adjacent columns; they spill right
Bracket lookups (-1) don't need sorted data in XLOOKUP
FILTER returns every matching row, so it replaces "lookup the 2nd match" tricks
IMPORTRANGE needs a one-time Allow access click per source file

Other Suites

  • Microsoft 365 — identical XLOOKUP / INDEX / MATCH; FILTER also spills
  • Apple iWork — Numbers XLOOKUP, XMATCH, VLOOKUP, INDEX / MATCH

Platform Differences

  • Same everywhere; IMPORTRANGE needs a connection.

⚠ Common Mistakes

  • VLOOKUP without FALSE returning wrong rows on unsorted data
  • Lookup keys with trailing spaces or numbers stored as text
  • Separate IMPORTRANGE calls for every row; import once to a tab and look up locally

✓ Tips & Best Practices

  • Use the missing-value argument instead of IFERROR
  • For two conditions, look up a joined key: XLOOKUP(A2&B2, X:X&Y:Y, Z:Z)
  • Cache IMPORTRANGE data on a hidden tab for speed

Quick Summary

  • , , -1 — next smaller
  • FILTER — all matches
