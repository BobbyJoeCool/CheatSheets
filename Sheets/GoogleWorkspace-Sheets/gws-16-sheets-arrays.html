One Formula for a Whole Column

Functions like FILTER, SORT, UNIQUE and SEQUENCE return ranges that spill into neighbouring cells. ARRAYFORMULA makes ordinary functions work on whole columns, so one formula in the header row replaces thousands of copied formulas. Array literals in braces build ranges on the fly: , separates columns, ; separates rows.

Notes

  • ⌘⇧↩ / Ctrl+Shift+Enter wraps a formula in ARRAYFORMULA
  • Spill blocked by data shows #REF! ("Array result was not expanded")
  • {A2:A, C2:C} puts two columns side by side; {A2:A; B2:B} stacks them
  • In some locales the column separator is \ instead of ,
  • SORTN returns the top N rows, with tie handling

Array Formulas

=ARRAYFORMULA(IF(A2:A="", "", B2:B*C2:C))     # whole-column total
=ARRAYFORMULA(PROPER(TRIM(A2:A)))              # clean a column
=FILTER(A2:D, C2:C="West", D2:D>1000)          # multiple conditions = AND
=FILTER(A2:D, (C2:C="West")+(C2:C="East"))     # OR
=SORT(A2:D, 4, FALSE)                          # by 4th column, descending
=SORTN(A2:D, 5, 0, 4, FALSE)                   # top 5 by column 4
=UNIQUE(B2:B)        =COUNTA(UNIQUE(B2:B))
=SEQUENCE(12)        =SEQUENCE(1, 7, 0)
={A1:A10, C1:C10}                              # two columns together
=VSTACK(Jan!A2:D, Feb!A2:D)                    # stack tabs
=CHOOSECOLS(A2:F, 1, 4)                        # pick columns
=TOCOL(A2:F, 1)                                # flatten, skip blanks

Code Explained

The IF(A2:A="", "", …) guard stops ARRAYFORMULA filling empty rows with zeros
FILTER takes extra condition arguments for AND; add conditions for OR
SORT's order argument is TRUE / FALSE (ascending / descending)
TOCOL(range, 1) ignores blanks; FLATTEN is the older equivalent

Other Suites

  • Microsoft 365 — dynamic arrays spill natively; no ARRAYFORMULA needed
  • Apple iWork — recent Numbers adds FILTER, SORT, SORTBY, UNIQUE, SEQUENCE; no ARRAYFORMULA

Platform Differences

  • Same everywhere.

Array Literals

LiteralGives
{1, 2, 3}One row, three columns
{1; 2; 3}One column, three rows
{A:A, C:C}Columns side by side
{"Name", "Total"; A2:A, D2:D}Header row on top (must match widths)
{A2:A; B2:B}Stack two columns

⚠ Common Mistakes

  • Copying an ARRAYFORMULA down the column; it already fills it
  • Typing in a cell inside a spill range, causing #REF! on the formula
  • Array literal pieces of different heights or widths (#VALUE! / mismatched)

✓ Tips & Best Practices

  • Put ARRAYFORMULA in the header row ({"Total"; ARRAYFORMULA(…)}) so sorting never breaks it
  • Use FILTER + SORTN for leaderboards
  • Prefer VSTACK over array literals for readability

Quick Summary

  • ARRAYFORMULA — whole-column formulas
  • FILTER / SORT / UNIQUE — spill results
  • {a, b} / {a; b} — columns / rows
  • SORTN — top N
