Type Less in Docs

The @ menu inserts almost anything without leaving the keyboard. Substitutions (Tools › Preferences) expand short codes into long text. With Markdown turned on, typing # makes a heading and **bold** makes bold. Find and replace supports regular expressions, which Word's replace doesn't.

Notes

  • Turn on Markdown: Tools › Preferences › Automatically detect Markdown
  • Substitutions: Tools › Preferences › Substitutions, e.g. addr → your address
  • Find and replace: tick Match using regular expressions; use $1 in Replace
  • Edit › Paste from Markdown / Copy as Markdown converts both ways
  • Tools › Line numbers for legal and review docs

Shortcuts, Markdown & Regex

@                        # insert menu: chips, tables, dates, blocks
⌘⇧C          / Ctrl+Shift+C   # word count
⌘⌥X          / Ctrl+Alt+X     # spelling & grammar
⌘⇧H          / Ctrl+H         # find & replace

# Markdown auto-detect
# Heading 1    ## Heading 2    - bullet    1. numbered
**bold**   *italic*   `code`   [text](url)   ---

# Find & replace with regex
\s{2,}                   → " "         # collapse spaces
(\w+), (\w+)              → $2 $1       # "Smith, Jane" → "Jane Smith"
^\d+\.\s                  → (empty)     # remove "1. " at line start

Code Explained

Regex in Docs uses RE2 syntax; $1, $2 refer to capture groups
Markdown detection works as you type; undo once to keep the literal characters
Substitutions are per user and apply in every doc you edit
Word count includes a "Display word count while typing" option

Other Suites

  • Microsoft 365 — Word wildcards (not full regex), AutoCorrect entries, Quick Parts
  • Apple iWork — macOS Text Replacements; Pages Find & Replace without regex

Platform Differences

  • Browser — regex replace, Markdown, substitutions
  • Offline — same
  • Mobile — basic find & replace; no regex

⚠ Common Mistakes

  • Running Replace all with a regex you haven't tested; check matches first
  • Leaving Markdown detection on when writing about Markdown
  • Creating substitutions that are real words (e.g. the)

✓ Tips & Best Practices

  • Prefix substitution codes with a symbol (;sig) to avoid accidents
  • Paste from Markdown when moving notes from other apps
  • Use line numbers when collecting feedback on a long draft
