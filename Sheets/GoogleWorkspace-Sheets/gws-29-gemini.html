AI Inside the Apps

Gemini appears as a side panel (✦) in Docs, Sheets, Slides, Gmail and Drive, and as inline tools like Help me write. In Sheets it can build formulas, tables and charts, and the AI() function runs a prompt per row. Features depend on your plan, and every result is a draft to check, not a final answer.

Notes

  • Side panel: ✦ icon top right; it can reference other Drive files with @
  • Docs: Help me write / refine, summaries, image generation
  • Sheets: "Help me organize", formula explanations, =AI("prompt", A2)
  • Gmail: summarise thread, draft replies, Help me write
  • Availability varies by Workspace edition and Google One plan

Prompts and the AI Function

# Side panel prompts
Docs:   "Summarize this doc in 5 bullets for a manager; flag open risks"
Sheets: "Create a formula in E2 that flags orders over $1,000 on weekends"
Slides: "Draft speaker notes for this slide, 60 seconds, plain language"
Gmail:  "Summarize this thread and list who owes what by when"
Drive:  "Find the latest budget sheet and list its totals by department"

# Sheets AI function (one call per cell)
=AI("Classify this feedback as positive, neutral or negative", B2)
=AI("Extract the company name", A2)
=AI("Write a 10-word product tagline for", C2)

Code Explained

Name the source (@file), the task, the format and the audience in prompts
AI() results don't recalculate automatically; refresh them when inputs change
Ask Gemini to explain a formula before trusting one it wrote
Generated text and images still need fact and rights checks

Other Suites

  • Microsoft 365 — Copilot in each app, COPILOT() function, Python in Excel
  • Apple iWork — Apple Intelligence Writing Tools; no spreadsheet AI function

Platform Differences

  • Browser — full side panel and AI function
  • Offline — no Gemini
  • Mobile — Gemini in Gmail and the Gemini app; fewer editor features

⚠ Common Mistakes

  • Using AI() for things a normal formula does exactly
  • Pasting AI summaries into reports without checking numbers
  • Vague prompts like "improve this"; say what better means

✓ Tips & Best Practices

  • Keep data in clean tables with clear headers; Gemini does better
  • Paste AI() results as values once checked
  • See the Agentic Coding set for prompting techniques
