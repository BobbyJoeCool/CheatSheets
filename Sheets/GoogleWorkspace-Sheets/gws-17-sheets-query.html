The QUERY Function

QUERY(range, "select … where … group by …") · Col1 vs A · order by · pivot · label / format · headers · dates

SQL Inside a Cell

QUERY runs a SQL-like statement (Google Visualization Query Language) over a range: select columns, filter with where, summarise with group by, sort with order by, cross-tab with pivot. One QUERY often replaces a pivot table, a FILTER and several SUMIFS.

Notes

  • Column names are letters (A, B) for ranges; Col1, Col2 for arrays and IMPORTRANGE
  • Text values in single quotes: where B = 'West'
  • Clause order matters: select, where, group by, pivot, order by, limit, offset, label, format
  • Third argument = number of header rows (usually 1)
  • Dates need the date keyword: where A >= date '2026-01-01'

Automate It

  • One QUERY on a raw-data tab instead of a chain of helper columns and pivots
  • Build the date in the where clause from a cell so reports update by changing one input

QUERY Examples

=QUERY(Sales!A:E, "select A, B, E where B = 'West' order by E desc", 1)
=QUERY(Sales!A:E, "select B, sum(E) group by B order by sum(E) desc", 1)
=QUERY(Sales!A:E, "select B, sum(E) group by B pivot C", 1)      # cross-tab
=QUERY(Sales!A:E, "select * where E > 1000 limit 10", 1)
=QUERY(Sales!A:E, "select B, count(A) group by B label count(A) 'Orders'", 1)
=QUERY(Sales!A:E, "select A, E where A >= date '"&TEXT(G1,"yyyy-mm-dd")&"'", 1)
=QUERY(Sales!A:E, "select B where D contains 'widget'", 1)
=QUERY(IMPORTRANGE(url, "Data!A:E"), "select Col2, sum(Col5) group by Col2", 1)
=QUERY({Jan!A2:E; Feb!A2:E}, "select Col1, Col5 where Col5 is not null", 0)

Code Explained

Aggregates: sum, avg, count, max, min; every non-aggregated selected column must be in group by
Joining a cell into the query string needs quote juggling: '"&G1&"'
Arrays (from {} or IMPORTRANGE) use Col1, not A
contains, starts with, matches (regex) and like work on text

Other Suites

  • Microsoft 365 — no QUERY; use FILTER + GROUPBY / PIVOTBY or Power Query
  • Apple iWork — no equivalent; use pivot tables and categories

Platform Differences

  • Same everywhere; QUERY over IMPORTRANGE needs a connection.

⚠ Common Mistakes

  • Double quotes around text inside the query; use single quotes
  • Selecting a column without aggregating or grouping it
  • Mixed data types in one column; QUERY uses the majority type and blanks the rest

✓ Tips & Best Practices

  • Build long queries in a cell and reference it: =QUERY(A:E, H1, 1)
  • Use label to give result columns friendly headers
