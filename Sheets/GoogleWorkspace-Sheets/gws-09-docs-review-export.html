Review, Mail Merge & Export

Suggesting mode · comment ⌘⌥M · Compare documents · eSignature · mail merge · download .docx / PDF / Markdown · publish to web

From Draft to Final

Suggesting mode is Docs' track changes: edits appear as suggestions that the owner accepts or rejects. Compare documents shows the differences between two docs as suggestions. Workspace plans add eSignature and mail merge from Sheets. When done, download as Word, PDF, Markdown or EPUB, or publish to the web.

Notes

  • Switch mode with the pencil menu (Editing / Suggesting / Viewing) or ⌘⌥⇧X / Ctrl+Alt+Shift+X
  • Accept all: Tools › Review suggested edits › Accept all
  • Tools › Compare documents picks a second doc and creates a comparison file
  • Mail merge (Workspace): Tools › Mail merge, data from a Sheet, send via Gmail
  • eSignature (Workspace): Tools › eSignature to add signature fields

Automate It

  • Mail merge from a Sheet instead of copy-paste letters
  • Apps Script merge for free accounts (see sheet 28)

Review a Draft

  1. Reviewer switches to Suggesting (pencil icon, top right)
  2. Edits show in colour with the author; comments explain why
  3. Owner opens Tools › Review suggested edits and steps through
  4. Accept or reject each, or Accept all / Reject all
  5. Resolve comments as they're handled
  6. File › Download › PDF or Word for the final copy

Platform Differences

  • Mobile — suggest and comment; no compare or merge

⚠ Common Mistakes

  • Editing in Editing mode on someone else's doc when they wanted suggestions
  • Downloading a .docx with unresolved suggestions that the recipient sees as tracked changes
  • Publishing to the web and forgetting it stays public until unpublished

✓ Tips & Best Practices

  • Share as Commenter to force suggestions
  • Use Compare documents when edits were made on a copy
  • Check File › Share › Publish to web for anything you published earlier
