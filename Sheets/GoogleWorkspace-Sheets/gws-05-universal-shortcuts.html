Sheet 05

Shortcuts That Work Everywhere

⌘/ / Ctrl+/ shortcut list · ⌥/ / Alt+/ search menus · ⌘⇧V paste plain · paint format · voice typing ⌘⇧S · Gemini panel

Learn These in Every Editor

Docs, Sheets and Slides share core shortcuts. The two to learn first: ⌘/ / Ctrl+/ shows every shortcut, and ⌥/ / Alt+/ searches the menus so you can run any command by typing its name. Paste without formatting and paint format keep files tidy; voice typing and the Gemini side panel help you draft.

Notes

  • Search the menus also finds functions in Sheets and settings like "word count"
  • Paint format: click the roller, then the target; double-click to keep it on
  • Voice typing (Docs, Slides speaker notes): Tools › Voice typing
  • Enable compatible shortcuts in the shortcut list to get extra keys (e.g. Excel-style in Sheets)
  • Browser shortcuts (⌘T, ⌘W) still belong to the browser

Shared Editor Shortcuts

⌘/            / Ctrl+/            # keyboard shortcut list
⌥/            / Alt+/             # search the menus
⌘C ⌘X ⌘V      / Ctrl+C X V        # copy, cut, paste
⌘⇧V           / Ctrl+Shift+V      # paste without formatting
⌘⌥C  ⌘⌥V      / Ctrl+Alt+C  V     # copy / paste formatting
⌘Z  ⌘⇧Z       / Ctrl+Z  Ctrl+Y    # undo / redo
⌘K            / Ctrl+K            # insert link
⌘F  ⌘⇧H       / Ctrl+F  Ctrl+H    # find / find & replace
⌘⌥M           / Ctrl+Alt+M        # comment
⌘⇧S           / Ctrl+Shift+S      # voice typing (Docs)
⌘\            / Ctrl+\            # clear formatting

Code Explained

⌘⌥C / ⌘⌥V is the keyboard version of paint format
Search the menus is the closest thing to Office's Tell Me / KeyTips
Clear formatting removes character formatting but keeps paragraph styles
Compatible shortcuts are toggled at the bottom of the ⌘/ dialog

Other Suites

  • Microsoft 365 — Paste Special ⌃⌘V / Ctrl+Alt+V, Format Painter, Search box Alt+Q
  • Apple iWork — Paste and Match Style ⌥⇧⌘V, Copy / Paste Style ⌥⌘C / ⌥⌘V

Platform Differences

  • Browser — every shortcut
  • Offline — same shortcuts
  • Mobile — no menu search; long-press for paste options

⚠ Common Mistakes

  • Pasting from a website with all its fonts; use ⌘⇧V / Ctrl+Shift+V
  • Clicking through menus for rarely used commands; type them into menu search
  • Expecting Office shortcuts in Sheets without turning on compatible shortcuts

✓ Tips & Best Practices

  • Make ⌥/ / Alt+/ your first move for anything you can't find
  • Double-click paint format to apply it to several places
  • Check the shortcut dialog every few weeks and learn one new key
