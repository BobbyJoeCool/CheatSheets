Present From the Browser

Slideshow (⌘↩ / Ctrl+Enter) goes full screen; Presenter view opens a second window with notes, a timer and next-slide preview. Audience Q&A lets people submit questions from a link shown on the slide. Turn on captions to show live subtitles. Present straight into a Meet call or publish the deck to the web.

Notes

  • Presenter view: Slideshow dropdown › Presenter view
  • Audience Q&A: Presenter view › Audience tools › Start new
  • Speaker notes: View › Show speaker notes; voice-type into them
  • Present in Meet from the Present button inside the call
  • File › Download › PDF or .pptx; File › Share › Publish to web for auto-advancing embeds

Presentation Keys

⌘↩            / Ctrl+Enter        # present from current slide
⌘⇧↩           / Ctrl+Shift+Enter  # present from the beginning
→ ↓ Space     / → ↓ Space         # next
← ↑           / ← ↑               # previous
12 ↩          / 12 Enter          # go to slide 12
B   W         / B   W             # black / white screen
L             / L                 # laser pointer
S             / S                 # open speaker notes
A             / A                 # audience tools
⌘⇧C           / Ctrl+Shift+C      # captions on / off
Esc           / Esc               # exit

Code Explained

Presenter view opens in a new browser window; drag it to your laptop screen
The Q&A link appears at the top of every slide while active
Captions use your microphone and work in several languages
Published decks can auto-advance and loop for kiosks

Other Suites

  • Microsoft 365 — PowerPoint Presenter View, Speaker Coach, live subtitles
  • Apple iWork — Keynote presenter display, X swap displays, iPhone remote

Platform Differences

  • Browser — Presenter view, Q&A, captions
  • Offline — present marked-offline decks; no Q&A or captions
  • Mobile — present to a TV / cast; phone as remote via Meet

⚠ Common Mistakes

  • Presenting the editor window instead of the slideshow
  • Forgetting to end Audience Q&A, leaving the banner on later slides
  • Relying on Wi-Fi for embedded videos

✓ Tips & Best Practices

  • Type a slide number and Enter to jump during Q&A
  • Press B to blank the screen for discussion
  • Keep a PDF copy on your laptop as a fallback
