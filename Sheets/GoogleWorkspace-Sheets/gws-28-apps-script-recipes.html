Automate Across Workspace

Apps Script can read and write Sheets in bulk, add custom menus, react to edits with simple triggers, run on a schedule with time-driven triggers, and reach Gmail, Docs, Drive and Calendar. For no-code automation, Workspace Flows and AppSheet cover many of the same jobs.

Notes

  • Batch: getValues() / setValues() read and write 2-D arrays in one call
  • onOpen(e) and onEdit(e) are simple triggers: no setup, limited permissions
  • Installable triggers (clock icon in the editor) run on a schedule or form submit
  • Quotas apply (emails per day, runtime per execution)
  • Use Logger.log() or console.log() and the Executions page to debug

Automate It

  • Time-driven trigger: every Monday 7am, email a summary of overdue tasks
  • onFormSubmit trigger: confirmation email + route to the right owner

Menu, Edit Trigger, Mail Merge

function onOpen() {
  SpreadsheetApp.getUi().createMenu('Tools')
    .addItem('Flag overdue', 'flagOverdue')
    .addItem('Send reminders', 'sendReminders').addToUi();
}

function onEdit(e) {                        // timestamp column C when B changes
  if (e.range.getColumn() === 2) e.range.offset(0, 1).setValue(new Date());
}

function sendReminders() {                  // one email per row
  const rows = SpreadsheetApp.getActive().getSheetByName('Tasks')
                 .getDataRange().getValues().slice(1);
  rows.filter(r => r[3] !== 'Done' && r[2] < new Date())
      .forEach(([task, email, due]) => GmailApp.sendEmail(
        email, `Overdue: ${task}`, `"${task}" was due ${due.toDateString()}.`));
}

Code Explained

getDataRange() = all used cells; .slice(1) drops the header row
Destructuring [task, email, due] names the first three columns
Simple triggers can't send email; run sendReminders from the menu or an installable trigger
Template literals (backtick strings) build message text with ${…}

⚠ Common Mistakes

  • Reading cells one at a time in a loop; use getValues() once
  • Expecting onEdit to fire for changes made by formulas or other scripts
  • Hitting email quotas with big sends; batch and check MailApp.getRemainingDailyQuota()

✓ Tips & Best Practices

  • Keep secrets in Script Properties, not in code
  • Add a custom menu so non-technical users can run scripts
  • Try Workspace Flows before writing a script for simple automations
