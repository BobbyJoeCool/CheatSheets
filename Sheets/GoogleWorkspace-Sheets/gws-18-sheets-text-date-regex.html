Clean Text, Do Date Math

Sheets has had regular expressions for years: REGEXMATCH, REGEXEXTRACT and REGEXREPLACE use the RE2 syntax. SPLIT breaks text into columns and TEXTJOIN joins ranges. Dates are serial numbers like in Excel, so subtraction gives days and EOMONTH, EDATE, NETWORKDAYS handle calendars.

Notes

  • REGEX functions are case-sensitive; add (?i) at the start of the pattern to ignore case
  • SPLIT(text, delimiter) splits on each character of the delimiter unless split_by_each is FALSE
  • TEXT(value, "format") returns formatted text
  • Dates: Format › Number › Date; =B2-A2 gives days
  • DATEDIF works and is documented in Sheets

Text & Date Formulas

=SPLIT("Smith, Jane", ", ", FALSE)          # Smith | Jane
=TEXTJOIN(", ", TRUE, B2:B10)               # join, skip blanks
=PROPER(TRIM(A2))
=REGEXMATCH(A2, "^\d{5}$")                   # TRUE for 5-digit zip
=REGEXEXTRACT(A2, "[\w.]+@[\w.]+")           # pull an email
=REGEXEXTRACT(A2, "(\d{3})-(\d{4})")         # two groups → two columns
=REGEXREPLACE(A2, "(?i)inc\.?", "Inc.")      # case-insensitive replace
=TEXT(B2, "$#,##0.00")    =TEXT(C2, "mmm d, yyyy")
=EOMONTH(TODAY(), 0)                        # month end
=EDATE(A2, 3)                               # +3 months
=NETWORKDAYS(A2, B2, Holidays!A:A)
=DATEDIF(Birth, TODAY(), "Y")               # age
=WORKDAY(TODAY(), 10)

Code Explained

REGEXEXTRACT with several capture groups spills one column per group
In Sheets formulas a single backslash is enough: "\d"
SPLIT(…, ", ", FALSE) splits on the whole ", " string
EOMONTH(d, -1)+1 = first day of the month

⚠ Common Mistakes

  • Dates typed in a format your locale doesn't read become text; check File › Settings › Locale
  • Expecting REGEXMATCH to ignore case; add (?i)
  • Using lookbehind (?<=…), which RE2 doesn't support

✓ Tips & Best Practices

  • Use REGEXEXTRACT instead of MID / FIND chains
  • Keep a Holidays tab for NETWORKDAYS
  • Wrap regex functions in ARRAYFORMULA to process a whole column
