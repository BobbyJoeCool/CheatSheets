Introduction to Google Workspace

free account vs Workspace · docs.new / sheets.new / slides.new · offline mode · Drive for desktop · mobile apps · Office files

Everything Lives in the Browser

Google Workspace is Docs, Sheets, Slides, Gmail, Drive, Calendar, Meet and friends. Every file lives in Drive, saves as you type, and can be opened by anyone you share it with. A free Google account gets the same editors; paid Workspace plans add custom domains, more storage, admin controls, and extras like eSignature, appointment booking pages and Gemini features.

Notes

  • Native Google files are links, not documents on disk; download to get .docx / .xlsx / .pptx
  • Office files can be edited directly ("Office editing" mode) or converted with File › Save as Google Docs
  • Offline: Drive settings › Offline, then mark files Available offline (Chrome or Edge)
  • Drive for desktop shows Drive as a disk in Finder / File Explorer
  • Chrome is the best-supported browser; most features work in Safari, Edge and Firefox

Open Things Fast

docs.new   sheets.new   slides.new     # new blank file in My Drive
forms.new  sites.new    keep.new       # other apps
drive.google.com/drive/recent          # recently opened files

⌘/            / Ctrl+/          # show all shortcuts (any editor)
⌥/            / Alt+/           # search the menus
⌘S            / Ctrl+S          # nothing to save — it already did
⌘O            / Ctrl+O          # open a file from Drive
⌘P            / Ctrl+P          # print / PDF
File › Download › .docx / .xlsx / .pptx / .pdf

Code Explained

The .new shortcuts work in any browser address bar while signed in
Shortcuts are listed macOS first, then Windows / ChromeOS, on every sheet
Browser shortcuts can win: ⌘N opens a browser window, not a document
Version history replaces "Save As" for keeping old copies (sheet 03)

Other Suites

  • Microsoft 365 — word.new, excel.new; desktop apps plus web apps in OneDrive
  • Apple iWork — Pages / Numbers / Keynote on Mac / iPad; iCloud.com for web versions

Platform Differences

  • Browser — full feature set
  • Offline / Drive for desktop — edit marked files without internet; syncs later
  • Mobile — Docs, Sheets, Slides apps; fewer menus, no add-ons or Apps Script editor

⚠ Common Mistakes

  • Downloading a Google file to "save" it; the Drive copy is already saved and current
  • Emailing a .gdoc shortcut file from Drive for desktop; it's only a link, not the document
  • Expecting complex Word or Excel features (macros, Power Query) to survive conversion

✓ Tips & Best Practices

  • Bookmark docs.new / sheets.new or type them; fastest way to a blank file
  • Turn on offline mode before travelling
  • Keep Office files as Office files if they go back to Office users; edit them in Office mode

Quick Summary
