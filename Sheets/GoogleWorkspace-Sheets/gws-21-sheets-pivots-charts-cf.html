Pivot Tables, Charts & Conditional Formatting

pivot tables · suggested pivots · calculated fields · chart editor · SPARKLINE · custom formula rules · color scales · Connected Sheets

Summarise and Highlight

Pivot tables (Insert › Pivot table) summarise data by dragging fields into Rows, Columns, Values and Filters, and Sheets suggests pivots for you. The chart editor builds charts that update with the data, and SPARKLINE draws a tiny chart in a cell. Conditional formatting with a custom formula highlights whole rows by any rule.

Notes

  • Pivot source: use an open-ended range (A1:E) or a table so new rows are included
  • Calculated field: Values › Add › Calculated field, e.g. =Revenue-Cost
  • Group dates: right-click a date in the pivot › Create pivot date group
  • Custom formula rules use the top-left cell of the range with relative refs
  • Connected Sheets (Workspace) analyses BigQuery data with pivots

Automate It

  • Pivot on an open-ended range so new rows show up automatically
  • A time-driven Apps Script trigger can email a chart or PDF weekly

Rules, Sparklines & Charts

# Format › Conditional formatting › Custom formula is
=$E2="Overdue"                        # whole row when E is Overdue
=AND($D2<TODAY(), $F2<>"Done")        # past due, not done
=COUNTIF($A:$A, $A2)>1                # duplicates
=ISEVEN(ROW())                        # banded rows

# SPARKLINE in a cell
=SPARKLINE(B2:M2)                                       # line
=SPARKLINE(B2:M2, {"charttype","column"; "color","#4285f4"})
=SPARKLINE(C2, {"charttype","bar"; "max", 100})         # progress bar
=SPARKLINE(B2:M2, {"charttype","winloss"})

Insert › Chart · Insert › Pivot table · Explore (✦) suggests both

Code Explained

$E2 locks the column so every cell in the row checks column E
SPARKLINE options go in a 2-column array literal of name / value pairs
A bar sparkline with max makes a simple progress bar
Charts and pivots update as the data changes; no refresh needed

Other Suites

  • Apple iWork — Numbers pivot tables, interactive charts, conditional highlighting (no formulas)

⚠ Common Mistakes

  • Custom formula written for row 1 when the range starts at row 2
  • Pivots on a fixed range (A1:E500) that miss new rows
  • Too many conditional rules on large sheets, making them slow

✓ Tips & Best Practices

  • Try Explore (bottom right) for instant pivot and chart suggestions
  • Use SPARKLINE progress bars in task trackers
  • Name pivot tabs clearly; they're easy to lose among data tabs
