LET, LAMBDA & Named Functions

LET · LAMBDA · MAP / BYROW / BYCOL · REDUCE / SCAN · MAKEARRAY · Named functions · import

Your Own Functions, No Script Needed

LET names steps inside a formula. LAMBDA defines a function, and the helper functions MAP, BYROW, BYCOL, REDUCE, SCAN and MAKEARRAY apply it across ranges. Save a LAMBDA as a Named function (Data › Named functions) to call it like =TAXED(B2) anywhere in the file, and import named functions from other files.

Notes

  • Named functions: Data › Named functions › Add new function
  • Give each argument a placeholder name and description; they show in formula help
  • Import from another file: Named functions › Import function
  • BYROW / BYCOL return one value per row / column
  • Named functions can call other named functions

LET, LAMBDA & Helpers

=LET(total, SUM(D2:D), west, SUMIFS(D2:D, B2:B, "West"), west/total)

# Data › Named functions → name: TAXED, args: amount, rate
#   definition: =ROUND(amount*(1+rate), 2)
=TAXED(B2, 0.0825)                                 # 100 → 108.25

=MAP(A2:A20, LAMBDA(x, PROPER(TRIM(x))))           # clean each cell
=BYROW(B2:E20, LAMBDA(r, MAX(r)-MIN(r)))           # range per row
=BYCOL(B2:E20, LAMBDA(c, AVERAGE(c)))              # average per column
=REDUCE(0, C2:C20, LAMBDA(acc, x, acc + (x>100)))  # count over 100
=SCAN(0, C2:C20, LAMBDA(acc, x, acc + x))          # running total
=MAKEARRAY(5, 5, LAMBDA(r, c, r*c))                # times table
=LAMBDA(x, x*2)(21)                                # → 42

Code Explained

Named functions don't include the LAMBDA( wrapper; arguments are declared in the side panel
MAP passes each cell; BYROW passes a whole row as a range
SCAN is REDUCE that returns every intermediate value
Unlike Apps Script custom functions, named functions recalculate instantly

Other Suites

  • Microsoft 365 — LET, LAMBDA, named LAMBDAs in Name Manager, same helpers
  • Apple iWork — recent Numbers has LET, LAMBDA and SCAN; no named functions

Platform Differences

  • Same everywhere.

⚠ Common Mistakes

  • Wrapping a named function's definition in another LAMBDA
  • Argument names that clash with cell references (A1, B2)
  • Using Apps Script for something a named function does faster

✓ Tips & Best Practices

  • Add descriptions and examples to named functions for teammates
  • Refactor long formulas into LET first, then into a named function
  • Keep a "function library" sheet and import from it

Quick Summary

  • LET — name steps
  • LAMBDA — define a function
  • Named functions — reusable in the file
  • MAP / BYROW / REDUCE / SCAN — loop over ranges
