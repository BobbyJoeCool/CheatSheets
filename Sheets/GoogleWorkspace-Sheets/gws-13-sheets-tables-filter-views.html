Structured Data in Sheets

Tables (Format › Convert to table) give a range a name, column types (number, date, dropdown, checkbox), banded formatting and structured references like Tasks[Status]. Filter views let each person filter or sort without changing what others see, which matters in shared sheets. Protected ranges stop accidental edits.

Notes

  • Convert: select data › ⌘⌥T / Ctrl+Alt+T
  • Column types validate entries; dropdown columns show coloured chips
  • Group by view: table menu › Create group by view
  • Filter (everyone sees it) vs filter view (only you, can be saved and shared by link)
  • Data › Protect sheets and ranges; choose who can edit

Automate It

  • Tables + filter views mean one shared sheet works for everyone without copies
  • Save filter views like "My open tasks" and bookmark their links

Other Suites

  • Microsoft 365 — Excel tables Ctrl+T, structured refs, slicers; no per-user filter views (Sheet Views in shared files)
  • Apple iWork — Numbers tables with header rows; filters affect everyone

Platform Differences

  • Browser — tables, filter views, protection
  • Offline — same
  • Mobile — use filter views; can't create tables

⚠ Common Mistakes

  • Turning on a normal filter in a shared sheet and hiding rows for everyone
  • Typing over a table's column type, causing validation warnings
  • Protecting the whole sheet and blocking teammates from input cells

✓ Tips & Best Practices

  • Name tables (click the table name) before writing formulas
  • Create filter views for each person or status and link them from a "Start here" tab
  • Use warnings, not blocks, for ranges people occasionally need to fix
