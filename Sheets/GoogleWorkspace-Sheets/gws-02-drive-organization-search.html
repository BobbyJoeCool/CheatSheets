Drive Organization & Search

My Drive vs Shared drives · Drive shortcuts · search operators · Priority & Activity · folder colours · storage cleanup

Find Files Instead of Filing Them

Drive search is fast and supports operators like type:, owner: and before:, so you rarely need deep folder trees. Shared drives (Workspace) belong to the team, not a person, so files survive when people leave. A shortcut (⇧Z) puts the same file in several folders without copying it.

Notes

  • / jumps to the Drive search box; click the sliders icon for advanced search
  • Shared with me only shows files; add them to My Drive with a shortcut
  • Shortcuts (⇧Z) are pointers; deleting a shortcut doesn't delete the file
  • Star important files (S); Starred works like a favourites list
  • Storage: drive.google.com/drive/quota lists the largest files

Drive Search & Keys

type:spreadsheet owner:me before:2026-01-01   # my old sheets
type:pdf "invoice" after:2026-09-01           # recent PDF invoices
owner:dana@acme.com is:starred                # Dana's starred files
title:"Q3 plan"                               # name only
to:me  /  from:me                             # shared with / by me

/              # focus search
⇧Z             # add shortcut to another folder
S              # star / unstar
.              # share selected file
N  /  ⇧F       # rename selected / new folder
⇧T  ⇧S  ⇧P     # new Doc / Sheet / Slides from Drive

Code Explained

Operators combine with spaces (AND); OR must be capitalised
Dates use YYYY-MM-DD
Drive keyboard shortcuts work when the file list has focus; ? shows them all
Searching for words inside PDFs and images works because Drive runs OCR

Other Suites

  • Microsoft 365 — OneDrive / SharePoint search, Add shortcut to My files, file Shared view
  • Apple iWork — iCloud Drive in Finder; Spotlight search and Finder tags

Platform Differences

  • Browser — operators, Activity panel, shortcuts
  • Drive for desktop — Finder / Explorer search, Spotlight indexes file names
  • Mobile — search with filters; fewer operators

⚠ Common Mistakes

  • Making copies of a file for each folder; use a shortcut so there's one version
  • Keeping team files in your own My Drive, so they disappear when you leave
  • Hunting through Shared with me instead of searching by owner

✓ Tips & Best Practices

  • Colour key folders (right-click › Organize › Folder colour)
  • Use the Activity panel (i details pane) to see who changed what
  • Empty Trash and sort by storage to free space

Quick Summary
