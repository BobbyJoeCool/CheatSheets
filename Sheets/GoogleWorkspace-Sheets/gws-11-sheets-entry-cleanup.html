Data Entry, Validation & Cleanup

Smart Fill ⌘⇧Y · fill down ⌘D · ⌘↩ fill selection · dropdowns · checkboxes · split text · remove duplicates · trim whitespace

Enter Fast, Keep It Clean

Smart Fill spots patterns (like Flash Fill) and offers to fill the column. Dropdowns and checkboxes make data entry consistent. The Data cleanup menu has Remove duplicates, Trim whitespace and Cleanup suggestions, and Split text to columns separates combined values.

Notes

  • Smart Fill: start typing a pattern; accept the grey suggestion with ⌘↩ or use ⌘⇧Y / Ctrl+Shift+Y
  • Dropdown: Insert › Dropdown (colour-coded chips) or Data › Data validation
  • Checkbox: Insert › Checkbox; stores TRUE / FALSE
  • Data › Data cleanup › Cleanup suggestions finds inconsistent values
  • Data › Split text to columns guesses the separator; change it if needed

Automate It

  • Cleanup suggestions handle one-off messes; a recorded macro (sheet 27) repeats the same fix weekly
  • Dropdowns from a range (=Lists!A2:A) update when the list changes

Data validation › Criteria: Dropdown (from a range) → =Lists!$A$2:$A

Code Explained

Fill down copies the top cell into the rest of the selection, adjusting relative references
Smart Fill results are formulas you can inspect, not just values
An open-ended range (A2:A) includes every future row
Validation can reject or just warn on invalid input

Other Suites

  • Microsoft 365 — Flash Fill Ctrl+E, Data Validation lists, Insert › Checkbox
  • Apple iWork — Numbers pop-up menus, checkboxes, autofill handle

Platform Differences

  • Browser — Smart Fill, cleanup suggestions, chips
  • Offline — entry and validation work; suggestions need a connection
  • Mobile — dropdowns and checkboxes work; no Smart Fill

⚠ Common Mistakes

  • Removing duplicates without keeping a copy; it can't be undone after you close the file
  • Typing dropdown values into each rule instead of pointing at a list range
  • Leaving trailing spaces that break lookups; run Trim whitespace

✓ Tips & Best Practices

  • Put all dropdown lists on one hidden "Lists" tab
  • Use colour-coded dropdown chips for status columns
  • Check Column stats before building a pivot
