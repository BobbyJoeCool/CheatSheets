Inbox Zero, the Gmail Way

Turn on keyboard shortcuts (Settings › See all settings › Keyboard shortcuts on) and Gmail becomes keyboard-driven: j / k to move, e to archive, r to reply. Search operators find anything, and any search can become a filter that labels, archives or forwards future mail automatically. Templates store canned replies.

Notes

  • ? shows every shortcut once they're enabled
  • Labels are like folders, but a message can have several
  • Create a filter: search, then the sliders icon › Create filter
  • Templates: Settings › Advanced › Templates on; then compose › ⋯ › Templates
  • Undo send: Settings › General › up to 30 seconds

Automate It

  • Filters that label, skip the inbox or forward mail matching a search
  • Templates for replies you send more than twice a week

Gmail Keys & Search

c          # compose            r / a / f   # reply / reply all / forward
j / k      # next / previous    o or ↩      # open
e          # archive            #           # delete
s          # star               l / v       # label / move to
x          # select             ⇧I / ⇧U     # mark read / unread
b          # snooze             /           # search
g i        # go to inbox        g s         # go to starred
⌘↩ / Ctrl+Enter                 # send

from:dana@acme.com has:attachment larger:5M older_than:1y
subject:(invoice OR receipt) after:2026/09/01 -label:paid
is:unread in:inbox category:primary

Code Explained

Single-key shortcuts only work after you turn them on in Settings
g then a letter jumps to a view (g i inbox, g t sent)
Dates in search use YYYY/MM/DD; older_than:1y / newer_than:7d are relative
- excludes, OR (capitals) and parentheses group

  • Browser — every shortcut and filter
  • Offline — Gmail offline mode (Chrome) reads and queues mail
  • Mobile — swipe actions, snooze, schedule send; no shortcuts or filters editor

⚠ Common Mistakes

  • Pressing letter keys while shortcuts are on and archiving mail by accident (undo with z)
  • Using labels like folders and never archiving, so the inbox stays full
  • Filters that skip the inbox without a label, so mail vanishes

✓ Tips & Best Practices

  • Use e (archive) as your default action; search finds everything later
  • Turn any useful search into a filter
  • Set undo send to 30 seconds

Quick Summary
