CSS, CSS Modules & Sass

global CSS · *.module.css · className={styles.x} · Sass · CSS ordering · clsx

Styling Options Built In

Next.js supports global CSS, CSS Modules (locally scoped class names), and Sass with no extra config beyond installing sass. CSS Modules are the safest default for component styles: every class is renamed to a unique hash, so names never collide. Global CSS is for resets, variables, and base element styles.

Rules

  • Global CSS can be imported anywhere, but keep it in the root layout
  • CSS Modules work in Server and Client Components
  • Production builds bundle and minify CSS automatically
  • Sass needs npm i -D sass (modern API in 16)

CSS Module

/* app/components/button.module.css */
.button { padding: 0.5rem 1rem; border-radius: 6px; }
.primary { background: var(--brand); color: white; }
.button:disabled { opacity: 0.5; }

// app/components/button.tsx
import styles from './button.module.css'
import clsx from 'clsx'

export function Button({ primary, ...props }: Props) {
  const c = clsx(styles.button, primary && styles.primary)
  return <button {...props} className={c} />
}

Global CSS + Sass

/* app/globals.css */
:root { --brand: #5c6bc0; }
*, *::before, *::after { box-sizing: border-box; }
body { font-family: var(--font-sans), sans-serif; }
/* import once in app/layout.tsx: './globals.css' */

/* app/card.module.scss */
$radius: 8px;
.card {
  border-radius: $radius;
  &:hover { box-shadow: 0 2px 8px rgb(0 0 0 / 0.2); }
}

⚠ Common Mistakes

  • Relying on import order between two modules to win a cascade fight; it can differ in production
  • Using styles['my-class'] typos; a missing key is undefined and silently renders no class
  • Importing a third-party global stylesheet inside a deep component instead of the root layout

✓ Tips & Best Practices

  • Use clsx (or cn with tailwind-merge) to combine conditional class names
  • Define design tokens as CSS variables in globals.css and reference them in modules
  • Use :global(.class) inside a module only for third-party overrides

Quick Summary

  • globals.css — import once in root layout
  • *.module.css — scoped class names
  • sass — install, then use .scss files
  • clsx — conditional class names
