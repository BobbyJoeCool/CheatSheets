Introduction & Rendering Model

App Router · Pages Router · Server Components · Turbopack · self-hosting

What Next.js Adds to React

Next.js is a full-stack React framework. React gives you components; Next.js adds file-based routing, server rendering, data fetching, caching, bundling (Turbopack), image/font optimization, and a production server. The App Router (app/) is the current model: components render on the server by default and only opt into the browser with 'use client'.

Version Notes (16.x)

  • 16.3 (Aug 2026); App Router bundles React 19.2+ canary
  • Requires Node.js 20.9+ and TypeScript 5.1+
  • Turbopack is the default bundler for dev and build
  • Majors ship roughly yearly; minors every few months

Hello, World (App Router)

// app/layout.tsx — required root layout
export default function RootLayout({ children }: LayoutProps<'/'>) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}

// app/page.tsx — the "/" route (a Server Component)
export default async function Home() {
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const repo = await res.json()
  return <h1>Hello, World — {repo.stargazers_count} stars</h1>
}

How It Renders

app/layout.tsx — wraps every page; must render <html> and <body>
app/page.tsx — a file named page makes the folder a public URL
async component — fetches on the server; no useEffect needed
LayoutProps<'/'> — global type helper generated by Next.js
Output is HTML + an RSC payload; only Client Components ship JS

⚠ Common Mistakes

  • Treating Next.js like a client-only SPA: fetching in useEffect throws away server rendering and adds a waterfall
  • Adding 'use client' to every file out of habit; it ships all that code to the browser
  • Following Pages Router tutorials (getServerSideProps) inside app/; those APIs do not exist there

✓ Tips & Best Practices

  • Start new projects with the App Router; mix in pages/ only during migrations
  • Run npx next info when filing bugs; it prints Node, Next, and React versions
  • Read version-matched docs from node_modules/next/dist/docs (linked from AGENTS.md)

Quick Summary

  • app/ — App Router, server-first rendering
  • page.tsx — makes a route public
  • layout.tsx — shared UI; root renders <html>
  • 'use client' — opt a subtree into the browser
  • Turbopack — default bundler in 16.x
