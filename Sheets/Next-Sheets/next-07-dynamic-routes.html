Sheet 07

Dynamic Routes

[slug] · [...slug] · [[...slug]] · params Promise · generateStaticParams · dynamicParams

Segments Filled at Request Time

Wrap a folder name in brackets to capture part of the URL. The captured values arrive in the params prop, which in Next.js 15+ is a Promise you must await. Export generateStaticParams() to prerender known values at build time; other values render on demand.

params Shapes

  • [id] → { id: string }
  • [...slug] → { slug: string[] }
  • [[...slug]] → { slug?: string[] }
  • Values arrive URL-decoded strings; parse numbers yourself

Dynamic Page with Static Params

// app/blog/[slug]/page.tsx
import { notFound } from 'next/navigation'
import { getPost, getAllSlugs } from '@/lib/posts'

export async function generateStaticParams() {
  const slugs = await getAllSlugs()           // ['intro', 'v16']
  return slugs.map((slug) => ({ slug }))     // prerendered at build
}

export default async function Post(props: PageProps<'/blog/[slug]'>) {
  const { slug } = await props.params        // must await
  const post = await getPost(slug)
  if (!post) notFound()                      // renders not-found.tsx
  return <article><h1>{post.title}</h1>{post.body}</article>
}

What Happens

generateStaticParams — returns one object per page to build
PageProps<'/blog/[slug]'> — typed params and searchParams
await props.params — sync access was removed in 16
notFound() — throws; no return needed
Unlisted slugs still work and are rendered on demand

⚠ Common Mistakes

  • Destructuring params synchronously ({ params: { slug } }); in 16 it is a Promise
  • Forgetting that [...slug] does not match the bare parent URL; use [[...slug]]
  • Returning raw strings from generateStaticParams; it must return objects keyed by segment name

✓ Tips & Best Practices

  • Validate params with Zod or a lookup before querying; they are user input
  • Use PageProps<'/route'> instead of hand-writing { params: Promise<...> }
  • Prerender your most-visited slugs and let the long tail render on demand

Quick Summary

  • [slug] — one dynamic segment
  • [...slug] / [[...slug]] — catch-all / optional
  • await params — params is a Promise
  • generateStaticParams — prerender known values
