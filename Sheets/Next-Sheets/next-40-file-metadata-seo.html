Special Metadata Files

Some metadata is easier as files placed in app/: icons, Open Graph images, sitemap.xml, robots.txt, and the web app manifest. Each can be a static file or a .ts/.tsx file that generates it. Generated Open Graph images use ImageResponse from next/og, which turns JSX into a PNG.

Placement

  • Root app/ files apply site-wide
  • Segment files (e.g. app/blog/[slug]/) apply per route
  • Generated files are static unless they use request data
  • Metadata image params are a Promise in 16

Dynamic OG Image

// app/blog/[slug]/opengraph-image.tsx
import { ImageResponse } from 'next/og'
export const size = { width: 1200, height: 630 }
export const contentType = 'image/png'
export const alt = 'Blog post cover'
export default async function OG(
  { params }: { params: Promise<{ slug: string }> }) {
  const post = await getPost((await params).slug)
  return new ImageResponse(
    <div style={{ display: 'flex', width: '100%', height: '100%',
      alignItems: 'center', justifyContent: 'center',
      background: '#141720', color: 'white', fontSize: 64 }}>
      {post.title}
    </div>, size)
}

Notes

size, contentType, alt — become meta tags
ImageResponse supports flexbox and a subset of CSS
Every <div> with several children needs display: flex
Load fonts as ArrayBuffer via the fonts option

sitemap.ts + robots.ts

// app/sitemap.ts
import type { MetadataRoute } from 'next'
export default async function sitemap()
  : Promise<MetadataRoute.Sitemap> {
  const posts = await getPosts()
  return [{ url: 'https://acme.com', priority: 1 },
    ...posts.map((p) => ({
      url: `https://acme.com/blog/${p.slug}`,
      lastModified: p.updatedAt })),
  ]
}
// app/robots.ts
export default function robots(): MetadataRoute.Robots {
  return { rules: { userAgent: '*', allow: '/' },
    sitemap: 'https://acme.com/sitemap.xml' } }

⚠ Common Mistakes

  • Using CSS grid or display: block layouts in ImageResponse; only flexbox is supported
  • Hard-coding localhost URLs in the sitemap; use the production origin
  • Placing favicon.ico in a nested segment; it only works at the app/ root

✓ Tips & Best Practices

  • Split sitemaps over 50,000 URLs with generateSitemaps()
  • Keep OG images simple and test them with a social preview tool
  • Use opengraph-image.alt.txt for static OG image alt text

Quick Summary

  • ImageResponse — JSX → PNG (next/og)
  • sitemap.ts / robots.ts — SEO files
