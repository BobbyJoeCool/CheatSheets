Sheet 02

Creating a Project

create-next-app · --ts · --tailwind · --src-dir · --app · AGENTS.md

Scaffolding a New App

create-next-app generates a ready-to-run project. Accepting the recommended defaults gives you TypeScript, ESLint, Tailwind CSS, the App Router, Turbopack, and an AGENTS.md file for coding agents. Every prompt also has a flag, so the setup can be scripted for CI or templates.

Requirements

  • Node.js 20.9+ (LTS); Node 18 is no longer supported
  • Works with npm, pnpm, Yarn, and Bun
  • --yes reuses previous answers or the defaults
  • next dev serves on http://localhost:3000

Create and Run

npx create-next-app@latest my-app            # interactive prompts
npx create-next-app@latest my-app --yes      # accept defaults
npx create-next-app@latest my-app --ts --tailwind --eslint \
  --app --src-dir --import-alias "@/*" --use-pnpm
npx create-next-app@latest api-only --api    # route handlers only
npx create-next-app@latest -e with-docker    # official example

cd my-app
npm run dev        # next dev   → http://localhost:3000
npm run build      # next build → .next/
npm run start      # next start (production server)

What You Get

package.json scripts: dev, build, start, lint
app/layout.tsx, app/page.tsx, app/globals.css
next.config.ts, tsconfig.json, eslint.config.mjs
AGENTS.md + CLAUDE.md pointing agents at bundled docs
public/ for static files served from /

⚠ Common Mistakes

  • Running an old global create-next-app; always use @latest so you get 16.x templates
  • Using npm run dev -p 4000: npm needs -- before flags (npm run dev -- -p 4000)
  • Setting PORT in .env; the server boots before .env loads, so use the shell env

✓ Tips & Best Practices

  • Pass every flag in CI so scaffolding never blocks on a prompt
  • Keep --src-dir if you want config files separated from app code
  • Use npx @next/codemod@canary upgrade latest to bring older apps forward

Quick Summary

  • npx create-next-app@latest — scaffold a project
  • --yes — accept recommended defaults
  • --api — route-handler-only project
  • npm run dev — dev server on port 3000
