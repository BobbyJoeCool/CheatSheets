Running Next.js Yourself

Any Node.js host can run next build && next start with every feature supported. For containers, set output: 'standalone': the build copies only the files and dependencies needed into .next/standalone, producing a small image. When running multiple instances, configure a shared cache handler and a stable deployment ID.

Self-Hosting Checklist

  • Put a reverse proxy (nginx, Caddy) in front
  • Serve .next/static with long cache headers or a CDN
  • Image optimization uses sharp automatically
  • Set NEXT_SERVER_ACTIONS_ENCRYPTION_KEY for many instances

Standalone Dockerfile

FROM node:22-alpine AS deps
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci

FROM node:22-alpine AS build
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm run build                      # next.config: output: 'standalone'

FROM node:22-alpine AS run
WORKDIR /app
ENV NODE_ENV=production PORT=3000 HOSTNAME=0.0.0.0
COPY --from=build /app/.next/standalone ./
COPY --from=build /app/.next/static ./.next/static
COPY --from=build /app/public ./public
USER node
CMD ["node", "server.js"]

Notes

standalone — traces only required node_modules
static and public must be copied manually
server.js replaces next start in standalone mode
HOSTNAME=0.0.0.0 — listen outside the container
Pass runtime env vars at docker run, not in the image

⚠ Common Mistakes

  • Forgetting to copy .next/static into the standalone image; pages load without JS or CSS
  • Baking secrets into the image with ENV; pass them at runtime instead
  • Running several instances with the default in-memory cache and expecting shared invalidation

✓ Tips & Best Practices

  • Use next start --keepAliveTimeout 70000 behind AWS ALB-style load balancers
  • Run the container as a non-root user (USER node)
  • Use the official with-docker example as a starting point

Quick Summary

  • next start — full-feature Node server
  • output: 'standalone' — small Docker images
  • cacheHandlers — shared cache across instances
  • Copy .next/static + public yourself
