next/image

<Image> · width/height · fill · sizes · preload · remotePatterns · qualities · placeholder="blur"

Optimized Images

<Image> from next/image resizes, compresses, and converts images to modern formats (WebP/AVIF) on demand, serves a responsive srcset, lazy-loads by default, and reserves space to prevent layout shift. Remote images must be allow-listed in next.config.

16.x Changes

  • priority deprecated → use preload
  • images.qualities defaults to [75]
  • minimumCacheTTL default is now 4 hours
  • Local src with query strings needs localPatterns

Static, Remote, and Fill Images

import Image from 'next/image'
import hero from '@/public/hero.jpg'          // static import

<Image src={hero} alt="Mountain lake" placeholder="blur" preload />
// width/height/blurDataURL inferred from the file

<Image src="https://cdn.example.com/u/42.png" alt="Avatar"
  width={64} height={64} className="rounded-full" />

<div style={{ position: 'relative', aspectRatio: '16 / 9' }}>
  <Image src={post.cover} alt={post.title} fill
    sizes="(max-width: 768px) 100vw, 50vw"
    style={{ objectFit: 'cover' }} />
</div>

// next.config.ts
images: { remotePatterns: [new URL('https://cdn.example.com/**')],
          qualities: [50, 75, 90] }

Notes

Static import — dimensions and blur placeholder are automatic
Remote src — width and height required (or fill)
fill — parent must be position: relative (or absolute/fixed)
sizes — tells the browser which srcset entry to pick
preload — only for the LCP image above the fold

⚠ Common Mistakes

  • Using fill without sizes; the browser downloads a full-viewport image for a small card
  • Adding preload to many images; it competes for bandwidth with the real LCP image
  • Expecting quality={80} to work without listing 80 in images.qualities; it snaps to 75

✓ Tips & Best Practices

  • Static-import local images to get dimensions and blur placeholders for free
  • Use a loaderFile for Cloudinary/Imgix so their CDN does the resizing
  • Self-hosting: sharp is used automatically for fast optimization

Quick Summary

  • <Image> — responsive, lazy, optimized
  • fill + sizes — fluid layouts
  • preload — replaces priority for LCP
  • remotePatterns — allow remote hosts
