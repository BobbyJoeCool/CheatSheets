Sheet 10

Loading, Error & Not Found UI

loading.tsx · error.tsx · retry() · global-error.tsx · not-found.tsx · notFound() · forbidden()

Built-In Boundaries

Special files turn into React boundaries automatically. loading.tsx becomes a Suspense fallback shown instantly while the segment streams. error.tsx becomes an error boundary (a Client Component) that catches render errors below it. not-found.tsx renders when you call notFound() or no route matches.

16.x Updates

  • error.tsx gets a retry() prop (stable in 16.3)
  • retry() re-fetches; old reset() only re-renders
  • catchError from next/error builds custom boundaries
  • forbidden() / unauthorized() need experimental.authInterrupts

The Three Files

// app/dashboard/loading.tsx
export default function Loading() { return <p>Loading dashboard…</p> }

// app/dashboard/error.tsx
'use client'                                  // must be a Client Component
export default function Error({ error, retry }: {
  error: Error & { digest?: string }; retry: () => void }) {
  return (
    <div role="alert">
      <p>Couldn't load data ({error.digest})</p>
      <button onClick={() => retry()}>Try again</button>
    </div>
  )
}

// app/blog/[slug]/not-found.tsx
export default function NotFound() { return <h2>Post not found</h2> }

Notes

loading.tsx wraps page.tsx in <Suspense> for you
error.digest — hash that matches the server log entry
In production, server error messages are replaced with a generic one
error.tsx doesn't catch errors in its own segment's layout.tsx
global-error.tsx must render its own <html> and <body>

⚠ Common Mistakes

  • Leaving 'use client' off error.tsx; error boundaries must be Client Components
  • Wrapping notFound() or redirect() in try/catch; use unstable_rethrow(err) in the catch
  • Expecting a 404 status after streaming starts; once the shell is sent the status is already 200

✓ Tips & Best Practices

  • Prefer retry() over reset() so Server Components re-fetch on recovery
  • Log error.digest to correlate client reports with server logs
  • Put loading.tsx low in the tree so more of the page shows immediately

Quick Summary

  • loading.tsx — automatic Suspense fallback
  • error.tsx — client error boundary with retry()
  • not-found.tsx + notFound() — 404 UI
  • global-error.tsx — root layout failures
