Code Before Every Request

proxy.ts (at the project root or in src/) runs before routing for every matching request. It can redirect, rewrite, set headers and cookies, or answer directly. Next.js 16 renamed middleware.ts to proxy.ts to make the network boundary clear, and Proxy runs on the Node.js runtime.

16.x Facts

  • Export proxy (named) or a default function
  • runtime config isn't allowed in proxy files
  • middleware.ts still works but is deprecated (Edge only)
  • Codemod: npx @next/codemod@canary middleware-to-proxy .

Auth Redirect + Locale Rewrite

// proxy.ts
import { NextResponse, type NextRequest } from 'next/server'
export function proxy(request: NextRequest) {
  const { pathname } = request.nextUrl
  const loggedIn = request.cookies.has('session')     // optimistic check
  if (pathname.startsWith('/dashboard') && !loggedIn) {
    return NextResponse.redirect(new URL('/login', request.url))
  }
  if (pathname === '/') {
    const al = request.headers.get('accept-language') ?? ''
    const lang = al.startsWith('de') ? 'de' : 'en'
    return NextResponse.rewrite(new URL(`/${lang}`, request.url))
  }
  const res = NextResponse.next(); res.headers.set('x-pathname', pathname)
  return res
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico).*)'],
}

Notes

redirect — changes the browser URL
rewrite — serves /en while the URL stays /
next() — continue, optionally adding headers
Cookie check is a fast hint; verify sessions again in code

⚠ Common Mistakes

  • Doing database lookups in proxy for every request; it adds latency to every page and asset
  • Relying on proxy as the only auth layer; Server Actions and handlers must check again
  • Building matchers from variables; matchers must be static constants

✓ Tips & Best Practices

  • Exclude _next/static, _next/image, and metadata files in the matcher
  • Pass data downstream with request headers via NextResponse.next({ request: { headers } })
  • Unit test matchers with unstable_doesProxyMatch from next/experimental/testing/server

Quick Summary

  • proxy.ts — runs before routing (Node.js)
  • config.matcher — limit where it runs
  • redirect / rewrite / next — responses
  • Renamed from middleware.ts in 16
