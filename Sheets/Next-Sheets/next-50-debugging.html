Sheet 50

Debugging

VS Code launch config · NODE_OPTIONS='--inspect' · server vs browser logs · React DevTools · DevTools MCP

Finding the Problem Fast

Next.js code runs in two places, so logs and breakpoints do too: Server Components and Actions log to the terminal; Client Components log to the browser console. Attach a debugger to the server with --inspect, use the browser's DevTools for the client, and use the Next.js DevTools overlay for errors, routes, and cache insights.

Built-In Help

  • Error overlay with source-mapped stacks
  • Server Function calls logged in the dev terminal (16.2+)
  • Next.js DevTools MCP for AI agents
  • next build --debug-prerender for build errors

VS Code launch.json

{
  "version": "0.2.0",
  "configurations": [
    { "name": "Next.js: server", "type": "node-terminal",
      "request": "launch", "command": "npm run dev -- --inspect" },
    { "name": "Next.js: client", "type": "chrome",
      "request": "launch", "url": "http://localhost:3000" },
    { "name": "Next.js: full stack", "type": "node", "request": "launch",
      "program": "${workspaceFolder}/node_modules/next/dist/bin/next",
      "runtimeArgs": ["--inspect"], "skipFiles": ["<node_internals>/**"],
      "serverReadyAction": { "action": "debugWithChrome",
        "pattern": "- Local:.+(https?://.+)", "uriFormat": "%s" } }
  ]
}

Notes

node-terminal — breakpoints in Server Components and Actions
chrome — breakpoints in Client Components
Full stack — launches server, then opens Chrome attached
Or next dev --inspect / next start --inspect (16.2+)
debugger; statements work in both environments

⚠ Common Mistakes

  • Looking for Server Component console.log output in the browser; it prints in the terminal
  • Debugging a production-only bug in next dev; reproduce with next build && next start
  • Ignoring error.digest; it's the key to the full server-side stack trace in logs

✓ Tips & Best Practices

  • Use next build --debug-build-paths to rebuild just the failing route
  • Toggle Suspense and error boundaries in React DevTools to test fallback UI
  • Connect your coding agent to the Next.js DevTools MCP for logs and route context

Quick Summary

  • Server logs — terminal; client logs — browser
  • --inspect — attach a Node debugger
  • Next.js DevTools — overlay + insights
  • --debug-prerender — readable build errors
