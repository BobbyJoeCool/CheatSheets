Without Cache Components

Apps that don't enable cacheComponents still use the previous model: caching through fetch options, the Data Cache, and route segment config exports. It remains supported in 16.x. When you turn on Cache Components, dynamic, revalidate, fetchCache, and dynamicParams segment exports are no longer available, so plan the migration.

Key Differences

  • Old: implicit static unless a dynamic API is used
  • New: dynamic unless you add 'use cache'
  • Old: ISR via revalidate export
  • New: ISR via cacheLife profiles

Previous-Model Patterns

// Data Cache with time-based and tag revalidation
const res = await fetch('https://api.example.com/posts', {
  next: { revalidate: 3600, tags: ['posts'] },
})

// Route segment config (page.tsx / layout.tsx / route.ts)
export const revalidate = 60              // ISR every 60 s
export const dynamic = 'force-static'     // or 'force-dynamic'
export const fetchCache = 'default-cache'

// Non-fetch data
import { unstable_cache } from 'next/cache'
const getStats = unstable_cache(
  async () => db.stats.aggregate(),
  ['stats'], { revalidate: 300, tags: ['stats'] })

Notes

next.revalidate — seconds before background refetch
tags — invalidate with revalidateTag('posts', 'max')
force-static — treat dynamic APIs as empty at build
unstable_cache persists across deploys (unlike 'use cache')

⚠ Common Mistakes

  • Enabling cacheComponents while pages still export revalidate or dynamic; the build reports them
  • Assuming fetch is cached by default as in Next 14; it has been uncached since 15
  • Migrating everything at once; adopt route by route following the dev overlay

✓ Tips & Best Practices

  • Use the official guide 'Migrating to Cache Components' and its agent Skill for large apps
  • Keep unstable_cache for data that must persist across deploys
  • Search the codebase for export const dynamic before flipping the flag

Quick Summary

  • next: { revalidate, tags } — Data Cache
  • export const revalidate — route ISR
  • unstable_cache — non-fetch caching
  • Cache Components removes segment caching exports
