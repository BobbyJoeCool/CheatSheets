⚠ Common Mistakes

  • Assuming fetch is cached — in current Next it isn't unless you use "use cache"
  • Server Actions without auth checks — anyone can POST to them
  • Putting secrets in NEXT_PUBLIC_ variables

✓ Tips & Best Practices

  • Tag cached data and call revalidateTag after writes
  • Use useActionState for form errors and pending state
  • Deploy with output: "standalone" for small Docker images

Quick Summary

  • "use cache" + cacheLife + cacheTag control caching
  • Server Actions handle forms; route handlers serve APIs
  • proxy.ts runs before every matched request
  • next/image, next/font, metadata for performance and SEO
