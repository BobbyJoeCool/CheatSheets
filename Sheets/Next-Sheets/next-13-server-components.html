Server Components

default in app/ · async components · direct DB access · server-only · no hooks

Rendering on the Server

Every component in app/ is a React Server Component (RSC) unless marked otherwise. Server Components run only on the server (at build time or per request), can be async, and can read databases, files, and secrets directly. Their code is never sent to the browser, which keeps bundles small.

What They Can't Do

  • No useState, useEffect, or other client hooks
  • No event handlers (onClick, onChange)
  • No browser APIs (window, localStorage)
  • Props passed to Client Components must be serializable

Query the Database in a Component

// app/orders/page.tsx  — a Server Component (no directive)
import 'server-only'                     // build error if imported by client
import { db } from '@/lib/db'
import { OrderFilter } from './order-filter' // a Client Component

export default async function OrdersPage() {
  const orders = await db.order.findMany({
    orderBy: { createdAt: 'desc' }, take: 20,
  })
  const apiKey = process.env.STRIPE_SECRET_KEY  // safe: never shipped
  return (
    <section>
      <OrderFilter />                       {/* interactive island */}
      <ul>{orders.map((o) => <li key={o.id}>{o.total}</li>)}</ul>
    </section>
  )
}

Notes

No directive needed: app/ defaults to server
import 'server-only' guards modules holding secrets or DB code
await directly in the component body
Secrets in non-NEXT_PUBLIC_ env vars stay on the server
Client Components can be rendered as children of server ones

⚠ Common Mistakes

  • Adding hooks to a Server Component and getting a build error; split the interactive part into a client file
  • Passing functions or class instances as props to Client Components; only serializable values cross the boundary
  • Importing a DB module from a Client Component; add server-only so the mistake fails at build time

✓ Tips & Best Practices

  • Keep pages and layouts as Server Components; push 'use client' to the leaves
  • Heavy libraries used only for rendering (syntax highlighters, markdown) belong on the server
  • Use React.cache() to dedupe the same query across components in one request

Quick Summary

  • Default in app/ — Server Component
  • async components — fetch with await
  • server-only — guard secret-holding modules
  • No hooks or event handlers on the server
