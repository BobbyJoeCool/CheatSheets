Route Handler Patterns

JSON / FormData bodies · cookies · streaming · CORS · webhooks · caching GET

Real-World Endpoints

Route Handlers use standard Web APIs, so most patterns are plain Request/Response code. Next.js adds helpers for cookies and headers, supports streaming responses (useful for AI output and large exports), and, with Cache Components, lets you cache GET logic with 'use cache' in a helper function.

Patterns

  • Webhooks: verify the signature on the raw body
  • CORS: handle OPTIONS preflight explicitly
  • Streaming: return a ReadableStream
  • Cache GET work with a 'use cache' helper

Verified Webhook

// app/api/stripe/route.ts
import Stripe from 'stripe'
import { revalidateTag } from 'next/cache'
const stripe = new Stripe(process.env.STRIPE_KEY!)

export async function POST(req: Request) {
  const raw = await req.text()            // raw body
  const sig = req.headers.get('stripe-signature')!
  let event: Stripe.Event
  try {
    event = stripe.webhooks.constructEvent(
      raw, sig, process.env.STRIPE_WEBHOOK_SECRET!)
  } catch {
    return new Response('Bad signature', { status: 400 })
  }
  if (event.type === 'product.updated')
    revalidateTag('products', 'max')
  return Response.json({ received: true })
}

Streaming + CORS

// app/api/stream/route.ts
export async function GET() {
  const enc = new TextEncoder()
  const stream = new ReadableStream({
    async start(ctrl) {
      for (const word of ['Hello', ' ', 'world']) {
        ctrl.enqueue(enc.encode(word))
        await new Promise((r) => setTimeout(r, 200))
      }
      ctrl.close()
    },
  })
  return new Response(stream, {
    headers: { 'Content-Type': 'text/plain' } })
}

export function OPTIONS() {        // CORS preflight
  return new Response(null, { status: 204, headers: {
    'Access-Control-Allow-Origin': 'https://app.acme.com',
    'Access-Control-Allow-Methods': 'GET, POST' } })
}

⚠ Common Mistakes

  • Calling req.json() before verifying a webhook signature; the signature covers the raw text
  • Reading the body twice; a request body stream can only be consumed once
  • Using Access-Control-Allow-Origin: * with credentials; browsers reject it

✓ Tips & Best Practices

  • Return new Response(stream) for long exports so memory stays flat
  • Use after() to log or send analytics without delaying the response
  • Set export const maxDuration = 60 for slow handlers on platforms that support it

Quick Summary

  • req.text() — raw body for signatures
  • ReadableStream — streamed responses
  • OPTIONS — CORS preflight
  • cookies() / headers() — async helpers
