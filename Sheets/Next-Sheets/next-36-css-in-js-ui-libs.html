CSS-in-JS & Component Libraries

styled-components registry · client-only constraint · shadcn/ui · Radix · server-compatible libraries

Libraries and the Server Boundary

Runtime CSS-in-JS libraries (styled-components, Emotion) need React context and run in the browser, so they only work in Client Components and need a style registry to collect styles during server rendering. Zero-runtime options (CSS Modules, Tailwind, vanilla-extract, Panda) work in Server Components with no extra setup.

Compatibility

  • styled-components: client only + registry
  • Emotion: client only; limited App Router support
  • vanilla-extract / Panda / StyleX: build-time, server-safe
  • shadcn/ui: copied source using Tailwind + Radix

styled-components Registry

// next.config.ts
const nextConfig: NextConfig = { compiler: { styledComponents: true } }

// lib/registry.tsx
'use client'
import { useState } from 'react'
import { useServerInsertedHTML } from 'next/navigation'
import { ServerStyleSheet, StyleSheetManager } from 'styled-components'

export function StyledRegistry({ children }: { children: React.ReactNode }) {
  const [sheet] = useState(() => new ServerStyleSheet())
  useServerInsertedHTML(() => {
    const styles = sheet.getStyleElement()
    sheet.instance.clearTag()
    return <>{styles}</>
  })
  if (typeof window !== 'undefined') return <>{children}</>
  return (
    <StyleSheetManager sheet={sheet.instance}>{children}</StyleSheetManager>)
}
// app/layout.tsx → <body><StyledRegistry>{children}</StyledRegistry></body>

How It Works

compiler.styledComponents — SWC transform for SSR + display names
useServerInsertedHTML — inject collected <style> tags while streaming
clearTag() — avoid duplicating styles across chunks
Every styled component file still needs 'use client'

⚠ Common Mistakes

  • Using styled.div in a Server Component; runtime CSS-in-JS needs 'use client'
  • Skipping the registry; styles load after hydration and the page flashes unstyled
  • Wrapping the whole app in a UI library provider when only a few widgets need it

✓ Tips & Best Practices

  • Prefer zero-runtime styling for new App Router projects
  • Interactive primitives (dialogs, menus) are client components; keep the pages around them server-rendered
  • Check each library's App Router docs for a ready-made Next.js integration package
