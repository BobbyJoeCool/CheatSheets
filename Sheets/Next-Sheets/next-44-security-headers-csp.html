Sheet 44

Security Headers & CSP

headers() in config · CSP nonce via proxy · NEXT_PUBLIC_ exposure · X-Frame-Options · HSTS

Hardening Responses

Add static security headers for every route through headers() in next.config.ts. A strict Content Security Policy with a per-request nonce has to be generated in proxy.ts; Next.js reads the nonce from the request's CSP header and applies it to its own scripts. Using nonces forces pages to render dynamically.

Exposure Rules

  • NEXT_PUBLIC_* env vars are inlined into client JS
  • Everything else stays server-side
  • Error messages from Server Components are hidden in production
  • Source maps are off for the browser by default

Static Headers (next.config.ts)

const security = [
  { key: 'Strict-Transport-Security',
    value: 'max-age=63072000; includeSubDomains' },
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'X-Frame-Options', value: 'DENY' },
  { key: 'Referrer-Policy',
    value: 'strict-origin-when-cross-origin' },
  { key: 'Permissions-Policy',
    value: 'camera=(), microphone=()' },
]
const nextConfig: NextConfig = {
  poweredByHeader: false,
  async headers() {
    return [{ source: '/(.*)', headers: security }]
  },
}

Nonce CSP (proxy.ts)

export function proxy(req: NextRequest) {
  const nonce = btoa(crypto.randomUUID())
  const csp = [
    `default-src 'self'`,
    `script-src 'self' 'nonce-${nonce}' 'strict-dynamic'`,
    `style-src 'self' 'nonce-${nonce}'`,
    `img-src 'self' blob: data:`,
    `frame-ancestors 'none'`,
  ].join('; ')
  const headers = new Headers(req.headers)
  headers.set('x-nonce', nonce)
  headers.set('Content-Security-Policy', csp)
  const res = NextResponse.next({ request: { headers } })
  res.headers.set('Content-Security-Policy', csp)
  return res
}
// read it: (await headers()).get('x-nonce')

⚠ Common Mistakes

  • Adding a nonce CSP and keeping pages static; nonces require dynamic rendering per request
  • Prefixing secrets with NEXT_PUBLIC_ to 'make them work' in the client; they're now public
  • Forgetting to apply the CSP to the response as well as the forwarded request

✓ Tips & Best Practices

  • Exclude _next/static, _next/image, and prefetches from the CSP proxy matcher
  • Start with Content-Security-Policy-Report-Only to find violations safely
  • Set poweredByHeader: false to drop the X-Powered-By header

Quick Summary

  • headers() — static security headers
  • proxy nonce — strict per-request CSP
  • NEXT_PUBLIC_ — public by design
  • poweredByHeader: false — hide the stack
