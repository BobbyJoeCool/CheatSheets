File-System Routing

page.tsx · route segments · nested folders · index route · default export

Folders Are URLs

Every folder inside app/ is a route segment, and the path of folders from app/ down to a page.tsx is the URL. A route becomes public only when its folder contains a page file whose default export is a React component. The page.tsx directly inside app/ is the index route /.

Rules

  • Page files: .tsx, .ts, .jsx, .js (see pageExtensions)
  • Pages can be async Server Components
  • Segment names become URL text exactly (keep them lowercase)
  • Unknown URLs render app/not-found.tsx

Folder → URL Mapping

app/page.tsx                        →  /
app/about/page.tsx                  →  /about
app/blog/page.tsx                   →  /blog
app/blog/[slug]/page.tsx            →  /blog/hello-world
app/shop/[...path]/page.tsx         →  /shop/a/b/c
app/(marketing)/pricing/page.tsx    →  /pricing
app/_lib/db.ts                      →  (private, never routed)
app/dashboard/settings/page.tsx     →  /dashboard/settings
app/api/users/route.ts              →  /api/users  (endpoint)

Reading the Map

Each / in the URL is one folder level
[slug] matches any single segment value
(marketing) organizes files without adding to the URL
_lib is ignored by the router entirely
route.ts returns a Response, not UI

A Minimal Page

// app/about/page.tsx
import type { Metadata } from 'next'

export const metadata: Metadata = { title: 'About' }

export default function AboutPage() {
  return <h1>About us</h1>
}

⚠ Common Mistakes

  • Using a named export (export function Page) instead of export default; the route 404s
  • Creating app/about.tsx like the Pages Router; App Router needs app/about/page.tsx
  • Mixed-case folder names (/AboutUs) that produce awkward, case-sensitive URLs

✓ Tips & Best Practices

  • Colocate components beside the page that uses them; only page is public
  • Use typedRoutes: true so links to missing routes fail type-checking
  • Check the next build route list to confirm every URL you expect exists

Quick Summary

  • page.tsx — default export makes the URL public
  • Folder nesting — URL path segments
  • app/page.tsx — the index route /
  • not-found.tsx — unmatched URLs
