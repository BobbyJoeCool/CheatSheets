Head Tags From Layouts and Pages

Export a metadata object or an async generateMetadata() function from any layout or page (Server Components only) and Next.js renders the matching <head> tags. Metadata merges from the root down, so layouts set defaults and pages override them. viewport and themeColor live in a separate viewport export.

Rules

  • Server Components only (not 'use client' files)
  • Shallow merge: nested objects like openGraph are replaced
  • fetch calls in generateMetadata are memoized with the page
  • Metadata can stream after the UI for bots that allow it

Static Defaults + Dynamic Page

// app/layout.tsx
import type { Metadata, Viewport } from 'next'
export const metadata: Metadata = {
  metadataBase: new URL('https://acme.com'),
  title: { default: 'Acme', template: '%s | Acme' },
  openGraph: { siteName: 'Acme', type: 'website' },
}
export const viewport: Viewport = { themeColor: '#5c6bc0' }
// app/blog/[slug]/page.tsx
export async function generateMetadata(
  props: PageProps<'/blog/[slug]'>): Promise<Metadata> {
  const { slug } = await props.params
  const post = await getPost(slug)                // deduped with page
  return { title: post.title,                     // 'Hello | Acme'
    openGraph: { images: [post.cover] },
    alternates: { canonical: `/blog/${slug}` } }
}

Notes

metadataBase — makes relative URLs absolute
template — %s replaced by child titles
title: { absolute: 'X' } — ignore the template
Nested openGraph replaces the parent's entirely
Use React.cache for non-fetch data in both functions

⚠ Common Mistakes

  • Exporting metadata from a 'use client' file; it's ignored with a build error
  • Putting themeColor in metadata; it moved to the viewport export
  • Forgetting metadataBase; relative Open Graph image URLs break in social previews

✓ Tips & Best Practices

  • Set title.template once in the root layout for consistent titles
  • Share the data fetch between generateMetadata and the page via React.cache
  • Repeat shared openGraph fields in pages that override it

Quick Summary
