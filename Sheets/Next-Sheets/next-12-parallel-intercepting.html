Parallel & Intercepting Routes

@slot · default.tsx · (.) · (..) · (...) · modal pattern · conditional slots

Several Pages in One Layout

Parallel routes render multiple pages in the same layout at once. Each @slot folder is passed to the parent layout as a prop. Intercepting routes load a route inside the current layout on client navigation (for example, a photo opens in a modal) while a direct visit still renders the full page.

Rules

  • Slots are not URL segments: @team/members → /members
  • Every slot needs a default.tsx (build fails without it in 16)
  • default.tsx is shown when a slot has no match after reload
  • Interception happens only on soft navigation

Photo Modal Pattern

app/
├─ layout.tsx                 # receives { children, modal }
├─ @modal/
│  ├─ default.tsx             # export default () => null
│  └─ (.)photo/[id]/page.tsx  # modal version (intercepted)
├─ photo/[id]/page.tsx        # full page on direct visit
└─ page.tsx                   # gallery with <Link href="/photo/1">

// app/layout.tsx
export default function Layout({ children, modal }: LayoutProps<'/'>) {
  return <html><body>{children}{modal}</body></html>
}

How It Plays Out

Click /photo/1 in the gallery → @modal renders the modal
Refresh or share the link → full photo/[id]/page.tsx
(.) intercepts a sibling segment at the same level
Close with router.back() from the modal
modal prop name comes from the @modal folder

⚠ Common Mistakes

  • Omitting default.tsx for a slot; Next.js 16 fails the build instead of guessing
  • Counting (..) by folders on disk; it follows route segments, so groups and slots don't count
  • Expecting interception on a hard refresh; direct loads always render the real page

✓ Tips & Best Practices

  • Return null from @modal/default.tsx so the modal is hidden by default
  • Add @modal/[...catchAll]/page.tsx returning null to close modals on navigation
  • Use slots to give each dashboard panel its own loading.tsx and error.tsx

Quick Summary

  • @slot — parallel route passed as a layout prop
  • default.tsx — required fallback per slot
  • (.), (..), (...) — interception levels
  • Modal = @modal slot + intercepted route
