The next Command

The next CLI runs every phase of the app. next dev gives hot reloading and the DevTools overlay, next build produces an optimized .next/ folder, and next start serves it. In 16.x next lint is removed: run ESLint or Biome directly. Dev output goes to .next/dev, so dev and build can run at the same time.

16.x Changes

  • Turbopack is default; opt out with --webpack
  • next lint removed; next build no longer lints
  • next upgrade and next experimental-analyze added in 16.1
  • A lockfile blocks two next dev runs in one project

Everyday Commands

next dev                        # Turbopack dev server on :3000
next dev -p 4000 -H 0.0.0.0     # custom port, reachable on LAN
next dev --experimental-https   # self-signed HTTPS for OAuth/webhooks
next dev --inspect              # attach a Node debugger (16.1+)
next build                      # production build → .next/
next build --webpack            # opt out of Turbopack
next build --debug-prerender    # readable prerender errors
next start -p 8080              # serve the production build
next typegen && tsc --noEmit    # route types without a build
next info                       # versions for bug reports
next upgrade                    # bump Next.js (16.1+)
next experimental-analyze       # Turbopack bundle analyzer

Notes

-p / PORT — port; PORT cannot come from .env
--debug-prerender — dev-only; never deploy that build
typegen — generates PageProps, LayoutProps, next-env.d.ts
experimental-analyze --output writes to .next/diagnostics

⚠ Common Mistakes

  • Calling next lint in CI after upgrading; the command no longer exists in 16
  • Assuming next build catches lint errors; add a separate lint step
  • Running tsc without next typegen first; route helper types will be missing

✓ Tips & Best Practices

  • Use next build --debug-build-paths="app/blog/**" to rebuild only a few routes while debugging
  • Add .next/ and next-env.d.ts to .gitignore
  • Turn telemetry off with next telemetry --disable if policy requires it

Quick Summary

  • next dev — HMR dev server (Turbopack)
  • next build / next start — production build and server
  • next typegen — route types for CI
  • next lint — removed; use ESLint or Biome
