Sheet 17

Fetching in Server Components

async/await fetch() · ORM queries · Promise.all · preload pattern · React cache()

Data Where You Render

In the App Router you fetch data by awaiting it inside an async Server Component: fetch(), an ORM, or any Node.js library. No special API is required. The main performance concern is avoiding waterfalls: start independent requests together, and deduplicate repeated calls in one request with React.cache().

Defaults (16.x)

  • fetch is not cached by default
  • Identical fetch GETs in one render are memoized
  • With Cache Components, uncached data needs <Suspense> or 'use cache'
  • Errors thrown here go to the nearest error.tsx

Parallel Requests + Deduped Helper

// lib/data.ts
import 'server-only'
import { cache } from 'react'
export const getUser = cache(async (id: string) =>
  db.user.findUnique({ where: { id } }))      // once per request

// app/users/[id]/page.tsx
export default async function Profile(props: PageProps<'/users/[id]'>) {
  const { id } = await props.params
  const [user, posts] = await Promise.all([      // start together
    getUser(id),
    fetch(`https://api.example.com/users/${id}/posts`)
      .then((r) => r.json()),
  ])
  return <UserView user={user} posts={posts} />
}

Notes

cache() — memoizes per server request, not across users
Promise.all — total time = slowest request, not the sum
Use Promise.allSettled when one failure shouldn't fail the page
Any component calling getUser(id) reuses the same result

⚠ Common Mistakes

  • Chaining await calls that don't depend on each other; each one waits for the last
  • Calling your own Route Handler from a Server Component; call the data function directly instead
  • Expecting React.cache() to persist between requests; use 'use cache' for that

✓ Tips & Best Practices

  • Wrap every data-access function in cache() once, in lib/, and reuse it everywhere
  • Kick off slow requests with a preload call before awaiting faster ones
  • Use AbortSignal.timeout(5000) so a slow API can't hang the render

Quick Summary

  • await in async Server Components
  • Promise.all — avoid waterfalls
  • cache() — per-request dedupe
  • fetch — uncached by default in 16
