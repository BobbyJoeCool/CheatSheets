Zero Layout Shift Fonts

next/font downloads fonts at build time and serves them from your own domain: no requests to Google at runtime, better privacy, and automatic size-adjust fallbacks so text doesn't jump when the font loads. Call the loader at module scope and apply the returned className or CSS variable.

Facts

  • Variable fonts need no weight option
  • Static fonts need explicit weight(s)
  • subsets limits the preloaded character set
  • Each loader call creates one font instance; share it

Google + Local Fonts

// app/fonts.ts
import { Inter, Roboto_Mono } from 'next/font/google'
import localFont from 'next/font/local'

export const inter = Inter({ subsets: ['latin'], variable: '--font-inter' })
export const mono = Roboto_Mono({ subsets: ['latin'], weight: ['400', '700'],
  variable: '--font-mono', display: 'swap' })
export const brand = localFont({
  src: [{ path: './fonts/Brand-Regular.woff2', weight: '400' },
        { path: './fonts/Brand-Bold.woff2', weight: '700' }],
  variable: '--font-brand' })

// app/layout.tsx
import { inter, mono, brand } from './fonts'
const vars = `${inter.variable} ${mono.variable} ${brand.variable}`
<html lang="en" className={vars}>
  <body className={inter.className}>{children}</body></html>

Notes

variable — exposes a CSS custom property
className — applies font-family directly
Underscores replace spaces: Roboto_Mono
localFont paths are relative to the calling file
Use var(--font-inter) in CSS or Tailwind @theme

Loader Options

⚠ Common Mistakes

  • Calling Inter() inside a component; loaders must run at module scope
  • Loading the same font in several files; each call adds another copy
  • Forgetting weight on a non-variable font; the build errors

✓ Tips & Best Practices

  • Export all fonts from one fonts.ts file and import them where needed
  • Prefer variable fonts: one file covers every weight
  • Set preload: false on fonts used only below the fold

Quick Summary

  • next/font/google — self-hosted at build
  • next/font/local — your own files
  • variable — CSS custom property
  • Module scope — call loaders once
