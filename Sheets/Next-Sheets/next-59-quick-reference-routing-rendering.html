⚠ Common Mistakes

  • Adding "use client" to a whole tree — push it down to the leaf that needs interactivity
  • Treating params / searchParams as plain objects — they are Promises; await them
  • Importing server-only code (DB, secrets) into a Client Component

✓ Tips & Best Practices

  • Fetch in Server Components and pass data down as props
  • Wrap slow sections in <Suspense> so the page streams
  • Use route groups to give sections different layouts without changing URLs

Quick Summary

  • Folders are routes; page / layout / loading / error files
  • Server Components by default, "use client" to opt in
  • await params, await cookies() — request APIs are async
  • <Link> for navigation, redirect() on the server
