The React Layer Under Next.js

The App Router ships a React canary build that includes everything in React 19.2. Several of these APIs are central to Next.js: <Suspense> drives streaming, use() reads promises, the form hooks power Server Actions, and <Activity> lets Cache Components keep previously visited pages alive in the background.

Where Next Uses Them

  • loading.tsx = automatic <Suspense>
  • Navigations are transitions, so they trigger <ViewTransition>
  • With Cache Components, up to 3 routes stay mounted in <Activity>
  • reactCompiler: true memoizes without useMemo

Form Hooks + Optimistic UI

'use client'
import { useActionState, useOptimistic } from 'react'
import { sendMessage } from './actions'

export function Chat({ messages }: { messages: Msg[] }) {
  const [list, addOptimistic] = useOptimistic(
    messages, (cur, text: string) => [...cur, { id: 'tmp', text }])
  const [state, action, pending] = useActionState(
    async (prev: State, form: FormData) => {
      addOptimistic(String(form.get('text')))
      return sendMessage(prev, form)            // Server Action
    }, { error: null })
  return <form action={action}>
    {list.map((m) => <p key={m.id}>{m.text}</p>)}
    <input name="text" /><button disabled={pending}>Send</button>
    {state.error && <p role="alert">{state.error}</p>}
  </form>
}

Notes

useOptimistic — show the message before the server confirms
useActionState — returns [state, action, pending]
Optimistic item is replaced when real data re-renders
Works without JS when the action is passed to <form action>

⚠ Common Mistakes

  • Assuming state resets on navigation with Cache Components; <Activity> keeps it, so reset menus in a useLayoutEffect cleanup
  • Calling use() on a promise created during the same client render; create it on the server or cache it
  • Expecting <ViewTransition> to animate plain setState calls; it reacts to transitions and Suspense

✓ Tips & Best Practices

  • Import ViewTransition from react; no Next.js config is required
  • Tag links with transitionTypes={['nav-forward']} for directional animations
  • Turn on the React Compiler gradually and watch build times

Quick Summary

  • use() — unwrap promises and context
  • useActionState / useOptimistic — form state
  • <Activity> — hidden but alive UI
