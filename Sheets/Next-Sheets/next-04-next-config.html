Configuring the Framework

next.config.ts exports a typed NextConfig object (or a function receiving the build phase). It controls build output, image optimization, redirects and rewrites, response headers, and opt-in features like Cache Components and the React Compiler. Changes require restarting next dev.

16.x Config Changes

  • experimental.dynamicIO → top-level cacheComponents
  • experimental.turbopack → top-level turbopack
  • reactCompiler and typedRoutes are top-level (stable)
  • serverRuntimeConfig / publicRuntimeConfig removed: use env vars

A Realistic Config

import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,         // 'use cache' + Partial Prerendering
  reactCompiler: true,           // needs babel-plugin-react-compiler
  typedRoutes: true,             // type-checked <Link href>
  images: { remotePatterns: [new URL('https://cdn.example.com/**')] },
  async redirects() {
    return [{ source: '/old-blog/:slug', destination: '/blog/:slug',
              permanent: true }]                     // 308
  },
  async rewrites() {
    return [{ source: '/docs/:path*',
              destination: 'https://docs.example.com/:path*' }]
  },
}
export default nextConfig

Key Options

cacheComponents — enables 'use cache', cacheLife, PPR
reactCompiler — automatic memoization at build time
redirects() — permanent: true = 308, false = 307
rewrites() — proxy a path without changing the URL

⚠ Common Mistakes

  • Leaving images.domains in place: it is deprecated in 16; use remotePatterns
  • Expecting rewrites() to change the browser URL; that is what redirects() does
  • Editing config while next dev runs and wondering why nothing changed; restart it

✓ Tips & Best Practices

  • Type the export with NextConfig to catch typos in option names
  • Use permanent: false while testing redirects; 308s are cached hard by browsers
  • Keep secrets out of config: anything in env: is inlined into the client bundle

Quick Summary

  • NextConfig — typed default export
  • cacheComponents — opt into the new caching model
  • redirects() / rewrites() / headers() — async arrays
  • output — 'standalone' or 'export' builds
