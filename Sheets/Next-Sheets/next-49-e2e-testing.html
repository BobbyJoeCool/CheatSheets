End-to-End Testing

Playwright · Cypress · next build && next start · webServer config · testing server actions

Testing the Real App

End-to-end tests drive a real browser against a running app, so they cover Server Components, Server Actions, streaming, and proxy together. Run them against a production build (next build && next start) to catch caching and prerender behavior. Next.js 16.3 adds @next/playwright with an instant() helper for navigation shells.

Good E2E Targets

  • Auth flows and redirects
  • Forms backed by Server Actions
  • Loading and error states
  • Critical purchase / signup journeys

playwright.config.ts

import { defineConfig, devices } from '@playwright/test'

export default defineConfig({
  testDir: './e2e',
  use: { baseURL: 'http://localhost:3000',
         trace: 'on-first-retry' },
  webServer: {
    command: 'npm run build && npm run start',
    url: 'http://localhost:3000',
    reuseExistingServer: !process.env.CI,
    timeout: 180_000,
  },
  projects: [
    { name: 'chromium', use: devices['Desktop Chrome'] }],
})

A Server Action Flow

import { test, expect } from '@playwright/test'

test('creates a todo', async ({ page }) => {
  await page.goto('/todos/new')
  await page.getByLabel('Title').fill('Write tests')
  await page.getByRole('button', { name: 'Add' }).click()
  await expect(page).toHaveURL(/\/todos\/\w+/)
  await expect(page.getByRole('heading'))
    .toHaveText('Write tests')
})

// 16.3: assert what shows instantly on navigation
import { instant } from '@next/playwright'
await instant(page, async () => {
  await page.click('a[href="/products/hats"]')
  await expect(page.locator('h1')).toContainText('Cap')
})

⚠ Common Mistakes

  • Testing only against next dev; caching, prefetching, and prerendering behave differently in production
  • Using CSS selectors that match hidden routes kept alive by <Activity>; prefer role-based locators
  • Logging in through the UI in every test; reuse a saved storageState

✓ Tips & Best Practices

  • Run E2E in CI against the same build you deploy
  • Use trace: 'on-first-retry' and open traces with npx playwright show-trace
  • Lock down instant navigations with @next/playwright instant() tests

Quick Summary

  • Playwright — default E2E choice
  • webServer — build + start before tests
  • Role locators — robust with <Activity>
  • instant() — test navigation shells (16.3)
