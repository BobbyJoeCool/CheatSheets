Pages Router Data Fetching

getStaticProps · getServerSideProps · getStaticPaths · fallback · revalidate (ISR) · notFound / redirect

Data Through Exported Functions

Pages Router pages fetch data with special exported functions that run only on the server. getStaticProps runs at build time (plus background ISR with revalidate), getServerSideProps runs on every request, and getStaticPaths lists dynamic routes to prebuild. Results arrive as page props.

Return Options

  • { props } — pass data to the page
  • { notFound: true } — render 404
  • { redirect: { destination, permanent } }
  • revalidate: n — ISR (getStaticProps only)

Static Paths + ISR

// pages/blog/[slug].tsx
import type { GetStaticPaths, GetStaticProps,
  InferGetStaticPropsType } from 'next'

export const getStaticPaths: GetStaticPaths = async () => ({
  paths: (await getTopSlugs()).map((slug) => ({ params: { slug } })),
  fallback: 'blocking',              // render unknown slugs on demand
})

export const getStaticProps = (async ({ params }) => {
  const post = await getPost(params!.slug as string)
  if (!post) return { notFound: true }
  return { props: { post }, revalidate: 60 }   // ISR every 60 s
}) satisfies GetStaticProps<{ post: Post }>

export default function Page(
  { post }: InferGetStaticPropsType<typeof getStaticProps>) {
  return <article>{post.title}</article>
}

Notes

fallback: 'blocking' — SSR the first request, then cache
revalidate: 60 — regenerate in the background
satisfies + InferGetStaticPropsType — typed props
On-demand ISR: res.revalidate('/blog/x') in an API route
Props must be JSON-serializable (no Date)

⚠ Common Mistakes

  • Returning Date objects in props; they aren't JSON-serializable, so convert to strings
  • Using getServerSideProps for content that rarely changes; it skips the CDN on every request
  • Exporting these functions from non-page files (components); they're ignored

✓ Tips & Best Practices

  • Use fallback: 'blocking' for large catalogs; prebuild only the top pages
  • Set Cache-Control headers inside getServerSideProps for CDN caching
  • Migrate one page at a time: each maps cleanly to an async Server Component

Quick Summary

  • getStaticProps — build-time + ISR
  • getServerSideProps — per-request SSR
  • getStaticPaths — list dynamic pages
  • notFound / redirect — return shapes
