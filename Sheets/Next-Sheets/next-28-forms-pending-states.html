Feedback While the Server Works

React 19 hooks turn Server Actions into full form workflows. useActionState stores the action's last return value (errors, messages) and a pending flag. useFormStatus reads the pending state of the parent form from a child button. useOptimistic shows the expected result before the server responds. Validate input on the server with Zod.

Validation Pattern

  • Parse FormData with safeParse
  • Return { errors } instead of throwing
  • Re-fill inputs with defaultValue from state
  • Client required is UX only, not security

Action With Zod

'use server'
import { z } from 'zod'
const Schema = z.object({
  email: z.email(),
  name: z.string().min(2, 'Too short'),
})
export type State = {
  errors?: Record<string, string[]>; ok?: boolean }

export async function signup(
  _prev: State, form: FormData): Promise<State> {
  const r = Schema.safeParse(Object.fromEntries(form))
  if (!r.success)
    return { errors: z.flattenError(r.error).fieldErrors }
  await db.user.create({ data: r.data })
  return { ok: true }
}

Client Form

'use client'
import { useActionState } from 'react'
import { useFormStatus } from 'react-dom'
import { signup, type State } from './actions'

function Submit() {
  const { pending } = useFormStatus() // parent form
  return <button disabled={pending}>Sign up</button>
}
export function SignupForm() {
  const init: State = {}
  const [state, action] = useActionState(signup, init)
  const e = state.errors
  return <form action={action}>
    <input name="email" /><p>{e?.email?.[0]}</p>
    <input name="name" /><p>{e?.name?.[0]}</p>
    <Submit />{state.ok && <p>Welcome!</p>}
  </form>
}

⚠ Common Mistakes

  • Calling useFormStatus in the same component that renders the <form>; it only reads a parent form
  • Forgetting that the action's first parameter becomes previous state when used with useActionState
  • Trusting client validation alone; server parsing is the only real check

✓ Tips & Best Practices

  • Share one Zod schema between client hints and server validation
  • Use <Form action="/search"> from next/form for GET search forms with client navigation
  • Return field values in state so inputs keep user input after an error

Quick Summary

  • useActionState — return value + pending
  • useFormStatus — pending from a child component
  • useOptimistic — instant UI before confirmation
  • Zod safeParse — return errors, don't throw
