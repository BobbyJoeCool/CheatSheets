Sheet 09

Linking & Navigation

<Link> · prefetch · useRouter() · redirect() · usePathname() · useSearchParams()

Moving Between Routes

Use <Link> for navigation: it renders an <a>, prefetches routes as they enter the viewport, and performs a client-side transition without a full reload. Use useRouter() for programmatic navigation in Client Components, and redirect() on the server (Server Components, Server Actions, Route Handlers).

Prefetch Behavior

  • Prefetching runs only in production builds
  • Default: prefetch the shared shell / loading boundary
  • prefetch={true}: prefetch the full page (per-link data in 16.3)
  • prefetch={false}: no prefetch until hover

Links, Router, and Redirects

import Link from 'next/link'
<Link href="/blog/hello">Read</Link>
<Link href={{ pathname: '/search', query: { q: 'next' } }}>Search</Link>
<Link href="/dashboard" prefetch={false} replace scroll={false}>Go</Link>

'use client'
import { useRouter, usePathname, useSearchParams } from 'next/navigation'
const router = useRouter()
router.push('/cart')            // new history entry
router.replace('/login')        // replace current entry
router.back(); router.refresh() // refresh re-fetches server data
const path = usePathname()      // '/blog/hello'
const q = useSearchParams().get('q')   // 'next'

import { redirect, permanentRedirect } from 'next/navigation'
redirect('/login')              // 307 (303 in Server Actions)

Notes

Import hooks from next/navigation, not next/router
replace — swaps the history entry instead of pushing
scroll={false} — keep scroll position after navigating
router.refresh() — re-renders Server Components, keeps client state
permanentRedirect() — 308 for moved content

⚠ Common Mistakes

  • Calling redirect() inside try/catch; it works by throwing, so the catch swallows it
  • Using plain <a> tags for internal links; you lose prefetching and do a full reload
  • Reading useSearchParams() without a <Suspense> boundary; the route can't be prerendered

✓ Tips & Best Practices

  • Show a spinner per link with useLinkStatus() inside a child of <Link>
  • Use onNavigate to close menus the instant a link is clicked
  • Prefer <Link> over router.push whenever the target is known while rendering

Quick Summary

  • <Link> — client navigation with prefetching
  • useRouter() — programmatic navigation (client)
  • redirect() — server-side 307/303 redirect
  • usePathname / useSearchParams — read the URL
