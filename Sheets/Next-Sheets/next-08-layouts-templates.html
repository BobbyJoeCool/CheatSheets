Sheet 08

Layouts & Templates

root layout · <html> · <body> · nested layouts · children · template.tsx

Shared UI That Persists

A layout.tsx wraps every page and nested layout below it via the children prop. Layouts persist across navigation: they don't remount, so state and scroll position survive. The root layout is required and must render <html> and <body>. A template.tsx looks the same but remounts on every navigation.

Layout Facts

  • Layouts nest: root → dashboard/layout → page
  • Layouts receive params (Promise) but not searchParams
  • A layout does not re-render when only the child page changes
  • Export metadata from layouts for shared titles

Root + Nested Layout

// app/layout.tsx
import './globals.css'
export default function RootLayout({ children }: LayoutProps<'/'>) {
  return (
    <html lang="en"><body><Header />{children}</body></html>
  )
}

// app/dashboard/layout.tsx
export default async function DashLayout(
  { children }: LayoutProps<'/dashboard'>) {
  const user = await getCurrentUser()
  return (
    <div className="grid grid-cols-[240px_1fr]">
      <Sidebar user={user} />
      <main>{children}</main>
    </div>
  )
}

Notes

globals.css — import global CSS once, in the root layout
LayoutProps<'/dashboard'> — types children, params, slots
DashLayout — wraps every /dashboard/* page
Sidebar keeps its state as the user moves between pages
Async layouts can fetch data like pages

⚠ Common Mistakes

  • Reading searchParams in a layout; layouts don't re-render when the query changes, so the value goes stale
  • Adding a <head> tag manually; use metadata or generateMetadata
  • Using a layout for per-page auth checks; a layout doesn't re-run on every child navigation

✓ Tips & Best Practices

  • Push data fetching down to the component that needs it so layouts stay fast
  • Use template.tsx when an animation or useEffect must run on every page change
  • Pass server data to client widgets in the layout as serializable props

Quick Summary

  • layout.tsx — persistent shared UI via children
  • Root layout — required; renders <html> and <body>
  • template.tsx — remounts per navigation
  • LayoutProps<'/path'> — typed layout props
