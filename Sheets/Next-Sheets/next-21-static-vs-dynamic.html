Static vs Dynamic Rendering

build-time vs request-time · cookies() · headers() · connection() · build output symbols

When Does a Route Render?

A route is static when Next.js can render it at build time (or revalidate it in the background) and serve the result from a CDN. It becomes dynamic when it reads request-specific data: cookies(), headers(), searchParams, connection(), or uncached data. With Cache Components, a single route can be both: a static shell with dynamic holes.

Dynamic Triggers

  • await cookies() / await headers()
  • await searchParams in a page
  • await connection() (explicit opt-in)
  • Uncached fetch or DB query (with Cache Components)

Explicitly Defer to Request Time

import { Suspense } from 'react'
import { connection } from 'next/server'
import { cookies } from 'next/headers'

export default function Page() {
  return (
    <>
      <Hero />                                   {/* static */}
      <Suspense fallback={<p>…</p>}><Greeting /></Suspense>
      <Suspense fallback={<p>…</p>}><RandomTip /></Suspense>
    </>
  )
}
async function Greeting() {
  const name = (await cookies()).get('name')?.value ?? 'friend'
  return <p>Welcome back, {name}</p>           // per request
}
async function RandomTip() {
  await connection()                           // don't prerender
  return <p>{tips[Math.floor(Math.random() * tips.length)]}</p>
}

Notes

<Hero /> is part of the prerendered shell
cookies() makes Greeting dynamic
connection() — use before Math.random() or Date.now()
Each dynamic part needs its own <Suspense> boundary
All request APIs are async in 16; sync access was removed

⚠ Common Mistakes

  • Reading cookies() in the root layout; every route becomes dynamic
  • Calling Date.now() during prerender without connection(); the build captures one frozen value
  • Assuming 'use client' makes a route dynamic; Client Components still prerender

✓ Tips & Best Practices

  • Read request data as deep in the tree as possible so the shell stays static
  • Check the symbols in next build output after every caching change
  • Use --debug-prerender to see which component forced a route dynamic

Quick Summary

  • Static — rendered at build, served from cache
  • Dynamic — cookies, headers, searchParams
  • connection() — explicit request-time render
  • ◐ — partial prerender: shell + holes
