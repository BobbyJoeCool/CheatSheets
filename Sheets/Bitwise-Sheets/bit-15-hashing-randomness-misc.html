Hashing, Randomness & Branchless Tricks

h & (cap - 1) · FNV-1a · xorshift · Gray code

Shift, XOR, Multiply

Fast hash functions and random number generators are mostly shifts, XORs and multiplies. XOR-shifting folds high bits into low bits; multiplying by a large odd constant spreads low bits back up. Power-of-two table sizes turn % cap into & (cap - 1). The same toolkit gives Gray codes and branch-free min, max and abs.

Notes

  • None of these are cryptographic
  • Buckets use the low bits, so mix high bits down first
  • Branchless code only helps on unpredictable branches. Measure

Hashing & PRNG Building Blocks (pseudocode)

// Java HashMap-style spread before masking
index ← (h ^ (h >>> 16)) & (cap - 1)          // cap = 2^k

function fnv1a(bytes)                          // FNV-1a, 32-bit
    h ← 0x811C9DC5                             // offset basis
    for each b in bytes
        h ← ((h ^ b) * 0x01000193) & 0xFFFFFFFF   // × FNV prime
    return h

function xorshift32(s)                         // Marsaglia; s ≠ 0
    s ← s ^ ((s << 13) & 0xFFFFFFFF)
    s ← s ^ (s >>> 17)
    s ← s ^ ((s << 5) & 0xFFFFFFFF)
    return s

gray ← x ^ (x >> 1)                            // binary → Gray code

Code Explained

A mask keeps only low bits, so h >>> 16 mixes the high half in
FNV-1a XORs each byte in before multiplying (FNV-1 is the reverse)
xorshift32 has period 2³² − 1 and never returns 0
Gray code: neighbors differ by one bit (0, 1, 3, 2, 6, 7, 5, 4); used in rotary encoders

⚠ Common Mistakes

  • h % cap with a negative Java hash gives a negative index. Use & (cap - 1)
  • Seeding xorshift with 0: it stays 0 forever
  • Using these hashes for passwords: use bcrypt or Argon2

✓ Tips & Best Practices

  • In Python, mask with & 0xFFFFFFFF after every multiply or left shift
  • Use your language's tested hashes unless you need a specific algorithm
  • Compilers already emit cmov for simple min/max; keep the readable version

Quick Summary

  • h & (cap - 1) — bucket index
  • h ^ (h >>> 16) — mix high bits down
  • xorshift — fast non-crypto PRNG
  • x ^ (x >> 1) — Gray code
