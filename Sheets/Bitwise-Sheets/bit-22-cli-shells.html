Bitwise on the Command Line

Bit Math Without Opening an Editor

Shells do integer arithmetic inside $(( )) with the C operators: bash and zsh use 64-bit signed integers and accept any base with base#digits. PowerShell spells the operators as words (-band, -bor, -bxor, -bnot, -shl, -shr) and can call .NET helpers directly. For conversions, printf, bc and a Python one-liner cover the rest.

Notes

  • No >>> in shells; >> is arithmetic
  • (( x & 4 )) returns exit status 0 when the bit is set
  • [ ] / test can't do bit math; use (( ))

bash / zsh

echo $(( 12 & 10 )) $(( 12 | 10 )) $(( 12 ^ 10 ))  # 8 14 6
echo $(( ~12 )) $(( 1 << 10 )) $(( -16 >> 2 ))     # -13 1024 -4
echo $(( 2#1011 )) $(( 16#ff )) $(( 0x1F ))        # 11 255 31
echo $(( 017 )) $(( 10#017 ))                      # 15 17
printf '%x %o %X\n' 255 8 3054                     # ff 10 BEE
printf '%d\n' 0x1F                                 # 31
echo 'obase=2; 178' | bc                           # 10110010
(( flags & 4 )) && echo "bit 2 set"
mask=$(( (1 << 6) - 1 ))                           # 63

# zsh only: print in a base
echo $(( [##2] 178 )) $(( [##16] 255 ))            # 10110010 FF

bash: Print n Bits

tobin() {                         # tobin VALUE [WIDTH]
  local n=$1 w=${2:-8} s=""
  for (( i = w - 1; i >= 0; i-- )); do
    s+=$(( (n >> i) & 1 ))
  done
  echo "$s"
}
tobin 178                         # 10110010
tobin 5 4                         # 0101

bash: Permission Bits

mode=$(stat -c %a file.txt)               # e.g. 644 (Linux)
(( 8#$mode & 8#200 )) && echo "owner can write"
printf '%04o\n' $(( 8#666 & ~8#027 ))     # 0640
umask 027                                 # files 640, dirs 750

⚠ Common Mistakes

  • $(( 017 )) is 15: a leading zero means octal
  • $(( 08 )) is an error (bad octal). Use 10#08
  • Reading ^ as power: bash's power operator is 2 ** 10

✓ Tips & Best Practices

  • zsh: [##2] prints binary, [##16] prints hex
  • chmod 754 f sets rwxr-xr--; umask shows the mask
  • jq has no bitwise operators; pipe numbers to the shell or Python

Quick Summary

  • $(( )) — C operators, 64-bit signed
  • base#digits — any base in
  • printf '%x', bc obase=2 — bases out
  • PowerShell -band -bor -bxor -shl
