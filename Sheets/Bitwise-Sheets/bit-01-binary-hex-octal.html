Binary, Hex & Octal

positional notation · bit / nibble / byte / word · 0b / 0x / 0o · hex ↔ binary · MSB / LSB · _ separators

Bits Are Place Values

Computers store integers as bits, and each bit is worth a power of two. Binary is the native form. Hexadecimal packs 4 bits (a nibble) into one digit and octal packs 3, so both are shorthand for bit patterns. Bits are numbered from 0 at the right (the LSB, least significant bit) up to w − 1 at the left (the MSB).

Vocabulary & Literals

  • nibble = 4 bits · byte = 8 · word = 32 or 64
  • 0b1010 binary · 0x1F hex · 0o17 octal
  • Separators: 0b1011_0010 (C++: 0b1011'0010)

Reading & Converting Binary (pseudocode)

// Place values for 8 bits: bit 7 … bit 0
//  128  64  32  16   8   4   2   1
//    1   0   1   1   0   0   1   0     = 0b1011_0010
//  128    + 32 +16         + 2         = 178 = 0xB2

// Decimal → binary: repeated division by 2
function toBinary(n)                 // n > 0
    s ← ""
    while n > 0
        s ← str(n mod 2) + s         // remainder = next bit
        n ← n div 2                  // drop that bit
    return s

// Binary → decimal: shift-and-add
function fromBinary(s)
    n ← 0
    for each ch in s
        n ← n * 2 + digit(ch)
    return n

Code Explained

n mod 2 — the lowest bit; n div 2 drops it (same as n >> 1)
Hex: group bits in 4s from the right. 1011 0010 → B 2 → 0xB2
Octal: group in 3s. 10 110 010 → 2 6 2 → 0o262
Leading zeros show the width, not the value: 0b0000_0101 is still 5
Every language has built-ins for this (see Sheets 16–22); the loop shows what they do

⚠ Common Mistakes

  • Counting bit 0 from the left. Bit 0 is the rightmost (LSB)
  • 017 is 15, not 17: a leading zero means octal in C, Java and bash
  • Forgetting one hex digit is exactly 4 bits (0xFF = 8 ones)

✓ Tips & Best Practices

  • Learn 0–F in binary by heart; hex masks become readable
  • Write masks in hex (0xFF00), not decimal (65280)
  • ¹ 0b arrived in C23 (GCC/Clang extension before) and C++14

Quick Summary

  • 0b / 0x / 0o — binary, hex, octal literals
  • bit i — worth 2ⁱ, counted from the right starting at 0
  • 1 hex digit = 4 bits; 2 hex digits = 1 byte
  • n mod 2, n div 2 — read, then drop, the lowest bit
