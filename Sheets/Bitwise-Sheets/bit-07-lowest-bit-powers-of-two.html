Sheet 07

Lowest Set Bit & Powers of Two

x & (x - 1) · x & -x · x | (x + 1) · power-of-two test · next power of two · x & (2ⁿ - 1) · align up / down

Tricks Built on ±1

Subtracting 1 flips the lowest set bit and every zero below it, so x & (x - 1) erases the lowest 1. In two's complement -x = ~x + 1, so x & -x keeps only the lowest 1. A power of two has exactly one bit set, which makes it easy to test for, round up to, and use for fast modulo and alignment.

Notes

  • Assume x is unsigned or non-negative unless noted
  • Without unary minus on unsigned: x & (~x + 1)
  • 0 is not a power of two; check x ≠ 0

The ±1 Family (pseudocode)

x ← 0b0101_1000                    // 88

x & (x - 1)    // 0b0101_0000      clear lowest set bit
x & -x         // 0b0000_1000      isolate lowest set bit (8)
x | (x - 1)    // 0b0101_1111      fill trailing zeros
x | (x + 1)    // 0b0101_1001      set lowest zero bit
~x & (x + 1)   // 0b0000_0001      isolate lowest zero bit

isPow2(x) ← x ≠ 0 and (x & (x - 1)) = 0

function nextPow2(x)               // smallest 2^k ≥ x, x ≥ 1
    x ← x - 1
    s ← 1
    while s < 32                   // smear the top 1 rightward
        x ← x | (x >> s)
        s ← s * 2
    return x + 1

Code Explained

x & (x - 1) drives Kernighan's popcount and set-bit loops (Sheets 08, 11)
x & -x is the Fenwick-tree step: i ← i + (i & -i)
Smearing copies the top 1 into every lower bit, giving 2ᵏ − 1; +1 finishes
The opening x - 1 keeps exact powers: nextPow2(64) = 64

⚠ Common Mistakes

  • isPow2(0) is true without the x ≠ 0 check
  • Rust debug panics on -x overflow; use x & x.wrapping_neg()
  • -3 % 8 is −3 in C/Java, but -3 & 7 is 5

✓ Tips & Best Practices

  • C++20: std::has_single_bit, std::bit_ceil, std::bit_floor
  • Java: Integer.highestOneBit, Integer.lowestOneBit
  • Size hash tables as 2ⁿ so h & (cap - 1) replaces h % cap

Quick Summary

  • x & (x - 1) — clear lowest 1
  • x & -x — isolate lowest 1
  • x & (x - 1) = 0, x ≠ 0 — power of two
  • (x + a - 1) & ~(a - 1) — align up
