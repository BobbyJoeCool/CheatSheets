Many Yes/No Options in One Integer

A flag word packs many on/off options into one integer, one bit per option. Combine options with |, test with &, and remove with & ~. Unix file permissions, OS open flags, regex options, window styles and feature switches all use this pattern: it's compact, fast to test, and travels as a single argument.

Notes

  • Each flag is a distinct power of two: 1 << n
  • A combination is just an int: READ | WRITE
  • Unix mode = 3 groups of rwx bits: user, group, other

Flags in Action (pseudocode)

READ    ← 1 << 0                       // 0b001
WRITE   ← 1 << 1                       // 0b010
EXECUTE ← 1 << 2                       // 0b100

perms ← READ | WRITE                   // combine:  0b011
(perms & WRITE) ≠ 0                    // has WRITE?  true
both  ← READ | EXECUTE
(perms & both) = both                  // has both?   false
perms ← perms | EXECUTE                // add:      0b111
perms ← perms & ~WRITE                 // remove:   0b101

mode  ← 0o754                          // rwx r-x r--
user  ← (mode >> 6) & 0o7              // 7 = rwx
group ← (mode >> 3) & 0o7              // 5 = r-x
other ← mode & 0o7                     // 4 = r--

Code Explained

One octal digit = 3 bits = one rwx triple; that's why modes are written in octal
& ~WRITE removes the flag whether or not it was set
umask 022: new file mode = 0o666 & ~0o022 = 0o644
Special bits sit above: setuid 0o4000, setgid 0o2000, sticky 0o1000

QuestionExpressionResult
has READ?(f & READ) != 0true

⚠ Common Mistakes

  • Numbering flags 1, 2, 3, 4: 3 equals 1 | 2, so flags collide
  • (perms & WRITE) == true: the result is 2, not a boolean
  • chmod(path, 755) in code is decimal (= 0o1363). Write 0o755

✓ Tips & Best Practices

  • Use a typed flags type: enum.Flag, [Flags], EnumSet
  • Never renumber flags that are saved to disk or sent over a wire
  • Validate input: (flags & ~ALL) == 0

Quick Summary

  • 1 << n — one flag per bit
  • a | b — combine; f & ~X — remove
  • (f & X) != 0 — has X
  • 0o755 — rwxr-xr-x
