Sheet 19

Bitwise in C & C++

uint32_t · UB: signed overflow, shift ≥ width · integer promotion · bit fields · __builtin_popcount · C++20 <bit> · std::bitset · C23 <stdbit.h>

Close to the Metal, Full of Traps

C and C++ map bit operations straight onto the hardware. Use unsigned fixed-width types (uint8_t … uint64_t) for bit work: unsigned overflow wraps by definition, while signed overflow is undefined behavior. Types smaller than int are promoted to int before any operator runs, and shifting by a negative count or by ≥ the width is undefined.

Notes

  • >> of a negative: implementation-defined in C, arithmetic in C++20
  • Wide literals: 1u, 1ull, UINT64_C(1)
  • 0b literals: C++14, C23. Separators: 0b1011'0010 (C++14, C23)

C++ Bit Toolkit

#include <bit>      // C++20; also <cstdint>, <bitset>

uint32_t x = 0b1011'0010;                  // 178
uint32_t m = 1u << 31;                     // fine: unsigned
uint64_t big = 1ull << 40;                 // 1 << 40 would be UB
uint8_t b = 0xF0;
auto y = ~b;                               // int -241 (promoted!)
uint8_t z = static_cast<uint8_t>(~b);      // 0x0F

std::popcount(x);                          // 4
std::countr_zero(x);                       // 1
std::bit_width(x);                         // 8
std::rotl(x, 4);                           // 2848
std::has_single_bit(64u);                  // true
std::bitset<8>(x).to_string();             // "10110010"
auto bits = std::bit_cast<uint32_t>(1.5f); // 0x3FC00000

Code Explained

Promotion: uint8_t / uint16_t become int, so ~b and b << 24 run signed
GCC/Clang: __builtin_popcount, __builtin_ctz, __builtin_clz (undefined at 0); ll suffix for 64-bit
MSVC: __popcnt, _BitScanForward, _byteswap_ulong
C23 <stdbit.h>: stdc_count_ones, stdc_leading_zeros, stdc_bit_width

C: Bit Fields & Builtins

#include <stdint.h>
/* bit fields: the order in memory varies by compiler */
struct Rgb565 { unsigned b : 5, g : 6, r : 5; };
uint32_t x = 178;
__builtin_popcount(x);       /* 4  (GCC/Clang) */
__builtin_ctz(x);            /* 1  (x must be != 0) */
__builtin_clz(x);            /* 24 */

C23: <stdbit.h> & printf %b

#include <stdbit.h>          /* C23 */
stdc_count_ones(x);          /* 4 */
stdc_trailing_zeros(x);      /* 1 */
stdc_bit_width(x);           /* 8 */
printf("%b\n", x);           /* 10110010 (C23) */
printf("%08x\n", x);         /* 000000b2 */

⚠ Common Mistakes

  • 1 << 40 with an int literal. Write 1ull << 40
  • char signedness varies: (char)0xF0 >> 4 may be −1 or 15
  • Mixing signed and unsigned: -1 < 0u is false

✓ Tips & Best Practices

  • Build with -Wall -Wextra -Wconversion -fsanitize=undefined
  • Use uint8_t / std::byte for raw bytes, not char
  • Prefer <bit> over compiler builtins for portable code

Quick Summary

  • uint32_t — unsigned, wraps safely
  • promotion — small types become int
  • shift ≥ width — UB
  • <bit> — popcount, rotl, bit_cast
