AND, OR, XOR & NOT

Four Operators, One Bit at a Time

The bitwise operators work on every bit position independently, like 32 or 64 tiny logic gates side by side. AND keeps bits that are set in both inputs, OR keeps bits set in either, XOR keeps bits that differ, and NOT flips every bit. Every other trick in this set is built from these four plus shifts.

Notes

  • & | ^ ~ — the C-style symbols nearly every language uses
  • && / || are logical and short-circuit; bitwise ops always evaluate both sides
  • Signed: ~x = -x - 1, so ~5 = -6

Worked 8-Bit Examples (pseudocode)

a ← 0b1100_1010              // 202
b ← 0b1010_0110              // 166

//     1100_1010   a
//   & 1010_0110   b
//   = 1000_0010   130    AND: 1 only where both are 1
//
//     1100_1010
//   | 1010_0110
//   = 1110_1110   238    OR: 1 where either is 1
//
//     1100_1010
//   ^ 1010_0110
//   = 0110_1100   108    XOR: 1 where they differ
//
//   ~ 1100_1010
//   = 0011_0101    53    NOT (8-bit unsigned view)

if (x & 1) = 0               // keep the parentheses
    print("even")

Code Explained

AND clears bits. Use it to keep only the bits in a mask
OR sets bits. Use it to turn on the bits in a mask
XOR flips bits. Use it to toggle, or to find what changed
NOT inverts all w bits, including the sign bit
C, C++, Java, JS, C#: x & 1 == 0 parses as x & (1 == 0). Python, Go and Rust bind & tighter, so it works there

⚠ Common Mistakes

  • Using & as logical AND on ints: 1 & 2 is 0 (false) while 1 && 2 is true
  • Leaving out parentheses: x & MASK == 0 in C, Java or JS
  • Expecting ~5 to be 2 (3-bit thinking). On a signed int it's −6
  • Reading ^ as "to the power of". It's XOR; use pow() for powers

✓ Tips & Best Practices

  • Read & as "keep", | as "set", ^ as "flip"
  • XOR undoes itself: (a ^ k) ^ k = a
  • Parenthesize every bitwise subexpression inside a comparison
  • Use De Morgan to turn "clear these bits" into x & ~mask

Quick Summary

  • & — 1 if both bits are 1
  • | — 1 if either bit is 1
  • ^ — 1 if the bits differ
  • ~ — flip every bit (~x = -x - 1 signed)
