XOR Undoes Itself

XOR is addition without carry, so it is its own inverse: x ^ x = 0 and x ^ 0 = x. It's also commutative and associative, so XOR-ing a whole list cancels every value that appears an even number of times. The same property powers toggling, parity, simple checksums and the "what changed?" test.

Notes

  • a ^ b ^ a = b, in any order
  • a ^ b = 0 exactly when a = b
  • (a ^ b) < 0 — signed ints with different signs

Classic XOR Problems (pseudocode)

// Single number: every value appears twice except one
function single(nums)
    r ← 0
    for each n in nums
        r ← r ^ n                  // pairs cancel to 0
    return r
single([4, 1, 2, 1, 2])            // 4
// Missing number in 0..n (array has n values)
function missing(nums)
    r ← length(nums)
    for i ← 0 to length(nums) - 1
        r ← r ^ i ^ nums[i]
    return r
missing([3, 0, 1])                 // 2
// Two singles: everything else appears twice
function twoSingles(nums)
    d ← 0
    for each n in nums
        d ← d ^ n                  // d = p ^ q, nonzero
    bit ← d & -d                   // a bit where p and q differ
    p ← 0
    for each n in nums
        if (n & bit) ≠ 0
            p ← p ^ n              // XOR of one group = p
    return (p, d ^ p)

changed ← old ^ new                // 1s = bits that changed

Code Explained

missing XORs every index 0..n with every value; whatever is present cancels
Toggle between a and b with no branch: x ← (a ^ b) ^ x
XOR swap (a ^= b; b ^= a; a ^= b) zeroes a value swapped with itself. Use a temp
twoSingles splits the list by one differing bit, so each group hides one single

⚠ Common Mistakes

  • XOR-swapping a[i] with a[j] when i = j sets it to 0
  • Treating XOR with a fixed key as encryption; repeating keys are easy to break
  • a ^ b == 0 in C/Java is a ^ (b == 0). Parenthesize

✓ Tips & Best Practices

  • XOR-fold to find the odd one out in O(1) memory
  • Diff two flag words with old ^ new before reacting
  • For parity, popcount(x) & 1 beats an XOR loop

Quick Summary

  • x ^ x = 0, x ^ 0 = x — cancel and keep
  • fold a list — pairs cancel
  • a ^ b — the bits that differ
  • x ^ k ^ k = x — undo
