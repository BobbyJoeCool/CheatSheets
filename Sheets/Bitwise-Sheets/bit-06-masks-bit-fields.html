Sheet 06

Masks & Bit Fields

(1 << n) - 1 · range mask · extract (x >> lo) & mask · insert field · clear a range · ~0 · named masks

Masks Select Bits; Fields Store Numbers

A mask is a value whose 1 bits mark the positions you care about: AND with it keeps those bits, OR sets them, AND-NOT clears them. A bit field is a run of adjacent bits holding a small number inside a bigger word. Read a field with shift, then mask; write it with clear the slot, then OR.

Notes

  • (1 << n) - 1 = n low ones: n = 4 → 0b1111
  • n = w overflows. Use ~0 for all bits
  • Name masks: LOW_NIBBLE = 0x0F

Build Masks, Read & Write Fields (pseudocode)

low(n)        ← (1 << n) - 1                // n low ones
range(lo, hi) ← low(hi - lo + 1) << lo      // ones in bits lo..hi
low(4)        // 0b0000_1111
range(2, 5)   // 0b0011_1100

function getField(x, lo, width)       // shift down, then mask
    return (x >> lo) & low(width)

function setField(x, lo, width, v)    // clear slot, then OR in
    m ← low(width) << lo
    return (x & ~m) | ((v << lo) & m)

x ← 0b1101_0110
getField(x, 2, 3)          // 0b101 = 5   (bits 2..4)
setField(x, 2, 3, 0b010)   // 0b1100_1010

Code Explained

& m after shifting v stops a too-wide value from spilling into neighbors
Mask-then-shift (x & m) >> lo works too, but needs the shifted mask
range(lo, hi) is inclusive at both ends: width = hi − lo + 1
Fields don't need byte alignment; any lo and width work

⚠ Common Mistakes

  • x & m >> lo is x & (m >> lo) in C-family. Parenthesize
  • OR-ing a new value without clearing the slot merges old and new bits
  • (1 << 32) - 1 on a 32-bit int shifts by the width. Use 0xFFFFFFFF

✓ Tips & Best Practices

  • Define SHIFT and MASK constants per field and use them as a pair
  • Keep masks unsigned so shifts never sign-fill
  • Struct bit fields (Sheet 19) aren't portable; mask by hand for file formats

Quick Summary

  • (1 << n) - 1 — n low ones
  • (x >> lo) & mask — read a field
  • (x & ~m) | (v << lo) — write a field
  • x & m / x | m / x & ~m — keep / set / clear
