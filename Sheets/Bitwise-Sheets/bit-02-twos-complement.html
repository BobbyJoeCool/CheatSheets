Sheet 02

Signed Integers & Two's Complement

sign bit · -x = ~x + 1 · ranges · overflow · sign extension · MIN

How Negative Numbers Are Stored

Fixed-width integers are either unsigned (every bit adds value) or signed. Almost every machine stores signed integers in two's complement: the top bit has a negative weight of −2^(w−1), so counting past the largest positive value wraps to the most negative one. Negation is ~x + 1, and the same adder circuit handles signed and unsigned math.

Key Facts

  • Sign bit = MSB. 1 means negative
  • -1 is all ones: 0xFF, 0xFFFFFFFF
  • MIN has no positive twin: −(−128) wraps to −128
  • C23 and C++20 now require two's complement

8-Bit Two's Complement (pseudocode)

// bit 7 weighs -128; bits 6..0 weigh 64..1 as usual
//   bits         unsigned   signed
//   0000_0000        0         0
//   0000_0001        1         1
//   0111_1111      127       127    ← signed MAX
//   1000_0000      128      -128    ← signed MIN
//   1111_1110      254        -2
//   1111_1111      255        -1

// Negate 5:
//   5        = 0000_0101
//   ~5       = 1111_1010
//   ~5 + 1   = 1111_1011    = -5 signed, 251 unsigned

// Read a w-bit unsigned pattern as signed
function toSigned(u, w)               // 0 ≤ u < 2^w
    if u ≥ 2^(w - 1)                  // sign bit set
        return u - 2^w
    return u

Code Explained

u - 2^w — 251 − 256 = −5. Same bits, two readings
Overflow: 127 + 1 = −128 in 8-bit signed (it wraps)
Unsigned wraps too: 0 − 1 = 255 in 8-bit
Sign extension: widening −5 to 16 bits copies the sign bit: 1111_1111_1111_1011
Zero extension (unsigned): 251 → 0000_0000_1111_1011

⚠ Common Mistakes

  • abs(INT_MIN) is still INT_MIN (overflow). Check before negating
  • C: -1 < 1u is false (−1 becomes 0xFFFFFFFF)
  • Byte 0xF0 read as signed is −16, not 240. Use & 0xFF
  • Assuming overflow traps. Most languages wrap silently

✓ Tips & Best Practices

  • Use unsigned types for bit patterns where you can
  • ~0 is a ready-made all-ones mask
  • Sign-extend a w-bit field: (x ^ m) - m, m = 1 << (w-1)
  • Landmarks: 0x7FFFFFFF = INT_MAX, 0x80000000 = INT_MIN

Quick Summary

  • two's complement — top bit weighs −2^(w−1)
  • -x = ~x + 1 — invert, then add one
  • -1 — every bit set
  • sign extension — widen by copying the sign bit
  • MIN — has no positive counterpart
