An Integer Can Be a Set

Let bit i mean "element i is in the set". With up to 64 elements, union, intersection and membership each become one instruction, and counting from 0 to 2ⁿ − 1 visits every subset. This is the engine behind bitmask dynamic programming, and, with arrays of words, behind bitmap indexes, Bloom filters and bit arrays.

Notes

  • Map elements to 0..n−1 first
  • 2ⁿ grows fast: n = 20 ≈ 1 M subsets, n = 30 ≈ 1 B
  • n > 64: array of words, word i div 64, bit i mod 64

Enumeration Patterns (pseudocode)

while s ≠ 0                              // visit each element of s
    visit(ctz(s))                        // index of lowest 1
    s ← s & (s - 1)                      // drop it

for mask ← 0 to (1 << n) - 1             // every subset of {0..n-1}
    process(mask)

sub ← m                                  // every non-empty submask of m
while sub ≠ 0
    process(sub)
    sub ← (sub - 1) & m

function nextSameBits(x)                 // Gosper's hack, x > 0
    c ← x & -x                           // lowest 1
    r ← x + c                            // carry ripples up
    return (((r ^ x) >> 2) div c) | r    // refill the low ones

Code Explained

The submask loop visits 2^popcount(m) − 1 masks; over every m that's 3ⁿ in total
Gosper walks k-subsets in order: 0111 → 1011 → 1101 → 1110 → 10011
Bitmask DP state: (visited mask, last item). TSP runs in O(2ⁿ · n²), fine to n ≈ 20

⚠ Common Mistakes

  • The submask loop skips the empty set; handle 0 separately if needed
  • 1 << n with n = 32 on 32-bit ints
  • 2ⁿ enumeration past n ≈ 25: 33 M subsets × work each gets slow

✓ Tips & Best Practices

  • Map each element to a bit once and keep the map
  • Precompute popcount per mask for DP tables
  • Sparse huge sets: a hash set beats a bitmap

Quick Summary

  • a | b, a & b, a & ~b — ∪, ∩, −
  • 0 .. 2ⁿ − 1 — all subsets
  • (sub - 1) & m — next submask
  • Gosper — next k-subset
