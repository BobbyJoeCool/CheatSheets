Floats That Become 32-Bit Ints

JavaScript numbers are 64-bit floats, but every bitwise operator first converts its operands to 32-bit signed integers, does the work, and returns a 32-bit result. >>> is the exception: it returns an unsigned 32-bit value. For anything wider than 32 bits use BigInt (123n), which supports every bitwise operator except >>>.

Notes

  • Results ≥ 2³¹ come back negative: 0x80000000 | 0 is −2147483648
  • x | 0 truncates toward zero, but only inside 32-bit range
  • Plain numbers are exact only up to 2⁵³ − 1

JavaScript Bit Toolkit

const x = 0b1011_0010;                   // 178
x.toString(2);                           // "10110010"
x.toString(2).padStart(16, "0");         // "0000000010110010"
parseInt("ff", 16);                      // 255

1 << 31;                                 // -2147483648
(1 << 31) >>> 0;                         // 2147483648
-16 >> 2;                                // -4
-16 >>> 2;                               // 1073741820
1 << 32;                                 // 1   (count masked to 0)
2 ** 32 | 0;                             // 0   (ToInt32 wraps)
Math.clz32(1);                           // 31
Math.imul(0xFFFFFFFF, 5);                // -5  (32-bit multiply)

1n << 64n;                               // 18446744073709551616n
BigInt.asUintN(64, -1n);                 // 18446744073709551615n

Code Explained

>>> 0 reinterprets a result as unsigned 32-bit (colors, hashes)
BigInt and Number don't mix: 1n << 3 throws TypeError; convert with BigInt(n)
BigInt.asUintN(w, b) / asIntN wrap to w bits like a fixed-width type
Typed arrays (Uint8Array, Uint32Array) wrap on write; DataView picks endianness

TypeScript Flag Enum

enum Perm { None = 0, R = 1 << 0, W = 1 << 1, X = 1 << 2 }

let p: Perm = Perm.R | Perm.W;        // 3
const canWrite = (p & Perm.W) !== 0;  // true
p &= ~Perm.W;                         // remove W → 1
const all = Perm.R | Perm.W | Perm.X; // 7

Binary Data: DataView & Typed Arrays

const buf = new Uint8Array([0x12, 0x34, 0x56, 0x78]).buffer;
const dv = new DataView(buf);
dv.getUint32(0).toString(16);        // "12345678" (big-endian)
dv.getUint32(0, true).toString(16);  // "78563412" (little)
new Uint8Array([300])[0];            // 44 (wraps mod 256)

⚠ Common Mistakes

  • x | 0 as floor for big values: 3_000_000_000 | 0 is negative. Use Math.trunc
  • 1 << 40 to reach 64 bits gives 256. Use 1n << 40n
  • Comparing hashes or colors without >>> 0: negatives sort and print wrong

✓ Tips & Best Practices

  • View 32 bits of a negative: (n >>> 0).toString(2)
  • TS flags: enum Perm { R = 1 << 0, W = 1 << 1 }, then Perm.R | Perm.W
  • Parse binary data with DataView / Uint8Array, not strings
