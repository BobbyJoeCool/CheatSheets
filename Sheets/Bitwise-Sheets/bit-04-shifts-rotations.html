Shifts & Rotations

<< × 2ⁿ · arithmetic >> · logical >>> · rounds toward −∞ · shift ≥ width · rotate left / right

Sliding Bits Left and Right

Shifts move every bit n positions. Left shift fills with zeros and multiplies by 2ⁿ (bits pushed off the top are lost). Right shift divides by 2ⁿ and comes in two kinds: arithmetic copies the sign bit (for signed numbers) and logical fills with zeros (for unsigned). A rotate wraps the bits that fall off one end back in at the other.

Notes

  • x >> n = floor(x / 2ⁿ). It rounds toward −∞: -7 >> 1 is −4, but -7 / 2 is −3
  • >>> exists in Java, JS, C# 11+ and Kotlin (ushr). C, C++, Go and Rust shift unsigned types instead
  • Shifting by ≥ the width is undefined in C/C++ and masked in Java/JS/C#

Shifts in 8 Bits (pseudocode)

x ← 0b0001_0110             // 22
x << 1      // 0b0010_1100     44   (× 2)
x << 3      // 0b1011_0000    176   (× 8)
x >> 2      // 0b0000_0101      5   (22 div 4)

// 8-bit signed -16 = 1111_0000
-16 >> 2    // 1111_1100 = -4    arithmetic: sign bit copied
-16 >>> 2   // 0011_1100 = 60    logical: zeros shifted in

// Rotate left by n inside a w-bit unsigned value
function rotl(x, n, w)
    n ← n mod w
    if n = 0
        return x                       // avoid shifting by w
    mask ← (1 << w) - 1
    return ((x << n) | (x >>> (w - n))) & mask

rotl(0b1001_0110, 3, 8)     // 0b1011_0100

Code Explained

Shifting into the sign bit flips the sign: 1 << 31 is negative in a 32-bit int
Real languages shift 32 or 64 bits: -16 >>> 2 on a 32-bit int is 1,073,741,820
The n = 0 guard avoids a shift by w, which is undefined or masked
Rotate right is rotl(x, w - n, w)
Compilers turn this pattern into one ROL/ROR instruction

⚠ Common Mistakes

  • 1 << 40 with a 32-bit 1. Java masks the count to 8 and gives 256. Write 1L << 40
  • Expecting >> to divide negatives like /: -7 >> 1 is −4, -7 / 2 is −3
  • Precedence: 1 << n - 1 means 1 << (n - 1), since shifts bind looser than + and −
  • Using >>> on a Java byte: it's promoted to int first, so sign bits leak in

✓ Tips & Best Practices

  • Write x * 8, not x << 3, unless you mean bits. The compiler optimizes either
  • Use unsigned types (or >>>) for bit patterns so right shifts never sign-fill
  • Prefer built-in rotates: Integer.rotateLeft, bits.RotateLeft, std::rotl
  • Parenthesize: (1 << n) - 1

Quick Summary

  • << — shift left: × 2ⁿ, zeros in
  • >> — arithmetic right: sign bit in
  • >>> — logical right: zeros in
  • rotate — bits shifted out wrap around
  • count ≥ width — undefined or masked: avoid
