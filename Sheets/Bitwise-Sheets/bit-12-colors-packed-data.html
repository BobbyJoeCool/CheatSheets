Several Values, One Integer

Packing stores several small values side by side in one integer: shift each into its slot and OR them together; unpack with shift-then-mask. Colors are the everyday example. 0x3A7BD5 is three 8-bit channels in one 24-bit number, the same value CSS writes as #3A7BD5. The same trick builds hash keys from coordinates, squeezes colors into 16 bits, and stores fractions in integers.

Notes

  • Channel order is a convention: ARGB, RGBA, BGRA
  • Alpha in the top byte makes a signed int negative

Pack & Unpack (pseudocode)

c ← 0x3A7BD5                           // #3A7BD5
r ← (c >> 16) & 0xFF                   // 0x3A = 58
g ← (c >> 8) & 0xFF                    // 0x7B = 123
b ← c & 0xFF                           // 0xD5 = 213
packed ← (r << 16) | (g << 8) | b      // 0x3A7BD5 again
argb   ← (0xFF << 24) | packed         // opaque: 0xFF3A7BD5

// RGB565: 5 bits red, 6 green, 5 blue
rgb565 ← ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3)   // 0x3BDA
r5 ← (rgb565 >> 11) & 0x1F
r8 ← (r5 << 3) | (r5 >> 2)             // 8 bits again: 57 (was 58)

// Two 32-bit ints in one 64-bit key
key ← (x << 32) | (y & 0xFFFFFFFF)     // mask y: negatives
x2  ← key >> 32
y2  ← key & 0xFFFFFFFF

Code Explained

& 0xFF after the shift drops the channels above
(r5 << 3) | (r5 >> 2) copies high bits down so 31 → 255, not 248
Mask y or a negative y smears ones over x
Morton (Z-order) codes interleave x and y bits so nearby points get nearby keys

⚠ Common Mistakes

  • Java/C# int with alpha ≥ 0x80 is negative: c >> 24 gives −1. Use >>> 24 or & 0xFF
  • Mixing RGBA and ARGB: channels come out rotated
  • x << 32 on a 32-bit x shifts by the width. Widen to 64 bits first

✓ Tips & Best Practices

  • Always & 0xFF after shifting a channel down
  • Name the layout in code (ARGB8888); the bits can't tell you
  • x86 BMI2 pdep / pext build Morton codes in one instruction

Quick Summary

  • (c >> 16) & 0xFF — red from 0xRRGGBB
  • (r << 16) | (g << 8) | b — pack
  • RGB565 — 5/6/5 bits in 16
  • (x << 32) | y — two ints, one key
