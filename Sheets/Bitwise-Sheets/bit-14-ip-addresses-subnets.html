Subnetting Is Masking

An IPv4 address is a 32-bit number written as four bytes. A CIDR prefix like /24 says how many leading bits name the network; the rest name hosts. Turn the prefix into a netmask with one shift. Then AND gives the network address, OR with the inverted mask gives the broadcast address, and comparing masked values answers "is this IP in that subnet?"

Notes

  • 192.168.10.37 = 0xC0A80A25
  • /24 = 255.255.255.0 = 0xFFFFFF00
  • Prefix 0 would shift by 32: special-case it

Subnet Math (pseudocode)

function ipToInt(a, b, c, d)
    return (a << 24) | (b << 16) | (c << 8) | d

ALL   ← 0xFFFFFFFF
ip    ← ipToInt(192, 168, 10, 37)          // 0xC0A80A25
p     ← 26                                 // 192.168.10.37/26
mask  ← (ALL << (32 - p)) & ALL            // 255.255.255.192
net   ← ip & mask                          // 192.168.10.0
bcast ← net | (~mask & ALL)                // 192.168.10.63
hosts ← (1 << (32 - p)) - 2                // 62 usable

function inSubnet(addr, net, mask)
    return (addr & mask) = net

inSubnet(ipToInt(192, 168, 10, 70), net, mask)   // false

Code Explained

& ALL keeps results in 32 bits where ints are wider (Python, Go int)
.70 is in the next /26 block (.64–.127)
/31 and /32 have no network/broadcast pair (RFC 3021)
Cisco wildcard mask = ~mask: 0.0.0.63 for /26
IPv6: the same math on 128 bits (two 64-bit halves or a big int)

⚠ Common Mistakes

  • Java ints make 192.x addresses negative; use long or unsigned compares
  • JS << gives negatives for 128.x and up; finish with >>> 0
  • Matching strings (startsWith("192.168.1")) also matches 192.168.10.x

✓ Tips & Best Practices

  • Libraries: Python ipaddress, Go net/netip, .NET 8 IPNetwork
  • Store IPv4 as unsigned 32-bit ints for fast sorting and range checks
  • Same subnet? (a & mask) == (b & mask)

Quick Summary

  • ~0 << (32 - p) — mask for /p
  • ip & mask — network address
  • net | ~mask — broadcast
  • (ip & mask) == net — membership
