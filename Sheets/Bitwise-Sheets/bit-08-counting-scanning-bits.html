Sheet 08

Counting & Scanning Bits

popcount · Kernighan · SWAR · trailing zeros (ctz) · leading zeros (clz) · bit length · parity · POPCNT / LZCNT

Four Questions About a Word

How many bits are set (popcount)? How many zeros sit below the lowest 1 (ctz, trailing zeros)? How many zeros sit above the highest 1 (clz, leading zeros)? How many bits does the number need (bit length)? Modern CPUs answer each in one instruction, and every major language exposes them. The loops below show what the built-ins do.

Relationships

  • bit length = w − clz(x) = floor(log₂ x) + 1
  • ctz(x) = index of the lowest set bit
  • parity = popcount(x) mod 2

Counting Without Built-ins (pseudocode)

// Kernighan: one iteration per SET bit
function popcount(x)                     // x unsigned
    count ← 0
    while x ≠ 0
        x ← x & (x - 1)                  // clear lowest 1
        count ← count + 1
    return count

// SWAR: all 32 bits in parallel, no loop
function popcount32(x)
    x ← x - ((x >> 1) & 0x55555555)                  // 2-bit sums
    x ← (x & 0x33333333) + ((x >> 2) & 0x33333333)   // 4-bit sums
    x ← (x + (x >> 4)) & 0x0F0F0F0F                  // 8-bit sums
    return ((x * 0x01010101) & 0xFFFFFFFF) >> 24     // add 4 bytes

ctz(x) ← popcount((x & -x) - 1)          // x ≠ 0

Code Explained

Kernighan runs once per set bit: fast on sparse words
SWAR adds neighbors in widening groups (1 → 2 → 4 → 8 bits)
The multiply sums all four byte counts into the top byte
(x & -x) - 1 turns the trailing zeros into ones, then counts them

⚠ Common Mistakes

  • __builtin_clz(0) is undefined. Check for 0 first
  • Python counts the magnitude: (-1).bit_count() is 1. Mask first
  • Using floating log2() for bit length; it rounds wrong for huge values

✓ Tips & Best Practices

  • CPU support: x86 POPCNT, LZCNT, TZCNT; ARM CLZ, CNT
  • Hamming distance = popcount(a ^ b)
  • Popcount a big bitset word by word and sum

Quick Summary

  • popcount — number of 1 bits
  • ctz — index of the lowest 1
  • clz — zeros above the highest 1
  • bit length — w - clz(x)
