Bitwise in C# & Go

C#: >>> (C# 11) · [Flags] & HasFlag · BitOperations · checked · Go: &^ AND NOT · ^x NOT · math/bits · iota flags

Two Languages with Real Unsigned Types

C# works like Java (two's complement, wraps by default) but adds unsigned types (byte is unsigned, sbyte signed, plus uint, ulong), >>> since C# 11, and [Flags] enums. Go also has unsigned types, writes NOT as unary ^x, adds &^ (AND NOT, "bit clear"), and keeps helpers in math/bits.

Notes

  • C#: wraps unless checked; shift counts masked
  • Go: shifting by ≥ width gives 0 (−1 for a negative >>)
  • Go needs explicit conversions: uint32(b) << 24

C#

uint x = 0b1011_0010;                  // 178
Convert.ToString(x, 2);                // "10110010"
x.ToString("X8");                      // "000000B2"
int a = -16 >>> 2;                     // 1073741820
int b = 1 << 33;                       // 2 (count masked)
BitOperations.PopCount(x);             // 4
BitOperations.TrailingZeroCount(x);    // 1
BitOperations.RotateLeft(x, 4);        // 2848
uint.IsPow2(64u);                      // true (.NET 7+)

[Flags] enum Perm { None = 0, R = 1, W = 2, X = 4 }
var p = Perm.R | Perm.W;
p.HasFlag(Perm.W);                     // true
p.ToString();                          // "R, W"

Go

x := uint32(0b1011_0010)          // 178
fmt.Sprintf("%08b %#x", x, x)     // "10110010 0xb2"
strconv.ParseUint("ff", 16, 32)   // 255, nil
^x                                // NOT: 4294967117
x &^ 0b11                         // AND NOT: 176
bits.OnesCount32(x)               // 4
bits.TrailingZeros32(x)           // 1
bits.Len32(x)                     // 8
bits.RotateLeft32(x, 4)           // 2848 (k < 0: right)
binary.BigEndian.Uint32(buf)      // bytes → uint32

const (
    R = 1 << iota                 // 1, then W = 2, X = 4
    W
    X
)

C#: BitArray, Endianness, checked

var bits = new BitArray(16) { [3] = true };
bits.Get(3);                                   // true
Span<byte> buf = stackalloc byte[4];
BinaryPrimitives.WriteUInt32BigEndian(buf, 0x12345678);
BinaryPrimitives.ReadUInt32LittleEndian(buf); // 0x78563412
checked { int n = int.MaxValue; n++; }  // OverflowException

Go: A Bitset Type

type Bitset []uint64
func (s Bitset) Has(i int) bool {
    return s[i>>6]&(1<<(i&63)) != 0
}
func (s Bitset) Set(i int) { s[i>>6] |= 1 << (i & 63) }
s := make(Bitset, 2)          // 128 bits
s.Set(70); s.Has(70)          // true

⚠ Common Mistakes

  • C#: byte c = a & b; won't compile; byte ops return int. Cast back
  • Go: ~x doesn't compile as NOT; write ^x
  • Go: b << 24 on a byte stays a byte (0). Convert first

✓ Tips & Best Practices

  • C#: give [Flags] enums powers of two and a None = 0
  • C#: BinaryPrimitives parses bytes without allocations
  • Go: %b, %08b, %#x print bits; bits.Add64 / Mul64 do carry math

Quick Summary

  • C# >>>, [Flags], BitOperations
  • Go ^x — NOT; &^ — AND NOT
  • Go math/bits — count, rotate, reverse
  • both — wrap on overflow, no UB
