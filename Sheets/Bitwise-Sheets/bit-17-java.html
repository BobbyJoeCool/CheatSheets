Bitwise in Java

int (32) / long (64) · >>> · b & 0xFF · shift count masked · 1L << 40 · Integer.bitCount / rotateLeft · BitSet / EnumSet

Fixed Width, Signed, Promoted

Java integers are fixed-width two's complement: byte 8, short 16, char 16 (unsigned), int 32, long 64. Overflow wraps silently. Every bitwise operator promotes byte, short and char to int first, which causes most surprises. Java has >>> for logical right shift and a rich set of static helpers on Integer and Long.

Notes

  • Shift counts are masked: int x << 33 is x << 1
  • (byte) 0xF0 is −16; b & 0xFF gives 240
  • Unsigned helpers (Java 8+): toUnsignedString, compareUnsigned

Java Bit Toolkit

int x = 0b1011_0010;                     // 178
Integer.toBinaryString(x);               // "10110010"
Integer.toHexString(-1);                 // "ffffffff"
Integer.parseInt("1011", 2);             // 11

int a = -16 >> 2;                        // -4
int b = -16 >>> 2;                       // 1073741820
int c = 1 << 33;                         // 2  (count masked to 1)
long d = 1L << 33;                       // 8589934592

byte raw = (byte) 0xF0;                  // -16
int u = raw & 0xFF;                      // 240

Integer.bitCount(x);                     // 4
Integer.numberOfTrailingZeros(x);        // 1
Integer.highestOneBit(x);                // 128
Integer.rotateLeft(x, 4);                // 2848

Code Explained

& 0xFF undoes sign extension when a byte becomes an int
>>> on a byte shifts the promoted int: (byte)-16 >>> 4 is 268435455
Bytes → int: (b0 & 0xFF) << 24 | (b1 & 0xFF) << 16 | …
Long mirrors Integer: Long.bitCount, Long.numberOfLeadingZeros

Bytes & Unsigned Helpers

byte[] buf = {0x12, 0x34, 0x56, 0x78};
ByteBuffer.wrap(buf).getInt();          // 0x12345678 (big-endian)
ByteBuffer.wrap(buf)
    .order(ByteOrder.LITTLE_ENDIAN)
    .getInt();                          // 0x78563412
long u = Integer.toUnsignedLong(-1);    // 4294967295
Integer.compareUnsigned(-1, 1);         // 1: -1 is the largest

⚠ Common Mistakes

  • 1 << 40 without L gives 256
  • long m = 0xFFFFFFFF; is −1L (sign-extended int). Write 0xFFFFFFFFL
  • x & MASK == 0 doesn't compile; it means x & (MASK == 0). Parenthesize

✓ Tips & Best Practices

  • Add L to any constant you'll shift by 31 or more
  • toBinaryString drops leading zeros; pad with String.format
  • Prefer EnumSet over int flags in public APIs

Quick Summary

  • >>> — logical right shift
  • b & 0xFF — unsigned byte
  • 1L << n — 64-bit shifts
  • Integer / Long — bitCount, rotate, reverse
