Test, Set, Clear, Toggle

Most bit work comes down to four moves on one position i: test, set, clear and toggle. Each builds a one-bit mask with 1 << i, then combines it with x using AND, OR, AND-NOT or XOR. Learn these four lines and you can read most flag and bitset code.

Notes

  • Positions count from 0 at the LSB
  • 1 << i must be as wide as x. For i ≥ 31 use a 64-bit one: 1L << i
  • Set/clear/toggle return a new value; assign it back (x |= m)

The Four Moves (pseudocode)

x ← 0b0010_1001                    // 41: bits 0, 3, 5 set
i ← 3

bit   ← (x >> i) & 1               // test → 1
isSet ← (x & (1 << i)) ≠ 0         // test as boolean → true

x | (1 << 2)       // 0b0010_1101   set bit 2
x & ~(1 << 3)      // 0b0010_0001   clear bit 3
x ^ (1 << 5)       // 0b0000_1001   toggle bit 5

// Write bit i to v (0 or 1) without branching
function setBitTo(x, i, v)
    return (x & ~(1 << i)) | (v << i)

isOdd ← (x & 1) = 1                // lowest bit: odd/even

// Several bits at once with one mask
m      ← (1 << 0) | (1 << 3)       // 0b0000_1001
allSet ← (x & m) = m               // true: both bits set
anySet ← (x & m) ≠ 0               // true: at least one

Code Explained

Test with ≠ 0, not = 1: x & (1 << 3) is 8, not 1
~(1 << i) is all ones except bit i: an AND mask with one hole
setBitTo clears first, then ORs v in, so it works whatever bit i held
x & 1 handles negatives better than x mod 2: in C/Java -3 % 2 is −1, -3 & 1 is 1

⚠ Common Mistakes

  • (x & (1 << i)) == 1 is only true for i = 0. Compare with != 0
  • 1 << 31 on a 32-bit signed int is negative. Use unsigned
  • x | 1 << i on its own line changes nothing. Assign it
  • ~1 << i is (~1) << i. Write ~(1 << i)

✓ Tips & Best Practices

  • Name positions or masks: READ = 1 << 0
  • Use library helpers: BitSet, std::bitset::test/set/reset/flip
  • Group bits in one mask to test several at once
  • Prefer != 0 tests; they work for any bit position

Quick Summary

  • (x >> i) & 1 — test bit i
  • x | (1 << i) — set bit i
  • x & ~(1 << i) — clear bit i
  • x ^ (1 << i) — toggle bit i
