Unlimited Width, Infinite Sign Bits

Python ints are arbitrary precision: they never overflow, and negative numbers act as if they had infinitely many leading 1 bits. That keeps ~ and >> mathematically clean (~x == -x - 1, and >> floors), but there is no fixed width. When you need 32- or 64-bit behavior, for hashes, protocols or ports of C code, mask with & 0xFFFFFFFF yourself.

Notes

  • No >>>: mask first, then shift: (x & 0xFFFFFFFF) >> n
  • bool is an int: True & 1 == 1
  • On sets, & | ^ - mean ∩, ∪, Δ, difference

Python Bit Toolkit

x = 0b1011_0010                       # 178
bin(x), hex(x), oct(x)                # ('0b10110010', '0xb2', '0o262')
f"{x:08b} {x:#06x}"                   # '10110010 0x00b2'
int("1011_0010", 2), int("ff", 16)    # (178, 255)

~5, -7 >> 1, 1 << 64                  # (-6, -4, 18446744073709551616)
x.bit_length(), x.bit_count()         # (8, 4)   bit_count: 3.10+

def u32(v): return v & 0xFFFFFFFF     # wrap to unsigned 32-bit
u32(-1)                               # 4294967295
u32(-16) >> 2                         # 1073741820  (Java's -16 >>> 2)
(0x12345678).to_bytes(4, "big")       # b'\x124Vx'
int.from_bytes(b"\x01\x00", "little") # 1

Code Explained

:08b pads to 8 binary digits; # adds the 0x / 0b prefix
bin(-5) is '-0b101'. To see two's-complement bits: bin(-5 & 0xFF) → '0b11111011'
Signed view of 32 bits: v - (1 << 32) if v & 0x80000000 else v
bit_count() counts the magnitude: (-1).bit_count() is 1
to_bytes raises OverflowError if the value doesn't fit (or is negative without signed=True)

Named Flags with IntFlag

from enum import IntFlag

class Perm(IntFlag):
    R = 4
    W = 2
    X = 1

p = Perm.R | Perm.W          # <Perm.R|W: 6>
Perm.W in p                  # True
p & ~Perm.W                  # <Perm.R: 4>

Porting 32-Bit Code

def fnv1a_32(data: bytes) -> int:
    h = 0x811C9DC5
    for b in data:
        h ^= b
        h = (h * 0x01000193) & 0xFFFFFFFF  # stay 32-bit
    return h

hex(fnv1a_32(b"a"))          # '0xe40c292c'

⚠ Common Mistakes

  • Expecting ~0 to be 0xFFFFFFFF. It's −1; use ~x & 0xFFFFFFFF
  • Porting C hashes without masking: values grow past 32 bits instead of wrapping
  • 2 ^ 10 is 8 (XOR). Powers are 2 ** 10 or 1 << 10

✓ Tips & Best Practices

  • f"{x:032b}" shows all 32 bits
  • IntFlag members combine with | and print by name
  • bit_length() gives floor(log₂ x) + 1 exactly; no float rounding

Quick Summary

  • int — unbounded, never overflows
  • & 0xFFFFFFFF — force 32-bit width
  • bin, format(x, "08b"), int(s, 2) — print & parse
  • bit_length, bit_count — length & popcount
