Sheet 03

Project Layout & Archetypes

archetype:generate · maven-archetype-quickstart · src/main/java · src/test/java · src/main/resources · target/ · .mvn/

The Standard Directory Layout

Every Maven plugin assumes the same folders, so a project that follows them needs almost no configuration. Production code goes in src/main/java, tests in src/test/java, and non-code files in the matching resources folders. Build output goes to target/. An archetype is a project template: archetype:generate creates this layout with a starter POM.

Notes

  • target/ is disposable; add it to .gitignore
  • Package folders mirror the Java package: com/example/app
  • .mvn/ holds the wrapper, maven.config and extensions.xml
  • For Spring Boot, start.spring.io generates the same layout

Generate a Project

mvn archetype:generate \
  -DgroupId=com.example \
  -DartifactId=my-app \
  -DarchetypeArtifactId=maven-archetype-quickstart \
  -DarchetypeVersion=1.5 \
  -DinteractiveMode=false

cd my-app && tree
my-app/
├── pom.xml
└── src/
    ├── main/java/com/example/App.java
    └── test/java/com/example/AppTest.java

mvn archetype:generate          # interactive: pick from a list
mvn package                     # creates target/
ls target/
#  classes/  test-classes/  surefire-reports/
#  my-app-1.0-SNAPSHOT.jar

Code Explained

-DarchetypeArtifactId — which template to use
-DarchetypeVersion — pin it; old defaults target ancient Java
-DinteractiveMode=false — no prompts (scripts, CI)
target/classes — compiled main code and copied resources

Gradle Equivalent

  • archetype:generate → gradle init
  • Same src/main/java / src/test/java layout
  • target/ → build/
  • See Gradle 03

Idiomatic Maven

  • <sourceDirectory>src</sourceDirectory> → move files into src/main/java
  • config files next to classes → src/main/resources
  • test data in src/main → src/test/resources

Standard Folders

FolderHolds
src/main/javaApplication source
src/main/resourcesConfig, templates, SQL (on classpath)
src/test/javaTest source
src/test/resourcesTest-only files
src/main/webappWeb content (war packaging)
target/All build output

⚠ Common Mistakes

  • Running archetype:generate without -DarchetypeVersion — you may get an old template with Java 1.7 settings
  • Putting application.properties in src/main/java — it never reaches the classpath
  • Committing target/ — it is regenerated on every build

✓ Tips & Best Practices

  • After generating, update the JUnit version and set maven.compiler.release
  • Create your own archetype from an existing project: mvn archetype:create-from-project
  • Use -B (batch mode) in scripts to avoid any prompt

Quick Summary

  • archetype:generate — scaffold a project
  • src/main / src/test — code and resources
  • target/ — build output, never committed
  • .mvn/ — per-project Maven settings
