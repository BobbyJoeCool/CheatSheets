Sheet 12

Repositories & settings.xml

Maven Central · ~/.m2/repository · <repositories> · <mirrors> · <servers> credentials · encrypted passwords · .mvn/maven.config

Where Artifacts Come From

Maven resolves artifacts from the local repository (~/.m2/repository) first, then from remote repositories: Maven Central by default, plus any declared in the POM. Machine-specific settings live in ~/.m2/settings.xml: mirrors that redirect traffic to a company proxy (Nexus, Artifactory), server credentials, and proxies. Keep credentials out of the POM.

Notes

  • Global settings: $MAVEN_HOME/conf/settings.xml
  • A <server> id must match the repository or mirror id
  • Plain http:// repositories are blocked since Maven 3.8.1

Under the Hood

  • Lookup order: local repo → mirror (if it matches) → repositories in the POM
  • _remote.repositories records where each file came from; *.lastUpdated marks failed lookups
  • SNAPSHOT update policy defaults to daily; -U forces a check

~/.m2/settings.xml

<settings>
  <mirrors>
    <mirror>
      <id>corp</id>
      <mirrorOf>*</mirrorOf>          <!-- route ALL repos here -->
      <url>https://nexus.acme.com/repository/maven-public/</url>
    </mirror>
  </mirrors>

  <servers>
    <server>
      <id>corp</id>                     <!-- matches the mirror id -->
      <username>${env.NEXUS_USER}</username>
      <password>${env.NEXUS_TOKEN}</password>
    </server>
  </servers>
</settings>

<!-- pom.xml: an extra repository -->
<repositories>
  <repository>
    <id>confluent</id>
    <url>https://packages.confluent.io/maven/</url>
    <snapshots><enabled>false</enabled></snapshots>
  </repository>
</repositories>

Code Explained

<mirrorOf>* — every repository request goes to Nexus
${env.NEXUS_TOKEN} — credentials from the environment, not the file
<snapshots><enabled>false — releases only from this repo
Use mvn -s ci-settings.xml for a CI-specific file

Gradle Equivalent

  • Central → mavenCentral(); extra repo → maven { url = uri("…") }
  • Mirrors → dependencyResolutionManagement in settings
  • ~/.m2/repository → mavenLocal() (avoid in Gradle)
  • See Gradle 10

Idiomatic Maven

  • passwords in pom.xml → <servers> in settings.xml
  • plain-text passwords in settings → env vars or mvn --encrypt-password
  • <repositories> in every project → one company mirror

mirrorOf Patterns

PatternMatches
*Every repository
external:*All except localhost / file repos
centralOnly Maven Central
*,!confluentAll except confluent

Local Repo Commands

CommandDoes
dependency:go-offlineDownload everything for -o

--encrypt-master-passwordCreate settings-security.xml

⚠ Common Mistakes

  • A <server> id that doesn't match the mirror id — 401 Unauthorized
  • Stale *.lastUpdated files after a network blip — builds keep failing until -U or deletion
  • Committing a settings.xml with real tokens to the repo

✓ Tips & Best Practices

  • See the merged settings: mvn help:effective-settings
  • Keep a .mvn/maven.config line like -s .mvn/settings.xml for team-wide (secret-free) settings
  • Browse and search Central at central.sonatype.com

Quick Summary

  • ~/.m2/repository — local cache
  • <mirror> — reroute to a proxy
  • <server> — credentials by id
  • -U — force update checks
