Common Commands

mvn …Does
cleanDelete target/
compileCompile main code
testUnit tests (Surefire)
packageBuild the JAR / WAR
verifyPackage + ITs + checks
installCopy to ~/.m2
deployUpload to remote repo
dependency:treeDependency tree
dependency:analyzeUnused / undeclared deps
help:effective-pomMerged POM
help:active-profilesActive profiles
versions:display-dependency-updatesNewer versions
exec:javaRun -Dexec.mainClass

Command-Line Flags

FlagEffect
-D name=valueSet a property
-P a,!bProfiles on / off
-o / -UOffline / force updates
-q / -X / -eQuiet / debug / stack traces
-B / -ntpBatch mode / no progress
-T 1CParallel, 1 thread per core
-f path/pom.xmlUse another POM
-s settings.xmlUse another settings file
-NRoot POM only
-fae / -ffFail at end / fast
-DskipTestsDon't run tests
-Dmaven.test.skip=trueDon't compile tests
-vMaven + JDK versions

Reactor (Multi-Module)

FlagEffect
-pl a,bOnly modules a, b
-pl !cEverything except c
-amPlus upstream dependencies
-amdPlus downstream dependents
-rf :xResume from module x
-r (Maven 4)Resume after last failure
