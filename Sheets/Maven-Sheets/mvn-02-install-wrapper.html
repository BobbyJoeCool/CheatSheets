Sheet 02

Installing Maven & the Wrapper

SDKMAN / Homebrew · JAVA_HOME · mvn -v · mvnw / mvnw.cmd · .mvn/wrapper/maven-wrapper.properties · mvn wrapper:wrapper

Install Once, Wrap Every Project

Install Maven globally with a package manager so mvn works anywhere, then add the Maven Wrapper to each project. The wrapper is a pair of scripts (mvnw, mvnw.cmd) plus .mvn/wrapper/maven-wrapper.properties that downloads and runs the exact Maven version the project expects. Commit all three so every developer and CI server builds with the same Maven.

Notes

  • Maven needs a JDK, not just a JRE; it finds it via JAVA_HOME or PATH
  • Wrapper 3.3+ defaults to only-script: no maven-wrapper.jar to commit
  • Downloaded Maven versions land in ~/.m2/wrapper/dists

Install, Verify, Add the Wrapper

sdk install maven                # SDKMAN (macOS / Linux)
brew install maven               # Homebrew
winget install Apache.Maven      # Windows

mvn -v                           # Maven, Java version, JAVA_HOME

# add (or upgrade) the wrapper in a project
mvn wrapper:wrapper -Dmaven=3.10.0
./mvnw -v                        # first run downloads Maven
./mvnw clean verify              # use mvnw from now on
mvnw.cmd clean verify            # Windows

# .mvn/wrapper/maven-wrapper.properties
distributionUrl=https://repo.maven.apache.org/maven2/\
  org/apache/maven/apache-maven/3.10.0/apache-maven-3.10.0-bin.zip

Code Explained

mvn -v — confirms which JDK Maven will compile with
wrapper:wrapper — writes mvnw, mvnw.cmd and .mvn/wrapper/
-Dmaven= — version to pin; re-run with a new one to upgrade
distributionUrl — the zip mvnw downloads; point it at a mirror if needed

Gradle Equivalent

  • mvnw → gradlew
  • maven-wrapper.properties → gradle-wrapper.properties
  • mvn wrapper:wrapper -Dmaven=x → gradle wrapper --gradle-version x
  • See Gradle 02

Idiomatic Maven

  • mvn in README and CI → ./mvnw
  • "install Maven 3.x first" docs → commit the wrapper and say nothing
  • a committed maven-wrapper.jar → only-script wrapper type

Wrapper Types (-Dtype=)

TypeWhat it commits
only-scriptScripts only; downloads Maven (default)
scriptScripts + downloads a wrapper JAR
binScripts + maven-wrapper.jar
sourceScripts + Java source of the downloader

⚠ Common Mistakes

  • JAVA_HOME pointing at an old JDK — mvn -v shows it; builds fail with "release 21 not supported"
  • Committing mvnw without the execute bit — run git update-index --chmod=+x mvnw
  • Upgrading Maven on your machine and assuming CI follows — only the wrapper version counts

✓ Tips & Best Practices

  • Add distributionSha256Sum to the properties file to verify the download
  • Corporate proxy? Set MVNW_REPOURL to your internal mirror
  • Keep a global Maven only for creating new projects; build with ./mvnw

Quick Summary

  • mvn -v — check Maven and JDK
  • mvn wrapper:wrapper — add the wrapper
  • ./mvnw — the command to use everywhere
  • distributionUrl — pins the Maven version
