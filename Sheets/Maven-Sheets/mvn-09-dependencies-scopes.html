Sheet 09

Declaring Dependencies & Scopes

<dependency> · compile · provided · runtime · test · system (avoid) · <optional> · classifier / type

Dependencies and Their Scope

Each <dependency> names an artifact by its coordinates and a scope that decides which classpaths it lands on and whether it passes on to projects that depend on yours. compile is the default and is visible everywhere. provided is for things the runtime supplies (the Servlet API, Lombok). runtime is needed only to run (JDBC drivers), and test only for tests.

Notes

  • Omit <version> when a BOM or parent manages it
  • <optional>true</optional> — used by you, not passed on
  • classifier picks a variant: sources, tests, linux-x86_64
  • Check the result: mvn dependency:tree

A dependencies Block

<dependencies>
  <dependency>                              <!-- compile (default) -->
    <groupId>com.google.guava</groupId>
    <artifactId>guava</artifactId>
    <version>33.4.8-jre</version>
  </dependency>
  <dependency>                              <!-- container supplies it -->
    <groupId>jakarta.servlet</groupId>
    <artifactId>jakarta.servlet-api</artifactId>
    <version>6.1.0</version>
    <scope>provided</scope>
  </dependency>
  <dependency>                              <!-- needed only to run -->
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <version>42.7.7</version>
    <scope>runtime</scope>
  </dependency>
  <dependency>                              <!-- version from junit-bom -->
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter</artifactId>
    <scope>test</scope>
  </dependency>
</dependencies>

Code Explained

compile — main + test classpath, and passed to consumers
provided — compile only; not packaged, not passed on
runtime — not visible to javac, only when running
No version on junit-jupiter — a BOM supplies it (sheet 11)

Gradle Equivalent

  • compile → implementation (or api)
  • provided → compileOnly; runtime → runtimeOnly
  • test → testImplementation
  • See Gradle 09

Idiomatic Maven

  • <scope>system</scope> + systemPath → install the JAR to a repository
  • JDBC driver at compile → runtime scope
  • Lombok at compile → provided + annotation processor path

Other Dependency Elements

ElementUse
<classifier>Variant: sources, tests, jdk8
<type>Packaging: jar (default), pom, test-jar
<optional>Don't pass to consumers
<exclusions>Drop a transitive (sheet 10)

⚠ Common Mistakes

  • Using provided for things that must ship in a Spring Boot fat JAR — they're missing at runtime
  • Leaving JUnit at compile scope — it ends up in your published dependencies
  • Copy-pasting a dependency with the wrong groupId (old javax.* vs jakarta.*)

✓ Tips & Best Practices

  • Search coordinates on central.sonatype.com and copy the Maven snippet
  • Find unused or undeclared dependencies: mvn dependency:analyze
  • Mark plugin-style extras <optional> so consumers don't inherit them

Quick Summary

  • compile — default, everywhere, transitive
  • provided — compile only, supplied at runtime
  • runtime — run only
  • test — tests only
