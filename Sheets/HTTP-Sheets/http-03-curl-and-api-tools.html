Sheet 03

Testing APIs with curl & Tools

curl -X / -H / -d / -i / -v · --json · -u · -L · HTTPie · Postman / Bruno · DevTools · copy as cURL

Talk to an API by Hand

curl is on every Mac, Linux box and Windows 10+, and it is the shared language of API docs: every example on these sheets can be pasted into a terminal. -v prints the whole conversation, which is the fastest way to see what really went over the wire. GUI clients (Postman, Bruno, Insomnia) save requests as collections, and the browser's Network tab shows what your front end actually sent.

House Style for This Set

  • In curl -v output, > lines are sent, < lines are received, * lines are curl's own notes
  • Raw messages show request, blank line, response; Host is often left out to save space
  • ... marks a trimmed token or body
  • $TOKEN, $KEY are shell variables you set first

curl You'll Use Every Day

API=https://api.example.com
curl $API/users/42                   # GET, prints body
curl -i $API/users/42                # + status line & headers
curl -I $API/users/42                # HEAD: headers only
curl -v $API/users/42                # full > request / < response
curl -X DELETE $API/users/42         # choose the method
curl -H "Accept: application/json" \
     -H "Authorization: Bearer $TOKEN" $API/me
curl -d 'name=Ada&role=admin' $API/users # form POST
curl --json '{"name":"Ada"}' $API/users # JSON POST
curl -u ada:s3cret $API/private      # Basic auth
curl -F avatar=@me.png $API/upload   # multipart
curl -L https://example.com/old      # follow redirects
curl -sS -o /dev/null -w '%{http_code}\n' $API/health

Code Explained

-d switches to POST and sends application/x-www-form-urlencoded
--json (curl 7.82+) = POST + JSON Content-Type and Accept
-X only changes the method word; it doesn't add a body
-F builds multipart/form-data; @file uploads a file
-w '%{http_code}' prints just the status, handy in scripts

In Your Stack

  • Express — supertest: await request(app).get('/users/42').expect(200)
  • Django — self.client.get('/users/42/') in TestCase; DRF adds APIClient
  • Spring — MockMvc: mvc.perform(get("/users/42")).andExpect(status().isOk())
  • Rails — Integration test: get user_path(42) then assert_response :success
  • ASP.NET — WebApplicationFactory<Program> → client.GetAsync("/users/42")
  • Go — httptest.NewRecorder() + h.ServeHTTP(rec, req), or httptest.NewServer

⚠ Common Mistakes

  • Using -X POST with -d: redundant, and -X with -L re-sends the forced method after a redirect
  • Forgetting quotes around JSON: the shell eats the braces and quotes
  • Leaving -k in scripts that reach production

✓ Tips & Best Practices

  • Reproduce a browser bug exactly: DevTools → Copy as cURL, then trim headers
  • Put a token in a variable once: export TOKEN=...
  • Pipe JSON to jq for readable output: curl -s ... | jq .

Quick Summary

  • -v — see the whole exchange
  • -i / -I — headers with body / headers only
  • --json · -d · -F — JSON · form · multipart
  • -H · -u · -L — header · Basic auth · follow redirects
