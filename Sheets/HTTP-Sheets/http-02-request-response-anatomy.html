Sheet 02

Anatomy of a Request & Response

scheme · host · port · path · query · fragment · percent-encoding · request line · status line · body

Every Part Has a Job

A URL names the resource: scheme, host, optional port, path, optional query string and a fragment the browser keeps to itself. The request puts the method and path on the request line, then headers (one Name: value per line, names case-insensitive), a blank line, and an optional body. The response mirrors that shape with a status line instead.

Notes

  • Path identifies the resource; query narrows or shapes it (filters, page)
  • The #fragment is never sent to the server
  • Header names are case-insensitive: content-type = Content-Type
  • HTTP/2+ sends headers lowercase and the request line as :method, :path pseudo-headers

Request and Response, Part by Part

POST /api/v1/orders?notify=true HTTP/1.1
Host: shop.example.com
Content-Type: application/json
Content-Length: 28
Authorization: Bearer eyJhbGciOiJSUzI1NiJ9...

{"sku":"A-100","quantity":2}

HTTP/1.1 201 Created
Location: /api/v1/orders/9001
Content-Type: application/json; charset=utf-8

{"id":9001,"status":"pending"}

Code Explained

POST method · /api/v1/orders path · ?notify=true query
Content-Type says how to parse the body; Content-Length its byte size
Authorization carries credentials (sheet 14)
201 Created + Location points to the new resource
charset=utf-8 is a media-type parameter after the ;

In Your Stack

  • Express — req.method · req.path · req.query.notify · req.get('Host') · req.body (needs express.json())
  • Django — request.method · request.path · request.GET['notify'] · request.headers['Host'] · request.body
  • Spring — @PathVariable · @RequestParam · @RequestHeader · @RequestBody
  • Rails — request.method · request.path · params[:notify] · request.headers["Host"] · request.raw_post
  • ASP.NET — [FromRoute] · [FromQuery] · [FromHeader] · [FromBody], or HttpContext.Request
  • Go — r.Method · r.URL.Path · r.URL.Query().Get("notify") · r.Host · r.Body

Debug It

  • DevTools → Network → click the request → Headers shows the request and status lines; Payload shows query and body
  • Server sees an empty body? Check Content-Type matches the parser you registered
  • A + in a query arrives as a space in most parsers: encode it as %2B

⚠ Common Mistakes

  • Building URLs with string concatenation: unencoded & or # in a value breaks the query
  • Putting secrets or tokens in the query string: they end up in logs, history and Referer
  • Expecting the server to see #fragment values

✓ Tips & Best Practices

  • Use your language's URL builder (URLSearchParams, urllib.parse.urlencode, UriComponentsBuilder)
  • Repeat keys for lists: ?tag=a&tag=b; document it, since frameworks differ
  • Keep URLs under ~2,000 characters; long filters belong in a POST body

Quick Summary

  • URL — scheme://host:port/path?query#fragment
  • request line — METHOD /path HTTP/version
  • headers — metadata; blank line; then body
  • %XX — percent-encode reserved characters
