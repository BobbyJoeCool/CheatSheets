CDI 4.1

Qualifiers, Producers & Alternatives

@Qualifier · @Default · @Produces · @Disposes · InjectionPoint · @Alternative · @Priority

Description

When two beans share a type, a qualifier annotation picks one. Producer methods turn anything (third-party objects, config values, per-injection values) into injectable beans, with optional disposers for cleanup. Alternatives swap an implementation per deployment, enabled globally with @Priority.

Notes

  • Every bean has @Any; beans without a qualifier also get @Default
  • Producer scope comes from an annotation on the producer method
  • InjectionPoint works only in @Dependent producers
  • Built-in @Named is a qualifier too, but string-based

Qualifier, Producer, Alternative

@Qualifier @Retention(RUNTIME) @Target({FIELD, PARAMETER, TYPE})
public @interface Express { }

@Express @ApplicationScoped
public class ExpressShipping implements Shipping { }
@ApplicationScoped
public class GroundShipping implements Shipping { }    // @Default

@Inject @Express Shipping fast;            // ExpressShipping
@Inject Shipping normal;                   // GroundShipping

public class Resources {
    @Produces @ApplicationScoped
    HttpClient http() { return HttpClient.newHttpClient(); }
    void close(@Disposes HttpClient c) { c.close(); }

    @Produces Logger log(InjectionPoint ip) {          // per class
        return Logger.getLogger(
            ip.getMember().getDeclaringClass().getName());
    }
}

@Alternative @Priority(1) @ApplicationScoped
public class FakeShipping implements Shipping { }      // wins when present

Code Explained

Custom qualifier = annotation with @Qualifier + RUNTIME retention
@Produces — method return value becomes a bean
@Disposes — called when the produced instance's scope ends
@Priority on an @Alternative enables it app-wide

Spring Equivalent

  • Qualifier → @Qualifier / @Primary
  • @Produces → @Bean method
  • @Alternative → @Profile or @ConditionalOnProperty · See Spring 10

Prefer / Avoid

  • @Named("express") strings → typed qualifier annotation
  • new third-party objects in many classes → one producer
  • alternatives in beans.xml → @Priority

Resolution Errors

ErrorCause → fix
Unsatisfied dependencyno bean matches → add scope/producer
Ambiguous dependency2+ match → add qualifier
Unproxyable typefinal class/method → remove final

Built-in Qualifiers

QualifierMeaning
@Defaultno other qualifier given

⚠ Common Mistakes

  • Forgetting RUNTIME retention — the qualifier is invisible and you get an ambiguity error
  • Producer method and a bean class for the same type — ambiguous; qualify one
  • Using InjectionPoint in an @ApplicationScoped producer — not allowed; one instance can't know every caller

✓ Tips & Best Practices

  • Group producers in a Resources class so third-party wiring lives in one place
  • Use Instance<Shipping> with @Any to iterate every implementation
  • Put test alternatives in src/test so they're only present in test deployments

Quick Summary

  • @Qualifier — choose between same-type beans
  • @Produces — make a bean from a method
  • @Disposes — cleanup
  • @Alternative + @Priority — swap impl
