Batch, Mail & Other Specs

Jakarta Batch · job XML · chunk / batchlet · Jakarta Mail · MimeMessage · XML Binding · SOAP

Description

Jakarta Batch runs long jobs as steps: either chunk (read → process → write in transactional chunks, with restart) or batchlet (one task). Jakarta Mail builds and sends email. Several XML-era specs (XML Binding, XML Web Services) are now optional and ship separately when you need them.

Notes

  • Batch jobs live in META-INF/batch-jobs/*.xml
  • Chunk steps checkpoint, so restarts resume
  • Mail session is usually a server resource

Batch Job (chunk)

<!-- META-INF/batch-jobs/import-products.xml -->
<job id="import-products" version="2.0">
  <step id="load">
    <chunk item-count="100">
      <reader ref="csvReader"/>
      <processor ref="productProcessor"/>
      <writer ref="productWriter"/>
    </chunk>
  </step>
</job>

Start a Job · Send Mail

long exec = BatchRuntime.getJobOperator()
    .start("import-products", new Properties());

@Resource(lookup = "java:app/mail/shop") Session mail;
MimeMessage m = new MimeMessage(mail);
m.setFrom("shop@example.com");
m.setRecipients(Message.RecipientType.TO, "bob@example.com");
m.setSubject("Order shipped");
m.setText("Your order is on its way.", "UTF-8");
Transport.send(m);

Code Explained

item-count — commit every 100 items
ref — CDI bean names (@Named) for reader/processor/writer
JobOperator — start, stop, restart, query executions
Transport.send — uses the session's SMTP config

Spring Equivalent

  • Jakarta Batch → Spring Batch (Job, Step, ItemReader)
  • Jakarta Mail → JavaMailSender (wraps the same API)

Prefer / Avoid

  • hand-rolled import loops → chunk step with restart
  • SMTP settings in code → server mail resource
  • new SOAP services → REST + JSON

⚠ Common Mistakes

  • Non-restartable reader (no checkpoint) — restart reprocesses from the beginning
  • Sending mail inside the order transaction — rollback can't unsend; send after commit
  • Assuming JAXB is on the classpath — add jakarta.xml.bind-api + an implementation

✓ Tips & Best Practices

  • Return checkpoint info from checkpointInfo() for restartable readers
  • Observe commit events (AFTER_SUCCESS) to send mail
  • Check getJobExecution(id).getBatchStatus() to monitor

Quick Summary

  • chunk — read/process/write in commits
  • batchlet — single task
  • JobOperator — control jobs
  • MimeMessage — email
