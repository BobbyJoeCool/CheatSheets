⚠ Common Mistakes

  • Spring's @Transactional / @Autowired in Jakarta code — not processed
  • javax.* imports on EE 9+ — silently ignored annotations
  • @Named alone — not a bean under annotated discovery

✓ Tips & Best Practices

  • Check the import package first when an annotation "does nothing"
  • Prefer CDI annotations over EJB equivalents for new code
  • Numbers in table titles point to the detail sheets

Quick Summary

  • CDI — scopes, injection, events
  • EJB — pools, timers, MDBs
  • REST — resources and params
