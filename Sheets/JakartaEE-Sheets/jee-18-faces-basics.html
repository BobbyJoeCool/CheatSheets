Faces 4.1

Faces Basics

Facelets XHTML · @Named backing beans · h:form · h:inputText · #{bean.property} · FacesContext

Description

Jakarta Faces is a server-side component framework. Pages are Facelets XHTML files built from components (h:inputText, h:dataTable); each component binds to a backing bean property through #{} EL. On submit, Faces converts, validates and updates the bean, then calls your action method.

Notes

  • Backing bean = @Named CDI bean with a scope (@ViewScoped, @RequestScoped)
  • Faces 4 removed @ManagedBean; CDI is required

Under the Container

  • Six phases: restore view → apply values → validate → update model → invoke app → render
  • Validation failure skips update + invoke, then re-renders with messages
  • View state is saved client- or server-side between requests (STATE_SAVING_METHOD)

signup.xhtml

<html xmlns:h="jakarta.faces.html" xmlns:f="jakarta.faces.core">
<h:body>
  <h:form>
    <h:inputText value="#{signup.email}" required="true"/>
    <h:inputSecret value="#{signup.password}"/>
    <h:commandButton value="Sign up" action="#{signup.save}"/>
    <h:messages/>
  </h:form>
</h:body></html>

Backing Bean

@Named @RequestScoped
public class Signup {
    private String email, password;     // + getters / setters
    @Inject UserService users;
    public String save() {
        users.register(email, password);
        return "welcome?faces-redirect=true";   // navigate
    }
}

Code Explained

jakarta.faces.html — Faces 4 namespace URNs (old xmlns.jcp.org still work)
value="#{signup.email}" — reads and writes the property
action — method returning the next view id, or null to stay

Spring Equivalent

  • Faces has no direct Spring twin; closest is Spring MVC + Thymeleaf forms (Spring 29)
  • JoinFaces runs Faces inside Spring Boot

Prefer / Avoid

  • @ManagedBean → @Named + CDI scope
  • @SessionScoped for form state → @ViewScoped
  • FacesContext.getCurrentInstance() everywhere → inject FacesContext

⚠ Common Mistakes

  • Missing setter — Faces reports "target unreachable" or "property not writable" on submit
  • @ViewScoped from the wrong package — use jakarta.faces.view.ViewScoped
  • Putting h:commandButton outside h:form — clicks do nothing

✓ Tips & Best Practices

  • Set jakarta.faces.PROJECT_STAGE=Development for detailed error pages
  • Use ?faces-redirect=true after POST to avoid resubmits
  • PrimeFaces or OmniFaces add richer components and utilities

Quick Summary

  • Facelets — XHTML views
  • @Named bean — backing model
  • #{bean.prop} — two-way binding
  • action — returns next view
