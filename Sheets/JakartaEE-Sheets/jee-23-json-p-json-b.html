JSON-B 3.0 · JSON-P 2.1

JSON Processing & Binding

JsonbBuilder · @JsonbProperty · @JsonbTransient · adapters · Json.createObjectBuilder · JsonPatch

Description

JSON-B binds Java objects to JSON and back, the default provider behind Jakarta REST. JSON-P is the lower-level API: build and read JSON trees or stream tokens, plus JsonPointer and JsonPatch. Use JSON-B for DTOs; reach for JSON-P for dynamic shapes and partial updates.

Notes

  • Records serialize by component (JSON-B 3)
  • Default naming is Java property names; change with a strategy
  • Implementations: Yasson (JSON-B), Parsson (JSON-P)
  • Jackson is common too, but isn't a Jakarta spec

JSON-B Binding

public record ProductDto(
    long id,
    @JsonbProperty("display_name") String name,
    @JsonbNumberFormat("#0.00") BigDecimal price,
    @JsonbDateFormat("yyyy-MM-dd") LocalDate added,
    @JsonbTransient String internalNote) { }

Jsonb jsonb = JsonbBuilder.create(new JsonbConfig()
    .withPropertyNamingStrategy(
        PropertyNamingStrategy.LOWER_CASE_WITH_UNDERSCORES)
    .withNullValues(false));
String json = jsonb.toJson(dto);
    // {"id":1,"display_name":"Mug","price":"9.50",...}
ProductDto back = jsonb.fromJson(json, ProductDto.class);

JSON-P Tree & Patch

JsonObject o = Json.createObjectBuilder()
    .add("sku", "MUG-1").add("qty", 2).build();  // {"sku":"MUG-1","qty":2}
JsonPatch patch = Json.createPatchBuilder()
    .replace("/qty", 5).build();
JsonObject updated = patch.apply(o);         // {"sku":"MUG-1","qty":5}

Code Explained

@JsonbProperty — rename one field
@JsonbTransient — never serialized
withNullValues(false) — omit nulls
JsonPatch — RFC 6902 ops: add, remove, replace, move

Spring Equivalent

  • Spring uses Jackson: @JsonProperty, @JsonIgnore, @JsonFormat
  • ObjectMapper / Jackson 3 JsonMapper ≈ Jsonb · See Spring 25

Prefer / Avoid

  • serializing entities → record DTOs
  • new Jsonb per call → one shared Jsonb (thread-safe)
  • Map<String,Object> for known shapes → typed records

⚠ Common Mistakes

  • Returning JPA entities — lazy collections trigger extra queries or fail outside the transaction
  • Expecting Jackson annotations to work with JSON-B — they're ignored unless Jackson is the provider
  • Creating a Jsonb per request — it's expensive; cache it or use a ContextResolver

✓ Tips & Best Practices

  • Customize REST's JSON-B with a ContextResolver<Jsonb> provider
  • Use JsonMergePatch for PATCH with application/merge-patch+json
  • Keep DTOs as records; validation annotations work on components

Quick Summary

  • JSON-B — object ↔ JSON
  • @JsonbProperty — rename
  • JSON-P — trees & streams
  • JsonPatch — partial updates
