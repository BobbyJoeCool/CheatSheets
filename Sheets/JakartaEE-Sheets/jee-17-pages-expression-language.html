Pages & Expression Language

Jakarta Pages (JSP) · ${} · #{} · implicit objects · EL lambdas · JavaBean properties

Description

Jakarta Expression Language (EL) is the small expression syntax shared by Pages (JSP) and Faces. It reads JavaBean properties, calls methods and evaluates operators. **${} evaluates immediately (Pages); #{}** is deferred and can also write back to a property (Faces forms). This sheet is a primer; the JSP set covers Pages in depth.

Notes

  • #{user.name} calls getName() / setName() (sheet 05)
  • EL 6 (EE 11) resolves record components and Optional
  • New UI work usually picks Faces or a JS front end
  • See the JSP set for tags, JSTL and directives

EL in a Page

<%@ page contentType="text/html;charset=UTF-8" %>
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<p>Hello, ${user.name}</p>                <!-- getName() -->
<p>Items: ${cart.items.size()}</p>        <!-- method call -->
<p>${empty cart.items ? 'Empty' : 'Has items'}</p>
<p>Total: ${cart.total gt 100 ? 'Free shipping' : ''}</p>
<p>${param.q} · ${header['User-Agent']}</p>
<c:forEach items="${cart.items}" var="i">
  <li>${i.sku} × ${i.qty}</li>
</c:forEach>

EL Lambdas & Collections (EL 3+)

${[1, 2, 3].stream().map(x -> x * 2).toList()}     // [2, 4, 6]
${orders.stream().filter(o -> o.paid).count()}     // 3
${x = 5; x + 1}                                    // 6

Code Explained

${} — evaluate now, read-only
#{} — deferred; Faces evaluates it in its lifecycle
empty — true for null, "", empty collection
jakarta.tags.core — JSTL 3 URI (was java.sun.com/jsp/jstl/core)

Spring Equivalent

  • Thymeleaf ${...} / *{...} plays the same role (Spring 28)
  • Spring EL (SpEL) #{...} is a different language with similar syntax

Prefer / Avoid

  • Java scriptlets <% %> → EL + JSTL tags
  • old JSTL URIs → jakarta.tags.*
  • logic in EL → a bean method

⚠ Common Mistakes

  • Using ${} in a Faces input — it's read-only, so the value never posts back; use #{}
  • Expecting EL to throw on a missing property — it renders empty for null paths, hiding typos
  • Old JSTL URIs on EE 10+ — tags silently render as text

✓ Tips & Best Practices

  • Escape output with <c:out value="${x}"/> or fn:escapeXml in Pages
  • Keep EL to property reads; push logic into beans
  • Use ${not empty list} instead of size checks

Quick Summary

  • ${} — immediate
  • #{} — deferred, writable
  • empty — null/blank check
  • jakarta.tags.core — JSTL 3
