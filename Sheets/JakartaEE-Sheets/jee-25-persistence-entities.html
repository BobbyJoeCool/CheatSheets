Sheet 25
Persistence 3.2

Entities & persistence.xml

@Entity · @Id · @GeneratedValue · @Column · persistence unit · @Embeddable

Description

Jakarta Persistence (JPA) maps Java classes to tables. An **@Entity** needs an @Id and a no-arg constructor; fields map to columns by name. A persistence unit in META-INF/persistence.xml names the datasource and settings. EE 11's Persistence 3.2 adds Java records as embeddables and more Java time types.

Notes

  • Field access if @Id is on a field; property access if on a getter
  • Use jta-data-source so the server manages connections
  • jakarta.persistence.schema-generation.* creates tables (dev only)
  • See the SQL set for schema design

Entity + Embeddable

@Entity @Table(name = "products",
       uniqueConstraints = @UniqueConstraint(columnNames = "sku"))
public class Product {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    @Column(nullable = false, length = 40) private String sku;
    @Column(precision = 10, scale = 2) private BigDecimal price;
    @Enumerated(EnumType.STRING) private Status status;
    @Embedded private Dimensions size;          // columns in same table
    @Version private long version;              // optimistic locking
    protected Product() { }                     // required by JPA
}
@Embeddable public record Dimensions(int width, int height) { } // 3.2

persistence.xml

<persistence-unit name="shop" transaction-type="JTA">
  <jta-data-source>java:app/jdbc/shop</jta-data-source>
  <properties>
    <property name="jakarta.persistence.schema-generation.database.action"
              value="create"/>
  </properties>
</persistence-unit>

Code Explained

IDENTITY — DB auto-increment; SEQUENCE batches better
EnumType.STRING — survives enum reordering
@Version — throws OptimisticLockException on stale updates
transaction-type="JTA" — container transactions

Spring Equivalent

  • Same jakarta.persistence annotations in Spring Data JPA
  • persistence.xml → spring.datasource.* + spring.jpa.* · See Spring 36

Prefer / Avoid

  • EnumType.ORDINAL → EnumType.STRING
  • schema generation in prod → Flyway/Liquibase migrations
  • java.util.Date → LocalDate / Instant

⚠ Common Mistakes

  • equals/hashCode on the generated id — new entities (id null) break sets; use a business key
  • Public no-arg constructor missing — provider can't instantiate; protected is enough
  • schema-generation drop-and-create left on — wipes the database on redeploy

✓ Tips & Best Practices

  • Define the datasource in the server or with @DataSourceDefinition
  • Use @Column(nullable=false) to match DB constraints so errors surface early
  • Log SQL with your provider's property (hibernate.show_sql) during dev

Quick Summary

  • @Entity — mapped class
  • @Id + @GeneratedValue — primary key
  • persistence.xml — unit + datasource
  • @Version — optimistic lock
