CDI 4.1

CDI Basics & Injection

@Inject · @Named · bean-defining annotations · discovery modes · CDI Lite · Instance<T>

Description

CDI (Contexts and Dependency Injection) is the Jakarta EE component model. The container discovers beans, creates them in the right scope, and wires dependencies by type with @Inject. Constructor injection is the preferred form. CDI Lite (Core Profile) works at build time; CDI Full adds decorators, conversations and portable extensions.

Notes

  • A class becomes a bean via a bean-defining annotation (any scope, @Dependent, stereotype)
  • Default discovery is annotated — plain classes aren't beans
  • @Named gives an EL name: #{orderService}
  • Quarkus and Helidon implement CDI Lite at build time

Under the Container

  • Normal-scoped beans are injected as a client proxy, not the real instance
  • annotated mode scans only classes with bean-defining annotations; all makes every class a bean
  • CDI Lite resolves injection at build time, so errors appear when you compile

Three Ways to Inject

@ApplicationScoped
public class CheckoutService {
    private final PaymentGateway gateway;
    private final Event<OrderPlaced> events;

    @Inject                                   // constructor (preferred)
    public CheckoutService(PaymentGateway g, Event<OrderPlaced> e) {
        this.gateway = g; this.events = e;
    }
    protected CheckoutService() { this(null, null); } // proxy needs it

    @Inject Clock clock;                      // field
    @Inject void setAudit(AuditLog a) { }     // initializer method

    @Inject Instance<Notifier> notifiers;     // dynamic / optional
    void notifyAll(Order o) {
        notifiers.forEach(n -> n.send(o));    // every Notifier bean
        if (notifiers.isUnsatisfied()) log.warn("no notifier");
    }
}

Code Explained

Constructor injection → final fields, easy unit tests
Normal-scoped beans need a non-private no-arg ctor for the proxy
Instance<T> — lazy, optional or multiple beans; get(), select()
Ambiguous or missing beans fail at deploy, not at runtime

Spring Equivalent

  • @Inject → @Autowired or plain constructor injection
  • Instance<T> → ObjectProvider<T>
  • @Named → bean name / @Qualifier · See Spring 08

Prefer / Avoid

  • field injection everywhere → constructor injection
  • CDI.current().select() lookups → @Inject
  • bean-discovery-mode="all" → annotated + explicit scopes

⚠ Common Mistakes

  • @Named without a scope — under annotated discovery it isn't a bean at all
  • Private no-arg constructor on an @ApplicationScoped bean — the proxy can't subclass it
  • Injecting into a static field — CDI ignores statics

✓ Tips & Best Practices

  • Read deploy logs for WELD-001408 (unsatisfied) and WELD-001409 (ambiguous)
  • Use @Model stereotype (= @Named @RequestScoped) for page models
  • Keep beans.xml out unless you need all or alternatives

Quick Summary

  • @Inject — type-safe injection
  • annotated — default discovery
  • Instance<T> — optional / many
  • CDI Lite — build-time subset
