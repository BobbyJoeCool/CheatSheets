⚠ Common Mistakes

  • Mixing descriptor versions — an old web-app version="4.0" can switch servers into legacy mode
  • Targeting Web Profile APIs on a Core runtime — missing at runtime
  • Renaming javax.sql / javax.crypto — Java SE packages keep javax

✓ Tips & Best Practices

  • Match descriptor versions to your EE release
  • Check your runtime's certified profile on jakarta.ee/compatibility
  • Omit descriptors entirely when annotations suffice

Quick Summary

  • Core — REST, CDI Lite, JSON
  • Web — + Servlet, JPA, Faces, Security, Data
  • Platform — + Messaging, Batch, Mail
