Data 1.0 (new in EE 11)

Jakarta Data Repositories

@Repository · CrudRepository · BasicRepository · @Find · @Query · PageRequest · Order

Description

Jakarta Data (new in EE 11) generates data access from an annotated interface, much like Spring Data. Extend BasicRepository or CrudRepository, or write annotated methods (@Find, @Insert, @Delete) and **@Query** with JDQL. The runtime implements the interface; inject it with @Inject.

Notes

  • Works over Jakarta Persistence or NoSQL providers
  • Method-name queries (findByName) exist but annotations are preferred
  • @By matches a parameter to an attribute
  • Hibernate generates repositories at compile time

Repository Interface

@Repository
public interface Products extends CrudRepository<Product, Long> {

    @Find Optional<Product> bySku(@By("sku") String sku);

    @Find @OrderBy("price")
    List<Product> inStatus(Status status);           // by param name

    @Query("WHERE price < :max AND name LIKE :pattern")
    Page<Product> cheap(BigDecimal max, String pattern, PageRequest page);

    @Delete void discontinued(Status status);        // bulk delete

    List<Product> findByNameContainsIgnoreCase(String part);  // name-based
}

@Inject Products products;
products.insert(new Product("MUG-1"));
Page<Product> first = products.cheap(TEN, "%mug%",
        PageRequest.ofSize(20));                      // page 1
first.content(); first.totalElements(); first.hasNext();

Code Explained

CrudRepository — insert, update, save, findById, delete…
@Find — parameters become WHERE conditions
@Query — JDQL, a subset of JPQL; FROM optional
PageRequest — 1-based pages, offset or cursor

Spring Equivalent

  • CrudRepository → Spring Data CrudRepository (Spring 38)
  • @Query / derived names → same idea (Spring 39–40)
  • PageRequest.ofSize → PageRequest.of(page, size)

Prefer / Avoid

  • hand-written DAO classes → @Repository interface
  • long method names → @Find + @By
  • save() everywhere → explicit insert / update

Paging & Sorting

TypeUse
PageRequest.ofPage(2)offset page

@OrderBy("price")static sort
Limit.of(10)first N

⚠ Common Mistakes

  • Mixing insert with an existing id — throws EntityExistsException; use update or save
  • Parameter names without -parameters compiler flag — @Find can't match; add @By or the flag
  • Expecting EE 10 servers to support it — Jakarta Data needs an EE 11 runtime

✓ Tips & Best Practices

  • Prefer cursor paging for large or changing tables
  • Return Stream<T> for big reads and close it
  • Keep complex queries in @Query; method names don't scale

Quick Summary

  • @Repository — generated interface
  • @Find / @Query — reads
  • @Insert/@Update/@Delete — writes
  • PageRequest — paging
