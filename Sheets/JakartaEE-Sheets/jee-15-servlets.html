Servlet 6.1

Servlets

HttpServlet · @WebServlet · doGet / doPost · HttpServletRequest · dispatching · async

Description

A servlet is the lowest layer of the Jakarta web tier: a class that receives an HttpServletRequest and writes an HttpServletResponse. REST, Faces and Spring MVC all run on top of servlets. You rarely write raw servlets now, but knowing them explains filters, sessions and threading everywhere above.

Notes

  • @WebServlet replaces web.xml mappings
  • Servlet 6.1 (EE 11) adds sendRedirect with status and HTTP/2 tweaks
  • One instance, many threads — no per-request fields

Under the Container

  • One servlet instance serves many threads at once, so instance fields are shared
  • The filter chain runs before the servlet's service() method
  • Async servlets hand the request off and free the container thread

A GET/POST Servlet

@WebServlet(urlPatterns = "/orders/*", asyncSupported = true)
public class OrderServlet extends HttpServlet {
    @Inject OrderService orders;                 // CDI works here

    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String id = req.getPathInfo().substring(1);    // /orders/42 → 42
        resp.setContentType("application/json");
        resp.getWriter().write(orders.json(id));
    }

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws IOException, ServletException {
        String sku = req.getParameter("sku");    // form or query param
        orders.create(sku);
        resp.sendRedirect(req.getContextPath() + "/orders");  // 302
    }
}

Code Explained

urlPatterns — /x exact, /x/* prefix, *.do extension
getPathInfo() — part after the servlet path
getParameter — query string or form body, first value
sendRedirect — 302 to a new URL; forward stays server-side

Spring Equivalent

  • Spring MVC's DispatcherServlet is one servlet that routes to controllers
  • @WebServlet → @RestController method · See Spring 20

Prefer / Avoid

  • web.xml <servlet-mapping> → @WebServlet
  • raw servlets for JSON APIs → Jakarta REST (sheet 21)
  • string concatenation into HTML → templates (Faces/Pages)

⚠ Common Mistakes

  • Instance fields for request data — two concurrent requests overwrite each other
  • Writing to the response after sendRedirect — throws IllegalStateException
  • Hard-coding /shop — use getContextPath() so it works under any context root

✓ Tips & Best Practices

  • Set the content type and encoding before calling getWriter()
  • Use asyncSupported = true on every filter in the chain too
  • Test with curl -i to see status and headers

Quick Summary

  • HttpServlet — base class
  • @WebServlet — URL mapping
  • doGet / doPost — handlers
  • forward / sendRedirect — dispatch
