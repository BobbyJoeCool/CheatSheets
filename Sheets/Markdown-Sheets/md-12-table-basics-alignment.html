Pipe Tables

A pipe table (a GFM extension, not core CommonMark) has a header row, a delimiter row of dashes, then body rows, with | between cells. Colons in the delimiter row set each column's alignment. Cells can hold inline Markdown (bold, code, links, images) but not block content like lists or code blocks. Columns don't need to line up in the source.

Rules

  • Header and delimiter rows must have the same number of cells
  • Outer pipes are optional but make tables easier to read
  • Short body rows get empty cells; extra cells are dropped
  • Put a blank line before the table so it isn't read as a paragraph
  • Escape a pipe inside a cell as \|, even inside backticks

⚠ Common Mistakes

  • No blank line before the table — the rows print as one paragraph
  • Delimiter row with a different cell count than the header — not a table
  • Unescaped | in a cell (even in `code`) — splits the column
  • Putting lists or code blocks in cells — use an HTML table (Sheet 13)

✓ Tips & Best Practices

  • Let a formatter align columns: Prettier or VS Code "Markdown All in One"
  • Keep tables narrow; split wide ones or move detail below
  • Right-align number columns with ---:
  • Use tablesgenerator.com to paste from a spreadsheet
