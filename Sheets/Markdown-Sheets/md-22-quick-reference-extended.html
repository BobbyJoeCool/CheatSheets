⚠ Common Mistakes

  • Using an extension your renderer lacks — it shows up as literal [^1], ==x== or [!NOTE]
  • Copying Obsidian notes to GitHub — wikilinks and embeds break
  • Assuming GFM = GitHub — alerts, math, footnotes and Mermaid are GitHub features on top of the GFM spec

✓ Tips & Best Practices

  • ✔ supported · ✖ not supported · ext needs an extension, plugin or filter
  • MkDocs extensions mostly come from pymdown-extensions
  • For portable docs, stick to the CommonMark + GFM columns
