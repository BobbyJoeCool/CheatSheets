Highlighting & Diagrams

The language in a fence's info string picks the syntax highlighter grammar (GitHub uses Linguist; other tools use Prism, highlight.js, Shiki or Pygments). Special languages like diff and console color added lines or prompts. Line highlighting, titles and line numbers are site-generator features with tool-specific syntax. A mermaid fence renders a diagram from text on GitHub, GitLab, Obsidian and many doc tools.

Good to Know

  • Unknown language → plain, unhighlighted text
  • Aliases usually work: js, sh, yml, py
  • GitHub also renders geojson, topojson (maps) and stl (3D) fences
  • GitHub ignores titles and line highlights in the info string

⚠ Common Mistakes

  • Misspelled language (```pyhton) — silently renders unhighlighted
  • Using bash for terminal sessions — $ prompts get highlighted as code
  • Expecting Mermaid in every renderer — Pandoc and plain CommonMark show raw text
  • Copying Docusaurus {2} syntax into MkDocs, or the reverse

✓ Tips & Best Practices

  • Use console for commands with output, bash for scripts
  • Use diff to show before/after changes in docs
  • Test diagrams in the Mermaid Live Editor (mermaid.live)
  • Keep diagrams small; split big ones into several
