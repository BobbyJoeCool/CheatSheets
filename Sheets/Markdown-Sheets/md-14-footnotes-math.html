Footnotes & Math

A footnote has a marker in the text, [^label], and a definition anywhere in the file, [^label]: note text. Notes are collected at the bottom, numbered in order of first use, with links back to the text. Math uses LaTeX between dollar signs: $…$ inline, $$…$$ on its own lines for display math. GitHub renders math with MathJax; most other tools use KaTeX.

Good to Know

  • Labels can be words ([^gruber]); output is still numbered
  • Indent 4 spaces to add paragraphs to a footnote
  • Opening $ must not be followed by a space
  • Escape currency as \$ where math is enabled
  • Neither footnotes nor math are in core CommonMark

⚠ Common Mistakes

  • Unescaped $ in prices — $5 and $10 renders as math on GitHub
  • Expecting [^3] to print "3" — notes renumber by order of use
  • Underscores in inline math read as emphasis by some parsers — use $`…`$
  • $ x $ with inner spaces — not treated as math

✓ Tips & Best Practices

  • Use word labels ([^source]) so notes survive reordering
  • Keep definitions right after the paragraph that uses them
  • Put display math on its own lines with blank lines around it
  • Preview math in the target tool; MathJax and KaTeX differ slightly

Quick Summary
