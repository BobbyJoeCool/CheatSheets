Metadata & Attributes

Front matter is a YAML block between --- lines at the very top of a file. Site generators (Jekyll, Hugo, Astro, Docusaurus), Obsidian and Pandoc read it as page metadata; GitHub shows it as a table. Attribute lists like {#id .class key=value} attach HTML attributes to headings, images, links and blocks, and fenced divs (:::) wrap content in a styled container.

Good to Know

  • Front matter must start on line 1 — nothing before the first ---
  • YAML uses spaces, never tabs; quote values containing :
  • Hugo also accepts TOML (+++) and JSON front matter

⚠ Common Mistakes

  • A blank line or text before the first --- — renders as a rule plus a heading
  • title: Markdown: A Guide — unquoted colon breaks the YAML
  • Tabs in YAML — parse error, often a silent build failure
  • Using {#id} on GitHub — the braces show up in the heading

✓ Tips & Best Practices

  • Quote string values in YAML to be safe
  • Use ISO dates: 2026-10-04
  • Keep front matter keys consistent across a site; document them
  • Prefer fenced divs over raw HTML for styled blocks in Pandoc

Quick Summary

  • --- yaml --- — front matter at line 1
  • +++ toml +++ — Hugo alternative
  • {#id .class} — attributes (Pandoc, MkDocs)
  • ::: name — fenced div
