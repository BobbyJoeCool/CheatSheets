Unordered & Ordered Lists

An unordered item starts with -, * or + plus a space. An ordered item starts with a number followed by . or ). Only the first number matters: it sets the start value, and later numbers are ignored. A list is tight when items have no blank lines between them and loose when they do; loose items get wrapped in <p> tags, which adds vertical space.

Rules

  • Changing the marker (- → *) or delimiter (. → )) starts a new list
  • An ordered list can interrupt a paragraph only if it starts at 1
  • List numbers can be up to 9 digits; 0. is a valid start
  • Escape the period to stop accidental lists: 1986\.

⚠ Common Mistakes

  • -item with no space — renders as a paragraph, not a list
  • One stray blank line between items makes the whole list loose (extra spacing)
  • Switching from - to * mid-list — silently starts a new list
  • A sentence starting 2020. Great year — becomes list item 2020

✓ Tips & Best Practices

  • Use - everywhere (markdownlint MD004 enforces one style)
  • Use all 1. for long, reordered lists; real numbers when text cites step numbers
  • Leave a blank line before and after every list
  • Put <!-- --> between two lists that should stay separate

Quick Summary

  • - item — unordered list
  • 1. item — ordered list
  • N. first — sets the start number
  • blank lines — loose list with <p>
  • 1986\. — escape to avoid a list
