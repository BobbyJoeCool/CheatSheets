Tooling: Pandoc, Linters & Site Generators

pandoc -o · --toc · markdownlint · Prettier · MkDocs · Hugo / Jekyll · MDX

The Markdown Toolchain

Pandoc converts Markdown to and from almost any format: HTML, Word, PDF (through LaTeX), EPUB, slides. Linters like markdownlint catch structural problems, and formatters like Prettier rewrite files into one consistent style. Static site generators turn a folder of .md files into a website. MDX extends Markdown with JSX components for React-based doc sites.

Good to Know

  • Pandoc PDF output needs a LaTeX engine (or --pdf-engine=typst / weasyprint)
  • markdownlint rules are numbered (MD001, MD013 …); configure per project
  • Prettier formats Markdown out of the box, including tables
  • MDX is stricter than Markdown: unclosed tags and <!-- --> are errors

Common Commands

# Pandoc — convert
pandoc README.md -o README.pdf                  # needs LaTeX
pandoc notes.md -o notes.docx --toc             # Word + table of contents
pandoc -s doc.md -o doc.html --metadata title="Doc"
pandoc in.docx -t gfm -o out.md                 # Word → GitHub Markdown
pandoc paper.md --citeproc --bibliography refs.bib -o paper.pdf

# Lint & format
npx markdownlint-cli2 "**/*.md"                 # report problems
npx markdownlint-cli2 --fix "**/*.md"           # auto-fix what it can
npx prettier --write "**/*.md" --prose-wrap preserve

# Static sites
pip install mkdocs-material && mkdocs serve     # http://127.0.0.1:8000
hugo new site blog && hugo server
npx create-docusaurus@latest my-site classic

Code Explained

-o file.ext — output format guessed from the extension
-s — standalone file with <head>
-t gfm — write GitHub-Flavored Markdown
--citeproc — format citations from a .bib file
--fix — rewrite files to satisfy lint rules
--prose-wrap — always / never / preserve

⚠ Common Mistakes

  • Running pandoc … -o out.pdf without LaTeX installed — fails with an engine error
  • Turning on every lint rule — MD013 line length floods long-prose docs
  • --prose-wrap always on a repo that uses one sentence per line — reflows everything
  • Moving .md files to MDX without fixing HTML comments and bare <

✓ Tips & Best Practices

  • Commit a .markdownlint.json so everyone lints the same way
  • Run markdownlint and Prettier in CI or a pre-commit hook
  • Use pandoc --list-output-formats to see every target
  • Pick MkDocs for plain docs, Docusaurus/Astro when you need components

Quick Summary

  • pandoc in -o out — convert formats
  • markdownlint-cli2 — lint
  • prettier --write — format
  • mkdocs serve — preview a docs site
  • MDX — Markdown + JSX
