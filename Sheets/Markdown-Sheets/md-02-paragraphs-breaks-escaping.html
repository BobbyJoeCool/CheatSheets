Paragraphs, Breaks & Escapes

A paragraph is one or more consecutive lines of text; a blank line ends it. A single newline inside a paragraph is a soft break and renders as a space, so you can wrap source lines freely. For a hard break (<br>) end the line with a backslash or two spaces. A backslash before any ASCII punctuation character makes it literal, and HTML entities insert special characters.

Rules

  • Up to 3 leading spaces are ignored; 4+ starts an indented code block
  • Hard breaks do nothing on the last line of a paragraph
  • Escapes and entities are not processed inside code spans or blocks
  • HTML comments are hidden from the page but stay in the HTML source

Code Explained

Blank line — closes the paragraph and starts a new <p>
Single newline — soft break, rendered as a space
·· — two trailing spaces = hard break (invisible in source)
\ at line end — visible hard break, preferred
\* \# \. — escape markup characters
&copy; &nbsp; — HTML entities

⚠ Common Mistakes

  • Relying on trailing spaces — editors strip them and they're invisible in code review
  • Expecting a single newline to break the line — it renders as a space
  • Escaping inside backticks — `\*` shows the backslash literally
  • Writing <tag> in prose — parsed as HTML and vanishes; use backticks or &lt;

✓ Tips & Best Practices

  • Use \ for hard breaks: visible and survives editors
  • Write one sentence per line — soft breaks keep git diffs small
  • Use &nbsp; to keep units and numbers together
  • Don't put secrets in <!-- --> — they ship in the HTML

Quick Summary

  • blank line — ends a paragraph
  • newline — soft break, renders as a space
  • \ / ·· — hard line break
  • \char — literal punctuation
