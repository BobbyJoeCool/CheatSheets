Obsidian & Chat Apps

Obsidian stores notes as plain .md files and adds wikilinks ([[Note]]), embeds (![[Note]]), block references, tags, comments, highlights, callouts and YAML properties. Chat apps support only a subset of Markdown and often change the symbols: Slack uses single * for bold, Jira wiki markup uses h1. and {code}. Check the table before pasting Markdown into another tool.

Obsidian Notes

  • Wikilinks resolve by note name, not path; renames update links
  • ^block-id at the end of a paragraph makes it linkable
  • #tag/sub nests tags; a tag can't be all digits
  • Settings → Files & links can switch new links to standard Markdown

⚠ Common Mistakes

  • Pasting **bold** into Slack — shows the asterisks; Slack bold is *b*
  • Using [[wikilinks]] in docs meant for GitHub — they render as literal brackets
  • Writing Markdown in Jira Server/DC wiki fields — uses h1., {code}, [t|url]
  • Spaces in tags (#in progress) — tag stops at the space

✓ Tips & Best Practices

  • For portable notes, switch Obsidian to standard Markdown links
  • Use block IDs for stable references to decisions
  • Jira Cloud's editor accepts Markdown shortcuts as you type
  • When unsure in chat apps, stick to `code` and plain URLs

Quick Summary

  • [[Note]] — wikilink (Obsidian)
  • ![[Note]] — embed
  • ^id — block reference
  • *b* — Slack / Jira bold
  • [t|url] — Jira wiki link
