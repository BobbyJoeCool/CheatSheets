What Is Markdown?

Markdown is a lightweight markup language created by John Gruber (with Aaron Swartz) in 2004 so people could write HTML as readable plain text. Gruber's description left edge cases undefined, so parsers drifted apart. CommonMark (2014) is the strict, unambiguous spec most modern parsers follow, and GitHub Flavored Markdown (GFM) is a superset of it that adds tables, task lists, strikethrough and autolinks.

Key Facts

  • Extensions: .md (preferred), .markdown; MIME type text/markdown (RFC 7763)
  • Gruber's Markdown.pl 1.0.1 (2004) was never updated; CommonMark fills the gaps
  • Most renderers pass inline HTML through, so HTML is the universal fallback

⚠ Common Mistakes

  • Assuming one Markdown — GFM tables render as plain text in strict CommonMark
  • Indenting with tabs — 4-column tab stops break list nesting
  • Saving as .txt — nothing renders it; use .md
  • No blank lines between blocks — older parsers need them

✓ Tips & Best Practices

  • Write CommonMark + GFM: the safest common ground
  • Check the target renderer before using an extension (Pandoc Obsidian Ext)
  • Test tricky input in the CommonMark dingus
  • Run markdownlint in your editor

Quick Summary

  • .md — plain text that a parser renders to HTML
  • CommonMark — the strict baseline spec
  • GFM GFM — CommonMark + tables, tasks, strike, autolinks
  • HTML — inline HTML is the fallback when syntax is missing
