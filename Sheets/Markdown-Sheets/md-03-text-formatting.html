Text Formatting

Emphasis & Inline Styles

Emphasis wraps text in * or _ delimiters: one for italic (<em>), two for bold (<strong>), three for both. Delimiters must touch the text they wrap. Strikethrough is a GFM extension; highlight, subscript and superscript exist only in some flavors, so inline HTML tags are the portable fallback.

Delimiter Rules

  • * works inside words: un*frigging*believable
  • _ does not: snake_case_name stays literal
  • * text * with inner spaces is not emphasis
  • Emphasis cannot span a blank line (paragraph boundary)
  • No underline syntax — use <ins> or <u>

Formatting Examples

*italic*   _italic_              <!-- <em> -->
**bold**   __bold__              <!-- <strong> -->
***bold italic***                <!-- <em><strong> -->
**bold with *italic* inside**
~~strikethrough~~                <!-- GFM <del> -->
==highlighted==                  <!-- Obsidian <mark> -->
H~2~O   x^2^                     <!-- Pandoc sub / sup -->
H<sub>2</sub>O  x<sup>2</sup>    <!-- HTML: portable -->
<mark>marked</mark> <ins>underlined</ins>
<kbd>Ctrl</kbd>+<kbd>C</kbd>     <!-- keyboard keys -->
un*frigging*believable           <!-- intraword: italic -->
snake_case_name                  <!-- stays literal -->
2 \* 3 = 6                       <!-- escaped asterisk -->

⚠ Common Mistakes

  • ** bold ** — spaces inside delimiters print the asterisks literally
  • H~2~O on GitHub — single tildes are strikethrough there; use <sub>
  • __init__ in prose renders as bold init — wrap code in backticks
  • Mixing delimiters *text_ — openers and closers must match

✓ Tips & Best Practices

  • Pick * for italic and ** for bold and stay consistent
  • Use <kbd> for shortcuts: Ctrl+S
  • Bold sparingly — for UI labels and warnings, not whole sentences
  • Escape math and globs: 2 \* 3, \*.md

Quick Summary

  • *x* — italic
  • **x** — bold
  • ~~x~~ — strikethrough (GFM)
  • <sub> <sup> <mark> — portable extras
  • \* — literal asterisk
