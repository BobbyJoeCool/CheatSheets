Sheet 07

Route Parameters

/users/:id · req.params · /:from-:to · always strings · validating ids · app.param()

Description

Route parameters are named segments of the path, captured into req.params. Values are always strings (or arrays for wildcards), already URL-decoded, so convert and validate before use. app.param(name, fn) runs a callback whenever a route with that param matches: a good place to load the record once and attach it to req.

Notes

  • req.params is rebuilt for each route; mounted routers don't see parent params unless mergeParams: true
  • %20 and other escapes are decoded: /files/my%20doc → "my doc"
  • - and . separate params: /flights/:from-:to, /:file.:ext
  • Param callbacks run once per request, before the route handler

Params & app.param()

app.get("/users/:userId/posts/:postId", (req, res) => {
  const { userId, postId } = req.params;   // "7", "42"
  res.json({ userId: Number(userId), postId: Number(postId) });
});

app.param("todoId", async (req, res, next, id) => {
  const n = Number(id);
  if (!Number.isInteger(n)) return res.status(400).json({ error: "bad id" });
  const todo = await db.todos.find(n);
  if (!todo) return res.sendStatus(404);
  req.todo = todo;                          // attach for handlers
  next();
});

app.get("/todos/:todoId", (req, res) => res.json(req.todo));
app.delete("/todos/:todoId", async (req, res) => {
  await db.todos.remove(req.todo.id);
  res.sendStatus(204);
});

app.get("/flights/:from-:to", (req, res) =>
  res.send(`${req.params.from} → ${req.params.to}`));  // NYC → LAX

Code Explained

req.params.userId — string; Number() before math or lookups
app.param(name, fn) — 4th arg is the raw value
Async param callbacks: rejected promises reach error middleware
Both /todos/:todoId routes reuse the same lookup

Prefer / Avoid

  • parseInt(id) without a radix or check → Number(id) + Number.isInteger
  • Repeating the same lookup in every handler → app.param() or a loadTodo middleware
  • req.param("id") → req.params.id

Express 4 → 5

  • 4.x req.param(name) searched params, body, query → 5.x removed; read the specific object
  • 4.x app.param(fn) customizing the param function → 5.x removed

⚠ Common Mistakes

  • Comparing req.params.id === 42: it's the string "42", so it's always false
  • Using parseInt for validation: "4x" becomes 4 and passes
  • Expecting a parent router's params in a child router without mergeParams: true

✓ Tips & Best Practices

  • Validate params with a schema (zod z.coerce.number().int(), sheet 30)
  • Put the record on req once, then every handler reads req.todo
  • Return 404 for missing records, 400 for malformed ids

Quick Summary

  • req.params — named segments, strings
  • Number() + check — convert ids
  • app.param() — preload per param
  • mergeParams — see parent params
