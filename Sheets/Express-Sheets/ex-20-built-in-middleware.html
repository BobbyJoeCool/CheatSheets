Sheet 20

Built-in Middleware

express.json · express.urlencoded · express.static · express.raw · express.text · what's not bundled

Description

Express 5 ships five middleware factories: four body parsers and static file serving. Everything else Express 3 used to bundle (logging, sessions, cookies, compression, CORS) is a separate package you install and mount yourself. This keeps the core small and lets you swap pieces.

Notes

  • Parsers come from body-parser 2; express.static from serve-static 2
  • Each is a factory: call it to get middleware — express.json(), not express.json
  • Parsers skip requests whose Content-Type doesn't match type
  • express.static calls next() if the file isn't found (fallthrough: true)

All Five, Configured

import path from "node:path";

app.use(express.json({ limit: "200kb", strict: true }));
app.use(express.urlencoded({ extended: false, limit: "50kb" }));
app.use("/hooks", express.raw({ type: "application/json" }));
app.use("/notes", express.text({ type: "text/*" }));

app.use(express.static(path.join(import.meta.dirname, "public"), {
  maxAge: "7d",              // Cache-Control
  etag: true,
  index: "index.html",
  extensions: ["html"],      // /about → about.html
}));

// json type option accepts arrays and functions
app.use(express.json({ type: ["application/json", "application/*+json"] }));

Code Explained

strict: true — only objects and arrays at top level
Route-prefix express.raw — keeps exact bytes for /hooks
extensions — tries .html when the URL has no extension
type — string, array, or (req) => boolean

Prefer / Avoid

  • express.json without calling it → express.json()
  • app.use(bodyParser.json()) → app.use(express.json())
  • express.static with a relative path → path.join(import.meta.dirname, "public")

⚠ Common Mistakes

  • Writing app.use(express.json): Express calls the factory with (req, res, next) and the request hangs
  • Relying on process.cwd() for static paths: it breaks when started from another folder
  • Expecting express.static to 404: it falls through to your routes when files are missing

✓ Tips & Best Practices

  • Mount express.static before logging if you don't want asset noise in logs
  • Set fallthrough: false on asset-only prefixes to get fast 404s
  • Check sheet 21 for the essential third-party middleware

Quick Summary

  • four parsers — json, urlencoded, text, raw
  • express.static — files
