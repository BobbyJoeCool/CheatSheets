Sheet 14

Sending Responses

res.send() · res.json() · res.end() · res.sendStatus() · res.format() · res.headersSent

Description

Every request needs exactly one response. res.send() picks a Content-Type from what you pass (string → HTML, Buffer → binary, object → JSON), adds Content-Length and an ETag, and ends. res.json() always sends JSON. res.end() ends with no Express processing, and res.sendStatus() sends just a status code and its text.

Notes

  • After a response is sent, res.headersSent is true
  • res.send(null) / res.send("") send an empty body
  • res.send on a GET checks freshness and may send 304
  • Express 5.1+: res.send(uint8array) sends binary

Response Methods

res.send("<h1>Hi</h1>");          // text/html; charset=utf-8
res.send({ ok: true });            // application/json
res.send(Buffer.from("raw"));      // application/octet-stream
res.json([1, 2, 3]);               // always JSON
res.json(null);                    // "null"
res.status(201).json(todo);        // status + body
res.sendStatus(204);               // 204, no body
res.sendStatus(404);               // 404 "Not Found"
res.end();                         // end, nothing added

// content negotiation in one call
res.format({
  "text/html": () => res.render("todo", { todo }),
  "application/json": () => res.json(todo),
  default: () => res.sendStatus(406),
});

// guard in shared code
if (!res.headersSent) res.status(500).json({ error: "oops" });

Code Explained

res.send(obj) — calls res.json under the hood
res.status() returns res, so calls chain
res.format — runs the callback matching Accept, sets Vary
res.headersSent — check before writing in error paths

Prefer / Avoid

  • res.send(JSON.stringify(obj)) → res.json(obj)
  • res.json(obj, 201) / res.send(201, obj) → res.status(201).json(obj)
  • res.send(204) (number as status) → res.sendStatus(204)

Express 4 → 5

  • 4.x res.json(obj, status) and res.send(status, body) → 5.x removed; use res.status() first
  • 4.x res.send(404) sent a status → 5.x res.sendStatus(404)

⚠ Common Mistakes

  • Sending in a loop or after an await without return: ERR_HTTP_HEADERS_SENT
  • Never sending in a branch: the request hangs until the client times out
  • res.json(undefined) expecting null: it sends an empty body

✓ Tips & Best Practices

  • Write return res.json(...) for every early exit
  • Send a consistent JSON shape for errors (sheet 25)
  • Use res.format instead of if/else on req.accepts

Quick Summary

  • res.json — JSON body
  • res.send — auto Content-Type
  • res.sendStatus — status only
  • one response per request
