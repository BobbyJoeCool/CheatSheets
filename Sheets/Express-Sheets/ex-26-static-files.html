Sheet 26

Serving Static Files

express.static("public") · virtual prefix /static · maxAge · immutable · dotfiles · SPA fallback

Description

express.static(root, options) serves files from a folder: CSS, images, client JavaScript, downloads. It sets Content-Type, ETag, Last-Modified and range support, and calls next() when no file matches so your routes still run. Mount it with a path to add a URL prefix, and mount several to search several folders in order.

Notes

  • The folder name is not part of the URL: public/logo.png → /logo.png
  • Directory requests serve index.html (index option)
  • Hidden files (.env, .git/) are ignored by default
  • In production, a CDN or Nginx in front is faster for heavy assets

Static Folders & SPA Fallback

import path from "node:path";
const dir = (p) => path.join(import.meta.dirname, p);

app.use(express.static(dir("public")));                  // /logo.png

app.use("/static", express.static(dir("assets"), {       // /static/app.css
  maxAge: "30d",
  immutable: true,              // hashed filenames never change
}));

app.use("/.well-known", express.static(dir(".well-known"), {
  dotfiles: "allow",            // needed for ACME / security.txt
}));

app.use("/downloads", express.static(dir("files"), {
  fallthrough: false,           // missing file → 404 error, no routes
  setHeaders: (res, filePath) => {
    if (filePath.endsWith(".pdf")) res.set("Content-Disposition", "attachment");
  },
}));

// single-page app: unknown GETs get index.html
app.use("/api", api);
app.get("/{*spa}", (req, res) => res.sendFile(dir("client/dist/index.html")));

Code Explained

/static — virtual prefix; files keep their folder-relative paths
immutable + long maxAge — only for fingerprinted files
dotfiles: "allow" — opt in for .well-known
SPA catch-all goes after the API so API 404s stay JSON

Prefer / Avoid

  • express.static("public") (cwd-relative) → an absolute path built from import.meta.dirname
  • Long maxAge on unhashed files → hash filenames, then cache for a year
  • Serving uploads from the app folder → a separate folder with fallthrough: false

Express 4 → 5

  • 4.x dotfiles (incl. .well-known/) served by default → 5.x dotfiles: "ignore" by default; opt in per mount

⚠ Common Mistakes

  • Putting public in the URL (/public/logo.png): the folder name isn't part of the path
  • Serving the project root with express.static("."): exposes source and config
  • SPA catch-all before API routes: API 404s return HTML

✓ Tips & Best Practices

  • Build assets with Vite and serve dist/ (Vite set)
  • Mount static before session middleware so asset requests skip session lookups
  • Use compression() or pre-compressed files for big bundles (52)

Quick Summary

  • express.static(dir) — serve a folder
  • prefix — app.use("/x", static(dir))
  • maxAge / immutable — caching
  • dotfiles ignored by default
