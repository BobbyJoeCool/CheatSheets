Helmet & Security Headers

helmet() · Content-Security-Policy · HSTS · nosniff · x-powered-by · per-route CSP

Description

Helmet sets a bundle of HTTP response headers that switch on browser protections: a Content-Security-Policy that limits where scripts and styles may load from, HSTS to force HTTPS, nosniff, frame blocking and more. Mount it first. The defaults suit an API or a site with no third-party scripts; most real sites tune the CSP directives.

Notes

  • helmet() also removes X-Powered-By
  • Each header has its own option key; false turns one off
  • CSP violations show in the browser console; test with reportOnly first
  • HSTS only matters over HTTPS; browsers ignore it on HTTP

Helmet with a Tuned CSP

import helmet from "helmet";

app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      "default-src": ["'self'"],
      "script-src": ["'self'", "https://cdn.jsdelivr.net"],
      "img-src": ["'self'", "data:", "https://images.example.com"],
      "connect-src": ["'self'", "https://api.example.com"],
      "frame-ancestors": ["'none'"],
    },
    // reportOnly: true,       // log violations without blocking
  },
  strictTransportSecurity: { maxAge: 63072000, includeSubDomains: true },
  crossOriginEmbedderPolicy: false,      // off if you embed third-party media
}));

// stricter policy on one route
app.use("/admin", helmet.contentSecurityPolicy({
  directives: { "default-src": ["'self'"], "script-src": ["'self'"] },
}));

// nonce for one inline script
app.use((req, res, next) => {
  res.locals.nonce = crypto.randomBytes(16).toString("base64");
  next();
});
// "script-src": ["'self'", (req, res) => `'nonce-${res.locals.nonce}'`]

Code Explained

Directives merge into Helmet's defaults
'self' — same origin only; quotes are part of the value
frame-ancestors 'none' — no one can iframe you
Nonces allow specific inline scripts without 'unsafe-inline'

Prefer / Avoid

  • 'unsafe-inline' in script-src → nonces or moving scripts to files
  • Turning contentSecurityPolicy off entirely → tune directives; start with reportOnly
  • app.disable("x-powered-by") alone → helmet() (covers it and more)

⚠ Common Mistakes

  • Shipping the default CSP with a CDN script: the page loads with scripts blocked
  • Enabling HSTS preload before every subdomain supports HTTPS: they become unreachable
  • Setting security headers in Express *and* Nginx with different values: browsers get duplicates

✓ Tips & Best Practices

  • Check your headers at securityheaders.com
  • Collect CSP reports with report-to before enforcing
  • Keep security header config in one module and document why each exception exists

Quick Summary

  • helmet() — security headers in one line
  • CSP — allowed script/style sources
  • HSTS — force HTTPS
  • nonces — safe inline scripts
