Sheet 03

First App & the app Object

express() · app.get() · app.listen() · listen error callback · app.set() · app.get(setting) · app.locals

Description

The app returned by express() holds routes, middleware and settings. app.set(name, value) stores a setting and app.get(name) reads it (one argument means "read a setting", two means "add a GET route"). app.enable / app.disable flip boolean settings. app.listen() starts an HTTP server and returns it so you can close it later.

Notes

  • app is a function (req, res): pass it to http.createServer(app) or https.createServer(opts, app)
  • app.locals — values available to every rendered view
  • app.get("env") — NODE_ENV, defaulting to "development"
  • Settings are global to the app; sub-apps inherit them when mounted

App, Settings & Startup

import express from "express";

const app = express();

app.set("trust proxy", 1);                 // behind one proxy
app.disable("x-powered-by");               // hide "Express" header
app.set("json spaces", 2);                 // pretty JSON in dev
app.locals.siteName = "Todo API";

app.get("/", (req, res) => res.send("ok"));

console.log(app.get("env"));               // "development"
console.log(app.enabled("x-powered-by"));  // false

const server = app.listen(3000, (err) => {
  if (err) {                               // e.g. EADDRINUSE
    console.error(err.message);
    process.exit(1);
  }
  console.log("port", server.address().port);  // 3000
});

Code Explained

app.set with two args stores; app.get with one arg reads
app.disable("x-powered-by") — removes X-Powered-By: Express
server — Node http.Server; call server.close() to stop
listen(0) picks a free port: handy in tests

Prefer / Avoid

  • app.get("x-powered-by") to check a flag → app.enabled("x-powered-by")
  • Global variables for shared config → app.locals or a config module
  • Ignoring listen errors → handle err in the callback and exit

Express 4 → 5

  • 4.x listen errors only on server.on("error") → 5.x also passed to the listen callback

⚠ Common Mistakes

  • Calling app.get("/users") with no handler: it reads a setting named "/users" and returns undefined
  • Listening on a port that's in use without handling the error: the process stays up doing nothing
  • Hardcoding the port: hosts set PORT; read process.env.PORT

✓ Tips & Best Practices

  • Keep app.listen out of the file that builds the app so tests can import the app (sheet 04)
  • Disable x-powered-by or use helmet() (sheet 41)
  • app.set("json spaces", 2) only in development

Quick Summary

  • app.set / app.get — settings
  • app.enable / disable — boolean settings
  • app.locals — view-wide values
  • app.listen — returns http.Server
