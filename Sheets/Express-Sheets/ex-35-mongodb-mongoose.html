Sheet 35

MongoDB with Mongoose

mongoose.connect() · Schema · model() · find / findById · CastError → 400 · lean() · timestamps

Description

Mongoose adds schemas, validation and models on top of the MongoDB driver. Connect once at startup, define a Schema per collection, and query through the model. Two errors need mapping: a malformed id raises **CastError (should be 400), and a duplicate unique field raises error code 11000** (should be 409). Use .lean() for read-only queries to get plain objects quickly.

Notes

  • _id is an ObjectId; Mongoose adds an id string getter
  • timestamps: true adds createdAt / updatedAt
  • runValidators: true is needed for validators on updates
  • Never pass raw req.query / req.body as a filter (operator injection)

Model + Routes

import mongoose from "mongoose";
await mongoose.connect(process.env.MONGODB_URI);

const todoSchema = new mongoose.Schema({
  title: { type: String, required: true, trim: true, maxlength: 200 },
  done: { type: Boolean, default: false },
  owner: { type: mongoose.Schema.Types.ObjectId, ref: "User", index: true },
}, { timestamps: true });
export const Todo = mongoose.model("Todo", todoSchema);

app.get("/todos", async (req, res) => {
  res.json(await Todo.find({ owner: req.user.id })
    .sort("-createdAt").limit(20).lean());
});

app.get("/todos/:id", async (req, res) => {
  const todo = await Todo.findOne({ _id: req.params.id, owner: req.user.id })
    .lean();
  if (!todo) throw new HttpError(404, "Todo not found");
  res.json(todo);
});

app.patch("/todos/:id", async (req, res) => {
  const todo = await Todo.findByIdAndUpdate(req.params.id,
    { $set: { title: req.valid.body.title } },
    { new: true, runValidators: true });
  res.json(todo);
});

app.use((err, req, res, next) => {
  if (err.name === "CastError") return res.status(400).json({ error: "id" });
  if (err.code === 11000) return res.status(409).json({ error: "duplicate" });
  next(err);
});

Code Explained

Connect once with top-level await before listen
.lean() — plain objects, no document methods, faster
{ new: true } — return the updated document
Error mapper sits before your generic error handler

Prefer / Avoid

  • Todo.find(req.query) → build the filter from validated fields
  • Full documents for read-only lists → .lean() + .select()
  • Checking ownership after loading → include owner in the query

⚠ Common Mistakes

  • Passing req.body as a filter: { "password": { "$ne": "" } } logs anyone in
  • Forgetting runValidators on updates: invalid data gets saved
  • Letting CastError bubble up as 500: bad ids look like server bugs

✓ Tips & Best Practices

  • Sanitize with mongoose.set("sanitizeFilter", true) as a safety net
  • Add indexes for every field you filter or sort on
  • NoSQL set covers MongoDB queries and modeling
