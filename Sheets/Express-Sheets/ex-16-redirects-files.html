Sheet 16

Redirects, Files & Downloads

res.redirect(301, url) · res.sendFile() · root · res.download() · res.attachment() · path traversal

Description

res.redirect([status,] url) sends a 302 (or the code you give) with a Location header. res.sendFile(path, options) streams a file with the right Content-Type, handling ranges and caching headers; pass a **root** so user input can't escape your folder. res.download() does the same with Content-Disposition: attachment so the browser saves the file.

Notes

  • res.sendFile needs an absolute path or the root option
  • .. in a path is rejected when root is set (403)
  • Both accept a callback (err) => … for missing files
  • res.attachment(name) sets the header without sending

Redirects & Files

app.get("/old-docs", (req, res) => res.redirect(301, "/docs"));
app.post("/login", (req, res) => res.redirect("/dashboard"));   // 302
app.post("/todos", (req, res) => res.redirect(303, "/todos")); // POST→GET
app.get("/back", (req, res) =>
  res.redirect(req.get("Referrer") || "/"));                   // was "back"

const files = path.join(import.meta.dirname, "uploads");

app.get("/files/:name", (req, res, next) => {
  res.sendFile(req.params.name, { root: files, maxAge: "1d" }, (err) => {
    if (err) next(err);              // ENOENT → 404 via err.status
  });
});

app.get("/reports/:id.pdf", (req, res) => {
  res.download(`/data/reports/${req.params.id}.pdf`,
    `report-${req.params.id}.pdf`);  // saved filename
});

app.get("/export.csv", (req, res) => {
  res.attachment("todos.csv");       // Content-Disposition + type
  res.send(toCsv(todos));
});

Code Explained

redirect(303, url) — after a POST, tells the browser to GET
root — joins and blocks ../ escapes
sendFile errors carry err.status (404, 403) for your handler
res.download(path, filename) — second arg is the save-as name

Prefer / Avoid

  • res.sendFile(dir + req.params.name) → res.sendFile(name, { root: dir })
  • res.redirect("back") → res.redirect(req.get("Referrer") || "/")
  • Redirecting to req.query.next unchecked → allow only relative paths you expect

Express 4 → 5

  • 4.x res.redirect(url, status) argument order → 5.x res.redirect(status, url)
  • 4.x res.redirect("back") magic string → 5.x removed; read Referrer yourself
  • 4.x res.sendfile() (lowercase) → 5.x removed; res.sendFile()

⚠ Common Mistakes

  • Joining user input into a path without root: ../../etc/passwd gets served
  • Open redirects via res.redirect(req.query.url): attackers send users to phishing sites
  • Using 301 for temporary moves: browsers cache it hard and won't come back

✓ Tips & Best Practices

  • Use 303 after form posts (Post/Redirect/Get) to stop double submits
  • Serve whole folders with express.static instead (sheet 26)
  • Stream big generated files with stream.pipeline(src, res) (45)

Quick Summary

  • res.redirect(status, url) — redirect
  • res.sendFile(p, { root }) — serve a file
  • res.download() — force save
  • root — blocks path traversal
