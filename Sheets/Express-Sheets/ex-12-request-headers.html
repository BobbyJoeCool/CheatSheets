Sheet 12

Headers & Content Negotiation

req.get() · req.is("json") · req.accepts() · req.acceptsLanguages() · req.fresh · req.xhr

Description

Read any request header with **req.get(name)** (case-insensitive). req.is(type) checks the Content-Type of the body the client sent. req.accepts(types) reads the Accept header and returns the best match for what the client wants back, or false. req.fresh compares the client's cached ETag / Last-Modified with the response so you can reply 304.

Notes

  • req.headers — raw object, keys lowercased
  • req.get("Referrer") and "Referer" both work
  • req.is() returns the matching type, false, or null (no body)
  • req.xhr — true when X-Requested-With: XMLHttpRequest (old jQuery convention)

Reading Headers & Negotiating

app.post("/upload", (req, res) => {
  if (!req.is("application/json") && !req.is("multipart/*")) {
    return res.status(415).send("Unsupported Media Type");
  }
  const agent = req.get("User-Agent");       // "Mozilla/5.0 …"
  const auth = req.get("authorization");     // case-insensitive
  res.json({ agent, hasAuth: Boolean(auth) });
});

app.get("/todos/:id", (req, res) => {
  const type = req.accepts(["json", "html"]); // best match or false
  if (type === "html") return res.render("todo", { todo });
  if (type === "json") return res.json(todo);
  res.sendStatus(406);                        // Not Acceptable
});

app.get("/greeting", (req, res) => {
  const lang = req.acceptsLanguages("en", "es", "fr") || "en";
  res.send({ en: "Hello", es: "Hola", fr: "Bonjour" }[lang]);
});

Code Explained

req.is("multipart/*") — wildcards and short names ("json") work
req.accepts([...]) — returns the first type the client prefers
415 wrong body type; 406 can't produce an acceptable type
res.format() does the accepts switch for you (sheet 14)

Prefer / Avoid

  • req.headers["Content-Type"] (wrong case) → req.get("Content-Type")
  • Parsing Accept by hand → req.accepts() / res.format()
  • req.xhr to detect API calls → check req.accepts("json") or a path prefix

⚠ Common Mistakes

  • Indexing req.headers with capital letters: Node lowercases the keys, so you get undefined
  • Calling req.accepts("json") and ignoring a false result: browsers get JSON they didn't ask for
  • Checking req.is("json") on a GET: no body means null, not false

✓ Tips & Best Practices

  • Return 415 early for routes that only take JSON
  • Express already sends 304 for res.send when req.fresh and ETags match
  • Use res.vary("Accept") when the body depends on Accept (sheet 15)

Quick Summary

  • req.get(name) — read a header
  • req.is(type) — body Content-Type
  • req.accepts(types) — what client wants
  • req.fresh — cache still valid
