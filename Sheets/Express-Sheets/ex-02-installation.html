Sheet 02

Installation & Project Setup

npm init -y · npm install express · "type": "module" · engines · express-generator · node --watch

Description

An Express project is an ordinary npm package with express as a dependency. Set "type": "module" so .js files use ES module syntax, add a start and dev script, and pin the Node version in engines. Node 18.11+ has --watch, so nodemon is no longer needed for restarts during development.

Notes

  • npm install express adds it to dependencies (runtime)
  • Check the install: npm ls express or node -p "require('express/package.json').version"
  • npx express-generator scaffolds an older-style app (CommonJS, Jade/Pug by default)
  • Add .gitignore with node_modules and .env before the first commit

Create the Project

mkdir todo-api && cd todo-api
npm init -y                       # writes package.json
npm install express               # express@5.x
npm install -D @types/express     # editor types (optional)
echo "node_modules\n.env" > .gitignore

package.json

{
  "name": "todo-api",
  "type": "module",
  "main": "src/server.js",
  "engines": { "node": ">=18" },
  "scripts": {
    "start": "node src/server.js",
    "dev": "node --watch --env-file=.env src/server.js"
  },
  "dependencies": { "express": "^5.2.1" }
}

Code Explained

"type": "module" — import/export in .js files
engines — documents (and on some hosts enforces) the Node version
--watch — restarts on file change; --env-file loads .env (Node 20.6+)
^5.2.1 — accepts 5.x minor and patch updates, never 6.0

Prefer / Avoid

  • npm install nodemon just to restart → node --watch
  • dotenv for local env files on Node 20.6+ → node --env-file=.env
  • Committing node_modules → commit package-lock.json, run npm ci in CI

⚠ Common Mistakes

  • Forgetting "type": "module": import throws SyntaxError: Cannot use import statement outside a module
  • Installing Express globally (-g): apps don't load global packages by default
  • Running npm install in CI: it can rewrite the lockfile; use npm ci

✓ Tips & Best Practices

  • Generate a fresh project instead of copying an old one so you start on Express 5
  • Use npm pkg set type=module to edit package.json from the shell
  • Pin the Node version with .nvmrc too (Node set, sheet 02)

Quick Summary

  • npm install express — add Express
  • "type": "module" — ES modules
  • node --watch — dev restarts
  • npm ci — reproducible installs
