Sheet 01

Introduction & History

TJ Holowaychuk · 2010 · minimal & unopinionated · node:http · middleware stack · OpenJS Foundation · Express 5

Description

Express is a small web framework for Node. It wraps Node's http server with routing (match a method and path to a function), a middleware stack (functions that run in order on every request), and helpers on the request and response objects. It is unopinionated: no ORM, no folder layout, no template language is forced on you. Most Node web tools (NestJS, many serverless adapters) either build on it or copy its handler shape.

Notes

  • Created by TJ Holowaychuk, first released 2010; inspired by Ruby's Sinatra
  • Maintained under the OpenJS Foundation with a technical committee
  • Express 5.0 shipped Sept 2024 after ten years on 4.x; 5.1 became the npm latest in March 2025
  • Express 5 needs Node 18+
  • Install name express; one dependency tree, no build step

Hello, Express

import express from "express";           // ES module import

const app = express();                     // create the application
const port = process.env.PORT ?? 3000;

app.get("/", (req, res) => {               // GET / → handler
  res.send("Hello, Express!");             // sends text/html
});

app.get("/api/time", (req, res) => {
  res.json({ now: new Date() });           // {"now":"2026-…"}
});

app.listen(port, (err) => {                // Express 5: errors arrive here
  if (err) throw err;
  console.log(`Listening on http://localhost:${port}`);
});

Code Explained

express() — returns an app, which is itself a request handler function
app.get(path, fn) — runs fn only for GET requests to that path
res.send / res.json — set headers and end the response
app.listen — wraps http.createServer(app).listen() and returns the server

Prefer / Avoid

  • const express = require("express") in new projects → import express from "express" with "type": "module"
  • Hand-rolled http.createServer routing → Express routes for anything past one endpoint
  • Pinning Express 4 for new apps → Express 5 (current, supported line)

Express 4 → 5

  • 4.x app.listen(port, cb) swallowed EADDRINUSE in cb → 5.x cb receives the error as its first argument
  • 4.x Node 0.10+ supported → 5.x Node 18+ required

⚠ Common Mistakes

  • Following a 2018 tutorial line for line: Express 4 path syntax like app.get("*") throws in Express 5
  • Expecting Express to validate input or talk to a database: it does neither; add libraries
  • Calling res.send twice in one handler: the second throws ERR_HTTP_HEADERS_SENT

✓ Tips & Best Practices

  • Check the version first: npm ls express
  • Read req/res docs as extensions of Node's http objects; Node methods still work
  • Keep the Node.js set (sheets 61–62) handy for the runtime side

Quick Summary

  • express() — create an app
  • app.METHOD(path, fn) — route
  • middleware — functions run in order
  • app.listen(port) — start the HTTP server
