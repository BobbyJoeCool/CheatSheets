Sheet 13

Parsing the Request Body

express.json() · express.urlencoded() · express.text() · express.raw() · limit · req.body undefined

Description

Express does not read the request body unless you mount a body parser. express.json() parses JSON, express.urlencoded() parses HTML form posts, and express.text() / express.raw() give you a string or Buffer. Each parser only runs when the request's Content-Type matches its type option; otherwise it skips, and in Express 5 **req.body stays undefined**.

Notes

  • Parsers are built in (body-parser 2); the separate body-parser package isn't needed
  • Default size limit is "100kb"; bigger bodies get 413
  • Malformed JSON → 400 error with err.type === "entity.parse.failed"
  • Multipart (file uploads) needs Multer (sheet 31)

Mounting Parsers

app.use(express.json({ limit: "1mb" }));           // application/json
app.use(express.urlencoded({ extended: false }));   // HTML forms

app.post("/todos", (req, res) => {
  // POST {"title":"Buy milk","done":false}
  console.log(req.body);           // { title: "Buy milk", done: false }
  res.status(201).json(req.body);
});

app.post("/login", (req, res) => {
  // form: username=bob&password=s3cret
  const { username, password } = req.body ?? {};
  res.send(`hi ${username}`);
});

// raw body for webhook signature checks, one route only
app.post("/webhooks/stripe",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const sig = req.get("stripe-signature");
    verify(req.body, sig);         // req.body is a Buffer
    res.sendStatus(200);
  });

Code Explained

limit — max bytes; accepts "1mb" strings
extended: false — flat querystring parsing (Express 5 default)
req.body ?? {} — guards against no body / wrong type
Route-level express.raw — keeps the exact bytes for HMAC checks

Prefer / Avoid

  • import bodyParser from "body-parser" → express.json() / express.urlencoded()
  • Global express.json() before a webhook route → express.raw() on that route only
  • if (req.body.x) without a guard → validate the body (sheet 30)

Express 4 → 5

  • 4.x req.body defaulted to {} → 5.x undefined when no parser ran
  • 4.x urlencoded extended defaulted to true → 5.x defaults to false

⚠ Common Mistakes

  • Forgetting express.json(): req.body is undefined and destructuring throws
  • Client sends JSON without Content-Type: application/json: the parser skips it
  • Raising limit globally to accept uploads: use Multer or streaming instead

✓ Tips & Best Practices

  • Use verify to keep raw bytes alongside parsed JSON when both are needed
  • Return a clean 400 for entity.parse.failed in your error handler
  • Parse only where needed on high-traffic apps (route-level parsers)

Quick Summary

  • express.json() — JSON bodies
  • express.urlencoded() — form posts
  • express.raw() — Buffer for signatures
  • no parser → req.body undefined
