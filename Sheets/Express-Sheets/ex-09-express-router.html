Sheet 09

express.Router

express.Router() · app.use("/api", router) · mergeParams · nested routers · app.router

Description

A Router is a mini-application with its own middleware and routes but no settings or listen. Build one per resource, export it, and mount it with app.use(prefix, router); paths inside the router are relative to the prefix. Routers can mount other routers, and mergeParams: true lets a child router read params from the parent's mount path.

Notes

  • express.Router(options) — caseSensitive, strict, mergeParams
  • Inside a router, req.baseUrl is the mount prefix; req.path is the rest
  • router.use(fn) middleware runs only for requests that reach this router
  • app.router is the app's own base router (back in Express 5)

One Router per Resource

// routes/todos.js
import { Router } from "express";
import comments from "./comments.js";

const router = Router();

router.use(requireAuth);                   // only /api/todos/*
router.get("/", listTodos);                // GET /api/todos
router.post("/", createTodo);              // POST /api/todos
router.get("/:id", getTodo);               // GET /api/todos/7
router.use("/:id/comments", comments);     // nested router
export default router;

// routes/comments.js
const comments = Router({ mergeParams: true });
comments.get("/", (req, res) => {
  res.json({ todoId: req.params.id });     // parent param
});

// app.js
app.use("/api/todos", todosRouter);
app.use("/api/v2/todos", todosV2Router);   // versioned

Code Explained

router.get("/") — resolves to the mount path /api/todos
router.use(requireAuth) — scoped to this router
mergeParams: true — without it req.params.id is undefined
Same router can be mounted at several prefixes

Prefer / Avoid

  • All routes on app in one file → a Router per resource
  • Repeating /api/todos in every path → mount once with app.use(prefix, router)
  • app.use("/x", require("./x")()) factories → export the router itself

Express 4 → 5

  • 4.x app.router removed (threw) → 5.x app.router returns the base router

⚠ Common Mistakes

  • Writing router.get("/api/todos") inside a router mounted at /api/todos: the real path doubles
  • Forgetting mergeParams: true on nested routers: parent params are undefined
  • Mounting routers after the 404 handler: they never run

✓ Tips & Best Practices

  • Name routers after the resource and mount them all in app.js
  • Use router.route("/:id") to chain methods (sheet 10)
  • Mount /api/v1 and /api/v2 routers side by side for versioning (32)

Quick Summary

  • Router() — mini-app of routes
  • app.use(prefix, router) — mount
  • mergeParams — parent params
  • req.baseUrl — mount prefix
