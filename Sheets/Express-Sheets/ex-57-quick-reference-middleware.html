⚠ Common Mistakes

  • Mounting the error handler before routes: it never sees their errors
  • Calling factories wrong: express.json instead of express.json()
  • Global cors() with no origin in production: any site can call your API from a browser

✓ Tips & Best Practices

  • Copy the mount order into app.js as a comment
  • Check each package's major version before copying options
