Template Engines

app.set("view engine", "ejs") · app.set("views") · EJS · Pug · Handlebars · app.engine()

Description

Express renders HTML through a template engine: you set a default engine and a views folder, and res.render("name") finds views/name.ext. EJS is plain HTML with <% %> tags, Pug uses indentation instead of closing tags, and Handlebars keeps logic out of templates. Any engine that exports __express or is registered with app.engine() works.

Notes

  • Install the engine: npm i ejs (or pug, express-handlebars)
  • views defaults to ./views relative to the process cwd
  • view cache is on in production: templates compile once
  • You can mix engines by giving full filenames: res.render("page.pug")

Configuring Engines

import path from "node:path";
import { engine } from "express-handlebars";

app.set("views", path.join(import.meta.dirname, "views"));
app.set("view engine", "ejs");               // res.render("home") → home.ejs

// Handlebars needs registering under an extension
app.engine("hbs", engine({ extname: ".hbs", defaultLayout: "main" }));
app.render("email/welcome.hbs", { name: "Bo" }, (err, html) => sendMail(html));

views/home.ejs

<%- include("partials/header", { title }) %>
<h1>Hello, <%= user.name %></h1>            <!-- escaped -->
<% if (todos.length) { %>
  <ul>
    <% todos.forEach((t) => { %>
      <li class="<%= t.done ? "done" : "" %>"><%= t.title %></li>
    <% }) %>
  </ul>
<% } else { %>
  <p>Nothing to do.</p>
<% } %>
<%- include("partials/footer") %>

Code Explained

view engine — extension used when none is given
app.engine(ext, fn) — register engines without __express
app.render — render to a string without a response (emails)
<%= %> escapes HTML; <%- %> outputs raw (includes only)

Prefer / Avoid

  • String-building HTML in route handlers → a template engine
  • <%- user.bio %> for user content → <%= user.bio %> (escaped)
  • Jade → Pug (renamed in 2016)

⚠ Common Mistakes

  • Forgetting to install the engine package: Cannot find module 'ejs'
  • Relying on the default views path and starting the app from another folder: views not found
  • Outputting user input with <%-: stored XSS

✓ Tips & Best Practices

  • Set views with an absolute path from import.meta.dirname
  • Pair templates with htmx for interactivity without a SPA
  • Use app.render for HTML emails so they share partials

Quick Summary

  • view engine — default extension
  • views — template folder
  • app.engine() — register an engine
  • <%= %> escaped, <%- %> raw
