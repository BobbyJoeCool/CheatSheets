Sheet 17

Cookies

res.cookie() · httpOnly · secure · sameSite · maxAge · res.clearCookie() · cookie-parser · signed cookies

Description

res.cookie(name, value, options) adds a Set-Cookie header; objects are JSON-encoded. Reading cookies needs the cookie-parser middleware, which fills req.cookies and, when given a secret, req.signedCookies (values with an HMAC that can't be edited client-side). For anything secret or large, store a session id in the cookie and the data on the server (sheet 37).

Notes

  • maxAge is in milliseconds; expires takes a Date
  • httpOnly hides the cookie from browser JavaScript
  • secure sends it over HTTPS only; sameSite limits cross-site sends
  • Browsers cap cookies near 4 KB each

Setting, Reading, Clearing

import cookieParser from "cookie-parser";
app.use(cookieParser(process.env.COOKIE_SECRET));   // secret → signed

app.post("/prefs", (req, res) => {
  res.cookie("theme", "dark", { maxAge: 30 * 24 * 3600e3 }); // 30 days
  res.cookie("cart", { items: [3, 7] });          // JSON-encoded "j:{…}"
  res.cookie("uid", user.id, {
    signed: true,            // tamper-proof
    httpOnly: true,          // no document.cookie
    secure: true,            // HTTPS only
    sameSite: "lax",         // not on cross-site POSTs
    path: "/",
  });
  res.sendStatus(204);
});

app.get("/me", (req, res) => {
  const theme = req.cookies.theme ?? "light";     // unsigned
  const uid = req.signedCookies.uid;              // false if tampered
  res.json({ theme, uid });
});

app.post("/logout", (req, res) => {
  res.clearCookie("uid", { path: "/" });          // match set options
  res.redirect("/");
});

Code Explained

cookieParser(secret) — enables signed: true
req.signedCookies.uid — false if the signature fails
Signed ≠ encrypted: the value is still readable
clearCookie needs the same path/domain used to set it

Prefer / Avoid

  • Storing user data in cookies → a session id; data on the server
  • maxAge: 3600 thinking seconds → maxAge: 3600 * 1000 (ms)
  • Auth cookies without flags → httpOnly, secure, sameSite

Express 4 → 5

  • 4.x res.clearCookie(name, { maxAge }) honored maxAge → 5.x maxAge / expires ignored

⚠ Common Mistakes

  • Expecting req.cookies without cookie-parser: it's undefined
  • Using sameSite: "none" without secure: true: browsers reject the cookie
  • Thinking signed cookies are private: anyone can base64-decode them

✓ Tips & Best Practices

  • Rotate COOKIE_SECRET by passing an array of secrets (newest first)
  • Prefix sensitive cookies with __Host- and set secure, path: "/"
  • Use sameSite: "lax" plus CSRF tokens for form posts (sheet 43)

Quick Summary

  • res.cookie(n, v, opts) — set
  • cookie-parser → req.cookies
  • signed: true — tamper-proof
  • res.clearCookie — same options to delete
