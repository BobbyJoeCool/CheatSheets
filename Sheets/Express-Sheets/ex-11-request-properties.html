Sheet 11

Request Properties

req.method · req.path · req.originalUrl · req.baseUrl · req.hostname · req.ip · req.protocol · req.secure

Description

req is Node's IncomingMessage plus Express properties for the URL, client and connection. Several of them (req.ip, req.protocol, req.hostname) change meaning behind a proxy: they read X-Forwarded-* headers only when the **trust proxy** setting allows it. Without that setting you'll log the proxy's address for every user.

Notes

  • req.path — path only, relative to the mount point
  • req.originalUrl — full URL as received, query included
  • req.subdomains — ["api"] for api.example.com
  • req.route — the matched route object (has .path)
  • req.app — the app handling the request

Inspecting a Request

app.set("trust proxy", 1);          // one proxy (Nginx, Heroku…)

// GET https://api.example.com:8443/v1/todos/7?full=1
// mounted: app.use("/v1", router); route "/todos/:id"
router.get("/todos/:id", (req, res) => {
  res.json({
    method: req.method,           // "GET"
    originalUrl: req.originalUrl, // "/v1/todos/7?full=1"
    baseUrl: req.baseUrl,         // "/v1"
    path: req.path,               // "/todos/7"
    hostname: req.hostname,       // "api.example.com"
    host: req.host,               // "api.example.com:8443"
    subdomains: req.subdomains,   // ["api"]
    protocol: req.protocol,       // "https" (from X-Forwarded-Proto)
    secure: req.secure,           // true
    ip: req.ip,                   // client IP from X-Forwarded-For
    route: req.route.path,        // "/todos/:id"
  });
});

Code Explained

trust proxy — without it req.ip is the proxy's IP
req.hostname drops the port; req.host keeps it
req.secure — shorthand for req.protocol === "https"
req.ips — the full X-Forwarded-For chain

Prefer / Avoid

  • Reading req.headers["x-forwarded-for"] yourself → trust proxy + req.ip
  • trust proxy: true everywhere → the exact hop count or proxy subnet
  • req.url for logging → req.originalUrl (not rewritten by mounts)

Express 4 → 5

  • 4.x req.host returned host without port → 5.x req.host includes the port

⚠ Common Mistakes

  • Rate-limiting by req.ip behind a proxy without trust proxy: every user shares one limit
  • Setting trust proxy to true on a server reachable directly: clients can fake their IP
  • Using req.path to build redirect URLs inside routers: it's missing the mount prefix

✓ Tips & Best Practices

  • Log req.method, req.originalUrl, status and time per request (sheet 51)
  • Test proxy settings by hitting /debug with a fake X-Forwarded-For
  • req.get("host") gives the raw Host header (sheet 12)

Quick Summary

  • req.path / originalUrl — URL parts
  • req.hostname / req.host — host
  • req.ip / ips — client address
  • trust proxy — honor X-Forwarded-*
