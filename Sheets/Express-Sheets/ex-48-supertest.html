Sheet 48

Testing Routes with Supertest

request(app).get("/") · .expect(200) · .send() / .set() · no listen() · node:test / Vitest / Jest

Description

Supertest sends real HTTP requests to your Express app without you starting a server: pass the app and it binds an ephemeral port per test. Chain .send(), .set() and .expect() assertions, then inspect res.body. It works with any runner: Node's built-in node:test, Vitest or Jest. This is why app.js exports the app and server.js calls listen.

Notes

  • Install: npm i -D supertest
  • Calls return promises: await them
  • .expect(200) and .expect("Content-Type", /json/) assert inline
  • res.body is parsed JSON; res.text the raw body

Route Tests with node:test

import { test, describe, beforeEach } from "node:test";
import assert from "node:assert/strict";
import request from "supertest";
import { createApp } from "../src/app.js";
import { memoryDb } from "./helpers.js";

describe("todos API", () => {
  let app;
  beforeEach(() => { app = createApp({ db: memoryDb() }); });

  test("POST /api/todos creates a todo", async () => {
    const res = await request(app)
      .post("/api/todos")
      .set("Authorization", "Bearer test-token")
      .send({ title: "Write tests" })
      .expect(201)
      .expect("Content-Type", /json/);
    assert.equal(res.body.title, "Write tests");
    assert.match(res.headers.location, /\/api\/todos\/\d+/);
  });

  test("rejects an empty title", async () => {
    const res = await request(app).post("/api/todos")
      .set("Authorization", "Bearer test-token")
      .send({ title: "" }).expect(400);
    assert.equal(res.body.error.code, "VALIDATION");
  });

  test("unknown route is a JSON 404", async () => {
    const res = await request(app).get("/nope").expect(404);
    assert.equal(res.body.error.code, "NOT_FOUND");
  });
});

Code Explained

createApp per test — fresh, isolated state
.send(obj) — sets JSON body and Content-Type
.expect(404, body) — status and deep-equal body
Run with node --test (or vitest)

Prefer / Avoid

  • Starting the server and hitting localhost:3000 → request(app) with no listen
  • Asserting on res.text for JSON → res.body
  • Sharing one app instance with mutable state → build a fresh app per test

⚠ Common Mistakes

  • Importing a module that calls app.listen: tests hang or fight over the port
  • Forgetting await: the test passes before assertions run
  • Hitting a real database from unit-level route tests: slow and flaky

✓ Tips & Best Practices

  • Add "test": "node --test" to scripts; no extra runner needed
  • Use .expect((res) => …) for custom assertions
  • Jest & Vitest set covers runners, mocks and coverage

Quick Summary

  • request(app) — test without listen
  • .send / .set / .query — build request
  • .expect() — inline assertions
  • res.body — parsed JSON
