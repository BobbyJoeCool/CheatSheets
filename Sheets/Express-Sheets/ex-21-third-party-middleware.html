Sheet 21

Essential Third-Party Middleware

cors · helmet · morgan · compression · cookie-parser · express-rate-limit · mount order

Description

A handful of npm packages appear in almost every Express app. helmet sets security headers, cors answers cross-origin requests, morgan logs each request, compression gzips responses, cookie-parser reads cookies, and express-rate-limit throttles abusive clients. Each exports a factory you call and pass to app.use(); the order you mount them in matters.

Notes

  • Install all at once: npm i helmet cors morgan compression cookie-parser express-rate-limit
  • Security and CORS go first so even error responses get the headers
  • Logging goes early so it times the whole request
  • Mount rate limits on the API or login routes, not on static files

A Typical Stack

import helmet from "helmet";
import cors from "cors";
import morgan from "morgan";
import compression from "compression";
import cookieParser from "cookie-parser";
import { rateLimit } from "express-rate-limit";

app.use(helmet());                                  // security headers
app.use(cors({ origin: ["https://app.example.com"], credentials: true }));
app.use(morgan(app.get("env") === "production" ? "combined" : "dev"));
app.use(compression());                             // gzip responses ≥ 1kb
app.use(express.json());
app.use(cookieParser(process.env.COOKIE_SECRET));

app.use("/api", rateLimit({
  windowMs: 15 * 60 * 1000,                         // 15 minutes
  limit: 100,                                       // per IP per window
  standardHeaders: "draft-8",                       // RateLimit header
  legacyHeaders: false,                             // no X-RateLimit-*
}));

app.use("/api", apiRouter);

Code Explained

helmet() — about a dozen headers in one call (sheet 41)
cors({ origin, credentials }) — allowlist; cookies need credentials (42)
morgan("dev") — short, colored; "combined" — Apache format
rateLimit — counts by req.ip, so set trust proxy behind a proxy

Prefer / Avoid

  • cors() with no options in production → an explicit origin allowlist
  • morgan in production with no log shipping → pino-http JSON logs (sheet 51)
  • compression() when Nginx/CDN already compresses → compress in one place only

⚠ Common Mistakes

  • Mounting cors() after the routes: preflight OPTIONS requests get 404
  • Rate limiting behind a load balancer without trust proxy: one bucket for every user
  • Logging with morgan *after* a middleware that ends the request: those requests never log

✓ Tips & Best Practices

  • Pin these packages' major versions; their option names change between majors
  • Check npm ls for duplicates after upgrades
  • Group the stack in a middleware/index.js so app.js stays short
