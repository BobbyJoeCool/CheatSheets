Integer Types

C has five standard signed integer types, each with an unsigned partner. The standard only sets minimum sizes, so the exact width depends on the platform: int is 32 bits almost everywhere, but long is 64 bits on Linux/macOS and 32 bits on Windows. <limits.h> gives the real ranges. Literals can be written in decimal, hex, octal and (C23) binary, with suffixes that set their type.

Notes

  • sizeof(char) is always 1
  • Signed overflow is undefined behavior
  • Unsigned arithmetic wraps modulo 2ⁿ
  • Use <stdint.h> when exact width matters

Integer Literals & Limits

#include <limits.h>

int dec = 42;           // decimal
int hex = 0x2A;         // 42
int oct = 052;          // 42 (leading 0 = octal!)
int bin = 0b101010;     // 42 (C23)
long big = 1'000'000L;  // (C23) digit separator

unsigned u   = 42u;
long long ll = 42LL;
unsigned long long ull = 42ULL;

printf("%d\n", INT_MAX);    // 2147483647
printf("%d\n", INT_MIN);    // -2147483648
printf("%u\n", UINT_MAX);   // 4294967295
printf("%zu\n", sizeof(long)); // 8 (Linux/macOS), 4 (Windows)

Code Explained

0x hex, 0 octal, 0b binary (C23)
' digit separator (C23) — ignored by the compiler
u, l, ll suffixes — combine freely: 42ull
INT_MAX — from <limits.h>; also LONG_MAX, CHAR_BIT

⚠ Common Mistakes

  • Writing 010 and expecting ten. A leading zero means octal: 010 == 8
  • Assuming long is 64-bit; it's 32-bit on Windows. Use int64_t or long long
  • INT_MAX + 1 is undefined behavior, not INT_MIN. The optimizer may assume it never happens

✓ Tips & Best Practices

  • Use plain int for everyday counters; reach for <stdint.h> types for file formats and protocols
  • Use unsigned for bit masks, not for "values that can't be negative"
  • Check sizeof at compile time with static_assert(sizeof(long) == 8, "...")

Quick Summary

  • char short int long long long — min sizes only
  • <limits.h> — real ranges
  • 0x 0 0b — hex, octal, binary (C23)
  • Signed overflow = UB; unsigned wraps
