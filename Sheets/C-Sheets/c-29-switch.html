switch

switch jumps to the case label matching an integer expression (including char and enum). Execution then falls through into the following cases until a break, so every case normally ends with break. default handles anything unmatched. Case labels must be compile-time integer constants; strings and ranges aren't allowed.

Notes

  • No strings: use strcmp + if chains
  • Labels must be unique constants
  • default can go anywhere
  • Declare variables inside a { } block

switch with Fallthrough

switch (cmd) {
case 'q':
case 'Q':                       // grouped labels
    quit = true;
    break;
case 'h': {                     // braces allow declarations
    int lines = show_help();
    printf("%d lines\n", lines);
    break;
}
case 'v':
    verbose++;
    [[fallthrough]];            // (C23) intentional
case 'r':
    run();
    break;
default:
    fprintf(stderr, "unknown: %c\n", cmd);
}

Code Explained

case 'q': case 'Q': — several labels share one body
break — leave the switch
{ int lines ... } — scope for case-local variables
[[fallthrough]]; — silences -Wimplicit-fallthrough
default — runs when no label matches

⚠ Common Mistakes

  • Forgetting break, so the next case runs too. Enable -Wimplicit-fallthrough
  • Declaring int x = 1; right after a case label: before C23 that's a syntax error, and other cases see x uninitialized. Add braces
  • Adding default: to an enum switch hides warnings when new enum values are added

✓ Tips & Best Practices

  • Mark deliberate fallthrough with [[fallthrough]]; or a /* fallthrough */ comment
  • For enum switches, omit default and handle every value so -Wswitch helps you
  • Put the most common cases first only for readability; order doesn't affect speed

Quick Summary

  • switch (int) — jump to matching case
  • break — stop fallthrough
  • default — unmatched values
  • Labels: integer constants only
