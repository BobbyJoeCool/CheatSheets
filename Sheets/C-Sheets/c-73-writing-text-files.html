Writing Text Files

fprintf · fputs · fputc · fflush · buffering & setvbuf · append mode · checking write errors

Writing Text

fprintf writes formatted text to a stream, fputs writes a string and fputc a character. Output is buffered: data sits in memory until the buffer fills, a newline is written to a line-buffered terminal, fflush is called or the file is closed. Write errors (disk full, closed pipe) often appear only at fflush or fclose, so check those.

Notes

  • fputs doesn't add a newline (puts does)
  • fprintf returns chars written or negative
  • fflush(NULL) flushes every output stream
  • fflush(stdin) is UB

Writing & Flushing

FILE *f = fopen("report.csv", "w");
if (!f) { perror("report.csv"); return -1; }

fprintf(f, "name,score\n");
for (size_t i = 0; i < n; i++)
    fprintf(f, "%s,%d\n", names[i], scores[i]);
fputs("# end\n", f);
fputc('\n', f);

if (ferror(f)) perror("write");
if (fclose(f) == EOF) perror("close");   // flush errors show here

printf("Working...");          // no newline: may not appear yet
fflush(stdout);                // force it out

setvbuf(stdout, NULL, _IONBF, 0);        // unbuffered
static char big[1 << 16];
setvbuf(f2, big, _IOFBF, sizeof big);    // 64 KB buffer, before first I/O

Code Explained

fprintf(f, ...) — like printf, to any stream
ferror(f) — any write failed so far?
fclose — flushes the remaining buffer; may fail
fflush(stdout) — show a prompt with no newline
setvbuf — choose buffering; call before other I/O

⚠ Common Mistakes

  • Debug output that disappears on a crash because it was still buffered; print to stderr or fflush
  • Ignoring fclose errors; on a full disk that's where the failure shows
  • Calling setvbuf after writing to the stream: UB

✓ Tips & Best Practices

  • Use stderr for logs and diagnostics; it's unbuffered
  • For crash-safe saves: write a temp file, fflush + fsync (POSIX), then rename
  • Batch small writes; buffered fprintf is far faster than many write() calls

Quick Summary

  • fprintf / fputs / fputc
  • Output is buffered
  • fflush — push it out now
