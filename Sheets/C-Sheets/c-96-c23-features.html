C23 at a Glance

nullptr · bool keywords · constexpr · typeof / auto · [[attributes]] · #embed · binary literals & digit separators · <stdbit.h> / <stdckdint.h>

What C23 Adds

C23 (ISO/IEC 9899:2024) is the biggest update since C99. It modernizes the language with nullptr, real bool/true/false keywords, constexpr, typeof and auto inference, standard [[attributes]], binary literals and digit separators, #embed, and new headers for checked arithmetic and bit utilities. It also removes old K&R function definitions and makes f() mean f(void).

Notes

  • -std=c23 (GCC 14+, Clang 18+); -std=c2x earlier
  • __STDC_VERSION__ is 202311L
  • constexpr needs GCC 13+ / Clang 19+
  • Library parts depend on your libc version

C23 in One Screen

#include <stdbit.h>
#include <stdckdint.h>
constexpr int N = 0b1000'0000;        // binary + separator = 128
int *p = nullptr;                     // typed null pointer
bool ok = true;                       // keywords, no header
auto total = 0L;                      // inferred: long
typeof(total) copy = total;

[[nodiscard]] int parse(const char *s);
static_assert(N == 128);              // no message needed

int sum;
if (ckd_add(&sum, INT_MAX, 1)) puts("overflow");
unsigned ones = stdc_count_ones(0xF0u);   // 4

int f();                              // means f(void) now
enum Color : unsigned char { RED, GREEN };  // fixed underlying type
static const unsigned char logo[] = {
#embed "logo.png"
};

Code Explained

constexpr / auto / typeof — inference & constants
ckd_add, stdc_count_ones — new headers
#embed — include file bytes

⚠ Common Mistakes

  • Using C23 features in code that must build with older compilers or MSVC
  • Defining your own bool/true macros, which clash with the new keywords
  • Assuming every C23 library function exists in your libc yet

✓ Tips & Best Practices

  • Guard optional use with #if __STDC_VERSION__ >= 202311L
  • Adopt nullptr, [[nodiscard]] and constexpr first; they catch bugs
  • Check compiler status pages (gcc.gnu.org, clang.llvm.org) per feature

Quick Summary

  • [[attributes]] standardized
  • #embed, 0b, ' separators
  • f() = f(void); K&R gone
