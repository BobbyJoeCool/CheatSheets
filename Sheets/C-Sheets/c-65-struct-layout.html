Struct Layout & Padding

padding · alignment · offsetof · member ordering to save space · #pragma pack · flexible array member int data[]

Padding & Alignment

The compiler inserts padding bytes between members so each one sits at an address that's a multiple of its alignment (often its size). The struct's total size is also rounded up to its largest alignment so arrays of it stay aligned. Ordering members from largest to smallest usually minimizes padding. A flexible array member lets the last member be a variable-length array.

Notes

  • Members stay in declaration order; no reordering
  • offsetof(T, m) from <stddef.h>
  • Packed structs may be slow or fault on some CPUs
  • Padding bytes have unspecified values

Layout & Flexible Arrays

#include <stddef.h>

struct bad  { char a; double b; char c; };   // 1+7, 8, 1+7 = 24
struct good { double b; char a; char c; };   // 8, 1, 1+6   = 16

printf("%zu %zu\n", sizeof(struct bad), sizeof(struct good));  // 24 16
printf("%zu\n", offsetof(struct bad, b));     // 8

struct __attribute__((packed)) wire { uint8_t type; uint32_t len; };
// sizeof(struct wire) == 5 (GCC/Clang)

typedef struct {
    size_t len;
    char   data[];                  // flexible array member (C99)
} Buf;

Buf *b = malloc(sizeof *b + 100);   // header + 100 bytes
b->len = 100;
memcpy(b->data, src, 100);
free(b);                            // one allocation, one free

Code Explained

struct bad — 7 bytes padding after each char
Largest-first ordering — less padding
offsetof — byte offset of a member
packed — no padding; unaligned access
data[] — sized at allocation time

⚠ Common Mistakes

  • Writing a struct to a file or socket with fwrite and expecting other compilers to read it: padding and endianness differ
  • Taking the address of a packed member and dereferencing it as an aligned pointer
  • Using sizeof(Buf) + n but forgetting the flexible member isn't counted in sizeof

✓ Tips & Best Practices

  • Order members by decreasing alignment
  • Serialize field by field with fixed-width types for file formats
  • Use static_assert(sizeof(T) == N) to lock in a layout that matters

Quick Summary

  • Padding aligns members
  • Largest-first ordering saves space
  • offsetof / alignof — inspect layout
  • T data[] — flexible array member
