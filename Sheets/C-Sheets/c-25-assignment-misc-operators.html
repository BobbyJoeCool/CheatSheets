= · += -= <<= &= … · assignment is an expression · comma operator · cast (T) · . / -> · & / * (see Group 9)

Assignment & Friends

In C, assignment is an expression: x = 5 has the value 5, which is why a = b = 0 and while ((c = getchar()) != EOF) work. Compound operators like += combine an operation with assignment. The comma operator evaluates left to right and yields the right value. Casts, member access (. ->), address-of & and dereference * round out the operator set.

Notes

  • Assignment is right-associative
  • x op= y evaluates x only once
  • Commas in calls/declarations are separators, not operators
  • & and * are covered in Sheet 44

Assignment Expressions

int a, b, c;
a = b = c = 0;              // right to left: c=0, b=0, a=0

int x = 10;
x += 5;   // 15     x -= 3;   // 12
x *= 2;   // 24     x /= 5;   // 4
x %= 3;   // 1      x <<= 4;  // 16
x |= 1;   // 17     x &= 0xF; // 1

int ch;
while ((ch = getchar()) != EOF)   // assign, then compare
    putchar(ch);

for (int i = 0, j = 9; i < j; i++, j--) { }  // comma operator
int r = (x++, x * 2);       // r = 4, x = 2

struct point pt = {1, 2}, *pp = &pt;
pt.x = 5;   pp->y = 7;      // member access
double d = (double)x / 3;   // cast

Code Explained

a = b = c = 0 — value of each assignment feeds the next
x op= y — same as x = x op y
(ch = getchar()) != EOF — parentheses required
i++, j-- — comma operator in the loop step
pp->y — shorthand for (*pp).y

⚠ Common Mistakes

  • while (ch = getchar() != EOF): != binds first, so ch becomes 0 or 1
  • x =+ 5 is x = +5, not x += 5
  • int a, b = 0; initializes only b

✓ Tips & Best Practices

  • Keep side effects to one per statement; chained assignments are fine, a[i] = i++ is not
  • Use the comma operator only in for headers
  • Prefer p->m over (*p).m

Quick Summary

  • Assignment is an expression with a value
  • += -= *= /= %= <<= >>= &= |= ^=
  • , — evaluate left, return right
  • . / -> — member access
