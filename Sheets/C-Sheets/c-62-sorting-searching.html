Sorting & Searching

<stdlib.h> provides qsort to sort any array and bsearch to binary-search a sorted one. Both are generic: they take a void * base, element count, element size and a comparator function returning negative, zero or positive. qsort is not guaranteed to be stable. For small or nearly sorted arrays, a hand-written insertion sort is simple and fast.

Notes

  • Comparator gets pointers to elements
  • bsearch needs the same comparator order
  • qsort is often introsort/merge sort; O(n log n)
  • C has no stable sort in the standard library

qsort, bsearch, Insertion Sort

int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);                  // no overflow
}
int cmp_str(const void *a, const void *b) {
    return strcmp(*(const char *const *)a, *(const char *const *)b);
}

int v[] = {42, 7, 19, 3};
qsort(v, 4, sizeof v[0], cmp_int);             // 3 7 19 42
int key = 19;
int *hit = bsearch(&key, v, 4, sizeof v[0], cmp_int);  // &v[2]

const char *names[] = {"cy", "al", "bo"};
qsort(names, 3, sizeof names[0], cmp_str);     // al bo cy

void insertion_sort(int *a, size_t n) {
    for (size_t i = 1; i < n; i++) {
        int x = a[i]; size_t j = i;
        while (j > 0 && a[j - 1] > x) { a[j] = a[j - 1]; j--; }
        a[j] = x;
    }
}

Code Explained

(x > y) - (x < y) — returns -1, 0, 1 safely
cmp_str — elements are char *, so args are char **
bsearch — returns pointer to a match or NULL
sizeof v[0] — element size, not array size
insertion sort — O(n²) but great for tiny n

⚠ Common Mistakes

  • return x - y; in a comparator overflows for large or negative values
  • Comparator for char * arrays that calls strcmp(a, b) on the char ** directly
  • Calling bsearch on unsorted data, or with a different comparator than the sort

✓ Tips & Best Practices

  • Break ties on a second field to make results deterministic
  • Pre-sort once and use bsearch for many lookups
  • For stability, sort an array of indexes and tie-break on the index

Quick Summary

  • qsort — generic, unstable sort
  • bsearch — binary search, sorted data
  • Comparator: negative / 0 / positive
  • Avoid x - y comparators
