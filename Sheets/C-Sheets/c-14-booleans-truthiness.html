Booleans & Truthiness

C treats any zero value (0, 0.0, NULL) as false and anything else as true. C99 added the _Bool type and the <stdbool.h> header with bool, true and false. In C23, bool, true and false became real keywords, so the header is no longer needed. Comparison and logical operators produce an int that is 0 or 1.

Notes

  • Converting any nonzero value to bool gives 1
  • if (ptr) means if (ptr != NULL)
  • !!x normalizes any value to 0 or 1
  • In C23, true and false have type bool

bool in Practice

#include <stdbool.h>        // not needed in C23

bool done = false;
bool ok = 42;               // 1 (any nonzero → true)
int  flag = (3 > 2);        // 1
int  none = (3 < 2);        // 0

if (done) { /* not run */ }
if (!done) puts("working"); // working

int count = 5;
if (count) puts("has items");   // has items

printf("%d\n", !!count);    // 1
printf("%d\n", ok);         // 1  (print bool as int)
printf("%s\n", ok ? "true" : "false");  // true

Code Explained

bool — alias for _Bool (C99), keyword in C23
bool ok = 42; — stores 1, not 42
(3 > 2) — comparisons evaluate to int 1 or 0
%d — bool has no format; print as int or with ?:

⚠ Common Mistakes

  • Comparing with true: if (x == true) fails when x is 2. Write if (x)
  • Assuming "" or "0" is false. They're non-null pointers, so they're true
  • Writing your own #define bool int in C23 code; bool is now a keyword

✓ Tips & Best Practices

  • Name booleans as questions: is_empty, has_error
  • Return bool from predicate functions instead of int 0/1
  • Keep #include <stdbool.h> for code that must build as C99–C17; it's harmless in C23

Quick Summary

  • 0 is false, nonzero is true
  • bool / true / false — <stdbool.h> or C23
  • Comparisons yield int 0 or 1
  • !!x — normalize to 0/1
