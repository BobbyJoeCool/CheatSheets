calloc, realloc & Aligned Allocation

calloc (zeroed) · realloc growth · temp-pointer pattern · realloc(NULL, n) · aligned_alloc · free_sized (C23) · overflow in n * size

Zeroed, Resized & Aligned Memory

calloc(n, size) allocates an array and sets every byte to zero; it also checks n * size for overflow. realloc(p, size) grows or shrinks a block, possibly moving it, and returns the new address. If it fails it returns NULL and leaves the old block untouched, so assign the result to a temporary first. aligned_alloc returns memory with a stricter alignment.

Notes

  • realloc(NULL, n) acts like malloc(n)
  • realloc(p, 0) is UB in C23; avoid it
  • Growing by ×2 (or ×1.5) keeps appends O(1) amortized
  • free_sized(p, n) (C23) — free with known size

calloc & Safe realloc

int *counts = calloc(256, sizeof *counts);   // 256 zeros
if (!counts) return -1;

size_t cap = 16, len = 0;
int *items = malloc(cap * sizeof *items);

if (len == cap) {
    if (cap > SIZE_MAX / 2 / sizeof *items) return -1;  // overflow check
    size_t new_cap = cap * 2;
    int *tmp = realloc(items, new_cap * sizeof *items);
    if (!tmp) { free(items); return -1; }    // old block still valid
    items = tmp;
    cap = new_cap;
}
items[len++] = 42;

void *buf = aligned_alloc(64, 4096);   // size must be multiple of 64
free(buf);

Code Explained

calloc — zero-filled, overflow-checked size
SIZE_MAX / 2 / sizeof — make sure the new size fits
tmp = realloc(...) — never assign straight to items
items = tmp — the block may have moved
aligned_alloc(64, ...) — cache-line aligned

⚠ Common Mistakes

  • p = realloc(p, n); — on failure p becomes NULL and the old block leaks
  • Keeping other pointers into a block after realloc moved it; they now dangle
  • Assuming calloc zero means 0.0 / NULL for every type; true on all mainstream platforms, not guaranteed

✓ Tips & Best Practices

  • Wrap growth logic in one function (vec_reserve) and reuse it
  • Store indexes, not pointers, into arrays that may be realloced
  • Use calloc for arrays of counters and structs you want zeroed

Quick Summary

  • calloc(n, size) — zeroed array
  • tmp = realloc(p, n) — safe resize
  • Blocks may move on realloc
  • aligned_alloc — custom alignment
