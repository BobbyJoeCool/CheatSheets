gcc · clang · MSVC · xcode-select --install · cc --version · -std=c17 / -std=c23 · editor + LSP (clangd)

Getting a Compiler

C code needs a compiler that turns source into machine code, plus a linker and the C library. On macOS the Xcode Command Line Tools install Clang (and alias gcc to it). Linux distributions ship GCC and usually offer Clang. On Windows use MSVC (Visual Studio) or GCC/Clang through MSYS2 or WSL. Pair the compiler with an editor that uses clangd for completion and inline errors.

Good to Know

  • On macOS, gcc is really Apple clang
  • cc is the system's default C compiler on Unix-like systems
  • Older compilers spell C23 as -std=c2x
  • MSVC flags use /: /std:c17, /W4

Install & Verify

# macOS: Apple Clang + make + lldb
xcode-select --install
clang --version        # Apple clang version 17.x ...

# macOS: real GCC via Homebrew (installs as gcc-15)
brew install gcc

# Debian / Ubuntu
sudo apt install build-essential clang gdb

cc --version           # which compiler is "cc"?

# Pick a standard explicitly
cc -std=c17 hello.c -o hello
cc -std=c23 hello.c -o hello

Code Explained

xcode-select --install — Clang, make, lldb, headers & SDK
build-essential — GCC, make, libc headers on Debian/Ubuntu
brew install gcc — versioned binary like gcc-15; plain gcc stays Clang
-std=c17 — choose the language standard; default varies by compiler
-std=gnu17 — C17 plus GNU extensions (GCC's default family)

⚠ Common Mistakes

  • Thinking gcc on a Mac is GNU GCC. It's Clang unless you call gcc-15 (or similar) from Homebrew
  • Not passing -std=: you get the compiler's default (often gnu17), so code may rely on extensions without you knowing
  • Running MSVC with C++ settings on a .c file; use /TC or keep the .c extension

✓ Tips & Best Practices

  • Use both GCC and Clang in CI; each catches warnings the other misses
  • Generate compile_commands.json with cmake -DCMAKE_EXPORT_COMPILE_COMMANDS=ON or bear -- make
  • Add -std=c17 -Wall -Wextra -pedantic to every build from day one

Quick Summary

  • clang / gcc — the two main open compilers
  • cc --version — see what you're really running
  • -std=c17 — pin the language standard
  • clangd — editor intelligence for C
