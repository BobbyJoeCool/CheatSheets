const and void Pointers

const can apply to the pointed-to data, the pointer itself, or both, depending on where it sits: read declarations right to left. void * is a generic pointer that can hold the address of any object; C converts it to and from other object pointer types without a cast. restrict promises the compiler that no other pointer touches the same data, enabling optimizations.

Notes

  • T * → const T * is implicit and safe
  • const T * → T * needs a cast (and care)
  • void * can't be dereferenced
  • memcpy uses restrict; memmove doesn't

const Placement & void *

int x = 1, y = 2;

const int *a = &x;        // pointer to const int
// *a = 5;                // error: data is read-only
a = &y;                   // OK: pointer can move

int *const b = &x;        // const pointer to int
*b = 5;                   // OK
// b = &y;                // error: pointer can't move

const int *const c = &x;  // neither can change

void *v = &x;             // any object pointer → void *
int  *ip = v;             // void * → int *, no cast in C
size_t len(const char *s);   // promises not to modify s

void add(int *restrict out, const int *restrict in, size_t n);

Code Explained

const int *a — "a is a pointer to const int"
int *const b — "b is a const pointer to int"
Right to left — const applies to what's on its left (or right, if first)
void * ↔ T * — implicit in C (not in C++)
restrict — out and in don't overlap

⚠ Common Mistakes

  • Casting away const and writing to an object that was defined const: UB
  • Casting malloc's result in C: unnecessary, and it can hide a missing #include <stdlib.h> in old compilers
  • Using restrict when pointers might alias; the optimizer will produce wrong results

✓ Tips & Best Practices

  • Make every read-only pointer parameter const T *
  • Use void * + size for generic APIs (qsort, memcpy)
  • Paste confusing declarations into cdecl.org for an English reading

Quick Summary

  • const T * — read-only data
  • T *const — fixed pointer
  • void * — generic, converts implicitly
  • restrict — no aliasing promise
