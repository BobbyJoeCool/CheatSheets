What C Is

C is a small, compiled, statically typed systems language created by Dennis Ritchie at Bell Labs (1972) to write Unix. It gives you direct control over memory through pointers, compiles to fast native code, and runs almost everywhere: operating systems, embedded firmware, databases, language runtimes. The trade-off is that the compiler trusts you: there are no bounds checks, no garbage collector, and many mistakes are undefined behavior rather than errors.

Key Facts

  • Source files end in .c; headers end in .h
  • ISO/IEC 9899; newest edition is C23 (2024)
  • This set targets C17 and tags newer features (C23)
  • C++ is a separate language, not a superset

Hello, World

/* hello.c */
#include <stdio.h>              // declares printf

int main(void)                  // program starts here
{
    printf("Hello, World!\n");  // Hello, World!
    return 0;                   // 0 = success
}

/* Check which standard the compiler is using */
#if __STDC_VERSION__ >= 201710L
    /* C17 or newer */
#endif

Code Explained

#include <stdio.h> — pulls in the standard I/O declarations
int main(void) — entry point; returns an exit status to the OS
\n — newline; printf doesn't add one for you
__STDC_VERSION__ — predefined macro holding the standard as a long date
Build & run: cc hello.c -o hello && ./hello

⚠ Common Mistakes

  • Treating C as "C++ without classes": casts, bool, empty () and string literals all behave differently
  • Assuming the compiler will catch memory bugs. It won't; out-of-bounds writes compile fine and corrupt memory silently
  • Mixing up the standard (C17) with a compiler version (GCC 14). Pick the standard with -std=

✓ Tips & Best Practices

  • Always compile with warnings on: -Wall -Wextra catches a large share of beginner bugs
  • Bookmark cppreference.com/w/c: it has a C-only section with per-standard notes
  • Read *K&R* for style, but check modern references; it predates C99

Quick Summary

  • C — compiled, low-level, portable systems language
  • C17 — baseline here; C23 is newest
  • main — entry point, returns exit status
  • UB — compiles, but results are unpredictable
