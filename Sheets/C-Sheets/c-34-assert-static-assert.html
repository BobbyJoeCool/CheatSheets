assert, static_assert & exit

assert · NDEBUG · static_assert / _Static_assert · abort · exit / EXIT_FAILURE · atexit · quick_exit

Assertions & Exiting

assert(cond) checks a condition at runtime and aborts with a message if it's false; it documents programmer assumptions, not user errors, and disappears when NDEBUG is defined. static_assert checks conditions at compile time. To end a program, exit runs cleanup (flushes streams, calls atexit handlers), while abort stops immediately.

Notes

  • static_assert is a keyword in C23 (_Static_assert in C11)
  • C23 allows static_assert(cond) without a message
  • assert calls abort() → exit code 134 on Unix
  • return n from main = exit(n)

assert, static_assert, exit

#include <assert.h>
#include <stdlib.h>

static_assert(sizeof(int) == 4, "need 32-bit int");
static_assert(CHAR_BIT == 8);                    // (C23) no message

int average(const int *a, size_t n) {
    assert(a != NULL);
    assert(n > 0 && "n must be positive");      // message trick
    /* ... */
}

static void cleanup(void) { puts("bye"); }

int main(void) {
    atexit(cleanup);            // runs on exit/return from main
    if (!config_ok()) exit(EXIT_FAILURE);
    if (corrupt) abort();       // no cleanup, core dump
    return EXIT_SUCCESS;        // prints "bye"
}

Code Explained

static_assert — compile error if false
assert(p) — file.c:7: average: Assertion 'a != NULL' failed.
&& "msg" — string is always true, appears in the message
atexit — register up to 32+ cleanup functions (LIFO)
abort — raises SIGABRT; no atexit handlers

⚠ Common Mistakes

  • Putting side effects in assert: assert(init() == 0) vanishes with NDEBUG
  • Using assert for runtime errors like a failed fopen; release builds won't check it
  • Calling exit inside a library function; return an error and let the caller decide

✓ Tips & Best Practices

  • Keep asserts on in test builds; consider leaving them on in release for critical invariants
  • Use static_assert next to code that depends on struct layout or type sizes
  • Return EXIT_FAILURE, not -1, for portable failure codes

Quick Summary

  • assert(cond) — runtime check, debug only
  • static_assert — compile-time check
  • exit — clean shutdown; abort — immediate
  • atexit(fn) — register cleanup
