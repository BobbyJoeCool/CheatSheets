while & do-while

while (cond) body checks the condition first, so the body may never run. do body while (cond); runs the body at least once and checks afterwards, and needs a semicolon at the end. while suits loops driven by input or state rather than a counter, such as reading characters until EOF.

Notes

  • do ... while (cond); needs the ;
  • while (1) / for (;;) — infinite loops
  • Variables declared in the body aren't visible in a do-while condition
  • do { } while (0) — macro idiom (Sheet 77)

Condition-Driven Loops

int c;
while ((c = getchar()) != EOF)      // read until end of input
    putchar(toupper(c));

int n = 12345, digits = 0;
while (n != 0) {                    // 0 iterations if n == 0
    n /= 10;
    digits++;
}

int choice;
do {                                // menu runs at least once
    printf("1) Start 2) Quit: ");
    if (scanf("%d", &choice) != 1) break;
} while (choice != 2);

while (node) {                      // walk a linked list
    sum += node->value;
    node = node->next;
}

(c = getchar()) != EOF — read, assign, test

⚠ Common Mistakes

  • Forgetting to change the loop variable inside while, creating an infinite loop
  • Missing ; after while (cond) in a do-while: a compile error
  • while (!feof(f)) reads one extra time; test the read call's result instead (Sheet 72)

✓ Tips & Best Practices

  • Prefer for when there's a counter; while when there isn't
  • Put the read call in the condition so the loop stops on failure
  • Use do-while for input validation: ask, then check

Quick Summary

  • while — test first, 0+ runs
  • do-while — test last, 1+ runs
  • while ((c = getchar()) != EOF)
  • Make sure the condition changes
