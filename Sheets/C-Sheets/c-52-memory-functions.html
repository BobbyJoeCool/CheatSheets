Memory Functions

memcpy · memmove (overlap-safe) · memset · memcmp · memchr · memccpy · memset_explicit (C23)

Raw Memory Functions

<string.h> includes functions that work on raw bytes rather than strings: they take an explicit length and don't stop at '\0'. memcpy copies between non-overlapping regions, memmove handles overlap, memset fills bytes, memcmp compares and memchr searches. They're the building blocks for copying structs, arrays and buffers.

Notes

  • Sizes are in bytes
  • memset sets each byte to the low 8 bits of its value
  • memcmp on structs also compares padding
  • memset_explicit (C23) won't be optimized away

Copy, Move, Fill, Compare

#include <string.h>

int src[5] = {1, 2, 3, 4, 5}, dst[5];
memcpy(dst, src, sizeof src);            // copy 20 bytes

int a[6] = {1, 2, 3, 4, 5, 6};
memmove(a + 1, a, 5 * sizeof *a);        // overlap: {1,1,2,3,4,5}

char buf[64];
memset(buf, 0, sizeof buf);              // zero it
memset(buf, '-', 10);                    // ten dashes

int ints[4];
memset(ints, 0xFF, sizeof ints);         // each int = -1
// memset(ints, 1, sizeof ints);         // each int = 0x01010101!

if (memcmp(src, dst, sizeof src) == 0) puts("same");
char *at = memchr(buf, '-', sizeof buf); // first '-'
memset_explicit(key, 0, sizeof key);     // (C23) wipe secrets

Code Explained

memcpy — fastest copy, regions must not overlap
memmove — correct even when they overlap
memset(p, 0, n) — zero n bytes
memset(ints, 1, ...) — sets bytes, not ints
memset_explicit — survives optimization

⚠ Common Mistakes

  • memcpy with overlapping regions (e.g. shifting an array): UB; use memmove
  • memset(arr, 1, n) to set ints to 1; only 0 and -1 (0xFF) work this way
  • Passing an element count instead of a byte count: memcpy(d, s, n) for n ints

✓ Tips & Best Practices

  • Use sizeof dst or n * sizeof *dst for the length
  • Copy structs with =; it's clearer than memcpy and type-checked
  • Clear passwords with memset_explicit (or explicit_bzero on BSD/glibc)

Quick Summary

  • memcpy — copy, no overlap
  • memmove — copy, overlap OK
  • memset — fill bytes
  • memcmp / memchr — compare / find
