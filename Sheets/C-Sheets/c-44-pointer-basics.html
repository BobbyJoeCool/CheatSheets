What a Pointer Is

A pointer is a variable that holds a memory address. &x gives the address of x; *p dereferences a pointer to read or write the object it points to. A pointer's type says what it points to, which tells the compiler how to read the bytes there. A pointer that points nowhere should be the null pointer: NULL, or nullptr in C23.

Notes

  • Pointer size is fixed per platform (8 bytes on 64-bit)
  • * in a declaration declares; in an expression dereferences
  • Dereferencing NULL is UB (usually a crash)
  • nullptr (C23) has its own type, nullptr_t

Address-of & Dereference

int x = 10;
int *p = &x;            // p holds x's address

printf("%d\n", *p);     // 10  (read through p)
*p = 20;                // write through p
printf("%d\n", x);      // 20
printf("%p\n", (void *)p);   // 0x7ffc...

int *q = NULL;          // points nowhere
if (q != NULL) *q = 5;  // always check before deref

int **pp = &p;          // pointer to pointer
**pp = 30;              // x == 30

int *a, b;              // a: int*, b: int  (!)
int *r;                 // uninitialized: wild pointer
int *s = nullptr;       // (C23)

Code Explained

int *p = &x; — declare a pointer and store x's address
*p — the int that p points at
NULL — guaranteed not to point at any object
**pp — follow two levels
int *r; — holds garbage; never dereference

⚠ Common Mistakes

  • Dereferencing an uninitialized pointer: int *p; *p = 1; writes to a random address
  • Forgetting *: p = 5; changes where p points, not the value
  • Printing a pointer with %d or %x; use %p with (void *)

✓ Tips & Best Practices

  • Initialize every pointer: to a valid address or NULL
  • Read int *p as "*p is an int"
  • Use nullptr in C23 code; it can't be mistaken for an integer

Quick Summary

  • &x — address of
  • *p — dereference
  • NULL / nullptr — points nowhere
  • Never dereference wild or null pointers
