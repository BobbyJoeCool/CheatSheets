Generic Programming

_Generic · void * containers · element-size parameters · macro-generated types · typeof (C23) · comparator callbacks

Generic Code in C

C has no templates, but there are several ways to write code that works for many types. void * plus an element size (like qsort) works for any type at the cost of type safety. Macros can generate type-specific code. _Generic (C11) selects an expression based on the type of its argument, giving compile-time overloading. C23 typeof makes type-generic macros easier to write safely.

Notes

  • _Generic is resolved at compile time
  • <tgmath.h> is built on _Generic
  • void * APIs need a size and callbacks
  • Macro-generated code is hard to debug; keep it small

_Generic & Macro Templates

#define type_name(x) _Generic((x),   \
    int: "int", double: "double",    \
    char *: "char *", default: "other")
printf("%s\n", type_name(3.0));       // double

double absd(double x) { return x < 0 ? -x : x; }
long   absl_(long x)  { return x < 0 ? -x : x; }
#define ABS(x) _Generic((x), double: absd, long: absl_, default: absl_)(x)
ABS(-2.5);                            // calls absd

#define DEFINE_VEC(T)                                              \
    typedef struct { T *data; size_t len, cap; } Vec_##T;          \
    static inline int Vec_##T##_push(Vec_##T *v, T x) { /* ... */ return 0; }
DEFINE_VEC(int)                        // Vec_int, Vec_int_push
DEFINE_VEC(double)                     // Vec_double, Vec_double_push

#define MAX(a, b) ({ typeof(a) a_ = (a), b_ = (b); a_ > b_ ? a_ : b_; })  // GNU
void swap_any(void *a, void *b, size_t size);   // void * + size

Code Explained

_Generic(x, type: expr, ...) — picks by x's type
ABS(x) — selects the function, then calls it
DEFINE_VEC(T) — stamps out a type-specific vector
typeof + statement expression — single evaluation (GNU)
void * + size — runtime-generic

⚠ Common Mistakes

  • Forgetting a type in _Generic; with no default, it's a compile error
  • Passing float to an _Generic that only lists double
  • Huge macro templates; errors point at the macro call, not the bug

✓ Tips & Best Practices

  • Use _Generic for thin type-dispatch wrappers over real functions
  • Keep generated code minimal and call shared void * helpers
  • Look at stb_ds.h or klib for battle-tested generic containers

Quick Summary

  • void * + size — runtime generic
  • Macros — generate per-type code
  • _Generic — compile-time dispatch
  • typeof (C23) — safer macros
