Storage Duration & Lifetime

automatic · static locals · allocated (heap) · thread_local · lifetime vs scope · returning a pointer to a local · register

How Long Objects Live

Storage duration is how long an object exists, separate from where its name is visible. Automatic objects (locals) live until their block ends. Static objects (globals and static locals) live for the whole program and are zero-initialized. Allocated objects live from malloc until free. Thread storage (thread_local) gives each thread its own copy.

Notes

  • Static locals initialize once, before first use
  • Static initializers must be constant expressions
  • Returning a local's address = dangling pointer
  • register is obsolete; can't take its address

Lifetimes

int calls(void) {
    static int n = 0;          // lives across calls
    return ++n;                // 1, 2, 3, ...
}

int *bad(void) {
    int local = 42;
    return &local;             // BUG: local dies at return
}

int *good(void) {
    int *p = malloc(sizeof *p);  // allocated: lives until free
    if (p) *p = 42;
    return p;                    // caller must free(p)
}

const char *name(void) { return "fixed"; }  // literal: static storage

thread_local int errors;     // C23 keyword (C11: _Thread_local)

Code Explained

static int n — one copy, keeps its value between calls
&local — address of an object that's gone after return
malloc — lifetime controlled by you
String literals — static storage, safe to return
thread_local — per-thread variable

⚠ Common Mistakes

  • Returning a pointer to a local array: char buf[64]; return buf;
  • Assuming a static local resets on each call
  • Using static buffers in functions called from multiple threads (like strtok); results get clobbered

✓ Tips & Best Practices

  • Return heap memory or fill a caller-provided buffer, never a local's address
  • Use static locals for one-time initialization or simple counters
  • GCC/Clang warn with -Wreturn-local-addr / -Wreturn-stack-address

Quick Summary

  • automatic — block lifetime
  • static — whole program, zeroed
  • allocated — malloc to free
  • thread — per-thread copy
