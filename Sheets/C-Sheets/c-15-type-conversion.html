Conversions

C converts between arithmetic types automatically. In expressions, small types (char, short) are promoted to int, and when two operands differ the usual arithmetic conversions pick a common type, preferring floating over integer and wider over narrower. Assignments convert to the target type, which can silently truncate. A cast (type)expr makes a conversion explicit.

Notes

  • Float → int truncates toward zero
  • Out-of-range float → int is UB
  • Out-of-range → unsigned wraps (well-defined)
  • Out-of-range → signed is implementation-defined

Implicit & Explicit Conversion

int    i = 3.99;              // 3 (truncated)
double d = 7 / 2;             // 3.0 (int division first)
double e = (double)7 / 2;     // 3.5
int    r = (int)(2.7 + 0.5);  // 3 (manual rounding)

unsigned char uc = 300;       // 44 (300 mod 256)
char c = 'a';
printf("%zu\n", sizeof(c + 1));  // 4: char promoted to int

int neg = -1;
unsigned int u = 1;
if (neg < u) puts("less");    // NOT printed!
// -1 converts to unsigned → 4294967295

long long big = 1000000 * 1000000;    // overflow (int math)
long long ok  = 1000000LL * 1000000;  // 1000000000000

Code Explained

int i = 3.99; — fraction dropped, no rounding
(double)7 / 2 — cast one operand before dividing
sizeof(c + 1) — arithmetic on char happens in int
neg < u — signed converted to unsigned; -Wsign-compare warns
1000000LL * — make the math wide before it overflows

⚠ Common Mistakes

  • double avg = total / n; with ints gives a truncated result. Write (double)total / n
  • Comparing int with size_t (if (i < strlen(s)) with negative i); the int becomes huge
  • long long x = a * b; with int a, b: the multiply overflows before widening

✓ Tips & Best Practices

  • Enable -Wconversion -Wsign-conversion to see every silent narrowing
  • Round with lround(x) from <math.h> instead of adding 0.5
  • Cast at the operand, not the result: (int64_t)a * b

Quick Summary

  • Small types promote to int
  • Mixed types convert to the wider/floating one
  • (T)x — explicit cast
  • Signed vs unsigned compares are a trap
