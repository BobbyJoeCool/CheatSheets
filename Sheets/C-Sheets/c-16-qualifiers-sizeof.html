Qualifiers & sizeof

Type qualifiers add rules to a type: const makes an object read-only, volatile tells the compiler every access matters (hardware registers, signal flags), and restrict promises a pointer is the only way to reach its data. sizeof is an operator that gives an object's size in bytes at compile time. C23 adds typeof and constexpr for type inference and true compile-time constants.

Notes

  • sizeof returns size_t; print with %zu
  • sizeof x needs no parentheses for objects
  • sizeof doesn't evaluate its operand (except VLAs)
  • alignof(T) — required alignment (C11 _Alignof)

const, volatile, sizeof, typeof

const int max = 10;
// max = 11;                    // error: read-only

volatile int ready = 0;         // re-read on every access
const volatile uint32_t *status_reg = (uint32_t *)0x40021000;

int arr[8];
printf("%zu\n", sizeof arr);            // 32
printf("%zu\n", sizeof arr / sizeof arr[0]);  // 8
printf("%zu\n", sizeof(double));        // 8
int i = 0;
size_t s = sizeof(i++);                 // i is still 0

typeof(max) copy = max;         // (C23) const int
constexpr int N = 16;           // (C23) compile-time constant
int buf[N];

Code Explained

volatile — no caching in registers; not a thread-safety tool
sizeof arr / sizeof arr[0] — element count (only for real arrays)
sizeof(i++) — operand not evaluated
typeof (C23) — the type of an expression
constexpr (C23) — usable where a constant expression is required

⚠ Common Mistakes

  • Using const int N = 10; int a[N]; at file scope. In C, const variables aren't constant expressions; use enum or constexpr
  • Using volatile for shared data between threads; use _Atomic or a mutex
  • sizeof(ptr) when you meant the array size: inside a function, an array parameter is a pointer

✓ Tips & Best Practices

  • Mark pointer parameters const when the function only reads: size_t len(const char *s)
  • Allocate with malloc(n * sizeof *p) so the size follows p's type
  • Use enum { BUF_SIZE = 256 }; for typed constants in pre-C23 code

Quick Summary

  • const — read-only
  • volatile — don't optimize away accesses
  • sizeof x — size in bytes, compile time
  • typeof / constexpr — C23 additions
