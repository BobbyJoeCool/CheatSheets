POSIX Threads

pthreads is the threading API on Linux, macOS and other Unix systems. It mirrors C11 threads with more features: attributes for stack size and detach state, read-write locks, barriers and thread cancellation. Thread functions take and return void *. Compile and link with -pthread. Most pthread functions return an error number instead of setting errno.

Notes

  • Always wait on a condvar inside a while loop
  • Spurious wakeups are allowed
  • Lock order must be consistent to avoid deadlock
  • Windows: use C11 threads or Win32 APIs

Producer / Consumer

#include <pthread.h>
static pthread_mutex_t m = PTHREAD_MUTEX_INITIALIZER;
static pthread_cond_t  ready = PTHREAD_COND_INITIALIZER;
static int queue_len = 0;
void *producer(void *arg) {
    pthread_mutex_lock(&m);
    queue_len++;
    pthread_cond_signal(&ready);        // wake a waiter
    pthread_mutex_unlock(&m);
    return NULL;
}
void *consumer(void *arg) {
    pthread_mutex_lock(&m);
    while (queue_len == 0)              // loop: spurious wakeups
        pthread_cond_wait(&ready, &m);  // unlocks m while waiting
    queue_len--;
    pthread_mutex_unlock(&m);
    return NULL;
}
pthread_t p, c;
pthread_create(&c, NULL, consumer, NULL);
pthread_create(&p, NULL, producer, NULL);
pthread_join(p, NULL);  pthread_join(c, NULL);

Code Explained

PTHREAD_MUTEX_INITIALIZER — static init, no init call
pthread_cond_signal — wake one waiting thread
while (cond) pthread_cond_wait(...) — the only correct pattern
pthread_cond_wait — atomically unlocks, sleeps, relocks
pthread_create(&t, attr, fn, arg)

⚠ Common Mistakes

  • if instead of while around pthread_cond_wait
  • Checking errno after a pthread call; the error is the return value
  • Locking two mutexes in different orders in different threads: deadlock

✓ Tips & Best Practices

  • Compile and link with -pthread, not just -lpthread
  • Keep critical sections short; never call slow I/O while holding a lock
  • Run under ThreadSanitizer (-fsanitize=thread) in CI
