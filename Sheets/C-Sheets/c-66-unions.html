Unions

A union overlays all its members on the same memory, so it's only as big as its largest member and holds one value at a time. Unions save space when an object can be one of several types, usually paired with a tag that records which member is active (a tagged union). C also allows reading a different member than the one written (type punning), with implementation-defined results.

Notes

  • sizeof(union) ≥ largest member
  • Writing one member changes the others' bytes
  • Anonymous unions/structs are C11
  • Initializer sets the first member unless designated

Tagged Union

typedef enum { NUM, STR, BOOL } Kind;

typedef struct {
    Kind kind;
    union {                     // anonymous union (C11)
        double num;
        char  *str;
        bool   flag;
    };
} Value;

void print_value(const Value *v) {
    switch (v->kind) {
    case NUM:  printf("%g\n", v->num); break;
    case STR:  printf("%s\n", v->str); break;
    case BOOL: printf("%s\n", v->flag ? "true" : "false"); break;
    }
}
Value v = {.kind = NUM, .num = 3.5};
print_value(&v);                // 3.5

union { float f; uint32_t u; } pun = {.f = 1.0f};
printf("%08x\n", pun.u);        // 3f800000

Code Explained

Kind kind — the tag says which member is valid
Anonymous union — access v->num directly
switch on the tag — handle each case
.num = 3.5 — designate the active member
pun.u — reinterpret float bits (type punning)

⚠ Common Mistakes

  • Reading the member that wasn't written last, without a tag, by accident
  • Forgetting to update the tag when changing the active member
  • Byte-view unions assume an endianness; results differ on big-endian CPUs

✓ Tips & Best Practices

  • Always pair a union with a tag enum in the same struct
  • Use switch on the tag with no default so -Wswitch flags new kinds
  • Use memcpy instead of a union for punning if the code might be compiled as C++

Quick Summary

  • union — members share memory
  • Size = largest member
  • Tagged union = enum + union
  • Punning: implementation-defined in C
