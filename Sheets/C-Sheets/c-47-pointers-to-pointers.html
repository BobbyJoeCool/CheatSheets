Double Pointers

A pointer to a pointer (T ) lets a function change which object** the caller's pointer refers to, not just the object's contents. You'll see them in main's argv, in functions that allocate and return memory through a parameter, in arrays of strings, and in dynamically allocated 2D arrays made of separate rows.

Notes

  • char **argv ⇔ char *argv[] as a parameter
  • T doesn't convert to const T implicitly
  • Jagged rows can differ in length
  • Each row allocation needs its own free

Changing the Caller's Pointer

int make_buffer(char **out, size_t n) {
    *out = malloc(n);              // set caller's pointer
    return *out ? 0 : -1;
}
char *buf = NULL;
if (make_buffer(&buf, 64) == 0) { /* use buf */ free(buf); }

for (char **a = argv; *a; a++)    // argv ends with NULL
    puts(*a);

int **grid = malloc(rows * sizeof *grid);       // jagged 2D
for (int r = 0; r < rows; r++)
    grid[r] = calloc(cols, sizeof **grid);
grid[1][2] = 7;
for (int r = 0; r < rows; r++) free(grid[r]);
free(grid);

Code Explained

char **out — address of the caller's char *
*out = malloc(n) — writes into the caller's variable
*a — loop until the NULL after the last arg
grid[r] = calloc(...) — one allocation per row
Free rows first, then the row array

⚠ Common Mistakes

  • Passing buf instead of &buf: the function changes its own copy and the caller's pointer stays NULL
  • Freeing the row array before the rows: the row pointers are lost (leak)
  • Treating int ** as a true 2D array int[R][C]; their memory layouts differ

✓ Tips & Best Practices

  • For rectangular data, prefer one block: int (*m)[cols] = malloc(rows * sizeof *m);
  • Check every row allocation and clean up the ones that succeeded on failure
  • Name out-parameters clearly: out_buf, out_len

Quick Summary

  • T ** — pointer to a pointer
  • Pass &ptr to let a function reassign it
  • argv — NULL-terminated char **
  • Jagged arrays: free rows, then spine
