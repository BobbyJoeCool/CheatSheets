Stacks, Queues & Ring Buffers

A stack is last-in, first-out: push and pop at one end, easily built on an array. A queue is first-in, first-out: add at the back, remove from the front. A ring buffer (circular buffer) implements a bounded queue in a fixed array using head and tail indexes that wrap around with % or a power-of-two mask.

Notes

  • Track count to tell full from empty
  • Power-of-two capacity → & (cap - 1) wrap
  • Linked lists make unbounded queues
  • Ring buffers suit producer/consumer streams

Array Stack & Ring Buffer

enum { CAP = 8 };
typedef struct { int items[CAP]; size_t top; } Stack;
bool push(Stack *s, int v) {
    if (s->top == CAP) return false;        // full
    s->items[s->top++] = v;
    return true;
}
int pop(Stack *s) { return s->items[--s->top]; }  // check top > 0

typedef struct { int buf[CAP]; size_t head, tail, count; } Ring;

bool ring_put(Ring *r, int v) {
    if (r->count == CAP) return false;      // full
    r->buf[r->tail] = v;
    r->tail = (r->tail + 1) % CAP;          // wrap around
    r->count++;
    return true;
}
bool ring_get(Ring *r, int *v) {
    if (r->count == 0) return false;        // empty
    *v = r->buf[r->head];
    r->head = (r->head + 1) % CAP;
    r->count--;
    return true;
}

Code Explained

items[top++] / items[--top] — push / pop
tail — next write slot; head — next read slot
% CAP — wrap to 0 at the end
count — distinguishes full from empty
bool return — caller learns about full / empty

⚠ Common Mistakes

  • Popping an empty stack without checking: reads items[-1] (UB via size_t wrap)
  • Using only head == tail to test empty; it's also true when full unless you track count or waste a slot
  • Using % with a negative index when moving backward

✓ Tips & Best Practices

  • Use power-of-two capacities and & (CAP - 1) in hot paths
  • Return bool and pass the value out, so errors aren't mixed with data
  • For lock-free single-producer/single-consumer rings, use _Atomic indexes

Quick Summary

  • Stack — LIFO, array + top
  • Queue — FIFO
  • Ring — fixed array, wrapping indexes
  • Track count for full vs empty
