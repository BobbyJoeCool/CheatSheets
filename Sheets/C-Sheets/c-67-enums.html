Enumerations

An enum defines named integer constants. Values start at 0 and count up unless you assign them. Enumerators are plain int constants usable anywhere a constant expression is needed, including case labels and array sizes. C enums aren't type-safe: any integer converts to an enum. C23 lets you fix the underlying type, e.g. enum : uint8_t.

Notes

  • Enumerators share one namespace with variables
  • Prefix names to avoid clashes: COLOR_RED
  • A trailing COUNT member gives the number of values
  • Underlying type pre-C23 is implementation-defined

Enums in Practice

enum color { RED, GREEN, BLUE };          // 0, 1, 2
enum status { OK = 0, ERR_IO = 10, ERR_MEM };   // ERR_MEM = 11

typedef enum { LOG_DEBUG, LOG_INFO, LOG_WARN, LOG_COUNT } LogLevel;
static const char *level_names[LOG_COUNT] = {
    [LOG_DEBUG] = "debug", [LOG_INFO] = "info", [LOG_WARN] = "warn",
};
printf("%s\n", level_names[LOG_WARN]);    // warn

enum perm { P_READ = 1 << 0, P_WRITE = 1 << 1, P_EXEC = 1 << 2 };
unsigned p = P_READ | P_WRITE;            // flags
if (p & P_WRITE) puts("writable");

enum : uint8_t { SMALL_A, SMALL_B };      // (C23) fixed type
enum { BUF_SIZE = 256 };                  // named constant
char buf[BUF_SIZE];

enum color c = 42;                        // allowed: no type safety

Code Explained

Implicit values — previous + 1
LOG_COUNT — sizes arrays indexed by the enum
Designated array init by enum — order-proof lookup table
1 << n — bit flags combined with |
enum { BUF_SIZE = 256 } — typed constant pre-C23

⚠ Common Mistakes

  • Assuming an enum variable can only hold listed values; C won't stop enum color c = 42;
  • Two enums with the same enumerator name in one scope: redefinition error
  • Printing an enum and expecting its name; you get the number. Use a lookup table

✓ Tips & Best Practices

  • End with a _COUNT member for loops and lookup tables
  • Use switch without default over enums so new values trigger warnings
  • Use C23 enum : uint8_t to control size in packed structs and protocols

Quick Summary

  • enum { A, B } — named int constants
  • Values start at 0 unless set
  • 1 << n — flag enums
  • enum : T (C23) — fixed type
