Where Things Live

A running C program's memory is divided into regions. The stack holds function locals and grows and shrinks with calls. The heap holds malloced blocks. Static storage holds globals and static variables: .data for initialized ones and .bss for zero-initialized ones. Code and string literals sit in read-only text/rodata segments. Objects also have alignment requirements.

Notes

  • Stack size: ~8 MB main thread (Linux/macOS), 1 MB (Windows)
  • Secondary threads often get smaller stacks
  • .bss takes no space in the executable file
  • alignas / alignof are C23 keywords (_Alignas C11)

Which Region?

int counter = 5;               // .data (initialized static)
int table[1000];               // .bss (zeroed static)
const char *msg = "hi";        // msg: .data; "hi": .rodata

void f(void) {
    int local = 1;             // stack
    static int calls;          // .bss
    int *heap = malloc(64);    // pointer on stack, block on heap
    char big[1 << 20];         // 1 MB on the stack: risky!
    free(heap);
}

alignas(64) static char cache_line[64];  // 64-byte aligned
printf("%zu\n", alignof(double));        // 8

struct s { char c; int i; };   // 3 padding bytes after c
printf("%zu\n", sizeof(struct s));       // 8

Code Explained

.data / .bss — static storage, exists for the whole run
"hi" — read-only literal
char big[1 << 20] — large locals can overflow the stack
alignas(64) — request stronger alignment
Padding — keeps int i 4-byte aligned (Sheet 65)

⚠ Common Mistakes

  • Big local arrays (char buf[10'000'000]) overflow the stack; use malloc or static
  • Assuming stack memory starts zeroed; locals are indeterminate
  • Assuming heap blocks are contiguous with each other

✓ Tips & Best Practices

  • Keep stack usage per function small; warn with -Wstack-usage=N (GCC)
  • Use static for large tables that never change size
  • Check alignment with alignof before using SIMD types

Quick Summary

  • stack — locals, automatic
  • heap — malloc/free
  • data/bss — globals & statics
  • rodata — literals, read-only
