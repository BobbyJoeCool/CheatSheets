Anatomy of a C Program

A C program is a set of declarations and function definitions spread over one or more source files. Execution starts in main. Statements end with a semicolon, blocks are wrapped in braces, and whitespace and indentation don't matter to the compiler. Everything must be declared before use, which is why headers with function prototypes are included at the top of the file.

Rules

  • Two valid main signatures: int main(void) and int main(int argc, char *argv[])
  • Reaching the end of main without return returns 0 (C99+); only main does this
  • argv[0] is the program name; argv[argc] is NULL
  • C is case-sensitive: Main is not main

Annotated Program

#include <stdio.h>        // printf
#include <stdlib.h>       // EXIT_SUCCESS, EXIT_FAILURE

static int square(int n); // prototype: declare before use

int main(int argc, char *argv[])
{
    if (argc < 2) {                          // no argument given
        fprintf(stderr, "usage: %s N\n", argv[0]);
        return EXIT_FAILURE;                 // non-zero = failure
    }
    int n = atoi(argv[1]);                   // "7" -> 7
    printf("%d squared is %d\n", n, square(n));
    return EXIT_SUCCESS;                     // 0
}

static int square(int n)  // definition (file-local)
{
    return n * n;
}

Code Explained

#include / #define — preprocessor lines, no semicolon
static int square(int n); — prototype so main can call it before its definition
argc / argv — count and array of command-line strings
fprintf(stderr, …) — errors go to standard error
EXIT_SUCCESS / EXIT_FAILURE — portable exit codes

⚠ Common Mistakes

  • Calling a function before it's declared. Pre-C99 compilers guessed int f(); modern ones error out. Add a prototype or include the header
  • Forgetting the ; after a struct definition; the error often appears on the next line
  • Treating argv[1] as a number; convert it with strtol (Sheet 20)

✓ Tips & Best Practices

  • Keep main short: parse arguments, call functions, return a status
  • Mark helper functions static so they're private to the file
  • Print usage messages and errors to stderr, results to stdout

Quick Summary

  • int main(void) — program entry point
  • argc / argv — command-line arguments
  • ; ends statements; {} groups them
  • Declare (prototype) before use
