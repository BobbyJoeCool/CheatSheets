Bitwise Operators

Bitwise operators work on the individual bits of integers: AND &, OR |, XOR ^, NOT ~, and shifts << >>. They're used for flags, masks, hardware registers and compact encodings. Use unsigned types: shifting a negative value left, or shifting by the type's width or more, is undefined behavior. C23's <stdbit.h> adds bit-counting helpers.

Notes

  • x << n = x * 2ⁿ (if no overflow)
  • >> on negative signed is implementation-defined
  • ~ flips all bits of the promoted type
  • Bitwise ops bind looser than ==

Masks & Shifts

unsigned a = 0xC;   // 1100
unsigned b = 0xA;   // 1010
a & b;              // 1000  (8)
a | b;              // 1110  (14)
a ^ b;              // 0110  (6)
~a;                 // 0xFFFFFFF3
1u << 4;            // 16
0x80u >> 3;         // 16

unsigned flags = 0;
flags |=  (1u << 3);          // set bit 3
flags &= ~(1u << 3);          // clear bit 3
flags ^=  (1u << 3);          // toggle bit 3
if (flags & (1u << 3)) { }    // test bit 3

if ((flags & MASK) == MASK) { }   // parentheses required!
#include <stdbit.h>                  // (C23)
stdc_count_ones(0xF0u);              // 4

Code Explained

|= with a shifted 1 — set a bit
&= ~mask — clear the bits in mask
^= — toggle
(flags & MASK) == MASK — == binds tighter than &
stdc_count_ones (C23) — population count

⚠ Common Mistakes

  • 1 << 31 on a 32-bit int is UB (shifts into the sign bit). Write 1u << 31
  • if (flags & MASK == MASK) parses as flags & (MASK == MASK); add parentheses
  • ~ on a uint8_t gives an int with high bits set: (uint8_t)~x to keep 8 bits

✓ Tips & Best Practices

  • Name bits with an enum: enum { F_READ = 1u << 0, F_WRITE = 1u << 1 };
  • Use uint32_t/uint64_t for bit fields in protocols so widths are fixed
  • See the separate Bitwise set for deeper tricks

Quick Summary

  • & | ^ ~ << >> — bit operations
  • x |= bit, x &= ~bit, x ^= bit
  • Use unsigned operands
  • Parenthesize & in comparisons
