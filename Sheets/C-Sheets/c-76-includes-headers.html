#include & Header Files

<…> vs "…" · include guards #ifndef · #pragma once · what goes in .h vs .c · extern declarations · -I paths

Header Files

#include pastes another file's text in place. Headers (.h) hold what other files need to know: function prototypes, type definitions, macros and extern declarations. Source files (.c) hold definitions. Every header needs an include guard (or #pragma once) so including it twice in one translation unit doesn't cause redefinition errors.

Notes

  • <file.h> searches system paths first
  • "file.h" searches the including file's dir first
  • #pragma once isn't standard but is universal
  • Each header should compile on its own

A Well-Formed Header

/* stack.h */
#ifndef STACK_H
#define STACK_H

#include <stddef.h>               // only what the header itself needs

typedef struct Stack Stack;       // opaque type

Stack *stack_new(size_t capacity);
void   stack_free(Stack *s);
int    stack_push(Stack *s, int v);
extern int stack_debug;           // declared here, defined in stack.c

#endif /* STACK_H */

/* stack.c */
#include "stack.h"                // own header first
#include <stdlib.h>
int stack_debug = 0;

Code Explained

#ifndef / #define / #endif — include guard
Minimal includes — keep compile times and coupling low
Prototypes + types — the public interface
extern — variable declaration only
Own header first — proves the header is self-contained

What Goes Where

function prototypesfunction definitions

⚠ Common Mistakes

  • Defining variables or non-static functions in a header: multiple definitions at link time
  • Guard names that collide between libraries (UTILS_H); prefix with the project name
  • #include-ing .c files instead of linking them

✓ Tips & Best Practices

  • Include what you use; don't rely on another header pulling it in
  • Forward-declare structs (struct Foo;) instead of including their headers when you only use pointers
  • Use #pragma once *and* guards if you want maximum compatibility

Quick Summary

  • .h — declarations; .c — definitions
  • #ifndef X_H guard or #pragma once
  • "" local, <> system
  • Headers should be self-contained
