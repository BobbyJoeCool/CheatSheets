Sheet 75

Files & Directories (POSIX)

remove · rename · tmpfile · open / read / write / close · stat · opendir / readdir · access

Beyond stdio

Standard C knows little about the file system: it can remove, rename and create a tmpfile, and that's it. Directories, permissions and file metadata come from POSIX (<unistd.h>, <sys/stat.h>, <dirent.h>) on Linux and macOS, or the Win32 API on Windows. POSIX also offers low-level file descriptors (open, read, write, close) underneath FILE *.

Notes

  • File descriptors are ints: 0 stdin, 1 stdout, 2 stderr
  • read/write can transfer fewer bytes than asked
  • fileno(f) gets the fd behind a FILE *
  • C has no portable mkdir or directory listing

Standard + POSIX File Ops

remove("old.txt");                         // delete (C)
rename("draft.txt", "final.txt");          // move/rename (C)
FILE *tmp = tmpfile();                     // auto-deleted on close
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <dirent.h>

int fd = open("data.bin", O_RDONLY);       // POSIX descriptor
char buf[4096];
ssize_t got = read(fd, buf, sizeof buf);   // may be < 4096
close(fd);
struct stat st;
if (stat("data.bin", &st) == 0)
    printf("%lld bytes\n", (long long)st.st_size);
if (access("cfg.ini", R_OK) == 0) { /* readable */ }
mkdir("out", 0755);

DIR *d = opendir(".");
for (struct dirent *e; d && (e = readdir(d)); )
    puts(e->d_name);
if (d) closedir(d);

Code Explained

remove / rename — the only standard file-system calls
open / read / close — unbuffered POSIX I/O
read result — bytes actually read, 0 at EOF, -1 error
stat — size, times, mode
opendir / readdir — list a directory

⚠ Common Mistakes

  • Assuming one read or write call transfers everything; loop until done
  • Checking access() then opening (TOCTOU race); just open and handle the error
  • Forgetting closedir / close; descriptors are a limited resource

✓ Tips & Best Practices

  • Prefer FILE * for text; use descriptors for sockets, pipes and poll
  • On Windows, use _mkdir, FindFirstFile, or a portability library
  • Use mkstemp (POSIX) instead of tmpnam for named temp files

Quick Summary

  • remove / rename / tmpfile — standard
  • open / read / write / close — POSIX fds
  • stat — metadata
  • opendir / readdir — directories
