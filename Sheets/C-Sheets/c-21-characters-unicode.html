Characters & Unicode

<ctype.h> classifies and converts single characters (isdigit, toupper, ...). Their argument must be an unsigned char value or EOF; passing a negative char is UB. C strings are just bytes, so UTF-8 text works with most string functions, but one character may take 1–4 bytes. Wide (wchar_t) and char16_t/char32_t types exist for other encodings.

Notes

  • ctype functions honor the current locale
  • wchar_t is 32-bit on Unix, 16-bit on Windows
  • strlen("é") is 2 in UTF-8
  • u8"" is char8_t[] in C23

ctype & Unicode Literals

#include <ctype.h>
#include <locale.h>

char s[] = "Hello, World 42";
int letters = 0;
for (char *p = s; *p; p++) {
    unsigned char c = (unsigned char)*p;   // required cast
    if (isalpha(c)) letters++;
    *p = (char)toupper(c);                 // "HELLO, WORLD 42"
}

setlocale(LC_ALL, "");          // use the user's locale
wchar_t  *w  = L"wide";         // wchar_t[]
char     *u8 = u8"héllo";       // UTF-8 (char8_t[] in C23)
char16_t *u  = u"utf16";        // <uchar.h>
char32_t *U  = U"utf32";
printf("%zu\n", strlen("héllo"));  // 6 bytes, 5 characters

Code Explained

(unsigned char)*p — avoids UB for bytes ≥ 0x80
toupper — returns the converted int; cast back to char
setlocale — locale-dependent functions start in "C"
L / u8 / u / U — literal prefixes
UTF-8 é = 2 bytes

⚠ Common Mistakes

  • isdigit(c) with a plain char holding é (negative): UB. Cast to unsigned char first
  • Uppercasing UTF-8 byte by byte; toupper only handles single-byte characters
  • Assuming strlen counts characters; it counts bytes

✓ Tips & Best Practices

  • Keep text in UTF-8 internally; convert only at OS boundaries (e.g. Windows APIs)
  • Use a library like ICU or utf8proc for case mapping and normalization
  • Count UTF-8 code points by skipping continuation bytes: (c & 0xC0) != 0x80

Quick Summary

  • isalpha(c), toupper(c) — pass unsigned char
  • UTF-8 works as bytes; length ≠ characters
  • L u8 u U — literal prefixes
  • setlocale(LC_ALL, "") — user locale
