Fixed-Size Arrays

An array is a fixed number of elements of one type stored contiguously. Its size must be known when it's created and can't change. Indexes run from 0 to n - 1, and C never checks them: an out-of-range index silently reads or corrupts other memory. Missing initializer values are set to zero, so = {0} clears a whole array.

Notes

  • Arrays can't be assigned or compared with ==
  • Copy with memcpy or wrap in a struct
  • = {} empty initializer is C23
  • Size from initializer: int a[] = {1, 2, 3};

Creating & Using Arrays

int scores[5];                          // indeterminate (local)
int zeros[100] = {0};                   // all zero
int empty[10] = {};                     // (C23) all zero
int primes[] = {2, 3, 5, 7, 11};        // size 5 from initializer
int sparse[10] = {[2] = 5, [7] = 9};    // designated; rest 0

size_t n = sizeof primes / sizeof primes[0];   // 5
for (size_t i = 0; i < n; i++)
    printf("%d ", primes[i]);           // 2 3 5 7 11

primes[0] = 1;                          // modify
// primes[5] = 13;                      // out of bounds: UB, no error

int copy[5];
memcpy(copy, primes, sizeof primes);    // copy contents
// copy = primes;                       // error: not assignable

Code Explained

{0} — first element 0, the rest default to 0
[2] = 5 — designated initializer (C99)
sizeof a / sizeof a[0] — element count
primes[5] — compiles, corrupts memory
memcpy — the way to copy an array

⚠ Common Mistakes

  • Looping i <= n; the last valid index is n - 1
  • Using sizeof a / sizeof a[0] inside a function on a parameter: gives pointer math, not the length
  • Leaving a local array uninitialized and reading it

✓ Tips & Best Practices

  • Define the size once: enum { N = 64 }; int a[N];
  • Use designated initializers for lookup tables indexed by enum
  • Compile tests with ASan to catch out-of-bounds indexes

Quick Summary

  • T a[N] — fixed size, contiguous
  • Indexes 0 … N-1, unchecked
  • = {0} — zero-initialize
  • Copy with memcpy
