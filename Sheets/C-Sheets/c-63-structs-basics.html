Grouping Data with struct

A struct groups named members of different types into one object. You access members with ., initialize them in order or by name with designated initializers, and copy a whole struct with plain assignment. Structs are values: assignment and passing to functions copy every member. C can't compare structs with ==; compare member by member.

Notes

  • The type name is struct point, not point
  • Unnamed members in initializers are zeroed
  • Structs can contain arrays and other structs
  • Struct copy is shallow: pointers are copied, not targets

Defining & Using Structs

struct point {
    int x;
    int y;
};                                     // semicolon required

struct point a = {3, 4};               // positional
struct point b = {.y = 7, .x = 1};     // designated, any order
struct point c = {0};                  // all zero
struct point d = {};                   // (C23) all zero

a.x = 10;                              // member access
b = a;                                 // copies x and y
printf("(%d, %d)\n", b.x, b.y);        // (10, 4)

struct rect { struct point tl, br; char label[16]; };
struct rect r = { .tl = {0, 0}, .br = {5, 5}, .label = "box" };
int w = r.br.x - r.tl.x;               // 5

bool eq = a.x == b.x && a.y == b.y;    // no a == b in C

Code Explained

struct point { ... }; — defines the type
.y = 7 — designated initializer (C99)
b = a — member-wise copy
r.br.x — nested access
Compare member by member

⚠ Common Mistakes

  • Forgetting the ; after the closing }: errors appear on the next line
  • Comparing with memcmp; padding bytes may differ even when members match
  • Assuming a struct copy duplicates pointed-to data; both copies share it

✓ Tips & Best Practices

  • Use designated initializers; they survive member reordering
  • Write bool point_eq(struct point a, struct point b) helpers
  • Group related parameters into a struct to shorten signatures

Quick Summary

  • struct T { ... }; — define a record
  • .member — access
  • {.x = 1} — designated init
  • Assignment copies; == doesn't exist
