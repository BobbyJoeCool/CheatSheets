Multi-File Programs & Libraries

Real programs split code across files: each .c compiles to an object file, and the linker joins them. Reusable code can be packaged as a static library (.a, copied into each executable) or a shared library (.so on Linux, .dylib on macOS, .dll on Windows) loaded at run time. pkg-config reports the flags needed to use installed libraries.

Notes

  • Static libs are linked only for symbols you use
  • Shared libs need -fPIC when compiling
  • LD_LIBRARY_PATH / DYLD_LIBRARY_PATH find shared libs
  • -Wl,-rpath,... bakes a search path into the binary

Building Libraries

# Separate compilation
cc -c main.c util.c                 # main.o util.o
cc main.o util.o -o app

# Static library
cc -c vec.c map.c
ar rcs libds.a vec.o map.o
cc main.c -L. -lds -o app           # -lds → libds.a

# Shared library
cc -fPIC -c vec.c map.c
cc -shared vec.o map.o -o libds.so          # Linux
cc -dynamiclib vec.o map.o -o libds.dylib   # macOS
cc main.c -L. -lds -Wl,-rpath,'$ORIGIN' -o app

# Installed libraries
cc main.c $(pkg-config --cflags --libs libcurl) -o app

nm -g libds.a                       # exported symbols
ldd ./app        # Linux deps;  otool -L ./app on macOS

Code Explained

ar rcs — create/replace/index an archive
-L. -lds — search . for libds.a/libds.so
-fPIC — position-independent code for shared libs
$ORIGIN — find libs next to the executable (Linux)
pkg-config — correct -I, -L, -l flags

⚠ Common Mistakes

  • Library order: with GNU ld, -lfoo must come after the objects that use it
  • Shared library found at build time but not at run time: set rpath or the loader path
  • Two libraries defining the same global symbol; mark internals static

✓ Tips & Best Practices

  • Hide internal symbols: -fvisibility=hidden plus __attribute__((visibility("default"))) on the API
  • Version shared libraries with sonames (libds.so.1)
  • Let CMake handle library details for anything non-trivial (Sheet 82)

Quick Summary

  • .c → .o → link
  • ar rcs libx.a — static library
  • -shared -fPIC — shared library
  • pkg-config --cflags --libs — dependency flags
