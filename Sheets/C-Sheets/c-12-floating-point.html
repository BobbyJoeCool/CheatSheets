Floating-Point Types

float, double and long double store real numbers in binary floating point (IEEE 754 on almost every platform). double gives about 15–16 significant digits and is the default type of literals like 3.14. Most decimal fractions such as 0.1 can't be stored exactly, so results carry tiny rounding errors. Special values NAN and INFINITY come from <math.h>.

Notes

  • float ≈ 7 digits; double ≈ 15–16
  • 3.14 is double; 3.14f is float
  • Integer division happens first: 1 / 2 is 0
  • Dividing a float by 0.0 gives inf or nan

Floats in Practice

#include <math.h>
#include <float.h>

float  f = 3.14f;           // f suffix = float
double d = 1e-3;            // 0.001
long double ld = 2.5L;

printf("%.17f\n", 0.1);           // 0.10000000000000001
printf("%d\n", 0.1 + 0.2 == 0.3); // 0  (not equal!)
printf("%f\n", 1.0 / 0.0);        // inf
printf("%d\n", !!isnan(NAN));     // 1
printf("%d\n", NAN == NAN);       // 0
printf("%g\n", DBL_EPSILON);      // 2.22045e-16

double a = 0.1 + 0.2, b = 0.3;
if (fabs(a - b) < 1e-9) puts("close enough");
double avg = (double)7 / 2;       // 3.5, not 3

Code Explained

%.17f — shows the stored value isn't exactly 0.1
isnan(x) — the only reliable NaN test; NaN != NaN
DBL_EPSILON — gap between 1.0 and the next double
fabs(a - b) < tol — compare with a tolerance
(double)7 / 2 — cast first to get real division

⚠ Common Mistakes

  • Comparing with == after arithmetic: 0.1 + 0.2 == 0.3 is false. Compare against a tolerance
  • double avg = sum / count; with two ints truncates before converting. Cast one operand
  • Using float for money. Store cents in an integer (int64_t) instead

✓ Tips & Best Practices

  • Default to double; use float only for large arrays or GPU/graphics data
  • Scale your tolerance: fabs(a - b) <= 1e-9 * fmax(fabs(a), fabs(b))
  • Link <math.h> functions with -lm on Linux

Quick Summary

  • double — default floating type
  • 3.0f / 3.0 / 3.0L — literal types
  • Never == computed floats
  • isnan / isinf — special values
