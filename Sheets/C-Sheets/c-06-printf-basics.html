Sheet 06

printf & Basic Output

printf · %d %u %ld %lld %zu · %f %e %g · %c %s %p · %% · puts · putchar · fprintf(stderr, …)

Printing with printf

printf writes formatted text to standard output. Its first argument is a format string; each % conversion specifier in it consumes the next argument and must match that argument's type exactly. puts and putchar are simpler, faster options for plain strings and single characters, and fprintf(stderr, ...) sends output to the error stream.

Notes

  • printf returns the number of characters written (negative on error)
  • puts adds a newline; fputs does not
  • stdout is line-buffered on a terminal
  • float args become double; %f fits both

Output Functions

int n = 42; unsigned u = 7u; long l = 123456789L;
long long ll = 9000000000LL; size_t sz = sizeof(int);
double d = 3.14159; char c = 'A'; const char *s = "text";

printf("%d %i\n", n, n);       // 42 42
printf("%u\n", u);             // 7
printf("%ld %lld\n", l, ll);   // 123456789 9000000000
printf("%zu\n", sz);           // 4
printf("%f\n", d);             // 3.141590
printf("%e\n", d);             // 3.141590e+00
printf("%g\n", d);             // 3.14159
printf("%c %s\n", c, s);       // A text
printf("%p\n", (void *)&n);    // 0x7ffd5c3a8b4c
printf("100%%\n");             // 100%

puts("line");                  // line + newline
putchar('x');                  // x (no newline)

Code Explained

%d / %i — int; same in printf, different in scanf
l, ll, z — length modifiers for long, long long, size_t
%f — fixed, 6 decimals by default; %e scientific; %g shortest
%p — pointer; cast to void * to be strictly correct
%% — a literal percent sign

⚠ Common Mistakes

  • printf("%d", 3.5) or printf("%f", 3): a mismatched type is undefined behavior and prints garbage
  • printf(user_input): if the text contains %, it's read as a format. Use printf("%s", user_input)
  • Using %d for size_t or long; use %zu / %ld. -Wformat warns

✓ Tips & Best Practices

  • Use puts for fixed lines; it's simpler and can't misread %
  • Call fflush(stdout) before a long operation if a prompt has no newline
  • Keep -Wall on: GCC and Clang check printf arguments against the format

Quick Summary

  • printf(fmt, ...) — formatted output
  • %d %u %ld %zu %f %c %s %p — core specifiers
  • puts / putchar — plain output
  • fprintf(stderr, ...) — errors
