C11 Threads

C11 added a portable threading API in <threads.h>: thrd_create starts a thread, thrd_join waits for it, mtx_t mutexes protect shared data, cnd_t condition variables let threads wait for events, and call_once runs initialization exactly once. Support is optional: glibc 2.28+, musl and MSVC 2022 provide it, but macOS doesn't, so many projects still use pthreads.

Notes

  • __STDC_NO_THREADS__ defined → not available
  • Thread functions return int
  • Return codes: thrd_success, thrd_error, …
  • thread_local gives per-thread variables

Threads + Mutex

#include <threads.h>
#include <stdio.h>

static long counter = 0;
static mtx_t lock;
int worker(void *arg) {
    int n = *(int *)arg;
    for (int i = 0; i < n; i++) {
        mtx_lock(&lock);
        counter++;                   // protected
        mtx_unlock(&lock);
    }
    return 0;
}
int main(void) {
    mtx_init(&lock, mtx_plain);
    thrd_t t[4];  int n = 100000;
    for (int i = 0; i < 4; i++) thrd_create(&t[i], worker, &n);
    for (int i = 0; i < 4; i++) thrd_join(t[i], NULL);
    printf("%ld\n", counter);        // 400000
    mtx_destroy(&lock);
}

Code Explained

int worker(void *arg) — required thread function signature
mtx_lock / mtx_unlock — critical section
mtx_init(&lock, mtx_plain) — plain (non-recursive) mutex
thrd_create(&t, fn, arg) — start a thread
thrd_join — wait; second arg receives the result

⚠ Common Mistakes

  • Incrementing a shared counter without a lock: lost updates (data race = UB)
  • Passing the address of a loop variable that changes before the thread reads it
  • Forgetting to join or detach; resources leak

✓ Tips & Best Practices

  • Wrap threading behind your own small API to switch between C11 and pthreads
  • Use _Atomic counters for simple shared counts (Sheet 93)
  • Test with -fsanitize=thread to find races
