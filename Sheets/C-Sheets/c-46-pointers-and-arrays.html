Arrays Are Not Pointers

In most expressions an array name decays to a pointer to its first element, which is why you can pass arrays to functions expecting pointers. But an array is not a pointer: sizeof on an array gives the whole array's size, &arr has type "pointer to array", and arrays can't be assigned. Once passed to a function, only the pointer remains.

No decay when used with

  • sizeof arr — size of the whole array
  • &arr — pointer to the whole array
  • String literal initializing a char array
  • typeof(arr) (C23)

Decay in Action

int arr[10];
int *p = arr;                  // decay: &arr[0]

printf("%zu\n", sizeof arr);   // 40
printf("%zu\n", sizeof p);     // 8

void f(int a[]) {              // really int *a
    printf("%zu\n", sizeof a); // 8, not 40!
}

int (*whole)[10] = &arr;       // pointer to array of 10
printf("%p %p\n", (void *)arr, (void *)&arr);  // same address
arr + 1;                       // +4 bytes  (next int)
&arr + 1;                      // +40 bytes (past the array)

int *ptrs[10];                 // array of 10 pointers
int (*rows)[10];               // pointer to arrays of 10

// arr = p;                    // error: arrays aren't assignable
#define COUNT(a) (sizeof(a) / sizeof((a)[0]))

Code Explained

int *p = arr; — implicit &arr[0]
sizeof a in f — the parameter is a pointer
&arr — same address, different type
int *ptrs[10] vs int (*rows)[10] — [] binds before *
COUNT(a) — works only on real arrays

⚠ Common Mistakes

  • Computing an array parameter's length with sizeof; always pass the length
  • Using the COUNT macro on a pointer: it silently returns sizeof(ptr)/sizeof(*ptr)
  • Returning a local array from a function; it's destroyed on return

✓ Tips & Best Practices

  • Clang warns -Wsizeof-array-argument; GCC -Wsizeof-pointer-div
  • Wrap array + length in a struct if you pass them together often
  • Use cdecl.org to decode complex declarations

Quick Summary

  • Arrays decay to &arr[0] in expressions
  • sizeof sees the whole array only before decay
  • &arr — pointer to whole array
  • Pass lengths explicitly
