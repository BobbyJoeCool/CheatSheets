Binary I/O

fread and fwrite move raw bytes between memory and a file, counted in items of a given size; they return how many full items were transferred. fseek moves the file position, ftell reports it and rewind goes back to the start. Writing a struct directly is fast but ties the file to your compiler's padding, type sizes and endianness.

Notes

  • Open with "rb" / "wb" for binary on Windows
  • Short count → check feof vs ferror
  • ftell returns long; use fseeko/ftello for >2 GB on 32-bit
  • Switching read ↔ write needs fseek/fflush between

fread, fwrite, fseek

typedef struct { uint32_t id; float score; } Rec;
Rec recs[3] = {{1, 9.5f}, {2, 7.0f}, {3, 8.25f}};

FILE *f = fopen("recs.bin", "wb");
size_t w = fwrite(recs, sizeof recs[0], 3, f);    // 3 on success
fclose(f);

f = fopen("recs.bin", "rb");
fseek(f, 0, SEEK_END);
long bytes = ftell(f);                            // 24
rewind(f);                                        // back to start

Rec r;
fseek(f, 2 * (long)sizeof r, SEEK_SET);           // jump to record 2
if (fread(&r, sizeof r, 1, f) == 1)
    printf("%u %.2f\n", r.id, r.score);           // 3 8.25

uint8_t b[4];                // portable: decode little-endian
uint32_t v = b[0] | b[1] << 8 | b[2] << 16 | (uint32_t)b[3] << 24;

Code Explained

fwrite(ptr, size, count, f) — returns items written
fseek(f, 0, SEEK_END) + ftell — file size
SEEK_SET — offset from the start
fread(...) == 1 — got one whole record
Assemble bytes manually to control endianness

fseek Origins

⚠ Common Mistakes

  • fread(buf, 1, n, f) vs fread(buf, n, 1, f): the second returns 0 or 1, hiding partial reads
  • Reading binary files in text mode on Windows: \r\n and 0x1A bytes get mangled
  • Writing structs with pointers to a file; the addresses are meaningless when read back

✓ Tips & Best Practices

  • Use fread(buf, 1, n, f) when you want a byte count back
  • Define file formats as explicit byte layouts with fixed-width fields
  • Add a magic number and version field at the start of every binary format

Quick Summary

  • fread / fwrite — items, not bytes
  • fseek / ftell / rewind — position
  • "rb" / "wb" — binary mode
  • Raw structs aren't portable
