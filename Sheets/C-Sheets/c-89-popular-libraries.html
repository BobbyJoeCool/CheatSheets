Widely Used C Libraries

C's standard library is small, so most projects lean on a few well-known libraries: cJSON for JSON, libcurl for HTTP, SQLite for an embedded database, zlib for compression, and SDL or raylib for graphics, input and audio. Install them with your package manager and get build flags from pkg-config or CMake's find_package.

Notes

  • macOS: brew install cjson curl sqlite zlib sdl2 raylib
  • Debian: apt install libcjson-dev libcurl4-openssl-dev ...
  • Most return error codes and need explicit cleanup
  • Single-file libs (SQLite amalgamation, stb_*) can be vendored

cJSON, libcurl, SQLite

cJSON *root = cJSON_Parse("{\"name\":\"Ana\",\"age\":31}");
const cJSON *name = cJSON_GetObjectItem(root, "name");
if (cJSON_IsString(name)) puts(name->valuestring);   // Ana
cJSON_Delete(root);
CURL *h = curl_easy_init();
curl_easy_setopt(h, CURLOPT_URL, "https://example.com");
CURLcode rc = curl_easy_perform(h);         // body → stdout by default
if (rc != CURLE_OK) fprintf(stderr, "%s\n", curl_easy_strerror(rc));
curl_easy_cleanup(h);
sqlite3 *db;  sqlite3_stmt *st;
sqlite3_open("app.db", &db);
sqlite3_prepare_v2(db, "SELECT name FROM users WHERE id = ?",
                   -1, &st, NULL);
sqlite3_bind_int(st, 1, 42);
while (sqlite3_step(st) == SQLITE_ROW)
    puts((const char *)sqlite3_column_text(st, 0));
sqlite3_finalize(st);  sqlite3_close(db);

Code Explained

cJSON_Parse / cJSON_Delete — parse tree, free it
curl_easy_* — one-request API
sqlite3_prepare_v2 + ? — parameterized query
sqlite3_step loop — one row at a time
Headers: <cjson/cJSON.h>, <curl/curl.h>, <sqlite3.h>

⚠ Common Mistakes

  • Building SQL with snprintf and user input: SQL injection. Always bind parameters
  • Forgetting cJSON_Delete / curl_easy_cleanup / sqlite3_finalize: leaks
  • Not checking return codes (CURLcode, SQLITE_OK)

✓ Tips & Best Practices

  • Use pkg-config --cflags --libs libcurl sqlite3 for portable flags
  • Vendor single-file libraries into third_party/ with their license
  • Call curl_global_init once at startup in multithreaded programs
