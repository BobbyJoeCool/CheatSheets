Trees & Heaps

A binary search tree (BST) keeps smaller keys in the left subtree and larger ones in the right, giving O(log n) search when balanced (O(n) when not). Recursion fits trees naturally: insert, search, traverse and free are each a few lines. A binary heap is a complete tree stored in an array, where each parent is ≤ (min-heap) its children; it powers priority queues.

Notes

  • In-order traversal of a BST yields sorted order
  • Free a tree in post-order
  • Heap: children of i are 2i+1, 2i+2
  • Parent of i is (i-1)/2

BST & Heap Basics

typedef struct Tree { int key; struct Tree *left, *right; } Tree;

Tree *insert(Tree *t, int key) {
    if (!t) {
        t = calloc(1, sizeof *t);
        if (t) t->key = key;
        return t;
    }
    if (key < t->key)      t->left  = insert(t->left, key);
    else if (key > t->key) t->right = insert(t->right, key);
    return t;
}
void in_order(const Tree *t) {
    if (!t) return;
    in_order(t->left); printf("%d ", t->key); in_order(t->right);
}
void tree_free(Tree *t) {
    if (!t) return;
    tree_free(t->left); tree_free(t->right); free(t);
}
void sift_up(int *h, size_t i) {                 // min-heap insert step
    while (i > 0 && h[(i - 1) / 2] > h[i]) {
        size_t p = (i - 1) / 2;
        int t = h[p]; h[p] = h[i]; h[i] = t;  i = p;
    }
}

Code Explained

insert returns the (possibly new) subtree root
Duplicates ignored — neither < nor >
in_order — left, node, right → sorted output
tree_free — children before parent
sift_up — swap with parent until order holds

⚠ Common Mistakes

  • Inserting sorted data into a plain BST: it degrades into a linked list (O(n))
  • Freeing a node before its children; the child pointers are lost
  • Deep recursion on unbalanced trees can overflow the stack

✓ Tips & Best Practices

  • Use a balanced tree (red-black, AVL) or a library when input may be sorted
  • Store heaps in arrays: no pointers, cache-friendly
  • Write insert/delete to return the new subtree root; it removes parent bookkeeping

Quick Summary

  • BST — left < node < right
  • In-order = sorted
  • Heap — array, parent (i-1)/2
  • Free in post-order
