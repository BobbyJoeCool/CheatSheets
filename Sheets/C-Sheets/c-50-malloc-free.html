malloc & free

malloc · free · p = malloc(n * sizeof *p) · check for NULL · don't cast in C · free(NULL) is safe · set to NULL after free

Heap Allocation

malloc(n) reserves n bytes on the heap and returns a void * to them, or NULL if it fails. The memory is uninitialized and stays allocated until you pass the same pointer to free. Every successful malloc needs exactly one matching free. Size allocations from the pointer itself, sizeof *p, so they stay correct if the type changes.

Notes

  • malloc(0) may return NULL or a unique pointer
  • free(NULL) does nothing
  • Don't cast malloc in C
  • Memory is returned to the OS only sometimes; that's normal

malloc / free

#include <stdlib.h>

int *nums = malloc(100 * sizeof *nums);   // 100 ints
if (nums == NULL) {
    perror("malloc");
    return -1;
}
for (size_t i = 0; i < 100; i++) nums[i] = (int)i;
free(nums);
nums = NULL;                 // avoid dangling use

struct point *pt = malloc(sizeof *pt);    // one struct
if (!pt) return -1;
*pt = (struct point){ .x = 1, .y = 2 };
free(pt);

char *copy = malloc(strlen(src) + 1);     // +1 for '\0'
if (copy) strcpy(copy, src);

Code Explained

100 * sizeof *nums — size follows the pointer type
if (nums == NULL) — always check
nums = NULL — later misuse becomes a clean crash
strlen(src) + 1 — room for the terminator

⚠ Common Mistakes

  • malloc(n) for n ints instead of n * sizeof(int): allocates bytes, not elements
  • malloc(strlen(s)) without + 1 for the '\0'
  • Losing the only pointer to a block (reassigning it) before freeing: a leak

✓ Tips & Best Practices

  • Write T *p = malloc(n * sizeof *p); every time
  • Pair allocation and free in the same module, ideally the same function
  • On Linux, malloc rarely returns NULL (overcommit), but check anyway for portability

Quick Summary

  • malloc(n * sizeof *p) — allocate
  • Check for NULL
  • free(p); p = NULL; — release
  • One free per allocation
