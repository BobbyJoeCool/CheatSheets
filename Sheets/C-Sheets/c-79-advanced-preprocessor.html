Advanced Preprocessor

# stringify · ## token paste · X-macros · __FILE__ / __LINE__ / __func__ · __DATE__ · #embed (C23) · gcc -E to debug

Preprocessor Tricks

Two operators work only inside macros: # turns an argument into a string literal (stringizing) and ## glues tokens together (token pasting). The preprocessor also predefines macros like __FILE__ and __LINE__, and the compiler provides __func__. X-macros keep parallel lists (enum values and their names) in sync. C23 adds #embed to include a binary file as data.

Notes

  • Arguments of #/## aren't macro-expanded first
  • Use two-level macros to expand then stringize
  • __func__ is a variable, not a macro
  • #embed is new; check compiler support

#, ##, X-macros, #embed

#define STR(x)   #x
#define XSTR(x)  STR(x)                 // expand first, then stringize
#define VERSION  3
STR(VERSION);                           // "VERSION"
XSTR(VERSION);                          // "3"

#define CAT(a, b) a##b
int CAT(var, 1) = 10;                   // int var1 = 10;
#define CHECK(e) if (!(e)) fprintf(stderr, "%s:%d %s: failed: %s\n", \
                                   __FILE__, __LINE__, __func__, #e)
#define COLORS X(RED) X(GREEN) X(BLUE)  // X-macro list
#define X(name) name,
enum color { COLORS };                  // RED, GREEN, BLUE
#undef X
#define X(name) #name,
const char *color_names[] = { COLORS }; // "RED", "GREEN", "BLUE"
#undef X

static const unsigned char icon[] = {
#embed "icon.png"                       // (C23) file bytes as initializer
};

Code Explained

#x — argument text as a string
XSTR — extra level so VERSION expands to 3
a##b — build identifiers
#e in CHECK — print the failed expression
X-macro — one list, many expansions

⚠ Common Mistakes

  • Expecting STR(VERSION) to give "3"; # doesn't expand its argument. Use a helper macro
  • Using __DATE__/__TIME__ in reproducible builds; output changes every build
  • Pasting tokens that don't form a valid token: CAT(+, +) style errors

✓ Tips & Best Practices

  • Use X-macros for enum ↔ string tables and command dispatch
  • Write ASSERT-style macros with #e, __FILE__, __LINE__ for clear failures
  • Debug macro expansion with cc -E and search for your line
