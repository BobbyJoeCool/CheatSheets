for Loops

for (init; condition; step) body puts loop setup, test and update in one line. The condition is checked before each iteration, so the body may run zero times. Since C99 you can declare the loop variable in init, which limits its scope to the loop. Any of the three parts can be empty; for (;;) is an infinite loop.

Notes

  • Loop variable declared in init dies after the loop
  • Use size_t for array indexes
  • Half-open ranges: i < n, not i <= n
  • break / continue work as usual (Sheet 32)

Loop Patterns

for (int i = 0; i < 5; i++)
    printf("%d ", i);                 // 0 1 2 3 4

int arr[] = {3, 1, 4, 1, 5};
size_t n = sizeof arr / sizeof arr[0];
for (size_t i = 0; i < n; i++) sum += arr[i];

for (size_t i = n; i-- > 0; )         // backward, safe with size_t
    printf("%d ", arr[i]);            // 5 1 4 1 3

for (int i = 0, j = 9; i < j; i++, j--) { }  // two variables

for (char *p = s; *p; p++) { }        // walk a string

for (int r = 0; r < 3; r++)           // nested
    for (int c = 0; c < 3; c++)
        grid[r][c] = 0;

for (;;) { if (done()) break; }       // infinite until break

Code Explained

int i = 0 in init — scoped to the loop (C99)
sizeof arr / sizeof arr[0] — element count
i-- > 0 — test then decrement; stops after index 0
*p — loop until the \0 terminator
for (;;) — no condition = always true

Common Ranges

HeaderVisits

⚠ Common Mistakes

  • for (size_t i = n - 1; i >= 0; i--) never ends: size_t can't go negative
  • for (i = 0; i <= n; i++) on an array of n reads one past the end
  • for (...); with a trailing semicolon runs an empty body

✓ Tips & Best Practices

  • Compute strlen or n once, not in the condition
  • Keep the loop variable local to the loop unless you need it afterwards
  • Use a while loop when there's no natural counter

Quick Summary

  • for (init; cond; step) — counted loop
  • Declare i in init (C99)
  • i < n — half-open range
  • for (;;) — infinite loop
