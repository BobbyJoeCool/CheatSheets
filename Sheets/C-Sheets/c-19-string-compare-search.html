Comparing & Searching

<string.h> compares and searches null-terminated strings. strcmp returns negative, zero or positive (not just -1/0/1) depending on byte order. The search functions return a pointer into the original string, or NULL when nothing is found, so the position is p - s. strtok splits a string by modifying it in place, which makes it unsafe for literals and for nested or threaded use.

Notes

  • strcmp compares bytes; not locale-aware
  • strcasecmp (POSIX) ignores case; _stricmp on MSVC
  • strtok_r (POSIX) / strtok_s are re-entrant
  • Always check search results for NULL

Compare, Find, Split

#include <string.h>

strcmp("apple", "apple");    // 0
strcmp("apple", "banana");   // < 0
strncmp("prefix_x", "prefix", 6);  // 0

const char *s = "key=value;x=1";
char *eq  = strchr(s, '=');  // first '=' → "=value;x=1"
char *lst = strrchr(s, '='); // last  '=' → "=1"
char *sub = strstr(s, "val");// "value;x=1"
size_t pos = (size_t)(eq - s);       // 3
size_t n = strcspn(s, ";=");         // 3 (chars before ; or =)

char line[] = "a,b,,c";              // must be writable
for (char *t = strtok(line, ","); t; t = strtok(NULL, ","))
    printf("[%s]", t);               // [a][b][c]

Code Explained

strcmp(a, b) == 0 — equality test
strchr / strrchr — first / last occurrence of a char
eq - s — pointer difference gives the index
strcspn — length of prefix with none of the given chars
strtok — skips empty fields and writes \0 into line

⚠ Common Mistakes

  • if (strcmp(a, b)) reads as "if equal" but means "if different"; write == 0 or != 0
  • Calling strtok on a string literal: it writes into it, which is UB
  • Using the result of strchr without checking for NULL

✓ Tips & Best Practices

  • Strip a trailing newline: s[strcspn(s, "\n")] = '\0';
  • Check a prefix: strncmp(s, "http", 4) == 0
  • Use strsep (BSD/glibc) or manual strchr loops when you need empty fields

Quick Summary

  • strcmp(a, b) == 0 — equal
  • strchr / strstr — return pointer or NULL
  • p - s — index of a match
  • strtok — modifies input; not re-entrant
