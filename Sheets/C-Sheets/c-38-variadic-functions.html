Variadic Functions

A function declared with ... accepts a variable number of extra arguments, like printf. Inside, <stdarg.h> macros walk them: va_start, va_arg(ap, type), va_end. The function can't tell how many arguments there are or their types, so it needs a count, a sentinel or a format string. Extra arguments undergo default promotions: char/short → int, float → double.

Notes

  • Need at least one named parameter (pre-C23)
  • C23: int f(...) and va_start(ap) allowed
  • Wrong va_arg type is UB
  • vprintf family accepts a va_list

Writing a Variadic Function

#include <stdarg.h>

int sum(int count, ...) {
    va_list ap;
    va_start(ap, count);            // C23: va_start(ap)
    int total = 0;
    for (int i = 0; i < count; i++)
        total += va_arg(ap, int);   // fetch next as int
    va_end(ap);
    return total;
}
sum(3, 10, 20, 30);                 // 60

void log_msg(const char *fmt, ...) {      // forward to vfprintf
    va_list ap;
    va_start(ap, fmt);
    fprintf(stderr, "[log] ");
    vfprintf(stderr, fmt, ap);
    va_end(ap);
}

Code Explained

count — tells the function how many args follow
va_arg(ap, int) — type must match the promoted argument
va_end — required before returning
vfprintf — the va_list version of fprintf

⚠ Common Mistakes

  • va_arg(ap, char) or va_arg(ap, float): those types are never passed; use int / double
  • Passing NULL as a sentinel where NULL is 0 (an int); cast it: (char *)NULL
  • Reusing a va_list after passing it to vprintf; make a va_copy first

✓ Tips & Best Practices

  • Add __attribute__((format(printf, 1, 2))) so GCC/Clang check your printf-style wrappers
  • Prefer arrays + count over varargs for non-format APIs; they're type-checked
  • Variadic macros (__VA_ARGS__) are covered in Sheet 77

Quick Summary

  • ... — variable arguments
  • va_start / va_arg / va_end
  • Caller must signal count or types
  • vfprintf — forward a va_list
