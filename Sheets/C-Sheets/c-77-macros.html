Macros

#define creates a macro: the preprocessor replaces its name with text before compilation. Object-like macros name constants; function-like macros take arguments. Because it's pure text substitution, every argument and the whole body need parentheses, arguments with side effects may be evaluated more than once, and multi-statement macros need the do { ... } while (0) wrapper.

Notes

  • No space between name and ( in function-like macros
  • Macros ignore scope; #undef removes one
  • __VA_ARGS__ — variadic macros (C99)
  • Prefer static inline functions when possible

Writing Safe Macros

#define PI        3.14159265358979
#define BUF_SIZE  256
#define SQUARE(x) ((x) * (x))            // parenthesize everything
#define BAD_SQ(x) x * x
BAD_SQ(1 + 2);                           // 1 + 2 * 1 + 2 = 5 (!)
SQUARE(1 + 2);                           // 9

#define MAX(a, b) ((a) > (b) ? (a) : (b))
int i = 5;  MAX(i++, 3);                 // i++ runs twice (!)

#define SWAP(a, b) do { typeof(a) t_ = (a); (a) = (b); (b) = t_; } while (0)
if (x > y) SWAP(x, y); else puts("ok"); // works thanks to do/while

#define LOG(fmt, ...) fprintf(stderr, "[%s:%d] " fmt "\n", \
                              __FILE__, __LINE__, __VA_ARGS__)
LOG("x=%d", x);                          // [main.c:12] x=5
#undef BUF_SIZE

Code Explained

((x) * (x)) — parens around args and body
BAD_SQ(1 + 2) — expands to 1 + 2 * 1 + 2
MAX(i++, 3) — argument evaluated twice
do { } while (0) — acts like one statement, needs ;
\ — continue a macro on the next line

⚠ Common Mistakes

  • Missing parentheses: #define DOUBLE(x) x + x then DOUBLE(3) * 2 gives 9
  • Passing i++ or a function call to a macro that uses its argument twice
  • A trailing ; in the macro body: #define N 10; breaks int a[N];

✓ Tips & Best Practices

  • Name macros in ALL_CAPS so readers know text substitution is happening
  • Use enum/constexpr for constants and static inline for small functions
  • See the expansion with cc -E file.c

Quick Summary

  • #define NAME value — text replacement
  • Parenthesize args and body
  • do { } while (0) — statement macros
  • __VA_ARGS__ — variadic macros
