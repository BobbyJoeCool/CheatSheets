Sheet 07

printf Format Specifiers

width %5d · precision %.2f / %.3s · flags - + 0 # space · %*d · %x %X %o · PRId64 / PRIu32 · mismatched specifier = UB

Controlling the Format

A full conversion specification is %[flags][width][.precision][length]type. Width sets a minimum field size, precision sets decimals for floats or a maximum length for strings, and flags control alignment, signs and padding. Fixed-width types like int64_t need the macros from <inttypes.h>, because their underlying type differs between platforms.

Notes

  • A value wider than the width is never truncated
  • * takes the width or precision from an argument (int)
  • %x / %o expect unsigned values
  • Wrong specifier for the argument type is undefined behavior

Width, Precision & Flags

#include <inttypes.h>

printf("[%5d]\n", 42);        // [   42]
printf("[%-5d]\n", 42);       // [42   ]
printf("[%05d]\n", 42);       // [00042]
printf("[%+d]\n", 42);        // [+42]
printf("[% d]\n", 42);        // [ 42]
printf("[%.2f]\n", 3.14159);  // [3.14]
printf("[%8.3f]\n", 3.14159); // [   3.142]
printf("[%.3s]\n", "abcdef"); // [abc]
printf("[%*d]\n", 6, 42);     // [    42]
printf("[%.*f]\n", 1, 2.25);  // [2.2] (round-half-even here)
printf("%x %X %o\n", 255u, 255u, 8u);  // ff FF 10
printf("%#x %#o\n", 255u, 8u);         // 0xff 010
printf("%08.3f\n", -3.5);              // -003.500

int64_t big = 9007199254740993;
uint32_t id = 42;
printf("%" PRId64 " %" PRIu32 "\n", big, id);

Code Explained

%5d — right-align in 5 columns; %-5d left-align
%05d — pad with zeros instead of spaces
%.2f — 2 digits after the point; %.3s — at most 3 chars
%#x — add 0x prefix (0 for octal)
PRId64 — string macro, e.g. "lld" or "ld"; joined by adjacent-literal concatenation

⚠ Common Mistakes

  • printf("%ld", int64_value): int64_t is long on 64-bit Linux but long long on Windows and macOS. Use PRId64
  • Expecting %.3s to pad. It only truncates; combine with width: %-10.3s
  • Passing a negative int to %x; cast to unsigned first

✓ Tips & Best Practices

  • Align table output with fixed widths: printf("%-12s %8.2f\n", name, price)
  • Use %*s with a computed width for indentation: printf("%*s", depth * 2, "")
  • In C23, %b prints binary on newer libcs (glibc 2.35+); don't rely on it for portable code

Quick Summary

  • %[flags][width][.prec][len]type — full spec
  • %-10s / %08.2f — align and pad
  • %*d — width from an argument
  • PRId64 — portable fixed-width printing
