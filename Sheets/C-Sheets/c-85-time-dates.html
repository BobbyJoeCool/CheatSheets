Time & Dates

<time.h> · time_t / time · clock / CLOCKS_PER_SEC · difftime · localtime / gmtime · strftime · timespec_get

Dates & Times

<time.h> measures time two ways. Calendar time (time_t, usually seconds since 1970-01-01 UTC) is converted to broken-down struct tm fields with localtime or gmtime and formatted with strftime. Processor time from clock() measures CPU use. For precise wall-clock intervals, use timespec_get (C11) or POSIX clock_gettime.

Notes

  • tm_year is years since 1900; tm_mon is 0–11
  • localtime returns a shared static buffer
  • Use localtime_r / gmtime_r (POSIX) in threads
  • mktime normalizes out-of-range fields

Getting & Formatting Time

#include <time.h>

time_t now = time(NULL);                     // seconds since epoch
struct tm local = *localtime(&now);          // copy the static result
printf("%d-%02d-%02d\n", local.tm_year + 1900, local.tm_mon + 1, local.tm_mday);

char buf[64];
strftime(buf, sizeof buf, "%Y-%m-%d %H:%M:%S", &local);   // 2026-10-12 09:41:07
strftime(buf, sizeof buf, "%A, %B %d", &local);           // Monday, October 12

struct tm due = local;
due.tm_mday += 30;                           // 30 days later
mktime(&due);                                // normalizes month/year

clock_t c0 = clock();  work();
double cpu = (double)(clock() - c0) / CLOCKS_PER_SEC;

struct timespec a, b;                        // wall-clock timing
timespec_get(&a, TIME_UTC);  work();  timespec_get(&b, TIME_UTC);
double secs = (b.tv_sec - a.tv_sec) + (b.tv_nsec - a.tv_nsec) / 1e9;

Code Explained

time(NULL) — current calendar time
*localtime(&now) — copy before another call overwrites it
strftime — format with % codes
mktime — fixes tm_mday = 42 into the next month
clock() — CPU time; timespec_get — wall time

⚠ Common Mistakes

  • Printing tm_year directly (126) or tm_mon (9 for October)
  • Using clock() to time code that sleeps or waits on I/O; it measures CPU time only
  • Keeping the pointer from localtime and calling it again; the first result changes

✓ Tips & Best Practices

  • Store and compute in UTC (gmtime), convert to local only for display
  • Use ISO 8601 (%Y-%m-%dT%H:%M:%SZ) for logs and files
  • Use clock_gettime(CLOCK_MONOTONIC, ...) (POSIX) for benchmarks

Quick Summary

  • time_t + localtime/gmtime → struct tm
  • strftime — format dates
  • mktime — normalize / convert back
  • clock (CPU) vs timespec_get (wall)
