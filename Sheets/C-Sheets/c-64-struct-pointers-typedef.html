Pointers to Structs & typedef

Most structs are passed around by pointer to avoid copying and to let functions modify them. p->m is shorthand for (*p).m. A typedef gives the struct a one-word name. A struct can contain a pointer to its own type, which is how lists and trees are built. Compound literals create unnamed struct values inline.

Notes

  • typedef struct Node Node; lets you use Node before its body
  • Self-reference needs the tag: struct Node *next
  • Returning small structs by value is fine
  • Compound literals are lvalues with block lifetime

->, typedef, Compound Literals

typedef struct {
    char   name[32];
    double balance;
} Account;

void deposit(Account *acct, double amt) {
    acct->balance += amt;            // same as (*acct).balance
}

Account a = {.name = "Ana", .balance = 10.0};
deposit(&a, 5.0);                    // a.balance == 15.0

typedef struct Node Node;            // forward typedef
struct Node { int value; Node *next; };

typedef struct { int x, y; } Point;
Point add(Point p, Point q) { return (Point){p.x + q.x, p.y + q.y}; }
Point r = add((Point){1, 2}, (Point){3, 4});   // {4, 6}

draw(&(Point){.x = 5, .y = 5});      // address of a temporary

Code Explained

typedef struct { ... } Account; — anonymous struct with a name
acct->balance — member via pointer
typedef struct Node Node; — then Node *next works inside
(Point){...} — compound literal (C99)
&(Point){...} — pass a temporary by pointer

⚠ Common Mistakes

  • Using . on a pointer (p.x) or -> on a value (s->x)
  • Returning &(Point){...} from a function: the compound literal dies at block end
  • typedef hiding a pointer (typedef struct X *XPtr;) makes const and ownership confusing

✓ Tips & Best Practices

  • Pass const T * for large read-only structs
  • Keep the struct tag and typedef name the same: typedef struct Node Node;
  • Use compound literals for one-off arguments and resetting: *p = (T){0};

Quick Summary

  • p->m == (*p).m
  • typedef struct {...} T; — short name
  • Self-reference via struct Tag *
  • (T){...} — compound literal
