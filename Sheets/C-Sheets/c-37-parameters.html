Parameters & Pass-by-Value

everything is pass-by-value · pointer params to modify caller · arrays decay to pointers · const params · int a[static 10] · multiple results via pointers

Passing Arguments

C passes every argument by value: the function gets a copy. To let a function change the caller's variable, pass its address and write through the pointer. Arrays are the apparent exception: an array argument decays to a pointer to its first element, so the function can modify the elements but no longer knows the length. Pass the length separately.

Notes

  • int a[] parameter = int *a
  • const pointer params promise read-only
  • Structs are copied by value (can be big)
  • int a[static 10] — at least 10 elements

Value, Pointer, Array

void no_effect(int x)  { x = 99; }        // changes the copy
void set(int *x)       { *x = 99; }       // changes caller's var

void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }

void fill(int *a, size_t n, int v) {      // array + length
    for (size_t i = 0; i < n; i++) a[i] = v;
}
int sum(const int a[], size_t n);         // read-only array

void divmod(int a, int b, int *q, int *r) { *q = a / b; *r = a % b; }

int n = 1;
no_effect(n);  set(&n);                   // n == 99
int x = 1, y = 2;  swap(&x, &y);          // x == 2, y == 1
int arr[5];    fill(arr, 5, 0);
int q, r;      divmod(17, 5, &q, &r);     // q 3, r 2

Code Explained

&n — pass the address so the callee can write to n
*x = 99 — write through the pointer
size_t n — arrays don't carry their length
const int a[] — callee can't modify elements
int *q, int *r — return several results

⚠ Common Mistakes

  • Using sizeof a on an array parameter: it's sizeof(int *), not the array size
  • Passing a large struct by value in a hot loop; pass const struct S * instead
  • Forgetting & with scanf("%d", n); it needs the address &n

✓ Tips & Best Practices

  • Put output parameters last and inputs first
  • Use const on every pointer the function only reads
  • Return small structs by value; it's clear and compilers optimize it well

Quick Summary

  • Everything is pass-by-value
  • Pass &x to let a function modify x
  • Arrays decay to pointers; pass the length
  • const T * — read-only access
