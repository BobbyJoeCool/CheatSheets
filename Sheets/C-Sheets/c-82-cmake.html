CMake

CMake generates build files (Makefiles, Ninja, Xcode, Visual Studio) from a portable CMakeLists.txt. Modern CMake is target-based: you create executables and libraries with add_executable / add_library, then attach include paths, flags and dependencies to each target with target_* commands. Builds happen out of source in a separate directory.

Notes

  • PUBLIC / PRIVATE / INTERFACE control propagation
  • Use -G Ninja for fast builds
  • CMAKE_EXPORT_COMPILE_COMMANDS helps clangd
  • find_package locates installed libraries

CMakeLists.txt

cmake_minimum_required(VERSION 3.20)
project(inventory LANGUAGES C)

set(CMAKE_C_STANDARD 17)
set(CMAKE_C_STANDARD_REQUIRED ON)
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)

add_library(ds STATIC src/vec.c src/map.c)
target_include_directories(ds PUBLIC include)
target_compile_options(ds PRIVATE -Wall -Wextra)

add_executable(app src/main.c)
target_link_libraries(app PRIVATE ds m)

enable_testing()
add_executable(test_vec tests/test_vec.c)
target_link_libraries(test_vec PRIVATE ds)
add_test(NAME vec COMMAND test_vec)

Code Explained

CMAKE_C_STANDARD 17 — adds -std=c17 (or equivalent)
add_library(ds STATIC ...) — a library target
PUBLIC include — users of ds get the include path too
target_link_libraries(app ... m) — link ds and libm
add_test — run with ctest

Command Line

CommandDoes
cmake -B buildconfigure into build/
cmake -B build -G Ninjause Ninja
cmake -B build -DCMAKE_BUILD_TYPE=Releaseoptimized build
cmake --build build -jbuild
ctest --test-dir buildrun tests

Visibility Keywords

KeywordApplies to
PRIVATEthis target only
PUBLICthis target and its users
INTERFACEusers only (header-only libs)

⚠ Common Mistakes

  • Using global include_directories() / add_compile_options() instead of target_* commands
  • Building in the source directory; use -B build
  • Forgetting CMAKE_BUILD_TYPE with single-config generators, getting an unoptimized build

✓ Tips & Best Practices

  • Symlink build/compile_commands.json to the project root for editors
  • Use find_package(CURL REQUIRED) then link CURL::libcurl
  • Add sanitizer presets in CMakePresets.json

Quick Summary

  • add_executable / add_library
  • target_* — per-target settings
  • cmake -B build && cmake --build build
  • ctest — run registered tests
