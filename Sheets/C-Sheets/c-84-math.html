Math

<math.h> · sqrt pow fabs · floor ceil round · fmod · trig & M_PI (not standard) · link with -lm · <tgmath.h> / <complex.h>

Math Functions

<math.h> provides floating-point math: roots, powers, rounding, trigonometry, logarithms and classification. Functions take and return double, with f and l suffixed versions for float and long double (sqrtf, sqrtl). <tgmath.h> picks the right version automatically. On Linux you must link the math library with -lm.

Notes

  • Trig functions use radians
  • M_PI isn't standard C (POSIX/MSVC need a define)
  • Domain errors return NaN (e.g. sqrt(-1))
  • <complex.h> adds double complex

Common Calls

#include <math.h>              // link with -lm on Linux

sqrt(16.0);         // 4.0
pow(2.0, 10);       // 1024.0
cbrt(27.0);         // 3.0
hypot(3, 4);        // 5.0
fabs(-2.5);         // 2.5   (abs() is for ints!)
floor(-2.5);        // -3.0
ceil(-2.5);         // -2.0
round(-2.5);        // -3.0  (half away from zero)
trunc(-2.7);        // -2.0
fmod(7.5, 2.0);     // 1.5
exp(1.0);           // 2.718281828...
log(M_E);           // 1.0   natural log
log10(1000);        // 3.0
sin(M_PI / 2);      // 1.0   (radians)
atan2(1.0, 1.0);    // 0.785398 (π/4)

Code Explained

pow(x, y) — x to the power y
fabs — floating absolute value
round vs trunc — nearest vs toward zero
fmod — floating remainder
atan2(y, x) — angle with the correct quadrant

⚠ Common Mistakes

  • Linker error undefined reference to 'sqrt': add -lm after your sources
  • Using abs() on a double; it converts to int. Use fabs
  • Passing degrees to sin; convert: deg * M_PI / 180

✓ Tips & Best Practices

  • Define _USE_MATH_DEFINES before <math.h> on MSVC for M_PI
  • Use hypot(x, y) instead of sqrt(x*x + y*y); it avoids overflow
  • Use float versions (sinf) in float-heavy code to avoid conversions

Quick Summary

  • sqrt pow fabs floor ceil round
  • Radians for trig
  • -lm on Linux
  • f/l suffixes or <tgmath.h>
