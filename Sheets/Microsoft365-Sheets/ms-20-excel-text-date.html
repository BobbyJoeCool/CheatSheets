Clean Text and Do Date Math

Modern text functions split and join without nested FIND / MID: TEXTSPLIT, TEXTBEFORE, TEXTAFTER, TEXTJOIN. The REGEX functions match patterns. Dates are numbers (days since 1900), so subtracting gives days, and EOMONTH, EDATE, NETWORKDAYS handle month ends, adding months and business days.

Notes

  • TEXT(value, format) turns numbers / dates into formatted text
  • Dates are serial numbers: =B2-A2 is days between; format the result as Number
  • TRIM removes extra spaces; CLEAN removes non-printing characters
  • REGEX functions are in Microsoft 365 (2024 onward), including the web
  • DATEDIF is undocumented but works: "y", "m", "d", "ym"

Text & Date Formulas

=TEXTSPLIT("Smith, Jane", ", ")         # Smith | Jane (spills)
=TEXTBEFORE(A2, "@")                    # jane  (from jane@acme.com)
=TEXTAFTER(A2, "@")                     # acme.com
=TEXTJOIN(", ", TRUE, B2:B10)           # join, skipping blanks
=PROPER(TRIM(A2))                       # "  jANE  smith" → Jane Smith
=TEXT(B2, "$#,##0.00")   =TEXT(C2, "mmm d, yyyy")
=REGEXTEST(A2, "^\d{5}$")               # TRUE for 5-digit zip
=REGEXEXTRACT(A2, "\d{3}-\d{4}")        # 555-1234
=REGEXREPLACE(A2, "\s+", " ")           # collapse whitespace
=EOMONTH(TODAY(), 0)                    # last day of this month
=EDATE(A2, 3)                           # 3 months later
=NETWORKDAYS(A2, B2, Holidays)          # business days
=DATEDIF(Birth, TODAY(), "y")           # age in years
=WORKDAY(TODAY(), 10)                   # 10 business days out

Code Explained

TEXTSPLIT spills across columns; a second delimiter argument splits into rows too
TEXTBEFORE / TEXTAFTER take an instance number: TEXTAFTER(A2, "/", -1) = after the last slash
In REGEX patterns \d digit, \s space, ^ $ start / end; the functions are case-sensitive by default
EOMONTH(date, -1)+1 gives the first day of the current month

⚠ Common Mistakes

  • Dates stored as text (left-aligned); date math fails. Use DATEVALUE or Text to Columns
  • Joining a date with & and getting 46085; wrap it in TEXT(date, "m/d/yyyy")
  • Using TEXT for numbers you still need to calculate with; it returns text

✓ Tips & Best Practices

  • Use TEXTBEFORE / TEXTAFTER instead of LEFT + FIND chains
  • Keep a Holidays table and pass it to NETWORKDAYS / WORKDAY
  • Test regex patterns on a few cells with REGEXTEST before replacing
