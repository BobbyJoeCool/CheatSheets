Summaries Without Formulas

A PivotTable summarises thousands of rows by dragging fields into Rows, Columns, Values and Filters. It groups dates by month or quarter, shows values as percentages, and drills into detail with a double-click. PivotCharts chart the result; Recommended Charts suggests a chart for any range; sparklines are tiny charts inside cells.

Notes

  • Source should be a table (sheet 16) so Refresh picks up new rows
  • Refresh: Alt+F5, Refresh All: Ctrl+Alt+F5 (Mac: PivotTable Analyze / Data › Refresh All)
  • Right-click a value › Show Values As › % of Grand Total, Running Total, Rank…
  • Double-click any value to see the rows behind it on a new sheet
  • Insert chart from selection: ⌥F1 / Alt+F1 embedded, F11 new chart sheet

Automate It

  • Data › Queries & Connections › Properties › Refresh data when opening the file
  • One-line VBA event: Private Sub Workbook_Open(): ThisWorkbook.RefreshAll: End Sub

Pivot & Chart Keys

Insert › PivotTable › From Table/Range     # Alt N V T (Win)
Drag fields:  Rows = Region   Columns = Year   Values = Sum of Amount

Analyze › Refresh  / Alt+F5        # refresh this PivotTable
Data › Refresh All / Ctrl+Alt+F5   # refresh all
⌥F1                / Alt+F1        # chart from selection (same sheet)
F11                / F11           # chart on its own sheet

=GETPIVOTDATA("Amount", $A$3, "Region", "West")  # read a pivot cell
Right-click date › Group › Months + Years        # date grouping

Code Explained

Clicking a pivot cell while writing a formula creates GETPIVOTDATA; turn it off in PivotTable › Options
Date grouping usually happens automatically; regroup via right-click › Group
Calculated fields (PivotTable Analyze › Fields, Items & Sets) work on sums, not row by row
PivotCharts follow the pivot's filters and slicers

⚠ Common Mistakes

  • Building pivots on a fixed range, then adding rows that never appear; use a table
  • Forgetting to refresh; pivots don't update when source data changes
  • Count instead of Sum because the column has text or blanks; fix the data and pick Sum

✓ Tips & Best Practices

  • Use Tabular layout + Repeat All Item Labels for pivots you'll copy elsewhere
  • Add a Timeline slicer for date filtering
  • Turn off GETPIVOTDATA if you want plain cell references
