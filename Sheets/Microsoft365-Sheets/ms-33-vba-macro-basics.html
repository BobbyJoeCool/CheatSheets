Record It Once, Replay Forever

A macro is a recorded or written list of steps in VBA (Visual Basic for Applications). The macro recorder writes the code for you while you click; the VBA editor lets you clean it up. Macros live in macro-enabled files (.xlsm, .docm) or in the Personal Macro Workbook, which makes them available in every Excel file on your machine.

Notes

  • Turn on the Developer tab: Options › Customize Ribbon › tick Developer
  • Use Relative References before recording if the macro should work from any cell
  • Store in Personal Macro Workbook for macros you want everywhere (Excel)
  • Run: Developer › Macros (⌥F8 / Alt+F8), a shortcut key, a button or the QAT
  • Macros from the internet are blocked by default; unblock only trusted files

A Recorded Macro, Cleaned Up

Sub FormatReport()
    ' Bold header, autofit, freeze top row, number format
    With ActiveSheet
        .Rows(1).Font.Bold = True
        .Columns("A:F").AutoFit
        .Range("D2:D1000").NumberFormat = "$#,##0.00"
    End With
    ActiveWindow.FreezePanes = False
    Range("A2").Select
    ActiveWindow.FreezePanes = True
    MsgBox "Report formatted", vbInformation
End Sub

Code Explained

The recorder writes every scroll and select; delete lines like ActiveWindow.ScrollRow
With … End With saves repeating the object name
Lines starting with ' are comments
Run from the editor with F5; step line by line with F8

Other Suites

  • Google Workspace — Extensions › Macros › Record; saved as Apps Script (JavaScript)
  • Apple iWork — no macro recorder; AppleScript / Shortcuts automate iWork

Platform Differences

  • Windows — full VBA, recorder in Word, Excel, PowerPoint (editor only), Outlook
  • Mac — VBA works; some Windows-only objects (ActiveX, some file APIs) fail
  • Web — VBA doesn't run; use Office Scripts (sheet 35)

⚠ Common Mistakes

  • Saving as .xlsx and losing all macros without warning (well, one warning)
  • Recording with absolute references, so the macro always edits the same cells
  • Enabling macros on unknown files; macros can run any code

✓ Tips & Best Practices

  • Record, then read the code; it's the fastest way to learn the object model
  • Assign macros to QAT buttons for one-click access
  • Add Application.ScreenUpdating = False at the start of long macros for speed

Quick Summary

  • Developer › Record Macro — record steps
  • Alt+F11 — VBA editor
  • .xlsm / .docm — macro-enabled files
  • Personal Macro Workbook — macros everywhere
