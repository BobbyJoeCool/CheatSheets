Sheet 04

Templates & Themes

File › New · personal templates folder · .dotx .xltx .potx · document themes · Normal.dotm · Book.xltx

Start From Something Good

A template is a file you start from instead of a blank page: styles, layouts, headers, formulas and placeholder text already set up. Save your own as .dotx, .xltx or .potx and they appear under File › New › Personal. A theme is a set of colours, fonts and effects that styles, charts and SmartArt follow, so changing the theme restyles the whole file at once.

Notes

  • Personal templates folder (Win): set in File › Options › Save › Default personal templates location
  • Mac: templates saved via File › Save as Template go to the My Templates folder automatically
  • Normal.dotm is Word's blank-document template; changing its styles changes every new doc
  • Excel uses Book.xltx in the XLSTART folder as the default new workbook if it exists
  • Design › Themes (Word), Page Layout › Themes (Excel), Design (PowerPoint)

Automate It

  • Save a styled file as a template once instead of copying last month's file and deleting content
  • Organization templates in SharePoint show up under File › New for everyone

Make Your Own Template

  1. Build a file with your styles, theme, headers / footers, logo and placeholder text
  2. Delete real content but keep placeholders like "[Client name]"
  3. File › Save As › file type Word / Excel / PowerPoint Template
  4. Windows: save into your personal templates folder (set the folder path first)
  5. Next time: File › New › Personal (Win) or File › New from Template (Mac)
  6. To change it later, open the template file itself (right-click › Open, not double-click)

  • Mac — My Templates folder is automatic
  • Web — use built-in templates; open a template from OneDrive and save a copy

⚠ Common Mistakes

  • Copying an old report and deleting content; hidden comments and tracked changes come along
  • Double-clicking a template to edit it; that opens a new copy, not the template
  • Hard-coding colours instead of theme colours, so a theme change misses half the file

✓ Tips & Best Practices

  • Use theme fonts (+Headings / +Body) in styles so the font changes in one place
  • Keep one master template per document type and version it in OneDrive
  • In Excel templates, lock formula cells and protect the sheet before saving
