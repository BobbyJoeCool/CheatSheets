AI and Python Inside the Apps

Copilot drafts and rewrites in Word, analyses and builds formulas in Excel, turns documents into decks in PowerPoint, and summarises threads in Outlook. The COPILOT() function brings AI into a cell. Python in Excel (=PY()) runs Python with pandas and charts in the cloud, returning results to the grid. Both are tools to check, not to trust blindly.

Notes

  • Copilot needs a qualifying plan or add-in; Personal / Family include some features
  • Good prompts name the source, task, format and audience
  • =COPILOT("Classify this feedback as positive / negative", B2) works row by row
  • Python in Excel: type =PY( or Formulas › Insert Python; reference cells with xl("A1:D100", headers=True)
  • Python runs in Microsoft's cloud; results can be values or Python objects

Prompts, COPILOT() and Python

# Copilot prompts (chat pane)
Word:  "Summarize this report in 5 bullets for an executive, plain language"
Excel: "Add a column that flags orders over $1,000 placed on weekends"
PPT:   "Create a 6-slide deck from /Q3-plan.docx with speaker notes"
Outlook: "Summarize this thread and list who owes what by when"

# COPILOT function in a cell
=COPILOT("Extract the city from this address", A2)
=COPILOT("Sentiment: positive, neutral or negative", B2:B50)

# Python in Excel (type =PY then Ctrl+Enter / ⌘↩ to run)
df = xl("Sales[#All]", headers=True)
df.groupby("Region")["Amount"].sum().sort_values(ascending=False)

Code Explained

Point Copilot at a file with /filename so it uses your content, not general knowledge
COPILOT() results recalculate; paste as values when you need them fixed
In Python cells, xl() reads ranges or tables into pandas DataFrames
Python output can spill as values or stay as an object you click to inspect

⚠ Common Mistakes

  • Pasting AI-generated numbers into reports without tracing them to the data
  • Vague prompts ("make this better"); say what better means
  • Using COPILOT() for things a normal formula does exactly (sums, lookups)

✓ Tips & Best Practices

  • Ask Copilot to explain a formula before you trust it
  • Keep data in tables with clear headers; AI and Python both work better
