Rules, Quick Steps & Templates

Rules · Quick Steps · My Templates · signatures · Quick Parts in mail · automatic replies · conditional formatting

Let Outlook Do the Filing

Rules act on mail automatically as it arrives (move newsletters, flag mail from your boss). Quick Steps bundle several actions into one click or shortcut (forward to team, categorise and archive). Templates and Quick Parts store messages you send repeatedly. Automatic replies handle out-of-office.

Notes

  • Create a rule from a message: right-click › Rules › Create Rule
  • Server-side rules run even when Outlook is closed; client-only rules don't
  • Quick Steps (classic Win / new Outlook): Home › Quick Steps; assign Ctrl+Shift+1…9
  • My Templates (web / new): compose › ⋯ › My Templates; classic: Save as .oft
  • Automatic replies: File › Automatic Replies (classic) or Settings › Mail › Automatic replies

Automate It

  • Rules for anything you file the same way more than twice
  • Quick Steps for multi-step actions like "reply with template, categorise, archive"

Set Up a Rule and a Quick Step

  1. Right-click a newsletter › Rules › Create Rule
  2. Condition: From sender; Action: Move to folder "Newsletters"
  3. Tick Run this rule now on messages already in the current folder
  4. Home › Quick Steps › Create New; name it "To Team"
  5. Add actions: Forward to team@…, Categorise "Shared", Move to Archive
  6. Pick a shortcut key (Ctrl+Shift+1) and Finish

  • New Outlook / Web — server rules, My Templates, Quick Steps
  • Mac — rules, signatures; no Quick Steps

⚠ Common Mistakes

  • Rules that run "on this computer only", so mail isn't sorted on your phone
  • Overlapping rules without Stop processing more rules, moving mail twice
  • Out-of-office without an end date, still replying a month later

✓ Tips & Best Practices

  • Order rules most specific first
  • Export rules (classic: Manage Rules › Options › Export) as a backup
  • Set separate internal and external automatic replies
