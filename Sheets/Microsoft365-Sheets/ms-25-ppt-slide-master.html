Slide Master & Layouts

Slide Master view · layouts & placeholders · theme fonts / colors · footers & slide numbers · .potx · Reset

Design Once, Every Slide Follows

The Slide Master is the top slide that sets fonts, colours, background and logo for the whole deck. Under it sit layouts (Title, Title and Content, Two Content…), each with placeholders for text and pictures. Fix the design in the master and every slide updates; fix it on individual slides and you're fixing it forever.

Notes

  • Open: View › Slide Master; close with Close Master View
  • Edit the top (master) slide for deck-wide changes; edit a layout for that layout only
  • Insert Placeholder adds picture, chart or text boxes to a custom layout
  • Footers and slide numbers: Insert › Header & Footer › tick Slide number
  • Reset (Home tab) snaps a slide back to its layout after manual edits

Automate It

  • Save the master as a .potx template (sheet 04) so new decks start on-brand
  • Use layouts with picture placeholders so pasted images crop to the right size

Build a Clean Master

  1. View › Slide Master; select the top master slide
  2. Set theme Colors and Fonts (Slide Master tab) instead of formatting text boxes
  3. Add the logo and background to the master; they appear on every layout
  4. Delete layouts you'll never use; rename the rest (right-click › Rename Layout)
  5. Create custom layouts with Insert Placeholder for repeated slide types
  6. Close Master View, then apply layouts with Home › Layout
  7. File › Save As › PowerPoint Template (.potx)

⚠ Common Mistakes

  • Pasting the logo on every slide; it belongs on the master
  • Typing in free text boxes instead of placeholders, so text isn't in the outline or accessibility order
  • Changing fonts slide by slide; change theme fonts once

✓ Tips & Best Practices

  • Hold ⇧ while clicking Normal view (Mac) / the Normal button (Win) to jump into the master
  • Use Reset after pasting slides from another deck to adopt your layouts
  • Keep a hidden "style guide" slide in templates showing approved colours

Quick Summary

  • View › Slide Master — deck-wide design
  • Layouts — reusable slide shapes
  • Reset — back to the layout
  • .potx — save as template
