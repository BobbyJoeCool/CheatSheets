Animations, Morph & Zoom

Morph transition · Animation Pane · triggers · Animation Painter · Summary / Slide / Section Zoom · timing

Motion That Explains

Morph is the most useful transition: duplicate a slide, move or resize things on the copy, and Morph animates the change smoothly. Animations bring objects in, out or along a path; the Animation Pane controls order and timing. Zoom (Insert › Zoom) makes a clickable overview slide that jumps to sections and back.

Notes

  • Morph matches objects by type and content; name them !!logo in the Selection Pane to force a match
  • Animation types: Entrance, Emphasis, Exit, Motion Path
  • Start: On Click, With Previous, After Previous
  • Animation Painter copies an animation to other objects
  • Triggers start an animation when a specific object is clicked

Use Morph

  1. Finish slide A with the objects in their start positions
  2. Duplicate it (⌘D / Ctrl+D) to make slide B
  3. On slide B, move, resize, recolour or rotate the objects
  4. Select slide B › Transitions › Morph
  5. Effect Options › Objects, Words or Characters
  6. Play from slide A (⇧⌘↩ / Shift+F5) to preview

  • Google Workspace — Insert › Animation; transitions; no Morph or Zoom

Platform Differences

  • Windows — Morph, Zoom, triggers, motion paths
  • Mac — Morph and Zoom supported
  • Web — plays Morph and Zoom; editing animations is limited

⚠ Common Mistakes

  • Animating every bullet on every slide; it slows the talk
  • Morph between slides with differently named objects, so things fade instead of move
  • Long durations; most effects read best at 0.3–0.5 s

✓ Tips & Best Practices

  • Use Morph for "zoom in on part of a chart" by scaling the chart up on slide B
  • Prefix shared object names with !! to make Morph pair them
  • Use Summary Zoom as a non-linear menu slide for Q&A

Quick Summary

  • Morph — duplicate, change, transition
  • Animation Pane — order and timing
  • Triggers — click an object to animate
  • Zoom — jump to sections
