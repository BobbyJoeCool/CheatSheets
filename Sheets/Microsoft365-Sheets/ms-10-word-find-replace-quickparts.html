Find & Replace, Quick Parts & AutoText

Advanced Find · wildcards · ^p ^t ^& · replace formatting · Quick Parts · Building Blocks · AutoText · AutoCorrect

Never Type the Same Thing Twice

Advanced Find & Replace can match special characters (^p paragraph marks, ^t tabs), formatting, and with Use wildcards on, patterns similar to regular expressions. Quick Parts / AutoText store reusable blocks (a signature, a disclaimer, a table) and AutoCorrect expands short codes into long text as you type.

Notes

  • Replace dialog: ⌃H (Mac Word) / Ctrl+H; click More for special characters and formatting
  • Replace ^p^p with ^p to remove double blank lines
  • Wildcards: < > word start / end, [0-9]{3}, (…) groups, \1 in Replace
  • Save a block: select it › Insert › Quick Parts › Save Selection to Quick Part Gallery
  • AutoText: type the entry name then press F3 to insert it

Automate It

  • AutoText / Quick Parts for repeated paragraphs and tables
  • AutoCorrect entry addr1 → full mailing address (plain or formatted)

Find & Replace Codes

^p      # paragraph mark          ^t   # tab
^l      # manual line break       ^m   # manual page break
^w      # any whitespace          ^?   # any character
^#      # any digit               ^$   # any letter
^&      # (Replace) the found text

# With "Use wildcards" ticked
<(Mr)>           # whole word Mr
[0-9]{3}-[0-9]{4}   # 555-1234
(<*>) (<*>)      → \2 \1    # swap two words
[A-Z]{2,}        # runs of capitals (acronyms)

Code Explained

Codes like ^p change when wildcards are on: use ^13 for paragraph marks in wildcard mode
^& in the Replace box reinserts what was found, e.g. find TODO replace **^&** with Bold format
Format button in the dialog searches for or replaces styles, fonts and highlighting
Wildcard * matches any run of characters, so <*> is "a whole word"

Other Suites

  • Google Workspace — Edit › Find and replace › Match using regular expressions (true regex)
  • Apple iWork — Pages Find & Replace with options; no regex; Text Replacements in macOS settings

Platform Differences

  • Windows — full Advanced Find, wildcards, Quick Parts, AutoText
  • Mac — same features; Quick Parts via Insert › AutoText
  • Web — basic Find & Replace, no wildcards or Quick Parts

⚠ Common Mistakes

  • Running Replace All without testing Find Next first; check a few hits before replacing
  • Forgetting that Use wildcards stays ticked; normal searches then fail on ( or *
  • Saving Quick Parts to Building Blocks.dotx without saving it when Word asks on exit

✓ Tips & Best Practices

  • Replace formatting only: leave both boxes empty, set Format › Font on each
  • Pick AutoCorrect codes that are never real words (;sig, zaddr)
  • Highlight all matches: Find › Reading Highlight › Highlight All
