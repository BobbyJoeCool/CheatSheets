Record Your Cleanup Once

Power Query (Data › Get Data) imports from files, folders, databases and the web, then records every cleanup step you click: remove columns, split, change types, unpivot, merge. Next month, drop in the new file and click Refresh All: every step replays. It replaces copy-paste-and-fix routines with a repeatable recipe.

Notes

  • Each click adds an Applied Step; select a step to see the data at that point
  • From Folder combines every file in a folder with the same layout
  • Merge = join (like XLOOKUP); Append = stack tables
  • Unpivot Columns turns month columns into Month + Value rows
  • Close & Load To › Only Create Connection for staging queries

Automate It

  • Power Query replaces manual monthly imports: point it at a folder, Refresh All each month
  • Refresh on open (Query Properties) so reports are always current

Typical Steps (M code)

let
    Source   = Excel.Workbook(File.Contents("C:\Data\sales.xlsx")),
    Sheet    = Source{[Item="Sales",Kind="Sheet"]}[Data],
    Headers  = Table.PromoteHeaders(Sheet),
    Types    = Table.TransformColumnTypes(Headers,
                 {{"Date", type date}, {"Amount", type number}}),
    NoBlanks = Table.SelectRows(Types, each [Amount] <> null),
    Unpivot  = Table.UnpivotOtherColumns(NoBlanks, {"Region"}, "Month", "Value"),
    Trimmed  = Table.TransformColumns(Unpivot, {{"Region", Text.Trim}})
in
    Trimmed

Code Explained

You rarely type M; every ribbon click writes a step like these
Each step references the previous one by name, so steps can be renamed and reordered
each [Amount] <> null is a row filter; [Column] refers to the current row
Change the source path in one place (Source step or a parameter) for a new file

Other Suites

  • Google Workspace — no Power Query; use IMPORTRANGE, QUERY, Apps Script or Connected Sheets
  • Apple iWork — no equivalent in Numbers; prepare data elsewhere or script it

Platform Differences

  • Windows — full editor, every connector
  • Mac — Power Query editor available in M365, fewer connectors
  • Web — refresh and some editing; limited sources

⚠ Common Mistakes

  • Changing types too late, after steps that already depended on text values
  • Hard-coded file paths that break on a coworker's PC; use a parameter or SharePoint path
  • Loading every staging query to a sheet; use Connection Only

✓ Tips & Best Practices

  • Name steps (right-click › Rename) so the recipe reads like a checklist
  • Use From Folder for monthly files; new files are picked up on refresh
  • Check the column quality bar (View › Column quality) for errors and empties

Quick Summary

  • Get Data — import and record steps
  • Merge / Append — join / stack
  • Unpivot — columns to rows
  • Refresh All — replay everything
