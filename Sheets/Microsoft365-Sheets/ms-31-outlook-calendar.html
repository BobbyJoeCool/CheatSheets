Calendar & Scheduling

Scheduling Assistant · room finder · shared calendars · time zones · Bookings · view shortcuts · drag mail to calendar

Find Time Without Email Ping-Pong

The Scheduling Assistant shows attendees' free / busy side by side so you pick a slot that works. Shared calendars let you see a team's availability. Bookings gives people a page to book time with you. Dragging an email onto the calendar turns it into an appointment with the message attached.

Notes

  • New event: ⌘N in Calendar / Ctrl+Shift+Q (meeting request) on Windows
  • Add a second time zone: Settings › Calendar › Time zones
  • Open a coworker's calendar: Add calendar › From directory
  • Teams meeting toggle adds a join link to any event
  • Bookings (business plans) or a personal booking page for 1:1s

Automate It

  • A Bookings page instead of trading three emails per meeting
  • Scheduling Assistant suggestions (Suggested times) instead of manual comparison

Calendar Shortcuts

⌘2              / Ctrl+2          # go to calendar
⌘N              / Ctrl+Shift+Q    # new meeting / event
⌃⌘1 … ⌃⌘4       / Ctrl+Alt+1 … 4  # day / work week / week / month
⌘T              / Alt+Home or T   # today
→ ←             / Alt+↓ ↑         # next / previous period (varies)
⌘O              / Ctrl+O          # open selected event
⌫               / Ctrl+D          # delete event

# Natural entry in a new event's time box (web / new Outlook)
tomorrow 3pm     next fri 9am    in 2 weeks

Code Explained

Classic Windows and new Outlook use slightly different view keys; hover buttons for hints
Ctrl+Shift+Q creates a meeting request with attendees; Ctrl+Shift+A an appointment
Natural-language dates work in the date fields of new Outlook and the web
Drag a message onto the Calendar icon to make an event from it

Other Suites

⚠ Common Mistakes

  • Booking over people's Tentative and Out of office blocks without checking the assistant
  • Sharing your calendar with full details when free / busy would do
  • Creating separate events for each time zone instead of using the time-zone picker

✓ Tips & Best Practices

  • Use "End appointments and meetings early" to get 5–10 minutes between meetings
  • Colour events with the same categories as your email
  • Block focus time as recurring Busy events so others see it

Quick Summary
