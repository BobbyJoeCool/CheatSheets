Format With Styles, Not by Hand

A style is a named bundle of formatting (font, size, spacing, numbering). Apply Heading 1–3 and Normal instead of bolding and resizing text by hand, and you get a Navigation pane, an automatic table of contents, and the ability to restyle the whole document by changing one style. Update to Match Selection copies hand formatting back into the style.

Notes

  • Styles pane: Home › Styles launcher, or ⌥⌘⇧S (Mac) / Ctrl+Alt+Shift+S (Win)
  • Right-click a style › Modify to change it everywhere it's used
  • Update Heading 1 to Match Selection turns one hand-formatted heading into the rule
  • Reveal Formatting (⇧F1) shows exactly what's applied to the selected text
  • Paragraph styles apply to whole paragraphs; character styles to selected words only

Style Shortcuts

⌥⌘1 2 3      / Ctrl+Alt+1 2 3  # Heading 1, 2, 3
⇧⌘N          / Ctrl+Shift+N    # Normal style
⌘⇧L          / Ctrl+Shift+L    # List Bullet style
⌃Space       / Ctrl+Space      # clear character formatting
⌘⌥⇧S         / Ctrl+Alt+Shift+S # Styles pane
⇧⌘S          / Ctrl+Shift+S    # Apply Styles box (type a name)
⇧F1          / Shift+F1        # Reveal Formatting
⌘[  ⌘]       / Ctrl+[  Ctrl+]  # shrink / grow font 1 pt
⇧⌘D          / Ctrl+Shift+D    # double underline
⇧⌘K          / Ctrl+Shift+K    # small caps

Code Explained

Heading shortcuts make the text a heading and add it to the Navigation pane / TOC
Ctrl+Space removes character formatting; Home › Clear All Formatting (Aa eraser) removes both
The Apply Styles box (Ctrl+Shift+S) lets you type any style name, including custom ones
On Mac Word, ⇧⌘S is Save As in some setups; check Tools › Customize Keyboard

Other Suites

  • Google Workspace — ⌘⌥1–6 headings, Format › Paragraph styles › Update to match
  • Apple iWork — Pages paragraph styles in the Format sidebar; Update button when a style is changed

Platform Differences

  • Windows — full Styles pane, Style Inspector, Manage Styles
  • Mac — Styles pane; no Style Inspector
  • Web — gallery + Modify; fewer options, no Reveal Formatting

⚠ Common Mistakes

  • Making headings by bolding Normal text; they don't appear in the TOC or Navigation pane
  • Turning on Automatically update; one stray edit restyles every matching paragraph
  • Pressing Enter twice for spacing instead of setting Space After in the style

✓ Tips & Best Practices

  • Set paragraph spacing (Before / After) in styles and never use blank lines for space
  • Use Style sets (Design tab) to try a new look without touching each style
  • Save finished styles to a template (sheet 04) so every new doc starts right
