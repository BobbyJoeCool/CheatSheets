Sheet 11

Review & Collaboration

Track Changes ⌘⇧E / Ctrl+Shift+E · accept / reject · comments · Compare / Combine · Restrict Editing · Editor · Read Aloud

Edit Other People's Documents Safely

Track Changes records every insertion, deletion and format change with the author's name so the owner can accept or reject each one. Comments hold questions without changing text. Compare builds a tracked-changes view of two versions when someone edited without tracking. Restrict Editing limits a file to comments or form filling.

Notes

  • Markup view: Simple Markup (clean, red bars) or All Markup (every change shown)
  • Accept / reject all at once: Review › Accept › Accept All Changes
  • Lock tracking: Track Changes › Lock Tracking with a password
  • Editor (Review tab) checks spelling, grammar, clarity and conciseness
  • Read Aloud (Review tab; Ctrl+Alt+Space on Windows) is a quick proofreading pass

Review Shortcuts

⇧⌘E         / Ctrl+Shift+E     # Track Changes on / off
⌥⌘A         / Ctrl+Alt+M       # new comment
—           / Alt R A C        # accept and move to next (KeyTips)
—           / Alt R J          # reject (KeyTips)
F7          / F7               # spelling & grammar
Review tab  / Ctrl+Alt+Space   # Read Aloud
⇧⌘G         / Ctrl+Shift+G     # word count

Review › Compare › Compare…     # two versions → tracked changes
Review › Compare › Combine…     # merge several reviewers' copies

Code Explained

Turn tracking on before you edit; changes made before that aren't recorded
Reply to comments and Resolve them instead of deleting, so the thread stays visible
Compare creates a third document; neither original is changed
File › Info › Inspect Document removes leftover comments and tracked changes before sending

Other Suites

  • Google Workspace — Suggesting mode (⌘⌥⇧X), comments ⌘⌥M, Tools › Compare documents
  • Apple iWork — Pages Edit › Track Changes, comments; no compare tool

Platform Differences

  • Windows — Compare, Combine, Lock Tracking, Restrict Editing
  • Mac — same; Restrict Editing under Review › Protect
  • Web — tracking and comments; Compare is desktop only

⚠ Common Mistakes

  • Sending a "clean" file that still contains tracked changes hidden by No Markup view
  • Deleting comments instead of resolving; you lose the discussion history
  • Treating Mark as Final as protection; anyone can click Edit Anyway

✓ Tips & Best Practices

  • Run Inspect Document before sending outside your organization
  • Set your name in Options › General so changes aren't attributed to "Author"
  • Use Compare when a reviewer forgot Track Changes instead of reading both side by side

Quick Summary

  • ⇧⌘E / Ctrl+Shift+E — Track Changes
  • Accept / Reject — per change or all
  • Compare — tracked diff of two files
  • Inspect Document — strip hidden data
