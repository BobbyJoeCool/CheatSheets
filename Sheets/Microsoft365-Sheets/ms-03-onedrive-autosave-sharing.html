Sheet 03

OneDrive, AutoSave & Sharing

AutoSave · Version History · share links · co-authoring · @mentions · Files On-Demand · SharePoint

Save Once, Never Again

When a file lives in OneDrive (personal) or SharePoint / Teams (work), AutoSave saves every change, Version History keeps older copies, and several people can edit at the same time (co-authoring). Sharing sends a link instead of an attachment, so everyone works on one copy. Files On-Demand shows all your cloud files in Finder / File Explorer without downloading them.

Notes

  • AutoSave toggle sits top-left of the window; it's off for local files
  • Version History: File › Info › Version History (Win) or the file name dropdown
  • @mention someone in a comment to email them a link to that spot
  • Link types: Anyone, People in your organization, Specific people
  • Co-authors' cursors show as coloured flags; their changes appear within seconds

Share a File the Right Way

  1. Save the file to OneDrive or SharePoint (File › Save As › pick a cloud location)
  2. Click Share (top right) and choose who the link works for
  3. Set Can edit or Can view; add an expiry date or block download if needed
  4. Type names to send, or Copy link to paste into chat / email
  5. Use Manage Access later to see and remove everyone who has a link
  6. Restore a bad edit from Version History › Restore

Other Suites

  • Google Workspace — everything autosaves in Drive; Share button and File › Version history the same way
  • Apple iWork — iCloud Drive + Share › Collaborate; File › Revert To › Browse All Versions

Platform Differences

  • Windows — OneDrive in File Explorer, Files On-Demand
  • Mac — OneDrive app in Finder (File Provider); same on-demand idea
  • Web — always AutoSave; version history from the file name menu

⚠ Common Mistakes

  • Emailing attachments back and forth and merging edits by hand; share one link instead
  • Using Anyone links for sensitive files; they work for whoever the link is forwarded to
  • Turning AutoSave off to "experiment" and forgetting it; use Save a Copy first instead

✓ Tips & Best Practices

  • Name important points in history by saving a copy (File › Save a Copy) before big changes
  • Use @mentions in comments to assign tasks; Word and Excel can turn them into tasks
  • Mark folders Always keep on this device when you'll be offline

Quick Summary

  • AutoSave — cloud files only
  • Version History — restore any earlier copy
  • Share — one link, set view / edit
  • @mention — notify a person in a comment
