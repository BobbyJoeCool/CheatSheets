Teams, OneNote & Loop

Teams search ⌘E / Ctrl+E · mute ⌘⇧M / Ctrl+Shift+M · chat vs channels · meeting recap · OneNote tags · Loop components

The Rest of the Suite

Teams is chat, channels and meetings; most time is saved with search, mute / camera shortcuts and meeting recaps. OneNote is the free-form notebook: tags turn notes into searchable to-dos. Loop components are live tables, lists and checklists you paste into a chat, email or doc; everyone edits the same copy.

Notes

  • Teams search box: ⌘E / Ctrl+E; / commands are mostly gone, use search
  • Channels for topic history; chats for quick back-and-forth
  • Meeting recap: recording, transcript, notes and (with Copilot) a summary
  • OneNote tags: ⌘1 / Ctrl+1 To Do, then search tags with Find Tags
  • Loop components work in Teams chat, Outlook mail, Whiteboard and the Loop app

Teams & OneNote Keys

# Teams
⌘E          / Ctrl+E          # search
⌘⇧M         / Ctrl+Shift+M    # mute / unmute
⌘⇧O         / Ctrl+Shift+O    # camera on / off
⌘⇧K         / Ctrl+Shift+K    # raise / lower hand
⌘⇧X         / Ctrl+Shift+X    # expand compose box
⌘.          / Ctrl+.          # show all shortcuts

# OneNote
⌘1          / Ctrl+1          # To Do tag
⌘2  ⌘3      / Ctrl+2  Ctrl+3  # Important / Question tags
⌘N          / Ctrl+N          # new page
⌘⌥F / ⌘F    / Ctrl+E          # search all notebooks

Code Explained

Hold Space while muted in a Teams meeting to talk temporarily (if enabled)
Ctrl+. lists every Teams shortcut for your platform
OneNote tags are searchable across notebooks: Home › Find Tags (Windows)
A Loop table pasted into chat stays in sync wherever else it's pasted

⚠ Common Mistakes

  • Long-running conversations in chats that should be channels; history gets lost
  • Copying meeting notes into email; share the OneNote / Loop link
  • Forgetting you're unmuted; learn ⌘⇧M / Ctrl+Shift+M

✓ Tips & Best Practices

  • Pin your top channels and chats
  • Use OneNote To Do tags + Find Tags for a weekly review
  • Paste a Loop checklist in meeting chats for action items
