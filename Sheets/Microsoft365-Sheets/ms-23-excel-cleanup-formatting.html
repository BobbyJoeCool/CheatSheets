Conditional Formatting & Data Tools

rule types · formula-based rules · Remove Duplicates · Text to Columns · sort & filter ⌘⇧F / Ctrl+Shift+L · Goal Seek · number formats

Highlight Problems, Fix Them in Bulk

Conditional formatting colours cells by rule: above average, duplicates, data bars, or any formula. Data tools fix messy data in bulk: Remove Duplicates, Text to Columns, sort and filter. Goal Seek works backwards from a target ("what price gives $10,000 profit?"). Custom number formats change how values look without changing them.

Notes

  • Formula rules are written for the top-left cell of the selection with relative refs
  • Highlight a whole row: select A2:F100 › rule =$E2="Overdue"
  • Manage Rules shows rule order; tick Stop If True to prevent overlaps
  • Filter: ⌘⇧F (Mac) / Ctrl+Shift+L; open a column's filter with ⌥↓ / Alt+↓
  • Goal Seek: Data › What-If Analysis › Goal Seek

Automate It

  • Office Script (sheet 35) that trims, dedupes and formats each new export the same way
  • Keep rules on a table so they extend to new rows

Rules & Formats

# Conditional formatting formulas (Home › Conditional Formatting › New Rule › Use a formula)
=$E2="Overdue"                     # whole row red when E says Overdue
=AND($D2<TODAY(), $F2<>"Done")     # past due and not done
=COUNTIF($A$2:$A$500, $A2)>1       # duplicates in column A
=MOD(ROW(), 2)=0                   # banded rows
=$C2>AVERAGE($C$2:$C$500)          # above average

# Custom number formats (⌘1 / Ctrl+1 › Number › Custom)
#,##0;[Red]-#,##0;"—"              # positive; negative red; zero as dash
0.0,,"M"                           # 2500000 → 2.5M
"Qty: "0                           # 5 → Qty: 5
[<1000]0;[<1000000]0.0,"K";0.0,,"M"  # auto K / M

Code Explained

$E2 locks the column but not the row, so each row checks its own E cell
Number format sections: positive;negative;zero;text
Each comma after the digits divides by 1,000 in the display only
⌘1 / Ctrl+1 opens Format Cells from anywhere

⚠ Common Mistakes

  • Writing a row rule as =E2="Overdue" without $, so every column checks a different cell
  • Running Remove Duplicates on a copy you didn't keep; it deletes rows permanently
  • Changing number formats and thinking the value changed; rounding is display only

✓ Tips & Best Practices

  • Select the whole data area before creating a rule, then write it for the first row
  • Copy the data to a new sheet before big cleanups
  • Use Ctrl+Shift+L twice to clear all filters at once

Quick Summary
