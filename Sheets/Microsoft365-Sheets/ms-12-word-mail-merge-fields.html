Mail Merge & Fields

Mailings tab · Excel data source · merge fields · Rules If…Then…Else · labels & envelopes · ⌥F9 / Alt+F9 · DATE PAGE REF

One Letter, Hundreds of Recipients

Mail merge combines a Word document with a list (usually an Excel table) to produce one letter, label, envelope or email per row. You insert merge fields like «FirstName» where data goes, add Rules for conditional text, preview, then Finish & Merge to a new document, the printer, or email via Outlook.

Notes

  • Data source: an Excel sheet with one header row and no blank rows works best
  • Mailings › Start Mail Merge › Letters / Labels / Envelopes / E-mail Messages
  • Preview Results shows real data; arrows step through records
  • Rules › If…Then…Else inserts different text per record (e.g. Mr / Ms)
  • Format numbers with field switches: { MERGEFIELD Amount \# "$#,##0.00" }

Automate It

  • Build the merge once, save the document; next month just re-point it at the new list
  • Email merge sends personalised messages through Outlook (desktop) in one step

Merge Fields & Switches

Dear «FirstName»,                      # merge field from the header row

{ MERGEFIELD Amount \# "$#,##0.00" }   # $1,250.00
{ MERGEFIELD DueDate \@ "MMMM d, yyyy" }  # March 4, 2026
{ IF { MERGEFIELD Balance } > 0 "Please pay by Friday." "Thank you!" }
{ DATE \@ "M/d/yyyy" }                 # today's date
{ PAGE }                               # current page number

⌥F9       / Alt+F9       # toggle field codes
⇧F9       / Shift+F9     # toggle the selected field only
⌘⇧F9      / Ctrl+Shift+F9  # unlink: turn field into plain text
⌘F9       / Ctrl+F9      # insert empty field braces

Code Explained

Excel formatting doesn't always carry over; use \# (number) and \@ (date) switches
Insert real field braces with ⌘F9 / Ctrl+F9; typed { } characters don't work
IF fields compare values and pick text, so one template handles several cases
Unlinking (Ctrl+Shift+F9) freezes a field's current result as text

⚠ Common Mistakes

  • Blank rows or merged cells in the Excel list, which stop or skew the merge
  • Trusting Excel's number formatting; zip codes lose leading zeros unless the column is text
  • Merging straight to the printer without previewing a few records first

✓ Tips & Best Practices

  • Keep the list as an Excel table (sheet 16) so new rows are included automatically
  • Merge to a new document first and skim it before printing or emailing
  • Use Check for Errors to catch empty or mismatched fields
