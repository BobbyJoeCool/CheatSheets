Data Entry, Fill & Validation

Flash Fill Ctrl+E · Fill Down ⌘D / Ctrl+D · fill series · Ctrl+Enter · Ctrl+; · Data Validation · checkboxes

Type Less, Fill More

Excel fills a lot for you. Flash Fill watches one or two examples and fills the rest of the column (split names, reformat IDs). Fill Down copies the cell above; the fill handle extends series like dates and weekdays. Ctrl+Enter puts the same entry into every selected cell. Data Validation limits what can be typed and can add a dropdown list.

Notes

  • Flash Fill: type the first result, then Ctrl+E (or Data › Flash Fill)
  • Drag the fill handle with the right mouse button for options (fill weekdays, months, series)
  • Double-click the fill handle to fill down as far as the column next to it has data
  • Insert › Checkbox puts real TRUE / FALSE checkboxes in cells (Microsoft 365)
  • Custom lists for fill: Options › Advanced › Edit Custom Lists

Automate It

  • Flash Fill handles one-off cleanups; record a macro or Office Script (sheet 35) when it repeats every week
  • Dropdowns from a table column grow automatically when you add list items

Entry Shortcuts

⌘D  ⌘R         / Ctrl+D  Ctrl+R    # fill down / fill right
Data › Flash Fill / Ctrl+E         # Flash Fill
⌃↩             / Ctrl+Enter        # enter in every selected cell
⌃;             / Ctrl+;            # today's date
⌘;             / Ctrl+Shift+;      # current time
⌥↓             / Alt+↓             # pick from values above / dropdown
⌥⌘↩ / ⌃⌥↩      / Alt+Enter         # new line inside a cell
F2 / ⌃U        / F2                # edit cell
⌘Z after entry                     # undo an AutoCorrect / AutoFill

Data › Data Validation › Allow: List › Source: =Status   # dropdown from named range

Code Explained

Ctrl+Enter with a range selected fills all of it, formulas included, with relative refs adjusted
Alt+↓ in an empty cell lists values already typed in that column
Point a validation list at a table column (via a name) so the dropdown updates itself
Checkboxes store TRUE / FALSE, so =COUNTIF(B2:B50,TRUE) counts ticked boxes

Other Suites

  • Google Workspace — Smart Fill ⌘⇧Y, dropdown chips, Insert › Checkbox
  • Apple iWork — Numbers autofill handle, pop-up menus and checkboxes as cell formats

Platform Differences

  • Windows — everything; Flash Fill Ctrl+E
  • Mac — same; some entry keys differ (⌘; time)
  • Web — Flash Fill, validation and checkboxes; fewer validation options

⚠ Common Mistakes

  • Flash Fill results are static; they don't update when the source changes (use formulas for live data)
  • Typing dropdown items into the validation Source box, then having to edit every copy later
  • Gaps in the neighbouring column stop double-click fill early

✓ Tips & Best Practices

  • Add an Input Message and Error Alert on the validation tabs so users know the rule
  • Use Circle Invalid Data (Data Validation menu) to find bad values already in the sheet
  • Format the column before entering IDs with leading zeros (Text format)
