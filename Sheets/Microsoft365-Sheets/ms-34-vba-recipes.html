Patterns You'll Reuse

Most useful macros are a loop over rows that checks a value and does something, an event that runs automatically (on open, on change), or a find-and-replace across many files. These recipes cover the object model basics: Range, Cells, Offset, last-row detection, events and error handling.

Notes

  • Cells(row, col) uses numbers; Range("A1") uses addresses
  • Last used row: Cells(Rows.Count, "A").End(xlUp).Row (same as Ctrl+↑ from the bottom)
  • Events go in the sheet or ThisWorkbook module, not a regular module
  • Declare variables with Dim; add Option Explicit at the top to catch typos
  • On Error GoTo Handler sends errors to a label so the macro can clean up

Loop, Event, Word Find

Option Explicit
Sub FlagOverdue()
    Dim r As Long, last As Long
    last = Cells(Rows.Count, "A").End(xlUp).Row
    For r = 2 To last
        If Cells(r, "D").Value < Date And Cells(r, "E").Value <> "Done" Then
            Cells(r, "E").Value = "Overdue"
            Rows(r).Interior.Color = RGB(255, 230, 230)
        End If
    Next r
End Sub

' Sheet module: runs whenever column B changes
Private Sub Worksheet_Change(ByVal Target As Range)
    If Not Intersect(Target, Me.Range("B:B")) Is Nothing Then _
        Target.Offset(0, 1).Value = Now      ' timestamp in column C
End Sub

Sub WordReplaceAll()                         ' Word
    With ActiveDocument.Content.Find
        .Text = "Acme Inc.": .Replacement.Text = "Acme Corp."
        .Execute Replace:=wdReplaceAll
    End With
End Sub

Code Explained

Long holds row numbers past 32,767; don't use Integer
Intersect(...) Is Nothing checks whether the changed cell is in column B
Offset(0, 1) = one column to the right of the changed cell
_ continues a statement on the next line; : puts two statements on one line

⚠ Common Mistakes

  • Changing cells inside Worksheet_Change without Application.EnableEvents = False, causing a loop
  • Using .Select everywhere; act on ranges directly
  • Looping cell by cell over 100,000 rows; read Range.Value into an array instead

✓ Tips & Best Practices

  • Use Debug.Print and the Immediate window to inspect values
  • Turn off events, screen updating and calculation during big macros, then restore them
  • Keep shared macros in an add-in (.xlam) instead of copying them into files

Quick Summary

  • Cells(r, c) — by number
  • End(xlUp).Row — last row
  • Worksheet_Change — run on edit
  • Option Explicit — catch typos
