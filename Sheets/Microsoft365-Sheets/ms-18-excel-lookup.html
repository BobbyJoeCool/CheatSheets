Lookup Functions

XLOOKUP · XMATCH · INDEX / MATCH · VLOOKUP (legacy) · approximate & wildcard match · two-way lookup · CHOOSECOLS

Find a Value in Another Table

XLOOKUP is the modern lookup: give it the value, the column to search and the column to return. It looks left or right, defaults to an exact match, has a built-in "not found" value, and can return several columns at once. INDEX / MATCH does the same in older versions. VLOOKUP still works but breaks when columns are inserted.

Notes

  • XLOOKUP(lookup, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
  • match_mode: 0 exact (default), -1 exact or next smaller, 1 next larger, 2 wildcard
  • search_mode: -1 searches last to first (latest entry)
  • Return several columns: make return_array span them; results spill right
  • XLOOKUP and XMATCH are in Excel 2021 and later, Microsoft 365 and the web

Lookup Patterns

=XLOOKUP(A2, Products[SKU], Products[Price])                # exact match
=XLOOKUP(A2, Products[SKU], Products[Price], "Not found")    # custom miss
=XLOOKUP(A2, Products[SKU], Products[[Name]:[Price]])        # spills 3 columns
=XLOOKUP(D2, Rates[MinIncome], Rates[Rate], , -1)            # tax bracket
=XLOOKUP(A2, Log[ID], Log[Status], , 0, -1)                  # last match
=XLOOKUP("*"&B2&"*", Names, Emails, , 2)                     # contains
=XLOOKUP(G2, Months, XLOOKUP(G1, Regions, Data))             # two-way
=INDEX(Products[Price], MATCH(A2, Products[SKU], 0))         # classic
=XMATCH(A2, Products[SKU])                                   # position → 7
=VLOOKUP(A2, $F$2:$H$200, 3, FALSE)                          # legacy

Code Explained

Leave optional arguments empty with commas: , , -1
Approximate match (-1) needs no sorting in XLOOKUP, unlike VLOOKUP's TRUE mode
Nested XLOOKUP: the inner one returns a whole column, the outer one picks the row
VLOOKUP's column number 3 silently changes meaning when a column is inserted

⚠ Common Mistakes

  • VLOOKUP without FALSE; it defaults to approximate and returns wrong rows on unsorted data
  • Lookup values with trailing spaces or numbers stored as text; wrap with TRIM() or fix the type
  • Return and lookup arrays of different sizes; XLOOKUP returns #VALUE!

✓ Tips & Best Practices

  • Use table columns as arrays so lookups never need $ and grow with the data
  • Use the not-found argument instead of wrapping in IFERROR, so real errors still show
  • For many matching rows, use FILTER (sheet 19) instead of a lookup

Quick Summary

  • XLOOKUP(val, look, return) — the default
  • , , -1 — next smaller (brackets)
  • INDEX/MATCH — older versions
  • VLOOKUP(…, FALSE) — legacy only
