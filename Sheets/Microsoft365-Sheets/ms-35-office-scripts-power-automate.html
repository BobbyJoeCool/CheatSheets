Office Scripts & Power Automate

Automate tab · Action Recorder · TypeScript main(workbook) · run from a button · Power Automate flows · scheduled runs · VBA vs Office Scripts

Automation That Runs in the Cloud

Office Scripts are Excel automation written in TypeScript. They run in Excel for the web and desktop (Windows and Mac) from the Automate tab, can be recorded with the Action Recorder, and are stored in OneDrive, so they work on any machine. Power Automate can run a script on a schedule or when an email or form arrives, with no one opening the file.

Notes

  • Automate tab › Record Actions writes a script as you click
  • Every script has function main(workbook: ExcelScript.Workbook)
  • Scripts are shared through the file or a SharePoint folder
  • Add a script button to the sheet: script ⋯ › Add button
  • Power Automate: "Run script" action in a scheduled or triggered flow (business plans)

Automate It

  • Schedule a flow: every Monday 7:00, run "CleanupExport" on the latest file
  • Trigger on Microsoft Forms response → add row → run formatting script

Office Script (TypeScript)

function main(workbook: ExcelScript.Workbook) {
  const sheet = workbook.getWorksheet("Data");
  const used = sheet.getUsedRange();
  const values = used.getValues();              // 2-D array

  // Trim text in column A, flag amounts over 1000 in column E
  for (let r = 1; r < values.length; r++) {
    values[r][0] = String(values[r][0]).trim();
    values[r][4] = Number(values[r][3]) > 1000 ? "Review" : "";
  }
  used.setValues(values);

  sheet.getRange("1:1").getFormat().getFont().setBold(true);
  used.getFormat().autofitColumns();
  sheet.freezePanes.freezeRows(1);
}

Code Explained

Read all values once with getValues(), change the array, write back once: fast
Arrays are 0-based; row 0 is the header
Scripts can't open other files; use Power Automate to pass data between files
TypeScript types like ExcelScript.Workbook give autocomplete in the editor

Other Suites

  • Google Workspace — Apps Script (JavaScript) with time-driven triggers
  • Apple iWork — Shortcuts and AppleScript on the Mac; no cloud runs

Platform Differences

  • Web — Automate tab, recorder, editor
  • Windows / Mac — run and edit scripts in M365 desktop on business plans
  • Personal plans — Office Scripts availability is limited; check the Automate tab

⚠ Common Mistakes

  • Calling getValue() inside a loop for every cell; batch with getValues()
  • Expecting a script to read a second workbook; that needs Power Automate
  • Writing a script for a one-time cleanup that Flash Fill or Power Query would do

✓ Tips & Best Practices

  • Record first, then edit the generated code
  • Return values from main so Power Automate can use them in later steps
  • Keep scripts small and single-purpose; chain them in a flow

Quick Summary

  • Automate › Record Actions — record a script
  • main(workbook) — entry point
  • getValues / setValues — batch read / write
  • Power Automate — schedule and trigger
