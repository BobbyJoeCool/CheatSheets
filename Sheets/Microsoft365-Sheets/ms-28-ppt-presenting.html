Run the Room From the Keyboard

Presenter View shows your notes, the next slide and a timer on your screen while the audience sees only the slide. During a show, the keyboard does everything: jump to any slide by number, blank the screen to pull attention back, draw on a slide. Rehearse Timings and Speaker Coach help you practise; Export turns a deck into PDF or video.

Notes

  • Slide Show › Use Presenter View; swap screens with Display Settings › Swap
  • Type a slide number and press Enter to jump straight to it
  • B / W blanks to black / white; press again to return
  • Live subtitles: Slide Show › Subtitle Settings (translate while you talk)
  • Speaker Coach (Slide Show › Rehearse with Coach) flags pace, fillers and reading slides

Slide Show Keys

⇧⌘↩          / F5              # start from the beginning
⌘↩           / Shift+F5        # start from current slide
→ ↓ Space N  /                 # next
← ↑ P        /                 # previous
12 ↩         / 12 Enter        # go to slide 12
B   W        /                 # black / white screen
⌘P  ⌘E       / Ctrl+P  Ctrl+E  # pen / eraser (Win: laser Ctrl+L)
E            /                 # erase all ink
—            / Ctrl+S          # all slides list (Windows)
Esc          / Esc             # end show
?  or  F1                      # show the shortcut list during a show

Code Explained

Keys are the same during any show; F1 (Win) or ? lists them on screen
Ink you draw can be kept or discarded when the show ends
Slides marked Hide Slide are skipped unless you jump to them by number
Rehearse Timings records time per slide for kiosk or auto-advance shows

Other Suites

  • Google Workspace — Present ⌘↩ / Ctrl+Enter, Presenter view, captions ⌘⇧C, laser L
  • Apple iWork — Keynote Play ⌥⌘P, presenter display, X swap displays, B / W

Platform Differences

  • Windows — Presenter View, Speaker Coach, Cameo, record to video
  • Mac — Presenter View, recording; some coach features later
  • Web — present, Speaker Coach, subtitles; no recording

⚠ Common Mistakes

  • Clicking back through 20 slides to answer a question; type the number and press Enter
  • Presenting from a cloud file over weak Wi-Fi; download it first
  • Mirroring displays, so the audience sees your notes

✓ Tips & Best Practices

  • Print or memorise slide numbers of your backup slides for Q&A
  • Press B to black out the screen during discussion
  • Export a PDF backup in case the venue PC lacks your fonts

Quick Summary
