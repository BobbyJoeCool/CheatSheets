Dynamic Arrays

spilling · # spill ref · FILTER · SORT / SORTBY · UNIQUE · SEQUENCE · TAKE / DROP · VSTACK / HSTACK · TOCOL

One Formula, Many Results

A dynamic array formula returns several values that spill into the cells below and to the right. FILTER pulls matching rows, SORT and UNIQUE reorder and dedupe, and SEQUENCE generates numbers. Refer to a whole spilled result with the spill operator #, e.g. =COUNTA(E2#), so dependent formulas resize with it.

Notes

  • Only the top-left cell holds the formula; the rest show greyed "ghost" values
  • #SPILL! means something is in the way; clear the cells shown by the dashed border
  • Spilling doesn't work inside tables; put dynamic formulas next to the table
  • @ in old formulas forces a single value (implicit intersection)
  • Microsoft 365 and Excel 2021+; TAKE / DROP / VSTACK / TOCOL need current M365 or 2024

Spill Formulas

=FILTER(Sales, Sales[Region]="West")                 # all West rows
=FILTER(Sales, (Sales[Region]="West")*(Sales[Amount]>1000), "None")  # AND
=FILTER(Sales, (Sales[Region]="West")+(Sales[Region]="East"))       # OR
=SORT(Sales, 3, -1)                                  # by 3rd column, descending
=SORTBY(Sales[Name], Sales[Amount], -1)              # names by amount
=UNIQUE(Sales[Region])                               # distinct list
=SORT(UNIQUE(Sales[Region]))                         # sorted distinct
=COUNTA(UNIQUE(Sales[Customer]))                     # distinct count
=SEQUENCE(12)          =SEQUENCE(1, 7, 0)            # 1…12 down / 0…6 across
=TAKE(SORT(Sales,3,-1), 5)                           # top 5 rows
=VSTACK(Jan, Feb, Mar)                               # stack tables
=E2#                                                 # whole spill from E2

Code Explained

Multiply conditions for AND, add them for OR; each comparison gives TRUE / FALSE (1 / 0)
The third FILTER argument is shown when nothing matches, instead of #CALC!
TAKE(x, 5) keeps the first 5 rows; TAKE(x, -5) the last 5; DROP removes them
Chart or validation sources can point at =$E$2# and resize automatically

Other Suites

  • Google Workspace — FILTER, SORT, UNIQUE, SEQUENCE, VSTACK spill natively; older sheets use ARRAYFORMULA
  • Apple iWork — recent Numbers has FILTER, SORT, UNIQUE, SEQUENCE, TAKE, VSTACK too

Platform Differences

  • Windows / Mac / Web — same in M365; Office 2019 and older have no spilling

⚠ Common Mistakes

  • Typing in a cell inside a spill range and getting #SPILL! on the formula
  • Putting FILTER inside a table, where spilling isn't allowed
  • Referencing E2:E50 instead of E2#, so new results fall outside your range

✓ Tips & Best Practices

  • Use FILTER + SORT + TAKE for live "top 10" lists on dashboards
  • Wrap UNIQUE in SORT for clean dropdown sources
  • Select the formula cell and look for the blue spill border to see the full result

Quick Summary

  • FILTER — matching rows
  • SORT / SORTBY / UNIQUE — reorder, dedupe
  • E2# — the whole spill
  • #SPILL! — clear the blocked cells
