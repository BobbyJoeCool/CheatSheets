Building Slides Fast

Designer · Reuse Slides · duplicate ⌘D / Ctrl+D · Outline view · Align & Distribute · Selection Pane · group ⌘⌥G / Ctrl+G · Smart Guides

From Outline to Finished Deck

Write the talk in Outline view (every line is a slide title or bullet), then let Designer suggest layouts for each slide. Duplicate a finished slide instead of starting from blank. Align & Distribute, Smart Guides and the Selection Pane make objects line up and keep busy slides manageable.

Notes

  • Outline view: View › Outline; Tab demotes a title to a bullet, ⇧Tab promotes
  • Designer (Home › Designer) suggests layouts when you add pictures or lists
  • Reuse Slides (Home › New Slide › Reuse Slides) pulls slides from another deck
  • Selection Pane: rename, hide and reorder overlapping objects
  • Nudge with arrow keys; hold ⌥ / Ctrl for fine nudges

Automate It

  • Reuse Slides from a library deck instead of rebuilding standard slides
  • Designer applies a consistent look to pictures and lists in one click

Building Shortcuts

⌘D             / Ctrl+D          # duplicate slide or object
⇧⌘N / ⌃M       / Ctrl+M          # new slide
⌥⌘G            / Ctrl+G          # group objects
⇧⌥⌘G           / Ctrl+Shift+G    # ungroup
⇧ + drag                         # constrain move / keep proportions
⌥ + drag       / Ctrl + drag     # drag a copy
⌘] ⌘[          / Ctrl+] Ctrl+[   # bigger / smaller text
Arrange menu   / Arrange menu    # bring to front / send to back
Arrange › Sel. / Alt+F10         # Selection Pane
⌘1             / Ctrl+1 (Format) # format pane

Code Explained

⌘D / Ctrl+D on a selected object makes a copy offset by the last move, so repeating it spaces evenly
Arrange › Align works on the selection; tick Align Selected Objects vs Align to Slide
Distribute Horizontally needs three or more objects
Ordering shortcuts differ by version; Arrange menu always works

Other Suites

  • Google Workspace — ⌘D duplicate, Arrange › Align & distribute, ⌘⌥G group
  • Apple iWork — Keynote: alignment guides, Arrange › Align / Distribute, ⌥-drag to copy

Platform Differences

  • Windows — Designer, Selection Pane Alt+F10, Reuse Slides
  • Mac — same; Selection Pane under Arrange
  • Web — Designer, align tools; Reuse Slides limited

⚠ Common Mistakes

  • Eyeballing alignment; a few pixels off is visible when projected
  • Building slides from Blank layout with text boxes, losing outline and accessibility order
  • Piling objects on top of each other with no names; use the Selection Pane

✓ Tips & Best Practices

  • Draft the whole talk in Outline view first, then design
  • Turn on View › Guides for consistent margins
  • Copy formatting with Format Painter or ⇧⌘C / Ctrl+Shift+C

Quick Summary

  • ⌘D / Ctrl+D — duplicate
  • Outline view — write first, design later
  • Align & Distribute — tidy objects
  • Selection Pane — manage layers
