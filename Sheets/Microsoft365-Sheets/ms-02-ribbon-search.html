Sheet 02

Ribbon, Search & KeyTips

Simplified / Classic ribbon · Quick Access Toolbar · Alt KeyTips · Microsoft Search · customize ribbon · ⌘⌥R / Ctrl+F1

Stop Hunting Through Tabs

Every command lives somewhere on the ribbon, but the fastest way to a command you can't remember is the Search box at the top of the window: type what you want and press Enter. On Windows, pressing Alt shows KeyTips, letters for every tab and button, so any ribbon command becomes a keyboard sequence. The Quick Access Toolbar (QAT) holds the handful of commands you use all day.

Notes

  • Search box (Windows): Alt+Q; it finds commands, help and recent files
  • KeyTips: press and release Alt, then the letters, e.g. Alt H B A = all borders
  • Number keys run QAT buttons on Windows: Alt+1, Alt+2 …
  • Simplified ribbon (one line) is the default on the web; switch with the ribbon's dropdown
  • Mac has no KeyTips; use the Help menu search (⇧⌘/) or the app's own search box

Automate It

  • Add your top 5 commands to the QAT and run them with Alt+1…5 on Windows
  • Export ribbon + QAT customizations (File › Options › Customize Ribbon › Import/Export) to reuse on a new PC

Ribbon & KeyTip Sequences

⌘⌥R      / Ctrl+F1       # collapse / expand the ribbon
⇧⌘/      / Alt+Q         # search commands (Help menu on Mac)
—        / Alt  then F10 # show KeyTips (Windows)

# KeyTip sequences (Windows) — press one after another
Alt H B A      # Home › Borders › All Borders
Alt H O I      # Home › Format › AutoFit column width (Excel)
Alt H V V      # Paste values (Excel)
Alt N T        # Insert › Table
Alt W F F      # View › Freeze Panes (Excel)
Alt 1          # first Quick Access Toolbar button

Code Explained

KeyTips are sequences, not chords: tap Alt, release, then type each letter
Old Office 2003 menu sequences (Alt E S V for paste values) still work in Excel
Right-click any ribbon button › Add to Quick Access Toolbar
Collapsing the ribbon gives you more rows; click a tab to peek at it

Other Suites

  • Google Workspace — search the menus with ⌥/ / Alt+/; menus instead of a ribbon
  • Apple iWork — toolbar + Format sidebar; customize via View › Customize Toolbar

Platform Differences

  • Windows — KeyTips, QAT number shortcuts
  • Mac — no KeyTips; Help menu search and ribbon tabs only
  • Web — KeyTips work with Alt+Win in some browsers; search box is the main route

⚠ Common Mistakes

  • Holding Alt down while typing KeyTip letters; it must be pressed and released
  • Customizing the ribbon on one PC and expecting it to follow you; export the file
  • Hunting through tabs for a command you could type into the Search box in two seconds

✓ Tips & Best Practices

  • Learn the KeyTips for the 3 commands you click most; they never change between versions
  • Turn on the Developer tab once; macros and form controls live there
  • On Mac, add menu shortcuts for anything in System Settings › Keyboard › Keyboard Shortcuts › App Shortcuts

Quick Summary

  • Alt — KeyTips (Windows)
  • Alt+Q / ⇧⌘/ — search commands
  • QAT — your favourites, Alt+1…
  • ⌘⌥R / Ctrl+F1 — hide the ribbon
