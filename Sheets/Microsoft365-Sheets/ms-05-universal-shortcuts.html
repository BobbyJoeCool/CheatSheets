Shortcuts That Work Everywhere

Paste Special ⌃⌘V / Ctrl+Alt+V · paste as text · Repeat ⌘Y / F4 · Format Painter · F7 spelling · Dictate · ⌘⇧S / F12

Learn Once, Use in Every App

Word, Excel, PowerPoint and Outlook share one set of core shortcuts. The biggest time-savers are Paste Special (paste as plain text or values), Repeat (do the last action again), Format Painter (copy formatting) and Undo history. Learn these once and they work in every app, on the web too in most cases.

Notes

  • Repeat (⌘Y / F4) repeats formatting, inserts, deletes: anything you just did
  • Double-click Format Painter to paint many places; Esc to stop
  • Paste as text: Paste Options › Keep Text Only, or ⌥⇧⌘V (Mac Word) / Ctrl+Shift+V (web)
  • Dictate: Home › Dictate, or Win+H for Windows system dictation
  • Shift+F3 cycles UPPER / lower / Title case in Word and PowerPoint

Shared Shortcuts

⌘C ⌘X ⌘V     / Ctrl+C X V     # copy, cut, paste
⌃⌘V         / Ctrl+Alt+V     # Paste Special dialog
⌘Z  ⌘Y      / Ctrl+Z  Ctrl+Y # undo / redo or repeat
⌘Y          / F4             # repeat last action
⇧⌘C ⇧⌘V     / Ctrl+Shift+C V # copy / paste formatting (Word, PPT)
⌘B ⌘I ⌘U    / Ctrl+B I U     # bold, italic, underline
⌘K          / Ctrl+K         # insert link
⌘F          / Ctrl+F         # find
⌃H / ⇧⌘H    / Ctrl+H         # replace
F7          / F7             # spelling & grammar
⇧F3         / Shift+F3       # change case (Word, PPT)
⇧⌘S         / F12            # Save As

Code Explained

On Windows, Ctrl+Y redoes after an undo and repeats otherwise; F4 is the same
Mac function keys may need fn (fn+F4) unless you set "Use F1, F2… as standard keys"
Copy / paste formatting (⇧⌘C) is the keyboard version of Format Painter
Excel's Paste Special has its own letters: V values, T formats, E transpose

Other Suites

  • Google Workspace — ⌘⇧V / Ctrl+Shift+V paste without formatting; paint format button
  • Apple iWork — Paste and Match Style ⌥⇧⌘V; Copy / Paste Style ⌥⌘C / ⌥⌘V

Platform Differences

  • Windows — F4 repeat, F12 Save As
  • Mac — ⌘Y repeat; F-keys may need fn
  • Web — Ctrl+Shift+V paste as text; no F12

⚠ Common Mistakes

  • Pasting from a web page and fighting its fonts; paste as text from the start
  • Clicking Format Painter once and expecting it to stay on; double-click it
  • Re-doing a multi-step format by hand when F4 / ⌘Y repeats it

✓ Tips & Best Practices

  • Set the default paste (Word › Options › Advanced › Pasting from other programs) to Keep Text Only
  • Use F4 after inserting a row in Excel to insert more rows one keystroke at a time
  • Turn on standard function keys on a Mac keyboard if you use Office shortcuts a lot

Quick Summary
