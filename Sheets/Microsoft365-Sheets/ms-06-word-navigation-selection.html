Word Navigation & Selection

Navigation pane · Go To F5 · extend selection F8 · word / paragraph jumps · select sentence · Read Mode · Focus

Move Through a Long Document

The Navigation pane (⌘F / Ctrl+F) lists every heading, so you can jump and even drag whole sections to reorder them. Go To (F5) jumps to a page, section, bookmark or comment. Selection shortcuts let you grab a word, sentence or paragraph without dragging, and Focus mode hides everything but the text.

Notes

  • Navigation pane has three views: Headings, Pages (thumbnails), Results (search hits)
  • Drag a heading in the pane to move the heading and everything under it
  • ⇧F5 / Shift+F5 returns to your last edit spot, even after reopening the file
  • Click in the left margin: once = line, twice = paragraph, three times = whole document
  • View › Focus (or Immersive Reader) for distraction-free writing

Moving & Selecting

⌘F           / Ctrl+F          # Navigation pane + search
⌥⌘G / F5     / F5 or Ctrl+G    # Go To (page, section, bookmark)
⇧F5          / Shift+F5        # back to last edit
⌥← →         / Ctrl+← →        # word by word
⌘↑ ↓         / Ctrl+↑ ↓        # paragraph by paragraph
⌘Home / End  / Ctrl+Home End   # start / end of document (fn⌘← → on laptops)
double-click                   # select word
⌘ + click    / Ctrl + click    # select sentence
triple-click                   # select paragraph
F8           / F8              # extend mode: F8 again = word, sentence…
⌥ + drag     / Alt + drag      # select a vertical block

Code Explained

Extend mode: press F8 repeatedly to grow word → sentence → paragraph → document; Esc ends it
Go To accepts +3 or -2 to move relative pages
Holding ⇧ with any movement key turns it into a selection
⌥ + drag block selection is handy for removing leading spaces or columns of text

Other Suites

  • Google Workspace — Document outline (left pane); ⌃⌘N H / Ctrl+Alt+N H jumps to the next heading
  • Apple iWork — Pages: View › Table of Contents sidebar; ⌘ + click word selection the same

Platform Differences

  • Windows — Ctrl+G / F5 Go To; Read Mode under View
  • Mac — ⌥⌘G or Edit › Find › Go To; ⌘G is Find Next
  • Web — Navigation pane under View; no F8 extend mode

⚠ Common Mistakes

  • Scrolling through 80 pages to find a section instead of opening the Navigation pane
  • Cut-and-pasting sections to reorder them; drag headings in the pane instead
  • Using direct formatting for headings, so they never show up in the Navigation pane (use styles, sheet 07)

✓ Tips & Best Practices

  • Keep the Navigation pane open while writing long docs; it doubles as a live outline
  • Use Outline view (⌥⌘O / Ctrl+Alt+O) with Show Level 2 to restructure fast
  • Press ⇧F5 right after opening a document to jump to where you left off

Quick Summary
