How Formulas Think

Every formula starts with =. References are relative by default (they shift when copied); add $ to lock the column, row, or both. Named ranges (TaxRate instead of $B$1) make formulas readable. When something breaks, the error value tells you why, and Evaluate Formula and Trace Precedents show how Excel got there.

Notes

  • Toggle $ while editing a reference: F4 (Win) or ⌘T (Mac) cycles A1 → $A$1 → A$1 → $A1
  • Other sheet: =Sales!B2; other sheet with spaces: ='Q1 Sales'!B2
  • Name a cell: click it, type a name in the Name Box, Enter. Manage in Formulas › Name Manager
  • Show formulas instead of results: ⌃ + grave accent (Mac) / Ctrl + grave accent (Win)
  • Formulas › Evaluate Formula steps through one calculation (Windows)

References & Operators

=B2*C2                 # relative: copied down becomes =B3*C3
=B2*$F$1               # $F$1 stays fixed (tax rate)
=B$1*$A2               # mixed: row 1 fixed, column A fixed (times table)
=SUM(Sales!B2:B13)     # another sheet
=SUM('Q1 Sales'!B:B)   # sheet name with spaces needs quotes
=Price*(1+TaxRate)     # named ranges
="Total: "&TEXT(D2,"$#,##0")   # & joins text → Total: $1,250
=A2<>""                # TRUE if A2 not empty
=(B2-C2)/C2            # parentheses before / → growth %
=2^10                  # 1024

Code Explained

Order: ( ), ^, * /, + -, &, then comparisons = < > <= >= <>
$ only matters when copying; it doesn't change the result in place
Names are workbook-wide by default, so TaxRate works on every sheet
& joins text; numbers turn into text with no formatting unless you wrap them in TEXT()

Other Suites

  • Google Workspace — same syntax and $; F4 toggles refs; sheet refs 'Sheet 1'!A1
  • Apple iWork — Numbers uses header names and Table 1::B2; preserve row / column instead of $

Platform Differences

  • Windows — F4, Evaluate Formula, Watch Window
  • Mac — ⌘T for $; Evaluate Formula missing in some builds
  • Web — F4 works; tracing arrows limited

Error Values

ErrorUsually means
#N/ALookup found no match
#VALUE!Wrong type: text where a number was expected
#REF!A referenced cell was deleted
#DIV/0!Dividing by zero or a blank
#NAME?Typo in a function or range name
#SPILL!Dynamic array result is blocked by data
#NUM!Impossible number (e.g. SQRT(-1))

⚠ Common Mistakes

  • Copying a formula and forgetting $, so the tax-rate reference walks down the sheet
  • Numbers stored as text (green triangle); they're ignored by SUM. Convert via the warning menu
  • Deleting a row that formulas point to and getting #REF!; check dependents first

✓ Tips & Best Practices

  • Click a reference in the formula bar and press F4 / ⌘T until the $ is where you want it
  • Name inputs (rates, thresholds) so formulas explain themselves
  • Use Ctrl+[ to jump to a formula's source cell; F5 + Enter jumps back

Quick Summary

  • F4 / ⌘T — cycle $
  • Sheet!A1 — cross-sheet
