LET, LAMBDA & GROUPBY

LET · LAMBDA · named LAMBDAs · MAP / BYROW / REDUCE · GROUPBY · PIVOTBY · TRIMRANGE · trim-ref dot operator

Formulas That Read Like Code

LET names intermediate results inside a formula, so a long calculation is readable and each part is computed once. LAMBDA turns a formula into your own function; save it in Name Manager and call it like a built-in. GROUPBY and PIVOTBY build summary tables with one formula, a live alternative to a PivotTable.

Notes

  • LET(name1, value1, name2, value2, …, result)
  • Named LAMBDA: Formulas › Name Manager › New › Refers to: =LAMBDA(x, …)
  • BYROW(range, LAMBDA(r, …)) applies a calculation to each row
  • GROUPBY / PIVOTBY / TRIMRANGE need a current Microsoft 365 build
  • A:.A (trim-ref) means column A trimmed to used cells, like TRIMRANGE(A:A)

LET, LAMBDA & Summaries

=LET(total, SUM(Sales[Amount]),
     west,  SUMIFS(Sales[Amount], Sales[Region], "West"),
     west / total)                                # West share

# Name Manager → Name: TAXED   Refers to:
=LAMBDA(amount, rate, ROUND(amount*(1+rate), 2))
=TAXED(B2, 0.0825)                                # → 108.25 for 100

=BYROW(B2:E20, LAMBDA(r, MAX(r)-MIN(r)))         # range per row
=MAP(A2:A20, LAMBDA(x, PROPER(TRIM(x))))         # clean each cell
=REDUCE(0, C2:C20, LAMBDA(acc, x, acc + (x>100)))  # count > 100

=GROUPBY(Sales[Region], Sales[Amount], SUM)      # totals by region
=PIVOTBY(Sales[Region], Sales[Year], Sales[Amount], SUM)  # cross-tab
=SUM(C2:.C10000)                                 # trims empty rows

Code Explained

Formulas can span lines: ⌥↩ / Alt+Enter in the formula bar; LET reads best that way
A LAMBDA typed in a cell with arguments after it runs once: =LAMBDA(x, x*2)(5) → 10
GROUPBY takes the function by name (SUM, AVERAGE, COUNTA) or a LAMBDA
The dot in C2:.C10000 trims trailing blank rows so whole-column formulas stay fast

Other Suites

  • Google Workspace — LET, LAMBDA, MAP, BYROW, REDUCE, Named functions; QUERY instead of GROUPBY
  • Apple iWork — recent Numbers has LET, LAMBDA and SCAN; no GROUPBY / PIVOTBY (use a pivot table)

Platform Differences

  • Windows / Mac / Web — LET and LAMBDA in M365 and 2024; GROUPBY / PIVOTBY / TRIMRANGE M365 only

⚠ Common Mistakes

  • Naming a LET variable like a cell (A1, R2C2); use words like rate
  • Defining LAMBDAs in one workbook and expecting them elsewhere; copy a sheet that uses them
  • Sharing GROUPBY files with Office 2021 users, who see #NAME?

✓ Tips & Best Practices

  • Refactor long formulas with LET first; it's easier to debug one named step at a time
  • Add comments to named LAMBDAs in Name Manager so others know the arguments
  • Use GROUPBY for summaries that must update without clicking Refresh

Quick Summary

  • LET — name steps inside a formula
  • LAMBDA — custom functions
  • BYROW / MAP / REDUCE — loop over ranges
  • GROUPBY / PIVOTBY — formula PivotTables
