Decide and Add Up

IF returns one value when a test is TRUE and another when FALSE. IFS and SWITCH replace deep nested IFs. The …IFS family (SUMIFS, COUNTIFS, AVERAGEIFS, MAXIFS, MINIFS) adds or counts only rows that match one or more conditions, which covers most reporting. SUMPRODUCT multiplies arrays and adds the result.

Notes

  • Criteria are text: ">100", "<>Closed", ">="&F1 (join a cell)
  • Wildcards in criteria: "*north*", "A?"; escape a literal * with ~*
  • SUMIFS argument order: sum range first, then range / criteria pairs
  • IFERROR(x, "") hides every error; IFNA only #N/A (safer for lookups)
  • Round results you compare: ROUND(x, 2) avoids floating-point surprises

Logic & Conditional Math

=IF(C2>=70, "Pass", "Fail")                      # → Pass
=IFS(C2>=90,"A", C2>=80,"B", C2>=70,"C", TRUE,"F")  # TRUE = else
=SWITCH(B2, "N","North", "S","South", "Other")   # last arg = default
=IF(AND(B2="West", C2>1000), "Big West", "")
=IF(OR(D2="", E2=""), "Missing", "OK")
=SUMIFS(Sales[Amount], Sales[Region],"West", Sales[Date],">="&F1)
=COUNTIFS(A:A, "Open", B:B, "<"&TODAY())          # overdue open items
=AVERAGEIFS(C:C, B:B, "Widget")
=MAXIFS(C:C, B:B, "Widget")                      # also MINIFS
=SUMPRODUCT(Qty, Price)                          # Σ qty × price
=ROUND(B2*1.0825, 2)   =ROUNDUP(x,0)   =MROUND(x, 0.25)
=IFERROR(B2/C2, 0)                               # 0 instead of #DIV/0!

Code Explained

IFS has no default; end with TRUE, value to catch everything else
Comparison operators in criteria must be inside the quotes; cell values are joined with &
COUNTIFS with "<"&TODAY() compares against today's date number
SUMPRODUCT also handles conditions: =SUMPRODUCT((Region="West")*Amount)

⚠ Common Mistakes

  • Putting the sum range last in SUMIFS (that's the old SUMIF order)
  • Writing ">F1"; that compares to the text "F1". Use ">"&F1
  • Wrapping everything in IFERROR, hiding real mistakes like typos in ranges

✓ Tips & Best Practices

  • Use SUMIFS even with one condition; same order every time and easy to add more
  • Build criteria from cells (">="&StartDate) so reports are driven by inputs, not edits
  • Prefer IFS or SWITCH over IFs nested more than two deep

Quick Summary

  • IF / IFS / SWITCH — choose a value
  • SUMIFS — sum range first, then pairs
  • ">"&cell — criteria from a cell
  • IFNA — catch only lookup misses
