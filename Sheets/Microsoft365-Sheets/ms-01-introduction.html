Introduction to Microsoft 365

M365 vs Office 2024 · desktop · web · mobile · Microsoft 365 Copilot app · .docx .xlsx .pptx

One Subscription, Three Ways In

Microsoft 365 is the subscription that bundles Word, Excel, PowerPoint, Outlook, OneDrive and Teams. Each app comes in three flavours: the desktop apps (Windows and Mac, the most complete), the web apps in the browser (free with a Microsoft account, fewer features), and mobile apps. Office 2024 is the one-time-purchase version: same core apps, no new features after release and no Copilot.

Notes

  • Start page: m365.cloud.microsoft (older office.com links redirect)
  • The Microsoft 365 Copilot app is the launcher on Windows / mobile: recent files, apps, Copilot chat
  • Windows desktop has the most features; Mac lags on VBA, Power Query editing and some add-ins
  • Files saved to OneDrive or SharePoint get AutoSave, sharing and version history
  • Free web apps need only a Microsoft account; desktop apps need a paid plan or Office 2024

Open Things Fast

word.new  excel.new  powerpoint.new   # new blank file in the browser (OneDrive)
ppt.new   xls.new   doc.new             # short aliases for the same

⌘N        / Ctrl+N     # new blank file (desktop)
⌘O        / Ctrl+O     # open
⌘S        / Ctrl+S     # save (AutoSave on: saves a version)
⌘W        / Ctrl+W     # close window
⌘P        / Ctrl+P     # print / export PDF
⌘,        / File › Options   # preferences / options
⌘Q        / Alt+F4     # quit

Code Explained

word.new and friends work in any browser address bar and create the file in your OneDrive
Shortcuts are listed macOS first, then Windows, on every sheet in this set
Mac preferences live under the app menu (⌘,); Windows uses File › Options
Web apps reuse most Windows shortcuts, but some browser shortcuts win (Ctrl+N opens a browser window)

Other Suites

  • Google Workspace — docs.new, sheets.new, slides.new; everything lives in Drive
  • Apple iWork — Pages, Numbers, Keynote are free on Mac / iPad; icloud.com for the web versions

Platform Differences

  • Windows — full feature set, VBA, Power Query, all add-ins
  • Mac — near parity; some features arrive later and VBA has gaps
  • Web — free, co-authoring first, no VBA macros, fewer formats

⚠ Common Mistakes

  • Saving to the local disk and then wondering why AutoSave and version history are greyed out
  • Assuming a feature exists on the web or Mac because you saw it on Windows; check the Platform box
  • Saving as .csv and losing every other sheet and all formulas without noticing

✓ Tips & Best Practices

  • Type excel.new in the address bar instead of hunting for the New button
  • Check File › Account (Windows) or Help › Check for Updates (Mac) to see your version
  • Pin the apps you use to the taskbar / Dock; open recent files from their jump list

Quick Summary

  • M365 — subscription, monthly features
  • Office 2024 — one-time, frozen
  • *.new — instant blank file in the browser
  • .xlsm — the only Excel format that keeps macros
