Line Things Up Properly

Use tables for anything in columns, tab stops for single lines with aligned parts (like a price list), and multilevel lists linked to headings for numbered sections like 1, 1.1, 1.1.1. Never line things up with spaces: they break the moment the font changes.

Notes

  • Convert Text to Table turns tab- or comma-separated text into a table instantly
  • Repeat Header Rows (Table Layout) repeats the header on every page of a long table
  • Tab in the last cell adds a row; ⇧Tab goes back a cell
  • Multilevel list: Home › Multilevel List › Define New Multilevel List › link levels to Heading 1–3
  • Layout › Columns for newsletter columns; use a Continuous section break to mix 1 and 2 columns

Code Explained

Alt+Shift+↑ moves table rows and whole list items, not just text
Inside a table, Tab moves cells, so use Ctrl+Tab / ⌃Tab to insert a real tab
AutoFormat As You Type creates lists and lines; undo once (⌘Z) to keep the plain text
Multilevel numbering stays correct only when every level uses the list's linked style

Other Suites

  • Google Workspace — Format › Table; repeat header via Table properties › Pin header row
  • Apple iWork — Pages tables; header rows repeat on each page automatically

Platform Differences

  • Windows — full table tools, Define New Multilevel List
  • Mac — same; Table Design / Layout tabs
  • Web — basic tables and lists; no list definitions or tab-stop dialog

⚠ Common Mistakes

  • Spacing text into columns with the space bar; it misaligns with proportional fonts
  • Restarting list numbers by typing them; right-click › Restart at 1 / Continue Numbering
  • Long tables without Repeat Header Rows, so page 2 has no column labels

✓ Tips & Best Practices

  • Click and drag on the ruler to set tab stops; double-click a stop to open the Tabs dialog
  • Use table styles (Table Design) instead of shading cells one by one
  • Set AutoFit to Window so tables resize with margins

Quick Summary

  • Convert Text to Table — tabs → table
  • Repeat Header Rows — header on every page
  • Alt+Shift+↑↓ — move rows / items
  • Multilevel list — 1 / 1.1 / 1.1.1
