Ranges That Grow by Themselves

An Excel table (not just a formatted range) knows its own size. New rows are added automatically, formulas in a column fill down by themselves, and you refer to data by name: Sales[Amount] instead of $C$2:$C$500. PivotTables, charts, dropdowns and Power Query that point at a table pick up new rows without edits.

Notes

  • Create: click in the data › ⌃T (Mac) / Ctrl+T (Win) › tick My table has headers
  • Rename it in Table Design › Table Name (e.g. Sales) before writing formulas
  • [@Amount] = the Amount value on this row; Sales[Amount] = the whole column
  • Total Row (Table Design) adds a SUBTOTAL row with a dropdown per column
  • Slicers (Table Design › Insert Slicer) are clickable filter buttons

Automate It

  • Point PivotTables, charts and validation lists at tables so new rows are picked up automatically
  • A table-based monthly import + Refresh All beats re-selecting ranges every month

Structured References

=[@Qty]*[@Price]                 # row formula; fills the whole column
=SUM(Sales[Amount])              # whole column, grows with the table
=SUMIFS(Sales[Amount], Sales[Region], "West")
=COUNTA(Sales[OrderID])          # number of rows
=Sales[[#Totals],[Amount]]       # value in the Total Row
=Sales[#Headers]                 # header row
=XLOOKUP(A2, Products[SKU], Products[Price])
=ROWS(Sales)                     # rows in the data body
=Sales[@[Qty]:[Price]]           # Qty through Price on this row

Code Explained

Excel writes these for you: click the cells while typing a formula inside or outside the table
Structured references don't need $; they don't shift when copied across columns of other tables
A calculated column (formula in a table column) is one formula, kept consistent for every row
The Total Row uses SUBTOTAL(109, …), so it ignores filtered-out rows

Other Suites

  • Google Workspace — Format › Convert to table ⌘⌥T; Table1[Column] references
  • Apple iWork — every Numbers table already has header rows; formulas use header names

Platform Differences

  • Windows — full tables + slicers
  • Mac — same; table shortcut is ⌃T
  • Web — create and use tables, slicers on newer builds

⚠ Common Mistakes

  • Leaving the default name Table1; rename tables before formulas reference them
  • Blank rows in the middle of data; the table still works but your eyes and filters suffer
  • Typing values over a calculated column, which breaks the column's consistency

✓ Tips & Best Practices

  • Press Tab in the last cell to add a row
  • Use Convert to Range if a file must go to an app that can't read tables
  • Turn off auto-fill of calculated columns per formula with the lightning-bolt button

Quick Summary

  • Ctrl+T — make a table
  • Table[Col] — whole column
  • [@Col] — this row
  • Total Row — SUBTOTAL that respects filters
