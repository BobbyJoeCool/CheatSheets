Excel Navigation & Selection

⌘↓ / Ctrl+↓ · ⇧ extend · Ctrl+Home / End · Name Box · Go To Special · Freeze Panes · select row / column

Get Around Big Sheets Without Scrolling

Ctrl+Arrow (⌘+Arrow on Mac) jumps to the edge of the current block of data; add Shift to select as you jump. The Name Box (left of the formula bar) jumps to any address or named range. Go To Special selects only blanks, formulas, constants or visible cells, which makes bulk fixes fast. Freeze Panes keeps headers on screen.

Notes

  • Ctrl+Home → A1; Ctrl+End → last used cell (shows leftover junk if it lands too far out)
  • Type B2:F500 or a range name in the Name Box and press Enter to select it
  • Go To Special: F5 / Ctrl+G › Special… (Mac: ⌃G › Special)
  • Select visible cells only: ⌘⇧Z (Mac) / Alt+; (Win), then copy filtered rows
  • Freeze: View › Freeze Panes freezes rows above and columns left of the active cell

Moving & Selecting

⌘↑ ↓ ← →       / Ctrl+↑ ↓ ← →     # jump to data edge
⇧⌘↓            / Ctrl+Shift+↓     # select to data edge
fn⌃←           / Ctrl+Home        # go to A1
fn⌃→           / Ctrl+End         # last used cell
⌃Space         / Ctrl+Space       # select column
⇧Space         / Shift+Space      # select row
⌘A             / Ctrl+A           # current region, again = whole sheet
⌥→ ←           / Ctrl+PgDn PgUp   # next / previous sheet
⌃G             / F5 or Ctrl+G     # Go To (then Special…)
⌘⇧Z            / Alt+;            # select visible cells only
⌃⌘\ / Ctrl+\  / Ctrl+\           # row differences

Code Explained

Jumps stop at the first blank cell, so gaps in your data break Ctrl+↓
Ctrl+A inside data selects the block (current region); press again for the whole sheet
After Go To Special › Blanks, type =↑ and press Ctrl+Enter to fill each blank from the cell above
Mac laptop shortcuts often need fn for Home / End / Page keys

Other Suites

  • Google Workspace — same ⌘↓ / Ctrl+↓ jumps; no Go To Special (use filters)
  • Apple iWork — Numbers: tables are separate objects; ⌥↑↓ add rows, ⌘↑↓ table edge

Platform Differences

  • Windows — every shortcut, Go To Special
  • Mac — same ideas, fn for Home / End, different sheet-switch keys
  • Web — arrows and Name Box work; Go To Special limited

⚠ Common Mistakes

  • Leaving stray formatting far below the data, so Ctrl+End and the scroll bar go to row 50,000
  • Copying a filtered range on the web and pasting hidden rows too; select visible cells first
  • Clicking A2 and choosing Freeze Panes when you wanted column A too; click B2

✓ Tips & Best Practices

  • Delete unused rows / columns below and right of the data, then save, to reset Ctrl+End
  • Name important ranges (sheet 15) and jump to them from the Name Box
  • Use Ctrl+Shift+↓ then Ctrl+Shift+→ to select a whole table in two keystrokes

Quick Summary

  • ⌘↓ / Ctrl+↓ — jump to edge
  • ⇧ + jump — select
  • F5 › Special — blanks, formulas, visible
  • Freeze Panes — keep headers visible
