Sheet 08

Long Documents

heading-based TOC · captions · cross-references · section breaks · different first page · page numbering · footnotes · F9

Reports, Theses and Manuals

Long documents depend on fields: a table of contents built from heading styles, captions that number figures automatically, and cross-references that say "see Figure 3" and stay correct when figures move. Section breaks let one document have different margins, orientation, headers or page numbering in different parts.

Notes

  • TOC: References › Table of Contents; it lists Heading 1–3 by default
  • Update all fields: select all (⌘A / Ctrl+A) then F9
  • Section break (Next Page) vs page break: only a section break can change headers or orientation
  • Link to Previous in a header ties it to the previous section; turn it off to make it different
  • Footnote: ⌥⌘F (Mac) / Ctrl+Alt+F (Win); endnote ⌥⌘E / Ctrl+Alt+D

Automate It

  • Record a macro: select all, F9, then update TOC; run it before every export
  • A template (sheet 04) with the cover, TOC and section setup already in place

Long-Document Keys & Fields

Insert › Break / Ctrl+Enter   # page break
⌥⌘F         / Ctrl+Alt+F       # insert footnote
⌥⌘E         / Ctrl+Alt+D       # insert endnote
⌘A then F9  / Ctrl+A then F9   # update every field
⌥F9         / Alt+F9           # show / hide field codes

{ TOC \o "1-3" \h \z \u }      # table of contents (levels 1–3, links)
{ SEQ Figure \* ARABIC }        # caption number
{ REF _Ref123 \h }              # cross-reference to a bookmark
{ PAGE }  of  { NUMPAGES }       # "Page 3 of 20"

Code Explained

Field codes in { } are what Word stores; you insert them through menus, not by typing braces
\o "1-3" = heading levels in the TOC; \h makes entries clickable links
Captions (References › Insert Caption) create SEQ fields that renumber automatically
Cross-references (References › Cross-reference) point at captions, headings or bookmarks

Other Suites

  • Google Workspace — Insert › Table of contents; Docs tabs for very long docs; no captions / cross-refs
  • Apple iWork — Pages: Insert › Table of Contents, section breaks, footnotes; no caption numbering fields

Platform Differences

  • Windows — every feature, Navigation pane drag-to-reorder
  • Mac — same features; some field shortcuts differ
  • Web — TOC, footnotes, section breaks; limited header / numbering control

⚠ Common Mistakes

  • Typing figure numbers by hand; insert captions so they renumber themselves
  • Changing a header and having it change in every section; turn off Link to Previous first
  • Exporting a PDF with a stale TOC; update fields (F9) right before you export

✓ Tips & Best Practices

  • Show formatting marks (⌘8 / Ctrl+Shift+8) to see and delete stray section breaks
  • Use Update Table › Update entire table after adding headings
  • Put front matter in its own section with roman numerals and restart body numbering at 1

Quick Summary

  • TOC — built from Heading styles
  • Captions + Cross-references — auto numbering
  • Section break — different headers / orientation
  • F9 — update fields
