⚠ Common Mistakes

  • Gantt dates that don't match dateFormat
  • Mindmap indentation mixed with tabs — use spaces consistently
  • Expecting %%{init}%% options to work when the host disables them (GitHub strict mode)

✓ Tips & Best Practices

  • Prefer the base theme when you set your own themeVariables
  • Keep styling in classDef so diagrams stay readable
  • Export SVG with mmdc for print and slides

Quick Summary

  • ER: ||, o|, }|, }o describe each end
  • Gantt: section, id, start, length, after
  • classDef + ::: style nodes
  • %%{init}%% or frontmatter configures a diagram
