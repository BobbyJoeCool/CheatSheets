Gantt — Tasks, Sections & Dates

gantt · dateFormat · axisFormat · section · task : id, start, 3d · after · done / crit · milestone

Tasks on a Calendar

A gantt chart draws tasks as bars on a date axis, grouped into sections. Each task line is Name : metadata, where the comma-separated metadata holds optional tags (done, active, crit, milestone), an optional id, a start (a date or after id) and an end (a date or a duration like 3d). dateFormat tells Mermaid how to read your dates; axisFormat sets how they print on the axis.

Rules

  • Tags come first, then id, then start, then end
  • No start given → the task starts when the previous one ends
  • after a b starts after the latest of tasks a and b
  • Durations: ms s m h d w M y — e.g. 1.5d
  • A milestone is a zero-length task: :milestone, m1, 2026-06-01, 0d

Release Plan

gantt
  title Release 2.0
  dateFormat YYYY-MM-DD
  axisFormat %b %d
  section Build
    Design       :done, des, 2026-03-02, 5d
    API          :active, api, after des, 8d
    UI           :ui, after des, 10d
  section Ship
    QA           :crit, qa, after api ui, 4d
    Launch       :milestone, after qa, 0d

Task Metadata

Example Meaning
:2026-03-02, 5d Start date + duration

Date Formats

Token Meaning
dateFormat YYYY-MM-DD Input: Day.js tokens
dateFormat HH:mm Input: times only
axisFormat %Y-%m-%d Axis: d3 time format
%b %d Mar 02
%a %e Mon 2
%H:%M 14:30
%W / %V Week number

⚠ Common Mistakes

  • Mixing up dateFormat (Day.js tokens like YYYY) and axisFormat (d3 tokens like %Y). They use different token systems.
  • Putting the id after the start date (:2026-03-02, des, 5d). The order is tags, id, start, end.
  • Referencing after x before task x is defined, or with a typo — Mermaid can't place the task and the chart fails.

✓ Tips & Best Practices

  • Give every task an id even if nothing references it yet; adding dependencies later is then one word.
  • Prefer after id over hard-coded dates so one slipped task moves everything that depends on it.
  • Mark only the true critical path crit; when everything is red nothing stands out.

Quick Summary

  • gantt + dateFormat — declaration and input dates
  • Task :tags, id, start, end — task line
  • after id — dependency
  • done · active · crit · milestone — tags
  • section — group rows
