Git Graph — Merges, Cherry-Picks & Options

merge · cherry-pick id: parent: · mainBranchName · showBranches · rotateCommitLabel · parallelCommits

Merging and Config

merge name joins another branch into the current one and creates a merge commit, which can take its own id, tag and type. cherry-pick id: "…" copies one commit from another branch onto the current one; for a merge commit you must also give parent:. Front matter config: gitGraph: controls the branch name, labels, ordering and whether parallel commits line up.

Rules

  • You can't merge a branch into itself
  • Cherry-pick source must be on a different branch
  • The current branch needs a commit before a cherry-pick
  • Branch colors come from git0 … git7 theme variables

Release Branch

---
config:
  gitGraph:
    mainBranchName: trunk
    rotateCommitLabel: false
---
gitGraph
  commit id: "A"
  branch release
  commit id: "B"
  checkout trunk
  commit id: "fix"
  checkout release
  cherry-pick id: "fix"
  checkout trunk
  merge release id: "M1" tag: "v2.0"

Rendered Output

Merge & Cherry-Pick

Syntax Effect
merge develop Merge develop into current
merge develop id: "M1" Merge commit id
merge develop tag: "v2" Tag the merge
merge develop type: REVERSE Merge commit type
cherry-pick id: "abc" Copy commit abc here
cherry-pick id: "M1" parent: "B" Pick a merge commit
cherry-pick id: "abc" tag: "t" Custom tag on the copy

Key Effect

mainBranchOrder: 2 Position of main

showCommitLabel: false Hide commit labels

⚠ Common Mistakes

  • Cherry-picking a commit that's already on the current branch. Mermaid throws an error; pick from another branch.
  • Cherry-picking a merge commit without parent:. A merge has two parents, so Mermaid needs to know which.
  • Expecting merge to fast-forward. Mermaid always draws a merge commit, even when Git wouldn't.

✓ Tips & Best Practices

  • Use rotateCommitLabel: false with short ids; rotated labels are easier only for long ones.
  • Tag merges, not ordinary commits, for release diagrams: merge release tag: "v2.0".
  • Hide labels (showCommitLabel: false) when the shape of history is the point, not the ids.

Quick Summary

  • merge name — merge commit on current branch
  • cherry-pick id: (parent:) — copy a commit
  • mainBranchName — rename main
  • showBranches / showCommitLabel — hide parts
  • git0…git7 — branch colors
