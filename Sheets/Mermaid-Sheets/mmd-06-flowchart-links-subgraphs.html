Links and Groups

Links connect nodes; the characters set the style (--> arrow, -.-> dotted, ==> thick) and the end (o, x, >). Text goes between pipes -->|text|. Chains and & let one line make several links. Subgraphs group nodes in a titled box and can have their own direction. Since v11 an edge can carry an id (e1@-->) so you can animate or restyle that one link.

Link Rules

  • Each extra dash makes a link span one more rank: ---->
  • linkStyle counts links from 0 in the order they are written
  • Links may point at a subgraph id as if it were a node
  • click only works with securityLevel: 'loose'
  • Escape commas in style values as \,

Link Types

Syntax Link
A --> B Arrow
A --- B Line, no arrowhead
A -.-> B Dotted arrow
A ==> B Thick arrow
A ~~~ B Invisible (layout only)
A --o B Circle end
A --x B Cross end
A <--> B Arrows on both ends
A ----> B Longer: +1 rank per dash
A -->|text| B Label (pipe form)
A -- text --> B Label (inline form)

Chains, IDs & Styles

Syntax Effect
A --> B --> C Chain of links
A & B --> C Two links into C
A --> B & C Two links out of A
A e1@--> B Give the edge id e1
e1@{ animate: true } Animate that edge
e1@{ animation: slow } Animate, fast / slow
e1@{ curve: linear } Curve for one edge (v11.10)
linkStyle 0 stroke:red Style link #0
linkStyle default … Style every link

Subgraphs & Clicks

Syntax Effect
subgraph id [Title] Open a titled group
end Close the group
direction LR Direction inside a subgraph
A --> groupId Link to a whole group
id@{ view: collapsed } Draw group as one node (v11.17)
click A "url" "tip" Open a link, with tooltip
click A href "url" _blank Link in a new tab
click A call fn() Run a page function

⚠ Common Mistakes

  • Counting linkStyle indexes from 1. They start at 0 and include every link, even ones made by & and chains.
  • Expecting direction inside a subgraph to win when its nodes link outside it; external links make the subgraph use the parent direction.
  • Starting the target id with o or x (A---oven) — Mermaid reads a circle or cross edge. Add a space: A--- oven.

✓ Tips & Best Practices

  • Use edge ids instead of linkStyle numbers: e1@{ … } keeps working when you reorder lines.
  • Use ~~~ invisible links to nudge layout without drawing anything.
  • Name subgraphs with an id and a title (subgraph api [Public API]) so you can link to them.

Quick Summary

  • --> / -.-> / ==> — arrow, dotted, thick
  • -->|text| — label a link
  • & — fan links in or out on one line
  • subgraph … end — titled group with its own direction
  • e1@--> + e1@{…} — style or animate one edge
