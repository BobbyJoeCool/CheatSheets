⚠ Common Mistakes

  • Using end as a node id — it closes the block; write End or quote it
  • Labels with ( ) [ ] { } unquoted — wrap the text in "…"
  • graph vs flowchart — newer features (shapes, &) need flowchart

✓ Tips & Best Practices

  • Test in the Mermaid Live Editor before pasting into docs
  • Pick LR for wide pipelines and TD for trees
  • Use autonumber in long sequence diagrams

Quick Summary

  • First line names the diagram type
  • Flowcharts: shapes by brackets, links by arrows
  • Sequence: ->> calls, -->> replies, loop / alt blocks
  • Class: <|-- inherits, *-- composes
