Overlapping Sets

A venn-beta diagram draws sets as overlapping circles. Declare each set with set, then name overlaps with union A,B["Label"]; unions can join three or more sets and Mermaid fills in the implied pairwise overlaps. Indented text lines put items inside the most recent set or union, and :N suffixes change relative sizes. It's one of the v12 types that defaults to redux-color and neo.

Notes

  • Sets in a union must be declared earlier with set
  • Ids: bare words or quoted strings
  • ["…"] sets the display label, keeping a short id
  • Added in v11.12.3; syntax may change

Product Fit

venn-beta
  title Good product idea
  set D["Desirable"]
  set F["Feasible"]
  set V["Viable"]
  union D,F["Buildable"]
  union F,V["Sustainable"]
  union D,F,V["Ship it"]
    text s1["MVP"]
  style D fill:#cfe2ff

⚠ Common Mistakes

  • Using a set in union before declaring it with set. Every id in a union must already exist.
  • Expecting exact areas. Sizes are relative hints; the layout still has to fit circles together.
  • Going beyond three sets. Four-set Venns are hard to draw and harder to read; consider a table.

✓ Tips & Best Practices

  • Keep set ids to one letter and put words in the labels: set D["Desirable"].
  • Use text items for examples so readers see what lives in each region.
  • Lower fill-opacity if overlaps look muddy.
