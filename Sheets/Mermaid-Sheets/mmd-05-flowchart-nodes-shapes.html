Sheet 05

Flowchart — Nodes, Shapes & Direction

flowchart TD / LR · id[text] · {decision} · [(database)] · @{ shape: }

Nodes and Direction

A flowchart draws nodes joined by links. The declaration sets the direction (TD, LR, …). A node is an id plus optional text in brackets, and the bracket style picks the shape: [ ] box, ( ) rounded, { } diamond. Since v11.3 you can also name any of 50+ shapes with id@{ shape: doc, label: "…" }. In v12, flowcharts default to the redux-color theme and neo look.

Node Rules

  • graph is the older keyword; flowchart has more features — use it
  • Declare an id once; later mentions reuse the same node
  • With no text, the id is the label: A draws a box labeled A
  • Quote labels with symbols: A["Save (draft)"]
  • Unicode works in quotes: A["Größe • Café"]

Order Handling

flowchart TD
  start([Start]) --> read[/Read order/]
  read --> stock{In stock?}
  stock --> ship[[Ship order]]
  stock --> wait(Back-order)
  ship --> db[(Orders DB)]
  ship --> inv@{ shape: doc, label: "Invoice" }
  wait --> stop(((Stop)))

Direction & Text

Syntax Meaning
flowchart TD Top → down (same as TB)
flowchart BT Bottom → top
flowchart LR Left → right
flowchart RL Right → left
A@{ shape: x, label: "…" } Named shape with label
A["`**bold** *it*`"] Markdown string, wraps
A@{ icon: "fa:user" } Icon shape (needs icon pack)
A@{ img: "url" } Image shape

⚠ Common Mistakes

  • Writing end as node text. Lowercase end closes a subgraph and breaks the chart; use End or ["end"].
  • Giving one id two different labels. They are one node, and the later text replaces the earlier one.
  • Using @{ shape: … } on a platform running Mermaid older than 11.3 — the whole diagram fails to parse.

✓ Tips & Best Practices

  • Use stadium ([ ]) for start and end, and diamond { } only for decisions, so readers can scan the flow.
  • Keep ids short (chk) and put the words in the label (chk{Valid?}); ids are what you type in links.
  • Prefer LR for pipelines and TD for decision trees and hierarchies.

Quick Summary

  • flowchart TD|LR|BT|RL — declaration sets direction
  • id[text] — brackets choose the shape
  • id@{ shape: name } — 50+ named shapes
  • "…" — quote labels with symbols or Unicode
