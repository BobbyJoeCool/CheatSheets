Relationships Between Classes

A relationship line connects two classes: A <|-- B means B inherits from A. The arrow end shows the kind of relationship (inheritance, composition, aggregation, association, dependency, realization) and the line shows solid (--) or dashed (..). Add a label after a colon, cardinality in quotes next to each class, and notes with note for. Arrowheads can point either way.

Notes

  • Solid -- = structural link; dashed .. = uses / implements
  • Cardinality strings go next to the class they describe
  • Two-way arrows: put a marker on both ends, <|--|>
  • bar ()-- foo draws a lollipop interface

Rendered Output

Relationship Types

Syntax Meaning
A <|-- B Inheritance: B extends A
A *-- B Composition: B dies with A
A o-- B Aggregation: A has B
A --> B Association
A -- B Link (solid)
A ..> B Dependency: A uses B
A ..|> B Realization: A implements B
A .. B Link (dashed)
A ()-- B Lollipop interface A on B

Labels & Cardinality

Syntax Meaning
A --> B : uses Label
A "1" --> "*" B Cardinality both ends
"0..1" Zero or one
"1..*" One or more
"n" Exactly n
A <|--|> B Two-way relationship
B --|> A Same as A <|-- B

Notes, Links & Layout

Syntax Meaning
note "text" Free-floating note
note for A "text" Note attached to a class
direction LR TB (default), BT, LR, RL
link A "url" "tip" Clickable class
click A href "url" Same, click form
style A fill:#eef Style one class

⚠ Common Mistakes

  • Reversing inheritance: Dog <|-- Animal says Animal extends Dog. The triangle points at the parent.
  • Using composition *-- for any "has a". Composition means the part can't exist without the whole; otherwise use o-- or -->.
  • Placing cardinality after the colon. Quotes go next to the class names: A "1" --> "*" B : label.

✓ Tips & Best Practices

  • Keep the parent above or left of children (direction helps) so inheritance trees read naturally.
  • Use dashed dependency ..> for "calls" and solid association --> for "stores a reference".
  • Put business rules in note for instead of long labels on lines.

Quick Summary

  • <|-- / ..|> — extends / implements
  • *-- / o-- — composition / aggregation
  • --> / ..> — association / dependency
  • "1" --> "*" — cardinality
  • note for A — notes on classes
