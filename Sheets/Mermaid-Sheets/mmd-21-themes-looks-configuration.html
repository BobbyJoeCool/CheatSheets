Changing the Whole Diagram

Three settings change how an entire diagram looks: theme (colors), look (line style: classic, handDrawn, neo) and layout (the engine that places nodes). Set them for one diagram in front matter under config:, or for a whole site in mermaid.initialize(). Since v12, ten diagram types (flowchart, sequence, class, state, ER, requirement, use case, venn, swimlane, agentflow) default to the redux-color theme and neo look; the rest use default and classic.

Notes

  • Front matter config: is the supported per-diagram method
  • Scope a setting to one type: config: flowchart: look: handDrawn
  • ELK is bundled in v12; layout: dagre gives the older layout
  • Get the pre-v12 look back: theme: default + look: classic
  • Platforms (GitHub, Obsidian) may ignore or limit config

Front Matter Config

---
config:
  theme: forest
  look: handDrawn
  layout: dagre
  flowchart:
    curve: stepBefore
---

⚠ Common Mistakes

  • Customizing themeVariables on a theme other than base. Only base can be modified; other themes ignore most variables.
  • Indenting front matter keys inconsistently. It's YAML: theme: must sit two spaces under config:.
  • Relying on %%{init}%% in new docs. It's deprecated since v10.5; use front matter.

✓ Tips & Best Practices

  • Use theme: neutral for documents that will be printed in black and white.
  • Set site-wide choices once in initialize() and keep front matter for exceptions.
  • Pin theme, look and layout explicitly in docs you publish so a Mermaid upgrade doesn't change them.

Quick Summary

  • config: — per-diagram settings in front matter
  • theme — colors (base is customizable)
  • look — classic, handDrawn, neo
  • layout — dagre, elk, cose-bilkent, …
  • initialize() — site-wide defaults
