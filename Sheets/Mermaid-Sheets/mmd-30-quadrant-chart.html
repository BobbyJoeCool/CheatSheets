Quadrant Chart

quadrantChart · x-axis Low --> High · y-axis · quadrant-1 … 4 · Point: [x, y] · radius / color

Two Axes, Four Boxes

A quadrantChart plots items on two axes and splits the space into four labeled quadrants, like an effort/impact or urgent/important matrix. Name each axis with a low and high label (x-axis Low --> High), label the quadrants, then list points as Name: [x, y] with coordinates from 0 to 1. Points can be styled inline or with classDef.

Notes

  • Coordinates run from 0 to 1 on both axes
  • quadrant-1 is top right, then counter-clockwise
  • Axis labels: x-axis Left --> Right; right part optional
  • Style order: inline style, then class, then theme

⚠ Common Mistakes

  • Using raw scores ([30, 80]). Coordinates must be scaled to 0–1.
  • Assuming quadrant-1 is top left. It's top right, then counter-clockwise like the math convention.
  • Writing the class before the colon in the wrong place: it's Name:::class: [x, y].

✓ Tips & Best Practices

  • Put the "good" direction up and right so quadrant-1 means "best" or "most attention".
  • Keep point names short; long names overlap in dense areas.
  • Use one highlight color for the items being discussed and leave the rest default.

Quick Summary

  • quadrantChart — declaration
  • x-axis / y-axis Low --> High — axes
  • quadrant-1…4 — labels, starting top right
  • Name: [x, y] — points from 0 to 1
