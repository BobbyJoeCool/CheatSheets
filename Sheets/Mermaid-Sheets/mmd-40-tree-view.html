Folder and File Trees

A treeView-beta diagram draws a directory tree with connector lines. Structure comes only from indentation, and a trailing / marks a directory (drawn in bold). You can paste an existing tree drawn with box characters (├──, └──, │) and Mermaid detects it automatically. Annotate entries with ## description, :::highlight, or an icon(); file and folder icons are off unless showIcons is set.

Notes

  • Quote names with spaces: "my file.txt"
  • Tabs are expanded to spaces
  • Box-drawing and indentation styles both work
  • Annotations combine in any order
  • Added in v11.14

Project Layout

---
config:
  treeView:
    showIcons: true
---
treeView-beta
  my-app/
    src/
      main.ts :::highlight ## entry point
      routes/
        index.ts
    tests/
    package.json ## scripts and deps
    README.md

Annotations

Syntax Effect

treeView: Config

Key Effect
showIcons: true Built-in file / folder icons
defaultIconPack Pack for bare icon names
extensionIcons Map .ts → icon
filenameIcons Map Dockerfile → icon

⚠ Common Mistakes

  • Forgetting the trailing / on folders. An empty folder then looks like a file.
  • Mixing box-drawing lines and plain indentation in one tree; pick one style.
  • Expecting file-type icons out of the box. Mermaid ships no mapping; set extensionIcons with a registered pack.

✓ Tips & Best Practices

  • Paste the output of the tree command straight in — the box characters are understood.
  • Use ## … descriptions instead of a separate table explaining what each file does.
  • Highlight only the files a reader should open first.
