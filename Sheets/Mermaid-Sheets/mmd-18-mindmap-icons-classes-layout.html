Decorating Nodes

Mindmap nodes can carry an icon and CSS classes, each written on its own line directly under the node: ::icon(fa fa-book) and :::urgent. Icons use icon-font classes (Font Awesome, Material Design Icons) that the page must load. Markdown strings give bold, italic and automatic wrapping. Config keys control colors by depth and the layout engine; tidy-tree gives a neat, balanced tree when its plugin is registered.

Notes

  • ::icon() and ::: lines go under the node they decorate
  • Icon fonts must be loaded by the page, not the diagram
  • ::: adds page CSS classes — define them in the site's CSS
  • Mindmap icon syntax is still marked experimental
  • Indentation rules from sheet 17 still apply

⚠ Common Mistakes

  • Putting ::icon() on the same line as the node text. It must be its own line, indented under the node.
  • Expecting icons to appear on GitHub: the platform doesn't load Font Awesome, so the icon slot stays empty.
  • Using layout: tidy-tree without registering @mermaid-js/layout-tidy-tree. Mermaid falls back to another layout and logs a warning.

✓ Tips & Best Practices

  • Use colorBy: depth when levels matter more than branches (outlines, study guides).
  • Use markdown strings for long node text so it wraps instead of making very wide nodes.
  • Export big mindmaps with mmdc -s 2 for crisp PNGs in slides.

Quick Summary

  • ::icon(…) — icon under a node
  • :::class — CSS classes under a node
  • "…" — markdown strings
  • colorBy / layout — color and layout config
