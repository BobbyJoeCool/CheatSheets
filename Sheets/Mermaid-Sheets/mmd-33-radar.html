Radar beta

radar-beta · axis · curve name{ } · max / min · graticule circle / polygon · ticks · showLegend

Scores on Several Axes

A radar-beta chart (also called spider chart) compares several items across the same set of axes arranged in a circle. Declare axes with axis id["Label"], then add one curve per item with a list of values in axis order, or as axis: value pairs. Options set the scale (max, min), the grid shape (graticule circle or polygon) and the number of rings (ticks).

Notes

  • Several axes or curves can share a line, comma-separated
  • Values follow axis order unless written as id: value
  • Without max, the largest data value sets the scale
  • Curve colors come from cScale0, cScale1, …
  • Added in v11.6

Framework Comparison

radar-beta
  title Frameworks
  axis perf["Speed"], dx["DX"], eco["Ecosystem"]
  axis learn["Learning"], size["Bundle"]
  curve a["Framework A"]{4, 5, 5, 3, 2}
  curve b["Framework B"]{5, 3, 2, 4, 5}
  max 5
  min 0
  graticule polygon
  ticks 5

Syntax

Syntax Meaning
radar-beta Declaration
title Text Title
axis a, b, c Axes (ids as labels)
axis a["Speed"] Axis with label
curve x["Name"]{1, 2, 3} Values in axis order
curve y{ c: 3, a: 1, b: 2 } Values by axis id

Options

Option Effect
max 100 Outer ring value
min 0 Center value (default 0)
graticule circle Round grid (default)
graticule polygon Straight-edged grid
ticks 5 Number of rings
showLegend false Hide legend

Styling

Setting Controls

⚠ Common Mistakes

  • Giving a curve fewer values than there are axes. The missing axes get no point; use the id: value form if data is partial.
  • Comparing values on different scales (price in $ next to a 1–5 score). Normalize everything to one scale first.
  • Plotting more than about four curves; overlapping fills become unreadable.

✓ Tips & Best Practices

  • Make "higher is better" true for every axis (invert cost-type metrics) so a bigger shape always means better.
  • Set max explicitly so two charts can be compared side by side.
  • Use graticule polygon when there are few axes; it reads more like a grid.

Quick Summary

  • radar-beta — declaration
  • axis id["Label"] — axes
  • curve id["Name"]{…} — one series
  • max · min · graticule · ticks — scale and grid
