stateDiagram-v2 · [*] · state "…" as s1 · s1 --> s2 : event · note · direction

States and Transitions

A stateDiagram-v2 shows the states something can be in and the transitions between them. s1 --> s2 : event draws a labeled arrow; [*] is the start state when it is on the left of an arrow and the end state when it is on the right. A state is created the first time you mention it; give it a longer description with state "…" as id or id : description. Since v12 state diagrams default to the redux-color theme and neo look.

Notes

  • Use stateDiagram-v2; stateDiagram is the older renderer
  • [*] --> A = start; A --> [*] = end
  • Names with spaces need an id: state "Out for delivery" as ofd
  • Notes can span lines with note left of X … end note

Order Lifecycle

stateDiagram-v2
  direction LR
  [*] --> Pending
  Pending --> Paid : pay
  Pending --> Cancelled : cancel
  Paid --> Shipped : ship
  state "Out for delivery" as ofd
  Shipped --> ofd
  ofd --> Delivered : sign
  Delivered --> [*]
  Cancelled --> [*]
  note right of Paid : Payment captured

Transitions

Syntax Meaning

A --> A : retry Self-transition

Notes

Syntax Meaning
note right of A : text One-line note
note left of A Start a multi-line note
…lines… Note body
end note Close the note

⚠ Common Mistakes

  • Using plain stateDiagram. It still parses, but stateDiagram-v2 is the maintained renderer and supports more syntax.
  • Writing a state name with spaces directly (Out for delivery --> Done). Declare state "Out for delivery" as ofd first.
  • Expecting [*] to be one shared node. Each [*] inside a composite state is its own start or end.

✓ Tips & Best Practices

  • Label every transition with the event that causes it; unlabeled arrows hide the important part.
  • Use direction LR for linear lifecycles and the default top-down for branching ones.
  • Keep ids short and lowercase, descriptions human: ofd : Out for delivery.

Quick Summary

  • stateDiagram-v2 — declaration
  • A --> B : event — labeled transition
  • [*] — start (left of arrow) or end (right of arrow)
  • state "…" as id — long names
  • note right of A : … — notes
