Styling Elements & Theme Variables

classDef · class · ::: · style · linkStyle · themeVariables · primaryColor · hex only

Styling Parts of a Diagram

To style individual elements, define a reusable class with classDef name props and attach it with class id name or id:::name; use style id props for a one-off and linkStyle n props for links. Props are CSS-like (fill, stroke, color). To restyle everything at once, use the base theme and override theme variables in front matter; Mermaid derives the remaining colors from the ones you set.

Notes

  • Theme variables accept hex colors only — #ff0000, not red
  • classDef default … styles every node without a class
  • Separate props with commas; escape commas inside values as \,
  • Multiple classes: classDef a,b fill:#eee

Classes, Styles and Variables

---
config:
  theme: base
  themeVariables:
    primaryColor: "#e8f0fe"
    primaryBorderColor: "#3367d6"
    lineColor: "#5f6368"
---
flowchart LR
  A[Draft]:::muted --> B[Review] --> C[Live]
  classDef muted fill:#f1f3f4,color:#80868b
  classDef go fill:#d4edda,stroke:#28a745
  class C go
  style B stroke-dasharray: 5 5
  linkStyle 1 stroke:#28a745,stroke-width:2px

⚠ Common Mistakes

  • Writing color names in themeVariables (primaryColor: blue). The theme engine only understands hex.
  • Using classDef in diagrams that don't support it. It works in flowchart, state, class, ER, requirement, block, use case and a few others — not sequence or gantt.
  • Counting linkStyle from 1. Indexes start at 0 in the order links are written.

✓ Tips & Best Practices

  • Name classes by meaning (error, done), not by color, so a palette change is one line.
  • Set just primaryColor first; Mermaid derives borders and secondary colors to match.
  • Prefer edge ids (e1@{ … }, sheet 06) over linkStyle numbers in diagrams that change often.

Quick Summary

  • classDef + class / ::: — reusable styles
  • style id … — one-off style
  • linkStyle n … — style links
  • theme: base + themeVariables — global palette
  • #hex — the only color format theme variables accept
