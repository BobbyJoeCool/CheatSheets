⚠ Common Mistakes

  • Dropping -beta. Swimlane, use case, radar, treemap, Venn, architecture, tree view, Ishikawa, Wardley and Cynefin still need it.
  • Named colors in themeVariables. Only hex values work: #ff0000, not red.
  • Writing new diagrams with %%{init}%%. It is deprecated; use config: in front matter.

✓ Tips & Best Practices

  • Use theme: neutral (or base with your colors) for print.
  • Try look: handDrawn for drafts, so readers know the design isn't final.
  • Pin the Mermaid version in your CDN URL. v12 changed default looks for 10 diagram types.

Quick Summary

  • Declaration picks the type: 31 types, newest end in -beta
  • config: sets theme, look and layout
  • classDef + ::: for reusable styles
  • mmdc for files, mermaid.run() for pages
