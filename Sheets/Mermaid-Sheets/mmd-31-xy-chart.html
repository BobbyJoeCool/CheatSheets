XY Chart

xychart · x-axis [categories] · y-axis min --> max · bar · line · horizontal · showDataLabel

Bars and Lines

An xychart draws bar and line series against an x-axis and a y-axis. The x-axis is usually a list of categories in square brackets; it can also be a numeric range. The y-axis is always numeric: give it a title and an optional min --> max. Each bar [ … ] or line [ … ] adds a series with one value per category; name a series to put it in the legend (v11.17). xychart horizontal turns the chart sideways.

Notes

  • Text with spaces needs quotes: "Revenue ($)"
  • No y range → Mermaid picks one from the data
  • xychart-beta still works as an alias
  • showDataLabel: true prints values on bars (v11.14)

Monthly Signups

xychart
  title "Signups 2026"
  x-axis [Jan, Feb, Mar, Apr, May, Jun]
  y-axis "Users" 0 --> 1200
  bar "Signups" [420, 510, 640, 700, 930, 1100]
  line "Target" [500, 550, 600, 700, 800, 900]

⚠ Common Mistakes

  • Giving a series a different number of values than there are categories. Extra or missing values misalign the chart.
  • Forgetting quotes around titles with spaces: y-axis Revenue in $ fails; use "Revenue in $".
  • Trying categories on the y-axis. Only the x-axis can be categorical.

✓ Tips & Best Practices

  • Set the y range explicitly (0 --> …) so bars aren't exaggerated by an auto range that doesn't start at 0.
  • Name series when there are two or more, so the legend explains them.
  • Change colors with themeVariables: xyChart: plotColorPalette: "#4e79a7, #f28e2b".

Quick Summary

  • xychart (horizontal) — declaration
  • x-axis [cats] / y-axis min --> max — axes
  • bar [ … ] / line [ … ] — series
  • "Name" before values — legend entry
