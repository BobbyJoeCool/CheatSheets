⚠ Common Mistakes

  • Lowercase end as node text breaks a flowchart. Write End or quote it.
  • A node name starting with o or x right after a link (A---oB) turns into a circle / cross end. Add a space.
  • Mixing tabs and spaces. Mindmap, treemap, tree view and Ishikawa use indentation as structure.

✓ Tips & Best Practices

  • Keep ids short and put the wording in labels: A["Long label (x)"].
  • Paste into mermaid.live to check a diagram before you commit it.
  • Arrows read the same across types: --> solid, -.-> / ..> dashed.
