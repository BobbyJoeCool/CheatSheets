What is Mermaid?

Mermaid is a JavaScript library that turns plain-text definitions into diagrams. You write a few lines of text, and Mermaid parses them and draws an SVG. Knut Sveidqvist started it in 2014. Because the source is text, diagrams live next to your code, show up in diffs and code review, and never go stale in a separate drawing tool. This set targets Mermaid 12.x (12.2.0) and covers all 31 diagram types in the official docs.

Good to Know

  • In Markdown, put the diagram in a ```mermaid code fence
  • Standalone source files use .mmd or .mermaid
  • Types marked beta need the suffix on line 1, e.g. venn-beta
  • A diagram that is just info prints the Mermaid version in use
  • Renders on these sheets use a light print theme, not Mermaid's v12 defaults (sheet 21)

⚠ Common Mistakes

  • Labeling the fence ```mmd on GitHub. Only the language name mermaid is rendered; anything else shows as plain code.
  • Assuming every platform runs the newest Mermaid. GitHub, GitLab and Obsidian bundle their own version, so beta types and new syntax may fail there.
  • Starting with a capitalized or misspelled declaration (Flowchart, sequencediagram). The first line must match the keyword exactly.

✓ Tips & Best Practices

  • Prototype in mermaid.live, then paste the text into your doc. The share link keeps the diagram in the URL.
  • Render an info diagram on a platform to see which Mermaid version it runs before using newer syntax.
  • Keep large diagrams in .mmd files and render them in CI with mmdc, so broken syntax fails the build.

Quick Summary
