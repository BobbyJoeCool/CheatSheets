Nested and Parallel States

A composite state holds its own sub-diagram: state Active { … }, with its own [*] start and end. Choice points (<<choice>>) branch on a condition, and fork / join bars (<<fork>>, <<join>>) split into parallel paths and merge them again. Inside a composite state, a line of -- separates concurrent regions that run at the same time. Style states with classDef and class or the ::: shortcut.

Notes

  • Composite states can nest several levels deep
  • You can transition into or out of the composite as a whole
  • Choice / fork / join are declared with state id <<type>>
  • classDef can't style the start / end states

Composite & Regions

Syntax Meaning
state Active { … } Composite state
state "Long" as L { … } Composite with a display name
[*] --> First Start inside the composite
-- Separator between concurrent regions
Active --> Done Leave the composite
direction LR (inside) Direction for that composite

Choice, Fork & Join

Syntax Meaning
state c <<choice>> Decision diamond
c --> A : x > 0 Guarded branch
state f <<fork>> Split into parallel paths
state j <<join>> Merge parallel paths
f --> A / f --> B Paths leave the fork
A --> j / B --> j Paths enter the join

Styling States

Syntax Meaning
classDef bad fill:#fdd Define a class
class A, B bad Apply to states
A:::bad --> B Apply inline
classDef bad,warn … Define two at once
style A fill:#eef Style one state

⚠ Common Mistakes

  • Forgetting the inner [*] in a composite state. Without it, the region has no visible starting point.
  • Putting -- outside a composite state. Concurrency separators only work inside state X { }.
  • Linking a fork to a join with no states between them — the bars overlap and the diagram becomes unreadable.

✓ Tips & Best Practices

  • Use a composite state when the same group of states is entered and left as one unit, such as Checkout.
  • Prefer <<choice>> with guard labels over two unlabeled arrows from a normal state.
  • Define one classDef per meaning (error, done) and reuse it, rather than styling states one by one.

Quick Summary

  • state X { … } — composite state with its own [*]
  • <<choice>> — branch on a condition
  • <<fork>> / <<join>> — split and merge
  • -- — concurrent regions inside a composite
  • classDef + class / ::: — style states
