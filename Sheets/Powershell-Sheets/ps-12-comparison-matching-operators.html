Sheet 12

Comparison & Matching Operators

-eq -ne -gt -lt · -ceq · -like / -notlike · -match / -notmatch · -contains / -in · array filters

Overview

Comparison operators are words, not symbols (> is redirection!). They are case-insensitive by default; prefix with c for case-sensitive (-ceq). When the left side is an array, the operator acts as a filter and returns the matching elements instead of True/False.

Notes

  • -like uses wildcards; -match uses regex
  • -contains tests collection membership, not substrings
  • Put $null on the left: $null -eq $x
  • Right side is converted to the left side’s type

Comparing Values

5 -eq 5                    # True
'abc' -eq 'ABC'            # True  (case-insensitive)
'abc' -ceq 'ABC'           # False
10 -gt 9                   # True
'10' -gt '9'               # False (string comparison)

'report.pdf' -like '*.pdf' # True
'v1.2.3' -match '^v(\d+)'  # True; $Matches[1] = '1'
'abc' -notmatch '\d'       # True

1, 2, 3, 2 -eq 2           # 2 2   (filter, not bool)
1, 5, 9 -gt 4              # 5 9
'a', 'b' -contains 'b'     # True
'b' -in 'a', 'b'           # True
'hello' -contains 'ell'    # False (not a substring test!)

$null -eq $items           # safe null test

Code Explained

-eq — equality; -ne for not equal
'10' -gt '9' — string on the left → alphabetical compare
-match — regex; fills $Matches on scalar input
1,2,3,2 -eq 2 — array on left → returns matching items
-contains / -in — same test, collection on opposite sides
$null -eq — with an array on the left you’d get a filter instead

⚠ Common Mistakes

  • Using > or ==. > redirects output to a file named after the right side; use -gt and -eq
  • Writing if ($list -eq $null). With an array on the left this filters and is usually falsy; write $null -eq $list
  • Using -contains for substrings. It checks whole items; use -like '*x*' or .Contains()

✓ Tips & Best Practices

  • Use -in in Where-Object for allow-lists: Where-Object Status -in 'Running','Paused'
  • Cast both sides when types are unclear: [int]$a -gt [int]$b
  • Anchor regexes (^…$) when you need a whole-string match

Quick Summary

  • -eq -ne -gt -lt -ge -le — compare; c prefix = case-sensitive
  • -like wildcard vs -match regex
  • -contains / -in — collection membership
  • Array on left — operator filters elements
