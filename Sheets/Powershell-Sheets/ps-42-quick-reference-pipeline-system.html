⚠ Common Mistakes

  • Format-* in the middle of a pipeline — it outputs formatting objects, not data
  • ConvertTo-Json without -Depth silently truncating nested objects
  • Export-Csv in Windows PowerShell 5.1 adding a type header (use -NoTypeInformation)

✓ Tips & Best Practices

  • Filter left: use -Filter on the source cmdlet before Where-Object
  • Use Invoke-RestMethod — it parses JSON into objects for you
  • Install modules with -Scope CurrentUser to avoid admin rights

Quick Summary

  • Where / ForEach / Select / Sort — the core pipeline
  • Get-Content / Set-Content for text, Import-Csv for data
  • Invoke-RestMethod for APIs
  • Invoke-Command for remote work
