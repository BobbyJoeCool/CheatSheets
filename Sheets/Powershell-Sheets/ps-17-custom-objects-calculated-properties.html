Sheet 17

Custom Objects & Calculated Properties

[PSCustomObject]@{} · @{Name=; Expression=} · -ExcludeProperty · Add-Member · Compare-Object · Tee-Object

Overview

Build your own output objects with [PSCustomObject]@{ }: they sort, filter, export to CSV/JSON and format just like built-in objects. Calculated properties add or reshape properties on the fly inside Select-Object, Sort-Object or Format-Table using a small hashtable with a name and an expression.

Notes

  • [PSCustomObject] keeps keys in the order you wrote them
  • Keys: Name (or n, Label, l) and Expression (e)
  • Return objects from functions, not formatted text
  • Select-Object outputs new objects (a copy)

Building and Reshaping Objects

$report = [PSCustomObject]@{
    Server = 'web01'
    CPU    = 37.5
    Online = $true
}                                   # $report.Server → web01

Get-ChildItem -File | Select-Object Name,
    @{ Name = 'MB'; Expression = { [math]::Round($_.Length / 1MB, 2) } },
    @{ n = 'Age'; e = { ((Get-Date) - $_.LastWriteTime).Days } }

Get-Process | Select-Object * -ExcludeProperty *Memory*

$report | Add-Member -NotePropertyName Owner -NotePropertyValue 'ops'
$report | Add-Member -MemberType ScriptProperty -Name Busy `
    -Value { $this.CPU -gt 80 }

Compare-Object (Get-Content a.txt) (Get-Content b.txt)
Get-Process | Tee-Object -Variable procs | Sort-Object CPU

Code Explained

[PSCustomObject]@{} — ordered, typed object; fastest way to build output
@{Name=…; Expression={…}} — calculated property; $_ is the input object
n / e — short keys for Name and Expression
-ExcludeProperty — works with * to drop properties
ScriptProperty — computed every time it’s read; $this is the object
Compare-Object — <= only in left, => only in right

⚠ Common Mistakes

  • Using New-Object PSObject -Property @{}. Property order is lost; [PSCustomObject]@{} keeps it and is faster
  • Building strings like "$name - $size" as function output. Callers can’t sort or export text; return objects
  • Forgetting -PassThru on Add-Member mid-pipeline, so nothing flows on

✓ Tips & Best Practices

  • Build arrays of objects in a loop: $rows = foreach ($s in $servers) { [PSCustomObject]@{…} }
  • Use Select-Object -Property *,@{n='X';e={…}} to keep all properties and add one
  • Use $obj.PSObject.Properties to loop over an object’s property names and values

Quick Summary

  • [PSCustomObject]@{} — create an ordered object
  • @{n='X'; e={…}} — calculated property
  • Add-Member — add properties after creation
  • Compare-Object — diff two sets
