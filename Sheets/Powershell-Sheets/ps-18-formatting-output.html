Sheet 18

Formatting Output

Format-Table · Format-List · Format-Wide · format-right rule · Out-String · Out-GridView

Overview

Format-* cmdlets control how objects look on screen. They convert objects into formatting instructions, so they must come last in a pipeline (the format-right rule). If you need to save or process the data, use Select-Object and Export-Csv instead.

Notes

  • Objects with 5+ properties default to a list view
  • Format-Table truncates long values with … unless -Wrap
  • $FormatEnumerationLimit (default 4) cuts off arrays in output
  • Out-GridView is Windows-only (7: GraphicalTools module)

Shaping Screen Output

Get-Process | Format-Table Name, Id, CPU -AutoSize
Get-Service | Format-Table -GroupBy Status -Property Name
Get-ChildItem | Format-Table Name,
    @{ n = 'KB'; e = { $_.Length / 1KB }; FormatString = 'N1' }

Get-Process pwsh | Format-List *        # every property
Get-Process pwsh | Format-List Name, Path, StartTime
Get-ChildItem | Format-Wide Name -Column 4

$text = Get-Process | Format-Table | Out-String -Width 200
Get-Service | Out-GridView -PassThru | Restart-Service

Get-Process | Select-Object Name, CPU |
    ConvertTo-Html -Title 'Processes' | Out-File procs.html

$FormatEnumerationLimit = -1            # show full arrays

Code Explained

-AutoSize — fits columns to content (waits for all input)
-GroupBy — a sub-table per group; sort by that property first
FormatString — number format inside a calculated column
Format-List * — best way to see all properties and values
Out-String — render formatted output into a string
-PassThru — Out-GridView returns the rows you select

Right vs Wrong

PipelineResult
… | Select | Export-Csv✔ real data
… | ft | Export-Csv✖ junk rows
… | Sort | ft✔ sorted table
… | ft | Sort✖ error / junk
… | ft | Out-File✔ text file

⚠ Common Mistakes

  • Piping Format-Table into Export-Csv or Where-Object. You get formatting objects, not data; format last
  • Returning Format-Table output from a function. Callers can’t use it; return objects and let them format
  • Expecting Out-GridView on Linux/macOS. It needs the GraphicalTools module there

✓ Tips & Best Practices

  • Use Format-List * to discover property names quickly
  • Use ft -AutoSize -Wrap for long paths or messages
  • Use $PSStyle.Formatting (7.2+) to change table header colors

Quick Summary

  • Format-Table / ft — columns
  • Format-List / fl — property list; fl * shows all
  • Format right — always the last command
  • Out-String / ConvertTo-Html — formatted text or HTML
