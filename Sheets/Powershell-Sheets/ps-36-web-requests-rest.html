Sheet 36

Web Requests & REST APIs

Invoke-RestMethod · Invoke-WebRequest · -Method / -Headers / -Body · ConvertTo-Json body · -Authentication Bearer · -OutFile

Overview

Invoke-RestMethod calls an API and parses the response (JSON or XML) into objects, so you can use properties right away. Invoke-WebRequest returns the raw response: status code, headers, content, links. Use it for downloads, scraping, or when you need the status and headers.

Notes

  • JSON responses become PSCustomObjects automatically
  • Send JSON with ConvertTo-Json + -ContentType 'application/json'
  • -Authentication Bearer -Token needs a SecureString (7+)
  • 5.1 may need TLS 1.2 enabled and -UseBasicParsing

Calling APIs

$repo = Invoke-RestMethod https://api.github.com/repos/PowerShell/PowerShell
$repo.stargazers_count                   # star count (a number)

$body = @{ title = 'Bug'; labels = @('ps') } | ConvertTo-Json
$params = @{
    Uri     = 'https://api.example.com/issues'; Method = 'Post'
    Body    = $body; ContentType = 'application/json'
    Headers = @{ Authorization = "Bearer $env:API_TOKEN" }
}
$issue = Invoke-RestMethod @params

$r = Invoke-WebRequest https://example.com
$r.StatusCode                            # 200
Invoke-WebRequest $url -OutFile .\setup.zip   # download

Invoke-RestMethod $api -FollowRelLink   # all pages
try { Invoke-RestMethod $u } catch { $_.Exception.Response.StatusCode }

Code Explained

Invoke-RestMethod — GET by default; result is already parsed
ConvertTo-Json — build the request body from a hashtable
@params — splatting keeps long API calls readable
-OutFile — stream the response to a file
-FollowRelLink — follows Link: rel=next paging (7+)

⚠ Common Mistakes

  • Passing a hashtable as -Body to a JSON API. It’s sent as form data; convert with ConvertTo-Json first
  • Forgetting -Depth on nested request bodies. Inner objects become type-name strings
  • Hard-coding tokens in scripts. Read them from $env: or SecretManagement

✓ Tips & Best Practices

  • Use -SkipHttpErrorCheck -StatusCodeVariable sc to handle 404s without try/catch
  • Inspect a parsed response with $r | ConvertTo-Json -Depth 5
  • In 5.1, enable TLS 1.2 via [Net.ServicePointManager] if HTTPS calls fail

Quick Summary

  • Invoke-RestMethod — call an API, get objects
  • Invoke-WebRequest — raw response, status, downloads
  • -Body (… | ConvertTo-Json) — send JSON
  • -Headers @{ Authorization = … } — authenticate
