Sheet 33

Regular Expressions

-match & $Matches · (?<name>) · -replace $1 · Select-String · [regex]::Matches() · switch -Regex

Overview

PowerShell uses the .NET regex engine. -match tests a string and fills $Matches with the first match; [regex]::Matches() or Select-String -AllMatches find all matches. Regex operators are case-insensitive by default; use the c versions (-cmatch, -creplace) when case matters.

Notes

  • Always single-quote patterns so $ isn’t expanded
  • -match on an array filters; it doesn’t set $Matches
  • Named groups: (?<year>\d{4}) → $Matches.year
  • Escape user text with [regex]::Escape()

Matching, Capturing, Replacing

$log = '2026-10-06 14:05 ERROR [db] Timeout after 30s'

if ($log -match '^(?<date>\S+) (?<time>\S+) (?<level>\w+)') {
    $Matches.level                       # ERROR
    $Matches.date                        # 2026-10-06
}
$log -replace '(\d+)s$', '$1 seconds'    # …after 30 seconds
$log -replace '(?<y>\d{4})-(?<m>\d\d)', '${m}/${y}'   # 10/2026-06 …

[regex]::Matches('a1 b22 c333', '\d+').Value   # 1 22 333
Select-String -Path *.log -Pattern 'user=(\w+)' -AllMatches |
    ForEach-Object { $_.Matches.Groups[1].Value }

switch -Regex ($line) {
    '^WARN'          { $warn++ }
    '^ERROR (\d+)'   { "code $($Matches[1])" }
}
'a-b_c d' -split '[-_ ]'                 # a b c d

Code Explained

(?<level>\w+) — named capture group
$Matches.level — read a named group from the last scalar match
'$1 seconds' — numbered group in the replacement (single quotes!)
'${m}/${y}' — named groups in the replacement
[regex]::Matches() — every match; .Value, .Groups, .Index
-AllMatches — Select-String finds more than one match per line

⚠ Common Mistakes

  • Double-quoting a pattern or replacement with $1. PowerShell expands it first; use single quotes
  • Expecting -match to return all matches. It stops at the first; use [regex]::Matches()
  • Using a dot for a literal period. . matches anything; write \.

✓ Tips & Best Practices

  • Build complex patterns with (?x) and comments on separate lines in a here-string
  • Test patterns quickly: 'sample' -match 'pattern'; $Matches
  • Use Select-String -Pattern … -Context 2 to see surrounding lines

Quick Summary

  • -match — test + $Matches (first match)
  • -replace — regex substitution with $1 / ${name}
  • [regex]::Matches() — all matches
  • Select-String / switch -Regex — files and branching
