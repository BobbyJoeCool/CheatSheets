Sheet 11

Arithmetic & Assignment Operators

+ - * / % · ++ / -- · += -= *= · [math]::Round() · -band / -bor / -shl · 1..10

Overview

Arithmetic works as expected on numbers, but + and * also work on strings and arrays. Division returns a double unless the result is exact, so 7 / 2 is 3.5. There is no exponent operator; use [math]::Pow(). Bitwise operators are words: -band, -bor, -shl.

Notes

  • 7 / 2 → 3.5; 6 / 2 → 3 (Int32)
  • [int] rounds half to even; use [math]::Floor() to drop decimals
  • The range .. works on integers and (7+) characters
  • ++ / -- exist as prefix and postfix

Arithmetic in Practice

7 / 2                     # 3.5
7 % 2                     # 1
[math]::Floor(7 / 2)      # 3
[math]::Round(2.567, 2)   # 2.57
[math]::Pow(2, 10)        # 1024
'ab' * 3                  # ababab
@(1, 2) * 2               # 1 2 1 2
'a' + 1                   # a1

$i = 5; $i++; $i          # 6
$total = 10; $total += 5  # 15
$s = 'Log'; $s += '.txt'  # Log.txt
$list = @(); $list += 4   # array now has 1 item

1..5                      # 1 2 3 4 5
'a'..'e'                  # a b c d e (7+)
5 -band 3; 5 -bor 3       # 1; 7

Code Explained

7 / 2 — division never truncates; floor it yourself
[math]::Round() — round half to even by default; pass 'AwayFromZero' for school rounding
'ab' * 3 — string repetition; handy for '-' * 40 separators
+= — works on numbers, strings and arrays (arrays are copied)
1..5 — inclusive range; also counts down: 5..1

⚠ Common Mistakes

  • Using ** or ^ for powers. Neither exists (^ is not XOR either); use [math]::Pow()
  • Growing a big array with += in a loop. Each add copies the whole array; use a List[object] or loop output
  • Expecting [int](7/2) to be 3. It rounds to even → 4; use [math]::Floor() or [math]::Truncate()

✓ Tips & Best Practices

  • Use [math]::Round($x, 2, 'AwayFromZero') for invoice-style rounding
  • Size math reads well with literals: $file.Length / 1MB
  • Use [int][math]::Ceiling($n / $pageSize) to count pages

Quick Summary

  • + - * / % — division returns double when inexact
  • += / ++ — compound assignment and increment
  • [math]:: — Pow, Round, Floor, Ceiling, Abs, Max
  • -band -bor -bxor -shl — bitwise ops
