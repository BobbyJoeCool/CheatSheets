⚠ Common Mistakes

  • catch not firing — the error was non-terminating; add -ErrorAction Stop
  • $a += $x in a big loop — rebuilds the array each time; use a List
  • Comparing with = or == instead of -eq

✓ Tips & Best Practices

  • Pipe to Get-Member to see what an object really has
  • Use [pscustomobject] for output, not formatted text
  • Add [CmdletBinding()] to get -Verbose, -ErrorAction for free

Quick Summary

  • Verb-Noun cmdlets, objects through the pipeline
  • -eq -like -match -contains compare
  • @() arrays, @{} hashtables
