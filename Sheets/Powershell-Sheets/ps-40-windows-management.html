Sheet 40

Windows Management

HKLM: / HKCU: · Get-ItemProperty · Get-CimInstance · Get-WinEvent · Register-ScheduledTask · Get-LocalUser

Overview

On Windows, PowerShell reaches every part of the OS. The registry is a drive you navigate with the same *-Item cmdlets as files. CIM (WMI) exposes hardware and OS details. You can also query event logs, schedule tasks, and manage local accounts. Most of this sheet is Windows-only.

Notes

  • Registry values are properties of keys: use *-ItemProperty
  • Use Get-CimInstance, not the old Get-WmiObject (gone in 7)
  • Many commands need an elevated (admin) session
  • Get-WinEvent -FilterHashtable is far faster than Where-Object

Registry, CIM, Events, Tasks

Get-ChildItem HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall
Get-ItemProperty HKCU:\Environment                   # all values of a key
Get-ItemPropertyValue HKCU:\Environment -Name TEMP
Set-ItemProperty HKCU:\Software\MyApp -Name Mode -Value 'prod'

Get-CimInstance Win32_OperatingSystem |
    Select-Object Caption, Version, LastBootUpTime
Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3"

Get-WinEvent -FilterHashtable @{
    LogName = 'System'; Level = 2; StartTime = (Get-Date).AddDays(-1)
} -MaxEvents 20                                      # errors, last 24h

$action  = New-ScheduledTaskAction -Execute pwsh -Argument '-File C:\bk.ps1'
$trigger = New-ScheduledTaskTrigger -Daily -At 2am
Register-ScheduledTask -TaskName Backup -Action $action -Trigger $trigger
Get-LocalUser | Where-Object Enabled

Code Explained

HKLM:\…\Uninstall — subkeys list installed programs
Get-ItemPropertyValue — a single value, without PS* noise
Win32_OperatingSystem — CIM class: OS name, version, boot time
Level = 2 — 1 critical, 2 error, 3 warning, 4 info
New-ScheduledTaskAction — what to run; trigger says when
Get-LocalUser — local accounts (Microsoft.PowerShell.LocalAccounts)

⚠ Common Mistakes

  • Using Get-WmiObject. It’s removed in PowerShell 7; Get-CimInstance is the replacement
  • Querying Win32_Product to list software. It’s slow and can trigger MSI repairs; read the Uninstall registry keys
  • Filtering events with Get-WinEvent | Where-Object. It reads the entire log first; use -FilterHashtable

✓ Tips & Best Practices

  • Run Get-CimInstance -ClassName Win32_* -List to discover CIM classes
  • Use Test-NetConnection host -Port 443 instead of telnet for port checks
  • Back up a registry key before editing: reg export HKCU\Software\MyApp app.reg

Quick Summary

  • HKLM: / HKCU: + *-ItemProperty — registry
  • Get-CimInstance Win32_* — system info
  • Get-WinEvent -FilterHashtable — event logs
  • Register-ScheduledTask — automation on a schedule
