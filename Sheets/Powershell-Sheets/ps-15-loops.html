Sheet 15

Loops

foreach · for · while · do / while / until · break / continue · :label

Overview

PowerShell has the classic loops plus foreach for collections. Loops are statements whose output can be captured: $squares = foreach ($n in 1..5) { $n * $n } builds an array without +=. The foreach statement is different from ForEach-Object in the pipeline (sheet 16).

Notes

  • foreach loads the whole collection first; fastest for data in memory
  • do…while and do…until always run at least once
  • Labels let break outer exit nested loops
  • Looping over $null runs zero times (3.0+)

Looping Patterns

foreach ($file in Get-ChildItem *.log) {
    "$($file.Name): $($file.Length) bytes"
}

for ($i = 0; $i -lt 5; $i++) { "Line $i" }

while (-not (Test-Path .\done.flag)) { Start-Sleep 2 }   # poll
do { $answer = Read-Host 'Continue? (y/n)' } until ($answer -in 'y', 'n')

$squares = foreach ($n in 1..5) { $n * $n }   # 1 4 9 16 25

:outer foreach ($row in 1..3) {
    foreach ($col in 1..3) {
        if ($col -eq 2) { continue }      # skip this column
        if ($row -eq 3) { break outer }   # leave both loops
        "$row,$col"
    }
}

Code Explained

foreach ($x in …) — iterates any collection or command output
for (init; test; step) — index-based loop
while (…) — tests before each pass
do { } until (…) — runs until the condition becomes true
$squares = foreach — collects every value emitted in the loop
:outer / break outer — label targets an outer loop

⚠ Common Mistakes

  • Using break inside ForEach-Object. It isn’t a loop statement, so break exits the enclosing loop or script; use return to skip an item
  • Building results with $arr += $x in big loops. It copies the array each time; capture the loop output instead
  • Writing while ($i < 5). < is reserved; use -lt

✓ Tips & Best Practices

  • Capture loop output directly: $names = foreach ($u in $users) { $u.Name }
  • Use foreach over ForEach-Object for speed when the data is already in a variable
  • Add Start-Sleep to polling loops so they don’t spin the CPU

Quick Summary

  • foreach ($x in $list) — iterate a collection
  • for / while / do…until — classic loops
  • break / continue / :label — control flow
  • $r = foreach … — collect output without +=
