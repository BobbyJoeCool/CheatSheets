Sheet 09

String Basics & Formatting

'single' vs "double" · $() subexpression · `n `t escapes · @" "@ · -f operator · {0:N2}

Overview

Single-quoted strings are literal. Double-quoted strings expand variables and $( ) subexpressions. The escape character is the backtick (`), not backslash. For layout and number formatting, use the -f format operator with .NET format strings.

Notes

  • Strings are immutable; methods return new strings
  • Use $( ) for properties: "$($u.Name)"
  • Double a quote to escape it: 'It''s', "Say ""hi"""
  • Here-string markers must be alone on their lines

Quoting & Formatting

$name = 'Ada'; $n = 3
'Hi $name'                    # Hi $name   (literal)
"Hi $name"                    # Hi Ada
"Items: $($n * 2)"            # Items: 6
"User: $($user.Name)"         # property needs $( )
"Tab`there, newline`nnext"    # backtick escapes
"Cost: `$5"                   # Cost: $5

$body = @"
Dear $name,
Your total is $($n * 10).
"@                            # expanding here-string

'{0} has {1} items' -f $name, $n     # Ada has 3 items
'{0:N2}' -f 1234.5678                # 1,234.57
'{0:P0}' -f 0.256                    # 26%
'[{0,-8}][{1,6}]' -f 'left', 'right' # [left    ][ right]
(42).ToString('D5')                  # 00042

Code Explained

'…' — no expansion at all; safest for regex and paths
$( ) — runs any expression inside a double-quoted string
`$ — escapes the dollar so it prints literally
@" "@ — multi-line; @' '@ is the literal version
-f — {index:format} placeholders, values on the right
{0,-8} — width 8, left-aligned; positive = right-aligned

⚠ Common Mistakes

  • Writing "$user.Name". Only $user expands, then .Name is literal text; use "$($user.Name)"
  • Using backslash escapes like \n. PowerShell’s escape is the backtick; \n stays as two characters
  • Indenting the closing "@. It must start at column 1 or the string never ends

✓ Tips & Best Practices

  • Default to single quotes; switch to double only when you need expansion
  • Use -f instead of string concatenation for tables of output
  • Format currency with a culture: $n.ToString('C', [cultureinfo]'en-GB')

Quick Summary

  • '…' literal vs "…" expanding
  • $( ) — embed expressions and properties
  • ` — escape character (`n, `t, `$)
  • -f — '{0:N2}' -f $x formatting
