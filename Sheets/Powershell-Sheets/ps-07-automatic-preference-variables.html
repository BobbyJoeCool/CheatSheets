Sheet 07

Automatic & Preference Variables

$_ / $PSItem · $? · $LASTEXITCODE · $PSScriptRoot · $Matches · $ErrorActionPreference

Overview

Automatic variables are created and updated by PowerShell itself: the current pipeline object, the last command's success, the script's folder. Preference variables are settings you can change, such as how errors or verbose messages are handled. Don't assign to automatic variables; do tune preference variables, ideally only inside a script or function.

Notes

  • $_ and $PSItem are identical; $_ is more common
  • $? is $true if the last command fully succeeded
  • $LASTEXITCODE is only set by native programs and scripts' exit
  • $PSScriptRoot is empty at the interactive prompt

Common Automatic Variables

Get-Process | Where-Object { $_.CPU -gt 100 }   # current object

git status; $LASTEXITCODE        # 0 = success for native exes
Get-Item nope.txt; $?            # False

$PSScriptRoot                    # C:\scripts  (folder of this .ps1)
$PSCommandPath                   # C:\scripts\deploy.ps1
Join-Path $PSScriptRoot 'config.json'

'2026-10-06' -match '(\d{4})-(\d\d)'
$Matches[0]; $Matches[1]         # 2026-10 / 2026

$ErrorActionPreference = 'Stop'  # make errors terminating
$VerbosePreference = 'Continue'  # show Write-Verbose output
$Error[0]                        # most recent error

Code Explained

$_ — set inside Where-Object, ForEach-Object, switch, catch
$LASTEXITCODE — check after git, npm, robocopy and other exes
$PSScriptRoot — reliable way to find files next to the script
$Matches — hashtable filled by a successful scalar -match
Preference — values: Stop, Continue, SilentlyContinue, Inquire

⚠ Common Mistakes

  • Reading $? after another command ran. Even an echo resets it; check it on the very next line or capture it
  • Using $PSScriptRoot in code run by selection (F8). It’s empty outside a running script file
  • Assuming cmdlets set $LASTEXITCODE. Only native programs and exit N do; use $? or try/catch for cmdlets

✓ Tips & Best Practices

  • Set $ProgressPreference = 'SilentlyContinue' to speed up Invoke-WebRequest in 5.1
  • Change preferences inside a function; they revert automatically when it returns
  • Use $PSDefaultParameterValues to set session-wide parameter defaults

Quick Summary

  • $_ / $PSItem — current pipeline object
  • $? / $LASTEXITCODE — success of last cmdlet / native exe
  • $PSScriptRoot — folder of the running script
  • $ErrorActionPreference — default error behavior
