Sheet 08

Types & Casting

[int] [string] [double] · type accelerators · -as / -is · .GetType() · [int]$x · 1kb / 0xFF

Overview

Every value is a .NET object with a type. PowerShell converts types for you, and the left operand decides: '5' + 3 is the string '53', but 5 + '3' is 8. Cast explicitly with [type], test with -is, and convert safely with -as, which returns $null instead of throwing.

Notes

  • [int] casts round to even: [int]2.5 → 2, [int]3.5 → 4
  • A typed variable [int]$n stays an int on every later assignment
  • Any non-empty string is $true: [bool]'False' → True
  • Type names are case-insensitive and System. is optional

Casting & Conversion

[int]'42'               # 42
[int]'4.6'              # 5
[string]42              # '42'
[datetime]'2026-10-06'  # Tuesday, October 6, 2026 12:00:00 AM
[bool]0; [bool]'0'      # False; True  (string is non-empty)

'5' + 3                 # 53   (string on the left)
5 + '3'                 # 8    (number on the left)

'abc' -as [int]         # $null, no error
42 -is [int]            # True
(42).GetType().Name     # Int32

[int]$n = 10
$n = '20'               # converted → 20
$n = 'abc'              # error: cannot convert

Code Explained

[int]'4.6' — string → number parses then rounds
[datetime] — parses culture-invariant formats like yyyy-MM-dd
'5' + 3 — left side is a string, so + concatenates
-as — safe conversion; test the result for $null
.GetType() — returns the type; .Name / .FullName for text
[int]$n — type constraint applies to the variable itself

⚠ Common Mistakes

  • Comparing versions as strings. '1.10' -gt '1.9' is False; cast with [version] first
  • Casting user input with [int] and letting it throw. Use -as [int] or [int]::TryParse() and check the result
  • Expecting [bool]'false' to be False. Strings are true when non-empty; compare text instead

✓ Tips & Best Practices

  • Put the value whose type you want on the left: [int]$a + $b forces numeric addition
  • Use [decimal] for money; [double] has binary rounding errors (0.1 + 0.2)
  • Run Get-Member to see the type name at the top of the output

Quick Summary

  • [type]value — explicit cast
  • -as / -is — safe convert / type test
  • Left operand decides — '5'+3 vs 5+'3'
  • 1kb, 0xFF, 42L — numeric literal shortcuts
