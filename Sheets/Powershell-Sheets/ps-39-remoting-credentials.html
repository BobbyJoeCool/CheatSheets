Sheet 39

Remoting & Credentials

Enter-PSSession · Invoke-Command · New-PSSession · SSH -HostName · Get-Credential · SecretManagement

Overview

PowerShell remoting runs commands on other machines and returns deserialized objects. Use Enter-PSSession for an interactive shell, Invoke-Command to run a script block on one or many computers in parallel, and New-PSSession for a reusable connection. Windows uses WinRM by default; PowerShell 7 also supports SSH on every OS.

Notes

  • Enable WinRM on a target: Enable-PSRemoting (admin)
  • Remote output objects have properties but no methods
  • Use $using:var to send local values to the remote side
  • Get-Credential returns a PSCredential (SecureString password)

Remote Commands

Enter-PSSession -ComputerName srv01      # [srv01]: PS> …

Invoke-Command -ComputerName srv01, srv02 { Get-Service Spooler }

$days = 7
Invoke-Command srv01 { Get-ChildItem C:\Logs |
    Where-Object LastWriteTime -lt (Get-Date).AddDays(-$using:days) }

$cred = Get-Credential CONTOSO\admin
$s = New-PSSession -ComputerName srv01 -Credential $cred
Invoke-Command -Session $s { $env:COMPUTERNAME }
Copy-Item .\app.zip -Destination C:\Deploy -ToSession $s

Enter-PSSession -HostName ubuntu01 -UserName bob    # SSH (7+)
$pw = Get-Secret -Name ApiKey -AsPlainText          # SecretManagement

Code Explained

Enter-PSSession — interactive; the prompt shows the remote computer
-ComputerName a, b — runs on all targets in parallel (fan-out)
$using:days — local variable value used remotely
-Credential $cred — connect as another account
-ToSession — copy files over an existing session
-HostName — SSH transport instead of WinRM

⚠ Common Mistakes

  • Using a local variable in a remote block without $using:. It’s $null on the remote machine
  • Calling methods on returned objects. They’re deserialized copies; run the method inside the script block
  • Storing passwords in plain text. Use SecretManagement, or Export-Clixml for per-user encrypted files

✓ Tips & Best Practices

  • Use Invoke-Command -ComputerName (Get-Content servers.txt) for fleet-wide checks
  • Reuse a New-PSSession for several commands; connecting is the slow part
  • Install the SecretManagement and SecretStore modules for a local vault

Quick Summary

  • Enter-PSSession — interactive remote shell
  • Invoke-Command -ComputerName — run anywhere, in parallel
  • New-PSSession / -Session — reuse a connection
  • Get-Credential / Get-Secret — handle credentials safely
