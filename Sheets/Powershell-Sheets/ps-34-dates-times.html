Sheet 34

Dates & Times

Get-Date -Format · [datetime]::ParseExact() · .AddDays() · New-TimeSpan · Measure-Command · Start-Sleep

Overview

Get-Date returns a [datetime] object with properties (Year, DayOfWeek) and methods (AddDays()). Subtracting two dates gives a [timespan]. Use -Format for text output, and ParseExact() when reading dates in a known format so the result doesn't depend on the machine's culture.

Notes

  • -Format returns a string, not a date
  • Format codes are case-sensitive: MM month, mm minute
  • Date math: $end - $start → TimeSpan
  • Store and compare in UTC; display in local time

Working with Dates

Get-Date                                 # Tuesday, October 6, 2026 9:41 AM
Get-Date -Format 'yyyy-MM-dd HH:mm'      # 2026-10-06 09:41
Get-Date -Format FileDateTime            # 20261006T0941075123
(Get-Date).AddDays(-30).Date             # midnight 30 days ago
(Get-Date).DayOfWeek                     # Tuesday
[datetime]::DaysInMonth(2026, 2)         # 28

$d = [datetime]::ParseExact('06/10/2026', 'dd/MM/yyyy', $null)
$d.Month                                 # 10

$span = New-TimeSpan -Start '2026-01-01' -End (Get-Date)
$span.Days                               # 278
((Get-Date) - $file.LastWriteTime).TotalHours

(Measure-Command { Get-ChildItem C:\ -Recurse }).TotalSeconds
Start-Sleep -Milliseconds 500
(Get-Date).ToUniversalTime().ToString('o')   # ISO 8601 UTC

Code Explained

-Format — custom .NET format string or a named format
.Date — same day at 00:00
ParseExact(text, fmt, $null) — $null = current culture; the format fixes the field order
New-TimeSpan — difference between two dates
.TotalHours — whole span as a decimal; .Hours is just the hour part
Measure-Command — times a script block; output is suppressed

⚠ Common Mistakes

  • Using mm for month. mm is minutes; months are MM
  • Comparing Get-Date -Format output as dates. It’s text; compare [datetime] objects instead
  • Parsing '06/10/2026' with [datetime]. Casts assume US month/day order; use ParseExact

✓ Tips & Best Practices

  • Use Get-Date -Format FileDate or 'yyyyMMdd' in file names; they sort correctly
  • Use .TotalSeconds / .TotalDays for spans, not .Seconds / .Days
  • Use Get-Date -AsUTC (7.1+) for timestamps in logs

Quick Summary

  • Get-Date -Format 'yyyy-MM-dd' — text output
  • .AddDays() / .Date — date arithmetic
  • New-TimeSpan / $a - $b — durations
  • Measure-Command / Start-Sleep — timing
