Sheet 24

Arrays & Lists

@() / , · $a[-1] · $a[0..2] · += copies · List[object] · array unrolling

Overview

Arrays are fixed-size, so += silently creates a new copy each time. That's fine for a few items but slow for thousands; use [System.Collections.Generic.List[object]] or capture loop output instead. PowerShell unrolls arrays in the pipeline and returns a single item as a scalar, so wrap results in @( ) when you need an array.

Notes

  • Indexes start at 0; -1 is the last item
  • Out-of-range index returns $null, no error
  • A command returning one item gives a scalar, not an array
  • , builds arrays: 1, 2, 3; ,$x = one-item array

Arrays and Lists

$a = 1, 2, 3                    # array
$empty = @()
$one = ,'only'                  # 1-item array
$a[0]; $a[-1]                   # 1; 3
$a[0..1]                        # 1 2
$a[-2..-1]                      # 2 3
$a.Count                        # 3
$a += 4                         # copy of array + 4
3 -in $a                        # True

$files = @(Get-ChildItem *.cfg) # always an array
$files.Count                    # 0, 1 or more, never $null

$list = [System.Collections.Generic.List[object]]::new()
$list.Add('a'); $list.Add('b')  # no copying, no output
$list.Remove('a')               # True
$list.Insert(0, 'z'); $list     # z b

Code Explained

1, 2, 3 — comma operator creates Object[]
$a[-2..-1] — ranges as indexes give slices
+= — allocates a new array each time
@( … ) — array subexpression; guarantees an array result
List[object] — growable; Add, Remove, Insert, Contains
$list.Add() — List’s Add returns nothing (ArrayList returns an index)

⚠ Common Mistakes

  • Using += to build a 10,000-item array. It’s O(n²); capture loop output or use a List
  • Checking $result.Count when a command returned one object. Always wrap: @(Get-Thing).Count
  • Using ArrayList.Add() without discarding. It outputs the new index into your results

✓ Tips & Best Practices

  • Prefer $x = foreach (…) { … } to build arrays; it’s fast and needs no +=
  • Use $a.Where({ … }, 'First') to stop at the first match
  • Return an array intact from a function with ,$arr or Write-Output -NoEnumerate

Quick Summary

  • 1,2,3 / @() — create arrays
  • $a[-1], $a[0..2] — index and slice
  • += copies — use List[object] for many adds
  • @( … ) — force an array result
