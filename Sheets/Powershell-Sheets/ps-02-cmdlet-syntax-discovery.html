Sheet 02

Cmdlet Syntax & Discovery

Verb-Noun · Get-Command · Get-Help · Get-Member · Get-Alias · parameters

Overview

Cmdlets are named Verb-Noun using a fixed list of approved verbs (Get, Set, New, Remove…), so you can guess names. Three commands let you learn anything from inside the shell: Get-Command finds commands, Get-Help explains them, and Get-Member shows what properties and methods an object has.

Notes

  • Parameters start with - and can be shortened while unique: -Na = -Name
  • Switch parameters are on/off flags: -Recurse, -Force
  • Run Update-Help once (as admin in 5.1) to download full help
  • Tab completes commands, parameters, paths and even property names

Discover, Learn, Inspect

Get-Command *service*              # anything with "service" in the name
Get-Command -Verb Get -Noun *Item* # Get-Item, Get-ChildItem, …
Get-Command -Module Microsoft.PowerShell.Utility

Get-Help Get-ChildItem -Examples   # just the examples
Get-Help Get-ChildItem -Parameter Filter
Get-Help about_Operators           # concept topics start with about_
Get-ChildItem -?                   # quick syntax summary

Get-Process | Get-Member           # TypeName + properties + methods
Get-Process | Get-Member -MemberType Property

Get-ChildItem -Path C:\Temp -Filter *.log -Recurse   # named
Get-ChildItem C:\Temp *.log -Recurse                 # positional
Get-Alias ls, gci, dir             # all → Get-ChildItem
Get-Verb | Where-Object Group -eq Lifecycle

Code Explained

Get-Command — search by wildcard, -Verb, -Noun, -Module
-Examples — fastest way to learn a cmdlet; also -Full, -Online
about_* — conceptual help: about_Splatting, about_Scopes…
Get-Member — what an object is: type name, properties, methods
positional — -Path and -Filter are positions 0 and 1 on Get-ChildItem
Get-Alias — maps short names back to cmdlets

⚠ Common Mistakes

  • Reading ls output as text. It is objects; use Get-Member to see the real property names before filtering
  • Using aliases like %, ? or ls in scripts. They hurt readability and ls/cat aren’t aliases on Linux/macOS pwsh
  • Skipping Update-Help. Without it Get-Help shows only syntax stubs

✓ Tips & Best Practices

  • Get-Help name -Online opens the current docs page in your browser
  • Pipe any result to Get-Member before writing Where-Object or Select-Object
  • Use Show-Command Get-ChildItem (Windows) for a form-based parameter picker

Quick Summary

  • Verb-Noun — cmdlet naming; see Get-Verb
  • Get-Command — find commands by name, verb, noun, module
  • Get-Help -Examples — learn by example
  • Get-Member — inspect an object’s properties and methods
