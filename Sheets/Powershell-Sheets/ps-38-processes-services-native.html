Sheet 38

Processes, Services & Native Commands

Get-Process / Stop-Process · Start-Process · Get-Service · Restart-Service · --% / $LASTEXITCODE · native args

Overview

Manage running programs with the *-Process cmdlets and Windows services with the *-Service cmdlets. You can also run any native executable directly; its text output becomes strings in the pipeline, and its exit code lands in $LASTEXITCODE. PowerShell 7.3+ passes arguments to native programs much more predictably than 5.1.

Notes

  • Service cmdlets are Windows-only
  • Native exe output is text: one string per line
  • Native exes don’t throw on failure; check $LASTEXITCODE
  • -Verb RunAs starts a program elevated (UAC)

Processes, Services, Executables

Get-Process | Sort-Object WS -Descending | Select-Object -First 5 Name, WS
Get-Process notepad -ErrorAction SilentlyContinue | Stop-Process
Stop-Process -Name chrome -Force
Start-Process notepad .\todo.txt
Start-Process msiexec -ArgumentList '/i app.msi /qn' -Wait -NoNewWindow
Start-Process pwsh -Verb RunAs           # elevated window

Get-Service | Where-Object Status -eq Running
Get-Service -Name Spooler | Restart-Service -Force
Set-Service -Name wuauserv -StartupType Disabled

$out = ipconfig /all                     # string[] of lines
git log --oneline -5
if ($LASTEXITCODE -ne 0) { throw "git failed: $LASTEXITCODE" }
& 'C:\Program Files\7-Zip\7z.exe' a backup.zip .\data
icacls.exe --% C:\Data /grant "Users":(R)   # stop-parsing

Code Explained

Sort-Object WS — WS = working set (memory) in bytes
Start-Process -Wait — waits for exit; -PassThru returns the process
-NoNewWindow — run in the current console
Restart-Service -Force — also restarts dependent services
$LASTEXITCODE — exit code of the last native program
--% — pass the rest of the line to the exe exactly as typed

⚠ Common Mistakes

  • Assuming a failed exe stops your script. It doesn’t; check $LASTEXITCODE after each important call
  • Parsing tasklist or sc query text. Get-Process and Get-Service return objects with real properties
  • Using Start-Process to capture output. It doesn’t return stdout; call the exe directly or use -RedirectStandardOutput

✓ Tips & Best Practices

  • Use Get-CimInstance Win32_Service to see service paths and accounts
  • Use Get-Process -IncludeUserName (admin) to see who owns a process
  • In 7.4+, set $PSNativeCommandUseErrorActionPreference to $true so failing exes throw under Stop

Quick Summary

  • Get- / Stop- / Start-Process — manage programs
  • Get- / Restart- / Set-Service — manage Windows services
  • exe args + $LASTEXITCODE — native commands
  • --% — stop-parsing for tricky arguments
