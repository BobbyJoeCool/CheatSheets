Sheet 14

if & switch

if / elseif / else · switch · -Wildcard / -Regex · -File · break / continue · $_ in switch

Overview

if tests any expression for truthiness (non-zero, non-empty, non-null). switch is far more powerful than in C-like languages: it can match wildcards or regex, read a file line by line, iterate an array, and run every matching branch unless you break. Both can be assigned to a variable.

Notes

  • Falsy: $false, 0, '', $null, empty array @()
  • In switch, $_ is the current value
  • switch on an array tests each element in turn
  • Use break to stop after the first match

Branching

if ($free -lt 10GB) {
    Write-Warning 'Low disk'
} elseif ($free -lt 50GB) {
    'Watch it'
} else { 'Plenty' }

$size = if ($n -gt 100) { 'big' } else { 'small' }

switch ($code) {
    200            { 'OK'; break }
    { $_ -ge 500 } { 'Server error'; break }
    default        { "Code $_" }
}

switch -Wildcard ($file) { '*.log' { 'log' }  '*.txt' { 'text' } }
switch -Regex ($line) { '^ERROR (\d+)' { "err $($Matches[1])" } }
switch -File .\app.log { { $_ -like '*WARN*' } { $warn++ } }

$type = switch ($ext) { '.ps1' { 'script' } default { 'other' } }

Code Explained

elseif — one word; no else if needed (though it works)
$size = if … — statements return values you can capture
{ $_ -ge 500 } — script block condition, true/false
default — runs when nothing else matched
-Regex — regex match; $Matches is available inside
-File — reads the file and switches on each line

⚠ Common Mistakes

  • Forgetting break when one value matches several branches. Every matching branch runs, unlike C#
  • Writing if ($a = 5). That assigns 5 and is always true; use -eq
  • Testing a single-item array @(0). It is falsy because PowerShell unwraps one element

✓ Tips & Best Practices

  • Use switch with script-block conditions instead of long elseif chains
  • Use switch -Regex -File to parse logs in a few lines
  • Prefer if (-not (Test-Path $p)) over if (!(Test-Path $p) -eq $true)

Quick Summary

  • if / elseif / else — truthy tests
  • switch — exact, wildcard, regex, file
  • break / continue — stop or skip in switch
  • $x = if … — capture a statement’s value
