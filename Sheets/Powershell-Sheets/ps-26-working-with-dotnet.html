Working with .NET

[Class]::Method() · ::new() · New-Object · using namespace · Get-Member -Static · Add-Type

Overview

PowerShell runs on .NET, so the entire class library is available directly. Call static members with [Type]::Member, create objects with [Type]::new(), and call instance methods with a dot. When no cmdlet does what you need, there is almost always a .NET class that does.

Notes

  • Method calls need parentheses: $s.ToUpper()
  • Type a method name without () to see its overloads
  • ::new() (5.0+) is faster than New-Object
  • using namespace must be the first lines of a script

Calling .NET from PowerShell

[math]::Sqrt(144)                       # 12
[math]::PI                              # 3.14159265358979
[int]::MaxValue                         # 2147483647
[guid]::NewGuid().Guid                  # 'a3f1…'
[IO.Path]::GetExtension('report.pdf')   # .pdf

$sb = [System.Text.StringBuilder]::new()
[void]$sb.Append('Hello, ').Append('World')
$sb.ToString()                          # Hello, World

using namespace System.Collections.Generic   # top of file only
$q = [Queue[string]]::new(); $q.Enqueue('job1')

[math] | Get-Member -Static -MemberType Method
[IO.File]::ReadAllText                  # shows overloads
Add-Type -AssemblyName System.Web
[System.Web.HttpUtility]::UrlEncode('a b&c')   # a+b%26c

Code Explained

[math]::Sqrt() — static method: no object needed
[int]::MaxValue — static property
::new() — calls the constructor; arguments go in the parens
[void] — discards the return value of chained calls
using namespace — lets you write [Queue[string]] without the full name
Add-Type -AssemblyName — loads a .NET assembly that isn’t loaded yet

⚠ Common Mistakes

  • Calling a method without parentheses. $s.ToUpper returns the method info, not the result
  • Calling methods with spaces like a cmdlet: $s.Replace 'a' 'b'. Methods need ('a', 'b')
  • Putting using namespace below other code. It must come before any other statement

✓ Tips & Best Practices

  • Use [T]::new (no parens) to read constructor overloads quickly
  • Prefer StringBuilder or -join when building large strings in a loop
  • Use Add-Type -TypeDefinition @' … '@ to compile small C# helpers inline

Quick Summary

  • [Type]::Member — static method or property
  • [Type]::new() — create an instance
  • $obj.Method() — instance call, always with parens
  • Get-Member -Static — discover what a type offers
