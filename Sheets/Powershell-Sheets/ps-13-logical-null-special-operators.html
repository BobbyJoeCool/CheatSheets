Sheet 13

Logical, Null & Special Operators

-and / -or / -not · ?? / ??= · ?. / ?[] · ? : ternary · && / || · & call / . dot-source

Overview

Logical operators are -and, -or, -xor and -not (or !), and they short-circuit. PowerShell 7 added C#-style operators: null-coalescing ??, null-conditional ?., the ternary ? :, and pipeline chains && / ||. The call operator & runs a command stored in a string or script block.

Notes

  • All of ?? ?. ? : && || are 7.0+ (not in 5.1)
  • ?. needs braces: ${obj}?.Name, since ? is legal in names
  • && / || act on the previous command’s $?
  • Precedence: -not binds tighter than -and / -or

Logic, Nulls, Calls

($age -ge 18) -and ($hasId)     # both must be true
-not (Test-Path $file)          # same as !(Test-Path $file)

$name = $inputName ?? 'Guest'   # default when $null
$config ??= @{}                 # assign only if $null
${user}?.Address?.City          # $null instead of error
${items}?[0]                    # safe index

$label = $n -gt 1 ? 'items' : 'item'

git pull && npm test            # test only if pull worked
npm test || Write-Warning 'fail' # runs only on failure

& 'C:\Program Files\Tool\tool.exe' --version
$sb = { param($x) $x * 2 }; & $sb 21     # 42
. .\helpers.ps1                 # load functions here

Start-Sleep 10 &                # background job (7+)

Code Explained

-and / -or — short-circuit: right side skipped when result is known
?? — returns the left side unless it is $null
${user}?.Address — stops at the first $null instead of throwing
? : — expression form of if/else; returns a value
&& — runs right side only if the left command succeeded
& — call a path with spaces or a script block

⚠ Common Mistakes

  • Writing $user?.Name without braces. PowerShell reads a variable called user?; use ${user}?.Name
  • Using ?? to replace empty strings. It only checks $null; '' ?? 'x' returns ''
  • Running a quoted path without &. 'C:\My Tool\x.exe' just prints the string

✓ Tips & Best Practices

  • Use ?? to replace if (-not $x) { $x = … } blocks for defaults
  • Use && in build scripts so a failing step stops the chain
  • Wrap each side of -and / -or in parentheses when it contains a command

Quick Summary

  • -and -or -xor -not — short-circuit logic
  • ?? / ??= — default for $null (7+)
  • ? : / ?. — ternary and null-conditional (7+)
  • & / . — call vs dot-source
