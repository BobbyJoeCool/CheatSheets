Sheet 29

Reading & Writing Files

Get-Content · -Raw / -Tail / -Wait · Set-Content / Add-Content · Out-File · -Encoding · Select-String

Overview

Get-Content reads a text file as an array of lines (or one string with -Raw). Set-Content writes, Add-Content appends, and Out-File / > write formatted output. PowerShell 7 writes UTF-8 without BOM by default; 5.1 uses different defaults per cmdlet, so pass -Encoding there.

Notes

  • Lines lose their newline characters when read
  • Get-Content -Raw keeps the file as one string
  • 5.1: Out-File/> write UTF-16; Set-Content writes ANSI
  • Use .NET [IO.File] methods for very large files

Read, Write, Search

$lines = Get-Content .\servers.txt         # string[]
$text  = Get-Content .\config.json -Raw    # one string
Get-Content .\app.log -Tail 20             # last 20 lines
Get-Content .\app.log -Tail 0 -Wait        # follow, like tail -f

Set-Content .\out.txt -Value 'line 1', 'line 2'
Add-Content .\out.txt -Value 'line 3'
Get-Process | Out-File .\procs.txt -Width 200

Set-Content .\a.txt 'x' -Encoding utf8BOM  # for old Windows tools

Select-String -Path .\*.log -Pattern 'ERROR' -Context 1, 2
Select-String -Path .\app.log -Pattern 'id=(\d+)' |
    ForEach-Object { $_.Matches[0].Groups[1].Value }
[IO.File]::ReadLines("$PWD\huge.log") | Select-Object -First 3

Code Explained

Get-Content — streams lines; each line also has ReadCount metadata
-Tail 0 -Wait — watch a log for new lines; Ctrl+C to stop
Set-Content -Value — writes strings as-is (no table formatting)
Out-File -Width — writes what you’d see on screen; widen to avoid cut-offs
Select-String -Context — lines before/after each match, like grep -B/-A
[IO.File]::ReadLines() — lazy reader; needs a full path

⚠ Common Mistakes

  • Treating Get-Content output as one string. It’s an array of lines; -match then filters lines. Use -Raw for whole-file regex
  • Using Out-File for data you’ll read back. It writes the formatted, possibly truncated view; use Set-Content or Export-Csv
  • Passing a relative path to [IO.File] methods. .NET uses the process directory, not $PWD

✓ Tips & Best Practices

  • Read config files with Get-Content -Raw | ConvertFrom-Json
  • Use Get-Content -ReadCount 1000 or [IO.File]::ReadLines() for multi-GB logs
  • Search a tree: Get-ChildItem -Recurse -Filter *.cs | Select-String 'TODO'

Quick Summary

  • Get-Content — lines; -Raw one string; -Tail -Wait follow
  • Set-Content / Add-Content — write / append text
  • Out-File / > — save formatted output
  • Select-String — grep for PowerShell
