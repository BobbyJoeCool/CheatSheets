Sheet 28

File System & Items

Get-ChildItem · Test-Path · New-Item · Copy- / Move- / Remove-Item · Join-Path / Split-Path · PSDrives

Overview

File and folder commands use the generic *-Item cmdlets, which also work on other providers like the registry, environment and certificates. Build paths with Join-Path rather than string concatenation so they work on every OS, and use -LiteralPath when names contain [ ].

Notes

  • Both / and \ work as separators on Windows
  • -Path supports wildcards; -LiteralPath doesn’t
  • -Force shows hidden files and creates parent folders
  • Files are FileInfo objects; folders DirectoryInfo

Finding and Managing Files

Get-ChildItem C:\Logs -Filter *.log -Recurse -File
Get-ChildItem -Directory -Depth 1          # folders, 2 levels
Get-ChildItem *.ps1, *.psm1                # several patterns

Test-Path .\out                            # True / False
Test-Path $p -PathType Leaf                # file only
New-Item .\out\reports -ItemType Directory -Force

Copy-Item .\src -Destination .\backup -Recurse
Rename-Item .\old.log -NewName new.log
Remove-Item .\temp -Recurse -Force

$cfg = Join-Path $PSScriptRoot 'config' 'app.json'   # 7+: many parts
Split-Path $cfg -Leaf                      # app.json
Split-Path $cfg -Parent                    # …\config
(Get-Item $cfg).Length                     # size in bytes

Code Explained

-Filter — provider-level filter: fastest way to match names
-Depth 1 — limits recursion (implies -Recurse)
-PathType Leaf — Leaf = file, Container = folder
New-Item -Force — creates missing parents; no error if the folder exists
Remove-Item -Recurse — deletes folders and contents. No recycle bin
Join-Path a b c — multiple child paths need 7+

⚠ Common Mistakes

  • Using -Include without -Recurse or a wildcard path. It silently matches nothing; add -Recurse or use -Filter
  • Building paths with "$dir\$file". Breaks on Linux and with trailing slashes; use Join-Path
  • Running Remove-Item -Recurse -Force on a variable that might be empty. Check Test-Path and use -WhatIf first

✓ Tips & Best Practices

  • Use -Filter before Where-Object: it’s handled by the file system and is much faster
  • Use -LiteralPath for names like report[1].txt
  • Get folder sizes: (gci $d -Recurse -File | Measure-Object Length -Sum).Sum / 1MB

Quick Summary

  • Get-ChildItem -Filter -Recurse -File — find files
  • Test-Path / New-Item -Force — check and create
  • Copy- / Move- / Rename- / Remove-Item — manage items
  • Join-Path / Split-Path — portable path handling
