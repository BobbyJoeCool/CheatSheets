Sheet 27

Classes & Enums

class · constructors · $this · static / hidden · inheritance : Base · enum / [Flags()]

Overview

PowerShell 5.0+ supports classes with typed properties, constructors, methods, static members and inheritance, plus enums for named constants. Classes are stricter than functions: methods must declare a return type and use return, because nothing is output implicitly. Use them for data models, DSC resources, and validation-heavy code.

Notes

  • Inside methods, use $this.Prop for members
  • Methods return only via return; [void] for none
  • Load a class before using it (define it above, or using module)
  • Changing a class needs a new session to reload

Class, Inheritance, Enum

enum Env { Dev; Test; Prod }
class Server {
    [string]$Name
    [Env]$Env = [Env]::Dev
    [int]$Port = 443
    hidden [datetime]$Created = (Get-Date)
    static [int]$Count = 0

    Server([string]$name) { $this.Name = $name; [Server]::Count++ }
    [string] Url() { return "https://$($this.Name):$($this.Port)" }
}
class WebServer : Server {
    WebServer([string]$name) : base($name) { $this.Port = 8443 }
}
$s = [WebServer]::new('web01'); $s.Url()   # https://web01:8443
[Server]::Count                            # 1
[Flags()] enum Perm { Read = 1; Write = 2; Exec = 4 }
[Perm]'Read, Write'                        # Read, Write (3)

Code Explained

[Env]$Env — property typed with an enum; only valid names accepted
static — shared by the class: [Server]::Count
Server([string]$name) — constructor: same name as the class
: base($name) — calls the parent constructor
[Flags()] — values combine with commas or -bor

⚠ Common Mistakes

  • Writing output in a method without return. Methods emit nothing implicitly; the result is empty
  • Using a property without $this. inside a method. $Name is an undefined local variable there
  • Using Import-Module to get a module’s classes. Classes need using module ModuleName at the top

✓ Tips & Best Practices

  • Override ToString() so objects print nicely in strings and lists
  • Use enums for parameters too: param([Env]$Target) gives validation and tab completion
  • Keep classes in a module and load with using module for reuse

Quick Summary

  • class Name { [type]$Prop; Name() {} } — define
  • [type] Method() { return … } — explicit returns
  • class B : A { B() : base() {} } — inherit
  • enum / [Flags()] enum — named constants
