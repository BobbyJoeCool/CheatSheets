Sheet 21

Functions & Script Blocks

function Verb-Noun · param() · return · [switch] · splatting @params · { } script blocks

Overview

A function is a named script block. Declare parameters in a param() block and call the function like a cmdlet: space-separated, no parentheses or commas. Everything the function emits is its output, not just what follows return. A script block { } is code stored as a value that you run later with &.

Notes

  • Call as Add-Num 1 2, never Add-Num(1, 2)
  • return $x = output $x, then exit
  • Name functions Verb-Noun with approved verbs
  • Splat with @name, not $name

Defining and Calling

function Get-Greeting {
    param(
        [string]$Name = 'World',
        [switch]$Shout
    )
    $msg = "Hello, $Name!"
    if ($Shout) { return $msg.ToUpper() }
    $msg
}
Get-Greeting                     # Hello, World!
Get-Greeting -Name Ada -Shout    # HELLO, ADA!

$p = @{ Path = 'C:\Logs'; Filter = '*.log'; Recurse = $true }
Get-ChildItem @p                 # hashtable splatting

$double = { param($x) $x * 2 }
& $double 21                     # 42
Invoke-Command -ScriptBlock $double -ArgumentList 5   # 10

Code Explained

param() — typed parameters with defaults
[switch] — on/off flag; $Shout is True only when passed
return — exits early; any earlier output is still returned
@p — spreads hashtable keys as named parameters
{ param($x) … } — script block with its own parameters
& $double 21 — invoke a script block like a command

⚠ Common Mistakes

  • Calling with parentheses and commas: Add-Num(1, 2) passes one array to the first parameter; use Add-Num 1 2
  • Leaving stray output: a bare $list.Add(1) or New-Item inside the function becomes part of the return value
  • Splatting with $p instead of @p. $p passes the whole hashtable as one argument

✓ Tips & Best Practices

  • Splat long parameter lists to keep lines short and readable
  • Type every parameter ([string], [int]) so bad input fails early
  • Use $PSBoundParameters to see which parameters the caller passed

Quick Summary

  • function Verb-Noun { param() } — define
  • Name arg1 arg2 — call with spaces, no parens
  • Output = everything emitted, return just exits
  • @params — splatting; & {} — run a script block
