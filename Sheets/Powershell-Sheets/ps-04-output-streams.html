Sheet 04

Output & Streams

Write-Output · Write-Host · Write-Verbose · streams 1–6 · 2>&1 · Out-Null

Overview

Anything a command or expression produces and doesn't capture goes to the success stream (stream 1), so a bare string or variable on its own line is output. Write-Host writes straight to the screen and cannot be piped or captured into a variable. PowerShell has six numbered streams, each with its own cmdlet, and all can be redirected.

Notes

  • Implicit output and Write-Output are the same thing
  • Use Write-Host only for colored, display-only messages
  • Verbose/Debug are hidden unless you pass -Verbose / -Debug
  • Function output = everything not captured, not just return

Writing Output

"Hello"                          # success stream → Hello
Write-Output "Hello"             # same as above
$x = Write-Output "Hi"           # captured: $x = 'Hi'
$y = Write-Host "Hi"             # prints Hi; $y is $null

Write-Host "Done" -ForegroundColor Green
Write-Verbose "Step 2"  -Verbose # VERBOSE: Step 2
Write-Warning "Low disk"         # WARNING: Low disk
Write-Error "Not found"          # red error, non-terminating

.\build.ps1 > out.txt            # stream 1 to file
.\build.ps1 *> all.txt           # every stream to file

New-Item x.txt | Out-Null        # discard output
$null = New-Item y.txt           # faster way to discard

Code Explained

implicit output — an uncaptured value goes down the pipeline
Write-Host — writes to stream 6 (Information) for display; not captured by $var =
2>&1 — redirect stream 2 into stream 1 so errors can be captured
$null = — discard; also [void](...) and | Out-Null

⚠ Common Mistakes

  • Using Write-Host in a function that should return data. The caller gets nothing back; output with a bare value or Write-Output
  • Stray output: $list.Add(1) on an ArrayList returns an index that leaks into the function result. Discard with $null =
  • Expecting Write-Error to stop the script. It’s non-terminating; use throw or -ErrorAction Stop

✓ Tips & Best Practices

  • Use Write-Verbose for progress notes; users opt in with -Verbose
  • Prefer $null = … over | Out-Null in loops. It skips the pipeline and is much faster
  • Use Write-Progress -Activity 'Copy' -PercentComplete 40 for long jobs

Quick Summary

  • "text" — implicit output to stream 1
  • Write-Host — display only, can’t be captured
  • Write-Verbose/Warning/Error — streams 4, 3, 2
  • 2>&1 / *> — merge or redirect streams
