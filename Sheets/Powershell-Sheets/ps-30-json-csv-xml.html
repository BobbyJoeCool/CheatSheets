Sheet 30

JSON, CSV & XML

ConvertTo-Json -Depth · ConvertFrom-Json · Import-Csv / Export-Csv · [xml] · Select-Xml · Export-Clixml

Overview

PowerShell converts structured text into objects and back. JSON and CSV round-trip with paired ConvertTo- / ConvertFrom- and Import- / Export- cmdlets; XML is cast with [xml] and navigated with dots. CLIXML saves full PowerShell objects, types included.

Notes

  • ConvertTo-Json default -Depth is 2; deeper data is flattened
  • Every CSV value comes back as a string
  • 7 drops the CSV #TYPE line; 5.1 needs -NoTypeInformation
  • -AsHashtable (6+) gives a hashtable instead of PSCustomObject

Round-Tripping Data

$cfg = Get-Content .\config.json -Raw | ConvertFrom-Json
$cfg.database.port                       # 5432
$cfg | ConvertTo-Json -Depth 10 | Set-Content .\config.json

@{ name = 'web'; tags = 'a', 'b' } | ConvertTo-Json -Compress
# {"name":"web","tags":["a","b"]}

$users = Import-Csv .\users.csv          # one object per row
$users | Where-Object { [int]$_.Age -gt 30 }
$users | Export-Csv .\out.csv -NoTypeInformation
'a,b', '1,2' | ConvertFrom-Csv            # from strings

[xml]$doc = Get-Content .\web.config -Raw
$doc.configuration.appSettings.add | Where-Object key -eq 'Mode'
Select-Xml -Xml $doc -XPath '//add[@key="Mode"]'

Get-Process | Export-Clixml .\procs.xml  # full objects

Code Explained

ConvertFrom-Json — JSON text → objects; use -Raw so it gets one string
-Depth 10 — prevents nested objects becoming “System.Collections…” text
-Compress — single-line JSON
[int]$_.Age — CSV fields are text; cast before numeric comparisons
[xml] — parses the text into an XmlDocument you can dot into
Export-Clixml — keeps types; re-import with Import-Clixml

⚠ Common Mistakes

  • Forgetting -Depth on ConvertTo-Json. Nested data silently becomes type-name strings (7.1+ warns)
  • Comparing CSV numbers as text: '100' -gt '9' is False. Cast fields with [int] or [double]
  • Piping Format-Table into Export-Csv. You export formatting objects; select properties instead

✓ Tips & Best Practices

  • Use ConvertTo-Json -Depth 10 as a habit for config files
  • Use Export-Clixml with Get-Credential to store a credential encrypted for the current user (Windows)
  • Use Import-Csv | Group-Object Dept -AsHashTable to build lookups from spreadsheets

Quick Summary

  • ConvertFrom-Json / ConvertTo-Json -Depth — JSON round-trip
  • Import-Csv / Export-Csv — CSV rows as objects
  • [xml] / Select-Xml — parse and query XML
  • Export-Clixml — save full objects
