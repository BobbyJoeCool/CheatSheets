Sheet 10

String Methods & Operators

-split / .Split() · -join · -replace / .Replace() · .Trim() · .Substring() · IsNullOrWhiteSpace

Overview

Strings have both operators (-split, -join, -replace) and .NET methods (.Split(), .Replace()). The key difference: operators are case-insensitive and use regex; methods are case-sensitive and literal. Pick based on whether you need a pattern.

Notes

  • -split '.' splits on every character (regex). Use '\.'
  • Methods are case-sensitive: 'Hi'.Contains('hi') → False
  • -replace supports $1 capture groups in the replacement
  • Indexes are 0-based; $s[-1] is the last character

Splitting, Joining, Replacing

$s = '  Hello, World  '
$s.Trim()                         # 'Hello, World'

'a,b,,c' -split ','               # a b '' c
'a1b22c' -split '\d+'             # a b c  (regex)
'one two' -split ' ', 2           # max 2 pieces
'a.b.c'.Split('.')                # a b c  (literal)
'x','y','z' -join '-'             # x-y-z

'Hello' -replace 'l', 'L'         # HeLLo
'2026-10-06' -replace '(\d+)-(\d+)-(\d+)', '$3/$2/$1'  # 06/10/2026
'a.b'.Replace('.', '!')           # a!b

'PowerShell'.Substring(0, 5)      # Power
'PowerShell'.IndexOf('Shell')     # 5
'PowerShell'.StartsWith('power', 'OrdinalIgnoreCase')  # True
[string]::IsNullOrWhiteSpace('  ')  # True

Code Explained

.Trim() — removes whitespace, or the characters you pass
-split ',' — regex split; empty strings are kept
-split ' ', 2 — limit the number of pieces
'$3/$2/$1' — single quotes so PowerShell doesn’t expand $3
.Replace() — literal and case-sensitive, no regex escaping needed
'OrdinalIgnoreCase' — string auto-converts to [StringComparison]

⚠ Common Mistakes

  • Splitting on ., | or $ with -split. These are regex metacharacters; escape them or use .Split()
  • Using double quotes around a replacement with $1. PowerShell expands it to empty first; use single quotes
  • Calling methods on $null. $x.Trim() throws if $x is null; test with IsNullOrWhiteSpace first

✓ Tips & Best Practices

  • Use -split '\r?\n' to split text into lines
  • Use [regex]::Escape($userText) before putting user input into a pattern
  • For case-insensitive substring tests use $s -like '*word*'

Quick Summary

  • -split / -join — break apart / glue together
  • -replace regex vs .Replace() literal
  • .Trim(), .Substring(), .IndexOf() — .NET methods
  • [string]::IsNullOrWhiteSpace() — null-safe empty check
