Pipeline Basics

Where-Object · ForEach-Object · Select-Object · Sort-Object · Group-Object · Measure-Object

Overview

The pipeline (|) passes whole objects from one command to the next, one at a time, so you filter and sort on real properties like CPU or Length instead of parsing text. A handful of *-Object cmdlets do most of the work: filter, transform, pick, sort, group, and measure.

Notes

  • Objects stream: the next command starts before the first finishes
  • Inside script blocks, $_ is the current object
  • Filter left: use a cmdlet’s own -Filter when it has one
  • Line breaks are allowed after a |

The Core Pipeline Cmdlets

Get-Process | Where-Object { $_.CPU -gt 100 }      # script block form
Get-Service | Where-Object Status -eq 'Running'    # simplified form

Get-ChildItem *.log | ForEach-Object { $_.Name.ToUpper() }
Get-ChildItem | ForEach-Object Name                # member shortcut

Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
Get-Process | Select-Object Name, Id, CPU
Get-Process | Select-Object -ExpandProperty Name   # plain strings

Get-ChildItem -File | Group-Object Extension |
    Sort-Object Count -Descending

Get-ChildItem -File -Recurse | Measure-Object Length -Sum -Average

(1..10).Where({ $_ % 2 -eq 0 })                    # 2 4 6 8 10
(1..3).ForEach({ $_ * 10 })                        # 10 20 30

Code Explained

Where-Object — keeps objects where the test is true
ForEach-Object — runs a block for each object; output flows on
-ExpandProperty — returns the property value, not an object with one property
Group-Object — buckets by property; output has Name, Count, Group
Measure-Object — Count, Sum, Average, Minimum, Maximum
.Where() / .ForEach() — array methods; faster than the cmdlets on in-memory data

⚠ Common Mistakes

  • Filtering late: Get-ChildItem -Recurse | Where-Object Name -like '*.log' reads everything; -Filter *.log is far faster
  • Using Select-Object Name when you need strings. You get objects with a Name property; use -ExpandProperty
  • Sorting text that holds numbers. '10','9' | Sort-Object → 10, 9; sort on { [int]$_ }

✓ Tips & Best Practices

  • Pipe to Get-Member mid-pipeline to see what the next command receives
  • Sort by several keys: Sort-Object Department, @{e='Salary'; Descending=$true}
  • Use Select-Object -First 1 to stop the upstream command early

Quick Summary

  • Where-Object — filter by property
  • ForEach-Object — act on each object
  • Select-Object / Sort-Object — pick and order
  • Group-Object / Measure-Object — bucket and summarize
