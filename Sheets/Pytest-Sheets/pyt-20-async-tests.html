Sheet 20

Async Tests

pytest-asyncio · asyncio_mode = "auto" · @pytest.mark.asyncio · async fixtures · loop_scope · AnyIO plugin

Testing async def Code

pytest can't run async def tests on its own. The pytest-asyncio plugin runs them on an event loop: mark a test with @pytest.mark.asyncio, or set asyncio_mode = "auto" so every async test and fixture is handled. Async fixtures work too. Projects using AnyIO or Trio can use AnyIO's pytest plugin with @pytest.mark.anyio instead.

Notes

  • pip install pytest-asyncio (1.x)
  • By default each test gets its own event loop
  • loop_scope="module" shares one loop across a module's tests
  • Never call asyncio.run inside an async test

Under the Hood

  • pytest-asyncio creates an event loop per loop scope and runs the test coroutine on it
  • A module-scoped async fixture must run on a loop at least that wide, or you get "attached to a different loop" errors
  • Set the default with asyncio_default_fixture_loop_scope

pytest-asyncio

# pyproject.toml
# [tool.pytest]
# asyncio_mode = "auto"
# asyncio_default_fixture_loop_scope = "function"

import asyncio, httpx, pytest

@pytest.fixture
async def client():                       # async fixture
    async with httpx.AsyncClient(base_url="http://test",
                                 transport=httpx.ASGITransport(app=app)) as c:
        yield c

async def test_get_order(client):         # auto mode: no mark needed
    resp = await client.get("/orders/1")
    assert resp.status_code == 200

@pytest.mark.asyncio(loop_scope="module")
async def test_shared_loop(): ...

async def test_timeout():
    with pytest.raises(TimeoutError):
        async with asyncio.timeout(0.1):
            await slow_call()

# AnyIO instead of pytest-asyncio
@pytest.mark.anyio
async def test_with_anyio(): ...

Code Explained

In auto mode every async def test and fixture is handled by pytest-asyncio
ASGITransport calls a FastAPI / Starlette app in memory, no server needed
asyncio.timeout (3.11+) makes a slow await fail instead of hanging
The AnyIO plugin needs an anyio_backend fixture to pick asyncio or trio

unittest Equivalent

  • async test → unittest.IsolatedAsyncioTestCase with async def test_x(self)
  • async fixture → async def asyncSetUp(self) / asyncTearDown

Prefer / Avoid

  • asyncio.run(...) inside a sync test → an async def test
  • await asyncio.sleep(1) to wait for work → await the event or task directly
  • mixing loop scopes by accident → set asyncio_default_fixture_loop_scope

⚠ Common Mistakes

  • Writing async def test_x without the plugin; pytest skips or warns instead of running it
  • A module-scoped async fixture with function-scoped loops ("Future attached to a different loop")
  • Testing timing with real sleep calls that make the suite slow and flaky

✓ Tips & Best Practices

  • Use asyncio_mode = "auto" unless you mix asyncio and trio
  • Wrap awaits that might hang in asyncio.timeout
  • Test ASGI apps in memory with httpx.ASGITransport

Quick Summary

  • pytest-asyncio — run async def tests
  • asyncio_mode = "auto" — no marks needed
  • async fixtures with yield
  • loop_scope — share a loop
