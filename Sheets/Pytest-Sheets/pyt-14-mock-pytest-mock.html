Sheet 14

unittest.mock & pytest-mock

mocker.patch · MagicMock · return_value · side_effect · assert_called_once_with · mocker.spy · autospec=True

Fakes That Record How They Were Used

A mock stands in for a real object and records every call, so a test can check *how* the code used it. The standard library's unittest.mock provides Mock, MagicMock and patch; the pytest-mock plugin wraps them in a mocker fixture that undoes patches automatically. Configure results with return_value and side_effect, then assert on calls.

Notes

  • pip install pytest-mock for the mocker fixture
  • autospec=True makes the mock reject calls that don't match the real signature
  • mocker.spy wraps a real function: it still runs, but calls are recorded
  • The same "patch where it's looked up" rule applies

Under the Hood

  • patch replaces the name in the target module's namespace for the duration, then restores it
  • autospec builds the mock from the real object, so wrong argument counts and missing attributes raise
  • A plain MagicMock accepts anything, which can hide bugs

Mocking an HTTP Client

def test_fetch_rate(mocker):
    get = mocker.patch("shop.rates.httpx.get", autospec=True)
    get.return_value.json.return_value = {"rate": 1.1}

    assert fetch_rate("EUR") == 1.1
    get.assert_called_once_with("https://rates.example/EUR", timeout=5)

def test_retries_then_succeeds(mocker):
    send = mocker.patch("shop.mail.smtp_send", autospec=True)
    send.side_effect = [ConnectionError, ConnectionError, None]
    notify("ann@example.com")
    assert send.call_count == 3

def test_raises(mocker):
    mocker.patch("shop.rates.fetch_rate", side_effect=TimeoutError)
    with pytest.raises(RateUnavailable):
        convert(10, "EUR")

def test_spy(mocker):
    spy = mocker.spy(shop.cart, "recalculate")
    cart.add("apple")
    spy.assert_called_once()           # real recalculate still ran

# without the plugin
from unittest.mock import patch
def test_plain():
    with patch("shop.rates.fetch_rate", return_value=2.0) as m:
        assert convert(1, "EUR") == 2.0

Code Explained

return_value.json.return_value configures what httpx.get(...).json() returns
side_effect as a list returns or raises each item in turn
side_effect=TimeoutError makes every call raise
mocker.spy keeps the real behavior and adds call recording

unittest Equivalent

  • mocker.patch(...) → @patch("…") decorator or with patch(…) block
  • mocker.spy → patch.object(obj, "fn", wraps=obj.fn)
  • mocker auto-undo → patch restores on exit, or self.addCleanup(p.stop)

Prefer / Avoid

  • bare MagicMock() for a real class → autospec=True / create_autospec
  • asserting every internal call → assert on results; check calls only at boundaries
  • mock.called == True → mock.assert_called_once_with(…)

Configuring a Mock

AttributeEffect
return_valueWhat a call returns
side_effect = ExcEvery call raises
side_effect = [a, b]Returns / raises in turn
side_effect = fnCalls fn with the same args
spec / autospecRestrict to the real API

Call Assertions

MethodChecks
assert_called()Called at least once
assert_called_once_with(…)Exactly once, these args
assert_any_call(…)Some call matched
assert_not_called()Never called
call_countNumber of calls
call_args_listEvery call's args

⚠ Common Mistakes

  • Typos like assert_caled_once() that silently passed on old Python; current versions raise AttributeError
  • Mocking the code under test itself, so the test checks only the mock
  • Patching httpx.get instead of shop.rates.httpx.get and making real requests

✓ Tips & Best Practices

  • Use autospec=True by default; it catches signature drift when the real API changes
  • Mock at the boundary (network, clock, filesystem), not your own internal functions
  • Prefer a simple fake class over a deeply configured MagicMock chain

Quick Summary

  • mocker.patch(target) — patch + auto-undo
  • return_value / side_effect — behavior
  • assert_called_once_with — check usage
  • autospec=True — match the real signature
