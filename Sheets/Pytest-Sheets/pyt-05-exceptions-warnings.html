Sheet 05

Exceptions & Warnings

pytest.raises · match= · excinfo.value · pytest.RaisesGroup · pytest.warns · pytest.deprecated_call · -W error

Test That Code Fails Correctly

pytest.raises is a context manager that passes only if the block raises the given exception type (or a subclass). match= checks the message with a regex, and the returned ExceptionInfo gives access to the exception object for further asserts. pytest.warns does the same for warnings, and pytest.RaisesGroup checks an ExceptionGroup from asyncio.TaskGroup or except* code.

Notes

  • Keep only the line that should raise inside the with block
  • match uses re.search, so escape special characters with re.escape
  • Pass a tuple to accept several types: raises((KeyError, IndexError))
  • filterwarnings = ["error"] in config makes unexpected warnings fail

raises, warns and Groups

import re, warnings, pytest

def test_bad_discount():
    with pytest.raises(ValueError, match=r"discount must be 0\.\.1"):
        total([10], discount=2)

def test_inspect_exception():
    with pytest.raises(HTTPError) as excinfo:
        client.get("/missing")
    assert excinfo.value.status == 404
    assert excinfo.type is NotFound

def test_literal_message():
    with pytest.raises(KeyError, match=re.escape("['sku']")):
        load({"name": "x"})

def test_task_group():
    with pytest.RaisesGroup(ValueError, TypeError):
        run_all_jobs()

def test_deprecated():
    with pytest.warns(DeprecationWarning, match="use total"):
        old_total([1])
    with pytest.deprecated_call():
        old_total([1])

Code Explained

excinfo.value is the exception instance; excinfo.type its class
Escape regex characters in match, or wrap the text in re.escape
RaisesGroup(ValueError, TypeError) passes when the group holds exactly those exceptions
deprecated_call accepts DeprecationWarning or PendingDeprecationWarning

unittest Equivalent

  • with pytest.raises(E): → with self.assertRaises(E):
  • match= → self.assertRaisesRegex(E, pattern)
  • pytest.warns(W) → self.assertWarns(W)
  • excinfo.value → cm.exception

Prefer / Avoid

  • try: … except E: pass + assert False → with pytest.raises(E):
  • a whole test body inside raises → only the call that should raise
  • raises(Exception) → the specific exception type

⚠ Common Mistakes

  • Catching Exception in raises, so a typo-caused NameError makes the test pass
  • Putting several statements in the block, so the wrong one raises and the test still passes
  • Forgetting that match is a regex: match="cost (USD)" never matches the parentheses literally

✓ Tips & Best Practices

  • Assert on attributes of excinfo.value (status codes, fields) rather than only the message
  • Turn warnings into errors in config, then use warns where a warning is expected
  • Use RaisesGroup(..., allow_unwrapped=True) when code may raise a bare exception or a group

Quick Summary

  • pytest.raises(E, match=) — expected exception
  • excinfo.value — inspect it
  • RaisesGroup — ExceptionGroups
  • warns / deprecated_call — expected warnings
