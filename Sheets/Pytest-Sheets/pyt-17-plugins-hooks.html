Extend pytest From conftest.py

pytest is built from plugins, and so are its extensions: install a package such as pytest-cov and it registers itself. Your own conftest.py is a local plugin too. It can implement hooks, functions with fixed pytest_* names that pytest calls at points in a run, such as adding a CLI option, changing collected tests, or reporting results.

Notes

  • pytest --trace-config lists active plugins
  • -p no:name disables a plugin for one run
  • All hooks are listed in the "API Reference → Hooks" docs
  • Hook arguments are matched by name; take only what you need

Under the Hood

  • Hooks are called through pluggy: every registered implementation runs, in plugin order
  • firstresult hooks stop at the first non-None return
  • @pytest.hookimpl(wrapper=True) wraps other implementations with yield

A --runslow Option in conftest.py

import pytest

def pytest_addoption(parser):
    parser.addoption("--runslow", action="store_true",
                     help="run tests marked slow")

def pytest_configure(config):
    config.addinivalue_line("markers", "slow: takes more than a second")

def pytest_collection_modifyitems(config, items):
    if config.getoption("--runslow"):
        return
    skip_slow = pytest.mark.skip(reason="needs --runslow")
    for item in items:
        if "slow" in item.keywords:
            item.add_marker(skip_slow)

@pytest.hookimpl(wrapper=True)
def pytest_runtest_call(item):
    start = time.perf_counter()
    result = yield                       # run the test
    item.user_properties.append(("secs", time.perf_counter() - start))
    return result

def pytest_report_header(config):
    return f"api: {os.environ.get('API_URL', 'local')}"

Code Explained

pytest_addoption adds --runslow; fixtures read it with pytestconfig.getoption
pytest_collection_modifyitems can skip, reorder or deselect tests after collection
The wrapper hook runs code around every test call
pytest_report_header adds a line to the top of the output

unittest Equivalent

  • plugins and hooks → no plugin system; subclass TestRunner / TestResult or use load_tests
  • pytest_collection_modifyitems → a custom load_tests(loader, tests, pattern) function

Prefer / Avoid

  • editing every slow test to check an env var → one collection_modifyitems hook
  • copy-pasting helpers between repos → package them as a plugin with an entry point
  • old hookwrapper=True + outcome.get_result() → wrapper=True + result = yield

⚠ Common Mistakes

  • Defining pytest_plugins in a non-root conftest.py, which is an error
  • Misspelling a hook name; pytest only warns about unknown pytest_* names in strict setups
  • Doing heavy work in pytest_configure that slows every run, even --co

✓ Tips & Best Practices

  • Start with conftest.py hooks; turn them into a package only when several repos need them
  • Use item.user_properties to attach data that shows up in JUnit XML
  • Read a plugin's source; most are a few hundred lines of hooks

Quick Summary

  • plugins — installed packages and conftest.py
  • hooks — pytest_* functions pytest calls
  • addoption + collection_modifyitems — custom flags
  • wrapper=True — run code around a hook
