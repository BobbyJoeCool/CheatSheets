monkeypatch

setattr · setenv / delenv · setitem · chdir · syspath_prepend · context() · automatic undo

Temporary Patches, Undone for You

The monkeypatch fixture replaces attributes, dictionary items, environment variables and the working directory for the length of one test, then puts everything back during teardown. Use it to swap a slow or external function for a fake, set environment variables, or simulate a missing key, without leaking changes into other tests.

Notes

  • Patch the name where it is looked up: "shop.cart.requests.get", not "requests.get"
  • raising=False allows setting an attribute that doesn't exist yet
  • monkeypatch.context() limits a patch to a with block
  • It's function-scoped; use pytest.MonkeyPatch.context() in wider fixtures

Under the Hood

  • Each patch records the original value on an undo stack
  • At teardown, undo() restores entries in reverse order
  • That's why it can't be requested by module- or session-scoped fixtures

Patching Without Cleanup Code

import pytest
import shop.rates

def test_converts_with_fake_rate(monkeypatch):
    monkeypatch.setattr(shop.rates, "fetch_rate", lambda cur: 2.0)
    assert convert(10, "EUR") == 20.0

def test_dotted_string_target(monkeypatch):
    monkeypatch.setattr("shop.cart.now", lambda: 1_700_000_000)

def test_env(monkeypatch):
    monkeypatch.setenv("API_URL", "http://localhost:9999")
    monkeypatch.delenv("API_TOKEN", raising=False)
    assert Settings().api_url.endswith("9999")

def test_dict_item(monkeypatch):
    monkeypatch.setitem(CONFIG, "retries", 0)
    monkeypatch.delitem(CONFIG, "proxy", raising=False)

def test_cwd(monkeypatch, tmp_path):
    monkeypatch.chdir(tmp_path)
    write_default_config()
    assert (tmp_path / "config.toml").exists()

@pytest.fixture(scope="module")
def offline():
    with pytest.MonkeyPatch.context() as mp:
        mp.setattr("socket.socket", None)
        yield

Code Explained

setattr(module, "name", value) or the dotted-string form both work
delenv(..., raising=False) doesn't fail if the variable isn't set
chdir is undone too, so relative paths in later tests still work
pytest.MonkeyPatch.context() is the way to patch in wider-scoped fixtures

unittest Equivalent

  • monkeypatch.setattr → unittest.mock.patch("mod.name", value) as decorator or context manager
  • setenv → patch.dict(os.environ, {"API_URL": …})
  • setitem → patch.dict(CONFIG, {…})
  • automatic undo → patch restores when the block exits

Prefer / Avoid

  • assigning module.func = fake by hand → monkeypatch.setattr
  • patching requests.get globally → patch shop.cart.requests.get where it's used
  • os.environ["X"] = "y" in a test → monkeypatch.setenv

⚠ Common Mistakes

  • Patching the original module after the code under test did from x import fn
  • Setting os.environ directly and leaking the value into later tests
  • Requesting monkeypatch from a module-scoped fixture (ScopeMismatch)

✓ Tips & Best Practices

  • Find the right target by asking "which module's namespace does the code read this name from?"
  • Use monkeypatch for simple replacements; use mocks (sheet 14) when you need to check calls
  • Combine with tmp_path and chdir to test code that uses relative paths

Quick Summary

  • setattr — swap a function or value
  • setenv / delenv — environment
  • chdir — working directory
  • undone automatically at teardown
