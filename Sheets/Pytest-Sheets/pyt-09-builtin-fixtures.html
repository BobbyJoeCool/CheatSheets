Sheet 09

Built-in Fixtures

tmp_path · tmp_path_factory · capsys / capfd · caplog · monkeypatch · request · pytestconfig

Fixtures pytest Gives You

pytest ships fixtures for the chores every test suite needs: a fresh temporary directory (tmp_path), captured stdout and stderr (capsys, capfd), captured log records (caplog), safe patching of attributes and environment variables (monkeypatch, sheet 13), and access to the test and config (request, pytestconfig). Request them like any fixture.

Notes

  • tmp_path is a pathlib.Path, unique per test, kept for the last 3 runs
  • capsys.readouterr() returns (out, err) and resets the buffers
  • caplog.set_level(logging.DEBUG) captures lower levels
  • tmpdir (py.path) is legacy; use tmp_path

Using the Built-ins

import logging, json

def test_writes_report(tmp_path):
    out = tmp_path / "report.json"
    write_report(out, {"total": 3})
    assert json.loads(out.read_text()) == {"total": 3}

def test_cli_prints(capsys):
    main(["--version"])
    out, err = capsys.readouterr()
    assert out.strip() == "orders 1.4.0"
    assert err == ""

def test_warns_in_log(caplog):
    caplog.set_level(logging.WARNING, logger="shop")
    apply_discount(cart, 0.9)
    assert "large discount" in caplog.text
    assert caplog.records[0].levelname == "WARNING"

def test_reads_env(monkeypatch):
    monkeypatch.setenv("APP_ENV", "test")
    assert load_settings().env == "test"

def test_option(pytestconfig):
    if pytestconfig.getoption("--runslow"): ...

Code Explained

Each test gets its own empty tmp_path, so file tests never collide
readouterr() empties the buffer, so call it again after more output
caplog.text is the formatted log; caplog.records are LogRecord objects
pytestconfig.getoption reads custom CLI options added in conftest.py

unittest Equivalent

  • tmp_path → tempfile.TemporaryDirectory() in setUp + addCleanup
  • capsys → contextlib.redirect_stdout(io.StringIO())
  • caplog → self.assertLogs("shop", level="WARNING")
  • monkeypatch.setenv → unittest.mock.patch.dict(os.environ, …)

Prefer / Avoid

  • tempfile.mkdtemp() with manual cleanup → tmp_path
  • tmpdir → tmp_path
  • patching sys.stdout by hand → capsys

⚠ Common Mistakes

  • Writing test files into the repo or /tmp instead of tmp_path
  • Using capsys for output from a subprocess or C extension; that needs capfd
  • Expecting caplog to catch DEBUG messages without setting the level

✓ Tips & Best Practices

  • Use tmp_path_factory.mktemp in session fixtures that need a directory
  • Assert on caplog.messages for exact messages without timestamps
  • Run pytest --fixtures to see every built-in and plugin fixture available
