Upgrading React

18 → 19 changes · codemods · removed APIs · propTypes / defaultProps · ReactDOM.render removal · @types/react changes

Moving to React 19

Upgrade in two steps: first to React 18.3, which adds warnings for every API removed in 19, then to 19. Run the official codemods to update most code automatically, and update @types/react with the types codemod. The biggest removals are ReactDOM.render, string refs, legacy context, propTypes checking and defaultProps on function components. After that, adopt new features gradually: Actions, use, ref as a prop.

Notes

  • npx codemod@latest react/19/migration-recipe runs the main code changes
  • npx types-react-codemod@latest preset-19 ./src updates TypeScript types
  • Libraries must support React 19 too; check peer dependencies
  • Minor releases since 19.0 (19.1, 19.2, 19.3) add features without breaking changes

♿ Accessibility

  • Re-run accessibility tests after upgrading; changed error handling or Suspense timing can affect focus and announcements

Version Notes

  • React 19.0 (Dec 2024), 19.1 (Mar 2025), 19.2 (Oct 2025), 19.3 (Sep 2026)
  • React 18 apps keep working on 18.3; security patches are backported to supported lines

Code Explained

18.3 warns about every API that 19 removes
The migration recipe codemod rewrites renders, refs and imports
The types codemod fixes @types/react 19 breakages
Default parameters replace defaultProps
ref as a prop replaces forwardRef

Upgrade Steps and Common Changes

# 1. Step through 18.3 to see deprecation warnings
npm install react@18.3 react-dom@18.3

# 2. Upgrade
npm install react@^19 react-dom@^19
npm install -D @types/react@^19 @types/react-dom@^19

# 3. Codemods
npx codemod@latest react/19/migration-recipe
npx types-react-codemod@latest preset-19 ./src

// Removed: ReactDOM.render
ReactDOM.render(<App />, el);                    // ✗
createRoot(el).render(<App />);                  // ✓

// Removed: defaultProps on function components
Button.defaultProps = { size: 'md' };            // ✗
function Button({ size = 'md' }) {}              // ✓

// Removed: propTypes checking (silently ignored)
Button.propTypes = { size: PropTypes.string };   // ✗ use TS

// Removed: string refs
<input ref="name" />                             // ✗
<input ref={nameRef} />                          // ✓

// Deprecated: forwardRef, Context.Provider
const In = forwardRef((p, ref) => <input ref={ref} />);
function In2({ ref }) { return <input ref={ref} />; }  // ✓

// Types: useRef needs an argument; global JSX removed
useRef<number>();                                // ✗
useRef<number | null>(null);                     // ✓

⚠ Common Mistakes

  • Jumping straight from 17 or 18.0 to 19 without the 18.3 step
  • Upgrading React before checking that key libraries support 19
  • Rewriting everything to new APIs at once

✓ Tips & Best Practices

  • Upgrade on a branch with full tests and StrictMode enabled
  • Read the official React 19 Upgrade Guide for edge cases
  • Adopt the React Compiler after the upgrade settles

Quick Summary

  • 18.3 first, then 19
  • Run code + types codemods
  • Removed: render, string refs, propTypes
  • Adopt new APIs gradually
