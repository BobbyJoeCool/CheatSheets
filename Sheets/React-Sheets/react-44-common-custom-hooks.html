Sheet 44

Common Custom Hooks

useToggle · useLocalStorage · useDebounce · useMediaQuery · useOnClickOutside · usePrevious · useOnlineStatus

A Starter Kit

A handful of small hooks show up in almost every codebase. They wrap browser APIs (matchMedia, localStorage, online events), timers (debounce) and DOM events (click outside) behind a simple interface. Write your own for learning; for production, libraries like usehooks-ts or react-use offer tested versions with SSR handling.

Notes

  • Guard browser APIs for server rendering (typeof window !== 'undefined')
  • Subscriptions to external sources are best built on useSyncExternalStore (sheet 45)
  • Debounce values for search inputs; throttle for scroll and resize
  • usePrevious reads a value from the previous render

♿ Accessibility

  • useMediaQuery('(prefers-reduced-motion: reduce)') lets components disable animation
  • Click-outside handlers should also close on Escape

Version Notes

  • Plain hook code; works on React 18 and 19
  • React 19.2's useEffectEvent simplifies hooks that call user callbacks

Code Explained

useLocalStorage reads once lazily and writes on every change
useDebounce resets its timer whenever value changes
useMediaQuery uses useSyncExternalStore, with false on the server
useEffectEvent lets the latest handler run without re-subscribing
ref.current?. guards against the element not being mounted yet

Common Hooks

export function useLocalStorage(key, initial) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key);
    return saved !== null ? JSON.parse(saved) : initial;
  });
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);
  return [value, setValue];
}

export function useDebounce(value, delay = 300) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

export function useMediaQuery(query) {
  return useSyncExternalStore(
    (cb) => {
      const mql = matchMedia(query);
      mql.addEventListener('change', cb);
      return () => mql.removeEventListener('change', cb);
    },
    () => matchMedia(query).matches,
    () => false,
  );
}

export function useOnClickOutside(ref, handler) {
  const onOutside = useEffectEvent(handler);
  useEffect(() => {
    const listener = (e) => {
      if (!ref.current?.contains(e.target)) onOutside(e);
    };
    const doc = document;
    doc.addEventListener('pointerdown', listener);
    return () => doc.removeEventListener('pointerdown', listener);
  }, [ref]);
}

⚠ Common Mistakes

  • Reading localStorage during render on the server
  • Debouncing the handler instead of the value and losing the latest input
  • Forgetting to remove document listeners

✓ Tips & Best Practices

  • Debounce search: const q = useDebounce(input, 300)
  • Wrap JSON.parse in try for corrupted storage
  • Prefer CSS media queries when only styles change

Quick Summary

  • Wrap browser APIs in hooks
  • Guard for SSR
  • Debounce values, not handlers
  • Use a library in production
