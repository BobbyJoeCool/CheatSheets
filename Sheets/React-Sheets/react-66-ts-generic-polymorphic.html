generic props <T,> · as prop · ComponentPropsWithoutRef · discriminated union props · ref prop types · satisfies

Flexible Component Types

Generic components take a type parameter so their props stay linked: a List<T> whose items are T[] passes T to renderItem. In .tsx files write <T,> so the compiler doesn't read it as JSX. Polymorphic components take an as prop to choose the rendered element and accept that element's props. Discriminated union props make prop combinations explicit and reject invalid ones.

Notes

  • ComponentPropsWithoutRef<E> excludes ref when you handle it separately
  • In React 19, ref is a normal prop and included in ComponentProps<'button'>
  • Omit<Props, 'x'> avoids conflicts when merging prop types
  • satisfies checks an object against a type without widening it

♿ Accessibility

  • When a polymorphic component renders a non-button element with onClick, require role and keyboard handling, or restrict as to interactive elements

Version Notes

  • Generic components are standard TypeScript; no React-specific API
  • React 19 removes the need for forwardRef generics workarounds

Code Explained

Generic, Polymorphic, Union Props

import type { ComponentPropsWithoutRef, ElementType, ReactNode } from 'react';

// Generic list
type ListProps<T> = {
  items: T[];
  getKey: (item: T) => string;
  renderItem: (item: T) => ReactNode;
};
export function List<T,>({ items, getKey, renderItem }: ListProps<T>) {
  return <ul>{items.map((i) => <li key={getKey(i)}>{renderItem(i)}</li>)}</ul>;
}
<List items={users} getKey={(u) => u.id}
  renderItem={(u) => u.name} />;    // u: User

// Polymorphic "as" prop
type TextProps<E extends ElementType> = {
  as?: E;
  children: ReactNode;
} & Omit<ComponentPropsWithoutRef<E>, 'as' | 'children'>;

export function Text<E extends ElementType = 'span'>(
  { as, children, ...rest }: TextProps<E>) {
  const Tag = as ?? 'span';
  return <Tag {...rest}>{children}</Tag>;
}
<Text as="a" href="/docs">Docs</Text>;      // href allowed
<Text as="label" htmlFor="x">Name</Text>;

// Discriminated union props
type AlertProps =
  | { kind: 'info'; message: string }
  | { kind: 'action'; message: string; onAction: () => void;
      actionLabel: string };
function Alert(props: AlertProps) {
  if (props.kind === 'action')
    return <button onClick={props.onAction}>{props.actionLabel}</button>;
  return <p>{props.message}</p>;
}

⚠ Common Mistakes

  • Writing <T> in .tsx and getting a JSX parse error
  • Polymorphic types so complex they slow the editor
  • Optional props that only make sense together (use a union)

✓ Tips & Best Practices

  • Keep polymorphic components to a few low-level primitives
  • Let inference pick T instead of passing it explicitly
  • Use libraries' asChild/Slot patterns as an alternative to as

Quick Summary
