View Transitions

<ViewTransition> · enter / exit · shared element names · startTransition trigger · addTransitionType · ::view-transition CSS

Animated UI Changes

<ViewTransition> animates elements when they change inside a transition, using the browser's View Transitions API. Wrap the part of the UI you want to animate; when an update happens in startTransition, useDeferredValue or Suspense reveals, React captures the before and after and cross-fades by default. Give elements on two screens the same name for shared-element animations, and style everything with CSS.

Notes

  • Only updates inside transitions (and Suspense reveals) animate; urgent updates don't
  • Props enter, exit, update, share pick CSS classes for each kind of change
  • name pairs an element that disappears with one that appears: a shared transition
  • addTransitionType('forward') lets CSS choose animations by navigation direction

♿ Accessibility

  • Respect prefers-reduced-motion: disable or shorten view-transition animations in CSS
  • Animations must not move focus or hide content longer than necessary

Version Notes

  • <ViewTransition> and addTransitionType are stable in React 19.3 (September 2026)
  • Requires browser support for the View Transitions API; unsupported browsers skip the animation

Code Explained

startTransition makes the change eligible for animation
Matching names morph the thumbnail into the hero image
addTransitionType('open') tags the transition for direction-specific CSS
enter/exit classes target the browser's view-transition pseudo-elements
The reduced-motion query turns animations off

ViewTransition

import {
  ViewTransition, startTransition, addTransitionType,
} from 'react';

function Gallery({ photos }) {
  const [selected, setSelected] = useState(null);

  function open(photo) {
    startTransition(() => {
      addTransitionType('open');
      setSelected(photo);
    });
  }

  return selected ? (
    <ViewTransition name={`photo-${selected.id}`}>
      <img className="hero" src={selected.src} alt={selected.alt} />
    </ViewTransition>
  ) : (
    <ul>
      {photos.map((p) => (
        <li key={p.id}>
          <ViewTransition name={`photo-${p.id}`}>
            <img src={p.thumb} alt={p.alt} onClick={() => open(p)} />
          </ViewTransition>
        </li>
      ))}
    </ul>
  );
}

<ViewTransition enter="slide-in" exit="slide-out">
  {show && <Panel />}
</ViewTransition>

/* CSS */
::view-transition-old(.slide-out) { animation: out 200ms; }
::view-transition-new(.slide-in) { animation: in 200ms; }
@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*) { animation: none; }
}

⚠ Common Mistakes

  • Calling setState outside a transition and expecting animation
  • Reusing the same name on two visible elements at once
  • Long animations that delay interaction

✓ Tips & Best Practices

  • Start with the default cross-fade, then add named shared elements
  • Keep animations under ~300ms
  • Use transition types for forward/back navigation styles

Quick Summary
