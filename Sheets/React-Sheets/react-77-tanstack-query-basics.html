TanStack Query: Setup & Queries

QueryClientProvider · useQuery · queryKey · queryFn · isPending / isError · staleTime · gcTime

Server State, Cached

TanStack Query manages server state: data that lives on a server and is fetched, cached and kept fresh in the browser. Wrap the app in QueryClientProvider, then call useQuery({ queryKey, queryFn }). The query key identifies the data in the cache; any component using the same key shares one request and one cached result. Data is refetched automatically when it's stale and the window regains focus or reconnects.

Notes

  • staleTime (default 0): how long data counts as fresh; fresh data isn't refetched
  • gcTime (default 5 min): how long unused data stays in the cache
  • Include every variable the queryFn uses in the queryKey
  • Failed queries retry 3 times with backoff by default

♿ Accessibility

  • Render isPending and isError states as text, with role="status" and role="alert"
  • Background refetches (isFetching) shouldn't replace content with spinners; show a subtle indicator

Version Notes

  • TanStack Query v5 is current: object-only signature, isPending (renamed from isLoading), gcTime (renamed from cacheTime)
  • Supports React 18 and 19, including Suspense

Code Explained

One QueryClient holds the cache for the whole app
staleTime: 60_000 treats data as fresh for a minute
['todos', { status }] caches each status separately
queryFn must throw on HTTP errors so isError works
isPending is the first load; isFetching includes background refreshes

Setup and useQuery

import {
  QueryClient, QueryClientProvider, useQuery,
} from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';

const queryClient = new QueryClient({
  defaultOptions: { queries: { staleTime: 60_000 } },
});

export function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <Todos status="open" />
      <ReactQueryDevtools />
    </QueryClientProvider>
  );
}

async function fetchTodos(status) {
  const res = await fetch(`/api/todos?status=${status}`);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}

function Todos({ status }) {
  const { data, error, isPending, isError, isFetching } = useQuery({
    queryKey: ['todos', { status }],
    queryFn: () => fetchTodos(status),
  });

  if (isPending) return <p role="status">Loading…</p>;
  if (isError) return <p role="alert">{error.message}</p>;

  return (
    <>
      {isFetching && <small>Refreshing…</small>}
      <ul>{data.map((t) => <li key={t.id}>{t.title}</li>)}</ul>
    </>
  );
}

⚠ Common Mistakes

  • Leaving variables out of the query key, so different inputs share a cache entry
  • Not throwing on res.ok === false
  • Copying query data into useState

✓ Tips & Best Practices

  • Set a sensible global staleTime to cut refetches
  • Build keys with a factory: todoKeys.list(status)
  • Use Devtools to inspect cache entries and states

Quick Summary
