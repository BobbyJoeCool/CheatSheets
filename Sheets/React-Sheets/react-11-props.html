Passing Data Down

Props are the arguments a parent passes to a child, written like HTML attributes. The child receives them as a single object, usually destructured in the parameter list. Any value can be a prop: strings, numbers, objects, arrays, functions and JSX. Props are read-only: a component must never change its own props; it asks the parent to change them instead.

Notes

  • Default values go in the destructuring pattern: { size = 'md' }
  • A prop with no value (<Modal open />) is true
  • Spread an object to pass many props: <Avatar {...user} />
  • When props change, React re-renders the child with the new values

♿ Accessibility

  • Pass accessible names (label, alt) as required props so callers can't forget them
  • Use aria-* props for state (aria-expanded={isOpen}), not just visual classes

Version Notes

  • React 19 ignores defaultProps on function components; use default parameters
  • propTypes checks were removed in React 19; use TypeScript

Code Explained

Destructuring lists exactly which props Button accepts
variant = 'primary' applies only when the prop is undefined
disabled with no value passes true
{...avatarProps} spreads src and size; alt is added after
Later props win: <X {...a} b={1} /> overrides a.b

Props In, UI Out

function Button({
  label,
  variant = 'primary',   // default value
  disabled = false,
  onClick,
}) {
  return (
    <button
      className={`btn btn-${variant}`}
      disabled={disabled}
      onClick={onClick}
    >
      {label}
    </button>
  );
}

function Toolbar({ user, onSave }) {
  const avatarProps = { src: user.photo, size: 32 };

  return (
    <div className="toolbar">
      <Avatar {...avatarProps} alt={user.name} />
      <Button label="Save" onClick={onSave} />
      <Button label="Delete" variant="danger" disabled />
    </div>
  );
}

// ✗ Mutating props
function Bad({ items }) {
  items.push('x');   // changes the parent's array
  return null;
}

⚠ Common Mistakes

  • Mutating a prop object or array
  • Copying a prop into state and wondering why it stops updating
  • Spreading all props onto a DOM element and leaking unknown attributes

✓ Tips & Best Practices

  • Destructure in the signature so the prop list is visible
  • Prefer several simple props over one big config object
  • Name callback props onSomething to match DOM events

Quick Summary

  • Props = function arguments
  • Defaults via destructuring
  • Read-only; ask the parent to change
  • {...obj} spreads, later props win
