React Compiler

babel-plugin-react-compiler · automatic memoization · Vite setup · 'use no memo' · compiler lint rules · incremental adoption

Automatic Memoization

The React Compiler is a build-time tool that analyzes components and hooks and inserts memoization automatically, at a finer level than hand-written useMemo, useCallback and memo. It assumes your code follows the Rules of React (pure render, no mutation of props or state, Rules of Hooks). Code it can't safely optimize is skipped, not broken. Add it to Vite via the Babel plugin.

Notes

  • Works with React 17, 18 and 19 (17/18 need react-compiler-runtime)
  • Opt a component out with the 'use no memo' directive at the top of its body
  • Compilation mode annotation compiles only functions marked 'use memo'
  • Existing useMemo/useCallback keep working; the compiler respects them

♿ Accessibility

  • No direct effect; fewer re-renders keep focus and screen-reader output steadier

Version Notes

  • React Compiler 1.0 was released in October 2025
  • Next.js, Vite and Expo templates offer it as an option
  • Lint rules ship in eslint-plugin-react-hooks (formerly eslint-plugin-react-compiler)

Code Explained

The Babel plugin runs inside Vite's React plugin
compilationMode: 'annotation' lets you adopt it one component at a time
Plain code is memoized automatically after compiling
'use no memo' skips a component that breaks the rules
DevTools shows a Memo ✨ badge on compiled components

Setup and Directives

# install
npm install -D babel-plugin-react-compiler@latest

// vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [
    react({
      babel: {
        plugins: [['babel-plugin-react-compiler', {
          // compilationMode: 'annotation',
        }]],
      },
    }),
  ],
});

// Before: manual memoization
const visible = useMemo(() => filter(todos, tab), [todos, tab]);
const onAdd = useCallback((t) => add(t), [add]);

// After: write plain code; the compiler caches it
const visible2 = filter(todos, tab);
const onAdd2 = (t) => add(t);

// Opt out one component
function LegacyWidget() {
  'use no memo';
  // mutates during render; fix later
}

// Opt in (annotation mode)
function Expensive() {
  'use memo';
}

⚠ Common Mistakes

  • Enabling it on code that mutates during render
  • Deleting all manual memoization at once without tests
  • Assuming it fixes slow algorithms (it only skips re-work)

✓ Tips & Best Practices

  • Turn on the lint rules first; they're useful even without the compiler
  • Keep useMemo where a value must be stable for an external library
  • Use 'use no memo' as a temporary escape hatch with a TODO

Quick Summary
