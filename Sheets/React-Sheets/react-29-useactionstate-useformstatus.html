useActionState & useFormStatus

[state, formAction, isPending] · previous state · returning errors · useFormStatus · pending · permalink

Results and Pending UI

useActionState wraps an action and keeps its result in state. Your function receives the previous state and the FormData, and whatever it returns becomes the new state, which is perfect for validation errors or success messages. It also returns isPending. useFormStatus, from react-dom, lets any component rendered inside a form read whether that form is submitting.

Notes

  • Signature: const [state, formAction, isPending] = useActionState(fn, initial)
  • Pass formAction to <form action> or <button formAction>
  • useFormStatus() returns { pending, data, method, action }
  • useFormStatus must be called in a child of the <form>, not the component that renders it

♿ Accessibility

  • Render returned errors in an element with role="alert" or link them with aria-describedby
  • Use aria-disabled or disabled on the submit button while pending, and show visible progress text

Version Notes

  • Both hooks are new in React 19; useActionState replaced the canary-era useFormState
  • The optional third argument permalink supports progressive enhancement with Server Functions

Code Explained

The action returns error state instead of throwing
defaultValue={state.email} restores the input after the auto-reset

isPending is also available in SignUpForm if needed

Errors and Pending State

import { useActionState } from 'react';
import { useFormStatus } from 'react-dom';

async function signUp(prevState, formData) {
  const email = String(formData.get('email'));
  if (!email.includes('@')) {
    return { error: 'Enter a valid email', email };
  }
  const res = await api.signUp(email);
  if (!res.ok) return { error: res.message, email };
  return { success: true };
}

function SignUpForm() {
  const [state, formAction, isPending] =
    useActionState(signUp, { error: null });

  if (state.success) return <p role="status">Check your inbox!</p>;

  return (
    <form action={formAction}>
      <label htmlFor="email">Email</label>
      <input id="email" name="email" defaultValue={state.email}
        aria-invalid={!!state.error}
        aria-describedby="email-error" />
      {state.error &&
        <p id="email-error" role="alert">{state.error}</p>}
      <SubmitButton />
    </form>
  );
}

function SubmitButton() {
  const { pending } = useFormStatus();
  return <button disabled={pending}>
    {pending ? 'Signing up…' : 'Sign up'}
  </button>;
}

⚠ Common Mistakes

  • Calling useFormStatus in the same component that renders <form>
  • Forgetting the prevState parameter and treating it as FormData
  • Throwing for validation errors and hitting the error boundary

✓ Tips & Best Practices

  • Return the submitted values so fields can be refilled after reset
  • Build one reusable <SubmitButton> with useFormStatus
  • Keep the action function outside the component so it stays pure and testable

Quick Summary

  • useActionState(fn, init)
  • → [state, formAction, isPending]
  • useFormStatus() in a form child
  • Return errors, don't throw
