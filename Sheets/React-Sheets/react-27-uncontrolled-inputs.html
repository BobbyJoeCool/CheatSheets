Sheet 27

Uncontrolled Inputs

defaultValue · defaultChecked · FormData · useRef · file inputs · form reset

The DOM Owns the Value

An uncontrolled input keeps its own value in the DOM. Set a starting value with defaultValue or defaultChecked, then read the values when you need them: with FormData on submit, or with a ref. This means less code and fewer re-renders, and it's how React 19's form Actions work. File inputs are always uncontrolled.

Notes

  • new FormData(form) reads every named field at once
  • formData.get('x') returns one value; getAll('x') returns all (checkbox groups)
  • Unchecked checkboxes are missing from FormData
  • form.reset() restores every field to its default value

♿ Accessibility

  • Native constraint attributes (required, type="email") give built-in validation messages
  • Uncontrolled forms still need labels and error text tied with aria-describedby

Version Notes

  • React 19 resets uncontrolled forms automatically after a successful form Action
  • defaultValue updates after mount are ignored; change the key to reset

Code Explained

FormData collects all named fields when the form submits
getAll('topic') returns every checked topic value
data.has('subscribe') is true only when the box is checked
reset() puts every field back to its default
The file input is read through a ref because its value can't be set

FormData and Refs

function Feedback() {
  function handleSubmit(e) {
    e.preventDefault();
    const data = new FormData(e.currentTarget);
    const payload = {
      email: data.get('email'),
      rating: Number(data.get('rating')),
      topics: data.getAll('topic'),
      subscribe: data.has('subscribe'),
    };
    send(payload);
    e.currentTarget.reset();
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="email" type="email" required
        defaultValue="me@example.com" />
      <input name="rating" type="range" min="1" max="5"
        defaultValue="3" />
      <label><input type="checkbox" name="topic"
        value="ui" defaultChecked /> UI</label>
      <label><input type="checkbox" name="topic"
        value="api" /> API</label>
      <label><input type="checkbox" name="subscribe" />
        Newsletter</label>
      <button>Send</button>
    </form>
  );
}

function Upload() {
  const fileRef = useRef(null);
  const upload = () => {
    const [file] = fileRef.current.files;
    if (file) api.upload(file);
  };
  return <>
    <input type="file" ref={fileRef} accept="image/*" />
    <button type="button" onClick={upload}>Upload</button>
  </>;
}

⚠ Common Mistakes

  • Changing defaultValue and expecting the field to update
  • Forgetting name attributes, so FormData misses fields
  • Using Object.fromEntries on multi-value fields and losing values

✓ Tips & Best Practices

  • Start uncontrolled; switch a field to controlled only when you need live logic
  • Use key on the form to reset it to new defaults
  • Pair with Zod to parse FormData into typed data (sheet 31)

Quick Summary

  • defaultValue / defaultChecked
  • Read with FormData or refs
  • Fewer re-renders
  • Files are always uncontrolled
