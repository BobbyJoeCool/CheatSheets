Calling the Server from the Client

A Server Function is an async function marked with 'use server'. The framework turns it into an endpoint, and Client Components can call it like a normal function or pass it to <form action>. React serializes the arguments, runs the function on the server, and returns the result. Treat every Server Function as a public API: validate inputs and check authorization inside it.

Notes

  • Put 'use server' at the top of a file to mark every export, or inside a function body
  • Server Functions used in action props are also called Server Actions
  • Arguments and return values must be serializable
  • Forms using Server Functions work before JavaScript loads (progressive enhancement)

♿ Accessibility

  • Return field errors and render them next to inputs; with progressive enhancement, the server must re-render the form with errors

Version Notes

  • Server Functions are stable in React 19 with a supporting framework
  • Frameworks encrypt closed-over values, but you should still never close over secrets

'use server' Functions

// app/actions.ts
'use server';
import { z } from 'zod';
import { revalidatePath } from 'next/cache';   // framework API
import { auth } from '@/lib/auth';

const Comment = z.object({
  postId: z.string(), body: z.string().min(1).max(500),
});

export async function addComment(prevState, formData: FormData) {
  const session = await auth();
  if (!session) return { error: 'Please sign in' };

  const parsed = Comment.safeParse(Object.fromEntries(formData));
  if (!parsed.success) return { error: 'Comment is empty or too long' };

  await db.comment.create({ data: { ...parsed.data,
    authorId: session.userId } });
  revalidatePath(`/posts/${parsed.data.postId}`);
  return { error: null };
}

export async function likePost(postId: string) {
  const session = await auth();
  if (!session) throw new Error('Unauthorized');
  return db.like.toggle(postId, session.userId);
}

// CommentForm.tsx
'use client';
import { useActionState } from 'react';
import { addComment, likePost } from './actions';

export function CommentForm({ postId }) {
  const [state, action, pending] = useActionState(addComment,
    { error: null });
  return (
    <form action={action}>
      <input type="hidden" name="postId" value={postId} />
      <textarea name="body" aria-describedby="err" />
      <p id="err" role="alert">{state.error}</p>
      <button disabled={pending}>Post</button>
      <button type="button" onClick={() => likePost(postId)}>♥</button>
    </form>
  );
}

⚠ Common Mistakes

  • Assuming a Server Function is private because it isn't linked in the UI
  • Trusting hidden form fields without checking ownership
  • Returning whole database records to the client

✓ Tips & Best Practices

  • Keep Server Functions in actions.ts files per feature
  • Return { error } objects for expected failures; throw for bugs
  • Revalidate or update caches after writes

Quick Summary
