React Hook Form

useForm · register · handleSubmit · formState.errors · Controller · watch · reset

Performant Form State

React Hook Form keeps field values in uncontrolled inputs and refs, so typing doesn't re-render the whole form. useForm() returns register to connect native inputs, handleSubmit to validate and call your submit function, and formState for errors and status. Use Controller for third-party components that only work as controlled inputs.

Notes

  • register('name', rules) returns name, ref, onChange and onBlur props
  • Built-in rules: required, min, max, minLength, maxLength, pattern, validate
  • mode: 'onBlur' or 'onChange' changes when validation runs (default 'onSubmit')
  • watch subscribes to values and re-renders; getValues reads without subscribing

♿ Accessibility

  • Set aria-invalid from errors and link messages with aria-describedby
  • setFocus or the default shouldFocusError moves focus to the first invalid field

Version Notes

  • React Hook Form v7 is current and supports React 19
  • Also works alongside React 19 Actions by calling handleSubmit from onSubmit

Code Explained

defaultValues sets initial values and enables isDirty
{...register('name', rules)} wires the input without state
errors.name.message holds the message from the rule
valueAsNumber stores age as a number
Controller adapts a controlled-only component; reset(data) clears dirty state after save

useForm, register, Controller

import { useForm, Controller } from 'react-hook-form';
import DatePicker from 'some-date-picker';

function ProfileForm({ onSave }) {
  const {
    register, handleSubmit, control, watch, reset,
    formState: { errors, isSubmitting, isDirty },
  } = useForm({
    defaultValues: { name: '', age: 18, birthday: null },
    mode: 'onBlur',
  });

  const name = watch('name');

  return (
    <form onSubmit={handleSubmit(async (data) => {
      await onSave(data);
      reset(data);
    })}>
      <input {...register('name', { required: 'Name is required',
        minLength: { value: 2, message: 'Too short' } })}
        aria-invalid={!!errors.name} />
      {errors.name && <p role="alert">{errors.name.message}</p>}

      <input type="number"
        {...register('age', { valueAsNumber: true, min: 13 })} />

      <Controller name="birthday" control={control}
        render={({ field }) => <DatePicker {...field} />} />

      <p>Hello {name || 'stranger'}</p>
      <button disabled={isSubmitting || !isDirty}>Save</button>
    </form>
  );
}

⚠ Common Mistakes

  • Passing register result to a component that doesn't forward ref
  • Calling watch() with no arguments in a large form (re-renders everything)
  • Mixing controlled value with register on the same input

✓ Tips & Best Practices

  • Use a schema resolver (sheet 31) instead of inline rules for big forms
  • Use useWatch in a child to isolate re-renders
  • Disable submit with isSubmitting to prevent double posts
