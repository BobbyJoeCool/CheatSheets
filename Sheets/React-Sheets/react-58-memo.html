Skipping Child Renders

memo(Component) returns a version of a component that skips re-rendering when its props are unchanged, compared with Object.is per prop (a shallow comparison). It helps when a component renders often with the same props and its render is expensive. It does nothing if a prop is a new object, array or function each render, which is why it's often paired with useMemo and useCallback.

Notes

  • State changes and context changes inside the memoized component still re-render it
  • children JSX is a new object every render, which defeats memo
  • A second argument arePropsEqual(prev, next) customizes the comparison
  • With the React Compiler, most manual memo calls are unnecessary

♿ Accessibility

  • Memoization doesn't affect output, but stale custom comparisons can leave ARIA attributes out of date

Version Notes

  • memo is unchanged in React 19
  • React Compiler 1.0 memoizes components and JSX automatically

memo and Its Pitfalls

import { memo, useCallback, useMemo, useState } from 'react';

const Chart = memo(function Chart({ data, options, onSelect }) {
  return <svg>{/* expensive drawing */}</svg>;
});

function Dashboard({ rows }) {
  const [filter, setFilter] = useState('');

  // ✗ New object/function each render: memo never skips
  // <Chart data={rows} options={{ grid: true }}
  //   onSelect={(p) => select(p)} />

  // ✓ Stable props
  const options = useMemo(() => ({ grid: true }), []);
  const onSelect = useCallback((p) => select(p), []);

  return (
    <>
      <input value={filter}
        onChange={(e) => setFilter(e.target.value)} />
      <Chart data={rows} options={options} onSelect={onSelect} />
    </>
  );
}

// Custom comparison: only re-render when id changes
const Row = memo(
  function Row({ item }) { return <li>{item.name}</li>; },
  (prev, next) => prev.item.id === next.item.id
              && prev.item.name === next.item.name,
);

⚠ Common Mistakes

  • Wrapping every component in memo by default
  • Custom comparators that forget a prop and show stale UI
  • Expecting memo to stop context-driven re-renders

✓ Tips & Best Practices

  • Enable the React Compiler instead of hand-tuning
  • Measure with the Profiler before and after
  • Fix structure first: move state down, pass children

Quick Summary

  • memo skips equal-prop renders
  • Shallow Object.is per prop
  • Needs stable object/function props
  • Compiler makes it automatic
