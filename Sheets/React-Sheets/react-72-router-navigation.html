React Router: Navigation

<Link> · <NavLink> · useNavigate · <Navigate> · relative paths · replace · location state

Moving Between Pages

Render <Link to> for navigation the user triggers; it renders an <a> and updates the URL without a page reload. <NavLink> adds an active state for menus. For navigation in code (after a form submit, on logout) call the function returned by useNavigate(). Render <Navigate to> to redirect during render. Paths without a leading slash are relative to the current route.

Notes

  • navigate(-1) goes back; navigate('/x', { replace: true }) replaces the history entry
  • state passes data that isn't in the URL: navigate('/done', { state: { id } })
  • useLocation().state reads it on the next page
  • Prefer <Link> over navigate for anything clickable: it supports middle-click and copy link

♿ Accessibility

  • <NavLink> sets aria-current="page" on the active link automatically
  • Use <Link> for navigation and <button> for actions, even if both look like links

Version Notes

  • Navigation is wrapped in startTransition, so pending UI and Suspense work smoothly
  • viewTransition prop/option enables View Transitions on navigation

Code Explained

end makes the Home link active only at exactly /
className can be a function of isActive and isPending
viewTransition animates the navigation with View Transitions
replace: true stops the back button returning to a logged-out page
<Navigate> redirects while rendering

Link, NavLink, useNavigate

import { Link, NavLink, Navigate, useNavigate } from 'react-router';

function Nav() {
  return (
    <nav>
      <NavLink to="/" end>Home</NavLink>
      <NavLink
        to="/inbox"
        className={({ isActive, isPending }) =>
          isActive ? 'active' : isPending ? 'pending' : ''}
      >
        Inbox
      </NavLink>
      <Link to="/settings" viewTransition>Settings</Link>
      <Link to="../" relative="path">Up one level</Link>
    </nav>
  );
}

function LogoutButton() {
  const navigate = useNavigate();
  async function logout() {
    await api.logout();
    navigate('/login', { replace: true });
  }
  return <button onClick={logout}>Log out</button>;
}

function Protected({ user, children }) {
  if (!user) return <Navigate to="/login" replace />;
  return children;
}

function Checkout() {
  const navigate = useNavigate();
  const done = (id) => navigate('/thanks', { state: { orderId: id } });
}

⚠ Common Mistakes

  • Using <a href> for internal links and reloading the page
  • navigate() during render instead of <Navigate>
  • Putting required data only in state (lost on refresh)

✓ Tips & Best Practices

  • Keep important state in the URL so it survives reloads and sharing
  • Use prefetch="intent" on links in framework mode
  • Use replace after login and form submissions

Quick Summary

  • <Link> for clicks
  • <NavLink> adds active + aria-current
  • useNavigate() in handlers
  • Relative paths by default
