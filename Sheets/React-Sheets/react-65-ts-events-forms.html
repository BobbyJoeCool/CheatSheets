Typing Event Handlers

React passes typed synthetic events. Inline handlers get their types inferred from the JSX attribute. When you write a separate handler, annotate the event: React.ChangeEvent<HTMLInputElement>, React.MouseEvent<HTMLButtonElement>, React.FormEvent<HTMLFormElement>, React.KeyboardEvent. For callback props, use the matching …EventHandler types or write the function signature you actually need.

Notes

  • Hover an inline handler's parameter in your editor to see its type
  • e.currentTarget is typed as the generic element; e.target is a plain EventTarget
  • FormData.get() returns FormDataEntryValue | null (string or File)
  • Prefer callback props with domain types (onSave(user: User)) over raw events

♿ Accessibility

  • Type keyboard handlers with KeyboardEvent and check e.key so keyboard support compiles alongside mouse support

Version Notes

  • React 19 types: React.FormEvent remains; form Actions receive FormData instead of an event
  • React.SyntheticEvent is the base of all event types

Event and Handler Types

import type {
  ChangeEvent, FormEvent, KeyboardEvent, MouseEvent,
  ChangeEventHandler,
} from 'react';

function Signup({ onSubmit }: { onSubmit: (email: string) => void }) {
  const [email, setEmail] = useState('');

  const handleChange = (e: ChangeEvent<HTMLInputElement>) => {
    setEmail(e.currentTarget.value);
  };

  const handleSubmit = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    onSubmit(email);
  };

  const handleKey = (e: KeyboardEvent<HTMLInputElement>) => {
    if (e.key === 'Escape') setEmail('');
  };

  const handleClick = (e: MouseEvent<HTMLButtonElement>) => {
    if (e.shiftKey) console.log('shift-click');
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={email} onChange={handleChange}
        onKeyDown={handleKey} />
      <button onClick={handleClick}>Join</button>
    </form>
  );
}

// Handler type for props
type FieldProps = { onChange: ChangeEventHandler<HTMLSelectElement> };

// Form Action: FormData, not an event
async function save(formData: FormData) {
  const name = formData.get('name');
  if (typeof name !== 'string') throw new Error('name required');
}

⚠ Common Mistakes

  • Using e.target.value on a non-input target and fighting EventTarget types
  • Importing the DOM's global MouseEvent instead of React's
  • Typing everything as any to silence errors

✓ Tips & Best Practices

  • Write handlers inline first, then extract with the inferred type
  • Use currentTarget for the element the handler is attached to
  • Expose domain callbacks (onSelect(id)) from components, not events
