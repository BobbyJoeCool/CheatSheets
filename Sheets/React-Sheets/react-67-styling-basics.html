Styling Basics

className · style prop · CSS imports · clsx · conditional classes · CSS variables via style

Classes and Inline Styles

Style React components with plain CSS: import a stylesheet (Vite bundles it) and apply classes with className. Build conditional class strings with a template literal or the tiny clsx helper. The style prop takes an object of camelCase properties and is best for truly dynamic values; pass dynamic values into CSS through custom properties (style={{ '--progress': '40%' }}).

Notes

  • import './Button.css' adds the CSS globally; class names are not scoped
  • Numbers in style get px automatically for length properties (width: 10)
  • Unitless properties (opacity, zIndex, lineHeight, flex) stay as numbers
  • Vendor prefixes in style use PascalCase: WebkitLineClamp

♿ Accessibility

  • Don't convey state with color alone; pair classes like .error with text or icons
  • Respect prefers-reduced-motion in CSS for transitions triggered by class changes

Version Notes

  • React 19 hoists <link rel="stylesheet" precedence> rendered by components (sheet 53)
  • CSS custom properties in style are typed as strings in @types/react

Code Explained

clsx joins strings and includes object keys whose values are truthy
Template literals build variant classes like btn-primary
--progress passes the number to CSS, which handles the drawing
width: size becomes size px automatically
The role="progressbar" attributes describe the bar to screen readers

className, clsx, style

import clsx from 'clsx';
import './Button.css';

function Button({ variant = 'primary', size, disabled, children }) {
  return (
    <button
      className={clsx('btn', `btn-${variant}`, {
        'btn-sm': size === 'small',
        'is-disabled': disabled,
      })}
      disabled={disabled}
    >
      {children}
    </button>
  );
}

function Progress({ value }) {
  return (
    <div
      className="progress"
      role="progressbar"
      aria-valuenow={value} aria-valuemin={0} aria-valuemax={100}
      style={{ '--progress': `${value}%` }}
    />
  );
}

function Avatar({ size }) {
  return <img style={{ width: size, height: size,
    borderRadius: '50%', objectFit: 'cover' }} alt="" />;
}

/* Button.css */
.btn { padding: 0.5em 1em; border-radius: 6px; }
.btn-primary { background: var(--brand); color: white; }
.progress::after { width: var(--progress); }

⚠ Common Mistakes

  • Passing a string to style
  • Using inline styles for hover/focus (they can't express pseudo-classes)
  • Global class names that collide across components

✓ Tips & Best Practices

  • Use custom properties for dynamic values and keep rules in CSS
  • Keep a naming convention (BEM) if you stay with global CSS
  • clsx and classnames are interchangeable; pick one

Quick Summary

  • className + imported CSS
  • clsx for conditional classes
  • style = camelCase object
  • Custom props bridge JS → CSS
