Server Rendering APIs

renderToReadableStream · renderToPipeableStream · prerender · hydrateRoot · hydration mismatches · suppressHydrationWarning

react-dom/server and Hydration

react-dom/server renders a React tree to HTML. renderToReadableStream (Web Streams: Deno, Bun, edge, modern Node) and renderToPipeableStream (Node streams) stream HTML and support Suspense. prerender from react-dom/static waits for all data, for static generation. On the client, hydrateRoot attaches React to the HTML. If server and client output differ, React reports a hydration mismatch and re-renders that part on the client.

Notes

  • bootstrapScripts / bootstrapModules add the client entry script tags
  • onShellReady / awaiting the stream gives you the shell before Suspense content
  • renderToString still exists but doesn't support streaming or waiting for Suspense data
  • suppressHydrationWarning silences one element's text mismatch (e.g. timestamps)

♿ Accessibility

  • Avoid rendering different text on server and client (dates, random IDs); use useId for IDs

Version Notes

  • prerender/prerenderToNodeStream (react-dom/static) are new in React 19
  • React 19.2 adds resume APIs for Partial Pre-rendering
  • React 19 shows a single diff-style error for hydration mismatches

Code Explained

renderToReadableStream returns a stream you can send as a Response
bootstrapModules adds the script that will hydrate the page
stream.allReady waits for every Suspense boundary, useful for crawlers
prerender resolves all data and returns static HTML
suppressHydrationWarning allows a known one-level text mismatch

Server Render and Hydrate

// server.ts (Web Streams)
import { renderToReadableStream } from 'react-dom/server';

export async function handler(request: Request) {
  let status = 200;
  const stream = await renderToReadableStream(
    <App url={request.url} />,
    {
      bootstrapModules: ['/assets/client.js'],
      onError(error) { status = 500; console.error(error); },
    },
  );
  // await stream.allReady;   // wait for everything (bots)
  return new Response(stream, {
    status, headers: { 'Content-Type': 'text/html' },
  });
}

// Node streams
import { renderToPipeableStream } from 'react-dom/server';
const { pipe } = renderToPipeableStream(<App />, {
  bootstrapScripts: ['/client.js'],
  onShellReady() { res.setHeader('content-type', 'text/html'); pipe(res); },
});

// Static generation
import { prerender } from 'react-dom/static';
const { prelude } = await prerender(<App url="/about" />);

// client.tsx
import { hydrateRoot } from 'react-dom/client';
hydrateRoot(document, <App url={location.href} />, {
  onRecoverableError: (e) => report(e),
});

// Intentional difference
<time suppressHydrationWarning>{new Date().toLocaleTimeString()}</time>

⚠ Common Mistakes

  • Reading window or localStorage during render
  • Using suppressHydrationWarning to hide real bugs
  • Choosing renderToString for new SSR code

✓ Tips & Best Practices

  • Use a framework unless you need a custom server
  • Send the shell fast; stream the rest
  • Wire onRecoverableError to logging to catch mismatches in production

Quick Summary

  • Stream with renderTo*Stream
  • prerender for static HTML
  • hydrateRoot on the client
  • Same output on both sides
