Three Ways to Use It

React Router maps URLs to components. It can be used in three modes. Declarative mode (<BrowserRouter> + <Routes>) only matches URLs to components. Data mode (createBrowserRouter + <RouterProvider>) adds loaders, actions and pending states. Framework mode adds a Vite plugin, file-based route config, type generation and server rendering. Everything imports from the single react-router package.

Notes

  • react-router-dom was merged into react-router in v7; old imports still re-export
  • Route objects use Component (or element) and nest with children
  • An index: true route renders at the parent's exact URL
  • path: '*' catches unmatched URLs for a 404 page

♿ Accessibility

  • After navigation, move focus to the new page's <h1> or main region so screen-reader users hear the change
  • Update <title> on every route

Version Notes

  • React Router v8 (June 2026) is a non-breaking upgrade from v7: ESM-only, React 19+, Node 22+
  • v7 merged Remix into React Router as framework mode
  • v6 reached end of life

Code Explained

<BrowserRouter> uses the History API for clean URLs
<Route path element> pairs a URL pattern with UI
In data mode, the route config is a plain array of objects
children routes render inside the parent's <Outlet> (sheet 74)
loader fetches data before the route renders (sheet 75)

Declarative and Data Mode

// Declarative mode
import { BrowserRouter, Routes, Route } from 'react-router';

createRoot(el).render(
  <BrowserRouter>
    <Routes>
      <Route path="/" element={<Home />} />
      <Route path="about" element={<About />} />
      <Route path="users/:id" element={<User />} />
      <Route path="*" element={<NotFound />} />
    </Routes>
  </BrowserRouter>,
);

// Data mode
import { createBrowserRouter } from 'react-router';
import { RouterProvider } from 'react-router/dom';

const router = createBrowserRouter([
  {
    path: '/',
    Component: Root,
    ErrorBoundary: RootError,
    children: [
      { index: true, Component: Home },
      { path: 'about', Component: About },
      {
        path: 'users/:id',
        Component: User,
        loader: ({ params }) => fetchUser(params.id),
      },
      { path: '*', Component: NotFound },
    ],
  },
]);

createRoot(el).render(<RouterProvider router={router} />);

⚠ Common Mistakes

  • Importing from react-router-dom in new v8 code
  • Defining the router inside a component (recreated each render)
  • Forgetting a catch-all * route

✓ Tips & Best Practices

  • Start new SPAs in data mode; it's easy to grow from
  • Keep route config in one file for an overview
  • Use framework mode when you want SSR without Next.js

Quick Summary
