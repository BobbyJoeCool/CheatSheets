Starting a New App

Create a client-side React app with Vite: one command scaffolds a project with a dev server, hot module replacement and a production build. Pick the react-ts template to get TypeScript from the start. If you need routing, server rendering or data loading built in, start from a framework instead (Next.js or React Router framework mode). Create React App is deprecated and should not be used for new projects.

Notes

  • Vite needs a current Node.js LTS release; check node -v before scaffolding
  • npm create vite@latest prompts for a framework and variant; flags skip the prompts
  • Templates: react, react-ts, react-swc, react-swc-ts (SWC is a faster compiler)
  • Use npm, pnpm, yarn or bun; the lockfile records which one the project uses

♿ Accessibility

  • Set <html lang> and a meaningful <title> in index.html right away
  • Add eslint-plugin-jsx-a11y while the project is small

Version Notes

  • Create React App was deprecated in February 2025; migrate CRA apps to Vite or a framework
  • React's docs recommend a framework for most new apps and Vite for client-only apps
  • npm create vite installs React 19 by default

Code Explained

-- passes the --template flag through npm to the Vite scaffolder
npm run dev serves source files directly with instant hot updates
npm run build runs tsc -b then vite build, writing static files to dist/
npm run preview checks the real build before deploying
-D saves test tools as devDependencies so they stay out of the bundle

Scaffold, Run, Build

# create a TypeScript React app
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install

# start the dev server (http://localhost:5173)
npm run dev

# type-check and bundle for production -> dist/
npm run build

# serve the production build locally
npm run preview

# add common libraries later
npm install react-router @tanstack/react-query
npm install -D vitest @testing-library/react

# framework alternatives
npx create-next-app@latest my-app
npx create-react-router@latest my-app

⚠ Common Mistakes

  • Starting a new project with create-react-app
  • Forgetting -- so npm swallows --template
  • Deploying the dev server instead of the dist/ build

✓ Tips & Best Practices

  • Choose react-ts even for small apps; types catch prop mistakes early
  • Commit the lockfile so every machine installs the same versions
  • Run npm run preview before deploying to catch build-only bugs

Quick Summary

  • npm create vite@latest -- --template react-ts
  • dev · build · preview
  • Framework when you need SSR or routing
  • CRA is deprecated
