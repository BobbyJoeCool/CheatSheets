Sheet 05

JSX Syntax

JSX → jsx() · single root · closing tags · camelCase attributes · className · htmlFor · style={{}}

Markup in JavaScript

JSX is a syntax extension that lets you write HTML-like markup inside JavaScript. The compiler turns each tag into a call to jsx() from react/jsx-runtime, which returns a plain object describing the element. JSX is stricter than HTML: every tag must close, a component returns one root element, and attributes use camelCase DOM property names such as className, htmlFor and onClick.

Notes

  • Lowercase tags (div) are DOM elements; capitalized tags (Card) are components
  • class and for are reserved words in JS, so JSX uses className and htmlFor
  • aria-* and data-* attributes keep their hyphens
  • style takes an object with camelCase keys and number values in px

♿ Accessibility

  • Every <img> needs alt (use alt="" for decorative images)
  • htmlFor links a <label> to an input by id; screen readers announce the label

Version Notes

  • The automatic JSX runtime (React 17+) removed the need to import React in every file
  • React.createElement still works but is rarely written by hand

Code Explained

Parentheses around multi-line JSX stop automatic semicolon insertion after return
width={48} passes a number; width="48" would pass a string
style={{ ... }}: outer braces enter JS, inner braces are the object literal
Void elements such as <br /> and <img /> must self-close
aria-label and data-id keep HTML spelling

JSX and What It Compiles To

function Profile({ user }) {
  return (
    <section className="profile">
      <img
        src={user.avatar}
        alt=""
        width={48}
        style={{ borderRadius: 8, objectFit: 'cover' }}
      />
      <label htmlFor="bio">Bio</label>
      <textarea id="bio" defaultValue={user.bio} />
      <br />
      <button aria-label="Edit profile" data-id={user.id}>
        ✎
      </button>
    </section>
  );
}

// Compiled output (automatic runtime):
import { jsx, jsxs } from 'react/jsx-runtime';

jsxs('section', {
  className: 'profile',
  children: [jsx('img', { src: user.avatar, alt: '' })],
});

⚠ Common Mistakes

  • Writing class= and getting a console warning
  • Passing a string to an event prop: onClick="save()"
  • Naming a component in lowercase so React treats it as an HTML tag

✓ Tips & Best Practices

  • Let Prettier format JSX; it adds the wrapping parentheses for you
  • Use the HTML-to-JSX converter in your editor when pasting markup
  • Keep inline style for dynamic values; put the rest in CSS

Quick Summary

  • JSX → jsx() calls → element objects
  • One root, closed tags, camelCase
  • className, htmlFor, style={{}}
  • aria-* / data-* keep hyphens
