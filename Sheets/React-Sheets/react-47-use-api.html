The use() API

use(promise) · use(context) · conditional calls · caching promises · no try/catch · error boundaries

Reading Resources in Render

use(resource) reads the value of a promise or a context. With a promise, the component suspends until it resolves, then receives the value; if it rejects, the nearest error boundary renders. Unlike hooks, use can be called inside conditions and loops. The promise must be cached or created outside the component, typically passed down from a Server Component, a loader or a cache.

Notes

  • Promises created during render are new each time, which suspends forever
  • Pass promises from Server Components to Client Components and use them there
  • use can't be called inside try/catch; use an error boundary or .catch()
  • Resolved values must be serializable when crossing the server/client boundary

♿ Accessibility

  • Pair use(promise) with a Suspense fallback that announces loading

Version Notes

  • use is new in React 19
  • React 19.2 adds cacheSignal for Server Components to abort work when a cached call is no longer needed

use(promise) and use(context)

import { Suspense, use } from 'react';
import { ErrorBoundary } from 'react-error-boundary';

// Server Component (or loader) creates the promise once
export default async function Page({ id }) {
  const messagePromise = fetchMessage(id);   // not awaited
  return (
    <ErrorBoundary fallback={<p>Couldn't load.</p>}>
      <Suspense fallback={<p>Loading…</p>}>
        <Message messagePromise={messagePromise} />
      </Suspense>
    </ErrorBoundary>
  );
}

// Client Component reads it
'use client';
function Message({ messagePromise }) {
  const message = use(messagePromise);
  return <p>{message.text}</p>;
}

// Conditional context read
function Heading({ children, plain }) {
  if (plain) return <h1>{children}</h1>;
  const theme = use(ThemeContext);
  return <h1 className={theme}>{children}</h1>;
}

// Client-only: cache the promise outside render
const cache = new Map();
function getUser(id) {
  if (!cache.has(id)) cache.set(id, fetchUser(id));
  return cache.get(id);
}
function User({ id }) {
  const user = use(getUser(id));
  return <span>{user.name}</span>;
}

⚠ Common Mistakes

  • use(fetch(url)) directly in a client component
  • Wrapping use in try/catch
  • Awaiting the promise on the server and losing streaming

✓ Tips & Best Practices

  • Start fetches early (in the parent) and use them late (in the child)
  • Handle rejections with promise.catch(() => fallback) when you want a value instead of an error
  • Prefer framework or library caches over hand-rolled maps

Quick Summary

  • use(promise) suspends until resolved
  • use(context) can be conditional
  • Promise must be stable
  • Errors → error boundary
