children & Composition

children · slot props · containment · specialization · layout components · ReactNode

Nesting Components

Whatever you put between a component's opening and closing tags arrives as the children prop. That lets a component wrap content it knows nothing about: cards, layouts, dialogs. For more than one slot, pass JSX through named props such as header or footer. This composition is React's main tool for reuse; you rarely need inheritance.

Notes

  • children can be text, elements, arrays, functions or nothing
  • Type it as ReactNode in TypeScript
  • Named slot props take any JSX: <Page sidebar={<Nav />} />
  • Specialization: build WelcomeDialog by rendering Dialog with fixed props

♿ Accessibility

  • Layout components should render landmarks (<header>, <nav>, <main>) around their slots
  • A Card that wraps a heading should let callers choose the heading level

Version Notes

  • children behavior is unchanged in React 19

Code Explained

Card places children without knowing what they are
Layout has three slots: two named props and children
JSX passed as a prop is just a value; nothing renders until the receiver places it
DangerCard reuses Card by composing it, not extending it
Content between tags becomes children, including multiple elements

children and Slots

function Card({ title, children }) {
  return (
    <article className="card">
      <h2>{title}</h2>
      <div className="card-body">{children}</div>
    </article>
  );
}

function Layout({ header, sidebar, children }) {
  return (
    <div className="layout">
      <header>{header}</header>
      <nav>{sidebar}</nav>
      <main>{children}</main>
    </div>
  );
}

// Specialization
function DangerCard(props) {
  return <Card {...props} title={`⚠ ${props.title}`} />;
}

export default function App() {
  return (
    <Layout header={<Logo />} sidebar={<Menu />}>
      <Card title="Welcome">
        <p>Anything can go here.</p>
        <button>Get started</button>
      </Card>
      <DangerCard title="Billing">Card expired</DangerCard>
    </Layout>
  );
}

⚠ Common Mistakes

  • Passing everything through props when children would read better
  • Inspecting or rewriting children instead of using explicit props
  • Using class inheritance to share UI

✓ Tips & Best Practices

  • Pass JSX down instead of data plus flags (icon={<Star />} over icon="star")
  • Composition often removes the need for context
  • Keep layout components free of data fetching

Quick Summary

  • Tag contents → children
  • Named props for extra slots
  • Compose, don't inherit
  • Type as ReactNode
