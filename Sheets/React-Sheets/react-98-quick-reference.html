Quick Reference

hooks · built-in components · react-dom APIs · JSX rules · event names · directives

React at a Glance

A one-page index of the APIs covered in this set. Hooks must be called at the top level of components and custom hooks; use is the exception. Components from react handle loading, errors and visibility; react-dom handles rendering, portals, forms and resource loading. Directives ('use client', 'use server') mark module boundaries in frameworks that support Server Components.

Notes

  • State: useState, useReducer; context: useContext, use
  • Refs: useRef, useImperativeHandle; effects: useEffect, useLayoutEffect, useInsertionEffect, useEffectEvent
  • Performance: useMemo, useCallback, useTransition, useDeferredValue
  • Other: useId, useSyncExternalStore, useActionState, useOptimistic, useDebugValue

♿ Accessibility

  • useId for label/ARIA links · semantic elements first · manage focus on route changes · aria-live for async results

Version Notes

  • Covers React 19.3 (September 2026)
  • See sheet 97 for removed and deprecated APIs

Code Explained

Hooks return values and setters; they never take this
use(Ctx) and use(promise) may run conditionally
Form hooks pair with React 19 Actions
Suspense, Activity and ViewTransition are components, not hooks
createPortal renders children into another DOM node
