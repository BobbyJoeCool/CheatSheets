Focus and Announcements

Single-page apps change content without page loads, so you must manage focus and announcements yourself. After route changes, move focus to the new page heading. When a dialog opens, move focus into it and trap it there; when it closes, return focus to the trigger. Announce async results (saved, 3 results, error) with an aria-live region. The native <dialog> element handles most dialog focus rules for you.

Notes

  • <dialog> opened with showModal() traps focus, closes on Escape and makes the page inert
  • Headings that receive focus need tabIndex={-1}
  • Live regions must exist in the DOM before their text changes
  • role="status" is polite; role="alert" interrupts

♿ Accessibility

  • Provide a Skip to main content link as the first focusable element
  • Keep focus visible: never set outline: none without a replacement

Version Notes

  • Native <dialog> and the inert attribute are supported in all current browsers
  • React 19 passes inert through as a boolean attribute

Code Explained

Focusing the <h1> on each route tells screen readers the page changed
tabIndex={-1} lets the heading take focus without entering the tab order
showModal() traps focus and returns it to the opener on close
onClose fires on Escape too, keeping React state in sync
The status paragraph is always rendered; only its text changes

Route Focus, Dialog, Live Region

// 1. Focus the heading after navigation
function Page({ title, children }) {
  const headingRef = useRef(null);
  const { pathname } = useLocation();
  useEffect(() => { headingRef.current?.focus(); }, [pathname]);
  return (
    <main id="main">
      <h1 ref={headingRef} tabIndex={-1}>{title}</h1>
      {children}
    </main>
  );
}

// 2. Native dialog with focus return
function ConfirmDialog({ open, onClose, children }) {
  const ref = useRef(null);
  useEffect(() => {
    const dlg = ref.current;
    if (open && !dlg.open) dlg.showModal();
    if (!open && dlg.open) dlg.close();
  }, [open]);
  return (
    <dialog ref={ref} onClose={onClose} aria-labelledby="dlg-title">
      <h2 id="dlg-title">Are you sure?</h2>
      {children}
      <button onClick={onClose}>Cancel</button>
    </dialog>
  );
}

// 3. Live region announcements
function SaveStatus({ status }) {
  return (
    <p role="status" aria-live="polite">
      {status === 'saved' ? 'Changes saved' : ''}
    </p>
  );
}

// 4. Skip link (first in body)
<a href="#main" className="skip-link">Skip to main content</a>

⚠ Common Mistakes

  • Mounting a live region together with its message (often not announced)
  • Custom modals without focus trapping or Escape handling
  • Losing focus to <body> after deleting the focused element

✓ Tips & Best Practices

  • Prefer <dialog> or a library (React Aria, Radix) over custom modals
  • Keep one app-level live region and send messages to it
  • Test with a real screen reader (VoiceOver, NVDA) regularly

Quick Summary

  • Focus headings on route change
  • Trap and return focus in dialogs
  • aria-live for async results
  • Skip link first
