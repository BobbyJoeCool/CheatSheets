Curly Braces Open JavaScript

Inside JSX, curly braces switch back to JavaScript. Anything that produces a value works: variables, function calls, ternaries, template literals and array map(). Statements do not: if, for and variable declarations must happen above the return. In attributes, quotes pass a string and braces pass any value, including numbers, objects and functions.

Notes

  • Braces work in two places: as element children and as attribute values
  • null, undefined, true and false render nothing
  • Numbers and strings render as text; plain objects throw an error
  • Text inside braces is escaped automatically, which prevents HTML injection

♿ Accessibility

  • Build alt and aria-label text from data so it stays accurate
  • Don't put meaning only in an emoji; add visible or aria-label text

Version Notes

  • Unchanged since early React; JSX expressions are plain JavaScript

Code Explained

fullName is computed above the return, where statements are allowed
className takes an expression, so a ternary picks the class
{/* … */} is the only way to comment inside JSX
Template literals build attribute strings from data
{'{braces}'} renders literal braces as text

Expressions in Markup

const user = { first: 'Ada', last: 'Lovelace', unread: 3 };
const formatDate = (d) => d.toLocaleDateString('en-US');

function Header({ today }) {
  const fullName = `${user.first} ${user.last}`;
  const isBusy = user.unread > 0;

  return (
    <header className={isBusy ? 'header busy' : 'header'}>
      {/* comments need braces too */}
      <h1>Hello, {fullName}!</h1>
      <p>Today is {formatDate(today)}</p>
      <p>{user.unread} unread {user.unread === 1
        ? 'message' : 'messages'}</p>
      <img
        src={`/avatars/${user.first.toLowerCase()}.png`}
        alt={`${fullName}'s avatar`}
      />
      <span title="literal string">{'{braces}'}</span>
    </header>
  );
}

⚠ Common Mistakes

  • Rendering an object ({user}) and getting Objects are not valid as a React child
  • Quoting an expression: src="{url}" passes the literal text
  • Expecting {false} or {null} to print the word

✓ Tips & Best Practices

  • Move long expressions into named variables above the return
  • Use String(value) when you want booleans to show as text
  • Use JSON.stringify(obj, null, 2) inside <pre> for quick debugging

Quick Summary

  • {} = JavaScript expression
  • Quotes = string, braces = any value
  • Statements go above return
  • null/false render nothing
