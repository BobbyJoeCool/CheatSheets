Styles Written in JavaScript

CSS-in-JS libraries let you write CSS inside component files. styled-components and Emotion create components with attached styles (styled.button), interpolate props, and theme through a provider. They generate styles at runtime, which costs performance and doesn't work in Server Components. Newer zero-runtime libraries (vanilla-extract, Panda CSS, StyleX, Linaria) extract static CSS at build time.

Notes

  • Transient props ($active) in styled-components aren't passed to the DOM
  • Runtime libraries inject <style> tags with useInsertionEffect
  • Server rendering needs a style registry to collect CSS
  • See the CSS Systems set for styled-components in depth

♿ Accessibility

  • Style :focus-visible inside styled components like any CSS
  • Pass aria-* attributes through; styled components forward valid HTML attributes

Version Notes

  • styled-components entered maintenance mode in 2025; prefer other options for new projects
  • Runtime CSS-in-JS works only in Client Components ('use client') under React Server Components

Code Explained

styled.button creates a component with generated class names
Interpolated functions read props and the theme at render time
$primary is a transient prop, so it never reaches the DOM
styled(Button) extends existing styles
vanilla-extract writes TypeScript that becomes a static .css file

styled-components and a Zero-Runtime Option

import styled, { ThemeProvider } from 'styled-components';

const theme = { brand: '#0b6bcb', radius: '6px' };

const Button = styled.button`
  padding: 0.5rem 1rem;
  border-radius: ${(p) => p.theme.radius};
  background: ${(p) => (p.$primary ? p.theme.brand : 'white')};
  color: ${(p) => (p.$primary ? 'white' : p.theme.brand)};
  &:focus-visible { outline: 2px solid ${(p) => p.theme.brand}; }
`;

const DangerButton = styled(Button)`
  background: crimson;
`;

export function App() {
  return (
    <ThemeProvider theme={theme}>
      <Button $primary>Save</Button>
      <DangerButton>Delete</DangerButton>
    </ThemeProvider>
  );
}

// vanilla-extract: button.css.ts (compiled to static CSS)
import { style } from '@vanilla-extract/css';
export const button = style({
  padding: '0.5rem 1rem',
  selectors: { '&:focus-visible': { outline: '2px solid' } },
});

// Button.tsx
import { button } from './button.css';
<button className={button}>Save</button>;

⚠ Common Mistakes

  • Starting a new RSC app with runtime CSS-in-JS
  • Interpolating props for every style and regenerating classes constantly
  • Passing non-HTML props to the DOM (use $ transient props)

✓ Tips & Best Practices

  • Prefer CSS variables for dynamic values even in CSS-in-JS
  • For new projects, choose CSS Modules, Tailwind or a zero-runtime library
  • Migrate gradually: the two approaches can coexist

Quick Summary
