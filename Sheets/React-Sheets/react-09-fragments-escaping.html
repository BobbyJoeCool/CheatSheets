<></> · <Fragment> · Fragment refs · whitespace rules · {' '} · auto-escaping · dangerouslySetInnerHTML

Grouping, Text and Raw HTML

A Fragment (<>…</>) groups children without adding a DOM node, which keeps tables, flex layouts and lists valid. JSX trims whitespace at line breaks, so adjacent elements on separate lines touch; insert {' '} where you want a space. All text in braces is escaped, so user input can't inject markup. To render trusted HTML strings, use dangerouslySetInnerHTML and sanitize first.

Notes

  • Use <Fragment key> when mapping; the <> shorthand takes no props
  • Whitespace inside a single line is kept; line breaks between tags are removed
  • HTML entities like &nbsp; work in JSX text, or write {'\u00a0'}
  • dangerouslySetInnerHTML replaces all children; the element must have none

♿ Accessibility

  • Fragments keep <tr> directly inside <tbody> and <li> inside <ul>, preserving table and list semantics
  • Sanitized HTML still needs headings and alt text checked

Version Notes

  • React 19.3: Fragment refs are stable; <Fragment ref> gives a FragmentInstance for focus, observers and event listeners on its children
  • <> shorthand since React 16.2

Code Explained

Row returns <td>s without a wrapper that would break the table
{' '} keeps the space between </strong> and on
DOMPurify.sanitize removes scripts and event attributes before injection
__html is deliberately awkward so raw HTML stands out in reviews
A Fragment ref can focus the first focusable child without a wrapper div

Fragments, Spaces and HTML

import { Fragment, useRef } from 'react';
import DOMPurify from 'dompurify';

function Row({ cells }) {
  return (
    <>
      {cells.map((c) => <td key={c.id}>{c.value}</td>)}
    </>
  );
}

function Byline({ author, date }) {
  return (
    <p>
      By <strong>{author}</strong>{' '}
      on <time>{date}</time>
    </p>
  );
}

function Article({ html }) {
  const clean = DOMPurify.sanitize(html);
  return <div dangerouslySetInnerHTML={{ __html: clean }} />;
}

function Toolbar({ children }) {
  const group = useRef(null);  // FragmentInstance
  // group.current.focus() -> first focusable child
  return <Fragment ref={group}>{children}</Fragment>;
}

⚠ Common Mistakes

  • Wrapping with a <div> inside <tr> or <ul> and creating invalid HTML
  • Passing unsanitized user HTML to dangerouslySetInnerHTML (XSS)
  • Losing a space between inline elements on separate lines

✓ Tips & Best Practices

  • Prefer Markdown renderers that output React elements over raw HTML
  • Let your formatter insert {' '} where it is needed
  • Reach for Fragment refs before adding wrapper divs just to hold a ref

Quick Summary

  • <> groups without a DOM node
  • {' '} for spaces across lines
  • Text is escaped by default
  • Sanitize before dangerouslySetInnerHTML
