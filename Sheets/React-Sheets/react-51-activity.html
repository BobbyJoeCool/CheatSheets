Activity

<Activity mode> · hidden vs visible · preserving state · pre-rendering · effects in hidden trees · tabs & back navigation

Hide Without Losing State

<Activity mode="visible" | "hidden"> hides part of the UI while keeping its state and DOM. Hidden content gets display: none, its effects are cleaned up, and its updates run at low priority. Showing it again restores everything instantly. Use it for tabs, sidebars and back-navigation where users expect to return to where they were, and to pre-render content they're likely to open next.

Notes

  • Hidden trees unmount effects (cleanup runs) but keep state
  • Effects re-run when the tree becomes visible again
  • Hidden trees still re-render on prop changes, at low priority
  • DOM-only state (video playback, input text) is preserved because the DOM stays

♿ Accessibility

  • display: none removes hidden content from the accessibility tree
  • Move focus into newly shown panels the same way you would after mounting

Version Notes

  • <Activity> is stable in React 19.2 (October 2025); earlier canaries called it <Offscreen>
  • Supported modes: visible and hidden

Code Explained

Each tab stays mounted; only its visibility changes
Switching away runs effect cleanups (stopping subscriptions, timers)
Typed text in ContactForm survives switching tabs
A hidden Checkout can load code and data before the user clicks
Conditional rendering would destroy the form's state

Tabs That Remember

import { Activity, useState } from 'react';

function App() {
  const [tab, setTab] = useState('home');

  return (
    <>
      <nav>
        <button onClick={() => setTab('home')}>Home</button>
        <button onClick={() => setTab('posts')}>Posts</button>
        <button onClick={() => setTab('contact')}>Contact</button>
      </nav>

      <Activity mode={tab === 'home' ? 'visible' : 'hidden'}>
        <Home />
      </Activity>
      <Activity mode={tab === 'posts' ? 'visible' : 'hidden'}>
        <Posts />          {/* keeps scroll + filters */}
      </Activity>
      <Activity mode={tab === 'contact' ? 'visible' : 'hidden'}>
        <ContactForm />    {/* keeps typed text */}
      </Activity>
    </>
  );
}

// Pre-render the likely next screen
<Activity mode="hidden">
  <Checkout />             {/* loads data + code early */}
</Activity>

// Compare: conditional rendering loses state
{tab === 'contact' && <ContactForm />}

Hidden vs Unmounted

State keptState lost
DOM kept (display: none)DOM removed
Effects cleaned upEffects cleaned up
Low-priority re-rendersNo renders
Instant re-showFull remount

⚠ Common Mistakes

  • Hiding heavy trees forever and paying their memory cost
  • Effects that don't clean up, so hidden trees keep side effects alive
  • Expecting hidden content to stay in the accessibility tree

✓ Tips & Best Practices

  • Use for a few high-value screens, not every conditional
  • Make sure every effect has a correct cleanup
  • Pair with Suspense to pre-load data for hidden screens

Quick Summary

  • <Activity mode> hides, keeps state
  • Effects clean up while hidden
  • Great for tabs and back nav
  • Stable since 19.2
