useLayoutEffect & useInsertionEffect

before paint · measuring the DOM · tooltip positioning · flicker · useInsertionEffect for CSS-in-JS · SSR caveats

Effects Before Paint

useLayoutEffect has the same signature as useEffect but runs synchronously after DOM changes and before the browser paints. Use it when you must measure layout and update state before the user sees anything, such as positioning a tooltip, to avoid a visible jump. It blocks painting, so keep it rare and fast. useInsertionEffect runs even earlier and exists for CSS-in-JS libraries to inject styles.

Notes

  • Order: render → DOM mutation → insertion effects → layout effects → paint → effects
  • State updates inside useLayoutEffect re-render synchronously before paint
  • useLayoutEffect does nothing on the server and warns in older React versions
  • useInsertionEffect can't update state or read refs

♿ Accessibility

  • Positioning popovers before paint prevents them from appearing over the trigger and confusing magnifier users

Version Notes

  • React 19 no longer warns about useLayoutEffect during server rendering
  • CSS anchor positioning can replace many measure-and-position effects

Code Explained

The first render places the tooltip at height 0, invisibly
The layout effect measures and sets height before the browser paints
The second render positions it correctly; users never see the first
If there's no room above, the tooltip flips below the target
useInsertionEffect adds styles before any layout effect reads them

Measure Before Paint

import { useLayoutEffect, useRef, useState } from 'react';

function Tooltip({ targetRect, children }) {
  const ref = useRef(null);
  const [height, setHeight] = useState(0);

  useLayoutEffect(() => {
    const { height } = ref.current.getBoundingClientRect();
    setHeight(height);             // re-renders before paint
  }, []);

  let top = targetRect.top - height;
  if (top < 0) top = targetRect.bottom;   // flip below

  return (
    <div ref={ref} role="tooltip"
      style={{ position: 'fixed', top, left: targetRect.left }}>
      {children}
    </div>
  );
}

// For CSS-in-JS authors only
import { useInsertionEffect } from 'react';
function useCSS(rule) {
  useInsertionEffect(() => {
    const style = document.createElement('style');
    style.textContent = rule;
    document.head.append(style);
    return () => style.remove();
  }, [rule]);
}

// Timeline:
// render -> DOM -> insertion -> layout -> PAINT -> useEffect

⚠ Common Mistakes

  • Using useLayoutEffect by default and slowing every render
  • Heavy work in layout effects that blocks paint
  • Using useInsertionEffect in app code

✓ Tips & Best Practices

  • Start with useEffect; switch only if you see a flicker
  • Check whether CSS (anchor positioning, position: sticky) solves it first
  • Use a positioning library such as Floating UI for complex popovers

Quick Summary

  • useLayoutEffect = before paint
  • For measure-then-render
  • Blocks paint: use sparingly
  • useInsertionEffect = CSS-in-JS only
