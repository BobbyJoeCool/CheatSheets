Sheet 18

Objects & Arrays in State

immutability · spread copies · nested updates · add/remove/replace items · toSorted() / with() · Immer / use-immer

Replace, Don't Mutate

React decides whether to re-render by comparing the old and new state references. If you mutate an object or array in place, the reference stays the same and React may ignore the change. Always create a new object or array: spread for objects, and non-mutating array methods (map, filter, toSorted, with) for arrays. Immer lets you write mutating code that produces immutable updates.

Notes

  • Spread copies are shallow; nested objects need their own spread
  • [...arr, x] adds, filter removes, map replaces
  • toSorted(), toReversed(), toSpliced() and with() return new arrays (ES2023)
  • Immer's produce or useImmer hook creates the copy for you

♿ Accessibility

  • Mutation bugs can leave the UI out of sync with aria-checked/aria-selected; immutable updates keep them accurate

Version Notes

  • ES2023 copying array methods are available in all current browsers
  • React 19 doesn't change the immutability rule

Code Explained

{ ...user, name } copies the top level and overrides one field
Nested data needs a spread at every level you change
map returns a new array with one item replaced by a new object
toSpliced, toSorted and with never touch the original
useImmer gives a draft you can push into; Immer builds the new state

Immutable Updates

const [user, setUser] = useState({
  name: 'Ada',
  address: { city: 'London', zip: 'N1' },
});

// Object field
setUser({ ...user, name: 'Grace' });

// Nested object
setUser({
  ...user,
  address: { ...user.address, city: 'Paris' },
});

const [todos, setTodos] = useState(initial);

// Add / remove / replace
setTodos([...todos, { id: crypto.randomUUID(), text }]);
setTodos(todos.filter((t) => t.id !== id));
setTodos(todos.map((t) =>
  t.id === id ? { ...t, done: !t.done } : t));

// Insert, sort, replace by index (new arrays)
setTodos(todos.toSpliced(1, 0, newTodo));
setTodos(todos.toSorted((a, b) => a.text.localeCompare(b.text)));
setTodos(todos.with(0, { ...todos[0], pinned: true }));

// Immer: write "mutations" on a draft
import { useImmer } from 'use-immer';
const [state, update] = useImmer({ todos: [] });
update((draft) => { draft.todos.push(newTodo); });

// ✗ Mutation: same reference, may not re-render
user.name = 'Grace'; setUser(user);

⚠ Common Mistakes

  • Sorting state in place with sort()
  • Spreading only the top level and mutating a nested object
  • Calling setUser(user) after mutating user

✓ Tips & Best Practices

  • Keep state shallow so updates need fewer spreads
  • Use Immer when updates go three or more levels deep
  • Store items in arrays with IDs, not by index

Quick Summary

  • New reference = re-render
  • Spread objects, copy arrays
  • toSorted/with/toSpliced
  • Immer for deep updates
