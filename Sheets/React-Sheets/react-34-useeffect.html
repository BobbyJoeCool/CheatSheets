Synchronizing with the Outside

useEffect(setup, deps) runs code after React commits a render to the screen. Use it to synchronize a component with something outside React: a network connection, a browser API subscription, a third-party widget, a timer. The setup can return a cleanup function that undoes it. React runs cleanup before the next setup and when the component unmounts.

Notes

  • No array: runs after every render; []: after mount only; [a, b]: when a or b change
  • Effects run after paint, so they don't block the browser
  • In development, StrictMode runs setup → cleanup → setup once on mount to test your cleanup
  • Effects only run on the client, not during server rendering

♿ Accessibility

  • Effects that move focus or announce changes must run after the content exists; useEffect timing is right for that

Version Notes

  • Unchanged API since 16.8; StrictMode double-invoke since React 18
  • React 19.2 adds useEffectEvent for non-reactive logic inside effects (sheet 35)

Code Explained

ChatRoom connects after rendering and disconnects on cleanup
Changing roomId runs cleanup for the old room, then setup for the new one
[] means the resize listener is added once and removed on unmount
The title effect re-runs only when count changes
Each effect handles one concern; split unrelated logic into separate effects

Setup and Cleanup

import { useEffect, useState } from 'react';

function ChatRoom({ roomId, serverUrl }) {
  useEffect(() => {
    const conn = createConnection(serverUrl, roomId);
    conn.connect();
    return () => conn.disconnect();   // cleanup
  }, [roomId, serverUrl]);             // re-sync when these change

  return <h1>Welcome to {roomId}</h1>;
}

function WindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    const onResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', onResize);
    return () => window.removeEventListener('resize', onResize);
  }, []);

  return <p>{width}px</p>;
}

function DocumentTitle({ count }) {
  useEffect(() => {
    document.title = `${count} new messages`;
  }, [count]);
  return null;
}

⚠ Common Mistakes

  • Missing cleanup, which StrictMode reveals as duplicate connections
  • Using effects to transform data for rendering (sheet 36)
  • Making the setup function async (it must return cleanup, not a promise)

✓ Tips & Best Practices

  • Write the cleanup first: how do I stop this?
  • One effect per external system
  • Move the logic into a custom hook once it works

Quick Summary

  • useEffect(setup, deps)
  • Runs after paint
  • Return cleanup
