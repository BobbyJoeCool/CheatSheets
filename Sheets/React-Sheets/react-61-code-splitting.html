Code Splitting & Lazy Loading

lazy() · dynamic import() · <Suspense> fallback · route-level splitting · preloading · default export requirement

Loading Code on Demand

Code splitting breaks the bundle into chunks that load only when needed. lazy(() => import('./X')) creates a component whose code downloads the first time it renders; wrap it in <Suspense> to show a fallback while it loads. Split at routes first, then at heavy, rarely used widgets such as editors, charts and modals.

Notes

  • lazy expects a module with a default export
  • Declare lazy components at module top level, never inside a component
  • Start the import early (on hover or route preload) to hide the delay
  • Bundlers create a separate chunk for every dynamic import()

♿ Accessibility

  • Give the Suspense fallback accessible loading text
  • After a lazy route loads, move focus to its heading

Version Notes

  • lazy and Suspense for code have been stable since React 16.6
  • React Router and Next.js split routes automatically

Code Explained

Each lazy route becomes its own chunk
.then(m => ({ default: m.Editor })) adapts a named export
One Suspense boundary covers both routes
Hovering starts the download before the click
Calling lazy inside a component resets state on every render

lazy + Suspense

import { lazy, Suspense, useState } from 'react';

// Route-level split
const Settings = lazy(() => import('./pages/Settings'));
const Reports = lazy(() => import('./pages/Reports'));

// Named export -> map it to default
const Editor = lazy(() =>
  import('./Editor').then((m) => ({ default: m.Editor })));

function App({ page }) {
  return (
    <Suspense fallback={<p role="status">Loading page…</p>}>
      {page === 'settings' ? <Settings /> : <Reports />}
    </Suspense>
  );
}

// Heavy widget: load only when opened
function Post() {
  const [editing, setEditing] = useState(false);
  return (
    <>
      <button
        onMouseEnter={() => import('./Editor')}   // preload
        onClick={() => setEditing(true)}>
        Edit
      </button>
      {editing && (
        <Suspense fallback={<p>Loading editor…</p>}>
          <Editor />
        </Suspense>
      )}
    </>
  );
}

// ✗ lazy inside a component: new component each render
function Bad() {
  const Chart = lazy(() => import('./Chart'));
  return <Chart />;
}

⚠ Common Mistakes

  • Calling lazy inside a component body
  • No error boundary for failed chunk loads (e.g. after a deploy)
  • Splitting tiny components and adding network round trips

✓ Tips & Best Practices

  • Check bundle size with vite build output or rollup-plugin-visualizer
  • Preload the next route on link hover
  • Retry failed chunk imports once, then show a reload prompt

Quick Summary

  • lazy(() => import())
  • Wrap in <Suspense>
  • Split routes first
  • Preload on hover
