A Store in One Hook

Zustand creates a global store with a single function: create((set, get) => ({ …state, …actions })) returns a hook. Components call it with a selector and re-render only when the selected value changes. There's no provider, no reducers and no boilerplate. Middleware adds persist (localStorage), devtools (Redux DevTools) and immer.

Notes

  • set merges the object you pass into state (one level deep)
  • get() reads current state inside actions
  • Select multiple values with useShallow to avoid re-renders from new objects
  • Access state outside React with useStore.getState() and useStore.setState()

♿ Accessibility

  • Persist accessibility preferences (font size, reduced motion) with the persist middleware

Version Notes

  • Zustand 5 is current: requires React 18+, uses useSyncExternalStore, drops the default export
  • TypeScript: use the curried form create<State>()(…)

Code Explained

create<CartState>()(…) is the curried form that types middleware correctly
persist saves state to localStorage under cart
devtools connects the store to Redux DevTools
Selecting items.length means CartBadge ignores other changes
useShallow compares the selected object's fields, not its identity

create, Selectors, Middleware

import { create } from 'zustand';
import { devtools, persist } from 'zustand/middleware';
import { useShallow } from 'zustand/react/shallow';

type CartState = {
  items: { id: string; qty: number }[];
  add: (id: string) => void;
  clear: () => void;
  total: () => number;
};

export const useCart = create<CartState>()(
  devtools(
    persist(
      (set, get) => ({
        items: [],
        add: (id) => set((s) => ({ items: [...s.items, { id, qty: 1 }] })),
        clear: () => set({ items: [] }),
        total: () => get().items.reduce((n, i) => n + i.qty, 0),
      }),
      { name: 'cart' },          // localStorage key
    ),
  ),
);

function CartBadge() {
  const count = useCart((s) => s.items.length);   // re-renders on count
  return <span>{count}</span>;
}

function CartActions() {
  const { add, clear } = useCart(
    useShallow((s) => ({ add: s.add, clear: s.clear })),
  );
  return <button onClick={() => add('a1')}>Add</button>;
}

// Outside React
useCart.getState().clear();
const unsub = useCart.subscribe((s) => console.log(s.items));

⚠ Common Mistakes

  • Calling useStore() with no selector and re-rendering on every change
  • Returning new objects from selectors without useShallow
  • Storing server data that belongs in TanStack Query

✓ Tips & Best Practices

  • One store per domain (useCart, useUI)
  • Keep actions in the store so components stay simple
  • Reset stores between tests with setState(initial)

Quick Summary

  • create((set, get) => ({…}))
  • Select only what you need
  • useShallow for multiple fields
  • persist, devtools middleware
