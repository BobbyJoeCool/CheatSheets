Redux Toolkit: Store & Slices

configureStore · createSlice · Immer in reducers · <Provider> · useSelector · useDispatch · typed hooks

Modern Redux

Redux Toolkit (RTK) is the official way to write Redux. configureStore creates the store with good defaults (DevTools, thunk middleware, mutation checks). createSlice defines a slice of state with reducers that look mutating but use Immer to produce immutable updates, and generates action creators automatically. React components read state with useSelector and send actions with useDispatch from react-redux.

Notes

  • Each slice owns one domain: cart, auth, ui
  • PayloadAction<T> types the action payload in TypeScript
  • Selectors should return the smallest value needed
  • Typed hooks: useSelector.withTypes<RootState>()

♿ Accessibility

  • Redux DevTools time-travel helps reproduce focus and announcement bugs tied to specific state sequences

Version Notes

  • Redux Toolkit 2 and react-redux 9 are current; both support React 19
  • RTK 2 removed the object syntax for extraReducers (use the builder callback)

Code Explained

push looks like mutation, but Immer turns it into a new array
cartSlice.actions contains added and removed action creators
selectors (RTK 2) attaches selectors to the slice
withTypes creates hooks typed once for the whole app
useAppSelector(selectCount) re-renders only when the count changes

Store, Slice, Hooks

// features/cart/cartSlice.ts
import { createSlice, type PayloadAction } from '@reduxjs/toolkit';

type Item = { id: string; name: string; qty: number };

const cartSlice = createSlice({
  name: 'cart',
  initialState: { items: [] as Item[] },
  reducers: {
    added(state, action: PayloadAction<Item>) {
      state.items.push(action.payload);          // Immer
    },
    removed(state, action: PayloadAction<string>) {
      state.items = state.items.filter((i) => i.id !== action.payload);
    },
  },
  selectors: {
    selectCount: (state) => state.items.length,
  },
});
export const { added, removed } = cartSlice.actions;
export const { selectCount } = cartSlice.selectors;
export default cartSlice.reducer;

// app/store.ts
import { configureStore } from '@reduxjs/toolkit';
export const store = configureStore({ reducer: { cart: cartReducer } });
export type RootState = ReturnType<typeof store.getState>;
export type AppDispatch = typeof store.dispatch;

// app/hooks.ts
export const useAppSelector = useSelector.withTypes<RootState>();
export const useAppDispatch = useDispatch.withTypes<AppDispatch>();

// main.tsx
<Provider store={store}><App /></Provider>

// Component
function CartBadge() {
  const count = useAppSelector(selectCount);
  const dispatch = useAppDispatch();
  return <button onClick={() => dispatch(removed('a1'))}>{count}</button>;
}

⚠ Common Mistakes

  • Hand-writing action types and switch reducers (legacy Redux)
  • Selecting the whole state object and re-rendering on every change
  • Returning and mutating the draft in the same reducer

✓ Tips & Best Practices

  • Organize by feature: features/cart/cartSlice.ts
  • Use RTK Query (sheet 83) for server data instead of slices
  • Install the Redux DevTools browser extension
