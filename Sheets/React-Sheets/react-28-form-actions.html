Form Actions

<form action={fn}> · FormData · async actions · formAction on buttons · automatic reset · requestFormReset

Forms That Call Functions

In React 19, a <form>'s action prop can be a function. When the form submits, React calls it with the form's FormData, wraps it in a transition (so the UI stays responsive), and, for uncontrolled fields, resets the form after it succeeds. Actions can be async. Individual submit buttons can override the action with formAction.

Notes

  • No preventDefault needed: React handles the submit
  • Async actions run inside a transition; pending state is available via hooks
  • Errors thrown in an action go to the nearest error boundary
  • requestFormReset(form) from react-dom resets a form manually

♿ Accessibility

  • Disable the submit button and show progress while pending (sheet 29)
  • After a successful action, move focus or announce the result

Version Notes

  • Function action/formAction props are new in React 19
  • With a framework, the function can be a Server Function ('use server', sheet 87)

Code Explained

action={subscribe} receives FormData; no submit handler needed
React awaits the async function inside a transition
Fields reset after success because they are uncontrolled
formAction on the second button runs saveDraft instead of publish
requestFormReset must be called inside a transition or action

Form Actions

function NewsletterForm() {
  async function subscribe(formData) {
    const email = formData.get('email');
    await api.subscribe(email);      // async is fine
  }

  return (
    <form action={subscribe}>
      <input name="email" type="email" required />
      <button>Subscribe</button>
    </form>
  );
}

function PostEditor({ post }) {
  async function publish(formData) {
    await api.save({ ...post, body: formData.get('body'),
      status: 'published' });
  }
  async function saveDraft(formData) {
    await api.save({ ...post, body: formData.get('body') });
  }

  return (
    <form action={publish}>
      <textarea name="body" defaultValue={post.body} />
      <button>Publish</button>
      <button formAction={saveDraft}>Save draft</button>
    </form>
  );
}

// Manual reset from inside a transition
import { requestFormReset } from 'react-dom';
startTransition(() => requestFormReset(formEl));

⚠ Common Mistakes

  • Calling e.preventDefault() inside an action (there's no event)
  • Controlling every field with state and losing the auto-reset
  • Expecting action to receive the event instead of FormData

✓ Tips & Best Practices

  • Return validation errors with useActionState instead of throwing
  • Keep actions small: parse, call the API, return a result
  • Use formAction for secondary buttons like Save draft

Quick Summary

  • Runs as a transition
