Writing Custom Hooks

extracting logic · naming · return values · composing hooks · state isn't shared · useDebugValue

Extracting Logic

A custom hook is a function whose name starts with use and that calls other hooks. It packages stateful logic (subscriptions, timers, form state, data fetching) so several components can share it. Each component that calls the hook gets its own independent state; hooks share logic, not data. Return whatever is most convenient: a value, a tuple, or an object.

Notes

  • Name it after what it does: useOnlineStatus, useChatRoom
  • Pass reactive values in as arguments; the hook re-syncs when they change
  • Return tuples [value, setValue] for two items, objects for more
  • useDebugValue(label) shows a label next to the hook in React DevTools

♿ Accessibility

  • Encapsulate accessibility behavior (focus traps, roving tabindex, live announcements) in hooks so every component gets it right

Version Notes

  • Custom hooks are plain functions; nothing new in React 19
  • The React Compiler optimizes custom hooks like components

Code Explained

useOnlineStatus hides two listeners and their cleanup
useDebugValue labels the hook in DevTools
useToggle returns a tuple, like useState
useAutosave composes useOnlineStatus and re-runs when value changes
Every component calling useOnlineStatus gets its own state and listeners

Writing and Composing Hooks

import { useDebugValue, useEffect, useState } from 'react';

export function useOnlineStatus() {
  const [online, setOnline] = useState(navigator.onLine);
  useEffect(() => {
    const on = () => setOnline(true);
    const off = () => setOnline(false);
    window.addEventListener('online', on);
    window.addEventListener('offline', off);
    return () => {
      window.removeEventListener('online', on);
      window.removeEventListener('offline', off);
    };
  }, []);
  useDebugValue(online ? 'Online' : 'Offline');
  return online;
}

export function useToggle(initial = false) {
  const [on, setOn] = useState(initial);
  const toggle = () => setOn((v) => !v);
  return [on, toggle];
}

// Hooks can call hooks
export function useAutosave(value, save) {
  const online = useOnlineStatus();
  useEffect(() => {
    if (!online) return;
    const id = setTimeout(() => save(value), 1000);
    return () => clearTimeout(id);
  }, [value, online, save]);
  return online;
}

function StatusBar() {
  const online = useOnlineStatus();   // own state
  const [open, toggle] = useToggle();
  return <p>{online ? '✅ Online' : '❌ Offline'}</p>;
}

⚠ Common Mistakes

  • Expecting two components using the same hook to share state
  • Hooks named useX that don't call hooks (make them plain functions)
  • Lifecycle-style hooks (useMount) that hide missing dependencies

✓ Tips & Best Practices

  • Extract a hook when two components copy the same effect
  • Keep hooks focused on one concern
  • Test hooks with renderHook (sheet 94)

Quick Summary

  • use* + calls hooks
  • Shares logic, not state
  • Compose hooks freely
  • useDebugValue for DevTools
