Typing State, Refs and Context

Most hooks infer their types: useState(0) is number. Provide a type argument when the initial value doesn't describe all possible values, such as null before data loads or an empty array. DOM refs start as null and take the element type. Reducers use a discriminated union for actions so each case knows its payload. Context typed as T | null plus a guard hook avoids non-null assertions.

Notes

  • useState<User | null>(null) allows null until data arrives
  • useState<string[]>([]) avoids an inferred never[]
  • useRef<HTMLInputElement>(null) gives RefObject<HTMLInputElement | null>
  • useRef<number | null>(null) for mutable values like timer IDs

♿ Accessibility

  • Type focus-target refs precisely (HTMLButtonElement) so .focus() calls are checked

Version Notes

  • @types/react 19: useRef requires an argument; all refs are mutable (RefObject.current is writable)
  • useReducer types infer from the reducer; explicit generics are rarely needed

Code Explained

Hooks with Types

import { createContext, use, useReducer, useRef, useState } from 'react';

type User = { id: string; name: string };

const [user, setUser] = useState<User | null>(null);
const [tags, setTags] = useState<string[]>([]);
const [count, setCount] = useState(0);          // number

const inputRef = useRef<HTMLInputElement>(null);
inputRef.current?.focus();
const timer = useRef<number | null>(null);

type Action =
  | { type: 'added'; text: string }
  | { type: 'toggled'; id: string }
  | { type: 'cleared' };
type Todo = { id: string; text: string; done: boolean };

function reducer(state: Todo[], action: Action): Todo[] {
  switch (action.type) {
    case 'added':
      return [...state, { id: crypto.randomUUID(),
        text: action.text, done: false }];
    case 'toggled':
      return state.map((t) => t.id === action.id
        ? { ...t, done: !t.done } : t);
    case 'cleared':
      return [];
  }
}
const [todos, dispatch] = useReducer(reducer, []);

const AuthContext = createContext<User | null>(null);
export function useAuth(): User {
  const user = use(AuthContext);
  if (!user) throw new Error('useAuth outside <AuthProvider>');
  return user;
}

export function useToggle(init = false) {
  const [on, setOn] = useState(init);
  return [on, () => setOn((v) => !v)] as const;
}

⚠ Common Mistakes

  • useState([]) inferring never[]
  • Non-null assertions (ctx!) on context instead of a guard hook
  • Returning [a, b] from a custom hook without as const

✓ Tips & Best Practices

  • Let inference work; annotate only where it can't
  • Name action types in past tense (added) like events
  • Use satisfies to check objects without widening

Quick Summary

  • useState<T | null>(null)
  • useRef<HTMLElement>(null)
  • Discriminated union actions
  • Context T | null + guard hook
