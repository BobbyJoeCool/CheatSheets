Document Metadata & Resources

<title> / <meta> / <link> in components · stylesheet precedence · async scripts · preload · preinit · prefetchDNS

Head Tags From Components

In React 19, components can render <title>, <meta> and <link> anywhere in the tree, and React hoists them into <head>. Stylesheets rendered with a precedence prop are deduplicated, inserted in order, and Suspense waits for them before revealing content. react-dom also exports resource hints such as preload, preinit and prefetchDNS to start loading fonts, scripts and styles early.

Notes

  • Works in client rendering, SSR and Server Components
  • <link rel="stylesheet" precedence="default"> is deduplicated by href
  • <script async src> anywhere in the tree is deduplicated and loaded once
  • Libraries like react-helmet are mostly unnecessary for basic metadata

♿ Accessibility

  • Set a unique, descriptive <title> per page; it's the first thing screen readers announce after navigation

Version Notes

  • Metadata hoisting, stylesheet precedence and resource APIs are new in React 19
  • Frameworks (Next.js metadata export) may provide their own higher-level APIs

Metadata, Styles and Preloading

import { preload, preinit, prefetchDNS, preconnect } from 'react-dom';

function BlogPost({ post }) {
  return (
    <article>
      <title>{`${post.title} | My Blog`}</title>
      <meta name="description" content={post.summary} />
      <meta name="author" content={post.author} />
      <link rel="canonical" href={post.url} />

      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </article>
  );
}

function CodeBlock({ code }) {
  return (
    <>
      <link rel="stylesheet" href="/prism.css" precedence="default" />
      <script async src="/prism.js" />
      <pre>{code}</pre>
    </>
  );
}

function App() {
  preinit('/analytics.js', { as: 'script' }); // load + run
  preload('/fonts/inter.woff2', { as: 'font', type: 'font/woff2',
    crossOrigin: 'anonymous' });
  prefetchDNS('https://api.example.com');
  preconnect('https://cdn.example.com');
  return <Routes />;
}

Resource APIs

FunctionDoes
prefetchDNS(url)DNS lookup early
preconnect(url)open connection
preload(url, {as})download early
preloadModule(url)download ES module
preinit(url, {as})download + execute/apply
preinitModule(url)download + run module

⚠ Common Mistakes

  • <title>Hi {name}</title> producing multiple children (use a template literal)
  • Two components rendering different <title>s at once
  • Stylesheets without precedence (not hoisted or deduplicated)

✓ Tips & Best Practices

  • Render the title in each route's top component
  • Preload fonts used above the fold
  • Let your framework's metadata API handle Open Graph images and sitemaps

Quick Summary

  • <title>/<meta>/<link> hoist to head
  • precedence for stylesheets
  • <script async> dedupes
  • preload/preinit for resources
