Sheet 062

Generators

function* · yield · yield* · return() · lazy / infinite sequences · async generators

Overview

A generator function (function*) returns an iterator that runs the function body lazily. Each yield pauses execution and hands out a value; the next next() call resumes right after it. Generators make custom iterators, lazy pipelines, and infinite sequences short and readable. async function* yields values over time.

Notes

  • Calling a generator function doesn't run it; it returns a generator object
  • yield* delegates to another iterable
  • return ends the generator; its value has done: true and is skipped by for...of
  • next(value) sends a value back in as the result of yield

Generators

function* count(to) {
  for (let i = 1; i <= to; i++) yield i;
}
[...count(3)];                     // [1, 2, 3]

function* ids() {                  // infinite, lazy
  let id = 0;
  while (true) yield ++id;
}
const gen = ids();
gen.next().value;                  // 1
gen.next().value;                  // 2

function* both() { yield* [1, 2]; yield* count(2); }  // delegate
[...both()];                       // [1, 2, 1, 2]

const obj = { *[Symbol.iterator]() { yield "a"; yield "b"; } };
[...obj];                          // ["a", "b"]

async function* pages(url) {       // async generator
  while (url) { const r = await (await fetch(url)).json();
                yield r.items; url = r.next; }
}

Code Explained

yield — pause and output a value
Infinite generators are fine; consume with care
yield* — yield every value of another iterable
*[Symbol.iterator]() — generator method makes an object iterable

TypeScript

  • Type as Generator<T, TReturn, TNext>, or let TS infer it from yield
  • Async generators are AsyncGenerator<T>; consume with for await

⚠ Common Mistakes

  • Calling count(3) and expecting it to run; you must iterate it
  • Spreading an infinite generator
  • Reusing a finished generator; create a new one with another call

✓ Tips & Best Practices

  • Combine generators with iterator helpers: ids().take(5).toArray()
  • Use async function* for paginated APIs and streams
  • Write recursive tree walks as yield* walk(child)

Quick Summary

  • function* — lazy iterator factory
  • yield — pause and output
  • yield* — delegate
  • async function* — values over time
