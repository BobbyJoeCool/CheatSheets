Sheet 118

Narrowing & Type Guards

typeof · instanceof · in · equality · type predicates is · asserts · control-flow analysis

Overview

Narrowing is how TypeScript refines a broad type to a specific one inside a branch. It follows your runtime checks: typeof, instanceof, in, equality, truthiness, and assignments. For checks it can't understand on its own, write a type predicate (x is T) or an assertion function (asserts x is T).

Notes

  • Narrowing follows control flow, including early returns
  • Narrowing resets in callbacks if the variable can be reassigned
  • Type predicates are trusted, so make sure they're correct
  • TS 5.5+ infers predicates from simple filter callbacks

Narrowing techniques

function format(x: string | number | Date | null) {
  if (x === null) return "—";                  // equality
  if (typeof x === "string") return x.trim();  // typeof
  if (x instanceof Date) return x.toISOString(); // instanceof
  return x.toFixed(2);                          // only number left
}

type Fish = { swim(): void };
type Bird = { fly(): void };
function move(a: Fish | Bird) {
  if ("swim" in a) a.swim(); else a.fly();      // in
}

function isString(v: unknown): v is string {    // type predicate
  return typeof v === "string";
}
const values: unknown[] = ["a", 1, "b"];
const strs = values.filter(isString);           // string[]

function assertUser(v: unknown): asserts v is { id: number } {
  if (!v || typeof v !== "object" || !("id" in v)) throw new Error("bad");
}
assertUser(data);  data.id;                     // narrowed after the call

Code Explained

Each check removes possibilities from the union
in — narrow by property presence
v is T — reusable custom check
Predicates make filter return the narrowed type
asserts — narrows everything after the call

⚠ Common Mistakes

  • Writing a type predicate whose logic doesn't match its claim
  • Expecting narrowing to persist inside a callback for a let variable
  • Using as instead of a real check

✓ Tips & Best Practices

  • Prefer discriminated unions; their narrowing is automatic
  • Use assertion functions at the top of handlers for input validation
  • Combine with Zod: schema.parse returns already-narrowed data

Quick Summary

  • control flow — checks narrow types
  • typeof / instanceof / in — built-in guards
  • x is T — custom predicate
