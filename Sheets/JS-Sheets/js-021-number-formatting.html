Sheet 021

Number & Locale Formatting

toFixed · toPrecision · toLocaleString · Intl.NumberFormat · currency · compact notation

Overview

For quick formatting, toFixed sets decimal places and toPrecision sets significant digits. For anything shown to users, use toLocaleString or Intl.NumberFormat, which handle thousands separators, currency, percentages, units, and compact notation for any locale.

Notes

  • toFixed returns a string, not a number
  • toFixed uses binary floats: (1.005).toFixed(2) is "1.00"
  • Create one Intl.NumberFormat and reuse it; it's faster than toLocaleString in loops
  • Locale defaults to the user's browser or system locale

Formatting numbers

(3.14159).toFixed(2);              // "3.14"
(1234.5).toFixed(0);               // "1235"
(0.000123).toPrecision(2);         // "0.00012"
(1234567.891).toLocaleString();    // "1,234,567.891" (en-US)
(1234567.891).toLocaleString("de-DE"); // "1.234.567,891"

const usd = new Intl.NumberFormat("en-US",
  { style: "currency", currency: "USD" });
usd.format(1234.5);                // "$1,234.50"

new Intl.NumberFormat("en", { style: "percent" }).format(0.256);  // "26%"
new Intl.NumberFormat("en", { notation: "compact" }).format(15300); // "15K"
new Intl.NumberFormat("en", { style: "unit", unit: "kilometer-per-hour" })
  .format(50);                     // "50 km/h"
new Intl.NumberFormat("en", { maximumFractionDigits: 1 }).format(2.47); // "2.5"

Code Explained

style: "currency" — needs a currency code
notation: "compact" — 15K, 1.2M
unit style — localized unit names
minimumFractionDigits / maximumFractionDigits — control decimals

TypeScript

  • Option objects are typed, so a typo like style: "curency" is a compile error
  • Returns string; convert back with Number() only if you must

⚠ Common Mistakes

  • Doing math on the result of toFixed; it's a string, so + concatenates
  • Building currency strings by hand ("$" + n), which breaks for other locales and negatives
  • Assuming toFixed rounds half-up; floating-point representation can round down

✓ Tips & Best Practices

  • Keep numbers as numbers until the moment you display them
  • Use Intl.NumberFormat(...).formatToParts() to style pieces (e.g., a smaller currency symbol)
  • Pass the user's locale explicitly on servers, where the default may be wrong

Quick Summary

  • toFixed(n) — n decimals, string
  • toLocaleString() — locale-aware
  • Intl.NumberFormat — currency, percent, units
  • notation: "compact" — 15K style
