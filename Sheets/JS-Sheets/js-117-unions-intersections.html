Unions & Intersections

| · & · discriminated unions · exhaustiveness · never

Overview

A union (A | B) is a value that can be one of several types; you must narrow it before using type-specific members. An intersection (A & B) has all members of both. Discriminated unions give each variant a shared literal field (like kind), which makes narrowing automatic and lets TypeScript check that every case is handled.

Notes

  • Only members common to all union variants are usable without narrowing
  • Literal unions replace most enums: "sm" | "md" | "lg"
  • Intersections of conflicting primitives become never
  • Assigning to never in default forces exhaustive handling

Unions and discriminated unions

type Size = "sm" | "md" | "lg";
function pad(value: string | number): string {
  return typeof value === "number" ? " ".repeat(value) : value;
}

type Shape =
  | { kind: "circle"; r: number }
  | { kind: "rect"; w: number; h: number }
  | { kind: "tri"; base: number; h: number };

function area(s: Shape): number {
  switch (s.kind) {
    case "circle": return Math.PI * s.r ** 2;     // s is circle here
    case "rect":   return s.w * s.h;
    case "tri":    return (s.base * s.h) / 2;
    default: return s satisfies never;           // errors if a case is missing
  }
}

type Timestamped = { createdAt: Date };
type Post = { title: string } & Timestamped;      // intersection
type Result<T> = { ok: true; value: T } | { ok: false; error: string };

⚠ Common Mistakes

  • Accessing a property that exists on only one variant without narrowing
  • Modeling states with several optional booleans (isLoading, isError) instead of a union
  • Forgetting a never check, so new variants silently fall through

✓ Tips & Best Practices

  • Model state machines and API results as discriminated unions
  • Use a consistent discriminant name (kind, type, or status)
  • Prefer literal unions to enums for simple string options

Quick Summary

  • | — one of several
  • & — all combined
  • discriminant field — auto narrowing
  • never — exhaustiveness
