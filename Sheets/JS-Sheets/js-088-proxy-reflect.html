Proxy & Reflect

new Proxy · get / set / has traps · Reflect.* · validation proxies · observable objects

Overview

A Proxy wraps an object and intercepts operations on it, like reading, writing, deleting, or calling, through trap functions in a handler. Reflect provides the default behavior for each trap, so you can add logic and then forward the operation. They power validation layers, reactive frameworks (Vue), and API wrappers.

Notes

  • Traps you don't define pass straight through to the target
  • Use Reflect.* inside traps to keep correct default behavior
  • Proxies are slower than plain objects; avoid in hot paths
  • Proxy.revocable creates a proxy you can switch off

Validation and logging proxies

const user = { name: "Ana", age: 30 };

const validated = new Proxy(user, {
  set(target, key, value, receiver) {
    if (key === "age" && (!Number.isInteger(value) || value < 0)) {
      throw new TypeError(`Invalid age: ${value}`);
    }
    return Reflect.set(target, key, value, receiver);
  },
  get(target, key, rcv) {
    if (!(key in target)) console.warn(`No "${String(key)}"`);
    return Reflect.get(target, key, rcv);
  },
});

validated.age = 31;          // OK
// validated.age = -5;       // TypeError
validated.nmae;              // warns: No "nmae"

const withDefault = new Proxy({}, { get: (t, k) => k in t ? t[k] : 0 });
withDefault.missing;         // 0
Reflect.ownKeys(user);       // ["name", "age"]

Code Explained

set trap — return true for success
Reflect.set/get — forward with default behavior
Default-value proxy — like Python's defaultdict
Reflect mirrors operators as functions

TypeScript

  • Type handlers as ProxyHandler<T>; new Proxy<T>(target, handler) returns T
  • TS can't see properties a proxy invents dynamically; type them explicitly

⚠ Common Mistakes

  • Returning nothing (undefined) from a set trap; strict mode treats it as failure and throws
  • Modifying the target directly, bypassing the proxy's checks
  • Expecting === between a proxy and its target to be true

✓ Tips & Best Practices

  • Always forward with Reflect unless you're intentionally blocking
  • Keep the raw target private so all access goes through the proxy
  • Prefer setters or plain functions when a proxy is overkill
