Sheet 099

Creating & Removing Elements

createElement · append · prepend · before / after · remove · replaceWith · template · DocumentFragment

Overview

Create elements with document.createElement, configure them, then insert them with append, prepend, before, after, or replaceWith. Remove with remove(). For repeated structures, clone a <template>. When adding many nodes, build them in a DocumentFragment so the page updates once.

Notes

  • append accepts multiple nodes and strings
  • Inserting an existing node moves it
  • cloneNode(true) copies the whole subtree
  • insertAdjacentHTML inserts markup at a position without wiping siblings

Building DOM nodes

const li = document.createElement("li");
li.textContent = "New task";
li.dataset.id = "7";
list.append(li);                         // end of list
list.prepend(header);                    // start
li.before(divider);  li.after(note);     // siblings
li.replaceWith(updatedLi);
li.remove();

const frag = document.createDocumentFragment();
for (const t of tasks) {
  const item = document.createElement("li");
  item.textContent = t.title;
  frag.append(item);
}
list.append(frag);                       // one insertion

// <template id="row"><tr><td class="n"></td><td class="p"></td></tr></template>
const tpl = document.querySelector("#row");
const row = tpl.content.cloneNode(true);
row.querySelector(".n").textContent = "Pen";
table.tBodies[0].append(row);

list.replaceChildren();                  // remove all children

Code Explained

Configure before inserting to avoid extra reflows
Fragment — builds offscreen, inserts once
<template> — inert HTML you clone and fill
replaceChildren() — clear an element

TypeScript

  • createElement("li") returns HTMLLIElement, so tag-specific properties are typed
  • tpl.content.cloneNode(true) returns Node; cast to DocumentFragment to query it

⚠ Common Mistakes

  • Building HTML strings with user data and inserting via innerHTML
  • Appending nodes one at a time in a large loop
  • Expecting append(existingNode) to copy it; it moves it

✓ Tips & Best Practices

  • Use <template> for anything more than a couple of nested elements
  • Clear and repopulate lists with replaceChildren(...nodes)
  • Consider a small library (lit-html) or framework when UI logic grows

Quick Summary

  • createElement — new node
  • append / prepend / before / after — insert
  • DocumentFragment — batch inserts
  • <template> — clone and fill
