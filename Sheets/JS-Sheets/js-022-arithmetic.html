Sheet 022

Arithmetic Operators

+ - * / % · ** · ++ -- · unary + - · + with strings · precedence

Overview

Arithmetic operators work on Numbers (and BigInts). + is special: if either side is a string it concatenates instead of adding. % is a remainder, not modulo, so its result takes the sign of the left operand. ** is exponentiation and is right-associative.

Notes

  • ++x increments then returns; x++ returns then increments
  • -x 2 is a SyntaxError; write (-x) 2
  • Precedence: ** › * / % › + -
  • Division always returns a float: 7 / 2 is 3.5

Arithmetic with results

7 + 2;        // 9
7 - 2;        // 5
7 * 2;        // 14
7 / 2;        // 3.5
7 % 2;        // 1
-7 % 2;       // -1   (sign of left side)
2 ** 10;      // 1024
2 ** 3 ** 2;  // 512  (right-assoc: 2 ** 9)

Math.trunc(7 / 2);          // 3  (integer division)
((-7 % 3) + 3) % 3;         // 2  (true modulo)

let i = 5;
i++;          // returns 5, i is now 6
++i;          // returns 7, i is now 7
"3" + 4;      // "34"
"3" * 4;      // 12
2 + 3 + "1";  // "51"

Code Explained

Math.trunc(a / b) — integer division toward zero
((a % n) + n) % n — modulo that's never negative
Prefix vs postfix — only matters when you use the returned value
+ evaluates left to right, switching to concatenation at the first string

TypeScript

  • Arithmetic on strings or objects is a compile error ("3" * 4 won't compile)
  • + with a string is still allowed and typed as string

⚠ Common Mistakes

  • Using % as modulo with negative numbers and getting negative results
  • Adding numbers read from inputs without converting them first
  • Writing i++ inside complex expressions, which makes the order hard to follow

✓ Tips & Best Practices

  • Use += 1 instead of ++ if your lint style prefers clarity
  • Use Math.round(x * 100) / 100 for 2-decimal rounding in calculations
  • Add parentheses whenever precedence isn't obvious

Quick Summary

  • + - * / — basic math, / is float
  • % — remainder, sign of left side
  • ** — exponent, right-associative
  • + with a string — concatenation
