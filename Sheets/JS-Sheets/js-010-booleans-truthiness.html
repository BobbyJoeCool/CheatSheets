Sheet 010

Booleans & Truthiness

true / false · falsy values · Boolean() · !! · truthy objects · empty arrays

Overview

Every value in JavaScript is either truthy or falsy when used as a condition. There are exactly eight falsy values; everything else, including empty arrays, empty objects, and the string "0", is truthy. Convert explicitly with Boolean(x) or the double-bang !!x.

Notes

  • Booleans are true and false, lowercase
  • if (x) tests truthiness, not x === true
  • new Boolean(false) is an object, so it's truthy
  • document.all is the one weird falsy object (legacy)

Truthiness in practice

Boolean(0);          // false
Boolean("");         // false
Boolean("0");        // true  (non-empty string)
Boolean([]);         // true  (empty array is an object)
Boolean({});         // true
!!"hello";           // true
!!null;              // false

const items = [];
if (items) { }                 // always runs: [] is truthy
if (items.length) { }          // correct emptiness check

const qty = 0;
const shown = qty || 1;        // 1  (0 treated as missing)
const kept = qty ?? 1;         // 0  (only null/undefined replaced)

Code Explained

!!x — shorthand for Boolean(x)
Check arrays with .length, objects with Object.keys(o).length
|| replaces every falsy value, including 0 and ""
?? replaces only null and undefined

TypeScript

  • Use boolean (lowercase), never the Boolean wrapper type
  • typescript-eslint's strict-boolean-expressions can ban relying on truthiness

⚠ Common Mistakes

  • if (arr) to check for an empty array; it's always true
  • count || default when 0 is a valid count; use ??
  • Comparing with == true; "1" == true is true but "2" == true is false

✓ Tips & Best Practices

  • Use ?? for defaults unless you truly want to replace "" and 0
  • Name boolean variables as questions: isReady, hasItems
  • Prefer explicit checks (x !== undefined) when the falsy cases matter

Quick Summary

  • 8 falsy values — everything else is truthy
  • Boolean(x) / !!x — convert
  • [] and {} — truthy
  • ?? vs || — null-only vs any falsy
