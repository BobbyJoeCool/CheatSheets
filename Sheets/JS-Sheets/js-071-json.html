Sheet 071

JSON

JSON.parse · JSON.stringify · indent · replacer · reviver · toJSON · unsupported values

Overview

JSON.stringify turns values into a JSON string and JSON.parse turns JSON text back into values. Both take optional hooks: a replacer and indent for stringify, a reviver for parse. JSON supports only objects, arrays, strings, finite numbers, booleans, and null, so Dates, Maps, undefined, and BigInts need handling.

Notes

  • JSON keys must be double-quoted; no trailing commas, no comments
  • undefined, functions, and symbols are dropped from objects (become null in arrays)
  • NaN and Infinity become null
  • JSON.parse throws SyntaxError on invalid input

Round-trip with hooks

const order = { id: 7, items: ["pen"], at: new Date(), note: undefined };

JSON.stringify(order);
// '{"id":7,"items":["pen"],"at":"2026-10-02T14:00:00.000Z"}'
JSON.stringify(order, null, 2);           // pretty, 2-space indent
JSON.stringify(order, ["id", "items"]);   // only these keys
JSON.stringify({ n: 1n }, (k, v) =>
  typeof v === "bigint" ? v.toString() : v);  // '{"n":"1"}'

const text = '{"id":7,"at":"2026-10-02T14:00:00.000Z"}';
JSON.parse(text).at;                      // string, not Date
const revived = JSON.parse(text, (k, v) =>
  k === "at" ? new Date(v) : v);
revived.at instanceof Date;               // true

try { JSON.parse("{bad}"); }
catch (e) { e.name; }                     // "SyntaxError"

Code Explained

Indent argument — number of spaces or a string like "\t"
Array replacer — whitelist of keys
Function replacer/reviver — called for every key/value
Dates serialize via toJSON to ISO strings

TypeScript

  • JSON.parse returns any, so validate it (Zod, sheet 085) or type it as unknown and narrow
  • JSON.stringify returns string (or undefined for undefined input)

⚠ Common Mistakes

  • Parsing untrusted JSON without try/catch
  • Expecting Dates to come back as Date objects after parse
  • Using the JSON round-trip as a deep clone for data with Maps or Dates

✓ Tips & Best Practices

  • Pretty-print logs with JSON.stringify(x, null, 2)
  • Convert Maps first: Object.fromEntries(map)
  • Validate parsed data at boundaries (APIs, files, localStorage)

Quick Summary

  • JSON.stringify — value → text
  • JSON.parse — text → value
  • replacer / reviver — custom handling
  • lossy — Dates, Maps, undefined
