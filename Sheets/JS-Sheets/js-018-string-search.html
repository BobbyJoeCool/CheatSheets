Sheet 018

String Methods — Search

indexOf · lastIndexOf · includes · startsWith · endsWith · search · match

Overview

Search methods tell you whether a substring exists and where. includes, startsWith, and endsWith return booleans; indexOf and lastIndexOf return a position or -1. For patterns, search returns a position and match returns match details (regex details on sheet 087). All are case-sensitive.

Notes

  • Positions are zero-based
  • -1 means not found, and it's truthy, so don't use if (s.indexOf(x))
  • startsWith/endsWith/includes throw if given a regex
  • Lowercase both sides for case-insensitive checks

Search methods with results

const s = "The quick brown fox";

s.includes("quick");        // true
s.includes("Quick");        // false (case-sensitive)
s.startsWith("The");        // true
s.startsWith("quick", 4);   // true  (from index 4)
s.endsWith("fox");          // true
s.endsWith("quick", 9);     // true  (as if length were 9)

s.indexOf("o");             // 12
s.indexOf("o", 13);         // 17   (search from 13)
s.lastIndexOf("o");         // 17
s.indexOf("cat");           // -1

s.search(/[A-Z]/);          // 0
s.match(/qu(\w+)/);         // ["quick", "ick", index: 4, ...]
s.toLowerCase().includes("the quick"); // true

Code Explained

Second argument to indexOf / includes — start position
endsWith(x, n) — treats the string as only n chars long
search — like indexOf but takes a regex
match — returns capture groups, or null

TypeScript

  • indexOf returns number; match returns RegExpMatchArray | null, so check for null first
  • Otherwise identical in TypeScript

⚠ Common Mistakes

  • if (s.indexOf(x)) fails when the match is at position 0; use includes or !== -1
  • Calling .length on the result of match without checking for null
  • Passing a regex to includes; it throws a TypeError

✓ Tips & Best Practices

  • Use includes for yes/no questions; indexOf only when you need the position
  • Use localeCompare(x, undefined, { sensitivity: "base" }) === 0 for accent-insensitive equality
  • Use matchAll to iterate every regex match with groups

Quick Summary

  • includes — contains?
  • startsWith / endsWith — prefix / suffix
  • indexOf — position or -1
  • match / search — regex searches
