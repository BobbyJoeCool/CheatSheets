Sheet 051

Array Methods — Mutating

push · pop · shift · unshift · splice · sort · reverse · fill

Overview

These methods change the original array in place. push/pop work at the end, shift/unshift at the start (slower on large arrays), and splice inserts or removes anywhere. sort and reverse also mutate and return the same array. ES2023 added non-mutating twins: toSorted, toReversed, toSpliced.

Notes

  • push/unshift return the new length
  • pop/shift return the removed item (or undefined)
  • splice returns an array of removed items
  • Mutating arrays held in React/Vue state won't trigger re-renders

Mutating methods with results

const a = [1, 2, 3];
a.push(4, 5);          // 5     a = [1,2,3,4,5]
a.pop();               // 5     a = [1,2,3,4]
a.unshift(0);          // 5     a = [0,1,2,3,4]
a.shift();             // 0     a = [1,2,3,4]

const b = ["a", "b", "c", "d"];
b.splice(1, 2);        // ["b","c"]  b = ["a","d"]
b.splice(1, 0, "x");   // []         b = ["a","x","d"]  (insert)
b.splice(-1, 1, "z");  // ["d"]      b = ["a","x","z"]  (replace)

[3, 1, 2].sort();      // [1, 2, 3]
[10, 9, 1].sort();     // [1, 10, 9]   (string sort!)
[10, 9, 1].sort((x, y) => x - y);  // [1, 9, 10]
[1, 2, 3].reverse();   // [3, 2, 1]
[0, 0, 0].fill(7, 1);  // [0, 7, 7]
[1, 2, 3, 4].copyWithin(0, 2);  // [3, 4, 3, 4]

Code Explained

splice(start, deleteCount, ...items) — remove and/or insert
Negative start counts from the end
sort() with no comparator sorts as strings
fill(value, start, end) — overwrite a range

TypeScript

  • None of these are allowed on a readonly T[] or ReadonlyArray<T>
  • pop()/shift() return T | undefined

⚠ Common Mistakes

  • Sorting numbers without a comparator
  • Calling sort() on a shared array and surprising other code that uses it
  • Using shift in a loop on huge arrays; it's O(n) each time

✓ Tips & Best Practices

  • Use the to… versions whenever you need to keep the original
  • Remove by value: arr.splice(arr.indexOf(x), 1) (check for -1 first)
  • Use push(...items) to append several values at once

Quick Summary

  • push / pop — end
  • unshift / shift — start
  • splice — anywhere
  • toSorted / toReversed — copies
