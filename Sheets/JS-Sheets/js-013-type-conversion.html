Sheet 013

Type Conversion & Coercion

String() · Number() · parseInt · parseFloat · unary + · implicit coercion · Boolean()

Overview

JavaScript converts types implicitly in many operators (+, ==, if), which is the source of most "wat" moments. Convert explicitly instead: String(), Number(), and Boolean() for general use, and parseInt/parseFloat when you need to read a number from the start of a string.

Notes

  • + with any string operand concatenates
  • -, *, / always convert to Number
  • Number("") is 0, a common surprise
  • parseInt stops at the first non-digit; Number rejects the whole string

Explicit vs implicit conversion

String(42);              // "42"
(42).toString(2);        // "101010" (base 2)
Number("42");            // 42
Number("42px");          // NaN
Number("");              // 0
Number(null);            // 0
Number(undefined);       // NaN
parseInt("42px", 10);    // 42
parseFloat("3.14abc");   // 3.14
+"7";                    // 7 (unary plus)

"5" + 3;                 // "53"  (concatenation)
"5" - 3;                 // 2     (numeric)
"5" * "2";               // 10
[] + {};                 // "[object Object]"
true + 1;                // 2

Code Explained

toString(radix) — number to string in any base
parseInt(s, 10) — always pass the radix
Unary + — shortest conversion, but less readable
+ prefers strings; other math operators prefer numbers

TypeScript

  • as number only tells the compiler; it never converts at runtime
  • TS flags many implicit coercions ("5" - 3 is a type error)

⚠ Common Mistakes

  • Reading form input and adding: input.value + 1 gives "51", not 6
  • Using parseInt without a radix on user input
  • Using parseInt(0.0000005), which returns 5 because the number stringifies as 5e-7

✓ Tips & Best Practices

  • Validate after converting: const n = Number(s); if (Number.isNaN(n)) …
  • Use Number() for strict parsing, parseFloat for "number with units"
  • Use === everywhere to avoid comparison coercion

Quick Summary

  • String() / Number() / Boolean() — explicit
  • parseInt(s, 10) — leading integer
  • + — concatenates with strings
  • Number("") — 0, watch out
