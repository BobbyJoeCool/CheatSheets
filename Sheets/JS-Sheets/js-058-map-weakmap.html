Map & WeakMap

Map · set / get / has / delete · insertion order · Map vs object · WeakMap · Map.groupBy

Overview

A Map is a key–value collection where keys can be any type (objects, functions, numbers) and insertion order is preserved. It has a proper size, is directly iterable, and is faster than plain objects for frequent adds and deletes. A WeakMap holds object keys weakly, letting them be garbage-collected.

Notes

  • Keys compare with SameValueZero: NaN works as a key
  • Object keys match by reference, not contents
  • map[key] = v sets an object property, not a Map entry
  • WeakMap isn't iterable and has no size

Map and WeakMap

const m = new Map();
m.set("a", 1).set(42, "num");       // set is chainable
const objKey = { id: 1 };
m.set(objKey, "object key");

m.get("a");                         // 1
m.get({ id: 1 });                   // undefined (different object)
m.get(objKey);                      // "object key"
m.has(42);                          // true
m.size;                             // 3
m.delete("a");                      // true

const scores = new Map([["ana", 9], ["bo", 7]]);
for (const [name, s] of scores) {}  // insertion order
[...scores.keys()];                 // ["ana", "bo"]
new Map(Object.entries({ x: 1 }));  // object → Map
Object.fromEntries(scores);         // Map → { ana: 9, bo: 7 }
Map.groupBy([1, 2, 3], n => n % 2 ? "odd" : "even");

const meta = new WeakMap();
meta.set(domNode, { clicks: 0 });   // freed with the node

Code Explained

set returns the Map, so calls chain
Object keys — must be the same reference to match
Convert with Object.entries and Object.fromEntries
WeakMap — attach data to objects without leaking memory

TypeScript

  • Type as Map<string, number>; get returns V | undefined
  • WeakMap<object, V> keys must be objects (or non-registered symbols)

⚠ Common Mistakes

  • Using bracket syntax (m["a"] = 1) on a Map; it bypasses the Map entirely
  • Expecting JSON.stringify(map) to work; it gives {}
  • Using a new object literal to look up an object key

✓ Tips & Best Practices

  • Use Map for caches, counters, and lookups keyed by objects or IDs
  • Count with m.set(k, (m.get(k) ?? 0) + 1)
  • Use WeakMap for per-object metadata like DOM node state

Quick Summary
