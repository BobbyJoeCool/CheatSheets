Sheet 005

Console Output

console.log · error · warn · table · dir · group · time / timeEnd · %s %o %c

Overview

The console object is the standard output tool in both browsers and Node. Beyond log, it has levels (info, warn, error), structured output (table, dir), grouping, counting, and timing. In Node, console.error and console.warn write to stderr; the rest write to stdout.

Notes

  • Multiple arguments are separated by spaces
  • Format specifiers work like printf: %s %d %o %c
  • %c applies CSS, browser only
  • process.stdout.write() prints without a trailing newline (Node)

Console methods with output

console.log("Total:", 42, true);     // Total: 42 true
console.log("%s is %d", "Ana", 30);  // Ana is 30
console.log(`Sum: ${2 + 3}`);        // Sum: 5
console.error("Disk full");          // stderr, red in browsers
console.warn("Deprecated");          // stderr, yellow
console.table([{ id: 1, n: "a" }, { id: 2, n: "b" }]);  // grid
console.dir(obj, { depth: null });   // full nested object (Node)
console.group("Load");               // indents following logs
console.log("step 1");               //   step 1
console.groupEnd();
console.count("hit");                // hit: 1
console.count("hit");                // hit: 2
console.time("q"); /* work */ console.timeEnd("q");  // q: 3.2ms
console.log("%cBig", "font-size:20px"); // styled (browser)

Code Explained

table — arrays of objects render as rows and columns
dir with depth: null — avoids Node's [Object] truncation
group / groupEnd — nest related output
time / timeEnd — labels must match exactly

TypeScript

  • Identical in TypeScript
  • console types come from lib.dom (browser) or @types/node

⚠ Common Mistakes

  • Using + to join objects: "user: " + obj prints user: [object Object]; pass it as a separate argument
  • Leaving noisy logs in production code; use a logger with levels
  • Expecting console.debug to show in Chrome; it's hidden unless Verbose is enabled

✓ Tips & Best Practices

  • console.log({ a, b }) labels values automatically
  • Use console.table for arrays of records; it's far easier to scan
  • Redirect only errors in Node: node app.js 2> errors.log

Quick Summary

  • console.log — stdout
  • console.error / warn — stderr
  • console.table — tabular view
  • console.time — quick timing
