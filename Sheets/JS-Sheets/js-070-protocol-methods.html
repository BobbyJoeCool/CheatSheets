Protocol Methods & Well-Known Symbols

toString · valueOf · toJSON · Symbol.toPrimitive · Symbol.iterator · Symbol.hasInstance · Symbol.dispose

Overview

JavaScript has no operator overloading, but objects can hook into language behavior with special methods. toString and valueOf control conversion, toJSON controls serialization, and well-known symbols like Symbol.iterator, Symbol.toPrimitive, and Symbol.dispose plug objects into for...of, type coercion, and using declarations.

Notes

  • Symbol.toPrimitive overrides both toString and valueOf
  • Its hint argument is "number", "string", or "default"
  • toJSON is called by JSON.stringify automatically
  • These are the closest JS equivalent to Python dunder methods

Hooking into the language

class Money {
  constructor(cents) { this.cents = cents; }
  [Symbol.toPrimitive](hint) {
    const d = this.cents / 100;
    return hint === "number" ? d : `$${d.toFixed(2)}`;
  }
  toJSON() { return { amount: this.cents / 100, currency: "USD" }; }
}
const m = new Money(1250);
`${m}`;                          // "$12.50"
+m;  m > 10;                     // 12.5, true (number hint)
JSON.stringify(m);               // '{"amount":12.5,"currency":"USD"}'

class Range {
  constructor(a, b) { this.a = a; this.b = b; }
  *[Symbol.iterator]() {
    for (let i = this.a; i <= this.b; i++) yield i;
  }
}
[...new Range(1, 3)];            // [1, 2, 3]

class TempFile { [Symbol.dispose]() { console.log("cleaned"); } }
{ using f = new TempFile(); }    // "cleaned" at block end

Code Explained

toPrimitive — one method for all conversions
toJSON — custom JSON shape
*[Symbol.iterator] — make instances iterable
Symbol.dispose + using — automatic cleanup

TypeScript

  • Implement interfaces to document the protocol: class Range implements Iterable<number>
  • using and Symbol.dispose are supported since TS 5.2 (Disposable interface)

⚠ Common Mistakes

  • Defining valueOf, then + with strings surprises you
  • Returning a string from toJSON when you meant an object
  • Using using without checking runtime support

✓ Tips & Best Practices

  • Prefer toPrimitive over separate toString/valueOf
  • Give classes a toString for readable logs
  • Use generator methods for Symbol.iterator; it's the shortest form

Quick Summary

  • toString / valueOf — conversion
  • toJSON — serialization
  • Symbol.iterator — iteration
  • Symbol.dispose — cleanup with using
