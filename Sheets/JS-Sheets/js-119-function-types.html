Function Types & Overloads

signatures · optional / default params · overloads · this parameter · void vs undefined · call signatures

Overview

Function types describe parameters and return values: (a: number, b: number) => number. Parameters can be optional (?), have defaults, or be rest arrays. Overloads declare several call signatures for one implementation. You can also type this explicitly and describe objects that are callable or constructable.

Notes

  • A void return type allows callbacks that return values (they're ignored)
  • Parameter names in function types are just labels
  • Overload signatures are visible; the implementation signature isn't
  • Optional params must come after required ones

Typing functions

function add(a: number, b: number): number { return a + b; }
const mul = (a: number, b: number): number => a * b;
type BinaryOp = (a: number, b: number) => number;
const sub: BinaryOp = (a, b) => a - b;          // params inferred

function greet(name: string, greeting = "Hi", punct?: string) {
  return `${greeting}, ${name}${punct ?? "!"}`;
}
function sum(...nums: number[]): number { return nums.reduce((t, n) => t + n, 0); }

function parse(input: string): number;          // overloads
function parse(input: string[]): number[];
function parse(input: string | string[]) {
  return Array.isArray(input) ? input.map(Number) : Number(input);
}
parse("4");            // number
parse(["1", "2"]);     // number[]

function onClick(this: HTMLButtonElement, e: MouseEvent) { this.disabled = true; }

type Logger = { (msg: string): void; level: "info" | "debug" };  // callable
type Ctor<T> = new (...args: any[]) => T;       // constructable

⚠ Common Mistakes

  • Writing overloads when a union parameter (or generic) would do
  • Marking a callback () => void and then relying on its return value
  • Putting optional parameters before required ones

✓ Tips & Best Practices

  • Prefer generics over overloads when the output type follows the input type
  • Use an options object type for functions with several optional params
  • Annotate return types on exported functions for clearer errors

Quick Summary
