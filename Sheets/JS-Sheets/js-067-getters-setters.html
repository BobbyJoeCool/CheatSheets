Sheet 067

Getters & Setters

get · set · computed properties · Object.defineProperty · validation in setters

Overview

Getters and setters look like plain properties to callers but run code when read or written. Use them for computed values, validation, and keeping a stable public API while the internal representation changes. Pair a setter with a private field to store the real value.

Notes

  • A getter without a setter makes a read-only property
  • Writing to a getter-only property is ignored (throws in strict mode)
  • Getters live on the prototype, so they're not own properties
  • Object.defineProperty creates them on existing objects

get, set, defineProperty

class Temperature {
  #celsius = 0;
  get celsius() { return this.#celsius; }
  set celsius(v) {
    if (v < -273.15) throw new RangeError("below absolute zero");
    this.#celsius = v;
  }
  get fahrenheit() { return this.#celsius * 9 / 5 + 32; }   // computed
  set fahrenheit(f) { this.celsius = (f - 32) * 5 / 9; }
}

const t = new Temperature();
t.celsius = 25;          // runs setter
t.fahrenheit;            // 77 (runs getter)
t.fahrenheit = 212;
t.celsius;               // 100

const user = { first: "Ana", last: "Diaz",
  get full() { return `${this.first} ${this.last}`; } };
user.full;               // "Ana Diaz"

Object.defineProperty(user, "id", { value: 7, writable: false });
user.id = 9;  user.id;   // 7

Code Explained

Setter validation keeps invalid values out
Computed getter — derived on every read
Object literals support get/set too
defineProperty — fine-grained control (writable, enumerable)

TypeScript

  • Getter and setter types can differ (TS 5.1+): accept string | number, return number
  • A getter with no setter is inferred as readonly

⚠ Common Mistakes

  • Setter that assigns to its own name (set x(v) { this.x = v }): infinite recursion
  • Expensive work in getters that look cheap to callers
  • Expecting getters to appear in JSON.stringify of class instances; they don't

✓ Tips & Best Practices

  • Store backing values in #private fields
  • Return copies from getters that expose internal arrays
  • Add a toJSON() method to include computed values in JSON

Quick Summary

  • get x() — computed read
  • set x(v) — validated write
  • getter only — read-only
  • defineProperty — descriptors
