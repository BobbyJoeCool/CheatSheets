Reading Files (Node)

fs/promises · readFile · encoding · readline line-by-line · createReadStream · sync vs async

Overview

Node reads files through the node:fs/promises module. readFile loads the whole file at once, which is simplest for small and medium files. For large files, read line by line with readline over a stream, or process chunks with createReadStream, so memory use stays flat.

Notes

  • Pass an encoding ("utf8") to get a string; otherwise you get a Buffer
  • Relative paths resolve from the current working directory, not the file
  • Sync versions (readFileSync) block the event loop; fine for CLI startup
  • Missing files throw an error with code: "ENOENT"

Reading files

import { readFile } from "node:fs/promises";
import { createReadStream } from "node:fs";
import { createInterface } from "node:readline";

const text = await readFile("notes.txt", "utf8");   // whole file
const lines = text.split(/\r?\n/);

const cfg = JSON.parse(await readFile("config.json", "utf8"));

const rl = createInterface({ input: createReadStream("big.log") });
for await (const line of rl) {                      // one line at a time
  if (line.includes("ERROR")) console.log(line);
}

try {
  await readFile("missing.txt", "utf8");
} catch (err) {
  if (err.code === "ENOENT") console.log("no such file");
  else throw err;
}

Code Explained

readFile(path, "utf8") — returns a string
/\r?\n/ — handles Windows and Unix line endings
readline + stream — constant memory for huge files
err.code — check ENOENT, EACCES, etc.

TypeScript

  • Install @types/node; readFile with an encoding is typed Promise<string>, without it Promise<Buffer>
  • Catch variables are unknown; narrow with err instanceof Error && "code" in err

⚠ Common Mistakes

  • Forgetting the encoding and printing a Buffer
  • Using relative paths that break when the script runs from another folder
  • Loading multi-GB files with readFile and running out of memory

✓ Tips & Best Practices

  • Resolve paths from the module: new URL("./data.txt", import.meta.url)
  • Use fs.existsSync sparingly; just try the read and handle ENOENT
  • Use readFile(path, { signal }) to make long reads cancelable

Quick Summary

  • readFile(p, "utf8") — whole file
  • readline — line by line
  • streams — large files
  • ENOENT — missing file
