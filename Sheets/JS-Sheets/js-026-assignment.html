Sheet 026

Assignment & Compound Assignment

= · += -= *= **= · ??= · ||= · &&= · chained assignment

Overview

= assigns and also returns the assigned value, which is why chains like a = b = 0 work. Compound operators (+=, *=, …) combine an operation with assignment. The logical assignment operators &&=, ||=, and ??= assign only when the condition holds, and they short-circuit.

Notes

  • Assignment is right-associative: a = b = 5 assigns b first
  • x ??= y only evaluates y if x is nullish
  • Compound assignment on const throws a TypeError
  • Destructuring assignment unpacks values (sheet 056)

Assignment operators

let x = 10;
x += 5;        // 15
x -= 3;        // 12
x *= 2;        // 24
x /= 4;        // 6
x %= 4;        // 2
x **= 3;       // 8

let s = "Hi";
s += "!";      // "Hi!"

let a, b;
a = b = 0;     // both 0

const opts = { retries: 0, name: "" };
opts.retries ??= 3;    // stays 0 (not nullish)
opts.name ||= "anon";  // "anon" ("" is falsy)
opts.timeout ??= 500;  // 500 (was undefined)
opts.debug &&= false;  // stays undefined (falsy, no assign)

[a, b] = [b, a];       // swap

Code Explained

x op= y — same as x = x op y
??= — assign only if null/undefined
||= — assign if falsy
&&= — assign only if truthy

TypeScript

  • Identical in TypeScript; compound assignments are type-checked (s -= 1 on a string is an error)
  • After x ??= 5, TS knows x is not nullish

Compound Operators

OpEquivalent
x += yx = x + y
x -= yx = x - y
x *= yx = x * y
x /= yx = x / y
x %= yx = x % y
x **= yx = x ** y
x <<= yx = x << y

Logical Assignment

OpAssigns whenEquivalent
x ??= yx is nullishx ?? (x = y)
x ||= yx is falsyx || (x = y)
x &&= yx is truthyx && (x = y)

⚠ Common Mistakes

  • Writing if (x = 5) instead of ===; it assigns and is always truthy
  • Using ||= for numbers where 0 is valid; use ??=
  • Chaining let a = b = 0, which creates b as an implicit global in sloppy mode

✓ Tips & Best Practices

  • Use ??= to lazily initialize: cache[key] ??= compute(key)
  • Destructuring swap [a, b] = [b, a] avoids a temp variable
  • Enable ESLint no-cond-assign to catch accidental = in conditions

Quick Summary

  • = — assigns and returns the value
  • += -= *= … — operate and assign
  • ??= — default if missing
  • ||= / &&= — conditional assignment
