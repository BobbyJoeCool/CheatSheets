Sheet 061

Iterators & Iterables

iterable protocol · Symbol.iterator · next() · done · iterator helpers · Iterator.from

Overview

An iterable is any object with a [Symbol.iterator]() method that returns an iterator: an object whose next() returns { value, done }. Arrays, strings, Maps, Sets, and NodeLists are all iterable, which is why for...of, spread, and destructuring work on them. ES2025 iterator helpers add lazy map, filter, take, and more.

Notes

  • Iterators are usually single-use
  • Iterator helpers are lazy: nothing runs until you consume
  • Iterator.from(x) wraps any iterable or iterator
  • Generators (sheet 062) are the easy way to write iterators

Iterator protocol and helpers

const it = [10, 20][Symbol.iterator]();
it.next();                         // { value: 10, done: false }
it.next();                         // { value: 20, done: false }
it.next();                         // { value: undefined, done: true }

const range = {
  from: 1, to: 3,
  [Symbol.iterator]() {
    let cur = this.from, last = this.to;
    return { next: () => cur <= last
      ? { value: cur++, done: false } : { value: undefined, done: true } };
  },
};
[...range];                        // [1, 2, 3]
for (const n of range) {}          // 1, 2, 3

const firstEvens = new Set([1, 2, 3, 4, 5, 6]).values()
  .filter(n => n % 2 === 0)
  .map(n => n * 10)
  .take(2)
  .toArray();                      // [20, 40]

Code Explained

next() — returns the next { value, done }
[Symbol.iterator]() — makes your object work with for...of
Helpers chain lazily on any iterator
toArray() — consumes the iterator into an array

TypeScript

  • Type with Iterable<T>, Iterator<T>, and IterableIterator<T>
  • Iterator helpers need lib ESNext (or ES2025) in tsconfig

⚠ Common Mistakes

  • Iterating the same iterator twice and getting nothing the second time
  • Calling iterator helpers on an array (arrays have their own map); call .values() first
  • Building infinite iterators and spreading them; it never ends

✓ Tips & Best Practices

  • Use iterator helpers to process large or infinite sequences without temporary arrays
  • Return this from [Symbol.iterator]() to make an iterator iterable too
  • Prefer generators over hand-written next() methods

Quick Summary

  • iterable — has [Symbol.iterator]
  • iterator — next() → { value, done }
  • for...of / spread — consume iterables
  • helpers — lazy map/filter/take
