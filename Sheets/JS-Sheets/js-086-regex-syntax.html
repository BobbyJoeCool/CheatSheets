Regular Expressions — Syntax

/pattern/flags · RegExp() · character classes · quantifiers · anchors · groups · flags g i m s u v y

Overview

A regular expression describes a text pattern. Write literals between slashes (/ab+c/i) or build them with new RegExp(string, flags) when the pattern is dynamic. Patterns combine literal characters, character classes, quantifiers, anchors, and groups. Flags change matching behavior.

Notes

  • Escape special characters with \: . * + ? ( ) [ ] { } ^ $ | \ /
  • Quantifiers are greedy by default; add ? for lazy
  • In new RegExp("…"), backslashes must be doubled
  • The g and y flags make regexes stateful via lastIndex

Pattern building blocks

/cat/;                    // literal "cat"
/c.t/;                    // . any char except newline: cat, cot
/[aeiou]/;                // one vowel
/[^0-9]/;                 // not a digit
/\d{3}-\d{4}/;            // 555-1234
/^\w+@\w+\.\w{2,}$/;     // simple email shape (anchored)
/colou?r/;                // optional u
/(ha)+/;                  // group repeated: ha, haha
/(?<year>\d{4})-(?<mon>\d{2})/;  // named groups
/<.+?>/;                  // lazy: shortest match
/\bcat\b/;               // whole word only
/cat|dog/;                // alternation

const word = "c++";
new RegExp(RegExp.escape(word), "g");  // escape user input (ES2025)
new RegExp("\\d+", "g");  // string form needs double backslashes

Code Explained

[…] — one character from a set
{n,m} — repeat between n and m times
^ $ — start and end of string (or line with m)
RegExp.escape — safely embed literal text

TypeScript

  • Identical in TypeScript; regex literals are typed RegExp
  • Set target to ES2018+ for named groups and lookbehind in compiled output

⚠ Common Mistakes

  • Forgetting to escape . in patterns like file extensions: use \.png$
  • Building a RegExp from user input without escaping it
  • Writing one giant regex to validate emails or HTML; use a parser or library

✓ Tips & Best Practices

  • Test patterns interactively on regex101.com with the JavaScript flavor
  • Use named groups instead of counting parentheses
  • Add the u (or v) flag when matching non-ASCII text
