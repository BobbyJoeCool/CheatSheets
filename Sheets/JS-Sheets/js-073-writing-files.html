Sheet 073

Writing & Appending Files (Node)

writeFile · appendFile · flags · mkdir recursive · rm · createWriteStream

Overview

writeFile creates or replaces a file; appendFile adds to the end. Both create the file if it's missing but not its parent folders, so call mkdir with recursive: true first. For many writes or large output, use createWriteStream. rm deletes files and folders.

Notes

  • writeFile overwrites without warning
  • Flag "wx" fails if the file already exists
  • Writes aren't atomic; write to a temp file and rename for safety
  • Call stream.end() to flush and close a write stream

Writing, appending, folders

import { writeFile, appendFile, mkdir, rm, rename } from "node:fs/promises";
import { createWriteStream } from "node:fs";

await mkdir("out/logs", { recursive: true });       // like mkdir -p
await writeFile("out/data.json", JSON.stringify(data, null, 2));
await appendFile("out/logs/app.log", `${new Date().toISOString()} start\n`);

await writeFile("out/once.txt", "x", { flag: "wx" }); // EEXIST if present

await writeFile("out/cfg.tmp", text);                // atomic replace
await rename("out/cfg.tmp", "out/cfg.json");

const out = createWriteStream("out/report.csv");
out.write("id,name\n");
for (const u of users) out.write(`${u.id},${u.name}\n`);
out.end();                                           // flush + close

await rm("out/old", { recursive: true, force: true }); // like rm -rf

Code Explained

recursive: true — creates all missing parent folders
flag: "wx" — exclusive create
Write temp then rename — readers never see half a file
force: true — no error if the path doesn't exist

TypeScript

  • Same API; data can be string, Buffer, or a typed array
  • Option objects are typed, so wrong flag names are caught

File Flags

FlagMeaning

aappend
wxwrite, fail if exists

⚠ Common Mistakes

  • Writing objects directly; you get [object Object] (stringify first)
  • Writing into a folder that doesn't exist (ENOENT)
  • Running rm with recursive: true on a path built from user input

✓ Tips & Best Practices

  • Always end lines with \n when appending logs
  • Use streams and pipeline for large or generated output
  • Check stat(p).isFile() before deleting unknown paths

Quick Summary

  • writeFile — create or replace
  • appendFile — add to end
  • mkdir -p — recursive: true
  • temp + rename — atomic writes
