Utility Types — Unions & Functions

Exclude · Extract · NonNullable · ReturnType · Parameters · Awaited · InstanceType

Overview

A second family of utility types works on unions and functions. Exclude and Extract filter union members, and NonNullable strips null and undefined. For functions, ReturnType and Parameters capture signatures, Awaited unwraps Promises, and InstanceType gets the instance type of a class.

Notes

  • Use these with typeof on functions and classes (values)
  • Awaited unwraps nested Promises recursively
  • NoInfer<T> (TS 5.4) blocks inference from a position
  • String helpers: Uppercase, Lowercase, Capitalize, Uncapitalize

Union and function utilities

type Status = "idle" | "loading" | "success" | "error";
type Busy = Extract<Status, "loading">;              // "loading"
type Settled = Exclude<Status, "idle" | "loading">;  // "success" | "error"
type Maybe = string | null | undefined;
type Sure = NonNullable<Maybe>;                      // string

async function fetchUser(id: number, opts?: { cache: boolean }) {
  return { id, name: "Ana" };
}
type FetchArgs = Parameters<typeof fetchUser>;
// [id: number, opts?: { cache: boolean }]
type FetchRet = ReturnType<typeof fetchUser>;  // Promise<{ id; name }>
type User = Awaited<FetchRet>;                 // { id: number; name: string }

class Logger { log(m: string) {} }
type L = InstanceType<typeof Logger>;          // Logger
type Args = ConstructorParameters<typeof Date>;

function wrap<F extends (...a: any[]) => any>(fn: F) {
  return (...args: Parameters<F>): ReturnType<F> => fn(...args);
}
type Event = `on${Capitalize<"click" | "focus">}`;   // "onClick" | "onFocus"

Code Explained

Extract / Exclude — keep or drop union members
Parameters — tuple of argument types
ReturnType + Awaited — the resolved result type
wrap — preserves the wrapped function's signature
Capitalize — string literal manipulation

⚠ Common Mistakes

  • Writing ReturnType<fetchUser> instead of ReturnType<typeof fetchUser>
  • Forgetting Awaited and getting Promise<User> where you wanted User
  • Using Exclude on object types; it filters unions, not properties (use Omit)

✓ Tips & Best Practices

  • Derive types from third-party functions you don't control with Parameters/ReturnType
  • Combine Awaited<ReturnType<typeof fn>> for async results
  • Use NonNullable after filtering arrays of optional values

Quick Summary

  • Exclude / Extract — filter unions
  • NonNullable — remove nullish
  • Parameters / ReturnType — function types
  • Awaited — unwrap Promises
