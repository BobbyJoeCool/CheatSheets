Fields, Static & Private Members

public fields · #private · static · static blocks · #x in obj

Overview

Class members come in three flavors. Instance fields belong to each object. Static members belong to the class itself and are shared. Private members start with # and are truly hidden: code outside the class body can't read them, and trying is a SyntaxError. Static blocks run once when the class is defined.

Notes

  • #private works for fields, methods, getters, and statics
  • #x in obj checks whether obj has that private field
  • Static members are inherited by subclasses
  • Private names don't show in Object.keys or JSON

Instance, static, private

class Counter {
  static #instances = 0;               // private static
  static MAX = 100;                    // public static
  #count = 0;                          // private instance field
  label;                               // public instance field

  static { console.log("ready"); }     // static block: runs once

  constructor(label) {
    this.label = label;
    Counter.#instances++;
  }
  #clamp(n) { return Math.min(n, Counter.MAX); }  // private method
  inc() { this.#count = this.#clamp(this.#count + 1); return this.#count; }
  static get created() { return Counter.#instances; }
  static isCounter(o) { return #count in o; }     // brand check
}

const c = new Counter("clicks");
c.inc();                               // 1
Counter.created;                       // 1
// c.#count;                           // SyntaxError
Counter.isCounter(c);                  // true

Code Explained

#field — only accessible inside the class body
static — accessed through the class name
static { } — one-time class setup
#x in o — safe check for real instances

TypeScript

  • TS private/protected are compile-time only; at runtime the field is public. #private is enforced at runtime
  • readonly blocks reassignment after construction

⚠ Common Mistakes

  • Using _underscore names and assuming they're private
  • Accessing static members through this in instance methods (it's the instance, not the class)
  • Proxies or structuredClone on objects with #private fields; they don't carry over

✓ Tips & Best Practices

  • Default to #private for anything callers shouldn't touch
  • Use static methods for alternate constructors
  • Use #x in obj instead of instanceof for brand checks across realms

Quick Summary

  • fields — per instance
  • static — on the class
  • #private — runtime-enforced privacy
  • static { } — class init block
