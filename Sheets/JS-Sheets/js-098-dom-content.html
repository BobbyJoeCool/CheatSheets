Sheet 098

Content, Attributes & Classes

textContent · innerHTML · getAttribute · dataset · classList · style

Overview

Once you have an element, you can change its text, HTML, attributes, classes, and inline styles. Use textContent for plain text (it's safe and fast). Use innerHTML only with trusted markup. classList manages classes without string juggling, and dataset reads and writes data-* attributes.

Notes

  • textContent escapes HTML automatically
  • innerHTML with user input is an XSS vulnerability
  • dataset converts data-user-id to dataset.userId
  • style sets inline styles only; computed values come from getComputedStyle

Changing content and attributes

const el = document.querySelector(".msg");

el.textContent = "Saved!";                 // plain text, safe
el.innerHTML = "<strong>Saved</strong>";   // parses HTML (trusted only)
el.textContent = userInput;                // always use for user data

el.classList.add("visible", "success");
el.classList.remove("error");
el.classList.toggle("open");               // add/remove
el.classList.toggle("dark", isDark);       // force on/off
el.classList.contains("open");             // true

const link = document.querySelector("a");
link.getAttribute("href");                 // "/docs"
link.setAttribute("target", "_blank");
link.removeAttribute("title");
link.href;                                 // full URL (property)

// <div data-user-id="42" data-role="admin">
el.dataset.userId;                         // "42" (string)
el.dataset.status = "active";              // adds data-status

el.style.setProperty("--accent", "teal");  // CSS variable
el.hidden = true;                          // hide via attribute
getComputedStyle(el).color;                // "rgb(0, 128, 128)"

Code Explained

textContent vs innerHTML — text vs parsed markup
toggle(cls, force) — boolean decides add or remove
Properties (link.href) return resolved values; attributes return raw strings
CSS variables via style.setProperty

TypeScript

  • dataset values are typed string | undefined
  • Element type matters: .href exists on HTMLAnchorElement, not plain Element

⚠ Common Mistakes

  • Inserting user input with innerHTML
  • Setting el.className = "x" and wiping out existing classes
  • Setting many styles in JS instead of toggling a CSS class

✓ Tips & Best Practices

  • Toggle classes and let CSS handle the visuals
  • Use setHTML / a sanitizer (DOMPurify) if you must insert user HTML
  • Batch DOM reads and writes to avoid layout thrashing

Quick Summary

  • textContent — safe text
  • classList — manage classes
  • get/setAttribute — raw attributes
  • dataset — data-* values
