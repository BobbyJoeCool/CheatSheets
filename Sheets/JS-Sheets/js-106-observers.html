Sheet 106

Observers & Animation Frames

IntersectionObserver · MutationObserver · ResizeObserver · requestAnimationFrame

Overview

Observers let the browser tell you when something changes instead of you polling for it. IntersectionObserver reports when elements enter or leave the viewport (lazy loading, infinite scroll, scroll animations). ResizeObserver reports element size changes, and MutationObserver reports DOM changes. requestAnimationFrame schedules work right before the next paint.

Notes

  • Observers batch notifications into an array of entries
  • Call unobserve(el) or disconnect() when done
  • Observers are far cheaper than scroll / resize listeners
  • rAF callbacks pause in background tabs

Observers and animation frames

const io = new IntersectionObserver((entries) => {
  for (const e of entries) {
    if (!e.isIntersecting) continue;
    e.target.src = e.target.dataset.src;       // lazy-load image
    io.unobserve(e.target);
  }
}, { rootMargin: "200px", threshold: 0.1 });
document.querySelectorAll("img[data-src]").forEach(img => io.observe(img));

const ro = new ResizeObserver(([entry]) => {
  const { width } = entry.contentRect;
  entry.target.classList.toggle("compact", width < 400);
});
ro.observe(sidebar);

const mo = new MutationObserver(muts => console.log(muts.length, "changes"));
mo.observe(list, { childList: true, subtree: true, attributes: true });
mo.disconnect();

function frame(time) {
  ball.style.transform = `translateX(${(time / 10) % 300}px)`;
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);

Code Explained

isIntersecting — element is in view
rootMargin — start loading before it's visible
contentRect — the element's new size
rAF — one call per frame, synced with the display

TypeScript

  • Entry types are provided: IntersectionObserverEntry, ResizeObserverEntry, MutationRecord
  • e.target is Element; cast to HTMLImageElement to set src

⚠ Common Mistakes

  • Never disconnecting observers on removed elements
  • Changing an element's size inside its own ResizeObserver callback (loop warnings)
  • Animating with setInterval instead of requestAnimationFrame

✓ Tips & Best Practices

  • Use loading="lazy" on images first; use IntersectionObserver for custom cases
  • Prefer CSS container queries over ResizeObserver for pure styling
  • Use the time argument in rAF for frame-rate-independent animation

Quick Summary

  • IntersectionObserver — visibility
  • ResizeObserver — size
  • MutationObserver — DOM changes
  • requestAnimationFrame — per-frame work
