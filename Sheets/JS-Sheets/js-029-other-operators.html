Sheet 029

Other Operators & Precedence

typeof · delete · in · void · comma · instanceof · precedence table

Overview

A few operators don't fit elsewhere: typeof and instanceof check types, in checks whether a property exists, delete removes a property, void evaluates an expression and returns undefined, and the comma operator evaluates several expressions and returns the last. The precedence table explains why some expressions parse in surprising ways.

Notes

  • in checks the prototype chain; Object.hasOwn checks own props only
  • delete returns true even if the property didn't exist
  • delete on an array leaves a hole; use splice
  • The comma operator is mostly seen in for loop headers

Miscellaneous operators

const car = { make: "Ford", year: 2020 };

"make" in car;                // true
"toString" in car;            // true  (inherited)
Object.hasOwn(car, "toString"); // false

delete car.year;              // true; car is { make: "Ford" }
const arr = [1, 2, 3];
delete arr[1];                // [1, empty, 3]  (hole!)

void 0;                       // undefined
typeof car;                   // "object"
car instanceof Object;        // true

for (let i = 0, j = 10; i < j; i++, j--) {}  // comma in for
const r = (1, 2, 3);          // 3
!("x" in car);                // parentheses needed

Code Explained

in — key exists anywhere in the chain
delete — removes a property; can't delete variables
void — forces undefined
Comma — evaluates left to right, keeps the last value

TypeScript

  • in narrows union types: if ("swim" in animal)
  • delete is only allowed on optional properties under strict

⚠ Common Mistakes

  • Writing !key in obj, which tests false in obj; use !(key in obj)
  • Using delete on arrays and leaving holes
  • Using in when inherited properties should not count; use Object.hasOwn

✓ Tips & Best Practices

  • Prefer Object.hasOwn(o, k) over o.hasOwnProperty(k)
  • To remove a key immutably, use rest destructuring instead of delete
  • When in doubt about precedence, add parentheses

Quick Summary

  • in — property exists (incl. inherited)
  • delete — remove a property
  • void — undefined
  • precedence — parenthesize when unsure
