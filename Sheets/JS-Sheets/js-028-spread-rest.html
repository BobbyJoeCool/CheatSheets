Sheet 028

Spread & Rest

... in arrays · objects · calls · rest params · rest in destructuring

Overview

The ... syntax has two jobs. As spread, it expands an iterable or object into individual elements: in array literals, object literals, and function calls. As rest, it gathers remaining items into an array or object: in parameters and destructuring patterns. Same syntax; position decides which.

Notes

  • Spread makes shallow copies; nested objects are shared
  • Object spread copies own enumerable properties; later keys win
  • Rest must be the last element in a pattern
  • Strings, Sets, and Maps are iterable, so they spread into arrays

Spread and rest

const a = [1, 2], b = [3, 4];
[...a, ...b];                      // [1, 2, 3, 4]
[..."hi"];                         // ["h", "i"]
[...new Set([1, 1, 2])];           // [1, 2]
Math.max(...a);                    // 2

const base = { x: 1, y: 2 };
({ ...base, y: 9 });               // { x: 1, y: 9 }
({ y: 9, ...base });               // { y: 2, x: 1 } (base wins)

function sum(...nums) {            // rest parameter
  return nums.reduce((t, n) => t + n, 0);
}
sum(1, 2, 3);                      // 6

const [first, ...others] = [1, 2, 3];  // 1, [2, 3]
const { id, ...rest } = { id: 7, n: "a", t: 1 }; // 7, { n, t }

Code Explained

Spread in [] — copy or concatenate arrays
Spread in {} — copy or merge objects; order sets priority
Rest in params — collects extra arguments as a real array
Rest in destructuring — "everything else"

TypeScript

  • Spreading objects merges their types: { ...a, ...b } is typed as the combination
  • Rest parameters can be typed as tuples: (...args: [string, number])

⚠ Common Mistakes

  • Treating a spread copy as a deep copy; nested objects are still shared
  • Putting defaults after options: { ...opts, ...defaults } overwrites the user's values
  • Spreading huge arrays into function calls; engines limit argument counts

✓ Tips & Best Practices

  • Use structuredClone when you need a deep copy (sheet 057)
  • Use rest destructuring to remove a property without mutating
  • Prefer rest parameters over the old arguments object

Quick Summary

  • spread — expand items
  • rest — collect items
  • shallow — nested values shared
  • order matters — later keys win
