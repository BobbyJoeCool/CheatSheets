⚠ Common Mistakes

  • as casts to silence errors — they hide real bugs; narrow instead
  • any spreading through a codebase — use unknown and narrow
  • Forgetting res.ok — fetch only rejects on network errors, not 4xx / 5xx

✓ Tips & Best Practices

  • Turn on "strict": true from the first commit
  • Model state as discriminated unions with a kind field
  • Use event delegation for lists instead of a listener per item
