Sheet 009

BigInt

BigInt · 10n · BigInt() · mixing with Number · typeof "bigint" · JSON limits

Overview

BigInt represents integers of any size, exactly. Create one with an n suffix (10n) or BigInt(). BigInts support the usual arithmetic, but you can't mix them with Numbers in one expression, division truncates toward zero, and Math functions don't accept them.

Notes

  • typeof 10n is "bigint"
  • 10n == 10 is true; 10n === 10 is false
  • JSON.stringify throws on BigInt by default
  • No decimals: 5n / 2n is 2n

Creating and using BigInt

const big = 9007199254740993n;      // exact, beyond MAX_SAFE_INTEGER
const fromNum = BigInt(42);         // 42n
const fromStr = BigInt("12345678901234567890"); // works

2n ** 64n;                          // 18446744073709551616n
7n / 2n;                            // 3n  (truncates)
-7n / 2n;                           // -3n
7n % 2n;                            // 1n

// 1n + 1;                          // TypeError: Cannot mix BigInt
1n + BigInt(1);                     // 2n
Number(10n) + 1;                    // 11 (may lose precision)

10n > 5;                            // true (comparison is OK)
typeof 10n;                         // "bigint"
JSON.stringify({ id: 1n.toString() }); // '{"id":"1"}'

Code Explained

n suffix — BigInt literal
BigInt("...") — parse huge integers from strings safely
Mixing types throws; convert one side explicitly
Comparisons across types are allowed

TypeScript

  • Use the bigint type: let id: bigint = 1n
  • BigInt literals need "target": "ES2020" or later in tsconfig

⚠ Common Mistakes

  • Passing a BigInt to Math.max or Math.round; they only accept Numbers
  • Converting big values back with Number() and silently losing digits
  • Sending BigInts to JSON.stringify without a replacer; it throws

✓ Tips & Best Practices

  • Store database IDs from 64-bit columns as BigInt or strings, never Number
  • Use a JSON replacer: (k, v) => typeof v === "bigint" ? v.toString() : v
  • Stick to Number for ordinary math; BigInt is slower

Quick Summary

  • 10n — BigInt literal
  • BigInt(x) — convert
  • no mixing — convert one side
  • / truncates — integers only
