Sheet 060

Sorting & Searching

sort() string default · comparators · localeCompare · stability · toSorted · binary search

Overview

sort() sorts in place and, without a comparator, converts items to strings and sorts by UTF-16 order, which breaks numbers. Pass a comparator (a, b) => number: negative puts a first, positive puts b first. Sorting is stable since ES2019. For a sorted copy, use toSorted().

Notes

  • a - b sorts numbers ascending; b - a descending
  • localeCompare sorts strings like a human would
  • Stable sort keeps the original order for equal items
  • Binary search only works on sorted data

Sorting and searching

[10, 1, 5].sort();                         // [1, 10, 5]  wrong
[10, 1, 5].sort((a, b) => a - b);          // [1, 5, 10]
[10, 1, 5].toSorted((a, b) => b - a);      // [10, 5, 1] (copy)

["b", "a", "C"].sort();                    // ["C", "a", "b"]
["b", "a", "C"].sort((a, b) => a.localeCompare(b)); // ["a", "b", "C"]
["item10", "item2"].sort(new Intl.Collator(undefined,
  { numeric: true }).compare);             // ["item2", "item10"]

const people = [{ n: "Bo", age: 30 }, { n: "Ana", age: 30 }, { n: "Cy", age: 25 }];
people.toSorted((a, b) => a.age - b.age || a.n.localeCompare(b.n));
// Cy 25, Ana 30, Bo 30   (age, then name)

function binarySearch(arr, x) {
  let lo = 0, hi = arr.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (arr[mid] === x) return mid;
    arr[mid] < x ? (lo = mid + 1) : (hi = mid - 1);
  }
  return -1;
}

Code Explained

Comparator sign decides the order
Intl.Collator({ numeric: true }) — natural sort for "item2" < "item10"
|| chains tie-breakers: first key, then second
Binary search — O(log n) on sorted arrays

TypeScript

  • Comparator type is (a: T, b: T) => number; returning a boolean is a type error
  • toSorted needs lib ES2023 or later

⚠ Common Mistakes

  • Sorting numbers with no comparator
  • Returning a > b (a boolean) from a comparator; it must return a number
  • Sorting a shared array in place and changing someone else's data

✓ Tips & Best Practices

  • Use toSorted unless you specifically want in-place mutation
  • Create one Intl.Collator and reuse its compare for big sorts
  • Sort by several keys with || between comparisons

Quick Summary

  • sort(fn) — in place, comparator required
  • toSorted(fn) — sorted copy
  • localeCompare — string order
  • binary search — sorted data only
