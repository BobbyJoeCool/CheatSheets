Comments & JSDoc

// · /* */ · /** */ · @param · @returns · @type · @deprecated

Overview

JavaScript has two comment forms: // for a single line and /* */ for blocks. A block that starts with / is a JSDoc** comment; editors read it to show hover documentation, parameter hints, and even type information. Good comments explain *why*, not *what*.

Notes

  • Block comments cannot be nested
  • /** */ must sit directly above the declaration it documents
  • JSDoc tags start with @
  • #!/usr/bin/env node on line 1 is a hashbang, not a comment, but is allowed

Comment forms and JSDoc

// Single-line comment
const rate = 0.07; // trailing comment

/* Block comment
   spanning lines */

/**
 * Calculates the price including tax.
 * @param {number} price - Base price in dollars
 * @param {number} [rate=0.07] - Tax rate (optional)
 * @returns {number} Price with tax, rounded to cents
 * @example withTax(10) // 10.7
 * @deprecated Use priceWithTax() instead
 */
function withTax(price, rate = 0.07) {
  return Math.round(price * (1 + rate) * 100) / 100;
}

Code Explained

@param {type} name — type and description for one parameter
[rate=0.07] — brackets mark an optional param with a default
@returns — return type and meaning
@deprecated — editors strike through the name at call sites

TypeScript

  • Types move into syntax (price: number), so JSDoc keeps only descriptions
  • Add // @ts-check at the top of a .js file to type-check it using JSDoc types

⚠ Common Mistakes

  • Commenting what the code obviously does (i++ // increment i)
  • Letting comments go stale after the code changes; wrong comments are worse than none
  • Writing /* instead of /**, so editors ignore the documentation

✓ Tips & Best Practices

  • Use JSDoc on exported functions; editors show it on hover everywhere they're used
  • Write TODO(name): with an owner so it can be tracked
  • Use @example to show a one-line call and its result

Quick Summary

  • // — single line
  • /* */ — block
  • /** */ — JSDoc, read by editors
  • @param / @returns — document functions
