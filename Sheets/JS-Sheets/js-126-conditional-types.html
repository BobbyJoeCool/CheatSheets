Conditional Types

T extends U ? X : Y · infer · distributive conditionals · filtering with never

Overview

A conditional type chooses a type based on a test: T extends U ? X : Y. Inside the true branch, infer declares a type variable to extract part of a type, like a Promise's value or a function's first argument. When T is a naked type parameter and receives a union, the condition is distributed over each member.

Notes

  • Conditional types are how ReturnType, Awaited, Exclude are built
  • Wrap in brackets ([T] extends [U]) to stop distribution
  • Returning never from a branch removes that union member
  • Keep them small; deeply recursive types slow the compiler

Conditional types and infer

type IsString<T> = T extends string ? "yes" : "no";
type A = IsString<"hi">;                 // "yes"
type B = IsString<42>;                   // "no"

type ElementOf<T> = T extends (infer E)[] ? E : T;
type C = ElementOf<number[]>;            // number
type D = ElementOf<string>;              // string

type UnwrapPromise<T> = T extends Promise<infer V> ? V : T;
type E = UnwrapPromise<Promise<Date>>;   // Date

type FirstArg<F> = F extends (first: infer A, ...rest: any[]) => any ? A : never;
type F1 = FirstArg<(id: number, x: string) => void>;  // number

type MyExclude<T, U> = T extends U ? never : T;       // distributes
type G = MyExclude<"a" | "b" | "c", "a">;             // "b" | "c"

type ToArray<T> = T extends any ? T[] : never;
type H = ToArray<string | number>;       // string[] | number[]
type ToArrayND<T> = [T] extends [any] ? T[] : never;
type I = ToArrayND<string | number>;     // (string | number)[]

Code Explained

extends in a type — "is assignable to"
infer E — capture a piece of the matched type
never in a branch — filters members out
Distribution — applied to each union member
[T] — disable distribution

⚠ Common Mistakes

  • Being surprised by distribution over unions; bracket the check to avoid it
  • Writing complex conditional types where an overload or simple union is clearer
  • Using infer outside an extends clause (not allowed)

✓ Tips & Best Practices

  • Test types with small type T1 = … lines and hover to verify
  • Name helper types clearly; they become documentation
  • Check type-fest before writing your own advanced utilities

Quick Summary

  • T extends U ? X : Y — type if/else
  • infer — extract part of a type
  • distributive — over unions
  • never — remove members
