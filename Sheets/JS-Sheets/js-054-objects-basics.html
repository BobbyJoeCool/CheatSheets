Objects — Basics

{} · dot vs bracket · shorthand · computed keys · methods · delete · in / Object.hasOwn

Overview

Objects are collections of key–value pairs. Keys are strings or symbols; values can be anything, including functions (methods). Access properties with dot notation for fixed names and bracket notation for dynamic or unusual keys. Modern literals support shorthand properties, shorthand methods, and computed keys.

Notes

  • Number keys are converted to strings: o[1] is o["1"]
  • Missing properties read as undefined, not an error
  • Objects are passed and compared by reference
  • Key order: integer-like keys ascending, then strings in insertion order

Object literal features

const name = "Ana", field = "role";

const user = {
  name,                        // shorthand: name: name
  age: 30,
  "first-name": "Ana",         // quoted key
  [field]: "admin",            // computed key → role
  greet() { return `Hi ${this.name}`; },  // method shorthand
};

user.age;                      // 30
user["first-name"];            // "Ana"
user[field];                   // "admin"
user.email;                    // undefined

user.email = "a@b.co";         // add
user.age += 1;                 // update
delete user["first-name"];     // remove

"age" in user;                 // true
Object.hasOwn(user, "greet");  // true

Code Explained

Shorthand name — uses a variable of the same name
[field] — key computed at runtime
Brackets — for variables and keys with dashes or spaces
in / Object.hasOwn — check existence

TypeScript

  • Describe shapes with type or interface (sheet 115); adding unknown keys becomes an error
  • Use Record<string, T> for dictionary-style objects

⚠ Common Mistakes

  • Using o.k when the key is in a variable k; that reads a property literally named "k"
  • Comparing objects with === expecting a deep comparison
  • Using objects as maps with user-supplied keys like __proto__; use Map

✓ Tips & Best Practices

  • Use shorthand properties and methods; they're cleaner and standard
  • Use Map when keys are dynamic, non-string, or added and removed often
  • Freeze config objects with Object.freeze

Quick Summary
