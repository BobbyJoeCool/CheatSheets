Sheet 055

Object Static Methods

Object.keys · values · entries · fromEntries · assign · freeze · groupBy

Overview

The Object constructor has static methods for working with objects as data. keys, values, and entries turn an object into arrays; fromEntries turns pairs back into an object. assign copies properties, freeze/seal lock objects down, and groupBy builds grouped objects from arrays.

Notes

  • These only include own, enumerable, string keys
  • freeze is shallow: nested objects can still change
  • Object.groupBy returns a null-prototype object (ES2024)
  • entries + map + fromEntries transforms objects

Object static methods

const prices = { apple: 1.2, pear: 0.8, fig: 2 };

Object.keys(prices);         // ["apple", "pear", "fig"]
Object.values(prices);       // [1.2, 0.8, 2]
Object.entries(prices);      // [["apple",1.2], ["pear",0.8], ["fig",2]]

const doubled = Object.fromEntries(
  Object.entries(prices).map(([k, v]) => [k, v * 2])
);                           // { apple: 2.4, pear: 1.6, fig: 4 }

Object.assign({}, prices, { fig: 3 });  // copy + override
const cfg = Object.freeze({ port: 80 });
cfg.port = 1;                // ignored (throws in strict mode)
Object.isFrozen(cfg);        // true

const people = [{ n: "Ana", t: "a" }, { n: "Bo", t: "b" }, { n: "Cy", t: "a" }];
Object.groupBy(people, p => p.t);
// { a: [{n:"Ana"…}, {n:"Cy"…}], b: [{n:"Bo"…}] }

Code Explained

entries → transform → fromEntries — map over an object
assign(target, ...sources) — mutates and returns target
freeze — no adds, deletes, or changes (top level)
groupBy(arr, fn) — key returned by fn becomes a group

TypeScript

  • Object.keys returns string[], not (keyof T)[], because objects may have extra keys at runtime
  • Object.entries(o) types values but keys stay string

⚠ Common Mistakes

  • Assuming freeze is deep; nested objects stay mutable
  • Using Object.assign(target, …) and accidentally mutating the target
  • Expecting symbol or inherited keys in Object.keys

✓ Tips & Best Practices

  • Use spread { ...a, ...b } instead of Object.assign({}, a, b)
  • Use Map.groupBy when group keys aren't strings
  • Write a small deepFreeze helper for config constants

Quick Summary

  • keys / values / entries — to arrays
  • fromEntries — back to object
  • freeze — shallow lock
  • groupBy — group array items
