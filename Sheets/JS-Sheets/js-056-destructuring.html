Sheet 056

Destructuring

array & object patterns · defaults · renaming · nested · swapping · in parameters

Overview

Destructuring unpacks values from arrays (by position) and objects (by key) into variables in one statement. It supports defaults, renaming, nesting, and rest. It's most useful in function parameters, loop heads, and when working with returned arrays or objects.

Notes

  • Defaults apply only when the value is undefined
  • Destructuring null or undefined throws a TypeError
  • Skip array items with empty commas: [, second]
  • Assignment without const needs parentheses for objects: ({ a } = o)

Array and object destructuring

const [a, b] = [10, 20];               // a=10, b=20
const [first, , third] = [1, 2, 3];    // skip one
const [x = 5, y = 7] = [1];            // x=1, y=7
const [head, ...tail] = [1, 2, 3];     // 1, [2, 3]
let p = 1, q = 2; [p, q] = [q, p];     // swap

const user = { id: 7, name: "Ana", address: { city: "Rome" } };
const { id, name } = user;             // 7, "Ana"
const { name: userName } = user;       // rename → "Ana"
const { role = "guest" } = user;       // default
const { address: { city } } = user;    // nested → "Rome"
const { id: _, ...rest } = user;       // rest → { name, address }

function show({ name, age = 0 } = {}) { return `${name} ${age}`; }
for (const [key, value] of Object.entries(user)) {}
const { data: { items = [] } = {} } = response;  // safe nested

Code Explained

Arrays — by position; objects — by key name
name: userName — read name, store as userName
Nested patterns follow the shape of the data
= {} defaults keep nested destructuring from throwing

TypeScript

  • Annotate the whole pattern: const { id, name }: User = user
  • In parameters: function show({ name, age = 0 }: Props)

Array Patterns

PatternFrom [1, 2, 3]
[a]a = 1
[, b]b = 2
[a, ...r]r = [2, 3]
[a, b, c, d = 0]d = 0

Object Patterns

PatternDoes
{ k }read k
{ k: v }rename to v
{ k = 1 }default
{ k: { j } }nested
{ k, ...r }rest of keys

⚠ Common Mistakes

  • Destructuring a value that can be null; add a default (= {}) or check first
  • Starting a line with { a } = obj without const or parentheses (parsed as a block)
  • Confusing rename and default: { a: b = 1 } renames to b with default 1

✓ Tips & Best Practices

  • Destructure options in function parameters for named arguments
  • Keep nested destructuring to two levels; deeper gets hard to read
  • Use rest to omit fields: const { password, ...safe } = user

Quick Summary

  • [a, b] = arr — by position
  • { a, b } = obj — by key
  • { a: x = 1 } — rename + default
  • ...rest — the remainder
