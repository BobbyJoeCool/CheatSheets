Sheet 031

Ternary & Conditional Expressions

? : · nested ternaries · && short-circuit · ?? defaults · expression vs statement

Overview

The ternary operator cond ? a : b is an *expression*, so it produces a value you can assign, return, or embed in a template. Use it for simple either/or choices. Short-circuit operators &&, ||, and ?? are the other common conditional expressions.

Notes

  • Ternaries can be nested, but readability drops fast
  • Format nested ternaries one condition per line
  • cond && value returns false/falsy when cond fails
  • In JSX, && and ternaries are the standard conditional rendering tools

Conditional expressions

const age = 20;
const label = age >= 18 ? "adult" : "minor";       // "adult"
const msg = `You have ${n} item${n === 1 ? "" : "s"}`;

const size =
  w > 1200 ? "xl" :
  w > 800  ? "lg" :
  w > 500  ? "md" : "sm";                          // flat chain

return isAdmin ? renderAdmin() : renderUser();

const name = user?.name ?? "Guest";                // null fallback
const title = draft.title || "Untitled";           // falsy fallback
const badge = count > 0 && `(${count})`;           // false or string

// Statement form: prefer if/else for side effects
isValid ? save() : showError();   // works, but if/else is clearer

Code Explained

? : — the whole expression evaluates to one branch
Flat chained ternary — readable when each line is one rule
&& returns false when the condition fails, so watch what you render
Use if/else when branches *do* things rather than produce values

TypeScript

  • The result type is the union of both branches: cond ? 1 : "a" is 1 | "a"
  • Ternaries also exist at type level as conditional types (sheet 126)

⚠ Common Mistakes

  • Deeply nested ternaries on one line; nobody can read them
  • count && <Badge/> renders 0 when count is 0; use count > 0 &&
  • Using a ternary purely for side effects

✓ Tips & Best Practices

  • If a ternary needs a comment, rewrite it as if/else
  • Let Prettier format nested ternaries so each condition gets a line
  • Replace value-mapping chains with an object or Map lookup

Quick Summary

  • c ? a : b — expression, returns a value
  • nested — one rule per line
  • && / || / ?? — short-circuit choices
  • side effects — use if/else
