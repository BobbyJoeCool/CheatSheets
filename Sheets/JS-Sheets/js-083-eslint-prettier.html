Sheet 083

ESLint & Prettier

eslint.config.js · flat config · rules · --fix · Prettier · .prettierrc · editor integration

Overview

ESLint finds bugs and enforces conventions; Prettier formats code so style debates disappear. Modern ESLint uses a flat config file, eslint.config.js, which exports an array of config objects. Let Prettier own formatting and ESLint own correctness, and don't let them fight.

Notes

  • Flat config replaced .eslintrc (ESLint 9+)
  • eslint --fix auto-fixes what it can
  • eslint-config-prettier turns off style rules that conflict with Prettier
  • Most editors run both on save

eslint.config.js and Prettier

// eslint.config.js
import js from "@eslint/js";
import globals from "globals";
import prettier from "eslint-config-prettier";

export default [
  js.configs.recommended,
  { languageOptions: { globals: { ...globals.browser, ...globals.node } } },
  { rules: {
      "no-unused-vars": ["warn", { argsIgnorePattern: "^_" }],
      eqeqeq: ["error", "always", { null: "ignore" }],
      "prefer-const": "error",
  } },
  { ignores: ["dist/", "coverage/"] },
  prettier,                         // last: disables style conflicts
];

// .prettierrc
{ "semi": true, "singleQuote": false, "printWidth": 90 }

$ npx eslint . --fix
$ npx prettier . --write

Code Explained

Config is an array; later entries override earlier ones
globals — tells ESLint which environment variables exist
Rule level: "off", "warn", "error"
ignores object — files to skip

TypeScript

  • Use typescript-eslint: tseslint.configs.recommended and its type-aware recommendedTypeChecked
  • Type-aware rules like no-floating-promises catch unawaited Promises

Commands

CommandDoes

⚠ Common Mistakes

  • Enabling ESLint stylistic rules and Prettier together, causing fix loops
  • Disabling rules inline everywhere instead of fixing the config
  • Leaving .eslintrc files around that flat config ignores

✓ Tips & Best Practices

  • Run both in a pre-commit hook (lint-staged + husky)
  • Add "lint": "eslint ." and "format": "prettier . --write" scripts
  • Fail CI on eslint . and prettier --check

Quick Summary

  • ESLint — correctness
  • Prettier — formatting
  • eslint.config.js — flat config array
  • eslint-config-prettier — no conflicts
