⚠ Common Mistakes

  • == coercion surprises — use ===
  • forEach with async callbacks doesn't wait; use for…of or Promise.all
  • sort() without a compare function sorts numbers as strings

✓ Tips & Best Practices

  • Default to const; use let only when reassigning
  • Prefer copy-returning array methods (toSorted, with) over mutation
  • Use ?? instead of || when 0 or "" are valid values

Quick Summary

  • const/let, ===, template literals
  • map / filter / reduce and destructuring
  • ?. and ?? for missing values
  • async / await + Promise.all
