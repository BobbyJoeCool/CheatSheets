Rest Parameters & Spread Arguments

...args · spread into calls · arguments vs rest · Math.max(...arr)

Overview

A rest parameter (...args) collects any number of remaining arguments into a real array. Spread does the opposite at the call site, expanding an array into separate arguments. Together they replace the old arguments object, which is array-like but not an array and doesn't exist in arrow functions.

Notes

  • Only one rest parameter, and it must be last
  • Rest gives [] when no extra arguments are passed
  • arguments still exists in regular functions, but avoid it
  • Spread works with any iterable: Sets, strings, Maps

Rest parameters and spread arguments

function sum(...nums) {
  return nums.reduce((t, n) => t + n, 0);
}
sum();                     // 0
sum(1, 2, 3);              // 6

function tag(label, ...items) {
  return `${label}: ${items.join(", ")}`;
}
tag("Fruit", "apple", "fig");   // "Fruit: apple, fig"

const nums = [5, 1, 9];
Math.max(...nums);              // 9
sum(...nums, 10);               // 25
new Date(...[2026, 0, 15]);     // spread into constructor

function old() {
  return Array.from(arguments); // legacy array-like
}
const wrap = (fn) => (...args) => fn(...args);  // forward all args

Code Explained

...nums — always an array, possibly empty
Leading named params take the first arguments
Spread in calls — pass array items as separate arguments
(...args) => fn(...args) — forward everything unchanged

TypeScript

  • Type rest as an array: (...nums: number[]), or a tuple for fixed shapes: (...args: [string, number])
  • Parameters<typeof fn> captures another function's argument list (sheet 125)

⚠ Common Mistakes

  • Placing a parameter after rest: (...a, b) is a SyntaxError
  • Using arguments inside an arrow function; it refers to the outer function's arguments
  • Spreading very large arrays into calls; it can exceed the engine's argument limit

✓ Tips & Best Practices

  • Use arr.reduce instead of Math.max(...arr) for huge arrays
  • Combine rest with destructuring: ([first, ...others]) => …
  • Prefer explicit parameters when the count is fixed

Quick Summary

  • ...args — collect extras into array
  • f(...arr) — expand into arguments
  • rest last — only one allowed
  • arguments — legacy, avoid
