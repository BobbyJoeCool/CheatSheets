Arrays — Basics

[] · length · index · at() · Array.from · Array.of · holes · nested arrays

Overview

Arrays are ordered, zero-indexed lists that can hold any mix of types and grow or shrink freely. length is always one more than the highest index. Create them with literals [], Array.from() (from iterables or with a mapping function), or Array.of(). Arrays are objects, so they're copied by reference.

Notes

  • typeof [] is "object"; use Array.isArray
  • Setting arr.length = 0 empties the array
  • Holes ([1, , 3]) behave inconsistently; avoid them
  • new Array(3) makes 3 holes, not [3]

Creating and accessing arrays

const fruits = ["apple", "banana", "cherry"];
fruits[0];                    // "apple"
fruits.at(-1);                // "cherry"
fruits.length;                // 3
fruits[5];                    // undefined

fruits.push("date");          // add to end → length 4
fruits[1] = "blueberry";      // replace

Array.from("abc");            // ["a", "b", "c"]
Array.from({ length: 3 }, (_, i) => i * 2);  // [0, 2, 4]
Array.of(7);                  // [7]
new Array(3);                 // [ <3 empty items> ]
Array(3).fill(0);             // [0, 0, 0]

const grid = Array.from({ length: 2 }, () => Array(3).fill(0));
grid[1][2] = 5;               // [[0,0,0],[0,0,5]]

const copy = [...fruits];     // shallow copy
copy === fruits;              // false

Code Explained

at(-1) — last element without length - 1
Array.from({ length: n }, fn) — build arrays of computed values
fill — set every slot to one value
Build 2D arrays with Array.from, not fill([])

TypeScript

  • Type as string[] or Array<string>; readonly string[] blocks mutation
  • Tuples fix length and position types: [string, number]

⚠ Common Mistakes

  • Array(3).fill([]) puts the same inner array in every slot
  • new Array(5) when you meant [5]
  • Assigning b = a and thinking it's a copy; both names point to one array

✓ Tips & Best Practices

  • Prefer literals and Array.from over the Array constructor
  • Use const for arrays; you can still push to them
  • Check emptiness with arr.length === 0

Quick Summary

  • [] — literal, zero-indexed
  • at(-1) — negative index
  • Array.from — from iterables or generated
  • reference type — copy with spread
