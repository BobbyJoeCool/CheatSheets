Sheet 004

Running & Debugging

node file.js · node --watch · REPL · DevTools · debugger · breakpoints · source maps

Overview

Run files with node, and use --watch to restart on save. For debugging, the debugger statement pauses execution whenever DevTools (or Node's inspector) is attached, letting you inspect variables, step through code, and view the call stack. Source maps connect bundled or compiled output back to your original files.

Notes

  • node --inspect file.js lets Chrome DevTools attach via chrome://inspect
  • VS Code's JavaScript Debug Terminal attaches automatically
  • console.trace() prints a stack trace without stopping
  • Breakpoints can be conditional: right-click the line number

Running and pausing

$ node app.js                 // run once
$ node --watch app.js         // rerun on file change
$ node --inspect-brk app.js   // pause on first line for debugger

function total(items) {
  let sum = 0;
  for (const item of items) {
    debugger;                 // pauses here when DevTools is open
    sum += item.price;
  }
  return sum;
}

console.trace("reached total");  // logs call stack, keeps going
console.assert(sum >= 0, "negative!"); // logs only if false

Code Explained

--watch — built into Node 18+; no nodemon needed
--inspect-brk — waits for a debugger before running
debugger — no-op unless a debugger is attached
console.assert — prints only when the condition is false

TypeScript

  • Source maps ("sourceMap": true) let breakpoints and stack traces point at .ts lines
  • Use tsx (npx tsx watch app.ts) to run and watch TypeScript during development

⚠ Common Mistakes

  • Leaving debugger statements in committed code; add an ESLint rule (no-debugger)
  • Debugging minified bundle output without source maps
  • Logging objects and reading them later: browser consoles show the object's *current* state, not the state when logged

✓ Tips & Best Practices

  • Log a snapshot with console.log(structuredClone(obj)) or JSON.stringify
  • Use logpoints in DevTools instead of adding temporary console.log lines
  • Name the variable in logs: console.log({ user }) prints { user: … }

Quick Summary

  • node --watch — auto-restart
  • debugger — breakpoint in code
  • --inspect — attach DevTools to Node
  • source maps — map output back to source
