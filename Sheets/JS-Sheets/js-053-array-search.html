Sheet 053

Array Methods — Search & Test

find · findIndex · findLast · includes · indexOf · some · every

Overview

Search and test methods answer questions about an array without changing it. find/findLast return the matching item, findIndex/findLastIndex return its position, includes checks for a value, and some/every return booleans. All the callback-based ones stop as soon as the answer is known.

Notes

  • find returns undefined when nothing matches; findIndex returns -1
  • includes uses SameValueZero, so it finds NaN; indexOf doesn't
  • includes and indexOf compare objects by reference
  • every on an empty array is true

Searching arrays

const users = [
  { id: 1, name: "Ana", admin: false },
  { id: 2, name: "Bo",  admin: true  },
  { id: 3, name: "Cy",  admin: true  },
];

users.find(u => u.admin);            // { id: 2, name: "Bo", … }
users.findLast(u => u.admin);        // { id: 3, name: "Cy", … }
users.findIndex(u => u.id === 3);    // 2
users.find(u => u.id === 9);         // undefined

users.some(u => u.admin);            // true
users.every(u => u.name.length > 1); // true
[].every(x => false);                // true (vacuous)

const nums = [1, 2, NaN, 2];
nums.includes(2);                    // true
nums.indexOf(2);                     // 1
nums.lastIndexOf(2);                 // 3
nums.includes(NaN);                  // true
nums.indexOf(NaN);                   // -1

Code Explained

find vs filter — first match vs all matches
findLast — searches from the end
some — at least one; every — all
Use includes for simple value membership

TypeScript

  • find returns T | undefined, so handle the miss before using the result
  • A type-predicate callback narrows: find((x): x is Admin => x.admin)

⚠ Common Mistakes

  • Using filter(...)[0] instead of find; it scans the whole array
  • Testing if (arr.indexOf(x)), which is false when x is at index 0
  • Searching for an object with includes(obj) using a different but equal object

✓ Tips & Best Practices

  • Use a Set for repeated membership checks on large lists
  • Use findLast instead of reverse().find(), which mutates
  • Combine with ??: users.find(fn)?.name ?? "none"

Quick Summary

  • find — first matching item
  • findIndex — its position
  • includes — value present?
  • some / every — any / all
