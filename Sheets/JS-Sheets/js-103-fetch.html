fetch & HTTP

fetch · method / headers / body · response.ok · json() · error handling · JSON POST

Overview

fetch(url, options) makes HTTP requests in browsers, Node 18+, Deno, and Bun. It returns a Promise of a Response. The key gotcha: fetch only rejects on network failure. A 404 or 500 still resolves, so always check response.ok or status. Read the body once with json(), text(), or blob().

Notes

  • Default method is GET
  • Send JSON with JSON.stringify plus a Content-Type header
  • Cookies are sent only for same-origin requests unless credentials: "include"
  • Cross-origin requests need CORS headers from the server

GET, POST, error handling

const res = await fetch("https://api.example.com/users?limit=10");
res.status;                                 // 200
res.ok;                                     // true for 200–299
res.headers.get("content-type");            // "application/json"
const users = await res.json();

async function postJSON(url, data) {
  const res = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json",
               Authorization: `Bearer ${token}` },
    body: JSON.stringify(data),
    signal: AbortSignal.timeout(8000),
  });
  if (!res.ok) throw new Error(`HTTP ${res.status}: ${await res.text()}`);
  return res.status === 204 ? null : res.json();
}
const created = await postJSON("/api/users", { name: "Ana" });

const url = new URL("/search", location.origin);
url.searchParams.set("q", "js & ts");       // encoded for you
await fetch(url);

Code Explained

res.ok — check before reading the body
Headers object — case-insensitive keys
204 No Content — no body to parse
Build query strings with URL to get encoding right

TypeScript

  • res.json() returns Promise<any>; validate it or type it: (await res.json()) as User[]
  • Better: parse with a Zod schema (sheet 085) so the type is checked at runtime

⚠ Common Mistakes

  • Assuming fetch throws on 404/500; it doesn't
  • Reading the body twice; use res.clone() if you need it again
  • Sending an object as body without JSON.stringify

✓ Tips & Best Practices

  • Wrap fetch in a small helper that checks ok and parses JSON
  • Always set a timeout signal on requests to external services
  • Use FormData as the body for file uploads; don't set Content-Type yourself

Quick Summary

  • fetch(url, opts) — HTTP request
  • check res.ok — 4xx/5xx resolve
  • json() / text() — read once
  • signal — timeouts and cancel
