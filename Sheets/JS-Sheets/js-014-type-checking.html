Sheet 014

Type Checking

typeof · instanceof · Array.isArray · Number.isNaN · Number.isInteger · Object.prototype.toString

Overview

typeof returns a string naming a value's primitive type, but it can't tell objects apart (arrays, dates, and null all report "object"). Use instanceof for class instances, Array.isArray for arrays, and the Number.is* helpers for numeric checks. For an exact internal type tag, Object.prototype.toString.call(x) works on anything.

Notes

  • typeof never throws, even on undeclared variables
  • instanceof checks the prototype chain
  • instanceof fails across iframes/realms; Array.isArray doesn't
  • Functions report "function", even classes

Type checks with results

typeof "hi";                 // "string"
typeof 42;                   // "number"
typeof 42n;                  // "bigint"
typeof true;                 // "boolean"
typeof undefined;            // "undefined"
typeof Symbol();             // "symbol"
typeof null;                 // "object"   (!)
typeof [];                   // "object"
typeof (() => {});           // "function"

Array.isArray([]);           // true
new Date() instanceof Date;  // true
[] instanceof Object;        // true
Number.isNaN(NaN);           // true
Number.isInteger(4.0);       // true
Object.prototype.toString.call([]);   // "[object Array]"
Object.prototype.toString.call(null); // "[object Null]"

Code Explained

typeof — good for primitives and functions
Array.isArray — the only reliable array test
instanceof — true for any class in the chain
toString.call — precise tag for any value

TypeScript

  • typeof, instanceof, in, and Array.isArray all narrow the type inside the if
  • TS also has a type-level typeof that captures a variable's type (sheet 123)

⚠ Common Mistakes

  • typeof x === "object" without excluding null
  • typeof arr === "array"; that string is never returned
  • Using global isNaN("abc") (true) when you meant Number.isNaN (false)

✓ Tips & Best Practices

  • Write a small isObject = x => x !== null && typeof x === "object" helper
  • Prefer Number.isFinite to check "is a usable number"
  • Use duck typing (typeof x.then === "function") for protocol checks

Quick Summary

  • typeof — primitives and functions
  • instanceof — class instances
  • Array.isArray — arrays
  • toString.call — exact tag
