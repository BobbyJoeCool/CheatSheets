Sheet 102

Forms & Input

form.elements · FormData · submit event · input / change events · constraint validation · checkValidity

Overview

Forms collect user input. Listen for submit on the form (not click on the button) so Enter works too, call preventDefault() to handle it in JavaScript, and read all fields at once with FormData. The built-in constraint validation API (required, type="email", pattern) checks input before you write custom code.

Notes

  • input fires on every change; change fires when the value is committed
  • Field values are always strings (checkboxes: checked)
  • FormData includes only fields with a name attribute
  • form.elements.email reaches fields by name

Handling a form

// <form id="signup"><input name="email" type="email" required>
//   <input name="age" type="number" min="18"><input name="terms" type="checkbox">
//   <button>Join</button></form>
const form = document.querySelector("#signup");

form.addEventListener("submit", async e => {
  e.preventDefault();
  if (!form.checkValidity()) { form.reportValidity(); return; }

  const data = Object.fromEntries(new FormData(form));
  // { email: "a@b.co", age: "21", terms: "on" }
  data.age = Number(data.age);

  await fetch("/api/signup", { method: "POST", body: new FormData(form) });
  form.reset();
});

const email = form.elements.email;
email.addEventListener("input", () => {
  email.setCustomValidity(
    email.value.endsWith("@example.com") ? "Use a real address" : "");
});

form.elements.terms.checked;      // true / false
form.querySelector("select").value;

Code Explained

checkValidity / reportValidity — run built-in checks
Object.fromEntries(new FormData(form)) — form → object
Pass FormData straight to fetch for multipart uploads
setCustomValidity("") — clear a custom error

TypeScript

  • FormData.get returns FormDataEntryValue | null (string or File); narrow before use
  • form.elements.email needs a cast to HTMLInputElement

⚠ Common Mistakes

  • Listening for button click instead of form submit
  • Doing math with field values without converting from strings
  • Relying only on client-side validation; always validate on the server

✓ Tips & Best Practices

  • Style invalid fields with :user-invalid so errors show after interaction
  • Use valueAsNumber and valueAsDate to skip manual parsing
  • Disable the submit button while the request is in flight

Quick Summary

  • submit + preventDefault — handle in JS
  • FormData — read all fields
  • constraint validation — built-in checks
  • values are strings — convert
