keyof, typeof & Indexed Access

keyof · typeof · T[K] · T[number] · lookup types

Overview

Three operators let you build types from other types. keyof T gives a union of T's keys. Type-level typeof x captures the type of a value. Indexed access T[K] looks up the type of a property, and T[number] gets the element type of an array or tuple. Together they let types follow your values automatically.

Notes

  • Type-level typeof only works on values (variables, properties)
  • keyof of an index signature gives string | number
  • (typeof arr)[number] is the classic "union from array" trick
  • These operators exist only in type positions

Deriving types

type User = { id: number; name: string; tags: string[] };

type UserKey = keyof User;              // "id" | "name" | "tags"
type NameType = User["name"];           // string
type Tag = User["tags"][number];        // string
type IdOrName = User["id" | "name"];    // number | string

const defaults = { theme: "dark", fontSize: 14, beta: false };
type Settings = typeof defaults;
// { theme: string; fontSize: number; beta: boolean }

const ROLES = ["admin", "editor", "viewer"] as const;
type Role = (typeof ROLES)[number];     // "admin" | "editor" | "viewer"

function getSetting<K extends keyof Settings>(key: K): Settings[K] {
  return defaults[key];
}
getSetting("fontSize");                 // number
// getSetting("color");                 // error: not a key

type Handler = typeof window.addEventListener;    // function type
type Ret = ReturnType<typeof getSetting>;         // combine with utilities

Code Explained

keyof — union of property names
T["k"] — type of one property
T[number] — element type
typeof value — type of a runtime value
as const + [number] — union from a constant list

⚠ Common Mistakes

  • Using typeof on a type (typeof User) instead of a value
  • Forgetting as const, so (typeof arr)[number] is just string
  • Duplicating a type by hand that could be derived from a value

✓ Tips & Best Practices

  • Make one source of truth (a const object or schema) and derive types from it
  • Use T[keyof T] to get the union of an object's value types
  • Hover derived types in the editor to confirm what you got

Quick Summary

  • keyof — key union
  • typeof — type from value
  • T[K] — indexed access
  • [number] — element type
