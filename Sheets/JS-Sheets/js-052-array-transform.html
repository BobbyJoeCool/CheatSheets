Sheet 052

Array Methods — Transform

map · filter · reduce · slice · concat · flat · flatMap · toSorted / toSpliced / with

Overview

Transform methods return a new array (or value) and leave the original alone. map transforms each item, filter keeps items that pass a test, and reduce folds everything into a single value. flat/flatMap remove nesting, and slice/concat copy and combine. Chain them for readable data pipelines.

Notes

  • Callbacks receive (item, index, array)
  • map always returns an array of the same length
  • reduce without an initial value throws on an empty array
  • Holes are skipped by most of these methods

Transform pipelines

const orders = [
  { item: "pen", qty: 3, price: 1.5 },
  { item: "pad", qty: 0, price: 4 },
  { item: "ink", qty: 2, price: 6 },
];

orders.map(o => o.item);                    // ["pen", "pad", "ink"]
orders.filter(o => o.qty > 0).length;       // 2
orders.reduce((t, o) => t + o.qty * o.price, 0);   // 16.5

const byItem = orders.reduce((acc, o) => {
  acc[o.item] = o.qty; return acc;
}, {});                                     // { pen: 3, pad: 0, ink: 2 }

[[1, 2], [3, [4]]].flat();                  // [1, 2, 3, [4]]
[[1, 2], [3, [4]]].flat(Infinity);          // [1, 2, 3, 4]
["a b", "c"].flatMap(s => s.split(" "));    // ["a", "b", "c"]
[1, 2, 3, 4].slice(1, 3);                   // [2, 3]
[1].concat([2], 3);                         // [1, 2, 3]
[1, 2, 3].with(1, 9);                       // [1, 9, 3]

Code Explained

reduce(fn, init) — always pass init
Reduce to an object — build lookups or counts
flat(depth) — Infinity flattens everything
flatMap — map then flatten one level

TypeScript

  • reduce often needs a typed initial value: reduce<Record<string, number>>(fn, {})
  • filter with a type predicate narrows: .filter((x): x is string => x != null)

⚠ Common Mistakes

  • Using map for side effects and ignoring the result; use forEach or for...of
  • Omitting reduce's initial value and crashing on empty arrays
  • Forgetting to return the accumulator in a reduce with a block body

✓ Tips & Best Practices

  • Filter before map to do less work
  • Prefer clear for...of loops over clever reduce calls
  • Use Object.groupBy (sheet 055) instead of hand-written grouping reduces

Quick Summary

  • map — transform each
  • filter — keep matches
  • reduce — fold to one value
  • flat / flatMap — remove nesting
