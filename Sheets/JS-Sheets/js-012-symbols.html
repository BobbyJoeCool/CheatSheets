Sheet 012

Symbols

Symbol() · description · Symbol.for · well-known symbols · symbol keys · non-enumerable

Overview

A Symbol is a unique, immutable primitive, mostly used as an object key that can't collide with any other key. Every Symbol() call creates a new value, even with the same description. Well-known symbols like Symbol.iterator let you hook into language features such as for...of.

Notes

  • Symbol keys are skipped by for...in, Object.keys, and JSON.stringify
  • Symbol.for(key) returns a shared, global symbol
  • Symbols can't be implicitly converted to strings
  • Not truly private: Object.getOwnPropertySymbols reveals them

Creating and using symbols

const id = Symbol("id");
const id2 = Symbol("id");
id === id2;                       // false (always unique)
id.description;                   // "id"

const user = { name: "Ana", [id]: 123 };
user[id];                         // 123
Object.keys(user);                // ["name"]  (symbol hidden)
JSON.stringify(user);             // '{"name":"Ana"}'
Object.getOwnPropertySymbols(user); // [Symbol(id)]

Symbol.for("app") === Symbol.for("app"); // true (global registry)
Symbol.keyFor(Symbol.for("app"));        // "app"

// `${id}`;                       // TypeError
String(id);                       // "Symbol(id)"

Code Explained

[id]: 123 — computed key syntax puts a symbol on an object
Symbol keys don't show in normal enumeration
Symbol.for — same key gives the same symbol across files
Use String(sym) or .description to print

TypeScript

  • Type is symbol; a const declared with Symbol() gets unique symbol
  • unique symbol types can be used as typed object keys

⚠ Common Mistakes

  • Calling new Symbol(); it's a TypeError, symbols aren't constructed
  • Treating symbol keys as truly private; reflection APIs can read them
  • Expecting Symbol("x") === Symbol("x"); use Symbol.for for shared ones

✓ Tips & Best Practices

  • Use symbols for metadata keys on objects you don't own, to avoid collisions
  • Use #private class fields for real privacy instead of symbols
  • Implement Symbol.iterator to make your own objects work with for...of (sheet 061)
