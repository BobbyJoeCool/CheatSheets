while & do...while

while · do...while · sentinel loops · infinite loops · condition placement

Overview

while repeats as long as its condition is truthy and checks before each pass, so the body may never run. do...while checks after the body, so it always runs at least once. Use them when the number of iterations isn't known in advance: reading input, retrying, polling, or walking a linked structure.

Notes

  • Make sure something in the body moves toward ending the loop
  • while (true) with an internal break is a valid pattern
  • do...while needs a semicolon after the condition
  • In async code, await inside while runs iterations sequentially

while and do...while

let n = 5;
while (n > 0) {
  console.log(n);           // 5 4 3 2 1
  n--;
}

let node = list.head;       // walk a linked list
while (node) {
  console.log(node.value);
  node = node.next;
}

let guess;
do {
  guess = Math.ceil(Math.random() * 6);
} while (guess !== 6);      // always rolls at least once

let attempts = 0;
while (true) {              // retry with exit condition
  if (await tryConnect()) break;
  if (++attempts >= 3) throw new Error("gave up");
}

Code Explained

Condition checked first — while may run zero times
while (node) — runs until the reference is null
do...while — body first, then the check
while (true) + break — clear when exits are in the middle

TypeScript

  • Narrowing works in loops: while (node) treats node as non-null inside
  • Otherwise identical in TypeScript

⚠ Common Mistakes

  • Forgetting to update the condition variable, creating an infinite loop
  • Busy-waiting with while for time to pass; use setTimeout or await
  • Leaving off the semicolon after do...while (cond)

✓ Tips & Best Practices

  • Add a max-iterations guard to loops driven by external data
  • Prefer for when the count is known; while when it isn't
  • Put the exit condition near the top of a while (true) body when possible

Quick Summary

  • while — check first, may run 0 times
  • do...while — runs at least once
  • while (true) — exit with break
  • always progress toward the exit
