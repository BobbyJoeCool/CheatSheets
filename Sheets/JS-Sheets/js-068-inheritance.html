Sheet 068

Inheritance

extends · super() · super.method() · overriding · extending built-ins

Overview

extends creates a subclass that inherits the parent's fields and methods. Override a method by defining one with the same name; call the parent version with super.method(). Subclass constructors must call super() first. You can also extend built-ins like Error, Array, and Map.

Notes

  • JavaScript supports single inheritance only
  • Static methods are inherited too
  • super.method() works in methods and object literals
  • instanceof is true for the class and every ancestor

Extending and overriding

class Animal {
  constructor(name) { this.name = name; }
  speak() { return `${this.name} makes a sound`; }
  static create(name) { return new this(name); }   // this = called class
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);                     // parent constructor
    this.breed = breed;
  }
  speak() {                          // override
    return `${super.speak()} — woof`;
  }
}

const d = new Dog("Rex", "lab");
d.speak();                           // "Rex makes a sound — woof"
d instanceof Animal;                 // true
Dog.create("Fido") instanceof Dog;   // true (inherited static)

class Stack extends Array {
  peek() { return this.at(-1); }
}
const s = Stack.from([1, 2]);
s.peek();                            // 2
s.map(x => x) instanceof Stack;      // true

Code Explained

super(name) — sets up the parent part of the object
super.speak() — reuse the parent method
new this() in statics — creates the subclass when called on it
Extending Array keeps array methods returning your type

TypeScript

  • Mark overrides with override; turn on noImplicitOverride to require it
  • abstract classes and methods force subclasses to implement them (sheet 121)

⚠ Common Mistakes

  • Deep inheritance chains that are hard to change; prefer composition
  • Forgetting super() in a subclass constructor
  • Overriding a method and accidentally dropping important parent behavior

✓ Tips & Best Practices

  • Keep hierarchies shallow, two levels if possible
  • Call super.method() when extending rather than replacing behavior
  • Use new this() in static factories so subclasses get the right type

Quick Summary

  • extends — inherit
  • super() — parent constructor
  • super.m() — parent method
  • override — same method name
