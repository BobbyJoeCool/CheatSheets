Slicing & Indexing

slice · substring · at() · charAt · [i] · codePointAt · for...of over characters

Overview

Extract parts of a string with slice(start, end), which takes negative indexes from the end. at(i) reads one character and also accepts negatives. substring is an older alternative that swaps reversed arguments and treats negatives as 0. The end index is always exclusive.

Notes

  • s[i] returns undefined out of range; charAt returns ""
  • at(-1) is the last character
  • substr is deprecated; don't use it
  • All indexing is by UTF-16 unit, not by visible character

Slicing and indexing

const s = "JavaScript";
//         0123456789

s[0];                 // "J"
s.at(-1);             // "t"
s.charAt(4);          // "S"
s[20];                // undefined
s.charAt(20);         // ""

s.slice(0, 4);        // "Java"
s.slice(4);           // "Script"
s.slice(-6);          // "Script"
s.slice(-6, -3);      // "Scr"
s.substring(4, 0);    // "Java" (args swapped)
s.slice(4, 0);        // ""     (no swap)

s.codePointAt(0);     // 74
for (const ch of "hé😀") console.log(ch);  // h, é, 😀

Code Explained

slice(start, end) — end not included
Negative values count back from the end
substring swaps args when start > end; slice returns ""
for...of iterates full code points, including emoji

TypeScript

  • s[i] is typed string, even out of range; enable noUncheckedIndexedAccess to get string | undefined
  • at() already returns string | undefined

Slice Patterns (s = "abcdef")

CodeResult
s.slice(0, 3)"abc" (first 3)
s.slice(-3)"def" (last 3)
s.slice(1, -1)"bcde" (trim ends)
s.slice(2)"cdef" (drop 2)
s.slice(0, -2)"abcd" (drop last 2)
s.slice()"abcdef" (copy)

⚠ Common Mistakes

  • Expecting the end index to be included; slice(0, 3) returns 3 characters
  • Using s[s.length - 1] everywhere instead of the clearer s.at(-1)
  • Slicing strings with emoji by index and cutting a surrogate pair in half

✓ Tips & Best Practices

  • Default to slice; you rarely need substring
  • Use Array.from(s) or [...s] before slicing user text with emoji
  • Think of indexes as positions *between* characters to reason about ranges

Quick Summary

  • slice(a, b) — substring, end exclusive
  • negative index — from the end
  • at(i) — one character
  • for...of — iterate characters safely
