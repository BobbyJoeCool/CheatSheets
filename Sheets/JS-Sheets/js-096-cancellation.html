Cancellation, Timeouts & Debouncing

AbortController · signal · AbortSignal.timeout · cleanup · debounce · throttle

Overview

Promises can't be cancelled by themselves, so the platform uses AbortController: create a controller, pass its signal to fetch, event listeners, or your own functions, and call abort() to stop them. AbortSignal.timeout(ms) gives a ready-made timeout. Debounce and throttle limit how often a function runs in response to rapid events.

Notes

  • An aborted fetch rejects with a DOMException named AbortError
  • A timeout signal aborts with TimeoutError
  • AbortSignal.any([a, b]) aborts when either does
  • One signal can cancel many operations at once

Abort, timeouts, debounce

const ac = new AbortController();
fetch("/api/search?q=js", { signal: ac.signal })
  .then(r => r.json())
  .catch(err => { if (err.name !== "AbortError") throw err; });
ac.abort();                                   // cancel it

const res = await fetch(url, { signal: AbortSignal.timeout(5000) });

function debounce(fn, ms) {                   // wait for a pause
  let t;
  return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); };
}
input.addEventListener("input", debounce(e => search(e.target.value), 300));

function throttle(fn, ms) {                   // at most once per ms
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= ms) { last = now; fn(...args); }
  };
}
window.addEventListener("scroll", throttle(updateHeader, 100));

Code Explained

signal — pass it to anything cancelable
Check err.name to ignore expected aborts
Debounce — runs after events stop for ms
Throttle — runs at most once every ms

TypeScript

  • Type parameters as AbortSignal; generic debounce<T extends (...a: any[]) => void>(fn: T, ms: number)
  • Narrow errors: err instanceof DOMException && err.name === "AbortError"

⚠ Common Mistakes

  • Treating AbortError as a real failure and showing an error message
  • Reusing an aborted controller; create a new one per operation
  • Firing a fetch on every keystroke without debounce or abort

✓ Tips & Best Practices

  • Abort the previous search request when a new one starts
  • Pass { signal } to addEventListener to remove listeners in bulk
  • Use requestAnimationFrame for visual throttling

Quick Summary

  • AbortController — cancel operations
  • AbortSignal.timeout — time limits
  • debounce — after a pause
  • throttle — at most every n ms
