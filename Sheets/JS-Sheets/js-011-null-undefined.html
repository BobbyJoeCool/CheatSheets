Sheet 011

null & undefined

null · undefined · typeof null · void 0 · missing vs empty · == null idiom

Overview

JavaScript has two "nothing" values. undefined means a value was never assigned: missing properties, missing arguments, and functions with no return. null is an intentional "no value" that you assign yourself. They are loosely equal (null == undefined) but strictly different.

Notes

  • typeof null is "object", a historical bug
  • typeof undefined is "undefined"
  • JSON has null but no undefined; those keys are dropped
  • void 0 always evaluates to undefined

Where each appears

let a;                     // undefined (declared, not assigned)
const o = { x: 1 };
o.y;                       // undefined (missing property)
function f(p) { return p; }
f();                       // undefined (missing argument)
(() => {})();              // undefined (no return)

let user = null;           // intentional "no user yet"

null == undefined;         // true
null === undefined;        // false
typeof null;               // "object"

if (value == null) { }     // catches both null and undefined
value ?? "default";        // default only for null/undefined
user?.name;                // undefined instead of TypeError
JSON.stringify({ a: undefined, b: null }); // '{"b":null}'

Code Explained

== null — the one widely accepted use of loose equality
?? — default only for nullish values
?. — stops and returns undefined on null/undefined
JSON drops undefined keys but keeps null

TypeScript

  • strictNullChecks makes null/undefined separate types you must handle
  • x?: T (may be missing) differs from x: T | undefined (must be present)

⚠ Common Mistakes

  • Using typeof x === "object" to detect objects; it's also true for null
  • Passing null and expecting the default parameter to kick in; only undefined triggers it
  • Assigning undefined on purpose; use null so intent is clear

✓ Tips & Best Practices

  • Pick one convention: null for "intentionally empty", undefined for "not set"
  • Combine ?. and ??: user?.name ?? "Guest"
  • Use x == null when either value means "missing"

Quick Summary

  • undefined — never assigned
  • null — deliberately empty
  • == null — matches both
  • ?. / ?? — safe access and defaults
