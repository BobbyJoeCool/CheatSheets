Sheet 131

Adopting TypeScript

allowJs · checkJs · // @ts-check · incremental strictness · project references · tsc -b

Overview

You can adopt TypeScript gradually. Start by type-checking existing JavaScript with checkJs and JSDoc, rename files to .ts one at a time with allowJs, then raise strictness flag by flag. For large codebases, project references split the code into separately built pieces, and tsc -b builds them incrementally.

Notes

  • allowJs lets .ts and .js files import each other
  • // @ts-check opts a single JS file into checking
  • // @ts-nocheck opts a file out during migration
  • incremental caches results in a .tsbuildinfo file

Migration path and project references

// Step 1: check JS without renaming (tsconfig.json)
{ "compilerOptions": { "allowJs": true, "checkJs": true, "noEmit": true } }

// Step 2: JSDoc types in .js files
/** @param {string} name @returns {string} */
export function greet(name) { return `Hi ${name}`; }

// Step 3: rename leaf modules to .ts, add real annotations
// Step 4: turn on strict checks one at a time
"noImplicitAny": true  →  "strictNullChecks": true  →  "strict": true

// Monorepo: tsconfig.json at the root
{ "files": [],
  "references": [{ "path": "./packages/core" },
                 { "path": "./packages/app" }] }

// packages/core/tsconfig.json
{ "compilerOptions": { "composite": true, "outDir": "dist" } }

$ npx tsc -b              // build all references in order
$ npx tsc -b --watch      // incremental rebuilds

Code Explained

checkJs — find bugs before converting anything
JSDoc — types without changing file extensions
Convert leaf modules first (fewest dependents)
composite — required for referenced projects
tsc -b — builds only what changed

⚠ Common Mistakes

  • Converting everything in one huge PR
  • Using any everywhere to get green builds, then never removing it
  • Turning on strict all at once on a large codebase

✓ Tips & Best Practices

  • Track remaining errors per flag and burn them down over time
  • Convert shared utilities and types first so everything benefits
  • Use ts-migrate or similar tools for large mechanical conversions

Quick Summary

  • checkJs — check JS first
  • allowJs — mix while converting
  • strict flags — one at a time
  • project references — tsc -b
