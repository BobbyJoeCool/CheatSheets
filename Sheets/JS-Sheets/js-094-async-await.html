async / await

async · await · try / catch · sequential vs parallel · top-level await · for await

Overview

async functions always return a Promise, and await pauses the function until a Promise settles, then gives you its value (or throws its rejection). This lets async code read top to bottom with normal try/catch. Be deliberate about running awaits in sequence versus starting work in parallel.

Notes

  • await only works in async functions and module top level
  • A return value is wrapped in a resolved Promise
  • A throw becomes a rejected Promise
  • await in forEach doesn't wait; use for...of

async/await patterns

async function loadUser(id) {
  try {
    const res = await fetch(`/api/users/${id}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (err) {
    console.error("loadUser failed", err);
    return null;
  }
}

const a = await loadUser(1);            // sequential: 2× time
const b = await loadUser(2);

const [c, d] = await Promise.all([      // parallel: 1× time
  loadUser(1), loadUser(2),
]);

for (const id of ids) await process(id);       // one at a time
// ids.forEach(async id => await process(id)); // doesn't wait!

for await (const chunk of stream) {}    // async iterables
const fetchJSON = async url => (await fetch(url)).json();

Code Explained

try/catch handles awaited rejections
Two awaits in a row — second starts after first finishes
Promise.all — start together, wait for all
for...of with await — ordered processing

  • Return type is Promise<T>; annotate as async function f(): Promise<User | null>

⚠ Common Mistakes

  • Awaiting independent calls one after another and doubling load time
  • Using await inside forEach or map and expecting it to wait
  • Calling an async function without await or .catch, losing its errors

✓ Tips & Best Practices

  • Start independent work first, await later
  • Use Promise.all with map for parallel loops: await Promise.all(ids.map(load))
  • Limit concurrency for big batches (p-limit) to avoid overwhelming servers

Quick Summary

  • async — returns a Promise
  • await — pause for a result
  • try/catch — handle rejections
  • Promise.all — parallel awaits
