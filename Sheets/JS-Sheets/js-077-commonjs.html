Sheet 077

CommonJS & Interop

require · module.exports · exports · .cjs / .mjs · "type" field · require(esm)

Overview

CommonJS is Node's original module system: require() loads modules synchronously and module.exports defines what a file exports. Many npm packages still use it. Node decides which system a .js file uses from the nearest package.json "type" field; .mjs and .cjs force ESM or CommonJS.

Notes

  • ESM can import CommonJS modules (default import = module.exports)
  • Modern Node can require() ES modules without top-level await
  • __dirname, __filename, require exist only in CommonJS
  • exports.x = … works; reassigning exports = … doesn't

CommonJS and interop

// math.cjs
function add(a, b) { return a + b; }
module.exports = { add, PI: 3.14 };      // or: exports.add = add;

// app.cjs
const { add } = require("./math.cjs");
const fs = require("node:fs");
console.log(__dirname, add(1, 2));       // 3

// app.mjs (ESM importing CommonJS)
import math from "./math.cjs";           // module.exports object
import { add } from "./math.cjs";        // named, when detectable
import { createRequire } from "node:module";
const require = createRequire(import.meta.url);
const legacy = require("./old.cjs");     // require inside ESM

// package.json
{ "type": "module",
  "exports": { "import": "./dist/index.js",
               "require": "./dist/index.cjs" } }

Code Explained

module.exports — the object require returns
Default import of CJS — always works
createRequire — use require from ESM
Conditional exports — ship both formats

TypeScript

  • Set "module": "nodenext" so TS follows Node's ESM/CJS rules exactly
  • esModuleInterop makes import x from "cjs-pkg" work for CommonJS packages

⚠ Common Mistakes

  • exports = { … } (reassigns the local variable, exports nothing)
  • Using require in a "type": "module" project without createRequire
  • Publishing packages without an exports map, causing dual-format confusion

✓ Tips & Best Practices

  • Write new code as ESM
  • Use .cjs for config files that tools still load with require
  • Check a package's exports field to see which formats it ships

Quick Summary

  • require / module.exports — CommonJS
  • .mjs / .cjs — force a format
  • "type": "module" — .js is ESM
  • createRequire — require from ESM
