Sheet 036

Loop Controls

break · continue · labeled statements · return from loops · can't break forEach

Overview

break exits the innermost loop (or switch) immediately. continue skips to the next iteration. Labels let break or continue target an outer loop. Array methods like forEach can't be broken out of; use for...of, some, every, or find when you need to stop early.

Notes

  • return inside a loop exits the whole function
  • Labels are identifiers followed by :
  • continue in a for loop still runs the update expression
  • There's no pass; an empty block {} does nothing

break, continue, labels

for (const n of [1, 2, 3, 4, 5]) {
  if (n === 2) continue;        // skip 2
  if (n === 4) break;           // stop at 4
  console.log(n);               // 1 3
}

outer: for (const row of grid) {
  for (const cell of row) {
    if (cell === target) {
      console.log("found");
      break outer;              // exits both loops
    }
  }
}

[1, 2, 3].forEach(n => {
  if (n === 2) return;          // only skips this callback
});

const firstBig = nums.find(n => n > 100);    // stops at first match
const hasNeg = nums.some(n => n < 0);        // stops when true

Code Explained

continue — skip the rest of this pass
break — leave the loop entirely
break label — leave a named outer loop
return in forEach acts like continue, not break

TypeScript

  • TS flags unreachable code after break/return (controlled by allowUnreachableCode)
  • Unused labels are flagged by allowUnusedLabels: false

⚠ Common Mistakes

  • Trying to break out of forEach; it's a SyntaxError
  • Using return in forEach expecting it to stop the loop
  • Overusing labels; extracting a function with return is usually clearer

✓ Tips & Best Practices

  • Replace search loops with find, some, or includes
  • Use continue for guard-style skips at the top of the loop body
  • Move nested search loops into a function and return when found

Quick Summary

  • break — exit loop
  • continue — skip to next
  • labels — target outer loops
  • forEach — can't break
