Sheet 042

Parameters & Defaults

positional · default values · arguments object · options-object pattern · pass-by-sharing

Overview

Parameters are positional and never required: missing ones are undefined, extra ones are ignored. Default values apply when an argument is undefined. JavaScript has no named arguments, so the common substitute is passing an options object and destructuring it in the parameter list.

Notes

  • Defaults are evaluated at call time and can reference earlier params
  • null does not trigger a default; only undefined does
  • Arguments are passed by sharing: objects can be mutated, but reassigning a param doesn't affect the caller
  • fn.length counts params before the first default

Defaults and options objects

function greet(name = "friend", punct = "!") {
  return `Hi ${name}${punct}`;
}
greet();                  // "Hi friend!"
greet("Ana");             // "Hi Ana!"
greet(undefined, "?");    // "Hi friend?"
greet(null);              // "Hi null!"

function rect(w, h = w) { return w * h; }   // default uses w
rect(4);                  // 16

function connect({ host = "localhost", port = 5432, ssl = false } = {}) {
  return `${host}:${port} ssl=${ssl}`;
}
connect({ port: 6543 });  // "localhost:6543 ssl=false"
connect();                // works thanks to "= {}"

function rename(user) { user.name = "Bo"; user = null; }
const u = { name: "Al" }; rename(u); u.name;  // "Bo"

Code Explained

Default applies only for undefined
Later defaults can use earlier parameters
Destructured options + = {} — named, optional arguments
Mutation is visible to the caller; reassignment is not

TypeScript

  • Mark optional params with ?: function f(a: string, b?: number)
  • A parameter with a default is automatically optional; type the options object with an interface

⚠ Common Mistakes

  • Passing null and expecting the default to apply
  • Using mutable shared defaults by reference (e.g., one cached object reused across calls)
  • More than three positional parameters; switch to an options object

✓ Tips & Best Practices

  • Put required parameters first and optional ones last
  • Always add = {} after a destructured options parameter
  • Don't mutate arguments; return a new value instead

Quick Summary

  • missing args — undefined
  • param = default — for undefined only
  • options object — named arguments
  • pass by sharing — objects mutable
