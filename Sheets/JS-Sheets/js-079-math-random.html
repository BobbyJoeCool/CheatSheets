Math & Random

round / floor / ceil / trunc · min / max · abs · pow · random ints · crypto.randomUUID · getRandomValues

Overview

Math is a built-in object of static functions and constants: rounding, min/max, powers, roots, and trigonometry. Math.random() gives a float in [0, 1), which is fine for games and shuffles but not for security. For IDs, tokens, and passwords use the Web Crypto API: crypto.randomUUID() and crypto.getRandomValues().

Notes

  • Math.round rounds .5 up toward +∞: Math.round(-2.5) is -2
  • Math.trunc drops decimals; Math.floor rounds down
  • crypto is global in browsers and modern Node
  • Angles in trig functions are radians

Math and random

Math.round(4.5);      // 5        Math.round(-4.5);  // -4
Math.floor(-4.2);     // -5       Math.ceil(4.2);    // 5
Math.trunc(-4.7);     // -4       Math.sign(-3);     // -1
Math.abs(-7);         // 7        Math.max(3, 9, 1); // 9
Math.min(...[4, 2]);  // 2        Math.pow(2, 8);    // 256
Math.sqrt(81);        // 9        Math.cbrt(27);     // 3
Math.hypot(3, 4);     // 5        Math.log10(1000);  // 3
Math.PI;              // 3.141592653589793

const randInt = (min, max) =>                // inclusive
  Math.floor(Math.random() * (max - min + 1)) + min;
randInt(1, 6);                               // 1–6
const pick = arr => arr[Math.floor(Math.random() * arr.length)];

const clamp = (n, lo, hi) => Math.min(Math.max(n, lo), hi);
clamp(15, 0, 10);                            // 10

crypto.randomUUID();      // "3b241101-e2bb-4255-8caf-4136c566a962"
crypto.getRandomValues(new Uint32Array(1))[0];  // secure int

Code Explained

randInt — the standard inclusive range formula
clamp — keep a value inside bounds
randomUUID — RFC 4122 v4 IDs
getRandomValues — cryptographically secure numbers

TypeScript

  • Identical in TypeScript; Math functions take and return number
  • crypto.randomUUID() is typed as a template literal type of the UUID shape

⚠ Common Mistakes

  • Using Math.random() for tokens, passwords, or session IDs
  • Math.round(x * 100) / 100 assuming exact decimal results; floats still apply
  • Calling Math.max() on an empty array: it returns -Infinity

✓ Tips & Best Practices

  • Shuffle fairly with Fisher–Yates, not sort(() => Math.random() - 0.5)
  • Convert degrees: rad = deg * Math.PI / 180
  • Use Number.EPSILON for float comparisons
