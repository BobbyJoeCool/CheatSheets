URL & History

URL · URLSearchParams · location · history.pushState · popstate · hash routing

Overview

The URL class parses and builds URLs safely, and URLSearchParams handles query strings with correct encoding. In the browser, location describes the current page, and the History API (pushState, replaceState, popstate) lets single-page apps change the address bar without reloading.

Notes

  • new URL(path, base) resolves relative URLs
  • URL.canParse(str) checks validity without try/catch
  • pushState doesn't fire popstate; only back/forward do
  • location.href = … navigates; location.replace skips history

URLs, params, history

const u = new URL("https://shop.example.com:8080/items?id=7&sort=asc#top");
u.hostname;          // "shop.example.com"
u.port;              // "8080"
u.pathname;          // "/items"
u.hash;              // "#top"
u.searchParams.get("id");             // "7"
u.searchParams.set("page", "2");
u.searchParams.delete("sort");
u.toString();        // "https://shop.example.com:8080/items?id=7&page=2#top"

new URL("../img/a.png", "https://x.com/docs/page/").href;
// "https://x.com/docs/img/a.png"

const params = new URLSearchParams({ q: "café & tea", n: 5 });
params.toString();   // "q=caf%C3%A9+%26+tea&n=5"
Object.fromEntries(new URLSearchParams(location.search));

history.pushState({ tab: "reviews" }, "", "?tab=reviews");
window.addEventListener("popstate", e => showTab(e.state?.tab));
location.reload();

Code Explained

URL parts are properties you can read or set
searchParams — live view of the query string
URLSearchParams — encodes spaces, &, accents
pushState(state, "", url) — change URL, keep page

TypeScript

  • searchParams.get returns string | null
  • history.state is any; type your state objects when reading them

⚠ Common Mistakes

  • Building query strings by concatenation and missing encoding
  • Expecting popstate after pushState
  • Parsing URLs with regex instead of the URL class

✓ Tips & Best Practices

  • Keep UI state like filters and tabs in the URL so pages are shareable
  • Use replaceState for state changes that shouldn't add history entries
  • Check out the Navigation API for richer SPA routing where supported
