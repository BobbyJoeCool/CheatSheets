Bitwise Operators

& · | · ^ · ~ · << >> >>> · 32-bit conversion · flags & masks

Overview

Bitwise operators work on the binary representation of numbers. JavaScript converts operands to 32-bit signed integers first, applies the operation, and converts back. They're used for flags and masks, color manipulation, hashing, and quick integer truncation.

Notes

  • >> keeps the sign; >>> fills with zeros (unsigned)
  • ~x equals -(x + 1)
  • Values above 2³¹−1 wrap around
  • BigInt supports all except >>>

Bits in action

//      5 = 0101     3 = 0011
5 & 3;      // 1  (0001)  AND
5 | 3;      // 7  (0111)  OR
5 ^ 3;      // 6  (0110)  XOR
~5;         // -6         NOT
5 << 1;     // 10 (1010)  shift left = ×2
5 >> 1;     // 2  (0010)  shift right = ÷2
-8 >> 1;    // -4         sign kept
-8 >>> 28;  // 15         zero-filled

const READ = 1, WRITE = 2, EXEC = 4;    // flags
let perm = READ | WRITE;                // 3
(perm & WRITE) !== 0;                   // true  (has WRITE)
perm &= ~WRITE;                         // 1  (remove WRITE)
perm ^= EXEC;                           // 5  (toggle EXEC)

(0xff8800 >> 8) & 0xff;                 // 136 (green channel)
(13).toString(2).padStart(8, "0");      // "00001101"

Code Explained

Flags — each power of 2 is one bit
perm & FLAG — test a bit
perm &= ~FLAG — clear a bit; ^= toggles
toString(2) — view the bits

TypeScript

  • Identical in TypeScript
  • Numeric enum flags (enum Perm { Read = 1, Write = 2 }) pair well with bitwise ops

⚠ Common Mistakes

  • Using x | 0 on numbers above 2³¹; they overflow to negative
  • Confusing & with && in conditions; & evaluates both sides and returns a number
  • Forgetting parentheses: perm & WRITE !== 0 parses as perm & (WRITE !== 0)

✓ Tips & Best Practices

  • Use Math.trunc instead of | 0 for readability unless performance matters
  • Define flags with shifts for clarity: 1 << 0, 1 << 1, 1 << 2
  • Use BigInt for masks wider than 32 bits

Quick Summary

  • & | ^ ~ — bit logic
  • << >> — shift, ×2 / ÷2
  • >>> — unsigned shift
  • 32-bit — operands are converted first
