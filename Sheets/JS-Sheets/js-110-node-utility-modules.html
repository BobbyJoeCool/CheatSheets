Sheet 110

Node Utility Modules

node:os · node:util · node:crypto · node:child_process · util.parseArgs · util.styleText

Overview

Node ships many small utility modules that replace common npm packages. node:os reports system info, node:util has helpers like promisify, inspect, parseArgs, and styleText. node:crypto covers hashing, random values, and UUIDs, and node:child_process runs other programs.

Notes

  • Always import built-ins with the node: prefix
  • util.promisify converts callback APIs to Promises
  • execFile is safer than exec (no shell interpretation)
  • util.styleText adds terminal colors without chalk

Utility modules

import os from "node:os";
import { promisify, inspect, styleText, isDeepStrictEqual } from "node:util";
import { createHash, randomUUID, randomBytes } from "node:crypto";
import { execFile } from "node:child_process";

os.platform();  os.cpus().length;   // "linux", 8
os.totalmem() / 1e9;                // 16 (GB)
os.homedir();  os.EOL;              // "/home/me", "\n"

console.log(styleText("green", "✔ passed"));
console.log(inspect(deepObj, { depth: null, colors: true }));
isDeepStrictEqual({ a: [1] }, { a: [1] });   // true

createHash("sha256").update("hello").digest("hex");
// "2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824"
randomUUID();                       // "9b1d…"
randomBytes(16).toString("base64url");       // URL-safe token

const run = promisify(execFile);
const { stdout } = await run("git", ["rev-parse", "--short", "HEAD"]);
stdout.trim();                      // "a1b2c3d"

Code Explained

os — CPU, memory, platform facts
styleText — colors that respect NO_COLOR
createHash — checksums and fingerprints
execFile + promisify — run commands, await output

TypeScript

  • All typed through @types/node
  • promisify keeps types for standard callback signatures; custom ones may need annotations

⚠ Common Mistakes

  • Passing user input to exec, which allows shell injection
  • Using crypto.createHash("md5") for passwords; use scrypt or argon2
  • Installing packages for features Node already has

✓ Tips & Best Practices

  • Check the built-ins table before adding a dependency
  • Hash passwords with crypto.scrypt and a random salt
  • Use spawn with stdio: "inherit" to show a child's output live

Quick Summary

  • os — system info
  • util — promisify, inspect, styleText
  • crypto — hashes, UUIDs, tokens
  • child_process — run programs
