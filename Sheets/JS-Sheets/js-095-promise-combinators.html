Sheet 095

Promise Combinators

Promise.all · allSettled · race · any · withResolvers · Promise.try

Overview

Combinators coordinate several Promises at once. Promise.all waits for every one and fails fast on the first rejection. allSettled waits for all and reports each outcome. race settles with whichever finishes first, and any returns the first success. withResolvers and try are newer helpers for creating promises.

Notes

  • All combinators take any iterable of Promises or values
  • all doesn't cancel the others when one fails
  • any rejects with an AggregateError if every input rejects
  • Results keep input order, not completion order

Combinators in action

const [user, posts] = await Promise.all([
  getUser(id), getPosts(id),
]);                                         // fails fast

const results = await Promise.allSettled(urls.map(u => fetch(u)));
const ok = results.filter(r => r.status === "fulfilled").map(r => r.value);
const failed = results.filter(r => r.status === "rejected").length;

const timeout = ms => new Promise((_, rej) =>
  setTimeout(() => rej(new Error("timeout")), ms));
await Promise.race([fetch(url), timeout(5000)]);   // first to settle

const fastest = await Promise.any([             // first success
  fetch("https://mirror1/x"), fetch("https://mirror2/x"),
]);

const { promise, resolve, reject } = Promise.withResolvers();
button.onclick = () => resolve("clicked");
await promise;                                  // "clicked"

Promise.try(() => maybeSyncOrAsync());          // always a Promise

Code Explained

all — every result, or the first error
allSettled — { status, value | reason } for each
race — timeouts and first response wins
withResolvers — resolve from outside the executor

TypeScript

  • Promise.all infers a tuple: [User, Post[]] from the example
  • allSettled results are PromiseSettledResult<T>[], narrowed by status

⚠ Common Mistakes

  • Using all when partial failure is acceptable; use allSettled
  • Racing against a timeout without cancelling the losing request (see sheet 096)
  • Passing functions instead of Promises: Promise.all([load]) instead of [load()]

✓ Tips & Best Practices

  • Use AbortSignal.timeout(ms) with fetch instead of hand-rolled race timeouts
  • Use allSettled for batch jobs and report failures together
  • Check runtime support for Promise.try (ES2025)

Quick Summary

  • all — all or fail fast
  • allSettled — every outcome
  • race — first to settle
  • any — first success
