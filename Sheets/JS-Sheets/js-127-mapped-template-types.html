Mapped & Template Literal Types

[K in keyof T] · +/- modifiers · as remapping · template literal types · Capitalize / Uppercase

Overview

A mapped type builds a new object type by looping over keys: { [K in keyof T]: … }. Modifiers +/- add or remove readonly and ?, and an as clause remaps keys, including renaming or filtering them. Template literal types build string types from other strings, which pairs perfectly with key remapping.

Notes

  • Partial, Readonly, Record, Pick are all mapped types
  • -? removes optionality; -readonly removes readonly
  • Remapping a key to never drops it
  • Template literal types distribute over unions

Mapped and template literal types

type User = { id: number; name: string; email?: string };

type Nullable<T> = { [K in keyof T]: T[K] | null };
type Mutable<T> = { -readonly [K in keyof T]: T[K] };
type Concrete<T> = { [K in keyof T]-?: T[K] };      // like Required

type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};
type UserGetters = Getters<User>;
// { getId: () => number; getName: () => string; getEmail?: … }

type OnlyStrings<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K];
};
type S = OnlyStrings<User>;              // { name: string }

type Method = "get" | "post";
type Path = "/users" | "/posts";
type Route = `${Uppercase<Method>} ${Path}`;
// "GET /users" | "GET /posts" | "POST /users" | "POST /posts"

type CssVar = `--${string}`;
const v: CssVar = "--accent";            // OK
type EventName<T extends string> = `${T}Changed`;

Code Explained

[K in keyof T] — loop over keys
-readonly / -? — strip modifiers
as + template literal — rename keys
as … ? K : never — filter keys by value type
Template literal unions — every combination

⚠ Common Mistakes

  • Forgetting string & K inside template literals when keys may include numbers or symbols
  • Generating huge unions from template literals (they multiply quickly)
  • Rebuilding utility types that already exist

✓ Tips & Best Practices

  • Use key remapping to generate event, getter, or action names from a model
  • Type CSS custom properties and route strings with template literals
  • Hover the result; mapped types are easier to verify than to read

Quick Summary
