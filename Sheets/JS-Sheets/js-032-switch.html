Sheet 032

switch

switch · case · default · fall-through · strict === matching · switch (true)

Overview

switch compares one value against several case labels using strict equality (===). Execution falls through to the next case unless you break (or return). default handles unmatched values. It's best for matching one variable against many fixed values.

Notes

  • Cases can be any expression, compared with ===
  • Stacking empty cases groups them: case "a": case "b":
  • Wrap a case in { } to declare let/const inside it
  • default can go anywhere but usually comes last

switch, fall-through, switch(true)

function dayType(day) {
  switch (day) {
    case "Sat":
    case "Sun":                      // grouped cases
      return "weekend";
    case "Fri": { const msg = "almost"; return msg; } // block
    default:
      return "weekday";
  }
}

switch (status) {
  case 200: console.log("OK"); break;
  case 404: console.log("Missing"); // no break: falls through!
  case 500: console.log("Error");   // also runs for 404
}

switch (true) {                      // ranges
  case temp < 0:  label = "freezing"; break;
  case temp < 20: label = "cool"; break;
  default:        label = "warm";
}

Code Explained

return exits the function, so no break needed
Missing break — execution continues into the next case
Braces give a case its own scope
switch (true) — first case expression that is true wins

TypeScript

  • Get exhaustiveness checks by assigning to never in default: const _x: never = value;
  • Cases narrow discriminated unions: case "circle": knows the shape is a circle

⚠ Common Mistakes

  • Forgetting break and running the next case too
  • Declaring const in two cases without braces: "Identifier has already been declared"
  • Expecting case "1" to match the number 1; matching is strict

✓ Tips & Best Practices

  • Add // falls through comments when fall-through is intentional (ESLint no-fallthrough)
  • Return from each case inside functions to avoid break entirely
  • Use an object lookup when every case just returns a value

Quick Summary

  • switch — match one value, ===
  • break — stops fall-through
  • default — unmatched values
  • switch (true) — range checks
