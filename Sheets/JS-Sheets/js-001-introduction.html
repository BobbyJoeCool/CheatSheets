Introduction & History

ECMAScript · TC39 · yearly releases · V8 / SpiderMonkey · .js / .mjs / .cjs · Hello, World

Overview

JavaScript is the language of the web: every browser runs it, and runtimes like Node.js, Deno, and Bun run it on servers and desktops. The language itself is standardized as ECMAScript by the TC39 committee, which ships a new edition every June (ES2015 was the big modernizing release; ES2025 is current). Engines such as V8 (Chrome, Node) and SpiderMonkey (Firefox) compile it just-in-time.

Notes

  • Created by Brendan Eich at Netscape in 1995, in about ten days
  • Not related to Java; the name was a marketing decision
  • .js follows the nearest package.json "type"; .mjs is always ESM, .cjs always CommonJS
  • Dynamically typed, garbage collected, single-threaded with an event loop

Hello, World — three ways

// 1. Browser: inside an HTML page
<script type="module">
  console.log("Hello, World");   // shows in DevTools console
</script>

// 2. Node.js: save as hello.js, then run
console.log("Hello, World");     // $ node hello.js

// 3. REPL: type `node` with no file
> 2 + 2
4
> "Hello".toUpperCase()
'HELLO'

Code Explained

<script type="module"> — modern browser entry point; enables import
console.log — standard output in both browser and Node
node file.js — runs a file; node alone opens the REPL
The REPL prints the value of each expression automatically

TypeScript

  • TypeScript is a typed superset by Microsoft: every valid JS file is valid TS
  • Files use .ts / .tsx; types are erased, so the output is plain JS

⚠ Common Mistakes

  • Calling it "Java" or assuming Java knowledge transfers; the type systems and object models are different
  • Following pre-2015 tutorials that use var and callbacks everywhere
  • Forgetting type="module" and then wondering why import throws

✓ Tips & Best Practices

  • Check feature support on MDN's compatibility tables before shipping to older browsers
  • Use the REPL or DevTools console to test one-liners quickly
  • Learn modern syntax first (ES2015+); legacy patterns can wait

Quick Summary

  • ECMAScript — the standard; yearly editions
  • V8 / SpiderMonkey — engines that run it
  • node file.js — run outside the browser
  • TypeScript — JS plus a compile-time type layer
