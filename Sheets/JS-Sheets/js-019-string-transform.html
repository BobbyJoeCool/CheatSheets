String Methods — Transform

replace · replaceAll · split · trim · toUpperCase · padStart · repeat · normalize

Overview

Transform methods return a new string and leave the original unchanged. The workhorses are replace/replaceAll, split and its partner Array.join, trim for whitespace, and case conversion. padStart/padEnd are handy for aligned output and zero-padded numbers.

Notes

  • replace with a string replaces only the first match
  • replaceAll with a regex requires the g flag
  • split("") splits into UTF-16 units; use [...s] for characters
  • normalize() fixes accented characters that look equal but aren't

Transform methods with results

const s = "  Hello, World  ";

s.trim();                          // "Hello, World"
s.trimStart();                     // "Hello, World  "
"a-b-c".replace("-", "+");         // "a+b-c"  (first only)
"a-b-c".replaceAll("-", "+");      // "a+b+c"
"a1b2".replace(/\d/g, "#");        // "a#b#"
"john".replace(/^./, c => c.toUpperCase()); // "John"

"a,b,c".split(",");                // ["a", "b", "c"]
"a,b,c".split(",", 2);             // ["a", "b"]
["a", "b"].join(" & ");            // "a & b"

"Hi".toUpperCase();                // "HI"
"5".padStart(3, "0");              // "005"
"ab".padEnd(5, ".");               // "ab..."
"ha".repeat(3);                    // "hahaha"
"é" === "e\u0301".normalize();     // true

Code Explained

Replacement function — receives the match and returns the new text
split(sep, limit) — limit caps the number of pieces
padStart(len, fill) — pads until the total length is len
normalize() — converts to a canonical Unicode form (NFC)

TypeScript

  • All return string; split returns string[]
  • Identical behavior in TypeScript

⚠ Common Mistakes

  • Expecting replace("x", "y") to replace every x; use replaceAll
  • Calling s.trim() without assigning the result; strings don't change in place
  • Using toUpperCase for locale-specific text (Turkish i); use toLocaleUpperCase("tr")

✓ Tips & Best Practices

  • Chain methods: s.trim().toLowerCase().split(/\s+/)
  • Use $1, $2 in replacement strings to insert capture groups
  • Use Intl.Segmenter to split into user-perceived characters or words

Quick Summary

  • replace / replaceAll — substitute
  • split / join — string ↔ array
  • trim — strip whitespace
  • padStart — fixed-width output
