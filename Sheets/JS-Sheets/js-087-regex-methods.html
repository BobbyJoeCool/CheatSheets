Regular Expressions — Methods

test · exec · match · matchAll · replace with $1 / fn · named groups · lookarounds

Overview

Regexes are used through methods on both RegExp and String. test answers yes/no, match and exec return match details, matchAll iterates every match with groups, and replace/replaceAll substitute text using $1-style references or a callback. Lookarounds check context without consuming it.

Notes

  • match with g returns only the matched strings, no groups
  • matchAll requires the g flag
  • Replacement callbacks receive the match, then each group
  • Reusing a g regex with test can skip matches because of lastIndex

Using regexes

const s = "Order 2026-03-15, ship 2026-04-01";
const date = /(?<y>\d{4})-(?<m>\d{2})-(?<d>\d{2})/g;

/\d/.test("a1");                       // true
s.match(/\d{4}/);                      // ["2026", index: 6, …]
s.match(/\d{4}/g);                     // ["2026", "2026"]

for (const m of s.matchAll(date)) {
  console.log(m.groups.y, m.groups.m, m.index);  // 2026 03 6 …
}

s.replace(date, "$<m>/$<d>/$<y>");     // "Order 03/15/2026, ship 04/01/2026"
"a-b_c".replace(/[-_](\w)/g, (_, c) => c.toUpperCase());  // "aBC"
"  x  ".replace(/^\s+|\s+$/g, "");     // "x"

"price: $42".match(/(?<=\$)\d+/)[0];   // "42"   lookbehind
"foobar".match(/foo(?=bar)/)[0];       // "foo"  lookahead
"a1b2".split(/\d/);                    // ["a", "b", ""]

Code Explained

matchAll — every match with groups and index
$<name> / $1 — insert groups in replacements
Callback replacement — compute the new text
(?<=…) / (?=…) — context checks that don't consume

TypeScript

  • match returns RegExpMatchArray | null; check before indexing
  • m.groups is typed as { [key: string]: string } | undefined

⚠ Common Mistakes

  • Calling match(...)[0] without checking for null
  • Using replace with a string pattern and expecting all occurrences changed
  • Reusing a global regex across test calls and getting alternating results

✓ Tips & Best Practices

  • Use replaceAll with a regex only when it has the g flag
  • Use a callback replacement for anything conditional
  • Prefer matchAll over exec loops

Quick Summary

  • test — yes/no
  • match / matchAll — details & groups
  • replace — $1, $<name>, or callback
  • lookarounds — check context
