Sheet 057

Copying & Equality

spread copy · structuredClone · shallow vs deep · JSON round-trip · reference equality

Overview

Assigning an object or array copies the reference, not the data. Spread ({...o}, [...a]) and Object.assign make shallow copies: the top level is new but nested objects are shared. structuredClone makes a true deep copy, including Maps, Sets, Dates, and circular references.

Notes

  • Primitives are always copied by value
  • structuredClone can't copy functions, DOM nodes, or class prototypes
  • The JSON round-trip loses Dates, undefined, Maps, and Sets
  • Equality (===) is by reference for objects

Reference, shallow, deep

const a = { n: 1, tags: ["x"] };
const ref = a;                       // same object
ref.n = 2;  a.n;                     // 2

const shallow = { ...a };
shallow.n = 3;      a.n;             // 2  (top level copied)
shallow.tags.push("y"); a.tags;      // ["x", "y"]  (shared!)

const deep = structuredClone(a);
deep.tags.push("z"); a.tags;         // ["x", "y"]  (independent)

const withDate = { d: new Date() };
structuredClone(withDate).d instanceof Date;        // true
JSON.parse(JSON.stringify(withDate)).d;             // string!

// structuredClone({ fn() {} });     // DataCloneError

{ a: 1 } === { a: 1 };               // false (different objects)
JSON.stringify(x) === JSON.stringify(y);  // crude deep equality

Code Explained

Reference copy — two names, one object
Shallow copy — nested arrays and objects still shared
structuredClone — independent deep copy
JSON round-trip — only for plain JSON-safe data

TypeScript

  • Readonly<T> and as const give immutability at type level; ReadonlyDeep from type-fest goes deeper
  • structuredClone<T>(x) returns the same type T

⚠ Common Mistakes

  • Copying with spread and then mutating a nested array, changing the original
  • Using the JSON round-trip on data with Dates or undefined
  • Comparing objects with === to check if their contents match

✓ Tips & Best Practices

  • Update nested state immutably: { ...s, user: { ...s.user, name } }
  • Use structuredClone by default when you need a real copy
  • Use a library like fast-deep-equal or Node's util.isDeepStrictEqual for deep comparison

Quick Summary

  • = — copies the reference
  • spread — shallow copy
  • structuredClone — deep copy
  • === — reference equality
