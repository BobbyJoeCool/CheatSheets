Sheet 112

tsconfig.json

strict · target · module · moduleResolution · lib · noUncheckedIndexedAccess · verbatimModuleSyntax · include

Overview

tsconfig.json controls how TypeScript checks and compiles your project. The most important setting is "strict": true, which turns on a family of safety checks. target sets the JS version to emit, module/moduleResolution set how imports work, and lib decides which built-in APIs (DOM, ES2025) are known.

Notes

  • Create one with npx tsc --init
  • strict enables strictNullChecks, noImplicitAny, and more
  • extends lets you share a base config
  • Use @tsconfig/* packages for good presets (node22, vite-react…)

A modern tsconfig.json

{
  "compilerOptions": {
    "target": "ES2023",
    "module": "nodenext",              // Node ESM/CJS rules
    "moduleResolution": "nodenext",
    "lib": ["ES2024", "DOM"],
    "strict": true,
    "noUncheckedIndexedAccess": true,  // arr[i] may be undefined
    "exactOptionalPropertyTypes": true,
    "verbatimModuleSyntax": true,      // require `import type`
    "erasableSyntaxOnly": true,        // safe for type stripping
    "skipLibCheck": true,              // skip .d.ts in node_modules
    "outDir": "dist",
    "rootDir": "src",
    "declaration": true,               // emit .d.ts (libraries)
    "sourceMap": true
  },
  "include": ["src"],
  "exclude": ["dist", "node_modules"]
}

Code Explained

target — syntax level of the output
module: nodenext — matches how Node really resolves imports
noUncheckedIndexedAccess — catches out-of-range reads
skipLibCheck — faster builds, fewer third-party errors
include — which files belong to the project

⚠ Common Mistakes

  • Leaving strict off and inheriting a pile of hidden anys
  • Mismatched module settings that make imports work in the editor but fail at runtime
  • Forgetting DOM in lib for browser code (or including it in Node-only code)

✓ Tips & Best Practices

  • Turn strictness flags on early; adding them later means fixing hundreds of errors
  • Use tsc --showConfig to see the final merged settings
  • Separate tsconfig.build.json for emitting, base config for editor/checking

Quick Summary

  • strict: true — essential
  • target — output JS level
  • module — import rules
  • lib — known built-in APIs
