Set & WeakSet

Set · add / has / delete · dedupe · union · intersection · difference · WeakSet

Overview

A Set stores unique values of any type in insertion order. It's the fastest way to remove duplicates and to check membership. ES2025 added set algebra methods: union, intersection, difference, symmetricDifference, and subset checks. A WeakSet holds objects weakly.

Notes

  • Uniqueness uses SameValueZero (NaN equals NaN)
  • Objects are unique by reference
  • has is O(1), unlike array.includes
  • Set methods accept any set-like object (has size, has, keys)

Set operations

const s = new Set([1, 2, 2, 3]);    // Set {1, 2, 3}
s.add(4).add(1);                    // 1 ignored (duplicate)
s.has(2);                           // true
s.delete(3);                        // true
s.size;                             // 3

[...new Set(["a", "b", "a"])];      // ["a", "b"]  dedupe

const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);
a.union(b);                         // Set {1, 2, 3, 4}
a.intersection(b);                  // Set {2, 3}
a.difference(b);                    // Set {1}
a.symmetricDifference(b);           // Set {1, 4}
new Set([2]).isSubsetOf(a);         // true
a.isDisjointFrom(new Set([9]));     // true

for (const v of a) {}               // insertion order
const seen = new WeakSet();
seen.add(obj); seen.has(obj);       // true

Code Explained

add ignores values already present
Spread into an array to dedupe
Set methods return new Sets
WeakSet — tag objects without preventing GC

TypeScript

  • Type as Set<string>; the set methods need "lib": ["ES2025"] or "ESNext"
  • new Set(arr) infers its element type from the array

⚠ Common Mistakes

  • Expecting two equal-looking objects to dedupe; they're different references
  • Using array.includes in a loop over large data instead of a Set
  • Calling set methods in old runtimes without checking support

✓ Tips & Best Practices

  • Convert to a Set once, then call has many times
  • Use new Set(arr).size !== arr.length to detect duplicates
  • Dedupe objects by key with a Map: [...new Map(a.map(o => [o.id, o])).values()]

Quick Summary

  • has — fast membership
