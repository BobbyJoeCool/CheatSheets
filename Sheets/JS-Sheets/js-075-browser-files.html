File & Blob APIs (Browser)

input type="file" · File · Blob · FileReader · file.text() · URL.createObjectURL · downloads

Overview

Browsers can't touch the file system directly, but users can hand you files through <input type="file"> or drag and drop. Each is a File (a Blob with a name). Read contents with file.text(), arrayBuffer(), or stream(). To let users download generated data, wrap it in a Blob and link to URL.createObjectURL.

Notes

  • input.files is a FileList; convert with Array.from
  • accept=".csv,image/*" filters the picker (not enforced)
  • Call URL.revokeObjectURL when done to free memory
  • FileReader is the older callback API; blob.text() is simpler

Upload, read, download

// <input type="file" id="picker" accept=".csv" multiple>
picker.addEventListener("change", async () => {
  for (const file of picker.files) {
    file.name; file.size;            // "data.csv", 2048
    const text = await file.text();
    console.log(text.split("\n").length, "rows");
  }
});

dropZone.addEventListener("dragover", e => e.preventDefault());
dropZone.addEventListener("drop", async e => {
  e.preventDefault();
  const [file] = e.dataTransfer.files;
  img.src = URL.createObjectURL(file);     // preview an image
});

function download(name, content, type = "text/plain") {
  const url = URL.createObjectURL(new Blob([content], { type }));
  const a = Object.assign(document.createElement("a"),
    { href: url, download: name });
  a.click();
  URL.revokeObjectURL(url);
}
download("report.json", JSON.stringify(data), "application/json");

Code Explained

file.text() — Promise of the contents as a string
dragover must call preventDefault or drop won't fire
Object URLs — temporary blob: links for previews
download attribute — saves instead of navigating

⚠ Common Mistakes

  • Trusting file.type or accept; validate content on the server
  • Never revoking object URLs, which leaks memory in long-lived pages
  • Forgetting preventDefault on dragover

✓ Tips & Best Practices

  • Show file size with Intl.NumberFormat and unit: "kilobyte"
  • Process huge files with file.stream() instead of text()
  • Upload with FormData and fetch (sheet 102 / 103)

Quick Summary

  • <input type=file> — get Files
  • file.text() — read contents
  • Blob + object URL — downloads
  • revoke URLs when done
