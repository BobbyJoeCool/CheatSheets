Declarations & Expressions

function · return · hoisting · implicit undefined · function expressions · IIFE

Overview

A function declaration (function name() {}) is hoisted, so you can call it before it appears in the file. A function expression assigns a function to a variable and isn't usable until that line runs. Functions return undefined unless they return something. An IIFE runs a function immediately, mostly in legacy code to create a private scope.

Notes

  • Functions are values: store, pass, and return them
  • return with no value returns undefined
  • Named function expressions can refer to themselves by name
  • Modules and block scope replaced most IIFE uses

Declarations, expressions, IIFE

greet("Ana");                        // works: declaration is hoisted
function greet(name) {
  return `Hello, ${name}`;
}

// square(3);                        // ReferenceError (TDZ)
const square = function (n) { return n * n; };
const fact = function f(n) { return n <= 1 ? 1 : n * f(n - 1); };

function log(msg) { console.log(msg); }
log("x");                            // returns undefined

function minMax(arr) {
  return [Math.min(...arr), Math.max(...arr)]; // "multiple" returns
}
const [lo, hi] = minMax([3, 9, 1]);  // 1, 9

(function () {                       // IIFE
  const secret = 42;                 // not visible outside
})();

Code Explained

Declarations hoist with their body
Expressions follow normal const rules (TDZ)
Return an array or object to send back several values
IIFE — define and call in one step

TypeScript

  • Annotate parameters and the return type: function greet(name: string): string
  • Return types are inferred, but explicit ones on exported functions catch mistakes early

⚠ Common Mistakes

  • Putting the return value on a new line after return; ASI returns undefined
  • Calling a function expression before its definition
  • Writing return a, b expecting two values; you get only b

✓ Tips & Best Practices

  • Use declarations for top-level named functions; they read like a table of contents
  • Return objects ({ min, max }) when the values have different meanings
  • Keep functions small enough to describe in one sentence

Quick Summary

  • function f(){} — hoisted declaration
  • const f = function(){} — expression
  • no return — undefined
  • IIFE — run immediately
