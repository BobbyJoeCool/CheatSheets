File Paths (Node)

node:path · join · resolve · basename · extname · import.meta.dirname · fileURLToPath

Overview

Build file paths with the node:path module instead of string concatenation; it handles separators on every OS. In ES modules there's no __dirname; use import.meta.dirname (Node 20.11+) or derive it from import.meta.url. Remember that relative paths resolve from the process's working directory.

Notes

  • path.join normalizes; path.resolve produces an absolute path
  • process.cwd() is where the command was run
  • import.meta.filename is this file's absolute path
  • File URLs (file:///…) and paths are different; convert with fileURLToPath

Path operations

import path from "node:path";
import { fileURLToPath } from "node:url";

path.join("src", "lib", "..", "app.js");   // "src/app.js"
path.resolve("data", "a.txt");             // "/home/me/proj/data/a.txt"
path.basename("/a/b/photo.png");           // "photo.png"
path.basename("/a/b/photo.png", ".png");   // "photo"
path.extname("archive.tar.gz");            // ".gz"
path.dirname("/a/b/c.txt");                // "/a/b"
path.parse("/a/b/c.txt");
// { root: "/", dir: "/a/b", base: "c.txt", ext: ".txt", name: "c" }
path.relative("/a/b", "/a/c/d");           // "../c/d"
path.sep;                                  // "/" (or "\\" on Windows)

const here = import.meta.dirname;          // folder of this module
const data = path.join(here, "data.json"); // works from any cwd
const legacy = path.dirname(fileURLToPath(import.meta.url));
process.cwd();                             // where node was launched

Code Explained

join — combine segments and normalize ..
resolve — absolute path from cwd
parse — all parts at once
import.meta.dirname — ESM replacement for __dirname

TypeScript

  • Identical in TypeScript; import.meta.dirname types need a recent @types/node
  • Set "module": "nodenext" so import.meta is allowed

⚠ Common Mistakes

  • Concatenating with "/", which breaks on Windows
  • Using __dirname in an ES module: ReferenceError
  • Assuming relative paths are relative to the script file

✓ Tips & Best Practices

  • Anchor data files to import.meta.dirname
  • Use path.resolve before comparing paths
  • Guard against ../ traversal: check resolved.startsWith(baseDir)

Quick Summary

  • path.join — combine safely
  • path.resolve — absolute path
  • basename / extname — parts
  • import.meta.dirname — module folder
