Declaration Files

.d.ts · declare · @types · ambient modules · global augmentation · module augmentation

Overview

Declaration files (.d.ts) describe the types of JavaScript code without containing any implementation. Most packages ship their own; others have community types in @types/*. Use declare to describe things that exist at runtime but TS doesn't know about, and augmentation to add to existing global or module types.

Notes

  • .d.ts files contain only types and declare statements
  • tsc --declaration generates them from your .ts code
  • A .d.ts with no import/export adds global declarations
  • Use declare module "x" for untyped packages or file imports

Declarations and augmentation

// types/globals.d.ts
declare const __APP_VERSION__: string;        // injected by bundler
interface Window { analytics?: { track(e: string): void } }

// types/untyped-lib.d.ts
declare module "tiny-slugify" {
  export default function slugify(s: string, sep?: string): string;
}

declare module "*.svg" { const url: string; export default url; }

// augment a module's types (file must be a module)
import "express";
declare module "express" {
  interface Request { user?: { id: number; role: string } }
}

// add globals from inside a module file
declare global { var __DEV__: boolean }

// $ npm i -D @types/node @types/express

Code Explained

declare const — value exists at runtime; trust me
declare module "pkg" — types for an untyped package
Wildcard modules — type asset imports
Module augmentation — add fields to library types
declare global — extend globals from a module file

⚠ Common Mistakes

  • Declaring things that don't actually exist at runtime (types can't create them)
  • Writing augmentation in a non-module file, so it replaces instead of merges
  • Installing @types/x when package x already bundles its types

✓ Tips & Best Practices

  • Check the npm page for the TS badge before installing @types
  • Keep custom declarations in a types/ folder included by tsconfig
  • Write a minimal declare module to unblock yourself, then improve it

Quick Summary

  • .d.ts — types only
  • @types/* — community types
  • declare — describe runtime values
  • augmentation — extend existing types
