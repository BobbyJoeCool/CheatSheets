Arrow Functions

=> · implicit return · returning ({}) · no own this / arguments · not constructible

Overview

Arrow functions are a compact syntax: (params) => expression. A single expression is returned implicitly; use braces and return for multiple statements. Arrows have no own this, arguments, or prototype. They inherit this from the surrounding code, which makes them ideal for callbacks.

Notes

  • One parameter can skip the parentheses: x => x * 2
  • Return an object literal by wrapping it: () => ({ a: 1 })
  • Arrows can't be used with new
  • Avoid arrows as object methods that need this

Arrow syntax forms

const sq = x => x * x;                // implicit return
const add = (a, b) => a + b;
const now = () => Date.now();         // no params
const make = (id) => ({ id, ok: true }); // object literal: wrap in ()
const area = (w, h) => {              // block body: explicit return
  const a = w * h;
  return a;
};

[1, 2, 3].map(n => n * 2);            // [2, 4, 6]

class Timer {
  seconds = 0;
  start() {
    setInterval(() => this.seconds++, 1000);  // arrow keeps this
  }
}

const obj = {
  name: "x",
  bad: () => this.name,               // this is NOT obj
  good() { return this.name; },       // method syntax
};

Code Explained

No braces — the expression is the return value
({ … }) — parentheses stop { being read as a block
Arrow inside a method sees the method's this
Use method syntax for object methods

TypeScript

  • Annotate inline: const add = (a: number, b: number): number => a + b
  • In .tsx files, write generic arrows as <T,>(x: T) => x so the parser doesn't read JSX

⚠ Common Mistakes

  • () => { a: 1 } returns undefined; braces became a block with a label
  • Using an arrow as an object method and getting the wrong this
  • Adding braces but forgetting return

✓ Tips & Best Practices

  • Use arrows for map, filter, event handlers, and promise chains
  • Use class field arrows (handle = () => {}) for handlers passed around
  • Keep implicit-return arrows to one readable line

Quick Summary

  • x => expr — implicit return
  • () => ({}) — return an object
  • lexical this — from surroundings
  • no new, no arguments
