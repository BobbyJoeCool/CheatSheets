Higher-Order Functions

callbacks · returning functions · compose · pipe · currying · partial application

Overview

A higher-order function takes a function as an argument, returns a function, or both. Array methods (map, filter, reduce) are the everyday examples. Building your own lets you compose small functions into pipelines, curry multi-argument functions, and wrap behavior like logging or retries around existing code.

Notes

  • Callbacks are functions passed to be called later
  • Pure functions (no side effects) compose most safely
  • Partial application fixes some arguments up front
  • bind can partially apply too: fn.bind(null, a)

Taking and returning functions

const nums = [1, 2, 3, 4];
nums.filter(n => n % 2).map(n => n * 10);   // [10, 30]

const twice = fn => x => fn(fn(x));
twice(n => n + 3)(1);                       // 7

const compose = (...fns) => x => fns.reduceRight((v, f) => f(v), x);
const pipe = (...fns) => x => fns.reduce((v, f) => f(v), x);
const slug = pipe(s => s.trim(), s => s.toLowerCase(),
                  s => s.replaceAll(" ", "-"));
slug("  Hello World ");                     // "hello-world"

const curry = fn => a => b => fn(a, b);
const add = curry((a, b) => a + b);
add(2)(3);                                  // 5

const withLog = fn => (...args) => {
  console.log("call", args);
  return fn(...args);
};

Code Explained

twice — takes a function, returns a new one
pipe — runs left to right; compose right to left
Curry — one argument at a time
Wrappers add behavior without changing the original

TypeScript

  • Function types: type Fn = (x: number) => number
  • Typing generic pipe/compose fully needs overloads; libraries like Remeda provide them

⚠ Common Mistakes

  • Passing fn() (the result) when the API expects fn (the function)
  • Passing parseInt straight to map: ["1","2","3"].map(parseInt) gives [1, NaN, NaN]
  • Over-abstracting simple code into point-free pipelines nobody can read

✓ Tips & Best Practices

  • Write .map(s => parseInt(s, 10)) to control which arguments are passed
  • Keep each function in a pipeline small and pure
  • Name intermediate functions when a pipeline grows beyond 3 steps

Quick Summary

  • higher-order — takes or returns functions
  • pipe / compose — chain functions
  • curry — one argument at a time
  • wrappers — add behavior
