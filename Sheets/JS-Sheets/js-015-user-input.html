User Input

prompt() · readline/promises · process.argv · process.stdin · parse & validate · Number.isNaN

Overview

Input comes from different places depending on the runtime. In the browser it's usually a form field or prompt(). In Node it's command-line arguments (process.argv) or interactive input through the readline/promises module. Input always arrives as a string, so convert and validate it before use.

Notes

  • prompt() blocks the page and returns null on Cancel
  • process.argv[0] is the node binary, [1] the script
  • Close the readline interface or the process won't exit
  • util.parseArgs handles --flags without a library (sheet 110)

Reading input in Node

import * as readline from "node:readline/promises";
import { stdin as input, stdout as output } from "node:process";

const rl = readline.createInterface({ input, output });
const answer = await rl.question("Your age? ");   // "30"
rl.close();

const age = Number(answer.trim());
if (!Number.isInteger(age) || age < 0) {
  console.error("Please enter a whole number");
  process.exit(1);
}
console.log(`Next year you'll be ${age + 1}`);

// $ node greet.js Ana 3
const [, , name, times] = process.argv;  // "Ana", "3"

Code Explained

readline/promises — question() returns a Promise
.trim() — remove the trailing newline and spaces
Validate with Number.isInteger before using the value
Destructure process.argv, skipping the first two entries

TypeScript

  • Every input is typed string; parse it, then the result narrows to number
  • process.argv and readline types come from @types/node

⚠ Common Mistakes

  • Doing math on input without converting: "2" + 1 is "21"
  • Forgetting rl.close(), so the script hangs after the last question
  • Ignoring null from prompt() when the user cancels

✓ Tips & Best Practices

  • Normalize input first: .trim().toLowerCase()
  • Loop rl.question until the answer validates instead of exiting
  • Read piped input line by line with for await (const line of rl)

Quick Summary
