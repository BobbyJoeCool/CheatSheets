this & Binding

this · call · apply · bind · lost method context · globalThis · strict-mode this

Overview

this is set by how a function is called, not where it's defined (except arrows, which inherit it). As a method (obj.f()), this is obj. Called plainly (f()), it's undefined in strict mode. call, apply, and bind set this explicitly, and new sets it to the new object.

Notes

  • Extracting a method (const f = obj.f) loses its this
  • Modules and classes are strict, so plain calls give undefined
  • bind returns a new function; it doesn't change the original
  • Event handlers set this to the element (non-arrow only)

How this gets set

const user = {
  name: "Ana",
  hi() { return `Hi, ${this.name}`; },
};
user.hi();                       // "Hi, Ana"  (method call)

const f = user.hi;
// f();                          // TypeError: this is undefined

function intro(greeting, punct) {
  return `${greeting}, ${this.name}${punct}`;
}
intro.call(user, "Hello", "!");     // "Hello, Ana!"
intro.apply(user, ["Hey", "?"]);    // "Hey, Ana?"
const bound = intro.bind(user, "Yo");
bound(".");                         // "Yo, Ana."

setTimeout(user.hi, 0);             // loses this
setTimeout(() => user.hi(), 0);     // keeps it
button.addEventListener("click", user.hi.bind(user));

Code Explained

Method call — this is the object before the dot
call(thisArg, ...args) — call now with a this
apply(thisArg, [args]) — same, args as array
bind(thisArg, ...preset) — new function, this fixed

TypeScript

  • Declare this as a fake first parameter: function intro(this: User, greeting: string)
  • noImplicitThis errors when this would be any

⚠ Common Mistakes

  • Passing obj.method as a callback and losing this
  • Using an arrow function as a method and expecting this to be the object
  • Calling bind repeatedly in render loops, creating new functions every time

✓ Tips & Best Practices

  • Wrap in an arrow (() => obj.m()) or bind once when passing methods around
  • Use class-field arrow handlers to avoid binding in constructors
  • Prefer spread over apply: fn(...args)

Quick Summary

  • method call — this = object
  • plain call — undefined (strict)
  • call / apply / bind — set it explicitly
  • arrows — inherit this
