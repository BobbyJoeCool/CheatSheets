Sheet 107

process & Environment

process.argv · process.env · --env-file · process.exit · exit codes · stdin / stdout

Overview

The global process object connects a Node program to its environment: command-line arguments (argv), environment variables (env), standard streams, the working directory, and the exit code. Node can load .env files natively with --env-file, and util.parseArgs parses flags without a library.

Notes

  • process.env values are always strings (or undefined)
  • Set process.exitCode instead of calling exit() so pending output flushes
  • Exit code 0 means success; anything else is failure
  • SIGINT is Ctrl+C; handle it for graceful shutdown

Arguments, env, exit

// $ node --env-file=.env app.js build --port 8080 -v
process.argv.slice(2);   // ["build", "--port", "8080", "-v"]

import { parseArgs } from "node:util";
const { values, positionals } = parseArgs({
  options: { port: { type: "string", default: "3000" },
             verbose: { type: "boolean", short: "v" } },
  allowPositionals: true,
});
// values = { port: "8080", verbose: true }, positionals = ["build"]

const port = Number(process.env.PORT ?? 3000);
const isProd = process.env.NODE_ENV === "production";
if (!process.env.API_KEY) {
  console.error("API_KEY is required");
  process.exitCode = 1;
}

process.stdout.write("no newline");
process.cwd();  process.platform;     // "/proj", "linux"
process.on("SIGINT", async () => { await server.close(); process.exit(0); });

Code Explained

--env-file — loads .env into process.env (Node 20.6+)
parseArgs — typed flags, defaults, short aliases
exitCode = 1 — fail without cutting off output
SIGINT handler — clean shutdown on Ctrl+C

TypeScript

  • process.env.X is string | undefined; validate env at startup (Zod works well)
  • parseArgs infers value types from the options config

⚠ Common Mistakes

  • Using process.env.PORT + 1 and getting "30001"
  • Calling process.exit() right after writing output, truncating it
  • Committing .env files with secrets

✓ Tips & Best Practices

  • Validate all required env vars once at startup and fail fast
  • Commit a .env.example listing the variables without values
  • Return non-zero exit codes from CLIs so scripts can detect failure

Quick Summary

  • process.argv — arguments
  • process.env — config (strings)
  • parseArgs — flag parsing
  • exitCode — signal success/failure
