Sheet 115

Type Aliases & Interfaces

type · interface · extends · declaration merging · type vs interface

Overview

Name your types with type aliases (type) or interfaces (interface). Both describe object shapes and can be extended. Interfaces support declaration merging and extends; type aliases can name anything: unions, tuples, primitives, mapped and conditional types. Use whichever your team prefers for objects and type for everything else.

Notes

  • Interfaces with the same name merge automatically
  • extends on interfaces reports conflicts clearly
  • Intersections (&) combine type aliases
  • Both are erased at runtime

type vs interface

interface User {
  id: number;
  name: string;
}
interface Admin extends User {          // inheritance
  permissions: string[];
}

type Point = { x: number; y: number };
type Point3D = Point & { z: number };   // intersection
type ID = string | number;              // union: type only
type Pair = [string, number];           // tuple: type only
type Handler = (e: Event) => void;      // function type

interface Window { appVersion: string } // merges with built-in Window
window.appVersion = "1.2.0";            // now allowed

const a: Admin = { id: 1, name: "Bo", permissions: ["write"] };
function move(p: Point): Point3D { return { ...p, z: 0 }; }

interface Repo<T> { find(id: ID): T | undefined }  // generic

Code Explained

interface X extends Y — add fields to a base
type A = B & C — combine with intersection
Unions, tuples, functions — need type
Merging — extend global or library interfaces
Both can be generic

⚠ Common Mistakes

  • Accidentally merging two interfaces with the same name in one scope
  • Using huge & intersections whose conflicts produce never fields
  • Mixing styles randomly across a codebase

✓ Tips & Best Practices

  • Pick a convention and enforce it with typescript-eslint consistent-type-definitions
  • Use interfaces for objects that classes implement
  • Name types as nouns; avoid I prefixes like IUser

Quick Summary

  • type — name any type
  • interface — object shapes, mergeable
  • extends / & — combine
  • both erased at runtime
