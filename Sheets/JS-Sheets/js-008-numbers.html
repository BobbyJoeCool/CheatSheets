Sheet 008

Numbers

Number · 1_000 · 0x 0b 0o · NaN · Infinity · MAX_SAFE_INTEGER · EPSILON · float precision

Overview

JavaScript has one number type, Number, a 64-bit IEEE 754 float used for both integers and decimals. Integers are exact up to Number.MAX_SAFE_INTEGER (2⁵³−1); beyond that, use BigInt. Floating-point rounding means 0.1 + 0.2 !== 0.3, and invalid math produces NaN rather than throwing.

Notes

  • NaN is the only value not equal to itself
  • Division by zero gives Infinity, not an error
  • -0 exists; Object.is(-0, 0) is false
  • Numeric separators _ are just for readability

Literals and special values

const big = 1_000_000;           // 1000000
const hex = 0xff;                // 255
const bin = 0b1010;              // 10
const oct = 0o17;                // 15
const sci = 2.5e3;               // 2500

0.1 + 0.2;                       // 0.30000000000000004
0.1 + 0.2 === 0.3;               // false
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON;  // true

1 / 0;                           // Infinity
"abc" * 2;                       // NaN
Number.isNaN(NaN);               // true
Number.isInteger(5.0);           // true
Number.isSafeInteger(2 ** 53);   // false
Number.MAX_SAFE_INTEGER;         // 9007199254740991

Code Explained

Prefixes 0x, 0b, 0o — hex, binary, octal
Number.EPSILON — tolerance for float comparison
Number.isNaN — reliable; global isNaN coerces first
Past 2⁵³, consecutive integers can't be represented

TypeScript

  • One number type for all of these; there's no int or float
  • Literal types like type Dice = 1 | 2 | 3 | 4 | 5 | 6 restrict values

⚠ Common Mistakes

  • Comparing floats with ===; compare the difference against a tolerance
  • Storing money as floats; use integer cents or a decimal library
  • Checking x === NaN, which is always false; use Number.isNaN(x)

✓ Tips & Best Practices

  • Round for display with toFixed, but keep full precision in calculations
  • Use BigInt for IDs or counters that can exceed 2⁵³
  • Write large literals with _ separators: 1_000_000

Quick Summary

  • Number — one 64-bit float type
  • NaN — invalid result, never equals itself
  • Infinity — overflow or ÷ 0
  • MAX_SAFE_INTEGER — exact-integer limit
