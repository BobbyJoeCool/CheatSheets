Sheet 033

for Loops

for · counters · multiple variables · nested loops · reverse loops · let in loop closures

Overview

The classic for loop has three parts: an initializer, a condition checked before each pass, and an update run after each pass. Use it when you need the index, a custom step, or reverse order. For simply visiting every element, for...of (sheet 034) is cleaner.

Notes

  • All three parts are optional: for (;;) loops forever
  • Declare the counter with let so each iteration gets its own copy
  • arr.length is re-read every pass, so modifying the array changes the loop
  • Loop backward when removing items by index

for loop variants

for (let i = 0; i < 5; i++) {
  console.log(i);                // 0 1 2 3 4
}

const arr = ["a", "b", "c"];
for (let i = 0; i < arr.length; i++) {
  console.log(i, arr[i]);        // 0 "a", 1 "b", 2 "c"
}

for (let i = arr.length - 1; i >= 0; i--) {}   // reverse
for (let i = 0; i <= 100; i += 10) {}          // step by 10
for (let i = 0, j = 9; i < j; i++, j--) {}     // two counters

for (let r = 0; r < 3; r++) {                  // nested: grid
  for (let c = 0; c < 3; c++) {
    grid[r][c] = r * 3 + c;
  }
}

for (var k = 0; k < 3; k++) setTimeout(() => console.log(k)); // 3 3 3
for (let k = 0; k < 3; k++) setTimeout(() => console.log(k)); // 0 1 2

Code Explained

i < arr.length — stops before the out-of-range index
Reverse loops — start at length - 1, condition >= 0
Comma lets you update two counters
let creates a fresh binding per iteration; var shares one

TypeScript

  • The counter is inferred as number; no annotation needed
  • With noUncheckedIndexedAccess, arr[i] is T | undefined even inside the loop

Common Forms

⚠ Common Mistakes

  • Off-by-one: i <= arr.length reads one past the end (undefined)
  • Using var for the counter with async callbacks inside
  • Removing items with splice while looping forward, which skips elements

✓ Tips & Best Practices

  • Cache length in hot loops only if profiling says so; engines optimize it already
  • Reach for for...of or array methods first; use for when you need index control
  • Name nested counters meaningfully (row, col) instead of i, j

Quick Summary

  • for (init; cond; update) — classic loop
  • let i — fresh per iteration
  • reverse — i-- from length - 1
  • use for index or step control
