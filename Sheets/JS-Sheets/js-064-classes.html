Sheet 064

Classes & Objects

class · new · methods · instanceof · class expressions · not hoisted

Overview

A class is a template for creating objects with shared methods. Define it with class Name { … }, create instances with new, and put shared behavior in methods. Class bodies always run in strict mode. Unlike function declarations, classes aren't hoisted, so define them before use.

Notes

  • Class names use PascalCase
  • Methods are non-enumerable and live on the prototype
  • Calling a class without new throws a TypeError
  • Classes can be expressions: const A = class {}

A complete minimal class

class BankAccount {
  owner;                              // public field
  balance = 0;                        // field with default

  constructor(owner) {
    this.owner = owner;
  }

  deposit(amount) {
    if (amount <= 0) throw new RangeError("amount must be > 0");
    this.balance += amount;
    return this;                      // allows chaining
  }

  toString() { return `${this.owner}: $${this.balance}`; }
}

const acct = new BankAccount("Ana");
acct.deposit(50).deposit(25);
acct.balance;                         // 75
`${acct}`;                            // "Ana: $75"
acct instanceof BankAccount;          // true
// BankAccount("x");                  // TypeError: needs new

Code Explained

Fields — declared at the top, set before the constructor body runs
constructor — runs once per new
Methods — shared through the prototype
return this — enables method chaining

TypeScript

  • Fields must be declared with types: balance: number = 0
  • strictPropertyInitialization errors if a field isn't set in the constructor or with a default

⚠ Common Mistakes

  • Forgetting this. inside methods and reading a global or undeclared variable
  • Passing a method as a callback and losing this (sheet 047)
  • Using a class when a plain function or object would do

✓ Tips & Best Practices

  • Implement toString() for readable logging and template output
  • Keep constructors simple; put logic in methods or static factories
  • Validate inputs in the constructor so invalid instances never exist

Quick Summary

  • class X {} — define
  • new X() — instantiate
  • fields + methods — state + behavior
  • not hoisted — define before use
