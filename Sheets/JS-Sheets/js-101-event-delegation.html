Sheet 101

Propagation & Delegation

capture · bubble · stopPropagation · delegation with closest() · CustomEvent · dispatchEvent

Overview

Most events propagate: they travel down from window to the target (capture phase), then back up (bubble phase). Because events bubble, one listener on a parent can handle events for all its children. This is event delegation: efficient, and it works for elements added later. You can also dispatch your own CustomEvents.

Notes

  • Listeners run in the bubble phase by default
  • { capture: true } runs during the capture phase
  • focus, blur, mouseenter, mouseleave don't bubble
  • stopPropagation hides events from other code; use sparingly

Bubbling and delegation

// <ul id="todos"><li><span>Buy milk</span><button class="del">×</button></li>…</ul>
const todos = document.querySelector("#todos");

todos.addEventListener("click", e => {          // one listener for all
  const del = e.target.closest(".del");
  if (!del || !todos.contains(del)) return;
  del.closest("li").remove();
});

child.addEventListener("click", e => e.stopPropagation()); // parent won't hear
document.addEventListener("click", logAll, { capture: true }); // runs first

const evt = new CustomEvent("cart:add", {
  detail: { id: 7, qty: 2 }, bubbles: true,
});
button.dispatchEvent(evt);
document.addEventListener("cart:add", e => updateBadge(e.detail.qty));

Code Explained

closest — find the relevant element from whatever was clicked
contains check — ignore matches outside the container
Capture listeners run before bubble listeners
CustomEvent — detail carries your data

TypeScript

  • Type custom events as CustomEvent<{ id: number; qty: number }>
  • Add them to DocumentEventMap via declaration merging so listeners get typed detail

⚠ Common Mistakes

  • Checking e.target.matches(".del") when the click lands on an icon inside the button; use closest
  • Calling stopPropagation everywhere and breaking analytics or delegation elsewhere
  • Delegating events that don't bubble (focus) instead of their bubbling versions

✓ Tips & Best Practices

  • Delegate for lists, tables, and anything rendered dynamically
  • Namespace custom event names (cart:add) to avoid collisions
  • Set bubbles: true on custom events meant for delegation

Quick Summary

  • bubbling — events travel up
  • delegation — one parent listener
  • closest — find the real target
  • CustomEvent — your own events
