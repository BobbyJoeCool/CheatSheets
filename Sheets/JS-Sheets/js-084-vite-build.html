Vite & Build Tools

npm create vite · dev server · HMR · vite build · import.meta.env · esbuild / Rollup

Overview

Vite is the standard dev server and build tool for front-end JavaScript. In development it serves native ES modules with instant hot module replacement (HMR); for production, vite build bundles, minifies, and tree-shakes into dist/. Environment variables prefixed VITE_ are exposed through import.meta.env.

Notes

  • Templates exist for vanilla, React, Vue, Svelte, Solid, and more
  • Files in public/ are copied as-is
  • Only VITE_* env vars reach browser code; others stay private
  • esbuild and Rollup do the heavy lifting under the hood

Create, configure, build

$ npm create vite@latest my-app -- --template vanilla
$ cd my-app && npm install
$ npm run dev            # http://localhost:5173 with HMR
$ npm run build          # → dist/
$ npm run preview        # serve dist/ locally

// vite.config.js
import { defineConfig } from "vite";
export default defineConfig({
  server: { port: 3000, proxy: { "/api": "http://localhost:8080" } },
  build: { outDir: "dist", sourcemap: true },
  resolve: { alias: { "@": "/src" } },
});

// .env
VITE_API_URL=https://api.example.com
// src/main.js
const api = import.meta.env.VITE_API_URL;
import.meta.env.DEV;     // true in dev server
import.meta.env.MODE;    // "development" / "production"

Code Explained

npm create vite — scaffolds a project
proxy — forward API calls in dev to avoid CORS
alias — import x from "@/x.js"
import.meta.env — build-time constants

TypeScript

  • Vite strips types but doesn't type-check; run tsc --noEmit in CI or a script
  • Declare custom env vars in vite-env.d.ts to type import.meta.env

⚠ Common Mistakes

  • Putting secrets in VITE_ variables; they end up in public bundles
  • Deploying the project root instead of dist/
  • Assuming a successful build means no type errors

✓ Tips & Best Practices

  • Use npm run preview to test the production build before deploying
  • Lazy-load routes with import() for smaller first loads
  • Inspect bundle size with rollup-plugin-visualizer

Quick Summary

  • npm create vite — scaffold
  • vite — dev server + HMR
  • vite build — production bundle
  • import.meta.env.VITE_* — env vars
