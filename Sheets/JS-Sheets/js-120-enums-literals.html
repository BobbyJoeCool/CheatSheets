Enums & Literal Unions

enum · const enum · string enums · literal unions · as const objects · erasableSyntaxOnly

Overview

An enum names a set of constants and, unlike most TS features, generates runtime code. Numeric enums auto-increment; string enums need explicit values. Many teams now prefer literal unions or an as const object, which give the same safety with no generated code and work with type stripping (erasableSyntaxOnly).

Notes

  • Numeric enums create a reverse mapping (value → name)
  • const enum inlines values but breaks with isolated-module tools
  • Enums are nominal: a plain string isn't assignable to a string enum
  • Enums aren't allowed under erasableSyntaxOnly

Enums and their alternatives

enum Direction { Up, Down, Left, Right }       // 0, 1, 2, 3
Direction.Up;              // 0
Direction[0];              // "Up" (reverse mapping)

enum Status {
  Active = "ACTIVE",
  Banned = "BANNED",
}
function setStatus(s: Status) {}
setStatus(Status.Active);
// setStatus("ACTIVE");    // error: string isn't Status

type StatusU = "ACTIVE" | "BANNED";            // literal union
function setStatus2(s: StatusU) {}
setStatus2("ACTIVE");      // OK, autocompletes

const Role = {                                 // as const object
  Admin: "admin",
  User: "user",
} as const;
type Role = (typeof Role)[keyof typeof Role];  // "admin" | "user"
Role.Admin;                                    // usable at runtime
Object.values(Role);       // ["admin", "user"]

Code Explained

Numeric enum — values start at 0
String enum — explicit values, no reverse map
Literal union — zero runtime cost
as const object — runtime values plus a derived union type
Same name for value and type is allowed

⚠ Common Mistakes

  • Using numeric enums and passing any number without error in older TS versions
  • Using const enum with Babel/esbuild/Vite, which compile files in isolation
  • Comparing a string enum to raw strings from an API without mapping

✓ Tips & Best Practices

  • Default to literal unions; reach for as const objects when you need runtime values
  • Turn on erasableSyntaxOnly to keep code compatible with type stripping
  • Validate external strings into your union type with Zod z.enum

Quick Summary

  • enum — named constants, runtime code
  • string enums — explicit values
  • literal unions — zero cost
  • as const object — values + type
