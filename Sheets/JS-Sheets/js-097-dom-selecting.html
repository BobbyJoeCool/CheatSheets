Sheet 097

Selecting & Traversing

querySelector · querySelectorAll · getElementById · closest · parent / children · NodeList vs HTMLCollection

Overview

The DOM is the browser's object tree for the page. querySelector returns the first element matching a CSS selector, and querySelectorAll returns a static NodeList of all matches. From any element you can move up (parentElement, closest), down (children, firstElementChild), and sideways (nextElementSibling).

Notes

  • querySelector returns null when nothing matches
  • querySelectorAll results don't update when the page changes
  • getElementsByClassName returns a live HTMLCollection
  • Scope searches to an element: form.querySelector("input")

Selecting and traversing

const title = document.querySelector("h1");
const btn = document.querySelector("#save");             // by id
const items = document.querySelectorAll(".item");        // NodeList
const firstLink = document.querySelector("nav a[href^='http']");
const byId = document.getElementById("save");            // fastest

items.forEach(el => el.classList.add("ready"));          // NodeList has forEach
[...items].map(el => el.textContent);                    // to array

const card = btn.closest(".card");          // nearest ancestor match
card.parentElement;                         // up one level
card.children;                              // HTMLCollection of elements
card.firstElementChild;  card.lastElementChild;
card.nextElementSibling;                    // next element
card.querySelector(".price");               // search inside card

btn.matches(".primary");                    // true/false
document.querySelector(".missing")?.remove();   // safe when null

Code Explained

Any CSS selector works, including attributes and pseudo-classes
Spread a NodeList to use array methods
closest — walks up, including the element itself
Use ?. when an element may not exist

TypeScript

  • querySelector returns Element | null; tag selectors infer types ("input" → HTMLInputElement)
  • For other selectors pass a generic: querySelector<HTMLButtonElement>("#save")

⚠ Common Mistakes

  • Running selection code before the DOM exists; use defer or type="module" scripts
  • Using childNodes/nextSibling and getting whitespace text nodes
  • Calling methods on a null result from querySelector

✓ Tips & Best Practices

  • Prefer data-* attributes as JS hooks: [data-action="save"]
  • Cache elements you use repeatedly in variables
  • Use element.querySelector to keep searches local and fast

Quick Summary

  • querySelector — first match
  • querySelectorAll — static list
  • closest — nearest ancestor
  • children / parentElement — move around
