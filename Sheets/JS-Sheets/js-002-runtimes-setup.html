Sheet 002

Runtimes & Project Setup

browser · Node.js · Deno · Bun · nvm · npm init · "type": "module"

Overview

You can run JavaScript in any browser with no setup, but real projects use a runtime (usually Node.js) and npm to manage packages. A project is just a folder with a package.json. Setting "type": "module" there makes every .js file an ES module, which is what modern code expects.

Notes

  • Install Node from nodejs.org or through a version manager like nvm or fnm
  • Use an LTS (even-numbered) Node release for real work
  • npm ships with Node; pnpm, yarn, and bun are alternatives
  • Deno and Bun include a formatter, test runner, and TS support out of the box

New project from scratch

$ nvm install --lts          # install latest LTS Node
$ node --version             # v24.x.x
$ npm --version              # 11.x.x

$ mkdir my-app && cd my-app
$ npm init -y                # creates package.json

// package.json
{
  "name": "my-app",
  "type": "module",          // .js files are ES modules
  "scripts": { "start": "node index.js" }
}

$ npm start                  # runs node index.js

Code Explained

nvm install --lts — installs and switches to the current LTS
npm init -y — accepts all defaults
"type": "module" — enables import/export in .js files
scripts — named commands run with npm run <name>

TypeScript

  • npm i -D typescript then npx tsc --init creates tsconfig.json
  • Deno, Bun, and recent Node versions run .ts directly by stripping types (no type checking)

Runtimes Compared

Runtime Run a file Notes
Node.js node app.js largest ecosystem
Deno deno run app.ts secure by default, permissions flags
Bun bun app.ts fast, npm-compatible
Browser <script src> no file system access

Setup Commands

Command Does
nvm ls list installed Node versions
nvm use 22 switch version
npm init -y new package.json
npm i <pkg> add a dependency
npx <tool> run a package binary

⚠ Common Mistakes

  • Installing Node with the system package manager and getting an outdated version
  • Leaving out "type": "module", so import fails with "Cannot use import statement outside a module"
  • Committing node_modules/; add it to .gitignore

✓ Tips & Best Practices

  • Add an .nvmrc file with the Node version so teammates match
  • Use node --env-file=.env instead of the dotenv package on modern Node
  • Run npm doctor if installs behave strangely

Quick Summary

  • nvm — manage Node versions
  • npm init — create package.json
  • "type": "module" — modern module mode
  • npx — run tools without global installs
