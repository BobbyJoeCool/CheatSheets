Events

addEventListener · event object · target vs currentTarget · once / passive · removeEventListener · preventDefault

Overview

addEventListener(type, handler, options) runs a handler whenever an event fires. The handler receives an event object with details: target (what was actually interacted with), currentTarget (the element the listener is on), key or mouse info, and methods like preventDefault() to stop the browser's default action.

Notes

  • Use the same function reference to remove a listener
  • once: true removes the listener after the first call
  • passive: true promises not to call preventDefault (smoother scrolling)
  • Avoid inline onclick="…" attributes

Listening for events

const btn = document.querySelector("#buy");

function onClick(event) {
  event.target;            // element clicked (may be a child)
  event.currentTarget;     // btn
  event.type;              // "click"
}
btn.addEventListener("click", onClick);
btn.removeEventListener("click", onClick);   // same reference

btn.addEventListener("click", () => track("buy"), { once: true });

form.addEventListener("submit", e => {
  e.preventDefault();      // stop page reload
  save(new FormData(form));
});

document.addEventListener("keydown", e => {
  if (e.key === "Escape") closeModal();
  if (e.ctrlKey && e.key === "s") { e.preventDefault(); save(); }
});

window.addEventListener("scroll", onScroll, { passive: true });

Code Explained

target vs currentTarget — origin vs listener's element
once — auto-remove after one call
preventDefault — cancel default action (submit, link, key)
e.key — readable key names

TypeScript

  • Event types are inferred from the name: "keydown" → KeyboardEvent, "click" → MouseEvent
  • e.target is EventTarget | null; cast or check instanceof HTMLElement

⚠ Common Mistakes

  • Removing a listener with a new arrow function; it never matches
  • Forgetting preventDefault on form submit and losing state to a reload
  • Using e.target when a child element was clicked and you needed the button

✓ Tips & Best Practices

  • Use currentTarget when the listener is on a container with children
  • Clean up many listeners with one AbortController signal
  • Prefer pointer* events to handle mouse, touch, and pen together
