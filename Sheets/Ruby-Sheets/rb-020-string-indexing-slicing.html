Indexing, Slicing and Splitting

str[...] accepts an index, a start and length, a range, a substring, or a regex. Negative indexes count from the end. split breaks a string into an array, and chars, each_char and each_line walk through it piece by piece.

Slicing Notes

  • Indexes count characters, not bytes
  • Out-of-range reads return nil, never raise
  • split with no argument splits on whitespace and drops empties
  • str[i] = "x" assigns into a mutable string

Index, Slice, Split

s = "Ruby on Rails"
s[0]                          # "R"
s[-1]                         # "s"
s[0, 4]                       # "Ruby" (start, length)
s[0..3]                       # "Ruby"
s[5..]                        # "on Rails" (endless range)
s[-5..]                       # "Rails"
s[100]                        # nil
s["on"]                       # "on" (or nil)
s[/R\w+$/]                    # "Rails"

"a,b,,c".split(",")           # ["a", "b", "", "c"]
"a b  c".split                # ["a", "b", "c"]
"a,b,c".split(",", 2)         # ["a", "b,c"]
"2026-10-17".split("-").map(&:to_i)  # [2026, 10, 17]
"hey".chars                   # ["h", "e", "y"]
"one\ntwo".lines              # ["one\n", "two"]
"one\ntwo".each_line(chomp: true) { |l| puts l }

t = +"cat"
t[0] = "b"                    # t == "bat"

Code Explained

s[0, 4] — start and length
s[5..] / s[-5..] — endless ranges for "to the end"
s["on"] — returns the substring if present, else nil
split(",", 2) — limit the number of parts
each_line(chomp: true) — lines without trailing newlines

The Ruby Way

  • s[s.length - 1] → s[-1]
  • s[3, s.length - 3] → s[3..]
  • s.split("") → s.chars

In Rails

  • AS · "Ruby".first(2) → "Ru", "Ruby".last(2) → "by"
  • AS · "hello".from(2) → "llo", "hello".to(1) → "he"
  • AS · "one two three".truncate_words(2) → "one two..."

Slice Forms

FormExample → Result
[i]"ruby"[1] → "u"
[start, len]"ruby"[1, 2] → "ub"
[range]"ruby"[1..2] → "ub"
[-n..]"ruby"[-2..] → "by"
[str]"ruby"["by"] → "by"
[regex, n]"a1b2"[/(\d)b(\d)/, 2] → "2"

Split Variants

CallResult
"a b".split["a", "b"]
"a-b".split("-")["a", "b"]
"a1b22c".split(/\d+/)["a", "b", "c"]
"a,b,".split(",")["a", "b"]
"a,b,".split(",", -1)["a", "b", ""]

⚠ Common Mistakes

  • Expecting split(",") to keep trailing empty fields; pass -1 as the limit for CSV-like data
  • Confusing s[1, 2] (start + length) with s[1..2] (start..end)
  • Slicing by byte offsets from index on multibyte text; use byteslice for byte positions

✓ Tips & Best Practices

  • partition("=") splits once into [before, sep, after]; great for key=value
  • Use each_char instead of chars on huge strings to avoid building an array
  • Real CSV has quoting rules; use the csv library (sheet 077) rather than split(",")

Quick Summary

  • s[i] / s[a, n] / s[a..b] — index / length / range
  • negative index — from the end
  • split — to an array
  • chars / lines — per char / per line
