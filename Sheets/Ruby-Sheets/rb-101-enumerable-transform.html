Enumerable: Iterate and Transform

Enumerable is the mixin behind Array, Hash, Range, Set and any class that defines each. Its transform methods build new collections: map converts each element, flat_map maps and flattens one level, filter_map maps and drops nil/false, and each_with_object accumulates into an object you choose.

Notes

  • These return new arrays; the receiver is unchanged
  • map! / select! exist on Array for in-place versions
  • Without a block, most methods return an Enumerator
  • with_index(1) adds a 1-based counter to any of them

Transforming Collections

nums = [1, 2, 3, 4]
nums.map { it * 10 }                    # [10, 20, 30, 40]
nums.each_with_index.map { |n, i| n * i }   # [0, 2, 6, 12]
nums.map.with_index(1) { |n, i| "#{i}. #{n}" }  # ["1. 1", "2. 2", …]

[[1, 2], [3]].flat_map { it.map(&:succ) }   # [2, 3, 4]
%w[a1 b c3].filter_map { it[/\d/]&.to_i }   # [1, 3]

words = %w[apple avocado banana]
words.each_with_object(Hash.new(0)) { |w, h| h[w[0]] += 1 }
# {"a" => 2, "b" => 1}

nums.zip(%w[a b c d])                   # [[1, "a"], [2, "b"], …]
nums.each_slice(2).map(&:sum)           # [3, 7]
{ a: 1, b: 2 }.map { |k, v| "#{k}=#{v}" }   # ["a=1", "b=2"]
(1..3).map { it ** 2 }                  # [1, 4, 9]

Code Explained

map — one output per input
each_with_index.map — use the index while mapping
flat_map — map then flatten one level
filter_map — map and drop falsy results in one pass
each_with_object(obj) — accumulate into obj, returned at the end

The Ruby Way

  • result = []; arr.each { result << f(x) } → arr.map { f(it) }
  • map { }.compact → filter_map { }
  • inject({}) { |h, x| h[x] = 1; h } → each_with_object({})

In Rails

  • Rails · User.pluck(:email) selects one column in SQL; User.all.map(&:email) loads every record
  • Rails · find_each iterates large tables in batches of 1000

⚠ Common Mistakes

  • Using each and expecting a transformed array; each returns the original receiver
  • Mutating inside map (map { it << x }); you change the originals and get them back too
  • Forgetting that map on a Hash returns an Array; add .to_h or use transform_values

✓ Tips & Best Practices

  • Chain without blocks: arr.each_with_index.select { |x, i| i.even? }.map(&:first)
  • sum, min_by, tally (sheet 103) replace many hand-rolled each_with_object loops
  • Any class with each + include Enumerable gets all of these (sheet 106)

Quick Summary

  • map — transform each
  • flat_map / filter_map — map + flatten / map + filter
  • each_with_object — accumulate
  • with_index(1) — numbered iteration
