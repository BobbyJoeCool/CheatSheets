Integers

Ruby has a single Integer class with arbitrary precision, so integers never overflow; huge values just use more memory. Integers are objects with methods (10.even?, 255.to_s(2)). Division between two integers floors toward negative infinity.

Integer Facts

  • Underscores improve readability: 1_000_000
  • Prefixes: 0x hex, 0b binary, 0o octal
  • 7 / 2 is 3; -7 / 2 is -4 (floors)
  • Integers are immutable and frozen

Integer Basics

big = 2 ** 100              # 1267650600228229401496703205376
1_000_000.class             # Integer
0xff                        # 255
0b1010                      # 10
0o17                        # 15
255.to_s(2)                 # "11111111"
"ff".to_i(16)               # 255

7 / 2                       # 3
-7 / 2                      # -4 (floor division)
7 % 3                       # 1
7.divmod(2)                 # [3, 1]
7.fdiv(2)                   # 3.5

10.even?                    # true
1234.digits                 # [4, 3, 2, 1]
3.pow(4, 5)                 # 1  (3**4 % 5, fast)
Integer.sqrt(17)            # 4
-5.abs                      # 5

Code Explained

2 ** 100 — no overflow; Ruby switches to bignum math internally
to_s(2) / to_i(16) — convert between bases
-7 / 2 — floors, unlike C or Java (which give -3)
divmod — quotient and remainder together
pow(b, mod) — modular exponent without huge intermediates

The Ruby Way

  • 1000000 → 1_000_000
  • x % 2 == 0 → x.even?
  • (a.to_f / b) → a.fdiv(b)

In Rails

  • AS · 5.minutes, 2.hours, 1.day build ActiveSupport::Duration values
  • AS · 3.days.ago / 2.weeks.from_now return times
  • Rails · views use number_with_delimiter(1234567) → "1,234,567"
  • AS · 1.kilobyte / 5.megabytes for size limits

⚠ Common Mistakes

  • Expecting 5 / 2 to be 2.5; integer division drops the fraction. Use fdiv or a float operand
  • Porting code from C/Java and getting different results for negative division and modulo
  • Calling Math.sqrt on huge integers; it returns a float and loses precision. Use Integer.sqrt

✓ Tips & Best Practices

  • Use Integer#digits for digit-sum style puzzles instead of string conversion
  • rand(1..6) gives a random integer in a range
  • Integer("0x1A") reads base prefixes (26), but "0x1A".to_i is 0; use "1A".hex or to_i(16) for bare hex

Quick Summary

  • Integer — arbitrary precision
  • / — floor division for integers
  • divmod / fdiv — both parts / float result
  • to_s(base) — base conversion
