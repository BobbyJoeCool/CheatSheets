Parameters and Keyword Arguments

Ruby methods take positional parameters (required or with defaults) and keyword parameters (name:), which can also be required or optional. Keywords make call sites self-documenting and order-independent. Since Ruby 3.0, keywords and positional hashes are fully separated.

Parameter Rules

  • Defaults can use earlier params: def f(a, b = a * 2)
  • Required keyword: def f(name:) (no default)
  • Wrong count → ArgumentError (wrong number of arguments)
  • Unknown keyword → ArgumentError (unknown keyword: :x)

Positional and Keyword Params

def greet(name, greeting = "Hello")
  "#{greeting}, #{name}!"
end
greet("Ada")                     # "Hello, Ada!"
greet("Ada", "Hi")               # "Hi, Ada!"

def connect(host, port: 5432, ssl: false)
  "#{host}:#{port} ssl=#{ssl}"
end
connect("db")                    # "db:5432 ssl=false"
connect("db", ssl: true)         # "db:5432 ssl=true"
connect("db", ssl: true, port: 1) # order doesn't matter

def create_user(email:, role: :member)   # email required
  [email, role]
end
create_user(email: "a@b.c")      # ["a@b.c", :member]
create_user                      # ArgumentError: missing keyword: :email
create_user(email: "x", admin: 1) # ArgumentError: unknown keyword: :admin

Code Explained

greeting = "Hello" — optional positional with a default
port: 5432 — optional keyword
email: — required keyword (no default)
unknown keywords — rejected, which catches typos

The Ruby Way

  • def resize(w, h, keep_ratio, crop) → keywords: resize(w, h, crop: true)
  • def f(opts = {}) + opts[:x] → def f(x: nil)
  • Boolean positional args (save(true)) → save(validate: true)

⚠ Common Mistakes

  • Passing a hash where keywords are expected: f(opts) doesn't work since 3.0; use f(**opts)
  • Mutable defaults are rebuilt each call, so def f(list = []) is safe in Ruby (unlike Python); don't add workarounds
  • Too many positional params; past three, callers can't tell which argument is which

✓ Tips & Best Practices

  • Make any boolean or "mode" argument a keyword
  • method(:connect).parameters lists every parameter and its kind
  • Required keywords give clear errors: missing keyword: :email

Quick Summary

  • a = default — optional positional
  • k: / k: v — required / optional keyword
  • keywords — order-independent, self-documenting
  • 3.0+ — keywords and hashes separated
