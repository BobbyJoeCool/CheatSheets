Bitwise Operators

Integers support bitwise AND, OR, XOR, NOT and shifts, operating on two's-complement bit patterns of any size. Because Ruby integers never overflow, left shifts grow the number instead of wrapping. Integer#[] reads single bits, and to_s(2) shows the pattern.

Bit Notes

  • ~n equals -n - 1 (two's complement)
  • >> on negatives fills with sign bits (arithmetic shift)
  • bit_length is bits needed, excluding the sign

Bit Operations

a = 0b1100              # 12
b = 0b1010              # 10
a & b                   # 8   (0b1000)
a | b                   # 14  (0b1110)
a ^ b                   # 6   (0b0110)
~a                      # -13
a << 2                  # 48  (0b110000)
a >> 2                  # 3   (0b11)

12.to_s(2)              # "1100"
format("%08b", 12)      # "00001100"
12[2]                   # 1  (bit 2 is set)
12[0]                   # 0
255.bit_length          # 8
0b1111.allbits?(0b0101) # true
0b1000.anybits?(0b1100) # true

READ, WRITE, EXEC = 1, 2, 4
perms = READ | WRITE    # 3
perms & WRITE != 0      # true
perms &= ~WRITE         # 1 (clear WRITE)

Code Explained

& | ^ — AND, OR, XOR per bit
~a — invert all bits (-a - 1)
<< — grows without overflow
12[2] — read bit 2 directly
allbits? / anybits? / nobits? — mask tests

The Ruby Way

  • (n & mask) == mask → n.allbits?(mask)
  • (n >> i) & 1 → n[i]
  • n.to_s(2).rjust(8, "0") → format("%08b", n)

⚠ Common Mistakes

  • Expecting 32-bit wrap-around from C or Java; 1 << 40 is just a big number. Mask with & 0xFFFF_FFFF
  • Printing ~n and expecting an unsigned value; ~12 is -13. Mask it: ~12 & 0xFF → 243
  • Using ^ as exponent; it's XOR. Power is **

✓ Tips & Best Practices

  • For a set of named flags, consider Set of symbols; use bits when storing or sending compactly
  • Integer("0b1010") and "1010".to_i(2) both parse binary strings
  • See the Bitwise set for algorithms (popcount, masks, subsets)

Quick Summary

  • & \| ^ ~ — bit logic
  • << >> — shifts, no overflow
  • n[i] — read a bit
  • allbits? / anybits? — mask tests
