if, elsif, else, unless

Conditionals test truthiness (only nil and false are falsy). if is an expression that returns the value of the branch that ran, so you can assign its result. unless means "if not" and reads well for a single negative condition.

Conditional Notes

  • It's elsif, not elseif or else if
  • then lets a branch fit on one line
  • An if with no matching branch returns nil
  • Avoid unless ... else; flip it to if

Conditionals

temp = 72
if temp > 85
  puts "hot"
elsif temp > 60
  puts "nice"             # nice
else
  puts "cold"
end

status = if temp > 60 then "warm" else "cool" end  # "warm"

unless logged_in?
  redirect_to_login
end

grade =
  if    score >= 90 then "A"
  elsif score >= 80 then "B"
  else                   "C"
  end

if (m = line.match(/(\d+)/))   # assign + test
  puts m[1]
end

Code Explained

elsif — the only spelling Ruby accepts
status = if ... — if returns the chosen branch's value
unless — runs when the condition is falsy
then — single-line branches
if (m = ...) — parentheses mark intentional assignment

The Ruby Way

  • if !valid? → unless valid?
  • x = nil; if c then x = 1 else x = 2 end → x = if c then 1 else 2 end
  • Deep nesting → guard clauses: return unless valid? (sheet 029)

⚠ Common Mistakes

  • Writing else if; Ruby parses it as a nested if that needs its own end
  • Using unless with else or with && / \|\| conditions; double negatives are hard to read
  • Writing if x = 5 by accident; Ruby warns, and the condition is always truthy

✓ Tips & Best Practices

  • Prefer case once you have more than two elsif branches comparing one value
  • Return early from methods instead of wrapping the whole body in if
  • Assigning from if keeps the variable defined in one place

Quick Summary

  • if / elsif / else — branches
  • unless — if not
  • if is an expression — assign its result
  • then — one-line branches
