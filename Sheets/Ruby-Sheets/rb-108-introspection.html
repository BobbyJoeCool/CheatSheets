Introspection

Ruby objects can describe themselves at runtime: list their methods, instance variables, ancestors and constants, check what they respond to, and find where a method is defined. Introspection powers debugging, REPL exploration, documentation tools and metaprogramming.

Notes

  • methods(false) / instance_methods(false) show only the class's own methods
  • public_methods, private_methods filter by visibility
  • source_location returns nil for methods written in C
  • Module#const_source_location finds where a constant is defined

Inspecting Objects and Classes

class Dog
  NOISE = "woof"
  attr_reader :name
  def initialize(name) = @name = name
  def bark = NOISE
end
d = Dog.new("Rex")

d.class                             # Dog
d.instance_variables                # [:@name]
d.instance_variable_get(:@name)     # "Rex"
Dog.instance_methods(false)         # [:name, :bark]
d.public_methods(false)             # methods defined on Dog
d.respond_to?(:bark)                # true
Dog.ancestors.first(3)              # [Dog, Object, Kernel]
Dog.constants                       # [:NOISE]
Dog.const_get(:NOISE)               # "woof"

d.method(:bark).owner               # Dog
d.method(:bark).source_location     # ["dog.rb", 5]
"x".method(:upcase).source_location # nil (C method)

Code Explained

instance_variables / instance_variable_get — read state by name
instance_methods(false) — only methods this class defines
ancestors — modules and superclasses in lookup order
const_get — constant by name (strings like "A::B" work too)
method(:m).source_location — file and line of the definition

The Ruby Way

  • Searching files for a method → method(:x).source_location
  • d.methods.include?(:x) → d.respond_to?(:x)
  • Reading private state with instance_variable_get in app code → add a reader

⚠ Common Mistakes

  • Reading obj.methods and drowning in Object methods; pass false or subtract Object.instance_methods
  • Using instance_variable_set to bypass validations in production code
  • Assuming source_location always works; C-implemented methods return nil

✓ Tips & Best Practices

  • In irb, ls obj and show_source Dog#bark are faster than calling these by hand
  • obj.method(:m).super_method walks up overridden implementations
  • Module#name and #to_s help identify anonymous classes (nil name means anonymous)
