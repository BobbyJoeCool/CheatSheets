Method Objects and Composition

method(:name) returns a Method object you can call, pass as a block with &, inspect, or compose with >> and <<. send and public_send call a method whose name is only known at runtime. Unbinding and rebinding (instance_method, bind) attach a method to another object of the same type.

Notes

  • send ignores visibility; public_send respects it
  • Method#arity, #parameters, #source_location describe a method
  • f >> g means "call f, then g"
  • Method#to_proc lets you pass methods where blocks are expected

Methods as Objects

m = 5.method(:+)
m.call(3)                       # 8

%w[1 2 3].map(&method(:Integer))  # [1, 2, 3]
[1, 2].each(&method(:puts))     # prints 1, 2

double = ->(x) { x * 2 }
inc    = ->(x) { x + 1 }
(double >> inc).(5)             # 11  (double first)
(double << inc).(5)             # 12  (inc first)
(method(:Integer) >> double).("21")  # 42

"hello".send(:upcase)           # "HELLO"
"hello".public_send(:length)    # 5
op = :+
3.public_send(op, 4)            # 7

um = String.instance_method(:upcase)   # UnboundMethod
um.bind_call("abc")             # "ABC"
def greet(name, greeting: "Hi") = nil
method(:greet).parameters       # [[:req, :name], [:key, :greeting]]

Code Explained

5.method(:+) — a bound Method object
&method(:Integer) — pass a method as a block
>> / << — compose left-to-right / right-to-left
public_send(op, 4) — dynamic call, visibility respected
bind_call — run an unbound method on another receiver

The Ruby Way

  • map { |s| Integer(s) } → map(&method(:Integer))
  • obj.send(user_input) → public_send, with an allow-list
  • Nested calls inc.(double.(x)) → (double >> inc).(x)

⚠ Common Mistakes

  • Using send with user-controlled names; it can call private methods like system
  • Expecting &method(:name) to be fast in hot loops; it allocates, so a plain block can be quicker
  • Confusing >> and << order; f >> g runs f first

✓ Tips & Best Practices

  • source_location jumps straight to where a method is defined while debugging
  • Prefer public_send in application code; reserve send for tests and metaprogramming
  • Composition with >> keeps small transformation steps reusable

Quick Summary

  • method(:x) — Method object
  • &method(:x) — method as block
  • >> / << — composition
  • public_send — safe dynamic call
