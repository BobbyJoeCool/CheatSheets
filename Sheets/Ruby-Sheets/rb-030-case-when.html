case / when

case compares one value against several patterns using ===, so a when can match a value, a class, a range, a regex, or a lambda. The first matching branch runs and its value is returned; there is no fall-through, so no break is needed. Without a subject, case acts like an if/elsif chain.

case Notes

  • when a, b matches either value
  • else handles no match; otherwise the result is nil
  • case/in is pattern matching (sheets 031–032), a different feature

case / when

def classify(x)
  case x
  when nil            then "nothing"
  when Integer, Float then "number"
  when /\A\d+\z/      then "numeric string"
  when String         then "text"
  else "other"
  end
end
classify("42")       # "numeric string"

grade = case score
        when 90.. then "A"
        when 80...90 then "B"
        when ->(s) { s < 0 } then "invalid"
        else "C"
        end

case                  # no subject: if/elsif style
when temp > 30 then :hot
when temp < 5  then :cold
else :mild
end

Code Explained

/\A\d+\z/ — regex === tests a match
90.. — endless range catches 90 and up
->(s) { s < 0 } — a lambda's === calls it
no subject — each when is a plain condition

The Ruby Way

  • if x == :a \|\| x == :b → case x when :a, :b
  • when x > 5 with a subject → subjectless case (or a lambda)
  • Hash lookup tables for pure value maps → { a: 1 }.fetch(x) when no logic is needed

⚠ Common Mistakes

  • Writing when x > 5 in a case x; that compares x to true/false. Drop the subject or use a lambda
  • Adding break out of habit from C or JavaScript; there's no fall-through to stop
  • Ordering when String before a more specific regex; the first match wins

✓ Tips & Best Practices

  • when *VALID_STATES splats an array of options into the branch
  • case returns a value, so assign it directly instead of setting a variable in each branch
  • Put nil checks first so later whens can assume a value

Quick Summary

  • case x when ... — compares with ===
  • when a, b — either
  • no fall-through — no break needed
  • subjectless case — if/elsif replacement
