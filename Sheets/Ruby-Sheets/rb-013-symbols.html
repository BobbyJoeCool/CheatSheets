Symbols

A Symbol (:name) is an immutable, interned identifier: every :name in a program is the same object. Symbols are used for hash keys, method names, and option flags where the value is a label rather than text. Strings are for data you manipulate; symbols are for names.

Symbol Facts

  • :a.object_id == :a.object_id is always true
  • { name: "Ada" } uses a symbol key; { "name" => "Ada" } a string key
  • Symbols are frozen and can't be mutated
  • %i[a b c] builds an array of symbols

Symbols vs Strings

:status.class                # Symbol
:ok.object_id == :ok.object_id   # true  (one object)

:name.to_s                   # "name"
"name".to_sym                # :name
:"first name"                # quoted symbol with a space
%i[draft live archived]      # [:draft, :live, :archived]

h = { name: "Ada" }          # symbol key
h[:name]                     # "Ada"
h["name"]                    # nil  — different key!

user.send(:name)             # call a method by name
[1, 2, 3].map(&:to_s)        # ["1", "2", "3"]
:upcase.to_proc.call("hi")   # "HI"

Code Explained

one object — every :ok is identical, so comparisons are fast
to_sym / to_s — convert both ways
h["name"] — string and symbol keys never match each other
&:to_s — Symbol#to_proc turns a method name into a block
send(:name) — symbols name methods for dynamic calls

The Ruby Way

  • { "status" => "active" } for fixed labels → { status: :active }
  • map { |x| x.to_s } → map(&:to_s)
  • params[:x].to_sym on user input → keep untrusted text as strings

In Rails

  • Rails · params accept both: params[:id] and params["id"] work (HashWithIndifferentAccess)
  • AS · hash.with_indifferent_access gives the same behavior to any hash
  • AS · hash.symbolize_keys / stringify_keys convert keys

⚠ Common Mistakes

  • Looking up h["name"] in a hash built with name: keys; the result is nil, not an error
  • JSON parsing returns string keys; access them with strings or pass symbolize_names: true
  • Comparing a symbol to a string (:ok == "ok" is false); convert one side first

✓ Tips & Best Practices

  • Use &:method only for zero-argument methods; map(&:round) works, map(&:round(2)) doesn't
  • Symbol#start_with?, #length, #upcase exist, so many string ops work directly on symbols
  • Symbols are garbage-collected since Ruby 2.2, but still avoid creating unbounded numbers of them

Quick Summary

  • :name — interned, immutable label
  • to_sym / to_s — convert
  • name: — symbol hash key
  • &:method — symbol as block
