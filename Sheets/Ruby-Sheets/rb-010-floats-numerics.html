Floats and Exact Numbers

Float is a 64-bit IEEE 754 double, so 0.1 + 0.2 is not exactly 0.3. For exact fractions use Rational (3r, 1/3r); for money and decimal precision use BigDecimal. Any operation mixing an Integer and a Float returns a Float.

Float Facts

  • Float::INFINITY, -Float::INFINITY, Float::NAN exist
  • 1.0 / 0 is Infinity; 1 / 0 raises ZeroDivisionError
  • round uses half-away-from-zero by default
  • BigDecimal needs require "bigdecimal" (bundled gem)

Float, Rational, BigDecimal

0.1 + 0.2                    # 0.30000000000000004
(0.1 + 0.2).round(2)         # 0.3
3.14159.round(2)             # 3.14
3.7.floor / 3.2.ceil         # 3 / 4
-3.7.truncate                # -3
2.5.round                    # 3
2.5.round(half: :even)       # 2

1.0 / 0                      # Infinity
(0.0 / 0).nan?               # true
(0.1 + 0.2 - 0.3).abs < Float::EPSILON  # true

1/3r + 1/6r                  # (1/2)
0.75.rationalize             # (3/4)
require "bigdecimal"
BigDecimal("0.1") + BigDecimal("0.2")   # 0.3e0
BigDecimal("19.99").to_s("F")           # "19.99"
Complex(3, 4).abs            # 5.0

Code Explained

0.30000000000000004 — binary floats can't represent 0.1 exactly
round(half: :even) — banker's rounding when you need it
Float::EPSILON — tolerance for comparing floats
1/3r — r suffix makes an exact Rational
BigDecimal("0.1") — build from strings, never from floats

The Ruby Way

  • a == b for floats → (a - b).abs < 1e-9
  • Money as Float → integer cents or BigDecimal
  • x.to_f / y → x.fdiv(y)

In Rails

  • Rails · decimal columns load as BigDecimal, so price.class is BigDecimal
  • Rails · number_to_currency(19.99) → "$19.99" in views
  • AS · BigDecimal#to_fs formats decimals for display

⚠ Common Mistakes

  • Storing currency in floats; 0.1 + 0.2 errors accumulate across totals
  • Building BigDecimal(0.1) from a float; the float's error is already baked in
  • Comparing x == Float::NAN; NaN never equals anything, use x.nan?

✓ Tips & Best Practices

  • Use round(2) only for display; keep full precision while calculating
  • Integer#fdiv avoids accidentally truncating integer division
  • Rational keeps fractions exact through long calculations, then convert at the end with to_f

Quick Summary

  • Float — fast, approximate
  • Rational — exact fractions (3r)
  • BigDecimal — exact decimals for money
  • nan? / EPSILON — safe float checks
