Enumerable: Filter and Find

Filtering methods select elements by a condition: select (alias filter) keeps matches, reject drops them, and partition splits into both groups. find (alias detect) returns the first match, grep filters with ===, and the predicates any? / all? / none? / one? answer yes/no questions.

Notes

  • find stops at the first match; select always scans everything
  • grep(pattern) uses ===, so it accepts classes, ranges and regexes
  • Predicates accept a pattern too: nums.all?(Integer)
  • take_while / drop_while stop at the first non-match

Filtering and Finding

nums = [3, 8, 1, 12, 7, 6]
nums.select(&:even?)              # [8, 12, 6]
nums.reject(&:even?)              # [3, 1, 7]
evens, odds = nums.partition(&:even?)  # [[8, 12, 6], [3, 1, 7]]
nums.find { it > 5 }              # 8
nums.find_index { it > 5 }        # 1
nums.take_while { it < 10 }       # [3, 8, 1]
nums.drop_while { it < 10 }       # [12, 7, 6]

%w[a.rb b.txt c.rb].grep(/\.rb\z/)    # ["a.rb", "c.rb"]
[1, "a", :b, 2.5].grep(Numeric)       # [1, 2.5]
nums.grep(5..10)                      # [8, 7, 6]
%w[a.rb b.txt].grep_v(/\.rb/)         # ["b.txt"]

nums.any? { it > 10 }             # true
nums.all?(Integer)                # true
nums.none?(&:negative?)           # true
[nil, false, 1].one?              # true (one truthy)
nums.count(&:even?)               # 3

Code Explained

select / reject — keep / drop by condition
partition — both groups at once
find — first match or nil
grep — filter with === (regex, class, range)
any? / all? / none? / one? — boolean questions

The Ruby Way

  • select { }.first → find { }
  • select { }.size > 0 → any? { }
  • select { |s| s =~ /x/ } → grep(/x/)

In Rails

  • Rails · User.where(active: true) filters in SQL; User.all.select(&:active?) filters in Ruby after loading all rows
  • AS · exclude? reads better than !include?

⚠ Common Mistakes

  • Calling [].all? { … }; it's true for an empty collection, which can hide missing data
  • Using select + first on large collections; find stops early
  • Confusing filter_map (map + compact) with select (keep elements as they are)

✓ Tips & Best Practices

  • grep with a block maps the matches: lines.grep(/ERROR (\d+)/) { $1 }
  • Use lazy.select { }.first(5) on huge or infinite sources (sheet 105)
  • min_by / max_by beat sort_by { }.first when you only need one element
