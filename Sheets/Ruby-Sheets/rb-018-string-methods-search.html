String Methods — Search

include? · start_with? · end_with? · index / rindex · count · match? · =~ · scan

Searching Strings

Ruby's string search methods are mostly predicates (include?, start_with?, match?) that return booleans, plus locators (index, rindex) that return a position or nil. Most accept either a plain string or a Regexp, so one method covers both literal and pattern searches.

Search Notes

  • Everything is case-sensitive; use casecmp? or /i
  • index returns nil when not found, not -1
  • match? doesn't set $~, so it's the fastest regex test
  • start_with? and end_with? accept multiple arguments

Search Methods

s = "Hello, Ruby world"
s.include?("Ruby")            # true
s.start_with?("Hell")         # true
s.start_with?("Hi", "He")     # true (any)
s.end_with?("world")          # true
s.index("o")                  # 4
s.index("o", 5)               # 13 (search from 5)
s.rindex("o")                 # 13
s.index("zzz")                # nil

s.count("lo")                 # 5 (counts chars l or o)
s.scan("o").size              # 2
s.match?(/r\w+y/i)            # true
s =~ /Ruby/                   # 7
s[/w\w+/]                     # "world"
s.scan(/\b\w/)                # ["H", "R", "w"]

"RUBY".casecmp?("ruby")       # true
"b".between?("a", "c")        # true

Code Explained

include? — substring test; returns a boolean
start_with?("Hi", "He") — true if any prefix matches
index(str, start) — first position at or after start
count("lo") — counts characters in the set, not the substring
=~ — match position or nil; sets $~

The Ruby Way

  • s.index("x") != nil → s.include?("x")
  • s =~ /re/ ? true : false → s.match?(/re/)
  • s.downcase == t.downcase → s.casecmp?(t)

In Rails

  • AS · exclude? is the inverse of include?: "abc".exclude?("z") → true
  • AS · "production".inquiry.production? → true
  • Rails · that's how Rails.env.production? works

⚠ Common Mistakes

  • Checking index(x) > 0; a match at position 0 fails the test, and nil > 0 raises
  • Using count("ab") to count occurrences of "ab"; use scan("ab").size
  • Forgetting /i and missing "ruby" vs "Ruby"

✓ Tips & Best Practices

  • Use match? in conditions; it's faster than =~ because it doesn't build MatchData
  • s[/(\d+)-(\d+)/, 2] grabs one capture group directly
  • each_char.with_index.select { |c, _| c == "o" }.map(&:last) finds all positions

Quick Summary

  • include? / start_with? — substring tests
  • index / rindex — position or nil
  • match? — fast regex test
  • scan — all matches
