Rake

Rake is Ruby's task runner (a bundled gem), like make written in Ruby. Tasks are defined in a Rakefile with task, documented with desc, grouped with namespace, and can depend on other tasks. rake -T lists documented tasks, and file tasks only rebuild outputs when their inputs change.

Rake Notes

  • Only tasks with a desc appear in rake -T
  • task default: :test sets what plain rake runs
  • Arguments: rake "greet[Ada]"
  • Rake::TestTask wires up Minitest suites

Rakefile

require "rake/testtask"

desc "Say hello"
task :hello, [:name] do |_t, args|
  puts "Hello, #{args.fetch(:name, 'world')}"
end

namespace :db do
  task :create do
    puts "creating…"
  end

  task reset: [:drop, :create]       # prerequisites run first
  task(:drop) { puts "dropping…" }
end

file "build/app.css" => ["src/app.scss"] do |t|   # only if stale
  sh "sass #{t.prerequisites.first} #{t.name}"
end

Rake::TestTask.new(:test) { |t| t.pattern = "test/**/*_test.rb" }
task default: :test

Code Explained

desc — documents the task for rake -T
task :hello, [:name] — task with arguments
namespace :db — rake db:create
reset: [:drop, :create] — prerequisites
file task — runs only when the output is older than inputs

The Ruby Way

  • Shell scripts for project chores → Rake tasks in Ruby
  • Copy-pasted setup in tasks → prerequisites
  • Long task names → namespaces

In Rails

  • Rails · custom tasks go in lib/tasks/*.rake
  • Rails · task cleanup: :environment do loads the app (models, config) first
  • Rails · bin/rails db:migrate and bin/rails -T run Rake tasks

⚠ Common Mistakes

  • Forgetting the quotes around rake "task[arg]" in zsh; brackets are glob characters there
  • Omitting desc and wondering why the task doesn't show in rake -T
  • Putting slow requires at the top of the Rakefile; every task pays the load time

✓ Tips & Best Practices

  • sh raises if the command fails, so the task stops instead of continuing silently
  • Use Rake::FileList["src/**/*.md"] for file sets with exclusions
  • Keep task bodies thin; call into your library code so it can be tested

Quick Summary

  • task / desc / namespace — define tasks
  • prerequisites — task a: [:b]
  • file — rebuild only when stale
  • rake -T — list tasks
