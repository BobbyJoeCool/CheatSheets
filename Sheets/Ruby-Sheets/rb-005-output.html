Output

puts · print · p · pp · printf · $stdout · warn / $stderr

Printing Output

Ruby has three everyday output methods: puts adds a newline and calls to_s, print writes without a newline, and p prints the inspect form (quotes, nils, types visible) and returns its argument, which makes it ideal for debugging. pp pretty-prints large nested structures.

Key Differences

  • puts nil prints an empty line; p nil prints nil
  • puts [1, 2] prints each element on its own line
  • puts and print return nil; p returns the object
  • warn writes to stderr, not stdout

Output Methods

puts "Hello"              # Hello⏎
puts "a", "b"             # a⏎b⏎
puts [1, [2, 3]]          # 1⏎2⏎3⏎ (flattened)
print "no", "line"        # noline
print "x\n"               # x⏎

p "Hello"                 # "Hello"
p 1, nil                  # 1⏎nil
x = p(42) + 1             # prints 42, x == 43
pp({ user: { id: 1, roles: [:admin] } })

printf("%-5s|%3d\n", "id", 7)   # id   |  7
$stdout.puts "explicit stdout"
$stdout.write("raw", "\n")      # returns bytes written
warn "Disk almost full"         # → stderr
$stderr.puts "error!"

Code Explained

puts — to_s + newline; arrays print one item per line
print — no newline, no separator between args
p — inspect form; returns its argument so you can wrap expressions
pp — pretty-print, wraps long nested data
warn — stderr; skipped when run with -W0

The Ruby Way

  • puts x.inspect → p x
  • print "text\n" → puts "text"
  • $stdout.puts "err" for errors → warn "err"

⚠ Common Mistakes

  • Debugging with puts; puts nil and puts "" both print a blank line, so you can't tell them apart. Use p
  • Expecting print to add spaces between arguments; print "a", "b" prints ab
  • Leaving p calls in production code; they also change return values when used as the last line

✓ Tips & Best Practices

  • p returns its argument, so result = p(compute) logs without restructuring code
  • Set $stdout.sync = true in scripts piped to other tools so output appears immediately
  • Use pp for hashes from JSON; it wraps and indents automatically

Quick Summary

  • puts — to_s + newline
  • print — no newline
  • p — inspect + returns arg
  • warn — stderr
