Recursion and Memoization

A recursive method calls itself on a smaller input until it reaches a base case. CRuby does not optimize tail calls by default, so very deep recursion raises SystemStackError. Memoization caches results so repeated subproblems are computed once; a Hash with a default block is the classic Ruby way to do it.

Notes

  • Always handle the base case first
  • Default stack depth is roughly 10k frames (varies)
  • Hash.new { |h, k| h[k] = ... } computes and stores on first lookup
  • @x ||= compute memoizes a single value per object

Recursion and Caching

def factorial(n)
  return 1 if n <= 1          # base case
  n * factorial(n - 1)        # recursive case
end
factorial(5)                  # 120

def fib(n) = n < 2 ? n : fib(n - 1) + fib(n - 2)
fib(30)                       # 832040 (slow: ~2.7M calls)

fib = Hash.new { |h, n| h[n] = n < 2 ? n : h[n - 1] + h[n - 2] }
fib[90]                       # 2880067194370816120 (instant)

def flat(x) = x.is_a?(Array) ? x.flat_map { flat(it) } : [x]
flat([1, [2, [3, [4]]]])      # [1, 2, 3, 4]

class Report
  def totals = @totals ||= expensive_query   # memoize once
end

def depth(n) = depth(n + 1)
depth(0)                      # SystemStackError: stack level too deep

Code Explained

return 1 if n <= 1 — stops the recursion
fib(30) — exponential calls without caching
Hash.new { |h, n| h[n] = ... } — compute once, store forever
flat_map + recursion — walk nested structures
@totals ||= — per-object memoization

The Ruby Way

  • Recursive fib → memoized hash or a loop
  • Deep recursion over long lists → iterate with each / reduce
  • Recomputing a value in many methods → @value ||= compute

In Rails

  • Rails · Rails.cache.fetch("stats", expires_in: 1.hour) { compute } memoizes across requests
  • Rails · controllers use @current_user ||= User.find_by(id: session[:user_id])

⚠ Common Mistakes

  • Forgetting the base case, or one that is never reached (e.g. n == 0 with negative input)
  • Using ||= to memoize methods that can return nil or false; they recompute every time
  • Recursing over large inputs and hitting SystemStackError; convert to a loop or explicit stack

✓ Tips & Best Practices

  • Memoize falsy values with defined?(@x) ? @x : (@x = compute)
  • Use an explicit array as a stack for deep tree walks
  • Hash#dig and flat_map handle many nested-data tasks without hand-written recursion

Quick Summary

  • base case + smaller input — recursion pattern
  • SystemStackError — too deep
  • Hash.new { } — memo table
  • @x \|\|= — memoize one value
