Arithmetic Operators

Arithmetic operators are methods on numeric objects: a + b is a.+(b). The result type follows the operands: Integer with Integer stays Integer (division floors), and anything mixed with a Float becomes a Float. ** is exponentiation and binds tighter than unary minus.

Arithmetic Rules

  • / on two integers floors toward −∞
  • % takes the sign of the divisor
  • -2 ** 2 is -4 (** before unary -)
  • Division by integer 0 raises; by 0.0 gives Infinity

Arithmetic in Action

10 + 3                 # 13
10 - 3                 # 7
10 * 3                 # 30
10 / 3                 # 3
10 / 3.0               # 3.3333333333333335
10 % 3                 # 1
2 ** 10                # 1024
2 ** -1                # (1/2)  Rational
4 ** 0.5               # 2.0

-7 / 2                 # -4
-7 % 2                 # 1
7.remainder(-2)        # 1   (sign of dividend)
7.divmod(-2)           # [-4, -1]
10.fdiv(4)             # 2.5
-2 ** 2                # -4
(-2) ** 2              # 4
1 / 0                  # ZeroDivisionError
1.0 / 0                # Infinity
3.+(4)                 # 7 — operators are methods

Code Explained

10 / 3.0 — one float operand makes the result a float
2 ** -1 — negative integer powers return a Rational
-7 % 2 — sign follows the divisor, so result is 1
remainder — C-style: sign follows the dividend
3.+(4) — every operator is a method call

The Ruby Way

  • (a.to_f / b) → a.fdiv(b)
  • Math.sqrt(x) for perfect squares → Integer.sqrt(x)
  • x = x + 1 → x += 1 (Ruby has no ++)

⚠ Common Mistakes

  • Writing x++; Ruby has no increment operator. Use x += 1
  • Expecting -7 % 3 to be -1 as in C or JavaScript; Ruby gives 2
  • Computing averages as sum / count with integers and losing the fraction

✓ Tips & Best Practices

  • Use divmod when you need both quotient and remainder (time conversion, pagination)
  • Integer#pow(exp, mod) is the fast way to do modular exponentiation
  • Parenthesize negative bases: (-2) ** 2

Quick Summary

  • / — floors for integers
  • % — sign of divisor
  • ** — power, binds tighter than unary -
  • fdiv — float division
