Operator Overloading

Since operators are method calls, a class can define +, -, ==, <=>, [], []=, unary -@ and more. Define <=> and include Comparable to get all comparisons; define coerce so expressions like 2 * vector work with your type on the right side.

Rules

  • != is derived from ==; don't define it
  • += uses your + automatically
  • Unary minus is -@, unary plus is +@
  • Operators should return new objects, not mutate self

Defining Operators

class Vec
  attr_reader :x, :y
  def initialize(x, y) = (@x, @y = x, y)

  def +(o)  = Vec.new(x + o.x, y + o.y)
  def *(k)  = Vec.new(x * k, y * k)
  def -@    = Vec.new(-x, -y)
  def ==(o) = o.is_a?(Vec) && x == o.x && y == o.y
  def [](i) = [x, y].fetch(i)
  def to_s  = "(#{x}, #{y})"
  def coerce(n) = [self, n]      # lets 2 * v work
end

a = Vec.new(1, 2)
b = Vec.new(3, 4)
(a + b).to_s                     # "(4, 6)"
(-a).to_s                        # "(-1, -2)"
(a * 3).to_s                     # "(3, 6)"
(3 * a).to_s                     # "(3, 6)" via coerce
a == Vec.new(1, 2)               # true
a[1]                             # 2
a += b                           # uses + → a is (4, 6)

Code Explained

def +(o) — a + b calls a.+(b)
def -@ — unary minus: -a
def ==(o) — value equality (also gives !=)
def [](i) — index access
coerce — 3 * a asks a to swap operands

The Ruby Way

  • add(other) methods on value types → define +
  • Defining <, >, <= by hand → <=> + include Comparable
  • Operators that mutate self → return a new object

⚠ Common Mistakes

  • Mutating self in +; a + b changing a surprises everyone
  • Defining == without eql? and hash; your objects then misbehave as hash keys (sheet 070)
  • Forgetting coerce, so 2 * vec raises TypeError: Vec can't be coerced

✓ Tips & Best Practices

  • Keep operator meanings familiar: + adds or combines, << appends
  • Return NotImplemented-style TypeError for unsupported operand types
  • Data.define value objects already get value-based ==

Quick Summary

  • operators are methods — def +(o)
  • -@ / +@ — unary operators
  • <=> + Comparable — comparisons
  • coerce — numbers on the left
