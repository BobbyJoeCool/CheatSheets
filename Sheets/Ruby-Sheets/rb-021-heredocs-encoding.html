Heredocs, % Literals and Encoding

Heredocs hold multi-line text; the squiggly form <<~ strips the common leading indentation so the text can be indented with your code. Percent literals (%w, %q, %Q, %i) avoid escaping quotes. Every string carries an encoding, UTF-8 by default.

Heredoc Rules

  • <<~TAG strips indentation; <<-TAG only lets the closing tag be indented
  • <<~'TAG' (quoted) disables interpolation
  • You can call methods on the opener: <<~SQL.strip
  • Any delimiter pair works for % literals: %w[], %w(), %w{}

Heredocs and % Literals

def report(name, total)
  <<~TEXT
    Report for #{name}
      Total: #{total}
    Done.
  TEXT
end
report("Ada", 3)   # "Report for Ada\n  Total: 3\nDone.\n"

sql = <<~SQL.squeeze(" ").strip
  SELECT *  FROM users
  WHERE id = 1
SQL

%w[red green blue]        # ["red", "green", "blue"]
%i[get post]              # [:get, :post]
%q(It's "quoted")         # It's "quoted"  (no interpolation)
%Q(Hi #{1 + 1})           # "Hi 2"
"café".encoding           # #<Encoding:UTF-8>

Code Explained

<<~TEXT — common indent removed; relative indent kept
<<~SQL.squeeze(" ").strip — methods apply to the whole heredoc
%w[] / %i[] — word / symbol arrays, no commas or quotes
%q / %Q — single / double-quote rules with free delimiters

The Ruby Way

  • "line1\n" + "line2\n" → a <<~TEXT heredoc
  • ["a", "b", "c"] → %w[a b c]
  • "He said \"hi\"" → %(He said "hi")

In Rails

  • Rails · ERB templates are where most multi-line HTML lives, not heredocs
  • AS · strip_heredoc predates <<~; seen in older Rails code

Encoding Methods

⚠ Common Mistakes

  • Using <<- and expecting the body's indentation to be removed; only <<~ does that
  • Mixing tabs and spaces in a squiggly heredoc; indentation stripping then looks wrong
  • Using force_encoding to convert text; it only relabels bytes. Use encode to convert

✓ Tips & Best Practices

  • Name heredoc tags after the content (SQL, HTML, JSON); editors highlight the body
  • Use scrub on text from files or sockets before regex work to avoid ArgumentError: invalid byte sequence
  • %w[] with interpolation is %W[#{a} b]

Quick Summary

  • <<~TAG — indented heredoc
  • %w[] / %i[] — word / symbol arrays
  • %q / %Q — custom-quoted strings
  • encode vs force_encoding — convert vs relabel
