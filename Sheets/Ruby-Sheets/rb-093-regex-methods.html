Regex in String Methods

Most string methods accept a regex: scan finds all matches, sub / gsub replace the first / every match, split splits on a pattern, and slice / [] extract matches. gsub takes a replacement string with backreferences, a hash, or a block that computes each replacement.

Notes

  • scan with groups returns arrays of captures
  • Backrefs in replacement strings: '\1' or '\k<name>'
  • In a gsub block, $1 / $~ refer to the current match
  • Regexp.union combines patterns or literal strings safely

scan, gsub, split

s = "a1 b22 c333"
s.scan(/\d+/)                     # ["1", "22", "333"]
s.scan(/([a-z])(\d+)/)            # [["a", "1"], ["b", "22"], …]
s.gsub(/\d+/, "#")                # "a# b# c#"
s.gsub(/(\w)(\d+)/, '\2\1')       # "1a 22b 333c"
s.gsub(/\d+/) { it.size.to_s }    # "a1 b2 c3"

iso = /(?<y>\d+)-(?<m>\d+)-(?<d>\d+)/
"2026-10-17".sub(iso, '\k<d>/\k<m>/\k<y>')     # "17/10/2026"
"cat hat".gsub(/[ch]/, "c" => "b", "h" => "m")   # "bat mat"
"a, b;c  d".split(/[,;\s]+/)      # ["a", "b", "c", "d"]
"price: $42"[/\$(\d+)/, 1]        # "42"

stop = Regexp.union("cat", "dog", "a.b")   # literals escaped
"a.b and cats".scan(stop)         # ["a.b", "cat"]
Regexp.escape("1+1=2")            # "1\\+1=2"

Code Explained

scan — all matches, or all capture groups
'\2\1' — swap groups (single quotes keep backslashes)
gsub { } — computed replacement per match
hash replacement — lookup table for each match
Regexp.union — one pattern from many alternatives

The Ruby Way

  • s.match(/x/)[1] → s[/x(…)/, 1]
  • Chained gsub for each word → gsub(Regexp.union(words), map)
  • split(" ") with messy separators → split(/[,;\s]+/)

⚠ Common Mistakes

  • Writing backrefs in double quotes ("\1"); that's an octal escape. Use '\1' or "\\1"
  • Expecting scan with one group to return full matches; it returns the group contents
  • Using gsub! in a chain; it returns nil when nothing changed

✓ Tips & Best Practices

  • gsub with a hash is a fast template filler: tpl.gsub(/\{(\w+)\}/) { vals[$1] }
  • String#tr beats gsub for single-character mappings
  • Test patterns interactively in irb or on rubular.com

Quick Summary

  • scan — find all
  • sub / gsub — replace first / all
  • block / hash — dynamic replacements
  • Regexp.union / escape — safe patterns
