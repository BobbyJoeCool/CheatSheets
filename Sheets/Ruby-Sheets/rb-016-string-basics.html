Strings

Ruby strings are mutable sequences of characters with an encoding (UTF-8 by default). Double quotes support interpolation and escapes; single quotes are literal except for \' and \\. With # frozen_string_literal: true at the top of a file, string literals are frozen and mutating them raises FrozenError.

String Facts

  • length counts characters; bytesize counts bytes
  • + builds a new string; << appends in place
  • Ruby 3.4+ warns when you mutate an unfrozen literal (chilled strings)
  • +"" or String.new gives a mutable string under the magic comment

String Basics

# frozen_string_literal: true
name = "Ada"
'Hi #{name}\n'               # literal: Hi #{name}\n
"Hi #{name}\n"               # Hi Ada⏎
"café".length                # 4
"café".bytesize              # 5
"".empty?                    # true

a = "Hi"
b = a + "!"                  # new string; a unchanged
a << "!"                     # FrozenError (frozen literal)
buf = +""                    # mutable copy
buf << "Hello" << ", " << name   # "Hello, Ada"
buf.frozen?                  # false

"ab" * 3                     # "ababab"
"a" == "a"                   # true
"apple" < "banana"           # true (byte order)
"Ruby".dup.frozen?           # false
"%.2f" % 3.14159             # "3.14"

Code Explained

'...' — no interpolation, no \n
length vs bytesize — é is 1 character, 2 bytes
+ vs << — copy vs append in place
+"" — unary plus returns an unfrozen string
"%.2f" % — format operator (sheet 017)

The Ruby Way

  • s = s + more in a loop → s << more on a +"" buffer
  • "Hello " + name + "!" → "Hello #{name}!"
  • str.length == 0 → str.empty?

⚠ Common Mistakes

  • Using single quotes and expecting #{} to interpolate
  • Calling << on a frozen literal and getting FrozenError; start from +"" or dup
  • Using length to size binary or network data; use bytesize

✓ Tips & Best Practices

  • Add # frozen_string_literal: true to every file; it catches accidental mutation and saves allocations
  • Build big strings with << or Array#join, not repeated +
  • str.dup gives you an unfrozen copy of anything

Quick Summary

  • "..." — interpolation + escapes
  • '...' — literal
  • << / + — append / copy
  • length / bytesize — chars / bytes
