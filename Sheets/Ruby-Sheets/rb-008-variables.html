Variables and Assignment

Variables are created by assignment, with no declaration keyword and no type. A variable is a name pointing at an object; reassigning points it elsewhere. The first character (sigil) sets the kind: lowercase for locals, @ instance, @@ class, $ global, and an uppercase first letter for constants.

Rules

  • Names: letters, digits, _; can't start with a digit
  • Reading an unassigned local raises NameError
  • Reassigning a constant only warns; it doesn't stop you
  • Assignment returns the assigned value: a = b = 0

Assignment Forms

name = "Ada"                  # local variable
count = 0
count += 1                    # 1

a = b = 0                     # chained: both 0
x, y = 1, 2                   # parallel assignment
x, y = y, x                   # swap → x=2, y=1
first, *rest = [1, 2, 3]      # 1, [2, 3]
head, (m, n) = 1, [2, 3]      # nested: m=2, n=3

MAX_USERS = 100               # constant
MAX_USERS = 200               # warning: already initialized

@title = "Book"               # instance variable
$debug = true                 # global (avoid)

defined?(zzz)                 # => nil
s1 = "hi"; s2 = s1            # same object
s2 << "!"; s1                 # => "hi!"

Code Explained

x, y = y, x — swap without a temp variable
first, *rest — splat collects the remainder
MAX_USERS = 200 — reassignment warns; constants aren't locked
defined? — check without raising NameError
s2 = s1 — copies the reference, not the string

The Ruby Way

  • temp = x; x = y; y = temp → x, y = y, x
  • arr[0] / arr[1] lookups → first, second = arr
  • $globals for config → constants or a config object

⚠ Common Mistakes

  • Mutating a string through one variable and being surprised the other changed; both point at one object
  • Expecting constants to be immutable; freeze them (LIST = %w[a b].freeze) to stop mutation
  • Typos create new variables silently (totl = 1), then the real one is used unchanged

✓ Tips & Best Practices

  • Use dup when you need an independent copy of a mutable object
  • Freeze constant collections; the warning only covers rebinding, not <<
  • Prefer locals and instance variables; globals make code hard to follow

Quick Summary

  • x = 1 — assignment creates the variable
  • x, y = y, x — swap
  • CONST — uppercase = constant
  • @ / @@ / $ — instance / class / global
