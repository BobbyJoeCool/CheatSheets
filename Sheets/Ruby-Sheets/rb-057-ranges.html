Ranges

A Range represents an interval: 1..10 includes the end, 1...10 excludes it. Ranges can be endless (1..) or beginless (..5), work with any comparable values (numbers, strings, dates), and support iteration, membership tests and stepping. They're used for slicing, case/when, and conditions.

Range Facts

  • cover? tests begin <= x <= end (fast, no iteration)
  • include? iterates for non-numeric ranges
  • (1..10) % 3 steps by 3 (Ruby 3.0+)
  • to_a on an endless range raises (infinite)

Range Basics

r = 1..10
r.to_a                       # [1, 2, ..., 10]
(1...10).size                # 9
r.sum                        # 55
r.step(3).to_a               # [1, 4, 7, 10]
((1..10) % 4).to_a           # [1, 5, 9]
(10).downto(8).to_a          # [10, 9, 8]

r.cover?(5.5)                # true
r.include?(11)               # false
("a".."e").to_a              # ["a", "b", "c", "d", "e"]
("a".."z").cover?("cat")     # true (compares strings)
("a".."z").include?("cat")   # false (not an element)

arr = %w[a b c d e]
arr[1..]                     # ["b", "c", "d", "e"]
arr[..-2]                    # ["a", "b", "c", "d"]
(1..).each { |n| break n if n * n > 50 }  # 8
age = 42
case age when ..17 then :minor when 18.. then :adult end  # :adult
(1..10).minmax               # [1, 10]

Code Explained

1..10 / 1...10 — inclusive / exclusive end
step(3) / % 4 — every nth value
cover? — range comparison; include? — membership
arr[1..] — slicing with endless ranges
(1..).each — infinite sequence, stop with break

The Ruby Way

  • x >= 1 && x <= 10 → (1..10).cover?(x)
  • (0..arr.size - 1) → arr.each_index or (0...arr.size)
  • if age < 18 … elsif age >= 65 → case age when ..17 … when 65..

In Rails

  • Rails · User.where(created_at: 1.week.ago..) builds created_at >= ?
  • AS · Date.current.all_week returns the range of this week's dates

⚠ Common Mistakes

  • Using ... and forgetting the end is excluded: (1...10).to_a.last is 9
  • Calling include? on string ranges and getting false for strings that cover? accepts
  • Writing 1..10.each; method calls bind tighter, so use (1..10).each

✓ Tips & Best Practices

  • Use ranges in case/when for buckets like grades or age groups
  • rand(1..6) picks a random integer in a range
  • Range#step with floats is precise: (0.0..1.0).step(0.25).to_a

Quick Summary

  • .. / ... — inclusive / exclusive
  • 1.. / ..5 — endless / beginless
  • cover? — fast bounds check
  • step / % — stepping
