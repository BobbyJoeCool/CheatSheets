Enumerable: Reduce and Aggregate

Aggregation methods boil a collection down to one value or a summary: sum, count, min_by / max_by, minmax, tally (counts) and group_by (buckets). reduce (alias inject) is the general tool: it carries an accumulator through every element.

Notes

  • reduce(:+) / reduce(0) { |acc, x| … } — symbol or block form
  • Without an initial value, reduce starts with the first element
  • sum takes a start value and a block: sum(0.0) { it.price }
  • tally counts equal values; map first to count by a key

Aggregating

nums = [4, 8, 15, 16, 23, 42]
nums.sum                           # 108
nums.sum { it * 2 }                # 216
nums.reduce(:*)                    # 7418880
nums.reduce(1) { |acc, n| acc * n }   # same, explicit start
nums.count(&:even?)                # 4
nums.minmax                        # [4, 42]
(nums.sum.to_f / nums.size).round(1)  # 18.0 (average)

people = [{ name: "Ada", dept: :eng, age: 36 },
          { name: "Bo",  dept: :ops, age: 29 },
          { name: "Cy",  dept: :eng, age: 41 }]
people.max_by { it[:age] }[:name]          # "Cy"
people.sum { it[:age] }                    # 106
people.group_by { it[:dept] }.transform_values(&:size)  # {eng: 2, …}
people.map { it[:dept] }.tally             # {eng: 2, ops: 1}
%w[a b a c a].tally.max_by(&:last)         # ["a", 3]

Code Explained

sum { } — sum of computed values
reduce(:*) — fold with an operator
reduce(1) { |acc, n| } — fold with an initial accumulator
group_by — key → array of elements
tally — value → count

The Ruby Way

  • inject(0) { |s, x| s + x } → sum
  • group_by { }.map { |k, v| [k, v.size] }.to_h → map { }.tally
  • sort_by { }.last → max_by { }

In Rails

  • Rails · Order.sum(:total) and Order.count run as SQL on a relation
  • Rails · Order.group(:status).count → {"paid" => 12, …} in one query

⚠ Common Mistakes

  • reduce without an initial value on an empty array returns nil; pass a start value
  • Summing floats for money; rounding errors accumulate. Use BigDecimal or integer cents
  • Integer average: sum / size truncates; convert to a float first

✓ Tips & Best Practices

  • sum is faster and more accurate than reduce(:+) for floats (it uses Kahan summation)
  • minmax_by { } returns both extremes in one pass
  • Combine group_by with transform_values for per-group stats

Quick Summary

  • sum / count / minmax — quick stats
  • reduce — general fold
  • tally — counts
  • group_by — buckets
