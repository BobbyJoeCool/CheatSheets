Lambdas

A lambda is a Proc with strict argument checking and method-like return: return exits only the lambda itself. Write them with the stabby literal ->(x) { } or lambda { |x| }. Lambdas are the right choice for small functions you store in variables, hashes or constants.

Lambda Facts

  • Wrong number of args → ArgumentError
  • return leaves the lambda, not the surrounding method
  • .curry builds partially applied versions

Lambdas in Practice

square = ->(x) { x * x }
square.(5)                    # 25
square.call(5, 6)             # ArgumentError (given 2, expected 1)

greet = ->(name, greeting: "Hi") { "#{greeting} #{name}" }
greet.("Ada")                 # "Hi Ada"
greet.("Ada", greeting: "Yo") # "Yo Ada"

def find_first_even(nums)
  check = ->(n) { return n.even? }   # return leaves lambda only
  nums.find { |n| check.(n) }
end
find_first_even([1, 4, 6])    # 4

TAX = { food: ->(p) { p * 1.02 }, other: ->(p) { p * 1.08 } }
TAX[:food].(100)              # 102.0

add = ->(a, b, c) { a + b + c }
add5 = add.curry[5]
add5[1][2]                    # 8
compose = square >> ->(n) { n + 1 }
compose.(3)                   # 10

Code Explained

->(x) { } — stabby lambda literal
strict arity — extra or missing args raise
return — exits just the lambda
hash of lambdas — a dispatch table
curry / >> — partial application and composition

The Ruby Way

  • lambda { |x| ... } → ->(x) { ... }
  • case-heavy dispatch on symbols → a hash of lambdas
  • Tiny private helper methods used once → a local lambda

In Rails

  • Rails · scopes are lambdas: scope :active, -> { where(active: true) }
  • Rails · validates :age, if: -> { adult? } takes a lambda condition

⚠ Common Mistakes

  • Calling a lambda with the wrong number of args from a callback API that passes extras (e.g. each_with_index)
  • Writing -> (x) with a space before the paren; it works but warns in some linters and reads oddly
  • Defining lambdas inside hot loops; build them once outside

✓ Tips & Best Practices

  • Use lambdas for anything stored in a variable or constant; arity errors catch bugs early
  • method(:name) gives a Method object that behaves like a lambda
  • >> and << compose lambdas and methods into pipelines

Quick Summary

  • ->(x) { } — lambda literal
  • strict arity — raises on mismatch
  • return — exits the lambda
  • curry / >> — functional helpers
