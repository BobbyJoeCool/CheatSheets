Comments & Documentation

# · =begin / =end · magic comments · # frozen_string_literal: true · RDoc · YARD @param / @return

Comments and Docs

# starts a comment that runs to the end of the line. =begin / =end block comments exist but are rarely used; prefer consecutive # lines. Comments at the very top of a file can be magic comments that change how Ruby parses it, and comments directly above a method become RDoc / YARD documentation.

Comment Facts

  • =begin and =end must start at column 0
  • Magic comments must be in the first two lines
  • # frozen_string_literal: true makes string literals immutable
  • ri and IDEs read RDoc/YARD comments for hover help

Comment Styles

# Single-line comment
x = 42 # trailing comment

=begin
Block comment. Must start at column 0.
Rarely used in real code.
=end

# frozen_string_literal: true   (only valid on line 1-2)
# encoding: utf-8                (default already)

# Calculates the area of a rectangle.
#
# @param width [Numeric] side length
# @param height [Numeric] side length
# @return [Numeric] the area
# @example
#   area(2, 3) #=> 6
def area(width, height) = width * height

# TODO: handle negative sizes

Code Explained

# — everything after it on the line is ignored
=begin/=end — block comment; column 0 only
magic comments — parser directives, not documentation
@param / @return — YARD tags; yard doc builds HTML
#=> — convention for showing a result in examples

The Ruby Way

  • =begin ... =end → a run of # lines (editors toggle these)
  • Comments that restate code → explain why, not what
  • Commented-out dead code → delete it; git remembers

⚠ Common Mistakes

  • Indenting =begin; it is then a syntax error, not a comment
  • Placing # frozen_string_literal: true below the first code line, where Ruby ignores it
  • Leaving a blank line between a doc comment and its def; RDoc then won't attach it

✓ Tips & Best Practices

  • Run yard stats --list-undoc to find public methods without docs
  • Use ri Array#each_slice in the terminal for stdlib docs offline
  • Keep TODO: / FIXME: tags consistent; rails notes and editors can list them

Quick Summary

  • # — line comment
  • =begin/=end — block comment (col 0)
  • # frozen_string_literal: true — magic comment
  • @param / @return — YARD docs
