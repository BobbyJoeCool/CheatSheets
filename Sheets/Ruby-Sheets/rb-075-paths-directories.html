Paths and Directories

File class methods build and inspect paths (join, basename, extname, exist?), Dir lists and globs directories, and FileUtils copies, moves and deletes. Pathname wraps all of these in an object-oriented API where / joins path segments.

Notes

  • File.join uses /, which works on Windows too
  • Dir.glob("**/*.rb") searches recursively
  • File.expand_path("~") resolves the home directory
  • require "fileutils" / "pathname" before using them

Paths, Dir, FileUtils, Pathname

path = File.join("app", "models", "user.rb")  # "app/models/user.rb"
File.basename(path)            # "user.rb"
File.basename(path, ".rb")     # "user"
File.extname(path)             # ".rb"
File.dirname(path)             # "app/models"
File.exist?(path)              # true / false
File.expand_path("~/notes")    # "/Users/ada/notes"

Dir.glob("**/*.rb")            # all .rb files, recursive
Dir.children("app")            # names, no "." / ".."
Dir.mkdir("tmp") unless Dir.exist?("tmp")

require "fileutils"
FileUtils.mkdir_p("out/logs")  # like mkdir -p
FileUtils.cp("a.txt", "out/")
FileUtils.rm_rf("tmp")         # careful: no confirmation

require "pathname"
dir = Pathname("app") / "models"
dir.join("user.rb").read
dir.children.select(&:file?)

Code Explained

File.join — portable path building
basename(path, ".rb") — strip the extension
Dir.glob("**/*.rb") — recursive pattern match
FileUtils.mkdir_p / cp / rm_rf — shell-like operations
Pathname("app") / "models" — / joins segments

The Ruby Way

  • "#{dir}/#{file}" → File.join(dir, file) or Pathname(dir) / file
  • system("mkdir -p out") → FileUtils.mkdir_p("out")
  • Dir.entries(d) - %w[. ..] → Dir.children(d)

In Rails

  • Rails · Rails.root.join("config", "app.yml") returns a Pathname
  • Rails · Rails.public_path and Rails.root / "tmp" for app paths

⚠ Common Mistakes

  • Building paths with string concatenation and doubling or missing slashes
  • Calling FileUtils.rm_rf with a variable that can be empty or "/"; validate first
  • Forgetting Dir.glob results are relative to the current directory; use base: or absolute patterns

✓ Tips & Best Practices

  • Dir.glob("*.{jpg,png}") matches several extensions
  • Pass noop: true, verbose: true to FileUtils calls to dry-run them
  • Ruby 4.0 moves Pathname toward core; check whether require "pathname" is still needed on your version

Quick Summary

  • File.join / basename / extname — paths
  • Dir.glob — find files
  • FileUtils — copy, move, delete
  • Pathname — OO paths with /
