Array Basics

Arrays are ordered, integer-indexed collections that can hold any mix of objects and grow automatically. Indexing with an out-of-range position returns nil instead of raising. Most array work is done with methods (first, dig, each) rather than manual index loops.

Array Facts

  • Negative indexes count from the end
  • Array.new(3, obj) shares one object in every slot
  • Array.new(3) { } builds a fresh object per slot
  • %w[] and %i[] build word / symbol arrays

Creating and Reading Arrays

nums = [10, 20, 30, 40]
mixed = [1, "two", :three, nil, [5]]
words = %w[apple banana cherry]   # ["apple", "banana", "cherry"]

Array.new(3)                 # [nil, nil, nil]
Array.new(3, 0)              # [0, 0, 0]
Array.new(3) { |i| i * i }   # [0, 1, 4]

nums[0]                      # 10
nums[-1]                     # 40
nums[10]                     # nil
nums.first                   # 10
nums.last(2)                 # [30, 40]
nums.length                  # 4
nums.fetch(10, :none)        # :none
[[1, [2, 3]]].dig(0, 1, 0)   # 2

grid = Array.new(2) { Array.new(2, 0) }  # independent rows
grid[0][0] = 1
grid                         # [[1, 0], [0, 0]]

Code Explained

Array.new(3) { |i| } — block builds each element
nums[10] — out of range is nil, not an error
last(2) — the last N elements
fetch(10, :none) — default instead of nil
dig(0, 1, 0) — safe nested lookup

The Ruby Way

  • arr[arr.length - 1] → arr.last
  • ["a", "b", "c"] → %w[a b c]
  • Array.new(3, []) for a grid → Array.new(3) { [] }

In Rails

  • AS · Array.wrap(x) is like Array(x) but doesn't split hashes
  • AS · arr.second, arr.third … arr.forty_two
  • AS · %w[a b c].to_sentence → "a, b, and c"

⚠ Common Mistakes

  • Array.new(3, []): all three slots are the same array, so pushing to one pushes to all
  • Expecting an error for a missing index; you get nil, which fails later and far away. Use fetch
  • Using count when you mean size; count iterates when given an argument or block

✓ Tips & Best Practices

  • Use first / last instead of [0] / [-1]; they read better and take a count
  • fetch with a block computes a default only when needed
  • Array#dig pairs well with JSON data

Quick Summary

  • [] / %w[] — create
  • a[i] / a[-1] — index
  • first / last / dig — read helpers
  • Array.new(n) { } — fresh object per slot
