Variadic Params and Forwarding

A splat *args collects extra positional arguments into an array, **opts collects extra keywords into a hash, and &block captures the block as a Proc. ... forwards everything (positional, keywords and block) to another method, and anonymous *, **, & forward just one kind.

Notes

  • Only one *rest and one **rest per method
  • ... must be the last parameter (leading args allowed: def f(a, ...))
  • Anonymous * / ** / & forwarding: Ruby 3.2+

Splats and Forwarding

def sum(*nums) = nums.sum
sum(1, 2, 3)                # 6
sum(*[4, 5])                # 9 (splat at call)

def tag(name, *classes, **attrs)
  [name, classes, attrs]
end
tag(:div, "a", "b", id: 1)  # [:div, ["a", "b"], {id: 1}]

def each_twice(&block)      # capture block as a Proc
  2.times(&block)
end
each_twice { print "hi " }  # hi hi

def log_call(...)           # forward everything
  puts "calling"
  target(...)
end

def wrap(*, **, &)          # anonymous forwarding (3.2+)
  inner(*, **, &)
end

Code Explained

*nums — any number of positional args, as an array
**attrs — extra keywords, as a hash
&block — the block as a Proc; pass it on with &block
... — forwards args, keywords and block unchanged

The Ruby Way

  • def f(*args, **kw, &blk) = g(*args, **kw, &blk) → def f(...) = g(...)
  • def f(list) called as f([a, b]) → def f(*items) called as f(a, b)
  • Capturing &block just to call it → use yield

In Rails

  • AS · delegate :name, :email, to: :user writes these forwarding methods for you
  • Rails · service objects often use def self.call(...) = new(...).call

Collectors

ParamReceives
*argsArray of extra positionals
**optsHash of extra keywords
&blkProc (or nil)
...everything, forwarded
* / ** / &anonymous, forwarded

Call-Site Spreads

CallPasses
f(*arr)elements as positionals
f(**hash)pairs as keywords
f(&proc)proc as the block

⚠ Common Mistakes

  • Passing an array without * to a *args method; it arrives as one element: [[1, 2]]
  • Mixing ... with other forwarding; you can't name *args and also use ...
  • Using &block everywhere; it allocates a Proc on each call, while yield doesn't

✓ Tips & Best Practices

  • ... is the cleanest way to write wrappers and decorators
  • Use *args for genuinely variable lists (like puts), keywords for options
  • block_given? works with yield; with &block you can test block.nil?

Quick Summary

  • *args / **opts — collect extras
  • &block — capture the block
  • ... — forward everything
  • f(*arr) / f(**h) — spread at call site
