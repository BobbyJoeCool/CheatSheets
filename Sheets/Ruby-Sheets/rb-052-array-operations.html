Array Operations

Arrays support set-like operators (&, \|, -) and combining methods (zip, product, flatten, transpose). These return new arrays; the originals are unchanged. Set operators remove duplicates in their result and compare elements with eql? and hash.

Notes

  • - removes every occurrence of each listed element
  • \| and & keep the left array's order
  • flatten(1) flattens just one level
  • * with a string joins: [1, 2] * "," → "1,2"

Combining Arrays

a = [1, 2, 2, 3]
b = [2, 3, 4]
a + b                        # [1, 2, 2, 3, 2, 3, 4]
a - b                        # [1]
a & b                        # [2, 3]
a | b                        # [1, 2, 3, 4]
a.uniq                       # [1, 2, 3]
[1, 2] * 2                   # [1, 2, 1, 2]

[[1, [2]], [3]].flatten      # [1, 2, 3]
[[1, [2]], [3]].flatten(1)   # [1, [2], 3]
[1, 2].zip([:a, :b])         # [[1, :a], [2, :b]]
[1, 2].product([:x, :y])     # [[1, :x], [1, :y], [2, :x], [2, :y]]
[[1, 2], [3, 4]].transpose   # [[1, 3], [2, 4]]
[1, 2, 3].rotate             # [2, 3, 1]
[3, 1, 2].reverse            # [2, 1, 3]
a.intersect?(b)              # true

Code Explained

- — difference; drops all matching values
& / \| — intersection / union, deduplicated
flatten(1) — limit the depth
zip — pair up by position
intersect? — any common element (3.1+)

The Ruby Way

  • (a + b).uniq → a \| b
  • a.select { |x| b.include?(x) } → a & b
  • (a & b).any? → a.intersect?(b)

In Rails

  • AS · [1, 2, 3].excluding(2) → [1, 3]; including(4) adds
  • AS · (1..7).to_a.in_groups_of(3) → rows padded with nil

⚠ Common Mistakes

  • Using a - b to remove one instance of a value; it removes them all
  • Calling transpose on ragged arrays; rows of different lengths raise IndexError
  • Expecting uniq on objects to use ==; it uses hash + eql? (sheet 070)

✓ Tips & Best Practices

  • uniq { |u| u.email } dedupes by a computed key
  • zip with a block iterates pairs without building the array
  • For heavy set math on large arrays, switch to Set (sheet 058)

Quick Summary

  • + / - — concat / difference
  • & / \| — intersect / union
  • zip / product / transpose — reshape
  • flatten(n) — remove nesting
