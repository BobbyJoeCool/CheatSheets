Sets

A Set is an unordered collection of unique elements with fast membership tests. In Ruby 4.0 Set is a core class reimplemented in C, so no require "set" is needed (and it's faster). Sets support union, intersection, difference and subset checks, and compare elements with eql? / hash like Hash keys.

Set Facts

  • include? is O(1) on average (vs O(n) for arrays)
  • Duplicates are silently ignored on add
  • add? returns nil if the element was already present
  • Sets keep insertion order when iterated

Using Sets

require "set"                # needed before 3.2; harmless in 4.0
tags = Set[:ruby, :rails]
tags << :ruby                # still 2 elements
tags.add?(:ruby)             # nil (already there)
tags.add?(:web)              # Set[:ruby, :rails, :web]
tags.include?(:rails)        # true
tags.size                    # 3

a = Set[1, 2, 3]
b = Set[2, 3, 4]
a | b                        # Set[1, 2, 3, 4]
a & b                        # Set[2, 3]
a - b                        # Set[1]
a ^ b                        # Set[1, 4]
Set[2, 3].subset?(a)         # true
a.superset?(Set[1])          # true
a.disjoint?(Set[9])          # true

[1, 1, 2].to_set             # Set[1, 2]
seen = Set.new
%w[a b a c].reject { !seen.add?(it) }  # ["a", "b", "c"]

Code Explained

Set[...] — literal-style constructor
<< / add — duplicates ignored
add? — nil when already present; handy for "seen" checks
\| & - ^ — union, intersection, difference, symmetric difference
subset? / superset? / disjoint? — relationships

The Ruby Way

  • arr.include?(x) inside a loop → build a Set once
  • arr.uniq after every insert → use a Set
  • (a & b).empty? with sets → a.disjoint?(b)

Set vs Array

⚠ Common Mistakes

  • Putting mutable objects (like arrays) in a set and then changing them; their hash changes and lookups fail
  • Expecting set[0]; sets have no index. Convert with to_a first
  • Serializing a Set to JSON directly; call to_a first

✓ Tips & Best Practices

  • Use a Set for allow-lists and "visited" tracking in graph searches
  • SortedSet was removed from the stdlib; sort with to_a.sort or use a gem
  • Freeze lookup sets in constants: ALLOWED = Set[:get, :post].freeze

Quick Summary

  • Set[...] — unique, unordered
  • include? — O(1) membership
  • \| & - ^ — set algebra
  • core class in 4.0 — no require needed
