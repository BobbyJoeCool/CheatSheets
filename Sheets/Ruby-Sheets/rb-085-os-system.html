Standard Library: OS and Processes

ENV reads environment variables, system runs a command and returns true / false, and backticks capture output. Open3.capture3 is the safe, complete option: it returns stdout, stderr and the exit status separately. exit / abort end the program, and OptionParser handles command-line flags.

Notes

  • ENV["X"] returns a String or nil
  • Pass commands as separate arguments to avoid shell injection
  • $? holds the last child process status
  • abort("msg") prints to stderr and exits with status 1

ENV, Commands, OptionParser

ENV["HOME"]                          # "/Users/ada"
ENV.fetch("API_KEY")                 # KeyError if unset
ENV.fetch("PORT", "3000").to_i       # 3000

system("ls", "-l")                   # true (output to terminal)
out = `git rev-parse --short HEAD`   # captured stdout
$?.success?                          # true

require "open3"
stdout, stderr, status = Open3.capture3("grep", "-c", "ERR", "app.log")
status.exitstatus                    # 0

require "optparse"
opts = { verbose: false }
OptionParser.new do |o|
  o.banner = "Usage: tool [options] FILE"
  o.on("-v", "--verbose", "Talk more") { opts[:verbose] = true }
  o.on("-n", "--count N", Integer)    { |n| opts[:count] = n }
end.parse!                           # removes flags from ARGV
abort("missing FILE") if ARGV.empty?
at_exit { puts "done" }
exit(0)

Code Explained

ENV.fetch — fail fast when a variable is required
system("ls", "-l") — args as a list, no shell parsing
backticks — capture stdout as a string
Open3.capture3 — stdout, stderr and status
OptionParser#parse! — parse and remove flags from ARGV

The Ruby Way

  • system("rm #{file}") → system("rm", file)
  • Backticks when you need stderr → Open3.capture3
  • Hand-parsing ARGV for flags → OptionParser

In Rails

  • Rails · Rails.env.production? instead of reading ENV["RAILS_ENV"]
  • Rails · keep secrets in Rails.application.credentials

⚠ Common Mistakes

  • Interpolating user input into a command string; that's shell injection. Pass arguments separately
  • Forgetting ENV values are strings: ENV["DEBUG"] == true is never true
  • Ignoring exit statuses; check $?.success? or the status from capture3

✓ Tips & Best Practices

  • system(..., exception: true) raises if the command fails (Ruby 2.6+)
  • ENV.fetch("X") { raise "set X" } gives a clear startup error
  • OptionParser builds --help output automatically from your on descriptions

Quick Summary

  • ENV / ENV.fetch — environment
  • system / backticks / Open3 — run commands
  • exit / abort / at_exit — program end
  • OptionParser — CLI flags
