RubyGems

RubyGems is Ruby's package system: a gem is a packaged library or tool, and the gem command installs, lists and removes them from rubygems.org. Ruby ships default gems (always installed, like json) and bundled gems (installed with Ruby but must be listed in a Gemfile under Bundler, like csv since 3.4).

Notes

  • Gems install into your Ruby's gem directory (no sudo with a version manager)
  • Executables from gems go on your PATH (rails, rubocop)
  • Versions follow semver: MAJOR.MINOR.PATCH
  • For projects, manage gems with Bundler (sheet 081)

The gem Command

gem install rubocop               # latest version
gem install rails -v 8.1.0        # specific version
gem install nokogiri --no-document  # skip docs (faster)
gem list                          # installed gems
gem list rails                    # filter by name
gem info rubocop                  # details + install path
gem outdated                      # newer versions available
gem update rubocop
gem uninstall rubocop -v 1.60.0
gem search ^rack                  # search rubygems.org
gem env                           # paths, version, sources
gem which json                    # file that `require "json"` loads
gem contents rake | head -5       # files in a gem
gem cleanup                       # remove old versions

Code Explained

gem install x -v — pin a version
--no-document — skip RDoc/ri generation
gem outdated / update — keep tools current
gem env — where gems and executables live
gem which json — find a library's file

The Ruby Way

  • gem install for every project dependency → a Gemfile + bundle install
  • sudo gem install → install Ruby with a version manager
  • Re-typing --no-document → put gem: --no-document in ~/.gemrc

Version Specs

SpecMeans
"1.2.3"exactly
">= 1.2"at least
"~> 1.2"≥ 1.2, < 2.0
"~> 1.2.3"≥ 1.2.3, < 1.3

⚠ Common Mistakes

  • Installing gems globally for a project and getting version conflicts between projects
  • Forgetting rbenv rehash (older rbenv) after installing a gem with an executable
  • Assuming a bundled gem like csv is always available; under Bundler it must be in the Gemfile

✓ Tips & Best Practices

  • gem install --user-install installs to your home directory when you can't use a version manager
  • gem info shows the homepage and license before you add a dependency
  • Check rubygems.org download counts and release dates when choosing between gems

Quick Summary

  • gem install / list / uninstall — manage gems
  • default vs bundled — always there vs Gemfile needed
  • ~> — pessimistic version constraint
  • Bundler — per-project gems
