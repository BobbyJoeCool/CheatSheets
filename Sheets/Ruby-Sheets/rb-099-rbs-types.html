Type Signatures: RBS and Sorbet

Ruby stays dynamically typed, but you can add gradual typing. RBS (bundled with Ruby) describes types in separate .rbs files under sig/, checked by Steep; TypeProf infers them from code. Sorbet (from Stripe) uses inline sig { } blocks in Ruby code and its own fast checker.

Notes

  • RBS files don't change runtime behavior
  • rbs-inline lets you write RBS in comments next to the code
  • Sorbet has typed: false / true / strict levels per file
  • Editors use these signatures for completion and hover types

RBS File

# sig/cart.rbs
class Cart
  attr_reader items: Array[Item]
  def initialize: () -> void
  def add: (Item item, ?qty: Integer) -> self
  def total: () -> Float
  def find: (String sku) -> Item?          # may return nil
end

Sorbet Inline

# typed: strict
class Cart
  extend T::Sig

  sig { params(item: Item, qty: Integer).returns(T.self_type) }
  def add(item, qty: 1) = tap { @items << [item, qty] }

  sig { returns(Float) }
  def total = @items.sum { |i, q| i.price * q }
end

Code Explained

sig/*.rbs — separate files; check with steep check (Sorbet: srb tc)
?qty: Integer — optional keyword
Item? — nilable return type
sig { params(...).returns(...) } — Sorbet inline signature
# typed: strict — Sorbet strictness level

The Ruby Way

  • Type checks with is_a? everywhere → signatures + a checker
  • Documenting types only in YARD comments → RBS or Sorbet sigs
  • Typing everything at once → start with core classes and strict files

⚠ Common Mistakes

  • Expecting RBS or Sorbet sigs to check types at runtime by default; RBS never does, Sorbet only with sorbet-runtime
  • Mixing RBS and Sorbet RBI in one project without a plan; pick one toolchain
  • Using untyped everywhere and getting no benefit

✓ Tips & Best Practices

  • rbs prototype rb lib/cart.rb generates a starting signature
  • Use typeprof on small libraries to bootstrap signatures
  • Gems can ship sig/ folders; rbs collection downloads community signatures

Quick Summary

  • RBS — separate signature files
  • Steep / TypeProf — check / infer
  • Sorbet — inline sig { }
  • gradual — type the important parts first
