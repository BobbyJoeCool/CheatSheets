Class Methods and Class-Level State

Class methods are called on the class itself (User.find) and are defined with def self.name or inside class << self. Class-level data lives in class instance variables (@count at class level), in class variables (@@count, shared with subclasses), or in constants. Factory methods that return new instances are a common use.

Notes

  • self inside a class body (outside methods) is the class
  • @@vars are shared across the whole inheritance tree (often surprising)
  • Class instance variables are per class, not inherited
  • Constants are looked up lexically and through ancestors

Class Methods and State

class Temperature
  SCALES = %i[c f].freeze           # constant
  @created = 0                      # class instance variable

  class << self                     # block of class methods
    attr_reader :created
    def from_f(f) = new((f - 32) * 5 / 9.0)
  end

  def self.boiling = new(100)       # single class method

  def initialize(c)
    @c = c
    self.class.instance_variable_set(:@created, self.class.created + 1)
  end
  attr_reader :c
end

Temperature.from_f(212).c           # 100.0
Temperature.boiling.c               # 100
Temperature.created                 # 2
Temperature::SCALES                 # [:c, :f]

Code Explained

class << self — opens the class's singleton class
def self.boiling — one class method
from_f — factory method returning new(...)
@created at class level — belongs to the class object
Temperature::SCALES — read a class constant

The Ruby Way

  • @@count for per-class counters → class instance variables
  • Many def self. methods → group them in class << self
  • Temperature.new(...) with conversion logic at call sites → named factories

In Rails

  • Rails · scope :recent, -> { order(created_at: :desc) } vs def self.recent — scopes always return a relation
  • AS · class_attribute :api_key is an inheritable, overridable class-level setting

⚠ Common Mistakes

  • Using @@vars and having a subclass silently change the parent's value
  • Calling an instance method from a class method (or vice versa) without a receiver
  • Mutating constants (SCALES << :k); freeze them so it raises instead

✓ Tips & Best Practices

  • private_class_method :new plus factories forces callers through validated constructors
  • Module#singleton_methods (or methods(false) on the class) lists class methods while debugging
  • Prefer class instance variables with class << self; attr_accessor for configuration

Quick Summary

  • def self.m / class << self — class methods
  • factory methods — named constructors
  • @civar vs @@cvar — per class vs shared
  • CONST — class constants
