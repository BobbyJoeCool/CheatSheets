Booleans & Truthiness

true / false · TrueClass · only nil and false are falsy · 0 and "" are truthy · !! · predicate methods

true, false and Truthiness

true and false are singleton objects of TrueClass and FalseClass; there is no Boolean class. In conditions, only nil and false are falsy. Everything else is truthy, including 0, "", [] and {}, which surprises people coming from Python, JavaScript or C.

Truthiness Rules

  • Falsy: false, nil. That's the whole list
  • Truthy: 0, 0.0, "", [], {}, "false"
  • !!value converts anything to true / false
  • Predicate methods end in ? and should return a boolean

Truthiness in Practice

true.class                # TrueClass
true & false              # false

puts "zero is truthy" if 0      # prints
puts "empty is truthy" if ""    # prints
puts "never" if nil             # (nothing)

!!nil                     # false
!!0                       # true
nil.to_a                  # []

[].empty?                 # true  — test emptiness explicitly
"".empty?                 # true
0.zero?                   # true
items = []
puts "none" if items.empty?     # none

flag = "false"
flag == "true"            # false — parse strings yourself

Code Explained

TrueClass — true is the only instance; no Boolean type exists
if 0 — runs; 0 is just an object
!!x — double negation gives a real boolean
empty? / zero? — ask the question you mean
"false" — a non-empty string, so truthy

The Ruby Way

  • if items.length > 0 → if items.any? or unless items.empty?
  • return x ? true : false → !!x (or return x from a ? method that already returns a boolean)
  • if flag == true → if flag

In Rails

  • AS · blank? is true for nil, false, "", " ", [], {}
  • AS · present? is !blank?; neither exists in plain Ruby
  • Rails · boolean columns cast "0", "false", "off" to false

⚠ Common Mistakes

  • Testing if count to mean "count is non-zero"; 0 is truthy, so use count.positive? or count.zero?
  • Treating "" as false when validating form input; check str.empty? or str.strip.empty?
  • Comparing x == true; it fails for truthy non-boolean values like 1 or "yes"

✓ Tips & Best Practices

  • Name boolean-returning methods with ? and keep them returning only true / false
  • Array#any? with no block is false for [nil, false]; it checks truthiness of elements
  • To parse a "boolean" string: %w[true yes 1 on].include?(s.downcase)

Quick Summary

  • nil / false — the only falsy values
  • 0, "", [] — truthy
  • !!x — force a boolean
  • empty? / zero? — explicit checks
