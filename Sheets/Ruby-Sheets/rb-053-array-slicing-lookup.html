arr[1..] · slice · take / drop · values_at · include? · index · sample / shuffle · fill

Slicing and Lookup

Beyond single indexes, arr[start, length] and arr[range] return sub-arrays, and take / drop grab from the front. Lookup methods answer "is it there?" (include?), "where is it?" (index), and "give me several" (values_at). sample and shuffle pick randomly.

Notes

  • Slices return new arrays; out-of-range slices return nil or []
  • index takes a value or a block
  • values_at accepts indexes and ranges
  • slice! removes and returns the slice

Slices and Lookups

a = %w[a b c d e]
a[1, 2]                      # ["b", "c"]
a[1..3]                      # ["b", "c", "d"]
a[2..]                       # ["c", "d", "e"]
a[..1]                       # ["a", "b"]
a.take(2)                    # ["a", "b"]
a.drop(3)                    # ["d", "e"]
a.values_at(0, 2, 4)         # ["a", "c", "e"]

a.include?("c")              # true
a.index("c")                 # 2
a.index { |x| x > "b" }      # 2
a.find_index("z")            # nil
a.sample                     # random element
a.shuffle(random: Random.new(1))  # repeatable order
b = a.dup
b.slice!(1, 2)               # ["b", "c"]; b is now ["a", "d", "e"]
Array.new(3).fill(0)         # [0, 0, 0]

Code Explained

a[1, 2] — start and length
a[2..] / a[..1] — endless / beginless ranges
take / drop — first n / all but first n
values_at — pick several indexes at once
slice! — cut a piece out of the array

The Ruby Way

  • a[0...n] → a.take(n) or a.first(n)
  • a.index(x) != nil → a.include?(x)
  • [a[0], a[2]] → a.values_at(0, 2)

In Rails

  • AS · arr.second, arr.third read like English
  • AS · arr.from(2) → elements from index 2; arr.to(1) → up to index 1

Lookup

MethodReturns
include?(v)true / false

⚠ Common Mistakes

  • Confusing a[1, 2] (length) with a[1..2] (end index)
  • Using include? on large arrays in a loop; each call is O(n). Convert to a Set
  • Calling shuffle! / sample in tests without a seed and getting flaky results

✓ Tips & Best Practices

  • first(n) and last(n) never return nil; they return shorter arrays
  • bsearch finds items in sorted arrays in O(log n) (sheet 060)
  • Pass random: Random.new(seed) to shuffle / sample for repeatable output

Quick Summary

  • a[s, n] / a[range] — slices
  • take / drop — from the front
  • include? / index — lookup
  • sample / shuffle — random
