HTTP Clients

The stdlib Net::HTTP handles HTTP without extra gems: Net::HTTP.get for quick reads, Net::HTTP.start for full control over headers, bodies and timeouts. Faraday is the most popular gem for real applications, adding middleware for JSON, retries and logging. Parse JSON responses with JSON.parse.

Notes

  • require "net/http" also loads URI
  • Check res.is_a?(Net::HTTPSuccess) or res.code (a String)
  • Always set open_timeout / read_timeout
  • Net::HTTP.get(uri) handles https itself; with start, pass use_ssl: true

Net::HTTP and Faraday

require "net/http"
require "json"

uri = URI("https://api.example.com/users/1")

res = Net::HTTP.start(uri.host, uri.port, use_ssl: true,
                      open_timeout: 3, read_timeout: 5) do |http|
  req = Net::HTTP::Post.new("/users",
                            "Content-Type" => "application/json")
  req["Authorization"] = "Bearer #{ENV.fetch('TOKEN')}"
  req.body = { name: "Ada" }.to_json
  http.request(req)
end
res.code                                       # "201"
JSON.parse(res.body) if res.is_a?(Net::HTTPSuccess)

require "faraday"
conn = Faraday.new("https://api.example.com") do |f|
  f.request :json
  f.response :json
end
conn.get("/users/1").body["name"]              # parsed hash

Code Explained

Net::HTTP.get(uri) — one-line GET, body only
Net::HTTP.start(...) do |http| — reuse a connection, set timeouts
Net::HTTP::Post.new + req.body — build a request
res.code / Net::HTTPSuccess — check the status
Faraday request :json / response :json — encode / decode automatically

The Ruby Way

  • open-uri URI.open(url).read in apps → Net::HTTP with timeouts
  • Manual JSON encode/decode on every call → Faraday JSON middleware
  • Ignoring status codes → res.value raises on non-2xx

⚠ Common Mistakes

  • Comparing res.code == 200; codes are strings, so use "200" or check the class
  • No timeouts; a slow server can hang your process for a long time
  • Building URLs by string concatenation; use URI.join and URI.encode_www_form

✓ Tips & Best Practices

  • Reuse one Net::HTTP.start block (or a Faraday connection) for many requests to the same host
  • URI.encode_www_form(q: "ruby", page: 2) builds query strings safely
  • Add faraday-retry for automatic retries with backoff

Quick Summary

  • Net::HTTP.get — quick GET
  • Net::HTTP.start — headers, body, timeouts
  • res.code / HTTPSuccess — status
  • Faraday — middleware-based client
