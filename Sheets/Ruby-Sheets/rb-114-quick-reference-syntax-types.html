⚠ Common Mistakes

  • 0 and "" are truthy — only nil and false are falsy
  • and / or have very low precedence; use && / || in expressions
  • Rescuing Exception instead of StandardError (catches interrupts and exits)

✓ Tips & Best Practices

  • Use p for debugging; it shows inspect output
  • Prefer guard clauses and modifier if for short checks
  • Use keyword arguments for anything beyond two parameters

Quick Summary

  • Everything is an object; methods return the last expression
  • #{} interpolation, symbols for names, nil and false falsy
  • case / in for pattern matching
  • Blocks with yield; lambdas with ->
