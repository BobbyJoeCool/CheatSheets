Debugging and Linting

Ruby ships the debug gem: put binding.break (or debugger) in code to stop and inspect, or binding.irb for a quick REPL at that point. RuboCop (or Standard) lints style and common bugs, and the stdlib Logger writes leveled log messages.

Notes

  • ruby -r debug/start script.rb starts under the debugger
  • binding.irb works without extra gems
  • rubocop -a auto-corrects safe offenses
  • Logger.new($stdout) logs to the terminal

Breakpoints, Logger, Linting

require "debug"
def total(items)
  sum = items.sum(&:price)
  binding.break if sum.negative?   # stop here (debug gem)
  sum
end

def parse(row)
  binding.irb                      # REPL with locals in scope
  row.split(",")
end

require "logger"
log = Logger.new($stdout, level: :info)
log.info("starting")               # I, [2026-10-17T…] INFO -- : starting
log.debug("details")               # hidden at :info level
log.error { "expensive #{dump}" }  # block: built only if logged

p obj.method(:save).source_location

Code Explained

binding.break — breakpoint with the full debugger
binding.irb — quick interactive inspection
Logger.new($stdout, level: :info) — leveled logging
log.error { } — lazy message, built only if needed
source_location — where a method is defined

The Ruby Way

  • puts debugging left in code → binding.break or Logger
  • Logging with string building at debug level → block form log.debug { }
  • Style debates in reviews → RuboCop / Standard in CI

In Rails

  • Rails · bin/rails console is an IRB session with your app loaded
  • Rails · Rails.logger.info writes to log/development.log; debug(obj) dumps in views

⚠ Common Mistakes

  • Committing binding.irb / binding.break; CI or production hangs waiting for input. Add a RuboCop rule (Lint/Debugger)
  • Running rubocop -A across a large codebase without reviewing; unsafe corrections can change behavior
  • Logging secrets or full request bodies at info level

✓ Tips & Best Practices

  • p returns its argument, so p(expr) is the quickest temporary probe
  • Use .rubocop.yml to tune cops and rubocop --auto-gen-config to adopt it gradually
  • VS Code's Ruby LSP integrates the debug gem for breakpoints in the editor

Quick Summary

  • binding.break / binding.irb — stop and inspect
  • Logger — leveled logs
  • rubocop -a — lint + auto-fix
  • source_location — find definitions
