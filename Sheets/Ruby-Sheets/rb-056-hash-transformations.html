Hash Transformations

Ruby makes it easy to reshape hashes: transform_values and transform_keys map one side, select / reject / filter_map filter, and to_h with a block builds a hash from any enumerable. group_by, tally and sort_by turn arrays into summary hashes.

Notes

  • select / reject on a Hash return a Hash
  • map on a Hash returns an Array; use to_h to get a hash back
  • sort_by returns an array of pairs
  • min_by / max_by return a [key, value] pair

Reshaping Hashes

prices = { apple: 1.2, pear: 0.8, kiwi: 2.5 }
prices.transform_values { (it * 100).round }  # {apple: 120, ...}
prices.transform_keys(&:to_s)        # {"apple" => 1.2, ...}
prices.select { |_, p| p > 1 }       # {apple: 1.2, kiwi: 2.5}
prices.reject { |_, p| p > 1 }       # {pear: 0.8}
prices.filter_map { |k, p| k if p < 2 }   # [:apple, :pear]
prices.to_h { |k, p| [k.upcase, p] }     # {APPLE: 1.2, ...}
prices.sort_by { |_, p| p }.first    # [:pear, 0.8]
prices.max_by { |_, p| p }           # [:kiwi, 2.5]
prices.sum { |_, p| p }              # 4.5

words = %w[ant bee cat ape]
words.group_by { it[0] }             # {"a" => ["ant", "ape"], ...}
words.map(&:size).tally              # {3 => 4}
words.each_with_index.to_h           # {"ant" => 0, "bee" => 1, ...}
words.zip(1..).to_h                  # {"ant" => 1, "bee" => 2, ...}

Code Explained

transform_values — new hash, same keys
select / reject — hash in, hash out
to_h { |k, v| [k2, v2] } — map into a new hash
group_by — key → array of members
tally — counts of each value

The Ruby Way

  • h.map { |k, v| [k, v * 2] }.to_h → h.transform_values { it * 2 }
  • h.each_with_object({}) { ... } for simple maps → to_h { }
  • Hash.new(0) counting loops → tally

In Rails

  • AS · users.index_by(&:id) → {1 => user1, ...}; ids.index_with { 0 } → {1 => 0, ...}
  • AS · deep_transform_keys(&:to_s) converts nested keys too

⚠ Common Mistakes

  • Calling map on a hash and expecting a hash back; you get an array of whatever the block returns
  • Sorting a hash with sort_by and forgetting to call to_h if you need a hash again
  • transform_keys! on a frozen hash, or one shared with other code

✓ Tips & Best Practices

  • transform_keys(a: :alpha) renames keys from a mapping hash (3.0+)
  • group_by(...).transform_values(&:count) is a quick histogram, though tally is simpler
  • each_with_object(Hash.new(0)) still wins for complex accumulation

Quick Summary

  • transform_values / transform_keys — map one side
  • select / reject — filter, keep a hash
  • to_h { } — build a hash
  • group_by / tally — summarize
