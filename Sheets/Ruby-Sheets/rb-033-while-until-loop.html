while, until and loop

while repeats while a condition is truthy and until repeats until it becomes truthy. loop do ... end runs forever until break, and it quietly stops when an enumerator raises StopIteration. In everyday Ruby these are less common than iterators like each and times (sheet 034).

Loop Notes

  • while / until don't create a new variable scope
  • loop does (it takes a block)
  • begin ... end while cond runs the body at least once
  • loop returns the enumerator's result on StopIteration

Condition Loops

i = 0
while i < 3
  print i                 # 012
  i += 1
end

n = 10
n -= 3 until n <= 0       # n == -2

begin
  input = gets&.chomp
end while input&.empty?   # do-while: body runs first

loop do
  line = $stdin.gets
  break if line.nil? || line.chomp == "quit"
  puts line.upcase
end

e = [1, 2].each
loop { puts e.next }      # 1, 2, then StopIteration ends it

Code Explained

while i < 3 — checks before each pass
begin ... end while — post-test loop (runs at least once)
loop do — infinite loop; leave with break
e.next — loop rescues StopIteration for you

The Ruby Way

  • while i < arr.size; arr[i]; i += 1; end → arr.each
  • while true → loop do
  • while !done → until done

⚠ Common Mistakes

  • Forgetting to update the counter in a while loop and hanging the program
  • Expecting variables first assigned inside loop do to exist after the loop; they're block-local
  • Using while to walk arrays by index; off-by-one errors are easy and each avoids them

✓ Tips & Best Practices

  • loop + external enumerators (next) is a clean way to read paired streams
  • Put the exit condition near the top of loop do with break if
  • For retries with limits, combine loop with a counter or use retry (sheet 039)

Quick Summary

  • while / until — condition loops
  • loop do — infinite loop + break
  • begin … end while — do-while
  • prefer iterators for collections
