Hash Methods

Hashes come with methods to query keys and values, merge hashes together, slice out subsets, delete entries, and dig into nested data. merge returns a new hash, while merge! (alias update) changes the receiver. A block passed to merge resolves conflicting keys.

Notes

  • key? / include? / member? are the same check
  • merge — later hashes win on duplicate keys
  • slice keeps listed keys; except drops them (3.0+)
  • delete returns the removed value

Query, Merge, Slice

h = { a: 1, b: 2, c: 3 }
h.keys                         # [:a, :b, :c]
h.values                       # [1, 2, 3]
h.key?(:b)                     # true
h.value?(3)                    # true
h.key(2)                       # :b (reverse lookup)

h.merge(c: 30, d: 4)           # {a: 1, b: 2, c: 30, d: 4}
h.merge({ a: 5 }) { |k, old, new| old + new }  # {a: 6, b: 2, c: 3}
h.slice(:a, :c)                # {a: 1, c: 3}
h.except(:a)                   # {b: 2, c: 3}
h.delete(:b)                   # 2 (h is now {a: 1, c: 3})

data = { user: { address: { city: "Oslo" } } }
data.dig(:user, :address, :city)   # "Oslo"
data.dig(:user, :phone, :area)     # nil
h.to_a                         # [[:a, 1], [:c, 3]]
h.each_pair { |k, v| puts "#{k}=#{v}" }
h.any? { |k, v| v > 2 }        # true

Code Explained

key(2) — find the key for a value
merge with a block — combine values on conflict
slice / except — keep / drop keys
delete — remove and return the value
dig — nil-safe nested lookup

The Ruby Way

  • h.keys.include?(k) → h.key?(k)
  • h.reject { |k, _| k == :a } → h.except(:a)
  • h[:a] && h[:a][:b] → h.dig(:a, :b)

In Rails

  • AS · deep_merge merges nested hashes; reverse_merge fills in defaults
  • AS · symbolize_keys / stringify_keys; except began in ActiveSupport before core

⚠ Common Mistakes

  • Expecting merge to modify the hash; it returns a new one. Use merge! or reassign
  • Using merge for nested config; inner hashes are replaced, not merged
  • Checking h[k].nil? to test presence; a key can exist with a nil value. Use key?

✓ Tips & Best Practices

  • h.merge(defaults) { |_, mine, _| mine } keeps existing values, like reverse_merge
  • filter_map / to_h and transform_values cover most reshaping (sheet 056)
  • dig also works across arrays: data.dig(:items, 0, :id)
