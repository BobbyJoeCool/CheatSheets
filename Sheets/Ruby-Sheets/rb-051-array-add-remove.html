Adding, Removing & Stack/Queue Use

push / << · pop · shift / unshift · insert · delete / delete_at · compact · stack & queue idioms

Adding and Removing Elements

Arrays grow and shrink at both ends, which makes them Ruby's built-in stack (push / pop) and queue (push / shift). Most mutating methods change the array in place and return either the array or the removed element, so read the return value carefully.

Notes

  • << and push return the array, so they chain
  • pop / shift return the removed item (or nil if empty)
  • delete removes every matching element
  • shift is O(1) in CRuby, so arrays make fine queues

Push, Pop, Shift, Delete

a = [1, 2, 3]
a << 4                       # [1, 2, 3, 4]
a.push(5, 6)                 # [1, 2, 3, 4, 5, 6]
a.pop                        # 6
a.shift                      # 1
a.unshift(0)                 # [0, 2, 3, 4, 5]
a.insert(1, :x)              # [0, :x, 2, 3, 4, 5]
a.delete(:x)                 # :x (returns the deleted value)
a.delete_at(0)               # 0
a.delete_if(&:even?)         # [3, 5]

[1, nil, 2, nil].compact     # [1, 2]
[1, 2] + [3]                 # [1, 2, 3] (new array)
[1, 2].concat([3], [4])      # [1, 2, 3, 4] (in place)

stack = []; stack.push(1); stack.push(2); stack.pop  # 2 (LIFO)
queue = []; queue.push(1); queue.push(2); queue.shift # 1 (FIFO)

Code Explained

<< / push — append at the end
pop / shift — remove from end / start
unshift / insert — add at start / position
delete(v) — removes all equal values
delete_if — remove by condition, in place

The Ruby Way

  • a = a + [x] in a loop → a << x
  • a.delete_at(a.index(x)) → a.delete(x) (or a.slice!)
  • a.reject! { } returning nil when unchanged → delete_if always returns the array

⚠ Common Mistakes

  • Modifying an array while iterating it with each; elements get skipped. Use delete_if or reject
  • Expecting delete to remove only the first match; it removes all. Use delete_at(index(v)) for one
  • Using + in loops; it builds a new array every time

✓ Tips & Best Practices

  • Thread::Queue is the thread-safe queue (sheet 094); plain arrays are not
  • pop(2) / shift(2) remove several elements at once
  • clear empties an array in place, keeping other references valid

Quick Summary

  • << / push / pop — stack
  • push / shift — queue
  • delete / delete_at / delete_if — remove
  • compact — drop nils
