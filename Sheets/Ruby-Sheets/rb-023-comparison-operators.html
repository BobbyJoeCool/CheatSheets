Comparison and the Spaceship

Comparison operators return true / false, except the spaceship <=>, which returns -1, 0, 1, or nil when values can't be compared. <=> is what sorting uses, and including Comparable turns one <=> method into <, >, between?, clamp and more.

Comparison Notes

  • == compares values; != is defined as !(a == b)
  • 1 == 1.0 is true; 1.eql?(1.0) is false
  • Strings compare byte-wise: "Z" < "a" is true
  • <=> returns nil for unrelated types: 1 <=> "a"

Comparing Values

5 == 5.0                 # true
5 != 6                   # true
3 < 5                    # true
"apple" < "banana"       # true
"Zebra" < "apple"        # true (uppercase sorts first)
[1, 2] == [1, 2]         # true (element-wise)
[1, 2] <=> [1, 3]        # -1

1 <=> 2                  # -1
2 <=> 2                  # 0
3 <=> 2                  # 1
1 <=> "a"                # nil

5.between?(1, 10)        # true
15.clamp(1, 10)          # 10
-3.clamp(0..)            # 0
"b".clamp("a", "c")      # "b"

%w[pear Apple fig].sort  # ["Apple", "fig", "pear"]
%w[pear Apple fig].sort_by(&:downcase)  # ["Apple", "fig", "pear"]
[3, 1, 2].max            # 3

Code Explained

<=> — -1 / 0 / 1 tells sort which comes first
nil — returned when the two values can't be ordered
between? / clamp — come from Comparable
clamp(0..) — clamp with an endless range
sort_by(&:downcase) — case-insensitive ordering

The Ruby Way

  • x >= 1 && x <= 10 → x.between?(1, 10)
  • [[x, lo].max, hi].min → x.clamp(lo, hi)
  • sort { |a, b| a.age <=> b.age } → sort_by(&:age)

⚠ Common Mistakes

  • Sorting mixed types; [1, "a"].sort raises ArgumentError because <=> returns nil
  • Forgetting that "10" < "9" is true for strings; convert numbers before comparing
  • Defining < and > by hand instead of <=> plus include Comparable

✓ Tips & Best Practices

  • Compare multiple keys with arrays: [a.last, a.first] <=> [b.last, b.first]
  • Use casecmp? for case-insensitive equality and casecmp for case-insensitive ordering
  • Float::NAN <=> 1 is nil, so NaN breaks sorts; filter it out first

Quick Summary

  • == / != — value equality
  • <=> — three-way compare
  • Comparable — free operators from <=>
  • clamp / between? — range helpers
