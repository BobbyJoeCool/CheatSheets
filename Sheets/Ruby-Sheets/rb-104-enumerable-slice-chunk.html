each_slice · each_cons · chunk · chunk_while · slice_when · cycle · uniq { }

Enumerable: Slice and Chunk

These methods split a collection into groups by size or by relationships between neighbors. each_slice(n) makes fixed-size chunks, each_cons(n) makes overlapping windows, and chunk_while / slice_when start a new group when adjacent elements stop (or start) satisfying a condition. chunk groups consecutive elements with the same key.

Notes

  • These return Enumerators; add .to_a or chain map
  • chunk only groups consecutive equal keys (unlike group_by)
  • cycle(n) repeats the collection n times (forever without n)
  • uniq { } deduplicates by a computed key

Slicing and Chunking

(1..7).each_slice(3).to_a        # [[1, 2, 3], [4, 5, 6], [7]]
(1..5).each_cons(2).to_a         # [[1, 2], [2, 3], [3, 4], [4, 5]]
[3, 5, 9].each_cons(2).map { |a, b| b - a }  # [2, 4]

nums = [1, 2, 3, 7, 8, 10]
nums.chunk_while { |a, b| b == a + 1 }.to_a
# [[1, 2, 3], [7, 8], [10]]
nums.slice_when { |a, b| b > a + 1 }.to_a     # same groups

temps = [12, 14, 21, 25, 19, 8]
temps.chunk { it > 18 ? :warm : :cool }.to_a
# [[:cool, [12, 14]], [:warm, [21, 25, 19]], [:cool, [8]]]

lines = ["# A", "x", "# B", "y", "z"]
lines.slice_before { it.start_with?("#") }.to_a
# [["# A", "x"], ["# B", "y", "z"]]
%w[apple Avocado bean].uniq { it[0].downcase }  # ["apple", "bean"]

Code Explained

each_slice(3) — fixed-size, non-overlapping chunks
each_cons(2) — sliding window of neighbors
chunk_while — keep grouping while the condition holds
chunk — consecutive runs with the same key
slice_before — start a group at each matching element

The Ruby Way

  • Index math for pairs (arr[i], arr[i + 1]) → each_cons(2)
  • Manual "current group" loops → chunk_while / slice_when
  • group_by { }.values when order matters → chunk

In Rails

  • Rails · User.in_batches(of: 500) { |rel| rel.update_all(flag: true) } batches in SQL
  • AS · arr.in_groups_of(3, false) is like each_slice(3); in_groups(3) splits into 3 groups

⚠ Common Mistakes

  • Expecting chunk to merge non-adjacent equal keys; use group_by for that
  • Forgetting .to_a and printing an Enumerator object
  • Calling cycle without a limit inside map; it never ends

✓ Tips & Best Practices

  • each_cons(2).all? { |a, b| a <= b } checks that an array is sorted
  • slice_when is perfect for detecting gaps in sequences or time series
  • each_slice keeps batch API calls under rate limits

Quick Summary

  • each_slice(n) — chunks
  • each_cons(n) — sliding windows
  • chunk_while / slice_when — split by neighbors
  • chunk — consecutive runs
