⚠ Common Mistakes

  • Hash#[] returning nil silently — use fetch when a key must exist
  • Mutating a frozen string literal (FrozenError)
  • method_missing without respond_to_missing?

✓ Tips & Best Practices

  • Use bundle exec so commands run with the Gemfile's gem versions
  • Prefer Data.define for small immutable value objects
  • Chain Enumerable methods instead of manual loops

Quick Summary

  • Arrays and hashes + Enumerable do most work
  • attr_accessor, include, super for OOP
  • File / JSON / CSV for data
  • Bundler + Rake + RSpec / Minitest for projects
