Special Operators

Some of Ruby's most-used operators don't fit the usual categories: === (case equality, used by case/when), =~ (regex match), &. (safe navigation), .. / ... (ranges), :: (constant lookup), defined? and -> (lambda literal).

Notes

  • === is a method; each class defines what "matches" means
  • .. includes the end, ... excludes it
  • defined? returns a description string or nil
  • :: with nothing on the left means top-level: ::File

=== =~ &. .. :: defined? ->

Integer === 5            # true  (is-a)
(1..10) === 5            # true  (cover)
/ab/ === "cab"           # true  (match)

"price: 42" =~ /\d+/     # 7
$~[0]                    # "42"
"no" !~ /\d/             # true

user&.email              # nil if user is nil
(1..5).to_a              # [1, 2, 3, 4, 5]
(1...5).to_a             # [1, 2, 3, 4]

Math::PI                 # 3.141592653589793
::File                   # top-level constant

defined?(foo)            # nil
defined?(puts)           # "method"
defined?(String)         # "expression"
square = ->(x) { x * x }
square.(4)               # 16

Code Explained

=== — "does the right side belong to the left side?"
=~ — match position or nil; sets $~
!~ — true when there's no match
.. / ... — inclusive / exclusive range
->(x) { } — lambda literal; call with .() or .call

The Ruby Way

  • if x.is_a?(Integer) || x.is_a?(Float) → case x when Integer, Float
  • if user != nil && user.email → user&.email
  • lambda { |x| ... } → ->(x) { ... }

⚠ Common Mistakes

  • Flipping ===: 5 === Integer is false; the pattern always goes on the left
  • Using defined?(@var) to test for nil; it only tells you whether the variable exists
  • Writing 1..5.each; .. has low precedence, so wrap it: (1..5).each

✓ Tips & Best Practices

  • Lambdas work in when: when ->(n) { n > 100 } then "big"
  • Use :: only for constants and nested modules; use . to call methods
  • defined?(yield) (or block_given?) checks whether a block was passed

Quick Summary

  • === — case equality
  • =~ — regex match position
  • &. — safe call
  • .. / ... / :: / -> — range / scope / lambda
