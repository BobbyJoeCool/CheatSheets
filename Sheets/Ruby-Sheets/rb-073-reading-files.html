Reading Files

File.read · File.readlines(chomp: true) · File.foreach · File.open block · each_line · IO modes

Reading Files

For small files, File.read returns the whole contents and File.readlines returns an array of lines. For large files, File.foreach streams one line at a time with constant memory. The block form of File.open gives you the file object and closes it automatically, even when an exception is raised.

Notes

  • Lines keep their \n unless you pass chomp: true
  • Paths are relative to the current working directory, not the script
  • Missing file → Errno::ENOENT
  • Default encoding is UTF-8; pass encoding: for others

Reading

text  = File.read("notes.txt")                 # whole file
lines = File.readlines("notes.txt", chomp: true)  # array, no \n

File.foreach("big.log") do |line|              # streams, low memory
  puts line if line.include?("ERROR")
end
File.foreach("big.log").count                  # line count

File.open("notes.txt") do |f|                  # auto-closed
  header = f.gets.chomp
  f.each_line.with_index(2) { |l, n| puts "#{n}: #{l}" }
end

File.read("data.bin", mode: "rb")              # binary
File.read("latin.txt", encoding: "ISO-8859-1:UTF-8")
here = File.join(__dir__, "notes.txt")         # relative to script
File.exist?(here) ? File.read(here) : ""
File.read("missing.txt")                       # Errno::ENOENT

Code Explained

File.read — whole file as one string
readlines(chomp: true) — array of clean lines
File.foreach — iterate without loading everything
File.open { |f| } — closes on exit, success or error
__dir__ — directory of the current source file

The Ruby Way

  • f = File.open(p); f.read; f.close → File.read(p)
  • File.readlines(p).each on huge files → File.foreach(p)
  • line.chomp on every line → chomp: true

⚠ Common Mistakes

  • Using paths relative to the script while running from another directory; build them with __dir__
  • File.readlines on multi-GB logs; it loads everything into memory
  • Opening files without the block form and leaking file handles on exceptions

✓ Tips & Best Practices

  • File.foreach(p).lazy.select { … }.first(10) stops reading early
  • Use mode: "rb" for images and archives to avoid encoding conversion
  • Pathname#read / #each_line give the same methods on path objects (sheet 075)

Quick Summary

  • File.read — whole file
  • readlines(chomp: true) — line array
  • File.foreach — stream lines
  • File.open { } — auto-close
