Input & Command-Line Arguments

gets · chomp · $stdin · STDIN.read · ARGV · ARGF · Integer(gets)

Reading Input

gets reads one line from standard input including the trailing newline, so it is almost always followed by chomp. Command-line arguments arrive as strings in the ARGV array, and ARGF reads from files named in ARGV or from stdin when none are given, like Unix filters do.

Input Notes

  • gets returns nil at end of input (Ctrl-D)
  • ARGV holds strings only; convert with Integer() / Float()
  • Inside a script, gets reads from files in ARGV first; use $stdin.gets to force the keyboard
  • $stdin.read slurps everything until EOF

Prompts, ARGV and ARGF

print "Name: "
name = gets.chomp                 # "Ada"
print "Age: "
age = Integer(gets)               # raises on "abc"
age = gets.to_i                   # "abc" → 0 (silent)

# ruby greet.rb Ada 36 --loud
ARGV                              # ["Ada", "36", "--loud"]
first, *rest = ARGV               # "Ada", ["36", "--loud"]
loud = ARGV.delete("--loud")      # removes the flag

$stdin.each_line do |line|        # read until EOF
  puts line.chomp.upcase
end

# cat a.txt | ruby filter.rb   or   ruby filter.rb a.txt b.txt
ARGF.each_line { |l| print l if l =~ /TODO/ }

Code Explained

gets.chomp — strip the "\n" that gets keeps
Integer(gets) — strict: raises ArgumentError on bad input
gets.to_i — lenient: returns 0 for junk
ARGV.delete — pull flags out before treating the rest as files
ARGF — files from ARGV, else stdin

The Ruby Way

  • gets.strip.to_i everywhere → Integer(gets, exception: false) and handle nil
  • Manually opening each ARGV file → iterate ARGF
  • Hand-parsing many flags → OptionParser (sheet 085)

⚠ Common Mistakes

  • Forgetting chomp, so "yes\n" == "yes" is false
  • Calling gets in a script that received file args; it reads the file, not the keyboard. Use $stdin.gets
  • Using to_i for validation; "abc".to_i is 0, which looks like valid input

✓ Tips & Best Practices

  • while (line = gets) loops until EOF and works with pipes
  • Use Integer(str, exception: false) to get nil instead of rescuing
  • STDIN.tty? tells you whether input is a keyboard or a pipe

Quick Summary

  • gets.chomp — read a clean line
  • ARGV — argument strings
  • ARGF — files or stdin
  • Integer() — strict conversion
