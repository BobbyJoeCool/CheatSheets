Iterating: each, times & for

each · times · upto / downto · step · each_with_index · for...in (and why it's rare)

Iterating with each, times, step

Ruby code loops with iterator methods that take a block rather than with counters. each walks a collection, times repeats, upto / downto / step count, and each_with_index adds a position. A for ... in loop exists, but it leaks its variable and is rarely used.

Iterator Notes

  • Every iterator returns its receiver (or an enumerator without a block)
  • Block variables are local to the block
  • for x in list is sugar for each without the new scope
  • with_index(1) starts counting at 1

Iteration Methods

3.times { |i| print i }          # 012
1.upto(4) { |i| print i }        # 1234
5.downto(3) { |i| print i }      # 543
0.step(10, 5) { |i| print i, " " }   # 0 5 10
1.0.step(2.0, 0.5).to_a          # [1.0, 1.5, 2.0]
(1..9).step(4).to_a              # [1, 5, 9]

%w[a b c].each { |x| print x }   # abc
%w[a b c].each_with_index { |x, i| puts "#{i}:#{x}" }
%w[a b c].each.with_index(1) { |x, i| puts "#{i}. #{x}" }
{ a: 1, b: 2 }.each { |k, v| puts "#{k}=#{v}" }
[[1, 2], [3, 4]].each { |(a, b)| print a + b, " " }  # 3 7

for x in [1, 2]                  # legal, but…
end
x                                # 2 — leaks out of the loop

Code Explained

3.times — yields 0, 1, 2
0.step(10, 5) — start, limit, increment
each_with_index — element, then index
each.with_index(1) — index offset for numbered lists
for x in — x survives after the loop

The Ruby Way

  • for i in 0...arr.size → arr.each_with_index
  • i = 0; arr.each { ...; i += 1 } → each_with_index
  • (0...n).each → n.times

⚠ Common Mistakes

  • Using for and then reusing the loop variable name later; it still holds the last value
  • Reversing block params on each_with_index (|i, x|); the element comes first
  • Calling each when you want a new array; each returns the original. Use map

✓ Tips & Best Practices

  • Call an iterator without a block to get an Enumerator: arr.each_with_index.map { |x, i| ... }
  • Integer#step with floats avoids accumulating rounding error that += loops have
  • Prefer each over for; it's the idiom every Ruby reader expects

Quick Summary

  • times / upto / step — counting
  • each — walk a collection
  • each_with_index / with_index(1) — positions
  • for — legal, leaks its variable
