Standard Library: Math and Random

The Math module provides floating-point functions and constants (sqrt, log, sin, PI). rand and the Random class generate pseudo-random numbers, with a seed for repeatable sequences. For tokens, passwords and anything security-related, use SecureRandom.

Notes

  • Math functions return Floats: Math.sqrt(16) is 4.0
  • rand with no args gives a Float in [0, 1)
  • Random.new(seed) repeats the same sequence
  • require "securerandom" for SecureRandom

Math, rand, SecureRandom

Math.log10(1000)              # 3.0
Math.log2(8)                  # 3.0
Math.sin(Math::PI / 2)        # 1.0
[12.gcd(18), 12.lcm(18)]      # [6, 36]

rand                          # 0.734... (Float)
rand(10)                      # 0..9
rand(1..6)                    # 1..6 (dice)
[1, 2, 3].sample              # random element
rng = Random.new(42)
rng.rand(100)                 # 51 (same every run with seed 42)

require "securerandom"
SecureRandom.hex(8)           # "3f9a1c2b7d4e6f80"
SecureRandom.uuid             # "b7f1…-…" (v4)
SecureRandom.alphanumeric(12) # "aZ3kP9qL2mXb"

Code Explained

Math.sqrt — Float result; Integer.sqrt for exact ints
Math.hypot(3, 4) — distance without overflow issues
rand(1..6) — inclusive integer range
Random.new(42) — seeded, repeatable generator
SecureRandom — cryptographically secure values

The Ruby Way

  • rand(6) + 1 → rand(1..6)
  • arr[rand(arr.size)] → arr.sample
  • rand.to_s for tokens → SecureRandom.hex / urlsafe_base64

⚠ Common Mistakes

  • Using rand for passwords or session tokens; it's predictable. Use SecureRandom
  • Passing degrees to Math.sin; it expects radians (deg * Math::PI / 180)
  • Math.sqrt(-1) raises Math::DomainError; use Complex if you need imaginary results

✓ Tips & Best Practices

  • Use Random.new(seed) and pass it into code under test (shuffle(random: rng))
  • SecureRandom.uuid_v7 gives time-ordered UUIDs (Ruby 3.3+)
  • Float#round(n) before display; Math results carry float noise

Quick Summary

  • Math.sqrt / log / sin — float math
  • rand(range) — random numbers
  • Random.new(seed) — repeatable
  • SecureRandom — security-grade randomness
