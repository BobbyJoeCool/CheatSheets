What Ruby Is

Ruby is a dynamic, object-oriented language created by Yukihiro "Matz" Matsumoto in 1995, designed for programmer happiness. Everything is an object, including integers, nil and classes themselves. Code reads close to English, blocks make iteration expressive, and the standard library ships batteries for files, JSON, dates and networking.

Quick Facts

  • File extension .rb; run with ruby file.rb
  • CRuby / MRI is the reference implementation (written in C)
  • New major/minor versions ship every December 25
  • Ruby 4.0 (2025): ZJIT, Ruby::Box, core Set, Ractor::Port
  • Best known for Rails, scripting, DevOps (Chef, Vagrant), CLIs

Hello, Ruby

# hello.rb
puts "Hello, World!"          # Hello, World!

puts

3.class                       # => Integer

Integer.class                 # => Class
3.even?                       # => false
"ruby".upcase.reverse         # => "YBUR"
[3, 1, 2].sort.first          # => 1

RUBY_VERSION                  # => "4.0.0"
RUBY_ENGINE                   # => "ruby"

Code Explained

puts — prints a line; no main() or boilerplate needed
5.times { } — integers are objects with methods
nil.class — even "nothing" is an object
Integer.class — classes are objects too (instances of Class)
RUBY_VERSION — constant for the running interpreter version

The Ruby Way

  • for i in 0...5 → 5.times { |i| }
  • if (x == nil) → if x.nil? or just unless x
  • return result at the end → let the last expression return

⚠ Common Mistakes

  • Assuming Ruby is "just Rails"; Rails is a framework, Ruby is the language underneath it
  • Following old 1.8/1.9 tutorials; hash syntax, keyword args and string encoding all changed since
  • Expecting static types; Ruby checks types at runtime, so typos surface only when the line runs

✓ Tips & Best Practices

  • Check ruby -v before following a tutorial; pin the version per project with .ruby-version
  • Use irb to try every snippet on these sheets; it prints each result for you
  • Read the official docs at docs.ruby-lang.org, or offline with ri String#split
