CSV

The csv library reads and writes comma-separated data, handling quoting, embedded commas and newlines correctly. Since Ruby 3.4 csv is a bundled gem, so add it to your Gemfile when using Bundler. With headers: true, each row becomes a CSV::Row you can index by column name.

CSV Notes

  • require "csv" first
  • headers: true treats the first line as column names
  • converters: :numeric turns "42" into 42
  • CSV.foreach streams large files row by row

Reading and Writing CSV

require "csv"
rows = CSV.read("people.csv")           # [["name", "age"], ["Ada", "36"]]

CSV.foreach("people.csv", headers: true, converters: :numeric) do |row|
  puts "#{row["name"]} is #{row["age"] + 1}"   # Ada is 37
end

table = CSV.read("people.csv", headers: true)
table["name"]                           # ["Ada", "Bob"] (column)
table.first.to_h                        # {"name" => "Ada", "age" => "36"}

CSV.open("out.csv", "w") do |csv|
  csv << %w[name age]                   # header row
  csv << ["Lin, Jr.", 41]               # comma gets quoted
end

line = CSV.generate_line(["a", "b,c"])  # "a,\"b,c\"\n"
CSV.parse("x;y\n1;2", col_sep: ";", headers: true).map(&:to_h)
# [{"x" => "1", "y" => "2"}]

Code Explained

CSV.read — all rows as arrays of strings
headers: true — rows act like hashes keyed by column
converters: :numeric — numbers instead of strings
CSV.open(…, "w") + << — write rows, quoting handled
col_sep: ";" — other delimiters

The Ruby Way

  • line.split(",") → CSV.parse_line(line) (handles quotes)
  • row[1] positional access → headers: true and row["age"]
  • Reading whole files with CSV.read for huge inputs → CSV.foreach

In Rails

  • Rails · send_data CSV.generate { |csv| … }, filename: "users.csv" streams a download
  • Rails · add gem "csv" to the Gemfile on Ruby 3.4+

⚠ Common Mistakes

  • Splitting lines on commas and breaking on quoted fields like "Lin, Jr."
  • Forgetting values are strings; "36" + 1 raises. Use converters: :numeric
  • On Ruby 3.4+, require "csv" failing under Bundler because the gem isn't in the Gemfile

✓ Tips & Best Practices

  • header_converters: :symbol gives row[:age] access and works with pattern matching
  • Add encoding: "bom\|utf-8" for CSVs exported from Excel
  • CSV::Table#by_col and #each let you process columns or rows

Quick Summary

  • CSV.read / foreach — read
  • headers: true — named columns
  • converters: :numeric — numbers
  • CSV.open … << — write
