Pattern Matching Advanced

Beyond basic shapes, patterns support find patterns ([*, x, *]), the pin operator (^) for comparing against an existing value, guards (if / unless), and alternatives (\|). Your own classes join in by defining deconstruct (array patterns) and deconstruct_keys (hash patterns).

Advanced Notes

  • ^name compares with a local; ^(expr) with any expression
  • Guards run after the pattern matches
  • x in pattern returns true / false and never raises

Find, Pin, Guards, Custom Classes

case [1, 42, "x", 7]
in [*, String => s, *] then "found #{s}"   # "found x"
end

expected = 5
case 5
in ^expected then "match"                  # pin, don't rebind
end
case order
in { total: Integer => t } if t > 100 then "big"   # guard
in { total: }                         then "normal"
end

Point = Struct.new(:x, :y)
case Point.new(0, 3)
in [0, y] then "on y-axis at #{y}"         # deconstruct
end
class Temp
  def initialize(c) = @c = c
  def deconstruct_keys(keys) = { celsius: @c }
end
Temp.new(30) in { celsius: 25.. }          # true

Code Explained

^expected — compare, don't rebind
if t > 100 — guard filters after matching
deconstruct_keys(keys) — return a hash for hash patterns

The Ruby Way

  • arr.find { |e| e.is_a?(String) } inside a case → in [*, String => s, *]
  • Re-checking a bound value in the branch body → a guard if ...
  • respond_to? checks on custom objects → define deconstruct_keys

⚠ Common Mistakes

  • Forgetting ^ and accidentally rebinding: in expected matches anything and overwrites expected
  • Using alternatives with bindings: in [x] \| [x, _] is a syntax error; alternatives can't bind names
  • Returning all fields from deconstruct_keys on hot paths; use the keys argument to compute only what's asked

✓ Tips & Best Practices

  • deconstruct_keys(keys) receives nil when the pattern uses **rest; return everything then
  • Data.define value objects work with both array and hash patterns for free
  • Use in as a boolean filter: events.select { it in { type: :click } }

Quick Summary

  • [*, x, *] — find pattern
  • ^var — pin
  • if / unless — guards
  • deconstruct / deconstruct_keys — custom matching
