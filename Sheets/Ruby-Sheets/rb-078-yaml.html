YAML

YAML is the common format for Ruby config files. require "yaml" loads Psych, which maps YAML to hashes, arrays, strings, numbers, booleans and nil. YAML.load_file is safe by default since Psych 4 (Ruby 3.1): it refuses arbitrary Ruby objects unless you list them in permitted_classes.

YAML Notes

  • Keys load as strings unless you pass symbolize_names: true
  • yes / no / on stay strings in YAML 1.2 style but booleans in 1.1 tools
  • Dates need permitted_classes: [Date] or YAML.unsafe_load
  • Aliases (&x / *x) need aliases: true

Load and Dump YAML

require "yaml"
yaml = <<~YML
  app: shop
  port: 8080
  debug: true
  hosts:
    - a.example.com
    - b.example.com
YML
cfg = YAML.safe_load(yaml, symbolize_names: true)
cfg[:port]                       # 8080
cfg[:hosts].size                 # 2

YAML.load_file("config.yml")     # safe by default (Psych 4)
YAML.load_file("dates.yml", permitted_classes: [Date])

{ "name" => "Ada", "langs" => %w[ruby c] }.to_yaml
# "---\nname: Ada\nlangs:\n- ruby\n- c\n"
YAML.dump([1, nil])              # "---\n- 1\n-\n"

Code Explained

YAML.safe_load — plain data only, no Ruby objects
symbolize_names: true — symbol keys
permitted_classes: [Date] — allow specific types
to_yaml / YAML.dump — Ruby → YAML text

The Ruby Way

  • YAML.load(untrusted) on old Ruby → YAML.safe_load
  • Ruby code in config files → plain YAML (or ERB + YAML when values need it)
  • cfg["db"]["host"] → symbolize_names: true + cfg.dig(:db, :host)

In Rails

  • Rails · config_for(:payment) loads config/payment.yml per environment
  • Rails · secrets live in encrypted credentials.yml.enc

⚠ Common Mistakes

  • Upgrading Ruby and getting Psych::DisallowedClass for dates or symbols; add permitted_classes
  • Indentation mistakes; YAML is whitespace-sensitive and tabs aren't allowed
  • Unquoted values like NO (a country code) parsing as false in YAML 1.1 tools; quote ambiguous strings

✓ Tips & Best Practices

  • Quote version numbers ("3.10"); unquoted they become floats like 3.1
  • YAML.load_file(p, symbolize_names: true, freeze: true) gives frozen config
  • Use anchors and aliases to share defaults between environments
