Interpolation and Formatting

"#{expr}" evaluates any Ruby expression and calls to_s on it. For layout and number formatting use format (alias sprintf) or the % operator, which take printf-style specifiers. rjust, ljust and center pad strings for simple column alignment.

Format Notes

  • format and % return strings; printf prints
  • %-10s left-aligns, %10s right-aligns
  • Named references: format("%<n>05.1f", n: 3.14)
  • to_s(2) / to_s(16) format integers in other bases

Formatting Output

name, score = "Ada", 93.456
"Hi #{name}, #{score.round(1)}%"   # "Hi Ada, 93.5%"
"Sum: #{1 + 2}"                    # "Sum: 3"

format("%.2f", score)              # "93.46"
format("%08.3f", score)            # "0093.456"
format("%5d|", 42)                 # "   42|"
format("%-5d|", 42)                # "42   |"
format("%+d", 5)                   # "+5"
format("%x %o %b", 255, 8, 5)      # "ff 10 101"
format("%s has %d", "box", 3)      # "box has 3"
format("%<x>s-%<y>s", x: 1, y: 2)  # "1-2"
"%05.1f" % 3.14159                 # "003.1"
"%s & %s" % ["a", "b"]             # "a & b"

"id".ljust(6, ".") + "|"           # "id....|"
"7".rjust(3, "0")                  # "007"
1234567.to_s.reverse.scan(/\d{1,3}/).join(",").reverse  # "1,234,567"

Code Explained

#{} — any expression; result goes through to_s
%08.3f — zero-pad to width 8, 3 decimals
%-5d — left-align in a 5-char field
%<x>s — named arguments from a hash
% with an array — multiple values

The Ruby Way

  • "Total: " + total.to_s → "Total: #{total}"
  • x.to_s.rjust(3, "0") for numbers → format("%03d", x)
  • Hand-rolled decimal rounding for display → format("%.2f", x)

In Rails

  • AS · Time#to_fs(:db) → "2026-10-17 14:05:00"
  • Rails · number_to_percentage(93.456, precision: 1) → "93.5%"
  • Rails · number_to_human(1_234_567) → "1.23 Million"

⚠ Common Mistakes

  • Writing "#{name}" inside single quotes; it prints literally
  • Passing a single array to % when the format has one %s: "%s" % [[1, 2]] is needed to print the array itself
  • Using round(2) and expecting trailing zeros; 3.10.round(2) displays 3.1. Use format("%.2f")

✓ Tips & Best Practices

  • %p inside format is handy for debug strings: format("got %p", value)
  • Integer#digits, to_s(2), and format("%08b", n) cover most binary display needs
  • inspect in interpolation ("#{x.inspect}") shows quotes and nils clearly
