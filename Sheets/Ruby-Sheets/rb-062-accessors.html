attr_reader · attr_writer · attr_accessor · custom setters · self.x = · validation in setters

Attribute Accessors

Instance variables are private, so classes expose them through methods. attr_reader generates getters, attr_writer generates setters (name=), and attr_accessor both. Write a custom setter when you need validation, and call setters inside the class with self.name = so Ruby doesn't create a local variable instead.

Accessor Notes

  • attr_reader :a, :b takes several names
  • Setters always return the assigned value
  • self.x = 1 calls the setter; x = 1 creates a local
  • Getters can be made private: private attr_reader :token

Readers, Writers, Custom Setters

class Product
  attr_reader :name, :price       # getters
  attr_accessor :stock            # getter + setter

  def initialize(name, price)
    @name = name
    self.price = price            # use the validating setter
  end

  def price=(value)               # custom setter
    raise ArgumentError, "negative price" if value.negative?
    @price = value.round(2)
  end

  def restock(n)
    self.stock = (stock || 0) + n # self. required for setters
  end
end

p1 = Product.new("Pen", 1.239)
p1.price                          # 1.24
p1.stock = 5
p1.restock(3)                     # 8
p1.price = -1                     # ArgumentError

Code Explained

attr_reader — def name = @name
attr_accessor — reader + writer
self.price = price — runs the validating setter
def price=(value) — custom setter with checks
self.stock = — without self, Ruby makes a local stock

The Ruby Way

  • Hand-written def name; @name; end → attr_reader :name
  • attr_accessor on everything → expose only what callers need
  • @price = v inside initialize that skips validation → self.price = v

In Rails

  • Rails · each table column becomes reader/writer methods on the model automatically
  • AS · mattr_accessor / cattr_accessor define module- or class-level accessors

⚠ Common Mistakes

  • Writing stock = 10 inside a method; it creates a local and the object never changes
  • Expecting a custom setter's return value; obj.price = 5 always evaluates to 5
  • Exposing attr_accessor for internal state; callers can then break invariants

✓ Tips & Best Practices

  • Use attr_reader by default and add writers only when needed
  • Predicate readers are just methods: def active? = @active
  • attr_reader returns the method names, so private attr_reader :x works in one line

Quick Summary

  • attr_reader / attr_writer / attr_accessor — generate methods
  • custom x= — validated setter
  • self.x = — call setter inside the class
  • private attr_reader — hidden getter
