Copying and Freezing

Assignment copies references, not objects. dup and clone make shallow copies (nested objects are still shared); clone also keeps the frozen state and singleton methods. freeze makes an object immutable, which raises FrozenError on mutation, and Ractor.make_shareable deep-freezes a structure.

Notes

  • freeze is shallow; inner objects stay mutable
  • dup returns an unfrozen copy; clone keeps frozen state
  • clone(freeze: false) unfreezes the copy
  • initialize_copy customizes what dup / clone copy

Copies and Freezing

a = [[1, 2], [3]]
b = a.dup
b << [4]                        # a unchanged
b[0] << 99                      # a[0] is [1, 2, 99] too (shared)
deep = Marshal.load(Marshal.dump(a))  # deep copy

s = "hi".freeze
s.frozen?                       # true
s << "!"                        # FrozenError
s.dup.frozen?                   # false
s.clone.frozen?                 # true
s.clone(freeze: false).frozen?  # false

CONFIG = { db: { host: "x" } }.freeze
CONFIG[:db][:host] = "y"        # allowed! inner hash not frozen
SAFE = Ractor.make_shareable({ db: { host: "x" } })
SAFE[:db].frozen?               # true (deep)

class Order
  def initialize = @items = []
  def initialize_copy(src) = @items = @items.dup  # after copy
end

Code Explained

dup — shallow copy, nested arrays shared
Marshal round-trip — quick deep copy for plain data
clone — keeps frozen state; freeze: false overrides
.freeze on a hash — only the outer hash is frozen
initialize_copy — deep-copy your own ivars on dup

The Ruby Way

  • Defensive dup everywhere → freeze shared data instead
  • Hand-freezing nested config → Ractor.make_shareable
  • Marshal deep copy of objects with procs or IO → copy explicitly in initialize_copy

⚠ Common Mistakes

  • Expecting dup to copy nested arrays; b[0] << x changes a[0] too
  • Freezing a constant hash and assuming its nested values are protected
  • Marshal deep copies of objects holding procs, IO or singleton methods; they raise TypeError

✓ Tips & Best Practices

  • Freeze constants at definition: LIMITS = [1, 5].freeze
  • Prefer immutable value objects (Data) over copying mutable ones
  • Object#then / tap with dup keeps transformations free of side effects

Quick Summary

  • dup / clone — shallow copies
  • freeze — shallow immutability
  • make_shareable — deep freeze
  • initialize_copy — custom copying
