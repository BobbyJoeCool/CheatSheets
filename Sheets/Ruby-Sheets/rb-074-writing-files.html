Writing and Appending

File.write replaces a file's contents in one call, and mode: "a" appends. For many writes, open the file with a mode string and a block: "w" truncates, "a" appends, "r+" reads and writes. puts, print, write and << all work on file objects just like on $stdout.

Notes

  • "w" creates or truncates the file
  • "a" creates or appends; never truncates
  • Add "b" for binary ("wb"), "x" to fail if the file exists
  • Writes are buffered; flush or closing writes them out

Writing

File.write("out.txt", "Hello\n")              # create / overwrite
File.write("out.txt", "more\n", mode: "a")    # append

File.open("report.txt", "w") do |f|           # auto-closed
  f.puts "Report"                             # with newline
  f.print "a", "b"                            # no newline
  f << "x" << "y\n"                           # chainable
  f.printf("%-5s %3d\n", "total", 42)
end

File.open("app.log", "a") { |f| f.puts "#{Time.now} started" }
File.write("img.png", bytes, mode: "wb")      # binary

File.open("new.txt", "wx") { |f| f.puts "x" } # Errno::EEXIST if present
File.open("data.txt", "w") do |f|
  f.sync = true                               # unbuffered
  f.write("line\n")
end
File.write("tmp.txt", "") && File.size("tmp.txt")   # 0

Code Explained

File.write(p, s) — one-shot write, returns bytes written
mode: "a" — append instead of replacing
f.puts / f.print / f << — same API as $stdout
"wx" — exclusive create, fails if the file exists
f.sync = true — write through immediately

The Ruby Way

  • File.open(p, "w") { |f| f.write(s) } → File.write(p, s)
  • Reopening a file for each line → one File.open block
  • Manual f.close → block form

Modes

ModeBehavior
"r"read (default)
"w"write, truncate / create
"a"append / create
"r+"read + write, no truncate
"w+"read + write, truncate
"wx"create only, error if exists

Write Methods

MethodAdds newline?
f.puts(x)yes
f.print(x)no
f.write(x)no, returns bytes
f << xno, chainable
f.printf(fmt, …)only if in fmt

⚠ Common Mistakes

  • Opening with "w" when you meant "a"; the old contents are gone
  • Writing in a loop with File.write(p, line, mode: "a"); it opens and closes the file each time
  • Forgetting the file is buffered and reading it from another process before it's flushed

✓ Tips & Best Practices

  • For crash-safe writes, write to file.tmp then File.rename over the original
  • FileUtils.mkdir_p(File.dirname(p)) before writing into new directories
  • Tempfile.create { |f| … } gives a self-deleting temporary file

Quick Summary

  • File.write — one-shot write
  • "w" / "a" — truncate / append
  • f.puts / f.write — write on a file object
  • block form — auto-close
