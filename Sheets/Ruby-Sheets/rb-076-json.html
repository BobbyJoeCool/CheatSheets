JSON

The json library converts between JSON text and Ruby hashes, arrays, strings, numbers, true / false and nil. JSON.parse returns string keys by default; pass symbolize_names: true for symbols. to_json / JSON.generate produce compact output and JSON.pretty_generate produces indented output.

JSON Notes

  • require "json" first (it's a default gem)
  • JSON null ↔ nil; symbols become strings
  • Custom objects need to_h or a to_json method
  • Invalid JSON raises JSON::ParserError

Parse and Generate

require "json"
text = '{"name":"Ada","langs":["ruby","c"],"admin":false}'
data = JSON.parse(text)
data["name"]                     # "Ada"
sym  = JSON.parse(text, symbolize_names: true)
sym[:langs]                      # ["ruby", "c"]

{ id: 1, tags: [:a] }.to_json    # '{"id":1,"tags":["a"]}'
JSON.generate([1, nil, true])    # '[1,null,true]'
puts JSON.pretty_generate(sym)   # indented, 2 spaces

config = JSON.load_file("config.json", symbolize_names: true)

User = Data.define(:id, :name) do
  def to_json(*args) = to_h.to_json(*args)
end
[User.new(1, "Ada")].to_json     # '[{"id":1,"name":"Ada"}]'
JSON.parse("{bad}")              # JSON::ParserError

Code Explained

JSON.parse — JSON text → Hash / Array
symbolize_names: true — symbol keys
to_json / JSON.generate — Ruby → compact JSON
JSON.load_file — read and parse in one step
def to_json(*args) — custom serialization

The Ruby Way

  • JSON.parse(s)["a"]["b"] → JSON.parse(s, symbolize_names: true).dig(:a, :b)
  • JSON.parse(File.read(p)) → JSON.load_file(p)
  • Hand-building JSON strings → build a hash and call to_json

In Rails

  • Rails · render json: @user calls as_json then encodes
  • Rails · @user.as_json(only: [:id, :name]) picks fields; to_json accepts the same options

⚠ Common Mistakes

  • Accessing parsed data with symbol keys (data[:name]) when keys are strings; you get nil
  • Using JSON.load on untrusted input; prefer JSON.parse, which never creates arbitrary objects
  • Expecting symbols to round-trip; they come back as strings

✓ Tips & Best Practices

  • Rescue JSON::ParserError around user-supplied JSON and return a clear error
  • JSON.pretty_generate for config and fixtures; compact to_json for APIs
  • Pattern match parsed data: case JSON.parse(s, symbolize_names: true) in { user: { id: } }

Quick Summary

  • JSON.parse — text → Ruby
  • symbolize_names: true — symbol keys
  • to_json / pretty_generate — Ruby → text
  • JSON.load_file — read a file
