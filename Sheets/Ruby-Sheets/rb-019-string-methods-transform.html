String Methods — Transform

upcase / downcase · capitalize · strip · sub / gsub · tr · squeeze · delete · bang ! variants

Transforming Strings

Transform methods return a new string; their bang (!) variants modify the receiver in place and return nil when nothing changed. sub replaces the first match and gsub replaces all, accepting a string, a hash, or a block for the replacement.

Transform Notes

  • tr maps characters one-to-one, like Unix tr
  • squeeze collapses runs of repeated characters
  • Bang methods return nil if no change was made; don't chain them

Transform Methods

s = "  Hello Ruby  "
s.strip                       # "Hello Ruby"
s.lstrip / s.rstrip           # "Hello Ruby  " / "  Hello Ruby"
"ruby".upcase                 # "RUBY"
"RuBy".downcase               # "ruby"
"ruby lang".capitalize        # "Ruby lang"

"a-b-c".sub("-", "+")         # "a+b-c"
"a-b-c".gsub("-", "+")        # "a+b+c"
"a1b2".gsub(/\d/) { |d| d.to_i * 2 }      # "a2b4"
"cat".gsub(/[ac]/, "a" => "4", "c" => "<")  # "<4t"
"hello".tr("el", "ip")        # "hippo"
"aaabbb".squeeze             # "ab"
"hello".delete("l")           # "heo"
"chomp\n".chomp               # "chomp"

name = +"ada"
name.capitalize!              # "Ada"
name.capitalize!              # nil (already capitalized)

Code Explained

sub / gsub — first / all replacements
block form — compute each replacement from the match
hash form — map each matched string to its replacement
tr("el", "ip") — e→i, l→p, character by character
capitalize! — returns nil on no change, so name.capitalize!.strip can raise

The Ruby Way

  • s.gsub(" ", "") → s.delete(" ")
  • s = s.strip → s.strip! only when you own the string
  • Chained gsub calls for single characters → one tr

In Rails

  • AS · " a b ".squish → "a b" (strip + collapse spaces)
  • AS · "user_name".titleize → "User Name", "Hello World".parameterize → "hello-world"
  • AS · "post".pluralize → "posts", "long text".truncate(6) → "lon..."

Trim & Clean

CallResult
" x ".strip"x"
"x\n".chomp"x"
"path/".chomp("/")"path"
"a b".squeeze(" ")"a b"
"1,234".delete(",")"1234"
"txt.rb".delete_suffix(".rb")"txt"

⚠ Common Mistakes

  • Writing s.upcase! and then using the return value; it's nil when the string was already uppercase
  • Using chop to remove a newline; it removes the last character whatever it is. Use chomp

✓ Tips & Best Practices

  • delete_prefix / delete_suffix are clearer and faster than sub(/\A.../, "")
  • gsub with a hash is a quick lookup-table replacer for templates
  • unicode_normalize before comparing user text that may contain accents

Quick Summary

  • upcase / downcase / capitalize — case
  • strip / chomp — trim
  • sub / gsub — replace
  • ! variants — in place, nil if unchanged
