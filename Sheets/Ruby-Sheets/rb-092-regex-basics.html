Regular Expressions: Basics

Regex literals are written /pattern/flags. =~ returns the match position or nil, match returns a MatchData object (or nil), and match? returns a boolean without setting match globals. Named captures ((?<year>\d+)) let you read groups by name, and Ruby uses \A / \z for true string start / end.

Regex Notes

  • ^ / $ match at line boundaries; \A / \z at string boundaries
  • After =~, $~ is the MatchData and $1, $2 the groups
  • Interpolation works: /#{Regexp.escape(word)}/
  • Regexp.new(str) builds a pattern at runtime

Matching

s = "Order 2026-10-17 total $42.50"
s =~ /\d{4}/                     # 6
$~[0]                            # "2026"
s.match?(/total/i)               # true

m = s.match(/(\d{4})-(\d\d)-(\d\d)/)
m[0]                             # "2026-10-17"
m[1]                             # "2026"
m.captures                       # ["2026", "10", "17"]

d = s.match(/(?<year>\d{4})-(?<mon>\d\d)/)
d[:year]                         # "2026"

if /\$(?<amount>[\d.]+)/ =~ s    # literal on the LEFT
  amount                         # "42.50" (local variable!)
end
"line1\nline2" =~ /^line2$/      # 6 (matches a line)
"line1\nline2".match?(/\Aline2/) # false (string start)

Code Explained

=~ — position or nil; sets $~, $1…
match — MatchData with groups, pre_match, post_match
(?<year>…) — named capture, read with m[:year]
/(?<amount>…)/ =~ s — creates local variables from names
\A vs ^ — whole string vs any line

The Ruby Way

  • ^…$ for validating input → \A…\z
  • !!(s =~ /x/) → s.match?(/x/)
  • Numbered groups in long patterns → named groups

In Rails

  • Rails · validates :zip, format: { with: /\A\d{5}\z/ }; Rails rejects ^/$ here unless you set multiline: true

⚠ Common Mistakes

  • Validating with ^ and $; "ok\n<script>" passes /^ok$/ because $ matches before the newline
  • Expecting m to mean multiline like in other languages; in Ruby m makes . match newlines (^/$ are always per-line)
  • Forgetting the named-capture local variables only appear when the regex literal is on the left of =~

✓ Tips & Best Practices

  • Use the x flag with comments for complex patterns
  • Regexp.escape(user_input) before interpolating text into a pattern
  • Ruby has a regex timeout: Regexp.timeout = 1.0 guards against ReDoS

Quick Summary
