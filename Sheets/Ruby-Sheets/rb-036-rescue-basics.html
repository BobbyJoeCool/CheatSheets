begin, rescue, else, ensure

Wrap risky code in begin ... end (or a whole method body) and handle failures in rescue clauses, matched top to bottom by exception class. else runs only when nothing was raised, and ensure always runs, which makes it the place for cleanup. A bare rescue catches StandardError and its subclasses.

Rescue Rules

  • rescue => e binds the exception object
  • List several classes: rescue IOError, SystemCallError => e
  • def ... rescue ... end needs no begin

Handling Exceptions

def read_number(path)
  Integer(File.read(path).strip)
rescue Errno::ENOENT => e
  warn "missing: #{e.message}"
  0
rescue ArgumentError, TypeError
  0
ensure
  puts "checked #{path}"      # always runs
end

begin
  result = 10 / divisor
rescue ZeroDivisionError => e
  puts e.message              # divided by 0
else
  puts "no error"             # only when nothing raised
end

Code Explained

rescue Errno::ENOENT => e — specific class, bound to e
multiple classes — comma-separated in one clause
ensure — runs on success, error, or return

The Ruby Way

  • begin ... end wrapping a whole method → method-level rescue
  • rescue Exception → rescue StandardError (the default)
  • rescue => e; nil that hides errors → rescue only what you can handle

In Rails

  • Rails · controllers use rescue_from ActiveRecord::RecordNotFound, with: :not_found
  • Rails · find raises RecordNotFound; find_by returns nil

⚠ Common Mistakes

  • Rescuing Exception; it also traps Interrupt (Ctrl-C) and SystemExit, so scripts won't stop
  • Putting a broad rescue before a specific one; the first matching clause wins
  • Using the rescue modifier on big expressions; it silently hides NoMethodError typos too

✓ Tips & Best Practices

  • Rescue as narrowly as possible and as close to the failing call as you can
  • Log e.full_message (or e.backtrace.first(5)) so you can find where it failed
  • Put cleanup in ensure, or better, use block APIs like File.open { } that clean up for you

Quick Summary

  • rescue Class => e — handle a specific error
  • else — success branch
  • ensure — always runs
  • bare rescue — StandardError only
