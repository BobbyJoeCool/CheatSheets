Making Classes Enumerable

Define an each method that yields every element and include Enumerable, and your class gains map, select, sort, min_by, first, lazy and dozens more. Return an Enumerator when each is called without a block so chaining works. Add <=> and include Comparable to make the objects themselves comparable.

Notes

  • sort / min / max need the elements to implement <=>
  • to_enum(:each) { size } lets enumerators report a size

A Custom Collection

class Playlist
  include Enumerable

  def initialize(*songs) = @songs = songs

  def each
    return to_enum(:each) { @songs.size } unless block_given?
    @songs.each { yield it }
    self
  end
end

Song = Data.define(:title, :secs) do
  include Comparable
  def <=>(other) = secs <=> other.secs
end

list = Playlist.new(Song["A", 200], Song["B", 95], Song["C", 310])
list.map(&:title)                  # ["A", "B", "C"]
list.select { it.secs > 150 }.size # 2
list.min.title                     # "B" (uses Song#<=>)
list.sort.map(&:title)             # ["B", "A", "C"]
list.sum(&:secs)                   # 605

Code Explained

include Enumerable — all collection methods from each
return to_enum(:each) { size } — blockless each returns an Enumerator
yield it — hand each element to the caller
include Comparable + <=> — min, sort, <, between?
list.min — Enumerable uses the elements' <=>

The Ruby Way

  • Exposing the internal array (attr_reader :songs) → implement each
  • Re-implementing map, select on your class → include Enumerable
  • Forgetting the blockless case → return to_enum(:each) unless block_given?

⚠ Common Mistakes

  • Subclassing Array or Hash; many methods return plain arrays and break your invariants
  • Not returning an Enumerator from a blockless each; list.each.with_index then raises LocalJumpError
  • Defining <=> that returns non-integers or never nil for incomparable types

✓ Tips & Best Practices

  • def each(&) = @songs.each(&) is the shortest correct delegation (it returns an Enumerator too)
  • Override size (and include? if you have a faster lookup) for big collections
  • Implement to_a / to_h only if they differ from the Enumerable defaults

Quick Summary

  • each + include Enumerable — collection superpowers
  • to_enum — blockless each
  • <=> + Comparable — ordering
  • don't subclass Array — wrap and delegate
