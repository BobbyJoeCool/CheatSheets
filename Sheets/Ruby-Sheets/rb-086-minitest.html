Minitest

Minitest is Ruby's built-in testing framework (a bundled gem), fast and plain Ruby. Test classes inherit from Minitest::Test, test methods start with test_, and assertions like assert_equal expected, actual check results. It also has a spec-style DSL and simple mocks and stubs.

Minitest Notes

  • Run with ruby -Ilib test/x_test.rb or rake test; add -n /name/ to filter
  • Order is assert_equal expected, actual
  • Tests run in random order to catch hidden dependencies
  • setup / teardown run around every test

A Test File

require "minitest/autorun"
require_relative "../lib/cart"

class CartTest < Minitest::Test
  def setup
    @cart = Cart.new
  end

  def test_total_adds_prices
    @cart.add(price: 2.5, qty: 2)
    assert_equal 5.0, @cart.total
  end

  def test_rejects_negative_qty
    error = assert_raises(ArgumentError) { @cart.add(price: 1, qty: -1) }
    assert_match(/qty/, error.message)
  end
end

Code Explained

Minitest::Test — base class for test cases
setup — fresh state before each test
assert_equal 5.0, @cart.total — expected first
assert_raises — returns the exception for further checks

The Ruby Way

  • assert x == y → assert_equal y, x (better failure messages)
  • Shared state in class variables → setup per test
  • Huge test methods → one behavior per test_ method

In Rails

  • Rails · tests inherit from ActiveSupport::TestCase and use YAML fixtures
  • Rails · bin/rails test test/models runs a directory; test "name" do defines tests

⚠ Common Mistakes

  • Swapping expected and actual; failure messages then read backwards
  • Naming a method without the test_ prefix; Minitest silently skips it
  • Depending on test order; random order will make the suite flaky

✓ Tips & Best Practices

  • Minitest::Mock and obj.stub(:method, value) { } cover simple doubles (require minitest/mock)
  • Run with --seed 1234 to reproduce an order-dependent failure
  • Add minitest-reporters for colored, readable output

Quick Summary

  • Minitest::Test + test_ methods — test cases
  • assert_equal expected, actual — main assertion
  • setup / teardown — per-test hooks
  • rake test — run the suite
