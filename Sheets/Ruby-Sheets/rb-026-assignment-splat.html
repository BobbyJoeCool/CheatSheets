Assignment and Splat

Ruby's assignment goes beyond =: compound operators (+=, ||=), parallel assignment (a, b = 1, 2), and splats (*, **) that collect or spread arrays and hashes. Destructuring works in assignment, block parameters and method calls.

Assignment Notes

  • a += 1 expands to a = a + 1
  • a ||= x is roughly a || a = x
  • * collects into an array; ** into a hash
  • Ruby 4.0: *nil no longer calls nil.to_a; it splats to nothing directly

Compound, Parallel, Splat

n = 10
n += 5; n -= 3; n *= 2   # 24
n /= 4                   # 6
n **= 2                  # 36
s = +"a"; s << "b"       # "ab"

a, b, c = 1, 2           # a=1 b=2 c=nil
first, *rest = [1, 2, 3]       # 1, [2, 3]
*init, last = [1, 2, 3]        # [1, 2], 3
a, (b, c), d = 1, [2, 3], 4    # nested
_, second = ["skip", "keep"]   # ignore with _

nums = [1, 2, 3]
[0, *nums, 4]            # [0, 1, 2, 3, 4]
def add(a, b, c) = a + b + c
add(*nums)               # 6
opts = { color: "red" }
{ size: 2, **opts }      # {size: 2, color: "red"}
def paint(color:) = color
paint(**opts)            # "red"
[*1..3, *"a"]            # [1, 2, 3, "a"]

Code Explained

a, b, c = 1, 2 — missing values become nil
*rest / *init — splat can sit anywhere, once
(b, c) — nested destructuring
*nums in a call — spreads array into positional args
**opts — spreads a hash into keywords or another hash

The Ruby Way

  • arr[0], arr[1..] → first, *rest = arr
  • a.merge(b) for literals → { **a, **b }
  • method(arr[0], arr[1]) → method(*arr)

⚠ Common Mistakes

  • Expecting a, b = [1, 2, 3] to fail; extra values are silently dropped
  • Using ||= with hash entries that may hold false; the false gets overwritten
  • Writing two splats in one assignment (*a, *b = ...); only one splat is allowed per side

✓ Tips & Best Practices

  • Use _ (or _name) for values you deliberately ignore; Ruby won't warn about it
  • Block params destructure too: pairs.each { |(k, v)| ... }
  • { **defaults, **options } gives you a merged options hash with later keys winning

Quick Summary

  • += etc. — compound assignment
  • a, b = b, a — parallel assignment
  • * / ** — collect or spread
  • _ — ignore a value
