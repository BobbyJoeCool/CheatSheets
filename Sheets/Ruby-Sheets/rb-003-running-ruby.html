Sheet 003

Running Ruby

irb · ruby file.rb · ruby -e · shebang #! · -w warnings · --yjit / --zjit · __FILE__ == $0

Ways to Run Code

Ruby is interpreted: ruby file.rb parses and runs the file directly, with no separate compile step. irb is the interactive REPL for experiments, and ruby -e runs one-liners. Since 3.1 the YJIT compiler can speed up long-running programs; Ruby 4.0 adds the experimental ZJIT.

Good to Know

  • irb shows the return value of every expression (=>)
  • A shebang plus chmod +x makes a script runnable directly
  • __FILE__ == $0 is true only when the file is run, not required
  • -w turns on warnings; worth using while learning

Running Ruby

ruby hello.rb               # run a file
ruby -e 'puts 2 ** 10'      # 1024
ruby -w app.rb              # with warnings
ruby --yjit server.rb       # enable YJIT
ruby -c app.rb              # Syntax OK (check only)
irb                         # interactive shell

script.rb

#!/usr/bin/env ruby
def main
  puts "Args: #{ARGV.inspect}"
end

main if __FILE__ == $0      # only when run directly

Code Explained

ruby -e — run code passed on the command line
-c — parse only; reports Syntax OK or the error
--yjit — JIT compile hot methods (also RUBY_YJIT_ENABLE=1)
#!/usr/bin/env ruby — finds the active Ruby on PATH
__FILE__ == $0 — guard like Python's if __name__ == "__main__"

The Ruby Way

  • Pasting into ruby to test → use irb and see each result
  • if __FILE__ == $0 then main end → main if __FILE__ == $0
  • #!/usr/bin/ruby → #!/usr/bin/env ruby so version managers work

⚠ Common Mistakes

  • Forgetting chmod +x and then wondering why ./script.rb says permission denied
  • Running a library file directly and executing code meant only for scripts; use the __FILE__ guard
  • Enabling YJIT for a 1-second script; JIT warm-up costs more than it saves on short runs

✓ Tips & Best Practices

  • One-liners like ruby -ne 'print if /ERROR/' app.log replace many grep/awk tricks
  • Use irb -r ./lib/my_code to load your code into a REPL session
  • Set export RUBY_YJIT_ENABLE=1 for long-running servers and workers

Quick Summary

  • ruby file.rb — run a script
  • irb — REPL with live results
  • ruby -e — one-liner
  • __FILE__ == $0 — "run directly" guard
