Search by Meaning

An embedding model turns text, images or audio into a vector of numbers, placed so that similar meanings land close together. A vector store finds the nearest neighbors of a query vector using approximate nearest neighbor (ANN) indexes such as HNSW, usually combined with metadata filters. This powers semantic search, recommendations and retrieval-augmented generation (RAG). You may not need a new database: PostgreSQL (pgvector), MongoDB, Redis, Cassandra and Neo4j all store vectors.

Notes

  • Use the same model for documents and queries
  • Normalize vectors to use dot product as cosine
  • More dimensions cost more memory and time
  • Store the model name and version with each vector

Embed, Store, Query (pgvector)

# 1. turn text into vectors (any embedding model)
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("all-MiniLM-L6-v2")             # 384 dimensions
docs = [{"id": 7, "text": "SQL Pocket Guide: a quick SQL reference"},
        {"id": 3, "text": "USB-C cable, 2 m, fast charging"}]
vecs = model.encode([d["text"] for d in docs], normalize_embeddings=True)

# 2. store them (pgvector here; same idea in every store)
import psycopg
from pgvector.psycopg import register_vector
conn = psycopg.connect("dbname=shop", autocommit=True)
conn.execute("CREATE EXTENSION IF NOT EXISTS vector")
register_vector(conn)
conn.execute("CREATE TABLE IF NOT EXISTS items "
             "(id int PRIMARY KEY, body text, embedding vector(384))")
conn.execute("CREATE INDEX IF NOT EXISTS items_embedding_idx ON items "
             "USING hnsw (embedding vector_cosine_ops)")
for d, v in zip(docs, vecs):
    conn.execute("INSERT INTO items VALUES (%s, %s, %s)", (d["id"], d["text"], v))

# 3. query: embed the question, take the nearest neighbors
q = model.encode("cable to charge my laptop", normalize_embeddings=True)
rows = conn.execute("SELECT id, body, 1 - (embedding <=> %s) AS score "
                    "FROM items ORDER BY embedding <=> %s LIMIT 5", (q, q)).fetchall()

Code Explained

normalize_embeddings=True scales vectors to length 1
register_vector lets psycopg send NumPy arrays as vector values
The HNSW index makes nearest-neighbor search approximate but fast
<=> is cosine distance, so 1 - distance is similarity

SQL Equivalent

  • pgvector keeps vectors in SQL: ORDER BY embedding <=> $1 LIMIT 5 with an HNSW index
  • Metadata filters are ordinary WHERE clauses · See SQL 72

Similarity Metrics

MetricNotes

Index Algorithms

AlgorithmTrade-off
Flat (exact)Perfect recall, slow at scale
HNSWFast and accurate; uses memory
IVFClusters vectors; less memory
DiskANNLarge sets on SSD
QuantizationSmaller vectors, a little less accuracy

⚠ Common Mistakes

  • Mixing vectors from different models in one index
  • No metadata filters, so results ignore stock or permissions
  • Judging quality without a set of test questions

✓ Tips & Best Practices

  • Start with the database you already run
  • Combine vector and keyword search (hybrid) for better results
  • Re-embed everything when you change models

Quick Summary

  • Embeddings place meaning in space
  • ANN indexes (HNSW) find neighbors
  • Filter by metadata
  • Often no new database needed
