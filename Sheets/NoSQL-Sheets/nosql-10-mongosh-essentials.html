The MongoDB Shell

mongosh is a Node.js REPL connected to MongoDB: you can write JavaScript, define functions and loop over results. find() returns a cursor that prints the first 20 documents; type it for more. Load scripts with load(), run one-off commands with --eval, and put helpers in ~/.mongoshrc.js. Output is already formatted, so the old .pretty() isn't needed.

Notes

  • Tab completes collections and methods
  • help and db.orders.help() list commands
  • exit or Ctrl+D quits
  • Every collection method also exists in the drivers

Cursors, Scripts and Settings

db                                   // current database
db.orders.find()                     // cursor: first 20 documents
it                                   // next 20
db.orders.find().toArray().length
db.orders.findOne({}, { items: 0 })  // first match, without items

const c = db.orders.find({ status: "pending" })
while (c.hasNext()) printjson(c.next())
db.orders.find().forEach(o => print(o._id, o.total))

db.orders.countDocuments({ status: "pending" })
const topBooks = () => db.products.find({ category: "Books" }).sort({ price: -1 }).limit(3)
topBooks()

config.set("displayBatchSize", 50)   // documents per page
load("seed-shop.js")                 // run a script file

// ~/.mongoshrc.js runs at startup
prompt = () => `${db.getName()}> `

// from the terminal
// mongosh shop --quiet --eval 'db.orders.countDocuments()'
// mongosh shop --file report.js

Code Explained

A cursor fetches documents in batches as you iterate
printjson prints a document; print prints plain values
Functions you define live until the shell exits, or forever if placed in .mongoshrc.js
--quiet --eval is handy in shell scripts and CI

SQL Equivalent

  • mongosh ↔ psql · show collections ↔ \dt · --eval ↔ psql -c
  • mongosh is a full JavaScript runtime, unlike psql's meta-commands · See SQL 2

Across Engines

  • Redis redis-cli: --scan, MONITOR, --eval script.lua
  • DynamoDB AWS CLI aws dynamodb … or NoSQL Workbench
  • Cassandra cqlsh: DESCRIBE KEYSPACES, SOURCE 'file.cql'
  • Neo4j cypher-shell or Neo4j Browser (:help)

In Your Code

  • Node for await (const o of orders.find({ status: "pending" })) console.log(o._id)
  • Python for o in orders.find({"status": "pending"}): print(o["_id"])
  • Java for (Document o : orders.find(eq("status", "pending"))) System.out.println(o.get("_id"));

Shell Helpers

CommandDoes

use nameSwitch database

Cursor Methods

MethodDoes
.toArray()All results as an array
.forEach(fn)Run a function per document
.hasNext() / .next()Manual iteration
.sort() / .limit() / .skip()Shape results
.explain()Show the query plan
.batchSize(n)Documents per round trip

⚠ Common Mistakes

  • Calling .toArray() on a huge result and running out of memory
  • Expecting count() on a cursor; use countDocuments()
  • Running destructive scripts against the wrong connection

✓ Tips & Best Practices

  • Show the database in the prompt to avoid mistakes
  • Keep reusable helpers in .mongoshrc.js
  • Use --file scripts for repeatable data fixes
