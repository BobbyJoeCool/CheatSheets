Drivers & ODMs

Node driver · Mongoose schemas · PyMongo · Motor · Spring Data MongoDB · Prisma MongoDB

From Your App

Official drivers exist for every major language and expose the same methods as mongosh. Create one client per application and reuse it: it holds a connection pool and tracks the replica set. ODMs (object-document mappers) such as Mongoose, Beanie and Spring Data MongoDB add schemas, validation, hooks and model classes on top. Never pass raw request JSON as a filter: { "$ne": null } in a password field is a NoSQL injection.

Notes

  • Default pool size is 100 connections per client
  • Retryable writes and reads are on by default
  • Motor is deprecated; use PyMongo's async API
  • Prisma has a MongoDB provider

Node: Driver and Mongoose

// npm i mongodb mongoose
import { MongoClient } from "mongodb"
const client = new MongoClient(process.env.MONGODB_URI, { appName: "shop-api" })
const orders = client.db("shop").collection("orders")       // reuse everywhere
const pending = await orders.find({ status: "pending" }).limit(20).toArray()

// Mongoose: schemas, validation, middleware, populate
import mongoose, { Schema } from "mongoose"
await mongoose.connect(process.env.MONGODB_URI)

const itemSchema = new Schema({
  productId: Number, qty: { type: Number, min: 1 },
  unitPrice: Schema.Types.Decimal128 }, { _id: false })

const Order = mongoose.model("Order", new Schema({
  customer: { type: Schema.Types.ObjectId, ref: "Customer", required: true },
  status: { type: String, enum: ["pending", "paid", "shipped"], default: "pending" },
  items: [itemSchema]
}, { timestamps: true }))

await Order.create({ customer: custId, items: [ { productId: 7, qty: 2, unitPrice: "19.99" } ] })
const list = await Order.find({ status: "pending" })
  .populate("customer", "name").lean()

// block operator injection from request input
const status = String(req.query.status)          // never pass objects through

Code Explained

The driver connects lazily on the first operation
timestamps: true adds createdAt and updatedAt
.populate("customer", "name") runs a second query and fills in names
.lean() returns plain objects, faster than full Mongoose documents

SQL Equivalent

  • Driver ↔ JDBC / pg · ODM ↔ ORM (Hibernate, Prisma) · populate ↔ a join done in the app
  • Operator injection is NoSQL's cousin of SQL injection · See SQL 76

⚠ Common Mistakes

  • Creating a new client per request
  • Passing req.body straight into find()
  • Using full Mongoose documents in hot read paths

✓ Tips & Best Practices

  • Create the client at startup and close it on shutdown
  • Use Mongoose sanitizeFilter or cast inputs to strings
  • Set appName to find your app in server logs

Quick Summary

  • One client per app
  • Drivers mirror mongosh
  • ODMs add schemas and hooks
  • Guard against operator injection
