$facet, $bucket & Window Stages

$facet · $bucket · $setWindowFields · $densify · $fill · $sortByCount

Facets, Buckets and Windows

$facet runs several sub-pipelines over the same input in one pass, which suits search pages with filters and counts. $bucket and $bucketAuto group values into ranges. $setWindowFields (5.0+) adds window functions: running totals, ranks and moving averages without collapsing documents. $densify and $fill fill gaps in time series.

Notes

  • Each $facet output is one array inside one document (16 MB cap)
  • $sortByCount = $group + $sort by count
  • Windows can count documents or a time / value range

$facet, $bucket, Windows & Gap Filling

// a search page: results plus counts in one pass
db.products.aggregate([
  { $match: { price: { $lt: 100 } } },
  { $facet: {
      byCategory: [ { $sortByCount: "$category" } ],
      byPrice: [ { $bucket: { groupBy: "$price", boundaries: [0, 20, 50, 100],
                              default: "other", output: { n: { $sum: 1 } } } } ],
      page: [ { $sort: { price: 1 } }, { $limit: 10 } ]
  } }
])

// even-sized buckets chosen by MongoDB
db.products.aggregate([ { $bucketAuto: { groupBy: "$price", buckets: 4 } } ])

// running total and order number per customer
db.orders.aggregate([
  { $setWindowFields: {
      partitionBy: "$customerId", sortBy: { orderDate: 1 },
      output: {
        runningTotal: { $sum: "$total", window: { documents: ["unbounded", "current"] } },
        orderNo: { $documentNumber: {} } } } }
])

// daily revenue with no missing days
db.dailySales.aggregate([
  { $densify: { field: "day", range: { step: 1, unit: "day", bounds: "full" } } },
  { $fill: { output: { revenue: { value: 0 } } } }
])

Code Explained

$facet returns one document with a byCategory, byPrice and page array
$bucket boundaries are inclusive below, exclusive above; default collects the rest
documents: ["unbounded", "current"] is everything from the first row to this one
$densify inserts the missing days; $fill gives them a value

SQL Equivalent

  • $facet ↔ several queries or GROUPING SETS · $bucket ↔ CASE + GROUP BY (or width_bucket)
  • $setWindowFields ↔ OVER (PARTITION BY … ORDER BY …) · $densify ↔ generate_series + LEFT JOIN · See SQL 44, 47, 79

Across Engines

  • Redis facet counts with FT.AGGREGATE … GROUPBY
  • DynamoDB precompute buckets and running totals on write
  • Cassandra no window functions; compute in Spark or the app
  • Neo4j collect plus list functions; the GDS library for graph analytics

In Your Code

  • Node { $facet: { byCategory: [{ $sortByCount: "$category" }] } }
  • Python {"$facet": {"byCategory": [{"$sortByCount": "$category"}]}}
  • Java facet(new Facet("byCategory", sortByCount("$category")))

⚠ Common Mistakes

  • Putting huge result sets inside $facet and hitting 16 MB
  • Forgetting sortBy in $setWindowFields
  • Bucket boundaries that don't cover all values without a default

✓ Tips & Best Practices

  • Limit each facet branch
  • Use time-range windows (range with unit) for time series
  • Pre-aggregate daily totals, then densify the small result

Quick Summary

  • $facet — many results, one pass
  • $bucket — ranges
  • $setWindowFields — windows
