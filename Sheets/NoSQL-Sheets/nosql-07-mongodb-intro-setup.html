Documents in Collections

MongoDB stores BSON documents (binary JSON) in collections inside databases. Each document has a unique _id and can hold nested objects and arrays, so one document often replaces several SQL rows. This set targets MongoDB 8.2. Run it in Atlas (managed, with a free tier) or self-host Community Server, talk to it with mongosh, and browse data with Compass. Below, the SQL set's shop data becomes three collections; order lines move inside each order.

Notes

  • Default port 27017
  • mongodb+srv:// connection strings look up hosts through DNS (Atlas)
  • Databases and collections are created on first write
  • Atlas M0 is free for learning

Run, Connect and Load the Shop Data

// docker run -d --name mongo -p 27017:27017 \
//   -e MONGO_INITDB_ROOT_USERNAME=admin -e MONGO_INITDB_ROOT_PASSWORD=secret mongo:8
// mongosh "mongodb://admin:secret@localhost:27017/?authSource=admin"
// mongosh "mongodb+srv://user:pass@cluster0.abcde.mongodb.net/shop"

use shop
db.customers.insertOne({ _id: 42, name: "Ada Lovelace",
  email: "ada@example.com", city: "Des Moines", country: "US",
  createdAt: new Date() })

db.products.insertMany([
  { _id: 7, name: "SQL Pocket Guide", category: "Books",
    price: NumberDecimal("19.99"), stock: 10 },
  { _id: 3, name: "USB-C Cable", category: "Electronics",
    price: NumberDecimal("9.99"), stock: 120 }
])

db.orders.insertOne({ _id: 1001, customerId: 42,
  orderDate: ISODate("2026-11-01"), status: "pending",
  total: NumberDecimal("49.97"),
  items: [ { productId: 7, qty: 2, unitPrice: NumberDecimal("19.99") },
           { productId: 3, qty: 1, unitPrice: NumberDecimal("9.99") } ] })

db.orders.findOne({ _id: 1001 })

Code Explained

The customers and products tables map straight to collections
order_items disappears: its rows become the embedded items array
SQL ids are reused as _id here; new documents usually get a generated ObjectId
NumberDecimal stores money exactly (sheet 08)

SQL Equivalent

  • database ↔ database · collection ↔ table · document ↔ row · field ↔ column
  • The orders + order_items join becomes one document · See SQL 2, 4

⚠ Common Mistakes

  • Forgetting authSource=admin when logging in as the root user
  • Storing prices as plain numbers (doubles)
  • Copying the SQL schema table by table instead of embedding order lines

✓ Tips & Best Practices

  • Use Atlas M0 or Docker for learning
  • Keep a seed.js you can load() in mongosh
  • Name collections in plural, lower camel case
