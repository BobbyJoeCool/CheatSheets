Sorted Sets

ZADD · ZRANGE · REV / BYSCORE · ZINCRBY · ZRANK · leaderboards · rate limits

Ranked Members

A sorted set stores unique members, each with a numeric score, kept in score order. Rank, range and score lookups are fast (O(log n)), which makes sorted sets the standard tool for leaderboards, "top N" lists, time-ordered indexes and sliding-window rate limits. The unified ZRANGE reads by rank, score (BYSCORE) or name (BYLEX), in either direction (REV).

Notes

  • Ties sort by member name
  • ( in a score range means exclusive: (10
  • -inf and +inf are open bounds
  • Scores are 64-bit floats

Leaderboards, Ranges & Rate Limits

> ZADD bestsellers:books 214 product:7 98 product:12 340 product:5
> ZINCRBY bestsellers:books 1 product:7          # one more sale
"215"
> ZRANGE bestsellers:books 0 2 REV WITHSCORES    # top 3
1) "product:5"
2) "340"
3) "product:7"
4) "215"
...
> ZREVRANK bestsellers:books product:7           # 0-based, from the top
(integer) 1
> ZSCORE bestsellers:books product:7

# products by price
> ZADD products:by_price 19.99 product:7 9.99 product:3 24.50 product:21
> ZRANGE products:by_price 10 20 BYSCORE          # 10 ≤ price ≤ 20
> ZRANGE products:by_price (10 +inf BYSCORE LIMIT 0 5
> ZCOUNT products:by_price 10 20

# sliding window: at most 100 requests per 60 s per IP
> ZREMRANGEBYSCORE rate:1.2.3.4 0 1793491140000  # drop entries older than 60 s
> ZADD rate:1.2.3.4 1793491200000 req-8f2c       # score = now in ms
> ZCARD rate:1.2.3.4                             # > 100 → reject
> EXPIRE rate:1.2.3.4 60

Code Explained

ZINCRBY updates a score atomically and re-sorts the member
REV reads highest first; WITHSCORES adds each score after its member
(10 excludes products costing exactly 10
Run the rate-limit steps in a MULTI or Lua script so they're atomic

SQL Equivalent

  • Sorted set ↔ an indexed column with ORDER BY score DESC LIMIT 3
  • ZREVRANK ↔ RANK() OVER (ORDER BY score DESC) · See SQL 45

Across Engines

  • MongoDB index on the score field + sort().limit(); $rank window
  • DynamoDB a GSI with the score as sort key, queried with ScanIndexForward = false
  • Cassandra a clustering column score DESC within a partition
  • Neo4j ORDER BY p.sales DESC LIMIT 3

In Your Code

  • Node await r.zIncrBy("bestsellers:books", 1, "product:7")
  • Python r.zincrby("bestsellers:books", 1, "product:7")
  • Java jedis.zincrby("bestsellers:books", 1, "product:7");

⚠ Common Mistakes

  • Using a list and sorting in the app instead of a sorted set
  • Forgetting to trim old entries in time-based sets
  • Running rate-limit steps as separate, non-atomic calls

✓ Tips & Best Practices

  • Use ZADD … GT to keep only a member's best score
  • Pair a time-indexed sorted set with hashes holding the details
  • Cap leaderboards with ZREMRANGEBYRANK
