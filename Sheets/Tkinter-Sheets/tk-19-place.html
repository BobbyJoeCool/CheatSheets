Exact Positioning with place()

place() positions a widget by coordinates inside its parent, either absolute pixels (x, y, width, height) or relative fractions of the parent size (relx, rely, relwidth, relheight from 0.0 to 1.0). The two can be combined: relative values are computed first, then the absolute ones are added as offsets. anchor chooses which point of the widget lands on the coordinates. place ignores other widgets entirely, so overlapping is possible and sometimes the point.

Notes

  • place doesn't resize the parent to fit children
  • Relative values make overlays follow window resizing
  • Placed widgets stack in creation order; use lift() to raise
  • Good for overlays, badges, splash screens and games
  • Poor for forms: no automatic alignment or resizing

Overlay, Badge and Centered Box

import tkinter as tk

root = tk.Tk()
root.geometry("400x260")

bg = tk.Label(root, bg="#2b3a55")
bg.place(x=0, y=0, relwidth=1, relheight=1)      # full background

box = tk.Frame(root, bg="white", padx=12, pady=12)
box.place(relx=0.5, rely=0.5, anchor="center")    # always centered
tk.Label(box, text="Sign in", bg="white",
         font=("Helvetica", 14)).pack()
tk.Entry(box).pack(pady=6)

badge = tk.Label(root, text="3", bg="red", fg="white", width=2)
badge.place(relx=1.0, x=-10, y=10, anchor="ne")   # 10 px from top-right

bar = tk.Frame(root, bg="#ffcc00", height=4)
bar.place(relx=0, rely=1.0, relwidth=0.6, anchor="sw")  # progress strip
def grow():
    w = float(bar.place_info()["relwidth"])
    bar.place_configure(relwidth=min(1.0, w + 0.1))
root.bind("<space>", lambda e: grow())
root.mainloop()

Code Explained

relwidth=1, relheight=1 stretches the background
relx=0.5, rely=0.5, anchor="center" centers the box
relx=1.0, x=-10 = right edge minus 10 pixels
anchor="sw" pins the strip's bottom-left corner
place_info() returns strings; convert before math

⚠ Common Mistakes

  • Building whole forms with place and hard-coded pixels
  • Expecting the parent to grow around placed children
  • Mixing up anchor with the position it applies to

✓ Tips & Best Practices

  • Combine relx with x for offsets from edges
  • Use place for overlays on top of a grid layout
  • Keep pixel values in constants for HiDPI scaling

Quick Summary

  • Absolute x/y or relative relx/rely
  • anchor picks the widget's reference point
  • Can overlap; no auto layout
  • Best for overlays and special effects
