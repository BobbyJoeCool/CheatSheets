Layouts, Elements and Custom Themes

Under the hood, each ttk style is drawn from elements (border, padding, label, indicator…) arranged in a layout tree. Style.layout(name) shows or replaces that tree, and element_options(element) lists what each element accepts, which tells you which configure() options actually work in the current theme. element_create() builds new elements (for example from images), and theme_create() with theme_settings() defines a whole theme based on an existing parent theme.

Notes

  • Layouts differ between themes; inspect, don't assume
  • Removing an element from a layout hides that part
  • Image elements enable fully custom-looking widgets
  • theme_settings() can change an existing theme too
  • Libraries like sv-ttk ship complete image-based themes

Inspect and Modify a Layout

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
style = ttk.Style(root); style.theme_use("clam")
print(style.layout("TButton"))
# [('Button.border', {'sticky': 'nswe', 'border': '1', 'children':
#   [('Button.focus', {... 'children': [('Button.padding', {...
#     'children': [('Button.label', {'sticky': 'nswe'})]})]})]})]
print(style.element_options("Button.label"))  # ('compound', 'space', 'text', …)
# Notebook without the dotted focus ring around tab labels
style.layout("TNotebook.Tab", [("Notebook.tab", {"sticky": "nswe", "children": [
    ("Notebook.padding", {"side": "top", "sticky": "nswe", "children": [
        ("Notebook.label", {"side": "top", "sticky": ""})]})]})])
# A new theme derived from clam
style.theme_create("brand", parent="clam", settings={
    "TButton": {"configure": {"padding": 8, "background": "#00695c",
                              "foreground": "white"},
                "map": {"background": [("active", "#00897b")]}},
    "TLabel": {"configure": {"foreground": "#004d40"}},
})
style.theme_use("brand")
ttk.Label(root, text="Branded").pack(padx=20, pady=6)
ttk.Button(root, text="Go").pack(pady=6)
root.mainloop()

Code Explained

layout() returns a nested list of (element, options)
element_options reveals supported options per element
Replacing the Tab layout drops Notebook.focus
settings uses configure/map/layout keys per style
Derived themes inherit everything they don't override

⚠ Common Mistakes

  • Configuring options the theme's elements don't support
  • Copying a layout from one theme into another blindly
  • Creating the same theme twice (TclError)

✓ Tips & Best Practices

  • Print layout() before editing it
  • Derive custom themes from clam
  • Reach for sv-ttk or ttkbootstrap before hand-building themes

Quick Summary

  • Styles = layouts of elements
  • layout() and element_options() to inspect
  • theme_create/theme_settings for themes
  • Derive from clam for control
