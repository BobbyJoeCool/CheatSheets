Building a Menu Bar

A menu bar is a tk.Menu attached to a window with config(menu=menubar). Each top-level entry (File, Edit, Help) is another Menu added with add_cascade(), and its items are added with add_command(). Set tearoff=0 on every menu, or Tk adds a dashed line that detaches the menu into its own window (an old X11 feature). accelerator= only displays a shortcut; bind the key separately. underline= marks the Alt-key mnemonic.

Notes

  • There is no ttk menu; tk.Menu is native on Windows and macOS
  • macOS puts the menu bar at the top of the screen
  • A menu named "apple" becomes the macOS application menu
  • root.option_add("*tearOff", False) disables tear-offs globally
  • Menus are owned by the window; they can't be packed

File / Edit / Help Menus

import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.option_add("*tearOff", False)
def new(e=None): print("new")
def save(e=None): print("save")

menubar = tk.Menu(root)
root.config(menu=menubar)

file_menu = tk.Menu(menubar)
menubar.add_cascade(label="File", menu=file_menu, underline=0)
file_menu.add_command(label="New", accelerator="Ctrl+N", command=new)
file_menu.add_command(label="Save", accelerator="Ctrl+S", command=save)
file_menu.add_separator()
file_menu.add_command(label="Exit", command=root.destroy)

help_menu = tk.Menu(menubar, name="help")   # special Help menu name
menubar.add_cascade(label="Help", menu=help_menu, underline=0)
help_menu.add_command(label="About",
    command=lambda: messagebox.showinfo("About", "Demo 1.0"))

root.bind("<Control-n>", new); root.bind("<Control-s>", save)
root.mainloop()

Code Explained

option_add("*tearOff", False) must come before menus are made
config(menu=menubar) installs the bar on the window
Each cascade's menu is a child Menu of the bar
name="help" gives the Help menu its platform placement
accelerator text plus a real bind() for each shortcut

⚠ Common Mistakes

  • Leaving tear-off lines on every menu
  • Expecting accelerator= to bind the shortcut
  • Calling pack() on a menu bar

✓ Tips & Best Practices

  • Use the same function for the menu item and the key binding
  • Group items with separators: New/Open, Save, Exit
  • Test on macOS: the bar moves to the screen top

Quick Summary

  • Menu + config(menu=…)
  • add_cascade for submenus, add_command for items
  • tearoff=0 everywhere
  • Accelerators need separate bindings
