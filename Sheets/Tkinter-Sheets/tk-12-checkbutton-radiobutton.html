Checkbutton & Radiobutton

Checkbutton · onvalue · offvalue · BooleanVar · Radiobutton · value · shared variable · indicatoron

Boolean and Choice Inputs

A Checkbutton toggles a variable between an on and an off value (by default 1 and 0; change them with onvalue/offvalue). A group of Radiobuttons shares one variable; each button has its own value, and selecting it writes that value to the variable. Because the state lives in the variable, you read the user's choice with var.get() rather than querying the widgets, and you can preselect by calling var.set().

Notes

  • Use BooleanVar for simple on/off checkboxes
  • Radiobuttons are grouped only by sharing a variable
  • Both accept command= to react immediately
  • ttk versions look native; classic ones allow colors
  • indicatoron=False makes classic radios look like toggle buttons

Options Panel

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
dark = tk.BooleanVar(value=False)
size = tk.StringVar(value="M")
level = tk.StringVar(value="beta")

def show():
    print(dark.get(), size.get(), level.get())
ttk.Checkbutton(root, text="Dark mode", variable=dark,
                command=show).grid(row=0, column=0, columnspan=3, sticky="w")

for col, (label, val) in enumerate([("Small", "S"), ("Medium", "M"),
                                    ("Large", "L")]):
    ttk.Radiobutton(root, text=label, value=val, variable=size,
                    command=show).grid(row=1, column=col, padx=4)
ttk.Checkbutton(root, text="Use beta channel", variable=level,
                onvalue="beta", offvalue="stable").grid(
                row=2, column=0, columnspan=3, sticky="w")
align = tk.StringVar(value="Left")         # classic toolbar-style group
for i, v in enumerate(("Left", "Center", "Right")):
    tk.Radiobutton(root, text=v, value=v, variable=align,
                   indicatoron=False, width=7).grid(row=3, column=i)
root.mainloop()

Code Explained

BooleanVar returns True/False from get()
All three Radiobuttons share size, so only one is selected
The initial value="M" preselects Medium
onvalue/offvalue store strings instead of 1/0
indicatoron=False draws push-button style radios

⚠ Common Mistakes

  • Giving each Radiobutton its own variable (they never exclude)
  • Leaving the variable unset, so no radio appears selected
  • Letting a local variable get garbage-collected; keep a reference

✓ Tips & Best Practices

  • Store vars on self in class-based apps
  • Build radio groups from a list of (label, value) pairs
  • Read choices from variables, never from widgets

Quick Summary

  • Checkbutton: on/off values in one variable
  • Radiobuttons: shared variable, unique value
  • Read state with var.get()
  • Preselect with var.set()
