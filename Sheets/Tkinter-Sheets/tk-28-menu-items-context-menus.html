Menu Items and Popup Menus

Menus can hold more than commands: add_checkbutton() toggles a variable, add_radiobutton() picks one value from a group, and nested add_cascade() builds submenus. Items are addressed by index or label; entryconfigure() changes them later, such as enabling Paste only when the clipboard has text. postcommand= runs just before a menu opens, which is the right time to refresh item states. A context menu is a Menu shown at the pointer with tk_popup(x, y).

Notes

  • Right-click is <Button-3> on Windows/Linux, <Button-2> on macOS
  • Also bind <Control-Button-1> on macOS for one-button mice
  • index("end") gives the last item's index
  • Check and radio items share Tk variables like widgets
  • delete(0, "end") clears a menu for rebuilding

View Options and Right-Click Menu

import tkinter as tk

root = tk.Tk()
menubar = tk.Menu(root); root.config(menu=menubar)
text = tk.Text(root, width=40, height=8); text.pack()
wrap = tk.BooleanVar(value=True); theme = tk.StringVar(value="light")

view = tk.Menu(menubar, tearoff=0, postcommand=lambda: print("opening"))
menubar.add_cascade(label="View", menu=view)
view.add_checkbutton(label="Word wrap", variable=wrap,
    command=lambda: text.config(wrap="word" if wrap.get() else "none"))
themes = tk.Menu(view, tearoff=0)
view.add_cascade(label="Theme", menu=themes)
for t in ("light", "dark"):
    themes.add_radiobutton(label=t.title(), value=t, variable=theme)
popup = tk.Menu(root, tearoff=0)
for ev in ("Cut", "Copy", "Paste"):
    popup.add_command(label=ev, command=lambda ev=ev: text.event_generate(f"<<{ev}>>"))
def show_popup(e):
    state = "normal" if text.tag_ranges("sel") else "disabled"
    for label in ("Cut", "Copy"): popup.entryconfigure(label, state=state)
    popup.tk_popup(e.x_root, e.y_root)
aqua = root.tk.call("tk", "windowingsystem") == "aqua"
text.bind("<Button-2>" if aqua else "<Button-3>", show_popup)

Code Explained

add_checkbutton toggles wrap and applies it
A nested Menu becomes the Theme submenu
Radio items share theme, so only one is ticked
entryconfigure(label, …) disables Cut/Copy without a selection
tk_popup opens at screen coordinates from the event

⚠ Common Mistakes

  • Binding only <Button-3>, so macOS right-click does nothing
  • Using widget x/y instead of x_root/y_root for popups
  • Changing items by numeric index after inserting new ones

✓ Tips & Best Practices

  • Refresh item states in postcommand or just before popping up
  • Address items by label so inserts don't break code
  • Reuse Cut/Copy/Paste through virtual events

Quick Summary

  • Check, radio and cascade items
  • entryconfigure updates items
  • postcommand refreshes before opening
  • tk_popup(x_root, y_root) for context menus
