Placing and Showing Windows

To place a window precisely, ask Tk for the screen size with winfo_screenwidth()/winfo_screenheight() and compute the position. A window can be normal, iconic (minimized), withdrawn (hidden, no taskbar entry) or zoomed (maximized; Windows and macOS). overrideredirect(True) removes the title bar and border, which suits splash screens.

Notes

  • Call update_idletasks() before measuring a new window
  • On Linux, maximize with attributes("-zoomed", True)
  • Frameless windows can't be moved or closed by the user
  • winfo_x()/winfo_y() give the window's current position
  • Multi-monitor setups report the primary or combined screen

Center, Minimize, Hide, Restore

import tkinter as tk

def center(win, w, h):
    win.update_idletasks()
    sw, sh = win.winfo_screenwidth(), win.winfo_screenheight()
    x, y = (sw - w) // 2, (sh - h) // 3
    win.geometry(f"{w}x{h}+{x}+{y}")

root = tk.Tk()
center(root, 500, 300)

print(root.state())            # 'normal'
root.iconify()                 # minimize to taskbar
root.deiconify()               # restore
root.state("zoomed")           # maximize (Windows/macOS)
# Splash screen: no title bar, semi-transparent
splash = tk.Toplevel(root)
splash.overrideredirect(True)
splash.attributes("-alpha", 0.9)
tk.Label(splash, text="Loading…", padx=40, pady=30).pack()
center(splash, 200, 100)
root.withdraw()                # hide main window meanwhile
root.after(1500, lambda: (splash.destroy(), root.deiconify()))
root.mainloop()

Code Explained

Screen size minus window size, halved, gives a centered origin
Dividing height by 3 sits slightly above center
state() reads or sets normal/iconic/withdrawn/zoomed
overrideredirect(True) removes the window decorations
after(1500, …) swaps splash for main window

⚠ Common Mistakes

  • Centering before update_idletasks(), using 1×1 sizes
  • Calling state("zoomed") on Linux, which raises TclError
  • Hiding the only window with withdraw() and losing the app

✓ Tips & Best Practices

  • Make center() a helper you reuse for dialogs
  • Withdraw the root while a splash or login window is shown
  • Save and restore geometry() between sessions

Quick Summary

  • winfo_screenwidth/height for positioning
  • iconify, deiconify, withdraw, state()
  • overrideredirect(True) for frameless windows
  • -alpha attribute for transparency
