Interactive Canvas Items

tag_bind(tag_or_id, sequence, handler) attaches events to canvas items rather than the whole widget, so each shape can react to clicks, hovers or drags. Inside a handler, the special tag "current" names the item under the pointer. Dragging is a three-event pattern: on press, remember the item and pointer position; on motion, move() the item by the difference; on release, finish. find_closest() and find_overlapping() help with hit-testing and snapping.

Notes

  • Item bindings fire only over painted areas, not empty interiors with fill=""
  • Widget-level bindings still run after item bindings
  • Use canvasx()/canvasy() when the canvas is scrolled
  • <Enter>/<Leave> on tags give hover effects
  • find_overlapping takes a rectangle, not a point

Drag-and-Drop Shapes

import tkinter as tk
c = tk.Canvas(tk.Tk(), width=400, height=260, bg="white"); c.pack()
for x, color in ((40, "tomato"), (160, "gold"), (280, "skyblue")):
    c.create_rectangle(x, 100, x + 80, 160, fill=color, tags="draggable")
c.create_rectangle(150, 200, 250, 250, dash=(3, 3), tags="target")
drag = {"item": None, "x": 0, "y": 0}
def press(e):
    drag["item"] = c.find_withtag("current")[0]
    drag["x"], drag["y"] = c.canvasx(e.x), c.canvasy(e.y)
    c.tag_raise(drag["item"])
def motion(e):
    x, y = c.canvasx(e.x), c.canvasy(e.y)
    c.move(drag["item"], x - drag["x"], y - drag["y"])
    drag["x"], drag["y"] = x, y
def release(e):
    hits = c.find_overlapping(*c.bbox("target"))
    if drag["item"] in hits:
        c.itemconfigure(drag["item"], outline="green", width=3)
    drag["item"] = None
c.tag_bind("draggable", "<ButtonPress-1>", press)
c.tag_bind("draggable", "<B1-Motion>", motion)
c.tag_bind("draggable", "<ButtonRelease-1>", release)
c.tag_bind("draggable", "<Enter>", lambda e: c.config(cursor="fleur"))
c.tag_bind("draggable", "<Leave>", lambda e: c.config(cursor=""))
c.mainloop()

Code Explained

Only items tagged draggable respond to the mouse
"current" gives the item that was clicked
Motion moves by the delta since the last event
find_overlapping(*bbox) checks for a drop on the target
Cursor changes on hover signal draggability

⚠ Common Mistakes

  • Using find_closest for clicks (it always returns something)
  • Forgetting canvasx/canvasy on scrolled canvases
  • Binding drag events on the canvas, so the background drags too

✓ Tips & Best Practices

  • Store drag state in a dict or object, not globals
  • Raise the dragged item so it stays on top
  • Snap to a grid by rounding coordinates on release

Quick Summary

  • tag_bind = events per item or tag
  • "current" = item under the mouse
  • Press / motion / release for dragging
  • find_* for hit-testing
