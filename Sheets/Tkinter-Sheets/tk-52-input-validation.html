Validating Entry Input

Entry and Spinbox can check input before it's accepted. Set validate= to when validation runs ("key" for every keystroke, "focusout", "all"…) and validatecommand= to a callback registered with register() plus percent substitutions that choose what Tk passes in, such as %P (the proposed new text). The callback returns True to allow the change or False to reject it. invalidcommand= runs when validation fails.

Notes

  • The callback must return a bool, or validation turns off
  • Changing the Entry's text inside the callback disables validation
  • %P includes text not yet inserted
  • Allow the empty string so users can clear the field
  • Validate the whole form again before saving

Numeric and Length Validation

import tkinter as tk
from tkinter import ttk

root = tk.Tk()

def is_number(proposed):
    if proposed in ("", "-", ".", "-."):
        return True                         # allow partial input
    try:
        float(proposed); return True
    except ValueError:
        return False

def max_len(proposed, limit):
    return len(proposed) <= int(limit)

def on_invalid(widget_name):
    root.nametowidget(widget_name).bell()   # beep on rejection
num_cmd = (root.register(is_number), "%P")
len_cmd = (root.register(max_len), "%P", 5)
bad_cmd = (root.register(on_invalid), "%W")
ttk.Entry(root, validate="key", validatecommand=num_cmd,
          invalidcommand=bad_cmd).pack(padx=8, pady=4)      # price
ttk.Entry(root, validate="key", validatecommand=len_cmd,
          width=8).pack(padx=8, pady=4)                     # ZIP code

Code Explained

register() wraps a Python function as a Tcl command
The tuple adds substitutions (%P) and fixed arguments (5)
Partial values like "-" must be allowed while typing
%W gives the widget's name for the invalid handler
nametowidget turns that name back into the widget

⚠ Common Mistakes

  • Passing the plain function instead of the register()ed name
  • Rejecting "", so users can't delete the last character
  • Returning None (no explicit return True)

✓ Tips & Best Practices

  • Use key for format, focusout for completeness checks
  • Show errors next to fields, not just with beeps
  • Use ttk's invalid state to tint bad fields

Quick Summary

  • validate= when, validatecommand= how
  • register() + %P for proposed text
  • Return True to accept
  • Allow partial input while typing
