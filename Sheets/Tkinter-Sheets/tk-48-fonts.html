Working with Fonts

Fonts can be given as a tuple ("Family", size, "bold italic"), a string "Helvetica 12 bold", or a tkinter.font.Font object. Font objects are live: change one with configure() and every widget using it updates. Positive sizes are points, negative sizes are pixels. Tk also defines named fonts like TkDefaultFont, TkTextFont and TkFixedFont; adjusting them with nametofont() restyles the whole app consistently, including ttk widgets.

Notes

  • font.families() lists installed font families
  • measure(text) gives pixel width; metrics() gives heights
  • Unknown families silently fall back to a default
  • Keep a reference to Font objects you create
  • Import as tkfont to avoid clashing with variables named font

Named Fonts and Font Objects

import tkinter as tk
import tkinter.font as tkfont
from tkinter import ttk

root = tk.Tk()

default = tkfont.nametofont("TkDefaultFont")     # app-wide base font
default.configure(family="Segoe UI", size=10)
tkfont.nametofont("TkFixedFont").configure(size=11)

heading = tkfont.Font(family="Georgia", size=16, weight="bold")
ttk.Label(root, text="Report", font=heading).pack(anchor="w", padx=10)
ttk.Label(root, text="Uses TkDefaultFont").pack(anchor="w", padx=10)
tk.Text(root, height=3, font="TkFixedFont").pack(padx=10, pady=4)

def bigger(): heading.configure(size=int(heading.cget("size")) + 2)
ttk.Button(root, text="A+", command=bigger).pack(pady=4)

print(heading.measure("Report"))       # pixel width of the text
print(heading.metrics("linespace"))    # line height in px
print(heading.actual())                # resolved family, size, weight…
print("Consolas" in tkfont.families())
mono = ("Courier New", 10)             # tuple form
small_italic = "Helvetica 9 italic"    # string form
root.mainloop()

Code Explained

nametofont("TkDefaultFont") changes the base font everywhere
A Font object updates all widgets using it on configure()
Text widgets can use named fonts by name string
measure and metrics help size layouts precisely
actual() shows what the OS really chose

⚠ Common Mistakes

  • Writing ("Segoe UI 10") (a string in parentheses, not a tuple)
  • Creating Font() before Tk() exists
  • Hard-coding a font family that isn't installed elsewhere

✓ Tips & Best Practices

  • Change named fonts once at startup for a consistent look
  • Use TkFixedFont for code and tabular text
  • Scale fonts, not widgets, for accessibility settings

Quick Summary
