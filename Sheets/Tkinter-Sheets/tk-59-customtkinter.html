CustomTkinter Widgets

CustomTkinter (pip install customtkinter) is a widget library built on Tkinter that draws its own rounded, modern widgets with automatic light/dark mode and HiDPI scaling. Its widgets are prefixed CTk (CTkButton, CTkEntry, CTkSwitch…) and use their own options such as corner_radius, fg_color and hover_color. Layout still uses pack, grid and place, and standard Tk variables and command= callbacks work as usual.

Notes

  • Use ctk.CTk() as the root instead of tk.Tk()
  • Colors can be a pair: ("light color", "dark color")
  • CTkImage supports separate light/dark images and scaling
  • Mixing ttk widgets in looks inconsistent
  • Use CTkFont for fonts that scale with the UI

Settings Panel in CustomTkinter

import customtkinter as ctk

ctk.set_appearance_mode("system")          # "light", "dark", "system"
ctk.set_default_color_theme("blue")        # "green", "dark-blue", or a .json

app = ctk.CTk()
app.title("Settings"); app.geometry("360x300")
app.grid_columnconfigure(0, weight=1)

ctk.CTkLabel(app, text="Profile", font=ctk.CTkFont(size=18, weight="bold")
             ).grid(row=0, column=0, padx=20, pady=(20, 6), sticky="w")
name = ctk.CTkEntry(app, placeholder_text="Display name")
name.grid(row=1, column=0, padx=20, pady=6, sticky="ew")
dark = ctk.StringVar(value="off")
ctk.CTkSwitch(app, text="Dark mode", variable=dark, onvalue="on",
              offvalue="off", command=lambda: ctk.set_appearance_mode(
                  "dark" if dark.get() == "on" else "light")
              ).grid(row=2, column=0, padx=20, pady=6, sticky="w")
size = ctk.CTkSegmentedButton(app, values=["S", "M", "L"])
size.set("M"); size.grid(row=3, column=0, padx=20, pady=6)
ctk.CTkButton(app, text="Save", corner_radius=8,
              fg_color=("#2e7d32", "#43a047"), hover_color="#1b5e20",
              command=lambda: print(name.get(), size.get())
              ).grid(row=4, column=0, padx=20, pady=16, sticky="ew")
app.mainloop()

Code Explained

Appearance and color theme are set globally first
CTkEntry supports placeholder text
CTkSwitch toggles the appearance mode live
CTkSegmentedButton is a modern radio group
fg_color pair = (light-mode, dark-mode) colors

⚠ Common Mistakes

  • Using bg=/fg= instead of fg_color/text_color
  • Creating tk.Tk() and placing CTk widgets in it
  • Setting the color theme after widgets exist

✓ Tips & Best Practices

  • Default to "system" appearance to follow the OS
  • Use CTkTabview and CTkScrollableFrame for layout
  • Keep logic separate so you can swap toolkits later

Quick Summary

  • Modern drawn widgets prefixed CTk
  • Automatic light/dark mode
  • fg_color, corner_radius, hover_color
  • Same layout managers and callbacks
