Widgets at a Glance

This sheet collects the widget set on one page: every common widget, whether it has a ttk version, the options you'll set most often, and the three geometry managers. Prefer the ttk widget whenever one exists; it looks native and is styled through ttk.Style. Classic tk widgets remain the right choice for Text, Canvas, Listbox and Menu, which have no ttk equivalent. Sheet numbers in the tables point to the detailed pages.

Notes

  • Every widget's first argument is its parent
  • Create, then place: w = W(parent); w.grid(…)
  • configure() changes options; cget() reads them
  • Constants: "end", "both", "left" as strings
  • Detailed pages: widgets 07–15, ttk 33–41

Widget Creation Cheat Codes

import tkinter as tk
from tkinter import ttk
root = tk.Tk()

ttk.Label(root, text="Hi", image=img, compound="left")   # img = PhotoImage
ttk.Button(root, text="OK", command=fn, style="Accent.TButton")
ttk.Entry(root, textvariable=sv, show="*", width=20)
ttk.Checkbutton(root, text="On", variable=bv)
ttk.Radiobutton(root, text="A", value="a", variable=sv)
ttk.Combobox(root, values=["a", "b"], state="readonly")
ttk.Spinbox(root, from_=0, to=10, increment=1)
ttk.Scale(root, from_=0, to=100, orient="horizontal", variable=dv)
ttk.Progressbar(root, mode="determinate", maximum=100, value=40)
ttk.Treeview(root, columns=("a", "b"), show="headings")
ttk.Notebook(root); ttk.Separator(root); ttk.Sizegrip(root)
ttk.Frame(root, padding=8); ttk.LabelFrame(root, text="Group")
ttk.Panedwindow(root, orient="horizontal")
ttk.Scrollbar(root, orient="vertical", command=widget.yview)

tk.Text(root, wrap="word", undo=True, height=10)
tk.Canvas(root, width=300, height=200, bg="white")
tk.Listbox(root, selectmode="extended", height=6)
tk.Menu(root, tearoff=0); tk.Toplevel(root)
tk.PhotoImage(file="icon.png")

Code Explained

One line per widget with its most-used options
sv, bv, dv stand for String/Boolean/Double vars
fn is any zero-argument callback
ttk widgets first, then classic-only widgets
Placeholders (img, widget) must exist in real code

⚠ Common Mistakes

  • Chaining .grid() onto the constructor and keeping None
  • Using classic widgets where a ttk one exists
  • Mixing pack and grid in one parent

✓ Tips & Best Practices

  • Keep this sheet next to the detailed pages
  • Start every app with import tkinter as tk + ttk
  • Reach for Treeview before building tables by hand

Quick Summary

  • ttk first; tk for Text, Canvas, Listbox, Menu
  • pack / grid / place
  • Variables link data to widgets
  • Options via configure()
