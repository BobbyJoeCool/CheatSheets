Shipping a Tkinter App

End users usually don't have Python, so bundle the interpreter, Tcl/Tk and your code into an executable. PyInstaller is the most common tool: --windowed hides the console window, --onefile produces a single file (slower to start), and --add-data includes images and other resources. Inside the bundle, locate resources relative to sys._MEIPASS or the script file. Nuitka compiles to C for speed, and cx_Freeze or Briefcase suit installers and app stores.

Notes

  • Build on each target OS; there's no cross-compiling
  • --add-data uses src:dest; Windows needed ; before PyInstaller 6
  • Antivirus tools sometimes flag --onefile builds
  • Rename a script to .pyw to run without a console on Windows
  • Sign and notarize macOS apps for distribution

Bundling with PyInstaller

# Install and build
pip install pyinstaller
pyinstaller --windowed --onefile --name Inventory \
    --icon assets/app.ico --add-data "assets:assets" app.py
# Output: dist/Inventory(.exe)  |  build/ = scratch  |  Inventory.spec

# One-folder build (faster startup, easier debugging)
pyinstaller --windowed --name Inventory --add-data "assets:assets" app.py

# Rebuild from the generated spec after editing it
pyinstaller Inventory.spec

# Resource helper inside app.py (works frozen or not):
#   import sys
#   from pathlib import Path
#   BASE = Path(getattr(sys, "_MEIPASS", Path(__file__).parent))
#   icon = tk.PhotoImage(file=BASE / "assets" / "save.png")

# Alternatives
python -m nuitka --standalone --enable-plugin=tk-inter \
    --windows-console-mode=disable app.py
cxfreeze build                       # cx_Freeze with pyproject config
briefcase create && briefcase build  # BeeWare installers

Code Explained

--windowed = no console window behind the GUI
--add-data "src:dest" copies resources into the bundle
The spec file records options for repeatable builds
sys._MEIPASS is the unpack folder in frozen apps
Nuitka needs the tk-inter plugin for Tkinter

⚠ Common Mistakes

  • Loading files by relative path from the current directory
  • Shipping a console window with a GUI app
  • Only testing the build on the developer's machine

✓ Tips & Best Practices

  • Keep all assets in one folder and add it once
  • Commit the .spec file for reproducible builds
  • Debug with a console build before switching to --windowed

Quick Summary

  • PyInstaller --windowed --onefile
  • --add-data for assets
  • Resolve paths via sys._MEIPASS
  • Build on every target OS
