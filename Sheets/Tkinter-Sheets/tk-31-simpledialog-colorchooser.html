Quick Input and Color Dialogs

tkinter.simpledialog provides tiny modal prompts: askstring(), askinteger() and askfloat() show a field with OK/Cancel and return the typed value, or None if cancelled. The numeric versions validate input and support minvalue/maxvalue. tkinter.colorchooser.askcolor() opens the native color picker and returns ((r, g, b), "#rrggbb"), or (None, None) on cancel. For anything richer, subclass simpledialog.Dialog and override body() and apply().

Notes

  • Numeric dialogs re-prompt automatically on bad input
  • initialvalue= pre-fills the field
  • show="*" works on askstring for passwords
  • Dialog subclasses get OK/Cancel buttons for free
  • Tk has no built-in date picker; see tkcalendar (Sheet 60)

Prompts and a Custom Dialog

import tkinter as tk
from tkinter import simpledialog as sd, colorchooser, ttk

root = tk.Tk()
name = sd.askstring("Name", "Your name?", initialvalue="Ada", parent=root)
age = sd.askinteger("Age", "Age in years:", minvalue=0, maxvalue=130,
                    parent=root)
rgb, hexcolor = colorchooser.askcolor("#3366cc", title="Pick a color",
                                      parent=root)
if hexcolor:
    root.config(bg=hexcolor)

class LoginDialog(sd.Dialog):
    def body(self, master):
        ttk.Label(master, text="User").grid(row=0, column=0, sticky="w")
        ttk.Label(master, text="Password").grid(row=1, column=0, sticky="w")
        self.user = ttk.Entry(master); self.user.grid(row=0, column=1)
        self.pw = ttk.Entry(master, show="*"); self.pw.grid(row=1, column=1)
        return self.user                     # widget with initial focus
    def validate(self):
        return bool(self.user.get())         # False keeps dialog open
    def apply(self):
        self.result = (self.user.get(), self.pw.get())
dlg = LoginDialog(root, title="Log in")
print(name, age, hexcolor, dlg.result)       # result is None on Cancel

Code Explained

Each prompt returns None if the user cancels
askinteger enforces the 0–130 range
askcolor returns RGB and hex; hex is None on cancel
body() builds fields and returns the focus widget
apply() stores the answer in self.result

⚠ Common Mistakes

  • Using the result without checking for None
  • Reading askcolor()[1] as always present
  • Building fields in __init__ instead of body()

✓ Tips & Best Practices

  • Use simpledialog for one value, a Dialog subclass for forms
  • Return the first Entry from body() for focus
  • Validate in validate() and explain errors with a messagebox
