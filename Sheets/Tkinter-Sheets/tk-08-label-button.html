Showing Text and Taking Clicks

A Label displays text or an image; it can show a fixed string with text= or a live value through textvariable=. A Button runs a callback when clicked, given by command= with no arguments. Both share many options: image with compound to mix picture and text, anchor and justify for alignment, wraplength for automatic line wrapping, and underline to mark a keyboard mnemonic. A disabled Button greys out and ignores clicks.

Notes

  • textvariable beats text when both are given
  • wraplength is in screen units (pixels by default)
  • invoke() runs a Button's command as if clicked
  • Message is an older wrapping label; prefer wraplength
  • ttk.Button has no bg; use a style instead

Labels and Buttons Together

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
count = tk.IntVar(value=0)

ttk.Label(root, text="Clicks:", font=("Segoe UI", 12)).grid(row=0, column=0)
ttk.Label(root, textvariable=count, width=5,
          anchor="e").grid(row=0, column=1)

def add():
    count.set(count.get() + 1)
    reset.config(state="normal")

ttk.Button(root, text="Add", underline=0, command=add).grid(row=1, column=0)
reset = ttk.Button(root, text="Reset", state="disabled",
                   command=lambda: count.set(0))
reset.grid(row=1, column=1)
root.bind("<Alt-a>", lambda e: add())       # Alt+A, matches underline

tk.Label(root, text="A long help message that wraps neatly "
         "inside two hundred pixels.", wraplength=200,
         justify="left").grid(row=2, column=0, columnspan=2, pady=6)

root.mainloop()

Code Explained

textvariable=count updates the label automatically
anchor="e" right-aligns text inside the label's width
underline=0 draws the mnemonic but doesn't bind the key
A lambda adapts the bind event argument to add()
wraplength plus justify controls multi-line text

⚠ Common Mistakes

  • Expecting underline to bind the key by itself
  • Changing text when textvariable is also set
  • Using justify to align a single line (use anchor)

✓ Tips & Best Practices

  • Prefer ttk.Label/ttk.Button for native styling
  • Disable buttons until their action makes sense
  • Use invoke() to trigger buttons from key bindings

Quick Summary

  • Label: text or textvariable, optional image
  • Button: command= callback, state
  • anchor aligns, justify aligns lines
  • wraplength wraps long text
