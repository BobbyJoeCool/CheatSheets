Drawing on a Canvas

A Canvas is a drawing surface for lines, shapes, text, images and even embedded widgets. Each create_*() call adds an item and returns its integer id. Coordinates are pixels from the canvas's top-left, with y growing downward. Rectangles and ovals are defined by a bounding box (x1, y1, x2, y2), lines and polygons by a list of points. Unlike drawing in many libraries, items are retained objects: you can move, recolor or delete them later without redrawing everything.

Notes

  • Ovals are drawn inside their bounding box
  • fill="" means no fill (transparent interior)
  • width is the outline thickness
  • Later items draw on top of earlier ones
  • Use highlightthickness=0 to remove the focus border

Basic Shapes

import tkinter as tk

root = tk.Tk()
c = tk.Canvas(root, width=360, height=240, bg="white", highlightthickness=0)
c.pack()

c.create_line(10, 10, 350, 10, fill="gray", dash=(4, 2))
c.create_line(20, 200, 80, 140, 140, 180, 200, 120,
              fill="navy", width=3, smooth=True, arrow="last")
c.create_rectangle(20, 30, 120, 100, fill="#90caf9", outline="#1565c0", width=2)
c.create_oval(140, 30, 240, 100, fill="#ffcc80", outline="")
c.create_oval(260, 30, 330, 100, outline="green", width=4)       # circle
c.create_polygon(260, 220, 300, 140, 340, 220, fill="#a5d6a7",
                 outline="black")
c.create_arc(140, 120, 240, 220, start=30, extent=300,
             style="pieslice", fill="gold")                     # Pac-Man

c.create_text(180, 230, text="Canvas demo", font=("Helvetica", 10, "bold"))
c.create_rectangle(0, 0, 360, 240, outline="red", width=1)
root.mainloop()

Code Explained

dash=(4, 2) draws 4 px on, 2 px off
Multi-point lines can be smoothed into curves
Rectangles and ovals take two opposite corners
create_arc uses start/extent in degrees
create_text centers on the point by default

⚠ Common Mistakes

  • Expecting y to increase upward like math plots
  • Passing width/height to create_oval instead of corners
  • Using fill on an arc with style="arc" (no interior)

✓ Tips & Best Practices

  • Wrap repeated shapes in helper functions
  • Store returned ids for items you'll change later
  • Use outline="" for flat, borderless shapes

Quick Summary

  • create_* returns an item id
  • Pixel coords, y downward
  • Boxes for rect/oval/arc, points for lines
  • Items persist and can be changed
