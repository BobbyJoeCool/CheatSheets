ttk.Style — configure & map

ttk.Style() · configure() · map() · lookup() · "Accent.TButton" · state specs · !disabled

Styling ttk Widgets

A style is a named bundle of appearance settings. Every ttk widget uses a default style named after its class (TButton, TLabel, TEntry, Treeview). Style.configure(name, **opts) sets options for a style, and Style.map(name, **opts) sets state-dependent options as lists of (state spec, value) pairs, such as a different background while active or pressed. Create a custom style by prefixing a class style ("Danger.TButton") and passing style= to the widget.

Notes

  • Changing TButton restyles every ttk Button
  • Prefixed styles inherit everything from the base style
  • Some themes (vista, aqua) ignore many color options; use clam
  • lookup() reads an effective option value
  • Use "." to configure the root style for all widgets

Custom Button Styles

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
style = ttk.Style(root)
style.theme_use("clam")                    # honors color options

style.configure(".", font=("Segoe UI", 10))          # all widgets
style.configure("TButton", padding=(10, 4))
style.configure("Danger.TButton", foreground="white",
                background="#c62828", bordercolor="#8e0000")
style.map("Danger.TButton",
          background=[("pressed", "#8e0000"), ("active", "#e53935"),
                      ("disabled", "#bdbdbd")],
          foreground=[("disabled", "#eeeeee")])

style.configure("Title.TLabel", font=("Segoe UI", 16, "bold"))
style.configure("Hint.TLabel", foreground="gray40")

ttk.Label(root, text="Account", style="Title.TLabel").pack(anchor="w", padx=10)
ttk.Label(root, text="This can't be undone.", style="Hint.TLabel").pack(padx=10)
ttk.Button(root, text="Cancel").pack(side="left", padx=10, pady=10)
ttk.Button(root, text="Delete", style="Danger.TButton").pack(side="right", padx=10)
print(style.lookup("Danger.TButton", "background"))   # '#c62828'
root.mainloop()

Code Explained

clam respects background/foreground; native themes may not
"." sets defaults for every style
Danger.TButton inherits TButton and overrides colors
map() entries are checked in order; first matching state wins
Widgets opt in with style="Name.TClass"

⚠ Common Mistakes

  • Styling on vista/aqua and seeing no color change
  • Naming a style Danger without the .TButton suffix
  • Using configure for hover colors instead of map

✓ Tips & Best Practices

  • Define all styles in one function at startup
  • Name styles by role: Primary.TButton, Muted.TLabel
  • Put specific states (pressed) before general ones (active)

Quick Summary

  • Styles named Prefix.TClass
  • configure = static, map = per-state
  • Widgets choose via style=
  • clam for full color control
