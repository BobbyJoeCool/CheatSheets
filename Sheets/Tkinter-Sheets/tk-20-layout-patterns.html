Layout Patterns & Pitfalls

nested Frames · never mix pack and grid · pack_propagate(False) · grid_propagate() · form layout · toolbar + status bar

Building Real Layouts

Real screens are built by nesting Frames, each with the geometry manager that suits its contents: pack for bars and simple stacks, grid for forms and tables, place for overlays. The one hard rule is: **never use pack and grid for children of the same parent**; Tk 8.6 raises a TclError, and older versions could freeze as both managers fought over the parent's size. Containers normally shrink to fit their children; turn that off with pack_propagate(False) or grid_propagate(False) to keep a fixed size.

Notes

  • Different managers in different Frames are fine
  • Propagation off = honor the Frame's width/height
  • Sketch the screen as nested boxes before coding
  • One Frame per region keeps code easy to change
  • winfo_children() lists a container's widgets

App Shell: Toolbar, Form, Status

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.geometry("520x300")

top = ttk.Frame(root, padding=4)                  # pack in root
body = ttk.Frame(root, padding=10)
status = ttk.Label(root, text="Ready", anchor="w", padding=(6, 2))
top.pack(fill="x"); status.pack(side="bottom", fill="x")
body.pack(fill="both", expand=True)
for t in ("New", "Open", "Save"):                 # pack in toolbar
    ttk.Button(top, text=t).pack(side="left")
body.columnconfigure(1, weight=1)                 # grid in body
for r, lbl in enumerate(("Title", "Author", "Year")):
    ttk.Label(body, text=lbl).grid(row=r, column=0, sticky="w", pady=2)
    ttk.Entry(body).grid(row=r, column=1, sticky="ew", pady=2)
preview = tk.Frame(body, width=120, height=80, bg="#ddd")
preview.grid(row=0, column=2, rowspan=3, padx=(10, 0))
preview.grid_propagate(False)                     # keep 120x80
tk.Label(preview, text="Cover", bg="#ddd").place(relx=.5, rely=.5,
                                                 anchor="center")
root.mainloop()

Code Explained

Root children all use pack: toolbar, status, body
The toolbar's buttons use pack inside their own Frame
The body uses grid for an aligned form
grid_propagate(False) keeps the preview at 120×80
place centers a label inside the fixed preview

⚠ Common Mistakes

  • pack and grid in the same parent (TclError in Tk 8.6)
  • Setting Frame width/height without disabling propagation
  • One giant grid for the whole window, hard to change later

✓ Tips & Best Practices

  • Name frames after regions: toolbar, sidebar, body
  • Color frames temporarily to see their bounds
  • Wrap each region in its own class as it grows

Quick Summary

  • Nest Frames; one manager per parent
  • pack for bars, grid for forms, place for overlays
  • Propagation off for fixed-size containers
  • Debug with colors and winfo_*
