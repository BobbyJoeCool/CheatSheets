Making Grids Resize Properly

By default, grid rows and columns stay at their natural size when the window grows. To let them grow, give them a weight with columnconfigure(index, weight=n) and rowconfigure(index, weight=n) on the parent. Extra space is shared in proportion to the weights. minsize sets a minimum pixel size, pad adds space, and uniform forces columns in the same group to equal width. Remember to configure the root too, or the frame inside it never grows.

Notes

  • Weight 0 (default) = fixed size
  • Configure the parent of the widgets, not the widgets
  • A list of indices configures several at once
  • Widgets still need sticky to fill the growing cell
  • uniform="grp" + equal weights = equal columns

A Resizable Two-Pane Layout

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.geometry("500x300")
root.columnconfigure(0, weight=1)        # let the frame grow
root.rowconfigure(0, weight=1)

frame = ttk.Frame(root, padding=6)
frame.grid(row=0, column=0, sticky="nsew")

frame.columnconfigure(0, weight=1, minsize=120)    # sidebar
frame.columnconfigure(1, weight=3)                 # main: 3× share
frame.rowconfigure(1, weight=1)                    # content row grows

ttk.Label(frame, text="Folders").grid(row=0, column=0, sticky="w")
ttk.Label(frame, text="Messages").grid(row=0, column=1, sticky="w")
tk.Listbox(frame).grid(row=1, column=0, sticky="nsew", padx=(0, 4))
tk.Text(frame).grid(row=1, column=1, sticky="nsew")

bar = ttk.Frame(frame)
bar.grid(row=2, column=0, columnspan=2, sticky="ew", pady=(6, 0))
bar.columnconfigure((0, 1, 2), weight=1, uniform="btn")
for i, t in enumerate(("Reply", "Forward", "Delete")):
    ttk.Button(bar, text=t).grid(row=0, column=i, sticky="ew", padx=2)

root.mainloop()

Code Explained

Root weights let the outer frame follow the window size
Columns share extra width 1:3 (sidebar:main)
Only row 1 grows; header and button rows stay fixed
sticky="nsew" makes widgets fill their growing cells
uniform="btn" keeps the three buttons the same width

⚠ Common Mistakes

  • Configuring weights on the child widget instead of its parent
  • Forgetting root weights, so nothing below it can grow
  • Giving weights but no sticky, leaving widgets centered

✓ Tips & Best Practices

  • Resize the window while developing to test weights
  • Use minsize to keep sidebars readable
  • Use uniform for toolbars of equal buttons

Quick Summary

  • Weights distribute extra space
  • Set on the parent with columnconfigure/rowconfigure
  • minsize and uniform for limits and equality
  • Pair weights with sticky
