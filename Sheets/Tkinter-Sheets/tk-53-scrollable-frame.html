Scrollable Frames

Canvas + Frame · create_window() · <Configure> · scrollregion · bbox("all") · <MouseWheel> · Button-4/5 on X11

Scrolling a Panel of Widgets

Frames can't scroll, but a Canvas can, and a Canvas can hold a widget with create_window(). The standard recipe: put an inner Frame inside a Canvas, add widgets to the inner Frame, and whenever its size changes (<Configure>), set the canvas scrollregion to bbox("all"). Also stretch the inner Frame to the canvas width so rows fill horizontally. Mouse-wheel scrolling needs explicit bindings, which differ by platform.

Notes

  • Bind the wheel only while the pointer is over the panel
  • Windows: delta ±120; macOS: small deltas; X11: Button-4/5
  • Tk 9.0 unifies X11 wheel events as <MouseWheel>
  • Thousands of rows? Use a Treeview or a virtualized list
  • Wrap the recipe in a reusable class

Reusable ScrollableFrame

import tkinter as tk
from tkinter import ttk

class ScrollableFrame(ttk.Frame):
    def __init__(self, parent, **kw):
        super().__init__(parent, **kw)
        self.canvas = tk.Canvas(self, highlightthickness=0)
        sb = ttk.Scrollbar(self, orient="vertical", command=self.canvas.yview)
        self.canvas.configure(yscrollcommand=sb.set)
        self.canvas.pack(side="left", fill="both", expand=True)
        sb.pack(side="right", fill="y")
        self.inner = ttk.Frame(self.canvas)
        win = self.canvas.create_window((0, 0), window=self.inner, anchor="nw")
        self.inner.bind("<Configure>", lambda e: self.canvas.configure(
            scrollregion=self.canvas.bbox("all")))
        self.canvas.bind("<Configure>",
            lambda e: self.canvas.itemconfigure(win, width=e.width))
        self.bind("<Enter>", lambda e: self.bind_all("<MouseWheel>", self._wheel))
        self.bind("<Leave>", lambda e: self.unbind_all("<MouseWheel>"))
    def _wheel(self, e):                       # Windows/macOS
        self.canvas.yview_scroll(-1 if e.delta > 0 else 1, "units")
root = tk.Tk(); root.geometry("300x250")
panel = ScrollableFrame(root); panel.pack(fill="both", expand=True)
for i in range(40):
    ttk.Checkbutton(panel.inner, text=f"Option {i + 1}").pack(anchor="w")

Code Explained

The inner Frame lives in the canvas via create_window
Inner <Configure> keeps scrollregion in sync
Canvas <Configure> stretches the inner Frame's width
Wheel is bound globally only while hovering
Callers add widgets to panel.inner

⚠ Common Mistakes

  • Forgetting to update scrollregion as content grows
  • Binding the wheel with bind_all permanently
  • Using pack(fill="x") in the inner frame without matching width

✓ Tips & Best Practices

  • Expose inner as the parent for child widgets
  • Call yview_moveto(0) after rebuilding content
  • Add X11 Button-4/5 bindings for Linux users on Tk 8.6

Quick Summary

  • Canvas + inner Frame + create_window
  • scrollregion = bbox("all") on resize
  • Stretch inner width to canvas width
  • Wheel bindings per platform
