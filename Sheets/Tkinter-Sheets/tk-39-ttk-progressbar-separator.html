Progressbar, Separator & Sizegrip

ttk.Progressbar · determinate · indeterminate · start() · step() · ttk.Separator · ttk.Sizegrip

Progress, Dividers and Resize Grips

ttk.Progressbar shows progress in two modes. Determinate fills toward maximum as you set value (or call step()). Indeterminate bounces back and forth with start(ms) / stop() when the total is unknown. Update the bar from the main thread, usually inside after() callbacks; a loop that blocks the event loop freezes it. ttk.Separator draws a thin horizontal or vertical divider, and ttk.Sizegrip adds the resize handle in a window's bottom-right corner.

Notes

  • maximum defaults to 100
  • step(n) adds n and wraps at maximum
  • Bind the bar to a DoubleVar with variable=
  • Separators need fill="x"/sticky="ew" to stretch
  • macOS shows its own resize corner; Sizegrip is optional there

Download Simulation

import tkinter as tk
from tkinter import ttk

root = tk.Tk(); root.geometry("360x180")
progress = tk.DoubleVar()

ttk.Label(root, text="Downloading…").pack(anchor="w", padx=10, pady=(10, 0))
bar = ttk.Progressbar(root, mode="determinate", maximum=50,
                      variable=progress, length=320)
bar.pack(padx=10, pady=6)
spinner = ttk.Progressbar(root, mode="indeterminate", length=320)
spinner.pack(padx=10)

ttk.Separator(root, orient="horizontal").pack(fill="x", pady=10)
status = ttk.Label(root, text="0%"); status.pack(side="left", padx=10)
ttk.Sizegrip(root).pack(side="right", anchor="se")

def tick():
    if progress.get() < bar["maximum"]:
        progress.set(progress.get() + 1)
        status.config(text=f"{progress.get() / bar['maximum']:.0%}")
        root.after(80, tick)          # schedule next update
    else:
        spinner.stop(); status.config(text="Done")

spinner.start(15)                     # ms per animation step
root.after(200, tick)
root.mainloop()

Code Explained

maximum=50 means 50 units fill the bar
variable=progress drives the bar from a DoubleVar
The indeterminate bar animates on its own after start()
after(80, tick) updates without blocking the loop
Sizegrip packs into the bottom-right corner

⚠ Common Mistakes

  • Updating the bar in a for loop with time.sleep (frozen UI)
  • Forgetting stop() on an indeterminate bar
  • Setting value above maximum

✓ Tips & Best Practices

  • Pair the bar with a text percentage for accessibility
  • Feed progress from threads through a queue (Sheet 51)
  • Use length= for a consistent bar width

Quick Summary

  • Determinate: value/maximum
  • Indeterminate: start()/stop()
  • Update via after(), not loops
  • Separator divides, Sizegrip resizes
