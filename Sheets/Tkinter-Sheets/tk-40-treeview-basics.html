Tables and Trees with Treeview

ttk.Treeview displays hierarchical items, tabular rows with columns, or both. Declare data columns with columns=(…), then set each header with heading() and width with column(). show="headings" hides the tree column for a plain table, and show="tree" shows only the tree. insert(parent, index, values=…) adds a row and returns its item id; use "" as the parent for top-level items. item() reads or updates a row, and delete() removes rows.

Notes

  • Column #0 is the tree column (labels via text=)
  • Item ids are strings; pass iid= to choose your own
  • get_children() lists items under a parent
  • Values are stored as strings; convert when reading
  • Add a Scrollbar with yscrollcommand like a Listbox

Employee Table

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
cols = ("name", "dept", "salary")
tree = ttk.Treeview(root, columns=cols, show="headings", height=8)
sb = ttk.Scrollbar(root, orient="vertical", command=tree.yview)
tree.configure(yscrollcommand=sb.set)
tree.grid(row=0, column=0, sticky="nsew"); sb.grid(row=0, column=1, sticky="ns")
root.columnconfigure(0, weight=1); root.rowconfigure(0, weight=1)

for c, title, w, anchor in [("name", "Name", 160, "w"),
                            ("dept", "Department", 120, "w"),
                            ("salary", "Salary", 90, "e")]:
    tree.heading(c, text=title, anchor=anchor)
    tree.column(c, width=w, anchor=anchor, stretch=(c == "name"))
rows = [("Ada Lovelace", "R&D", 98000), ("Alan Turing", "R&D", 102000),
        ("Grace Hopper", "Ops", 95000)]
for r in rows:
    tree.insert("", "end", values=(r[0], r[1], f"{r[2]:,}"))
iid = tree.insert("", 0, iid="new", values=("New Hire", "Sales", "60,000"))
tree.item(iid, values=("Jo Doe", "Sales", "61,000"))   # update row
print(tree.item(iid, "values"))           # ('Jo Doe', 'Sales', '61,000')
print(len(tree.get_children()))           # 4
tree.delete(*tree.get_children()[2:])     # remove rows 3+
root.mainloop()

Code Explained

show="headings" hides the tree column for a flat table
heading() sets titles; column() sets width and alignment
stretch lets only the Name column absorb extra width
insert("", "end", values=…) appends a top-level row
item(iid, values=…) edits a row in place

⚠ Common Mistakes

  • Forgetting show="headings" and getting an empty first column
  • Reusing an iid (raises TclError)
  • Sorting numeric columns as strings

✓ Tips & Best Practices

  • Use database primary keys as iid for easy lookup
  • Right-align numeric columns with anchor="e"
  • Clear with delete(*tree.get_children())

Quick Summary

  • columns, heading, column define the table
  • insert("", "end", values=…) adds rows
  • Item ids identify rows
  • show="headings" for flat tables
