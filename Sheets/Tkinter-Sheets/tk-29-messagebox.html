Standard Message Boxes

tkinter.messagebox shows native modal dialogs with one call. The show functions (showinfo, showwarning, showerror) only inform and return "ok". The ask functions return the user's answer: askyesno() and askokcancel() return True/False, askyesnocancel() adds None for Cancel, askretrycancel() returns a bool, and askquestion() returns the string "yes" or "no". Always pass parent= so the dialog is centered on, and owned by, the right window.

Notes

  • The call blocks until the user answers
  • icon= overrides the default (info, warning, error, question)
  • default= picks the button activated by Enter
  • detail= adds smaller secondary text (Tk 8.5+)
  • Appearance is native, so it differs by OS

Inform, Confirm, Decide

import tkinter as tk
from tkinter import messagebox as mb

root = tk.Tk()
dirty = True

def on_close():
    if dirty:
        answer = mb.askyesnocancel(
            "Unsaved changes", "Save changes before closing?",
            detail="Your edits will be lost if you don't save.",
            icon="warning", parent=root)
        if answer is None:          # Cancel: keep the window open
            return
        if answer:                  # Yes
            print("saving…")
    root.destroy()                  # Yes, No, or nothing to save

def delete():
    if mb.askokcancel("Delete", "Delete 3 files?", icon="warning",
                      default="cancel", parent=root):
        mb.showinfo("Done", "Files deleted.", parent=root)
tk.Button(root, text="Delete…", command=delete).pack(padx=30, pady=20)
root.protocol("WM_DELETE_WINDOW", on_close)

Code Explained

askyesnocancel gives three outcomes: True, False, None
Test is None first; None is also falsy
detail= explains consequences under the main question
default="cancel" makes Enter the safe choice
parent=root keeps dialogs on top of the app

⚠ Common Mistakes

  • Treating askquestion() like a bool ("no" is truthy)
  • Checking if not answer and merging No with Cancel
  • Omitting parent= so dialogs appear behind Toplevels

✓ Tips & Best Practices

  • Make destructive confirmations default to Cancel
  • Write titles as short nouns, messages as questions
  • Use showerror for failures the user must act on

Quick Summary

  • show* inform; ask* return answers
  • askyesnocancel → True/False/None
  • parent=, icon=, default=, detail=
  • Modal: blocks until answered
