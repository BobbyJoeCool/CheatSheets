Control Variables

StringVar · IntVar · DoubleVar · BooleanVar · get() · set() · trace_add() · trace_remove()

Tk Variables Link Data and Widgets

Control variables (StringVar, IntVar, DoubleVar, BooleanVar) are values held inside the Tcl interpreter that widgets can watch. Connect one through textvariable= or variable=, and every widget using it updates when you call set(); every user edit is visible through get(). trace_add() registers a callback that fires when the variable is written, read or unset, which is how you build live previews and dependent fields.

Notes

  • Create variables after Tk() exists (or pass master=)
  • IntVar.get() raises TclError if the text isn't a valid int
  • Trace callbacks receive (name, index, mode) strings
  • trace_add replaces the deprecated trace/trace_variable
  • Keep a reference: an unreferenced variable is deleted

Live Total with Traces

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
price = tk.DoubleVar(value=9.99)
qty = tk.IntVar(value=1)
total = tk.StringVar()

def update_total(*_):
    try:
        total.set(f"Total: ${price.get() * qty.get():,.2f}")
    except tk.TclError:              # empty or invalid field
        total.set("Total: —")

for v in (price, qty):
    v.trace_add("write", update_total)
update_total()
ttk.Entry(root, textvariable=price, width=8).grid(row=0, column=0)
ttk.Spinbox(root, from_=1, to=99, textvariable=qty,
            width=4).grid(row=0, column=1, padx=4)
ttk.Label(root, textvariable=total).grid(row=1, column=0, columnspan=2)
tid = qty.trace_add("write", lambda *a: print("qty", qty.get()))
qty.trace_remove("write", tid)      # stop watching
print(qty.trace_info())             # [(('write',), 'name…')]
root.mainloop()

Code Explained

*_ absorbs the three trace arguments
try/except TclError handles half-typed numbers
The same callback traces both inputs
textvariable= links Entry, Spinbox and Label
trace_add returns an id needed by trace_remove

⚠ Common Mistakes

  • Creating a StringVar() before Tk() with no master
  • Letting IntVar.get() crash on an empty Entry
  • Writing to the same variable inside its write trace (recursion)

✓ Tips & Best Practices

  • Use variables for any value shown in more than one place
  • Wrap numeric get() calls in try/except tk.TclError
  • Give variables a name= to debug traces

Quick Summary

  • String/Int/Double/BooleanVar
  • get() / set() sync all linked widgets
  • trace_add("write", fn) reacts to changes
  • Keep references so they aren't deleted
