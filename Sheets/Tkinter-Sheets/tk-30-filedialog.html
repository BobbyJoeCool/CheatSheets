Open and Save File Pickers

tkinter.filedialog wraps the native file pickers. askopenfilename() returns a path string (or "" if cancelled), askopenfilenames() returns a tuple of paths, asksaveasfilename() returns the chosen save path, and askdirectory() returns a folder. The askopenfile()/asksaveasfile() variants return an open file object (or None). filetypes is a list of (label, pattern) pairs that fills the type drop-down.

Notes

  • Cancel returns "" (or () / None for some variants)
  • Paths use forward slashes even on Windows
  • defaultextension is appended if the user omits one
  • confirmoverwrite (default True) asks before replacing
  • initialfile pre-fills the file name box

Open, Save As, Choose Folder

import tkinter as tk
from tkinter import filedialog as fd
from pathlib import Path

root = tk.Tk()
TYPES = [("Text files", "*.txt"), ("Markdown", "*.md *.markdown"),
         ("All files", "*.*")]
text = tk.Text(root, width=60, height=15); text.pack()

def open_file():
    path = fd.askopenfilename(parent=root, title="Open",
                              filetypes=TYPES, initialdir=Path.home())
    if not path:                       # cancelled
        return
    text.delete("1.0", "end")
    text.insert("1.0", Path(path).read_text(encoding="utf-8"))

def save_as():
    path = fd.asksaveasfilename(parent=root, filetypes=TYPES,
                                defaultextension=".txt", initialfile="notes")
    if path:
        Path(path).write_text(text.get("1.0", "end-1c"), encoding="utf-8")
tk.Button(root, text="Open", command=open_file).pack(side="left")
tk.Button(root, text="Save As", command=save_as).pack(side="left")
tk.Button(root, text="Folder", command=lambda: print(
    fd.askdirectory(parent=root, mustexist=True))).pack(side="left")

Code Explained

Patterns in one entry are space-separated
if not path handles Cancel
initialdir starts browsing in the home folder
defaultextension adds .txt when missing
"end-1c" avoids saving Text's extra newline

⚠ Common Mistakes

  • Opening "" after the user cancels
  • Using askopenfile() without closing the file object
  • Missing a ("All files", "*.*") fallback entry

✓ Tips & Best Practices

  • Remember the last folder and pass it as initialdir
  • Prefer the filename functions plus pathlib for I/O
  • Always pass an encoding when reading text

Quick Summary

  • askopenfilename, asksaveasfilename, askdirectory
  • Cancel → empty string
  • filetypes list of (label, pattern)
  • defaultextension for save dialogs
