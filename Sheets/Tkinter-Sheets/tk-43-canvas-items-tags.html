Changing Items with Ids and Tags

Every canvas item has a unique integer id and any number of string tags. Methods that take an item accept either form: an id affects one item, a tag affects every item carrying it, and the special tag "all" means everything. itemconfigure() changes options, coords() reads or replaces coordinates, move() shifts by an offset, and delete() removes items. find_withtag() and friends return matching ids, and tag_raise()/tag_lower() change stacking order.

Notes

  • Tags are added with tags= or addtag_withtag()
  • "current" is the item under the mouse pointer
  • gettags(id) lists an item's tags
  • type(id) returns "oval", "line", etc.
  • moveto() (Python 3.8+) moves to absolute coordinates

Grouping with Tags

import tkinter as tk

root = tk.Tk()
c = tk.Canvas(root, width=360, height=200, bg="white"); c.pack()

for i in range(5):                     # five "pieces" in two groups
    x = 20 + i * 68
    team = "red" if i % 2 else "blue"
    c.create_oval(x, 80, x + 50, 130, fill=team, tags=("piece", team))

label = c.create_text(180, 20, text="Click a key: r, b, d, s")
def recolor(team, color):
    c.itemconfigure(team, fill=color)          # every item tagged team
root.bind("r", lambda e: recolor("red", "salmon"))
root.bind("b", lambda e: c.move("blue", 0, 20))   # shift blue pieces
root.bind("d", lambda e: c.delete("red"))
root.bind("s", lambda e: c.itemconfigure(label,
          text=f"{len(c.find_withtag('piece'))} pieces"))
first = c.find_withtag("piece")[0]
print(c.coords(first))                 # [20.0, 80.0, 70.0, 130.0]
c.coords(first, 20, 150, 70, 190)      # replace coordinates
c.addtag_withtag("selected", first)
print(c.gettags(first))                # ('piece', 'blue', 'selected')
c.tag_raise("selected")
root.mainloop()

Code Explained

Each oval carries two tags: piece and its team
itemconfigure("red", …) changes all red items at once
move(tag, dx, dy) shifts by an offset
find_withtag returns a tuple of ids
coords(id, …) replaces an item's coordinates

⚠ Common Mistakes

  • Using numeric strings as tags ("1" looks like an id)
  • Calling coords() with too few numbers for the item type
  • Forgetting "all" matches the background too

✓ Tips & Best Practices

  • Tag items by role and by group
  • Use delete("all") to clear before redrawing
  • Prefer tags over storing long lists of ids

Quick Summary

  • Ids for one item, tags for groups
  • itemconfigure, coords, move, delete
  • find_* methods return ids
  • tag_raise/tag_lower set stacking
