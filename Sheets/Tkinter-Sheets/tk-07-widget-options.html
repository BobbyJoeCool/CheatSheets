Widget Options & Configuration

configure() · cget() · widget["text"] · keys() · option_add() · winfo_class() · standard options

How Widget Options Work

Every widget is configured through options (keyword arguments) such as text, width or state. Set them when you create the widget, change them later with configure() (alias config()), and read them with cget() or dictionary syntax widget["text"]. keys() lists every option a widget supports. option_add() sets app-wide defaults through Tk's option database, which saves repeating the same font or color on every widget.

Notes

  • config() with no arguments returns a dict of all options
  • Values come back as strings or Tcl objects; convert if needed
  • Units: plain ints are pixels; "2c", "1i", "10p" also work
  • width on text widgets is in characters, not pixels
  • ttk widgets support fewer appearance options (use styles)

Set, Change and Read Options

import tkinter as tk

root = tk.Tk()
root.option_add("*Font", "Helvetica 11")        # default for all widgets
root.option_add("*Button.relief", "groove")      # only classic Buttons

btn = tk.Button(root, text="Save", width=12, state="disabled")
btn.pack(padx=10, pady=10)

btn.configure(text="Save now", state="normal")  # change several at once
btn["fg"] = "darkgreen"                         # dict-style set

print(btn.cget("text"))        # 'Save now'
print(btn["width"])            # 12
print(btn.winfo_class())       # 'Button'
print("command" in btn.keys()) # True

info = btn.configure("relief")
print(info)    # ('relief', 'relief', 'Relief', <raised>, 'groove')

root.mainloop()

Code Explained

option_add patterns: *Font for all, *Button.relief per class
configure() accepts any number of keyword options
Item assignment btn["fg"] = … is shorthand for configure
winfo_class() gives the class name used in option patterns
configure("relief") returns name, db name, class, default, value

⚠ Common Mistakes

  • Using bg= on ttk widgets (raises TclError: unknown option)
  • Comparing w["width"] == "12" when it returns an int
  • Misspelling an option; Tk raises instead of ignoring it

✓ Tips & Best Practices

  • Set fonts and colors once with option_add before creating widgets
  • Use keys() in the REPL to explore any widget
  • Group related changes in a single configure() call

Quick Summary

  • Options are keyword args on create
  • configure() to change, cget() / [] to read
  • option_add() for app-wide defaults
  • keys() lists everything a widget supports
