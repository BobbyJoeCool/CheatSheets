bind() & Event Sequences

bind() · <Button-1> · <Double-Button-1> · <Key> · <Return> · <Control-s> · <Configure> · unbind()

Binding Events to Handlers

widget.bind(sequence, handler) calls handler(event) whenever the event sequence occurs on that widget. Sequences are strings in angle brackets: <Modifier-Type-Detail>, such as <Button-1> (left click), <Control-s>, <KeyPress-Return> or <Double-Button-1>. Common shorthand works too: <Return>, <Escape>, <Key> (any key). <Configure> fires on resize or move, and <Enter>/<Leave> track the mouse pointer entering or leaving a widget.

Notes

  • Handlers always receive one event argument
  • Letters are case-sensitive: <Control-S> needs Shift
  • add="+" adds a handler instead of replacing
  • Key events go to the widget with keyboard focus
  • macOS uses <Command-…> for Cmd shortcuts

Mouse, Keyboard and Resize

import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=300, height=200, bg="white")
canvas.pack(fill="both", expand=True)
status = tk.Label(root, anchor="w"); status.pack(fill="x")

def on_click(e):
    canvas.create_oval(e.x - 4, e.y - 4, e.x + 4, e.y + 4, fill="red")

def on_drag(e):
    status.config(text=f"drag {e.x},{e.y}")

canvas.bind("<Button-1>", on_click)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<Double-Button-1>", lambda e: canvas.delete("all"))
canvas.bind("<Enter>", lambda e: canvas.config(cursor="crosshair"))
canvas.bind("<Configure>",
            lambda e: status.config(text=f"size {e.width}×{e.height}"))
root.bind("<Control-s>", lambda e: print("save"))
root.bind("<Escape>", lambda e: root.destroy())
root.bind("<Key>", lambda e: print("key", e.keysym), add="+")
canvas.unbind("<B1-Motion>")          # remove a binding
root.mainloop()

Code Explained

<Button-1> handler draws a dot at the click position
<B1-Motion> = mouse moved while button 1 held
<Configure> reports the new size on every resize
Shortcuts bound on root work wherever focus is in that window
add="+" keeps any existing <Key> handler

Mouse Events

SequenceWhen
<Button-1>Left press
<ButtonRelease-1>Left release
<Double-Button-1>Double-click
<B1-Motion>Drag with left
<Button-3>Right click (Win/X11)

Keyboard Events

SequenceWhen
<Key>Any key press
<Return>Enter key
<Escape>Esc
<Control-s>Ctrl+S
<F1>F1 key

Window Events

SequenceWhen
<Configure>Resized / moved
<Enter> / <Leave>Pointer in / out
<FocusIn>Gains focus
<Map> / <Unmap>Shown / hidden
<Destroy>Being destroyed

⚠ Common Mistakes

  • Handler without an event parameter (TypeError on trigger)
  • Binding <Control-S> and wondering why Ctrl+S does nothing
  • Binding keys to a widget that never gets focus

✓ Tips & Best Practices

  • Bind app shortcuts on the root or with bind_all
  • Use def handler(event=None) to share with command=
  • Check e.widget when one handler serves many widgets

Quick Summary

  • bind("<Sequence>", handler)
  • Handlers take one event argument
  • <Modifier-Type-Detail> syntax
  • unbind and add="+" manage handlers
