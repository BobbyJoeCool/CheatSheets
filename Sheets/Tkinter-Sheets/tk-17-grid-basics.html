Rows and Columns with grid()

grid() places widgets in a table of rows and columns inside their parent. Rows and columns are created on demand and size themselves to the largest widget they hold. A widget can span several cells with columnspan/rowspan. Inside its cell, a widget is centered unless sticky pins it to edges using compass letters: "w" aligns left, "ew" stretches horizontally, "nsew" fills the cell. grid is the go-to manager for forms and anything aligned in columns.

Notes

  • Empty rows/columns take no space
  • Row and column numbers needn't be consecutive
  • grid_remove() hides but remembers options; grid_forget() doesn't
  • sticky only stretches within the cell, not the cell itself
  • Cell growth needs columnconfigure/rowconfigure (Sheet 18)

A Classic Form

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
form = ttk.Frame(root, padding=10)
form.grid(row=0, column=0, sticky="nsew")

fields = ["First name", "Last name", "Email"]
entries = {}
for r, label in enumerate(fields):
    ttk.Label(form, text=label + ":").grid(row=r, column=0,
                                           sticky="e", padx=(0, 6), pady=3)
    e = ttk.Entry(form, width=30)
    e.grid(row=r, column=1, sticky="ew", pady=3)
    entries[label] = e

ttk.Label(form, text="Notes:").grid(row=3, column=0, sticky="ne", pady=3)
tk.Text(form, width=30, height=4).grid(row=3, column=1, pady=3)

buttons = ttk.Frame(form)
buttons.grid(row=4, column=0, columnspan=2, sticky="e", pady=(8, 0))
ttk.Button(buttons, text="Cancel").grid(row=0, column=0, padx=4)
ttk.Button(buttons, text="Save").grid(row=0, column=1)

entries["Email"].grid_remove()       # hide…
entries["Email"].grid()              # …and restore with old options
root.mainloop()

Code Explained

Labels in column 0 align right with sticky="e"
Entries fill their cell width with sticky="ew"
sticky="ne" keeps the Notes label at the top of its tall row
A nested Frame spanning both columns holds the buttons
grid() with no args re-shows a grid_removed widget

⚠ Common Mistakes

  • Writing sticky="left"; it uses compass letters
  • Expecting sticky="ew" to widen a column with no weight
  • Calling .grid() inline and storing the None it returns

✓ Tips & Best Practices

  • Build forms in a loop over field names
  • Put button rows in their own Frame
  • Use grid_remove for widgets you toggle often

Quick Summary

  • Rows × columns, created on demand
  • columnspan/rowspan merge cells
  • sticky pins or stretches in the cell
  • Ideal for forms and aligned layouts
