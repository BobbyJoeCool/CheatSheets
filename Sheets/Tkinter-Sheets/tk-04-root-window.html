Configuring the Main Window

The root Tk() object is a window with its own set of window-manager (wm) methods. They control the title bar, size, position, size limits, icon and stacking. geometry() takes a string "WIDTHxHEIGHT+X+Y" where any part can be left out. Most of these calls are requests to the operating system's window manager, so results can vary slightly between Windows, macOS and Linux desktops.

Notes

  • All wm methods also exist on Toplevel windows
  • Sizes are in pixels; positions are from the screen's top-left
  • Without geometry(), the window sizes itself to fit its widgets
  • wm_title() is the long name for title()
  • Call with no arguments to read the current value

Root Window Setup

import tkinter as tk

root = tk.Tk()
root.title("Inventory Manager")
root.geometry("640x400+100+80")   # W x H + X + Y
root.minsize(400, 250)            # user can't shrink below this
root.maxsize(1200, 900)
root.resizable(True, False)       # width yes, height no

icon = tk.PhotoImage(file="app.png")
root.iconphoto(True, icon)        # True = default for all windows

root.attributes("-topmost", True) # keep above other windows
root.configure(bg="#1e1e2e")      # classic background color

print(root.title())               # 'Inventory Manager'
root.update_idletasks()
print(root.winfo_width(), root.winfo_height())

root.mainloop()

Code Explained

geometry() sets size and position in one string
minsize/maxsize bound manual resizing
resizable(width, height) takes two booleans
iconphoto(True, …) applies the icon to future Toplevels too
update_idletasks() makes winfo_* report real sizes

geometry() Strings

⚠ Common Mistakes

  • Writing geometry(640, 400); it takes one string
  • Reading winfo_width() before the window is drawn (returns 1)
  • Using .ico with iconphoto; it needs a PhotoImage

✓ Tips & Best Practices

  • Set minsize so layouts never collapse
  • Use iconbitmap('app.ico') on Windows for the taskbar icon
  • Keep a reference to the icon image object

Quick Summary

  • title, geometry, minsize, resizable
  • "WxH+X+Y" geometry strings
  • attributes() for topmost/alpha/fullscreen
  • wm calls are requests to the OS
