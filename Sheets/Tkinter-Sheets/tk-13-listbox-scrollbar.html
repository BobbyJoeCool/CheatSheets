Lists and Scrolling

A Listbox shows a list of strings the user can select from. Items are addressed by index (0-based) or "end", and curselection() returns a tuple of selected indices. selectmode controls single or multiple selection. Scrollbars connect in two directions: the widget's yscrollcommand is set to the scrollbar's set, and the scrollbar's command is set to the widget's yview. The same pairing works for Text, Canvas, Entry (horizontal) and Treeview.

Notes

  • listvariable links a StringVar holding a Tcl list
  • <<ListboxSelect>> fires when the selection changes
  • curselection() may be empty; always check
  • Selections are lost when focus moves unless exportselection=False
  • For columns or icons, use ttk.Treeview instead

Listbox with Scrollbar

import tkinter as tk
from tkinter import ttk

frame = ttk.Frame(tk.Tk(), padding=8)
frame.pack(fill="both", expand=True)

fruits = ["Apple", "Banana", "Cherry", "Date", "Elderberry",
          "Fig", "Grape", "Honeydew", "Kiwi", "Lemon"]
lb = tk.Listbox(frame, height=6, selectmode="extended",
                exportselection=False)
sb = ttk.Scrollbar(frame, orient="vertical", command=lb.yview)
lb.configure(yscrollcommand=sb.set)

lb.grid(row=0, column=0, sticky="nsew")
sb.grid(row=0, column=1, sticky="ns")
frame.rowconfigure(0, weight=1); frame.columnconfigure(0, weight=1)

lb.insert("end", *fruits)
lb.itemconfigure(0, foreground="red")
def on_select(event):
    print([lb.get(i) for i in lb.curselection()])
lb.bind("<<ListboxSelect>>", on_select)
lb.selection_set(2); lb.see(2)         # select and scroll to Cherry
lb.delete("end")                       # remove last item
frame.mainloop()

Code Explained

Scrollbar command → lb.yview scrolls the list
yscrollcommand → sb.set moves the scrollbar thumb
sticky="ns" stretches the scrollbar to full height
curselection() gives indices; get(i) gives text
selection_set + see select in code and scroll into view

⚠ Common Mistakes

  • Wiring only one direction, so the thumb never moves
  • Indexing curselection()[0] when nothing is selected
  • Losing the selection when clicking into another Entry

✓ Tips & Best Practices

  • Use grid with weights so the list grows with the window
  • Prefer ttk.Scrollbar for a native look
  • Use <<ListboxSelect>> instead of <Button-1>

Quick Summary

  • Listbox: index-based string list
  • curselection() → tuple of indices
  • selectmode for single vs multi
  • Scrollbars wire both directions
