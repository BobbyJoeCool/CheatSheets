Colors and Borders on Classic Widgets

Classic tk widgets accept colors as names ("red", "SteelBlue", around 750 X11 names) or hex strings "#rgb", "#rrggbb" (or 12-digit "#rrrrggggbbbb"). Platform-specific system colors such as "SystemButtonFace" (Windows) or "systemWindowBackgroundColor" (macOS) follow the OS theme. Borders come from relief and borderwidth, and the focus ring from highlightthickness/highlightcolor. ttk widgets ignore these options; style them instead (Sheet 34).

Notes

  • winfo_rgb(color) returns 16-bit (r, g, b) components
  • activebackground applies on hover for buttons
  • disabledforeground colors text in disabled widgets
  • selectbackground colors selected text in Entry/Text
  • Avoid relying on color alone to convey meaning

Reliefs, Colors and Highlights

import tkinter as tk

root = tk.Tk()
root.configure(bg="#eceff1")

reliefs = ("flat", "raised", "sunken", "groove", "ridge", "solid")
for i, r in enumerate(reliefs):
    tk.Label(root, text=r, relief=r, borderwidth=3, width=8,
             bg="white").grid(row=0, column=i, padx=4, pady=8)

btn = tk.Button(root, text="Hover me", bg="#1976d2", fg="white",
                activebackground="#0d47a1", activeforeground="white",
                relief="flat", padx=12, pady=4, cursor="hand2")
btn.grid(row=1, column=0, columnspan=3, pady=6)
entry = tk.Entry(root, highlightthickness=2, highlightcolor="#ff9800",
                 highlightbackground="#cfd8dc", selectbackground="#ffe0b2",
                 selectforeground="black", insertbackground="#ff9800")
entry.grid(row=1, column=3, columnspan=3)
def lighten(color, f=0.3):
    r, g, b = (v // 257 for v in root.winfo_rgb(color))
    r, g, b = (int(v + (255 - v) * f) for v in (r, g, b))
    return f"#{r:02x}{g:02x}{b:02x}"
print(lighten("SteelBlue"))          # '#7da7ca'
root.mainloop()

Code Explained

Six reliefs show the classic border styles
active* colors apply while the mouse is over the button
highlight* options style the Entry's focus ring
insertbackground sets the text cursor color
winfo_rgb converts any color spec to numbers

⚠ Common Mistakes

  • Setting bg on a macOS tk.Button (native buttons ignore it)
  • Using colors on ttk widgets instead of styles
  • Choosing text/background pairs with poor contrast

✓ Tips & Best Practices

  • Keep a palette dict and reference colors by role
  • Set highlightthickness=0 for flat, borderless designs
  • Use cursor="hand2" on clickable labels

Quick Summary

  • Names, #rgb, #rrggbb, system colors
  • relief + borderwidth for borders
  • highlight* for focus rings
  • Classic widgets only; ttk uses styles
