Multi-Line Text Editing

The Text widget edits many lines of text and is powerful enough to build a small editor. Positions are text indices written as "line.column" strings: lines start at 1, columns at 0, so the very start is "1.0". "end" is just after the last character, and Text always keeps an extra trailing newline there. Indices accept modifiers such as "insert linestart" or "end-1c". undo=True turns on the built-in undo stack.

Notes

  • get("1.0", "end-1c") drops the automatic final newline
  • state="disabled" makes Text read-only (also blocks insert)
  • Re-enable with state="normal" before changing a read-only Text
  • wrap can be "none", "char" or "word"
  • Attach a Scrollbar for long content (Sheet 13)

Insert, Read, Replace, Undo

import tkinter as tk

root = tk.Tk()
text = tk.Text(root, width=50, height=10, wrap="word",
               undo=True, font=("Consolas", 11))
text.pack(fill="both", expand=True)

text.insert("1.0", "Line one\nLine two\n")
text.insert("end", "Appended line")

content = text.get("1.0", "end-1c")      # everything, no extra \n
first = text.get("1.0", "1.end")         # 'Line one'
lines = int(text.index("end-1c").split(".")[0])

text.delete("2.0", "3.0")                # remove line 2
text.replace("1.5", "1.8", "ONE")        # 'Line ONE'
text.edit_separator()                    # mark an undo step

def log(msg):                            # read-only output pattern
    text.config(state="normal")
    text.insert("end", msg + "\n")
    text.see("end")
    text.config(state="disabled")

root.bind("<Control-z>", lambda e: text.edit_undo())
root.mainloop()

Code Explained

"1.0" is line 1, column 0: the first character
"end-1c" steps back over the trailing newline
index() converts any index to "line.col" form
replace() (Tk 8.6+) deletes and inserts in one step
see("end") scrolls so the newest line is visible

⚠ Common Mistakes

  • Using "0.0" or "1.1" as the start (it's "1.0")
  • Saving get("1.0", "end") and gaining a newline each time
  • Inserting into a disabled Text and wondering why nothing happens

✓ Tips & Best Practices

  • Track unsaved changes with <<Modified>> and edit_modified(False)
  • Use the disable/insert/re-disable pattern for log panes
  • Prefer wrap="word" for prose, "none" for code

Quick Summary

  • Indices are "line.column", from "1.0"
  • get, insert, delete, replace
  • "end-1c" excludes the trailing newline
  • undo=True enables edit_undo/edit_redo
