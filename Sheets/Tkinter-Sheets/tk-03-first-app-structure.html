Your First Application

Every Tkinter app follows the same shape: create one Tk() root window, build widgets with a parent (the master they live inside), place each one with a geometry manager, then call mainloop(). mainloop() blocks and processes events until the window closes. For anything past a demo, wrap the UI in a class, either subclassing tk.Tk for the app or ttk.Frame for a reusable panel, so widgets and callbacks share state through self.

Notes

  • Only one Tk() per program; extra windows use Toplevel
  • A widget isn't visible until a geometry manager places it
  • Code after mainloop() runs only after the window closes
  • root.destroy() closes the window and ends mainloop()
  • Keep references to widgets you need to read or update later

Class-Based App Skeleton

import tkinter as tk
from tkinter import ttk

class App(tk.Tk):
    def __init__(self):
        super().__init__()
        self.title("Greeter")
        self.geometry("300x120")

        self.name = tk.StringVar()
        ttk.Label(self, text="Name:").grid(row=0, column=0, padx=8, pady=8)
        ttk.Entry(self, textvariable=self.name).grid(row=0, column=1)
        ttk.Button(self, text="Greet", command=self.greet).grid(
            row=1, column=0, columnspan=2)
        self.out = ttk.Label(self)
        self.out.grid(row=2, column=0, columnspan=2, pady=8)

    def greet(self):
        self.out.config(text=f"Hello, {self.name.get() or 'world'}!")

if __name__ == "__main__":
    App().mainloop()

Code Explained

Subclassing tk.Tk makes the app object the root window
StringVar links the Entry text to Python
Widgets take the parent as their first argument (self)
command=self.greet passes the method, not its result
The __main__ guard lets the module be imported safely

⚠ Common Mistakes

  • Writing command=self.greet(), which calls it once at startup
  • Chaining x = ttk.Entry(...).grid(); x becomes None
  • Creating a second tk.Tk() instead of a Toplevel

✓ Tips & Best Practices

  • Create and place widgets on separate lines when you keep a reference
  • Put each screen in its own ttk.Frame subclass
  • Keep business logic out of callbacks so it can be tested

Quick Summary

  • One Tk() root per app
  • Create widget → place it → mainloop()
  • Subclass tk.Tk or ttk.Frame for structure
  • Pass callbacks without parentheses
