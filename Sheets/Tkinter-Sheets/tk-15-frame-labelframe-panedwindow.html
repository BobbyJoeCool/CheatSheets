Containers for Grouping

Container widgets group other widgets so they can be laid out and styled as one unit. A Frame is an invisible (or bordered) box. A LabelFrame adds a titled border, which suits form sections. A PanedWindow splits space between children with draggable sashes, like a file browser's sidebar. Containers are the key to good layouts: each Frame can use its own geometry manager independently of its parent, which is how complex screens are built from simple pieces.

Notes

  • padding= on ttk Frames adds inner space
  • Classic Frames use padx/pady, relief, borderwidth
  • PanedWindow children are added with add(), not pack/grid
  • A Frame shrinks to fit its children unless propagation is off
  • ttk.Panedwindow is the themed version (Sheet 38)

Frames, LabelFrame and Panes

import tkinter as tk
from tkinter import ttk

root = tk.Tk(); root.geometry("520x260")
panes = tk.PanedWindow(root, orient="horizontal", sashwidth=6,
                       sashrelief="raised")
panes.pack(fill="both", expand=True)

sidebar = ttk.Frame(panes, padding=6)
for name in ("Inbox", "Sent", "Archive"):
    ttk.Button(sidebar, text=name).pack(fill="x", pady=2)

main = ttk.Frame(panes, padding=8)
info = ttk.LabelFrame(main, text="Contact", padding=8)
info.pack(fill="x")
ttk.Label(info, text="Name").grid(row=0, column=0, sticky="w")
ttk.Entry(info).grid(row=0, column=1, sticky="ew", padx=4)
info.columnconfigure(1, weight=1)

box = tk.Frame(main, relief="sunken", borderwidth=2, height=60)
box.pack(fill="x", pady=8)
panes.add(sidebar, minsize=100)
panes.add(main, stretch="always")
root.mainloop()

Code Explained

The PanedWindow fills the window; sash is draggable
Sidebar Frame uses pack, the LabelFrame inside uses grid
columnconfigure(1, weight=1) lets the Entry stretch
relief="sunken" draws a classic inset border
add(…, minsize=100) keeps the sidebar from vanishing

⚠ Common Mistakes

  • Packing children into a PanedWindow instead of add()
  • Setting Frame width/height and seeing no effect (propagation)
  • Mixing pack and grid inside the same Frame

✓ Tips & Best Practices

  • One Frame per logical region of the screen
  • Use LabelFrames to group related form fields
  • Set minsize on panes the user shouldn't collapse

Quick Summary

  • Frame groups, LabelFrame adds a title
  • PanedWindow gives draggable splits
  • Each container has its own geometry manager
  • Nest frames to build complex layouts
