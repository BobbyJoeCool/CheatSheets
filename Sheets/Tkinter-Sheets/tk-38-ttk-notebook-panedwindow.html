Notebook & ttk.Panedwindow

ttk.Notebook · add() · select() · tab() · <<NotebookTabChanged>> · enable_traversal() · ttk.Panedwindow

Tabs and Split Panes

ttk.Notebook shows one child at a time behind a row of tabs. Each page is usually a Frame added with add(child, text=…). select() switches tabs, tab() reads or changes tab options, and <<NotebookTabChanged>> fires when the tab changes. enable_traversal() adds Ctrl+Tab navigation. ttk.Panedwindow is the themed splitter: add panes with add(child, weight=n) and users drag the sash between them.

Notes

  • Tabs can be identified by index, child widget or "current"
  • hide(tab) hides a tab; add() the same child to show it again
  • forget(tab) removes it entirely
  • state="disabled" greys out a tab
  • ttk.Panedwindow uses weight, not minsize/stretch

Settings Window with Tabs

import tkinter as tk
from tkinter import ttk

root = tk.Tk(); root.geometry("420x260")
nb = ttk.Notebook(root)
nb.pack(fill="both", expand=True, padx=6, pady=6)

general, advanced, about = (ttk.Frame(nb, padding=10) for _ in range(3))
nb.add(general, text="General", underline=0)
nb.add(advanced, text="Advanced", underline=0)
nb.add(about, text="About", state="disabled")
nb.enable_traversal()            # Ctrl+Tab, Alt+G, Alt+A

ttk.Checkbutton(general, text="Start at login").pack(anchor="w")
panes = ttk.Panedwindow(advanced, orient="horizontal")
panes.pack(fill="both", expand=True)
panes.add(ttk.Treeview(panes, show="tree"), weight=1)
panes.add(tk.Text(panes, width=20), weight=3)

def changed(event):
    i = nb.index("current")
    root.title(f"Settings — {nb.tab(i, 'text')}")

nb.bind("<<NotebookTabChanged>>", changed)
nb.select(advanced)              # open on Advanced
nb.tab(about, state="normal")    # enable later
root.mainloop()

Code Explained

Each tab's page is a padded Frame
underline plus enable_traversal() adds Alt shortcuts
A disabled tab is visible but not selectable
Pane weights 1:3 split extra width
index("current") + tab(i, "text") read the active tab

⚠ Common Mistakes

  • Packing pages into the Notebook instead of add()
  • Using select() return value as an index (it's a widget name)
  • Passing minsize= to ttk.Panedwindow panes

✓ Tips & Best Practices

  • Build each tab as its own Frame subclass
  • Load expensive tabs lazily on first <<NotebookTabChanged>>
  • Save sashpos in settings to restore layouts
