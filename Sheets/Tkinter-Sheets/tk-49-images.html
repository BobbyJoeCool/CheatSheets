Showing Images

tk.PhotoImage loads PNG and GIF (and PPM/PGM) natively; Tk 9.0 adds SVG support. It can scale by whole factors with zoom(n) and subsample(n), and set pixels with put(). For JPEG, smooth resizing or other formats, use Pillow: open with PIL.Image, process, then wrap with PIL.ImageTk.PhotoImage. Whatever you use, keep a reference to the image object. If it's only a local variable, Python frees it and the widget goes blank.

Notes

  • pip install pillow provides PIL.Image and PIL.ImageTk
  • compound="left" shows image and text together
  • PhotoImage(width=, height=) creates a blank canvas image
  • Animated GIF frames load with format="gif -index n"
  • Use Image.LANCZOS for high-quality downscaling

PhotoImage and Pillow

import tkinter as tk
from tkinter import ttk
from PIL import Image, ImageTk, ImageOps

root = tk.Tk()

icon = tk.PhotoImage(file="save.png")                 # native PNG
small = icon.subsample(2)                             # half size
ttk.Button(root, text="Save", image=small, compound="left").pack(pady=4)

pil = Image.open("photo.jpg")                         # JPEG via Pillow
pil = ImageOps.exif_transpose(pil)                    # respect rotation
pil.thumbnail((300, 200), Image.LANCZOS)              # fit, keep ratio
photo = ImageTk.PhotoImage(pil)
label = ttk.Label(root, image=photo); label.pack(padx=10, pady=10)
label.image = photo                                   # keep references!
root.images = [icon, small]
gray = ImageTk.PhotoImage(ImageOps.grayscale(pil))
label.bind("<Enter>", lambda e: label.configure(image=gray))
label.bind("<Leave>", lambda e: label.configure(image=photo)); label.gray = gray
dot = tk.PhotoImage(width=8, height=8)
dot.put("red", to=(0, 0, 8, 8))                       # solid red square
ttk.Label(root, image=dot, text=" Online", compound="left").pack()
root.dot = dot
root.mainloop()

Code Explained

subsample(2) keeps every 2nd pixel: half size
exif_transpose fixes sideways phone photos
thumbnail resizes in place, preserving aspect ratio
Attaching images to widgets keeps them alive
put(color, to=box) fills pixels on a blank image

⚠ Common Mistakes

  • Images vanishing because only a local variable held them
  • Loading JPEG with tk.PhotoImage (unsupported in Tk 8.6)
  • Creating images before Tk() exists

✓ Tips & Best Practices

  • Cache resized images instead of resizing on every redraw
  • Store icons in a dict on the app object
  • Use compound for toolbar buttons with labels

Quick Summary

  • PhotoImage: PNG/GIF natively
  • Pillow for JPEG and resizing
  • zoom/subsample scale by integers
  • Always keep a reference
