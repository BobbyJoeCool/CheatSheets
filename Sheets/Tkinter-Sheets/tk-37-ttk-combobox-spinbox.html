Combobox & ttk.Spinbox

ttk.Combobox · values · current() · state="readonly" · <<ComboboxSelected>> · ttk.Spinbox · ttk.Scale

Drop-downs and Spin Inputs

ttk.Combobox combines an Entry with a drop-down list from values. By default users can type anything; state="readonly" restricts them to the list, which suits fixed choices. Read the value with get() or a textvariable, the position with current(), and react with <<ComboboxSelected>>. ttk.Spinbox steps through a range or list with arrows, and ttk.Scale is a themed slider whose value is a float you round yourself.

Notes

  • values can be updated at any time with configure()
  • current(i) selects by index; current() returns it (-1 if none)
  • <<ComboboxSelected>> fires only on list picks, not typing
  • postcommand refreshes the list just before it opens
  • ttk.Spinbox fires <<Increment>> and <<Decrement>>

Country / State Picker

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
data = {"USA": ["California", "Texas", "Wisconsin"],
        "Canada": ["Ontario", "Quebec", "Alberta"]}

country = ttk.Combobox(root, values=list(data), state="readonly", width=18)
region = ttk.Combobox(root, state="readonly", width=18)
country.grid(row=0, column=0, padx=8, pady=6)
region.grid(row=0, column=1, padx=8)

def on_country(event):
    region.configure(values=data[country.get()])
    region.current(0)

country.bind("<<ComboboxSelected>>", on_country)
country.current(0); on_country(None)

qty = ttk.Spinbox(root, from_=1, to=20, width=5, wrap=True)
qty.set(1); qty.grid(row=1, column=0, sticky="w", padx=8)

zoom = tk.DoubleVar(value=100)
ttk.Scale(root, from_=25, to=400, variable=zoom,
          command=lambda v: zoom.set(round(float(v) / 25) * 25)
          ).grid(row=1, column=1, sticky="ew", padx=8)
ttk.Label(root, textvariable=zoom).grid(row=2, column=1)
root.mainloop()

Code Explained

readonly limits choices to values
Selecting a country reloads the region list
current(0) selects the first entry in code
Spinbox.set() sets the shown value
The Scale callback snaps the float to steps of 25

⚠ Common Mistakes

  • Binding <<ComboboxSelected>> and expecting typed input to fire it
  • Using current() result -1 as a valid index
  • Expecting ttk.Scale to support resolution

✓ Tips & Best Practices

  • Use readonly Comboboxes for enums and categories
  • Chain dependent Comboboxes with the selected event
  • Show a Scale's value in a Label for clarity

Quick Summary

  • Combobox: values, current(), readonly
  • <<ComboboxSelected>> on list picks
  • ttk.Spinbox: arrows over range/list
