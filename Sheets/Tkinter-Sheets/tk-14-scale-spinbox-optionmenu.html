Scale, Spinbox & OptionMenu

Scale · from_ · to · resolution · Spinbox · values · increment · OptionMenu

Numeric Sliders and Choosers

A Scale is a slider for numbers between from_ and to (note the trailing underscore, because from is a Python keyword). A Spinbox is an Entry with up/down arrows that steps through a numeric range or a fixed list of values. An OptionMenu is a classic drop-down built from a variable and a list of choices; ttk.Combobox (Sheet 37) is the modern alternative. All three can share a Tk variable so the current value is always one get() away.

Notes

  • Scale passes the new value as a string to its command
  • resolution sets the Scale step; tickinterval adds labels
  • Spinbox wrap=True loops past the ends
  • OptionMenu takes the default value and choices positionally
  • ttk.Scale has no resolution; round the value yourself

Volume, Quantity and Size

import tkinter as tk

root = tk.Tk()
vol = tk.DoubleVar(value=50)
qty = tk.IntVar(value=1)
size = tk.StringVar(value="Medium")

tk.Scale(root, from_=0, to=100, resolution=5, orient="horizontal",
         label="Volume", tickinterval=25, length=240,
         variable=vol, command=lambda v: print("vol", float(v))
         ).pack(padx=10, pady=4)
tk.Spinbox(root, from_=1, to=10, increment=1, width=5,
           textvariable=qty, wrap=True).pack(pady=4)

tk.Spinbox(root, values=("XS", "S", "M", "L", "XL"),
           state="readonly", width=6).pack(pady=4)

opts = ["Small", "Medium", "Large"]
menu = tk.OptionMenu(root, size, size.get(), *opts,
                     command=lambda v: print("size", v))
menu.config(width=10); menu.pack(pady=4)
def reset():
    vol.set(50); qty.set(1); size.set("Medium")
tk.Button(root, text="Reset", command=reset).pack(pady=6)
root.mainloop()

Code Explained

from_/to set the range; resolution=5 snaps to steps
command receives the value as text, so convert it
Spinbox with values= cycles through a fixed list
OptionMenu args: master, var, default, *choices
Setting each variable resets every linked widget

⚠ Common Mistakes

  • Writing from=0, a syntax error (use from_)
  • Doing math on the Scale callback value without float()
  • Passing the choices as one list to OptionMenu without *

✓ Tips & Best Practices

  • Show the live number in a Label via the same variable
  • Use readonly Spinboxes to prevent invalid typing
  • Prefer ttk.Combobox for long choice lists

Quick Summary

  • Scale: slider, from_/to/resolution
  • Spinbox: arrows over range or values
  • OptionMenu: classic drop-down
  • Share one Tk variable per value
