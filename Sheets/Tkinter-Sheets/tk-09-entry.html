Single-Line Text Input

An Entry holds one line of editable text. Read it with get(), and modify it with insert(index, text) and delete(first, last). Indices are character positions, or the names 0, "end" (also tk.END), "insert" (the cursor) and "sel.first"/"sel.last". Linking a StringVar through textvariable= is often cleaner than calling get(). show="*" masks passwords, and state="readonly" allows selecting and copying but not editing.

Notes

  • get() always returns a str; convert numbers yourself
  • delete(0, "end") clears the whole field
  • width is in average characters, not pixels
  • readonly keeps the text selectable; disabled doesn't
  • Validation on each keystroke is covered on Sheet 52

Reading, Editing and Masking

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
user = tk.StringVar(value="guest")

ttk.Label(root, text="User").grid(row=0, column=0, sticky="w")
name = ttk.Entry(root, textvariable=user, width=24)
name.grid(row=0, column=1, pady=4)

ttk.Label(root, text="Password").grid(row=1, column=0, sticky="w")
pw = ttk.Entry(root, show="•", width=24)
pw.grid(row=1, column=1, pady=4)

def submit(event=None):
    print(user.get(), len(pw.get()))
    pw.delete(0, "end")               # clear password field
    name.select_range(0, "end")       # highlight user name
    name.icursor("end")               # cursor to end
    name.focus_set()

pw.bind("<Return>", submit)
ttk.Button(root, text="Log in", command=submit).grid(row=2, column=1)
name.insert("end", "_01")             # 'guest_01'
root.mainloop()

Code Explained

textvariable keeps the Entry and user in sync
show="•" displays a mask character instead of the text
event=None lets one function serve both bind and command
select_range + icursor mimic native field behavior
insert("end", …) appends to the current text

⚠ Common Mistakes

  • Calling delete(0) and expecting the field to clear
  • Doing math on get() without int()/float()
  • Setting state="disabled" when users still need to copy

✓ Tips & Best Practices

  • Use a StringVar when several widgets show the same value
  • Bind <Return> to submit forms
  • Set exportselection=0 when many Entries share a window

Quick Summary

  • get, insert, delete(0, "end")
  • Indices: ints, "end", "insert", sel.*
  • show= masks, readonly locks editing
  • Link with textvariable=StringVar
