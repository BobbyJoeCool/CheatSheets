scrollregion · xview_moveto() · scale() · after() loop · frame timing · delete("all")

Large Drawings and Moving Pictures

A canvas can be bigger than its window. Set scrollregion to the drawing's extent (often bbox("all")) and connect scrollbars with xview/yview, exactly as with a Listbox. scale(tag, x, y, sx, sy) zooms items around a point (it scales coordinates, not line widths or fonts). Animation means updating item positions on a timer: a function moves things, then reschedules itself with after(ms, func). Never animate with while True + time.sleep, which freezes the window.

Notes

  • About 16 ms per frame ≈ 60 fps; 33 ms ≈ 30 fps
  • after_cancel(id) stops a scheduled frame
  • xview_moveto(0) jumps to the left edge
  • Mouse wheel scrolling needs your own bindings
  • For heavy graphics, consider Pygame or OpenGL instead

Bouncing Ball on a Scrollable Canvas

import tkinter as tk
root = tk.Tk()
W, H = 800, 600                                   # world size
c = tk.Canvas(root, width=400, height=300, bg="black",
              scrollregion=(0, 0, W, H))
hs = tk.Scrollbar(root, orient="horizontal", command=c.xview)
vs = tk.Scrollbar(root, orient="vertical", command=c.yview)
c.configure(xscrollcommand=hs.set, yscrollcommand=vs.set)
c.grid(row=0, column=0); vs.grid(row=0, column=1, sticky="ns")
hs.grid(row=1, column=0, sticky="ew")
ball = c.create_oval(10, 10, 40, 40, fill="orange")
vel = [4, 3]
def frame():
    x1, y1, x2, y2 = c.coords(ball)
    if x1 + vel[0] < 0 or x2 + vel[0] > W: vel[0] = -vel[0]
    if y1 + vel[1] < 0 or y2 + vel[1] > H: vel[1] = -vel[1]
    c.move(ball, *vel)
    root.anim = root.after(16, frame)            # ~60 fps
def zoom(factor):
    c.scale("all", 0, 0, factor, factor)
    c.configure(scrollregion=c.bbox("all"))
root.bind("+", lambda e: zoom(1.25)); root.bind("-", lambda e: zoom(0.8))
root.bind("<space>", lambda e: root.after_cancel(root.anim))
frame()
root.mainloop()

Code Explained

scrollregion defines the full 800×600 world
Scrollbars wire to xview/yview both ways
Each frame bounces off world edges, then moves
after(16, frame) schedules the next frame
scale() zooms; scrollregion is updated to match

⚠ Common Mistakes

  • Animating with time.sleep in a loop
  • Forgetting to update scrollregion after zooming
  • Starting several after loops by calling frame() twice

✓ Tips & Best Practices

  • Keep the after id so you can pause and resume
  • Move items instead of deleting and recreating them
  • Base movement on elapsed time for steady speed

Quick Summary

  • scrollregion + scrollbars for big drawings
  • scale() zooms coordinates
  • Animate with after() loops
  • Never block with sleep
