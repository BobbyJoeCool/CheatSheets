Embedding Matplotlib & Add-ons

FigureCanvasTkAgg · NavigationToolbar2Tk · draw() · tkcalendar · tkinterdnd2 · Pillow

Charts and Popular Add-ons

Matplotlib plots embed in Tkinter through FigureCanvasTkAgg, which turns a Figure into a Tk widget, plus an optional NavigationToolbar2Tk for zoom and pan. Create the figure with matplotlib.figure.Figure rather than pyplot, so no extra window or global state is created. Other widely used add-ons fill gaps in Tk: tkcalendar (date pickers), tkinterdnd2 (drag files in from the OS) and Pillow (image formats, Sheet 49).

Notes

  • Call canvas.draw() (or draw_idle()) after changing plots
  • pack_toolbar=False lets you grid the toolbar yourself
  • mpl_connect handles clicks and hovers on the plot
  • tkinterdnd2 needs its own root: TkinterDnD.Tk()
  • get_date() from tkcalendar returns a datetime.date

Live Plot, Date Picker, File Drop

import tkinter as tk
from matplotlib.figure import Figure
from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg, NavigationToolbar2Tk
from tkcalendar import DateEntry
from tkinterdnd2 import TkinterDnD, DND_FILES

root = TkinterDnD.Tk()                     # Tk root with drag-and-drop
fig = Figure(figsize=(5, 3), dpi=100)
ax = fig.add_subplot()
line, = ax.plot([1, 2, 3, 4], [3, 1, 4, 2], marker="o")
canvas = FigureCanvasTkAgg(fig, master=root)
canvas.get_tk_widget().pack(fill="both", expand=True)
NavigationToolbar2Tk(canvas, root).update()

def add_point():
    xs, ys = list(line.get_xdata()), list(line.get_ydata())
    line.set_data(xs + [xs[-1] + 1], ys + [ys[-1] + 1])
    ax.relim(); ax.autoscale_view(); canvas.draw_idle()
tk.Button(root, text="Add point", command=add_point).pack()
when = DateEntry(root, date_pattern="yyyy-mm-dd"); when.pack(pady=4)
when.bind("<<DateEntrySelected>>", lambda e: print(when.get_date()))
drop = tk.Label(root, text="Drop files here", relief="groove", height=3)
drop.pack(fill="x", padx=8, pady=8)
drop.drop_target_register(DND_FILES)
drop.dnd_bind("<<Drop>>", lambda e: print(root.tk.splitlist(e.data)))
root.mainloop()

Code Explained

Figure + FigureCanvasTkAgg = plot as a Tk widget
The toolbar adds zoom, pan and save buttons
relim/autoscale_view refit axes after new data
DateEntry is a drop-down calendar field
splitlist splits dropped paths safely (spaces in braces)

⚠ Common Mistakes

  • Using plt.figure() and getting a second window
  • Changing data without calling draw()/draw_idle()
  • Splitting dropped paths on spaces

✓ Tips & Best Practices

  • Reuse one Figure and update data instead of recreating
  • Use draw_idle for frequent updates
  • Check each add-on's license before shipping

Quick Summary

  • FigureCanvasTkAgg embeds Matplotlib
  • Use Figure, not pyplot
  • tkcalendar for dates, tkinterdnd2 for drops
  • Pillow for images
