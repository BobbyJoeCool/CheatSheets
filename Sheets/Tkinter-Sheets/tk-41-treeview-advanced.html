Treeview — Selection, Tags & Sorting

selection() · <<TreeviewSelect>> · tag_configure() · parent/child items · sort on heading click · see() · move()

Working with Treeview Data

Treeview selections are item ids: selection() returns the selected ids, and <<TreeviewSelect>> fires when it changes. focus() gives the item with keyboard focus. For hierarchies, pass a parent id to insert(), open or close nodes with item(iid, open=True), and react to <<TreeviewOpen>> to lazy-load children. Tags style rows (striping, highlighting) and can receive events via tag_bind(). Sorting isn't built in; reorder rows with move() from a heading's command.

Notes

  • selectmode: extended (default), browse, none
  • see(iid) scrolls an item into view
  • identify_row(y) finds the row under the mouse
  • parent(iid) and next(iid) navigate the tree
  • Tag colors need the clam-style themes on some platforms

Sortable, Striped, Hierarchical

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
tree = ttk.Treeview(root, columns=("size",)); tree.pack(fill="both", expand=True)
tree.heading("#0", text="Name")
tree.tag_configure("odd", background="#f3f3f8")
tree.tag_configure("big", foreground="#c62828")

docs = tree.insert("", "end", text="Documents", open=True)
for i, (name, kb) in enumerate([("cv.pdf", 120), ("video.mp4", 9800),
                                ("notes.txt", 4)]):
    tags = (("odd",) if i % 2 else ()) + (("big",) if kb > 1000 else ())
    tree.insert(docs, "end", text=name, values=(kb,), tags=tags)

def sort_by(col, reverse=False):
    for parent in ("",) + tree.get_children(""):
        kids = list(tree.get_children(parent))
        kids.sort(key=lambda k: float(tree.set(k, col) or 0), reverse=reverse)
        for idx, k in enumerate(kids):
            tree.move(k, parent, idx)
    tree.heading(col, command=lambda: sort_by(col, not reverse))

tree.heading("size", text="KB", command=lambda: sort_by("size"))
tree.bind("<<TreeviewSelect>>",
          lambda e: print([tree.item(i, "text") for i in tree.selection()]))
tree.bind("<Double-1>", lambda e: print("open", tree.identify_row(e.y)))
root.mainloop()

Code Explained

#0 is the tree column; its header is set like any other
Children are inserted under the docs parent id
Tags combine: striping plus a red highlight for big files
move() reorders rows; the heading toggles sort direction
identify_row(e.y) maps a click to an item id

⚠ Common Mistakes

  • Treating selection() results as row values
  • Sorting with string comparison ("100" < "9")
  • Loading huge trees up front instead of lazily

✓ Tips & Best Practices

  • Lazy-load children on <<TreeviewOpen>> with a dummy child
  • Re-apply stripe tags after sorting
  • Keep a dict mapping iid → your data object

Quick Summary

  • selection() returns item ids
  • Parents make hierarchies; open= expands
  • Tags style and bind rows
  • Sort via move() in heading commands
