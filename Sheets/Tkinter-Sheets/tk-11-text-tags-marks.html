Text Widget — Tags, Marks & Search

tag_configure() · tag_add() · tag_bind() · mark_set() · INSERT · see() · search() · window_create()

Formatting and Finding Text

Tags are named styles applied to ranges of a Text widget: configure a tag's look once with tag_configure(), then attach it to ranges with tag_add() or as an extra argument to insert(). Tags can also receive events through tag_bind(), which is how clickable links are made. Marks are named positions that float with edits; "insert" and "current" are built-in marks. search() finds text (optionally with regex) and returns the index of the match.

Notes

  • The "sel" tag is the user's selection
  • Later-created tags win when styles overlap; reorder with tag_raise()
  • Marks have gravity: "right" (default) or "left"
  • search() returns "" when nothing matches
  • window_create() embeds a widget inside the text

Highlight, Link and Search

import tkinter as tk, webbrowser

text = tk.Text(width=60, height=12); text.pack()
text.tag_configure("h1", font=("Helvetica", 16, "bold"))
text.tag_configure("hit", background="yellow")
text.tag_configure("link", foreground="blue", underline=True)

text.insert("end", "Report\n", "h1")
text.insert("end", "See the docs for details. More docs here.\n")
text.insert("end", "tkdocs.com", ("link",))
text.tag_bind("link", "<Button-1>",
              lambda e: webbrowser.open("https://tkdocs.com"))

def highlight(word):
    text.tag_remove("hit", "1.0", "end")
    start = "1.0"
    while True:
        count = tk.IntVar()
        pos = text.search(word, start, "end", nocase=True, count=count)
        if not pos: break
        end = f"{pos}+{count.get()}c"
        text.tag_add("hit", pos, end)
        start = end

highlight("docs"); text.mark_set("insert", "2.0")
text.mainloop()

Code Explained

Third insert argument applies one or more tags
tag_bind makes tagged text respond to clicks
search(..., count=var) reports the match length
Loop from the end of each match to find the next
mark_set("insert", …) moves the cursor

⚠ Common Mistakes

  • Forgetting "end" as stopindex, so search wraps forever
  • Passing a tag string where a tuple is needed in loops
  • Expecting Python regex syntax; regexp=True uses Tcl's

✓ Tips & Best Practices

  • Clear old highlights with tag_remove before re-searching
  • Use tags for syntax highlighting and log levels
  • Change the "current" cursor on <Enter> of link tags

Quick Summary

  • Tags = named styles on ranges
  • tag_bind for clickable text
  • Marks = floating positions (insert, current)
  • search() returns an index or ""
