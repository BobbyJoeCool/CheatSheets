Custom Modal Dialogs

Toplevel · transient() · grab_set() · wait_window() · returning a result · <Escape> to cancel · centering on parent

Writing Your Own Modal Dialog

A modal dialog blocks the rest of the app until it closes. Build one from a Toplevel with four steps: transient(parent) to keep it above its parent, grab_set() to route all input to it, wait_window() to pause the caller until it's destroyed, and a result attribute the caller reads afterward. Bind <Return> to OK and <Escape> to Cancel, route the close button through protocol(), and center the dialog on its parent so it appears where the user is looking.

Notes

  • wait_window() keeps processing events (not frozen)
  • grab_set() may fail before the window is visible; call wait_visibility() first on X11
  • Release grabs automatically by destroying the dialog
  • Store the result before destroy()
  • A simpledialog.Dialog subclass does most of this for you

Reusable Modal Dialog

import tkinter as tk
from tkinter import ttk

class RenameDialog(tk.Toplevel):
    def __init__(self, parent, old_name):
        super().__init__(parent)
        self.title("Rename"); self.result = None
        self.transient(parent)
        self.var = tk.StringVar(value=old_name)
        e = ttk.Entry(self, textvariable=self.var, width=30)
        e.pack(padx=12, pady=12); e.select_range(0, "end"); e.focus_set()
        ttk.Button(self, text="OK", command=self.ok).pack(side="left", padx=12)
        ttk.Button(self, text="Cancel", command=self.destroy).pack(side="right", padx=12)
        self.bind("<Return>", lambda e: self.ok())
        self.bind("<Escape>", lambda e: self.destroy())
        self.update_idletasks()                      # center on parent
        x = parent.winfo_rootx() + (parent.winfo_width() - self.winfo_width()) // 2
        y = parent.winfo_rooty() + (parent.winfo_height() - self.winfo_height()) // 3
        self.geometry(f"+{x}+{y}")
        self.wait_visibility(); self.grab_set()
        self.wait_window()                           # block until closed
    def ok(self):
        self.result = self.var.get().strip() or None
        self.destroy()
# usage: name = RenameDialog(root, "report.txt").result

Code Explained

transient + grab_set = classic modal behavior
Entry text is pre-selected so typing replaces it
Enter and Escape map to OK and Cancel
Geometry is computed from the parent's position
wait_window() returns after destroy(), then .result is read

⚠ Common Mistakes

  • Forgetting grab_set(), so users click the main window
  • Reading .result before wait_window() returns
  • Using grab_set_global(), which locks the whole desktop

✓ Tips & Best Practices

  • Return None for Cancel, a value for OK
  • Wrap the pattern in a base class for all your dialogs
  • Keep dialogs non-resizable unless content needs it

Quick Summary

  • Toplevel + transient + grab_set + wait_window
  • Enter = OK, Escape = Cancel
  • Center on the parent window
  • Caller reads dialog.result
