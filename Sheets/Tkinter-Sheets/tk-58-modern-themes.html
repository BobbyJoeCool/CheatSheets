Modern Looks with Theme Packages

Two popular packages give ttk apps a modern look with almost no code changes. sv-ttk (Sun Valley) applies a Windows 11-style light or dark theme with one call, plus extra styles like Accent.TButton and Switch.TCheckbutton. ttkbootstrap brings more than 20 Bootstrap-inspired themes, a bootstyle= keyword for color roles (success, danger-outline…) and extra widgets such as Meter, DateEntry, Floodgauge and Tableview. Both are on PyPI: pip install sv-ttk ttkbootstrap.

Notes

  • Both work with regular ttk widgets and layouts
  • Pick one theme package per app; don't mix them
  • ttkbootstrap's Window replaces tk.Tk()
  • ttkbootstrap can also be used as import ttkbootstrap as ttk
  • Classic tk widgets aren't themed by either

sv-ttk and ttkbootstrap

# Two separate examples: pick ONE theme package per app
# --- sv-ttk: one call on a normal Tk app ---------------------------
import tkinter as tk
from tkinter import ttk
import sv_ttk

root = tk.Tk()
ttk.Button(root, text="Save", style="Accent.TButton").pack(pady=6)
ttk.Checkbutton(root, text="Dark mode", style="Switch.TCheckbutton",
                command=sv_ttk.toggle_theme).pack(pady=6)
sv_ttk.set_theme("dark")                 # or "light"; get_theme()

# --- ttkbootstrap: its own Window and bootstyle keyword ------------
import ttkbootstrap as tb
from ttkbootstrap.constants import SUCCESS, DANGER
app = tb.Window(themename="darkly", title="Dashboard")
tb.Button(app, text="Deploy", bootstyle=SUCCESS).pack(side="left", padx=8)
tb.Button(app, text="Delete", bootstyle=(DANGER, "outline")).pack(side="left")
tb.Meter(app, amountused=72, subtext="CPU", bootstyle="info",
         interactive=True).pack(pady=10)
tb.DateEntry(app, dateformat="%Y-%m-%d").pack()
tb.Progressbar(app, value=40, bootstyle="striped").pack(fill="x", padx=8)
app.style.theme_use("flatly")            # switch themes at runtime
print(app.style.theme_names())           # all ttkbootstrap themes
app.mainloop()

Code Explained

sv-ttk restyles every ttk widget on the root
Accent.TButton and Switch.TCheckbutton are sv-ttk styles
tb.Window creates the root with a theme
bootstyle sets the color role and variant
Meter and DateEntry are ttkbootstrap-only widgets

⚠ Common Mistakes

  • Calling sv_ttk.set_theme() before creating Tk()
  • Creating both tk.Tk() and tb.Window()
  • Expecting classic tk.Button to pick up the theme

✓ Tips & Best Practices

  • Use sv-ttk for a native Windows 11 look
  • Use ttkbootstrap for dashboards and colorful UIs
  • Respect the OS dark mode setting with a toggle

Quick Summary

  • sv-ttk: set_theme("dark")
  • ttkbootstrap: Window(themename=…)
  • bootstyle= for color roles
  • Extra widgets: Meter, DateEntry, Tableview
