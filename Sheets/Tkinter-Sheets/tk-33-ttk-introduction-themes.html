Themed Widgets and Themes

tkinter.ttk provides themed versions of most widgets plus several new ones (Combobox, Notebook, Progressbar, Treeview, Separator, Sizegrip). Their look comes from the active theme rather than per-widget color options, so the same code looks native on Windows (vista), macOS (aqua) and gets a clean cross-platform look with clam. ttk.Style().theme_use() reads or switches the theme for the whole app at once. Appearance changes go through styles (Sheet 34).

Notes

  • Importing ttk doesn't replace tk widgets; use ttk. explicitly
  • from tkinter.ttk import * after from tkinter import * shadows tk widgets
  • Linux defaults to default; clam usually looks better
  • Theme changes apply instantly to existing widgets
  • No ttk version of Text, Canvas, Listbox, Menu or Toplevel

Listing and Switching Themes

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
style = ttk.Style(root)
print(style.theme_names())   # ('winnative','clam','alt','default','classic','vista','xpnative')
print(style.theme_use())     # current theme, e.g. 'vista'

theme = tk.StringVar(value=style.theme_use())
box = ttk.Combobox(root, values=style.theme_names(),
                   textvariable=theme, state="readonly")
box.pack(padx=10, pady=10)
box.bind("<<ComboboxSelected>>", lambda e: style.theme_use(theme.get()))

ttk.Button(root, text="ttk.Button").pack(pady=4)
ttk.Checkbutton(root, text="ttk.Checkbutton").pack(pady=4)
ttk.Entry(root).pack(pady=4)
ttk.Progressbar(root, value=60, length=160).pack(pady=4)
tk.Button(root, text="classic tk.Button").pack(pady=4)  # unaffected

if root.tk.call("tk", "windowingsystem") == "x11":
    style.theme_use("clam")      # nicer default on Linux
root.mainloop()

Code Explained

theme_names() lists themes available on this platform
theme_use() with no argument returns the current theme
Choosing a theme restyles every ttk widget immediately
Classic tk.Button ignores ttk themes
Switch Linux apps to clam for a modern flat look

⚠ Common Mistakes

  • Wildcard-importing tkinter and ttk in the wrong order
  • Setting bg=/fg= on ttk widgets
  • Hard-coding vista and crashing on macOS/Linux

✓ Tips & Best Practices

  • Use ttk for every widget it offers
  • Check theme_names() before calling theme_use()
  • Pick clam when you need consistent custom colors

Quick Summary
