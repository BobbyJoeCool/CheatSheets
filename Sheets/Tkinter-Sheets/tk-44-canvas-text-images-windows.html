Text, Images and Widgets on a Canvas

Besides shapes, a canvas can hold text items (create_text), images (create_image with a PhotoImage) and real widgets (create_window). For all three, anchor says which point of the item sits on the given coordinate: "center" by default, "nw" for top-left. bbox(item) returns the bounding box (x1, y1, x2, y2) of any item or tag, which is how you size a background behind text or check whether things overlap.

Notes

  • Text items support width= for wrapping and justify=
  • Keep a Python reference to images or they disappear
  • Embedded widgets always draw above other canvas items
  • itemcget(id, "text") reads a text item's string
  • Canvas text can be edited with dchars()/insert()

Labelled Card with Image and Button

import tkinter as tk

root = tk.Tk()
c = tk.Canvas(root, width=320, height=200, bg="#263238",
              highlightthickness=0)
c.pack()

img = tk.PhotoImage(file="avatar.png").subsample(2)
c.image = img                                   # keep a reference
c.create_image(20, 20, image=img, anchor="nw", tags="card")

title = c.create_text(110, 30, text="Ada Lovelace", anchor="nw",
                      fill="white", font=("Helvetica", 14, "bold"))
c.create_text(110, 60, anchor="nw", width=190, fill="#b0bec5",
              text="Wrote the first published algorithm for a machine.")

x1, y1, x2, y2 = c.bbox(title)                  # box around the name
bg = c.create_rectangle(x1 - 4, y1 - 2, x2 + 4, y2 + 2, fill="#37474f",
                        outline="")
c.tag_lower(bg, title)                          # put it behind the text

btn = tk.Button(c, text="Follow", command=lambda: print("followed"))
c.create_window(300, 180, window=btn, anchor="se")

print(c.itemcget(title, "text"))                # 'Ada Lovelace'
root.mainloop()

Code Explained

anchor="nw" places the image's top-left at (20, 20)
Storing img on the canvas prevents garbage collection
width=190 wraps the description text
bbox + tag_lower creates a highlight behind text
create_window embeds a real Button at the corner

⚠ Common Mistakes

  • Creating a PhotoImage in a function and losing it
  • Expecting canvas items to draw over embedded widgets
  • Using x/y of text as its top-left without anchor="nw"

✓ Tips & Best Practices

  • Use anchor="nw" for layout-style positioning
  • Measure text with bbox before placing neighbors
  • Embed forms with create_window inside scrollable canvases

Quick Summary

  • create_text, create_image, create_window
  • anchor picks the reference point
  • bbox() measures items
  • Keep image references alive
