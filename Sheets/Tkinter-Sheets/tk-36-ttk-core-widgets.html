ttk Basics and Widget State

Core ttk widgets (Button, Label, Entry, Checkbutton, Radiobutton, Frame, Scale, Scrollbar) work like their classic counterparts but share a common state system. Each widget has a set of state flags (disabled, focus, pressed, selected, readonly, invalid, alternate…). state(["disabled"]) sets flags, state(["!disabled"]) clears them, and instate(["selected"]) tests them. Styles map their looks to these same flags.

Notes

  • state() with no args returns current flags
  • configure(state="disabled") still works on most ttk widgets
  • invalid is set by validation and can be styled
  • padding is a ttk option on many widgets
  • Classic-only options (bg, relief) raise TclError

Toggling and Testing State

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
frm = ttk.Frame(root, padding=12); frm.pack()

agree = tk.BooleanVar()
name = ttk.Entry(frm, width=24)
check = ttk.Checkbutton(frm, text="I agree", variable=agree)
submit = ttk.Button(frm, text="Submit")
name.grid(row=0, column=0, pady=4)
check.grid(row=1, column=0, sticky="w")
submit.grid(row=2, column=0, pady=6)

def refresh(*_):
    ok = agree.get() and name.get().strip()
    submit.state(["!disabled"] if ok else ["disabled"])
    name.state(["!invalid"] if name.get().strip() else ["invalid"])

agree.trace_add("write", refresh)
name.bind("<KeyRelease>", refresh)
refresh()

ttk.Style().map("TEntry", fieldbackground=[("invalid", "#ffe0e0")])
print(submit.state())                 # ('disabled',)
print(check.instate(["selected"]))    # False
check.state(["alternate"])            # tri-state "mixed" look
root.mainloop()

Code Explained

state(["disabled"]) / ["!disabled"] toggle a flag
Submit is enabled only when both conditions hold
invalid flag plus a style map tints the Entry
instate() returns a bool for a flag test
alternate shows a Checkbutton as partially checked

⚠ Common Mistakes

  • Passing a string instead of a list: state("disabled")
  • Mixing configure(state=…) and state() inconsistently
  • Expecting instate to return the flag list

✓ Tips & Best Practices

  • Drive enabled/disabled from one refresh() function
  • Style the invalid state for validation feedback
  • Use alternate for "some selected" parent checkboxes

Quick Summary

  • Shared state flags across ttk
  • state([...]) sets/clears with !
  • instate([...]) tests
  • Styles map looks to states
