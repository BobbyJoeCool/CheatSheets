Events, Methods and Helpers

The second quick reference covers what happens after widgets exist: binding events, reading the event object, scheduling with after(), querying geometry with winfo_*, standard dialogs and control variables. These calls make up most of the glue code in a Tkinter app. Keep callbacks short, move slow work off the main thread (Sheet 51), and remember that Tk is single-threaded: only the main thread may touch widgets.

Notes

  • Handlers from bind() take one event argument
  • command= callbacks take none
  • after() returns an id for after_cancel()
  • Dialogs return None/"" when cancelled
  • Detailed pages: events 21–26, dialogs 29–32, timers 50

Glue Code Cheat Codes

w.bind("<Button-1>", lambda e: print(e.x, e.y))     # widget binding
root.bind_all("<Control-s>", save)                  # app-wide shortcut
w.event_generate("<<Refresh>>")                     # fire virtual event

var = tk.StringVar(value="x"); var.trace_add("write", lambda *a: ...)
job = root.after(500, tick); root.after_cancel(job)

w.winfo_width(); w.winfo_height()                   # size (after layout)
w.winfo_rootx(); w.winfo_rooty()                    # screen position
w.winfo_children(); w.winfo_toplevel(); w.winfo_exists()
root.update_idletasks()                             # finish layout now

from tkinter import messagebox, filedialog, simpledialog
messagebox.askyesno("Quit?", "Really quit?", parent=root)   # True/False
filedialog.askopenfilename(filetypes=[("Text", "*.txt")])   # "" on cancel
simpledialog.askinteger("Age", "Age?", minvalue=0)          # None on cancel

root.clipboard_clear(); root.clipboard_append("copied")
text = root.clipboard_get()
root.protocol("WM_DELETE_WINDOW", on_close)
w.focus_set(); w.lift(); w.destroy()

Code Explained

Bindings: widget, app-wide and virtual events
Variables and timers are the main state tools
winfo_* queries need layout done first
Standard dialogs return values or cancel markers
Clipboard, close handling and focus helpers

⚠ Common Mistakes

  • Touching widgets from worker threads
  • Blocking the loop with sleep or long loops
  • Reading winfo_* before the window is drawn

✓ Tips & Best Practices

  • Bind shortcuts once on the root
  • Use virtual events to decouple parts of the app
  • Wrap dialogs in helpers that pass parent=
