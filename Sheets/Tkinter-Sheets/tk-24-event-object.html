The Event Object

event.widget · event.x/y · x_root/y_root · keysym · char · delta · state · width/height

What the Event Tells You

Every bound handler receives an Event object describing what happened. Which attributes are meaningful depends on the event type: mouse events fill x/y (relative to the widget) and x_root/y_root (relative to the screen); key events fill keysym (a name like "Return"), char (the typed character, possibly empty) and keycode; <Configure> fills width/height; <MouseWheel> fills delta. event.widget always names the widget that received the event.

Notes

  • Unused attributes hold ?? or 0
  • char is "" for keys like Shift or arrows
  • keysym is reliable across keyboard layouts
  • state is a bitmask of held modifiers
  • delta is ±120 per notch on Windows, small values on macOS

Inspecting Events

import tkinter as tk

root = tk.Tk()
out = tk.Label(root, width=48, anchor="w", font=("Consolas", 10))
out.pack(fill="x")
area = tk.Frame(root, width=320, height=160, bg="#eef")
area.pack(fill="both", expand=True)

def show(e):
    out.config(text=f"{e.type}: x={e.x} y={e.y} "
                    f"root=({e.x_root},{e.y_root}) num={e.num}")

def key(e):
    shift = bool(e.state & 0x0001)
    ctrl = bool(e.state & 0x0004)
    out.config(text=f"keysym={e.keysym!r} char={e.char!r} "
                    f"shift={shift} ctrl={ctrl}")
def wheel(e):
    step = -1 if e.delta > 0 else 1          # Windows/macOS
    out.config(text=f"wheel delta={e.delta} step={step}")
area.bind("<Button>", show)                  # any mouse button
root.bind("<Key>", key)
area.bind("<MouseWheel>", wheel)
area.bind("<Button-4>", lambda e: out.config(text="X11 wheel up"))
area.bind("<Configure>", lambda e: print(e.widget, e.width, e.height))
root.mainloop()

Code Explained

e.type names the event kind, e.g. ButtonPress
e.num tells which mouse button was pressed
Bit masks on e.state reveal Shift and Control
e.delta sign gives wheel direction
X11 sends wheel as <Button-4>/<Button-5> instead

⚠ Common Mistakes

  • Using e.char to detect arrows or function keys (it's empty)
  • Mixing up widget x/y and screen x_root/y_root
  • Assuming delta is ±120 on every platform

✓ Tips & Best Practices

  • Print the whole event while learning: print(e)
  • Match on keysym for named keys
  • Normalize wheel input with the sign of delta

Quick Summary

  • Handlers get an Event object
  • x/y, x_root/y_root for position
  • keysym, char, state for keys
  • widget names the source
