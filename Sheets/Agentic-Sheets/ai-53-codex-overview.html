Codex — Overview & Setup

Codex is OpenAI's coding agent. The Codex CLI is an open-source terminal agent; the same agent also runs in an IDE extension (VS Code, Cursor, Windsurf), a desktop app, and Codex cloud, where tasks run in a remote sandbox and come back as diffs or PRs. Sign in with a ChatGPT plan or use an API key. Project instructions come from AGENTS.md.

Key Ideas

  • Sandbox + approval policy are separate dials
  • Config lives in ~/.codex/config.toml
  • Project config: .codex/config.toml (trusted repos)
  • Same AGENTS.md read across CLI, IDE, cloud

Install, Sign In, First Run

npm install -g @openai/codex        # or: brew install --cask codex
codex --version
codex login                         # ChatGPT sign-in (browser / device code)
codex login --with-api-key          # API key billing instead

cd my-project
codex                               # interactive TUI
codex "explain the auth flow"       # TUI with a first prompt
codex exec "add a CHANGELOG entry"  # non-interactive run
codex resume --last                 # pick up the most recent session

Code Explained

@openai/codex — the open-source CLI package
codex login — ChatGPT plan auth
--with-api-key — pay-per-token via OpenAI API
codex exec — scriptable, non-interactive
resume --last — continue the latest session

⚠ Common Mistakes

  • Expecting Codex to read CLAUDE.md or .cursorrules; use AGENTS.md
  • Leaving OPENAI_API_KEY set and getting API charges instead of using your ChatGPT plan
  • Running in an untrusted folder and wondering why project config and instructions are ignored
  • Sending cloud tasks that need local services the sandbox can't reach

✓ Tips & Best Practices

  • Start with the default workspace-write sandbox and on-request approvals
  • Write AGENTS.md first; it pays off across CLI, IDE, and cloud
  • Check /status when config doesn't seem to apply
  • Use cloud tasks for parallel, well-scoped chores
