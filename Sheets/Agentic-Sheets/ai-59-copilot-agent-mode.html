Copilot Agent Mode (VS Code)

In agent mode, Copilot plans, edits files across the workspace, runs terminal commands, reads errors, and iterates until the task is done. You pick which tools it can use (built-in, extension, and MCP tools), approve terminal commands, and review changes with keep / undo controls and checkpoints. MCP servers are configured per workspace in .vscode/mcp.json.

Approvals

  • Terminal commands ask by default
  • Auto-approve allow/deny lists in settings
  • Tools picker limits what the agent can call
  • Keep / Undo per file or all changes

.vscode/mcp.json

{
  "inputs": [
    { "type": "promptString", "id": "pg-url",
      "description": "Postgres URL", "password": true }
  ],
  "servers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/"
    },
    "postgres": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": { "DATABASE_URL": "${input:pg-url}" }
    }
  }
}

Code Explained

servers — VS Code's key (not mcpServers)
type: http — remote server; OAuth as needed
type: stdio — local process
inputs — prompt once for secrets
${input:pg-url} — keeps secrets out of the file

Agent Mode Workflow

StepDo

2. Add context#file, #codebase, images
3. Choose toolsTools icon → enable/disable
4. ApproveAllow / deny terminal commands
5. ReviewKeep or Undo each change
6. Roll backRestore a checkpoint

⚠ Common Mistakes

  • Enabling every MCP tool; too many tools confuse tool selection and slow responses
  • Auto-approving all terminal commands, including destructive ones
  • Using mcpServers as the key in .vscode/mcp.json; VS Code expects servers
  • Clicking Keep on all changes without opening the diff

✓ Tips & Best Practices

  • Create tool sets for common tasks (e.g. "frontend": browser + files)
  • Use inputs with password: true for secrets in MCP config
  • Restore a checkpoint instead of asking the agent to undo its own mess
  • Commit .vscode/mcp.json so the team shares servers

Quick Summary

  • agent mode — autonomous multi-file edits + terminal
  • tools picker — control what it can call
  • .vscode/mcp.json — workspace MCP servers (servers)
  • keep / undo / checkpoints — review and roll back
