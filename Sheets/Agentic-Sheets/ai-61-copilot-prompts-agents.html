Prompt Files, Custom Agents & Skills

Copilot lets you package reusable workflows three ways. Prompt files (.prompt.md) are saved prompts you run with /name. Custom agents (.agent.md) define a persona with its own instructions, tool list, model, and handoffs to other agents. Agent skills (folders with SKILL.md) bundle instructions and scripts the agent loads when relevant.

Locations

  • Prompts: .github/prompts/*.prompt.md
  • Agents: .github/agents/*.agent.md
  • User agents: ~/.copilot/agents/
  • Skills: .github/skills/<name>/SKILL.md
  • Built-in agents: Agent, Plan, Ask

Custom Agent: .github/agents/test-writer.agent.md

---
name: test-writer
description: Writes and fixes unit tests for changed code
tools: ['search/codebase', 'edit', 'runCommands', 'problems']
model: ['<preferred model>', '<fallback model>']
handoffs:
  - label: Review tests
    agent: reviewer
    prompt: Review the tests just written for gaps.
---
You write focused unit tests. For each changed function:
1. Find existing tests and follow their style.
2. Cover happy path, edge cases, and one failure case.
3. Run the test command from AGENTS.md until green. Never weaken asserts.

Code Explained

name / description — shown in the agent picker
tools — allowed tools for this agent
model — string or prioritized list
handoffs — buttons that pass work to another agent
body — the agent's instructions

Which One?

Multi-step pipeline (plan → code → review)Agents + handoffs

⚠ Common Mistakes

  • Giving a review agent edit tools; it will change code instead of commenting
  • Overlapping agent descriptions so it's unclear which to pick
  • Saving prompts outside .github/prompts/ so /name never finds them
  • Expecting VS Code-only fields to work on github.com (target matters)

✓ Tips & Best Practices

  • Build a planner → implementer → reviewer chain with handoffs
  • Share prompts and agents in the repo so the team gets them
  • Use skills for procedures with scripts; agents for personas
  • Ask Copilot to generate an agent from a description, then trim it

Quick Summary

  • .prompt.md — saved prompt → /name
  • .agent.md — persona + tools + model + handoffs
  • SKILL.md — on-demand know-how and scripts
  • handoffs — chain agents into workflows
