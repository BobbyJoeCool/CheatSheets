⚠ Common Mistakes

  • /clear vs /compact: clear drops context; compact summarizes it
  • Exit code 1 doesn't block in hooks; only 2 does
  • Project-level defaultMode: auto is ignored; set it in user settings
  • Rewind doesn't undo Bash changes; use git

✓ Tips & Best Practices

  • Learn Esc, Esc Esc, Shift+Tab first
  • Name sessions with -n for easy -r
  • Keep CLAUDE.md under ~200 lines
  • Run /doctor after config changes
