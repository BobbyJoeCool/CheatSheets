CLAUDE.md Basics

CLAUDE.md is a Markdown file of standing instructions that Claude Code loads at the start of every session. Use it for what Claude can't reliably infer from the code: build and test commands, conventions, architecture notes, and "never do X" rules. Treat it like code: commit it, review changes to it, and prune it. It is context, not enforcement; use hooks for hard rules.

What Belongs Here

  • Exact build, test, lint, and run commands
  • Code style rules that differ from defaults
  • Repo layout and where key logic lives
  • Workflow rules (branching, commit format)
  • Gotchas: "tests need Docker running"

A Lean Project CLAUDE.md

# Invoice API

## Commands
- Install: `uv sync`
- Test all: `uv run pytest -q`   · one file: `uv run pytest tests/test_tax.py -q`
- Lint + types: `uv run ruff check . && uv run mypy src`
- Dev server: `uv run fastapi dev src/app.py`

## Architecture
- `src/api/` routes only; business logic lives in `src/services/`
- DB access through `src/repo/` (SQLAlchemy 2.0, async)

## Conventions
- Type hints on all public functions; Pydantic v2 models for I/O
- Money is `Decimal`, never float
- IMPORTANT: never edit files in `migrations/` by hand; use `alembic revision`

## Workflow
- Run lint + tests before saying a task is done
- Commit messages: Conventional Commits (`feat:`, `fix:`)

⚠ Common Mistakes

  • Writing a 600-line CLAUDE.md; it costs context every request and lowers adherence. Aim for under ~200 lines
  • Listing generic advice ("write clean code"); it changes nothing. Be specific and checkable
  • Never updating it; stale commands send the agent down wrong paths
  • Relying on CLAUDE.md to block dangerous actions; it's guidance, so use deny rules or hooks

✓ Tips & Best Practices

  • Start with /init, then cut anything Claude already does right
  • When Claude repeats a mistake, add one line here instead of correcting it in chat again
  • Run /doctor for trim suggestions on a large CLAUDE.md
  • Review CLAUDE.md changes in PRs like any other code

Quick Summary

  • CLAUDE.md — standing instructions loaded every session
  • commands — the most valuable lines in the file
  • concise — under ~200 lines; move reference to skills
  • guidance only — use hooks / deny rules to enforce
