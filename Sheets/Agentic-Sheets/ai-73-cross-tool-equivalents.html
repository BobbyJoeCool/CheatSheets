Cross-Tool Equivalents

Most agentic coding tools share the same building blocks under different names: an instructions file, a settings file, approval controls, MCP configuration, reusable prompts or skills, custom agents, and a headless mode. Use this table to translate what you know in one tool into another.

Portable Everywhere

  • AGENTS.md for shared instructions
  • MCP servers (config syntax varies)
  • SKILL.md folders (growing support)
  • Git worktrees for parallel agents

⚠ Common Mistakes

  • Copying a config file between tools as-is; names match but syntax differs (mcpServers vs servers)
  • Assuming features map one-to-one; e.g. hook events and sandbox scope vary a lot
  • Forgetting which tool reads which instructions file when rules seem ignored
  • Relying on this table without checking current docs; tools change monthly

✓ Tips & Best Practices

  • Keep shared knowledge in AGENTS.md and MCP servers
  • Keep tool-specific power features (hooks, scoped rules) in each tool's files
  • When switching tools, port your instructions first, then your workflows
  • Re-check vendor docs before relying on a specific flag
