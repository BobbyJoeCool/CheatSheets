What Is Agentic Coding

Agentic coding means giving an AI model tools (read files, edit files, run commands, search) and letting it work in a loop until a task is done. Instead of suggesting one line at a time, an agent explores the codebase, makes a plan, edits several files, runs the tests, and fixes what breaks. Your job shifts from typing code to directing, reviewing, and verifying it.

Key Ideas

  • The model decides which tool to call next; you set the goal and the guardrails
  • Agents run on your machine (CLI/IDE) or in a cloud sandbox (async agents)
  • Output quality tracks input quality: clear goals and a way to verify
  • You still own the code: review every diff before it merges

Three Levels of AI Coding

AutocompletePredicts the next few tokens or lines as you typeCopilot inline suggestions

Vocabulary

TermMeaning
Agentic loopGather context → take action → verify → repeat
Tool callA structured request from the model to run a capability (Read, Edit, Bash)
Human-in-the-loopA person approves risky steps or reviews before merge
Vibe codingAccepting AI output without reading it; fine for throwaway prototypes only
Agentic engineeringUsing agents with specs, tests, review and guardrails for real code
Context windowEverything the model can see at once: instructions, files, history

⚠ Common Mistakes

  • Treating the agent like autocomplete: one-line prompts with no goal or acceptance criteria
  • Vibe coding production code: unread diffs ship bugs and security holes you never saw
  • Giving full autonomy on day one; start with approvals and loosen as trust builds
  • Blaming the model for bad output when the prompt never said what "done" looks like

✓ Tips & Best Practices

  • Start with a small, well-tested repo task to learn how your agent behaves
  • Write down project rules once (CLAUDE.md / AGENTS.md) instead of repeating them
  • Always give the agent a way to check its own work: tests, a linter, or a build
  • Use git: commit before big agent runs so you can roll back cleanly

Quick Summary

  • agent — model + tools + loop, working toward a goal
  • you — set goals, guardrails, and review
  • autonomy — dial it up as trust and tests grow
  • verify — tests and review make agent output trustworthy
