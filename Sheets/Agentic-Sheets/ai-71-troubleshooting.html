Troubleshooting Agents

Most agent problems trace back to a few causes: polluted or overflowing context, missing or conflicting instructions, vague prompts, misconfigured tools, or permission and environment issues. Diagnose before retrying: check what context and config loaded, read the last few tool calls, and change one thing at a time. A fresh session with a better prompt fixes more than most people expect.

First Moves

  • Esc to stop, read the last tool output
  • /context to check fullness
  • /memory to confirm instructions loaded
  • /doctor or claude doctor for setup issues
  • /clear + sharper prompt

⚠ Common Mistakes

  • Retrying the same prompt in the same polluted session and expecting a different result
  • Changing several config files at once, so you can't tell what fixed or broke things
  • Assuming the model is "broken" before checking context, instructions, and tool output
  • Ignoring setup diagnostics (claude doctor) when installs or auth misbehave

✓ Tips & Best Practices

  • Keep a scratch file of decisions so resets are cheap
  • Use --safe-mode to bisect config problems quickly
  • Turn repeated failures into a CLAUDE.md line or a hook
  • When stuck, ask the agent to list three hypotheses before acting

Quick Summary

  • stop and read — last tool output tells the story
  • check context — /context, /memory
  • check config — /doctor, --safe-mode, /mcp
  • reset — /clear + better prompt
