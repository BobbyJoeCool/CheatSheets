Cursor

Cursor is an AI-first code editor built on VS Code. Its Agent reads and edits across the codebase, runs terminal commands, and uses MCP tools; Ask answers without editing; Plan drafts a plan first. Rules in .cursor/rules/ (plus AGENTS.md) steer behavior. Background agents run tasks remotely, and Bugbot reviews pull requests.

Good to Know

  • Imports VS Code extensions, themes, keybindings
  • Tab completion predicts multi-line edits
  • Model picker per chat; many vendors' models
  • Cursor CLI brings the agent to the terminal

.cursor/rules/react.mdc

---
description: React component conventions for the web app
globs: src/components/**/*.tsx
alwaysApply: false
---
- Function components only; props typed with an interface named <Name>Props
- Co-locate tests as <Name>.test.tsx using Testing Library
- Use Tailwind classes; no inline style objects
- Reference: @src/components/Button/Button.tsx

Code Explained

description — lets Agent decide relevance

.mdc — required extension for project rules

⚠ Common Mistakes

  • Saving project rules as .md; Cursor only recognizes .mdc in .cursor/rules
  • Setting alwaysApply: true on every rule; all of them load into every chat
  • Keeping a legacy .cursorrules and new rules with conflicting guidance
  • Accepting multi-file Agent changes without reviewing the diff

✓ Tips & Best Practices

  • Write good rule descriptions so "Apply Intelligently" works
  • Use globs for language- or folder-specific rules
  • Keep shared rules in AGENTS.md so other tools see them too
  • Use checkpoints to roll back an agent run quickly
