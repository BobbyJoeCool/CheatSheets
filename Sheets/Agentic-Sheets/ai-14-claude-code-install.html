Installation & Authentication

The native installer is the recommended install and updates itself in the background. Homebrew, WinGet, and Linux package managers also work but update manually. After installing, run claude in a project and sign in through the browser with your Claude subscription, or use a Console account or cloud provider for API billing.

Requirements

  • macOS 13+, Windows 10 1809+, Ubuntu 20.04+, Debian 10+, Alpine 3.19+
  • 4 GB+ RAM; x64 or ARM64
  • Windows: Git for Windows recommended (Git Bash); WSL 2 for sandboxing
  • npm install needs Node.js 22+

Install, Verify, Sign In

# Native installer (recommended, auto-updates)
curl -fsSL https://claude.ai/install.sh | bash       # macOS / Linux / WSL
irm https://claude.ai/install.ps1 | iex              # Windows PowerShell

# Package managers (manual updates)
brew install --cask claude-code                      # stable channel
winget install Anthropic.ClaudeCode
npm install -g @anthropic-ai/claude-code             # never with sudo

claude --version          # 2.1.x (Claude Code)
claude doctor             # install + settings diagnostics
claude update             # update now
claude auth login         # browser sign-in (or just run `claude`)
claude auth login --console   # API billing via Anthropic Console
claude auth status        # JSON; exit 0 if logged in

Code Explained

install.sh — installs to ~/.local/bin/claude
--cask claude-code — stable; claude-code@latest for newest
claude doctor — read-only health check, no session
claude update — applies an update immediately
--console — pay-per-token instead of subscription
auth status — scriptable login check for CI

⚠ Common Mistakes

  • Using sudo npm install -g; causes permission problems and is a security risk
  • Installing twice (npm + native) and then running a stale copy; claude doctor flags conflicts
  • Expecting Homebrew or WinGet installs to auto-update; run brew upgrade claude-code
  • Leaving ANTHROPIC_API_KEY set in your shell and getting API bills instead of using your subscription

✓ Tips & Best Practices

  • Use the native installer unless your org mandates a package manager
  • Pick stable channel for team machines; latest for early features
  • Use claude setup-token for CI instead of a personal API key
  • On Windows, install Git for Windows so Claude can use Bash

Quick Summary

  • install.sh / install.ps1 — native install, auto-updates
  • claude doctor — diagnose install and settings
  • claude auth login — subscription or --console billing
  • autoUpdatesChannel — latest or stable
