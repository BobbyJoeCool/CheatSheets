Copilot — Overview & Modes

GitHub Copilot spans the whole range of AI coding: inline completions and next edit suggestions as you type, Copilot Chat in the editor, agent mode that edits and runs commands in your workspace, the Copilot cloud agent (formerly coding agent) that works on GitHub issues and opens PRs, code review, and the Copilot CLI. It works in VS Code, Visual Studio, JetBrains, Xcode, Eclipse, and on github.com.

Plans & Usage

  • Free tier with limits; paid Pro / Pro+ / Business / Enterprise
  • Agent features draw on a monthly request/credit allowance
  • Bigger models cost more per request
  • Org admins control policies and models

⚠ Common Mistakes

  • Using Ask mode and expecting files to change; switch to Agent mode
  • Accepting completions without reading them, especially in security-sensitive code
  • Burning premium requests on trivial tasks with the most expensive model
  • Assuming the cloud agent can reach private internal services from its sandbox

✓ Tips & Best Practices

  • Use Plan then Agent for anything bigger than one file
  • Add .github/copilot-instructions.md before heavy agent use
  • Assign well-scoped issues to the cloud agent; review the draft PR like a teammate's
  • Turn on Copilot code review for a free second pass on PRs
