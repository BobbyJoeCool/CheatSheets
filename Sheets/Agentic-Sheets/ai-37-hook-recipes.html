Hook Recipes

These patterns cover most real-world hook use: format files after every edit, block reads or edits of secrets, stop destructive commands, run tests before Claude declares victory, and notify you when it needs input. Keep scripts in .claude/hooks/, make them executable, and commit them so the whole team gets the same guardrails.

Recipe Checklist

  • chmod +x .claude/hooks/*.sh
  • Read input with jq -r '.tool_input.file_path'
  • Exit 2 + stderr message to block
  • Keep each hook fast (< 1–2 s)

Protect Secrets + Auto-Format

#!/usr/bin/env bash
# .claude/hooks/protect-files.sh   (PreToolUse, matcher: "Edit|Write|Read")
f=$(jq -r '.tool_input.file_path // empty')
case "$f" in
  *.env|*.env.*|*/secrets/*|*.pem)
    echo "Blocked: $f is a protected file" >&2
    exit 2 ;;                                  # 2 = block, stderr → Claude
esac
exit 0

#!/usr/bin/env bash
# .claude/hooks/format.sh   (PostToolUse, matcher: "Edit|Write")
f=$(jq -r '.tool_input.file_path // empty')
case "$f" in
  *.ts|*.tsx|*.js) npx prettier --write "$f" >/dev/null ;;
  *.py)            ruff format "$f" >/dev/null ;;
esac
exit 0

Code Explained

jq -r ... — pull the file path from stdin JSON
// empty — avoid null when the field is missing
exit 2 — blocks; message goes to Claude
PostToolUse format — every edit gets formatted
>/dev/null — keep hook output out of context

⚠ Common Mistakes

  • Formatting with a hook that prints the whole file to stdout; it floods Claude's context
  • Forgetting chmod +x; the hook fails silently as a non-blocking error
  • A Stop hook that always blocks; Claude can never finish. Track attempts or check stop_hook_active
  • Matching Read only and missing cat .env via Bash; also add Read(./.env) deny rules

✓ Tips & Best Practices

  • Combine hooks with deny rules and the sandbox for defense in depth
  • Put team hooks in .claude/settings.json, personal ones in ~/.claude/settings.json
  • Use http hooks to send events to an internal audit service
  • Package proven hooks in a plugin to share across repos
