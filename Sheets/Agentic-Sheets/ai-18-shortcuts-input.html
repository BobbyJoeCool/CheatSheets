Keyboard Shortcuts & Input

A handful of keys do most of the work: Esc interrupts, Esc Esc rewinds, Shift+Tab cycles permission modes, and @ / ! / / prefixes change what you're typing. The prompt box behaves like a readline editor, supports images from the clipboard, and can hand off to your $EDITOR for long prompts.

Setup Notes

  • macOS: set Option as Meta in your terminal for Alt shortcuts
  • /terminal-setup installs Shift+Enter for newlines
  • Vim editing: /config → Editor mode
  • /keybindings opens your custom keybindings file

⚠ Common Mistakes

  • Pressing Ctrl+C repeatedly to stop Claude and accidentally exiting; use Esc
  • Not knowing Esc Esc rewinds, then manually reverting files
  • Typing long prompts in the tiny input box; Ctrl+G opens your editor
  • Alt shortcuts "not working" on macOS because Option isn't set as Meta

✓ Tips & Best Practices

  • Learn three keys first: Esc, Esc Esc, Shift+Tab
  • Paste screenshots with Ctrl+V for UI bugs
  • Queue follow-ups while Claude works instead of waiting
  • Press ? on an empty prompt to see shortcuts any time
