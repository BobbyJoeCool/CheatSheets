Checkpoints & Undo

Claude Code takes a checkpoint before each prompt that starts a turn, snapshotting files its edit tools touch. Press Esc Esc on an empty prompt (or run /rewind) to restore code, conversation, or both to any earlier prompt, or to summarize part of the conversation. Checkpoints are a fast session-level undo; git remains your real history.

Retention

  • Last 100 checkpoints per session
  • Saved with the session; work after /resume
  • Snapshots swept after ~30 days (cleanupPeriodDays)
  • After /clear, rewind can reopen the previous session

⚠ Common Mistakes

  • Expecting rewind to undo a rm or a code generator run; Bash changes aren't tracked
  • Rewinding after a subagent made edits and assuming they're gone
  • Skipping commits because "checkpoints have my back"; snapshots expire and aren't shared
  • Pressing Esc Esc with text in the input; it clears the draft instead (press Up to recall)

✓ Tips & Best Practices

  • Commit before any big or risky agent run
  • Use "Restore conversation" to retry a prompt while keeping good edits
  • Use "Summarize from here" to collapse a long debugging detour
  • Use /branch to explore two approaches from the same point

Quick Summary

  • checkpoint — auto snapshot before each prompt
  • Esc Esc / /rewind — restore code, chat, or both
  • summarize — compress part of the conversation
  • git — real history; covers Bash changes
