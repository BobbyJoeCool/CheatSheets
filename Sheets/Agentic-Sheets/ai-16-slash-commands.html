Built-in Slash Commands

Type / to open the command menu; keep typing to filter. Commands control the session itself (context, model, permissions, history), while bundled skills like /batch or /simplify run workflows. Arguments go after the name: /compact keep the schema decisions. Your own skills appear in the same menu.

Tips

  • Commands only work at the start of a message
  • Sent mid-turn, most commands queue until Claude finishes
  • /status, /tasks, /usage run immediately
  • Plugin skills appear as /plugin-name:skill

Session & Context

CommandDoes
/clear [name]New conversation, empty context
/compact [focus]Summarize history to free context
/contextVisual grid of what fills context
/resume [session]Reopen an earlier conversation
/rewindRoll back conversation and/or code
/branch [name]Fork the conversation at this point
/rename [name]Name the session for /resume
/btw [question]Side question without polluting context
/export [file]Save the conversation as text

⚠ Common Mistakes

  • Using /clear when you meant /compact; clear drops everything, compact keeps a summary
  • Typing a command mid-sentence; it's only recognized at the start of a message
  • Forgetting /rewind exists and manually undoing a bad multi-file edit
  • Running /init again on a curated CLAUDE.md and overwriting your edits without review

✓ Tips & Best Practices

  • /context first when answers get worse; it shows what's eating space
  • Use /btw for quick questions that shouldn't steer the main task
  • Name sessions (/rename) so /resume is easy later
  • Run /security-review before opening any PR that touches auth or input handling

Quick Summary

  • /clear · /compact — reset vs summarize context
  • /rewind · /resume — go back · come back
  • /model · /config · /permissions — tune the session
  • /diff · /security-review — review before commit
