MCP Concepts

The Model Context Protocol is an open standard for connecting AI applications to tools and data. A host (Claude Code, Copilot, Cursor, Codex) runs an MCP client per connection; each server exposes tools (actions), resources (data), and prompts (templates). One server works with every MCP-capable tool, so integrations are written once.

Why It Matters

  • One integration works across many agents
  • Servers handle auth, rate limits, schemas
  • Agents discover tools at runtime
  • Vendors ship official remote servers

⚠ Common Mistakes

  • Thinking MCP is Claude-only; it's an open protocol supported by most major tools
  • Confusing tools with resources: tools act, resources are read
  • Using deprecated SSE for new servers; use Streamable HTTP
  • Assuming JSON config keys match across tools (mcpServers vs servers)

✓ Tips & Best Practices

  • Prefer remote HTTP servers with OAuth over sharing API tokens
  • Check each server's tool list before enabling it
  • Use MCP resources (@server:resource) to pull data without a tool call
  • Browse official registries before building your own server
