The AGENTS.md Standard

AGENTS.md is an open, vendor-neutral format for agent instructions: plain Markdown at the repo root (and optionally in subfolders), with no required schema. Think of it as a README for agents: setup commands, test commands, code style, and PR rules. It's read natively by Codex, Copilot, Cursor, Windsurf, Claude Code (when no CLAUDE.md exists), and many others.

Format Rules

  • Plain Markdown; any headings you like
  • Root file applies repo-wide
  • Nested files apply to their subtree; closer files win
  • Explicit user prompts override file instructions
  • Keep it short; tools cap size (Codex: 32 KiB default)

A Solid AGENTS.md

# AGENTS.md

## Setup
- Install: `pnpm install`
- Start dev server: `pnpm dev` (http://localhost:3000)

## Testing
- All tests: `pnpm test`   · single: `pnpm vitest run path/to/file.test.ts`
- Before finishing: `pnpm lint && pnpm typecheck && pnpm test`

## Code style
- TypeScript strict; no `any`. Named exports only.
- React components in `src/components/<Name>/<Name>.tsx` with a test beside it

## PR rules
- Title: `[area] short summary`; include a "How I tested" section
- Never commit `.env*` files or edit `generated/`

⚠ Common Mistakes

  • Copying your README into AGENTS.md; agents need commands and rules, not marketing copy
  • Letting the file grow past the tool's size cap; later content gets dropped
  • Writing rules only a human can follow ("use good judgment")
  • Forgetting nested files exist when debugging "ignored" instructions

✓ Tips & Best Practices

  • Keep commands copy-pasteable and tested
  • Put package-specific commands in nested AGENTS.md files
  • Review AGENTS.md changes in PRs like code
  • Link deeper docs instead of inlining them
