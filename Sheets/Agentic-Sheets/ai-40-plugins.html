Plugins & Marketplaces

A plugin packages skills, subagents, hooks, MCP servers, output styles, and LSP servers into one installable unit. A marketplace is a Git repo or folder with a catalog (marketplace.json) listing plugins. Anthropic's official marketplace is added automatically; you can add your team's own. Plugins are how you share a whole Claude Code setup across repos.

Install Scopes

  • User: you, every project
  • Project: everyone in the repo (.claude/settings.json)
  • Local: you, this repo only
  • Cloud sessions don't load local plugins

Plugin Commands and Layout

/plugin                                  # browse and manage
/plugin marketplace add my-org/plugins   # repo, URL, or path
/plugin install commit-commands@claude-plugins-official
claude plugin install code-review@claude-code-plugins
claude plugin disable code-review        # turn off, keep installed
/reload-plugins                          # apply without restart
claude --plugin-dir ./my-plugin          # test locally

my-plugin/
├── .claude-plugin/plugin.json   # name, version, description
├── skills/review/SKILL.md       # → /my-plugin:review
├── agents/reviewer.md           # subagent
├── hooks/hooks.json             # lifecycle hooks
├── .mcp.json                    # MCP servers
└── output-styles/terse.md       # output style

Code Explained

marketplace add — register a catalog once
name@marketplace — install a plugin by name
disable — stop it without uninstalling
--plugin-dir — load a plugin for one session
plugin.json — manifest at .claude-plugin/
skills/ agents/ hooks/ — components loaded together

⚠ Common Mistakes

  • Installing many plugins "just in case"; every skill description costs context every turn
  • Installing third-party plugins without reading them; they run hooks and MCP servers as you
  • Expecting project-scoped plugins to appear for teammates who haven't installed them
  • Editing an installed plugin's files directly instead of its source repo

✓ Tips & Best Practices

  • Check a plugin's Context cost in /plugin before installing
  • Review Not used recently in the Installed tab and disable extras
  • Host an internal marketplace repo for your team's skills and hooks
  • Use managed settings to allowlist approved marketplaces

Quick Summary

  • plugin — bundle of skills, agents, hooks, MCP
  • marketplace — catalog repo with marketplace.json
  • /plugin install name@mkt — install
  • --plugin-dir — develop and test locally
