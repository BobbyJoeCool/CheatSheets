Claude Code — Introduction

Claude Code is Anthropic's agentic coding tool. The same agent runs in your terminal, inside VS Code and JetBrains, in the Claude desktop app, on the web at claude.ai/code (cloud sandboxes), on mobile, and in Slack. It reads your codebase, edits files, runs commands, and connects to outside systems through MCP. Configuration (CLAUDE.md, settings, skills, hooks) is shared across surfaces.

Good to Know

  • Requires a Pro, Max, Team, Enterprise, or Console account
  • Also runs on Amazon Bedrock, Google Cloud, and Microsoft Foundry
  • Sessions can move between surfaces (/desktop, --teleport)
  • The CLI is the most complete surface; others share its engine

⚠ Common Mistakes

  • Assuming the free claude.ai plan includes Claude Code; it requires a paid plan or Console billing
  • Configuring the IDE extension separately; it reads the same ~/.claude and .claude/ files as the CLI
  • Using cloud sessions for work that needs local services or secrets the sandbox doesn't have
  • Running Claude Code outside the project root, so it can't find CLAUDE.md or settings

✓ Tips & Best Practices

  • Start in the CLI to learn the controls, then pick the surface that fits each task
  • Use the desktop or IDE surface when you want to review diffs visually
  • Hand long, well-scoped tasks to a cloud session and check from your phone
  • Run claude doctor when anything about setup looks off

Quick Summary

  • claude — start an interactive session in this folder
  • surfaces — CLI, IDE, desktop, web, mobile, Slack, GitHub
  • shared config — CLAUDE.md, settings, skills apply everywhere
  • handoff — /desktop, --cloud, --teleport
