Codex AGENTS.md, Skills & MCP

Codex builds its instructions by concatenating AGENTS.md files: first your global file in ~/.codex/, then each directory from the repo root down to where you're working. An AGENTS.override.md at any level replaces the regular file there. Skills package reusable instructions, and MCP servers add tools, configured with codex mcp or in config.toml.

Discovery Order

  • 1. ~/.codex/AGENTS.override.md or AGENTS.md
  • 2. Repo root → cwd: override or AGENTS.md per folder
  • 3. Plus names in project_doc_fallback_filenames
  • Later (closer) files appear last → take precedence
  • Total capped by project_doc_max_bytes (32 KiB)

Instructions, Fallbacks, MCP

# Global personal instructions
cat ~/.codex/AGENTS.md

# Temporary override in a subfolder (replaces AGENTS.md there)
echo "Use the legacy build: make build-legacy" > services/old/AGENTS.override.md

# config.toml: also read other instruction files, raise the cap
#   project_doc_fallback_filenames = ["CLAUDE.md", "CONTRIBUTING.md"]
#   project_doc_max_bytes = 65536

# Verify what loaded
codex --ask-for-approval never "Summarize the instructions you loaded"

# MCP servers
codex mcp add context7 -- npx -y @upstash/context7-mcp
codex mcp list
codex mcp login github                # OAuth for remote servers

Code Explained

~/.codex/AGENTS.md — applies to every project
AGENTS.override.md — replaces that folder's AGENTS.md
fallback_filenames — read CLAUDE.md etc. too
max_bytes — files beyond the cap are skipped
summarize instructions — quick verification
codex mcp add — everything after -- is the command

⚠ Common Mistakes

  • Leaving an AGENTS.override.md in place after the temporary need passes
  • Writing a huge AGENTS.md and losing nested files to the 32 KiB cap
  • Assuming SKILL.md files from Claude Code work identically; check Codex-specific fields
  • Adding MCP servers without checking their tool list and permissions

✓ Tips & Best Practices

  • Use project_doc_fallback_filenames to reuse an existing CLAUDE.md
  • Keep the global AGENTS.md for personal habits only
  • Restart Codex after editing instructions to rebuild the chain
  • Share MCP config via project .codex/config.toml in trusted repos

Quick Summary

  • AGENTS.md chain — global → root → cwd
  • AGENTS.override.md — replace a level's rules
  • project_doc_max_bytes — 32 KiB default cap
  • codex mcp — add / list / login servers
