Building an MCP Server

When no server exists for your internal system, build one. The official Python SDK (with the FastMCP API) and TypeScript SDK turn ordinary functions into tools: the function signature becomes the input schema and the docstring becomes the description the model reads. Test it with the MCP Inspector, then register it with your agent.

Design Tips

  • Few, well-named tools beat many tiny ones
  • Descriptions are prompts: say when to use it
  • Return concise, structured text
  • Validate inputs; return helpful errors
  • Read-only tools first

Python (FastMCP) Server: server.py

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("inventory")

@mcp.tool()
def check_stock(sku: str) -> str:
    """Return on-hand quantity for a product SKU. Use before promising
    availability to a customer."""
    qty = {"A-100": 42, "B-200": 0}.get(sku.upper())
    return f"{sku}: {qty} in stock" if qty is not None else f"{sku}: unknown SKU"

@mcp.resource("inventory://warehouses")
def warehouses() -> str:
    """List of warehouse codes."""
    return "CHI, DAL, SEA"

if __name__ == "__main__":
    mcp.run()          # stdio transport by default

Code Explained

FastMCP("inventory") — server name shown to clients
@mcp.tool() — function → callable tool
sku: str — type hints → JSON input schema
docstring — the description the model reads
@mcp.resource — readable data at a URI
mcp.run() — serve over stdio

⚠ Common Mistakes

  • Vague docstrings ("does stuff"); the model can't decide when to call the tool
  • Printing logs to stdout in a stdio server; it corrupts the protocol stream (log to stderr)
  • Returning huge payloads that blow out the agent's context
  • Exposing destructive actions with no confirmation or dry-run option

✓ Tips & Best Practices

  • Write tool descriptions like instructions to a new teammate
  • Use the Inspector to try every tool before wiring it to an agent
  • Add a dry_run flag to tools that change data
  • Ship it as a remote HTTP server when several people need it

Quick Summary

  • FastMCP — Python decorators → tools
  • type hints + docstring — schema + description
  • Inspector — test tools interactively
  • mcp add — register with your agent
