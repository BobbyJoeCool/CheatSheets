Cloud, Remote & Scheduled Sessions

Claude Code on the web runs sessions in Anthropic-managed cloud sandboxes: start a task at claude.ai/code, from the mobile app, or with claude --cloud, and get back a branch or PR. Remote Control lets you drive a local session from your phone. Routines (/schedule) run prompts in the cloud on a schedule, and /loop repeats a prompt while a session stays open.

Cloud Session Facts

  • Clones your GitHub repo into a fresh sandbox
  • Network and environment set per cloud environment
  • Local plugins and secrets aren't there by default
  • Pull work back with /teleport

Cloud and Remote Commands

/web-setup                          # connect GitHub using local gh credentials
claude --cloud "fix the flaky checkout test and open a PR"
/remote-env                         # pick default cloud environment
/teleport                           # pull a cloud session into this terminal
claude --teleport

claude --remote-control "api-work"  # local session, controllable from app
/remote-control                     # enable for the current session
/autofix-pr                         # cloud session watches PR, pushes CI fixes

/schedule every weekday 8am: summarize new Sentry errors and open issues
/loop 10m check if the deploy finished and report status

Code Explained

--cloud — new cloud session from the CLI
/teleport — cloud → local terminal
remote-control — steer a local session remotely
/autofix-pr — keeps a PR green in the cloud
/schedule — create a cloud routine
/loop — repeat a prompt while open

⚠ Common Mistakes

  • Sending tasks to the cloud that need your local database or VPN
  • No setup script, so every cloud session wastes time installing dependencies
  • Merging cloud-session PRs without the same review you'd give a teammate
  • Using /loop for long-term schedules; it stops when the session closes. Use /schedule

✓ Tips & Best Practices

  • Write cloud prompts like tickets: goal, files, verify command, PR expectations
  • Run several cloud sessions in parallel for independent chores
  • Use Remote Control to approve prompts from your phone during long local runs
  • Use routines for daily triage, dependency checks, and reports

Quick Summary

  • claude --cloud — start a cloud sandbox session
  • /teleport — bring it back local
  • /remote-control — drive local from anywhere
  • /schedule · /loop — recurring vs in-session repeats
