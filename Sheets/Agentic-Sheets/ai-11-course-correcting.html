Steering & Course-Correcting

Agents go off track: wrong file, wrong approach, a loop of failed fixes. The fix is early, specific intervention. Interrupt as soon as you see a bad direction, say what's wrong, and point to the right path. If the session is muddled, rewind to before the mistake or start fresh with a better prompt. Correcting early is cheap; correcting late means unwinding a big diff.

Warning Signs

  • Editing files you didn't expect
  • Same error after 2–3 attempts
  • Adding workarounds, mocks, or # type: ignore
  • Long explanations with no tool calls
  • Claims of success without running tests

⚠ Common Mistakes

  • Watching a wrong approach play out "to see where it goes"; every turn adds a bigger mess
  • Correcting the same mistake twice in chat instead of fixing the instructions file
  • Keeping a session alive full of failed attempts; old errors keep steering the agent
  • Saying only "that's wrong" without saying what right looks like

✓ Tips & Best Practices

  • Interrupt early; the first two tool calls tell you if the approach is sound
  • After two failed corrections, /clear and rewrite the prompt with what you learned
  • Turn a repeated correction into a line in CLAUDE.md
  • Commit known-good states so git is your undo button

Quick Summary

  • interrupt — Esc as soon as it drifts
  • rewind — go back before the mistake
  • redirect — say what's wrong and what's right
  • fresh start — better than a polluted session
