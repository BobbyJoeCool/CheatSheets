Custom Subagents

Define your own subagents as Markdown files with YAML frontmatter in .claude/agents/ (project) or ~/.claude/agents/ (personal). The frontmatter sets the name, the description Claude uses to decide when to delegate, the allowed tools, and the model; the body is the subagent's system prompt. Good custom agents are narrow: a reviewer, a test writer, a migration checker.

Scope Priority (high → low)

  • Managed settings
  • --agents CLI flag (JSON)
  • Project: .claude/agents/
  • User: ~/.claude/agents/
  • Plugin agents/ directory

Custom Agent: .claude/agents/code-reviewer.md

---
name: code-reviewer
description: Expert code reviewer. Use PROACTIVELY after any significant
  code change, before commits, or when the user asks for a review.
tools: Read, Grep, Glob, Bash
model: sonnet
permissionMode: default
skills: [security-checklist]
maxTurns: 25
---

You are a senior reviewer for this repo. When invoked:
1. Run `git diff` to see recent changes; focus on modified files.
2. Check correctness, error handling, security, and test coverage.
3. Report: Critical / Warnings / Suggestions, each as file:line + fix.
Never edit files. If unsure, say what you'd verify instead of guessing.

Code Explained

name — used for @code-reviewer and --agent
description — "Use PROACTIVELY" encourages auto-delegation
tools — allowlist; omit to inherit all
model — sonnet · opus · haiku · full ID
skills — preloaded fully into the agent's context
body — becomes the agent's system prompt

⚠ Common Mistakes

  • Giving a review-only agent Edit and Write tools; it will "helpfully" change code
  • Writing a generic description; Claude can't tell when to delegate
  • Building one giant "do everything" agent instead of several narrow ones
  • Using the most expensive model for simple read-only agents

✓ Tips & Best Practices

  • Let Claude draft the agent: ask it to create one in .claude/agents/
  • Run a whole session as an agent with claude --agent code-reviewer
  • Use isolation: worktree for agents that edit in parallel
  • Commit project agents so the team shares the same reviewers

Quick Summary

  • .claude/agents/*.md — frontmatter + system prompt
  • description — decides automatic delegation
  • tools · model — least privilege, right-sized model
  • --agent name — run a session as that agent
