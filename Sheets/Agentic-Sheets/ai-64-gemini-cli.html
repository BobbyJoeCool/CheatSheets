Gemini CLI

Gemini CLI is Google's open-source terminal agent. It reads GEMINI.md context files hierarchically (global, project, subfolders), supports MCP servers, custom slash commands, extensions, a sandbox, checkpointing, and a non-interactive mode for scripts. Sign in with a Google account for a free tier, or use an API key or Vertex AI.

Context Files

  • Global: ~/.gemini/GEMINI.md
  • Project: GEMINI.md from root to cwd
  • Subfolders loaded as they're touched
  • context.fileName can add AGENTS.md

Install, Run, Configure

npm install -g @google/gemini-cli        # or: npx @google/gemini-cli
gemini                                   # interactive; sign in on first run
gemini -p "explain src/router.ts"        # non-interactive prompt
gemini -m <model>                        # choose model
gemini --sandbox                         # run tools in a container sandbox
gemini --yolo                            # auto-approve all (risky)

# In a session
#   /memory show | /memory add <fact> | /memory refresh
#   /mcp   /tools   /chat save <tag>   /restore   /compress   /stats
#   @path/to/file   !git status

# ~/.gemini/settings.json (or .gemini/settings.json in a project)
#   { "context": { "fileName": ["AGENTS.md", "GEMINI.md"] },
#     "mcpServers": { "github": { "httpUrl": "https://api.githubcopilot.com/mcp/" } } }

Code Explained

gemini -p — one-shot, scriptable
--sandbox — Docker/Podman or macOS Seatbelt
/memory — view, add, reload GEMINI.md context
/restore — roll back via checkpoints
@file · !cmd — add files; run shell
context.fileName — which context files to read

⚠ Common Mistakes

  • Expecting Gemini CLI to read AGENTS.md by default; add it to context.fileName
  • Running --yolo outside a sandbox on a machine with real credentials
  • Editing GEMINI.md mid-session and forgetting /memory refresh
  • Committing API keys into .gemini/settings.json

✓ Tips & Best Practices

  • Use /memory show to see exactly what context loaded
  • Turn on checkpointing so /restore can undo file changes
  • Wrap repeated prompts as .toml custom commands
  • Use --sandbox for untrusted repos
