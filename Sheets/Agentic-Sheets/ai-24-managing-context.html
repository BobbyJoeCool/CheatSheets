Managing Context

Context management is the day-to-day skill that most affects output quality. Watch how full the window is, clear it between tasks, compact with focus when a long task needs to continue, and push noisy work (wide searches, log digging) into subagents. Claude Code auto-compacts near the limit, but a deliberate /compact with instructions keeps what matters.

Signals You Need to Act

  • Answers ignore earlier decisions
  • Claude re-reads files it already read
  • Context indicator shows high usage
  • You're switching to an unrelated task

Context Commands in Practice

> /context                       # colored grid: what's using space
> /context all                   # per-tool token detail (incl. MCP)

> /compact keep the API contract decisions and the failing test names
> /clear                         # new task → empty context
> /clear billing-spike           # label the old one for /resume

> /btw what does this regex match?   # side question; not added to context

> use a subagent to find every caller of formatCurrency and report
  only file:line and how it's called

Code Explained

/context — spot big files, MCP tools, memory bloat
/compact <focus> — summary keeps what you name
/clear — fastest way to restore quality
/btw — answers without growing the main thread
subagent — reads widely; returns only a summary

⚠ Common Mistakes

  • Waiting for auto-compaction mid-task; the automatic summary may drop details you needed
  • Using one session for an entire day of unrelated work
  • Pasting huge logs directly instead of filtering them first
  • Clearing without saving the plan or decisions to a file first

✓ Tips & Best Practices

  • Write decisions to a file (docs/plans/x.md) before /clear so the next session can read them
  • Compact at natural milestones, with a focus sentence
  • Ask for subagents explicitly for exploration-heavy questions
  • Check /context all if MCP tools seem to eat space

Quick Summary

  • /context — see what fills the window
  • /compact focus — summarize, keep what matters
  • /clear — new task, new context
  • subagents — isolate noisy work
