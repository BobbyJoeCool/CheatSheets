IDE Integration & Code Intelligence

The VS Code extension (also works in Cursor and other VS Code forks) and the JetBrains plugin put Claude Code next to your editor: inline diffs you accept or reject, your current selection shared as context, and IDE diagnostics visible to Claude. Code intelligence plugins connect Claude to a language server so it can jump to definitions and see type errors instead of grepping.

Connecting

  • VS Code: install "Claude Code" extension; click the Claude icon
  • JetBrains: install plugin; runs in the IDE terminal
  • From an external terminal: /ide or claude --ide
  • Same settings, CLAUDE.md, skills as the CLI

⚠ Common Mistakes

  • Assuming the IDE extension has separate config; it reads the same ~/.claude and .claude/ files
  • Accepting all inline diffs at once without reading them
  • Running an IDE session and a terminal session on the same files at the same time
  • Skipping code intelligence on big typed repos, so Claude greps and reads far more than needed

✓ Tips & Best Practices

  • Select the code you're asking about; it becomes precise context
  • Install a code intelligence plugin for TypeScript, Python, Go, Rust, or Java projects
  • Use the IDE for review and the terminal for long or parallel runs
  • Run /ide in a terminal session to link it to your open editor

Quick Summary

  • VS Code / JetBrains — inline diffs, selection context
  • /ide — connect a terminal session to the IDE
  • LSP plugins — definitions, references, type errors
  • same config — settings and skills shared with CLI
