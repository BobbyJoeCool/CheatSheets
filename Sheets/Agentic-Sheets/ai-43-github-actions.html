GitHub Actions & CI

claude-code-action runs Claude Code inside GitHub Actions. In interactive mode it answers @claude mentions in issues and PRs: explaining, fixing, and pushing commits. In automation mode (when you give it a prompt) it runs on any event: PR opened, schedule, label. Quick setup is /install-github-app, which installs the GitHub App, adds the secret, and opens a PR with the workflow.

Setup

  • Run /install-github-app (needs gh and repo admin)
  • Secret: ANTHROPIC_API_KEY or CLAUDE_CODE_OAUTH_TOKEN
  • Subscription token: claude setup-token

.github/workflows/claude.yml

name: Claude Code
on:
  issue_comment: { types: [created] }
  pull_request_review_comment: { types: [created] }
jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      id-token: write
      actions: read
    steps:
      - uses: actions/checkout@v6
        with: { fetch-depth: 1 }
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          claude_args: "--max-turns 10 --model claude-sonnet-5"

Code Explained

if: contains(...) — only start on @claude comments
id-token: write — needed for GitHub App auth
actions: read — lets Claude read CI results
checkout — a local copy to work in
@v1 — current major version
claude_args — any CLI flags (turns, model, tools)

⚠ Common Mistakes

  • Committing API keys in the workflow file; always use repository or org secrets
  • Passing github_token: ${{ secrets.GITHUB_TOKEN }}; commits made with it don't trigger your CI
  • No --max-turns or job timeout, so a confused run eats Actions minutes and tokens
  • Expecting fork PRs on public repos to get reviews; GitHub withholds secrets from them

✓ Tips & Best Practices

  • Keep CLAUDE.md concise; the action reads it every run
  • Use issue templates so @claude requests arrive with context
  • Use concurrency groups to stop parallel runs piling up
  • For automatic PR reviews without a workflow, consider the managed Code Review feature

Quick Summary

  • /install-github-app — one-command setup
  • @claude — interactive mode in issues and PRs
  • prompt: — automation mode on any event
  • claude_args — pass CLI flags
