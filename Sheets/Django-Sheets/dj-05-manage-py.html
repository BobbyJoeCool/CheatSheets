manage.py & Management Commands

runserver · shell · check · createsuperuser · showmigrations · custom BaseCommand · handle()

Running Commands

manage.py is a thin wrapper around django-admin that sets DJANGO_SETTINGS_MODULE for your project. Every built-in task (dev server, migrations, shell, tests) is a management command, and you can add your own by placing a module in <app>/management/commands/.

Notes

  • python manage.py help lists every command; help <cmd> shows its options
  • shell auto-imports all models (Django 5.2+)
  • check runs system checks; add --deploy before going live
  • Custom commands are great for cron jobs and data imports
  • Call commands from code with call_command("migrate")

Everyday Commands

python manage.py runserver 0.0.0.0:8000   # dev server on all interfaces
python manage.py shell                    # Python REPL with Django loaded
python manage.py createsuperuser          # admin login
python manage.py makemigrations && python manage.py migrate
python manage.py check --deploy           # production checklist
python manage.py import_books books.csv --dry-run

Custom Command

# blog/management/commands/import_books.py
from django.core.management.base import BaseCommand, CommandError

class Command(BaseCommand):
    help = "Import books from a CSV file"

    def add_arguments(self, parser):          # argparse parser
        parser.add_argument("path")
        parser.add_argument("--dry-run", action="store_true")

    def handle(self, *args, **opts):
        if not opts["path"].endswith(".csv"):
            raise CommandError("Expected a .csv file")
        count = import_csv(opts["path"], save=not opts["dry_run"])
        self.stdout.write(self.style.SUCCESS(f"Imported {count}"))

Code Explained

The file name becomes the command name: import_books
management/ and commands/ both need __init__.py
add_arguments gets an argparse parser; --dry-run → opts["dry_run"]
CommandError prints the message and exits with status 1
Write with self.stdout.write so tests can capture output

⚠ Common Mistakes

  • Using print() in commands; tests can't capture it, use self.stdout.write
  • Missing __init__.py in management/commands/, so the command is not found
  • Running flush on the wrong database; it deletes every row without a backup

✓ Tips & Best Practices

  • Use runserver_plus (django-extensions) for an in-browser debugger
  • Wrap bulk imports in transaction.atomic() so a failure rolls everything back
  • Schedule custom commands with cron or a task runner instead of web endpoints

Quick Summary

  • manage.py <cmd>: run any command
  • BaseCommand.handle(): command body
  • add_arguments(parser): CLI options
  • call_command(): invoke from Python
