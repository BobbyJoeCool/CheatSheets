Reacting to Events

Signals let decoupled code react when something happens elsewhere: a model is saved, a user logs in, a request finishes. A receiver function is connected to a signal, usually with @receiver, and is called synchronously by whoever sends it. Register receivers in your AppConfig.ready() so they're connected exactly once at startup.

Notes

  • Receivers run in the same thread and transaction as the sender
  • queryset.update() and bulk_create() don't send model signals
  • Pass sender= to listen to one model only
  • Use dispatch_uid to avoid duplicate connections
  • Prefer explicit calls when the code is in the same app

Receivers and Registration

# accounts/signals.py
from django.conf import settings
from django.db.models.signals import post_save, pre_delete
from django.dispatch import receiver, Signal

@receiver(post_save, sender=settings.AUTH_USER_MODEL)
def create_profile(sender, instance, created, **kwargs):
    if created:
        Profile.objects.create(user=instance)

@receiver(pre_delete, sender=Document)
def delete_file(sender, instance, **kwargs):
    instance.file.delete(save=False)

order_paid = Signal()                         # custom signal
order_paid.send(sender=Order, order=order)    # send it

# accounts/apps.py
class AccountsConfig(AppConfig):
    name = "accounts"
    def ready(self):
        from . import signals                 # connect receivers

Code Explained

Receivers must accept **kwargs for future arguments
created is True only on the first save
save=False deletes the file without re-saving the row
Importing signals in ready() runs the decorators
send() returns a list of (receiver, response)

⚠ Common Mistakes

  • Defining receivers in a module that's never imported, so they never fire
  • Expecting post_save after queryset.update(); no signal is sent
  • Doing slow work (emails, APIs) in a receiver; it blocks the request, enqueue a task instead

✓ Tips & Best Practices

  • Use transaction.on_commit inside receivers for side effects
  • Signals suit cross-app hooks; within an app, call the function directly
  • Disconnect noisy receivers in tests with post_save.disconnect

Quick Summary

  • @receiver(signal, sender=): listen
  • post_save(created=...): after save
  • AppConfig.ready(): register once
  • Signal().send(): custom events
