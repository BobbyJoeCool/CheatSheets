Forms Built from Models

A ModelForm builds its fields from a model, so field types, max_length, choices, blank and help_text carry over automatically. Its save() creates or updates the model instance. Pass instance=obj to edit an existing row. Use save(commit=False) to get the unsaved object, set fields the user shouldn't control, then save it yourself.

Notes

  • List fields explicitly; avoid "__all__" and exclude
  • Model validation (clean(), unique, constraints) runs in is_valid()
  • After commit=False, call form.save_m2m() for many-to-many data
  • Override labels, widgets and help text in Meta
  • Add extra non-model fields like any normal form field

ModelForm Create and Edit

from django import forms
from .models import Post

class PostForm(forms.ModelForm):
    notify = forms.BooleanField(required=False)          # extra field
    class Meta:
        model = Post
        fields = ["title", "body", "tags", "pub_date"]
        labels = {"body": "Content"}
        widgets = {"pub_date": forms.DateInput(attrs={"type": "date"})}
        help_texts = {"tags": "Pick up to five."}

def post_edit(request, pk=None):
    post = get_object_or_404(Post, pk=pk, author=request.user) if pk else None
    form = PostForm(request.POST or None, instance=post)
    if form.is_valid():
        post = form.save(commit=False)                   # not in DB yet
        post.author = request.user
        post.save()
        form.save_m2m()                                  # tags
        if form.cleaned_data["notify"]:
            notify_followers(post)
        return redirect(post)
    return render(request, "blog/post_form.html", {"form": form})

Code Explained

instance=None creates; instance=post edits
commit=False returns the object without saving
save_m2m() is only needed after commit=False
widgets / labels dicts override per field
Filtering the lookup by author stops editing others' posts

⚠ Common Mistakes

  • fields = "__all__"; a later model field like is_admin becomes editable
  • Using commit=False and forgetting save_m2m(), so tags are never saved
  • Setting author from a hidden input; users can change it, set it in the view

✓ Tips & Best Practices

  • Use modelform_factory(Post, fields=[...]) for quick one-off forms
  • Override __init__(self, *args, user=None, **kwargs) to pass the user in
  • Reuse one ModelForm for create and update by passing instance

Quick Summary

  • ModelForm: fields from a model
  • Meta.fields: explicit whitelist
  • instance=: edit existing row
  • save(commit=False): set extra fields first
