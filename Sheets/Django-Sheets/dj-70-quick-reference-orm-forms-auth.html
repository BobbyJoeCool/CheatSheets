⚠ Common Mistakes

  • N+1 queries in templates — add select_related / prefetch_related
  • Swapping to a custom user model after the first migration — set AUTH_USER_MODEL on day one
  • null=True on CharField — use blank=True and an empty string instead

✓ Tips & Best Practices

  • Run check --deploy before every release
  • Use F() for counters so concurrent updates don't race
  • Keep business logic on models or services, not in views

Quick Summary

  • Models → migrations → QuerySets
  • filter(field__lookup=…), Q for OR, F for columns
  • ModelForm + is_valid() + cleaned_data
  • @admin.register + list_display for a free back office
