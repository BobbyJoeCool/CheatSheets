Shaping the Change List and Form

A ModelAdmin class controls two pages per model. The change list shows rows in a table with columns, filters, search and pagination. The change form edits one object, with field order, grouping and read-only fields. Most customization is declarative: set class attributes and the admin builds the UI.

Notes

  • list_display can include model fields, methods or ModelAdmin methods
  • search_fields supports lookups: "author__username", "=sku"
  • list_select_related stops N+1 queries on FK columns
  • date_hierarchy adds year/month/day drill-down
  • @admin.display sets a column's header, sort field and boolean icon

A Customized ModelAdmin

@admin.register(Post)
class PostAdmin(admin.ModelAdmin):
    list_display = ["title", "author", "status", "created", "is_live"]
    list_display_links = ["title"]
    list_editable = ["status"]
    list_filter = ["status", "created",
                   ("author", admin.RelatedOnlyFieldListFilter)]
    search_fields = ["title", "body", "author__username"]
    date_hierarchy = "created"
    ordering = ["-created"]
    list_per_page = 50
    list_select_related = ["author"]
    prepopulated_fields = {"slug": ["title"]}
    readonly_fields = ["created", "updated"]
    autocomplete_fields = ["author"]
    fieldsets = [
        (None, {"fields": ["title", "slug", "body"]}),
        ("Publishing", {"fields": ["status", "pub_date", "author"]}),
        ("Metadata", {"fields": ["created", "updated"],
                      "classes": ["collapse"]}),
    ]

    @admin.display(boolean=True, description="Live?", ordering="pub_date")
    def is_live(self, obj):
        return obj.is_live

Code Explained

list_editable fields can't also be list_display_links
RelatedOnlyFieldListFilter lists only authors who have posts
prepopulated_fields fills the slug as you type the title
autocomplete_fields needs search_fields on the related admin
classes: ["collapse"] makes a fieldset collapsible

⚠ Common Mistakes

  • A ForeignKey in list_display without list_select_related: one query per row
  • A huge FK dropdown (thousands of users); use autocomplete_fields or raw_id_fields
  • Putting a field in both fields and exclude: ImproperlyConfigured

✓ Tips & Best Practices

  • Add show_facets = admin.ShowFacets.ALWAYS (5.0+) to see filter counts
  • Use readonly_fields for computed values via methods
  • Run manage.py check; admin options are validated at startup

Quick Summary

  • list_display / list_filter / search_fields
  • fieldsets: group the edit form
  • readonly_fields: show, don't edit
  • @admin.display: custom columns
