The HttpRequest Object

request.method · GET · POST · FILES · user · headers · META · build_absolute_uri()

What a View Receives

Every view's first argument is an HttpRequest. It carries the HTTP method, URL, query string (GET), form data (POST), uploads (FILES), cookies, headers and anything middleware attached, such as request.user and request.session. GET and POST are QueryDicts: read-only, dict-like and able to hold several values per key.

Notes

  • request.POST only has form-encoded data; JSON bodies are in request.body
  • request.GET.get("q", "") avoids KeyError on missing params
  • getlist("tag") returns every value for repeated keys
  • request.headers is case-insensitive: headers["User-Agent"]
  • request.user is AnonymousUser when nobody is logged in

Reading Request Data

import json

def search(request):                 # GET /search/?q=django&tag=web&tag=py
    request.method                   # 'GET'
    request.path                     # '/search/'
    request.get_full_path()          # '/search/?q=django&tag=web&tag=py'
    request.GET.get("q", "")         # 'django'
    request.GET["tag"]               # 'py'  (last value)
    request.GET.getlist("tag")       # ['web', 'py']
    request.GET.urlencode()          # 'q=django&tag=web&tag=py'
    request.headers["Accept-Language"]   # 'en-US,en;q=0.9'
    request.COOKIES.get("theme")     # 'dark' or None
    request.user.is_authenticated    # True / False
    request.build_absolute_uri()     # 'https://example.com/search/?q=...'
    request.is_secure()              # True over HTTPS

def api_create(request):             # POST with a JSON body
    data = json.loads(request.body)  # bytes -> dict
    ip = request.META.get("REMOTE_ADDR")

Code Explained

request.GET[key] returns the last value; getlist returns all
get_full_path() includes the query string; path does not
request.body is raw bytes; read it before touching POST for JSON
META holds CGI-style keys like REMOTE_ADDR, HTTP_HOST
Make a mutable copy with request.GET.copy()

⚠ Common Mistakes

  • Expecting JSON in request.POST; it's empty for application/json, parse request.body
  • Using request.GET["q"] without a default; a missing param raises MultiValueDictKeyError
  • Trusting REMOTE_ADDR behind a proxy; it is the proxy's IP, not the client's

✓ Tips & Best Practices

  • Validate query params with a Form instead of manual parsing
  • Use request.headers rather than META["HTTP_..."] names
  • request.accepts("application/json") lets one view serve HTML and JSON

Quick Summary

  • request.GET / POST: QueryDicts
  • request.body: raw bytes (JSON)
  • request.user: current user
  • build_absolute_uri(): full URL
