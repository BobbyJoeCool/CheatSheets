Running Django in Production

In production Django runs behind an application server: Gunicorn for WSGI, or Uvicorn/Daphne for ASGI. A reverse proxy (Nginx, Caddy or the platform's load balancer) handles TLS and slow clients. Static files are collected and served by WhiteNoise or a CDN. Configuration comes from environment variables, and each deploy runs migrations and collectstatic.

Notes

  • Typical worker count: 2 × CPU cores + 1
  • Run migrate once per deploy, not per worker
  • Health check endpoint: a tiny view returning 200
  • PaaS options: Fly.io, Render, Railway, Heroku; or a VPS with Docker
  • Use PostgreSQL in production, not SQLite, for multi-user sites

Deploy Steps

pip install -r requirements.txt
python manage.py check --deploy
python manage.py collectstatic --noinput
python manage.py migrate --noinput
gunicorn config.wsgi:application --bind 0.0.0.0:8000 --workers 3
# or ASGI:
gunicorn config.asgi:application -k uvicorn_worker.UvicornWorker

WhiteNoise + Env Settings

MIDDLEWARE.insert(1, "whitenoise.middleware.WhiteNoiseMiddleware")
STORAGES["staticfiles"] = {"BACKEND":
    "whitenoise.storage.CompressedManifestStaticFilesStorage"}
DATABASES = {"default": dj_database_url.config(conn_max_age=600)}

Dockerfile

FROM python:3.13-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
RUN python manage.py collectstatic --noinput
CMD ["gunicorn", "config.wsgi:application", "--bind", "0.0.0.0:8000"]

Code Explained

WhiteNoise goes right after SecurityMiddleware
dj-database-url reads DATABASE_URL from the environment
conn_max_age keeps DB connections open between requests
uvicorn_worker runs Uvicorn under Gunicorn's process manager
Build static files into the image; run migrations at release time

⚠ Common Mistakes

  • Running runserver in production; it isn't built for load or security
  • Each container running migrate on start, causing race conditions
  • Forgetting CSRF_TRUSTED_ORIGINS behind HTTPS, so every form POST fails

✓ Tips & Best Practices

  • Keep settings twelve-factor style: everything that varies comes from env
  • Set CONN_MAX_AGE or use a pooler (PgBouncer, 5.1+ pool option)
  • Automate deploys from CI so every release runs the same steps

Quick Summary

  • Gunicorn (WSGI) / Uvicorn (ASGI)
  • WhiteNoise or CDN: static files
  • Env vars: secrets and config
  • collectstatic + migrate each deploy
