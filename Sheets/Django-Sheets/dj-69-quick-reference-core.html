⚠ Common Mistakes

  • Forgetting include() namespaces, so {% url %} names collide between apps
  • Mixins after the base view (class V(DetailView, LoginRequiredMixin)) — put mixins first
  • Marking user input |safe and opening an XSS hole

✓ Tips & Best Practices

  • Name every URL and always reverse — never hard-code paths
  • Use get_object_or_404 instead of try/except DoesNotExist in views
  • Start with generic CBVs; drop to function views when they fight you

Quick Summary

  • urls.py → view → template, wired by names
  • render, redirect, get_object_or_404
  • Generic CBVs for CRUD screens
  • {% extends %} + {% block %} for layouts
