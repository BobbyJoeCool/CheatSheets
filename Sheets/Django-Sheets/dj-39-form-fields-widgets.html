Form Fields & Widgets

CharField · EmailField · ChoiceField · widget= · attrs · TextInput · Select · as_div

Fields Validate, Widgets Render

Each form field validates and converts one input (string → int, date, Decimal…). Each field has a default widget, the class that renders its HTML. Swap widgets with widget= and add HTML attributes (CSS classes, placeholders) with attrs. Field arguments control labels, help text, initial values and whether the field is required.

Notes

  • All fields are required=True by default
  • ChoiceField needs choices; ModelChoiceField uses a QuerySet
  • TypedChoiceField(coerce=int) converts the chosen value
  • Use DateInput(attrs={"type": "date"}) for a native date picker
  • Disabled fields ignore submitted data and use initial

Fields and Widgets

from django import forms

class SignupForm(forms.Form):
    username = forms.CharField(min_length=3, max_length=30,
        widget=forms.TextInput(attrs={"placeholder": "ann_dev",
                                      "class": "input"}))
    email = forms.EmailField(label="Email address",
                             help_text="We never share it.")
    password = forms.CharField(widget=forms.PasswordInput)
    age = forms.IntegerField(min_value=13, required=False)
    birthday = forms.DateField(widget=forms.DateInput(attrs={"type": "date"}))
    plan = forms.ChoiceField(choices=[("free", "Free"), ("pro", "Pro")],
                             widget=forms.RadioSelect, initial="free")
    topics = forms.MultipleChoiceField(choices=TOPICS,
                                       widget=forms.CheckboxSelectMultiple)
    country = forms.ModelChoiceField(queryset=Country.objects.all(),
                                     empty_label="Choose...")
    terms = forms.BooleanField(label="I accept the terms")

form.cleaned_data["age"]       # 30 (int) or None
form.cleaned_data["country"]   # <Country: Canada>

Code Explained

attrs become HTML attributes on the rendered input
PasswordInput doesn't re-fill its value on error
RadioSelect / CheckboxSelectMultiple change the look, not the data
ModelChoiceField returns a model instance in cleaned_data
A required BooleanField must be checked to validate

⚠ Common Mistakes

  • Expecting ChoiceField to return an int; it returns a string unless you use TypedChoiceField
  • Setting widget=forms.Textarea() on an IntegerField; widget changes don't change cleaning
  • Building a ModelChoiceField queryset at import time with user-specific filters; set it in __init__

✓ Tips & Best Practices

  • Set queryset per request: self.fields["country"].queryset = ... in __init__
  • Add CSS classes for all fields in a loop over self.fields in __init__
  • Use forms.URLField / EmailField rather than regex on CharField

Quick Summary

  • Field = validation + type
  • Widget = HTML rendering
  • attrs={...}: HTML attributes
  • ModelChoiceField(queryset=): pick a row
