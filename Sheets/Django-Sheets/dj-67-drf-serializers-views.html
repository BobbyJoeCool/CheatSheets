Building JSON APIs

Django REST Framework (DRF) is the standard third-party package for APIs. Serializers convert model instances to JSON and validate incoming data, much like forms. Views and ViewSets handle requests; a ModelViewSet gives full CRUD in a few lines, and a router generates its URLs. Authentication, permissions, pagination and a browsable HTML API are built in.

Notes

  • Install djangorestframework and add "rest_framework" to INSTALLED_APPS
  • ModelSerializer builds fields from a model like ModelForm
  • serializer.is_valid(raise_exception=True) returns 400 automatically
  • Global defaults live in the REST_FRAMEWORK setting
  • Django Ninja is a popular type-hint-based alternative

Serializer, ViewSet, Router

from rest_framework import serializers, viewsets, permissions
from rest_framework.routers import DefaultRouter

class PostSerializer(serializers.ModelSerializer):
    author = serializers.ReadOnlyField(source="author.username")
    class Meta:
        model = Post
        fields = ["id", "title", "body", "author", "created"]
        read_only_fields = ["created"]

class PostViewSet(viewsets.ModelViewSet):
    serializer_class = PostSerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]
    def get_queryset(self):
        return Post.objects.select_related("author").order_by("-created")
    def perform_create(self, serializer):
        serializer.save(author=self.request.user)

router = DefaultRouter()
router.register("posts", PostViewSet, basename="post")
urlpatterns = [path("api/", include(router.urls))]

Code Explained

source="author.username" reads a nested attribute
ModelViewSet provides list, create, retrieve, update, destroy
perform_create sets server-side fields on save
The router creates /api/posts/ and /api/posts/<pk>/
IsAuthenticatedOrReadOnly: anyone reads, users write

⚠ Common Mistakes

  • fields = "__all__" on serializers, exposing internal fields
  • Nested serializers without select_related / prefetch_related: N+1 queries
  • Accepting author from the client instead of setting it in perform_create

✓ Tips & Best Practices

  • Add drf-spectacular for an OpenAPI schema and Swagger UI
  • Use token or session auth for first-party apps; JWT via simplejwt if needed
  • Write object-level permissions with has_object_permission()
