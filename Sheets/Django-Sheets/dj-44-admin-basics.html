The Built-in Admin

django.contrib.admin generates a full CRUD interface from your models. Register a model in the app's admin.py, create a superuser, and visit /admin/. It is meant for trusted staff, not end users. Only accounts with is_staff = True can log in, and they see only the models their permissions allow.

Notes

  • The admin URL is wired in config/urls.py as path("admin/", admin.site.urls)
  • Model __str__ is what the admin shows for each row
  • verbose_name / verbose_name_plural set the labels
  • Superusers have every permission automatically
  • 6.0: admin icons now come from Font Awesome Free

Register Models

# blog/admin.py
from django.contrib import admin
from .models import Post, Tag

admin.site.register(Tag)                       # default options

@admin.register(Post)                          # with options (Sheet 45)
class PostAdmin(admin.ModelAdmin):
    list_display = ["title", "status", "created"]

# config/urls.py — customize the site
admin.site.site_header = "Blog Administration"
admin.site.site_title = "Blog Admin"
admin.site.index_title = "Dashboard"
urlpatterns = [path("manage/", admin.site.urls)]   # move off /admin/

Create an Admin User

python manage.py createsuperuser
# Username: ann   Email: ann@example.com   Password: ********
python manage.py runserver   # then open http://127.0.0.1:8000/manage/

Code Explained

register(Model) uses a plain ModelAdmin
@admin.register attaches a customized ModelAdmin
site_header shows in the top bar and login page
Changing the URL prefix reduces automated login attacks
The admin needs auth, contenttypes, sessions and messages

⚠ Common Mistakes

  • Building the customer-facing site on the admin; it's for staff workflows
  • Leaving /admin/ with a weak superuser password on a public server
  • No __str__ on models, so every row shows as "Post object (1)"

✓ Tips & Best Practices

  • Give staff accounts only the permissions they need, via groups
  • Override templates/admin/base_site.html for branding
  • Add 2FA with django-otp or similar for admin logins

Quick Summary
