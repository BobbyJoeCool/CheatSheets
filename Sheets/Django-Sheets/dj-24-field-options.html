Field Options

null · blank · default · unique · choices · db_index · verbose_name · help_text

Options Every Field Accepts

Field options fine-tune a column. null is about the database (can the column hold NULL?), while blank is about validation (can a form leave it empty?). choices limits values and gives readable labels through get_FOO_display(). Others add uniqueness, indexes, defaults and the labels shown in forms and the admin.

Notes

  • For text fields use blank=True alone; empty string means "no value"
  • null=True, blank=True is the usual pair for optional non-text fields
  • default can be a value or a callable like timezone.now
  • db_default (5.0+) sets the default in the database itself
  • editable=False hides a field from forms and the admin

Options in Practice

from django.db import models
from django.db.models.functions import Now
from django.utils import timezone

class Order(models.Model):
    class Status(models.TextChoices):
        PENDING = "P", "Pending"
        SHIPPED = "S", "Shipped"
        CANCELLED = "C", "Cancelled"

    number = models.CharField(max_length=20, unique=True)
    status = models.CharField(max_length=1, choices=Status,
                              default=Status.PENDING, db_index=True)
    note = models.TextField(blank=True, help_text="Shown on the invoice")
    shipped_at = models.DateTimeField(null=True, blank=True)
    placed_at = models.DateTimeField(default=timezone.now)
    created = models.DateTimeField(db_default=Now())
    code = models.CharField("Promo code", max_length=10, blank=True)

o = Order(number="A-1")
o.status                          # 'P'
o.get_status_display()            # 'Pending'
Order.Status.SHIPPED.label        # 'Shipped'
Order.objects.filter(status=Order.Status.SHIPPED)

Code Explained

TextChoices members store the first value, display the second
5.0+: pass the enum class directly as choices=
default=timezone.now (no parentheses) runs per row
db_default=Now() lets the DB fill the value on INSERT
First positional argument is verbose_name

⚠ Common Mistakes

  • null=True on a CharField; you get two "empty" values: None and ""
  • default=timezone.now() with parentheses; every row gets the server start time
  • Thinking choices adds a DB constraint; it only validates in forms and full_clean()

✓ Tips & Best Practices

  • Add a CheckConstraint if choices must be enforced in the database
  • Use help_text generously; it appears in forms and the admin
  • Put choices classes inside the model so they travel with it

Quick Summary

  • null: database; blank: forms
  • choices=TextChoices: labeled values
  • default vs db_default: Python vs DB
  • unique / db_index: constraints, speed
