Test Client & Fixtures

self.client · get() / post() · force_login() · assertRedirects · fixtures · RequestFactory · override_settings

Testing Views End to End

The test client (self.client) acts like a browser without a server: it sends requests through URLs, middleware and views and returns the response with extra attributes such as context and templates. Log users in instantly with force_login(). RequestFactory builds bare requests to call a view directly. Fixtures, mocks and override_settings control the environment.

Notes

  • response.context["form"] lets you inspect template variables
  • follow=True follows redirects and records redirect_chain
  • The test client skips CSRF checks by default
  • mail.outbox collects emails sent during tests
  • captureOnCommitCallbacks runs on_commit hooks in TestCase

Client Tests

from django.core import mail
from django.test import TestCase, RequestFactory, override_settings

class PostViewTests(TestCase):
    fixtures = ["users.json"]                     # loaded per test class

    def setUp(self):
        self.user = User.objects.get(username="ann")
        self.client.force_login(self.user)
    def test_create_redirects(self):
        resp = self.client.post(reverse("blog:create"),
                                {"title": "New", "body": "Text"})
        post = Post.objects.get(title="New")
        self.assertRedirects(resp, post.get_absolute_url())

    def test_invalid_form(self):
        resp = self.client.post(reverse("blog:create"), {"title": ""})
        self.assertFormError(resp.context["form"], "title",
                             "This field is required.")
    @override_settings(DEFAULT_FROM_EMAIL="t@x.io")  # temp setting
    def test_email(self):                         # locmem backend in tests
        self.client.post(reverse("contact"), {"msg": "Hi"})
        self.assertEqual(len(mail.outbox), 1)
    def test_view_directly(self):
        request = RequestFactory().get("/dash/")
        request.user = self.user
        self.assertEqual(dashboard(request).status_code, 200)

Code Explained

force_login skips the password check (fast)
assertRedirects also fetches the target and checks it loads
post(url, data, content_type="application/json") sends JSON
resp.json() parses a JSON response
RequestFactory skips middleware: set request.user yourself

⚠ Common Mistakes

  • Relying on large JSON fixtures that break every time a model changes
  • Using RequestFactory and expecting request.user or session to exist
  • Comparing resp.content byte strings instead of using assertContains

✓ Tips & Best Practices

  • Prefer factories over fixtures; they adapt to model changes
  • Use self.client.get(url, headers={"accept": "application/json"}) for header tests
  • Use freezegun or time-machine to control timezone.now()

Quick Summary
