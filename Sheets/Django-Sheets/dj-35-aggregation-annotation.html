Aggregation & Annotation

aggregate() · annotate() · Count · Sum · Avg · values() + annotate() GROUP BY · Subquery · OuterRef

Summaries and Computed Columns

aggregate() returns a dict of totals over the whole QuerySet. annotate() adds a computed value to each row, often a count or sum of related objects. Put values() before annotate() to group by those fields (SQL GROUP BY). Subquery and OuterRef embed a correlated query, such as each author's latest post title.

Notes

  • Annotations can be filtered and ordered like fields
  • Count("x", distinct=True) avoids double counting across joins
  • filter=Q(...) on an aggregate counts only matching rows
  • Default ordering can break GROUP BY; clear it with order_by()
  • 6.0: StringAgg works on every database; AnyValue is new

Aggregates in Practice

from django.db.models import Count, Sum, Avg, Max, Q, OuterRef, Subquery

Order.objects.aggregate(total=Sum("amount"), avg=Avg("amount"))
# {'total': Decimal('9120.50'), 'avg': Decimal('45.60')}

authors = Author.objects.annotate(
    n_posts=Count("post"),
    n_live=Count("post", filter=Q(post__status="P")),
).filter(n_posts__gte=5).order_by("-n_posts")
authors[0].n_posts                                  # 42

# GROUP BY status
Post.objects.values("status").annotate(n=Count("id")).order_by()
# <QuerySet [{'status': 'D', 'n': 7}, {'status': 'P', 'n': 30}]>

# GROUP BY month
from django.db.models.functions import TruncMonth
Order.objects.annotate(m=TruncMonth("created")).values("m") \
     .annotate(total=Sum("amount")).order_by("m")

# correlated subquery: newest post title per author
newest = Post.objects.filter(author=OuterRef("pk")).order_by("-created")
Author.objects.annotate(latest=Subquery(newest.values("title")[:1]))

Code Explained

aggregate keys are the names you give (total, avg)
filter=Q(...) → COUNT(...) FILTER (WHERE ...)
Filtering on an annotation becomes HAVING
Empty order_by() stops Meta.ordering adding GROUP BY columns
OuterRef("pk") points at the outer query's row

⚠ Common Mistakes

  • Two Counts over different joins multiply each other; add distinct=True or use subqueries
  • values().annotate() with model ordering set, producing one group per row
  • aggregate(Sum(...)) on no rows returns None; use default=0 (4.0+)

✓ Tips & Best Practices

  • Use Sum("amount", default=0) to avoid None checks
  • Annotate counts in list views instead of calling .count() per row
  • Check heavy queries with qs.explain(analyze=True) on PostgreSQL

Quick Summary

  • aggregate(): dict of totals
  • annotate(): per-row computed value
  • values(...).annotate(...): GROUP BY
  • Subquery(OuterRef): per-row subquery
