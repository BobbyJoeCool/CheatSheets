View · as_view() · dispatch() · get() / post() · TemplateView · RedirectView

Views as Classes

A class-based view (CBV) maps each HTTP method to a method on a class: get(), post(), put() and so on. as_view() turns the class into a callable for the URLconf; on each request it creates a new instance, stores request, args and kwargs on self, then dispatch() calls the method that matches request.method. Unhandled methods return 405.

Notes

  • Class attributes are defaults; pass overrides to as_view(template_name=...)
  • Each request gets a fresh instance, so self state is per-request
  • URL captures are in self.kwargs["pk"]
  • setup() runs before dispatch(); override it to set shared attributes
  • Generic CBVs (Sheets 13–14) build on these base classes

View, TemplateView, RedirectView

from django.http import HttpResponse, JsonResponse
from django.views import View
from django.views.generic import TemplateView, RedirectView

class PingView(View):
    http_method_names = ["get", "post"]
    def get(self, request, *args, **kwargs):
        return JsonResponse({"pong": True})
    def post(self, request, *args, **kwargs):
        return HttpResponse(status=204)

class AboutView(TemplateView):
    template_name = "about.html"
    def get_context_data(self, **kwargs):
        ctx = super().get_context_data(**kwargs)    # includes URL kwargs
        ctx["team"] = Member.objects.all()
        return ctx

# urls.py
urlpatterns = [
    path("ping/", PingView.as_view()),
    path("about/", AboutView.as_view(), name="about"),
    path("terms/", TemplateView.as_view(template_name="terms.html")),
    path("old/", RedirectView.as_view(pattern_name="about", permanent=True)),
]

Code Explained

Always register ClassName.as_view(), never the bare class
http_method_names limits allowed methods (others → 405)
get_context_data must call super() to keep base context
as_view(template_name=...) sets attributes without subclassing
RedirectView(pattern_name=...) reverses a named URL

UseWhen

Generic CBVCRUD on a model

⚠ Common Mistakes

  • path("x/", PingView) without .as_view(): TypeError on every request
  • Storing per-user data on a class attribute; it is shared by all requests
  • Overriding get_context_data without super(), which drops view and URL kwargs

✓ Tips & Best Practices

  • Start with FBVs; switch to CBVs when you see repeated GET/POST structure
  • Use ccbv.co.uk to see every attribute and method a CBV inherits
  • Override dispatch() for checks that apply to every HTTP method

Quick Summary

  • View: method → handler
  • as_view(): URLconf callable
  • TemplateView: template + context
  • RedirectView: simple redirects
