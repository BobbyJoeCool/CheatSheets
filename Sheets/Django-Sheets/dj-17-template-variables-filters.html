{{ var }} · dot lookup · |date · |default · |length · |safe · |linebreaks · autoescape

Variables and Filters

{{ var }} prints a context value. The dot does dictionary lookup, attribute lookup, method call (no arguments) and list index, in that order. Filters transform a value with | and can be chained; some take one argument after a colon. All output is auto-escaped for HTML unless you mark it safe.

Notes

  • {{ user.profile.name }}: attribute chain
  • {{ items.0 }}: list index; {{ d.key }}: dict key
  • Methods are called without arguments: {{ post.get_absolute_url }}
  • Chain filters left to right: {{ name|lower|truncatechars:20 }}
  • |safe turns off escaping: only for trusted HTML

Filters in Use

{{ post.title|title }}                    {# Hello World #}
{{ post.body|truncatewords:30 }}          {# first 30 words... #}
{{ post.created|date:"M j, Y" }}          {# Oct 11, 2026 #}
{{ post.created|timesince }}              {# 3 days, 2 hours #}
{{ comments|length }}                     {# 12 #}
{{ count }} comment{{ count|pluralize }}  {# 1 comment / 2 comments #}
{{ price|floatformat:2 }}                 {# 19.90 #}
{{ bio|default:"No bio yet" }}            {# when falsy #}
{{ middle_name|default_if_none:"" }}      {# only when None #}
{{ body|linebreaks }}                     {# \n -> <p> / <br> #}
{{ tags|join:", " }}                      {# django, python #}
{{ html_snippet|safe }}                   {# no escaping #}
{{ data|json_script:"page-data" }}        {# safe <script> JSON #}
{{ url|urlize }}                          {# clickable links #}
{{ size|filesizeformat }}                 {# 1.2 MB #}

Code Explained

Filter args follow a colon and are quoted if strings
default covers "", 0, None, []; default_if_none only None
date uses PHP-style format letters (Y-m-d, M j)
json_script outputs JSON in a <script> tag safely
safe disables escaping for that one value

⚠ Common Mistakes

  • {{ post.get_comments(5) }}: templates can't pass method arguments
  • Using |safe on user input, which opens an XSS hole
  • Spaces around the colon: {{ x|date : "Y" }} is a syntax error

✓ Tips & Best Practices

  • Pass data to JavaScript with json_script, not {{ data|safe }} inside <script>
  • Use naturaltime / intcomma from django.contrib.humanize for friendly output
  • Prefer default_if_none when 0 or "" are valid values

Quick Summary

  • {{ a.b.c }}: dict/attr/method/index lookup
  • |filter:arg: transform output
  • |default: fallback value
  • |safe: opt out of escaping
