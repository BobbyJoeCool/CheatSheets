Built-in Tags & Control Flow

{% if %} · {% for %} · {% empty %} · forloop · {% with %} · {% csrf_token %} · {% comment %}

Tags for Logic

Tags in {% %} add logic: conditions, loops, URL building, CSRF tokens and more. {% if %} supports and, or, not, comparisons and in. {% for %} loops over any iterable, provides a forloop object and has an {% empty %} branch for empty lists. Block tags always need their closing tag ({% endif %}, {% endfor %}).

Notes

  • No parentheses in {% if %}; nest tags instead
  • {% for k, v in d.items %} unpacks pairs
  • forloop.length (6.0) gives the total number of items
  • {% with %} caches an expensive value for a block
  • {% querystring %} (5.1+) rebuilds the current query string

Control Flow

{% if user.is_authenticated and user.is_staff %}
  <a href="{% url 'admin:index' %}">Admin</a>
{% elif user.is_authenticated %}
  Hi {{ user.first_name|default:user.username }}
{% else %}
  <a href="{% url 'login' %}?next={{ request.path }}">Log in</a>
{% endif %}

<ul>
{% for post in posts %}
  <li class="{% cycle 'odd' 'even' %}">
    {{ forloop.counter }}/{{ forloop.length }} {{ post.title }}
    {% if forloop.last %}(newest){% endif %}
  </li>
{% empty %}
  <li>No posts yet.</li>
{% endfor %}
</ul>

{% with total=order.items.count %}{{ total }} item{{ total|pluralize }}{% endwith %}
<a href="{% querystring page=page_obj.next_page_number %}">Next</a>
<form method="post">{% csrf_token %} ... </form>
{% comment "TODO" %} hidden from output {% endcomment %}

Code Explained

elif / else are optional branches
{% empty %} runs when the iterable has no items
{% cycle %} alternates values on each loop pass
{% with %} evaluates once and names the result
{% csrf_token %} is required in every POST form

⚠ Common Mistakes

  • {% if (a or b) and c %}: parentheses aren't allowed
  • Calling .all in a loop condition repeatedly; use {% with %} or prepare it in the view
  • Leaving out {% csrf_token %} in a POST form: 403 CSRF verification failed

✓ Tips & Best Practices

  • Use {% empty %} instead of a separate {% if posts %} check
  • Use {% querystring %} for pagination links so filters are kept
  • Use {% regroup %} to group a sorted list by a field

Quick Summary

  • {% if %}…{% endif %}: conditions
  • {% for %}…{% empty %}: loops
  • forloop.*: loop state
  • {% with %}: local variable
