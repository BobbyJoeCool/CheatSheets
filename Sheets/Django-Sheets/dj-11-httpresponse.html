Response Types

HttpResponse · JsonResponse · FileResponse · StreamingHttpResponse · HttpResponseRedirect · status codes · Http404

Returning Responses

Every view returns an HttpResponse or a subclass. The base class sends a string or bytes with a content type and status code; subclasses cover JSON, file downloads, streamed output and redirects. Headers are set like dictionary items, and cookies with set_cookie(). Raising Http404 or PermissionDenied returns the matching error page instead.

Notes

  • Default content_type is text/html; charset=utf-8
  • JsonResponse needs a dict unless you pass safe=False
  • FileResponse streams efficiently and sets Content-Length
  • StreamingHttpResponse has no .content; it iterates a generator
  • Use HTTPStatus.CREATED instead of magic numbers like 201

Response Examples

from http import HTTPStatus
from django.http import (HttpResponse, JsonResponse, FileResponse,
    StreamingHttpResponse, HttpResponseRedirect, Http404)
from django.core.exceptions import PermissionDenied

HttpResponse("<h1>Hi</h1>")                         # 200 text/html
HttpResponse("ok", content_type="text/plain")
HttpResponse(status=HTTPStatus.NO_CONTENT)          # 204
JsonResponse({"id": 1, "ok": True})                 # application/json
JsonResponse([1, 2, 3], safe=False)                 # list needs safe=False
JsonResponse({"error": "bad"}, status=400)
FileResponse(open("report.pdf", "rb"), as_attachment=True,
             filename="report.pdf")                 # download
StreamingHttpResponse((f"{row}\n" for row in rows),
                      content_type="text/csv")
HttpResponseRedirect("/login/")                     # 302

resp = HttpResponse("Hi")
resp["Cache-Control"] = "no-store"                  # set a header
resp.set_cookie("theme", "dark", max_age=3600)
raise Http404("Post not found")                     # 404 page
raise PermissionDenied                              # 403 page

Code Explained

status= takes an int or HTTPStatus member
safe=False allows non-dict top-level JSON
FileResponse closes the file for you when done
Generators keep memory flat for big CSV exports
resp["Header"] = value sets any response header

⚠ Common Mistakes

  • Passing a list to JsonResponse without safe=False: TypeError
  • Building JSON with HttpResponse(json.dumps(...)) and forgetting content_type
  • Opening files with open(path) in text mode for FileResponse; use "rb"

✓ Tips & Best Practices

  • Use HttpResponse(status=204) for successful actions with no body
  • Serve user uploads through FileResponse only after a permission check
  • For big exports use StreamingHttpResponse so the worker doesn't buffer everything

Quick Summary

  • HttpResponse(body, status=): base response
  • JsonResponse(dict): JSON
  • FileResponse(f, as_attachment=True): download
  • raise Http404: error page
