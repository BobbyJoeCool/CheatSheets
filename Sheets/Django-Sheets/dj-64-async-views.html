Async Views and the ORM

Views can be async def coroutines. Under an ASGI server they run on the event loop, which helps when a view waits on several slow I/O calls at once (external APIs, streaming). The ORM offers async versions of query methods (prefix a) and async for iteration. Sync-only code must be wrapped with sync_to_async; calling async code from sync code uses async_to_sync.

Notes

  • Under WSGI, async views still work but gain nothing
  • Middleware that is sync-only forces a thread switch per request
  • Transactions aren't async yet; wrap them in a sync function
  • Lazy QuerySet methods (filter) have no a version; evaluation does
  • Use httpx.AsyncClient for concurrent outbound HTTP

Async View with Concurrent Calls

import asyncio, httpx
from asgiref.sync import sync_to_async, async_to_sync
from django.http import JsonResponse

async def dashboard(request):
    async with httpx.AsyncClient(timeout=5) as client:
        weather, news = await asyncio.gather(
            client.get("https://api.example.com/weather"),
            client.get("https://api.example.com/news"))
    user = await request.auser()                     # async user lookup
    post = await Post.objects.filter(author=user).afirst()
    count = await Post.objects.acount()
    titles = [p.title async for p in Post.objects.order_by("-id")[:5]]
    return JsonResponse({"weather": weather.json(), "posts": count,
                         "titles": titles})

Code Explained

asyncio.gather runs both requests at the same time
request.auser() (5.0+) loads the user without blocking
afirst, acount, aget, acreate are awaitable
async for iterates a QuerySet asynchronously
sync_to_async runs blocking code in a thread

⚠ Common Mistakes

  • Calling sync ORM methods inside async def: SynchronousOnlyOperation
  • Using requests in an async view; it blocks the event loop, use httpx
  • Making every view async under WSGI and expecting a speedup

✓ Tips & Best Practices

  • Go async only for views that wait on I/O; keep the rest sync
  • Use StreamingHttpResponse with an async generator for server-sent events
  • Use Django Channels for WebSockets

Quick Summary

  • async def view: runs on the event loop
  • aget / acount / async for: async ORM
  • sync_to_async: call sync code
  • ASGI server: Uvicorn, Daphne
