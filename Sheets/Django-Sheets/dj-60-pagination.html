Splitting Lists into Pages

Paginator slices any list or QuerySet into pages. get_page(number) is forgiving: it returns the first page for junk input and the last page for numbers too high. The Page object it returns is iterable and knows its neighbors. ListView does all of this for you when you set paginate_by, adding page_obj and paginator to the context.

Notes

  • Paginate an ordered QuerySet; otherwise pages can repeat rows
  • Each page runs a COUNT(*) plus a LIMIT/OFFSET query
  • page(n) raises EmptyPage / PageNotAnInteger; get_page(n) doesn't
  • orphans=3 folds a tiny last page into the previous one
  • Use {% querystring %} to keep filters in page links

View

from django.core.paginator import Paginator

def post_list(request):
    qs = Post.objects.published().order_by("-created")
    paginator = Paginator(qs, 20, orphans=3)
    page_obj = paginator.get_page(request.GET.get("page"))
    return render(request, "blog/list.html", {"page_obj": page_obj})

page_obj.number                    # 3
paginator.num_pages                # 12
paginator.count                    # 231 rows
page_obj.start_index()             # 41
paginator.get_elided_page_range(3, on_each_side=2)  # 1 2 3 4 5 … 11 12

Template

{% for post in page_obj %}<p>{{ post.title }}</p>{% endfor %}
<nav>
  {% if page_obj.has_previous %}
    <a href="{% querystring page=page_obj.previous_page_number %}">‹ Prev</a>
  {% endif %}
  Page {{ page_obj.number }} of {{ page_obj.paginator.num_pages }}
  {% if page_obj.has_next %}
    <a href="{% querystring page=page_obj.next_page_number %}">Next ›</a>
  {% endif %}
</nav>

Code Explained

get_page(None) and get_page("abc") return page 1
Iterate page_obj directly for the rows on that page
get_elided_page_range adds … for long page lists
{% querystring page=... %} keeps ?q= and other params
In ListView, just set paginate_by = 20

⚠ Common Mistakes

  • Paginating an unordered QuerySet: UnorderedObjectListWarning, rows shift between pages
  • Building links with ?page=2, which drops the search filters
  • Deep OFFSET pages on million-row tables; switch to keyset pagination

✓ Tips & Best Practices

  • Reuse one _pagination.html include across the site
  • Use get_elided_page_range for compact page lists
  • Add rel="next" / rel="prev" for accessibility and crawlers
