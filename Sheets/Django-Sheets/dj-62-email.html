Email from Django

send_mail() sends a simple message in one call, while EmailMessage and EmailMultiAlternatives give full control: CC, BCC, reply-to, HTML versions and attachments. Delivery goes through the configured email backend: SMTP in production, the console backend in development and the in-memory backend in tests. Django 6.0 moved to Python's modern email API; 6.1 adds the MAILERS setting for multiple backends.

Notes

  • Console backend prints emails to the terminal: perfect for dev
  • Tests automatically use locmem; read mail.outbox
  • Use keyword arguments; 6.0 deprecates extra positional ones
  • Send from a background task so requests don't wait on SMTP
  • Transactional services (SES, Postmark) via django-anymail

Settings and Sending

# settings.py
EMAIL_BACKEND = "django.core.mail.backends.smtp.EmailBackend"
EMAIL_HOST = "smtp.example.com"
EMAIL_PORT = 587
EMAIL_USE_TLS = True
EMAIL_HOST_USER = os.environ["SMTP_USER"]
EMAIL_HOST_PASSWORD = os.environ["SMTP_PASSWORD"]
DEFAULT_FROM_EMAIL = "Shop <no-reply@example.com>"

from django.core.mail import send_mail, EmailMultiAlternatives
from django.template.loader import render_to_string

send_mail(subject="Welcome!", message="Thanks for joining.",
          from_email=None, recipient_list=["ann@example.com"])

ctx = {"order": order}
msg = EmailMultiAlternatives(
    subject=f"Order #{order.pk}",
    body=render_to_string("emails/order.txt", ctx),
    to=[order.email], reply_to=["support@example.com"])
msg.attach_alternative(render_to_string("emails/order.html", ctx), "text/html")
msg.attach("invoice.pdf", pdf_bytes, "application/pdf")
msg.send()

Code Explained

from_email=None uses DEFAULT_FROM_EMAIL
Always include a plain-text body with the HTML version
attach(name, content, mimetype) adds a file
send() returns the number of messages sent
Render email bodies from templates, like pages

⚠ Common Mistakes

  • Setting both EMAIL_USE_TLS and EMAIL_USE_SSL; pick the one your port uses
  • Sending email inside the request; slow SMTP makes pages hang
  • Putting SMTP passwords in settings.py instead of the environment

✓ Tips & Best Practices

  • Send via django.tasks or Celery, after commit with on_commit
  • Use django-anymail to switch providers without code changes
  • Preview HTML emails with the file-based backend
