Inlines & Custom Actions

TabularInline · StackedInline · @admin.action · queryset actions · get_queryset() · has_*_permission

Related Rows and Bulk Actions

Inlines edit child objects on the parent's page, such as order items inside an order. TabularInline uses a compact table and StackedInline a full form per row. Actions run on rows selected in the change list, like "Mark as published". Override hook methods to filter visible rows or tighten permissions per user.

Notes

  • Inlines need a ForeignKey from child to parent
  • extra controls how many blank inline rows appear
  • Actions receive (modeladmin, request, queryset)
  • Report results with self.message_user()
  • delete_selected is the one built-in action

Inlines, Actions, Hooks

class OrderItemInline(admin.TabularInline):
    model = OrderItem
    extra = 1
    fields = ["product", "quantity", "price"]

@admin.register(Order)
class OrderAdmin(admin.ModelAdmin):
    inlines = [OrderItemInline]
    actions = ["mark_shipped"]

    @admin.action(description="Mark selected orders as shipped",
                  permissions=["change"])
    def mark_shipped(self, request, queryset):
        n = queryset.update(status="S", shipped_at=timezone.now())
        self.message_user(request, f"{n} orders shipped.", messages.SUCCESS)

    def get_queryset(self, request):          # staff see their region only
        qs = super().get_queryset(request)
        if request.user.is_superuser:
            return qs
        return qs.filter(region=request.user.region)

Code Explained

inlines lists inline classes shown under the main form
permissions=["change"] hides the action from users without change perm
queryset is exactly the rows the user ticked
get_queryset limits the change list and object access
save_model(request, obj, form, change) sets fields on save

⚠ Common Mistakes

  • Actions using queryset.update() and expecting save() / signals to run
  • Filtering get_queryset but not formfield_for_foreignkey, so dropdowns leak other regions
  • Too many inline rows with FK dropdowns; each row repeats the choice query

✓ Tips & Best Practices

  • Loop and call obj.save() in actions when signals or save() logic matter
  • Return an HttpResponseRedirect from an action to show a confirmation page
  • Use TabularInline for short rows, StackedInline for wide forms

Quick Summary

  • TabularInline / StackedInline: child rows
  • @admin.action: bulk operations
  • get_queryset(): per-user rows
  • has_*_permission(): fine-grained access
