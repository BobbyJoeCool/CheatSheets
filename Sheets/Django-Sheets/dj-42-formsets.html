formset_factory · modelformset_factory · inlineformset_factory · management_form · extra · can_delete

Many Forms on One Page

A formset manages several copies of the same form, such as rows of order items. Factories build the formset class: formset_factory for plain forms, modelformset_factory for a QuerySet and inlineformset_factory for children of one parent object. Every formset renders a hidden management form that tells Django how many forms were submitted.

Notes

  • extra = number of blank forms added for new rows
  • can_delete=True adds a DELETE checkbox to each form
  • min_num / max_num with validate_min / validate_max enforce limits
  • Formset-level checks go in a BaseFormSet.clean() override
  • Adding rows in JavaScript means cloning the empty form and bumping TOTAL_FORMS

Inline Formset for Order Items

from django.forms import inlineformset_factory

ItemFormSet = inlineformset_factory(
    Order, OrderItem,                    # parent, child
    fields=["product", "quantity"],
    extra=2, can_delete=True, min_num=1, validate_min=True,
)

def order_edit(request, pk):
    order = get_object_or_404(Order, pk=pk)
    form = OrderForm(request.POST or None, instance=order)
    formset = ItemFormSet(request.POST or None, instance=order)
    if form.is_valid() and formset.is_valid():
        with transaction.atomic():
            form.save()
            formset.save()               # creates, updates, deletes rows
        return redirect(order)
    return render(request, "orders/edit.html",
                  {"form": form, "formset": formset})

Template

<form method="post">{% csrf_token %}
  {{ form }}
  {{ formset.management_form }}
  {% for f in formset %}<div class="item">{{ f }}</div>{% endfor %}
  <button>Save</button>
</form>

Code Explained

The inline formset sets the FK to order for you
min_num=1, validate_min=True requires at least one item
Validate both form and formset before saving either
formset.save() handles new, changed and deleted rows
{{ formset.empty_form }} gives a blank row (__prefix__ index) for JS

⚠ Common Mistakes

  • Leaving out {{ formset.management_form }}: "ManagementForm data is missing"
  • Saving the parent form before checking formset.is_valid(), leaving partial data
  • Adding forms in JS without updating TOTAL_FORMS, so new rows are ignored

✓ Tips & Best Practices

  • Wrap parent + formset saves in transaction.atomic()
  • Use prefix= when a page has more than one formset
  • For dynamic rows, consider htmx partials instead of hand-written JS

Quick Summary

  • formset_factory(Form, extra=): many forms
  • inlineformset_factory(Parent, Child): children
  • management_form: required hidden fields
  • formset.save(): create/update/delete
