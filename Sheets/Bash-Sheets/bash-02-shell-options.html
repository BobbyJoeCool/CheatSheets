Sheet 02

Shell Options (set & shopt)

set -o · set +o · shopt -s · shopt -u · globstar · nullglob · $-

Two Option Systems

Bash has two sets of on/off switches. set controls the POSIX options (single letters like -e, or long names with -o name): a minus turns an option on and a plus turns it off, which feels backwards at first. shopt controls bash-only options: -s sets, -u unsets. Options apply to the current shell and are inherited by subshells, so setting them inside a script never changes your interactive shell.

Notes

  • set -o / shopt with no args list every option and its state
  • $- holds active single-letter flags; $SHELLOPTS / $BASHOPTS hold the long names
  • set -euo pipefail (strict mode) is covered on Sheet 22
  • Put interactive options in ~/.bashrc, script options at the top of the script

set & shopt in Action

set -o                         # list set options with on/off
set -o noclobber               # same as: set -C
echo hi > notes.txt            # bash: notes.txt: cannot overwrite existing file
echo hi >| notes.txt           # >| overrides noclobber once
set +o noclobber               # + turns it back OFF

echo "$-"                      # himBHs   (flags active in this shell)
shopt                          # list all shopt options
shopt -s globstar nullglob     # enable two at once
shopt -u nullglob              # disable
shopt -q extglob && echo on    # -q: no output, just exit status
shopt -p globstar              # shopt -s globstar  (re-runnable line)

# Temporarily change set options inside a function (bash 4.4+)
f() { local -; set -f; echo *; }   # prints *  ; noglob reverts on return

Code Explained

set -o name / set +o name — long-name form; easier to read than letters
>| — force a single overwrite while noclobber is on
$- — h hashall, i interactive, m job control, B brace expansion, H history
shopt -q — use in if to test an option without output
shopt -p — prints commands that recreate the current state; save and replay
local - — saves set options and restores them when the function returns

⚠ Common Mistakes

  • Reading set -e as "off": in set, - means on and + means off
  • Enabling shopt -s extglob inside a function that uses the patterns: it must be on before the code is parsed
  • Turning on nullglob globally, then ls *.txt lists everything when nothing matches
  • Expecting set in a script to persist after it exits; it only affects that process

✓ Tips & Best Practices

  • Use long names in scripts (set -o pipefail); they document themselves
  • Save and restore state: old=$(shopt -p nullglob) … eval "$old"
  • shopt -s checkwinsize histappend belongs in every interactive ~/.bashrc
  • Use failglob in scripts to catch typos in file patterns early

Quick Summary

  • set -o x / set +o x — turn a POSIX option on / off
  • shopt -s x / shopt -u x — turn a bash option on / off
  • shopt -q x — test an option
  • local - — scope set options to a function
