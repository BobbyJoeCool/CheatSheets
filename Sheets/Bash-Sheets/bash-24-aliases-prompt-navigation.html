Sheet 24

Aliases, Prompt & Navigation

alias · \cmd · PS1 · \u \h \w · PROMPT_COMMAND · pushd / popd · CDPATH

Making the Shell Yours

An alias is a text shortcut expanded when you type a command; for anything that needs arguments in the middle or logic, write a function instead. PS1 defines the prompt using backslash escapes, and PROMPT_COMMAND runs before each prompt is drawn. The directory stack (pushd, popd) and CDPATH make moving between project folders fast.

Notes

  • Aliases are off in scripts unless shopt -s expand_aliases
  • Wrap non-printing color codes in \[ \] or line wrapping breaks
  • Put aliases and PS1 in ~/.bashrc (Sheet 01)
  • PROMPT_COMMAND can be an array in bash 5.1+

~/.bashrc Customizations

alias ll='ls -alF'
alias gs='git status'
alias rm='rm -i'                  # confirm before deleting
\rm temp.txt                      # backslash skips the alias once
command rm temp.txt               # so does `command`
unalias gs                        # remove an alias
alias                             # list all aliases

PS1='\u@\h:\w\$ '                 # ada@laptop:~/src$
PS1='\[\e[32m\]\u\[\e[0m\]:\[\e[34m\]\w\[\e[0m\]\$ '   # green user, blue dir
PROMPT_COMMAND='printf "\e]0;%s\a" "${PWD##*/}"'       # dir in window title

pushd /etc > /dev/null            # cd, remembering where you were
popd                              # go back
cd -                              # toggle to the previous directory
CDPATH=.:~/projects               # `cd api` finds ~/projects/api

Code Explained

\rm / command rm — run the real command, skipping the alias
\u \h \w — user, short host name, working directory
\[ … \] — tells bash these bytes take no space on screen
\e[32m — ANSI color: 32 green, 34 blue, 0 reset
\e]0;…\a — escape sequence that sets the terminal title
CDPATH — extra directories cd searches for relative names

⚠ Common Mistakes

  • Aliases that take arguments mid-command (alias g='grep $1 file'); aliases only prepend text, so use a function
  • Color codes without \[ \]: long commands wrap onto the same line and overwrite the prompt
  • Defining an alias and using it on the same line, or in a function defined on that line: aliases expand when the line is read
  • Overwriting PROMPT_COMMAND and losing what other tools (like history -a) added

✓ Tips & Best Practices

  • type ll shows whether a name is an alias, function, or file
  • Use tput setaf 2 instead of raw codes for portable colors
  • Show the git branch with __git_ps1 from git's git-prompt.sh
  • Add to PROMPT_COMMAND instead of replacing it: PROMPT_COMMAND="mycmd; $PROMPT_COMMAND"

Quick Summary

  • alias name='cmd' — shortcut
  • \cmd — bypass an alias
  • PS1 — prompt; \[ \] around colors
  • PROMPT_COMMAND — run before each prompt
  • pushd / popd / cd - — move around
