Sheet 08

Special Parameters & Environment

$0 $1 $# · "$@" · $? · $$ $! · PIPESTATUS · RANDOM · PATH

Built-In Parameters

Bash sets a group of special parameters you can read but not assign: the script's arguments, the last exit status, process IDs, and more. Alongside them are shell variables bash maintains (RANDOM, SECONDS, LINENO) and environment variables inherited from the parent process (PATH, HOME, USER). The most important rule: use "$@" (quoted) to pass arguments along unchanged.

Notes

  • "$@" expands to one word per argument; "$*" joins them into one
  • $? is overwritten by every command; save it right away
  • Inside a function, $1, $#, $@ refer to the function's arguments
  • env / printenv list exported variables; set lists everything

Reading Special Parameters

# run as:  ./demo.sh one "two words" three
echo "$0"                     # ./demo.sh
echo "$1 | $2"                # one | two words
echo "$#"                     # 3
for a in "$@"; do echo "[$a]"; done   # [one] [two words] [three]
echo "$*"                     # one two words three   (single string)
echo "${10}"                  # 10th argument needs braces

false; echo "$?"              # 1   (exit status of last command)
echo "$$ $BASHPID"            # PID of script / of the current (sub)shell
sleep 30 & echo "$!"          # PID of the last background job
false | true; echo "${PIPESTATUS[@]}"   # 1 0
echo "$RANDOM"                # 0–32767
echo "$SECONDS $EPOCHSECONDS" # secs since start / Unix time (5.0+)
echo "$LINENO ${BASH_SOURCE[0]}"        # current line / this file

Code Explained

$0 — how the script was called (path as typed)
"$@" — preserves two words as one argument
${10} — $10 means ${1} followed by 0
$? — 0 is success; 1–255 is failure
$BASHPID — differs from $$ inside ( … ) subshells
PIPESTATUS — array of every stage's exit status in the last pipeline

⚠ Common Mistakes

  • for a in $@ (unquoted): arguments with spaces are split into separate words
  • if [ $? -eq 0 ] after an echo you added for debugging: $? is now echo's status
  • $10 reads as $1 followed by a literal 0; use ${10}
  • PATH=/my/bin replaces the whole search path; use PATH="/my/bin:$PATH"

✓ Tips & Best Practices

  • Test commands directly: if grep -q x f; then instead of checking $?
  • Save status before anything else: cmd; rc=$?
  • $(basename "$0") gives a clean script name for usage messages
  • Script directory: dir=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)

Quick Summary

  • "$@" — pass arguments through unchanged
  • $# — how many arguments
  • $? — exit status of the last command
  • $$ / $! — this shell's PID / last background PID
  • PIPESTATUS — every stage's status
