⚠ Common Mistakes

  • cmd | while read loses variables (subshell)
  • local v=$(cmd) hides cmd's failure
  • macOS /bin/bash is 3.2: check the matrix

✓ Tips & Best Practices

  • #!/usr/bin/env bash picks up a newer Homebrew bash
  • Clean up with trap 'rm -rf "$tmp"' EXIT
  • Check versions: (( BASH_VERSINFO[0] >= 4 ))

Quick Summary

  • if / case / for / while — control flow
  • set -euo pipefail + trap — safe scripts
  • & + wait — run jobs in parallel
