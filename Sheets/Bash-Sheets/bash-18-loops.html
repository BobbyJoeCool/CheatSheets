Sheet 18

Loops

for … in · for (( )) · while · until · while IFS= read -r · break · continue

Repeating Commands

for … in walks a list of words (filenames, array elements, brace ranges). The C-style for (( )) counts with arithmetic. while repeats while a command succeeds, and until repeats while it fails. The standard way to read a file line by line is while IFS= read -r line, fed by a redirect or process substitution, not a pipe.

Notes

  • for x; do with no in loops over "$@"
  • A loop's output can be redirected once: done > out.txt
  • break 2 / continue 2 act on the enclosing loop
  • while : or while true loops forever

Loop Patterns

for f in *.jpg; do echo "converting $f"; done      # over a glob
for name in "${names[@]}"; do echo "$name"; done     # over an array
for i in {1..5}; do echo "$i"; done                  # fixed range
for ((i = 0; i < 10; i += 2)); do echo "$i"; done    # 0 2 4 6 8

while IFS= read -r line; do                 # file, line by line
  echo "> $line"
done < input.txt

count=0
while read -r user _; do (( ++count )); done < <(who)  # count survives
until curl -sf localhost:8080/health; do sleep 2; done  # retry until up

for f in *; do
  [[ -d $f ]] && continue                   # skip directories
  [[ $f == STOP ]] && break                 # leave the loop
done

Code Explained

for f in *.jpg — glob expands to a list; quote "$f" inside
{1..5} — literal range; use (( )) when the end is a variable
IFS= — keep leading/trailing spaces; -r — keep backslashes
< <(cmd) — process substitution keeps the loop in this shell
read -r user _ — _ swallows the rest of the line
until — opposite of while; loops until success

⚠ Common Mistakes

  • for line in $(cat file) splits on spaces, not lines, and globs; use while IFS= read -r
  • cat f | while read …; do n=…; done then echo $n: the loop ran in a subshell, so n is empty
  • for i in {1..$n} doesn't expand; use for ((i = 1; i <= n; i++))
  • ssh or ffmpeg inside a read loop eat its input; add < /dev/null to them

✓ Tips & Best Practices

  • Loop over files safely with globs, not ls output
  • Read NUL-separated names from find: while IFS= read -r -d '' f; do …; done < <(find . -print0)
  • Parallel-ish: append & to the loop body, then wait after done
  • shopt -s lastpipe (scripts) runs the last pipe stage in the current shell

Quick Summary

  • for x in list — words, globs, arrays
  • for (( ; ; )) — counting
  • while IFS= read -r line — lines of a file
  • < <(cmd) — feed without a subshell
  • break / continue — loop control
