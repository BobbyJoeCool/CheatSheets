Sheet 09

Parameter Expansion — Defaults & Length

${var:-def} · ${var:=val} · ${var:?msg} · ${var:+alt} · ${#var} · ${!var}

Defaults, Errors & Length

Parameter expansion lets you supply a fallback, assign a default, abort with a message, or substitute a value, all without an if. The colon matters: ${v:-d} uses the default when v is unset or empty, while ${v-d} uses it only when v is unset. ${#v} gives a length, and ${!v} reads a variable whose name is stored in v.

Notes

  • : is a no-op command; : "${X:=1}" assigns without running anything
  • ${v:?msg} exits a non-interactive script with status 1
  • := can't assign to positional params: ${1:=x} is an error
  • For indirection, a nameref (declare -n) is often clearer than ${!v}

Defaults & Length in Practice

unset u; e=""; s="value"
echo "${u:-def} ${e:-def} ${s:-def}"   # def def value
echo "${u-def} [${e-def}]"             # def []    (no colon: only unset)
: "${PORT:=8080}"; echo "$PORT"        # 8080  (assigns if unset or empty)
echo "${s:+yes} [${e:+yes}]"           # yes []    (alternate if non-empty)
: "${API_KEY:?must be set}"            # bash: API_KEY: must be set  (exits)

name=${1:-world}                       # first arg, or "world"
out=${OUTPUT_DIR:-$HOME/out}           # defaults can expand too

echo "${#s}"                           # 5   (string length)
arr=(a bb ccc); echo "${#arr[@]} ${#arr[2]}"   # 3 3

var=s;  echo "${!var}"                 # value   (indirect: $s)
APP_HOST=x APP_PORT=y
echo "${!APP_@}"                       # APP_HOST APP_PORT   (names by prefix)

Code Explained

:- — use a default, don't store it
:= — use a default and assign it to the variable
:? — required variable; prints the message to stderr and exits
:+ — the opposite of :-: value only when the variable is set
${#arr[@]} — element count; ${#arr[2]} — length of element 2
${!prefix@} — names of all variables starting with the prefix

Length & Indirection

FormResult
${#v}length of string
${#arr[@]}number of elements
${#arr[i]}length of element i
${!v}value of var named by v
${!pre@}var names starting pre
${!arr[@]}array indices / keys
${v+set}"set" if v exists

⚠ Common Mistakes

  • Using ${v-d} when the variable may be set but empty: no colon means empty counts as set
  • ${PORT:=8080} on its own line runs 8080 as a command; prefix it with :
  • ${#arr} gives the length of element 0, not the element count; use ${#arr[@]}
  • Testing existence with [ -n "$v" ]: that's false for set-but-empty; use ${v+x} or [[ -v v ]]

✓ Tips & Best Practices

  • Required settings at the top of a script: : "${DB_URL:?}" documents and enforces them
  • Optional args: verbose=${2:-false} reads cleaner than an if
  • Build optional flags: cmd ${DRY_RUN:+--dry-run} adds the flag only when set
  • Prefer declare -n over ${!v} when you need to write through the reference

Quick Summary

  • ${v:-d} — default value
  • ${v:=d} — default and assign
  • ${v:?msg} — fail if missing
  • ${v:+a} — alternate if present
  • ${#v} / ${!v} — length / indirection
