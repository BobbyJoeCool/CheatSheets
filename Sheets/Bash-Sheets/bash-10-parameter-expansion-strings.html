Sheet 10

Parameter Expansion — Substrings & Transforms

${v:off:len} · ${v#pat} · ${v%pat} · ${v/a/b} · ${v^^} · ${v,,} · ${v@Q}

String Surgery Without Subprocesses

Bash can slice, trim, replace and change case inside ${…} without calling sed, cut or basename, which is much faster in loops. # and % remove a glob pattern from the start or end; doubling them (##, %%) makes the match greedy. / replaces the first match and // replaces all. Patterns are globs, not regexes.

Notes

  • Memory aid: # is left of $ on the keyboard (start); % is right (end)
  • Negative offsets need a space or parens: ${v: -3} or ${v:(-3)}
  • Case operators ^ , need bash 4+; @U @L @u need 5.1
  • All forms work on every element of an array: ${arr[@]%.txt}

Slicing, Trimming, Replacing

f="/home/ada/report.final.txt"
echo "${f:6:3}"                 # ada    (offset 6, length 3)
echo "${f: -3}"                 # txt    (last 3 chars)
echo "${f##*/}"                 # report.final.txt   (basename)
echo "${f%/*}"                  # /home/ada          (dirname)
echo "${f%.*}"                  # /home/ada/report.final   (drop last ext)
echo "${f%%.*}"                 # /home/ada/report   (drop all exts)
b=${f##*/}; echo "${b#*.}"      # final.txt   (shortest prefix to first .)

s="a-b-c"
echo "${s/-/+} ${s//-/+}"       # a+b-c a+b+c   (first / all)
echo "${s/#a/X} ${s/%c/Z}"      # X-b-c a-b-Z   (anchor start / end)
echo "${s//-}"                  # abc   (delete every -)

n="hello World"
echo "${n^} | ${n^^} | ${n,,}"  # Hello World | HELLO WORLD | hello world
echo "${n@Q}"                   # 'hello World'   (quoted for reuse, 4.4+)

Code Explained

${f:6:3} — substring; offset is 0-based
##*/ — greedy: strips through the last /
%/* — non-greedy: strips from the last / to the end
%.* vs %%.* — one extension vs everything after the first dot
/# and /% — replace only at the start / end
^ / , — first char; doubled = whole string

Trim & Replace

FormEffect
${v:o}from offset o to end
${v:o:n}n chars from offset o
${v#p} / ${v##p}remove shortest / longest prefix
${v%p} / ${v%%p}remove shortest / longest suffix
${v/p/r}replace first match
${v//p/r}replace all matches
${v//p}delete all matches

Case & Transforms

FormEffect
${v^} / ${v^^}upper first / all (4.0+)
${v,} / ${v,,}lower first / all (4.0+)
${v~~}toggle case of all
${v@U} / ${v@L}upper / lower all (5.1+)
${v@Q}quoted for shell reuse (4.4+)
${v@E}expand \n style escapes
${v@A}as a declare statement

⚠ Common Mistakes

  • ${v:-3} is the default operator, not "last 3 chars"; use ${v: -3}
  • Expecting regex: ${v//[0-9]+/} matches a digit then a literal +; use extglob +([0-9]) or [[ =~ ]]
  • Using ${f%.*} on archive.tar.gz and expecting archive; that needs %%
  • Using ${v^^} under #!/bin/bash on macOS: bash 3.2 has no case operators

✓ Tips & Best Practices

  • Replace $(basename "$f") with ${f##*/} and $(dirname "$f") with ${f%/*} in loops
  • Change every extension at once: mv "$f" "${f%.jpeg}.jpg"
  • Case-insensitive compare: [[ ${a,,} == "${b,,}" ]]

Quick Summary

  • ${v:o:n} — substring
  • ${v#p} / ${v%p} — trim start / end
  • ${v/p/r} / ${v//p/r} — replace first / all
  • ${v^^} / ${v,,} — upper / lower
  • ${v@Q} — safely quoted copy
