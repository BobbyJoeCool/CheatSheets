Associative Arrays

declare -A · h[key]=val · "${!h[@]}" · "${h[@]}" · [[ -v h[key] ]] · unset

Key-Value Maps

An associative array maps string keys to string values, like a dictionary or hash map. It needs bash 4.0+ and must be declared with declare -A before use; without it, bash treats the name as an indexed array and every key collapses to index 0. Key order is not preserved, so sort the keys yourself when order matters.

Notes

  • local -A declares one inside a function
  • Keys can contain spaces: h["new york"]=NY
  • Values are strings only; no nested maps
  • Not available in macOS /bin/bash (3.2)

Working with a Map

declare -A ages                 # required (bash 4.0+)
ages[alice]=31
ages[bob]=27
declare -A color=([red]=f00 [green]=0f0)    # literal form

echo "${ages[alice]}"           # 31
echo "${#ages[@]}"              # 2
echo "${!ages[@]}"              # bob alice   (keys, any order)
[[ -v ages[carol] ]] || echo "no carol"     # does the key exist?
(( ages[bob]++ ))               # 28   (arithmetic on a value)
unset 'ages[bob]'               # delete a key (quote it)

for k in "${!ages[@]}"; do      # iterate keys
  printf '%-6s %s\n' "$k" "${ages[$k]}"
done

declare -A count                # word frequency
for w in red blue red; do (( count[$w]++ )); done
echo "${count[red]}"            # 2

Code Explained

declare -A — without it, ages[alice]=31 sets index 0 of an indexed array
[[ -v h[k] ]] — true if the key exists, even with an empty value
${!h[@]} — keys; ${h[@]} — values
(( h[k]++ )) — missing keys start at 0, so counting just works
unset 'h[k]' — quoting prevents glob expansion of [k]
count[$w] — the key can come from a variable

Syntax

FormMeaning

⚠ Common Mistakes

  • Skipping declare -A: string keys are evaluated as arithmetic, usually 0, so every key overwrites the same slot
  • h=([a]=1) without -A silently makes an indexed array
  • Expecting keys in insertion order; bash returns them in hash order
  • unset h[$k] unquoted can glob-match a file named like h1 and delete the wrong thing

✓ Tips & Best Practices

  • Sorted keys: mapfile -t keys < <(printf '%s\n' "${!h[@]}" | sort)
  • Use a map as a set: seen[$x]=1, then [[ -v seen[$x] ]]
  • Pass a map to a function with a nameref: f() { local -n m=$1; …; }; f ages
  • Fail early on old bash: (( BASH_VERSINFO[0] >= 4 ))

Quick Summary

  • declare -A h — create a map
  • h[key]=value — set
  • "${!h[@]}" — keys
  • [[ -v h[key] ]] — key exists
  • unset 'h[key]' — delete
