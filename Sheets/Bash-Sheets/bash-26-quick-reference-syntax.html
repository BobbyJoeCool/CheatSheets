⚠ Common Mistakes

  • Unquoted $var or ${arr[@]}: split and globbed
  • > f 2>&1 and 2>&1 > f are different
  • {1..$n} never expands; braces run first

✓ Tips & Best Practices

  • Quote by default: "$v", "$(cmd)", "${a[@]}"
  • Use [[ ]] for strings, (( )) for numbers
  • declare -p var shows exactly what's stored

Quick Summary

  • ${v:-d} / ${v%p} / ${v//p/r} — default, trim, replace
  • "${a[@]}" — every element safely
  • 2>&1 / <<EOF — redirect and inline input
