Writing Scripts That Hold Up

Most shell bugs come from a short list: unquoted variables, parsing ls, ignored failures, and assuming a feature exists on every machine. Decide up front which shell you're targeting: use #!/usr/bin/env bash and bash features freely, or #!/bin/sh and stick to POSIX. Run ShellCheck on everything; it catches most of these problems automatically.

Notes

  • Install ShellCheck: brew install shellcheck / apt install shellcheck
  • On Debian/Ubuntu, /bin/sh is dash, not bash
  • Silence one warning: # shellcheck disable=SC2086 above the line
  • When a script passes about 100 lines, consider Python

A Script Template

#!/usr/bin/env bash
# deploy.sh — sync a build to a server
set -euo pipefail

script_dir=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)
tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT

log() { printf '%s %s\n' "$(date +%T)" "$*" >&2; }

main() {
  command -v rsync > /dev/null || { log "rsync not found"; exit 127; }
  local target=${1:?usage: deploy.sh host}
  log "deploying to $target"
  rsync -a "$script_dir/dist/" "$target:/srv/app/"
}
main "$@"

Code Explained

script_dir — find files next to the script, wherever it's run from
mktemp -d + trap … EXIT — private temp dir, always removed
log to stderr — keeps stdout clean for real output
command -v — POSIX way to test that a program exists
${1:?usage} — required argument with a built-in error
main "$@" — whole file is parsed before anything runs

⚠ Common Mistakes

  • #!/bin/sh with [[ ]] or arrays: works where sh is bash, breaks on Debian (dash) and Alpine (busybox)
  • Parsing ls output: breaks on spaces and newlines in names; use globs or find -print0
  • cd somewhere; rm -rf * without checking cd succeeded; use cd dir || exit
  • Hard-coding /tmp/myfile: collisions and security issues; use mktemp

✓ Tips & Best Practices

  • Quote everything, then remove quotes only where you want splitting
  • Use -- before untrusted filenames: rm -- "$f"
  • Check the version you need: (( BASH_VERSINFO[0] >= 4 )) || { echo 'need bash 4+' >&2; exit 1; }
  • Format with shfmt -i 2 -w script.sh for consistent style

Quick Summary

  • ShellCheck — run on every script
  • #!/usr/bin/env bash — be explicit about bash
  • command -v / printf / $( ) — portable choices
  • mktemp + trap — safe temp files
  • Quote every expansion
