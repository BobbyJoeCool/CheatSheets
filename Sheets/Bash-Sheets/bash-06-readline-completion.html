Readline, Key Bindings & Completion

Ctrl-R · Alt-. · ~/.inputrc · bind · set -o vi · complete · compgen

The Line Editor

Bash uses the GNU Readline library to edit the command line. Its default key bindings come from Emacs, or vi with set -o vi. Readline settings live in ~/.inputrc and apply to every Readline program (bash, python, psql…), while bind changes them for the current shell. Programmable completion (complete, compgen) controls what Tab offers; the bash-completion package adds rules for hundreds of commands.

Notes

  • Reload ~/.inputrc without restarting: Ctrl-X Ctrl-R
  • bind -p lists every binding; bind -l lists function names
  • Install bash-completion: brew install bash-completion@2 or apt install bash-completion

~/.inputrc, bind & complete

# ~/.inputrc
set completion-ignore-case on
set show-all-if-ambiguous on      # list matches on the first Tab
"\e[A": history-search-backward   # Up arrow: search by typed prefix
"\e[B": history-search-forward    # Down arrow

# In bash / ~/.bashrc
set -o vi                         # vi-style editing (default: emacs)
bind '"\C-x\C-r": re-read-init-file'
bind -x '"\C-g": git status'      # run a shell command from a key

complete -W "start stop restart" svc    # fixed word list for `svc`
_deploy() {
  local cur=${COMP_WORDS[COMP_CWORD]}   # word being completed
  COMPREPLY=($(compgen -W "dev staging prod" -- "$cur"))
}
complete -F _deploy deploy        # use the function for `deploy`

Code Explained

history-search-backward — type git, press Up, see only git commands
\e[A — the escape sequence most terminals send for Up
bind -x — bind a key to a shell command instead of an editing function
COMP_WORDS / COMP_CWORD — the words on the line and the current index
compgen -W list -- "$cur" — prints the words in list that start with $cur
COMPREPLY — the array of candidates your function returns

⚠ Common Mistakes

  • Putting bind lines in ~/.inputrc, or set completion-… lines in ~/.bashrc: each file has its own syntax
  • Ctrl-S freezes the terminal (XOFF) instead of searching forward; run stty -ixon first
  • Writing COMPREPLY=$(compgen …) without parentheses gives one string, not an array
  • Leaving out -- in compgen -W list -- "$cur": a word starting with - is read as an option

✓ Tips & Best Practices

  • The prefix-search Up/Down binding is the single biggest speedup
  • Ctrl-X Ctrl-E is the easiest way to write a long one-liner
  • Add set colored-stats on to color completions like ls --color
  • Find a key's escape code: press Ctrl-V, then the key

Quick Summary

  • ~/.inputrc — Readline settings for all programs
  • bind — change bindings in this shell
  • set -o vi — vi editing mode
  • complete -W / -F — define Tab completion
  • compgen — generate matching candidates
