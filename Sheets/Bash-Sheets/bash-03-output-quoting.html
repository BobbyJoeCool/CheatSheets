Sheet 03

Output, Quoting & Escaping

echo · printf · 'single' · "double" · $'…' · printf %q

Printing and Quoting

echo is fine for simple text, but its options and escape handling differ between shells, so prefer printf for anything formatted. Quoting controls which expansions happen: single quotes keep everything literal, double quotes still expand $var, $(cmd) and backslash escapes while preventing word splitting and globbing, and $'…' (ANSI-C quoting) turns escapes like \n and \t into real characters.

Notes

  • printf reuses its format for extra arguments: printf '%s\n' a b c
  • printf does not add a newline unless the format has \n
  • You can't put a ' inside single quotes, even escaped
  • Send errors to stderr with >&2 so pipelines stay clean

Output & Quoting Examples

echo "Hello"                    # Hello
echo -n "no newline"            # no newline   (prompt follows on same line)
echo -e "a\tb\nc"               # a<TAB>b  then c on a new line
printf '%s\n' one two           # one / two   (format reused per argument)
printf '%-8s|%5d|\n' id 42      # id      |   42|
printf '%.2f %05d %x\n' 3.14159 42 255   # 3.14 00042 ff
printf -v line '%s=%s' key val  # store in $line instead of printing

name="World"
echo 'Hi $name'                 # Hi $name    (single: literal)
echo "Hi $name"                 # Hi World    (double: expands)
echo $'tab:\tend'               # tab:<TAB>end   (ANSI-C quoting)
echo "Cost: \$5"                # Cost: $5
echo 'it'\''s'                  # it's   (close, escaped ', reopen)
printf '%q\n' "a b'c"           # a\ b\'c   (shell-safe re-quoting)
echo "failed" >&2               # write to stderr

Code Explained

echo -n / -e — no newline / interpret escapes (not portable)
%-8s — left-align in 8 chars; %5d right-align; %05d zero-pad
printf -v var — format into a variable; no subshell needed
'…'\''…' — the standard trick for a quote inside single quotes
%q — output that can be pasted back into a shell safely
>&2 — redirect stdout to stderr for messages

⚠ Common Mistakes

  • echo $var unquoted: runs of spaces collapse and * expands to filenames
  • echo -e in sh scripts: dash prints -e literally; use printf
  • printf "$msg": a % in the data becomes a format code; use printf '%s\n' "$msg"
  • Escaping ' inside single quotes ('it\'s') doesn't work; use "it's" or $'it\'s'

✓ Tips & Best Practices

  • Default to double quotes around every expansion: "$var", "$(cmd)"
  • Use single quotes for anything you pass to grep, sed, or awk
  • printf '%s\n' "${arr[@]}" prints one array element per line
  • Color: printf '\e[31m%s\e[0m\n' red

Quick Summary

  • printf '%s\n' — safe, portable output
  • '…' — fully literal
  • "…" — expand, but no splitting or globbing
  • $'…' — real tabs and newlines
  • >&2 — print to stderr
