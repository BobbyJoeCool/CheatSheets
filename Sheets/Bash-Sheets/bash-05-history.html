Sheet 05

History & History Expansion

HISTSIZE · HISTCONTROL · !! · !$ · ^old^new · history · fc

Command History

Interactive bash records every command in memory and writes it to ~/.bash_history when the shell exits. History expansion (! shortcuts) rewrites the line before it runs, so sudo !! reruns the last command with sudo. By default each terminal overwrites the file on exit and older lines are lost; a few lines in ~/.bashrc fix both problems.

Notes

  • History expansion is interactive-only; it's off in scripts
  • ! inside double quotes still expands: echo "hi!" can fail
  • set +H turns off ! expansion entirely
  • Add :p to any designator to print it instead of running it
  • Ctrl-R searches history interactively (Sheet 06)

Setup and Shortcuts

# ~/.bashrc
HISTSIZE=10000                 # lines kept in memory
HISTFILESIZE=20000             # lines kept in ~/.bash_history
HISTCONTROL=ignoreboth         # skip duplicates + lines starting with space
HISTIGNORE='ls:bg:fg:history'  # never record these
HISTTIMEFORMAT='%F %T  '       # show timestamps in `history`
shopt -s histappend            # append on exit instead of overwrite
PROMPT_COMMAND="history -a; $PROMPT_COMMAND"   # save after every command

history 5                      # last 5 commands
sudo !!                        # rerun last command with sudo
!grep                          # rerun most recent command starting "grep"
cp file.txt /tmp && cd !$:h    # !$ = last arg; :h = its directory
^teh^the                       # rerun previous, replacing teh → the
!42:p                          # print command 42 without running it
fc                             # open last command in $EDITOR, run on save

Code Explained

ignoreboth — ignorespace + ignoredups; start a line with a space to keep it out
HISTTIMEFORMAT — any strftime format; also saves timestamps in the file
history -a in PROMPT_COMMAND — shares history across open terminals
!$:h — modifiers edit the recalled word (:h head, :t tail)
^a^b — quick substitution on the previous command, first match only
fc — fix command; fc -l lists, fc -s reruns

⚠ Common Mistakes

  • No histappend: with two terminals open, whichever closes last overwrites the other's history
  • HISTFILESIZE smaller than HISTSIZE truncates the file on every exit
  • echo "Done!" fails with "event not found"; use single quotes or set +H
  • Typing secrets on the command line: they land in the history file; prefix with a space when ignorespace is set

✓ Tips & Best Practices

  • Press Alt-. to paste the last argument; faster than typing !$
  • Check before running: add :p, then !! to run it
  • shopt -s histverify puts expanded ! commands back on the line for review
  • shopt -s cmdhist keeps multi-line commands as one entry (on by default)

Quick Summary

  • HISTSIZE / HISTFILESIZE — memory / file size
  • HISTCONTROL=ignoreboth — skip dups and space-prefixed
  • !! !$ !* — previous command / last arg / all args
  • ^old^new — fix a typo and rerun
  • history -a + histappend — keep everything
