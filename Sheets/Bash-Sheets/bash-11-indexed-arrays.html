Sheet 11

Indexed Arrays

arr=(a b c) · "${arr[@]}" · ${#arr[@]} · +=() · ${arr[@]:1:2} · ${!arr[@]}

Arrays of Values

An indexed array holds an ordered list of strings with 0-based integer indices. Arrays are the right way to store lists of filenames or arguments, because each element keeps its spaces. Always expand the whole array as "${arr[@]}", quoted, to get one word per element. Arrays can be sparse: deleting an element leaves a gap in the indices.

Notes

  • $arr alone means ${arr[0]}, a common surprise
  • Arrays can't be exported to child processes
  • Bash has no nested arrays; use naming schemes or associative arrays
  • declare -a arr is optional; assignment creates the array

Creating & Using Arrays

fruits=(apple "star fruit" cherry)
echo "${fruits[0]}"             # apple    (0-based)
echo "${fruits[-1]}"            # cherry   (negative = from the end)
echo "${#fruits[@]}"            # 3
fruits+=(date)                  # append one or more
fruits[10]=fig                  # sparse: indices 4–9 don't exist
echo "${!fruits[@]}"            # 0 1 2 3 10   (indices in use)
echo "${fruits[@]:1:2}"         # star fruit cherry   (slice)
unset 'fruits[1]'               # remove one element (no reindexing)
fruits=("${fruits[@]}")         # reindex to 0..n-1

for f in "${fruits[@]}"; do echo "[$f]"; done   # one per element
printf '%s\n' "${fruits[@]}"    # same, one per line

files=(*.log)                   # glob results into an array
read -ra parts <<< "a b c"      # split a string into an array
mapfile -t lines < notes.txt    # one element per line (4.0+)

Code Explained

(a "b c") — quotes keep b c as one element
+=( ) — append; arr+=x without parens appends to element 0's text
${!arr[@]} — list of indices, useful for sparse arrays
${arr[@]:start:count} — slice by position
unset 'arr[1]' — quote it so [1] isn't treated as a glob
read -ra — -a fills an array, -r keeps backslashes

Expansion Forms

FormResult
"${a[@]}"each element as its own word ✔
"${a[*]}"one string, joined by 1st char of IFS
${a[@]}elements re-split on spaces ✖
$aelement 0 only
${a[i]}element i
${#a[@]}element count

Whole-Array Operations

FormEffect
"${a[@]/x/y}"replace in every element
"${a[@]%.txt}"trim every element
"${a[@]^^}"uppercase every element
(IFS=,; echo "${a[*]}")join with commas
b=("${a[@]}")copy an array
unset adelete the whole array

⚠ Common Mistakes

  • for x in ${arr[@]} unquoted: elements with spaces are split, and * expands to filenames
  • arr=$(ls) creates a string, not an array; use arr=(*) or mapfile -t arr < <(cmd)
  • Looping for i in $(seq 0 $((${#a[@]}-1))) over a sparse array hits missing indices; loop over "${!a[@]}"
  • words=($line) splits on spaces and expands globs in the data

✓ Tips & Best Practices

  • Build command arguments in an array: args=(-v --out "$dir"), then cmd "${args[@]}"
  • mapfile -t arr < <(find . -name '*.md') loads command output safely, one line per element
  • Check for empty: (( ${#arr[@]} == 0 ))
  • declare -p arr prints indices and values exactly

Quick Summary

  • arr=(a b c) — create
  • "${arr[@]}" — every element, safely
  • ${#arr[@]} — count
  • arr+=(x) — append
  • ${!arr[@]} — indices
