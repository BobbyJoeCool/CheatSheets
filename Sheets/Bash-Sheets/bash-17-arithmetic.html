Integer Math

Bash does integer-only math with signed 64-bit numbers. $(( expr )) substitutes the result; (( expr )) runs as a command and is true when the result is non-zero, so it doubles as a numeric test. Inside either form you can use C-style operators and drop the $ from variable names. For decimals, hand the work to bc or awk.

Notes

  • Division truncates toward zero: $(( -7 / 2 )) is -3
  • Leading 0 means octal: 08 and 09 are errors
  • Unset or non-numeric variables count as 0
  • Overflow wraps silently (64-bit)

Arithmetic Examples

a=17; b=5
echo $(( a + b ))              # 22
echo $(( a / b ))              # 3    (integer division)
echo $(( a % b ))              # 2    (remainder)
echo $(( a ** 2 ))             # 289
echo $(( (a + b) * 2 ))        # 44
(( a++ )); echo "$a"           # 18
(( b += 10 )); echo "$b"       # 15   (no $ needed inside (( )))
(( a > b )) && echo "a is bigger"
echo $(( a > b ? a : b ))      # 18   (ternary)
echo $(( 16#ff )) $(( 2#1010 ))    # 255 10   (base#number)
echo $(( 0x1F )) $(( 010 ))    # 31 8   (hex, and octal from leading 0)
echo $(( 10#09 ))              # 9    (force base 10)
printf '%.2f\n' "$(echo '10/3' | bc -l)"   # 3.33
awk 'BEGIN { printf "%.1f\n", 7 / 2 }'     # 3.5

Code Explained

$(( )) — expression → number (substituted into the line)
(( )) — expression as a command: exit 0 if non-zero, 1 if zero
** — power; % — remainder
16#ff — any base from 2 to 64
10#$n — strip leading zeros from input like 08
bc -l — arbitrary precision with the math library

⚠ Common Mistakes

  • (( count++ )) when count is 0 returns status 1, which kills a set -e script; use (( ++count )) or count=$((count + 1))
  • Reading user input 08 or 09 as a number: octal error; use $(( 10#$n ))
  • Expecting $(( 10 / 3 )) to be 3.33; bash has no floats
  • Writing $(( $a+$b )) with spaces in values; inside (( )) plain names are cleaner

✓ Tips & Best Practices

  • Prefer (( n > 5 )) over [ $n -gt 5 ] for numeric tests
  • Commas run several expressions: (( a = 1, b = a + 2 ))
  • Random in a range: $(( RANDOM % 6 + 1 )) (dice roll)
  • Round with printf: printf '%.0f' 2.6 gives 3

Quick Summary

  • $(( expr )) — compute a value
  • (( expr )) — compute and test
  • ** % ?: — power, remainder, ternary
  • 16#ff / 10#08 — explicit bases
  • bc / awk — decimals
