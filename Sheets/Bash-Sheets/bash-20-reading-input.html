Reading Input

read -r · -p · -s · -t · -n · -a · IFS=, read · mapfile -t

Getting Data In

read takes one line from stdin, splits it on IFS, and assigns the pieces to variables; the last variable gets the rest of the line. Always use -r so backslashes are kept as typed. mapfile (also called readarray, bash 4+) loads a whole file or command output into an array, one line per element.

Notes

  • read returns non-zero at end of input, which ends while read loops
  • Prompts from read -p go to stderr, so they show even when stdout is redirected
  • With no variable name, read stores the line in $REPLY
  • read -e uses Readline (arrow keys, Tab) for the input

read & mapfile

read -r name                          # one line into $name
read -rp "Your name: " name           # with a prompt
read -rsp "Password: " pw; echo       # -s: don't echo what's typed
read -rn1 -p "Continue? [y/N] " ans   # return after one keypress
read -rt 5 -p "Quick! " a || echo "timed out"
read -r first rest <<< "a b c"        # first=a  rest="b c"
IFS=, read -r id name email <<< "7,Ada,ada@x.io"
read -ra words <<< "one two three"    # array: ${words[1]} = two
read -rei "main" -p "Branch: " br     # editable default (4.0+)

mapfile -t lines < todo.txt           # one element per line (4.0+)
echo "${#lines[@]} lines; first: ${lines[0]}"
mapfile -t -n 10 top < big.log        # first 10 lines only
mapfile -t users < <(cut -d: -f1 /etc/passwd)
data=$(< notes.txt)                   # whole file in one string
[[ -t 0 ]] || echo "stdin is a pipe or file"

Code Explained

-p — prompt; -s — silent; -n1 — single character
-t 5 — give up after 5 seconds (status > 128)
IFS=, — split on commas for this read only
-a — fill an array instead of separate variables
-e -i text — pre-filled, editable answer
mapfile -t — strip the newline from each line

⚠ Common Mistakes

  • Leaving off -r: C:\new becomes C:new
  • Leaving off IFS= when reading lines: leading and trailing spaces are stripped
  • echo "$x" | read y sets y in a subshell; use read y <<< "$x"
  • mapfile in a #!/bin/bash script on macOS: bash 3.2 doesn't have it

✓ Tips & Best Practices

  • Read lines exactly: IFS= read -r line
  • Ask the terminal even when stdin is redirected: read -r ans < /dev/tty
  • Use $(< file) instead of $(cat file); it skips starting cat
  • Default answer: read -rp "Port [8080]: " p; p=${p:-8080}

Quick Summary

  • read -r var — one line
  • read -rp "msg" var — prompt
  • read -ra arr — split into an array
  • IFS=, read -r a b — split on commas
  • mapfile -t arr < file — file to array
