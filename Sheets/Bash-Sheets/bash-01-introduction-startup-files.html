What Bash Is

Bash (Bourne-Again SHell) was written by Brian Fox for the GNU Project in 1989 and is maintained by Chet Ramey. It is the default shell on most Linux distributions. macOS switched to zsh in Catalina but still ships bash 3.2 at /bin/bash; get a current version with brew install bash. Which startup files run depends on whether the shell is a login shell and whether it is interactive.

Good to Know

  • Check your version: bash --version or echo $BASH_VERSION
  • This set targets bash 5.x; features needing 4.0+ are tagged
  • $SHELL is your login shell, not necessarily the current one
  • To change shells: add the path to /etc/shells, then chsh -s /path/to/bash

Hello World & Startup Checks

#!/usr/bin/env bash
echo "Hello, World!"            # Hello, World!

bash --version | head -1        # GNU bash, version 5.2.37(1)-release ...
echo "$BASH_VERSION"            # 5.2.37(1)-release
echo "${BASH_VERSINFO[0]}"      # 5   (major version as a number)

# ~/.bash_profile: make login shells load ~/.bashrc too
if [ -f ~/.bashrc ]; then
  . ~/.bashrc
fi

[[ $- == *i* ]] && echo interactive   # i flag = interactive
shopt -q login_shell && echo login    # true in login shells

bash --norc --noprofile         # clean shell: no startup files
source ~/.bashrc                # reload after edits (same as: . ~/.bashrc)

Code Explained

#!/usr/bin/env bash — shebang; finds the first bash on PATH (Homebrew bash beats /bin/bash)
BASH_VERSINFO — array: major, minor, patch… handy for version checks
. ~/.bashrc — login shells skip .bashrc, so source it from .bash_profile
$- — current single-letter flags; contains i when interactive
--norc / --noprofile — start without startup files to debug your config
source — runs a file in the current shell, so its variables stick

⚠ Common Mistakes

  • Aliases in ~/.bash_profile only: Linux terminals open non-login shells, which read ~/.bashrc instead
  • Creating ~/.bash_profile stops bash reading ~/.profile; source it if you need both
  • #!/bin/bash on macOS runs bash 3.2, so declare -A and mapfile fail
  • Editing ~/.bashrc and expecting the open terminal to change; source it or open a new shell

✓ Tips & Best Practices

  • Keep ~/.bash_profile to two lines: exports plus . ~/.bashrc
  • Put [[ $- == *i* ]] || return near the top of ~/.bashrc to skip prompt setup in scripts
  • Test login behavior with bash -l, and a clean slate with env -i bash --norc
  • Gate new features: (( BASH_VERSINFO[0] >= 4 )) || exit 1

Quick Summary

  • $BASH_VERSION — which bash is running
  • ~/.bash_profile — login shells
  • ~/.bashrc — interactive non-login shells
  • source file — run in the current shell
  • #!/usr/bin/env bash — portable shebang
