Sheet 13

Globbing & Extended Globs

* ? [...] · [[:digit:]] · extglob · !(…) @(…) · ** · nullglob

Filename Patterns

Before a command runs, bash replaces unquoted glob patterns with the matching filenames, sorted alphabetically. The command never sees the *; it sees the list of files. With shopt -s extglob you get regex-like operators such as !(…) ("anything except"), and shopt -s globstar makes ** search subdirectories recursively.

Notes

  • No match: the pattern is passed through literally (*.csv) by default
  • * doesn't match a leading . unless you write .* or set dotglob
  • Quoting turns globbing off: "*.txt" is a literal string
  • The same patterns work in case and in [[ $x == pattern ]]

Glob Patterns in Use

ls *.txt                     # every .txt in this directory
ls file?.log                 # file1.log, fileA.log  (exactly one char)
ls [abc]*.md                 # starts with a, b or c
ls [!0-9]*                   # doesn't start with a digit
ls *[[:upper:]]*             # contains an uppercase letter

shopt -s globstar            # bash 4.0+
ls **/*.py                   # .py files in all subdirectories
shopt -s nullglob            # no match → expands to nothing
for f in *.csv; do echo "$f"; done   # runs 0 times if no .csv

shopt -s extglob
ls !(*.bak)                  # everything except .bak files
ls *.@(jpg|png|gif)          # any one of these extensions
rm -- *+([0-9]).tmp          # names ending in digits, then .tmp
[[ $ans == @(y|yes) ]] && echo "confirmed"

Code Explained

? — exactly one character; * — zero or more
[!…] — negated set ([^…] also works in bash)
[[:upper:]] — POSIX class; goes inside a bracket expression
**/ — zero or more directories deep with globstar
nullglob — makes empty loops safe
rm -- — ends options, so a file named -rf can't become a flag

Basic Wildcards

PatternMatches
*any string, incl. empty
?any one character
[abc]one of a, b, c
[a-z]one char in range
[!x] / [^x]any char except x
[[:alpha:]]letter (also digit, space, alnum)

Extended Globs (extglob)

PatternMatches
?(p|q)zero or one of the patterns
*(p|q)zero or more
+(p|q)one or more
@(p|q)exactly one
!(p|q)anything except these
*.@(c|h).c or .h files

⚠ Common Mistakes

  • for f in *.csv with no CSVs runs once with f='*.csv'; enable nullglob or test [[ -e $f ]]
  • Using regex syntax (.*, +) in a glob: *.log.* means "contains .log.", not "any characters"
  • ls *.txt with thousands of files can hit "Argument list too long"; use find … -exec … +
  • Turning on extglob inside the same function or if block that uses it: bash parses first, so it errors

✓ Tips & Best Practices

  • Put shopt -s extglob near the top of a script, on its own line
  • Preview what a glob matches before rm: echo rm *.tmp
  • Case-insensitive match one time: [Rr][Ee]adme*
  • Count matches: files=(*.log); echo ${#files[@]} (with nullglob)

Quick Summary

  • * ? […] — any / one / set
  • **/ — recursive with globstar
  • !(p) @(a|b) — extglob operators
  • nullglob — no match means no words
  • Quote to turn globbing off
