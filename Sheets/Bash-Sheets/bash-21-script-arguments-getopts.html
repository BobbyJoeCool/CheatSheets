Parsing Command-Line Options

getopts is the built-in parser for short options (-v, -o file, -vo file). Its option string lists the letters; a colon after a letter means it takes a value. It doesn't handle --long options, so for those write a while/case loop over "$@" and shift as you go. Either way, finish with only the positional arguments left in "$@".

Making It Runnable

  • Start with #!/usr/bin/env bash, then chmod +x script.sh
  • Run it as ./script.sh, or put its directory on PATH
  • -- marks the end of options: rm -- -file.txt
  • Print usage to stderr and exit 2 on bad input

getopts (short options)

usage() { echo "usage: ${0##*/} [-v] [-o file] in..." >&2; exit 2; }

verbose=0; out=out.txt
while getopts ":vo:h" opt; do
  case $opt in
    v)  verbose=1 ;;
    o)  out=$OPTARG ;;
    h)  usage ;;
    :)  echo "-$OPTARG needs a value" >&2; usage ;;
    \?) echo "unknown: -$OPTARG" >&2; usage ;;
  esac
done
shift $((OPTIND - 1))      # drop the parsed options
(( $# > 0 )) || usage      # need at least one input

for f in "$@"; do echo "$f → $out"; done

Manual loop (long options)

while (( $# )); do
  case $1 in
    -v|--verbose)  verbose=1 ;;
    -o|--output)   out=$2; shift ;;
    --output=*)    out=${1#*=} ;;
    -h|--help)     usage ;;
    --)            shift; break ;;
    -*)            echo "unknown: $1" >&2
                   usage ;;
    *)             break ;;
  esac
  shift
done
# "$@" now holds only the positional args
echo "verbose=$verbose out=$out files=$#"

⚠ Common Mistakes

  • Forgetting shift $((OPTIND - 1)): the options are still in "$@" when you process files
  • Expecting getopts to read --verbose; it only knows single letters
  • out=$2; shift without checking $2 exists: -o at the end silently gets an empty value
  • Putting options after file names: getopts stops at the first non-option

✓ Tips & Best Practices

  • Use "${0##*/}" in usage text so it shows the script name, not its path
  • Accept both --output file and --output=file, as shown
  • Keep option defaults in variables at the top so -h can print them
  • GNU getopt (external, with a t) handles long options but isn't on macOS by default

Quick Summary

  • getopts "ab:" opt — short options
  • $OPTARG — option value
  • shift $((OPTIND-1)) — leave only the args
  • while (( $# )); case $1 — long options
  • exit 2 — bad usage
