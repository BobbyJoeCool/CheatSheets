The this Keyword

this · field shadowing · this() · method chaining · fluent API · passing this

Referring to the Current Object

Inside an instance method or constructor, this is a reference to the object the method was called on. It's used to reach fields hidden by same-named parameters, to call another constructor with this(...), to return the current object for method chaining, and to pass the current object to other methods.

Notes

  • this doesn't exist in static methods
  • this(...) must be the first line of a constructor
  • this can't be reassigned
  • Inner classes reach the outer object with Outer.this

Four Uses of this

public class Point {
    private int x, y;

    public Point(int x, int y) {
        this.x = x;                  // 1. field vs parameter
        this.y = y;
    }
    public Point() {
        this(0, 0);                  // 2. call another constructor
    }

    public Point moveX(int dx) { x += dx; return this; }   // 3. chaining
    public Point moveY(int dy) { y += dy; return this; }

    public void register(Registry r) {
        r.add(this);                 // 4. pass self
    }
}

Point p = new Point().moveX(3).moveY(4);   // fluent: (3, 4)

StringBuilder sb = new StringBuilder()
    .append("a").append("b");               // JDK uses the same pattern

Notes

Without this., x = x assigns the parameter to itself
return this enables fluent chaining
Builders and StringBuilder rely on chaining

⚠ Common Mistakes

  • name = name; in a setter does nothing; write this.name = name;
  • Using this inside a static method — compile error
  • Leaking this from a constructor (e.g., registering a listener) before the object is fully built

✓ Tips & Best Practices

  • Use this. consistently in constructors and setters
  • Return this for builder-style APIs
  • Inside lambdas, this refers to the enclosing object (unlike anonymous classes)

Quick Summary

  • this — current object
  • this.x — field when shadowed
  • this(...) — chain constructors
  • return this — fluent chaining
