Structured Application Logs

SLF4J is a logging facade: your code calls its API, and a backend such as Logback or Log4j 2 decides formatting and where logs go (console, files, JSON). Log levels let you control verbosity without changing code. Use logging instead of System.out.println for anything that runs in production.

Notes

  • Add slf4j-api plus exactly one backend binding
  • {} placeholders avoid building strings for disabled levels
  • Pass the exception last to log its stack trace
  • The JDK also has java.util.logging and System.Logger

Using SLF4J

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class OrderService {
    private static final Logger log =
        LoggerFactory.getLogger(OrderService.class);

    public void place(Order o) {
        log.info("Placing order {} for {}", o.id(), o.customer());
        log.debug("Items: {}", o.items());          // cheap if DEBUG off
        try {
            charge(o);
        } catch (PaymentException e) {
            log.error("Payment failed for {}", o.id(), e);   // + stack trace
        }
        if (o.total() > 10_000) log.warn("Large order {}", o.id());
    }
}

// MDC: add context to every log line in this thread
MDC.put("requestId", requestId);
try { handle(); } finally { MDC.clear(); }

Notes

One static final logger per class
Exception as the final argument → full stack trace
MDC values appear when the pattern includes %X{requestId}

logback.xml

<configuration>
  <appender name="OUT" class="ch.qos.logback.core.ConsoleAppender">
    <encoder>
      <pattern>%d{HH:mm:ss} %-5level %logger{20} - %msg%n</pattern>
    </encoder>
  </appender>
  <logger name="com.acme" level="DEBUG"/>
  <root level="INFO"><appender-ref ref="OUT"/></root>
</configuration>

⚠ Common Mistakes

  • String concatenation in log calls: log.debug("x=" + x) — use {}
  • Logging an exception with e.getMessage() only, losing the stack trace
  • Adding two SLF4J backends — SLF4J picks one and warns

✓ Tips & Best Practices

  • Log at boundaries: requests in, responses out, errors
  • Never log passwords, tokens, or personal data
  • Use JSON output in production for log search tools

Quick Summary

  • SLF4J = API, Logback/Log4j = engine
  • LoggerFactory.getLogger(X.class)
  • {} placeholders
  • Exception last for stack traces
