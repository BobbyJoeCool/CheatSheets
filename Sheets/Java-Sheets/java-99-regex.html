Regular Expressions

java.util.regex.Pattern compiles a regular expression once; a Matcher applies it to text to find matches, extract capture groups, and replace text. String has shortcuts (matches, replaceAll, split) that compile a new pattern every call. In Java string literals, every regex backslash must be doubled.

Notes

  • matches() must match the entire input; find() searches for the next occurrence
  • Compile patterns once and reuse them (static final)
  • Groups are numbered from 1; group 0 is the whole match
  • Pattern.quote(text) escapes user input

Using Pattern & Matcher

static final Pattern DATE =
    Pattern.compile("(?<year>\\d{4})-(?<month>\\d{2})-(?<day>\\d{2})");

Matcher m = DATE.matcher("Due 2026-10-02, paid 2026-09-15");
while (m.find()) {
    System.out.println(m.group("month"));          // 10, then 09
}

DATE.matcher("2026-10-02").matches();                // true (whole string)
"a1b22c333".replaceAll("\\d+", "#");                  // a#b#c#
"Ada Lovelace".replaceAll("(\\w+) (\\w+)", "$2, $1"); // Lovelace, Ada
"a, b;c".split("[,;]\\s*");                           // [a, b, c]

Pattern email = Pattern.compile("^[\\w.+-]+@[\\w-]+\\.[\\w.]+$",
                                Pattern.CASE_INSENSITIVE);
email.matcher("ada@example.com").matches();          // true

List<String> words = Pattern.compile("\\b\\w{5,}\\b")
    .matcher("Regular expressions are handy")
    .results().map(MatchResult::group).toList();  // [Regular, expressions…]

Notes

(?<name>…) — named group, read with group("name")
$1, $2 refer to groups in replacements
results() (Java 9) streams all matches

⚠ Common Mistakes

  • Single backslashes: "\d" doesn't compile; write "\\d"
  • Using matches() when you meant find()
  • Calling String.replaceAll in a hot loop — compile a Pattern once

✓ Tips & Best Practices

  • Use named groups for readability
  • Escape user input with Pattern.quote before inserting it in a regex
  • Test patterns at regex101.com (Java flavor)

Quick Summary

  • Pattern.compile once
  • matcher.find() / matches()
  • group(n) / group("name")
  • Double every backslash
