JavaFX Layouts

VBox · HBox · BorderPane · GridPane · StackPane · FlowPane · AnchorPane · Insets · alignment · grow priority

Layout Panes

JavaFX arranges nodes with layout panes, each a Parent with its own positioning rules. Panes nest to build complex screens, and they resize their children automatically. Spacing, padding (Insets), alignment, and grow priorities control how extra space is shared.

Notes

  • Panes are nodes, so they nest freely
  • setPadding(new Insets(10)) adds inner space
  • HBox.setHgrow(node, Priority.ALWAYS) lets a child stretch
  • Constraints are set with static methods on the pane class

Building a Form Screen

BorderPane root = new BorderPane();
root.setPadding(new Insets(10));

HBox toolbar = new HBox(8, new Button("New"), new Button("Save"));
root.setTop(toolbar);

GridPane form = new GridPane();
form.setHgap(8); form.setVgap(8);
form.add(new Label("Name"), 0, 0);  form.add(new TextField(), 1, 0); // col,row
form.add(new Label("Email"), 0, 1);  form.add(new TextField(), 1, 1);
TextArea notes = new TextArea();
form.add(notes, 0, 2, 2, 1);                         // colspan 2
GridPane.setVgrow(notes, Priority.ALWAYS);
root.setCenter(form);

Label status = new Label("Ready");
HBox bar = new HBox(status);
bar.setAlignment(Pos.CENTER_RIGHT);
root.setBottom(bar);

StackPane badge = new StackPane(new Circle(20), new Label("3"));   // layered

Notes

GridPane.add(node, col, row, colspan, rowspan)
setVgrow lets the notes area take extra height
StackPane layers children on top of each other
Pos constants set alignment

⚠ Common Mistakes

  • Using absolute coordinates (setLayoutX) instead of panes
  • Forgetting grow priorities, so fields don't stretch when the window resizes
  • Deep nesting of VBox/HBox where one GridPane would be simpler

✓ Tips & Best Practices

  • Start with BorderPane as the window skeleton
  • Use GridPane for forms
  • Use Scene Builder to design layouts visually (generates FXML)

Quick Summary

  • Panes position children
  • BorderPane · GridPane · VBox/HBox
  • Insets padding, spacing gaps
  • Grow priorities share space
