JSON With Google's Gson

Gson converts Java objects to JSON (toJson) and back (fromJson) with almost no setup. It reads fields directly via reflection, so classes don't need getters or annotations. GsonBuilder customizes naming, nulls, dates, and pretty printing. For generic types like List<User>, use TypeToken.

Notes

  • Artifact: com.google.code.gson:gson
  • Records are supported since Gson 2.10
  • Gson instances are thread-safe; create one and reuse it
  • Null fields are omitted by default

Serialize & Deserialize

record User(String name, int age, List<String> roles) { }

Gson gson = new Gson();
String json = gson.toJson(new User("Ada", 36, List.of("admin")));
// {"name":"Ada","age":36,"roles":["admin"]}

User u = gson.fromJson(json, User.class);

Type listType = new TypeToken<List<User>>(){}.getType();
List<User> users = gson.fromJson("[{\"name\":\"Alan\",\"age\":41}]", listType);

Gson pretty = new GsonBuilder().setPrettyPrinting().serializeNulls()
    .setFieldNamingPolicy(FieldNamingPolicy.LOWER_CASE_WITH_UNDERSCORES)
    .create();

class Product {
    @SerializedName("product_id") String id;     // custom JSON key
    transient String cache;                        // skipped
}

JsonObject obj = JsonParser.parseString(json).getAsJsonObject();   // tree model
obj.get("name").getAsString();                    // "Ada"
obj.getAsJsonArray("roles").size();               // 1

Notes

TypeToken captures the generic type erased at runtime
transient fields are excluded
The tree model (JsonObject) handles JSON without classes

Core API

GsonBuilder Options

OptionEffect
setPrettyPrinting()Indented output
serializeNulls()Include null fields
setFieldNamingPolicy(…)snake_case, etc.
registerTypeAdapter(T, adapter)Custom (e.g., LocalDate)
excludeFieldsWithoutExposeAnnotation()Only @Expose fields

⚠ Common Mistakes

  • gson.fromJson(json, List.class) returns a list of LinkedTreeMap, not your type
  • LocalDate fields without a type adapter — Gson can't access java.time internals on modern JDKs
  • Expecting numbers in Map<String, Object> to be ints — Gson parses them as Double

✓ Tips & Best Practices

  • Keep one configured Gson as a constant
  • Register TypeAdapters for java.time types
  • Use Jackson (Sheet 109) if you're on Spring or need streaming/performance features
