Optional

Optional · of · ofNullable · empty · isPresent · ifPresent · orElse · orElseGet · orElseThrow · map · flatMap

A Container for Maybe-Absent Values

Optional<T> wraps a value that may or may not be present, making "no result" explicit in a method's return type instead of returning null. It provides methods to transform the value, supply defaults, or throw when it's missing, so callers handle absence on purpose.

Notes

  • Designed mainly for return types
  • Don't use it for fields, parameters, or collections
  • Optional.of(null) throws; use ofNullable
  • Primitive versions: OptionalInt, OptionalDouble

Creating & Consuming

Optional<String> a = Optional.of("Ada");
Optional<String> b = Optional.ofNullable(map.get("missing"));   // empty
Optional<String> c = Optional.empty();

a.isPresent();                          // true
b.isEmpty();                            // true (Java 11)
a.get();                                // "Ada"  (avoid: throws if empty)

String name = b.orElse("Guest");                    // "Guest"
String lazy = b.orElseGet(() -> loadDefault());     // called only if empty
String must = a.orElseThrow();                      // throws if empty
String err = b.orElseThrow(() -> new NotFound("user"));

a.ifPresent(n -> System.out.println("Hi " + n));
b.ifPresentOrElse(System.out::println, () -> System.out.println("none"));

int len = a.map(String::length).orElse(0);          // 3
var upper = a.filter(n -> n.startsWith("A")).map(String::toUpperCase);
Optional<Address> addr = findUser(id).flatMap(User::address);
var nicks = users.stream().map(this::nick)
                 .flatMap(Optional::stream).toList();

Notes

orElse always evaluates its argument; orElseGet only when needed
map transforms the value if present
flatMap avoids Optional<Optional<T>>
Optional::stream drops empties in a stream

⚠ Common Mistakes

  • if (opt.isPresent()) opt.get() — use ifPresent, map, or orElse
  • orElse(expensiveCall()) runs the call even when a value exists
  • Returning null from a method declared to return Optional

✓ Tips & Best Practices

  • Make "not found" methods return Optional<T>
  • End chains with orElseThrow when absence is a bug
  • Stream APIs like findFirst and max already return Optional

Quick Summary

  • Explicit "maybe a value"
  • ofNullable — wrap nullable
  • orElse orElseGet orElseThrow
  • map / flatMap / filter
