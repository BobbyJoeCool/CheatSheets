Serialization

Serializable · ObjectOutputStream · ObjectInputStream · serialVersionUID · transient · writeObject · readObject

Saving Objects as Bytes

Java serialization converts an object graph into a byte stream with ObjectOutputStream and rebuilds it with ObjectInputStream. A class opts in by implementing the marker interface Serializable. Fields marked transient are skipped. It's convenient for quick persistence, but it's fragile across versions and unsafe with untrusted data.

Notes

  • Every object in the graph must be Serializable
  • static fields are never serialized
  • Declare serialVersionUID to control version compatibility
  • Never deserialize data from untrusted sources (remote code execution risk)

Write and Read an Object

public class Session implements Serializable {
    private static final long serialVersionUID = 1L;
    private final String user;
    private final List<String> history = new ArrayList<>();
    private transient String password;           // not saved

    public Session(String u, String pw) { user = u; password = pw; }
}

Session s = new Session("ada", "secret");
try (var out = new ObjectOutputStream(
        new BufferedOutputStream(new FileOutputStream("session.bin")))) {
    out.writeObject(s);
}

try (var in = new ObjectInputStream(
        new BufferedInputStream(new FileInputStream("session.bin")))) {
    Session loaded = (Session) in.readObject();   // cast needed
    // loaded.password == null (transient)
}

Notes

readObject returns Object, so you cast
readObject throws ClassNotFoundException as well as IOException
Constructors are not run during deserialization
transient fields get default values

⚠ Common Mistakes

  • Changing a class without a fixed serialVersionUID → InvalidClassException on old files
  • Serializing objects with non-serializable fields → NotSerializableException
  • Deserializing network or user-supplied bytes

✓ Tips & Best Practices

  • Prefer JSON or Protobuf for anything long-lived or shared
  • Use ObjectInputFilter (Java 9+) to restrict allowed classes
  • Mark caches, passwords, and connections transient
