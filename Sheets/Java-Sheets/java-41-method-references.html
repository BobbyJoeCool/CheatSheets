Method References

:: · static reference · bound instance · unbound instance · constructor reference · Comparator.comparing

Naming an Existing Method

A method reference (Class::method) is shorthand for a lambda that just calls an existing method. String::toUpperCase means s -> s.toUpperCase(). It's shorter and often clearer, and works anywhere a lambda of a compatible functional interface is expected.

Notes

  • Four kinds: static, bound instance, unbound instance, constructor
  • No parentheses after the method name
  • Overloaded methods are resolved by the target interface
  • Use a lambda when you need extra arguments or logic

The Four Kinds

// 1. Static method          x -> Integer.parseInt(x)
Function<String, Integer> parse = Integer::parseInt;

// 2. Bound instance (specific object)   s -> System.out.println(s)
Consumer<String> print = System.out::println;
String prefix = "Hi ";
Function<String, String> greet = prefix::concat;   // "Hi " + s

// 3. Unbound instance (first arg is the object)  s -> s.length()
Function<String, Integer> len = String::length;
BiFunction<String, String, Boolean> eq = String::equalsIgnoreCase;

// 4. Constructor            () -> new ArrayList<>()
Supplier<List<String>> mk = ArrayList::new;
Function<String, File> toFile = File::new;

names.forEach(System.out::println);
names.stream().map(String::trim)
     .filter(Predicate.not(String::isBlank)).toList();
people.sort(Comparator.comparing(Person::lastName)
                      .thenComparing(Person::firstName));

Notes

Bound: the object is fixed when the reference is created
Unbound: the object is supplied as the first argument
Predicate.not (Java 11) negates a method reference
Comparator.comparing takes a key-extractor reference

Reference → Lambda

ReferenceEquivalent lambda
Math::absx -> Math.abs(x)
String::toLowerCases -> s.toLowerCase()
list::addx -> list.add(x)
String::compareTo(a, b) -> a.compareTo(b)
Person::new(n) -> new Person(n)

⚠ Common Mistakes

  • Writing String::length() with parentheses — compile error
  • Using an unbound reference where the interface has no "object" parameter
  • Ambiguity with overloaded methods like Integer::toString (static and instance) — use a lambda

✓ Tips & Best Practices

  • Use references when the lambda only forwards its arguments
  • toArray(String[]::new) creates a correctly typed array from a stream
  • Combine with Comparator.comparing for readable sorting
