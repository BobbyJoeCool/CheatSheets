Sheet 09

Arithmetic Operators

+ · - · * · / · % · ++ · -- · integer division · precedence

Doing Math

Java's arithmetic operators work on all numeric primitives. The key rule: if both operands are integers, the result is an integer, so / discards the remainder. % returns the remainder and keeps the sign of the left operand. ++ and -- change a variable by one, with different results depending on prefix or postfix position.

Notes

  • int / int → int; make one operand double to keep decimals
  • Integer division by zero throws ArithmeticException
  • Floating division by zero gives Infinity or NaN
  • * / % bind tighter than + -

Increment, Decrement & Precedence

int x = 5;
int a = x++;      // a = 5, x = 6   (use, then increment)
int b = ++x;      // b = 7, x = 7   (increment, then use)
int c = x--;      // c = 7, x = 6
int d = --x;      // d = 5, x = 5

int r1 = 2 + 3 * 4;        // 14
int r2 = (2 + 3) * 4;      // 20
int r3 = 10 - 4 - 3;       // 3   (left to right)
double avg = (3 + 4) / 2;   // 3.0  ✖ int division first
double ok  = (3 + 4) / 2.0; // 3.5  ✔
int last = 1234 % 10;      // 4   (last digit)
boolean even = 8 % 2 == 0; // true
Math.floorMod(-7, 3);      // 2   (always non-negative)

Notes

Prefix vs postfix only matters when the value is used in the same expression
(3 + 4) / 2 is computed as int before widening to double
Math.floorMod gives a true modulo for negatives

⚠ Common Mistakes

  • double avg = sum / count; with two ints truncates — cast: (double) sum / count
  • x = x++; leaves x unchanged — postfix returns the old value
  • Using % to test odd numbers with n % 2 == 1 fails for negatives; use n % 2 != 0

✓ Tips & Best Practices

  • Use parentheses whenever precedence isn't obvious to a reader
  • Keep ++/-- on their own line or in a for header
  • Math.addExact / multiplyExact throw on overflow

Quick Summary

  • / on ints — truncates
  • % — remainder, sign of left operand
  • x++ — old value; ++x — new value
  • * / % before + -
