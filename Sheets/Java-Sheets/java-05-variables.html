Variables & Constants

declaration · initialization · var · final · static final · camelCase · scope

Declaring Variables

A variable is a named storage slot with a fixed type. You declare it with the type and name, optionally assigning an initial value. Since Java 10, var lets the compiler infer the type of a local variable from its initializer, but the type is still fixed. final makes a variable assignable only once.

Notes

  • Local variables have no default value; reading one before assignment is a compile error
  • Fields get defaults: 0, false, null
  • var only works for local variables with an initializer
  • Constants: static final + UPPER_SNAKE_CASE

Declaration Forms

int age;                     // declare
age = 30;                    // assign
int year = 2026;             // declare + initialize
int a = 1, b = 2, c;         // several at once (c unassigned)
double price = 9.99;
String name = "Ada";

var count = 10;              // inferred: int
var list = new ArrayList<String>();   // ArrayList<String>
// var x;                    // ✖ no initializer
// var y = null;             // ✖ type cannot be inferred

final int LIMIT = 5;
// LIMIT = 6;                // ✖ cannot assign a final variable

static final double TAX_RATE = 0.08;  // class-level constant

Key Points

Type comes first: int age
var is not dynamic typing; count stays int
final locals can be assigned later, but only once
static final — one shared, unchangeable value

⚠ Common Mistakes

  • Using var where the type is unclear: var data = load(); hides what data is
  • Shadowing a field with a same-named local, then wondering why the field never changes
  • Assuming final makes an object immutable — final List can still be modified

✓ Tips & Best Practices

  • Declare variables as close as possible to first use
  • Prefer final for values that never change; it documents intent
  • Use var when the right side already names the type: var map = new HashMap<String,Integer>();

Quick Summary

  • type name = value; — declaration
  • var — local type inference
  • final — assign once
  • static final — class constant
