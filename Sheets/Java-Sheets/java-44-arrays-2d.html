Arrays of Arrays

Java has no true matrix type. A 2D array is an array of arrays: grid[r] is a row (itself an array), and grid[r][c] is one element. Because rows are separate objects, they can have different lengths, which is called a jagged array. The same idea extends to 3D and beyond.

Notes

  • grid.length = number of rows
  • grid[r].length = columns in row r
  • Arrays.deepToString prints nested arrays
  • Row-by-row iteration is fastest (cache-friendly)

Creating & Traversing

int[][] grid = new int[3][4];            // 3 rows × 4 cols, all 0
int[][] m = {
    {1, 2, 3},
    {4, 5, 6}
};
m[1][2];                                  // 6
m.length;                                 // 2 rows
m[0].length;                              // 3 cols

for (int r = 0; r < m.length; r++) {
    for (int c = 0; c < m[r].length; c++) {
        System.out.print(m[r][c] + " ");
    }
    System.out.println();
}
for (int[] row : m)                       // for-each version
    for (int v : row) total += v;

int[][] jag = new int[3][];               // rows sized later
jag[0] = new int[]{1};
jag[1] = new int[]{1, 2};
jag[2] = new int[]{1, 2, 3};
System.out.println(Arrays.deepToString(jag));   // [[1], [1, 2], [1, 2, 3]]

Notes

Always use m[r].length for the inner bound (safe for jagged)
new int[3][] leaves rows null until assigned
Arrays.toString(m) prints row addresses, not values

⚠ Common Mistakes

  • Using m[0].length for every row of a jagged array → index errors
  • int[][] copy = m.clone(); copies only the outer array; rows are still shared
  • Swapping indexes: m[c][r] instead of m[r][c]

✓ Tips & Best Practices

  • Use r/c (or row/col) names, never i/j, for grids
  • Check bounds before reading neighbors: r >= 0 && r < m.length
  • For real linear algebra, use a library (EJML, Apache Commons Math)
