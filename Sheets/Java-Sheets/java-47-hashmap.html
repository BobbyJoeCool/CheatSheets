HashMap

HashMap · put · get · getOrDefault · containsKey · remove · entrySet · merge · computeIfAbsent

Key → Value Lookup

HashMap<K, V> stores key-value pairs and finds values by key in about O(1) time using each key's hashCode() and equals(). Keys are unique; putting an existing key replaces its value. Iteration order is not guaranteed. Use LinkedHashMap for insertion order or TreeMap for sorted keys.

Notes

  • Allows one null key and many null values
  • get returns null for missing keys
  • Custom key classes must override equals and hashCode
  • Map.of(...) is immutable and rejects nulls

Map Operations

Map<String, Integer> stock = new HashMap<>();
stock.put("apple", 5);                     // {apple=5}
stock.put("pear", 2);
stock.put("apple", 7);                     // replaces → 7
stock.get("apple");                        // 7
stock.get("kiwi");                         // null
stock.getOrDefault("kiwi", 0);             // 0
stock.containsKey("pear");                 // true
stock.putIfAbsent("pear", 99);             // stays 2
stock.remove("pear");                      // 2
stock.size();                              // 1

Map<String, Integer> counts = new HashMap<>();
for (String w : words)
    counts.merge(w, 1, Integer::sum);      // word count

Map<String, List<String>> byDept = new HashMap<>();
byDept.computeIfAbsent("eng", k -> new ArrayList<>()).add("Ada");

for (var e : stock.entrySet())
    System.out.println(e.getKey() + "=" + e.getValue());

Notes

merge(k, 1, sum) — insert 1 or add 1
computeIfAbsent — create the bucket list on first use
entrySet() — key and value without extra lookups

⚠ Common Mistakes

  • int c = map.get(k); NPE when the key is missing — use getOrDefault
  • Mutating a key object after inserting it; its hash changes and it's lost
  • Assuming HashMap iteration order is stable or sorted

✓ Tips & Best Practices

  • Use merge for counters and computeIfAbsent for grouping
  • Use EnumMap when keys are enum constants
  • Use Map.entry(k, v) and Map.ofEntries for small constant maps

Quick Summary

  • put / get — O(1) lookup
  • Unique keys, no order
  • getOrDefault merge computeIfAbsent
  • Keys need equals + hashCode
