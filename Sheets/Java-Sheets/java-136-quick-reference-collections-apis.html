⚠ Common Mistakes

  • Modifying a list while looping over it (ConcurrentModificationException)
  • List.of / Map.of are immutable — add throws
  • Building SQL by string concatenation instead of PreparedStatement

✓ Tips & Best Practices

  • Program to interfaces: List, Map, Set
  • Use java.time, never Date / Calendar, for new code
  • Use virtual threads for blocking I/O on Java 21+

Quick Summary

  • ArrayList / HashMap / HashSet are the defaults
  • Streams: filter → map → collect
  • Comparator.comparing for sorting
  • Files + Path for I/O; JUnit + Mockito for tests
