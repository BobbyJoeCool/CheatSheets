Mutable Strings

Because String is immutable, building text with + in a loop creates a new string every pass. StringBuilder is a mutable character buffer: append, insert, delete, and reverse modify it in place, and toString() produces the final String. Methods return the builder itself, so calls can be chained.

Notes

  • Not thread-safe; StringBuffer is the synchronized version (Sheet 19)
  • Default capacity is 16 characters; it grows automatically
  • The compiler already optimizes simple a + b + c expressions
  • Use it when concatenating inside loops

Building Text

StringBuilder sb = new StringBuilder();
sb.append("Hello").append(", ").append("World")
  .append('!').append(2026);         // Hello, World!2026

sb.insert(0, ">> ");                 // >> Hello, World!2026
sb.delete(sb.length() - 4, sb.length());   // >> Hello, World!
sb.deleteCharAt(0);                  // > Hello, World!
sb.replace(2, 7, "Howdy");           // > Howdy, World!
sb.setCharAt(0, '<');                // < Howdy, World!
String result = sb.toString();

new StringBuilder("stressed").reverse().toString();   // "desserts"

StringBuilder csv = new StringBuilder(256);           // pre-sized
for (int i = 0; i < 5; i++) {
    if (!csv.isEmpty()) csv.append(',');
    csv.append(i);
}                                                     // "0,1,2,3,4"
sb.setLength(0);                                      // clear & reuse

Notes

delete(start, end) — end is exclusive
setLength(0) empties the builder without reallocating
String.join / Collectors.joining are simpler for separators

⚠ Common Mistakes

  • str += piece inside a large loop — O(n²) copying
  • Comparing two builders with equals — it compares references; use compareTo or toString()
  • Forgetting toString() when a String is required

✓ Tips & Best Practices

  • Pre-size with new StringBuilder(expectedLength) for big outputs
  • Chain calls for readability
  • Reuse one builder in loops with setLength(0)

Quick Summary
