Date + Time, With and Without Zones

LocalDateTime combines a date and a time but has no zone, so it doesn't identify an exact moment. ZonedDateTime adds a ZoneId (like America/New_York) and handles daylight saving. Instant is an exact point on the UTC timeline, ideal for timestamps and logs.

Notes

  • Store moments as Instant (UTC); convert to a zone for display
  • ZoneId.of("Europe/Paris") — use region IDs, not "CET"
  • DST gaps and overlaps are resolved automatically
  • Instant.toEpochMilli() ↔ legacy millisecond timestamps

Converting Between Types

LocalDateTime meeting = LocalDateTime.of(2026, 10, 2, 14, 30);
LocalDateTime ldt = LocalDate.of(2026, 1, 1).atTime(9, 0);
LocalDateTime now = LocalDateTime.now();

ZonedDateTime ny = meeting.atZone(ZoneId.of("America/New_York"));
ZonedDateTime tokyo = ny.withZoneSameInstant(ZoneId.of("Asia/Tokyo"));
// ny:    2026-10-02T14:30-04:00[America/New_York]
// tokyo: 2026-10-03T03:30+09:00[Asia/Tokyo]

Instant stamp = Instant.now();                     // 2026-10-02T18:30:00Z
long ms = stamp.toEpochMilli();
Instant back = Instant.ofEpochMilli(ms);
ZonedDateTime local = stamp.atZone(ZoneId.systemDefault());

meeting.toLocalDate();                             // 2026-10-02
meeting.plusHours(36);                             // 2026-10-04T02:30
Duration d = Duration.between(stamp, stamp.plusSeconds(90));   // PT1M30S

Notes

withZoneSameInstant — same moment, different wall clock
withZoneSameLocal — same wall clock, different moment
Instant prints in UTC with a trailing Z

⚠ Common Mistakes

  • Storing LocalDateTime for events users see in different zones
  • Using three-letter zone IDs like "EST" — ambiguous, and some don't observe DST
  • Assuming a day is always 24 hours; DST days are 23 or 25

✓ Tips & Best Practices

  • Persist Instant (or TIMESTAMP WITH TIME ZONE)
  • Convert to the user's zone only at display time
  • Use ZoneId.getAvailableZoneIds() for zone pickers

Quick Summary

  • LocalDateTime — no zone
  • ZonedDateTime — zone + DST
  • Instant — UTC moment
  • Store UTC, display local
