Declarative Layouts in XML

FXML describes a JavaFX scene graph in XML, separating layout from logic. FXMLLoader reads the file and builds the nodes. fx:controller names the Java class that handles events (Sheet 132), fx:id links elements to controller fields, and #method attributes link events to controller methods. Scene Builder edits FXML visually.

Notes

  • Requires the javafx-fxml artifact
  • Store .fxml files under src/main/resources
  • Modules must opens the controller package to javafx.fxml
  • Element names are class names; attributes are properties

login.fxml

<?xml version="1.0" encoding="UTF-8"?>
<?import javafx.scene.control.*?>
<?import javafx.scene.layout.*?>

<VBox xmlns:fx="http://javafx.com/fxml"
      fx:controller="com.acme.ui.LoginController"
      spacing="10" alignment="CENTER" prefWidth="300">
  <padding><Insets top="20" right="20" bottom="20" left="20"/></padding>
  <Label text="Sign in" styleClass="title"/>
  <TextField fx:id="userField" promptText="Username"/>
  <PasswordField fx:id="passField" promptText="Password"/>
  <Button text="Log in" defaultButton="true" onAction="#handleLogin"/>
  <Label fx:id="errorLabel" styleClass="error"/>
</VBox>

Notes

<?import?> lines work like Java imports
fx:id="userField" → controller field userField
onAction="#handleLogin" → controller method
defaultButton fires on Enter

Loading FXML

public void start(Stage stage) throws IOException {
    FXMLLoader loader = new FXMLLoader(
        getClass().getResource("/com/acme/ui/login.fxml"));
    Parent root = loader.load();
    LoginController ctrl = loader.getController();
    stage.setScene(new Scene(root));
    stage.show();
}

⚠ Common Mistakes

  • Wrong resource path → NullPointerException: Location is required
  • fx:id without a matching @FXML field (or a typo) → field stays null
  • Forgetting opens … to javafx.fxml in module-info.java → IllegalAccessException

✓ Tips & Best Practices

  • Paths starting with / are relative to the classpath root
  • Design in Scene Builder, then polish by hand
  • Split big screens with fx:include

Quick Summary

  • XML layout → FXMLLoader.load()
  • fx:controller names the logic class
  • fx:id → fields, #method → events
  • Keep layout separate from code
