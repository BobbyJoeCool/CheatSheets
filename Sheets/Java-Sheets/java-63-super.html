The super Keyword

super · super() · super.method() · super.field · constructor chaining · multi-level inheritance

Reaching the Parent

super refers to the parent-class part of the current object. super(...) calls a parent constructor and must be the first statement in a constructor. super.method() calls the parent's version of an overridden method, letting a subclass extend behavior instead of replacing it entirely.

Notes

  • If you don't call super(...), Java inserts super()
  • super.super.method() is not allowed
  • super can't be used in static contexts
  • Hidden fields can be reached with super.field

Extending Behavior

class Employee {
    protected final String name;
    protected double baseSalary;

    Employee(String n, double b) { name = n; baseSalary = b; }
    double pay() { return baseSalary; }
}

class Manager extends Employee {
    private final double bonus;

    Manager(String name, double base, double bonus) {
        super(name, base);                         // 1. parent constructor
        this.bonus = bonus;
    }
    @Override
    double pay() { return super.pay() + bonus; }   // 2. reuse parent logic

}

class Director extends Manager {
    Director(String n) { super(n, 150_000, 30_000); }   // multi-level
    @Override
    double pay() { return super.pay() * 1.1; }          // Manager.pay()
}
new Director("Ada").pay();   // (150000 + 30000) × 1.1 = 198000.0

Notes

super.pay() calls the immediate parent's version
Director → Manager → Employee: each layer adds to the last
Constructors run top-down: Employee, Manager, Director

⚠ Common Mistakes

  • Calling super(...) after other statements — compile error
  • Forgetting super.method() when you meant to extend, not replace, behavior
  • Declaring a field with the same name as the parent's (field hiding) and confusing which one is used

✓ Tips & Best Practices

  • Call super.method() first or last consistently, and document which
  • Avoid field hiding; give subclass fields distinct names
  • Keep constructors simple so chains are easy to follow

Quick Summary

  • super(...) — parent constructor, first line
  • super.m() — parent method
  • Chains run parent → child
  • No super.super
