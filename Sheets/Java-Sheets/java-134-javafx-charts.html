JavaFX Charts & Media

LineChart · BarChart · PieChart · XYChart.Series · NumberAxis · CategoryAxis · Media · MediaPlayer · MediaView

Visualizing Data and Playing Media

JavaFX includes ready-made charts in javafx.scene.chart: line, bar, area, scatter, bubble, and pie. XY charts take one or more XYChart.Series of data points plotted against two axes. The javafx-media module adds Media, MediaPlayer, and MediaView for audio and video playback.

Notes

  • Charts are nodes; add them to any layout
  • Updating a series' data list updates the chart live
  • Media requires the javafx-media artifact
  • Supported media: MP3, WAV, AAC, MP4 (H.264), HLS streams

Charts & Media

NumberAxis x = new NumberAxis(1, 12, 1);
NumberAxis y = new NumberAxis();
x.setLabel("Month");  y.setLabel("Sales ($k)");
LineChart<Number, Number> line = new LineChart<>(x, y);

XYChart.Series<Number, Number> s2026 = new XYChart.Series<>();
s2026.setName("2026");
s2026.getData().addAll(new XYChart.Data<>(1, 23),
                       new XYChart.Data<>(2, 31));
line.getData().add(s2026);

var bar = new BarChart<String, Number>(new CategoryAxis(), new NumberAxis());
XYChart.Series<String, Number> q = new XYChart.Series<>();
q.getData().add(new XYChart.Data<>("Q1", 120));
bar.getData().add(q);

PieChart pie = new PieChart(FXCollections.observableArrayList(
    new PieChart.Data("Java", 45), new PieChart.Data("Kotlin", 30)));

Media media = new Media(Path.of("intro.mp4").toUri().toString());
MediaPlayer player = new MediaPlayer(media);
MediaView view = new MediaView(player);
player.setOnReady(player::play);

Notes

Numeric axes take lower bound, upper bound, tick unit
One series = one line or bar group; add several to compare
Media needs a URI string, not a file path
setOnReady waits until media metadata loads

⚠ Common Mistakes

  • Passing a plain file path to new Media(...) → MediaException; use toUri().toString()
  • Re-creating a whole chart for new data instead of updating its series
  • Forgetting the javafx-media dependency or module requirement

✓ Tips & Best Practices

  • Call chart.setAnimated(false) when updating data rapidly
  • Style charts with CSS: .chart-series-line { -fx-stroke: … }
  • Keep a reference to MediaPlayer so it isn't garbage-collected mid-playback
