Logical Operators

&& · || · ! · short-circuit · & · | · ^ · De Morgan

Combining Conditions

Logical operators combine boolean values. && (AND) and || (OR) short-circuit: they stop evaluating as soon as the result is known, which lets you guard a risky check behind a safe one. The non-short-circuit forms & and | always evaluate both sides, and ^ is exclusive OR.

Notes

  • Operands must be boolean; if (1) does not compile in Java
  • ! binds tighter than &&, which binds tighter than ||
  • Short-circuiting is the standard null-guard pattern
  • ^ on booleans is true when exactly one side is true

Short-Circuit in Practice

String s = null;
if (s != null && s.length() > 3) { }   // safe: right side skipped
if (s.length() > 3 && s != null) { }   // ✖ NullPointerException

int i = 0;
boolean r1 = false && (++i > 0);        // i stays 0
boolean r2 = false &  (++i > 0);        // i becomes 1

boolean inRange = age >= 18 && age <= 65;
boolean weekend = day == SAT || day == SUN;
boolean ok = !(a || b);                 // same as !a && !b
boolean mix = a || b && c;              // a || (b && c)

Notes

Put the cheap or null check first in &&
& and | are mainly for bitwise math (Sheet 12)
De Morgan: !(a && b) ≡ !a || !b
Add parentheses when mixing && and ||

⚠ Common Mistakes

  • Writing & when you meant && — both sides run, and null guards stop working
  • if (x > 0 || x < 10) is always true; you probably meant &&
  • if (flag == true) is redundant; write if (flag)

✓ Tips & Best Practices

  • Extract long conditions into named booleans: boolean canVote = ...
  • Order && checks from cheapest to most expensive
  • Use Objects.nonNull / Objects.isNull in stream filters

Quick Summary

  • && — both true, short-circuits
  • || — either true, short-circuits
  • ! — invert
  • ^ — exactly one true
