Advanced Strings

StringBuffer · intern · compareTo · compareToIgnoreCase · matches · chars · codePoints · String.valueOf

Beyond the Basics

This sheet covers the less common parts of String: lexicographic comparison, the string pool and intern(), Unicode code points, and the thread-safe StringBuffer. For everyday string building, use StringBuilder (Sheet 90); this sheet explains when its older sibling still applies.

Notes

  • compareTo compares UTF-16 values, so "Z" < "a"
  • intern() returns the pooled copy of a string
  • Emoji take two chars (a surrogate pair)
  • StringBuffer is synchronized; StringBuilder is not

Comparison, Pooling & Unicode

"apple".compareTo("apricot");          // -2  ('p' − 'r')
"Zebra".compareTo("apple");            // -7  (uppercase sorts first)
"Zebra".compareToIgnoreCase("apple");  // 25
"abc".compareTo("abcd");               // -1  (shorter first)

String a = new String("hi");
String b = a.intern();
b == "hi";                              // true (pooled instance)

String e = "Hi 👋";
e.length();                             // 5  (UTF-16 units)
e.codePointCount(0, e.length());        // 4  (real characters)
e.codePoints().forEach(cp ->
    System.out.print(Character.toChars(cp)));   // Hi 👋

StringBuffer sb = new StringBuffer("ab");
sb.append("cd").reverse();               // "dcba" (thread-safe)
"2026-10-02".matches("\\d{4}-\\d{2}-\\d{2}");    // true

Notes

Use Collator for language-aware sorting
intern() is rarely needed; the JVM pools literals automatically
Use codePoints() when text may contain emoji
matches must match the whole string

⚠ Common Mistakes

  • Sorting user-facing names with compareTo — uppercase letters sort before lowercase
  • Using length() to count characters in emoji-rich text
  • Reaching for StringBuffer by default — it's slower and almost never needed

✓ Tips & Best Practices

  • String.CASE_INSENSITIVE_ORDER is a ready-made Comparator
  • Use Collator.getInstance(Locale.US) for natural-language sorting
  • Use StringBuilder (Sheet 90) for all single-threaded building
