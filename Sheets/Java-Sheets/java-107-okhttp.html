A Popular HTTP Client Library

OkHttp (by Square) is a widely used HTTP client, especially on Android, where it underpins Retrofit. It offers connection pooling, transparent GZIP, caching, automatic retries, and interceptors for logging or adding headers. Requests are built with Request.Builder, executed synchronously with execute() or asynchronously with enqueue().

Notes

  • Artifact: com.squareup.okhttp3:okhttp
  • Reuse one OkHttpClient across the app
  • Always close the Response (try-with-resources)
  • response.body().string() can be read only once

Requests With OkHttp

OkHttpClient client = new OkHttpClient.Builder()
    .connectTimeout(Duration.ofSeconds(5))
    .addInterceptor(chain -> chain.proceed(chain.request().newBuilder()
        .header("Authorization", "Bearer " + token).build()))
    .build();

Request req = new Request.Builder().url(base + "/users/1").build();
try (Response res = client.newCall(req).execute()) {
    if (!res.isSuccessful()) throw new IOException("HTTP " + res.code());
    String json = res.body().string();
}

MediaType JSON = MediaType.get("application/json");
RequestBody body = RequestBody.create("{\"name\":\"Ada\"}", JSON);
Request post = new Request.Builder().url(base + "/users")
    .post(body).build();

client.newCall(post).enqueue(new Callback() {           // async
    public void onResponse(Call call, Response res) throws IOException {
        try (res) { System.out.println(res.code()); }
    }
    public void onFailure(Call call, IOException e) { e.printStackTrace(); }
});

Notes

The interceptor adds an auth header to every request
isSuccessful() is true for 200–299
enqueue runs on OkHttp's thread pool
In OkHttp 4, RequestBody.create(String, MediaType) argument order matters

⚠ Common Mistakes

  • Not closing Response → leaked connections and "A connection was leaked" warnings
  • Calling body().string() twice — the stream is consumed after the first call
  • Creating a client per request, which defeats connection pooling

✓ Tips & Best Practices

  • Add HttpLoggingInterceptor (okhttp-logging) for debugging
  • Use Retrofit on top of OkHttp for typed REST APIs
  • Use client.newBuilder() to derive clients with different timeouts

Quick Summary

  • OkHttpClient — reuse it
  • Request.Builder → newCall
  • execute() sync / enqueue() async
  • Close every Response
