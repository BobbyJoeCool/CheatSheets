Dates Without Times

LocalDate (in java.time, Java 8+) represents a calendar date such as 2026-10-02, with no time and no time zone. It's immutable and thread-safe, so every "change" returns a new object. Use it for birthdays, due dates, and holidays. It replaces the old java.util.Date and Calendar APIs.

Notes

  • Months are 1–12 (unlike the old Calendar's 0–11)
  • parse expects ISO format yyyy-MM-dd by default
  • Period measures date-based amounts (years, months, days)
  • Formatting is on Sheet 94

Working With Dates

LocalDate today = LocalDate.now();                  // 2026-10-02
LocalDate d = LocalDate.of(2026, 12, 25);
LocalDate p = LocalDate.parse("2026-03-15");

d.getYear();                 // 2026
d.getMonth();                // DECEMBER
d.getMonthValue();           // 12
d.getDayOfWeek();            // FRIDAY
d.getDayOfYear();            // 359
d.isLeapYear();              // false
d.lengthOfMonth();           // 31

LocalDate due = today.plusDays(30).plusMonths(1);   // new object
today.minusWeeks(2);
today.withDayOfMonth(1);                            // first of month
today.with(TemporalAdjusters.lastDayOfMonth());

today.isBefore(d);                                  // true
long days = ChronoUnit.DAYS.between(today, d);      // 84
Period age = Period.between(LocalDate.of(1990, 5, 1), today);
age.getYears();                                     // 36

Notes

plusX returns a new date; assign the result
ChronoUnit.DAYS.between — total days
Period.between — years/months/days breakdown
TemporalAdjusters handles "next Monday", "last day"

⚠ Common Mistakes

  • Calling date.plusDays(1); without assigning — the original never changes
  • of(2026, 2, 30) → DateTimeException; invalid dates are rejected
  • Using LocalDate for timestamps that need a time zone; use ZonedDateTime or Instant

✓ Tips & Best Practices

  • Store dates as ISO strings or SQL DATE
  • Inject a Clock and call LocalDate.now(clock) for testable code
  • Use datesUntil to loop over a range of days
