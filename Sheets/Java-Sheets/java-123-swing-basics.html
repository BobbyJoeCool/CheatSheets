Desktop GUIs With Swing

Swing (javax.swing) is the long-standing GUI toolkit bundled with the JDK. A window is a JFrame; you add components like labels, buttons, and text fields to panels inside it. All Swing work must happen on the Event Dispatch Thread (EDT), so start your UI with SwingUtilities.invokeLater.

Notes

  • Swing ships with every JDK; no dependency needed
  • Swing is not thread-safe; touch components only on the EDT
  • Long tasks on the EDT freeze the UI; use SwingWorker

A Minimal Window

import javax.swing.*;

public class HelloSwing {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(HelloSwing::createUi);   // run on EDT
    }
    private static void createUi() {
        JFrame frame = new JFrame("Greeter");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        JTextField name = new JTextField(12);
        JButton greet = new JButton("Greet");
        JLabel out = new JLabel("…");
        greet.addActionListener(e -> out.setText("Hi, " + name.getText()));

        JPanel panel = new JPanel();
        panel.add(new JLabel("Name:")); panel.add(name);
        panel.add(greet);               panel.add(out);
        frame.add(panel);
        frame.pack();                       // size to fit contents
        frame.setLocationRelativeTo(null);  // center on screen
        frame.setVisible(true);
    }
}

Notes

invokeLater queues UI creation on the EDT
EXIT_ON_CLOSE ends the program when the window closes
pack() sizes the frame to its components' preferred sizes
Call setVisible(true) last

⚠ Common Mistakes

  • Building or updating components from main or a background thread
  • Running slow work (network, DB) inside a button listener, freezing the window
  • Calling setVisible(true) before adding components, causing layout glitches

✓ Tips & Best Practices

  • JOptionPane.showMessageDialog(frame, "Saved") for quick alerts
  • Set a modern look: UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName())
  • FlatLaf gives Swing a contemporary appearance

Quick Summary

  • JFrame → JPanel → components
  • Start with invokeLater (EDT)
  • pack() then setVisible(true)
  • SwingWorker for slow tasks
