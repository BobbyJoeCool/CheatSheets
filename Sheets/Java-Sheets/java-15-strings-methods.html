Common String Methods

String has a large built-in API for searching, extracting, and transforming text. Indexes are zero-based, and ranges like substring(begin, end) include begin but exclude end. Because strings are immutable, every transforming method returns a new string.

Notes

  • Out-of-range indexes throw StringIndexOutOfBoundsException
  • indexOf returns -1 when not found
  • split takes a regex: escape . and |
  • strip() is Unicode-aware; trim() only removes ≤ U+0020

Splitting & Chaining

"a,b,,c".split(",");            // [a, b, , c]
"a,b,,c,,".split(",");          // [a, b, , c]   trailing empties dropped
"a,b,,c,,".split(",", -1);      // [a, b, , c, , ] keep them
"1.2.3".split("\\.");           // [1, 2, 3]   escape the dot
"a | b".split("\\s*\\|\\s*");    // [a, b]
"one  two".split("\\s+");        // [one, two]

String clean = "  Ada LOVELACE ".strip().toLowerCase();  // "ada lovelace"
String initials = clean.charAt(0) + "" + clean.charAt(4);  // "al"
"banana".chars().filter(ch -> ch == 'a').count();         // 3
String.valueOf(new char[]{'h','i'});                       // "hi"
"hello".toCharArray();                                     // [h, e, l, l, o]

Notes

split(",", -1) keeps trailing empty fields (important for CSV)
"\\." — escaped for regex, then for Java
chars() gives an IntStream of character codes

⚠ Common Mistakes

  • "1.2.3".split(".") returns an empty array — . means "any character" in regex
  • Using replaceAll for a plain-text replace with special chars; use replace
  • Off-by-one in substring(b, e) — the end index is exclusive

✓ Tips & Best Practices

  • Use replace for literal text, replaceAll only for regex
  • Prefer strip() over trim() in modern code
  • Use s.indexOf(x) >= 0 or contains — don't loop manually

Quick Summary

  • charAt indexOf contains — search
  • substring(b, e) — e exclusive
  • replace strip toLowerCase — transform
  • split(regex) — tokenize
