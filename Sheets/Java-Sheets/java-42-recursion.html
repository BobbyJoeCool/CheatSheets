Recursion

Methods That Call Themselves

A recursive method solves a problem by calling itself on a smaller version of the same problem. Every recursive method needs a base case that returns without recursing, and a recursive case that moves toward it. Each call adds a frame to the call stack, so very deep recursion throws StackOverflowError.

Notes

  • Java does not optimize tail calls
  • Default stack handles roughly a few thousand to tens of thousands of frames
  • Recursion suits trees, nested data, and divide-and-conquer
  • Naive Fibonacci is exponential; memoize or iterate

Classic Examples

static long factorial(int n) {
    if (n <= 1) return 1;               // base case
    return n * factorial(n - 1);        // recursive case
}
factorial(5);                           // 120

static int sumDigits(int n) {
    return n < 10 ? n : n % 10 + sumDigits(n / 10);
}
sumDigits(1234);                        // 10

static long fib(int n) {                // O(2^n) — slow
    return n < 2 ? n : fib(n - 1) + fib(n - 2);
}

static Map<Integer, Long> memo = new HashMap<>();
static long fastFib(int n) {            // O(n) with memoization
    if (n < 2) return n;
    Long cached = memo.get(n);
    if (cached != null) return cached;
    long r = fastFib(n - 1) + fastFib(n - 2);
    memo.put(n, r);
    return r;
}

Notes

factorial(5) = 5 × 4 × 3 × 2 × 1
Each call waits on the next; results unwind back up
Don't memoize with HashMap.computeIfAbsent recursively; it throws ConcurrentModificationException

⚠ Common Mistakes

  • Missing or unreachable base case → StackOverflowError
  • Recursive step that doesn't shrink the problem (f(n) calling f(n))
  • Using recursion for simple loops over large ranges

✓ Tips & Best Practices

  • Write the base case first
  • Memoize overlapping subproblems or convert to a loop
  • Use recursion for trees, directories, and parsing nested structures

Quick Summary

  • Base case — stops recursion
  • Recursive case — smaller input
  • Each call uses stack space
  • Memoize repeated work
