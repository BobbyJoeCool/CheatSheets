Times Without Dates

LocalTime represents a time of day like 14:30:15, with no date and no time zone, down to nanosecond precision. It's immutable and wraps around midnight: adding 2 hours to 23:00 gives 01:00. Use it for opening hours, alarms, and schedules that repeat daily.

Notes

  • Range: 00:00 to 23:59:59.999999999
  • Duration measures time-based amounts
  • Arithmetic wraps at midnight with no day overflow
  • parse expects HH:mm or HH:mm:ss

Working With Times

LocalTime now = LocalTime.now();               // 14:32:07.123456
LocalTime open = LocalTime.of(9, 0);           // 09:00
LocalTime close = LocalTime.parse("17:30");    // 17:30

open.getHour();                  // 9
close.getMinute();               // 30
LocalTime.NOON;                  // 12:00
LocalTime.MIDNIGHT;              // 00:00

open.plusHours(2).plusMinutes(15);             // 11:15
LocalTime.of(23, 0).plusHours(2);              // 01:00 (wraps)
now.truncatedTo(ChronoUnit.MINUTES);           // 14:32
now.withSecond(0).withNano(0);                 // 14:32

boolean isOpen = !now.isBefore(open) && now.isBefore(close);
Duration shift = Duration.between(open, close);
shift.toMinutes();                             // 510
shift.toHours();                               // 8
shift.toMinutesPart();                         // 30
long mins = ChronoUnit.MINUTES.between(open, close);   // 510

Notes

!isBefore(open) means "at or after open"
Duration.toMinutesPart gives the leftover minutes
truncatedTo drops smaller units
Wrap-around means overnight spans need extra care

⚠ Common Mistakes

  • Duration.between(23:00, 01:00) is negative (−22h) — overnight spans need dates
  • Forgetting results are new objects: t.plusHours(1); alone does nothing
  • Comparing times with == instead of equals/isBefore

✓ Tips & Best Practices

  • Use LocalDateTime (Sheet 93) when spans cross midnight
  • Truncate before display or comparison to avoid nanosecond noise
  • Format with DateTimeFormatter.ofPattern("h:mm a") (Sheet 94)
