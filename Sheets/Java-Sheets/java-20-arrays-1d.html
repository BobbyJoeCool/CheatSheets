Fixed-Size Collections

An array stores a fixed number of elements of one type in contiguous memory. Its size is set when created and cannot change. Elements are accessed by zero-based index, and length (a field, not a method) gives the size. Arrays are objects, so array variables hold references.

Notes

  • New arrays are filled with defaults: 0, false, null
  • Accessing index length or beyond throws ArrayIndexOutOfBoundsException
  • Assigning one array variable to another shares the same array
  • For resizable lists, use ArrayList (Sheet 45)

Creating & Using Arrays

int[] scores = new int[5];             // [0, 0, 0, 0, 0]
String[] names = {"Ada", "Alan", "Grace"};   // literal
double[] temps = new double[]{1.5, 2.5};    // explicit form

scores[0] = 90;                        // set
int first = scores[0];                 // get: 90
names.length;                          // 3
names[names.length - 1];               // "Grace" (last)

for (int i = 0; i < scores.length; i++) {
    scores[i] = i * 10;                // [0, 10, 20, 30, 40]
}
for (String n : names) System.out.println(n);

int[] copy = scores;                   // same array!
copy[0] = 99;                          // scores[0] is now 99
int[] real = Arrays.copyOf(scores, scores.length);  // true copy
System.out.println(Arrays.toString(scores));   // [99, 10, 20, 30, 40]

Notes

int[] a is preferred over int a[]
Array literals {...} only work in declarations
Printing an array directly shows [I@1b6d3586
Arrays.toString gives readable output

⚠ Common Mistakes

  • Looping with i <= a.length — the last valid index is length - 1
  • Comparing arrays with == or .equals() — use Arrays.equals
  • Expecting a = b to copy — it copies the reference

✓ Tips & Best Practices

  • Use the enhanced for when you don't need the index
  • Prefer List when the size may change
  • int[] a = {} creates an empty array safely, avoiding null

Quick Summary

  • type[] name = new type[n] — create
  • a[i] — zero-based access
  • a.length — size (field)
  • Arrays.toString — print contents
