String Basics

String literal · immutability · + concat · length() · string pool · text blocks · null vs ""

Strings in Java

A String is an immutable sequence of characters and a full object, not a primitive. Every method that seems to change a string actually returns a new one. Literals are stored in a shared string pool, so identical literals share one object. Java 15 added text blocks (""") for multi-line strings.

Notes

  • String is in java.lang, so no import is needed
  • length() is a method; arrays use .length field
  • null (no object) is different from "" (empty string)
  • isBlank() (Java 11+) treats whitespace-only as empty

Under the JVM

  • Literals live in the string pool; identical literals share one object
  • Compact strings (9): Latin-1 text stores 1 byte per char, not 2
  • a + b compiles to invokedynamic StringConcatFactory (9), not a StringBuilder

Creating & Combining Strings

String a = "Java";                  // literal (pooled)
String b = new String("Java");      // forces a new object (rarely needed)
String empty = "";
String none = null;

a.length();                          // 4
"".isEmpty();                        // true
"  ".isBlank();                      // true

String full = a + " " + 21;          // "Java 21"
String c = "Hi".concat("!");         // "Hi!"
String joined = String.join("-", "a", "b", "c");   // "a-b-c"
"ab".repeat(3);                      // "ababab"

a.toUpperCase();                     // "JAVA" (new string)
System.out.println(a);               // "Java" (unchanged)

String json = """
    {"name": "Ada",
     "age": 36}
    """;                             // text block, keeps line breaks

Notes

toUpperCase() returns a new string; a is unchanged
+ with any type converts it via String.valueOf
Text blocks strip common leading indentation
none.length() throws NullPointerException

Java Versions

  • 1.0 — immutable String, literals, +
  • 11 — isBlank · strip · lines · repeat
  • 15 — text blocks """

Idiomatic Java

  • Multi-line literal glued with + "\n" + → a text block
  • s.length() == 0 → s.isEmpty()
  • s.trim().isEmpty() → s.isBlank()

⚠ Common Mistakes

  • Calling s.toUpperCase(); without assigning — strings are immutable, the result is lost
  • Using .length (no parentheses) on a String — that's for arrays
  • Confusing 'a' (char) with "a" (String)

✓ Tips & Best Practices

  • Check s == null || s.isBlank() before trusting user input
  • Use text blocks for SQL, JSON, and HTML snippets
  • Use String.join instead of manual loops with separators

Quick Summary

  • String — immutable object
  • length() — character count
  • + / concat / join — combine
  • """ — text block
