Reusing and Extending Classes

Inheritance lets a class (subclass) acquire the fields and methods of another (superclass) with extends. The subclass can add members and override behavior. Java allows single class inheritance only, and every class ultimately extends Object. Use inheritance for genuine is-a relationships.

Notes

  • Private members are inherited but not directly accessible
  • protected members are visible to subclasses
  • final class cannot be extended (e.g., String)
  • Prefer composition ("has-a") when "is-a" is doubtful

Class Hierarchy

public class Vehicle {
    protected final String make;
    private int speed;

    public Vehicle(String make) { this.make = make; }
    public void accelerate(int amt) { speed += amt; }
    public int getSpeed() { return speed; }
    public String describe() { return make + " vehicle"; }
}public class Car extends Vehicle {               // Car is-a Vehicle
    private final int doors;

    public Car(String make, int doors) {
        super(make);                             // parent constructor
        this.doors = doors;
    }
    @Override
    public String describe() { return make + " car, " + doors + " doors"; }
}

Car c = new Car("Volvo", 4);
c.accelerate(30);                 // inherited
c.getSpeed();                     // 30
c.describe();                     // "Volvo car, 4 doors"
Vehicle v = c;                    // a Car is a Vehicle

Notes

make is protected, so Car can read it
speed is private: use getSpeed()
super(make) must run first
A Car can be stored in a Vehicle variable

Inheritance vs Composition

UseWhen
extendsTrue is-a, shared behavior
Compositionhas-a, reuse without coupling
InterfaceShared capability across unrelated classes

⚠ Common Mistakes

  • Using inheritance just to reuse code (e.g., Stack extends Vector)
  • Forgetting super(...) when the parent has no no-arg constructor — compile error

✓ Tips & Best Practices

  • Favor composition over inheritance by default
  • Mark classes final unless designed for extension
  • Keep shared state private with protected accessors if needed

Quick Summary

  • extends — single inheritance
  • Subclass inherits members
  • super(...) — parent constructor
  • Use for real is-a relationships
