Program Structure

package · import · class · main · static void · String[] args · braces

Anatomy of a Java Program

Every Java program lives inside a class. Execution starts at the main method, which must be public static void and take a String[]. Statements end with semicolons, blocks use curly braces, and indentation is for readers only. Optional package and import lines always come first, in that order.

Rules

  • One public class per file, and the file name must match it
  • Java is case-sensitive: Main ≠ main
  • Java 21+ preview / Java 25: void main() { } works in a single-file program
  • Class names use PascalCase; methods and variables use camelCase

Annotated Boilerplate

package com.example.app;           // 1. package (optional, first line)

import java.util.List;             // 2. imports
import java.util.Scanner;

public class Main {                // 3. class declaration
    static final int MAX = 10;     // 4. fields (class members)

    public static void main(String[] args) {   // 5. entry point
        System.out.println("args: " + args.length);
        greet("Ada");              // 6. call another method
    }

    static void greet(String name) {           // 7. other methods
        System.out.println("Hi, " + name);
    }
}

Line by Line

package — namespace; must match the folder path
import — lets you use List instead of java.util.List
public — visible to the JVM launcher
static — runs without creating a Main object
void — main returns nothing
String[] args — command-line arguments

⚠ Common Mistakes

  • Forgetting a semicolon or closing brace — the error often points at the next line
  • Putting import above package — package must be the first statement
  • Writing Main.main logic in a non-static method and calling it from main without an object

✓ Tips & Best Practices

  • Keep main short: parse args, then call well-named methods
  • Mirror packages in folders: com/example/app/Main.java
  • Let your IDE format braces; mixed styles hurt readability

Quick Summary

  • package → import → class — fixed order
  • main — public static void main(String[] args)
  • { } — blocks; ; — ends statements
  • File name = public class name
