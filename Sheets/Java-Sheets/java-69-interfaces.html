Interfaces

interface · implements · abstract methods · default methods · static methods · private methods · constants

Contracts Between Types

An interface declares what a type can do without dictating how. Classes implement interfaces and must provide all abstract methods. A class can implement many interfaces, which is Java's way of combining capabilities. Since Java 8, interfaces can include default and static methods, and since Java 9, private helpers.

Notes

  • Methods are public abstract unless marked otherwise
  • Fields are implicitly public static final
  • A one-method interface is a functional interface (lambda-ready)

Defining & Implementing

public interface Shape {
    double PI_APPROX = 3.14;                     // constant
    double area();                               // abstract
    double perimeter();

    default String describe() {                  // default method
        return "%s with area %.2f".formatted(name(), area());
    }
    private String name() { return getClass().getSimpleName(); }
    static Shape unitSquare() { return new Rect(1, 1); }   // factory
}

public interface Scalable { Shape scale(double f); }

public record Rect(double w, double h) implements Shape, Scalable {
    public double area() { return w * h; }
    public double perimeter() { return 2 * (w + h); }
    public Rect scale(double f) { return new Rect(w * f, h * f); }
}

Shape s = new Rect(2, 3);
s.describe();                 // "Rect with area 6.00"
Shape.unitSquare().area();    // 1.0

Notes

default methods give implementers free behavior
private interface methods share code between defaults
static methods are called on the interface name
One class, two interfaces: Shape, Scalable

⚠ Common Mistakes

  • Using interfaces just to hold constants (the "constant interface" anti-pattern)
  • Forgetting public when implementing — interface methods are public, so narrower access fails
  • Two interfaces with the same default method → you must override and choose

✓ Tips & Best Practices

  • Name interfaces by capability: Readable, Payable
  • Declare variables with interface types
  • Add default methods to evolve an interface without breaking implementers
