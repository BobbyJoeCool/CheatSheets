map & filter

map · filter · flatMap · distinct · limit · skip · mapToInt · takeWhile · mapMulti

Transforming and Selecting

filter(predicate) keeps only elements that pass a test. map(function) transforms each element into a new value, possibly of a different type. flatMap maps each element to a stream and flattens the results into one stream, which is how you handle nested lists. Chaining these builds most real-world pipelines.

Notes

  • filter never changes elements, only drops some
  • map produces exactly one output per input
  • flatMap produces zero or more outputs per input
  • Order of operations affects performance: filter early

Examples

record Emp(String name, String dept, double salary, List<String> skills) { }

List<String> engNames = emps.stream()
    .filter(e -> e.dept().equals("eng"))
    .map(Emp::name)
    .toList();                                     // ["Ada", "Alan"]

double total = emps.stream()
    .mapToDouble(Emp::salary).sum();               // DoubleStream → sum

List<String> allSkills = emps.stream()
    .flatMap(e -> e.skills().stream())             // List<List> → flat
    .distinct()
    .sorted()
    .toList();                                     // [java, sql, …]

Stream.of(1, 2, 3, 10, 4).takeWhile(n -> n < 5).toList();  // [1, 2, 3]
Stream.of(1, 2, 3, 4, 5).skip(1).limit(3).toList();        // [2, 3, 4]
List<List<Integer>> nested = List.of(List.of(1, 2), List.of(3));
nested.stream().flatMap(List::stream).toList();            // [1, 2, 3]

Notes

Emp::name — record accessor as a method reference
mapToDouble switches to a primitive stream for sum
takeWhile stops at the first failure (unlike filter)

⚠ Common Mistakes

  • Using map when the function returns a list, producing Stream<List<T>> — use flatMap
  • Calling filter after expensive map calls that could have been skipped
  • Side effects inside map (like incrementing counters)

✓ Tips & Best Practices

  • Filter before mapping to reduce work
  • Use mapToInt / mapToDouble for numeric aggregates
  • Optional::stream in flatMap drops empty Optionals cleanly

Quick Summary

  • filter — keep matching
  • map — transform 1→1
  • flatMap — 1→many, flattened
  • mapToX — primitive streams
