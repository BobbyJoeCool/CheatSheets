Styling With CSS

JavaFX controls are styled with CSS using JavaFX-specific property names prefixed with -fx-. Add stylesheets to a Scene or Parent, select nodes by style class, id, or type, and react to states with pseudo-classes like :hover and :focused. The default theme is Modena, which you override rather than replace.

Notes

  • Properties use -fx- names: -fx-background-color, not background-color
  • Control type selectors are lowercase-hyphenated: .button, .text-field
  • Inline setStyle overrides stylesheet rules
  • Looked-up colors (variables) like -fx-accent retheme everything

app.css

.root {
    -fx-font-family: "Inter", "Segoe UI", sans-serif;
    -fx-font-size: 13px;
    -fx-accent: #5c6bc0;                 /* looked-up color: theme accent */
    -fx-base: #20232f;                   /* dark base derives other colors */
}
.button {
    -fx-background-color: -fx-accent;
    -fx-text-fill: white;
    -fx-background-radius: 6;
    -fx-padding: 6 14;
}
.button:hover   { -fx-background-color: derive(-fx-accent, 20%); }
.button:pressed { -fx-background-color: derive(-fx-accent, -15%); }
.text-field:focused { -fx-border-color: -fx-accent; }
.error  { -fx-text-fill: #e57373; }
#title  { -fx-font-size: 20px; -fx-font-weight: bold; }

Notes

.root styles the scene's root node
derive(color, %) lightens or darkens
.error is a custom style class
#title targets the node with id title

Applying Styles

scene.getStylesheets().add(getClass()
    .getResource("/app.css").toExternalForm());
errorLabel.getStyleClass().add("error");
titleLabel.setId("title");
saveBtn.setStyle("-fx-font-weight: bold;");
var bad = PseudoClass.getPseudoClass("invalid");
field.pseudoClassStateChanged(bad, true);

⚠ Common Mistakes

  • Using web CSS names without -fx- — they're silently ignored
  • Wrong stylesheet path → no styles and only a console warning
  • Hard-coding colors everywhere instead of overriding -fx-accent / -fx-base

✓ Tips & Best Practices

  • Add stylesheets="@app.css" to FXML roots
  • Use custom pseudo-classes for validation states
  • AtlantaFX offers modern ready-made themes
