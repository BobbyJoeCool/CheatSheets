Bitwise Operators

& · | · ^ · ~ · << · >> · >>> · masks · flags

Working With Bits

Bitwise operators act on the individual bits of integer types (int, long, and smaller types promoted to int). They are used for flags, masks, hashing, low-level protocols, and fast multiplication or division by powers of two. Java integers are two's complement, which matters for ~ and right shifts.

Notes

  • >> keeps the sign bit (arithmetic shift)
  • >>> fills with zeros (logical shift); no <<< exists
  • int shifts use only the low 5 bits of the distance: 1 << 32 == 1
  • ~x equals -x - 1

Flags & Masks

final int READ = 1, WRITE = 2, EXEC = 4;    // 001, 010, 100
int perms = READ | WRITE;                   // 3   (set flags)
boolean canWrite = (perms & WRITE) != 0;    // true (test flag)
perms &= ~WRITE;                            // 1   (clear flag)
perms ^= EXEC;                              // 5   (toggle flag)

int x = 7;
boolean odd = (x & 1) == 1;                 // true
int times8 = x << 3;                        // 56
int half = x >> 1;                          // 3
Integer.toBinaryString(10);                 // "1010"
Integer.bitCount(255);                      // 8
int lowByte = 0xABCD & 0xFF;                // 205 (0xCD)

Patterns

| sets, & ~ clears, ^ toggles, & tests
(x & 1) — fastest odd/even test
& 0xFF — keep the low 8 bits
For readable flags, prefer EnumSet (Sheet 71)

⚠ Common Mistakes

  • if (perms & WRITE) doesn't compile — compare to 0
  • Forgetting parentheses: perms & WRITE != 0 parses as perms & (WRITE != 0)
  • Using >> on negative values when you wanted unsigned results; use >>>

✓ Tips & Best Practices

  • Write masks in hex or binary literals: 0b0100, 0xFF
  • Integer.toBinaryString is your debugging friend
  • EnumSet gives bit-flag speed with readable names

Quick Summary

  • & | ^ ~ — bit logic
  • << — × 2ⁿ
  • >> — ÷ 2ⁿ, keeps sign
  • >>> — shift in zeros
