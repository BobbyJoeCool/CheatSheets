Classes Inside Classes

Java lets you declare classes inside other classes. A static nested class is an ordinary class scoped to its outer class. An inner (non-static) class is tied to an instance of the outer class and can read its fields. Local classes live inside a method, and anonymous classes are declared and instantiated in a single expression.

Notes

  • Inner classes hold a hidden reference to the outer object
  • Prefer static nested unless you need the outer instance
  • Lambdas replace anonymous classes for functional interfaces

The Four Kinds

public class Outer {
    private int count = 5;
    static class Builder { }                    // 1. static nested

    class Counter {                             // 2. inner
        int doubled() { return count * 2; }     //    reads outer field
    }

    void demo() {
        class Local { }                         // 3. local
        Comparator<String> byLen = new Comparator<>() {   // 4. anonymous
            public int compare(String a, String b) {
                return a.length() - b.length(); }
        };
        Comparator<String> lam = (a, b) -> a.length() - b.length();
    }
}

Outer.Builder b = new Outer.Builder();      // no Outer needed
Outer o = new Outer();
Outer.Counter c = o.new Counter();          // needs an Outer
c.doubled();                                // 10

Notes

o.new Counter() — inner instances need an outer object
The lambda equals the anonymous class in one line

⚠ Common Mistakes

  • Inner classes that keep large outer objects alive (memory leaks)
  • new Counter() from a static method — needs outerObj.new Counter()
  • Using an anonymous class where a lambda would do

✓ Tips & Best Practices

  • Default to static nested classes
  • Use anonymous classes only when you need state or several methods

Quick Summary

  • static class — independent
  • Inner — bound to outer object
  • Local — inside a method
  • Anonymous — one-shot implementation
