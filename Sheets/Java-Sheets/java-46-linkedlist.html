LinkedList · addFirst · addLast · removeFirst · getFirst · poll · peek · doubly linked

Doubly Linked List

LinkedList<E> stores elements in nodes linked forward and backward. Adding or removing at either end is O(1), but reaching index i means walking node by node, so get(i) is O(n). It implements both List and Deque, so it can act as a list, queue, or stack.

Notes

  • Each element carries two extra references: more memory than ArrayList
  • In practice ArrayList and ArrayDeque are faster for most work
  • Allows null elements (unlike ArrayDeque)
  • Iterator removal is O(1) per element

Usage

LinkedList<String> ll = new LinkedList<>();
ll.add("B");                  // [B]
ll.addFirst("A");             // [A, B]
ll.addLast("C");              // [A, B, C]
ll.getFirst();                // "A"
ll.getLast();                 // "C"
ll.removeFirst();             // "A"  → [B, C]
ll.removeLast();              // "C"  → [B]

ll.offer("X");                // queue: add to tail
ll.peek();                    // "B"  (head, no remove)
ll.poll();                    // "B"  (head, removes)
ll.poll();                    // "X"
ll.poll();                    // null (empty, no exception)
// ll.removeFirst();          // ✖ NoSuchElementException when empty

ListIterator<String> it = names.listIterator();
while (it.hasNext()) {
    if (it.next().startsWith("x")) it.remove();   // O(1) unlink
}

Notes

poll/peek return null when empty
remove/get… methods throw when empty
ListIterator can also add and set mid-walk

⚠ Common Mistakes

  • Looping for (i…) ll.get(i) — O(n²) overall
  • Choosing LinkedList "for fast inserts" without measuring; ArrayList usually wins
  • Calling removeFirst() on an empty list instead of pollFirst()

✓ Tips & Best Practices

  • Need a queue or stack? Prefer ArrayDeque (Sheet 51)
  • Use LinkedList when you need null elements in a queue
  • Always iterate with for-each or an iterator, never by index

Quick Summary

  • Doubly linked nodes
  • O(1) at ends, O(n) by index
  • List + Deque
  • poll/peek → null if empty
