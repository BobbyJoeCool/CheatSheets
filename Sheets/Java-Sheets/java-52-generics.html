Sheet 52

Generics

<T> · type parameter · generic class · generic method · bounded type · ? extends · ? super · type erasure

Type-Safe Reusable Code

Generics let classes and methods work with any type while keeping compile-time type checking. List<String> only accepts strings, so no casts are needed when reading. You declare type parameters like <T>, can bound them (<T extends Number>), and can use wildcards (?) in parameters for flexible APIs.

Notes

  • Generics work with reference types only: Box<Integer>, not Box<int>
  • Types are erased at runtime: List<String> and List<Integer> share one class
  • You can't new T() or create new T[n]
  • PECS: Producer extends, Consumer super

Classes, Methods, Bounds

class Box<T> {                                   // generic class
    private T value;
    Box(T value) { this.value = value; }
    T get() { return value; }
}
Box<String> b = new Box<>("hi");
String s = b.get();                              // no cast

record Pair<K, V>(K key, V value) { }            // two params
var p = new Pair<>("age", 36);

static <T> T first(List<T> list) { return list.get(0); }   // generic method
static <T extends Comparable<T>> T max(T a, T b) {         // bounded
    return a.compareTo(b) >= 0 ? a : b;
}
max(3, 7);                                       // 7
max("fig", "kiwi");                              // "kiwi"

static double sum(List<? extends Number> nums) { // reads Numbers
    double t = 0;
    for (Number n : nums) t += n.doubleValue();
    return t;
}
static void fill(List<? super Integer> out) { out.add(42); }  // writes Integers

Notes

<T> before the return type declares a generic method
T extends Comparable<T> guarantees compareTo exists
? extends Number accepts List<Integer>, List<Double>
? super Integer accepts List<Number>, List<Object>

⚠ Common Mistakes

  • Assuming List<Integer> is a List<Number> — it isn't; use List<? extends Number>
  • Using raw types (List list) which disable type checking
  • if (obj instanceof List<String>) — not allowed due to erasure

✓ Tips & Best Practices

  • Follow PECS when designing method parameters
  • Let the diamond <> and var infer types
  • Add bounds when you need methods of the bound type

Quick Summary

  • <T> — type parameter
  • <T extends X> — bounded
  • ? extends read, ? super write
  • Erased at runtime
