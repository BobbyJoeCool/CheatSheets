Sheet 48

HashSet

HashSet · add · contains · remove · uniqueness · retainAll · removeAll · Set.of · LinkedHashSet

Unique Elements

A Set holds no duplicates. HashSet<E> is backed by a HashMap, so add, remove, and contains are about O(1). add returns false if the element was already present. Sets are ideal for membership tests, removing duplicates, and math-style unions and intersections.

Notes

  • No index: there is no get(i)
  • Iteration order is unpredictable
  • Elements need correct equals and hashCode
  • Set.of(...) is immutable and throws on duplicate arguments

Set Operations

Set<String> tags = new HashSet<>();
tags.add("java");                     // true
tags.add("java");                     // false (duplicate)
tags.add("sql");
tags.contains("sql");                 // true
tags.remove("sql");                   // true
tags.size();                          // 1

List<Integer> dupes = List.of(3, 1, 3, 2, 1);
Set<Integer> unique = new HashSet<>(dupes);           // [1, 2, 3]
var ordered = new ArrayList<>(new LinkedHashSet<>(dupes));   // [3, 1, 2]

Set<Integer> a = new HashSet<>(Set.of(1, 2, 3, 4));
Set<Integer> b = Set.of(3, 4, 5);
Set<Integer> union = new HashSet<>(a);  union.addAll(b);     // [1,2,3,4,5]
Set<Integer> inter = new HashSet<>(a);  inter.retainAll(b);  // [3, 4]
Set<Integer> diff  = new HashSet<>(a);  diff.removeAll(b);   // [1, 2]
a.containsAll(Set.of(1, 2));                                  // true (subset)

Notes

LinkedHashSet removes duplicates but keeps first-seen order
Set algebra methods modify the receiver; copy first
containsAll checks for a subset

⚠ Common Mistakes

  • Expecting sorted or insertion order from HashSet
  • Storing mutable objects and changing them after insertion
  • Using list.contains in a loop over large data — convert to a Set first

✓ Tips & Best Practices

  • Convert lists to sets for O(1) membership checks
  • Use LinkedHashSet to dedupe while keeping order
  • Use Set.copyOf(collection) for an immutable snapshot

Quick Summary

  • No duplicates
  • add returns false if present
  • O(1) contains
