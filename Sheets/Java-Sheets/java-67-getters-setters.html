Getters & Setters

Controlled Access to Fields

Getters (accessors) return a field's value, and setters (mutators) change it. Routing access through methods lets you validate input, compute values, and change the internal representation later without breaking callers. JavaBeans conventions use getX(), isX() for booleans, and setX(value).

Notes

  • Frameworks (Jackson, JPA, JavaFX) rely on these naming conventions
  • Omit setters to make a field read-only
  • Records generate accessors named x(), not getX()
  • Lombok can generate them (Sheet 110)

Conventions & Validation

public class Person {
    private String name;
    private int age;
    private boolean active;

    public String getName() { return name; }
    public void setName(String name) {
        if (name == null || name.isBlank())
            throw new IllegalArgumentException("name required");
        this.name = name.strip();
    }

    public int getAge() { return age; }
    public void setAge(int age) {
        if (age < 0 || age > 150) throw new IllegalArgumentException("age");
        this.age = age;
    }

    public boolean isActive() { return active; }    // boolean → is
    public void setActive(boolean active) { this.active = active; }

    public boolean isAdult() { return age >= 18; }  // computed, no field
}

record Point(int x, int y) { }      // immutable alternative
new Point(1, 2).x();                // 1

Notes

Setters normalize input (strip()) as well as validate
Computed getters need no backing field
Records give read-only accessors for free

⚠ Common Mistakes

  • Setters that don't validate, making encapsulation pointless
  • Getter returning a mutable List or Date that callers can change
  • getIsActive() naming, which breaks JavaBeans tools — use isActive()

✓ Tips & Best Practices

  • Prefer immutable objects; add setters only when state must change
  • Return defensive copies of mutable fields
  • Use with-style methods (withAge(31)) that return new objects

Quick Summary

  • getX() / isX() — read
  • setX(v) — validated write
  • Omit setters → read-only
  • Records: x() accessors
