Do-While Loop

do · while · post-test loop · menu loop · input validation · retry

Run First, Check After

A do-while loop runs its body once before checking the condition, then repeats while the condition is true. That guarantee makes it the natural fit for menus, "play again?" prompts, and input validation, where you must ask at least once before you can test the answer.

Notes

  • Note the semicolon after while (cond);
  • Variables declared inside the body aren't visible in the condition
  • Body always executes at least once
  • break and continue work as in other loops

Menus & Validation

Scanner in = new Scanner(System.in);
int choice;
do {
    System.out.println("1) New  2) Open  3) Quit");
    choice = in.nextInt();
    switch (choice) {
        case 1 -> newFile();
        case 2 -> openFile();
        case 3 -> System.out.println("Bye");
        default -> System.out.println("Invalid");
    }
} while (choice != 3);

int age;
do {
    System.out.print("Age (1-120): ");
    age = in.nextInt();
} while (age < 1 || age > 120);       // re-ask until valid

int tries = 0;
boolean ok;
do {
    ok = tryConnect();
    tries++;
} while (!ok && tries < 3);           // retry with a limit

Notes

choice is declared outside the loop so the condition can see it
The validation loop reads first, then decides
Combine success flags and counters for retries

⚠ Common Mistakes

  • Forgetting the semicolon after while (cond) — compile error
  • Declaring the tested variable inside do { } — it's out of scope in while (...)
  • Using do-while where the body must not run on empty input

✓ Tips & Best Practices

  • Use it for menus and validation; otherwise while is usually clearer
  • Print why input was rejected so the user isn't stuck guessing
  • Cap retries with a counter to avoid infinite loops

Quick Summary

  • do { } while (cond);
  • Body runs at least once
  • Condition checked after each pass
  • Ideal for menus and prompts
