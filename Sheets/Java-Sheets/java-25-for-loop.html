For Loop

for · init · condition · update · nested loops · counting down · step · multiple variables

Counting Loops

The classic for loop packs three parts into its header: an initializer that runs once, a condition checked before each pass, and an update run after each pass. It's the natural choice when you know how many times to loop or need the index. Any of the three parts can be empty.

Notes

  • The loop variable is scoped to the loop
  • for (;;) is an infinite loop
  • The condition is checked before each iteration
  • Modifying a list while indexing it shifts positions

For Loop Variants

for (int i = 0; i < 5; i++) {          // 0 1 2 3 4
    System.out.print(i + " ");
}
for (int i = 10; i > 0; i -= 2) { }    // 10 8 6 4 2
for (int i = 1; i <= 100; i *= 10) { } // 1 10 100

int[] a = {4, 8, 15};
for (int i = 0; i < a.length; i++) {
    System.out.println(i + ": " + a[i]);   // 0: 4 …
}
for (int i = a.length - 1; i >= 0; i--) { }   // reverse

for (int i = 0, j = 9; i < j; i++, j--) { }   // two pointers

for (int r = 1; r <= 3; r++) {          // nested: times table
    for (int c = 1; c <= 3; c++) {
        System.out.print(r * c + "\t");
    }
    System.out.println();
}

Notes

i < a.length — correct upper bound
Reverse loops start at length - 1
Comma operator allowed only in init and update
Nested loops multiply: 3 × 3 = 9 iterations

⚠ Common Mistakes

  • i <= a.length — off-by-one, throws ArrayIndexOutOfBoundsException
  • A semicolon after the header for (...); makes an empty loop
  • Removing items from a List in an index loop skips elements; loop backwards or use removeIf

✓ Tips & Best Practices

  • Use the enhanced for (Sheet 28) when you don't need i
  • Use IntStream.range(0, n) for stream-style counting
  • Cache expensive bounds: for (int i = 0, n = list.size(); i < n; i++)

Quick Summary

  • for (init; cond; update)
  • Best when count or index matters
  • Bounds: 0 to < length
  • Nested loops multiply work
