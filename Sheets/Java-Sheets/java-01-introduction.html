What Is Java

Java is a statically typed, class-based, object-oriented language created by James Gosling at Sun Microsystems and released in 1995. Source code compiles to bytecode (.class files) that runs on the Java Virtual Machine, so the same compiled program runs on Windows, macOS, and Linux. Oracle has owned Java since 2010 and ships a new version every six months, with a Long-Term Support release every two years.

Key Facts

  • Motto: "Write once, run anywhere" (WORA)
  • Current LTS releases: Java 17, 21, and 25
  • Primary uses: backend services, Android, enterprise apps, big data (Kafka, Spark), desktop tools
  • Memory is managed by a garbage collector; no manual free

Hello, World

// File name must match the public class: Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

// Terminal
// javac Hello.java      → creates Hello.class (bytecode)
// java Hello            → Hello, World!
// java Hello.java       → compile + run in one step (Java 11+)

How It Runs

javac — compiler; turns .java source into .class bytecode
java — launcher; starts the JVM and runs main
Bytecode — platform-neutral instructions the JVM executes
JIT — the JVM compiles hot bytecode to native machine code at runtime
java File.java — single-file source launch, no separate compile

JDK vs JRE vs JVM

JDKJRE + javac, jar, jshell, javadocWrite and compile Java

⚠ Common Mistakes

  • Naming the file differently from its public class — javac refuses to compile it
  • Running java Hello.class — the launcher wants the class name, not the file name
  • Installing only a JRE build and then wondering why javac is missing

✓ Tips & Best Practices

  • Stick to an LTS release (17, 21, 25) for real projects
  • Use jshell to try one-liners without writing a class
  • Run java -version and javac -version to confirm both match

Quick Summary

  • javac — compile source to bytecode
  • java — run bytecode on the JVM
  • JDK — everything a developer needs
  • LTS — the versions to target in production
