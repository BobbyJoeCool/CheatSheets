String Formatting

String.format · formatted() · %s · %d · %f · %n · width · flags · padding

Formatting Text

String.format builds a string from a format string containing % specifiers, and "...".formatted(args) (Java 15+) does the same as an instance method. Specifiers follow the pattern %[index$][flags][width][.precision]conversion. printf uses the identical syntax but prints directly.

Notes

  • Specifiers are matched to arguments left to right
  • %n is the platform line separator
  • %% prints a literal percent sign
  • Pass a Locale for grouping and decimal symbols

Formatting Examples

String.format("%s has %d items", "Cart", 3);   // "Cart has 3 items"
"%s scored %.1f%%".formatted("Ada", 92.456);    // "Ada scored 92.5%"

String.format("[%8s]", "right");     // "[   right]"
String.format("[%-8s]", "left");     // "[left    ]"
String.format("[%05d]", 42);         // "[00042]"
String.format("%,d", 1234567);       // "1,234,567"
String.format("%+d", 5);             // "+5"
String.format("%.3f", 2.0);          // "2.000"
String.format("%10.2f|", 3.14159);   // "      3.14|"
String.format("%x / %X", 255, 255);  // "ff / FF"
String.format("%e", 12345.678);      // "1.234568e+04"
String.format("%2$s %1$s", "a", "b"); // "b a"
String.format(Locale.GERMANY, "%,.2f", 1234.5); // "1.234,50"

Anatomy

%-8s — flag - (left), width 8, string
%05d — flag 0 (zero pad), width 5
%.1f — precision 1
%2$s — argument index 2

⚠ Common Mistakes

  • Mismatched types: %d with a double throws IllegalFormatConversionException
  • Forgetting %% and getting UnknownFormatConversionException
  • Using String.format in tight loops for simple concatenation; it's slower

✓ Tips & Best Practices

  • Use .formatted() for readability: "Hi %s".formatted(name)
  • Build aligned text tables with fixed widths like %-12s%8.2f
  • For currency, use NumberFormat.getCurrencyInstance(locale)
