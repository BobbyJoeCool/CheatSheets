Packages on Disk and Java Modules

Package names map directly to folders: com.acme.app lives in com/acme/app/. Name packages with a reversed domain to keep them globally unique. Java 9 added the module system (JPMS): a module-info.java file declares which packages a module exports and which modules it requires, giving strong encapsulation between JARs.

Notes

  • Package names are all lowercase
  • src/main/java is the Maven/Gradle source root
  • Unexported packages are invisible to other modules
  • opens allows reflection (needed by Jackson, JavaFX FXML)

module-info.java

module com.acme.app {
    requires java.net.http;                 // JDK module
    requires transitive com.acme.core;      // consumers get it too
    requires static lombok;                 // compile-time only

    exports com.acme.app.api;               // public API
    exports com.acme.app.spi to com.acme.plugins;   // qualified export

    opens com.acme.app.model to com.fasterxml.jackson.databind;
    opens com.acme.app.ui to javafx.fxml;   // reflection for FXML

    uses com.acme.app.spi.Exporter;         // service loader
}

// Compile & run with modules
// javac -d out --module-path libs $(find src -name "*.java")
// java --module-path out:libs -m com.acme.app/com.acme.app.Main

Notes

requires — dependency on another module
exports — packages others may compile against
opens — packages others may reflect into
No module-info.java → your code runs on the classpath (unnamed module)

⚠ Common Mistakes

  • Folder path not matching the package line — compile error or class not found
  • Forgetting opens for FXML controllers or Jackson DTOs → InaccessibleObjectException
  • Splitting one package across two modules — not allowed

✓ Tips & Best Practices

  • Start with the classpath; add module-info.java when you need it (JavaFX apps usually do)
  • Group by feature (orders, users) rather than by layer
  • Keep exports minimal

Quick Summary

  • Package = folder path
  • Reverse-domain names
  • module-info.java — JPMS
  • requires exports opens
