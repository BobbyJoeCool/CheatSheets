Swing Layout Managers

FlowLayout · BorderLayout · GridLayout · BoxLayout · GridBagLayout · nested panels · setLayout

Arranging Components

Swing positions components with layout managers rather than fixed coordinates, so windows resize sensibly. Each container has one layout manager, set with setLayout. Complex screens are built by nesting panels, each with the layout that suits its part of the window.

Notes

  • JPanel defaults to FlowLayout
  • JFrame's content pane defaults to BorderLayout
  • GridBagLayout is powerful but verbose; MigLayout is a popular alternative
  • Avoid setLayout(null) with absolute positions

Nesting Layouts

JFrame f = new JFrame("Layouts");
f.setLayout(new BorderLayout(8, 8));                 // hgap, vgap

JPanel toolbar = new JPanel(new FlowLayout(FlowLayout.LEFT));
toolbar.add(new JButton("New"));
toolbar.add(new JButton("Open"));
f.add(toolbar, BorderLayout.NORTH);

JPanel form = new JPanel(new GridLayout(2, 2, 6, 6));   // rows, cols, gaps
form.add(new JLabel("Name"));  form.add(new JTextField());
form.add(new JLabel("Email")); form.add(new JTextField());
f.add(form, BorderLayout.CENTER);

JPanel side = new JPanel();
side.setLayout(new BoxLayout(side, BoxLayout.Y_AXIS));  // vertical stack
side.add(new JCheckBox("Subscribe"));
side.add(new JCheckBox("Remember me"));
f.add(side, BorderLayout.EAST);

f.pack();
f.setVisible(true);

Notes

BorderLayout regions: NORTH, SOUTH, EAST, WEST, CENTER
CENTER takes all leftover space
GridLayout cells are equal size

⚠ Common Mistakes

  • Adding two components to the same BorderLayout region — only the last one shows
  • Using setSize on components inside layouts; set preferred sizes or let layouts decide
  • Absolute positioning that breaks on different fonts and screen scaling

✓ Tips & Best Practices

  • Sketch the window as nested rectangles first
  • Add BorderFactory.createEmptyBorder(8, 8, 8, 8) for padding
  • Use CardLayout to switch between screens

Quick Summary

  • One layout manager per container
  • Nest panels for complex UIs
  • BorderLayout — frame skeleton
  • GridLayout / BoxLayout / FlowLayout
