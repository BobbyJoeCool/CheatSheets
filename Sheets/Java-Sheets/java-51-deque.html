Double-Ended Queue

A Deque ("deck") supports adding and removing at both ends in O(1). ArrayDeque is a resizable circular array and is the best general-purpose stack *and* queue in Java. Methods come in pairs for the first and last positions, each with a throwing and a non-throwing version.

Notes

  • ArrayDeque rejects null elements
  • Faster than Stack and usually faster than LinkedList
  • Not thread-safe; use LinkedBlockingDeque for concurrency
  • descendingIterator() walks tail → head

Deque Operations

Deque<Integer> d = new ArrayDeque<>();
d.addFirst(2);              // [2]
d.addFirst(1);              // [1, 2]
d.addLast(3);               // [1, 2, 3]
d.offerLast(4);             // [1, 2, 3, 4]
d.peekFirst();              // 1
d.peekLast();               // 4
d.pollFirst();              // 1 → [2, 3, 4]
d.pollLast();               // 4 → [2, 3]

// Palindrome check
Deque<Character> chars = new ArrayDeque<>();
for (char c : "racecar".toCharArray()) chars.addLast(c);
boolean pal = true;
while (chars.size() > 1)
    if (!chars.pollFirst().equals(chars.pollLast())) pal = false;

// Sliding-window maximum (indices kept in decreasing value order)
Deque<Integer> win = new ArrayDeque<>();
for (int i = 0; i < a.length; i++) {
    while (!win.isEmpty() && a[win.peekLast()] <= a[i]) win.pollLast();

Notes

⚠ Common Mistakes

  • Adding null to an ArrayDeque → NullPointerException
  • Mixing push and offer on the same deque and confusing which end is which
  • Comparing boxed Character/Integer values with ==

✓ Tips & Best Practices

  • Use ArrayDeque as your default stack and queue
  • Stick to one naming style: either stack methods or queue methods
  • Monotonic deques solve many "window" problems in O(n)

Quick Summary

  • O(1) at both ends
  • …First / …Last method pairs
  • poll/peek → null when empty
  • Best stack + queue: ArrayDeque
