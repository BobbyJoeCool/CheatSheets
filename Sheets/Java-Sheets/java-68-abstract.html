Abstract Classes

abstract class · abstract method · partial implementation · template method · constructor · cannot instantiate

Partially Implemented Base Classes

An abstract class can't be instantiated; it exists to be extended. It may contain abstract methods (declared without a body) that every concrete subclass must implement, alongside normal fields, constructors, and implemented methods. Use one when related classes share state and some behavior but differ in specific steps.

Notes

  • Any class with an abstract method must be declared abstract
  • Abstract classes can have constructors (called via super)
  • A subclass that doesn't implement all abstract methods must also be abstract
  • abstract and final can't be combined

Template Method Pattern

public abstract class Report {
    private final String title;                  // shared state
    protected Report(String title) { this.title = title; }

    public final String render() {               // fixed algorithm
        return header() + "\n" + body() + "\n" + footer();
    }
    private String header() { return "== " + title + " =="; }
    protected String footer() { return "-- end --"; }    // optional hook
    protected abstract String body();             // required step
}

public class SalesReport extends Report {
    private final double total;
    public SalesReport(double total) { super("Sales"); this.total = total; }
    @Override
    protected String body() { return "Total: $" + total; }
}

Report r = new SalesReport(1200);
System.out.println(r.render());
// == Sales ==
// Total: $1200.0
// -- end --

Notes

render() is final, so the overall order is locked
body() must be supplied; footer() may be overridden
Variables can still have the abstract type: Report r

⚠ Common Mistakes

  • Making a class abstract when an interface would do — it uses up the single inheritance slot
  • Forgetting to implement an abstract method — the compiler forces the subclass to be abstract
  • Calling abstract methods from the constructor before subclass fields are set

✓ Tips & Best Practices

  • Pair an interface with an abstract "skeleton" class (like AbstractList)
  • Mark the template method final
  • Use protected for hooks meant only for subclasses

Quick Summary

  • abstract class — no new
  • abstract methods — no body
  • Mix state + implemented methods
  • Template method pattern
