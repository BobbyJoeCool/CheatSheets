Variable Scope

local · block · parameter · instance field · static field · shadowing · effectively final · lifetime

Where Variables Live

Scope is the region of code where a name can be used. Local variables exist from their declaration to the end of the enclosing block { }. Fields belong to an object (instance) or the class (static) and are visible throughout the class. An inner name with the same identifier shadows the outer one.

Notes

  • Java forbids redeclaring a local in a nested block
  • A local can shadow a field; use this.name to reach the field
  • Lambdas and inner classes can only capture effectively final locals
  • Loop variables die when the loop ends

Scope Levels

public class Counter {
    static int created = 0;       // class scope: shared
    private int count = 0;        // instance scope: per object

    void add(int count) {         // parameter shadows field
        this.count += count;      // field via this
        created++;
    }

    void demo() {
        int total = 0;            // method scope
        for (int i = 0; i < 3; i++) {   // i: loop scope
            int sq = i * i;       // block scope
            total += sq;
        }
        // System.out.println(i);   ✖ i out of scope
        int base = 10;            // effectively final
        Runnable r = () -> System.out.println(base);   // ✔ captured
        // base = 11;             ✖ would break capture
    }
}

Notes

created is shared by all Counter objects
this.count vs count resolves the shadowing
Effectively final = never reassigned after initialization

⚠ Common Mistakes

  • Forgetting this. in a setter: name = name; assigns the parameter to itself
  • Declaring a variable inside a loop when you need it after the loop
  • Trying to modify a captured local inside a lambda

✓ Tips & Best Practices

  • Declare variables in the smallest scope that works
  • Use different parameter names or this. consistently
  • Avoid mutable static fields; they act like global state

Quick Summary

  • Locals end at their }
  • Fields span the class
  • this.x — field when shadowed
  • Lambdas capture effectively final locals
