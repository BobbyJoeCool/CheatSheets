Break & Continue

break · continue · labeled break · labeled continue · return · early exit

Controlling Loop Flow

break exits the innermost loop (or switch) immediately. continue skips the rest of the current iteration and moves to the next one. Both act on the innermost loop unless you use a label to target an outer loop. return exits the whole method, ending every loop at once.

Notes

  • Labels are identifiers followed by a colon: outer:
  • In a for loop, continue still runs the update step
  • In a while loop, continue jumps straight to the condition
  • Overusing labels usually means the method should be split

Examples

for (int i = 0; i < 10; i++) {
    if (i == 5) break;          // stop entirely
    System.out.print(i);         // 01234
}

for (int i = 0; i < 6; i++) {
    if (i % 2 == 0) continue;   // skip evens
    System.out.print(i);         // 135
}

outer:
for (int r = 0; r < grid.length; r++) {
    for (int c = 0; c < grid[r].length; c++) {
        if (grid[r][c] == target) {
            found = true;
            break outer;          // leaves BOTH loops
        }
    }
}

Notes

break outer jumps past the labeled loop
continue outer would start the next outer iteration instead
Searching? return from a helper method is often cleaner

⚠ Common Mistakes

  • Expecting break inside a switch in a loop to exit the loop — it only exits the switch
  • continue in a while loop placed before the counter update causes an infinite loop
  • Using flag variables and nested ifs where a labeled break or return is clearer

✓ Tips & Best Practices

  • Extract nested searches into methods and return the result
  • Keep continue at the top of the loop as a filter
  • Name labels by meaning: rows:, search:

Quick Summary

  • break — leave loop
  • continue — skip to next pass
  • break label — leave outer loop
  • return — leave method
