Robust CSV Reading and Writing

OpenCSV correctly handles the parts of CSV that split gets wrong: quoted fields, embedded commas and quotes, and multi-line values. Read rows as String[] with CSVReader, write with CSVWriter, or map rows directly to annotated Java beans with CsvToBean and StatefulBeanToCsv.

Notes

  • Artifact: com.opencsv:opencsv
  • Read methods throw CsvValidationException and IOException
  • Bean binding requires a no-arg constructor (records aren't supported)
  • Separators other than , are set with a CSVParserBuilder

Read, Write, Bind

try (CSVReader r = new CSVReaderBuilder(new FileReader("people.csv"))
        .withSkipLines(1).build()) {                    // skip header
    String[] row;
    while ((row = r.readNext()) != null) {
        System.out.println(row[0] + " is " + row[1]);  // quotes handled
    }
}

try (CSVWriter w = new CSVWriter(new FileWriter("out.csv"))) {
    w.writeNext(new String[]{"name", "note"});
    w.writeNext(new String[]{"Ada", "Said \"hi\", left"});   // auto-escaped
}

public class Person {                                   // bean mapping
    @CsvBindByName(column = "name") private String name;
    @CsvBindByName(column = "age")  private int age;
    // no-arg constructor, getters/setters
}
List<Person> people = new CsvToBeanBuilder<Person>(new FileReader("people.csv"))
    .withType(Person.class).build().parse();

try (Writer out = new FileWriter("people-out.csv")) {
    new StatefulBeanToCsvBuilder<Person>(out).build().write(people);
}

Notes

withSkipLines(1) drops the header for array-based reading
CSVWriter quotes every field by default
Bean binding matches header names to annotated fields

⚠ Common Mistakes

  • Using records or classes without no-arg constructors for bean binding
  • Reading Excel files saved with ; separators using the default parser
  • Forgetting to skip the header when reading String[] rows

✓ Tips & Best Practices

  • Use readAll() only for small files; stream with readNext() otherwise
  • Specify UTF-8 explicitly with Files.newBufferedReader(path)
  • Basic CSV concepts are on Sheet 81
