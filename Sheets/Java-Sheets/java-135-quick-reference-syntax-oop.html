⚠ Common Mistakes

  • == on strings or boxed numbers — use equals
  • Integer division 5 / 2 == 2; cast first for decimals
  • Swallowing exceptions with an empty catch

✓ Tips & Best Practices

  • Use records for data carriers and var for obvious local types
  • Prefer arrow switch expressions — no fall-through
  • Close resources with try-with-resources

Quick Summary

  • Static types, classes everywhere, main starts the program
  • equals for value equality
  • switch + patterns + records + sealed = modern data modelling
  • Lambdas and method refs for functional code
