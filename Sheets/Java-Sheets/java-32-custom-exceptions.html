Defining Your Own Exceptions

Create a custom exception by extending Exception (checked) or RuntimeException (unchecked). Custom types let callers catch a specific domain failure, like InsufficientFundsException, and can carry extra fields that describe what went wrong. Provide constructors that accept a message and a cause.

Notes

  • Name ends with Exception by convention
  • Exceptions are Serializable; add serialVersionUID to silence warnings
  • Make extra fields final and expose getters
  • Group related exceptions under one base class

Defining & Using

public class InsufficientFundsException extends Exception {
    private static final long serialVersionUID = 1L;
    private final double shortfall;

    public InsufficientFundsException(String msg, double shortfall) {
        super(msg);
        this.shortfall = shortfall;
    }
    public InsufficientFundsException(String msg, Throwable cause) {
        super(msg, cause);
        this.shortfall = 0;
    }
    public double getShortfall() { return shortfall; }
}

public void withdraw(double amt) throws InsufficientFundsException {
    if (amt > balance)
        throw new InsufficientFundsException("Balance too low", amt - balance);
    balance -= amt;
}

try { acct.withdraw(500); }
catch (InsufficientFundsException e) {
    System.out.printf("Short by $%.2f%n", e.getShortfall());
}

Notes

super(msg) stores the message for getMessage()
super(msg, cause) chains the original exception
The extra field gives callers data, not just text

ConstructorPurpose

⚠ Common Mistakes

  • Extending Throwable or Error directly — extend Exception or RuntimeException
  • Omitting the cause constructor, so wrapped errors lose their stack trace
  • Creating a new exception class for every method when one domain type would do

✓ Tips & Best Practices

  • Only create custom types when callers need to catch them specifically
  • Keep messages human-readable and include key values
  • Make it a record-like immutable object: final fields, no setters

Quick Summary

  • extends Exception — checked
  • extends RuntimeException — unchecked
  • Constructors: message + cause
  • Add fields for context
