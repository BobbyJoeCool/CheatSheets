Jackson

ObjectMapper · readValue · writeValueAsString · TypeReference · @JsonProperty · @JsonIgnore · JsonNode · JavaTimeModule

High-Performance JSON

Jackson is the most widely used Java JSON library and the default in Spring Boot. Its ObjectMapper converts between JSON and Java objects (data binding), exposes a tree model (JsonNode), and offers streaming APIs. Annotations control naming, inclusion, and formats. Jackson 3 (2025) moved to tools.jackson.* packages; the API below is Jackson 2.

Notes

  • Artifact: com.fasterxml.jackson.core:jackson-databind
  • ObjectMapper is thread-safe after configuration
  • Unknown JSON properties fail by default
  • Add jackson-datatype-jsr310 for java.time types

Data Binding & Tree Model

ObjectMapper mapper = new ObjectMapper()
    .registerModule(new JavaTimeModule())
    .configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);

record User(String name, int age, LocalDate joined) { }

String json = mapper.writeValueAsString(new User("Ada", 36, today));
User u = mapper.readValue(json, User.class);
var list = mapper.readValue(arrayJson, new TypeReference<List<User>>() {});

class Product {
    @JsonProperty("product_id") private String id;
    @JsonIgnore private String internalNote;
    @JsonInclude(JsonInclude.Include.NON_NULL) private String color;
}

JsonNode root = mapper.readTree(json);
root.get("name").asText();                  // "Ada"
root.path("missing").asInt(0);              // 0 (path() never null)

Notes

TypeReference captures generic types
Records work out of the box (2.12+)
get() returns null for missing fields; path() returns a missing node

⚠ Common Mistakes

  • Creating a new ObjectMapper per call — it's expensive to build
  • Forgetting JavaTimeModule → errors on LocalDate fields
  • Private fields with no getters or @JsonProperty, which Jackson can't see

✓ Tips & Best Practices

  • Configure one shared mapper (Spring Boot does this for you)
  • Ignore unknown properties when consuming external APIs
  • Use JsonNode for exploratory or partial parsing
