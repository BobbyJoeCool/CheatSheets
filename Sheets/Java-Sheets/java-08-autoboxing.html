Autoboxing & Wrapper Types

Integer · Double · Boolean · Character · valueOf · unboxing · Integer cache · null

Wrapper Classes

Each primitive has a wrapper class (int → Integer, double → Double) that holds the value as an object. Collections and generics only accept objects, so Java converts automatically: autoboxing wraps a primitive, unboxing unwraps it. The convenience hides costs and two traps: null unboxing and == on wrappers.

Notes

  • List<int> is illegal; use List<Integer>
  • Unboxing null throws NullPointerException
  • Integer.valueOf caches values from −128 to 127
  • Wrapper objects are immutable

Boxing in Action

Integer boxed = 42;              // autobox: Integer.valueOf(42)
int plain = boxed;               // unbox:   boxed.intValue()

List<Integer> nums = new ArrayList<>();
nums.add(5);                     // autoboxed
int first = nums.get(0);         // unboxed

Integer a = 127, b = 127;
a == b;                          // true  (cached)
Integer c = 128, d = 128;
c == d;                          // false (different objects!)
c.equals(d);                     // true  ✔

Integer missing = null;
int boom = missing;              // NullPointerException

Integer.MAX_VALUE;               // 2147483647
Integer.compare(3, 7);           // -1
Character.isDigit('7');          // true

Notes on the Example

== compares references for wrappers
The cache makes small-number bugs invisible in testing
map.get(key) returns null when absent → NPE if unboxed
Static helpers live on the wrapper classes

⚠ Common Mistakes

  • Comparing Integer objects with == — use .equals() or unbox first
  • int count = map.get("x"); when the key is missing throws NPE; use getOrDefault
  • Summing boxed values in a hot loop creates millions of objects; use int

✓ Tips & Best Practices

  • Use primitives for local math, wrappers only where objects are required
  • Prefer Integer.valueOf over new Integer(...) (constructor is deprecated)
  • Use IntStream / mapToInt to avoid boxing in streams

Quick Summary

  • Autoboxing — primitive → wrapper
  • Unboxing — wrapper → primitive (NPE on null)
  • .equals() — compare wrapper values
  • Cache: −128 … 127
