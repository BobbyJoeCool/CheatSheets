Combining Inheritance and Interfaces

extends creates a subclass of one class, inheriting its state and behavior. implements promises to fulfill one or more interface contracts. A class can do both: class A extends B implements C, D. Interfaces themselves use extends, and can extend several interfaces at once.

Notes

  • Interfaces extend interfaces with extends, never implements
  • Conflicting default methods must be overridden
  • Interface.super.method() picks a specific default

Mixing Both

abstract class Animal {
    protected final String name;
    Animal(String name) { this.name = name; }
    abstract String sound();
}
interface Swimmer { default String move() { return "swims"; } }
interface Walker  { default String move() { return "walks"; } }
interface Pet extends Comparable<Pet> { String owner(); }  // iface extends

class Duck extends Animal implements Swimmer, Walker, Pet {
    private final String owner;
    Duck(String n, String o) { super(n); owner = o; }

    String sound() { return "quack"; }
    public String owner() { return owner; }
    public int compareTo(Pet p) { return owner.compareTo(p.owner()); }

    @Override
    public String move() {                     // resolve the conflict
        return Swimmer.super.move() + " and " + Walker.super.move();
    }
}
new Duck("Don", "Ada").move();   // "swims and walks"

Notes

One superclass (Animal), three interfaces
Pet inherits compareTo from Comparable
X.super.move() calls a specific interface's default

⚠ Common Mistakes

  • class A implements B extends C — wrong order, compile error
  • interface X implements Y — interfaces use extends
  • Ignoring the diamond conflict error instead of overriding the method

✓ Tips & Best Practices

  • Keep inheritance shallow; layer behavior with interfaces
  • Records and enums can implement interfaces, which is often enough
  • Use composition plus an interface for flexible delegation

Quick Summary

  • extends — one class
  • implements — many interfaces
  • Interfaces extends interfaces
  • X.super.m() — pick a default
