Properties & Binding

StringProperty · IntegerProperty · bind · bindBidirectional · Bindings · addListener · ObservableValue · computed bindings

Observable State

JavaFX values are held in properties: observable wrappers that notify listeners when they change. Binding links one property to another so it updates automatically: label.textProperty().bind(field.textProperty()) mirrors typing in real time. Bindings can be one-way, two-way, or computed from several values.

Notes

  • A bound property can't be set directly; call unbind() first
  • Bidirectional bindings keep two properties in sync
  • Bindings has helpers: concat, when, createStringBinding
  • Listeners receive (observable, oldValue, newValue)

Properties, Bindings, Listeners

public class Person {                                  // property pattern
    private final StringProperty name = new SimpleStringProperty("");
    public StringProperty nameProperty() { return name; }
    public String getName() { return name.get(); }
    public void setName(String v) { name.set(v); }
}

TextField input = new TextField();
Label echo = new Label();
echo.textProperty().bind(input.textProperty());        // one-way

a.textProperty().bindBidirectional(b.textProperty());  // two-way

IntegerProperty qty = new SimpleIntegerProperty(2);
DoubleProperty price = new SimpleDoubleProperty(9.5);
NumberBinding total = qty.multiply(price);             // 19.0, auto-updates
totalLbl.textProperty().bind(Bindings.format("$%.2f", total));

Button save = new Button("Save");
save.disableProperty().bind(input.textProperty().isEmpty());   // computed

qty.addListener((obs, oldV, newV) -> System.out.println(oldV + " → " + newV));

Notes

The property pattern: field + xProperty() + get/set
Fluent operations (multiply, isEmpty) build bindings
Bindings.format produces a bound string
The Save button enables itself when text is entered

⚠ Common Mistakes

  • Calling set() on a bound property → RuntimeException: A bound value cannot be set
  • Listeners or bindings that keep large objects alive; unbind when screens close
  • Forgetting dependencies in createXxxBinding, so it never recomputes

✓ Tips & Best Practices

  • Bind disableProperty for form validation
  • Expose properties from view models; bind controls to them
  • Use Bindings.isEmpty, greaterThan, and, or for readable rules

Quick Summary

  • Properties = observable values
  • bind — one-way
  • bindBidirectional — two-way
