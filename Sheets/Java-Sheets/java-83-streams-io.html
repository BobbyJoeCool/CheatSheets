Byte Streams & I/O Streams

InputStream · OutputStream · FileInputStream · DataOutputStream · binary files · transferTo · readAllBytes

Reading and Writing Raw Bytes

InputStream and OutputStream are the base classes for byte I/O: images, audio, zip files, network data. Readers and writers (Sheets 76–77) handle text; streams handle binary. Decorator classes stack on top: BufferedInputStream adds buffering, and DataInputStream reads primitives like int and double in a fixed binary format.

Notes

  • read() returns a byte as 0–255, or -1 at end
  • Use InputStreamReader to turn bytes into characters
  • Java 9+: readAllBytes() and transferTo(out)
  • Data streams use big-endian order

Binary Copy & Primitive Data

try (var in = new BufferedInputStream(new FileInputStream("photo.jpg"));
     var out = new BufferedOutputStream(new FileOutputStream("copy.jpg"))) {
    in.transferTo(out);                        // copy everything (Java 9+)
}

try (var in = new FileInputStream("photo.jpg")) {
    byte[] buf = new byte[8192];
    int n;
    while ((n = in.read(buf)) != -1) {         // manual chunked read
        process(buf, n);
    }
}

try (var dos = new DataOutputStream(new FileOutputStream("scores.dat"))) {
    dos.writeInt(3);
    dos.writeDouble(98.5);
    dos.writeUTF("Ada");
}
try (var dis = new DataInputStream(new FileInputStream("scores.dat"))) {
    int count = dis.readInt();                 // 3
    double score = dis.readDouble();           // 98.5
    String name = dis.readUTF();               // "Ada"
}

Notes

transferTo is the simplest stream copy
Only the first n bytes of buf are valid each pass
Read data back in the same order it was written

⚠ Common Mistakes

  • Using FileReader for binary files — bytes get corrupted by decoding
  • Writing the whole buffer instead of only the n bytes read
  • Reading primitives back in a different order than they were written

✓ Tips & Best Practices

  • For whole files, Files.readAllBytes / Files.write are simplest
  • Always buffer file streams
  • Use ByteArrayOutputStream to capture output in tests

Quick Summary

  • Streams = bytes; readers = chars
  • transferTo — copy
  • DataInput/OutputStream — primitives
  • Buffer everything
