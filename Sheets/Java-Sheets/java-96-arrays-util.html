Arrays Utility Class

Arrays.toString · sort · fill · copyOf · copyOfRange · asList · equals · stream · binarySearch · deepToString

Static Helpers for Arrays

java.util.Arrays provides static methods for working with arrays: printing, sorting, searching, filling, copying, comparing, hashing, and converting to lists and streams. Arrays have no useful methods of their own, so this class is where nearly all array work happens.

Notes

  • Arrays.asList returns a fixed-size list backed by the array
  • Primitive arrays don't work with asList as you'd expect
  • equals compares contents; deepEquals handles nested arrays

Array Operations

int[] a = {5, 3, 8, 1};

Arrays.toString(a);                     // "[5, 3, 8, 1]"
Arrays.sort(a);                         // [1, 3, 5, 8]
Arrays.binarySearch(a, 5);              // 2
int[] big = Arrays.copyOf(a, 6);        // [1, 3, 5, 8, 0, 0]
int[] mid = Arrays.copyOfRange(a, 1, 3);// [3, 5]
Arrays.fill(big, 4, 6, -1);             // [1, 3, 5, 8, -1, -1]
Arrays.equals(a, new int[]{1, 3, 5, 8});// true

int sum = Arrays.stream(a).sum();       // 17

List<String> fixed = Arrays.asList("x", "y", "z");
fixed.set(0, "X");                      // ✔ allowed
fixed.add("w");                         // ✖ UnsupportedOperationException
List<String> growable = new ArrayList<>(Arrays.asList("x", "y"));

Integer[] boxed = {3, 1, 2};
Arrays.sort(boxed, Comparator.reverseOrder());   // [3, 2, 1]
Arrays.setAll(a, i -> i * i);           // [0, 1, 4, 9]

Notes

copyOf pads with defaults when growing
fill(arr, from, to, val) — to is exclusive
asList allows set but not add/remove
setAll computes each element from its index

⚠ Common Mistakes

  • Arrays.asList(intArray) gives a List<int[]> with one element
  • Adding to an asList result → UnsupportedOperationException
  • Printing an array with println(arr) instead of Arrays.toString

✓ Tips & Best Practices

  • Use deepToString for 2D arrays
  • Use Arrays.stream for sums, averages, and filtering
  • Use List.of(arr) for an immutable list from an object array
