Files & NIO

Files · Path · Path.of · readString · writeString · readAllLines · write · lines · StandardOpenOption

Modern File API

The NIO.2 API (java.nio.file) is the modern way to work with files. A Path represents a location; the Files class provides static methods to read, write, copy, move, and inspect files, often in one line. It reports errors with clear exceptions and uses UTF-8 by default for text methods.

Notes

  • Path.of (Java 11) replaces Paths.get
  • readString/readAllLines load the whole file into memory
  • Files.lines streams lazily; close it with try-with-resources
  • StandardOpenOption controls append, create, and truncate

One-Liners

import java.nio.file.*;

Path p = Path.of("data", "notes.txt");          // data/notes.txt

Files.writeString(p, "Hello\nWorld\n");          // create / overwrite
Files.writeString(p, "More\n", StandardOpenOption.APPEND);
String all = Files.readString(p);                // whole file
List<String> lines = Files.readAllLines(p);      // [Hello, World, More]
Files.write(p, List.of("a", "b"));               // write lines

try (Stream<String> s = Files.lines(p)) {         // lazy, big files
    s.filter(l -> l.startsWith("E")).forEach(System.out::println);
}

byte[] bytes = Files.readAllBytes(Path.of("logo.png"));
Files.exists(p);                                 // true
Files.size(p);                                   // bytes
Files.copy(p, Path.of("backup.txt"), StandardCopyOption.REPLACE_EXISTING);
Files.move(p, Path.of("archive/notes.txt"));
Files.deleteIfExists(Path.of("temp.txt"));

Notes

Path.of("a", "b") joins segments with the right separator
APPEND adds instead of overwriting
copy fails if the target exists unless you pass REPLACE_EXISTING
Directory operations are on Sheet 79

⚠ Common Mistakes

  • readAllLines on a multi-gigabyte log → OutOfMemoryError; use lines
  • Leaving a Files.lines stream unclosed, which leaks a file handle
  • Writing to a path whose parent folder doesn't exist → NoSuchFileException

✓ Tips & Best Practices

  • Call Files.createDirectories(p.getParent()) before writing
  • Use Files.writeString(p, text, CREATE, APPEND) for logs
  • Convert legacy File objects with file.toPath()
