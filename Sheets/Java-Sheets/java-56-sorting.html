Sorting & Searching

Collections.sort · List.sort · Arrays.sort · Comparator · reverseOrder · binarySearch · stable sort

Ordering and Finding Data

Java sorts arrays with Arrays.sort and lists with list.sort(comparator) or Collections.sort. Without a comparator, elements use their natural order (Comparable). Object sorts are stable, so equal elements keep their relative order. Once sorted, binarySearch finds elements in O(log n).

Notes

  • Primitives sort with dual-pivot quicksort; objects with TimSort (stable)
  • binarySearch on unsorted data gives meaningless results
  • Not found → binarySearch returns -(insertionPoint) - 1
  • Defining Comparable and Comparator is covered on Sheet 101

Sorting Examples

int[] nums = {5, 2, 9, 1};
Arrays.sort(nums);                                  // [1, 2, 5, 9]
Arrays.sort(nums, 1, 3);                            // sort a range only

List<String> words = new ArrayList<>(List.of("pear", "Fig", "apple"));
Collections.sort(words);                            // [Fig, apple, pear]
words.sort(String.CASE_INSENSITIVE_ORDER);          // [apple, Fig, pear]
words.sort(Comparator.reverseOrder());              // [pear, apple, Fig]
words.sort(Comparator.comparing(String::length));   // [Fig, pear, apple]

Integer[] boxed = {3, 1, 2};
Arrays.sort(boxed, Collections.reverseOrder());     // [3, 2, 1]

emps.sort(Comparator.comparing(Emp::dept)
          .thenComparing(Emp::salary, Comparator.reverseOrder()));

var sortedCopy = words.stream().sorted().toList();  // source unchanged
int[] sorted = {1, 3, 5, 7};
Arrays.binarySearch(sorted, 5);                     // 2
Arrays.binarySearch(sorted, 4);                     // -3 (would insert at 2)
Collections.binarySearch(List.of("a", "c"), "c");   // 1

Notes

Uppercase sorts before lowercase in natural order
reverseOrder needs objects, not int[]
thenComparing breaks ties
stream().sorted() leaves the original list as-is

⚠ Common Mistakes

  • Calling binarySearch on an unsorted list
  • Trying Arrays.sort(intArray, Collections.reverseOrder()) — doesn't compile for primitives
  • Sorting an immutable List.of in place → UnsupportedOperationException

✓ Tips & Best Practices

  • Sort descending primitives by sorting, then reversing, or use boxed() streams
  • Build comparators with comparing and thenComparing rather than subtraction
  • Use a TreeMap/TreeSet if you need data sorted continuously

Quick Summary

  • Arrays.sort / list.sort
  • Natural order or Comparator
  • Object sorts are stable
  • binarySearch — sorted data only
