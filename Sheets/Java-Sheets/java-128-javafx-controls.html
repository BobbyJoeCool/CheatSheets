Built-In UI Controls

JavaFX includes a rich set of controls in javafx.scene.control: buttons, text inputs, choices, lists, tables, sliders, date pickers, menus, and dialogs. Each control exposes properties (text, value, selection) that you can read, set, listen to, or bind (Sheet 130). Data-heavy controls use ObservableLists.

Notes

  • ListView/ComboBox/TableView display ObservableLists
  • Selection lives in getSelectionModel()
  • TableColumns use cell value factories to read data
  • Alert provides ready-made dialogs

Common Controls

TextField name = new TextField();
name.setPromptText("Your name");
CheckBox agree = new CheckBox("I agree");
var size = new ComboBox<>(FXCollections.observableArrayList("S", "M", "L"));
size.setValue("M");
Slider volume = new Slider(0, 100, 50);
DatePicker date = new DatePicker(LocalDate.now());

var list = new ListView<>(FXCollections.observableArrayList("A", "B"));
list.getSelectionModel().selectedItemProperty()
    .addListener((obs, old, sel) -> System.out.println(sel));

record Person(String name, int age) { }
TableView<Person> table = new TableView<>();
var nameCol = new TableColumn<Person, String>("Name");
nameCol.setCellValueFactory(
    c -> new SimpleStringProperty(c.getValue().name()));
table.getColumns().add(nameCol);
table.setItems(FXCollections.observableArrayList(new Person("Ada", 36)));

Alert a = new Alert(Alert.AlertType.CONFIRMATION, "Delete file?");
a.showAndWait().filter(r -> r == ButtonType.OK).ifPresent(r -> delete());

Notes

setPromptText shows placeholder text
Selection listeners get old and new values
Cell value factories map row objects to column values
showAndWait returns an Optional<ButtonType>

⚠ Common Mistakes

  • Replacing a list's items instead of modifying its ObservableList, losing listeners
  • Using PropertyValueFactory("name") with records — it looks for getName(); use a lambda
  • Reading getText() once instead of binding or listening for changes

✓ Tips & Best Practices

  • Use FXCollections.observableArrayList for all list data
  • Use TableView with records and lambda cell factories
  • Use Tooltip and prompt text for discoverability

Quick Summary

  • Controls expose properties
  • ObservableList drives lists/tables
  • getSelectionModel() — selection
  • Alert and choosers for dialogs
