HttpClient (Built-in)

HttpClient · HttpRequest · HttpResponse · GET · POST · BodyHandlers · sendAsync · timeouts · headers

HTTP Without Dependencies

java.net.http.HttpClient (Java 11+) is the JDK's modern HTTP client. It supports HTTP/1.1 and HTTP/2, synchronous and asynchronous requests, timeouts, redirects, and pluggable body handlers. Build an immutable HttpRequest, send it, and read the HttpResponse. No library needed.

Notes

  • Create one HttpClient and reuse it; it's thread-safe
  • Non-2xx responses don't throw; check statusCode()
  • send throws IOException and InterruptedException
  • Use a JSON library (Sheets 108–109) for bodies

GET, POST, Async

HttpClient client = HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(5))
    .followRedirects(HttpClient.Redirect.NORMAL)
    .build();

String base = "https://api.example.com";
HttpRequest get = HttpRequest.newBuilder(URI.create(base + "/users/1"))
    .header("Accept", "application/json")
    .timeout(Duration.ofSeconds(10))
    .GET().build();

var res = client.send(get, HttpResponse.BodyHandlers.ofString());
if (res.statusCode() == 200) System.out.println(res.body());

HttpRequest post = HttpRequest.newBuilder(URI.create(base + "/users"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString("{\"name\":\"Ada\"}"))
    .build();
client.send(post, HttpResponse.BodyHandlers.discarding());

client.sendAsync(get, HttpResponse.BodyHandlers.ofString())
      .thenApply(HttpResponse::body)
      .thenAccept(System.out::println)
      .join();                                       // wait (demo only)

Notes

Builders produce immutable request objects
BodyHandlers decide how the response body is read
sendAsync returns a CompletableFuture (Sheet 114)

⚠ Common Mistakes

  • Creating a new HttpClient per request — wasteful
  • Assuming 404/500 throw an exception
  • Forgetting the Content-Type header on POST bodies

✓ Tips & Best Practices

  • Set both connect and request timeouts
  • Wrap the client in a small service class for testability
  • Use ofFile to download large files without holding them in memory

Quick Summary

  • HttpClient — reusable, thread-safe
  • HttpRequest.newBuilder(uri)
  • send / sendAsync
  • Check statusCode() yourself
