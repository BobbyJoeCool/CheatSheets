Defining & Calling Methods

method signature · return type · void · static · access modifier · calling · naming

What a Method Is

A method is a named block of code that belongs to a class. Its signature is the name plus the parameter types; its declaration also states access level, whether it's static, and the return type (void if nothing is returned). Methods make code reusable, testable, and readable by giving a name to each step.

Notes

  • Every method lives inside a class; Java has no free functions
  • Names are verbs in camelCase: calculateTotal
  • static methods are called on the class; instance methods on an object
  • A non-void method must return a value on every path

Under the JVM

  • Calls compile to invokestatic, invokevirtual, or invokespecial (private and constructors)
  • The JIT inlines small methods (under ~35 bytes of bytecode), so short methods cost nothing
  • Each call pushes a stack frame holding its locals and operand stack

Declaring & Calling

public class Calc {
    // access  static  return  name   parameters
    public static int  add(int a, int b) {
        return a + b;
    }

    static void greet(String name) {          // no return value
        System.out.println("Hello, " + name);
    }

    double area(double r) {                   // instance method
        return Math.PI * r * r;
    }

    public static void main(String[] args) {
        int sum = add(2, 3);                  // 5
        greet("Ada");                         // Hello, Ada
        Calc c = new Calc();
        double a = c.area(2);                 // 12.566…
    }
}

Anatomy

public — who can call it
static — no object needed
int — type of the returned value
(int a, int b) — parameter list
return — hands the value back

Java Versions

  • 1.0 — methods, static, access modifiers
  • 5 — @Override and generic methods
  • 25 — instance main: beginners can skip static

Idiomatic Java

  • process(data, true) boolean flag → two named methods
  • Returning -1 for "not found" → OptionalInt or Optional<T>
  • getTotal() that hits the database → name it loadTotal()

⚠ Common Mistakes

  • Calling an instance method from static main without an object: "non-static method cannot be referenced"
  • Declaring a return type but missing return on some branch
  • Ignoring a returned value, like s.trim(); with no assignment

✓ Tips & Best Practices

  • Keep methods short and doing one thing
  • Make helpers private unless other classes need them

Quick Summary
