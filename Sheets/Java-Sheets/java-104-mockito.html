Faking Dependencies in Tests

Mockito creates mock objects: stand-ins for real dependencies (databases, HTTP clients, services) whose behavior you script with when(...).thenReturn(...). After running the code under test, verify(...) checks how the mock was called. This isolates the unit you're testing from slow or unpredictable collaborators.

Notes

  • Artifact: org.mockito:mockito-junit-jupiter (includes core)
  • Unstubbed methods return defaults: null, 0, false, empty collections
  • Mockito 5 can mock final classes by default
  • Mock interfaces you own, not value objects

Mocking a Repository

@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock UserRepository repo;               // fake dependency
    @Mock EmailSender email;
    @InjectMocks UserService service;        // real object, mocks injected

    @Test
    void registersNewUser() {
        when(repo.existsByEmail("ada@x.com")).thenReturn(false);
        when(repo.save(any())).thenAnswer(inv -> inv.getArgument(0));

        User u = service.register("ada@x.com");

        assertEquals("ada@x.com", u.email());
        verify(email).sendWelcome("ada@x.com");          // called once
        verify(repo, never()).delete(any());
    }

    @Test
    void rejectsDuplicates() {
        when(repo.existsByEmail(anyString())).thenReturn(true);
        assertThrows(DuplicateException.class,
                     () -> service.register("a@x.com"));
        verifyNoInteractions(email);
    }
}

Notes

@InjectMocks builds UserService with the mocks
thenAnswer computes the return value from the call
verify(mock).method(args) asserts a call happened
never(), times(2), atLeastOnce() control counts

⚠ Common Mistakes

  • Mixing raw values and matchers: f(1, any()) — use f(eq(1), any())
  • Mocking the class under test instead of its dependencies
  • Over-verifying every call, making tests break on harmless refactors

✓ Tips & Best Practices

  • Verify outcomes and important interactions only
  • Use ArgumentCaptor to inspect complex arguments
  • Use spy sparingly — it means partially real objects

Quick Summary
