File Paths & Directories

Path · resolve · relativize · normalize · toAbsolutePath · createDirectories · list · walk · DirectoryStream

Navigating the File System

A Path can be absolute (from the root) or relative (from the current working directory). Path methods combine, compare, and clean up paths without touching the disk. Files methods create, list, walk, and delete directories. Use these instead of building paths with string concatenation.

Notes

  • Relative paths resolve against System.getProperty("user.dir")
  • Files.list is one level; Files.walk is recursive
  • Files.delete fails on non-empty directories
  • Close list/walk streams with try-with-resources

Path Manipulation & Directories

Path base = Path.of("/home/ada/projects");
Path file = base.resolve("app/src/Main.java");  // …/projects/app/src/Main.java
file.getFileName();                                // Main.java
file.getParent();                                // …/projects/app/src
Path.of("a/./b/../c").normalize();                 // a/c
base.relativize(file);                             // app/src/Main.java
Path.of("notes.txt").toAbsolutePath();             // /current/dir/notes.txt

Files.createDirectories(Path.of("out/reports/2026"));  // all parents
Files.isDirectory(base);                               // true

try (Stream<Path> s = Files.list(base)) {             // one level
    s.forEach(System.out::println);
}
try (Stream<Path> s = Files.walk(base)) {             // recursive
    var java = s.filter(f -> f.toString().endsWith(".java")).toList();
}
try (Stream<Path> s = Files.walk(Path.of("tmp"))) {   // delete a tree
    s.sorted(Comparator.reverseOrder())
     .forEach(f -> f.toFile().delete());
}

Notes

resolve appends a child path
relativize gives the path from one to another
Reverse-sorted walk deletes children before parents

⚠ Common Mistakes

  • Concatenating paths with "/" — breaks on Windows; use resolve
  • Calling createDirectory when parents don't exist
  • Assuming relative paths are relative to the source file; they're relative to the working directory

✓ Tips & Best Practices

  • Get the user's home with Path.of(System.getProperty("user.home"))
  • Use glob filters: Files.newDirectoryStream(dir, "*.{png,jpg}")
  • Load bundled files with getResourceAsStream, not file paths
