reduce & Collectors

reduce · collect · Collectors.toList · groupingBy · counting · joining · partitioningBy · toMap · summingInt

Aggregating Results

Terminal operations turn a stream into a result. reduce folds elements into one value with an accumulator. collect uses a Collector to build a container: lists, sets, maps, joined strings, or grouped summaries. The Collectors class provides ready-made collectors, and many can be nested.

Notes

  • reduce(identity, op) returns a value; without an identity it returns Optional
  • groupingBy returns Map<K, List<V>> by default
  • toMap throws on duplicate keys unless you pass a merge function

Collecting

int sum = Stream.of(1, 2, 3, 4).reduce(0, Integer::sum);       // 10
Optional<Integer> prod =
    Stream.of(2, 3, 4).reduce((a, b) -> a * b);                // 24

String csv = names.stream()
    .collect(Collectors.joining(", ", "[", "]"));      // "[Ada, Alan]"
Map<String, List<Emp>> byDept = emps.stream()
    .collect(Collectors.groupingBy(Emp::dept));

Map<String, Long> countByDept = emps.stream()
    .collect(Collectors.groupingBy(Emp::dept, Collectors.counting()));
                                                       // {eng=2, ops=1}
Map<String, Double> avgPay = emps.stream()
    .collect(Collectors.groupingBy(Emp::dept,
             Collectors.averagingDouble(Emp::salary)));

var evenOdd = IntStream.range(0, 6).boxed()
    .collect(Collectors.partitioningBy(n -> n % 2 == 0));  // {false=[1,3,5], …}
Map<String, Double> pay = emps.stream()
    .collect(Collectors.toMap(Emp::name, Emp::salary, (a, b) -> a));

Notes

joining(sep, prefix, suffix)
The second groupingBy argument is a downstream collector
partitioningBy always has both true and false keys
(a, b) -> a keeps the first value on duplicate keys

⚠ Common Mistakes

  • toMap with duplicate keys → IllegalStateException; supply a merge function
  • Using reduce to build collections — use collect
  • Expecting groupingBy to keep insertion order; pass LinkedHashMap::new or TreeMap::new

✓ Tips & Best Practices

  • Use stream.toList() for plain lists; Collectors for everything else
  • Nest mapping inside groupingBy for "names by dept"
  • IntSummaryStatistics gives all numeric stats in one pass

Quick Summary

  • reduce — fold to one value
  • collect — build a container
