Object-Relational Mapping

JPA (Jakarta Persistence) is the standard API for mapping Java classes to database tables; Hibernate is its most popular implementation. You annotate classes as entities, and an EntityManager saves, loads, and tracks them, generating SQL for you. Changes to managed entities are written automatically when the transaction commits.

Notes

  • Packages: jakarta.persistence.* (older code: javax.persistence)
  • Entities need a no-arg constructor and an @Id
  • Records can't be entities (they're final and immutable)
  • Spring Data JPA wraps all of this in repositories

Mapping Entities

@Entity
@Table(name = "customer")
public class Customer {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)
    private String name;
    @Column(unique = true) private String email;

    @OneToMany(mappedBy = "customer", cascade = CascadeType.ALL)
    private List<Order> orders = new ArrayList<>();

    protected Customer() { }                        // required by JPA
    public Customer(String n, String e) { name = n; email = e; }
}

@Entity
public class Order {
    @Id @GeneratedValue private Long id;
    @ManyToOne(fetch = FetchType.LAZY) @JoinColumn(name = "customer_id")
    private Customer customer;
    private BigDecimal total;
}

Notes

@Id + @GeneratedValue — database-generated primary key
mappedBy marks the owning side (Order.customer)
LAZY loads the customer only when accessed
cascade saves/deletes orders with their customer

Core Annotations

AnnotationPurpose
@Entity / @TableClass ↔ table
@Id / @GeneratedValuePrimary key
@ColumnColumn details

Relationships

AnnotationExample
@OneToOneUser ↔ Profile
@OneToManyCustomer → Orders
@ManyToOneOrder → Customer
@ManyToManyStudent ↔ Course

⚠ Common Mistakes

  • @Enumerated default (ORDINAL) — reordering the enum corrupts data; use STRING
  • EAGER fetching everywhere, which loads half the database per query
  • Using @Data (Lombok) on entities — see Sheet 110

✓ Tips & Best Practices

  • Make @ManyToOne relationships LAZY
  • Manage schemas with Flyway or Liquibase, not hbm2ddl=update in production
  • Log SQL in development to see what Hibernate generates

Quick Summary

  • JPA = API, Hibernate = engine
  • @Entity + @Id
  • Relationship annotations
  • EntityManager tracks entities
