Resizable Lists

ArrayList<E> is the go-to List implementation: a resizable array that grows automatically. It gives fast index access (get, set) and fast appends, but inserting or removing in the middle shifts elements. Declare variables as the interface type List<E> so you can swap implementations later.

Notes

  • Holds objects only: List<Integer>, not List<int>
  • List.of(...) creates an immutable list
  • remove(int) removes by index; remove(Object) by value
  • Not thread-safe

Core Operations

List<String> list = new ArrayList<>();
list.add("Ada");                    // [Ada]
list.add("Grace");                  // [Ada, Grace]
list.add(1, "Alan");                // [Ada, Alan, Grace]
list.get(0);                        // "Ada"
list.set(0, "Lovelace");            // [Lovelace, Alan, Grace]
list.size();                        // 3
list.contains("Alan");              // true
list.indexOf("Grace");              // 2
list.remove("Alan");                // by value → true
list.remove(0);                     // by index → "Lovelace"
list.isEmpty();                     // false

List<Integer> nums = new ArrayList<>(List.of(5, 3, 9));
nums.remove(Integer.valueOf(3));    // value 3, not index 3
nums.addAll(List.of(1, 2));         // [5, 9, 1, 2]
nums.sort(null);                    // [1, 2, 5, 9]
nums.removeIf(n -> n > 4);          // [1, 2]
List<Integer> fixed = List.of(1, 2);
fixed.add(3);                       // ✖ UnsupportedOperationException

Notes

<> (diamond) infers the type argument
Wrap List.of in new ArrayList<>(…) to get a mutable copy
sort(null) uses natural order

⚠ Common Mistakes

  • nums.remove(3) on a List<Integer> removes index 3, not the value 3
  • Modifying an immutable List.of list
  • Removing items inside a for-each loop → ConcurrentModificationException

✓ Tips & Best Practices

  • Declare as List<T>; construct as new ArrayList<>()
  • Pre-size big lists: new ArrayList<>(10_000)
  • Use removeIf and replaceAll instead of manual loops
