System Class

System.out · System.in · System.err · currentTimeMillis · nanoTime · getenv · getProperty · exit · arraycopy · lineSeparator

Access to the Runtime Environment

java.lang.System exposes the standard streams, the clock, environment variables, JVM system properties, and a few low-level utilities. All members are static. It's how a program reads configuration from its environment, measures elapsed time, and exits with a status code.

Notes

  • nanoTime is for measuring durations, not the time of day
  • Environment variables are read-only from Java
  • exit(0) = success; non-zero = failure
  • System.gc() is only a hint to the garbage collector

Under the JVM

  • nanoTime is monotonic; currentTimeMillis follows the wall clock and can jump
  • arraycopy is an intrinsic, often a single block copy
  • exit runs shutdown hooks and then stops every thread, daemon or not

Common Calls

long start = System.nanoTime();
doWork();
long ms = (System.nanoTime() - start) / 1_000_000;      // elapsed ms

long epochMs = System.currentTimeMillis();              // wall clock
String home = System.getProperty("user.home");          // /home/ada
String javaVer = System.getProperty("java.version");    // 21.0.4
String mode = System.getProperty("app.mode", "dev");    // -Dapp.mode=prod
String dbUrl = System.getenv("DATABASE_URL");           // null if unset
Map<String, String> env = System.getenv();

int[] src = {1, 2, 3, 4, 5};
int[] dst = new int[3];
System.arraycopy(src, 1, dst, 0, 3);                    // dst = [2, 3, 4]

String nl = System.lineSeparator();                     // "\n" or "\r\n"
System.identityHashCode(obj);

System.setOut(new PrintStream(new FileOutputStream("log.txt")));  // redirect
System.err.println("warning");
if (badArgs) System.exit(1);                            // stop with error code

Notes

-Dkey=value on the java command sets properties
getenv returns null for unset variables
arraycopy(src, srcPos, dst, dstPos, length)
Avoid exit in libraries and servers

Java Versions

  • 1.0 — System.out / in / err · currentTimeMillis · arraycopy
  • 5 — nanoTime · getenv
  • 7 — lineSeparator() · 9 — System.Logger

Idiomatic Java

  • System.getProperty("line.separator") → System.lineSeparator()
  • System.gc() to "free memory" → remove it; it's only a hint and often a full pause

⚠ Common Mistakes

  • Measuring elapsed time with currentTimeMillis — clock changes skew it; use nanoTime
  • Calling getenv("X").trim() without a null check
  • Calling System.exit from deep inside library code

✓ Tips & Best Practices

  • Use Objects.requireNonNullElse(System.getenv("PORT"), "8080")
  • Use JMH for real benchmarks, not ad-hoc nanoTime
  • Prefer Files and Path.of(System.getProperty("user.home")) for user paths

Quick Summary

  • nanoTime — durations
  • getenv / getProperty — config
