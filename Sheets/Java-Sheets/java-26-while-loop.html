While Loop

while · condition · sentinel · infinite loop · while(true) · input loop · iterator loop

Condition-Driven Loops

A while loop repeats its body as long as its condition stays true, checking the condition before every pass. If the condition starts false, the body never runs. Use it when you don't know in advance how many iterations you need: reading until end of input, waiting for a state, or processing until a sentinel value appears.

Notes

  • Something inside the loop must eventually make the condition false
  • while (true) + break is a valid, common pattern
  • The body may run zero times
  • Prefer for when you have a counter

While Patterns

int n = 1;
while (n < 100) {
    n *= 2;                       // 2 4 8 16 32 64 128
}

// Sentinel: read until "quit"
Scanner in = new Scanner(System.in);
String cmd = in.nextLine();
while (!cmd.equals("quit")) {
    handle(cmd);
    cmd = in.nextLine();
}

// Digits of a number
int x = 4096, digits = 0;
while (x > 0) { x /= 10; digits++; }   // digits = 4

while (true) {                    // loop-and-a-half
    String line = in.nextLine();
    if (line.isEmpty()) break;
    process(line);
}

Notes

The sentinel loop reads once before and once at the end
x /= 10 strips one digit per pass
while (true) reads clearly when the exit is in the middle

⚠ Common Mistakes

  • Forgetting to update the loop variable → infinite loop
  • while (x != 10) with x += 3 skips 10 and never stops; use <
  • A stray semicolon while (cond); loops forever doing nothing

✓ Tips & Best Practices

  • Add a safety counter while debugging possibly-infinite loops
  • Assign-and-test in one line: while ((line = br.readLine()) != null)
  • Keep the exit condition visible at the top when possible

Quick Summary

  • while (cond) { } — check first
  • Zero or more iterations
  • Use for unknown counts
  • while (true) + break — mid-exit
