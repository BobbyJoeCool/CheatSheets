FileReader & FileWriter

FileReader · FileWriter · append mode · character streams · charset · read() · write() · close

Basic Character File I/O

FileReader and FileWriter read and write characters to files. They're the simplest file classes in java.io, reading one character (or a buffer) at a time. On their own they're unbuffered and slow, so they're usually wrapped in BufferedReader/BufferedWriter (Sheet 77). Java 11 added constructors that take a Charset.

Notes

  • FileWriter(path) overwrites; FileWriter(path, true) appends
  • Before Java 18, the default charset was platform-dependent
  • read() returns -1 at end of file
  • Always close streams; use try-with-resources

Reading & Writing Characters

import java.io.*;
import java.nio.charset.StandardCharsets;

try (FileWriter fw = new FileWriter("notes.txt", StandardCharsets.UTF_8)) {
    fw.write("Line one\n");
    fw.write("Line two\n");
}                                                // overwrites file

try (var fw = new FileWriter("notes.txt", StandardCharsets.UTF_8, true)) {
    fw.write("Appended\n");                      // append mode
}

try (FileReader fr = new FileReader("notes.txt", StandardCharsets.UTF_8)) {
    int ch;
    while ((ch = fr.read()) != -1) {             // one char at a time
        System.out.print((char) ch);
    }
}

try (FileReader fr = new FileReader("notes.txt")) {
    char[] buf = new char[1024];
    int n = fr.read(buf);                        // fill a buffer
    String chunk = new String(buf, 0, n);
}

Notes

read() returns an int so -1 can signal EOF
Cast to char to print the character
Reading into a char[] is much faster than single chars
Both constructors throw IOException

Constructors

ConstructorBehavior
FileWriter(String path)Create / overwrite
FileWriter(String path, boolean append)Append if true
FileWriter(String, Charset)Explicit encoding (11+)
FileReader(String path)Open for reading

⚠ Common Mistakes

  • Forgetting the append flag and wiping the file
  • Not closing the writer, so buffered data never reaches disk
  • Relying on the default charset on older JVMs — accented characters get garbled

✓ Tips & Best Practices

  • Wrap in BufferedReader/BufferedWriter for real work
  • For small files, Files.readString / Files.writeString are simpler (Sheet 78)
  • Always specify StandardCharsets.UTF_8

Quick Summary

  • FileReader — read chars
  • FileWriter — write chars
  • true flag — append
  • Close with try-with-resources
