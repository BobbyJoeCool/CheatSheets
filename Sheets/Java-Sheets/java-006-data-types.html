Sheet 006

Primitive Data Types

byte · short · int · long · float · double · char · boolean · literals

The Eight Primitives

Java has eight primitive types that hold raw values directly, not object references. Integer types differ only in size and range; float and double are IEEE 754 floating point; char is a 16-bit UTF-16 code unit; boolean is true or false and cannot be treated as a number. Everything else is a reference type.

Notes

  • Integer literals are int by default; add L for long
  • Decimal literals are double by default; add f for float
  • Underscores improve readability: 1_000_000
  • Integer overflow wraps silently: no exception

Under the JVM

  • byte, short, char and boolean locals each take a full 32-bit slot; arrays of them are packed
  • long and double take two slots, and writes aren't atomic unless volatile
  • char is a UTF-16 code unit, not a character — an emoji needs two

Literals & Edge Cases

int hex = 0xFF;            // 255
int bin = 0b1010;          // 10
int oct = 017;             // 15  (leading 0 = octal!)
long big = 9_000_000_000L; // needs L
float f = 1.5f;            // needs f
double d = 1.5;
char c = 'A';              // 65 as a number
char u = '\u03A9';          // Ω
int max = Integer.MAX_VALUE;   // 2147483647
max + 1;                   // -2147483648 (overflow)
0.1 + 0.2;                 // 0.30000000000000004
1.0 / 0;                   // Infinity
0.0 / 0;                   // NaN

Edge Cases

017 is octal; never pad decimals with zeros
Math.addExact(a, b) throws on overflow instead of wrapping
double cannot represent 0.1 exactly; use BigDecimal for money
Double.isNaN(x) — NaN == NaN is false

Java Versions

  • 1.0 — the eight primitives
  • 7 — binary literals 0b1010 and underscores 1_000_000
  • 8 — unsigned helpers: Integer.toUnsignedString, divideUnsigned
  • 17 — all floating point is strict; strictfp is redundant

Idiomatic Java

  • 1000000 → 1_000_000
  • byte / short locals "to save memory" → int (they take a full slot anyway)
  • 017 meaning seventeen → no leading zeros; Java reads them as octal (15)

⚠ Common Mistakes

  • long ms = 24 * 60 * 60 * 1000 * 365; overflows as int before assignment; write 365L
  • Comparing doubles with == after arithmetic; compare with a tolerance
  • Writing float f = 1.5; — a double literal won't narrow implicitly

✓ Tips & Best Practices

  • Default to int and double; use others when size or range demands it
  • Use long for timestamps and IDs
  • Use BigDecimal for currency, BigInteger for huge integers

Quick Summary

  • int long — whole numbers
  • double float — decimals
  • char — one UTF-16 unit
  • boolean — true / false only
