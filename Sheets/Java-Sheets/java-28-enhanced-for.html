Enhanced For Loop

for-each · Iterable · arrays · collections · Map.entrySet · ConcurrentModificationException · var

Looping Over Elements

The enhanced for loop (for-each) visits every element of an array or any Iterable (lists, sets, queues) without an index. It is shorter and avoids off-by-one errors. The trade-off: you can't see the index, can't go backwards, and can't safely add or remove elements from the collection during the loop.

Notes

  • The loop variable is a copy of each element (or reference)
  • Works on arrays and anything implementing Iterable
  • Maps aren't Iterable; loop over entrySet(), keySet(), or values()
  • Structural changes throw ConcurrentModificationException

For-Each Examples

int[] nums = {3, 5, 7};
int sum = 0;
for (int n : nums) sum += n;              // 15

List<String> names = List.of("Ada", "Alan");
for (String name : names) {
    System.out.println(name.toUpperCase());
}

Map<String, Integer> stock = Map.of("apples", 4, "pears", 2);
for (Map.Entry<String, Integer> e : stock.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}
for (var e : stock.entrySet()) { }        // var shortens it

for (int n : nums) n *= 2;                // ✖ array unchanged

for (String s : list) {
    if (s.isEmpty()) list.remove(s);      // ✖ ConcurrentModificationException
}
list.removeIf(String::isEmpty);           // ✔

Notes

Read it as "for each n in nums"
Assigning to the loop variable doesn't change the array
Use removeIf or an Iterator to delete safely
entrySet gives key and value in one pass

⚠ Common Mistakes

  • Adding or removing items from a collection inside its own for-each loop
  • Expecting for (int x : arr) x = 0; to clear the array
  • Calling map.get(key) inside a keySet() loop; use entrySet() instead

✓ Tips & Best Practices

  • Default to for-each; switch to indexed only when you need i
  • Use list.forEach(System.out::println) for one-liners
  • Need index and element? IntStream.range(0, list.size())

Quick Summary

  • for (T x : items) — every element
  • Arrays + any Iterable
  • No index, no structural changes
  • Maps: loop entrySet()
