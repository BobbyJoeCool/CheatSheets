BufferedReader Input

BufferedReader · InputStreamReader · readLine · lines() · parseInt · IOException · StringTokenizer

Fast Line-Based Input

BufferedReader wraps a character stream and reads text a line at a time through an internal buffer. Paired with InputStreamReader(System.in), it reads console input far faster than Scanner, which matters for large inputs and competitive programming. It only returns strings, so you parse values yourself.

Notes

  • readLine() returns null at end of input
  • Methods throw the checked IOException
  • No regex tokenizing overhead, unlike Scanner
  • Console (System.console()) can read passwords without echo

Reading Console Input

import java.io.*;

public static void main(String[] args) throws IOException {
    BufferedReader br = new BufferedReader(
            new InputStreamReader(System.in));

    String name = br.readLine();                 // "Ada"
    int age = Integer.parseInt(br.readLine().trim());   // 36

    String[] parts = br.readLine().split("\\s+");   // "3 4 5"
    int sum = 0;
    for (String p : parts) sum += Integer.parseInt(p);  // 12

    String line;
    while ((line = br.readLine()) != null) {     // until EOF
        System.out.println(line.toUpperCase());
    }
}

Notes

throws IOException — or wrap in try/catch
.trim() before parsing removes stray spaces
split("\\s+") handles multiple spaces
Ctrl+D (Mac/Linux) or Ctrl+Z (Windows) sends EOF

Scanner vs BufferedReader

FeatureScannerBufferedReader
SpeedSlowerMuch faster
Parses typesYes (nextInt…)No, strings only
Buffer size1 KB8 KB default
ExceptionsUncheckedChecked IOException
Best forSmall interactive inputLarge input, files

Reading Patterns

GoalCode
One intInteger.parseInt(br.readLine())
Ints on a lineArrays.stream(line.split(" ")).mapToInt(Integer::parseInt)
All linesbr.lines().toList()
PasswordSystem.console().readPassword()

⚠ Common Mistakes

  • Forgetting throws IOException, which gives a compile error
  • Calling .trim() on a null line at EOF — check for null first
  • Mixing Scanner and BufferedReader on the same System.in; buffers steal each other's data

✓ Tips & Best Practices

  • Use br.lines() for a stream of all remaining lines
  • Wrap in try-with-resources when reading files (Sheet 77)
  • System.console() returns null inside most IDEs; test in a real terminal

Quick Summary

  • BufferedReader — fast line input
  • readLine() — next line or null
  • Parse manually with parseInt
  • Checked IOException
