Switch — Expressions (Java 14+)

-> arrow · yield · switch expression · exhaustiveness · pattern matching · when guard · case null

Modern Switch

Java 14 made switch usable as an expression with arrow labels (case X ->). Arrow cases never fall through, can list several values, and the whole switch can return a value. Java 21 added pattern matching: switch on any object type, deconstruct records, add when guards, and handle case null.

Notes

  • A switch expression must be exhaustive (cover every case)
  • yield returns a value from a block body
  • Enums and sealed types can be exhaustive without default
  • Arrow and colon labels can't be mixed in one switch

Arrow Syntax & Patterns

String name = switch (day) {
    case 1, 7 -> "Weekend";
    case 2, 3, 4, 5, 6 -> "Weekday";
    default -> {
        log(day);
        yield "Unknown";             // block result via yield
    }
};

// Pattern matching (Java 21)
String describe(Object o) {
    return switch (o) {
        case null -> "null!";
        case Integer i when i > 100 -> "big int " + i;
        case Integer i -> "int " + i;
        case String s -> "text of " + s.length();
        case Point(int x, int y) -> "point " + x + "," + y;
        default -> "something else";
    };
}

Notes

Comma-separated labels replace stacked cases
when adds a condition to a pattern
Point(int x, int y) is a record pattern
Order matters: specific patterns before general ones

⚠ Common Mistakes

  • Using return inside a switch expression block — use yield
  • Putting case Integer i before case Integer i when … — the guarded case becomes unreachable
  • Forgetting ; after the closing brace of a switch expression assignment

✓ Tips & Best Practices

  • Default to arrow syntax in all new code
  • Omit default on enums so the compiler flags new constants
  • Combine with sealed interfaces (Sheet 73) for type-safe branching

Quick Summary

  • case A, B -> — no fall-through
  • switch as expression → value
  • yield — return from block
  • case Type t when … — patterns (21+)
