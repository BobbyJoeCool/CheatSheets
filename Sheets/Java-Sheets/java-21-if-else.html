Sheet 21

If / Else

if · else if · else · nested if · braces · guard clause · pattern matching instanceof

Making Decisions

An if statement runs a block only when its condition is true. Add else if branches to test more conditions in order, and an optional else to catch everything else. Java checks branches top to bottom and runs only the first one that matches. Conditions must be boolean; there is no truthy/falsy conversion.

Notes

  • Braces are optional for one statement, but always use them
  • Only the first matching branch runs
  • if (x) requires x to be boolean
  • Java 16+: if (obj instanceof String s) binds s

Syntax & Patterns

int score = 83;
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';                       // ← this runs
} else if (score >= 70) {
    grade = 'C';
} else {
    grade = 'F';
}

// Guard clause: exit early instead of nesting
if (user == null) return;
if (!user.isActive()) return;
process(user);

// Pattern matching for instanceof (Java 16+)
if (obj instanceof String s && !s.isBlank()) {
    System.out.println(s.length());
}

Notes

Order branches from most to least specific
Guard clauses keep the "happy path" unindented
s is only in scope where the match is certain

⚠ Common Mistakes

  • if (x > 0); — the stray semicolon ends the if; the block always runs
  • Dangling else without braces attaches to the nearest if
  • Ordering >= 70 before >= 90 makes the higher branches unreachable

✓ Tips & Best Practices

  • Always use braces, even for one-line bodies
  • Replace deep nesting with guard clauses or extracted methods
  • Use switch when testing one variable against many constants

Quick Summary

  • if — run when true
  • else if — next test, in order
  • else — fallback
  • instanceof pattern — test + cast
