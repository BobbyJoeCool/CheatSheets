Organizing and Referencing Classes

A package is a namespace that groups related classes, like java.util or com.acme.billing. Every class's full name includes its package: java.util.ArrayList. An import statement lets you use the short name. Imports are purely a compile-time convenience; they don't load or include code.

Notes

  • java.lang (String, Math, System) is imported automatically
  • Classes in the same package need no import
  • Wildcard * imports one package, not its subpackages
  • Java 25: import module java.base; imports a whole module

Import Forms

package com.acme.billing;                  // this file's package

import java.util.List;                     // single-type import
import java.util.*;                        // wildcard: all of java.util
import java.time.LocalDate;
import static java.lang.Math.PI;           // static member import
import static java.lang.Math.*;            // all static members

public class Invoice {
    List<String> items = new ArrayList<>();      // from java.util.*
    LocalDate due = LocalDate.now().plusDays(30);
    double area = PI * pow(2, 2);                // static imports

    java.sql.Date sqlDate;                 // fully qualified: avoids
    java.util.Date utilDate;               // the Date name clash
}

Notes

package must be the first statement
Static imports bring in fields and methods
When two packages share a class name, qualify one fully
Unused imports are harmless but clutter files

⚠ Common Mistakes

  • Thinking import java.util.* also imports java.util.function — it doesn't
  • Importing two classes with the same simple name — compile error
  • Overusing static wildcard imports so readers can't tell where max comes from

✓ Tips & Best Practices

  • Prefer single-type imports; let the IDE manage them
  • Use static imports for test assertions and constants
  • Organize imports automatically (Ctrl+Alt+O in IntelliJ)

Quick Summary

  • package — namespace
  • import a.b.C — short name
  • import static — static members
  • java.lang is automatic
