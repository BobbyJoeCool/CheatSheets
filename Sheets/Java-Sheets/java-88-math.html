Math Class

Math.abs · pow · sqrt · round · floor · ceil · max · min · random · PI · floorMod · addExact

Built-In Math Functions

java.lang.Math is a utility class of static methods and constants for common numeric work: powers, roots, rounding, trigonometry, logarithms, and overflow-safe arithmetic. Most methods take and return double. Because it's in java.lang, no import is needed.

Notes

  • Trig functions use radians; convert with Math.toRadians
  • round returns long for double input, int for float
  • *Exact methods throw ArithmeticException on overflow
  • StrictMath gives bit-identical results across platforms

Common Calls

Math.abs(-7.5);          // 7.5
Math.pow(2, 10);         // 1024.0
Math.sqrt(144);          // 12.0
Math.cbrt(27);           // 3.0
Math.max(3, 9);          // 9
Math.min(-1, 4);         // -1

Math.round(2.5);         // 3    (half up → long)
Math.round(-2.5);        // -2   (toward +∞)
Math.floor(2.9);         // 2.0
Math.ceil(2.1);          // 3.0
Math.rint(2.5);          // 2.0  (half to even)

Math.floorDiv(-7, 2);    // -4
Math.floorMod(-7, 2);    // 1
Math.hypot(3, 4);        // 5.0
Math.clamp(15, 0, 10);   // 10   (Java 21)
Math.addExact(Integer.MAX_VALUE, 1);   // ✖ ArithmeticException
Math.round(3.14159 * 100) / 100.0;     // 3.14  (2 decimals)

Notes

floor/ceil return double; cast if you need int
round ties go toward positive infinity
clamp limits a value to a range (Java 21+)
For exact money rounding use BigDecimal.setScale

⚠ Common Mistakes

  • Math.sin(90) expecting 1 — 90 is radians; use Math.sin(Math.toRadians(90))
  • int x = Math.round(2.7); doesn't compile — it returns long
  • Math.abs(Integer.MIN_VALUE) is still negative (overflow)

✓ Tips & Best Practices

  • Use Math.floorMod for wrap-around indexes (clock math, circular buffers)
  • Use *Exact methods where silent overflow would be a bug
  • Use Random/ThreadLocalRandom instead of Math.random() (Sheet 89)
