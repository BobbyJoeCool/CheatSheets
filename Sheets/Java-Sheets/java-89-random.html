Random Numbers

Random · nextInt · nextDouble · bounds · seed · ThreadLocalRandom · SecureRandom · Math.random

Generating Random Values

java.util.Random produces pseudo-random numbers from a seed. With a fixed seed, the sequence is reproducible, which is useful for tests and simulations. ThreadLocalRandom is faster in multithreaded code, and SecureRandom produces cryptographically strong values for tokens and passwords. Math.random() is a quick shortcut for a double in [0, 1).

Notes

  • nextInt(bound) returns 0 to bound − 1
  • Java 17+: nextInt(origin, bound) for ranges
  • Never use Random for security-sensitive values
  • Collections.shuffle(list, rnd) shuffles reproducibly

Random in Practice

Random rnd = new Random();
rnd.nextInt();                 // any int
rnd.nextInt(6);                // 0–5
rnd.nextInt(6) + 1;            // 1–6 (die roll)
rnd.nextInt(10, 21);           // 10–20 (Java 17+)
rnd.nextDouble();              // 0.0 ≤ x < 1.0
rnd.nextBoolean();             // true / false
rnd.nextGaussian();            // normal: mean 0, sd 1

Random seeded = new Random(42);  // same sequence every run
seeded.nextInt(100);             // always the same first value

int r = ThreadLocalRandom.current().nextInt(1, 101);   // 1–100, thread-safe

SecureRandom sec = new SecureRandom();
byte[] token = new byte[16];
sec.nextBytes(token);
String hex = HexFormat.of().formatHex(token);          // 32 hex chars

List<String> deck = new ArrayList<>(List.of("A", "K", "Q"));
Collections.shuffle(deck, new Random(7));
String pick = deck.get(rnd.nextInt(deck.size()));      // random element

Notes

Upper bounds are exclusive
ThreadLocalRandom.current() — never share or store it
HexFormat (Java 17) formats bytes as hex
Random element: index nextInt(size)

⚠ Common Mistakes

  • rnd.nextInt(6) for a die — that's 0–5, add 1
  • Creating new Random() inside a loop; reuse one instance
  • Generating passwords or reset tokens with Random

✓ Tips & Best Practices

  • Seed Random in tests to make failures reproducible
  • Use rnd.ints(5, 1, 50) for a stream of random ints
  • Use UUID.randomUUID() for unique IDs
