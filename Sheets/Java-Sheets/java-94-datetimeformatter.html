Formatting and Parsing Dates

DateTimeFormatter converts java.time objects to text (format) and text back to objects (parse). Use built-in ISO formatters, localized styles, or a custom pattern built from pattern letters like yyyy-MM-dd. Formatters are immutable and thread-safe, so store them in static final constants.

Notes

  • Pattern letters are case-sensitive: MM month, mm minute
  • Use uuuu or yyyy for year; YYYY is week-based year
  • Pass a Locale for month and day names
  • Parsing fails with DateTimeParseException on mismatch

Format & Parse

LocalDateTime t = LocalDateTime.of(2026, 10, 2, 14, 5);

t.format(DateTimeFormatter.ISO_LOCAL_DATE);              // 2026-10-02
DateTimeFormatter f = DateTimeFormatter.ofPattern("dd/MM/yyyy HH:mm");
t.format(f);                                             // 02/10/2026 14:05
DateTimeFormatter.ofPattern("EEEE, MMMM d, yyyy").format(t);
                                              // Friday, October 2, 2026
DateTimeFormatter.ofPattern("h:mm a", Locale.US).format(t);   // 2:05 PM
DateTimeFormatter.ofPattern("d MMM", Locale.FRANCE).format(t);  // 2 oct.

DateTimeFormatter.ofLocalizedDate(FormatStyle.MEDIUM)
    .withLocale(Locale.UK).format(t);                    // 2 Oct 2026

LocalDate d = LocalDate.parse("25/12/2026",
    DateTimeFormatter.ofPattern("dd/MM/yyyy"));          // 2026-12-25

static final DateTimeFormatter LOG =
    DateTimeFormatter.ofPattern("yyyy-MM-dd'T'HH:mm:ss.SSS");

Notes

'T' — literal text in single quotes
Locale controls names: Friday vs vendredi
Reusing a static final formatter avoids rebuilding it

⚠ Common Mistakes

  • YYYY instead of yyyy — wrong year around New Year
  • mm for month (it's minutes) or hh without a
  • Parsing a LocalDate with a pattern that includes time fields

✓ Tips & Best Practices

  • Keep formatters as static final constants
  • Exchange data in ISO-8601; format for humans only at the UI
  • Use ofLocalizedDate to respect the user's locale automatically
