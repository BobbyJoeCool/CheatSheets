Passing Data In

Parameters are the variables in a method declaration; arguments are the values you pass when calling it. Java is always pass-by-value. For primitives, the method gets a copy of the number. For objects, it gets a copy of the reference, so it can modify the object's contents but cannot make the caller's variable point to a new object.

Notes

  • Arguments must match parameter count, order, and types
  • Java has no named or default parameters; use overloading or builders
  • Mark parameters final to prevent reassignment
  • Strings are immutable, so methods can't change a caller's String

Pass-by-Value in Action

static void bump(int n) { n++; }
int x = 5;
bump(x);
System.out.println(x);            // 5  (copy was changed)

static void addItem(List<String> list) { list.add("new"); }
List<String> items = new ArrayList<>();
addItem(items);
System.out.println(items);        // [new]  (same object)

static void replace(List<String> list) {
    list = new ArrayList<>();     // reassigns the local copy only
    list.add("lost");
}
replace(items);
System.out.println(items);        // [new]  (caller unaffected)

static void rename(String s) { s = s.toUpperCase(); }
String name = "ada";
rename(name);                     // name is still "ada"

Notes

bump changes its own copy of 5
addItem follows the reference to the shared list
replace points its copy elsewhere; the caller still sees the original
Return a value instead of trying to modify primitives

⚠ Common Mistakes

  • Expecting a method to swap two int variables — it can't; return the values instead
  • Surprising callers by mutating a list they passed in
  • Long parameter lists of the same type (int, int, int) that are easy to pass in the wrong order

✓ Tips & Best Practices

  • Copy defensively when storing caller-provided collections: List.copyOf(list)
  • Keep parameter lists under ~4; group the rest into an object or record
  • Validate arguments at the top with Objects.requireNonNull

Quick Summary

  • Always pass-by-value
  • Primitives: copy of the value
  • Objects: copy of the reference
  • No named/default params
