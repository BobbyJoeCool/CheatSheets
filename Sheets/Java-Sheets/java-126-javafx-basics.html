Modern Java Desktop UIs

JavaFX is Java's modern GUI toolkit, maintained as the open-source OpenJFX project and added as a dependency (it's no longer bundled with the JDK). An app extends Application and builds its UI in start(Stage). The Stage is the window, the Scene holds the content, and the content is a tree of nodes called the scene graph.

Notes

  • Artifacts: org.openjfx:javafx-controls (+ javafx-fxml)
  • Use the javafx-maven-plugin or org.openjfx.javafxplugin for Gradle
  • UI updates must happen on the JavaFX Application Thread
  • From other threads, use Platform.runLater(...)

Hello JavaFX

import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class HelloFx extends Application {
    @Override
    public void start(Stage stage) {
        Label label = new Label("Hello, JavaFX!");
        Button btn = new Button("Click");
        btn.setOnAction(e -> label.setText("Clicked"));

        VBox root = new VBox(10, label, btn);     // spacing 10
        Scene scene = new Scene(root, 320, 200);  // width, height

        stage.setTitle("Hello"); stage.setScene(scene);
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}

Notes

launch starts the toolkit and calls start on the FX thread
VBox(10, …) stacks children with 10 px spacing
One Stage can switch between several Scenes

⚠ Common Mistakes

  • Running a JavaFX app on a plain JDK without the OpenJFX dependency → "JavaFX runtime components are missing"
  • Updating controls from a background thread → IllegalStateException
  • Doing slow work inside start, delaying the first window

✓ Tips & Best Practices

  • Use Task / Service for background work (Sheet 129)
  • Package with jlink/jpackage to ship a native installer
  • Prefer FXML + controllers for larger screens (Sheets 131–132)
