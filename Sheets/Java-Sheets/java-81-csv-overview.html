Working With CSV

CSV (comma-separated values) stores tables as plain text, one row per line. Simple files can be handled with split(","), but real CSV allows quoted fields containing commas, quotes, and even line breaks, which naive splitting gets wrong. For anything user-supplied, use a library such as OpenCSV (Sheet 111).

Notes

  • RFC 4180 defines the common CSV rules
  • A quote inside a quoted field is doubled: ""
  • Excel may use ; as the delimiter in some locales
  • Watch for a UTF-8 BOM at the start of Excel exports

Manual Parsing (Simple Files Only)

record Product(String name, double price, int qty) { }

List<Product> products;
try (Stream<String> lines = Files.lines(Path.of("products.csv"))) {
    products = lines.skip(1)                         // header row
        .filter(l -> !l.isBlank())
        .map(l -> l.split(",", -1))                  // keep empty fields
        .map(f -> new Product(f[0].strip(),
                              Double.parseDouble(f[1]),
                              Integer.parseInt(f[2])))
        .toList();
}

List<String> out = new ArrayList<>();
out.add("name,price,qty");
for (Product p : products)
    out.add(String.join(",", p.name(), String.valueOf(p.price()),
                        String.valueOf(p.qty())));
Files.write(Path.of("copy.csv"), out);

"\"Smith, Ada\",42".split(",");    // ✖ ["\"Smith", " Ada\"", "42"]

Notes

skip(1) drops the header
split(",", -1) keeps trailing empty columns
The last line shows why quoted commas break split

⚠ Common Mistakes

  • split(",") on data that contains quoted commas
  • Forgetting to skip or validate the header row
  • Writing fields without escaping commas and quotes, which produces broken files

✓ Tips & Best Practices

  • Use a library the moment quoting is possible
  • Write numbers with Locale.ROOT so decimals use .
  • Strip a leading BOM: line.replace("\uFEFF", "")

Quick Summary

  • Text tables, one row per line
  • Quotes allow commas in fields
  • split only for simple data
