Sheet 22

Ternary Operator

?: · conditional expression · nested ternary · type promotion · null default

Choosing a Value Inline

The conditional operator condition ? a : b evaluates to a when the condition is true and b otherwise. Unlike if, it is an expression, so it produces a value you can assign, return, or pass to a method. Use it for simple value choices, not for running statements.

Notes

  • Both branches must produce compatible types
  • Only the chosen branch is evaluated
  • Mixed numeric types are promoted: true ? 1 : 2.0 → 1.0
  • Mixing int and Integer can unbox null → NPE

Examples

int age = 20;
String status = age >= 18 ? "adult" : "minor";     // "adult"

int max = a > b ? a : b;                           // Math.max(a, b)
System.out.println(n == 1 ? "1 item" : n + " items");
return list.isEmpty() ? null : list.get(0);

String name = input != null ? input : "Guest";      // null default
String name2 = Objects.requireNonNullElse(input, "Guest");  // same

// Nested — readable only when formatted like a chain
String size = n < 10  ? "small"
            : n < 100 ? "medium"
            :           "large";

Object o = true ? 1 : "one";   // Integer 1 (common supertype)
Integer x = null;
int bad = flag ? x : 0;        // NPE if flag is true (unboxing)

Notes

Great inside println, return, and assignments
Chain-format nested ternaries, one condition per line
requireNonNullElse (Java 9+) replaces null-default ternaries

⚠ Common Mistakes

  • Using the ternary as a statement: x > 0 ? doA() : doB(); doesn't compile unless the value is used
  • Deeply nested ternaries on one line that no one can read
  • Surprise double results from true ? 1 : 2.0

✓ Tips & Best Practices

  • Keep each branch short; extract a method if it isn't
  • Parenthesize the condition when it contains operators
  • Prefer a switch expression for 3+ outcomes

Quick Summary

  • cond ? a : b — value expression
  • Only one branch is evaluated
  • Branch types must be compatible
  • Use for values, not actions
