Writing to the Console

System.out is a PrintStream connected to standard output. println prints and adds a newline, print does not, and printf formats values with format specifiers. System.err writes to standard error, which many IDEs show in red and which can be redirected separately.

Notes

  • println() with no argument prints a blank line
  • Any type can be printed; objects call toString()
  • %n in printf is the platform-correct newline
  • printf and String.format share the same specifier syntax

Output Variants

System.out.println("Hello");           // Hello⏎
System.out.print("A"); System.out.print("B");  // AB
System.out.println(42);                // 42
System.out.println(3.0 / 2);           // 1.5
System.out.println('A' + 1);           // 66   (char math → int)
System.out.println("A" + 1);           // A1   (string concat)
System.out.println(1 + 2 + "x");       // 3x   (left to right)
System.out.println("x" + 1 + 2);       // x12
System.out.printf("%s is %d%n", "Ada", 36);   // Ada is 36
System.out.printf("%.2f%n", Math.PI);          // 3.14
System.out.println("Tab\there");       // Tab     here
System.out.println("Quote: \"hi\"");    // Quote: "hi"
System.err.println("Error!");          // goes to stderr

Notes on the Example

+ with a String on either side means concatenation
char + int is arithmetic: 'A' is 65
%s any value, %d integer, %f decimal
.2f — two decimal places
System.err — unbuffered error stream

⚠ Common Mistakes

  • "Sum: " + 1 + 2 prints Sum: 12 — wrap math in parentheses: "Sum: " + (1 + 2)
  • Using \n in printf on Windows tools that expect \r\n — prefer %n
  • Passing an int to %f throws IllegalFormatConversionException

✓ Tips & Best Practices

  • Use printf for tables of numbers; width specifiers align columns
  • Send diagnostics to System.err so they don't mix with program output
  • For real apps, use a logger (Sheet 105) instead of println

Quick Summary

  • println — print + newline
  • print — no newline
  • printf — formatted output with % specifiers
  • System.err — error stream
