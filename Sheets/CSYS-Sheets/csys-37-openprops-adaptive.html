Adaptive Theming

/* 1. Import Open Props */
@import "open-props";
@import "open-props/normalize";

/* 2. Build semantic token layer */
:root {
  --color-bg:       var(--gray-0);
  --color-surface:  var(--gray-1);
  --color-text:     var(--gray-9);
  --color-muted:    var(--gray-6);
  --color-border:   var(--gray-3);
  --color-accent:   var(--indigo-6);
  --color-accent-2: var(--indigo-1);
}

/* 3. Dark mode — override semantic layer only */
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg:       var(--gray-9);
    --color-surface:  var(--gray-8);
    --color-text:     var(--gray-1);
    --color-muted:    var(--gray-5);
    --color-border:   var(--gray-7);
    --color-accent:   var(--indigo-4);
    --color-accent-2: var(--indigo-9);
  }
}

/* 4. Class-based dark mode (JS toggle) */
[data-theme="dark"] {
  --color-bg:       var(--gray-9);
  --color-surface:  var(--gray-8);
  --color-text:     var(--gray-1);
}

/* 5. Use semantic tokens everywhere */
body { background: var(--color-bg); color: var(--color-text); }

.card {
  background: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: var(--radius-2);
  padding: var(--size-4);
}

/* 6. Open Props built-in adaptive tokens */
body {
  background: var(--surface-1); /* Auto-adapts to dark mode */
  color: var(--text-1);         /* Auto-adapts */
}

/* 7. High-contrast support */
@media (prefers-contrast: more) {
  :root {
    --color-border: var(--gray-9);
    --color-text:   var(--gray-9);
  }
}

Adaptive Pattern

--surface-* / --text-* — Open Props built-in adaptive tokens; auto-flip in dark mode
Custom semantic layer isolates your code from specific palette values
prefers-color-scheme: dark — system dark mode preference
:root overrides only the semantic tokens — palette tokens remain unchanged
[data-theme="dark"] — class/attr toggle for JS-controlled dark mode
prefers-contrast: more — increases contrast for accessibility
Never reference palette tokens (--indigo-6) directly in components — go through semantic layer

⚠ Common Mistakes

  • Using both @import "open-props" and JIT plugin together — JIT replaces the import; using both injects props twice
  • Directly using palette tokens in components (var(--indigo-6)) — when you later need dark mode, you must find and update every usage
  • Forgetting to test with OS dark mode enabled — browser dark mode preview in DevTools doesn't always match real OS setting

✓ Tips

  • Test adaptive themes with prefers-color-scheme: dark in Chrome DevTools Rendering panel
  • Support both media query and class toggle — some users want manual override independent of OS setting
  • Use CSS color-scheme: light dark on :root — lets the browser adapt native UI controls (scrollbars, inputs) too

Summary

  • Semantic token layer — maps palette tokens to purpose; override only the layer for dark mode
  • --surface-* / --text-* — Open Props tokens that adapt automatically
  • prefers-color-scheme: dark — OS-level dark mode query
  • [data-theme="dark"] — JS-toggleable dark mode override
