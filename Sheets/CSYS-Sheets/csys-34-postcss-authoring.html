Writing a PostCSS Plugin

// my-plugin.js
const postcss = require('postcss')

// Plugin factory — returns an object with postcssPlugin + Once/Declaration/Rule
const myPlugin = postcss.plugin('my-plugin', (opts = {}) => {
  const { prefix = '' } = opts

  return (root, result) => {
    // Walk all declarations
    root.walkDecls('color', decl => {
      // decl.prop === 'color'
      // decl.value === '#fff'
      if (decl.value === 'red') {
        decl.value = 'var(--color-danger, #ef4444)'
      }
    })

    // Walk rules (selectors)
    root.walkRules(rule => {
      rule.selector = rule.selector.replace(
        /\.btn/g,
        `.${prefix}btn`
      )
    })

    // Walk @at-rules
    root.walkAtRules('custom-mixin', atRule => {
      const mixinName = atRule.params  // @custom-mixin flex-center → 'flex-center'
      atRule.replaceWith(
        postcss.decl({ prop: 'display', value: 'flex' }),
        postcss.decl({ prop: 'align-items', value: 'center' }),
        postcss.decl({ prop: 'justify-content', value: 'center' }),
      )
    })

    // Append a new rule to the stylesheet
    root.append(postcss.rule({
      selector: ':root',
      nodes: [postcss.decl({ prop: '--plugin-loaded', value: '1' })]
    }))
  }
})

// Modern API (PostCSS 8+)
module.exports = {
  postcssPlugin: 'my-plugin',
  Declaration: { color: decl => { /* handle color decls */ } },
  AtRule: { 'custom-mixin': atRule => { /* handle mixin */ } },
}

Plugin API Explained

root — the root CSS AST node (entire stylesheet)
result — PostCSS Result; use result.warn() for warnings
root.walkDecls(prop, fn) — visit every declaration; filter by property name
root.walkRules(fn) — visit every rule (selector block)
root.walkAtRules(name, fn) — visit specific @-rules
decl.prop — CSS property name string
decl.value — CSS value string; modify to transform
atRule.replaceWith(...nodes) — replace @-rule with new nodes
postcss.decl() — factory to create a Declaration node
postcss.rule() — factory to create a Rule node

⚠ Common Mistakes

  • Mutating decl.prop while walking — some walkers use the original prop for filtering; modify after the condition check
  • Not returning from plugin factory — the factory must return a function (or for PostCSS 8, the object with handlers)
  • Forgetting async support — if your plugin does async work, return a Promise or use async/await in the handler

✓ Tips

  • Use postcss-plugin-boilerplate or the official PostCSS plugin template to get testing set up
  • Use node.source.start.line and .column for error messages with accurate source positions
  • Test plugins with postcss([myPlugin]).process(css).css — simple unit testing without a bundler

Summary

  • root.walkDecls(prop, fn) — visit and transform CSS declarations
  • root.walkAtRules(name, fn) — intercept and replace custom @-rules
  • decl.replaceWith() / atRule.replaceWith() — swap nodes in the AST
  • postcss.decl() / postcss.rule() — factory methods to create new nodes
