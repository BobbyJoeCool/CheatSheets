Sheet 14

Bulma — Setup & Columns

columns · column · is-* sizes · is-offset-* · is-multiline · CDN

What Is Bulma?

Bulma is a modern CSS-only framework based on Flexbox. It ships zero JavaScript — all interactivity requires your own JS or a companion library. It uses a simple, readable class naming convention with is-* modifiers and has-* helpers. The column system uses fractional widths (is-half, is-one-third) rather than a numbered 12-column grid. Bulma is fully customizable via Sass variables.

Setup & Facts

  • CDN: cdn.jsdelivr.net/npm/bulma@0.9.4/css/bulma.min.css
  • npm: npm install bulma then import Sass partials
  • Zero JavaScript — you provide your own interaction logic
  • Column system: columns container + column children
  • Responsive: mobile-first with -mobile -tablet -desktop suffixes
  • Current version: Bulma 0.9.x (v1.0 released with CSS variables)

Column Explained

columns — flex container (the row)
column — auto-width flex child
is-{n} — numeric size 1–12 (of 12)
is-half — 50% width
is-one-third — 33.33%
is-two-thirds — 66.67%
is-one-quarter — 25%
is-three-quarters — 75%
is-offset-{n} — push right by n columns
is-multiline — on columns: allows wrapping to next row
is-gapless — on columns: removes gaps between columns
is-variable is-{n} — custom gap size

Column System

<!-- CDN -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bulma@0.9.4/css/bulma.min.css">

<!-- Basic columns (auto-equal widths) -->
<div class="columns">
  <div class="column">First</div>
  <div class="column">Second</div>
  <div class="column">Third</div>
</div>

<!-- Sized columns -->
<div class="columns">
  <div class="column is-two-thirds">Main</div>
  <div class="column">Sidebar</div>
</div>

<!-- Numeric sizes (12-column) -->
<div class="columns">
  <div class="column is-8">8 columns</div>
  <div class="column is-4">4 columns</div>
</div>

<!-- Offset -->
<div class="columns">
  <div class="column is-6 is-offset-3">Centered</div>
</div>

<!-- Multiline wrapping -->
<div class="columns is-multiline">
  <div class="column is-4">Card</div>
  <div class="column is-4">Card</div>
  <div class="column is-4">Card</div>
  <div class="column is-4">Wraps here</div>
</div>

⚠ Common Mistakes

  • Columns not stacking on mobile — add is-mobile to columns to keep them side-by-side, or omit it to stack by default
  • Forgetting is-multiline when column total exceeds 12 — extra columns are hidden without it
  • Bulma has no JS — interactive components like modals need is-active class toggled via your JS

✓ Tips

  • Use is-{size}-tablet for responsive column widths: is-half-tablet is-full-mobile
  • is-narrow on a column makes it only as wide as its content
  • Bulma's column system auto-equalizes — no width classes needed for equal-width layouts

Summary

  • columns > column — two-layer system (no separate row needed)
  • is-{n} or is-half/one-third — fractional or numeric widths
  • is-multiline — required for wrapping card grids
  • is-{size}-{breakpoint} — responsive column sizing
