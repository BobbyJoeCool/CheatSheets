Typography & Color Examples

<!-- Type scale -->
<p class="text-xs">12px</p>    <!-- text-sm=14 text-base=16 -->
<h1 class="text-4xl font-bold tracking-tight">Heading</h1>
<p class="text-lg leading-relaxed">Body text</p>

<!-- Font weight / style -->
<span class="font-thin">100</span>
<span class="font-semibold">600</span>
<span class="font-black italic">900 italic</span>

<!-- Text color with opacity -->
<p class="text-slate-700">Slate 700</p>
<p class="text-blue-600 dark:text-blue-400">Adaptive</p>
<p class="text-black/50">50% opacity black</p>

<!-- Background color -->
<div class="bg-indigo-500">Solid</div>
<div class="bg-gradient-to-r from-purple-500 to-pink-500">Gradient</div>
<div class="bg-white/80 backdrop-blur-sm">Frosted glass</div>

<!-- Text alignment / decoration / transform -->
<p class="text-center truncate uppercase">Truncated</p>
<a class="underline decoration-dotted">Dotted</a>

Class Explained

text-{size} — font-size + matching line-height pair
font-{weight} — thin(100) to black(900)
tracking-tight — negative letter-spacing (−0.025em)
leading-relaxed — line-height: 1.625
text-slate-700 — named palette + shade (50–950)
text-blue-600/75 — color at 75% opacity (v3 syntax)
text-black/50 — shorthand opacity modifier
bg-gradient-to-r — gradient direction right
from-* / to-* — gradient stop colors
backdrop-blur-sm — blur background behind element
truncate — overflow hidden + ellipsis
uppercase — text-transform: uppercase

⚠ Common Mistakes

  • Using text-opacity-50 (old API) — v3 uses slash syntax: text-black/50
  • Setting text-{color} without a shade — text-blue alone does nothing; always add shade: text-blue-500
  • Gradient requires all three: bg-gradient-to-r from-X to-Y — missing from- or to- renders transparent

✓ Tips

  • Use via-{color} between from- and to- for three-stop gradients
  • Add @tailwindcss/typography plugin for prose class — styles rich HTML content automatically
  • Arbitrary colors: text-[#5c6bc0] or bg-[hsl(230,40%,55%)]

Summary

  • text-{size} — sets font-size with paired default line-height
  • text-{palette}-{shade} — named color at specific lightness
  • color/opacity — slash syntax for color opacity modifiers
  • bg-gradient-to-{dir} from-X to-Y — CSS gradient shorthand
