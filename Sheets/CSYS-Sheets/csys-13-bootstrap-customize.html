Sass Customization

// Custom Bootstrap setup — src/styles/main.scss

// 1. Override variables BEFORE importing Bootstrap
$primary: #6366f1;
$secondary: #64748b;
$font-family-base: 'Inter', system-ui, sans-serif;
$border-radius: 0.5rem;
$grid-columns: 12;
$grid-gutter-width: 1.5rem;
$spacer: 1rem;

// Custom color map merge
$custom-colors: (
  "brand": #10b981,
  "surface": #f8fafc,
);
$theme-colors: map-merge($theme-colors, $custom-colors);

// 2. Import Bootstrap source
@import "bootstrap/scss/bootstrap";

// 3. Add component overrides after
.btn {
  font-weight: 600;
  letter-spacing: 0.025em;
}

// Dark mode (Bootstrap 5.3+)
[data-bs-theme="dark"] {
  --bs-body-bg: #0f172a;
  --bs-body-color: #e2e8f0;
}

// CSS variables override (no Sass rebuild needed)
:root {
  --bs-primary: #6366f1;
  --bs-primary-rgb: 99, 102, 241;
}

Explained

$primary — overrides the primary color; must be set BEFORE importing Bootstrap
$theme-colors — map of color name → hex; extend with map-merge
map-merge($theme-colors, $custom) — adds custom colors without removing defaults
$spacer — base unit for spacing scale (default 1rem)
$border-radius — base border-radius for components
@import "bootstrap/scss/bootstrap" — imports entire framework after overrides
data-bs-theme="dark" — Bootstrap 5.3 color mode attribute
--bs-primary-rgb — CSS var needed for opacity utilities to work

⚠ Common Mistakes

  • Setting Sass variables AFTER @import "bootstrap" — they have no effect; variables must precede the import
  • Overriding --bs-primary CSS var only — opacity utilities still use --bs-primary-rgb; update both
  • Using map-set instead of map-merge — Bootstrap uses map-merge for adding to theme maps

✓ Tips

  • Import only needed partials for smaller bundles: functions → variables → maps → mixins → your components
  • Use Bootstrap's Utility API ($utilities map) to add/remove utility classes in Sass
  • Bootstrap 5.3 dark mode: add data-bs-theme="dark" to <html> or any container

Summary

  • $primary: #hex BEFORE @import bootstrap — override sequence is critical
  • map-merge($theme-colors, $custom) — extend color map without replacing
  • --bs-* CSS vars — runtime overrides without Sass rebuild
  • data-bs-theme="dark" — Bootstrap 5.3 color mode toggle
