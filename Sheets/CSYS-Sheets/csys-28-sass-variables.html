$var · !default · maps · lists · colors · strings · numbers · booleans

Variables & Data Types

// ── Numbers ──────────────────────────────────────────────
$size: 1rem;
$count: 3;
$ratio: 1.618;
$percent: 75%;

// ── Strings ──────────────────────────────────────────────
$family: 'Inter', sans-serif;    // quoted
$selector: button;               // unquoted

// ── Colors ───────────────────────────────────────────────
$primary: #6366f1;
$primary: hsl(239, 84%, 67%);
$primary: rgb(99, 102, 241);

// ── Booleans / Null ──────────────────────────────────────
$enable-shadows: true;
$empty: null;                    // omits property if used

// ── Lists ─────────────────────────────────────────────────
$margins: 10px 20px 30px;       // space-separated
$fonts: ('Inter', 'Roboto');    // comma-separated

@use 'sass:list';
$first: list.nth($margins, 1);   // 10px
$len:   list.length($fonts);     // 2

// ── Maps ─────────────────────────────────────────────────
@use 'sass:map';

$colors: (
  'primary': #6366f1,
  'secondary': #64748b,
  'success': #10b981,
);

$primary: map.get($colors, 'primary');    // #6366f1
$updated: map.set($colors, 'danger', #ef4444);
$merged:  map.merge($colors, ('info': #0ea5e9));

// Iterate map
@each $name, $value in $colors {
  .bg-#{$name} { background-color: $value; }
}

// !default — set only if not already defined
$grid-cols: 12 !default;   // won't override if $grid-cols already set

Explained

$variable: value — lexically scoped Sass variable
!default — sets value only if variable is undefined or null; used in library partials
null — when used as a property value, the property is omitted entirely
list.nth($list, 1) — 1-indexed list access
map.get($map, 'key') — retrieve a value from a map
map.merge($a, $b) — shallow merge two maps
@each $k, $v in $map — iterate map key-value pairs
.bg-#{$name} — interpolate variable into class name

⚠ Common Mistakes

  • Using Sass variables for runtime theming — Sass variables are compile-time; CSS custom properties are needed for JavaScript-toggled themes
  • Forgetting 1-based indexing on lists — list.nth($list, 1) is the first item, not index 0
  • Accessing map keys without quotes — map.get($m, primary) vs map.get($m, 'primary') — unquoted keys are treated as Sass values

✓ Tips

  • Use maps for design token systems — store color shades as a nested map for programmatic access
  • Use !default in all library/shared files — lets consumers override tokens without editing source
  • Generate utility classes from maps with @each — one map drives dozens of generated classes

Summary

  • $var: value — compile-time variable; lexically scoped
  • !default — set only if not already defined (library pattern)
  • ('key': value) — Sass map; access with map.get()
  • @each $k, $v in $map — iterate map to generate utility classes
