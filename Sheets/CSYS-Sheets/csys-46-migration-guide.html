Migration Strategies

Migrating between CSS systems works best as an incremental strangler-fig: the new system grows alongside the old one, replacing it component by component. CSS @layer enables clean coexistence by giving you explicit control over which system wins specificity battles during the transition period. Never do a big-bang rewrite.

Migration Principles

  • Migrate incrementally, one component at a time
  • Use @layer to control specificity between old and new
  • Delete old code immediately as each component migrates
  • Agree on a feature freeze for the old system before starting
  • Add visual regression tests before migrating each component

Migration Checklist

StepAction
1Audit current CSS: size, specificity, dead code
2Define target system and coexistence strategy
3Set up new system alongside old (no deletions yet)
4Migrate highest-traffic components first
5Add visual regression tests before/after each
6Delete old code immediately as components migrate
7Remove old system package when fully migrated
8Update linting rules to enforce new system only

⚠ Common Mistakes

  • Big-bang rewrite — specificity conflicts between old and new break layouts unpredictably without coexistence strategy
  • Migrating utilities first instead of layout components — layout impact validates the new system fastest
  • Keeping old code "just in case" — migration debt compounds; both systems require maintenance as they slowly drift

✓ Tips

  • Use CSS @layer to give migrated components predictable specificity during coexistence period
  • Migrate components with dedicated QA owners first — faster feedback loop on visual regressions
  • Track migration progress as a percentage of components done — shared visibility accelerates the work

Summary

  • Incremental strangler-fig — new system grows alongside old
  • CSS @layer — controls specificity between legacy and new during coexistence
  • Delete old code immediately — migration debt compounds if orphaned
  • Visual regression test every component before and after migration
