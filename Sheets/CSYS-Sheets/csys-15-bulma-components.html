Components

<!-- Buttons -->
<button class="button is-primary is-large">Primary</button>
<button class="button is-outlined is-danger is-rounded">Outlined</button>
<button class="button is-loading">Loading...</button>

<!-- Card -->
<div class="card">
  <div class="card-image"><figure class="image"><img src="..."></figure></div>
  <div class="card-content">
    <p class="title">Card Title</p>
    <p class="content">Content goes here.</p>
  </div>
  <footer class="card-footer">
    <a class="card-footer-item">Save</a>
  </footer>
</div>

<!-- Notification (alert) -->
<div class="notification is-warning">
  <button class="delete"></button>
  Watch out for this!
</div>

<!-- Hero -->
<section class="hero is-primary is-medium">
  <div class="hero-body">
    <p class="title">Hero title</p>
    <p class="subtitle">Subtitle</p>
  </div>
</section>

<!-- Tags -->
<span class="tag is-info is-medium">New</span>
<span class="tag is-success"><span class="icon">✓</span></span>

Notes

is-primary/info/success/warning/danger — color variants on most components
is-small/medium/large — size variants
is-outlined — transparent background, colored border
is-rounded — full pill border-radius
is-loading — spinner replaces button content
card-image > figure — image at top of card
delete — × button for dismissing notifications/modals (no JS built-in)
hero is-{size} — small medium large fullheight
hero-body — centered content inside hero
tag — inline label; wrap in tags for groups

⚠ Common Mistakes

  • Modal visible without is-active class — Bulma modals rely entirely on this class being toggled by your JS
  • Notification dismiss button does nothing — the .delete button requires JS to add display:none to the parent
  • Navbar hamburger not working — you must write the JS to toggle is-active on both the burger and the menu

✓ Tips

  • Use level component for horizontal alignment of mixed elements (text + buttons)
  • section + container is Bulma's standard page section pattern
  • Use media component for comment/avatar layouts — left icon + flexible right content

Summary

  • is-{color} — color modifier works on most components
  • is-active — toggled via JS to show modals/dropdowns/menus
  • hero > hero-body — full-width banner section
  • notification + delete — dismissible alert (JS handles hide)
