Sass/SCSS — Setup & Syntax

sass · scss · dart sass · .scss vs .sass · CLI · npm · watch

What Is Sass?

Sass (Syntactically Awesome Style Sheets) is the most widely used CSS preprocessor, adding variables, nesting, mixins, functions, and modules to CSS. The modern implementation is Dart Sass — the reference implementation, actively maintained. Sass has two syntaxes: SCSS (superset of CSS, uses braces) and the indented .sass syntax (uses indentation, no braces). SCSS is overwhelmingly preferred in modern projects.

Key Facts

  • Dart Sass is the current standard; LibSass and Ruby Sass are deprecated
  • .scss — superset of CSS; valid CSS is valid SCSS
  • .sass — indented syntax; no braces or semicolons
  • Install: npm install -D sass
  • Vite, webpack (sass-loader), and Parcel support Sass natively
  • New module system (@use/@forward) replaced @import in Dart Sass

Syntax Explained

$variable — Sass variable; replaced at compile time
& — parent selector reference; combines with parent class
&:hover — generates .card:hover
&--modifier — generates .card--modifier (BEM pattern)
#{$var} — interpolation; inserts variable into selector/property
@use 'sass:math' — import a Sass built-in module
color.adjust() — programmatically modify a color
math.div(a, b) — division (replaces deprecated a / b)

Setup & Core Syntax

// Install and compile
// npm install -D sass
// npx sass src/main.scss dist/main.css --watch

// Variables (Sass) vs CSS custom properties
$primary: #6366f1;          // Sass variable — compile-time
$font-stack: 'Inter', sans-serif;
$spacing-unit: 1rem;

// CSS custom properties — runtime
:root { --primary: #6366f1; }

// Nesting
.card {
  background: white;
  border-radius: 8px;

  &:hover { box-shadow: 0 4px 20px rgba(0,0,0,.1); }
  &--featured { border: 2px solid $primary; }   // BEM modifier

  .card__title {       // descendent
    font-size: 1.25rem;
    color: $primary;
  }
}

// Parent selector reference
.btn {
  &-primary { background: $primary; }
  &-secondary { background: #64748b; }
  &:focus-visible { outline: 2px solid $primary; }
}

// Interpolation
$side: top;
.box { border-#{$side}: 1px solid red; }  // border-top

// @use — new module system
@use 'sass:math';
@use 'sass:color';
$lighter: color.adjust($primary, $lightness: 20%);
$half: math.div(100%, 2);   // 50%

⚠ Common Mistakes

  • Still using @import — it is deprecated in Dart Sass; use @use and @forward instead
  • Using / for division — deprecated; use math.div(a, b) or calc(a / b)
  • Installing node-sass — it wraps LibSass (deprecated); install sass (Dart Sass) instead

✓ Tips

  • Use sass:color functions instead of CSS filter tricks for programmatic color manipulation
  • Use --load-path to avoid long relative import paths: @use 'tokens' instead of @use '../../../tokens'
  • Vite uses Sass automatically when it detects .scss — no extra plugin needed, just npm install -D sass

Summary

  • $variable — compile-time variable replaced in output CSS
  • & — parent selector; enables nesting and BEM patterns
  • @use 'sass:color' — import built-in module for color functions
  • math.div() — safe division (replaces deprecated / operator)
