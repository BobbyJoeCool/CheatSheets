⚠ Common Mistakes

  • Creating styled-components inside a render function — a new class every render
  • Global selectors leaking out of a CSS Module without :global intent
  • Still using Sass @import, which is deprecated and slated for removal

✓ Tips & Best Practices

  • Use transient $props so styling props don't reach the DOM
  • Order PostCSS plugins: import → nesting / preset-env → autoprefixer → cssnano
  • Map ITCSS layers to CSS @layer for predictable cascade order

Quick Summary

  • CSS-in-JS: styles as components; Modules: scoped files
  • Sass: $vars, nesting, @mixin, @use
  • PostCSS: plugins transform standard CSS
  • ITCSS: specificity rises layer by layer
