Sass/SCSS — Mixins & Functions

@mixin · @include · @function · @return · @content · @if · @each · @for

Mixins & Functions

// ── Mixins — output CSS declarations ─────────────────────
@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

@mixin truncate($width: 100%) {
  width: $width;
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

@mixin respond-to($bp) {
  $breakpoints: ('sm': 640px, 'md': 768px, 'lg': 1024px);
  @media (min-width: map.get($breakpoints, $bp)) { @content; }
}

.card { @include flex-center; }
.title { @include truncate(200px); }

.hero {
  font-size: 3rem;
  @include respond-to('md') { font-size: 2rem; }
}

// ── Functions — return a value ────────────────────────────
@use 'sass:math';

@function rem($px, $base: 16) {
  @return math.div($px, $base) * 1rem;
}

@function clamp-size($min, $max, $vw: 100vw) {
  @return clamp(#{$min}, calc(#{$vw} * 0.05), #{$max});
}

$h1: rem(48);    // 3rem
$body: rem(16);  // 1rem

// ── Control flow ─────────────────────────────────────────
@mixin theme-colors($dark: false) {
  @if $dark {
    background: #0f172a; color: #f1f5f9;
  } @else {
    background: #ffffff; color: #0f172a;
  }
}

@for $i from 1 through 12 {
  .col-#{$i} { width: math.div(100%, 12) * $i; }
}

$sizes: (sm: 0.875rem, md: 1rem, lg: 1.25rem);
@each $name, $size in $sizes {
  .text-#{$name} { font-size: $size; }
}

Explained

@mixin name($arg: default) — define a reusable CSS block
@include name(args) — insert mixin output at call site
@content — slot for content block passed to mixin (like a yield)
@function name — returns a value; no CSS output
@return value — exits function and returns value
@if / @else if / @else — conditional logic
@for $i from 1 through 12 — inclusive loop (1 to 12)
@each $k, $v in $map — map iteration
1rem multiplication — multiply a unitless number by 1rem to get rem unit

⚠ Common Mistakes

  • Using a function where a mixin is needed — functions return values; they can't output CSS declarations directly
  • Forgetting @return in a function — without it the function returns null silently
  • Trying to output CSS from @function — any CSS inside a function is invalid; use @mixin instead

✓ Tips

  • Use keyword arguments for clarity: @include respond-to($bp: 'md')
  • Use @content in breakpoint mixins for cleaner component-level responsiveness
  • Use @error in mixins for invalid argument checks — better than silent failures

Summary

  • @mixin / @include — reusable CSS declaration blocks
  • @function / @return — compute and return a value
  • @content — slot inside mixin for caller-provided CSS block
  • @each $k, $v in $map — generate utility classes from token maps
