What Are Styled Components?

styled-components is a CSS-in-JS library for React that lets you write actual CSS inside JavaScript using tagged template literals. Each styled component is a React component with its styles baked in. Styles are scoped by default — no class name collisions. At runtime the library generates unique class names and injects a <style> tag. It supports theming, dynamic props, and server-side rendering.

Key Facts

  • Install: npm install styled-components
  • v6 is current — requires React 18+ or 16.8+
  • Babel plugin or SWC plugin recommended for SSR and display names
  • Styles are co-located with components — no separate CSS file
  • Supports all CSS including pseudo-classes, media queries, nesting
  • Runtime cost: styles injected at runtime (vs build-time CSS)

Explained

styled.button`…` — tagged template literal creates a React button component
styled.h1, styled.div etc — one factory per HTML element
&:hover — self-referencing nesting (like Sass &)
styled(Button)`…` — extends an existing styled or regular component
createGlobalStyle — injects global CSS (resets, fonts)
keyframes`…` — creates a scoped animation name
${"{fadeIn}"} — interpolates the keyframe into a property
css`…` — helper for reusable CSS blocks with interpolations

Basics

import styled, { css, createGlobalStyle, keyframes } from 'styled-components'

// Basic styled component
const Button = styled.button`
  background: #6366f1;
  color: white;
  padding: 0.5rem 1rem;
  border: none;
  border-radius: 6px;
  cursor: pointer;

  &:hover { background: #4f46e5; }
  &:disabled { opacity: 0.5; cursor: not-allowed; }
`

// Extending a component
const LargeButton = styled(Button)`
  font-size: 1.25rem;
  padding: 0.75rem 1.5rem;
`

// Any HTML element
const Title = styled.h1`
  font-size: 2rem;
  font-weight: 700;
  color: #0f172a;
`

// Global styles
const GlobalStyle = createGlobalStyle`
  *, *::before, *::after { box-sizing: border-box; }
  body { margin: 0; font-family: 'Inter', sans-serif; }
`

// Keyframe animation
const fadeIn = keyframes`
  from { opacity: 0; transform: translateY(-10px); }
  to   { opacity: 1; transform: translateY(0); }
`
const Animated = styled.div`
  animation: ${fadeIn} 0.3s ease-out;
`

// Usage
function App() {
  return (
    <>
      <GlobalStyle />
      <Title>Hello</Title>
      <Button>Click me</Button>
    </>
  )
}

⚠ Common Mistakes

  • Defining styled components inside render — recreates the component class on every render, breaking React reconciliation
  • Forgetting <GlobalStyle /> in the tree — it renders nothing visible but must be mounted to inject styles
  • Using styled.div(props => ...) object syntax without css helper — interpolations with props need the tagged template form

✓ Tips

  • Use the Babel plugin (babel-plugin-styled-components) for readable class names in dev and SSR support
  • Use .attrs() to set default HTML attributes: styled.input.attrs({ type: 'text' })
  • Use css helper when building reusable snippet functions that include interpolations

Summary

  • styled.div`css` — creates a React component with scoped styles
  • styled(Component)`css` — extends any styled or React component
  • createGlobalStyle — global CSS (resets, fonts, body styles)
  • keyframes`…` — scoped animation keyframe definition
