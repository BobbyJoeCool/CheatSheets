⚠ Common Mistakes

  • Treating palette tokens as semantic — --indigo-6 is not adaptive; create semantic tokens like --color-accent: var(--indigo-6)
  • Confusing --size-* (spacing) with --font-size-* (type) — both start at 1 but have different value ranges
  • Using gradient tokens in production without JIT — all 30 gradients are large SVG data URIs; JIT ensures only used ones are included

✓ Tips

  • Build a semantic token layer on top: :root { --color-brand: var(--indigo-6); } — insulates your code from Open Props version changes
  • Use --ease-elastic-* for button press animations — they create satisfying spring-like feedback
  • Use --size-fluid-* for heading font sizes — clamp-based so they resize fluidly without media queries

Summary

  • --size-{1-15} — spacing scale; 4 = 1rem
  • --font-size-{0-8} — type scale; 1 = 1rem
  • --shadow-{1-6} — elevation shadows; 2 = card elevation
  • --surface-* / --text-* — adaptive tokens that respond to dark mode
