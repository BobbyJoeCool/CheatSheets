Bootstrap — Utility Classes

d-* · flex-* · text-* · bg-* · p-* · m-* · gap-* · position-*

Utility Examples

<!-- Display -->
<div class="d-none d-md-block">Hidden on mobile</div>
<div class="d-flex d-md-none">Flex on mobile only</div>

<!-- Flex utilities -->
<div class="d-flex justify-content-between align-items-center gap-3">
  <span class="flex-grow-1">Grows</span>
  <span class="flex-shrink-0">Fixed</span>
</div>

<!-- Spacing: p-{n} m-{n}, 0-5 + auto -->
<div class="p-3 mb-4 mt-0 mx-auto">Spaced</div>
<div class="px-4 py-2">Axis-specific padding</div>

<!-- Text utilities -->
<p class="text-center text-md-start fw-bold fs-4">Heading</p>
<p class="text-truncate text-muted">Muted truncated text</p>

<!-- Colors / backgrounds -->
<div class="bg-primary text-white rounded p-3">Box</div>
<div class="bg-opacity-50 bg-danger">Transparent danger</div>

<!-- Position -->
<div class="position-relative">
  <span class="position-absolute top-0 end-0 badge">New</span>
</div>

<!-- Borders -->
<div class="border border-primary rounded-3 border-2">Bordered</div>

Utility Notes

d-{bp}-{value} — responsive display: none flex block inline grid etc.
justify-content-{val} — start center end between around evenly
align-items-{val} — start center end baseline stretch
gap-{n} — gap between flex/grid children (0–5)
p-{n} — padding all sides; px/py/pt/pb/ps/pe for axes
m-{n} — margin; mx-auto = horizontal centering
fw-bold / fw-semibold — font-weight utilities
fs-{1-6} — font-size matching heading scale
top-0 end-0 — absolute position helpers
bg-opacity-{n} — background opacity (10–75 + 100)

⚠ Common Mistakes

  • Using float-left/right — Bootstrap 5 uses float-start/float-end for RTL support
  • Spacing scale 0–5 is not in px or rem equal steps — 3 is 1rem, 4 is 1.5rem, 5 jumps to 3rem
  • Using ml-* mr-* — Bootstrap 5 uses logical properties: ms-* me-* (start/end)

✓ Tips

  • Use vstack / hstack as shorthand for vertical/horizontal flex stacks
  • overflow-hidden overflow-auto overflow-scroll — overflow utilities available in Bootstrap 5.1+
  • Use ratio ratio-16x9 wrapper for responsive embeds instead of padding hacks

Summary

  • d-{bp}-{value} — responsive display control
  • p-{n} m-{n} — spacing on 0–5 scale (not linear)
  • ms-* me-* — logical inline spacing (start/end)
  • position-absolute top-0 end-0 — position + placement utilities
