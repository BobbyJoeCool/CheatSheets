PostCSS — Essential Plugins

autoprefixer · postcss-preset-env · cssnano · postcss-import · stylelint · purgecss

Essential Plugin Usage

// postcss.config.js — full production pipeline
module.exports = {
  plugins: [
    // 1. Resolve @import first
    require('postcss-import'),

    // 2. Future CSS features
    require('postcss-preset-env')({
      stage: 2,
      features: {
        'nesting-rules': true,
        'custom-media-queries': true,
        'media-query-ranges': true,   // @media (width >= 768px)
        'color-function': true,       // color(display-p3 …)
      },
    }),

    // 3. Vendor prefixes
    require('autoprefixer'),

    // 4. PurgeCSS — remove unused CSS
    require('@fullhuman/postcss-purgecss')({
      content: ['./src/**/*.{html,js,jsx,ts,tsx,vue}'],
      defaultExtractor: content => content.match(/[\w-/:]+(?<![:])/g) || [],
      safelist: ['active', 'is-visible', /^modal/],
    }),

    // 5. Minify (production only)
    process.env.NODE_ENV === 'production' && require('cssnano')({
      preset: ['default', { discardComments: { removeAll: true } }],
    }),
  ].filter(Boolean),
}

// Stylelint — CSS linting (separate config or postcss plugin)
// .stylelintrc.json
{
  "extends": "stylelint-config-standard",
  "rules": {
    "color-no-invalid-hex": true,
    "declaration-block-no-duplicate-properties": true,
    "no-duplicate-selectors": true
  }
}

Plugin Notes

postcss-import — must run first; inlines all @import before other plugins process the CSS
postcss-preset-env stage: 2 — polyfills W3C proposals at stage 2+ (candidate)
nesting-rules: true — polyfills CSS nesting syntax for older browsers
media-query-ranges — enables @media (width >= 768px) syntax
autoprefixer — reads browserslist, adds needed vendor prefixes
purgecss content — files to scan for used class names
safelist — class names/patterns never purged regardless of scan
cssnano preset: 'default' — safe minification (no breaking transforms)
.filter(Boolean) — removes false entries from conditional plugins

⚠ Common Mistakes

  • Running PurgeCSS without a safelist — dynamically added classes (from JS) get purged; always safelist them
  • Using postcss-nested alongside postcss-preset-env nesting-rules — they conflict; use only one nesting plugin
  • No browserslist configured — autoprefixer falls back to defaults; explicit targets give predictable output

✓ Tips

  • Use npx browserslist to see which browsers your current config targets
  • Chain Sass → PostCSS: Sass compiles .scss first, then PostCSS processes the CSS output
  • Use cssnano preset: 'lite' for safer, less aggressive minification that avoids edge-case bugs

Summary

  • Plugin order: import → preset-env → autoprefixer → purgecss → cssnano
  • autoprefixer — reads browserslist to decide which prefixes to add
  • purgecss safelist — protect dynamic and third-party classes from removal
  • .filter(Boolean) — clean way to conditionally include plugins
