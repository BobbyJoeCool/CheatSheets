Flexbox & Grid Examples

<!-- Flex row, centered, gap -->
<div class="flex items-center justify-between gap-4">
  <span class="flex-1">Left</span>
  <span class="flex-none">Right</span>
</div>

<!-- Flex column, wrapping -->
<div class="flex flex-col flex-wrap gap-2">...</div>

<!-- Grid: 3 equal cols, 4 rows auto -->
<div class="grid grid-cols-3 gap-6">
  <div class="col-span-2">Wide cell</div>
  <div>Cell</div>
</div>

<!-- Responsive grid -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">
  ...
</div>

<!-- Sizing -->
<div class="w-full h-screen max-w-2xl mx-auto">...</div>
<div class="w-1/2 min-h-64 p-6 m-4">...</div>

<!-- Container with padding -->
<div class="container mx-auto px-4">...</div>

Class Explained

flex — display: flex
items-center — align-items: center
justify-between — justify-content: space-between
flex-1 — flex: 1 1 0% (grows to fill)
flex-none — flex: none (no grow/shrink)
grid-cols-3 — 3-column grid template
col-span-2 — cell spans 2 columns
gap-4 — gap: 1rem (4 × 0.25rem scale)
mx-auto — margin-left/right: auto
max-w-2xl — max-width: 42rem
h-screen — height: 100vh
container — centered, max-width per breakpoint

⚠ Common Mistakes

  • Using w-full on a flex child without understanding it interacts with flex sizing — combine with min-w-0 to avoid overflow
  • Forgetting min-h-0 on flex columns — flex children default min-height: auto, causing overflow in nested layouts
  • container alone does nothing — always pair with mx-auto and px-* for centered content

✓ Tips

  • Use gap-* on flex/grid parents instead of margin on children — avoids first/last child edge cases
  • Arbitrary values: w-[342px], grid-cols-[1fr_2fr] — use square brackets for one-off values
  • Use aspect-video / aspect-square for responsive ratio boxes without padding hacks

Summary

  • flex / grid — activate flex or grid layout on a container
  • gap-{n} — spacing between flex/grid children
  • p-{n} / m-{n} — padding/margin using 0.25rem scale
  • grid-cols-{n} — n equal columns; col-span-{n} to stretch cells
