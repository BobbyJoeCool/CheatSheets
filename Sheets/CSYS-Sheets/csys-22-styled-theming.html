ThemeProvider & Global Styles

import styled, { ThemeProvider, createGlobalStyle, useTheme } from 'styled-components'

// 1. Define theme object
const lightTheme = {
  colors: {
    primary: '#6366f1',
    background: '#ffffff',
    surface: '#f8fafc',
    text: '#0f172a',
    textMuted: '#64748b',
    border: '#e2e8f0',
  },
  space: { sm: '0.5rem', md: '1rem', lg: '1.5rem', xl: '2rem' },
  radius: { sm: '4px', md: '8px', lg: '16px', full: '9999px' },
  shadow: { sm: '0 1px 3px rgba(0,0,0,.1)', lg: '0 10px 40px rgba(0,0,0,.15)' },
}

const darkTheme = {
  ...lightTheme,
  colors: {
    ...lightTheme.colors,
    background: '#0f172a',
    surface: '#1e293b',
    text: '#f1f5f9',
    textMuted: '#94a3b8',
    border: '#334155',
  },
}

// 2. Global styles using theme
const GlobalStyle = createGlobalStyle`
  body {
    background: ${p => p.theme.colors.background};
    color: ${p => p.theme.colors.text};
    font-family: 'Inter', sans-serif;
    transition: background 0.2s, color 0.2s;
  }
`

// 3. Styled component consuming theme
const Card = styled.div`
  background: ${p => p.theme.colors.surface};
  border: 1px solid ${p => p.theme.colors.border};
  border-radius: ${p => p.theme.radius.md};
  padding: ${p => p.theme.space.lg};
  box-shadow: ${p => p.theme.shadow.sm};
`

// 4. useTheme hook in a regular component
function Logo() {
  const theme = useTheme()
  return <svg fill={theme.colors.primary}>...</svg>
}

// 5. Wrap app
function App() {
  const [dark, setDark] = React.useState(false)
  return (
    <ThemeProvider theme={dark ? darkTheme : lightTheme}>
      <GlobalStyle />
      <Card>Content</Card>
    </ThemeProvider>
  )
}

Theming Explained

ThemeProvider — context provider; makes theme available to all nested styled components
p.theme.colors.primary — access theme inside template literal via props
createGlobalStyle — also receives theme from ThemeProvider
useTheme() — hook to access theme inside a regular (non-styled) React component
...lightTheme — spread to inherit and override for dark theme
theme={"{dark ? darkTheme : lightTheme}"} — swap theme object for dark mode

⚠ Common Mistakes

  • Accessing theme without ThemeProvider — p.theme is an empty object; wrap the app in <ThemeProvider>
  • Calling useTheme() outside a ThemeProvider context — returns empty object and components won't style correctly
  • Recreating the theme object inside render — creates a new reference every render, causing all themed components to re-render

✓ Tips

  • Define theme as a module-level constant — never inline or inside a component
  • Use TypeScript module augmentation for full autocomplete on theme tokens
  • Layer ThemeProvider — an inner provider overrides the outer, enabling section-level theming

Summary

  • ThemeProvider theme={"{…}"} — passes theme to all nested styled components
  • p.theme.key — access theme tokens inside template literals
  • useTheme() — hook for theme access in regular components
  • createGlobalStyle — theme-aware global CSS injection
