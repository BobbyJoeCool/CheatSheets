Bootstrap — Forms & Validation

form-control · form-select · form-check · input-group · was-validated · is-invalid

Form Examples

<!-- Floating labels -->
<div class="form-floating mb-3">
  <input type="email" class="form-control" id="email" placeholder="Email">
  <label for="email">Email address</label>
</div>

<!-- Select -->
<select class="form-select">
  <option selected>Choose...</option>
  <option value="1">One</option>
</select>

<!-- Checkboxes / Radios -->
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="cb1">
  <label class="form-check-label" for="cb1">Check me</label>
</div>

<!-- Input group -->
<div class="input-group">
  <span class="input-group-text">@</span>
  <input type="text" class="form-control" placeholder="Username">
  <button class="btn btn-primary">Go</button>
</div>

<!-- Validation -->
<form class="was-validated">
  <input type="text" class="form-control" required>
  <div class="valid-feedback">Looks good!</div>
  <div class="invalid-feedback">Required field.</div>
</form>

<!-- Range / Switch -->
<input type="range" class="form-range">
<div class="form-check form-switch">
  <input class="form-check-input" type="checkbox" role="switch">
</div>

Form Notes

form-control — styles text inputs, textarea, file
form-floating — wrapper for floating label inputs
form-select — custom-styled select element
form-check — wrapper for checkbox/radio with label
form-check-input — styles the input itself
form-switch — toggle switch variant of checkbox
input-group — flex container for prepend/append
input-group-text — text addon beside input
was-validated — on form: shows valid/invalid states for all
is-invalid / is-valid — per-input validation state classes
invalid-feedback — shows error message below input

⚠ Common Mistakes

  • Forgetting for/id pairing on floating labels — they must match or the label won't animate
  • Using was-validated on page load — validation state shows immediately; only add after first submit attempt
  • Nesting input-group inside form-floating — they're incompatible without custom CSS

✓ Tips

  • Use novalidate on form + JS validation for full control; add was-validated class via JS on submit
  • form-control-color — styles color picker inputs to match Bootstrap sizing
  • Use row g-3 with col-* for multi-column form layouts aligned to the grid

Summary

  • form-control / form-select / form-check-input — core form element classes
  • form-floating — wrapper enabling floating label animation
  • input-group — flex container for prepend/append add-ons
  • was-validated / is-invalid — two approaches to showing validation state
