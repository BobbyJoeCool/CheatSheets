$primary · $link · has-text-* · is-primary · is-light · CSS custom properties

Bulma Theming (Sass)

// Override Bulma variables BEFORE importing
$primary: #6366f1;
$link: #3b82f6;
$success: #10b981;
$warning: #f59e0b;
$danger: #ef4444;

$family-sans-serif: 'Inter', sans-serif;
$radius: 8px;
$radius-large: 16px;

$navbar-height: 4rem;
$card-shadow: 0 4px 20px rgba(0, 0, 0, 0.1);

// Import Bulma after variables
@import "bulma/bulma";

// Bulma 1.0 CSS variables (no Sass needed)
:root {
  --bulma-primary-h: 231deg;
  --bulma-primary-s: 84%;
  --bulma-primary-l: 60%;
}

// Custom modifier classes following Bulma pattern
.is-shadowed { box-shadow: 0 8px 32px rgba(0,0,0,0.12); }
.has-radius-xl { border-radius: 1.5rem; }

Theming Notes

$primary — sets the primary color token; auto-derives dark/light variants
$link — color for anchor tags and link-styled buttons
$family-sans-serif — body font stack
$radius — base border-radius for components
$navbar-height — changes navbar size and has-navbar-fixed-top offset
--bulma-primary-h/s/l — v1.0 CSS variable system (HSL triplet)
is-* — modifier pattern; create custom with same pattern
has-* — helper modifier pattern for text/bg colors

⚠ Common Mistakes

  • Setting Sass variables after the Bulma @import — they must precede it to take effect
  • Mixing Bulma 0.9 and 1.0 approaches — 1.0 uses CSS HSL variables; 0.9 uses hex Sass variables
  • Using has-text-black for body text — use has-text-grey-darker for more readable dark text

✓ Tips

  • Import only the Bulma modules you need: @import "bulma/sass/utilities" etc.
  • Use $custom-colors map to add brand colors that automatically get is-brand class generated
  • Bulma's is-{color}-light modifier lightens the background — great for soft badges and alerts

Summary

  • $primary: #hex before @import "bulma" — override sequence
  • has-text-{color} — text color helper classes
  • has-background-{color} — background color helpers
  • is-{color}-light — soft tinted variant of a color
