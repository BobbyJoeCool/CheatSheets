Bootstrap — Setup & Grid

container · row · col-* · breakpoints · offset-* · order-* · gutter

What Is Bootstrap?

Bootstrap (v5) is the world's most popular CSS framework — a component-first library providing pre-styled UI elements, a 12-column grid, and utility classes. Unlike Tailwind, Bootstrap ships complete components (navbars, modals, cards) ready to use. It now requires no jQuery; JS components use Vanilla JS bundled as bootstrap.bundle.min.js. The grid uses flexbox and is mobile-first with six breakpoints.

Setup Options

  • CDN: link CSS + JS bundle in <head> and before </body>
  • npm: npm install bootstrap — import in JS or Sass
  • Current version: Bootstrap 5.3 with CSS variables and color modes
  • bootstrap.bundle.min.js includes Popper.js for dropdowns/tooltips
  • Sass source: customize variables before importing Bootstrap

Grid System

<!-- CDN -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3/dist/js/bootstrap.bundle.min.js"></script>

<!-- Basic 12-column grid -->
<div class="container">
  <div class="row">
    <div class="col-12 col-md-8">Main content</div>
    <div class="col-12 col-md-4">Sidebar</div>
  </div>
</div>

<!-- Auto-width columns -->
<div class="row">
  <div class="col">Equal</div>
  <div class="col">Equal</div>
  <div class="col-6">Double</div>
</div>

<!-- Offset, order, gutter -->
<div class="row g-4">
  <div class="col-md-4 offset-md-2 order-md-last">Shifted</div>
</div>

<!-- Fluid / responsive containers -->
<div class="container-fluid">Full width</div>
<div class="container-md">Fluid until md, then fixed</div>

Grid Explained

container — centered fixed-width; max-width per breakpoint
container-fluid — always 100% width
row — flex container with negative horizontal margins
col — equal-width auto column
col-{n} — fixed column count (1–12)
col-{bp}-{n} — column width at breakpoint and above
offset-{bp}-{n} — push column right by n columns
order-{n} — flex order (first, last, 0–5)
g-{n} — gutters (gap between columns)
gx-{n} / gy-{n} — horizontal / vertical gutter only

⚠ Common Mistakes

  • Putting content directly in .row without a .col — row uses negative margins that will break layout
  • Forgetting .row inside .container — the negative margin compensation only works inside a container
  • Using col-xs-* — Bootstrap 5 dropped the xs infix; unprefixed col-6 is the xs equivalent

✓ Tips

  • Use row-cols-{n} on the row instead of per-child col-* for uniform card grids
  • container-{bp} is fluid below that breakpoint and fixed above — great for full-bleed mobile designs
  • Set $grid-gutter-width in Sass to change default gutter globally

Summary

  • container > row > col — the three-layer grid hierarchy
  • col-{bp}-{n} — 12-column spans at specific breakpoints
  • offset-{bp}-{n} — push column right by n grid columns
  • g-{n} — gutter (gap) between grid columns
