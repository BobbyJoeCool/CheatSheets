CSS Modules — Composition & Values

composes: from · @value · CSS variables · Sass modules · TypeScript typings

Composition & @value

/* colors.module.css — shared design tokens */
@value primary: #6366f1;
@value primaryDark: #4f46e5;
@value success: #10b981;
@value danger: #ef4444;
@value sm: (max-width: 640px);
@value md: (min-width: 641px);

/* Button.module.css */
@value primary, primaryDark from './colors.module.css';

.base {
  padding: 0.5rem 1rem;
  border-radius: 6px;
  border: none;
  font-weight: 500;
  transition: background 0.15s;
}

/* Cross-file composition */
.primaryBtn {
  composes: base;
  composes: focusRing from './shared.module.css';
  background: primary;      /* @value used as CSS value */
  color: white;
}

.primaryBtn:hover {
  background: primaryDark;
}

/* Responsive via @value breakpoint */
@media sm {
  .primaryBtn { width: 100%; }
}

/* Using CSS custom properties alongside modules */
.card {
  composes: base from './shared.module.css';
  background: var(--surface);
  color: var(--text-primary);
  border: 1px solid var(--border);
}

/* Sass module (.module.scss) — full Sass works */
.button {
  @include focus-ring;       /* Sass mixin */
  $pad: 0.5rem;
  padding: $pad calc($pad * 2);
}

Explained

@value name: value — define a reusable value (color, breakpoint) in a CSS Module
@value name from './file' — import a value from another module
Imported @value can be used as a CSS value: background: primary
composes: base — inherits styles from a local class
composes: name from './other.module.css' — cross-file composition
The element gets multiple generated class names — one per composed class
.module.scss — Sass syntax fully supported; variables and mixins work
CSS custom properties (var(--token)) complement CSS Modules for runtime theming

⚠ Common Mistakes

  • composes must be first in the rule — placing it after other properties causes it to be ignored by some loaders
  • Composing from non-module CSS files — composes: from './global.css' only works if that file is also a CSS Module
  • Using @value for dynamic values — @value is a static build-time substitution; use CSS custom properties for runtime theming

✓ Tips

  • Combine CSS Modules with CSS custom properties — modules for scoped class names, vars for dynamic theming
  • Create a tokens.module.css with all @value declarations; import tokens across all feature modules
  • Use composes: from global to apply a third-party animation class without losing module scoping elsewhere

Summary

  • @value name: value — define reusable tokens in a CSS Module
  • @value x from './file' — import tokens across modules
  • composes: class from './file.module.css' — cross-file composition
  • CSS vars + CSS Modules — best of both: scoped classes + runtime theming
