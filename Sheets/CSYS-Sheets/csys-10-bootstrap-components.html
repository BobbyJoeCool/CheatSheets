Bootstrap — Core Components

btn · card · navbar · modal · alert · badge · dropdown · collapse

Component Examples

<!-- Buttons -->
<button class="btn btn-primary">Primary</button>
<button class="btn btn-outline-secondary btn-sm">Small Outline</button>
<button class="btn btn-danger btn-lg disabled">Disabled</button>

<!-- Card -->
<div class="card shadow">
  <img src="..." class="card-img-top" alt="...">
  <div class="card-body">
    <h5 class="card-title">Title</h5>
    <p class="card-text">Content</p>
    <a href="#" class="btn btn-primary">Go</a>
  </div>
</div>

<!-- Alert with dismiss -->
<div class="alert alert-warning alert-dismissible fade show">
  <strong>Warning!</strong> Message.
  <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
</div>

<!-- Badge / Spinner -->
<span class="badge bg-primary rounded-pill">99+</span>
<div class="spinner-border text-primary" role="status"></div>

<!-- Modal trigger -->
<button data-bs-toggle="modal" data-bs-target="#myModal">Open</button>
<div class="modal fade" id="myModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Title</h5>
        <button class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">Content</div>
      <div class="modal-footer">
        <button class="btn btn-secondary" data-bs-dismiss="modal">Close</button>
      </div>
    </div>
  </div>
</div>

Component Notes

btn btn-{variant} — variant: primary secondary success danger warning info light dark link
btn-outline-{variant} — transparent background, colored border
btn-sm / btn-lg — small or large button sizing
card-img-top — image at top of card, rounded-top
alert-dismissible fade show — animated dismissible alert
data-bs-dismiss="alert" — JS-powered dismiss via data attr
badge bg-{color} — inline label with background color
data-bs-toggle="modal" — triggers modal by target ID
modal-dialog-centered — vertically centers modal
modal-dialog-scrollable — scrollable body, fixed header/footer

⚠ Common Mistakes

  • Forgetting data-bs-toggle and data-bs-target — modal/dropdown won't work without both attributes
  • Missing fade show on alerts — dismissible animation requires both classes
  • Not initializing tooltips/popovers — they require new bootstrap.Tooltip(el) JS call; they don't auto-init

✓ Tips

  • Use modal-dialog-centered modal-lg together for a centered large modal
  • Programmatic modal: const m = new bootstrap.Modal('#myModal'); m.show()
  • Use list-group inside card for flush item lists without padding

Summary

  • btn btn-{variant} — pre-styled button with color variant
  • card > card-body > card-title/text — card structure
  • data-bs-toggle/target — JS component activation via HTML
  • alert alert-{variant} alert-dismissible fade show — dismissible alert
