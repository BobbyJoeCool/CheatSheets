Sass/SCSS — Module System

@use · @forward · @use with · namespace · private · index files · partials

@use & @forward

// ── File structure ───────────────────────────────────────
// tokens/_colors.scss
$primary: #6366f1 !default;
$secondary: #64748b !default;

// tokens/_spacing.scss
$base: 1rem !default;
$sm: $base * 0.5;
$lg: $base * 1.5;

// tokens/_index.scss — barrel file
@forward 'colors';
@forward 'spacing';
@forward 'mixins';

// ── @use — consume a module ──────────────────────────────
// Namespace access (default: filename)
@use 'tokens/colors';
.btn { background: colors.$primary; }

// Custom namespace
@use 'tokens/colors' as t;
.btn { background: t.$primary; }

// No namespace (use with caution)
@use 'tokens/colors' as *;
.btn { background: $primary; }

// ── @forward — re-export from barrel ────────────────────
// Selective forward with prefix
@forward 'colors' with ($primary: #4f46e5 !default);
@forward 'mixins' show flex-center, truncate;  // only these
@forward 'utils' hide -private-fn;             // hide private

// ── Private members ──────────────────────────────────────
$_internal-size: 14px;  // _ or - prefix = private (not @forward-able)

// ── @use with — override !default variables ──────────────
@use 'bootstrap/scss/bootstrap' with (
  $primary: #6366f1,
  $body-font-family: 'Inter',
  $grid-gutter-width: 1.5rem
);

Module System Explained

@use 'path' — imports a module; runs once per file regardless of how many times used
colors.$primary — namespace-qualified access to module member
@use 'path' as ns — custom namespace alias
@use 'path' as * — no namespace; names available directly (collision risk)
@forward 'path' — re-exports module members so they're accessible to consumers of this file
@forward with ($var: val !default) — configure !default variables on forward
show / hide — whitelist or blacklist members in a forward
$_private — underscore prefix makes member non-forwardable
@use 'lib' with ($var: val) — override !default vars at the @use site

@forward Options

SyntaxEffect

Recommended Structure

File / folderContents
tokens/_colors.scssColor variables
tokens/_spacing.scssSpacing scale
tokens/_index.scss@forward all tokens
mixins/_index.scss@forward all mixins
components/_card.scssCard component styles
main.scss@use everything, output CSS

⚠ Common Mistakes

  • Trying to use @use and @import in the same file — they conflict; migrate fully to @use/@forward
  • Forgetting @forward in index files — @use alone does not re-export; barrel files need @forward
  • Expecting variables to be globally available after @use — each file must @use the module it needs; there's no global state

✓ Tips

  • Create _index.scss barrel files in every folder — lets consumers @use 'tokens' instead of long paths
  • Use @forward 'file' as prefix-* to namespace tokens by category: color-primary, space-md
  • Audit any remaining @import usage — Dart Sass will remove support in a future version

Summary

  • @use 'path' — import module; access via filename.$var
  • @forward 'path' — re-export module members from a barrel file
  • @use 'lib' with ($var: val) — configure !default variables at import
  • $_private — underscore prefix prevents member from being forwarded
