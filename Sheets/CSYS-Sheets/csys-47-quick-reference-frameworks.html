⚠ Common Mistakes

  • Tailwind classes built by string concatenation — the scanner can't see them, so they're purged
  • Mixing Tailwind v3 config habits into a v4 project (@theme replaces most of the JS config)
  • Loading Bootstrap's JS twice, or forgetting bootstrap.bundle for dropdowns and popovers

✓ Tips & Best Practices

  • Keep full class names in source; map state to classes with an object
  • Customize Bootstrap with Sass variables before @import, not overrides after
  • Pick one framework per project — mixing grids causes specificity fights

Quick Summary

  • Tailwind / UnoCSS: utilities composed in markup
  • Bootstrap / Bulma / Foundation: components + grid classes
  • All are mobile-first with breakpoint prefixes
  • Theme via CSS variables or Sass settings
