What Is Foundation?

Foundation for Sites (v6) by Zurb is a professional-grade responsive framework with a powerful XY Grid system based on CSS Grid and Flexbox. It offers a rich component set including accessible modals, sticky elements, off-canvas navigation, and motion-ui animations. Foundation is highly customizable via Sass and is used heavily in enterprise and agency projects.

Setup Facts

  • CDN: cdn.jsdelivr.net/npm/foundation-sites@6.8/dist/css/foundation.min.css
  • npm: npm install foundation-sites
  • XY Grid (v6.4+) replaces the old float-based grid
  • Breakpoints: small (0), medium (640px), large (1024px), xlarge (1200px), xxlarge (1440px)
  • Requires jQuery + Foundation JS for interactive components

XY Grid

<!-- Basic XY Grid -->
<div class="grid-container">
  <div class="grid-x grid-margin-x">
    <div class="cell small-12 medium-8">Main</div>
    <div class="cell small-12 medium-4">Sidebar</div>
  </div>
</div>

<!-- Auto cells -->
<div class="grid-x">
  <div class="cell auto">Expands</div>
  <div class="cell shrink">Content width</div>
</div>

<!-- Gutters -->
<div class="grid-x grid-margin-x">...margin gutters...</div>
<div class="grid-x grid-padding-x">...padding gutters...</div>

<!-- Vertical grid -->
<div class="grid-y" style="height:500px">
  <div class="cell small-6">Top half</div>
  <div class="cell small-6">Bottom half</div>
</div>

<!-- Offsets -->
<div class="grid-x">
  <div class="cell medium-6 medium-offset-3">Centered</div>
</div>

<!-- Source order -->
<div class="cell medium-6 medium-order-2">Reordered</div>

XY Grid Explained

grid-container — centered max-width wrapper
grid-x — horizontal flex grid row
grid-y — vertical flex grid (needs explicit height)
cell — grid child (column)
small-{n} — width at small+ (1–12)
medium-{n} — width at medium+ (640px+)
large-{n} — width at large+ (1024px+)
auto — cell expands to fill remaining space
shrink — cell shrinks to content width
grid-margin-x — margin-based gutters
grid-padding-x — padding-based gutters
medium-offset-{n} — push cell right

⚠ Common Mistakes

  • Forgetting grid-container wrapper — without it, grid margins extend to viewport edge
  • Using grid-margin-x and grid-padding-x together — pick one gutter approach per grid
  • Using old row > columns syntax — Foundation 6.4+ uses grid-x > cell; the old API is deprecated

✓ Tips

  • Use grid-container fluid for full-width layouts without the max-width cap
  • show-for-{bp} / hide-for-{bp} — visibility utility classes for responsive show/hide
  • Foundation's Block Grid: small-up-2 medium-up-3 large-up-4 for equal-column card grids

Summary

  • grid-container > grid-x > cell — three-layer XY grid
  • small-{n} medium-{n} — responsive 12-column spans
  • auto / shrink — flexible cell sizing without fixed columns
  • grid-margin-x / grid-padding-x — two gutter strategies
