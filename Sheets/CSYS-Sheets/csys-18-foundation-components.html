Foundation — UI Components

button · callout · card · menu · top-bar · reveal · tabs · accordion

Component Examples

<!-- Buttons -->
<button class="button primary large">Primary</button>
<button class="button secondary hollow">Hollow</button>
<button class="button success expanded">Full Width</button>

<!-- Callout (alert) -->
<div class="callout warning">
  <h5>Heads Up!</h5>
  <p>This is a warning callout.</p>
  <button class="close-button" data-close>&times;</button>
</div>

<!-- Card -->
<div class="card">
  <div class="card-divider">Card Header</div>
  <img src="...">
  <div class="card-section">
    <h4>Title</h4>
    <p>Content.</p>
  </div>
</div>

<!-- Reveal Modal -->
<button data-open="myModal">Open</button>
<div id="myModal" class="reveal" data-reveal>
  <h1>Modal Title</h1>
  <p>Content.</p>
  <button class="close-button" data-close>&times;</button>
</div>

<!-- Top Bar -->
<div class="top-bar">
  <div class="top-bar-left">
    <ul class="menu"><li class="menu-text">Brand</li></ul>
  </div>
  <div class="top-bar-right">
    <ul class="menu"><li><a href="#">Link</a></li></ul>
  </div>
</div>

Component Notes

button primary/secondary/success/warning/alert — color variants
hollow — transparent background, colored border/text
expanded — full-width button
callout — alert/notification box
data-close — JS data attribute to close a closable component
close-button — positioned × dismiss button
card-divider — header row in card
card-section — content area inside card
data-reveal — initializes modal JS plugin
data-open="id" — trigger to open reveal by ID
top-bar — horizontal navigation bar
menu — horizontal/vertical link list

⚠ Common Mistakes

  • Foundation uses alert (not danger) for red color — different naming than Bootstrap/Bulma
  • JS plugins require initialization: $(document).foundation() — won't work without this call
  • Reveal modal needs data-reveal on the modal AND data-open="id" on the trigger — both are required

✓ Tips

  • Use data-magellan for sticky section-linked navigation as users scroll
  • Foundation's data-sticky component handles sticky headers better than CSS position: sticky for complex cases
  • button-group wraps multiple buttons into a connected bar without gaps

Summary

  • button primary/secondary/alert — color class directly on button
  • callout {color} — alert box with optional dismiss
  • data-reveal + data-open — modal plugin pair
  • menu — versatile navigation list with many variants
