Advanced Patterns

import styled from 'styled-components'

// 1. Polymorphic "as" prop — change underlying element
const Heading = styled.h2`
  font-size: 1.5rem; font-weight: 700;
`
// <Heading as="h1"> renders an h1 with h2 styles
// <Heading as="p">  renders a p with h2 styles

// 2. Targeting another styled component as child
const Icon = styled.svg`width: 1rem; height: 1rem;`

const Button = styled.button`
  display: flex;
  align-items: center;
  gap: 0.5rem;
  ${Icon} { color: currentColor; }        /* targets Icon inside Button */
  &:hover ${Icon} { transform: scale(1.1); }
`

// 3. Object syntax (alternative to template literals)
const Box = styled.div({
  display: 'flex',
  flexDirection: 'column',
  gap: '1rem',
})

// Object with props
const Text = styled.span(props => ({
  color: props.$muted ? '#64748b' : '#0f172a',
  fontSize: props.$size === 'sm' ? '0.875rem' : '1rem',
}))

// 4. Server-Side Rendering (SSR)
import { ServerStyleSheet } from 'styled-components'

// In Express / Next.js custom _document.js:
const sheet = new ServerStyleSheet()
try {
  const html = renderToString(sheet.collectStyles(<App />))
  const styleTags = sheet.getStyleTags()
  // inject styleTags into HTML head
} finally {
  sheet.seal()
}

// 5. StyleSheetManager — inject into shadow DOM or iframe
import { StyleSheetManager } from 'styled-components'
<StyleSheetManager target={shadowRoot}>
  <App />
</StyleSheetManager>

Explained

as="h1" — renders the styled component as a different HTML element or React component
${"{Icon}"} inside another component — generates a CSS selector for that component's class
&:hover ${"{Icon}"} — targets Icon when parent is hovered
styled.div({"{…}"}) — object syntax; camelCase properties, string values
styled.div(props => ({"{…}"}) — object syntax with prop access
ServerStyleSheet — collects styles for SSR; prevents FOUC
sheet.collectStyles(jsx) — wraps JSX to intercept style collection
StyleSheetManager — redirects style injection to a custom target

⚠ Common Mistakes

  • Using component selector (${"{OtherSC}"}) on a non-styled component — only works when the target is a styled-component
  • Forgetting sheet.seal() in SSR — causes memory leaks; always call it in a finally block
  • Using as without considering accessibility — changing as="button" to as="div" loses keyboard semantics

✓ Tips

  • Use object syntax for styles computed from JS variables — cleaner than template literal string interpolation
  • Consider migrating to Linaria or Vanilla Extract if bundle size or runtime performance is a concern
  • Use StyleSheetManager disableCSSOMInjection for environments where CSSOM is unavailable (e.g. print)

Summary

  • as="element" — render styled component as different HTML/React element
  • ${"{OtherSC}"} — target another styled component as CSS selector
  • ServerStyleSheet — collect styles for SSR hydration
  • Object syntax — alternative to template literals for dynamic styles
