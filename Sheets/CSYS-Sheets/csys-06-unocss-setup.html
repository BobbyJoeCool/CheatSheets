UnoCSS — Setup & Presets

presetUno · presetAttributify · presetIcons · uno.config.ts · on-demand

What Is UnoCSS?

UnoCSS is an atomic CSS engine — not a framework, but an engine that lets you define your own utility rules, or use community presets. It is intentionally preset-less by default; all behavior comes from presets you opt into. presetUno gives you Tailwind/Windi-compatible classes. Because it generates styles purely on-demand with no pre-scanning step, it is extremely fast. It supports attributify mode, where utilities are written as HTML attributes rather than class strings.

Key Facts

  • Created by Anthony Fu; used heavily in Vite ecosystem
  • presetUno — Tailwind v3 + Windi CSS compatible utilities
  • presetAttributify — write utilities as HTML attributes
  • presetIcons — 100k+ icons as CSS classes via Iconify
  • No Tailwind CSS dependency — fully independent engine
  • Config file: uno.config.ts (TypeScript-first)

Installation & Config

npm install -D unocss

# Vite integration (vite.config.ts)
import UnoCSS from 'unocss/vite'
export default { plugins: [UnoCSS()] }
// uno.config.ts
import { defineConfig, presetUno, presetAttributify, presetIcons } from 'unocss'

export default defineConfig({
  presets: [
    presetUno(),           // Tailwind-compat utilities
    presetAttributify(),   // attribute mode
    presetIcons({
      scale: 1.2,
      cdn: 'https://esm.sh/',
    }),
  ],
  rules: [
    ['custom-rule', { color: 'red' }],   // static rule
    [/^m-(\d+)$/, ([, d]) => ({ margin: `${d / 4}rem` })], // dynamic
  ],
  shortcuts: {
    'btn': 'px-4 py-2 rounded bg-blue-500 text-white hover:bg-blue-600',
  },
  theme: {
    colors: { primary: '#6366f1' },
  },
})

Config Explained

presetUno() — activates Tailwind-compatible utility classes
presetAttributify() — enables HTML attribute mode
presetIcons() — each Iconify icon becomes a CSS class
rules — custom static or regex-matched utility definitions
shortcuts — alias multiple utilities to a single class name
theme — custom design tokens used in rules and presets
cdn — load icon data from CDN (browser-only)

⚠ Common Mistakes

  • No presets = no utilities — UnoCSS is an engine; without presetUno() none of the common classes work
  • Forgetting import 'virtual:uno.css' in your app entry — styles won't load without this import
  • Mixing attributify and class mode without the presetAttributify — attribute syntax is silently ignored

✓ Tips

  • Use shortcuts as a component layer — cleaner than @apply and works with dynamic rule matching
  • UnoCSS Inspector: http://localhost:5173/__unocss — see generated CSS in real time
  • Use regex rules for design tokens: [/^color-(.*)$/, ([,c]) => ({ color: `var(--${c})` })]

Summary

  • presetUno() — Tailwind-compatible utilities
  • presetAttributify() — write utilities as HTML attributes
  • rules — custom static or regex-based utility definitions
  • shortcuts — alias multiple utilities to one class name
