Settings Explained

_settings.scss — copy from Foundation source; override here before main import
@include foundation-* — selective component inclusion for smaller bundles
$global-width — max-width of grid-container
$foundation-palette — color map for all theme colors
$breakpoints — responsive breakpoint map
$grid-margin-gutters — gutter sizes per breakpoint
rem-calc(px) — converts px values to rem using $global-font-size
foundation-global-styles — required base styles mixin

⚠ Common Mistakes

  • Not importing _settings.scss before Foundation — all overrides must come before the Foundation import
  • Forgetting foundation-global-styles mixin — it's required even if importing other components selectively
  • Setting $global-radius: 0 globally then expecting component-specific radius to work — you must also update those component variables

✓ Tips

  • Use rem-calc() everywhere — it keeps all sizes relative to the global font size setting
  • Copy the official _settings.scss from the Foundation source to your project — it documents every variable
  • Use @include breakpoint(medium) mixin in Sass for same breakpoints as the grid

Summary

  • _settings.scss — override variables here before importing Foundation
  • @include foundation-{component} — selective inclusion for smaller bundles
  • $foundation-palette — central color map
  • rem-calc(px) — px to rem conversion using global font size
