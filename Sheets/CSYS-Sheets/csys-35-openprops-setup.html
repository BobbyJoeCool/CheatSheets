Open Props — Setup & Import

open-props · @import · normalize · postcss-jit-props · CDN · props.all.css

What Is Open Props?

Open Props is a collection of CSS custom properties (design tokens) that cover the most common design decisions — colors, spacing, typography, shadows, gradients, borders, animations, and more. It is framework-agnostic and works anywhere CSS runs. Rather than inventing tokens, you adopt a well-considered system with excellent defaults. The postcss-jit-props plugin ensures only the custom properties you actually use are included in the build output.

Setup Options

  • CDN: unpkg.com/open-props — easiest for prototyping
  • npm: npm install open-props
  • JIT: postcss-jit-props — ships only used props
  • Props file: open-props/props.all.css — ~40KB, all props
  • Normalize: open-props/normalize.css — sensible element defaults using Open Props tokens
  • Author: Adam Argyle (Chrome team)

Import Strategies

/* ── CDN (all props) ─────────────────────────────────── */
@import "https://unpkg.com/open-props";
@import "https://unpkg.com/open-props/normalize.css";

/* ── npm (all props) ─────────────────────────────────── */
@import "open-props";
@import "open-props/normalize";

/* ── Selective import (smaller) ──────────────────────── */
@import "open-props/colors";
@import "open-props/sizes";
@import "open-props/fonts";
@import "open-props/shadows";
@import "open-props/animations";

/* ── PostCSS JIT (best for production) ───────────────── */
/* postcss.config.js:
   require('postcss-jit-props')(OpenProps)
   — only the custom props you USE are emitted */
/* Using Open Props in your CSS */
.card {
  background: var(--surface-1);
  border: var(--border-size-1) solid var(--surface-3);
  border-radius: var(--radius-2);
  padding: var(--size-4);
  box-shadow: var(--shadow-2);
}

.card__title {
  font-size: var(--font-size-3);
  font-weight: var(--font-weight-6);
  color: var(--text-1);
}

.btn-primary {
  background: var(--indigo-6);
  color: var(--indigo-0);
  padding: var(--size-2) var(--size-4);
  border-radius: var(--radius-full);
}

Token System Explained

--size-{1-15} — spacing scale from 0.25rem to 15rem
--font-size-{0-8} — type scale from 0.75rem to 3.5rem
--color-{0-15} — per-palette shade 0 (lightest) to 15 (darkest)
--surface-{1-4} — neutral surface colors (adapt in dark mode)
--text-{1-4} — text colors (1=primary, 2=secondary)
--shadow-{1-6} — elevation shadows small to large
--radius-{1-6} — border-radius from 2px to 24px
--border-size-{1-5} — border widths 1px to 5px
postcss-jit-props — tree-shakes unused custom properties

⚠ Common Mistakes

  • Importing all of Open Props without JIT in production — 40KB of custom properties you mostly don't use; always use JIT or selective imports
  • Expecting colors to adapt to dark mode automatically — only --surface-* and --text-* adapt; palette tokens like --indigo-6 do not change
  • Using wrong prop names — props are --size-4 not --spacing-4; check the docs for exact names

✓ Tips

  • Use open-props/normalize — it provides a beautiful typographic baseline using Open Props tokens
  • Open Props dark mode adapts --surface-* and --text-* tokens automatically via @media (prefers-color-scheme: dark)
  • Browse all tokens at open-props.style — interactive token explorer with live previews

Summary

  • @import "open-props" — load all design tokens as CSS custom properties
  • postcss-jit-props — emit only the props you actually use
  • --surface-* / --text-* — adaptive tokens that respond to dark mode
  • open-props/normalize — element baseline styles built on Open Props tokens
