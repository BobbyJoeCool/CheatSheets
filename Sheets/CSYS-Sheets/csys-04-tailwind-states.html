Tailwind CSS — States & Responsive

hover: · focus: · sm: · md: · dark: · group-hover: · peer

Variants in Action

<!-- Pseudo-class variants -->
<button class="bg-blue-500 hover:bg-blue-700 focus:ring-2 active:scale-95">
  Click me
</button>

<!-- Responsive breakpoints (mobile-first) -->
<div class="text-sm md:text-base lg:text-lg xl:text-xl">
  Responsive text
</div>
<div class="block sm:flex lg:grid lg:grid-cols-3">...</div>

<!-- Dark mode (requires darkMode: 'class' in config) -->
<div class="bg-white dark:bg-gray-900 text-black dark:text-white">
  Adapts to dark mode
</div>

<!-- Group: parent state targets children -->
<div class="group">
  <p class="text-gray-400 group-hover:text-white">Reveals on parent hover</p>
</div>

<!-- Peer: sibling state targeting -->
<input type="checkbox" class="peer hidden" id="toggle" />
<label for="toggle" class="peer-checked:text-green-500">Active</label>

<!-- Stacking variants -->
<button class="dark:hover:bg-gray-700 md:focus:ring-4">
  Multiple variants
</button>

Variants Explained

hover: — applies on :hover
focus: — applies on :focus
active: — applies while pressed
disabled: — applies when :disabled
sm: — min-width 640px and above
md: — min-width 768px and above
lg: — min-width 1024px and above
xl: — min-width 1280px and above
2xl: — min-width 1536px and above
dark: — inside dark mode context
group-hover: — parent has class group and is hovered
peer-checked: — preceding sibling with peer is checked

⚠ Common Mistakes

  • Using sm: to mean "small screens only" — Tailwind is mobile-first; sm: means 640px and up
  • Forgetting group class on the parent — group-hover: on children does nothing without it
  • Setting dark: classes without configuring darkMode: 'class' — defaults to media query, not class toggle

✓ Tips

  • Stack multiple variants: dark:md:hover:bg-slate-700 — order is variant:variant:utility
  • Use max-{bp}: variants for styles that apply below a breakpoint
  • Named groups: group/sidebar + group-hover/sidebar:opacity-100 for nested group contexts

Summary

  • variant:utility — prefix any utility with a variant
  • sm: md: lg: xl: — mobile-first min-width breakpoints
  • group + group-hover: — parent-driven child state
  • peer + peer-checked: — sibling-driven state targeting
