Theming & Advanced Config

// uno.config.ts — theming
import { defineConfig, presetUno } from 'unocss'

export default defineConfig({
  presets: [presetUno()],

  // Theme — extends/merges with preset theme
  theme: {
    colors: {
      primary: { DEFAULT: '#6366f1', light: '#a5b4fc', dark: '#4338ca' },
      surface: 'hsl(220 14% 96%)',
    },
    breakpoints: {
      xs: '480px', sm: '640px', md: '768px', lg: '1024px',
    },
    fontFamily: { display: '"Cal Sans", sans-serif' },
  },

  // Preflights — inject raw CSS before utilities
  preflights: [
    {
      getCSS: ({ theme }) => `
        :root {
          --color-primary: ${theme.colors.primary.DEFAULT};
          --font-display: ${theme.fontFamily.display};
        }
      `,
    },
  ],

  // Layer ordering
  layers: {
    preflights: -1,
    components: 0,
    default: 1,
    utilities: 2,
    'my-layer': 3,
  },

  // CSS-in-JS rule returning layer-aware styles
  rules: [
    [/^layer-(.+)$/, ([, name], { rawSelector }) => {
      return `@layer ${name} { ${rawSelector} { display: block } }`
    }],
  ],
})

Explained

theme.colors.primary.DEFAULT — used by bg-primary (without shade)
theme.colors.primary.light — used by bg-primary-light
theme.breakpoints — defines responsive variant widths
preflights — array of objects with getCSS() returning raw CSS strings
getCSS({ theme }) — receives resolved theme for token injection
layers — controls @layer ordering; lower number = earlier
rawSelector — the generated CSS selector in dynamic rules

⚠ Common Mistakes

  • Setting theme keys outside of presetUno's expected structure — unknown keys are silently ignored
  • Preflights returning undefined — getCSS() must always return a string, even an empty one
  • Expecting extendTheme to work like Tailwind's theme.extend — UnoCSS merges at the top-level theme key

✓ Tips

  • Use preflights to inject CSS custom properties derived from theme — keeps tokens in one place
  • Name custom layers in layers config to control cascade order relative to preset utilities
  • Use theme() helper in rules to access resolved token values without hardcoding

Summary

  • theme — design tokens; merged with preset theme defaults
  • preflights — inject raw CSS at start (resets, custom props)
  • layers — control @layer ordering by name
  • rules context — access theme, selector, generator in dynamic rules
