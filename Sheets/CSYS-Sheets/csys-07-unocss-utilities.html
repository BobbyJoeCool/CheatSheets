Rules, Shortcuts & Variants

// uno.config.ts
import { defineConfig, presetUno } from 'unocss'

export default defineConfig({
  presets: [presetUno()],

  // Static shortcuts — simple string alias
  shortcuts: {
    'btn': 'px-4 py-2 rounded bg-blue-500 text-white font-semibold',
    'card': 'rounded-lg shadow-md bg-white p-6',
    'input-base': 'border border-gray-300 rounded px-3 py-2 focus:outline-none',
  },

  // Dynamic shortcuts — regex-matched
  shortcuts: [
    [/^btn-(.*)$/, ([, c]) => `btn bg-${c}-500 hover:bg-${c}-600`],
  ],

  // Custom static rule
  rules: [
    ['flex-center', { display: 'flex', 'align-items': 'center', 'justify-content': 'center' }],
  ],

  // Custom dynamic rule
  rules: [
    [/^grid-area-(.+)$/, ([, area]) => ({ 'grid-area': area })],
    [/^text-stroke-(\d+)$/, ([, w]) => ({ '-webkit-text-stroke': `${w}px` })],
  ],

  // Custom variants
  variants: [
    (matcher) => {
      if (!matcher.startsWith('hocus:')) return matcher
      return { matcher: matcher.slice(6), selector: s => `${s}:hover,${s}:focus` }
    },
  ],

  // Safelist
  safelist: 'prose m-auto flex flex-col items-center'.split(' '),
})

Explained

shortcuts (object) — static alias; 'btn' expands to utility string
shortcuts (array) — regex-matched dynamic shortcuts
rules[0] (tuple) — static rule: class name → CSS object
rules[1] (regex) — dynamic rule: regex + function returning CSS
variants — custom pseudo-class/attribute matchers
matcher — the class string being matched in variant
selector — function to rewrite the CSS selector
safelist — always-included classes regardless of scan

⚠ Common Mistakes

  • Using object shortcuts and array shortcuts in same config — they must both be in the array form when mixing static and dynamic
  • Icon class collection not installed — presetIcons requires @iconify-json/{collection} package installed
  • Writing rules that return strings instead of CSS objects — rules must return { property: 'value' } not CSS strings

✓ Tips

  • Arbitrary variants: [&:nth-child(3)]:text-red-500 — any selector in square brackets
  • Use children:hover:text-blue-500 to style all child elements on hover of parent
  • UnoCSS supports Windi CSS's space-x-* and divide-* which Tailwind also has — fully compatible

Summary

  • shortcuts — static or regex-matched class aliases
  • rules — custom utilities (static tuple or regex function)
  • variants — custom pseudo-class/variant matchers
  • i-{collection}-{icon} — icon classes via presetIcons
