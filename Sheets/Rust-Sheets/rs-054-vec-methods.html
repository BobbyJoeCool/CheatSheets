Modifying a Vec

Removing or inserting in the middle of a Vec shifts later elements, so it costs O(n). swap_remove is O(1) when order does not matter. retain filters in place, dedup removes consecutive duplicates, and drain removes a range while yielding the removed items.

Key Points

  • remove(i) and insert(i, x) panic if i is out of range
  • extend takes any iterator; append moves from another Vec
  • dedup only removes adjacent duplicates: sort first
  • clear keeps the capacity

Vec Methods

let mut v = vec![1, 2, 3, 4, 5];

v.insert(0, 0);                             // [0, 1, 2, 3, 4, 5]
let removed = v.remove(1);                  // 1 → [0, 2, 3, 4, 5]
let swapped = v.swap_remove(0);             // 0 → [5, 2, 3, 4] (last moved in)
v.extend([6, 7]);                           // [5, 2, 3, 4, 6, 7]
v.extend_from_slice(&[8]);

let mut other = vec![100, 200];
v.append(&mut other);                       // other is now empty
println!("{v:?} {other:?}");

v.retain(|&x| x % 2 == 0);          // keep evens: [2, 4, 6, 8, 100, 200]
let tail = v.split_off(4);          // v = [2, 4, 6, 8], tail = [100, 200]
v.truncate(2);                              // [2, 4]
println!("{}", v.contains(&4));             // true

let mut words = vec!["b", "a", "b", "c", "a"];
words.sort();
words.dedup();                              // ["a", "b", "c"]

let mut nums = vec![10, 20, 30, 40, 50];
let middle: Vec<i32> = nums.drain(1..4).collect();   // [20, 30, 40]
println!("{nums:?}");                       // [10, 50]

let mut people = vec![("ada", 36), ("bob", 25), ("ada", 40)];
people.dedup_by_key(|p| p.0);               // removes only adjacent "ada" dupes
nums.resize(4, 0);                          // [10, 50, 0, 0]
nums.reverse();
nums.clear();                               // len 0, capacity kept
let joined = [1, 2, 3].map(|x| x.to_string()).join("-");   // "1-2-3"

Code Explained

swap_remove fills the hole with the last element
append moves all items and leaves other empty
retain keeps only items matching the predicate
drain(1..4) removes and returns a range

Coming From…

  • Python list.insert, pop(i), list comprehension for filtering
  • Java ArrayList.add(i, x), remove(i), removeIf
  • C++ erase / insert / std::erase_if (C++20)

The Rust Way

  • removing in a loop by index → retain
  • v.remove(i) when order is irrelevant → swap_remove(i)

⚠ Common Mistakes

  • dedup on unsorted data expecting all duplicates gone
  • Removing by index while iterating forward (skips items)
  • Calling remove(0) repeatedly (O(n²); use VecDeque)

✓ Tips & Best Practices

  • Sort then dedup to make values unique, or collect into a HashSet
  • Use drain(..) to move every item out while keeping capacity
  • Use retain_mut to modify and filter in one pass

Quick Summary

  • insert / remove — O(n)
  • swap_remove — O(1)
  • retain / dedup
  • drain / split_off
