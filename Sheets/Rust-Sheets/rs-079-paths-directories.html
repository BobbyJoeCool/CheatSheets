Paths & Directories

Path / PathBuf · join / extension / file_name · fs::create_dir_all · read_dir · metadata · remove_file / rename

Working with the File System

Path is a borrowed path (like &str) and PathBuf is owned and growable (like String). They handle separators per platform. join builds paths, and methods like extension, file_name and parent take them apart. std::fs creates, lists, renames and deletes files and directories.

Key Points

  • Paths are not always UTF-8: to_str() returns Option
  • display() prints a path lossily
  • Accept impl AsRef<Path> to take &str, String or PathBuf
  • read_dir order is not sorted

Paths and Directories

use std::fs;
use std::path::{Path, PathBuf};

let p = Path::new("/home/ada/docs/report.final.pdf");
println!("{:?}", p.file_name());            // Some("report.final.pdf")
println!("{:?}", p.file_stem());            // Some("report.final")
println!("{:?}", p.extension());            // Some("pdf")
println!("{:?}", p.parent());               // Some("/home/ada/docs")

let mut out = PathBuf::from("build");
out.push("assets");                         // build/assets
out.push("app.js");
out.set_extension("min.js");                // build/assets/app.min.js
println!("{}", out.display());
let cfg = Path::new("config").join("app.toml");   // config/app.toml

fs::create_dir_all("build/assets")?;        // mkdir -p
fs::write(&out, "…")?;
println!("{}", out.exists());               // true

for entry in fs::read_dir("build/assets")? {
    let entry = entry?;
    let meta = entry.metadata()?;
    println!("{:?} {} bytes", entry.file_name(), meta.len());
}

let mut rs_files: Vec<PathBuf> = fs::read_dir("src")?
    .filter_map(|e| e.ok().map(|e| e.path()))
    .filter(|p| p.extension().is_some_and(|x| x == "rs"))
    .collect();
rs_files.sort();
fs::rename(&out, "build/app.js")?;
fs::copy("build/app.js", "build/app.bak")?;
fs::remove_file("build/app.bak")?;
fs::remove_dir_all("build")?;               // rm -rf: careful

Code Explained

file_stem drops only the last extension
push appends components with the right separator
create_dir_all makes all missing parents
read_dir yields entries with names and metadata

Coming From…

  • Python pathlib.Path (/ operator, .suffix, .iterdir())
  • Java Path.of, resolve, Files.list, Files.createDirectories
  • Go path/filepath.Join, os.ReadDir, os.MkdirAll

The Rust Way

  • format!("{}/{}", dir, name) → Path::new(dir).join(name)
  • fn f(p: &str) for paths → fn f(p: impl AsRef<Path>)

⚠ Common Mistakes

  • Building paths with string concatenation and /
  • Unwrapping to_str() on non-UTF-8 paths
  • Expecting read_dir results in sorted order

✓ Tips & Best Practices

  • Use walkdir for recursive traversal
  • Use dirs / directories crates for home and config folders
  • Sort read_dir output when order matters

Quick Summary
