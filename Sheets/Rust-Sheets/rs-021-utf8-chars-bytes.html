UTF-8, chars & bytes

UTF-8 guarantee · no s[0] indexing · byte-range slices & panics · chars() / char_indices() · bytes() · is_char_boundary · String::from_utf8_lossy

Why You Cannot Index a String

Rust strings are always valid UTF-8, where a character takes 1 to 4 bytes. Indexing with s[0] is not allowed because a byte position may fall in the middle of a character. Instead, iterate with chars() (Unicode scalars) or bytes() (raw bytes), and slice only on character boundaries.

Key Points

  • &s[0..1] panics if byte 1 is not a char boundary
  • chars().nth(i) is O(n), not O(1)
  • Invalid UTF-8 from files → from_utf8 returns an error
  • User-visible "characters" (graphemes) may be several chars

Under the Hood

  • A String is a Vec<u8> with a UTF-8 invariant checked at creation
  • chars() decodes UTF-8 on the fly; it does not store chars
  • Slicing checks is_char_boundary at runtime and panics on failure
  • from_utf8_unchecked (unsafe) skips validation

chars, bytes and slicing

let s = "héllo🦀";
println!("{}", s.len());                    // 10 bytes
println!("{}", s.chars().count());          // 6 chars
// let c = s[0];                    // error: cannot index str by integer

println!("{:?}", s.chars().next());         // Some('h')
println!("{:?}", s.chars().nth(1));         // Some('é')
println!("{:?}", s.chars().rev().next());   // Some('🦀')
println!("{}", &s[0..1]);                   // h
// println!("{}", &s[0..2]);                // panic: byte 2 is inside 'é'
println!("{}", s.is_char_boundary(2));      // false

for (i, c) in s.char_indices() {
    print!("{i}:{c} ");                     // 0:h 1:é 3:l 4:l 5:o 6:🦀
}
println!();
println!("{:?}", "hé".bytes().collect::<Vec<u8>>());   // [104, 195, 169]
println!("{:?}", "hé".as_bytes());          // same, as &[u8]

let raw = vec![72, 105, 0xFF];
println!("{:?}", String::from_utf8(raw.clone()));   // Err(FromUtf8Error …)
println!("{}", String::from_utf8_lossy(&raw));      // Hi�

let first3: String = s.chars().take(3).collect();   // "hél"
let ascii_upper = "hello".to_ascii_uppercase();     // fast for ASCII

Code Explained

Coming From…

  • C++ std::string is bytes with no encoding guarantee
  • Python str indexes by code point; bytes is separate
  • Java / JS strings are UTF-16; charAt can split emoji

The Rust Way

  • s.chars().nth(i) in a loop (O(n²)) → iterate once with chars()
  • &s[..n] with a char count → s.chars().take(n).collect()

⚠ Common Mistakes

  • Slicing with indices computed from char counts
  • Assuming one char per visible character (é can be e + ◌́)
  • Using chars().nth for random access

✓ Tips & Best Practices

  • Work in bytes for ASCII-only protocols
  • Use unicode-segmentation for graphemes
  • Validate external bytes with from_utf8

Quick Summary

  • always UTF-8
  • no s[i] indexing
  • chars() / bytes()
  • slice on char boundaries
