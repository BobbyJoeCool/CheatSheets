Entry API & BTreeMap

entry().or_insert() · or_insert_with / or_default · and_modify · word-count pattern · BTreeMap sorted keys · range() · first_key_value

Insert-or-Update and Sorted Maps

The entry API looks up a key once and lets you insert a default or update the existing value, avoiding double lookups and borrow problems. BTreeMap is a map kept in sorted key order, with O(log n) operations, ordered iteration, range queries and min/max access.

Key Points

  • entry(k) takes the key by value
  • or_insert returns &mut V
  • or_default() uses V::default() (0, empty Vec…)
  • BTreeMap keys need Ord, not Hash

Entry API and BTreeMap

use std::collections::{BTreeMap, HashMap};

let text = "the cat and the hat and the bat";
let mut counts: HashMap<&str, usize> = HashMap::new();
for word in text.split_whitespace() {
    *counts.entry(word).or_insert(0) += 1;  // word-count pattern
}
println!("{}", counts["the"]);              // 3

let mut groups: HashMap<usize, Vec<&str>> = HashMap::new();
for w in ["hi", "yo", "hey", "cat"] {
    groups.entry(w.len()).or_default().push(w);   // group by length
}
println!("{:?}", groups[&3]);               // ["hey", "cat"]

let mut stock = HashMap::from([("apple", 5)]);
stock.entry("apple").and_modify(|n| *n += 10).or_insert(1);   // 15
stock.entry("pear").and_modify(|n| *n += 10).or_insert(1);    // 1
let cache = stock.entry("kiwi").or_insert_with(|| expensive());

let mut scores = BTreeMap::new();
scores.insert(72, "C");
scores.insert(95, "A");
scores.insert(85, "B");
for (score, grade) in &scores { print!("{score}{grade} "); }   // 72C 85B 95A
println!();
println!("{:?}", scores.first_key_value());  // Some((72, "C"))
println!("{:?}", scores.last_key_value());   // Some((95, "A"))
let b_or_better: Vec<_> = scores.range(80..).map(|(k, _)| k).collect();
println!("{b_or_better:?}");                // [85, 95]
let sorted_counts: BTreeMap<_, _> = counts.into_iter().collect(); // by word
fn expensive() -> i32 { 42 }

Code Explained

entry(word).or_insert(0) returns a &mut usize to increment
or_default() creates an empty Vec on first use
and_modify updates existing; or_insert handles new keys
BTreeMap iterates in key order and supports range

Coming From…

  • Python collections.Counter, defaultdict(list), dict.setdefault
  • Java merge(k, 1, Integer::sum), computeIfAbsent, TreeMap
  • C++ map[k]++ default-inserts; std::map is ordered like BTreeMap

The Rust Way

  • if let Some(v) = m.get_mut(k) { … } else { m.insert(k, …) } → entry
  • sorting a HashMap's keys every time → BTreeMap

⚠ Common Mistakes

  • or_insert(expensive()) running even when the key exists
  • Holding the &mut from or_insert while touching the map again
  • Using BTreeMap only to print sorted output once (sort instead)

✓ Tips & Best Practices

  • Use entry for counters, groupings and caches
  • Use BTreeMap for leaderboards, time series and ranges
  • Collect into BTreeMap to sort a HashMap for display
