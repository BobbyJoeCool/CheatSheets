Sheet 011

Integers

i8…i128 · u8…u128 · isize / usize · literals 0x 0o 0b 1_000 10u8 · i32::MAX · debug panics vs release wraps

Sized Integer Types

Rust integers state their size and sign: i8 to i128 are signed, u8 to u128 unsigned, and isize/usize match the pointer size. The default is i32. Overflow panics in debug builds and wraps in release builds, so use the explicit checked_, wrapping_ and saturating_ methods when overflow is possible.

Key Points

  • usize is used for indexes and lengths
  • Literal suffixes: 10u8, 5_i64
  • No implicit conversion between integer types
  • Integer division truncates toward zero

Under the Hood

  • Debug builds insert an overflow check after each arithmetic op
  • Release builds (overflow-checks = false by default) emit plain wrapping instructions
  • Integers are plain machine values on the stack; no boxing

Integer Types and Overflow

let a = 42;                    // i32 (default)
let b: u8 = 255;
let big: i64 = 9_000_000_000;
let hex = 0xFF;                // 255
let oct = 0o17;                // 15
let bin = 0b1010;              // 10
let byte = b'A';               // 65u8
let idx: usize = 3;

println!("{} {}", i32::MAX, u8::MIN);   // 2147483647 0
println!("{}", 7 / 2);                  // 3
println!("{}", -7 / 2);                 // -3 (toward zero)
println!("{}", (-7i32).rem_euclid(2));  // 1

// let c = b + 1;              // debug: panic "attempt to add with overflow"
println!("{:?}", b.checked_add(1));     // None
println!("{}", b.wrapping_add(1));      // 0
println!("{}", b.saturating_add(10));   // 255
println!("{:?}", b.overflowing_add(1)); // (0, true)

println!("{}", u64::from(b) + big as u64);   // explicit widening
println!("{}", i32::from_str_radix("ff", 16).unwrap());   // 255
println!("{}", 255u8.count_ones());     // 8

Code Explained

A literal with no suffix is i32 unless the context says otherwise
Overflow panics in debug: catches bugs early
checked_add returns Option, None on overflow
From widens safely; as can truncate (sheet 015)

Coming From…

  • C++ int32_t, uint8_t; signed overflow is undefined behavior
  • Java fixed sizes (int, long), no unsigned types, always wraps
  • Python ints are arbitrary precision, never overflow

The Rust Way

  • as casts to widen → u64::from(x) / .into()
  • relying on wraparound → wrapping_* to make it explicit

⚠ Common Mistakes

  • Testing only in release mode and missing overflow bugs
  • Mixing i32 and usize without conversion (type error)
  • Using as and silently truncating

✓ Tips & Best Practices

  • Use usize for indexes, u64/i64 for IDs and money in cents
  • Turn on overflow-checks = true in release for safety-critical code
  • Use TryFrom when narrowing (sheet 015)

Quick Summary

  • i32 default, sized types
  • usize — indexes
  • debug panic / release wrap
  • checked_ / saturating_
