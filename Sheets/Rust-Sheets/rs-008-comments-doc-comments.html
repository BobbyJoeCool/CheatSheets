Comments & Doc Comments

// · /* */ (nestable) · /// item docs · //! crate / module docs · # Examples / # Panics / # Errors · cargo doc --open

Comments and Documentation

Rust has // line comments and nestable /* */ block comments. Doc comments use Markdown: /// documents the item that follows and //! documents the enclosing crate or module. cargo doc turns them into HTML, and code blocks in doc comments run as tests.

Key Points

  • Doc comments support headings, lists, links and code blocks
  • Standard sections: Examples, Panics, Errors, Safety
  • Link to items with [Type] intra-doc links
  • docs.rs builds docs for every published crate

Doc Comments

//! # geometry
//! Shapes and area calculations.

/// A rectangle with a width and height.
///
/// See also [`Circle`].
pub struct Rect { pub w: f64, pub h: f64 }

/// Returns the area of `r`.
///
/// # Examples
///
/// ```
/// use geometry::{Rect, area};
/// let r = Rect { w: 3.0, h: 4.0 };
/// assert_eq!(area(&r), 12.0);
/// ```
///
/// # Panics
///
/// Panics if a side is negative.
pub fn area(r: &Rect) -> f64 {
    assert!(r.w >= 0.0 && r.h >= 0.0, "negative side");
    r.w * r.h  // regular comment
    /* block /* nested */ comment */
}

Code Explained

//! at the top documents the crate itself
[Circle] becomes a link in generated docs
The example in runs during cargo test`
# Panics tells callers when the function can panic

Coming From…

  • C++ Doxygen /// or /** */ comments
  • Python docstrings + doctest
  • Java Javadoc /** */ with HTML and @param tags

The Rust Way

  • docs that drift from code → doc tests that run in CI
  • no docs on pub items → #![warn(missing_docs)]

⚠ Common Mistakes

  • Doc examples that no longer compile (they fail cargo test)
  • Using // where /// was intended (no docs generated)
  • Missing # Safety on unsafe fn

✓ Tips & Best Practices

  • Write an Examples section for every public function
  • Use cargo doc --open --no-deps to preview your crate only
  • Hide setup lines in doc tests with a leading #

Quick Summary

  • // /* */ — comments
  • /// — item docs
  • //! — crate/module docs
  • doc tests run with cargo test
