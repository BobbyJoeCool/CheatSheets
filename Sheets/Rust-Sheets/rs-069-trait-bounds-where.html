Trait Bounds & where

T: Display + Clone · where clauses · impl Trait in argument & return position · conditional impls · ?Sized

Constraining Generics

A trait bound like T: Display + Clone limits a generic to types implementing those traits, which lets the body call their methods. Long bounds move to a where clause. impl Trait is shorthand in argument position and an opaque return type in return position. Bounds on an impl block create conditional methods.

Key Points

  • + combines bounds
  • where also allows bounds on associated types
  • Return-position impl Trait hides one concrete type
  • Generics are Sized by default; ?Sized relaxes that

Bounds and where

use std::fmt::{Debug, Display};
use std::hash::Hash;
use std::collections::HashMap;

fn show_twice<T: Display + Clone>(x: T) -> String {
    let y = x.clone();
    format!("{x} {y}")
}

fn count_items<I, K>(items: I) -> HashMap<K, usize>
where
    I: IntoIterator<Item = K>,
    K: Eq + Hash,
{
    let mut m = HashMap::new();
    for k in items { *m.entry(k).or_insert(0) += 1; }
    m
}
println!("{:?}", count_items("abca".chars()).get(&'a'));   // Some(2)

fn log_all(items: &[impl Debug]) { for i in items { println!("{i:?}"); } }

fn evens(limit: u32) -> impl Iterator<Item = u32> {   // opaque return type
    (0..limit).filter(|n| n % 2 == 0)
}
println!("{:?}", evens(7).collect::<Vec<_>>());   // [0, 2, 4, 6]

struct Wrapper<T>(T);
impl<T: Display> Wrapper<T> {               // method exists only if T: Display
    fn print(&self) { println!("[{}]", self.0); }
}
Wrapper(5).print();                         // [5]
// Wrapper(vec![1]).print();                // E0599: bounds not satisfied

fn describe<T: Debug + ?Sized>(x: &T) { println!("{x:?}"); }
describe("a str");                          // T = str (unsized) is OK
describe(&[1, 2][..]);                      // T = [i32]

Code Explained

T: Display + Clone allows {} and .clone()
The where clause keeps the signature readable
impl Iterator hides the exact filter type
impl<T: Display> adds print only where T is printable

Coming From…

  • C++20 requires clauses and concepts
  • Java <T extends Comparable<T>> bounded types
  • TypeScript <T extends Shape> constraints

The Rust Way

  • fn f<T: A + B + C, U: D>(…) → where clause
  • returning Box<dyn Iterator> for one type → impl Iterator

⚠ Common Mistakes

  • Returning two different types from -> impl Trait
  • Missing bound errors (E0277: trait bound not satisfied)
  • Unnecessary bounds on struct definitions (put them on impls)

✓ Tips & Best Practices

  • Bound impls, not structs, unless the struct needs it
  • Use impl Trait args for simple cases; named generics when reused
  • Read E0277 help: it names the missing trait
