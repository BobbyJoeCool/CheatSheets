Formatting, Linting and Editions

cargo fmt formats code to the community style, and cargo clippy adds hundreds of lints that catch bugs and suggest idiomatic code. Editions let Rust make breaking syntax changes without splitting the ecosystem: each crate picks an edition, and crates of different editions work together.

Key Points

  • Editions are set in Cargo.toml: edition = "2024"
  • The 2024 edition shipped with Rust 1.85 (Feb 2025)
  • cargo fix --edition migrates code automatically
  • Lint levels: allow, warn, deny, forbid

Tools and Lint Attributes

// Terminal:
// cargo fmt                    format everything
// cargo fmt --check            CI: fail if not formatted
// cargo clippy                 lint
// cargo clippy -- -D warnings  CI: warnings become errors
// cargo fix --edition          migrate to the next edition

#![warn(clippy::pedantic)]      // crate-wide, stricter lints
#![deny(unsafe_code)]           // forbid unsafe in this crate

#[allow(clippy::too_many_arguments)]
fn build(a: i32, b: i32, c: i32, d: i32, e: i32, f: i32, g: i32, h: i32) {}

fn main() {
    let v = vec![1, 2, 3];
    if v.len() == 0 {}          // clippy: use `v.is_empty()`
    let x = 5;
    let _unused = x;            // leading _ silences unused warning
}

// rustfmt.toml
// max_width = 100
// imports_granularity = "Crate"

Code Explained

#![…] applies to the whole crate; #[…] to the next item
Clippy catches style issues like len() == 0
-D warnings makes CI strict
An underscore prefix marks a variable as intentionally unused

Coming From…

The Rust Way

  • #[allow(warnings)] to silence noise → fix or allow specific lints
  • manual formatting debates → cargo fmt in CI

Editions

EditionNotable Changes
2015Rust 1.0
2018Path changes, async keyword, NLL
2021Disjoint closure captures, IntoIterator for arrays
2024let chains, unsafe extern, RPIT capture rules, gen keyword reserved

Lint Levels

LevelEffect
allowSilent
warnWarning
denyError (can be overridden)
forbidError (cannot be overridden)
expectWarn if lint does NOT fire

⚠ Common Mistakes

  • Not running Clippy and missing easy wins
  • Thinking editions split crates (they interoperate)
  • Blanket #![allow(clippy::all)]

✓ Tips & Best Practices

  • Run cargo fmt --check and cargo clippy -- -D warnings in CI
  • Use #[expect(lint)] to document intentional exceptions
  • Let rust-analyzer run clippy on save

Quick Summary
