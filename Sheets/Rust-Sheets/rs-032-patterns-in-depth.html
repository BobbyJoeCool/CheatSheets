Destructuring with Patterns

Patterns can take apart structs, tuples, enums, references and slices in one step. .. skips the remaining fields, @ binds a value while also testing it, and a guard (if cond) adds a condition to an arm. Patterns appear in match, let, if let, function parameters and for loops.

Key Points

  • Struct patterns: Point { x, y: 0 }
  • Slice patterns match length and position
  • Default binding mode borrows when matching a reference
  • Guards do not count toward exhaustiveness

Advanced Patterns

struct Point { x: i32, y: i32 }
enum Shape { Circle { r: f64 }, Rect { w: f64, h: f64 } }

let p = Point { x: 3, y: 0 };
match p {
    Point { x: 0, .. } => println!("on y axis"),
    Point { x, y: 0 } => println!("on x axis at {x}"),   // matches
    Point { x, y } => println!("({x}, {y})"),
}

let s = Shape::Rect { w: 2.0, h: 3.0 };
let area = match s {
    Shape::Circle { r } => std::f64::consts::PI * r * r,
    Shape::Rect { w, h } if w == h => w * w,    // guard
    Shape::Rect { w, h } => w * h,
};

let age = 15;
match age {
    n @ 13..=19 => println!("teen: {n}"),   // bind and test
    n => println!("age {n}"),
}

let v = [1, 2, 3, 4, 5];
match v.as_slice() {
    [] => println!("empty"),
    [one] => println!("one: {one}"),
    [first, .., last] => println!("{first}..{last}"),   // 1..5
}
if let [a, b, rest @ ..] = &v[..] { println!("{a} {b} {rest:?}"); }

let opt = Some(String::from("hi"));
if let Some(ref s) = opt { println!("{s}"); }   // borrow, don't move
match &opt { Some(s) => println!("{s}"), None => {} }   // same, modern style

let ((a2, b2), Point { x: px, .. }) = ((1, 2), Point { x: 9, y: 9 });
fn print_pair(&(a, b): &(i32, i32)) { println!("{a},{b}"); }

Code Explained

.. ignores fields you do not need
The guard if w == h only runs after the shape matches
n @ 13..=19 tests the range and keeps the value
rest @ .. captures the remaining slice

Coming From…

  • Python structural match with class patterns and guards
  • Java 21 record patterns and when guards in switch
  • C++ structured bindings, but no pattern matching in switch

The Rust Way

  • ref keyword in new code → match on &value
  • indexing v[0] after a length check → slice pattern

Syntax

PatternMeaning

(x, _)Tuple, ignore 2nd

p if condGuard

⚠ Common Mistakes

  • Moving out of a value inside match and using it later (match on &x)
  • Relying on a guard for exhaustiveness
  • Forgetting .. and listing every struct field

✓ Tips & Best Practices

  • Destructure in function parameters for clarity
  • Use slice patterns for command parsing: ["add", name]
  • Match on tuples to handle combinations of two values

Quick Summary

  • destructure anything
  • .. — rest
  • @ — bind + test
  • guards if cond
