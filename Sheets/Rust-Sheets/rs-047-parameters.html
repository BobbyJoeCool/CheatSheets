Parameters & Arguments

by value (move) · &T / &mut T params · mut bindings · impl Trait params · no default args or overloading · Option / builder instead

How Arguments Are Passed

The parameter type decides ownership: T takes ownership (move or copy), &T borrows for reading and &mut T borrows for changing. mut x: T only makes the local binding mutable. Rust has no default arguments and no overloading; use Option parameters, separate function names, traits or a builder.

Key Points

  • The caller writes &x / &mut x explicitly
  • impl Trait accepts any type implementing the trait
  • impl Into<String> accepts both &str and String
  • Patterns can destructure parameters

Parameter Kinds

fn consume(v: Vec<i32>) -> usize { v.len() }    // takes ownership
fn inspect(v: &[i32]) -> i32 { v.iter().sum() } // borrows
fn extend(v: &mut Vec<i32>) { v.push(99); }     // mutable borrow
fn countdown(mut n: u32) { while n > 0 { n -= 1; } }   // local mut

let mut data = vec![1, 2, 3];
println!("{}", inspect(&data));             // 6
extend(&mut data);
println!("{}", consume(data));              // 4; data moved

fn show(item: impl std::fmt::Display) { println!("[{item}]"); }
show(42);
show("text");

struct User { name: String }
fn new_user(name: impl Into<String>) -> User { User { name: name.into() } }
let a = new_user("ada");                    // &str
let b = new_user(String::from("bob"));      // String

// No defaults: use Option…
fn connect(host: &str, port: Option<u16>) -> String {
    format!("{host}:{}", port.unwrap_or(80))
}
println!("{}", connect("example.com", None));   // example.com:80

// …or separate names instead of overloading
fn area_square(s: f64) -> f64 { s * s }
fn area_rect(w: f64, h: f64) -> f64 { w * h }

fn print_point((x, y): (i32, i32)) { println!("({x}, {y})"); }
print_point((3, 4));

Code Explained

consume moves data; it cannot be used afterwards
&mut data is visible at the call site
impl Display takes integers and strings
impl Into<String> avoids forcing callers to allocate

Coming From…

  • C++ default arguments and overloading are both allowed
  • Python keyword and default arguments: def connect(host, port=80)
  • Java overloading; no defaults (same workaround: builders)

The Rust Way

  • many bool parameters → an options struct or enum
  • boolean flag parameter f(true) → two functions or an enum

⚠ Common Mistakes

  • Taking String when &str is enough
  • Taking &mut when only reading
  • Trying to overload by type (E0428 duplicate definition)

✓ Tips & Best Practices

  • Choose the weakest parameter: &T over &mut T over T
  • Use builders for 4+ optional settings (sheet 106)
  • Use impl AsRef<Path> for path parameters
