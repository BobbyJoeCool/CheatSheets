CLI Arguments & Environment

env::args() · env::var · clap #[derive(Parser)] · #[arg(short, long)] · subcommands · ExitCode / process::exit

Building Command-Line Tools

std::env::args() gives raw arguments (the first is the program name). For anything beyond trivial, use clap: derive Parser on a struct and get parsing, validation, --help and --version for free. Read configuration from env::var, and report success or failure with ExitCode.

Key Points

  • cargo add clap -F derive
  • Doc comments become help text
  • env::var returns Result<String, VarError>
  • process::exit skips destructors; prefer returning ExitCode

clap and env

use clap::{Parser, Subcommand};
use std::process::ExitCode;

/// Search files for a pattern
#[derive(Parser, Debug)]
#[command(version, about)]
struct Cli {
    /// Pattern to look for
    pattern: String,
    /// Files to search
    #[arg(required = true)]
    files: Vec<std::path::PathBuf>,
    /// Max matches to show
    #[arg(short, long, default_value_t = 10)]
    max: usize,
    #[command(subcommand)]
    cmd: Option<Cmd>,
}

#[derive(Subcommand, Debug)]
enum Cmd {
    /// Count matches only
    Count,
    /// Export results
    Export { #[arg(long)] json: bool },
}

fn main() -> ExitCode {
    let cli = Cli::parse();                 // exits with help on bad input
    let level = std::env::var("LOG_LEVEL").unwrap_or_else(|_| "info".into());
    if cli.files.iter().any(|f| !f.exists()) {
        eprintln!("error: missing file");
        return ExitCode::from(2);
    }
    println!("{cli:?} level={level}");
    ExitCode::SUCCESS
}

Code Explained

Plain fields are positional; #[arg(short, long)] makes -m / --max
default_value_t sets a typed default
Subcommand enums model tool count / tool export
Returning ExitCode sets the process status

Coming From…

  • Python argparse / click / typer (typer is closest to clap derive)
  • Java picocli annotations
  • Go flag package / cobra for subcommands

The Rust Way

  • hand-parsing env::args() → clap derive
  • process::exit(1) deep in code → return errors up to main

⚠ Common Mistakes

  • Forgetting that args() includes the program name
  • Calling env::set_var in multi-threaded code (now unsafe in edition 2024)
  • process::exit skipping file flushes

✓ Tips & Best Practices

  • Use #[arg(env = "…")] for env fallbacks
  • Use exit code 2 for usage errors, 1 for failures
  • Test CLIs with assert_cmd

Quick Summary

  • env::args() — raw
  • clap #[derive(Parser)]
  • env::var → Result
  • return ExitCode
