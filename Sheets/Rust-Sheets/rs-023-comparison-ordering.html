Equality and Ordering Traits

Comparison operators are backed by traits: == uses PartialEq, < uses PartialOrd. Eq and Ord add the guarantee of a total order, which sorting, BTreeMap and max() on iterators require. Floats are only partial because of NaN. Derive these traits for your own types.

Key Points

  • Both sides must be the same type (or have an impl)
  • cmp returns Ordering::Less | Equal | Greater
  • Derived ordering compares fields top to bottom
  • Strings compare by bytes (lexicographic)

Comparisons

use std::cmp::Ordering;

println!("{}", 3 == 3);                     // true
println!("{}", "apple" < "banana");         // true
println!("{}", "Z" < "a");                  // true (byte order)
println!("{:?}", 5_i32.cmp(&9));            // Less
println!("{:?}", 2.5.partial_cmp(&f64::NAN));   // None

match 7_i32.cmp(&5) {
    Ordering::Less => println!("smaller"),
    Ordering::Equal => println!("same"),
    Ordering::Greater => println!("bigger"),  // bigger
}

println!("{}", 3_i32.max(8));               // 8
println!("{}", 15_i32.clamp(0, 10));        // 10
println!("{}", 2.0_f64.max(f64::NAN));      // 2

#[derive(Debug, PartialEq, Eq, PartialOrd, Ord)]
struct Version { major: u32, minor: u32 }
let v1 = Version { major: 1, minor: 9 };
let v2 = Version { major: 2, minor: 0 };
println!("{}", v1 < v2);                    // true

let mut people = vec![("Ada", 36), ("Bob", 25)];
people.sort_by(|a, b| a.1.cmp(&b.1).then(a.0.cmp(&b.0)));
println!("{}", (1, "b") < (1, "c"));         // true (tuples compare in order)

Code Explained

cmp gives an Ordering you can match
NaN makes partial_cmp return None
Derived Ord compares major, then minor
then chains a tie-breaker

Coming From…

  • C++ operator<=> (C++20) returns an ordering like cmp
  • Java Comparable.compareTo returns an int
  • Python __eq__/__lt__; tuples compare element by element

The Rust Way

  • if a > b { a } else { b } → a.max(b)
  • manual PartialOrd impl for field order → #[derive]

⚠ Common Mistakes

  • Comparing String with &str the wrong way round (works both ways for ==)
  • Deriving Ord with fields in the wrong order
  • Calling .max() on an iterator of floats

✓ Tips & Best Practices

  • Put fields in comparison order when deriving Ord
  • Use sort_by_key with tuples for multi-key sorts
  • Use total_cmp for floats
