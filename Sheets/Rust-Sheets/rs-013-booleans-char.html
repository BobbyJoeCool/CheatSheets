Booleans & char

bool · char is a 4-byte Unicode scalar · 'a' vs "a" · is_alphabetic() / is_ascii_digit() · to_digit(10) · char::from_u32

true/false and Unicode Characters

bool is true or false and is the only type allowed in conditions. A char is a 4-byte Unicode scalar value (any code point except surrogates), written in single quotes. Strings are UTF-8, so a String is not an array of chars (sheet 021).

Key Points

  • No truthy values: if 1 {} does not compile
  • b'a' is a byte (u8), not a char
  • char methods cover Unicode and ASCII classes
  • as u32 gives the code point

bool and char

let ok = true;
let ready: bool = 3 > 2;
println!("{}", ok && !ready);          // false
println!("{}", ok as i32);             // 1

let c = 'R';
let heart = '♥';
let crab = '🦀';
println!("{}", std::mem::size_of::<char>());   // 4
println!("{}", c as u32);              // 82
println!("{:?}", char::from_u32(0x1F980));     // Some('🦀')
println!("{}", 'a'.is_alphabetic());   // true
println!("{}", '7'.is_ascii_digit());  // true
println!("{:?}", '7'.to_digit(10));    // Some(7)
println!("{:?}", 'f'.to_digit(16));    // Some(15)
println!("{}", 'ß'.to_uppercase());    // SS (can be several chars)
println!("{}", 'a'.to_ascii_uppercase());     // A
println!("{}", heart.len_utf8());      // 3 bytes in UTF-8
println!("{}", ('a'..='e').collect::<String>());   // abcde
println!("{}", "Rust".chars().count());// 4

Code Explained

bool as i32 gives 0 or 1
A char is always 4 bytes in memory
to_digit(radix) returns an Option
to_uppercase returns an iterator because some letters expand

Coming From…

  • C++ char is 1 byte; Unicode needs char32_t
  • Java char is a UTF-16 unit (2 bytes); emoji need two
  • Python no char type; a 1-length string

The Rust Way

  • c as u8 - b'0' digit math → c.to_digit(10)
  • indexing strings to get chars → .chars()

⚠ Common Mistakes

  • Using "a" where a char 'a' is expected
  • Assuming to_uppercase() returns one char
  • Treating String length as character count

✓ Tips & Best Practices

  • Use is_ascii_* methods for protocol and ID parsing
  • Use chars().count() for code point counts
  • Use the unicode-segmentation crate for user-visible characters
