Slices

&[T] / &mut [T] · &v[1..3] · &str as a slice · split_at · chunks / windows · first() / last()

Views into Contiguous Data

A slice &[T] is a borrowed view of a contiguous run of elements in an array, Vec or other buffer. Slicing with a range out of bounds panics. Functions that read sequences should take &[T], which accepts arrays, Vecs and sub-slices alike, just as &str accepts every kind of string.

Key Points

  • &Vec<T> coerces to &[T] automatically
  • get(range) returns Option<&[T]> instead of panicking
  • &mut [T] allows in-place edits but not resizing
  • Most Vec reading methods are actually slice methods

Under the Hood

  • A slice reference is a fat pointer: start pointer + length (16 bytes)
  • &v[1..3] is pointer arithmetic plus a bounds check
  • [T] itself is unsized (!Sized); it lives behind &, Box or Rc
  • Iterating a slice compiles to a pointer loop with no per-item bounds check

Slice Operations

let v = vec![10, 20, 30, 40, 50];
let arr = [1, 2, 3];

let mid: &[i32] = &v[1..4];                 // [20, 30, 40]
println!("{:?} {:?}", &v[..2], &v[3..]);    // [10, 20] [40, 50]
// let bad = &v[3..9];                      // panic: range end 9 out of range
println!("{:?}", v.get(3..9));              // None

fn total(xs: &[i32]) -> i32 { xs.iter().sum() }
println!("{} {} {}", total(&v), total(&arr), total(mid));   // 150 6 90

println!("{:?} {:?}", v.first(), v.last()); // Some(10) Some(50)
let (left, right) = v.split_at(2);          // [10, 20] [30, 40, 50]
if let Some((head, tail)) = v.split_first() { println!("{head} {tail:?}"); }

for pair in v.chunks(2) { print!("{pair:?} "); }    // [10, 20] [30, 40] [50]
println!();
for w in v.windows(3) { print!("{} ", w.iter().sum::<i32>()); }   // 60 90 120
println!();

let mut nums = [5, 3, 8, 1];
let s: &mut [i32] = &mut nums[1..];
s.sort();                                   // sort part of the array
println!("{nums:?}");                       // [5, 1, 3, 8]
nums.reverse();
nums.fill(0);
println!("{}", v.contains(&30));            // true
println!("{:?}", v.iter().position(|&x| x == 40));   // Some(3)
println!("{:?}", [[1, 2], [3, 4]].concat()); // [1, 2, 3, 4]

Code Explained

&v[1..4] borrows three elements without copying
get(range) avoids a panic on bad ranges
One function accepts Vec, array and sub-slice
chunks splits into groups; windows slides an overlapping view

Coming From…

  • C++20 std::span<T> ≈ &[T]
  • Go slices, but Go slices can grow with append and share backing arrays
  • Python v[1:4] copies into a new list

The Rust Way

  • fn f(v: &Vec<i32>) → fn f(v: &[i32])
  • v[v.len() - 1] → v.last() (no panic on empty)

⚠ Common Mistakes

  • Out-of-range slicing in production code (use get)
  • Trying to push through a slice
  • Returning a slice of a local Vec (dangles: E0515)

✓ Tips & Best Practices

  • Take &[T] / return Vec<T> in APIs
  • Use chunks_exact when the remainder must be handled separately
  • Slice patterns work on slices: [first, rest @ ..]
