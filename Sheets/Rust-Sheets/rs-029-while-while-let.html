Sheet 029

while & while let

while cond · while let Some(x) = stack.pop() · counters vs iterators · continue · avoiding index loops

Conditional Loops

while repeats while a bool is true. while let repeats while a pattern matches, which is the idiomatic way to drain a stack, queue or iterator until it returns None. For walking collections, prefer for with iterators over index-based while loops.

Key Points

  • while loops have type () (no break value)
  • while let stops at the first non-matching value
  • Index loops pay a bounds check on each v[i]
  • Works with Option, Result and other enums

while and while let

let mut n = 5;
while n > 0 {
    print!("{n} ");                         // 5 4 3 2 1
    n -= 1;
}
println!();

let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    print!("{top} ");                       // 3 2 1
}
println!();

let mut it = "a,b,c".split(',');
while let Some(part) = it.next() {
    if part == "b" { continue; }
    print!("{part} ");                      // a c
}
println!();

use std::collections::VecDeque;
let mut queue = VecDeque::from([1]);
while let Some(x) = queue.pop_front() {     // breadth-first style
    if x < 8 { queue.push_back(x * 2); queue.push_back(x * 2 + 1); }
}

let mut lines = std::io::stdin().lines();
while let Some(Ok(line)) = lines.next() {   // stops at EOF or error
    if line.is_empty() { break; }
}

let mut x: u64 = 27;
let mut steps = 0;
while x != 1 { x = if x % 2 == 0 { x / 2 } else { 3 * x + 1 }; steps += 1; }
println!("{steps}");                        // 111

Code Explained

while checks the condition before each pass
while let Some(top) ends when pop returns None
The queue example processes items until empty
Nested patterns like Some(Ok(line)) work too

Coming From…

  • Python / Java while stack: / while (!stack.isEmpty())
  • C++ while (!s.empty()) { auto x = s.top(); s.pop(); }
  • Go for len(stack) > 0 { … } (no while keyword)

The Rust Way

  • while i < v.len() { v[i]; i += 1 } → for x in &v
  • loop { match it.next() { Some(x) => …, None => break } } → while let

Loop Choice

SituationUse
Walk a collectionfor x in &v
Count a rangefor i in 0..n
Until conditionwhile cond
Until Nonewhile let Some(x) = …
Forever / retryloop
Need a value outloop + break v

⚠ Common Mistakes

  • Off-by-one errors in manual index loops
  • Mutating a Vec while iterating it with for (borrow error)
  • Expecting while let to skip non-matching items (it stops)

✓ Tips & Best Practices

  • Use while let for stacks, queues and channel receivers
  • Use retain instead of removing inside a loop
  • Prefer iterator adapters for filtering

Quick Summary

  • while cond
  • while let Some(x) = …
  • stops at first mismatch
  • prefer for over index loops
