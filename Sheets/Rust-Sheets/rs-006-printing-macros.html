Sheet 006

Printing Macros

println! / print! · eprintln! / eprint! · format! · write! / writeln! · dbg! · io::Write & flush()

Output with Macros

Rust prints with macros: println! writes a line to stdout, eprintln! to stderr, and format! returns a String instead of printing. write! targets any writer, such as a file or String buffer. dbg! prints an expression with its file, line and value, then returns it.

Key Points

  • All take a format string checked at compile time
  • print! does not flush; call io::stdout().flush() before input
  • dbg! writes to stderr and takes ownership unless you pass &x
  • Printing locks stdout per call; lock once for heavy output

Output Macros

use std::io::{self, Write};
use std::fmt::Write as FmtWrite;

let name = "Ada";
let score = 92.456;

println!("Hello, {name}!");                 // Hello, Ada!
println!("{} scored {:.1}", name, score);    // Ada scored 92.5
print!("Enter value: ");
io::stdout().flush()?;                      // show prompt now
eprintln!("warning: low disk");             // stderr

let msg = format!("{name}-{}", 42);         // "Ada-42"

let mut s = String::new();
write!(s, "{}+{}", 1, 2)?;                   // write into a String
writeln!(io::stderr(), "logged")?;

let x = dbg!(score * 2.0);      // [src/main.rs:16:9] score * 2.0 = 184.912
dbg!(&msg);                                 // borrow, keep using msg

let stdout = io::stdout();
let mut out = stdout.lock();                // fast bulk output
for i in 0..3 { writeln!(out, "line {i}")?; }

Code Explained

{name} captures a variable; {} takes the next argument
flush() makes the prompt appear before waiting for input
format! builds a String with the same syntax
dbg! returns its value, so it can wrap expressions inline

Coming From…

  • C++ std::println("Hello, {}", name) (C++23) / std::format
  • Python print(f"Hello, {name}"), print(..., file=sys.stderr)
  • Java System.out.printf("%s scored %.1f%n", name, score)

The Rust Way

  • println! for debugging → dbg! (shows file, line, expression)
  • thousands of println! calls in a loop → lock stdout once

Macros

MacroTarget
print! / println!stdout
eprint! / eprintln!stderr
format!Returns String
write! / writeln!Any writer
dbg!stderr + returns value
panic!Message, then panic

⚠ Common Mistakes

  • Prompt not showing because print! was not flushed
  • Passing a value to dbg! and losing ownership (use &x)
  • Leaving dbg! calls in committed code

✓ Tips & Best Practices

  • Use inline captures {name} for readability
  • Use the log / tracing crates for real logging (sheet 100)
  • Clippy has a lint (dbg_macro) to catch leftover dbg!

Quick Summary

  • println! / eprintln!
  • format! — String
  • write! — any writer
  • dbg! — debug + return
