Sheet 007

Format Syntax

{} Display vs {:?} Debug · {:#?} pretty · inline args {name} · positional {0} · width / fill / align {:>8} {:08.2} · {:x} {:b} {:e} · {{ escaping

Formatting Values

Format strings use {} placeholders. {} uses the Display trait (user-facing text) and {:?} uses Debug (developer view, derivable). After the colon come options: fill, alignment, width, precision and type, so {:>8.2} right-aligns a number in 8 columns with 2 decimals.

Key Points

  • Order: {name:fill align sign # 0 width .precision type}
  • Width and precision can come from arguments: {:>w$}
  • #[derive(Debug)] gives any struct {:?}
  • Implement Display yourself for {} (sheet 067)

Format Options

#[derive(Debug)]
struct Point { x: i32, y: i32 }
let p = Point { x: 3, y: -4 };
let pi = 3.14159;
let n = 255;
let w = 10;

println!("{p:?}");             // Point { x: 3, y: -4 }
println!("{p:#?}");            // pretty, multi-line
println!("{0} {1} {0}", "a", "b");   // a b a
println!("[{:>8}]", "right");  // [   right]
println!("[{:<8}]", "left");   // [left    ]
println!("[{:^8}]", "mid");    // [  mid   ]
println!("[{:*^9}]", "x");     // [****x****]
println!("{:.2}", pi);         // 3.14
println!("{:08.3}", pi);       // 0003.142
println!("{:+}", 5);           // +5
println!("{n:x} {n:X} {n:#x}"); // ff FF 0xff
println!("{n:b} {n:o}");       // 11111111 377
println!("{:e}", 1234.5);      // 1.2345e3
println!("[{:>w$}]", "dyn");   // [       dyn]
println!("{{literal}}");       // {literal}

Code Explained

:? needs Debug; :#? pretty-prints it
>, <, ^ align right, left and center
08.3 pads with zeros to width 8, 3 decimals
w$ reads the width from the variable w

Coming From…

  • C++ std::format("{:>8.2f}", x) uses almost the same syntax
  • Python f-strings: f"{x:>8.2f}" (Rust's syntax is modeled on it)
  • Java String.format("%8.2f", x)

The Rust Way

  • manual padding with loops → width/fill options
  • implementing Debug by hand → #[derive(Debug)]

⚠ Common Mistakes

  • {} on a type without Display ("doesn't implement Display")
  • Expecting {:.2} to round integers (it applies to floats and strings)
  • Unescaped { in a format string

✓ Tips & Best Practices

  • Derive Debug on nearly every type
  • Implement Display for types users see
  • Use {:#?} for nested structs in logs

Quick Summary

  • {} Display · {:?} Debug
  • {:>8.2} — align, width, precision
  • {:x} / {:b} — radix
  • {{ — literal brace
