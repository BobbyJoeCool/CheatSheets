HTTP Clients with reqwest

reqwest::get · Client · .json() / .text() · POST .json(&body) · headers & timeouts · reqwest::blocking

Calling HTTP APIs

reqwest is the standard HTTP client, built on hyper and async by default. Create one Client and reuse it: it pools connections. Requests are built with method calls, sent with .send().await, and the response body is read as text, bytes or deserialized JSON via serde. A blocking API exists for simple scripts.

Key Points

  • cargo add reqwest -F json (+ tokio)
  • Non-2xx statuses are not errors until error_for_status()
  • Set timeouts on the Client builder
  • The blocking feature must not be used inside an async runtime

reqwest

use serde::{Deserialize, Serialize};
use std::time::Duration;

#[derive(Debug, Deserialize)]
struct Repo { name: String, stargazers_count: u32 }
#[derive(Serialize)]
struct NewTodo<'a> { title: &'a str, done: bool }
#[tokio::main]
async fn main() -> Result<(), reqwest::Error> {
    let body = reqwest::get("https://httpbin.org/ip").await?.text().await?;
    println!("{body}");

    let client = reqwest::Client::builder()
        .user_agent("cheatsheet-demo/1.0")
        .timeout(Duration::from_secs(10))
        .build()?;

    let repo: Repo = client
        .get("https://api.github.com/repos/rust-lang/rust")
        .header("Accept", "application/vnd.github+json")
        .send().await?
        .error_for_status()?                // 4xx/5xx → Err
        .json().await?;                     // deserialize
    println!("{} ⭐ {}", repo.name, repo.stargazers_count);

    let resp = client
        .post("https://httpbin.org/post")
        .bearer_auth("TOKEN")
        .query(&[("page", "1")])
        .json(&NewTodo { title: "write sheet", done: false })
        .send().await?;
    println!("{}", resp.status());          // 200 OK

    Ok(())
}

Code Explained

reqwest::get is a one-off shortcut
The builder sets a user agent and timeout once
error_for_status turns HTTP errors into Err
.json(&body) serializes the request; .json() parses the response

Coming From…

  • Python requests / httpx (httpx.AsyncClient ≈ reqwest Client)
  • JavaScript fetch() with await res.json()
  • Java java.net.http.HttpClient; Go net/http Client

The Rust Way

  • reqwest::get in a loop → one shared Client
  • checking only ? on send → also error_for_status()

⚠ Common Mistakes

  • Creating a new Client per request (no connection reuse)
  • Assuming a 404 returns Err from send()
  • Calling reqwest::blocking from inside Tokio (panics)

✓ Tips & Best Practices

  • Store the Client in app state and clone it (cheap Arc)
  • Use rustls-tls to avoid OpenSSL system deps
  • Add retries with reqwest-middleware / reqwest-retry

Quick Summary

  • one shared Client
  • .send().await?
  • error_for_status()
  • .json() both ways
