Iterator Adapters & Consumers

map / filter / filter_map · enumerate / zip / chain · take / skip / take_while · flat_map / flatten · peekable · fold / sum / count · collect::<Vec<_>>()

Transforming Sequences

Adapters take an iterator and return a new lazy iterator: map transforms, filter selects, filter_map does both, flat_map flattens nested results. Consumers drive the chain and produce a result: collect, sum, count, fold, min, max. collect can build a Vec, String, HashMap, HashSet or Result<Vec<_>, E>.

Key Points

  • filter closures receive &&T for iter() chains: use |&&x| or |x| **x
  • copied() / cloned() turn &T into T
  • sum and collect usually need a type annotation
  • rev needs a double-ended iterator

Adapter Chains

let nums = [1, 2, 3, 4, 5, 6, 7, 8];

let even_squares: Vec<i32> = nums.iter()
    .filter(|&&n| n % 2 == 0)
    .map(|n| n * n)
    .collect();                             // [4, 16, 36, 64]

let parsed: Vec<i32> = ["1", "x", "3"].iter()
    .filter_map(|s| s.parse().ok())
    .collect();                             // [1, 3]

let total: i32 = nums.iter().sum();         // 36
let product: i64 = (1..=10).product();      // 3628800
let odd_count = nums.iter().filter(|n| *n % 2 == 1).count();   // 4
let csv = nums.iter().map(|n| n.to_string()).collect::<Vec<_>>().join(",");

for (i, n) in nums.iter().enumerate().skip(6) { print!("{i}:{n} "); } // 6:7 7:8
let pairs: Vec<(char, i32)> = "abc".chars().zip(1..).collect();   // [('a',1),…]
let both: Vec<i32> = [1, 2].into_iter().chain([9]).collect();     // [1, 2, 9]
let head: Vec<_> = nums.iter().take_while(|&&n| n < 4).collect(); // [1, 2, 3]
let words: Vec<&str> = ["a b", "c"].iter().flat_map(|s| s.split(' ')).collect();
let flat: Vec<i32> = vec![vec![1], vec![2, 3]].into_iter().flatten().collect();

let sentence = nums.iter().fold(String::new(), |mut acc, n| {
    if !acc.is_empty() { acc.push('-'); }
    acc += &n.to_string();
    acc
});                                         // "1-2-3-4-5-6-7-8"

let mut it = [1, 1, 2, 3, 3].into_iter().peekable();
while let Some(x) = it.next() {
    if it.peek() == Some(&x) { print!("dup{x} "); }   // dup1 dup3
}
let (small, big): (Vec<i32>, Vec<i32>) = nums.into_iter().partition(|&n| n < 5);
println!("{:?}", nums.iter().max());        // Some(8)

Code Explained

filter(|&&n| …) destructures the double reference
filter_map keeps only the Some results
zip(1..) numbers items from 1
partition splits into two collections by a predicate

Coming From…

  • Java stream().filter().map().collect(Collectors.toList())
  • Python comprehensions, map, filter, itertools
  • JavaScript arr.filter().map().reduce() (eager, not lazy)

The Rust Way

  • .filter(…).map(…) with Options → filter_map
  • .map(…).flatten() → flat_map

⚠ Common Mistakes

  • filter(|n| n % 2 == 0) on &&i32 (type error: use *n or &&n)
  • Forgetting a type for collect() or sum()
  • Collecting into a Vec just to call .len() (use count())

✓ Tips & Best Practices

  • Break long chains over lines, one adapter per line
  • Use inspect(|x| dbg!(x)) to debug chains
  • Use itertools for join, group_by, sorted, unique

Quick Summary
