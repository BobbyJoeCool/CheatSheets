Rc<T> & Weak

Rc::new · Rc::clone · strong_count · single-thread shared ownership · Weak / upgrade() · reference cycles · parent pointers

Reference-Counted Shared Ownership

Rc<T> lets several owners share one read-only value on a single thread. Each Rc::clone increments a count; the value is dropped when the last owner goes away. Weak<T> is a non-owning pointer that does not keep the value alive, used for parent links and caches to avoid reference cycles, which would leak memory.

Key Points

  • Rc gives shared &T only; add RefCell for mutation
  • Rc is not Send: use Arc across threads
  • Weak::upgrade() returns Option<Rc<T>>
  • Cycles of strong Rcs are never freed

Under the Hood

  • Rc::new allocates one block: strong count, weak count, then the value
  • Rc<T> is one pointer (8 bytes); clone is a non-atomic increment
  • Drop decrements; at strong = 0 the value drops, at weak = 0 the block frees
  • Arc is the same layout with atomic counts

Rc and Weak

use std::rc::{Rc, Weak};
use std::cell::RefCell;

let shared = Rc::new(String::from("config"));
let a = Rc::clone(&shared);                 // count 2 (cheap)
let b = Rc::clone(&shared);                 // count 3
println!("{}", Rc::strong_count(&shared));  // 3
drop(a);
println!("{}", Rc::strong_count(&shared));  // 2

#[derive(Debug)]
struct Node {
    name: String,
    parent: RefCell<Weak<Node>>,            // weak: child doesn't own parent
    children: RefCell<Vec<Rc<Node>>>,       // strong: parent owns children
}
fn node(name: &str, kids: Vec<Rc<Node>>) -> Rc<Node> {
    Rc::new(Node { name: name.into(), parent: RefCell::new(Weak::new()),
                   children: RefCell::new(kids) })
}
let leaf = node("leaf", vec![]);
let branch = node("branch", vec![Rc::clone(&leaf)]);
*leaf.parent.borrow_mut() = Rc::downgrade(&branch);
if let Some(p) = leaf.parent.borrow().upgrade() {
    println!("{} -> {}", leaf.name, p.name);    // leaf -> branch
}
println!("{} {}", Rc::strong_count(&branch), Rc::weak_count(&branch));   // 1 1
drop(branch);
println!("{}", leaf.parent.borrow().upgrade().is_none());   // true

let mut unique = Rc::new(5);
*Rc::make_mut(&mut unique) += 1;            // clone-on-write if shared
println!("{:?}", Rc::try_unwrap(unique));   // Ok(6): last owner gets value

Code Explained

Rc::clone shares the same String; no copy
Children hold Weak parents, so there is no cycle
upgrade() returns None once the parent is dropped
make_mut clones only when other owners exist

Coming From…

  • C++ std::shared_ptr / std::weak_ptr (atomic counts by default)
  • Python reference counting + a cycle collector; Rust has no collector
  • Java / Go tracing GC handles cycles automatically

The Rust Way

  • shared.clone() → Rc::clone(&shared) (shows it is cheap)
  • parent and child both holding Rc → parent strong, child Weak

⚠ Common Mistakes

  • Strong cycles (parent ↔ child) leaking memory
  • Expecting Rc<T> to allow mutation (needs RefCell)
  • Sending an Rc to another thread (E0277: Rc cannot be sent)

✓ Tips & Best Practices

  • Use Rc<str> / Rc<[T]> for shared immutable data
  • Consider arena or index-based graphs (Vec<Node> + ids)
  • Use Arc only when threads are involved

Quick Summary

  • Rc<T> — shared, single thread
  • Rc::clone bumps a count
  • Weak — no ownership
  • avoid strong cycles
