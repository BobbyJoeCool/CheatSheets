Sheet 078

Writing Files

fs::write · File::create · OpenOptions (append, create) · BufWriter · write! / writeln! · flush() / sync_all

Getting Data Out

fs::write creates or truncates a file and writes everything in one call. File::create gives a handle for repeated writes; wrap it in BufWriter to batch small writes. OpenOptions controls append, create-new and truncate behavior. write!/writeln! format directly into any writer.

Key Points

  • File::create truncates an existing file
  • BufWriter flushes on drop but ignores errors there: call flush()
  • sync_all() forces data to disk
  • Write to a temp file and rename for atomic replacement

Writing

use std::fs::{self, File, OpenOptions};
use std::io::{self, BufWriter, Write};

fn main() -> io::Result<()> {
    fs::write("hello.txt", "Hello, file!\n")?;      // create or overwrite
    fs::write("data.bin", [0xDE, 0xAD, 0xBE, 0xEF])?;

    let mut f = File::create("report.txt")?;        // truncates
    writeln!(f, "Report")?;
    writeln!(f, "{:<10}{:>5}", "apples", 12)?;
    f.write_all(b"raw bytes\n")?;

    let mut log = OpenOptions::new()
        .create(true)
        .append(true)
        .open("app.log")?;                         // append mode
    writeln!(log, "started")?;

    let out = File::create("numbers.csv")?;
    let mut w = BufWriter::new(out);                // batch small writes
    for i in 0..10_000 {
        writeln!(w, "{i},{}", i * i)?;
    }
    w.flush()?;                                     // surface write errors

    match OpenOptions::new().write(true).create_new(true).open("once.lock") {
        Ok(_) => println!("created lock"),
        Err(e) if e.kind() == io::ErrorKind::AlreadyExists => println!("busy"),
        Err(e) => return Err(e),
    }

    let tmp = "config.toml.tmp";                    // atomic replace
    fs::write(tmp, "port = 8080\n")?;
    fs::rename(tmp, "config.toml")?;

    let f2 = File::create("important.dat")?;
    f2.sync_all()?;                                 // fsync to disk
    Ok(())
}

Code Explained

fs::write takes any bytes or string
writeln! formats straight into the file
OpenOptions with append(true) adds to the end
Write-then-rename keeps readers from seeing half a file

Coming From…

  • Python open(p, "w") / "a" modes with with
  • Java Files.writeString, BufferedWriter, StandardOpenOption.APPEND
  • Go os.WriteFile, os.OpenFile(p, os.O_APPEND|…), bufio.Writer

The Rust Way

  • many write! calls on a raw File → BufWriter
  • relying on drop to flush → call flush() and check it

OpenOptions

OptionEffect
read(true)Readable
write(true)Writable
append(true)Write at end
truncate(true)Empty first
create(true)Create if missing
create_new(true)Fail if exists

Write Calls

CallUse
fs::write(p, data)Whole file
f.write_all(&bytes)All bytes

⚠ Common Mistakes

  • Forgetting flush() on BufWriter and losing errors
  • Using write instead of write_all (may write partially)
  • Opening with File::create when appending was intended

✓ Tips & Best Practices

  • Use temp file + rename for config and state files
  • Use create_new(true) for lock files
  • Use tempfile crate for scratch files

Quick Summary

  • fs::write — one call
  • File::create truncates
  • OpenOptions — append / create_new
  • BufWriter + flush()
