Sheet 072

Box<T>

Box::new · heap allocation · recursive types · Box<dyn Trait> · Box<[T]> · moving out of a box

Owning Heap Pointer

Box<T> puts a value on the heap and owns it: when the Box is dropped, the value is dropped and the memory freed. Use it for recursive types (whose size would otherwise be infinite), trait objects (Box<dyn Trait>), and moving large values cheaply. A Box derefs to T, so you use it almost like the value itself.

Key Points

  • *b moves the value out of a Box (for owned boxes)
  • Box<[T]> / Box<str> are fixed-size heap buffers
  • Box has no runtime overhead beyond the allocation
  • Box::leak gives a &'static mut T (memory never freed)

Under the Hood

  • Box<T> is a single non-null pointer (8 bytes); Box<dyn T> / Box<[T]> are fat (16)
  • Option<Box<T>> uses the null niche: still 8 bytes
  • Box::new(x) may build x on the stack, then copy it to the heap
  • Drop calls T::drop, then frees with the global allocator

Using Box

let b = Box::new(5);                        // i32 on the heap
println!("{}", *b + 1);                     // 6
println!("{}", b);                          // Display passes through: 5

#[derive(Debug)]
enum List { Cons(i32, Box<List>), Nil }    // recursive: needs indirection
use List::{Cons, Nil};
let list = Cons(1, Box::new(Cons(2, Box::new(Nil))));
println!("{list:?}");                       // Cons(1, Cons(2, Nil))

#[derive(Debug)]
struct Node { val: i32, left: Option<Box<Node>>, right: Option<Box<Node>> }
let leaf = |v| Some(Box::new(Node { val: v, left: None, right: None }));
let root = Node { val: 2, left: leaf(1), right: leaf(3) };
fn sum(n: &Option<Box<Node>>) -> i32 {
    n.as_ref().map_or(0, |b| b.val + sum(&b.left) + sum(&b.right))
}
println!("{}", root.val + sum(&root.left) + sum(&root.right));   // 6

trait Animal { fn speak(&self) -> &str; }
struct Cat;
impl Animal for Cat { fn speak(&self) -> &str { "meow" } }
let pet: Box<dyn Animal> = Box::new(Cat);
println!("{}", pet.speak());

let big = Box::new([0u8; 1_000_000]);       // 1 MB moved by pointer, not copied
let moved = big;                            // copies 8 bytes

let s: Box<str> = "fixed".into();           // no spare capacity
let v: Box<[i32]> = vec![1, 2, 3].into_boxed_slice();
let inner: i32 = *Box::new(7);              // move out of the box
let forever: &'static mut Vec<u8> = Box::leak(Box::new(Vec::new()));

Code Explained

*b reads through the Box; Display works directly
Box<List> gives the enum a known size
Trees use Option<Box<Node>> for optional children
Moving a Box copies only the pointer

Coming From…

  • C++ std::unique_ptr<T> (same ownership semantics)
  • Java / Python / Go every object is already heap-allocated and GC-managed
  • C malloc + free, done automatically by Box's drop

The Rust Way

  • Box<Vec<T>> → Vec<T> (already on the heap)
  • Box<T> for small Copy values → plain T

⚠ Common Mistakes

  • Boxing everything out of habit
  • Recursive struct without Box (E0072: recursive type has infinite size)
  • Very large Box::new([0; N]) overflowing the stack first (use vec!)

✓ Tips & Best Practices

  • Use vec![0; n].into_boxed_slice() for big zeroed buffers
  • Box the largest enum variant to shrink the enum
  • Prefer Box<dyn Error + Send + Sync> in threaded code
