Methods & impl Blocks

impl · &self / &mut self / self · associated functions new() · Self · multiple impl blocks · auto-ref on method calls

Behavior for Your Types

Methods live in impl blocks. The first parameter decides access: &self reads, &mut self modifies, self consumes the value. Functions without self are associated functions, called with Type::name(), and new is the conventional constructor. Self refers to the type being implemented.

Key Points

  • p.area() auto-borrows: same as Point::area(&p)
  • There are no constructors; new is just a convention
  • A type can have many impl blocks
  • Methods consuming self suit builders and conversions

impl Blocks

#[derive(Debug)]
struct Rect { w: f64, h: f64 }

impl Rect {
    pub fn new(w: f64, h: f64) -> Self { Self { w, h } }   // associated fn
    pub fn square(s: f64) -> Self { Self::new(s, s) }

    pub fn area(&self) -> f64 { self.w * self.h }          // read
    pub fn scale(&mut self, k: f64) { self.w *= k; self.h *= k; }   // modify
    pub fn into_tuple(self) -> (f64, f64) { (self.w, self.h) }    // consume

    pub fn fits_in(&self, other: &Rect) -> bool {
        self.w <= other.w && self.h <= other.h
    }
}

impl Rect {                                 // a second impl block is fine
    pub const UNIT: Rect = Rect { w: 1.0, h: 1.0 };   // associated const
}

let mut r = Rect::new(3.0, 4.0);
println!("{}", r.area());                   // 12
r.scale(2.0);                               // auto &mut r
println!("{:?}", r);                        // Rect { w: 6.0, h: 8.0 }
println!("{}", Rect::square(2.0).fits_in(&r));   // true
println!("{}", Rect::area(&Rect::UNIT));    // 1: explicit form

let t = r.into_tuple();                     // r moved
// r.area();                                // E0382: borrow of moved value

struct Counter { n: u32 }
impl Counter {
    fn tick(&mut self) -> &mut Self { self.n += 1; self }   // chainable
}
let mut c = Counter { n: 0 };
c.tick().tick().tick();
println!("{}", c.n);                        // 3

Code Explained

new and square are called with Rect::
r.scale(2.0) borrows r mutably automatically
into_tuple(self) consumes the Rect
Returning &mut Self allows method chaining

Coming From…

  • C++ / Java methods inside the class body; this is implicit
  • Python def area(self) with explicit self, like Rust
  • Go methods with receivers: func (r *Rect) Scale(k float64)

The Rust Way

  • fn get_area(&self) → fn area(&self) (no get_ prefix)
  • new() with no arguments → also implement Default

⚠ Common Mistakes

  • Calling a &mut self method on an immutable binding
  • Using self when &self would do (moves the caller's value)
  • Expecting new to be special

✓ Tips & Best Practices

  • Name conversions into_* (consume), as_* (borrow), to_* (copy)
  • Return Self from constructors
  • Group methods into several impl blocks by topic
