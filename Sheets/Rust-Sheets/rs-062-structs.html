Sheet 062

Structs

named-field structs · tuple structs · unit structs · field init shorthand · struct update ..other · #[derive(Debug)]

Grouping Data

A struct groups named fields into a new type. Tuple structs have unnamed fields (struct Meters(f64)) and are ideal for newtypes. Unit structs have no fields and serve as markers. All fields must be initialized, and the whole instance is either mutable or immutable.

Key Points

  • Field init shorthand: User { name, age }
  • Struct update ..other copies or moves remaining fields
  • Mutability applies to the whole binding, not single fields
  • Derive common traits: Debug, Clone, PartialEq

Defining Structs

#[derive(Debug, Clone, PartialEq)]
struct User {
    name: String,
    email: String,
    age: u32,
    active: bool,
}

struct Meters(f64);                         // tuple struct (newtype)
struct Rgb(u8, u8, u8);
struct Marker;                              // unit struct

fn new_user(name: String, email: String) -> User {
    User { name, email, age: 0, active: true }   // field init shorthand
}

let mut u = new_user("Ada".into(), "ada@x.io".into());
u.age = 36;                                 // whole binding is mut
println!("{} {}", u.name, u.age);           // Ada 36
println!("{u:?}");                          // User { name: "Ada", … }

let u2 = User { email: "bob@x.io".into(), ..u.clone() };   // rest from u
let User { name, age, .. } = &u2;           // destructure
println!("{name} {age}");                   // Ada 36

let d = Meters(42.5);
let c = Rgb(255, 128, 0);
println!("{} {}", d.0, c.1);                // 42.5 128
let Rgb(r, g, b) = c;

let _m = Marker;
println!("{}", std::mem::size_of::<Marker>());   // 0

let p = (u.name.clone(), u.age);            // tuple vs struct: names win
let same = u == u.clone();                  // PartialEq derived: true

Code Explained

Every field must be set when creating a struct
..u.clone() fills the remaining fields
Tuple structs access fields by position
A unit struct takes zero bytes

Coming From…

  • C++ struct with public members; Rust fields are private outside the module
  • Java record User(String name, …) ≈ derive Debug/Clone/PartialEq
  • Python @dataclass; Go type User struct { … }

The Rust Way

  • let x = Point { x: x, y: y } → Point { x, y }
  • raw f64 for distances → newtype Meters(f64)

⚠ Common Mistakes

  • Making one field mut (not possible: use the whole binding or Cell)
  • ..other moving a String out of other and then using it
  • Forgetting #[derive(Debug)] before printing with {:?}

✓ Tips & Best Practices

  • Use newtypes to prevent mixing units and IDs
  • Implement Default and use ..Default::default()
  • Keep fields private and expose methods (sheet 084)
