Sheet 012

Floating-Point Numbers

f32 / f64 · f64::NAN / INFINITY · is_nan() · total_cmp · round / floor / ceil / trunc · powi / powf / sqrt · f64::EPSILON

IEEE 754 Floats

Rust has f32 and f64 (the default). Math functions are methods on the value: x.sqrt(), x.powi(2), x.round(). Floats implement only PartialEq/PartialOrd because NaN is not equal to itself, so they cannot be sorted with plain sort() or used as HashMap keys.

Key Points

  • 2.0 is f64; write 2.0_f32 for f32
  • No implicit int ↔ float conversion
  • total_cmp gives a full ordering for sorting
  • Use integers (cents) or a decimal crate for money

Float Methods

let x = 2.0_f64;
let y: f32 = 1.5;

println!("{}", x.sqrt());              // 1.4142135623730951
println!("{}", x.powi(10));            // 1024
println!("{}", x.powf(0.5));           // 1.414…
println!("{}", 2.567_f64.round());     // 3
println!("{}", (-2.5_f64).round());    // -3 (half away from zero)
println!("{}", 2.7_f64.floor());       // 2
println!("{}", 2.1_f64.ceil());        // 3
println!("{}", (-2.7_f64).trunc());    // -2
println!("{:.2}", 3.14159);            // 3.14
println!("{}", 0.1 + 0.2 == 0.3);      // false
println!("{}", (0.1_f64 + 0.2 - 0.3).abs() < f64::EPSILON);   // true

let nan = f64::NAN;
println!("{}", nan == nan);            // false
println!("{}", nan.is_nan());          // true
println!("{}", 1.0 / 0.0);             // inf

let mut v = vec![2.5_f64, -1.0, 9.0];
// v.sort();                           // error: f64 is not Ord
v.sort_by(|a, b| a.total_cmp(b));      // [-1.0, 2.5, 9.0]
println!("{}", v.iter().cloned().fold(f64::MIN, f64::max));   // 9

Code Explained

Math functions are methods on f64/f32
round rounds half away from zero
Compare floats with a tolerance
total_cmp sorts floats, placing NaN consistently

Coming From…

  • C++ std::sqrt(x), std::round(x); floats are not totally ordered either
  • Java Math.sqrt(x); Double.compare for sorting
  • Python math.sqrt(x); round(2.5) is 2 (banker's)

The Rust Way

  • partial_cmp(...).unwrap() in sorts → total_cmp
  • f64 for money → integer cents or rust_decimal

⚠ Common Mistakes

  • Calling sqrt(x) as a free function (it is x.sqrt())
  • Sorting or deduping floats with Ord-based methods
  • 2.0 * 3 (int literal with float: write 3.0)

✓ Tips & Best Practices

  • Prefer f64 unless memory or GPU work needs f32
  • Use ordered-float crate for float keys
  • Use {:.N} only for display, not rounding stored values

Quick Summary

  • f64 default
  • methods: x.sqrt(), x.round()
  • NaN ≠ NaN → no Ord
  • total_cmp — sort floats
