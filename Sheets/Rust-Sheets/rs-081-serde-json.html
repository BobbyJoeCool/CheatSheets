Serde & JSON

#[derive(Serialize, Deserialize)] · serde_json::to_string_pretty · from_str · Value / json! · #[serde(rename_all, default, skip)] · TOML / CSV via serde

Serialization Framework

Serde converts Rust types to and from data formats. Derive Serialize and Deserialize on your structs, then use a format crate: serde_json, toml, serde_yaml, csv. Attributes rename fields, supply defaults and skip values. For unknown shapes, serde_json::Value holds any JSON.

Key Points

  • cargo add serde -F derive and cargo add serde_json
  • Missing fields are errors unless Option or #[serde(default)]
  • Unknown fields are ignored unless deny_unknown_fields
  • Enums serialize as externally tagged by default

Serde

use serde::{Deserialize, Serialize};
use serde_json::{json, Value};

#[derive(Debug, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
struct User {
    user_id: u64,
    display_name: String,
    #[serde(default)]
    tags: Vec<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    email: Option<String>,
    #[serde(skip)]
    cache: u32,
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let input = r#"{"userId": 7, "displayName": "Ada", "extra": true}"#;
    let u: User = serde_json::from_str(input)?;     // tags → [], email → None
    println!("{u:?}");

    let out = serde_json::to_string(&u)?;
    println!("{out}");          // {"userId":7,"displayName":"Ada","tags":[]}
    println!("{}", serde_json::to_string_pretty(&u)?);

    let v: Value = serde_json::from_str(r#"{"a": {"b": [1, 2, 3]}}"#)?;
    println!("{}", v["a"]["b"][1]);                 // 2

    let doc = json!({ "name": "Ferris", "langs": ["rust"], "age": 9 });
    #[derive(Deserialize)]
    struct Config { port: u16, debug: bool }
    let cfg: Config = toml::from_str("port = 8080\ndebug = true")?;
    Ok(())
}

Code Explained

rename_all = "camelCase" maps user_id ↔ userId
#[serde(default)] fills missing fields
Value indexing returns Null for missing keys
The same derive works with toml and other formats

Coming From…

  • Python json.loads / json.dumps; Pydantic for typed models
  • Java Jackson annotations (@JsonProperty, @JsonIgnore)
  • Go encoding/json with struct tags json:"userId"

The Rust Way

  • navigating Value everywhere → typed structs with derive
  • manual field renames → #[serde(rename_all = …)]

⚠ Common Mistakes

  • Forgetting features = ["derive"] on serde
  • Expecting missing JSON fields to default without default
  • Indexing Value and unwrapping types blindly

✓ Tips & Best Practices

  • Use Option<T> for truly optional fields
  • Use serde_with for custom formats (dates as strings, etc.)
  • Deserialize borrowed data with &'a str fields for zero-copy
