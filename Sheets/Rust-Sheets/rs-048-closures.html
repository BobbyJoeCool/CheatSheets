Closures

Anonymous Functions That Capture

A closure is an anonymous function written |args| body that can capture variables from its surroundings. The compiler picks the least intrusive capture: borrow, mutable borrow, or move. The move keyword forces captured values to move into the closure, which is required for threads and returning closures.

Key Points

  • Parameter and return types are usually inferred
  • Once inferred, a closure's types are fixed
  • Each closure has its own unique, unnamed type
  • Edition 2021 captures individual fields, not whole structs

Under the Hood

  • A closure compiles to an anonymous struct holding its captures
  • Calling it is a direct call to a method on that struct (inlinable)
  • A closure with no captures is zero-sized and coerces to a fn pointer
  • move changes captures from references to owned fields

Closures

let add_one = |x: i32| x + 1;
let square = |x| x * x;                     // inferred from first use
println!("{} {}", add_one(4), square(5));   // 5 25

let factor = 3;
let scale = |x: i32| x * factor;            // borrows factor
println!("{}", scale(10));                  // 30

let mut count = 0;
let mut inc = || count += 1;                // mutable borrow
inc();
inc();
println!("{count}");                        // 2

let name = String::from("Ada");
let greet = move || println!("hi {name}");  // name moved in
greet();
// println!("{name}");                      // E0382: moved into closure

let nums = vec![1, 2, 3, 4, 5, 6];
let threshold = 3;
let big: Vec<i32> = nums.iter().copied().filter(|&n| n > threshold).collect();
let mut sorted = vec!["bb", "a", "ccc"];
sorted.sort_by_key(|s| s.len());            // ["a", "bb", "ccc"]

let handle = std::thread::spawn(move || nums.len());   // move required
println!("{}", handle.join().unwrap());     // 6

let multi_line = |a: i32, b: i32| -> i32 {
    let s = a + b;
    s * 2
};
println!("{}", multi_line(1, 2));           // 6

Code Explained

|x| x * x gets its type from the first call
scale borrows factor; inc borrows count mutably
move transfers name into the closure
Threads require move because they may outlive the scope

Coming From…

  • C++ lambdas with explicit capture lists [&], [=], [x = std::move(x)]
  • Java / JavaScript lambdas / arrow functions capture effectively-final or any variables
  • Python lambda x: x + 1 (single expression only)

The Rust Way

  • .map(|x| foo(x)) → .map(foo)
  • clone() before a move closure only when the original is still needed

⚠ Common Mistakes

  • Calling a mutating closure without declaring it mut
  • Using a variable after moving it into a move closure
  • Calling one closure with two different argument types

✓ Tips & Best Practices

  • Pass function names directly when no capture is needed
  • Clone into a new binding just before move to keep the original
  • Keep closures short; name complex ones as functions

Quick Summary

  • |args| body
  • captures by ref, mut ref or value
  • move — take ownership
  • unique type per closure
