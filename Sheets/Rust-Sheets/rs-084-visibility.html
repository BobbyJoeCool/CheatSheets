Visibility

private by default · pub · pub(crate) / pub(super) · struct field visibility · public enum variants · API surface design

Controlling Access

Everything is private to its module (and that module's children) by default. pub makes an item visible to anyone who can see its parent, pub(crate) limits it to the current crate and pub(super) to the parent module. Struct fields are private individually; enum variants are public whenever the enum is.

Key Points

  • A pub struct with private fields cannot be built outside its module
  • Private fields protect invariants: expose constructors and getters
  • Child modules can see their ancestors' private items
  • #[non_exhaustive] stops outside code from matching exhaustively

Visibility Levels

mod bank {
    pub struct Account {
        pub owner: String,                  // readable and writable outside
        balance: i64,                       // private: protects the invariant
    }

    impl Account {
        pub fn new(owner: &str) -> Self {
            Account { owner: owner.into(), balance: 0 }
        }
        pub fn balance(&self) -> i64 { self.balance }   // getter
        pub fn deposit(&mut self, amt: i64) -> Result<(), String> {
            if amt <= 0 { return Err("amount must be positive".into()); }
            self.balance += amt;
            audit::log(amt);
            Ok(())
        }
    }

    pub enum Kind { Checking, Savings }     // variants public automatically
    pub(crate) fn internal_rate() -> f64 { 0.02 }   // crate-wide only

    mod audit {
        pub(super) fn log(amt: i64) { println!("audit {amt}"); } // parent only
    }
}

use bank::Account;
let mut acct = Account::new("Ada");
acct.deposit(50).unwrap();
println!("{} {}", acct.owner, acct.balance());   // Ada 50
// acct.balance = 1_000_000;                // E0616: field `balance` is private
// let a = Account { owner: "x".into(), balance: 5 };   // E0451: private field
let k = bank::Kind::Savings;
println!("{}", bank::internal_rate());
// bank::audit::log(1);                     // E0603: module `audit` is private

Code Explained

balance can only change through deposit
pub(crate) hides internal_rate from other crates
pub(super) lets only bank call audit::log
Private fields block struct literals outside the module

Coming From…

  • Java public / package-private / private; pub(crate) ≈ package-private
  • C++ public / private / protected, per class not per module
  • Go capitalized = exported; Python _name by convention only

The Rust Way

  • all fields pub on a type with invariants → private fields + methods
  • pub helpers used only inside the crate → pub(crate)

⚠ Common Mistakes

  • Making every field pub and losing control of invariants
  • Expecting pub items in a private module to be reachable
  • Exposing internal types in public function signatures (warning: private type in public API)

✓ Tips & Best Practices

  • Start private; open up as needed
  • Use pub(crate) for internal APIs
  • Review your public surface with cargo doc

Quick Summary

  • private by default
  • pub / pub(crate) / pub(super)
  • fields private per field
  • enum variants follow the enum
