Default Methods, derive & Supertraits

default method bodies · overriding defaults · #[derive(…)] · supertraits trait A: B · blanket impls · marker traits

Reusing Trait Code

Trait methods can have default bodies that implementors get for free or override. #[derive] generates impls of standard traits automatically. A supertrait (trait Pretty: Display) requires implementors to also implement another trait. Blanket impls implement a trait for every type meeting a bound.

Key Points

  • Default methods can call required methods
  • #[derive] works for Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, Default
  • Marker traits have no methods (Copy, Send, Eq)
  • std has blanket impls like impl<T: Display> ToString for T

Defaults, Supertraits, Blanket Impls

use std::fmt::Display;

trait Greet {
    fn name(&self) -> String;               // required
    fn hello(&self) -> String {             // default body
        format!("Hello, {}!", self.name())
    }
}

struct En; struct Es;
impl Greet for En { fn name(&self) -> String { "Ada".into() } }
impl Greet for Es {
    fn name(&self) -> String { "Ana".into() }
    fn hello(&self) -> String { format!("¡Hola, {}!", self.name()) } // override
}
println!("{} {}", En.hello(), Es.hello());  // Hello, Ada! ¡Hola, Ana!

trait Labeled: Display {                    // supertrait
    fn label(&self) -> String { format!("<{self}>") }   // can use Display
}
struct Tag(&'static str);
impl Display for Tag {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        write!(f, "{}", self.0)
    }
}
impl Labeled for Tag {}                     // all defaults
println!("{}", Tag("new").label());         // <new>

trait Shout { fn shout(&self) -> String; }
impl<T: Display> Shout for T {              // blanket impl
    fn shout(&self) -> String { self.to_string().to_uppercase() }
}
println!("{} {}", "hi".shout(), 42_i32.shout());   // HI 42

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, Default)]
struct Id(u32);
println!("{:?} {}", Id::default(), Id(1) < Id(2));   // Id(0) true

Code Explained

En uses the default hello; Es overrides it
Labeled: Display lets its default use {self}
The blanket impl gives shout to every Display type
One derive line generates nine trait impls

Coming From…

  • Java default interface methods; interfaces can extend interfaces
  • C++ base classes with virtual functions and default implementations
  • Python mixins and ABCs with concrete methods

The Rust Way

  • copy-pasted method bodies across impls → a default method
  • hand-written PartialEq/Hash matching fields → #[derive]

⚠ Common Mistakes

  • Overlapping blanket impls (E0119: conflicting implementations)
  • Deriving Eq on a struct with f64 fields (not allowed)
  • Forgetting to implement the supertrait first

✓ Tips & Best Practices

  • Put shared logic in default methods built on a few required ones
  • Derive generously on data types
  • Add blanket impls carefully in libraries: they limit future impls
