HashSet & BTreeSet

HashSet · BTreeSet · insert returns bool · union / intersection / difference / symmetric_difference · is_subset · dedup via collect

Collections of Unique Values

A set stores each value at most once. HashSet has O(1) average operations with no order, and BTreeSet keeps values sorted. insert returns false when the value was already present, which makes "have I seen this?" checks one call. Set operations return lazy iterators.

Key Points

  • Same key rules as maps: Eq + Hash or Ord
  • Operators work on references: &a | &b, &a & &b, &a - &b
  • collect::<HashSet<_>>() removes duplicates
  • contains takes a borrowed value

Sets

use std::collections::{BTreeSet, HashSet};

let mut seen = HashSet::new();
for x in [3, 1, 3, 2, 1] {
    if !seen.insert(x) { print!("dup {x} "); }   // dup 3 dup 1
}
println!("{}", seen.len());                 // 3

let a: HashSet<i32> = [1, 2, 3, 4].into();
let b: HashSet<i32> = [3, 4, 5].into();

let mut u: Vec<_> = a.union(&b).copied().collect();
u.sort();                                   // [1, 2, 3, 4, 5]
let i: HashSet<_> = a.intersection(&b).collect();   // {3, 4}
let d: HashSet<_> = &a - &b;                // {1, 2}
let x: HashSet<_> = &a ^ &b;                // {1, 2, 5}
println!("{:?}", u);

println!("{}", a.contains(&2));             // true
let small: HashSet<i32> = [3, 4].into();
println!("{}", small.is_subset(&a));        // true
println!("{}", a.is_disjoint(&HashSet::from([9])));   // true

let words = ["pear", "apple", "pear", "fig"];
let unique: BTreeSet<&str> = words.into_iter().collect();
println!("{unique:?}");                     // {"apple", "fig", "pear"}
println!("{:?}", unique.first());           // Some("apple")

let mut tags = HashSet::from(["rust".to_string()]);
println!("{}", tags.contains("rust"));      // &str lookup on String set
tags.remove("rust");
tags.retain(|t| t.len() > 3);

Code Explained

insert returns false for values already in the set
Set methods borrow both sets and yield references
&a - &b builds a new set with the difference
Collecting into a BTreeSet dedups and sorts

Coming From…

  • Python set with |, &, -, ^ operators
  • Java HashSet / TreeSet with retainAll, removeAll
  • Go no set type; map[T]struct{}

The Rust Way

  • if !v.contains(&x) { v.push(x) } on a Vec → HashSet
  • contains check then insert → just check insert's return value

⚠ Common Mistakes

  • Expecting a HashSet to print in order
  • Calling contains then insert (two lookups)
  • Storing f64 values (not Hash)

✓ Tips & Best Practices

  • Use a BTreeSet for sorted unique output
  • Collect into a set to dedup without sorting
  • Use HashSet<&str> to dedup borrowed text cheaply

Quick Summary

  • unique values
