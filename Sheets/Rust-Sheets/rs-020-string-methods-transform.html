String Methods — Transform & Split

to_uppercase / to_lowercase · trim family · replace / replacen · split / split_whitespace / lines · split_once · repeat · join / concat

Changing and Splitting Text

Transforming methods like to_uppercase and replace return a new String. Trimming and splitting return slices (&str) that borrow from the original, so they cost nothing until you collect or convert them. split_once is the handy way to split key=value pairs.

Key Points

  • trim returns &str (no allocation)
  • split returns a lazy iterator
  • split_whitespace handles runs of spaces and tabs
  • lines handles both \n and \r\n

Transform and Split

let s = "  Hello, Rust!  ";
println!("[{}]", s.trim());                  // [Hello, Rust!]
println!("[{}]", s.trim_start());            // [Hello, Rust!  ]
println!("{}", "xxabcxx".trim_matches('x'));  // abc
println!("{}", "Rust".to_uppercase());       // RUST
println!("{}", "a-b-c".replace('-', "+"));   // a+b+c
println!("{}", "a-b-c".replacen('-', "", 1)); // ab-c
println!("{}", "ab".repeat(3));              // ababab

let parts: Vec<&str> = "a,b,,c".split(',').collect();   // ["a", "b", "", "c"]
let words: Vec<&str> = " one  two\tthree ".split_whitespace().collect();
                                             // ["one", "two", "three"]
let n = "k=v=w".splitn(2, '=').collect::<Vec<_>>();     // ["k", "v=w"]
println!("{:?}", "user=ada".split_once('='));   // Some(("user", "ada"))
println!("{:?}", "a/b/c".rsplit_once('/'));     // Some(("a/b", "c"))

for line in "one\ntwo\r\nthree".lines() { print!("{line} "); } // one two three

let csv = ["x", "y", "z"].join(",");         // "x,y,z"
let glued = ["ab", "cd"].concat();           // "abcd"
let title: String = "rust".chars().enumerate()
    .map(|(i, c)| if i == 0 { c.to_ascii_uppercase() } else { c })
    .collect();                              // "Rust"

Code Explained

trim variants return slices of the original
replacen limits the number of replacements
split_once returns both halves as an Option
Mapping over chars and collecting builds a new String

Coming From…

  • Python strip, split, partition, "sep".join(list)
  • Java strip(), split(regex), String.join
  • Go strings.TrimSpace, strings.Fields, strings.Cut

The Rust Way

  • s.split("=").collect::<Vec<_>>()[1] → s.split_once('=')
  • s.split(" ") on user input → split_whitespace()

⚠ Common Mistakes

  • Expecting split(' ') to collapse repeated spaces
  • Forgetting that to_uppercase allocates a new String
  • [1] on a split Vec that may have one element (panics)

✓ Tips & Best Practices

  • Keep data as &str slices until you need to own it
  • Use split_once for headers, env vars and config lines
  • Use str::parse right after splitting numbers

Quick Summary
