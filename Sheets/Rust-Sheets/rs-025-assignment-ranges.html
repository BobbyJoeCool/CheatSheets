Assignment and Range Expressions

Assignment = is an expression of type (), so a = b = c does not chain. Compound operators modify in place. Ranges are values: a..b excludes the end, a..=b includes it, and open forms a.., ..b and .. are used for slicing. Ranges are iterators, so they work in for loops and adapter chains.

Key Points

  • Assignment returns () (no if (x = 5) bugs)
  • Destructuring assignment: (a, b) = (b, a)
  • step_by(n) skips; rev() counts down
  • Ranges in patterns: 1..=9

Assignment and Ranges

let mut x = 10;
x += 5;   x -= 3;   x *= 2;   x /= 4;   x %= 4;
println!("{x}");                            // 2
let mut bits = 0b0001u8;
bits <<= 3;                                 // 0b1000

let (mut a, mut b) = (1, 2);
(a, b) = (b, a);                            // swap via destructuring
println!("{a} {b}");                        // 2 1

for i in 0..3 { print!("{i} "); }           // 0 1 2
for i in 1..=3 { print!("{i} "); }          // 1 2 3
for i in (0..10).step_by(3) { print!("{i} "); }   // 0 3 6 9
for i in (1..=3).rev() { print!("{i} "); }  // 3 2 1
println!();

let r = 1..=10;
println!("{}", r.contains(&5));             // true
println!("{}", (1..5).len());               // 4
println!("{}", (1..=100).sum::<i32>());     // 5050
let evens: Vec<_> = (0..10).filter(|n| n % 2 == 0).collect();

let v = [10, 20, 30, 40, 50];
println!("{:?}", &v[1..3]);                 // [20, 30]
println!("{:?}", &v[..2]);                  // [10, 20]
println!("{:?}", &v[3..]);                  // [40, 50]
println!("{:?}", &v[..]);                   // all
let letters: String = ('a'..='e').collect(); // "abcde"

Code Explained

Compound operators update x in place
Tuples allow swapping without a temp variable
step_by and rev adapt the range iterator
Open ranges slice from the start or to the end

Coming From…

  • Python range(0, 10, 3); v[1:3], v[3:]
  • Go v[1:3] slices; for i := range 10 (Go 1.22)
  • Kotlin / Swift 1..3 is inclusive; Rust uses ..=

The Rust Way

  • for i in 0..v.len() { v[i] } → for x in &v
  • (0..n).rev() instead of manual countdown with while

⚠ Common Mistakes

  • 1..10 expecting 10 to be included
  • a = b = 0 (assigns () to a: type error)
  • (0..10).step_by(0) panics

✓ Tips & Best Practices

  • Use ..= for "through" ranges like dice rolls
  • Pass ranges to drain, replace_range and slices
  • Ranges of chars work: 'a'..='z'

Quick Summary

  • = returns ()
  • compound ops in place
  • .. exclusive · ..= inclusive
  • step_by / rev
