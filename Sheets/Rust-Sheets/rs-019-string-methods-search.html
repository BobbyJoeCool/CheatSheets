String Methods — Search & Inspect

len() (bytes) · is_empty() · contains · starts_with / ends_with · find / rfind · matches · strip_prefix / strip_suffix

Inspecting Text

Search methods live on str, so they work on both String and &str. They accept a pattern: a &str, a char, a slice of chars or a closure. find returns Option<usize> with a byte index, and len() counts bytes, not characters.

Key Points

  • Patterns: "ab", 'a', ['a', 'b'], char::is_numeric
  • strip_prefix returns Option<&str>
  • Byte indexes from find are safe to slice with
  • Use the regex crate for regular expressions

Search Methods

let s = "Hello, Rust world";

println!("{}", s.len());                    // 17 (bytes)
println!("{}", "".is_empty());              // true
println!("{}", s.contains("Rust"));         // true
println!("{}", s.contains(char::is_numeric));   // false
println!("{}", s.starts_with("Hell"));      // true
println!("{}", s.ends_with('d'));           // true
println!("{:?}", s.find('o'));              // Some(4)
println!("{:?}", s.rfind('o'));             // Some(13)
println!("{:?}", s.find("xyz"));            // None
println!("{:?}", s.find([',', ' ']));       // Some(5)
println!("{}", s.matches('o').count());     // 2
println!("{:?}", s.match_indices("l").map(|(i, _)| i).collect::<Vec<_>>());
                                            // [2, 3, 15]

if let Some(i) = s.find(',') {
    println!("{}", &s[..i]);                // Hello
}
println!("{:?}", "v1.2".strip_prefix('v'));  // Some("1.2")
println!("{:?}", "v1.2".strip_prefix('x'));  // None
println!("{:?}", "a.txt".strip_suffix(".txt"));   // Some("a")
println!("{}", "café".len());               // 5 (é is 2 bytes)
println!("{}", "Abc".eq_ignore_ascii_case("aBC"));   // true

Code Explained

len() counts UTF-8 bytes
Patterns can be chars, strings, arrays of chars or functions
find gives a byte index you can slice with
strip_prefix both checks and removes

Coming From…

  • Python in, startswith, find (returns -1, not None)
  • Java contains, indexOf (returns -1)
  • Go strings.Contains, strings.Index, strings.TrimPrefix

The Rust Way

  • if s.starts_with(p) { &s[p.len()..] } → s.strip_prefix(p)
  • s.len() == 0 → s.is_empty()

⚠ Common Mistakes

  • Treating len() as a character count
  • Expecting -1 from find (it returns None)
  • Building a byte index by counting chars and slicing (can panic)

✓ Tips & Best Practices

  • Use chars().count() for a character count
  • Use eq_ignore_ascii_case for ASCII comparisons
  • Reach for regex only when simple patterns are not enough

Quick Summary

  • len() — bytes
  • find → Option<usize>
  • patterns: &str, char, fn
  • strip_prefix → Option
