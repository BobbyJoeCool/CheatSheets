Introduction & History

Mozilla Research, 2010 · Graydon Hoare · 1.0 in May 2015 · Rust Foundation (2021) · memory safety without GC · zero-cost abstractions

Fast, Safe Systems Programming

Rust started as Graydon Hoare's project, was sponsored by Mozilla Research from 2009–2010, and reached 1.0 in May 2015. It gives C/C++-level speed with memory safety enforced at compile time by the borrow checker, with no garbage collector. Today it runs in Linux, Windows, Android, browsers, cloud infrastructure and CLI tools.

Key Points

  • Source files: .rs; packages are crates built with Cargo
  • New stable release every 6 weeks; editions (2015, 2018, 2021, 2024) group breaking changes
  • The Rust Foundation (2021) stewards the project
  • Known for great compiler error messages

Hello, World

// src/main.rs
fn main() {
    println!("Hello, World");            // Hello, World

    let name = std::env::args().nth(1).unwrap_or("World".into());
    println!("Hello, {name}!");          // Hello, Ada!
}

// $ cargo new hello && cd hello
// $ cargo run -- Ada

Code Explained

fn main() is the entry point of a binary crate
println! ends in ! because it is a macro, not a function
args().nth(1) returns an Option; unwrap_or gives a default
{name} inlines a variable in the format string

Coming From…

  • C++ similar speed and control, but memory safety is the programmer's job
  • Go also compiles to one binary, but uses a garbage collector
  • Python / Java run on an interpreter or VM; Rust is compiled ahead of time

The Rust Way

  • learning Rust by fighting the borrow checker → read the error: it usually names the fix
  • unwrap() everywhere in real code → ? and proper error types (sheet 043)

⚠ Common Mistakes

  • Expecting Rust to feel like a GC language: ownership changes how you design data
  • Copying C++ patterns (shared mutable pointers) and fighting the compiler
  • Skipping the compiler message, which usually suggests the fix

✓ Tips & Best Practices

  • Read "The Rust Programming Language" (the Book) free online
  • Run cargo clippy from day one
  • Try snippets at play.rust-lang.org
