Expressions Everywhere

A Rust program is a set of items (functions, structs, enums, modules) in a crate rooted at main.rs or lib.rs. Most constructs are expressions that produce values, including blocks, if and match. A block's value is its last expression without a semicolon; adding ; turns it into a statement that yields ().

Key Points

  • let is a statement; if, match, blocks are expressions
  • The semicolon matters: x + 1 returns, x + 1; does not
  • main can return Result<(), E> to use ?
  • Items can be declared in any order

Blocks, Expressions and main

use std::fs;

fn area(w: f64, h: f64) -> f64 {
    w * h                       // no semicolon: this is the return value
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let a = area(3.0, 4.0);
    let label = if a > 10.0 { "big" } else { "small" };   // if is an expression

    let total = {               // a block is an expression
        let tax = a * 0.06;
        a + tax                 // value of the block
    };

    let config = fs::read_to_string("config.toml")?;   // ? needs Result return
    println!("{label} {total:.2} {}", config.len());
    Ok(())                      // success value for main
}

Code Explained

The last line of area is returned because it has no ;
if … else produces a value assigned to label
The block computes total with a temporary tax
main returning Result lets ? stop with an error message

Coming From…

  • Java if is a statement; you need the ternary ?: for values
  • Python has conditional expressions, but blocks are not values
  • C++ blocks are statements; GCC statement expressions are non-standard

The Rust Way

  • return x; at the end of every function → trailing expression x
  • unwrap() in main → main() -> Result + ?

⚠ Common Mistakes

  • A stray ; on the last line: "expected f64, found ()"
  • Using ? in a main that returns ()
  • Expecting if without else to produce a value

✓ Tips & Best Practices

  • Let the compiler's type errors guide you to missing or extra semicolons
  • Use blocks to limit the scope of temporaries
  • Return Result from main in CLI tools

Quick Summary

  • expressions produce values
  • no ; — returned value
  • blocks are expressions
  • main → Result for ?
