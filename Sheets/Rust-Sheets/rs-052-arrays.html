Fixed-Size Sequences

An array [T; N] holds exactly N values of one type, and N is part of the type: [i32; 3] and [i32; 4] are different types. Arrays live inline (usually on the stack) with no heap allocation. Indexing is bounds-checked. Use a Vec when the length is not known at compile time.

Key Points

  • [value; N] repeats a value N times (needs Copy or a const)
  • Arrays coerce to slices: &arr → &[T]
  • Arrays implement Debug, PartialEq, Ord, Hash, Default
  • Arrays iterate by value with for x in arr (2021+)

Under the Hood

  • [T; N] is N values laid out back to back: size_of = N * size_of::<T>()
  • No length is stored; N is known at compile time
  • Constant-index accesses are bounds-checked at compile time
  • Large arrays on the stack can overflow it; use vec! or Box<[T; N]>

Arrays

let primes: [u32; 5] = [2, 3, 5, 7, 11];
let zeros = [0u8; 100];                     // 100 zero bytes
let names = ["Ada", "Bob", "Cy"];           // [&str; 3]

println!("{}", primes[0]);                  // 2
println!("{}", primes.len());               // 5
println!("{:?}", primes.get(9));            // None
// let x = primes[9];                // compile error: index out of bounds

let doubled = primes.map(|p| p * 2);        // [4, 6, 10, 14, 22]
let total: u32 = primes.iter().sum();       // 28
println!("{}", primes.contains(&7));        // true

let mut grid = [[0; 3]; 2];                 // 2 rows × 3 columns
grid[1][2] = 9;
println!("{grid:?}");                       // [[0, 0, 0], [0, 0, 9]]

fn sum(xs: &[u32]) -> u32 { xs.iter().sum() }
println!("{}", sum(&primes));               // array → slice

let [first, second, ..] = primes;           // destructure
let squares: [usize; 4] = std::array::from_fn(|i| i * i);   // [0, 1, 4, 9]

println!("{}", std::mem::size_of_val(&zeros));   // 100
let v: Vec<u32> = primes.to_vec();          // copy to the heap
let back: [u32; 5] = v.try_into().unwrap(); // Vec → array (length checked)
let mut sorted = [3, 1, 2];
sorted.sort();
for p in primes { print!("{p} "); }         // by value

Code Explained

The length 5 is part of the type [u32; 5]
get returns an Option instead of panicking
[[0; 3]; 2] builds a 2-D array
from_fn builds an array from an index function

Coming From…

  • C / C++ int a[5] / std::array<int, 5> (Rust adds bounds checks)
  • Go [5]int arrays are values, like Rust's
  • Java / Python arrays/lists are heap objects with runtime length

The Rust Way

  • Vec for a fixed set of values → array [T; N]
  • for i in 0..arr.len() → for x in arr / arr.iter()

⚠ Common Mistakes

  • Using a runtime value as N ([0; n] needs a const)
  • Huge stack arrays causing stack overflow
  • Expecting arrays of different lengths to be the same type

✓ Tips & Best Practices

  • Use const generics for functions over any N: fn f<const N: usize>(a: [T; N])
  • Use array::from_fn for computed arrays
  • Use chunks_exact to view a slice as fixed-size pieces

Quick Summary

  • [T; N] — fixed length
  • [v; N] — repeat
  • inline, no heap
  • coerces to &[T]
