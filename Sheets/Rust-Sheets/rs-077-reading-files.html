Reading Files

fs::read_to_string · File::open · BufReader & lines() · read_to_end · io::Result · ? in file code

Getting Data In

For small files, fs::read_to_string reads everything into a String and fs::read into Vec<u8>. For large files, wrap a File in a BufReader and iterate lines() so memory stays flat. All I/O returns io::Result<T>, so ? handles errors cleanly.

Key Points

  • read_to_string fails on invalid UTF-8
  • lines() strips \n and \r\n; each line is io::Result<String>
  • Files close automatically when dropped
  • io::ErrorKind::NotFound lets you match specific errors

Reading

use std::fs::{self, File};
use std::io::{self, BufRead, BufReader, Read};

fn main() -> io::Result<()> {
    let text = fs::read_to_string("notes.txt")?;     // whole file → String
    println!("{} lines", text.lines().count());

    let bytes: Vec<u8> = fs::read("logo.png")?;       // whole file → bytes
    println!("{} bytes", bytes.len());

    let file = File::open("big.log")?;
    let reader = BufReader::new(file);
    for (n, line) in reader.lines().enumerate() {    // streams line by line
        let line = line?;
        if line.contains("ERROR") { println!("{}: {line}", n + 1); }
    }

    let mut f = File::open("data.bin")?;
    let mut header = [0u8; 4];
    f.read_exact(&mut header)?;                      // exactly 4 bytes
    let mut rest = Vec::new();
    f.read_to_end(&mut rest)?;

    match fs::read_to_string("missing.txt") {
        Ok(s) => println!("{s}"),
        Err(e) if e.kind() == io::ErrorKind::NotFound => println!("no file"),
        Err(e) => return Err(e),
    }

    let nums: Vec<i64> = fs::read_to_string("nums.txt")?
        .lines()
        .filter_map(|l| l.trim().parse().ok())
        .collect();
    println!("sum = {}", nums.iter().sum::<i64>());
    Ok(())
}

Code Explained

read_to_string is the one-liner for small text files
BufReader::lines reads one line at a time
read_exact fills a fixed buffer or errors
Match on e.kind() to handle a missing file

⚠ Common Mistakes

  • Reading huge files into memory at once
  • Unbuffered small reads on a File (many syscalls)
  • Ignoring the io::Result inside lines()

✓ Tips & Best Practices

  • Use BufReader for anything read piece by piece
  • Add the path to error messages (map_err / anyhow context)
  • Use memmap2 for very large read-only files

Quick Summary
