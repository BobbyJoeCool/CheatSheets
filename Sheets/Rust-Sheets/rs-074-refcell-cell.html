Cell, RefCell & Interior Mutability

interior mutability · Cell get / set · RefCell borrow() / borrow_mut() · runtime borrow panics · Rc<RefCell<T>> · OnceCell

Mutating Through a Shared Reference

Interior mutability lets you change data behind a &T. Cell<T> swaps whole values (best for Copy types) with no borrowing at all. RefCell<T> hands out borrows checked at runtime: breaking the rules panics instead of failing to compile. Rc<RefCell<T>> is the classic shared, mutable, single-threaded value.

Key Points

  • Neither Cell nor RefCell is Sync (single thread only)
  • Thread-safe versions: Mutex, RwLock, atomics
  • try_borrow_mut returns a Result instead of panicking
  • OnceCell sets a value once, then reads it

Cell and RefCell

use std::cell::{Cell, OnceCell, RefCell};
use std::rc::Rc;

struct Counter { hits: Cell<u32> }
impl Counter {
    fn hit(&self) { self.hits.set(self.hits.get() + 1); } // &self, yet mutates
}
let c = Counter { hits: Cell::new(0) };
c.hit();
c.hit();
println!("{}", c.hits.get());               // 2

let log = RefCell::new(Vec::new());
log.borrow_mut().push("start");             // mutable borrow, released at ;
log.borrow_mut().push("end");
println!("{:?}", log.borrow());             // ["start", "end"]
println!("{}", log.borrow().len());         // many shared borrows OK

let r1 = log.borrow_mut();
// let r2 = log.borrow_mut();              // panic: already mutably borrowed
println!("{}", log.try_borrow().is_err());  // true
drop(r1);

let shared = Rc::new(RefCell::new(vec![1, 2]));
let other = Rc::clone(&shared);
other.borrow_mut().push(3);                 // mutate through one owner
println!("{:?}", shared.borrow());          // [1, 2, 3] seen by all

struct Lazy { value: OnceCell<String> }
impl Lazy {
    fn get(&self) -> &str {
        self.value.get_or_init(|| { println!("computing"); "ready".into() })
    }
}
let l = Lazy { value: OnceCell::new() };
println!("{} {}", l.get(), l.get());        // computing (once), ready ready

let flag = Cell::new(false);
let old = flag.replace(true);               // swap in, return old

Code Explained

Cell::set changes the value through &self
Each borrow_mut() ends at the end of its statement
Two live borrow_muts panic at runtime
Rc<RefCell<…>> lets every owner mutate the shared Vec

Coming From…

  • C++ mutable members; no runtime borrow checks
  • Java / Python everything is mutable through any reference
  • Go no equivalent; any pointer can mutate

The Rust Way

  • RefCell for Copy fields → Cell (no borrow tracking)
  • Rc<RefCell<T>> everywhere → restructure ownership or pass &mut

⚠ Common Mistakes

  • Holding a borrow() while calling a function that does borrow_mut() (panic)
  • Using RefCell to dodge every borrow error
  • Expecting Rc<RefCell<T>> to work across threads

✓ Tips & Best Practices

  • Keep RefCell borrows short; drop guards quickly
  • Use try_borrow_mut where re-entrancy is possible
  • Prefer Cell for counters and flags

Quick Summary

  • mutate through &T
  • Cell — whole-value swaps
  • RefCell — runtime-checked borrows
  • Rc<RefCell<T>> — shared + mutable
