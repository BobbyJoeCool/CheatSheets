Letting the Compiler Work Out Types

Rust infers types from how values are used, even from later lines in the same function. When it cannot, add an annotation on the variable, a turbofish ::<T> on the call, or a partial type with _. Function signatures are never inferred: parameters and return types are always written out.

Key Points

  • Inference is local to a function body
  • Vec<_> lets the element type be inferred
  • type aliases are just names, not new types
  • size_of::<T>() shows a type's size in bytes

Inference and Aliases

use std::collections::HashMap;
use std::mem::size_of;

let mut v = Vec::new();           // Vec<?> for now
v.push(3u16);                     // now Vec<u16>

let nums: Vec<i32> = "1 2 3".split(' ').map(|s| s.parse().unwrap()).collect();
let nums = "1 2 3".split(' ').map(|s| s.parse::<i32>().unwrap())
    .collect::<Vec<_>>();

let total: u64 = nums.iter().map(|&n| n as u64).sum();   // sum needs a type
let words: HashMap<_, _> = [("a", 1), ("b", 2)].into_iter().collect();

type Grid = Vec<Vec<u8>>;
type Result<T> = std::result::Result<T, String>;

fn make_grid(n: usize) -> Grid { vec![vec![0; n]; n] }
fn parse_age(s: &str) -> Result<u8> { s.parse().map_err(|_| s.to_string()) }

println!("{}", size_of::<u8>());          // 1
println!("{}", size_of::<String>());      // 24 (ptr, len, cap)
println!("{}", size_of::<Option<Box<i32>>>());   // 8 (niche)
println!("{}", size_of::<(u8, u32)>());   // 8 (padding)

Code Explained

v's element type is fixed by the later push
collect and sum often need the target type
Turbofish puts the type on the method call instead
The Result<T> alias fixes the error type for a module

Coming From…

  • C++ auto infers from the initializer only
  • Java var infers local types from the initializer
  • Python / JavaScript dynamic typing; TypeScript infers like Rust

The Rust Way

  • annotating every let → annotate only where inference needs help
  • type UserId = u64 for safety → newtype struct UserId(u64) (sheet 106)

⚠ Common Mistakes

  • collect() without a target type ("type annotations needed")
  • Expecting type aliases to prevent mixing values
  • Turbofish on the wrong method in a chain

✓ Tips & Best Practices

  • Put the type on let when a long chain ends in collect
  • Use module-level type Result<T> aliases
  • Check sizes with size_of when optimizing memory

Quick Summary

  • local inference, explicit signatures
  • let x: T / turbofish ::<T>
  • Vec<_> — partial
  • type — alias only
