VecDeque, BinaryHeap & Choosing

VecDeque push_front / pop_back · queues & stacks · BinaryHeap max-heap · Reverse for min-heap · LinkedList (rarely) · choosing a collection

Queues and Priority Queues

VecDeque is a ring buffer with O(1) push and pop at both ends, the standard queue. BinaryHeap is a priority queue that always pops the largest item; wrap items in Reverse for a min-heap. LinkedList exists but is rarely the right choice.

Key Points

  • A Vec is already a good stack (push / pop)
  • VecDeque supports indexing and make_contiguous
  • BinaryHeap iteration order is arbitrary; only pop is ordered
  • Heap items need Ord

Queues and Heaps

use std::collections::{BinaryHeap, VecDeque};
use std::cmp::Reverse;

let mut q = VecDeque::new();
q.push_back("a");                           // enqueue
q.push_back("b");
q.push_front("z");                          // front: z a b
println!("{:?}", q.pop_front());            // Some("z") (dequeue)
println!("{:?} {}", q.back(), q[0]);        // Some("b") a
q.rotate_left(1);                           // b a

let mut stack = vec![1, 2];                 // Vec as a stack
stack.push(3);
println!("{:?}", stack.pop());              // Some(3)

let mut heap = BinaryHeap::new();
for x in [5, 1, 8, 3] { heap.push(x); }
println!("{:?}", heap.peek());              // Some(8)
println!("{:?}", heap.pop());               // Some(8)
println!("{:?}", heap.into_sorted_vec());   // [1, 3, 5]

let mut min = BinaryHeap::new();
for x in [5, 1, 8] { min.push(Reverse(x)); }
println!("{:?}", min.pop().map(|Reverse(x)| x));   // Some(1)

let mut tasks = BinaryHeap::new();          // (priority, name)
tasks.push((2, "write"));
tasks.push((9, "deploy"));
tasks.push((5, "test"));
while let Some((p, name)) = tasks.pop() {
    print!("{name}:{p} ");                  // deploy:9 test:5 write:2
}
println!();

let window: VecDeque<i32> = (1..=5).collect();
let last3: Vec<_> = window.iter().rev().take(3).collect();   // [5, 4, 3]

Code Explained

push_front/pop_front are O(1) on VecDeque
peek shows the largest without removing it
Reverse(x) flips ordering for a min-heap
Tuples order by the first field, so they work as (priority, item)

Coming From…

  • Python collections.deque and heapq (a min-heap)
  • Java ArrayDeque and PriorityQueue (a min-heap)
  • C++ std::deque and std::priority_queue (a max-heap, like Rust)

The Rust Way

  • Vec::remove(0) for a queue → VecDeque::pop_front()
  • sorting after every insert → BinaryHeap

Choosing a Collection

NeedUse
List, stack, indexingVec
Queue / dequeVecDeque
Lookup by keyHashMap
Sorted keys, rangesBTreeMap
Unique valuesHashSet / BTreeSet
Highest/lowest firstBinaryHeap
O(1) splice, rareLinkedList

⚠ Common Mistakes

  • Assuming BinaryHeap iterates in sorted order
  • Using LinkedList for performance (poor cache use)
  • Forgetting Reverse and getting a max-heap

✓ Tips & Best Practices

  • Default to Vec and HashMap; switch with a reason
  • Use (Reverse(cost), node) in Dijkstra-style searches
  • Use VecDeque for sliding windows and BFS

Quick Summary

  • VecDeque — both ends O(1)
  • BinaryHeap — max first
  • Reverse — min-heap
  • Vec for stacks
