Logical & Bitwise

&& || ! short-circuit · & | ^ ! on integers · << >> · count_ones / leading_zeros · rotate_left · bool & vs &&

Boolean Logic and Bit Operations

&& and || short-circuit and work only on bool. On integers, &, |, ^ and ! are bitwise (note ! is bitwise NOT, there is no ~). Shifts << and >> are arithmetic for signed types and logical for unsigned. Integer types also have methods for counting and rotating bits.

Key Points

  • !x on an integer flips all bits (C uses ~)
  • Shifting by ≥ bit width panics in debug
  • & / | on bools evaluate both sides
  • Use u32 / u64 for bit flags; the bitflags crate helps

Logic and Bits

let a = true;
let b = false;
println!("{} {} {}", a && b, a || b, !a);   // false true false
println!("{}", a ^ b);                      // true (bool XOR)

fn check() -> bool { println!("called"); true }
let _ = false && check();                   // check() not called
let _ = false & check();                    // check() IS called

let x: u8 = 0b1100_1010;
let y: u8 = 0b1010_0110;
println!("{:08b}", x & y);                  // 10000010
println!("{:08b}", x | y);                  // 11101110
println!("{:08b}", x ^ y);                  // 01101100
println!("{:08b}", !x);                     // 00110101
println!("{:08b}", x << 2);                 // 00101000
println!("{:08b}", x >> 3);                 // 00011001
println!("{}", -16i32 >> 2);                // -4 (arithmetic shift)

println!("{}", x.count_ones());             // 4
println!("{}", 1u32.leading_zeros());       // 31
println!("{}", 8u32.trailing_zeros());      // 3
println!("{:08b}", x.rotate_left(4));       // 10101100
println!("{}", 64u32.is_power_of_two());    // true

const READ: u8 = 1 << 0;
const WRITE: u8 = 1 << 1;
let mut perms = READ;
perms |= WRITE;                             // set
perms &= !READ;                             // clear
println!("{}", perms & WRITE != 0);         // true

Code Explained

&& skips the right side when the left is false
Bool & evaluates both sides
! on u8 is bitwise NOT
|= sets and &= !flag clears a bit flag

Coming From…

  • C / C++ same operators, but ~ for NOT; ! is logical only
  • Java >>> for logical shift; Rust picks by signedness
  • Python ~x NOT; ints are unbounded

The Rust Way

  • ~x → !x
  • hand-rolled flag constants everywhere → bitflags! crate

⚠ Common Mistakes

  • Writing ~x (not Rust syntax)
  • Expecting >> on i32 to shift in zeros (cast to u32 first)
  • Shifting by a value ≥ the bit width

✓ Tips & Best Practices

  • Parenthesize bit tests (x & 1) == 0 for readers coming from C
  • Use {:08b} / {:#x} to print bit patterns
  • Use checked_shl when the shift amount is untrusted

Quick Summary
