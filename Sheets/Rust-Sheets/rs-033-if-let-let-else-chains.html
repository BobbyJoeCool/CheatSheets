if let, let else & let Chains

if let · if let … else · let … else { return } · let chains (2024 edition) · matches! · while let

Matching One Pattern

if let runs code only when one pattern matches, a shorter form of a two-arm match. let … else binds a value or diverges (return, break, panic), which keeps the happy path unindented. The 2024 edition (Rust 1.88+) adds let chains: if let Some(x) = a && x > 0.

Key Points

  • let … else requires the else block to diverge
  • Let chains need edition 2024
  • matches!(v, Pat) returns a bool
  • Bindings from if let live only in its block

if let, let else, let chains

let config: Option<&str> = Some("8080");

if let Some(port) = config {
    println!("port {port}");
} else {
    println!("default port");
}

fn parse_port(s: Option<&str>) -> Result<u16, String> {
    let Some(text) = s else {
        return Err("missing".into());       // must diverge
    };
    let Ok(port) = text.parse::<u16>() else {
        return Err(format!("bad port: {text}"));
    };
    Ok(port)                                // happy path stays flat
}
println!("{:?}", parse_port(config));      // Ok(8080)

// Let chains (edition 2024)
let user: Option<(&str, u32)> = Some(("ada", 36));
if let Some((name, age)) = user
    && age >= 18
    && let Some(first) = name.chars().next()
{
    println!("{first} is an adult");        // a is an adult
}

#[derive(Debug)]
enum Cmd { Quit, Move(i32) }
let c = Cmd::Move(3);
println!("{}", matches!(c, Cmd::Move(n) if n > 0));   // true

let mut tokens = vec!["b", "a"];
while let Some(t) = tokens.pop() { print!("{t} "); }  // a b

Code Explained

if let handles the one case you care about
let … else returns early when the pattern fails
Let chains combine patterns and conditions with &&
matches! accepts guards too

Coming From…

  • Swift if let and guard let … else (same idea)
  • Kotlin ?.let { } and ?: return
  • Python walrus if (m := re.match(...)):

The Rust Way

  • nested if let pyramids → let … else or let chains
  • match x { Some(v) => …, None => {} } → if let Some(v) = x

Forms

FormUse
if let P = e { }One pattern

⚠ Common Mistakes

  • let … else block that does not diverge (compile error)
  • Let chains on an older edition (use nested ifs)
  • Using if let where a missing case should be handled

✓ Tips & Best Practices

  • Use let … else for validation at the top of functions
  • Combine with ? for Option/Result chains
  • Use matches! in filter closures

Quick Summary

  • if let — one pattern
  • let … else — bind or exit
  • let chains (2024)
  • matches! — bool
