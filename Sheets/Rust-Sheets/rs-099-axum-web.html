Web Servers with Axum

Router::new().route() · handlers · extractors Path / Query / Json / State · IntoResponse · TcpListener · tower middleware

HTTP Services

Axum (from the Tokio team) builds web services from async handler functions. Handler arguments are extractors that parse the request (path params, query strings, JSON bodies, shared state), and return values implement IntoResponse. Middleware comes from the tower ecosystem, such as tower-http for tracing, CORS and compression.

Key Points

  • cargo add axum tokio -F tokio/full serde -F serde/derive
  • Axum 0.8 path syntax: /users/{id}
  • The body extractor (Json) must be the last argument
  • Share state with with_state and State<T> (T: Clone)

An Axum Service

use axum::{extract::{Path, Query, State}, http::StatusCode,
           response::IntoResponse, routing::get, Json, Router};
use serde::{Deserialize, Serialize};
use std::sync::{Arc, Mutex};

#[derive(Clone, Default)]
struct AppState { todos: Arc<Mutex<Vec<Todo>>> }
#[derive(Clone, Serialize, Deserialize)]
struct Todo { id: u32, title: String }
#[derive(Deserialize)]
struct Paging { limit: Option<usize> }
async fn list(State(s): State<AppState>, Query(p): Query<Paging>)
    -> Json<Vec<Todo>> {
    let todos = s.todos.lock().unwrap();
    Json(todos.iter().take(p.limit.unwrap_or(50)).cloned().collect())
}
async fn get_one(State(s): State<AppState>, Path(id): Path<u32>)
    -> impl IntoResponse {
    match s.todos.lock().unwrap().iter().find(|t| t.id == id) {
        Some(t) => Ok(Json(t.clone())),
        None => Err((StatusCode::NOT_FOUND, "no such todo")),
    }
}
async fn create(State(s): State<AppState>, Json(t): Json<Todo>)
    -> impl IntoResponse {
    s.todos.lock().unwrap().push(t.clone());
    (StatusCode::CREATED, Json(t))
}

#[tokio::main]
async fn main() {
    let app = Router::new()
        .route("/todos", get(list).post(create))
        .route("/todos/{id}", get(get_one))
        .with_state(AppState::default());
    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000").await.unwrap();
    axum::serve(listener, app).await.unwrap();
}

Code Explained

Routes map paths and methods to handler functions
Extractors like Path(id) destructure in the parameter list
Tuples of (StatusCode, body) are valid responses
with_state makes AppState available to every handler

Coming From…

  • Python FastAPI (typed params ≈ extractors)
  • JavaScript Express / Hono route handlers
  • Java Spring @GetMapping + @PathVariable; Go net/http + chi

The Rust Way

  • parsing req.uri() by hand → Path / Query extractors
  • std::sync::Mutex held across .await → lock, copy, drop, then await

⚠ Common Mistakes

  • Putting Json<T> before other extractors (compile error)
  • Old /:id path syntax with Axum 0.8 (now /{id})
  • Long-running blocking work inside handlers

✓ Tips & Best Practices

  • Add tower_http::trace::TraceLayer for request logs
  • Return Result<T, AppError> with impl IntoResponse for AppError
  • Test routers with tower::ServiceExt::oneshot
