loop & Break Values

loop · break / continue · break value · labels 'outer: · break 'outer · infinite loops & !

Infinite Loops and Labeled Breaks

loop repeats forever until break. Unlike other loops, loop is an expression that can return a value with break value. Labels like 'outer: let break and continue target an enclosing loop. A loop with no break has type !.

Key Points

  • Use loop instead of while true (clearer and helps the compiler)
  • Labels start with an apostrophe: 'outer
  • Labeled blocks can also break 'label value
  • Server main loops are often loop {}

loop, break and labels

let mut count = 0;
let result = loop {
    count += 1;
    if count == 10 {
        break count * 2;                    // value of the loop
    }
};
println!("{result}");                       // 20

let mut attempts = 0;
let data = loop {
    attempts += 1;
    match fetch(attempts) {
        Some(d) => break d,
        None if attempts < 3 => continue,
        None => break String::from("default"),
    }
};

'outer: for x in 0..5 {
    for y in 0..5 {
        if y > x { continue 'outer; }       // next x
        if x + y == 6 { break 'outer; }     // leave both loops
        print!("({x},{y}) ");
    }
}
println!();

let found = 'search: {                      // labeled block
    for n in [3, 8, 12] {
        if n % 4 == 0 { break 'search Some(n); }
    }
    None
};
println!("{found:?}");                      // Some(8)

fn serve() -> ! { loop { /* accept connections */ } }
fn fetch(n: u32) -> Option<String> { (n == 2).then(|| "ok".into()) }

Code Explained

break count * 2 gives the loop its value
Retry logic reads cleanly with loop and match
continue 'outer jumps to the next outer iteration
A labeled block can exit early with a value

Coming From…

  • Java labeled break outer; but loops have no value
  • Python no labels; use flags, functions or for … else
  • Go labeled break/continue; for {} is the infinite loop

The Rust Way

  • while true {} → loop {}
  • let mut found = false; flags → break with a value

⚠ Common Mistakes

  • break value inside for or while (not allowed)
  • Forgetting the apostrophe in labels
  • Busy loops without sleep or blocking calls

✓ Tips & Best Practices

  • Use loop + break value for retry and search logic
  • Extract nested loops into a function and return instead of labels
  • Functions that never return should say -> !

Quick Summary

  • loop — forever
  • break value returns
