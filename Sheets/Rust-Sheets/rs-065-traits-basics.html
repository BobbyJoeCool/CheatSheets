Traits — Basics

trait definitions · impl Trait for Type · trait methods · orphan rule · impl Trait params · &dyn Trait preview

Shared Behavior

A trait declares methods that types can implement, like an interface. Implement it with impl Trait for Type. Functions accept "anything implementing the trait" with impl Trait (static dispatch) or &dyn Trait (dynamic dispatch). The orphan rule requires either the trait or the type to be defined in your crate.

Key Points

  • Traits must be in scope (use) to call their methods
  • You can implement your traits for std types like i32
  • You cannot implement Display for Vec<T> (both foreign)
  • Wrap foreign types in a newtype to get around the orphan rule

Defining and Implementing Traits

trait Describe {
    fn name(&self) -> String;
    fn describe(&self) -> String;
}
struct Dog { breed: String }
struct Robot { id: u32 }
impl Describe for Dog {
    fn name(&self) -> String { "dog".into() }
    fn describe(&self) -> String { format!("a {} dog", self.breed) }
}
impl Describe for Robot {
    fn name(&self) -> String { format!("robot-{}", self.id) }
    fn describe(&self) -> String { "a metal friend".into() }
}
impl Describe for i32 {                     // our trait, std type: allowed
    fn name(&self) -> String { "number".into() }
    fn describe(&self) -> String { format!("the number {self}") }
}
fn introduce(x: &impl Describe) {           // static dispatch
    println!("{}: {}", x.name(), x.describe());
}
introduce(&Dog { breed: "corgi".into() });  // dog: a corgi dog
introduce(&7);                              // number: the number 7

let things: Vec<Box<dyn Describe>> = vec![  // dynamic dispatch (sheet 070)
    Box::new(Robot { id: 9 }),
    Box::new(Dog { breed: "lab".into() }),
];
for t in &things { println!("{}", t.describe()); }

// impl std::fmt::Display for Vec<i32> {}   // E0117: orphan rule
struct List(Vec<i32>);                      // newtype workaround
impl std::fmt::Display for List {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        write!(f, "[{} items]", self.0.len())
    }
}

Code Explained

Describe lists methods every implementor must provide
Each type supplies its own method bodies
&impl Describe accepts any implementing type
A newtype lets you implement foreign traits for foreign types

Coming From…

  • Java interfaces; Rust traits can also be added to existing types
  • Go interfaces are implicit; Rust impls are explicit
  • C++ concepts (C++20) for static, virtual base classes for dynamic

The Rust Way

  • inheritance hierarchies → traits plus composition
  • methods taking a concrete type when any implementor would do → impl Trait
