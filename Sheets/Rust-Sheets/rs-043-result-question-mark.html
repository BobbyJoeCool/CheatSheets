Result<T, E> & the ? Operator

Ok / Err · ? propagation · map_err · ok() / err() · Box<dyn Error> · main() -> Result

Recoverable Errors as Values

Functions that can fail return Result<T, E>: Ok(value) or Err(error). The **? operator** returns the error to the caller if there is one and unwraps the value otherwise, so error handling stays one character per call. Box<dyn Error> is a quick catch-all error type for applications.

Key Points

  • Result is #[must_use]: ignoring one warns
  • ? converts the error with From::from
  • ? only works in functions returning Result/Option
  • map_err changes the error type

Under the Hood

  • expr? desugars to match Try::branch(expr) { Continue(v) => v, Break(r) => return FromResidual::from_residual(r) }
  • For Result, the residual path calls From::from(err)
  • No exceptions or unwinding: an Err is an ordinary return value
  • Result<T, E> size ≈ max(T, E) + tag

Result and ?

use std::fs;
use std::num::ParseIntError;

fn parse_double(s: &str) -> Result<i32, ParseIntError> {
    let n: i32 = s.trim().parse()?;         // Err → return early
    Ok(n * 2)
}
println!("{:?}", parse_double("21"));       // Ok(42)
println!("{:?}", parse_double("x"));
                              // Err(ParseIntError { kind: InvalidDigit })

fn read_port(path: &str) -> Result<u16, String> {
    let text = fs::read_to_string(path).map_err(|e| format!("{path}: {e}"))?;
    text.trim().parse::<u16>().map_err(|e| e.to_string())
}

fn load() -> Result<u16, Box<dyn std::error::Error>> {
    let text = fs::read_to_string("port.txt")?;   // io::Error → Box
    let port = text.trim().parse::<u16>()?;       // ParseIntError → Box
    Ok(port)
}

let maybe: Option<i32> = parse_double("5").ok();   // Result → Option
let total: Result<Vec<i32>, _> =
    ["1", "2", "x"].iter().map(|s| s.parse::<i32>()).collect();
println!("{}", total.is_err());             // true: stops at first Err
let n2 = parse_double("8").inspect_err(|e| eprintln!("{e}")).unwrap_or(0);

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let port = load()?;                     // error printed, exit code 1
    println!("listening on {port}");
    Ok(())
}

Code Explained

? unwraps Ok or returns the Err immediately
map_err adds context or converts the error type
Box<dyn Error> accepts any error via From
Collecting into Result<Vec<_>, _> stops at the first error

Coming From…

  • Go if err != nil { return err } (? is the one-character version)
  • Java checked exceptions with throws; Result is explicit in the type
  • Python try / except; errors are invisible in signatures

The Rust Way

  • match r { Ok(v) => v, Err(e) => return Err(e.into()) } → r?
  • .unwrap() in library code → return Result

⚠ Common Mistakes

  • Using ? in a function returning ()
  • Error types that do not convert (implement From)
  • Ignoring a Result with let _ = without a reason

✓ Tips & Best Practices

  • Add context with map_err or anyhow's .context()
  • Make main return Result in CLI tools
  • Collect into Result<Vec<T>, E> to validate a batch
