stdin & stdout

io::stdin().read_line · lines() · lock() · io::stdout() / stderr() · BufRead · trim().parse()

Console Input and Output

io::stdin().read_line(&mut s) reads one line including the trailing newline into a String, so call trim() before parsing. stdin().lines() iterates every line until EOF, which suits filters and pipes. For heavy output, lock stdout once and wrap it in a BufWriter.

Key Points

  • read_line appends; clear the buffer when reusing it
  • read_line returns Ok(0) at EOF
  • print! needs flush() before waiting for input
  • stdout is line-buffered only when attached to a terminal

Console I/O

use std::io::{self, BufRead, BufWriter, Write};

fn main() -> io::Result<()> {
    print!("Your name: ");
    io::stdout().flush()?;                  // show the prompt now
    let mut name = String::new();
    io::stdin().read_line(&mut name)?;      // includes '\n'
    let name = name.trim();
    println!("Hello, {name}!");

    print!("Age: ");
    io::stdout().flush()?;
    let mut buf = String::new();
    io::stdin().read_line(&mut buf)?;
    match buf.trim().parse::<u32>() {
        Ok(age) => println!("Next year: {}", age + 1),
        Err(_) => eprintln!("not a number: {:?}", buf.trim()),
    }

    // Filter mode: cat input.txt | app
    let stdin = io::stdin();
    let mut total = 0i64;
    for line in stdin.lock().lines() {      // until EOF (Ctrl-D / Ctrl-Z)
        let line = line?;
        if let Ok(n) = line.trim().parse::<i64>() { total += n; }
    }

    let stdout = io::stdout();
    let mut out = BufWriter::new(stdout.lock());   // fast bulk output
    for i in 0..5 { writeln!(out, "row {i}")?; }
    writeln!(out, "total {total}")?;
    out.flush()?;

    let all: String = io::read_to_string(io::stdin())?;   // whole input
    eprintln!("{} bytes read", all.len());  // diagnostics to stderr
    Ok(())
}

Code Explained

flush() makes print! text appear before input
read_line keeps the newline, so trim before parsing
lock().lines() reads until end of input
Diagnostics go to stderr so stdout stays clean for pipes

The Rust Way

  • parsing without trim() → buf.trim().parse()

⚠ Common Mistakes

  • Parsing input with the newline still attached
  • Reusing a buffer with read_line without clear()
  • Prompt invisible because print! was not flushed

✓ Tips & Best Practices

  • Use dialoguer / inquire for interactive prompts
  • Use is_terminal() (std::io::IsTerminal) to detect pipes
  • Exit with a non-zero code on errors (sheet 082)

Quick Summary

  • read_line keeps \n → trim
  • stdin().lines() until EOF
  • flush before input
  • lock + BufWriter for speed
