Creating and Growing Strings

Create a String from a literal with String::from, .to_string() or .into(), then grow it with push (one char) and push_str (a &str). + takes ownership of the left String and appends a &str, while format! builds a new String from any values without moving them.

Key Points

  • s1 + &s2 moves s1; s2 is only borrowed
  • format! is the clearest way to join several values
  • with_capacity avoids reallocations in loops
  • Raw strings skip escape processing: r"C:\dir"

Building Text

let mut s = String::new();
s.push('R');                         // one char
s.push_str("ust");                   // a &str
s += " 2024";                        // += takes &str
println!("{s}");                     // Rust 2024

let a = String::from("Hello");
let b = "World".to_string();
let c = a + ", " + &b + "!";         // a is moved here
// println!("{a}");                  // error: borrow of moved value
println!("{c}");                     // Hello, World!

let msg = format!("{}-{}-{}", "x", 42, 3.5);   // nothing moved
let mut out = String::with_capacity(64);
for i in 0..5 { out.push_str(&i.to_string()); }
println!("{out} {}", out.capacity()); // 01234 64

let path = r"C:\Users\ada";        // raw: no escapes
let json = r#"{"name": "Ada"}"#;     // # lets you use quotes
let multi = "line one
line two";                           // newline kept
let joined = "one \
    two";                            // \ at end: "one two"
let bytes: &[u8; 3] = b"abc";        // byte string
let names = ["a", "b", "c"].join(", ");   // "a, b, c"

Code Explained

push adds a char; push_str adds a slice
+ reuses a's buffer, so a cannot be used afterwards
format! borrows its arguments
r#"…"# allows double quotes inside without escaping

Coming From…

  • Java StringBuilder.append(); + creates new strings
  • Python "".join(parts) and f-strings; strings are immutable
  • Go strings.Builder and fmt.Sprintf

The Rust Way

  • s = s + &x in a loop → s.push_str(&x) or write!(s, …)
  • chains of + with conversions → one format!

⚠ Common Mistakes

  • Using a after a + &b (moved)
  • a + b where b is a String (needs &b)
  • Calling to_string() on every literal inside a loop

✓ Tips & Best Practices

  • Use write! on a String with use std::fmt::Write
  • Use concat() / join() for slices of strings
  • Pre-size with with_capacity when the size is known
