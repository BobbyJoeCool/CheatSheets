Standard Library Tour

time::{Instant, Duration} · SystemTime · chrono / jiff dates · rand crate · process::Command · std::env

Everyday Utilities

The standard library is small but solid. Instant and Duration time code, SystemTime gives wall-clock time, and process::Command runs other programs. Dates and random numbers live in crates: chrono or jiff for calendars and time zones, rand for randomness.

Key Points

  • Instant is monotonic: use it for measuring
  • SystemTime can go backwards (clock changes)
  • std has no date formatting or time zones
  • Command does not use a shell unless you call one

Time, Processes, Crates

use std::time::{Duration, Instant, SystemTime, UNIX_EPOCH};
use std::process::Command;
use std::thread;

let start = Instant::now();
thread::sleep(Duration::from_millis(50));
println!("{:?}", start.elapsed());          // 50.1ms
println!("{}", start.elapsed().as_millis() >= 50);   // true

let d = Duration::from_secs(90) + Duration::from_millis(500);
println!("{} {:?}", d.as_secs_f64(), d);    // 90.5 90.5s

let unix = SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_secs();
println!("{unix}");                         // e.g. 1794500000

let out = Command::new("git").args(["rev-parse", "--short", "HEAD"]).output()?;
if out.status.success() {
    println!("commit {}", String::from_utf8_lossy(&out.stdout).trim());
}
let status = Command::new("ls").arg("-l").current_dir("/tmp").status()?;
println!("exit {:?}", status.code());       // Some(0)

// chrono (cargo add chrono)
use chrono::{Local, NaiveDate, Duration as CDuration};
let today = Local::now().date_naive();
let due = NaiveDate::from_ymd_opt(2026, 12, 31).unwrap();
println!("{} days left", (due - today).num_days());
println!("{}", Local::now().format("%Y-%m-%d %H:%M"));
let next_week = today + CDuration::days(7);

// rand 0.9 (cargo add rand)
use rand::Rng;
let mut rng = rand::rng();
let roll: u8 = rng.random_range(1..=6);
let coin: bool = rng.random();

Code Explained

Instant::elapsed measures durations reliably
Durations add and print in readable form
Command::output captures stdout/stderr and the exit status
chrono handles calendar dates and formatting

⚠ Common Mistakes

  • Using SystemTime for benchmarks
  • Passing user input through a shell (sh -c)
  • Expecting date formatting in std

✓ Tips & Best Practices

  • Use humantime to parse/print durations like "5m"
  • Check status.success() after running a command
  • Seed rand with a fixed StdRng for reproducible tests
