Sheet 030

for Loops

for x in iter · &v / &mut v / v (into_iter) · ranges 0..n · .iter().enumerate() · .rev() · .zip()

Iterating Over Anything

for loops over anything that implements IntoIterator. How you name the collection decides ownership: for x in &v borrows each item, for x in &mut v lets you modify items, and for x in v consumes the collection. Adapters like enumerate, rev and zip add indexes, reverse order and pairing.

Key Points

  • for x in v moves v; it cannot be used afterwards
  • for loops have no bounds checks on each item
  • Use enumerate() instead of a manual counter
  • Arrays iterate by value in edition 2021+

for Loops

let mut v = vec![10, 20, 30];

for x in &v { print!("{x} "); }              // borrow: 10 20 30
for x in &mut v { *x += 1; }                 // modify in place
for (i, x) in v.iter().enumerate() {
    print!("{i}:{x} ");                      // 0:11 1:21 2:31
}
for x in v.iter().rev() { print!("{x} "); }  // 31 21 11
println!();

let names = ["Ada", "Bob"];
let ages = [36, 25];
for (n, a) in names.iter().zip(ages) {
    println!("{n} is {a}");
}

for x in v { drop(x); }                      // consumes v
// println!("{:?}", v);                      // error: borrow of moved value

for i in (0..10).step_by(5) { print!("{i} "); }   // 0 5
for c in "hey".chars() { print!("{c}."); }   // h.e.y.
println!();

use std::collections::HashMap;
let scores = HashMap::from([("a", 1), ("b", 2)]);
for (k, val) in &scores { println!("{k}={val}"); }   // order not fixed

let grid = vec![vec![1, 2], vec![3, 4]];
for row in &grid {
    for cell in row { print!("{cell} "); }
}

Code Explained

&v yields &i32; &mut v yields &mut i32
*x += 1 dereferences to change the item
zip pairs two iterators and stops at the shorter
Looping over v by value moves it

Coming From…

  • Python for i, x in enumerate(v), zip(a, b)
  • Java enhanced for (var x : list); no built-in enumerate
  • C++ range-based for (auto& x : v) ≈ for x in &mut v

The Rust Way

  • for i in 0..v.len() { v[i] } → for x in &v (clippy: needless_range_loop)
  • manual counter let mut i = 0 → .enumerate()

⚠ Common Mistakes

  • Consuming v with for x in v and needing it later
  • Pushing to v inside for x in &v (borrow error)
  • Forgetting * when modifying through &mut

✓ Tips & Best Practices

  • Use iter().copied() to get values from &[i32]
  • Use chunks(n) / windows(n) for groups (sheet 038)
  • Labels work on for too: 'row: for …

Quick Summary

  • &v · &mut v · v
  • enumerate / rev / zip
  • no index loops
