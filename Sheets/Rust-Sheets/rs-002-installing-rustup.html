Installing with rustup

rustup-init · rustup update · stable / beta / nightly · rustup default · rustup toolchain install · rust-toolchain.toml · rustup component add

Managing Rust Toolchains

rustup installs and updates Rust and lets you switch between stable, beta and nightly toolchains. It also installs components (clippy, rustfmt, rust-analyzer, rust-src) and cross-compilation targets. A rust-toolchain.toml file in a project pins the toolchain for everyone who builds it.

Key Points

  • Install from rustup.rs (or brew install rustup on macOS)
  • Tools live in ~/.cargo/bin (add it to PATH)
  • Use stable unless you need a nightly-only feature
  • rustup doc opens the Book and std docs offline

rustup Commands

# Install (macOS / Linux)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

rustc --version             # rustc 1.9x.x (…)
cargo --version
rustup update               # get the newest stable

rustup toolchain install nightly
rustup default stable
cargo +nightly build        # one-off nightly build

rustup component add clippy rustfmt rust-analyzer
rustup target add wasm32-unknown-unknown
rustup target add aarch64-unknown-linux-gnu

rustup show                 # active toolchain and targets
rustup doc --book           # offline Book

# rust-toolchain.toml (project root)
# [toolchain]
# channel = "1.89.0"
# components = ["clippy", "rustfmt"]

Code Explained

The installer script sets up rustup, rustc and cargo
cargo +nightly uses nightly for one command only
Targets add standard libraries for cross-compiling
rust-toolchain.toml makes the project build with the pinned version

The Rust Way

  • installing Rust from a distro package → rustup (current and switchable)
  • nightly by default → stable, nightly only for specific crates

⚠ Common Mistakes

  • ~/.cargo/bin not on PATH, so cargo is not found
  • Mixing a distro-installed rustc with rustup
  • Depending on nightly features in a library others use on stable

✓ Tips & Best Practices

  • Commit rust-toolchain.toml so CI and teammates match
  • Run rustup update regularly: releases are backward compatible
  • Install rust-analyzer for editor support
