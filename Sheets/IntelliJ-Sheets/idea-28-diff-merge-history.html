Diff, Merge & History

diff viewer ⌘D · three-way merge · resolve conflicts · Annotate with Git Blame · history · rebase · cherry-pick

Description

The diff viewer compares any two versions side by side or unified. On conflicts, the three-way merge tool shows yours, theirs and the result, with one-click accept per chunk and a magic wand for non-conflicting changes. Annotate (blame) shows who changed each line; history works per file or per selection.

Notes

  • 2026.2 streamlines conflict resolution into one flow
  • Interactive rebase: Git log › right-click › Interactively Rebase from Here
  • Cherry-pick: right-click a commit in the log

Steps

  1. When a merge stops, open Resolve Conflicts from the notification
  2. Pick a file › Merge… to open the three-way view
  3. Click ✨ (Apply non-conflicting changes) first
  4. For each conflict, accept left >>, right <<, or edit the middle
  5. Apply, then commit the merge
  6. Use Annotate (right-click gutter › Annotate with Git Blame) to see line authors

Where to Find It

Blame → gutter right-click › Annotate with Git Blame
File history → right-click › Git › Show History
Selection history → select › Git › Show History for Selection

⚠ Common Mistakes

  • Accepting "theirs" for a whole file to finish fast — silently drops your changes
  • Rebasing shared branches from the log — rewrites history others pulled
  • Ignoring whitespace in diffs, then committing whitespace-only churn

✓ Tips & Best Practices

  • Compare branches with Git › Compare with Branch before merging
  • Annotate › click a line to open its commit
  • Use Show History for Selection to trace one method
