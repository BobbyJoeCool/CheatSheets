Sheet 16

Change Signature, Move & Inline

Change Signature ⌘F6 · Move F6 · Inline ⌥⌘N · Safe Delete ⌘⌫ · Pull Members Up · parameter object

Description

Change Signature adds, removes or reorders parameters and updates every call site, with a default value for new parameters. Move relocates classes and static members, fixing imports. Inline does the reverse of extract. Safe Delete removes a symbol only after checking it's unused.

Notes

  • Refactorings show a preview when usages are ambiguous
  • Pull Members Up / Push Members Down work across a hierarchy
  • Introduce Parameter Object groups parameters into a record

Change Signature Example

// Before
public Invoice bill(Customer c, List<Item> items) { ... }
bill(customer, cart.items());

// ⌘F6 → add parameter: Currency currency, default value: Currency.USD
public Invoice bill(Customer c, List<Item> items, Currency cur) {…}
bill(customer, cart.items(), Currency.USD);     // every call updated

// Introduce Parameter Object (via ⌃T) → record BillRequest
public Invoice bill(BillRequest request) { ... }
bill(new BillRequest(customer, cart.items(), Currency.USD));

// Inline (⌥⌘N) on a one-line helper removes it and pastes the body

Code Explained

Default value fills existing calls; use Use any var to pick a local
Delegate via overloading keeps the old signature as a wrapper
Move (F6) on a static method → pick the target class
Safe Delete warns and lists usages if any remain

Where in Settings

  • Editor › Code Editing › Refactorings — show preview
  • Editor › Code Style › Java › Imports — how moved code imports
  • Advanced Settings — Safe Delete search in comments

In VS Code

  • No Change Signature in VS Code core; Java ext has a basic one
  • Move class via drag in Explorer updates package · See VS Code 13

⚠ Common Mistakes

  • Deleting with ⌘⌫ in the editor — that deletes a line; Safe Delete is ⌘⌫ in the Project view or via ⌃T
  • Adding a parameter with no default — every call breaks until fixed by hand
  • Moving classes across modules without checking dependencies — creates cycles

✓ Tips & Best Practices

  • Use delegation ("Keep method as delegate") for public APIs
  • Preview → Exclude usages you don't want changed
  • Introduce Parameter Object once a method has 4+ params

Quick Summary
