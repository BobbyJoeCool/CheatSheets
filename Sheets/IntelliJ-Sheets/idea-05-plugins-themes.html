Sheet 05

Plugins, Themes & Appearance

Marketplace · Installed · bundled plugins · themes · fonts & ligatures · Presentation mode

Description

Plugins add languages, frameworks and tools. Install from Settings › Plugins › Marketplace; bundled plugins can be disabled to speed up startup. Themes and editor color schemes are separate: the theme styles the UI, the scheme colors the code. Editor fonts support ligatures (JetBrains Mono is the default).

Notes

  • Plugins can be required per project: Settings › Build… › Required Plugins
  • Disable unused bundled plugins (e.g. frameworks you never use)
  • Presentation mode enlarges everything for demos
  • Zoom editor: ⌘ + mouse wheel if enabled

Plugin Pick

  • Key Promoter X (Halirutan) — shows the shortcut each time you click a menu
  • A popular theme: Dracula or One Dark from the Marketplace

Steps

  1. Open Settings › Plugins (⌘, then type *plugins*)
  2. Marketplace tab: search, click Install, restart if asked
  3. Installed tab: disable bundled plugins you don't use
  4. Appearance › Theme: pick a UI theme
  5. Editor › Color Scheme: pick or duplicate a scheme
  6. Editor › Font: font, size, line height, ligatures

Where to Find It

Plugins → Settings › Plugins
Theme → Appearance & Behavior › Appearance
Font → Editor › Font
Presentation → View › Appearance › Enter Presentation Mode

Where in Settings

  • Settings › Plugins — install / disable (IDE-wide)
  • Build, Execution, Deployment › Required Plugins — per project
  • Editor › General › Mouse Control — Ctrl/⌘+wheel zoom

In VS Code

  • Extensions view ⇧⌘X ↔ Settings › Plugins
  • Themes and fonts work the same way · See VS Code 05, 23

⚠ Common Mistakes

  • Installing many overlapping plugins — slow startup and conflicting inspections
  • Editing a bundled color scheme directly — duplicate it first, or updates reset it
  • Ignoring "Required plugins" prompts — the project's run configs may depend on them

✓ Tips & Best Practices

  • Use Help › Diagnostic Tools › Analyze Plugin Startup to find slow plugins
  • Enable ligatures with JetBrains Mono for ->, !=, >=
  • Keep one dark and one light scheme on Quick Switch

Quick Summary

  • Marketplace — install plugins
  • Installed — disable bundled
  • Theme vs Scheme — UI vs code colors
  • Presentation mode — demos
