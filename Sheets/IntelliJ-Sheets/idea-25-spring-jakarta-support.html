Subscription

Spring & Jakarta EE Support

Spring bean navigation · Endpoints tool window · application.properties completion · CDI checks · app servers

Description

With a subscription, IntelliJ understands Spring and Jakarta EE models: gutter icons jump between beans and injection points, application.yml keys complete and validate, and the Endpoints tool window lists every HTTP route. Jakarta support checks CDI injection, Persistence mappings and lets you run apps on WildFly, Tomcat, Payara and others.

Notes

  • 2026.2 adds richer Spring Security insights and DB migration workflows
  • Spring Boot run configs show actuator beans and health
  • See the Spring and Jakarta EE sets for the frameworks

What the IDE Checks

@Service                                    // gutter 🫘 → bean definition
public class OrderService {
    private final PaymentGateway gateway;   // gutter → which bean injects
    public OrderService(PaymentGateway g) { this.gateway = g; }
}
// ⚠ "Could not autowire. There is more than one bean of type ..."

@ApplicationScoped                          // Jakarta CDI
public class Checkout {
    @Inject Shipping shipping;              // ⚠ ambiguous dependency
}

@RestController @RequestMapping("/api/orders")
public class OrderController {
    @GetMapping("/{id}")                    // gutter 🌐 → HTTP Client
    Order one(@PathVariable long id) { ... }
}

Code Explained

Bean gutter icons: navigate to definitions and injection points
Ambiguous / unsatisfied dependencies are flagged before you run
Endpoint gutter icon generates an HTTP Client request (sheet 26)
Spring Boot config keys: completion, docs, unused-key warnings

⚠ Common Mistakes

  • Expecting Spring inspections on the free tier — they need a subscription
  • Ignoring "could not autowire" in tests with component scan differences — check the test context

✓ Tips & Best Practices

  • Use Endpoints to discover an unfamiliar API quickly
  • Turn on Boot config metadata generation for your own properties
  • Open Liberty's Maven dev mode works well alongside the IDE
