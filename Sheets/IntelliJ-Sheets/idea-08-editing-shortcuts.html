Sheet 08

Editing Shortcuts & Multi-Caret

duplicate ⌘D · delete line ⌘⌫ · move statement · Extend Selection ⌥↑ · multi-caret ⌃G · paste history

Description

These are the shortcuts that save the most time day to day. Extend Selection grows the selection by syntax (word → expression → statement → block). Move Statement moves a whole method or statement up and down. Multiple carets edit several places at once; select the next occurrence with ⌃G.

Notes

  • ⌥-drag (macOS) / Alt-drag adds a column selection
  • ⌥⇧-click adds a caret anywhere
  • Esc collapses back to one caret

Explained

⌘⌫ / Ctrl+Y deletes the line without touching the clipboard
Move Statement keeps code valid; Move Line moves text only
⌃G repeatedly, then type — rename local occurrences without a refactor
Paste from history keeps your last clipboard entries

Where in Settings

  • Editor › General › Smart Keys — auto-close brackets, smart Home
  • Editor › General › Clipboard — history size
  • Keymap — rebind Ctrl+Y if you want redo on Windows

In VS Code

  • ⌘D (VS Code) = next occurrence; IntelliJ ⌃G. ⌘D here duplicates
  • ⌥↑ moves lines in VS Code; here it extends selection · See VS Code 06–07

⚠ Common Mistakes

  • Using Ctrl+Y as redo on Windows — it deletes the line in IntelliJ's default keymap
  • Hitting ⌘D for next occurrence (VS Code habit) — duplicates the line instead
  • Editing with multiple carets across code you can't see — scroll to check every caret

✓ Tips & Best Practices

  • Learn ⌥↑ — it replaces most mouse selections
  • ⇧⌘↑ reorders methods without cut/paste
  • Use Join Lines to collapse a declaration and assignment

Quick Summary

  • ⌥↑ — extend selection
  • ⌃G — next occurrence caret
