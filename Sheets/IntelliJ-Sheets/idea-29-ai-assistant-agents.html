Sheet 29

AI Assistant & Agents

AI chat · inline prompts · AI completion · Junie agent · third-party agents · MCP servers · commit messages

Description

IntelliJ's AI features come in layers: free local full-line completion, cloud AI completion and AI chat, and agents that make multi-file changes (JetBrains' Junie, plus third-party agents such as Claude Code and Copilot). 2026.2 added native GitHub Copilot integration and agent skills. MCP servers give agents access to tools and data.

Notes

  • Cloud AI needs a JetBrains AI plan (a free tier exists)
  • Project rules: .junie/guidelines.md and similar files steer agents
  • AI features may be disabled by org policy
  • The Agentic Coding set covers prompting and workflows

Plugin Pick

  • Claude Code (Anthropic) — runs Claude Code with IDE diff view and selection context
  • GitHub Copilot — now natively integrated in 2026.2

Steps

  1. Open AI chat from the right tool window stripe
  2. Attach context: current file, selection, or @ mentions
  3. Ask for a change; review the diff before Apply
  4. For multi-file work, switch to an agent (Junie or a third-party agent)
  5. Approve tool and terminal actions as the agent requests them
  6. Use Generate Commit Message in the commit window

⚠ Common Mistakes

  • Applying AI diffs without running tests — confident-looking code can still be wrong
  • Sharing secrets in prompts or context files — exclude them with .aiignore
  • Assuming feature names stay the same — AI menus change often between releases

✓ Tips & Best Practices

  • Keep a project guidelines file so agents follow your conventions
  • Ask the agent to write tests first, then the change
  • Use the local completion when offline or for privacy
