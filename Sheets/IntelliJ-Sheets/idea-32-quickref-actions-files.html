⚠ Common Mistakes

  • Invalidating caches as the first fix — try Reload Maven/Gradle first; reindexing is slow
  • Committing workspace.xml — conflicts on every pull
  • Editing IDE VM options (Help › Edit Custom VM Options) when you meant the app's run config

✓ Tips & Best Practices

  • Analyze Stack Trace turns pasted logs into clickable code links
  • Show Bytecode helps explain records, lambdas and switch
  • Keep .http files beside controllers as living docs
