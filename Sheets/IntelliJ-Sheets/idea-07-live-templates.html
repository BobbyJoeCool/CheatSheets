Sheet 07

Live Templates & Surround With

psvm / main · sout · fori / iter · Insert Live Template ⌘J · Surround With ⌥⌘T · variables

Description

Live templates expand an abbreviation into code: type psvm and press ⇥. Surround With wraps the selection in a construct (if, try/catch, for). You can add your own templates with variables ($NAME$) and functions that suggest values from context.

Notes

  • ⌘J lists templates valid at the caret
  • Templates are scoped by context (Java statement, expression, comment…)
  • Share custom templates by exporting settings

Plugin Pick

  • String Manipulation (Vojtech Krasa) — case conversions, sorting, escaping on selections

Built-in Templates and a Custom One

psvm / main  →  public static void main(String[] args) { }
sout         →  System.out.println();
soutv        →  System.out.println("name = " + name);
fori         →  for (int i = 0; i < ; i++) { }
iter         →  for (User user : users) { }
ifn          →  if (x == null) { }
thr          →  throw new
prsf         →  private static final

// Custom: Settings › Editor › Live Templates › + › "log"
private static final Logger LOG =
    LoggerFactory.getLogger($CLASS$.class);   // CLASS = className()

Code Explained

soutv picks the nearest variable automatically
$CLASS$ with expression className() fills the current class
Select code, ⌥⌘T, choose try / catch to wrap it
$END$ marks where the caret lands

Where in Settings

  • Editor › Live Templates — add / edit groups (IDE-wide)
  • Editor › General › Postfix Completion — the postfix variant
  • Editor › Live Templates › By default expand with — Tab / Enter / Space

In VS Code

  • User snippets JSON ↔ Live Templates; ${1:name} ↔ $NAME$
  • Surround With ↔ snippets with $TM_SELECTED_TEXT · See VS Code 10

⚠ Common Mistakes

  • Defining a template without setting its context — it never appears; click Define under the template
  • Overlapping abbreviations with completion words — templates pop up when you don't want them
  • Forgetting $END$ — caret ends at the last variable instead of the body

✓ Tips & Best Practices

  • Select code then Tools › Save as Live Template to bootstrap one
  • Group team templates and export them
  • Use Surround With for try-with-resources on a selection

Quick Summary
