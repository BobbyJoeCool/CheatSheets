Introduction & Installation

single distribution · Toolbox App · idea launcher · EAP builds · other JetBrains IDEs

Description

IntelliJ IDEA is JetBrains' Java IDE. Since 2025.3 it ships as one distribution: the core IDE is free, and Ultimate features (Spring, Jakarta EE, the profiler, HTTP Client, full database tools) unlock with a subscription. Install it through the Toolbox App, which handles updates, multiple versions and the idea command-line launcher.

Notes

  • This set targets 2026.2 (Java 27 day-one support)
  • Sheets that need a subscription carry a Subscription tag
  • PyCharm, WebStorm, Rider share most of this UI and keymap

⚠ Common Mistakes

  • Installing outside Toolbox and then via Toolbox — two copies with separate settings and plugins
  • Skipping Find Action — most "missing" features are just unbound

✓ Tips & Best Practices

  • Learn three keys first: ⇧⇧, ⇧⌘A, ⌥⏎
  • Use Toolbox to roll back if an update breaks a plugin
  • Check JetBrains' feature comparison page for the current free/paid split
