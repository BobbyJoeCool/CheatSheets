Sheet 03

The Interface

new UI · main toolbar · tool windows · Search Everywhere ⇧⇧ · Find Action · Distraction-Free

Description

The new UI (default since 2024.2) has a compact main toolbar (project, branch, run widget), tool window stripes on the left, right and bottom, and editor tabs in the middle. Every tool window has a shortcut; Search Everywhere finds files, classes, symbols, actions and settings from one box.

Notes

  • Hide all tool windows: ⇧⌘F12 / Ctrl+Shift+F12
  • Esc returns focus to the editor from any tool window
  • Drag tool window icons to move them between stripes
  • Classic UI is available as a plugin

⚠ Common Mistakes

  • Clicking through menus for actions — ⇧⇧ or ⇧⌘A finds them faster and shows the shortcut
  • Closing tool windows to make space — use ⇧⌘F12 to toggle them all
  • Losing the editor focus — press Esc instead of clicking

✓ Tips & Best Practices

  • Use ⌘E as your main file switcher
  • Pin a layout with Window › Store Current Layout as Default
  • Turn on Compact mode on small screens

Quick Summary
