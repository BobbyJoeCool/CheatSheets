Sheet 12

Find Usages & Search

Find Usages ⌥F7 · Show Usages ⌥⌘F7 · Find in Files ⇧⌘F · Replace in Files · regex · scopes

Description

Find Usages searches by meaning: it finds real references to a symbol, not text that happens to match. Find in Files is the text search, with regex, file masks and scopes (project, module, tests, changed files). Use usages for code and text search for strings, config and comments.

Notes

  • Show Usages opens a popup; Find Usages opens the tool window
  • Regex replace supports $1 groups and case conversion \U$1
  • Custom scopes: Settings › Appearance & Behavior › Scopes

Explained

Find Usages groups results: read / write access, imports, tests
.* in the search bar toggles regex; Cc match case; W whole word
File mask (*.yml) limits Find in Files
Open results in the Find tool window to keep them

Where in Settings

  • Appearance & Behavior › Scopes — named scopes for search and inspections
  • Editor › General › Smart Keys — Find selected text with ⌘F
  • Advanced Settings › Find in Files — results limit

In VS Code

  • Find All References ⇧F12 ↔ ⌥F7; Search view ⇧⌘F ↔ Find in Files
  • Search Editor ↔ Find tool window · See VS Code 09

⚠ Common Mistakes

  • Text-searching a method name to rename it — misses overloads and hits comments; use Rename (sheet 15)
  • Forgetting the scope is "Directory" from last time — results look incomplete
  • Regex replace without previewing — use Preview before Replace All

✓ Tips & Best Practices

  • ⌥⌘F7 popup is fastest for a quick look
  • Use Changed Files scope before committing
  • Structural Search (sheet 17) for code-shape searches

Quick Summary
