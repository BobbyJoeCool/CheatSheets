Sheet 10

Formatting, Imports & Code Style

Reformat Code ⌥⌘L · Optimize Imports ⌃⌥O · code style schemes · .editorconfig · Actions on Save

Description

Reformat Code applies the project's code style (indents, wrapping, spacing). Optimize Imports removes unused imports and sorts the rest. Both can run automatically with Actions on Save. Commit the code style to .idea/codeStyles/ or use **.editorconfig** so everyone formats the same way.

Notes

  • .editorconfig overrides IDE code style when supported
  • Reformat a selection, a file, or a whole directory (right-click)
  • Import on-demand thresholds decide when * imports appear

Plugin Pick

  • CheckStyle-IDEA — runs Checkstyle rules in the editor
  • google-java-format — replaces the formatter with Google style

.editorconfig for a Java Project

root = true

[*]
charset = utf-8
end_of_line = lf
insert_final_newline = true

[*.java]
indent_style = space
indent_size = 4
max_line_length = 120
ij_java_class_count_to_use_import_on_demand = 99
ij_java_names_count_to_use_import_on_demand = 99

Code Explained

ij_java_* keys — IntelliJ-specific settings inside .editorconfig
99 thresholds — effectively never use * imports
Export: Code Style › ⚙ › Export › EditorConfig File
Reformat on a directory: right-click › Reformat Code

Where in Settings

  • Editor › Code Style › Java — scheme (Project vs IDE)
  • Tools › Actions on Save — reformat, optimize imports, rearrange
  • Editor › General › Auto Import — optimize imports on the fly

In VS Code

  • Format Document ⇧⌥F ↔ ⌥⌘L; editor.formatOnSave ↔ Actions on Save
  • .editorconfig works in both (extension in VS Code) · See VS Code 14

⚠ Common Mistakes

  • Reformatting whole files in a PR — huge diffs; choose changed lines only in Actions on Save
  • Keeping code style at IDE level — teammates format differently; switch the scheme to Project
  • Mixing formatter plugins with Actions on Save — they fight over the same lines

✓ Tips & Best Practices

  • Mark generated code with // @formatter:off / on (enable in Code Style › Formatter)
  • Add .editorconfig to the repo root for all editors
  • Run Reformat on a directory once, commit it alone, then turn on save actions
