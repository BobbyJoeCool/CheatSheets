Sheet 06

Code Completion

basic ⌃Space · type-matching ⌃⇧Space · postfix (.var, .for, .nn) · ⇧⌘⏎ · parameter info

Description

IntelliJ completes as you type. Basic completion lists everything visible; type-matching completion filters to values that fit the expected type. Postfix completion transforms the expression you just typed (list.for → a for loop). Complete Current Statement adds the missing ;, braces or parentheses and moves the caret.

Notes

  • Press basic completion twice for non-imported classes and more
  • ⇥ replaces the word under the caret; ⏎ inserts
  • Full-line completion is a local AI model, free and offline
  • Middle-matching: type uSer to find findUserService

Postfix Completion — Type, Then Press ⇥

users.for          →  for (User user : users) { }
users.fori         →  for (int i = 0; i < users.size(); i++) { }
findUser(id).var   →  User user = findUser(id);
user.nn            →  if (user != null) { }
user.null          →  if (user == null) { }
name.sout          →  System.out.println(name);
expr.return        →  return expr;
flag.not           →  !flag
list.stream        →  list.stream()
user.cast          →  ((Type) user)
order.try          →  try { order } catch (Exception e) { }
x > 0.if           →  if (x > 0) { }

Code Explained

Postfix works after any expression, including method calls
⇧⌘⏎ — finish the statement: adds ;, closes (, opens {
⌘P — show parameter hints for the call under the caret
Custom postfix templates: Editor › General › Postfix Completion

Where in Settings

  • Editor › General › Code Completion — case sensitivity, auto-popup delay
  • Editor › General › Postfix Completion — enable / add templates
  • Editor › General › Inline Completion — full-line AI completion

In VS Code

  • ⌃Space is the same in both editors
  • No built-in postfix in VS Code; Java extension adds a few · See VS Code 12

⚠ Common Mistakes

  • Pressing ⏎ in the middle of a word — inserts and leaves the old tail; use ⇥ to replace
  • Typing the closing ) and ; by hand — ⇧⌘⏎ does it and moves to the next line
  • Disabling auto-popup because it's slow — usually a sign indexing hasn't finished

✓ Tips & Best Practices

  • Use .var constantly — it names variables from the type
  • Sort suggestions by relevance (⋮ in the popup)
  • Type-matching completion after new or return filters to valid types

Quick Summary

  • ⌃Space — basic completion
  • ⌃⇧Space — type-matching
  • .var / .for / .nn — postfix
  • ⇧⌘⏎ — complete statement
