Sheet 09

Generating Code

Generate ⌘N · constructors · getters / setters · equals / hashCode / toString · override ⌃O · records

Description

Generate (⌘N / Alt+Insert) writes boilerplate: constructors, getters and setters, equals()/hashCode(), toString(), delegate methods and test methods. Override and Implement methods list what a superclass or interface offers. Intentions (⌥⏎) can convert a class to a record when it qualifies.

Notes

  • Generated accessors follow JavaBeans naming (Jakarta EE 05)
  • equals/hashCode templates: IntelliJ default, Java 7+ Objects, Apache, Guava
  • In tests, ⌘N offers Test Method, SetUp, TearDown

Plugin Pick

  • Lombok (bundled) — needs annotation processing on: Build… › Compiler › Annotation Processors; IntelliJ offers to enable it

Before ⌘N → After

public class Customer {                   // caret here, ⌘N
    private final String name;
    private int points;
}
// Generate › Constructor, Getter and Setter, equals() and hashCode()
public Customer(String name) { this.name = name; }
public String getName() { return name; }
public int getPoints() { return points; }
public void setPoints(int points) { this.points = points; }
@Override public boolean equals(Object o) {
    if (!(o instanceof Customer c)) return false;
    return points == c.points && Objects.equals(name, c.name);
}
@Override public int hashCode() { return Objects.hash(name, points); }

// ⌥⏎ on the class › "Convert to record" (when fields are final)
public record Customer(String name, int points) { }

Code Explained

final fields get no setter option
instanceof pattern in equals — newer templates use it
⌃O override / ⌃I implement list inherited methods
Convert to record needs immutable fields and no extra state

Where in Settings

  • Editor › Code Style › Java › Code Generation — field prefixes, final params
  • Editor › File and Code Templates — new file headers
  • Build… › Compiler › Annotation Processors — Lombok

In VS Code

  • Java extension: Source Action › Generate Getters and Setters
  • Fewer generators; no Convert-to-record intention · See VS Code 13

⚠ Common Mistakes

  • Generating equals with mutable fields used in a HashSet — hash changes after insert
  • Regenerating toString by hand after adding fields — use Generate again and replace
  • Lombok without annotation processing — red code, missing getters at compile time

✓ Tips & Best Practices

  • Use records for DTOs and value objects; generate only what records can't
  • Turn on Code Generation › *Add @Override* everywhere
  • In tests, ⌘N › Test Method creates the method skeleton

Quick Summary

  • ⌘N — generate
  • ⌃O / ⌃I — override / implement
  • Convert to record — intention
  • Lombok — enable annotation processing
