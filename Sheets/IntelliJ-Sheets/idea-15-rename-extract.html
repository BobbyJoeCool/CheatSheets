Sheet 15

Rename & Extract Refactorings

Rename ⇧F6 · Extract Variable ⌥⌘V · Method ⌥⌘M · Constant ⌥⌘C · Field · Parameter · Refactor This ⌃T

Description

Refactorings change structure without changing behavior, and IntelliJ updates every reference. Rename works on any symbol (classes rename their file). Extract pulls an expression or block into a variable, constant, field, parameter or new method; the method extraction finds duplicates and offers to replace them.

Notes

  • Most refactorings run in place; press ⇧F6/⌥⌘V again for the dialog
  • Select an expression first, or the IDE offers candidates
  • Rename also updates comments and strings if you ask

Before → After Extract

// Before: select the expression, press ⌥⌘V
double total = order.getQty() * order.getPrice() * 1.08;

// Extract Variable (⌥⌘V)
double subtotal = order.getQty() * order.getPrice();
double total = subtotal * 1.08;

// Extract Constant (⌥⌘C) on 1.08
private static final double TAX_RATE = 1.08;
double total = subtotal * TAX_RATE;

// Extract Method (⌥⌘M) on the two lines
double total = totalWithTax(order);
private double totalWithTax(Order order) {
    double subtotal = order.getQty() * order.getPrice();
    return subtotal * TAX_RATE;
}

Code Explained

⌥⌘V with several matches → "Replace all 3 occurrences?"
Extract Method detects parameters and the return value
⌃T Refactor This — menu of refactorings valid here
Rename a class: file, usages, tests and Test classes optional

Where in Settings

  • Editor › Code Editing › Refactorings — in place vs dialog
  • Editor › Code Style › Java › Code Generation — naming prefixes
  • Advanced Settings — rename in comments by default

In VS Code

  • Rename Symbol F2 ↔ ⇧F6; Extract via Quick Fix ⌘.
  • VS Code Java offers fewer extracts (no constant/parameter object) · See VS Code 13

⚠ Common Mistakes

  • Find-and-replace to rename — misses overloads and catches unrelated text
  • Extracting a method mid-expression with side effects — check the preview; order may change
  • Renaming a public API class used by other repos — IntelliJ can't see those callers

✓ Tips & Best Practices

  • Use Extract Method to split long methods, then rename the pieces
  • Undo (⌘Z) reverts a whole refactoring in one step
  • Commit before a large rename so the diff is clean

Quick Summary

  • ⇧F6 — rename everywhere
  • ⌥⌘V / ⌥⌘C — variable / constant
  • ⌥⌘M — extract method
  • ⌃T — refactoring menu
