Sheet 11

Code Navigation

Declaration ⌘B · Implementations ⌥⌘B · Super Method ⌘U · Type / Call Hierarchy · File Structure · Back

Description

Navigation is where IntelliJ pulls furthest ahead of a text editor: it knows every type, so jumps are exact. Go to a declaration, its implementations, the super method, or browse type and call hierarchies. Back and Forward retrace your jumps like a browser.

Notes

  • ⌘-click = Go to Declaration
  • ⌘B on a declaration shows its usages instead
  • Navigate › Related Symbol (⌃⌘↑) jumps between test and class or interface pairs

Explained

File Structure: type to filter members; ⌘F12 again shows inherited
Call Hierarchy toggles callers ↔ callees
Gutter icons (↑ ↓ ●) jump to overridden / implementing methods
Back/Forward cross files; Last Edit Location only follows edits

Where in Settings

  • Editor › General › Breadcrumbs — show path at top or bottom
  • Editor › General › Code Folding — what folds by default
  • Keymap › Main Menu › Navigate — every navigation action

In VS Code

  • F12 Go to Definition ↔ ⌘B; ⇧⌘O Go to Symbol ↔ ⌘F12
  • Go Back ⌃- ↔ ⌘[ · See VS Code 08

⚠ Common Mistakes

  • Scrolling to find a method — ⌘F12 and type is faster
  • Using text search to find callers — Call Hierarchy is exact and ignores comments
  • Forgetting Back — ⌘[ returns after a deep jump chain

✓ Tips & Best Practices

  • CamelHump search: ⌘O then OSI finds OrderServiceImpl
  • Add :42 after a file name to open at a line
  • Pin the Hierarchy tool window when exploring a large type tree
