Sheet 04

Settings & Keymaps

Settings ⌘, · IDE vs project settings · keymap presets · assign a shortcut · Backup and Sync

Description

Settings (⌘, / Ctrl+Alt+S) hold both IDE-level options (theme, keymap, plugins) and project-level ones (code style, inspections, SDK), marked with a project icon. The keymap can follow a preset (macOS, Windows, VS Code, Eclipse) and every action can get a custom shortcut. Backup and Sync carries settings between machines.

Notes

  • Search box in Settings matches option names and descriptions
  • Project-level settings live in .idea/; IDE-level in your config folder
  • Registry… (via Find Action) — internal toggles; change with care

Steps

  1. Open Settings: ⌘, / Ctrl+Alt+S
  2. Go to Keymap; pick a preset (e.g. *macOS*, *VS Code*)
  3. Search an action (e.g. *Reformat Code*) or click 🔍 to find by shortcut
  4. Right-click › Add Keyboard Shortcut and press the keys
  5. Resolve conflicts IntelliJ shows, then Apply
  6. Enable Backup and Sync from the ⚙ menu to sync to your JetBrains account

Where to Find It

Keymap → Settings › Keymap
Sync → ⚙ › Backup and Sync
Export → File › Manage IDE Settings › Export Settings
Config dir → Help › Show Log in Finder (one level up)

Where in Settings

  • Keymap — preset, custom shortcuts (IDE-wide)
  • Appearance & Behavior › System Settings — autosave, confirm exit
  • Editor › General — smart keys, scrolling, soft wraps

In VS Code

  • keybindings.json ↔ Keymap; VS Code keymap preset exists here
  • Settings Sync ↔ Backup and Sync · See VS Code 04–05

⚠ Common Mistakes

  • Changing code style at IDE level and expecting teammates to get it — project code style must be committed
  • Remapping common keys blindly — breaks muscle memory shared with docs and teammates
  • Toggling Registry keys from a blog post — can destabilize the IDE

✓ Tips & Best Practices

  • Quick Switch Scheme (⌃\) toggles theme, keymap, presentation mode
  • Search keymap by shortcut to see what a key already does
  • Export settings before reinstalling
