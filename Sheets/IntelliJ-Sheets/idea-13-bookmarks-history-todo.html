Sheet 13

Bookmarks, Local History & TODO

bookmarks F3 · mnemonic ⌥F3 · Local History · TODO tool window · Recent Locations ⇧⌘E · scratch files

Description

Bookmarks mark lines you return to; mnemonic bookmarks get a letter or digit. Local History is IntelliJ's own versioning: every change is kept locally, so you can restore deleted code even without Git. The TODO tool window collects TODO/FIXME comments, and scratch files give you a runnable throwaway file.

Notes

  • Local History is per machine; it's not a backup
  • Custom TODO patterns: Editor › TODO
  • Scratch files live outside the project

Plugin Pick

⚠ Common Mistakes

  • Relying on Local History as a backup — it's local, time-limited and lost if caches are cleared
  • Leaving TODOs with no owner — the tool window fills up with noise
  • Saving scratch work in the project and committing it by accident

✓ Tips & Best Practices

  • Recent Locations shows code snippets around each visit — great after a long jump chain
  • Filter the TODO window by Current File or Changelist
  • Use scratch files with the HTTP client or SQL console for quick experiments
