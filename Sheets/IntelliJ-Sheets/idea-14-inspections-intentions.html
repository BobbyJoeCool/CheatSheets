Sheet 14

Inspections & Intentions

Show Context Actions ⌥⏎ · severities · inspection profiles · Problems · Inspect Code · @SuppressWarnings

Description

Inspections analyze code as you type and highlight bugs, smells and modernizations. Intentions are quick fixes and conversions offered at the caret via **⌥⏎** (Alt+Enter), the most useful key in the IDE. Inspection profiles set severities and can be shared with the project. Inspect Code runs everything across a scope.

Notes

  • Yellow = warning, red = error, underline = weak warning
  • Lightbulb 💡 = quick fix; pencil = intention
  • F2 jumps to the next problem

Plugin Pick

  • SonarQube for IDE (SonarSource) — Sonar rules in the editor; connect to a server to share rule sets

Where in Settings

  • Editor › Inspections — profile, severities (Project / IDE)
  • Editor › Intentions — enable / disable intentions
  • Tools › Actions on Save › Run code cleanup — apply safe fixes

In VS Code

  • Quick Fix ⌘. ↔ ⌥⏎; Problems ⇧⌘M ↔ ⌘6
  • Linters (ESLint, SonarLint) give similar warnings · See VS Code 12–13

⚠ Common Mistakes

  • Suppressing with @SuppressWarnings("all") — hides real bugs; suppress the specific inspection
  • Changing severities in an IDE profile — teammates don't get it; use a project profile
  • Ignoring red code that compiles — often a stale index; File › Invalidate Caches

✓ Tips & Best Practices

  • Run Inspect Code on a module before a big refactor
  • "Run inspection by name" fixes one issue type across the project
  • Turn on Java language-level migration inspections when upgrading JDKs
