⚠ Common Mistakes

  • JSON.parse on untrusted input without try/catch — a bad body throws
  • JSON.stringify silently dropping undefined, functions and Map values
  • Sending JSON without a Content-Type: application/json header

✓ Tips & Best Practices

  • Stream large files as NDJSON instead of one giant array
  • Use jq to explore API responses from the command line
  • Return problem+json error bodies with type, title, status, detail

Quick Summary

  • Every language has parse + stringify in its standard library or one package
  • JSONPath / jq query; Pointer addresses; Patch edits
  • APIs: application/json in and out, 4xx for bad bodies
  • JSON5 / JSONC for configs; NDJSON for streams
