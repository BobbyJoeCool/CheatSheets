⚠ Common Mistakes

  • Trailing commas, comments or single quotes in strict JSON
  • Large IDs as numbers — JavaScript loses precision past 2^53; send them as strings
  • Treating format as enforced — many validators only annotate it unless asked to assert

✓ Tips & Best Practices

  • Validate payloads against a schema at the boundary of your app
  • Set additionalProperties: false to catch typos in keys
  • Use ISO 8601 strings for dates; JSON has no date type

Quick Summary

  • Six types: string, number, boolean, null, object, array
  • Keys and strings use double quotes only
  • Schema: type, properties, required, items
  • Combine schemas with allOf / anyOf / oneOf
