Sheet 24

Reference Modification & String Functions

field(start:length) · FUNCTION UPPER-CASE / LOWER-CASE · FUNCTION REVERSE · FUNCTION LENGTH · FUNCTION TRIM · FUNCTION ORD / CHAR

Substrings and Intrinsic Functions

Reference modification picks bytes by position: NAME(1:3) is the first three characters. Intrinsic functions return values you can use in MOVE, COMPUTE and conditions: case conversion, reversal, length and trimming.

Key Points

  • Positions start at 1; length is optional (to the end)
  • Start and length can be variables or expressions
  • FUNCTION TRIM is in GnuCOBOL; check your Enterprise COBOL level
  • Out-of-range positions are caught only with SSRANGE

Substrings and Functions

       01  WS-NAME      PIC X(20)  VALUE "  Ada Lovelace".
       01  WS-PHONE     PIC X(10)  VALUE "3195551234".
       01  WS-OUT       PIC X(20).
       01  WS-LEN       PIC 99.
       01  WS-POS       PIC 99     VALUE 4.

           DISPLAY WS-PHONE(1:3)              *> 319
           DISPLAY WS-PHONE(WS-POS:3)         *> 555
           DISPLAY WS-PHONE(7:)               *> 1234
           MOVE "X" TO WS-PHONE(10:1)         *> 319555123X
           MOVE FUNCTION UPPER-CASE(WS-NAME) TO WS-OUT
      *>   "  ADA LOVELACE"
           MOVE FUNCTION TRIM(WS-NAME) TO WS-OUT
      *>   "Ada Lovelace"
           MOVE FUNCTION TRIM(WS-NAME TRAILING) TO WS-OUT
           COMPUTE WS-LEN =
              FUNCTION LENGTH(FUNCTION TRIM(WS-NAME))  *> 12
           MOVE FUNCTION REVERSE(WS-PHONE) TO WS-OUT
           DISPLAY FUNCTION ORD("A")      *> 66 ASCII / 194 EBCDIC
           DISPLAY FUNCTION CHAR(66)      *> A (ASCII)

Code Explained

(7:) takes position 7 through the end
Reference modification also works on the receiving side of a MOVE
TRIM removes leading and trailing spaces; LEADING/TRAILING pick one side
ORD returns the ordinal position (code + 1), not the raw code

Modern Equivalent

  • Python s[0:3], s.upper(), s.strip(), len(s), s[::-1], ord("A")
  • Java s.substring(0, 3), toUpperCase(), strip(), length(), StringBuilder.reverse()
  • JavaScript s.slice(0, 3), toUpperCase(), trim(), length, [...s].reverse().join("")

Prefer / Avoid

  • magic positions (14:2) everywhere → REDEFINES with named sub-fields
  • loops to find the last non-blank → FUNCTION TRIM / LENGTH

String Functions

FunctionReturns
UPPER-CASE(x)Uppercase copy
LOWER-CASE(x)Lowercase copy
TRIM(x [LEADING|TRAILING])Spaces removed
LENGTH(x)Length in bytes
REVERSE(x)Reversed text
ORD(c) / CHAR(n)Ordinal ↔ character
CONCAT(a b …)Joined text (2014; check compiler)

Ref-Mod Forms

FormMeans
x(s:l)l bytes from s
x(s:)s to end
x(i + 1:2)Expression start
tbl(i)(1:3)Table entry substring

⚠ Common Mistakes

  • Starting at 0 instead of 1
  • Length running past the end of the field (no error without SSRANGE)
  • Assuming ORD("A") returns the character code (it is code + 1)

✓ Tips & Best Practices

  • Compile with SSRANGE in test to catch bad positions
  • Prefer named REDEFINES fields for fixed layouts
  • Check your compiler level before using TRIM or CONCAT

Quick Summary

  • x(s:l) — substring
  • UPPER-CASE / LOWER-CASE
  • TRIM — strip spaces
  • LENGTH / REVERSE
