Common Business-Oriented Language

COBOL was designed in 1959 by the CODASYL committee, drawing on Grace Hopper's FLOW-MATIC, so business programs could be written in English-like statements and run on any vendor's machine. It still runs core systems at banks, insurers, airlines and government agencies, mostly as overnight batch jobs and CICS transactions on IBM Z mainframes.

Key Points

  • Source files: .cbl, .cob, .cpy (copybooks)
  • Programs are split into four divisions
  • Strong at fixed-format records and exact decimal math
  • IBM Enterprise COBOL 6.x on z/OS; GnuCOBOL 3.x for local practice

Hello, World

       IDENTIFICATION DIVISION.
       PROGRAM-ID. HELLO.
      * The smallest useful COBOL program
       PROCEDURE DIVISION.
           DISPLAY "Hello, World".
           STOP RUN.

      *> GnuCOBOL:  cobc -x hello.cbl
      *>            ./hello
      *> Output:    Hello, World

Code Explained

IDENTIFICATION DIVISION and PROGRAM-ID are the only required lines
Code starts in column 8; column 7 holds * for comments
DISPLAY writes a line to standard output (SYSOUT on z/OS)
STOP RUN ends the whole run unit; subprograms use GOBACK

Modern Equivalent

  • Python print("Hello, World")
  • Java System.out.println("Hello, World"); inside main
  • JavaScript console.log("Hello, World");

Prefer / Avoid

  • "COBOL is dead" → about 800 billion lines are estimated in production
  • learning old COBOL-74 style → COBOL-85 scope terminators (END-IF)

⚠ Common Mistakes

  • Treating COBOL as a toy language: it handles exact decimal money math better than most languages
  • Starting code in column 1 in fixed format (columns 1–7 are reserved)
  • Using STOP RUN in a called subprogram, which ends the caller too

✓ Tips & Best Practices

  • Practice locally with GnuCOBOL, then move to IBM Z Xplore for real z/OS
  • Read existing programs first: maintenance is most COBOL work
  • Learn JCL alongside COBOL (see the JCL & z/OS set)

Quick Summary

  • DIVISION — four-part program structure
  • DISPLAY — print a line
  • STOP RUN — end the program
