Printing Paged Reports

A COBOL report is a print file written line by line. Each line type is a WORKING-STORAGE group: headings, details and totals. WRITE … AFTER ADVANCING controls spacing, and the program counts lines so it can start a new page with fresh headings when the page fills.

Key Points

  • AFTER ADVANCING PAGE starts a new page
  • AFTER ADVANCING 2 LINES double-spaces
  • Count lines yourself and break at a page limit
  • Print datasets often use RECFM=FBA (ASA control character first)

Headings, Paging and Details

       01  WS-LINE-CT       PIC 99   VALUE 99.
       01  WS-PAGE-CT       PIC 999  VALUE 0.
       01  WS-MAX-LINES     PIC 99   VALUE 55.
       01  HDG-1.
           05 FILLER        PIC X(30) VALUE "ACME BANK".
           05 FILLER        PIC X(30) VALUE "ACCOUNT BALANCES".
           05 FILLER        PIC X(6)  VALUE "PAGE ".
           05 HDG-PAGE      PIC ZZ9.
       01  HDG-2            PIC X(66) VALUE
           "ACCOUNT     NAME                         BALANCE".

       2000-PRINT-DETAIL.
           IF WS-LINE-CT >= WS-MAX-LINES
              PERFORM 2100-HEADINGS
           END-IF
           WRITE PRINT-REC FROM DETAIL-LINE
               AFTER ADVANCING 1 LINE
           ADD 1 TO WS-LINE-CT.

       2100-HEADINGS.
           ADD 1 TO WS-PAGE-CT
           MOVE WS-PAGE-CT TO HDG-PAGE
           WRITE PRINT-REC FROM HDG-1 AFTER ADVANCING PAGE
           WRITE PRINT-REC FROM HDG-2 AFTER ADVANCING 2 LINES
           MOVE 3 TO WS-LINE-CT.

Code Explained

Starting WS-LINE-CT at 99 forces headings before the first detail
Headings reset the line count to the lines they used
HDG-2 is one literal laid out as column titles
Detail lines come from an edited group (sheet 19)

Modern Equivalent

  • Python Write lines to a text file; reportlab or HTML templates for paged output
  • Java Jasper Reports or PrintWriter with manual paging
  • JavaScript HTML/CSS print styles or a PDF library like pdfkit

Prefer / Avoid

  • hard-coded 60-line pages → a WS-MAX-LINES constant
  • headings written once at start → headings on every page break

ADVANCING Options

PhraseEffect
AFTER ADVANCING 1 LINESingle space
AFTER ADVANCING 2 LINESDouble space
AFTER ADVANCING PAGENew page
BEFORE ADVANCING nPrint, then move
AFTER ADVANCING ws-nVariable spacing

ASA Control Chars

CharBefore Printing
spaceSingle space
0Double space
-Triple space
1New page
+No space (overprint)

⚠ Common Mistakes

  • Line counter starting at 0, so the first page has no headings
  • Forgetting to reset the line count after headings
  • Mixing BEFORE and AFTER ADVANCING in one file

✓ Tips & Best Practices

  • Put report title and run date in the first heading line
  • Keep page size in one field so it can change easily
  • Print a "* END OF REPORT *" line so readers know it is complete

Quick Summary
