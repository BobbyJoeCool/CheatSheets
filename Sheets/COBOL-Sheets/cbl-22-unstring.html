Sheet 22

UNSTRING

UNSTRING … DELIMITED BY · ALL SPACES · multiple delimiters OR · INTO · COUNT IN · TALLYING IN

Splitting Text into Fields

UNSTRING breaks a field apart at delimiters and moves each piece into a receiving field, like split. Use it to parse CSV lines, names and free-form input. Optional phrases record each piece's length, which delimiter matched and how many fields were filled.

Key Points

  • ALL SPACES treats a run of blanks as one delimiter
  • List several delimiters with OR
  • Extra pieces are ignored unless you check ON OVERFLOW
  • Each receiver is filled using normal MOVE rules

Parsing a CSV Line

       01  IN-LINE      PIC X(60) VALUE "1042,ADA,LOVELACE,LONDON".
       01  WS-ID        PIC X(6).
       01  WS-FIRST     PIC X(15).
       01  WS-LAST      PIC X(20).
       01  WS-CITY      PIC X(15).
       01  WS-LEN-LAST  PIC 99.
       01  WS-FIELDS    PIC 99 VALUE 0.
       01  WS-DELIM     PIC X.

           UNSTRING IN-LINE DELIMITED BY "," OR ";"
               INTO WS-ID
                    WS-FIRST
                    WS-LAST  DELIMITER IN WS-DELIM
                             COUNT IN WS-LEN-LAST
                    WS-CITY
               TALLYING IN WS-FIELDS
               ON OVERFLOW DISPLAY "EXTRA FIELDS"
           END-UNSTRING
      *>   WS-ID "1042"  WS-LAST "LOVELACE"  WS-LEN-LAST 8
      *>   WS-DELIM ","  WS-FIELDS 4

           UNSTRING "ADA    BYRON  KING" DELIMITED BY ALL SPACES
               INTO WS-FIRST WS-LAST WS-CITY
           END-UNSTRING

Code Explained

Each comma-separated piece goes to the next receiver
COUNT IN gets the length of the piece before padding
TALLYING IN adds the number of receivers filled (start it at 0)
ALL SPACES collapses runs of blanks between words

Modern Equivalent

  • Python line.split(","); re.split(r"[,;]", line); s.split() for spaces
  • Java line.split(","); line.split("[,;]"); s.trim().split("\\s+")
  • JavaScript line.split(","); line.split(/[,;]/); s.trim().split(/\s+/)

Prefer / Avoid

  • quoted CSV with embedded commas → a real parser or JSON PARSE
  • tallying without resetting → MOVE 0 to the counter first

Phrases

PhraseGives
DELIMITED BY x OR ySplit points
ALL litRuns count as one
DELIMITER IN dWhich delimiter ended the piece
COUNT IN nPiece length
WITH POINTER pStart position
TALLYING IN tReceivers filled
ON OVERFLOWMore data than receivers

⚠ Common Mistakes

  • Not resetting the TALLYING counter, so counts accumulate
  • Receivers too short, silently cutting long values
  • Using it on quoted CSV with commas inside quotes

✓ Tips & Best Practices

  • Unstring into PIC X fields, then validate and convert numbers
  • Use COUNT IN to detect empty fields (length 0)
  • Use ON OVERFLOW to catch lines with extra columns

Quick Summary

  • UNSTRING … INTO — split
  • ALL SPACES — collapse blanks
  • COUNT IN — piece length
  • TALLYING IN — field count
