Counting and Replacing Characters

INSPECT scans a field in place. TALLYING counts occurrences, REPLACING swaps characters or strings of the same length, and CONVERTING maps one set of characters to another. BEFORE and AFTER INITIAL limit the scan to part of the field.

Key Points

  • Replacement text must be the same length as the original
  • Tally counters are added to, not reset
  • LEADING only matches at the start of the field
  • CONVERTING is a character-for-character translation

Count, Replace, Convert

       01  WS-TEXT      PIC X(30) VALUE "000123-45-6789  MAIN ST".
       01  WS-NAME      PIC X(20) VALUE "ada lovelace".
       01  WS-COUNT     PIC 99.
       01  WS-ZEROS     PIC 99.

           MOVE 0 TO WS-COUNT WS-ZEROS
           INSPECT WS-TEXT TALLYING WS-COUNT FOR ALL "-"
      *>   WS-COUNT = 2
           INSPECT WS-TEXT TALLYING WS-ZEROS FOR LEADING "0"
      *>   WS-ZEROS = 3
           INSPECT WS-TEXT REPLACING ALL "-" BY " "
      *>   "000123 45 6789  MAIN ST"
           INSPECT WS-TEXT REPLACING LEADING "0" BY " "
      *>   "   123 45 6789  MAIN ST"
           INSPECT WS-TEXT REPLACING ALL " " BY "_"
                   AFTER INITIAL "ST"
           INSPECT WS-NAME CONVERTING
                   "abcdefghijklmnopqrstuvwxyz"
                TO "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
      *>   "ADA LOVELACE"
           MOVE 0 TO WS-COUNT
           INSPECT WS-NAME TALLYING WS-COUNT
                   FOR CHARACTERS BEFORE INITIAL " "
      *>   WS-COUNT = 3 ("ADA")

Code Explained

FOR ALL "-" counts every dash
FOR LEADING "0" stops at the first non-zero
AFTER INITIAL "ST" only touches bytes after the first ST
CHARACTERS BEFORE INITIAL " " counts the bytes before the first blank

Modern Equivalent

  • Python s.count("-"), s.replace("-", " "), s.upper(), s.translate(...)
  • Java s.chars().filter(c -> c == '-').count(), s.replace(...), s.toUpperCase()
  • JavaScript s.split("-").length - 1, s.replaceAll("-", " "), s.toUpperCase()

Prefer / Avoid

  • CONVERTING for case → FUNCTION UPPER-CASE (clearer)
  • REPLACING with different lengths → STRING/UNSTRING or a new field

INSPECT Forms

FormDoes

⚠ Common Mistakes

  • Not zeroing the tally field, so each run adds to the last count
  • Replacing "ST" with "STREET" (lengths must match)
  • Expecting LEADING to skip spaces before the zeros

✓ Tips & Best Practices

  • Count trailing spaces: reverse with FUNCTION REVERSE, then tally LEADING spaces
  • Use CONVERTING to strip unwanted characters to spaces
  • Combine TALLYING and REPLACING in one statement to save a pass

Quick Summary

  • TALLYING — count
  • REPLACING — same-length swap
  • CONVERTING — translate
  • INITIAL — limit range
