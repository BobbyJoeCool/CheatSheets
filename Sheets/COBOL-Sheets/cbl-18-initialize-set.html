Sheet 18

INITIALIZE & SET

INITIALIZE · REPLACING NUMERIC BY · REPLACING ALPHANUMERIC BY · SET … TO TRUE · SET index UP BY · SET ADDRESS OF

Resetting Data and Setting Flags

INITIALIZE resets every field in a record by type: numeric fields to zero, alphanumeric fields to spaces, and leaves FILLER alone. SET assigns special items: condition names, indexes, pointers and addresses.

Key Points

  • INITIALIZE skips FILLER and REDEFINES items
  • WITH FILLER (2002+) includes FILLER too
  • TO VALUE resets fields to their VALUE clauses
  • SET is the only way to change an index

INITIALIZE and SET

       01  ORDER-REC.
           05 ORD-ID       PIC 9(6).
           05 ORD-CUST     PIC X(20).
           05 ORD-AMT      PIC S9(7)V99 COMP-3.
           05 FILLER       PIC X(5)  VALUE "*END*".
           05 ORD-STATUS   PIC X     VALUE "N".
              88 ORD-NEW             VALUE "N".
              88 ORD-SHIPPED         VALUE "S".
       01  WS-TABLE.
           05 WS-ITEM      PIC X(10) OCCURS 50 INDEXED BY IX.
       01  WS-PTR          USAGE POINTER.

           INITIALIZE ORDER-REC           *> 0, spaces, 0; FILLER kept
           INITIALIZE ORDER-REC
              REPLACING ALPHANUMERIC BY "?"
                        NUMERIC      BY 1
           INITIALIZE ORDER-REC TO VALUE  *> status back to "N"
           SET ORD-SHIPPED TO TRUE        *> ORD-STATUS = "S"
           SET IX TO 1
           SET IX UP BY 2                 *> IX now 3
           SET WS-PTR TO ADDRESS OF ORDER-REC

Code Explained

Plain INITIALIZE gives zeros and spaces, not VALUE clauses
REPLACING chooses a different fill per category
SET … TO TRUE moves the 88's value into its parent
Indexes hold offsets, so only SET and SEARCH change them

Modern Equivalent

  • Python rec = Order() (new dataclass with defaults)
  • Java order = new Order(); or a reset() method
  • JavaScript order = { ...defaultOrder }

Prefer / Avoid

  • MOVE SPACES TO record → INITIALIZE (keeps numerics valid)
  • MOVE "S" TO ORD-STATUS → SET ORD-SHIPPED TO TRUE

⚠ Common Mistakes

  • MOVE SPACES to a record with numeric fields, then adding to them (S0C7)
  • Expecting INITIALIZE to restore VALUE clauses without TO VALUE
  • Using MOVE or ADD on an index

✓ Tips & Best Practices

  • INITIALIZE output records before building each one
  • Use TO VALUE to reset report headings and defaults
  • Use SET with 88s everywhere flags change

Quick Summary

  • INITIALIZE — zeros & spaces
  • REPLACING — custom fill
  • SET cond TO TRUE — flag
  • SET idx — indexes
