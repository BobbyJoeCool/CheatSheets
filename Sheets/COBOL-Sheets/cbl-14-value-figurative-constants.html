Sheet 14

VALUE & Figurative Constants

VALUE clause · ZERO / ZEROS · SPACE / SPACES · HIGH-VALUES / LOW-VALUES · QUOTE · ALL "literal"

Starting Values and Built-in Constants

The VALUE clause sets an item's initial value when the program loads. Figurative constants are reserved words that fill a field of any size: ZEROS, SPACES, HIGH-VALUES (all bits on) and LOW-VALUES (all bits off). They work in VALUE, MOVE and comparisons.

Key Points

  • WORKING-STORAGE without VALUE starts as whatever was in memory
  • Singular and plural forms are identical: ZERO = ZEROS = ZEROES
  • HIGH-VALUES sorts after everything: a classic end-of-file key
  • VALUE on a group sets the whole group as alphanumeric

Under the Hood

  • HIGH-VALUES = X'FF' bytes; LOW-VALUES = X'00'
  • SPACES = X'40' in EBCDIC, X'20' in ASCII
  • ZEROS moved to a COMP-3 field gives X'000C', a valid packed 0

VALUE and Constants

       01  WS-TOTAL      PIC 9(7)V99   VALUE ZERO.
       01  WS-NAME       PIC X(20)     VALUE SPACES.
       01  WS-TITLE      PIC X(20)     VALUE "MONTHLY REPORT".
       01  WS-LINE       PIC X(40)     VALUE ALL "-".
       01  WS-KEY        PIC X(10)     VALUE LOW-VALUES.
       01  WS-PI         PIC 9V9(4)    VALUE 3.1416.
       01  WS-HEX        PIC X(2)      VALUE X"0D25".
       01  WS-HDR.
           05 FILLER     PIC X(6)      VALUE "PAGE: ".
           05 HDR-PAGE   PIC ZZ9.

           MOVE HIGH-VALUES TO WS-KEY      *> end-of-file marker
           MOVE QUOTE TO WS-NAME(1:1)      *> "
           IF WS-NAME = SPACES
              DISPLAY "NAME IS BLANK"
           END-IF
           MOVE ALL "AB" TO WS-NAME        *> ABABABABAB...

Code Explained

ALL "-" repeats the literal to fill all 40 bytes
FILLER with VALUE builds constant report text
X"0D25" is a hexadecimal literal
Comparing to SPACES works for any length

Modern Equivalent

  • Python " " * 20, "-" * 40, 0, None; b"\xff" * 10
  • Java " ".repeat(20), "-".repeat(40), 0; Arrays.fill
  • JavaScript " ".repeat(20), "-".repeat(40), 0; Buffer.alloc(10, 0xff)

Prefer / Avoid

  • no VALUE on counters → VALUE ZERO (or INITIALIZE at start)
  • magic "9999999999" keys → HIGH-VALUES

⚠ Common Mistakes

  • Doing arithmetic on numeric fields with no VALUE (S0C7 data exception)
  • Moving HIGH-VALUES to a numeric field, which is not a valid number
  • Expecting a VALUE to be reapplied on each call of a subprogram

✓ Tips & Best Practices

  • Give every counter and accumulator VALUE ZERO
  • Build fixed report headings with FILLER VALUE items
  • Use INITIALIZE to reset records between iterations

Quick Summary

  • VALUE — initial value at load
  • ZEROS / SPACES — fill
  • HIGH-VALUES — sorts last
  • ALL "x" — repeat a literal
