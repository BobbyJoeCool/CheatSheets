PICTURE — Alphanumeric & Edited

PIC X / PIC A · Z zero suppression · * check protection · $ , . · CR / DB / + / - · B 0 / insertion

Text Fields and Display Formats

PIC X holds any characters and PIC A holds letters and spaces. Edited pictures format numbers for people: suppress leading zeros, insert commas and a real decimal point, add currency and signs. You MOVE a number into an edited field; you cannot do math on it.

Key Points

  • Alphanumeric moves are left-justified and space-padded
  • Edited fields are for output only
  • Floating $$$ or --- moves the symbol next to the first digit
  • . in an edited picture is a real, stored period

Editing in Action

       01  WS-AMT        PIC S9(5)V99   VALUE -1234.5.
       01  WS-CODE       PIC X(6)       VALUE "AB".
       01  E1            PIC ZZ,ZZ9.99.
       01  E2            PIC $$$,$$9.99.
       01  E3            PIC ***,**9.99.
       01  E4            PIC ZZ,ZZ9.99CR.
       01  E5            PIC -ZZ,ZZ9.99.
       01  E6            PIC 99/99/9999.
       01  E7            PIC 999B99B9999.

           MOVE WS-AMT TO E1    *>  1,234.50  (sign lost)
           MOVE WS-AMT TO E2    *>  $1,234.50
           MOVE WS-AMT TO E3    *> **1,234.50
           MOVE WS-AMT TO E4    *>  1,234.50CR
           MOVE WS-AMT TO E5    *> - 1,234.50
           MOVE 11122026  TO E6 *> 11/12/2026
           MOVE 123456789 TO E7 *> 123 45 6789
           DISPLAY "[" WS-CODE "]"   *> [AB    ]

Code Explained

Z replaces leading zeros with spaces; * with asterisks
$$$,$$9 floats the $ to sit beside the first digit
Without CR, DB, + or -, the sign is lost
B inserts a space and / a slash, useful for IDs and dates

Modern Equivalent

  • Python f"{amt:,.2f}" → -1,234.50; str.ljust(6) pads text
  • Java String.format("%,.2f", amt) or DecimalFormat("#,##0.00")
  • JavaScript amt.toLocaleString("en-US", {minimumFractionDigits: 2})

Prefer / Avoid

  • math on edited fields → keep a numeric field, edit only for output
  • hand-built date strings → edited 99/99/9999 picture

⚠ Common Mistakes

  • Using -ZZ9 but moving a large value, so the leading digit is cut off
  • Forgetting a sign symbol, so negatives print as positives
  • Doing ADD on an edited field (compile error)

✓ Tips & Best Practices

  • Leave one more position than the largest value for the sign or $
  • Use CR on statements and - on internal reports
  • Use BLANK WHEN ZERO for columns that should be empty when 0

Quick Summary

  • X — any text
  • Z — suppress zeros
  • $$$,$$9.99 — floating currency
  • CR / - — show negatives
