Sheet 04

Program Structure — Divisions

IDENTIFICATION DIVISION · ENVIRONMENT DIVISION · DATA DIVISION · PROCEDURE DIVISION · sections & paragraphs · the period

Four Divisions, Always in Order

Every program has up to four divisions: IDENTIFICATION names it, ENVIRONMENT connects it to files, DATA declares every variable and record, and PROCEDURE holds the logic. The PROCEDURE DIVISION is organized into paragraphs (named blocks) that you call with PERFORM.

Key Points

  • Hierarchy: division → section → paragraph → sentence → statement
  • A sentence ends with a period; a statement does not
  • All variables are declared up front in the DATA DIVISION
  • Paragraph names start in Area A (column 8)

A Complete Skeleton

       IDENTIFICATION DIVISION.
       PROGRAM-ID. PAYCALC.
       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT EMP-FILE ASSIGN TO EMPIN.
       DATA DIVISION.
       FILE SECTION.
       FD  EMP-FILE.
       01  EMP-REC            PIC X(80).
       WORKING-STORAGE SECTION.
       01  WS-TOTAL           PIC 9(7)V99 VALUE 0.
       PROCEDURE DIVISION.
       0000-MAIN.
           PERFORM 1000-INIT
           PERFORM 9000-END
           STOP RUN.
       1000-INIT.
           DISPLAY "STARTING".
       9000-END.
           DISPLAY "TOTAL " WS-TOTAL.

Code Explained

0000-MAIN drives the program by calling other paragraphs
Numbered paragraph names (1000-, 9000-) are a common shop standard
Only the last statement in a paragraph needs the period
SELECT … ASSIGN TO EMPIN links the file to DD name EMPIN

Modern Equivalent

  • Python Module with imports, globals, then functions and if __name__ == "__main__":
  • Java Class with fields, then methods, then public static void main
  • JavaScript Module: imports, top-level consts, functions, then a main() call

Prefer / Avoid

  • periods after every statement → one period per paragraph
  • one giant paragraph → small numbered paragraphs called by PERFORM

⚠ Common Mistakes

  • Putting divisions out of order, which is a compile error
  • A stray period inside an IF, which ends the IF early
  • Declaring variables in the PROCEDURE DIVISION (not allowed)

✓ Tips & Best Practices

  • Keep a skeleton template and start every program from it
  • Number paragraphs so their order in the source is obvious
  • Put one paragraph per task: read, validate, write

Quick Summary

  • IDENTIFICATION — program name
  • ENVIRONMENT — files
  • DATA — all variables
  • PROCEDURE — paragraphs of logic
