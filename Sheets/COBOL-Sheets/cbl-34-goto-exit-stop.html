GO TO, EXIT & Ending a Program

GO TO · GO TO … DEPENDING ON · EXIT PARAGRAPH / EXIT PERFORM · STOP RUN vs GOBACK · RETURN-CODE · structured style

Jumps and Exits

GO TO jumps to a paragraph and never comes back, which makes old programs hard to follow. COBOL 2002 added EXIT PARAGRAPH and EXIT PERFORM for structured exits. Programs end with STOP RUN (whole run unit) or GOBACK (return to the caller), setting RETURN-CODE for the job step.

Key Points

  • GOBACK works in main programs and subprograms
  • RETURN-CODE becomes the job step's condition code
  • GO TO … DEPENDING ON jumps by index (1, 2, 3…)
  • Many shops allow GO TO only to an exit paragraph

Old Style vs Structured

      *>   Legacy: PERFORM THRU with GO TO exit
           PERFORM 2000-EDIT THRU 2000-EXIT.
       2000-EDIT.
           IF IN-QTY NOT NUMERIC
              MOVE "BAD QTY" TO ERR-MSG
              GO TO 2000-EXIT
           END-IF
           MOVE IN-QTY TO WS-QTY.
       2000-EXIT.
           EXIT.

      *>   Structured (2002+)
       2100-EDIT.
           IF IN-QTY NOT NUMERIC
              MOVE "BAD QTY" TO ERR-MSG
              EXIT PARAGRAPH
           END-IF
           MOVE IN-QTY TO WS-QTY.

       9000-TERM.
           IF WS-ERRORS > 0
              MOVE 8 TO RETURN-CODE
           END-IF
           GOBACK.

Code Explained

EXIT. alone is a no-op paragraph used as a GO TO target
EXIT PARAGRAPH replaces the GO TO-exit pattern
RC 8 tells the JCL that this step had errors
GOBACK is safe whether or not the program was called

Modern Equivalent

  • Python return from a function; sys.exit(8)
  • Java return; / break;; System.exit(8)
  • JavaScript return; / break;; process.exitCode = 8

Prefer / Avoid

  • GO TO between paragraphs → PERFORM + EXIT PARAGRAPH
  • STOP RUN everywhere → GOBACK (works when called too)

Ending & Exiting

StatementEffect
STOP RUNEnd the run unit
GOBACKReturn to caller / end
EXIT PROGRAMReturn from subprogram
EXIT PARAGRAPHLeave the paragraph
EXIT PERFORMLeave inline loop
GO TO pJump, no return

Return Codes

RCConvention
0Success
4Warning
8Error
12Severe error
16Fatal

⚠ Common Mistakes

  • GO TO out of a PERFORMed paragraph, leaving the PERFORM unfinished
  • STOP RUN in a subprogram, which ends the calling program too
  • Never setting RETURN-CODE, so failed runs look successful

✓ Tips & Best Practices

  • Set RETURN-CODE so the JCL can skip later steps on errors
  • Refactor GO TO only with good tests: legacy logic can depend on it
  • End every program with GOBACK

Quick Summary

  • GO TO — jump, avoid
  • EXIT PARAGRAPH — structured exit
  • GOBACK — return / end
  • RETURN-CODE — step condition code
