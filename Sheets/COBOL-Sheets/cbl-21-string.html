Sheet 21

STRING

STRING … DELIMITED BY SIZE · DELIMITED BY SPACE · INTO · WITH POINTER · ON OVERFLOW · END-STRING

Joining Text Together

STRING concatenates pieces into one receiving field. Each piece is copied up to its delimiter: SIZE takes the whole field, while SPACE or a literal stops at the first match. This is how COBOL trims trailing blanks while building names, CSV lines and messages.

Key Points

  • The receiver is not cleared first: move SPACES to it
  • Copying stops when the receiver is full (overflow)
  • WITH POINTER tracks the next position to write
  • Literals and figurative constants can be pieces

Building a Full Name and CSV Line

       01  FIRST-NAME   PIC X(15)  VALUE "ADA".
       01  LAST-NAME    PIC X(20)  VALUE "LOVELACE".
       01  CITY         PIC X(15)  VALUE "LONDON".
       01  WS-FULL      PIC X(40).
       01  WS-CSV       PIC X(60).
       01  WS-PTR       PIC 99.

           MOVE SPACES TO WS-FULL
           STRING FIRST-NAME DELIMITED BY SPACE
                  " "        DELIMITED BY SIZE
                  LAST-NAME  DELIMITED BY SPACE
             INTO WS-FULL
           END-STRING                     *> "ADA LOVELACE"
           MOVE SPACES TO WS-CSV
           MOVE 1 TO WS-PTR
           STRING LAST-NAME DELIMITED BY "  "
                  ","       DELIMITED BY SIZE
                  CITY      DELIMITED BY "  "
             INTO WS-CSV WITH POINTER WS-PTR
             ON OVERFLOW DISPLAY "CSV TOO LONG"
           END-STRING                     *> "LOVELACE,LONDON"
           DISPLAY WS-PTR                 *> 16 (next free byte)

Code Explained

DELIMITED BY SPACE stops at the first blank, trimming the field
DELIMITED BY " " (two spaces) keeps single spaces inside names
WITH POINTER starts at 1 and ends one past the last byte written
ON OVERFLOW runs if the receiver fills up

Modern Equivalent

  • Python " ".join([first, last]) or f"{first} {last}"
  • Java String.join(" ", first, last) or first + " " + last
  • JavaScript [first, last].join(" ") or ${first} ${last}

Prefer / Avoid

  • DELIMITED BY SPACE on "MARY ANN" → two-space delimiter or FUNCTION TRIM
  • forgetting to clear the receiver → MOVE SPACES before STRING

Clauses

ClauseMeaning
DELIMITED BY SIZEWhole piece
DELIMITED BY SPACEUp to first blank
DELIMITED BY litUp to that text
WITH POINTER pStart/next position
ON OVERFLOWReceiver full or bad pointer
NOT ON OVERFLOWSuccess branch

⚠ Common Mistakes

  • Leftover text from the last use because the receiver was not cleared
  • Names with spaces ("VAN DYKE") cut at the first space
  • Pointer starting at 0, which triggers overflow immediately

✓ Tips & Best Practices

  • Initialize the pointer to 1 before every STRING
  • Use a pointer to append across several STRING statements
  • Check ON OVERFLOW whenever the input lengths vary

Quick Summary

  • STRING … INTO — concatenate
  • DELIMITED BY SPACE — trim
  • WITH POINTER — append position
  • ON OVERFLOW — too long
