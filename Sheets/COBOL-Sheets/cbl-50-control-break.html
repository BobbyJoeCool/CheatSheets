Subtotals When a Key Changes

A control break happens when the key of the current record differs from the previous one in a sorted file. At each break the program prints a subtotal, resets the accumulator and saves the new key. At end of file it forces a final break, then prints the grand total.

Key Points

  • Input must be sorted on the break keys
  • Save the key of the group you are totalling
  • Higher-level breaks trigger all lower-level breaks first
  • Roll each subtotal into the next level's total

Single-Level Break by State

       01  WS-PREV-STATE     PIC XX     VALUE SPACES.
       01  WS-STATE-TOT      PIC S9(9)V99 VALUE 0.
       01  WS-GRAND-TOT      PIC S9(11)V99 VALUE 0.

       0000-MAIN.
           OPEN INPUT SALES-IN OUTPUT RPT-OUT
           PERFORM 8000-READ
           IF NOT END-OF-SALES
              MOVE SL-STATE TO WS-PREV-STATE
           END-IF
           PERFORM UNTIL END-OF-SALES
              IF SL-STATE NOT = WS-PREV-STATE
                 PERFORM 3000-STATE-BREAK
              END-IF
              ADD SL-AMT TO WS-STATE-TOT
              PERFORM 2000-PRINT-DETAIL
              PERFORM 8000-READ
           END-PERFORM
           PERFORM 3000-STATE-BREAK            *> final break
           PERFORM 4000-GRAND-TOTAL
           CLOSE SALES-IN RPT-OUT
           GOBACK.

       3000-STATE-BREAK.
           MOVE WS-PREV-STATE TO ST-LINE-STATE
           MOVE WS-STATE-TOT  TO ST-LINE-AMT
           WRITE PRINT-REC FROM STATE-TOTAL-LINE
               AFTER ADVANCING 2 LINES
           ADD WS-STATE-TOT TO WS-GRAND-TOT
           MOVE ZERO TO WS-STATE-TOT
           MOVE SL-STATE TO WS-PREV-STATE.

Code Explained

The first key is saved before the loop
A changed key prints the previous state's total
The final break after the loop prints the last state
Each state total rolls into the grand total, then resets

Modern Equivalent

  • Python itertools.groupby(rows, key=lambda r: r.state) then sum
  • Java Collectors.groupingBy(R::state, summingDouble(R::amt))
  • JavaScript Object.groupBy(rows, r => r.state) then reduce each group

Prefer / Avoid

  • forgetting the final break → always break once more after the loop
  • unsorted input → sort step before the report

Break Paragraph Steps

StepAction
1Print subtotal line

4Save new key

⚠ Common Mistakes

  • Missing the final break, so the last group has no total
  • Saving the new key before printing, so totals show the wrong label
  • Running a break report on unsorted data

✓ Tips & Best Practices

  • Write one break paragraph per level and call lower levels from higher ones
  • Check that grand total = sum of all detail amounts
  • Test with an empty file and a one-record file

Quick Summary

  • break — key changed
  • save previous key — label totals
  • final break — after the loop
  • roll up — subtotal → total
