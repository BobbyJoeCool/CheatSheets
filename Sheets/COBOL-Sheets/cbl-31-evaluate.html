Sheet 31

EVALUATE

EVALUATE TRUE · EVALUATE variable · WHEN … THRU · ALSO (decision tables) · ANY · WHEN OTHER · END-EVALUATE

COBOL's Case Statement

EVALUATE picks the first matching WHEN and runs its statements: there is no fall-through. EVALUATE TRUE tests a list of conditions; EVALUATE field matches values and ranges; ALSO evaluates two or more subjects at once, like a decision table.

Key Points

  • Only the first matching WHEN runs
  • Stacked WHENs share one action (an OR)
  • WHEN OTHER is the default branch
  • ANY matches anything in an ALSO column

Three EVALUATE Styles

           EVALUATE TRUE
              WHEN WS-SCORE >= 90   MOVE "A" TO WS-GRADE
              WHEN WS-SCORE >= 80   MOVE "B" TO WS-GRADE
              WHEN OTHER            MOVE "F" TO WS-GRADE
           END-EVALUATE

           EVALUATE WS-MONTH
              WHEN 1 THRU 3         MOVE 1 TO WS-QTR
              WHEN 4 THRU 6         MOVE 2 TO WS-QTR
              WHEN 7
              WHEN 8
              WHEN 9                MOVE 3 TO WS-QTR
              WHEN OTHER            MOVE 4 TO WS-QTR
           END-EVALUATE

           EVALUATE TRUE  ALSO WS-STATE
              WHEN MEMBER ALSO "IA"   MOVE .05 TO WS-DISC
              WHEN MEMBER ALSO ANY    MOVE .03 TO WS-DISC
              WHEN OTHER              MOVE 0   TO WS-DISC
           END-EVALUATE

Code Explained

Order matters: the 90 test must come before the 80 test
WHEN 7, 8, 9 stacked act as one branch
ALSO lines up two subjects: a condition and the state
ANY makes the second column match every state

Modern Equivalent

  • Python match month: with case 1|2|3:; if/elif for conditions
  • Java switch (month) { case 1, 2, 3 -> 1; … default -> 4; }
  • JavaScript switch (true) { case score >= 90: … default: … }

Prefer / Avoid

  • nested IF ladders → EVALUATE TRUE
  • no WHEN OTHER → always add one, even if it just logs

Forms

⚠ Common Mistakes

  • Putting a broad WHEN before a narrow one so the narrow one never runs
  • Expecting C-style fall-through between WHENs
  • Leaving out WHEN OTHER and silently skipping bad codes

✓ Tips & Best Practices

  • Use EVALUATE TRUE with 88-level names for readable rules
  • Use ALSO to code a business decision table directly
  • Keep each WHEN to one PERFORM when actions are long

Quick Summary

  • EVALUATE TRUE — condition list
  • WHEN a THRU b — ranges
  • ALSO — decision tables
  • WHEN OTHER — default
