Sheet 15

Condition Names (Level 88)

88 levels · VALUE lists & THRU · IF WS-EOF · SET … TO TRUE · flags & switches · FALSE clause

Naming the Values That Matter

A level-88 item gives a name to one or more values of the field above it. You test the name like a boolean (IF END-OF-FILE) and turn it on with SET … TO TRUE. This replaces magic values like "Y" and "A" scattered through the logic.

Key Points

  • 88s take no storage; they describe the parent field
  • One 88 can list several values or ranges
  • Several 88s on one field act like an enum
  • SET name TO FALSE needs a WHEN SET TO FALSE value

Flags and Enums

       01  WS-EOF-FLAG      PIC X     VALUE "N".
           88 END-OF-FILE             VALUE "Y".
           88 MORE-RECORDS            VALUE "N".
       01  WS-STATUS        PIC X.
           88 ACTIVE                  VALUE "A".
           88 CLOSED                  VALUE "C" "X".
           88 VALID-STATUS            VALUE "A" "C" "X".
       01  WS-AGE           PIC 999.
           88 MINOR                   VALUE 0 THRU 17.
           88 SENIOR                  VALUE 65 THRU 120.
       01  WS-DEBUG         PIC X     VALUE "N".
           88 DEBUG-ON                VALUE "Y"
                                WHEN SET TO FALSE "N".

           PERFORM UNTIL END-OF-FILE
              READ IN-FILE AT END SET END-OF-FILE TO TRUE
              END-READ
           END-PERFORM
           IF NOT VALID-STATUS
              DISPLAY "BAD STATUS " WS-STATUS
           END-IF
           SET DEBUG-ON TO FALSE           *> moves "N"

Code Explained

SET END-OF-FILE TO TRUE moves "Y" to the parent field
CLOSED is true for either "C" or "X"
THRU defines a range, inclusive at both ends
WHEN SET TO FALSE tells SET … FALSE what to move

Modern Equivalent

  • Python Enum class or constants; status in {"C", "X"}
  • Java enum Status { ACTIVE, CLOSED }; boolean eof
  • JavaScript Object of constants or a TypeScript enum; Set.has()

Prefer / Avoid

  • IF WS-STATUS = "A" → IF ACTIVE
  • MOVE "Y" TO WS-EOF-FLAG → SET END-OF-FILE TO TRUE

⚠ Common Mistakes

  • SET … TO TRUE on an 88 with several values moves only the first one
  • Testing the parent field with literals and the 88 elsewhere (inconsistent)
  • Using SET … TO FALSE without a WHEN SET TO FALSE clause

✓ Tips & Best Practices

  • Name 88s as yes/no questions: IS-VALID, END-OF-FILE
  • Add a VALID-… 88 listing every legal code for validation
  • Define 88s in the copybook so every program shares them

Quick Summary

  • 88 — named value(s)
  • IF name — test
  • SET name TO TRUE — assign
  • THRU — inclusive range
