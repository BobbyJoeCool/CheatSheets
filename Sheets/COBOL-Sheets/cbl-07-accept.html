Sheet 07

ACCEPT

ACCEPT … FROM CONSOLE · ACCEPT from SYSIN · FROM DATE YYYYMMDD · FROM TIME · FROM DAY-OF-WEEK · FUNCTION CURRENT-DATE

Reading Input and System Values

ACCEPT reads a line of input into a data item, or copies a system value such as the date or time. In batch, plain ACCEPT reads from SYSIN (an in-stream card in the JCL); interactive programs on GnuCOBOL read from the keyboard.

Key Points

  • Input is moved into the field like an alphanumeric MOVE
  • Each ACCEPT reads the next SYSIN record
  • FROM DATE without YYYYMMDD gives a 2-digit year
  • FUNCTION CURRENT-DATE returns 21 characters with time zone

ACCEPT Forms

       WORKING-STORAGE SECTION.
       01  WS-PARM        PIC X(20).
       01  WS-TODAY       PIC 9(8).
       01  WS-NOW         PIC 9(8).
       01  WS-DOW         PIC 9.
       01  WS-STAMP.
           05 WS-YYYY     PIC 9(4).
           05 WS-MM       PIC 99.
           05 WS-DD       PIC 99.
           05 FILLER      PIC X(13).
       PROCEDURE DIVISION.
           ACCEPT WS-PARM                *> next SYSIN line
           ACCEPT WS-TODAY FROM DATE YYYYMMDD  *> 20261112
           ACCEPT WS-NOW   FROM TIME     *> HHMMSShh 14302599
           ACCEPT WS-DOW   FROM DAY-OF-WEEK    *> 1=Mon..7=Sun
           MOVE FUNCTION CURRENT-DATE TO WS-STAMP
           DISPLAY WS-YYYY "-" WS-MM "-" WS-DD *> 2026-11-12
           STOP RUN.

      *> JCL:  //SYSIN DD *
      *>       BRANCH042
      *>       /*

Code Explained

ACCEPT WS-PARM reads BRANCH042 from the JCL's in-stream SYSIN
TIME is hours, minutes, seconds and hundredths
Lay out CURRENT-DATE as a group to pick out parts
For startup parameters, many shops prefer PARM= + LINKAGE

Modern Equivalent

  • Python input(); date.today().strftime("%Y%m%d")
  • Java scanner.nextLine(); LocalDate.now().format(BASIC_ISO_DATE)
  • JavaScript readline for input; new Date().toISOString().slice(0,10)

Prefer / Avoid

  • ACCEPT … FROM DATE (2-digit year) → DATE YYYYMMDD
  • hard-coded run dates → read them from SYSIN so reruns can override

⚠ Common Mistakes

  • Using 2-digit FROM DATE (the Y2K bug in miniature)
  • No SYSIN DD in the JCL, so ACCEPT gets end-of-file or abends
  • Accepting into a numeric field and getting non-numeric data

✓ Tips & Best Practices

  • Accept into PIC X, validate with IS NUMERIC, then move
  • Use FUNCTION CURRENT-DATE when you also need the time zone
  • Let SYSIN override the run date for testing and reruns

Quick Summary

  • ACCEPT x — read SYSIN or keyboard
  • FROM DATE YYYYMMDD — 4-digit date
  • FROM TIME — HHMMSShh
  • CURRENT-DATE — date, time, offset
