Sheet 59

Compiler Options & Listings

CBL / PROCESS statements · SSRANGE · NUMPROC · TRUNC · ARITH · OPTIMIZE · LIST / MAP / XREF

Options That Change Behavior

Enterprise COBOL options control both performance and results: TRUNC decides whether binary fields are truncated to their PIC digits, NUMPROC how signs are handled, and SSRANGE whether subscripts are checked. The compile listing shows options, messages, cross-references and the generated code.

Key Points

  • Options come from shop defaults, the JCL PARM, or CBL/PROCESS in source
  • CBL statements must come before IDENTIFICATION DIVISION
  • Message severities: I (info), W (4), E (8), S (12), U (16)
  • Changing TRUNC or NUMPROC can change program output

Under the Hood

  • TRUNC(STD) truncates COMP to PIC digits; TRUNC(BIN) keeps the full binary value but is slower
  • OPTIMIZE(2) can reorder code, making some debug output look out of order
  • LIST shows the machine code for each statement: useful for S0C7 offsets

Options in Source and JCL

       CBL SSRANGE,TRUNC(STD),ARITH(EXTEND),OPTIMIZE(0)
       CBL LIST,MAP,XREF,OFFSET
       IDENTIFICATION DIVISION.
       PROGRAM-ID. PAYCALC.

      *> JCL PARM on the compile step:
      *> //COBOL EXEC PGM=IGYCRCTL,
      *> //  PARM='SSRANGE,XREF,MAP,LIST,RENT'

      *> GnuCOBOL equivalents:
      *> cobc -x -debug           (runtime checks like SSRANGE)
      *> cobc -x -fbinary-truncate=no   (like TRUNC(BIN))
      *> cobc -x -t listing.lst   (listing file)

Code Explained

Two CBL lines set options for this compile only
SSRANGE catches bad subscripts at run time
MAP and XREF list every field's offset and every reference
OPTIMIZE(0) keeps code in source order while debugging

Modern Equivalent

  • Python Interpreter flags: python -O, -W error
  • Java javac -Xlint:all -g; JVM flags like -ea
  • JavaScript tsc --strict, node --trace-warnings

Prefer / Avoid

  • changing TRUNC/NUMPROC per program → keep shop-wide defaults
  • testing without SSRANGE → SSRANGE in test, measured in prod

⚠ Common Mistakes

  • Putting CBL after IDENTIFICATION DIVISION (it is ignored or an error)
  • Ignoring W-level messages about truncation
  • Changing TRUNC and getting different results from binary fields

✓ Tips & Best Practices

  • Keep LIST/OFFSET listings for production modules to map abend offsets
  • Read the options page of the listing when results differ between environments
  • Treat compile RC 4 warnings as work to fix

Quick Summary

  • CBL / PARM — set options
  • SSRANGE — bounds checks
  • TRUNC / NUMPROC — change results
  • listing — MAP, XREF, offsets
