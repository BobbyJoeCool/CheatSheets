COPY & Copybooks

COPY member · REPLACING ==:PREFIX:== BY ==WS== · copybook libraries & SYSLIB · -I in GnuCOBOL · shared record layouts · REPLACE statement

Sharing Code Between Programs

A copybook is a source member that the compiler pastes in wherever COPY appears. Shops keep every record layout, common working-storage and standard paragraphs in copybooks so all programs agree on file formats. REPLACING swaps text as it is copied, such as a field prefix.

Key Points

  • Copybooks are found in SYSLIB (z/OS) or -I paths (GnuCOBOL)
  • A COPY statement ends with a period
  • ==text== delimits pseudo-text for REPLACING
  • Changing a copybook means recompiling every program that uses it

A Copybook and Two Uses

      *> Member CUSTREC (in USER.COPYLIB or copy/CUSTREC.cpy)
       01  :PFX:-CUSTOMER.
           05 :PFX:-ID          PIC 9(6).
           05 :PFX:-NAME        PIC X(30).
           05 :PFX:-STATE       PIC XX.
           05 :PFX:-BALANCE     PIC S9(7)V99 COMP-3.

      *> In the program:
       WORKING-STORAGE SECTION.
           COPY CUSTREC REPLACING ==:PFX:== BY ==IN==.
           COPY CUSTREC REPLACING ==:PFX:== BY ==OUT==.
      *>   gives IN-CUSTOMER, IN-ID … and OUT-CUSTOMER, OUT-ID …

       PROCEDURE DIVISION.
           MOVE IN-ID TO OUT-ID
           COPY ERRPARA.                   *> shared paragraphs

      *> GnuCOBOL:  cobc -x -I copy main.cbl
      *> z/OS:      //COBOL.SYSLIB DD DSN=USER.COPYLIB,DISP=SHR

Code Explained

:PFX: is a placeholder tag, replaced on each COPY
One layout serves input and output with different prefixes
Paragraph copybooks share standard error handling
The compile listing shows copied lines, often marked with a C

Modern Equivalent

  • Python import a module with a shared @dataclass
  • Java A shared class or record in a common library JAR
  • JavaScript import a shared type or schema module

Prefer / Avoid

  • layouts typed into each program → one copybook per record
  • copybooks with logic that varies by program → parameters via REPLACING or CALL

COPY Forms

FormEffect
COPY member.Paste member
COPY member OF lib.From a named library
REPLACING ==a== BY ==b==Swap pseudo-text
REPLACING a BY bSwap whole words
REPLACE ==a== BY ==b==.Applies to following source
REPLACE OFF.Stop replacing

⚠ Common Mistakes

  • Changing a copybook and recompiling only some programs (file layouts disagree)
  • Missing period after COPY
  • Placeholder text that also appears in normal names, so REPLACING changes too much

✓ Tips & Best Practices

  • Use a distinctive tag like :PFX: for prefixes
  • Search the compile listing to see the final expanded source
  • Track which programs use each copybook (impact analysis)

Quick Summary

  • COPY m. — paste source
  • REPLACING — swap text
  • SYSLIB / -I — search path
  • one layout per copybook
