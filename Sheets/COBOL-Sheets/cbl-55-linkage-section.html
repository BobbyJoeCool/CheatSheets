LINKAGE SECTION & Parameters

LINKAGE SECTION · PROCEDURE DIVISION USING · RETURNING · GOBACK · matching caller & callee layouts · ENTRY points

Receiving Parameters

The LINKAGE SECTION describes data owned by someone else: the caller's parameters or the JCL PARM. PROCEDURE DIVISION USING lists the items in the same order the caller passes them. Names may differ; only position and layout must match.

Key Points

  • LINKAGE items have no storage until a call maps them
  • Parameters are matched by position, not name
  • A main program can receive the JCL PARM as a length + text
  • RETURNING gives function-style results (2002+)

Subprogram and JCL PARM

      *> Subprogram receiving two parameters
       IDENTIFICATION DIVISION.
       PROGRAM-ID. VALIDATE.
       DATA DIVISION.
       LINKAGE SECTION.
       01  LK-RECORD          PIC X(200).
       01  LK-RESULT.
           05 LK-VALID        PIC X.
              88 LK-IS-VALID          VALUE "Y".
           05 LK-REASON       PIC X(30).
       PROCEDURE DIVISION USING LK-RECORD LK-RESULT.
           SET LK-IS-VALID TO TRUE
           IF LK-RECORD(1:10) NOT NUMERIC
              MOVE "N" TO LK-VALID
              MOVE "BAD ACCOUNT" TO LK-REASON
           END-IF
           GOBACK.

      *> Main program receiving PARM='2026-11'
       LINKAGE SECTION.
       01  LK-PARM.
           05 LK-PARM-LEN     PIC S9(4) COMP.
           05 LK-PARM-TEXT    PIC X(100).
       PROCEDURE DIVISION USING LK-PARM.
           IF LK-PARM-LEN > 0
              DISPLAY "RUN PERIOD " LK-PARM-TEXT(1:LK-PARM-LEN)
           END-IF

Code Explained

The caller passes CALL "VALIDATE" USING IN-REC WS-RESULT
VALIDATE writes LK-RESULT, which is the caller's WS-RESULT
z/OS passes the PARM as a halfword length followed by the text
Only use the first LK-PARM-LEN bytes: the rest is not yours

Modern Equivalent

  • Python def validate(record, result): positional parameters; sys.argv for run args
  • Java static void validate(String rec, Result r); main(String[] args)
  • JavaScript function validate(rec, result); process.argv for run args

Prefer / Avoid

  • reading past the PARM length → reference-modify with LK-PARM-LEN
  • LINKAGE layouts typed by hand → shared copybook

⚠ Common Mistakes

  • Different parameter order in caller and callee
  • Reading the full 100-byte PARM area when only 7 bytes were passed
  • Giving LINKAGE items VALUE clauses

✓ Tips & Best Practices

  • Name LINKAGE items with an LK- prefix
  • Check the PARM length before using it
  • Return status in a parameter field rather than RETURN-CODE for subprograms

Quick Summary

  • LINKAGE — caller's data
  • USING — by position
  • PARM — length + text
  • GOBACK — return
