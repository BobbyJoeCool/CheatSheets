SELECT & ASSIGN

FILE-CONTROL · SELECT … ASSIGN TO · ORGANIZATION IS · ACCESS MODE IS · FILE STATUS IS · GnuCOBOL vs z/OS assignment

Declaring Files

Each file gets a SELECT entry in the FILE-CONTROL paragraph. It gives the internal file name, the external name it is assigned to, its organization, how it will be accessed, and the two-byte FILE STATUS field that receives a result code after every I/O.

Key Points

  • On z/OS, the ASSIGN name is the DD name (max 8 characters)
  • GnuCOBOL maps ASSIGN names to env vars DD_name or file names
  • ACCESS MODE is SEQUENTIAL, RANDOM or DYNAMIC
  • One SELECT per file, even input and output of the same layout

SELECT Examples

       FILE-CONTROL.
           SELECT TRAN-IN  ASSIGN TO TRANIN
               ORGANIZATION IS SEQUENTIAL
               ACCESS MODE  IS SEQUENTIAL
               FILE STATUS  IS WS-TRAN-FS.

           SELECT ACCT-MAST ASSIGN TO ACCTMAST
               ORGANIZATION IS INDEXED
               ACCESS MODE  IS DYNAMIC
               RECORD KEY   IS AM-ACCT-NO
               FILE STATUS  IS WS-ACCT-FS.

           SELECT RPT-OUT  ASSIGN TO RPTOUT
               FILE STATUS  IS WS-RPT-FS.

      *>   GnuCOBOL only: text file named by literal
           SELECT CSV-IN   ASSIGN TO "data/input.csv"
               ORGANIZATION IS LINE SEQUENTIAL
               FILE STATUS  IS WS-CSV-FS.

Code Explained

SEQUENTIAL is the default organization and access mode
Indexed files need RECORD KEY (sheet 44)
DYNAMIC allows both random and sequential reads
A literal path is handy on GnuCOBOL; production uses DD names

Modern Equivalent

  • Python open(os.environ["TRANIN"]) style config-driven paths
  • Java Path.of(System.getenv("TRANIN"))
  • JavaScript fs.createReadStream(process.env.TRANIN)

Prefer / Avoid

  • no FILE STATUS → a status field on every SELECT
  • literal paths in production code → DD names / env vars

⚠ Common Mistakes

  • ASSIGN names longer than 8 characters on z/OS
  • Same DD name used for two SELECTs
  • Indexed file declared without RECORD KEY

✓ Tips & Best Practices

  • Name DD names after the file's role: ACCTMAST, TRANIN, RPTOUT
  • Use one FILE STATUS field per file, not a shared one
  • On GnuCOBOL, set DD_name variables in a run script

Quick Summary

  • SELECT … ASSIGN TO dd
  • ORGANIZATION — file type
  • ACCESS MODE — how you read
  • FILE STATUS — result code
