Sheet 06

DISPLAY

DISPLAY · literals & variables · UPON CONSOLE / UPON SYSOUT · WITH NO ADVANCING · figurative constants · debug output

Writing Lines of Output

DISPLAY writes one or more literals and data items as a single line. On z/OS the line goes to SYSOUT (the job log); under GnuCOBOL it goes to the terminal. It is meant for messages and debugging; reports go through file WRITE statements.

Key Points

  • Items are joined with no separator; add " " yourself
  • Numeric DISPLAY fields print all digits, including leading zeros
  • Signed fields show an overpunched last digit unless edited
  • Each DISPLAY ends the line unless WITH NO ADVANCING

DISPLAY Variations

       WORKING-STORAGE SECTION.
       01  WS-NAME     PIC X(10)    VALUE "ADA".
       01  WS-QTY      PIC 9(5)     VALUE 42.
       01  WS-AMT      PIC S9(5)V99 VALUE -12.50.
       01  WS-AMT-ED   PIC -ZZ,ZZ9.99.
       PROCEDURE DIVISION.
           DISPLAY "HELLO"                *> HELLO
           DISPLAY "NAME: " WS-NAME "|"   *> NAME: ADA       |
           DISPLAY WS-QTY                 *> 00042
           DISPLAY WS-AMT                 *> 0001250- (GnuCOBOL)
           MOVE WS-AMT TO WS-AMT-ED
           DISPLAY WS-AMT-ED              *>     -12.50
           DISPLAY "NO NEWLINE " WITH NO ADVANCING
           DISPLAY "SAME LINE"            *> NO NEWLINE SAME LINE
           DISPLAY "TO OPERATOR" UPON CONSOLE
           DISPLAY ALL "-"                *> repeat "-" (1 char)
           STOP RUN.

Code Explained

PIC X(10) pads with spaces, so ADA prints with trailing blanks
Move numbers to an edited field before displaying them
Signed DISPLAY output differs by compiler; never parse it
UPON CONSOLE sends to the z/OS operator console: avoid in batch

Modern Equivalent

  • Python print("NAME:", name) adds spaces; end="" skips the newline
  • Java System.out.print(...) vs println(...)
  • JavaScript console.log("NAME:", name); process.stdout.write() for no newline

Prefer / Avoid

  • displaying raw numeric fields → move to an edited PIC first
  • leaving debug DISPLAYs in production → D lines or a debug flag

Common Forms

FormResult
DISPLAY litText line
DISPLAY a b cConcatenated, no spaces
WITH NO ADVANCINGNo line break
UPON SYSOUTJob log (default)
UPON CONSOLEOperator console
UPON SYSERRstderr (GnuCOBOL)

What Prints

FieldShows

COMP-3 fieldconverted to digits

⚠ Common Mistakes

  • Expecting a decimal point from PIC 9V99 (the V is implied, not printed)
  • Displaying COMP-3 data with a group move first, which prints garbage bytes
  • Relying on DISPLAY for report output instead of a print file

✓ Tips & Best Practices

  • Wrap values in "|" delimiters while debugging to see padding
  • Create edited fields like PIC Z,ZZ9.99 for any number a person reads
  • Use UPON SYSERR in GnuCOBOL for error messages

Quick Summary

  • DISPLAY a b — one line, no separators
  • WITH NO ADVANCING — stay on the line
  • edited PIC — readable numbers
  • UPON CONSOLE — operator, rarely used
