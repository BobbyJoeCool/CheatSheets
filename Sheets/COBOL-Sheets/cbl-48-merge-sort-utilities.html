MERGE & Sort Utilities

MERGE … USING … GIVING · DFSORT / Syncsort · sorting in a JCL step · SORT-CONTROL · COBOL vs utility

Combining Sorted Files

MERGE combines two or more files that are already sorted on the same keys into one sorted file. Many shops skip COBOL for plain sorting and merging and use a DFSORT (or Syncsort) step in the JCL instead, keeping COBOL for the business logic.

Key Points

  • All MERGE inputs must be in the merge key order
  • MERGE allows an OUTPUT PROCEDURE but no INPUT PROCEDURE
  • DFSORT can also filter, reformat and sum in one step
  • SORT-CONTROL names a DD with extra sort control statements

MERGE in COBOL

       FILE-CONTROL.
           SELECT MERGE-WORK ASSIGN TO MRGWK.
           SELECT EAST-TRANS ASSIGN TO EASTIN.
           SELECT WEST-TRANS ASSIGN TO WESTIN.
           SELECT ALL-TRANS  ASSIGN TO ALLOUT.

       SD  MERGE-WORK.
       01  MW-REC.
           05 MW-ACCT          PIC 9(10).
           05 MW-DATE          PIC 9(8).
           05 FILLER           PIC X(62).

           MERGE MERGE-WORK
                 ON ASCENDING KEY MW-ACCT MW-DATE
                 USING  EAST-TRANS WEST-TRANS
                 GIVING ALL-TRANS

Code Explained

East and west files are each sorted by account and date
MERGE interleaves them into one sorted output
The DFSORT table below does the same job as a JCL step
Use COBOL only when per-record logic is needed

Modern Equivalent

  • Python heapq.merge(east, west, key=lambda r: (r.acct, r.date))
  • Java Stream concat + sort, or a manual two-pointer merge
  • JavaScript Concat + sort, or a two-pointer merge for big sorted inputs

Prefer / Avoid

  • COBOL program that only sorts → DFSORT step
  • merging unsorted files → sort each first

DFSORT Equivalent

StatementDoes
SORT FIELDS=(1,10,CH,A)Sort on bytes 1–10
MERGE FIELDS=(1,10,CH,A,11,8,CH,A)Merge two keys
INCLUDE COND=(1,2,CH,EQ,C'IA')Keep IA only
SUM FIELDS=NONEDrop duplicate keys
OUTREC BUILD=(1,30)Reformat output

COBOL or Utility?

NeedUse
Plain sort / mergeDFSORT step
Filter by simple field testDFSORT INCLUDE
Complex per-record rulesCOBOL SORT + procedures
Lookups during sortCOBOL input procedure

⚠ Common Mistakes

  • Merging files that are not sorted on the merge keys (wrong order, no error)
  • Different record layouts in the inputs
  • Writing a COBOL program for a job one DFSORT statement could do

✓ Tips & Best Practices

  • Keep DFSORT control cards in a PDS member so they are versioned
  • Check sort order with a quick DFSORT SORT … CKFIELDS or a COBOL sequence check
  • See the JCL set for SORT step details

Quick Summary

  • MERGE — combine sorted files
  • DFSORT — sort in JCL
  • SORT FIELDS= — utility keys
  • COBOL — for per-record logic
