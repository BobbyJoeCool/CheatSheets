OCCURS Basics

OCCURS n TIMES · subscripts start at 1 · multi-dimensional tables · tables of groups · out-of-range subscripts · SSRANGE

Tables Are COBOL's Arrays

The OCCURS clause repeats a field or group a fixed number of times, making a table. You reach an entry with a subscript in parentheses, starting at 1. Nest OCCURS for two or three dimensions, and repeat whole groups to build tables of records.

Key Points

  • OCCURS cannot be used on an 01 or 77 level
  • Subscripts can be literals, fields or field + n
  • Size is fixed at compile time (see ODO, sheet 38)
  • No bounds checking unless compiled with SSRANGE

Under the Hood

  • Entry address = table start + (subscript − 1) × entry length
  • Out-of-range subscripts read or overwrite neighboring storage
  • SSRANGE adds a check on every reference; with -debug GnuCOBOL does the same

Defining and Using Tables

       01  MONTH-TABLE.
           05 MONTH-SALES     PIC 9(7)V99 OCCURS 12 TIMES.
       01  REGION-TABLE.
           05 REGION OCCURS 4 TIMES.
              10 REGION-NAME  PIC X(10).
              10 REGION-QTR   PIC 9(7)V99 OCCURS 4 TIMES.
       01  WS-SUB             PIC 99 COMP.
       01  WS-R               PIC 9  COMP.
       01  WS-Q               PIC 9  COMP.
       01  WS-YEAR            PIC 9(9)V99 VALUE 0.

           MOVE 1500.00 TO MONTH-SALES(1)
           MOVE 2 TO WS-SUB
           ADD 250 TO MONTH-SALES(WS-SUB)
           DISPLAY MONTH-SALES(WS-SUB + 1)
           MOVE "MIDWEST" TO REGION-NAME(3)
           MOVE 99.95 TO REGION-QTR(3, 2)    *> region 3, Q2
           PERFORM VARYING WS-SUB FROM 1 BY 1 UNTIL WS-SUB > 12
              ADD MONTH-SALES(WS-SUB) TO WS-YEAR
           END-PERFORM
           INITIALIZE REGION-TABLE

Code Explained

MONTH-SALES(1) is the first entry, not (0)
Each REGION entry holds a name and 4 quarter amounts
(3, 2) lists outer subscript first, then inner
COMP subscripts are faster than DISPLAY ones

Modern Equivalent

  • Python sales = [Decimal(0)] * 12; sales[0] is the first
  • Java BigDecimal[] sales = new BigDecimal[12]; sales[0]
  • JavaScript const sales = new Array(12).fill(0); sales[0]

Prefer / Avoid

  • off-by-one from 0-based habits → loops FROM 1 … UNTIL > n
  • testing without SSRANGE → compile tests with SSRANGE

⚠ Common Mistakes

  • Subscript 0, which points before the table and corrupts memory
  • Using OCCURS on an 01 level (compile error)
  • Loop limit higher than the OCCURS count

✓ Tips & Best Practices

  • Turn on SSRANGE in test builds, then measure before using it in production
  • Use COMP for subscripts and counters
  • Use (ALL) with SUM/MAX instead of loops when you only need a total

Quick Summary

  • OCCURS n — fixed-size table
  • X(1) — first entry
  • X(i, j) — 2-D
  • SSRANGE — bounds checks
