Sheet 02

Installing GnuCOBOL

brew install gnucobol · apt install gnucobol · cobc -x · cobc -free · cobcrun · VS Code extensions

A Free COBOL Compiler

GnuCOBOL translates COBOL to C and compiles it with your system C compiler, so it runs on macOS, Linux and Windows. It supports most of COBOL-85, much of 2002/2014, and IBM dialect options, which makes it the easiest way to practice before touching a mainframe.

Key Points

  • cobc is the compiler; cobcrun runs modules
  • -x builds an executable; without it you get a module
  • -std=ibm mimics Enterprise COBOL behavior
  • Error messages give file, line and severity

Install, Compile & Run

# macOS (Homebrew)
brew install gnucobol
# Debian / Ubuntu
sudo apt install gnucobol

cobc --version                 # cobc (GnuCOBOL) 3.2.0

cobc -x hello.cbl              # build ./hello
./hello                        # Hello, World

cobc -x -free hello.cbl        # free-format source
cobc -x -std=ibm payroll.cbl   # IBM dialect rules
cobc -x -I copy/ main.cbl      # copybook folder
cobc -m util.cbl               # module util.so / .dylib
cobcrun util                   # run a module
cobc -x -debug -Wall prog.cbl  # runtime checks + warnings

Code Explained

Default source format is fixed; add -free for free format
-I adds a search path for COPY members
-debug turns on subscript and numeric checks at run time
-Wall shows warnings such as truncation risks

Modern Equivalent

  • Python brew install python · python3 app.py
  • Java brew install openjdk · javac App.java && java App
  • JavaScript brew install node · node app.js

Prefer / Avoid

  • compiling with no flags → -Wall -debug while learning
  • tabs in fixed-format source → spaces (tabs shift columns)

⚠ Common Mistakes

  • Forgetting -x and wondering where the executable is
  • Saving source with tabs, which pushes code past column 72
  • Expecting IBM-only syntax to compile without -std=ibm

✓ Tips & Best Practices

  • Set editor rulers at columns 7, 8, 12 and 72
  • Use -ftrace to print each paragraph as it runs
  • Keep copybooks in a copy/ folder and pass -I copy

Quick Summary

  • cobc -x — compile to an executable
  • -free — free-format source
  • -std=ibm — IBM dialect
  • -debug -Wall — safer learning builds
