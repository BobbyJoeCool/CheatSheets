Intrinsic Math Functions

FUNCTION MOD / REM · INTEGER / INTEGER-PART · ABS · SQRT · MAX / MIN / SUM / MEAN · RANDOM

Built-in Numeric Functions

Intrinsic functions return a value you use inside COMPUTE, MOVE or a condition. COBOL has functions for remainders, rounding to integers, absolute value, square roots, statistics over a list or table, random numbers and even financial values like present value.

Key Points

  • Write FUNCTION name(args); or omit FUNCTION with REPOSITORY … ALL INTRINSIC
  • ALL passes every table entry: SUM(TBL(ALL))
  • MOD follows the divisor's sign; REM follows the dividend's
  • INTEGER rounds down; INTEGER-PART truncates toward zero

Math Functions

       01  WS-N        PIC S9(5)    VALUE -17.
       01  WS-X        PIC S9(5)V99.
       01  WS-SCORES.
           05 WS-SCORE PIC 999 OCCURS 5 VALUE 0.
       01  WS-SEED     PIC 9(8)     VALUE 12345.

           COMPUTE WS-X = FUNCTION MOD(WS-N, 5)          *> 3
           COMPUTE WS-X = FUNCTION REM(WS-N, 5)          *> -2
           COMPUTE WS-X = FUNCTION ABS(WS-N)             *> 17
           COMPUTE WS-X = FUNCTION INTEGER(-2.5)         *> -3
           COMPUTE WS-X = FUNCTION INTEGER-PART(-2.5)    *> -2
           COMPUTE WS-X = FUNCTION SQRT(2)               *> 1.41
           COMPUTE WS-X = FUNCTION MAX(4, 9, 2)          *> 9
           COMPUTE WS-X = FUNCTION SUM(WS-SCORE(ALL))
           COMPUTE WS-X = FUNCTION MEAN(WS-SCORE(ALL))
           COMPUTE WS-X = FUNCTION RANDOM(WS-SEED)       *> first call seeds
           COMPUTE WS-X = FUNCTION RANDOM * 100          *> 0 to 99.99
           COMPUTE WS-X = FUNCTION PRESENT-VALUE(.05, 100, 100)

Code Explained

MOD(-17, 5) = 3 but REM(-17, 5) = -2
INTEGER(-2.5) = -3 (floor); INTEGER-PART(-2.5) = -2
(ALL) passes the whole table as arguments
Seed RANDOM once, then call it with no argument

Modern Equivalent

  • Python -17 % 5 → 3, math.fmod(-17, 5) → -2, math.floor, statistics.mean
  • Java Math.floorMod(-17, 5) → 3, -17 % 5 → -2, Math.floor, streams
  • JavaScript ((-17 % 5) + 5) % 5 → 3, -17 % 5 → -2, Math.floor, reduce

Prefer / Avoid

  • loops to sum a table → FUNCTION SUM(TBL(ALL))
  • MOD on negative numbers without checking → know MOD vs REM

⚠ Common Mistakes

  • Using MOD when the business rule needs REM behavior for negatives
  • Calling RANDOM with the same seed every time (same "random" number)
  • Assuming INTEGER truncates negative numbers

✓ Tips & Best Practices

  • Use MOD for check digits and day-of-cycle math
  • Pass tables with (ALL) instead of writing loops
  • Store function results in fields with enough decimals

Quick Summary

  • MOD / REM — remainders
  • INTEGER / INTEGER-PART
  • SUM(t(ALL)) — whole table
  • RANDOM — seed once
