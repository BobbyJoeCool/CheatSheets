Sheet 29

IF / ELSE

IF … ELSE … END-IF · scope terminators vs the period · nested IFs · CONTINUE vs NEXT SENTENCE · stray-period bug

Making Decisions

IF runs statements when a condition is true and ELSE runs others when it is false. Close every IF with END-IF. In old code the period ended the IF instead, and a misplaced period is still one of the most common COBOL bugs.

Key Points

  • A period ends every open IF at once
  • CONTINUE is a no-op placeholder
  • NEXT SENTENCE jumps past the next period (avoid)
  • Indent nested IFs and match each with its END-IF

IF with Scope Terminators

           IF WS-BALANCE < 0
              DISPLAY "OVERDRAWN"
              ADD 25 TO WS-FEES
           ELSE
              IF WS-BALANCE > 10000
                 SET PREMIUM-CUST TO TRUE
              ELSE
                 CONTINUE
              END-IF
           END-IF

      *>   The stray-period bug:
           IF WS-QTY = 0
              DISPLAY "NO STOCK".
              ADD 1 TO WS-REORDERS
      *>   ADD runs ALWAYS: the period closed the IF

           IF ACTIVE AND WS-BALANCE > 0
              PERFORM 2000-BILL
           END-IF

Code Explained

END-IF ends exactly one IF, so nesting is safe
CONTINUE fills an empty branch
The period after "NO STOCK" ends the IF; the ADD is outside it
Conditions can mix 88-level names and comparisons

Modern Equivalent

  • Python if bal < 0: … elif bal > 10000: … else: pass
  • Java if (bal < 0) { … } else if (bal > 10000) { … }
  • JavaScript if (bal < 0) { … } else if (bal > 10000) { … }

Prefer / Avoid

  • period-terminated IFs → END-IF on every IF
  • NEXT SENTENCE → CONTINUE

Terminators

ItemEffect
END-IFCloses one IF
. (period)Closes all open statements
CONTINUEDo nothing, fall through
NEXT SENTENCEJump past next period

Nesting Tips

RuleWhy
One period per paragraphNo accidental closes
Indent 3 per levelReadable branches
ELSE aligned with IFShows pairing
Max ~3 levelsUse EVALUATE beyond that

⚠ Common Mistakes

  • A period inside an IF that silently ends it early
  • Mixing NEXT SENTENCE with END-IF (jumps further than expected)
  • Deep nesting that should be an EVALUATE

✓ Tips & Best Practices

  • Search old programs for . inside IF blocks when debugging
  • Use EVALUATE TRUE for three or more branches
  • Put the period on its own line at paragraph end if your shop allows

Quick Summary

  • IF … END-IF — always close
  • period — closes everything
  • CONTINUE — empty branch
  • avoid NEXT SENTENCE
