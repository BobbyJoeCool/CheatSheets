Sheet 27

COMPUTE

COMPUTE x = … · + - * / ** · precedence & parentheses · ROUNDED MODE (2014) · intermediate precision · ARITH(EXTEND)

Formulas in One Statement

COMPUTE evaluates an arithmetic expression and stores the result, like assignment in modern languages. It supports +, -, *, / and ** (power) with normal precedence, plus ROUNDED, ON SIZE ERROR and several receivers.

Key Points

  • Spaces are required around operators: A - B, not A-B
  • A-B is read as a single name with a hyphen
  • Intermediate results keep extra decimal places
  • Multiple receivers can each have their own ROUNDED

Under the Hood

  • Intermediate precision depends on operand sizes and the ARITH compiler option
  • ARITH(COMPAT) allows 18 digits; ARITH(EXTEND) allows 31
  • Exponentiation with non-integer powers uses floating point internally

Formulas

       01  WS-PRIN     PIC 9(7)V99   VALUE 10000.
       01  WS-RATE     PIC V9(4)     VALUE .0525.
       01  WS-YEARS    PIC 99        VALUE 3.
       01  WS-AMT      PIC 9(7)V99.
       01  WS-INT      PIC 9(7)V99.
       01  WS-PCT      PIC 999V9.
       01  WS-A        PIC S99       VALUE 7.
       01  WS-B        PIC S99       VALUE 2.

           COMPUTE WS-AMT ROUNDED =
              WS-PRIN * (1 + WS-RATE) ** WS-YEARS    *> 11659.13
           COMPUTE WS-INT = WS-AMT - WS-PRIN         *> 1659.13
           COMPUTE WS-PCT ROUNDED =
              WS-INT / WS-PRIN * 100                 *> 16.6
           COMPUTE WS-A = WS-A - WS-B * 2            *> 3
           COMPUTE WS-AMT ROUNDED MODE NEAREST-EVEN = 2.125
              ON SIZE ERROR DISPLAY "TOO BIG"
           END-COMPUTE                               *> 2.12

Code Explained

** binds tighter than *, which binds tighter than +
Parentheses make the compound-interest formula clear
ROUNDED MODE NEAREST-EVEN is banker's rounding (2014 standard)
END-COMPUTE closes the SIZE ERROR scope

Modern Equivalent

  • Python amt = (prin * (1 + rate) ** years).quantize(Decimal("0.01"))
  • Java prin.multiply(BigDecimal.ONE.add(rate).pow(years)).setScale(2, HALF_UP)
  • JavaScript Math.round(prin * (1 + rate) ** years * 100) / 100 (float caveats)

Prefer / Avoid

  • COMPUTE A=B-C with no spaces → COMPUTE A = B - C
  • deeply nested formulas → intermediate named fields

⚠ Common Mistakes

  • COMPUTE X = A-B becomes "the field named A-B"
  • Expecting floating-point behavior from fixed decimals (or vice versa)
  • Small receivers silently truncating the high digits

✓ Tips & Best Practices

  • Put spaces around every operator, always
  • Use ROUNDED on any money result
  • Check whether your compiler supports ROUNDED MODE before using it

Quick Summary

  • COMPUTE x = expr — formula
  • ** — power
  • spaces around - — required
