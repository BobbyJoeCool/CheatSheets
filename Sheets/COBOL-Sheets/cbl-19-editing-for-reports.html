Editing Fields for Output

edited PICs in action · BLANK WHEN ZERO · JUSTIFIED RIGHT · SIGN LEADING SEPARATE · currency & dates · column-aligned output

Making Numbers Readable

Report lines are built from edited fields and fixed text, then written as one record. Clauses like BLANK WHEN ZERO, JUSTIFIED RIGHT and SIGN … SEPARATE control how values sit in their columns, so a printed report lines up without any string math.

Key Points

  • Build each print line as an 01 group of fields and FILLER
  • Widths of the edited fields define the columns
  • SIGN LEADING SEPARATE puts a real +/- character first
  • Dates can use 99/99/9999 or 9999-99-99 style pictures

A Detail Line

       01  DETAIL-LINE.
           05 DL-ACCT      PIC 9(6).
           05 FILLER       PIC X(2)   VALUE SPACES.
           05 DL-NAME      PIC X(20).
           05 DL-CITY      PIC X(12)  JUSTIFIED RIGHT.
           05 FILLER       PIC X(2)   VALUE SPACES.
           05 DL-BAL       PIC $$$,$$9.99-.
           05 FILLER       PIC X      VALUE SPACE.
           05 DL-FEES      PIC ZZ9.99 BLANK WHEN ZERO.
           05 FILLER       PIC X      VALUE SPACE.
           05 DL-OPENED    PIC 9999/99/99.
       01  WS-EXPORT-AMT   PIC S9(5)V99
                           SIGN LEADING SEPARATE.

           MOVE CUST-ACCT  TO DL-ACCT
           MOVE CUST-NAME  TO DL-NAME
           MOVE CUST-CITY  TO DL-CITY       *> right-aligned
           MOVE CUST-BAL   TO DL-BAL        *> $1,234.50-
           MOVE ZERO       TO DL-FEES       *> blanks
           MOVE 20190304   TO DL-OPENED     *> 2019/03/04
           WRITE PRINT-REC FROM DETAIL-LINE
               AFTER ADVANCING 1 LINE

Code Explained

Each MOVE fills one column of the print line
JUSTIFIED RIGHT pads text on the left instead of the right
A trailing - shows the sign after the amount
SIGN LEADING SEPARATE is common for files sent to other systems

Modern Equivalent

  • Python f-strings with widths: f"{acct:06d} {name:<20}{bal:>12,.2f}"
  • Java String.format("%06d %-20s%,12.2f", …)
  • JavaScript Template string with padStart / padEnd / toLocaleString

Prefer / Avoid

  • building lines with STRING → a group of edited fields
  • hard-coded column positions → named FILLER items

Clauses

ClauseEffect
BLANK WHEN ZEROAll spaces if value is 0
JUSTIFIED RIGHTRight-align text
SIGN LEADING SEPARATESign as first character
SIGN TRAILING SEPARATESign as last character
SIGN LEADINGSign in first digit's zone

⚠ Common Mistakes

  • Line group longer than the print record, so the end is cut
  • Moving a YYYYMMDD date into a 99/99/9999 picture and getting 20/26/1112
  • Forgetting a sign position, so credits look like debits

✓ Tips & Best Practices

  • Total the widths of each line group against the record length
  • Rearrange dates with REDEFINES before editing them
  • Keep heading and detail columns in matching widths

Quick Summary

  • line group — edited fields + FILLER
  • BLANK WHEN ZERO — empty zeros
  • JUSTIFIED RIGHT — align text
  • SIGN … SEPARATE — real sign char
