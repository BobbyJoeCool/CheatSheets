Reading and Writing HCL from Code

The reference implementation is the Go module github.com/hashicorp/hcl/v2. hclsimple decodes a file into a struct, gohcl maps fields with struct tags, and hclwrite generates or edits files while keeping comments. Other languages use ports such as python-hcl2 or convert to JSON first.

Notes

  • Errors come back as diagnostics with file, line and column ranges
  • An hcl.EvalContext supplies the variables and functions expressions may use
  • gohcl tags: hcl:"name", hcl:"name,optional", hcl:"name,block", hcl:"name,label"
  • hclwrite keeps comments and layout, so it is the safe way to edit a user's file
  • Ports in other languages may lag behind Go on templates and for expressions

Go (hcl/v2)

// app.hcl: name = "inventory"
//          server "web" { addr = ":8080" }
type Config struct {
  Name    string   `hcl:"name"`
  Port    int      `hcl:"port,optional"`
  Servers []Server `hcl:"server,block"`
}
type Server struct {
  Label string `hcl:"label,label"`
  Addr  string `hcl:"addr"`
}

var cfg Config
err := hclsimple.DecodeFile("app.hcl", nil, &cfg)
if err != nil { log.Fatal(err) }   // diagnostics

f := hclwrite.NewEmptyFile()
f.Body().SetAttributeValue("name", cty.StringVal("web"))
os.WriteFile("out.hcl", f.Bytes(), 0o644)

Python (python-hcl2 v7)

import hcl2

with open("app.hcl") as f:
    data = hcl2.load(f)      # plain dict
data["server"]               # list of block dicts

Code Explained

hcl:"server,block" maps every server block into the slice
hcl:"label,label" receives the block's label
Passing nil as the eval context means expressions can't use variables or functions
hcl2.load returns blocks as lists of dicts and keeps "${…}" expressions as strings; v8 also keeps string quotes by default

Same Data In…

  • Go cfg.Servers[0].Label == "web"
  • Python {'name': 'inventory', 'server': [{'web': {'addr': ':8080'}}]}
  • JSON hcl2json app.hcl prints a JSON form any language can read

Gotcha

  • hclsimple picks native or JSON syntax from the file extension (.hcl or .json)
  • python-hcl2 targets Terraform-style files; unusual expressions may parse differently than in Go

⚠ Common Mistakes

  • Decoding without an EvalContext and then wondering why var.x fails
  • Rewriting a user's file with string formatting instead of hclwrite
  • Ignoring diagnostic warnings that point at likely typos

✓ Tips & Best Practices

  • Print diagnostics with hcl.NewDiagnosticTextWriter for caret-style error output
  • Add a field tagged hcl:",remain" to collect attributes and blocks you didn't map
  • Parse generated files back before writing them to disk

Quick Summary

  • hclsimple.DecodeFile — file → struct
  • gohcl tags — map attributes, blocks, labels
  • hclwrite — generate and edit, comments kept
  • python-hcl2 / hcl2json — other languages
