HCL Beyond Terraform

Packer .pkr.hcl · Nomad .nomad.hcl · Vault config · Consul config · Boundary · docker-bake.hcl

The Same Syntax, Many Tools

HCL shows up across HashiCorp tools and beyond. Packer builds machine images, Nomad schedules jobs, Vault, Consul and Boundary read server config, and Docker Buildx Bake describes image builds. Each tool brings its own block types, variables and functions; this set leaves Terraform to its own reference.

Notes

  • Packer and Nomad jobs use HCL 2 with variables, locals and functions
  • Vault and Consul read their config with HCL 1: plain values, no expressions
  • docker buildx bake reads docker-bake.hcl, with variables and functions
  • Every tool has a fmt or validate command for its files
  • Packer's old JSON templates are not HCL JSON; packer hcl2_upgrade converts them

Packer: build.pkr.hcl

packer {
  required_plugins {
    docker = {
      source  = "github.com/hashicorp/docker"
      version = ">= 1.0.0"
    }
  }
}

variable "tag" {
  type    = string
  default = "latest"
}

source "docker" "app" {
  image  = "ubuntu:24.04"
  commit = true
}

build {
  sources = ["source.docker.app"]
  provisioner "shell" {
    inline = ["apt-get update", "apt-get install -y curl"]
  }
}

Code Explained

required_plugins lists the plugins packer init downloads
source "docker" "app" — two labels: the builder type and a name
sources = ["source.docker.app"] refers to that source by type and name
provisioner "shell" runs commands inside the image during the build

Same Data In…

  • Dockerfile FROM ubuntu:24.04 / RUN apt-get update && apt-get install -y curl
  • compose.yaml services: {app: {build: ., image: me/app}} ↔ target "app" in docker-bake.hcl
  • K8s YAML kind: Deployment + replicas: 2 ↔ a Nomad job with group { count = 2 }

Gotcha

  • Vault and Consul config is read with HCL 1: ${…} stays literal text and HCL 2 expressions are errors
  • Packer refers to sources as "source.<type>.<name>"; leaving out source. fails validation

⚠ Common Mistakes

  • Using HCL 2 expressions in Vault or Consul config
  • Writing sources = ["docker.app"] instead of "source.docker.app" in Packer
  • Copying Terraform functions into a tool that doesn't provide them

✓ Tips & Best Practices

  • Run packer init . before packer build so plugins are installed
  • Use docker buildx bake --print to see the resolved build config as JSON
  • Keep Nomad job variables in a .vars.hcl file and pass it with -var-file

Quick Summary

  • Packer — source + build blocks
  • Nomad — job → group → task
  • Vault / Consul — HCL 1 config, no expressions
  • Bake — target blocks for docker buildx bake
