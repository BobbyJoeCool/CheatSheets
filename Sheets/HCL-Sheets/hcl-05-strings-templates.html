Strings & Templates

"…" · escapes · ${ } · $${ %%{ · %{ if } · %{ for } · ~ strip markers · type unwrap

Every String Is a Template

A quoted string is a template: ${ expr } inserts a value and %{ … } runs a directive (if or for). A ~ strip marker trims the whitespace beside a directive. A template that is only one interpolation, like "${var.port}", returns the value itself with its original type.

Notes

  • Escapes: \n \r \t \" \\ \uNNNN \UNNNNNNNN
  • $${ writes a literal ${; %%{ writes a literal %{
  • Strings use double quotes only; 'single' is an error
  • A quoted string can't span lines; use a heredoc (sheet 06)
  • %{ for } joins every pass into one string with no separator unless you write one

Interpolation & Directives

greeting = "Hello, ${var.name}!"
url      = "https://${var.host}:${var.port}/api"
path     = "C:\\temp\\${var.file}"
literal  = "Use $${HOME} in the shell"   # → Use ${HOME} …
port     = "${var.port}"                 # stays a number

status = "Build %{ if var.ok }passed%{ else }failed%{ endif }"

hosts = "%{ for h in var.hosts }${h},%{ endfor }"
# ["a", "b"] → "a,b,"

csv = <<EOT
%{ for h in var.hosts ~}
${h}
%{ endfor ~}
EOT

Code Explained

${var.name} inserts the value, converted to a string
$${HOME} escapes the interpolation so the shell sees ${HOME}
"${var.port}" is a lone interpolation, so the result keeps the number type
~} removes the newline after each directive, so csv is "a\nb\n"

Same Data In…

  • JSON {"greeting": "Hello, Bob!", "status": "Build passed", "hosts": "a,b,"}
  • YAML greeting: Hello, Bob! / status: Build passed

Gotcha

  • "${var.port}" doesn't make a string; add text around it or use the app's tostring()
  • A shell ${HOME} inside a template fails because HCL tries to evaluate it; write $${HOME}

⚠ Common Mistakes

  • Using single quotes for strings
  • Writing "${var.port}" and expecting a string
  • Forgetting that %{ for } puts the separator after the last item too

✓ Tips & Best Practices

  • Write var.name instead of "${var.name}" when you need the value, not a string
  • Use the app's join(",", list) (Terraform, Packer) for separators instead of %{ for }
  • Add ~ to directives in heredocs to keep blank lines out of the output

Quick Summary

  • ${ } — interpolation
  • %{ if } / %{ for } — directives
  • ~ — strip whitespace
  • $${ %%{ — literal escapes
