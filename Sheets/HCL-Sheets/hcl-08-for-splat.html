Sheet 08

For Expressions & Splats

[for x in xs : …] · {for k, v in m : k => v} · index · if filter · ... grouping · .* · [*]

Transform Collections

A for expression builds a new collection from another: [for … : …] makes a tuple and {for … : k => v} makes an object, with an optional if filter. A splat is shorthand for the most common case, pulling one attribute out of every element: var.users[*].name.

Notes

  • for x in list gives each value; for i, x in list adds the index
  • Over a map or object, for k, v in m gives each key and value
  • if cond at the end drops elements where cond is false
  • In the object form, ... after the value groups duplicate keys into tuples
  • [*] (full splat) and .* (attribute-only splat) differ when an index follows

Building New Collections

# var.users = [
#   { name = "ana", role = "admin" },
#   { name = "bo",  role = "dev" },
#   { name = "cy",  role = "dev" },
# ]

names   = [for u in var.users : u.name]
# ["ana", "bo", "cy"]

admins  = [for u in var.users : u.name if u.role == "admin"]
# ["ana"]

indexed = [for i, u in var.users : "${i}:${u.name}"]
# ["0:ana", "1:bo", "2:cy"]

by_name = {for u in var.users : u.name => u.role}
# { ana = "admin", bo = "dev", cy = "dev" }

by_role = {for u in var.users : u.role => u.name...}
# { admin = ["ana"], dev = ["bo", "cy"] }

names2  = var.users[*].name          # same as names

Code Explained

: u.name is the result for each element; if filters before collecting
i is the 0-based index when you name two variables over a list
=> u.role sets each value; a repeated key without ... is an error
u.name... collects every value for a key into a tuple

Same Data In…

  • JSON {"names": ["ana", "bo", "cy"], "by_role": {"admin": ["ana"], "dev": ["bo", "cy"]}}
  • YAML by_role: {admin: [ana], dev: [bo, cy]}

Gotcha

  • {for …} fails when two elements produce the same key, unless you add ...
  • A splat on a single object gives a one-element tuple and on a null object []; a null list is an error, which can hide a wrong input type

For Expression Forms

FormResult
[for x in xs : f]tuple
[for i, x in xs : f]tuple, with index
{for k, v in m : k => v}object
[for x in xs : f if c]filtered
{for x in xs : x.k => x...}grouped tuples
for x in a setvalue only, no index

Splats

ExpressionSame as
xs[*].id[for x in xs : x.id]
xs.*.id[for x in xs : x.id]
xs[*].tags[0][for x in xs : x.tags[0]]
xs.*.tags[0][for x in xs : x.tags][0]
null[*][]
obj[*] (not a list)[obj]

⚠ Common Mistakes

  • Forgetting ... when grouping and getting a duplicate-key error
  • Using .* before an index and getting the first element's list instead of each first tag
  • Iterating a set and expecting a numeric index

✓ Tips & Best Practices

  • Prefer [*] over .*; it behaves the way most people expect
  • Split long for expressions over several lines inside the brackets
  • Use the object form to turn a list into a lookup map keyed by name

Quick Summary

  • [for … : …] — new tuple
  • {for … : k => v} — new object
  • if / ... — filter / group
  • [*] — one attribute from every element
