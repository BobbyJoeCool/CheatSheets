Sheet 03

Identifiers & Literal Values

identifiers · dashes · no reserved words · numbers · true / false · null · strings are templates

Names and the Simplest Values

An identifier names attributes, block types, variables and functions. It may contain letters, digits, _ and -, but can't start with a digit or a dash, and HCL has no global reserved words. Literals are numbers, true, false and null; strings exist only as templates (sheet 05), even when they contain no interpolation.

Notes

  • Identifiers follow Unicode rules (UAX #31), so non-ASCII letters are allowed
  • Dashes are allowed (max-conns), but _ is the usual separator
  • Numbers are decimal only: no hex, octal or binary literals
  • Numbers are arbitrary precision; the app decides how to store them
  • null is a null value; the app decides if that differs from leaving the attribute out

Names and Literals

name        = "inventory"    # string (a template)
max-conns   = 400            # a dash in a name is legal
max_conns   = 400            # underscore is the usual style
ratio       = 0.75
big         = 1e9            # exponent
precise     = 12345678901234567890.5
enabled     = true
description = null           # "not set"

# keywords are contextual, so these names are fine:
for = "ok"
if  = "ok"

# 9lives = 1                 # ERROR: starts with a digit
# mask   = 0xFF              # ERROR: decimal only

Code Explained

max-conns and max_conns are two different names
precise keeps every digit; HCL numbers aren't limited to 64 bits
null passes a null value; apps like Terraform then use the default
for and if work as names because they are keywords only inside expressions

Same Data In…

  • JSON {"name": "inventory", "max_conns": 400, "enabled": true, "description": null}
  • YAML max_conns: 400 / enabled: true / description: null
  • TOML no null: leave description out

Gotcha

  • A dash next to a name is part of the name: a-b reads a variable called a-b; write a - b to subtract
  • The app may still store numbers as 64-bit ints or floats when it decodes them

⚠ Common Mistakes

  • Writing a-b for subtraction
  • Writing hex values like 0x1F; HCL accepts decimal only
  • Quoting numbers and booleans out of habit; it works only when the app converts them

✓ Tips & Best Practices

  • Use snake_case names; they never clash with subtraction
  • Use null to fall back to a default instead of an empty string
  • Write large numbers plainly; there is no _ digit separator

Quick Summary

  • identifier — letters, digits, _, -; no digit first
  • numbers — decimal, arbitrary precision
  • true false null — literal keywords
  • strings — always templates
