Format, Edit and Convert

Each HashiCorp tool formats its own files (packer fmt, nomad fmt, terraform fmt), and hclfmt from the HCL repo formats any HCL file. hcledit reads and changes attributes from scripts, and hcl2json converts native syntax to JSON for tools like jq.

Notes

  • The formatters share one style: 2-space indent and aligned = in groups
  • packer/nomad fmt -check and hclfmt -require-no-change make a CI gate
  • hcledit edits files without disturbing comments
  • The HashiCorp HCL extension adds syntax highlighting in VS Code
  • JetBrains IDEs support HCL through the HCL plugin

Command Line

# format
hclfmt -w app.hcl                  # any HCL file
packer fmt -check .                # CI gate for Packer
nomad fmt -check jobs/             # CI gate for Nomad

# read and edit from scripts
hcledit attribute get server.web.port -f app.hcl   # 8080
hcledit attribute set server.web.port 9090 -f app.hcl -u
hcledit block list -f app.hcl                      # server.web

# convert to JSON and query
hcl2json app.hcl | jq '.server.web[0].port'

Code Explained

hclfmt -w rewrites the file; without -w it prints the result
fmt -check exits non-zero when a file isn't formatted; hclfmt needs -check -require-no-change
hcledit addresses join the block type, labels and attribute with dots
hcl2json wraps each block body in an array, so jq needs [0]

Same Data In…

  • YAML yq does for YAML what hcledit and hcl2json do for HCL
  • TOML taplo fmt is the TOML counterpart of hclfmt

Gotcha

  • Formatters fix layout only; a perfectly formatted file can still fail the app's schema
  • hcledit … -u rewrites the file in place; commit first so you can review the change

⚠ Common Mistakes

  • Running one tool's fmt and expecting it to validate the content
  • Using sed to change HCL values and breaking quoting or alignment
  • Forgetting [0] when querying hcl2json output for a block

✓ Tips & Best Practices

  • Turn on format-on-save so diffs show only real changes
  • Use hcledit in CI scripts to bump versions or ports without regex
  • Pipe hcl2json into jq to answer "which jobs set X?" across many files

Quick Summary

  • hclfmt / * fmt — format
  • -check — CI gate
  • hcledit — scripted edits
  • hcl2json — convert, then jq
