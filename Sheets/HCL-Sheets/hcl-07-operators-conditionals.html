Operators & Conditionals

* / % + - · == != · < > · && || ! · precedence · cond ? a : b

Math, Comparisons and Choices

HCL 2 has arithmetic, comparison and logical operators, plus the conditional cond ? a : b. Arithmetic converts operands to numbers ("2" + "3" is 5); there is no + for joining strings. Both branches of a conditional must convert to one common type, and an error in the branch that isn't chosen is not raised.

Notes

  • + only adds numbers; join strings with a template: "${a}${b}"
  • == compares type and value: 1 == "1" is false
  • ! negates a bool; - negates a number
  • Parentheses let an expression span several lines
  • Binary operators group left to right within a precedence level

Operators in Use

total    = var.count * 2 + 1          # numbers only
half     = var.size / 2               # 7 / 2 → 3.5
rest     = 17 % 5                     # 2
negative = -var.offset

is_prod  = var.env == "prod"
in_range = var.port >= 1024 && var.port <= 65535
allowed  = !var.locked || var.admin

replicas = var.env == "prod" ? 3 : 1
label    = var.name != "" ? var.name : "default"
mixed    = var.on ? 1 : "off"         # both become strings

long = (
  var.base_cost
  + var.extra_cost * var.months
)

Code Explained

7 / 2 is 3.5; division never truncates
&& binds looser than >= and <=, so in_range needs no parentheses
mixed unifies 1 and "off" to string, so 1 becomes "1"
The parentheses let long span lines; without them the newline ends the attribute

Same Data In…

  • JSON {"total": 7, "half": 3.5, "is_prod": true, "replicas": 3} (for count = 3, size = 7, env = "prod")
  • YAML replicas: 3 / label: default

Gotcha

  • "a" + "b" is an error, not "ab"
  • Branches that can't unify (a list and a string) fail even if only one branch is ever used

⚠ Common Mistakes

  • Joining strings with +
  • Comparing a number to a string with == and always getting false
  • Splitting a conditional across lines without parentheses

✓ Tips & Best Practices

  • Give both conditional branches the same type to avoid surprise conversions
  • Check != "" or != null to pick defaults; Terraform also offers coalesce()
  • Wrap mixed && / || in parentheses so the intent is obvious

Quick Summary

  • arithmetic — numbers only
  • == — type and value must match
  • ? : — branches unify to one type
  • ( ) — grouping and multi-line expressions
