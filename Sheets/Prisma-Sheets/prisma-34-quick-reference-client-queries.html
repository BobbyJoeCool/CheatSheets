⚠ Common Mistakes

  • N+1: querying relations in a loop — use include or one findMany with in
  • $queryRawUnsafe with string-built SQL (injection)
  • deleteMany({}) with an empty filter wipes the table

✓ Tips & Best Practices

  • Use select to return only the fields the caller needs
  • Prefer cursor pagination for large or live tables
  • Turn on query logging (log: ["query"]) while tuning

Quick Summary

  • findMany({ where, select, include, orderBy, take })
  • Nested writes: create, connect, connectOrCreate
  • $transaction for all-or-nothing
  • Catch P2002 / P2025 by e.code
