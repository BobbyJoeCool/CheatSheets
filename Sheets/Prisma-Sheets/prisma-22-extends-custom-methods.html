Advanced: $extends & Custom Methods

$extends · model · query · result · client · $allModels · Prisma.defineExtension

Client Extensions

$extends returns a new client with extra behavior and full type safety; the original stays unchanged. Four components: model adds methods to delegates, query intercepts operations (before/after), result adds computed fields, and client adds top-level methods. Extensions replace the $use middleware, which was removed in Prisma 7.

Notes

  • Extensions are pure TypeScript — no SQL changes
  • Chain: prisma.$extends(a).$extends(b)
  • $allModels / $allOperations wildcards
  • Export the extended client as your db

All Four Components

export const db = prisma.$extends({
  model: { user: {
    signUp: (email: string) => prisma.user.create({ data: { email } }),
  } },
  result: { user: {
    fullName: {                                   // computed field
      needs: { first: true, last: true },
      compute: (u) => `${u.first} ${u.last}`,
    },
  } },
  query: { $allModels: {
    async $allOperations({ model, operation, args, query }) {
      const t = performance.now();
      const res = await query(args);              // before → run → after
      console.log(`${model}.${operation}`, performance.now() - t);
      return res;
    },
  } },
  client: { $health: () => prisma.$queryRaw`SELECT 1` },
});

const u = await db.user.signUp("ada@example.com");
u.fullName;                                       // "Ada Lovelace" (typed)

Code Explained

model — custom delegate methods
result — virtual field, typed
needs — fields required to compute
$allModels — apply to every model
$allOperations — every method
query(args) — run the real query
client — top-level helper

Components

⚠ Common Mistakes

  • Calling db inside its own query hook — infinite recursion
  • Using the base prisma and expecting extension behavior
  • Heavy result.compute on list queries — runs per row
  • Still calling prisma.$use() after upgrading to v7

✓ Tips & Best Practices

  • Package extensions with Prisma.defineExtension in their own files
  • Use result with needs to mask secrets (e.g. last 4 digits)
  • Put tenant scoping in a query extension
  • Type the extended client: type DB = typeof db
