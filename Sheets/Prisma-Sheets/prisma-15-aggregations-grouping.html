Aggregations & Grouping

aggregate · _count · _sum · _avg · _min · _max · groupBy · having

Statistics in the Database

aggregate() computes _count, _sum, _avg, _min, and _max over the rows matching where and returns one object. groupBy() returns one result per distinct combination of by fields; having filters groups after aggregation. Both run as a single SQL query — no rows are loaded into Node.

Notes

  • _sum/_avg of no rows → null
  • Decimal fields return Decimal objects
  • groupBy + skip/take requires orderBy
  • count({ select }) counts non-null fields

Aggregate & Group

const stats = await prisma.order.aggregate({
  where: { status: "PAID", createdAt: { gte: new Date("2026-01-01") } },
  _count: { _all: true },
  _sum: { total: true },
  _avg: { total: true },
  _min: { total: true },
  _max: { createdAt: true },
});  // { _count: { _all: 120 }, _sum: { total: 9840.5 }, … }

const byCustomer = await prisma.order.groupBy({
  by: ["customerId", "status"],
  where: { createdAt: { gte: new Date("2026-01-01") } },
  _sum: { total: true },
  _count: { _all: true },
  having: { total: { _sum: { gt: 1000 } } },   // big spenders only
  orderBy: { _sum: { total: "desc" } },
  take: 10,
});  // [{ customerId: 4, status: "PAID", _sum: { total: 5210 }, … }]

await prisma.user.count({ select: { _all: true, phone: true } });
                                         // { _all: 50, phone: 32 }

Code Explained

where — filter before aggregating
_count: { _all: true } — row count
_sum/_avg/_min/_max — per field
by — group key(s)
having — filter on aggregates
orderBy: { _sum } — rank groups
count({ select }) — non-null counts

⚠ Common Mistakes

  • Loading rows with findMany to sum in JS — use aggregate
  • Treating _sum as 0 when empty — it's null; use ?? 0
  • Putting aggregate filters in where — they belong in having
  • groupBy with take but no orderBy — validation error

✓ Tips & Best Practices

  • Convert Decimal with .toNumber() only for display
  • Count relations with include: { _count } instead
  • For date buckets (per day/month) use $queryRaw + date_trunc
  • Index the by and where columns of hot reports

Quick Summary

  • aggregate — one stats object
  • groupBy — stats per group
  • having — filter groups
  • _count · _sum · _avg · _min · _max
