Sheet 06

CRUD: Create Operations

create · createMany · createManyAndReturn · skipDuplicates · nested create

Inserting Data

create() inserts one record and returns it; select/include shape the result. Nested create inside data writes related rows in the same transaction. createMany() sends one multi-row INSERT and returns { count }; createManyAndReturn() returns the rows (Postgres, CockroachDB, SQLite).

Notes

  • Required fields without defaults must be set
  • createMany can't nest relations
  • skipDuplicates → ON CONFLICT DO NOTHING
  • Duplicate unique value → P2002

Create Examples

const user = await prisma.user.create({
  data: { email: "ada@example.com", name: "Ada" },
});                                     // { id: 1, email: "ada@…", … }

await prisma.user.create({              // nested create, one transaction
  data: {
    email: "cy@example.com",
    profile: { create: { bio: "Hi" } },
    posts: { create: [{ title: "First" }, { title: "Second" }] },
  },
  include: { posts: true },
});

await prisma.post.createMany({
  data: [{ title: "A", authorId: 1 }, { title: "B", authorId: 1 }],
  skipDuplicates: true,
});                                     // { count: 2 }

await prisma.tag.createManyAndReturn({
  data: [{ name: "orm" }, { name: "sql" }],
});                                     // [{ id: 1, name: "orm" }, …]

Code Explained

data — typed UserCreateInput
profile: { create } — 1-1 nested insert
posts: { create: [] } — 1-n nested
include — return relations too
createMany — one INSERT, { count }
skipDuplicates — ignore conflicts
createManyAndReturn — rows back

⚠ Common Mistakes

  • Looping await create() for bulk data — use createMany
  • Expecting IDs from createMany — use createManyAndReturn
  • Setting authorId and author: { connect } together
  • Date strings without a timezone — use Date or ISO Z

✓ Tips & Best Practices

  • Nested create keeps parent + children atomic
  • Chunk huge batches (~5,000 rows) to stay under param limits
  • Map P2002 to HTTP 409 Conflict
  • select only the fields the caller needs

Quick Summary

  • create — insert one
  • createMany — bulk, { count }
  • createManyAndReturn — bulk + rows
  • nested create — atomic graph insert
