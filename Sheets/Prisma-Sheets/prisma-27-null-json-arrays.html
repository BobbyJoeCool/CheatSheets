Special Cases: Null, JSON, Arrays

null · Prisma.JsonNull · DbNull · path · String[] · BigInt · Bytes · Decimal

Edge-Case Types

Optional fields hold null, but Json fields have two nulls: a database NULL (Prisma.DbNull) and a JSON null value (Prisma.JsonNull). JSON fields can be filtered by path. Scalar lists (String[]) are native on Postgres/CockroachDB. BigInt maps to JS bigint, Bytes to Uint8Array, and Decimal to a Decimal object.

Notes

  • Prisma.AnyNull filters both nulls
  • Postgres path = array; MySQL = '$.a.b'
  • JSON.stringify throws on bigint
  • Lists: no MySQL/SQLite — use Json

Null, JSON & Lists

import { Prisma } from "../generated/prisma/client";

await prisma.user.findMany({ where: { phone: null } });          // IS NULL
await prisma.user.findMany({ where: { phone: { not: null } } }); // IS NOT NULL

await prisma.user.create({ data: { email: "a@b.c", settings: { theme: "dark", beta: true } } });
await prisma.user.update({ where: { id: 1 }, data: { settings: Prisma.DbNull } });   // SQL NULL
await prisma.user.update({ where: { id: 2 }, data: { settings: Prisma.JsonNull } }); // JSON null

await prisma.user.findMany({
  where: { settings: { path: ["theme"], equals: "dark" } },      // Postgres
});
await prisma.product.findMany({
  where: { meta: { path: ["tags"], array_contains: ["sale"] } },
});

await prisma.post.update({ where: { id: 1 }, data: { tags: { push: "orm" } } });
await prisma.post.findMany({ where: { tags: { hasEvery: ["orm", "ts"] } } });

const u = await prisma.user.findUnique({ where: { id: 1 } });
JSON.stringify(u, (_, v) => (typeof v === "bigint" ? v.toString() : v));

⚠ Common Mistakes

  • Setting a Json field to null — use DbNull or JsonNull
  • Using MySQL path syntax on Postgres (or vice versa)
  • Returning BigInt from an API — JSON.stringify throws
  • Comparing Decimals with === — use .equals()

✓ Tips & Best Practices

  • Validate JSON shape with Zod on write (Sheet 29)
  • Add a GIN index for frequent JSON path filters
  • Prefer Json columns for flexible data, columns for queried data
  • Convert Decimal with .toFixed(2) for display
