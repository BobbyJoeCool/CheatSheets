Advanced Filters & Paging

Offset pagination (skip/take) is simple but slows down as the offset grows. Cursor pagination starts after a known unique value, so every page costs the same. Relation filters (some, every, none, is) filter parents by their children; list filters (has, hasSome) query scalar arrays.

Notes

  • Cursor must be unique & in orderBy
  • skip: 1 skips the cursor row itself
  • every is true when there are no children
  • Null check: { field: null } / { not: null }

Cursor Paging + Advanced Filters

async function page(cursor?: number) {
  const rows = await prisma.post.findMany({
    take: 20,
    ...(cursor && { skip: 1, cursor: { id: cursor } }),
    orderBy: { id: "desc" },
  });
  return { rows, next: rows.at(-1)?.id };   // pass `next` back as cursor
}
await prisma.user.findMany({
  where: {
    posts: { some: { published: true } },   // ≥1 published post
    comments: { none: {} },                 // no comments at all
    profile: { isNot: null },               // 1-1 relation exists
    tags: { hasSome: ["ts", "orm"] },       // String[] overlap
    deletedAt: null,                        // IS NULL
  },
  orderBy: [
    { lastLogin: { sort: "desc", nulls: "last" } },
    { posts: { _count: "desc" } },
  ],
});

Code Explained

cursor + skip: 1 — start after last row
take: 20 — page size (negative = backwards)
some — at least one child matches
none: {} — has zero children
isNot: null — optional 1-1 exists
hasSome — array overlaps list
nulls: 'last' — null ordering
_count — sort by relation count

⚠ Common Mistakes

  • Cursor on a non-unique column — rows skipped or repeated
  • Forgetting skip: 1 — the cursor row repeats
  • isEmpty on a String — it's for scalar lists; use equals: ""
  • every returning parents with no children — add some: {}

✓ Tips & Best Practices

  • Return next cursor in your API instead of page numbers
  • Add id as the last orderBy for deterministic order
  • Index the cursor/orderBy columns together
  • Use offset only for small, admin-style tables

Quick Summary

  • cursor + skip: 1 + take — keyset paging
  • some · every · none — to-many filters
  • is · isNot — to-one filters
  • has · hasSome · hasEvery — arrays
  • nulls: 'last' — null sort order
