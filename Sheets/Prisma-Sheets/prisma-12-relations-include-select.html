Relations: Include & Select

include · select · nested where/orderBy/take · _count · relationLoadStrategy

Loading Related Data

include returns all scalar fields plus the listed relations. select returns only the listed fields and relations. Both nest, and a to-many relation accepts where, orderBy, take, and skip to limit what's loaded. _count returns relation counts without loading rows.

Notes

  • select ⊂ include — can't be siblings
  • Inside include, use select on a relation
  • relationLoadStrategy needs preview relationJoins
  • Default query strategy: one query per level

Include & Select

const user = await prisma.user.findUnique({
  where: { id: 1 },
  include: {
    profile: true,                                   // 1-1
    posts: {                                         // filtered 1-n
      where: { published: true },
      orderBy: { createdAt: "desc" },
      take: 5,
      include: { comments: { take: 3 } },            // 2 levels deep
    },
    _count: { select: { posts: true, followers: true } },
  },
});
const cards = await prisma.post.findMany({
  relationLoadStrategy: "join",                      // single SQL query
  select: {
    id: true,
    title: true,
    author: { select: { name: true, avatarUrl: true } },
    tags: { select: { name: true } },
  },
});   // { id, title, author: { name, avatarUrl }, tags: { name }[] }[]

Code Explained

include: { profile: true } — add relation
nested where/orderBy/take — limit children
include inside include — multi-level
_count — counts, no rows loaded
select — exact payload shape
relationLoadStrategy — join or query

⚠ Common Mistakes

  • include: { posts: true } on large relations — loads every row
  • select and include side by side — validation error
  • Deep includes in list endpoints — huge payloads
  • Reading user.posts without including it

✓ Tips & Best Practices

  • Always take on to-many includes in list views
  • Use _count for badges instead of loading rows
  • Try relationLoadStrategy: 'join' on Postgres for deep trees
  • Share shapes with satisfies Prisma.PostSelect (Sheet 23)

Quick Summary

  • include — all scalars + relations
  • select — only what you list
  • nested where/orderBy/take — trim children
  • _count — relation counts
