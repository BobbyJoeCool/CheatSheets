Relations & Enums

A relation pairs a relation field (Prisma-only) with a foreign key column. The FK side declares @relation(fields, references); the other side holds a back-relation (Post[] or Profile?). Implicit many-to-many needs only list fields on both sides. An enum limits values and becomes a TS union.

Notes

  • 1-1: FK field must be @unique
  • Two links to one model need names
  • prisma format adds back-relations
  • Enums: native on Postgres/MySQL

schema.prisma

enum Role {
  USER
  ADMIN
}

model User {
  id      Int      @id @default(autoincrement())
  role    Role     @default(USER)
  posts   Post[]                          // 1-n
  profile Profile?                        // 1-1
}
model Profile {
  id     Int  @id @default(autoincrement())
  userId Int  @unique
  user   User @relation(fields: [userId], references: [id], onDelete: Cascade)
}
model Post {
  id       Int   @id @default(autoincrement())
  authorId Int?
  author   User? @relation(fields: [authorId], references: [id], onDelete: SetNull)
  tags     Tag[]                // implicit m-n ↔ Tag.posts Post[]
}

Code Explained

Post[] — virtual, no column
fields — FK column(s) here
references — key on the other model
Cascade — delete profile with user
SetNull — keep post, null author
Tag[] ↔ Post[] — join table _PostToTag

Referential Actions

ActionOn parent delete
CascadeDelete children too
RestrictBlock if children exist
NoActionLike Restrict (deferred)
SetNullFK → NULL (optional FK)
SetDefaultFK → @default
default (required FK)Restrict
default (optional FK)SetNull

⚠ Common Mistakes

  • @relation(fields…) on both sides — FK side only
  • SetNull on a required FK — validation error
  • No index on FKs — Postgres doesn't add one
  • Comparing enums to raw strings — use Role.ADMIN

✓ Tips & Best Practices

  • Add @@index([authorId]) on FK columns
  • Use explicit m-n once the link needs extra data
  • relationMode = "prisma" only for DBs without FKs
  • Rename enum values in steps: add, migrate, remove

Quick Summary

  • @relation(fields, references) — FK side
  • Post[] / Profile? — back-relations
  • onDelete — Cascade · Restrict · SetNull
  • enum — fixed values → TS union
