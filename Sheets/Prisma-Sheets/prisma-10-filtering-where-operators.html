Filtering: Where Clauses & Operators

equals · gt/gte/lt/lte · contains · startsWith · in/notIn · not · AND/OR/NOT

Building Filters

where takes an object of field conditions. Multiple keys are combined with an implicit AND. A plain value means equals; an object unlocks operators like gt, contains, or in. Use OR: [...], AND: [...], and NOT for boolean logic — they nest to any depth and work in every query method.

Notes

  • undefined value = condition ignored
  • null value = IS NULL
  • mode: 'insensitive' — Postgres & Mongo
  • MySQL: case-insensitive by default collation

Where Examples

await prisma.user.findMany({
  where: {
    email: { endsWith: "@acme.com" },          // LIKE '%@acme.com'
    age:   { gte: 18, lt: 65 },                // 18 ≤ age < 65
    role:  { in: ["ADMIN", "EDITOR"] },        // IN (...)
    name:  { not: "Bot" },                     // <> 'Bot'
  },
});
await prisma.post.findMany({
  where: {
    published: true,                           // AND (implicit)
    OR: [
      { title: { contains: "prisma", mode: "insensitive" } },
      { body:  { contains: "prisma", mode: "insensitive" } },
    ],
    NOT: { status: "ARCHIVED" },
    slug: search ? { startsWith: search } : undefined, // optional
  },
});

Code Explained

endsWith — suffix match
gte + lt — range on one field
in — match any value in the list
not — inequality
OR: [...] — at least one branch
NOT — exclude matches
undefined — filter skipped

⚠ Common Mistakes

  • Expecting contains to be case-insensitive on Postgres — add mode
  • null vs undefined: null filters, undefined ignores
  • OR: [] from an empty array returns no rows — guard it
  • Two conditions on the same key in one object — last wins

✓ Tips & Best Practices

  • Build optional filters with undefined — no if chains
  • Use in instead of many OR equals — shorter SQL
  • Leading-wildcard contains can't use B-tree indexes
  • Type reusable filters as Prisma.UserWhereInput

Quick Summary

  • { field: value } — equals
  • gt · gte · lt · lte — ranges
  • contains · startsWith · endsWith — text
  • in · notIn · not — sets/negation
  • AND · OR · NOT — logic
