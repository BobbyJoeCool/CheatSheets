⚠ Common Mistakes

  • Forgetting prisma generate after a schema change — the client types go stale
  • Missing output in the Prisma 7 generator, or importing from @prisma/client
  • Using db push in production — it skips migration history

✓ Tips & Best Practices

  • Index every foreign key you filter on (@@index([authorId]))
  • Review generated SQL with --create-only before applying risky changes
  • Keep the connection URL in prisma.config.ts / env, never in the schema

Quick Summary

  • Schema = generator + datasource + models
  • migrate dev locally, migrate deploy in prod
  • @id, @unique, @default, @relation do most of the work
  • Prisma 7: prisma-client generator + driver adapter
