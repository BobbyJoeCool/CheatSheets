Prisma Client Setup & Methods

new PrismaClient · adapter · singleton · $transaction · $queryRaw · $disconnect

Creating the Client

PrismaClient is the generated query builder. Each instance owns a connection pool, so create one instance per process and import it everywhere. Model delegates (prisma.user) expose CRUD methods; $-prefixed methods act on the client itself: transactions, raw SQL, extensions, and lifecycle.

Notes

  • Queries run only when awaited
  • Pool connects lazily — $connect() optional
  • model BlogPost → prisma.blogPost
  • Dev hot-reload → cache on globalThis

src/lib/prisma.ts — Singleton

import "dotenv/config";
import { PrismaClient } from "../../generated/prisma/client";
import { PrismaPg } from "@prisma/adapter-pg";

const adapter = new PrismaPg({ connectionString: process.env.DATABASE_URL! });
const create = () => new PrismaClient({ adapter, log: ["warn", "error"] });

const g = globalThis as unknown as { prisma?: ReturnType<typeof create> };
export const prisma = g.prisma ?? create();
if (process.env.NODE_ENV !== "production") g.prisma = prisma;
// elsewhere
import { prisma } from "./lib/prisma";
const user = await prisma.user.findUnique({ where: { id: 1 } }); // User | null

// graceful shutdown
process.on("SIGTERM", async () => {
  await prisma.$disconnect();
  process.exit(0);
});

Code Explained

PrismaPg — wraps the pg driver + pool
log — query · info · warn · error
globalThis — one pool across hot reloads
findUnique — result type inferred
$disconnect() — close pool on shutdown
Serverless: create outside the handler

⚠ Common Mistakes

  • new PrismaClient() per request — exhausts connections
  • Missing await — the query never runs
  • $disconnect() after each request — slow reconnects
  • No dotenv/config — DATABASE_URL is undefined

✓ Tips & Best Practices

  • Export one prisma from lib/prisma.ts
  • Global omit hides password everywhere
  • Use …OrThrow when a missing row is a bug
  • Set transactionOptions once, not per call

Quick Summary

  • PrismaClient({ adapter }) — one per process
  • prisma.model.method() — typed CRUD
  • $transaction — batch or callback
  • $disconnect() — close on shutdown
