What is Prisma ORM?

Prisma ORM is a schema-first, type-safe ORM for Node.js and TypeScript. You model data in schema.prisma, Prisma Migrate turns it into tables, and Prisma Client is generated from it so every query is type-checked. Prisma 7 is Rust-free: the client connects through a JavaScript driver adapter, and the connection URL lives in prisma.config.ts.

Requirements (v7)

  • Node ≥ 20.19 · TypeScript ≥ 5.4
  • ESM: "type": "module" in package.json
  • .env is not auto-loaded — use dotenv/config
  • Postgres, MySQL/MariaDB, SQLite, SQL Server, CockroachDB

New Project (PostgreSQL)

npm init -y && npm pkg set type=module
npm i -D prisma typescript tsx @types/node
npm i @prisma/client @prisma/adapter-pg dotenv
npx tsc --init
npx prisma init --datasource-provider postgresql \
  --output ../generated/prisma
# creates prisma/schema.prisma, prisma.config.ts, .env
# .env
DATABASE_URL="postgresql://app:secret@localhost:5432/shop"
npx prisma migrate dev --name init  # SQL migration + apply
npx prisma generate                 # build the typed client
npx tsx src/index.ts                # run your code

Code Explained

prisma — CLI: init, migrate, generate, studio
@prisma/client — runtime for the generated client
@prisma/adapter-pg — driver adapter (pg)
--output — client location; import from there
migrate dev — schema diff → SQL → apply
generate — re-run after every schema change (v7 no longer runs it from migrate dev)

prisma.config.ts + schema.prisma

// prisma.config.ts (project root)
import "dotenv/config";
import { defineConfig, env } from "prisma/config";
export default defineConfig({
  schema: "prisma/schema.prisma",
  datasource: { url: env("DATABASE_URL") },
});
// prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}
datasource db {
  provider = "postgresql"
}

⚠ Common Mistakes

  • Importing from @prisma/client — import from your output path
  • Keeping url in datasource — v7 rejects it; use the config file
  • Skipping prisma generate after schema edits — stale types
  • Committing .env — add it to .gitignore

✓ Tips & Best Practices

  • Add generated/ to .gitignore; generate in postinstall
  • Install the VS Code Prisma extension for autocomplete
  • npx prisma format fixes layout and missing relations
  • npx prisma init --db provisions a hosted Prisma Postgres

Quick Summary

  • prisma init — schema, config, .env
  • prisma.config.ts — paths + datasource URL
  • prisma-client — v7 generator, needs output
  • prisma generate — rebuild client
