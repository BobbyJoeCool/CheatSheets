Sheet 03

Schema: Models & Fields

model · @id · @default · @unique · @updatedAt · ? optional · [] list

Models

A model maps to a table; each line is a field: name Type modifier @attributes. Scalar types map to both a database column and a TypeScript type. Every model needs a unique identifier (@id or @@id). @ attributes configure one field; @@ block attributes configure the whole model.

Conventions

  • Models PascalCase singular: OrderItem
  • Fields camelCase: createdAt
  • @@map("users") for snake_case tables
  • prisma format aligns and fixes

schema.prisma

model User {
  id        Int       @id @default(autoincrement())
  publicId  String    @unique @default(uuid(7))
  email     String    @unique
  name      String?                    // string | null
  isActive  Boolean   @default(true)
  balance   Decimal   @default(0) @db.Decimal(12, 2)
  tags      String[]                   // Postgres list
  settings  Json      @default("{}")
  views     BigInt    @default(0)
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
  lastLogin DateTime? @map("last_login")

  @@map("users")
}

Code Explained

autoincrement() — DB sequence PK
uuid(7) — time-sortable UUID
String? — nullable column
@db.Decimal(12, 2) — native type
String[] — not on MySQL/SQLite
@updatedAt — set by Prisma on update
@map / @@map — DB-side names

⚠ Common Mistakes

  • Float for money — rounding errors; use Decimal
  • New required field on a full table — needs a @default
  • Expecting @updatedAt to change on raw SQL updates
  • + on Decimal — use .plus() / .times()

✓ Tips & Best Practices

  • Public IDs: uuid(7) / cuid(2); joins: autoincrement()
  • Store DateTime in UTC; format in the UI
  • @db.VarChar(n) for a DB-enforced length
  • @ignore hides a column from the client

Quick Summary

  • model — one table, one delegate
  • ? / [] — optional / list
  • @id @default() — PK + generator
  • @updatedAt — auto timestamp
