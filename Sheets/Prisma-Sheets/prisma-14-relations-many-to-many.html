Relations: Many-to-Many & Advanced

implicit m-n · explicit join model · @@id · connect · set · some

Many-to-Many

Implicit m-n uses list fields on both models; Prisma creates and manages a hidden _AToB join table. Use it when the link carries no data. Explicit m-n defines a join model with two relations and a composite key, so you can store extra columns like grade or enrolledAt.

Notes

  • Implicit join table: _PostToTag (A, B)
  • Implicit needs single-field @ids on both models
  • Explicit: query the join model directly
  • Switching implicit → explicit needs a data migration

Schema

// implicit: Post.tags Tag[] ↔ Tag.posts Post[] (Sheet 04)
// explicit, with data
model Student {
  id          Int          @id
  enrollments Enrollment[]
}
model Course {
  id          Int          @id
  enrollments Enrollment[]
}
model Enrollment {
  student    Student  @relation(fields: [studentId], references: [id])
  studentId  Int
  course     Course   @relation(fields: [courseId], references: [id])
  courseId   Int
  grade      String?
  enrolledAt DateTime @default(now())
  @@id([studentId, courseId])
}

Queries

// implicit
await prisma.post.update({
  where: { id: 1 },
  data: { tags: { connect: [{ id: 2 }, { id: 3 }] } },
});
await prisma.post.update({        // replace all
  where: { id: 1 },
  data: { tags: { set: [{ id: 4 }] } },
});
// explicit
await prisma.enrollment.create({
  data: { studentId: 1, courseId: 10, grade: "A" },
});
await prisma.student.findUnique({
  where: { id: 1 },
  include: { enrollments: { include: { course: true } } },
});
await prisma.course.findMany({    // has an A
  where: { enrollments: { some: { grade: "A" } } },
});

⚠ Common Mistakes

  • Adding a column to an implicit join table — use an explicit model
  • No @@id/@@unique on the join model — duplicate links
  • set when you meant connect — drops existing links
  • Deep include through the join model in list views

✓ Tips & Best Practices

  • Start explicit if you might ever need link metadata
  • Flatten join results: s.enrollments.map(e => e.course)
  • connect to a missing ID throws — validate IDs first
  • Index courseId on the join model for reverse lookups

Quick Summary

  • implicit — A[] ↔ B[], no extra data
  • explicit — join model + @@id
  • connect · disconnect · set — manage links
  • some — filter through the link
