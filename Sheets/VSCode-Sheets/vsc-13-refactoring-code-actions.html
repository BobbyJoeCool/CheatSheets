Sheet 13

Refactoring & Code Actions

Rename Symbol F2 · Quick Fix ⌘. · extract function / variable · organize imports · source actions · refactor preview

Let the Language Server Change Code

Rename Symbol (F2) renames a variable, function or class everywhere it's used, across files, using the language server rather than text matching. Code Actions (the 💡 light bulb, ⌘. / Ctrl+.) offer quick fixes for errors (add import, fix typo) and refactorings for selections (extract function, extract constant, inline). Source actions act on the whole file: organize imports, fix all.

Notes

  • What's offered depends on the language server
  • Rename shows a preview with ⇧↩ / Shift+Enter before applying
  • Renaming a file in Explorer can update imports (TypeScript and others ask first)
  • Refactor menu: ⌃⇧R / Ctrl+Shift+R

Extract and Rename

# 1. select an expression
const total = items.reduce((s, i) => s + i.price * i.qty, 0);
#    ⌃⇧R / Ctrl+Shift+R → "Extract to function in module scope"
# 2. VS Code creates the function and puts you in rename
function calcTotal(items) { return items.reduce(...); }
const total = calcTotal(items);
# 3. F2 on calcTotal → type orderTotal → ⇧↩ to preview

⌘.      / Ctrl+.          # quick fix / code actions
F2      / F2              # rename symbol
⌃⇧R     / Ctrl+Shift+R    # refactor menu
⇧⌥O     / Shift+Alt+O     # organize imports

Code Explained

Extract works on a selection: select first, then open the refactor menu
After extracting, the new name is selected for an immediate rename
Rename preview lists every file and line; untick any you don't want changed
Organize Imports sorts and removes unused imports for languages that support it

settings.json

  • "editor.codeActionsOnSave": { "source.organizeImports": "explicit" } — on manual save
  • "editor.codeActionsOnSave": { "source.fixAll": "explicit" } — run every auto-fix
  • "javascript.updateImportsOnFileMove.enabled": "always"
  • "editor.lightbulb.enabled": "onCode"

In Other Editors

  • JetBrains — Rename ⇧F6 / Shift+F6, Show Context Actions ⌥↩ / Alt+Enter, Refactor This ⌃T / Ctrl+Alt+Shift+T, Extract Method ⌥⌘M / Ctrl+Alt+M
  • Vim / Neovim — Neovim 0.11 LSP defaults: grn rename, gra code action; or vim.lsp.buf.rename() / .code_action()

⚠ Common Mistakes

  • Renaming with Find & Replace and changing unrelated names in strings and comments
  • Skipping the rename preview and renaming generated or vendored files too
  • Using "always" for organize imports on save and getting noisy diffs in files you only looked at

✓ Tips & Best Practices

  • Use F2 even for local variables; it never touches a different variable with the same name
  • Rename files from Explorer so imports update, not from the terminal
  • Put source actions in codeActionsOnSave with "explicit" so autosave doesn't trigger them

Quick Summary

  • F2 — rename everywhere
  • ⌘. / Ctrl+. — quick fixes
  • ⌃⇧R / Ctrl+Shift+R — refactor
  • codeActionsOnSave — fix and sort on save
