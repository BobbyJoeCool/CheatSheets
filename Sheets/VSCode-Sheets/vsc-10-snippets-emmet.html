Snippets & Emmet

user snippets JSON · prefix / body · $1 tab stops · ${1:placeholder} · snippet variables · Emmet abbreviations

Type a Little, Get a Lot

Snippets expand a short prefix into a template with tab stops. Extensions ship snippets for their languages; you add your own with Snippets: Configure Snippets, per language (python.json), global, or per project (.vscode/*.code-snippets). Emmet is built in for HTML and CSS: ul>li*3 + Tab expands to the full markup.

Notes

  • Snippets show in IntelliSense with a square icon
  • Tab moves between $1, $2…; $0 is the final cursor position
  • ${1|a,b,c|} offers a choice list
  • Insert any snippet with the palette Snippets: Insert Snippet

Extension Pick

  • Auto Rename Tag (Jun Han) — renaming an opening HTML/JSX tag renames the closing one
  • Language snippet packs (e.g. ES7+ React snippets) add ready-made prefixes

A User Snippet (typescript.json)

{
  "Test block": {
    "prefix": "desc",
    "description": "describe + it",
    "body": [
      "describe('${1:subject}', () => {",
      "  it('${2:does something}', () => {",
      "    $0",
      "  });",
      "});"
    ]
  },
  "Log value": {
    "prefix": "logv",
    "body": "console.log('${TM_FILENAME}:${TM_LINE_NUMBER}', ${1:value});"
  }
}

Code Explained

body is a string or an array of lines; escape $ as \\$ when you need it literally
${1:subject} is a tab stop with default text; typing replaces it
Variables like TM_FILENAME, TM_SELECTED_TEXT, CURRENT_YEAR fill in on expansion
Emmet: div.card>h2+p → nested div with an h2 and a p

settings.json

  • "editor.snippetSuggestions": "top" — list snippets first in IntelliSense
  • "emmet.includeLanguages": { "javascript": "javascriptreact" } — Emmet in JSX
  • "editor.tabCompletion": "onlySnippets" — Tab expands a prefix without the menu

In Other Editors

  • JetBrains — Live Templates ⌘J / Ctrl+J, Surround With ⌥⌘J; Emmet built in for HTML
  • Vim / Neovim — LuaSnip or UltiSnips with a completion plugin (nvim-cmp, blink.cmp); emmet-vim for HTML

Snippet Syntax

SyntaxMeans

${1|a,b|}Choice
$1 … $1Mirrored stop

⚠ Common Mistakes

  • Editing a built-in snippet file inside an extension folder; updates overwrite it
  • A prefix that matches a common word, so the snippet pops up while typing prose
  • Unescaped $ in a body (shell or PHP code) being read as a tab stop

✓ Tips & Best Practices

  • Commit team snippets as .vscode/project.code-snippets with a scope field
  • Wrap selected text: use ${TM_SELECTED_TEXT} and run Insert Snippet with a selection
  • Use Emmet's Wrap with Abbreviation palette command to wrap existing HTML

Quick Summary

  • prefix + body — a snippet
  • $1 / $0 — tab stops / final cursor
  • *.code-snippets — project snippets
  • Emmet — ul>li*3 + Tab
