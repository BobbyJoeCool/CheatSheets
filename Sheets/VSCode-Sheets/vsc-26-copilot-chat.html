AI Built Into the Editor

VS Code ships with GitHub Copilot built in (sign in with GitHub; a free tier exists). Inline suggestions appear as ghost text while you type; next edit suggestions predict the next change you'll make elsewhere. The Chat view (⌃⌘I / Ctrl+Alt+I) answers questions and makes edits; inline chat (⌘I / Ctrl+I) works on the selection in place. Pick an agent in Chat: Ask (read-only answers), Agent (edits and runs tools) or Plan (writes a plan to review first).

Notes

  • Tab accepts a suggestion; ⌘→ / Ctrl+→ accepts one word
  • Add context with #file, #selection, #codebase, or drag files into Chat
  • / commands in chat: /explain, /fix, /tests, /plan
  • Pick the model from the model picker in the Chat input

Custom Instructions & Prompt Files

# .github/copilot-instructions.md  (always added)
- Use TypeScript strict mode and named exports.
- Tests use Vitest; put them next to the file as *.test.ts.
- Never edit files under src/generated/.

# .github/instructions/api.instructions.md
---
applyTo: "src/api/**"
---
Return problem+json errors (see docs/errors.md).

# .github/prompts/new-endpoint.prompt.md → /new-endpoint
---
description: Scaffold a REST endpoint with tests
---
Create a handler, route and Vitest test for ${input:name}.

Code Explained

copilot-instructions.md is added to every chat request in the repo
*.instructions.md with applyTo globs add rules only for matching files
Prompt files become /name commands you can run in Chat
AGENTS.md at the repo root is read too, so other agents can share the same rules

settings.json

  • "github.copilot.enable": { "*": true, "markdown": false } — per-language on/off
  • "github.copilot.nextEditSuggestions.enabled": true
  • "editor.inlineSuggest.enabled": true
  • "chat.agent.maxRequests": 25 — steps before Agent asks to continue

⚠ Common Mistakes

  • Accepting a long suggestion without reading it; review AI code like a teammate's PR
  • Asking Chat about "this code" without adding the file or selection as context
  • Writing team rules in personal settings instead of copilot-instructions.md in the repo

✓ Tips & Best Practices

  • Start bigger changes in Plan, then hand the plan to Agent
  • Keep copilot-instructions.md short and specific; long files get diluted
  • Use inline chat (⌘I / Ctrl+I) for small, local edits
