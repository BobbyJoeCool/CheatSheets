Split Editors, Folding & View Options

split right ⌘\ · editor groups · preview vs pinned tabs · fold / unfold regions · sticky scroll · word wrap ⌥Z · minimap

Arrange the Editor Area

Split the editor into editor groups side by side or stacked; each group has its own tabs. Single-clicking a file opens a preview tab (italic) that the next click replaces; double-click or edit to keep it. Folding collapses blocks by indentation or language regions. Sticky Scroll pins the enclosing class and function names at the top.

Notes

  • Drag a tab to an editor edge to split there
  • ⌘1 / Ctrl+1, ⌘2 / Ctrl+2… focus group 1, 2…
  • // #region / // #endregion make foldable regions in most languages
  • Pin a tab to keep it at the left and safe from Close All

Layout Moves

⌘\        / Ctrl+\          # split editor right
⌘K ⌘\     / Ctrl+K Ctrl+\    # split (choose direction)
⌘1 ⌘2     / Ctrl+1 Ctrl+2     # focus group 1 / 2
⌃⌘→       / Ctrl+Alt+→        # move tab to next group
⌘W        / Ctrl+W            # close tab
⇧⌘T       / Ctrl+Shift+T      # reopen closed tab
⌘K ↩      / Ctrl+K Enter      # keep preview tab open
⌥⌘[ / ⌥⌘] / Ctrl+Shift+[ / ]  # fold / unfold block
⌘K ⌘0     / Ctrl+K Ctrl+0     # fold all
⌘K ⌘J     / Ctrl+K Ctrl+J     # unfold all
⌘K ⌘2     / Ctrl+K Ctrl+2     # fold level 2
⌥Z        / Alt+Z             # toggle word wrap

Code Explained

Opening the same file in two groups gives two views of one buffer; edits show in both
⌘K ⌘<n> folds everything at level n, a quick outline of a long file
Word wrap is per window by default; set it per language in settings for Markdown
Reopen Closed Tab works across a session, not just the last tab

settings.json

  • "workbench.editor.enablePreview": false — every open is a real tab
  • "editor.stickyScroll.enabled": true — pin scope headers while scrolling
  • "editor.minimap.enabled": false — hide the code minimap
  • "workbench.editor.limit.enabled": true + "workbench.editor.limit.value": 8 — cap open tabs

In Other Editors

  • JetBrains — Split Right from the tab menu, ⌘W / Ctrl+F4 close, fold ⌘- / Ctrl+-, unfold all ⇧⌘+ / Ctrl+Shift++
  • Vim / Neovim — :vsplit / :split, Ctrl+W h/j/k/l to move, zc / zo fold, zM / zR all, :set wrap

⚠ Common Mistakes

  • Losing a file because it opened as a preview tab and the next click replaced it
  • Splitting into four groups on a laptop screen and reading code at 40 characters wide
  • Folding code to hide it in a review, then missing changes inside the folds

✓ Tips & Best Practices

  • Double-click a file in Explorer to open it as a kept tab straight away
  • Use ⌘K ⌘2 / Ctrl+K Ctrl+2 to get an outline view of a long file
  • Pin the two or three files you return to all day

Quick Summary

  • ⌘\ / Ctrl+\ — split
  • preview tab — italic, replaced on next open
  • ⌘K ⌘0 / ⌘K ⌘J — fold / unfold all
  • ⌥Z / Alt+Z — word wrap
