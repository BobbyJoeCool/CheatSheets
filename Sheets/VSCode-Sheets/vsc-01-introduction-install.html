A Free Editor That Acts Like an IDE

Visual Studio Code is a free, open-source-based code editor from Microsoft that runs on macOS, Windows and Linux. Out of the box it edits, searches and runs Git; extensions and language servers add IntelliSense, debugging and testing for almost every language. Install Stable for daily work (monthly feature releases); Insiders ships nightly. The code command opens files and folders from the terminal.

Notes

  • Download from code.visualstudio.com, or brew install --cask visual-studio-code / winget install Microsoft.VisualStudioCode
  • macOS: run Shell Command: Install 'code' command in PATH from the Command Palette
  • Windows / Linux installers add code to PATH for you
  • Forks such as Cursor, Windsurf and VSCodium share almost everything on these sheets

The code CLI

code .                       # open the current folder
code app.py README.md        # open files in the last window
code -n ~/projects/api       # new window
code -r src/                 # reuse the current window
code -g src/app.ts:42:7      # go to line 42, column 7
code -d old.json new.json    # diff two files
code --wait COMMIT_EDITMSG   # block until the tab closes
git config --global core.editor "code --wait"
code --list-extensions       # installed extension IDs
code --version               # 1.1xx.x  commit  arch
code --disable-extensions .  # troubleshoot without extensions

Code Explained

code . opens the folder as the workspace, which is what Explorer, Search and Git all work from
-g takes file:line:column; terminal links in VS Code use the same format
--wait makes code usable as Git's editor for commit messages and rebase lists
Use code-insiders for the Insiders build; both can be installed side by side

settings.json

  • "update.mode": "default" — check for updates automatically ("manual" / "none")
  • "window.restoreWindows": "all" — reopen every window on launch
  • "telemetry.telemetryLevel": "off" — turn off usage data

In Other Editors

  • JetBrains — launcher idea . / pycharm .; File → Open a folder to make it a project
  • Vim / Neovim — vim . or nvim . opens a file browser (netrw) on the folder

⚠ Common Mistakes

  • Opening single files instead of the project folder, so search, Git and IntelliSense see nothing else
  • Forgetting the macOS Install 'code' command step and wondering why code is not found
  • Mixing Stable and Insiders settings: they are separate installs with separate profiles

✓ Tips & Best Practices

  • Set Git's editor to code --wait so commits and interactive rebases open in VS Code
  • Launch with --disable-extensions to tell an editor bug from an extension bug
  • Turn on Settings Sync right after installing so a new machine is one sign-in away

Quick Summary

  • code . — open this folder
  • code -g f:l — jump to a line
  • code -d a b — diff two files
  • --wait — use VS Code as Git's editor
