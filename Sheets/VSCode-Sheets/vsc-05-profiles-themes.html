Sheet 05

Profiles, Themes & Keybindings

profiles · export / import profile · color & icon themes · fonts & ligatures · keybindings.json · when clauses

Different Setups for Different Work

A profile bundles settings, keybindings, snippets, extensions and UI state. Make one per kind of work (Python, Web, Writing) and switch with a click; a folder remembers its profile. Color themes and file icon themes are just extensions. Custom shortcuts live in keybindings.json as key, command and an optional when clause that limits where they fire.

Notes

  • Profiles: gear icon → Profiles, or Command Palette Profiles: New Profile
  • Start a profile from a template (Python, Data Science, Angular…) or copy an existing one
  • Export a profile to a GitHub gist or file and share the link
  • Theme picker: ⌘K ⌘T / Ctrl+K Ctrl+T (arrow keys preview live)

Extension Pick

  • Material Icon Theme (Philipp Kief) — file and folder icons by type, easier to scan than the default
  • GitHub Theme or One Dark Pro — popular color themes with light and dark variants

keybindings.json

[
  // Move the terminal toggle, only when the editor has focus
  {
    "key": "ctrl+t",
    "command": "workbench.action.terminal.toggleTerminal",
    "when": "editorTextFocus"
  },
  // Run a palette command with arguments
  {
    "key": "cmd+k cmd+m",
    "command": "workbench.action.editor.changeLanguageMode"
  },
  // Remove a default binding (leading "-")
  { "key": "cmd+k cmd+w", "command": "-workbench.action.closeAllEditors" }
]

Code Explained

Open it from Keyboard Shortcuts (⌘K ⌘S / Ctrl+K Ctrl+S) → Open Keyboard Shortcuts (JSON) icon
when uses context keys like editorTextFocus, terminalFocus, resourceExtname == .py
Two-step chords (cmd+k cmd+m) are pressed in sequence
A - before the command removes a default binding instead of adding one

settings.json

  • "workbench.colorTheme": "Default Dark Modern"
  • "window.autoDetectColorScheme": true — follow the OS light/dark mode
  • "editor.fontFamily": "'JetBrains Mono', Menlo, monospace" + "editor.fontLigatures": true

In Other Editors

  • JetBrains — Keymap settings and Color Scheme per IDE; no profiles, but separate IDEs fill that role
  • Vim / Neovim — :colorscheme; vim.keymap.set("n", "<leader>t", …) in init.lua; autocmd for context

⚠ Common Mistakes

  • Installing every extension in one profile, then living with a slow editor for every project
  • Adding a keybinding without a when clause and breaking the same key in the terminal
  • Editing keybindings.json by hand without checking conflicts in the Keyboard Shortcuts editor

✓ Tips & Best Practices

  • Keep a minimal Default profile and add language profiles on top
  • Use the Record Keys button in Keyboard Shortcuts to find what a key already does
  • Sync profiles with Settings Sync so they follow you to new machines

Quick Summary
