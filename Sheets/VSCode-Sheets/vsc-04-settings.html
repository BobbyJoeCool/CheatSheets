Sheet 04

Settings

Settings editor vs settings.json · User / Workspace / Folder · [python] overrides · @modified · Settings Sync

Layers of JSON, Most Specific Wins

Every option is a key in a settings.json file. User settings apply everywhere; Workspace settings live in .vscode/settings.json and override them for one project; in a multi-root workspace each Folder can override again. A "[language]" block overrides by file type. The Settings editor (⌘, / Ctrl+,) is a searchable UI over the same files; the {} icon opens the JSON.

Notes

  • Workspace settings are committed with the repo; keep personal taste in User
  • Search filters: @modified, @ext:ms-python.python, @lang:python, @tag:experimental
  • Hover a setting's gear → Copy Setting ID for the JSON key
  • Settings Sync (Accounts menu) syncs settings, keys, snippets, extensions, profiles

settings.json (JSON with comments)

{
  // User: ~/Library/Application Support/Code/User/settings.json
  "editor.fontSize": 14,
  "editor.tabSize": 2,
  "editor.rulers": [80, 120],
  "files.autoSave": "onFocusChange",
  "files.trimTrailingWhitespace": true,
  "files.insertFinalNewline": true,

  // Language-specific override
  "[python]": {
    "editor.tabSize": 4,
    "editor.formatOnSave": true
  },
  "[markdown]": { "editor.wordWrap": "on" }
}

Code Explained

Settings files are JSONC: comments and trailing commas are allowed
Windows path: %APPDATA%\Code\User\settings.json; Linux: ~/.config/Code/User/
"[python]" applies only to Python files and beats both User and Workspace values
Unknown or misspelled keys are greyed out with a warning squiggle

settings.json

  • "workbench.settings.editor": "json" — open settings straight to JSON
  • "files.autoSave": "afterDelay" + "files.autoSaveDelay": 1000
  • "editor.rulers": [80] — vertical guide lines at those columns

In Other Editors

  • JetBrains — Settings ⌘, / Ctrl+Alt+S, stored as XML in .idea/ (project) and the IDE config dir; Settings Sync via JetBrains account
  • Vim / Neovim — ~/.vimrc or ~/.config/nvim/init.lua; :set tabstop=2; ftplugin/python.lua for per-language settings

⚠ Common Mistakes

  • Committing personal preferences (font size, theme) in .vscode/settings.json for the whole team
  • Editing a setting in the UI under the wrong tab (User vs Workspace) and wondering why it doesn't apply
  • Copying JSON with a missing comma; VS Code ignores the whole file until it parses

✓ Tips & Best Practices

  • Filter by @modified to see exactly what you have changed from the defaults
  • Put formatter and linter settings in Workspace so every contributor gets them
  • Use Copy Setting ID instead of guessing key names

Quick Summary

  • ⌘, / Ctrl+, — Settings editor
  • settings.json — the real source (JSONC)
  • "[lang]" — per-language override
  • Workspace beats User; Folder beats Workspace
