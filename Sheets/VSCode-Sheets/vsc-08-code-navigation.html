Move Through Code by Meaning

The language server knows what every name refers to. Go to Definition (F12, or ⌘/Ctrl+Click) jumps to where a symbol is declared; Peek shows it inline without leaving your place. Find All References lists every use. Go Back (⌃- / Alt+←) returns along your trail, like a browser's back button.

Notes

  • Navigation needs a language extension; plain-text files only get word search
  • Breadcrumbs above the editor show the file path and symbol path; click to jump
  • The Outline view lists the current file's symbols
  • Call Hierarchy and Type Hierarchy are in the right-click menu

Following a Bug Through the Code

F12          / F12            # go to definition
⌘Click       / Ctrl+Click     # same, with the mouse
⌥F12         / Alt+F12        # peek definition (inline)
⌘F12         / Ctrl+F12       # go to implementation
⇧F12         / Shift+F12      # peek references
⇧⌥F12        / Shift+Alt+F12  # find all references (panel)
⇧⌘O          / Ctrl+Shift+O   # symbol in this file
⌘T           / Ctrl+T         # symbol in workspace
⌃G           / Ctrl+G         # go to line
⌃-  / ⌃⇧-    / Alt+← / Alt+→  # back / forward
⇧⌘\          / Ctrl+Shift+\   # matching bracket
F8 / ⇧F8     / F8 / Shift+F8  # next / previous problem

Code Explained

Peek opens an embedded editor: you can edit the definition there and Esc closes it
References in the panel stay put while you click through them
Back / Forward cross files and remember cursor positions, not just files
F8 cycles through errors and warnings in the current file

settings.json

  • "breadcrumbs.enabled": true — path and symbol bar above the editor
  • "editor.gotoLocation.multipleDefinitions": "goto" — skip the peek when there are several
  • "workbench.editor.revealIfOpen": true — reuse an open tab instead of opening a new one

In Other Editors

  • JetBrains — declaration ⌘B / Ctrl+B, implementation ⌥⌘B / Ctrl+Alt+B, find usages ⌥F7 / Alt+F7, file structure ⌘F12 / Ctrl+F12, back ⌘[ / Ctrl+Alt+←
  • Vim / Neovim — gd / LSP definition, grr references and gri implementation (Neovim 0.11 defaults), Ctrl+O / Ctrl+I jump list, % bracket

⚠ Common Mistakes

  • Searching text for a function name and landing in comments and strings; use Find All References
  • Opening a new tab for every jump and losing track; use Go Back instead of the tab bar
  • Expecting navigation in a file with no language extension installed

✓ Tips & Best Practices

  • Use Peek (⌥F12 / Alt+F12) to check a signature without losing your place
  • Breadcrumbs: ⇧⌘. / Ctrl+Shift+. focuses them so you can pick a sibling symbol by keyboard
  • Map the mouse's back/forward buttons to Go Back / Go Forward
