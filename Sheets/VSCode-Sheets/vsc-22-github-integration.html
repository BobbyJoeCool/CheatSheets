Pull Requests and Issues in the Editor

Signing in with GitHub (Accounts menu) lets VS Code publish a repo, clone private ones and push over HTTPS. The GitHub Pull Requests extension adds a view for PRs and issues: check out a PR as a local branch, review the diff with full IntelliSense, leave comments in the gutter and approve or request changes. Pressing . on any github.com repo opens github.dev, a browser VS Code for quick edits.

Notes

  • Publish to GitHub in Source Control creates the remote repo and pushes
  • Clone: palette Git: Clone → Clone from GitHub
  • github.dev has no terminal or debugger; Codespaces adds them
  • The GitHub set covers PRs, Issues and Actions on the website

Extension Pick

  • GitHub Pull Requests (GitHub) — PR and issue views, review comments, check out PRs
  • GitHub Actions (GitHub) — workflow runs and logs in the Side Bar

Review a Pull Request Locally

  1. Open the GitHub view and expand Pull Requests → Waiting for my review
  2. Click the PR → Checkout; VS Code switches to its branch
  3. Open Files Changed; each file opens as a diff you can navigate and run
  4. Click + in the gutter to comment on a line, or select lines first
  5. Use the PR description page to Approve, Comment or Request Changes
  6. Switch back with the branch picker, or Exit Review Mode

  • "githubPullRequests.defaultMergeMethod": "squash"
  • "github.gitProtocol": "ssh" — clone with SSH instead of HTTPS
  • "git.openRepositoryInParentFolders": "always"

⚠ Common Mistakes

  • Reviewing only on the website and never running the PR's code
  • Leaving review comments as Start Review and forgetting to submit, so the author never sees them
  • Editing on github.dev and expecting to run tests there

✓ Tips & Best Practices

  • Check out PRs locally for anything bigger than a typo
  • Use Copy GitHub Permalink to share a line in chat
  • Create the PR from VS Code right after pushing; it fills the title from your commits

Quick Summary

  • Publish to GitHub — create remote + push
  • GitHub Pull Requests ext — review in the editor
  • Checkout — run the PR locally
