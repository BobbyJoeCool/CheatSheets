Sheet 06

Multi-Cursor & Selection

⌥Click / Alt+Click · ⌘D / Ctrl+D · ⇧⌘L select all · column selection · expand / shrink selection · undo cursor

Edit Many Places at Once

VS Code supports multiple cursors: every cursor types, deletes and pastes at the same time. Add them by clicking, by selecting the next match of the current word, or by dragging a column (box) selection. Expand selection grows the selection by syntax (word → string → argument list → statement → block), which is faster than shift-arrowing.

Notes

  • Esc collapses back to one cursor
  • Pasting N lines into N cursors puts one line at each cursor
  • Matches respect the Find widget's case and whole-word toggles
  • Rename Symbol (F2) is safer than multi-cursor for code identifiers

Typical Moves

# Rename every "user" in this block
⌘D ⌘D ⌘D      / Ctrl+D ×3    # add next 3 matches
⌘K ⌘D         / Ctrl+K Ctrl+D # skip this match, take the next
⇧⌘L           / Ctrl+Shift+L  # select ALL matches

# Add a comma to the end of 10 lines
select lines → ⇧⌥I / Shift+Alt+I   # a cursor at each line end

# Column edit
⇧⌥ + drag     / Shift+Alt + drag
⌥⌘↓           / Ctrl+Alt+↓        # cursor on the line below

# Grow and shrink by syntax
⌃⇧⌘→ / Shift+Alt+→   ⌃⇧⌘← / Shift+Alt+←
⌘U            / Ctrl+U        # undo last cursor

Code Explained

⌘D / Ctrl+D with nothing selected selects the word under the cursor first
Select All Occurrences is the fast version, but check the match count in the Find widget first
Cursors at line ends (⇧⌥I / Shift+Alt+I) is the quickest way to edit a column of lines
On Linux, Ctrl+Alt+↓ may be taken by the desktop; rebind if it does nothing

settings.json

  • "editor.multiCursorModifier": "ctrlCmd" — make ⌘/Ctrl+Click add cursors (⌥/Alt+Click then opens links)
  • "editor.columnSelection": true — plain drags make box selections
  • "editor.multiCursorPaste": "spread" — one pasted line per cursor

In Other Editors

  • JetBrains — add next occurrence ⌃G / Alt+J, select all ⌃⌘G / Ctrl+Alt+Shift+J, column mode ⇧⌘8 / Alt+Shift+Insert, extend selection ⌥↑ / Ctrl+W
  • Vim / Neovim — * then cgn and . to repeat; Ctrl+V block mode + I / A; vim-visual-multi plugin for real cursors

⚠ Common Mistakes

  • Using ⇧⌘L / Ctrl+Shift+L on a common word and changing matches far off-screen
  • Renaming a variable with multi-cursor and missing uses in other files; use F2
  • Fighting ⌥/Alt+Click because it opens links after changing multiCursorModifier

✓ Tips & Best Practices

  • Use ⌘D / Ctrl+D a few times and watch each match before typing
  • Expand selection twice to grab a whole string or argument list
  • Paste a list into the same number of cursors to fill a column

Quick Summary

  • ⌘D / Ctrl+D — next match
  • ⇧⌘L / Ctrl+Shift+L — all matches
  • ⇧⌥I / Shift+Alt+I — cursors at line ends
  • Expand selection — grow by syntax
