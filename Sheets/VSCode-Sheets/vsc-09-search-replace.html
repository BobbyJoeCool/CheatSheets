Search & Replace

find / replace in file · Search view ⇧⌘F · regex & capture groups · files to include / exclude · preserve case · Search Editor

Find It Once, Change It Everywhere

The Find widget (⌘F / Ctrl+F) searches the current file; Search (⇧⌘F / Ctrl+Shift+F) searches the whole workspace with ripgrep, honoring .gitignore. Both support regular expressions with capture groups ($1 in the replacement), match case and whole word. A Search Editor puts results in a full editor tab you can save and re-run.

Notes

  • Toggles: Match Case ⌥⌘C / Alt+C, Whole Word ⌥⌘W / Alt+W, Regex ⌥⌘R / Alt+R
  • Preserve Case (AB button) keeps User → Account, user → account
  • Replace previews a diff per file before anything is written
  • Click ⋯ in Search to show files to include / exclude boxes

Extension Pick

  • Todo Tree (Gruntfuggly) — collects every TODO / FIXME in the workspace into a tree, using the same search engine

Regex Replace Across Files

# Search: ⇧⌘H / Ctrl+Shift+H opens Search with Replace
Find:    console\.log\((.*)\);?
Replace: logger.debug($1);
files to include:  src/**/*.ts
files to exclude:  **/*.test.ts, dist

# Rename keys: snake_case → camelCase
Find:    _([a-z])
Replace: \u$1            # \u = uppercase next char

# In-file: ⌥⌘F / Ctrl+H
Find:    ^\s*$\n         # blank lines (regex on)
Replace: (empty)
⌥↩ / Alt+Enter         # select all matches → multi-cursor

Code Explained

$1, $2 insert capture groups; \u, \l, \U, \L change case in the replacement
Include / exclude boxes take globs, comma-separated; ./src limits to a folder
Alt+Enter on Find turns every match into a cursor for hand edits
Search skips files in .gitignore and files.exclude unless you turn that off

settings.json

  • "search.exclude": { "/dist": true, "/*.min.js": true }
  • "search.useIgnoreFiles": true — respect .gitignore (default)
  • "search.smartCase": true — case-sensitive only when you type a capital

In Other Editors

  • JetBrains — Find in Files ⇧⌘F / Ctrl+Shift+F, Replace in Files ⇧⌘R / Ctrl+Shift+R, regex $1 groups the same
  • Vim / Neovim — :%s/old/new/gc, :vimgrep / :grep + quickfix, :cdo s/a/b/g across files; Telescope live_grep

⚠ Common Mistakes

  • Replace All across the workspace without reading the preview; build output and vendored code can match too
  • Forgetting the regex toggle is on and wondering why . matches everything
  • Searching inside node_modules because search.exclude was changed

✓ Tips & Best Practices

  • Open a Search Editor (⇧⌘P → Search Editor: New) for searches you'll re-run
  • Use Preserve Case for renames that appear as Foo, foo and FOO
  • Right-click a folder in Explorer → Find in Folder to scope a search

Quick Summary

  • ⌘F / Ctrl+F — this file
  • ⇧⌘F / Ctrl+Shift+F — workspace
  • $1 — capture group in replace
  • include / exclude — glob filters
