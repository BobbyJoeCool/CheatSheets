Managing Extensions

Extensions view ⇧⌘X · code --install-extension · .vscode/extensions.json · disable per workspace · Extension Bisect · extension settings

Add Only What You Use

Almost every language, linter, theme and tool comes as an extension from the Marketplace (VSCodium and some forks use Open VSX). Install from the Extensions view (⇧⌘X / Ctrl+Shift+X) or the CLI. Recommend extensions to a team with .vscode/extensions.json; VS Code prompts anyone who opens the repo. Disable extensions per workspace to keep other projects fast.

Notes

  • An extension ID is publisher.name, e.g. ms-python.python
  • Check the publisher's verified ✓ badge and install count
  • Extension Bisect finds the extension causing a problem by halving the set
  • Extension settings: gear icon → Settings, or @ext: in the Settings search

Extension Pick

  • EditorConfig (EditorConfig) — applies .editorconfig rules
  • Code Spell Checker (Street Side Software) — catches typos in code and comments

Install and Recommend

code --install-extension ms-python.python
code --install-extension esbenp.prettier-vscode@11.0.0
code --uninstall-extension some.extension
code --list-extensions > extensions.txt

# .vscode/extensions.json (commit this)
{
  "recommendations": [
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode",
    "vitest.explorer"
  ],
  "unwantedRecommendations": ["hookyqr.beautify"]
}

Code Explained

@version installs a specific version, useful when a new release breaks something
--list-extensions output can be piped back into --install-extension on a new machine
Recommendations show under Recommended in the Extensions view
unwantedRecommendations stops VS Code suggesting an extension for this repo

settings.json

  • "extensions.autoUpdate": "onlyEnabledExtensions"
  • "extensions.ignoreRecommendations": false
  • "extensions.autoCheckUpdates": true

⚠ Common Mistakes

  • Installing from unknown publishers; extensions run with your user's permissions
  • Two extensions doing the same job (two Python formatters, two Git UIs) and slowing startup
  • Recommending extensions only in a README instead of extensions.json

✓ Tips & Best Practices

  • Disable heavy extensions per workspace instead of uninstalling them
  • Use Show Running Extensions to spot slow activation times
  • Keep extensions.json short: only what the project actually needs

Quick Summary

  • ⇧⌘X / Ctrl+Shift+X — Extensions view
  • publisher.name — extension ID
  • extensions.json — team recommendations
  • Extension Bisect — find a bad extension
