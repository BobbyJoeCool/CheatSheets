Agent Mode, MCP & Other AI Tools

agent tools · tool approval · .vscode/mcp.json · MCP servers · custom agents · Claude Code extension · other harnesses

Agents That Use Tools

In Agent mode the model can read and edit files, run terminal commands and call tools. Each tool call that can change things asks for approval unless you allow it. MCP servers (Model Context Protocol) add more tools, such as a database, a browser or an issue tracker, configured in .vscode/mcp.json. VS Code can also host other agents: the session picker offers harnesses such as Copilot, Local, Claude and Codex, and the Claude Code extension adds its own panel.

Notes

  • Tool approvals can be once, for the session, for the workspace, or always
  • The tools icon in the Chat input turns individual tools on or off
  • MCP: List Servers in the palette starts, stops and shows logs
  • The Agentic Coding set covers prompting and workflows in depth

Extension Pick

  • Claude Code for VS Code (Anthropic) — Claude Code in a side panel with inline diffs
  • GitHub Copilot Chat (GitHub) — Chat, agents and MCP support

.vscode/mcp.json

{
  "inputs": [
    { "id": "gh-token", "type": "promptString",
      "description": "GitHub token", "password": true }
  ],
  "servers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    },
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": { "Authorization": "Bearer ${input:gh-token}" }
    }
  }
}

Code Explained

servers lists each MCP server: command + args for a local (stdio) one, type: "http" + url for a remote one
inputs prompt for secrets once and store them securely, so the file can be committed
Servers can also be installed from the Extensions view (@mcp) or added to User settings
Custom agents (.github/agents/*.agent.md) can limit which tools an agent may use

settings.json

  • "chat.agent.enabled": true
  • "chat.mcp.discovery.enabled": true — reuse MCP configs from other apps
  • "github.copilot.chat.codeGeneration.useInstructionFiles": true

In Other Editors

⚠ Common Mistakes

  • Turning on "always allow" for terminal commands in a repo you don't fully trust
  • Committing tokens in mcp.json instead of using inputs or environment variables
  • Adding a dozen MCP servers so the model has too many tools to pick from well

✓ Tips & Best Practices

  • Enable only the MCP servers a task needs
  • Review the diff Agent produces in Source Control before committing
  • Use a custom agent with a read-only tool set for reviews and research
