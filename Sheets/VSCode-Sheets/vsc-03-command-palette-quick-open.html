Sheet 03

Command Palette & Quick Open

⇧⌘P / Ctrl+Shift+P · ⌘P / Ctrl+P · > @ : # ? prefixes · recent files · keybinding lookup

One Box to Reach Everything

Quick Open (⌘P / Ctrl+P) finds files by fuzzy name. Typing a prefix turns the same box into other tools: > runs a command (the Command Palette, ⇧⌘P / Ctrl+Shift+P), @ jumps to a symbol in this file, # searches symbols across the workspace, : goes to a line and ? lists every prefix. Every command shows its shortcut, so the palette is also how you learn them.

Notes

  • Fuzzy matching: usrctl finds UserController.ts
  • Recently used files and commands float to the top
  • ⌘Enter / Ctrl+Enter opens the result to the side
  • Press ⌘P / Ctrl+P twice to toggle between the last two files

Prefixes in the Quick Open Box

app.ts           # file by name (fuzzy)
app.ts:42        # file, then line 42
>format doc      # run a command
>Preferences: Open User Settings (JSON)
@render          # symbol in this file
@:               # symbols grouped by kind
#UserService     # symbol anywhere in the workspace
:120             # go to line 120
edt ⟨tab⟩        # open editors list
term             # pick a terminal (prefix "term ")
task             # run a task (prefix "task ")
debug            # start a launch configuration
?                # show all prefixes

Code Explained

File, command and symbol search all live in one widget; the first character decides the mode
file:line jumps straight to a line, handy when pasting from a stack trace
@: groups symbols as Classes, Methods, Properties so long files are easy to scan
The word prefixes (term, task, debug) need a space after them

settings.json

  • "workbench.commandPalette.history": 50 — how many recent commands to keep
  • "workbench.quickOpen.closeOnFocusLost": false — keep the box open when you click away
  • "search.quickOpen.includeSymbols": true — mix workspace symbols into file results

In Other Editors

  • JetBrains — Search Everywhere: double ⇧ / double Shift; Find Action ⇧⌘A / Ctrl+Shift+A
  • Vim / Neovim — : command line; Telescope / fzf-lua (find_files, commands, lsp_document_symbols)

⚠ Common Mistakes

  • Clicking through menus for things the palette finds in two keystrokes
  • Typing > in ⌘P / Ctrl+P and forgetting that ⇧⌘P / Ctrl+Shift+P already adds it
  • Searching for a function with @ when it lives in another file; use # for the workspace

✓ Tips & Best Practices

  • Use ⌘P / Ctrl+P then @ to land in a file and a symbol in one go
  • F1 also opens the Command Palette and is easier to hit on some keyboards
  • Bind your top three palette commands to keys from the gear icon

Quick Summary

  • ⌘P / Ctrl+P — files
  • ⇧⌘P / Ctrl+Shift+P — commands
  • @ / # — symbols here / everywhere
  • : — line
