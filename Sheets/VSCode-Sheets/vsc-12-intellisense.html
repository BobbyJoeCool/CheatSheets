Completions From a Language Server

IntelliSense is VS Code's name for completions, parameter hints, hover info and diagnostics. Most of it comes from a language server that an extension starts (Pylance for Python, the TypeScript server, the Java Language Server). They speak the Language Server Protocol (LSP), which is why one editor can support so many languages. Errors and warnings land in the Problems panel.

Notes

  • TypeScript / JavaScript, HTML, CSS and JSON support is built in
  • Other languages: install the language's extension pack (Python, Java, C#, Go, Rust)
  • Inlay hints show parameter names and inferred types in the code
  • Language server logs: Output panel → pick the server in the dropdown

Extension Pick

  • Error Lens (Alexander) — prints each error and warning at the end of its line, so you don't need the Problems panel
  • Language extension packs from Microsoft and the language teams (see each language set)

Asking for Help While Typing

⌃Space     / Ctrl+Space        # trigger suggestions
⇧⌘Space    / Ctrl+Shift+Space  # parameter hints
⌘K ⌘I      / Ctrl+K Ctrl+I     # show hover
Tab / ↩    / Tab / Enter       # accept suggestion
⌃Space again                   # expand suggestion details
⇧⌘M        / Ctrl+Shift+M      # Problems panel
F8 / ⇧F8   / F8 / Shift+F8     # next / previous problem

# Restart a stuck server (palette):
>TypeScript: Restart TS Server
>Python: Restart Language Server
>Developer: Reload Window

Code Explained

Suggestions appear as you type; ⌃Space / Ctrl+Space forces them after you dismissed them
Parameter hints show the signature and bold the argument you're on
When completions stop or go wrong, restarting the server fixes most cases
Reload Window restarts all extensions without closing VS Code

settings.json

  • "editor.inlayHints.enabled": "onUnlessPressed" — hide hints while holding ⌃⌥ / Ctrl+Alt
  • "editor.quickSuggestions": { "strings": "on" } — suggest inside strings too
  • "editor.acceptSuggestionOnEnter": "off" — only Tab accepts
  • "editor.suggest.preview": true — show the completion inline before accepting

In Other Editors

  • JetBrains — completion ⌃Space / Ctrl+Space, parameter info ⌘P / Ctrl+P, quick doc F1 / Ctrl+Q; analysis is built into each IDE, not LSP
  • Vim / Neovim — built-in LSP (vim.lsp.enable() in 0.11), K hover, Ctrl+S signature help in insert mode, nvim-lspconfig, blink.cmp / nvim-cmp

⚠ Common Mistakes

  • Installing two servers for the same language (e.g. two Python servers) that fight over diagnostics
  • Blaming VS Code for missing completions when the project's interpreter / SDK isn't selected
  • Ignoring the Problems count in the Status Bar until CI fails

✓ Tips & Best Practices

  • Select the right interpreter or SDK first (Status Bar language item)
  • Turn on inlay hints for parameter names when reading unfamiliar APIs
  • Check the server's Output channel before reinstalling anything

Quick Summary

  • ⌃Space / Ctrl+Space — suggest
  • ⇧⌘Space — parameter hints
  • LSP — one protocol, many languages
  • Restart TS / language server — fixes stuck IntelliSense
