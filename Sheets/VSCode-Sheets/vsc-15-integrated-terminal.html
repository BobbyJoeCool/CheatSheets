Integrated Terminal

toggle ⌃` · new / split terminal · terminal profiles · shell integration · run selected text · terminal links · move to editor area

A Real Shell Next to the Code

The integrated terminal runs your normal shell (zsh, bash, PowerShell) in the Panel, starting in the workspace folder. You can have many terminals, split them side by side, or move one into an editor tab. Shell integration marks each command, so you can jump between commands, see which failed, and rerun recent ones.

Notes

  • File paths and URLs in output are clickable (⌘ / Ctrl+Click)
  • Run Selected Text sends the selection to the active terminal
  • Terminals survive a window reload (persistent sessions)
  • Pick a different shell from the + ▾ dropdown (terminal profiles)

Terminal Shortcuts

⌃`       / Ctrl+`         # toggle terminal
⌃⇧`      / Ctrl+Shift+`   # new terminal
⌘\        / Ctrl+Shift+5      # split terminal
⌘K         / (palette) Clear  # clear the terminal
⌘↑ / ⌘↓    / Ctrl+↑ / Ctrl+↓  # previous / next command
⌃R         / Ctrl+Alt+R       # run recent command
⇧⌘C        / Ctrl+Shift+C     # open external terminal

# Palette commands
>Terminal: Run Selected Text In Active Terminal
>Terminal: Move Terminal into Editor Area
>Terminal: Select Default Profile

Code Explained

Command navigation (⌘↑ / Ctrl+↑) needs shell integration, which is on by default for common shells
The blue / red dot beside each command shows success or failure
Run Recent Command searches history from all sessions with shell integration
Moving a terminal into the editor area lets you split it next to code

settings.json

  • "terminal.integrated.defaultProfile.osx": "zsh" (.windows / .linux for others)
  • "terminal.integrated.fontSize": 13
  • "terminal.integrated.cwd": "${workspaceFolder}"
  • "terminal.integrated.scrollback": 10000 — lines kept

In Other Editors

  • JetBrains — Terminal tool window ⌥F12 / Alt+F12; New Session, Split Right from its menu
  • Vim / Neovim — :terminal (:vsplit | terminal), Ctrl+\ Ctrl+N to leave terminal mode; toggleterm.nvim plugin

⚠ Common Mistakes

  • Running a long server in the only terminal, then killing it to run a command; open a second terminal
  • Setting PATH in .zshrc and expecting already-open terminals to see it; open a new one
  • Using the terminal's ⌘K / Ctrl+K and triggering a VS Code chord instead

✓ Tips & Best Practices

  • Name terminals ("server", "tests") so the dropdown makes sense
  • Use Run Selected Text to try lines from a script without saving
  • Turn on terminal.integrated.stickyScroll.enabled to keep the running command visible

Quick Summary
