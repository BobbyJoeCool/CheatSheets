Sheet 07

Line Editing Shortcuts

move line ⌥↑ · copy line ⇧⌥↓ · delete line · toggle comment ⌘/ · indent / outdent · join lines · transform case

Work in Whole Lines

Most editing is moving, copying, deleting and commenting whole lines. These commands work on the current line with no selection, or on every line the selection touches, so you never need to select a line first. They also work with multiple cursors.

Notes

  • ⌘X / Ctrl+X and ⌘C / Ctrl+C with nothing selected cut or copy the whole line
  • Move Line stays inside the file; it re-indents when the language supports it
  • Transform to Upper / Lower / Title / Snake / Kebab case are palette commands (no default key)
  • Sort Lines Ascending is a palette command too

Reshaping a Block

⌥↑ / ⌥↓          Alt+↑ / Alt+↓          # move line(s) up / down
⇧⌥↓ / ⇧⌥↑        Shift+Alt+↓ / ↑        # copy line(s) down / up
⇧⌘K              Ctrl+Shift+K           # delete line(s)
⌘↩ / ⇧⌘↩         Ctrl+Enter / +Shift    # new line below / above
⌘/               Ctrl+/                 # toggle line comment
⇧⌥A              Shift+Alt+A            # toggle block comment
⌘] / ⌘[          Ctrl+] / Ctrl+[        # indent / outdent
⌃J               (palette: Join Lines)  # join with the next line
⇧⌘\              Ctrl+Shift+\           # jump to matching bracket
>Transform to Snake Case               # user_name
>Sort Lines Ascending

Code Explained

Moving lines with ⌥↑ / Alt+↑ is faster than cut-and-paste and keeps the clipboard
Comment toggles use the language's syntax (#, //, <!-- -->) automatically
Join Lines has a default key on macOS only; bind it on Windows / Linux if you use it
All of these apply to every line under every cursor

settings.json

  • "editor.emptySelectionClipboard": true — copy/cut the line when nothing is selected (default)
  • "editor.comments.insertSpace": true — // text instead of //text
  • "editor.autoIndentOnPaste": true — re-indent pasted code

In Other Editors

  • JetBrains — move line ⌥⇧↑ / Alt+Shift+↑, duplicate ⌘D / Ctrl+D, delete ⌘⌫ / Ctrl+Y, comment ⌘/ / Ctrl+/, join ⌃⇧J / Ctrl+Shift+J
  • Vim / Neovim — :m +1 / ddp move, yyp copy, dd delete, gcc comment (built in since Neovim 0.10), >> / <<, J join

⚠ Common Mistakes

  • Selecting a line by dragging before copying it; the shortcut already copies the whole line
  • Using Copy Line on Linux where Shift+Alt+↓ is taken by the desktop; rebind it
  • Block-commenting in languages without block comments (Python) and getting a string literal instead

✓ Tips & Best Practices

  • Move a function by putting the cursor in it, expanding selection to the block, then ⌥↑ / Alt+↑
  • Bind Transform to Snake / Camel Case if you rename keys often
  • Use Sort Lines on import lists and .gitignore files

Quick Summary

  • ⌥↑ / Alt+↑ — move line
  • ⇧⌥↓ / Shift+Alt+↓ — copy line
  • ⇧⌘K / Ctrl+Shift+K — delete line
  • ⌘/ / Ctrl+/ — comment
