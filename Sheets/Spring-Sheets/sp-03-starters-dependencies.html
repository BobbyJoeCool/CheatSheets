Starters

A starter pulls in everything one feature needs: the library, Spring's integration and Boot's auto-configuration. spring-boot-starter-data-jpa brings Hibernate, Spring Data JPA, a pool and transactions. Boot 4 split auto-configuration into modules, so starters are more focused and each has a -test partner.

Notes

  • Official: spring-boot-starter-*; third-party: *-spring-boot-starter
  • Boot 4 renamed starter-web → starter-webmvc
  • Flyway now needs spring-boot-starter-flyway
  • spring-boot-starter-classic restores Boot 3-style all-in-one
  • See the tree: ./mvnw dependency:tree

Common Dependencies (Maven)

<dependency>                         <!-- REST + Tomcat -->
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-webmvc</artifactId>
  <exclusions>                       <!-- drop Tomcat... -->
    <exclusion>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-tomcat</artifactId>
    </exclusion>
  </exclusions>
</dependency>
<dependency>                         <!-- ...use Jetty -->
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-jetty</artifactId>
</dependency>

Gradle

implementation("org.springframework.boot:spring-boot-starter-data-jpa")
runtimeOnly("org.postgresql:postgresql")
testImplementation("org.springframework.boot:spring-boot-starter-webmvc-test")

Code Explained

Versions come from the BOM; only non-managed libs need one
<exclusions> removes a transitive dependency (here Tomcat)
Undertow was removed in Boot 4; Jetty is the alternative
runtimeOnly: needed to run, not compile (JDBC drivers)
-test starters bring that technology's test slices

⚠ Common Mistakes

  • Using starter-web in new Boot 4 builds; it still works but is deprecated
  • Adding flyway-core alone; Boot 4 won't auto-configure it without the starter
  • Expecting @WebMvcTest without spring-boot-starter-webmvc-test

✓ Tips & Best Practices

  • Keep the starter list small; each adds auto-config and startup time
  • Upgrading from 3.x? Start with starter-classic, then slim down
  • Use dependency:tree -Dincludes=groupId to find version clashes

Quick Summary

  • spring-boot-starter-*: one feature
  • BOM: manages versions
  • -test starters: test slices
  • <exclusions>: swap transitive deps
