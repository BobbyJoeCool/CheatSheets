Mocking Beans

@MockitoBean · @MockitoSpyBean · when().thenReturn() · verify() · @WithMockUser · spring-security-test

Mocks and Test Users

@MockitoBean replaces a bean in the test context with a Mockito mock; @MockitoSpyBean wraps the real bean so you can verify calls. They replace Boot's removed @MockBean / @SpyBean. For secured endpoints, spring-security-test adds @WithMockUser and request post-processors such as jwt() and csrf().

Notes

  • Mocks are reset after each test automatically
  • Each different set of mocked beans creates a new context
  • Boot 4: add spring-boot-starter-security-test for @WithMockUser
  • Plain unit tests: use @ExtendWith(MockitoExtension.class) + @Mock

Mocks and Security in a Slice

@WebMvcTest(AdminController.class)
class AdminControllerTests {

    @Autowired MockMvcTester mvc;
    @MockitoBean UserService users;             // mock
    @MockitoSpyBean AuditLog audit;             // real bean, spied

    @Test
    @WithMockUser(roles = "ADMIN")
    void adminCanDelete() {
        assertThat(mvc.delete().uri("/admin/users/5").with(csrf()))
            .hasStatus(HttpStatus.NO_CONTENT);
        verify(users).delete(5L);
        verify(audit).record(contains("deleted 5"));
    }

    @Test
    void anonymousIsRejected() {
        assertThat(mvc.delete().uri("/admin/users/5").with(csrf()))
            .hasStatus(HttpStatus.UNAUTHORIZED);
    }
}

Code Explained

csrf() adds a valid token to state-changing requests
verify(users).delete(5L) checks the mock was called
Without a user the API returns 401
For token APIs: .with(jwt()) fakes a validated JWT

⚠ Common Mistakes

  • Forgetting .with(csrf()) on POST/PUT/DELETE; you get 403, not your status
  • Mocking the class under test; you test Mockito, not your code
  • Many unique @MockitoBean combos, each spawning a new context

✓ Tips & Best Practices

  • Put shared mocks on a base class or meta-annotation
  • Prefer real objects over mocks for simple value collaborators
  • Use @WithMockUser on the class to cover every test

Quick Summary

  • @MockitoBean: mock a bean
  • @MockitoSpyBean: spy a real bean
  • @WithMockUser: fake login
  • csrf() / jwt(): request helpers
