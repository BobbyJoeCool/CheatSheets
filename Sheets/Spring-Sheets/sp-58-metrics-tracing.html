Metrics & Tracing

Micrometer · MeterRegistry · Counter · Timer · @Observed · Prometheus endpoint · OpenTelemetry

Measuring the App

Boot instruments the app with Micrometer: HTTP requests, JVM, connection pools and caches are measured automatically. Add a registry (e.g. Prometheus) to export them. Record your own counters, timers and gauges with a MeterRegistry, or annotate code with @Observed to get a metric *and* a trace span. Tracing exports to OpenTelemetry.

Notes

  • Prometheus: add micrometer-registry-prometheus
  • Tracing: spring-boot-starter-opentelemetry (Boot 4)
  • Trace and span ids are added to log lines automatically
  • Tag cardinality must stay low: no user ids in tags

Custom Metrics

@Service
class CheckoutService {
    private final Counter orders;
    private final Timer payment;

    CheckoutService(MeterRegistry registry) {
        this.orders = Counter.builder("shop.orders")
            .tag("channel", "web").register(registry);
        this.payment = registry.timer("shop.payment.time");
        Gauge.builder("shop.cart.open", carts, CartStore::size).register(registry);
    }

    void checkout(Cart cart) {
        payment.record(() -> gateway.charge(cart));
        orders.increment();
    }

    @Observed(name = "shop.lookup")              // metric + span
    Product lookup(String sku) { … }
}

application.yml

management:
  endpoints.web.exposure.include: prometheus
  tracing.sampling.probability: 0.1     # trace 10% of requests

Code Explained

Meter names use dots; Prometheus shows shop_orders_total
timer.record(…) times the lambda
Gauges sample a value when scraped
Turn @Observed on with …observations.annotations.enabled

⚠ Common Mistakes

  • Tagging with unbounded values (user id, URL with ids); memory explodes
  • Sampling 100% of traces in production
  • Creating meters inside hot methods instead of once

✓ Tips & Best Practices

  • Tag all meters with the app name via …metrics.tags.application
  • Use Grafana dashboards for JVM and HTTP metrics
  • Prefer @Observed / Observation for code you want traced
