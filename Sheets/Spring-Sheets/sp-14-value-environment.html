Sheet 14

@Value & Environment

@Value("${...}") · default values · SpEL #{} · Environment · getProperty() · @PropertySource

Reading Single Values

@Value injects one property into a field or constructor parameter, with an optional default after a colon. It also evaluates SpEL expressions in #{...}. For lookups at runtime, inject the Environment. For more than two or three related values, switch to @ConfigurationProperties (Sheet 15).

Notes

  • ${...} = property placeholder; #{...} = SpEL expression
  • Missing key with no default → startup fails
  • @Value works on constructor parameters too (best for testing)
  • @PropertySource adds .properties files (not YAML)

@Value and Environment

@Service
class MailService {
    private final String from;
    private final int retries;
    private final List<String> admins;
    private final Environment env;

    MailService(@Value("${mail.from}") String from,
                @Value("${mail.retries:3}") int retries,          // default 3
                @Value("${mail.admins}") List<String> admins,     // a,b,c
                Environment env) {
        this.from = from; this.retries = retries;
        this.admins = admins; this.env = env;
    }

    boolean sandbox() {
        return env.getProperty("mail.sandbox", Boolean.class, false);
    }
    boolean isProd() { return env.matchesProfiles("prod"); }
}

@Value("#{T(java.lang.Math).random() * 100}") double roll;  // SpEL
@Value("${app.timeout:PT30S}") Duration timeout;            // converted

Code Explained

${mail.retries:3} → 3 when the key is absent
Comma-separated values convert to List or arrays
env.getProperty(key, type, default) reads and converts at runtime
Duration, DataSize, enums and Path convert automatically

⚠ Common Mistakes

  • @Value on a static field; Spring never sets it
  • Writing @Value("mail.from") without ${}; you get the literal text
  • Using @Value in a class created with new; nothing is injected

✓ Tips & Best Practices

  • Group related keys into @ConfigurationProperties instead of many @Values
  • Give defaults for optional keys so local runs need no config
  • Use Environment only when the key isn't known until runtime

Quick Summary

  • @Value("${k:default}"): one value
  • #{...}: SpEL expression
  • Environment.getProperty(): runtime
  • @PropertySource: extra files
