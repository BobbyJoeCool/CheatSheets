Building Responses

ResponseEntity · @ResponseStatus · HttpStatus · headers · ResponseEntity.created() · noContent()

Controlling the Response

Returning an object gives 200 OK with a JSON body. When you need a different status, headers or an empty body, return ResponseEntity<T>, built with static factories such as ok(), created(uri), noContent() and notFound(). For a fixed status on every success, @ResponseStatus on the method is shorter.

Notes

  • ResponseEntity<Void> for responses with no body
  • created(uri) sets status 201 and the Location header
  • ResponseEntity.of(optional) → 200 with body or 404
  • Errors are better handled centrally (Sheet 24)

ResponseEntity Builders

@GetMapping("/{id}")
ResponseEntity<Order> get(@PathVariable long id) {
    return ResponseEntity.of(repo.findById(id));            // 200 or 404
}

@PostMapping
ResponseEntity<Order> create(@RequestBody NewOrder body, UriComponentsBuilder ucb) {
    Order saved = service.create(body);
    URI location = ucb.path("/api/orders/{id}").build(saved.id());
    return ResponseEntity.created(location).body(saved);    // 201 + Location
}

@DeleteMapping("/{id}")
ResponseEntity<Void> delete(@PathVariable long id) {
    return service.delete(id) ? ResponseEntity.noContent().build()   // 204
                              : ResponseEntity.notFound().build();   // 404
}

@GetMapping(value = "/{id}/invoice", produces = MediaType.APPLICATION_PDF_VALUE)
ResponseEntity<byte[]> invoice(@PathVariable long id) {
    return ResponseEntity.ok()
        .header(HttpHeaders.CONTENT_DISPOSITION, "attachment; filename=inv.pdf")
        .cacheControl(CacheControl.noStore())
        .body(pdf.render(id));
}

Code Explained

UriComponentsBuilder is pre-filled with the request's host and port
.build() ends a builder with no body
header(...) / cacheControl(...) set response headers
byte[] with produces streams a file download

⚠ Common Mistakes

  • Returning null for "not found"; the client gets 200 with an empty body
  • Building Location from a hard-coded host; use UriComponentsBuilder
  • Wrapping every method in ResponseEntity even when status is always 200

✓ Tips & Best Practices

  • Use ResponseEntity.of(Optional) for simple lookups
  • Throw a custom exception for errors and map it once (Sheet 24)
  • Use HttpStatus constants, not raw numbers

Quick Summary

  • ResponseEntity<T>: status + headers + body
  • created(uri): 201 with Location
  • noContent() / notFound(): no body
  • @ResponseStatus: fixed status
