Filters, Interceptors & CORS

OncePerRequestFilter · HandlerInterceptor · preHandle() · WebMvcConfigurer · @CrossOrigin · addCorsMappings()

Code Around Every Request

A servlet Filter wraps the whole request, before Spring MVC sees it; extend OncePerRequestFilter and make it a bean. A HandlerInterceptor runs inside MVC, around the chosen controller method. CORS lets browsers on other origins call your API; configure it per controller with @CrossOrigin or globally in a WebMvcConfigurer.

Notes

  • Order: filters → DispatcherServlet → interceptors → controller
  • Spring Security is itself a filter chain (Sheet 45)
  • Filter beans apply to all URLs unless registered with patterns

Filter, Interceptor and CORS

@Component
class RequestIdFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest req,
            HttpServletResponse res, FilterChain chain)
            throws ServletException, IOException {
        res.setHeader("X-Request-Id", UUID.randomUUID().toString());
        chain.doFilter(req, res);                 // continue the chain
    }
}

class AuthInterceptor implements HandlerInterceptor {
    public boolean preHandle(HttpServletRequest q, HttpServletResponse s,
                             Object handler) {
        return q.getHeader("X-Api-Key") != null;   // false = stop here
    }
}

@Configuration
class WebConfig implements WebMvcConfigurer {
    public void addInterceptors(InterceptorRegistry r) {
        r.addInterceptor(new AuthInterceptor()).addPathPatterns("/api/**");
    }
    public void addCorsMappings(CorsRegistry r) {
        r.addMapping("/api/**").allowedOrigins("https://app.example.com")
         .allowedMethods("GET", "POST", "PUT", "DELETE");
    }
}

Code Explained

OncePerRequestFilter runs once even on forwards and error dispatches
Forgetting chain.doFilter() ends the request silently
preHandle returning false skips the controller
CORS answers browser preflight OPTIONS requests

⚠ Common Mistakes

  • allowedOrigins("*") with allowCredentials(true); browsers reject it
  • CORS set in MVC only, while Spring Security blocks the preflight; add http.cors()
  • Reading the request body in a filter; the controller then gets nothing

✓ Tips & Best Practices

  • Use FilterRegistrationBean to limit a filter to URL patterns or set its order
  • Put logging/tracing in filters; handler-aware logic in interceptors
  • Use @CrossOrigin only for one-off controllers; prefer global config

Quick Summary

  • OncePerRequestFilter: servlet level
  • HandlerInterceptor: around handlers
  • addCorsMappings(): global CORS
  • @CrossOrigin: per controller
