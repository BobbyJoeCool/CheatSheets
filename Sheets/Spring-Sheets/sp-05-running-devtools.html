Sheet 05

Running, Building & DevTools

mvnw spring-boot:run · gradlew bootRun · executable jar · spring-boot-devtools · auto-restart · LiveReload

Run, Package, Repeat

In development run with spring-boot:run or bootRun. For deployment, package / bootJar builds an executable fat jar with your code, all dependencies and the embedded server; run it with java -jar. DevTools restarts the app when compiled classes change.

Notes

  • DevTools restarts fast because it reloads only your classes
  • DevTools turns itself off under java -jar
  • Templates and static files refresh without a restart
  • docker-compose starter starts compose.yaml services

Run & Build

./mvnw spring-boot:run                     # dev run
./mvnw spring-boot:run -Dspring-boot.run.profiles=local
./mvnw clean package                       # target/demo-0.0.1.jar
./mvnw package -DskipTests

./gradlew bootRun --args='--server.port=9090'
./gradlew bootJar                          # build/libs/demo-0.0.1.jar

java -jar demo.jar --spring.profiles.active=prod
SERVER_PORT=8081 java -jar demo.jar        # env var override

DevTools (Maven)

<artifactId>spring-boot-devtools</artifactId>
<scope>runtime</scope> <optional>true</optional>

Code Explained

--name=value arguments override every other property source
-Dspring-boot.run.profiles is a Maven plugin flag
package runs tests first; avoid -DskipTests in CI
Gradle: developmentOnly("…:spring-boot-devtools")
optional keeps DevTools out of the packaged jar

⚠ Common Mistakes

  • Expecting DevTools to restart on edit; the IDE must compile first
  • Shipping DevTools by leaving out optional / developmentOnly
  • Running Gradle's -plain.jar; it has no dependencies inside

✓ Tips & Best Practices

  • Add spring-boot-docker-compose and Postgres starts with the app
  • Pass config at deploy time with env vars like SERVER_PORT
  • Set the jar name with <finalName> or archiveFileName

Quick Summary

  • bootRun / spring-boot:run: dev
  • bootJar / package: fat jar
  • java -jar app.jar --k=v: run
  • DevTools: restart on compile
