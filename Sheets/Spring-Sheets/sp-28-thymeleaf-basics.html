Server-Rendered HTML

For server-side HTML, use a plain @Controller (not @RestController): the method adds data to the Model and returns a view name, which Boot resolves to templates/{name}.html and renders with Thymeleaf. Thymeleaf templates are valid HTML; dynamic parts live in th:* attributes, so files open fine in a browser.

Notes

  • Add spring-boot-starter-thymeleaf
  • ${...} reads model attributes; @{...} builds URLs
  • th:text escapes HTML; th:utext doesn't
  • DevTools disables the template cache for live reload

Controller

@Controller
@RequestMapping("/products")
class ProductPageController {
    private final ProductService service;
    ProductPageController(ProductService s) { this.service = s; }

    @GetMapping
    String list(Model model) {
        model.addAttribute("products", service.findAll());
        return "products/list";              // templates/products/list.html
    }
}

templates/products/list.html

<html xmlns:th="http://www.thymeleaf.org">
<body>
  <h1 th:text="${#lists.size(products)} + ' products'">0 products</h1>
  <p th:if="${products.isEmpty()}">Nothing here yet.</p>
  <ul>
    <li th:each="p, stat : ${products}" th:classappend="${stat.odd} ? 'odd'">
      <a th:href="@{/products/{id}(id=${p.id})}" th:text="${p.name}">Name</a>
      <span th:text="${#numbers.formatCurrency(p.price)}">$0.00</span>
    </li>
  </ul>
</body>
</html>

Code Explained

The return value is a view name, not a body
Placeholder text (Name) is replaced at render time
stat gives index, count, odd, first, last
@{/products/{id}(id=…)} fills the path variable

⚠ Common Mistakes

  • Using @RestController, which returns the string "products/list" as the body
  • A leading slash in the view name ("/products/list") breaks some setups
  • Using th:utext with user input; that's an XSS hole

✓ Tips & Best Practices

  • Share headers and footers with th:fragment + th:replace
  • Use #temporals for java.time values
  • Add htmx for interactivity without a SPA

Quick Summary

  • @Controller + Model: view data
  • Return view name → templates/
  • th:text, th:each, th:if
  • @{...}: URLs · ${...}: data
