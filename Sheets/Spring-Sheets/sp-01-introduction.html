What Spring Is

Spring Framework (2003) is a Java framework built on Inversion of Control: you write plain classes and a container creates and wires them. Spring Boot (2014) adds auto-configuration, starters and an embedded server, so an app runs from one main(). This set targets Boot 4.1 / Framework 7.0 on Java 17+.

Notes

  • Convention over configuration: defaults back off when you define your own
  • Framework = container, MVC, data access, AOP, test support
  • Boot = opinionated setup for Framework + other Spring projects
  • Packages are jakarta.*, not javax.*, since Boot 3
  • New Boot minor release every 6 months (May, November)

Hello, World — a Complete App

@SpringBootApplication            // config + auto-config + scanning
@RestController                   // methods return response bodies
public class DemoApplication {

    @GetMapping("/")              // GET http://localhost:8080/
    String hello() {
        return "Hello, World";    // -> Hello, World
    }

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

Run It

./mvnw spring-boot:run     # or: ./gradlew bootRun

Code Explained

@SpringBootApplication makes this class the configuration root
spring-boot-starter-webmvc on the classpath → embedded Tomcat
@RestController + @GetMapping map a request to a method
SpringApplication.run() builds the ApplicationContext
No XML, no web.xml, no external server to install

⚠ Common Mistakes

  • Treating Spring and Spring Boot as one thing; Boot configures Spring
  • Copying old tutorials that import javax.persistence; Boot 3+ needs jakarta
  • Calling new MyService(); the container never sees it, so nothing is injected

✓ Tips & Best Practices

  • Generate every project at start.spring.io
  • Check the Boot version first when reading answers online; 2.x, 3.x and 4.x differ
  • Run once with --debug to see which auto-configs applied

Quick Summary

  • Spring Framework: IoC container + modules
  • Spring Boot: auto-config + starters
  • @SpringBootApplication: app root
  • SpringApplication.run(): starts it
