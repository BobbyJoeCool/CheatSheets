Cross-Cutting Concerns

Aspect-oriented programming moves code that cuts across many classes (logging, timing, security, transactions) into one aspect. Spring AOP works with proxies: callers get a proxy object that runs the advice and then calls the real bean. @Transactional, @Cacheable, @Async and method security are all built this way.

Notes

  • Spring AOP intercepts public method calls on beans only
  • Default proxy type in Boot: CGLIB subclass (even with interfaces)
  • final classes or methods can't be proxied by CGLIB
  • Full AspectJ (compile-time weaving) can do more but is rarely needed

Proxies and the Self-Invocation Trap

@Service
class OrderService {

    @Transactional
    public void placeOrder(Order o) { save(o); }

    public void importAll(List<Order> orders) {
        orders.forEach(this::placeOrder);    // ❌ this.placeOrder skips the proxy
    }                                        //    → no transaction!
}

@Service
class ImportService {
    private final OrderService orders;       // injected = the proxy
    ImportService(OrderService orders) { this.orders = orders; }

    public void importAll(List<Order> list) {
        list.forEach(orders::placeOrder);    // ✅ goes through the proxy
    }
}

Is It a Proxy?

AopUtils.isAopProxy(orderService);          // true
orderService.getClass();                    // OrderService$$SpringCGLIB$$0

Code Explained

Callers hold the proxy; this inside the bean is the target
Calls on this bypass all advice: transactions, caching, security
Fix: move the method to another bean and inject it
The CGLIB class name gives the proxy away in stack traces

⚠ Common Mistakes

  • Calling an annotated method on this and wondering why it has no effect
  • Putting @Transactional on private methods; proxies can't intercept them
  • Making a bean class final (or a Kotlin class without open)

✓ Tips & Best Practices

  • Annotate public service methods called from other beans
  • Split a bean when it needs to call its own advised method
  • Check AopUtils.isAopProxy() when an annotation seems ignored

Quick Summary

  • Aspect: cross-cutting module
  • Proxy: wraps the bean, runs advice
  • Self-invocation: bypasses the proxy
  • CGLIB: Boot's default proxy
