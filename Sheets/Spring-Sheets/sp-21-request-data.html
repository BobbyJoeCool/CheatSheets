Reading Request Data

@PathVariable · @RequestParam · @RequestBody · @RequestHeader · @CookieValue · @ModelAttribute · defaults

Getting Data Out of a Request

Handler method parameters declare what you need from the request: @PathVariable for URI segments, @RequestParam for query strings and form fields, @RequestBody for a JSON body, plus headers and cookies. Spring converts each value to the parameter's type and returns 400 Bad Request when a required value is missing or invalid.

Notes

  • @RequestParam is required by default; set required = false or a default
  • Use Optional<T> or @Nullable for optional values
  • A plain object parameter (no annotation) binds query params by name
  • @RequestBody uses Jackson; only one body per request

Every Kind of Input

@GetMapping("/products/{category}/{id}")
Product show(@PathVariable String category,                  // /products/books/7
             @PathVariable("id") long productId) { … }

@GetMapping("/products")                                     // ?q=lamp&page=2
Page<Product> search(@RequestParam String q,
                     @RequestParam(defaultValue = "0") int page,
                     @RequestParam Optional<String> sort,
                     @RequestParam List<String> tag) { … }   // ?tag=a&tag=b

@PostMapping("/products")
Product create(@RequestBody @Valid NewProduct body,          // JSON body
               @RequestHeader("X-Request-Id") String reqId,
               @CookieValue(name = "cart", required = false) String cart) { … }

record ProductFilter(String q, BigDecimal maxPrice, int page) { }

@GetMapping("/filter")                                       // ?q=x&maxPrice=20
List<Product> filter(ProductFilter f) { … }                  // binds by name

Code Explained

@PathVariable("id") maps a differently named segment
defaultValue implies required = false
Repeated params bind to List<String>
@Valid runs Bean Validation on the body (Sheet 23)
A record parameter is filled from matching query params

⚠ Common Mistakes

  • Primitive int for an optional param; missing → 400, use Integer or a default
  • Sending form data to a @RequestBody method; it expects JSON
  • Expecting @RequestParam Map to hold repeated values; use MultiValueMap

✓ Tips & Best Practices

  • Group many query params into a record parameter
  • Accept MultipartFile for uploads; set spring.servlet.multipart.max-file-size
  • Use @RequestHeader HttpHeaders headers to read them all

Quick Summary

  • @PathVariable: /items/{id}
  • @RequestParam: ?q=…
  • @RequestBody: JSON body
  • Record param: bind many query params
