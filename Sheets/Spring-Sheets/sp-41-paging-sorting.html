Paging & Sorting

Pageable · PageRequest.of() · Sort · Page<T> · Slice · Window / ScrollPosition · ?page=&size=&sort=

Paging Through Results

Pass a Pageable to a repository method and get a Page<T> (content + total count), a Slice<T> (content + has-next, no count) or a Window<T> for keyset scrolling. Build one with PageRequest.of(page, size, sort). In controllers, Spring binds ?page=&size=&sort= straight into a Pageable parameter.

Notes

  • Pages are zero-based: page=0 is the first page
  • Page runs an extra count(*) query; Slice doesn't
  • Keyset scrolling stays fast on deep pages
  • Cap page size with spring.data.web.pageable.max-page-size

Repository and Controller

interface ProductRepository extends JpaRepository<Product, Long> {
    Page<Product> findByCategory(String category, Pageable pageable);
    Slice<Product> findByActiveTrue(Pageable pageable);
    Window<Product> findTop20ByOrderByIdAsc(ScrollPosition position);
}

@GetMapping("/products")                    // ?page=2&size=20&sort=price,desc
PagedModel<Product> list(@RequestParam String category,
        @PageableDefault(size = 20, sort = "name") Pageable pageable) {
    return new PagedModel<>(repo.findByCategory(category, pageable));
}

// building one yourself
Pageable p = PageRequest.of(0, 50, Sort.by("price").descending()
                                        .and(Sort.by("name")));

// keyset scrolling
Window<Product> w = repo.findTop20ByOrderByIdAsc(ScrollPosition.keyset());
while (!w.isEmpty()) {
    w.forEach(this::export);
    if (!w.hasNext()) break;
    w = repo.findTop20ByOrderByIdAsc(w.positionAt(w.size() - 1));
}

Code Explained

@PageableDefault applies when the request has no params
PagedModel gives stable JSON instead of serializing PageImpl
Sort.by(…).descending().and(…) chains sort orders
positionAt() remembers where the last window ended

⚠ Common Mistakes

  • Assuming page=1 is the first page; it's the second
  • Returning Page<Entity> directly; JSON shape and lazy fields cause trouble
  • Deep offset pages on huge tables; use keyset scrolling

✓ Tips & Best Practices

  • Use Slice for infinite scroll; skip the count query
  • Set spring.data.web.pageable.one-indexed-parameters=true for 1-based APIs
  • Map pages to DTOs: page.map(ProductView::from)

Quick Summary

  • Pageable param → Page<T>
  • PageRequest.of(page, size, sort)
  • Slice: no count query
  • Window + ScrollPosition: keyset
