MockMvc & RestTestClient

MockMvcTester · perform() · assertThat().hasStatusOk() · jsonPath · RestTestClient · bindTo… · expectStatus()

Testing HTTP Endpoints

MockMvcTester (Framework 6.2+) tests Spring MVC without a server, using AssertJ: assertThat(mvc.get().uri("/x")).hasStatusOk(). RestTestClient (Framework 7) offers a fluent expectStatus() / expectBody() API and can target MockMvc, a single controller or a real running server. Both check status, headers and JSON bodies.

Notes

  • MockMvcTester replaces the older MockMvc + ResultMatchers style
  • bodyJson() supports JSON paths and comparisons
  • RestTestClient.bindToController() needs no Spring context
  • .body(obj) serializes with Jackson

MockMvcTester (AssertJ)

assertThat(mvc.post().uri("/api/orders")
        .contentType(MediaType.APPLICATION_JSON)
        .content("{\"item\":\"book\",\"qty\":2}"))
    .hasStatus(HttpStatus.CREATED)
    .hasHeader("Location", "/api/orders/1")
    .bodyJson().extractingPath("$.qty").isEqualTo(2);

assertThat(mvc.get().uri("/api/orders/99"))
    .hasStatus(HttpStatus.NOT_FOUND)
    .bodyJson().extractingPath("$.title").isEqualTo("Order not found");

RestTestClient

RestTestClient client = RestTestClient
    .bindToController(new OrderController(fakeService)).build();

client.get().uri("/api/orders/7")
    .exchange()
    .expectStatus().isOk()
    .expectBody()
    .jsonPath("$.item").isEqualTo("book");

Order o = client.get().uri("/api/orders/7").exchange()
    .expectBody(Order.class).returnResult().getResponseBody();

Code Explained

mvc is injected in @WebMvcTest or with @AutoConfigureMockMvc
Error bodies can be checked against ProblemDetail fields
bindToController tests one controller in plain JUnit
returnResult() exits the chain for custom assertions

⚠ Common Mistakes

  • Mixing old andExpect(status().isOk()) style with AssertJ; pick one
  • Testing JSON as an exact string; field order and spacing break it
  • Using bindToServer without RANDOM_PORT; nothing is listening

✓ Tips & Best Practices

  • bodyJson().isLenientlyEqualTo(json) ignores order and extra fields
  • Prefer RestTestClient in RANDOM_PORT tests over TestRestTemplate
  • Name tests after behavior: returns404ForUnknownOrder

Quick Summary

  • MockMvcTester: AssertJ MVC tests
  • RestTestClient: fluent client tests
  • bodyJson() / jsonPath()
  • bindToController: no context
