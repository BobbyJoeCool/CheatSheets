Protecting APIs with JWTs

As an OAuth2 resource server, your API accepts bearer tokens (usually JWTs) issued by an authorization server such as Keycloak, Auth0, Okta or Spring Authorization Server. Set the issuer-uri and Boot fetches the signing keys, validates each token's signature, expiry and issuer, and turns its scopes into authorities.

Notes

  • Add spring-boot-starter-security-oauth2-resource-server
  • Scopes become SCOPE_read, SCOPE_write authorities
  • The token's sub claim becomes authentication.getName()
  • No sessions: every request carries its own token

Resource Server Setup

@Bean
SecurityFilterChain api(HttpSecurity http) throws Exception {
    http
        .authorizeHttpRequests(a -> a
            .requestMatchers(GET, "/api/**").hasAuthority("SCOPE_read")
            .requestMatchers("/api/**").hasAuthority("SCOPE_write")
            .anyRequest().authenticated())
        .oauth2ResourceServer(o -> o.jwt(Customizer.withDefaults()))
        .sessionManagement(s -> s.sessionCreationPolicy(STATELESS));
    return http.build();
}

@GetMapping("/api/me")
Map<String, Object> me(@AuthenticationPrincipal Jwt jwt) {
    return Map.of("sub", jwt.getSubject(),
                  "email", jwt.getClaimAsString("email"));
}

application.yml

spring.security.oauth2.resourceserver.jwt:
  issuer-uri: https://auth.example.com/realms/shop
  audiences: shop-api

Code Explained

Boot reads /.well-known/openid-configuration from the issuer
audiences rejects tokens meant for other APIs
@AuthenticationPrincipal Jwt gives access to every claim
Map a roles claim with a JwtAuthenticationConverter bean

⚠ Common Mistakes

  • Validating JWTs by hand instead of using the resource server support
  • Putting sensitive data in JWT claims; anyone can decode them
  • Accepting any audience, so tokens for other apps work on yours

✓ Tips & Best Practices

  • Use opaque tokens (opaquetoken) when you need instant revocation
  • Test with jwt() from spring-security-test (Sheet 55)
  • Run Keycloak in Docker Compose for local development
