Shipping the App

The Boot plugin builds an executable jar you run with java -jar. For containers, build-image / bootBuildImage creates an OCI image with Cloud Native Buildpacks (no Dockerfile needed), or you write a Dockerfile that uses Boot's layered jar so dependency layers are cached between builds. Shutdown is graceful by default: in-flight requests finish first.

Notes

  • Configure via env vars: SPRING_PROFILES_ACTIVE, SERVER_PORT
  • Buildpacks pick a JRE and tune memory for the container
  • Layers: dependencies → loader → snapshot deps → application
  • server.shutdown=immediate turns graceful shutdown off

Build Commands

./mvnw spring-boot:build-image -Dspring-boot.build-image.imageName=shop:1.4
./gradlew bootBuildImage --imageName=shop:1.4
docker run -p 8080:8080 -e SPRING_PROFILES_ACTIVE=prod shop:1.4

Dockerfile with Layers

FROM eclipse-temurin:25-jre AS build
WORKDIR /app
COPY target/shop.jar app.jar
RUN java -Djarmode=tools -jar app.jar extract --layers --launcher

FROM eclipse-temurin:25-jre
WORKDIR /app
COPY --from=build /app/app/dependencies/ ./
COPY --from=build /app/app/spring-boot-loader/ ./
COPY --from=build /app/app/snapshot-dependencies/ ./
COPY --from=build /app/app/application/ ./
ENTRYPOINT ["java", "org.springframework.boot.loader.launch.JarLauncher"]

Code Explained

imageName tags the image; push it to any registry
extract --layers splits the jar into cacheable folders
Code changes rebuild only the small application layer
JarLauncher starts the app from the extracted layout

⚠ Common Mistakes

  • Fixed -Xmx larger than the container limit; the pod gets OOM-killed
  • Copying the fat jar as a single layer; every build re-uploads everything
  • Baking secrets into the image instead of injecting env vars

✓ Tips & Best Practices

  • Use buildpacks unless you need full control of the Dockerfile
  • Run as a non-root user in custom images
  • Use CDS or AOT cache (Java 25) to cut startup time

Quick Summary

  • java -jar: run anywhere
  • bootBuildImage: OCI image
  • extract --layers: Docker caching
  • Graceful shutdown by default
