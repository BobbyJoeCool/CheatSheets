spring.datasource.url · username / password · HikariCP · H2 console · PostgreSQL / MySQL drivers · connection pool settings

Connecting to a Database

Add a JDBC starter (jdbc or data-jpa) plus a driver, set spring.datasource.url, username and password, and Boot creates a pooled DataSource using HikariCP. With an embedded database such as H2 on the classpath and no URL, Boot starts an in-memory database for you. Docker Compose or Testcontainers can provide a real database without manual setup.

Notes

  • The driver class is detected from the URL
  • Pool settings live under spring.datasource.hikari.*
  • Keep credentials in env vars: SPRING_DATASOURCE_PASSWORD
  • @ServiceConnection fills the URL for Testcontainers (Sheet 56)

application.yml

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/shop
    username: shop
    password: ${DB_PASSWORD}
    hikari:
      maximum-pool-size: 10        # default 10
      minimum-idle: 2
      connection-timeout: 5s       # wait for a free connection
      max-lifetime: 30m

compose.yaml (with docker-compose starter)

services:
  postgres:
    image: postgres:17
    environment:
      POSTGRES_DB: shop
      POSTGRES_PASSWORD: secret

Driver

runtimeOnly("org.postgresql:postgresql")

Code Explained

Boot reads url, username, password to build the pool
Pool size: match DB limits ÷ number of app instances
With the compose starter, Boot starts the container and sets the URL
Drivers are runtimeOnly: your code uses only JDBC interfaces

⚠ Common Mistakes

  • A huge pool (100+); the database becomes the bottleneck
  • Testing only on H2 while production runs Postgres; SQL dialects differ
  • Committing the production password in application.yml

✓ Tips & Best Practices

  • Use Testcontainers or Docker Compose to develop against the real database
  • Watch pool metrics: hikaricp.connections.pending in Actuator
  • Set spring.datasource.hikari.pool-name for clearer logs

Quick Summary

  • spring.datasource.url: connect
  • HikariCP: default pool
  • Driver: runtimeOnly
  • Compose / Testcontainers: real DB
