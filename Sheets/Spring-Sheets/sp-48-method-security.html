Method Security

@EnableMethodSecurity · @PreAuthorize · @PostAuthorize · @Secured · SpEL expressions · authentication.name

Securing Methods

URL rules guard endpoints; method security guards business logic wherever it's called. Enable it with @EnableMethodSecurity, then annotate service methods with @PreAuthorize (check before running) or @PostAuthorize (check the return value). Expressions are SpEL and can use the method's arguments, the current authentication and your own beans.

Notes

  • Works through AOP proxies, like @Transactional
  • Denied calls throw AuthorizationDeniedException → 403
  • @Secured / @RolesAllowed are simpler, role-only options
  • @PostFilter removes items the user may not see

Rules on Service Methods

@Configuration
@EnableMethodSecurity
class MethodSecurityConfig { }

@Service
class DocumentService {

    @PreAuthorize("hasRole('ADMIN')")
    public void purge() { … }

    @PreAuthorize("#doc.ownerId == authentication.name")
    public void update(Document doc) { … }

    @PostAuthorize("returnObject.ownerId == authentication.name")
    public Document read(long id) { return repo.findById(id).orElseThrow(); }

    @PreAuthorize("@acl.canEdit(#id, authentication)")    // custom bean
    public void rename(long id, String name) { … }

    @PostFilter("filterObject.ownerId == authentication.name")
    public List<Document> mine() { return repo.findAll(); }
}

Code Explained

#doc refers to the method parameter named doc
returnObject is the value the method returned
@acl calls a bean named acl (your own @Component)
filterObject is each element of the returned list

⚠ Common Mistakes

  • Forgetting @EnableMethodSecurity; annotations are silently ignored
  • Calling a secured method from the same class; the proxy is bypassed
  • @PostAuthorize on methods with side effects; they already ran

✓ Tips & Best Practices

  • Create meta-annotations like @IsAdmin for repeated expressions
  • Move complex checks into a bean and call it with @bean.method()
  • Test with @WithMockUser(roles = "ADMIN") (Sheet 55)

Quick Summary

  • @EnableMethodSecurity: turn on
  • @PreAuthorize("…"): check first
  • @PostAuthorize: check result
  • #arg, authentication, @bean
