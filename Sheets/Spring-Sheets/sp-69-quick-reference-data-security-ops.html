⚠ Common Mistakes

  • N+1 selects from lazy relations in a loop — use fetch joins or @EntityGraph
  • @Transactional on a private method — it's ignored
  • Exposing every actuator endpoint publicly

✓ Tips & Best Practices

  • Prefer test slices (@WebMvcTest, @DataJpaTest) over full @SpringBootTest
  • Use Flyway or Liquibase, not ddl-auto=update, outside local dev
  • Turn on virtual threads for blocking web apps on Java 21+

Quick Summary

  • JpaRepository + derived queries cover most CRUD
  • @Transactional on public service methods
  • SecurityFilterChain bean configures access
  • Actuator, caching and scheduling are one annotation each
