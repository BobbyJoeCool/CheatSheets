Calling HTTP APIs

RestClient is Spring's synchronous HTTP client with a fluent API. Inject Boot's pre-configured RestClient.Builder, set a base URL and default headers, and build one client per remote service. Each call chains method → URI → headers/body → retrieve() → body(); 4xx/5xx responses throw unless handled by onStatus().

Notes

  • The builder is a prototype bean: each injection is a fresh copy
  • RestTemplate still works but is in maintenance mode
  • Global timeouts: spring.http.clients.connect-timeout / read-timeout

A Client for One Service

@Component
class GitHubClient {
    private final RestClient http;

    GitHubClient(RestClient.Builder builder) {
        this.http = builder.baseUrl("https://api.github.com")
            .defaultHeader(HttpHeaders.ACCEPT, "application/vnd.github+json")
            .build();
    }

    Repo repo(String owner, String name) {
        return http.get()
            .uri("/repos/{owner}/{name}", owner, name)       // URI vars
            .retrieve()
            .onStatus(s -> s.value() == 404,
                      (req, res) -> { throw new RepoNotFound(name); })
            .body(Repo.class);                             // JSON → record
    }

    ResponseEntity<Void> star(String owner, String name, String token) {
        return http.put().uri("/user/starred/{o}/{n}", owner, name)
            .headers(h -> h.setBearerAuth(token))
            .retrieve().toBodilessEntity();               // status only
    }
}

Code Explained

{owner} and {name} are filled and URL-encoded in order
onStatus maps a status to your own exception
body(Repo.class) reads JSON with Boot's JsonMapper

⚠ Common Mistakes

  • Building a new RestClient per call; build once and reuse (it's thread-safe)
  • Concatenating query strings by hand; use URI variables or uriBuilder
  • No timeouts set; a slow server can block request threads

✓ Tips & Best Practices

  • Use HTTP interface clients for many endpoints (Sheet 31)
  • Use builder.clone() to derive a second client from one builder
  • Log calls with a requestInterceptor

Quick Summary

  • RestClient.Builder: inject, then build
