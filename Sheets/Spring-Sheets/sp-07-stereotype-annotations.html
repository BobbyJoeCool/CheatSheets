Sheet 07

Stereotypes & Component Scanning

@Component · @Service · @Repository · @Controller · @ComponentScan · basePackages

Stereotypes

Mark a class with a stereotype and component scanning registers it as a bean. @Component is generic; @Service, @Repository and @Controller name the layer. @Repository also translates persistence exceptions into Spring's DataAccessException, and @RestController adds @ResponseBody to every method.

Notes

  • @Configuration is a @Component too, so it is scanned
  • Spring Data repository interfaces need no annotation
  • Override the name: @Service("billing")
  • Custom stereotype: meta-annotate with @Component

One Class per Layer

@RestController
@RequestMapping("/orders")
class OrderController {
    private final OrderService service;
    OrderController(OrderService service) { this.service = service; }

    @GetMapping("/{id}")
    Order get(@PathVariable long id) { return service.find(id); }
}

@Service
class OrderService {
    private final OrderRepository repo;
    OrderService(OrderRepository repo) { this.repo = repo; }
    Order find(long id) { return repo.findById(id).orElseThrow(); }
}

interface OrderRepository extends JpaRepository<Order, Long> { }

Code Explained

All three are found because they sit under the main class's package
A single constructor is injected automatically
Classes may be package-private; Spring doesn't need public
Spring Data generates the repository implementation

⚠ Common Mistakes

  • Putting @Service on an interface; annotate the implementation class
  • Two classes with the same simple name → ConflictingBeanDefinitionException
  • Annotating a class that a @Bean method also creates → two beans

✓ Tips & Best Practices

  • Use @Service / @Repository over @Component; they document intent
  • Keep controllers thin so logic is testable without HTTP
  • Use @Bean for library classes you can't annotate

Quick Summary

  • @Component: generic bean
  • @Service / @Repository: layers
  • @RestController: JSON controller
  • Scan root: main class's package
