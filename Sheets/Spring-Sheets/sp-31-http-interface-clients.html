HTTP Interface Clients

@HttpExchange · @GetExchange · @PostExchange · @ImportHttpServices · HttpServiceProxyFactory · service groups

Declarative HTTP Clients

An HTTP interface is a Java interface whose methods carry @GetExchange, @PostExchange and friends; Spring generates the implementation backed by RestClient. In Boot 4, @ImportHttpServices registers interfaces as beans in named groups, and each group is configured with spring.http.serviceclient.<group>.* properties.

Notes

  • Method parameters use the same annotations as controllers
  • Return types: the body, ResponseEntity<T>, or void
  • Errors throw RestClientResponseException subclasses
  • Works with WebClient too, returning Mono / Flux

Interface + Registration

@HttpExchange("/repos")
public interface RepoApi {

    @GetExchange("/{owner}/{repo}")
    Repo get(@PathVariable String owner, @PathVariable String repo);

    @GetExchange("/{owner}/{repo}/issues")
    List<Issue> issues(@PathVariable String owner, @PathVariable String repo,
                       @RequestParam(defaultValue = "open") String state);

    @PostExchange("/{owner}/{repo}/issues")
    Issue create(@PathVariable String owner, @PathVariable String repo,
                 @RequestBody NewIssue issue);
}

@SpringBootApplication
@ImportHttpServices(group = "github", types = RepoApi.class)
class App { }

Group Config

spring.http.serviceclient.github:
  base-url: https://api.github.com
  read-timeout: 5s

Code Explained

@HttpExchange on the type sets a shared path prefix
group = "github" links the interface to its config block
Inject RepoApi like any bean; there's no implementation class
Before Boot 4: build it with HttpServiceProxyFactory yourself

⚠ Common Mistakes

  • Annotating the interface with @Component; it's not a class Spring can build
  • Forgetting base-url, so relative paths have no host
  • Using controller annotations like @GetMapping instead of @GetExchange

✓ Tips & Best Practices

  • One group per remote service, with its own timeouts and headers
  • Customize a group in code with an HttpServiceGroupConfigurer bean
  • Test with MockRestServiceServer or WireMock

Quick Summary
