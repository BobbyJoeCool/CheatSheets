Advice & Pointcut Expressions

@Aspect · @Before · @AfterReturning · @Around · ProceedingJoinPoint · execution() · @annotation()

Writing an Aspect

An @Aspect class (also a @Component) holds advice methods. Each advice names a pointcut: an expression that selects methods by signature (execution(...)), by annotation (@annotation(...)) or by package (within(...)). @Around is the most flexible: it gets a ProceedingJoinPoint and decides when to call proceed().

Notes

  • Needs spring-boot-starter-aspectj (renamed from starter-aop in Boot 4)
  • Advice on the same join point is ordered with @Order on the aspect
  • Prefer annotation-based pointcuts; they're explicit
  • Always return the result of proceed() from @Around

Timing Every @Timed Method

@Aspect @Component
class TimingAspect {
    private static final Logger log = LoggerFactory.getLogger(TimingAspect.class);

    @Around("@annotation(com.example.Timed)")
    Object time(ProceedingJoinPoint pjp) throws Throwable {
        long start = System.nanoTime();
        try {
            return pjp.proceed();                       // call the real method
        } finally {
            long ms = (System.nanoTime() - start) / 1_000_000;
            log.info("{} took {} ms", pjp.getSignature().toShortString(), ms);
        }
    }

    @Pointcut("within(com.example..service..*)")
    void services() { }

    @AfterThrowing(pointcut = "services()", throwing = "ex")
    void logError(JoinPoint jp, Exception ex) { log.warn("{} failed", jp, ex); }
}

Code Explained

@annotation(...) matches methods carrying @Timed, a plain marker annotation
finally logs the time even when the method throws
@Pointcut names a reusable expression: services()
throwing = "ex" binds the exception to the parameter

⚠ Common Mistakes

  • Forgetting @Component on the aspect; it's never registered
  • Not returning pjp.proceed() in @Around, so callers get null
  • Over-broad execution(* *(..)) pointcuts that advise Spring's own beans

✓ Tips & Best Practices

  • Use a marker annotation (@Timed, @Audited) as the pointcut
  • Use Micrometer's @Observed for timing instead of hand-made aspects
  • Keep advice short; it runs on every matching call

Quick Summary

  • @Aspect @Component: the aspect
  • @Around + proceed(): wrap a call
  • @annotation(X): match by annotation
  • @Pointcut: reusable expression
