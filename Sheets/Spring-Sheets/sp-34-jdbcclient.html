Plain SQL with JdbcClient

JdbcClient (Framework 6.1+) is the modern, fluent way to run SQL without JPA: sql() → param() → query() / update(). It maps rows to records by column name and supports named or positional parameters. Boot auto-configures one when a DataSource exists; the older JdbcTemplate is still available.

Notes

  • Named params :id or positional ? — don't mix them
  • query(Class) maps snake_case columns to camelCase fields
  • Every call joins the current @Transactional transaction

Repository with JdbcClient

record Customer(long id, String name, String email) { }

@Repository
class CustomerDao {
    private final JdbcClient jdbc;
    CustomerDao(JdbcClient jdbc) { this.jdbc = jdbc; }

    Optional<Customer> find(long id) {
        return jdbc.sql("SELECT * FROM customer WHERE id = :id")
            .param("id", id)
            .query(Customer.class)                // row → record
            .optional();                          // 0 or 1 row
    }

    List<Customer> byName(String prefix) {
        return jdbc.sql("SELECT * FROM customer WHERE name LIKE ?")
            .param(prefix + "%").query(Customer.class).list();
    }

    long insert(String name, String email) {
        var keys = new GeneratedKeyHolder();
        jdbc.sql("INSERT INTO customer(name, email) VALUES (:n, :e)")
            .param("n", name).param("e", email)
            .update(keys, "id");                  // capture generated id
        return keys.getKey().longValue();
    }
}

Code Explained

optional() returns Optional.empty() for no row
single() throws if the row count isn't exactly 1
update() returns rows affected; with a KeyHolder it captures ids
query(Integer.class).single() reads a count(*)

⚠ Common Mistakes

  • String-concatenating values into SQL; always bind parameters
  • single() on a lookup that may find nothing; use optional()
  • Leaving a stream() open; wrap it in try-with-resources

✓ Tips & Best Practices

  • Use paramSource(record) to bind every field of an object at once
  • Keep SQL in text blocks (""") for readability
  • Use JdbcTemplate.batchUpdate() for large bulk inserts

Quick Summary

  • jdbc.sql(...).param(...)
  • .query(T.class).list() / optional()
  • .update(): insert / update / delete
  • DataAccessException: unchecked errors
