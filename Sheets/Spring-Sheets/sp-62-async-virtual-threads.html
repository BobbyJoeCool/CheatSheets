Async Work and Virtual Threads

@Async runs a method on a task executor instead of the caller's thread; it returns void or a CompletableFuture. Enable it with @EnableAsync. On Java 21+, setting spring.threads.virtual.enabled=true switches Tomcat, @Async, @Scheduled and other executors to virtual threads, so blocking code scales without reactive APIs.

Notes

  • Boot's executor is applicationTaskExecutor
  • @Async works through a proxy: no self-calls
  • Exceptions from void methods go to an AsyncUncaughtExceptionHandler
  • Security and MDC context don't cross threads by default

@Async and Futures

@Configuration
@EnableAsync
class AsyncConfig { }

@Service
class ReportService {

    @Async
    public CompletableFuture<Report> build(long id) {
        return CompletableFuture.completedFuture(generate(id));   // slow work
    }

    @Async
    public void emailLater(String to) { mail.send(to); }         // fire & forget
}

// caller: run three in parallel, then wait for all
var a = reports.build(1);
var b = reports.build(2);
var c = reports.build(3);
CompletableFuture.allOf(a, b, c).join();
List<Report> all = Stream.of(a, b, c).map(CompletableFuture::join).toList();

Turn On Virtual Threads

spring.threads.virtual.enabled=true     # Java 21+

Code Explained

Each build() call returns immediately with a future
allOf(...).join() waits until all three finish
Return CompletableFuture so callers see exceptions
With virtual threads, @Async uses a new virtual thread per task

⚠ Common Mistakes

  • Calling an @Async method from the same class; it runs synchronously
  • void async methods that fail silently; return a future or add a handler
  • Unlimited parallel calls to a downstream service on virtual threads

✓ Tips & Best Practices

  • Cap concurrency with @ConcurrencyLimit (Sheet 64)
  • Copy MDC/security context with a TaskDecorator
  • Use @Async("executorName") to pick a dedicated pool

Quick Summary

  • @EnableAsync + @Async
  • CompletableFuture<T>: async result
  • virtual.enabled=true: Java 21+
  • Proxy rules: no self-calls
