Test Slices

@WebMvcTest · @DataJpaTest · @JsonTest · @RestClientTest · @AutoConfigureMockMvc · @Import

Testing One Layer

Test slices start only the part of the app you're testing, so they're much faster than @SpringBootTest. @WebMvcTest loads controllers, advice, filters and JSON, but not services; @DataJpaTest loads JPA, repositories and an embedded database and rolls back each test. Mock what's outside the slice with @MockitoBean.

Notes

  • Boot 4: slices live in tech-specific test modules (-test starters)
  • @WebMvcTest(Controller.class) limits it to one controller
  • @DataJpaTest replaces your DataSource with an embedded DB

Web Slice

@WebMvcTest(OrderController.class)
class OrderControllerTests {

    @Autowired MockMvcTester mvc;
    @MockitoBean OrderService service;           // not in the slice → mock

    @Test void returnsOrder() {
        given(service.find(7)).willReturn(new Order(7, "book"));

        assertThat(mvc.get().uri("/api/orders/7"))
            .hasStatusOk()
            .bodyJson().extractingPath("$.item").isEqualTo("book");
    }
}

Data Slice

@DataJpaTest
class OrderRepositoryTests {
    @Autowired OrderRepository repo;

    @Test void findsByStatus() {
        repo.save(new Order("book", Status.NEW));
        assertThat(repo.findByStatus(Status.NEW)).hasSize(1);
    }                                            // rolled back afterwards
}

Code Explained

Only OrderController and MVC infrastructure are loaded
given(...) is BDD-style Mockito stubbing
TestEntityManager can also insert rows directly

⚠ Common Mistakes

  • Importing half the app into a slice; use @SpringBootTest instead
  • Expecting security to be off in @WebMvcTest; it's on (Sheet 55)
  • Trusting the embedded DB; keep the real one with replace = NONE

✓ Tips & Best Practices

  • Test controllers with slices, flows with one @SpringBootTest
  • Use @JsonTest + JacksonTester for tricky DTO serialization
  • Check which slice annotations your -test starter provides

Quick Summary
