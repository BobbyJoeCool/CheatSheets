Bean Validation

@Valid · @Validated · @NotNull · @NotBlank · @Size · @Email · BindingResult · MethodArgumentNotValidException

Validating Input

Add spring-boot-starter-validation and annotate fields with Jakarta Bean Validation constraints like @NotBlank, @Size and @Email. Put @Valid on a @RequestBody (or record parameter) and Spring validates it before your method runs; failures return 400 with field errors. Since Framework 6.1, constraints on @RequestParam and @PathVariable are checked too, with no extra setup.

Notes

  • Implementation is Hibernate Validator
  • @Valid also cascades into nested objects and list elements
  • null passes most constraints; add @NotNull when required
  • Messages can come from ValidationMessages.properties

Constraints on a Request DTO

record NewCustomer(
    @NotBlank @Size(max = 80)          String name,
    @NotBlank @Email                   String email,
    @Min(18) @Max(130)                 int age,
    @Pattern(regexp = "\\+?[0-9 ]{7,15}") String phone,
    @NotEmpty List<@Valid Address> addresses) { }

record Address(@NotBlank String street, @NotBlank String city) { }

@RestController                              // no @Validated needed (6.1+)
class CustomerController {

    @PostMapping("/customers")
    Customer create(@RequestBody @Valid NewCustomer body) { … }

    @GetMapping("/customers")
    List<Customer> page(@RequestParam @Min(1) @Max(100) int size) { … }
}

Custom Constraint

@Constraint(validatedBy = SkuValidator.class) @Target(FIELD) @Retention(RUNTIME)
@interface Sku { String message() default "bad SKU"; Class<?>[] groups() default {};
                 Class<? extends Payload>[] payload() default {}; }

Code Explained

Body failures throw MethodArgumentNotValidException → 400
Param failures throw HandlerMethodValidationException → 400
List<@Valid Address> validates every element
SkuValidator implements ConstraintValidator<Sku, String>

⚠ Common Mistakes

  • Annotating fields but forgetting @Valid on the parameter; nothing is checked
  • @Validated on a controller: errors become 500 ConstraintViolationException
  • Missing the validation starter; annotations compile but never run

✓ Tips & Best Practices

  • Validate DTOs at the edge, not JPA entities
  • Return field errors in a ProblemDetail (Sheet 24)
  • Validate config classes too: @Validated on @ConfigurationProperties

Quick Summary

  • starter-validation: enables it
  • @Valid @RequestBody: check body
  • Param constraints: checked (6.1+)
  • Fail → 400 with field errors
