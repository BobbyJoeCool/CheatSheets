JPA Entities

@Entity · @Table · @Id · @GeneratedValue · @Column · @Enumerated · @Embedded · equals/hashCode

Mapping Classes to Tables

A JPA entity is a class annotated with @Entity whose instances map to table rows. It needs an @Id, a no-arg constructor (can be protected) and non-final fields. Hibernate (version 7 in Boot 4) implements JPA: it generates SQL, tracks changes to loaded entities and writes them back when the transaction commits.

Notes

  • Packages are jakarta.persistence.*
  • Entities can't be records; use records for DTOs
  • Unannotated fields are mapped by default; @Transient skips one
  • Table/column names become snake_case by default

An Entity

@Entity
@Table(name = "customers")
public class Customer {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 80)
    private String name;
    @Column(unique = true)
    private String email;
    @Enumerated(EnumType.STRING)        // store "GOLD", not 2
    private Tier tier = Tier.BASIC;
    @Embedded
    private Address address;            // street, city columns inline
    @Version
    private int version;                // optimistic locking

    protected Customer() { }            // for JPA
    public Customer(String name, String email) { … }
}

@Embeddable
public record Address(String street, String city) { }

Code Explained

IDENTITY uses the database's auto-increment column
EnumType.STRING survives reordering the enum
@Embeddable (records allowed) adds columns to the same table
@Version makes concurrent updates fail instead of overwrite

⚠ Common Mistakes

  • equals/hashCode on all fields or on a null id; sets break after save
  • EnumType.ORDINAL (the default); reordering the enum corrupts data
  • Exposing entities in REST responses; lazy fields and cycles break JSON

✓ Tips & Best Practices

  • Base equals/hashCode on the id with a constant hash, or a natural key
  • Use SEQUENCE on Postgres so Hibernate can batch inserts
  • Keep entities in the domain layer; map to DTO records at the edges

Quick Summary

  • @Entity + @Id: a mapped table
  • protected no-arg constructor
  • EnumType.STRING: safe enums
  • @Version: optimistic locking
