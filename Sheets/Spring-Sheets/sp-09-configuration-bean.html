Sheet 09

@Configuration & @Bean

@Configuration · @Bean · method names as bean names · proxyBeanMethods · @Import · third-party beans

Java-Based Configuration

A @Configuration class holds @Bean methods: the return value becomes a bean and the parameters are injected. Use @Bean for classes you can't annotate (Clock, RestClient) or that need custom setup. In the default mode, calling one @Bean method from another returns the same singleton.

Notes

  • Bean name = method name; override with @Bean("name")
  • proxyBeanMethods = false skips the proxy ("lite mode")
  • @Import(Other.class) adds configs that aren't scanned
  • A public close() / shutdown() is called on exit

Defining Beans in Code

@Configuration(proxyBeanMethods = false)
@Import(CacheConfig.class)                     // pull in another config
class AppConfig {

    @Bean
    Clock clock() {                            // bean "clock"
        return Clock.systemUTC();
    }

    @Bean
    RestClient github(RestClient.Builder b) {  // Boot's builder injected
        return b.baseUrl("https://api.github.com").build();
    }

    @Bean(initMethod = "start", destroyMethod = "stop")
    MessagePump pump(Clock clock) {            // uses the bean above
        return new MessagePump(clock, Duration.ofSeconds(5));
    }
}

Code Explained

Lite mode: get dependencies via parameters, never by calling clock()
RestClient.Builder is pre-configured by Boot (Sheet 30)
initMethod / destroyMethod add lifecycle calls to plain classes
Your @Bean of a type Boot also defines replaces Boot's

⚠ Common Mistakes

  • Calling a @Bean method in lite mode and getting a second instance
  • Defining your own JsonMapper bean without realizing it replaces Boot's
  • Non-static @Bean for a BeanFactoryPostProcessor; it inits too early

✓ Tips & Best Practices

  • Use lite mode + parameter injection; Boot's own configs do
  • Prefer Boot's *Customizer beans to replacing a whole bean
  • One config class per feature (SecurityConfig, HttpConfig)

Quick Summary

  • @Configuration: bean definitions
  • @Bean: return value is a bean
  • Parameters: injected dependencies
  • proxyBeanMethods=false: lite mode
