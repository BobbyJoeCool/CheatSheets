JSON with Jackson 3

Spring MVC turns objects into JSON (and back) with Jackson. Boot 4 uses Jackson 3: the core classes moved to the tools.jackson package and the main type is JsonMapper, while the annotations kept their com.fasterxml.jackson.annotation package. Shape output with annotations on your DTOs and tune defaults with spring.jackson.* properties.

Notes

  • Records serialize out of the box: components become fields
  • java.time types are written as ISO-8601 strings
  • Customize the mapper with a JsonMapperBuilderCustomizer bean
  • @JsonComponent became @JacksonComponent in Boot 4

Shaping a DTO

import com.fasterxml.jackson.annotation.*;   // annotations: unchanged package

@JsonInclude(JsonInclude.Include.NON_NULL)   // drop null fields
record OrderView(
    long id,
    @JsonProperty("customer_name") String customerName,
    @JsonFormat(pattern = "yyyy-MM-dd") LocalDate placedOn,
    @JsonIgnore String internalNote,
    List<LineView> lines) { }

Using the Mapper Directly

import tools.jackson.databind.json.JsonMapper;   // Jackson 3 package

@Service
class Exporter {
    private final JsonMapper mapper;                 // Boot's configured mapper
    Exporter(JsonMapper mapper) { this.mapper = mapper; }

    String toJson(OrderView v) { return mapper.writeValueAsString(v); }
    OrderView read(String json) { return mapper.readValue(json, OrderView.class); }
}

Code Explained

JSON keys: id, customer_name, placedOn, lines
internalNote never appears in the JSON
Jackson 3 exceptions are unchecked: no throws needed
Tweak Boot's mapper with a JsonMapperBuilderCustomizer bean

⚠ Common Mistakes

  • Importing com.fasterxml.jackson.databind in Boot 4 code; it's Jackson 2
  • Defining your own ObjectMapper bean; Boot 4 configures a JsonMapper
  • Serializing entities with bidirectional relations → infinite recursion

✓ Tips & Best Practices

  • Use dedicated response records instead of annotating entities
  • Set spring.jackson.default-property-inclusion=non_null app-wide
  • Mid-migration? spring.jackson.use-jackson2-defaults=true keeps old output

Quick Summary

  • Boot 4: Jackson 3 (tools.jackson)
  • JsonMapper: inject to (de)serialize
  • Annotations: @JsonProperty, @JsonIgnore
  • *Customizer bean: tweak defaults
