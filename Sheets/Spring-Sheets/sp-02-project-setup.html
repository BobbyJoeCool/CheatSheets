Generating a Project

Start at start.spring.io (Spring Initializr), your IDE's new-project wizard, or curl. Pick Maven or Gradle, the Boot and Java versions and dependencies, and you get a working build, a wrapper script, a main class and a test. Versions come from the Boot BOM, so you rarely write one yourself.

Notes

  • The wrapper (./mvnw, ./gradlew) needs no global Maven/Gradle
  • Maven inherits from spring-boot-starter-parent
  • Gradle applies the org.springframework.boot plugin
  • Java 17 minimum; 21 or 25 (LTS) recommended

Maven: pom.xml (trimmed)

<parent>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-parent</artifactId>
  <version>4.1.0</version>         <!-- the only version you set -->
</parent>
<properties><java.version>21</java.version></properties>
<dependencies>
  <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-webmvc</artifactId>
  </dependency>
</dependencies>

Gradle: build.gradle.kts

plugins {
    java
    id("org.springframework.boot") version "4.1.0"
    id("io.spring.dependency-management") version "1.1.7"
}
java { toolchain { languageVersion = JavaLanguageVersion.of(21) } }
dependencies {
    implementation("org.springframework.boot:spring-boot-starter-webmvc")
}

Code Explained

The parent sets plugin config, encoding and the version BOM
Starters are listed without a version; the BOM supplies it
Gradle toolchain picks the JDK used to compile
The Boot plugin adds bootRun, bootJar, bootBuildImage
No parent allowed? Import spring-boot-dependencies as a BOM

⚠ Common Mistakes

  • Adding <version> to a starter; it overrides the BOM and mixes versions
  • Choosing a SNAPSHOT or milestone Boot version for real work
  • Using a global mvn instead of ./mvnw, so builds differ per machine

✓ Tips & Best Practices

  • Commit the wrapper files so CI uses the same build-tool version
  • Use Initializr's Explore button to preview the build file
  • Override one managed version with a property, e.g. <postgresql.version>

Quick Summary

  • start.spring.io: new project
  • starter-parent: BOM + plugins
  • Boot Gradle plugin: bootRun, bootJar
  • ./mvnw / ./gradlew: use the wrapper
