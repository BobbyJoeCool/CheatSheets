⚠ Common Mistakes

  • Field injection with @Autowired — hard to test; use constructor injection
  • Calling a @Transactional / @Async method from the same class — the proxy is bypassed
  • Forgetting @Valid — constraint annotations do nothing without it

✓ Tips & Best Practices

  • Group settings in @ConfigurationProperties records instead of many @Values
  • Return ProblemDetail from a @RestControllerAdvice for consistent errors
  • Use RestClient for new synchronous HTTP code

Quick Summary

  • Stereotypes + constructor injection wire the app
  • application.yml + profiles configure it
  • @RestController + @GetMapping + @RequestBody serve JSON
  • @RestControllerAdvice handles errors in one place
