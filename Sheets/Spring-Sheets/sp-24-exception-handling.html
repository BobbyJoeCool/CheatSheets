Exception Handling

@ExceptionHandler · @RestControllerAdvice · ProblemDetail · ErrorResponseException · ResponseStatusException · spring.mvc.problemdetails

Turning Exceptions into Responses

Handle errors in one place with a @RestControllerAdvice class whose @ExceptionHandler methods map exception types to responses. Spring supports RFC 9457 Problem Details: return a ProblemDetail and it's sent as application/problem+json. Set spring.mvc.problemdetails.enabled=true so Spring's own errors use the same format.

Notes

  • @ExceptionHandler in a controller applies to that controller only
  • Advice handlers apply to all controllers (narrow with basePackages)
  • Throw ResponseStatusException for quick one-off errors
  • Extend ResponseEntityExceptionHandler to customize Spring's built-in errors

Global Error Handling

@RestControllerAdvice
class ApiErrors {

    @ExceptionHandler(OrderNotFoundException.class)
    ProblemDetail notFound(OrderNotFoundException ex) {
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(
            HttpStatus.NOT_FOUND, ex.getMessage());
        pd.setTitle("Order not found");
        pd.setType(URI.create("https://shop.example.com/errors/not-found"));
        return pd;
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    ProblemDetail invalid(MethodArgumentNotValidException ex) {
        ProblemDetail pd = ProblemDetail.forStatus(HttpStatus.BAD_REQUEST);
        pd.setProperty("errors", ex.getFieldErrors().stream()
            .map(e -> e.getField() + ": " + e.getDefaultMessage()).toList());
        return pd;
    }
}

Code Explained

The status inside ProblemDetail becomes the response status
Body: type, title, status, detail, instance (request path)
setProperty() adds custom fields to the JSON
Validation handler lists every failing field

⚠ Common Mistakes

  • Catching exceptions in every controller method instead of one advice class
  • Leaking stack traces or SQL in detail; log them, return a safe message
  • A catch-all Exception handler that also swallows 404/405 from Spring

✓ Tips & Best Practices

  • Use stable type URIs so clients can switch on error kind
  • Extend ResponseEntityExceptionHandler to reformat Spring's errors
  • Log 5xx at ERROR, 4xx at DEBUG or WARN

Quick Summary

  • @RestControllerAdvice: global
  • @ExceptionHandler(X.class): map one
  • ProblemDetail: standard error JSON
  • problemdetails.enabled: built-ins too
