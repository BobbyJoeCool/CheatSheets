AssertJ

assertThat · isEqualTo · containsExactly · extracting · satisfies · assertThatThrownBy · SoftAssertions

Fluent Assertions That Read Like Sentences

AssertJ is the most popular assertion library for Java. assertThat(actual) returns a type-specific object whose methods your IDE autocompletes: strings get startsWith, lists get containsExactly, optionals get isPresent. Failure messages are detailed, and extracting pulls fields out of objects for compact collection checks. Spring Boot includes it.

Notes

  • import static org.assertj.core.api.Assertions.*
  • Chain several checks on one value
  • usingRecursiveComparison() compares objects field by field
  • Soft assertions collect all failures, like assertAll

In Spring Boot

  • MockMvcTester returns AssertJ-style assertions for HTTP responses (assertThat(mvc.get().uri("/x")).hasStatusOk())
  • JsonContent in @JsonTest supports extractingJsonPathStringValue
  • Boot's ApplicationContextRunner has AssertJ assertions for auto-configuration

Fluent Checks

import static org.assertj.core.api.Assertions.*;

@Test
void fluent() {
    assertThat(order.total()).isEqualTo(19.99).isPositive();
    assertThat(order.total()).isCloseTo(19.99, within(0.001));
    assertThat(order.reference()).startsWith("ORD-").hasSize(10);
    assertThat(order.lines())
        .hasSize(2)
        .extracting(Line::sku, Line::qty)
        .containsExactly(tuple("A1", 2), tuple("B2", 1));
    assertThat(order.tags()).containsExactlyInAnyOrder("gift", "rush");
    assertThat(order.paidAt()).isEmpty();                      // Optional
    assertThat(order).usingRecursiveComparison()
        .ignoringFields("id", "createdAt")
        .isEqualTo(expectedOrder);
    assertThat(order.customer()).satisfies(c -> {
        assertThat(c.name()).isEqualTo("Ann");
        assertThat(c.email()).contains("@");
    });
}

@Test
void exceptions() {
    assertThatThrownBy(() -> cart.add("A1", 0))
        .isInstanceOf(IllegalArgumentException.class)
        .hasMessageContaining("qty");
    assertThatExceptionOfType(OrderNotFoundException.class)
        .isThrownBy(() -> service.find(99));
}

Code Explained

extracting + tuple checks several fields of every element in one line
usingRecursiveComparison with ignoringFields skips generated values
satisfies groups checks about one nested object

JUnit 4 / TestNG Equivalent

  • JUnit 4 Hamcrest assertThat(x, is(equalTo(y))); AssertJ works with JUnit 4 too
  • TestNG TestNG users also use AssertJ; SoftAssert is TestNG's built-in version

Prefer / Avoid

  • assertEquals(2, list.size()) → assertThat(list).hasSize(2)
  • loops of asserts over a list → extracting(...).containsExactly(...)
  • overriding equals just for tests → usingRecursiveComparison()

⚠ Common Mistakes

  • Forgetting to call a terminal check: assertThat(x); alone asserts nothing
  • Mixing JUnit's assertEquals and AssertJ in confusing ways in one test
  • Using contains when order matters (containsExactly)

✓ Tips & Best Practices

  • Let autocomplete guide you after assertThat(…).
  • Use as("description") before a check to label it in failures
  • Turn on AssertJ's IntelliJ / Sonar rules to catch assertions with no check

Quick Summary

  • assertThat(actual) — fluent, typed
  • extracting + containsExactly — collections
  • usingRecursiveComparison — objects
  • assertThatThrownBy / soft assertions
