Sheet 12

Method Sources & Argument Providers

@MethodSource · Stream<Arguments> · @FieldSource · ArgumentsProvider · ArgumentsAccessor · @AggregateWith · converters

Arguments From Code

When cases need real objects, supply them from code. @MethodSource names a static factory method returning a Stream of Arguments; @FieldSource reads a static field. A custom ArgumentsProvider can be shared across classes. On the receiving side, ArgumentsAccessor and @AggregateWith turn many arguments into one object.

Notes

  • Without a name, @MethodSource looks for a method with the test's name
  • Factory methods are static unless PER_CLASS
  • Arguments.of(...) / static arguments(...)
  • External methods: @MethodSource("shop.Cases#orders")

Code-Supplied Cases

import static org.junit.jupiter.params.provider.Arguments.arguments;

@ParameterizedTest
@MethodSource("discountCases")
void discounts(Cart cart, double rate, double expected) {
    assertEquals(expected, cart.total(rate), 0.001);
}

static Stream<Arguments> discountCases() {
    return Stream.of(
        arguments(cartOf(10, 10), 0.25, 15.0),
        arguments(cartOf(), 0.50, 0.0),
        arguments(cartOf(99.99), 0.0, 99.99));
}

static final List<String> RESERVED = List.of("admin", "root");
@ParameterizedTest @FieldSource("RESERVED")
void reservedNames(String name) { assertFalse(Usernames.isAvailable(name)); }

@ParameterizedTest
@ArgumentsSource(CountryRatesProvider.class)
void rates(String country, double rate) { }

class CountryRatesProvider implements ArgumentsProvider {
    public Stream<? extends Arguments> provideArguments(ParameterDeclarations p, ExtensionContext c) {
        return Tax.table().entrySet().stream().map(e -> arguments(e.getKey(), e.getValue()));
    }
}

@ParameterizedTest
@CsvSource({"Ann, Smith, 34", "Bo, Li, 27"})
void people(@AggregateWith(PersonAggregator.class) Person p) { assertTrue(p.age() > 0); }

Code Explained

Each arguments(...) becomes one invocation
@FieldSource (5.11+) reads a List, array or Supplier field
An ArgumentsProvider can compute cases from anywhere and be reused
@AggregateWith builds one parameter from several CSV columns

JUnit 4 / TestNG Equivalent

  • JUnit 4 @Parameters static method returning Collection<Object[]>
  • TestNG @DataProvider(name = "…") returning Object[][] or an Iterator

Prefer / Avoid

  • Object[][] arrays → Stream<Arguments>
  • the same provider copied between classes → an ArgumentsProvider or external @MethodSource
  • eight parameters → @AggregateWith into a record

⚠ Common Mistakes

  • Non-static factory methods without PER_CLASS
  • Building expensive objects for every case when only some need them
  • Factory method names that drift from the annotation string (rename refactors miss them)

✓ Tips & Best Practices

  • Name factory methods after what they supply (discountCases)
  • Use records with @AggregateWith for wide rows
  • Keep shared case providers in a test/…/Cases class

Quick Summary

  • @MethodSource — Stream<Arguments>
  • @FieldSource — a static field
  • ArgumentsProvider — reusable
  • @AggregateWith — many columns → one object
