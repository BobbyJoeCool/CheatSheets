Sheet 11

Parameterized Tests — Sources

@ParameterizedTest · @ValueSource · @CsvSource · @CsvFileSource · @EnumSource · @NullAndEmptySource · name = patterns

One Method, Many Inputs

@ParameterizedTest runs a method once per set of arguments supplied by a source annotation: literal values, CSV rows, a CSV file, enum constants, or null and empty values. JUnit converts strings to the parameter types (numbers, enums, dates). Each invocation appears separately in the report, named by the name pattern.

Notes

  • Needs junit-jupiter-params (included in junit-jupiter)
  • Combine sources: @NullAndEmptySource + @ValueSource
  • Text blocks make @CsvSource tables readable
  • @ParameterizedClass (5.13+) parameterizes a whole class

In Spring Boot

  • Parameterized tests work in @SpringBootTest classes; the context is created once and reused for every invocation
  • Injected beans (@Autowired) and parameters can be mixed: sources first, then resolved parameters

Sources

@ParameterizedTest
@ValueSource(strings = {"A1", "B22", "C333"})
void validSkus(String sku) { assertTrue(Sku.isValid(sku)); }

@ParameterizedTest(name = "{0} + {1} = {2}")
@CsvSource({
    "1, 2, 3",
    "10, -4, 6",
    "'1,000', 1, 1001",            // quotes protect the comma
})
void adds(String a, int b, int expected) { /* … */ }

@ParameterizedTest
@CsvSource(useHeadersInDisplayName = true, textBlock = """
    country, rate
    US,      0.07
    DE,      0.19
    """)
void taxRates(String country, double rate) {
    assertEquals(rate, Tax.rate(country), 1e-9);
}

@ParameterizedTest
@CsvFileSource(resources = "/prices.csv", numLinesToSkip = 1)
void fromFile(String sku, BigDecimal price) { }

@ParameterizedTest
@EnumSource(value = Status.class, names = {"PAID", "SHIPPED"})
void finalStates(Status s) { assertTrue(s.isFinal()); }

@ParameterizedTest
@NullAndEmptySource
@ValueSource(strings = {"  ", "\t"})
void blankNames(String name) { assertThrows(IllegalArgumentException.class, () -> new User(name)); }

Code Explained

{0}, {1} in name insert arguments; {index} the invocation number
Strings convert to int, double, BigDecimal, enums and java.time types automatically
textBlock with headers reads like a table
@NullAndEmptySource adds null and "" to the other values

JUnit 4 / TestNG Equivalent

  • JUnit 4 @RunWith(Parameterized.class) with a constructor and @Parameters method (class-level)
  • TestNG @DataProvider method + @Test(dataProvider = "…")

Prefer / Avoid

  • loops of asserts over cases → @ParameterizedTest
  • copy-pasted tests differing by one value → one parameterized test
  • unreadable report names → name = "…" pattern

⚠ Common Mistakes

  • Unquoted commas in @CsvSource values splitting a value in two
  • Forgetting that blank CSV cells become null
  • Very long CSV tables in annotations; move them to @CsvFileSource

✓ Tips & Best Practices

  • Use textBlock CSV for anything with more than a few rows
  • Give each invocation a readable name
  • Put the expected value in each row

Quick Summary

  • @ParameterizedTest + a source
  • @CsvSource / textBlock — tables
  • @EnumSource / @NullAndEmptySource
  • name = "…" — readable reports
