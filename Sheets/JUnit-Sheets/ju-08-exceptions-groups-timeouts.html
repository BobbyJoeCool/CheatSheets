Sheet 08

Exceptions, Grouped Assertions & Timeouts

assertThrows · assertThrowsExactly · assertDoesNotThrow · assertAll · assertTimeout · assertTimeoutPreemptively · @Timeout

Errors, Several Checks at Once, and Time

assertThrows passes if the lambda throws the given type (or a subclass) and returns the exception so you can check its message. assertAll runs several assertions and reports every failure together instead of stopping at the first. assertTimeout and @Timeout fail tests that run too long.

Notes

  • assertThrowsExactly rejects subclasses
  • assertAll takes Executable lambdas, can be nested
  • assertTimeoutPreemptively runs code in another thread and aborts it
  • @Timeout works on methods, classes, and lifecycle methods

Throws, Groups, Time

@Test
void rejectsNegativeQuantity() {
    var ex = assertThrows(IllegalArgumentException.class,
                          () -> cart.add("A1", -1));
    assertEquals("qty must be > 0", ex.getMessage());
}

@Test
void exactType() {
    assertThrowsExactly(OrderNotFoundException.class, () -> service.find(99));
}

@Test
void doesNotThrow() {
    Order o = assertDoesNotThrow(() -> service.find(1));   // returns the value
}

@Test
void addressFields() {
    Address a = customer.address();
    assertAll("address",
        () -> assertEquals("1 Main St", a.street()),
        () -> assertEquals("Tripoli", a.city()),
        () -> assertEquals("IA", a.state()));
}

@Test
void fastEnough() {
    assertTimeout(Duration.ofMillis(200), () -> pricing.quote(cart));
}

@Test
@Timeout(value = 2, unit = TimeUnit.SECONDS)
void finishesInTwoSeconds() { importer.run(); }

Code Explained

The exception returned by assertThrows lets you assert on message or fields
All three address checks run, and every failure is reported
assertTimeout lets the code finish, then fails if it was slow; the preemptive version aborts it
Set a project-wide default timeout in junit-platform.properties

JUnit 4 / TestNG Equivalent

  • JUnit 4 @Test(expected = X.class), ExpectedException rule; @Test(timeout = 2000)
  • TestNG @Test(expectedExceptions = X.class, timeOut = 2000); SoftAssert for grouped checks

Prefer / Avoid

  • try { …; fail(); } catch (X e) {} → assertThrows
  • several asserts where you want all failures → assertAll
  • catching Exception.class → the specific type

⚠ Common Mistakes

  • Wrapping several statements in the assertThrows lambda so the wrong one throws
  • assertTimeoutPreemptively with code that uses thread-locals (Spring transactions)
  • Catching Exception and passing on a typo-caused NullPointerException

✓ Tips & Best Practices

  • Keep only the call that should throw inside the lambda
  • Use assertAll for checking the fields of one object
  • Prefer @Timeout for slow-test guards; it's declarative

Quick Summary

  • assertThrows — returns the exception
  • assertAll — report every failure
  • assertTimeout / preemptive
  • @Timeout — declarative limit
