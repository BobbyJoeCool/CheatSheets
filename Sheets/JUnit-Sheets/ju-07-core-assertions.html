Sheet 07

Core Assertions

assertEquals · assertTrue / assertFalse · assertNull · assertSame · assertArrayEquals · assertIterableEquals · message suppliers

The Built-in Assertions Class

org.junit.jupiter.api.Assertions holds static methods you import with import static …Assertions.*. Each takes the expected value first, the actual second, and an optional message last, either a String or a Supplier<String> that is only built if the assertion fails. For collections, assertIterableEquals compares element by element.

Notes

  • assertEquals(double, double, delta) for floating point
  • assertSame checks identity (==); assertEquals uses equals()
  • assertInstanceOf returns the cast value
  • fail("msg") fails unconditionally

Assertions in Use

import static org.junit.jupiter.api.Assertions.*;

@Test
void assertions() {
    Order order = service.place(cart);

    assertEquals(OrderStatus.NEW, order.status());
    assertEquals(19.99, order.total(), 0.001);                 // delta for doubles
    assertNotEquals(0, order.id());
    assertTrue(order.lines().size() > 0, "order has lines");
    assertFalse(order.isPaid());
    assertNull(order.paidAt());
    assertNotNull(order.createdAt(), () -> "createdAt missing on " + order);
    assertSame(cart.customer(), order.customer());
    assertArrayEquals(new int[]{1, 2}, order.lineIds());
    assertIterableEquals(List.of("A1", "B2"), order.skus());
    assertLinesMatch(List.of("Order \\d+", ">> >>", "Total: .*"), order.receiptLines());
    Invoice inv = assertInstanceOf(Invoice.class, order.document());
}

Code Explained

The message comes last in JUnit 5/6 (it was first in JUnit 4)
The lambda message is built only when the assertion fails
assertLinesMatch allows regex lines and >> >> to skip lines
assertInstanceOf both checks the type and returns the cast object

JUnit 4 / TestNG Equivalent

  • JUnit 4 Assert.assertEquals("msg", expected, actual) (message first); assertThat with Hamcrest
  • TestNG Assert.assertEquals(actual, expected, "msg") — actual first

Prefer / Avoid

  • assertTrue(a.equals(b)) → assertEquals(b, a) (better message)
  • assertTrue(list.size() == 2) → AssertJ hasSize(2) (sheet 09)
  • string messages built with + on every call → Supplier<String>

⚠ Common Mistakes

  • Swapping expected and actual, so failures say "expected <bad> but was <good>"
  • Comparing doubles without a delta
  • Using assertSame on strings or boxed numbers

✓ Tips & Best Practices

  • Use AssertJ for collections and complex objects (sheet 09)
  • Give a message when the values alone don't explain the failure
  • Static-import Assertions.* once per file

Quick Summary

  • assertEquals(expected, actual)
  • message last (String or Supplier)
  • delta for doubles
  • assertInstanceOf — check and cast
