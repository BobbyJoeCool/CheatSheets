Capturing, Spying and Static Mocks

An ArgumentCaptor grabs the argument a mock received so you can assert on it in detail. A @Spy wraps a real object: real methods run unless stubbed. The do…().when() family stubs void methods and spies safely. BDDMockito reads as given/when/then, and mockStatic fakes a static method inside a try-with-resources block.

Notes

  • Captors: @Captor ArgumentCaptor<Order> captor;
  • Stub spies with doReturn, not when, to avoid calling the real method
  • mockStatic / mockConstruction need the inline mock maker (default in Mockito 5)
  • Strictness: @MockitoSettings(strictness = Strictness.LENIENT) loosens checks

In Spring Boot

  • @MockitoBean mocks are reset after each test automatically (MockReset.AFTER)
  • Strict-stub checks apply to @MockitoBean mocks too
  • @MockitoSpyBean wraps a real bean, like @Spy inside the context

Captors, Spies, BDD, Static

import static org.mockito.BDDMockito.*;

@ExtendWith(MockitoExtension.class)
class CheckoutTest {
    @Mock PaymentGateway gateway;
    @Spy PriceCalculator calc = new PriceCalculator();
    @Captor ArgumentCaptor<Charge> chargeCaptor;
    @InjectMocks Checkout checkout;

    @Test
    void chargesTheRightAmount() {
        given(gateway.charge(any())).willReturn(new Receipt("r1"));   // BDD stub

        checkout.pay(cart);

        then(gateway).should().charge(chargeCaptor.capture());        // BDD verify
        Charge c = chargeCaptor.getValue();
        assertThat(c.amountCents()).isEqualTo(1999);
        assertThat(c.currency()).isEqualTo("USD");
        verify(calc).total(cart);                                     // real method ran
    }

    @Test
    void gatewayDown() {
        doThrow(new GatewayException()).when(gateway).refund(anyString());
        assertThrows(RefundFailed.class, () -> checkout.refund("r1"));
    }

    @Test
    void fixedNow() {
        try (MockedStatic<Instant> mocked = mockStatic(Instant.class, CALLS_REAL_METHODS)) {
            mocked.when(Instant::now).thenReturn(Instant.parse("2026-11-04T00:00:00Z"));
            assertThat(checkout.receiptDate()).isEqualTo("2026-11-04");
        }                                                             // restored here
    }
}

Code Explained

The captor holds the Charge passed to the gateway so its fields can be checked
@Spy lets the real total run while still recording the call
doThrow(...).when(mock).voidMethod() is how to stub void methods
mockStatic is scoped to the try block; injecting a Clock is usually cleaner

JUnit 4 / TestNG Equivalent

  • JUnit 4 Same Mockito API; runner or rule instead of the extension
  • TestNG Same Mockito API; MockitoTestNGListener for annotations

Prefer / Avoid

  • mockStatic for time → inject a Clock
  • when(spy.x()) → doReturn(v).when(spy).x()
  • captors for simple equality → verify(m).x(eq(expected))

do… Family

CallUse for
doReturn(v).when(m).x()Spies, avoiding real call
doThrow(e).when(m).x()Void methods that throw
doNothing().when(m).x()Void on spies
doAnswer(inv -> …).when(m).x()Side effects, callbacks
doCallRealMethod().when(m).x()Real method on a mock

⚠ Common Mistakes

  • when(spy.method()) calling the real method during stubbing
  • Forgetting to close MockedStatic, leaking the mock into other tests
  • Captors used where a simple matcher would read better

✓ Tips & Best Practices

  • Use BDD style if your team writes given/when/then test names
  • Wrap static APIs (time, UUIDs) behind injectable interfaces
  • Use lenient() on a single stub instead of loosening the whole class

Quick Summary

  • ArgumentCaptor — inspect arguments
  • @Spy — real object + recording
  • do…().when() — voids and spies
  • mockStatic — scoped static mocks
