Azure Virtual Machines

A VM is a size (vCPUs, memory), an image, managed disks and a network interface in a subnet. Size names encode the family and features: Standard_D2s_v5 is general purpose, 2 vCPUs, premium-storage capable, version 5; Dpsv6 sizes run on Microsoft's Arm-based Cobalt CPUs. cloud-init configures Linux on first boot, and Azure Bastion gives browser or native SSH without public IPs.

Key Points

  • Images: Ubuntu2404, Debian12, Win2022Datacenter, or a Compute Gallery image
  • Trusted Launch (Secure Boot, vTPM) is the default for supported Gen2 images
  • Zones: pass --zone 1 to pin a VM to a zone
  • B-series burstable sizes suit dev and light workloads

Security Check

  • No public IP: use Bastion or Entra ID login through Bastion
  • Enable encryption at host for temp disk and cache encryption
  • Patch with Azure Update Manager, not by hand

Limits & Quotas

  • vCPU quotas per region and per VM family (new subscriptions start low)
  • Check with az vm list-usage -l <region>; request increases in Quotas
  • Not every size exists in every region or zone

Create a Private Linux VM

az vm create -g rg-app -n vm-web-1 -l eastus2 --zone 1 \
    --image Ubuntu2404 --size Standard_D2ps_v6 \
    --admin-username azureuser --generate-ssh-keys \
    --vnet-name vnet-shop-prod --subnet snet-app \
    --public-ip-address "" --nsg "" \
    --custom-data cloud-init.yaml --assign-identity

az vm list-sizes -l eastus2 --query "[?contains(name,'pds_v6')].name" -o tsv
az vm image list --publisher Canonical --offer ubuntu-24_04-lts --all -o table

# SSH through Bastion with your Entra ID account
az network bastion ssh -g rg-net -n bas-shop --auth-type AAD \
    --target-resource-id $(az vm show -g rg-app -n vm-web-1 --query id -o tsv)
az vm run-command invoke -g rg-app -n vm-web-1 \
    --command-id RunShellScript --scripts "systemctl status nginx"

cloud-init.yaml

#cloud-config
package_upgrade: true
packages: [nginx]
runcmd:
  - systemctl enable --now nginx

Code Explained

--public-ip-address "" and --nsg "" skip the public IP and NIC NSG (subnet NSG applies)
D2ps_v6 is a 2-vCPU Arm (Cobalt) general-purpose size
--assign-identity adds a system-assigned managed identity
run-command executes a script without SSH

AWS / GCP Equivalent

  • AWS EC2, AMIs, user data, Session Manager (aws-15)
  • GCP Compute Engine, images, startup scripts, OS Login / IAP (gcp-15)

Cost Check

  • Billed per minute while running, plus disks and IPs always
  • Arm (Cobalt) and B-series sizes are cheapest for many Linux workloads
  • Bastion has an hourly cost: share one per hub

Do & Don't

  • Do Bake golden images in Azure Compute Gallery for faster, consistent boots
  • Do Put VMs in scale sets even for one instance
  • Don’t Open SSH to the internet with a public IP
  • Don’t Resize production VMs by hand during business hours

Local Testing

  • Multipass or Vagrant runs the same cloud-init file locally
  • cloud-init schema --config-file cloud-init.yaml validates the file
  • Packer builds Azure images from a local template

Production Checklist

  • No public IPs; Bastion or private access only
  • Update Manager patch schedules and Azure Monitor agent installed
  • Zones or scale sets for redundancy; backups enabled
