Load Balancing

Azure Load Balancer (L4) · Application Gateway (L7) · backend pools · health probes · path-based routing · choosing Load Balancer / Application Gateway / Front Door / Traffic Manager

Spreading Traffic

Azure has four balancers. Azure Load Balancer is layer 4 (TCP / UDP), regional, very fast. Application Gateway is a regional layer-7 balancer with path / host routing, TLS termination and an optional WAF. Front Door is the global layer-7 entry (sheet 14), and Traffic Manager is DNS-based global routing (sheet 13).

Key Points

  • Use Standard SKU: Basic Load Balancer and Basic public IPs are retired
  • Application Gateway v2 autoscales and is zone-redundant
  • Health probes decide which backends receive traffic
  • Load Balancer outbound rules can also provide egress

L4 Load Balancer and L7 Application Gateway

az network lb create -g rg-net -n lb-api --sku Standard \
    --frontend-ip-name fe --backend-pool-name be \
    --public-ip-address pip-lb-api
az network lb probe create -g rg-net --lb-name lb-api -n tcp-8080 \
    --protocol Tcp --port 8080
az network lb rule create -g rg-net --lb-name lb-api -n tcp-443 \
    --protocol Tcp --frontend-port 443 --backend-port 8080 \
    --frontend-ip-name fe --backend-pool-name be --probe-name tcp-8080

az network application-gateway create -g rg-net -n agw-shop \
    --sku WAF_v2 --capacity 2 --zones 1 2 3 \
    --vnet-name vnet-shop-prod --subnet snet-agw \
    --public-ip-address pip-agw --priority 100 \
    --servers app-shop.azurewebsites.net --http-settings-protocol Https
az network application-gateway probe create -g rg-net \
    --gateway-name agw-shop -n health --protocol Https \
    --path /health --host-name-from-http-settings true

Code Explained

A Standard LB needs a frontend, a backend pool, a probe and a rule
The rule maps port 443 on the frontend to 8080 on the backends
Application Gateway WAF_v2 adds web application firewall rules
The custom probe checks /health over HTTPS

AWS / GCP Equivalent

  • AWS NLB (L4), ALB (L7), Global Accelerator, Route 53 (aws-17)
  • GCP Network LB, Application LB (regional / global) (gcp-17)

Cost Check

  • Standard LB bills per rule-hour plus data processed
  • Application Gateway v2 bills fixed hourly + capacity units
  • Use one Application Gateway for many apps via host-based routing

Do & Don't

  • Do Use zone-redundant frontends
  • Do Probe a real health endpoint, not just a TCP port, at L7
  • Don’t Build new solutions on Basic SKUs
  • Don’t Put Application Gateway in a subnet shared with other resources

Local Testing

  • Practice probes and routing with nginx / Traefik in Docker Compose
  • Network Watcher connection troubleshoot checks backend reachability
  • curl -v --resolve host:443:<ip> tests TLS on the gateway before DNS

Production Checklist

  • Health probes tuned with realistic thresholds
  • WAF in Prevention mode on public HTTP endpoints
  • Diagnostics and metrics (unhealthy host count) alerting
