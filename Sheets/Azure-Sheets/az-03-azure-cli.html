Scripting Azure

The Azure CLI (az) is a cross-platform command line for every Azure service. Commands follow az <group> <subgroup> <verb>, output JSON by default, and accept --query (JMESPath) to pick fields and -o table|tsv|yaml to format. Defaults save typing; extensions add preview and newer services.

Key Points

  • Install: brew install azure-cli, winget, or the Linux script
  • az upgrade updates the CLI; az extension add -n <name> adds features
  • Use -o tsv to capture values in shell variables
  • az find "create vm" and -h show examples

Security Check

  • Tokens are cached under ~/.azure; protect that folder like a password
  • Never pass --password on the command line in scripts: use managed identity or OIDC
  • Azure now requires MFA for CLI sign-ins by users

Everyday az

az login                                   # browser sign-in
az login --use-device-code                 # SSH / no browser
az account set --subscription "shop-prod"
az account show --query "{name:name, id:id}" -o table

az config set defaults.group=rg-shop-dev defaults.location=eastus2
az config set core.output=table

# JMESPath: names of running VMs
az vm list -d --query "[?powerState=='VM running'].name" -o tsv

# Capture an ID for the next command
SUB=$(az account show --query id -o tsv)
STG=$(az storage account show -n shopdevdata --query id -o tsv)

az extension add --name containerapp --upgrade
az extension list -o table
az group delete -n rg-scratch --yes --no-wait   # async cleanup

az interactive                             # autocomplete shell

Code Explained

az account set picks the subscription every later command uses
Defaults in az config apply until you change them
-d adds runtime details such as power state to vm list
--no-wait returns immediately while Azure deletes in the background

AWS / GCP Equivalent

  • AWS AWS CLI v2, --query, profiles (aws-03)
  • GCP gcloud, --format / --filter, configurations (gcp-03)
  • Both az and aws use JMESPath for --query

Cost Check

  • The CLI is free; Cloud Shell storage (a file share) costs a little
  • A typo in --sku can create a premium tier: check before running
  • --no-wait deletes still bill until they finish

Output Formats

FlagUse
-o jsonDefault, full detail
-o tableHumans
-o tsvShell variables
-o yamlReadable config
-o noneQuiet scripts

Handy Flags

FlagDoes
--queryJMESPath filter
--subscriptionOne-off subscription
--no-waitDon't block
--debugShow HTTP calls
--only-show-errorsQuieter output

Do & Don't

  • Do Set defaults for group and location in interactive sessions
  • Do Pass --subscription explicitly in scripts
  • Don’t Parse -o table output in scripts (use tsv or json)
  • Don’t Store service principal secrets in shell history

Local Testing

  • Run the CLI in Docker: docker run -it mcr.microsoft.com/azure-cli
  • Cloud Shell in the browser needs no install
  • Use --debug to see the REST calls a command makes

Production Checklist

  • Automation signs in with managed identity or OIDC, not passwords
  • Scripts pin the subscription and fail on errors (set -euo pipefail)
  • CLI version pinned in CI images
