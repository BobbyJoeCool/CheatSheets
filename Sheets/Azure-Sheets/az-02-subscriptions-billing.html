Subscriptions & Billing

Paying for Azure

A subscription is the billing and quota container: charges roll up from resources to resource groups to subscriptions to a billing account. Cost Management shows spend by service, resource group or tag, budgets send alerts at thresholds, and Azure Advisor recommends savings. Tags make costs traceable to teams.

Key Points

  • Budgets alert; they do not stop resources (use automation for that)
  • Tags are not inherited by default; use Azure Policy to inherit or require them
  • Cost data refreshes several times a day, not in real time
  • Separate subscriptions per environment keep bills and quotas apart

Limits & Quotas

  • 980 resource groups per subscription
  • 50 tags per resource; tag names up to 512 chars (128 on storage accounts)
  • 800 deployments kept per resource group history (older ones auto-deleted)

Budgets, Tags and Cost Queries

# Monthly budget with an email at 80%
az consumption budget create --budget-name shop-monthly \
    --amount 300 --category cost --time-grain Monthly \
    --start-date 2026-12-01 --end-date 2027-12-01 \
    --resource-group rg-shop-prod

# Tag a resource group and everything you create later
az group update -n rg-shop-prod --tags owner=team-a costcenter=1234
az tag list --resource-id /subscriptions/<sub-id>/resourceGroups/rg-shop-prod

# Usage for the last month
az consumption usage list --start-date 2026-10-01 --end-date 2026-10-31 \
    --query "[].{name:instanceName, cost:pretaxCost}" -o table

# Savings advice
az advisor recommendation list --category Cost -o table

# Quota usage per region (vCPUs and more)
az vm list-usage -l eastus2 -o table

Code Explained

Budgets can be scoped to a subscription or resource group
az group update --tags replaces the tag set; merge with az tag update --operation merge
Usage lines map cost to individual resources
list-usage shows how close you are to vCPU quotas

Cost Check

  • Budgets and Cost Management are free to use
  • Biggest surprises: running VMs left on, premium SKUs picked by default, data egress
  • Dev / Test subscriptions (with Visual Studio) get discounted rates

Do & Don't

  • Do Create a budget per subscription before deploying anything
  • Do Require owner and costcenter tags with Azure Policy
  • Don’t Rely on the invoice to discover a runaway resource
  • Don’t Share one subscription for dev and prod

Local Testing

  • Estimate with the Azure Pricing Calculator before deploying
  • Infracost reads Terraform azurerm plans and prices them
  • Use a Visual Studio subscription credit for experiments

Production Checklist

  • Budgets and anomaly alerts routed to the team
  • Tag policy enforced at the management group
  • Monthly Advisor cost review with owners
