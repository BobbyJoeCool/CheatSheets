Foundry Tools & ML

Foundry Tools (formerly Azure AI Services): Vision, Speech, Language, Translator, Document Intelligence · Azure Machine Learning · GitHub Copilot pointer

Prebuilt AI and Custom ML

Foundry Tools (formerly Azure AI Services) are prebuilt APIs: Vision (image analysis, OCR), Speech (speech-to-text, text-to-speech, translation), Language (sentiment, entities, PII detection, summarization), Translator and Document Intelligence (forms, invoices, receipts). Azure Machine Learning trains, tracks and deploys your own models.

Key Points

  • One multi-service resource can serve several tools with one endpoint
  • Prebuilt models need no training; custom models train on your labeled data
  • Containers exist for some tools to run on-premises or at the edge
  • GitHub Copilot is the developer assistant (separate product)

Document Intelligence: Read an Invoice

from azure.ai.documentintelligence import DocumentIntelligenceClient
from azure.identity import DefaultAzureCredential
client = DocumentIntelligenceClient(
    "https://ai-shop.cognitiveservices.azure.com/", DefaultAzureCredential())
with open("invoice.pdf", "rb") as f:
    poller = client.begin_analyze_document("prebuilt-invoice", body=f)
doc = poller.result().documents[0]
print(doc.fields["VendorName"].value_string, doc.fields["InvoiceTotal"].content)

Language: Detect PII

from azure.ai.textanalytics import TextAnalyticsClient
from azure.identity import DefaultAzureCredential
ta = TextAnalyticsClient("https://ai-shop.cognitiveservices.azure.com/",
                         DefaultAzureCredential())
res = ta.recognize_pii_entities(["Call Ada at 555-0100 about order 42."])[0]
print(res.redacted_text)        # Call *** at ******** about order 42.

Azure Machine Learning CLI

az extension add -n ml
az ml workspace create -g rg-ml -n mlw-shop
az ml job create -f train-job.yml -g rg-ml -w mlw-shop

Code Explained

prebuilt-invoice extracts vendor, totals and line items
Long operations return a poller; result() waits
PII detection returns redacted text and the entities found
Azure ML jobs are defined in YAML and run on managed compute

Do & Don't

  • Do Start with prebuilt models before training custom ones
  • Do Use Entra ID auth and regional endpoints that meet data rules
  • Don’t Send documents with personal data without reviewing retention settings
  • Don’t Call synchronous APIs in a loop for large batches (use batch APIs)

Local Testing

  • Several tools ship Docker containers (e.g. Language, Speech) for local or disconnected use
  • Foundry portal playgrounds test tools without code
  • Record sample responses and replay them in unit tests

Production Checklist

  • Managed identity auth and private endpoints
  • Retries for 429 / transient errors
  • Monitoring of usage against quotas and budgets
