Running VMs Cheaply and Safely

VMs keep their managed disks (Premium SSD v2, Premium SSD, Standard SSD, Ultra) across restarts; snapshots copy a disk at a point in time. Stopping from inside the OS keeps billing compute: you must deallocate to stop paying. Discounts come from Spot VMs (evictable), Reservations and the savings plan for compute, and Azure Hybrid Benefit for existing Windows / SQL licenses.

Key Points

  • az vm stop powers off but still bills compute; az vm deallocate stops it
  • Deallocated VMs still pay for disks and static public IPs
  • Spot VMs can be evicted with 30 seconds notice
  • Auto-shutdown schedules stop dev VMs every evening

Operate and Save

az vm deallocate -g rg-app -n vm-web-1          # stop paying for compute
az vm start -g rg-app -n vm-web-1
az vm resize -g rg-app -n vm-web-1 --size Standard_D4ps_v6
az vm auto-shutdown -g rg-app -n vm-dev-1 --time 1900   # UTC, daily

# Disks and snapshots
az disk create -g rg-app -n disk-data --size-gb 256 --sku PremiumV2_LRS --zone 1
az vm disk attach -g rg-app --vm-name vm-web-1 --name disk-data
az snapshot create -g rg-app -n snap-data-20261112 --source disk-data \
    --incremental true

# Spot VM that deallocates on eviction, pay up to on-demand price
az vm create -g rg-batch -n vm-spot-1 --image Ubuntu2404 \
    --size Standard_D4ps_v6 --priority Spot --max-price -1 \
    --eviction-policy Deallocate --generate-ssh-keys

# Windows license you already own
az vm update -g rg-app -n vm-win-1 --license-type Windows_Server

az disk list --query "[?diskState=='Unattached'].name" -o tsv  # waste

Code Explained

Deallocate releases the host; the VM keeps its disks and config
Incremental snapshots store only changed blocks
--max-price -1 means never evict on price, only on capacity
Unattached disks are a common forgotten cost

AWS / GCP Equivalent

  • AWS EBS, snapshots, Spot, Savings Plans / RIs (aws-16)
  • GCP Persistent Disk / Hyperdisk, Spot VMs, CUDs / SUDs (gcp-16)
  • AWS "stop" stops billing compute; Azure needs deallocate

Cost Check

  • Reservations: up to ~72% off for 1 or 3 years on a fixed size
  • Savings plan for compute: flexible across sizes and regions, lower discount
  • Spot: up to ~90% off, eviction at any time

Do & Don't

  • Do Deallocate (or auto-shutdown) dev VMs outside working hours
  • Do Rightsize with Advisor before buying Reservations
  • Don’t Shut down from inside the OS and assume billing stopped
  • Don’t Run stateful, uninterruptible workloads on Spot

Local Testing

  • Simulate Spot eviction with az vm simulate-eviction in a sandbox
  • Compare prices in the Azure Pricing Calculator
  • Test snapshot restores into a scratch resource group

Production Checklist

  • Backups or snapshot schedules for data disks
  • Reservations / savings plan cover the steady baseline
  • Alerts for unattached disks and unused public IPs
