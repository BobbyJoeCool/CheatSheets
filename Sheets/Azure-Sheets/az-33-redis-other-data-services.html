Caches, Search and Analytics

Azure Managed Redis is the current Redis offering (built on Redis Enterprise); Azure Cache for Redis is being retired, so new work should start on Managed Redis. Azure AI Search provides full-text, vector and hybrid search, often the retrieval layer for RAG. Microsoft Fabric (and older Synapse) covers analytics and data warehousing.

Key Points

  • Cache-aside: read cache, fall back to the database, then populate
  • Managed Redis supports Entra ID authentication
  • AI Search indexes data from Blob, SQL, Cosmos DB and more
  • See the SQL and NoSQL sets for engine details

Cache-Aside in Python

import json, redis
from redis_entraid.cred_provider import create_from_default_azure_credential
creds = create_from_default_azure_credential(
    ("https://redis.azure.com/.default",))
r = redis.Redis(host="amr-shop.eastus2.redis.azure.net", port=10000,
                ssl=True, credential_provider=creds)

def get_product(pid):
    if (hit := r.get(f"product:{pid}")):
        return json.loads(hit)
    row = db_fetch_product(pid)                  # slow path
    r.set(f"product:{pid}", json.dumps(row), ex=300)
    return row

Code Explained

Managed Redis is managed with the redisenterprise CLI group
AI Search with 2 replicas gets a read SLA
The redis-entraid package supplies Entra tokens to redis-py
Cache entries expire after 300 seconds

AWS / GCP Equivalent

Cost Check

  • Managed Redis bills per hour by SKU; size the memory to the working set
  • AI Search: per search unit per hour (partitions × replicas)
  • Fabric bills by capacity; pause when idle

Do & Don't

  • Do Set TTLs on every cache key
  • Do Plan migration from Azure Cache for Redis to Managed Redis
  • Don’t Treat a cache as the source of truth
  • Don’t Index everything in AI Search without a retrieval plan

Local Testing

  • Run Redis or Valkey in Docker: docker run -p 6379:6379 redis
  • Elasticsearch / OpenSearch containers approximate search behavior locally
  • Mock the cache layer in unit tests

Production Checklist

  • Cache with zone redundancy and Entra auth
  • AI Search with 2+ replicas and private endpoint
  • Cache hit-rate and memory alerts
