Styled Text & HTML

JTextPane · StyledDocument · SimpleAttributeSet · StyleConstants · insertString · JEditorPane · HyperlinkListener

Rich Text

JTextPane edits text with mixed fonts, colors and embedded icons, stored in a StyledDocument. Styles are AttributeSets you build with StyleConstants. JEditorPane displays text/html (HTML 3.2 with basic CSS) and RTF; make it non-editable and add a HyperlinkListener to use it as a simple help viewer.

Notes

  • insertString can throw BadLocationException
  • Named styles (addStyle) can be reused
  • The HTML engine is old: no modern CSS

EDT Check

  • Document writes take a lock, but caret and view updates need the EDT
  • Append chat or log lines inside invokeLater from other threads

Colored Log and HTML Help

JTextPane pane = new JTextPane();
StyledDocument doc = pane.getStyledDocument();

SimpleAttributeSet error = new SimpleAttributeSet();
StyleConstants.setForeground(error, new Color(0xC62828));
StyleConstants.setBold(error, true);

SimpleAttributeSet mono = new SimpleAttributeSet();
StyleConstants.setFontFamily(mono, Font.MONOSPACED);

void append(String text, AttributeSet style) {
    try { doc.insertString(doc.getLength(), text, style); }
    catch (BadLocationException e) { throw new IllegalStateException(e); }
}
append("ERROR ", error);
append("connection refused\n", mono);

JEditorPane help = new JEditorPane("text/html",
        "<h2>Help</h2><p>See <a href='https://example.com'>docs</a></p>");
help.setEditable(false);                       // links need read-only
help.addHyperlinkListener(e -> {
    if (e.getEventType() == HyperlinkEvent.EventType.ACTIVATED)
        Desktop.getDesktop().browse(e.getURL().toURI());   // sheet 53
});

Code Explained

SimpleAttributeSet + StyleConstants — a style
insertString(offset, text, style) — add text
JEditorPane("text/html", …) — HTML viewer
ACTIVATED — link clicked

JavaFX Equivalent

  • JTextPane → TextFlow (view) or RichTextFX
  • JEditorPane HTML → WebView (full browser)
  • HyperlinkListener → Hyperlink controls
  • See Java 128

Prefer / Avoid

  • setText(getText() + …) for logs → insertString at the end
  • complex HTML in JEditorPane → keep it simple or use JavaFX WebView

⚠ Common Mistakes

  • Expecting links to work in an editable JEditorPane — hyperlink events fire only when read-only
  • Using modern CSS (flexbox, grid) in Swing HTML — silently ignored
  • Swallowing BadLocationException — hides offset bugs

✓ Tips & Best Practices

  • Create named styles with pane.addStyle("error", null) and reuse them
  • Use setParagraphAttributes for alignment and spacing
  • For big logs, remove old text from the start of the document

Quick Summary

  • JTextPane + StyledDocument — styled text
  • StyleConstants — build attribute sets
  • insertString — append with a style
  • JEditorPane + HyperlinkListener — HTML help
