GroupLayout & SpringLayout

GroupLayout · SequentialGroup · ParallelGroup · setAutoCreateGaps · linkSize · SpringLayout · putConstraint

Builder-Style Layouts

GroupLayout (Java 6) describes the layout twice: once horizontally and once vertically, each as nested sequential and parallel groups. It was made for GUI builders like NetBeans Matisse, but it also produces clean forms by hand. SpringLayout pins component edges to other edges with springs and struts; it's rarely written by hand today.

Notes

  • Every component must be in both dimensions
  • setAutoCreateGaps(true) adds L&F-correct spacing
  • linkSize makes buttons the same width
  • Builder-generated GroupLayout code is hard to edit

Two-Column Form with GroupLayout

JPanel p = new JPanel();
GroupLayout g = new GroupLayout(p);
p.setLayout(g);
g.setAutoCreateGaps(true);
g.setAutoCreateContainerGaps(true);

JLabel nameL = new JLabel("Name:"), mailL = new JLabel("Email:");

g.setHorizontalGroup(g.createSequentialGroup()
    .addGroup(g.createParallelGroup(GroupLayout.Alignment.TRAILING)
        .addComponent(nameL).addComponent(mailL))
    .addGroup(g.createParallelGroup()
        .addComponent(nameFld).addComponent(mailFld)));

g.setVerticalGroup(g.createSequentialGroup()
    .addGroup(g.createParallelGroup(GroupLayout.Alignment.BASELINE)
        .addComponent(nameL).addComponent(nameFld))
    .addGroup(g.createParallelGroup(GroupLayout.Alignment.BASELINE)
        .addComponent(mailL).addComponent(mailFld)));

Code Explained

horizontal — labels column, then fields column
vertical — row 1, then row 2
TRAILING — right-align the labels
BASELINE — line up label and field text

JavaFX Equivalent

  • no direct equivalent; use GridPane
  • linkSize → bind prefWidth of buttons
  • SpringLayout → AnchorPane anchors
  • See Java 127

Prefer / Avoid

  • hand-written SpringLayout → GridBag, GroupLayout or MigLayout
  • fixed pixel gaps → setAutoCreateGaps(true)

⚠ Common Mistakes

  • Adding a component to only the horizontal group — throws IllegalStateException at layout time
  • Editing Matisse's generated GroupLayout by hand — the builder overwrites or breaks it
  • Using p.add(...) with GroupLayout — groups add components for you

✓ Tips & Best Practices

  • Write the horizontal group as columns and the vertical group as rows
  • Use g.linkSize(SwingConstants.HORIZONTAL, ok, cancel) for equal buttons
  • Prefer GroupLayout over GridBag for label/field forms with baselines

Quick Summary

  • GroupLayout — describe each axis with groups
  • sequential vs parallel — in a row vs aligned
  • setAutoCreateGaps — standard spacing
  • SpringLayout — edge springs (rarely by hand)
