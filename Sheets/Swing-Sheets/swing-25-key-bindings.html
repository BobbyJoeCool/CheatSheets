Keyboard Shortcuts Done Right

Key bindings map a KeyStroke to an action name in an InputMap, and the name to an Action in an ActionMap. Unlike KeyListener, bindings work when the component isn't focused (with the right condition), don't need focus tricks, and are how Swing's own components handle keys. Use KeyListener only for raw typing, like a game.

Notes

  • Three input maps per component, picked by condition
  • Bind "none" to disable a built-in key
  • Menu accelerators are bindings set for you

Shortcuts on a Panel

JComponent root = frame.getRootPane();
InputMap im = root.getInputMap(JComponent.WHEN_IN_FOCUSED_WINDOW);
ActionMap am = root.getActionMap();

int menuKey = Toolkit.getDefaultToolkit().getMenuShortcutKeyMaskEx();
im.put(KeyStroke.getKeyStroke(KeyEvent.VK_F, menuKey), "find");
am.put("find", new AbstractAction() {
    @Override public void actionPerformed(ActionEvent e) {
        searchField.requestFocusInWindow();
    }
});

im.put(KeyStroke.getKeyStroke("ESCAPE"), "close");   // string form
am.put("close", closeAction);

// Only when the table has focus: Delete removes rows
table.getInputMap(JComponent.WHEN_FOCUSED)
     .put(KeyStroke.getKeyStroke("DELETE"), "deleteRow");
table.getActionMap().put("deleteRow", deleteAction);

// Disable the table's Enter-moves-down behavior
table.getInputMap(JComponent.WHEN_ANCESTOR_OF_FOCUSED_COMPONENT)
     .put(KeyStroke.getKeyStroke("ENTER"), "none");

Code Explained

InputMap — keystroke → name
ActionMap — name → Action
WHEN_IN_FOCUSED_WINDOW — anywhere in the window
"none" — turn off a default binding

JavaFX Equivalent

  • key bindings → scene.getAccelerators().put(...)
  • KeyStroke → KeyCombination
  • WHEN_FOCUSED → node.setOnKeyPressed
  • See Java 129

Prefer / Avoid

  • KeyListener for shortcuts → InputMap + ActionMap
  • CTRL_DOWN_MASK hard-coded → getMenuShortcutKeyMaskEx()

InputMap Conditions

ConditionActive when
WHEN_FOCUSEDcomponent has focus

WHEN_IN_FOCUSED_WINDOWanything in the window

⚠ Common Mistakes

  • Using KeyListener on a panel — it only fires when that panel has focus, which panels rarely get
  • Binding the same key at two levels — the focused component's binding wins silently
  • Typos in the string form — getKeyStroke("Ctrl S") returns null (modifiers are lowercase)

✓ Tips & Best Practices

  • Bind window-wide shortcuts on the root pane with WHEN_IN_FOCUSED_WINDOW
  • Reuse the menu's Action so the shortcut shows in the menu too
  • Inspect a component's defaults with getInputMap().allKeys()

Quick Summary

  • InputMap + ActionMap — the binding pair
  • conditions — focused, ancestor, window
  • KeyStroke — key + modifiers
  • KeyListener — only for raw typing
