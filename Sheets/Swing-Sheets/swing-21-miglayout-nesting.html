MigLayout & Nesting Panels

MigLayout · constraint strings · wrap · grow / push · nested JPanels · form layout patterns

Concise Layouts

MigLayout is a third-party layout manager (com.miglayout:miglayout-swing) that handles grids, rows, columns and docking with short constraint strings. One MigLayout panel often replaces several nested JDK layouts. Without it, the standard approach is nesting: a BorderLayout skeleton with simpler panels in each region.

Notes

  • Three strings: layout, column and row constraints
  • wrap ends a row; span merges cells
  • grow fills the cell; push claims extra space
  • Units: px, mm, %, logical pixels by default

Same Form, Two Ways

// MigLayout: 2 columns, labels right-aligned, fields grow
JPanel form = new JPanel(new MigLayout(
        "fillx, insets dialog",          // layout constraints
        "[right][grow, fill]",           // columns
        "[][]"));                        // rows
form.add(new JLabel("Name:"));
form.add(nameFld, "wrap");
form.add(new JLabel("Email:"));
form.add(mailFld, "wrap");
form.add(new JScrollPane(notes), "span 2, grow, push");
form.add(okBtn, "span 2, split 2, tag ok");      // platform button order
form.add(cancelBtn, "tag cancel");

// JDK only: nest simple layouts
JPanel root = new JPanel(new BorderLayout(0, 8));
root.add(fieldsPanel, BorderLayout.PAGE_START);  // GridBag form
root.add(new JScrollPane(notes), BorderLayout.CENTER);
root.add(buttonRow, BorderLayout.PAGE_END);      // FlowLayout(TRAILING)

Code Explained

"[right][grow, fill]" — column rules
wrap — next component starts a new row
span 2, grow, push — full width, takes extra space
tag ok — orders buttons per platform

JavaFX Equivalent

  • MigLayout has a JavaFX version: MigPane
  • nesting → BorderPane + VBox/HBox
  • grow → setHgrow(Priority.ALWAYS)
  • See Java 127

Prefer / Avoid

  • deeply nested panels → one MigLayout panel
  • pixel gaps → insets dialog / gap related (platform values)

⚠ Common Mistakes

  • Forgetting wrap — every component ends up in one long row
  • Using grow without push in a fill layout — the cell can't get bigger, so nothing grows
  • Nesting five levels deep for a simple form — hard to read and slow to lay out

✓ Tips & Best Practices

  • Add debug to the layout string to see cell borders while building
  • Keep MigLayout strings short and consistent across screens
  • Pull repeated nested panels into small factory methods
