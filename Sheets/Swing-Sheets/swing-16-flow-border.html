FlowLayout & BorderLayout

FlowLayout · alignment · hgap / vgap · BorderLayout · NORTH / CENTER / SOUTH · PAGE_START · default for content pane

The Two Everyday Layouts

FlowLayout lines components up in a row at their preferred size and wraps to a new row when space runs out. It's ideal for button bars. BorderLayout has five regions: the edges (NORTH, SOUTH, EAST, WEST) take their preferred thickness and CENTER gets everything left over. It's the classic frame layout: toolbar on top, status bar at the bottom, main content in the center.

Notes

  • Each BorderLayout region holds one component
  • Adding twice to a region replaces the first
  • PAGE_START / LINE_END respect right-to-left
  • FlowLayout wrapping doesn't grow the preferred height

Classic Window Layout

JPanel root = new JPanel(new BorderLayout(8, 8));   // hgap, vgap

root.add(toolBar, BorderLayout.PAGE_START);         // top
root.add(new JScrollPane(table), BorderLayout.CENTER);
root.add(sidePanel, BorderLayout.LINE_END);         // right (LTR)

JPanel buttons = new JPanel(new FlowLayout(FlowLayout.TRAILING, 6, 0));
buttons.add(new JButton("OK"));
buttons.add(new JButton("Cancel"));

JPanel south = new JPanel(new BorderLayout());
south.add(statusLabel, BorderLayout.CENTER);        // left, stretches
south.add(buttons, BorderLayout.LINE_END);          // right
root.add(south, BorderLayout.PAGE_END);

frame.setContentPane(root);
frame.pack();

Code Explained

BorderLayout(8, 8) — gaps between regions
CENTER — takes all remaining space
FlowLayout(TRAILING, 6, 0) — right-aligned row
nested panel — status left, buttons right

JavaFX Equivalent

  • BorderLayout → BorderPane
  • FlowLayout → FlowPane / HBox
  • gaps → setSpacing / setHgap
  • See Java 127

Prefer / Avoid

  • NORTH/EAST → PAGE_START/LINE_END (RTL-aware)
  • two components in one region → nest a panel in that region

⚠ Common Mistakes

  • Adding without a constraint to a BorderLayout — it goes to CENTER and replaces what was there
  • Expecting FlowLayout to stretch components — it never does
  • Putting a wrapping FlowLayout in a scroll pane — it won't grow taller to wrap

✓ Tips & Best Practices

  • Use BorderLayout for the window skeleton and nest other layouts inside
  • Put a panel in CENTER to make the main area fill the window
  • Use FlowLayout(TRAILING) for dialog button rows

Quick Summary

  • BorderLayout — edges plus a stretchy center
  • FlowLayout — a row at preferred sizes
  • one component per region — nest panels for more
  • PAGE_START etc. — RTL-aware names
