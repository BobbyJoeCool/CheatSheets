Sort, Filter and Edit

A TableRowSorter sorts and filters rows in the view only; the model keeps its order. Filters are RowFilters, from simple regex matches to your own include logic. Because the view no longer matches the model, convert indexes with convertRowIndexToModel. Cell editors handle in-place edits: DefaultCellEditor wraps a text field, check box or combo.

Notes

  • Sorter compares by getColumnClass type
  • Filter + sort combine; set both on one sorter
  • Columns can be reordered: use model column too

Search Box, Sort Keys and a Combo Editor

TableRowSorter<ItemModel> sorter = new TableRowSorter<>(model);
table.setRowSorter(sorter);
sorter.setSortKeys(List.of(new RowSorter.SortKey(1, SortOrder.ASCENDING)));

onTextChange(search, () -> {
    String q = search.getText().strip();
    sorter.setRowFilter(q.isEmpty() ? null
        : RowFilter.regexFilter("(?i)" + Pattern.quote(q), 0, 1));
});

sorter.setRowFilter(new RowFilter<ItemModel, Integer>() {   // custom
    @Override public boolean include(Entry<? extends ItemModel,
            ? extends Integer> e) {
        return model.at(e.getIdentifier()).qty() > 0;      // in stock
    }
});

TableColumn status = table.getColumnModel().getColumn(3);
status.setCellEditor(new DefaultCellEditor(
        new JComboBox<>(Status.values())));
status.setPreferredWidth(90);

int modelRow = table.convertRowIndexToModel(table.getSelectedRow());

Code Explained

setSortKeys — initial sort
regexFilter("(?i)…", 0, 1) — search columns 0–1
custom RowFilter — any rule
DefaultCellEditor(combo) — pick from a list

JavaFX Equivalent

  • TableRowSorter → SortedList + FilteredList
  • regex filter → setPredicate
  • cell editors → ComboBoxTableCell etc.
  • See Java 128

Prefer / Avoid

  • sorting the model list yourself → TableRowSorter
  • regex from raw user text → Pattern.quote(text)

⚠ Common Mistakes

  • Passing user text straight into regexFilter — ( or * throws PatternSyntaxException
  • Saving while a cell is still being edited — the last edit is lost; stop editing first
  • Using view indexes after filtering — rows shift and you act on the wrong item

✓ Tips & Best Practices

  • Turn on terminateEditOnFocusLost so clicking Save commits edits
  • Use setComparator(col, cmp) for natural or custom sort orders
  • Show "No matches" when sorter.getViewRowCount() == 0

Quick Summary

  • TableRowSorter — sort/filter in the view
  • RowFilter — regex, number, date, custom
  • convertRowIndexToModel — always after sorting
  • DefaultCellEditor — in-place edits
