Lists of Items

JList<E> shows a vertical list backed by a ListModel<E>. Use DefaultListModel when items are added and removed at runtime, or a custom model over your own collection. A ListSelectionModel controls single or multiple selection. Wrap the list in a JScrollPane, and draw items your own way with a cell renderer (sheet 34).

Notes

  • Items display with toString() by default
  • Selection events fire twice while dragging
  • Large lists: set a prototype value for speed

EDT Check

  • Change DefaultListModel on the EDT only
  • Bulk load: fill a new model, then setModel once

Editable List with Selection

DefaultListModel<Task> model = new DefaultListModel<>();
model.addAll(loadTasks());                    // Java 11+
JList<Task> list = new JList<>(model);
list.setSelectionMode(ListSelectionModel.MULTIPLE_INTERVAL_SELECTION);
list.setVisibleRowCount(8);                   // preferred height
list.setPrototypeCellValue(new Task("Prototype task name"));

list.addListSelectionListener(e -> {
    if (e.getValueIsAdjusting()) return;      // wait for final value
    List<Task> picked = list.getSelectedValuesList();
    deleteBtn.setEnabled(!picked.isEmpty());
});

addBtn.addActionListener(e -> {
    model.addElement(new Task("New task"));
    list.setSelectedIndex(model.size() - 1);
    list.ensureIndexIsVisible(model.size() - 1);
});
deleteBtn.addActionListener(e -> list.getSelectedValuesList()
        .forEach(model::removeElement));
panel.add(new JScrollPane(list));

Code Explained

DefaultListModel — mutable, fires updates
getValueIsAdjusting() — skip mid-drag events
setPrototypeCellValue — skip measuring each item
ensureIndexIsVisible — scroll to it

JavaFX Equivalent

  • JList → ListView
  • DefaultListModel → ObservableList
  • selection → getSelectionModel().selectedItemProperty()
  • See Java 128

Prefer / Avoid

  • new JList<>(array) then trying to add → DefaultListModel
  • getSelectedValues() (deprecated) → getSelectedValuesList()

⚠ Common Mistakes

  • Reacting to every selection event — work runs 2–3 times per click; check getValueIsAdjusting()
  • Modifying the model inside a selection listener — confusing re-entrant events
  • Forgetting the scroll pane — long lists get cut off

✓ Tips & Best Practices

  • Double-click to open: MouseAdapter + locationToIndex
  • Use AbstractListModel over your own List for big data
  • Show an empty-state label when the model is empty

Quick Summary
