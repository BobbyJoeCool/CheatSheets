⚠ Common Mistakes

  • Slow work in a listener — freezes every window
  • get() on a worker from the EDT before it's done — blocks
  • Changing a document inside its own DocumentListener

✓ Tips & Best Practices

  • One Action per command, shared by menu, toolbar and button
  • Key bindings over KeyListener
  • Fire the narrowest model event
