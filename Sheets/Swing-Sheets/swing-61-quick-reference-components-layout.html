⚠ Common Mistakes

  • null layout + setBounds — breaks on other fonts, HiDPI and translations
  • Forgetting revalidate() after adding components at runtime
  • Reading view rows from the model after sorting — convert indexes

✓ Tips & Best Practices

  • Nest simple layouts: BorderLayout outside, forms inside
  • Pad with EmptyBorder, not fixed sizes
  • Set FlatLaf before creating any component
