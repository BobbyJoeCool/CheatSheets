Java 2D Shapes & Strokes

Graphics2D · RenderingHints · Rectangle2D · Ellipse2D · Path2D · BasicStroke · GradientPaint · AffineTransform

The Java 2D API

The Graphics passed to paintComponent is really a Graphics2D. It draws any Shape (rectangles, ellipses, lines, arcs, paths) with draw for outlines or fill for solids. A Stroke sets line width and dashes, a Paint sets color or gradient, and an AffineTransform moves, scales and rotates everything drawn after it. Turn on antialiasing for smooth edges.

Notes

  • Shapes use double coordinates (.Double classes)
  • Transforms apply to everything drawn after them
  • Work on a g.create() copy so settings don't leak

Shapes, Strokes and Transforms

@Override protected void paintComponent(Graphics g) {
    super.paintComponent(g);
    Graphics2D g2 = (Graphics2D) g.create();
    g2.setRenderingHint(RenderingHints.KEY_ANTIALIASING,
            RenderingHints.VALUE_ANTIALIAS_ON);

    Shape card = new RoundRectangle2D.Double(10, 10, 200, 120, 16, 16);
    g2.setPaint(new GradientPaint(0, 10, Color.WHITE,
                                  0, 130, Color.LIGHT_GRAY));
    g2.fill(card);
    g2.setColor(Color.DARK_GRAY);
    g2.setStroke(new BasicStroke(2f));
    g2.draw(card);

    Path2D arrow = new Path2D.Double();
    arrow.moveTo(0, -10); arrow.lineTo(8, 10); arrow.lineTo(-8, 10);
    arrow.closePath();
    g2.translate(110, 70);                       // move origin
    g2.rotate(Math.toRadians(angle));           // spin around it
    g2.fill(arrow);

    g2.dispose();
}

Code Explained

RoundRectangle2D — shape object
GradientPaint — fill with a gradient
BasicStroke(2f) — 2 px outline
translate + rotate — transform the drawing

JavaFX Equivalent

  • Graphics2D → GraphicsContext (Canvas)
  • Shape → Rectangle, Circle, Path nodes
  • AffineTransform → Rotate, Translate, Scale
  • See Java 134

Prefer / Avoid

  • g.drawRect int APIs → Shape objects + draw/fill
  • undoing transforms by hand → g.create() copy + dispose()

⚠ Common Mistakes

  • Changing the stroke or transform on g itself — the border and children inherit it
  • Forgetting antialiasing — jagged diagonal lines and curves
  • Using int drawing calls for scaled drawings — rounding errors add up

✓ Tips & Best Practices

  • Build complex shapes with Area (add, subtract, intersect)
  • Use Shape.contains(point) for hit testing clicks
  • Keep model coordinates and use one AffineTransform to fit the view

Quick Summary

  • Graphics2D — the real drawing API
  • draw / fill + Shape — outlines and solids
  • Stroke / Paint — line style and fill
  • AffineTransform — move, rotate, scale
