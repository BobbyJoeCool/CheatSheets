Custom Painting

paintComponent · super.paintComponent · repaint · Graphics · getWidth / getHeight · getPreferredSize · paint vs paintComponent

Drawing Your Own Component

To draw charts, games or custom widgets, subclass JPanel (or JComponent) and override paintComponent(Graphics g). Call super.paintComponent(g) first to clear the background, then draw with g. Swing calls this method whenever the component needs repainting; you request a repaint with repaint(). Override getPreferredSize so layouts know how big the component wants to be.

Notes

  • Swing double-buffers JComponents by default
  • repaint() calls are merged into one paint
  • Paint from state; don't change state in paint

EDT Check

  • paintComponent runs on the EDT: keep it fast
  • Never call paintComponent yourself; call repaint()
  • repaint() is safe from any thread

Bar Chart Component

class BarChart extends JPanel {
    private List<Integer> values = List.of();

    void setValues(List<Integer> v) {
        values = List.copyOf(v);
        repaint();                             // request a redraw
    }
    @Override public Dimension getPreferredSize() {
        return new Dimension(320, 200);
    }
    @Override protected void paintComponent(Graphics g) {
        super.paintComponent(g);               // clear background
        if (values.isEmpty()) return;
        Graphics2D g2 = (Graphics2D) g.create();
        g2.setRenderingHint(RenderingHints.KEY_ANTIALIASING,
                RenderingHints.VALUE_ANTIALIAS_ON);
        int max = Collections.max(values), w = getWidth() / values.size();
        for (int i = 0; i < values.size(); i++) {
            int h = values.get(i) * (getHeight() - 10) / max;
            g2.setColor(UIManager.getColor("Component.accentColor"));
            g2.fillRect(i * w + 2, getHeight() - h, w - 4, h);
        }
        g2.dispose();
    }
}

Code Explained

super.paintComponent(g) — background first
g.create() / dispose() — private copy
getWidth() / getHeight() — current size
repaint() — after the data changes

JavaFX Equivalent

  • paintComponent → Canvas + GraphicsContext
  • or shapes in a Pane (retained mode)
  • repaint() → redraw the canvas yourself
  • See Java 134

Prefer / Avoid

  • overriding paint → override paintComponent
  • getGraphics() and drawing from a listener → update state, call repaint()

⚠ Common Mistakes

  • Skipping super.paintComponent — old drawings smear across the panel
  • Drawing with getGraphics() — your drawing vanishes on the next repaint
  • Loading images or computing data inside paintComponent — runs on every frame

✓ Tips & Best Practices

  • Precompute shapes when data changes, not when painting
  • Use theme colors from UIManager so the chart fits dark mode
  • Repaint only changed regions for smooth animation

Quick Summary

  • paintComponent — override to draw
  • super.paintComponent — clear first
  • repaint() — ask Swing to redraw
  • getPreferredSize — tell layouts your size
