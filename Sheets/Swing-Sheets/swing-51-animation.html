Animation & Game Loops

Timer-driven animation · delta time · repaint(Rectangle) · double buffering · Toolkit.sync · key state for games

Moving Things Smoothly

Swing animation is a Swing `Timer` that updates state and calls repaint() about 60 times a second. Use delta time (time since the last tick) so speed doesn't depend on frame rate. For games, track which keys are held in a set updated by key bindings, and read that set each tick. JComponent is already double-buffered, so frames don't flicker.

Notes

  • 16 ms ≈ 60 fps; Swing timing isn't exact
  • Toolkit.sync() smooths frames on Linux
  • Stop the timer when the panel is hidden

EDT Check

  • Drive frames with a Swing Timer, not a while loop on the EDT
  • A separate game thread must hand state to the EDT safely

Bouncing Ball with Delta Time

class Bounce extends JPanel {
    private double x = 50, y = 50, vx = 180, vy = 140;  // px/second
    private long last = System.nanoTime();
    private final Timer timer = new Timer(16, e -> tick());

    Bounce() { timer.start(); }

    private void tick() {
        long now = System.nanoTime();
        double dt = (now - last) / 1e9;                  // seconds
        last = now;
        x += vx * dt; y += vy * dt;
        if (x < 0 || x > getWidth() - 20)  vx = -vx;
        if (y < 0 || y > getHeight() - 20) vy = -vy;
        repaint();
        Toolkit.getDefaultToolkit().sync();             // Linux
    }
    @Override protected void paintComponent(Graphics g) {
        super.paintComponent(g);
        ((Graphics2D) g).fill(new Ellipse2D.Double(x, y, 20, 20));
    }
    @Override public void removeNotify() {
        timer.stop(); super.removeNotify();
    }
}

Code Explained

Timer(16, …) — ~60 ticks per second
dt — move by speed × elapsed time
repaint() — draw the new frame
removeNotify — stop when removed

JavaFX Equivalent

  • Swing Timer → AnimationTimer.handle(now)
  • tweens → TranslateTransition, Timeline
  • dt → compute from now nanoseconds
  • See Java 129

Prefer / Avoid

  • fixed step per tick (x += 3) → speed × delta time
  • KeyListener for game input → key bindings that fill a pressed-keys set

⚠ Common Mistakes

  • while (true) { …; Thread.sleep(16); } on the EDT — nothing ever paints
  • Moving a fixed amount per tick — the game runs faster on fast machines
  • Leaving the timer running after the panel is closed — CPU stays busy

✓ Tips & Best Practices

  • Clamp dt (e.g. max 0.05 s) so a pause doesn't teleport objects
  • Separate update and draw: state in tick, pixels in paintComponent
  • Use easing functions for UI animations (fade, slide)

Quick Summary

  • Swing Timer — the animation clock
  • delta time — frame-rate-independent motion
  • repaint() — draw each frame
  • key-state set — smooth game input
