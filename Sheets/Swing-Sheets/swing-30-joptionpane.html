JOptionPane

showMessageDialog · showConfirmDialog · showInputDialog · showOptionDialog · message types · return values

Ready-Made Dialogs

JOptionPane covers the common dialogs in one line: a message with an OK button, a Yes/No/Cancel question, a text or choice input, and custom button sets. All show…Dialog methods are modal: the call blocks until the user answers and then returns the answer. Pass the parent component so the dialog centers over the right window.

Notes

  • Parent null centers on the screen
  • Message can be a String, Component or Object[]
  • Closing with the X returns CLOSED_OPTION

EDT Check

  • Show dialogs from the EDT only
  • Modal dialogs block your code but keep the EDT painting
  • From a worker, show errors in done()

Message, Confirm, Input, Options

JOptionPane.showMessageDialog(frame, "Export finished.");
JOptionPane.showMessageDialog(frame, ex.getMessage(),
        "Export failed", JOptionPane.ERROR_MESSAGE);

int answer = JOptionPane.showConfirmDialog(frame,
        "Save changes to report.csv?", "Unsaved changes",
        JOptionPane.YES_NO_CANCEL_OPTION, JOptionPane.WARNING_MESSAGE);
if (answer == JOptionPane.YES_OPTION) save();
else if (answer == JOptionPane.CANCEL_OPTION
      || answer == JOptionPane.CLOSED_OPTION) return;

String name = JOptionPane.showInputDialog(frame, "Folder name:", "New");
if (name != null && !name.isBlank()) createFolder(name);   // null = cancel

Object[] choices = {"Overwrite", "Keep Both", "Skip"};
int pick = JOptionPane.showOptionDialog(frame, "File exists.",
        "Copy", JOptionPane.DEFAULT_OPTION, JOptionPane.QUESTION_MESSAGE,
        null, choices, choices[1]);                        // default
if (pick == 0) overwrite();

Code Explained

showMessageDialog — info with OK
showConfirmDialog — returns an *_OPTION int
showInputDialog — null when cancelled
showOptionDialog — your own button labels

JavaFX Equivalent

  • JOptionPane → Alert + showAndWait()
  • input → TextInputDialog / ChoiceDialog
  • returns Optional<ButtonType>
  • See Java 128

Prefer / Avoid

  • Yes/No for destructive actions → verb buttons ("Delete", "Cancel")
  • null parent → pass the owning frame or component

⚠ Common Mistakes

  • Not handling CLOSED_OPTION — closing the dialog is treated like "No"
  • Not checking showInputDialog for null — NullPointerException on cancel
  • Showing a dialog from a background thread — random painting bugs and focus problems

✓ Tips & Best Practices

  • Pass a JPanel as the message to build a small custom form
  • Wrap long text in <html><body width='300'> so it wraps
  • Use verbs on buttons for clearer choices

Quick Summary

  • showMessageDialog — tell
  • showConfirmDialog — ask yes/no
  • showInputDialog — ask for a value
  • showOptionDialog — custom buttons
