Sheet 53

Desktop Integration

Desktop.browse · Desktop.open · Taskbar · SystemTray · TrayIcon · setAboutHandler · SplashScreen

Fitting In With the OS

java.awt.Desktop opens URLs in the browser, files in their default apps and new emails. Since Java 9 it also handles macOS menu items like About, Preferences and Quit. Taskbar sets dock badges and progress, SystemTray adds a tray icon with a menu, and a SplashScreen image shows while the JVM starts.

Notes

  • Always check isSupported(Action) first
  • SystemTray is missing on some Linux desktops
  • Splash: SplashScreen-Image: in the JAR manifest

EDT Check

  • Desktop.browse / open can block: call them off the EDT
  • TrayIcon listeners run on the EDT

Browser, macOS Menu, Dock and Tray

Desktop d = Desktop.getDesktop();
if (d.isSupported(Desktop.Action.BROWSE))
    CompletableFuture.runAsync(() -> {
        try { d.browse(URI.create("https://example.com/help")); }
        catch (IOException e) { log.warn("browse failed", e); }
    });

if (d.isSupported(Desktop.Action.APP_QUIT_HANDLER))
    d.setQuitHandler((e, response) -> {
        if (confirmQuit()) response.performQuit();
        else response.cancelQuit();
    });

if (Taskbar.isTaskbarSupported())
    Taskbar.getTaskbar().setIconBadge("3");        // dock badge

if (SystemTray.isSupported()) {
    PopupMenu menu = new PopupMenu();
    MenuItem open = new MenuItem("Open");
    open.addActionListener(e -> frame.setVisible(true));
    menu.add(open);
    TrayIcon tray = new TrayIcon(trayImage, "Inventory", menu);
    tray.setImageAutoSize(true);
    SystemTray.getSystemTray().add(tray);          // throws AWTException
}

Code Explained

isSupported — check before calling
runAsync — keep browse off the EDT
setQuitHandler — macOS Quit (also About, Prefs)
TrayIcon — AWT PopupMenu menu

JavaFX Equivalent

  • Desktop.browse → getHostServices().showDocument
  • tray → still AWT SystemTray
  • Taskbar → same AWT API
  • See Java 126

Prefer / Avoid

  • Runtime.exec("open …") → Desktop.open(file)
  • com.apple.eawt classes → Desktop handlers (Java 9+)

⚠ Common Mistakes

  • Calling browse without checking support — UnsupportedOperationException on headless Linux
  • Calling Desktop methods on the EDT — can freeze while the OS launches an app
  • Adding a tray icon without a way to exit — users can't quit the app

✓ Tips & Best Practices

  • Set apple.awt.application.name early for the macOS menu title
  • Add SplashScreen-Image in the manifest for an instant splash
  • Remove the tray icon on exit with SystemTray.remove

Quick Summary

  • Desktop — browser, files, mail, macOS menus
  • isSupported — always check
  • Taskbar — badges and progress
  • SystemTray — tray icon + menu
