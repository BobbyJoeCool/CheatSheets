JTable Basics

JTable · DefaultTableModel · column names · setAutoCreateRowSorter · setFillsViewportHeight · getSelectedRow · table header

Tabular Data

JTable shows rows and columns from a TableModel. For quick tables, DefaultTableModel stores Object[] rows and column names. Put the table in a JScrollPane so the header shows and the body scrolls. Turning on the auto row sorter gives click-to-sort headers, and then view and model row indexes can differ (sheet 37).

Notes

  • The header only shows inside a scroll pane
  • DefaultTableModel cells are editable by default
  • Real apps usually use a custom model (sheet 36)

EDT Check

  • addRow / setValueAt on the EDT only
  • From a worker, publish rows and add them in process

Quick Table

String[] cols = {"SKU", "Name", "Qty", "Price"};
DefaultTableModel model = new DefaultTableModel(cols, 0) {
    @Override public Class<?> getColumnClass(int c) {
        return switch (c) { case 2 -> Integer.class;
                            case 3 -> BigDecimal.class;
                            default -> String.class; };
    }
    @Override public boolean isCellEditable(int r, int c) {
        return c == 2; }                      // only Qty
};
model.addRow(new Object[]{"A-100", "Widget", 12, new BigDecimal("4.50")});

JTable table = new JTable(model);
table.setAutoCreateRowSorter(true);           // click headers to sort
table.setFillsViewportHeight(true);           // drop target fills area
table.setSelectionMode(ListSelectionModel.SINGLE_SELECTION);
table.getColumnModel().getColumn(1).setPreferredWidth(220);
frame.add(new JScrollPane(table));

int view = table.getSelectedRow();            // -1 if none
if (view >= 0) {
    int row = table.convertRowIndexToModel(view);
    String sku = (String) model.getValueAt(row, 0);
}

Code Explained

getColumnClass — numbers align and sort right
isCellEditable — only Qty editable
setAutoCreateRowSorter — sortable headers
convertRowIndexToModel — view → model row

JavaFX Equivalent

  • JTable → TableView<T>
  • columns → TableColumn + setCellValueFactory
  • model → ObservableList<T>
  • See Java 128

Prefer / Avoid

  • DefaultTableModel of Object[] for real data → AbstractTableModel over records
  • getValueAt(table.getSelectedRow(), …) → convert to the model index first

⚠ Common Mistakes

  • Adding the table without a scroll pane — no header, no scrolling
  • Using view row indexes on the model after sorting — you read the wrong row
  • Leaving every DefaultTableModel cell editable — double-click edits your IDs

✓ Tips & Best Practices

  • Always override getColumnClass so numbers right-align and sort as numbers
  • Set preferred widths for text-heavy columns
  • Turn on setFillsViewportHeight for drag and drop onto empty space
