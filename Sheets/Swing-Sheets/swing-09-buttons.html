Sheet 09

Buttons

JButton · addActionListener · setMnemonic · setToolTipText · setEnabled · setDefaultButton · JToggleButton

Clickable Commands

JButton fires an ActionEvent when clicked, when Space is pressed while it has focus, or when Enter is pressed and it is the window's default button. All buttons extend AbstractButton, which also covers toggle buttons, check boxes, radio buttons and menu items, so text, icons, mnemonics and enabling work the same way on every one of them.

Notes

  • A button can share an Action (sheet 23) with menus and toolbars
  • setEnabled(false) greys it out and blocks events
  • JToggleButton stays pressed: read isSelected()

Buttons in a Form

JButton save = new JButton("Save");
save.setMnemonic(KeyEvent.VK_S);              // Alt+S
save.setToolTipText("Save changes (Ctrl+S)");
save.addActionListener(e -> saveRecord());

JButton cancel = new JButton("Cancel");
cancel.addActionListener(e -> dialog.dispose());

dialog.getRootPane().setDefaultButton(save);  // Enter = Save

JButton delete = new JButton("Delete", trashIcon);
delete.setEnabled(false);                     // until a row is selected
table.getSelectionModel().addListSelectionListener(
    e -> delete.setEnabled(table.getSelectedRow() >= 0));

JToggleButton bold = new JToggleButton("B");
bold.addItemListener(e -> setBold(bold.isSelected()));

JPanel bar = new JPanel(new FlowLayout(FlowLayout.TRAILING));
bar.add(save); bar.add(cancel);

Code Explained

setMnemonic — Alt+key shortcut, underlined
setDefaultButton — Enter triggers it
setEnabled — tie to selection state
JToggleButton — on/off state

JavaFX Equivalent

  • JButton → Button + setOnAction
  • setDefaultButton → button.setDefaultButton(true)
  • JToggleButton → ToggleButton
  • See Java 128

Prefer / Avoid

  • one listener with if (e.getSource() == a) → one lambda per button
  • hiding unusable buttons → disable them and explain with a tooltip

⚠ Common Mistakes

  • Running slow work in the click handler — the button stays pressed and the app freezes
  • Forgetting a default button in dialogs — users expect Enter to confirm
  • Mnemonic letter not in the text — nothing gets underlined, so users never find it

✓ Tips & Best Practices

  • Order dialog buttons by platform convention (OK left of Cancel on Windows)
  • Disable a button while its action runs to stop double submits
  • Use putClientProperty("JButton.buttonType", ...) with FlatLaf for styles

Quick Summary

  • addActionListener — what a click does
  • setMnemonic / default button — keyboard access
  • setEnabled — reflect whether the action is possible
  • AbstractButton — shared base of all buttons
