Split Panes & Scroll Panes

JSplitPane · setDividerLocation · setResizeWeight · setOneTouchExpandable · JViewport · setRowHeaderView · scrollRectToVisible

Resizable Areas and Scrolling

JSplitPane puts two components side by side (or stacked) with a draggable divider; resizeWeight decides which side gets extra space when the window grows. JScrollPane shows part of a large component through a JViewport, with scroll bars, optional row and column headers and corner components. Nest split panes for three-pane layouts.

Notes

  • Divider location in pixels only works after layout
  • Minimum sizes limit how far the divider moves
  • Scrollable components control unit/block increments

Three-Pane Mail Layout

JSplitPane inner = new JSplitPane(JSplitPane.VERTICAL_SPLIT,
        new JScrollPane(messageTable), new JScrollPane(preview));
inner.setResizeWeight(0.4);                   // top gets 40% of growth

JSplitPane outer = new JSplitPane(JSplitPane.HORIZONTAL_SPLIT,
        new JScrollPane(folderTree), inner);
outer.setOneTouchExpandable(true);            // little arrows
outer.setContinuousLayout(true);              // redraw while dragging
frame.add(outer);
frame.pack();
SwingUtilities.invokeLater(() -> outer.setDividerLocation(0.25));

JScrollPane sp = new JScrollPane(codeArea);
sp.setRowHeaderView(new LineNumbers(codeArea));   // gutter
sp.getVerticalScrollBar().setUnitIncrement(16);   // faster wheel
sp.setHorizontalScrollBarPolicy(
        ScrollPaneConstants.HORIZONTAL_SCROLLBAR_NEVER);

codeArea.scrollRectToVisible(codeArea.modelToView2D(pos).getBounds());
sp.getViewport().setViewPosition(new Point(0, 0));     // jump to top

Code Explained

setResizeWeight(0.4) — share of extra space
setDividerLocation(0.25) — after layout
setRowHeaderView — line-number gutter
setUnitIncrement — scroll speed

JavaFX Equivalent

  • JSplitPane → SplitPane + setDividerPositions
  • JScrollPane → ScrollPane
  • row header → no direct equivalent
  • See Java 127

Prefer / Avoid

  • setDividerLocation(0.25) before showing → call it after pack/visible
  • default slow wheel scrolling → setUnitIncrement(16)

⚠ Common Mistakes

  • Setting a proportional divider location before the split pane has a size — ignored
  • No minimum sizes — users drag a pane down to nothing and can't find it
  • Putting a scroll pane inside a scroll pane — double scroll bars and broken wheel scrolling

✓ Tips & Best Practices

  • Save divider locations in Preferences and restore them
  • Remove scroll pane borders for flat layouts: setBorder(null)
  • Implement Scrollable on custom views for smart scrolling

Quick Summary

  • JSplitPane — two panes + draggable divider
  • setResizeWeight — who gets extra space
  • JScrollPane / JViewport — scroll a big component
  • row/column headers — gutters, rulers
