Other Languages and Regions

Keep every user-facing string in resource bundles (messages.properties, messages_de.properties) and load them with ResourceBundle.getBundle. Use MessageFormat for sentences with values, and the java.text/java.time formatters for numbers and dates. For Arabic or Hebrew, flip the whole UI with applyComponentOrientation; layouts that use LEADING/LINE_START follow automatically.

Notes

  • .properties files are UTF-8 since Java 9
  • Missing keys throw MissingResourceException
  • Translations often run 30% longer: use layouts

Bundles, Messages and RTL

// messages.properties:     save=Save
//   items={0,choice,0#No items|1#One item|1<{0} items}
// messages_de.properties:  save=Speichern
Locale.setDefault(Locale.forLanguageTag("de-DE"));      // or user choice
ResourceBundle msg = ResourceBundle.getBundle("i18n.messages");

JButton save = new JButton(msg.getString("save"));      // "Speichern"
status.setText(MessageFormat.format(msg.getString("items"), count));

NumberFormat money = NumberFormat.getCurrencyInstance(); // 1.234,50 €
var date = DateTimeFormatter.ofLocalizedDate(FormatStyle.MEDIUM);
label.setText(money.format(total) + " · " + date.format(LocalDate.now()));

// Right-to-left (ar, he, fa)
var o = ComponentOrientation.getOrientation(Locale.getDefault());
frame.applyComponentOrientation(o);                     // whole tree

// Translate Swing's own strings (OK, Cancel in JOptionPane)
UIManager.put("OptionPane.okButtonText", msg.getString("ok"));

Code Explained

getBundle("i18n.messages") — picks the locale file
MessageFormat + choice — plurals
localized formatters — numbers, dates
applyComponentOrientation — mirror for RTL

JavaFX Equivalent

  • ResourceBundle → same, plus FXMLLoader.setResources
  • RTL → setNodeOrientation(RIGHT_TO_LEFT)
  • %key in FXML text attributes
  • See Java 131

Prefer / Avoid

  • string concatenation for sentences → MessageFormat patterns
  • LEFT / EAST constants → LEADING / LINE_END

⚠ Common Mistakes

  • Building sentences from pieces — word order differs between languages
  • Fixed-width buttons and labels — German and Finnish text gets cut off
  • Sorting names with String.compareTo — wrong order for accented letters; use Collator

✓ Tips & Best Practices

  • Pseudo-localize (wrap strings in [ ]) to find hard-coded text
  • Keep keys stable and descriptive (orders.empty.title)
  • Test an RTL locale to catch LEFT/RIGHT constants

Quick Summary

  • ResourceBundle — strings per locale
  • MessageFormat — sentences with values
  • locale formatters — numbers and dates
  • applyComponentOrientation — right-to-left
