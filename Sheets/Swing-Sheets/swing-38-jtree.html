JTree

DefaultMutableTreeNode · DefaultTreeModel · TreePath · TreeSelectionListener · expandPath · TreeCellRenderer · TreeWillExpandListener

Hierarchical Data

JTree shows a hierarchy such as folders or categories. The quick route is DefaultMutableTreeNode objects (each holds a user object) in a DefaultTreeModel. Selections and expansions are expressed as TreePaths from the root to a node. For big or slow data, load children only when a node is about to expand.

Notes

  • Nodes display userObject.toString()
  • Changes must go through the model to show
  • setRootVisible(false) hides the root

EDT Check

  • Insert and remove nodes through the model on the EDT
  • Lazy-load children with a SwingWorker, insert in done()

Folder Tree with Lazy Loading

DefaultMutableTreeNode root = new DefaultMutableTreeNode(rootDir);
DefaultTreeModel model = new DefaultTreeModel(root);
JTree tree = new JTree(model);
tree.setRootVisible(false);
tree.setShowsRootHandles(true);
root.add(new DefaultMutableTreeNode("Loading…"));   // placeholder child

tree.addTreeWillExpandListener(new TreeWillExpandListener() {
    public void treeWillExpand(TreeExpansionEvent e) {
        var node = (DefaultMutableTreeNode)
                e.getPath().getLastPathComponent();
        loadChildrenAsync(model, node);              // worker → insert
    }
    public void treeWillCollapse(TreeExpansionEvent e) { }
});

tree.addTreeSelectionListener(e -> {
    var node = (DefaultMutableTreeNode)
            tree.getLastSelectedPathComponent();
    if (node != null) showDetails(node.getUserObject());
});

model.insertNodeInto(new DefaultMutableTreeNode(dir), parent,
        parent.getChildCount());                     // fires the event
tree.scrollPathToVisible(new TreePath(child.getPath()));

Code Explained

DefaultTreeModel — holds nodes, fires events
placeholder child — shows the expand handle
getLastSelectedPathComponent — the selected node
insertNodeInto — add and notify

JavaFX Equivalent

  • JTree → TreeView<T>
  • DefaultMutableTreeNode → TreeItem<T>
  • lazy load → override TreeItem.getChildren
  • See Java 128

Prefer / Avoid

  • node.add(child) after display → model.insertNodeInto(...)
  • loading the whole tree up front → load on expand

⚠ Common Mistakes

  • Calling node.add on a showing tree — the tree doesn't update until something reloads it
  • Calling model.reload() for small changes — collapses everything the user opened
  • Loading big folders on the EDT in treeWillExpand — freezes on network drives

✓ Tips & Best Practices

  • Use nodeChanged(n) after editing a node's user object
  • Customize icons with DefaultTreeCellRenderer.setLeafIcon etc.
  • Remember expanded paths and restore them after a refresh

Quick Summary

  • DefaultMutableTreeNode + DefaultTreeModel — quick tree
  • TreePath — root-to-node path
  • model methods — change the tree and notify
  • TreeWillExpandListener — lazy loading
