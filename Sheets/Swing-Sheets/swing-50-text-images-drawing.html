Text and Pictures on a Canvas

drawString(text, x, y) places text by its baseline, not its top. FontMetrics gives ascent, descent and string widths so you can center or align text precisely. drawImage draws an Image at a position or scaled to a size. An offscreen BufferedImage lets you render once and reuse it, and AlphaComposite controls transparency.

Notes

  • y in drawString is the baseline
  • Text antialiasing is a separate hint
  • BufferedImage.createGraphics() must be disposed

Centered Label and Cached Background

private BufferedImage background;                     // cache

@Override protected void paintComponent(Graphics g) {
    super.paintComponent(g);
    Graphics2D g2 = (Graphics2D) g.create();
    if (background == null || background.getWidth() != getWidth())
        background = renderBackground(getWidth(), getHeight());
    g2.drawImage(background, 0, 0, null);

    g2.setRenderingHint(RenderingHints.KEY_TEXT_ANTIALIASING,
            RenderingHints.VALUE_TEXT_ANTIALIAS_ON);
    g2.setFont(getFont().deriveFont(Font.BOLD, 24f));
    FontMetrics fm = g2.getFontMetrics();
    String s = "72%";
    int x = (getWidth() - fm.stringWidth(s)) / 2;
    int y = (getHeight() - fm.getHeight()) / 2 + fm.getAscent();
    g2.drawString(s, x, y);                           // baseline at y

    g2.setComposite(AlphaComposite.SrcOver.derive(0.4f)); // 40%
    g2.drawImage(mark, getWidth() - 70, getHeight() - 70, 64, 64, null);
    g2.dispose();
}

Code Explained

cached BufferedImage — render the costly part once
stringWidth / getAscent — center text
drawString(s, x, y) — y is the baseline
AlphaComposite 0.4 — 40% opacity

JavaFX Equivalent

  • drawString → gc.fillText or Text nodes
  • FontMetrics → Text.getLayoutBounds()
  • AlphaComposite → setGlobalAlpha / setOpacity
  • See Java 134

Prefer / Avoid

  • drawString at the top y → add fm.getAscent()
  • redrawing a static background every frame → cache in a BufferedImage

⚠ Common Mistakes

  • Using the top of the text as y — text draws above where you expect
  • Measuring text with a different font than you draw with — misaligned centering
  • Rebuilding the cached image every paint — check size first

✓ Tips & Best Practices

  • Use TextLayout for precise bounds and hit testing
  • Create offscreen images with createCompatibleImage
  • Pass this as the ImageObserver for async-loaded images

Quick Summary

  • drawString — y is the baseline
  • FontMetrics — measure to align
  • drawImage — draw or scale an image
  • BufferedImage — offscreen cache
