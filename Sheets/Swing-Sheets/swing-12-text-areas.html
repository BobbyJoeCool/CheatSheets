Multi-Line Plain Text

JTextArea edits or shows multiple lines of plain text in one font. It doesn't scroll by itself: put it in a JScrollPane. Rows and columns set its preferred size. Turn on line wrapping with setLineWrap(true) and wrap at word boundaries with setWrapStyleWord(true). For styled text or HTML use JTextPane or JEditorPane (sheet 42).

Notes

  • append adds text at the end
  • Tab moves focus only if you change focus keys
  • Huge logs: trim old lines to keep it fast

Notes Field and Log

JTextArea notes = new JTextArea(6, 40);       // rows, columns
notes.setLineWrap(true);
notes.setWrapStyleWord(true);                 // wrap at spaces
JScrollPane notesScroll = new JScrollPane(notes);

JTextArea log = new JTextArea(10, 60);
log.setEditable(false);
log.setFont(new Font(Font.MONOSPACED, Font.PLAIN, 12));

void logLine(String s) {                      // call on the EDT
    log.append(s + "\n");
    log.setCaretPosition(log.getDocument().getLength()); // autoscroll
}

// Keep only the last 1000 lines
int extra = log.getLineCount() - 1000;
if (extra > 0) log.replaceRange("", 0, log.getLineEndOffset(extra - 1));

String text = notes.getText();
int line = notes.getLineOfOffset(notes.getCaretPosition());

Code Explained

JTextArea(6, 40) — preferred rows and columns
setWrapStyleWord — wrap whole words
setCaretPosition(length) — scroll to the end
replaceRange — delete old lines

JavaFX Equivalent

  • JTextArea → TextArea
  • setLineWrap → setWrapText(true)
  • append → appendText
  • See Java 128

Prefer / Avoid

  • text area without a scroll pane → wrap it in JScrollPane
  • setText(getText() + s) → append(s)

⚠ Common Mistakes

  • Rebuilding the whole text with setText for each log line — slow and resets the caret
  • Turning on line wrap but leaving the horizontal scrollbar policy — wrap and scroll fight
  • Appending from a worker thread — use publish/process or invokeLater

✓ Tips & Best Practices

  • Give log areas a monospaced font for aligned columns
  • Use DefaultCaret.ALWAYS_UPDATE to keep auto-scrolling
  • Set rows/columns rather than pixel sizes

Quick Summary

  • JTextArea — multi-line plain text
  • JScrollPane — required for scrolling
  • setLineWrap + setWrapStyleWord — word wrap
  • append + caret — log output
