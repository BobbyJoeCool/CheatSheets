File & Color Choosers

JFileChooser · showOpenDialog · showSaveDialog · FileNameExtensionFilter · setMultiSelectionEnabled · JColorChooser · FileDialog

Picking Files and Colors

JFileChooser is Swing's file dialog: open, save or pick a folder, with filters and multi-select. It returns APPROVE_OPTION when the user confirms. JColorChooser.showDialog returns a Color or null. On macOS, the AWT FileDialog gives the native Finder dialog, which users often prefer.

Notes

  • Reuse one chooser to remember the last folder
  • Save dialogs don't add extensions for you
  • Directory mode: DIRECTORIES_ONLY

Open, Save and Color

JFileChooser chooser = new JFileChooser();          // keep as a field
chooser.setFileFilter(new FileNameExtensionFilter("CSV files", "csv"));
chooser.setMultiSelectionEnabled(true);
if (chooser.showOpenDialog(frame) == JFileChooser.APPROVE_OPTION) {
    for (File f : chooser.getSelectedFiles()) importCsv(f.toPath());
}

chooser.setMultiSelectionEnabled(false);
chooser.setSelectedFile(new File("report.csv"));
if (chooser.showSaveDialog(frame) == JFileChooser.APPROVE_OPTION) {
    Path out = chooser.getSelectedFile().toPath();
    if (!out.toString().endsWith(".csv")) out = Path.of(out + ".csv");
    if (Files.exists(out) && !confirmOverwrite(out)) return;
    export(out);
}

Color c = JColorChooser.showDialog(frame, "Highlight", Color.YELLOW);
if (c != null) highlighter.setColor(c);

FileDialog fd = new FileDialog(frame, "Open", FileDialog.LOAD); // native
fd.setVisible(true);

Code Explained

FileNameExtensionFilter — by extension
APPROVE_OPTION — user confirmed
add .csv + overwrite check — your job
JColorChooser — null on cancel

JavaFX Equivalent

  • JFileChooser → FileChooser (native)
  • folder mode → DirectoryChooser
  • JColorChooser → ColorPicker
  • See Java 128

Prefer / Avoid

  • new chooser per click → one reused chooser (remembers folder)
  • File APIs after choosing → convert with toPath() and use Files

⚠ Common Mistakes

  • Ignoring the return value — getSelectedFile() may hold a stale file after Cancel
  • Not adding the extension on save — users get files Excel won't open by double-click
  • Silently overwriting existing files on save — always confirm

✓ Tips & Best Practices

  • Remember the last folder in Preferences between runs
  • Use FileDialog on macOS for the native look
  • Read big chosen files with a SwingWorker

Quick Summary

  • JFileChooser — open, save, pick folder
  • APPROVE_OPTION — check before reading
  • filters + extension + overwrite check — save dialogs
  • JColorChooser.showDialog — pick a color
