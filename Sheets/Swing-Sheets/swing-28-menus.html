Menu Bars

A window's menu bar is a JMenuBar holding JMenus, which hold JMenuItems, separators and nested submenus. Menu items are buttons, so they take Actions, mnemonics and icons. Accelerators (Ctrl+S, Cmd+S) trigger an item without opening the menu and are shown next to its text. On macOS, a system property moves the bar to the top of the screen.

Notes

  • Set the bar with frame.setJMenuBar(bar)
  • Mnemonic: Alt+letter opens a menu (Windows/Linux)
  • macOS menus have no mnemonics; accelerators use Cmd

File and View Menus

System.setProperty("apple.laf.useScreenMenuBar", "true"); // before UI
int menuKey = Toolkit.getDefaultToolkit().getMenuShortcutKeyMaskEx();

JMenu file = new JMenu("File");
file.setMnemonic(KeyEvent.VK_F);
JMenuItem open = new JMenuItem("Open…");
open.setAccelerator(KeyStroke.getKeyStroke(KeyEvent.VK_O, menuKey));
open.addActionListener(e -> openFile());
file.add(open);
file.add(new JMenuItem(saveAction));          // Action-based item
file.addSeparator();
JMenu recent = new JMenu("Open Recent");      // submenu
file.add(recent);

JMenu view = new JMenu("View");
JCheckBoxMenuItem grid = new JCheckBoxMenuItem("Show Grid", true);
grid.addItemListener(e -> canvas.setGrid(grid.isSelected()));
view.add(grid);

JMenuBar bar = new JMenuBar();
bar.add(file); bar.add(view);
frame.setJMenuBar(bar);

Code Explained

useScreenMenuBar — macOS top-of-screen bar
setAccelerator — shortcut shown in the menu
new JMenuItem(action) — shares text, icon, state
JCheckBoxMenuItem — on/off item

JavaFX Equivalent

  • JMenuBar → MenuBar (setUseSystemMenuBar)
  • JMenuItem → MenuItem + setOnAction
  • JCheckBoxMenuItem → CheckMenuItem
  • See Java 128

Prefer / Avoid

  • InputEvent.CTRL_DOWN_MASK → getMenuShortcutKeyMaskEx()
  • the same logic on item and button → one shared Action

⚠ Common Mistakes

  • Setting useScreenMenuBar after creating any Swing component — ignored on macOS
  • Adding the bar with frame.add(bar) — it lands in the content pane, not the menu area
  • Forgetting … on items that open a dialog — the convention tells users more input follows

✓ Tips & Best Practices

  • Fill dynamic submenus (Open Recent) in a MenuListener.menuSelected
  • Use JRadioButtonMenuItem + ButtonGroup for view modes
  • Keep File / Edit / View / Help order users expect

Quick Summary

  • JMenuBar → JMenu → JMenuItem — the structure
  • setAccelerator — keyboard shortcut
  • frame.setJMenuBar — attach to the window
  • check / radio items — toggles in menus
