Combo Boxes & Spinners

JComboBox<E> · DefaultComboBoxModel · setEditable · getSelectedItem · JSpinner · SpinnerNumberModel · SpinnerDateModel

Pick From a List or Step a Value

JComboBox<E> shows one choice from a drop-down list. It's backed by a ComboBoxModel; DefaultComboBoxModel lets you add and remove items, and setEditable(true) lets users type their own value. JSpinner steps a value up and down with arrow buttons; its model decides whether it's a number, a date or one item from a list.

Notes

  • Items display with toString() unless you add a renderer
  • getSelectedItem() returns Object; cast it
  • Combo ActionListener fires on every selection

Choices and Steppers

record Country(String code, String name) {
    @Override public String toString() { return name; }  // display
}
DefaultComboBoxModel<Country> model = new DefaultComboBoxModel<>();
model.addElement(new Country("US", "United States"));
model.addElement(new Country("CA", "Canada"));
JComboBox<Country> country = new JComboBox<>(model);
country.addActionListener(e -> {
    Country c = (Country) country.getSelectedItem();
    loadRegions(c.code());
});

JComboBox<String> size = new JComboBox<>(new String[]{"S", "M", "L"});
size.setSelectedIndex(1);
size.setEditable(true);                       // typed values allowed

JSpinner qty = new JSpinner(new SpinnerNumberModel(1, 1, 99, 1));
int n = (Integer) qty.getValue();
qty.addChangeListener(e -> updateTotal());

JSpinner date = new JSpinner(new SpinnerDateModel());
date.setEditor(new JSpinner.DateEditor(date, "yyyy-MM-dd"));

Code Explained

toString() — the text a plain combo shows
DefaultComboBoxModel — mutable list of items
SpinnerNumberModel(v, min, max, step) — bounded
DateEditor — format the date

JavaFX Equivalent

  • JComboBox → ComboBox / ChoiceBox
  • JSpinner → Spinner + value factory
  • renderer → setCellFactory
  • See Java 128

Prefer / Avoid

  • parallel arrays of ids and labels → a record with toString()
  • SpinnerDateModel for new code → LocalDate + a formatted field

⚠ Common Mistakes

  • Changing the model inside the combo's ActionListener — fires more events and can loop
  • Casting spinner values to the wrong type — SpinnerNumberModel(1.0, …) returns Double
  • Overriding toString() just for display in domain classes — prefer a renderer

✓ Tips & Best Practices

  • Use a ListCellRenderer (sheet 34) to show icons in combos
  • Use setPrototypeDisplayValue to size a combo without measuring every item
  • Commit a spinner's typed text with commitEdit() before reading

Quick Summary

  • JComboBox<E> — drop-down choice
  • DefaultComboBoxModel — add/remove items
  • JSpinner + model — step a value
  • getSelectedItem / getValue — read results
