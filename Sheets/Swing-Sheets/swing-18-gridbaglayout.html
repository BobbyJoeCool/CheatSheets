GridBagLayout

GridBagConstraints · gridx / gridy · gridwidth · weightx / weighty · fill · anchor · insets

Flexible Grids in the JDK

GridBagLayout places components in a grid where rows and columns can have different sizes, cells can span several columns, and extra space goes where the weights say. Each component is added with a GridBagConstraints object. It's verbose, but it's the most capable layout that ships with the JDK and the usual choice for forms when you can't add MigLayout.

Notes

  • All weights 0 → everything clumps in the center
  • Constraints are copied on add; reuse one object
  • fill stretches; anchor positions without stretching
  • Columns size to the widest preferred size in them

Label / Field Form

JPanel form = new JPanel(new GridBagLayout());
GridBagConstraints c = new GridBagConstraints();
c.insets = new Insets(4, 4, 4, 4);

String[] labels = {"Name", "Email", "Notes"};
JComponent[] fields = {nameFld, emailFld, new JScrollPane(notes)};
for (int row = 0; row < labels.length; row++) {
    c.gridx = 0; c.gridy = row;
    c.weightx = 0; c.fill = GridBagConstraints.NONE;
    c.anchor = GridBagConstraints.LINE_END;      // right-align label
    form.add(new JLabel(labels[row] + ":"), c);

    c.gridx = 1;
    c.weightx = 1;                               // field takes width
    c.fill = GridBagConstraints.HORIZONTAL;
    c.anchor = GridBagConstraints.LINE_START;
    form.add(fields[row], c);
}
c.gridy = labels.length - 1; c.weighty = 1;      // notes grows tall
c.fill = GridBagConstraints.BOTH;
form.add(fields[2], c);                          // re-add, new rules

Code Explained

gridx / gridy — cell position
weightx = 1 — column 1 gets extra width
fill = HORIZONTAL — stretch across the cell
insets — padding around each cell

JavaFX Equivalent

  • GridBagLayout → GridPane
  • gridwidth → GridPane.setColumnSpan
  • weights → ColumnConstraints.setHgrow
  • See Java 127

Prefer / Avoid

  • new GridBagConstraints(11 args) → set named fields on one reused object
  • huge GridBag screens → nest smaller panels or use MigLayout

⚠ Common Mistakes

  • Forgetting weights — the whole form floats in the middle of the window
  • Leaving fill set from the previous component — reused constraints carry every field over
  • Using gridwidth = REMAINDER and fixed gridx together — confusing results

✓ Tips & Best Practices

  • Write a tiny helper gbc(x, y) that returns preset constraints
  • Give only the main field column weightx = 1
  • Use BASELINE anchors so labels line up with field text

Quick Summary

  • GridBagConstraints — rules per component
  • weights — who gets extra space
  • fill vs anchor — stretch vs position
  • insets — cell padding
