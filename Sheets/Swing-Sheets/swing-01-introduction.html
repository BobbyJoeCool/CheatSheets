Introduction to Swing

AWT vs Swing · lightweight components · javax.swing · java.desktop module · pluggable look and feel · Swing vs JavaFX

What Swing Is

Swing is the GUI toolkit that ships with the JDK in the javax.swing package. It was added in Java 1.2 (1998) on top of AWT. AWT wraps native OS widgets (heavyweight); Swing paints its own components in Java (lightweight), so a JButton looks and behaves the same on every OS and can be restyled with a pluggable look and feel. Swing is stable and in maintenance mode: no new components, but it still ships with every JDK and runs IDEs, trading tools and many business apps.

Good to Know

  • Lives in the java.desktop module: requires java.desktop;
  • Swing is single-threaded: touch components only on the EDT (sheet 05)
  • Java set: Java 123–125 is the 3-page primer

Hello, Swing

import javax.swing.*;

public class Hello {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {   // build UI on the EDT
            JFrame frame = new JFrame("Hello");  // top-level window
            frame.add(new JLabel("Hello, Swing!",
                    SwingConstants.CENTER));      // into content pane
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            frame.setSize(300, 120);
            frame.setLocationRelativeTo(null);   // center on screen
            frame.setVisible(true);              // show it last
        });
    }
}
// javac Hello.java && java Hello
// or, single-file launch (Java 11+):  java Hello.java

Code Explained

invokeLater — run the lambda on the EDT
frame.add — goes into the content pane
EXIT_ON_CLOSE — quit when the window closes
setVisible(true) — last, after building

JavaFX Equivalent

  • JFrame → Stage + Scene
  • JLabel → Label
  • invokeLater → Application.launch + Platform.runLater
  • See Java 126

Prefer / Avoid

  • UI built straight in main → wrap it in invokeLater
  • AWT Button in a Swing UI → JButton

⚠ Common Mistakes

  • Building or changing components from main or a worker thread — causes random painting bugs; use invokeLater
  • Calling setVisible(true) before adding components — the window may show empty; build first, show last
  • Expecting native widgets — Swing draws its own; set a look and feel (sheet 44) for a native feel
