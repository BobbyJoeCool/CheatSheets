Text Fields

JTextField · setColumns · getText · JPasswordField · getPassword · JFormattedTextField · MaskFormatter

Single-Line Input

JTextField takes one line of text; its column count sets the preferred width. JPasswordField hides input and returns a char[] you can wipe after use. JFormattedTextField binds the text to a value through a formatter, such as a number format or a MaskFormatter for phone numbers, and only commits valid input. Pressing Enter fires an ActionEvent.

Notes

  • Text lives in a Document (sheet 27)
  • getText() never returns null
  • Formatted fields commit on Enter or focus loss

Fields and Validation

JTextField name = new JTextField(20);         // ~20 chars wide
name.addActionListener(e -> search(name.getText().strip()));

JPasswordField pw = new JPasswordField(16);
char[] secret = pw.getPassword();
try { login(user, secret); }
finally { Arrays.fill(secret, '\0'); }       // wipe after use

NumberFormat money = NumberFormat.getCurrencyInstance(Locale.US);
JFormattedTextField price = new JFormattedTextField(money);
price.setValue(19.99);
price.setColumns(8);
Number p = (Number) price.getValue();         // committed value

MaskFormatter phone = new MaskFormatter("(###) ###-####");
phone.setPlaceholderCharacter('_');
JFormattedTextField phoneFld = new JFormattedTextField(phone);

name.setText("");                             // clear
name.selectAll(); name.requestFocusInWindow();

Code Explained

JTextField(20) — preferred width in columns
getPassword() — char[], wipe after
getValue() — last valid committed value
MaskFormatter — fixed patterns: # digit

JavaFX Equivalent

  • JTextField → TextField
  • JPasswordField → PasswordField
  • JFormattedTextField → TextFormatter
  • See Java 128

Prefer / Avoid

  • new String(pw.getPassword()) → keep it a char[] and wipe it
  • parsing getText() by hand → JFormattedTextField.getValue()

⚠ Common Mistakes

  • Calling getPassword and converting to String — the password stays in memory until GC
  • Reading getText() on a formatted field — returns the raw text, not the committed value
  • Relying on setColumns for exact width — the layout manager has the final say

✓ Tips & Best Practices

  • Validate on submit and show the error next to the field
  • Right-align numbers: setHorizontalAlignment(TRAILING)
  • With FlatLaf, set placeholder text via JTextField.placeholderText

Quick Summary

  • JTextField — one line of text
  • JPasswordField — hidden input as char[]
  • JFormattedTextField — typed, validated value
  • Enter — fires ActionEvent
