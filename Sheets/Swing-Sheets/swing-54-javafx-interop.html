Mixing the Toolkits

OpenJFX's javafx-swing module connects the two toolkits. JFXPanel is a Swing component that hosts a JavaFX scene, which is useful for adding a WebView or JavaFX charts to a Swing app. SwingNode does the reverse. Each toolkit keeps its own UI thread, so every call across the boundary must hop to the other thread.

Notes

  • Needs OpenJFX's javafx.swing module
  • Creating a JFXPanel starts the JavaFX runtime
  • Swing apps: call setImplicitExit(false)

EDT Check

  • Swing: EDT · JavaFX: Application Thread
  • Swing → FX: Platform.runLater · FX → Swing: invokeLater

WebView Inside a Swing Window

// module-info: requires javafx.swing; requires javafx.web;
JFXPanel fxPanel = new JFXPanel();             // on the EDT
frame.add(fxPanel, BorderLayout.CENTER);
Platform.setImplicitExit(false);               // keep FX alive

Platform.runLater(() -> {                      // FX thread
    WebView web = new WebView();
    web.getEngine().load("https://example.com/docs");
    web.getEngine().titleProperty().addListener((obs, old, title) ->
        SwingUtilities.invokeLater(() -> frame.setTitle(title))); // back
    fxPanel.setScene(new Scene(web));
});

// The other way: a Swing table inside a JavaFX layout
SwingNode node = new SwingNode();
SwingUtilities.invokeLater(() -> node.setContent(new JScrollPane(table)));
borderPane.setCenter(node);

Code Explained

invokeLater — update Swing from FX
SwingNode — Swing in JavaFX

⚠ Common Mistakes

  • Touching JavaFX nodes from a Swing listener — IllegalStateException: Not on FX application thread
  • Closing the last JavaFX window without setImplicitExit(false) — FX shuts down for good
  • Waiting on one thread for the other with invokeAndWait — easy deadlock

✓ Tips & Best Practices

  • Use JFXPanel + WebView for modern HTML help inside Swing
  • Convert images with SwingFXUtils.toFXImage
  • Migrate one screen at a time
