Sheet 56

Accessibility

AccessibleContext · setAccessibleName · setAccessibleDescription · setLabelFor · mnemonics · keyboard-only use · screen readers

Usable by Everyone

Swing exposes components to screen readers through the Java Accessibility API: every component has an AccessibleContext with a name, description and role. Standard components fill most of it in; icon-only buttons, custom painted components and fields without labels need help. Keyboard access matters just as much: every action reachable without a mouse, a sensible Tab order and visible focus.

Notes

  • Windows needs the Java Access Bridge enabled
  • macOS VoiceOver works through the JDK
  • Check contrast in both light and dark themes

Names, Labels and Keyboard Access

JLabel nameLbl = new JLabel("Name:");
nameLbl.setDisplayedMnemonic('N');
nameLbl.setLabelFor(nameFld);                    // name comes from label

JButton del = new JButton(trashIcon);            // icon only
del.setToolTipText("Delete selected rows");
del.getAccessibleContext().setAccessibleName("Delete");
del.getAccessibleContext().setAccessibleDescription(
        "Deletes the selected rows after confirmation");

chart.setFocusable(true);                        // custom component
chart.getAccessibleContext().setAccessibleName("Monthly sales chart");
chart.getAccessibleContext().setAccessibleDescription(summaryText());

// Keyboard: every action reachable without a mouse
getRootPane().setDefaultButton(okBtn);
table.getInputMap().put(KeyStroke.getKeyStroke("DELETE"), "delete");
table.getActionMap().put("delete", deleteAction);

// java -Djavax.accessibility.assistive_technologies=... (rare)
// Windows: jabswitch -enable   (turn on Java Access Bridge)

Code Explained

setLabelFor — screen reader reads the label
setAccessibleName — for icon-only buttons
setAccessibleDescription — longer help
key bindings — no mouse needed

JavaFX Equivalent

  • AccessibleContext → setAccessibleText
  • setLabelFor → Label.setLabelFor
  • roles → setAccessibleRole
  • See Java 128

Prefer / Avoid

  • icon-only button with only a tooltip → also set an accessible name
  • mouse-only features (double-click) → add a key binding too

⚠ Common Mistakes

  • Labels not linked with setLabelFor — screen readers announce "edit text" with no name
  • Custom-painted controls that can't take focus — keyboard users can't reach them
  • Color as the only signal (red = error) — add text or an icon

✓ Tips & Best Practices

  • Test with the Access Bridge + NVDA on Windows and VoiceOver on macOS
  • Unplug the mouse for ten minutes and use the app
  • Use JComponent.outline (FlatLaf) plus text for errors

Quick Summary

  • AccessibleContext — name, description, role
  • setLabelFor — link labels to fields
  • keyboard access — Tab order, mnemonics, bindings
  • test with a real screen reader
