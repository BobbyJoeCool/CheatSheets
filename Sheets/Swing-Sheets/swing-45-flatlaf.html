FlatLaf & Modern Themes

FlatLightLaf.setup · FlatDarkLaf · FlatMacLightLaf · IntelliJ themes · .properties theming · client properties · placeholder text

A Modern Look in One Line

FlatLaf (com.formdev:flatlaf) is an open-source flat look and feel used by JetBrains tools and many modern Swing apps. It gives clean light and dark themes, macOS-style themes, HiDPI-sharp rendering, and per-component client properties for features Swing lacks, such as placeholder text and rounded buttons. The flatlaf-intellij-themes add-on brings dozens of IntelliJ themes.

Notes

  • Call setup() before creating components
  • FlatLaf.updateUI() re-skins open windows
  • Theme files: FlatLightLaf.properties overrides

Setup, Dark Mode and Client Properties

public static void main(String[] args) {
    FlatLightLaf.setup();                           // before any UI
    UIManager.put("Button.arc", 8);                 // rounded corners
    UIManager.put("Component.focusWidth", 1);
    SwingUtilities.invokeLater(App::new);
}

void setDark(boolean dark) {
    FlatAnimatedLafChange.showSnapshot();           // smooth fade
    if (dark) FlatDarkLaf.setup(); else FlatLightLaf.setup();
    FlatLaf.updateUI();                             // all windows
    FlatAnimatedLafChange.hideSnapshotWithAnimation();
}

search.putClientProperty("JTextField.placeholderText", "Search…");
search.putClientProperty("JTextField.showClearButton", true);
tabs.putClientProperty("JTabbedPane.tabClosable", true);
tabs.putClientProperty("JTabbedPane.tabCloseCallback",
        (IntConsumer) tabs::removeTabAt);
help.putClientProperty("JButton.buttonType", "help");
frame.getRootPane().putClientProperty("JRootPane.titleBarShowIcon", false);

Code Explained

FlatLightLaf.setup() — install the L&F
UIManager.put("Button.arc", 8) — theme tweak
FlatLaf.updateUI() — switch themes live
client properties — per-component features

JavaFX Equivalent

  • FlatLaf → AtlantaFX (modern JavaFX themes)
  • client properties → CSS style classes
  • dark mode → swap stylesheets
  • See Java 133

Prefer / Avoid

  • custom-painted placeholder text → JTextField.placeholderText
  • per-component colors → theme keys in a .properties file

⚠ Common Mistakes

  • Calling setup() after building the UI — some components keep the old L&F
  • Hard-coding colors that look wrong in dark mode — use theme keys (UIManager.getColor)
  • Forgetting flatlaf-extras for SVG icons and animated theme changes

✓ Tips & Best Practices

  • Use JComponent.outline = "error" to mark invalid fields
  • Follow the OS dark mode with FlatLaf + a system theme detector
  • Try themes live with the FlatLaf Demo app
