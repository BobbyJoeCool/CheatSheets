Building a Window

A Swing app starts in main, hands control to the Event Dispatch Thread with SwingUtilities.invokeLater, then builds a JFrame. The usual order is: create the frame, add components, call pack() so the frame sizes itself to its contents, center it, then setVisible(true). Most real apps subclass nothing: they create a JFrame and put a JPanel with the app's content inside it.

Notes

  • pack() uses each component's preferred size; setSize forces a size
  • setLocationRelativeTo(null) centers on the primary screen
  • Default close action is HIDE_ON_CLOSE: the JVM keeps running

EDT Check

  • main runs on the main thread, not the EDT
  • Create and show the frame inside invokeLater

Window Skeleton

public class App {
    private void createAndShowGui() {
        JFrame frame = new JFrame("Inventory");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        JPanel content = new JPanel(new BorderLayout(8, 8));
        content.setBorder(BorderFactory.createEmptyBorder(12, 12, 12, 12));
        content.add(new JLabel("Items"), BorderLayout.NORTH);
        content.add(new JScrollPane(new JList<>(new String[]{"A", "B"})));
        content.add(new JButton("Add"), BorderLayout.SOUTH);

        frame.setContentPane(content);
        frame.pack();                          // size to preferred sizes
        frame.setMinimumSize(frame.getSize());
        frame.setLocationRelativeTo(null);
        frame.setVisible(true);
    }
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new App().createAndShowGui());
    }
}

Code Explained

setContentPane — use your own panel
createEmptyBorder — padding inside the window
pack() — size from the layout
setMinimumSize — no smaller than packed

JavaFX Equivalent

  • setDefaultCloseOperation → Platform.setImplicitExit
  • pack() → stage.sizeToScene()
  • setLocationRelativeTo(null) → stage.centerOnScreen()
  • See Java 126

Prefer / Avoid

  • class App extends JFrame → create a JFrame and add a panel
  • setSize(800, 600) → pack() (respects fonts and HiDPI)

setDefaultCloseOperation

ConstantEffect
EXIT_ON_CLOSEexit the JVM
DISPOSE_ON_CLOSEfree the window; JVM exits when none left
HIDE_ON_CLOSEdefault · just hides it
DO_NOTHING_ON_CLOSEyou handle windowClosing

⚠ Common Mistakes

  • Forgetting EXIT_ON_CLOSE — the window closes but the program keeps running in the background
  • Calling pack() before adding components — the frame packs to almost nothing
  • Hard-coding setSize — text gets clipped on HiDPI screens and other fonts

✓ Tips & Best Practices

  • Put UI construction in an instance method like createAndShowGui()
  • Use DISPOSE_ON_CLOSE for secondary windows so the app can exit cleanly
  • Use an EmptyBorder on the content panel instead of padding every component

Quick Summary

  • invokeLater(...) — build the UI on the EDT
  • pack() — size the window to its content
  • setLocationRelativeTo(null) — center it
  • setVisible(true) — show it last
