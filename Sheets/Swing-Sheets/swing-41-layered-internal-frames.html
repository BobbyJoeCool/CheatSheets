Layered Panes, Internal Frames & JLayer

JLayeredPane · layer constants · glass pane · JDesktopPane · JInternalFrame · JLayer · LayerUI

Stacking and Decorating

JLayeredPane stacks components at depths (layers); every window's root pane uses one for popups and drag images. The glass pane sits on top of everything and can block input or draw overlays. JDesktopPane + JInternalFrame build MDI apps with windows inside a window. JLayer (Java 7) wraps a component and lets a LayerUI paint over it and see its events, ideal for validation marks, dimming and busy spinners.

Notes

  • Higher layer numbers draw on top
  • Glass pane is invisible until setVisible(true)
  • MDI is old-fashioned; prefer tabs or windows

JLayer Validation Overlay

class InvalidMarkUI extends LayerUI<JTextField> {
    @Override public void paint(Graphics g, JComponent c) {
        super.paint(g, c);                         // draw the field
        JTextField f = (JTextField) ((JLayer<?>) c).getView();
        if (!isValidEmail(f.getText())) {
            Graphics2D g2 = (Graphics2D) g.create();
            g2.setColor(Color.RED);
            g2.fillOval(c.getWidth() - 10, 4, 6, 6);   // red dot
            g2.dispose();
        }
    }
}
JLayer<JTextField> emailLayer = new JLayer<>(email, new InvalidMarkUI());
form.add(emailLayer);                              // add the layer

// Busy overlay with the glass pane
JPanel glass = (JPanel) frame.getGlassPane();
glass.setLayout(new GridBagLayout());
glass.add(new JLabel("Working…"));
glass.addMouseListener(new MouseAdapter() { });    // swallow clicks
glass.setVisible(true);                            // block the UI

Code Explained

LayerUI.paint — draw over the wrapped view
getView() — the decorated component
add the JLayer, not the field
glass pane + empty listener — blocks clicks

JavaFX Equivalent

  • JLayeredPane → StackPane (child order = depth)
  • glass pane → a top node in a StackPane
  • JInternalFrame → no built-in equivalent
  • See Java 127

Prefer / Avoid

  • subclassing a field to paint marks → wrap it in a JLayer
  • custom overlay windows → glass pane or JLayer

⚠ Common Mistakes

  • Adding the wrapped component instead of the JLayer — the decoration never shows
  • Forgetting to dispose() a Graphics.create() copy — leaks state
  • Showing a glass pane without consuming mouse events — clicks still reach the UI

✓ Tips & Best Practices

  • LayerUI.installUI + setLayerEventMask to watch child events
  • Use the glass pane for drag previews and tutorials
  • Prefer tabs or multiple windows over MDI for new apps

Quick Summary

  • JLayeredPane — components at depths
  • glass pane — top overlay, can block input
  • JLayer + LayerUI — decorate any component
  • JInternalFrame — windows inside a window
