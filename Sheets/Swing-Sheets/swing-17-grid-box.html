GridLayout & BoxLayout

GridLayout · rows / cols · BoxLayout · Box.createHorizontalGlue · createRigidArea · createVerticalStrut · setAlignmentX

Equal Cells and Stacks

GridLayout splits a container into equal-size cells, filled row by row. Every cell gets the same size no matter what the component wants, which suits keypads and button grids. BoxLayout stacks components in one row or column and respects maximum sizes. Add glue to absorb extra space and rigid areas or struts for fixed gaps.

Notes

  • GridLayout(0, 3) — any rows, 3 columns
  • BoxLayout needs the target panel in its constructor
  • Box.createVerticalBox() is a shortcut panel
  • Mixed X alignments in a BoxLayout look odd

Keypad and Toolbar Row

JPanel keypad = new JPanel(new GridLayout(4, 3, 4, 4)); // r, c, gaps
for (String k : "7 8 9 4 5 6 1 2 3 0 . C".split(" "))
    keypad.add(new JButton(k));                          // fills by row

JPanel row = new JPanel();
row.setLayout(new BoxLayout(row, BoxLayout.LINE_AXIS));
row.add(new JLabel("Find:"));
row.add(Box.createRigidArea(new Dimension(6, 0)));       // fixed gap
row.add(searchField);
row.add(Box.createHorizontalGlue());                     // push right
row.add(new JButton("Go"));

Box column = Box.createVerticalBox();
for (JComponent c : List.of(title, subtitle, body)) {
    c.setAlignmentX(Component.LEFT_ALIGNMENT);           // same for all
    column.add(c);
    column.add(Box.createVerticalStrut(4));
}
searchField.setMaximumSize(new Dimension(Integer.MAX_VALUE,
        searchField.getPreferredSize().height));         // no tall field

Code Explained

GridLayout(4, 3, 4, 4) — equal cells with gaps
createRigidArea — fixed spacer
createHorizontalGlue — absorbs extra width
setMaximumSize — stop vertical stretch

JavaFX Equivalent

  • GridLayout → GridPane / TilePane
  • BoxLayout → HBox / VBox
  • glue → Region + HBox.setHgrow(ALWAYS)
  • See Java 127

Prefer / Avoid

  • GridLayout for a form → GridBagLayout or MigLayout (labels shouldn't be as wide as fields)
  • X_AXIS / Y_AXIS → LINE_AXIS / PAGE_AXIS (RTL-aware)

⚠ Common Mistakes

  • Text fields stretching tall in a vertical BoxLayout — cap setMaximumSize height
  • Different alignmentX values in one column — items jump left and right
  • Passing a different panel to new BoxLayout(...) than the one you set it on — throws AWTError

✓ Tips & Best Practices

  • Use Box.createVerticalBox() for quick stacks without a JPanel
  • Glue on both sides centers a component in a BoxLayout row
  • GridLayout(1, 0) gives equal-width buttons in a row

Quick Summary

  • GridLayout — equal cells, row by row
  • BoxLayout — one row or column, respects max size
  • glue / struts / rigid areas — control spacing
  • setAlignmentX — align a column's items
