Undo, Redo & Text Actions

UndoManager · UndoableEditListener · DefaultEditorKit · cut / copy / paste actions · Highlighter · Caret

Editing Support

Text components don't come with undo, but every Document reports undoable edits. Add an UndoManager as an UndoableEditListener and bind undo/redo actions to the menu shortcut keys. DefaultEditorKit provides ready-made actions for cut, copy, paste and select all. A Highlighter marks ranges, such as search hits, without changing the text.

Notes

  • Cut/copy/paste keys already work in text fields
  • UndoManager.setLimit(n) caps memory (default 100)
  • Caret controls the cursor and selection

Undo, Redo and Search Highlights

UndoManager undo = new UndoManager();
area.getDocument().addUndoableEditListener(undo);

Action undoAction = new AbstractAction("Undo") {
    public void actionPerformed(ActionEvent e) {
        if (undo.canUndo()) undo.undo();
    }
};                                        // redo: same with canRedo/redo
int menu = Toolkit.getDefaultToolkit().getMenuShortcutKeyMaskEx();
area.getInputMap().put(KeyStroke.getKeyStroke(KeyEvent.VK_Z, menu),
        "undo");
area.getActionMap().put("undo", undoAction);

editMenu.add(new JMenuItem(new DefaultEditorKit.CutAction()));
editMenu.add(new JMenuItem(new DefaultEditorKit.CopyAction()));
editMenu.add(new JMenuItem(new DefaultEditorKit.PasteAction()));

Highlighter hl = area.getHighlighter();
var painter = new DefaultHighlighter.DefaultHighlightPainter(Color.YELLOW);
hl.removeAllHighlights();
for (int i = text.indexOf(q); i >= 0; i = text.indexOf(q, i + 1))
    hl.addHighlight(i, i + q.length(), painter);

Code Explained

UndoManager — collects document edits
canUndo / undo — step back
DefaultEditorKit.CutAction — works on the focused field
addHighlight — mark a range

JavaFX Equivalent

  • UndoManager → built into TextInputControl.undo()
  • cut/copy/paste → cut(), copy(), paste()
  • highlights → style ranges in RichTextFX
  • See Java 128

Prefer / Avoid

  • writing your own cut/copy/paste → DefaultEditorKit actions
  • coloring search hits by editing text → Highlighter

⚠ Common Mistakes

  • Calling undo() when canUndo() is false — throws CannotUndoException
  • Not calling discardAllEdits() after loading a file — the first undo erases the whole file
  • Each keystroke as its own undo step — group edits with a CompoundEdit for typing bursts

✓ Tips & Best Practices

  • Enable Undo/Redo menu items from canUndo() / canRedo()
  • Use getUndoPresentationName() for "Undo Typing" labels
  • Highlight all search hits and select the current one

Quick Summary

  • UndoManager — add as an edit listener
  • undo/redo actions — bind to menu shortcut keys
  • DefaultEditorKit — ready cut/copy/paste
  • Highlighter — mark text ranges
