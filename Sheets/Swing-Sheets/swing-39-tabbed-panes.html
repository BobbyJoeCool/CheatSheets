Tabbed Panes

JTabbedPane · addTab · setTabPlacement · SCROLL_TAB_LAYOUT · setTabComponentAt · closeable tabs · ChangeListener

Tabs

JTabbedPane shows one panel at a time behind a row of tabs. Each tab has a title, an optional icon and tooltip, and a component. A ChangeListener tells you when the selected tab changes, which is a good moment to lazy-load that tab's content. setTabComponentAt replaces a tab's title with any component, which is how closeable tabs are built.

Notes

  • Too many tabs wrap into rows unless you scroll
  • Mnemonics: setMnemonicAt(index, VK_…)
  • FlatLaf adds closeable tabs via a client property

Editor Tabs with Close Buttons

JTabbedPane tabs = new JTabbedPane(JTabbedPane.TOP,
        JTabbedPane.SCROLL_TAB_LAYOUT);       // one scrolling row
tabs.addTab("Summary", summaryIcon, summaryPanel, "Overview");
tabs.setMnemonicAt(0, KeyEvent.VK_1);

void openFile(Path p) {
    JScrollPane editor = new JScrollPane(new JTextArea(read(p)));
    tabs.addTab(p.getFileName().toString(), editor);
    int i = tabs.indexOfComponent(editor);
    JPanel tab = new JPanel(new FlowLayout(FlowLayout.LEADING, 4, 0));
    tab.setOpaque(false);
    tab.add(new JLabel(p.getFileName().toString()));
    JButton close = new JButton("×");
    close.setBorder(BorderFactory.createEmptyBorder());
    close.addActionListener(e -> tabs.remove(editor));
    tab.add(close);
    tabs.setTabComponentAt(i, tab);
    tabs.setSelectedIndex(i);
}

tabs.addChangeListener(e -> loadIfNeeded(tabs.getSelectedComponent()));

Code Explained

SCROLL_TAB_LAYOUT — arrows instead of wrapped rows
addTab(title, icon, comp, tip) — full form
setTabComponentAt — custom tab header
ChangeListener — selected tab changed

JavaFX Equivalent

  • JTabbedPane → TabPane + Tab
  • closeable tabs → tab.setClosable(true)
  • selection → getSelectionModel() listener
  • See Java 128

Prefer / Avoid

  • removing tabs by index stored earlier → remove(component) (indexes shift)
  • building every tab at startup → lazy-load on first select

⚠ Common Mistakes

  • Keeping tab indexes in fields — they shift when tabs are added or removed
  • Forgetting setOpaque(false) on a custom tab panel — it paints a gray box on the tab
  • Loading heavy data for every tab at startup — slow launch

✓ Tips & Best Practices

  • FlatLaf: client property JTabbedPane.tabClosable
  • Use side tabs (LEFT) for settings screens with many sections
  • Mark unsaved tabs with * in the title
