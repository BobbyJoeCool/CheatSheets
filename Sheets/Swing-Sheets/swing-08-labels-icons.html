Sheet 08

Labels & Icons

JLabel · ImageIcon · setIcon · HTML in labels · setHorizontalAlignment · setLabelFor · setDisplayedMnemonic

Showing Text and Images

JLabel displays read-only text, an icon, or both. It can't be focused or clicked by default, which makes it the right component for captions, status text and pictures. Labels accept simple HTML (<html>…) for bold, color and line breaks. Paired with setLabelFor, a label gives its field a keyboard mnemonic and an accessible name.

Notes

  • HTML labels support HTML 3.2 and basic CSS only
  • ImageIcon loads synchronously; big images block the EDT
  • An empty label ("") collapses to zero height in some layouts

Text, Icons and HTML

JLabel title = new JLabel("Inventory");
title.setFont(title.getFont().deriveFont(Font.BOLD, 18f));

JLabel status = new JLabel("Ready", SwingConstants.LEFT);
status.setForeground(new Color(0x2E7D32));

ImageIcon icon = new ImageIcon(
        getClass().getResource("/icons/ok.png"));
JLabel ok = new JLabel("Saved", icon, SwingConstants.LEADING);
ok.setIconTextGap(6);
ok.setHorizontalTextPosition(SwingConstants.TRAILING);

JLabel help = new JLabel(
        "<html><b>Tip:</b> double-click<br>a row to edit</html>");

JLabel nameLbl = new JLabel("Name:");
JTextField nameFld = new JTextField(15);
nameLbl.setDisplayedMnemonic('N');   // Alt+N focuses the field
nameLbl.setLabelFor(nameFld);        // also sets accessible name

status.setText("3 items saved");     // update later (on the EDT)

Code Explained

deriveFont — same font, new style/size
LEADING — left in LTR, right in RTL
<html> — multi-line or styled text
setLabelFor — mnemonic + accessible name

JavaFX Equivalent

  • JLabel → Label
  • setIcon → setGraphic(new ImageView(...))
  • HTML labels → TextFlow with Text nodes
  • See Java 128

Prefer / Avoid

  • new Font("Arial", ...) → getFont().deriveFont(...) (keeps L&F font)
  • label + field without setLabelFor → always link them

Alignment & Position

MethodControls
setHorizontalAlignmentcontent in the label box
setVerticalAlignmentcontent top/center/bottom
setHorizontalTextPositiontext relative to icon
setIconTextGap(px)space between them

Constructors

FormCreates
JLabel(text)text only
JLabel(icon)icon only
JLabel(text, align)text + alignment
JLabel(text, icon, align)both

⚠ Common Mistakes

  • Using a JLabel as a button — it has no focus or keyboard support; use a borderless JButton
  • Building HTML from user input — < in the data breaks the label; escape it or skip HTML
  • Loading icons with file paths — getResource works once the app is a JAR

✓ Tips & Best Practices

  • Cache ImageIcons you reuse instead of loading them per row
  • Use setToolTipText for long text that you truncate
  • Prefer LEADING/TRAILING over LEFT/RIGHT for RTL support

Quick Summary

  • JLabel — read-only text and/or icon
  • ImageIcon + getResource — load images
  • <html> — styled or multi-line text
  • setLabelFor — link a caption to its field
