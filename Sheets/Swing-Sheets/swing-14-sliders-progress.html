Sheet 14

Sliders & Progress Bars

JSlider · setMajorTickSpacing · setPaintLabels · ChangeListener · JProgressBar · setIndeterminate · ProgressMonitor

Ranges and Progress

JSlider picks an integer from a range by dragging; ticks and labels make the scale readable. It fires ChangeEvents as it moves, and getValueIsAdjusting() tells you when the drag has ended. JProgressBar shows how far a task has gotten, or an animated indeterminate bar when you can't measure progress. ProgressMonitor pops up a progress dialog only if a task takes a while.

Notes

  • Slider values are always int; scale for decimals
  • setStringPainted(true) shows "42%" on the bar
  • ProgressMonitor waits ~500 ms before appearing

EDT Check

  • Update progress bars on the EDT only
  • From a worker, use setProgress + listener or publish

Volume Slider and Download Bar

JSlider volume = new JSlider(0, 100, 50);
volume.setMajorTickSpacing(25);
volume.setMinorTickSpacing(5);
volume.setPaintTicks(true);
volume.setPaintLabels(true);
volume.addChangeListener(e -> {
    if (!volume.getValueIsAdjusting())        // drag finished
        player.setVolume(volume.getValue() / 100.0);
});

JProgressBar bar = new JProgressBar(0, 100);
bar.setStringPainted(true);                   // "37%"
bar.setIndeterminate(true);                   // until size is known

worker.addPropertyChangeListener(e -> {       // SwingWorker progress
    if ("progress".equals(e.getPropertyName())) {
        bar.setIndeterminate(false);
        bar.setValue((Integer) e.getNewValue());
    }
});
worker.execute();

Code Explained

JSlider(min, max, value) — integer range
getValueIsAdjusting() — still dragging
setIndeterminate(true) — unknown length
property listener — progress from a worker

JavaFX Equivalent

  • JSlider → Slider + valueProperty
  • JProgressBar → ProgressBar
  • indeterminate → setProgress(-1)
  • See Java 128

Prefer / Avoid

  • heavy work on every slider tick → act when !getValueIsAdjusting()
  • bar.setValue from a worker thread → setProgress + listener

⚠ Common Mistakes

  • Running slow work in the slider listener during drag — the slider stutters
  • Forgetting setStringPainted(true) — custom strings don't show
  • Leaving the bar indeterminate after the task ends — reset it in done()

✓ Tips & Best Practices

  • Use a Hashtable<Integer, JLabel> label table for named stops
  • Show indeterminate first, switch to determinate once the size is known
  • Hide the bar with setVisible(false) when idle

Quick Summary

  • JSlider — pick an int by dragging
  • getValueIsAdjusting — react when the drag ends
  • JProgressBar — show task progress
  • indeterminate — progress of unknown length
