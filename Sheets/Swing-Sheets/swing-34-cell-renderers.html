Custom Drawing for Cells

Lists, combos, tables and trees don't create a component per row. They use one renderer component as a rubber stamp: configure it for a cell, paint it, move to the next. Extending DefaultListCellRenderer or DefaultTableCellRenderer (both are JLabels) and calling super keeps the look and feel's selection colors and focus border for free.

Notes

  • Renderers only paint: they can't receive clicks
  • Reset every property you change, every call
  • Editing uses a separate editor (sheet 37)

List and Table Renderers

class TaskRenderer extends DefaultListCellRenderer {
    @Override public Component getListCellRendererComponent(JList<?> list,
            Object value, int index, boolean selected, boolean focus) {
        super.getListCellRendererComponent(
                list, value, index, selected, focus);
        Task t = (Task) value;
        setText(t.title());
        setIcon(t.done() ? doneIcon : todoIcon);
        setFont(getFont().deriveFont(t.done() ? Font.PLAIN : Font.BOLD));
        return this;                            // the stamp
    }
}
list.setCellRenderer(new TaskRenderer());

class MoneyRenderer extends DefaultTableCellRenderer {
    { setHorizontalAlignment(TRAILING); }
    @Override protected void setValue(Object v) {
        BigDecimal amt = (BigDecimal) v;
        setText(amt == null ? "" : CURRENCY.format(amt));
        setForeground(amt != null && amt.signum() < 0 ? Color.RED : null);
    }
}
table.setDefaultRenderer(BigDecimal.class, new MoneyRenderer());

Code Explained

super.get…Component — keeps selection colors
return this — one reused label
setValue — the simple table hook
setDefaultRenderer(Class, r) — per column type

JavaFX Equivalent

  • renderers → setCellFactory + updateItem
  • rubber stamp → virtualized reused cells
  • setValue → updateItem(item, empty)
  • See Java 128

Prefer / Avoid

  • new JLabel() inside the renderer → configure and return this
  • hard-coded selection colors → call super and keep L&F colors

⚠ Common Mistakes

  • Changing a color for some rows but not resetting it — the color leaks into other rows
  • Doing slow work (DB, image loading) in a renderer — it runs for every visible cell on every repaint
  • Adding listeners to the renderer — it's a stamp, not a live component

✓ Tips & Best Practices

  • Pass null to setForeground to restore the L&F default
  • Cache icons and formats as static fields
  • Use getColumnClass in the model so default renderers apply

Quick Summary

  • renderer — one stamp component per view
  • extend Default…CellRenderer + call super
  • reset properties every call
  • setDefaultRenderer — by column class
