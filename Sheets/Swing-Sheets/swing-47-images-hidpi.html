Images, Icons & HiDPI

getResource · ImageIO.read · getScaledInstance · BaseMultiResolutionImage · sun.java2d.uiScale · FlatSVGIcon · app icons

Sharp Images on Every Screen

Since Java 9, Swing scales the whole UI on HiDPI screens. Bitmap icons designed at 16 px then get blurry at 200%. Fix it with multi-resolution images (a 1× and a 2× PNG), or with SVG icons via FlatLaf's FlatSVGIcon. Load images from the classpath with getResource, and use ImageIO.read when you need a BufferedImage to process.

Notes

  • Scale factor comes from the OS (Java 9+)
  • sun.java2d.uiScale overrides it for testing
  • ImageIcon loads synchronously

Icons That Stay Sharp

// 1x + 2x PNGs combined into one icon
Image x1 = ImageIO.read(App.class.getResource("/icons/save.png"));
Image x2 = ImageIO.read(App.class.getResource("/icons/save@2x.png"));
Icon save = new ImageIcon(new BaseMultiResolutionImage(x1, x2));

// SVG icon (flatlaf-extras): scales to any size and theme
FlatSVGIcon trash = new FlatSVGIcon("icons/trash.svg", 16, 16);
deleteBtn.setIcon(trash);

// Window/taskbar icons: give several sizes
frame.setIconImages(List.of(load("/app16.png"), load("/app32.png"),
                            load("/app64.png"), load("/app256.png")));

// Scaling a photo for a thumbnail (quality)
BufferedImage src = ImageIO.read(file);
var thumb = new BufferedImage(160, 120, BufferedImage.TYPE_INT_RGB);
Graphics2D g = thumb.createGraphics();
g.setRenderingHint(RenderingHints.KEY_INTERPOLATION,
        RenderingHints.VALUE_INTERPOLATION_BILINEAR);
g.drawImage(src, 0, 0, 160, 120, null);
g.dispose();
// java -Dsun.java2d.uiScale=2 -jar app.jar   (test 200%)

Code Explained

BaseMultiResolutionImage — picks 1× or 2×
FlatSVGIcon — vector icon, any scale
setIconImages — several sizes for the OS
bilinear hint — smoother thumbnails

JavaFX Equivalent

  • ImageIcon → Image + ImageView
  • @2x files → loaded automatically by JavaFX
  • SVG → SVGPath or a library
  • See Java 128

Prefer / Avoid

  • getScaledInstance → draw into a BufferedImage with rendering hints
  • one 16 px PNG per icon → SVG or 1×/2× pairs

⚠ Common Mistakes

  • Shipping only 16 px PNGs — blurry on every Retina and 4K display
  • Using getScaledInstance in paint code — slow and low quality
  • Missing resource paths returning null — ImageIcon(null) throws later, far from the bug

✓ Tips & Best Practices

  • Name 2× assets name@2x.png and load both with one helper
  • Test at 150% and 200% with -Dsun.java2d.uiScale
  • Use SVG icons that follow the theme with FlatLaf color filters

Quick Summary

  • HiDPI — Swing scales the UI; bitmaps blur
  • multi-resolution / SVG — sharp icons
  • getResource + ImageIO — load images
  • setIconImages — app icon sizes
