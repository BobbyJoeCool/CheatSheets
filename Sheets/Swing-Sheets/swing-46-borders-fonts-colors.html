Borders, Fonts & Colors

BorderFactory · EmptyBorder · TitledBorder · CompoundBorder · deriveFont · setBackground · setOpaque

Styling Components

Borders draw around a component and also add space, so an EmptyBorder is the standard way to pad panels. BorderFactory creates line, titled, compound and matte borders. Fonts are best derived from the L&F's font with deriveFont, so sizes scale with the platform. Background colors only show on opaque components.

Notes

  • A border's insets add to the component's size
  • JLabel is not opaque by default
  • Logical fonts: Font.SANS_SERIF, MONOSPACED

Padding, Groups and Fonts

JPanel card = new JPanel(new BorderLayout());
card.setBorder(BorderFactory.createCompoundBorder(
        BorderFactory.createLineBorder(new Color(0xD0D7DE), 1, true),
        BorderFactory.createEmptyBorder(12, 16, 12, 16)));   // padding

JPanel shipping = new JPanel(new GridLayout(0, 1));
shipping.setBorder(BorderFactory.createTitledBorder("Shipping"));

JComponent divider = new JPanel();
divider.setBorder(BorderFactory.createMatteBorder(0, 0, 1, 0, Color.GRAY));

JLabel heading = new JLabel("Orders");
heading.setFont(heading.getFont().deriveFont(Font.BOLD, 16f));

JLabel badge = new JLabel(" NEW ");
badge.setOpaque(true);                       // needed for background
badge.setBackground(new Color(0x2E7D32));
badge.setForeground(Color.WHITE);

Font code = new Font(Font.MONOSPACED, Font.PLAIN, 12);
Color accent = UIManager.getColor("Component.accentColor");  // theme

Code Explained

CompoundBorder — outer line + inner padding
TitledBorder — labeled group box
deriveFont — keep family, change style/size
setOpaque(true) — let background paint

JavaFX Equivalent

  • borders → -fx-border-color / -fx-padding
  • TitledBorder → TitledPane
  • fonts/colors → CSS or setFont / setTextFill
  • See Java 133

Prefer / Avoid

  • setPreferredSize for spacing → EmptyBorder
  • new Font("Arial", …) → deriveFont or logical fonts

⚠ Common Mistakes

  • Setting a background on a non-opaque JLabel — nothing shows
  • Replacing a component's L&F border to add padding — use a compound border instead
  • Fixed font sizes in pixels — look tiny on HiDPI and break user font settings

✓ Tips & Best Practices

  • Pad the content pane with one EmptyBorder instead of every component
  • Read theme colors from UIManager so dark mode works
  • Use TitledBorder sparingly; whitespace groups well too

Quick Summary

  • BorderFactory — padding, lines, titles
  • CompoundBorder — combine two borders
  • deriveFont — font variants
  • setOpaque(true) — backgrounds that show
