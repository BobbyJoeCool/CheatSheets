Popup Menus & Toolbars

JPopupMenu · setComponentPopupMenu · JToolBar · setFloatable · addSeparator · Actions in toolbars

Context Menus and Tool Rows

A JPopupMenu is a menu that appears at the mouse: the right-click context menu. The simplest way to attach one is setComponentPopupMenu, which handles the platform's popup trigger and the Menu key for you. A JToolBar is a row of icon buttons, usually above the content. Feed both the same Actions as your menus so everything stays in sync.

Notes

  • Toolbars can float by default; turn it off
  • Context menus should act on the item under the mouse
  • setHideActionText gives icon-only buttons

Table Context Menu and Toolbar

JPopupMenu rowMenu = new JPopupMenu();
rowMenu.add(new JMenuItem(editAction));
rowMenu.add(new JMenuItem(deleteAction));
rowMenu.addSeparator();
rowMenu.add(new JMenuItem(copyAction));
table.setComponentPopupMenu(rowMenu);         // right-click + Menu key
table.setInheritsPopupMenu(true);

// Select the row under the mouse before the menu shows
rowMenu.addPopupMenuListener(new PopupMenuListener() {
    public void popupMenuWillBecomeVisible(PopupMenuEvent e) {
        SwingUtilities.invokeLater(() -> selectRowUnderMouse(table));
    }
    public void popupMenuWillBecomeInvisible(PopupMenuEvent e) { }
    public void popupMenuCanceled(PopupMenuEvent e) { }
});

JToolBar tools = new JToolBar();
tools.setFloatable(false);
tools.add(newAction); tools.add(saveAction);
tools.addSeparator();
tools.add(deleteAction);
frame.add(tools, BorderLayout.PAGE_START);

Code Explained

setComponentPopupMenu — trigger handled for you
PopupMenuListener — prepare before showing
setFloatable(false) — fixed toolbar
tools.add(action) — icon button from an Action

JavaFX Equivalent

  • JPopupMenu → ContextMenu + setContextMenu
  • JToolBar → ToolBar
  • floating toolbars → no equivalent
  • See Java 128

Prefer / Avoid

  • manual isPopupTrigger code → setComponentPopupMenu
  • toolbar buttons with their own listeners → Actions shared with menus

⚠ Common Mistakes

  • Acting on the selected row when the user right-clicked a different one — select the row under the mouse first
  • Giving toolbar buttons text and icons — crowded; hide text and rely on tooltips
  • Leaving toolbars floatable — users drag them off and can't get them back

✓ Tips & Best Practices

  • Use 16 px icons in menus and 24 px in toolbars (LARGE_ICON_KEY)
  • Put a toolbar in PAGE_START of a BorderLayout
  • Disable actions that don't apply instead of hiding menu items

Quick Summary

  • JPopupMenu — context menu
  • setComponentPopupMenu — attach with no trigger code
  • JToolBar — row of action buttons
  • shared Actions — menus, popups, toolbars agree
