Action Events & Actions

ActionListener · ActionEvent · getActionCommand · AbstractAction · Action.NAME · putValue · shared setEnabled

Commands You Can Reuse

An Action bundles a command's behavior with its text, icon, tooltip, shortcut and enabled state. Pass the same Action to a button, a menu item and a toolbar button, and all three stay in sync: disable the action and every control greys out. Subclass AbstractAction and implement actionPerformed, or build one from a lambda with a small helper.

Notes

  • new JButton(action) copies name, icon and tooltip
  • ACCELERATOR_KEY shows in menus, not on buttons
  • Key bindings (sheet 25) can trigger the same Action

EDT Check

  • actionPerformed runs on the EDT
  • Long commands: start a SwingWorker and return
  • setEnabled on an Action must happen on the EDT

One Action, Three Controls

Action saveAction = new AbstractAction("Save", saveIcon) {
    @Override public void actionPerformed(ActionEvent e) {
        saveDocument();
    }
};
saveAction.putValue(Action.SHORT_DESCRIPTION, "Save the file");
saveAction.putValue(Action.MNEMONIC_KEY, KeyEvent.VK_S);
saveAction.putValue(Action.ACCELERATOR_KEY,
    KeyStroke.getKeyStroke(KeyEvent.VK_S,
        Toolkit.getDefaultToolkit().getMenuShortcutKeyMaskEx()));

fileMenu.add(new JMenuItem(saveAction));      // shows Ctrl/Cmd+S
toolBar.add(saveAction);                      // icon button
JButton saveBtn = new JButton(saveAction);

saveAction.setEnabled(false);                 // all three disable
document.onDirtyChange(dirty -> saveAction.setEnabled(dirty));

String cmd = e.getActionCommand();            // from ActionEvent
boolean ctrl = (e.getModifiers() & ActionEvent.CTRL_MASK) != 0;

Code Explained

AbstractAction(name, icon) — command + label
putValue — tooltip, mnemonic, shortcut
getMenuShortcutKeyMaskEx() — Ctrl or Cmd
setEnabled — syncs every control

JavaFX Equivalent

  • Action → no direct class; bind disableProperty
  • accelerator → MenuItem.setAccelerator
  • shared state → one BooleanProperty bound to all
  • See Java 129

Prefer / Avoid

  • duplicate listeners on menu + button → one shared Action
  • hard-coded CTRL_DOWN_MASK → getMenuShortcutKeyMaskEx() (Cmd on macOS)

⚠ Common Mistakes

  • Setting a button's text after giving it an Action — the action's NAME overrides it on change
  • Expecting ACCELERATOR_KEY to work on a plain button — use a key binding
  • Creating a new Action per control — enabled state drifts apart

✓ Tips & Best Practices

  • Keep all actions in one Actions class per window
  • Use setHideActionText(true) for icon-only toolbar buttons
  • Use SELECTED_KEY for toggle actions shared by check menu items and toggle buttons

Quick Summary

  • Action — command + text + icon + state
  • AbstractAction — implement actionPerformed
  • one action, many controls — stays in sync
  • putValue — tooltip, mnemonic, shortcut
