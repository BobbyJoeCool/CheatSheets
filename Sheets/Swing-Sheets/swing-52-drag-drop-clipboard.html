Drag & Drop and Clipboard

TransferHandler · setDragEnabled · DropMode · importData · Transferable · DataFlavor · getSystemClipboard

Moving Data In and Out

Swing routes drag and drop, cut/copy/paste through one class: TransferHandler. Text components, lists and tables already support it; turn on dragging with setDragEnabled(true). To accept files dropped from the desktop or reorder list items, write a TransferHandler with canImport and importData. Data travels as a Transferable in one or more DataFlavors.

Notes

  • Files arrive as DataFlavor.javaFileListFlavor
  • DropMode controls where a drop lands
  • Clipboard text: DataFlavor.stringFlavor

Drop Files onto a List, Copy Text

fileList.setDropMode(DropMode.INSERT);
fileList.setTransferHandler(new TransferHandler() {
    @Override public boolean canImport(TransferSupport s) {
        return s.isDataFlavorSupported(DataFlavor.javaFileListFlavor);
    }
    @Override public boolean importData(TransferSupport s) {
        if (!canImport(s)) return false;
        try {
            @SuppressWarnings("unchecked")
            List<File> files = (List<File>) s.getTransferable()
                    .getTransferData(DataFlavor.javaFileListFlavor);
            files.forEach(f -> model.addElement(f.toPath()));
            return true;
        } catch (UnsupportedFlavorException | IOException e) {
            return false;
        }
    }
});

Clipboard cb = Toolkit.getDefaultToolkit().getSystemClipboard();
String cell = table.getValueAt(r, 0).toString();
cb.setContents(new StringSelection(cell), null);
String pasted = (String) cb.getData(DataFlavor.stringFlavor);

Code Explained

canImport — accept or reject the drag
importData — take the dropped data
javaFileListFlavor — files from the OS
StringSelection — put text on the clipboard

JavaFX Equivalent

  • TransferHandler → setOnDragOver / setOnDragDropped
  • DataFlavor → DataFormat
  • clipboard → Clipboard.getSystemClipboard()
  • See Java 129

Prefer / Avoid

  • DropTarget + low-level DnD listeners → TransferHandler
  • custom copy keys → the built-in TransferHandler.getCopyAction()

⚠ Common Mistakes

  • Reading big dropped files in importData — it runs on the EDT; hand paths to a worker
  • Replacing a text field's handler — you lose its built-in cut/copy/paste
  • Forgetting setDragEnabled(true) — lists and tables won't start drags

✓ Tips & Best Practices

  • Use s.isDrop() to tell a drop from a paste
  • Show the drop line with DropMode.INSERT on lists and tables
  • Implement exportDone to remove items after a MOVE

Quick Summary

  • TransferHandler — one API for DnD and clipboard
  • canImport / importData — accept data
  • DataFlavor — type of transferred data
  • getSystemClipboard — copy and paste
