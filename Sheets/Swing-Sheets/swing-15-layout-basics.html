Sheet 15

How Layout Works

LayoutManager · setLayout · preferred / min / max size · pack · revalidate · repaint · null layout (avoid)

Layout Managers Do the Sizing

Every Container has a layout manager that decides where each child goes and how big it is. It asks each component for its preferred, minimum and maximum size, then fits them into the available space. pack() sizes a window to the preferred size of its content. When content changes at runtime, revalidate() re-runs layout and repaint() redraws.

Notes

  • JPanel defaults to FlowLayout
  • A content pane defaults to BorderLayout
  • Managers differ in which size hints they respect
  • Nest panels with simple layouts for complex screens

EDT Check

  • revalidate() / repaint() are safe from any thread
  • Adding or removing children must happen on the EDT
  • Layout runs later, on the EDT, not inside revalidate()

Size Hints and Re-Layout

JPanel panel = new JPanel(new BorderLayout());   // pick a manager
panel.setLayout(new FlowLayout());                // or change it

JButton ok = new JButton("OK");
ok.getPreferredSize();                 // from text, font, insets
ok.setPreferredSize(new Dimension(90, 28));   // override (sparingly)

JTextField search = new JTextField(20);
search.setMaximumSize(search.getPreferredSize()); // stop BoxLayout stretch

// Runtime change: add a row, then re-layout and redraw
rows.add(new RowPanel(item));
rows.revalidate();                    // queue layout of this subtree
rows.repaint();                       // queue a redraw

frame.pack();                         // resize window to fit content

// Absolute positioning (avoid): breaks with fonts, HiDPI, i18n
panel.setLayout(null);
ok.setBounds(10, 10, 90, 28);

Code Explained

getPreferredSize() — what the component wants
setMaximumSize — cap growth in BoxLayout
revalidate() — re-run layout after changes
setLayout(null) — manual bounds (avoid)

JavaFX Equivalent

  • layout managers → layout panes (VBox, GridPane)
  • revalidate → automatic on scene graph change
  • setPreferredSize → setPrefWidth / setPrefHeight
  • See Java 127

Prefer / Avoid

  • setLayout(null) + setBounds → a layout manager + pack()
  • setPreferredSize everywhere → let content decide; set columns/rows

⚠ Common Mistakes

  • Using null layout — text gets clipped on other fonts, HiDPI and translations
  • Adding components without revalidate() — they don't appear until the window resizes
  • Calling setPreferredSize with fixed pixels — fights the layout and the look and feel

✓ Tips & Best Practices

  • Sketch the screen as nested boxes first, then pick one simple layout per box
  • Use setBorder(createEmptyBorder(...)) for padding instead of fixed sizes
  • Debug layouts by giving panels temporary colored borders

Quick Summary

  • layout manager — sizes and places children
  • preferred/min/max — hints components report
  • revalidate() + repaint() — after runtime changes
  • null layout — avoid
