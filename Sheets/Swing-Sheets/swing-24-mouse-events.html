Clicks, Drags and Wheels

Mouse input comes through three listener interfaces: MouseListener (press, release, click, enter, exit), MouseMotionListener (move, drag) and MouseWheelListener. MouseAdapter implements all three, so one subclass can handle everything once you register it for each type. Coordinates in a MouseEvent are relative to the component that received it.

Notes

  • mouseClicked only fires if press and release don't move
  • Popup trigger differs: press on macOS/Linux, release on Windows

Drawing Canvas with Drag and Popup

class Canvas extends JPanel {
    private Point start;
    Canvas() {
        MouseAdapter m = new MouseAdapter() {
            @Override public void mousePressed(MouseEvent e) {
                maybePopup(e); start = e.getPoint();
            }
            @Override public void mouseReleased(MouseEvent e) {
                maybePopup(e);
            }
            @Override public void mouseDragged(MouseEvent e) {
                shapes.add(new Line2D.Float(start, e.getPoint()));
                start = e.getPoint();
                repaint();
            }
        };
        addMouseListener(m);                    // press, release, click
        addMouseMotionListener(m);              // move, drag
        addMouseWheelListener(m);               // (wheel: mouseWheelMoved)
    }
    private void maybePopup(MouseEvent e) {
        if (e.isPopupTrigger()) menu.show(this, e.getX(), e.getY());
    }
}

Code Explained

one MouseAdapter — registered three times
mouseDragged — motion with a button down
isPopupTrigger — check press and release

JavaFX Equivalent

  • MouseListener → setOnMousePressed / Clicked
  • drag → setOnMouseDragged
  • wheel → setOnScroll
  • See Java 129

Prefer / Avoid

  • checking getButton() == BUTTON3 for menus → isPopupTrigger() or setComponentPopupMenu
  • adding the adapter only with addMouseListener → also add motion/wheel

⚠ Common Mistakes

  • Using mouseClicked for drag-select — it never fires if the mouse moved
  • Checking isPopupTrigger only in mousePressed — popups don't open on Windows
  • Heavy work in mouseMoved — it fires constantly

✓ Tips & Best Practices

  • Use setComponentPopupMenu instead of manual popup logic when you can
  • Show a hand cursor with Cursor.HAND_CURSOR
  • Repaint only the changed rectangle during drags for speed

Quick Summary

  • MouseAdapter — one class, all mouse methods
  • register three ways — listener, motion, wheel
  • getPoint() — component-relative coords
  • isPopupTrigger() — cross-platform menus
