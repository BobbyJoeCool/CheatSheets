Sheet 10

Check Boxes & Radio Buttons

JCheckBox · JRadioButton · ButtonGroup · isSelected · setSelected · ItemListener · clearSelection

Choices: Many or One

Use JCheckBox for independent yes/no options and JRadioButton for picking exactly one from a small set. Radio buttons only become exclusive when you add them to a ButtonGroup; the group is a logical helper, not a visual container, so you still add each button to a panel. Read state with isSelected(), or react with an ItemListener or ActionListener.

Notes

  • ItemListener fires on select and deselect
  • ActionListener fires only on user clicks
  • setSelected from code fires ItemEvents too
  • Use a titled border to label a radio group

Options Panel

JCheckBox wrap = new JCheckBox("Wrap lines", true);
wrap.addItemListener(e ->
    textArea.setLineWrap(e.getStateChange() == ItemEvent.SELECTED));

JRadioButton csv  = new JRadioButton("CSV", true);
JRadioButton json = new JRadioButton("JSON");
JRadioButton xml  = new JRadioButton("XML");
ButtonGroup format = new ButtonGroup();      // makes them exclusive
for (JRadioButton b : List.of(csv, json, xml)) format.add(b);

JPanel formatPanel = new JPanel(new GridLayout(0, 1));
formatPanel.setBorder(BorderFactory.createTitledBorder("Format"));
formatPanel.add(csv); formatPanel.add(json); formatPanel.add(xml);

String chosen = csv.isSelected() ? "csv"
              : json.isSelected() ? "json" : "xml";

json.setActionCommand("json");               // or read from the group:
format.getSelection().getActionCommand();    // "json" when selected

Code Explained

getStateChange() — SELECTED or DESELECTED
ButtonGroup — one selected at a time
titled border — visual frame for the group
getSelection() — the selected button's model

JavaFX Equivalent

  • JCheckBox → CheckBox
  • ButtonGroup → ToggleGroup
  • ItemListener → selectedProperty().addListener
  • See Java 128

Prefer / Avoid

  • chains of isSelected() → map buttons to values (Map<JRadioButton, Format>)
  • check box for exclusive options → radio buttons in a ButtonGroup

API

CallDoes
isSelected()current state
setSelected(b)change state (fires events)
group.clearSelection()none selected
group.getSelection()selected ButtonModel

Which Listener?

ListenerFires when
ItemListenerstate changes (user or code)
ActionListeneruser clicks only
ChangeListenerany model change (noisy)

⚠ Common Mistakes

  • Forgetting the ButtonGroup — radio buttons act like check boxes
  • Adding the ButtonGroup to a panel — it isn't a component; add the buttons
  • Reacting to both select and deselect in an ItemListener — check getStateChange()

✓ Tips & Best Practices

  • Use ActionListener when code-driven setSelected calls shouldn't trigger logic
  • Map radio buttons to an enum with setActionCommand(e.name())
  • Put radio groups in a GridLayout(0, 1) panel for a clean column

Quick Summary

  • JCheckBox — independent on/off
  • JRadioButton + ButtonGroup — one of many
  • isSelected() — read state
  • ItemListener — react to changes
