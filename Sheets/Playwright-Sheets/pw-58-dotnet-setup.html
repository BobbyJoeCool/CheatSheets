Playwright for .NET

The .NET binding uses PascalCase methods ending in Async, options objects initialised with new() { … }, and Expect() for web-first assertions. Browsers are installed with the generated playwright.ps1 script after building the project. Use the library package for scripts and tools, or a test-framework package (NUnit, MSTest, xUnit) for tests (next sheet).

Notes

  • .NET 8+; PowerShell (pwsh) runs the install script on any OS
  • Microsoft.Playwright = library; .NUnit/.MSTest/.Xunit = test helpers
  • Roles via AriaRole.Button enum
  • await using disposes browsers (IAsyncDisposable)

Console App

// dotnet new console -n Scraper && cd Scraper
// dotnet add package Microsoft.Playwright && dotnet build
// pwsh bin/Debug/net8.0/playwright.ps1 install --with-deps chromium
using System.Text.RegularExpressions;
using Microsoft.Playwright;
using static Microsoft.Playwright.Assertions;

using var playwright = await Playwright.CreateAsync();
await using var browser = await playwright.Chromium.LaunchAsync(
    new() { Headless = false, SlowMo = 50 });
var context = await browser.NewContextAsync(new() { Locale = "en-US" });
var page = await context.NewPageAsync();

await page.GotoAsync("https://playwright.dev");
await Expect(page).ToHaveTitleAsync(new Regex("Playwright"));
await page.GetByRole(AriaRole.Link, new() { Name = "Get started" }).ClickAsync();
await Expect(page.GetByText("Installation").First).ToBeVisibleAsync();
await page.ScreenshotAsync(new() { Path = "docs.png", FullPage = true });

Code Explained

Playwright.CreateAsync() — start driver
new() { Headless = false } — target-typed options
…Async() — every call is awaited
Expect(...) — from Assertions static import
AriaRole.Link — role enum

⚠ Common Mistakes

  • Running playwright.ps1 before dotnet build; the script doesn't exist yet
  • Forgetting await on Expect(...); assertions silently don't run
  • Disposing the browser while pages are still in use

✓ Tips & Best Practices

  • Set PLAYWRIGHT_BROWSERS_PATH in CI so browsers are cached between runs
  • Use codegen --target csharp-nunit for test scaffolding
  • Use events (page.Request +=) for network logging
