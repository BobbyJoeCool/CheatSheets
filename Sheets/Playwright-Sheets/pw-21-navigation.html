Navigation & Load States

goto() · waitUntil · baseURL · waitForURL() · waitForLoadState() · reload() · goBack()

Navigating Pages

page.goto() loads a URL and waits for the load event by default. With baseURL set in config, pass paths like '/login'. After a click causes navigation, you rarely need explicit waits: the next locator action or toHaveURL assertion waits for the new page. Use waitForURL() when you need to block until a redirect chain finishes.

Notes

  • goto returns the main Response (or null for same-document)
  • goto throws on network errors, not on 404/500 status
  • networkidle is discouraged; assert on content instead
  • SPAs: route changes are not loads; assert URL or content

Examples

await page.goto('/login');                                 // baseURL + /login
const res = await page.goto('/products/42');
expect(res?.status()).toBe(200);
await page.goto('/', { waitUntil: 'domcontentloaded' });  // don't wait for images
await page.goto('https://other.site', { referer: 'https://google.com' });

await page.getByRole('button', { name: 'Sign in' }).click();
await page.waitForURL('**/dashboard');                     // glob
await page.waitForURL(/\/orders\/\d+/, { waitUntil: 'commit' });
await expect(page).toHaveURL('/dashboard');               // usually enough

await page.waitForLoadState('domcontentloaded');           // after popup/new page
await page.reload();
await page.goBack();
await page.goForward();
await page.setContent('<button>Hi</button>');              // inline HTML

Code Explained

goto(path) — resolved against baseURL
waitUntil — which event counts as loaded
waitForURL — glob, RegExp or predicate
toHaveURL — assertion that also waits
setContent — render an HTML string

waitUntil Values

ValueWaits For
loadwindow load event (default)
domcontentloadedDOMContentLoaded
networkidle500 ms no network (avoid)
commitResponse received, doc starts

Navigation APIs

⚠ Common Mistakes

  • waitForNavigation() in new code; it's deprecated and racy, use waitForURL or assertions
  • waitUntil: 'networkidle' on apps with polling or websockets; it never settles
  • Checking page.url() right after a click; it may still be the old URL

✓ Tips & Best Practices

  • Set baseURL so tests run against any environment with one config change
  • Use domcontentloaded to speed up pages with heavy images or ads
  • After login redirects, assert a heading on the target page instead of the URL alone

Quick Summary

  • goto(path) — navigate with baseURL
  • waitUntil — load, domcontentloaded, commit
  • waitForURL() — block for redirects
  • toHaveURL() — preferred URL check
