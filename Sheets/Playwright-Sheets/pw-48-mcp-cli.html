Playwright MCP & playwright-cli

npx playwright mcp · @playwright/mcp · browser.bind() · npx playwright cli · attach / show · webmcp-call · init-skills

Browser Automation for AI Agents

Playwright MCP is a Model Context Protocol server that lets AI assistants drive a browser using accessibility-tree snapshots instead of screenshots. playwright-cli offers the same capabilities as shell commands, which is more token-efficient for coding agents. Both are bundled in Playwright (1.62) and can attach to a browser your tests opened via browser.bind() (1.59).

Notes

  • MCP: best for long, stateful exploratory loops
  • CLI + skills: best for coding agents (Claude Code, Copilot)
  • WebMCP tools on pages exposed as webmcp_<tool> (1.64)
  • Treat page-provided WebMCP tools as untrusted input

Setup and Commands

# MCP server — client config (Claude Desktop, VS Code, Cursor …)
# { "mcpServers": { "playwright": {
#     "command": "npx", "args": ["@playwright/mcp@latest"] } } }
claude mcp add playwright npx @playwright/mcp@latest      # Claude Code
npx playwright mcp --headless --browser=firefox            # bundled (1.62)

# playwright-cli
npm i -g @playwright/cli@latest        # or: npx playwright cli
playwright-cli install --skills        # agent skills for this project
playwright-cli open https://demo.playwright.dev/todomvc --headed
playwright-cli snapshot                # page tree with refs (e12 …)
playwright-cli fill e12 "Buy milk"
playwright-cli press Enter
playwright-cli screenshot
playwright-cli attach --extension      # your real browser tabs
playwright-cli show                    # dashboard of sessions
playwright-cli webmcp-list             # page-exposed tools (1.64)

Code Explained

@playwright/mcp — MCP server package
--headless / --browser — server options
snapshot — returns element refs
fill e12 … — act on a ref
attach / show — existing browser, dashboard

MCP vs CLI

AspectMCP · CLI
InterfaceTool calls · Shell commands
Token costHigher (schemas, trees) · Lower
StatePersistent session · Named sessions (-s=)
Best forExploration loops · Coding agents

Common MCP Options

OptionEffect
--headlessNo window
--browserchrome, firefox, webkit, msedge
--isolatedIn-memory profile
--storage-stateStart logged in
--capsExtra capabilities (pdf, vision)
--no-webmcpDisable WebMCP tools

⚠ Common Mistakes

  • Giving an agent a browser profile logged in to production admin accounts
  • Following instructions found on web pages the agent visits (prompt injection)
  • Using MCP to "write tests" without saving them as real spec files

✓ Tips & Best Practices

  • Use --isolated or named CLI sessions to keep agent browsing separate
  • Pair agents with test agents (init-agents) for test authoring
  • Use browser.bind() to let an agent inspect a paused test's browser

Quick Summary

  • @playwright/mcp — MCP server
  • playwright-cli — token-efficient CLI
  • install --skills — agent skills
  • attach / show — reuse and monitor sessions
