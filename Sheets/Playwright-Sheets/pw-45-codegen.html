Recording Tests

npx playwright codegen <url> opens a browser plus the Inspector and writes code as you click and type. It picks resilient locators (role, label, text, test id), and the toolbar adds assertions (visible, text, value, ARIA snapshot) by clicking elements. Output can target any supported language and runner. Since 1.59, page.pickLocator() lets scripts and agents request a locator interactively.

Notes

  • Generated code is a starting point; refactor into page objects
  • Codegen honours testIdAttribute via --test-id-attribute
  • --save-storage records login state for reuse
  • Recording inside an existing test: VS Code "Record at cursor"

Commands

npx playwright codegen                                   # blank page
npx playwright codegen http://localhost:3000
npx playwright codegen --target=python-pytest demo.playwright.dev/todomvc
npx playwright codegen -o tests/recorded.spec.ts localhost:3000
npx playwright codegen --device="iPhone 15" localhost:3000
npx playwright codegen --viewport-size="1280,720" --color-scheme=dark localhost:3000
npx playwright codegen --lang="de-DE" --timezone="Europe/Berlin" localhost:3000
npx playwright codegen --geolocation="41.89,12.49" localhost:3000
npx playwright codegen --save-storage=auth.json localhost:3000/login   # log in, close
npx playwright codegen --load-storage=auth.json localhost:3000         # start logged in
npx playwright codegen --test-id-attribute=data-qa localhost:3000
npx playwright codegen --http-credentials=user:pass intranet.local     # 1.63

Code Explained

--target — language/runner of output
-o — write to a file
--device / emulation flags — record mobile, locale, dark
--save-storage — capture auth state
--load-storage — reuse it

⚠ Common Mistakes

  • Committing raw recordings full of nth() and duplicated steps
  • Recording against production with real accounts and saving the storage file in git
  • Expecting codegen to record waits; it relies on auto-waiting, add assertions yourself

✓ Tips & Best Practices

  • Record the happy path, then add edge cases by hand
  • Use the assertion buttons; recordings without assertions test nothing
  • Use codegen just to discover locators for tricky elements

Quick Summary

  • codegen <url> — record actions
  • --target — choose language
  • assert buttons — add expectations
  • --save/--load-storage — auth for recording
