CLI Filtering & Flags

file:line · --grep · --grep-invert · --project · --last-failed · --only-changed · --list · --max-failures

Choosing What Runs

The test command combines several filters: file filters (positional regex on paths, optionally :line), title filters (--grep/-g, --grep-invert/-G), project filters (--project, repeatable, globs allowed) and change-based filters (--last-failed, --only-changed). Everything a filter selects still respects test.only and skip annotations.

Notes

  • Grep matches the full title path incl. project, file and tags
  • --only-changed[=ref] uses git to pick affected test files
  • --last-failed reads test-results/.last-run.json
  • --list prints what would run without running it

Recipes

npx playwright test tests/cart                       # files under tests/cart
npx playwright test cart.spec.ts:42                  # one test by line
npx playwright test cart.spec.ts:42:5                # line + column
npx playwright test -g "applies coupon"              # title contains
npx playwright test -g "@smoke" -G "@slow"           # tag in, tag out
npx playwright test --project=chromium --project=firefox
npx playwright test --project="mobile-*"             # glob on project names
npx playwright test --last-failed                    # only last failures
npx playwright test --only-changed=origin/main       # files touched vs main
npx playwright test --list -g "@smoke"               # dry run
npx playwright test -x                               # stop at first failure
npx playwright test --max-failures=5
npx playwright test --repeat-each=10 --workers=1
npx playwright test --pass-with-no-tests             # don't fail empty runs
npx playwright test --tsconfig=tsconfig.e2e.json

Code Explained

positional — regex on file path
:line[:col] — exact test or describe
-g / -G — include / exclude titles
--project — name or glob, repeatable
--only-changed — git-aware selection
-x — fail fast

⚠ Common Mistakes

  • npx playwright test "applies coupon": positional args filter paths, not titles
  • Unquoted globs (--project=mobile-*) expanded by the shell
  • Expecting --last-failed to work after cleaning test-results/

✓ Tips & Best Practices

  • Put --only-changed=origin/main in a fast pre-merge CI job
  • Use --list to check tag filters before a long run
  • Combine -x with --headed while fixing one broken flow

Quick Summary

  • path[:line] — file / test selection
  • -g / -G — title include / exclude
  • --project — choose projects
  • --last-failed / --only-changed — smart reruns
