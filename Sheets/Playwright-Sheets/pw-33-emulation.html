devices['iPhone 15'] · viewport · locale · timezoneId · geolocation · colorScheme · reducedMotion · forcedColors

Emulating Devices and Environments

The devices registry bundles user agent, viewport, device scale factor, touch and isMobile for hundreds of phones, tablets and desktops. On top of that, any context can emulate locale, time zone, geolocation, color scheme, reduced motion, forced colors and contrast, either globally in use, per file with test.use(), or at runtime with page.emulateMedia().

Notes

  • Mobile emulation runs in desktop engines (WebKit ≈ Safari iOS)
  • isMobile is Chromium-only; Firefox ignores it
  • Since 1.64, screen is copied from device descriptors
  • Geolocation needs permissions: ['geolocation']

Examples

// playwright.config.ts
projects: [
  { name: 'Mobile Safari', use: { ...devices['iPhone 15'] } },
  { name: 'Pixel', use: { ...devices['Pixel 7'] } },
],

// per file
test.use({
  locale: 'fr-FR',
  timezoneId: 'Europe/Paris',
  geolocation: { latitude: 48.8584, longitude: 2.2945 },
  permissions: ['geolocation'],
  colorScheme: 'dark',
  reducedMotion: 'reduce',             // also contrast / forcedColors (1.63)
});

// at runtime
await page.emulateMedia({ colorScheme: 'light', media: 'print' });
await page.setViewportSize({ width: 375, height: 812 });
await context.setOffline(true);

Code Explained

devices[name] — full device profile
locale / timezoneId — Intl + Date behaviour
geolocation + permission — fake GPS
colorScheme — prefers-color-scheme
emulateMedia — switch at runtime (print, dark)

⚠ Common Mistakes

  • Expecting devices['iPhone 15'] to behave exactly like iOS Safari; it's WebKit on desktop OS
  • Setting geolocation without granting the permission; the page sees a denial
  • Using viewport: null with device profiles; it disables the emulated size

✓ Tips & Best Practices

  • List names with Object.keys(devices)
  • Test reducedMotion: 'reduce' to catch animation-dependent UI
  • Use locale/timezoneId to reproduce date bugs users report

Quick Summary

  • devices[...] — phone/tablet/desktop profiles
  • locale / timezoneId — i18n and dates
  • colorScheme / reducedMotion — media features
  • emulateMedia() — switch at runtime
