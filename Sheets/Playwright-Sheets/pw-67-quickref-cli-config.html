⚠ Common Mistakes

  • Positional args as titles; they filter file paths
  • baseURL outside use
  • CI without --with-deps on Linux

✓ Tips & Best Practices

  • Branch config on process.env.CI
  • trace: 'on-first-retry' + HTML report on CI
  • Use --last-failed for fast iteration
