Playwright Under Other Runners

Vitest 4 browser mode runs component and unit tests in a real browser using Playwright as the provider. jest-playwright is no longer actively maintained; new Jest users should move e2e tests to @playwright/test. For BDD, playwright-bdd compiles Gherkin .feature files into Playwright tests, so you keep fixtures, parallelism and reports.

Notes

  • npm i -D vitest @vitest/browser-playwright
  • Vitest tests import page from vitest/browser
  • npx bddgen generates specs from features before playwright test
  • Cucumber.js + library mode also works, but loses runner features

Vitest Browser Mode + playwright-bdd

// vitest.config.ts
import { defineConfig } from 'vitest/config';
import { playwright } from '@vitest/browser-playwright';
export default defineConfig({
  test: { browser: { enabled: true, provider: playwright(),
                     instances: [{ browser: 'chromium' }, { browser: 'webkit' }] } },
});
// playwright.config.ts with playwright-bdd
import { defineBddConfig } from 'playwright-bdd';
const testDir = defineBddConfig({ features: 'features/*.feature',
                                  steps: 'features/steps/*.ts' });
export default defineConfig({ testDir });
// features/steps/cart.ts
import { createBdd } from 'playwright-bdd';
const { Given, When, Then } = createBdd();
Given('I am on the shop', async ({ page }) => { await page.goto('/'); });
When('I add {string} to the cart', async ({ page }, item: string) => {
  await page.getByRole('button', { name: `Add ${item}` }).click();
});
Then('the cart shows {int} item(s)', async ({ page }, n: number) =>
  expect(page.getByTestId('cart-count')).toHaveText(String(n)));

Code Explained

provider: playwright() — Vitest drives Playwright
instances — browsers to run
defineBddConfig — features + steps → generated tests
createBdd() — Given/When/Then with fixtures
{string} / {int} — Cucumber expressions

⚠ Common Mistakes

  • Running playwright test without bddgen first; generated specs are stale or missing
  • Using Vitest browser mode for full e2e flows; it's built for component/unit scope
  • Mixing Jest's expect with Playwright's in one file

✓ Tips & Best Practices

  • Add "test:bdd": "bddgen && playwright test" to scripts
  • Keep step definitions thin; call page objects
  • Share locators between Vitest component tests and Playwright e2e via roles
