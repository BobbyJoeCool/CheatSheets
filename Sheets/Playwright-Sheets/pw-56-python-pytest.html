pytest-playwright

The pytest-playwright plugin provides fixtures (page, context, browser, new_context …) and CLI flags for browsers, headed mode, tracing, video and screenshots. Configure context defaults by overriding browser_context_args in conftest.py, and parallelize with pytest-xdist. For async tests use pytest-playwright-asyncio with pytest-asyncio.

Notes

  • Test files: test_*.py; functions test_*
  • CLI flags only affect the built-in browser/context/page fixtures
  • --base-url comes from pytest-base-url
  • Async tests: mark with asyncio(loop_scope="session")

conftest.py + test

# conftest.py
import pytest

@pytest.fixture(scope="session")
def browser_context_args(browser_context_args):
    return {**browser_context_args, "viewport": {"width": 1440, "height": 900},
            "storage_state": "playwright/.auth/user.json"}

# test_cart.py
from playwright.sync_api import Page, expect

def test_add_to_cart(page: Page):
    page.goto("/products")                                  # uses --base-url
    page.get_by_role("button", name="Add to cart").first.click()
    expect(page.get_by_test_id("cart-count")).to_have_text("1")

@pytest.mark.skip_browser("webkit")
@pytest.mark.browser_context_args(locale="de-DE", timezone_id="Europe/Berlin")
def test_german_dates(page: Page):
    page.goto("/orders")
    expect(page.get_by_text("01.03.2026")).to_be_visible()

Code Explained

browser_context_args — session-wide context options
page: Page — type hint for autocompletion
.first — property, not method, in Python
skip_browser / only_browser — markers
browser_context_args marker — per-test override

⚠ Common Mistakes

  • Overriding browser_context_args without merging the incoming dict; you lose plugin defaults
  • Expecting --headed to affect browsers you launch manually
  • Very high -n values; more workers than cores slows everything down

✓ Tips & Best Practices

  • Put common flags in pytest.ini: addopts = --browser chromium --tracing retain-on-failure
  • Use breakpoint() with --headed for interactive debugging
  • Run pytest --numprocesses auto in CI

Quick Summary

  • page fixture — fresh page per test
  • browser_context_args — context defaults
  • markers — per-test browser/context control
  • -n auto — parallel via xdist
