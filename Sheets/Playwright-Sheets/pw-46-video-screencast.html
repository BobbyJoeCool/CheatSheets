Screenshots, Video & Screencast

screenshot option · video modes · fps · recordVideo · page.screencast · showActions · chapters

Capturing Media

The runner can attach a screenshot and a video of each test automatically, controlled by use.screenshot and use.video. Manual page.screenshot() / locator.screenshot() capture images on demand (PNG, JPEG or WebP). The page.screencast API (1.59) records polished demo videos with action annotations, chapter titles and overlays, and can stream frames.

Notes

  • Videos are written when the context closes
  • video.fps option added in 1.64; fontSize deprecated
  • WebP screenshots: .webp names + quality (1.62)
  • Library mode: browser.newContext({ recordVideo: { dir } })

Examples

// playwright.config.ts
use: {
  screenshot: 'only-on-failure',                 // 'on' | 'off'
  video: { mode: 'retain-on-failure', size: { width: 1280, height: 720 }, fps: 15 },
},

// manual screenshots
await page.screenshot({ path: 'shots/home.png', fullPage: true });
await page.screenshot({ path: 'shots/home.webp', quality: 80 });
await page.getByTestId('chart').screenshot({ path: 'shots/chart.png' });
const buffer = await page.screenshot();          // in memory

// demo recording with annotations (1.59)
await page.screencast.start({ path: 'demo.webm', size: { width: 1280, height: 800 } });
await page.screencast.showChapter('Checkout', { description: 'Pay with card' });
await page.screencast.showActions({ position: 'bottom' });
await page.getByRole('button', { name: 'Pay' }).click();
await page.screencast.stop();

⚠ Common Mistakes

  • video: 'on' for the whole suite in CI; large artifacts and slower runs
  • Reading the video path before the context closes; the file isn't finished
  • Using screenshots as assertions; use toHaveScreenshot for comparisons

✓ Tips & Best Practices

  • retain-on-failure gives videos only where they help
  • Use screencast chapters to make product demo videos from tests
  • Attach targeted screenshots with testInfo.attach at key steps

Quick Summary

  • use.screenshot / use.video — automatic capture
  • page.screenshot() — manual images
  • video.fps — frame rate (1.64)
  • page.screencast — annotated recordings
