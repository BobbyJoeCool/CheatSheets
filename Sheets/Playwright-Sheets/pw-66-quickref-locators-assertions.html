⚠ Common Mistakes

  • Plain expect(await l.textContent()) instead of await expect(l).toHaveText()
  • Missing await before web-first assertions
  • nth() where a filter() by content would be stable

✓ Tips & Best Practices

  • Priority: role → label → placeholder → text → test id → CSS
  • Scope with filter/within before picking a role
  • Raise timeouts per assertion, not globally

Quick Summary

  • getByRole — default locator
  • filter / within — narrow
  • actions auto-wait
  • await expect(...) — auto-retry
