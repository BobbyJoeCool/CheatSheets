The Stories-and-Gallery Model

Since 1.62, component testing needs no extra package. You write small story components next to your components, and a gallery page (served by your own Vite/dev server) exposes window.mount({ story, props }). The built-in mount fixture opens the gallery, mounts the story and returns a Locator for its root. Any framework works if your dev server can render the gallery.

Notes

  • @playwright/experimental-ct-* packages are discontinued
  • npx playwright init-skills installs a skill that can generate the gallery
  • Gallery exposes window.mount() / window.unmount() into #root

playwright.config.ts + Gallery (React, Vite)

// playwright.config.ts
projects: [{
  name: 'components',
  testDir: './tests/components',
  use: {
    baseURL: 'http://localhost:5173/playwright/gallery/index.html',
    serviceWorkers: 'block', reuseContext: true,
  },
}],
webServer: { command: 'npm run dev', url: 'http://localhost:5173' },

// playwright/gallery/main.tsx  (index.html has <div id="root"> + this script)
import { createRoot } from 'react-dom/client';
const modules = import.meta.glob('/src/**/*.story.tsx', { eager: true });
const root = createRoot(document.getElementById('root')!);
window.mount = async ({ story, props = {} }) => {           // 'components/Button/Primary'
  const i = story.lastIndexOf('/');
  const mod: any = modules[`/src/${story.slice(0, i)}.story.tsx`];
  const Story = mod?.[story.slice(i + 1)];
  if (!Story) throw new Error(`Unknown story: ${story}`);
  root.render(<Story {...props} />);
};
window.unmount = async () => root.render(null);

Code Explained

components project — own testDir and baseURL
baseURL — the gallery page
reuseContext — fast, shared context
import.meta.glob — collect stories (Vite)
window.mount — render a story by id

⚠ Common Mistakes

  • Keeping @playwright/experimental-ct-*; packages are no longer published or updated
  • Pointing baseURL at the app root instead of the gallery page
  • Importing app-wide side effects (analytics, service workers) into the gallery

✓ Tips & Best Practices

  • Stay on 1.62 until you migrate, then move scenario setup into stories
  • Load global CSS and providers in the gallery so components render as in the app
  • Run the components project separately: --project=components

Quick Summary

  • stories — scenarios as components
  • gallery — your page exposing window.mount
  • mount fixture — built in, returns Locator
  • components project — config entry point
