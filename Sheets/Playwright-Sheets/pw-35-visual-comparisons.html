Screenshot Testing

await expect(page).toHaveScreenshot() compares a screenshot with a stored baseline. The first run writes the baseline and fails (by design); later runs diff pixel-by-pixel. Playwright waits for two identical consecutive screenshots, disables animations and hides the caret to reduce noise. Baselines are stored per browser and per OS, because font rendering differs.

Notes

  • Baseline path: <file>-snapshots/<name>-<project>-<platform>.png
  • WebP baselines supported (1.62/1.64)
  • --update-snapshots=missing now passes (1.64)
  • toMatchSnapshot() compares arbitrary text/buffers

Examples

await expect(page).toHaveScreenshot();                       // auto-named
await expect(page).toHaveScreenshot('landing.png', { fullPage: true });
await expect(page.getByTestId('pricing-card')).toHaveScreenshot('card.png');

await expect(page).toHaveScreenshot({
  maxDiffPixels: 100,                         // or maxDiffPixelRatio: 0.01
  threshold: 0.2,                             // per-pixel color tolerance 0–1
  mask: [page.getByTestId('clock'), page.locator('.ad')],   // pink boxes
  animations: 'disabled',
  stylePath: './tests/screenshot.css',        // hide dynamic bits via CSS
});

// playwright.config.ts
expect: { toHaveScreenshot: { maxDiffPixels: 50, type: 'webp' } },
snapshotPathTemplate: '{testDir}/__screenshots__/{testFilePath}/{arg}{ext}',

Code Explained

no name — derived from test title
locator screenshot — element only
maxDiffPixels — tolerated changed pixels
mask — cover dynamic regions
stylePath — inject CSS for the shot
snapshotPathTemplate — custom layout

Updating Baselines

CommandEffect
--update-snapshotsSame as =changed
=allRewrite every baseline
=changedOnly mismatches + new
=missingOnly create new
=noneNever write

⚠ Common Mistakes

  • Committing baselines made on macOS and running CI on Linux; every test fails
  • Full-page screenshots of pages with live data; mask or mock it
  • Blindly running --update-snapshots after failures; review the diff in the HTML report first

✓ Tips & Best Practices

  • Generate and update baselines inside the official Playwright Docker image
  • Keep visual tests in their own project with one browser
  • Prefer element screenshots of components over whole pages

Quick Summary

  • toHaveScreenshot() — visual regression
  • maxDiffPixels / threshold — tolerance
  • mask / stylePath — hide noise
  • --update-snapshots — refresh baselines
