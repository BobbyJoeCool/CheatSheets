Installing Playwright

The quickest start is npm init playwright@latest, which installs @playwright/test, writes playwright.config.ts, adds an example test and optionally a GitHub Actions workflow. Browsers are separate downloads stored in a shared cache; npx playwright install fetches the versions matched to your installed Playwright release. On Linux CI, --with-deps also installs the OS libraries the browsers need.

Requirements

  • Node.js 20, 22 or 24 (latest LTS recommended)
  • Windows 10+/Server 2016+, macOS 14+ (WebKit needs macOS 15+), Ubuntu 22.04/24.04/26.04, Debian 12/13
  • Ubuntu 20.04 and Debian 11 are no longer supported
  • Browser cache: ~/.cache/ms-playwright (Linux), ~/Library/Caches/ms-playwright (macOS), %USERPROFILE%\AppData\Local\ms-playwright (Windows)

Install Commands

# New project (interactive: TS/JS, test dir, GitHub Actions, browsers)
npm init playwright@latest
yarn create playwright      # or: pnpm create playwright

# Add to an existing project
npm i -D @playwright/test
npx playwright install                   # all default browsers
npx playwright install chromium          # one browser
npx playwright install --with-deps       # browsers + OS packages (CI)
npx playwright install-deps              # OS packages only
npx playwright install --no-remove       # keep older browser builds
npx playwright install --list            # show installed browsers

# Upgrade
npm i -D @playwright/test@latest && npx playwright install
npx playwright --version                 # Version 1.64.x

Code Explained

npm init playwright@latest — scaffold + install in one step
install <browser> — chromium, firefox, webkit, chrome, msedge
--with-deps — apt packages for Linux; needs sudo
--no-remove — don't delete stale browsers on update
Re-run install after every Playwright upgrade

⚠ Common Mistakes

  • Upgrading @playwright/test without re-running npx playwright install; tests fail with "Executable doesn't exist"
  • Running --with-deps locally on macOS/Windows; it only matters on Linux
  • Committing the browser cache or node_modules/.cache to git

✓ Tips & Best Practices

  • Pin the exact version in package.json so CI and laptops use the same browsers
  • Install only the browsers you test (install chromium) to speed up CI
  • Use the official Docker image when OS dependencies are painful

Quick Summary

  • npm init playwright@latest — scaffold everything
  • npx playwright install — download matching browsers
  • --with-deps — add Linux system packages
  • PLAYWRIGHT_BROWSERS_PATH — move the browser cache
