Frames, Shadow DOM and Lists

Content inside an <iframe> needs a FrameLocator: page.frameLocator(selector) or locator.contentFrame(). Since 1.63, page.frameLocator() searches across all frames. Open shadow DOM is pierced automatically by every locator except XPath. When a locator matches many elements, assert with toHaveCount/toHaveText([...]), or iterate with all().

Notes

  • Closed shadow roots are not supported
  • count() and all() do not wait; assert first, then iterate
  • Strict mode error lists every match — read it to fix the locator
  • page.frames() / page.frame({ url }) give Frame objects

Examples

// iframes
const stripe = page.frameLocator('iframe[title="Secure card input"]');
await stripe.getByPlaceholder('Card number').fill('4242 4242 4242 4242');
const map = page.getByTitle('Embedded map').contentFrame();
await map.getByRole('button', { name: 'Zoom in' }).click();

// shadow DOM: write locators as if the shadow root weren't there
await page.getByRole('button', { name: 'Details' }).click(); // in <x-details>

// lists
const items = page.getByRole('listitem');
await expect(items).toHaveCount(3);                     // waits
await expect(items).toHaveText(['Apple', 'Banana', 'Cherry']);
for (const item of await items.all()) {                 // no waiting!
  console.log(await item.textContent());
}
const names = await items.allTextContents();            // string[]

Code Explained

frameLocator() — locate inside an iframe
contentFrame() — locator → frame locator
shadow DOM — pierced automatically
toHaveCount / toHaveText([]) — wait for list state
all() — snapshot array of locators

⚠ Common Mistakes

  • Calling page.getByText() for text inside an iframe; it never matches, use a FrameLocator
  • Looping over await items.all() before the list has loaded; it returns [] silently
  • Using XPath for shadow-DOM components; XPath does not pierce shadow roots

✓ Tips & Best Practices

  • Assert toHaveCount before all() so the list is ready
  • Prefer toHaveText([...]) over manual loops for list checks
  • For cross-origin iframes (payments) target by title attribute

Quick Summary

  • frameLocator() — enter an iframe
  • shadow DOM — transparent to locators
  • toHaveCount / toHaveText([]) — list assertions
  • all() — iterate after waiting
