Form Controls and File Uploads

Checkboxes and radios use check()/uncheck()/setChecked(), which verify the state actually changed. <select> elements use selectOption() by value, label or index. File inputs accept paths or in-memory buffers through setInputFiles(). For drop zones without an <input>, use locator.drop() (1.60) or catch the filechooser event.

Notes

  • selectOption returns the selected values
  • setInputFiles([]) clears the selection
  • Custom (non-native) dropdowns: click to open, then getByRole('option')
  • Paths are relative to the current working directory

Examples

await page.getByLabel('I agree').check();
await page.getByLabel('Newsletter').uncheck();
await page.getByLabel('Dark mode').setChecked(true);
await page.getByLabel('Express').check();                 // radio

const size = page.getByLabel('Size');
await size.selectOption('m');                             // by value
await size.selectOption({ label: 'Large' });              // by visible label
await size.selectOption({ index: 0 });
await page.getByLabel('Tags').selectOption(['a', 'b']);   // multi-select

const file = page.getByLabel('Avatar');
await file.setInputFiles('fixtures/avatar.png');
await file.setInputFiles(['a.pdf', 'b.pdf']);
await file.setInputFiles({ name: 'n.txt', mimeType: 'text/plain',
                          buffer: Buffer.from('hi') });           // in memory
await file.setInputFiles([]);                             // clear

const chooser = page.waitForEvent('filechooser');         // no <input>
await page.getByRole('button', { name: 'Upload' }).click();
await (await chooser).setFiles('report.csv');
await page.getByTestId('dropzone').drop({ files: 'photo.jpg' });   // 1.60

Code Explained

check() — asserts the box becomes checked
selectOption() — value, { label }, { index }
setInputFiles() — paths, buffers, or []
filechooser — start waiting before clicking
drop() — simulate an external file drop

Matching Assertions

⚠ Common Mistakes

  • click() on a checkbox that toggles twice via label + input; check() is idempotent
  • selectOption on a styled div dropdown; it only works on native <select>
  • Awaiting the filechooser promise before clicking; it never resolves

✓ Tips & Best Practices

  • Keep upload fixtures in a fixtures/ folder and resolve with path.join(__dirname, …)
  • Use in-memory buffers for generated files (CSV, JSON) to avoid temp files
  • Assert with toHaveValue after selectOption to catch JS-driven resets

Quick Summary

  • check/uncheck/setChecked — toggles with verification
  • selectOption() — native selects
  • setInputFiles() — file inputs
  • drop() / filechooser — other upload UIs
