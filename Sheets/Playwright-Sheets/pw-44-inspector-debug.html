Inspector & Debug Mode

--debug · --debug=cli · PWDEBUG=1 · page.pause() · DEBUG=pw:api · locator.highlight()

Live Debugging

--debug runs headed with one worker, no timeout, and opens the Playwright Inspector, which pauses before each action so you can step, see the target highlighted, and edit locators live. page.pause() stops at a specific line. Since 1.59, --debug=cli exposes the paused session to playwright-cli so a coding agent can inspect it.

Notes

  • PWDEBUG=1 = --debug for any runner (Python, Java, .NET)
  • PWDEBUG=console exposes playwright object in DevTools
  • IDE breakpoints work with --debug or VS Code debugging
  • DEBUG=pw:api logs every API call to stderr

Debugging Tools

// run one test under the Inspector
// npx playwright test cart.spec.ts:18 --debug
// PWDEBUG=1 npx playwright test          (same, via env var)
// npx playwright test --debug=cli        (agent-driven, 1.59)

test('checkout', async ({ page }) => {
  await page.goto('/cart');
  await page.pause();                                   // opens Inspector here
  await page.getByRole('button', { name: 'Checkout' }).highlight();   // visual check
  console.log(await page.getByRole('row').count());     // quick probe
});

// verbose logs
// DEBUG=pw:api npx playwright test                    API calls
// DEBUG=pw:browser npx playwright test                browser stdout
// in DevTools console with PWDEBUG=console:
//   playwright.$('text=Checkout')  playwright.inspect(sel)  playwright.locator(sel)

Code Explained

--debug — headed, step-through, no timeout
page.pause() — breakpoint in the browser
highlight() — outline what a locator matches
DEBUG=pw:api — log calls and waits
PWDEBUG=console — DevTools helpers

⚠ Common Mistakes

  • Leaving page.pause() in committed code; CI hangs until the test timeout
  • Debugging with many workers; use --debug (forces one worker) or --workers=1
  • Reading only the error message; the Inspector's log shows each actionability retry

✓ Tips & Best Practices

  • Combine cart.spec.ts:18 --debug to start at exactly one test
  • Use highlight() while tuning locators in headed mode
  • Use DEBUG=pw:api in CI to see the last action before a hang

Quick Summary
