Playwright for Java

The Java binding (com.microsoft.playwright:playwright) uses camelCase methods and options builder objects instead of object literals. Playwright.create() starts the driver; close it with try-with-resources. Assertions come from PlaywrightAssertions.assertThat. With JUnit 5, @UsePlaywright injects Page, BrowserContext and friends into test methods; TestNG uses manual lifecycle hooks.

Notes

  • Maven artifact: com.microsoft.playwright : playwright : 1.64.0
  • CLI = main class com.microsoft.playwright.CLI (via mvn exec:java)
  • Playwright objects are not thread-safe: one per thread
  • Roles are enums: AriaRole.BUTTON

Maven + JUnit 5 Test

import com.microsoft.playwright.*;
import com.microsoft.playwright.junit.*;
import com.microsoft.playwright.options.AriaRole;
import static com.microsoft.playwright.assertions.PlaywrightAssertions.assertThat;

@UsePlaywright(LoginTest.CustomOptions.class)
public class LoginTest {
  public static class CustomOptions implements OptionsFactory {
    @Override public Options getOptions() {
      return new Options().setHeadless(true).setBaseUrl("http://localhost:3000");
    }
  }
  @Test
  void signsIn(Page page) {                                  // injected fixture
    page.navigate("/login");
    page.getByLabel("Email").fill("ada@example.com");
    page.getByRole(AriaRole.BUTTON,
        new Page.GetByRoleOptions().setName("Sign in")).click();
    assertThat(page).hasURL("http://localhost:3000/dashboard");
  }
}

Code Explained

@UsePlaywright — JUnit 5 extension
OptionsFactory — headless, baseUrl, context
Page page param — injected per test
GetByRoleOptions().setName() — options builder
assertThat(...).hasURL() — web-first assertion

⚠ Common Mistakes

  • Sharing one Playwright instance across parallel threads; create one per thread
  • Forgetting to close Playwright; driver processes leak
  • Using page.goto from TS examples; Java uses navigate

✓ Tips & Best Practices

  • Enable JUnit parallel execution; @UsePlaywright gives each thread its own objects
  • Use PLAYWRIGHT_JAVA_SRC so codegen-generated traces link to sources
  • Generate code with codegen --target java-junit

Quick Summary

  • options builders — .setX() chains
