UI Mode

--ui · watch mode · timeline · pick locator · filters · --ui-host / --ui-port

Interactive UI Mode

npx playwright test --ui opens a desktop-style app for exploring, running and debugging tests. Every action is captured like a trace: a timeline of screenshots, DOM snapshots you can inspect, network, console, source and errors. Watch mode re-runs a test whenever its file changes, making UI mode the most productive way to write tests.

Notes

  • Uses the same config and projects as the CLI
  • --ui-host=0.0.0.0 --ui-port=8080 serves it to a browser (containers, remote)
  • Filter by text, @tag, status and project in the sidebar
  • Pick locator → click an element in a snapshot to get its locator

Launching

npx playwright test --ui                         # open UI mode
npx playwright test --ui tests/cart              # pre-filtered
npx playwright test --ui --project=chromium
npx playwright test --ui-host=0.0.0.0 --ui-port=9323   # browser access
# Docker: expose 9323 and open http://localhost:9323

Tips for Use

Eye icon — toggle watch mode per test or file
Snapshots are live DOM: use DevTools on them
Locator field — type a locator to highlight matches
Run a single test repeatedly while editing

⚠ Common Mistakes

  • Debugging failures only from terminal output when UI mode shows the DOM at each step
  • Leaving watch on for the whole suite; every save re-runs everything
  • Forgetting UI mode respects fullyParallel/workers; heavy suites still use many cores

✓ Tips & Best Practices

  • Write new tests in UI mode with watch on for instant feedback
  • Use the Pick Locator tool to settle selector choices
  • Open the snapshot in a new window to use browser DevTools on it

Quick Summary

  • --ui — interactive runner
  • watch mode — rerun on save
  • timeline + snapshots — time-travel debugging
  • --ui-host/--ui-port — remote access
