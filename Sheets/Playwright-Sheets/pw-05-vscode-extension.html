Playwright Test for VS Code

The official Playwright Test for VS Code extension (ms-playwright.playwright) integrates the runner into the editor. Tests appear in the Test Explorer and get run/debug icons in the gutter. A Playwright sidebar lets you choose projects, toggle Show browser, Pick locator from a live page, Record new tests with codegen, and open traces without leaving the editor.

Notes

  • Needs @playwright/test installed in the workspace
  • Detects multiple config files; pick the active one in the sidebar
  • Breakpoints work in tests and page objects (debug mode)
  • Run the "Install Playwright" command to scaffold a new project

Workflow

test('checkout', async ({ page }) => {
  await page.goto('/cart');
  // 1. put cursor here → "Record at cursor"
  // 2. click through the app; steps are typed in live
  await page.getByRole('button', { name: 'Checkout' }).click();
  // 3. set a breakpoint on the next line → Debug test
  await expect(page.getByText('Order placed')).toBeVisible();
});
// 4. hover a locator in the editor → it highlights in the open browser

Code Explained

Record at cursor — fastest way to extend a test
Breakpoints — pause with full variable inspection
Live highlight — editing a locator re-highlights matches
Show browser — keeps one window open between runs

⚠ Common Mistakes

  • Opening the folder above the project root; the extension can't find the config
  • Leaving "Show browser" on in parallel runs; everything funnels through one window
  • Expecting codegen output to be final; rename and restructure recorded steps

✓ Tips & Best Practices

  • Use "Pick locator" to settle locator debates quickly
  • Run a single test from the gutter instead of the whole file while iterating
  • Combine with UI mode (--ui) for watch mode and timeline debugging

Quick Summary

  • gutter icons — run/debug one test
  • Pick locator — copy a robust locator
  • Record new / at cursor — codegen in editor
  • Show trace viewer — debug in VS Code
