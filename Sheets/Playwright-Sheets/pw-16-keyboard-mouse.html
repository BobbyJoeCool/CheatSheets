Sheet 16

Keyboard, Mouse & Drag

press() · keyboard.down/up · mouse.move/wheel · hover() · dragTo() · focus() · scroll option

Low-Level Input

Most tests only need locator actions, but page.keyboard and page.mouse give raw control for shortcuts, canvas apps, sliders and custom drag-and-drop. locator.press() focuses the element first; page.keyboard.press() sends to whatever is focused. dragTo() handles standard HTML5 and pointer-based drag-and-drop.

Key Names

  • Letters/digits: a, A, 1; named: Enter, Tab, Escape, Backspace
  • Arrows: ArrowUp … ArrowRight; Home, End, PageDown, F1–F12
  • Chords with +: Shift+Tab, Control+A
  • ControlOrMeta → Cmd on macOS, Ctrl elsewhere

Examples

await page.getByLabel('Search').press('Enter');
await page.getByRole('textbox').press('ControlOrMeta+A');   // select all
await page.keyboard.press('Shift+Tab');                     // focused element
await page.keyboard.down('Shift');                          // hold
await page.keyboard.press('ArrowDown');
await page.keyboard.up('Shift');
await page.keyboard.insertText('héllo 👋');                  // no key events
await page.getByRole('menuitem', { name: 'File' }).hover();
await page.getByLabel('Name').focus();

await page.mouse.move(100, 200);                            // canvas drawing
await page.mouse.down();
await page.mouse.move(300, 200, { steps: 10 });
await page.mouse.up();
await page.mouse.wheel(0, 600);                             // scroll down

await page.getByText('Task A').dragTo(page.getByTestId('done-column'));
await page.getByRole('slider').click({ position: { x: 40, y: 5 } });

Code Explained

locator.press() — focus + key
keyboard.down/up — hold modifiers
insertText() — paste-like, no keydown
mouse.move(x, y, { steps }) — smooth drag path
dragTo() — drag source to target

⚠ Common Mistakes

  • Using page.keyboard.press without focusing the right element first; keys go to the wrong place
  • Hard-coding pixel coordinates for normal UI; they break on viewport or layout changes
  • Expecting dragTo to work with libraries that need many intermediate moves; use mouse with steps

✓ Tips & Best Practices

  • Prefer locator.press() over page.keyboard.press() so focus is explicit
  • Use ControlOrMeta for cross-platform shortcuts
  • For canvas apps, compute coordinates from locator.boundingBox()

Quick Summary

  • press('Key+Chord') — keyboard shortcuts
  • keyboard.down/up — held keys
  • mouse.move/down/up — manual drag
  • dragTo() — one-line drag-and-drop
