page.clock · install() · setFixedTime() · runFor() · grantPermissions() · page.localStorage · addInitScript()

Controlling Time, Permissions and Storage

page.clock fakes Date, timers and requestAnimationFrame, so you can test countdowns, session expiry and "last seen 5 minutes ago" without waiting. Permissions such as notifications, clipboard and camera are granted per context. addInitScript() runs before any page script, which is the standard way to seed localStorage, feature flags or stub globals.

Notes

  • Call clock.install() before goto so the page sees fake time
  • setFixedTime freezes Date.now() but timers still run
  • page.localStorage / sessionStorage APIs added in 1.61
  • context.clearPermissions() resets grants

Examples

// fake time
await page.clock.install({ time: new Date('2026-01-01T09:00:00') });
await page.goto('/session');
await page.clock.fastForward('29:00');                 // jump 29 minutes
await expect(page.getByText('Session expires in 1 minute')).toBeVisible();
await page.clock.runFor(60_000);                       // run timers 1 min
await expect(page.getByText('Session expired')).toBeVisible();

await page.clock.setFixedTime(new Date('2026-12-25T10:00:00'));   // frozen Date
await page.clock.pauseAt(new Date('2026-12-25T10:05:00'));

// permissions
await context.grantPermissions(['notifications', 'clipboard-read'],
  { origin: 'https://app.test' });

// seed storage before any app code runs
await page.addInitScript(() => {
  localStorage.setItem('onboarding-done', 'true');
  (window as any).__FEATURE_FLAGS__ = { newCheckout: true };
});
await page.goto('/');

Code Explained

install({ time }) — take over Date & timers
fastForward — jump, firing due timers once
runFor — run all timers in the period
setFixedTime — freeze Date only
grantPermissions — per origin or all
addInitScript — runs before page scripts

⚠ Common Mistakes

  • Installing the clock after goto; the page already captured real timers
  • Using setFixedTime and expecting setTimeout callbacks to be frozen too
  • Seeding localStorage with page.evaluate after load; the app already read the old value

✓ Tips & Best Practices

  • Combine clock.install with pauseAt to snapshot UIs at exact times
  • Grant clipboard permissions to test copy buttons, then read with page.evaluate
  • Headless clipboard is isolated since 1.62, so tests can't leak into each other

Quick Summary

  • page.clock — deterministic time
  • fastForward / runFor — advance time
  • grantPermissions() — browser permissions
  • addInitScript() — seed state before load
