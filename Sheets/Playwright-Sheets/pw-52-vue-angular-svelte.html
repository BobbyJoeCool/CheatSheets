Other Frameworks

Playwright tests the rendered page, so the framework only changes setup: how the app starts, its port, and how to wait for hydration on SSR frameworks. Vue (via create-vue) and SvelteKit (sv) scaffolders offer Playwright out of the box; Nuxt adds a helper package with hydration-aware goto; Angular uses ng serve or a schematic that wires ng e2e.

Notes

  • npm create vue@latest → choose Playwright for e2e
  • npx sv create or npx sv add playwright for SvelteKit
  • ng add playwright-ng-schematics → ng e2e runs Playwright
  • Protractor is end-of-life; Playwright is a common replacement

Setups

// Vue (create-vue): vite preview on 4173 in CI, dev on 5173 locally
webServer: { command: process.env.CI ? 'npm run preview' : 'npm run dev',
             port: process.env.CI ? 4173 : 5173 },

// Nuxt — hydration-aware helpers
import { expect, test } from '@nuxt/test-utils/playwright';
test.use({ nuxt: { rootDir: fileURLToPath(new URL('..', import.meta.url)) } });
test('home', async ({ page, goto }) => {
  await goto('/', { waitUntil: 'hydration' });
  await expect(page.getByRole('heading')).toHaveText('Welcome to Nuxt');
});

// Angular
webServer: { command: 'npx ng serve', url: 'http://localhost:4200' },

// SvelteKit (sv scaffold)
webServer: { command: 'npm run build && npm run preview', port: 4173 },

⚠ Common Mistakes

  • Interacting with SSR pages before hydration; the click lands on static HTML and is lost
  • Porting Protractor's browser.waitForAngular() habits; Playwright auto-waits on the DOM instead
  • Using generated class names (.v-btn__content, .mat-mdc-…) as locators

✓ Tips & Best Practices

  • Wait for an interactive signal (enabled button, hydrated marker) before acting
  • Use reducedMotion: 'reduce' to speed through framework transitions
  • Keep each framework's start command in package.json scripts and reference them
