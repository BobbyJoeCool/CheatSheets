Other Built-in Locators

getByText · getByLabel · getByPlaceholder · getByAltText · getByTitle · getByTestId · testIdAttribute

The getBy* Family

Besides getByRole, Playwright ships six user-facing locators. Use getByLabel for form fields, getByText for non-interactive content, getByPlaceholder/getByAltText/getByTitle when those attributes are the best handle, and getByTestId when you control the markup and need a stable contract that is independent of copy and language.

Matching Rules

  • Strings: case-insensitive substring, whitespace normalized
  • { exact: true }: case-sensitive, full string
  • RegExp: getByText(/welcome, \w+/i)
  • getByTestId is always exact; default attribute data-testid

Examples

page.getByLabel('Email address')                  // <label>, aria-label(ledby)
page.getByLabel('Password', { exact: true })      // not "Confirm password"
page.getByPlaceholder('name@example.com')
page.getByText('Welcome back')                    // substring, any case
page.getByText('Total', { exact: true })          // only the exact node text
page.getByText(/order #\d+ confirmed/i)
page.getByAltText('Company logo')                 // <img alt>
page.getByTitle('Issues count')                   // title="…"
page.getByTestId('cart-badge')                    // data-testid="cart-badge"

// playwright.config.ts — use a custom attribute
export default defineConfig({ use: { testIdAttribute: 'data-qa' } });
// or at runtime: selectors.setTestIdAttribute('data-qa');

Code Explained

getByLabel — best for inputs, selects, checkboxes
getByText — matches the smallest element containing the text
exact — opt out of substring matching
testIdAttribute — rename data-testid

⚠ Common Mistakes

  • getByText('Save') on a page with "Save" and "Save draft"; strict mode throws, use exact or a role locator
  • Using getByText for buttons; getByRole('button', { name }) is stricter and accessible
  • Forgetting that getByTestId is exact while other getBy* are substring by default

✓ Tips & Best Practices

  • Agree on data-testid naming (feature-element) with developers
  • Text locators break on copy changes and translations; prefer roles or labels for i18n apps
  • Run codegen to see which locator Playwright would pick

Quick Summary

  • getByLabel — form controls
  • getByText — visible content
  • getByTestId — stable dev contract
  • testIdAttribute — custom test-id attribute
