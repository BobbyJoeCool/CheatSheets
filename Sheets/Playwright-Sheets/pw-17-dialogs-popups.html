Dialogs, Downloads & New Pages

page.on('dialog') · accept() · waitForEvent('download') · saveAs() · popups · context.waitForEvent('page')

Events: Dialogs, Downloads, Popups

Native alert/confirm/prompt dialogs are auto-dismissed unless you register a dialog handler. Downloads, popups and new tabs are events: start waiting with page.waitForEvent() (or context.waitForEvent('page')) before the action that triggers them, then await the promise. Downloads are saved to a temp folder and deleted when the context closes unless you saveAs().

Notes

  • page.once('dialog', …) handles exactly one dialog
  • Dialog handlers must accept or dismiss, or the page hangs
  • beforeunload dialogs need page.close({ runBeforeUnload: true })
  • acceptDownloads is true by default in the test runner

Examples

// confirm() / prompt()
page.once('dialog', async (dialog) => {
  expect(dialog.message()).toContain('Delete item?');
  await dialog.accept();                 // dialog.accept('text') for prompt()
});
await page.getByRole('button', { name: 'Delete' }).click();

// download
const downloadPromise = page.waitForEvent('download');
await page.getByRole('link', { name: 'Export CSV' }).click();
const download = await downloadPromise;
expect(download.suggestedFilename()).toBe('report.csv');
await download.saveAs(test.info().outputPath(download.suggestedFilename()));

// popup / new tab
const popupPromise = page.waitForEvent('popup');
await page.getByRole('link', { name: 'Open docs' }).click();
const popup = await popupPromise;
await expect(popup).toHaveURL(/docs/);

Code Explained

once('dialog') — register before the trigger
accept() / dismiss() — must be called
waitForEvent('download') — promise first, then click
saveAs() — persist before context closes
'popup' — window.open / target=_blank

Dialog API

MethodReturns
type()alert | confirm | prompt | beforeunload
message()Dialog text
defaultValue()prompt default
accept(text?)Confirm / answer
dismiss()Cancel

Download API

MethodReturns
suggestedFilename()Server filename
path()Temp file path
saveAs(path)Copy to path
createReadStream()Readable stream
failure()Error or null

Other Page Events

EventFires When
page.on('popup')Page opens a window
context.on('page')Any new page in context
page.on('close')Page closes
page.on('crash')Renderer crashes

⚠ Common Mistakes

  • await page.waitForEvent('download') before clicking; it waits forever because nothing triggers it
  • Registering page.on('dialog') and never calling accept/dismiss; the page freezes
  • Reading download.path() after the context closed; the temp file is gone

✓ Tips & Best Practices

  • Promise.all([waitForEvent, click]) is a compact alternative
  • Use context.waitForEvent('page') when you don't know which page opens the tab
  • Assert dialog text inside the handler with expect

Quick Summary

  • once('dialog') — handle alerts/confirms
  • waitForEvent('download') — capture files
  • waitForEvent('popup') — capture new tabs
  • saveAs() — keep downloaded files
