getByRole

ARIA roles · name · exact · checked / pressed / expanded · level · description

Locating by Role

getByRole() is Playwright's recommended locator. It finds elements the way users and assistive technology perceive them: by ARIA role (implicit or explicit) and accessible name. Because it ignores CSS classes and DOM structure, it survives refactors, and a failing role locator often points to a real accessibility bug.

Notes

  • Name match is case-insensitive substring by default
  • exact: true requires a full, case-sensitive match
  • name accepts a RegExp: { name: /sign (in|up)/i }
  • Hidden elements are excluded unless includeHidden: true

Examples

page.getByRole('button', { name: 'Submit' })                  // <button>Submit</button>
page.getByRole('link', { name: 'Docs', exact: true })         // not "API Docs"
page.getByRole('heading', { level: 2, name: /pricing/i })     // <h2>
page.getByRole('checkbox', { name: 'Remember me', checked: true })
page.getByRole('button', { name: 'Bold', pressed: true })     // aria-pressed
page.getByRole('button', { name: 'Menu', expanded: false })   // aria-expanded
page.getByRole('option', { name: 'Blue', selected: true })
page.getByRole('textbox', { name: 'Email' })                  // via <label>
page.getByRole('row', { name: /Alice/ }).getByRole('button', { name: 'Edit' })
page.getByRole('img', { name: 'Logo', description: 'Company logo' })   // 1.60
page.getByRole('dialog').getByRole('button', { name: 'Close' })

Code Explained

role — first argument, ARIA role string
name — accessible name (text, label, aria-label)
state filters — checked, pressed, expanded, selected, disabled
level — heading level 1–6
chain — scope to a row, dialog or region

⚠ Common Mistakes

  • Using the visible text of an icon button; its accessible name comes from aria-label
  • Expecting name: 'Save' to exclude "Save draft"; substring match needs exact: true
  • Adding redundant role="button" to a <button>; implicit roles already match

✓ Tips & Best Practices

  • Use the Pick Locator tool to see the role and name Playwright computes
  • When no role locator works, fix the markup (labels, aria-label) rather than falling back to CSS
  • Scope by landmark (dialog, navigation, row) to keep names short

Quick Summary

  • getByRole(role, { name }) — preferred locator
  • exact — full-string match
  • state options — filter by ARIA state
  • chaining — scope inside containers
