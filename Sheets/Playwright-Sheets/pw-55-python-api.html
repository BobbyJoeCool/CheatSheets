Playwright for Python

The Python package mirrors the Node API with snake_case names and keyword arguments: get_by_role("button", name="Save"). It has a sync API (simplest, used with pytest) and an async API for asyncio programs. Web-first assertions come from playwright.sync_api.expect. Install the pytest plugin even for scripts; it pulls in playwright itself.

Notes

  • Python 3.9+; pip install pytest-playwright (or uv add)
  • playwright install --with-deps chromium downloads browsers
  • No await in the sync API; methods block
  • Timeouts in ms, same as Node

Sync API (script)

import re
from playwright.sync_api import sync_playwright, expect

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False, slow_mo=100)
    page = browser.new_page(viewport={"width": 1280, "height": 720}, locale="en-GB")
    page.goto("https://playwright.dev")
    expect(page).to_have_title(re.compile("Playwright"))
    page.get_by_role("link", name="Get started").click()
    expect(page.get_by_role("heading", name="Installation")).to_be_visible()
    browser.close()

Code Explained

sync_playwright() — context manager starts driver
launch(headless=False, slow_mo=…) — kwargs
new_page(viewport=…, locale=…) — kwargs options
expect(...).to_have_title() — snake_case matchers
re.compile — RegExp equivalent

Async API

import asyncio
from playwright.async_api import async_playwright, expect

async def main():
    async with async_playwright() as p:
        browser = await p.firefox.launch()
        page = await browser.new_page()
        await page.goto("https://example.com")
        await expect(page.get_by_text("Example Domain")).to_be_visible()
asyncio.run(main())

Code Explained

async_playwright() — asyncio version
await every call, including expect
same names as sync API

⚠ Common Mistakes

  • Mixing sync and async APIs in one program; pick one
  • Using the sync API inside an asyncio event loop (e.g. Jupyter); use async_api there
  • Forgetting playwright install after pip install; browsers aren't bundled

✓ Tips & Best Practices

  • Use with page.expect_download() as d: / expect_popup() for event waits
  • Run codegen with --target python-pytest for ready-made tests
  • Use uv or venvs to pin the Playwright version per project

Quick Summary

  • sync_playwright() — blocking API
  • async_playwright() — asyncio API
  • snake_case + kwargs — Pythonic names
  • expect() — same web-first assertions
