Sheet 10

SPACE, UNIT & Volumes

SPACE=(TRK,(10,5)) · CYL / TRK / block units · directory blocks · RLSE · UNIT=SYSDA · VOL=SER= · AVGREC · SMS classes

Asking for Disk Space

New datasets need space: a primary amount, a secondary amount added when it fills (up to 15 more extents per volume), and for a PDS, directory blocks. Space is given in tracks, cylinders, blocks or records. Most sites use SMS, which picks the volume, so UNIT and VOL are rarely needed.

Key Points

  • 1 cylinder = 15 tracks; 1 track ≈ 56 KB on 3390 disks
  • RLSE gives back unused space when the dataset closes
  • AVGREC=K with record units: SPACE=(200,(50,10)),AVGREC=K = 50,000 records of 200 bytes
  • SMS: STORCLAS, MGMTCLAS, DATACLAS replace manual placement

SPACE Forms

//* Tracks: 10 primary, 5 secondary, release unused
//OUT1     DD DSN=USER.SMALL,DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(10,5),RLSE),
//            RECFM=FB,LRECL=80
//* Cylinders for big files
//OUT2     DD DSN=USER.BIG,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(100,50),RLSE),
//            RECFM=VB,LRECL=1004
//* PDS with 20 directory blocks
//LIB      DD DSN=USER.LOADLIB,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(5,5,20)),RECFM=U,BLKSIZE=32760
//* By record count: 50K records of 200 bytes
//OUT3     DD DSN=USER.RECS,DISP=(NEW,CATLG,DELETE),
//            SPACE=(200,(50,10)),AVGREC=K,
//            RECFM=FB,LRECL=200
//* Explicit device and volume (non-SMS)
//OUT4     DD DSN=USER.PINNED,DISP=(NEW,CATLG,DELETE),
//            UNIT=SYSDA,VOL=SER=WORK01,SPACE=(TRK,1)

Code Explained

Secondary space is added in extents as the dataset grows
The third number in SPACE is PDS directory blocks
AVGREC=K multiplies the counts by 1,024
UNIT=SYSDA is the generic disk device name

Modern Equivalent

  • Python Disk quotas and volumes are handled by the OS; files grow freely
  • Java Same: the JVM writes, the file system allocates
  • JavaScript Same: Node writes, the file system allocates

Abend Check

  • SB37: no secondary space left or 16 extents used; increase SPACE
  • SD37: no secondary amount coded; SE37: PDS directory or volume full

⚠ Common Mistakes

  • No secondary quantity, so the job abends SD37 at the primary limit
  • Tiny PDS directory, so adding members fails
  • Asking for huge primary space that no volume can satisfy (job fails to allocate)

✓ Tips & Best Practices

  • Estimate: records × LRECL ÷ 56,000 ≈ tracks
  • Always code RLSE on outputs
  • Use PDSE to avoid directory-block limits

Quick Summary

  • SPACE=(unit,(pri,sec,dir))
  • RLSE — release unused
  • AVGREC — size by records
  • SB37 / SD37 / SE37 — out of space
