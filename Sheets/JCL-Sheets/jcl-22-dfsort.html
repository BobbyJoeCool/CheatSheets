DFSORT

SORT FIELDS=(1,10,CH,A) · CH / ZD / PD / BI formats · INCLUDE COND= / OMIT · INREC / OUTREC BUILD= · SUM FIELDS=NONE · ICETOOL

Sorting, Filtering and Reformatting

DFSORT (PGM=SORT) sorts, merges, filters and reformats records with control statements in SYSIN. Fields are given as position, length, format, order. INCLUDE keeps matching records, OUTREC BUILD rearranges fields, and SUM FIELDS=NONE removes duplicate keys.

Key Points

  • Positions start at 1; for VB data, position 5 is the first data byte
  • Formats must match the data: CH text, ZD zoned, PD packed
  • SORTIN in, SORTOUT out, SYSOUT messages
  • RC 0 = success, 16 = failure

In COBOL

  • Packed PIC S9(7)V99 COMP-3 = 5 bytes → format PD, length 5
  • Zoned PIC S9(5) = 5 bytes → format ZD
  • Positions come from the copybook: offset + 1

Sort, Filter, Reformat

//SORTSTEP EXEC PGM=SORT
//SYSOUT   DD SYSOUT=*
//SORTIN   DD DSN=PROD.SALES.NOV,DISP=SHR
//SORTOUT  DD DSN=USER.SALES.IAMN,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(5,5),RLSE)
//SYSIN    DD *
* Keep Iowa and Minnesota, sales over 1000.00
  INCLUDE COND=((21,2,CH,EQ,C'IA',OR,21,2,CH,EQ,C'MN'),
                AND,51,5,PD,GT,+100000)
* State ascending, sales descending
  SORT FIELDS=(21,2,CH,A,51,5,PD,D)
* Output: account, state, sales
  OUTREC BUILD=(1,10,21,2,51,5)

Code Explained

Bytes 21–22 hold the state; bytes 51–55 a packed amount
Packed 100000 with 2 implied decimals = 1000.00
OUTREC keeps 17 bytes: account, state, amount
SUM FIELDS=NONE keeps one record per key

Modern Equivalent

  • Python sorted(filter(lambda r: r.state in ("IA","MN"), rows), key=…)
  • Java rows.stream().filter(…).sorted(comparing(…)).map(…)
  • JavaScript rows.filter(…).sort(…).map(r => ({acct, state, sales}))

Abend Check

  • DFSORT RC 16 ICE…A message in SYSOUT: read the first A-level message
  • ICE043A / wrong data in output: field position or format does not match the layout

⚠ Common Mistakes

  • Positions counted from 0 (DFSORT starts at 1)
  • Treating packed data as CH, which sorts by raw bytes
  • Forgetting the 4-byte RDW when coding positions on VB files

✓ Tips & Best Practices

  • Copy field positions from the COBOL compile listing MAP
  • Use SORT FIELDS=COPY with INCLUDE for fast filtering
  • Use OUTFIL to split one input into several outputs in one pass

Quick Summary

  • SORT FIELDS=(p,l,f,o)
  • INCLUDE COND= — filter
  • OUTREC BUILD= — reformat
  • SUM FIELDS=NONE — dedupe
