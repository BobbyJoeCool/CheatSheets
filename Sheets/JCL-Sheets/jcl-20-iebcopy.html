IEBCOPY

copy PDS / PDSE members · COPY OUTDD=… INDD=… · SELECT MEMBER= · EXCLUDE · compress in place · unload / reload

Copying Libraries and Members

IEBCOPY copies whole partitioned datasets or selected members between libraries. It also compresses a PDS in place to reclaim space left by deleted and replaced members, and unloads a library to a sequential file for transfer or backup.

Key Points

  • INDD and OUTDD name DD statements, not datasets
  • SELECT copies only listed members; EXCLUDE skips them
  • R after a member name replaces an existing member
  • PDSEs reuse space and do not need compressing

Copy Members and Compress

//COPYMEM  EXEC PGM=IEBCOPY
//SYSPRINT DD SYSOUT=*
//FROMLIB  DD DSN=PROD.COBOL.SRC,DISP=SHR
//TOLIB    DD DSN=USER.COBOL.SRC,DISP=SHR
//SYSIN    DD *
  COPY OUTDD=TOLIB,INDD=FROMLIB
  SELECT MEMBER=(PAYCALC,PAYRPT,(TAXCALC,TAXNEW,R))
/*

//* Compress a PDS in place
//COMPRESS EXEC PGM=IEBCOPY

//LIB      DD DSN=USER.OLD.PDS,DISP=OLD

//OUT      DD DSN=USER.COBOL.UNLOAD,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(5,5))
//SYSIN    DD *
  COPY OUTDD=OUT,INDD=IN

Code Explained

Only three members are copied; TAXCALC is renamed TAXNEW and replaces an existing one
INDD = OUTDD on the same library compresses it
An unload makes a sequential file you can send by FTP
DISP=OLD prevents others updating the library during compress

Modern Equivalent

  • Python shutil.copytree(src, dst) or copy chosen files
  • Java Files.walk + Files.copy for selected files
  • JavaScript fs.cpSync(src, dst, { recursive: true, filter })

Abend Check

  • SYSPRINT reports a member not found: a SELECT name does not exist in INDD
  • Compressing a PDS that others are using: corruption risk; use DISP=OLD

Control Statements

StatementDoes
COPY OUTDD=o,INDD=iCopy all members
INDD=(a,b)Several inputs

⚠ Common Mistakes

  • Forgetting R, so existing members are not replaced (and the copy is skipped)
  • Using SELECT and EXCLUDE in the same COPY group
  • Compressing a busy production library

✓ Tips & Best Practices

  • Back up a PDS (unload) before risky changes
  • Move libraries to PDSE to stop needing compresses
  • Read SYSPRINT: it lists every member copied or skipped

Quick Summary

  • IEBCOPY — library copies
  • SELECT / EXCLUDE — choose members
  • R — replace
  • INDD = OUTDD — compress
