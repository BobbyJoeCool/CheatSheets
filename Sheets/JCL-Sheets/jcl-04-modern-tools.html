Working from a Laptop

Zowe is the open-source framework for z/OS. Zowe CLI lets you list datasets, upload source, submit jobs and download output from any terminal or CI pipeline. Zowe Explorer does the same inside VS Code. Both talk to z/OSMF, the REST API layer on z/OS.

Key Points

  • Install with npm install -g @zowe/cli
  • zowe config init creates zowe.config.json with your host and user
  • Command groups: zos-files (files), zos-jobs (jobs), zos-tso, zos-uss
  • USS gives a real UNIX shell on z/OS via SSH

Zowe CLI Session

npm install -g @zowe/cli
zowe config init                      # host, port, user

zowe files list ds "USER.*"           # list datasets
zowe files list am "USER.JCL"         # list members
zowe files download am "USER.JCL" -d jcl/
zowe files upload ftds jcl/PAYROLL.jcl "USER.JCL(PAYROLL)"

zowe jobs submit ds "USER.JCL(PAYROLL)" --wait-for-output
# jobid: JOB04711  retcode: CC 0000  status: OUTPUT
zowe jobs list sfbi JOB04711          # spool files
zowe jobs view sfbi JOB04711 2        # JESMSGLG
zowe jobs download output JOB04711 -d out/
zowe jobs delete job JOB04711

Code Explained

--wait-for-output blocks until the job ends and prints the return code
Spool file IDs come from list sfbi (spool files by job ID)
Download output to check it into tickets or test reports
The same commands run in GitHub Actions or Jenkins

Modern Equivalent

  • Python subprocess.run(["zowe", "jobs", "submit", …]) or the Zowe Python SDK
  • Java Zowe Java SDK (zowe-client-java-sdk)
  • JavaScript Zowe Node.js SDK (@zowe/zos-jobs-for-zowe-sdk)

Abend Check

  • 401 Unauthorized from z/OSMF: wrong password or expired; update the profile
  • ECONNREFUSED / TLS errors: wrong port or self-signed cert (rejectUnauthorized: false only for labs)

⚠ Common Mistakes

  • Storing passwords in plain text config files committed to Git
  • Submitting from CI without waiting for and checking the return code
  • Uploading files with Windows line endings or tabs

✓ Tips & Best Practices

  • Use zowe config secure to store credentials in the OS keychain
  • Always use --wait-for-output in pipelines and fail on RC > 4
  • Keep JCL as .jcl files in Git and upload on build
