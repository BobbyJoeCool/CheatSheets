Sheet 05

JCL Syntax

// in columns 1–2 · name, operation, operand & comment fields · column 72 limit · continuation rules · //* comments · /* delimiter · // null statement

How a JCL Line Is Built

Every JCL statement starts with // in columns 1–2, followed by a name (starting in column 3), an operation (JOB, EXEC, DD), operands separated by commas with no spaces, and optional comments. Statements must end by column 71; to continue, end the line after a comma and resume between columns 4 and 16.

Key Points

  • Names: 1–8 characters, start with a letter or @ # $
  • Spaces separate fields; a space ends the operands
  • JCL is uppercase (except inside quotes and in-stream data)
  • Column 72 non-blank used to mean continuation (rare today)

Fields and Continuation

//*-+----1----+----2----+----3----+----4----+----5----+----6----+-
//* name   operation  operands                        comments
//PAYROLL  JOB  (ACCT),'R BREUTZMANN',CLASS=A,
//         MSGCLASS=X,NOTIFY=&SYSUID
//STEP1    EXEC PGM=PAYCALC,PARM='2026-11'  RUN FOR NOV
//INFILE   DD   DSN=PROD.PAY.TRANS,
//              DISP=SHR
//OUTFILE  DD   SYSOUT=*
//SYSIN    DD   *
DATA LINES HAVE NO // AND ARE NOT JCL
/*
//

Code Explained

Ruler: // fills columns 1–2, names start in column 3
A trailing comma means "continued on the next line"
Text after the first space following operands is a comment
/* ends in-stream data; a lone // marks the end of the job

Modern Equivalent

  • Python Python: indentation and newlines are syntax; \ or brackets continue lines
  • Java Java: free format; statements end with ;
  • JavaScript JavaScript: free format; YAML-like configs (e.g. GitHub Actions) are the closer analog

Abend Check

  • IEFC605I UNIDENTIFIED OPERATION FIELD: the name or operation is misspelled or misaligned
  • EXPECTED CONTINUATION NOT RECEIVED: a line ended with a comma but the next line starts in the wrong column

Column Rules

ColumnsUse
1–2//
3–10Name (optional on DD continuations)
After nameOne space, then operation
4–16Continuation operands start
72Old continuation marker
73–80Ignored (sequence)

⚠ Common Mistakes

  • A space inside the operand list, which turns the rest into a comment
  • Continuing a line that does not end with a comma
  • Starting a continuation in column 17 or later

✓ Tips & Best Practices

  • Use HILITE JCL in ISPF or IBM Z Open Editor in VS Code
  • Put one parameter group per continuation line for readability
  • Run TYPRUN=SCAN to check syntax without running anything

Quick Summary

  • //name op operands — every statement
  • comma at end — continue
  • space — ends operands
  • //* comment · /* data end
