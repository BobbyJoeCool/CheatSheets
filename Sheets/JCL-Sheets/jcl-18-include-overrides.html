INCLUDE & Overrides

INCLUDE MEMBER= · overriding EXEC params PARM.STEP1= · nullifying parameters · override order · common override mistakes

Pulling in JCL and Changing Procs

INCLUDE MEMBER= pastes a JCL fragment from a library in the JCLLIB list, like a copybook for JCL. When calling a proc, PARM.procstep= and other keyword.procstep= values override EXEC parameters, and DD overrides can change, add or nullify individual parameters.

Key Points

  • INCLUDE members hold JCL statements, not a whole job
  • EXEC overrides: PARM.STEP1=, REGION.STEP1=, TIME.STEP1=
  • A DD override changes only the parameters you code
  • Code a parameter with no value to nullify it: UNIT=

INCLUDE and Overrides

//USER01I  JOB (ACCT),'INCLUDE',CLASS=A,MSGCLASS=X
//         JCLLIB ORDER=(USER.JCLLIB,USER.PROCLIB)
//*
//STEP1    EXEC PGM=PAYCALC
//         INCLUDE MEMBER=STDLIBS      STEPLIB + SYSOUT DDs
//INFILE   DD DSN=PROD.PAY.TRANS,DISP=SHR
//*
//* Override EXEC parameters inside the proc NIGHTLY
//RUN      EXEC NIGHTLY,
//         PARM.STEP1='2026-11',
//         REGION.STEP2=256M
//* Change only DISP and SPACE on an existing DD
//STEP2.OUTFILE DD DISP=(NEW,CATLG,CATLG),
//            SPACE=(CYL,(20,10))
//* Nullify the proc's UNIT and VOL on this DD
//STEP2.WORK   DD UNIT=,VOL=
//* Send a DD to a dummy for this run
//STEP3.AUDIT  DD DUMMY

Code Explained

STDLIBS might hold STEPLIB, SYSOUT and CEEDUMP DDs used everywhere
PARM.STEP1= overrides the PARM on proc step STEP1
OUTFILE keeps its DSN; only DISP and SPACE change
UNIT=,VOL= removes those parameters so SMS chooses

Modern Equivalent

  • Python import of shared config; keyword overrides on a function call
  • Java Shared config classes; overriding defaults with builder methods
  • JavaScript Shared YAML anchors or composite actions; with: inputs override defaults

Abend Check

  • IEFC612I PROCEDURE NOT FOUND for INCLUDE members too: JCLLIB missing the library
  • DD override has no effect: procstep name misspelled, so a new DD was added instead

Override Forms

FormEffect
PARM.pstep='x'Replace PARM
REGION.pstep=Replace REGION
COND.pstep=Replace COND
//pstep.dd DD parm=…Change DD params
//pstep.dd DD parm=Nullify a param
//pstep.dd DD DUMMYMake it dummy
//pstep.newdd DD …Add a DD

⚠ Common Mistakes

  • Overrides listed out of proc-step order
  • Coding a full DD when only one parameter needed to change
  • INCLUDE members that contain JOB or PROC statements

✓ Tips & Best Practices

  • Collect standard DDs in an INCLUDE member
  • List every override with a comment explaining why
  • Check the expanded JCL to confirm each override applied

Quick Summary

  • INCLUDE MEMBER= — paste JCL
  • PARM.pstep= — EXEC override
  • partial DD override
  • parm= (empty) — nullify
