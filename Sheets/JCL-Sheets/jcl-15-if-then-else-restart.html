IF / THEN / ELSE & Restart

// IF (RC > 4) THEN · ELSE / ENDIF · STEP.RC · ABEND / ABENDCC · RUN · RESTART=stepname · idempotent steps

Readable Conditional Steps

IF/THEN/ELSE/ENDIF statements wrap steps in conditions that read forwards: IF (RC <= 4) THEN runs the steps when the condition is true. You can test the highest RC so far, a specific step's RC, abends and abend codes. RESTART= reruns a failed job from a chosen step.

Key Points

  • RC alone = highest RC of all earlier steps
  • STEP1.RC tests one step; STEP1.PSTEP.RC a proc step
  • ABEND is true if any earlier step abended
  • IF blocks can nest up to 15 levels

IF Blocks and Restart

//STEP010  EXEC PGM=VALIDATE
//         IF (STEP010.RC <= 4) THEN
//STEP020  EXEC PGM=UPDATE
//         IF (STEP020.RC = 0) THEN
//STEP030  EXEC PGM=REPORT
//         ENDIF
//         ELSE
//STEP040  EXEC PGM=ERRMAIL,PARM='VALIDATION FAILED'
//         ENDIF
//*
//         IF (ABEND | STEP020.ABENDCC = S0C7) THEN
//STEP090  EXEC PGM=ALERT
//         ENDIF
//*
//* Rerun from STEP020 after fixing the data:
//* //USER01P JOB (ACCT),'RERUN',CLASS=A,RESTART=STEP020

Code Explained

STEP020 runs only if VALIDATE ended with RC 0–4
REPORT runs only if UPDATE returned 0
STEP040 runs when validation failed
RESTART=STEP020 skips STEP010 on the rerun

Modern Equivalent

  • Python if result.returncode <= 4: run("update") in a Python driver
  • Java if (exitCode <= 4) { … } in a launcher, or Spring Batch flow decisions
  • JavaScript GitHub Actions if: steps.validate.outcome == 'success'

Abend Check

  • JCL ERROR on an IF block: an IF without a matching ENDIF (or the reverse)
  • Restart fails because STEP010 created a temp dataset STEP020 needs: restart earlier or catalog it

⚠ Common Mistakes

  • Comparing RC > 4 when you meant <= (logic inverted from COND habits)
  • Forgetting ENDIF
  • Restarting at a step that depends on temp datasets from skipped steps

✓ Tips & Best Practices

  • Use IF/THEN/ELSE for all new conditional logic
  • Design steps to be rerunnable: delete outputs first, then create
  • Comment each IF with the business reason

Quick Summary

  • IF (cond) THEN … ENDIF
  • RC / step.RC — return codes
  • ABEND / ABENDCC — failures
  • RESTART= — rerun from a step
