Mainframe & z/OS Overview

IBM Z · z/OS · LPARs · batch vs online · JES2 · subsystems (DB2, CICS, IMS, MQ) · EBCDIC

The Platform Behind the Jobs

IBM Z mainframes run z/OS, the operating system behind most bank, insurance and government batch processing. Work runs either online (CICS or IMS transactions, answered in milliseconds) or as batch jobs: JCL scripts submitted to JES2, which queues them, runs each step and collects the output.

Key Points

  • One machine is split into LPARs, each running its own OS image
  • JCL tells z/OS which programs to run and which datasets to give them
  • Text is EBCDIC, not ASCII: A is X'C1', a space is X'40'
  • Batch jobs usually run overnight in a batch window

Your First Job

//HELLO    JOB (ACCT),'FIRST JOB',CLASS=A,MSGCLASS=X,
//         NOTIFY=&SYSUID
//* Print a message with the IEBGENER copy utility
//STEP1    EXEC PGM=IEBGENER
//SYSPRINT DD SYSOUT=*
//SYSIN    DD DUMMY
//SYSUT2   DD SYSOUT=*
//SYSUT1   DD *
HELLO FROM Z/OS
/*

Code Explained

The JOB statement names the job and how JES should treat it
One EXEC step runs the IEBGENER program
SYSUT1 (input) is in-stream data; SYSUT2 (output) goes to the job log
Submit it, then read the output in SDSF or Zowe Explorer

Modern Equivalent

  • Python subprocess.run(["cat"], input="HELLO") in a scheduled script
  • Java ProcessBuilder("cat") launched by a scheduler
  • JavaScript child_process.spawn("cat") from a cron-triggered Node script

Abend Check

  • JCL ERROR with no step run: a syntax problem, check the JESYSMSG listing
  • Job sits in the input queue: wrong CLASS or held (TYPRUN=HOLD)

⚠ Common Mistakes

  • Expecting files and folders: z/OS has datasets with dotted names
  • Assuming ASCII when comparing or sorting data (EBCDIC sorts letters before digits)
  • Submitting without NOTIFY and never seeing that the job finished

✓ Tips & Best Practices

  • Get free z/OS access through IBM Z Xplore to practice
  • Learn to read the job log before writing complex JCL
  • Keep each job's JCL in a PDS member under version control

Quick Summary

  • JES2 — queues and spools jobs
