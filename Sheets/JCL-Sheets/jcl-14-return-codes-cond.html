Return Codes & COND

Skipping Steps on Errors

Each step ends with a return code (condition code). The old COND parameter tells z/OS when to skip a step: COND=(4,LT) means "skip this step if 4 is less than any earlier RC". It reads backwards, which is why most new JCL uses IF/THEN/ELSE (sheet 15).

Key Points

  • RC convention: 0 OK, 4 warning, 8 error, 12 severe, 16 fatal
  • COND tests are true → step is bypassed
  • An abend normally bypasses later steps unless EVEN or ONLY
  • COND on the JOB statement applies to every step

In COBOL

  • MOVE 8 TO RETURN-CODE in COBOL becomes the step's RC 8
  • An abended COBOL step has no RC; COND=EVEN steps still run
  • Utilities set RCs too: SORT 16 = failure, IDCAMS 8 = errors

COND Examples

//STEP010  EXEC PGM=VALIDATE
//* Skip if 4 < any previous RC  (run only if all RCs <= 4)
//STEP020  EXEC PGM=UPDATE,COND=(4,LT)
//* Skip if any previous RC = 0  (run only after an error)
//STEP030  EXEC PGM=ERRMAIL,COND=(0,EQ)
//* Test one specific step
//STEP040  EXEC PGM=REPORT,COND=(8,LE,STEP020)
//* Always run, even after an abend (cleanup)
//STEP050  EXEC PGM=CLEANUP,COND=EVEN
//* Run ONLY if an earlier step abended
//STEP060  EXEC PGM=ALERT,COND=ONLY

Code Explained

Read (4,LT) as "if 4 is less than the RC, skip"
STEP020 runs when VALIDATE ends with RC 0 or 4
STEP040 is skipped if 8 ≤ STEP020's RC
EVEN runs after abends; ONLY runs only after abends

Modern Equivalent

  • Python sys.exit(4); a wrapper checks result.returncode <= 4 before the next step
  • Java System.exit(4); the scheduler checks the exit code
  • JavaScript process.exitCode = 4; step1 && step2 in npm scripts skips on non-zero

Abend Check

  • IEF202I STEP020 - STEP WAS NOT RUN BECAUSE OF COND: the COND test was true
  • FLUSH in the step summary: bypassed because an earlier step abended

Common Patterns

CONDRuns When
(4,LT)All RCs ≤ 4
(0,NE)All RCs = 0
(8,LE)All RCs < 8
(0,EQ)No earlier RC = 0
EVENAlways, even after abend
ONLYOnly after an abend

⚠ Common Mistakes

  • Reading COND forwards and skipping exactly the wrong steps
  • COND=(0,NE) on a step after a utility that returns 4 for warnings
  • Expecting COND to catch abends without EVEN or ONLY

✓ Tips & Best Practices

  • Translate every COND into words in a comment
  • Prefer IF/THEN/ELSE in new JCL
  • Make programs set RETURN-CODE deliberately (0, 4, 8, 16)

Quick Summary

  • RC 0 / 4 / 8 / 16
  • COND true → step skipped
  • (4,LT) — run if RCs ≤ 4
  • EVEN / ONLY — abend handling
