z/OS Files

A dataset is a z/OS file with a name of up to 44 characters made of dot-separated qualifiers. Sequential (PS) datasets hold records in order; partitioned datasets (PDS/PDSE) hold named members, like files in a folder. Each dataset has fixed attributes: record format, record length and block size.

Key Points

  • Each qualifier: 1–8 characters, starting with a letter or @ # $
  • The first qualifier (HLQ) is usually your user ID or an application
  • Members are named in parentheses: USER.JCL(PAYROLL)
  • Datasets are found through the catalog, so you rarely give a volume

Allocate a PS and a PDSE

//ALLOC    JOB (ACCT),'ALLOCATE',CLASS=A,MSGCLASS=X
//STEP1    EXEC PGM=IEFBR14
//* Sequential dataset: 80-byte fixed-blocked records
//SEQ      DD DSN=USER.TEST.DATA,DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(5,5)),
//            RECFM=FB,LRECL=80,BLKSIZE=0
//* Library (PDSE) for JCL members
//LIB      DD DSN=USER.JCL,DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(10,10)),DSNTYPE=LIBRARY,
//            RECFM=FB,LRECL=80

Code Explained

IEFBR14 does nothing: the DD statements create the datasets
CATLG adds each new dataset to the catalog
BLKSIZE=0 lets z/OS choose the best block size
DSNTYPE=LIBRARY makes a PDSE instead of a PDS

Modern Equivalent

  • Python pathlib.Path("test/data.txt").touch(); folders hold files
  • Java Files.createFile(Path.of("test/data.txt"))
  • JavaScript fs.writeFileSync("test/data.txt", "")

Abend Check

  • IEF253I DUPLICATE NAME ON DIRECT ACCESS VOLUME: the dataset already exists; delete it or use another name
  • Qualifier over 8 characters: JCL ERROR, invalid DSN

⚠ Common Mistakes

  • Lowercase or too-long qualifiers
  • Writing to a PDS until it runs out of directory blocks (use PDSE)
  • Creating a dataset that already exists (not cataloged twice)

✓ Tips & Best Practices

  • Prefix datasets with your user ID while testing
  • Use PDSE (DSNTYPE=LIBRARY) for new libraries
  • Let SMS and BLKSIZE=0 pick placement and block size
