Sheet 08

DD Statement Basics

DD names · DSN= · DISP= · SYSOUT=* · DUMMY · in-stream DD * / DD DATA · DLM=

Connecting Data to a Step

A DD (data definition) statement connects a name the program uses to a real dataset, a print destination or in-stream data. The program never names the dataset: it opens a DD name, and the JCL decides what that is. This is why the same program can run against test and production data.

Key Points

  • DD names: 1–8 characters, must match the program's file names
  • SYSOUT=* sends output to the job log (MSGCLASS)
  • DUMMY gives an empty input or throws output away
  • DD * ends at /* or the next //; DD DATA only at /* (or DLM)

In COBOL

  • SELECT CUST-FILE ASSIGN TO CUSTIN opens the DD named CUSTIN
  • ACCEPT with no FROM reads the SYSIN DD
  • DISPLAY writes to SYSOUT (or the DD named in the OUTDD option)

Common DD Types

//STEP1    EXEC PGM=CUSTUPD
//* Existing cataloged dataset, shared read
//CUSTIN   DD DSN=PROD.CUSTOMER.MASTER,DISP=SHR
//* New output dataset
//CUSTOUT  DD DSN=USER.CUSTOMER.NEW,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(5,2),RLSE),RECFM=FB,LRECL=200
//* Print output to the job log
//RPTOUT   DD SYSOUT=*
//* No input this run
//TRANIN   DD DUMMY
//* In-stream control cards (read by ACCEPT)
//SYSIN    DD *
RUNDATE=20261112
/*
//* In-stream data that contains // lines
//JCLCOPY  DD DATA,DLM=$$
//OLDJOB   JOB (ACCT),'COPIED'
$$

Code Explained

The program opens CUSTIN; the JCL picks the master file
CUSTOUT is created, cataloged on success and deleted on abend
TRANIN DUMMY: the first READ gets end of file
DLM=$$ lets data contain // lines

Modern Equivalent

  • Python open(os.environ["CUSTIN"]): config decides the file, not the code
  • Java new FileReader(System.getenv("CUSTIN"))
  • JavaScript fs.createReadStream(process.env.CUSTIN)

Abend Check

  • IEC130I CUSTIN DD STATEMENT MISSING / FILE STATUS 35: the DD name is missing or misspelled
  • IEF212I … DATA SET NOT FOUND: wrong DSN or not cataloged

DD Forms

FormUse
DSN=x,DISP=SHRRead existing
DSN=x,DISP=OLDExclusive use
DSN=x,DISP=(NEW,CATLG,DELETE)Create
SYSOUT=*Job log / printer
DUMMYEmpty input / discard
DD *In-stream data
DD DATA,DLM=xxData with // lines
PATH='/u/…'UNIX file

⚠ Common Mistakes

  • DD name in the JCL not matching the ASSIGN name in the program
  • Using DD * for data that starts with // (use DD DATA)
  • DISP=OLD on a shared production file, locking other jobs out

✓ Tips & Best Practices

  • Use DISP=SHR for read-only input
  • Comment each DD with what the program expects
  • Swap test and production by changing DSNs, never the program

Quick Summary

  • DD name — what the program opens
  • DSN + DISP — real dataset
  • SYSOUT=* — job log
  • DD * / DUMMY — in-stream / empty
