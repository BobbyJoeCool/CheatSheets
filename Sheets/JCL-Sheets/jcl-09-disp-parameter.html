Sheet 09

The DISP Parameter

NEW / OLD / SHR / MOD · normal disposition · abnormal disposition · CATLG / DELETE / KEEP / PASS / UNCATLG · defaults · (NEW,CATLG,DELETE)

Status and What Happens After

DISP=(status,normal,abnormal) says whether the dataset exists and is shared, then what to do with it when the step ends normally and when it abends. The classic create pattern is (NEW,CATLG,DELETE): create it, keep and catalog it if the step works, delete it if the step fails.

Key Points

  • Status: NEW (create), OLD (exclusive), SHR (shared), MOD (append / create)
  • Normal and abnormal default to "keep as it was" for existing datasets
  • For NEW, the default is DELETE at step end
  • PASS hands a dataset to a later step in the same job

DISP Patterns

//* Read, shared with other jobs
//IN       DD DSN=PROD.SALES,DISP=SHR
//* Update in place, nobody else may use it
//MASTER   DD DSN=PROD.ACCT.MASTER,DISP=OLD
//* Create; catalog if OK, delete on abend
//NEWOUT   DD DSN=USER.REPORT.DATA,
//            DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(10,5)),RECFM=FB,LRECL=133
//* Append to the end (creates it if it does not exist)
//LOG      DD DSN=USER.RUN.LOG,DISP=MOD
//* Delete an existing dataset
//OLDFILE  DD DSN=USER.OLD.DATA,DISP=(OLD,DELETE)
//* Keep on success, but keep for debugging on abend too
//WORK     DD DSN=USER.WORK.DATA,DISP=(NEW,CATLG,CATLG),
//            SPACE=(CYL,(1,1))

Code Explained

SHR lets other jobs read the same dataset at the same time
OLD enqueues the dataset so only this job can use it
MOD positions writes after the last record
(NEW,CATLG,CATLG) keeps output from a failed run for inspection

Modern Equivalent

  • Python open(path, "r") / "w" / "a"; os.remove on failure in except
  • Java StandardOpenOption.READ / CREATE_NEW / APPEND; cleanup in finally
  • JavaScript fs.open(path, "r" | "wx" | "a"); delete in a catch block

Abend Check

  • IEF287I … NOT CATLGD 2: a dataset with that name is already cataloged
  • Job waits with "DATASET RESERVATION UNSUCCESSFUL": another job holds it with DISP=OLD

Defaults

You CodeMeans
DISP=SHR(SHR,KEEP,KEEP)
DISP=NEW(NEW,DELETE,DELETE)
DISP=(NEW,CATLG)abnormal = CATLG
no DISP(NEW,DELETE,DELETE)

⚠ Common Mistakes

  • DISP=NEW alone, so the dataset is deleted when the step ends
  • DISP=OLD on read-only input, blocking other jobs
  • Creating a dataset whose name is already cataloged (NOT CATLGD 2)

✓ Tips & Best Practices

  • Default to (NEW,CATLG,DELETE) for outputs
  • Delete-then-create in a prior IEFBR14 step makes jobs rerunnable
  • Use SHR for anything you only read

Quick Summary

  • SHR / OLD — read / exclusive
  • NEW — create
  • (NEW,CATLG,DELETE) — standard
  • MOD — append
