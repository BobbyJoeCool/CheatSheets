Sheet 16

In-Stream & Cataloged Procedures

PROC / PEND · cataloged procs · JCLLIB ORDER= · calling a proc · stepname.ddname overrides · added DDs

Reusable JCL

A procedure (proc) is a named set of steps you call with one EXEC. In-stream procs sit inside the job between PROC and PEND; cataloged procs live as members in a procedure library found through JCLLIB or the system proclib. Callers override or add DDs with procstep.ddname.

Key Points

  • A proc cannot contain JOB statements or DD * (in older z/OS)
  • IBM supplies procs like IGYWCL (compile + link)
  • JCLLIB ORDER= lists your proc libraries, searched first
  • Overrides must follow the EXEC in proc-step order

Define and Call a Proc

//USER01P  JOB (ACCT),'PROCS',CLASS=A,MSGCLASS=X
//         JCLLIB ORDER=(USER.PROCLIB)
//*
//* In-stream procedure
//RUNPGM   PROC PGM=,INDSN=
//STEP1    EXEC PGM=&PGM
//STEPLIB  DD DSN=USER.LOADLIB,DISP=SHR
//INFILE   DD DSN=&INDSN,DISP=SHR
//SYSOUT   DD SYSOUT=*
//         PEND
//*
//RUN1     EXEC RUNPGM,PGM=PAYCALC,INDSN=PROD.PAY.TRANS
//*
//* Cataloged proc USER.PROCLIB(NIGHTLY) with overrides
//RUN2     EXEC NIGHTLY
//STEP1.INFILE DD DSN=USER.TEST.TRANS,DISP=SHR
//STEP1.EXTRA  DD DSN=USER.EXTRA.DATA,DISP=SHR

Code Explained

RUNPGM takes two symbolic parameters, PGM and INDSN
RUN1 calls it, filling in both values
STEP1.INFILE replaces the INFILE DD in the NIGHTLY proc
STEP1.EXTRA adds a DD the proc did not have

Modern Equivalent

  • Python A shell function or Python function wrapping a command with arguments
  • Java A reusable method or Spring Batch step bean
  • JavaScript A reusable GitHub Actions workflow or npm script with arguments

Abend Check

  • IEFC612I PROCEDURE NOT FOUND: missing JCLLIB library or misspelled proc name
  • Override ignored: the procstep or DD name is wrong, or overrides are out of order

⚠ Common Mistakes

  • Overrides in a different order than the proc steps
  • Overriding a DD name that does not exist in the proc (it is added instead)
  • Editing a shared production proc to fix one job

✓ Tips & Best Practices

  • Keep site procs read-only; override in your JCL
  • Expand procs in the job log with MSGLEVEL=(1,1) to see the final JCL
  • Name proc steps clearly so overrides read well
