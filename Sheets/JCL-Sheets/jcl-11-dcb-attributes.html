Sheet 11

DCB Attributes

RECFM=FB / VB / F / U · LRECL · BLKSIZE=0 (system-determined) · DSORG=PS / PO · LIKE= · DSNTYPE=LIBRARY

The Shape of the Records

DCB attributes describe the records in a dataset: their format (fixed or variable, blocked or not), their length and how many are grouped into a block. For new datasets you set them on the DD; existing datasets keep theirs in the catalog/label, and they must match what the program expects.

Key Points

  • Code them directly (RECFM=FB) or in DCB=(…)
  • VB LRECL includes the 4-byte record descriptor word
  • BLKSIZE=0 lets the system pick an efficient block size
  • LIKE= copies attributes from an existing dataset

In COBOL

  • RECFM=FB, LRECL=150 must match an FD with a 150-byte 01 record
  • Variable files: LRECL = largest COBOL record + 4
  • A mismatch gives FILE STATUS 39 on OPEN (or an S013 abend)

Attributes for Common Files

//* Fixed 80-byte card-image records (JCL, source)
//SRC      DD DSN=USER.COBOL.SRC,DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(20,10)),DSNTYPE=LIBRARY,
//            RECFM=FB,LRECL=80,BLKSIZE=0
//* Report with ASA control character
//RPT      DD DSN=USER.REPORT,DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(10,10)),RECFM=FBA,LRECL=133
//* Variable records up to 500 bytes of data
//VAR      DD DSN=USER.VARDATA,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(1,1)),RECFM=VB,LRECL=504
//* Same attributes as an existing dataset
//COPY     DD DSN=USER.CUST.COPY,DISP=(NEW,CATLG,DELETE),
//            LIKE=PROD.CUSTOMER.MASTER
//* Old style
//OLDSTYLE DD DSN=USER.OLD,DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,1),DCB=(RECFM=FB,LRECL=100)

Code Explained

Source and JCL libraries are FB 80
FBA reports: byte 1 is the carriage control character
VB 504 = 500 bytes of data + 4-byte RDW
LIKE= copies RECFM, LRECL and space from the model

Modern Equivalent

  • Python Text files with newlines; struct for fixed binary records
  • Java DataInputStream.readFully(buf) for fixed-length records
  • JavaScript fs.read into a Buffer of the record length

Abend Check

  • FILE STATUS 39 on OPEN: RECFM or LRECL do not match the program
  • IEC141I 013-20: BLKSIZE not a multiple of LRECL for fixed records

⚠ Common Mistakes

  • LRECL that does not match the COBOL record length
  • Forgetting the 4 extra bytes on VB LRECL
  • Hard-coding an old BLKSIZE that is no longer efficient

✓ Tips & Best Practices

  • Code BLKSIZE=0 on new datasets
  • Check attributes in ISPF 3.4 with the I (info) line command
  • Keep LRECL in the copybook header comment

Quick Summary

  • RECFM — record format
  • LRECL — record length
  • BLKSIZE=0 — system choice
  • LIKE= — copy attributes
