Symbolic Parameters & SET

&SYMBOL · defaults on PROC · SET statement · . delimiter &HLQ..DATA · system symbols &SYSUID / &LYYMMDD · EXPORT SYMLIST

Variables in JCL

Symbolic parameters (&NAME) are placeholders replaced before the job runs. Defaults are set on the PROC statement or with SET, and callers override them on EXEC. System symbols such as &SYSUID and dates are filled in by z/OS. A period ends a symbol, so &HLQ..DATA becomes USER.DATA.

Key Points

  • Symbol names: 1–7 characters after &
  • A null symbol (PARM=) removes the text
  • Two periods are needed when a period follows a symbol
  • && is a temp dataset, not a symbol

Symbols and SET

//USER01S  JOB (ACCT),'SYMBOLS',CLASS=A,MSGCLASS=X
//         SET HLQ=USER,ENV=TEST,RUNDT=20261112
//*
//STEP1    EXEC PGM=PAYCALC,PARM='&RUNDT'
//INFILE   DD DSN=&HLQ..&ENV..PAY.TRANS,DISP=SHR
//*        resolves to USER.TEST.PAY.TRANS
//OUTFILE  DD DSN=&HLQ..PAY.D&LYYMMDD,
//            DISP=(NEW,CATLG,DELETE),SPACE=(TRK,(5,5))
//*        e.g. USER.PAY.D261112
//*
//* Symbols inside in-stream data (z/OS 2.1+)
//         EXPORT SYMLIST=(RUNDT)
//STEP2    EXEC PGM=RPT
//SYSIN    DD *,SYMBOLS=JCLONLY
RUN DATE &RUNDT
/*

Code Explained

SET defines symbols for the rest of the job
&HLQ..&ENV..PAY keeps a dot between each part
&LYYMMDD is the local date when the job is read in
SYMBOLS=JCLONLY replaces exported symbols inside SYSIN

Modern Equivalent

  • Python f-strings / env vars: f"{hlq}.{env}.PAY.TRANS"
  • Java String.format("%s.%s.PAY.TRANS", hlq, env) or properties
  • JavaScript Template literals: ${hlq}.${env}.PAY.TRANS

Abend Check

  • IEFC657I THE SYMBOL … WAS NOT USED / unresolved &X in a DSN: misspelled or never set
  • Name like USERPAY instead of USER.PAY: only one period after the symbol

⚠ Common Mistakes

  • One period after a symbol before a qualifier, which joins them
  • Expecting symbols to be replaced in in-stream data without SYMBOLS=
  • Using symbols for things that should be program parameters

✓ Tips & Best Practices

  • Put environment-specific values (HLQ, ENV) in one SET at the top
  • Use &SYSUID in test JCL so anyone can run it
  • Check the expanded JCL in the job log (MSGLEVEL=(1,1))

Quick Summary

  • &NAME — symbolic parameter
  • SET — define symbols
  • .. — symbol then period
  • &SYSUID / &LYYMMDD — system symbols
