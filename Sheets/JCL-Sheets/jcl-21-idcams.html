IDCAMS

DEFINE CLUSTER (KSDS) · KEYS / RECORDSIZE · REPRO · PRINT · DELETE … PURGE · LISTCAT · SET MAXCC=0

The VSAM and Catalog Utility

IDCAMS (Access Method Services) defines, loads, prints and deletes VSAM datasets and manages catalog entries. It takes commands in SYSIN: DEFINE CLUSTER creates a KSDS, REPRO copies data in or out, PRINT dumps records and LISTCAT shows catalog details.

Key Points

  • Commands continue with a trailing -
  • IF LASTCC = 8 THEN SET MAXCC = 0 ignores "not found" on deletes
  • KEYS(length offset) must match the program's record key
  • REPRO can load a KSDS from a sorted sequential file

Define, Load, Print

//VSAMDEF  EXEC PGM=IDCAMS
//SYSPRINT DD SYSOUT=*
//SEQIN    DD DSN=USER.ACCT.SORTED,DISP=SHR
//SYSIN    DD *
  DELETE USER.ACCT.KSDS CLUSTER PURGE
  IF LASTCC = 8 THEN SET MAXCC = 0

  DEFINE CLUSTER (NAME(USER.ACCT.KSDS) -
         INDEXED -
         KEYS(10 0) -
         RECORDSIZE(100 100) -
         FREESPACE(10 10) -
         CYLINDERS(5 2)) -
       DATA  (NAME(USER.ACCT.KSDS.DATA)) -
       INDEX (NAME(USER.ACCT.KSDS.INDEX))

  REPRO INFILE(SEQIN) OUTDATASET(USER.ACCT.KSDS)
  PRINT INDATASET(USER.ACCT.KSDS) CHARACTER COUNT(5)
  LISTCAT ENTRIES(USER.ACCT.KSDS) ALL
/*

Code Explained

The delete makes the job rerunnable; RC 8 (not found) is reset to 0
KEYS(10 0): 10-byte key starting at offset 0
RECORDSIZE(100 100): average and maximum record length
REPRO loads the KSDS; input must be in key order

Modern Equivalent

  • Python CREATE TABLE … PRIMARY KEY then a bulk INSERT (sqlite3)
  • Java JDBC DDL + batch inserts, or a TreeMap persisted to disk
  • JavaScript SQL DDL via a driver, or an embedded key-value store

Abend Check

  • IDCAMS RC 8 IDC3012I ENTRY NOT FOUND on DELETE: harmless with the LASTCC reset
  • REPRO RC 12 IDC3314I duplicate / out-of-sequence key: sort the input by key first

⚠ Common Mistakes

  • KEYS offset or length not matching the COBOL RECORD KEY (status 39)
  • REPRO from unsorted input into a KSDS
  • Missing - continuation, so the rest of the command is lost

✓ Tips & Best Practices

  • Keep VSAM DEFINE jobs in source control beside the programs
  • Use FREESPACE on files with many inserts
  • Use PRINT … CHARACTER COUNT(n) to check data quickly

Quick Summary

  • IDCAMS — VSAM utility
  • DEFINE CLUSTER — create KSDS
  • REPRO — load / copy
  • SET MAXCC=0 — ignore not-found
