TSO / ISPF Essentials

ISPF primary menu · 3.4 DSLIST · ISPF editor commands · SUBMIT · SDSF (ST, O, ?) · TSO commands

The Classic Green Screen

TSO is the interactive command line on z/OS, and ISPF is the menu-driven interface on top of it. You browse datasets in option 3.4, edit members in the ISPF editor, type SUB to submit JCL, and check results in SDSF. Many developers now use Zowe Explorer instead, but ISPF is still everywhere.

Key Points

  • Primary commands go on the Command line; line commands in the line-number area
  • PF3 saves and exits; CANCEL exits without saving
  • =3.4 jumps straight to the dataset list from anywhere
  • SDSF ST lists your jobs; ? shows a job's output files

Everyday Commands

=3.4                  Dataset list (DSLIST)
  Dsname Level: USER.*
  E  next to a member    Edit       B  Browse      V  View
  Z                      Compress a PDS

ISPF editor primary commands
  SUB                    Submit this JCL
  F PAYROLL ALL          Find every PAYROLL
  C OLD NEW ALL          Change all OLD to NEW
  HILITE JCL             Color JCL keywords
  RES                    Clear messages
  CANCEL                 Exit without saving

Line commands (type over the line numbers)
  I5  insert 5 lines   D  delete   DD/DD  delete block
  R   repeat           C/A  copy after   M/B  move before

=SD ; ST              SDSF status of your jobs
  ?  job's spool files   S  view   P  purge

Code Explained

Commands are typed on the screen, not run as a script
Line commands act on the lines they are typed on
HILITE JCL colors JCL syntax in the editor
In SDSF, S next to JESMSGLG shows the job log

Modern Equivalent

  • Python Terminal: ls, vim, then run python job.py and read stdout
  • Java An IDE (IntelliJ) plus a Run console
  • JavaScript VS Code plus the integrated terminal

Abend Check

  • INVALID COMMAND in ISPF: you typed a TSO command; prefix it with TSO
  • Edit fails with "member in use": someone else (or another session) has it open

⚠ Common Mistakes

  • Pressing PF3 when you meant to throw away changes (it saves)
  • Purging job output before reading the error messages
  • Forgetting quotes around full dataset names in TSO (your prefix gets added)

✓ Tips & Best Practices

  • Learn =3.4, SUB, =SD ; ST and ? first
  • Turn on HILITE JCL to spot typos
  • Use Zowe Explorer for editing, ISPF for quick checks

Quick Summary

  • SDSF ST / ? — job output
