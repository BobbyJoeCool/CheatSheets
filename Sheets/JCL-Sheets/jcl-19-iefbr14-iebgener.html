Sheet 19

IEFBR14 & IEBGENER

allocate with IEFBR14 · delete with DISP=(MOD,DELETE) · IEBGENER copy · SYSUT1 / SYSUT2 · SYSIN DD DUMMY · ICEGENER

The Two Most-Used Utilities

IEFBR14 does nothing at all: it exists so DD statements can create or delete datasets. IEBGENER copies a sequential dataset (SYSUT1) to another (SYSUT2), printing or creating it on the way. Many sites alias IEBGENER to the faster ICEGENER from DFSORT.

Key Points

  • IEFBR14 always returns RC 0
  • DISP=(MOD,DELETE) deletes whether or not the dataset exists
  • IEBGENER with SYSIN DD DUMMY is a straight copy
  • SYSUT2 can be SYSOUT=* to print a dataset

Delete, Create, Copy

//* Delete if it exists (no error if it does not)
//DELETE   EXEC PGM=IEFBR14
//DD1      DD DSN=USER.PAY.COPY,DISP=(MOD,DELETE),
//            SPACE=(TRK,0)
//*
//* Copy a dataset, creating the output
//COPY     EXEC PGM=IEBGENER
//SYSPRINT DD SYSOUT=*
//SYSIN    DD DUMMY
//SYSUT1   DD DSN=PROD.PAY.TRANS,DISP=SHR
//SYSUT2   DD DSN=USER.PAY.COPY,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(5,5),RLSE),LIKE=PROD.PAY.TRANS
//*
//* Print a dataset to the job log
//PRINT    EXEC PGM=IEBGENER
//SYSPRINT DD SYSOUT=*
//SYSIN    DD DUMMY
//SYSUT1   DD DSN=USER.PAY.COPY,DISP=SHR
//SYSUT2   DD SYSOUT=*

Code Explained

MOD creates the dataset if missing, then DELETE removes it: no failure either way
This delete-then-create pattern makes the job rerunnable
LIKE= copies the input's attributes to the output
Printing to SYSOUT is a quick way to look at a file in the job log

Modern Equivalent

  • Python Path(p).unlink(missing_ok=True); shutil.copyfile(a, b)
  • Java Files.deleteIfExists(p); Files.copy(a, b)
  • JavaScript fs.rmSync(p, { force: true }); fs.copyFileSync(a, b)

Abend Check

  • IEBGENER RC 12: missing SYSUT1/SYSUT2 or bad DCB; read SYSPRINT
  • NOT CATLGD 2 on SYSUT2: the output name already exists; add a delete step first

IEFBR14 Uses

DD CodingEffect
DISP=(NEW,CATLG)Create + catalog
DISP=(MOD,DELETE)Delete if present
DISP=(OLD,DELETE)Delete (must exist)
DISP=(OLD,UNCATLG)Uncatalog only

IEBGENER DDs

DDRole
SYSUT1Input
SYSUT2Output
SYSINControl (DUMMY = copy)
SYSPRINTMessages

⚠ Common Mistakes

  • Creating an output that already exists because there was no delete step
  • Forgetting SYSPRINT, so IEBGENER errors are lost
  • Expecting IEFBR14 to do anything without DD statements

✓ Tips & Best Practices

  • Start rerunnable jobs with an IEFBR14 delete step
  • Use LIKE= or copy DCB from the input
  • Use IEBGENER + SYSOUT to peek at small datasets

Quick Summary

  • IEFBR14 — DD-only step
  • (MOD,DELETE) — safe delete
  • IEBGENER — SYSUT1 → SYSUT2
  • SYSIN DD DUMMY — plain copy
