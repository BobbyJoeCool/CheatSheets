Sheet 07

The EXEC Statement

step names · PGM= · PROC= (or proc name) · PARM= · REGION / TIME on steps · step limits · PARMDD

Running a Program or Procedure

Each EXEC statement starts a step. PGM= runs a load module found in STEPLIB, JOBLIB or the system libraries. Naming a procedure runs all its steps instead. PARM= passes up to 100 characters to the program, and step-level REGION, TIME and COND override job defaults.

Key Points

  • Step names: 1–8 characters, unique within the job
  • A job can have up to 255 steps
  • PARM with commas or spaces must be in quotes
  • PARMDD points to a DD with a longer parameter (up to 32,760 bytes)

EXEC Forms

//STEP010  EXEC PGM=PAYCALC
//*
//STEP020  EXEC PGM=PAYRPT,PARM='2026-11,SUMMARY'
//*
//STEP030  EXEC PGM=BIGJOB,REGION=512M,TIME=(10,0)
//*
//* Run a cataloged procedure (all its steps)
//COMPILE  EXEC IGYWCL
//* or explicitly:
//COMPILE2 EXEC PROC=IGYWCL
//*
//* Long parameters from a DD
//STEP040  EXEC PGM=EXTRACT,PARMDD=MYPARM
//MYPARM   DD *
REGION=MIDWEST,START=20261101,END=20261130,FORMAT=CSV
/*

Code Explained

STEP010 runs PAYCALC with job defaults
The program reads PARM through its LINKAGE SECTION
Step REGION/TIME override the JOB values for that step only
Naming a proc without PGM= runs the procedure

Modern Equivalent

  • Python python paycalc.py 2026-11 SUMMARY → sys.argv[1:]
  • Java java PayRpt 2026-11 SUMMARY → String[] args
  • JavaScript node payrpt.js 2026-11 SUMMARY → process.argv.slice(2)

Abend Check

  • S806 abend: the program was not found; check STEPLIB/JOBLIB and the name
  • IEFC642I EXCESSIVE PARAMETER LENGTH on PARM: over 100 characters, use PARMDD

EXEC Parameters

ParameterMeaning
PGM=nameLoad module to run
PROC=name / nameProcedure to run
PARM='…'Up to 100 chars to program
PARMDD=ddnameLong PARM from a DD
REGION=Memory for the step
TIME=CPU limit for the step
COND=Skip test (sheet 14)

⚠ Common Mistakes

  • Duplicate step names, which breaks referbacks and restarts
  • Unquoted PARM containing commas
  • Forgetting STEPLIB for programs in your own load library

✓ Tips & Best Practices

  • Number steps by 10s (STEP010, STEP020) so you can insert steps
  • Use descriptive step names: SORTIN, UPDATE, REPORT
  • Put long or changing parameters in a PARMDD member

Quick Summary

  • EXEC PGM= — run a program
  • EXEC procname — run a proc
  • PARM= — up to 100 chars
  • STEPLIB — where to find it
