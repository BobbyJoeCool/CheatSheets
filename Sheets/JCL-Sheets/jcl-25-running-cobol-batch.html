Running a COBOL Batch Program

EXEC PGM= · STEPLIB · DD names ↔ SELECT … ASSIGN · PARM= → LINKAGE SECTION · DISPLAY → SYSOUT · RETURN-CODE → step RC

Wiring a Program to Its Data

Running a COBOL program means one EXEC step plus a DD for every file the program opens. The DD names must match the ASSIGN TO names in the program. PARM arrives in the LINKAGE SECTION, DISPLAY output lands in SYSOUT, and the program's RETURN-CODE becomes the step's RC.

Key Points

  • Read the program's SELECT statements to know which DDs it needs
  • Missing DD → FILE STATUS 35 on OPEN (or an abend)
  • Add CEEDUMP so abends produce a useful dump
  • Test and production differ only in DSNs and STEPLIB

In COBOL

  • SELECT TRAN-IN ASSIGN TO TRANIN ↔ //TRANIN DD DSN=…
  • PROCEDURE DIVISION USING LK-PARM receives PARM='2026-11' as length + text
  • MOVE 4 TO RETURN-CODE → step RC 4 → IF/COND in the JCL

A Complete Run Step

//USER01R  JOB (ACCT),'PAYROLL RUN',CLASS=A,MSGCLASS=X,
//         NOTIFY=&SYSUID
//PAYRUN   EXEC PGM=PAYCALC,PARM='2026-11'
//STEPLIB  DD DSN=USER.LOADLIB,DISP=SHR
//* Files the program opens (match SELECT ... ASSIGN TO)
//TRANIN   DD DSN=PROD.PAY.TRANS.NOV,DISP=SHR
//ACCTMAST DD DSN=PROD.ACCT.KSDS,DISP=SHR
//PAYOUT   DD DSN=USER.PAY.OUT,DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(5,5),RLSE),RECFM=FB,LRECL=150
//RPTOUT   DD SYSOUT=*
//REJECTS  DD DSN=USER.PAY.REJECTS,DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(5,5),RLSE),RECFM=FB,LRECL=180
//* Runtime DDs
//SYSOUT   DD SYSOUT=*
//CEEDUMP  DD SYSOUT=*
//SYSUDUMP DD SYSOUT=*
//         IF (PAYRUN.RC > 4) THEN
//ALERT    EXEC PGM=IEFBR14
//         ENDIF

Code Explained

Five file DDs match five SELECT statements in PAYCALC
PARM '2026-11' is the run period
SYSOUT collects DISPLAY messages and control totals
The IF step reacts to RC 8 or higher from PAYCALC

Modern Equivalent

  • Python python paycalc.py 2026-11 with paths in env vars; sys.exit(rc)
  • Java java -cp app.jar PayCalc 2026-11 with config; System.exit(rc)
  • JavaScript node paycalc.js 2026-11 with process.env paths; process.exitCode = rc

Abend Check

  • FILE STATUS 35 / IEC130I … DD STATEMENT MISSING: a SELECT's DD name is not in the step
  • S806: STEPLIB does not contain PAYCALC (or the name is misspelled)

⚠ Common Mistakes

  • A DD name typo that only shows up as status 35 at run time
  • Output LRECL not matching the FD record
  • No CEEDUMP DD, so an abend leaves little to debug

✓ Tips & Best Practices

  • List the program's DD names in its header comment
  • Use symbols for the environment qualifier so one JCL fits test and prod
  • Check control totals in SYSOUT after every run

Quick Summary

  • one DD per SELECT
  • PARM → LINKAGE
  • DISPLAY → SYSOUT
  • RETURN-CODE → step RC
