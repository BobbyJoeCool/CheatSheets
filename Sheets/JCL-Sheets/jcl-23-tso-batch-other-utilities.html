TSO in Batch & Other Utilities

IKJEFT01 · SYSTSIN commands · REXX in batch · DSN RUN PROGRAM (DB2) · BPXBATCH for USS · IEBUPDTE

Running Commands in a Job

IKJEFT01 runs TSO commands, CLISTs and REXX execs in batch, reading them from SYSTSIN. It is also how batch DB2 COBOL programs are run, through the DSN command. BPXBATCH runs UNIX (USS) shell commands, and IEBUPDTE creates or updates PDS members from in-stream data.

Key Points

  • SYSTSPRT gets the command output
  • The step RC is the highest RC of the commands
  • DB2 programs must run under DSN so they connect to the subsystem
  • BPXBATCH writes STDOUT/STDERR to DDs or files

In COBOL

  • A DB2 COBOL program runs as RUN PROGRAM(name) PLAN(name) under DSN
  • The program's file DDs (SELECT ASSIGN) go in the same step
  • Its RETURN-CODE becomes the IKJEFT01 step RC

IKJEFT01, DB2 and USS

//* TSO commands in batch
//TSOCMD   EXEC PGM=IKJEFT01
//SYSTSPRT DD SYSOUT=*
//SYSTSIN  DD *
  LISTCAT LEVEL(USER.PAY)
  DELETE 'USER.PAY.OLD'
/*
//*
//* Run a DB2 COBOL program
//DB2RUN   EXEC PGM=IKJEFT01,DYNAMNBR=20
//STEPLIB  DD DSN=DSNC10.SDSNLOAD,DISP=SHR
//         DD DSN=USER.LOADLIB,DISP=SHR
//SYSTSPRT DD SYSOUT=*
//SYSOUT   DD SYSOUT=*
//CUSTRPT  DD SYSOUT=*
//SYSTSIN  DD *
  DSN SYSTEM(DB2P)
  RUN PROGRAM(CUSTRPT) PLAN(CUSTPLAN)
  END
/*
//*
//* UNIX command
//USSCMD   EXEC PGM=BPXBATCH,
//         PARM='SH ls -l /u/user01/data'
//STDOUT   DD SYSOUT=*
//STDERR   DD SYSOUT=*

Code Explained

TSOCMD lists and deletes datasets from a job
DSN SYSTEM(DB2P) connects to the DB2 subsystem named DB2P
CUSTRPT is a DD the COBOL program writes to
BPXBATCH runs ls in the z/OS UNIX shell

Modern Equivalent

  • Python subprocess.run(["ls", "-l"]) from a Python job
  • Java ProcessBuilder("ls", "-l")
  • JavaScript child_process.execSync("ls -l")

Abend Check

  • DSNE… SUBSYSTEM NOT DEFINED / not connected: wrong SYSTEM() name or missing SDSNLOAD in STEPLIB
  • SQLCODE -805 / -818: the plan or package does not match the program; rebind

⚠ Common Mistakes

  • Running a DB2 program with EXEC PGM= directly (no DB2 connection)
  • No SYSTSPRT DD, so TSO error messages are lost
  • Unquoted dataset names in TSO, which get your prefix added

✓ Tips & Best Practices

  • Check SYSTSPRT first when an IKJEFT01 step fails
  • Keep DB2 run JCL in a proc with SYSTEM and PLAN as symbols
  • Use BPXBATCH for Java or shell steps in the same job
