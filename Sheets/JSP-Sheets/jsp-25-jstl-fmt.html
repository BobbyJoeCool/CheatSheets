JSTL Formatting (fmt:)

fmt:formatNumber · fmt:formatDate · fmt:timeZone · fmt:setLocale · fmt:message · fmt:bundle

Numbers, Dates, and i18n

The fmt: library handles locale-aware formatting for numbers and dates, as well as internationalization (i18n) via resource bundles. <fmt:formatNumber> formats decimals, percentages, and currency according to locale rules. <fmt:formatDate> formats java.util.Date values. <fmt:message> looks up a key in a resource bundle for translated strings — the foundation of multi-language JSP applications.

Key Facts

  • Locale is determined by <fmt:setLocale>, the session, or the browser's Accept-Language header — in that priority order
  • fmt:formatDate accepts java.util.Date or java.sql.Date only — not Java 8+ LocalDate
  • Resource bundles are .properties files on the classpath: messages_en.properties, messages_fr.properties
  • <fmt:setBundle> sets the bundle globally for the page; <fmt:bundle> sets it for a block
  • Time zone affects date output: set with <fmt:timeZone> or <fmt:setTimeZone>

Tag Notes

type="currency" — formats with locale's currency symbol and grouping
currencyCode="EUR" — override currency symbol using ISO 4217 code
pattern — Java DecimalFormat / SimpleDateFormat pattern string
dateStyle / timeStyle — short | medium | long | full; uses locale rules
<fmt:message key="k"> — looks up key in active bundle; falls back to key name if not found
<fmt:param value="${x}"> — substitutes into {0}, {1} placeholders in bundle string
basename — classpath base name without locale suffix or .properties

⚠ Common Mistakes

  • Passing a LocalDate or LocalDateTime to <fmt:formatDate> — it only accepts java.util.Date; convert first with Date.from(localDate.atStartOfDay().toInstant(ZoneOffset.UTC))
  • Forgetting to set a bundle before using <fmt:message> — without a bundle, every key renders as the key name literally
  • Using type="currency" without setting locale — defaults to the server JVM locale, which may not match the user's country

✓ Tips

  • Set locale and bundle in a shared fragment included at the top of every page — centralizes the i18n setup in one place
  • Use pattern="yyyy-MM-dd" for machine-readable dates in hidden fields or data attributes — avoids locale-dependent parsing issues
  • Store the resolved locale in session scope after detection — avoids re-checking Accept-Language on every request

Quick Summary

  • <fmt:formatNumber type="currency"> — locale-aware currency output
  • <fmt:formatDate pattern="yyyy-MM-dd"> — date formatting
  • <fmt:setLocale value="fr_FR"> — set locale for page/session
  • <fmt:setBundle basename="..."> — load .properties resource bundle
  • <fmt:message key="k"> — i18n string lookup with {0} params
