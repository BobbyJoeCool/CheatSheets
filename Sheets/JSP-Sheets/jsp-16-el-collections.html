list[index] · map[key] · bean.property · nested access · EL 3.0 streams · lambda in EL

Navigating Collections in EL

EL can traverse any Java collection or bean without a scriptlet. Lists and arrays use bracket notation with an integer index. Maps use bracket notation with a string key. JavaBeans use the dot or bracket operator against the property name, which EL resolves via the getX() / isX() convention. All access is null-safe — a null anywhere in a chain returns empty string rather than throwing.

Key Facts

  • List/array index is zero-based: ${list[0]} is the first element
  • Map key can be dynamic: ${map[varName]} looks up the value of varName as the key
  • Bean property ${bean.name} calls bean.getName(); boolean uses isName()
  • Chains are null-safe at every step: ${order.customer.address.city} returns "" if any link is null
  • EL 3.0 (Jakarta EE 7+) added stream API and lambda support for filtering collections

Collection Access Patterns

<%-- ── List / array ───────────────────────────────────────── --%>
${products[0].name}         <%-- first product's name --%>
${products[0]["name"]}      <%-- identical --%>
${products[lastIndex]}      <%-- dynamic index from EL var --%>

<%-- ── Map ─────────────────────────────────────────────────── --%>
${labels["submit.button"]}  <%-- key with dot — bracket required --%>
${config["api.url"]}
${config[selectedKey]}      <%-- dynamic key lookup --%>

<%-- ── JavaBean ──────────────────────────────────────────── --%>
${user.firstName}           <%-- calls user.getFirstName() --%>
${user.active}              <%-- calls user.isActive() (boolean) --%>
${user.address.city}        <%-- nested bean chain --%>
${user.orders[0].total}     <%-- bean → list → bean property --%>

<%-- ── EL 3.0 stream API ─────────────────────────────────── --%>
${products.stream()
    .filter(p -> p.price lt 50)
    .map(p -> p.name)
    .toList()}

Access Notes

list[n] — zero-based index; works on arrays, List, LinkedList
map["key"] — bracket required for keys with dots or hyphens
map[var] — dynamic key; var is evaluated as a string first
bean.prop — calls getProp(); must follow JavaBean naming
bean.boolProp — calls isBoolProp() for boolean properties
.stream().filter().toList() — EL 3.0; Jakarta EE 7+ containers only
st.index — 0-based; st.count — 1-based; both from varStatus

⚠ Common Mistakes

  • Using ${map.key.with.dots} — EL navigates three levels of beans; use ${map["key.with.dots"]} for a map key that contains dots
  • Expecting ${list.size()} to work — EL dot notation calls getters, not arbitrary methods; use ${fn:length(list)} or <c:forEach> with varStatus
  • Forgetting that boolean properties must use is prefix — if the getter is getActive() instead of isActive(), ${bean.active} may return null

✓ Tips

  • Use ${fn:length(collection)} to get collection size — it works on arrays, Lists, Maps, and strings uniformly
  • Take advantage of EL's null-safety in deep chains — ${order.customer.address.city} is safe without null checks; a null mid-chain silently returns ""
  • Avoid EL 3.0 stream API in template markup — it reduces readability; do filtering in the servlet and pass a pre-filtered list as a request attribute

Quick Summary

  • ${list[0]} — zero-based list/array access
  • ${map["dotted.key"]} — bracket required for special-char keys
  • ${bean.prop} — calls getter via JavaBean convention
  • Null-safe chains — any null returns "", not NPE
  • fn:length(col) — get size of any collection type
