PageContext API & Scope Resolution

findAttribute · PAGE_SCOPE · REQUEST_SCOPE · SESSION_SCOPE · APPLICATION_SCOPE · getELContext

PageContext as a Unified API

PageContext is the single object that provides programmatic access to all four JSP scopes and all nine implicit objects from one place. It is most useful inside custom tag handlers, which do not have direct access to implicit objects. In JSPs, pageContext is available as an implicit object. Its key value is findAttribute(name), which searches all four scopes in order — the same search EL performs when you write ${name}.

Key Facts

  • Scope search order for findAttribute(): page → request → session → application
  • This is identical to the order EL uses when you write ${name} without a scope prefix
  • Tag handlers receive pageContext via setPageContext() — it is their only gateway to the web context
  • getELContext() returns the ELContext needed to evaluate EL expressions programmatically
  • Scope integer constants are on PageContext itself: PageContext.REQUEST_SCOPE etc.

PageContext API Usage

// ── In a tag handler (no implicit objects available) ──────
public class MyTag extends SimpleTagSupport {
    public void doTag() throws JspException, IOException {
        PageContext pc = (PageContext) getJspContext();

        // Access any implicit object
        HttpServletRequest  req = (HttpServletRequest)  pc.getRequest();
        HttpServletResponse res = (HttpServletResponse) pc.getResponse();
        HttpSession         ses = pc.getSession();
        ServletContext      ctx = pc.getServletContext();
        JspWriter           out = pc.getOut();

        // Search all scopes (page→request→session→application)
        Object user = pc.findAttribute("currentUser");

        // Scope-targeted get/set
        pc.setAttribute("msg", "Hello", PageContext.REQUEST_SCOPE);
        Object val = pc.getAttribute("msg", PageContext.REQUEST_SCOPE);
        pc.removeAttribute("msg", PageContext.REQUEST_SCOPE);

        // Forward from inside a tag
        pc.forward("/WEB-INF/jsp/result.jsp");

        // Include another resource
        pc.include("/WEB-INF/jsp/widget.jsp");

        // Write output
        out.print("<p>Tag output</p>");
    }
}

Method Notes

findAttribute(name) — searches page→request→session→app; returns first match or null
getAttribute(name, scope) — single-scope targeted get
setAttribute(name, val, scope) — store in a specific scope
removeAttribute(name, scope) — delete from specific scope
getRequest() — returns ServletRequest; cast to HttpServletRequest
getOut() — returns JspWriter for writing response output
getELContext() — needed to programmatically evaluate EL in tag handlers
forward(path) / include(path) — dispatch to another resource

findAttribute vs getAttribute

MethodScope Searched

${name}All 4 scopes (EL equivalent)
${requestScope.name}Request scope only (EL)

⚠ Common Mistakes

  • Calling pageContext.getAttribute("key") (no scope argument) and expecting it to search all scopes — the no-arg version only looks in page scope; use findAttribute() for a full search
  • Casting pageContext.getJspContext() to PageContext in a SimpleTag without checking — getJspContext() returns JspContext; the cast is valid in a servlet container but not in all EL environments
  • Using pageContext.forward() in a JSP scriptlet after output has started — once the buffer is flushed, forward throws IllegalStateException

✓ Tips

  • In tag handlers, always use pageContext.findAttribute(name) to mirror what EL does — users of your tag will expect ${name} resolution semantics
  • Prefer explicit-scope variants (getAttribute(name, REQUEST_SCOPE)) over findAttribute() when you know which scope you need — it's faster and unambiguous
  • Use pageContext.getELContext() with ExpressionFactory to evaluate user-supplied EL attribute values in custom tags
  • Access pageContext directly in JSP scriptlets when you need to programmatically forward or set attributes in multiple scopes in one block

Quick Summary

  • pageContext — gateway to all implicit objects and all scopes
  • findAttribute(name) — searches page→request→session→app (same as EL ${name})
  • getAttribute(name) — page scope only; use scoped variant for others
  • setAttribute(name, val, scope) — store in a specific scope
  • Tag handlers — use pageContext as the only gateway to the web context
