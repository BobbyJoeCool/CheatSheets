Sheet 09

Implicit Objects — out, config, pageContext, page, exception

JspWriter · out.print · pageContext · PageContext API · exception · isErrorPage

The Remaining Five Implicit Objects

Beyond request, response, session, and application, JSP provides five more implicit objects. out is the buffered writer that sends text to the response. pageContext is a gateway to all other implicit objects and all four scopes — useful in tag handlers. config gives access to servlet init parameters. page is this — rarely needed. exception holds the unhandled Throwable on error pages only.

Key Facts

  • out type: jakarta.servlet.jsp.JspWriter — a buffered PrintWriter equivalent
  • pageContext type: jakarta.servlet.jsp.PageContext — gateway to everything
  • config type: jakarta.servlet.ServletConfig — reads <init-param> in web.xml
  • page type: Object (actually this) — essentially never useful in a JSP
  • exception is only available when isErrorPage="true"; null otherwise
  • Never mix out and response.getWriter() — they buffer separately and produce garbled output

Usage Examples

<%-- ── out: write to response ───────────────────────────── --%>
<% out.print("Hello"); %>             <%-- same as <%= "Hello" %> --%>
<% out.println("
"); %>            <%-- newline after content --%>
<% out.flush(); %>                    <%-- flush buffer manually --%>
<%= out.getBufferSize() %>            <%-- e.g. 8192 (bytes) --%>
<%= out.getRemaining() %>             <%-- bytes left in buffer --%>

<%-- ── pageContext: scope-crossing access ───────────────── --%>
<%
    // Get any implicit object via pageContext
    HttpServletRequest  req  = (HttpServletRequest)  pageContext.getRequest();
    HttpServletResponse res  = (HttpServletResponse) pageContext.getResponse();
    HttpSession         ses  = pageContext.getSession();
    ServletContext      ctx  = pageContext.getServletContext();

    // Search all scopes for an attribute
    Object val = pageContext.findAttribute("username");
    // → checks page → request → session → application in order

    // Scope-specific set/get
    pageContext.setAttribute("msg", "Hi", PageContext.REQUEST_SCOPE);
%>

<%-- ── config: servlet init parameters ─────────────────── --%>
<%= config.getInitParameter("adminEmail") %>
<%= config.getServletName() %>

<%-- ── exception: available on error pages only ─────────── --%>
<%-- In error.jsp: <%@ page isErrorPage="true" %> --%>

Error: <%= exception.getMessage() %>

<% exception.printStackTrace(new java.io.PrintWriter(out)); %>

Method Notes

out.print(val) — writes to response buffer; no newline
out.flush() — sends buffer to client; after this, headers are committed
pageContext.findAttribute(name) — searches all four scopes in order: page → request → session → application
pageContext.setAttribute(k,v,scope) — scope constants: PAGE_SCOPE, REQUEST_SCOPE, SESSION_SCOPE, APPLICATION_SCOPE
pageContext.forward(path) — equivalent to RequestDispatcher.forward()
config.getInitParameter(name) — reads JSP servlet's own <init-param> from web.xml
exception — the Throwable that caused the error; only on isErrorPage="true" pages

⚠ Common Mistakes

  • Accessing exception without isErrorPage="true" — the variable is not declared; causes a compile error
  • Calling out.flush() before all headers are set — once the buffer is flushed, response headers are committed and cannot be changed
  • Using page (i.e. this) — it is typed as Object, so it requires a cast to be useful; pageContext provides the same access more cleanly
  • Reading config.getInitParameter() expecting application-wide params — config reads the JSP servlet's own <init-param>; use application.getInitParameter() for context params

✓ Tips

  • Use pageContext.findAttribute("name") in custom tag handlers to search all scopes without knowing which scope holds the value
  • On error pages, log exception.getMessage() via application.log() rather than printing stack traces to the response
  • Prefer EL (${}) over out.print() for all output — EL is cleaner and does not require a scriptlet block
  • Use pageContext.getELContext() when writing tag handlers that need to evaluate EL expressions programmatically

Quick Summary

  • out — JspWriter; buffered response writer; prefer EL over out.print()
  • pageContext — gateway to all implicit objects and scopes
  • pageContext.findAttribute(name) — searches page→request→session→app
  • config — servlet init-params; rarely used in view JSPs
  • exception — Throwable on error pages; requires isErrorPage="true"
