Sheet 17

EL Functions & Custom Functions

fn:length · fn:substring · fn:contains · fn:split · fn:join · fn:escapeXml · custom static method

Calling Functions in EL

EL does not allow arbitrary method calls — only registered EL functions declared in a TLD. JSTL provides the fn: library of string and collection utility functions. You can also map your own public static Java methods to EL functions via a TLD. Functions are called as ${prefix:name(arg1, arg2)} inside any EL expression.

Key Facts

  • Declare the fn: library: <%@ taglib prefix="fn" uri="jakarta.tags.functions" %>
  • EL functions must be public static methods in a Java class registered in a TLD
  • fn:length() works on String, arrays, Collections, and Maps
  • fn:escapeXml() converts < > & " ' to HTML entities — always use on user input
  • String indices in fn: functions are zero-based

fn: Function Usage

<%@ taglib prefix="fn" uri="jakarta.tags.functions" %>

<%-- ── String length / test ───────────────────────────────── --%>
${fn:length("hello")}           <%-- 5 --%>
${fn:length(productList)}       <%-- list size --%>
${fn:contains("foobar", "foo")} <%-- true --%>
${fn:containsIgnoreCase("Hello","hello")} <%-- true --%>
${fn:startsWith("index.jsp", "index")}    <%-- true --%>
${fn:endsWith("file.jsp", ".jsp")}        <%-- true --%>
${fn:indexOf("foobar", "bar")}  <%-- 3 --%>

<%-- ── Substrings ─────────────────────────────────────────── --%>
${fn:substring("Hello World", 6, 11)}    <%-- "World" --%>
${fn:substringBefore("foo@bar", "@")}    <%-- "foo" --%>
${fn:substringAfter("foo@bar", "@")}     <%-- "bar" --%>

<%-- ── Transform ─────────────────────────────────────────── --%>
${fn:toUpperCase("hello")}       <%-- "HELLO" --%>
${fn:toLowerCase("HELLO")}       <%-- "hello" --%>
${fn:trim("  hi  ")}             <%-- "hi" --%>
${fn:replace("a-b-c", "-", "_")} <%-- "a_b_c" --%>

<%-- ── Split / Join ──────────────────────────────────────── --%>
<%-- fn:split returns String[] --%>

${parts[0]}                      <%-- "a" --%>
${fn:join(parts, " | ")}         <%-- "a | b | c" --%>

<%-- ── Escape (ALWAYS for user data) ─────────────────────── --%>
${fn:escapeXml(param.comment)}   <%-- <script> → safe --%>

<%-- ── Custom EL function usage (after TLD registration) ─── --%>
<%@ taglib prefix="myutil" uri="/WEB-INF/tlds/myutil.tld" %>
${myutil:formatCurrency(product.price, "USD")}

Custom Function TLD Entry

fn:length(obj) — String char count or collection size
fn:substring(s, start, end) — indices zero-based, end exclusive
fn:split(str, delim) — returns String[]; iterate with c:forEach
fn:join(arr, sep) — joins String[] with separator
fn:escapeXml(str) — escapes 5 XML/HTML special chars; use on all untrusted output
Custom function — must be public static, registered in TLD <function> element

⚠ Common Mistakes

  • Forgetting fn:escapeXml() on user-supplied output — bare ${param.x} is XSS-vulnerable; always wrap with ${fn:escapeXml(param.x)} or use <c:out>
  • Passing a List to fn:join() — it only accepts String[]; convert with fn:split(fn:join(...), ",") or iterate with c:forEach
  • Calling ${fn:substring(s, 0, fn:length(s))} when you want a trimmed copy — just use ${fn:trim(s)}

✓ Tips

  • Use ${fn:escapeXml(value)} as the default for any output that may contain user data — make it a habit, not an afterthought
  • Check empty before using string functions: ${not empty s ? fn:toUpperCase(s) : ''} — some fn: functions throw on null input
  • Register project-wide utility functions (currency formatting, date formatting) as custom EL functions — keeps JSPs clean and functions testable as plain Java statics

Quick Summary

  • ${fn:length(x)} — size of String, List, Map, or array
  • ${fn:escapeXml(s)} — escape HTML entities; use on all user data
  • ${fn:split(s,d)} → String[]; ${fn:join(arr,sep)} → String
  • ${fn:contains / startsWith / endsWith} — boolean string tests
  • Custom functions — public static methods registered in TLD
