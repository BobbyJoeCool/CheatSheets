SimpleTag Handlers

SimpleTagSupport · doTag · JspFragment · invoke · getJspBody · JspContext · DynamicAttributes

The Modern Tag API

SimpleTagSupport is the preferred API for new custom tags. Unlike classic tags, a new instance is created for every tag invocation — no pooling, no release() required. The entire logic lives in a single doTag() method. Body content is accessed via getJspBody().invoke(null) to render it, or invoke(writer) to capture it. Implement DynamicAttributes to accept arbitrary attributes without declaring each one in the TLD.

Key Facts

  • New instance per invocation — no pooling, no state bleed between calls
  • Single method: doTag() — no start/end/afterBody split
  • getJspBody() returns a JspFragment; call invoke(null) to render it to response
  • invoke(writer) captures body into a StringWriter for inspection/modification
  • Throw SkipPageException from doTag() to stop rendering the rest of the JSP
  • Access web context via getJspContext() — cast to PageContext for HTTP-specific methods

SimpleTagSupport Examples

// ── Basic SimpleTag: conditional render ───────────────────
public class IfRoleTag extends SimpleTagSupport {
    private String role;
    public void setRole(String role) { this.role = role; }

    @Override
    public void doTag() throws JspException, IOException {
        PageContext pc = (PageContext) getJspContext();
        HttpSession session = pc.getSession();
        User user = (User) session.getAttribute("currentUser");

        if (user != null && role.equals(user.getRole())) {
            getJspBody().invoke(null); // render body to response
        }
        // if condition fails, body is not rendered
    }
}

// ── Tag with body capture and transform ───────────────────
public class MarkdownTag extends SimpleTagSupport {
    @Override
    public void doTag() throws JspException, IOException {
        StringWriter sw = new StringWriter();
        getJspBody().invoke(sw);        // capture body to string
        String markdown = sw.toString();
        String html = MarkdownParser.toHtml(markdown);
        getJspContext().getOut().print(html);
    }
}

// ── DynamicAttributes: accept any attribute ────────────────
public class HtmlTag extends SimpleTagSupport
        implements DynamicAttributes {
    private final Map<String,Object> attrs = new LinkedHashMap<>();
    private String tag;
    public void setTag(String tag) { this.tag = tag; }

    @Override
    public void setDynamicAttribute(String uri, String name,
            Object value) {
        attrs.put(name, value);
    }

    @Override
    public void doTag() throws JspException, IOException {
        JspWriter out = getJspContext().getOut();
        out.print("<" + tag);
        for (Map.Entry<String,Object> e : attrs.entrySet())
            out.print(" " + e.getKey() + "=\"" + e.getValue() + "\"");
        out.print(">");
        if (getJspBody() != null) getJspBody().invoke(null);
        out.print("</" + tag + ">");
    }
}

API Notes

doTag() — single lifecycle method; replaces doStartTag/doEndTag/doAfterBody
getJspBody() — returns JspFragment; null if tag was used without body
jspBody.invoke(null) — render body to the response output stream
jspBody.invoke(writer) — capture body into a Writer for transformation
getJspContext() — returns JspContext; cast to PageContext for HTTP access
getJspContext().getOut() — JspWriter for writing to response
DynamicAttributes.setDynamicAttribute(uri, name, val) — called for each unknown attribute; requires TLD dynamic-attributes="true"
throw new SkipPageException() — stops rest of JSP; equivalent to classic SKIP_PAGE

⚠ Common Mistakes

  • Calling getJspBody() when the tag was used as a self-closing tag — returns null; always null-check before invoking the body
  • Casting getJspContext() to PageContext in environments where it is not an HTTP context — add a null/instanceof check when portability matters
  • Forgetting to add <dynamic-attributes>true</dynamic-attributes> to the TLD when implementing DynamicAttributes — without it, unknown attributes cause a translation error instead of calling setDynamicAttribute()

✓ Tips

  • Use SimpleTagSupport for all new tags — the one-method API is much easier to reason about than the classic multi-method lifecycle
  • Implement DynamicAttributes for HTML-passthrough tags — lets callers add arbitrary HTML attributes (class, data-*, aria-*) without declaring each one in the TLD
  • For tags that repeat their body, call getJspBody().invoke(null) in a Java loop — cleaner than the classic EVAL_BODY_AGAIN pattern

Quick Summary

  • SimpleTagSupport.doTag() — single method; new instance per call
  • getJspBody().invoke(null) — render body to response
  • getJspBody().invoke(writer) — capture body for transformation
  • DynamicAttributes — accept arbitrary tag attributes
  • throw new SkipPageException() — stop rest of JSP page
