⚠ Common Mistakes

  • Old java.sun.com taglib URIs on a Jakarta EE 10+ server — use jakarta.tags.*
  • <c:if> has no else — reach for <c:choose>
  • Printing user input with ${} instead of <c:out> (XSS)

✓ Tips & Best Practices

  • Wrap repeated markup in a .tag file instead of copy-paste
  • Use varStatus for row striping and "last item" commas
  • Forward from a servlet; let the JSP only render

Quick Summary

  • c: control flow and output, fmt: i18n, fn: strings
  • <c:forEach> + varStatus for loops
  • Tag files for reuse; handlers + TLD for logic
  • Servlet sets attributes, JSP renders them
