EL Operators & Type Coercion

arithmetic · relational · logical · empty · instanceof · ternary · operator precedence

EL Operator Set

EL supports a full set of operators that work entirely within ${} expressions — no Java scriptlet required. Operators come in keyword and symbol forms: eq and == are identical. The empty operator tests for null, empty string, zero-length array/collection, or empty map — a single test that replaces multiple null-checks. The ternary ? : is useful for inline conditionals in attribute values.

Key Facts

  • Keyword aliases exist for XML-unsafe symbols: lt, gt, le, ge, eq, ne, and, or, not
  • empty x is true when: x is null, "", empty array, empty Collection, or empty Map
  • Division by zero returns Infinity for doubles, throws ArithmeticException for integers
  • EL 3.0 added += string concatenation operator: ${"Hello" += " World"}
  • Precedence: [] . → unary → arithmetic → relational → logical → ternary → assignment

EL Operator Examples

<%-- ── Arithmetic ─────────────────────────────────────────── --%>
${5 + 3}          <%-- 8 --%>
${10 - 4}         <%-- 6 --%>
${3 * 4}          <%-- 12 --%>
${10 / 4}         <%-- 2.5 --%>
${10 div 4}       <%-- 2.5   (keyword alias) --%>
${10 % 3}         <%-- 1 --%>
${10 mod 3}       <%-- 1     (keyword alias) --%>

<%-- ── Relational ────────────────────────────────────────── --%>
${price == 0}     <%-- true/false --%>
${price eq 0}     <%-- identical (XML-safe alias) --%>
${price != 0}     <%-- not equal --%>
${price ne 0}     <%-- identical --%>
${price > 100}    <%-- greater than --%>
${price gt 100}   <%-- identical --%>
${price >= 100}   <%-- greater or equal --%>
${price ge 100}   <%-- identical --%>
${price < 10}     <%-- less than --%>
${price lt 10}
${price le 10}    <%-- less or equal --%>

<%-- ── Logical ──────────────────────────────────────────── --%>
${a && b}         <%-- logical AND --%>
${a and b}        <%-- identical --%>
${a || b}         <%-- logical OR --%>
${a or b}         <%-- identical --%>
${!active}        <%-- logical NOT --%>
${not active}     <%-- identical --%>

<%-- ── empty operator ───────────────────────────────────── --%>
${empty list}         <%-- true if null or size==0 --%>
${not empty list}     <%-- true if non-null and non-empty --%>
${empty param.q}      <%-- true if param missing or blank --%>

<%-- ── Ternary ───────────────────────────────────────────── --%>
${user.active ? "Active" : "Inactive"}
${empty cart ? "Empty" : cart.size += " items"}

<%-- ── instanceof (EL 3.0) ─────────────────────────────── --%>
${product instanceof com.example.DigitalProduct}

Operator Notes

== / eq — structural equality; uses .equals() on objects
empty — single keyword tests null, blank, and empty collections at once
and / or / not — XML-safe alternatives; use in tag attributes to avoid escaping &&
lt / gt / le / ge — use in XML attribute values where < and > need escaping
? : — ternary; both branches must be valid EL expressions
+= — EL 3.0 string concatenation; not available in EL 2.x

⚠ Common Mistakes

  • Using < and > inside tag attributes — XML parsers reject them; use lt and gt inside attribute values
  • Expecting empty 0 to be true — zero is not empty in EL; only null, "", and empty collections are
  • Using == to compare strings and getting unexpected results — EL uses .equals() semantics, which is correct, but ensure types match; "5" == 5 coerces and evaluates true

✓ Tips

  • Use ${not empty list} rather than ${list != null && list.size() > 0} — empty covers all cases in one operator
  • Always use keyword aliases (lt, gt, and, or) inside XML attribute values — avoids &amp; escaping and parse errors
  • For complex conditionals in EL, simplify by computing a boolean in the servlet and passing it as a request attribute — keep EL expressions short

Quick Summary

  • eq / ne / lt / gt / le / ge — keyword aliases for XML safety
  • and / or / not — keyword aliases for && || !
  • empty x — true if null, "", or empty collection/map
  • ? : — ternary conditional inside EL
  • Use keyword forms inside tag attribute values to avoid XML escaping
