EL Syntax & Value Expressions

${} immediate · #{} deferred · dot operator · bracket operator · null-safe · isELIgnored

Expression Language Fundamentals

The Expression Language (EL) is JSP's primary syntax for reading data and calling functions without scriptlets. ${expr} is an immediate value expression — it evaluates and outputs when the page renders. #{expr} is a deferred expression — it is evaluated later by a component framework (e.g. JSF). EL is null-safe: accessing a property of a null object returns empty string, not a NullPointerException.

Key Facts

  • EL is enabled by default in JSP 2.0+; disable per-page with <%@ page isELIgnored="true" %>
  • Null safety: ${null.anything} → empty string, not NPE
  • Dot operator ${bean.name} calls getName() via JavaBean convention
  • Bracket operator ${map["key"]} works for maps, lists, arrays, and bean properties
  • EL does not output HTML — use <c:out> or fn:escapeXml() to escape before printing user data
  • To output a literal ${, escape it: \${

EL Expression Patterns

<%-- ── Immediate vs deferred --%>
${user.name}          <%-- immediate: evaluates now (JSP/JSTL) --%>
#{user.name}          <%-- deferred: evaluated by framework (JSF) --%>

<%-- ── Dot vs bracket operator --%>
${user.firstName}     <%-- calls user.getFirstName() --%>
${user["firstName"]}  <%-- identical to dot for beans --%>
${map["key-name"]}    <%-- bracket required: key has hyphen --%>
${list[0]}            <%-- array/list index access --%>
${map[varName]}       <%-- dynamic key from another variable --%>

<%-- ── Null safety --%>
${user.address.city}  <%-- "" if user, address, or city is null --%>

<%-- ── Composite expressions --%>

    View Order #${order.id}



<%-- ── Escape literal ${ --%>
\${not evaluated}     <%-- renders as: ${not evaluated} --%>

<%-- ── EL in tag attributes --%>
...
...

<%-- ── isELIgnored: treat ${ as literal --%>
<%@ page isELIgnored="true" %>
${this is printed literally}

Syntax Notes

${expr} — immediate; renders value to response when page processes
#{expr} — deferred; for JSF/component frameworks; not evaluated by JSTL
bean.property — calls getter: getProperty() or isProperty() for booleans
map["key"] — use brackets when key has special chars or is dynamic
list[0] — zero-based index for arrays and List types
Null mid-chain — any null in a chain returns empty string; no exception
\${ — literal dollar-brace; EL does not evaluate escaped expressions

⚠ Common Mistakes

  • Outputting ${param.userInput} directly — EL does not HTML-escape; a value like <script> renders as live HTML; always use <c:out value="${...}" /> for user data
  • Using dot notation for a map key containing a hyphen (${map.my-key}) — EL parses this as subtraction; use ${map["my-key"]}
  • Forgetting that ${user.name} calls getName() — if the bean method is named fetchName() instead of getName(), EL returns null silently
  • Using #{} in a plain JSP/JSTL page — deferred expressions are not evaluated by the JSP engine; they render as empty string or cause a parse error

✓ Tips

  • Use ${pageContext.request.contextPath} in all link and resource href/src attributes to build portable context-relative URLs
  • Chain null-safe access freely: ${order.customer.address.city} returns "" if any step is null — no defensive null-checks needed
  • Use <c:out value="${val}" /> rather than bare ${val} whenever displaying data that came from user input or a database
  • Set isELIgnored="true" only on legacy JSP 1.x pages being migrated — never on new pages

Quick Summary

  • ${expr} — immediate EL; evaluates and outputs during page rendering
  • . operator — calls getter; [] operator — index/dynamic key access
  • Null-safe — null mid-chain returns "", not NPE
  • \${ — escape to print literal dollar-brace
  • Always escape user data — use <c:out> or fn:escapeXml()
