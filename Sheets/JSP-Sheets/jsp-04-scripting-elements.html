Sheet 04

Scripting Elements

<% %> · <%= %> · <%! %> · generated servlet mapping · thread safety

The Three Scripting Element Types

JSP provides three scripting delimiters for embedding Java directly in a page. Scriptlets (<% %>) inject statements into _jspService(). Expressions (<%= %>) evaluate and print a value — no semicolon. Declarations (<%! %>) add class-level members outside _jspService(), making them shared across all requests.

Key Facts

  • Scriptlet variables are local to _jspService() — they disappear after the response
  • Declaration variables are instance fields — shared across all concurrent requests (thread-unsafe without synchronization)
  • <%= expr %> calls out.print(expr) — do not add a semicolon inside
  • HTML between scriptlets is emitted as out.write("...") in the generated servlet
  • Modern JSP: prefer EL ${} and JSTL over scriptlets for all new code

    Generated Servlet Mapping

    <% stmt; %> → statement placed inline in _jspService()
    <%= expr %> → out.print(expr) in _jspService()
    <%! member %> → class-level field or method, outside _jspService()
    HTML text → out.write("HTML text") in _jspService()
    <%-- --%> → removed entirely; not even a Java comment remains
    ${ } → EL evaluation call; preferred over <%= %>

    ⚠ Common Mistakes

    • Adding a semicolon inside <%= expr; %> — this is a compilation error; expressions must not end with ;
    • Using <%! %> for mutable counters or state — instance fields are shared across all concurrent requests without synchronization
    • Expecting HTML comments <!-- --> to hide sensitive output — they are sent to the browser; use JSP comments <%-- --%> instead
    • Declaring loop variables in <%! %> instead of <% %> — they become shared instance fields, causing data corruption under concurrent load

    ✓ Tips

    • Replace <%= bean.getName() %> with ${bean.name} — EL is shorter, null-safe, and auto-escapes in JSTL <c:out>
    • When you must use scriptlets, keep them to a single variable assignment or cast — any logic beyond that belongs in the servlet
    • Use <%! %> only for constants (static final) and jspInit() / jspDestroy() lifecycle hooks
    • Read the generated servlet in work/ to understand exactly what your scriptlet becomes — it demystifies output ordering bugs

    Quick Summary

    • <% %> — scriptlet; Java statements in _jspService(); local scope
    • <%= %> — expression; prints value; no semicolon
    • <%! %> — declaration; class-level; shared across requests
    • <%-- --%> — JSP comment; never sent to browser
    • ${} — prefer EL over expressions for all output
