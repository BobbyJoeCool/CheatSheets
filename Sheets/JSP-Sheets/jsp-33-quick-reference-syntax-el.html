⚠ Common Mistakes

  • <%= %> and ${} print raw text — escape user data with <c:out> or fn:escapeXml
  • Confusing <%@ include %> (compile time) with <jsp:include> (request time)
  • Business logic in scriptlets instead of a servlet or controller

✓ Tips & Best Practices

  • Put JSPs under WEB-INF/ so only your servlets can forward to them
  • Prefix links with ${pageContext.request.contextPath}
  • Set contentType with charset=UTF-8 on every page

Quick Summary

  • Directives configure; actions run at request time
  • EL ${…} reads beans, maps, lists and scopes
  • Scopes: page → request → session → application
  • Use JSTL and EL, not scriptlets
