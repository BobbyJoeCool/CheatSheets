JSTL Iteration

c:forEach · items · var · varStatus · begin · end · step · c:forTokens · delims

Iterating Collections Without Scriptlets

<c:forEach> is the primary JSTL iteration tag. It iterates over any Collection, array, Map, comma-separated string, Iterator, or Enumeration. The varStatus attribute provides loop metadata (index, count, first, last). <c:forTokens> splits a string by one or more delimiters and iterates the tokens — a compact way to loop over delimited data.

Key Facts

  • items accepts: Collection, List, Set, Map, array, Iterator, Enumeration, or comma-separated String
  • For Maps, var is a Map.Entry; access key/value via ${entry.key} and ${entry.value}
  • varStatus.index is 0-based; varStatus.count is 1-based
  • begin / end / step allow range-based loops without a collection
  • <c:forTokens> delims can contain multiple delimiter characters — any one character matches

c:forEach & c:forTokens Usage

<%@ taglib prefix="c" uri="jakarta.tags.core" %>

<%-- ── Basic collection iteration ────────────────────────── --%>

  
    
    ${p.price}
  


<%-- ── varStatus: loop metadata ───────────────────────────── --%>

  
    ${st.count}         <%-- 1-based row number --%>
    ${o.id}
    ← first
    ← last
  


<%-- ── begin / end / step: numeric range ─────────────────── --%>

  ${i}                           <%-- 1 3 5 7 9 --%>


<%-- ── Map iteration ─────────────────────────────────────── --%>

  
${entry.key}: ${entry.value}



<%-- ── Partial iteration (begin/end on a collection) ─────── --%>

  <%-- first 5 items only --%>


<%-- ── c:forTokens: split string by delimiter ────────────── --%>

  ${color}


<%-- Multiple delimiters (any one char matches) --%>

  ${token}                       <%-- a b c d --%>

Attribute Notes

items — the collection to iterate; omit for numeric range with begin/end
var — loop variable name; available inside tag body only
varStatus — loop status object; properties: index, count, first, last, begin, end, step
begin — start index (0-based for collections); start value for numeric range
end — end index (inclusive); for collections, limits iterations
step — increment between iterations; default 1
delims (forTokens) — string of delimiter characters; each char is an independent delimiter

⚠ Common Mistakes

  • Accessing var after the <c:forEach> closing tag — the variable is removed from scope when the loop ends; save the last value with <c:set> inside the loop if needed
  • Confusing varStatus.index (0-based) with varStatus.count (1-based) — using index for display row numbers produces rows starting at 0
  • Passing a List<String> to <c:forTokens items> — forTokens requires a String; use <c:forEach> for collections

✓ Tips

  • Use varStatus.first and varStatus.last to add comma separators without an extra <c:if>: output the comma before every item except the first
  • Use begin="0" end="4" on a large collection to render just the first N items — avoids loading all items then hiding them with CSS
  • Iterate Maps with ${entry.key} and ${entry.value} — no need to call entrySet() in a scriptlet first

Quick Summary

  • <c:forEach items="${list}" var="x"> — iterate any collection or array
  • varStatus — index (0-based), count (1-based), first, last
  • begin / end / step — numeric range or collection slice
  • Map — var is Map.Entry; use ${entry.key} / ${entry.value}
  • <c:forTokens items="a,b" delims=","> — split string and iterate
