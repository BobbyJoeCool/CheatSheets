Tag Files

WEB-INF/tags · .tag extension · <%@ tag %> · <%@ attribute %> · <%@ variable %> · jsp:doBody · tagdir

Reusable Templates Without Java

Tag files are the simplest way to create a custom tag — you write JSP syntax in a .tag file and place it under WEB-INF/tags/. No Java class, no TLD required. The container compiles the tag file into a SimpleTag handler automatically. Tag files are ideal for reusable layout components (cards, panels, form fields) that need named attributes and optional body content.

Key Facts

  • Files go in WEB-INF/tags/ (or subdirectories); extension is .tag or .tagx
  • No TLD required — declare with tagdir="/WEB-INF/tags/" in the taglib directive
  • <%@ attribute name="title" required="true" %> declares an attribute the caller must or may supply
  • <jsp:doBody /> renders the body content provided by the calling page
  • Tag file implicit objects: request, response, session, application, out, jspContext

Directive Notes

<%@ tag %> — tag file equivalent of <%@ page %>; sets encoding, description, etc.
<%@ attribute name="x" required="true" %> — declares a named attribute; available as EL var ${x}
rtexprvalue="true" — allows EL expressions as attribute values (default true)
<jsp:doBody /> — inserts caller's body; omit if tag has no body
tagdir="/WEB-INF/tags" — declares a tag file library; each .tag file becomes a tag
Subdirectories — files in WEB-INF/tags/ui/ need a separate taglib with tagdir="/WEB-INF/tags/ui"
<%@ variable %> — exposes a scoped variable to the calling page (advanced usage)

⚠ Common Mistakes

  • Placing tag files at the context root instead of WEB-INF/tags/ — they must be inside WEB-INF to be treated as tag files; outside WEB-INF they are accessible as plain JSPs
  • Using uri= in the taglib directive for a tag file library instead of tagdir= — tag files don't have a TLD URI; they use directory-based declaration
  • Forgetting <jsp:doBody /> in a tag that expects body content — without it, the caller's body is silently discarded

✓ Tips

  • Use tag files for any HTML structure that appears more than twice — panels, form groups, nav items, table rows — they are far easier to maintain than repeated markup
  • Organize tag files into subdirectories by component type (WEB-INF/tags/layout/, WEB-INF/tags/form/) and declare each directory as a separate prefix
  • Use <c:out value='${attr}'/> inside tag files to output attribute values — attribute values may contain user data and should be escaped

Quick Summary

  • WEB-INF/tags/name.tag — tag file; no Java, no TLD needed
  • <%@ attribute name="x" required="true"> — declare attribute
  • <jsp:doBody /> — render caller's body content
  • tagdir="/WEB-INF/tags" — declare in taglib directive (not uri=)
  • Best for — markup-heavy reusable UI components
