Sheet 28

Classic Tag Handlers

TagSupport · BodyTagSupport · doStartTag · doEndTag · SKIP_BODY · EVAL_BODY_INCLUDE · doAfterBody

The Classic Tag API

Classic tag handlers implement Tag or BodyTag interfaces — usually by extending TagSupport or BodyTagSupport. They are stateful Java objects, reused across invocations in a pool. The lifecycle is: doStartTag() → (optionally evaluate body) → doEndTag(). The return value of each method controls what happens next. BodyTagSupport adds doAfterBody() for tags that loop over their body.

Key Facts

  • Classic tags are pooled and reused — always implement release() to reset state
  • doStartTag() returns: SKIP_BODY (skip body), EVAL_BODY_INCLUDE (render body once)
  • BodyTagSupport.doStartTag() can also return EVAL_BODY_BUFFERED (buffer body for inspection)
  • doEndTag() returns: SKIP_PAGE (abort rest of JSP), EVAL_PAGE (continue)
  • doAfterBody() returns: EVAL_BODY_AGAIN (repeat body) or SKIP_BODY (stop)
  • Access page context via the inherited pageContext field

TagSupport & BodyTagSupport Examples

// ── Simple tag: outputs a greeting ───────────────────────
public class GreetTag extends TagSupport {
    private String name;

    public void setName(String name) { this.name = name; }

    @Override
    public int doStartTag() throws JspException {
        try {
            pageContext.getOut().print("Hello, " + name + "!");
        } catch (IOException e) {
            throw new JspException(e);
        }
        return SKIP_BODY;          // no body to render
    }

    @Override
    public void release() {
        super.release();
        name = null;               // reset pooled state
    }
}

// ── Body tag: repeats body N times ────────────────────────
public class RepeatTag extends BodyTagSupport {
    private int times;
    private int count;

    public void setTimes(int times) { this.times = times; }

    @Override
    public int doStartTag() {
        count = 0;
        return times > 0 ? EVAL_BODY_BUFFERED : SKIP_BODY;
    }

    @Override
    public int doAfterBody() throws JspException {
        count++;
        if (count < times) {
            return EVAL_BODY_AGAIN; // repeat
        }
        try {
            getBodyContent().writeOut(getPreviousOut());
        } catch (IOException e) { throw new JspException(e); }
        return SKIP_BODY;           // done
    }
}

Lifecycle Notes

setPageContext(pc) — called first; stores PageContext (inherited from TagSupport)
setParent(tag) — called if tag is nested; stores parent tag reference
setXxx(val) — one setter per declared attribute; called before doStartTag()
doStartTag() — return SKIP_BODY or EVAL_BODY_INCLUDE/BUFFERED
doAfterBody() — BodyTagSupport only; EVAL_BODY_AGAIN loops body
doEndTag() — return EVAL_PAGE to continue or SKIP_PAGE to abort
release() — called when tag is returned to pool; nullify all fields
getBodyContent() — returns buffered body as BodyContent for inspection/modification

⚠ Common Mistakes

  • Not implementing release() — classic tags are pooled; instance fields from a previous invocation bleed into the next call if not reset
  • Returning EVAL_BODY_BUFFERED without reading from getBodyContent() — the buffered body is silently discarded; you must call writeOut(getPreviousOut()) to emit it
  • Calling pageContext.getOut().print() in doAfterBody() while using EVAL_BODY_BUFFERED — write to getPreviousOut() instead; getOut() returns the body buffer, not the response

✓ Tips

  • Prefer SimpleTagSupport for all new custom tags — the API is simpler, not pooled (no release() pitfall), and handles body content more cleanly
  • Use classic BodyTagSupport when you need to inspect or transform the body content before emitting it (e.g., a Markdown-rendering tag)
  • Always wrap pageContext.getOut().print() in a try/catch for IOException and rethrow as JspException — the tag interface requires it

Quick Summary

  • TagSupport — doStartTag() + doEndTag(); no body manipulation
  • BodyTagSupport — adds doAfterBody(); can buffer and transform body
  • SKIP_BODY / EVAL_BODY_INCLUDE — doStartTag() return values
  • EVAL_BODY_AGAIN — repeat body; used for iteration tags
  • release() — must reset all fields; tags are pooled
