JSTL Functions (fn:)

fn:length · fn:escapeXml · fn:substring · fn:split · fn:join · fn:replace · fn:contains · fn:toUpperCase

EL Function Library

The fn: library provides 16 string and collection utility functions callable directly inside EL expressions — ${fn:method(arg)}. They are not tags; they return values rather than producing output. This sheet covers all 16 functions with practical examples. Declare the library with <%@ taglib prefix="fn" uri="jakarta.tags.functions" %>. See Sheet 17 for custom EL function registration.

Key Facts

  • fn: functions are called inside ${}, not as tags — they return a value
  • fn:length() works on String, array, Collection, and Map — returns int
  • fn:escapeXml() escapes the 5 XML special chars: < > & " '
  • fn:split() returns String[]; iterate with <c:forEach>
  • fn:join() accepts only String[] — not List or Collection
  • String indices in all fn: functions are zero-based

All fn: Functions with Examples

<%@ taglib prefix="fn" uri="jakarta.tags.functions" %>
<%@ taglib prefix="c"  uri="jakarta.tags.core" %>

<%-- Length --%>
${fn:length("hello")}                    <%-- 5 --%>
${fn:length(productList)}                <%-- list size --%>

<%-- Boolean tests --%>
${fn:contains("foobar", "foo")}          <%-- true --%>
${fn:containsIgnoreCase("Hello","hello")}<%-- true --%>
${fn:startsWith("index.jsp","index")}    <%-- true --%>
${fn:endsWith("logo.png",".png")}        <%-- true --%>
${fn:indexOf("foobar","bar")}            <%-- 3, -1 if absent --%>

<%-- Extraction --%>
${fn:substring("Hello World",6,11)}      <%-- "World" --%>
${fn:substringBefore("user@host","@")}   <%-- "user" --%>
${fn:substringAfter("user@host","@")}    <%-- "host" --%>

<%-- Transform --%>
${fn:toUpperCase("hello")}               <%-- "HELLO" --%>
${fn:toLowerCase("HELLO")}               <%-- "hello" --%>
${fn:trim("  hi  ")}                     <%-- "hi" --%>
${fn:replace("a-b-c","-","_")}           <%-- "a_b_c" --%>
${fn:escapeXml("bold")}           <%-- <b>bold</b> --%>

<%-- Split and Join --%>

${parts[0]}  ${parts[1]}  ${parts[2]}    <%-- a  b  c --%>
${fn:join(parts," | ")}                  <%-- "a | b | c" --%>

Function Notes

fn:contains(s,sub) — case-sensitive; use containsIgnoreCase for flexible matching
fn:indexOf(s,sub) — returns -1 if not found; useful for guard checks
fn:substring(s,begin,end) — begin inclusive, end exclusive, 0-based
fn:replace(s,before,after) — replaces ALL occurrences, not just first
fn:split(s,delim) — delimiter is a single literal string (unlike c:forTokens)
fn:join(arr,sep) — accepts String[] only; result from fn:split works directly
fn:escapeXml(s) — essential before printing any user data in HTML context

⚠ Common Mistakes

  • Passing a List to fn:join() — it only accepts String[]; use <c:forEach> with manual separator logic for Lists
  • Using fn:split(s, ",") and expecting regex behavior — the delimiter is a literal string, not a regex pattern; for regex splitting use Java in the servlet
  • Skipping fn:escapeXml() for output that "looks safe" — a value like AT&T contains an ampersand that will break HTML if unescaped

✓ Tips

  • Combine functions: ${fn:toUpperCase(fn:trim(param.code))} — fn: calls nest cleanly inside EL
  • Guard against null before string functions: ${not empty s ? fn:toUpperCase(s) : ''} — some functions throw on null input depending on EL version
  • Use fn:length() with gt instead of != 0 for collection size checks — reads naturally: ${fn:length(list) gt 0}

Quick Summary

  • ${fn:length(x)} — String length or collection size
  • ${fn:escapeXml(s)} — escape HTML entities; use on all output
  • ${fn:contains / startsWith / endsWith / indexOf} — boolean/int tests
  • ${fn:split(s,d)} → String[]; ${fn:join(arr,sep)} → String
  • fn: functions nest: ${fn:trim(fn:toLowerCase(s))}
