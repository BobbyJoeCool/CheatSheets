Action Mailer

ApplicationMailer · mail() · deliver_later · mailer views · previews · default from: · attachments · Action Mailbox note

Sending Email

Mailers work like controllers: each method sets instance variables and calls mail, and a view template renders the body (HTML and/or text). Call deliver_later to send through Active Job. Previews render emails in the browser while you design them. Inbound email is a separate framework, Action Mailbox.

Notes

  • Generate with bin/rails g mailer User welcome
  • Views: app/views/user_mailer/welcome.html.erb and .text.erb
  • Links need absolute URLs: set default_url_options[:host] per environment
  • Pass data with .with(user:) (parameterized mailers) and read params[:user]

app/mailers/user_mailer.rb

class UserMailer < ApplicationMailer
  default from: email_address_with_name("hello@example.com", "Example App")
  before_action { @user = params[:user] }

  def welcome
    attachments["guide.pdf"] = File.read(Rails.root.join("public/guide.pdf"))
    mail to: email_address_with_name(@user.email_address, @user.name),
         subject: "Welcome, #{@user.name}!"
  end
end

Sending

UserMailer.with(user: user).welcome.deliver_later
UserMailer.with(user: user).welcome.deliver_later(wait: 1.hour)
UserMailer.with(user: user).welcome.deliver_now      # scripts, tests

config.action_mailer.default_url_options = { host: "example.com" }
config.action_mailer.smtp_settings = { address: "smtp.postmarkapp.com", port: 587,
  user_name: Rails.application.credentials.dig(:smtp, :user),
  password:  Rails.application.credentials.dig(:smtp, :password) }

Code Explained

email_address_with_name — "Example App" <hello@example.com>
before_action — mailers have callbacks too
attachments[...] — files; attachments.inline for images in HTML
dashboard_url — _url helpers, never _path, in emails
Previews — no email sent, renders HTML and text parts

The Rails Way

  • deliver_now in a controller → deliver_later
  • Positional mailer arguments → .with(...) and params
  • Sending real mail in development → letter_opener or previews

⚠ Common Mistakes

  • Forgetting default_url_options, so links in emails raise "Missing host to link to!"
  • Passing unsaved records to deliver_later; GlobalID needs a persisted record
  • Only writing an HTML template; some clients and spam filters prefer a text part too

✓ Tips & Best Practices

  • Inline CSS with premailer-rails or keep styles simple; many clients strip <style>
  • Use rails_blob_url for Active Storage images in emails
  • Set config.action_mailer.deliver_later_queue_name = :mailers
