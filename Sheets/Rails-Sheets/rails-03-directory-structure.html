Sheet 03

Directory Structure

app/ · config/ · db/ · lib/ · bin/ · storage/ · script/ · Zeitwerk file naming

Where Things Live

Every Rails app has the same layout, which is why you can open any Rails project and find your way around. Code under app/ is autoloaded by Zeitwerk: file paths must match constant names, and you never write require for your own classes.

Layout Rules

  • app/models/admin/user.rb must define Admin::User
  • Any new folder under app/ (e.g. app/services) is autoloaded automatically
  • lib/ is autoloaded only for subfolders listed in config.autoload_lib(ignore: %w[assets tasks])
  • storage/ holds SQLite databases and local Active Storage files

Code Explained

app/ — your application code, autoloaded and reloaded in development
config/ — routes, environments, initializers, credentials, deploy config
db/ — migrations and the generated schema.rb
public/ — static files served before Rails sees the request
script/ — one-off and maintenance scripts (g script generator, 8.0+)

The Rails Way

  • require_relative "../models/user" in app code → let Zeitwerk autoload by file name
  • A grab-bag app/lib or utils.rb → name folders after what they hold (app/services, app/queries)
  • Business logic in lib/ → keep app logic in app/; reserve lib/ for app-independent code

⚠ Common Mistakes

  • Naming app/services/pdf_maker.rb but defining PDFMaker: Zeitwerk expects PdfMaker unless you add an acronym inflection
  • Putting two classes in one file; the second can't be autoloaded by name
  • Editing files in public/ and expecting asset fingerprinting; only app/assets is processed

✓ Tips & Best Practices

  • Run bin/rails zeitwerk:check in CI to catch naming mismatches before production eager loading does
  • Keep concerns/ for genuinely shared modules, not as a dumping ground
  • Look at config/application.rb first in an unfamiliar app: it shows load_defaults and custom settings

Quick Summary

  • app/ — autoloaded code
  • config/ — settings and routes
  • db/ — migrations and schema
  • file path = constant — Zeitwerk rule
