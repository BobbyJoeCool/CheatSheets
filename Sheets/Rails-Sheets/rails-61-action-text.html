Rich Text Content

Action Text adds rich text fields to any model. The content is stored in a separate action_text_rich_texts table, so no column is needed on your model. Images and files dropped into the editor are stored with Active Storage. The default editor is Trix; 37signals' newer Lexxy editor is available as a gem.

Notes

  • Install: bin/rails action_text:install (adds JS, CSS, tables)
  • Generator field type: bin/rails g model Article content:rich_text
  • Content is sanitized on render; embedded attachments render through partials
  • Eager-load with with_rich_text_content to avoid N+1 queries

Model

class Article < ApplicationRecord
  has_rich_text :content
  validates :content, presence: true
end

Form & Display

<%= form_with model: @article do |f| %>
  <%= f.label :content %>
  <%= f.rich_textarea :content %>
  <%= f.submit %>
<% end %>

<div class="trix-content"><%= @article.content %></div>

Working with Content

article.content.to_plain_text          # "Hello world"
article.content.body.to_html
article.content.embeds                 # attached blobs
Article.with_rich_text_content.limit(10)
article.update!(content: "<p>New <strong>text</strong></p>")
params.expect(article: [:title, :content])   # permit like a normal attribute

Code Explained

has_rich_text :content — article.content returns an ActionText::RichText
f.rich_textarea — 8.0 name; rich_text_area still works
trix-content class — editor styling for displayed content
to_plain_text — for search indexes, previews, emails
Permit the field like any attribute

The Rails Way

  • A text column with raw HTML from a JS editor → has_rich_text
  • Storing uploaded images in a custom table → Action Text embeds via Active Storage
  • Sanitizing HTML by hand on display → let Action Text's sanitizer handle it

⚠ Common Mistakes

  • Querying where(content: ...) on the model; content lives in another table
  • Forgetting with_rich_text_* when listing many records
  • Rendering content.body.to_s with raw, bypassing the sanitizer

✓ Tips & Best Practices

  • Make any model embeddable (e.g. @mentions) with include ActionText::Attachable
  • Index to_plain_text for full-text search
  • Try Lexxy for new projects that need tables or code blocks
