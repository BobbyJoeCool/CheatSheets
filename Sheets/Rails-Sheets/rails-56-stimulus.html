Stimulus

data-controller · data-action · targets · values · outlets · connect() · g stimulus

Sprinkles of JavaScript

Stimulus attaches small JavaScript controllers to HTML through data- attributes. The HTML stays server-rendered; controllers add behavior such as toggles, clipboard copy, autosave and character counters. Controllers connect and disconnect automatically as Turbo changes the page.

Notes

  • Controller file hello_controller.js → identifier hello; admin/menu_controller.js → admin--menu
  • Generate with bin/rails g stimulus dropdown
  • With import maps, controllers are eager-loaded from app/javascript/controllers
  • State lives in the DOM (values), not in hidden JS variables

app/javascript/controllers/clipboard_controller.js

import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  static targets = ["source", "button"]
  static values  = { successText: { type: String, default: "Copied!" } }
  static classes = ["success"]

  connect() { this.originalText = this.buttonTarget.textContent }

  copy(event) {
    event.preventDefault()
    navigator.clipboard.writeText(this.sourceTarget.value)
    this.buttonTarget.textContent = this.successTextValue
    this.element.classList.add(this.successClass)
  }

  disconnect() { this.buttonTarget.textContent = this.originalText }
}

The HTML

<div data-controller="clipboard"
     data-clipboard-success-text-value="Link copied"
     data-clipboard-success-class="copied">
  <input data-clipboard-target="source" value="<%= post_url(@post) %>" readonly>
  <button data-clipboard-target="button" data-action="clipboard#copy">Copy</button>
</div>
<%= tag.div data: { controller: "toggle", action: "keydown.esc@window->toggle#hide" } %>

Code Explained

static targets — this.sourceTarget, this.hasSourceTarget
static values — typed, read from data-*-value, with …ValueChanged() callbacks
data-action="clipboard#copy" — default event for buttons is click
keydown.esc@window — key filter + global listener
connect / disconnect — lifecycle as elements enter/leave the DOM

The Rails Way

  • document.querySelector from global scripts → targets scoped to the controller
  • Inline onclick handlers → data-action (also CSP-friendly)
  • One giant app.js → one small controller per behavior

⚠ Common Mistakes

  • Misspelling the identifier (data-controller="Clipboard"): identifiers are lowercase with dashes
  • Keeping state in JS variables that Turbo snapshots lose; store it in values
  • Adding listeners in connect without removing them in disconnect

✓ Tips & Best Practices

  • Use bin/rails g stimulus name so the file lands where the loader expects it
  • Use outlets to let controllers talk without global events
  • Check this.application.debug = true in the console to log lifecycle events

Quick Summary

  • data-controller — attach behavior
  • targets — scoped elements
  • values — typed DOM state
  • data-action — event → method
