Routing Basics

Mapping URLs to Actions

config/routes.rb connects an HTTP verb and path to a controller#action. Each named route also generates URL helpers: post_path(@post) returns "/posts/1" and post_url(@post) returns the full URL. Routes match top to bottom, so the first match wins.

Routing Facts

  • Verbs: get, post, patch, put, delete, plus match via: [...]
  • Dynamic segments like :id arrive in params[:id] as strings
  • as: names the route; resource routes are named automatically
  • Use _path in views and redirects, _url in mailers and external links

config/routes.rb

Rails.application.routes.draw do
  root "pages#home"                           # GET /

  get  "about",       to: "pages#about"       # about_path
  get  "posts/:id",   to: "posts#show", as: :post
  post "posts",       to: "posts#create"
  get  "search",      to: "search#index", as: :search
  get  "up" => "rails/health#show", as: :rails_health_check
end

Using the Helpers

<%= link_to "About", about_path %>          <!-- /about -->
<%= link_to post.title, post_path(post) %>   <!-- /posts/42 -->
<%= link_to "Find", search_path(q: "rails") %> <!-- /search?q=rails -->
<%= root_url %>                              <!-- http://localhost:3000/ -->

Code Explained

to: "posts#show" — PostsController#show
as: :post — creates post_path and post_url
Passing a model (post_path(post)) calls post.to_param (the id)
Extra hash keys become the query string
/up — the generated health check (returns 200 when the app boots)

The Rails Way

  • Hard-coded href="/posts/#{post.id}" → post_path(post)
  • A custom get for each CRUD action → resources :posts (sheet 08)
  • redirect_to "/posts" → redirect_to posts_path

⚠ Common Mistakes

  • Putting a catch-all get "*path" above other routes; routes match in order so it swallows everything after it
  • Using _path in mailer views; emails need absolute _url helpers and default_url_options[:host]
  • Expecting params[:id] to be an Integer; route params are always strings

✓ Tips & Best Practices

  • Run bin/rails routes -g post whenever you forget a helper name
  • Visit /rails/info/routes in development for a searchable route table
  • Set Rails.application.routes.default_url_options[:host] once for jobs and mailers

Quick Summary

  • root — the home page
  • get "x", to: "c#a" — a single route
  • as: — names the helper
  • _path / _url — relative / absolute
