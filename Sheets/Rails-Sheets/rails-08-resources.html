Sheet 08

Resourceful Routes

resources · resource (singular) · the 7 actions · only: / except: · member · collection · param:

REST in One Line

resources :posts creates seven routes that map HTTP verbs to the standard CRUD actions, with named helpers for each. Use only: or except: to keep just the actions you implement. A singular resource is for things a user has exactly one of, like a profile, so there is no :id in the path.

Resource Notes

  • The 7 actions: index, show, new, create, edit, update, destroy
  • PATCH and PUT both route to update
  • member routes act on one record (has :id); collection routes act on the set
  • param: :slug renames :id in the path and in params

config/routes.rb

resources :posts                                # all 7
resources :photos, only: [:index, :show]
resources :tags,   except: :destroy
resource  :profile                              # singular, no index, no :id
resources :articles, param: :slug               # /articles/:slug

resources :posts do
  member do
    patch :publish                              # /posts/:id/publish
  end
  collection do
    get :drafts                                 # /posts/drafts
  end
end
resources :comments, path: "notes"              # URL /notes, helpers comments_*

Code Explained

only: / except: — avoid routes to actions that don't exist
resource :profile — /profile, profile_path, still uses ProfilesController
member — publish_post_path(post)
collection — drafts_posts_path
path: — change the URL without renaming controllers or helpers

The Rails Way

  • post "posts/:id/publish" written by hand → member { patch :publish }
  • Custom actions piling up on one controller → a new resource (resource :publication) with standard actions
  • resources :posts when only 2 actions exist → add only:

The Seven Routes for resources :posts

Verb + PathAction · Helper

⚠ Common Mistakes

  • Linking to destroy with a plain link_to; it sends GET. Use button_to ... method: :delete
  • Adding get :drafts without collection, which produces /posts/:post_id/drafts inside a block
  • Using resources :profile (plural) for a singleton and then needing a fake :id

✓ Tips & Best Practices

  • Prefer adding a new controller over adding a 4th custom action: "every action is one of the seven"
  • Use param: :slug together with to_param in the model for pretty URLs
  • Check helper names with bin/rails routes -c posts

Quick Summary

  • resources — 7 CRUD routes
  • resource — singular, no id
  • member / collection — extra actions
  • only: — keep it tight
