Built-in View Helpers

link_to · button_to · image_tag · tag.div · number_to_currency · time_ago_in_words · truncate · pluralize

Helpers You Use Daily

Action View ships hundreds of helpers for links, tags, numbers, dates and text. They escape output, build correct URLs from routes, and add Rails conventions such as CSRF tokens and fingerprinted asset paths. Use button_to for anything that changes data.

Helper Notes

  • link_to always makes a GET link; button_to makes a form (POST by default)
  • tag.div, tag.span build any element; class: accepts arrays and hashes
  • Number and date helpers respect I18n locale settings
  • Helpers are available in views, and in the console via helper.

Links, Buttons & Tags

<%= link_to "Posts", posts_path, class: "nav" %>
<%= link_to @post.title, @post %>
<%= link_to "Docs", "https://guides.rubyonrails.org", target: "_blank", rel: "noopener" %>
<%= button_to "Delete", @post, method: :delete,
      form: { data: { turbo_confirm: "Sure?" } } %>
<%= link_to "Cancel", :back %>
<%= mail_to "hi@example.com" %>
<%= image_tag "logo.svg", alt: "Logo", width: 120 %>
<%= tag.div "Saved", class: ["flash", { "flash-error": @error }] %>
<%= tag.span data: { controller: "clipboard" } do %>Copy<% end %>

Numbers, Dates & Text

number_to_currency(1234.5)            # "$1,234.50"
number_with_delimiter(1234567)        # "1,234,567"
number_to_percentage(63.8, precision: 0)   # "64%"
number_to_human_size(1_500_000)       # "1.43 MB"
time_ago_in_words(3.hours.ago)        # "about 3 hours"
l(Date.current, format: :long)        # "October 23, 2026"
truncate("A long sentence", length: 10, separator: " ")  # "A long..."
pluralize(2, "comment")               # "2 comments"
excerpt("Rails is fun", "is", radius: 3)      # "...ls is fu..."

Code Explained

button_to ... method: :delete — a tiny form, safe for non-GET actions
data: { turbo_confirm: } — Turbo confirm dialog before submit
class: [..., { "x": cond }] — conditional classes
l(...) — localized date/time formatting
pluralize — uses Active Support inflections

The Rails Way

  • <a href="<%= post_path(p) %>"> → link_to p.title, p
  • link_to "Delete", ..., data: { turbo_method: :delete } for destructive actions → button_to
  • Formatting money with "$#{price}" → number_to_currency(price)

⚠ Common Mistakes

  • Making delete links with link_to; crawlers and prefetchers can trigger GET links
  • Passing user input as link_to URLs without checking the scheme (javascript: links)
  • Using number_to_currency on floats for stored money; keep money as decimals or integer cents

✓ Tips & Best Practices

  • Use tag.attributes(...) (7.1+) to spread attributes into hand-written tags
  • Put app-specific formatting in a helper (format_price) that wraps the built-ins
  • Try helpers quickly in bin/rails c with helper.number_to_human(12345)

Quick Summary

  • link_to — GET links
  • button_to — actions that change data
  • tag.* — build elements
  • number_* / time_ago_* — formatting
