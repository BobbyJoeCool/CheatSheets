Forms Bound to Models

form_with model: @post builds a form whose URL, HTTP method, field names and values come from the model. A new record posts to posts_path; a saved one patches post_path(@post). Field names like post[title] line up with params.expect(post: [...]) in the controller.

Form Notes

  • Every form includes a hidden CSRF authenticity_token
  • f.submit label is "Create Post" or "Update Post" automatically
  • Turbo submits the form via fetch; respond with 422 or a redirect (303)
  • Use url: for forms not tied to a model, such as search

app/views/posts/_form.html.erb

<%= form_with model: post do |f| %>
  <% if post.errors.any? %>
    <div class="errors">
      <h2><%= pluralize(post.errors.count, "error") %> prevented saving:</h2>
      <ul><% post.errors.full_messages.each do |msg| %><li><%= msg %></li><% end %></ul>
    </div>
  <% end %>

  <%= f.label :title %>
  <%= f.text_field :title, autofocus: true, required: true %>

  <%= f.label :body %>
  <%= f.textarea :body, rows: 8 %>

  <%= f.label :status %>
  <%= f.select :status, Post.statuses.keys, include_blank: "Pick one" %>

  <%= f.check_box :featured %> <%= f.label :featured %>
  <%= f.submit class: "btn" %>
<% end %>

A Search Form (no model)

<%= form_with url: search_path, method: :get do |f| %>
  <%= f.search_field :q, value: params[:q] %>
  <%= f.submit "Search", name: nil %>
<% end %>

Code Explained

model: post — URL, method and post[...] names inferred
errors.full_messages — "Title can't be blank"
f.textarea — 8.0 name; text_area still works
check_box — adds a hidden 0 so unchecked boxes still submit
method: :get — search params go in the query string

The Rails Way

  • Hand-written <input name="post[title]"> → f.text_field :title
  • Separate new/edit forms → one _form partial used by both
  • form_tag / form_for → form_with (the unified API)

⚠ Common Mistakes

  • Rendering the form with status 200 after a failed save; Turbo won't replace the page
  • Forgetting name: nil on a GET search submit, which adds commit=Search to the URL
  • Using form_with model: @comment for a nested resource; pass [@post, @comment]

✓ Tips & Best Practices

  • Use f.label :title, "Headline" to override text; otherwise it reads from I18n
  • Wrap field + error in a small helper so invalid fields get an error class
  • Rails adds field_with_errors wrappers; style them or set config.action_view.field_error_proc
