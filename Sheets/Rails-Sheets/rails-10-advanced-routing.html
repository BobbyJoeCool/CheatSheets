Advanced Routing

dynamic segments · globbing *path · constraints · defaults · redirect() · direct · resolve · mount

Beyond Resources

Rails routing can match optional and glob segments, restrict routes with regex or request-based constraints, redirect without a controller, mount Rack apps and engines, and define custom URL helpers with direct and resolve. Large route files can be split with draw.

Advanced Notes

  • Optional segments go in parentheses: (/:page)
  • Constraints can be a hash, regex, lambda or an object with matches?(request)
  • redirect returns 301 by default; pass status: 302 for temporary
  • draw(:admin) loads config/routes/admin.rb

config/routes.rb

get "photos/:id", to: "photos#show", constraints: { id: /\d+/ }
get "archive/:year(/:month)", to: "archive#show"      # optional segment
get "docs/*path", to: "docs#show", format: false      # glob: "a/b/c"
get "feed", to: "posts#index", defaults: { format: :rss }

get "/old-blog", to: redirect("/blog")
get "/stories/:name", to: redirect("/articles/%{name}", status: 302)

constraints subdomain: "api" do
  resources :widgets
end
constraints ->(req) { req.session[:admin] } do
  mount MissionControl::Jobs::Engine, at: "/jobs"
end

direct(:docs) { "https://guides.rubyonrails.org" }    # docs_url
resolve("Basket") { [:basket] }    # form_with model: @basket → /basket

draw(:admin)                                           # config/routes/admin.rb
match "*unmatched", to: "errors#not_found", via: :all  # keep last

Code Explained

constraints: { id: /\d+/ } — /photos/abc won't match
*path — captures the rest of the URL into params[:path]
%{name} — reuse a captured segment in a redirect
mount — attach a Rack app or engine at a path
resolve — teach polymorphic helpers about a singular resource

The Rails Way

  • A controller action that only redirects → to: redirect(...) in routes
  • Checking request.subdomain in every action → a routing constraints subdomain: block
  • One 800-line routes.rb → split areas with draw(:name)

⚠ Common Mistakes

  • Placing the catch-all match "*unmatched" before engine mounts; it steals their requests
  • Forgetting regex anchors don't apply: segment constraints are already anchored, so ^ and $ raise errors
  • Using a constraint lambda for authorization alone; still check permissions in the controller

✓ Tips & Best Practices

  • Use format: false on glob routes so file.pdf stays part of the path
  • Name redirects (as:) if you link to them from views
  • Wrap admin-only mounts in an authenticated constraint, e.g. authenticated from your auth layer

Quick Summary

  • constraints — restrict matches
  • *path — glob the rest
  • redirect() — no controller needed
  • mount / draw — engines and split files
