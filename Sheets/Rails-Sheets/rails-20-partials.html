Partials & Collection Rendering

render "form" · locals: · render @posts · collection: / as: · strict locals comment (7.1) · cached: true · spacer_template

Reusable View Pieces

A partial is a template whose file name starts with an underscore. render "form" renders _form.html.erb from the same folder. Rendering a model or collection uses conventions: render @posts renders posts/_post.html.erb once per post, with a local named post. Rails 7.1 strict locals declare which locals a partial accepts.

Partial Notes

  • render "shared/nav" → app/views/shared/_nav.html.erb
  • Pass data through locals, not instance variables
  • Collection rendering is one call, much faster than a loop of render
  • Inside a collection partial: post_counter, post_iteration.first? / .last?

app/views/posts/_post.html.erb

<%# locals: (post:, show_author: true) -%>
<article id="<%= dom_id post %>">
  <h2><%= link_to post.title, post %></h2>
  <% if show_author %><p>by <%= post.author.name %></p><% end %>
</article>

Rendering It

<%= render @posts %>                                  <%# _post per item %>
<%= render @posts, show_author: false %>              <%# extra local %>
<%= render partial: "posts/post", collection: @posts, as: :post %>
<%= render(@posts) || tag.p("No posts yet") %>        <%# empty fallback %>
<%= render partial: "post", collection: @posts, cached: true %>
<%= render partial: "post", collection: @posts, spacer_template: "divider" %>

<%= render "form", post: @post %>                     <%# _form.html.erb %>
<%= render @post %>                                   <%# single model %>
<%= render "shared/card" do %>Body text<% end %>      <%# partial with a block %>

Code Explained

locals: (post:, show_author: true) — required and optional locals; unknown ones raise
dom_id post — "post_42", used by Turbo for targeting
render @posts returns nil on an empty collection, so || adds a fallback
cached: true — multi-fetch fragment cache for every item
spacer_template — rendered between items

The Rails Way

  • <% @posts.each do |p| %><%= render "post", post: p %><% end %> → render @posts
  • Partials reading @post → pass post: as a local
  • Guessing which locals a partial needs → declare strict locals

⚠ Common Mistakes

  • Naming the file post.html.erb without the underscore; render "post" can't find it
  • Rendering partials in a loop (N renders) instead of collection rendering
  • Passing a local the strict-locals comment doesn't declare → ActionView::Template::Error

✓ Tips & Best Practices

  • Use strict locals in every new partial; it documents the partial and catches typos
  • Combine cached: true with touch: true on associations for Russian-doll caching (sheet 63)
  • Put cross-controller partials in app/views/shared/ or application/

Quick Summary

  • _name.html.erb — a partial
  • render @posts — collection by convention
  • locals: — pass data in
  • strict locals — declare inputs
