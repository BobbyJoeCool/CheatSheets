Associations & Complex Forms

Forms often edit more than one record. collection_select and collection_check_boxes set associations from a list. fields_for with accepts_nested_attributes_for saves child records in the same submit. When a form doesn't map to one table, build a form object with Active Model.

Notes

  • Nested attributes params end in _attributes and must be permitted
  • Include :id and :_destroy to update and remove existing children
  • collection_check_boxes sends tag_ids: [] with a hidden empty value
  • File uploads need f.file_field; form_with sets multipart automatically

Model

class Project < ApplicationRecord
  belongs_to :category
  has_many :tasks, dependent: :destroy
  has_and_belongs_to_many :tags
  has_one_attached :logo
  accepts_nested_attributes_for :tasks, allow_destroy: true,
    reject_if: ->(attrs) { attrs["name"].blank? }
end

Form

<%= form_with model: @project do |f| %>
  <%= f.collection_select :category_id, Category.order(:name), :id, :name,
        prompt: "Category" %>
  <%= f.collection_check_boxes :tag_ids, Tag.all, :id, :name %>
  <%= f.file_field :logo, accept: "image/*", direct_upload: true %>

  <%= f.fields_for :tasks do |tf| %>
    <%= tf.text_field :name %>
    <%= tf.check_box :_destroy %> <%= tf.label :_destroy, "Remove" %>
  <% end %>
  <%= f.submit %>
<% end %>

Controller Params

params.expect(project: [:category_id, :logo, tag_ids: [],
                        tasks_attributes: [[:id, :name, :_destroy]]])

Code Explained

collection_select — (method, collection, value_method, text_method)
tag_ids — Rails writes the join rows for you
direct_upload: true — browser uploads straight to storage (sheet 60)
fields_for :tasks — one block per existing task
reject_if — skip blank rows instead of failing validation

The Rails Way

  • Saving parent and children in separate controller actions → nested attributes or a form object
  • Complex nested attributes across three levels → an Active Model form object
  • options_for_select(Category.all.map { ... }) → collection_select

⚠ Common Mistakes

  • Forgetting :id in permitted nested attributes, so every submit creates duplicate children
  • Missing allow_destroy: true, so _destroy is ignored
  • Using collection_check_boxes but permitting :tag_ids without []

✓ Tips & Best Practices

  • Add new nested rows dynamically with a <template> and a small Stimulus controller
  • Reach for a form object once a form touches more than two models
  • Use f.fields_for :address for has_one / belongs_to too

Quick Summary

  • collection_select — pick a record
  • fields_for — nested records
  • accepts_nested_attributes_for — model side
  • form object — multi-model forms
