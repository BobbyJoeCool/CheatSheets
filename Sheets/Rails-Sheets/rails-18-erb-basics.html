ERB Templates

<%= %> · <% %> · <%# %> · auto-escaping · html_safe / raw · template lookup · Herb compiler (8.2 edge)

Embedded Ruby

Views are ERB templates: HTML with Ruby inside tags. <%= %> outputs the result, <% %> runs code without output. Output is HTML-escaped automatically, so user data can't inject markup. Templates are found by convention: app/views/<controller>/<action>.<format>.erb.

ERB Notes

  • File names: show.html.erb, show.json.jbuilder, show.turbo_stream.erb
  • Views see controller instance variables and all helpers
  • -%> trims the newline after a tag
  • Rails 8.2 (edge) switches new apps to the Herb HTML-aware ERB engine, which also catches unclosed tags

app/views/posts/show.html.erb

<%# a comment: never sent to the browser %>
<h1><%= @post.title %></h1>
<p>By <%= @post.author.name %> · <%= time_ago_in_words(@post.created_at) %> ago</p>

<% if @post.published? %>
  <%= simple_format(@post.body) %>
<% else %>
  <p class="muted">Draft</p>
<% end %>

<ul>
  <% @post.tags.each do |tag| %>
    <li><%= tag.name %></li>
  <% end %>
</ul>

<%= "<b>bold?</b>" %>          <%# escaped: &lt;b&gt;bold?&lt;/b&gt; %>
<%= sanitize @post.summary %>  <%# keeps safe tags only %>
<%= raw @trusted_html %>       <%# no escaping: trusted input only %>

Code Explained

<%= %> — evaluate and output (escaped)
<% %> — control flow: if, each, assignments
simple_format — turns newlines into <p> / <br>
sanitize — strips scripts and unsafe attributes
raw / .html_safe — mark a string as safe: never on user input

The Rails Way

  • <% @posts = Post.all %> in a view → load data in the controller
  • Big if trees in templates → a helper method or partial
  • .html_safe on user content → sanitize or plain escaped output

Tags

TagMeaning
<%= expr %>Output escaped result
<% code %>Run, no output
<%# comment %>Comment
<%== expr %>Output without escaping (like raw)
<%- / -%>Trim leading / trailing whitespace

⚠ Common Mistakes

  • Using <% where you meant <%=, so nothing appears and no error is raised
  • Calling .html_safe on interpolated strings containing user data → XSS
  • Writing <%= @posts.each do |p| %>, which prints the whole array inspect after the loop

✓ Tips & Best Practices

  • Use debug(@post) or <%= console %> (web-console) to inspect values during development
  • Turn on config.action_view.annotate_rendered_view_with_filenames to see which template rendered what
  • Keep logic in helpers or models; templates should read like HTML

Quick Summary

  • <%= %> — output
  • <% %> — logic
  • auto-escape — safe by default
  • raw — trusted only
