Nested, Namespaced & Scoped Routes

nested resources · shallow: true · namespace · scope · module: · concern / concerns: · path:

Organizing Routes

Nesting expresses ownership in the URL (/posts/1/comments). Namespaces group controllers in a module and URL prefix, like an admin area. scope lets you change only the URL prefix, only the module, or only the helper name, independently. Concerns reuse route blocks.

Rules of Thumb

  • Never nest more than one level deep
  • shallow: true nests only the actions that need the parent (index, new, create)
  • namespace :admin = URL /admin, module Admin::, helpers admin_
  • Nested params arrive as params[:post_id] and params[:id]

config/routes.rb

resources :posts do
  resources :comments, shallow: true
end

namespace :admin do
  resources :users                 # Admin::UsersController, /admin/users
  root "dashboard#show"            # admin_root_path
end

scope "/app" do                    # URL only
  resources :reports               # ReportsController, /app/reports
end
scope module: "api" do             # module only
  resources :tokens                # Api::TokensController, /tokens
end
scope "(:locale)", locale: /en|es/ do
  resources :products              # /es/products and /products
end

concern :commentable do
  resources :comments, only: [:index, :create]
end
resources :articles, concerns: :commentable
resources :videos,   concerns: :commentable

Nested Helpers

<%= link_to "Comments", post_comments_path(@post) %>
<%= form_with model: [@post, Comment.new] do |f| %> ... <% end %>

Code Explained

Shallow: post_comments_path(post) for index/create, comment_path(c) for the rest
namespace — controllers live in app/controllers/admin/
scope "(:locale)" — optional segment with a constraint
concern — share nested routes across resources
[@post, Comment.new] — polymorphic nested form URL

The Rails Way

  • /posts/1/comments/5/likes/2 → shallow nesting, max one level
  • An admin area with if current_user.admin? in every action → namespace :admin plus a base Admin::BaseController
  • Duplicated nested blocks → a routing concern

⚠ Common Mistakes

  • Deep nesting that forces every helper to take three objects: post_comment_like_path(post, comment, like)
  • Namespacing routes without moving controllers into the matching folder; Zeitwerk raises uninitialized constant Admin::UsersController
  • Forgetting the parent in nested forms: form_with model: @comment posts to /comments

✓ Tips & Best Practices

  • Give namespaced controllers a shared parent (Admin::BaseController) for auth filters
  • Use scope "(:locale)" for i18n URLs without duplicating routes
  • Use bin/rails routes -g admin to confirm what a namespace produced

Quick Summary

  • nested — ownership in URL
  • shallow: true — short member paths
  • namespace — URL + module + helper
  • scope — pick which to change
