Sheet 67

Testing Jobs, Mailers & Time

assert_enqueued_with · perform_enqueued_jobs · ActionMailer::TestCase · assert_emails · travel_to · freeze_time

Side Effects Under Control

Rails' test helpers capture enqueued jobs and sent emails instead of running or delivering them, and let you travel in time. Assert that something was enqueued, run it inline when you need its effect, and freeze the clock to test expirations and schedules.

Notes

  • The test adapter queues jobs without running them
  • perform_enqueued_jobs { } runs jobs enqueued inside the block
  • Delivered mail collects in ActionMailer::Base.deliveries
  • Time helpers come from ActiveSupport::Testing::TimeHelpers (included by default)

Jobs

class SignupTest < ActiveSupport::TestCase
  include ActiveJob::TestHelper

  test "enqueues the welcome email job" do
    assert_enqueued_with(job: SendDigestJob, args: [users(:ann)], queue: "mailers") do
      users(:ann).request_digest!
    end
  end

  test "runs jobs" do
    perform_enqueued_jobs do
      users(:ann).request_digest!
    end
    assert_emails 1                   # delivered by the job
  end
end

Mailers

class UserMailerTest < ActionMailer::TestCase
  test "welcome" do
    mail = UserMailer.with(user: users(:ann)).welcome
    assert_equal ["ann@example.com"], mail.to
    assert_equal "Welcome, Ann!", mail.subject
    assert_match "Get started", mail.html_part.body.to_s
  end
end
# anywhere: assert_enqueued_email_with UserMailer, :welcome, params: { user: }

Time

test "reset token expires after 15 minutes" do
  token = users(:ann).generate_token_for(:password_reset)
  travel 16.minutes
  assert_nil User.find_by_token_for(:password_reset, token)
end

travel_to(Time.zone.local(2026, 12, 25, 9)) { assert Holiday.today? }

Code Explained

assert_enqueued_with — job class, args and queue
perform_enqueued_jobs — run them inline for end-to-end checks
mail.html_part.body — multipart content
assert_enqueued_email_with — deliver_later was called
travel / travel_to — shift the clock; reset after each test

The Rails Way

  • Stubbing Time.now by hand → travel_to / freeze_time
  • Asserting jobs by checking side effects only → assert_enqueued_with first, then a job unit test
  • Sending real mail in tests → the :test delivery method (default)

⚠ Common Mistakes

  • Testing a job only via perform_enqueued_jobs in a slow integration test; unit-test perform_now too
  • Calling Time.now in code under test; travel_to stubs it, but Time.current is the safer habit
  • Expecting assert_emails to see deliver_later mail without running jobs

✓ Tips & Best Practices

  • Test jobs directly: SendDigestJob.perform_now(users(:ann))
  • Use mailer previews for visual checks and tests for content
  • Freeze time in tests that format dates to avoid midnight flakes
