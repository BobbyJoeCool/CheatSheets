Translating the App

Rails' I18n API looks up strings by key in YAML files under config/locales. Views use t(".key") with lazy lookup scoped to the template path. Dates, numbers and validation messages are localized through the same files. The locale is set per request, usually from the URL, the user's setting or the Accept-Language header.

Notes

  • Keys are nested: en.posts.index.title
  • Missing translations show "translation missing" spans; raise instead in tests
  • Model and attribute names come from activerecord.models / .attributes
  • Add rails-i18n (gem) for date, number and error translations in many languages

config/locales/en.yml

en:
  hello: "Hello, %{name}!"
  posts:
    index:
      title: "All posts"
      count:
        zero: "No posts"
        one: "1 post"
        other: "%{count} posts"
  activerecord:
    models:
      post: "Article"
    attributes:
      post:
        title: "Headline"

Using Translations

<h1><%= t(".title") %></h1>                        <%# posts.index.title %>
<p><%= t(".count", count: @posts.size) %></p>
<p><%= t("hello", name: Current.user.name) %></p>
<p><%= l(@post.created_at, format: :short) %></p>
<%= link_to t(".new", default: "New post"), new_post_path %>

Setting the Locale

# config/application.rb
config.i18n.available_locales = %i[en es]
config.i18n.default_locale = :en
config.i18n.raise_on_missing_translations = true   # in test/development env files

class ApplicationController < ActionController::Base
  around_action :switch_locale
  def switch_locale(&action)
    locale = params[:locale] || Current.user&.locale || I18n.default_locale
    I18n.with_locale(locale, &action)
  end
  def default_url_options = { locale: I18n.locale }
end

Code Explained

%{name} — interpolation variable
zero/one/other — pluralization keys chosen by count:
t(".title") — lazy lookup from posts/index template path
Post.model_name.human / human_attribute_name — "Article", "Headline"
with_locale — set the locale for one request only

The Rails Way

  • Hard-coded English strings in views → t(".key")
  • I18n.locale = x in a before_action → around_action with I18n.with_locale
  • Custom date formatting → l(date, format:) with formats in YAML

⚠ Common Mistakes

  • Assigning I18n.locale globally in a threaded server, leaking locale between requests
  • Concatenating translated fragments; word order differs by language. Interpolate instead
  • Forgetting pluralization rules differ by language (some have few, many)

✓ Tips & Best Practices

  • Turn on raise_on_missing_translations in test so CI catches gaps
  • Run i18n-tasks missing before releases
  • Use _html keys only for trusted markup; interpolated values are still escaped
