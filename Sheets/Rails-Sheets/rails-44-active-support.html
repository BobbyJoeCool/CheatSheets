Rails' Additions to Ruby

Active Support extends Ruby's core classes and provides utilities used across Rails: blankness, time zones and durations, inflections, hash and array helpers, delegate, and caching and instrumentation APIs. Inside a Rails app all of it is loaded. The Ruby set's In Rails boxes mark which of these look like core Ruby but aren't.

Notes

  • Outside Rails: require "active_support/all" or pick files like active_support/core_ext/object/blank
  • Time.current respects config.time_zone; Time.now uses the server zone
  • Durations (3.days) are calendar-aware: months and DST are handled
  • Inflections are configurable in config/initializers/inflections.rb

Everyday Extensions

delegate

class Post < ApplicationRecord
  belongs_to :author
  delegate :name, to: :author, prefix: true, allow_nil: true   # post.author_name
end

Code Explained

presence — turns blank values into nil for || defaults
beginning_of_week / all_month — calendar helpers for ranges
to_fs — named formats (replaces to_formatted_s)
parameterize — URL-safe slugs
delegate ... prefix: true — author_name without Law of Demeter chains

The Rails Way

  • Time.now / Date.today in app code → Time.current / Date.current
  • if x.nil? || x == "" → x.blank?
  • Hand-written getters forwarding to another object → delegate

⚠ Common Mistakes

  • Using Time.now and Date.today, which ignore the app time zone and cause off-by-one-day bugs
  • Expecting ActiveSupport methods in a plain Ruby script without requiring them
  • Overusing try, which hides typos in method names; prefer &.

✓ Tips & Best Practices

  • Keep custom acronyms in inflections.rb (inflect.acronym "API")
  • See the Ruby set's In Rails boxes for core-vs-Rails comparisons
  • Use ActiveSupport::Duration values in config (config.x.trial = 14.days)
