What Rails Is

Ruby on Rails is a full-stack web framework written in Ruby, extracted from Basecamp by David Heinemeier Hansson in 2004. It follows MVC (models, views, controllers) and favors convention over configuration: name things the Rails way and most wiring happens for you. Rails 8 aims to be a One Person Framework: database-backed jobs, cache and websockets, auth, and deployment ship in the box.

Key Facts

  • Rails is a set of gems: activerecord, actionpack, actionview, activejob, actionmailer, activestorage, actioncable, activesupport and more
  • Omakase: the default stack is curated (SQLite, Propshaft, Importmap, Hotwire, Solid Queue, Kamal)
  • Current release line: 8.1 (8.1.4, Sept 2026). 8.2 is on edge
  • Files: .rb (Ruby), .html.erb (templates), .yml (config)

Hello, World in Rails

rails new hello && cd hello
bin/rails generate controller Pages home
bin/rails server            # http://localhost:3000/pages/home

app/controllers/pages_controller.rb

class PagesController < ApplicationController
  def home
    @greeting = "Hello, World"   # visible in the view
  end                            # implicit render: pages/home
end

app/views/pages/home.html.erb

<h1><%= @greeting %></h1>

Code Explained

rails new — generates a full app with sensible defaults
generate controller — controller, view, route and test in one step
@greeting — instance variables flow from controller to view
No render call needed: Rails renders pages/home.html.erb by convention
<%= %> — ERB output tag, HTML-escaped automatically

The Rails Way

  • Configuring table names and paths by hand → follow naming conventions (Post model ↔ posts table)
  • Adding a gem for every need → check the built-in framework first (jobs, cache, auth, storage)
  • Fighting the defaults on day one → ship with the omakase stack, swap pieces when you hit a real limit

⚠ Common Mistakes

  • Learning Rails before Ruby: blocks, symbols and hashes are everywhere, so confusion about Rails is often confusion about Ruby
  • Treating conventions as optional: a Person model with a people_table breaks every helper that guesses names
  • Following tutorials for Rails 5/6: Webpacker, Turbolinks and rails-ujs are gone from new apps

✓ Tips & Best Practices

  • Read the official Rails Guides for your exact version; they are versioned at guides.rubyonrails.org
  • Run bin/rails about to see the Rails, Ruby and gem versions an app actually uses
  • Each minor release gets about 1 year of bug fixes and 2 of security fixes; plan upgrades accordingly
