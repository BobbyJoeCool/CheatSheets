Custom Helpers & View Components

app/helpers · helper modules · capture · safe_join · tag builder · ViewComponent · Phlex

Your Own View Building Blocks

Helpers are modules in app/helpers whose methods every view can call. They suit small formatting and markup snippets. For larger reusable UI with logic and tests, many apps use components: Ruby classes paired with templates (ViewComponent) or written fully in Ruby (Phlex).

Notes

  • All helpers are included in all views by default (config.action_controller.include_all_helpers)
  • Build HTML in helpers with tag and safe_join, never string concatenation
  • capture turns a block of ERB into a string
  • Components are gems: view_component (GitHub) and phlex-rails

app/helpers/application_helper.rb

module ApplicationHelper
  def status_badge(post)
    css = post.published? ? "badge-green" : "badge-gray"
    tag.span(post.status.humanize, class: ["badge", css])
  end

  def nav_link(text, path)
    link_to text, path, class: ["nav", { active: current_page?(path) }]
  end

  def card(title, &block)
    tag.div(class: "card") do
      safe_join([tag.h3(title), capture(&block)])
    end
  end
end

ViewComponent

class AlertComponent < ViewComponent::Base
  def initialize(type: :info)
    @type = type
  end

  def call = tag.div(content, class: "alert alert-#{@type}")
end
# view: <%= render AlertComponent.new(type: :error) do %>Oops<% end %>

Code Explained

tag.span(..., class: [...]) — escaped, attribute-safe HTML
current_page? — highlight the active nav link
capture(&block) — render the caller's ERB block to a string
safe_join — join escaped and safe strings without .html_safe
content — the block passed to a ViewComponent

The Rails Way

  • "<span class='#{css}'>#{text}</span>".html_safe → tag.span(text, class: css)
  • Helpers that query the database → pass data in from the controller
  • A 200-line partial with logic → a component with its own test

Helpers vs Partials vs Components

ToolBest For
HelperSmall formatting, one-liners
PartialMarkup reused with simple locals
ViewComponentUI with logic, slots, unit tests
PhlexViews written in pure Ruby
Presenter / decoratorModel-specific display logic

⚠ Common Mistakes

  • Building HTML by concatenating strings and calling .html_safe, which reintroduces XSS
  • One giant ApplicationHelper; split by domain (PostsHelper, MoneyHelper)
  • Calling helpers from models; use a presenter or pass formatted values instead

✓ Tips & Best Practices

  • Test helpers with ActionView::TestCase (assert_dom_equal)
  • Use ViewComponent previews to build a component gallery for design review
  • Use class_names (alias token_list) for conditional CSS classes in plain ERB
