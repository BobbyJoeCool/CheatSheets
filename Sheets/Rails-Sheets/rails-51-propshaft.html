Propshaft & Asset Delivery

Propshaft · app/assets · stylesheet_link_tag · asset_path · digests · assets:precompile · Sprockets (legacy)

Serving CSS, Images and Fonts

Rails 8 uses Propshaft, a simple asset pipeline: it doesn't compile or bundle, it just adds a content digest to each file name so browsers can cache forever, and rewrites url() references in CSS. Modern CSS and import maps cover what Sprockets used to compile.

Notes

  • Load paths: app/assets/*, vendor/assets, and gem assets
  • Digested files: app-3f2e9a1c.css; Rails helpers map names to them
  • Production: bin/rails assets:precompile writes to public/assets
  • Tailwind / Sass / esbuild output goes into app/assets/builds for Propshaft to serve

Layout & Views

<%= stylesheet_link_tag :app, "data-turbo-track": "reload" %>   <%# all in app/assets/stylesheets %>
<%= stylesheet_link_tag "admin" %>
<%= image_tag "logo.svg", alt: "Logo" %>
<%= favicon_link_tag "favicon.ico" %>
<link rel="preload" href="<%= asset_path("inter.woff2") %>" as="font" crossorigin>

CSS

/* app/assets/stylesheets/application.css */
@import url("buttons.css");
.hero { background: url("hero.jpg"); }   /* rewritten to /assets/hero-ab12.jpg */

Commands & Config

bin/rails assets:precompile     # digest into public/assets
bin/rails assets:clobber        # remove compiled assets
bin/rails assets:reveal         # list logical paths
bin/rails assets:reveal:full    # with full paths

config/initializers/assets.rb

Rails.application.config.assets.paths << Rails.root.join("node_modules/@fontsource")
Rails.application.config.assets.excluded_paths << Rails.root.join("app/assets/stylesheets/src")

Code Explained

:app — every stylesheet in app/assets/stylesheets, in order
data-turbo-track: reload — full reload when assets change after deploy
asset_path — digested URL for any asset
CSS url() — Propshaft rewrites to digested paths
excluded_paths — keep source files out of the load path

The Rails Way

  • Sprockets //= require directives → native CSS @import or a CSS bundler
  • Hard-coded /images/logo.png → image_tag "logo.png"
  • Committing public/assets → precompile in the Docker build

Propshaft vs Sprockets

Propshaft · Sprockets
Default inRails 8 · Rails ≤ 7
Compiles Sass/CoffeeScriptno (use bundlers) · yes
Digests + cachingyes · yes
Manifest directivesnone · //= require
Speed / complexityfast, tiny · slower, larger

⚠ Common Mistakes

  • Referencing assets with relative ../images paths in ERB; use helpers so digests apply
  • Forgetting to precompile in production and getting 404s for /assets/*
  • Mixing Sprockets and Propshaft gems in one app

✓ Tips & Best Practices

  • Use bin/rails assets:reveal to debug "asset not found" errors
  • Thruster adds far-future caching and compression for /assets in Rails 8 containers
  • For Tailwind, tailwindcss-rails builds into app/assets/builds/tailwind.css

Quick Summary

  • Propshaft — digest, don't compile
  • stylesheet_link_tag :app — all styles
  • asset_path — digested URL
  • assets:precompile — production build
