Sheet 03

First App & Project Layout

app = FastAPI() · @app.get · title · version · app/main.py · __init__.py

Description

A FastAPI app is one FastAPI() object plus functions decorated with HTTP methods. Small projects fit in main.py; anything bigger moves into an app/ package with routers, models and settings split into modules. Pass metadata to FastAPI() so the docs show a real title, version and description.

Notes

  • Return dicts, lists, Pydantic models or Response objects
  • Functions run in order of registration when paths overlap
  • app/__init__.py makes app an importable package
  • Run a package app with fastapi dev app/main.py

app/main.py

from fastapi import FastAPI
from app.routers import todos, users     # split by feature

app = FastAPI(
    title="Todo API",
    version="1.2.0",
    description="Tracks **todos** for each user.",
    contact={"name": "Bob", "url": "https://example.com"},
)

app.include_router(todos.router)          # sheet 25
app.include_router(users.router)

@app.get("/health", tags=["ops"])
def health():
    return {"status": "ok"}

Code Explained

title / version / description — shown at the top of /docs
description accepts Markdown
include_router — mounts routes from another module
tags=[...] — groups operations in the docs
/health — cheap endpoint for load balancers

Other Framework

  • Flask — create_app() factory + blueprints (sheet 51)
  • Django — one project with many apps (startapp)

Prefer / Avoid

  • Avoid one 2,000-line main.py · Prefer routers per feature
  • Avoid circular imports via from main import app · Prefer routers that never import app

Typical Layout

⚠ Common Mistakes

  • Naming the file fastapi.py: it shadows the real package
  • Importing app inside routers, causing circular imports
  • Defining /users/me after /users/{id}: the param route wins

✓ Tips & Best Practices

  • Keep schemas (API shapes) separate from DB models
  • Add /health early; deploy tools expect it
  • Use tags on routers so /docs stays organized

Quick Summary

  • FastAPI(title=, version=) — app + docs metadata
  • app/ package — routers, schemas, models, deps
  • include_router() — compose the app
  • registration order — decides overlapping matches
