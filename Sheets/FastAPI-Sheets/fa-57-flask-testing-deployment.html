Sheet 57

Testing & Deploying Flask

app.test_client() · test_cli_runner() · TESTING=True · pytest fixtures · Gunicorn · Waitress · ProxyFix

Description

Test Flask apps with the built-in test client and pytest fixtures that build the app through create_app() with test config. Deploy with a production WSGI server: Gunicorn on Linux, Waitress on Windows, behind Nginx. Add ProxyFix so Flask trusts the proxy's forwarded headers.

Notes

  • TESTING=True propagates exceptions to the test
  • Disable CSRF in tests: WTF_CSRF_ENABLED=False
  • Gunicorn workers ≈ 2 × cores + 1 for sync workers
  • Never deploy with flask run

tests/conftest.py + test

import pytest
from myapp import create_app
from myapp.extensions import db

@pytest.fixture
def app():
    app = create_app({"TESTING": True, "WTF_CSRF_ENABLED": False,
                      "SQLALCHEMY_DATABASE_URI": "sqlite:///:memory:"})
    with app.app_context():
        db.create_all()
        yield app

@pytest.fixture
def client(app):
    return app.test_client()

def test_create_todo(client):
    r = client.post("/todos", json={"title": "Buy milk"})
    assert r.status_code == 201
    assert r.get_json()["title"] == "Buy milk"

Code Explained

create_app({...}) — test config per run
app.app_context() — DB setup inside context
app.test_client() — fake requests
r.get_json() — parsed JSON
"myapp:create_app()" — Gunicorn calls the factory

Other Framework

  • Django — TestCase client; Gunicorn + collectstatic

Prefer / Avoid

  • Avoid testing against the dev database · Prefer an isolated test DB
  • Avoid app.run(debug=True) on servers · Prefer Gunicorn/Waitress

⚠ Common Mistakes

  • Tests sharing state through a module-level app
  • Forgetting ProxyFix: url_for(_external=True) builds http:// links
  • Running Gunicorn as root on port 80 instead of behind Nginx

✓ Tips & Best Practices

  • Use app.test_cli_runner() to test custom flask commands
  • Run Gunicorn under systemd (see the Ubuntu set)
  • Serve static/ from Nginx in production

Quick Summary

  • create_app(test_config) — isolated tests
  • test_client() — fake requests
  • Gunicorn / Waitress — production servers
  • ProxyFix — trust proxy headers
