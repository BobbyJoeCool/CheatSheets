Flask-SQLAlchemy & Flask-Migrate

SQLAlchemy(model_class=Base) · db.session · db.select · db.get_or_404 · flask db init / migrate / upgrade

Description

Flask-SQLAlchemy wires SQLAlchemy into Flask: one db object, a session scoped to each request, and helpers like get_or_404() and paginate(). Models use normal SQLAlchemy 2.0 syntax. Flask-Migrate wraps Alembic as flask db commands.

Notes

  • pip install flask-sqlalchemy flask-migrate
  • Config key: SQLALCHEMY_DATABASE_URI
  • Session is removed automatically at request end
  • Relative SQLite paths resolve in instance/

Models + Queries

from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

class Base(DeclarativeBase): pass
db = SQLAlchemy(model_class=Base)
migrate = Migrate()
class Todo(db.Model):
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(db.String(100))
    done: Mapped[bool] = mapped_column(default=False)

@bp.get("/todos")
def list_todos():
    page = db.paginate(db.select(Todo), per_page=20)
    return {"items": [t.title for t in page.items]}

@bp.get("/todos/<int:id>")
def show(id):
    todo = db.get_or_404(Todo, id)
    return {"id": todo.id, "title": todo.title}

Flask-Migrate

flask db init                     # once: migrations/ folder
flask db migrate -m "add todos"   # autogenerate
flask db upgrade                  # apply

Code Explained

SQLAlchemy(model_class=Base) — 2.0-style models
db.Model — table name from class name (todo)
db.paginate(select) — page object with .items
db.get_or_404() — fetch or 404
flask db — Alembic via the Flask CLI

Other Framework

  • FastAPI — plain SQLAlchemy/SQLModel + yield session dependency (sheets 23, 28)
  • Django — built-in ORM + makemigrations

Prefer / Avoid

  • Avoid legacy Todo.query.filter_by() · Prefer db.session.execute(db.select(...))
  • Avoid db.create_all() once you have users · Prefer migrations

⚠ Common Mistakes

  • Forgetting migrate.init_app(app, db) in the factory: flask db can't find models
  • Models not imported anywhere: autogenerate sees no tables
  • Long-lived objects used after the request's session closed

✓ Tips & Best Practices

  • Import models in create_app() so migrations detect them
  • Turn on SQLALCHEMY_ECHO = True while debugging queries
  • Review migration files before upgrade

Quick Summary

  • db = SQLAlchemy() — Flask-integrated ORM
  • db.Model + Mapped[...] — models
  • get_or_404 / paginate — view helpers
  • flask db — Alembic migrations
