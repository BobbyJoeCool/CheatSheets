Sheet 41

Overrides & Async Tests

dependency_overrides · test database · httpx.AsyncClient + ASGITransport · pytest.mark.anyio · auth in tests

Description

app.dependency_overrides swaps real dependencies (DB session, current user, settings) for test versions without touching app code. When tests themselves must be async (to call async helpers or share an event loop with an async DB), use httpx.AsyncClient with ASGITransport and mark tests with anyio.

Notes

  • Override the exact callable used in Depends()
  • A SQLite file or in-memory DB per test run keeps tests isolated
  • ASGITransport does not run lifespan; use asgi-lifespan if needed
  • anyio comes with FastAPI; pytest-asyncio also works

conftest.py

import pytest
from httpx import ASGITransport, AsyncClient
from sqlmodel import Session, SQLModel, create_engine
from sqlmodel.pool import StaticPool
@pytest.fixture
def session():
    engine = create_engine("sqlite://", poolclass=StaticPool,
                connect_args={"check_same_thread": False})
    SQLModel.metadata.create_all(engine)
    with Session(engine) as s: yield s

@pytest.fixture
def client(session):
    app.dependency_overrides[get_db] = lambda: session
    app.dependency_overrides[get_current_user] = lambda: User(id=1)
    with TestClient(app) as c:
        yield c
    app.dependency_overrides.clear()

@pytest.mark.anyio
async def test_async():
    t = ASGITransport(app=app)
    async with AsyncClient(transport=t, base_url="http://t") as ac:
        r = await ac.get("/health")
    assert r.status_code == 200

Code Explained

sqlite:// + StaticPool — one shared in-memory DB
dependency_overrides[get_db] — tests use that session
fake get_current_user — skip real auth
ASGITransport — async client against the app

Other Framework

  • Flask — app.config["TESTING"] = True + a test DB URI
  • Django — test DB created automatically per run

Prefer / Avoid

  • Avoid patching modules with mock.patch · Prefer dependency_overrides
  • Avoid async tests unless needed · Prefer TestClient + sync tests

⚠ Common Mistakes

  • Overriding a function with a different signature than the one in Depends()
  • In-memory SQLite without StaticPool: each connection gets an empty DB
  • Mixing pytest-asyncio and anyio markers in one suite

✓ Tips & Best Practices

  • Add anyio_backend fixture returning "asyncio" to skip trio runs
  • Use factories (make_user()) for test data
  • Run tests in CI against the real DB engine too

Quick Summary

  • dependency_overrides — swap dependencies
  • in-memory DB + StaticPool — isolated tests
  • AsyncClient + ASGITransport — async tests
  • clear overrides after each test
