Routing & URL Building

@app.route · @app.get / @app.post · <int:id> converters · methods=[…] · url_for() · redirect() · trailing slashes

Description

Flask maps URLs to view functions with @app.route (or method shortcuts). Converters like <int:id> parse path parts. Build URLs with url_for(), which uses the function name (the endpoint), so changing a path never breaks links. Trailing slashes matter: they decide redirect vs 404.

Notes

  • Default methods are GET (plus HEAD, OPTIONS)
  • Endpoint name defaults to the function name
  • /todos/ with slash: /todos redirects to it
  • /todos without slash: /todos/ is a 404

Routes & URLs

from flask import Flask, redirect, url_for, abort

app = Flask(__name__)

@app.route("/todos", methods=["GET", "POST"])
def todos():
    ...

@app.get("/todos/<int:todo_id>")
def show_todo(todo_id):
    ...

@app.get("/files/<path:name>")
def files(name): ...                       # "a/b/c.txt"

@app.get("/go/<slug>")
def go(slug):
    return redirect(url_for("show_todo", todo_id=7))   # → /todos/7

with app.test_request_context():
    url_for("todos")                        # '/todos'
    url_for("todos", page=2)                # '/todos?page=2'
    url_for("static", filename="app.css")   # '/static/app.css'
    url_for("show_todo", todo_id=3, _external=True)

Code Explained

methods=[...] — allow several methods on one view
<int:todo_id> — converted to int, else 404
url_for("show_todo", todo_id=7) — build by endpoint
extra kwargs → query string
_external=True — absolute URL

Other Framework

  • FastAPI — {todo_id} + type hint; request.url_for("name", ...)
  • Django — <int:pk> + reverse("name", args=[...])

Prefer / Avoid

  • Avoid hard-coded URLs in templates · Prefer url_for()
  • Avoid one view with if request.method == branches · Prefer @app.get / @app.post

⚠ Common Mistakes

  • Two views with the same function name: "View function mapping is overwriting" error
  • Inconsistent trailing slashes causing surprise 404s
  • Calling url_for outside a request or app context

✓ Tips & Best Practices

  • flask --app app routes lists every route and endpoint
  • Use endpoint= to name views explicitly when needed
  • Blueprint endpoints are prefixed: url_for("todos.show")

Quick Summary

  • @app.route / @app.get — map URLs
  • converters — typed path parts
  • url_for(endpoint) — never hard-code URLs
  • trailing slash — redirect vs 404
