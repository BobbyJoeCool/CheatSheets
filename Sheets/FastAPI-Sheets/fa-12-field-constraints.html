Sheet 12

Field & Constraints

Field(gt=0, max_length=…) · default_factory · examples= · EmailStr · HttpUrl · Annotated

Description

Field() adds constraints, defaults and docs to a model field, the same way Query() does for parameters. Pydantic also ships ready-made types such as EmailStr, HttpUrl, PositiveInt and SecretStr. Constraints can live in Field() or inside Annotated[...], which lets you build reusable constrained types.

Notes

  • EmailStr needs email-validator (in fastapi[standard])
  • default_factory runs per instance (lists, UUIDs, timestamps)
  • examples=[...] pre-fills "Try it out" in /docs
  • SecretStr hides the value in reprs and logs

Constrained Model

from datetime import datetime, timezone
from decimal import Decimal
from typing import Annotated
from uuid import UUID, uuid4
from pydantic import (BaseModel, Field, EmailStr,
                      HttpUrl, SecretStr)

Title = Annotated[str, Field(min_length=1, max_length=100)]

class SignUp(BaseModel):
    id: UUID = Field(default_factory=uuid4)
    email: EmailStr
    password: SecretStr = Field(min_length=12)
    name: Title
    age: int = Field(ge=13, le=120)
    website: HttpUrl | None = None
    balance: Decimal = Field(0, max_digits=10, decimal_places=2)
    tags: list[str] = Field(default_factory=list, max_length=5)
    joined: datetime = Field(
        default_factory=lambda: datetime.now(timezone.utc))

    model_config = {"json_schema_extra": {"examples": [{
        "email": "bob@example.com", "password": "horse-battery",
        "name": "Bob", "age": 40}]}}

Code Explained

Title — reusable constrained string
default_factory=uuid4 — new ID per instance
SecretStr — use .get_secret_value() to read
max_length on a list — max items
json_schema_extra examples — shown in /docs

Other Framework

  • Flask — WTForms validators: Length, Email, NumberRange (sheet 50)
  • Django — max_length, validators=[...] on model/form fields

Prefer / Avoid

  • Avoid default=datetime.now() (evaluated once) · Prefer default_factory
  • Avoid float for money · Prefer Decimal with decimal_places

⚠ Common Mistakes

  • created: datetime = datetime.now(): every instance shares the import-time value
  • Logging a SecretStr with .get_secret_value() defeats the point
  • Forgetting email-validator when installing plain fastapi

✓ Tips & Best Practices

  • Put shared Annotated types in one module (types.py)
  • Use alias + populate_by_name for camelCase APIs (sheet 16)
  • Keep examples realistic; they double as documentation

Quick Summary

  • Field() — constraints, defaults, docs
  • default_factory — per-instance defaults
  • EmailStr, HttpUrl, SecretStr — ready-made types
  • Annotated — reusable constrained types
