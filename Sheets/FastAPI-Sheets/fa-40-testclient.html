TestClient Basics

from fastapi.testclient import TestClient · client.get() / post(json=) · status_code / .json() · fixtures · lifespan

Description

TestClient calls your app in-process with an httpx-style API, so tests are fast and need no running server. Write normal pytest functions that make requests and assert on status_code and json(). Use it as a context manager (with TestClient(app)) when you need lifespan startup and shutdown to run.

Notes

  • Test functions can be plain def, even for async routes
  • TestClient needs httpx (in fastapi[standard])
  • Run with pytest from the project root
  • See the pytest set for fixtures and parametrize

tests/test_todos.py

import pytest
from fastapi.testclient import TestClient
from app.main import app

@pytest.fixture
def client():
    with TestClient(app) as c:              # runs lifespan
        yield c

def test_create_and_get(client):
    r = client.post("/todos", json={"title": "Buy milk"})
    assert r.status_code == 201
    todo = r.json()
    assert todo["title"] == "Buy milk"

    r = client.get(f"/todos/{todo['id']}")
    assert r.status_code == 200
    assert r.json() == todo

def test_validation(client):
    r = client.post("/todos", json={})
    assert r.status_code == 422
    assert r.json()["detail"][0]["loc"] == ["body", "title"]

Code Explained

with TestClient(app) — starts and stops lifespan
fixture — one client per test
post(json=...) — sends JSON body
r.json() — parsed response
422 test — pins the error shape

Other Framework

Prefer / Avoid

  • Avoid starting a real server for tests · Prefer TestClient
  • Avoid one giant test · Prefer one behavior per test

⚠ Common Mistakes

  • Plain TestClient(app) with lifespan-created resources: startup never ran
  • Tests sharing a real database and depending on order
  • Asserting on whole error messages that change between versions

✓ Tips & Best Practices

  • Put the client fixture in tests/conftest.py
  • Use pytest -x -q for quick feedback
  • Use client.headers.update(...) for auth on every request

Quick Summary

  • TestClient(app) — in-process requests
  • with — run lifespan
  • assert status_code + json()
  • pytest fixtures — reusable setup
