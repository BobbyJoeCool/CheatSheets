WebSockets

@app.websocket · await ws.accept() · receive_text / send_json · WebSocketDisconnect · connection manager

Description

WebSockets keep a two-way connection open for real-time features like chat, live dashboards and notifications. Declare an endpoint with @app.websocket, accept() the connection, then loop on receive_* and send_*. A disconnect raises WebSocketDisconnect, which you catch to clean up.

Notes

  • URL scheme is ws:// or wss:// (TLS)
  • Dependencies, path and query params work on websockets
  • Multiple workers don't share connections; use Redis pub/sub
  • TestClient.websocket_connect() tests them

Chat Room

from fastapi import WebSocket, WebSocketDisconnect

class Manager:
    def __init__(self):
        self.active: list[WebSocket] = []
    async def connect(self, ws: WebSocket):
        await ws.accept()
        self.active.append(ws)
    def disconnect(self, ws: WebSocket):
        self.active.remove(ws)
    async def broadcast(self, msg: dict):
        for ws in self.active:
            await ws.send_json(msg)

manager = Manager()

@app.websocket("/ws/{room}")
async def chat(ws: WebSocket, room: str, name: str = "anon"):
    await manager.connect(ws)
    try:
        while True:
            text = await ws.receive_text()
            await manager.broadcast(
                {"room": room, "from": name, "text": text})
    except WebSocketDisconnect:
        manager.disconnect(ws)

Code Explained

@app.websocket(path) — websocket route
await ws.accept() — complete the handshake
receive_text() — waits for the next message
send_json() — send a dict as JSON
WebSocketDisconnect — client left

Other Framework

  • Flask — no native support; Flask-SocketIO or Flask-Sock
  • Django — Django Channels with consumers

Prefer / Avoid

  • Avoid an in-memory manager with many workers · Prefer Redis pub/sub broadcast
  • Avoid unauthenticated sockets · Prefer a token in query or first message

⚠ Common Mistakes

  • Forgetting accept(): the client sees an immediate close
  • Raising HTTPException in a websocket; use WebSocketException or close()
  • Broadcasting while iterating a list that a disconnect modifies

✓ Tips & Best Practices

  • Send heartbeats (ping) to keep proxies from closing idle sockets
  • Configure Nginx with Upgrade / Connection headers (sheet 45)
  • Prefer SSE (sheet 39) when data only flows server → client
