Middleware & CORS

@app.middleware("http") · call_next · CORSMiddleware · allow_origins · GZipMiddleware · TrustedHostMiddleware

Description

Middleware wraps every request and response: it can time requests, add headers, or reject traffic before routes run. Write one with @app.middleware("http") or add a class with app.add_middleware(). CORS middleware is what lets a browser app on another origin call your API.

Notes

  • Last added = outermost = runs first
  • Middleware sees all routes, including 404s
  • CORS is enforced by browsers, not servers or curl
  • Exceptions in routes reach middleware as 500 responses

Under the Hood

  • Stack: ServerErrorMiddleware outermost, ExceptionMiddleware innermost
  • @app.middleware uses BaseHTTPMiddleware; pure ASGI middleware is faster
  • Preflight OPTIONS requests are answered by CORSMiddleware itself

Timing Header + CORS

import time
from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()
@app.middleware("http")
async def add_timing(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)          # run the route
    ms = (time.perf_counter() - start) * 1000
    response.headers["Server-Timing"] = f"app;dur={ms:.1f}"
    return response

app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://app.example.com", "http://localhost:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

Code Explained

call_next(request) — passes control inward
code after call_next — edits the response
allow_origins — exact origins, scheme + host + port

Other Framework

  • Flask — flask-cors and before_request / after_request hooks
  • Django — MIDDLEWARE list + django-cors-headers

Prefer / Avoid

  • Avoid allow_origins=["*"] with credentials · Prefer an explicit list
  • Avoid auth checks in middleware · Prefer dependencies (per route, testable)

⚠ Common Mistakes

  • allow_origins=["*"] + allow_credentials=True: browsers reject it
  • Trailing slash in an origin (https://app.com/): never matches
  • Reading await request.body() in BaseHTTPMiddleware and breaking streaming

✓ Tips & Best Practices

  • Add CORS last so it wraps everything, including errors
  • Use TrustedHostMiddleware in production
  • Put request IDs in middleware and in log context

Quick Summary

  • @app.middleware("http") — wrap every request
  • add_middleware() — add built-in classes
  • CORSMiddleware — browser cross-origin access
  • last added — runs first
