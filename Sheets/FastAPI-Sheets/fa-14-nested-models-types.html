Nested Models & Special Types

nested models · list[Item] · dict[str, int] · Literal · datetime / UUID / Decimal · discriminated unions

Description

Fields can be other models, lists and dicts of models, or special types. Pydantic validates the whole tree and reports errors with a full location path like items.2.price. Literal restricts a field to exact values, and a discriminated union picks the right model from a tag field such as type.

Notes

  • Nested errors show the path: ["body", "items", 2, "price"]
  • dict[str, int] validates keys and values
  • Literal["a", "b"] is a lightweight Enum
  • Field(discriminator="type") makes unions fast and clear

An Order with Line Items

from datetime import datetime
from decimal import Decimal
from typing import Annotated, Literal
from pydantic import BaseModel, Field

class Address(BaseModel):
    city: str
    zip: str = Field(pattern=r"^\d{5}$")

class LineItem(BaseModel):
    sku: str
    qty: int = Field(gt=0)
    price: Decimal

class Card(BaseModel):   type: Literal["card"];   last4: str
class PayPal(BaseModel): type: Literal["paypal"]; email: str

class Order(BaseModel):
    ship_to: Address
    items: list[LineItem] = Field(min_length=1)
    payment: Annotated[Card | PayPal, Field(discriminator="type")]
    meta: dict[str, str] = {}
    placed: datetime

Code Explained

ship_to: Address — nested object
list[LineItem] + min_length=1 — at least one item
Literal["card"] — exact value only
discriminator="type" — choose model by type
datetime — accepts ISO 8601 strings

Other Framework

  • Flask — nested JSON is plain dicts unless you add a schema library
  • Django — DRF nested serializers (many=True)

Prefer / Avoid

  • Avoid dict for structured data · Prefer a nested model
  • Avoid untagged A | B unions · Prefer a discriminator field

⚠ Common Mistakes

  • Untagged unions match the first model that fits: wrong type silently chosen
  • float prices: 0.1 + 0.2 problems; use Decimal
  • Naive datetime values: store and return timezone-aware UTC

✓ Tips & Best Practices

  • Reuse nested models across In/Out schemas
  • Let the error loc path drive form-field highlighting on the client
  • Use set[str] for tags to dedupe automatically

Quick Summary

  • nested model — field typed as another model
  • list[Model] — arrays of objects
  • Literal — exact allowed values
  • discriminated union — tag picks the model
