Flask Introduction & First App

micro-framework · WSGI · Werkzeug · Jinja2 · pip install flask · Flask(__name__) · flask run --debug

Description

Flask is a small, mature WSGI framework from the Pallets project. It gives you routing, a request object, templates (Jinja2) and a dev server, and leaves the database, forms and auth to extensions you pick. That makes it quick to learn and flexible, at the cost of making more choices yourself than in Django or FastAPI.

Notes

  • Released 2010 by Armin Ronacher; current major is Flask 3.x
  • Built on Werkzeug (WSGI toolkit) and Jinja2
  • Return a dict or list from a view → JSON
  • --debug enables reload and the interactive debugger

Under the Hood

  • Werkzeug parses the WSGI environ into a Request object
  • Flask pushes app + request contexts so request works as a global (sheet 52)
  • The dev server is Werkzeug's: never use it in production

app.py

from flask import Flask, request

app = Flask(__name__)                 # __name__ locates templates/static

@app.get("/")
def index():
    return "<h1>Hello, Flask</h1>"     # str → HTML

@app.get("/todos/<int:todo_id>")
def get_todo(todo_id: int):
    done = request.args.get("done", default=False, type=bool)
    return {"id": todo_id, "done": done}   # dict → JSON

@app.post("/todos")
def create_todo():
    data = request.get_json()
    return {"title": data["title"]}, 201

Run It

pip install flask
flask --app app run --debug          # http://127.0.0.1:5000

Code Explained

Flask(__name__) — app object; finds templates/ and static/
@app.get — route shortcut (Flask 2.0+)
request.args.get(..., type=) — query param
return (body, 201) — body plus status

Other Framework

  • FastAPI — typed params replace request.args / get_json() (sheet 01)
  • Django — project + app, URLconf, views

Prefer / Avoid

  • Avoid app.run() in production · Prefer Gunicorn (sheet 57)
  • Avoid FLASK_ENV (removed) · Prefer --debug or FLASK_DEBUG=1

⚠ Common Mistakes

  • Naming the file flask.py: shadows the package
  • Leaving --debug on a public server: the debugger allows code execution
  • Using request outside a request: "Working outside of request context"

✓ Tips & Best Practices

  • Use @app.get / @app.post shortcuts for clarity
  • Put settings in a .flaskenv file (needs python-dotenv)
  • Move to the app factory early (sheet 51)

Quick Summary

  • Flask(__name__) — WSGI app
  • @app.get(path) — routes
  • dict return — JSON
  • flask --app app run --debug — dev server
