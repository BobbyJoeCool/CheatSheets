Sheet 29

SQLAlchemy 2.0

DeclarativeBase · Mapped[int] · mapped_column · sessionmaker · session.execute(select()) · relationship()

Description

SQLAlchemy 2.0 is the standard Python ORM and works with FastAPI directly. Models use typed Mapped[...] annotations, queries use select(), and sessions come from a sessionmaker. Keep ORM models separate from Pydantic schemas and convert with from_attributes=True.

Notes

  • pip install sqlalchemy (+ a driver like psycopg)
  • 2.0 style: select() everywhere, no session.query()
  • Mapped[str | None] → nullable column
  • expire_on_commit=False keeps objects usable after commit

Models, Session, Query

from sqlalchemy import ForeignKey, String, create_engine, select
from sqlalchemy.orm import (DeclarativeBase, Mapped, mapped_column,
                            relationship, sessionmaker)

class Base(DeclarativeBase): pass

class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(String(255), unique=True)
    todos: Mapped[list["Todo"]] = relationship(back_populates="owner")

class Todo(Base):
    __tablename__ = "todos"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(100))
    owner_id: Mapped[int] = mapped_column(ForeignKey("users.id"))
    owner: Mapped[User] = relationship(back_populates="todos")

engine = create_engine("postgresql+psycopg://app@localhost/app")
SessionLocal = sessionmaker(engine, expire_on_commit=False)

def todos_for(db, user_id: int) -> list[Todo]:
    return db.scalars(select(Todo).where(Todo.owner_id == user_id)).all()

Code Explained

DeclarativeBase — base class for models
Mapped[int] + mapped_column() — typed column
relationship(back_populates=) — two-way link
sessionmaker(engine) — session factory
db.scalars(select(...)) — ORM objects, not rows

Other Framework

  • Flask — Flask-SQLAlchemy wraps the same models (sheet 54)
  • Django — Django ORM: Todo.objects.filter(owner_id=...)

Prefer / Avoid

  • Avoid legacy session.query(Todo) · Prefer select(Todo)
  • Avoid lazy-loading in loops (N+1) · Prefer selectinload(User.todos)

⚠ Common Mistakes

  • Returning ORM objects whose lazy relationships load after the session closed
  • Forgetting String(n) length on MySQL
  • Creating a new engine per request instead of one per app

✓ Tips & Best Practices

  • Use a yield dependency for sessions (sheet 23)
  • Turn on echo=True on the engine to see SQL while learning
  • See the SQL set for joins and indexes
