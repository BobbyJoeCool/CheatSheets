Sheet 09

Validation with Query, Path & Annotated

Annotated[int, Path(ge=1)] · Query(max_length=50) · pattern= · alias= · deprecated=True

Description

Query(), Path(), Header() and friends add validation and docs metadata to a parameter. Put them inside Annotated[...] so the real type stays visible and defaults stay normal Python defaults. Numeric bounds, string lengths, regex patterns, aliases and deprecation all live here.

Notes

  • Annotated style is the recommended one
  • Old style q: str = Query(None) still works
  • A Pydantic model with Annotated[M, Query()] groups query params
  • Errors still come back as 422 with the failed rule

Constrained Parameters

from typing import Annotated
from pydantic import BaseModel, Field
from fastapi import FastAPI, Path, Query

app = FastAPI()
TodoId = Annotated[int, Path(ge=1, title="Todo ID")]   # reusable

@app.get("/todos/{todo_id}")
def get_todo(todo_id: TodoId): ...

@app.get("/search")
def search(
    q: Annotated[str, Query(min_length=2, max_length=50)],
    sort: Annotated[str, Query(pattern="^(asc|desc)$")] = "asc",
    page_size: Annotated[int, Query(alias="page-size", le=100)] = 20,
    old: Annotated[str | None, Query(deprecated=True)] = None,
): ...

class Filters(BaseModel):
    model_config = {"extra": "forbid"}   # reject unknown params
    limit: int = Field(20, gt=0, le=100)
    tags: list[str] = []

@app.get("/todos")
def list_todos(f: Annotated[Filters, Query()]): ...

Code Explained

Path(ge=1) — 0 or negatives → 422
TodoId alias — reuse the same rules on many routes
pattern= — regex the value must match
alias="page-size" — URL name differs from Python name
Query model — one object for many filters

Other Framework

  • Flask — validate manually or with Marshmallow / Pydantic
  • Django — forms or DRF serializers validate query data

Prefer / Avoid

  • Avoid q: str = Query(None) · Prefer Annotated[str | None, Query()] = None
  • Avoid repeating the same Path(ge=1) · Prefer a type alias

⚠ Common Mistakes

  • Using regex=: renamed to pattern= in current versions
  • Putting a default inside Query(...) and also after =: pick one (after = with Annotated)
  • Forgetting alias makes Python-style names show in URLs

✓ Tips & Best Practices

  • Define Annotated aliases in deps.py and reuse them
  • Use extra="forbid" on query models to catch typos
  • Keep max page sizes server-side, not just in the client

Quick Summary

  • Annotated[T, Query(...)] — validated query param
  • Path(ge=1) — bounded path param
  • pattern, min_length — string rules
  • query model — grouped filters
