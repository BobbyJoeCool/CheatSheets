Depends Basics

Depends() · Annotated[T, Depends(fn)] · shared params · type aliases · per-request cache

Description

Dependency injection lets a path operation declare "I need X" and have FastAPI build X for it. A dependency is any callable; its parameters are resolved exactly like a route's (path, query, body, other dependencies). Use it for shared query params, DB sessions, the current user, settings, and permission checks.

Notes

  • Dependencies can be def or async def
  • Their params appear in /docs as if on the route
  • Same dependency used twice in one request runs once
  • Wrap in an Annotated alias to reuse with one name

Under the Hood

  • FastAPI builds a dependency tree per route at startup
  • Per request it solves the tree, caching results by callable
  • def dependencies run in the threadpool, like def routes

Shared Paging Dependency

from typing import Annotated
from fastapi import Depends, FastAPI, Query

app = FastAPI()

def paging(skip: Annotated[int, Query(ge=0)] = 0,
           limit: Annotated[int, Query(le=100)] = 20) -> dict:
    return {"skip": skip, "limit": limit}

Paging = Annotated[dict, Depends(paging)]     # reusable alias

@app.get("/todos")
def list_todos(page: Paging):
    return repo.list(**page)

@app.get("/users")
def list_users(page: Paging, q: str | None = None):
    return users.search(q, **page)

# /todos?skip=40&limit=10 → page = {"skip": 40, "limit": 10}

Code Explained

paging() — normal function with query params
Depends(paging) — call it, inject the result
Paging alias — one name for type + dependency
Both routes get the same validated paging params

Other Framework

  • Flask — no DI; use g, decorators or helper functions
  • Django — middleware, decorators, or class-based view mixins

Prefer / Avoid

  • Avoid page: dict = Depends(paging) · Prefer Annotated aliases
  • Avoid copying the same params into every route · Prefer one dependency

⚠ Common Mistakes

  • Calling the function yourself: Depends(paging()) passes the result, not the callable
  • Using dependencies for heavy app-wide setup; put that in lifespan (sheet 26)
  • Forgetting dependency params show in docs and leak internal names

✓ Tips & Best Practices

  • Keep dependencies in deps.py with Annotated aliases
  • Return a small dataclass instead of a dict for type checking
  • Override any dependency in tests (sheet 41)

Quick Summary

  • Depends(fn) — FastAPI calls fn, injects result
  • dependency params — resolved like route params
  • Annotated alias — reuse everywhere
  • per-request cache — runs once per request
