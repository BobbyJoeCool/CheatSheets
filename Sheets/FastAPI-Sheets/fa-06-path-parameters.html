Sheet 06

Path Parameters

/items/{item_id} · type conversion · Enum · {file_path:path} · 422 errors

Description

Path parameters are the {name} parts of a URL. Declare a function argument with the same name and a type, and FastAPI converts the string from the URL to that type, returning a 422 error with details if it can't. Use an Enum to restrict a parameter to fixed values, and :path to capture slashes.

Notes

  • Path params are always required
  • Types: int, float, str, bool, UUID, date, Enums
  • Enum values appear as a dropdown in /docs
  • Constraints like ge=1 come from Path() (sheet 09)

Typed Path Parameters

from enum import Enum
from uuid import UUID
from fastapi import FastAPI

class Status(str, Enum):                 # str mixin → JSON-friendly
    open = "open"
    done = "done"

app = FastAPI()

@app.get("/todos/{todo_id}")
def get_todo(todo_id: int): ...       # /todos/x → 422

@app.get("/users/{user_id}")
def get_user(user_id: UUID): ...      # must be a valid UUID

@app.get("/todos/status/{status}")
def by_status(status: Status):        # only "open" or "done"
    return {"status": status, "is_done": status is Status.done}

@app.get("/files/{file_path:path}")
def read_file(file_path: str): ...    # "a/b/c.txt"

Code Explained

{todo_id} + todo_id: int — names must match exactly
Bad input returns 422, never reaches your function
class Status(str, Enum) — limits values, documents them
status is Status.done — compare Enum members, not strings
{file_path:path} — Starlette converter that allows /

Other Framework

  • Flask — /todos/<int:todo_id>, <uuid:id>, <path:p> converters
  • Django — path("todos/<int:pk>/", ...)

Prefer / Avoid

  • Avoid todo_id: str then int(todo_id) · Prefer todo_id: int
  • Avoid magic strings for fixed choices · Prefer str, Enum

⚠ Common Mistakes

  • Function arg named id but path says {todo_id}: it becomes a query param instead
  • Using a plain Enum without str: serialization surprises in some tools
  • Expecting /files/{name} to match a/b.txt: needs :path

✓ Tips & Best Practices

  • Prefer UUIDs in public URLs to avoid guessable IDs
  • Add Path(ge=1) to reject zero and negatives (sheet 09)
  • Test the 422 shape once; clients will depend on it

Quick Summary

  • {name} + typed arg — path parameter
  • conversion failure — automatic 422
  • str, Enum — fixed set of values
  • {p:path} — capture slashes
