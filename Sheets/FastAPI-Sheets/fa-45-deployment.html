Sheet 45

Deployment

fastapi run --workers 4 · Uvicorn · Gunicorn + UvicornWorker · Dockerfile · Nginx · HTTPS · health checks

Description

In production, run FastAPI with fastapi run (or Uvicorn directly) with several worker processes, inside a container, behind a reverse proxy that handles HTTPS. Use one worker per container when an orchestrator like Kubernetes scales containers for you; use several workers on a single VM.

Notes

  • Workers ≈ CPU cores for one VM/container
  • In Kubernetes: 1 worker per pod, scale pods
  • Proxy terminates TLS; app speaks plain HTTP inside
  • Run migrations as a separate deploy step

Dockerfile

FROM python:3.13-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY ./app ./app
EXPOSE 8000
CMD ["fastapi", "run", "app/main.py", "--port", "8000", \
     "--workers", "4", "--proxy-headers"]

Nginx Reverse Proxy

server {
    listen 443 ssl;
    server_name api.example.com;
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;     # websockets
        proxy_set_header Connection "upgrade";
    }
}

Code Explained

slim base image — smaller, faster pulls
copy requirements first — cached dependency layer
exec-form CMD — clean signals and shutdown
--proxy-headers — trust X-Forwarded-*
Upgrade headers — needed for websockets

Other Framework

  • Flask — Gunicorn or Waitress behind Nginx (sheet 57)
  • Django — Gunicorn (WSGI) or Uvicorn (ASGI) + collectstatic

Prefer / Avoid

  • Avoid fastapi dev / --reload in prod · Prefer fastapi run
  • Avoid running as root in the container · Prefer a non-root USER

⚠ Common Mistakes

  • Many workers per pod and autoscaling pods: double counting, memory blowup
  • Forgetting forwarded headers: wrong scheme in redirects and docs
  • Baking secrets into the image instead of env vars

✓ Tips & Best Practices

  • Add a HEALTHCHECK or orchestrator probe on /health
  • Pin the Python base image tag and rebuild for security updates
  • See the Docker and Ubuntu sets for container and server setup

Quick Summary

  • fastapi run --workers N — prod server
  • Docker — repeatable builds
  • Nginx / proxy — TLS, headers, websockets
  • 1 worker per pod — when the platform scales
