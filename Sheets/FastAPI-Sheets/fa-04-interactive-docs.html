Sheet 04

Interactive Docs & OpenAPI

/docs · /redoc · /openapi.json · summary · description · tags · docstrings

Description

FastAPI builds an OpenAPI schema from your routes, parameters and models, then serves two UIs from it: Swagger UI at /docs (try requests in the browser) and ReDoc at /redoc (read-only reference). The raw schema at /openapi.json can generate clients, import into Postman, or drive contract tests.

Notes

  • Docstrings become operation descriptions (Markdown allowed)
  • summary overrides the auto title made from the function name
  • response_description labels the success response
  • Disable in prod with docs_url=None, redoc_url=None

Documenting an Operation

@app.post(
    "/todos",
    tags=["todos"],
    summary="Create a todo",
    response_description="The created todo",
    status_code=201,
)
def create_todo(todo: TodoIn) -> TodoOut:
    """
    Create a todo for the current user.

    - **title**: required, 1-100 chars
    - **due**: optional ISO date
    """
    ...

@app.get("/legacy", deprecated=True, include_in_schema=True)
def legacy(): ...

Code Explained

tags — section heading in Swagger UI
summary — one-line title for the operation
docstring — long description, rendered as Markdown
-> TodoOut — documents the response schema
deprecated=True — shown struck through in the docs

Other Framework

  • Flask — no built-in docs; use flask-smorest or APIFlask (sheet 56)
  • Django — DRF + drf-spectacular for OpenAPI

Prefer / Avoid

  • Avoid writing a separate API doc by hand · Prefer docstrings + models
  • Avoid exposing /docs on a public prod API unintentionally · Prefer an explicit choice

Operation Doc Params

ParamEffect
tags=[...]group operations
summary=short title
description=long text (or docstring)
response_description=success label
deprecated=Truemark as deprecated
include_in_schema=Falsehide from docs

⚠ Common Mistakes

  • Expecting /docs to work offline: Swagger UI loads assets from a CDN by default
  • Using print-style docstrings with odd indentation: Markdown renders them as code
  • Forgetting response models, so docs show an empty {} response

✓ Tips & Best Practices

  • Use openapi_tags (sheet 43) to add descriptions to each tag
  • Import /openapi.json into Postman or Bruno to get a ready collection
  • Add examples to models (sheet 12) so "Try it out" is pre-filled

Quick Summary

  • /docs — Swagger UI
  • /redoc — ReDoc
  • /openapi.json — schema for tools
  • docstring + summary — operation text
