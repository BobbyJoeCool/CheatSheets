Sheet 49

Templates with Jinja2

render_template() · templates/ · {% extends %} / {% block %} · filters · static/ · url_for('static') · autoescape

Description

render_template() renders a Jinja2 file from the templates/ folder with the variables you pass. Templates use inheritance: a base.html defines blocks that child templates fill. Output is auto-escaped in .html templates, and url_for, request, session and g are available inside them.

Notes

  • Templates live in templates/, assets in static/
  • {{ }} outputs; {% %} runs logic; {# #} comments
  • Auto-escaping is on for .html, .htm, .xml
  • Context processors inject variables into every template

View

from flask import render_template

@app.get("/todos")
def todo_list():
    return render_template("todos.html", todos=repo.all(),
                           title="My Todos")

templates/base.html + todos.html

<!-- base.html -->
<title>{% block title %}App{% endblock %}</title>
<link rel="stylesheet"
      href="{{ url_for('static', filename='app.css') }}">
<main>{% block content %}{% endblock %}</main>

<!-- todos.html -->
{% extends "base.html" %}
{% block title %}{{ title }}{% endblock %}
{% block content %}
  <ul>
  {% for t in todos %}
    <li>{{ loop.index }}. {{ t.title | title }}
        {% if t.done %}✔{% endif %}</li>
  {% else %}
    <li>Nothing to do!</li>
  {% endfor %}
  </ul>
{% endblock %}

Code Explained

render_template(name, **ctx) — render with variables
{% extends %} + {% block %} — layout inheritance
url_for('static', filename=) — asset URL
loop.index — 1-based loop counter
| title — filter: Title Case

Prefer / Avoid

  • Avoid | safe on user content · Prefer auto-escaping
  • Avoid repeating layout HTML · Prefer base.html + blocks

⚠ Common Mistakes

  • Putting templates in the wrong folder (e.g. next to app.py, not in templates/)
  • Using | safe to fix double escaping instead of fixing the data
  • Heavy logic in templates; compute in the view

✓ Tips & Best Practices

  • Use @app.context_processor for values every page needs
  • Use macros for repeated form fields
  • flask shell + render_template_string for quick experiments

Quick Summary

  • render_template() — Jinja2 from templates/
  • extends / block — layouts
  • filters — {{ x | upper }}
  • auto-escape — XSS protection by default
