Sheet 51

Blueprints & the App Factory

Blueprint(…, url_prefix=) · register_blueprint() · create_app() · package layout · instance/ · init_app()

Description

A Blueprint groups related routes, templates and static files, like FastAPI's APIRouter. The application factory (create_app()) builds and configures the app inside a function, which makes testing with different configs easy and avoids circular imports. Extensions are created once and attached with init_app().

Notes

  • Endpoints become blueprint.view (e.g. todos.show)
  • flask --app myapp run finds create_app() automatically
  • instance/ holds local config and the SQLite DB, not committed
  • Blueprints can have their own templates/ folders

myapp/__init__.py + todos.py

# myapp/todos.py
from flask import Blueprint, render_template
bp = Blueprint("todos", __name__, url_prefix="/todos")

@bp.get("/")
def index():
    return render_template("todos/index.html")

# myapp/__init__.py
from flask import Flask

def create_app(config: dict | None = None) -> Flask:
    app = Flask(__name__, instance_relative_config=True)
    app.config.from_object("myapp.config.Default")
    app.config.update(config or {})
    from .extensions import db      # db = SQLAlchemy()
    db.init_app(app)
    from . import todos, auth
    app.register_blueprint(todos.bp)
    app.register_blueprint(auth.bp)
    return app

Code Explained

Blueprint(name, __name__, url_prefix=) — route group
create_app(config) — build a configured app
db.init_app(app) — bind extension to this app
imports inside the factory — no circular imports

Other Framework

  • FastAPI — APIRouter + include_router() (sheet 25)
  • Django — apps + include(); settings modules per environment

Prefer / Avoid

  • Avoid a module-level app = Flask() imported everywhere · Prefer create_app()
  • Avoid url_for("show") across blueprints · Prefer url_for("todos.show")

⚠ Common Mistakes

  • Creating extensions inside create_app(): other modules can't import them
  • Relative url_for(".show") used outside its blueprint
  • Committing instance/ with secrets

✓ Tips & Best Practices

  • Pass {"TESTING": True, ...} to create_app() in tests
  • Register error handlers with @bp.app_errorhandler for app-wide pages
  • Keep one blueprint per feature, like routers

Quick Summary

  • Blueprint — group of routes
  • create_app() — factory, testable config
  • init_app() — extensions without globals
  • bp.endpoint — namespaced URLs
