OpenAPI Customization & Client Generation

openapi_tags · include_in_schema=False · generate_unique_id_function · custom openapi() · openapi_url=None

Description

The OpenAPI schema is a product of its own: clients are generated from it, docs are read from it. Add tag descriptions, hide internal routes, give operations stable IDs for nice generated method names, and patch the schema for anything FastAPI doesn't model. Then generate a typed TypeScript or Python client.

Notes

  • Schema is built once and cached on app.openapi_schema
  • openapi_url=None turns off schema and both doc UIs
  • Operation IDs default to function_name_path_method
  • OpenAPI 3.1 is the version FastAPI emits

Tags, IDs, Custom Schema

from fastapi.openapi.utils import get_openapi
from fastapi.routing import APIRoute

def route_id(route: APIRoute) -> str:
    return f"{route.tags[0]}-{route.name}"      # todos-list_todos

app = FastAPI(
    openapi_tags=[
        {"name": "todos", "description": "Manage todo items"},
        {"name": "auth", "description": "Login and tokens"}],
    generate_unique_id_function=route_id,
)

@app.get("/internal/metrics", include_in_schema=False)
def metrics(): ...

def custom_openapi():
    if app.openapi_schema:
        return app.openapi_schema
    schema = get_openapi(title="Todo API", version="2.0.0",
                         routes=app.routes)
    schema["info"]["x-logo"] = {"url": "/static/logo.png"}
    app.openapi_schema = schema
    return schema

app.openapi = custom_openapi

Code Explained

openapi_tags — descriptions and order of tags
generate_unique_id_function — clean operation IDs
include_in_schema=False — hide a route
get_openapi() — build the default schema
app.openapi = ... — replace the generator

Other Framework

  • Flask — APIFlask / flask-smorest generate OpenAPI from schemas
  • Django — drf-spectacular with @extend_schema

Prefer / Avoid

  • Avoid hand-written API clients · Prefer generated ones from /openapi.json
  • Avoid unstable operation IDs · Prefer a custom ID function

⚠ Common Mistakes

  • Changing route function names and breaking generated client method names
  • Forgetting to cache the custom schema: rebuilt on every /openapi.json hit
  • Hiding routes from the schema and assuming that secures them

✓ Tips & Best Practices

  • Regenerate clients in CI and fail on uncommitted diffs
  • Use swagger_ui_parameters={"persistAuthorization": True}
  • Export the schema with app.openapi() in a script for frontends

Quick Summary

  • openapi_tags — documented tag groups
  • unique ID function — clean client names
  • custom openapi() — patch the schema
  • generate clients from /openapi.json
