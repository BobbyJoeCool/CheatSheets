Sheet 28

SQLModel

SQLModel, table=True · Field(primary_key=True) · create_engine · Session · select() · table vs data models

Description

SQLModel (by FastAPI's author) merges Pydantic and SQLAlchemy: one class can be both a validated model and a database table. Use table=True for real tables and plain SQLModel classes for API schemas that inherit shared fields. Under the hood it is SQLAlchemy, so its sessions and select() work as usual.

Notes

  • pip install sqlmodel
  • table=True classes are tables; others are just schemas
  • create_all() is fine for demos; use Alembic in real apps
  • SQLite needs check_same_thread=False with FastAPI

Table + Schemas + Route

from sqlmodel import Field, Session, SQLModel, create_engine, select

class TodoBase(SQLModel):
    title: str = Field(index=True, max_length=100)
    done: bool = False

class Todo(TodoBase, table=True):            # DB table
    id: int | None = Field(default=None, primary_key=True)
    owner_id: int = Field(foreign_key="user.id")

class TodoCreate(TodoBase): pass             # API input
class TodoRead(TodoBase): id: int            # API output

engine = create_engine("sqlite:///todos.db",
                       connect_args={"check_same_thread": False})
SQLModel.metadata.create_all(engine)

@app.get("/todos", response_model=list[TodoRead])
def list_todos(done: bool | None = None):
    with Session(engine) as s:
        stmt = select(Todo)
        if done is not None:
            stmt = stmt.where(Todo.done == done)
        return s.exec(stmt).all()

Code Explained

TodoBase — shared fields, no table
table=True — real table; id is the primary key
TodoCreate / TodoRead — input and output schemas
select(Todo).where(...) — typed query
s.exec(stmt).all() — run and fetch rows

Other Framework

  • Flask — Flask-SQLAlchemy db.Model (sheet 54)
  • Django — models.Model with the Django ORM

Prefer / Avoid

  • Avoid returning table=True models with secret columns · Prefer a Read schema
  • Avoid create_all() in production · Prefer Alembic migrations

⚠ Common Mistakes

  • Expecting table=True models to validate on construction: they skip validation for speed
  • Forgetting s.refresh(obj) and returning an object with id=None
  • Sharing one Session across requests

✓ Tips & Best Practices

  • Provide the session through a yield dependency (sheet 23)
  • Use TodoUpdate with all-optional fields for PATCH
  • Drop to SQLAlchemy when SQLModel lacks a feature; both mix fine

Quick Summary

  • Session + select() — SQLAlchemy underneath
