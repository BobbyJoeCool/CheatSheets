APIRouter & Bigger Applications

APIRouter(prefix=, tags=) · include_router() · routers/ folder · shared deps · relative imports · /v1

Description

An APIRouter is a mini app: it has the same decorators as FastAPI and is mounted with app.include_router(). Give each feature its own router module with a prefix, tags and shared dependencies. Routers can include other routers, which makes API versioning (/v1, /v2) a matter of nesting.

Notes

  • Routers never need to import app
  • prefix must start with / and not end with one
  • responses= on a router documents shared errors
  • Include order still decides overlapping matches

routers/todos.py + main.py

# app/routers/todos.py
from fastapi import APIRouter
from app.deps import CurrentUser, DbSession

router = APIRouter(prefix="/todos", tags=["todos"],
                   responses={404: {"description": "Not found"}})

@router.get("/")
def list_todos(user: CurrentUser, db: DbSession): ...

@router.get("/{todo_id}")
def get_todo(todo_id: int, user: CurrentUser): ...

# app/main.py
from fastapi import APIRouter, FastAPI
from app.routers import todos, users

v1 = APIRouter(prefix="/v1")
v1.include_router(todos.router)          # /v1/todos/...
v1.include_router(users.router)

app = FastAPI()
app.include_router(v1)

Code Explained

APIRouter(prefix=, tags=) — shared settings
@router.get("/") — becomes /todos/
deps imported from app.deps, not main
v1.include_router(...) — nest for versions

Other Framework

  • Flask — Blueprint("todos", __name__, url_prefix="/todos") (sheet 51)
  • Django — include("todos.urls") with app_name

Prefer / Avoid

  • Avoid from app.main import app in routers · Prefer APIRouter
  • Avoid mixing versions in one router · Prefer one router tree per version

⚠ Common Mistakes

  • Prefix /todos/ plus path / gives /todos// problems: no trailing slash on prefix
  • Defining routes after include_router and expecting them included: inclusion copies routes at that moment
  • Circular imports between routers and main.py

✓ Tips & Best Practices

  • Use @router.get("") if you want /todos with no trailing slash
  • Put shared dependencies on the router, not each route
  • Mirror router files in tests/

Quick Summary

  • APIRouter — mini app per feature
  • include_router() — mount with prefix/tags/deps
  • nested routers — /v1, /v2
  • no app imports — no circular imports
