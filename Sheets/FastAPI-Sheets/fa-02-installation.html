Sheet 02

Installation & the fastapi CLI

pip install fastapi[standard] · uv add · venv · fastapi dev · fastapi run · uvicorn

Description

Install FastAPI into a virtual environment with the standard extra, which brings Uvicorn, the fastapi CLI, httpx, jinja2, python-multipart and email validation. The CLI gives you fastapi dev for development (auto-reload, localhost only) and fastapi run for production (no reload, listens on all interfaces).

Notes

  • fastapi alone has no server; use fastapi[standard]
  • Quote the extra in zsh: "fastapi[standard]"
  • fastapi dev finds main.py, app.py or api.py automatically
  • uv is a fast pip + venv replacement; both work

Set Up a Project

# pip + venv
python3 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install "fastapi[standard]"
pip freeze > requirements.txt

# or uv
uv init todo-api && cd todo-api
uv add "fastapi[standard]"

# check it
python -c "import fastapi; print(fastapi.__version__)"

# run
fastapi dev main.py                  # reload, 127.0.0.1:8000
fastapi run main.py --port 8080      # prod, 0.0.0.0, no reload
uvicorn main:app --reload            # same thing, by hand

Code Explained

python3 -m venv .venv — isolated environment per project
[standard] — server, CLI and common optional deps
uv add — installs and records in pyproject.toml + uv.lock
fastapi dev — development server with reload
main:app — module main, variable app

Other Framework

  • Flask — pip install flask, run with flask --app app run --debug
  • Django — pip install django, run with manage.py runserver

Prefer / Avoid

  • Avoid installing into the system Python · Prefer a venv or uv
  • Avoid --reload in production · Prefer fastapi run --workers N

fastapi CLI Options

OptionDoes

⚠ Common Mistakes

  • pip install fastapi[standard] in zsh fails: quote the brackets
  • Using fastapi dev in Docker: it only listens on 127.0.0.1
  • Forgetting to activate the venv, then fastapi: command not found

✓ Tips & Best Practices

  • Commit uv.lock or a pinned requirements.txt for repeatable builds
  • Use fastapi run in containers; it binds 0.0.0.0 already
  • uv run fastapi dev runs inside the project env without activating

Quick Summary

  • fastapi[standard] — framework + server + CLI
  • fastapi dev — reload, localhost
  • fastapi run — production, all interfaces
  • uvicorn main:app — the server underneath
