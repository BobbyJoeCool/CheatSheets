Sheet 30

Async Database Access

create_async_engine · AsyncSession · asyncpg / aiosqlite · await session.scalars() · expire_on_commit=False

Description

With async def routes, use SQLAlchemy's async API so database waits don't block the event loop. You need an async driver (asyncpg, aiosqlite, psycopg async), an AsyncEngine, and AsyncSession. Every query is awaited, and lazy loading is off-limits, so load relationships eagerly.

Notes

  • Async only helps if every I/O call in the route is async
  • Lazy relationship access raises MissingGreenlet
  • Use selectinload() for relationships
  • Create the engine in lifespan, dispose on shutdown

Async Session Dependency

from typing import Annotated, AsyncIterator
from fastapi import Depends
from sqlalchemy import select
from sqlalchemy.ext.asyncio import (AsyncSession,
    async_sessionmaker, create_async_engine)
from sqlalchemy.orm import selectinload

engine = create_async_engine(
    "postgresql+asyncpg://app@localhost/app", pool_size=10)
SessionLocal = async_sessionmaker(engine, expire_on_commit=False)

async def get_db() -> AsyncIterator[AsyncSession]:
    async with SessionLocal() as session:
        yield session

Db = Annotated[AsyncSession, Depends(get_db)]

@app.get("/users/{user_id}")
async def get_user(user_id: int, db: Db) -> UserWithTodos:
    stmt = (select(User).where(User.id == user_id)
            .options(selectinload(User.todos)))
    user = await db.scalar(stmt)
    if user is None:
        raise HTTPException(404)
    return user

Code Explained

create_async_engine — async driver URL
async_sessionmaker — AsyncSession factory
async with — closes the session for you
selectinload — load todos up front
await db.scalar(...) — one object or None

Other Framework

  • Flask — sync SQLAlchemy only (WSGI); async views gain little here
  • Django — async ORM: await Todo.objects.aget(pk=1)

Prefer / Avoid

  • Avoid sync drivers in async def routes · Prefer an async driver
  • Avoid user.todos lazy access · Prefer selectinload or await user.awaitable_attrs.todos

⚠ Common Mistakes

  • MissingGreenlet errors from lazy loads after the query
  • Mixing a sync Session into async routes: blocks the loop
  • expire_on_commit=True (default): attributes expire, then need a lazy reload

✓ Tips & Best Practices

  • Return Pydantic models built inside the session to avoid lazy loads
  • Use pool_pre_ping=True for long-lived connections
  • Plain def routes + sync SQLAlchemy is a fine, simpler choice

Quick Summary

  • create_async_engine + async driver
  • AsyncSession — await every call
  • selectinload — no lazy loads
  • yield dependency — session per request
