Sheet 35

Scopes, API Keys & HTTP Basic

Security(scopes=) · SecurityScopes · APIKeyHeader · HTTPBasic · HTTPBearer · secrets.compare_digest

Description

Beyond user logins, APIs often need scopes (fine-grained permissions inside a token), API keys for machine clients, and occasionally HTTP Basic for simple internal tools. Security() is Depends() plus a list of required scopes, and SecurityScopes tells the dependency which scopes the route needs.

Notes

  • Scopes are strings like todos:read, todos:write
  • Declare available scopes on OAuth2PasswordBearer(scopes={...})
  • API keys: send in a header, never in URLs (they get logged)
  • Compare secrets with secrets.compare_digest

Scopes + API Key

import secrets
from fastapi import Security
from fastapi.security import APIKeyHeader, SecurityScopes

oauth2 = OAuth2PasswordBearer(tokenUrl="auth/token",
    scopes={"todos:read": "Read todos", "todos:write": "Edit todos"})

def current_user(scopes: SecurityScopes,
                 token: Annotated[str, Depends(oauth2)]) -> User:
    payload = decode(token)                   # sheet 33
    granted = set(payload.get("scopes", []))
    if not set(scopes.scopes) <= granted:
        raise HTTPException(403, "Not enough permissions")
    return load_user(payload)

@app.post("/todos")
def create(user: Annotated[User, Security(current_user,
                                          scopes=["todos:write"])]): ...

api_key = APIKeyHeader(name="X-API-Key")

def require_key(key: Annotated[str, Depends(api_key)]):
    if not secrets.compare_digest(key, settings.api_key):
        raise HTTPException(401, "Invalid API key")

Code Explained

scopes={...} — documented scopes for /docs
SecurityScopes.scopes — scopes this route requires
Security(dep, scopes=[...]) — require scopes
APIKeyHeader(name=) — reads X-API-Key
compare_digest — constant-time comparison

Other Framework

  • Flask — custom decorator checking request.headers["X-API-Key"]
  • Django — DRF permissions; djangorestframework-api-key

Prefer / Avoid

  • Avoid API keys in query strings · Prefer a header
  • Avoid key == expected · Prefer secrets.compare_digest

⚠ Common Mistakes

  • Storing API keys in plain text in the DB: hash them like passwords
  • Using 401 when a valid user lacks a scope: that's 403
  • HTTP Basic over plain HTTP: credentials are only base64

✓ Tips & Best Practices

  • Prefix keys (tk_live_...) so leaks are easy to spot and scan for
  • Let users create and revoke multiple keys
  • Put scope checks on routers for whole feature areas

Quick Summary
