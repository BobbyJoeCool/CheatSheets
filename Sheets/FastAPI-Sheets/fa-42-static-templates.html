Sheet 42

Static Files & Templates

StaticFiles · app.mount() · Jinja2Templates · TemplateResponse(request, "x.html", …) · url_for · HTMX

Description

FastAPI can serve HTML too. StaticFiles serves CSS, JS and images from a folder, mounted at a path. Jinja2Templates renders HTML templates with your data. Pair them with HTMX for interactive pages without a JavaScript framework.

Notes

  • jinja2 is included in fastapi[standard]
  • Mounted apps are independent: no docs, no route deps
  • TemplateResponse takes request as its first argument
  • Use response_class=HTMLResponse for clean docs

main.py

from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates
from fastapi.responses import HTMLResponse

app.mount("/static", StaticFiles(directory="static"), name="static")
templates = Jinja2Templates(directory="templates")

@app.get("/todos/page", response_class=HTMLResponse)
def todo_page(request: Request, db: DbSession):
    todos = list_todos(db)
    return templates.TemplateResponse(request, "todos.html",
                                      {"todos": todos})

templates/todos.html

<link rel="stylesheet" href="{{ url_for('static', path='app.css') }}">
<ul>
  {% for t in todos %}
    <li class="{{ 'done' if t.done }}">{{ t.title }}</li>
  {% else %}
    <li>Nothing to do!</li>
  {% endfor %}
</ul>

Code Explained

app.mount(path, StaticFiles(...), name=) — static folder
Jinja2Templates(directory=) — template loader
TemplateResponse(request, name, context) — render
url_for('static', path=) — static file URL
{% for %}...{% else %} — empty-list fallback

Other Framework

  • Flask — render_template() + static/ folder by default (sheet 49)
  • Django — render() + {% static %} tag

Prefer / Avoid

  • Avoid building HTML strings in Python · Prefer templates (auto-escaped)
  • Avoid serving static files via Python in prod · Prefer Nginx or a CDN

⚠ Common Mistakes

  • Old TemplateResponse("x.html", {"request": request}) signature is deprecated
  • Mounting static at / and hiding all API routes
  • Using |safe on user input: XSS

✓ Tips & Best Practices

  • Return template partials for HTMX requests (HX-Request header)
  • Use html=True to serve a built SPA folder
  • Cache static files with long max-age + hashed names

Quick Summary

  • StaticFiles + mount() — static assets
  • Jinja2Templates — server-rendered HTML
  • TemplateResponse(request, ...) — render
  • HTMX — interactivity without a JS framework
