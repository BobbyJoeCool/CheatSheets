Sheet 24

Global Dependencies & Overrides

FastAPI(dependencies=[…]) · APIRouter(dependencies=…) · decorator dependencies= · dependency_overrides

Description

Dependencies don't have to be parameters. List them in dependencies=[...] on a route, a router or the whole app and they run for every matching request, with their return value ignored: perfect for auth checks, API keys and rate limits. app.dependency_overrides swaps any dependency for another, mainly in tests.

Notes

  • Order: app → router → route → parameter dependencies
  • List form ignores return values
  • Overrides are keyed by the original callable
  • Clear overrides after each test

Apply at Every Level

from fastapi import APIRouter, Depends, FastAPI, Header, HTTPException

async def verify_key(x_api_key: str = Header()):
    if x_api_key != settings.api_key:
        raise HTTPException(401, "Bad API key")

app = FastAPI(dependencies=[Depends(log_request)])     # every route

admin = APIRouter(prefix="/admin",
                  dependencies=[Depends(RoleChecker("admin"))])

@app.get("/reports", dependencies=[Depends(verify_key)])
def reports(): ...                                     # just this one

app.include_router(admin)

# tests
def fake_user():
    return User(id=1, roles=["admin"])

app.dependency_overrides[get_current_user] = fake_user
# ... run tests ...
app.dependency_overrides.clear()

Code Explained

FastAPI(dependencies=) — runs on all routes
APIRouter(dependencies=) — runs on that router's routes
decorator dependencies= — one route
dependency_overrides[orig] = fake — swap implementation
.clear() — restore real dependencies

Other Framework

  • Flask — @bp.before_request for blueprint-wide checks
  • Django — middleware or @method_decorator on views

Prefer / Avoid

  • Avoid unused params like _: None = Depends(check) · Prefer dependencies=[...]
  • Avoid monkeypatching modules in tests · Prefer dependency_overrides

⚠ Common Mistakes

  • Overriding with a function whose params differ, then getting surprise 422s
  • Leaving overrides set between tests: later tests pass for the wrong reason
  • Global auth dependency that also blocks /health and /docs

✓ Tips & Best Practices

  • Use a pytest fixture that sets and clears overrides
  • Keep public routes on a separate router without the auth dependency
  • Overrides work for sub-dependencies too

Quick Summary

  • dependencies=[...] — run, ignore result
  • app / router / route — pick the scope
  • dependency_overrides — swap for tests
  • clear overrides — avoid test leaks
