Streaming & Server-Sent Events

StreamingResponse · async generators · text/event-stream · sse-starlette · LLM streaming · large downloads

Description

StreamingResponse sends a body in chunks from a generator, so the client starts receiving before you finish. Use it for large exports and streaming AI output. Server-Sent Events (SSE) are a simple text format over a stream (data: ...\n\n) that browsers read with EventSource and auto-reconnect.

Notes

  • Generators can be sync or async
  • SSE is one-way (server → client), plain HTTP
  • Disable proxy buffering (X-Accel-Buffering: no)
  • sse-starlette adds EventSourceResponse with pings

CSV Export + SSE

import asyncio, csv, io
from fastapi.responses import StreamingResponse

@app.get("/export.csv")
def export(db: DbSession):
    def rows():
        buf = io.StringIO(); w = csv.writer(buf)
        w.writerow(["id", "title"])
        for t in db.scalars(select(Todo)).yield_per(500):
            w.writerow([t.id, t.title])
            yield buf.getvalue(); buf.seek(0); buf.truncate()
        yield buf.getvalue()
    return StreamingResponse(rows(), media_type="text/csv",
        headers={"Content-Disposition": "attachment"})

@app.get("/events")
async def events(request: Request):
    async def gen():
        n = 0
        while not await request.is_disconnected():
            n += 1
            yield f"event: tick\ndata: {n}\n\n"
            await asyncio.sleep(1)
    return StreamingResponse(gen(), media_type="text/event-stream",
                             headers={"Cache-Control": "no-cache"})

Code Explained

rows() — yields CSV chunks as rows are read
yield_per(500) — stream rows from the DB
Content-Disposition — download as a file
SSE frame — event: + data: + blank line
is_disconnected() — stop when the client leaves

Other Framework

  • Flask — Response(stream_with_context(gen()), mimetype=...)
  • Django — StreamingHttpResponse(gen())

Prefer / Avoid

  • Avoid building a huge string in memory · Prefer a generator
  • Avoid polling every second · Prefer SSE for server pushes

⚠ Common Mistakes

  • Proxy buffering hides streaming: client gets everything at the end
  • Using the request session after the route returned in a stream (it may be closed)
  • Forgetting the blank line that ends each SSE event

✓ Tips & Best Practices

  • Read the stream with EventSource in browsers or httpx.stream() in Python
  • Send id: so clients resume with Last-Event-ID
  • Set Cache-Control: no-cache on SSE

Quick Summary

  • StreamingResponse — chunked body from a generator
  • SSE — text/event-stream, one-way
  • is_disconnected() — stop early
  • turn off proxy buffering
