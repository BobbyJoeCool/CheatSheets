Validation Errors & Error Formats

422 shape · RequestValidationError · override handler · jsonable_encoder · error envelopes

Description

When input fails validation FastAPI raises RequestValidationError and returns 422 with a detail list: one entry per problem, each with type, loc, msg and input. You can override the handler to reshape errors into your API's standard error envelope, change the status to 400, or log bad requests.

Notes

  • loc starts with the source: body, query, path, header
  • Pydantic errors in your own code are ValidationError (500 if uncaught)
  • exc.errors() gives the list; exc.body the raw body
  • jsonable_encoder makes errors JSON-safe

Custom Error Envelope

from fastapi import Request
from fastapi.encoders import jsonable_encoder
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

def envelope(code: str, message: str, fields=None, status=400):
    return JSONResponse(status_code=status, content=jsonable_encoder(
        {"error": {"code": code, "message": message, "fields": fields}}))

@app.exception_handler(RequestValidationError)
async def on_invalid(request: Request, exc: RequestValidationError):
    fields = {".".join(map(str, e["loc"][1:])): e["msg"]
              for e in exc.errors()}
    return envelope("invalid_input", "Check the fields", fields, 422)

@app.exception_handler(StarletteHTTPException)
async def on_http(request: Request, exc: StarletteHTTPException):
    return envelope(f"http_{exc.status_code}", str(exc.detail),
                    status=exc.status_code)

Code Explained

exc.errors() — list of error dicts
loc[1:] — drop body to get the field path
jsonable_encoder — converts dates, Decimals, sets
StarletteHTTPException handler — also catches unknown-route 404s
Every error now has one shape

Other Framework

  • Flask — return your own error JSON from @app.errorhandler
  • Django — DRF EXCEPTION_HANDLER setting

Prefer / Avoid

  • Avoid ad-hoc error shapes per route · Prefer one envelope everywhere
  • Avoid echoing input for password fields · Prefer stripping sensitive inputs

⚠ Common Mistakes

  • Overriding the 422 handler and dropping the field locations clients rely on
  • Registering for FastAPI's HTTPException only: route 404s use Starlette's
  • Logging full request bodies with passwords

✓ Tips & Best Practices

  • Version your error format with the API
  • Use RFC 9457 Problem Details if you want a standard shape
  • Reuse FastAPI's default handlers: from fastapi.exception_handlers import ...

Quick Summary

  • 422 — detail list of type/loc/msg
  • RequestValidationError — override to reshape
  • Starlette HTTPException — catch all HTTP errors
  • one envelope — predictable clients
