Sheet 07

Query Parameters

non-path args · defaults · str | None = None · bool parsing · list[str] · Query()

Description

Any simple-typed function argument that is not in the path is read from the query string. Give it a default to make it optional; leave the default off to make it required. FastAPI parses bool leniently (1, true, on, yes), and needs Query() to accept a list of repeated values.

Notes

  • skip: int = 0 → optional with default
  • q: str | None = None → optional, may be missing
  • q: str with no default → required (422 if missing)
  • Order of args does not matter to FastAPI

Filtering & Paging

from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/todos")
def list_todos(
    owner: str,                           # required
    skip: int = 0,                        # optional, default 0
    limit: int = 20,
    done: bool | None = None,             # optional tri-state
    q: str | None = None,
    tag: Annotated[list[str] | None, Query()] = None,
):
    return {"owner": owner, "skip": skip, "done": done, "tag": tag}

# /todos?owner=bob                      → done None, tag None
# /todos?owner=bob&done=yes&skip=40     → done True, skip 40
# /todos?owner=bob&tag=home&tag=urgent  → tag ["home", "urgent"]
# /todos                                → 422 owner missing

Code Explained

owner: str — no default, so required
bool | None = None — lets you tell "not sent" from False
list[str] needs Query(); otherwise FastAPI expects a body
Annotated[..., Query()] — metadata without changing the type
Unknown query params are ignored by default

Other Framework

  • Flask — request.args.get("skip", 0, type=int), getlist("tag")
  • Django — request.GET.get("skip"), getlist("tag")

Prefer / Avoid

  • Avoid Optional[str] in new code · Prefer str | None
  • Avoid unbounded limit · Prefer Query(le=100) (sheet 09)

Required vs Optional

SignatureBehavior
q: strrequired
q: str = "x"optional, default "x"
q: str | None = Noneoptional, None if missing
q: Annotated[str, Query()]required with metadata
q: list[int] = Query([])repeatable, default empty

⚠ Common Mistakes

  • tags: list[str] = [] without Query(): FastAPI treats it as a request body
  • Using if done: when done may be None; use if done is not None
  • Mutable default lists in plain functions; prefer None + Query()

✓ Tips & Best Practices

  • Group many filters into a Pydantic model with Annotated[Filter, Query()] (sheet 09)
  • Use skip/limit or cursor params consistently across endpoints
  • Document defaults in the signature; /docs shows them

Quick Summary

  • non-path simple arg — query parameter
  • default present — optional
  • X | None = None — may be absent
  • list[T] + Query() — repeated values
