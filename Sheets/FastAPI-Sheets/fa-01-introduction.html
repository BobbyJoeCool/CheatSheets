Sheet 01

Introduction & the ASGI Stack

Starlette · Pydantic · Uvicorn · ASGI · type hints · OpenAPI

Description

FastAPI is a Python web framework for building APIs from ordinary type hints. You declare what a request should look like, and FastAPI parses it, validates it, converts it, and documents it in OpenAPI. It sits on Starlette (the web toolkit) and Pydantic (validation), and runs on an ASGI server such as Uvicorn.

Notes

  • Created by Sebastián Ramírez, first released in 2018
  • Still versioned 0.x: pin the version in production
  • Needs Python 3.10+ for current releases (X | None syntax)
  • Async-first, but plain def endpoints work too

Under the Hood

  • Starlette provides routing, requests, responses, middleware and WebSockets
  • Pydantic v2 (Rust core) does parsing and validation
  • Each request becomes an ASGI scope + receive / send call

Hello, FastAPI — main.py

from fastapi import FastAPI

app = FastAPI(title="Todo API")       # the ASGI application

@app.get("/")                          # GET /
def root():
    return {"message": "Hello, FastAPI"}   # dict → JSON

@app.get("/todos/{todo_id}")
def read_todo(todo_id: int, done: bool = False):
    return {"id": todo_id, "done": done}

# $ fastapi dev main.py
# GET /todos/3?done=true → {"id": 3, "done": true}
# GET /todos/abc         → 422 (not an int)
# Docs: http://127.0.0.1:8000/docs

Code Explained

FastAPI() — the app object; an ASGI callable
@app.get(path) — registers a path operation
todo_id: int — path param, converted and validated
done: bool = False — not in the path, so it is a query param
Return value is serialized to JSON automatically

Other Framework

  • Flask — @app.get("/todos/<int:todo_id>"), request.args
  • Django — path("todos/<int:id>/", view) in urls.py

Prefer / Avoid

  • Avoid parsing request.query_params by hand · Prefer typed function parameters
  • Avoid returning json.dumps(...) · Prefer returning dicts or models

⚠ Common Mistakes

  • Running python main.py without a server: FastAPI needs Uvicorn or fastapi dev
  • Expecting async def to speed up blocking code: it does not (see sheet 36)
  • Leaving the version unpinned; minor releases can change behavior

✓ Tips & Best Practices

  • Open /docs first: it shows exactly how FastAPI read your hints
  • Start with fastapi dev; it reloads on save
  • Read Starlette docs for anything request/response-level

Quick Summary

  • FastAPI() — ASGI app built on Starlette + Pydantic
  • @app.get() — path operation decorator
  • type hints — drive parsing, validation and docs
  • /docs — free interactive API docs
