Sheet 17

Response Types

JSONResponse · HTMLResponse · PlainTextResponse · RedirectResponse · FileResponse · StreamingResponse

Description

By default FastAPI wraps your return value in a JSONResponse. Return a Response subclass yourself to send HTML, plain text, redirects, files or streams. Returning a Response skips response-model validation, so you control the exact bytes. Set response_class= on the decorator to change the default and the docs.

Notes

  • All live in fastapi.responses (re-exported from Starlette)
  • FileResponse streams from disk and sets Content-Length
  • RedirectResponse defaults to 307 (keeps method)
  • ORJSONResponse is faster JSON (needs orjson)

Choosing a Response

from fastapi.responses import (HTMLResponse, PlainTextResponse,
    RedirectResponse, FileResponse, StreamingResponse, JSONResponse)

@app.get("/hello", response_class=HTMLResponse)
def hello():
    return "<h1>Hello</h1>"                  # str sent as HTML

@app.get("/old")
def old():
    return RedirectResponse("/new", status_code=301)

@app.get("/report.pdf")
def report():
    return FileResponse("files/report.pdf", filename="report.pdf")

@app.get("/teapot")
def teapot():
    return JSONResponse({"error": "teapot"}, status_code=418,
                        headers={"X-Brew": "no"})

Code Explained

response_class= — sets the default class and docs media type
RedirectResponse(url, 301) — permanent redirect
FileResponse(filename=) — download with a name
JSONResponse(..., status_code, headers) — full control

Other Framework

  • Flask — return a str, redirect(), send_file(), Response(...)
  • Django — HttpResponse, JsonResponse, FileResponse, redirect()

Prefer / Avoid

  • Avoid JSONResponse(content=model) · Prefer returning the model (validated, filtered)
  • Avoid reading a whole file into memory · Prefer FileResponse

⚠ Common Mistakes

  • Returning a JSONResponse with a datetime: not JSON-serializable without jsonable_encoder
  • Using 302 after a form POST: use 303 so the browser does a GET
  • Expecting response models to filter a returned JSONResponse

✓ Tips & Best Practices

  • Use response_class=ORJSONResponse app-wide for speed (sheet 44)
  • Pass media_type= to Response for custom types like CSV
  • Use FileResponse with headers={"Cache-Control": ...} for static downloads

Quick Summary

  • default — JSONResponse
  • return a Response — exact control, no filtering
  • response_class= — change default + docs
  • FileResponse / RedirectResponse — common cases
