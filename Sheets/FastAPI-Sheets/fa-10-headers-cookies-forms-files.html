Sheet 10

Headers, Cookies, Forms & Files

Header() · Cookie() · Form() · File() · UploadFile · python-multipart

Description

Not everything arrives as JSON. Header() and Cookie() read those parts of the request; Form() reads HTML form fields; File() and UploadFile handle multipart uploads. Forms and files need the python-multipart package (included in fastapi[standard]). A request can carry form fields or JSON, not both.

Notes

  • user_agent header param matches User-Agent (underscores → hyphens)
  • UploadFile spools to disk past ~1 MB; bytes loads into memory
  • Multiple files: list[UploadFile]
  • Files + JSON together: send JSON as a form field

Non-JSON Inputs

from typing import Annotated
from fastapi import FastAPI, Header, Cookie, Form, File, UploadFile

app = FastAPI()

@app.get("/whoami")
def whoami(
    user_agent: Annotated[str | None, Header()] = None,
    x_request_id: Annotated[str | None, Header()] = None,
    session: Annotated[str | None, Cookie()] = None,
): ...

@app.post("/login")
def login(username: Annotated[str, Form()],
          password: Annotated[str, Form()]): ...

@app.post("/avatars")
async def upload(file: UploadFile, caption: Annotated[str, Form()] = ""):
    data = await file.read()               # bytes
    return {"name": file.filename, "type": file.content_type,
            "size": len(data)}

@app.post("/attachments")
async def many(files: list[UploadFile]): ...

Code Explained

Header() — x_request_id reads X-Request-Id
Cookie() — reads a cookie by name
Form() — application/x-www-form-urlencoded or multipart field
UploadFile — .filename, .content_type, await .read()
list[UploadFile] — several files under one field

Other Framework

  • Flask — request.headers, request.cookies, request.form, request.files
  • Django — request.headers, request.COOKIES, request.POST, request.FILES

Prefer / Avoid

  • Avoid file: bytes for large uploads · Prefer UploadFile
  • Avoid trusting file.filename as a path · Prefer generating your own name

⚠ Common Mistakes

  • Mixing a JSON model with Form() params: the body can only be one encoding
  • Missing python-multipart: FastAPI raises at startup for form routes
  • Saving uploads with the client filename: path traversal risk

✓ Tips & Best Practices

  • Check content_type and size before saving uploads
  • Use convert_underscores=False on Header() for odd header names
  • Stream large files to disk with shutil.copyfileobj(file.file, out)

Quick Summary

  • Header() / Cookie() — request metadata
  • Form() — form fields
  • UploadFile — streamed file uploads
  • form vs JSON — one encoding per request
