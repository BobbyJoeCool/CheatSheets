Sheet 05

Path Operations

@app.get · post · put · patch · delete · route order · status_code · operation_id

Description

A path operation is one HTTP method on one path, handled by one function. FastAPI has a decorator per method. The decorator holds routing and docs settings (status code, tags, response model); the function signature holds the inputs. Routes are matched in the order they were added, so fixed paths must come before parameterized ones.

Notes

  • Methods: get post put patch delete head options trace
  • @app.api_route(path, methods=[...]) handles several methods
  • Same path, different methods → separate functions
  • Function name becomes the default docs summary

Under the Hood

  • Each decorator creates a Starlette APIRoute
  • Path is compiled to a regex once at startup
  • First matching route wins; no specificity sorting

CRUD on One Resource

from fastapi import FastAPI, status

app = FastAPI()

@app.get("/todos")                       # list
def list_todos(): ...

@app.get("/todos/stats")                 # fixed path FIRST
def todo_stats(): ...

@app.get("/todos/{todo_id}")             # then the param path
def get_todo(todo_id: int): ...

@app.post("/todos", status_code=status.HTTP_201_CREATED)
def create_todo(todo: TodoIn): ...

@app.patch("/todos/{todo_id}")           # partial update
def update_todo(todo_id: int, todo: TodoPatch): ...

@app.delete("/todos/{todo_id}", status_code=204)
def delete_todo(todo_id: int) -> None: ...

Code Explained

/todos/stats first — else stats hits the int route (422)
status_code= — success code for response and docs
204 responses must not return a body
PUT replaces; PATCH changes only sent fields

Other Framework

  • Flask — @app.get, @app.post, or @app.route(..., methods=[...])
  • Django — one view checks request.method; DRF ViewSets map methods

Prefer / Avoid

  • Avoid verbs in paths like /getTodos · Prefer GET /todos
  • Avoid one handler branching on method · Prefer one function per method

⚠ Common Mistakes

  • Ordering /users/{id} above /users/me: me hits the param route
  • Returning data from a 204 route: clients and proxies may choke
  • Two functions with the same name in one module: the second silently replaces the first

✓ Tips & Best Practices

  • Group related operations with an APIRouter (sheet 25)
  • Set operation_id if you generate typed clients
  • Use status constants for readability

Quick Summary

  • @app.<method>(path) — one operation per function
  • registration order — first match wins
  • status_code= — success code
  • PUT vs PATCH — replace vs partial
