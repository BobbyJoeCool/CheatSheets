Teaching Copilot Your Repo

Copilot Chat on github.com answers questions about repos, files, issues, PRs and diffs. Its answers (and those of the coding agent and code review) improve with custom instructions: .github/copilot-instructions.md for repo-wide rules, .github/instructions/*.instructions.md with an applyTo glob for specific paths, and reusable prompt files. The coding agent also reads AGENTS.md.

Instruction Facts

  • Keep instructions short, factual and about *this* repo
  • Path-specific files combine with the repo-wide file
  • Personal and org instructions can be set in Copilot settings

Who Can Do This

  • Role: Write (commit instruction files)
  • Plan: any Copilot plan
  • Repos: public and private

Repo + Path Instructions

<!-- .github/copilot-instructions.md -->
# Project notes for Copilot
- Stack: Next.js 15, TypeScript strict, Prisma, PostgreSQL.
- Run tests with `npm test`; lint with `npm run lint`.
- Use `zod` for validation; never `any`.
- API routes live in `app/api/`; shared types in `lib/types.ts`.
- Write commit messages in Conventional Commits style.

- Use Vitest, not Jest.

⚠ Common Mistakes

  • Pages of style essays: long instructions get diluted; keep to what's specific
  • Instructions that contradict the linter config
  • Forgetting the test command: agents can't check their own work

✓ Tips & Best Practices

  • Ask Copilot to draft copilot-instructions.md from the repo, then edit it
  • Mirror the content in AGENTS.md so other AI tools benefit too
  • Review instruction files like code: they change behavior

Quick Summary
