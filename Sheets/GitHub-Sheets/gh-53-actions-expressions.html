The ${{ }} Language

Anything inside ${{ }} is an expression, evaluated by GitHub before the step runs; the result is pasted into the YAML as text. Expressions read contexts (Sheet 54), call functions (Sheet 55) and combine values with operators. In if: the wrapper is optional: if: github.ref == 'refs/heads/main' works as-is.

Evaluation Rules

  • Strings use single quotes; escape with ''
  • String comparison ignores case: 'ABC' == 'abc' is true
  • Missing properties evaluate to null, not an error
  • && / || return a value, enabling a && b || c as a ternary

Expressions in Practice

env:
  IS_MAIN: ${{ github.ref == 'refs/heads/main' }}    # 'true'/'false'
  TARGET: ${{ github.ref_name == 'main' && 'prod' || 'staging' }}
  RETRIES: ${{ inputs.retries || 3 }}                # default
jobs:
  deploy:
    if: github.event_name == 'push' && !contains(github.ref, 'wip')
    runs-on: ubuntu-latest
    steps:
      - if: ${{ !cancelled() && env.TARGET == 'prod' }}
        run: echo "Deploying to $TARGET"
      - run: echo "${{ 2 > 1 }} ${{ 'a' < 'b' }} ${{ null == '' }}"
        # → true true true
      - run: echo "${{ toJSON(github.event.commits.*.message) }}"

Code Explained

cond && 'a' || 'b' — ternary; breaks if 'a' is falsy
inputs.retries || 3 — fallback when empty
! at the start of if: — wrap in ${{ }} (YAML tag char)
.*.message — object filter: array of every commit message

In the Logs

  • Unrecognized named-value: 'secret' — typo in a context name (secrets)
  • Unexpected symbol: '"abc"' — double quotes inside ${{ }}; use single quotes

⚠ Common Mistakes

  • Writing if: !startsWith(...) without ${{ }}: YAML reads ! as a tag
  • if: ${{ inputs.flag }} == true — only part is an expression; the rest is a non-empty string, always truthy
  • Using ${{ }} to build shell code from user input (see Sheet 63)

✓ Tips & Best Practices

  • Wrap a whole condition in one ${{ }} or none at all
  • Keep if: conditions short; move complex logic into a step that writes an output
  • Debug any value with run: echo '${{ toJSON(x) }}'

Quick Summary

  • ${{ expr }} — evaluated before the step runs
  • 'single' quotes — string literals
  • a && b || c — inline conditional
  • if: — ${{ }} optional, except leading !
