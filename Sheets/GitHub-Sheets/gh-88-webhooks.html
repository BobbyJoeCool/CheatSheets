Getting Pushed Events

A webhook sends an HTTP POST to your URL whenever chosen events happen on a repo, org or app: pushes, PRs, issues, releases and dozens more. Each delivery carries a JSON payload and headers naming the event and a delivery ID. Set a secret and verify the X-Hub-Signature-256 HMAC on every request. Failed deliveries can be inspected and redelivered.

Webhook Facts

  • Respond with 2xx within 10 seconds; queue slow work
  • Payloads are capped at 25 MB
  • A ping event is sent when the hook is created

Who Can Do This

  • Role: Admin (repo hooks) · Org owner (org hooks)
  • Plan: Free
  • Repos: public and private

Verify the Signature (Node.js)

import crypto from "node:crypto";
import express from "express";

const app = express();
app.post("/github", express.raw({ type: "application/json" }), (req, res) => {
  const sig = req.get("X-Hub-Signature-256") ?? "";
  const mac = "sha256=" + crypto
    .createHmac("sha256", process.env.WEBHOOK_SECRET)
    .update(req.body)                       // raw bytes, not parsed JSON
    .digest("hex");
  const ok = sig.length === mac.length &&
    crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(mac));
  if (!ok) return res.status(401).end();

  const event = req.get("X-GitHub-Event");  // e.g. "pull_request"
  const body = JSON.parse(req.body);
  res.status(202).end();                    // answer fast…
  queue.add({ event, action: body.action, body });   // …work later
});

Code Explained

express.raw — HMAC must use the raw body
timingSafeEqual — avoid timing attacks
X-GitHub-Event + action — what happened
202 then queue — stay under the 10 s limit

⚠ Common Mistakes

  • Verifying the signature against re-serialized JSON: it never matches
  • Doing slow work before responding: timeouts and duplicate retries
  • Not handling duplicates: use X-GitHub-Delivery as an idempotency key

✓ Tips & Best Practices

  • Subscribe only to events you handle
  • Prefer a GitHub App's single webhook over many repo webhooks
  • Use Actions instead when the reaction can run inside GitHub
