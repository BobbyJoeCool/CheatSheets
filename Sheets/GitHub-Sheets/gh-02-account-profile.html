Your Identity on GitHub

Your username is your URL (github.com/you) and the name people @mention. Emails link commits to your account: a commit counts toward your profile only if its author email is a verified address on your account (or your noreply address). A profile README (a repo named exactly like your username) and pinned repositories make your profile a portfolio page.

Profile Facts

  • Changing your username breaks old profile links (repo links redirect)
  • Private contributions can show as anonymous counts
  • Keep email private: use ID+user@users.noreply.github.com

Who Can Do This

  • Role: account owner
  • Plan: Free
  • Repos: account-wide

Set Up a Strong Profile

  1. Settings → Public profile: name, bio, pronouns, company, links
  2. Settings → Emails: add + verify, tick Keep my email addresses private
  3. Set Git to your noreply address: git config --global user.email "ID+you@users.noreply.github.com"
  4. Create a repo named your-username with a README to get a profile README
  5. Profile → Customize your pins (up to 6 repos or gists)
  6. Set a status (emoji + text, optional busy flag)

⚠ Common Mistakes

  • Committing with a work or unverified email: commits don't link to you and the graph stays empty
  • Turning on Block command line pushes that expose my email without updating user.email: pushes get rejected
  • Renaming your account right before a job search: old links on your résumé 404

✓ Tips & Best Practices

  • Find your noreply address under Settings → Emails
  • Use the profile README for a short intro, current focus and contact links
  • Add topics to every pinned repo; they show as tags
