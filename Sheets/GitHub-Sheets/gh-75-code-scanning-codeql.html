Finding Bugs in Your Own Code

Code scanning analyzes source code and reports alerts in the Security tab and on PR diffs. CodeQL, GitHub's engine, treats code as data and runs security queries. Default setup turns it on with one click for supported languages; advanced setup commits a codeql.yml workflow you can customize. Third-party tools upload results as SARIF. Copilot Autofix suggests fixes for many alerts.

Scanning Facts

  • Default setup scans on push, PRs and weekly
  • Compiled languages may need build-mode: manual
  • Alerts can be dismissed: false positive, won't fix, used in tests

Who Can Do This

  • Role: Write (view) · Admin (enable)
  • Plan: Free for public; Code Security for private
  • Repos: public and private

Advanced Setup Workflow

# .github/workflows/codeql.yml
on:
  push: { branches: [main] }
  pull_request:
  schedule: [{ cron: "23 4 * * 1" }]
permissions: { contents: read, security-events: write }
jobs:
  analyze:
    runs-on: ubuntu-latest
    strategy:
      matrix: { language: [javascript-typescript, python, actions] }
    steps:
      - uses: actions/checkout@v6
      - uses: github/codeql-action/init@v4
        with:
          languages: ${{ matrix.language }}
          queries: security-extended
      - uses: github/codeql-action/analyze@v4

Code Explained

security-events: write — upload results
matrix language — one analysis per language
actions — scans your workflow files too
queries: — default, security-extended, security-and-quality
analyze — runs queries, uploads SARIF

⚠ Common Mistakes

  • Advanced setup copied once and never updated: new languages go unscanned
  • Dismissing real alerts as false positives to make the PR green
  • Running both default and advanced setup: default must be off for advanced

✓ Tips & Best Practices

  • Start with default setup; switch to advanced only when you need custom queries or builds
  • Turn on Copilot Autofix to get fix suggestions on PRs
  • Use code scanning merge protection rules to block PRs with new high alerts
