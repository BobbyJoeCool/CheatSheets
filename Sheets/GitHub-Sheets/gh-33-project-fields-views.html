Project Fields & Views

custom fields (text / number / date / single select / iteration) · group by · sort · slice by · filter syntax · saved views

Shaping the Data

Fields add your own columns: text, number, date, single select and iteration, alongside built-ins like Assignees, Labels, Milestone, Repository and Linked PRs. Views save a layout plus its filter, sort, group by, slice by and visible fields. Each view is a tab, so one project can serve triage, sprint and roadmap needs.

View Facts

  • Unsaved view changes show a dot on the tab; Save to keep
  • Filters use issue-search style syntax plus field names
  • Slice by adds a side panel to flip between values

Who Can Do This

  • Role: Write on the project
  • Plan: Free
  • Repos: public and private

Build a Sprint View

  1. + New field → Iteration, 2-week cycles
  2. + New view → Board
  3. Filter: iteration:@current -status:Done
  4. Group by Assignees or slice by Repository
  5. Show fields: Priority, Estimate, Linked PRs
  6. Save; rename the tab "Current sprint"

⚠ Common Mistakes

  • Editing a shared view without saving a copy: teammates lose their layout
  • Using text fields for things you'll group by: use single select
  • Grouping by a field with 40 values: unreadable boards

✓ Tips & Best Practices

  • Duplicate a view before big changes
  • Use Priority as single select with P0–P3, colored
  • field:value filters accept quotes for spaces
