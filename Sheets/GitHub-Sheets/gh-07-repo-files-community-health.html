Repo Files & Community Health

README · LICENSE · CONTRIBUTING · CODE_OF_CONDUCT · SECURITY.md · SUPPORT · .github repo defaults · community profile

Files GitHub Treats Specially

Certain files change how GitHub presents and runs your repo. A README renders on the Code tab; a LICENSE is detected and shown in the sidebar; CONTRIBUTING, CODE_OF_CONDUCT, SECURITY and SUPPORT are linked when people open issues and PRs. They can live in the root, docs/ or .github/, and an org-wide .github repository supplies defaults for every repo that lacks its own.

Community Profile

  • Insights → Community Standards checks which files exist
  • README lookup order: .github/, root, then docs/
  • The org .github repo must be public to supply defaults

Who Can Do This

  • Role: Write (to commit files)
  • Plan: Free
  • Repos: public and private

A Well-Furnished Repo

my-project/
├── README.md               # renders on the Code tab
├── LICENSE                 # detected → sidebar badge
├── CHANGELOG.md
├── .github/
│   ├── CODEOWNERS              # Sheet 16
│   ├── CONTRIBUTING.md         # linked on new issue / PR
│   ├── CODE_OF_CONDUCT.md
│   ├── SECURITY.md             # Security tab → policy
│   ├── SUPPORT.md
│   ├── FUNDING.yml             # Sponsor button (Sheet 37)
│   ├── ISSUE_TEMPLATE/         # Sheet 20
│   ├── pull_request_template.md  # Sheet 29
│   ├── dependabot.yml          # Sheet 74
│   └── workflows/              # Actions (Sheet 40)
└── docs/

octo-org/.github/           # ORG defaults for all repos
└── profile/README.md       # org profile page

Code Explained

.github/ — keeps the root tidy; GitHub looks here first
LICENSE — use the Add file → license template picker
SECURITY.md — tells reporters how to disclose privately
org .github repo — fallback health files for every repo
profile/README.md — the org's public landing page

⚠ Common Mistakes

  • No LICENSE on a public repo: people can view but not legally reuse your code
  • Private org .github repo: defaults silently don't apply
  • README with only a title: visitors (and recruiters) leave in seconds

✓ Tips & Best Practices

  • Put a screenshot or GIF near the top of the README
  • Relative links in README (docs/setup.md) work on GitHub and in clones
  • Use choosealicense.com to pick a license quickly

Quick Summary

  • README / LICENSE — rendered and detected
  • health files — linked from issues and PRs
  • .github/ — home for repo config
  • org .github repo — org-wide defaults
