Finding Code, Issues and Repos

The search bar accepts qualifiers that narrow results: repo:, org:, path:, language: and more. Code search understands exact strings, regular expressions in /slashes/, boolean AND/OR/NOT and symbol search for definitions. Issues, PRs, repos and users each have their own qualifiers (Sheet 23 covers issues). Code search requires being signed in.

Search Facts

  • Default search scope is the current repo or org when you're inside one
  • Code search covers default branches; files over ~350 KB aren't indexed
  • Save frequent searches in the search bar dropdown

Who Can Do This

  • Role: anyone signed in (code search)
  • Plan: Free
  • Repos: public + private you can read

Code Search Queries

# Exact phrase in one repo
repo:octo-org/shop "def charge("

# Language + path filters
org:octo-org language:python path:tests/ fixture

# Regex (slashes) and boolean logic
/sk_(live|test)_[A-Za-z0-9]{24}/ NOT path:*.md

# Symbol definitions
symbol:parse_invoice language:go

# Files by name or extension
path:**/Dockerfile FROM node
path:*.tf aws_s3_bucket

# Repositories
topic:cheatsheet stars:>50 pushed:>2026-01-01

Code Explained

"…" — exact text, including punctuation
/regex/ — RE2 syntax, case-sensitive by default
NOT path:*.md — exclude matches
symbol: — definitions, not usages
stars:>50 pushed:>date — repo filters

Code Qualifiers

QualifierMatches
repo: / org: / user:scope
path:file path glob (path:src/**/*.ts)
language:detected language
content:file contents only (not path)
is:archived / is:forkrepo state

⚠ Common Mistakes

  • Searching for secrets in public code and pasting what you find into issues: report privately instead
  • Forgetting the default scope: you're searching only this repo when you meant all of GitHub
  • Expecting non-default branches to show up in code search

✓ Tips & Best Practices

  • Click a result's symbol to see definitions and references across the repo
  • Bookmark search URLs: every query is in the ?q= parameter
  • Combine org: + path: to find every repo using a config pattern

Quick Summary

  • qualifiers — repo: org: path: language:
  • /regex/ and AND/OR/NOT — precise code search
  • symbol: — find definitions
  • repo qualifiers — stars, topics, dates
