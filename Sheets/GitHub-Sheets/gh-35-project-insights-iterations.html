Project Insights & Iterations

iteration field · breaks · current / next iteration filters · charts · burn-up · status updates · roadmap date fields

Sprints and Progress Charts

An iteration field splits time into repeating cycles (for example 2 weeks) with optional breaks for holidays; filters like @current, @next and @previous follow the calendar. Insights turn project data into charts (bar, column, line, stacked) such as burn up or items per assignee. Status updates post a dated on-track / at-risk / off-track note on the project.

Facts

  • Iteration length, start date and breaks are set on the field
  • Charts use the same filter syntax as views
  • Historical charts: org projects on Team / Enterprise

Who Can Do This

  • Role: Write on the project (charts, updates)
  • Plan: Free (historical insights: Team+)
  • Repos: public and private

Run a Sprint Rhythm

  1. Iteration field: 2 weeks, starting Monday; add breaks
  2. Board view filtered to iteration:@current
  3. Planning: move items from @next into @current
  4. Insights → New chart → Burn up, filtered to @current
  5. End of sprint: post a status update with highlights

⚠ Common Mistakes

  • Changing iteration length mid-sprint: dates and filters shift for everyone
  • Charts without filters: closed history drowns the signal
  • Status updates written only when things go wrong

✓ Tips & Best Practices

  • Use breaks for holidays so velocity stays comparable
  • Roadmap view + iteration field shows sprints as columns
  • Pin the burn-up chart link in the team channel

Quick Summary

  • @current / @next — calendar-aware filters
  • insights — charts from project data
