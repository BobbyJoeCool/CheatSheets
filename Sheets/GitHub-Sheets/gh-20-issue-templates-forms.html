Issue Templates & Forms

.github/ISSUE_TEMPLATE/ · Markdown templates · YAML issue forms · input / textarea / dropdown / checkboxes · config.yml · contact links

Better Bug Reports by Design

Files in .github/ISSUE_TEMPLATE/ give people a menu of issue types when they click New issue. Markdown templates pre-fill the body; issue forms (YAML) render real form fields (text inputs, dropdowns, checkboxes) with validation, then post the answers as Markdown. A config.yml can turn off blank issues and add contact links to docs or Discussions.

Form Facts

  • Templates must be on the default branch
  • Forms can preset labels, assignees, type and projects
  • Org .github repo templates apply to repos without their own

Who Can Do This

  • Role: Write (add templates)
  • Plan: Free
  • Repos: public and private

An Issue Form

# .github/ISSUE_TEMPLATE/bug.yml
name: Bug report
description: Something isn't working
labels: [needs-triage]
type: Bug
body:
  - type: input
    id: version
    attributes: { label: Version, placeholder: "1.4.0" }
    validations: { required: true }
  - type: dropdown
    attributes: { label: OS, options: [macOS, Windows, Linux] }
  - type: textarea
    attributes: { label: Steps to reproduce, render: shell }
  - type: checkboxes
    id: terms
    attributes:
      label: Checks
      options: [{ label: Searched issues, required: true }]

Code Explained

name / description — shown in the chooser
type: Bug — sets the issue type (org types)
input / textarea / dropdown / checkboxes — fields
render: shell — wrap answer in a code block
validations.required — can't submit without it

TypeRenders

⚠ Common Mistakes

  • Adding templates on a feature branch and wondering why they don't appear
  • Required fields for everything: people give up and open blank issues
  • Duplicate id values in one form: the form fails to load

✓ Tips & Best Practices

  • Add a markdown block at the top linking to docs and FAQs
  • Route questions to Discussions with a contact link
  • Pair a form's labels with an auto-triage workflow

Quick Summary

  • .github/ISSUE_TEMPLATE/ — template menu
  • YAML forms — fields + validation
  • config.yml — blank issues + contact links
  • URL params — prefilled issues
