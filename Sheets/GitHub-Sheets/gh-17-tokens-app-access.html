Access for Scripts and Third Parties

Tools that act for you need a credential. Fine-grained personal access tokens are limited to chosen repos and specific permissions with an expiry; classic PATs use broad scopes and should be avoided. GitHub Apps act as themselves with fine-grained permissions and short-lived tokens; OAuth apps act as you. Orgs can require approval for tokens and apps and enforce SAML SSO.

Token Facts

  • Tokens are shown once; store them in a secret manager
  • Orgs can block classic PATs or require approval for fine-grained ones
  • Leaked tokens on public GitHub are auto-revoked by secret scanning

Who Can Do This

  • Role: account owner · org owner (policies)
  • Plan: Free (SAML SSO: Enterprise)
  • Repos: account-wide

Create a Fine-Grained Token

  1. Settings → Developer settings → Personal access tokens → Fine-grained
  2. Generate new token; set a short expiration
  3. Resource owner: you or an org (may need approval)
  4. Only select repositories
  5. Grant the minimum permissions (e.g. Contents: Read)
  6. Store it in your password manager or CI secrets

Automate It

Short-lived App token inside Actions
- id: app
  uses: actions/create-github-app-token@v2
  with: { app-id: "${{ vars.APP_ID }}", private-key: "${{ secrets.APP_KEY }}" }
- run: gh api repos/OTHER-ORG/REPO --jq .full_name
  env: { GH_TOKEN: "${{ steps.app.outputs.token }}" }

⚠ Common Mistakes

  • Classic PAT with repo scope and no expiry in CI: one leak exposes every repo you can reach
  • Using your personal PAT for org automation: it breaks when you leave
  • Ignoring Authorize SSO on a token: org repos return 404

✓ Tips & Best Practices

  • Name tokens after where they're used; you'll know what to rotate
  • Review Settings → Applications and revoke apps you don't use
  • Prefer GitHub Apps for bots: they don't use a seat and tokens expire in an hour

Quick Summary

  • fine-grained PAT — scoped, expiring
  • classic PAT — avoid
  • GitHub App — bot identity, short tokens
  • org policies — approve and restrict
