Markdown, GitHub-Style

GitHub Flavored Markdown (GFM) extends CommonMark everywhere you write: READMEs, issues, PRs, comments, wikis and discussions. It adds tables, task lists, strikethrough and autolinks, plus GitHub-only features: alerts, #123 and @user references, Mermaid diagrams, math, collapsible <details> sections and rendered GeoJSON/STL files.

Rendering Notes

  • Comments and READMEs share the renderer; .md files in repos too
  • Task lists in issues track progress and can become sub-issues

Who Can Do This

  • Role: anyone who can comment or commit
  • Plan: Free
  • Repos: public and private

GitHub-Only Syntax

> [!NOTE]
> Useful information users should know.
> [!WARNING] …  [!TIP] …  [!CAUTION] …

- [x] Write tests
- [ ] Update docs  #42

⚠ Common Mistakes

  • No blank line after <summary>: the Markdown inside <details> renders as plain text
  • Linking to blob/main/... lines: they drift; use a permalink (y)
  • Using alerts inside other blocks (lists, tables): they only work as top-level blockquotes

✓ Tips & Best Practices

  • Paste a URL onto selected text to make a link instantly
  • Drag images into an issue comment to upload them; reuse the URL in READMEs
  • The Markdown set covers core syntax; this sheet is the GitHub layer
