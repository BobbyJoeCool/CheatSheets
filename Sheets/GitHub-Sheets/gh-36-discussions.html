Conversations That Aren't Tasks

Discussions is a forum inside a repo (or org) for questions, ideas, announcements and polls: things that don't need an owner or a close date. Each discussion lives in a category with a format: open-ended, Question & Answer (mark an answer), Announcement (only maintainers post) or Poll. Issues and discussions convert into each other.

Discussion Facts

  • Off by default: Settings → Features → Discussions
  • Category forms: .github/DISCUSSION_TEMPLATE/<slug>.yml
  • Org discussions are hosted by one repo you choose

Who Can Do This

  • Role: Read (post) · Triage (moderate, mark answers) · Admin (enable)
  • Plan: Free
  • Repos: public and private

Set Up Discussions

  1. Settings → General → Features → Discussions
  2. Edit categories: Q&A, Ideas, Announcements, Show and tell
  3. Pin a welcome post explaining what goes where
  4. Add a config.yml contact link sending questions here (Sheet 20)
  5. Convert support-style issues: issue sidebar → Convert to discussion

⚠ Common Mistakes

  • Turning on Discussions with no categories plan: it becomes a second issue tracker
  • Leaving Q&A unanswered: mark answers so search finds them
  • Announcements in an open category: replies bury them

✓ Tips & Best Practices

  • Spotlight up to 4 discussions at the top of the page
  • Use a discussion form to collect structured feature ideas
  • Search is:answered / is:unanswered to triage Q&A
