The GraphQL API

The GraphQL API has one endpoint, POST https://api.github.com/graphql, where you ask for exactly the fields you need, across related objects, in one request. It's the only API for some features, notably Projects. Every object has a global node ID; lists use cursor pagination (first, after, pageInfo). Limits are counted in points per hour, not requests.

GraphQL Facts

  • 5,000 points / hour for users; query cost shown via rateLimit
  • first / last max 100 per connection
  • Try queries in the Explorer on docs.github.com

Who Can Do This

  • Role: token with the needed permissions
  • Plan: Free
  • Repos: public and private

Query, Paginate, Mutate

# Open PRs with review state and checks — one request
query($owner: String!, $repo: String!, $cursor: String) {
  repository(owner: $owner, name: $repo) {
    pullRequests(states: OPEN, first: 50, after: $cursor) {
      pageInfo { hasNextPage endCursor }
      nodes {
        number title reviewDecision
        author { login }
        commits(last: 1) { nodes { commit { statusCheckRollup { state } } } }
      }
    }
  }
  rateLimit { cost remaining resetAt }
}

# Mutation: comment on an issue or PR by node ID
mutation { addComment(input: { subjectId: "I_kwDOAB12", body: "Thanks!" }) {
  commentEdge { node { url } } } }

Code Explained

$cursor + pageInfo.endCursor — next page
reviewDecision / statusCheckRollup — data REST spreads over calls
rateLimit { cost } — what this query cost
node IDs (I_kw…) — used by mutations

⚠ Common Mistakes

  • Asking for first: 100 at several nesting levels: cost multiplies fast
  • Using REST numeric IDs in mutations: GraphQL wants node IDs
  • Ignoring errors in a 200 response: GraphQL reports failures in the body

✓ Tips & Best Practices

  • Get a node ID from REST: every object has a node_id field
  • Use variables, not string concatenation, for inputs
  • Ask only for fields you use; it's faster and cheaper

Quick Summary

  • one endpoint — POST /graphql
  • select exactly the fields you need
  • cursor pagination — first / after
  • points-based limits — check rateLimit
