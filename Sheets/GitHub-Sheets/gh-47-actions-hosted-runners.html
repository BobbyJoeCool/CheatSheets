Sheet 47

Actions: GitHub-Hosted Runners

ubuntu-latest · windows-latest · macos-latest · ubuntu-24.04-arm · larger runners · billing

Machines GitHub Runs for You

A GitHub-hosted runner is a fresh VM created for one job and destroyed afterward. You pick it with a label in runs-on:. Images come with a large preinstalled toolset (Git, Docker on Linux, Node, Python, Java, compilers, cloud CLIs), and the -latest labels move to new OS versions over time. Paid larger runners add more CPU, RAM, GPUs or static IPs.

Runner Facts

  • Standard Linux runner: 4 vCPU / 16 GB on public repos, 2 vCPU / 7 GB on private
  • Private-repo minutes cost more on Windows (≈2×) and macOS (≈10×) than Linux
  • -latest labels switch images gradually; pin ubuntu-24.04 when you need stability
  • Each job has passwordless sudo on Linux/macOS
  • Installed software list: the runner-images repo, linked from each job's Set up job log

Picking Runners

jobs:
  linux:
    runs-on: ubuntu-latest          # x64
    steps:
      - run: echo "$RUNNER_OS $RUNNER_ARCH"   # Linux X64
  arm:
    runs-on: ubuntu-24.04-arm       # native ARM64
    steps: [{ run: uname -m }]      # aarch64
  windows:
    runs-on: windows-latest
    steps: [{ run: "Get-ChildItem env:" }]  # shell: pwsh
  mac:
    runs-on: macos-latest           # Apple silicon
    steps: [{ run: xcodebuild -version }]
  big:
    runs-on: ubuntu-latest-16-core  # larger runner (org setup)
    steps: [{ run: nproc }]

Code Explained

ubuntu-latest — cheapest, fastest to start; default choice
ubuntu-24.04-arm — native ARM builds, no QEMU
windows-latest — default shell is PowerShell Core
macos-latest — needed for iOS/macOS builds; 10× minutes
Larger runner labels are names you set in org settings

In the Logs

  • Waiting for a runner to pick up this job... for a long time — the label doesn't exist (typo, or a larger runner not set up) or you hit the concurrency limit
  • Set up job → Runner Image shows the exact image version used

⚠ Common Mistakes

  • Running macOS for jobs that don't need it: 10× the minutes on private repos
  • Hard-coding /home/runner/work/...: use $GITHUB_WORKSPACE and $RUNNER_TEMP
  • Assuming a tool version: -latest image updates can change preinstalled versions; use setup-* actions

✓ Tips & Best Practices

  • Check usage under Settings → Billing → Usage; public repos on standard runners are free
  • Use ubuntu-24.04-arm to build ARM Docker images natively instead of emulating
  • Free up Linux disk space by deleting unused SDKs (/usr/share/dotnet, /opt/ghc) when builds run out

Quick Summary

  • runs-on: ubuntu-latest — default, 1× minutes
  • *-arm labels — native ARM64
  • windows 2× · macos 10× — private-repo minutes
  • larger runners — paid, custom labels
