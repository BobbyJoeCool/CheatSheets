Seeing How a Repo Is Used

The Insights tab collects graphs about activity: Pulse (the last day to month of PRs, issues and commits), Contributors, Traffic (views, clones, referrers, popular content for the last 14 days), Commits and Code frequency, plus the Dependency graph and Network. Traffic data is private to people with push access.

Insight Facts

  • Traffic history only covers 14 days; save it if you want trends
  • Contributors graph counts commits on the default branch
  • Org-level insights need Enterprise

Who Can Do This

  • Role: Read (Pulse, graphs) · Write (Traffic)
  • Plan: Free for public; Pro/Team for private
  • Repos: public and private (plan-dependent)

Check a Repo's Health

  1. Insights → Pulse: pick a period, scan merged PRs and open issues
  2. Contributors: who's active, commit trends
  3. Traffic: views, unique visitors, top referrers
  4. Commits / Code frequency: steady or stalled?
  5. Dependency graph: what you depend on (Sheet 73)
  6. Forks: who copied it and how active they are

⚠ Common Mistakes

  • Judging popularity from stars alone: check traffic and clones
  • Waiting a month to look at Traffic: anything older than 14 days is gone
  • Reading Contributors as 'who worked hardest': squash merges hide co-authors

✓ Tips & Best Practices

  • Schedule an Actions workflow to append traffic JSON to a file in the repo
  • Use Pulse for a weekly status update to your team
  • Add Co-authored-by: trailers so pair work shows up

Quick Summary

  • Pulse — recent activity summary
  • Traffic — 14 days of views/clones
  • Contributors / Commits — activity trends
  • Dependency graph / Network — structure
