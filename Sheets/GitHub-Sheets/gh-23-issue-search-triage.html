Finding and Triaging Issues

The issues list is a search box: is:issue is:open is just the default query. Combine qualifiers for state, labels, people, types, dates and relationships, and use AND, OR and parentheses for complex filters. Save frequent queries as views or bookmarks, and use saved replies to answer common reports quickly.

Search Facts

  • Space between qualifiers means AND
  • - before a qualifier negates it: -label:wontfix
  • @me works in author:, assignee:, mentions:

Who Can Do This

  • Role: Read
  • Plan: Free
  • Repos: public and private

Triage Queries

# Untriaged bugs nobody owns
is:issue is:open type:Bug no:assignee no:label

# My work across an org
org:octo-org is:open assignee:@me sort:updated-desc

# Stale issues
is:issue is:open updated:<2026-04-01 -label:pinned

# Boolean groups
is:issue is:open (label:p0 OR label:p1) -label:blocked

# Children of an epic, still open
parent-issue:octo-org/shop#120 is:open

# PRs waiting on my review
is:pr is:open review-requested:@me draft:false

Code Explained

no:assignee / no:label — missing metadata
sort:updated-desc — most recent activity first
updated:<date — untouched since
( … OR … ) — grouping
review-requested:@me — your review queue

⚠ Common Mistakes

  • Forgetting is:issue: PRs show up in the same results
  • Typing a bare word like bug when you meant label:bug: it searches text instead
  • Leaving triage to whoever notices: schedule it

✓ Tips & Best Practices

  • Bookmark query URLs; ?q= holds the whole search
  • Date ranges: created:2026-09-01..2026-09-30
  • Settings → Saved replies for "please add steps to reproduce"

Quick Summary

  • qualifiers — is: label: assignee: type:
  • - / no: — negate and find missing
  • AND / OR / ( ) — boolean logic
  • saved views + replies — faster triage
