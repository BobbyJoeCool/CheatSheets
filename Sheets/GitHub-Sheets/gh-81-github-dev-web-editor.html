Editing Without Cloning

Press . on any repo or PR and github.dev opens a lightweight VS Code in the browser, free and instant, with no compute behind it. You can browse, search, edit many files and commit to a new branch with a PR. For single files, the pencil icon edits right on github.com. When you need a terminal, run code or debug, switch to a codespace.

Limits

  • No terminal, no running code, no debugger
  • Only web-capable extensions work
  • Web uploads: 25 MB per file, 100 files at once

Who Can Do This

  • Role: Read (browse) · Write (commit) · fork for others' repos
  • Plan: Free
  • Repos: public and private

Fix a Typo Across Files

  1. On the repo, press . (or change github.com to github.dev)
  2. Search with Ctrl/⌘ Shift F; edit the files
  3. Source Control panel: review changes, write a message
  4. Commit & Push → choose Create a new branch
  5. Open the PR when prompted
  6. Need to run tests? Continue Working on → Create codespace

⚠ Common Mistakes

  • Committing straight to main from the web editor: choose a new branch
  • Expecting npm test to run: there's no compute
  • Uploading build artifacts through the web UI

✓ Tips & Best Practices

  • Great for doc fixes and reviewing big PRs with full-file context
  • Settings sync carries your theme and keybindings into github.dev
  • Rule of thumb: need to run it → codespace
