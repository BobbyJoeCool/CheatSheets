Building Integrations the Right Way

A GitHub App is an integration with its own identity, fine-grained permissions, event subscriptions and one webhook. It's installed on an account and chosen repos. To act, the app signs a short JWT with its private key, exchanges it for an installation access token (valid one hour) and calls the API as itself (my-app[bot]). Apps don't use a seat and survive people leaving.

App Facts

  • Permissions are requested up front; installers approve them
  • Installation tokens expire after 1 hour
  • Apps can be private or listed in the Marketplace

Who Can Do This

  • Role: account owner or Org owner (create, install)
  • Plan: Free
  • Repos: public and private

JWT → Installation Token

import { App } from "octokit";
const app = new App({
  appId: process.env.APP_ID,
  privateKey: process.env.APP_PRIVATE_KEY,     // PEM from app settings
  webhooks: { secret: process.env.WEBHOOK_SECRET },
});
// Act on one installation (JWT + token exchange handled for you)
const octokit = await app.getInstallationOctokit(INSTALLATION_ID);
await octokit.rest.issues.createComment({
  owner: "octo-org", repo: "shop", issue_number: 42,
  body: "Hi from my-app[bot]",
});
// React to events
app.webhooks.on("pull_request.opened", async ({ octokit, payload }) => {
  await octokit.rest.issues.addLabels({
    owner: payload.repository.owner.login,
    repo: payload.repository.name,
    issue_number: payload.number, labels: ["triage"] });
});

Code Explained

App — wraps JWT signing + token caching
getInstallationOctokit — client as the installation
webhooks.on — handler gets an authenticated client
private key — keep in a secret store, rotate if leaked

⚠ Common Mistakes

  • Requesting every permission "just in case": installers refuse, risk grows
  • Caching installation tokens past one hour
  • Committing the app's private key to a repo

✓ Tips & Best Practices

  • Create apps with a manifest for repeatable setup
  • Use Probot or Octokit's App to skip auth plumbing
  • Ask only for events you handle; it cuts webhook traffic

Quick Summary

  • GitHub App — own identity + permissions
  • JWT → installation token (1 hour)
  • one webhook, chosen events
  • best choice for bots and integrations
