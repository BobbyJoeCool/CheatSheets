The REST API

Nearly everything in the UI is available at https://api.github.com. Send a token in Authorization: Bearer, ask for application/vnd.github+json, and pin an API version with X-GitHub-Api-Version. Lists are paginated (per_page up to 100, follow the Link header). Watch your rate limit in the x-ratelimit-* headers, and use ETags to make cheap conditional requests.

Rate Limits

  • Unauthenticated: 60 requests / hour per IP
  • Authenticated user or PAT: 5,000 / hour
  • GITHUB_TOKEN in Actions: 1,000 / hour per repo

Who Can Do This

  • Role: depends on endpoint: token needs the matching permission
  • Plan: Free
  • Repos: public and private

curl Patterns

API=https://api.github.com
H=(-H "Authorization: Bearer $TOKEN"
   -H "Accept: application/vnd.github+json"
   -H "X-GitHub-Api-Version: 2022-11-28")

# Read
curl "${H[@]}" $API/repos/octo-org/shop
curl "${H[@]}" "$API/repos/octo-org/shop/issues?state=open&per_page=100&page=2"

# Write
curl "${H[@]}" -X POST $API/repos/octo-org/shop/issues \
  -d '{"title":"From the API","labels":["api"]}'

# Rate limit + conditional request
curl "${H[@]}" $API/rate_limit
curl "${H[@]}" -H 'If-None-Match: "a18c3bded88eb5dbb5c849a489412bf3"' \
  $API/repos/octo-org/shop -i      # 304 = unchanged, free

Code Explained

Accept + version header — stable responses
per_page / page — pagination; prefer the Link header
-d JSON — body for POST / PATCH / PUT
If-None-Match — 304s don't count toward limits

Status Codes

CodeMeans
200 / 201 / 204OK / created / no content

422validation failed

⚠ Common Mistakes

  • Reading 404 as "doesn't exist": private resources return 404 when you lack access
  • Looping pages without honoring Link or retry-after
  • Hitting the API in a tight loop: secondary rate limits kick in

✓ Tips & Best Practices

  • Use Octokit (@octokit/rest, PyGithub, go-github) instead of raw curl in code
  • In Actions, actions/github-script gives an authenticated Octokit
  • Docs list the fine-grained permission each endpoint needs

Quick Summary

  • api.github.com + Bearer token
  • version header — stable contract
  • pagination — per_page, Link
  • rate limits — headers, ETags, backoff
