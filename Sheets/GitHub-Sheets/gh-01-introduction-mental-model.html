What GitHub Adds to Git

Git is the version-control tool on your machine; GitHub is the hosted platform built around Git repositories. On top of storing repos it adds collaboration (Issues, Pull Requests, Discussions), planning (Projects), automation (Actions), hosting (Pages, Packages), security scanning, cloud dev environments (Codespaces) and AI help (Copilot). Everything belongs to an account: a personal user or an organization, optionally grouped under an enterprise.

Good to Know

  • Git commands live in the Git CLI set; this set is the platform
  • Repo URL shape: github.com/OWNER/REPO
  • Most features work on Free; plans add private-repo features and limits

Who Can Do This

  • Role: anyone with a GitHub account
  • Plan: Free
  • Repos: public and private

Getting Oriented

  1. Sign up at github.com and verify your email
  2. Turn on two-factor authentication (required to contribute code)
  3. Add an SSH key or sign in with HTTPS + a credential manager
  4. Create or fork a repository (Sheets 06, 11)
  5. Open an issue, push a branch, open a pull request
  6. Add a workflow in .github/workflows/ for CI (Sheet 40)

⚠ Common Mistakes

  • Treating GitHub as a backup of your machine: only what you commit and push is there
  • Building team work under a personal account: transfer to an org early
  • Assuming a doc screenshot matches your plan: many settings are plan-gated

✓ Tips & Best Practices

  • Create a free organization even for a solo portfolio; it separates projects from you
  • Press ? on any GitHub page to see its keyboard shortcuts
  • GitHub Docs pages show a plan badge saying who gets each feature
