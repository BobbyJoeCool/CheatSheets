Actions: Using Actions

uses: owner/repo@ref · with: · SHA pinning · ./local · docker:// · Marketplace

Reusable Steps

uses: runs an action: packaged code from a public repo (owner/repo@ref), a subfolder (owner/repo/path@ref), a local folder in your repo (./.github/actions/x) or a Docker image (docker://). Inputs go in with:; outputs come back on steps.<id>.outputs. The ref decides what code runs: a moving tag (v6), a fixed tag (v6.0.1) or a full commit SHA.

Picking Actions

  • Prefer actions/* and verified creators (✓ badge in the Marketplace)
  • Read action.yml for inputs, outputs and defaults
  • Local actions need actions/checkout first
  • Orgs can restrict which actions are allowed (Sheet 63)

Every Way to Reference an Action

steps:
  - uses: actions/checkout@v6                     # major tag (moves)
  - uses: actions/setup-node@v6.0.0               # exact tag
  - uses: actions/cache@<full-40-char-commit-sha>    # v5.0.0
  - uses: owner/monorepo/actions/lint@v2          # subfolder
  - uses: ./.github/actions/setup                 # local action
  - uses: docker://alpine:3.20                    # image
    with:
      args: echo hello
  - id: meta
    uses: docker/metadata-action@v5
    with:
      images: ghcr.io/${{ github.repository }}
      tags: type=semver,pattern={{version}}
  - run: echo "${{ steps.meta.outputs.tags }}"

Code Explained

@v6 — newest v6.x; easy, but the owner can move it
@<40-char SHA> — immutable; comment the version
./path — action in this repo (after checkout)
docker:// — runs the image; args is the command
id: + steps.<id>.outputs — read action outputs

Security Check

  • Risk: a compromised third-party action tag (as in the 2025 tj-actions/changed-files incident) runs malicious code with your secrets.
  • Fix: pin third-party actions to a full SHA, let Dependabot bump them, and keep permissions: minimal.

In the Logs

  • Unable to resolve action owner/repo@v9, unable to find version — tag doesn't exist or repo is private
  • Can't find 'action.yml' — local action used before checkout, or wrong path

Ref Choices

RefTrade-off
@v6auto patches; trusts the owner
@v6.0.1fixed until the tag is moved
@<sha>immutable; needs update tooling
@mainnever: changes on every commit

Everyday Actions

⚠ Common Mistakes

  • Using @main or @master: every upstream commit runs in your pipeline unreviewed
  • Passing inputs as env: to an action: actions read with: (as INPUT_* vars)
  • Pinning a SHA from a fork instead of the original repo

✓ Tips & Best Practices

  • Add a github-actions entry to .github/dependabot.yml to get PRs for action updates
  • Tools like pinact or ratchet convert tags to SHAs in bulk
  • Check an action's runs.using:; node20 actions show deprecation warnings

Quick Summary

  • uses: owner/repo@ref — run an action
  • with: — inputs · steps.id.outputs — outputs
  • ./path / docker:// — local or image actions
  • full SHA — safest pin for third-party code
