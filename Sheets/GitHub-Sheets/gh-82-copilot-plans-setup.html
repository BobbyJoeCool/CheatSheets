Copilot on GitHub

GitHub Copilot adds AI help across GitHub: code completion and chat in editors, chat on github.com, code review, PR summaries and the coding agent. Individuals use Free, Pro or Pro+; organizations buy Business or Enterprise seats and control features with policies. Advanced models and agent work use premium requests, with a monthly allowance per plan.

Plan Facts

  • Free has limited completions and chat each month
  • Students, teachers and popular OSS maintainers may get Pro free
  • Orgs can exclude files from Copilot (content exclusion)

Who Can Do This

  • Role: account owner · Org owner (seats, policies)
  • Plan: Free / Pro / Pro+ / Business / Enterprise
  • Repos: public and private

Set Up Copilot

  1. Settings → Copilot: pick a plan (or accept an org seat)
  2. Install the Copilot extension in your editor; sign in
  3. Choose features and models in Settings → Copilot → Features
  4. Org: Org Settings → Copilot → Access to assign seats
  5. Org: Policies for models, coding agent, code review
  6. Org: Content exclusion for sensitive paths

⚠ Common Mistakes

  • Assuming org code is used to train models: Business/Enterprise data isn't used for training
  • Leaving premium-request budgets unset: overages surprise you
  • Using Copilot on repos with secrets in plain files: add content exclusions

✓ Tips & Best Practices

  • Check plan prices and allowances on the Copilot plans page; they change
  • Set a budget for premium requests under Billing
  • Give the org a short copilot-instructions.md per repo (Sheet 83)
