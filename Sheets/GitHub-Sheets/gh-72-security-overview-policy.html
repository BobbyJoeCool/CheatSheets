Security Overview & Policy

Security tab · SECURITY.md · private vulnerability reporting · security configurations · GitHub Advanced Security (Secret Protection / Code Security)

The Security Toolbox

The Security tab gathers a repo's security policy, advisories and alerts from Dependabot, code scanning and secret scanning. Public repos get these tools free. Private repos need the paid GitHub Advanced Security products: Secret Protection (secret scanning, push protection) and Code Security (code scanning, Copilot Autofix, dependency review). Orgs roll settings out with security configurations.

Free on Every Repo

  • Dependency graph + Dependabot alerts and updates
  • Private vulnerability reporting + advisories
  • Public repos: secret scanning, push protection, CodeQL too

Who Can Do This

  • Role: Admin (repo) · Org owner / security manager (org)
  • Plan: Free for public; Secret Protection / Code Security for private
  • Repos: public and private

Baseline for Any Repo

  1. Add a SECURITY.md with how to report privately
  2. Settings → Advanced Security: enable Private vulnerability reporting
  3. Enable Dependabot alerts + security updates
  4. Enable secret scanning + push protection
  5. Enable code scanning → Default setup
  6. Orgs: Org Settings → Advanced Security → Configurations → apply to all repos

⚠ Common Mistakes

  • No SECURITY.md: reporters open public issues with exploit details
  • Turning on alerts and never triaging them: alert fatigue wins
  • Configuring each repo by hand in an org: use security configurations

✓ Tips & Best Practices

  • Start with the GitHub-recommended configuration, then tune
  • Assign a security manager team so someone owns alerts
  • Review the org Security overview monthly
