AI Review on Pull Requests

Request Copilot as a reviewer and it leaves review comments, often with suggested changes you can commit. It always submits as Comment: it never approves or blocks, so it doesn't count toward required reviews. A ruleset can request Copilot review automatically on every PR. Copilot can also write a PR summary into the description.

Review Facts

  • Reads copilot-instructions.md for your conventions
  • Re-request after new pushes for another pass
  • Each review uses premium requests

Who Can Do This

  • Role: Write (request) · Admin (automatic review rule)
  • Plan: Copilot plan with code review
  • Repos: public and private

Use Copilot Review Well

  1. PR → Reviewers → Copilot
  2. Read comments; Commit suggestion for good ones
  3. Resolve or reply to false alarms (👎 helps tune)
  4. Ruleset → Automatically request Copilot code review
  5. PR description → Copilot ✦ → Summary to draft the body
  6. Keep human review required for merging

⚠ Common Mistakes

  • Treating Copilot's review as the required approval: it can't be
  • Committing every suggestion without testing
  • Ignoring repeated false positives instead of adding instructions

✓ Tips & Best Practices

  • Ask for Copilot review on drafts to catch nits before people look
  • Add review-focused rules ("flag missing tests") to instructions
  • Summaries are a starting point; edit for the why
