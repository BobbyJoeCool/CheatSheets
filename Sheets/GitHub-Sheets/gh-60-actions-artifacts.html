Actions: Artifacts

upload-artifact · download-artifact · retention-days · immutable · cache vs artifact

Files That Outlive the Job

An artifact is a set of files uploaded from a job and stored with the run: build output, test reports, coverage, logs. Other jobs in the same run download it with actions/download-artifact, and people download it from the run page or with gh run download. Artifacts are for passing results; caches are for speeding up inputs.

Artifact Rules

  • Names must be unique per run; artifacts are immutable (no appending)
  • Default retention 90 days (or the repo setting); retention-days 1–90
  • Downloads are zip files from the UI; extracted in workflows
  • Hidden files are excluded by default (include-hidden-files)

Build Once, Use Twice

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
      - run: npm ci && npm run build
      - uses: actions/upload-artifact@v7
        with:
          name: dist
          path: dist/
          retention-days: 7
          if-no-files-found: error
  e2e:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/download-artifact@v8
        with: { name: dist, path: dist }
      - run: npx playwright test
      - if: failure()
        uses: actions/upload-artifact@v7
        with: { name: playwright-report, path: playwright-report/ }

Code Explained

name — key other jobs and people use
path — file, folder, glob or multiline list
if-no-files-found: error — fail instead of warn
download-artifact — omit name to fetch all
if: failure() — upload reports only when tests fail

Security Check

  • Risk: artifacts from PR runs are built from untrusted code; a privileged workflow_run job that downloads and executes them runs attacker code.
  • Fix: treat downloaded artifacts as data; never source scripts from them in jobs that hold secrets.

In the Logs

  • No files were found with the provided path: dist/. No artifacts will be uploaded. — wrong path or the build didn't run
  • Failed to CreateArtifact: ... an artifact with this name already exists — matrix jobs need unique names, e.g. dist-${{ matrix.os }}

⚠ Common Mistakes

  • Same artifact name from every matrix job: v4+ rejects duplicates; add the matrix value to name
  • Mixing major versions of upload and download actions across jobs
  • Using artifacts as a cache: they don't cross runs automatically and cost storage

✓ Tips & Best Practices

  • Merge many small artifacts with pattern: + merge-multiple: true on download
  • Short retention-days (1–7) for intermediate build output keeps storage costs low
  • gh run download <run-id> -n dist fetches one artifact locally

Quick Summary

  • upload-artifact — save files from a job
  • download-artifact — get them in a later job
  • immutable + unique names per run
  • artifact = results · cache = inputs
