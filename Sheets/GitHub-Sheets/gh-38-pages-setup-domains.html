Hosting a Site From a Repo

GitHub Pages serves static sites from a repo. A user/org site comes from a repo named USERNAME.github.io; any other repo is a project site at USERNAME.github.io/REPO. The source is either a branch + folder (/ or /docs) or a GitHub Actions workflow. You can add a custom domain with DNS records and force HTTPS.

Pages Facts

  • Private-repo Pages need Pro, Team or Enterprise
  • Published sites are public (unless Enterprise private Pages)
  • Verify your domain to stop takeovers

Who Can Do This

  • Role: Admin (configure) · Write (publish content)
  • Plan: Free for public; Pro/Team+ for private repos
  • Repos: public (private with paid plans)

DNS for a Custom Domain

# Apex domain (example.com) — A records
example.com.      A      185.199.108.153
example.com.      A      185.199.109.153
example.com.      A      185.199.110.153
example.com.      A      185.199.111.153
# IPv6 (optional)
example.com.      AAAA   2606:50c0:8000::153   (…8001…8003::153)

# Subdomain (www.example.com) — CNAME
www.example.com.  CNAME  octocat.github.io.

# Domain verification (Settings → Pages → Verified domains)
_github-pages-challenge-octocat.example.com.  TXT  "abc123…"

Code Explained

four A records — GitHub's Pages IPs for apex domains
CNAME — subdomain points to USERNAME.github.io
TXT challenge — proves you own the domain
then Settings → Pages → Custom domain → Enforce HTTPS

⚠ Common Mistakes

  • Adding the custom domain in Settings before DNS is set: HTTPS cert can't be issued
  • Leaving a dangling CNAME after deleting the site: domain takeover risk; verify domains
  • Using a branch source and an Actions workflow at once: pick one

✓ Tips & Best Practices

  • Use a subdomain (www or docs) with CNAME; it's simpler than apex records
  • With the Actions source, set the domain in Settings; no CNAME file needed
  • dig example.com +noall +answer checks your records

Quick Summary

  • USERNAME.github.io — user site
  • branch or Actions — two sources
  • A / AAAA / CNAME — custom domain
  • verify + Enforce HTTPS — secure it
