Spring Boot, Kotlin & Android Plugins

org.springframework.boot · bootRun / bootJar · platform() vs dependency-management · kotlin("jvm") · com.android.application · AGP pairing

Framework Plugins

Frameworks ship Gradle plugins that add their own tasks and conventions. The Spring Boot plugin builds an executable bootJar and runs the app with bootRun; the Kotlin plugin compiles Kotlin and adds compiler plugins like plugin.spring. The Android Gradle Plugin (AGP) replaces the java plugin entirely and must be paired with a supported Gradle version. This sheet covers the build side only; see the Spring set for Spring itself.

Version Pairing (Oct 2026)

  • AGP 9.4 needs Gradle 9.6+ and JDK 17
  • AGP 9 compiles Kotlin itself (built-in Kotlin) — no kotlin-android plugin
  • Gradle 9 needs Kotlin Gradle Plugin 2.0+, AGP 8.4+
  • Spring Boot 4 supports Gradle 9; check its docs for the minimum

Spring Boot + Kotlin

import org.springframework.boot.gradle.plugin.SpringBootPlugin

plugins {
    id("org.springframework.boot") version "4.1.0"
    kotlin("jvm") version "2.2.20"
    kotlin("plugin.spring") version "2.2.20"   // opens Spring classes
}
dependencies {
    implementation(platform(SpringBootPlugin.BOM_COORDINATES))
    implementation("org.springframework.boot:spring-boot-starter-web")
    testImplementation("org.springframework.boot:spring-boot-starter-test")
}
kotlin { jvmToolchain(21) }
tasks.bootJar { archiveFileName = "app.jar" }  // build/libs/app.jar

Code Explained

org.springframework.boot — adds bootJar, bootRun
kotlin("plugin.spring") — makes Spring beans open
platform(BOM_COORDINATES) — Boot's versions without the extra plugin
Starters need no version once the BOM is imported
jvmToolchain(21) — Kotlin shortcut for a Java toolchain

In Groovy DSL

kotlin("jvm") version "…" → id 'org.jetbrains.kotlin.jvm' version '…'
kotlin("plugin.spring") → id 'org.jetbrains.kotlin.plugin.spring'
tasks.bootJar { } → tasks.named('bootJar') { }

Java vs Kotlin Projects

Java — drop the Kotlin plugins; java { toolchain { … } } replaces jvmToolchain
Kotlin — add kotlin("plugin.jpa") for no-arg @Entity classes
Kotlin — add jackson-module-kotlin for data-class JSON

⚠ Common Mistakes

  • Applying both io.spring.dependency-management and platform() — two mechanisms fighting; pick one (platform() is native)
  • Upgrading AGP without upgrading Gradle — AGP checks the Gradle version and fails
  • Keeping kotlin-android with AGP 9 — it clashes with built-in Kotlin

✓ Tips & Best Practices

  • Boot also builds a -plain.jar; turn it off with tasks.jar { enabled = false }
  • Let Android Studio's AGP Upgrade Assistant bump AGP and Gradle together
  • Keep Kotlin plugin versions in the catalog so all kotlin(…) plugins match

Quick Summary

  • bootJar / bootRun — Spring Boot build
  • kotlin("jvm") — Kotlin compilation
  • com.android.application — Android (AGP)
  • Pair AGP with its minimum Gradle version
