Application Plugin & JARs

application plugin · mainClass · ./gradlew run · jar task · manifest attributes · distZip / installDist · fat JARs (Shadow)

Shipping an App

The application plugin adds a run task, start scripts and ZIP/TAR distributions that bundle your JAR with its dependencies in lib/. A plain jar contains only your classes, so java -jar fails unless every dependency is on the classpath. For one self-contained file, use the Shadow plugin to build a fat JAR.

Notes

  • Archives are reproducible by default in Gradle 9 (fixed order and timestamps)
  • JAR name: <project>-<version>.jar in build/libs/
  • installDist output: build/install/<app>/bin/<app>

Runnable App + Fat JAR

plugins {
    application
    id("com.gradleup.shadow") version "9.0.0"
}
application {
    mainClass = "com.example.App"
    applicationDefaultJvmArgs = listOf("-Xmx512m")
}
tasks.jar {
    manifest {
        attributes("Main-Class" to "com.example.App",
                   "Implementation-Version" to project.version)
    }
}
tasks.shadowJar {
    archiveClassifier = "all"          // build/libs/app-1.0-all.jar
    mergeServiceFiles()                // merge META-INF/services
}

Code Explained

mainClass — the class with main() used by run and scripts
applicationDefaultJvmArgs — baked into the start scripts
manifest { attributes } — entries in META-INF/MANIFEST.MF
shadowJar — classes + all runtime dependencies in one JAR
mergeServiceFiles() — keeps ServiceLoader files from clashing

In Groovy DSL

listOf("-Xmx512m") → ['-Xmx512m']
attributes("Main-Class" to "…") → attributes('Main-Class': '…')
tasks.jar { } → tasks.named('jar') { }

Java vs Kotlin Projects

Java — mainClass = "com.example.App", the class with main()
Kotlin — top-level fun main() in App.kt → mainClass = "com.example.AppKt"
Kotlin — shadowJar also bundles kotlin-stdlib

Running It

./gradlew run --debug-jvmWait for a debugger on 5005

⚠ Common Mistakes

  • Running java -jar on the plain JAR — NoClassDefFoundError, because dependencies aren't inside it
  • Reading System.in under ./gradlew run — set standardInput = System.in on the run task
  • Using the old com.github.johnrengelman.shadow id — use com.gradleup.shadow

✓ Tips & Best Practices

  • Prefer installDist + lib/ folder over a fat JAR when libraries need signing
  • Use relocate("com.google", "shadow.google") in a shaded library to avoid clashes
  • Set version in gradle.properties so CI can override it with -Pversion=

Quick Summary

  • application { mainClass } — make it runnable
  • ./gradlew run — run from the build
  • installDist / distZip — ship with start scripts
  • shadowJar — one fat JAR
