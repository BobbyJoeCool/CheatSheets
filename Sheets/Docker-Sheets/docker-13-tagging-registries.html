Sharing Images

To push, an image needs a name that includes where it goes: registry-host/namespace/repo:tag. docker tag adds that name (it doesn't copy anything), docker login stores credentials, and docker push uploads only the layers the registry doesn't already have. With no host in the name, Docker assumes Docker Hub (docker.io).

Notes

  • One image can carry many tags: 1.4.2, 1.4, 1, latest
  • Docker Hub free accounts have pull rate limits; log in to raise them
  • Use access tokens, not passwords, for docker login

Tag, Log In, Push

docker tag myapp:dev myuser/myapp:1.4.2           # Docker Hub
docker tag myapp:dev myuser/myapp:latest
docker login                                      # Docker Hub (browser login)
docker push myuser/myapp:1.4.2
docker push -a myuser/myapp                       # all local tags of the repo

# GitHub Container Registry
echo "$GH_TOKEN" | docker login ghcr.io -u octocat --password-stdin
docker tag myapp:dev ghcr.io/acme/myapp:1.4.2
docker push ghcr.io/acme/myapp:1.4.2

# Local private registry
docker run -d -p 5000:5000 --name registry registry:2
docker tag myapp:dev localhost:5000/myapp:1.4.2
docker push localhost:5000/myapp:1.4.2
docker logout ghcr.io

Notes

--password-stdin keeps tokens out of shell history and ps
push -a pushes every tag of that repository
localhost:5000 is trusted over HTTP; other hosts need TLS or insecure-registries in daemon.json
Multi-arch pushes use docker buildx build --push (Sheet 18)

⚠ Common Mistakes

  • docker push myapp:1.0 with no namespace — Hub denies it; tag as user/myapp:1.0
  • Pushing only latest — you can't roll back; push a version tag too
  • Pushing an arm64-only image from a Mac to amd64 servers — exec format error; build multi-platform
  • Pasting tokens with -p — they land in shell history; use --password-stdin

✓ Tips & Best Practices

  • Tag with the git SHA as well as semver for exact traceability
  • Use docker manifest inspect or buildx imagetools inspect to see which platforms a tag has
  • Credential helpers (docker-credential-ecr-login, gcloud) refresh short-lived tokens for you
  • Set a registry-mirrors cache in daemon.json to dodge Hub rate limits in CI

Quick Summary

  • tag src dst — add a name, no copy
  • login / push — authenticate, upload
  • host/ns/repo:tag — where it goes
  • registry:2 — run your own registry
