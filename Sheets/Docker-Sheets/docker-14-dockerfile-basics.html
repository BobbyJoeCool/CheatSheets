Dockerfile Basics

FROM · RUN · COPY vs ADD · WORKDIR · EXPOSE · CMD vs ENTRYPOINT · exec vs shell form · .dockerignore

The Recipe

A Dockerfile is a list of instructions run top to bottom to build an image. FROM picks a base image, RUN, COPY and ADD create new layers, and CMD/ENTRYPOINT set what runs when a container starts. Each layer is cached, so the order of instructions decides how fast rebuilds are (Sheet 17).

Notes

  • File is named Dockerfile (no extension) by convention
  • # comments only at the start of a line; \ continues one
  • The build context is the folder you pass to docker build

A Complete Node.js Dockerfile

FROM node:22-alpine
WORKDIR /app
# Dependencies first, so this layer stays cached
COPY package.json package-lock.json ./
RUN npm ci --omit=dev
# Then the source (filtered by .dockerignore)
COPY . .
# Documents the port; you still need -p to publish
EXPOSE 3000
USER node
# Exec form: node runs as PID 1
CMD ["node", "server.js"]

RUN apt-get install -y curlShell form fine for RUN

COPY vs ADD

InstructionDoes
COPY src destCopy files from the build context
COPY --chown=node:node . .Copy and set owner
COPY --from=build /out /appCopy from another stage (Sheet 17)
ADD app.tar.gz /opt/Copies and extracts local tar files

⚠ Common Mistakes

  • Shell-form CMD node app.js — sh becomes PID 1 and swallows SIGTERM, so stops take 10 s
  • No .dockerignore — node_modules, .git and .env get sent and baked into the image
  • RUN cd /app — each RUN is a new shell; use WORKDIR /app instead
  • EXPOSE doesn't publish anything — you still need -p on docker run

✓ Tips & Best Practices

  • Use COPY unless you need tar extraction; ADD's magic surprises people
  • Copy dependency manifests first, install, then copy source to keep the install layer cached
  • ENTRYPOINT for the fixed program, CMD for default arguments users can override
  • Run docker init to generate a starter Dockerfile + .dockerignore for your language

Quick Summary

  • FROM — base image
  • RUN / COPY — build steps, one layer each
  • CMD vs ENTRYPOINT — default args vs fixed program
  • .dockerignore — keep junk out of the context
