Sheet 07

Running Containers

docker run · -d · -it · --rm · --name · -e / --env-file · -w · --entrypoint

docker run

docker run = create + start in one step: it pulls the image if needed, creates a container with your options, then starts its main process. Everything after the image name replaces the image's default command (CMD). Options always go before the image name; arguments for the app go after it.

Shape of the Command

  • docker run [OPTIONS] IMAGE[:TAG] [COMMAND] [ARG...]
  • No tag = :latest, which is just a tag name, not "newest"
  • docker create + docker start split the two steps
  • Container exits when its main process (PID 1) exits

Common Patterns

docker run -d --name web -p 8080:80 nginx:1.27       # background service
docker run --rm -it ubuntu:24.04 bash                # interactive, auto-delete
docker run --rm alpine echo "hi"                     # override CMD: prints hi
docker run --rm -e TZ=UTC -e DEBUG=1 alpine env      # set env vars
docker run --rm --env-file .env myapp                # env vars from a file
docker run --rm -w /src -v "$PWD":/src node:22 npm test  # workdir + mount
docker run --rm --entrypoint sh myapp -c 'ls /app'   # new ENTRYPOINT
docker run -d --name db -e POSTGRES_PASSWORD=dev \
  -v pgdata:/var/lib/postgresql/data postgres:17     # named volume
docker run --rm --network host nginx                 # host network (Linux)

Code Explained

-d — detached: runs in background, prints the container ID
-it — -i keeps stdin open + -t allocates a terminal; use both for shells
--rm — delete the container when it exits
--name — fixed name instead of a random one like jolly_turing
-w — working directory inside the container
--entrypoint — replaces the image's ENTRYPOINT; args after the image go to it

⚠ Common Mistakes

  • Putting options after the image — docker run nginx -p 80:80 passes -p to nginx, not Docker
  • Using -it in scripts or CI — no TTY there; drop -t or the command fails
  • Expecting docker run to reuse a container — it always makes a new one; use docker start to restart
  • Name conflicts — --name web fails if a stopped web exists; docker rm web or add --rm

✓ Tips & Best Practices

  • Pin tags (nginx:1.27) instead of latest for repeatable results
  • Use --env-file for many variables and keep secrets out of shell history
  • Detach from -it without stopping: press Ctrl-P Ctrl-Q
  • docker run --init adds a tiny init so signals and zombies are handled (Sheet 11)

Quick Summary

  • -d / -it — background vs interactive
  • --rm — auto-delete on exit
  • -e / --env-file — environment variables
  • IMAGE CMD args — args after the image replace CMD
