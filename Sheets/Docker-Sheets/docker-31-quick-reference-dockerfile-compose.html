⚠ Common Mistakes

  • Inline # comments after Dockerfile instructions aren't comments
  • depends_on without a condition doesn't wait for readiness
  • .env feeds ${…}, not containers

✓ Tips & Best Practices

  • Exec-form CMD ["…"] so signals reach the app
  • Quote ports and decimals in YAML
  • docker compose config shows what will run

Quick Summary

  • Dockerfile — build recipe
  • compose.yaml — multi-container app
  • Every run flag has a Compose key
