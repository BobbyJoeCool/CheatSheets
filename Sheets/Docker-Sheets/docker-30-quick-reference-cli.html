⚠ Common Mistakes

  • Options after the image name go to the app, not Docker
  • prune -a --volumes deletes unused data volumes
  • localhost in a container is the container itself

✓ Tips & Best Practices

  • Most commands accept a unique ID prefix
  • Add --format json (or a Go template) for scripting
  • docker <cmd> --help lists every flag

Quick Summary

  • run / exec / logs — daily trio
  • build / push — ship images
  • system df / prune — keep disks clean
