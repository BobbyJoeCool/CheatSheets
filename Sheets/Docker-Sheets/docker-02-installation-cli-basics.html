Getting Docker

On macOS and Windows, install Docker Desktop: it bundles the engine (inside a lightweight VM), CLI, Compose, Buildx and a GUI (Sheets 04–06). On Linux servers, install Docker Engine (docker-ce) from Docker's own apt/dnf repository; distro packages such as docker.io are often older. Docker Desktop for Linux also exists if you want the GUI.

Desktop vs Engine

  • Engine — free, open source (Apache 2.0), Linux only
  • Desktop — free for personal use, education and small businesses (&lt;250 staff and &lt;$10M revenue)
  • Larger companies need a paid Desktop subscription
  • Both use the same docker CLI and commands

Install Engine on Ubuntu/Debian

# Quick dev install (convenience script; review it before running)
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Run docker without sudo (log out and back in afterwards)
sudo usermod -aG docker $USER

# Verify
docker version                         # client and server sections
docker run --rm hello-world            # end-to-end test
docker info --format '{{.ServerVersion}} {{.Driver}}'   # 29.x overlayfs

# Rootless mode: daemon runs as your user, not root
dockerd-rootless-setuptool.sh install

Notes

get.docker.com adds Docker's apt repo and installs docker-ce, CLI, containerd, Buildx and Compose plugins
For production, follow the manual repo steps in the Docker docs instead of the script
The docker group is root-equivalent: members can mount / into a container
Rootless mode limits that risk; ports below 1024 need extra setup
--format takes a Go template, e.g. '{{json .}}'

⚠ Common Mistakes

  • Installing the distro's docker.io package and then Docker's docker-ce — conflicting packages; remove one first
  • Forgetting to log out after usermod -aG docker — group changes need a new session (or newgrp docker)
  • Running curl | sudo sh in production — pin versions with the documented repo install instead
  • Mixing up client and server versions — docker version shows both; the server is what matters

✓ Tips & Best Practices

  • Prefer the management form (docker container …) in scripts; it reads clearly
  • Use docker ps --format 'table {{.Names}}\t{{.Status}}' for custom columns
  • Set DOCKER_CLI_HINTS=false to silence CLI tips in scripts
  • Keep Engine updated: v29+ rejects clients older than API 1.44 (Docker 25)

Quick Summary

  • docker-ce — Engine on Linux
  • Docker Desktop — Mac/Windows, GUI + VM
  • docker group — sudo-free, but root-equivalent
  • --format — Go templates for output
