Regular Expressions in Swift

Swift has native, type-checked regex. A regex literal /…/ is compiled and checked at build time, and its capture groups become typed tuple elements on the match. RegexBuilder spells the same patterns as a readable DSL. String methods like firstMatch(of:), wholeMatch(of:), matches(of:) and replacing(_:with:) accept either form. Pattern syntax is covered in the RegEx set.

Notes

  • Literals need Swift 5.7+ and iOS 16 / macOS 13
  • Captures: match.1, match.2 …; match.0 is the whole match
  • #/ … /# allows spaces and / inside (extended literal)
  • try Regex(string) builds one at runtime (untyped captures)

Regex Literals & Builder

let log = "2026-10-26 ERROR disk full"

if let m = log.firstMatch(of: /(\d{4})-(\d{2})-(\d{2}) (\w+)/) {
    m.1                                   // "2026" (Substring)
    m.4                                   // "ERROR"
}
"abc123".contains(/\d+/)                  // true
"2026-10-26".wholeMatch(of: /\d{4}-\d{2}-\d{2}/) != nil   // true
"a1b22c333".matches(of: /\d+/).map(\.output)              // ["1","22","333"]
"tel: 555-1234".replacing(/\d/, with: "#")                // "tel: ###-####"

let named = /(?<user>\w+)@(?<host>[\w.]+)/
if let m = "ada@swift.org".firstMatch(of: named) { m.host }  // "swift.org"

import RegexBuilder
let price = Regex {
    "$"
    TryCapture { OneOrMore(.digit) } transform: { Int($0) }
}
"Total: $42".firstMatch(of: price)?.1                     // 42 (Int)

⚠ Common Mistakes

  • Using firstMatch when the whole input must match: use wholeMatch
  • Forgetting captures are Substring: wrap with String(...) to store
  • Building a runtime Regex(string) from user input without try

✓ Tips & Best Practices

  • Add .ignoresCase() to a regex instead of (?i)
  • Use RegexBuilder for long patterns that need comments
  • See the RegEx set for pattern syntax and common patterns
