Sets

Set<Element> is an unordered collection of unique, Hashable values with O(1) average contains, insert and remove. Use it for membership tests and deduplication, and for set algebra: union, intersection, difference and symmetric difference.

Notes

  • A set literal needs a type: let s: Set = [1, 2]
  • insert returns (inserted: Bool, memberAfterInsert:)
  • Iteration order is unspecified
  • Each operation has a mutating form… twin

Set Operations

var tags: Set = ["swift", "ios", "ui"]
tags.insert("ios").inserted               // false (already there)
tags.insert("mac")
tags.contains("ui")                       // true
tags.remove("ui")                         // Optional("ui")

let a: Set = [1, 2, 3, 4]
let b: Set = [3, 4, 5]
a.union(b)                                // [1, 2, 3, 4, 5]
a.intersection(b)                         // [3, 4]
a.subtracting(b)                          // [1, 2]
a.symmetricDifference(b)                  // [1, 2, 5]

a.isSubset(of: [1, 2, 3, 4, 5])           // true
a.isDisjoint(with: [9])                   // true
Set([3, 1, 3, 2]).sorted()                // [1, 2, 3]

var seen = Set<Int>()
[4, 1, 4, 2, 1].filter { seen.insert($0).inserted }   // [4, 1, 2]

Code Explained

Set — unique, unordered
insert(_:).inserted — was it new?
union / intersection / subtracting
isSubset / isDisjoint — relations
seen.insert trick — order-preserving dedupe

The Swifty Way

  • ✗ array.contains(x) in a hot loop
    ✓ build a Set once, then set.contains(x) — O(1) vs O(n)

Coming From…

  • TypeScript Set exists, but no union/intersection built in
  • Kotlin union, intersect, subtract — same idea

⚠ Common Mistakes

  • Expecting a stable order when printing or iterating
  • Writing let s = [1, 2] and getting an Array: annotate Set
  • Putting non-Hashable types in a Set: compile error

✓ Tips & Best Practices

  • Make your struct Hashable (often just : Hashable) to store it in a Set
  • Use OptionSet for bit flags, Set for runtime collections
  • OrderedSet from swift-collections keeps insertion order
