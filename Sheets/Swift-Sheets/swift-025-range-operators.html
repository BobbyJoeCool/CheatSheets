Range Operators

... · ..< · one-sided ranges · ClosedRange · stride(from:to:by:) · ~=

Ranges

a...b is a closed range including both ends; a..<b is half-open and excludes b. One-sided ranges (a..., ..<b) run to the end or from the start of a collection. Ranges drive for loops, slicing, switch cases and contains checks, and stride gives custom steps.

Notes

  • ..< matches zero-based indices: 0..<array.count
  • a...b requires a <= b, otherwise it traps
  • stride(from:to:by:) excludes the end; through: includes it
  • ~= is the pattern-match operator switch uses

Range Operators

for i in 1...3 { print(i) }         // 1 2 3
for i in 0..<3 { print(i) }         // 0 1 2

let nums = [10, 20, 30, 40, 50]
nums[1...3]                         // [20, 30, 40]
nums[2...]                          // [30, 40, 50]
nums[..<2]                          // [10, 20]

(1...10).contains(7)                // true
(1..<10).count                      // 9
let r = 5...                        // PartialRangeFrom<Int>
r.contains(1_000)                   // true

for x in stride(from: 0, to: 10, by: 3) { }       // 0 3 6 9
for x in stride(from: 10, through: 0, by: -5) { } // 10 5 0
for x in (1...3).reversed() { }     // 3 2 1
1...5 ~= 3                          // true

Code Explained

... — closed; ..< — half-open
nums[2...] / nums[..<2] — one-sided slices
stride(from:to:by:) — custom step, end excluded
through: — end included
.reversed() — count down

The Swifty Way

  • ✗ for i in 0...arr.count - 1
    ✓ for i in arr.indices — no crash on an empty array

Coming From…

  • Kotlin 1..3 ≈ 1...3; until ≈ ..<
  • Python range(0, 3) ≈ 0..<3
  • TypeScript No ranges; for (let i=0;i<3;i++) ≈ 0..<3

⚠ Common Mistakes

  • 0...arr.count - 1 on an empty array: 0...-1 traps
  • Building 5...1 to count down: use reversed() or stride
  • Iterating a PartialRangeFrom with no break: it never ends

✓ Tips & Best Practices

  • Use array.indices instead of building index ranges by hand
  • Ranges of Double work for contains but not for for loops; use stride
  • x.clamped(to:) is easy to add as an extension on Comparable

Quick Summary

  • a...b / a..<b — closed / half-open
  • a... / ..<b — one-sided
  • stride — custom steps
