Introduction & History

Chris Lattner · 2014 · open source · Swift Evolution · ABI stability · Swift 6

What Swift Is

Swift is Apple's general-purpose, compiled language for iOS, macOS, watchOS, tvOS and visionOS, and it also runs on Linux and Windows. It was built to replace Objective-C with something safe by default (no null pointers without ?, no unchecked overflow, no uninitialized variables) while staying as fast as C-family code. It is open source and evolves through public proposals.

Notes

  • Announced at WWDC 2014; open-sourced in December 2015
  • Created by Chris Lattner and the Apple developer tools team (Lattner also started LLVM)
  • File extension .swift; compiled through LLVM to native code
  • Changes go through Swift Evolution proposals (SE-0001 …) at swift.org

Hello, World

// hello.swift
print("Hello, World!")            // Hello, World!

let name = "Swift"                // constant, type inferred as String
var year = 2014                   // variable, type inferred as Int
year += 12
print("\(name) is \(year - 2014) years old")   // Swift is 12 years old

// Run it:  swift hello.swift
// Compile: swiftc hello.swift -o hello && ./hello

Code Explained

print — writes to standard output; no main() needed in a script
let — constant; var — variable
\(…) — string interpolation
swift file.swift — runs directly; swiftc — builds a binary

The Swifty Way

  • ✗ Starting new code in Swift 5 language mode
    ✓ Swift 6 language mode (strict concurrency on) — new projects should opt into data-race checking from day one

Coming From…

  • Kotlin Closest cousin: modern, null-safe, same era
  • TypeScript Like TS with a real compiler and value types
  • Java Compiled AOT to native, no JVM, no GC (uses ARC)
  • Python Same readability, but static types and much faster

⚠ Common Mistakes

  • Treating Swift as "just for iPhone": the language, package manager and stdlib work on Linux and Windows too
  • Learning from pre-Swift 5 tutorials: syntax and APIs changed a lot (String indexing, Codable, concurrency)
  • Assuming ARC is garbage collection: there is no collector, and reference cycles leak

✓ Tips & Best Practices

  • Bookmark docs.swift.org (The Swift Programming Language book) and developer.apple.com/documentation
  • Check a feature's version in its Swift Evolution proposal before using it
  • Use a Playground or swift repl to try snippets from this set

Quick Summary

  • Swift — Apple's compiled, safe-by-default language (2014)
  • swift.org — open source home, Evolution proposals
  • Swift 6 — current major version, data-race safety
