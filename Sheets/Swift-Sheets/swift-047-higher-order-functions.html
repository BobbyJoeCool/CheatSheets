Higher-Order Functions

Collections have methods that take closures to transform data without manual loops. map transforms each element, filter keeps matches, reduce combines into one value, and compactMap transforms and drops nils. They return new arrays and can be chained into readable pipelines.

Notes

  • map on a Dictionary returns an Array; use mapValues to keep it a Dictionary
  • flatMap flattens nested sequences
  • reduce(into:) is faster for building collections
  • Add .lazy to avoid intermediate arrays on long chains

map · filter · reduce

let nums = [1, 2, 3, 4, 5, 6]

nums.map { $0 * $0 }                        // [1, 4, 9, 16, 25, 36]
nums.filter { $0.isMultiple(of: 2) }        // [2, 4, 6]
nums.reduce(0, +)                           // 21
nums.reduce(into: [:]) { $0[$1 % 3, default: 0] += 1 }
                                            // [1: 2, 2: 2, 0: 2]

["1", "x", "3"].compactMap { Int($0) }      // [1, 3]
[[1, 2], [3]].flatMap { $0 }                // [1, 2, 3]
nums.contains { $0 > 5 }                    // true
nums.allSatisfy { $0 > 0 }                  // true
nums.first { $0 > 3 }                       // Optional(4)
nums.count(where: { $0 > 3 })               // 3   (6.0+)

let total = orders
    .filter { $0.isPaid }
    .map(\.amount)
    .reduce(0, +)

Code Explained

map — transform every element
filter — keep elements that pass
reduce — fold into one value
compactMap — transform + drop nil
flatMap — flatten one level

The Swifty Way

  • ✗ var r = []; for x in a { if p(x) { r.append(f(x)) } }
    ✓ a.filter(p).map(f)

Coming From…

  • Kotlin mapNotNull ≈ compactMap; fold ≈ reduce

⚠ Common Mistakes

  • Using map for side effects: use for-in or forEach
  • filter { … }.count on large arrays: use count(where:)
  • flatMap to drop nils: that's compactMap (old flatMap overload was renamed)

✓ Tips & Best Practices

  • Use key paths: users.map(\.name)
  • reduce(into:) mutates an accumulator, avoiding copies
  • Break long chains into named let steps when debugging

Quick Summary

  • map / filter / reduce — core trio
  • compactMap — drop nils
  • .lazy — no intermediate arrays
