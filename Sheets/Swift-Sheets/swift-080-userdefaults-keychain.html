UserDefaults & Keychain

UserDefaults · set(_:forKey:) · suites · Keychain Services · SecItemAdd · what not to store

Small Persistent Values

UserDefaults stores small preferences (Bools, numbers, strings, dates, small Data) as a property list, keyed by string. It is not encrypted, so secrets like tokens and passwords belong in the Keychain, Apple's encrypted credential store, accessed through the SecItem… C API (or a small wrapper library).

Notes

  • UserDefaults is loaded into memory: keep it small
  • register(defaults:) sets fallback values (not saved)
  • App groups share defaults with extensions via suiteName
  • Keychain items survive app deletion on iOS by default

UserDefaults & Keychain

import Foundation
let d = UserDefaults.standard
d.register(defaults: ["volume": 0.8])
d.set(true, forKey: "onboarded")
d.set("dark", forKey: "theme")
d.bool(forKey: "onboarded")                 // true
d.double(forKey: "volume")                  // 0.8 (registered)
d.string(forKey: "missing")                 // nil
d.removeObject(forKey: "theme")

import Security
func saveToken(_ token: String) -> Bool {
    let q: [String: Any] = [
        kSecClass as String: kSecClassGenericPassword,
        kSecAttrAccount as String: "apiToken",
        kSecValueData as String: Data(token.utf8),
    ]
    SecItemDelete(q as CFDictionary)        // replace if present
    return SecItemAdd(q as CFDictionary, nil) == errSecSuccess
}

Code Explained

register(defaults:) — fallback values
set(_:forKey:) / bool(forKey:) — read/write
removeObject(forKey:) — delete
kSecClassGenericPassword — keychain item kind
SecItemAdd → errSecSuccess — store securely

The Swifty Way

  • ✗ UserDefaults.standard.set(token, forKey: "token")
    ✓ store tokens in the Keychain — UserDefaults is a plain-text plist

Coming From…

  • Kotlin SharedPreferences ≈ UserDefaults; Keystore ≈ Keychain
  • TypeScript localStorage ≈ UserDefaults (also not secure)
  • Python keyring library ≈ Keychain

⚠ Common Mistakes

  • Storing large arrays or images in UserDefaults: slows launch
  • Storing secrets in UserDefaults or Info.plist
  • Ignoring the OSStatus from SecItemAdd: failures go unnoticed

✓ Tips & Best Practices

  • Wrap keys in a enum DefaultsKey: String to avoid typos
  • Use @AppStorage("theme") in SwiftUI to bind to UserDefaults
  • Read with SecItemCopyMatching using kSecReturnData: true

Quick Summary

  • UserDefaults — small prefs
  • Keychain — secrets
  • SecItemAdd / SecItemCopyMatching
