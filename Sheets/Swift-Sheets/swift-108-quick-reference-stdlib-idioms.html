⚠ Common Mistakes

  • map on a Dictionary returns an Array: use mapValues
  • reversed() returns a view: wrap with Array(...)
  • Non-2xx HTTP responses don't throw: check statusCode

✓ Tips & Best Practices

  • Use .formatted() for anything users read
  • Add swift-collections for Deque, OrderedSet, Heap
  • Prefer async APIs over completion handlers
