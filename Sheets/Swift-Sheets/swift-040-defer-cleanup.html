defer & Cleanup

defer · execution order · scope exit · defer with guard · resource cleanup

Running Code on Exit

A defer block runs when the current scope exits, however it exits: normal end, return, throw or break. Put cleanup right next to the setup it undoes, so you can't forget it on an early-exit path. Multiple defers in one scope run in reverse order.

Notes

  • defer runs at the end of its enclosing scope, not the function
  • A defer inside an if or loop body runs at the end of that body
  • Can't return, throw or break out of a defer
  • Ideal for locks, files, timers and state flags

defer for Cleanup

func load(path: String) throws -> String {
    let handle = try FileHandle(forReadingFrom: URL(filePath: path))
    defer { try? handle.close() }           // runs on every exit

    guard let data = try handle.readToEnd() else { return "" }
    return String(decoding: data, as: UTF8.self)
}

func demo() {
    defer { print("1st defer") }
    defer { print("2nd defer") }
    print("body")
}
demo()                       // body, 2nd defer, 1st defer

@MainActor func refresh() async {
    isLoading = true
    defer { isLoading = false }             // reset even if we bail out
    guard let data = try? await api.fetch() else { return }
    show(data)
}

Code Explained

defer { } — runs when the scope exits
reverse order — last declared runs first
try? inside defer — defer can't throw
flag reset — classic loading-state pattern

The Swifty Way

  • ✗ calling close() before every return
    ✓ one defer { close() } right after opening

Coming From…

  • Java finally ≈ defer placed next to setup
  • Python try/finally or with ≈ defer
  • TypeScript try/finally ≈ defer

⚠ Common Mistakes

  • Placing defer at the end of a function: it must come before the exits it should cover
  • Expecting a defer inside an if to wait until the function returns
  • Calling a throwing function in defer without try?

✓ Tips & Best Practices

  • Write the defer immediately after acquiring the resource
  • Prefer Mutex.withLock { } over manual lock/unlock + defer when available
  • Keep defer bodies short and side-effect free

Quick Summary

  • defer — run on scope exit
  • Runs on return, throw, break
  • Multiple defers run in reverse
