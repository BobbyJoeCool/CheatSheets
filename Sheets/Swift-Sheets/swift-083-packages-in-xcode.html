Packages in Xcode

Add Package Dependencies · Package.resolved · version rules · local packages

Using Packages in Xcode

Xcode has SwiftPM built in. Add a remote package through File › Add Package Dependencies…, pick a version rule, and choose which products to link to which targets. Local packages (a folder with Package.swift) can be dragged into the project to split an app into modules you edit side by side.

Notes

  • Locked versions: Package.resolved, inside the project's xcshareddata/swiftpm folder
  • Package settings are under the project's Package Dependencies tab
  • Local packages override a remote package with the same name
  • CI: xcodebuild -resolvePackageDependencies

Typical Workflow

// 1. File › Add Package Dependencies…
//    URL: https://github.com/apple/swift-collections
//    Rule: Up to Next Major Version  1.1.0 < 2.0.0
//    Add product "Collections" to target "MyApp"

// 2. Use it
import Collections
var recent: OrderedSet = ["home", "search"]

// 3. Local package for a feature module
//    File › New › Package…  → Packages/Profile
//    Drag Packages/Profile into the project navigator
//    Target › General › Frameworks: + Profile
import Profile

// 4. Housekeeping (File › Packages)
//    Resolve Package Versions
//    Update to Latest Package Versions
//    Reset Package Caches              (fixes odd resolve errors)

Code Explained

Add Package Dependencies — search or paste a URL
version rule — how updates are allowed
link product to target — needed before import
local package — feature modules in-repo
Reset Package Caches — first fix for weird errors

The Swifty Way

  • ✗ copying a library's source files into the app
    ✓ add it as a package dependency — updates and licenses stay clear

⚠ Common Mistakes

  • Adding the package but not linking its product to the target: "No such module"
  • Not committing Package.resolved for apps: teammates get different versions
  • Pointing at a branch for production builds

✓ Tips & Best Practices

  • Group local packages in a Packages/ folder
  • Use swift package dump-package to inspect a package's products
  • When resolution fails after branch switches, Reset Package Caches first
