Linting & Formatting

swift-format (Apple's formatter and linter) ships with the Swift 6 toolchain as swift format. SwiftLint (community, by Realm) is the most common linter in iOS teams, with hundreds of configurable rules. Run them in Xcode build phases, pre-commit hooks or CI so style is checked by tools, not reviewers.

Notes

  • swift-format config: .swift-format (JSON)
  • SwiftLint config: .swiftlint.yml (YAML)
  • SwiftLint has a build tool plugin for SwiftPM and Xcode
  • swiftlint --fix auto-corrects some rules

Commands & Config

# swift-format (in the Swift 6 toolchain)
swift format --in-place --recursive Sources Tests
swift format lint --recursive Sources
swift format dump-configuration > .swift-format

# SwiftLint
brew install swiftlint
swiftlint                       # lint current folder
swiftlint --fix                 # auto-correct
swiftlint --strict              # warnings fail the run (CI)

# .swiftlint.yml
disabled_rules: [trailing_comma]
opt_in_rules: [empty_count, force_unwrapping]
excluded: [Pods, .build]
line_length: { warning: 120, error: 160 }

// In code
// swiftlint:disable:next force_cast
let v = obj as! UIView

Code Explained

swift format --in-place — rewrite files
swift format lint — report only
swiftlint --fix / --strict
opt_in_rules — enable extra rules
// swiftlint:disable:next rule — local exception

The Swifty Way

  • ✗ style comments in code review
    ✓ a formatter in a pre-commit hook — machines argue about commas

Coming From…

  • TypeScript Prettier ≈ swift-format; ESLint ≈ SwiftLint
  • Python black ≈ swift-format; ruff/flake8 ≈ SwiftLint
  • Kotlin ktlint / detekt ≈ SwiftLint

⚠ Common Mistakes

  • Running formatter and linter with conflicting rules (e.g. trailing commas)
  • Disabling rules file-wide instead of per line
  • Linting generated code: add it to excluded

✓ Tips & Best Practices

  • Format on save in VS Code with the Swift extension
  • Add swiftlint --strict to CI so warnings can't pile up
  • Commit the config files so everyone shares the same rules

Quick Summary

  • swift format — official formatter
  • SwiftLint — community linter
  • run both in CI
