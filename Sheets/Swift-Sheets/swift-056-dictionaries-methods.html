mapValues · compactMapValues · Dictionary(grouping:by:) · uniquingKeysWith · merge · filter

Dictionary Methods

Dictionaries have their own transforms: mapValues and compactMapValues keep the keys, filter returns a Dictionary, and merge combines two with a rule for duplicate keys. Initializers like Dictionary(grouping:by:) turn arrays into dictionaries in one line.

Notes

  • map on a Dictionary returns an Array of whatever you return
  • filter returns a Dictionary (since Swift 4)
  • uniquingKeysWith: decides which value wins
  • merging returns new; merge mutates

Transform & Combine

let prices = ["apple": 1.2, "pear": 0.9, "kiwi": 2.5]

prices.mapValues { $0 * 2 }               // same keys, doubled
prices.filter { $0.value > 1 }            // ["apple": 1.2, "kiwi": 2.5]
prices.map { "\($0.key): \($0.value)" }   // [String]
["a": "1", "b": "x"].compactMapValues(Int.init)   // ["a": 1]

let words = ["apple", "avocado", "banana", "blueberry", "cherry"]
Dictionary(grouping: words, by: { $0.first! })
// ["a": ["apple", "avocado"], "b": [...], "c": ["cherry"]]

let pairs = [("a", 1), ("b", 2), ("a", 3)]
Dictionary(pairs, uniquingKeysWith: +)    // ["a": 4, "b": 2]
Dictionary(pairs, uniquingKeysWith: { _, new in new })  // ["a": 3, "b": 2]

var stock = ["apple": 5]
stock.merge(["apple": 3, "pear": 2]) { old, new in old + new }
// ["apple": 8, "pear": 2]
prices.min { $0.value < $1.value }?.key   // "pear"

Code Explained

mapValues — transform values, keep keys
compactMapValues — drop nil results
Dictionary(grouping:by:) — bucket an array
uniquingKeysWith: — resolve duplicate keys
merge(_:uniquingKeysWith:) — combine in place

The Swifty Way

  • ✗ loop + if d[k] == nil { d[k] = [] }; d[k]!.append(x)
    ✓ Dictionary(grouping: xs, by: key)

Coming From…

  • Kotlin groupBy ≈ Dictionary(grouping:by:)
  • Python defaultdict(list) ≈ grouping; {**a, **b} ≈ merging
  • TypeScript Object.groupBy ≈ grouping

Builders

InitializerUse
Dictionary(uniqueKeysWithValues:)Pairs, no dupes
Dictionary(_:uniquingKeysWith:)Pairs with dupes
Dictionary(grouping:by:)Group into arrays
zip(keys, values)Pair two arrays

⚠ Common Mistakes

  • Using map and expecting a Dictionary back: use mapValues
  • uniqueKeysWithValues with duplicate keys: runtime crash
  • Forgetting merge needs a closure even when there are no conflicts

✓ Tips & Best Practices

  • Dictionary(uniqueKeysWithValues: zip(ids, users)) pairs arrays
  • users.reduce(into: [:]) { $0[$1.id] = $1 } indexes by ID
  • OrderedDictionary (swift-collections) keeps insertion order

Quick Summary

  • mapValues / filter — keep a Dictionary
  • grouping:by: — bucket
  • merge — combine with a rule
