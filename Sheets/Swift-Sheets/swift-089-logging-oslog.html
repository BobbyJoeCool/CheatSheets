Logging with OSLog

Logger from the OSLog framework is Apple's unified logging API. Messages are cheap, tagged with a subsystem and category, filterable by level in Xcode's console and Console.app, and private by default: dynamic values are redacted in logs collected off-device unless you mark them public.

Notes

  • Interpolated values are redacted unless privacy: .public
  • Debug-level messages aren't persisted
  • View logs in Xcode's console, Console.app or log stream
  • Prefer Logger over print in app code

Logger

import OSLog

extension Logger {
    static let network = Logger(subsystem: "com.example.app", category: "network")
    static let ui = Logger(subsystem: "com.example.app", category: "ui")
}

let userID = "u_42", ms = 128
Logger.network.debug("Starting request")
Logger.network.info("Loaded \(ms) ms for user \(userID, privacy: .private)")
Logger.network.notice("Cache hit")
Logger.network.error("Status \(503, privacy: .public)")
Logger.network.fault("Unexpected nil token")

// Formatting options
Logger.ui.info("Progress \(0.4567, format: .fixed(precision: 2))")
Logger.ui.info("ID \(userID, privacy: .private(mask: .hash))")

// Terminal on a Mac:
// log stream --predicate 'subsystem == "com.example.app"' --level debug

Code Explained

Logger(subsystem:category:) — tagged logger
.debug … .fault — levels
privacy: .public / .private — redaction
format: .fixed(precision:) — number formatting
log stream --predicate — live filter

The Swifty Way

  • ✗ print("user: \(email)")
    ✓ logger.info("user: \(email, privacy: .private)") — fast, filterable, private

Coming From…

  • Kotlin Android Log.d(TAG, …) ≈ Logger with category
  • Python logging.getLogger("net") ≈ category logger
  • TypeScript console.debug/info/error with no privacy controls

Log Levels

LevelPersisted?
debugNo (memory only)
infoOnly when collected
notice (default)Yes
errorYes
faultYes, with extra context

⚠ Common Mistakes

  • Logging tokens or emails as .public
  • Pre-building a String, then logging \(message): the whole message becomes one redacted value
  • Expecting debug messages in a user's sysdiagnose

✓ Tips & Best Practices

  • One static Logger per category in an extension
  • Use OSSignposter to measure intervals in Instruments
  • Filter Xcode's console by subsystem and level

Quick Summary

  • Logger — unified logging
  • subsystem + category
  • private by default
