SwiftPM

The Swift Package Manager builds, tests and manages dependencies for Swift code. A package is described by Package.swift, a Swift file that declares products (libraries or executables), targets (modules), and dependencies on other packages. SwiftPM resolves versions with semantic versioning and records them in Package.resolved.

Notes

  • The first line // swift-tools-version: sets the manifest API version
  • Sources go in Sources/<Target>/, tests in Tests/<Target>Tests/
  • Commit Package.resolved for apps; libraries usually don't
  • Xcode opens a Package.swift directly

Package.swift

// swift-tools-version: 6.0
import PackageDescription

let package = Package(
    name: "Weather",
    platforms: [.iOS(.v17), .macOS(.v14)],
    products: [
        .library(name: "WeatherKitLite", targets: ["WeatherKitLite"]),
        .executable(name: "weather", targets: ["CLI"]),
    ],
    dependencies: [
        .package(url: "https://github.com/apple/swift-argument-parser",
                 from: "1.5.0"),
    ],
    targets: [
        .target(name: "WeatherKitLite"),
        .executableTarget(name: "CLI", dependencies: [
            "WeatherKitLite",
            .product(name: "ArgumentParser", package: "swift-argument-parser"),
        ]),
        .testTarget(name: "WeatherKitLiteTests", dependencies: ["WeatherKitLite"]),
    ]
)

Code Explained

swift-tools-version — manifest version
platforms — minimum OS versions
products — what others can use
.package(url:from:) — up to next major
.product(name:package:) — depend on a product

The Swifty Way

  • ✗ .package(url: …, branch: "main") in releases
    ✓ .package(url: …, from: "1.5.0") — branches aren't reproducible

⚠ Common Mistakes

  • Mismatching target names and folder names under Sources/
  • Depending on a package name instead of its product name
  • Pinning exact: versions everywhere: blocks bug-fix updates

✓ Tips & Best Practices

  • Use .upToNextMinor(from:) for 0.x packages
  • Add resources with resources: [.process("Assets")] and read via Bundle.module
  • Search swiftpackageindex.com for well-maintained packages
