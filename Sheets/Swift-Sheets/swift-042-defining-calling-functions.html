Defining & Calling Functions

func · -> · return · implicit return · Void · @discardableResult

Functions

Declare a function with func, a parameter list, and an optional return type after ->. A function with no -> returns Void. If the body is a single expression, the return keyword can be dropped. Functions can return tuples to hand back several values at once.

Notes

  • Functions are first-class values (Sheet 044)
  • Callers must use the result unless it's @discardableResult
  • Return type Never means the function never returns
  • Functions can be declared at file scope, in types, or nested

Defining & Calling

func greet(name: String) -> String {
    return "Hello, \(name)!"
}
greet(name: "Ada")                          // "Hello, Ada!"

func square(_ x: Int) -> Int { x * x }      // implicit return
square(4)                                   // 16

func log(_ message: String) {               // returns Void
    print("[log] \(message)")
}

func minMax(_ a: [Int]) -> (min: Int, max: Int)? {
    guard let lo = a.min(), let hi = a.max() else { return nil }
    return (lo, hi)
}
if let r = minMax([3, 9, 1]) { print(r.min, r.max) }   // 1 9

@discardableResult
func save() -> Bool { true }
save()                                      // no unused-result warning

Code Explained

func name(param: Type) -> Ret — declaration
implicit return — single-expression body
no -> — returns Void
named tuple return — (min: Int, max: Int)
@discardableResult — result may be ignored

The Swifty Way

  • ✗ func f() -> Int { return x * 2 }
    ✓ func f() -> Int { x * 2 }

Coming From…

  • Kotlin fun f(x: Int): Int = x * x ≈ implicit return
  • TypeScript function f(x: number): number
  • Python def f(x) -> int: with tuple returns

Function Shapes

SignatureMeaning
func f()No params, returns Void
func f() -> IntReturns Int
func f() -> (Int, Int)Returns a tuple
func f() -> Int?May return nil
func f() -> NeverNever returns

⚠ Common Mistakes

  • Ignoring a result: compiler warning unless @discardableResult
  • Returning an unnamed tuple from a public API: use a struct when it grows
  • Writing -> Void everywhere: just omit the arrow

✓ Tips & Best Practices

  • Keep functions small; extract when you'd write a comment heading
  • Return optionals or throw rather than sentinel values like -1
  • Use _ = f() to ignore a result on purpose

Quick Summary

  • func f(x: T) -> R — declare
  • implicit return — one expression
  • tuple returns — multiple values
