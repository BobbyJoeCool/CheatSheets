Sheet 020

String Methods — Search

contains · hasPrefix · hasSuffix · firstIndex(of:) · range(of:) · starts(with:)

Finding Things in Strings

Searching uses methods on String (many from Foundation): contains, hasPrefix, hasSuffix, firstIndex(of:), and range(of:) for substrings. Comparisons are case-sensitive by default; pass options: such as .caseInsensitive to range(of:), or lowercase both sides.

Notes

  • Add import Foundation for range(of:) and components(separatedBy:)
  • contains takes a Character, a String, or a predicate
  • localizedStandardContains is what Finder-style search uses
  • Regex-based search: see Sheet 093

Search Methods

import Foundation
let s = "Swift is fast. Swift is safe."

s.contains("fast")                  // true
s.contains("FAST")                  // false
s.localizedCaseInsensitiveContains("FAST")   // true
s.hasPrefix("Swift")                // true
s.hasSuffix("safe.")                // true

s.firstIndex(of: ".")               // Index of first "."
s.contains(where: \.isNumber)       // false

if let r = s.range(of: "is") {
    s[r.upperBound...]              // " fast. Swift is safe."
}
s.range(of: "SWIFT", options: .caseInsensitive) != nil   // true
s.ranges(of: "Swift").count         // 2
s.starts(with: "Sw")                // true

Code Explained

contains(_:) — substring or Character
hasPrefix / hasSuffix — start / end tests
range(of:) — Range<String.Index>? of a match
options: .caseInsensitive — Foundation compare options
ranges(of:) — every match (5.7+)

The Swifty Way

  • ✗ s.lowercased().contains(q.lowercased())
    ✓ s.localizedStandardContains(q) — handles case and diacritics

Coming From…

  • TypeScript includes / startsWith ≈ contains / hasPrefix
  • Python in / startswith / find ≈ same here
  • Java indexOf returns -1; range(of:) returns nil

Compare Options

OptionEffect
.caseInsensitiveA == a
.diacriticInsensitiveé == e
.backwardsSearch from the end
.anchoredMatch only at start
.regularExpressionPattern is a regex

⚠ Common Mistakes

  • Expecting firstIndex(of:) to take a String: it takes a Character; use range(of:)
  • Forgetting import Foundation: range(of:) won't be found
  • Comparing user search text case-sensitively

✓ Tips & Best Practices

  • Use localizedStandardContains for user-facing search boxes
  • Combine options: [.caseInsensitive, .diacriticInsensitive]
  • s.firstRange(of:) (5.7+) works without Foundation

Quick Summary

  • contains / hasPrefix / hasSuffix — tests
  • range(of:options:) — locate a substring
  • localizedStandardContains — user search
