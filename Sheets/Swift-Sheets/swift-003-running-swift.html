Running Swift

Playgrounds · swift repl · swift file.swift · swift run · #!/usr/bin/env swift

Ways to Run Code

Swift can be run four ways: interactively in a Playground or the REPL, as a script interpreted on the fly, as a Swift package built with swift run, or as an app built by Xcode. Scripts and the REPL are great for learning; packages are how real command-line tools and libraries are built.

Notes

  • Playgrounds show each line's result in a sidebar
  • swift repl (or just swift) starts an interactive session
  • A script can start with a shebang and be made executable
  • #Preview in Xcode is the app-world equivalent for UI

Running Swift

# Interactive REPL
$ swift repl
  1> let x = 21 * 2
x: Int = 42
  2> :quit

# Run a single file (compiled in memory, then run)
$ swift greet.swift Ada

# Executable script
#!/usr/bin/env swift
print("Hi, \(CommandLine.arguments[1])")
$ chmod +x greet.swift && ./greet.swift Ada

# Package: create, build, run
$ swift package init --type executable --name greet
$ swift run greet Ada

Code Explained

swift repl — read-eval-print loop; :quit exits
swift file.swift — interpret a single file
CommandLine.arguments — args; [0] is the program
swift run — build and run a package's executable

The Swifty Way

  • ✗ Growing a 300-line script file
    ✓ swift package init --type executable — packages give you modules, tests and dependencies

Coming From…

  • Kotlin REPL ≈ kotlinc; Playground ≈ Kotlin scratch file
  • TypeScript swift file.swift ≈ npx tsx file.ts
  • Python swift repl ≈ python; scripts work the same way

⚠ Common Mistakes

  • Forgetting chmod +x on a shebang script
  • Reading CommandLine.arguments[1] without checking the count (traps if missing)
  • Expecting a Playground to run in the iOS app lifecycle; use a real app target or #Preview instead

✓ Tips & Best Practices

  • swift -e 'print(1+1)' runs a one-liner
  • Add import Foundation at the top of scripts that need dates, files or networking
  • Use Swift Playgrounds on iPad to learn and prototype away from the Mac

Quick Summary
