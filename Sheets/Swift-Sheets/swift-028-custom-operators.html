Operator Overloading & Custom Operators

static func + · prefix · postfix · infix · precedencegroup

Defining Operators

Types can overload existing operators by declaring a static func with the operator's name. You can also declare entirely new operators with prefix, postfix or infix operator, and give infix operators a precedence group. Use custom operators sparingly: a well-named method is usually clearer.

Notes

  • Operator functions are static members of a type or extension
  • Equatable / Comparable / Hashable conformance = overloads of == / <
  • New operators are declared at file scope
  • Allowed characters: / = - + ! * % < > & | ^ ~ ? and some Unicode

Overloading & New Operators

struct Vec: Equatable { var x, y: Double }

extension Vec {
    static func + (l: Vec, r: Vec) -> Vec { Vec(x: l.x + r.x, y: l.y + r.y) }
    static func * (v: Vec, k: Double) -> Vec { Vec(x: v.x * k, y: v.y * k) }
    static prefix func - (v: Vec) -> Vec { Vec(x: -v.x, y: -v.y) }
    static func += (l: inout Vec, r: Vec) { l = l + r }
}

var p = Vec(x: 1, y: 2) + Vec(x: 3, y: 4)  // (4, 6)
p += Vec(x: 1, y: 1)                       // (5, 7)
-p * 2                                     // (-10, -14)

infix operator **: PowerPrecedence
precedencegroup PowerPrecedence {
    higherThan: MultiplicationPrecedence
    associativity: right
}
func ** (b: Double, e: Double) -> Double { pow(b, e) }
2 ** 3 ** 2                                // 512.0

Code Explained

static func + — overload an existing operator
prefix func - — unary operator
inout — compound assignment mutates the left side
infix operator ** — declare a new operator
precedencegroup — precedence and associativity

The Swifty Way

  • ✗ a <*> operator only you understand
    ✓ a method like combined(with:) — readers can search for a name

⚠ Common Mistakes

  • Forgetting static on the operator function
  • Defining a new operator without a precedence group, then mixing it with +
  • Overloading == by hand when : Equatable would synthesize it

✓ Tips & Best Practices

  • Overload operators for math-like types (vectors, money, matrices) only
  • Conform to AdditiveArithmetic to get + - and .zero together
  • Keep the operator and a named method in sync, e.g. + and adding(_:)

Quick Summary
