URLs, Environment & Bundles

URLComponents builds and edits URLs safely, handling percent-encoding of query items for you. ProcessInfo exposes the environment, arguments and system details. Bundle reads resources and Info.plist values shipped with the app. Locale describes the user's language, region and formatting preferences.

Notes

  • URL(string:) returns nil for invalid strings
  • Build query strings with URLQueryItem, never by concatenation
  • Bundle.main = app; Bundle.module = package resources
  • Environment variables are set in Xcode's scheme editor

URLs & System Info

import Foundation
var c = URLComponents()
c.scheme = "https"
c.host = "api.example.com"
c.path = "/search"
c.queryItems = [URLQueryItem(name: "q", value: "swift & ios"),
                URLQueryItem(name: "page", value: "2")]
c.url   // …/search?q=swift%20%26%20ios&page=2

let u = URL(string: "https://example.com:8080/a/b?x=1")!
u.host()                  // "example.com"
u.port                    // 8080
u.query()                 // "x=1"

let env = ProcessInfo.processInfo.environment
let apiKey = env["API_KEY"] ?? ""
ProcessInfo.processInfo.isLowPowerModeEnabled
CommandLine.arguments     // ["/path/to/tool", …]

let version = Bundle.main.infoDictionary?["CFBundleShortVersionString"] as? String
let seed = Bundle.main.url(forResource: "seed", withExtension: "json")
Locale.current.identifier // "en_US"

Code Explained

URLComponents — safe URL building
URLQueryItem — encoded query pairs
host() / port / query() — read URL parts
ProcessInfo — env and system state
Bundle.main — resources and Info.plist

The Swifty Way

  • ✗ URL(string: base + "?q=" + text)!
    ✓ URLComponents + queryItems — encodes &, spaces, Unicode

⚠ Common Mistakes

  • Force-unwrapping URL(string:) built from user input
  • Shipping API keys in the bundle: anyone can extract them
  • Hard-coding "en" instead of reading Locale.current

✓ Tips & Best Practices

  • Use Bundle.main.bundleIdentifier as your Logger subsystem
  • URL.appending(queryItems:) (iOS 16+) adds query items to a URL
  • Read build settings into code via Info.plist $(VARIABLE) entries

Quick Summary

  • URLComponents — build URLs
  • ProcessInfo / CommandLine — environment
  • Bundle / Locale — app & user info
