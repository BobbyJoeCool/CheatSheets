⚠ Common Mistakes

  • arr[0] on empty arrays and x! on nil both crash
  • = returns Void: if x = y won't compile
  • Integer overflow traps; use &+ to wrap

✓ Tips & Best Practices

  • Default to let, struct, final class, some P
  • Prefer guard for early exits
