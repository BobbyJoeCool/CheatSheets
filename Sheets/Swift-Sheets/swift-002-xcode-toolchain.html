Xcode & Toolchain

Xcode · swiftc · Command Line Tools · simulators · SDKs · swiftly

The Toolchain

On a Mac, Xcode is the toolchain: it bundles the Swift compiler, the SDKs for every Apple platform, simulators, Instruments and the debugger. The Command Line Tools package gives you swift and swiftc without the full IDE. On Linux, or to manage several toolchain versions, use swiftly.

Notes

  • Install Xcode from the Mac App Store or developer.apple.com
  • Each Xcode release pins one Swift version; check with swift --version
  • xcode-select picks which Xcode the command line uses
  • Simulators are downloaded per platform from Xcode › Settings › Components

Setup Commands

# Command Line Tools only (no IDE)
xcode-select --install

# Which Swift / which Xcode?
swift --version
xcode-select -p                 # /Applications/Xcode.app/Contents/Developer
sudo xcode-select -s /Applications/Xcode-beta.app

# swiftly: install and switch toolchains (macOS + Linux)
swiftly install latest
swiftly use 6.0
swiftly list

# List simulators and boot one
xcrun simctl list devices
xcrun simctl boot "iPhone 16"

Code Explained

xcode-select --install — compiler + SDK without Xcode
xcode-select -s — switch the active Xcode
swiftly — official toolchain manager
xcrun — runs a tool from the active Xcode

The Swifty Way

  • ✗ Downloading toolchain tarballs by hand
    ✓ swiftly install latest — swiftly handles paths and switching

Coming From…

  • Kotlin Xcode ≈ Android Studio + SDK Manager
  • TypeScript swiftly ≈ nvm for Node versions
  • Python swiftly ≈ pyenv

⚠ Common Mistakes

  • Running swift from an old Xcode: xcode-select -p shows which one is active
  • Mixing Homebrew Swift with Xcode's Swift: pick one toolchain per project
  • Expecting VS Code to build iOS apps: it edits and builds packages, but signing and simulators still need Xcode

✓ Tips & Best Practices

  • Keep the release Xcode and a beta side by side; switch with xcode-select -s
  • xcrun --find swiftc shows the exact compiler path in use
  • Use xcodebuild -scheme App test in CI

Quick Summary

  • Xcode — IDE + compiler + SDKs + simulators
  • xcode-select — choose the active toolchain
  • swiftly — install and switch Swift versions
