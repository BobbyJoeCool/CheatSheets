Swift Macros

Macros generate code at compile time. Freestanding macros start with # and produce an expression or declarations (#Preview, #expect). Attached macros start with @ and add members, accessors, conformances or peers to a declaration (@Observable, @Model, @Test). Macros are implemented with swift-syntax in a separate compiler-plugin target.

Notes

  • Right-click a macro › Expand Macro in Xcode to see the code
  • Macros are sandboxed and can't read files or the network
  • Third-party macro packages ask for trust on first build
  • Expansion must type-check, so errors point at real code

Using & Defining Macros

import Observation
@Observable final class Store {           // attached macro
    var items: [String] = []              // tracked automatically
}

#Preview { ContentView() }               // freestanding: declarations
#expect(total == 42)                     // freestanding: expression
let id = #URL("https://swift.org")       // custom macro (e.g. a package)

// Declaring a macro (in the library target)
@freestanding(expression)
public macro stringify<T>(_ value: T) -> (T, String) =
    #externalMacro(module: "MyMacrosPlugin", type: "StringifyMacro")

let (v, code) = #stringify(2 + 3)        // (5, "2 + 3")

// Package.swift
// .macro(name: "MyMacrosPlugin", dependencies: [
//     .product(name: "SwiftSyntaxMacros", package: "swift-syntax"),
//     .product(name: "SwiftCompilerPlugin", package: "swift-syntax")])

Macro Roles

RoleAdds
expressionA value (#stringify)
declarationDeclarations (#Preview)
memberMembers in a type
accessorget/set on a property
extensionProtocol conformances
peerSibling declarations

Code Explained

@Observable — attached macro adds tracking
#Preview / #expect — freestanding macros
@freestanding(expression) — declare a macro
#externalMacro — points at the implementation
.macro target — swift-syntax plugin

The Swifty Way

  • ✗ hand-written boilerplate in every model
    ✓ an attached macro (if many types need it) — but plain functions first

Coming From…

⚠ Common Mistakes

  • Writing a macro where a generic function would do
  • Debugging generated code without expanding it
  • Adding swift-syntax to the app target: it belongs in the macro plugin

✓ Tips & Best Practices

  • Use the Xcode "Swift Macro" package template to start
  • Test with assertMacroExpansion from SwiftSyntaxMacrosTestSupport
  • Keep macro output small and readable

Quick Summary

  • #name — freestanding; @Name — attached
  • compile-time code generation
  • built on swift-syntax
