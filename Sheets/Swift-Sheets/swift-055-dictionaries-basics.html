Dictionaries — Basics

[K: V] · optional subscript · default: · updateValue · removeValue · keys / values

Working with Dictionaries

Dictionary<Key, Value>, written [Key: Value], stores values by unique, Hashable keys. Lookups return an optional because the key might be missing. Assigning nil to a key removes it. Order is not preserved; sort the keys or use OrderedDictionary when order matters.

Notes

  • Keys must be Hashable (String, Int, enums, your structs)
  • dict[key, default: v] reads with a fallback
  • updateValue returns the old value
  • Iteration yields (key: K, value: V) tuples

Create, Read, Change

var ages = ["Ada": 36, "Grace": 45]
var empty: [String: Int] = [:]

ages["Ada"]                               // Optional(36)
ages["Zoe"]                               // nil
ages["Zoe", default: 0]                   // 0

ages["Linus"] = 28                        // insert
ages["Ada"] = 37                          // update
ages["Grace"] = nil                       // remove
ages.updateValue(29, forKey: "Linus")     // Optional(28) (old)
ages.removeValue(forKey: "Nope")          // nil

ages.count                                // 2
ages.keys.sorted()                        // ["Ada", "Linus"]
Array(ages.values)                        // [37, 29] (any order)

var counts: [Character: Int] = [:]
for ch in "hello" { counts[ch, default: 0] += 1 }
counts["l"]                               // Optional(2)

Code Explained

[String: Int] — dictionary type
d[k] — optional lookup
d[k] = nil — remove a key
default: — fallback for reads and +=
keys / values — views, unordered

The Swifty Way

  • ✗ if d[k] == nil { d[k] = 0 }; d[k]! += 1
    ✓ d[k, default: 0] += 1

Coming From…

  • Python d.get(k, 0) ≈ d[k, default: 0]
  • TypeScript Map ≈ [K: V], but a value type here
  • Kotlin getOrDefault ≈ default:; mutableMapOf ≈ var

⚠ Common Mistakes

  • Force-unwrapping d[k]! for keys that may be missing
  • Expecting iteration in insertion order
  • Using a class with mutable fields as a key: its hash can change

✓ Tips & Best Practices

  • Use enums as keys for fixed sets of options
  • Dictionary(uniqueKeysWithValues:) builds from pairs (traps on duplicates)
  • Sort before display: d.sorted { $0.key < $1.key }

Quick Summary

  • [K: V] — hashed key/value store
  • d[k] returns optional
  • default: — fallback & counting
