Working with Arrays

Array<Element>, written [Element], is an ordered, zero-indexed collection and a value type: assigning it copies it (lazily, via copy-on-write). A let array is fully immutable. Subscripting out of range traps, so check indices or use first/last, which return optionals.

Notes

  • All elements share one type (use [any P] for mixed types)
  • append is amortized O(1); insert(at: 0) is O(n)
  • isEmpty beats count == 0
  • first / last are optional; [0] crashes on empty

Create, Read, Change

var fruits = ["apple", "banana"]          // [String]
var empty: [Int] = []
let zeros = Array(repeating: 0, count: 3) // [0, 0, 0]

fruits.append("cherry")                   // [apple, banana, cherry]
fruits += ["date", "elder"]
fruits.insert("avocado", at: 1)
fruits[0] = "apricot"
fruits.remove(at: 2)                      // returns "banana"
fruits.removeLast()                       // returns "elder"

fruits.count                              // 4
fruits.first                              // Optional("apricot")
fruits.indices.contains(10)               // false
fruits.firstIndex(of: "cherry")           // Optional(2)

var copy = fruits                         // independent copy
copy.append("fig")
fruits.count                              // still 4

Code Explained

[String] — array type shorthand
Array(repeating:count:) — prefilled
append / insert(_:at:) / remove(at:)
first / last — safe optional access
copy = fruits — value semantics

The Swifty Way

  • ✗ if arr.count > 0 { arr[0] }
    ✓ if let first = arr.first

Coming From…

  • Kotlin mutableListOf ≈ var [T]; listOf ≈ let
  • TypeScript Arrays are values here, not shared refs
  • Java ArrayList<T> ≈ [T], but copied on assign

⚠ Common Mistakes

  • arr[arr.count] or arr[0] on empty: index out of range crash
  • Expecting two variables to share one array: arrays are values
  • removeLast() on an empty array: crash; use popLast()

✓ Tips & Best Practices

  • reserveCapacity(n) before appending many items
  • arr.indices.contains(i) ? arr[i] : nil for safe lookup
  • Use ContiguousArray only after profiling
