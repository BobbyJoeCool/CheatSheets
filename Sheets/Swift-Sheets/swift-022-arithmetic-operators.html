Arithmetic Operators

+ − * / % · integer division · &+ &− &* · no ++ / −−

Math Operators

Swift has the usual + - * / % operators, but with two safety rules: both sides must be the same type, and overflow traps instead of wrapping. There are no ++ or -- operators (removed in Swift 3); use += 1. The & versions (&+ &- &*) wrap on overflow when you want that.

Notes

  • / on integers truncates toward zero
  • % is remainder (sign follows the left operand), not modulo
  • + also concatenates Strings and Arrays
  • Unary minus: -x; unary plus exists but does nothing

Arithmetic

let a = 17, b = 5
a + b                               // 22
a - b                               // 12
a * b                               // 85
a / b                               // 3
a % b                               // 2
-a % b                              // -2
Double(a) / Double(b)               // 3.4

var count = 0
count += 1                          // no count++ in Swift

UInt8.max &+ 1                      // 0   (wraps)
Int8.min &- 1                       // 127 (wraps)
// UInt8.max + 1                    // compile error (constant)
// let x: UInt8 = 255; x + 1        // runtime trap

[1, 2] + [3]                        // [1, 2, 3]
"ab" + "cd"                         // "abcd"

Code Explained

/ — integer division truncates
% — remainder keeps the left sign
+= 1 — replaces ++
&+ &- &* — wrapping (overflow) operators
+ — also joins Strings and Arrays

The Swifty Way

  • ✗ i++
    ✓ i += 1 — ++ was removed in Swift 3
  • ✗ (a % n + n) % n copied around
    ✓ a small mod(_:_:) helper — Swift has no built-in modulo

Coming From…

  • Java No ++; overflow traps instead of wrapping
  • Python 7 // 2 floors; Swift 7 / 2 truncates toward zero
  • TypeScript Int and Double never mix without conversion

⚠ Common Mistakes

  • Expecting 7 / 2 to be 3.5: convert to Double first
  • Using % as Python-style modulo on negative numbers
  • Mixing Int and Double in one expression without conversion

✓ Tips & Best Practices

  • x.quotientAndRemainder(dividingBy: y) returns both at once
  • Use multipliedReportingOverflow(by:) to detect overflow safely
  • pow is in Foundation and works on Double: pow(2.0, 10)

Quick Summary

  • + - * / % — same-type operands only
  • Overflow traps; &+ etc. wrap
  • += 1 — no ++
