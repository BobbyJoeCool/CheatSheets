Result Builders

@resultBuilder · buildBlock · buildOptional · buildEither · DSLs · @ViewBuilder

Building DSLs

A result builder turns a closure full of plain statements into a single value by calling static build… methods behind the scenes. This is the feature behind SwiftUI's @ViewBuilder, RegexBuilder and Swift Testing traits. You annotate a type with @resultBuilder, then use it as an attribute on closure parameters or properties.

Notes

  • Each line in the closure becomes an argument to buildBlock
  • buildOptional enables if without else
  • buildEither(first:) / (second:) enable if/else and switch
  • buildArray enables for loops

A Tiny HTML Builder

@resultBuilder
struct ListBuilder {
    static func buildBlock(_ parts: String...) -> [String] { parts }
    static func buildOptional(_ p: [String]?) -> String { p?.joined() ?? "" }
    static func buildEither(first p: [String]) -> String { p.joined() }
    static func buildEither(second p: [String]) -> String { p.joined() }
}

func ul(@ListBuilder _ items: () -> [String]) -> String {
    "<ul>" + items().map { "<li>\($0)</li>" }.joined() + "</ul>"
}

let loggedIn = true
let html = ul {
    "Home"
    "About"
    if loggedIn { "Account" } else { "Sign in" }
}
// <ul><li>Home</li><li>About</li><li>Account</li></ul>

Builder Methods

Code Explained

@resultBuilder — marks the builder type
buildBlock — combines the lines
buildEither — supports if/else
@ListBuilder — applied to a closure parameter

In SwiftUI

  • See SwiftUI 03 · Views & body

⚠ Common Mistakes

  • Declaring variables with let inside an old builder: some builders don't allow it
  • Expecting guard or return in a builder closure: not supported
  • Building a DSL for something a plain array literal would do

✓ Tips & Best Practices

  • Read SwiftUI compiler errors with result builders in mind: they point at buildBlock
  • Implement buildPartialBlock instead of many buildBlock overloads
  • Mark helper functions returning views @ViewBuilder to use if inside

Quick Summary

  • @resultBuilder — declarative DSLs
  • build… methods — map statements to a value
  • Powers @ViewBuilder, RegexBuilder
