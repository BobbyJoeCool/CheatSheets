while & repeat-while

while · repeat { } while · condition checks · infinite loops

Condition-Driven Loops

while checks its condition before each pass and may run zero times. repeat-while checks after each pass, so its body always runs at least once (Swift's name for do-while). Use these when you don't know the number of iterations in advance: reading input, retrying, or walking a linked structure.

Notes

  • repeat { } while cond replaces C's do { } while
  • while let keeps looping while an optional has a value
  • while true with break is fine for event loops
  • Make sure something in the body changes the condition

while & repeat-while

var n = 27, steps = 0
while n != 1 {                      // Collatz
    n = n.isMultiple(of: 2) ? n / 2 : 3 * n + 1
    steps += 1
}
print(steps)                        // 111

var attempt = 0
repeat {
    attempt += 1
    print("try \(attempt)")
} while attempt < 3 && !connect()   // body runs at least once

var stack = [1, 2, 3]
while let top = stack.popLast() {   // until empty
    print(top)                      // 3 2 1
}

while let line = readLine() {       // stdin until EOF
    print(line.uppercased())
}

Code Explained

while cond — check first, may run 0 times
repeat { } while cond — runs at least once
while let — loop while unwrapping succeeds
readLine() — next stdin line or nil at EOF

The Swifty Way

  • ✗ while !stack.isEmpty { let x = stack.removeLast() … }
    ✓ while let x = stack.popLast() { … }

Coming From…

  • Java do { } while ≈ repeat { } while
  • Kotlin do { } while ≈ repeat { } while
  • Python No do-while; while let ≈ walrus while (x := f())

⚠ Common Mistakes

  • Writing do { } while: in Swift do starts a scope or do/catch
  • Forgetting to update the condition variable: infinite loop
  • Busy-waiting in while for async work: use await instead

✓ Tips & Best Practices

  • Add a max-attempt counter to retry loops
  • while let works with iterators: var it = seq.makeIterator(); while let x = it.next()
  • Use Task.sleep(for:) inside async retry loops

Quick Summary

  • while — 0 or more passes
  • repeat-while — 1 or more passes
  • while let — drain optionals
