Subscripts & Callables

subscript · static subscript · callAsFunction · @dynamicMemberLookup

Custom Subscripts & Callable Types

A subscript lets instances be indexed with [ ], using any parameter types, labels and even several parameters. callAsFunction lets an instance be called like a function. @dynamicMemberLookup routes dot-syntax property access through a subscript, which powers wrappers like SwiftUI's Binding projections.

Notes

  • Subscripts can be get-only or get/set
  • Static subscripts work on the type: Config["key"]
  • callAsFunction can be overloaded and can take any parameters
  • Dynamic member lookup with key paths stays type-safe

Subscripts & Callables

struct Grid {
    let cols: Int
    var cells: [Int]
    subscript(row: Int, col: Int) -> Int {
        get { cells[row * cols + col] }
        set { cells[row * cols + col] = newValue }
    }
}
var g = Grid(cols: 3, cells: Array(repeating: 0, count: 9))
g[row: 1, col: 2] = 7
g[row: 1, col: 2]                           // 7

struct Multiplier {
    let k: Int
    func callAsFunction(_ x: Int) -> Int { x * k }
}
let triple = Multiplier(k: 3)
triple(5)                                   // 15

@dynamicMemberLookup
struct Wrapper<T> {
    var value: T
    subscript<V>(dynamicMember kp: KeyPath<T, V>) -> V { value[keyPath: kp] }
}
Wrapper(value: "hello").count               // 5

Code Explained

subscript(row:col:) — custom indexing
get / set — read and write
callAsFunction — instance is callable
@dynamicMemberLookup — forward properties

The Swifty Way

  • ✗ grid.value(atRow: 1, col: 2)
    ✓ grid[row: 1, col: 2] — when access is the main operation

Coming From…

  • Python __getitem__ ≈ subscript; __call__ ≈ callAsFunction
  • Kotlin operator fun get / invoke ≈ same
  • TypeScript Index signatures; no callable objects

⚠ Common Mistakes

  • Unchecked index math in subscripts: traps on bad input
  • Using @dynamicMemberLookup with String keys and losing type safety
  • Overusing callAsFunction where a named method reads better

✓ Tips & Best Practices

  • subscript(safe i: Int) -> Element? on Array gives optional access
  • Key-path dynamic members give autocomplete and type checking
  • SwiftUI's $model.name uses dynamic member lookup on Bindable

Quick Summary

  • subscript — [ ] access
  • callAsFunction — x()
  • @dynamicMemberLookup — forwarded .prop
