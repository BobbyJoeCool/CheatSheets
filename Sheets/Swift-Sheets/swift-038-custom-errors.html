Custom Errors

enum errors · associated values · LocalizedError · errorDescription · catch patterns

Designing Error Types

Errors are usually enums: one case per failure, with associated values for detail. Conform to LocalizedError to provide user-facing text through errorDescription, which shows up as error.localizedDescription. Structs work too when an error needs many fields.

Notes

  • Group errors per feature or layer: NetworkError, ParseError
  • LocalizedError adds errorDescription, recoverySuggestion
  • Make errors Equatable to compare them in tests
  • Wrap low-level errors in an underlying: Error case

Custom Errors

enum NetworkError: Error, LocalizedError, Equatable {
    case offline
    case badStatus(code: Int)
    case decoding(String)

    var errorDescription: String? {
        switch self {
        case .offline: "You're offline."
        case .badStatus(let c): "Server returned \(c)."
        case .decoding(let field): "Couldn't read \(field)."
        }
    }
}

do {
    throw NetworkError.badStatus(code: 503)
} catch let e as NetworkError {
    print(e.localizedDescription)          // Server returned 503.
} catch {
    print(error)
}

struct ValidationError: Error { let field: String; let reason: String }

Code Explained

enum … : Error — one case per failure
associated values — carry details
errorDescription — user-facing message
catch let e as NetworkError — typed catch
struct errors — when you need fields

The Swifty Way

  • ✗ throw NSError(domain: "x", code: 1)
    ✓ throw MyError.specificCase — type-safe and matchable

⚠ Common Mistakes

  • Throwing strings or Ints: they aren't Error (unless you extend them, which you shouldn't)
  • Showing "\(error)" to users: it's a debug dump; use localizedDescription
  • One giant app-wide error enum with 50 cases

✓ Tips & Best Practices

  • Add case underlying(any Error) to wrap system errors
  • Implement LocalizedError so SwiftUI .alert text is ready to use
  • Test with #expect(throws: NetworkError.offline) { … }

Quick Summary

  • enum X: Error — idiomatic error type
  • LocalizedError — user text
  • catch let e as X — handle a type
