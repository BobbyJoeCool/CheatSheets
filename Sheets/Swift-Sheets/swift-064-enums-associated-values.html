Enums That Carry Data

Each enum case can carry its own associated values of any types, making enums Swift's tagged unions. This models states precisely: a .loaded case carries data, a .failed case carries an error, and impossible combinations simply can't be represented. Extract the values with switch or if case.

Notes

  • Associated values can be labeled: case rect(w: Double, h: Double)
  • An enum can't have both raw values and associated values
  • Optional and Result are enums with associated values
  • Synthesized Equatable/Hashable work if all payloads conform

Modeling State

enum LoadState {
    case idle
    case loading(progress: Double)
    case loaded([String])
    case failed(Error)

    var isBusy: Bool {
        if case .loading = self { true } else { false }
    }
}

var state = LoadState.loading(progress: 0.4)

switch state {
case .idle:                     print("tap to load")
case .loading(let p):           print("\(Int(p * 100))%")   // 40%
case .loaded(let items) where items.isEmpty: print("nothing")
case .loaded(let items):        print(items.count)
case .failed(let error):        print(error.localizedDescription)
}

state = .loaded(["a", "b"])
if case .loaded(let items) = state { print(items) }   // ["a", "b"]
state.isBusy                                          // false

Code Explained

case loading(progress: Double) — labeled payload
case .loading(let p) — bind the payload
where — refine a case
if case — test one case
computed property — query the state

The Swifty Way

  • ✗ var isLoading: Bool; var data: [String]?; var error: Error?
    ✓ one enum LoadState — no invalid combinations

⚠ Common Mistakes

  • Using several optionals + Bools instead of one state enum
  • Writing case .loaded(_) everywhere and never using the data
  • Expecting == on enums with an Error payload: Error isn't Equatable

✓ Tips & Best Practices

  • Store the enum in your view model and switch in the view
  • Use indirect for recursive cases (Sheet 049)
  • Give cases static helper factories for common payloads

Quick Summary
