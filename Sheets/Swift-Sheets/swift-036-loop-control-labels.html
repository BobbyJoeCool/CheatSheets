Loop Control & Labels

break · continue · labeled statements · break outer · return

Controlling Loops

break ends the innermost loop (or switch), and continue skips to its next pass. To affect an outer loop from inside a nested one, give the outer loop a label and write break label or continue label. return leaves the whole function.

Notes

  • Labels work on for, while, repeat, if and switch
  • Inside a switch within a loop, plain break exits the switch
  • forEach closures can't use break/continue
  • return inside forEach only skips that element

break · continue · labels

for n in 1...10 {
    if n.isMultiple(of: 2) { continue }   // skip evens
    if n > 7 { break }                    // stop at 9
    print(n)                              // 1 3 5 7
}

let grid = [[1, 2], [3, 42], [5, 6]]
search: for (r, row) in grid.enumerated() {
    for (c, value) in row.enumerated() {
        if value == 42 {
            print("found at \(r),\(c)")   // found at 1,1
            break search                  // exits BOTH loops
        }
    }
}

outer: for i in 1...3 {
    for j in 1...3 {
        if j == 2 { continue outer }      // next i
        print(i, j)                       // 1 1, 2 1, 3 1
    }
}

Control Transfer

StatementEffect
continueNext pass of loop
breakLeave loop or switch
break labelLeave labeled statement
returnLeave the function
fallthroughRun next switch case

Code Explained

continue — next iteration
break — exit innermost loop
label: — name a loop
break label / continue label — target an outer loop

The Swifty Way

  • ✗ a found flag checked after the inner loop
    ✓ a labeled break — or move the search into a function and return

Coming From…

  • Java break outer; ≈ break outer
  • Kotlin break@outer ≈ break outer
  • Python No labels; needs a flag or a function

⚠ Common Mistakes

  • Using break inside a switch inside a loop and expecting the loop to stop
  • Trying break in forEach: compile error
  • Giving labels vague names like loop1

✓ Tips & Best Practices

  • Prefer extracting nested loops into a function that returns the result
  • Use first(where:) or contains(where:) instead of loop + break
  • Name labels after the job: search:, rows:

Quick Summary

  • break / continue — innermost loop
  • label: + break label — outer loop
  • first(where:) — often replaces the loop
