Sheet 023

Comparison Operators

== · != · < > <= >= · === · !== · tuple comparison

Comparing Values

Comparison operators return Bool. == and != work for any Equatable type; <, >, <=, >= need Comparable. For class instances, === checks whether two references point to the same object, while == compares values. Tuples of up to 6 Equatable elements compare element by element.

Notes

  • Structs and enums get == for free by declaring : Equatable
  • Strings compare by Unicode canonical equivalence
  • Optionals compare: nil == nil is true; nil < 1 is an error
  • === / !== only work on class instances

Comparisons

3 == 3                              // true
3 != 4                              // true
"apple" < "banana"                  // true (lexicographic)
(1, "b") < (1, "c")                 // true (tuple order)

struct Point: Equatable { var x, y: Int }
Point(x: 1, y: 2) == Point(x: 1, y: 2)   // true (synthesized)

class Node {}
let a = Node(), b = a, c = Node()
a === b                             // true  (same object)
a === c                             // false

let score: Int? = 90
score == 90                         // true
max(3, 9, 4)                        // 9
min("pear", "fig")                  // "fig"
(1...10).contains(5)                // true

Code Explained

== != — Equatable
< > <= >= — Comparable
: Equatable — compiler writes == for you
=== — identity of class instances
max / min — variadic, any Comparable

The Swifty Way

  • ✗ if x >= 1 && x <= 10
    ✓ if (1...10).contains(x)

Coming From…

  • Java == compares values here; === ≈ Java's == on objects
  • TypeScript No ==/=== coercion split: == is strict
  • Kotlin == ≈ ==, === ≈ === (same meaning)

⚠ Common Mistakes

  • Using == on class instances without implementing Equatable: compile error
  • Using === to compare struct values: it only works on classes
  • Comparing Doubles with == after arithmetic

✓ Tips & Best Practices

  • Add : Comparable and implement < to unlock sorted(), min(), max()
  • Compare Strings for users with localizedStandardCompare
  • clamped isn't built in: write min(max(x, lo), hi)

Quick Summary

  • == — value equality (Equatable)
  • < — ordering (Comparable)
  • === — same object (classes)
