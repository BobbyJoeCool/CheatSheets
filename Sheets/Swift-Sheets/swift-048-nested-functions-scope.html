Nesting and Scope

Functions can be declared inside other functions. A nested function is visible only in its enclosing function and can use (capture) the outer function's local variables. Every pair of braces creates a new scope; names declared inside are not visible outside, and an inner name can shadow an outer one.

Notes

  • Nested functions keep helpers private to one function
  • They can capture and modify outer vars
  • Global functions live at file scope in a module
  • do { } creates a scope without any condition

Nested Functions

func validate(_ form: [String: String]) -> [String] {
    var errors: [String] = []

    func require(_ key: String) {             // nested helper
        if form[key, default: ""].isEmpty {
            errors.append("\(key) is required")   // captures errors
        }
    }

    require("name")
    require("email")
    return errors
}
validate(["name": "Ada"])                     // ["email is required"]

let level = "global"
func show() {
    let level = "local"                       // shadows the outer one
    print(level)                              // local
    do {
        let temp = 42                         // only lives in do { }
        print(temp)
    }
    // print(temp)                            // error: not in scope
}

Coming From…

⚠ Common Mistakes

  • Calling a nested function before it's declared and expecting it to see later locals
  • Accidentally shadowing a property with a local of the same name
  • Deep nesting that hides what the outer function does

✓ Tips & Best Practices

  • Use nested functions for recursion helpers with extra parameters
  • Shadowing in if let name is idiomatic; elsewhere pick new names
  • Extract to a private method once a nested helper grows large
