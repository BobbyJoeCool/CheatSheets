Sheet 077

Reading & Writing Files

String(contentsOf:) · write(to:atomically:) · Data · FileHandle · options

Reading & Writing

Small files can be read and written in one call: String(contentsOf:encoding:) and Data(contentsOf:) for reading, write(to:atomically:encoding:) and Data.write(to:options:) for writing. For large files, stream with FileHandle or iterate lines asynchronously with url.lines. All of these throw.

Notes

  • atomically: true writes to a temp file, then swaps it in
  • Data is the raw-bytes type
  • url.lines is an AsyncSequence (iOS 15+)
  • Specify .utf8 encoding explicitly

Read, Write, Append

import Foundation
let url = URL.documentsDirectory.appending(path: "log.txt")

try "first line\n".write(to: url, atomically: true, encoding: .utf8)
let text = try String(contentsOf: url, encoding: .utf8)   // "first line\n"

let data = try Data(contentsOf: url)                      // bytes
try data.write(to: url, options: [.atomic, .completeFileProtection])

// append
let h = try FileHandle(forWritingTo: url)
defer { try? h.close() }
try h.seekToEnd()
try h.write(contentsOf: Data("second line\n".utf8))

// large files: stream lines
for try await line in url.lines {
    print(line)                                           // first line …
}

let lines = text.split(whereSeparator: \.isNewline)       // small files

Code Explained

write(to:atomically:encoding:) — save text
String(contentsOf:encoding:) — load text
Data(contentsOf:) / data.write(to:) — bytes
FileHandle + seekToEnd — append
url.lines — async line streaming

The Swifty Way

  • ✗ reading a 2 GB log with String(contentsOf:)
    ✓ for try await line in url.lines — constant memory

Coming From…

  • Python open(p).read() ≈ String(contentsOf:)
  • Kotlin File.readText() / writeText() ≈ same calls
  • TypeScript fs.readFileSync / fs.promises ≈ these

Write Options

OptionEffect
.atomicTemp file + swap
.withoutOverwritingFail if file exists
.completeFileProtectionEncrypted while locked
.noFileProtectionAlways readable

⚠ Common Mistakes

  • Using String(contentsOf:) without encoding: (deprecated)
  • Writing on the main thread in a hot path: move large I/O to a background task
  • Forgetting try: every file call throws

✓ Tips & Best Practices

  • Wrap file access in a small type that owns the URL and errors
  • Use Data("text".utf8) to turn Strings into bytes without optionals
  • Use FileHandle.standardInput / readLine() for CLI input

Quick Summary

  • String(contentsOf:) / write(to:) — text
  • Data — bytes
  • FileHandle / url.lines — stream
