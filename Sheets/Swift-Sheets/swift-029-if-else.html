Branching with if

if runs a block when its condition is true, with optional else if and else branches. Swift needs no parentheses around the condition but always requires braces. Conditions can be separated by commas and can include let unwrapping and case patterns.

Notes

  • Condition must be Bool: no truthiness
  • Braces are mandatory even for one-line bodies
  • Variables unwrapped with if let exist only inside that branch
  • Since 5.9, if can also be an expression (Sheet 031)

if / else if / else

let temp = 72

if temp > 85 {
    print("Hot")
} else if temp > 60 {
    print("Nice")                   // Nice
} else {
    print("Cold")
}

// multiple conditions with commas (all must pass)
let input: String? = "18"
if let s = input, let age = Int(s), age >= 18 {
    print("Adult: \(age)")          // Adult: 18
}

// pattern in a condition
let result: Result<Int, Error> = .success(3)
if case .success(let v) = result, v > 2 { print(v) }    // 3

if #available(iOS 17, macOS 14, *) { /* new API */ }

Code Explained

if cond { } — no parens, braces required
else if — chained checks, first match wins
if let …, cond — unwrap, then test
if case — match an enum pattern
#available — OS version check

The Swifty Way

  • ✗ if (x > 0) { … }
    ✓ if x > 0 { … } — parentheses are noise in Swift

Coming From…

  • Kotlin Same shape; if is also an expression
  • TypeScript No parens, braces always
  • Python elif ≈ else if; braces instead of indentation

⚠ Common Mistakes

  • Writing a long else if chain over one value: use switch
  • Using the unwrapped name after the if block ends: it's out of scope (use guard)
  • if #available without *: required for future platforms

✓ Tips & Best Practices

  • Put the common case first for readability
  • Use guard for preconditions so the happy path isn't nested
  • Prefer switch when checking one value against several cases
