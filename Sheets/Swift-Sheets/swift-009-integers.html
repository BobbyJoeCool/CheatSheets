Integers

Int · Int8…Int64 · UInt · .min / .max · overflow trap · 0x 0b 1_000

Integer Types

Int is the default integer and is 64 bits on all current Apple and Linux platforms. Fixed-size types (Int8 … Int64, UInt8 … UInt64) exist for interop and binary formats. Arithmetic that overflows traps at runtime instead of wrapping silently; the &+, &-, &* operators opt into wrapping.

Notes

  • Use Int unless you need a specific size
  • UInt is not a way to say "never negative": it complicates arithmetic
  • Underscores are allowed in literals: 1_000_000
  • Mixing Int and Int32 needs an explicit conversion

Literals & Limits

let a = 42                    // Int
let big = 1_000_000           // 1000000
let hex = 0xFF                // 255
let bin = 0b1010              // 10
let oct = 0o17                // 15

Int.max                       // 9223372036854775807
Int8.min                      // -128
UInt8.max                     // 255

7 / 2                         // 3   (truncates toward zero)
-7 / 2                        // -3
7 % 3                         // 1
(-7) % 3                      // -1  (sign follows dividend)
10.isMultiple(of: 5)          // true
Int.max &+ 1                  // Int.min (wraps, no trap)
Int("42")                     // Optional(42)

0x 0b 0o — hex, binary, octal literals
.max / .min — limits of each type
/ — integer division truncates
&+ — wrapping add; plain + traps on overflow
Int("42") — parsing returns an optional

The Swifty Way

  • ✗ n % 2 == 0
    ✓ n.isMultiple(of: 2) — reads as intent
  • ✗ UInt for counts
    ✓ Int (what collections use)

⚠ Common Mistakes

  • Assuming overflow wraps: Int.max + 1 crashes the app
  • Dividing two Ints and expecting a fraction: convert to Double first
  • Comparing Int with Int32 without converting: compile error

✓ Tips & Best Practices

  • Use addingReportingOverflow(_:) when you need to detect overflow without crashing
  • Use UInt8 arrays ([UInt8]) or Data for raw bytes
  • Use Int.random(in: 1...6) for random integers

Quick Summary

  • Int — default, 64-bit
  • + - * — trap on overflow; &+ &- &* wrap
  • / and % — truncate toward zero
