Sheet 011

Booleans

Bool · true / false · toggle() · Bool.random() · no implicit truthiness

The Bool Type

Bool has exactly two values, true and false. Swift has no truthiness: an Int, optional or string cannot stand in for a condition, so you always write an explicit comparison. This removes a whole class of bugs from C-family languages.

Notes

  • Conditions in if, while and guard must be Bool
  • toggle() flips a var in place
  • Name Bools as assertions: isLoading, hasError, canSubmit
  • Bool.random() returns a coin flip

Using Bools

var isOn = false
isOn.toggle()                       // true
let canVote = age >= 18             // comparison → Bool

let count = 3
// if count { }                     // error: Int is not Bool
if count != 0 { print("has items") }

let name: String? = nil
// if name { }                      // error
if name != nil { }                  // explicit check
if let name { print(name) }         // unwrap instead

let items: [Int] = []
items.isEmpty                       // true
!items.isEmpty                      // false
Bool("true")                        // Optional(true)
Bool.random()                       // true or false

Code Explained

toggle() — flips the value in place
if count != 0 — explicit, no truthiness
isEmpty — idiomatic emptiness check
Bool("true") — parses only "true" / "false"

The Swifty Way

  • ✗ if items.count == 0
    ✓ if items.isEmpty — O(1) on all collections
  • ✗ isOn = !isOn
    ✓ isOn.toggle()

Coming From…

  • TypeScript No truthy "", 0 or null
  • Python if items: must be if !items.isEmpty
  • Kotlin Same: conditions must be Boolean

⚠ Common Mistakes

  • Writing if x for an Int or optional: Swift has no truthiness
  • Expecting Bool("yes") or Bool("1") to parse: both return nil
  • Naming a Bool status or flag: callers can't tell what true means

✓ Tips & Best Practices

  • Prefer positive names (isVisible) over negative ones (isNotHidden)
  • Use an enum instead of two Bools that can't both be true
  • allSatisfy(_:) and contains(where:) compute Bools over collections

Quick Summary

  • Bool — true / false, no truthiness
  • toggle() — flip in place
  • isEmpty — preferred emptiness test
