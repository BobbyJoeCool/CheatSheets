Sheet 016

String Basics

String literals · """ multiline · #"raw"# · isEmpty · count · value semantics

Strings Are Values

String is a value type: assigning or passing it makes an independent copy (cheaply, thanks to copy-on-write). Strings are collections of Character, which are full Unicode grapheme clusters, so count is what a user sees, not the byte count. Multiline literals use triple quotes and raw strings use #.

Notes

  • count is O(n): it walks the grapheme clusters
  • Concatenate with +, += or append
  • """ lines are trimmed to the closing quote's indentation
  • Raw strings #"…"# treat \ literally

String Literals

var s = "Hello"
s += ", world"                      // "Hello, world"
s.count                             // 12
s.isEmpty                           // false

let poem = """
    Roses are red,
      violets are blue
    """                             // indentation stripped to """

let path = #"C:\Users\bob"#         // backslashes literal
let regex = #"\d+\.\d+"#
let named = #"Hi \#(name)"#         // interpolation in raw

var t = s                           // copy
t += "!"
s                                   // "Hello, world" (unchanged)

"café" == "cafe\u{301}"             // true (canonical equality)
"👨‍👩‍👧".count                       // 1

Code Explained

+= — append to a var string
""" — multiline literal
#"…"# — raw string; \#(x) interpolates
t = s — independent copy
== — compares Unicode meaning, not bytes

The Swifty Way

  • ✗ s.count == 0
    ✓ s.isEmpty — isEmpty is O(1); count is O(n)

Coming From…

  • Java Value semantics; no .equals needed
  • TypeScript .length counts UTF-16; count counts characters
  • Python Like str, but += mutates a var in place

Swift Versions

  • 5.0 — raw strings #"…"#
  • 4.0 — multiline """ literals

Escapes

EscapeMeaning
\n \tNewline, tab
\" \\Quote, backslash
\u{1F600}Unicode scalar
\ (line end)Join lines in """ literal

⚠ Common Mistakes

  • Calling count in a loop condition on a long string: it's O(n) each time
  • Expecting s[0]: integer subscripting doesn't exist (see Sheet 019)
  • Misaligned closing """: lines indented less than it are a compile error

✓ Tips & Best Practices

  • Use raw strings for regex and Windows paths
  • Build big strings with append in a loop or joined(), not repeated +
  • Use s.utf8.count when you need the byte length

Quick Summary

  • String — value type of Characters
  • """ — multiline; #"…"# — raw
  • isEmpty / count — emptiness and length
