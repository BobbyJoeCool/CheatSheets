for-in Loops

for-in · ranges · stride · enumerated() · zip · where clause

Looping with for-in

for-in iterates over any Sequence: ranges, arrays, dictionaries, sets, strings and more. There is no C-style for (i = 0; …) loop. Use enumerated() when you need the index, zip to walk two sequences together, and a where clause to filter.

Notes

  • The loop variable is a let; use var in the pattern to mutate it
  • Dictionary iteration yields (key, value) tuples, unordered
  • _ ignores the loop value: for _ in 1...3
  • forEach can't break or continue

for-in Forms

for i in 1...3 { print(i) }                  // 1 2 3
for _ in 0..<2 { print("hi") }               // hi hi

let names = ["Ada", "Grace", "Linus"]
for name in names { print(name) }

for (i, name) in names.enumerated() {
    print("\(i): \(name)")                   // 0: Ada …
}

let ages = ["Ada": 36, "Grace": 85]
for (name, age) in ages.sorted(by: { $0.key < $1.key }) {
    print(name, age)
}

for (n, a) in zip(names, [36, 85]) { }       // pairs up, stops at shorter
for n in 1...20 where n.isMultiple(of: 7) { print(n) }   // 7 14
for ch in "hey" { print(ch) }                // h e y
for i in stride(from: 10, to: 0, by: -3) { } // 10 7 4 1

Code Explained

for x in seq — any Sequence
enumerated() — (offset, element) pairs
dictionary — (key, value), unordered
zip(a, b) — walk two sequences
where — filter inside the loop header

The Swifty Way

  • ✗ for i in 0..<names.count { names[i] }
    ✓ for name in names or enumerated()

Coming From…

  • Kotlin for ((i, x) in list.withIndex()) ≈ enumerated()
  • Python enumerate / zip work the same way
  • TypeScript for…of ≈ for-in; Swift has no for…in over keys

⚠ Common Mistakes

  • Using enumerated() offsets as indices into an ArraySlice (slices don't start at 0)
  • Mutating an array while iterating it: you iterate the original copy
  • Expecting dictionary loops in insertion order

✓ Tips & Best Practices

  • Use zip(arr.indices, arr) for real indices on slices
  • Use for case let x? to skip nils
  • lazy + for avoids building intermediate arrays

Quick Summary

  • for x in seq — the only for loop
  • enumerated() / zip — indices and pairs
  • where — filter in the header
