Codable — Custom Coding

init(from:) · encode(to:) · containers · nestedContainer · PropertyListEncoder

Hand-Written Coding

When the JSON shape doesn't match your model, implement init(from:) and encode(to:) yourself. You work with containers: a keyed container for objects, an unkeyed container for arrays, and a single-value container for plain values. Nested containers flatten or build nested JSON.

Notes

  • Implementing one side doesn't stop synthesis of the other
  • decodeIfPresent returns nil for missing keys
  • Use try container.decode(T.self, forKey:) for required fields
  • PropertyListEncoder works with the same Codable types

Custom init(from:)

// JSON: {"name":"Ada","stats":{"age":36},"role":"ADMIN"}
struct User: Codable {
    var name: String
    var age: Int
    var isAdmin: Bool

    enum CodingKeys: String, CodingKey { case name, stats, role }
    enum StatsKeys: String, CodingKey { case age }

    init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        name = try c.decode(String.self, forKey: .name)
        let stats = try c.nestedContainer(keyedBy: StatsKeys.self, forKey: .stats)
        age = try stats.decodeIfPresent(Int.self, forKey: .age) ?? 0
        isAdmin = (try c.decodeIfPresent(String.self, forKey: .role)) == "ADMIN"
    }

    func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: CodingKeys.self)
        try c.encode(name, forKey: .name)
        var stats = c.nestedContainer(keyedBy: StatsKeys.self, forKey: .stats)
        try stats.encode(age, forKey: .age)
        try c.encode(isAdmin ? "ADMIN" : "USER", forKey: .role)
    }
}

Code Explained

container(keyedBy:) — JSON object
nestedContainer — reach into a sub-object
decodeIfPresent … ?? 0 — default for missing
transform on decode — String → Bool
encode(to:) — mirror the shape back

⚠ Common Mistakes

  • Forgetting a key in CodingKeys: that property silently isn't coded
  • Using decode for optional fields: throws on missing key
  • Encoding a different shape than you decode: round-trips break

✓ Tips & Best Practices

  • Decode enums with unknown values safely via a single-value container and a fallback case
  • Use a property wrapper for repeated custom rules (e.g. default values)
  • Write a round-trip test: encode → decode → ==
