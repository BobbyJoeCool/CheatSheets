Array Methods

Arrays inherit dozens of methods from Sequence and Collection. Methods ending in -ed or -ing (sorted, reversed, shuffled) return a new array; their imperative twins (sort, reverse, shuffle) mutate a var in place. Search methods return optionals.

Notes

  • sort() needs var; sorted() works on let
  • Elements must be Comparable for sort() without arguments
  • Equatable elements unlock contains(_:) and firstIndex(of:)
  • removeAll(where:) is O(n) and safe while filtering

Common Methods

var n = [5, 3, 8, 1, 9, 3]

n.sorted()                                 // [1, 3, 3, 5, 8, 9]
n.sorted(by: >)                            // [9, 8, 5, 3, 3, 1]
n.sort()                                   // mutates n
n.reversed()                               // ReversedCollection
Array(n.reversed())                        // [9, 8, 5, 3, 3, 1]

n.contains(8)                              // true
n.firstIndex(of: 3)                        // Optional(1)
n.lastIndex(of: 3)                         // Optional(2)
n.first(where: { $0 > 4 })                 // Optional(5)
n.min(); n.max()                           // Optional(1), Optional(9)

n.removeAll { $0 == 3 }                    // [1, 5, 8, 9]
n.shuffle()
n.randomElement()                          // Optional(...)
n.swapAt(0, 1)
Array(Set([1, 1, 2]))                      // unique values

Code Explained

sorted / sort — copy vs in place
sorted(by: >) — descending
firstIndex(of:) / first(where:) — search
removeAll(where:) — filter in place
randomElement() — optional random pick

The Swifty Way

  • ✗ for (i, x) in a.enumerated().reversed() { if bad(x) { a.remove(at: i) } }
    ✓ a.removeAll(where: bad)

⚠ Common Mistakes

  • Calling n.sort() and using the return value: it returns Void
  • Forgetting reversed() returns a lazy view, not an Array
  • Array(Set(x)) to dedupe when order matters: order is lost

✓ Tips & Best Practices

  • Dedupe keeping order: var seen = Set<T>(); a.filter { seen.insert($0).inserted }
  • partition(by:) splits an array in place in O(n)
  • elementsEqual(_:) compares any two sequences

Quick Summary

  • sorted vs sort — copy vs mutate
  • firstIndex / first(where:) — search
  • removeAll(where:) — in-place filter
