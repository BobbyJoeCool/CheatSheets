Characters and Unicode

A Character is one extended grapheme cluster: what a reader sees as one symbol, even if it is made of several Unicode scalars (like an emoji with a skin tone). A String also exposes views on its contents: unicodeScalars, utf8 and utf16, each with its own count.

Notes

  • Character literals use double quotes: let c: Character = "A"
  • Character has properties like isLetter, isNumber, isUppercase
  • utf16 count matches NSString.length and JavaScript .length
  • Iterating a String yields Characters

Characters & Views

let s = "Café 👍🏽"
s.count                             // 6  characters
s.unicodeScalars.count              // 7  (👍 + 🏽 modifier)
s.utf16.count                       // 9
s.utf8.count                        // 14 bytes

for ch in "a1B!" {
    print(ch, ch.isLetter, ch.isNumber, ch.isUppercase)
}                                   // a true false false …

let c: Character = "7"
c.wholeNumberValue                  // Optional(7)
Character("A").asciiValue           // Optional(65)
Character(UnicodeScalar(66))        // "B"

"é".unicodeScalars.map(\.value)     // [233]
Array("abc")                        // ["a", "b", "c"]

Code Explained

count — user-visible characters
unicodeScalars / utf16 / utf8 — encoding views
isLetter / isNumber — Unicode-aware tests
wholeNumberValue / asciiValue — numeric values

The Swifty Way

  • ✗ Array(s.utf8) to count letters
    ✓ s.count or s.filter(\.isLetter).count — bytes ≠ characters

Coming From…

  • TypeScript .length ≈ utf16.count, not count
  • Java char is UTF-16 unit; Character is a grapheme
  • Python len(s) counts code points ≈ unicodeScalars.count

⚠ Common Mistakes

  • Sending s.count to an API that expects UTF-16 or byte length
  • Assuming isNumber means ASCII 0–9: it includes other numeral systems; use isASCII && isNumber
  • Treating each unicodeScalar as a visible character

✓ Tips & Best Practices

  • Use NSRange(s.startIndex..., in: s) when bridging to NSString APIs
  • Use s.lowercased() before comparing, or localizedCaseInsensitiveCompare
  • Character.isHexDigit and hexDigitValue help parse hex

Quick Summary

  • Character — one grapheme cluster
  • utf8 / utf16 / unicodeScalars — views
  • isLetter etc. — Unicode-aware tests
