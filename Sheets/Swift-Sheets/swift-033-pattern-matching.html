Pattern Matching

case let · where · tuple patterns · range patterns · if case · for case

Patterns

Swift patterns go far beyond equality. You can bind values (case let x), add a where clause, match tuples and enum associated values, and use the same patterns outside switch with if case, guard case and for case. Under the hood, value matching uses the ~= operator.

Notes

  • _ matches anything and binds nothing
  • let can go before the whole pattern or each binding
  • where adds a Boolean condition to a case
  • case let x? matches non-nil optionals

Pattern Matching

let point = (3, 0)
switch point {
case (0, 0):          print("origin")
case (_, 0):          print("on x-axis")       // on x-axis
case (let x, let y) where x == y: print("diagonal")
default:              print("elsewhere")
}

enum Shape { case circle(r: Double), rect(w: Double, h: Double) }
let s = Shape.rect(w: 2, h: 3)
switch s {
case .circle(let r):            print(3.14 * r * r)
case let .rect(w, h) where w == h: print("square")
case .rect(let w, let h):       print(w * h)   // 6.0
}

if case .circle(let r) = s, r > 1 { }          // single case
let items: [Int?] = [1, nil, 3]
for case let n? in items { print(n) }          // 1 3

Code Explained

(_, 0) — tuple pattern with wildcard
case (let x, let y) where … — bind + condition
case .rect(let w, let h) — extract associated values
if case — one pattern without switch
for case let n? — loop only non-nil

The Swifty Way

  • ✗ switch e { case .a(let v): use(v); default: break }
    ✓ if case .a(let v) = e { use(v) }

⚠ Common Mistakes

  • Writing if case x = .ok with the sides reversed: pattern on the left, value on the right
  • Forgetting ? in for case let n?: then n is still optional
  • Putting expensive work in where: it runs for every case tried

✓ Tips & Best Practices

  • Overload ~= to let your types match in switch (e.g. regex or predicate)
  • Use case let (x, y) to bind every element at once
