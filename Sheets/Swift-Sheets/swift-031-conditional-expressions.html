Sheet 031

Conditional Expressions

?: ternary · if expressions · switch expressions · let x = if …

Choosing a Value

The ternary operator cond ? a : b picks one of two values. Since Swift 5.9, if and switch can also be expressions: each branch is a single expression and the whole statement produces a value you can assign or return. This replaces the old pattern of declaring a var and setting it in each branch.

Notes

  • Each branch of an if/switch expression must be one expression
  • All branches must produce the same type
  • if expressions require an else
  • Use ternary for short choices, expressions for anything longer

Ternary & Expressions

let age = 20
let label = age >= 18 ? "adult" : "minor"     // "adult"

// if expression (5.9+)
let fee = if age < 12 { 0.0 }
          else if age >= 65 { 5.0 }
          else { 10.0 }                       // 10.0

// switch expression
let grade = 87
let letter = switch grade {
    case 90...: "A"
    case 80..<90: "B"
    case 70..<80: "C"
    default: "F"
}                                             // "B"

func icon(for ok: Bool) -> String {
    if ok { "checkmark" } else { "xmark" }    // implicit return
}

Code Explained

c ? a : b — ternary
let x = if … { } else { } — if expression
let x = switch v { case …: value } — switch expression
implicit return — single-expression function body

The Swifty Way

  • ✗ var x: String then set in every branch
    ✓ let x = if … { } else { } — one let, checked for completeness

Coming From…

  • Kotlin val x = if (…) a else b — same idea
  • TypeScript Only ternary; no if-expressions
  • Python a if c else b ≈ c ? a : b

Swift Versions

  • 5.9 — if and switch expressions
  • 5.1 — implicit return for single-expression bodies

Which to Use

FormBest when
c ? a : bTwo short values
if expressionSeveral conditions
switch expressionMatching one value
Nested ternaryNever: hard to read

⚠ Common Mistakes

  • Putting statements (like print) in a branch of an if expression: each branch must be one expression
  • Leaving off else in an if expression
  • Nesting ternaries three deep

✓ Tips & Best Practices

  • Use switch expressions to map enums to display strings
  • Branches can call fatalError() or throw, since those return Never
  • Format multi-branch if expressions one branch per line

Quick Summary

  • ? : — ternary
  • let x = if … — if expression (5.9)
  • let x = switch … — switch expression
