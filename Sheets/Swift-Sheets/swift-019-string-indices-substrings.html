Sheet 019

String Indices & Substrings

String.Index · startIndex · index(_:offsetBy:) · Substring · prefix · suffix

Indexing into Strings

Because characters vary in size, Strings are indexed by String.Index, not Int. You move from startIndex with index(_:offsetBy:). Slicing a String produces a Substring, which shares the original's storage; convert it to String before storing it long-term.

Notes

  • endIndex is one past the last character
  • prefix(n) / dropFirst(n) avoid manual indices
  • Substring has nearly all String methods
  • index(_:offsetBy:limitedBy:) avoids out-of-bounds traps

Indices & Substrings

let s = "Hello, Swift"

s[s.startIndex]                     // "H"
let i = s.index(s.startIndex, offsetBy: 7)
s[i]                                // "S"
s[i...]                             // "Swift" (Substring)
s[..<i]                             // "Hello, "

s.prefix(5)                         // "Hello"
s.suffix(5)                         // "Swift"
s.dropFirst(7)                      // "Swift"
s.dropLast(7)                       // "Hello"

if let comma = s.firstIndex(of: ",") {
    let word = String(s[..<comma])  // "Hello" as String
}
s.index(s.startIndex, offsetBy: 50, limitedBy: s.endIndex)  // nil

Code Explained

String.Index — opaque position, not an Int
index(_:offsetBy:) — walk n characters
s[i...] / s[..<i] — range slices → Substring
prefix / suffix / dropFirst — easy slicing
String(sub) — copy into its own String

The Swifty Way

  • ✗ s[s.index(s.startIndex, offsetBy: 3)] everywhere
    ✓ Array(s)[3] once, or prefix/dropFirst — arrays give O(1) Int indexing

Coming From…

  • TypeScript s.slice(0, 5) ≈ s.prefix(5)
  • Python s[7:] ≈ s.dropFirst(7)
  • Kotlin s[7] works there; here use String.Index

Index Members

MemberMeaning

⚠ Common Mistakes

  • Using an index from one string on another: undefined results or a trap
  • Subscripting s[s.endIndex]: past the end, crashes
  • Holding a small Substring of a huge String: keeps the whole buffer alive

✓ Tips & Best Practices

  • For lots of random access, convert once: let chars = Array(s)
  • s.split(separator:) and firstIndex(of:) usually beat manual index math
  • Use limitedBy: when the offset comes from input

Quick Summary

  • String.Index — positions, not Ints
  • prefix / suffix / dropFirst — easy slices
  • Substring → String(sub) before storing
