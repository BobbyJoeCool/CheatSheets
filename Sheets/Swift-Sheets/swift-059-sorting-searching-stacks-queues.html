Sorting, Searching, Stacks & Queues

Swift's sort is stable and O(n log n). Sort by a property with a closure, or by several keys with KeyPathComparator. For stacks, a plain Array with append and popLast is ideal. Arrays make poor queues (removeFirst is O(n)); use Deque from swift-collections, or an index-based queue.

Notes

  • sort has been stable since Swift 5
  • No built-in binary search; write one or use a sorted index
  • min(by:) / max(by:) find extremes without sorting
  • Heap (swift-collections) is a priority queue

Sort, Search, Stack, Queue

struct P { let name: String; let age: Int }
let people = [P(name: "Bo", age: 30), P(name: "Al", age: 25),
              P(name: "Cy", age: 30)]

people.sorted { $0.age < $1.age }              // Al, Bo, Cy
people.sorted(using: [KeyPathComparator(\.age, order: .reverse),
                      KeyPathComparator(\.name)])   // Bo, Cy, Al
people.max { $0.age < $1.age }?.name           // "Bo"

func bsearch(_ a: [Int], _ t: Int) -> Int? {
    var lo = 0, hi = a.count - 1
    while lo <= hi {
        let mid = (lo + hi) / 2
        if a[mid] == t { return mid }
        if a[mid] < t { lo = mid + 1 } else { hi = mid - 1 }
    }
    return nil
}

var stack = [1, 2]; stack.append(3); stack.popLast()   // 3
import DequeModule
var queue: Deque = [1, 2]; queue.append(3); queue.popFirst()  // 1

Code Explained

sorted { } — custom order, stable
KeyPathComparator — multi-key sort (Foundation)
max(by:) — extreme without sorting
binary search — O(log n) on sorted arrays
append + popLast = stack; Deque = queue

The Swifty Way

  • ✗ queue.removeFirst() on an Array
    ✓ Deque.popFirst() — O(1) instead of O(n)

⚠ Common Mistakes

  • Using removeFirst() on arrays in BFS loops: quadratic time
  • Binary searching an unsorted array
  • Sorting just to find the min or max

✓ Tips & Best Practices

  • Add swift-collections for Deque, Heap, OrderedSet (Sheet 091)
  • For BFS without dependencies, keep a head index into an array
  • partitioningIndex(where:) in Swift Algorithms is a ready-made binary search

Quick Summary

  • sorted(by:) / KeyPathComparator — sorting
  • Array = stack; Deque = queue
