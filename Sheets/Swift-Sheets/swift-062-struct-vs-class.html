Struct vs Class

when to use each · copy vs share · copy-on-write · actors preview · Apple guidance

Choosing struct or class

Apple's guidance: use structs by default. Choose a class when you need identity (one shared, changing thing), inheritance, Objective-C interop, or deinit. When many tasks share mutable state, choose an actor. Value types make code easier to reason about because no one else can change your copy.

Notes

  • Stdlib collections are structs with copy-on-write storage
  • A struct holding a class reference shares that object
  • Enums are value types too
  • Actors are reference types with built-in isolation

Same Data, Two Behaviors

struct PointS { var x = 0 }
final class PointC { var x = 0 }

var s1 = PointS(); var s2 = s1
s2.x = 9
s1.x                                        // 0  (copy)

let c1 = PointC(); let c2 = c1
c2.x = 9
c1.x                                        // 9  (shared)

func bump(_ p: PointS) -> PointS { var p = p; p.x += 1; return p }
func bump(_ p: PointC) { p.x += 1 }         // mutates caller's object

// struct with a class inside: copies share the object
struct Wrapper { let ref = PointC() }
let w1 = Wrapper(); let w2 = w1
w2.ref.x = 5
w1.ref.x                                    // 5

actor Inventory { var items: [String] = [] }   // shared + safe

Code Explained

struct copy — changes stay local
class reference — changes are shared
functions — structs return new values, classes mutate
nested class in struct — still shared
actor — shared state with isolation

The Swifty Way

  • ✗ class Settings passed everywhere and mutated
    ✓ struct Settings + one owner that updates it

⚠ Common Mistakes

  • Assuming a struct is deeply immutable when it holds class references
  • Choosing class "for performance" without measuring
  • Making a large class hierarchy where protocols + structs would do

✓ Tips & Best Practices

  • If you'd want == to compare contents, it's probably a struct
  • If you'd want === (same thing), it's probably a class
  • Implement copy-on-write manually only for big custom value types

Quick Summary

  • struct by default
  • class for identity / inheritance
  • actor for shared mutable state
