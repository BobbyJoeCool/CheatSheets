XCTest

XCTest is the long-standing test framework, still required for UI tests and performance tests and found in most existing projects. Tests are methods starting with test inside an XCTestCase subclass, with setUp/tearDown around each one and XCTAssert… functions for checks.

Notes

  • Test methods must start with test and take no arguments
  • A new instance of the class is created for each test
  • UI testing uses XCUIApplication (XCTest only)
  • Can coexist with Swift Testing in one target

XCTestCase

import XCTest
@testable import MyApp

final class CartTests: XCTestCase {
    var cart: Cart!

    override func setUp() { cart = Cart() }
    override func tearDown() { cart = nil }

    func testAddIncreasesCount() {
        cart.add("apple")
        XCTAssertEqual(cart.count, 1)
    }

    func testBlankNameThrows() {
        XCTAssertThrowsError(try cart.add(named: "")) { error in
            XCTAssertEqual(error as? CartError, .blankName)
        }
    }

    func testFetch() async throws {
        let items = try await API.fetch()
        XCTAssertFalse(items.isEmpty)
    }

    func testPerformance() { measure { _ = (1...10_000).sorted(by: >) } }
}

Code Explained

XCTestCase — test class
setUp / tearDown — per-test fixtures
XCTAssertEqual / XCTAssertThrowsError
async throws test methods
measure { } — performance baseline

The Swifty Way

  • ✗ XCTAssertTrue(a == b)
    ✓ XCTAssertEqual(a, b) — the failure message shows both values

Coming From…

  • Java JUnit 4 TestCase ≈ XCTestCase
  • Python unittest.TestCase is almost identical
  • TypeScript Jest beforeEach ≈ setUp

⚠ Common Mistakes

  • Naming a method checkAdd(): it won't run without the test prefix
  • Leaving state in static vars between tests
  • Using XCTestExpectation + wait for async code that could just be async

✓ Tips & Best Practices

  • Use try XCTUnwrap(x) instead of force unwrapping in tests
  • Run one test: click the diamond in the gutter, or -only-testing: in xcodebuild
  • Keep XCTest for UI tests; write new unit tests with Swift Testing
