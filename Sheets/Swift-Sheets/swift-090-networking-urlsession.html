Networking with URLSession

URLSession · data(from:) · URLRequest · httpMethod · HTTPURLResponse · decoding

HTTP with URLSession

URLSession handles HTTP. With async/await, a request is one line: try await URLSession.shared.data(from: url) returns the body Data and a URLResponse. Check the status code yourself (non-2xx responses don't throw), then decode the body with JSONDecoder. Use URLRequest to set the method, headers and body.

Notes

  • Only transport failures throw; 404 and 500 come back normally
  • Cast the response to HTTPURLResponse for statusCode
  • App Transport Security requires HTTPS by default
  • Make your own URLSession(configuration:) for timeouts/caching

GET & POST

import Foundation
struct Todo: Codable { let id: Int; let title: String }
enum APIError: Error { case status(Int) }

func fetchTodos() async throws -> [Todo] {
    let url = URL(string: "https://api.example.com/todos")!
    let (data, response) = try await URLSession.shared.data(from: url)
    guard let http = response as? HTTPURLResponse,
          (200..<300).contains(http.statusCode) else {
        throw APIError.status((response as? HTTPURLResponse)?.statusCode ?? -1)
    }
    return try JSONDecoder().decode([Todo].self, from: data)
}

func create(_ todo: Todo) async throws {
    var req = URLRequest(url: URL(string: "https://api.example.com/todos")!)
    req.httpMethod = "POST"
    req.setValue("application/json", forHTTPHeaderField: "Content-Type")
    req.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
    req.httpBody = try JSONEncoder().encode(todo)
    let (_, resp) = try await URLSession.shared.data(for: req)
    print((resp as! HTTPURLResponse).statusCode)        // 201
}

Code Explained

data(from:) — simple GET
HTTPURLResponse.statusCode — check it yourself
URLRequest — method, headers, body
data(for:) — send a custom request
JSONDecoder().decode — parse the body

The Swifty Way

Coming From…

  • TypeScript await fetch(url) ≈ data(from:); also no throw on 404
  • Python requests.get ≈ data(from:); use raise_for_status ≈ status check
  • Kotlin Ktor / Retrofit suspend calls ≈ async URLSession

⚠ Common Mistakes

  • Assuming a 404 throws: check statusCode
  • Building query strings by hand: use URLComponents
  • Decoding on the main actor in a tight loop: fine for small JSON, move large work off

✓ Tips & Best Practices

  • Wrap requests in one APIClient type with a generic send<T: Decodable>
  • Set config.timeoutIntervalForRequest on a custom session
  • Use URLProtocol subclasses to stub the network in tests

Quick Summary

  • try await URLSession.shared.data(…)
  • check HTTPURLResponse.statusCode
  • URLRequest for method/headers/body
