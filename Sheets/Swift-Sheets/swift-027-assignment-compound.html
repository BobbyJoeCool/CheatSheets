Assignment & Compound Assignment

= · += −= *= /= · no value returned · tuple assignment · swap

Assigning Values

= assigns but, unlike C, returns nothing, so if x = y is a compile error rather than a silent bug. Compound operators (+=, -=, *=, /=, %=, &=, |=, <<= …) update a var in place. Tuples let you assign or swap several values at once.

Notes

  • Assignment returns Void, so it can't be used as a condition
  • Compound assignment works on any type that defines it (String +=)
  • swap(&a, &b) and (a, b) = (b, a) both swap
  • ??= doesn't exist; write x = x ?? default

Assignment Forms

var n = 10
n += 5                              // 15
n -= 3                              // 12
n *= 2                              // 24
n /= 5                              // 4
n %= 3                              // 1
n <<= 3                             // 8

var s = "Hi"
s += "!"                            // "Hi!"
var list = [1]
list += [2, 3]                      // [1, 2, 3]

var (x, y) = (1, 2)                 // tuple assignment
(x, y) = (y, x)                     // swap: x 2, y 1
swap(&x, &y)                        // back: x 1, y 2
list.swapAt(0, 2)                   // [3, 2, 1]

let (q, _) = (7, 99)                // ignore with _
// if n = 5 { }                     // error: '=' returns Void

Compound Operators

OpSame as
a += ba = a + b
a -= ba = a - b
a *= ba = a * b
a /= ba = a / b
a <<= na = a << n

Code Explained

+= -= *= /= %= — arithmetic compound
<<= &= |= ^= — bitwise compound
(x, y) = (y, x) — swap via tuples
swapAt(_:_:) — swap array elements
_ — discard part of a tuple

The Swifty Way

  • ✗ let t = a; a = b; b = t
    ✓ (a, b) = (b, a)

Coming From…

  • Python a, b = b, a ≈ (a, b) = (b, a)
  • Kotlin No tuple swap; Swift has it
  • TypeScript [a, b] = [b, a] ≈ tuple swap

⚠ Common Mistakes

  • Expecting a = b = 0 to chain: = returns Void
  • Calling swap(&arr[0], &arr[1]): overlapping access error; use swapAt
  • Using compound assignment on a let

✓ Tips & Best Practices

  • Use list.append(contentsOf:) for clarity over += when appending sequences
  • Use defer or a local var instead of chained assignments
  • Use inout + & to let a function assign to a caller's variable

Quick Summary

  • = — returns Void
  • += etc. — update in place
  • (a, b) = (b, a) — swap
