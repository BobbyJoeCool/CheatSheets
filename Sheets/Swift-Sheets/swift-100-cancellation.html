Task Cancellation

Task.isCancelled · checkCancellation() · cancel() · CancellationError · withTaskCancellationHandler

Cancelling Tasks

Cancellation in Swift is cooperative: calling cancel() only sets a flag. Your code checks it with Task.isCancelled or try Task.checkCancellation(), which throws CancellationError. Many system APIs (Task.sleep, URLSession) check automatically. Cancelling a parent cancels all its child tasks.

Notes

  • Nothing stops a task that never checks for cancellation
  • Task.sleep throws CancellationError when cancelled
  • SwiftUI's .task modifier cancels when the view disappears
  • withTaskCancellationHandler reacts immediately to cancel

Checking for Cancellation

func process(_ items: [Item]) async throws -> [Result] {
    var out: [Result] = []
    for item in items {
        try Task.checkCancellation()          // throws if cancelled
        out.append(await transform(item))
    }
    return out
}

func pollForever() async {
    while !Task.isCancelled {                 // non-throwing check
        await refresh()
        try? await Task.sleep(for: .seconds(30))
    }
}

let job = Task { try await process(items) }
job.cancel()
do { _ = try await job.value }
catch is CancellationError { print("stopped") }

func download(_ url: URL) async throws -> Data {
    let op = LegacyDownloader(url)
    return try await withTaskCancellationHandler {
        try await op.start()
    } onCancel: { op.abort() }                // runs right away
}

Code Explained

try Task.checkCancellation() — throw if cancelled
Task.isCancelled — Bool check
job.cancel() — request cancellation
catch is CancellationError — handle it
withTaskCancellationHandler — immediate hook

The Swifty Way

    ✓ Task.isCancelled / checkCancellation()

⚠ Common Mistakes

  • Long CPU loops with no cancellation checks
  • Showing an error alert for CancellationError: it's expected, not a failure
  • Using try? on Task.sleep inside a loop and never re-checking isCancelled

✓ Tips & Best Practices

  • Cancel the previous search Task before starting a new one
  • Store tasks in a property and cancel them in deinit or onDisappear
  • Use .task(id:) in SwiftUI to restart work when an input changes

Quick Summary

  • cancellation is cooperative
  • checkCancellation() / isCancelled
  • parent cancel → children cancel
