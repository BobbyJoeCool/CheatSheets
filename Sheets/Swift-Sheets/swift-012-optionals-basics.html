Optionals — Basics

Optional · nil · T? · force unwrap ! · if let · guard let

What an Optional Is

An optional T? holds either a value of type T or nil. Non-optional types can never be nil, so the compiler forces you to deal with missing values only where they can occur. You unwrap with if let or guard let; the force-unwrap ! crashes if the value is nil.

Notes

  • T? is shorthand for Optional<T>
  • Optionals are nil by default when declared as var
  • Many APIs return optionals: Int("x"), array.first, dict[key]
  • ! is a promise to the compiler: break it and the app crashes

Unwrapping

var nickname: String? = nil         // no value
nickname = "Ace"

if let nickname {                   // shorthand (5.7+)
    print("Hi, \(nickname)")        // String, not String?
}

if let n = Int("42"), n > 0 {       // unwrap + condition
    print(n * 2)                    // 84
}

func greet(_ name: String?) {
    guard let name else { return }  // early exit if nil
    print("Hello, \(name)")
}

let first = [1, 2, 3].first!        // 1 — crashes if empty

Code Explained

String? — may be nil
if let x — unwraps into a new non-optional constant
, n > 0 — more conditions after the unwrap
guard let … else — unwrapped value lives after the guard
! — force unwrap; traps on nil

The Swifty Way

  • ✗ if x != nil { use(x!) }
    ✓ if let x { use(x) } — one check, no force unwrap

Coming From…

  • Kotlin String? and ?. work almost the same
  • TypeScript Like strictNullChecks, enforced
  • Java Optional<T> but built into the language

Swift Versions

  • 5.7 — if let x shorthand (was if let x = x)

Unwrapping Options

SyntaxWhen

⚠ Common Mistakes

  • Force-unwrapping user input or network data: crashes on bad data
  • Nesting if let pyramids: use guard let or one if let a, let b
  • Comparing an optional Bool with if flag == true without realizing nil is false there

✓ Tips & Best Practices

  • Unwrap several at once: if let a, let b, a > b { }
  • Use guard let at the top of functions to keep the main path unindented
  • Search the project for ! before shipping

Quick Summary

  • T? — value or nil
  • if let / guard let — safe unwrap
  • ! — force unwrap, crashes on nil
