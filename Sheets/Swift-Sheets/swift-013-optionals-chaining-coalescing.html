Sheet 013

Optionals — Chaining & Coalescing

?. chaining · ?? · map / flatMap · if let x shorthand · implicitly unwrapped T!

Beyond if let

Optional chaining (?.) calls through an optional and short-circuits to nil if any link is missing. The nil-coalescing operator ?? supplies a default. Because Optional is an enum with map and flatMap, you can transform the wrapped value without unwrapping it first.

Notes

  • The result of a chain is always optional
  • ?? is lazy: the right side runs only if needed
  • T! (implicitly unwrapped) is mainly for IBOutlets
  • Optional is enum { case none, some(T) }

Chaining & Coalescing

struct User { var address: Address? }
struct Address { var city: String? }
let user: User? = User(address: Address(city: "Tripoli"))

user?.address?.city                 // Optional("Tripoli")
user?.address?.city?.count          // Optional(7)
user?.address?.city ?? "Unknown"    // "Tripoli"

let port = Int(env["PORT"] ?? "") ?? 8080   // chained ??

let n: Int? = 4
n.map { $0 * 2 }                    // Optional(8)
n.flatMap { $0 > 3 ? $0 : nil }     // Optional(4)

switch n {
case .some(let v): print(v)         // 4
case .none: print("nil")
}

Code Explained

?. — call only if non-nil, else the chain is nil
?? — default when nil
map — transform the value if present
flatMap — transform that itself may return nil
.some / .none — Optional's enum cases

The Swifty Way

  • ✗ if let c = city { return c } else { return "?" }
    ✓ return city ?? "?"

Coming From…

  • Kotlin ?. same; ?: ≈ ??
  • TypeScript ?. and ?? same syntax
  • Python No ?.; x if x is not None else d

Optional Operators

SyntaxResult type
a?.bB?
a ?? bB (or B? if b is optional)
a.map(f)U?
a.flatMap(f)U? (f returns U?)
a!A (traps on nil)

⚠ Common Mistakes

  • Expecting user?.name.count to be Int: anything after ?. is optional
  • Adding ?? "" just to silence the compiler: it hides data that is really missing
  • Declaring properties as T! to dodge initializers: crashes later instead of failing at compile time

✓ Tips & Best Practices

  • Use ?? "" only when an empty string is a real answer, not to silence the compiler
  • Collapse T?? with flatMap { $0 }
  • Optional chaining also works for assignment: user?.name = "Ada"

Quick Summary

  • ?. — optional chaining
  • ?? — default value
  • map / flatMap — transform without unwrapping
