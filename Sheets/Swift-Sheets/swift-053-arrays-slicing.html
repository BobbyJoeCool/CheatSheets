Arrays — Slicing & Ranges

ArraySlice · arr[1...3] · prefix · suffix · dropFirst · dropLast

Slices

Subscripting an array with a range returns an ArraySlice: a view that shares storage with the original. Slices keep the original's indices, so a slice of a[2...4] starts at index 2, not 0. Convert with Array(slice) before storing it or passing it to APIs that expect [T].

Notes

  • Slicing is O(1); converting to Array is O(n)
  • prefix, suffix, dropFirst, dropLast also return slices
  • split(separator:) returns [ArraySlice]
  • A slice keeps the whole original buffer alive

Slicing

let a = [10, 20, 30, 40, 50, 60]

let mid = a[2...4]                        // ArraySlice [30, 40, 50]
mid.startIndex                            // 2  (not 0!)
mid[2]                                    // 30
// mid[0]                                 // crash: index out of range
mid.first                                 // Optional(30)

a.prefix(2)                               // [10, 20]
a.suffix(2)                               // [50, 60]
a.dropFirst()                             // [20, 30, 40, 50, 60]
a.dropLast(3)                             // [10, 20, 30]
a.prefix(while: { $0 < 35 })              // [10, 20, 30]

let owned = Array(mid)                    // [30, 40, 50], indices 0…2
[1, 0, 2, 3, 0, 4].split(separator: 0)    // [[1], [2, 3], [4]]

var b = a
b.replaceSubrange(1...2, with: [0])       // [10, 0, 40, 50, 60]
b.removeSubrange(0..<2)                   // [40, 50, 60]

Code Explained

a[2...4] — slice shares storage
startIndex — slice keeps original indices
prefix / suffix / drop… — slicing helpers
Array(slice) — re-index from 0
replaceSubrange / removeSubrange — edit ranges

The Swifty Way

  • ✗ slice[0]
    ✓ slice.first or slice[slice.startIndex] — slices don't start at 0

Coming From…

  • Python a[2:5] ≈ a[2..<5] (but re-indexed there)
  • TypeScript slice() copies; Swift slices share
  • Go Slices share storage too, re-indexed from 0

Slicing Helpers

CallResult for [1,2,3,4]
prefix(2)[1, 2]
suffix(1)[4]
dropFirst(2)[3, 4]
a[1...][2, 3, 4]
a[..<1][1]

⚠ Common Mistakes

  • Indexing a slice from 0: it uses the parent's indices
  • Storing slices of large arrays long-term: memory isn't freed
  • Passing ArraySlice where [T] is required: wrap in Array(...)

✓ Tips & Best Practices

  • Write functions against some Collection<Int> to accept arrays and slices
  • Use prefix(n) instead of a[0..<n]: it never traps when n > count
  • chunks(ofCount:) from Swift Algorithms splits into fixed sizes

Quick Summary
