Variadics, Overloads, Function Types

A variadic parameter (Int...) accepts zero or more values, received as an array. Functions can be overloaded by parameter types or labels. Every function has a function type like (Int, Int) -> Int, so functions can be stored in variables, passed as arguments and returned.

Notes

  • A function may have several variadic parameters (5.4+)
  • You can't pass an array directly to a variadic parameter
  • Overloads that differ only by return type confuse inference
  • Function types are what closures conform to

Variadics & Function Values

func sum(_ nums: Int...) -> Int { nums.reduce(0, +) }
sum()                                       // 0
sum(1, 2, 3)                                // 6

func area(of side: Double) -> Double { side * side }
func area(width: Double, height: Double) -> Double { width * height }
area(of: 3)                                 // 9.0  (overload by label)

func add(_ a: Int, _ b: Int) -> Int { a + b }
func mul(_ a: Int, _ b: Int) -> Int { a * b }

var op: (Int, Int) -> Int = add             // store a function
op(3, 4)                                    // 7
op = mul
op(3, 4)                                    // 12

func apply(_ f: (Int, Int) -> Int, _ x: Int, _ y: Int) -> Int { f(x, y) }
apply(+, 2, 5)                              // 7 (operators are functions)

func makeAdder(_ n: Int) -> (Int) -> Int { { $0 + n } }
makeAdder(10)(5)                            // 15

Code Explained

Int... — variadic, arrives as [Int]
overloads — same name, different labels/types
(Int, Int) -> Int — function type
apply(+, …) — operators are functions
-> (Int) -> Int — return a function

The Swifty Way

  • ✗ func sum(_ a: [Int]) + func sum(_ a: Int...)
    ✓ one variadic version that forwards

Coming From…

  • Kotlin vararg nums: Int ≈ Int...
  • TypeScript ...nums: number[] ≈ Int...
  • Python *args ≈ variadic; no overloads there

Swift Versions

  • 5.4 — multiple variadic parameters
  • 5.9 — parameter packs each T for variadic generics

In SwiftUI

  • ViewBuilder closures are function types: () -> some View
  • See SwiftUI 03 · Views & body

⚠ Common Mistakes

  • Passing [1, 2, 3] to an Int... parameter: type mismatch
  • Overloading on return type alone: callers need annotations everywhere
  • Storing a function that captures self strongly in a property: retain cycle

✓ Tips & Best Practices

  • Use a typealias for function types used in several places
  • Pass operators directly: reduce(0, +), sorted(by: <)
  • Prefer overloads by label over Any parameters

Quick Summary

  • T... — variadic
  • Overloads by label or type
  • (A) -> B — functions are values
