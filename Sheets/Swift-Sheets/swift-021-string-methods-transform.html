String Methods — Transform

uppercased · replacing · trimmingCharacters · split · joined · reversed

Changing Strings

Transform methods return a new String (or array), leaving the original unchanged unless you use a mutating variant like append, insert or removeAll(where:). Splitting returns [Substring] with split, or [String] with Foundation's components(separatedBy:).

Notes

  • split drops empty pieces by default
  • trimmingCharacters(in:) needs Foundation
  • replacing(_:with:) is the 5.7+ stdlib form
  • joined(separator:) turns [String] back into one String

Transform Methods

import Foundation
let s = "  Hello, Swift  "

s.uppercased()                      // "  HELLO, SWIFT  "
s.lowercased()
s.trimmingCharacters(in: .whitespaces)    // "Hello, Swift"
s.replacing("Swift", with: "World")       // "  Hello, World  "

"a,b,,c".split(separator: ",")      // ["a", "b", "c"]
"a,b,,c".split(separator: ",", omittingEmptySubsequences: false)
"a,b,,c".components(separatedBy: ",")     // ["a","b","","c"]
["a", "b", "c"].joined(separator: "-")    // "a-b-c"

String("abc".reversed())            // "cba"
"swift".capitalized                 // "Swift"

var t = "Hi"
t.append("!")                       // "Hi!"
t.insert(contentsOf: ">> ", at: t.startIndex)   // ">> Hi!"

Code Explained

uppercased / lowercased / capitalized — case
trimmingCharacters(in:) — strip edges
replacing(_:with:) — every occurrence
split → [Substring]; components → [String]
reversed() — wrap in String(...)

The Swifty Way

  • ✗ s.replacingOccurrences(of: a, with: b)
    ✓ s.replacing(a, with: b) — stdlib, no Foundation needed (5.7+)

Coming From…

  • TypeScript trim() ≈ trimmingCharacters(in: .whitespaces)
  • Python s.strip().split(",") ≈ same chain
  • Kotlin split keeps empties there; Swift drops them

Character Sets

SetContains

.whitespacesAndNewlinesPlus newlines
.punctuationCharacters. , ! ?

⚠ Common Mistakes

  • Expecting split to keep empty fields when parsing CSV
  • Calling reversed() and getting a ReversedCollection instead of a String
  • Using .whitespaces and leaving trailing newlines: use .whitespacesAndNewlines

✓ Tips & Best Practices

  • s.split(whereSeparator: \.isWhitespace) splits on any whitespace
  • s.filter { !$0.isPunctuation } removes characters by test
  • Use localizedCapitalized for user-visible title case
