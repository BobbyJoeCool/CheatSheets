Bit Operators

Bitwise operators work on the binary representation of integers: AND &, OR |, XOR ^, NOT ~, and shifts << and >>. Shifting past the bit width gives 0 (or -1 for negative signed values) instead of undefined behavior. The &<< and &>> forms mask the shift amount. The Bitwise set covers patterns in depth.

Notes

  • >> on signed types is arithmetic (keeps the sign)
  • OptionSet is the Swift way to model flag bits
  • Binary literals: 0b1010; print with String(n, radix: 2)
  • See the Bitwise set for masks, tricks and interview patterns

Bit Manipulation

let a: UInt8 = 0b1100_1010           // 202
let b: UInt8 = 0b1010_0110           // 166

a & b                                // 0b1000_0010  (130)
a | b                                // 0b1110_1110  (238)
a ^ b                                // 0b0110_1100  (108)
~a                                   // 0b0011_0101  (53)
a << 1                               // 0b1001_0100  (148)
a >> 2                               // 0b0011_0010  (50)

String(a, radix: 2)                  // "11001010"
a.nonzeroBitCount                    // 4
a.leadingZeroBitCount                // 0

struct Perms: OptionSet {
    let rawValue: Int
    static let read = Perms(rawValue: 1 << 0)
    static let write = Perms(rawValue: 1 << 1)
}
let p: Perms = [.read, .write]       // p.contains(.write) == true

Code Explained

& | ^ ~ — and, or, xor, not
<< >> — shifts; over-shift is safe
nonzeroBitCount — popcount
OptionSet — named flags with set syntax

The Swifty Way

  • ✗ if flags & 2 != 0
    ✓ if perms.contains(.write) — OptionSet names every bit

Coming From…

  • Java No >>>: use an unsigned type for logical shift
  • TypeScript No 32-bit coercion; widths come from the type
  • Python Same operators; fixed widths here

⚠ Common Mistakes

  • Forgetting parentheses: a & b == 0 is a & (b == 0), a type error
  • Using >> on a negative Int and expecting zeros shifted in
  • Hand-rolling flag constants instead of an OptionSet

✓ Tips & Best Practices

  • Use UInt8/UInt32 for bit fields so shifts don't sign-extend
  • n & (n - 1) == 0 (for n > 0) tests for a power of two
  • The Bitwise set has a full page on these patterns
