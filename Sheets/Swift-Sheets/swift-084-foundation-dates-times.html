Foundation — Dates & Times

Date · Calendar · DateComponents · .formatted() · Duration · ISO8601

Working with Time

Date is a single point in time, independent of time zones and calendars. To get human parts like day or month, ask a Calendar (which knows the user's locale and time zone). For display, use .formatted(); for exchanging with servers, use ISO 8601. Duration and clocks measure elapsed time.

Notes

  • Date.now is the current moment
  • Never add 86 400 seconds for "one day": use Calendar
  • DateComponents holds year/month/day/hour pieces
  • Use ContinuousClock to measure code

Dates & Calendar

import Foundation
let now = Date.now
let cal = Calendar.current

let nextWeek = cal.date(byAdding: .day, value: 7, to: now)!
cal.component(.weekday, from: now)               // 1 = Sunday
cal.isDateInToday(now)                           // true
cal.dateComponents([.day], from: now, to: nextWeek).day   // 7

let birthday = cal.date(from: DateComponents(year: 1990, month: 4, day: 2))!

now.formatted(date: .abbreviated, time: .shortened)   // "Oct 26, 2026, 9:41 AM"
now.formatted(.iso8601)                          // "2026-10-26T14:41:00Z"
now.formatted(.relative(presentation: .named))   // "now"
let parsed = try Date("2026-10-26T12:00:00Z", strategy: .iso8601)

now.timeIntervalSince(birthday) / 86_400         // days (approx)

let elapsed = ContinuousClock().measure { heavyWork() }
print(elapsed)                                   // 0.123 seconds
try await Task.sleep(for: .seconds(2))

Code Explained

Date.now — current instant
date(byAdding:value:to:) — calendar math
DateComponents — build a date from parts
.formatted(...) — display / ISO 8601
ContinuousClock().measure — timing

The Swifty Way

  • ✗ date.addingTimeInterval(86_400)
    ✓ cal.date(byAdding: .day, value: 1, to: date) — DST days aren't 24 h

Coming From…

⚠ Common Mistakes

  • DateFormatter without en_US_POSIX locale for fixed formats
  • Storing local time strings instead of UTC ISO 8601
  • Comparing dates for "same day" with ==

✓ Tips & Best Practices

  • Use Date.ISO8601FormatStyle for API timestamps
  • Reuse formatters; creating DateFormatter repeatedly is slow
  • Use Text(date, style: .relative) in SwiftUI
