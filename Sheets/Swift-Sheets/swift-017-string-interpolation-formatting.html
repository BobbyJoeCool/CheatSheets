String Interpolation & Formatting

\() · custom interpolation · .formatted() · FormatStyle · String(format:)

Building Strings

String interpolation \(expr) embeds any expression in a literal. For numbers, dates and lists, Foundation's FormatStyle API (.formatted()) produces locale-aware text and is the modern replacement for String(format:) and the older Formatter classes.

Notes

  • Any expression can go inside \( ), including calls
  • .formatted() respects the user's locale
  • String(format:) uses C-style %d %.2f %@ specifiers
  • Custom interpolation: extend DefaultStringInterpolation

Interpolation & formatted()

import Foundation
let name = "Ada", score = 92.456, n = 1234567

"Hi \(name), you scored \(score)"   // ... 92.456
"Sum: \(2 + 3)"                     // Sum: 5

score.formatted(.number.precision(.fractionLength(1)))  // "92.5"
n.formatted()                       // "1,234,567"
0.256.formatted(.percent)           // "25.6%"
19.99.formatted(.currency(code: "USD"))   // "$19.99"
Date.now.formatted(date: .abbreviated, time: .omitted)
["a", "b", "c"].formatted()         // "a, b, and c"

String(format: "%.2f", score)       // "92.46"
String(format: "%05d", 42)          // "00042"
String(format: "%@ is %d", name, 36)    // "Ada is 36"

Code Explained

\(expr) — interpolate any value
.formatted() — locale-aware formatting
.precision(.fractionLength(n)) — decimal places
.currency(code:) / .percent — styles
String(format:) — printf-style

The Swifty Way

  • ✗ String(format: "%.1f%%", p * 100)
    ✓ p.formatted(.percent) — locale-correct for free

Coming From…

  • TypeScript ${x} ≈ \(x); Intl ≈ FormatStyle
  • Kotlin "$x" ≈ "\(x)"
  • Python f-strings; f"{x:.2f}" ≈ precision style

⚠ Common Mistakes

  • Passing a Swift Int to %@ or a String to %d in String(format:): garbage or a crash
  • Hard-coding "," separators and $ signs: breaks in other locales
  • Interpolating an optional: prints Optional(…) and warns

✓ Tips & Best Practices

  • Use .formatted(.number.grouping(.never)) to drop thousands separators
  • Pass locale: Locale(identifier: "en_US_POSIX") for machine-readable output
  • Use Text(score, format: .percent) in SwiftUI with the same styles

Quick Summary

  • \(x) — interpolation
  • .formatted(...) — modern, locale-aware
  • String(format:) — C-style specifiers
