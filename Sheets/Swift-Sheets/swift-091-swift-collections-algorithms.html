Extra Collections & Algorithms

Two official Apple packages fill gaps in the standard library. swift-collections adds data structures: Deque, OrderedSet, OrderedDictionary, Heap and more. swift-algorithms adds sequence operations: chunking, windows, combinations, permutations, uniqued() and more. Both are maintained by the Swift team.

Notes

  • Add https://github.com/apple/swift-collections and …/swift-algorithms
  • Import the umbrella Collections or a single module (DequeModule)
  • Heap is a min-max heap: popMin() and popMax()
  • Algorithms methods are lazy where possible

Collections & Algorithms

import Collections
import Algorithms

var q: Deque = [1, 2, 3]
q.prepend(0); q.popFirst()                // 0, O(1) at both ends

var tags: OrderedSet = ["b", "a", "b"]    // ["b", "a"] keeps order
var scores: OrderedDictionary = ["zed": 1, "amy": 2]
scores.keys.first                         // "zed" (insertion order)

var heap = Heap([5, 1, 9, 3])
heap.popMin()                             // 1
heap.popMax()                             // 9

let nums = Array(1...7)
nums.chunks(ofCount: 3).map(Array.init)   // [[1,2,3],[4,5,6],[7]]
nums.windows(ofCount: 3).first.map(Array.init)   // [1, 2, 3]
[1, 2, 1, 3].uniqued().map { $0 }         // [1, 2, 3]
["a", "b", "c"].combinations(ofCount: 2).count   // 3
[1, 2, 3].permutations().count            // 6
nums.adjacentPairs().first                // (1, 2)

Code Explained

Deque — fast at both ends
OrderedSet / OrderedDictionary — keep order
Heap — min and max priority queue
chunks / windows — split sequences
uniqued / combinations / permutations

The Swifty Way

  • ✗ Array(Set(xs)) to dedupe
    ✓ xs.uniqued() — keeps the original order

⚠ Common Mistakes

  • Pulling in a third-party queue when Deque exists
  • Forgetting Array(...) around chunks/windows when you need arrays
  • Expecting OrderedDictionary subscripts by Int index (use .elements[i])

✓ Tips & Best Practices

  • Import only the module you need (HeapModule) to keep builds lean
  • partitioningIndex(where:) gives binary search on sorted data
  • striding(by:) and product(_:_:) replace nested index loops
