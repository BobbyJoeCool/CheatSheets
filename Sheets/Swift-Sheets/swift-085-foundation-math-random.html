Foundation — Math & Random

Int.random(in:) · randomElement() · abs · pow · min / max · Measurement

Numbers, Math & Randomness

Basic math (abs, min, max, squareRoot(), rounded()) is in the standard library; C-style functions like pow, sin and log come from Foundation. Every numeric type has random(in:), and collections have randomElement() and shuffled(). Measurement adds unit-aware values and conversions.

Notes

  • random(in:) uses a cryptographically secure generator by default
  • Pass your own RandomNumberGenerator for repeatable results
  • Double.pi, .squareRoot() need no Foundation
  • Measurement formats in the user's preferred units

Math & Random

import Foundation
abs(-7)                                   // 7
min(3, 8, 1); max(3, 8, 1)                // 1, 8
16.0.squareRoot()                         // 4.0
pow(2.0, 10)                              // 1024.0
sin(Double.pi / 2)                        // 1.0
log10(1000.0)                             // 3.0
(7.0).rounded(.up)                        // 7.0

Int.random(in: 1...6)                     // dice roll
Double.random(in: 0..<1)
Bool.random()
["red", "green", "blue"].randomElement()  // Optional("green")
[1, 2, 3, 4].shuffled()

let run = Measurement(value: 5, unit: UnitLength.kilometers)
run.converted(to: .miles).value           // 3.106…
run.formatted()                           // "5 km" (or "3.1 mi" in US)

var g = SystemRandomNumberGenerator()
Int.random(in: 1...100, using: &g)

Coming From…

  • Python random.randint(1, 6) ≈ Int.random(in: 1...6)
  • TypeScript Math.random() ≈ Double.random(in: 0..<1)
  • Kotlin (1..6).random() ≈ same

⚠ Common Mistakes

  • Calling pow with Int arguments: it expects floating point
  • Seeding your own generator for security-sensitive values
  • Showing raw unit numbers instead of Measurement.formatted()

✓ Tips & Best Practices

  • Write a seeded generator for reproducible tests and games
  • Use Swift Numerics for complex numbers and more math functions
  • Decimal for money; Double for measurements
