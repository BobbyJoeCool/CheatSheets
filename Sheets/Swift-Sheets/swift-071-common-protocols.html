Everyday Protocols

A handful of standard protocols unlock most of the language's conveniences. For structs and enums, the compiler can synthesize Equatable, Hashable, Comparable (enums), and Codable just from the declaration, as long as every stored property conforms too.

Notes

  • Synthesis needs all stored properties to conform
  • Identifiable needs an id that's Hashable
  • Sendable marks types safe to share across concurrency domains
  • CustomStringConvertible controls print output

Conformance in One Line

struct User: Identifiable, Hashable, Codable, Sendable {
    let id: UUID
    var name: String
    var age: Int
}

let a = User(id: UUID(), name: "Ada", age: 36)
let b = a
a == b                                      // true  (Equatable via Hashable)
Set([a, b]).count                           // 1     (Hashable)
let json = try JSONEncoder().encode(a)      // Codable

enum Priority: Comparable { case low, medium, high }
Priority.low < .high                        // true (synthesized order)
[Priority.high, .low].sorted()              // [.low, .high]

extension User: Comparable {
    static func < (l: User, r: User) -> Bool { l.name < r.name }
}
[a].sorted()                                // by name

enum Comparable — case order, synthesized

The Swifty Way

  • ✗ hand-written == comparing every field
    ✓ : Equatable (synthesized) — stays correct when fields change

Coming From…

  • Kotlin data class gives equals/hashCode ≈ synthesis
  • Java record auto-generates equals/hashCode
  • Python @dataclass(eq=True, frozen=True)

In SwiftUI

  • List(users) needs Identifiable
  • NavigationLink(value:) needs Hashable values
  • See SwiftUI 26 · Lists

⚠ Common Mistakes

  • Using an array index or changing value as id: breaks diffing
  • Expecting synthesis when one property doesn't conform
  • Marking a class Sendable with mutable state: compiler error

✓ Tips & Best Practices

  • Customize synthesis by implementing just == or hash(into:)
  • Exclude a property from Codable with a custom CodingKeys
  • Use UUID() or server IDs for Identifiable.id
