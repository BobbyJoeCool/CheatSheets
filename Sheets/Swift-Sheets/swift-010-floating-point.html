Floating-Point & Decimal

Double · Float · Decimal · .infinity · .nan · rounded() · truncatingRemainder

Floating-Point Numbers

Double (64-bit) is the default for decimal literals; Float (32-bit) is used mainly for graphics and ML APIs. Both follow IEEE 754, so 0.1 + 0.2 is not exactly 0.3, and special values .infinity and .nan exist. For money, use Foundation's Decimal, which stores base-10 digits exactly.

Notes

  • 3.0 is a Double; write Float(3.0) or annotate for Float
  • Dividing by zero gives ±.infinity, not a crash
  • .nan != .nan is true; test with .isNaN
  • rounded() takes a FloatingPointRoundingRule

Doubles in Practice

let d = 3.75                        // Double
let f: Float = 3.75                 // Float
let e = 1.5e3                       // 1500.0

0.1 + 0.2 == 0.3                    // false
abs((0.1 + 0.2) - 0.3) < 1e-9       // true

d.rounded()                         // 4.0
d.rounded(.down)                    // 3.0
d.rounded(.towardZero)              // 3.0
(2.5).rounded(.toNearestOrEven)     // 2.0
Int(d)                              // 3 (truncates)

1.0 / 0                             // inf
(0.0 / 0).isNaN                     // true
7.5.truncatingRemainder(dividingBy: 2)   // 1.5
Double.pi                           // 3.141592653589793

⚠ Common Mistakes

  • Comparing floats with ==: use a tolerance
  • Using % on a Double: compile error; use truncatingRemainder(dividingBy:)
  • Storing money in Double: rounding errors add up

✓ Tips & Best Practices

  • Format for display with .formatted(.number.precision(…)) (Sheet 017)
  • Use Decimal(string: "19.99") rather than Decimal(19.99) to avoid binary error
  • Swift Numerics adds isApproximatelyEqual(to:)

Quick Summary

  • Double — default floating type
  • rounded(_:) — explicit rounding rules
  • Decimal — exact base-10 for money
