switch — Basics

switch · case · default · exhaustiveness · no implicit fallthrough · fallthrough

The switch Statement

switch compares a value against cases and runs the first match. It must be exhaustive: every possible value is covered, either by listing every case (common with enums) or with default. There is no implicit fallthrough, so no break is needed at the end of a case.

Notes

  • A case can list several values: case "a", "e", "i":
  • Cases can match ranges, tuples and patterns
  • fallthrough exists but is rarely used
  • Every case needs at least one statement (break if empty)

switch Basics

let ch: Character = "e"
switch ch {
case "a", "e", "i", "o", "u":
    print("vowel")                  // vowel
case "y":
    print("sometimes")
default:
    print("consonant")
}

let score = 85
switch score {
case 90...100: print("A")
case 80..<90:  print("B")           // B
case ..<0:     break                // do nothing
default:       print("other")
}

enum Direction { case north, south, east, west }
let d = Direction.east
switch d {                          // no default needed
case .north, .south: print("vertical")
case .east, .west:   print("horizontal")
}

Case Forms

Code Explained

case a, b: — several values
case 80..<90: — range match
default: — catch-all
break — empty case body
enum switch — exhaustive without default

The Swifty Way

  • ✗ default: on your own enum
    ✓ list every case — the compiler then flags new cases you forgot

Coming From…

  • Java No break needed; no fall-through bugs
  • Kotlin when ≈ switch; both exhaustive on enums
  • Python match (3.10) is similar

⚠ Common Mistakes

  • Expecting fall-through into the next case like C
  • Leaving a case body empty: needs at least break
  • Adding default to enum switches and missing new cases later

✓ Tips & Best Practices

  • Use @unknown default: when switching over enums from Apple frameworks
  • Switch on tuples to handle two values at once (Sheet 033)
  • Use a switch expression when every case produces a value

Quick Summary

  • switch — exhaustive, first match wins
  • No implicit fallthrough
  • case a, b / ranges / enums
