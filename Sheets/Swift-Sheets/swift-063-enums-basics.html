Enumerations

An enum defines a type with a fixed set of cases. Swift enums are full types: they can have raw values (String, Int), methods, computed properties and protocol conformances. switch over an enum must cover every case, so adding a case shows you every place that needs updating.

Notes

  • Cases are lowerCamelCase: case north
  • Raw-value enums get init?(rawValue:) for free
  • CaseIterable adds allCases
  • Use .case shorthand when the type is known

Enums with Raw Values

enum Suit: String, CaseIterable {
    case hearts = "♥", diamonds = "♦", clubs = "♣", spades = "♠"

    var isRed: Bool { self == .hearts || self == .diamonds }
}

let s = Suit.hearts
s.rawValue                                  // "♥"
Suit(rawValue: "♣")                         // Optional(.clubs)
Suit(rawValue: "x")                         // nil
Suit.allCases.count                         // 4
s.isRed                                     // true

enum Level: Int, Comparable {
    case low = 1, medium, high              // 1, 2, 3 (auto)
    static func < (a: Level, b: Level) -> Bool { a.rawValue < b.rawValue }
}
Level.high.rawValue                         // 3
Level.low < .high                           // true

var dir: Suit = .spades                     // shorthand

Code Explained

enum X: String — raw values
init?(rawValue:) — failable from raw
CaseIterable / allCases — every case
computed property on an enum
auto-incrementing Int raw values

The Swifty Way

  • ✗ let status = "active"
    ✓ enum Status { case active, paused } — typos become compile errors

Coming From…

  • TypeScript String-literal unions ≈ String enums
  • Java Java enums ≈ these, plus allCases

⚠ Common Mistakes

  • Using rawValue strings around the app instead of the enum
  • Adding default: to switches over your own enum: hides new cases
  • Force-unwrapping init(rawValue:) on external data

✓ Tips & Best Practices

  • String raw values are auto-filled with the case name if omitted
  • Enums with String raw values are Codable for free
  • Use a caseless enum as a namespace for constants
