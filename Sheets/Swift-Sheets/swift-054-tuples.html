(a, b) · named elements · destructuring · multiple return values · _ ignore

Tuples

A tuple groups a fixed number of values, possibly of different types, into one compound value: (Int, String). Elements can be accessed by position (.0) or by name if labeled. Tuples are perfect for returning several values or short-lived groupings; use a struct once the data has meaning beyond one function.

Notes

  • Tuples up to 6 elements are Equatable/Comparable if elements are
  • Tuples can't conform to protocols (not Hashable, not Codable)
  • () is the empty tuple, which is Void
  • Destructure with let (a, b) = t; ignore with _

Tuples

let http404 = (404, "Not Found")
http404.0                                 // 404
http404.1                                 // "Not Found"

let status = (code: 200, message: "OK")   // named elements
status.code                               // 200

let (code, message) = status              // destructure
let (onlyCode, _) = status                // ignore part

func stats(_ xs: [Double]) -> (mean: Double, max: Double) {
    (xs.reduce(0, +) / Double(xs.count), xs.max() ?? 0)
}
let s = stats([2, 4, 9])
print(s.mean, s.max)                      // 5.0 9.0

(1, "b") == (1, "b")                      // true
(2, "a") < (2, "b")                       // true

for (name, score) in [("Ada", 9), ("Bo", 7)] { print(name, score) }

Code Explained

.0 .1 — positional access
(code: …, message: …) — named elements
let (a, b) = t — destructuring
tuple return — lightweight multi-value
== / < — element-wise comparison

⚠ Common Mistakes

  • Trying to use a tuple as a Dictionary key or Set element: not Hashable
  • Accessing .2 on a 2-element tuple: compile error
  • Long unnamed tuples that force readers to count positions

✓ Tips & Best Practices

  • Name tuple elements in return types; callers get autocomplete
  • zip and enumerated yield tuples you can destructure in for
  • Swap with tuples: (a, b) = (b, a)

Quick Summary

  • (A, B) — fixed-size group
  • .0 or .name — access
  • Struct when it outgrows one use
