Keeping the Bill Predictable

FinOps is the habit of making cloud spend visible, owned and optimized. The loop is the same on every provider: tag resources so costs map to teams, watch with budgets and cost explorers, optimize by deleting idle resources, rightsizing, and buying commitments for steady use. Most waste is forgotten resources, oversized instances, and data transfer nobody priced.

Key Points

  • Tags (AWS, Azure) and labels (Google Cloud) drive cost allocation reports
  • Billing exports to a data store allow your own analysis
  • Advisors recommend rightsizing and commitments
  • Unattached disks, idle IPs, old snapshots and NAT gateways are common leaks

Find Spend and Waste

# AWS: last month's cost by service
aws ce get-cost-and-usage --time-period Start=2026-10-01,End=2026-11-01 \
    --granularity MONTHLY --metrics UnblendedCost \
    --group-by Type=DIMENSION,Key=SERVICE
aws ec2 describe-volumes --filters Name=status,Values=available

# Azure: cost advice and unattached disks
az advisor recommendation list --category Cost -o table
az disk list --query "[?diskState=='Unattached'].[name,diskSizeGb]" -o table

# Google Cloud: export billing to BigQuery, then query it
bq query --use_legacy_sql=false '
  SELECT service.description AS svc, ROUND(SUM(cost), 2) AS usd
  FROM `billing.gcp_billing_export_v1_XXXX`
  WHERE invoice.month = "202610" GROUP BY svc ORDER BY usd DESC'
gcloud recommender recommendations list --project=app-prod \
    --location=us-central1-a \
    --recommender=google.compute.instance.MachineTypeRecommender

Code Explained

Cost Explorer groups spend by service, tag or account
status=available EBS volumes are attached to nothing
Azure Advisor lists rightsizing and reservation advice
Google Cloud billing export to BigQuery is the standard reporting path

Across the Clouds

  • AWS Cost Explorer, Budgets, Compute Optimizer (aws-02, aws-16)
  • Azure Cost Management, Advisor, Reservations (az-02, az-16)
  • Google Cloud Billing reports, BigQuery export, Recommender (gcp-02, gcp-16)

Rule of Thumb

  • Tag first: you cannot optimize what you cannot attribute
  • Delete before you optimize: idle resources are pure waste
  • Commit only to the baseline you have run for 3+ months

Do & Don't

  • Do Enforce required tags / labels with policy
  • Do Shut down dev and test environments outside working hours
  • Don’t Wait for the monthly invoice to notice a spike
  • Don’t Buy commitments before rightsizing

Local Testing

  • Infracost shows cost changes in Terraform pull requests
  • Pricing calculators estimate designs before building
  • Run cost queries against a billing export sample

Production Checklist

  • Budgets with anomaly detection per team
  • Tag policy enforced; untagged resources reported
  • Monthly FinOps review with owners
